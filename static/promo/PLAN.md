# 《数学阶梯 · 从 1+1 到前沿》宣传片 · 制作规划

> 这是**完整版（2 分 47 秒 · 12 幕）**的规划。
> **快闪版（45 秒 · 13 刀硬切）**的设计在 [`PLAN-short.md`](./PLAN-short.md)，
> 两支片子的用法与二次修改在 [`README.md`](./README.md)。

> 交付形态：**一个自包含的 HTML 文件**（`static/promo/index.html`）。
> 画面 = Canvas2D + WebGL 实时程序化生成；音乐 = Web Audio 实时合成。
> 全片**不加载任何图片、音频、视频、字体、CDN 资源**，双击即播，离线可跑。

---

## 0. 三条硬约束与对应做法

| 约束 | 做法 |
| --- | --- |
| 画面要炫技 | GPU 粒子流场、片元着色器分形上色、Bloom 后处理、色差/颗粒/暗角、3D 线框矩阵变换、实时卷积混响 |
| 画面要流畅 | 单 rAF 主循环 + 音频时钟驱动时间轴（掉帧不跑偏）、零逐帧分配、DPR 上限、自适应降级（掉帧自动减粒子/关 Bloom） |
| 不许用图片/视频/生成模型 | 所有像素由 shader 与 draw call 现算；所有声音由振荡器与噪声现合成；录屏走浏览器 `MediaRecorder`（编码，不是生成） |

## 1. 分镜（总长约 165 秒 · 12 幕）

贯穿母题：**阶梯**。每幕收尾，画面下缘亮起一级台阶，台阶随全片累积上升；
最后一幕所有台阶连成完整的六卷阶梯。

| # | 时间 | 幕 | 画面（炫技点） | 文案 |
| --- | --- | --- | --- | --- |

| 1 | 0:08–0:22 | 算术 · 1+1 | 128k 粒子被吸引到格点，逐点点亮成计数阵列；`1+1=2` 由粒子聚合而成 | 从 1+1 开始 |
| 2 | 0:22–0:36 | 代数 · 未知数 | 数字熔成符号 x；天平两端同步变形；抛物线 y=x² 生长，判别式三态掠过 | 字母登场，式子开始说话 |
| 3 | 0:36–0:52 | 几何与三角 · 旋转 | 单位圆上一点旋转，投影出正弦波；三点同时旋转叠出拍频；圆的周长滚动展开成 π | 给公式一张看得见的脸 |

## 2. 音乐设计（Web Audio 实时合成，无采样）

- **调性**：C 大调起步 → 第 8 幕转 a 小调（借用降 E 色彩）→ 第 9 幕回 C 大调高潮 → 收束长音收尾。
- **速度**：84 BPM（幕 0–2）→ 96（幕 3–4）→ 112（幕 5–7）→ 126（幕 8–9）→ 收束自由延长。
- **配器（全部合成）**：
  | 音色 | 合成法 |
  | --- | --- |
  | 钟 / 拨弦 | FM（正弦载波 + 正弦调制），指数衰减包络 |
  | 铺底 Pad | 三路失谐锯齿 + 低通 + 缓慢 LFO |
  | 贝斯 | 锯齿 → 低通包络（每拍重触发） |
  | 底鼓 | 正弦 110→45 Hz 下滑 + 快包络 |
  | 军鼓 | 白噪声带通 + 短衰减 + 一点点音高 |
  | 踩镲 | 高通白噪声 4 ms |
  | 上升音 | 噪声扫频 + 音高上行，用于幕间转场 |
  | 混响 | 程序生成脉冲响应（噪声 × 指数衰减）走 ConvolverNode |
- **调度**：lookahead 调度器（每 25 ms 排未来 120 ms 的音符），音符时间戳全部来自 `AudioContext.currentTime`，
  与画面共用同一个 transport 时钟 → **音画永不漂移**，即使渲染掉帧。
- **和声进行**：I–V–vi–IV → vi–IV–I–V → 加九音与 sus 色彩。

## 3. 技术架构

```
┌─ WebGL 画布（底层） ────────────────────────────────┐
│  · 背景场：透视方格 + 纸纹噪点 + 暗角（全片常驻）      │
│  · 粒子系统：256k 点精灵，顶点着色器里做流场（CPU 不动）│
│  · 3D 线框：矩阵变换幕 / 神经网络幕                    │
│  · 片元着色器：复数域上色 / 曼德博 / 双曲镶嵌          │
│  · 后处理：亮部提取 → 两级高斯（半分辨率）→ 合成        │
│           （加色差、胶片颗粒、暗角、扫描线）            │
└──────────────────────────────────────────────────┘
┌─ Canvas2D 画布（上层，叠加） ────────────────────────┐
│  公式、坐标轴、单位圆、黎曼矩形、高尔顿板、傅里叶本轮、  │
│  阶梯、字幕、印章 —— 全部矢量绘制，带 shadowBlur 辉光    │
└──────────────────────────────────────────────────┘
```

- **时钟**：`audio.currentTime` 为唯一真源；主循环用固定逻辑步长（1/120 s）累积，渲染用插值。
- **零 GC**：所有数组预分配，幕内不做逐帧分配；字符串只在字幕切换时生成。
- **自适应质量**：滚动平均帧时长 > 20 ms 逐级降（粒子 256k→128k→64k，Bloom 关，DPR 1.5→1）；
  连续 3 秒 < 14 ms 再升回去。按 `F` 显示 FPS/质量档，`空格` 暂停，`R` 重播，数字键跳幕。
- **录屏**：页面内置「录制」按钮 —— `canvas.captureStream(60)` + `MediaStreamAudioDestinationNode`
  合成一条流交给 `MediaRecorder`（VP9/Opus），录完直接下载 `.webm`；再用 ffmpeg 转 mp4。

## 4. 验收标准

1. 无头浏览器加载，控制台**零报错**；
2. 逐幕截图（12 张）人眼过一遍，每幕都要「看得出在讲什么」；
3. 关掉音频画面照样跑完整片；
4. 输出 `README.md` 讲清楚：怎么播、怎么录、怎么转 mp4、怎么改文案与时长。

**实际交付时的验收结果**（详见 [`README.md`](./README.md) 第五节）：

| 项 | 结果 |
| --- | --- |
| 控制台 | 零报错零警告（12 幕定格 + 整片 167s 真实播放） |
| 逐幕截图 | 12/12 出画，另出拼图便于扫全片 |
| 整片播放 | 167.0s 播完自动停，无累积异常 |
| 配乐 | Web Audio 电平探针确认有输出（RMS 0.02–0.05 且起伏） |
| 出片 | 内置录制 + 无头 `record.mjs` 两条路都能落盘，ffmpeg 转 mp4 确认含 **AAC 立体声音轨** |
| 竖屏 | 500×900 自适应不崩 |
| 修复的 bug | ① 跳幕起播给 `AudioParam` 传负数时间（RangeError）；② 录制时音频图未初始化导致成片无声；③ 傅里叶轨迹逐帧累积 → 改成解析窗口，任何帧率下波形一致 |
