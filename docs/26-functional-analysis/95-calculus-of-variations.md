# 变分法选讲：Euler-Lagrange 与最速降线

## 1. 从一个场景开始

两点之间连一根滑道，小球从高点静止释放。滑道可以笔直通到底，也可以先陡后缓地拐个弯——**形状由你设计**。哪一条让小球最先到达终点？

伽利略猜过答案（他押了圆弧，错了）；1696 年约翰·伯努利把这道"最速降线问题"公开悬赏半年，牛顿匿名用一个通宵寄去解答，伯努利一眼认出："我从狮子的爪印记出了狮子。"注意这道题真正奇怪的地方：待求的**不是一个数**——坡度多大？耗时几秒？都不是。待求的是**一整条曲线的形状**。微分学那套"导数为零找极值"的老地图在这里整个失效，需要一张新地图。

## 2. 直觉解释

把新旧两种优化并排放好，差异就一目了然：

| 维度 | 普通极值 | 变分法 |
| --- | --- | --- |
| 候选解 | 数轴上的一个数 $x$ | 函数空间里的一条曲线 $y(x)$ |
| 比较工具 | 函数值 $f(x)$ | 泛函值 $J[y]$ |
| 提问方式 | 它等于几？ | 它长什么样？ |

所以这一课要讲透的头号问题是：**函数的自变量还是函数吗？**答：在变分问题里，函数自己降级成了自变量。把每条候选曲线送进一台读数机，它吐出一个实数；我们比较的是这些数。这种"吃函数、吐数字"的机器叫**泛函**——正是本章反复排练的那句话"函数是空间中的点"的兑现：每条候选曲线是这个空间里的一个点，泛函就是架在这空间上的海拔计，我们要找的是盆底那一个点。

无穷多候选怎么比？先暴力降维：把区间钉死成有限个格子，曲线只许在格点上转折——形状海洋立刻塌缩成几个高度数字，又回到老手艺"挑数组挑最小"。但动手前记住一刀工细节：每段的贡献都要乘上这一段自己的**宽度**再累加，长短不同的话语权就不同。这行字看着平淡，本课的判题练习就埋在这里。

## 3. 正式定义

**泛函**是从函数集合到实数的映射，最常见的形态是带参积分：

$$J[y]=\int_{x_0}^{x_1}F\big(x,\ y(x),\ y'(x)\big)\ dx$$

| 符号 | 含义 |
| --- | --- |
| $J[y]$ | 泛函：方括号提醒你输入的是整条函数 $y$，不是某个点的值 |
| $F$ | 读数规则：位置、高度、斜率如何折算成每一小段的成绩 |
| $y'$ | 曲线的斜率：弯曲方式要参与计费 |
| $x_0,x_1$ 与端点条件 | 铆钉：两端的高度固定，比赛才公平 |

**变分问题**：在所有满足端点条件的曲线中，找出使 $J[y]$ 达到最小的那条。

类似"普通函数在极值点导数为零"，泛函的最优曲线满足**欧拉–拉格朗日方程**：

$$\frac{d}{dx}\Big(\frac{\partial F}{\partial y'}\Big)-\frac{\partial F}{\partial y}=0$$

使用方法三步：认出这台赛题的 $F$ → 算出 $\tfrac{\partial F}{\partial y}$ 与 $\tfrac{\partial F}{\partial y'}$ 两个偏导 → 代入方程解出一条微分方程。至于这条方程为什么成立，完整推导锁在本课第 8 节的选读里，眼下把它当作"驻点条件"这句话的函数版复刻即可放心使用。

## 4. 分步例题

**例 · 为什么连接两点的最短路必然是直线**。设区间为 $[a,b]$，弧长泛函的读数规则是每小段长度 $\sqrt{dx^2+dy^2}$，即

$$F(x,y,y')=\sqrt{1+y'^{\,2}}$$

1. 清点偏导：$F$ 只含 $y'$，对 $y$ 的偏导为零：$\tfrac{\partial F}{\partial y}=0$；
2. 算另一个：$\tfrac{\partial F}{\partial y'}=\dfrac{y'}{\sqrt{1+y'^{\,2}}}$；
3. 代入欧拉–拉格朗日：$\dfrac{d}{dx}\Big(\dfrac{y'}{\sqrt{1+y'^{\,2}}}\Big)=0$；
4. 括号里在整个区间上恒为常数，而解出常数的唯一途径是 $y'=c$（常数）；
5. 于是 $y=cx+d$——一次函数，恰是穿过两个铆钉点的直线。

几何常识"两点间线段最短"，如今是方程亲手吐出来的代数结论。更要紧的是方法通用：换掉读数规则 $F$，同一台机器就会吐出别的冠军曲线——下面的实验已经把这扇门推开了一条缝。

## 5. 动手实验

### 实验（python）：固定网格折线赛跑

```python title="固定网格折线赛跑：形状决定快慢"
import matplotlib.pyplot as plt        # 导入绘图库：负责画出赛道对比图

G = 1.0                                # 重力加速度（教学尺度取 1，量纲无关结论）
AX, AY = 0.0, 0.0                      # 起点 A：静止释放（y 表示下落深度，向下为正）
BX, BY = 4.0, 3.0                      # 终点 B：向右 4、向下 3

def seg_time(v0, x0, y0, x1, y1):      # def：一段直滑道上的匀加速下滑
    dx = x1 - x0
    dy = y1 - y0                       # 深度差决定能量：速度全靠它涨
    ell = (dx*dx + dy*dy) ** 0.5       # 斜边长：勾股定理配 ** 0.5 开平方
    acc = G * dy / ell                 # 切向加速度 = g·sin(倾角)
    v1 = (v0*v0 + 2 * acc * ell) ** 0.5   # 匀加速公式：v 的平方 = 初速平方 + 2as
    return (v1 - v0) / acc, v1         # 返回这段耗时与末速度

best_t = None                          # None 表示"尚未产生任何纪录"
best_p = None                          # 纪录对应的拐点位置

for i in range(1, 15):                 # 拐点横坐标以 0.25 步进扫过全部格子
    px = i / 4                         # i/4 得到 0.25 到 3.5 的格点
    for j in range(1, 12):             # 拐点深度同样按 0.25 步进扫描
        py = j / 4
        t1, v_mid = seg_time(0.0, AX, AY, px, py)   # 上半程从静止出发
        t2, _ = seg_time(v_mid, px, py, BX, BY)     # 下半程带着中途速度继续
        total = t1 + t2                # 总耗时：两段相加
        if best_t is None or total < best_t:        # 刷新纪录的条件
            best_t = total
            best_p = (px, py)

t_straight, _ = seg_time(0.0, AX, AY, BX, BY)      # 对照组：一口气走直线

print("冠军拐点 =", best_p)
print("冠军用时(ms) =", round(best_t * 1000))
print("直线用时(ms) =", round(t_straight * 1000))
print("省下(ms) =", round((t_straight - best_t) * 1000))

xs1 = [AX, BX]                         # 直线参照画成虚线
ys1 = [-AY, -BY]
plt.plot(xs1, ys1, linestyle="--", color="gray", label="straight")

kx = [AX, best_p[0], BX]               # 冠军折线画成实线（y 取负模拟俯视滑道）
ky = [-AY, -best_p[1], -BY]
plt.plot(kx, ky, marker="o", color="crimson", label="best kink")
plt.legend()
plt.axis("equal")                      # 两轴等比例：形状不走样
```

怎么玩：160 个候选拐点逐一计时后，冠军落在 $(0.5,\ 1.25)$——宁可先扎一段深坑攒速度，也不肯一路平缓匀速。直线大约 4082 毫秒，冠军折线约 3645 毫秒，净赚近十分之一的赛程。这正是"未知量是函数"最直观的样子：改的只是一个拐点，成绩表就整个重排。把循环里的 0.25 步长减半重跑，冠军会继续左移贴向经典答案——那条真正的冠军滑道叫**摆线（旋轮线）**：

$$x=r\,(\theta-\sin\theta)\,,\qquad y=r\,(1-\cos\theta)$$

它是滚动的轮子边缘上某点划出的轨迹，也是惠更斯制作等时摆时相中的曲线：沿它无论从哪个高度松手，到达底部的时间竟然一样。

### 快问快答

```quiz
变分问题和“解方程求最大值”最大的不同是什么？
- 变分法完全不用导数
- 它的候选解是一整条函数，评估的是泛函这个“函数的函数” [*]
- 它只能处理物理里的下落问题
- 它永远没有最小值
? 普通优化在数轴上挑点，变分法在整个函数空间里挑曲线：每个候选都送进积分 J 里读出一个数，再对这些数谈最小值。读数机的名字就叫泛函。
```

:::warning[常见误区]

**误区一**："你以为泛函的自变量还是 x。" x 只是积分里的哑变量，走一遍就被积掉了；真正的自变量是整条函数 y——这也是 J 用方括号书写的用意。

**误区二**："你以为可以对每段滑道各自偷懒。" 各段互相咬合：拐点动一动，下游的速度账目全线重算。孤立看每段的贪心策略不等于全局最优——这是函数空间极值与逐点极值的本质区别。

**误区三**："你以为离散求和就是把各项加起来。" 连续量的离散近似必须逐项乘上自己的宽度（段长、权重），否则长短段话语权相同，结论会被挤歪——下一节练习请亲自体验翻车现场。

:::

## 6. 练习

**练习**：一根绷在两堵墙间的弹性膜，应变能按 $E=\displaystyle\int_0^1 y'^{\,2}\ dx$ 计费（斜率越陡越贵）。两端钉死在高度 0 和 1，内部在横向 0.7 处有一个剖分节点——于是膜面近似成两段折线。请扫出能量最低的中间高度 k：打印"最低点占全程高度的百分数"和"最小能量的千分之一取整"。代码能跑，但它的冠军一听就不靠谱：

```exercise
# @title: 练习：漏乘宽度，直线丢掉王座
# @check: 70
# @check: 1000
# @hint: 积分段的主张是"每一小段的贡献 = 这段的平方项 × 这段的宽度"。现在两项都没乘宽度——宽窄不同的两段被硬塞了一样大的话语权，歪的路线自然冒充了冠军。
left = 0.7         # 左段的横向宽度（占全程七成）
right = 0.3        # 右段的横向宽度
steps = 20

best_e = None      # 目前见过的最小近似能量
best_k = None      # 取得该值的中间高度

for i in range(1, steps):
    k = i / steps                 # 候选：中间高度占全程的比例
    s1 = k / left                 # 左段平均斜率
    s2 = (1 - k) / right          # 右段平均斜率
    e = s1 * s1 + s2 * s2         # ← 问题在这：两项都没有乘各自的宽度
    if best_e is None or e < best_e:
        best_e = e
        best_k = k

print(round(best_k * 100))
print(round(best_e * 1000))
```

<details>
<summary>点开查看逐步解答</summary>

正确做法是把宽窄还给各段：`e = left * s1 * s1 + right * s2 * s2`。修正后冠军回到 `70`、最小能量恰好 `1000`（即 E=1）——中间高度 0.7 恰好正是直线 y=x 过该节点的高度：**加权正确的能量自动把王座还给了直线**。

而初始代码漏乘宽度，两段的斜率平方同权竞争：右段窄、同样的高度差会把斜率抬得更陡，于是错误版本干脆把节点推向 k≈0.85 的位置去讨好它——一个鼓包的假冠军就此登基（node 同语义实跑输出 `85  1724`，与正确答案恰好互换身份）。三种高度的账目对比如下：

| 中间高度 k | 漏乘宽度（错） | 乘上宽度（对） |
| --- | --- | --- |
| 0.50 | 3.288 | 1.190 |
| 0.70 | 2.000 | **1.000 ← 真冠军** |
| 0.85 | **1.724 ← 假冠军** | 1.107 |

宽度就是话语权：乘回去之后，直线不用跟任何鼓包比武，能量自动降到期望的最小值 1。

这套"带宽度权重的平方能量找平衡"的语言并不陌生：[Lax-Milgram 选读](./85-lax-milgram.md)说过这样的能量碗必有唯一碗底；有限元把连续区域剁成这种带权剖分后求解，正是本练习的工业放大版。
</details>

## 7. 边界与适用条件

- 欧拉–拉格朗日方程给出的是**必要条件**：最优解必满足它，但满足它的未必唯一、未必是最优（可能同时存在几个驻定形状等着被进一步评审）。
- "冠军存在"这件事由别处担保：这里玩的是最简单的一类泛函；更弱的条件与更大的函数空间里，碗底是否还在，是 [Lax-Milgram 选读](./85-lax-milgram.md)那一课的能量碗故事。
- 折线实验做了理想化：拐角处速度方向瞬时改变，忽略真实滑道的转弯损耗；分段计时用的是精确的匀加速公式，但离散本身只在网格内寻优——它展示思路，不替代解析解。
- 本课只处理"一个自变量、一个未知函数、无约束"的经典格局；偏微分方程对应的多元版本、以及约束下的工程最优控制（控制量受限、终端时间受限），要等到弱形式的 PDE 与现代控制的章节再开工。

## 8. 选读：欧拉–拉格朗日方程的两步推导

<details>
<summary>选读 · 扰动一分钟，边界项自杀两次</summary>

设 $y$ 是候选冠军，给它套一件微微变形的外衣：考察一族试穿品 $y+\varepsilon\eta$，其中 $\eta$ 在两个端点为零、中间随意起伏，$\varepsilon$ 控制变形幅度。若 $y$ 真的最优，则读数 $J(\varepsilon)$ 应在 $\varepsilon=0$ 处取得谷底，于是对 $\varepsilon$ 的导数为零。

把 $J$ 对 $\varepsilon$ 求导（对积分号下求导），得到必须成立的条件：

$$\int_{x_0}^{x_1}\Big(\frac{\partial F}{\partial y}\,\eta+\frac{\partial F}{\partial y'}\,\eta'\Big)\ dx=0$$

第二项里纠缠着 $\eta'$，请 [分部积分](../14-integrals/32-partial-integration.md)把它转嫁给 $\eta$：$\displaystyle\int F_{y'}\,\eta'\,dx=F_{y'}\,\eta\Big|_{x_0}^{x_1}-\int\frac{d}{dx}F_{y'}\,\eta\,dx$。第一件巧事发生：$\eta$ 两端为零，边界项当场蒸发。剩下的两项重新合体：

$$\int_{x_0}^{x_1}\Big(\frac{\partial F}{\partial y}-\frac{d}{dx}\Big(\frac{\partial F}{\partial y'}\Big)\Big)\eta\ dx=0$$

第二件巧事是基本引理：$\eta$ 的形状**完全任意**，要让积分为零，只剩一种可能——括号里的函数处处为零。这正是欧拉–拉格朗日方程。顺带一条工兵捷径留给好奇者：当 $F$ 不显含 $x$ 时，方程允许一次降阶积分（贝尔特拉米恒等式），最速降线之所以能用手算干净利落地解出摆线，靠的就是它。
</details>
