# 从向量空间到函数空间

## 1. 开场钩子

傅里叶级数把一段声音写成 $\dfrac{a_0}{2}+\sum a_n\cos nx+b_n\sin nx$。这看起来像把一个“点”分解成许多坐标，只是这个点不是箭头，而是整条波形。

## 2. 直觉解释

把每个连续函数看作无限维空间里的一个点。两个函数相加，就是逐点把高度相加；乘以常数，就是把所有高度放大。这样，“信号”“温度分布”“位移曲线”都成了向量。

## 3. 正式定义

设 $F$ 是某个定义域上的一批函数。若任意 $f,g\in F$ 与数 $k$ 都满足：

$$f+g\in F,\qquad kf\in F,$$

并且加法和数乘保持通常运算律，则称 $F$ 是一个**函数向量空间**。零向量就是处处取值 $0$ 的函数。

## 4. 分步例题

考虑次数不超过 2 的多项式全体 $P_2$。

1. 取 $p(x)=1+x^2$，$q(x)=3-x+x^2$；
2. $(p+q)(x)=4-x+2x^2$，仍是二次或更低次多项式；
3. $5p(x)=5+5x^2$，也留在 $P_2$；
4. $1,x,x^2$ 像三个坐标轴；
5. 因此 $p(x)$ 可以写成坐标 $(1,0,1)$。

### 实验 1：把波当作向量

蓝线是合成的整体波形。它可以继续和另一条波形逐点相加，就像平面里的两个箭头相加。

### 实验 2：修改函数向量的系数

```python title="用坐标表写一个函数向量"
# coeffs 是函数 1*cos(1x)+0.6*sin(2x) 的两组坐标
coeff_cos = [1.0, 0.0]
coeff_sin = [0.0, 0.6]
print("cos 方向:", coeff_cos)
print("sin 方向:", coeff_sin)
```

改小第二个数，相当于把函数在 $\sin 2x$ 方向上的分量缩短；改符号则翻转方向。

## 6. 常见误区

:::warning[常见误区]

**误区一**：你以为只有有限列的表格才是向量。其实只要能相加、数乘并遵守运算律，函数也可以是向量。

**误区二**：你以为“所有函数”天然是一个好空间。太大会失去积分、距离等结构，泛函分析常先选一个合适子空间。

**误区三**：你以为逐点收敛就足够代表函数列收敛。后面会看到范数不同，收敛意义也不同。

:::

## 7. 练习

```exercise
# @title: 练习：函数向量的加法与数乘
# @check: [4, -2]
# @check: [-2.0, 1.0]
# @hint: 先逐项相加得到 (4,-2)；再对结果乘以 -0.5。
p = [1, 2]
q = [3, -4]
total = [p[0] + q[0], p[1] + q[1]]
scaled = [total[0], total[1]]
print(total)
print(scaled)
```

<details>
<summary>点开查看逐步解答</summary>

两个一次函数 $1+2x$ 与 $3-4x$ 相加得 $4-2x$。再乘以 $-0.5$ 得 $-2+x$，Python 会显示第二行 `[-2.0, 1.0]`。

```python
p = [1, 2]
q = [3, -4]
total = [p[0] + q[0], p[1] + q[1]]
scaled = [total[0] * (-0.5), total[1] * (-0.5)]
print(total)
print(scaled)
```

## 9. 选读边界

<details>
<summary>选读 · 为什么域和定义域要固定</summary>

同一表达式的定义域改变后，函数就不是同一个对象。例如定义在 $[0,1]$ 和 $[0,2]$ 上的 $x^2$ 不能直接逐点相加。泛函分析中的空间必须先约定共同定义域、允许的奇点与可积性。
</details>
