# 直接证明

## 1. 从一个场景开始

“奇数的平方为什么一定是奇数？”有人算 $3^2=9$、$5^2=25$，越算越信。可数学要的不是越算越信，而是从定义出发搭一条谁也拆不掉的桥：奇数能写成什么，平方后就必然长成什么。

## 2. 直觉解释

直接证明像接力：

1. 起点是定义或已经证明的事实；
2. 中间每一步只做一次可检查的变形；
3. 终点恰好是要证的结论。

它不要求聪明地跳步，而要求每个“凭什么”都有地址。写证明时可以先画依赖链，再翻译成句子。

## 3. 正式定义

要证条件句 $P \Rightarrow Q$，直接证明从假设 $P$ 出发，结合定义、公理和已证定理，推出 $Q$。

若直接推 $Q$ 不顺，可以证逆否命题 $\neg Q \Rightarrow \neg P$。两种命题在所有赋值下同真假：

| $P$ | $Q$ | $P \Rightarrow Q$ | $\neg Q \Rightarrow \neg P$ |
| --- | --- | --- | --- |
| 真 | 真 | 真 | 真 |
| 真 | 假 | 假 | 假 |
| 假 | 真 | 真 | 真 |
| 假 | 假 | 真 | 真 |

所以证明其中一条，就等于证明另一条。

## 4. 分步例题

**例 1**：证明两个偶数之和是偶数。

1. 设 $m,n$ 是偶数；
2. 按定义存在整数 $a,b$，使 $m=2a$，$n=2b$；
3. 于是 $m+n=2a+2b=2(a+b)$；
4. $a+b$ 是整数，所以 $m+n$ 能被 $2$ 整除，即为偶数。

**例 2**：证明若 $n^2$ 是偶数，则 $n$ 是偶数。

直接从偶数定义推出 $n$ 本身并不顺，改证逆否命题：

1. 设 $n$ 不是偶数，即 $n$ 是奇数；
2. 写 $n=2k+1$；
3. $n^2=(2k+1)^2=4k^2+4k+1=2(2k^2+2k)+1$；
4. 所以 $n^2$ 是奇数；
5. 逆否命题成立，原命题成立。

### 实验 2：用余数分类

```python title="按除以 2 的余数检查奇偶"
for n in [4, 7, 10, 13]:
    if n % 2 == 0:    # % 是取余数；除以 2 余 0 就是偶数
        print("even")
    else:
        print("odd")
```

输出 `even`、`odd`、`even`、`odd`。代码只抽查四个数；证明负责所有整数。

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为举很多例子就是证明。例子能发现错误，不能锁住无穷多个对象；锁住无穷的是定义和代数结构。

**误区二**：你以为逆否证明是反证法。逆否证明只替换成等价命题；反证法要额外假设结论否定并制造矛盾。

**误区三**：你以为写越长越严谨。没有地址的长句可能藏住跳步；好证明每一步短，但每一步都能追问。

:::

## 9. 选读：分情况为什么合法

<details>
<summary>选读 · 覆盖所有情况才算分完</summary>

分情况证明把论域切成若干子集合，再在每个子集合里证结论。它合法的条件是这些子集合的并集覆盖原论域。整数按余数可分成偶数和奇数两类，所以对两类分别证明即可覆盖所有整数。若漏掉“余数为 $1$”这类情况，就不是分情况证明，而是抽样。

</details>
