## 实战挑战 · 从医学报表到平台实验

**第一幕 · 巧克力与诺贝尔奖**（真实研究及其翻案）。2012 年，《新英格兰医学杂志》刊登了 Messerli 医生的短文：23 个国家的人均巧克力消费量与每千万人诺贝尔奖得主数高度相关（$r \approx 0.79$），文中半开玩笑地暗示巧克力中的黄烷醇或可提升国民智力。媒体狂欢之后，Maurage 等人（《营养杂志》2013）逐条拆解：人均 GDP 与巧克力消费相关高达 $0.73$、与诺奖数相关 $0.66$；同样富含黄烷醇的茶消费与诺奖数却几乎无关（$r = 0.03$）；而且数据是国家层面的汇总——连"获奖者本人吃不吃巧克力"都无从知晓。这是**生态学谬误**加**共同原因混杂**的双料教材。

亲手用一组教学虚构的迷你国家数据，把"国富"这个共同原因剥出来：

```exercise
# @title: 实战挑战：剥出共同原因
# @check: 0
# @check: 0
# @check: 5
# @check: 14
# @hint: 组内诺奖差 = 同组两国的诺奖数相减；(d) 国别均值差 = 富国均值 − 穷国均值，先各自组内平均再相减
rich_choc = [8, 4]      # 两个富国的年人均巧克力消费（千克，教学虚构数字）
rich_nobel = [16, 16]   # 对应的每千万人诺奖数
poor_choc = [1, 1]      # 两个穷国的同类数据
poor_nobel = [2, 2]

rich_gap = rich_nobel[0] - rich_nobel[1]    # 富国内部：巧克力差 4 千克，诺奖差多少？（已示范）
print(rich_gap)

print(0)                                    # ← 占位：(b) 穷国内部的诺奖差

mean_rich_choc = (rich_choc[0] + rich_choc[1]) / 2
mean_poor_choc = (poor_choc[0] + poor_choc[1]) / 2
mean_rich_nobel = (rich_nobel[0] + rich_nobel[1]) / 2
mean_poor_nobel = (poor_nobel[0] + poor_nobel[1]) / 2

print(round(mean_rich_choc - mean_poor_choc))   # (c) 国别间平均巧克力差（已示范）
print(round(0))                                 # ← 占位：(d) 国别间平均诺奖差
```

<details>
<summary>点开查看第一幕解答</summary>

**(a)(b)** 组内诺奖差：富国内部 $16-16=0$；穷国内部 $2-2=0$——在财富相近的国家之间，巧克力吃得再多，诺奖纹丝不动。

**(c)** 国别间巧克力均值差：$(8+4)/2 - (1+1)/2 = 6-1 = 5$ 千克。

**(d)** 国别间诺奖均值差：$16-2 = 14$ 个。若只看这张混合散点图，你会看到"多吃 5 千克巧克力伴随多 14 位诺奖得主"的惊人规律。

真相只有一句话：**财富同时推高巧克力消费与科研投入**（叉结构 $X \leftarrow Z \to Y$，第 30 课的主角）。组内差为 0、组间差悬殊，正是共同原因混杂的指纹。对照第 10 课的真实肾结石案例：那边是分层后方向翻转，这边是分层后关联消失——同一套因果图的两种病症。
</details>

**第二幕 · "基因借口"**（真实医学争论）。1950 年代，统计学家费雪（R. A. Fisher，同时也是遗传学家）公开质疑"吸烟致肺癌"的因果解读：他提出，或许存在某种基因型既让人更爱吸烟、又让人更易患癌——若是如此，观察到的强相关无需任何因果箭头。这场争论塑造了整个学科的方法论自觉：

```quiz
费雪质疑吸烟致癌时的核心论点属于哪一类？
- 他用实验证明吸烟能延长寿命
- 他指出观察数据无法排除一个共同原因（如基因）同时导致吸烟偏好与癌症 [*]
- 他认为当时的样本太小没有统计学意义
? 费雪并未否认相关性本身，而是坚持观察研究挡不住第三变量解释。后来的大规模队列研究与机制证据支持了吸烟的因果作用，但"费雪之问"成了混杂思想的经典教材——也提醒我们：反驳一个解释不需要证明它对，只需要证明它没被排除。
```

**第三幕 · 平台实验：该信哪一栏？**（结构取自常见产品实验，数字为教学虚构）。一个学习平台把新练习提醒随机指派给 5000 名学生；其中 4000 人真的使用了新提醒。实验期结束时，新页指派组共有 900 人完成周目标，旧页对照组 5000 人中有 550 人完成。运营同学想直接比较“实际使用新提醒的人”和“对照组”，但这会把自愿使用带来的选择偏差放回比较器。

```exercise
# @title: 实战挑战：平台实验该信哪一栏
# @check: 18.0
# @check: 11.0
# @check: 7.0
# @check: 20.0
# @hint: 意向处理分析始终用“被指派”的人数做分母；最后一行错在只用实际使用新功能的人做分母
assigned_new = 5000          # 被随机指派到新提醒的学生数
used_new = 4000              # 其中真的使用新提醒的人数
new_conversions_all = 900    # 新页指派组完成周目标的总人数
used_conversions = 800       # 新页使用者中完成周目标的人数
assigned_control = 5000      # 被随机指派到旧页的学生数
control_conversions = 550    # 对照组完成周目标的人数

itt_new = 0                                       # ← 占位：按“指派”算的新页完成率（百分数，一位小数）
control_rate = round(control_conversions / assigned_control * 100, 1)
assignment_lift = 0                               # ← 占位：新页指派率 − 对照率
naive_used_rate = 25                              # ← 有 bug：这是“实际使用者”口径，不是随机对照口径
print(itt_new)
print(control_rate)
print(assignment_lift)
print(naive_used_rate)
```

正确读法是**意向处理分析**：随机化保证“被指派新提醒”和“被指派旧提醒”的两组事前可比，所以 $900/5000=18\%$ 对 $550/5000=11\%$ 的差回答“发出提醒”的因果效果。若改看实际使用者的 $800/4000=20\%$，就把“谁更可能主动用新功能”混进了估计。想估计“真的使用”本身的效应，需要更专门的工具变量或遵守处理分析，不能靠简单换分母解决。
