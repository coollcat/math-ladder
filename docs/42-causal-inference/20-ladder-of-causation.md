# 因果之梯：看见、动手、假如当初

## 1. 从一个场景开始

村里公鸡一打鸣，天就亮了。村长提议：多养一百只公鸡，让冬天也早点天亮。全村哄笑——可同样的推理换个包装，天天在新闻里上演："常喝咖啡的人心脏病率高，所以戒掉咖啡保护心脏""用打火机的群体肺癌率高……"。上一课我们学会了对报表起疑；这一课要回答更根本的问题：**"看见 X 就看见 Y"和"动手设置 X 能否得到 Y"，到底差在哪里？差多少？**

## 2. 直觉解释

图灵奖得主珀尔（Judea Pearl）把这类问题排成一架三层楼梯：

- **第一层·看见（关联）**："公鸡叫时，天亮的频率是多少？"只需翻统计报表。它回答预测问题：看见一个，猜另一个。
- **第二层·动手（干预）**："如果我**强制**公鸡半夜打鸣，天会提前亮吗？"报表答不了——报表里没有"被强迫的公鸡"，只有自愿打鸣的公鸡。它需要实验或因果模型。
- **第三层·回想（反事实）**："假如昨天那支疫苗没打，老王还会住院吗？"连实验都帮不上忙：老王的疫苗已经打了，另一个世界无法重跑。

晴雨表是同款考题：指针骤降常伴随风暴（第一层有效），但用手掰弯指针不会召来风暴（第二层失效）。第一层的规律再漂亮，也不保证能扛着走进第二层。

## 3. 正式定义

| 层 | 问题句型 | 数学记号 | 典型来源 |
| --- | --- | --- | --- |
| 1 关联 | 看见 $X=x$ 后，$Y$ 的分布？ | $P(Y \mid X = x)$ | 观察数据 |
| 2 干预 | 强制设定 $X=x$ 后，$Y$ 的分布？ | $P(Y \mid do(X{=}x))$ | 随机实验/因果模型 |
| 3 反事实 | 假如当时 $X$ 取别的值，这个个体会怎样？ | $P(Y_x \mid X{=}x', Y{=}y')$ | 结构因果模型 |

新符号 **do 算子**的含义：$do(X=x)$ 表示"切断所有指向 $X$ 的箭头，再把 $X$ 焊死在 $x$"——世界其余部分照旧运转。它与条件概率的区别是本质性的：

$$P(Y \mid X = x) \neq P(Y \mid do(X = x)) \quad \text{一般来说}$$

左边混合了"X 影响 Y"与"别的东西同时影响 X 和 Y"两种水流；右边只留第一种。两者什么时候相等、怎么从观察数据推出来，是接下来两课的主题；本课先训练眼睛，把两层的问题认出来。

## 4. 分步例题

冰淇淋世界：连续观察 1000 天。天气分热/凉（热 200 天）；热天里 180 天在卖冰淇淋，全部 1000 天中共发生游泳事故 28 起——**恰好都落在卖冰淇淋的日子**；凉天的 800 天从不发生事故。

1. 整理计数：卖冰淇淋共 $180+80=260$ 天，其中事故 $28$ 起；不卖的 $740$ 天，事故 $0$ 起；
2. 第一层提问"看见卖冰淇淋，事故概率"：$28/260 \approx 10.8\%$；对照"不卖"的 $0\%$——报表显示冰淇淋与事故强烈相关；
3. 第二层提问"强制禁售冰淇淋（do）"：禁售改变的是"谁吃冰淇淋"，**不改变天气构成**——热天照样 200 天，该来的 28 起事故照样来；
4. 于是 $P(\text{事故} \mid do(\text{禁售})) = 28/1000 = 2.8\%$，与什么都不做完全一样；
5. 对比结论：观察口径"差距巨大"（$10.8\%$ vs $0\%$），干预口径"毫无作用"（$2.8\%$ vs $2.8\%$）。天气是共同原因：它同时催生冰淇淋与事故——这正是下一课要画的箭头图。

## 5. 动手实验

### 实验 1（viz）：两种问法，一张图看穿

```viz
{
  "type": "datachart",
  "title": "冰淇淋事故率：看见 ≠ 动手",
  "labels": ["看见卖", "看见没卖", "do 禁售"],
  "values": [10.8, 0, 2.8]
}
```

前两根柱是观察口径：卖冰淇淋的日子事故率高得多。第三根柱是干预口径：禁售不改变天气，事故基线仍在。零等待图先立住反差，下面的代码再逐日重建。

### 实验 2（python）：双层计算器

```python title="同一份数据，两种问法，两个答案"
# days 的每个元素是 [是否炎热, 是否卖冰淇淋, 是否出事故]，取值 0/1
days = []
for i in range(200):            # 热 200 天：前 180 天卖冰淇淋；全季 28 起事故都出在热天
    has_ice = 1 if i < 180 else 0
    has_acc = 1 if i < 28 else 0
    days.append([1, has_ice, has_acc])
for i in range(800):            # 凉 800 天：前 80 天卖冰淇淋，从不事故
    has_ice = 1 if i < 80 else 0
    days.append([0, has_ice, 0])

def share(rows):                # 返回 rows 里出事故的比例
    hits = 0
    for row in rows:
        hits = hits + row[2]
    return hits / len(rows)

ice_days = []                   # 第一层：按"看见什么"分组
no_ice_days = []
for row in days:
    if row[1] == 1:
        ice_days.append(row)
    else:
        no_ice_days.append(row)
print(f"看见卖冰淇淋的事故率: {share(ice_days):.3f}")
print(f"看见没卖冰淇淋的事故率: {share(no_ice_days):.3f}")

ban_hits = 0                    # 第二层：do(禁售) 只改"谁吃冰淇淋"，不改天气与事故
for row in days:
    ban_hits = ban_hits + row[2]
print(f"干预 do(禁售) 后的事故率: {ban_hits / len(days):.3f}")
```

输出依次约 `0.108`、`0.000`、`0.028`——观察口径的天壤之别，在干预口径下蒸发殆尽。想再验证一次？把最后一行改成"强卖给所有人"口径（答案仍是 $28/1000$）：**对结果而言，do 只有通过原因才起作用**。

### 实验 3（matplotlib）：两幅对比图

```python title="左图吓人，右图泄气"
import matplotlib.pyplot as plt

labels = ["看见 卖冰淇淋", "看见 没卖", "干预 do(禁售)", "干预 do(强卖)"]

```

红色高柱与蓝色零柱是"报表给你的世界观"；两根灰柱才是"动手改造世界的真实后果"——都钉在黑色虚线上。统计关联描述世界，因果回答改造。

### 快问快答

```quiz
"天气预报说明天降雨概率 90%"属于因果之梯的哪一层？
- 第二层，因为带"概率"
- 第一层，它由历史观测数据归纳而来，回答"看见什么预测什么" [*]
- 第三层，因为它谈论未来
? 谈未来不代表谈干预。这句预报说的是"明天的自然状态"，不是"如果人为播种乌云会怎样"。判断层次看问题结构，不看时间指向。
```

:::warning[常见误区]

**误区一**：你以为 do 只是条件概率的花哨记号。两者的差别是"是否切断了指向 X 的其他来路"；随机对照试验之所以金贵，正因为随机化在物理上实现了 do。

**误区二**：你以为第一层数据攒够多就能爬上第二层。纯观察数据原则上不含干预信息（除非叠加因果假设）——这是"因果层级定理"的内容，不是技术困难而是信息缺失。

**误区三**：你以为反事实就是随口编故事。第三层的陈述在给定因果模型时有严格定义和数值答案；没有模型，"假如当初"才真的只是修辞。本课结尾的练习会逼你直面这一点。

:::

**练习 2**：新闻标题"常随身带打火机的人肺癌率高出十倍，建议限购打火机"。用因果之梯指出这句话错在哪一步。

<details>
<summary>点开查看逐步解答</summary>

第一步（第一层统计）没错：看见带打火机确实伴随更高肺癌率。错在第二步——**未经第二层许可就把它包装成了干预建议**。"限购打火机"是一个 do 操作；除非打火机是肺癌的原因，否则 do 之后肺癌率纹丝不动。这里吸烟才是共同原因：它同时导致"带打火机"与"肺癌"。正确的第二层问题是"若强制无人带打火机，肺癌率如何"——答案是几乎不变。新闻业最经典的越层行为，就是把 $P(Y|X)$ 直接朗读成 $P(Y|do(X))$。
</details>

## 7. 选读：为什么观察数据"原则上"不够

<details>
<summary>选读 · 因果层级定理一瞥</summary>

珀尔证明了所谓因果层级定理（Causal Hierarchy Theorem）：对一个因果系统，若只掌握第一层（联合分布）的全部信息，则第二、三层的绝大多数问题是**数学上不可识别**的——不是样本不够，而是分布本身不携带干预信息。直观版本：同一份观察数据可以由"冰淇淋致事故"与"天气共因"两个截然不同的世界产生，两个世界里所有 $P(Y|X)$ 完全相同，而所有 $P(Y|do(X))$ 截然不同。要从第一层爬上第二层，必须额外注入结构假设（谁指向谁），或亲手做实验。这也解释了本章为什么需要因果图这种"假设的书写语言"。

</details>
