# 结构因果模型 SCM：把因果写进方程

## 1. 从一个场景开始

街角的「灯塔奶茶」有个朴素的经营发现：亮着招牌灯的日子，平均销量明显高于熄灯的日子。老板当机立断——招牌改成全年常亮，电费不贵，稳赚。

三个月后对账：销量纹丝不动。报表没有骗人（亮灯日确实卖得多），但干预失败了。差在哪里？差在老板把"看见"读成了"动手"。上一章的因果图给了箭头语言；这一课要把箭头升级成**可计算的机器**：把每个变量写成一条方程，让"观察世界"和"改写世界"都能按行执行。

## 2. 直觉解释

把世界想成一条**装配流水线**：每个变量的值不是凭空来的，而是由它的"父母"加一颗骰子组装出来的。比如奶茶店：

- 天气 $T$ 是自由变量，由老天爷掷骰子决定；
- 招牌灯 $L$ 也由自己的骰子决定；
- 广告效果 $A$ 由天气和灯一起生成；
- 销量 $S$ 由广告和天气一起生成。

写成方程时用一种新的等号 $\;:=\;$，读作"**由……生成**"。它和普通等号的区别是天大的：$y := x$ 说"先有 $x$，后有 $y$"——这是单向阀门，把两边调换就换了故事。初中数学里 $y = x$ 与 $x = y$ 等价，流水线说明书里绝不许这么换。

两种提问方式对应两种操作：

| 操作 | 白话 | 在方程上做什么 |
| --- | --- | --- |
| 观察 | "听见 $A{=}1$ 时，$S$ 平均多少？" | 什么都不动，只按条件筛选流水线的产出 |
| 干预 do | "强制把 $A$ 拧到 1，$S$ 会怎样？" | **撕掉 $A$ 的原方程，重写为 $A := 1$**，其余方程照旧运转 |

第 20 课因果之梯里那句"切断指向 X 的所有箭头"，到这里有了精确的说法：切断箭头 = 删除该变量的旧方程、换成常数赋值。其余变量浑然不觉地继续各自的生产节拍。

## 3. 正式定义

**结构因果模型**（Structural Causal Model, SCM）是三元组 $\langle U,\, V,\, F\rangle$：

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $U$ | 外生变量 | 骰子集合：模型外给定、彼此独立、无父节点 |
| $V$ | 内生变量 | 装配品集合：每个都由 $F$ 中某条方程生成 |
| $F$ | 结构方程组 | 每个 $V_i \in V$ 对应唯一一条 $V_i := f_i(\text{pa}_i, U_i)$ |

奶茶店的完整 SCM（噪声各一枚公平硬币）：

$$T := U_1, \quad L := U_2, \quad A := T \cdot L, \quad S := 2A + T$$

逐项翻译：热天且亮灯才开广告位（$A := T\wedge L$，用乘法表示"与"）；每一单广告多卖 2 杯、每逢热天天然客流 +1 杯。注意两点纪律：**每个内生变量恰有一条出生方程**；外生硬币之间相互独立，谁也不指挥谁。

沿模型可以谈干预分布（do 之后整个系统重新联立）：

$$P_{do(X{=}x)}(V) \;=\; \text{把 } F \text{ 中 } X \text{ 的那条方程替换成 } X{:=}x \text{ 后重新生成的分布}$$

## 4. 分步例题

四个等可能的世界（两枚硬币各两次结果），逐列填写：

1. 写骨架：$(T,L)$ 取 $(0,0),(0,1),(1,0),(1,1)$ 各占四分之一；
2. 算 $A$：只有 $(1,1)$ 世界满足"热天且亮灯"，得 $A=(0,0,0,1)$；
3. 算 $S=2A+T$：四个世界的销量依次为 $0,\,0,\,1,\,3$——**观察口径总销量 4 杯**；其中亮灯的只有那一个世界，卖了 3 杯，灭灯三个世界平均约 0.33 杯——报表的"亮灯厉害"来自这里；
4. 做 $do(A{=}1)$：撕掉 $A$ 的方程、焊死为 1，重算 $S=2+T$，四个世界变为 $2,2,3,3$，总销量 **10 杯**；
5. 做 $do(A{=}0)$：同样手术，$S=T$，总销量 **2 杯**；
6. 对齐直觉：常亮招牌相对断电确实多卖（10 对 2），但这份收益早已包含在自然运转里（观察合计 4）——报表上亮灯日的风光，一半是热天的功劳。SCM 把这笔账拆得明明白白。

## 5. 动手实验

### 实验 1（viz）：同一间店，三种世界

```viz
{
  "type": "datachart",
  "title": "四季度的总销量（杯）：自然观察 vs 两种干预",
  "labels": ["自然观察", "do 招牌常亮", "do 招牌断电"],
  "values": [4, 10, 2]
}
```

三根柱出自同一个模型、同一套硬币，唯一的差别是谁动了哪条方程。中间柱比左柱高得多，不代表"常亮是新点子"，只代表"强制常亮改变了原本偶尔熄灯的世界"。

### 实验 2（python）：可换方程的小流水线

```python title="SCM 模拟器：观察模式与两种干预模式"
# worlds 的每个元素是 [T, L]：外生硬币的一种组合，共四个等可能世界
worlds = []
for t in (0, 1):                 # 第一枚硬币：天气
    for l in (0, 1):             # 第二枚硬币：招牌灯
        worlds.append([t, l])

def sales(t, l, mode="observe"):
    # mode 有三种："observe" 自然运转 / "do_on" 强制亮灯 / "do_off" 强制断电
    if mode == "observe":
        a = t * l                # 原方程：热天且亮灯才投广告
    elif mode == "do_on":
        a = 1                    # 手术一：撕掉原方程，焊死 a = 1
    else:
        a = 0                    # 手术二：焊死 a = 0
    return 2 * a + t             # 销量方程永远照常运转

totals = {"observe": 0, "do_on": 0, "do_off": 0}   # 字典收集三种模式的总销量
for t, l in worlds:              # 解包赋值：一行同时取列表的两个元素
    for mode in ("observe", "do_on", "do_off"):
        totals[mode] += sales(t, l, mode)
print(totals)
```

输出 `{'observe': 4, 'do_on': 10, 'do_off': 2}`，与第 4 节手算一致。试把它当作真正的实验室：给 `sales` 加一条"雨天客流量 -1"的新方程，再看看三根柱如何挪动。

### 快问快答

```quiz
在 SCM 里把方程 S := 2A + T 改写成 A := (S − T) / 2，得到的是同一个模型吗？
- 是，代数变形完全等价
- 不是，改写后的式子不再是 A 的结构方程，它把生成方向调转了 [*]
- 取决于噪声大小
? 结构方程的"方向"是模型的灵魂：A 的父母是 T 和 L，S 的父母是 A 和 T，这个血缘由 F 唯一指定。普通代数变形可以随意重排等式，但结构方程一旦倒置，"谁导致谁"、乃至每个 do 操作的含义都会改变。
```

:::warning[常见误区]

**误区一**：你以为 SCM 就是普通方程组。普通方程组对称、可互相代入；结构方程组有方向、每个变量只有一个出生地。把 $\,:=\,$ 当成 $=$ 用，等于丢了整套因果内容。

**误区二**：你以为噪声骰子可有可无。若把两个独立的量硬写进同一条方程而不给各自噪声，就把并不存在的直接因果关系焊进了结构——后门分析会全盘失真。噪声是"拒绝乱攀亲戚"的机制保障。

**误区三**：你以为写出方程就算建模完成。同一份观察数据永远兼容多套不同的 SCM（这套不给下雨也能自圆其说）；方程组里每一笔箭头都是**可被实验检验或领域知识背书的假设**，而不是数据自动吐出的结论。

:::

## 6. 练习

**练习 1**：补全模拟器的手术分支，输出依次应为 `4`、`10`、`2`：

```exercise
# @title: 练习：让流水线真的换方程
# @check: 4
# @check: 10
# @check: 2
# @hint: 三个 sum 都对同一批四个世界求和；(a) 观察模式走原方程 S=2*(T*L)+T；(b)(c) 干预模式先把 A 固定成 1 或 0 再算 S=2*A+T
worlds = [[0, 0], [0, 1], [1, 0], [1, 1]]   # [T, L]，四个等可能世界

sum_observe = 0     # 自然观察的总销量
sum_do_on = 0       # do(亮灯) 的总销量
sum_do_off = 0      # do(断电) 的总销量
for w in worlds:
    t = w[0]
    l = w[1]
    a = t * l
    s = 2 * a + t            # 已示范：观察模式的销量
    sum_observe += s

    a_forced = t * l          # ← 有 bug：干预并没有真的替换方程
    sum_do_on += 2 * a_forced + t
    sum_do_off += 2 * a_forced + t

print(sum_observe)
print(sum_do_on)
print(sum_do_off)
```

**练习 2**：给"雨夜路滑 → 有人摔倒 → 急诊骨折病例上升"这条链各配一条结构方程（变量自拟）。指出：哪一步适合做 do 思考？哪一步只能停留在联想？

<details>
<summary>点开查看逐步解答</summary>

一组可行答案：`R := U_r`（下不下雨由气象骰子决定）；`Wet := R`（雨使地面湿）；`Fall := Wet · U_f`（湿滑与行人自身谨慎共同决定摔倒）；`Broke := Fall · U_b`（摔了还要看力度运气）。真正值得做的是对 `Wet` 的干预——撒盐除冰（$do(Wet{=}0)$）会顺着链条削弱后面两级；而"病例数 B"不宜强行设定，它是链条末端被动产出的果。判断口诀：**能拧的旋钮画在最上游；只想动下游的果，通常说明模型选错了干预点**。
</details>

## 7. 选读：从方程组到反事实

<details>
<summary>选读 · SCM 如何安放第三层问题</summary>

反事实课里那个"平行世界的你"，在 SCM 里有严格的坐标：给定事实证据 $(U=u,\,X=x)$ 先反推出噪声取值，再在结构方程组里做一次替身手术——把 $X$ 的方程换成 $X{:=}x'$，其余一切保留，重算 $Y$。记作 $Y_x(u)$。这正是珀尔证明"潜在结果框架与结构框架等价"的关键一步：鲁宾需要的平行世界，珀尔用方程手术伪造了出来。从此本章前面所有课共用一台引擎——因果图是外壳，SCM 是发动机，do 与反事实都是这台发动机的不同档位。

</details>
