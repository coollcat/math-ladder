# do 算子与干预分布

## 1. 从一个场景开始

还是那家灯塔奶茶店——但这次老板学乖了，带着两份完全不同的问题回来找我们：

- "报表里，**亮着广告位**的日子，大卖（销量顶格）的比例是多少？"
- "如果我把广告位**全年强制常亮**，大卖比例又是多少？"

第一问翻台账就能答；第二问必须动用 SCM 这台发动机。第 20 课我们已经见过 $P(Y \mid X=x)$ 与 $P(Y \mid do(X{=}x))$ 的记号分岔，本课的任务是把它彻底落地：给定一套结构方程，**亲手把两种分布各算一遍，并看清它们在哪里分道扬镳**。

## 2. 直觉解释

把 SCM 的每条方程想成一台由父母零件驱动的小机器，骰子（噪声）照常滚动：

- **条件化**只是在流水线末端挑拣成品——所有机器的接线一概未动；
- **干预**则走进车间，拧下目标变量 $X$ 的电源插头，接上一个输出恒为 $x$ 的稳压电源。$X$ 的旧机器报废，其余机器**毫无察觉**地照常生产。

所以 $do(X{=}x)$ 只切断指向 $X$ 的箭头，绝不碰从 $X$ 出发的箭头——下游机器该收到的零件照收，只是来源被换了。"广告影响销量"的通道完好无损；被消灭的是"热天促使开店投广告""亮灯顺手带出广告"这些反向混流的入口。

## 3. 正式定义

在 $\mathrm{SCM}=\langle U,V,F\rangle$ 上，干预分布 $P(Y \mid do(X{=}x))$ 由两条等价的规程定义：

**图手术版**：删去 $F$ 中 $X$ 的那条结构方程，代之以常数赋值 $X{:=}x$，重新联立整个系统求 $Y$ 的分布。

**截断因子化版**（同一件事的概率语言）：联合分布按"每个节点条件于其父节点"连乘，然后**划掉属于 $X$ 的那个因子**、并把式中出现的父辈取值换成 $x$：

$$P_{do(X{=}x)}(v) \;=\; \Big(\!\!\prod_{V_i \neq X} P(v_i \mid pa_i)\Big)\Big|_{X:=x}$$

与普通条件分布的分水岭在于：$P(Y\mid X{=}x)$ 里含有一个以 $X$ 为条件的贝叶斯重加权，而 $do$ 版本里 $X$ 处处的取值是**外生指定**的，不需要任何加权换算。二者一般不相等——除非碰上后续几课要研究的可识别情形。

## 4. 分步例题

给奶茶店的世界升级一个新变量：客流旺 $D$（热天或有路演夜就旺）。全季度八个等可能世界，三枚公平硬币 $(T,L,U_3)$，方程组：

$$T := U_1,\quad L := U_2,\quad A := T\cdot L,\quad D := T \vee U_3,\quad S := A + D$$

其中 $A$ 是"广告位点亮"，$S$ 是当日销量。

1. **铺底座**：八个世界按 $(T,L,U_3)$ 枚举，逐行算出 $(A,D,S)$；
2. **观察口径**：找出 $A{=}1$ 的世界——只有 $T{=}1,L{=}1$ 的两个（$U_3$ 自由）；逐格检查发现它们同时都满足 $D{=}1$，于是 $S=A+D=2$ 恒成立，$P(S{=}2\mid A{=}1)=1$；
3. **识破假象**：这个"100% 大卖"其实是幸存者幻觉——广告位只在热天亮，而热天本来就自带旺客流；
4. **手术口径**：$do(A{=}1)$ 撕掉 $A$ 方程、焊死为 1；$T,U_3$ 的硬币照掷，$D:=T\vee U_3$ 的机器原封不动。清点：$T{=}1$ 或 $U_3{=}1$ 的世界共六个，此时 $S=1+D{=}2$；剩下两个（冷天无路演）$S=1+0{=}1$；
5. **对读**：$P(S{=}2\mid do(A{=}1))=6/8=0.75$，远低于台账上的 $1$；均值口径同理：$\mathbb{E}[S\mid A{=}1]=2$ 对 $\mathbb{E}[S\mid do(A{=}1)]=7/4$；
6. **顺杆测出总效果**：再算 $do(A{=}0)$ 得 $\mathbb{E}[S]=3/4$，两个干预相减，真实广告效果 $=7/4-3/4=1$ 杯——干净利落的一杯，而不是台账暗示的天壤之别。

左柱是台账里的世界，中间和右柱才是政策旋钮真正能到达的两个世界。左右两柱之差（0.25 杯）全是天气择优的功劳；中间与右柱之差（1 杯）才是广告本身的力气。

### 实验 2（python）：同底账，双出口

```python title="八世界的完整对照实验"
atoms = []                                   # 收集八个等可能世界
for t in (0, 1):                             # T：热天骰子
    for l in (0, 1):                         # L：招牌灯骰子
        for g in (0, 1):                     # 第三枚骰子：路演夜
            a = t * l                        # 原方程：广告 = 热×灯
            d = t or g                       # 客流 = 热天或有路演
            atoms.append([t, l, g, a, d])

def observe(rows):
    picked = []
    for r in rows:
        if r[3] == 1:                        # 条件化：只挑 A=1 的行
            picked.append(r[3] + r[4])       # 销量按原方程拼接
    return picked

def intervene(rows, forced):
    made = []
    for r in rows:
        a_new = forced                       # 手术：a 不再听父母的话
        d_old = r[0] or r[2]                 # 其余机器照常运转
        made.append(a_new + d_old)
    return made

seen = observe(atoms)
forced_on = intervene(atoms, 1)
forced_off = intervene(atoms, 0)

print("看 A=1 样本:", seen)
# count：统计列表里某个值出现了几次
print("do A=1 分布:", forced_on.count(1), "个不旺,", forced_on.count(2), "个大卖")
print("do A=0 分布:", forced_off.count(0), "个冷清,", forced_off.count(1), "个平稳")
print("三种均值:", sum(seen) / len(seen),
      sum(forced_on) / len(forced_on),
      sum(forced_off) / len(forced_off))
```

输出依次为 `[2, 2]`、`2 / 6`、`2 / 6` 与 `2.0  1.75  0.75`——第 4 节表格的全部数字一键复现。注意 `intervene` 里根本没有按 `A` 挑行的语句：这就是"不许再从结果倒推原因"的实现形态。

### 快问快答

```quiz
下列哪个问题必须用 P(Y | do(X=x)) 才能正确回答？
- 看见橱窗摆了新品时，进店率是多少？
- 把橱窗新品全部撤下，进店率会怎样变化？ [*]
- 进店的顾客里，多少人顺便看了橱窗？
? 只有第二种是把 X 当作"待拧的旋钮"来发问。前两种都是描述可见世界的关联，台账即可回答——提问方式本身决定了我方需要哪层的数学。
```

:::warning[常见误区]

**误区一**：你以为 $do(X{=}x)$ 是一种更强的"条件于更极端的 $X$"。强度不是差别所在，信息的方向才是：条件化让数据替你筛选世界，干预让你指定世界。前者永远得不到后者没编码的内容。

**误区二**：你以为做手术也要切断 $X$ 的出边。出边恰恰是效应传出的血管——剪掉它们，等于先杀死了病人再量脉搏。手术刀只落在指入 $X$ 的箭头上。

**误区三**：你以为两枚分布差别不大就可放心互换。差多少取决于路径强度，而"哪条路径是因果、哪条是混流"无法从差异大小看出来；差异小可能只是虚惊，也可能是两条相反的偏倚恰好抵消。分道扬镳与否，靠图判据说话——这正是下一课的主题。

:::

## 6. 练习

**练习 1**：初始代码把三个关键计数都填错了，请修正；预期输出依次应为 `2`、`6`、`2`、`1`：

```exercise
# @title: 练习：数清楚两个世界的家底
# @check: 2
# @check: 6
# @check: 2
# @check: 1
# @hint: 观察口径要先筛 A=t*l==1 再数大卖；do 口径不筛行，直接把 a 替换成定值后再数；最小值想一想 do(A=1) 下销量还会不会归零
rows = []                                    # 八个世界：[T, L, U3]
for t in (0, 1):
    for l in (0, 1):
        for g in (0, 1):
            rows.append([t, l, g])

hits_obs = 0                                 # 观察：A=1 且 S=2 的世界个数
hits_on = 0                                  # do(A=1)：S=2 的世界个数
hits_off_zero = 0                            # do(A=0)：S=0 的世界个数
min_do_on = 9                                # do(A=1)：最小的 S（先放一个大数）
for r in rows:
    t, l, g = r[0], r[1], r[2]
    if t * l == 1 and t * l + (t or g) == 2:
        hits_obs += 1

    s_on = t * l + (t or g)                  # ← 有 bug：这仍是观察公式，没焊死 a
    if s_on == 2:
        hits_on += 1

    a_forced_off = 1                         # ← 有 bug：do(A=0) 应焊死为 0
    s_off = a_forced_off + (t or g)
    if s_off == 0:
        hits_off_zero += 1

    if s_on < min_do_on:
        min_do_on = s_on

print(hits_obs)
print(hits_on)
print(hits_off_zero)
print(min_do_on)
```

**练习 2**：有人提议"既然要切断混淆，那我把每个变量的所有邻居都临时拆线、只留自己单独运转，最干净"。请指出这种'全面断联'方案错在哪里。

<details>
<summary>点开查看逐步解答</summary>

全面断联等价于把整张因果网拆成一堆孤岛，得到的所有变量都退化为纯噪声——算出的"干预分布"属于一个从未存在过的碎裂宇宙，与现实运行无关。正确的干预是外科式的：只对提问涉及的 $X$ 换电源，其余线路必须保持原生状态，这样模拟出的才是"除了这一处被扳动、世界照常呼吸"的反事实现实。换句话说，**do 的力量一半来自切断谁，另一半来自放过谁**。
</details>

<summary>选读 · 从辛普森悖论到调整公式</summary>

回看第 10 课的分层表：把子组效应按子组占比加权平均，就能剥掉混杂。这套老手艺其实就是截断因子化的特例——"按混杂分布加权"对应保留混杂节点的因子、"划掉处理变量的因子"对应不再按处理取值反推人群构成。当图中有多条后门路径时，把所有可控的混杂因子一起进权、其余因子原样连乘，就成了下一课的后门调整公式。可以说，珀尔整套识别理论就是"哪些因子可乘、哪些必须截断"的完整说明书，而其中的两页纸——后门与前门——即将翻开。
