# 反事实思维：平行世界里的那个你

## 1. 从一个场景开始

小明发烧，吃了退烧药，第二天退烧了。妈妈宣布："多亏这药！"爸爸摇头："不吃药，今天也退了。"谁对？

注意这场争论的奇特之处：它关于一件**从未发生的事**。要裁决谁对，我们得知道小明在"没吃药"那条时间线里会不会退烧——可他吃了药，另一条时间线没有留下任何记录。"假如当初"如何才能变成可以计算的对象？这是因果之梯最高层的入场券。

## 2. 直觉解释

想象每个关键时刻都分裂出**平行世界**：世界 A 里小明吃药，世界 B 里他没吃。两份结局摆在一起，差值就是药物对他的真实效果。

麻烦在于我们是凡人：只能站在一条时间线里。看见的那份叫**事实**，看不见的那份叫**反事实**——统计学家鲁宾（Donald Rubin）称之为**潜在结果**："潜在"，因为它在另一种处理下本可以发生。

个体的因果效应永远无法直接测量（一个人不能既吃药又不吃药），这叫**基本问题**。那这门学科还剩什么可做？答案是：把问题从个体搬到群体——随机分组让两组人在统计上"同源"，群体的平均效果就变得可以估计了。本课先在上帝视角的完整表格里练手，再下到凡间看现实能看见什么。

## 3. 正式定义

对个体 $i$ 与二值处理：

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $Y_i(1)$ | 潜在结果 | 若个体 $i$ 接受处理会出现的结局 |
| $Y_i(0)$ | 潜在结果 | 若不接受会出现的结局 |
| $\text{ITE}_i$ | 个体处理效应 | $Y_i(1) - Y_i(0)$，两个世界的差 |

**平均处理效应**：

$$\text{ATE} = \mathbb{E}\big[Y(1) - Y(0)\big]$$

**基本问题**（Holland, 1986 命名）：对每个个体，$Y_i(1)$ 与 $Y_i(0)$ 至多能观察到一个。

**随机化的救赎**：当处理是随机指派时，两组在期望意义上同质，于是

$$\mathbb{E}\big[Y(1)-Y(0)\big] = \mathbb{E}[Y \mid T{=}1] - \mathbb{E}[Y \mid T{=}0]$$

右边全部由可观察数据构成——不可见的平行世界之差，被随机化翻译成了可见的组间之差。

## 4. 分步例题

三名员工，公司考虑发培训名额。上帝视角的完整表格（现实中拿不到）：

| 员工 | 参加后的工资增量 | 不参加的工资增量 | ITE |
| --- | --- | --- | --- |
| 甲 | 9 千 | 5 千 | +4 千 |
| 乙 | 7 千 | 6 千 | +1 千 |
| 丙 | 12 千 | 11 千 | +1 千 |

1. 算个体效应列：甲 $9-5=4$；乙 $7-6=1$；丙 $12-11=1$；
2. 平均处理效应 $\text{ATE} = (4+1+1)/3 = 2$ 千；
3. 切回凡间：公司按"自愿报名"执行，只有丙举手。凡间只见一条时间线——丙涨了 12，甲、乙各涨了 5 和 6；
4. 天真的"效应估计"：参加组均值 $12$，未参加组均值 $(5+6)/2 = 5.5$，差 $6.5$ 千——把真实 ATE 高估三倍不止；
5. 事故原因：报名者丙本来就是两条时间线都会大涨的人（自选择）。比较"参加者与未参加者"，实际比较的是**两种人**，不是**两种待遇**。

### 实验 1（viz）：天真账和平行世界账

左柱把“两种人”当成了“两种待遇”；右柱才是同一批人在两条时间线里的平均差。先记住这两根柱的高度差，再用代码拆开它。

### 实验 2（python）：上帝视角与凡间视角

```python title="同一张表，两种视角，两个答案"
# people 的每个元素是 [姓名, 参加工资, 不参加工资]，单位千元——上帝视角完整表
people = [["甲", 9, 5], ["乙", 7, 6], ["丙", 12, 11]]

ites = []
for p in people:
    ite = p[1] - p[2]              # 个体效应：两个世界的工资差
    ites.append(ite)
print(f"各人 ITE: {ites}")

ate = sum(ites) / len(ites)
print(f"真实 ATE: {ate:.1f}")

naive = 12                          # 凡间：丙参加，只看得见 Y(1)=12 这一条线
stay_avg = (5 + 6) / 2              # 未参加的甲乙，只看得见各自 Y(0)
print(f"天真的组间差: {naive - stay_avg:.1f}")
```

输出 `[4, 1, 1]`、`2.0`、`6.5`——第 4 节的手算全部复现。

### 实验 3（python）：抽签如何救场

```python title="把自愿报名换成随机抽签"
import random

y1 = {"甲": 9, "乙": 7, "丙": 12}   # 字典：花括号里"键: 值"，用键查值
y0 = {"甲": 5, "乙": 6, "丙": 11}
names = ["甲", "乙", "丙"]

diffs = []                           # 记录每次随机实验的组间差
for trial in range(4000):
    treated = []                     # 本轮抽中的幸运儿名单
    for name in names:
        if random.random() < 0.5:    # random.random()：取 0 到 1 的随机小数，各半概率入组
            treated.append(name)

    has_treat = len(treated) > 0
    has_ctrl = len(treated) < 3
    if not (has_treat and has_ctrl): # 两组必须都非空才能比较
        continue                     # continue：跳过本轮循环的剩余部分

    t_sum, c_sum = 0, 0              # 多变量同时赋值
    for name in names:
        if name in treated:          # 凡间规则：被抽中只显示 Y(1)，否则 Y(0)
            t_sum += y1[name]
        else:
            c_sum += y0[name]
    diffs.append(t_sum / len(treated) - c_sum / (len(names) - len(treated)))   # 对照组人数 = 总人数减处理组人数

est = sum(diffs) / len(diffs)
print(f"随机实验的平均估计: {est:.2f}")
```

典型输出在 `2.0` 附近小幅波动——**抽签让天真的组间差自动对准真实 ATE**。这就是随机对照试验的全部数学秘密：不追求每个个体公平，只追求两组同源。（大数定律在幕后打工，卷九的老朋友。）多跑几次看波动幅度，再想想为什么自愿制下无论重跑多少次都停在 `6.5`。

### 实验 4（matplotlib）：平行世界的斜率图

```python title="每人一根线：左端是不参加的你，右端是参加的你"
import matplotlib.pyplot as plt

data = [["甲", 5, 9], ["乙", 6, 7], ["丙", 11, 12]]   # [姓名, Y(0), Y(1)]

for p in data:
    plt.plot([0, 1], [p[1], p[2]], marker="o")        # 一条线连接两个世界的结局
    plt.text(-0.06, p[1], p[0], ha="right")
    plt.text(1.06, p[2], f"+{p[2] - p[1]}", ha="left", color="dimgray")

plt.xticks([0, 1], ["不参加的世界", "参加的世界"])
plt.xlim(-0.5, 1.5)
plt.ylabel("工资增量（千元）")
```

每根线的斜率就是该员工的 ITE：甲的线最陡（+4），乙、丙平缓（+1）。注意右端的三个点比左端更分散——培训放大了人与人之间的差距。平均效应相同的世界，个体命运可以截然不同。

### 快问快答

```quiz
"张三吃了药三天就好了"这句话若要成为因果结论，隐含的对照是什么？
- 隐含对照是安慰剂组的平均痊愈速度
- 隐含对照是张三不吃药的那个平行世界，而它从未被观察 [*]
- 不需要对照，好转本身就是证据
? 单个反事实陈述永远无法验证——另一个世界没有留档。能让因果结论站住的，是把无数个不可见的"张三"组织成可比群体的设计。
```

:::warning[常见误区]

**误区一**：你以为"为您提升 30 分"这类广告承诺可以被科学担保。对**个体**的处理效应原则上测不到（基本问题）；能兑现的只有群体平均值——你个人的效果可能高得多也可能为零甚至为负。

**误区二**：你以为 ATE 相同的政策同样好。斜率图提醒我们：均值背后藏着完全不同的受益分布。"平均涨薪两千"可能是人人一千五，也可能是一人一万八其余归零。

**误区三**：你以为反事实只是文学修辞。给定因果模型，$Y_i(0)$ 有严格定义、有数值、有置信区间；没有模型它才退化为修辞。这也是上一课强调"先画图"的原因——图就是反事实问题的答题卡。

:::

## 7. 选读：两套语言，一座桥

<details>
<summary>选读 · 鲁宾的潜在结果与珀尔的结构反事实</summary>

本课的潜在结果框架（Rubin, 1974；Holland, 1986 总结）把因果效应定义成"两个潜在结果之差"，长于实验设计与估计；珀尔的结构因果模型则从"切断箭头后的世界"出发推导反事实，长于表达复杂图结构。两者已被证明在数学上可以互相翻译：结构模型里的 $Y_x(u)$ 对应潜在结果 $Y_i(x)$。日常实践中的一句话分工——**谈设计用鲁宾的语言（分组、盲法、可比性），谈假设画珀尔的图（箭头、后门、do）**。掌握任一套，另一套都更容易上手。

</details>
