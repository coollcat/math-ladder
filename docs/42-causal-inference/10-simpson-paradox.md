# 相关会撒谎：辛普森悖论开场

## 1. 从一个场景开始

1986 年，《英国医学杂志》刊登了一项肾结石治疗对比（Charig 等，1986）：350 名患者接受传统开刀取石，350 名接受新的微创技术（经皮肾镜）。汇总成绩单——

- 开刀：成功 $273/350 \approx 78\%$
- 微创：成功 $289/350 \approx 83\%$

结论似乎明明白白：**微创更好**。可是八年后，两位统计学家（Julious 与 Mullee，1994）把同一批数据按"石头大小"重新拆开，报表瞬间精神分裂：**分小组看，开刀在每一组里都更强；合在一起看，却输给了微创**。两份报表都是真的。这一课就从这个"数学没出错、结论却翻转"的事故现场出发。

## 2. 直觉解释

翻转的机关是**人数配比**。

开刀是老技术，大石头（难治的）大多归了它；微创是新潮选项，小石头（好治的）大多选了它。于是微创的总体成功率站在一群"简单题"上，开刀的总体率则背着一大批"难题"。好比两位学生：乙在简单卷和困难卷上都考得不如甲，可乙恰好抽到的简单卷多得多——总分反而更高。

合并率本质是个**加权平均**：每组成功率乘以该组人数占比再相加。两组的权重不同，加权平均的大小关系完全可以和组内的大小关系相反。这不是数学故障，而是"把不可比的混合比率摆上天平"这个动作本身的故障。

## 3. 正式定义

**辛普森悖论**：存在一种分组方式，使得对每一组 $i$ 都有 $P(A \mid B, C_i) > P(A \mid \bar{B}, C_i)$，但把分组抹掉后 $P(A \mid B) < P(A \mid \bar{B})$。（$\bar{B}$ 读作"B 不成立"。）

机制一句话：合并率是组率的加权和，

$$\text{合并率}(B) = w_1 \cdot P(A \mid B, C_1) + w_2 \cdot P(A \mid B, C_2)$$

其中权重 $w_i$ 是 **B 组内部**落在 $C_i$ 的人数占比。只要 $B$ 与 $\bar{B}$ 两边的权重结构不同，不等号就能翻转。

真实数据的完整对照表：

| | 开刀 | 微创 |
| --- | --- | --- |
| 小石头（小于 2 cm） | $81/87 = 93.1\%$ | $234/270 = 86.7\%$ |
| 大石头（不小于 2 cm） | $192/263 = 73.0\%$ | $55/80 = 68.8\%$ |
| **合计** | $273/350 = 78.0\%$ | $289/350 = 82.6\%$ |

看权重：微创组的病人 $77\%$ 是小石头（$270/350$），开刀组只有 $25\%$（$87/350$）——天平两端放的砝码根本不同。

## 4. 分步例题

用迷你数字亲手造一个悖论（药物 A 对 B，结局为康复）：

1. A 组：轻症 $9/10 = 90\%$ 康复；重症 $20/40 = 50\%$ 康复；
2. B 组：轻症 $85/100 = 85\%$；重症 $4/10 = 40\%$——每个小组内 A 都胜出；
3. 合并：A 共 $(9+20)/(10+40) = 29/50 = 58\%$；B 共 $(85+4)/(100+10) = 89/110 \approx 80.9\%$；
4. 翻转出现：组内 A 全胜，总分 B 领先 23 个百分点；
5. 追凶：A 组的重症占比高达 $80\%$（$40/50$），B 组仅 $9\%$（$10/110$）——A 的总分被重症拖垮。**改变比分的不是题目难度本身，而是两组人撞上的难度配比。**

### 实验 2（python）：从计数重建全部六个百分比

```python title="肾结石数据的六次除法"
# 计数格式：[成功数, 总数]，数据来自 Charig et al. (1986)
small_open = [81, 87]     # 小石头 + 开刀
small_perc = [234, 270]   # 小石头 + 微创
large_open = [192, 263]   # 大石头 + 开刀
large_perc = [55, 80]     # 大石头 + 微创

def rate(cell):           # def 函数：输入 [成功, 总数]，返回百分数（保留一位小数）
    return round(cell[0] / cell[1] * 100, 1)

print(f"小石头  微创 {rate(small_perc)}% vs 开刀 {rate(small_open)}%")
print(f"大石头  微创 {rate(large_perc)}% vs 开刀 {rate(large_open)}%")

all_open = [small_open[0] + large_open[0], small_open[1] + large_open[1]]
all_perc = [small_perc[0] + large_perc[0], small_perc[1] + large_perc[1]]
print(f"合计    微创 {rate(all_perc)}% vs 开刀 {rate(all_open)}%")

share_small_perc = small_perc[1] / (small_perc[1] + large_perc[1])   # 微创组里小石头占比
check = share_small_perc * rate(small_perc) + (1 - share_small_perc) * rate(large_perc)
print(round(check, 1))   # 加权分解：占比×组率 相加，应还原合计值
```

最后一行的加权分解打印出 `82.6`——合计值确实是"小石头占七成七的加权平均"，机关当场拆穿。（`share_small_perc` 算的正是这个权重：微创组里小石头的占比，删掉它下一行立刻报错；换成开刀组的占比 `small_open[1] / (small_open[1] + large_open[1])` 再加权一遍，会还原出开刀组的合计率。）

### 实验 3（matplotlib）：一张图装下整个悖论

```python title="三组口径的成功率对比"
import matplotlib.pyplot as plt

groups = ["small stones", "large stones", "ALL"]
perc_rates = [86.7, 68.8, 82.6]     # 微创
open_rates = [93.1, 73.0, 78.0]     # 开刀

pos = [0, 1, 2]
plt.bar([p - 0.18 for p in pos], perc_rates, width=0.36, label="percutaneous")   # 列表推导式批量错位
plt.bar([p + 0.18 for p in pos], open_rates, width=0.36, label="open surgery")
plt.xticks(pos, groups)
plt.ylabel("success rate (%)")
plt.ylim(60, 100)
plt.axvline(1.5, color="gray", linestyle="--")   # axvline：竖直参考线，隔开分组与合计
plt.legend()
```

虚线左边：橙柱（开刀）双双更高；右边合计处蓝柱反超——**一图看尽方向反转**。

### 快问快答

```quiz
作为院长，你该依据哪张表决定给下一位病人的术式建议？
- 合计表，它样本最多最可靠
- 分层表，因为石头大小同时影响"选哪种术式"与"能否治好" [*]
- 哪张都行，反正结论会翻转
? 石头大小是治疗前就确定的病情属性，且同时影响术式选择与疗效——比较疗效必须固定它（分层或更规范的随机化）。合计表把两种病情结构搅成一锅。
```

:::warning[常见误区]

**误区一**：你以为悖论说明统计学自相矛盾。数学全程无误；错的是解释层面——两个合并率的可比性被不同的组内构成破坏了。

**误区二**：你以为样本够大就不会遇到它。与样本量无关：把表中所有数字同乘一万倍，翻转原封不动。它是**结构性**现象。

**误区三**：你以为"永远该信分层表"。方向取决于变量扮演的角色：石头大小是治疗**之前**的属性，该分层；但若第三个变量是治疗后的后果（如并发症），分层反而制造扭曲。"什么时候该控制什么"正是本章后面因果图要正式回答的问题。

:::

```exercise
b_mild = [85, 100]     # 药物B 轻症
b_severe = [4, 10]     # 药物B 重症

print(round(a_mild[0] / a_mild[1] * 100))          # A 轻症（已示范）

print(round(0))                                    # ← 占位：A 重症的康复百分数
print(round(b_mild[0] / b_mild[1]))                # ← 有 bug：算出来的是小数比例，忘了换算百分数
print(round(0))                                    # ← 占位：B 重症的康复百分数

print(round((a_mild[0] + a_severe[0]) / (a_mild[1] + a_severe[1])))   # ← 有 bug：同样忘了乘 100
print(round(0))                                    # ← 占位：药物 B 的合并总率（照上一行的结构写）
```

**练习 2**：想自己配制一个辛普森悖论，配方是什么？

<details>
<summary>点开查看逐步解答</summary>

两条原料：(1) **组内优势**——想让谁最终翻盘获胜，就让对手在每个小组里都略胜；(2) **权重悬殊**——让己方绝大多数样本落在"容易出高分"的小组里，对方落在低分组。悬殊越极端，翻转幅度越大。检验配方是否成立的唯一标准是把四个格子填进加权公式各算一遍。顺便记住这个配方，你在广告 AB 测试、学校升学率排名里都能亲手抓到现行。
</details>

## 7. 选读：悖论简史与伯克利招生案

<details>
<summary>选读 · 它不止住在医院里</summary>

尤尔（Yule, 1900）与辛普森（Simpson, 1951）先后从代数上刻画了这种现象，"辛普森悖论"由此得名。最著名的现实版本是 1973 年加州大学伯克利分校研究生录取争议：全校汇总显示男性录取率显著高于女性，看似性别歧视；统计学家 Bickel 等（1975，《科学》）按院系分层后发现，多数院系里女性录取率反而持平甚至更高——真相是女性更多申请了录取率普遍偏低的人文院系，而男性扎堆在名额庞大的工科。汇总表把"院系选择"这个第三变量藏了起来，制造了一桩冤案。处理办法不是丢弃汇总数据，而是先问一句：**有没有一个既影响选择、又影响结局的量被悄悄混进来了？**

</details>
