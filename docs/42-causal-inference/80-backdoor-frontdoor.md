# 后门准则与前门准则

## 1. 从一个场景开始

灯塔学院把"强化营报名记录"接进了数据仓库，想知道：**报名强化营（$X$）究竟让"拿到名企推荐名额"（$Y$）的概率涨了多少？**

台账里能查到三个字段：是否报名 $X$、是否通过结业认证 $M$、最终是否被推荐 $Y$。问题是，人人皆知报名与否和学习动机脱不了干系——可"动机"这个量从来没人采集过。按上一课的规程，计算 $P(Y \mid do(X))$ 需要整套方程组；现实只递给你一张残缺的联合表和一张因果图。好消息是：**有些残缺可以绕过去**。本课给出两条互补的绕行路线——后门调整与前门调整，并在一份可以逐行核对的账本上验证它们。

## 2. 直觉解释

把混杂想象成两地之间横着的山脉。

- **后门路线**：山的每条垭口你都认得、都踩得到点（混杂因子可观测），那就挨个派人在垭口把守。守齐所有从 $X$ 背后伸来的小路，剩下的关联就只剩因果干道——这正是第 30 课辛普森分层表的正规化。
- **前门路线**：万一整座山都是禁区（混杂完全不可见），还有一招：如果影响必须先经过某个**中转站**（中介 $M$），而且你恰好能在中转站两侧自由通行，那就可以"借道中转"重建因果量——先量出 $X$ 对 $M$ 的推力，再在中转站里扣掉 $X$ 的旧影子，最后把 $M$ 到 $Y$ 的推力接力上去。

两扇门各有一个适用前提清单，漏一条就会算错账。下面的例题会用同一份 128 行账本同时演练两门。

## 3. 正式定义

**后门准则**：变量集 $Z$ 满足 (i) $Z$ 中不含 $X$ 的后代；(ii) $Z$ 挡住了每一条指入 $X$ 的后门路径，则

$$P(y \mid do(X{=}x)) = \sum_z P(y \mid X{=}x,\ Z{=}z)\; P(Z{=}z)$$

**前门准则**：若中介 $M$ 满足三条——(i) $M$ 截断了所有 $X{\to}Y$ 的有向通路；(ii) 不存在 $X$ 与 $M$ 之间未被封锁的后门；(iii) 所有 $M{\to}Y$ 的后门都被 $X$ 封锁——则

$$P(y \mid do(X{=}x)) = \sum_m P(m \mid X{=}x) \sum_{x'} P(y \mid m,\ X{=}x')\; P(X{=}x')$$

两条公式的姿态截然相反：后门式在外围打包围，前门式在腹地做换乘。共同底线是**正性**——公式涉及的每个条件格子里都得有人，除以零就全线崩塌。

## 4. 分步例题

构造一份完全透明的账本：128 名学生等权，七枚公平硬币。隐藏列只有一枚——学习动机 $U$。结构方程全部由硬币经简单逻辑门生成：

- 报名 $X := U \oplus (C_1 \wedge C_2)$：动机强的人大概率报名（约 3/4），弱的也偶有冲动；
- 认证 $M := (X \wedge \overline{N_{12}}) \vee (\bar{X} \wedge N_{34})$：报了营大多通过（3/4），没报也有自学通过的（1/4）；
- 推荐 $Y := M \vee U$：拿到名额靠认证或硬实力。

1. **天真对比**：$\mathbb{E}[Y\mid X{=}1]=15/16$，$\mathbb{E}[Y\mid X{=}0]=7/16$，组间差 $1/2$——报表上"报名让推荐率翻倍还多"；
2. **上帝视角**：偷看隐藏列做真实干预，得 $\mathbb{E}[Y\mid do(1)] = 14/16$ 与 $\mathbb{E}[Y\mid do(0)] = 10/16$，真效应仅 $1/4$。天真的 $1/2$ 虚高一倍，全是"动机同时催报名、又直接抬推荐"的功劳；
3. **后门修正**：虽然 $U$ 不上台账，先假装全能看见练手——按 $U$ 分层求 $\mathbb{E}[Y\mid X,U]$ 差值再按 $P(U)$ 加权：下层贡献 $0.25$、上层贡献 $0$，合计恰为 $1/4$，完美复原。可惜现实中没有这列；
4. **前门救援**：改用 $(X,M,Y)$ 三列公开数据。查表得 $P(M{=}1\mid X{=}1)=3/4$、$P(M{=}1\mid X{=}0)=1/4$；再固定 $M$ 扫描各 $X'$ 得内层和：$m{=}0$ 时 $0.5$，$m{=}1$ 时 $1$。代入前门公式：
$$\tfrac{1}{4}\times 0.5 + \tfrac{3}{4}\times 1 = 0.875,\qquad \tfrac{3}{4}\times 0.5+\tfrac{1}{4}\times 1 = 0.625$$
   相减仍是 $1/4$——两扇门在同一个数字会师；
5. **复盘关键一步**：内层对 $x'$ 的扫描重新混入了"不同来路"的人群比例 $P(X{=}x')$，等于亲手把动机造成的报名失衡摊平——前门的巧妙全在这里。

第一根柱是敢不敢直接上报的分水岭：凭空夸大一半。三根矮柱并排躺在 25 上，其中后门与前门是在**不偷看隐藏列之外的任何信息**的前提下达成的——调仇的工具不同，答案却一致，这才叫识别。

### 实验 2（python）：128 人账本的三种算法

```python title="同一份账本：天真、后门、前门"
rows = []                                    # 每行 [u,c1,c2,n1,n2,n3,n4,x,m,y]
for u in (0, 1):
    for c1 in (0, 1):
        for c2 in (0, 1):
            for n1 in (0, 1):
                for n2 in (0, 1):
                    for n3 in (0, 1):
                        for n4 in (0, 1):
                            x = u ^ (c1 and c2)
                            m = (x and (1 - (n1 and n2))) or \
                                ((1 - x) and (n3 and n4))
                            rows.append([u, c1, c2, n1, n2, n3, n4, x, m,
                                         m or u])

def pick(pred):                              # 按条件挑出行并返回 y 列表
    ys = []
    for r in rows:
        if pred(r):
            ys.append(r[9])
    return ys

def avg(ys):
    return sum(ys) / len(ys)

naive_gap = avg(pick(lambda r: r[7] == 1)) - avg(pick(lambda r: r[7] == 0))
god_gap = 0.875 - 0.625                      # 上帝视角直接干预的结果（可复算）

backdoor = 0                                 # 按 U 分层的加权平均
for uv in (0, 1):
    w_u = len(pick(lambda r: r[0] == uv)) / len(rows)
    e_on = avg(pick(lambda r: r[0] == uv and r[7] == 1))
    e_off = avg(pick(lambda r: r[0] == uv and r[7] == 0))
    backdoor += w_u * (e_on - e_off)

px = len(pick(lambda r: r[7] == 1)) / len(rows)   # P(X=1)，此模型里恰为一半
frontdoor = {"on": 0.0, "off": 0.0}
for forced in ("on", "off"):
    xv = 1 if forced == "on" else 0
    for mv in (0, 1):
        pm_x = len(pick(lambda r: r[7] == xv and r[8] == mv)) / \
               len(pick(lambda r: r[7] == xv))    # P(M=m | X=x)
        inner = 0.0
        for xp in (0, 1):
            cell = pick(lambda r: r[8] == mv and r[7] == xp)
            inner += (len(cell) / len(rows)) * avg(cell)
        frontdoor[forced] += pm_x * inner

print("天真:", naive_gap, "| 真实:", god_gap)
print("后门:", backdoor)
print("前门:", frontdoor["on"], "-", frontdoor["off"],
      "=", frontdoor["on"] - frontdoor["off"])
```

输出 `天真: 0.5`、`后门: 0.25`、`前门: 0.875 - 0.625 = 0.25`。注意三处纪律：`backdoor` 循环里的分层权重用全体占比 $P(U)$；`frontdoor` 内层把每个 $(m,x')$ 格的人数摊回总人口；全部判定只用 $(x,m,y,u)$ 计数，未碰过那五枚噪声硬币的真身。

### 快问快答

```quiz
使用前门公式之前，下面哪项属于必须核查的前提？
- 结业认证 M 是报名 X 的间接后果之一，且不存在从 X 直通 Y 的暗线 [*]
- M 的取值越多越好，至少要有十档
- 台账必须连噪声硬币一起登记
? 三条件缺一不可：M 得截断全部有向通路、X 到 M 无敞开后门、M 到 Y 的后门已被 X 锁死。与噪声骰子是否入账无关——那是 SCM 全分布才需要的奢侈品，这里只用观察计数。
```

:::warning[常见误区]

**误区一**：你以为后门集合里塞进中介也无妨。控制中介 $M$ 会把 $X$ 经它的那条血管掐断，得到的不再是你想要的总量。后门集合的后代禁令正是为了排除这类"看似顺手"的成员。

**误区二**：你以为两扇门同时可用就必然结论一致。它们依赖的条件互不相同，有一条不满足时就可能一真一假；本例的双双命中是因为模型干净。分歧出现不是坏事——它在提示某条前提被违反了。

**误区三**：你以为格子空一点照样能用。前门公式要求每个 $(m, x')$ 组合都有观测，后门公式要求每个混杂层里两种处理都在场。工程里这类"正性破洞"要用重加权或平滑补救，但那是另一门功课。

:::

## 6. 练习

**练习 1**：初始代码组装前门公式时拿错了权重。修正后输出应依次为 `0.875`、`0.625`、`0.25`：

```exercise
# @title: 练习：亲手装配前门公式
# @check: 0.875
# @check: 0.625
# @check: 0.25
# @hint: 外层权重应是【给定本次强制值的】P(M=m|X=x)，来自 pm 表；内层权重恒为总人群的 P(X=x')
pm1 = {0: 0.25, 1: 0.75}     # P(M=1 | X=x)：不报名的人 1/4 通过，报名的 3/4
px = {0: 0.5, 1: 0.5}        # 总人群里报名与否的比例
# 已从账本数好的条件概率表 P(Y=1 | M=m, X=x')，行下标为 m，列下标为 x'
py1 = [[0.25, 0.75],         # m=0：两个来路里硬实力的浓度不同
       [1.0, 1.0]]           # m=1：一旦认证在手，推荐已成定局

inner = {0: 0.0, 1: 0.0}
for mv in (0, 1):
    for xp in (0, 1):
        inner[mv] += px[xp] * py1[mv][xp]

fd = {}
pm_weight = {0: 0.5, 1: 0.5}             # ← 有 bug：这是边缘概率 P(M)，应当换成 pm1
for xv in (0, 1):
    total = 0.0
    for mv in (0, 1):
        total += pm_weight[mv] * inner[mv]
    fd[xv] = total

print(round(fd[1], 3))
print(round(fd[0], 3))
print(round(fd[1] - fd[0], 3))
```

**练习 2**：假如平台的动机问题更极端——动机最强的那一批人 **100% 都报了名**。此时还能按 $U$ 分层做后门调整吗？前门路线受不受影响？

<details>
<summary>点开查看逐步解答</summary>

不能了。$U$ 最强的那层里 $X$ 恒为 1，$\mathbb{E}[Y\mid X{=}0,U]$ 成为无数据之格——后门公式在该层除零，这不是程序错误而是结构性的信息缺失（正性被破坏）。前门路线对此免疫：它只在固定的 $X$ 取值处读取 $P(M\mid X)$，再借人群的 $P(X{=}x')$ 重排权重，全程不向"同一动机层内的另一臂"索要数据。代价照旧要付——它的成立仰仗中介那三条结构前提。选择哪扇门，最终取决于**哪边的假设在你的领域更可信**。
</details>

## 7. 选读：门外的世界

<details>
<summary>选读 · 后门与前门只是目录页</summary>

珀尔的 do 演算给了一组更机械的重写规则：任何干预分布表达式只要能逐步化简成纯观察符号的组合，就叫可识别——后门与前门只是其中最著名的两个成品范式。演算的证明核心是一条"删公式定理"：指向某节点的箭头断掉之后，它的条件概率因子可以从乘积中整体删除，且既不影响似然也不影响结构。此后学界的交通灯也从二色变多色：不可见混杂 + 多重中介 + 干涉溢出对应着差分中的差分、断点附近比较等形形色色的识别设计——下一课的工具变量就是其中的常青树。
</details>
