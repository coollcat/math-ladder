# 工具变量与断点回归直觉

## 1. 从一个场景开始

灯塔学院上线了「错题重算法」辅导软件，教务会上只剩一个问题：**真的每天用它刷题（$X$），月考成绩（$Y$）能涨几分？**

上一课的后门路线在这里卡壳：愿不愿意坚持用软件，和学习热情脱不了干系，而"热情"这个混杂因子压根不在台账里——后门的垭口全在禁区里，一个都把守不了。好在本章实战挑战第三幕早就埋了伏笔：学院当初是**按学号奇偶随机发放激活码**的。抽中的多半会用起来，没抽中的少数人也自己蹭到了账号；随机指派 $Z$ 干净得像硬币，可惜它不是"使用"本身——指派之手没能按服所有人。这门半途而废的随机实验，反而成了一把现成的撬棍。

## 2. 直觉解释

把估计因果效应想象成**挪动一块巨石**：

- **直接上手推**（普通对比）：手和石头之间隔着淤泥。热情既让人多用软件、又让人成绩好，两条绳缠在一起，推出来的力道虚高。
- **找一根钢钎**（工具变量）：抽签 $Z$ 是插进石底的撬杠，它只干一件事——把一部分人的"使用率"顶上去。钢钎不认识成绩单，也不偏袒热情的学生。

两段传动合起来看：钢钎先把使用率撬动了多少（第一阶段），被撬动的这部分使用又把成绩抬了多少（第二阶段），一除，就是每一分"真实使用"的价值。混杂被隔离在传动链之外，根本不用知道它是谁。

像测一段黑箱水管的水压：往入口注水、量出口流量——前提只有一个，中间不许有别的出水口。

## 3. 正式定义

变量 $Z$ 要当好 $X{\to}Y$ 的工具变量，须满足两条：

| 条件 | 内容 | 本例的化身 |
| --- | --- | --- |
| 相关性 | $Z$ 确实撬动 $X$ | 领到激活码，使用率真实上涨 |
| 排他性 | $Z$ 对 $Y$ 的影响**只许**经过 $X$ 这一扇门 | 激活码既不会显灵提分，也不会顺便替你复习 |

两条齐备时，真实效应由 **Wald 估计量**复原：

$$\beta_{IV} = \frac{\mathbb{E}[Y \mid Z{=}1] - \mathbb{E}[Y \mid Z{=}0]}{\mathbb{E}[X \mid Z{=}1] - \mathbb{E}[X \mid Z{=}0]}$$

分子是"指派把成绩平均抬了几分"，分母是"指派把使用率撬动了几个百分点"；相除得到**被撬动那批人**身上每单位使用的真实回报。它还有个更正式的名字叫两阶段最小二乘的源头思想——先用 $Z$ 拟合出 $X$ 里干净的那部分，再让这份干净的变异去解释 $Y$；二元工具下整台机器就退化成上面这个比值。

同一思想还有一副更日常的面孔——**断点回归**：奖学金发给模拟考 600 分以上的学生，600.1 分与 599.9 分的两位同学实力只差毫厘，领没领到奖金却判若云泥——分数线像一台只在天堑附近运转的抽签机，两侧一比就是局部真效应。它的骨架与上面的比值完全同源。

## 4. 分步例题

16 名学员的迷你账本：8 人热情（$U{=}1$）、8 人普通（$U{=}0$），每组各抽 4 人发激活码。行为规则：热情者**无论如何都会用**，普通学员只在被指派时才用；成绩方程 $Y = 2X + 3U$——真实效应 $\beta = 2$，热情自带 3 分底子。

1. **天真对比**：使用者共 12 人（8 名热情者 + 4 名被指派的普通者），$\mathbb{E}[Y\mid X{=}1]=(8\times5+4\times2)/12=4$；不用的恰是 4 名普通学员，均值为 $0$。报表结论："用了能涨 4 分！"；
2. **拆穿**：使用者圈子里三分之二是天生的热情型选手，对照组全是普通人——比的是两种人，不是两种待遇（第 40 课的老熟人）；
3. **上帝视角**：强制人人使用与禁用人人使用，均值分别为 $3.5$ 与 $1.5$，真效应 $= 2$；
4. **第一阶段**：$\mathbb{E}[X\mid Z{=}1]=1$（指派组全员上场），$\mathbb{E}[X\mid Z{=}0]=0.5$（自发参加的一半）——抽签撬动了 $0.5$ 个单位的使用率；
5. **第二阶段**：$\mathbb{E}[Y\mid Z{=}1]=3.5$、$\mathbb{E}[Y\mid Z{=}0]=2.5$，分子为 $1$；
6. **Wald 合龙**：$1 \div 0.5 = 2$——从头到尾没查一眼热情字段，真效应分毫不差地回来了。

### 实验 2（python）：钢钎撬一下，指针稳不稳

```python title="把热情加成拖到多大都撼不动 Wald"
# sliders: boost=3 [0:6:1]
rows = []
for repeat in range(4):              # 每种背景组合配四名学员，凑齐 16 人
    for u in (0, 1):                 # 学习热情：台账之外的隐藏列
        for z in (0, 1):             # 是否被抽中发放激活码
            x = u or z               # 行为规则：热情者自用，其余被指派才用
            y = 2 * x + boost * u    # boost：热情的成绩加成，滑块可调
            rows.append([u, z, x, y])

def gmean(want, key, kval):          # 按 key 列的取值筛选行，对 want 列求平均
    total, hits = 0, 0
    for r in rows:
        if r[key] == kval:
            total += r[want]
            hits += 1
    return total / hits              # hits 不可能为零：每种组合都有人在场

naive = gmean(3, 2, 1) - gmean(3, 2, 0)      # 天真口径：直接横跳比较两组
lever_x = gmean(2, 1, 1) - gmean(2, 1, 0)    # 第一阶段：指派撬动的使用率增量
lever_y = gmean(3, 1, 1) - gmean(3, 1, 0)    # 第二阶段的原料：指派抬升的成绩

print("天真对比:", naive)
print("Wald:", lever_y / lever_x)
```

把 `boost` 从 0 拖到 6：天真对比一路飙到 6 分，Wald 却钉死在 `2.0`——热情冒充得越凶，钢钎越显得可靠。（第二阶段的完整装配在练习 1 里等你亲手完成。）

### 快问快答

```quiz
研究"咖啡摄入对心脏的影响"，下面哪个最适合当工具变量？
- 受试者自我报告的每日咖啡杯数
- 所在城市咖啡馆门店密度，它只通过影响购买便利性改变饮用量 [*]
- 受试者是否自认容易失眠
? 门店密度与心脏结果之间很难找到绕过"喝了多少"的暗道，也不太会与遗传易感性同进退；杯数与失眠自评都是"个人体质的自白"，和结果背后那些说不清的共同原因纠缠不清。
```

:::warning[常见误区]

**误区一**：你以为"弱一点的工具也能凑合"。第一阶段力气太小（分母趋近零）时，分子会被同步放大着除出去，估计值剧烈摆动甚至冲出合理范围。挑工具先掂量撬动力气。

**误区二**：你以为"只要和 X 相关就能当工具"。相关性只是入场券，生死线是排他性——工具到 Y 不许有第二条暗道。若城市密度还能通过"工作压力"影响心脏，整台仪器当场报废。

**误区三**：你以为 Wald 算的是所有人的效应。它的读数对象只是**被工具撬动的那批人**（统计学叫依从者的局部效应）；指派改变不了行为的老顽固不在秤盘里。外推全员之前，先想想这两类人有多像。

:::

## 6. 练习

**练习 1**：初始代码的第一阶段少装了一个零件，请修正；预期输出依次为 `4.0`、`0.5`、`2.0`：

```exercise
# @title: 练习：补全 Wald 分母
# @check: 4.0
# @check: 0.5
# @check: 2.0
# @hint: 分母应是【X】在 Z 两组的条件均值之差——指派到底把使用率顶高了多少
rows = []
for repeat in range(4):
    for u in (0, 1):
        for z in (0, 1):
            x = u or z
            y = 2 * x + 3 * u
            rows.append([u, z, x, y])

def picked(kcol, kval, vcol):        # 挑出 kcol 列等于 kval 的行，收集它们的 vcol 值
    got = []
    for r in rows:
        if r[kcol] == kval:
            got.append(r[vcol])
    return got

def avg(xs):
    return sum(xs) / len(xs)         # sum：连加求和；len：数个数

naive = avg(picked(2, 1, 3)) - avg(picked(2, 0, 3))
num = avg(picked(1, 1, 3)) - avg(picked(1, 0, 3))
denom = avg(picked(1, 1, 2))            # ← 有 bug：只取了指派组的使用率，忘了减去未指派组

print(round(naive, 1))
print(round(denom, 1))
print(round(num / denom, 1))
```

**练习 2**：假如激活码印得太精美，拿到的人光看着心情就好、连上自习都更专注——这时 Wald 还可信吗？坏在哪一条？修复的思路是什么？

<details>
<summary>点开查看逐步解答</summary>

不可信了。"好看 → 心情好 → 成绩高"是一条绕过 $X$ 的暗道，**排他性**被击穿；此时 Wald 读出的不再只是使用的回报，还掺着士气的加成。诊断思路沿第一章的两问倒推：既然相关性毫无问题，嫌疑犯只能是第二条；补救要么找到不激起情绪的发放方式（换工具），要么把士气做成可观测变量并入模型（那已回到第 80 课的后门阵地）。可见两套技术并非竞争关系，而是轮番上阵：**谁的假设在你的场景里更可信，就请谁出场**。
</details>

## 7. 选读：门槛上的天然实验室

<details>
<summary>选读 · 断点回归的三件法宝</summary>

拿分数线当抽签机时，有三件事值得记住。其一，效应只属于**断点附近的窄带**——离线越远，两侧人群差距越大，可比性随之流失，所以报告结果时要说清"对分数恰在门槛一带的学生"。其二，警惕断点附近的**人为操纵**：考生若能反复补考刷分，600 分处的人数密度会诡异地堆积，天然随机性就在这一点上漏气。其三，除了"过不过线"这根立柱，还可以画出结局对分数的散点图，看曲线在断点是整体**跳跃**还是顺带**拐弯**——两者讲的故事不同。经济学里的助学奖金、医保起付线、酒驾吊扣阈值……无数政策评估靠这一招在纸面上完成了不可能的实验。

</details>
