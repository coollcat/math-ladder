# 中介分析：直接效应与间接效应

## 1. 从一个场景开始

上一课的 Wald 估计量给了灯塔学院一个干净的数字：每天使用「错题重算法」软件，对被它撬动的学员平均提分 $2$。教务处却不肯收货："我要知道这 2 分**从哪条管道流进来的**——几成是 App 里那三条巧算口诀立竿见影？几成是督促大家多刷了题、熟能生巧？"

这问的不是效应总量，而是效应的**路线图**：刷题量 $M$（台账可查）是登记在册的中转站， $X$ 的部分影响先到站再出发；可"底子 $U$"这种暗流同时在给练习量和考分两头供水。把一笔总账拆成两股，比算出总额难得多——这门收尾的会计课，教你用上一课反事实思维里的平行世界来记账。

## 2. 直觉解释

想象影响是一条灌溉渠系统，闸门开在 $X$：

- **干渠直灌**（直接效应）：关掉一切中转池，水照样从主干道到达田里——App 的口诀不靠加练也涨分；
- **支渠绕行**（间接效应）：水先进练习量 $M$ 这座蓄水池，攒够了再浇出去——多刷的题变成熟练度。

天真的拆账手法是"把蓄水池的水位按住不动，看剩下的效果"。听起来聪明，实则有个致命暗礁：**水位本身是河流的一部分**。按住水位之后，留在每个水池格子里的农户构成全变了（爱蓄水的和天生水旺的被拆散到不同格），比较对象已经悄悄换人。正确姿势来自第 40 课：不是去按住真实的河，而是在平行世界里**搬运假想中的水**。

## 3. 正式定义

沿用潜在结果记号，让每名学员持有四种假想结局：

| 符号 | 含义 |
| --- | --- |
| $M_i(x)$ | 强制处理状态为 $x$ 时个体 $i$ 的练习量 |
| $Y_i(x, m)$ | 处理状态 $x$ 且练习量被安置在 $m$ 时的成绩 |

以"冻结在不参加水平 $M_i(0)$"为基准的两笔分账：

$$\text{NDE} = \mathbb{E}\big[Y(1, M(0)) - Y(0, M(0))\big]$$

$$\text{NIE} = \mathbb{E}\big[Y(1, M(1)) - Y(1, M(0))\big]$$

NDE 叫**自然直接效应**——全体学员的中转站都冻在无人干预的水位上、只扳动主阀门的收获；NIE 叫**自然间接效应**——主阀门开足后、单靠中转站水位上涨送来的增量。望远镜求和逐个体恒成立：

$$Y(1,M(1)) - Y(0,M(0)) = \big[Y(1,M(0))-Y(0,M(0))\big] + \big[Y(1,M(1))-Y(1,M(0))\big]$$

于是总有 $\text{TE} = \text{NDE} + \text{NIE}$：这笔总账在个体层面天然闭合，不存在下落不明的零头。

## 4. 分步例题

八名学员的小班：一半底子薄（$U{=}0$）、一半底子厚（$U{=}1$）。结构方程只有两条——$M := 2X + U$（打卡计划每日加练 2 组）与 $Y := M + X + 2U$（每练一组值 1 分，口诀白赚 1 分，好底子另带 2 分手感）。

1. **铺卡片**：以厚底子学员为例填四张卡——$M(0)=1,\ M(1)=3$；$Y(0,M(0))=3$，$Y(1,M(0))=4$，$Y(1,M(1))=6$；
2. **望远镜核验**：$6-3 = (4-3) + (6-4)$，右端恰好是"只扳阀门"$+1$ 与"只放水库"$+2$；
3. **清点全班**：薄底子四人数字同构地给出 $1$ 与 $2$，平均后 NDE $=1$、NIE $=2$、TE $=3$；
4. **读账**：巧算口诀立竿见影占三分之一；大头 $2$ 分走的是"每日加练两组 $\times$ 每组一分"的支渠；
5. **天真控制法翻车现场**：改用观察数据按练习量分层，四个水层 $\left\lbrace 0,1,2,3\right\rbrace$ 每层里只剩一种人（不打卡的都在低水位、打卡的全在高水位），任何一层里都找不到另一组可比——把中介当协变量控制，人群当场碎成没有对照组的孤岛；
6. **病根回放**：联系第 80 课的正性条款——条件化的格子缺人手，公式就断粮。中介分析偏偏必然要条件化中转站，所以正面硬控注定水土不服，得请平行世界代劳；
7. **好消息**：本例的处理其实是抽签发放（第 85 课的那门半途而废实验），总量口径无须修正就是真 TE $=3$；要补的只是"分账"这一步，而它已经由四张卡片完成。

### 实验 2（python）：拖动加练力度，看账目如何重排

```python title="冻结中转站的平行世界记账法"
# sliders: a=2 [0:4:1]
nde_sum, nie_sum, te_sum = 0, 0, 0   # 三本流水账分别累计三类差值
people = 0                           # 人数计数器
for repeat in range(4):              # 两类底子各配四名学员
    for u in (0, 1):                 # 学习底子：台账之外的隐藏列
        m0 = u                       # M(X=0)：无人强制时的日常练习量
        m1 = a + u                   # M(X=1)：计划每日加练 a 组
        y00 = m0 + 0 + 2 * u         # Y(X=0, 冻结 M 于无干预水平)
        y10 = m0 + 1 + 2 * u         # Y(X=1, 仍冻结) → 直接管道独奏
        y11 = m1 + 1 + 2 * u         # Y(X=1, 水库随干预上涨)
        nde_sum += y10 - y00         # 只扳主阀门：自然直接效应
        nie_sum += y11 - y10         # 只松绑水库：自然间接效应
        te_sum += y11 - y00          # 阀门水库一起动：总效应
        people += 1

count = float(people)
print("直接效应:", nde_sum / count)
print("间接效应:", nie_sum / count)
print("总效应:", te_sum / count)
```

默认 `a=2` 时三行输出 `1.0`、`2.0`、`3.0`，与例题的分账表完全合龙。把加练力度拖到 0：总账塌回 1 分全是口诀贡献；拖到 4：支渠吸走过半水量。不论怎么拖，三根柱永远严丝合缝地相加——这就是分账而不是三个孤立统计量的含义。

### 快问快答

```quiz
产品经理说："推送提升了次晨打开率，打开率又拉高了周留存。我把打开率放进回归一起控制，就能看到推送对留存的净效果了。"这句话错在哪？
- 回归变量太多会撑爆内存
- 打开率身后还有活跃度这类隐藏因素在两头供水，按住它会让格子里的用户构成失衡，"净效果"混进了筛选偏差 [*]
- 应该连推送也从回归里删掉才有净效果
? 与本章的例题同一个病灶：中转站从来不是一个安静的走廊，它的每一段水位背后都有故事。想要干净的分账，要么有平行世界的模型，要么老老实实承认只报总量。
```

:::warning[常见误区]

**误区一**：你以为"算完总效应再控制住 M"就叫拆账。控制一个真实的中介会重塑每层的人群构成（还可能撞上孤岛格子）；分账的正确动作是在**假想世界里替换中介取值**，动的是模型里的滑杆，不是样本里的筛子。

**误区二**：你以为 TE $=$ NDE $+$ NIE 是可以随便引用的万能定律。恒等式确实逐个体成立，但前提是四张潜在结局卡片各自有意义；若干预效应会把人打出原世界（例如政策引发迁移），同一批人的"另一条时间线"不复存在，账就对不上。

**误区三**：你以为"每练一组值 1 分乘上加练组数"这条乘积捷径放之四海。$\text{NIE} = a\times b$ 式的系数相乘只在两个前提下安全：$M$ 对 $Y$ 的增益不随 $X$ 改变（无交互），且 $M$ 身后没有未被登记的暗流。例题故意配平了两条；现实中失守任何一条，乘出来的是掺假的账。

:::

## 6. 练习

**练习 1**：初始代码把"冻结"那行写松了，请修正；预期输出依次为 `1.0`、`2.0`、`3.0`：

```exercise
# @title: 练习：亲手分完这笔账
# @check: 1.0
# @check: 2.0
# @check: 3.0
# @hint: 直接效应那格里水库必须冻死在无人干预的水平 m0；一松绑就直接跳进间接效应的账了
roster = []                          # 学员名单：每人一行 [学习底子]
for repeat in range(4):
    for u in (0, 1):
        roster.append([u])

totals = {"direct": 0.0, "indirect": 0.0, "total": 0.0}   # 字典当三本账本用
for p in roster:
    u = p[0]
    m0 = u                           # 不参加计划的日常练习量
    m1 = 2 + u                       # 参加后的练习量（加练 2 组）
    y00 = m0 + 0 + 2 * u             # Y(X=0, M 冻结)
    y10 = m1 + 1 + 2 * u             # ← 有 bug：冻结字样写在了注释里，代码却用了涨水后的 m1
    y11 = m1 + 1 + 2 * u             # Y(X=1, M 随干预上涨)
    totals["direct"] += y10 - y00
    totals["indirect"] += y11 - y10
    totals["total"] += y11 - y00

n = len(roster)                      # 名单人数：len 数出列表长度
print(round(totals["direct"] / n, 1))
print(round(totals["indirect"] / n, 1))
print(round(totals["total"] / n, 1))
```

**练习 2**：全部四种潜在结局其实还有第四张卡 $Y(0, M(1))$——主阀门关着、水库却满着的世界。请你用它从另一头重新分账（总效应写成 NDE$'$ 加 NIE$'$），并解释为什么在本课的无交互方程里两种分法给出的数字一模一样。

<details>
<summary>点开查看逐步解答</summary>

第四张卡：$Y(0, M(1)) = (2+u) + 0 + 2u = 2 + 3u$。换基准的分账：NIE$' = Y(0,M(1)) - Y(0,M(0)) = 2$，NDE$' = Y(1,M(1)) - Y(0,M(1)) = 1$，合计仍是 $3$。两套答案吻合的根本原因是方程里没有交互项——练的每一组值多少钱、口诀直授值多少分，都不随另一个变量的状态而变。此时无论先冻谁、后放谁，两条管道的运费各自独立结算；一旦引入交互（比如口诀只对练过题的人生效），两侧的冻法就会给出不同的切分，你必须选一边作为报告口径并说明理由。
</details>

## 7. 选读：从前门到中介分析

<details>
<summary>选读 · 两代方法的家谱</summary>

回头看第 80 课的前门准则，它其实就是中介分析的极端特例：$X$ 到 $Y$ **不许存在**直通暗线，全部影响被迫挤过 $M$ 那座独木桥，所以桥上的推力 $\times$ 桥下的落点就能拼出整个 $do$ 分布。本课放宽了前提——两条血管并存，直接那条从此遮遮掩掩，非用"冻结假想中介"的反事实手术不可见。这套思路九十年代由 Pearl 与 Robins 各自成形，如今称为自然效应；再往后发展出的边际结构模型、干预中介（controlled direct effect）等分支处理的都是 $M$ 身后有隐藏混杂的疑难场景。家谱理顺了你会发现：识别的三板斧——找后门、借前门、拆水管——原来是同一台戏的三幕。
</details>
