# 先验与后验：让观点可以被数据更新

## 1. 从一个场景开始

两位球迷看到同一条新闻："某球员今晚训练中投进 90% 的罚球"。甲一直认为这球员是铁神射手，看完更信了；乙本来觉得他徒有虚名，看完只稍微动摇。**同样的证据，不同的起点，得出不同程度的更新。**

频率派统计（上一章）只处理"证据怎么说"；贝叶斯统计的招牌动作是承认每个人都有出发点的判断（先验），然后给出一条精确的规则，说明证据应该如何修正它——这条规则就是贝叶斯公式。

## 2. 直觉解释

把"观点"写成对各个假设下注的概率，比如"这枚硬币有偏"你押 10%。来了新证据后怎么办？三步舞：

1. **先验**：看证据之前，各假设的分额——"公平"0.9、"有偏"0.1；
2. **似然**：每个假设下，眼前这批数据出现的可能性有多大——若硬币公平，连出 3 个正面概率 $0.5^3$；若有偏（偏到 0.8），概率 $0.8^3$。有偏假设下这数据更"不奇怪"；
3. **后验**：按"谁的解释力强就把分额多分给谁"重新瓜分——新的押注比例就是更新后的观点。

一句话总结：**后验 ∝ 先验 × 似然**。所有贝叶斯方法——从垃圾邮件过滤器到宇宙学参数估计——都是这一句在不同舞台上的重演。

## 3. 正式定义

设 $H$ 是假设、$D$ 是数据。**贝叶斯公式**：

$$P(H \mid D)=\frac{P(D \mid H)\,P(H)}{P(D)}=\frac{P(D \mid H)\,P(H)}{P(D \mid H)P(H)+P(D \mid H^{c})P(H^{c})}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $P(H)$ | 先验概率 | 见到数据前对假设的押注 |
| $P(D\mid H)$ | 似然 | 假设成立时，数据出现的可能性 |
| $P(H\mid D)$ | 后验概率 | 见到数据后更新的押注 |
| $P(D)$ | 证据/归一化常数 | 保证新押注加起来等于 1 |

实战里更好用的是**赔率形式**（赌马的人说的"赔率"就是它）：

$$\underbrace{\frac{P(H\mid D)}{P(H^{c}\mid D)}}_{\text{后验赔率}}=\underbrace{\frac{P(H)}{P(H^{c})}}_{\text{先验赔率}}\times\underbrace{\frac{P(D\mid H)}{P(D\mid H^{c})}}_{\text{似然比}}$$

乘法代替除法，归一化自动消失：**后验赔率 = 先验赔率 × 似然比**。证据每来一批就乘一次，观点滚动前进。

## 4. 分步例题

**例**：某病在人群中的患病率是 1%。检测灵敏度 90%（患病者九成呈阳性），假阳性率 8%（健康者 8% 被误报）。某人检出阳性，他真患病的概率是多少？

1. 先验赔率：患病 : 健康 $=0.01 : 0.99=1 : 99$；
2. 似然比：阳性结果在两种世界下的概率之比 $=0.90 : 0.08=11.25$；
3. 后验赔率：先验赔率乘以似然比，得 $11.25 : 99$。等价地说，$99$ 份健康被压成约 $8.8$ 份；
4. 换回概率：$11.25/(11.25+99)=11.25/110.25\approx 0.102$。

结论惊人：阳性之后真患病的概率也只有约 10%！直觉解释：健康人基数太大（99 倍），哪怕误报率只有 8%，假阳性的绝对人数也远超真阳性。**忽略先验直接采信检测，是医学史上反复付出的学费。**

### 实验 2（python）：用自然频率把公式走一遍

不用任何公式，纯数人头重做例题：

```python title="十万人里数一数：阳性的人到底是谁"
prevalence = 100000       # 十万人
sick = prevalence // 100  # 患病率 1%：整除取 1000 人
healthy = prevalence - sick

true_pos = sick * 9 // 10       # 灵敏度 90%：患病且检出阳性
false_pos = healthy * 8 // 100  # 假阳性率 8%：健康却误报阳性

total_pos = true_pos + false_pos
print(f"阳性总人数 {total_pos}")
print(f"其中真患病 {true_pos} 人")
print(f"占比约 {true_pos * 100 // total_pos}%")
```

十万人、8820 位阳性、其中约 900 位真患病——公式给出的 10% 在这里变成了看得见摸得着的人头。这种"自然频率"算法是人类大脑最舒服的贝叶斯姿势。

### 快问快答

```quiz
甲和乙对同一批数据算出了不同的后验概率。最可能的原因是？
- 至少有一人数学错了
- 他们的先验不同 [*]
- 贝叶斯公式对不同人给出不同答案
? 公式人人相同，但公式需要输入先验：起点不同，终点自然不同。这不是缺陷而是设计——贝叶斯框架诚实地承认「判断依赖出发点」，并把分歧摆在明处。
```

:::warning[常见误区]

**误区一**："你以为先验越客观越好、最好没有先验。" 不选边站也是一种选边（均匀押注）。真正的问题不是"要不要先验"，而是"我的先验是否合理、是否会被足够的数据纠正"。下一课你会看到，数据够多时先验的影响会淡出。

**误区二**："你以为似然 P(D|H) 就是'假设为真的概率'。" 似然描述的是"假设之下数据的产出率"，不是假设的分数。两者方向相反：前者以假设为条件推数据，后者以数据为条件反推假设。

**误区三**："你以为一次强证据就该彻底翻案。" 更新是按似然比逐批相乘的：一次 11 倍的证据能把 1:99 推到约 1:8.8，但离定论还远。贝叶斯的美德是连续、渐进，不搞一次性审判。

:::

## 6. 练习

**练习 1**：你对"朋友推荐的餐厅靠谱"的先验赔率是 1 比 9（不太信）。朋友先后两次独立安利（每次的似然比为 3）。更新后的后验概率是多少？下面的代码能跑但答案不对——改到通过：

```exercise
# @title: 练习：赔率形式的贝叶斯更新
# @check: 0.5
# @hint: 独立证据的似然比相乘：两次就是 3 的平方；总似然比乘给分子，分母仍是原反对份数，最后归一化
odds_for, odds_against = 1, 9    # 先验赔率 1:9
lr_each = 3                      # 每条证据的似然比

num = odds_for                   # ← 问题在这：分子没乘任何证据
den = odds_against               # ← 分母同样原封未动
p = num / (num + den)
print(round(p, 1))
```

**练习 2**：例题中如果把检测换成灵敏度相同、但假阳性率降到 1% 的新方法，阳性后的真患病概率变为多少？

<details>
<summary>点开查看逐步解答</summary>

```python
odds_for, odds_against = 1, 9
total_lr = 3 ** 2
p = odds_for * total_lr / (odds_for * total_lr + odds_against)
print(round(p, 1))
```

似然比升到 $0.90/0.01=90$，后验赔率 $=1\times 90 : 99\times 1=90:99$，概率 $90/189\approx 47.6\%$。假阳性率从 8% 压到 1%（特异性 92%→99%），阳性含金量从 10% 跃升至近一半——筛查手段的价值主要由特异性决定，这正是罕见病筛查反复强调特异性的原因。

</details>

**练习 3**：有人说"贝叶斯更新会陷入死循环：用什么先验全凭心情"。结合本课实验 1 的曲线反驳或限定这个批评。

<details>
<summary>点开查看逐步解答</summary>

部分成立的部分：先验确实影响短期结论，尤其数据稀少时（曲线两端）。失效的部分：只要先验不给某些假设塞死 0 概率，持续到来的数据就会通过一次次似然比相乘把不同先验的后验拉到一起——先验的话语权随证据积累而稀释。所以正确的回应不是"取消先验"，而是"诚实声明先验 + 让数据说话"。第 30 课会用模拟亲眼验证这种收敛。

</details>

## 7. 选读：为什么分母长那样

<details>
<summary>选读 · 全概率公式的登场</summary>

分母 $P(D)=P(D\mid H)P(H)+P(D\mid H^c)P(H^c)$ 是第 36 章预备讲的全概率公式：数据可能从两种世界产生，按各自世界的权重加权求和。它的作用纯粹是记账——把"先验 × 似然"得到的相对分数归一化成合法概率。赔率形式之所以清爽，就是因为这一步被约分约掉了：比较两个假设时根本不需要知道数据的绝对概率，只需要它在两种世界下的相对产出率。

</details>
