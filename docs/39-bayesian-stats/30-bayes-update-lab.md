# 贝叶斯更新实验室：序列、预测与共识

## 1. 从一个场景开始

垃圾邮件过滤器每收到一封新邮件，都要在毫秒之内回答两个问题：这封邮件像不像垃圾？以及——刚才那批邮件教会我的东西，怎么不推倒重来地并进旧知识里？

人工重算"从头再来"当然可以，但既慢又丑。贝叶斯框架给出优雅得多的答案：**后验就是下一轮的先验**。知识以分布的形式滚动前进，新数据只负责推它一把。这一课把这套机制开进实验室。

## 2. 直觉解释

三个问题定义本课：

**问题一：证据一条条来和一锅端进来，结论一样吗？** 一样。更新公式是连乘，乘法交换律保证顺序与分组都不影响终点——先看 3 封再看 97 封，与一次看完 100 封，后验分毫不差。

**问题二：看完数据，预测下一次试验的概率是多少？** 直觉说用后验均值 $a/(a+b)$。对 Beta-Bernoulli 这恰好是对的：预测下一次成功的概率就是 $\dfrac{a}{a+b}$（伪次数加真次数的频率）。

**问题三：观点不同的人最终会达成一致吗？** 只要没人给假设塞死 0 概率，数据足够多时所有人的后验都会挤向真值附近——先验是船锚，数据是洋流，洋流够久，锚也拦不住。

## 3. 正式定义

**序列更新**：数据分批到达 $D_1, D_2, \ldots$，则

$$P(\theta \mid D_1, D_2)=\frac{P(D_2 \mid \theta)\,P(\theta \mid D_1)}{P(D_2)}$$

即：第一批数据的**后验**充当第二批的**先验**。

**后验预测分布**：看过数据后，第 $n{+}1$ 次试验的成功概率为

$$P(X_{n+1}=1 \mid D)=\frac{a+k}{a+b+n}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $D_1, D_2$ | 数据批次 | 分批到来的观测 |
| $(a+k,\ b+n-k)$ | 当前后验参数 | 虚拟计数加真实计数的滚动总和 |
| $\frac{a+k}{a+b+n}$ | 预测概率 | 下一次成功的押注（拉普拉斯继承法则的现代版） |

注意预测公式的两个极端：毫无数据时（$k=n=0$）退化为先验均值；数据海量时退化为裸频率——先验只在过渡地带扶一把。

## 4. 分步例题

**例**：广告过滤系统对某渠道的垃圾邮件率先验取 Beta(2, 2)：第一周抽检 6 封，5 封正常 1 封垃圾；第二周抽检 10 封，3 封正常 7 封垃圾。（把"正常"记作成功、按比例建模即可。）

1. 第一周结束：$a=2+5=7$，$b=2+1=3$，后验均值 $7/10=0.7$，预测下一封邮件正常的概率也是 0.7；
2. 第二周结束（接着加）：$a=7+3=10$，$b=3+7=10$；
3. 验证顺序无关：两周一锅端共 16 封、8 封正常，直接算 $a=2+8=10$，$b=2+8=10$——完全一致 ✓；
4. 当前预测概率 $10/20=0.5$：第一周的干净被第二周的垃圾潮大幅回调，估计值在证据间震荡收敛。

## 5. 动手实验

### 实验 1（python）：顺序无关性实测

同一批数据，两种喂法，输出必须逐位相同：

```python title="分批更新 vs 一锅端：终局对照"
import random                     # 随机库

stream = []
for i in range(50):
    outcome = 1 if random.random() < 0.65 else 0   # 真实成功率 0.65 的数据流
    stream.append(outcome)

def update(a, b, batch):          # 自定义函数：按一批数据做共轭更新，返回新参数
    for outcome in batch:
        if outcome == 1:
            a = a + 1             # 成功计入 a
        else:
            b = b + 1             # 失败计入 b
    return a, b                   # 把更新后的参数交还调用方

# 喂法一：一条一条来
a, b = 2, 2
for outcome in stream:
    a, b = update(a, b, [outcome])
print(f"逐条更新终点: a={a}, b={b}")

# 喂法二：切成三批大口吞
a2, b2 = 2, 2
chunks = [stream[:20], stream[20:35], stream[35:]]   # 切成 20+15+15 三批
for batch in chunks:
    a2, b2 = update(a2, b2, batch)
print(f"分批更新终点: a={a2}, b={b2}")
```

两行输出完全相同——交换律不是近似，是精确恒等。工程上这意味着流式系统不必囤积历史数据：一个 $(a,b)$ 记录本就装下了全部记忆。

### 实验 2（python）：小样本下的预测——拉普拉斯继承法则

太阳升起了多少次，就该押多大的注赌它明天继续升起？用无信息先验 Beta(1,1) 连看 6 次成功：

```python title="6 战 6 捷之后，下一次的成功概率"
import matplotlib.pyplot as plt   # 画图库

k = 6                             # 观察到的成功次数
n = 6                             # 总次数

raw_freq = k / n                  # 裸频率：6/6 = 1，显得过度自信
laplace = (1 + k) / (1 + 1 + n)   # 继承法则：(伪成功 + k) / (总伪次数 + n)

ns = list(range(0, 31))           # 试验数从 0 到 30，固定全胜
preds = []
for total in ns:
    preds.append((1 + total) / (2 + total))   # 全胜记录下的预测概率曲线

plt.plot(ns, preds)
plt.axhline(1.0, color="gray", linestyle="--")   # 裸频率会撞上的天花板
plt.xlabel("连续成功次数")
plt.ylabel("下一次成功的预测概率")
print(round(laplace, 4))
```

预测值 0.875，而不是裸频率的 100%。曲线随连胜逼近天花板却永不触及——"从未失败"不等于"不会失败"，这正是贝叶斯对黑天鹅的天然防备。

### 快问快答

```quiz
两位分析师先验悬殊（Beta(1,1) 对 Beta(60,40)）。要让他们对转化率的判断差距缩到 5 个百分点以内，最有效的手段是？
- 请他们重新商量先验
- 继续积累数据 [*]
- 各自调大自己的先验强度
? 共同数据通过一次次似然比相乘稀释先验分歧：数据越多，起点越不重要。谈判只能治标，数据才是共识机器。
```

:::warning[常见误区]

**误区一**："你以为'顺序无关'等于'顺序不重要'。" 终点相同，但中途轨迹大不相同：先看到 5 连胜还是先看到 5 连败，过程中的预测值天差地别。实时系统关心轨迹，报告才只关心终点。

**误区二**："你以为后验预测就是后验均值那么简单。" 对 Beta-Bernoulli 恰好如此，但一般情形下预测要对整个后验求平均，形状复杂得多。"均值即预测"是共轭结构送的特例，不是普遍定律。

**误区三**："你以为先验给某假设赋了 0 也无妨。" 概率 0 是死刑且不可上诉：无论后续多少相反证据，似然比乘多大都翻不了案（0 乘任何数仍是 0）。给可能性留活路，是贝叶斯使用者的基本修养。

:::

## 6. 练习

**练习 1**：无信息先验 Beta(1,1) 下连续观察到 6 次成功。下面的代码能跑但预测过度自信——改到通过：

```exercise
# @title: 练习：拉普拉斯继承法则
# @check: 0.875
# @hint: 别用裸频率 k/n；预测概率 = (a + k) / (a + b + n)，无信息先验是 a = b = 1
a_prior, b_prior = 1, 1   # 无信息先验
k, n = 6, 6               # 六战六捷

prediction = k / n        # ← 裸频率：把「还没见过失败」当成了「不可能失败」
print(prediction)
```

**练习 2**：过滤器当前后验是 Beta(12, 8)。来了 5 封新邮件：4 正常 1 垃圾（按"垃圾邮件率"建模）。写出新后验并预测下一封是垃圾的概率。

<details>
<summary>点开查看逐步解答</summary>

```python
a_prior, b_prior, k, n = 1, 1, 6, 6
prediction = (a_prior + k) / (a_prior + b_prior + n)
print(prediction)
```

$a=12+1=13$，$b=8+4=12$，新后验 Beta(13, 12)，预测概率 $13/25=0.52$。注意只需在原参数上做加减法——历史 20 封的记忆全部浓缩在 (12, 8) 两个数字里，无需回看原始邮件。这就是流式贝叶斯的存储优势。

</details>

**练习 3**：实验 2 里若先验改成 Beta(10, 1)（强烈乐观），6 连胜后的预测概率变成多少？先验话语权如何体现？

<details>
<summary>点开查看逐步解答</summary>

$(10+6)/(11+6)=16/17\approx 0.941$，比无信息先验的 0.875 高出近 7 个百分点——同样的 6 条数据，乐观者被推得更靠右。数据少时先验定基调；等 $n$ 涨到几百，两种先验的差距会缩到千分位以下（可用实验 1 的代码自行验证）。

</details>

## 7. 选读：预测为什么恰好是后验均值

<details>
<summary>选读 · 一步积分的魔法</summary>

预测概率的定义是对所有可能的 $\theta$ 加权平均"该 $\theta$ 下的成功率"：

$$P(X_{new}=1 \mid D)=\int_0^1 \theta \cdot f(\theta \mid D)\,d\theta$$

这个积分恰恰就是后验分布的均值定义本身，所以答案直接抄后验均值 $\frac{a+k}{a+b+n}$。对 Beta 密度乘以 $\theta$ 再积分能这么干脆，是因为幂函数积分只是指数加一——又是指数族的红利。非共轭模型里这一步往往积不动，于是才有下一卷 MCMC 用随机采样硬算积分的故事。

</details>
