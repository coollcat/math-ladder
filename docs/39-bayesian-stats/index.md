## 实战挑战 · 阳性报告单上的贝叶斯：钼靶筛查疑云

真实背景：1982 年，医生兼研究员 David Eddy 记录了一道让美国医生集体翻车的题——乳腺癌筛查患病率 1%、灵敏度 80%、假阳性率 9.6%，问阳性者真患病的概率。正确答案约 7.7%，但 **100 位医生里约 95 位答了"75%"**（出处：Eddy, 1982，转引自 Association for Psychological Science 的综述文章）。认知心理学家 Gigerenzer 随后发现解药出奇简单：把条件概率翻译成「自然频率」数人头即可。

下面用 Gigerenzer 常用的那组数字做一遍（情境为经典题型的改编）：某地 **0.8%** 的女性患乳腺癌；患病者 **90%** 钼靶呈阳性（灵敏度）；无病者仍有 **7%** 被误报阳性。现在追踪 **1000 名**参检女性的人头：

**(a)** 其中真正患病的有多少人？第一问已示范：

```exercise
# @title: 实战挑战：用自然频率破解阳性惊恐
# @check: 8
# @check: 7
# @check: 69
# @check: 76
# @check: 10
# @hint: (b) 灵敏度 90% 就是患者里九成被检出，整数除法取整即可；(c) 假阳性只发生在没病的那 992 人里；(e) 用整除估算「几分之一」
sick = 1000 * 8 // 1000        # (a) 患病人数 = 1000 × 8/1000（已示范）
healthy = 1000 - sick          # 没病的人数

print(sick)                    # (a)
print()                        # (b) 患病且检出阳性的人数（按 90% 取整）
print()                        # (c) 无病却误报阳性的人数（按 7% 取整）
print()                        # (d) 阳性报告总数 = (b) + (c)
print()                        # (e) 用整除估算：大约每几位阳性者中才有 1 位真患者？
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** $1000\times 0.008=8$ 人。

**(b)** 灵敏度 90%：$8\times 0.9=7.2$，自然频率法按人头取整记 **7** 人（Gigerenzer 原书同款处理）。

**(c)** 无病的 992 人误报率 7%：$992\times 0.07=69.44$，取整 **69** 人。

**(d)** 阳性总数 $7+69=76$ 人——其中真患者只有 7 位。

**(e)** $76 \div 7\approx 10.9$，整除取整得 **10**——大约每十位阳性者里才有 1 位真患者。阳性报告的含金量远低于直觉，因为健康基数（992）是患者基数（8）的一百多倍，小误报率乘上大分母照样制造人山人海的假阳性。

贝叶斯公式版核对：后验 $=\frac{0.008\times 0.9}{0.008\times 0.9+0.992\times 0.07}=\frac{0.0072}{0.0766}\approx 9.4\%$ ✓ 与数人头一致。Eddy 的医生们之所以答 75%，是把 80%/90% 的灵敏度错当成了"阳性的可信度"——方向恰好搞反，这正是第 10 课误区二的临床级后果。

```python
posterior = 0.008 * 0.9 / (0.008 * 0.9 + 0.992 * 0.07)
posterior                            # 约 0.094；打印核对可用 round(posterior*100, 1)
```

</details>

```quiz
医生们高估阳性可信度的最主要原因是？
- 他们数学不好
- 忽略了基础比率：健康人群基数太大，少量误报也能堆出海量假阳性 [*]
- 钼靶机器精度太差
? 灵敏度回答的是「患者中多少比例呈阳性」，而医生要的是反方向——「阳性中多少比例是患者」。不带上患病率这个基础比率，两个问题根本不是一回事。
```

## 实战挑战 · 贝叶斯别忘了除以全概率

贝叶斯公式：$P(病|阳性)=\frac{P(阳性|病)P(病)}{P(阳性)}$，分母是**全概率**。某病先验 1%、灵敏度 99%、健康人假阳率 5%，问检测阳性时真患病的概率。下面这题漏了分母，修到输出 `0.1667`：

```exercise
# @title: 实战挑战：贝叶斯别忘了除以全概率
# @check: 0.1667
# @hint: 分母 P(阳性) = 灵敏度×先验 + 假阳率×(1−先验)，是两路人马的总和。
prior = 0.01          # P(病)
sens = 0.99           # P(阳性 | 病)
fpr = 0.05            # P(阳性 | 健康)

p_pos = sens * prior + fpr * (1 - prior)   # 全概率：真阳 + 假阳
post = sens * prior                       # ← 问题在这：漏了除以 p_pos
print(round(post, 4))
```

<details>
<summary>点开查看逐步解答</summary>

后验 = 分子 ÷ 全概率：

```python
post = sens * prior / p_pos   # 0.0099 / 0.0594
print(round(post, 4))         # 0.1667
```

改完：$P(阳性) = 0.99\times0.01 + 0.05\times0.99 = 0.0594$，后验 $= \frac{0.0099}{0.0594} = 0.1667$。初始代码只算了分子 $0.0099$，等于把"条件概率"当成了"后验"。这个例子是贝叶斯的经典反直觉现场：即便检测 99% 灵敏，阳性后真患病也只有约 17%——因为先验太低、假阳又不少。分母的全概率，正是把这两路人马都算进来的关键。

</details>
