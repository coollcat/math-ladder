# 正态均值与方差的贝叶斯推断

## 1. 从一个场景开始

果汁厂的灌装线上贴着一张工艺档案：「每瓶维生素 C 含量约 60 毫克」。这是十年陈酿的经验——但它也只是经验，是一条以 60 为中心、宽度有限的信念曲线。今天化验室送来 3 瓶抽查结果，平均 64 毫克。

真实均值到底该记多少？死守档案还是听化验室的？答案应该是**按嗓门加权表决**：谁的证据更硬，谁分到的票就多。这一课把上一课练好的贝叶斯引擎接上正态分布，推出一个用得最多的闭式结论——**精度加权更新**。

## 2. 直觉解释

先认清场上的两位证人：

- **先验**：一条钟形信念 $N(\mu_0,\tau^2)$——档案认为真实均值在 $\mu_0$ 附近，不完全确定的程度由 $\tau$ 描述；
- **似然**：数据也是一条钟形 $N(\bar{x},\sigma^2/n)$——它主张均值在样本均值 $\bar{x}$ 附近，但说话底气受两头钳制：单瓶噪声越大越含糊，抽得越多越笃定。

两个钟形相乘还是一个钟形（正态家族的自我繁殖），中心落在哪里？就在**两条钟形的重心**处。而重心偏向谁，不由人数决定，由**精度**决定——

> **精度 = 方差的倒数 = 嗓门大小。**

方差小 = 曲线瘦高 = 声音尖利，投票权自然大。这就是全部秘密：贝叶斯更新在此化身为一场按精度加权的表决。

## 3. 正式定义

观测模型：$n$ 个读数来自 $N(\mu, \sigma^2)$，其中单瓶噪声 $\sigma$ 视作已知（仪表规格书或历史质控给出）。配正态先验 $\mu \sim N(\mu_0, \tau^2)$，则后验仍是正态：

$$\frac{1}{\tau_n^2}=\frac{1}{\tau^2}+\frac{n}{\sigma^2}, \qquad \mu_n=\frac{\dfrac{\mu_0}{\tau^2}+\dfrac{n\bar{x}}{\sigma^2}}{\dfrac{1}{\tau^2}+\dfrac{n}{\sigma^2}}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mu$ | 待估参数 | 真实平均含量（关心的只有它） |
| $\sigma^2$ | 观测方差 | 单瓶读数围绕真值的抖动，已知 |
| $\mu_0,\tau^2$ | 先验均值与方差 | 档案经验的中心与不确信程度 |
| $\lambda_0=\dfrac{1}{\tau^2}$ | 先验精度 | 经验这方的嗓门 |
| $\lambda=\dfrac{n}{\sigma^2}$ | 数据精度 | 数据这方的嗓门 |
| $\tau_n^2$ | 后验方差 | $\dfrac{1}{\lambda_0+\lambda}$——两股嗓门叠加 |

两个极端自检公式不失手：毫无数据（$\lambda=0$）时 $\mu_n=\mu_0$；海量数据时先验只剩零头，$\mu_n$ 贴住 $\bar{x}$。「没数据听档案、数据多听车间」，一根公式全管了。样本均值的发言权为何写作 $n/\sigma^2$？因为 $\bar{x}$ 本身围绕真值按 $N(\mu,\sigma^2/n)$ 抖动——样本量在分母上跑步，噪声越大、份数越少，嗓门就越小。

## 4. 分步例题

**例**：换新产线的第一周，档案可信度打折：取先验 $N(60,\ 10^2)$（即 $\tau=10$）。工艺噪声已知 $\sigma=10$。抽查 3 瓶，平均 $\bar{x}=64$。

1. 算两边嗓门：先验精度 $\lambda_0=1/100=0.01$；数据精度 $\lambda=3/100=0.03$；
2. 配比：$0.01 : 0.03 = 1 : 3$——三瓶化验握着七成五的话语权；
3. 表决：$\mu_n=(0.01\times 60+0.03\times 64)\div 0.04=15+48=63$ 毫克；
4. 不确定度收敛：后验方差 $1/0.04=25$，宽度从 $\tau=10$ 收窄到 $\tau_n=5$，正好腰斩。

解读盯一步：均值只走了四分之三的路（60 到 64 的差被表决截在 63）而非直接跳到 64——新产线首周的化验声音很响，但老档案还留了一票。若换成 σ 很小的精密仪器，同样 3 瓶会把档案甩得更远。

### 实验 2（python）：三条曲线同台 + 两种算法互查

```python title="先验 × 似然 = 后验：闭式解与网格法对照"
import random                     # 固定随机流，保证人人复现同一批读数
import math                       # 钟形曲线要靠指数函数 exp
import matplotlib.pyplot as plt   # 画图库

random.seed(11)                   # 固定随机种子
y = []
for _ in range(12):
    y.append(random.gauss(66, 5)) # 一瓶模拟读数，出自 N(66, 5²)

mu0, tau, sig = 60.0, 5.0, 5.0    # 经验中心 / 经验不确定度 / 单瓶噪声
n = len(y)                        # 读数条数
xbar = sum(y) / n                 # 样本均值：数据方的立脚点

lam0 = 1 / tau ** 2               # 先验精度：方差的倒数
lam = n / sig ** 2                # 数据精度
mu_closed = (lam0 * mu0 + lam * xbar) / (lam0 + lam)   # 精度加权表决

ts = []                           # 参数轴上的格子（复习上一课）
wc = []                           # 未归一化的后验曲线
for i in range(401):
    t = 48 + i * (34 / 400)
    ts.append(t)
    wp = math.exp(-((t - mu0) ** 2) / (2 * tau ** 2))     # 先验这层底色
    wl = 1.0                                              # 数据权重逐条累乘
    for yi in y:
        wl = wl * math.exp(-((yi - t) ** 2) / (2 * sig ** 2))
    wc.append(wp * wl)

tot = 0                          # 归一化常数（它的身份下一课揭晓）
for w in wc:
    tot = tot + w
mean_grid = 0                    # 格子上的加权平均
for i in range(len(ts)):
    mean_grid = mean_grid + ts[i] * wc[i] / tot

plt.plot(ts, wc, label="posterior")
plt.axvline(mu_closed, color="red", linestyle="--")       # 闭式解画一条竖线
plt.axvline(mu0, color="gray", linestyle=":")
plt.legend()
print(f"样本均值 {xbar:.2f} | 闭式解 {mu_closed:.2f} | 网格法 {mean_grid:.2f}")
```

红竖线（闭式解 64.96）稳稳压在后验峰顶，与上一课的网格兵兑出同一位置——解析优雅与体力活殊途同归。格局也看得清：后验比两条输入都瘦，因为精度做了**加法**。至于看不见的方差 σ 若本身未知？给它在格子上也铺一层候选值即可，上一课的屠龙刀依旧锋利；正统的共轭之路见本课末尾选读。

### 快问快答

```quiz
想把样本均值的波动幅度减半，抽样数量翻倍够吗？
- 翻倍就够
- 要变成原来的四倍 [*]
- 和抽样数量无关
? 样本均值的波动正比于 sigma 除以根号 n：想让波动砍半就得让根号 n 翻倍，也就是 n 变成四倍。
```

:::warning[常见误区]

**误区一**：「你以为先验和数据一人一票最公平。」精度悬殊时等权平均会被弱信息带偏——嗓门只认精度，不认人头。练习 1 里双方嗓门整整差九倍，平起平坐就是冤案。

**误区二**：「你以为『σ 已知』是教材偷懒。」工业现场常由仪器规格书、Gage R&R 报告锁定测量噪声，此设定相当现实；即便 σ 真未知，「铺网格」也能立刻开工，别因此搁浅推断。

**误区三**：「你以为区间变窄就是学到了真理。」后验收窄依赖模型假设成立：读数近似正态、无系统偏差。一把偏了零点的游标卡尺能把结论收得很窄又错得很整齐——窄而错是最危险的组合，异常排查永远排在加密格子之前。

:::

## 6. 练习

**练习 1**：老产线回来了：先验 $N(60,\ 5^2)$（工艺档案很有底气），仪器噪声 $\sigma=5$。抽检 9 瓶，平均 $\bar{x}=66$。下面的代码能跑，但表决方式错了——改成精度加权并算出后验标准差。改到通过：

```exercise
# @title: 练习：让精度定话语权
# @check: 65.4
# @check: 1.58
# @hint: 两边嗓门分别是 1/τ² 与 n/σ²；后验均值做加权平均，后验标准差要先加总精度再开方
mu0, tau = 60.0, 5.0      # 经验中心与先验不确定度
n, sig = 9, 5.0           # 抽检瓶数与单瓶噪声
xbar = 66.0               # 样本平均

post_mean = (mu0 + xbar) / 2          # ← 一人一票等权平均：两边嗓门差九倍，不该平起平坐
post_sd = 2.0                         # ← 也随手拍了个数
print(round(post_mean, 1))
print(round(post_sd, 2))
```

<details>
<summary>点开查看逐步解答</summary>

```python
mu0, tau, sig, n, xbar = 60.0, 5.0, 5.0, 9, 66.0   # 重建已知条件
lam0 = 1 / tau ** 2          # 0.04
lam = n / sig ** 2           # 9/25 = 0.36 —— 数据九倍音量
post_mean = (lam0 * mu0 + lam * xbar) / (lam0 + lam)
post_var = 1 / (lam0 + lam)
post_sd = post_var ** 0.5
print(round(post_mean, 1))   # 65.4
print(round(post_sd, 2))     # 1.58
```

配比恰为 1 : 9，十份话语权里经验只占一份：估计值 65.4 离样本均值一步之遥。后验方差 $1/0.4=2.5$，标准差从两侧的 5 收缩到约 1.58——两股精度相加的直接红利。

</details>

**练习 2**：想让「数据和档案恰好五五开」（$\lambda=\lambda_0$），在 $\tau=\sigma=5$ 时需要抽几瓶？

<details>
<summary>点开查看逐步解答</summary>

解方程 $n/\sigma^2 = 1/\tau^2$：代入 $n/25=1/25$ 得 $n=1$——一瓶就够了！仪器精度高（σ 小），每瓶读数都很能说话；档案本身也不算硬气。反差在于若 $\sigma=20$（工艺飘忽），打平要 $n=16$ 瓶。这个平行小题点破常被忽略的一件事：**打平所需的样本量完全由 σ 对 τ 的比值决定**，而非绝对数值大小。

</details>

## 7. 选读：σ 自己也该有个分布

<details>
<summary>选读 · 方差未知的正统打开方式</summary>

方差未知时处理思路一脉相承：给它也配个先验然后一起更新。正态世界有现成的共轭搭档——逆伽马（或等价的伽马）分布，专管「方差这类恒为正数的旋钮」；μ 走本课的精度加权，σ² 走伽马族自己的计数逻辑。工程常用 shortcut 是拿样本方差代替 σ² 再套一遍本课公式，只要 n 不太小误差相当可控。真正的通用解是把 $(\mu, \sigma^2)$ 一起铺上网格或交给后面登场的 MCMC——工具没有门户之见。

</details>
