# 共轭先验：Beta 与二项的天作之合

## 1. 从一个场景开始

新按钮上线第一天：3 次点击、1 次转化。真实转化率是多少？频率派说"33%"，可你心里打鼓——明天再来 3 次全失败，估计就变成 0% 了，难道按钮一夜变烂了？

小样本下，裸的频率太不可靠。贝叶斯派的做法：先把"转化率大概是多少"的旧经验（比如同类按钮通常在 10% 到 30% 之间）写成一个**分布**，再让数据去更新它。问题是怎么把"一段范围的经验"写成数学对象？答案是一族专为概率值量身定做的分布——Beta 分布。

## 2. 直觉解释

Beta 分布有两个旋钮 $a$ 和 $b$，读法极其好记：

> **$a$ = 见过的"伪成功"次数，$b$ = 见过的"伪失败"次数。**

- Beta(1, 1)：一次成功一次失败都没见过——对 0 到 1 的所有转化率一视同仁（均匀分布）；
- Beta(6, 4)："相当于已经看过 10 次试验、6 成成功"——分布的重心在 0.6 附近；
- $a+b$ 越大，先验越自信（想象看过的虚拟历史越多）。

然后是魔法时刻：手头来了 $k$ 成功、$n-k$ 次失败的**真实数据**，更新规则居然只是做加法——

$$a \leftarrow a + k, \qquad b \leftarrow b + (n-k)$$

伪次数与真次数合并记账，完事。这就是**共轭先验**：先验与似然形状同族，相乘后不换脸，更新变成加法。

## 3. 正式定义

设参数为转化率 $\theta \in [0,1]$，数据为 $n$ 次独立试验中 $k$ 次成功（伯努利/二项模型）。取先验 $\theta \sim \mathrm{Beta}(a, b)$，密度为：

$$f(\theta)=\theta^{a-1}(1-\theta)^{b-1}, \qquad 0 \le \theta \le 1$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\theta$ | 待估参数 | 真实成功率本身（把它当随机变量是贝叶斯的标志） |
| $a, b$ | 先验超参数 | 相当于先验里虚拟的成功/失败次数 |
| $k, n$ | 数据 | 实际观察到的成功数与总试验数 |
| 后验 | 更新结果 | $\mathrm{Beta}(a+k,\ b+n-k)$ |
| 后验均值 | 点估计 | $\dfrac{a+k}{a+b+n}$ |

后验均值公式值得盯三秒：它就是**总成功数除以总试验数**（虚拟的加真实的）。当数据量 $n$ 远超 $a+b$ 时它退化为普通频率 $\bar{x}$；当数据很少时先验说了算。一条公式同时管住了"没数据听先验"和"数据多听数据"，衔接天衣无缝。

## 4. 分步例题

**例**：团队凭历史经验认为新功能转化率大约四成，这份信心的分量约等于看过 10 次试验（4 成功 6 失败），故取先验 Beta(4, 6)。上线后收集到 21 次成功、9 次失败（共 30 次）。

1. 写下先验：$\mathrm{Beta}(4, 6)$，先验均值 $4/10=0.4$；
2. 合并数据：$a'=4+21=25$，$b'=6+9=15$；
3. 写出后验：$\mathrm{Beta}(25, 15)$，后验均值 $25/40=0.625$；
4. 解读：纯频率是 $21/30=0.7$，先验把估计从 0.7 拉回 0.625——因为 30 次数据的分量（30）只比先验分量（10）大三倍，先验仍有话语权。若数据积累到 300 次，同样的先验只会拉动约一个百分点。

三个必玩动作：(1) 保持 $a=b$ 对称拉大——峰变高变窄，信心增强而观点未变；(2) 把 $a$ 拖大 $b$ 拖小——峰向右跑（越相信高成功率）；(3) 设 $a=b=1$——摊平成均匀分布（完全无信息）。纵轴数值不重要（未归一化），看形状即可。

### 实验 2（python）：看着信念被数据一步步推走

生成一枚真实转化率 70% 的"硬币"，让三位起点不同的分析师轮流观看**同一条**数据流：

```python title="三种先验在同一路数据流下的收敛"
import random                     # 随机库
import matplotlib.pyplot as plt   # 画图库

true_p = 0.7                      # 真实转化率（模拟中我们全知）
priors = [(1, 1), (5, 2), (2, 8)] # 三位分析师的先验：中立 / 偏乐观 / 偏悲观

# 先生成一整条数据流，保证三人看到的世界完全相同
stream = []
for step in range(200):
    outcome = 1 if random.random() < true_p else 0   # 一次真实试验：1 成功 0 失败
    stream.append(outcome)

traces = []                       # traces[j]：第 j 位分析师的后验均值轨迹
for a0, b0 in priors:
    a, b = a0, b0                 # 从各自先验出发
    trace = [a / (a + b)]         # 第 0 步是先验均值
    for outcome in stream:
        if outcome == 1:
            a = a + 1             # 看到成功：a 加一（共轭更新）
        else:
            b = b + 1             # 看到失败：b 加一
        trace.append(a / (a + b)) # 当前后验均值
    traces.append(trace)

plt.plot(traces[0], label="Beta(1,1)")
plt.plot(traces[1], label="Beta(5,2)")
plt.plot(traces[2], label="Beta(2,8)")
plt.axhline(true_p, color="red", linestyle="--")   # 红线 = 真实转化率
plt.legend()
```

三条线起点天差地别，几十步内全部挤向红色真值线——先验的分歧被数据稀释的过程肉眼可见。把 200 改成 30 再跑一次：小数据下三条线还各执一词，这就是"先验话语权与样本量成反比"的现场版。

### 快问快答

```quiz
先验从 Beta(2,2) 换成 Beta(200,200)，同样看到 100 次试验中 90 次成功，谁的后验均值更靠近 0.9？
- 先验弱的那位（约 0.88） [*]
- 先验强的那位（约 0.58）
- 两位一样
? Beta(200,200) 相当于 400 次虚拟试验，100 次真实数据撼不动它多少；Beta(2,2) 只有 4 次分量，很快被数据带跑。先验强度就是虚拟样本量。
```

:::warning[常见误区]

**误区一**："你以为 Beta 分布里的 a、b 是坐标或均值。" 它们是"虚拟计数"：均值是 $a/(a+b)$，但形状还受总量 $a+b$ 控制——Beta(50,50) 与 Beta(2,2) 均值相同，信心天差地别。

**误区二**："你以为共轭意味着'先验和数据长得像'。" 共轭说的是数学结构：先验族乘以似然后仍留在同一个族内，从而更新只需改参数。它是一种计算便利，不是对数据的描述。

**误区三**："你以为后验均值就是最终答案。" 贝叶斯给出的是整条分布（还能算区间、算预测），均值只是摘要之一。小样本时后验明显偏斜，报一个均值会丢掉"我们其实还很不确定"这个关键信息。

:::

**练习 1**：先验取无信息的 Beta(3, 3)，随后观察到 8 次成功、2 次失败。求后验均值。下面的代码能跑但忽略了先验——改到通过：

```exercise
# @title: 练习：合并伪次数与真次数
# @check: 0.6875
# @hint: 后验均值 = (a + 成功数) / (a + b + 总试验数)，别丢掉先验的两个参数
a_prior = 3       # 先验伪成功次数
b_prior = 3       # 先验伪失败次数
k = 8             # 观察到的成功数
n = 10            # 总试验数

mean = k / n      # ← 这是裸频率，先验还没进场
print(mean)
```

**练习 2**：接上题，再观察到 2 次成功、8 次失败。用"接着加法"一步算出新后验均值，并验证它与"把 20 次数据一口气合并"的结果相同。

<details>
<summary>点开查看逐步解答</summary>

```python
a_prior, b_prior, k, n = 3, 3, 8, 10
mean = (a_prior + k) / (a_prior + b_prior + n)
print(mean)
```

分批：$a''=3+8+2=13$，$b''=3+2+8=13$，均值 $13/26=0.5$。一口锅：同样得到 Beta(13, 13)。**更新的顺序无关紧要**——这是共轭结构送的礼物，也是第 30 课要专门演示的性质。顺带一提：前 10 次 80% 成功率曾让均值高达 0.6875，后半段回落到 0.5，信念随证据起落，正是贝叶斯的本色。

</details>

**练习 3**：产品要求"估计值与真实值差超过 5 个百分点的风险很小"才允许停测。用实验 1 的滑块解释为什么 $a+b$ 至少要几百。

<details>
<summary>点开查看逐步解答</summary>

Beta(a,b) 的标准差约为 $\sqrt{ab/((a+b)^2(a+b+1))}$，当 $a=b$ 时近似 $\frac{1}{2\sqrt{a+b}}$。要让它小于 0.025（即 ±5 个百分点内覆盖大部分质量），需要 $a+b\gtrsim 400$。滑块上把 $a=b$ 从 2 拉到 400 就能看见峰从平缓到尖耸——"估计精度由总虚拟样本量决定"这件事在图上一目了然。

</details>

## 7. 选读：为什么恰好是 Beta 族

<details>
<summary>选读 · 共轭性的代数面目</summary>

似然是 $\theta^k(1-\theta)^{n-k}$——关于 $\theta$ 的多项式。先验 $\theta^{a-1}(1-\theta)^{b-1}$ 也是同款多项式。两者相乘指数直接相加：

$$\theta^{a-1}\theta^{k}(1-\theta)^{b-1}(1-\theta)^{n-k}=\theta^{(a+k)-1}(1-\theta)^{(b+n-k)-1}$$

这正是另一个 Beta 密度的形状（分母的归一化常数负责收拾残局）。所以"共轭"的本质是：**指数族的成员相乘，指数相加**。二项之于 Beta，正如泊松之于 Gamma、正态之于正态——同一出戏的三次巡演。

</details>
