# 边际似然与模型比较：奥卡姆剃刀的数学

## 1. 从一个场景开始

你和朋友对一枚硬币打赌。朋友甲观点简单：「这枚硬币就是公平的，没得商量。」朋友乙格局打开：「我保留一切可能，正面率 p 可以是任何值。」你们投了十次，六正四反。

谁的世界观更配得上这份数据？注意问题变了——前几课都在问「参数是多少」，这一课问的是「**哪个模型更可信**」。要回答它，需要一个给整个模型打分的数：这个模型生出眼前数据的概率有多大？这个分数叫**边际似然**，而它会自动执行一条古老的哲学法则：如无必要，勿增实体。

## 2. 直觉解释

把模型想成一位预言家：

- **甲（公平硬币）**：不许参数、不做调整，给出一张死板的预测表——十次六正的概率是一个固定数字；
- **乙（万能 p）**：手里有一整族预言家（每个 p 值一位），用先验给他们分配出场费，最后让所有人**同时下注**。

乙看起来占尽便宜？错了，代价立刻显现：一百分的自信摊到几百个分身头上，每个分身的注都薄得可怜。十次六正这种「平庸」的结果，公平硬币敢重仓押注，乙的预测力却被均匀稀释。

这就是**奥卡姆剃刀的数学面目**：灵活不是免费的，每多一分弹性都要向所有具体预测收税。数据贴合简单模型的死板预期时，简单模型完胜；数据古怪到简单模型几乎没押注时，复杂模型才有翻身的机会。剃刀从不偏袒谁——它只奖励「敢说真话还说对了」。

## 3. 正式定义

对模型 $M$（自带参数先验 $p(\theta \mid M)$），数据的边际似然定义为把参数积分掉的预测概率：

$$P(D\mid M)=\int_\Theta L(D\mid\theta,M)\,p(\theta\mid M)\,d\theta$$

两个模型的擂台赛就叫**贝叶斯因子**：

$$B_{12}=\frac{P(D\mid M_1)}{P(D\mid M_2)}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $M$ | 一个完整模型 | 结构 + 参数先验，缺一不可 |
| $\int_\Theta$ | 对参数积分 | 把「每个参数取值下的可能」按权重加总 |
| $P(D\mid M)$ | 边际似然 | 模型的赛前报价：生出数据的整体概率 |
| $B_{12}$ | 贝叶斯因子 | 模型 1 相对模型 2 的赔率倍数 |

三件事必须点破。其一，边际似然用的是**计数**层面的数据概率（六正四反有 C(10,6) 种排列方式，全都要算进去）。其二，它对参数空间的**一切宽度**收税：先验铺得越宽、峰越多，同一份数据分到的单价越低。其三，回顾上一课被扫地扫掉的归一化常数 $\sum_j w_j$——它的连续版正是这个积分！网格法随手就能把它请回来算数值。

## 4. 分步例题

继续硬币对决：甲 = 公平硬币；乙 = 正面率服从均匀先验。数据为十次六正四反。

1. **甲的报价**：二项计数概率 $\binom{10}{6}\,(0.5)^{10}=210/1024\approx 0.205$；
2. **乙的报价**：全部 p 预言家的加权平均下注 $\binom{10}{6}\int_0^1 p^6(1-p)^4\,dp$。这个积分有个漂亮捷径——幂函数积分只是指数加一，于是均匀先验下**任何**模式的报价恒等于同一个数：

$$P(D\mid M_{\text{乙}})=\frac{1}{n+1}=\frac{1}{11}\approx 0.091$$

3. **裁决**：贝叶斯因子 $B=0.205/0.091\approx 2.26$，甲领先约两倍半——「平庸」数据下简单模型完胜，剃刀落下。

反转剧本也备好了：若十次全正，甲的报价跌到 $(1/2)^{10}\approx 0.0010$ 一格，而乙仍稳拿 $1/11$——贝叶斯因子翻到约 $1:93$，剃刀同样利落地砍向死板的甲。**同一个公式自动决定奖惩**，这份不偏不倚正是它的魅力。

### 实验 2（python）：亲手算出两个报价

```python title="数值积分与精确公式两条腿互证"
import math   # 组合数与阶乘都靠它

N = 2001                        # 把 [0,1] 切成两千根格子
total = 0                       # 数值法累加单个 p 预言家的裸积分（还没数排列）
for i in range(N):
    p = (i + 0.5) / N           # 格子中心，避开两端
    total = total + p ** 6 * (1 - p) ** 4 / N

num_exact = math.factorial(6) * math.factorial(4)     # 精确式分子 k!(n-k)!
den_exact = math.factorial(11)                        # 精确式分母 (n+1)! = 11!

comb = math.factorial(10) // (math.factorial(6) * math.factorial(4))   # C(10,6) = 210：六正四反的排列数
total = comb * total                                  # 210 种排法一起买单（计数层面）
ml_flex = comb * num_exact / den_exact                # 乙的报价 = 210 × 裸形（计数层面）

ml_fair = comb * 0.5 ** 10                            # 甲的报价（计数层面）

bf = ml_fair / ml_flex                                # 贝叶斯因子
print(f"数值积分 ≈ {round(total, 4)}，精确式 = {round(ml_flex, 4)}")
print(f"甲的报价 = {round(ml_fair, 4)}")
print(f"贝叶斯因子 = {round(bf, 2)} —— 支持公平硬币")
```

两条腿踩出同一个 $0.0909$——注意两条腿都先乘了 $C(10,6)=210$：裸形积分的闭式是 $\frac{6!\,4!}{11!}\approx0.0004$，那只是一条特定序列的身价；补上 210 种排法后，上下阶乘约简恰好只剩 $1/(n+1)=1/11$，「均匀先验什么数据都报同一价」自此有了算术凭证。

### 实验 3（python）：窄心眼 vs 宽格局的正面对决

```python title="同一份数据，两种先验气量的报价对照"
import math   # 阶乘换算 Beta 函数值

def marg(k, n, a, b):
    # 报价 = C(n,k) × B(a+k, b+n-k) ÷ B(a,b)，全程整数阶乘防误差
    B_prior = math.factorial(a - 1) * math.factorial(b - 1) / math.factorial(a + b - 1)
    B_post = math.factorial(a + k - 1) * math.factorial(b + n - k - 1) / math.factorial(a + b + n - 1)
    cnk = math.factorial(n) // (math.factorial(k) * math.factorial(n - k))
    return cnk * B_post / B_prior

cases = [(6, "居中·六正四反"), (2, "偏科·二正八反"), (10, "极端·十正零反")]
for k, tag in cases:
    wide = 1 / 11                                       # 均匀先验：永远 1/(n+1)
    narrow = marg(k, 10, 50, 50)                        # 自信的窄先验 Beta(50,50)
    verdict = "窄先验赢" if narrow > wide else "宽先验赢"
    print(f"{tag}: 均匀={wide:.4f} 窄Beta(50,50)={narrow:.4f} → {verdict}")
```

三行判词讲完奥卡姆：数据贴着窄先验的心窝时，专注让它以约两倍的赔率取胜；数据偏科一点点就被摊薄的对手反超；到了十正零反的极端局面，窄先验崩到千分之一价位。先验宽度是策略不是立场——数据落点说了算。

### 快问快答

```quiz
模型越复杂，边际似然一定越高吗？
- 是，能解释的数据更多
- 否，弹性会被自动征税 [*]
- 取决于数据量，只有数据少才惩罚复杂模型
? 边际似然是按参数先验平均后的预测概率：灵活性摊薄了对每一种具体结果的置信度，这笔税无论数据多少都在收。
```

:::warning[常见误区]

**误区一**：「你以为拟合最好的模型就是最好的模型。」最大似然一路偏爱最尖的钉子（过拟合的职业装）；边际似然按赛前整体报价评分，自带简朴加分。两者可以背道而驰，这正是奥卡姆剃刀的价值所在。

**误区二**：「你以为宽先验等于客观中立所以不吃亏。」宽先验对每个具体结论都不敢重仓，报价全面摊薄；它能赢的场景仅仅是数据相对它的灵活性也算极端而已。中立与自信从不冲突——但要明白自己在为什么付代价。

**误区三**：「你以为边际似然还能顺便告诉我们参数在哪。」不能。参数在这个积分里已经被积掉了——它是纯模型层的分数，回答「这套世界观能否生出数据」；参数定位是后验的事，两层任务别混着开会。

:::

```python
print(round(p_fair, 4))      # 0.2051
print(round(p_flex, 4))      # 0.0909
```

$210\times(1/1024)\approx 0.2051$，贝叶斯因子约 2.26 支持甲。想看反转就把 `k` 改成 10 重跑一次——剃刀当场调转方向。

**练习 2**：均匀先验对「六正四反」「七正三反」「任意模式」统统报价 $1/11$，看起来毫无辨别力——这是缺陷还是特性？

<details>
<summary>点开查看逐步解答</summary>

这是特性，而且诚实得很：均匀先验拒绝在任何具体方向上下重注，于是对所有模式提供同一标准票——真正「什么都不知道」的世界观就该如此谦逊。辨别力由别的先验供给（比如专注中庸值的 Beta(50,50)，见实验 3）。这恰是贝叶斯因子的深意：它衡量的从来不是哪个模型「更好」，而是哪套**带立场的假设组合**更匹配这份数据——立场本身就是模型的一部分。

</details>

## 7. 选读：把剃刀拆成零件

<details>
<summary>选读 · 奥卡姆因子的分解式</summary>

利用拉普拉斯近似可以把边际似然拆成两件套：

$$P(D\mid M)\approx L(\hat{\theta})\times\frac{\Delta\theta_{\text{后验}}}{\Delta\theta_{\text{先验}}}$$

第一项是最佳拟合处的似然峰值——复杂模型的地盘；第二项是后验宽度与先验宽度之比——惩罚项：先验摊得多开、而后验被数据勒得只剩细缝时，比值骤降，这就是赫赫有名的**奥卡姆因子**。「预测能力 = 贴合度 × 诚实度」，发布会上的花活骗不过这个乘法。

</details>
