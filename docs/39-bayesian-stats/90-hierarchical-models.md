# 层次模型与部分池化

## 1. 从一个场景开始

连锁奶茶品牌要复盘 12 家门店的本周下单转化率。问题出在两头的极端：

- 商圈旗舰店流量巨大，转化率 36%，误差小得像钉在墙上的牌子；
- 郊区快闪新店只接待了 30 位顾客，转化 15 单——账面 50%，全场冠军！

该给快闪店发奖吗？运营老手会冷笑：「上周他们还是垫底。」整条链上的直觉是：**小店的数据吵闹而不可靠，大店的数据沉稳但不能代表每家店的个性**。这一课把这个直觉铸成公式：层次模型——数据按「全局—门店」两层嵌套生成，估计也随之分两层投票。

## 2. 直觉解释

面对一组天然分群的数据，有两个失败的极端做法：

| 做法 | 剧情 | 病灶 |
| --- | --- | --- |
| 完全合并 | 十二家店揉成一锅算总转化率 33% | 店与店的真实差异被抹平，机场店和写字楼店被判同罪 |
| 各算各的 | 每家店用自己的数据单飞 | 小店的 50% 与大店的 36% 平起平坐，噪声获得尊严 |

第三条路叫**部分池化**：让每家店的参数都长在一个共同的家族里——先由「全局层」定下各店大致的水位 $m$，再允许各家围绕水位上下浮动。观测到的账面数字于是被两只手同时拉扯：

> **自己的数据往一边拽，整个家族往另一边拽；谁家的数据越薄，家族那边的拉力就越明显。**

快闪店的 50% 会被礼貌地拽回水位附近（它只有 30 位顾客发声）；旗舰店的 36% 几乎纹丝不动（1800 位顾客不容置疑）。这种朝全局水位的回拉有个学名——**收缩**。它不是保守主义的审美，而是第六十课精度加权法则的直接后果：小样本 = 低精度 = 小嗓门。

## 3. 正式定义

两层生成剧本：真实转化率 $\theta_j$ 先从全局分布中抽出（把全局层的发言折算成 $K$ 位虚拟顾客、均值 $m$），再由各自门店的数据说话：

$$\theta_j \sim \text{以}\ m\ \text{为心、强度}\ K\ \text{的先验}, \qquad k_j \sim \text{Binomial}(n_j, \theta_j)$$

给定数据后，第 $j$ 家店的收缩估计为

$$\hat{\theta}_j=\frac{n_j\,\bar{r}_j+K\,m}{n_j+K}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $n_j,\ k_j$ | 第 j 家店的顾客数与成交数 | 它手里全部的证据 |
| $\bar{r}_j=k_j/n_j$ | 账面转化率 | 未收缩时的「裸观点」 |
| $m$ | 全局水位 | 通常取全体合并的转化率 |
| $K$ | 虚拟顾客数 | 全局层的等效发言量：K 越大家族嗓门越大 |
| $\hat{\theta}_j$ | 收缩后的估计 | 数据与家族的两手合议 |

两个边界自检：$n_j$ 极小时 $\hat{\theta}_j \to m$（孤证不立）；$n_j$ 极大时 $\hat{\theta}_j \to \bar{r}_j$（铁证如山）。注意它没有退化成「大家都取平均」——只要某家店有足够证据偏离水位，合约照样放行：**收缩的幅度由数据厚度决定，而不是一刀切**。

## 4. 分步例题

用实验的真实台账做快闪新店的核算：六家代表店合并水位 $m\approx 33.15\%$，全局层议价能力按 $K=400$ 位虚拟顾客计。

1. 快闪店账面：$n=30$，$\bar{r}=50\%$；
2. 家族一票：$K\times m=400\times 33.15\approx 13260$ 个「虚拟成交百分点」；
3. 自己一票：$n\times\bar{r}=30\times 50=1500$；
4. 合议：$(1500+13260)\div(30+400)\approx 34.3\%$——从全场冠军回到普通队员附近；
5. 对照旗舰店（$n=1800$，$\bar r=36\%$）：同样配方算出约 $35.5\%$，仅向水位挪了半格——厚数据稳如泰山。

一步之内，「发不发奖杯」自动有了答案：34.3% 在水平线之上但远配不上 50% 的浮夸。要问 $K=400$ 这个报价哪来的？先验强度的设定权在你（业务经验给出）；第七节选读展示更高级的做法——让数据自己开出这个价。

玩法三连：(1) 把 `t`（本店顾客数）拖到 5 再拖到 500，看实线从「贴着水位线躺平」绷直成「几乎重合对角线」；(2) 增大 `kk` 整条曲线变软——家族话语权压过个体；(3) 移动 `g` 观察吸引子搬家。曲线与对角线的纵向落差就是收缩力度，一眼读出谁会被拉多少。

### 实验 2（python）：六家门店的三张成绩单

```python title="完全合并 / 各算各的 / 部分池化，同台竞技"
stores = [                        # (店名, 顾客数, 成交数)：本章开场的六家代表
    ("商圈旗舰", 1800, 648),
    ("写字楼店", 900, 216),
    ("校园店", 600, 228),
    ("社区老店", 450, 135),
    ("机场店", 120, 51),
    ("快闪新店", 30, 15),
]
grand_k = 0                       # 全体成交总数
grand_n = 0                       # 全体顾客总数
for name, nn, kk in stores:
    grand_k = grand_k + kk
    grand_n = grand_n + nn
m = grand_k / grand_n * 100       # 合并水位（百分比）
K = 400                           # 全局层折算成 400 位虚拟顾客

print(f"合并水位 m = {round(m, 2)}%")
print("店铺     各算各的      部分池化")
for name, nn, kk in stores:
    raw = kk / nn * 100                               # 裸转化率
    part = (nn * raw + K * m) / (nn + K)              # 收缩公式上场
    print(f"{name}   {round(raw, 1)}%        {round(part, 1)}%")
```

输出表里藏着整课剧情：快闪新店 50% 被拉到 34.3%，是全场最大跌幅（数据最薄）；商圈旗舰 36% 只微调到 35.5%（数据最厚）。有趣的副线还有校园店：38% 反而显得比水位高出不少，因为它的样本厚到足以自证——**部分池化不搞平均主义，它只收割噪声**。

### 快问快答

```quiz
同样是向上修正，为什么快闪店被拉得比社区老店狠得多？
- 系统偏爱新店
- 快闪店样本薄，自己的一票弱，家族票占比自然大 [*]
- 因为快闪店位置偏
? 收缩比例由 n/(n+K) 决定：30 位顾客对 400 位虚拟顾客，个体几乎没有谈判力；450 位顾客的老店则底气足得多。
```

:::warning[常见误区]

**误区一**：「你以为层次越多越专业。」每一层超参数都要付可辨识性的代价，两层（店内—全局）已覆盖绝大多数场景；再多嵌套属于层次灾难的前奏，除非数据真的按三层自然生长。

**误区二**：「你以为部分池化就是把所有人往中间平均。」它保留个体差异，只是按证据厚度来定价：厚数据的离群值照样屹立（校园店 36% 起跳）。真正被抹掉的是小样本伪装出来的戏剧性。

**误区三**：「你以为水位 m 和虚拟顾客数 K 是拍脑袋定的。」临时拍板当然可以跑通流程，却埋下「分析师性格决定结论」的隐患；成熟做法让它们也从数据中估出来（下一节的选读），拍脑袋永远是过渡方案而不是终点。

:::

## 6. 练习

**练习 1**：促销复盘专用题：促销页上线，全局基线 $m=30\%$，全局层取 $K=50$ 位虚拟顾客。快闪推送页来访 150 人、成交 57 单；旗舰主会场来了 450 人、成交 121 单。下面的代码能跑，但它是在「各算各的」世界里裸奔。补上部分池化的合议公式，改到通过：

```exercise
# @title: 练习：给两条数据装上弹簧
# @check: 36
# @check: 27.2
# @hint: 公式是 (n*r + K*m) / (n + K)，统一先把两个账面率算成百分数再代入
m = 30.0                   # 全局基线（百分数）
K = 50                     # 全局层的虚拟顾客数

flash_n, flash_conv = 150, 57          # 快闪页：150 人 57 单
flag_n, flag_conv = 450, 121           # 主会场：450 人 121 单

flash_est = flash_conv / flash_n * 100   # ← 只信自家数据，100% 裸奔
flag_est = flag_conv / flag_n * 100      # ← 同样没让家族投票
print(round(flash_est))
print(round(flag_est, 1))
```

<details>
<summary>点开查看逐步解答</summary>

```python
flash_r = flash_conv / flash_n * 100    # 38%
flag_r = flag_conv / flag_n * 100       # 约 26.9%
flash_est = (flash_n * flash_r + K * m) / (flash_n + K)
flag_est = (flag_n * flag_r + K * m) / (flag_n + K)
print(round(flash_est))      # 36
print(round(flag_est, 1))    # 27.2
```

快闪页 38% 的涨势收缩成 36%——依然亮眼但不夸张；主会场自身的 26.9% 则被家族轻轻托起到 27.2%。一个往下收、一个往上托，方向由账面落在水位的哪一侧决定：**弹簧只会把你拉向水位，从不关心你是谁的粉丝**。

</details>

**练习 2**：如果促销团队直接拿快闪页的裸转化率 38% 向 CEO 汇报「效果翻倍」，审计时最有力的反驳话术是什么？

<details>
<summary>点开查看逐步解答</summary>

三层递进：(1) 抽样噪声——150 人的样本上 ±8 个百分点的波动家常便饭，38 与基线 30 的差距近半可能只是运气；(2) 回归趋势——即便真有效果，首批接触者往往是最爱尝鲜的用户，后续流量结构必然稀释涨幅（对比历史记录里的社区老店）；(3) 行业惯例——对照层级的同类测量本就该共享一部分信息，部分池化的 36% 才是「这份数据 + 全部常识」的诚实报价。三句话术背后是同一个数学：小样本的极端值天生富余，不收缩才是无依据的慷慨。

</details>

## 7. 选读：让家族自己给自己定价

<details>
<summary>选读 · 超参数也是参数</summary>

正文里 $m$ 取合并均值、$K$ 交给业务直觉，学术名叫**经验贝叶斯**的顺手版。正统的完全贝叶斯更进一步：给 $m$ 和 $K$ 也配上先验（比如「$K$ 大概率在一百到一千之间」的宽信念），然后与六家店的参数一起扔进联合后验。此时本教程一路攒的家当悉数登场——后验维度高了、形状歪了，网格摆不开，正是上一课 MCMC 的主场；游走回来的足迹顺带告诉我们「数据其实支持多大的 $K$」。层次模型 + MCMC 是当代贝叶斯应用的主力机型：门店有差异、差异本身也有浓度，连「个性有多大」这件事都可以边学边估。

</details>
