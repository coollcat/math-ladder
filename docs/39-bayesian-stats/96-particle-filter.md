# 粒子滤波：用一群样本追一个会动的隐状态

## 1. 从一个场景开始

一辆小车开进了隧道。你只能在隧道口每隔一秒收到一次它发来的距离读数（带噪声），却想随时知道它究竟在哪儿。更麻烦的是：小车会**突然加速或转弯**，运动不再是简单的匀速直线；距离读数也不是位置的线性函数（雷达测距走的是平方根）。

如果状态转移和观测都是**线性 + 高斯**，这道题有现成的最优解——卡尔曼滤波，一套闭式递推公式。可一旦出现"突然转弯"这种非线性、非高斯的成分，卡尔曼的公式就撑不住了。

**粒子滤波（particle filter）**给出的是一条出人意料的路子：干脆不放公式，撒一把"猜测"出去，让它们自己竞争——谁跟观测吻合，谁就获得更多话语权，然后照话语权"繁殖"下一代。它把"追一个会动的隐状态"变成了一场反复进行的**适者生存**。

## 2. 直觉解释

**核心直觉：一群假设 + 三步循环。**

想象你派出 600 个侦察兵，每人扛着一个"小车现在在这儿"的猜测。每一步做三件事：

1. **预测**：每个侦察兵按运动模型往前挪一步。既然小车可能加速，就让每人挪的量不同——**在因果上加一点随机抖动**。这一步把上一刻的"位置云"整体推向前方，同时变胖一点（不确定性增加）；
2. **加权**：收到新的距离读数，逐个检查每个侦察兵的位置能不能"解释"这个读数。解释得越好的，权重越大；离读数十万八千里的，权重几乎归零。**权重就是话语权**；
3. **重采样**：按权重把侦察兵**重新点名**——权重大的被复制好几份、权重小的被淘汰；人群仍是 600 个，但分布已朝观测更可能的位置聚集。三步走完用加权平均读出估计值，这就是粒子滤波的全部骨架，也叫**序贯重要采样 + 重采样（SIR）**。

**为什么必须重采样？** 加权这一步有个慢性病：跑久了，权重会悄悄集中到个别侦察兵身上——第 10 步还有 600 个人说话，第 30 步可能就剩 3 个还在发声，其余 597 人的权重小到可以忽略。这叫**权重退化**。重采样就是解药：它把"快被淹没的大多数"重新拉回牌桌，让每一步都有足够多的人参与。

**它和卡尔曼的分工。** 卡尔曼滤波是线性高斯世界的**精确解**，一步公式算到底、又快又准；粒子滤波是通用世界的**数值解**，代价是要撒很多粒子、算很多次。**能用卡尔曼就绝不用粒子滤波；一旦模型非线性或噪声非高斯，粒子滤波才登场。**

## 3. 正式定义

**状态空间模型**：隐状态 $x_t$ 随时间按转移模型演化，我们只能看到带噪的观测 $z_t$：

$$x_t = f(x_{t-1}) + v_t, \qquad z_t = h(x_t) + w_t .$$

$f$ 和 $h$ 可以是任意函数（不必线性），$v_t$、$w_t$ 可以是任意噪声分布（不必高斯）。

**粒子滤波**：用 $N$ 个带权样本 $\lbrace x_t^{(i)},\, w_t^{(i)} \rbrace_{i=1}^{N}$ 近似后验分布 $p(x_t \mid z_{1:t})$。三个步骤：

1. **预测**：从转移模型采样 $x_t^{(i)} \sim p(x_t \mid x_{t-1}^{(i)})$；
2. **加权**：用似然更新权重并归一化，

$$w_t^{(i)} \propto w_{t-1}^{(i)}\, p(z_t \mid x_t^{(i)}), \qquad \sum_{i=1}^{N} w_t^{(i)} = 1 .$$

估计值取加权均值 $\hat x_t = \sum_i w_t^{(i)} x_t^{(i)}$；

3. **重采样**：当权重要退化时，按权重把粒子重新复制一遍，并把所有权重置为 $1/N$。

**有效样本量（ESS）**：衡量"还有多少粒子在真正说话"，

$$\mathrm{ESS} = \frac{1}{\sum_{i=1}^{N} \left( w_t^{(i)} \right)^2 } \in [1, N].$$

权重均匀时 $\mathrm{ESS} = N$；权重全集中到一个粒子上时 $\mathrm{ESS} \approx 1$。常用判据：**$\mathrm{ESS} < N/2$ 就重采样**。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $x_t$ | 隐状态 | 想追的东西（小车位置），看不见 |
| $z_t$ | 观测 | 每步拿到的读数，带噪声 |
| $f,\ h$ | 转移/观测函数 | 可为非线性，这是卡尔曼失效的地方 |
| $x_t^{(i)}$ | 粒子 | 第 $i$ 个"猜测" |
| $w_t^{(i)}$ | 权重 | 该粒子解释观测的能力，归一化后求和为 1 |
| $\mathrm{ESS}$ | 有效样本量 | 实际"在说话"的粒子数，$1/\sum w^2$ |
| $N$ | 粒子数 | 撒多少侦察兵，典型几百到几千 |

## 4. 分步例题

用 3 个粒子手算一步。初始粒子位置 $x_0 = 0.0,\ 1.0,\ 2.0$，权重均等 $1/3$。运动很朴素：每步固定前进 1 米（这一小步先不加噪声，方便看清权重）。第 1 步收到观测 $z_1 = 1.6$，观测噪声方差 $R = 1$。

1. **预测**：三个粒子各自 +1，得到 $1.0,\ 2.0,\ 3.0$；
2. **算似然**：权重 $\propto e^{-(z_1 - x)^2/(2R)}$，逐个代入
   - $x=1.0$：$e^{-0.6^2/2} = 0.8353$；
   - $x=2.0$：$e^{-(-0.4)^2/2} = 0.9231$；
   - $x=3.0$：$e^{-(-1.4)^2/2} = 0.3753$；
3. **归一化**：三者之和 $2.1337$，得权重 $0.3915,\ 0.4326,\ 0.1759$。中间那个粒子（离读数 1.6 最近）话语权最大；
4. **加权估计**：$\hat x_1 = 1.0 \times 0.3915 + 2.0 \times 0.4326 + 3.0 \times 0.1759 = 1.784$ 米；
5. **查退化**：$\mathrm{ESS} = 1/(0.3915^2 + 0.4326^2 + 0.1759^2) = 1/0.3714 \approx 2.69$。3 个粒子还剩 2.69 个在说话——**还没到 $N/2 = 1.5$，这一步不必重采样**；
6. **读法**：如果观测落在 3.0 附近，第三个粒子会一枝独秀、其余权重趋近 0，ESS 就会掉到 1 出头——那时重采样把"运气好的那个"复制成好几份，人群重新获得多样性。

### 实验 2（python）：一维目标跟踪的完整实现

小车每秒前进 1 米，观测噪声标准差 2 米。跑一遍粒子滤波，和"直接用观测"比一比：

```python
import random                     # 随机数库
import math                       # 数学库

random.seed(11)                   # 固定种子：结果可复现

T = 40                            # 跟踪 40 秒
true_x = [0.0]                    # 真实位置：从 0 开始
for t in range(1, T):
    true_x.append(true_x[-1] + 1.0)      # 每秒匀速走 1 米

obs = []
for x in true_x:
    obs.append(x + random.gauss(0, 2.0)) # gauss(mu, sigma)：正态抽样，这里是观测噪声

N = 600                           # 粒子数
q = 0.8                           # 过程噪声标准差：模型对"匀速"有多不确定
R = 4.0                           # 观测噪声方差（= 2 米的平方）
particles = []
for i in range(N):
    particles.append(random.gauss(0, 5.0))   # 初始粒子撒在 0 附近
weights = [1.0 / N] * N                      # 初始权重均等
est = []                          # 每步的加权均值

def resample(parts, wts):
    # 系统重采样：按累积权重等间隔取点，权重大的粒子被复制更多次
    cum = []
    s = 0.0
    for w in wts:
        s = s + w
        cum.append(s)             # 累积权重
    u0 = random.random() / len(parts)
    out = []
    idx = 0
    for i in range(len(parts)):
        target = u0 + i / len(parts)
        while cum[idx] < target:  # 找到 target 落在哪个累积区间
            idx = idx + 1
        out.append(parts[idx])
    return out

for t in range(T):
    # ① 预测：每个粒子按运动模型前进，再加一点过程噪声
    for i in range(N):
        particles[i] = particles[i] + 1.0 + random.gauss(0, q)
    # ② 加权：离观测越近，似然越大
    total = 0.0
    for i in range(N):
        d = obs[t] - particles[i]
        weights[i] = math.exp(-d * d / (2 * R))
        total = total + weights[i]
    for i in range(N):
        weights[i] = weights[i] / total
    # ③ 估计（加权均值）+ ④ 查退化
    m = 0.0
    sq = 0.0
    for i in range(N):
        m = m + weights[i] * particles[i]
        sq = sq + weights[i] * weights[i]
    est.append(m)
    if 1.0 / sq < N / 2:          # 有效样本量掉到一半以下就重采样
        particles = resample(particles, weights)
        weights = [1.0 / N] * N
# 对账：粒子滤波误差 vs 直接用观测的误差
err = 0.0
oerr = 0.0
for t in range(T):
    err = err + (est[t] - true_x[t]) ** 2
    oerr = oerr + (obs[t] - true_x[t]) ** 2
print(round(est[-1], 2))          # 末步估计位置
print(round(true_x[-1], 2))       # 末步真实位置
print(round(obs[-1], 2))          # 末步原始观测
print(round((err / T) ** 0.5, 3)) # 滤波的均方根误差
print(round((oerr / T) ** 0.5, 3))# 观测本身的均方根误差
```

输出 `39.15`、`39.0`、`36.35`、`1.381`、`2.141`。读法：末步真实位置 39.0 米，原始观测抖到 36.35 米（噪声害的），**粒子滤波给出 39.15 米——把噪声压了回去**。整段轨迹的均方根误差 1.381 米，明显低于观测本身的 2.141 米。**粒子滤波的价值不在单点准，而在把逐帧噪声平滑掉、并顺手给出不确定度。**

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为粒子越多越好，无脑加到十万。" 粒子数增加确实降低蒙特卡洛误差，但计算量线性上涨；而且维度一高（比如 20 维状态），需要的粒子数会**指数爆炸**——这叫维数灾难。工程上通常几百到几千，配合更好的提议分布（而不是盲目加粒子）才划算。**精度和算力永远要做交易。**

**误区二**："你以为重采样是干净的免费操作。" 重采样会**降低粒子多样性**：被复制多次的粒子让云团出现大量重复点，短时间看挺好，长期却会让估计变得粗糙（样本贫化）。这就是为什么不能每步都重采样——要等 ESS 掉到阈值以下再动手；进阶做法还会在重采样后加一点抖动（roughening）把多样性补回来。

**误区三**："你以为粒子滤波是卡尔曼的升级版，可以替代它。" 方向反了。**线性高斯模型下卡尔曼滤波是精确最优解**，又快又准；粒子滤波只是近似，还得撒一堆粒子。正确的心智模型是：先试卡尔曼，模型真的非线性/非高斯了再换粒子滤波。把它当成"通用但昂贵"的备胎，而不是默认首选。

:::

## 7. 练习

**练习 1**：下面这段代码在算有效样本量，但它返回的其实是 $\sum w^2$ 本身，不是 ESS。修到输出 `100.0` 与 `1.02`：

```exercise
# @title: 练习：权重退化有多严重
# @check: 100.0
# @check: 1.02
# @hint: ESS = 1 / Σw²。均匀权重时 ESS = N；权重集中到一个粒子时 ESS 趋近 1。初始代码忘了取倒数。
n = 100
w_even = [1.0 / n] * n                 # 权重全均等
sq = 0.0
for x in w_even:
    sq = sq + x * x
ess_even = 1.0 / sq                    # 这一行是对的
print(round(ess_even, 1))              # 应当是 100.0

w_bad = [0.99] + [0.01 / (n - 1)] * (n - 1)   # 一个粒子独吞 99% 权重
sq_bad = 0.0
for x in w_bad:
    sq_bad = sq_bad + x * x
ess_bad = sq_bad                       # ← 错了：ESS 是 1/Σw²
print(round(ess_bad, 2))               # 应当是 1.02
```

<details>
<summary>点开查看逐步解答</summary>

把最后一步取倒数：

```py
ess_bad = 1.0 / sq_bad    # 1 / 0.9801 ≈ 1.02
print(round(ess_bad, 2))  # 1.02
```

均匀权重时 $\sum w^2 = n \cdot (1/n)^2 = 1/n$，所以 $\mathrm{ESS} = n = 100$，全部粒子都在干活。而一个粒子独吞 99% 权重时，$\sum w^2 \approx 0.98$，$\mathrm{ESS} \approx 1.02$——**名义上 100 个粒子，实际上只剩 1 个在说话**。这正是权重退化的判据：不看粒子总数，只看 ESS。

</details>

**练习 2**：在这门课的跟踪实验里，如果把重采样那一段（实验 2 的第 ④ 步）整段删掉，会发生什么？请从"权重分布"和"估计精度"两个角度预测，再实际跑一遍验证。

<details>
<summary>点开查看逐步解答</summary>

**权重分布**：删掉重采样后，权重在每一步都乘上一个似然因子，越乘越悬殊。跑不到二三十步，几乎所有权重都会集中到极少数粒子上，$\mathrm{ESS}$ 掉到个位数。

**估计精度**：短期（前几步）估计可能还行，甚至因为保留了全部粒子而略好；但一旦 ESS 塌缩，加权均值就退化成"几个幸运粒子的平均"，估计开始随机跳变、抖动变大，长期误差反而上升。而且**后期即使观测很有信息也救不回来**——粒子云已经不再覆盖真实位置，更隐蔽的是它会逐渐"漂移"到错误的地方再也回不去（没被复制的粒子彻底消失了）。**重采样不是锦上添花，而是让滤波长期活下去的呼吸机。**

</details>

## 8. 选读：重要性采样为什么成立

<details>
<summary>选读 · 用另一把尺子量同一块面积</summary>

粒子滤波的数学地基是**重要性采样**。想估计函数 $g$ 在目标分布 $p(x)$ 下的期望，但 $p$ 不好直接抽样，就借一个容易抽样的**提议分布** $q$，把期望改写成在 $q$ 下的形式：

$$E_p[g] = \int g(x)\, \frac{p(x)}{q(x)}\, q(x)\, \mathrm{d}x = E_q\!\left[ g(x)\, \frac{p(x)}{q(x)} \right] \approx \sum_{i=1}^{N} g(x^{(i)})\, \tilde w^{(i)}, \qquad x^{(i)} \sim q,$$

权重 $\tilde w^{(i)} \propto p(x^{(i)})/q(x^{(i)})$ 的作用是"把 $q$ 的量尺换算成 $p$ 的量尺"——**只要 $q$ 覆盖了 $p$ 的支撑集，这套换算就无偏**。

搬到序贯场景后，因为后验满足 $p(x_t \mid z_{1:t}) \propto p(z_t \mid x_t)\, p(x_t \mid z_{1:t-1})$，权重可以**递推**更新：$w_t^{(i)} \propto w_{t-1}^{(i)}\, p(z_t \mid x_t^{(i)})$——这正是粒子滤波第 2 步的来历。ESS 也不是拍脑袋：权重全均等时 $\sum w^2 = 1/N$ 给出 $N$，越集中 $\sum w^2$ 越大、ESS 越小，它精确度量了"权重被少数人垄断"的程度。ESS 塌缩的根源是权重方差随步数累积——**这就是长序列里必须反复重采样、乃至必须引入更好提议分布的数学原因。**

</details>
