# 概率图模型：联合分布拆成一张图

## 1. 从一个场景开始

深夜，家里的网络警报器"哔"地响了。可能的原因：盗贼入室（B）、地震晃动了传感器（E）。警报一响，邻居 John 大概率会打电话（J），邻居 Mary 也可能打电话（M）。一个问题、五个随机变量——想知道"John 打来电话时，家里真进贼的概率"，照第 36 章联合分布的老办法，得先把五变量联合分布写成一张 32 行的大表、填上 31 个参数。

可你心里的常识明明是分层的："盗贼和地震各自独立发生"、"警报只看盗贼和地震"、"两个邻居只看警报"。常识里的每一个"只看"，都在把大表剁成一小格一小格。这一课把这种直觉铸成机器：**概率图模型**——把联合分布拆成一张图，再把图拆回一连串小表。

## 2. 直觉解释

先看常识怎么剁表。五句话：

- 盗贼来不来，不看任何人：P(B)；
- 地震震不震，不看任何人：P(E)；
- 警报响不响，**只看**盗贼和地震：P(A | B, E)；
- John 打不打电话，**只看**警报（他不知道地震，更猜不到盗贼）：P(J | A)；
- Mary 同理：P(M | A)。

把它们连乘：

$$P(B, E, A, J, M) = P(B)\,P(E)\,P(A \mid B, E)\,P(J \mid A)\,P(M \mid A)$$

右边五个小因子加起来 10 个参数（1+1+4+2+2），左边大表要 31 个——变量越多差距越恐怖（实验 1 的账本）。每个"只看"都把一个变量从"跟全世界耦合"解放成"只跟几个邻居耦合"；把这些"只看"画成箭头（谁指向谁 = 谁直接影响谁），就得到一张有向图——**贝叶斯网络**。

图还免费附赠一句读法：**给定警报 A，John 打不打电话与震没震地震无关**——地震的全部影响都经警报中转了。这叫条件独立，记作 $J \perp E \mid A$。箭头顺着"影响的流向"铺开，条件独立就藏在图的拓扑里：看图读独立，比翻大表快得多。

## 3. 正式定义

**有向图模型（贝叶斯网络）**：取一张有向无环图（DAG，第 29 章拓扑排序课的老朋友——箭头不许绕圈），每个节点挂一个随机变量，联合分布按下面的规则拆解：

$$P(X_1, \dots, X_n) = \prod_i P(X_i \mid \text{Parents}(X_i))$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\text{Parents}(X_i)$ | 父节点集 | 箭头直接指向 $X_i$ 的变量们 |
| $P(X_i \mid \cdot)$ | 局部因子 | 每个节点自带的条件概率小表（CPT） |
| $X \perp Y \mid Z$ | 条件独立 | 缩小到 $Z$ 的世界里，$P(X, Y \mid Z) = P(X \mid Z)\,P(Y \mid Z)$ |
| 因子 | factor | 挂在变量组上的非负表格，消元时的运算对象 |

**变量消元**：求边缘或条件分布时，不必展开整张大表——把含某个变量的因子合并相乘，**沿着它求和**，把它折叠进一张小消息表，再处理下一个变量。每一步的中间产物都叫"消息"：把被消变量的一切可能打包，寄给还活着的邻居。

**sum-product 消息传递**：把消元的每一步看成图上的通信——每个节点收齐邻居寄来的消息，逐元素相乘（product），沿要求和的维度求和（sum），再把结果寄给下家。树状图上一次消息往返就能精确算完所有边缘；带环图上迭代着传，就是实用的近似算法。

顺带预告：**从图上直接读出全部条件独立**的几何判定规则叫 d-分离，第 42 章因果推断会在因果图上为条件独立颁发"几何身份证"——见 [DAG、路径与 d-分离](../42-causal-inference/60-d-separation.md)。本课先把"联合 = 因子乘积"这台机器造出来，并亲手跑一遍它的核心算法。

## 4. 分步例题

警报器网络填上真实感的数字（因子以 P(值为 1) 记，值为 0 时取补）：

| 因子 | 数值 |
| --- | --- |
| P(B=1) | 0.001 |
| P(E=1) | 0.002 |
| P(A=1 \| B,E) | (B,E)=(0,0): 0.001；(0,1): 0.29；(1,0): 0.94；(1,1): 0.95 |
| P(J=1 \| A) | A=0: 0.05；A=1: 0.90 |
| P(M=1 \| A) | A=0: 0.01；A=1: 0.70 |

**目标**：John 和 Mary 都来电话（J=1, M=1）之后，家里真进贼的概率 P(B=1 | J=1, M=1)。

1. **暴力路线**：展开 32 行大表，把 J=1、M=1 的行全加起来做分母、其中 B=1 的行做分子——每行乘 5 个数，共 160 次乘法；
2. **消元路线**：先消 E——合并 P(B)、P(E)、P(A|B,E)，沿 E 求和，得到 4 行小表 g(B,A)；再消 A——把 g 与 P(J|A)、P(M|A) 相乘，沿 A 求和，得到 8 行表 h(B,J,M)；最后在 J=1、M=1 处两行相除。第一步 24 次、第二步 48 次乘法，共 72 次；
3. **对账**：两条路线都给出约 **0.284**——0.1% 的先验在"两位邻居同时来电话"的证据下涨到 28%，而整套计算没碰过"32 行"这三个字；
4. **读图**：E 的 2 行、A 的 4 行小表就够用。图把"哪些变量必须见面"写在了箭头上——这就是拆图的全部秘密。

### 实验 3：暴力枚举 32 行（python）

```python title="警报器网络：五重循环铺开全联合大表"
fB = {(0,): 0.999, (1,): 0.001}     # P(B)：键是单元素元组——(1,) 的逗号不能省
fE = {(0,): 0.998, (1,): 0.002}     # P(E)
fA = {(0, 0, 0): 0.999, (0, 0, 1): 0.001,   # P(A | B,E)：键是三元组 (B, E, A)
      (0, 1, 0): 0.71,  (0, 1, 1): 0.29,
      (1, 0, 0): 0.06,  (1, 0, 1): 0.94,
      (1, 1, 0): 0.05,  (1, 1, 1): 0.95}
fJ = {(0, 0): 0.95, (0, 1): 0.05,   # P(J | A)：键 (A, J)
      (1, 0): 0.10, (1, 1): 0.90}
fM = {(0, 0): 0.99, (0, 1): 0.01,   # P(M | A)：键 (A, M)
      (1, 0): 0.30, (1, 1): 0.70}

joint = {}                          # 全联合大表：键是五元组 (B, E, A, J, M)
mults = 0                           # 乘法计数器
for b in (0, 1):                    # 逐个试 B 的两种取值
    for e in (0, 1):
        for a in (0, 1):
            for j in (0, 1):
                for m in (0, 1):
                    p = fB[(b,)] * fE[(e,)] * fA[(b, e, a)] * fJ[(a, j)] * fM[(a, m)]
                    joint[(b, e, a, j, m)] = p
                    mults = mults + 5          # 每行 5 次乘法

den = 0                             # 分母：证据 J=1, M=1 的总概率
for b in (0, 1):
    for e in (0, 1):
        for a in (0, 1):
            den = den + joint[(b, e, a, 1, 1)]
num = 0                             # 分子：证据在场且 B=1
for e in (0, 1):
    for a in (0, 1):
        num = num + joint[(1, e, a, 1, 1)]
print(f"乘法次数 {mults}")
print(f"P(B=1 | J=1, M=1) = {round(num / den, 4)}")
```

### 实验 4：变量消元对账（python）

```python title="同一张网：消 E 再消 A，72 次乘法算出同一个答案"
fB = {(0,): 0.999, (1,): 0.001}
fE = {(0,): 0.998, (1,): 0.002}
fA = {(0, 0, 0): 0.999, (0, 0, 1): 0.001,   # 键 (B, E, A)——与实验 3 相同的因子
      (0, 1, 0): 0.71,  (0, 1, 1): 0.29,
      (1, 0, 0): 0.06,  (1, 0, 1): 0.94,
      (1, 1, 0): 0.05,  (1, 1, 1): 0.95}
fJ = {(0, 0): 0.95, (0, 1): 0.05, (1, 0): 0.10, (1, 1): 0.90}   # 键 (A, J)
fM = {(0, 0): 0.99, (0, 1): 0.01, (1, 0): 0.30, (1, 1): 0.70}   # 键 (A, M)

g = {}                       # 消息表 g(B, A)：E 的一切影响打包在内
mults = 0
for b in (0, 1):
    for a in (0, 1):
        s = 0
        for e in (0, 1):
            s = s + fB[(b,)] * fE[(e,)] * fA[(b, e, a)]   # product：合并三个因子
            mults = mults + 3
        g[(b, a)] = s          # sum：沿 E 求和——E 从此退场

h = {}                       # 消息表 h(B, J, M)：A 的影响折叠进来
for b in (0, 1):
    for j in (0, 1):
        for m in (0, 1):
            s = 0
            for a in (0, 1):
                s = s + g[(b, a)] * fJ[(a, j)] * fM[(a, m)]
                mults = mults + 3
            h[(b, j, m)] = s

num = h[(1, 1, 1)]           # B=1 且两位邻居都来电话
den = h[(0, 1, 1)] + h[(1, 1, 1)]
print(f"乘法次数 {mults}")
print(f"P(B=1 | J=1, M=1) = {round(num / den, 4)}")
```

与实验 3 的 0.284 严丝合缝对上——乘法却从 160 次降到 72 次，而且省的幅度随变量数指数扩大。g 和 h 就是 sum-product 里的"消息"：**把一个变量的一切可能打包求和，寄给还活着的邻居**。

::::warning[常见误区]

**误区一**："图上的箭头就是因果。" 本课的箭头只记录"因子分解时谁挂在谁的条件里"——一种生成顺序的记账，某些箭头画反了照样能表示同一个联合分布。让箭头真正背上因果含义，要靠第 42 章的干预语言（do 算子）来升级。

**误区二**："画出图就完事了。" 图只是骨架，每个节点还挂着一张条件概率表；参数从数据或专家经验里来，而真正的计算开销在推断——消元、消息传递或采样（第 80 课的 MCMC 机器）。

**误区三**："变量消元永远快。" 消元顺序有讲究：坏顺序会把小表合并成大表，中间产物的最大宽度（树宽）由图的结构决定；找最优顺序本身是 NP 困难问题。实践靠启发式排序，或干脆换近似算法。

::::

## 6. 练习

**练习 1**：三变量链 A → B → C：P(A=1) = 0.6，P(B=1 | A) 在 A=1 时 0.9、A=0 时 0.2，P(C=1 | B) 在 B=1 时 0.75、B=0 时 0.1。先手算 P(B=1)，再算 P(C=1)。

<details>
<summary>点开查看逐步解答</summary>

P(B=1) = 0.6×0.9 + 0.4×0.2 = 0.62——这一步正是"消 A"：沿 A 求和把 P(A) 与 P(B|A) 合并成 B 的边缘。P(C=1) = 0.62×0.75 + 0.38×0.1 = 0.503。链上两次"沿中间变量求和"，就是最简版的变量消元。
</details>

**练习 2**：同一张链 A → B → C 的因子已经摆在代码里。把"消 A"与"算 P(C=1)"两步补全（初始代码漏乘了先验因子与条件因子），改到通过：

```exercise
# @title: 练习：把消息表寄出来
# @check: 0.62
# @check: 0.503
# @hint: 消元 = 合并（乘因子）+ 折叠（沿被消变量求和）。第一步沿 a 求和，别忘了乘 P(A)；第二步把 h 与 P(C|B) 相乘后再沿 b 求和。
fA  = {(0,): 0.4, (1,): 0.6}                                 # P(A)
fBA = {(0, 0): 0.8, (0, 1): 0.2, (1, 0): 0.1, (1, 1): 0.9}   # P(B | A)：键 (a, b)
fCB = {(0, 0): 0.9, (0, 1): 0.1, (1, 0): 0.25, (1, 1): 0.75} # P(C | B)：键 (b, c)

h = {}                       # 消息表 h(b)：A 的影响折叠进来
for b in (0, 1):
    s = 0
    for a in (0, 1):
        s = s + fBA[(a, b)]              # ← 只拿了条件因子：P(A) 的先验去哪了？
    h[(b,)] = s

p_c = h[(0,)] * fCB[(0, 1)] + h[(1,)]    # ← 第二项也欠着自己的条件因子
print(round(h[(1,)], 2))
print(round(p_c, 3))
```

**练习 3**：警报器网络里，J 与 E 无条件时独立吗？给定 A=1 之后呢？（提示：算算 P(J=1, E=1) 与 P(J=1)·P(E=1) 比一比。）

<details>
<summary>点开查看逐步解答</summary>

无条件时**不**独立：P(J=1, E=1) ≈ 0.000594，而 P(J=1)·P(E=1) ≈ 0.0521×0.002 ≈ 0.000104——前者约是后者的 5.7 倍。结构原因：E 与 J 处在"共果 A"的两端（对撞结构），警报同时被两者影响，边缘化掉 A 之后两者仍纠缠。给定 A=1 后：P(J=1 | A=1, E) = 0.90 与 E 无关——J 的因子只挂 A，地震的影响已被 A 全额中转，$J \perp E \mid A$ 成立。条件独立在图上一眼可读；第 42 章的 d-分离会把这套读法升级成完整的几何判定规则。
</details>

## 7. 选读：消元顺序与树宽

<details>
<summary>选读 · 推断的价格为什么由图的形状决定</summary>

消元一个变量 = 把它所有邻居的因子合并成一张新表，新表的宽度约等于"邻居数"——坏顺序会让中间表越滚越大，最坏时退回全联合大表。一张图在最优消元顺序下的最大中间表宽度叫**树宽**，它就是在这张图上做精确推断的价格标签。链与树最便宜：sum-product 让消息从叶子流向根、再流回来，两趟扫描精确算出全部边缘——警报器网络的两次消元正是它的缩影。一般有环图上，让消息在环里迭代传递（loopy belief propagation）或改用抽样（第 80 课的 MCMC）都是实用退让。再往下游看：第 53 章图网络上的消息传递、第 47 章 Transformer 里的注意力，都是"节点间互寄信息"这个直觉的工程化身——而它最早的精确形态，就是本课因子图上的 sum-product。

</details>
