# 频率派与贝叶斯：一场世纪之争

## 1. 从一个场景开始

同一批临床数据摆上会议桌。统计师甲（频率派）汇报："10 人中 7 人痊愈；相对 50% 历史基准，95% 置信区间是 (0.42, 0.98)，正态近似 p 值约 0.34。"统计师乙（贝叶斯）汇报："无信息先验下，95% 可信区间约 (0.39, 0.89)；痊愈率超过 70% 的后验概率约 43%（把握方向反过来：不超过 70% 的概率约 57%）。"

数字接近，回答的问题却不同——甲坚称"参数是固定的，谈它的概率没有意义"；乙直接说"就眼前这批数据而言，参数落在哪一段最可信"。吵了快一百年，这一课把两套语言的字典并排放好。

## 2. 直觉解释

分歧的根源只有一个问题：**未知参数算不算随机变量？**

- **频率派**说不算。真实转化率是一个写死的数，随机的是抽到的样本。一切结论必须挂在"长期重复"上：覆盖率、错误率、p 值，全是想象中无限次重复实验的频率。
- **贝叶斯**说可以算。我反正不知道真值，就用一个分布来表达"我的不确定"；拿到数据后按贝叶斯公式更新。概率是"信念的度量"，不必绑定重复试验。

打个比方：频率派像鉴定师，只肯对可反复检验的流程发证书；贝叶斯像侦探，随时愿意给"凶手就是他"标个把握百分比。**流程证书**适合流水线质检，**把握度**适合一次性的决策。

## 3. 正式定义

同一份二项数据 $k$ 成功、$n$ 次试验，两种报告的对照：

| 维度 | 频率派 | 贝叶斯 |
| --- | --- | --- |
| 参数地位 | 固定未知常数 | 随机变量（携带不确定性分布） |
| 核心工具 | 似然 $L(\theta)\propto\theta^{k}(1-\theta)^{n-k}$ | 先验 $\times$ 似然 $\to$ 后验 |
| 区间名称 | 置信区间 | 可信区间 / 后验区间 |
| 区间解释 | 反复使用此配方，约 95% 的区间盖住真值 | 给定眼前数据，参数有 95% 的概率落在其中 |
| 显著性问题 | p 值对红线 | 后验概率 / 贝叶斯因子 |

两者共享同一座桥——**似然函数**。区别只在桥那头接什么：频率派让似然单独发言，贝叶斯给似然配了先验的底色。数据越多，先验底色越淡，两派的数字越靠拢（第 20 课实验 2 亲眼看过这个收敛）。

## 4. 分步例题

**例**：10 位患者 7 位痊愈。分别给出两种 95% 区间（频率派用正态近似公式，贝叶斯取无信息先验 Beta(1,1)，故后验为 Beta(8, 4)）。

1. 频率派：$\hat{p}=0.7$，$\mathrm{SE}=\sqrt{0.7\times0.3/10}\approx 0.145$，区间 $0.7\pm1.96\times0.145=(0.42,\ 0.98)$；
2. 贝叶斯：后验 Beta(8, 4)，在网格上数出中央 95% 质量范围约 $(0.39,\ 0.89)$；
3. 对照：两条带子位置接近但**含义不同**——前者说的是配方的长期战绩，后者直接陈述"就这批数据而言，痊愈率的把握范围"；
4. 关键差别在小样本：n 很大时两带几乎重合；n 小、尤其观测到极端比例（如 0/10 或 10/10）时，正态近似的置信区间会给出荒谬结果（比如越过 1），而后验区间永远安分地待在 (0,1) 内。

### 实验 2（python）：亲手数出可信区间

不查任何表，在网格上把 Beta(8,4) 的中央 95% 质量切出来：

```python title="网格法求 95% 可信区间，并与频率派公式对照"
import math   # 幂运算之外再备一个开方

k, n = 7, 10            # 数据：10 位患者 7 位痊愈
a_post, b_post = 1 + k, 1 + (n - k)   # Beta(1,1) 先验经共轭更新的后验参数

grid = []               # 存 (theta, 未归一化密度) 对
steps = 2000
for i in range(steps):
    theta = 0.0005 + i * (0.999 / steps)
    w = theta ** (a_post - 1) * (1 - theta) ** (b_post - 1)   # Beta 密度的形状部分
    grid.append((theta, w))

total_w = 0             # 归一化：先把总质量数出来
for _, w in grid:
    total_w = total_w + w

cum = 0                 # 扫描累积质量，找 2.5% 与 97.5% 的分界点
low = high = None       # None 表示「还没找到」（首见用法）
for theta, w in grid:
    cum = cum + w / total_w
    if low is None and cum >= 0.025:
        low = theta
    if cum >= 0.975:
        high = theta
        break

phat = k / n                                     # 频率派点估计
se = math.sqrt(phat * (1 - phat) / n)            # 正态近似的标准误
f_lo, f_hi = phat - 1.96 * se, phat + 1.96 * se  # 频率派置信区间

print(f"贝叶斯可信区间: ({low:.2f}, {high:.2f})")
print(f"频率派置信区间: ({round(f_lo, 2)}, {round(f_hi, 2)})")
```

两个区间几乎重叠（这正是无信息先验常被批评"不够贝叶斯"的原因）。试着把 `a_post, b_post` 改成 `1 + k, 1 + (n - k)` 之外的强先验组合，看后验区间如何搬家而频率派纹丝不动——**这是两派最本质的分野时刻**。

### 快问快答

```quiz
医生问：「就这位病人这批检测结果而言，有效概率多大？」哪一派的语言能直接回答？
- 频率派：p 值就是这个概率
- 贝叶斯：后验概率直接回答 [*]
- 两派都答不了
? 「给定数据后假设的概率」只有贝叶斯框架合法拥有。p 值方向相反（给定假设看数据），答非所问。一次性决策场景是贝叶斯的主场。
```

:::warning[常见误区]

**误区一**："你以为两派必有一派对。" 它们回答的问题不同：可重复的流程质量问频率派，单次事件的把握程度问贝叶斯。工业界成熟做法是双轨并行——A/B 平台用频率派守门，定价与风控用贝叶斯更新。

**误区二**："你以为可信区间和置信区间只是改名。" 数字常常接近，语义完全不同：可信区间可以对单一案例直接陈述概率，置信区间永远只能说配方的历史战绩。混用术语会让听众误读整整一层含义。

**误区三**："你以为贝叶斯不需要检验显著性。" 它有对应的武器（后验概率、贝叶斯因子、ROPE 决策规则），同样要防多重比较和偷看。换了语言不等于免做功课，纪律问题在两派世界同样存在。

:::

## 实战挑战 · A/B 测试的贝叶斯决策

某购物车页做 A/B 测试：新版 400 人里 120 人下单，旧版 400 人里 96 人下单。给两个转化率都配无信息先验 $\mathrm{Beta}(1,1)$，分别得到独立后验；产品经理真正想问的不是“点估计差多少”，而是“新版更好的把握有多大”。

```exercise
# @title: 实战挑战：写出两组后验并计算观察提升
# @check: 121
# @check: 281
# @check: 97
# @check: 305
# @check: 0.06
# @hint: Beta-Binomial 更新时成功参数加成功数、失败参数加失败数；观察提升用两个裸频率相减
a_success, a_fail = 120, 280   # 新版成功/失败人数
c_success, c_fail = 96, 304    # 旧版成功/失败人数

a_post = 1 + a_success         # 新版后验 Beta 的 a 参数（已示范）
b_post = 1 + a_fail            # 新版后验 Beta 的 b 参数（已示范）
c_post = c_success             # ← 问题在这：旧版也必须从先验出发
d_post = c_fail                # ← 这里同样漏掉了先验
p_new, p_old = a_success / 400, c_success / 400
lift = round(p_new - p_old, 2)

print(a_post)
print(b_post)
print(c_post)
print(d_post)
print(lift)
```

<details>
<summary>点开查看逐步解答</summary>

```python
a_success, a_fail = 120, 280
c_success, c_fail = 96, 304
print(1 + a_success)
print(1 + a_fail)
print(1 + c_success)
print(1 + c_fail)
print(round(a_success / 400 - c_success / 400, 2))
```

两组都从 $\mathrm{Beta}(1,1)$ 出发，所以新版后验是 $\mathrm{Beta}(121,281)$，旧版后验是 $\mathrm{Beta}(97,305)$。观察提升为 $120/400-96/400=0.06$，也就是 6 个百分点。但这只是描述差异；要回答“新版更好的把握”，还必须比较两条完整后验分布。

</details>

下面的网格法把两个参数区域扫一遍：只要抽样到的 $p_{\text{new}}>p_{\text{old}}$，就把联合未归一化密度记入分子。结果显示新版更好的后验概率约为 **97.2%**。

```python title="A/B 后验：P(新版转化率更高)"
n_grid = 400                    # 每个方向的网格数；400×400 已足够给出三位小数
numerator = 0                   # “新版更好”区域的加权质量
denominator = 0                 # 全部网格的总质量

for i in range(n_grid):
    p_new = (i + 0.5) / n_grid       # 避免正好落在 0 或 1
    for j in range(n_grid):
        p_old = (j + 0.5) / n_grid
        w_new = p_new ** 120 * (1 - p_new) ** 280   # Beta(121,281) 形状部分
        w_old = p_old ** 95 * (1 - p_old) ** 303    # Beta(97,305) 形状部分
        weight = w_new * w_old                      # 独立后验的联合权重
        denominator = denominator + weight
        if p_new > p_old:
            numerator = numerator + weight

print(round(numerator / denominator, 3))
```

```quiz
A/B 决策会上最贴近这个贝叶斯结果的结论是？
- 新版一定能让每一组用户提高 6 个百分点
- 观察数据显示新版更好的后验概率约 97%，但上线后仍需持续监控 [*]
- p 值小于 0.05 才允许提到任何“更好”
? 贝叶斯结果量化了当前证据下的参数排序把握；它不保证未来个体结果，也不取消持续监控、样本质量和业务成本判断。
```

## 7. 选读：争论如何走向休战

<details>
<summary>选读 · 实用主义的胜利</summary>

二十世纪上半叶两派论战激烈到人身攻击（费希尔骂贝叶斯方法是"谬论的摇篮"）。转折来自计算时代：MCMC 让任意模型的后验变得可算（下一卷的主角），机器学习又全面拥抱贝叶斯式的概率预测；与此同时，频率派的大规模 A/B 基础设施证明了它在流程把关上的可靠。当代统计学的主流姿态是工具箱主义：**先问清你要对谁负责——对流程还是对这一次决策——再挑语言。**

</details>
