# 可数性与基数入门

## 1. 从一个场景开始

希尔伯特旅馆有无穷多个房间，客满。深夜来了新客人，经理广播："请 1 号房客人搬去 2 号，2 号搬去 3 号……人人后移一格。"1 号房空出，新人入住——**无穷旅馆永远有房**。

第二天，无穷位新客人排成长队。经理再广播："请 $n$ 号客人搬去 $2n$ 号。"奇数号房间全部腾空，无穷位新人各得其所。

有限世界里这些操作会立刻失败；在无穷世界它们却合法。这说明：**无穷不服从日常直觉，必须重新定义"一样多"**。

## 2. 直觉解释

上一课的口号现在升格为定义：两个集合**等势**（基数相同），当且仅当存在双射把一方逐个配给另一方。

- 自然数 $\mathbb{N}$ 与偶数集：$n \leftrightarrow 2n$ 是双射——所以它们**一样多**！虽然"感觉上"少了一半；
- 整数 $\mathbb{Z}$ 与自然数：把整数按 $0,\ 1,\ -1,\ 2,\ -2, \dots$ 排成一队编号即可——正负两岸轮流过桥。

凡是能与 $\mathbb{N}$ 一一配对的集合叫**可数无限**（基数 $\aleph_0$）。可数并不意味着能从头数到尾，只意味着**每个元素终会在某个有限时刻被点到名**。

真正的问题是：有没有连这个资格都拿不到的集合？康托尔的回答是：有，而且就在你眼前——实数区间。

## 3. 正式定义

集合 $A$ **可数**，当且仅当 $A$ 有限或存在从 $\mathbb{N}$ 到 $A$ 的满射（等价地，$A$ 与 $\mathbb{N}$ 的某子集等势）。

| 集合 | 基数 | 配对方案 |
| --- | --- | --- |
| 偶数集 | $\aleph_0$ | $n \mapsto 2n$ |
| 整数 $\mathbb{Z}$ | $\aleph_0$ | 蛇形轮转 $0,1,-1,2,-2,\dots$ |
| 有理数 $\mathbb{Q}$ | $\aleph_0$ | 矩阵对角线扫描（见实验 1） |
| 实数区间 $(0,1)$ | 严格更大 | 康托尔对角线证明不可数 |

**康托尔对角线法**：把实数区间 $(0,1)$ 假想成一张无限小数串清单，再逐位翻转第 $n$ 行的第 $n$ 位，就造出一个不在清单中的串，因此 $|\mathbb{R}| > |\mathbb{N}|$。更一般的**康托尔定理**进一步说：任何集合 $A$ 与其幂集 $2^A$ 之间都不存在满射。无穷不止一个层级——这是 19 世纪数学最惊人的发现之一。

## 4. 分步例题

**例**：证明正有理数可数。思路是把它们摆进无穷矩阵：

1. 第 $i$ 行第 $j$ 列写分数 $\frac{i}{j}$（$i, j \in \mathbb{N}^+$）——所有正有理数都出现（还会重复，如 $\frac{1}{2}=\frac{2}{4}$）；
2. 沿反对角线蛇形扫描：$(1,1) \to (1,2),(2,1) \to (3,1),(2,2),(1,3) \to \cdots$；
3. 每条对角线上分子分母之和相同，是**有限的**——扫描保证每个格子终被访问；
4. 跳过重复项与未约分项，得到一列不重不漏的清单。于是 $\mathbb{Q}^+$ 与 $\mathbb{N}$ 等势。

关键洞察：二维的"无穷乘无穷"并不可怕，只要能切成有限大小的层（对角线），就能排队点名。

## 5. 动手实验

### 实验 1（python）：对角线扫过的次序长什么样

```python title="画出 N×N 网格的对角线扫描路径"
import matplotlib.pyplot as plt

points = []                        # 收集扫描经过的格子坐标
for s in range(2, 11):             # 对角线编号 s = 行+列，从 2 开始
    for i in range(1, s):
        j = s - i                  # 同一条对角线上行与列此消彼长
        points.append((i, j))

xs = [p[0] for p in points]        # 列表推导式：对每个 p 取 p[0]，收集成新列表
ys = [p[1] for p in points]
fig, ax = plt.subplots(figsize=(6, 5))
ax.scatter(xs, ys, s=90, c=range(len(points)), cmap="viridis")   # c=按先后顺序上色
ax.plot(xs, ys, linewidth=0.8, alpha=0.5)
for idx, (px, py) in enumerate(points[:12]):    # enumerate：同时给出下标和元素
    ax.text(px + 0.08, py + 0.08, str(idx), fontsize=9)
ax.set_xlabel("i")
ax.set_ylabel("j")
```

颜色从深紫到亮黄就是点名次序。注意每条对角线的格子数是 $1, 2, 3, \dots$——**有限层叠成无穷**，这正是可数性的构造精髓。

### 实验 2（python）：康托尔对角线——亲手造一个"漏网之数"

```python title="翻转对角线，制造不在表中的序列"
rows = [
    "000",
    "111",
    "010",
]                              # 假装这是一张无穷清单的前三行（每位取自一个实数的二进制展开）

anti = ""                      # 目标串：与每一行都至少一位不同
for k in range(len(rows)):     # len()：列表长度
    digit = rows[k][k]         # 第 k 行的第 k 位：对角线上的字符
    if digit == "0":
        anti = anti + "1"
    else:
        anti = anti + "0"      # 翻转：保证与第 k 行在第 k 位分道扬镳
print(anti)

differs_from_row = []
for k in range(len(rows)):
    differs_from_row.append(anti[k] != rows[k][k])   # != 对字符串逐位比较
print(differs_from_row)
```

输出 `101` 和 `[True, True, True]`。无论清单多长、构造多狡猾，对角线翻转总能产出一个**必然缺席**的新串。把表补到一万行？反证法说：那就翻转一万位——新串依然不在表中。

这里先比较的是无限串本身。若把它们直接当作二进制小数，还要处理 $0.0111\cdots = 0.1000\cdots$ 这类双写；严格的实数版证明常改用三进制展开或区间套来绕开这个技术坑。

:::warning[常见误区]

**误区一**：你以为"偶数是自然数的一半"所以基数更小。比较无穷集合只认双射，不认子集关系或"占比"；直觉在这里没有投票权。

**误区二**：你以为可数=可以按大小顺序数完。可数只要求**存在某种**排队方式；有理数按数值排序根本排不出来（任意两数之间还有无数个数），但对角线扫描照样收编它。

**误区三**：你以为无理数只是"少数捣乱分子"。事实相反：可数集合在实数中的占比是零测意义上的尘埃，不可数的无理数才是大陆本身。
:::

## 6. 练习

```quiz
下列哪个集合与自然数集不等势？
- 全体奇数
- 全体整数
- 0 到 1 之间的全体实数 [*]
? 奇数和整数都能排出队伍；而对角线论证证明实数区间不可数。
```

**练习 1**：写出自然数集与"完全平方数集"之间的显式双射。

<details>
<summary>点开查看逐步解答</summary>

映射 $n \mapsto n^2$ 即可：不同的平方根给出不同的平方（单射），每个完全平方数都是某数的平方（满射）。平方数在数轴上越来越稀疏，却丝毫不影响它与全体自然数等势——"稀疏"是几何印象，"等势"是代数事实。
</details>

**练习 2**：对角线程序已经能跑，但它只是抄了对角线、忘了翻转，产出的串恰好撞上第三行。修好它：

```exercise
# @title: 补全康托尔翻转
# @check: 101
# @hint: 新串的第 k 位必须与旧表第 k 行的第 k 位相反。初始代码原样照抄，抄出来的串恰好就是清单的最后一行。
rows = ["000", "111", "010"]

anti = ""
for k in range(len(rows)):
    digit = rows[k][k]
    anti = anti + digit        # ← 问题在这：照抄不是对抗，需要翻转 0 与 1
print(anti)
```

修好后输出 `101`。初始版本抄出的 `010` 正好是第三行自己——这份"假清单"当场演示了为什么必须翻转：**不与每一行正面顶牛，就挤不进"缺席者"的安全区**。

## 7. 选读：比不可数更高的塔

<details>
<summary>选读 · 幂集阶梯与连续统假设</summary>

康托尔定理说幂集永远严格更大，于是基数形成无尽阶梯：$\aleph_0 < |2^{\mathbb{N}}| < |2^{2^{\mathbb{N}}}| < \cdots$。第一个悬案是：实数基数是否恰为 $|2^{\mathbb{N}}|$（连续统假设）？1938 年哥德尔与 1963 年科恩联手证明：**它在标准公理体系内既不能证实也不能否证**——数学第一次发现自家地基上有一扇推不开也锁不死的门。本站知识图谱里"可计算性"章的图灵停机问题，正是用对角线思想在计算世界的回声。
</details>
