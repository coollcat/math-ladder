# 极图与 Ramsey：最少多少边逼出团，最多多少点必同色

## 1. 从一个场景开始

一个校友平台要在用户之间连"同班"这条边。产品经理提了一个硬约束：**任何 6 个人里都不许出现"三人两两都是同班"的小圈子**（小圈子会让推荐算法失效）。技术团队反问：那在这个人数规模下，我们最多还能连多少条边？

这是个"反向"的问题。前面十几课都在问"这张图有什么性质"，这一课问的是：**给一个禁令，图的边数最多能堆到多高？** 一旦越过某个数，某种结构就躲不掉了。同样的追问换个说法还有另一个版本：一场聚会至少要来多少人才保证"必有三人互相认识或互相不认识"？答案是 6——小得让人吃惊。

## 2. 直觉解释

**先做第一件反直觉的观察：想躲开三角形，"均匀地分两拨"是最省边的策略。**

把 5 个点分成两拨，$2$ 个和 $3$ 个，只在**拨与拨之间**连边（这叫完全二分图 $K_{2,3}$）。同一拨里的点互不相连，所以任何三角形都凑不齐第三个边——可它却有 $2\times3=6$ 条边。相比之下，两两相连的 $K_5$ 有 10 条边，三角形多到数不清。

**第二件反直觉的事更妙：躲得开不等于躲得久。** 5 个点可以坦然避开单色三角形，但再加一个点，就必输。原因只有抽屉原理一句话——把 6 个点里的某一个拿出来看，它和其余 5 个点之间有 5 条边，每条边非红即蓝，于是**必有 3 条是同色的**。

极图问题问的是"边够多时会不会出现某种结构"，Ramsey 问题问的是"点够多时会不会出现某种着色模式"。两条追问的骨架其实是同一根：**结构在密度或规模超过阈值后不可避免**。

## 3. 正式定义

**定义一（极图与 Turán 数）**：给定禁用的子图 $H$，记

$$\operatorname{ex}(n,H)=\max\lbrace\,|E(G)|: G \text{ 有 } n \text{ 个顶点且不含 } H \text{ 作为子图}\,\rbrace$$

即"含 $n$ 个点、又不让 $H$ 出现"的图中边数的最大值。

**定理（Mantel）**：$\operatorname{ex}(n,K_3)=\left\lfloor\dfrac{n^2}{4}\right\rfloor$——躲开三角形要付出的代价是**砍掉将近一半的边**。

**定理（Turán, 1941）**：对 $r\ge2$，**完全 $r$ 部图** $T_r(n)$（顶点尽量均分成 $r$ 部，部内不连、部间全连）是唯一达到 $\operatorname{ex}(n,K_{r+1})$ 的图，且

$$\operatorname{ex}(n,K_{r+1})=\Big(1-\frac1r\Big)\frac{n^2}{2}-\frac{s(r-s)}{2r},\qquad n=qr+s,\ 0\le s<r.$$

其中 $n=qr+s$、$0\le s<r$；当 $r\mid n$（即 $s=0$）时退化回 $\big(1-\frac1r\big)\frac{n^2}{2}$。

**定义二（Ramsey 数）**：$R(s,t)$ 是最小的正整数 $n$，使得**任意**给 $K_n$ 的每条边涂红或涂蓝之后，都必然出现红色的 $K_s$ 或蓝色的 $K_t$。

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $\operatorname{ex}(n,H)$ | 极图数 / Turán 数 | 一个**最大值**：边数上限 |
| $T_r(n)$ | Turán 图 | 完全 $r$ 部图，各部件数相差不超过 1 |
| $R(s,t)$ | Ramsey 数 | 一个**阈值**：点数到了就躲不掉 |
| $K_3$ | 三角形 / 3-团 | 最小的"团"，三点两两相连 |

## 4. 分步例题

**例 1（手算 $\operatorname{ex}(5,K_3)$）**：为什么 5 个点的无三角形图最多 6 条边？

1. 全部边共 $\binom52=10$ 条，先估个上限：三角形自由意味着每个点不能"同时连向一对相连的点"；
2. 构造下界：$K_{2,3}$ 有 $2\times3=6$ 条边且无三角形，所以 $\operatorname{ex}(5,K_3)\ge6$；
3. 上界（Mantel）：$\left\lfloor25/4\right\rfloor=6$，所以最多就是 6；
4. 结论：**7 条边必然逼出三角形**——这是本课第一个"密度阈值"。

**例 2（$R(3,3)$ 的下界：5 个点真的躲得开）**：把 $K_5$ 的 5 个点摆成正五边形。

1. 红色取五边形的 5 条边（构成 5 环），蓝色取剩下的 5 条对角线（也是一个 5 环）；
2. 红色图是 $C_5$，没有三角形；蓝色图同样是 $C_5$，也没有三角形；
3. 所以 $K_5$ 存在一种二着色，一个单色三角形都没有；
4. 这证明 $R(3,3)>5$。

**例 3（$R(3,3)$ 的上界：6 个点躲不开）**：

1. 任取一个顶点 $v$，它与其余 5 个点相连，5 条边、2 种颜色；
2. 抽屉原理：$5=2\times2+1$，必有一种颜色出现至少 3 次。设 $v$ 到 $a,b,c$ 三条边都是红色；
3. 看 $a,b,c$ 之间的三条边：**只要有任意一条是红的**（比如 $ab$），那么 $v,a,b$ 就是一个红色三角形；
4. 若一条红的都没有，$a,b,c$ 三条边全蓝，那它们本身就是蓝色三角形；
5. 两种情形必居其一，于是 $R(3,3)\le6$。结合例 2，得 $R(3,3)=6$。

### 实验 2（python）：把"最多 6 条"和"6 个点必输"都暴力验一遍

```python
def edges_of(n):
    out = []                      # 收集完全图 K_n 的所有边
    for i in range(n):
        for j in range(i + 1, n):
            out.append((i, j))    # append：往列表末尾追加一条边
    return out

def mono_triangles(n, mask, edges, two_color):
    red = []
    for i in range(n):
        red.append([False] * n)   # 邻接矩阵：red[i][j] 为真表示这条边染红
    for idx in range(len(edges)):
        if (mask >> idx) % 2 == 1:      # >> 右移、% 2 读末位：取第 idx 条边的颜色
            i, j = edges[idx]
            red[i][j] = True
            red[j][i] = True
    hits = 0
    for a in range(n):
        for b in range(a + 1, n):
            for c in range(b + 1, n):
                if red[a][b] and red[b][c] and red[a][c]:
                    hits = hits + 1     # 红三角
                elif two_color and (not red[a][b]) and (not red[b][c]) and (not red[a][c]):
                    hits = hits + 1     # 蓝三角：两条边都没染红
    return hits

e5 = edges_of(5)
best = 0
for mask in range(1 << 10):             # 1 << 10 = 1024：十位二进制穷举 5 点全部子图
    if mono_triangles(5, mask, e5, False) == 0:
        cnt = 0
        for idx in range(10):
            cnt = cnt + (mask >> idx) % 2
        if cnt > best:
            best = cnt
print("5 点无三角形的最大边数 =", best)

e6 = edges_of(6)
good = 0
for mask in range(1 << 15):             # 15 条边，2^15 = 32768 种二着色
    if mono_triangles(6, mask, e6, True) == 0:
        good = good + 1
print("K6 中躲开单色三角形的着色数 =", good)

pentagon = [(0, 1), (1, 2), (2, 3), (3, 4), (0, 4)]   # 五边形的五条边
mask5 = 0
for idx in range(len(e5)):
    if e5[idx] in pentagon:             # in：判断这个元素是否在列表里
        mask5 = mask5 + (1 << idx)      # 把第 idx 位点亮，表示这条边染红
print("K5 五边形反例里的单色三角形 =", mono_triangles(5, mask5, e5, True))
```

三行输出：`5 点无三角形的最大边数 = 6`、`K6 中躲开单色三角形的着色数 = 0`、`K5 五边形反例里的单色三角形 = 0`。第二行那个 0 就是 $R(3,3)\le6$ 的机器证明——**32768 种着色，一种都逃不掉**；第三行的 0 则是 $R(3,3)>5$ 的实证。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为点数一多，Ramsey 数会飞涨得很快。" 恰恰相反，起步非常小：$R(3,3)=6$ 只需要 6 个人。当然再往上就失控了——$R(3,4)=9$、$R(4,4)=18$，而 $R(5,5)$ 至今没人算出来。**小步慢走过的门槛，后面是一堵墙。**

**误区二**："你以为无三角形图可以很稠密。" Mantel 定理把话说死了：最多约 $n^2/4$ 条边，只占全部 $\binom n2$ 的一半左右。换句话说**三角形是廉价的**，任何图只要边数过半，三角形就必然出现，想躲开它必须主动扔边。

**误区三**："你以为 Turán 图的答案就是随便分两块。" 对禁止 $K_{r+1}$ 的一般情形，极值图是完全 $r$ 部图，$r=2$ 才是二分图这个特例。而且分块必须**尽量均匀**：若某部比另一部多出两个点，把多的那个挪过去就能多连一批边，反而更大。

:::

## 7. 练习

**练习 1**：Turán 图 $T_2(n)$ 就是把 $n$ 个点尽量均分成两拨后的完全二分图。下面的代码多除了一个 2，把它改对：

```exercise
# @title: 练习：完全二分图的边数
# @check: 4
# @check: 6
# @check: 9
# @hint: 完全二分图里每条边恰好连接左拨一个点与右拨一个点，所以边数就是两拨大小的乘积；"除以 2"是握手定理里数度数的做法，这里不存在重复计数。
def turan_edges(n):
    a = n // 2            # 较小的一拨（整除，向下取整）
    b = n - a             # 较大的一拨
    return a * b // 2     # ← 问题在这

for n in [4, 5, 6]:
    print(turan_edges(n))
```

初始代码打出 `2, 3, 4`；改完应为 `4, 6, 9`——正是 $\left\lfloor n^2/4\right\rfloor$ 在 $n=4,5,6$ 处的取值。注意 $n=5$ 时两拨是 2 与 3，**不能两边都取 2**，否则白白丢掉一条边的余量：均分不是"平均分"，是"差不超过 1"。

**练习 2**（概念）：证明 $R(3,3)\le6$ 时，为什么只需盯住"$v$ 的 5 条出边"就能收网？

<details>
<summary>点开查看逐步解答</summary>

关键在于把"$K_6$ 的任意着色"**归约到一个固定的局部结构**上：任取一个顶点 $v$（对称性保证选哪个都一样），它的 5 条边被两种颜色分割。抽屉原理 $5=2\times2+1$ 保证有一色至少 3 条——这是全部推力的来源。接下来那 3 个邻点之间的 3 条边穷尽了两种可能：沾红则与 $v$ 组成红三角，全蓝则自成蓝三角。**没有第三种情形**，故 $K_6$ 无处可逃。

这套"取一点 → 抽屉分色 → 检查内层"的三步套路，是 Ramsey 归纳证明的通用模板：证明 $R(s,t)$ 有限时，正是用 $R(s-1,t)$ 与 $R(s,t-1)$ 作为两条分支的规模上界，得到递推 $R(s,t)\le R(s-1,t)+R(s,t-1)$。用二项式系数配平它，就能一路推出 $R(s,t)\le\binom{s+t-2}{s-1}$ 的粗上界——前面第 28 章的杨辉三角在这里又露了一面。
</details>

## 8. 选读：Ramsey 数为什么几乎都算不出来

<details>
<summary>选读 · 从 6 到 43 的漫长爬行，与 Erdős 的外星人</summary>

已知的 Ramsey 数少得可怜：$R(3,3)=6$，$R(3,9)=36$，$R(4,4)=18$，$R(4,5)=25$。**$R(5,5)$ 的精确值在 43 与 48 之间，上下界之间空了 5 格，几十年没人填上**。困难在于两个方向都不好走：

- **下界**要靠具体构造：给出一种二着色，证明某个 $n$ 还躲得开。5 个点的五边形就是这么来的；但 $n$ 一大，构造空间爆炸。
- **上界**要靠穷尽论证：证明所有着色都躲不开。$K_{43}$ 有 $\binom{43}2=903$ 条边，$2^{903}$ 种着色——任何暴力枚举都不可能完成。

一条聪明的出路是**概率方法**：随机给每条边独立地染红或染蓝。用并集界算出"出现单色 $K_k$ 的概率小于 1"，就证明存在一种着色躲得开它，从而 $R(k,k)>2^{k/2}$。这条论证只用了两页纸，却是 Ramsey 理论最优雅的起点，也是"用概率证明存在性"的开山之作。

Erdős 讲过一则著名的寓言：外星人降临，要求人类交出 $R(5,5)$，否则毁灭地球。人类应该把全世界所有算力和数学家集中起来去找它。但如果外星人要的是 $R(6,6)$，那人类**不如直接和外星人开战**——因为找到它的希望渺茫得多。这就是组合爆炸的重量：门槛从 5 挪到 6，问题的性质已经完全变了。

</details>
