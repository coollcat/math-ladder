# 学习理论

学习理论不是教模型怎么训练，而是问训练成功意味着什么：多少样本才够？假设类太大会怎样？为什么现代大模型有时违反旧直觉？

5. [假设类容量与一致性：多大的模型学得会](./50-capacity-consistency.md)——前辈笔记里那本判定规则小抄有多厚，模拟考冠军的虚高就有多少：把“小抄厚度”写进泛化误差的账本；

10. [Scaling Laws：堆料背后的经验规律](./90-scaling-laws.md)——双对数坐标下散点落成一条直线，数亿美元砸进算力集群之前，董事会只想问一句：这条直线可信吗？

## 实战挑战 · 当排行榜撒谎：从鲸鱼叫声到疫苗有效度

这是本章的真实评估大题：第一幕看"被污染的选择成绩"，第二幕看"协议干净的疗效估计"。两者共同回答模型选择的前提——分数只在数据流程可信时才算数。

**第一幕 · 排行榜上的 99.73%**（真实事件）。2013 年，Kaggle 与康奈尔生态学家合办北太平洋右鲸音频识别赛。参赛者 Will Cukierski 发现了一个惊人的捷径：**完全不读音频**，只靠"文件大小（字节）+ 文件名里的时间戳"这类元数据特征做逻辑回归，就在排行榜拿下 0.9973 的 AUC——因为带鲸歌的片段在采集流程里被不同方式处理过，文件体积和毫秒字段悄悄记住了答案。主办方确认泄漏后重启比赛并修复数据：同一个模型的成绩跌到 **0.59**，几乎等于瞎猜。出处见 Kaggle 官方赛后复盘《The Leakage (and how it was fixed)》。

```quiz
鲸鱼竞赛里，"文件大小 + 时间戳"这类特征为什么被判死刑？
- 它们数值太大，模型消化不了
- 它们是数据处理流程的副产品：只在历史数据和排行榜里与标签挂钩，换批新录音就失灵 [*]
- 它们泄露了参赛者的身份信息
? 这就是数据泄漏：考场的答案顺着流程裂缝溜进了练习册。判断特征的金标准问句："部署时还能拿到它吗？它与标签的关联在部署时还存在吗？"
```

**第二幕 · 疫苗有效度的算术**（真实数据）。辉瑞/BioNTech 三期试验（Polack 等，《新英格兰医学杂志》2020）在无既往感染人群中共录得 170 例确诊：疫苗组 8 例（21720 人），安慰剂组 162 例（21728 人）。新闻标题的"有效度 95%"来自一条朴素公式：

$$\text{VE} = 1 - \frac{\text{疫苗组发病率}}{\text{安慰剂组发病率}}$$

注意这场试验的底气不止数字大——**随机分组**保证了两组人同源，发病率之差才敢读成因果之差；反事实比较的正式方法留给后续因果推断课。亲手把整条链算一遍：

```exercise
# @title: 实战挑战：把"95% 有效"一步步算出来
# @check: 36.8
# @check: 745.6
# @check: 4.9
# @check: 95
# @check: 88.9
# @hint: 发病率 = 发病数 ÷ 组内总人数，乘 100000 换算成"每十万人发病数"；风险比 rr = 疫苗组发病率 ÷ 安慰剂组发病率；VE = 1 − rr；(e) 用新数字 20、20000、180、20000 重走一遍流程
vax_cases = 8        # 疫苗组确诊病例（《新英格兰医学杂志》2020 最终分析）
vax_total = 21720    # 疫苗组人数
pla_cases = 162      # 安慰剂组确诊病例
pla_total = 21728    # 安慰剂组人数

risk_vax = vax_cases / vax_total        # 疫苗组发病率（小数）
print(round(risk_vax * 100000, 1))      # (a) 每 10 万人发病数（已示范）

risk_pla = pla_cases / pla_total
print(round(0))                         # ← 占位：(b) 安慰剂组每 10 万人发病数

rr = risk_pla / risk_vax                # ← 有 bug：风险比的分子分母放反了
print(round(rr * 100, 1))               # (c) 风险比写成百分数——修好后它应远小于 100

ve = 1 - rr                             # 疫苗有效度
print(round(ve * 100))                  # (d) 整数百分数

new_rr = (20 / 20000) / (180 / 20000)   # 另一场试验：疫苗组 20 例、安慰剂组 180 例，各两万人
ve_new = 1 - new_rr
print(round(0))                         # ← 占位：(e) 新试验的有效度（保留一位小数）
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** $8/21720 \times 100000 \approx 36.8$ ——疫苗组每十万人约 37 人发病。

**(b)** $162/21728 \times 100000 \approx 745.6$ ——安慰剂组每十万人约 746 人发病，是疫苗组的二十倍。

**(c)** 风险比 $\text{rr} = 36.83/745.62 \approx 0.0494$，即打了疫苗的风险只剩没打者的约 4.9%。初始代码把比值倒置会出现 2024% 的荒谬数字——风险比永远"处理组除以对照组"。

**(d)** $\text{VE} = 1 - 0.0494 \approx 0.9506$，取整即 **95%**——新闻标题的来源。VE 读作"接种使发病风险下降的比例"。

**(e)** 新试验中两组人数相同，$\text{rr} = 20/180 = 1/9$，$\text{VE} = 1 - 1/9 \approx 88.9\%$。

回看全程：这五次除法之所以敢被读成"疫苗让人少生病"，全押在**随机化**上——若两组是自愿报名 vs 拒绝接种，第 42 章的自选择偏差立刻接管账本。数据泄漏毁掉排行榜的方式，与此一脉相承：都是让"考卷"悄悄污染了"成绩"。相关课程：[交叉验证实战](./40-cross-validation.md)（评估的制度设计）、[训练误差与泛化鸿沟](./20-generalization-gap.md)（为什么模拟考会虚高）、[学习问题的形式化：经验风险最小化](./10-erm-formalize.md)。

</details>

## 实战挑战 · 泛化误差 = 训练误差 + 鸿沟

学习理论的核心等式：**泛化误差 = 训练误差 + 泛化鸿沟**。训练误差 5%、泛化鸿沟 15% 时，测试误差应是 20%。下面这题把加号写成了减号，修到输出 `0.2`：

```exercise
# @title: 实战挑战：泛化误差是加不是减
# @check: 0.2
# @hint: 测试误差 = 训练误差 + 泛化鸿沟，鸿沟只会让误差变大，不会变小。
train_err = 0.05     # 训练误差 5%
gap = 0.15           # 泛化鸿沟 15%
test_err = train_err - gap    # ← 问题在这：该是加号
print(test_err)
```

<details>
<summary>点开查看逐步解答</summary>

泛化误差是训练误差与鸿沟之和：

```python
test_err = train_err + gap   # 0.05 + 0.15
print(test_err)              # 0.2
```

改完：$0.05 + 0.15 = 0.2$。初始代码得 $-0.10$——误差为负在物理上不可能。这条等式是学习理论的定海神针：模型在测试集上的表现，永远被"记住训练集的程度"和"换分布后掉多少"两笔账共同决定。想降低泛化误差，要么降训练误差，要么收窄鸿沟（更多数据、更简单模型）。

</details>
