# Scaling Laws：堆料背后的经验规律

## 1. 从一个场景开始

大模型时代的会议室里流传着一张传说级的图表：横轴是训练数据量或算力，纵轴是预训练损失，把两张轴都换成对数刻度后，散点几乎落成一条笔直的斜线。Kaplan 等人 2020 年率先把这幅图写成论文，各家实验室随后竞相复核。决定投入数亿美元扩充集群之前，董事会只问一句话：

> "这条直线，真的值得信吗？"

学习理论前几课给了我们样本复杂度与容量账本，却没画过这张宏观全景图。本课的任务：把"堆料见效"翻译成一条可拟合、可外推、也可质疑的幂律公式——并且亲手把它从带噪数据里挖出来。

## 2. 直觉解释

跨七个数量级仍近似成立的实验规律长这样：

$$L(N) \;=\; L_\infty \;+\; A\cdot N^{-\alpha}$$

三个角色的性格分别如下：

- **$L_\infty$（地板）**：知识或任务自带的不可约损失——世界本来就有噪声与未卜先知的极限，堆料无法击穿它。它与偏差方差故事里的噪声地板遥相呼应。
- **$\alpha$（陡度）**：衰减的劲道。它回答的问题最实用：**数据翻倍，收益打几折？** 答案是固定折扣 $2^{-\alpha}$。α=0.34 时约打七九折；α=0.5 直接对半砍。
- **$A$（幅度）**：起点的好坏，取决于架构、tokenizer 与任务的"先天禀赋"。

为什么在对数坐标上会变成直线？给公式两边取常用对数（减掉地板后）：$\lg(L-L_\infty)=\lg A-\alpha\lg N$——这是以 $\lg N$ 为自变量的一次函数，斜率直接读出 $-\alpha$。**把幂律拉直**是整个实证 scaling 研究的核心手法：先猜对函数形状，再让眼睛替统计做主。

## 3. 正式定义

| 符号 | 名字 | 要点 |
| --- | --- | --- |
| $N$ | 规模量 | 数据量、参数量或算力各自有独立轨道，本课聚焦数据 |
| $L_\infty$ | 渐近地板 | 若猜错它的值，后续所有拟合都会系统性歪斜 |
| $\alpha$ | 幂指数 | 决定"每次翻倍的收益保留比例"$2^{-\alpha}$ |
| $A$ | 幅度常数 | 设定曲线的纵向基准 |

这里需要一位新工具正式登场：**`math.log10(x)` 是以 10 为底的对数**，回答"x 是 10 的几次方"。自然对数 `math.log` 的底是无理数 e，适合微积分推演；而工程世界里数据动辄千倍万倍，十进制对数把"几位数的感觉"变成均匀刻度——$\log_{10}1000=3$ 恰好是三个数量级。拟合幂律时我们全程用它在压缩跨度。其余量化约定：损失取测试分布上的交叉熵均值；拟合在减去地板后于双对数坐标里做一次线性回归。

## 4. 分步例题

取本站模拟设定 $\alpha=0.34$、$A=40$、$L_\infty=1.5$（这组数字将在实验中被真实地"重新发明"出来）。

1. **每次翻倍赚多少？** 收益保留比例 $2^{-\alpha}=2^{-0.34}$。由于 $0.34\approx\frac13$ 而 $2^{1/3}\approx1.26$，保留约 $\frac{1}{1.26}\approx 0.79$——即每翻一倍，超额损失只剩原来的七成九；
2. **预测大规模处的损失**：$N=10^6$ 时超额部分为 $40\times(10^6)^{-0.34}=40\times10^{-2.04}=40\times0.00912=0.365$，故 $L\approx1.5+0.365=1.87$；
3. **倒推预算问题**：想把超额损失从 0.37 压到 0.185（再减半），需要 $2^{-\alpha}$ 的连乘次数 $k$ 满足 $0.79^{\,k}=\tfrac12$，即 $k=\frac{\ln 0.5}{\ln 0.79}\approx\frac{-0.693}{-0.236}\approx2.9$——大约翻三倍。预算谈判桌上这就是一句行话："给我八倍数据，我给你一半的痛。"

### 实验 1（viz）：把幂律拉直的示波器

```viz
  "expr": "log(a)/log(10) - p*x",

  ]

```

横轴是 $\lg N$（从一千到千万），纵轴是 $\lg(L-L_\infty)$——真正的损失要先扣掉地板再取对数。这条线本身就说明了一切：(1) 读斜率：每往右一格（数据 ×10），纵直落 p 格；(2) 拖 `a` 改截距不改斜率——幅度是"起跑线"，不是"速度"；(3) 一个耐人寻味的副产品：地板 $L_\infty$ 在拉直后的图上消失了——选对地板的本质要求是**扣除后剩下的东西呈现幂律**，判据回到直线本身。

### 实验 2（python）：从一百条带噪观测里重新发明 α

人造一条真值 $\alpha=0.34$、$A=40$、$L_\infty=1.5$ 的幂律，叠加少量测量噪声后，假装不知道参数，全靠双对数回归把 α 和 A 挖回来：

```python title="双对数线性回归：从带噪曲线反演 alpha 与 A"
import random       # random：伪随机数（此前课程已介绍）
import math         # 老朋友 math.log 自然对数登场
import statistics   # statistics.mean：均值

LINF = 1.5          # 真实的地板：稍后被我们当成已知量用掉
A_TRUE = 40.0       # 真实幅度
ALPHA = 0.34        # 真实陡度——待会看拟合能追回多准

ks = list(range(0, 13))
Ns = [1000.0 * (2 ** k) for k in ks]     # 数据规模从一千起连续翻倍十三次

rng = random.Random(31)
losses = []
for N in Ns:
    base = LINF + A_TRUE * N ** (-ALPHA)
    losses.append(base * (1 + rng.gauss(0, 0.004)))   # 叠加 0.4% 的测量噪声

# math.log10 首次出场：十进制对数把十三倍的量级跨度压成均匀刻度
xs_lg = [math.log10(N) for N in Ns]
ys_lg = [math.log10(L - LINF) for L in losses]

mx = statistics.mean(xs_lg)
my = statistics.mean(ys_lg)
sxy = sum((xs_lg[i] - mx) * (ys_lg[i] - my) for i in range(len(xs_lg)))
sxx = sum((vx - mx) ** 2 for vx in xs_lg)

slope = sxy / sxx                      # 最小二乘斜率——负号代表衰减方向
alpha_hat = -slope                     # 还原成正的幂指数
intercept = my - slope * mx
A_hat = 10 ** intercept                # 截距 lg A 再做 10 的幂还原幅度
print(f"alpha_hat={alpha_hat:.3f} A_hat={A_hat:.1f}")
```

典型输出：`alpha_hat=0.341 A_hat=40.7`。十三组带噪数据就把真实参数逼到小数点后两位——这正是工业界敢拿它画路线图的底气。把噪声方差放大二十倍重跑，估计值立刻摇摇晃晃：**定律的可信度来自数据的干净程度，而不是公式本身的庄严感。**

### 快问快答

```quiz
Scaling Laws 图为什么坚持用双对数坐标？
- 对数轴会把任何曲线都拉直，纯粹为了画面整洁
- 幂律取对数后恰好是一次函数：斜率读出负的幂指数，截距给出幅度 [*]
- 因为损失在原始尺度下是锯齿状的，必须压扁才能看清趋势
? 取 lg 之前先减去地板的话，公式 lg(L-L∞) = lgA − α·lgN 正是一次函数。斜率的绝对值就是 α，它决定每次翻倍能保留几成收益——这一页纸上写着整个时代的预算逻辑。
```

:::warning[常见误区]

**误区一**：你以为拟合出直线就等于理解了机制。α 只是现象学的陡度标签；不同的假设（容量受限 vs 数据受限 vs 训练时长受限）可能画出平行的直线。直线忠实记录，从不解释。

**误区二**：你以为可以放心外推到图外三个数量级。已有多家复现报告指出偏离幂律形态的拐弯信号——定律在自己的标尺之外不作任何承诺，样本量增长总有撞上天花板的一天。

**误区三**：你以为地板 $L_\infty$ 随便设个好看数字即可。扣多了整条线上翘弯曲，扣少了压不直——它是整套拟合中最脆弱的一环。严肃的做法是把地板本身连同 α、A 一起放进非线性拟合并检查残差结构。

:::

## 6. 练习

**练习**：隔壁团队宣布他们的模型遵循 $\alpha=0.5$、$A=40$、$L_\infty=1.5$ 的幂律。(a) 把训练数据扩大四倍，超额损失变为其几倍？(b) 连续翻倍几次能把超额损失恰好压到一半？(c) 此时若 $N=4096$，总损失的预测是多少？

```exercise
# @title: 练习：新团队的幂律首秀
# @check: 0.5
# @check: 2
# @check: 2.125
# @hint: 四倍 = 两次翻倍：保留比例直接算 4**(−α)；翻倍次数解方程 2**(−α·k)=0.5 得 k=1/α，本题恰为整数（别用 ln 换底再 ceil——边界处浮点会多计一次）；总损失 = 地板 + A·N**(−α)
import math            # math.log 与 math.ceil 都是老朋友

alpha_e = 0.5          # 团队宣称的幂指数
A_e = 40.0             # 幅度
linf_e = 1.5           # 地板

ratio_at_4x = (-alpha_e)               # ← 有 bug：四倍规模的保留比例应是 4 的负 α 次幂
print(ratio_at_4x)

doublings_needed = 0                   # ← 占位：解方程 2**(−α·k)=1/2，代入公式 k=1/alpha_e 并取整验证
print(doublings_needed)

n_target = 4096                        # 换算成具体规模的预测
loss_pred = linf_e + A_e * n_target    # ← 有 bug：规模 N 要放在指数位置衰减
print(round(loss_pred, 3))
```

<details>
<summary>点开查看逐步解答</summary>

(a) 数据 ×4 即两次翻倍：保留比例 $4^{-0.5}=0.5$——α=0.5 时超额损失每四倍规模减半；

(b) 单次翻倍保留 $2^{-0.5}\approx0.707$，连乘到不超过 0.5 需要 $k=\dfrac{\ln 0.5}{\ln 0.707}=2$ 次——答案恰好等于 $1/\alpha$，这不是巧合而是等式 $2^{-\alpha k}=\tfrac12\Rightarrow \alpha k=1$ 的直接解；

(c) 总损失 $1.5+40\times 4096^{-0.5}=1.5+\dfrac{40}{64}=1.5+0.625=\mathbf{2.125}$。注意它在向地板缓缓沉没，而地板永远是醒不来的海底。

</details>

## 7. 选读：α 与 A 到底是怎么被读出来的

<details>
<summary>选读 · 回归的世界观</summary>

双对数回归第一步要扣地板 $L_\infty$，但真实的 α、A、$L_\infty$ 三者本该联合求解——正文实验里我们"作弊"地用了真地板来演示线性化。诚实的流程是非线性最小二乘（三参数同时调）或者按置信区间扫描地板找残差最白的那一个。第二步要注意权重：对数空间的最小二乘最小化的是相对误差而非绝对误差，这对跨越多个数量级的数据通常是 blessing——远端的巨型 N 天然主导未取对数的平方和。至于 Kaplan 原文与 Chinchilla 复现在"数据与参数谁更稀缺"上的著名分歧，本质就是三条轨道（N_data、N_params、C_compute）各自的 α 不同导致的最优配比之争，本课聚焦的数据轨道只是它们的入口。

</details>
