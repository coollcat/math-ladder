# 学习问题的形式化：经验风险最小化

## 1. 从一个场景开始

你负责公司的邮件过滤。同事递来三条现成的规则：**甲**"含'中奖'就拦截"；**乙**"发件人不在通讯录就拦截"；**丙**"含链接就拦截"。手头有 100 封已人工标好"垃圾/正常"的历史邮件。

所谓"学习"，在这里其实就是一件朴素的事：**把每条规则放到这 100 封邮件上跑一遍，数数各错杀、漏放多少，挑错得最少的那条**。没有玄机，就是一场程序自己当阅卷人的考试。

学习理论要回答的正是这件事背后的数学：这场考试怎么定义？考得好就等于真本事吗？本课先把"考试"本身写严谨。

## 2. 直觉解释

三个角色各就各位：

- **候选规则库（假设类）**：甲乙丙三条规则全体，记作 $\mathcal{H}$。它是考场——**只有库里的规则允许上场**。库外的天才规则再多，我们够不着。
- **考卷（数据）**：带标准答案的样本 $(x_i, y_i)$。
- **扣分表（损失函数）**：预测对一次扣 0 分，错一次扣 1 分；或者按错的离谱程度平方扣分。

给每条规则打的总分取平均，就是它的**模拟考成绩**。"学习"= 在假设类里挑模拟考冠军。这个原则朴素到近乎显然，但它有一个正式的名字——经验风险最小化，而且是整个机器学习的地基。

## 3. 正式定义

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $(x, y)$ | 样本 | 输入与真实标签，来自未知分布 $D$ |
| $\mathcal{H}$ | 假设类 | 允许上场的全部规则的集合 |
| $h(x)$ | 预测 | 规则 $h$ 对输入 $x$ 给出的答案 |
| $\ell(\hat{y}, y)$ | 损失 | 预测 $\hat{y}$ 与真实 $y$ 差距的罚分 |

**泛化风险**（真实成绩）：规则 $h$ 在整个世界上的平均损失——

$$R(h) = \mathbb{E}_{(x,y) \sim D}\big[\ell(h(x),\, y)\big]$$

**经验风险**（模拟考成绩）：在手头 $n$ 个样本上的平均损失——

$$\hat{R}(h) = \frac{1}{n} \sum_{i=1}^{n} \ell\big(h(x_i),\, y_i\big)$$

**ERM 原则**：从假设类里挑经验风险最小的规则——

$$\hat{h} = \arg\min_{h \in \mathcal{H}} \hat{R}(h)$$

注意两层关键区分：$R$ 对**未知分布**取期望，算不出来，是"真实水平"；$\hat{R}$ 对**手头样本**取平均，永远可算，是"模拟考水平"。ERM 用后者顶替前者，这笔交易是否划算，是接下来三课的主线。

## 4. 分步例题

5 封邮件（1 表示垃圾），规则输出 1 表示拦截：

| 邮件 $i$ | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| 真实 $y_i$ | 0 | 0 | 1 | 0 | 1 |
| 甲"含中奖" | 0 | 0 | 1 | 0 | 0 |
| 乙"非通讯录" | 1 | 1 | 0 | 0 | 1 |

用 0-1 损失（错一封扣 1）逐条算：

1. **甲**：第 3 封拦对了，第 5 封漏了 → 错 1 封，$\hat{R}(甲) = 1/5 = 0.2$；
2. **乙**：第 1、2 封错杀，第 3 封漏放，第 5 封拦对 → 错 3 封，$\hat{R}(乙) = 3/5 = 0.6$；
3. 若还有丙"全都不拦"：错 2 封，$\hat{R}(丙) = 2/5 = 0.4$；
4. 三者比较 $0.2 < 0.4 < 0.6$，ERM 冠军是甲；
5. 注意第 4 步只是"在库里比"，甲的真实水平如何，考卷说了不算——下一课专门拆穿这一点。

```viz

```

怎么玩：拖动任意蓝点。图里那条蓝线就是假设类"全体直线"中模拟考成绩最好的那一条，左上角的「平均误差」读数就是它此刻的**平方损失版经验风险**。每拖一个点，ERM 自动重新选冠军——你负责出题，它负责应考。第 21 章的最小二乘，就是这条原则在平方损失下的精确解。

### 实验 2（python）：两条规则，谁的经验风险小

```python title="在 5 封邮件上给两条规则打分"
import statistics

# 数据：每个元素是 [编号, 真实标签]，标签 1 表示垃圾邮件
data = [[1, 0], [2, 0], [3, 1], [4, 0], [5, 1]]

def rule_a(x):          # def 定义函数：之后写 rule_a(3) 就能得到它的返回值
    return 1 if x == 3 else 0   # 条件表达式："如果 x==3 返回 1，否则返回 0"

def rule_b(x):
    if x == 3:                  # 第 3 封发件人在通讯录，不拦
        return 0
    if x == 4:                  # 第 4 封发件人也在通讯录，不拦
        return 0
    return 1                    # 其余邮件按乙规则拦截

loss_a = []
for row in data:
    pred = rule_a(row[0])
    loss_a.append(abs(pred - row[1]))   # 0-1 损失：abs(pred-y)，对则 0 错则 1

print(statistics.mean(loss_a))          # 甲的平均损失（statistics 卷九已登场）

loss_b = []
for row in data:
    loss_b.append(abs(rule_b(row[0]) - row[1]))
print(statistics.mean(loss_b))
```

跑出来是 `0.2` 和 `0.6`——和例题的手算完全一致。把某条规则的判断条件改狠一点，看平均损失怎么反应。

### 快问快答

```quiz
经验风险最小的规则，泛化风险也一定最小吗？
- 是的，两者是一回事
- 不一定，模拟考冠军可能只是恰好背过这张卷子 [*]
- 是的，只要样本量超过 100
? 经验风险只对手头样本负责。样本有限时它是对真实风险的近似，近似就有误差——误差多大、怎么控，是后面三课的主题。
```

:::warning[常见误区]

**误区一**：你以为"经验风险 = 泛化风险"。前者是模拟考，后者是高考；两者之间隔着一个随样本量缩小的鸿沟，本课只负责把两者**定义清楚**，不承诺它们相等。

**误区二**：你以为假设类越大越好。库里规则越多，越容易找到一条"完美贴合考卷答案"的规则——但贴合答案不等于掌握规律（过拟合预告）。

**误区三**：你以为损失函数随便选。0-1 损失里漏放一封垃圾邮件和错杀一封重要合同，扣分一样；现实里代价常常不对称。选损失就是在替业务表态。

:::

因为考卷和练习册是同一份。规则完全可以靠死记这份考卷的答案拿到零失误，而它在没见过的邮件上一塌糊涂——这不是学习，是背题。要让考试有说服力，必须留出一批**训练时没碰过的数据**当新考卷。这个"留一手"的动作怎么做才科学，就是第 40 课交叉验证的正题。

## 7. 选读：ERM 与最小二乘的血缘

<details>
<summary>选读 · 一个原则的两件马甲</summary>

第 21 章的最小二乘法，用本课语言重述一遍：假设类取"全体直线" $h(x) = ax + b$，损失取平方损失 $\ell = (h(x)-y)^2$，ERM 就是"选使平方损失总和最小的 $a, b$"——正是最小二乘的目标函数。所以最小二乘不是一条孤立的公式，而是 ERM 原则在连续参数下的特例。

再往深一步：对**固定的**一条规则 $h$，经验风险 $\hat{R}(h)$ 就是 $n$ 个独立同分布损失值的样本均值。大数定律（卷九）保证 $n \to \infty$ 时 $\hat{R}(h)$ 逼近真实风险 $R(h)$。麻烦在于 ERM 挑的是 $\mathcal{H}$ 里 $\hat{R}$ 最小的那个——"从一堆估计值里挑最大/最小"这个动作本身会引入新的偏差，这正是下一课泛化鸿沟的来源。

</details>
