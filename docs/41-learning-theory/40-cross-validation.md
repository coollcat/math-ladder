# 交叉验证实战：把考卷制度性地藏起来

## 1. 从一个场景开始

教练手里只有两名射击选手各 10 发的成绩记录，要挑一人去奥运，还想顺便告诉你"他真实水平大概多少"。如果用这 10 发挑人、再用**同样这 10 发**汇报成绩——挑出来的必然是"这 10 发恰好超常发挥"的那个，汇报的也必然是虚高的分数。

数据科学里同款陷阱无处不在：用全部数据选模型，再宣称这个模型误差很小。解法朴素而深刻：**留几发子弹不当场看**。怎么留才既公平又不浪费数据？这就是交叉验证。

## 2. 直觉解释

三个身份要分清：

- **训练集**：练习册，模型从中学习；
- **验证集**：模拟考卷，用来**比较**不同模型的优劣、调复杂度；
- **测试集**：高考卷，密封保存，只在一切决定做完后开一次封，汇报最终成绩。

只留一份验证集的问题是"一份考卷运气太大"。k 折交叉验证的主意是：把数据切成 k 叠，**轮流让每一叠当一次模拟考**，其余 k−1 叠负责训练；每个模型考 k 次，取平均分。人人都当过考官，运气互相抵消，对数据的利用也更充分。

最后一步常被忽略却至关重要：选定模型配置后，**在全部数据上重新训练一遍**再交付——选型时的 k 次训练每次只用了一部分数据，别浪费剩下的。

## 3. 正式定义

给定数据集 $D$ 与候选复杂度集合。k 折交叉验证：

1. 把 $D$ 随机切成大小相近的 $k$ 份 $D_1, \ldots, D_k$；
2. 对第 $i$ 折：用 $D \setminus D_i$ 训练（$\setminus$ 表示"去掉"），在 $D_i$ 上算平均损失，记作 $e_i$；
3. 输出交叉验证估计值：

$$\mathrm{CV}_k = \frac{1}{k}\sum_{i=1}^{k} e_i$$

对每个候选复杂度算一遍 $\mathrm{CV}_k$，选最小的那个；随后在全量 $D$ 上重训最终模型。

| 符号 | 名字 | 要点 |
| --- | --- | --- |
| $e_i$ | 第 $i$ 折验证误差 | 用没见过 $D_i$ 的模型来算，公平 |
| $\mathrm{CV}_k$ | k 折平均验证误差 | 测试误差的无偏倾向估计 |
| $k$ | 折数 | 常用 5 或 10：折多时每折训练集占比 $(k{-}1)/k$ 更大、更接近全量训练，估计偏差小；但验证份变小，折间波动与计算量上升 |

注意 $\mathrm{CV}_k$ 估计的是"**这套训练流程**的平均水平"，不是手里某个具体模型的误差——它回答"按这个配方再练一个，新数据上大概错多少"。

## 4. 分步例题

微型数据集：$(x, y)$ 共 4 点：$(1,2),\ (2,5),\ (3,6),\ (4,8)$。两个候选模型：**M1 均值器**（永远预测训练集 $y$ 的平均值）、**M2 直线**（过两个训练点连直线）。取 $k=2$：

1. **第 1 折**：验证集 $\lbrace(1,2),(2,5)\rbrace$，训练集 $\lbrace(3,6),(4,8)\rbrace$；
2. M1 预测训练均值 $7$：误差 $((7-2)^2 + (7-5)^2)/2 = 14.5$；
3. M2 连线得 $y = 2x$：预测 $2, 4$，误差 $((2-2)^2+(5-4)^2)/2 = 0.5$；
4. **第 2 折**：验证集 $\lbrace(3,6),(4,8)\rbrace$，训练集 $\lbrace(1,2),(2,5)\rbrace$；
5. M1 预测均值 $3.5$：误差 $((3.5-6)^2+(3.5-8)^2)/2 = (6.25+20.25)/2 = 13.25$；M2 连线得 $y = 3x - 1$：预测 $8, 11$，误差 $((8-6)^2+(11-8)^2)/2 = 6.5$——M2 这次也被训练噪声带偏了斜率，但依然远好于完全不看 $x$ 的 M1；
6. 汇总：$\mathrm{CV}_2(\mathrm{M1}) = (14.5+13.25)/2 = 13.875$，$\mathrm{CV}_2(\mathrm{M2}) = (0.5+6.5)/2 = 3.5$。M2 胜出，且胜得有内容：两折里它吃过亏、占过便宜，平均下来仍然碾压。

### 实验 2（python）：亲手跑一遍 4 折交叉验证

```python title="三个模型的 4 折 CV 实测"
import statistics

xs = [1, 2, 3, 4, 5, 6, 7, 8]
ys = [2.1, 4.2, 5.7, 8.4, 9.8, 12.3, 13.7, 16.4]   # 约等于 y = 2x 加噪声

folds = [[0, 1], [2, 3], [4, 5], [6, 7]]           # 手工切好 4 折：存的是下标

def fit_mean(train_idx):                           # 模型一：均值器的"训练"就是求平均
    total = 0
    for i in train_idx:
        total = total + ys[i]
    return ["mean", total / len(train_idx)]

def fit_line(train_idx):                           # 模型二：最小二乘直线的公式解
    n = len(train_idx)
    mx = sum(xs[i] for i in train_idx) / n         # 生成器表达式：sum 里现算现收
    my = sum(ys[i] for i in train_idx) / n
    sxy = sum((xs[i] - mx) * (ys[i] - my) for i in train_idx)
    sxx = sum((xs[i] - mx) ** 2 for i in train_idx)
    slope = sxy / sxx                              # 斜率 = 协方差和 / 平方和
    intercept = my - slope * mx
    return ["line", slope, intercept]

def predict(model, x):
    if model[0] == "mean":
        return model[1]
    slope, intercept = model[1], model[2]
    return slope * x + intercept

def cv_error(fitter):
    total = 0
    for fold in folds:
        train_idx = []                             # 其余三折的下标拼成训练集
        for other in folds:
            if other != fold:
                train_idx = train_idx + other
        model = fitter(train_idx)                  # 只用训练折拟合
        for i in fold:                             # 在留出折上记账
            err = predict(model, xs[i]) - ys[i]
            total = total + err * err
    return total / len(xs)

print(f"均值器 CV={cv_error(fit_mean):.2f}")
print(f"直线   CV={cv_error(fit_line):.2f}")
```

典型输出：均值器约 `36.6`，直线约 `0.1`——与例题的手工结论一致：真规律是线性的，直线模型在每一折都赢。把 `ys` 改成一团纯随机数再跑，赢家会换成均值器（直线开始追噪声）——**CV 自动适应数据的真实复杂度**，这正是它的价值。

### 实验 3（python）：逐折细看——赢家也有翻车的时候

```python title="四个折各自的验证误差"
import matplotlib.pyplot as plt

xs = [1, 2, 3, 4, 5, 6, 7, 8]
ys = [2.1, 4.2, 5.7, 8.4, 9.8, 12.3, 13.7, 16.4]
folds = [[0, 1], [2, 3], [4, 5], [6, 7]]

errs_mean = []
errs_line = []
for cut in range(len(folds)):                  # cut：本轮当验证折的编号
    val = folds[cut]
    train = []
    for k in range(8):
        if k not in val:                       # in：判断元素是否在列表里
            train.append(k)

    total = 0                                  # 均值器：训练折 y 的平均
    for i in train:
        total = total + ys[i]
    m = total / len(train)
    e1 = 0
    for i in val:
        e1 = e1 + (m - ys[i]) ** 2 / len(val)
    errs_mean.append(e1)

    n = len(train)                             # 直线：最小二乘公式解
    mx = sum(xs[i] for i in train) / n         # sum 里现算现收的生成器写法
    my = sum(ys[i] for i in train) / n
    slope = sum((xs[i] - mx) * (ys[i] - my) for i in train) / sum((xs[i] - mx) ** 2 for i in train)
    b = my - slope * mx
    e2 = 0
    for i in val:
        e2 = e2 + (slope * xs[i] + b - ys[i]) ** 2 / len(val)
    errs_line.append(e2)

pos = [0, 1, 2, 3]
plt.bar([p - 0.18 for p in pos], errs_mean, width=0.36, label="mean")   # 左右错开半根柱宽
plt.bar([p + 0.18 for p in pos], errs_line, width=0.36, label="line")
plt.xticks(pos, ["fold1", "fold2", "fold3", "fold4"])
plt.legend()
plt.ylabel("validation MSE")
```

灰柱（均值器）高耸入云且忽高忽低；蓝柱（直线）贴地飞行。逐折看还有个好处：哪一折最难考一目了然——本数据里第 1、4 折对均值器格外残酷（离全局重心最远）。真实项目里"某折异常"常常就是数据里异常值或分组结构的信号。

### 快问快答

```quiz
用 5 折交叉验证选好了模型复杂度，交付前还应该做什么？
- 直接交付验证误差最低的那一折模型
- 在全部数据上重新训练，再用从未参与任何环节的测试集报告成绩 [*]
- 再跑一遍交叉验证，把分数改好看一点
? 选型阶段每轮训练只用了部分数据；定下配方后应全量重训。而测试集必须保持"从未影响任何决策"，否则成绩就是自我实现。
```

:::warning[常见误区]

**误区一**：你以为交叉验证给出的是"手里这个模型的测试误差"。它估计的是训练**流程**的平均水平；单个模型的运气仍然可能偏离这个数。

**误区二**：你以为测试集可以反复使用。每看一次并据此改动，它就向训练集堕落一分。行业惯例：整个项目周期只开封一次。

**误区三**：你以为随机切折永远安全。数据带时间结构（股价、疫情曲线）时随机打乱等于用过去考未来——要用"前向滚动"式切分。竞赛史上的著名事故（本章挑战题的鲸鱼泄漏）正是这类裂缝的极端版。

:::

<details>
<summary>点开查看逐步解答</summary>

训练误差是"对着答案复习过的成绩"，验证误差是"新题成绩"，两者之间隔着泛化鸿沟。直线模型没有自由容量去背 8 个带噪的点的抖动，它学到的斜率就是规律本身——对新题旧题一视同仁，鸿沟趋近于零。均值器同样不背题，但它把所有结构都压平了：验证时离全局重心最远的那两折误差高得吓人（63.5 与 65.3），这些"没见过的位置"恰好暴露了它的系统性缺陷——它的两种误差差距来自**欠拟合的结构性偏差**而非背题。真正让训练与验证成绩拉开的是**会背题的高容量模型**：九次插值的训练误差近乎零、验证误差 41（实验 1 的图）。三种情形合起来正是上一课 U 形曲线的左壁、右壁与谷底。
</details>

## 7. 选读：折数的两难与分层

<details>
<summary>选读 · k 取多大</summary>

$k$ 越大：每折训练集越大（$k{-}1)/k$ 比例），单次训练越接近全量训练，估计偏差越小；但要对齐 $k$ 份训练且每折验证集变小，估计的波动变大，计算量也线性上涨。$k=5$ 或 $10$ 是几十年实践磨出来的折中。类别标签不均衡时还有"分层 k 折"：让每折里各类比例与全局一致，防止某一折恰好缺了稀有类。重复交叉验证（换几种切法跑多轮取平均）进一步压波动，代价是时间。这些工程细节万变不离其宗：**评估用的信息绝不允许回流进训练**。

</details>
