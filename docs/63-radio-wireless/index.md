## 实战挑战 · Wi-Fi 穿墙链路预算

**背景**（参数出处均为公开资料）：中国工信部规定 2.4 GHz 频段免执照设备 EIRP 不超过 20 dBm（100 mW，天线增益小于 10 dBi 时，信部无〔2002〕353 号通知）；Cisco 无线勘测参考指南给出常见建材在 2.4 GHz 的典型穿透损耗：石膏板隔墙约 3 dB、承重混凝土墙约 12 dB。工程速算公式 FSPL = 32.44 + 20log₁₀(f_MHz) + 20log₁₀(d_km) 在 2450 MHz、5 米处约为 **54 dB**（本挑战直接取用，整数化后正好 54）。

**题目**：路由器（EIRP 取满额 20 dBm）放在客厅，你在卧室刷手机（接收天线按 0 dBi 算），直线距离 5 米，中间隔着 **2 堵石膏板墙 + 1 堵承重混凝土墙**。手机灵敏度 −75 dBm。

- (a) 三堵墙的总穿透损耗是多少 dB？
- (b) 手机收到的功率 Pr = 多少 dBm？
- (c) 相对灵敏度的链路余量还有几 dB？还能愉快刷视频吗？

(a) 已示范：

```exercise
# @title: 实战挑战：三堵墙之后的 Wi-Fi 存活报告
# @check: 18
# @check: -52
# @check: 23
# @hint: 承重墙不是普通隔墙——它要按 12 dB 计账；Pr 与余量都是纯加减法，对照第 30 课的账单格式。
wall_total = 3 + 3 + 3        # ← (a) 问题在这：最后一堵是承重墙，单价不同

pr = 20 - 54 - wall_total     # (b) EIRP − 自由空间损耗 − 穿透损耗
margin = pr + 75              # (c) 余量 = Pr − (−75)
print(wall_total)
print(pr)
print(margin)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 石膏板按 3 dB/堵计两堵，承重墙按 12 dB 计一堵：$3+3+12=18$ dB。把承重墙也当 3 dB 是新手最常见的漏账——误差整整 9 dB，足以让"满格"变"找网"。

**(b)** 链路预算一行加法（第 30 课格式）：$P_r = 20 - 54 - 18 = -52$ dBm。若没有墙，$20-54=-34$ dBm；穿墙吃掉了 18 dB，按每 20 dB 十倍距折算就是 10 的 0.9 次幂 ≈ 8 倍——相当于把距离从 5 米等效拉到约 $5\times8\approx40$ 米，这就是"一堵承重墙 ≈ 八倍距离"的由来。

**(c)** 余量 $=-52-(-75)=23$ dB。结论：能刷，而且家底厚实；但若再叠一层楼板（15~20 dB 量级），余量就见底了。完整代码：

```python
wall_total = 3 + 3 + 12
pr = 20 - 54 - wall_total
margin = pr + 75
print(wall_total, pr, margin)
```

工程哨卡：余量为正且大于 10 dB 才谈得上稳定体验；多径深衰落还要再吃掉 10~20 dB（第 40 课的 Rayleigh 账单），所以现场勘测永远比纸面悲观。
</details>

## 实战挑战 · 自由空间损耗：距离的平方

自由空间里接收功率与距离的**平方**成反比：距离翻倍，功率降到 $\frac14$。下面这题只除了距离本身，修到输出 `0.25`：

```exercise
# @title: 实战挑战：自由空间损耗是距离平方
# @check: 0.25
# @hint: 功率 ∝ 1/d²，分母是 d 的平方。
d = 2.0          # 距离（相对原点的倍数）
P1 = 1.0         # 距离 1 时的接收功率
P2 = P1 / d      # ← 问题在这：该除以 d²
print(P2)
```

<details>
<summary>点开查看逐步解答</summary>

自由空间传播损耗与距离平方成反比：

```python
P2 = P1 / (d * d)   # 1 / 4
print(P2)           # 0.25
```

改完：距离从 1 翻倍到 2，功率从 1 降到 $\frac{1}{2^2}=0.25$。初始代码得 $0.5$，等于把三维空间的能量扩散当成了线性衰减——真实是电波在一个不断膨胀的球面上摊开，面积 $\propto d^2$，所以功率 $\propto \frac1{d^2}$。这正是 Friis 公式里那个 $20\log_{10} d$ 的来历。

</details>
