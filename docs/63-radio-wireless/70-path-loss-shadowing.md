# 大尺度路径损耗与阴影衰落

## 1. 从一个场景开始

同一个运营商，有人在家满格，有人走到小区南门就只剩一格——直线距离不过十公里的事。规划工程师必须回答：**这个基站的信号圆圈到底画多大？**

自由空间的 Friis 公式（第 30 课）给不出答案，因为城市不是真空：楼房挡、地面反、树丛吸。这一课把 Friis 的"物理精确"升级成工程师的"统计够用"——你会看到距离的账在对数坐标里是一条直线，以及为什么"十公里外少一格"不是玄学，是对数。

## 2. 直觉解释

Friis 公式里距离走的是平方反比（指数 $n=2$），那是真空的特权待遇。地面电波被遮挡、反射、绕行，能量漏得更快：实测数据套公式，等效指数常常落在 $n \approx 3 \sim 4$。

好消息是，取了对数以后，**任意指数的损耗曲线都变成直线**：距离每翻十倍，损耗固定增加 $10n$ dB。城市规划不再需要积分，只需要两个数——起点损耗 $PL_0$ 和斜率 $10n$。

但直线只是"平均脸"。同一距离上反复测量，会得到一簇上下散布的读数：山体、楼群、高架像影子一样罩在某些方向上。把损耗画成分布，**在对数（dB）坐标里恰好是正态曲线**——这片"慢吞吞的包络"叫阴影衰落，它决定了圆圈边缘上"时好时坏"的那批用户。

## 3. 正式定义

**log-distance 路径损耗模型**：以参考距离 $d_0$ 处的损耗 $PL_0$ 为起点，

$$PL(d) = PL_0 + 10n\log_{10}\left(\frac{d}{d_0}\right) + X_\sigma$$

**阴影衰落项**：$X_\sigma$ 服从零均值正态分布（单位 dB），标准差 $\sigma$ 典型取 4~12 dB。

| 符号 | 单位 | 含义 |
| --- | --- | --- |
| $n$ | 无量纲 | 路径损耗指数：自由空间 2，市区 3~4，穿墙更狠 |
| $PL_0$ | dB | 参考点 $d_0$（常取 1 米）处的损耗，用 Friis 公式算出 |
| $X_\sigma$ | dB | 阴影衰落，对数正态（dB 域正态）的慢包络 |
| $d$ | 米 | 收发距离 |

**与第 30 课的分工**：Friis 公式是 $n=2$ 时从物理推导出的**确定底座**，负责给出 $PL_0$；log-distance 模型是覆盖真实环境的**统计修正**，用实测斜率 $n$ 和阴影 $\sigma$ 描写遮挡。两者不是竞争关系，是接力关系。

**阴影余量**：要求边缘覆盖率 $p$ 时，平均损耗预算要再扣 $z\sigma$（$p=90\%$ 对应 $z \approx 1.28$，来自正态分布分位数，第 36 章的正态课给过这张表）。

## 4. 分步例题

**例**：2.4 GHz 微基站，发射 EIRP 20 dBm，手机灵敏度 −100 dBm。实测 $PL_0 = 40$ dB（1 米参考）、$n = 3.5$、$\sigma = 8$ dB，要求小区边缘 90% 覆盖。求覆盖半径。

1. 总预算：$20 - (-100) = 120$ dB——这是可以挥霍的全部损耗；
2. 扣阴影余量：$z\sigma = 1.28 \times 8 \approx 10$ dB，留给"平均路损"的只剩 $110$ dB；
3. 解距离：$110 = 40 + 35\log_{10}(d/1)$，得 $\log_{10} d = 2$，即 $d = 100$ 米；
4. 对照：若假装没有阴影（不扣 10 dB），半径变成 $10^{(120-40)/35} = 10^{2.29} \approx 195$ 米——**一笔 10 dB 的账，半径差出一倍**。

检查量级：市区微基站覆盖一两百米，与工程常识一致；教科书里"宏大"的公里级覆盖属于空旷郊区（$n$ 更小、$\sigma$ 更小）。

### 实验 2（python）：覆盖半径账本

```python title="给定预算与阴影，反解覆盖半径"
import math

# sliders: n=3.5 [2:4:0.1], sigma_db=8 [0:12:1]

eirp_dbm = 20      # 发射等效功率（dBm）
sens_dbm = -100    # 手机灵敏度（dBm）
pl0 = 40.0         # 1 米参考点损耗（dB），来自 Friis 公式
z = 1.28           # 90% 边缘覆盖率对应的正态分位数

budget = eirp_dbm - sens_dbm               # 总损耗预算
margin = round(z * sigma_db)               # 阴影余量：z 倍标准差
d = 10 ** ((budget - margin - pl0) / (10 * n))   # 反解距离：对数方程移项
print(f"预算 {budget} dB，扣阴影 {margin} dB")
print(f"覆盖半径约 {round(d, 1)} 米")
```

怎么玩：默认参数正好复现例题的 100 米。把 $\sigma$ 拧到 12：余量涨到 15 dB，半径缩到 61 米——**地形越乱，圆圈越小**；把 $n$ 拧到 2.5：半径弹回 631 米，斜率松一格，覆盖宽十倍。

### 实验 3（python）：开车穿过阴影走廊

```python title="沿路实测路损：直线骨架 + 对数正态散布（固定种子）"
import math
import random
import matplotlib.pyplot as plt

random.seed(7)                    # 固定随机种子：每次运行得到同一条"路"
n, pl0, sigma = 3.5, 40.0, 8.0

ds = []
pls = []
for i in range(60):
    d = 20 * (i + 1)              # 从 20 米到 1200 米的取样点
    pl = pl0 + 10 * n * math.log10(d) + random.gauss(0, sigma)   # gauss：正态抽样
    ds.append(d)
    pls.append(pl)

ideal = [pl0 + 10 * n * math.log10(d) for d in ds]
plt.scatter(ds, pls, s=12, label="measured")      # scatter：散点图
plt.plot(ds, ideal, color="tomato", label="model")
plt.xlabel("distance (m)")
plt.ylabel("path loss (dB)")
plt.legend()
plt.grid(True)
```

怎么玩：橙线是模型的"平均脸"，蓝点是被阴影揉皱的实测。有的点比模型差十几 dB——那是开进了楼影；偏离的方向在几百米内持续不回头，这正是"慢"衰落的性格：**它跟位置绑定，不像多径那样挪半步就翻篇**。

### 快问快答

```quiz
距离增加十倍，路径损耗指数 n = 3.5 时平均路损增加多少？
- 3.5 dB
- 20 dB
- 35 dB [*]
? 十倍距的代价是 10n dB，n=3.5 就是 35 dB。20 dB 是自由空间 n=2 的老价格，3.5 dB 是把指数误当损耗了。
```

:::warning[常见误区]

**误区一**："你以为 n=2 处处成立。" 平方反比是真空版权；市区实测 n 常在 3~4，隧道、走廊里甚至超过 4。拿到一个环境先拟合 n，再谈覆盖。

**误区二**："你以为阴影衰落就是第 40 课那种快衰落。" 阴影是秒级、米级的"慢包络"，换个街区才变脸；多径衰落挪几厘米就翻篇。两者叠加出现，处方也不同：阴影靠余量和选址，快衰落靠分集与编码。

**误区三**："你以为规划只看平均就行。" 平均值刚好达标的边缘，一半用户实际掉线。90% 覆盖要扣 1.3σ 余量、99% 要扣 2.3σ——**余量不是浪费，是给概率买的保险**。

:::

## 6. 练习

**练习 1**：已知 $PL_0 = 40$ dB、可容忍平均路损 115 dB、$n = 3$，求覆盖半径（米，取整）。代码能跑但答案荒谬：

```exercise
# @title: 练习：反解覆盖半径
# @check: 316
# @hint: 对数方程 115 = 40 + 10n·log10(d)，移项后除数是 10n 而不是 n
pl0 = 40
pl_max = 115
n = 3

d = 10 ** ((pl_max - pl0) / n)   # ← 问题在这：少了系数 10
print(round(d))
```

改对后输出 316：$10^{75/30} = 10^{2.5} \approx 316$ 米。原式算出的天文数字正是"忘除以 10"的现场——对数账上差一个系数，距离差十万八千里。

**练习 2**：把例题的覆盖率要求提到 99%（$z \approx 2.33$），其余不变，半径缩到多少？

<details>
<summary>点开查看逐步解答</summary>

余量 $2.33 \times 8 \approx 19$ dB，平均路损预算 $120 - 19 = 101$ dB。

$\log_{10} d = (101-40)/35 = 1.74$，$d = 10^{1.74} \approx 55$ 米。

```python
print(round(10 ** ((101 - 40) / 35), 1))
```

输出 55.1。覆盖率从 90% 提到 99%，半径从 100 米缩到 55 米——**最后 9 个百分点的覆盖，价格是接近一半的半径**。
</details>

**练习 3**：为什么阴影衰落叫"对数正态"？直接说"正态"不行吗？

<details>
<summary>点开查看逐步解答</summary>

损耗在线性倍数下是许多遮挡因子连乘；取 dB（对数）后连乘变连加，多个独立小损耗相加趋于正态。所以分布在线性坐标看是"对数正态"，在 dB 坐标看是标准正态。工程全部在 dB 域操作，所以"正态"三个字只有在 dB 世界里才成立——单位选错，分布就认错。
</details>

## 7. 边界与适用条件

- 模型要求 $d > d_0$（1 米以内是天线近场，谁的话都不算数）；室内、街道峡谷要换分段或专用模型（如 COST-231 系列），一个 n 走天下只在小范围内成立。
- 阴影余量的 $z\sigma$ 公式假设单小区边缘独立；真实网络有切换与小区合并增益，规划工具会用相关性修正。
- $n$ 与 $\sigma$ 都是实测统计量：不同城市、不同频段、天线高度都会改变它们，搬迁参数不搬迁测量等于换汤不换药。

## 8. 选读：为什么偏偏是正态

<details>
<summary>选读 · 中心极限定理在 dB 域的一次标准作案</summary>

电波从基站到你手机，路上翻过若干片遮挡：每片吃掉几 dB。关键在于 dB 把乘法改写成了加法——总损耗是各片损耗之和。第 36 章讲过：独立随机变量求和，分布向正态收敛（中心极限定理）。片数够多、没有一片独大，dB 域的损耗就逼近正态，线性域自然是"对数正态"。

这也解释了 σ 的物理出身：遮挡越碎、地物越杂，单项越多越杂，σ 越大。σ 不是模型的补丁参数，是地形复杂度的气温计。

</details>
