# 分集、均衡与 OFDM 直觉

## 1. 从一个场景开始

同一栋楼里，有人满格刷 4K，有人转个身就转圈。第 40 课的解释是：你恰好站在多径相消的深谷里；第 80 课补了一刀：深谷还会随时间变脸。深谷是无线世界的常态，**通信系统的全部本事，就是让深谷不再致命**。

这一课凑齐三板斧：**分集**——同一份内容多路下注，让"处处深谷"变成极小概率事件；**均衡器**——信道把星座拧歪了，就学出信道把它拧回来；**OFDM**——把宽带切成几百条窄带，让每条子信道都躺进平坦区。Wi-Fi 与 4G/5G 的地基，就是这三块砖。

## 2. 直觉解释

**分集是买彩票的艺术**。单支天线遇到深谷，像一张彩票中了"衰落实票"；两支相隔十几厘米的天线，各自经历**几乎独立**的深浅——两条都踩进深谷的概率是单条概率的平方。深谷从"常客"降级成"传奇"，靠的不是功率翻倍，而是概率开根号。

**均衡器是查账的会计**。第 62 章的 QAM 星座怕两件事：噪声把点抖糊，信道把点拧歪。均衡器先测量信道在各频率上的"扭曲系数"，再逐一乘上倒数，把星座拧回原位。账能平，但有代价——深谷处的倒数巨大，把噪声也一起放大了。

**OFDM 是化整为零的智慧**。第 80 课的判据说：带宽超过相干带宽就要遭遇频率选择性衰落。OFDM 干脆不跟深谷硬碰：20 MHz 切成 64 条 312.5 kHz 的窄条，每条远窄于相干带宽，条条平坦——**对一个复数乘法就能修正的平坦信道，均衡器退化成小学算术**。宽带的问题被"拆"没了，而不是"打赢"了。

## 3. 正式定义

**分集**：同一符号经 $L$ 条近似独立的衰落路径发送（时间错开、频率错开或空间错开），全深谷概率近似

$$P_{\text{全谷}} \approx p^L$$

$p$ 为单路深谷概率——阶数每加一，概率降一个量级。

**均衡**：信道频响 $H(f)$、接收 $y = Hx + n$ 时，频域一阶均衡取

$$\hat{x} = \frac{y}{\hat{H}}$$

$\hat{H}$ 是估计出的信道；$\hat{H}$ 小的频点噪声被放大 $1/|\hat{H}|$ 倍。

**OFDM**：把带宽 $B$ 分成 $N$ 条子载波，间隔 $\Delta f = B/N$，每条承载一段星座符号；设计条件

$$\Delta f \ll B_c$$

配合循环前缀（CP）长度不小于最大时延扩展，子信道互不串扰、各自平坦。

| 招式 | 治什么 | 一句话 |
| --- | --- | --- |
| 分集 | 深谷太深 | 多路下注，全谷概率指数下降 |
| 均衡 | 星座被拧歪 | 测信道、乘倒数，补回原形 |
| OFDM | 宽带撞深谷 | 化整为零，条条平坦 |

## 4. 分步例题

**例 1（空间分集）**：单天线深谷概率 1%，手机装两支独立天线，深谷概率变成多少？

1. 独立假设下：$P = 0.01^2 = 0.0001$；
2. 也就是说从"百分之一"降到"万分之一"；
3. 四支天线（Wi-Fi 路由器常态）：$0.01^4 = 10^{-8}$——亿分之一的传奇事件。

**例 2（频率分集）**：20 MHz 信号、相干带宽 4 MHz。把同一份数据错开 5 MHz 重发一次，两份都毁的概率多大？

1. 相隔 5 MHz 超过 $B_c$，两段频谱近似独立衰落；
2. 各自深谷概率设 1%：联合 $0.01^2 = 0.01\%$；
3. 结论：重发不是浪费，是把"频率彩票"买了两张。

**例 3（OFDM 参数账）**：Wi-Fi 2.4 GHz 用 64 点 FFT、子载波间隔 312.5 kHz（其中 52 条承载数据）。对照室内 $B_c = 4$ MHz 检查。

1. $312.5\text{ kHz} \ll 4\text{ MHz}$——每条子载波稳稳落在平坦区；
2. CP 取 0.8 微秒，盖过室内几十纳秒的时延扩展；
3. 每条子载波上的"均衡" = 乘一个复数；64 条并行 = 化整为零的完整闭环。

### 实验 1（viz）：宽带撞谷，窄带绕谷


怎么玩：横轴是频率（MHz），纵轴是信道增益。τ=0.05 微秒时深谷每 10 MHz 一道——20 MHz 宽带信号必跨两道谷，而 312.5 kHz 的 OFDM 子载波只是曲线上一个几乎平坦的小点。把 τ 拧小（室内变空旷）：谷距拉开，宽带也变"幸运"；拧大（金属仓库）：谷越来越密，宽带寸步难行。

### 实验 2（python）：分集把深谷降成传奇

```python title="深谷概率随分集阶数指数下降（固定种子抽验）"
import math
import random

p_single = 1 - math.exp(-0.25)   # 单路幅度跌破 0.5 的精确概率（Rayleigh）

p2 = p_single ** 2    # 平方运算：两路独立全谷 = 单路概率的平方
p4 = p_single ** 4    # 四路全谷：再平方一次

print(f"单路深谷: {round(p_single * 100, 1)}%")
print(f"两路分集: {round(p2 * 100, 2)}%")
print(f"四路分集: {round(p4 * 100, 2)}%")

random.seed(42)                        # 固定种子：抽验结果可复现
trials = 20000
deep = 0
for t in range(trials):
    a = math.sqrt(-math.log(1 - random.random()))   # 反变换采样 Rayleigh 幅度
    if a < 0.5:
        deep = deep + 1
print(f"20000 次抽验单路深谷占比: {round(deep / trials * 100, 1)}%")
```

怎么玩：精确账给出 22.1% → 4.89% → 0.24%——每加两路，深谷概率乘上一次 0.22。抽验行与 22.1% 对上，说明模型没跑偏。把门限 0.5 改成 0.3 再跑：单路概率掉到 4.4%，四路已是十万分之四。

### 实验 3（python）：均衡器的补丁与它的代价

```python title="信道凹陷多深，均衡补丁增益就多高"
import math
import matplotlib.pyplot as plt

tau = 0.05        # 时延差 0.05 微秒，与实验 1 同一信道
fs = []
hs = []
eqs = []
for k in range(61):
    f_mhz = float(k)
    h = abs(math.cos(math.pi * f_mhz * tau))
    eq = 1 / max(h, 0.05)     # max：把增益钳在 20 倍以内，防除零爆表
    fs.append(f_mhz)
    hs.append(h)
    eqs.append(eq)

plt.plot(fs, hs, label="channel |H|")
plt.plot(fs, eqs, color="tomato", label="equalizer 1/|H|")
plt.xlabel("frequency (MHz)")
plt.ylabel("gain")
plt.legend()
plt.grid(True)
```

怎么玩：蓝线是信道，深谷处接近零；红线是均衡器，在同样的位置竖起尖塔——**信道凹陷多深，补丁增益多高，噪声也按同倍数放大**。这就是为什么工程上用纠错编码横跨子载波"救谷"，而不是指望均衡器独自硬补。

### 快问快答

```quiz
OFDM 把宽带切成几百条窄子载波，根本目的是？
- 让发射功率变大
- 让每个子信道都变成平坦衰落，均衡退化为一次复数乘法 [*]
- 让天线数量变多
? 子载波间隔远小于相干带宽时，每条子载波只经历平坦衰落；宽带的选择性问题被拆解成几百个小学生的乘法题。
```

:::warning[常见误区]

**误区一**："你以为分集就是同一份数据发三遍，浪费三倍功率。" 分集的收益来自"多张独立的衰落彩票"，不是功率叠加；时间分集用编码重排、频率分集用跳频，一根天线也能玩。

**误区二**："你以为均衡器无所不能。" 深谷处 $1/\hat{H}$ 巨大，噪声同步放大，信噪比并没被治愈——均衡补的是"扭曲"，不是"深谷"。谷底保命要靠编码与分集。

**误区三**："你以为 OFDM 消灭了多径。" 它没有消灭，而是适应：CP 把时延扩展整个"吃掉"，子载波各自平坦。代价是 CP 占掉约十分之一的吞吐，且对频偏极其敏感——高铁上的 Doppler 校准（上一课）由此成为必修课。

:::

## 6. 练习

**练习 1**：某链路单路深谷概率 $p = 0.1$。改用两路独立天线后，"两路同时深谷"的概率是百分之几（取整）？代码能跑但把分集算成了翻倍：

```exercise
# @title: 练习：两路分集的深谷概率
# @check: 1
# @hint: 独立事件同时发生是概率相乘，不是相加翻倍
p = 0.1     # 单路深谷概率

p_two = p * 2     # ← 问题在这：分集不是把概率翻倍
print(round(p_two * 100))
```

改对后输出 1：$0.1^2 = 0.01$，即 1%。四路分集是 $0.1^4 = 0.0001$，万分之一——阶数每升一级，概率掉一个数量级。

**练习 2**：室内 $B_c = 4$ MHz。80 MHz 宽带至少要切多少条子载波才能条条平坦？实际系统为什么取 256？

<details>
<summary>点开查看逐步解答</summary>

$80/4 = 20$ 条起。实际取 256：一是凑 2 的幂让 FFT 高效（第 61 章 FFT 课的正餐），二是留保护间隔与导频子载波，三是 CP 再扣一块——理论下限只是入场券，工程还要付 FFT 效率与开销的账。
</details>

**练习 3**：均衡后深谷处的信噪比如何变化？设 $|\hat{H}| = 0.1$，信号被补 10 倍，算一算。

<details>
<summary>点开查看逐步解答</summary>

信号被乘 $10$ 倍恢复原样，但噪声同样被乘 $10$ 倍（补丁不认人）——信噪比**原地不动**，一分没赚。均衡把星座摆正，让后级判决能用上正确坐标；抗噪的账，还是得交给分集与编码。这正是三板斧缺一不可的原因。
</details>

## 7. 边界与适用条件

- $p^L$ 公式假设各路衰落独立；天线间距不够（相关系数高）时收益打折，手机内部两支天线实际是"高度相关加少量独立"的混合。
- OFDM 的 CP 与导频是硬开销：Wi-Fi 物理层效率因此打八折上下；对频偏与相位噪声敏感，多普勒补偿（上一课）是高铁场景的生死线。
- 均衡公式给的是频域一阶均衡（ZF）；实用系统常用 MMSE 变体在"补正"与"放大噪声"之间折价，深谷处宁可留一点残留扭曲。

## 8. 选读：子载波为什么互不干扰

<details>
<summary>选读 · 正交的 FFT 视角</summary>

OFDM 发端把数据直接铺在频域：每个子载波是一个复数星座点，整体做一次逆 FFT 变成时域波形。收端一次 FFT 就把各子载波分开——因为矩形脉冲的频移族恰好两两内积为零（正交），"几十个窄带滤波器"被一次矩阵乘法吞并。第 61 章 FFT 课的分治思想在这里兑现成吞吐率：64 点 FFT 用不到 1 微秒跑完，比任何模拟滤波器组都便宜。多径再添一笔：只要 CP 长过时延扩展，循环卷积在频域退化成逐子载波乘法——前面的 $\hat{x} = y/\hat{H}$ 才得以成立。

</details>
