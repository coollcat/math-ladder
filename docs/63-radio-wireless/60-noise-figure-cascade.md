# 噪声系数与级联系统

## 1. 从一个场景开始

深夜收听几百公里外的远程电台，你把音量拧到最大，信号还是糊在一片沙沙声里。工程师看了一眼电路图说：信号其实够用，坏在**信噪比从天线到解码芯片一路走低**——每经过一级电路，都掉一截。

奇怪的是，这些电路明明是放大器，为什么越放大越糟？因为**信号还没发烧，噪声已经到岗**：放大器在放大信号的同时，也放大了自己的嗡嗡声，还顺手添了一点新的。这一课给"添了多少"立一本账，并回答接收机设计的第一铁律——为什么第一级放大器最金贵。

## 2. 直觉解释

先认识那个永远在场的对手。任何导体里的电子都在做无规则热运动，哪怕天线接地、设备关机，这种骚动依然存在——它叫**热噪声**，是宇宙给所有电路收的"入场税"。

放大器像一台复印机：给它一份文件（信号）加一张底噪纸，它把两样都放大 G 倍，而且复印机自己还会往纸上撒墨点。于是**信噪比每过一级就降一点**。

衡量一台放大器"撒墨"有多严重的指标叫**噪声系数**：输入信噪比除以输出信噪比。理想复印机撒墨为零，噪声系数等于 1；现实器件都大于 1。

那把多台设备串起来呢？直觉说"各算各的取平均"，账本却揭示了更精妙的结构：**后级撒的墨会被前级的放大倍数稀释**——第一级还没有任何增益帮它撑腰，所以它的一点噪声最致命。这就是 Friis 级联公式的全部灵魂。

## 3. 正式定义

**热噪声底**：温度 $T$（开尔文）、带宽 $B$（赫兹）内，电阻型噪声源给出的噪声功率为

$$N = kTB$$

室温（290 K）下换算成 dBm，有工程速算：$-174$ dBm/Hz + $10\log_{10} B$。

**噪声系数**：定义比值

$$F = \frac{SNR_{\text{in}}}{SNR_{\text{out}}} \geq 1$$

工程上常用 dB 表示：$NF = 10\log_{10} F$（dB），3 dB 约等于信噪比打对折。

**Friis 级联公式**：增益 $G_1, G_2, \dots$、噪声系数 $F_1, F_2, \dots$ 的多级链路，总噪声系数为

$$F_{\text{总}} = F_1 + \frac{F_2 - 1}{G_1} + \frac{F_3 - 1}{G_1 G_2} + \cdots$$

| 符号 | 单位 | 含义 |
| --- | --- | --- |
| $k$ | J/K | 玻尔兹曼常数 $1.38\times 10^{-23}$ |
| $T$ | K | 绝对温度，室温常取 290 K |
| $B$ | Hz | 系统带宽，带宽越宽进来的噪声越多 |
| $F$ | 无量纲 | 噪声系数（比值），NF 是它的 dB 化身 |
| $G$ | 无量纲 | 功率增益（比值），dB 版即 $10\log_{10} G$ |

注意 $F_2-1$：减掉 1 是因为"输入里本来就有"的那份噪声不该记在后级头上；分母 $G_1$ 就是稀释效应——前级增益越大，后级的过错越显得无足轻重。

## 4. 分步例题

**例**：两级接收机。第一级低噪声放大器：$NF_1 = 2$ dB、$G_1 = 20$ dB；第二级混频器：$NF_2 = 10$ dB、增益忽略。求总噪声系数；再把两级顺序调换，看看会发生什么。

1. 换算比值：$F_1 = 10^{0.2} \approx 1.58$，$F_2 = 10^{1} = 10$，$G_1 = 10^{2} = 100$；
2. 正常顺序：$F_{\text{总}} = 1.58 + \dfrac{10-1}{100} = 1.58 + 0.09 = 1.67$；
3. 化成 dB：$NF_{\text{总}} = 10\log_{10} 1.67 \approx 2.2$ dB——与第一级的 2 dB 几乎没差；
4. 调换顺序（混频器在前）：$F_{\text{总}} = 10 + \dfrac{1.58-1}{100} \approx 10.01$，即 $NF \approx 10$ dB；
5. 结论：同样两个器件，仅仅换个座位，整机噪声从 2.2 dB 恶化到 10 dB——信噪比家底直接赔掉四倍多。

检查量级：第一级贡献 $F_1$ 裸奔，第二级贡献被 $G_1=100$ 压成 0.09——级联公式天然偏袒前排。

### 实验 2（python）：两级接收机的分账账本

```python title="Friis 级联：正常顺序 vs 错误顺序"
import math

# sliders: gain1_db=20 [0:40:1]

nf1_db = 2.0    # 第一级低噪声放大器的噪声系数（dB）
nf2_db = 10.0   # 第二级混频器的噪声系数（dB）

f1 = 10 ** (nf1_db / 10)     # dB 化身还原成比值：10 的 (NF/10) 次方
f2 = 10 ** (nf2_db / 10)
g1 = 10 ** (gain1_db / 10)   # 增益滑块同样从 dB 还原成比值

ft_good = f1 + (f2 - 1) / g1          # 正常顺序：低噪声放大器在前
ft_bad = f2 + (f1 - 1) / g1           # 错误顺序：把混频器放最前面
print(f"G1={gain1_db} dB 时：正常 NF={round(10 * math.log10(ft_good), 2)} dB")
print(f"调换顺序后 NF={round(10 * math.log10(ft_bad), 2)} dB")
```

怎么玩：默认 $G_1=20$ dB 时，正常顺序约 2.2 dB、调换后约 10.0 dB，相差 7.8 dB。把增益滑块拧到 0 dB：两级贡献平起平坐，谁在前都一样惨——**没有增益就没有豁免权**；拧到 40 dB，正常顺序进一步贴平 2 dB。

### 实验 3（python）：热噪声底有多"冷"

```python title="kTB 噪声底：带宽每宽十倍，噪声底抬 10 dB"
import math

# sliders: bw_mhz=20 [0.1:100:0.1]

k = 1.38e-23      # 玻尔兹曼常数（焦耳/开尔文）
t = 290           # 室温（开尔文）
b = bw_mhz * 1e6  # 带宽从 MHz 换算成 Hz：乘 10 的 6 次方

n_watt = k * t * b                       # 热噪声功率（瓦）
n_dbm = 10 * math.log10(n_watt / 1e-3)   # 换算 dBm：先除以 1 毫瓦再取对数
print(f"带宽 {bw_mhz} MHz 的热噪声底 = {round(n_dbm, 1)} dBm")
print(f"速算核对：-174 + 10log10(B) = {round(-174 + 10 * math.log10(b), 1)} dBm")
```

怎么玩：20 MHz 宽带对应约 −101 dBm 的噪声地板。第 30 课账单里 −70 dBm 的接收信号，落在 20 MHz 信道里信噪比约 31 dB——这就是"余量厚实"的物理含义。把带宽拧到 100 MHz：地板抬到约 −94 dBm，**宽带是把双刃剑**，速率和噪声一起涨。

### 快问快答

```quiz
接收机设计的第一铁律是：把噪声系数最小、增益最大的器件放在哪里？
- 链路的最后一级，负责收尾
- 链路的第一级，紧贴天线 [*]
- 放哪里都一样，总量守恒
? Friis 公式里后级贡献都要除以它前面的全部增益，唯独第一级的贡献原样计入。第一级噪声是系统永远洗不掉的底色。
```

:::warning[常见误区]

**误区一**："你以为放大器只放大信号。" 它对输入端的一切照单全收——信号、外来噪声、自己的热噪声一起放大，再额外添加新的。所以放大解决不了信噪比问题，只能冻结现状。

**误区二**："你以为无源器件没有噪声系数。" 一段 3 dB 的馈线本身就是 $F=2$（损耗一半、噪声不减）的一级。天线到低噪放之间的每一分贝电缆，都在白白抬升整机噪声——所以卫星接收机的低噪放要装在锅面正中央。

**误区三**："你以为噪声系数低的系统一定收得好。" NF 只管电路自己产生的噪声；天线收到的宇宙背景、城市人为噪声是"外来户口"，要靠选频、选址和天线方向图另案处理。

:::

## 6. 练习

**练习 1**：三级简化链路的比值参数已给好（$F_1=2$、$G_1=10$、$F_2=11$，第二级后增益很大）。代码能跑但总噪声系数算错了：

```exercise
# @title: 练习：两级级联的总噪声系数
# @check: 3.0
# @hint: Friis 公式里第二级的贡献是 (F2-1) 除以第一级增益——检查是不是忘了除以 G1
f1 = 2    # 第一级噪声系数（比值）
g1 = 10   # 第一级增益（比值）
f2 = 11   # 第二级噪声系数（比值）

ft = f1 + (f2 - 1)     # ← 问题在这：后级的过错要被前级增益稀释
print(ft)
```

改对后输出 3.0：$F_{\text{总}} = 2 + \dfrac{11-1}{10} = 3$，即 4.77 dB。若把 $g1$ 改成 100，第二级贡献缩到 0.1，$F_{\text{总}}=2.1$——稀释效应立刻现形。

**练习 2**：热噪声底速算：带宽从 1 MHz 加宽到 100 MHz，噪声底抬高多少 dB？

<details>
<summary>点开查看逐步解答</summary>

带宽乘 100，即 $10\log_{10} 100 = 20$ dB。1 MHz 时约 −114 dBm，100 MHz 时约 −94 dBm。

```python
import math
b1 = 1e6
b2 = 1e8
print(round(10 * math.log10(b2 / b1), 1))
```

输出 20.0。这就是"带宽翻十倍噪声抬 10 dB"的铁账——扩带宽提速率前，先想想灵敏度付不付得起。
</details>

**练习 3**：某接收机第一级 $NF_1=3$ dB、$G_1=10$ dB，第二级 $NF_2=6$ dB。求总 NF（dB，一位小数）。

<details>
<summary>点开查看逐步解答</summary>

$F_1 = 10^{0.3} \approx 2.0$，$F_2 = 10^{0.6} \approx 3.98$，$G_1 = 10$。

$F_{\text{总}} = 2.0 + \dfrac{3.98-1}{10} = 2.30$，$NF_{\text{总}} = 10\log_{10} 2.30 \approx 3.6$ dB。

```python
import math
f1 = 10 ** 0.3
f2 = 10 ** 0.6
ft = f1 + (f2 - 1) / 10
print(round(10 * math.log10(ft), 1))
```

输出 3.6。第二级足足 6 dB 的差货，整机只比第一级多了 0.6 dB——增益护体，名副其实。
</details>

## 7. 边界与适用条件

- Friis 公式假设各级线性、阻抗匹配、增益以功率比计；接收机前端常用"噪声温度" $T_e = 290(F-1)$ 等价表述，射电天文更爱用它。
- 无源损耗按 $F = L$（损耗比值）计级，混在链条里同样参与稀释；天线噪声温度与电路噪声温度相加才是系统全账。
- kTB 只是热噪声底；闪烁噪声、散粒噪声在低频和大电流下另计，NF 也随频率与偏置漂移，数据手册的曲线才是设计依据。

## 8. 选读：噪声温度为什么是"同一种话"

<details>
<summary>选读 · 从 kTB 到 F 的翻译表</summary>

把整条接收链折算到输入端：系统总噪声功率 = $k T_{\text{sys}} B$，其中 $T_{\text{sys}} = T_{\text{天线}} + T_{e1} + T_{e2}/G_1 + \cdots$，而 $T_e = 290(F-1)$。逐项对照 Friis 公式，会发现两条公式逐字同构——噪声温度只是把"信噪比比值"翻译成"开尔文温度"的方言，热噪声底 $kTB$ 是它们共同的祖先。

射电望远镜盯着 −260 ℃ 的冷天空追求 10 K 级系统温度，手机基站顶着 290 K 地面环境用 2~3 dB 的 NF——同一个公式，两种极端的人生。

</details>
