# 蜂窝频率复用：六边形棋盘上的频谱魔术

## 1. 从一个场景开始

一座千万人口的城市，几百万人同时举着手机；而分给运营商的频谱往往只有几十 MHz——按"一个频率只能一对通话用"的算法，连一条街都喂不饱。

现实里大家却打得火热。魔术的名字叫**频率复用**：同一个频率，在城里被反复使用了成百上千次——只要使用它的基站彼此隔开足够远，干扰就被距离驯服。隔多远才安全？这个问题有一个漂亮的几何答案，画在地图上是一盘六边形的棋。

## 2. 直觉解释

把城市切成一块块小区（cell），每块中央立一座基站，各自服务自己那块地盘：

- 相邻小区必须用**不同**的频率组，否则边界上的用户两头挨打；
- 隔开几个小区之后，同一组频率可以**原封不动地再次登场**——距离已经把同频信号衰减成了背景噪音。

这些小区在教科书上都画成正六边形：正方形有尖角覆盖浪费、圆形铺不满平面，而六边形是**能无缝铺满平面的形状中最接近圆的**——用最规则的几何逼近"每个方向等距覆盖"的理想。

同一簇内小区各用不同频率，这簇的图案叫**复用簇**；簇的大小 $N$ 是频率规划的头号参数。$N$ 越大，同频基站离得越远、干扰越小，但每个频率在单位面积里"出场率"越低——容量与质量又一对跷跷板。

## 3. 正式定义

**复用因子** $N$：簇内小区数。它必须能写成

$$N = i^2 + ij + j^2 \qquad (i, j \text{ 为非负整数，不同时为零})$$

合法取值：1, 3, 4, 7, 9, 12, 13, 19, …

**同频复用比**：本小区中心到最近同频小区中心的距离 $D$ 与小区半径 $R$ 之比

$$\frac{D}{R} = \sqrt{3N}$$

**最坏情形信干比**（移动台位于小区边缘，六个同频基站距离均近似 $D$）：

$$\frac{S}{I} \approx \frac{(D/R)^{\gamma}}{6} = \frac{(3N)^{\gamma/2}}{6}$$

其中 $\gamma$ 是路径损耗指数（自由空间 2，城区典型 3~4）。

| 符号 | 名字 | 直觉 |
| --- | --- | --- |
| $R$ | 小区半径 | 基站到六边形顶点 |
| $D$ | 复用距离 | 到最近同频基站的距离 |
| $N$ | 复用因子 | 一簇几种"频道配方" |
| $\gamma$ | 路径损耗指数 | 距离惩罚的狠度 |

## 4. 分步例题

**例**：GSM 经典配置 $N=7$、城区 $\gamma=4$。求 $D/R$ 与最坏 SIR，并换算 dB。

1. 验证合法性：$7 = 2^2 + 2\times1 + 1^2$，即 $(i,j)=(2,1)$ ✓；
2. 复用比：$D/R = \sqrt{21} \approx 4.58$；
3. 代入 SIR 公式：$\dfrac{(3\times7)^2}{6} = \dfrac{441}{6} = 73.5$；
4. 换算分贝：$10\log_{10} 73.5 \approx 18.7$ dB；
5. 结论：18.7 dB 恰好压过模拟 FM 语音约 18 dB 的门限——这不是巧合，$N=7$ 正是当年照着这条门槛反推出来的。

检查量级：若把 $N$ 缩到 3，SIR 掉到 $(9)^2/6=13.5$ 即 11.3 dB，语音开始"串台"——数字会说话。

### 实验 2（python）：亲手铺一张七频组蜂窝地图

```python title="N=7 蜂窝与六个最近同频小区"
import math
import matplotlib.pyplot as plt

R = 1.0                              # 小区半径
i, j = 2, 1                          # (2,1) 对应 N=7
N = i * i + i * j + j * j            # 复用因子公式

ux = math.sqrt(3) * R                # 网格基向量一：水平方向
uy = 0.0
vx = math.sqrt(3) / 2 * R            # 网格基向量二：斜向
vy = 1.5 * R

cells = [[0, 0], [i, j], [-j, i + j], [-i - j, i], [-i, -j], [j, -i - j], [i + j, -j]]
for c in cells:
    cx = c[0] * ux + c[1] * vx       # 六边形中心坐标：网格向量加权
    cy = c[0] * uy + c[1] * vy
    pxs = []
    pys = []
    for k in range(7):               # 七个顶点（首尾重合）画出六边形
        ang = math.pi / 6 + k * math.pi / 3
        pxs.append(cx + R * math.cos(ang))
        pys.append(cy + R * math.sin(ang))
    if c == [0, 0]:
        plt.plot(pxs, pys, color="tomato", linewidth=2.5)
        plt.text(cx, cy, "home", ha="center")
    else:
        plt.plot(pxs, pys, color="steelblue")
        plt.text(cx, cy, "same\nfreq", ha="center")

plt.title(f"N={N}, D/R={round(math.sqrt(3 * N), 2)}")
plt.axis("equal")                    # 两轴等比例，六边形不变形
plt.grid(True)
print(f"N={N}, D/R={round(math.sqrt(3*N), 3)}, SIR={round((3*N)**2/6, 1)} ({round(10*math.log10((3*N)**2/6), 1)} dB)")
```

怎么玩：红框是你的小区，蓝框是六个最近的同频邻居——它们沿 $(i,j)=(2,1)$ 方向整整齐齐排成两列。把 `i, j = 2, 1` 改成 `1, 1` 再跑一次：N 变 3，蓝圈逼近，SIR 掉到 11.3 dB——复用更激进、容量更大、质量更险。

### 实验 3（python）：滑块比较不同簇大小的质量账

```python title="N 与 gamma 双滑杆的 SIR 计算器"
import math

# sliders: n=7 [1:12:1], gamma=4 [20:50:5]

g = gamma / 10                       # 滑杆给整数，这里还原成 2.0~5.0
sir = (3 * n) ** (g / 2) / 6         # 最坏情形信干比
sir_db = 10 * math.log10(sir)

verdict = "达标"                     # 语音门限按 18 dB 参考
if sir_db < 18:
    verdict = "低于语音门限"
print(f"N={n}, gamma={g}: SIR={round(sir, 1)} = {round(sir_db, 1)} dB -> {verdict}")
```

怎么玩：固定 γ=4，从 N=1 扫到 12——合法簇大小里只有 7、9、12 越过语音门限（N 必须能写成 i²+ij+j²，8 和 11 只是滑杆路过）；再拧 γ=3（郊区开阔地），连 9 都危险了。频率规划的日常就是在这张表里找"够用又省频谱"的最小 N。

### 快问快答

```quiz
教科书蜂窝图为什么用正六边形而不是正方形或圆形？
- 六边形看起来像蜂巢，纯属审美传统
- 六边形是能无缝铺满平面中最接近圆形的形状 [*]
- 基站天线只能发出六边形信号
? 圆形覆盖最理想但铺不满；正方形能铺满却四角浪费且邻域方向不均匀。正六边形以最规则的形状逼近圆，还让每个小区恰好共享六条边、六个邻居——SIR 公式里的那个 6 就是它们。
```

:::warning[常见误区]

**误区一**："你以为同一个频率想在哪用就在哪用。" 复用是有纪律的重用：必须满足 $D/R=\sqrt{3N}$ 的几何间隔并校验 SIR 门限，否则不是扩容而是互相屠杀。

**误区二**："你以为小区越小越好（裂化增容）。" 小区半径减半，同样距离上切换次数翻倍、同频邻居同步逼近，SIR 却因几何不变而不变——裂化买容量的代价是切换与骨干网成本，不是免费的。

**误区三**："你以为现代网络还在老老实实画六边形。" CDMA/OFDMA 时代常用 $N=1$（全频复用），六边形让位给功率控制、调度与 ICIC 等软手段。六边形棋盘是理解一切复用的起点，而非终点。

:::

**练习 2**：某城市 $\gamma=3.5$。要保证最坏 SIR ≥ 15 dB，最小可用哪个 N？（候选 3、4、7、9）

<details>
<summary>点开查看逐步解答</summary>

逐个代入 $\dfrac{(3N)^{1.75}}{6}$ 并换算 dB：

- N=3：(9)^1.75/6 ≈ 7.8 → 8.9 dB ✗；
- N=4：(12)^1.75/6 ≈ 12.9 → 11.1 dB ✗；
- N=7：(21)^1.75/6 ≈ 34.3 → 15.4 dB ✓（贴线达标）。

答案 **N=7**。代码验证：

```python
import math
for n in [3, 4, 7, 9]:
    sir = (3 * n) ** 1.75 / 6
    print(n, round(10 * math.log10(sir), 1))
```
</details>

**练习 3**：把小区半径从 1 km 缩到 0.5 km（其他不变），同样频谱下城区容量大约变为几倍？代价是什么？

<details>
<summary>点开查看逐步解答</summary>

面积缩为 1/4 → 单位面积小区数 ×4 → 同样 N 下频率"出场率"×4，容量约 **4 倍**。代价：每部手机穿越边界更频繁，切换次数约翻倍（半径减半、周长减半而车速不变），基站回传与切换信令开销大增——裂化是用运维复杂度换容量。
</details>

## 7. 边界与适用条件

- SIR 公式假设移动台在小区边缘、六个同频基站等距 $D$、只计路径损耗不计阴影衰落与天线方向图——它是**下界估计**，真实网络靠仿真细化。
- $\gamma$ 取值随环境变化（2~5），规划前需路测拟合；$\gamma=2$ 时公式给出各 N 中最低的 SIR，是最保守的设计依据。
- 实际覆盖不是完美六边形：地形、建筑与业务热点把边界揉成不规则形状，"蜂窝"是理想化的规划语言。

## 8. 选读：(i,j) 方向怎么找同频小区

<details>
<summary>选读 · 六边形网格上的坐标法</summary>

把相邻小区中心的连线当作两条基向量：$u_1$（水平）与 $u_2$（斜 60°）。任一同频小区的中心可以写成 $i\,u_1 + j\,u_2$，其模长恰为 $\sqrt{i^2+ij+j^2}\times\sqrt3 R$——这就是 $N=i^2+ij+j^2$ 与 $D/R=\sqrt{3N}$ 的来历（勾股定理在斜坐标系下的版本）。

实验 2 里那六个蓝框，就是把 $(i,j)$ 分别旋转 60° 得到的六个方向：$(i,j)\to(-j,i+j)\to(-i-j,i)\to(-i,-j)\to(j,-i-j)\to(i+j,-j)$。整套几何只需要初中勾股与高中三角，却支撑起了全球几百张 GSM 网络——优雅公式最好的名片是"被全世界用了三十年"。

</details>
