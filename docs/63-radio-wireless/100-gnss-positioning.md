# 卫星导航与定位几何：伪距方程、钟差未知数、最小二乘解算与 DOP 精度因子

## 1. 从一个场景开始

手机刚出隧道，地图上的蓝点几乎瞬间归位。天上两万多公里处飘着几十颗卫星，每颗都揣着原子钟，而你口袋里的手机连秒都数不准——**凭什么四盏灯，就能把你钉在地图上？**

答案是一场几何与统计的合谋：每个"测距"其实是带钟差的伪距，每多一颗卫星多一行方程，最后用第 21 章的最小二乘一把收网。本章收官课，把全课程的账本在这里对齐。

## 2. 直觉解释

先想"纯粹版"：一颗卫星广播"我离你 20200 千米"，你就在以它为球心、半径 20200 千米的球面上——一个方程一个球。三个球面交汇，理论上交出一个点：三个坐标齐了。

但你手机的表不争气。信号飞行约 67 毫秒，手机石英钟哪怕差 1 微秒，测出的"距离"就虚报 300 米——**测出来的不是真距离，是真距离加一个统一的钟差偏置**，所以叫**伪距**。钟差成了第 4 个未知数：三个方程对四个未知数，账平不了，第四盏灯登场——四颗卫星、四个方程，位置和钟差一起解出来。

解出来只是开始。同样的测距噪声，几何形状会把它放大或压缩：四颗卫星挤在天顶一小片天空，水平位置被拉扯得没边；摊开到四面八方，误差就被压扁。放大倍数有个名字——**DOP（精度因子）**。"天空分布越开精度越好"这句口诀，本课把它算成数。

顺便划清地盘：第 57 章球面三角管的是"球面上两点的弧长与大圆航线"，那里是**量距离**；本课管"多个球面怎么交汇出位置"，是**解几何**——两门手艺互不重复。

## 3. 正式定义

**伪距方程**：第 $i$ 颗卫星位置 $(x_i, y_i, z_i)$、用户真位置 $(x_u, y_u, z_u)$、光速 $c$、接收机钟差 $\delta t$ 时，

$$\rho_i = \sqrt{(x_i-x_u)^2+(y_i-y_u)^2+(z_i-z_u)^2} + c\,\delta t$$

**线性化**：方程对位置是非线性的，在近似值 $(x_0, y_0, z_0)$ 附近做一阶泰勒展开（第 15 章），每颗卫星贡献一行：

$$\Delta\rho_i \approx -l_i\,\Delta x - m_i\,\Delta y - n_i\,\Delta z + c\,\Delta\delta t$$

其中 $(l_i, m_i, n_i)$ 是用户**指向卫星**的单位向量。四行叠成矩阵 $A$，就是第 21 章的正規方程素材。

**最小二乘一行解**：多于四颗卫星时方程过剩，取残差平方和最小者（第 21 章正规方程的原文）：

$$\Delta x = (A^T A)^{-1} A^T\,\Delta\rho$$

**DOP 精度因子**：测距噪声 $\sigma_\rho$ 经几何放大后的位置标准差

$$\sigma_{\text{pos}} = \text{DOP} \times \sigma_\rho$$

| 符号 | 单位 | 含义 |
| --- | --- | --- |
| $\rho_i$ | 米 | 伪距：真距离 + 钟差折算的光程 |
| $\delta t$ | 秒 | 接收机钟差（卫星钟由地面段精校） |
| $A$ | 无量纲 | 视线方向矩阵，每行末位恒为 1（钟差列） |
| HDOP/VDOP | 无量纲 | 水平/垂直精度因子，越小几何越好 |

## 4. 分步例题

把三维压成一个竖直剖面看 DOP 的来历：**三颗卫星对称排布**——一颗在天顶，两颗在同一仰角 $e$ 的左右两侧（方位对开）。三个未知数（水平 $x$、竖直 $z$、钟差），三个方程，正好方形，能手工解到底。

**例**：测距噪声 $\sigma_\rho = 1$ 米。求仰角 $e = 45^\circ$ 与 $e = 60^\circ$ 两种阵形的水平精度。

1. 组装 $A^T A$（三行分别为 $(0, -1, 1)$、$(-\cos e, -\sin e, 1)$、$(\cos e, -\sin e, 1)$ 的 $A$ 自乘）；
2. 水平列恰好与其他未知数解耦，位置误差方差 $= \sigma_\rho^2/(2\cos^2 e)$，即 HDOP $= \dfrac{1}{\sqrt{2}\cos e}$；
3. $e = 45^\circ$：HDOP $= 1.0$，水平误差 1.0 米；竖直方向解出约 1.18 米；
4. $e = 60^\circ$：HDOP $= 1.41$，水平误差恶化到 1.41 米；竖直反而改善到约 0.99 米；
5. 结论：**卫星挤向天顶，水平被放大；卫星压向地平，竖直被放大**——"摊开"的真义是仰角、方位都不扎堆，这也是接收机选星算法"最大体积"原则的出处。

怎么玩：横轴是（对称两侧卫星的）仰角，纵轴是水平精度因子。$45^\circ$ 处 HDOP = 1 是黄金位置；拧到 $85^\circ$（卫星全挤在头顶），HDOP 冲上 8——同样的 1 米测距噪声，水平误差放大八倍。曲线两头高中间低的"谷"，就是选星算法要找的甜点区。

### 实验 2（python）：DOP 公式的蒙特卡洛验证

```python title="抽验：水平误差标准差 = 1/(√2·cos e)（固定种子）"
import math
import random

# sliders: elev_deg=45 [10:85:5]

random.seed(21)                    # 固定随机种子：每次运行同一批抽验
c = math.cos(math.radians(elev_deg))   # math.radians：角度换弧度
trials = 30000
acc = 0.0
acc2 = 0.0
for t in range(trials):
    y2 = random.gauss(0, 1)        # gauss：抽一个均值 0、标准差 1 的正态数
    y3 = random.gauss(0, 1)
    dx = (y3 - y2) / (2 * c)       # 最小二乘解出的水平误差（解析形式）
    acc = acc + dx
    acc2 = acc2 + dx * dx

mean = acc / trials
var = acc2 / trials - mean * mean          # 方差 = 平方均值 − 均值平方
formula = 1 / (math.sqrt(2) * c)
print(f"公式 HDOP = {round(formula, 3)}")
print(f"抽验标准差 = {round(math.sqrt(var), 3)}（均值 {round(mean, 3)}）")
```

怎么玩：默认 $45^\circ$ 时公式与抽验都在 1.0 附近对上——3 万次抽验就是公式的人肉证据。把仰角拧到 $75^\circ$：两边一起跳到约 2.73，几何放大毫不留情；拧回 $20^\circ$，HDOP 约 0.75，水平最舒适（竖直的账见例题）。

### 实验 3（python）：四步收网——伪距、线性化、最小二乘

```python title="对称三星阵：从伪距残差解出位置偏移与钟差"
import math

r_orbit = 2e7          # 卫星轨道半径（米），约 2 万公里
e = 45.0
ce = math.cos(math.radians(e))    # 视线向量的水平分量
se = math.sin(math.radians(e))    # 竖直分量

sats = [(0.0, 1.0), (-ce, se), (ce, se)]   # 三颗卫星的方向（单位向量）
truth = (2.0, 3.0, 5.0)                    # 真值：偏移 x=2, z=3, 钟差光程=5 米

rows = []
rho = []
for ex, ez in sats:
    sx, sz = ex * r_orbit, ez * r_orbit          # 卫星坐标
    d = math.sqrt((sx - truth[0]) ** 2 + (sz - truth[1]) ** 2)
    rho.append(d + truth[2] - r_orbit)           # 伪距残差：真距离 + 钟差 − 参考距离
    rows.append((-ex, -ez, 1.0))                 # A 的一行：负视线方向 + 钟差列

mtm = [[sum(rows[k][i] * rows[k][j] for k in range(3)) for j in range(3)] for i in range(3)]
aty = [sum(rows[k][i] * rho[k] for k in range(3)) for i in range(3)]

det = (mtm[0][0] * (mtm[1][1] * mtm[2][2] - mtm[1][2] * mtm[2][1])
       - mtm[0][1] * (mtm[1][0] * mtm[2][2] - mtm[1][2] * mtm[2][0])
       + mtm[0][2] * (mtm[1][0] * mtm[2][1] - mtm[1][1] * mtm[2][0]))   # 克拉默法则的分母
sol = []
for j in range(3):
    m = [row[:] for row in mtm]                  # 复制矩阵，准备替换第 j 列
    for i in range(3):
        m[i][j] = aty[i]
    dj = (m[0][0] * (m[1][1] * m[2][2] - m[1][2] * m[2][1])
          - m[0][1] * (m[1][0] * m[2][2] - m[1][2] * m[2][0])
          + m[0][2] * (m[1][0] * m[2][1] - m[1][1] * m[2][0]))
    sol.append(dj / det)

print("解出的偏移与钟差（应接近 2, 3, 5）：")
print([round(v, 2) for v in sol])    # round：列表里每个数保留两位小数
```

怎么玩：真值藏在伪距里，代码只拿到三行残差—— $A^T A$ 与 $A^T\Delta\rho$ 组装后，克拉默法则替 $(A^T A)^{-1}$ 跑完最后一步，三个未知数全部归位。这就是接收机芯片每秒上演亿万次的戏码，只不过它用 30 颗卫星的超定方程和矩阵库，而不是 3 颗卫星和克拉默。

```quiz
定位明明只需要三个坐标，为什么至少要四颗卫星？
- 第四颗卫星用于信号备份，坏了顶上
- 三个坐标之外，接收机钟差是第四个未知数 [*]
- 四颗卫星的信号叠加后功率更强
? 每颗卫星给一个伪距方程，伪距里混着接收机钟差这个谁也躲不开的未知数。四盏灯四个方程，位置和钟差一起解出。
```

:::warning[常见误区]

**误区一**："你以为手机表差几微秒无所谓。" 1 微秒 × 光速 = 300 米。钟差不是精度问题，是**结构问题**——不解出它，所有伪距一起偏，交点根本不收敛。

**误区二**："你以为卫星越多精度一定越好。" 加星一般有益，但挤在同一小片天空的新卫星对几何几乎没贡献；决定 DOP 的是分布的"体积"，不是数量。均匀四面开花，才把误差压扁。

**误区三**："你以为测距 1 米准、定位就 1 米准。" 定位误差 = DOP × 测距误差。同样的 1 米测距，好几何给 1.5 米定位，烂几何能给 8 米——收星之前，先看天。

:::

## 6. 练习

**练习 1**：对称三星阵仰角 $60^\circ$，测距噪声 $\sigma_\rho = 2$ 米。求水平定位误差（米，一位小数）。代码能跑但掉进了弧度陷阱：

```exercise
# @title: 练习：DOP 账本算水平误差
# @check: 2.8
# @hint: math.cos 吃弧度不吃角度——先把 60 过一遍 math.radians；σ_h = σρ × HDOP
import math

elev = 60.0        # 卫星仰角（度）
sigma_rho = 2.0    # 测距噪声（米）

hdop = 1 / (math.sqrt(2) * math.cos(elev))   # ← 问题在这：60 被当成了弧度
print(round(sigma_rho * hdop, 1))
```

改对后输出 2.8：HDOP $= \dfrac{1}{\sqrt{2}\cos 60^\circ} \approx 1.414$，$\sigma_h = 2 \times 1.414 \approx 2.8$ 米。原式算出负值——把 60 弧度（约 15 个半圈）塞进余弦，几何当场翻车。

**练习 2**：三颗卫星能不能"凑合"定位？什么时候三颗就够了？

<details>
<summary>点开查看逐步解答</summary>

若接收机配了原子钟级的时间源（比如地基增强、或先解出钟差后再定位），钟差已知，三颗卫星三个方程解三个坐标即可。手机不行——石英钟漂移是分钟级的，所以量产方案永远把钟差当未知数：**第四颗卫星不是冗余，是给钟买的赎金**。多出的第五、六颗才是真正的冗余，用来剔除坏星与提升完好性。
</details>

**练习 3**：某时刻 HDOP = 1.5、VDOP = 2.0，测距噪声 1 米。三维位置误差（PDOP 口径）是多少？

<details>
<summary>点开查看逐步解答</summary>

PDOP $= \sqrt{\text{HDOP}^2 + \text{VDOP}^2} = \sqrt{1.5^2 + 2^2} = 2.5$，三维误差 $= 2.5 \times 1 = 2.5$ 米。

```python
import math
print(round(math.sqrt(1.5 ** 2 + 2.0 ** 2) * 1.0, 2))
```

输出 2.5。三个方向的误差方差相加再开方——勾股定理在误差世界里的日常加班。
</details>

## 7. 边界与适用条件

- 线性化一步到位只在初值离真值近时成立；冷启动时接收机从粗初值迭代三到五轮（每轮重算 $A$ 与 $\Delta\rho$），米级初值也能收敛到亚米级。
- 伪距里还藏着电离层与对流层延迟（数米到数十米），双频观测量与模型修正另账处理；城市峡谷的多路径（本章第 40 课的老对手）会让个别伪距带病上岗。
- 本课的对称阵公式是教学简化；真实 DOP 由当前可见卫星的 $A^T A$ 数值求逆得出，选星、权重与故障检测是接收机的看家本领。

## 8. 选读：对称三星阵的闭式分解

<details>
<summary>选读 · 例题那两条 DOP 公式的来历</summary>

三行 $A$ 自乘得 $A^T A$：水平列只有两侧卫星贡献 $2\cos^2 e$，且与竖直、钟差列正交（两侧符号相消）——于是水平方差独立成块，$\sigma_h^2 = \sigma_\rho^2/(2\cos^2 e)$，这就是 HDOP $= 1/(\sqrt{2}\cos e)$ 的全部身世。剩下 $(1+2\sin^2 e,\ 1+2\sin e;\ 1+2\sin e,\ 3)$ 的二阶块管竖直与钟差，二阶行列式 $2 + 6\sin^2 e - 4\sin e$ 出手后即得例题里的 VDOP 数字。第 21 章"正規方程把耦合拆成对称矩阵"的手法，在两万公里的高空照常营业。

</details>
