# 电波与频谱：看不见的高速公路

## 1. 从一个场景开始

按下汽车钥匙，隔着两排楼车门"咔哒"解锁了；同一时刻，你家的 Wi-Fi 正穿过三堵墙把视频送进卧室，而阳光却连一张纸都穿不透。

同样是"波"，待遇怎么差这么多？答案藏在两个字里——**波长**。这一课我们把电磁波的"出厂参数表"读明白：频率、波长、速度之间那条铁律，以及它如何决定谁适合远行、谁适合扛包。

## 2. 直觉解释

想象向池塘扔石子：水波一圈圈往外跑，**每秒跑过的圈数**是频率，**相邻两个波峰的间距**是波长。水波跑得不快，但电磁波是波里的短跑冠军——真空里永远以光速 $c \approx 3\times 10^8$ 米/秒飞驰。

速度、频率、波长被一条铁律锁死：

$$c = f \times \lambda$$

频率翻倍，波长就得减半——三个量里定了两个，第三个没有自由。这条"速度守恒"式的约束，就是整个无线电世界的地基：

- 频率低（波长长）：绕过障碍的本事大（广播信号能翻山），但一秒钟驮不了多少数据；
- 频率高（波长短）：数据带宽宽得像八车道（5G、Wi-Fi 6E），却容易被墙挡住、被雨打散。

Wi-Fi 常用的 2.4 GHz 频段，波长只有约 12 厘米——和你家防盗网上面的缝隙差不多大，所以它"见缝就钻、遇墙就跪"，行为完全可以用几何直觉去猜。

## 3. 正式定义

**电磁波**：变化的电场与磁场互相激发、以波动形式在空间传播。真空中速度为光速

$$c \approx 2.998\times 10^8 \text{ m/s} \approx 3\times 10^8 \text{ m/s}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $f$ | 频率 | 赫兹 Hz | 每秒振动的次数 |
| $\lambda$ | 波长 | 米 | 一个完整波形的空间长度 |
| $T$ | 周期 | 秒 | 振动一次的时间，$T = 1/f$ |
| $c$ | 波速 | m/s | 真空中等于光速 |

核心关系式（单行写全）：

$$\lambda = \frac{c}{f}$$

**频谱**：把无线电按频率切成一段一段的"车道"，每段叫一个**频段**。频段是国家级稀缺资源——中国规定 2400–2483.5 MHz 为免执照的 ISM 频段，Wi-Fi、蓝牙、微波炉都在这里挤公交（出处：工业和信息化部信部无〔2002〕353 号通知）。

## 4. 分步例题

**例**：Wi-Fi 的 2 号信道中心频率是 2437 MHz，求它的波长。

1. 统一单位：$f = 2437 \text{ MHz} = 2.437\times 10^9$ Hz；
2. 代入公式：$\lambda = \dfrac{3\times 10^8}{2.437\times 10^9}$；
3. 先算数量级：$\dfrac{3}{24.37}\times 10^{-1} \approx 0.1231$ 米；
4. 结论：$\lambda \approx 12.3$ 厘米——比你的手掌略短。

检查量级：频率在 GHz 量级的电波，波长必在厘米~分米量级；若算出几米或几微米，立刻回头查指数。

## 5. 动手实验

### 实验 1（viz）：波形三要素热身

```viz
{
  "type": "wave",
  "title": "一行波的三个旋钮",
  "A": 1,
  "f": 2,
  "phi": 0
}
```

怎么玩：拖动 f 把波拧密——横向上"单位长度塞进更多周期"，这正是"高频"的几何含义。记住这个画面：频率管疏密，而波长就是相邻波峰的距离。

### 实验 2（python）：常见业务的波长表

```python title="算一张「你身边的电磁波」波长对照表"
import math

C = 3e8                       # 光速近似值：3×10^8 米/秒
services = [
    ["调频广播", 100e6],       # 100 MHz = 100×10^6 Hz，e 记数法首见于科学记数法课
    ["手机 GSM", 900e6],
    ["GPS L1 民用码", 1575.42e6],
    ["Wi-Fi 信道1", 2412e6],
    ["微波炉", 2450e6],
    ["5G 主力", 3500e6],
]
for item in services:
    name = item[0]
    f = item[1]
    lam_m = C / f                        # 波长 = 光速 ÷ 频率
    lam_cm = lam_m * 100                 # 换成厘米更直观
    print(f"{name}: {round(f/1e6)} MHz -> {round(lam_cm)} cm")
```

注意微波炉（2450 MHz）和 Wi-Fi 信道 1（2412 MHz）几乎肩并肩——它们共用 ISM 频段，这就是"热剩饭时 Wi-Fi 掉线"的物理原因：邻居太近了。

### 实验 3（python）：滑块看波长如何决定波形密度

```python title="固定 2 米窗口，不同频率的空间波形"
import math
import matplotlib.pyplot as plt

# sliders: f_mhz=2450 [100:10000:50]

C = 3e8                          # 光速（米/秒）
lam = C / (f_mhz * 1e6)          # 由频率算波长（米）
xs = []
ys = []
for i in range(600):
    x = i * 2 / 599              # 观察窗固定 0 到 2 米
    xs.append(x)
    ys.append(math.sin(2 * math.pi * x / lam))   # 空间正弦波：位置代替时间当横轴

plt.plot(xs, ys)
plt.title(f"f={f_mhz} MHz, wavelength={round(lam*100, 1)} cm")
plt.xlabel("position (m)")
plt.grid(True)
```

怎么玩：把滑块从 100 MHz 拉到 10000 MHz，窗口里的周期数疯狂增殖。低频时 2 米装不下一个完整周期（波长 3 米），高频时密得像百叶帘——**频率每升十倍，同样窗口里的周期就多十倍**。


:::warning[常见误区]

**误区一**："你以为无线电像声音一样靠空气传播。" 电磁波不需要介质，真空中跑得最欢；太阳光穿越 1.5 亿公里真空才到你脸上。声音才是"没空气就哑"的那位。

**误区二**："你以为频率越高信号越强。" 频率只决定波长和带宽潜力，不决定功率。高频反而更容易被墙吸收——5 GHz Wi-Fi 穿墙不如 2.4 GHz，正是这条规律的日常体验。

**误区三**："你以为波长是从公式背出来的数。" 它有真实的几何身份：拿一把尺子对着天线附近的场分布量，相邻波峰间距就是它。12 厘米意味着比这小的障碍物主要反射它，比这大的才谈得上"阻挡"。

:::

## 6. 练习

**练习 1**：已知某蓝牙设备工作在 2450 MHz，求波长是多少厘米（四舍五入到整数）。下面的代码能跑，但答案明显不对——找到那个换算错误：

```exercise
# @title: 练习：蓝牙信号的波长
# @check: 12
# @hint: λ = c ÷ f 得到的是"米"；题目要厘米，检查最后一行的换算系数是 ×100 还是 ×1000
C = 3e8            # 光速（米/秒）
f = 2450e6         # 蓝牙频率（赫兹）

lam_m = C / f          # 波长（米）
lam_cm = lam_m * 1000  # ← 问题在这：这是毫米不是厘米
print(round(lam_cm))
```

改对后输出 12：蓝牙波长约 12 厘米，和 Wi-Fi 同量级——毕竟住在同一个频段隔壁。

**练习 2**：光从月球（距地球约 384000 千米）到地球需要多久？用"距离 = 速度 × 时间"反推，并解释为什么登月通话会有明显延迟。

<details>
<summary>点开查看逐步解答</summary>

时间 = 距离 ÷ 速度 = $3.84\times 10^8$ 米 ÷ $3\times 10^8$ 米/秒 ≈ **1.28 秒**（单程）。地面控制员说一句话，宇航员约 2.6 秒后才能听到回应——电视直播里的尴尬停顿全是这段光程账。验证代码：

```python
d = 3.84e8      # 月地距离（米）
c = 3e8         # 光速（米/秒）
print(round(d / c, 2))
```
</details>

## 7. 边界与适用条件

- 公式 $\lambda = c/f$ 中的 $c$ 是**真空**光速；在同轴电缆或介质板里，波速降到 $c/\sqrt{\varepsilon_r}$，波长同步缩短（工程上叫"波长缩短效应"）。
- "低频绕射强、高频带宽宽"是统计倾向而非铁律，具体环境要实测；本课只建立数量级直觉。
- 频段划分各国不同，本文引用的中国 ISM 规定（20 dBm EIRP 上限等）会在链路预算一课直接上岗。

## 8. 选读：频谱为什么按段拍卖

<details>
<summary>选读 · 频率资源的经济学一面</summary>

两个电台若在同一城市用同一频率同时开播，接收机收到的是两列无法分离的叠加波——信息全部搅在一起。所以频谱必须"分车道"：国家把 30 kHz~300 GHz 划成无数频段，分配给广播、移动、雷达、天文……其中 2.4 GHz 这类 ISM 频段例外地"先到先得、功率受限"，于是成了 Wi-Fi 与蓝牙的公共广场。

2021 年工信部通知进一步明确：2400 MHz 频段设备 EIRP 大于 20 dBm 需申请执照。你看，第 3 节那张表不只是物理，还是法律——下一课我们讲的天线增益，会直接决定你这台设备"法律上允许喊多大声"。

</details>
