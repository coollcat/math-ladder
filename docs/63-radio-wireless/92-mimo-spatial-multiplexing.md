# MIMO：把空间也变成车道

## 1. 从一个场景开始

家里的 Wi-Fi 路由器从两根天线换成四根，网速直接翻了倍——功率没加、带宽没宽，多出来的速度从哪来的？第 40 课的误区卡里埋过一句伏笔："MIMO 技术反手利用多径，把多条路径当作并行车道。"当时只敢点到为止，因为拧出这些车道要用一件重家伙：第 21 章的 SVD。

第 90 课的分集让多支天线**轮流备份**，用概率开根号保命；这一课让多支天线**同时开工**，各自发一路不同的数据流——空间本身就是新车道。这就是 MIMO（多输入多输出）：5G 与现代 Wi-Fi 的速度发动机。

## 2. 直觉解释

**分集与复用，同一副天线的两种活法**。深谷面前，两支天线发同一份数据，赌的是"两条衰落彩票同时输"是小概率（第 90 课的空间分集）；深谷不深时，两支天线干脆各发各的，一条链路瞬间变两条——买保险还是开新车，取决于信道此刻的脾气。MIMO 的本事是**在两者之间无缝换挡**，这一课只讲后一种：空间复用。

**串扰不是敌人，是待拧的麻花**。两支天线同时发射，接收端两支天线各自收到的都是两路信号的混叠——账面上看是灾难。但第 21 章的 SVD 说：任何矩阵都能拆成"旋转 × 拉伸 × 旋转"。把信道矩阵 H 拆开，发端先做一次旋转（预编码），收端再做一次反向旋转（合并），串扰这块麻花就被拧直了——剩下的每一条子信道各跑各的数据流，互不打架。

**容量线性增长的源泉是空间自由度**。香农公式（第 62 章）说一条信道的容量是 $\log_2(1+\text{SNR})$——加功率只换来对数缓涨。而 2×2 MIMO 拆出两条并行子信道，容量是两条相加；4×4 拆出四条。天线对数翻倍，车道翻倍，容量翻倍——这是无线通信里唯一能买到**线性增长**的货币：空间。

## 3. 正式定义

收发两端各有 $N_t$ 根发射、$N_r$ 根接收天线时，窄带信道是一个矩阵：

$$y = Hx + n$$

$H$ 是 $N_r \times N_t$ 信道矩阵（元素是收发天线对之间的复增益），$x$ 是发射向量，$n$ 是噪声。对 $H$ 做 SVD 分解 $H = U\Sigma V^{\mathsf T}$（复信道严格说应取共轭转置 $V^{\mathsf H}$，本课沿用第 21 章的实记号），奇异值 $\sigma_1 \ge \sigma_2 \ge \cdots$ 就是并行子信道的电压增益。

**空间复用容量**（每条子信道按同一 SNR 供电的对拍口径）：

$$C = \sum_i \log_2\left(1 + \sigma_i^2 \cdot \text{SNR}\right)$$

| 记号 | 名字 | 读法 |
| --- | --- | --- |
| $N_t, N_r$ | 收发天线数 | 空间车道的两头接口 |
| $\text{rank}(H) \le \min(N_t, N_r)$ | 空间自由度 | 并行子信道的条数上限——线性红利的账本 |
| $\sigma_i$ | 第 $i$ 个奇异值 | 第 $i$ 条子信道的电压增益，$\sigma_i^2$ 是功率增益 |
| $U, V$ | 左右旋转 | 收端合并矩阵与发端预编码矩阵（见选读） |
| $\text{SNR}$ | 每流信噪比 | 本课取"每条子信道同功率"口径，见边界与适用条件 |

**分集与复用一句话对照**：分集把"全深谷概率"从 $p$ 压到 $p^L$（第 90 课），复用把容量从 1 条车道抬到 $\min(N_t,N_r)$ 条——前者买保险，后者修路。

## 4. 分步例题

**例 1（手拆 2×2 信道）**：信道矩阵 $H = \begin{bmatrix} 1 & 0.8 \\ 0.8 & 1 \end{bmatrix}$（对角线是两条直射路径，0.8 是天线间串扰），SNR = 10。

1. $H$ 对称，第 21 章的结论直接上岗：对称矩阵的特征值是 $1 \pm 0.8$，即 1.8 与 0.2；
2. 两个特征值都是正数，奇异值就是它们本身：$\sigma_1 = 1.8$、$\sigma_2 = 0.2$；
3. 增益条：$\sigma_1^2 = 3.24$、$\sigma_2^2 = 0.04$——第一条车道的功率增益是第二条的 81 倍；
4. 容量逐条记账：$\log_2(1+3.24 \times 10) + \log_2(1+0.04 \times 10) = \log_2 33.4 + \log_2 1.4 \approx 5.06 + 0.49 = 5.55$ bit/s/Hz；
5. SISO 对照：$\log_2 11 \approx 3.46$——多花一倍天线与射频链路，多赚六成容量。

**例 2（天线翻倍账）**：把 SNR = 10 代进同一公式，数一数车道数：

1. 1×1（SISO）：$\log_2 11 \approx 3.46$；
2. 2×2 正交信道（两条满增益子信道）：$2 \times 3.46 = 6.92$——恰好翻倍；
3. 4×4 正交信道：$4 \times 3.46 = 13.84$——天线翻倍、容量翻倍，线性红利实打实；
4. 对照例 1 的串扰信道（5.55）：串扰偷走的是**每条车道的增益**，不是**车道本身**——SVD 拧完麻花，第二条弱车道照样白赚 0.49。

### 实验 2（python）：SVD 拆信道，对拍容量公式

```python title="2×2 信道矩阵的 SVD 分解与容量对拍"
import math
import numpy as np                        # 数值库（第 21 章正式引入）：矩阵与 SVD 都在这里

H = np.array([[1.0, 0.8], [0.8, 1.0]])    # 2×2 信道矩阵：对角线直射路径，0.8 是串扰
U, s, Vt = np.linalg.svd(H)               # SVD 三件套：左旋转 U、奇异值 s、右旋转 Vᵀ（多重赋值一次接住）
snr = 10.0                                # 每条子信道分到的信噪比（线性值，不是 dB）

cap = 0.0
for i in range(len(s)):                   # 逐条并行子信道记账
    gain = s[i] ** 2                      # λᵢ²：第 i 条子信道的功率增益
    cap = cap + math.log2(1 + gain * snr) # 香农公式：每条子信道各算各的 log₂(1+ρ)
    print(f"子信道 {i}: 增益 λ² = {round(gain, 2)}, 单条容量 = {round(math.log2(1 + gain * snr), 2)} bit/s/Hz")

print(f"奇异值 = {round(s[0], 1)}, {round(s[1], 1)}")
print(f"2×2 MIMO 总容量 = {round(cap, 2)} bit/s/Hz")
print(f"SISO 对照 = {round(math.log2(1 + snr), 2)} bit/s/Hz")
```

怎么玩：奇异值稳稳落在 1.8 与 0.2 上，与例 1 的手算严丝合缝；总容量 5.55 对拍成功。把矩阵里的 0.8 改成 0.3 再跑：信道变正交，奇异值奔着 1.3 与 0.7 去，两条车道更均衡——串扰越小，车道越平。

### 实验 3（python）：天线翻倍、容量翻倍

```python title="车道数从 1 到 4，容量线性爬坡"
import math

def mimo_cap(gains):                      # 给定各并行子信道的 λ² 清单，按香农逐条加总
    c = 0.0
    for g in gains:
        c = c + math.log2(1 + g * 10.0)   # SNR 固定取 10，方便横向对比
    return c

print(f"1×1 SISO    : {round(mimo_cap([1.0]), 2)} bit/s/Hz")
print(f"2×2 串扰 0.8 : {round(mimo_cap([3.24, 0.04]), 2)} bit/s/Hz")
print(f"2×2 正交信道 : {round(mimo_cap([1.0, 1.0]), 2)} bit/s/Hz")
print(f"4×4 正交信道 : {round(mimo_cap([1.0, 1.0, 1.0, 1.0]), 2)} bit/s/Hz")
```

怎么玩：3.46 → 6.92 → 13.84，天线数每翻一倍容量精确翻倍；串扰信道卡在 5.55，介于中间。把 SNR 改成 1 再跑：四行变成 1.0、2.14、2.0、4.0——低信噪比时弱车道只剩 0.06 的一点点贴补，正交信道的翻倍依然铁打。

### 快问快答

```quiz
空间复用的容量随天线数线性增长，这个"线性"数的是？
- 发射功率
- 收发天线对数 min(Nt, Nr)，即空间自由度 [*]
- 占用的频谱带宽
? 每一对收发天线之间多出一条近似独立的并行子信道，SVD 把它们拧出来；功率与带宽不变，车道数翻了倍。
```

:::warning[常见误区]

**误区一**："你以为 MIMO 快靠的是功率大。" 复用的每一分容量都来自空间自由度：功率、带宽照旧，车道多了条数自然翻倍。加大功率只会撞上对数缓涨的墙（第 62 章），修路才是硬通货。

**误区二**："你以为天线越多越好，随便摆。" 线性红利的前提是各条子信道**近似独立**——天线挤在一起、散射不富，H 的秩缩水，十根天线也拧不出十条车道。手机里两根天线是"高相关加少量独立"的混合，收益先打折。

**误区三**："你以为 SVD 一拆就万事大吉。" 拆的前提是收发两端都**知道 H**——导频估计加反馈，信道老化快时账本说过期就过期（第 80 课的相干时间）；而且例 1 的弱车道在低 SNR 下贡献趋近于零，注水功率分配会干脆不给它供电。

:::

## 6. 练习

**练习 1**：信道矩阵 $H = \begin{bmatrix} 1 & 0.6 \\ 0.6 & 1 \end{bmatrix}$ 已被 SVD 拆成奇异值 1.6 与 0.4，SNR = 10。代码能跑，但把两条车道并成了一条算账：

```exercise
# @title: 练习：0.6 串扰信道的容量账
# @check: 增益条: 2.56, 0.16
# @check: 容量 = 6.11
# @hint: 容量要"逐条子信道算完再相加"：Σ log₂(1+λᵢ²·SNR)。先把增益加总再一次对数，等于把两条车道并成一条，账就错了。
import math

s1, s2 = 1.6, 0.4      # SVD 拆出的两个奇异值（信道 [[1, 0.6], [0.6, 1]] 的拆解结果）
snr = 10.0

g1 = s1 * s1           # λ₁²：第一条子信道的功率增益
g2 = s2 * s2           # λ₂²：第二条子信道的功率增益
cap = math.log2(1 + (g1 + g2) * snr)     # ← 问题在这：增益先加总再一次对数，两条车道被并成了一条

print(f"增益条: {round(g1, 2)}, {round(g2, 2)}")
print(f"容量 = {round(cap, 2)}")
```

改对后容量 6.11：$\log_2 26.6 + \log_2 2.6 \approx 4.73 + 1.38$——比并成一条账（4.82）多赚 1.29 bit/s/Hz。**先对数后相加**与**先相加后对数**的差，就是并行子信道的全部意义。

**练习 2**：同一副 2×2 天线，深谷频发与信道顺畅两种场景，分别该选分集还是复用？为什么 MIMO 系统能两头兼顾？

<details>
<summary>点开查看逐步解答</summary>

深谷频发（信道恶劣）：两支天线发同一份数据，全深谷概率从 $p$ 压到 $p^2$（第 90 课），先保命；信道顺畅：各发各的，容量近似翻倍。MIMO 收发机的账本本来就同时记着 $H$ 的估计——信道矩阵条件好就切复用，条件差就切分集，标准正交空时码更是"无 SVD 也能分集"的开环兜底。同一副硬件，两种活法，切换的依据就是信道账本本身。
</details>

**练习 3**：某 4×4 链路被困在两面强反射墙之间，实测信道矩阵的秩只有 2。SNR = 10 时容量上限是多少？再加天线还有救吗？

<details>
<summary>点开查看逐步解答</summary>

秩 2 意味着只有 2 条非零奇异值——空间自由度被环境钳在 2，容量上限 $2\log_2 11 \approx 6.92$ bit/s/Hz，与 2×2 正交信道持平。继续加天线不涨秩就白搭：线性红利数的是 $\min(N_t, N_r, \text{rank}(H))$，环境不给出独立路径，天线只是昂贵的装饰品。这正是大规模 MIMO 要配富散射环境的原因。
</details>

## 7. 边界与适用条件

- 本课容量公式取"每条子信道同功率 SNR"的对拍口径；严格的总功率约束下应写成 $\sum_i \log_2(1+\sigma_i^2 \cdot \text{SNR}/N_t)$，最优分配是注水——弱子信道在低 SNR 时干脆不供电（第 62 章香农课的功率预算思想）。
- SVD 预编码要求收发两端都知道 $H$：导频估计加反馈链路，TDD 系统可靠互易性省掉反馈；信道老化越快（第 80 课相干时间），账本过期越快。
- 天线间距不足或散射不富时 $H$ 的秩缩水，$\min(N_t,N_r)$ 是上限不是承诺；毫米波视距场景自由度天然少，靠大规模阵列的波束赋形增益（第 20 课的方向图再分配）补账。
- 串扰值 0.8、0.6 这类"友好信道"是教学设定；真实信道的 $H$ 逐符号变化，SVD 要跟着导频一路重算。

## 8. 选读：为什么恰好是 SVD

<details>
<summary>选读 · 两次旋转拧直麻花</summary>

设 $H = U\Sigma V^{\mathsf T}$。发端把数据流 $s$ 先乘 $V^{\mathsf T}$ 再发射（预编码），收端把收到的东西先乘 $U^{\mathsf T}$ 再判决（合并）：

$$U^{\mathsf T} y = U^{\mathsf T} H V^{\mathsf T} s + U^{\mathsf T} n = \Sigma s + U^{\mathsf T} n$$

中间那个 $U^{\mathsf T}HV$ 恰好等于对角阵 $\Sigma$——第 21 章"正交矩阵不改变长度"的条款在这里兑现：两次旋转把串扰项整个抵消，每条接收流只剩 $\sigma_i s_i$ 加一份仍是白噪声的 $U^{\mathsf T}n$。串扰没有消失，而是被发端与收端的两次旋转**分头预付**了；奇异值 $\sigma_i$ 大的车道连噪声都相对更弱，这正是 $\sigma_i^2$ 出现在容量公式里的原因。工程上这叫 SVD 波束赋形：每一对左右奇异向量，就是一对接一发的定制波束。
</details>
