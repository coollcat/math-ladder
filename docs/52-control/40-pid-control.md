# PID 控制：三股力量的分工

## 1. 从一个场景开始

第 10 课的定速巡航留下了悬案：比例反馈只能把上坡掉速压小，压不到零。老练的司机会怎么做？——发现"一直在偏慢"之后，**把油门一点点多踩下去，直到误差消失**。这个"记仇 + 找补"的动作，就是积分项。

工业界 90% 以上的控制回路至今仍是 PID：温度、压力、流量、舵机角度。三个参数各管一段时间的误差，配伍得当则又快又稳。这一课拆开这个百年老方子。

## 2. 直觉解释

把控制器想象成一位司机，他看三样东西决定油门：

- **P（比例）· 现在的误差**：偏得越多，打的方向越大。反应快，但只要有持续扰动，就会留一点"残余误差"换平衡；
- **I（积分）· 过去的总账**：误差一直不清零，累计值就一直涨，油门就被一直推——直到误差归零、总账冻结。**专治稳态误差**；
- **D（微分）· 误差的趋势**：看到误差正在快速缩小，提前松油门防冲过头。相当于给系统装了预判刹车。

一句话分工：**P 管当下，I 记历史，D 预未来。**

## 3. 正式定义

连续时间 PID 控制律：

$$u(t) = K_p\,e(t) + K_i \int_0^t e(\tau)\,\mathrm{d}\tau + K_d\,\frac{\mathrm{d}e}{\mathrm{d}t}$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $e = r - y$ | 误差 | 目标减测量 |
| $K_p$ | 比例增益 | 对当前误差的反应强度 |
| $K_i$ | 积分增益 | 对累积误差的反应强度 |
| $K_d$ | 微分增益 | 对误差变化率的反应强度 |

计算机里实现的是离散版（采样周期 $\Delta t$）：

$$u_k = K_p\,e_k + K_i \sum_{j=0}^{k} e_j\,\Delta t + K_d\,\frac{e_k - e_{k-1}}{\Delta t}$$

积分变成累加器，微分变成相邻两拍差分——两个都是循环里一行代码的事。

## 4. 分步例题

对象仍用第 10 课的车速模型 $v' = u + d - v$，取 $r=10$、$d=-2$（上坡），先只开 P，$K_p=3$：

1. 稳态误差公式（第 10 课）：$e_\star = (r-d)/(K_p+1) = 12/4 = 3$；车速停在 7；
2. 打开 I（$K_i=0.5$）：只要误差还是正数，累加器 `integ` 就每步涨一点，油门 $u = 3e + 0.5\,\text{integ}$ 被越顶越高；
3. 车速爬过 7、逼近 10；稳态时 $e_\star = 0$，比例项交出 0——**全部油门由积分项独扛**：$u_\star = v_\star - d = 10-(-2) = 12$，故 $\text{integ}_\star = u_\star/K_i = 12/0.5 = 24$（实验 2 把步数加大到 2000，`integ` 正是停在它附近）；
4. 终局：$e_\star = 0$，车速精确停回 10——积分用"过去的证据"换来了"现在的清零"。

### 实验 2：PID 三滑杆调参实验室

下面的仿真带滑块：`kp`/`ki`/`kd` 由系统注入，改完直接重跑。目标 10，坡度 −2：

```python title="PID 定速巡航实验室"
# sliders: kp=3 [0:10:0.5], ki=0 [0:2:0.1], kd=0 [0:1:0.1]
import matplotlib.pyplot as plt

r = 10        # 目标速度
d = -2        # 坡度扰动
dt = 0.05     # 采样周期（秒）
v = 0.0       # 当前车速
prev_e = r    # 上一拍的误差（用于 D 项）
integ = 0.0   # 积分累加器
trace = []

for step in range(400):
    e = r - v
    integ = integ + e * dt                 # I：误差随时间累加
    deriv = (e - prev_e) / dt              # D：误差的变化快慢
    u = kp * e + ki * integ + kd * deriv   # 三股力量合流成油门指令
    v = v + dt * (u + d - v)
    prev_e = e
    trace.append(v)

overshoot = max(trace) - r                   # max：全程最大值，冲过目标的幅度
final_err = round(r - trace[-1], 3)
print(f"终态误差: {final_err}")
print(f"超调量: {round(overshoot, 3)}")

plt.plot(trace, label="speed")
plt.axhline(r, color="gray", linestyle="--")
plt.xlabel("step")
plt.ylabel("v")
plt.legend()
```

三组必做实验：(a) 只开 P（ki=kd=0），记录终态误差；(b) 加大 ki 到 0.5，看误差清零但曲线可能冲头（超调）；(c) 补一点 kd 压超调。体会"P 快、I 准、D 稳"的三角关系。

### 实验 3：判题小练兵

```exercise
# @title: 练习：给比例反馈配上积分
# @check: 3.0
# @check: 0.0
# @hint: 第二段仿真的油门要加上积分项 ki * integ；第一问保持纯 P 不动。
r = 10
d = -2
kp = 3
ki = 0.5
dt = 0.05

# 第一问：纯 P，跑 200 步看稳态误差
v = 0.0
for step in range(200):
    e = r - v
    u = kp * e
    v = v + dt * (u + d - v)
print(round(r - v, 1))

# 第二问：PI 控制，跑 800 步
v = 0.0
integ = 0.0
for step in range(800):
    e = r - v
    integ = integ + e * dt
    u = kp * e                    # ← 问题在这：积分账本算了却没用上
    v = v + dt * (u + d - v)
print(round(r - v, 1))
```

第一行 3.0 是 P 的宿命；第二行改成 PI 后应精确归零。积分清误差靠的是慢模式（本例时间常数约 8 秒），步数给足才看得到归零——这也是"调参要有耐心"的第一课。

## 常见误区

:::warning[常见误区]

**误区一**："Ki 越大消误差越快，所以调到最大。"
积分是把双刃剑：累计的油门指令有惯性，误差已经反向了它还在使劲——这叫**积分饱和（windup）**，表现为大幅超调和长时间摆动。工程对策是给累加器设上限（抗饱和钳位）。

**误区二**："D 项多多益善。"
微分放大高频噪声：测量里的一根毛刺经过差分会变成尖峰。实用中必须先滤波再求导，或者干脆用 PI 加输出限幅代替。

**误区三**："三个参数可以一个个孤立调到最优。"
三者通过闭环特征方程耦合在一起：改 Ki 会改变整个系统的等效阻尼。工程上有 Ziegler–Nichols 这类整定口诀，但最终都要回到第 30 课的特征值判决来验收。

:::

## 6. 练习

**练习 1**：手算：对象同实验 2（$r=10, d=-2$），若想用纯 P 把稳态误差压到 0.5，$K_p$ 要多大？

<details>
<summary>点开查看逐步解答</summary>

$e_\star = (r-d)/(K_p+1) = 12/(K_p+1) = 0.5$ → $K_p + 1 = 24$ → $K_p = 23$。

23 的增益在真实执行器上多半早已饱和——数值上可行、物理上破产。对比之下 Ki=0.5 就能清零，这就是积分存在的理由。
</details>

**练习 2**：在实验 2 中把 `d` 改成下坡 `+2` 再跑默认参数。终态误差和超调怎么变？为什么？

<details>
<summary>点开查看逐步解答</summary>

默认滑杆开的是纯 P（ki=0）：套第 10 课公式，$e_\star = (r-d)/(K_p+1) = (10-2)/4 = 2$，车速停在 **8**——仍是**正误差**、低于目标，而不是冲过目标：在这个模型里 $d$ 只是平移平衡点，下坡不过把纯 P 固有的残余误差从上坡时的 3 缓到 2，永远清不了零；一阶对象从冷启动单调爬升，超调保持 0。把 ki 开回 0.5 后误差照样精确归零（$v_\star = 10$）；由于从 v=0 起步误差全程为正，积分器只进不出，稳态收在 $\text{integ}_\star = u_\star/K_i = (v_\star - d)/0.5 = 16$——比上坡的 24 轻：下坡替你分担了油门，I 记的总账反而更小。
</details>

**练习 3**：概念辨析：恒温器的 bang-bang 控制（练习见第 10 课）缺了 PID 里的哪些成分？

<details>
<summary>点开查看逐步解答</summary>

它其实自带粗暴的 P 和隐性的 I（开着就持续加热=时间积分），但没有比例细调与微分预判，因此永远在阈值间振荡。模糊的结论别急着下：bang-bang 在最小时间控制里反而是最优解之一——控制方案没有绝对高下，只有是否匹配对象。
</details>

## 7. 选读：积分为什么会饱和

<details>
<summary>选读 · windup 的机制与钳位</summary>

执行器有物理上限（油门踩死）。当误差长时间为正，积分器照常累加，内部指令早已超过执行器能给的上限——这段"虚胖"的积分离误差归零还很远就开始消化，等误差终于反向，多余的积累还要慢慢吐出来，造成大超调。经典对策 anti-windup：当指令触顶时暂停积分累加（或按超出量回吐）。在实验 2 里给 `u` 加一行 `u = min(u, 6)` 再把 ki 调大，你会亲眼看到饱和如何制造摆振，以及钳位如何救场。

</details>
