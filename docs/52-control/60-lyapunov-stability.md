# Lyapunov 稳定性直觉

## 1. 从一个场景开始

验收一座山谷稳不稳，你会把每颗可能的石头都推下去试一遍吗？当然不会——聪明的办法是**看地形**：只要这座山只有一个洼地、而且山坡处处朝低处倾，那么随便哪颗石头都注定滚进谷底。

动力系统的稳定性判定恰恰面临同样的处境。第 30 课的特征值判决书确实神速，但它有个前提：**先要把系统写成线性的**。倒立摆、带库仑摩擦的滑块、种群与天敌……现实系统的方程里挤满了幂次和乘积项，根本没有特征值可请。这一课请出的裁判叫 **Lyapunov**（李雅普诺夫）：不解轨迹、不算特征值，看一眼"地形图"就盖章。

## 2. 直觉解释

把状态空间想象成一片山地，高度由一个函数 $V(x)$ 给出——它是我们**发明出来的能量计分板**：

- 板上原点必须是全场的最低点：$V(0)=0$，别处一律 $V(x)>0$；
- 最关键的脑洞：**这块板不必是真实的物理能量**！摩擦耗散的是机械能，但计分板可以算入任何你喜欢的加权组合——只要上面两条地形性质成立，它就是合格的"山"；
- 判稳只需要再核一件事：沿着系统真实的运动方向走一步，海拔**只降不升**（$\dot{V}\le 0$）。

三条齐备，石头无处可逃：要么一路下滑回到谷底（渐近稳定），要么至少被困在等高线上不再逃逸（稳定）。Lyapunov 方法的全部艺术都在"出题"——找到一座恰好配得上这个系统的山。

## 3. 正式定义

设系统 $\dot{x} = f(x)$ 以原点为平衡点（$f(0)=0$）。取可微函数 $V(x)$ 满足：

$$V(0)=0,\qquad V(x)>0 \ \text{当 } x\neq 0$$

即 $V$ **正定**（第 21 章"正定"的地形版）。再计算 $V$ 沿轨线的导数——梯度与速度场的内积：

$$\dot{V}(x) = \nabla V(x)\cdot f(x)$$

判决表：

| $\dot{V}(x)$ 的符号 | 结论 |
| --- | --- |
| 负定（除原点外恒为负） | 渐近稳定：状态必然回到原点 |
| 半负定（$\le 0$ 但有一片平地） | 稳定：出不去了，但不保证回家 |
| 存在某处 $>0$ | 这张计分板**作废**，换一张再试 |

$2\times 2$ 的手算流程固定四步：选板 $V$ → 求梯度 $\nabla V=(\partial V/\partial x,\ \partial V/\partial y)$ → 写出场分量 $(f_1, f_2)$ → 合并 $\dot{V}=f_1\dfrac{\partial V}{\partial x}+f_2\dfrac{\partial V}{\partial y}$ 化简。

**与第 30 课判决书的对话**：在线性系统上，二次型的 $V=\tfrac{1}{2}x^\top P x$ 与特征值给出完全一致的裁决——两条路是同一真理的两种语言。分歧出现在非线性地带：若雅可比矩阵的特征值实部全负，快车道依然有效；可一旦落在纯虚数或零根的"边缘"上，第 30 课沉默了，Lyapunov 却还开门营业——下面例题与实验会正面撞见这个场面。

## 4. 分步例题

判断系统 $\dot{x} = -x - x^3$，$\dot{y} = -2y$ 在原点的稳定性：

1. 出题：选圆碗 $V(x,y)=\dfrac{x^2+y^2}{2}$，显然正定；
2. 求梯度：$\nabla V = (x,\ y)$；
3. 抄场分量：$(f_1, f_2) = (-x-x^3,\ -2y)$；
4. 内积合并：$\dot{V} = x(-x-x^3) + y(-2y) = -x^4 - x^2 - 2y^2$。

读结果：三项全非正，且**同时为零只有原点一处**——负定，渐近稳定证书签发。顺嘴一提：$-x^2-2y^2$ 是线性化的老台词（特征值 $-1,-2$），多出来的 $-x^4$ 是非线性世界的赠品；这里它只是加固判决，而在别的系统里，这类"高次小项"会成为唯一的救命稻草。

### 实验 2：不解方程，直接验收

主角换成线性化失效的系统：$\dot{x}=y$，$\dot{y}=-x-y^3$。它的雅可比特征值是 $\pm i$——第 30 课只会说"中心，无法判断"。我们用能量山的语言重审一次：仍是圆碗 $V=\tfrac{1}{2}(x^2+y^2)$，而 $\dot{V}=xy+y(-x-y^3)=-y^4\le 0$，从不升海拔！

```python title="欧拉法走 20 秒，看计分板掉不掉分"
import matplotlib.pyplot as plt    # 画图库，老朋友了

def v_of(x, y):
    # 计分板：圆形碗，平方加权的一半
    return (x*x + y*y) / 2

def climb(damp):
    # damp=False 时关掉三次方阻尼（退化成纯转圈的中心）
    x, y = 2.0, 0.0                # 初始状态：从 x=2 处松手
    dt = 0.001                     # 步长：每步推进的时间
    trace = []                     # 记录每一步的海拔
    for step in range(20000):
        vx = y                     # 第一个分量恒等于速度
        vy = -x - y**3 if damp else -x   # **：三次幂；阻尼开关
        x = x + dt * vx            # 欧拉一步：旧位置加变化率乘步长
        y = y + dt * vy
        trace.append(v_of(x, y))
    return trace

for label, damp in [("有阻尼", True), ("无阻尼", False)]:
    tr = climb(damp)
    print(label)
    print(f"  起始 V = {tr[0]:.3f}")     # .3f：保留三位小数
    print(f"  第5秒  V = {tr[4999]:.3f}")
    print(f"  结束  V = {tr[-1]:.3f}")

plt.plot(climb(True))
plt.xlabel("step")
plt.ylabel("V")
```

真机数字说话：有阻尼时海拔从 2.000 一路泄到 0.034，单调下行、永不回头——这正是 $\dot{V}=-y^4\le 0$ 加上一点点额外论证（见选读）兑现的现实；关掉阻尼后 $V$ 稳定在 2 附近微微打转（尾部的 2.040 是欧拉法的数值毛边），**困在原地但拒绝回家**。两种命运，一个 $\dot{V}$ 全说清了。

### 实验 3：判题小练兵

另一款圆碗例题（同 §4）：$\dot{x}=-x-x^3$，$\dot{y}=-2y$，验证它在三个采样点的掉分速率。

```exercise
# @title: 练习：验收能量计分板的掉分速率
# @check: -22
# @check: -90
# @check: -10
# @hint: 沿轨线的导数必须用场分量的原文。第一个分量除了线性阻尼还藏着一记三次方的重刹，漏抄它，降幅会被严重低估。
def v_slope(x, y):
    # V 沿轨线的下降速度 = 各偏导乘对应场分量再相加：x*f1 + y*f2
    f1 = -x              # ← 问题在这：漏掉了 -x**3 这一记三次方刹车
    f2 = -2*y            # 第二个分量完整：常值阻尼 -2y
    return x*f1 + y*f2

print(v_slope(2, 1))   # 点 (2, 1)
print(v_slope(3, 0))   # 点 (3, 0)：x 轴上是三次方项的主场
print(v_slope(1, 2))   # 点 (1, 2)
```

修好后再往深处想一层：三个答案全是负数——但负得越狠说明离谷底越远时下滑越猛；靠近原点时 $-x^4$ 逐渐让位给 $-x^2$，回落反而变斯文。

## 常见误区

:::warning[常见误区]

**误区一**："$V$ 必须是系统的真实物理能量。"
不必。物理能量只是最常登场的候选者；任何正定又光滑的函数都有资格当计分板。工程师的手艺主要体现在调权构造合适的二次型。

**误区二**："算出 $\dot{V}\le 0$ 就万事大吉。"
半负定只担保"出不了一片区域"，不担保回到原点——本课的无阻尼对照就是活标本（$-y^4$ 在整条横轴上都是零）。要升级成渐近稳定，得补一刀不变性论证（选读框）或者换一张更陡峭的板。

**误区三**："一时找不到合格的 $V$，说明系统不稳定。"
Lyapunov 方法是**单向**的：出示了证书则稳定无疑；没找着证书什么都不证明。许多稳定系统的好山丘极难构造，这是方法的老毛病，也是它被称作"艺术"的原因。

:::

## 6. 练习

**练习 1**：有人想给系统 $\dot{x}=-x+y^2$，$\dot{y}=-y$ 也套用圆碗 $V=\tfrac{1}{2}(x^2+y^2)$，请沿流程算出 $\dot{V}$ 并判断这张板是否合格。

<details>
<summary>点开查看逐步解答</summary>

$\nabla V=(x,y)$，代入得 $\dot{V}=x(-x+y^2)-y^2=-x^2+xy^2-y^2$。

表面上全是减号，可惜中间夹着一项 $+xy^2$。令 $u=y^2$，把式子看成 $-x^2+ux-u$ 关于 $x$ 的开口向下的抛物线，顶点在 $x=u/2$ 处取值 $u(u-4)/4$ —— 只要 $u>4$（例如 $x=8,\ y=4$ 时 $\dot{V}=48$），它就翻成正值。

结论：这张板作废。（系统本身其实稳定，配十字交叉项的加权板能救回来，但那已超出圆碗的手艺——恰好印证误区三。）
</details>

**练习 2**：把实验 2 的初始状态改成 `(4.0, 0.0)` 再跑一遍。预测两条曲线的形状会有什么变化？

<details>
<summary>点开查看逐步解答</summary>

起始海拔从 2 变成 8（平方翻四倍）；有阻尼版依旧单调下行、终点更低；无阻尼版仍在同一水平带上打转。要点在于：**判决不看出发点多高**——计分板定了"只降不升"的规矩后，从哪里松手都是同一个结局结构。证书的全部分量写在系统方程与 $V$ 里，与初值无关。
</details>

## 7. 选读：半定那道坎怎么迈过去

<details>
<summary>选读 · 不变性论证一页纸</summary>

实验主角的 $\dot{V}=-y^4$ 只在直线 $y=0$ 上为零，属于半负定。Lyapunov 直接判决只给到"稳定"，但可以补一个观察：一条轨迹若想永远贴着 $\dot{V}=0$ 的集合走，就得让 $y\equiv 0$，而这要求 $\dot{y}=0$，即 $-x-0=0$，进一步锁死 $x=0$——所以能赖在那条直线上的唯有原点自己。其他轨迹迟早要离开平地继续掉海拔。这套"集合不变则只剩原点"的论证就是 **LaSalle 不变性原理**的精神，结论直通渐近稳定。此外，若 $V$ 四周趋向无穷（径向无界），整套论证覆盖任意远的位置，结论从局部升级为全局。对比线性化的车灯（第 30 课特征值 $\pm i$ 处熄火），正是这盏山丘探照灯照出了答案。

</details>
