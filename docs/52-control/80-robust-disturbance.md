# 鲁棒性与扰动抑制

## 1. 从一个场景开始

定速巡航在第 10、40 两课里表现得越来越懂事：比例反馈压住坡度、积分还清欠账。可工程师心里清楚一件事——**那一套讨论，全都默认模型是对的**。现实中：载重改变了车辆的时间常数；侧风一阵一阵地加戏；传感器读数自带毛刺；执行器用久了力气变小。

**鲁棒性（robustness）**问的就是：模型不再精确时，这套控制器是变笨一点，还是当场翻车？本章同时补上它的孪生问题——**扰动从门口灌进来时，反馈如何把它摁出去**。

## 2. 直觉解释

三个比喻撑起全课：

- **灵敏度 S ＝ 回路折扣券**。凡是把环节圈进反馈回路的，误差都被打上 $1/(1+L)$ 的折——回路增益 $L$ 越大，折扣越狠。放大器系数漂了 10%，输出只漂 1%。但券有两处失效：回路外的部件（比如传感器自己）无券可用；频率太高时回路反应不过来，折扣自动归零。
- **裕度 ＝ 悬崖边退了几步**。相位每转一圈就晚一步，控制器于是变得像出租车里抢答的乘客。增益裕度问：油门还能整体加大几倍才翻车？相位裕度问：刹车动作还能再迟到几度才追尾？二者合起来是稳定性的安全垫，工程惯例至少各留 **2 倍增益、45° 相位**。
- **积分偿债 ＝ 第 40 课的"历史欠账"**。常值风扰表现为误差赖着不走，积分器一路记账、油门一路加码，直到欠款清零。扰动如果只是缓变的"老赖"，积分恰好是对付它的职业选手。

至于水床效应，先把悬念立在这：低频段被压下去的误差不会消失，它会鼓到别处去。

## 3. 正式定义

标准单回路：对象 $P(s)$ 与控制器 $C(s)$ 相乘称开环增益 $L(s) = P(s)C(s)$。定义**灵敏度函数**：

$$S(s) = \frac{1}{1 + P(s)C(s)}$$

与互补灵敏度 $T(s) = \dfrac{P(s)C(s)}{1+P(s)C(s)}$（两者相加恒为 $1$）。读法表：

| 视角 | 读法 |
| --- | --- |
| $\lvert S(i\omega)\rvert$ 小 | 该频段的参数漂移、内部噪声被打折 |
| $\lvert T(i\omega)\rvert$ 小 | 该频段对测量噪声、模型失配不敏感 |
| $S + T = 1$ | 折扣总额守恒：一头压扁，另一头必然顶起 |

两个裕度的口语版定义（都在开环幅频曲线上取点）：**增益裕度** $GM$＝在相位恰好跌穿 −180° 的频率上看，$\lvert L\rvert$ 距离临界值 1 还差多少倍；**相位裕度** $PM$＝在 $\lvert L\rvert$ 恰好降到 1 的频率上看，相位距离 −180° 还剩多少度。

一阶组合 $C=k$（纯比例）、$P = 1/(s+1)$ 时可以全程手算：

$$\lvert S(i\omega)\rvert = \frac{\sqrt{1+\omega^2}}{\sqrt{(k+1)^2+\omega^2}}$$

## 4. 分步例题

阵风载荷实验台（沿用第 10 课车速模型 $v' = u + d - v$，目标 $r=10$）：

1. **只有 P**（$K_p=3$），平路顺行后风扰跳变 $d=-2$：稳态误差 $\frac{10-(-2)}{3+1}=3$，车速赖在 7 不动——第 10 课算过的天花板；
2. **接通积分**（$K_i=0.5$）：账本持续进账，最终 $e_\star=0$、积分存额停在 $u_\star/K_i = 12/0.5 = 24$——第 40 课真机跑出的数字；
3. **风变大却不重调参**（$d=-3$）：同一组旋钮照样清零误差，这次积分自动记满 $u_\star/K_i = 13/0.5 = 26$。控制器没有学习算法，它只是诚实——欠多少记多少；
4. **顺手量一张折扣券**（$k=9$）：直流处 $\lvert S\rvert = 1/(1+9)=0.1$，即回路内的扰动十不存一；一小时弧频 $\omega=1$ 处按上式得 $\lvert S\rvert\approx 0.14$。折扣随频率递减的趋势已经现身。

### 实验 2：阵风实录对比

```python title="阵风来袭：P 和 PI 的两份答卷"
import matplotlib.pyplot as plt    # 画图库

dt = 0.05                          # 决策间隔（秒）
N = 1200                           # 总拍数：60 秒

def run(use_i):
    v = 0.0                        # 当前车速
    integ = 0.0                    # 积分累加器：历史欠账本
    trace = []                     # 全程车速记录
    for step in range(N):
        d = -3.0 if step >= 120 else 0.0   # 三元式：第 120 拍起刮定常逆风
        e = 10 - v                 # 误差
        integ = integ + e * dt     # I：账本继续进账
        u = 3.0 * e + (0.5 * integ if use_i else 0.0)
        v = v + dt * (u + d - v)
        trace.append(v)
    return trace

for name, flag in [("纯P", False), ("PI", True)]:
    tr = run(flag)
    low = min(tr[120:])            # min：阵风时段的最低车速（max 的孪生兄弟）
    print(f"{name}: 阵风时段最低={low:.2f}, 终速={tr[-1]:.2f}")

plt.plot(run(False), label="P")
plt.plot(run(True), label="PI")
plt.axhline(10, color="gray", linestyle="--")
plt.legend()
```

两份答卷性格迥异：纯 P 一路溜到 **6.75** 并赖着不走——那就是 $\frac{10-(-3)}{4}$ 的宿命值；PI 短暂探底 **8.33** 后掉头回家，终速回到 **10.0**（尾巴还差 0.002，那是慢账本的最后一口利息，再等一会儿自然到账）。积分偿的不是力气，是耐心。

### 实验 3：判题小练兵

亲手复现 §4 的折扣计算，体会一个常见错误在哪一步走岔：

```exercise
# @title: 练习：量一量折扣券的成色
# @check: 0.14
# @check: 0.3
# @hint: S 是两个复数的商，模要"先分别勾股、再相除"；分母是 (k+1) 与 ω 这一对直角边整体求模，不是先算出 |L| 再加一。
import math                     # sqrt 开平方

def sens_mag(w):
    # 对象 P = 1/(s+1)、C=k 时，S 的分子分母各自是复数，用勾股定理取模
    num = math.sqrt(1 + w * w)         # 分子：|1 + jw|
    den = k0 + math.sqrt(1 + w * w)    # ← 问题在这：错把 1+|L| 当成了分母的模
    return num / den

k0 = 9                          # 回路增益 k（写在外层让函数直接取用）

print(round(sens_mag(1.0), 2))   # 一弧度处的折扣成色
print(round(sens_mag(3.0), 2))   # 三弧度处：折扣开始失效
```

修正后的分母是 $\sqrt{(k+1)^2+w^2}$ 整体——0.14 与 0.3 正是 §4 手算的两个数。这个坑的本质：**复数相减后再取模 ≠ 先取模再相减**，1 与 $\lvert L\rvert$ 之间还有夹角这本账。

## 常见误区

:::warning[常见误区]

**误区一**："增益裕度达标就稳了。"
两项裕度要一起看：增益余量大而相位所剩无几时，执行器的延迟叠加上去照样震荡。真实验收单上它们是一对必须同时签字的项目。

**误区二**："积分是万能吸尘器。"
积分只擅长对付**慢变量**的扰动：高频阵风它来不及还嘴就被惯性拖累，遇上大缺口还会患上第 40 课讲过的积分饱和。抗饱和钳位与限幅是积分上岗的必备装备。

**误区三**："鲁棒就是所有参数都往坏里留足余量。"
余量堆得太厚，标称性能被啃得所剩无几——又快又软的车和永远不会翻但也永远跑不快的车一样没人要。鲁棒设计的精髓是在最坏情形承诺与日常性能之间谈判，而不是无限投保。

:::

**练习 1**：接手 §4 第 3 步的场景自己推一遍：$K_p=3$、目标 10、风 $d=-3$，求纯 P 的稳态车速与误差；再说明为什么积分到来后这一页翻篇。

<details>
<summary>点开查看逐步解答</summary>

套第 10 课公式：$v_\star = r - \frac{r-d}{k+1} = 10 - \frac{13}{4} = 6.75$，误差 3.25 —— 与实验 2 实跑终速严丝合缝。
积分接管后稳态条件变成"油门必须独自扛住风的反向力"：$u_\star = v_\star - d = 13$，而这笔油门全部由积分存额支付，$\text{integ}_\star = 13/0.5 = 26$。账本记满之时误差清零——原理与风的幅度无关，这正是"不重调参也能换季"的原因。
</details>

**练习 2**：在实验 2 中做两组改档：(a) 把 `dt` 改小为 0.02、`N` 改成 3000（总时长不变）；(b) 把风速从 −3 改成 −9。记录两份答卷的关键数字怎么动。

<details>
<summary>点开查看逐步解答</summary>

(a) 步长变细只让曲线更光滑，两个控制器的关键数字几乎不动（离散化误差缩小）——这是检验仿真可信度的常规体检。(b) 风 ×3 后纯 P 的宿命谷直接跌到 $v_\star = \frac{3\times 10 - 9}{4} = 5.25$，失守更深；PI 会探得更低些但终点仍精确回家，且积分存额最终记到 $(10-(-9))/0.5 = 38$。两条对照再次确认：**P 的代价随风上限飘，I 的结局只认目标**。
</details>

## 7. 选读：两张验收单上的行业惯例

<details>
<summary>选读 · 裕度数字与水床定量</summary>

教科书级的安全垫通常取相位裕度不低于 45°、增益裕度不低于 2 倍（6 分贝）；伺服系统常压到 30° 与 1.5 倍的下沿换取速度，航天与化工则反过来加码。更深的定量化是 **Bode 积分定理**：对一类常见对象，$\ln\lvert S\rvert$ 在整条频率轴上的加权面积近似守恒——水床因此不是修辞而是定理。从这个视角看，第 70 课的最优设计必须在某处放弃一部分折扣，而数学只是替你挑了性价比最高的放弃位置。奈奎斯特图如何把这些直觉画成一圈判据，第 60 章工程控制论留了专座。

</details>
