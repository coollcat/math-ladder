# 开环与闭环：反馈让误差变成燃料

## 1. 从一个场景开始

定速巡航把目标设成 90 km/h。平路上它表现完美，可车一上长坡，速度悄悄掉到 82——控制器明明"什么都没做错"。与此同时，浴室里的你拧一下水龙头，水温偏了就马上回调，几分钟内总能到位。

差别在哪？前者是**按剧本盲干**（开环），后者是**边测边改**（闭环）。这一课把这两种结构写清楚：它们是整个控制理论的入口，也是火箭姿态、血糖调节、推荐系统共用的骨架。

## 2. 直觉解释

- **开环控制**：烤面包机的定时器。不管面包今天干湿，到点就弹起。它的指令在按下按钮那一刻就全部定死，**不看结果**。
- **闭环控制**：淋浴时的你的手。感受水温（测量）→ 和心里期望比较（比较）→ 拧阀门（修正）。这个"测—比—改"循环转得越快，水温跟得越紧。

闭环的核心动作只有三步：

> **测量**输出 y → 算**误差** e = 目标 − y → 按 e 决定下一步动作。

误差不再是坏消息，而是修正动作的**燃料**：没有误差，闭环控制器反而无事可做。

## 3. 正式定义

考察一阶被控对象（比如车速，时间常数已归一）：

$$\frac{\mathrm{d}v}{\mathrm{d}t} = u + d - v$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $v$ | 被控量 | 车速（我们关心的输出） |
| $u$ | 控制量 | 油门给出的等效驱动 |
| $d$ | 扰动 | 坡度等外力，上坡为负 |
| $r$ | 参考目标 | 想要的速度，例如 12 |

**开环控制律**：$u = u_0$ 与测量无关。按平路标定 $u_0 = r = 12$，则平路稳态 $v_\star = 12$ 完美；一旦上坡 $d = -3$，稳态变成

$$v_\star = u_0 + d = 12 - 3 = 9$$

**比例闭环控制律**：$u = k\,(r - v)$，其中 $k>0$ 叫**反馈增益**。令导数为零解稳态：

$$v_\star = \frac{k\,r + d}{k + 1}, \qquad e_\star = r - v_\star = \frac{r - d}{k + 1}$$

关键读法：扰动造成的稳态误差被压缩到 $\frac{1}{k+1}$——增益越大，坡度越"说了不算"。

## 4. 分步例题

取 $r = 12$、$d = -3$（上坡）：

1. 开环：$v_\star = 12 + (-3) = 9$，掉速 3，且永远回不来；
2. 闭环 $k = 4$：$v_\star = (4 \times 12 - 3) / 5 = 45/5 = 9$……等等，和开环一样？

第 2 步算出的确实是 9——拆开看：增益把车速抬到 $kr/(k+1) = 9.6$，扰动又拽下 $|d|/(k+1) = 0.6$，净结果恰好回到 9。这组参数下两股力量打平纯属巧合，别当成规律。继续：

3. 闭环 $k = 9$：$v_\star = (108 - 3)/10 = 10.5$，掉速缩到 1.5；
4. 闭环 $k = 99$：$v_\star = (1188 - 3)/100 = 11.85$，只剩 0.15；
5. 规律确认：误差 = $15/(k+1)$，随增益增大**反比例消失，但永不等于零**。

最后一点是比例反馈的天花板：它能压制扰动，却无法把稳态误差清零。谁来清零？第 40 课的积分项（PID）。

### 实验 2：数值仿真对比两条回路

```python title="开环 vs 闭环：上坡 3 个单位的稳态对比"
import matplotlib.pyplot as plt

r = 12        # 目标速度
d = -3        # 坡度扰动（上坡为负）
dt = 0.01     # 仿真步长：每次推进的时间间隔

def simulate(u_rule, steps):
    # 自定义函数：按传入的控制规则跑一段仿真
    v = 0.0
    trace = []
    for step in range(steps):
        u = u_rule(v)
        v = v + dt * (u + d - v)
        trace.append(v)
    return trace

open_loop = simulate(lambda v: 12.0, 3000)          # lambda：一行小函数，这里永远给固定油门
closed_loop = simulate(lambda v: 9.0 * (r - v), 3000)

print(f"开环终速: {open_loop[-1]:.2f}")             # [-1] 取列表最后一个元素
print(f"闭环终速: {closed_loop[-1]:.2f}")

plt.plot(open_loop, label="open loop")
plt.plot(closed_loop, label="closed loop k=9")
plt.axhline(r, color="gray", linestyle="--")         # 目标参考线
plt.legend()
```

开环停在 9.00；闭环停在 10.50，与手算一致。把 `9.0` 改成 `99.0` 再跑，你会看到 11.85——数值实验替公式背书。

## 常见误区

:::warning[常见误区]

**误区一**："增益越大越好。"
本课的一阶对象里确实如此，但真实系统有延迟和惯性：增益太大会震荡甚至发散（第 30 课特征值给出判据）。高增益还会放大传感器噪声、顶爆执行器上限。

**误区二**："开环一无是处。"
扰动可控、对象听话时，开环又便宜又简单——洗衣机的定时电机、红绿灯的固定配时都用得好好的。反馈是为"世界不配合"准备的。

**误区三**："闭环转起来误差就该是零。"
比例反馈只能把误差压到 $\frac{r-d}{k+1}$，压不到零。消除常值扰动的稳态误差需要积分作用（PID 课的主角）。

:::

## 6. 练习

**练习 1**：换一组参数手算：$r = 10$、$d = -2$、$k = 3$，求闭环稳态速度与稳态误差。

<details>
<summary>点开查看逐步解答</summary>

$v_\star = (3 \times 10 - 2)/4 = 28/4 = 7$；误差 $e_\star = (10-(-2))/(3+1) = 12/4 = 3$。

验算另一条路：$e_\star = r - v_\star = 10 - 7 = 3$ ✓。
</details>

**练习 2**：把两个增益下的稳态速度算出来并打印（第一行已示范格式）：

```exercise

r = 12

for k in [4, 19]:
    v_star = k * r + d    # ← 问题在这：还差一步，对照第 3 节公式补上

```

$k=4$ 时误差还有 3，$k=19$ 时只剩 0.75——增益花出去，误差缩回来，但账永远不清零。

**练习 3**：恒温器是"开关式"反馈（低于 20℃ 开加热、高于 21℃ 关）。它是开环还是闭环？和比例反馈比，温度曲线会长什么样？

<details>
<summary>点开查看逐步解答</summary>

它是闭环（测量了温度才决定开关），但控制量只有两挡。温度会在 20~21℃ 之间锯齿状波动，而不是平滑贴住目标。这种 bang-bang 控制便宜皮实，家电里随处可见；缺点是永远在抖动，且对高频扰动反应粗糙。
</details>

## 7. 选读：一阶系统为什么不怕高增益

<details>
<summary>选读 · 时间常数被反馈压缩</summary>

把 $u = k(r-v)$ 代入对象方程整理：

$$\frac{\mathrm{d}v}{\mathrm{d}t} = -(k+1)\left(v - \frac{kr+d}{k+1}\right)$$

这是一阶线性 ODE，解为 $v(t) = v_\star + (v_0 - v_\star)e^{-(k+1)t}$：收敛速度从 1 变成 $k+1$。一阶世界里增益既加快收敛又压缩误差，全是好处。但只要系统多了一个储能元件（二阶），同样的高增益就会让相位滞后累积、产生振荡——这正是第 30 课要用特征值精确回答的问题。

</details>
