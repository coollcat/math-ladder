# 可控性与可观性

## 1. 从一个场景开始

第 20 课的双水箱留过一个尾巴：把 A→B 那条溢流管道切断后，无论泵怎么开，B 箱水位纹丝不动——泵只接 A 箱，B 成了操纵杆够不着的孤岛。

于是状态方程 $x_{k+1} = Ax_k + Bu_k$ 逼出两个朴素的问题：

> **问题一（可控性）**：操纵杆 $u$ 能不能把内部状态推到任何想要的地方？
>
> **问题二（可观性）**：只凭出口处一根传感器，能不能反推出系统内部的全部状态？

这两个词是现代控制的准入证：LQR、观测器、卡尔曼滤波上岗之前，都要先出示这两份体检报告。

## 2. 直觉解释

把系统想象成一座仓库，配一名搬运工和一个盘点员：

- **可控性 = 搬运问题**。搬运工（输入矩阵 $B$）的手只伸得到几个货架，但货架之间有传送带（矩阵 $A$ 的交叉项）——第一秒够不着的地方，第二秒借着存货接力也许就到了。所以关键不看 $B$ 自己，而看 **$B$ 和 $AB$ 是不是朝着不同方向使劲**。
- **可观性 = 盘点问题**。盘点员只看得见门口一杆秤（输出 $y$），却想倒推每种库存还剩多少。他唯一的希望是：每一种存货的变化，都要能在秤的读数里留下痕迹。

几何版一句话：把 $B$ 和 $AB$ 当成两个向量——它们铺满整个平面，状态想去哪就去哪（可控）；它们挤在同一条直线上，状态就被锁死在这条线上来回蹭。

## 3. 正式定义

对 $n$ 维系统 $\dot{x} = Ax + Bu$（离散版本的结论相同），称

$$\mathcal{C} = \begin{bmatrix} B & AB & A^2 B & \cdots & A^{n-1}B \end{bmatrix}$$

为**可控性矩阵**；设输出 $y = Cx$，称

$$\mathcal{O} = \begin{bmatrix} C \\ CA \\ \vdots \\ CA^{n-1} \end{bmatrix}$$

为**可观性矩阵**。两个判决合并成一张表：

| 矩阵 | 秩判据 | 结论 |
| --- | --- | --- |
| $\mathcal{C}$ | 秩 $= n$ | 完全可控：有限步内能把状态推到任意处 |
| $\mathcal{O}$ | 秩 $= n$ | 完全可观：凭输出历史能唯一还原初值 |

为什么只需要前 $n$ 个幂？因为 $A^n$ 及更高的幂都能由 $I, A, \dots, A^{n-1}$ 线性表出（凯莱–哈密顿定理，第 21 章的遗产），再往后拼列不会带来新方向。$n=2$ 时事情最清爽：可控性矩阵就两列 $B$ 和 $AB$，秩是否为 2 只看行列式是不是零。

## 4. 分步例题

对象还是双水箱：$A=\begin{bmatrix}0.7 & 0\\ 0.3 & 0.8\end{bmatrix}$，$B=\begin{bmatrix}0.2\\ 0\end{bmatrix}$。

1. 先算接力向量：$AB=\begin{bmatrix}0.7\times 0.2\\ 0.3\times 0.2\end{bmatrix}=\begin{bmatrix}0.14\\ 0.06\end{bmatrix}$——注意第二个分量 0.06 正是那条溢流管道送来的馈赠；
2. 拼可控性矩阵求行列式：$\det\begin{bmatrix}0.2 & 0.14\\ 0 & 0.06\end{bmatrix}=0.2\times 0.06-0.14\times 0=0.012\neq 0$，秩为 2 → **完全可控**。泵明明只碰 A 箱，借一步接力后整个平面都够得着；
3. 反例（切断管道后 $A=\begin{bmatrix}0.7 & 0\\ 0 & 0.8\end{bmatrix}$）：此时 $AB=\begin{bmatrix}0.14\\ 0\end{bmatrix}$，$\det=0.2\times 0-0.14\times 0=0$ → 秩 1，**不可控**。够得着的全部状态被压在一条水平线上，纵轴方向永远是孤岛；
4. 可观性体检（接 $y=x_2$，传感器装在 B 箱）：两行读数为 $(0,1)$ 与 $(0,1)A=(0.3,\,0.8)$，$\det\begin{bmatrix}0 & 1\\ 0.3 & 0.8\end{bmatrix}=-0.3\neq 0$ → **可观**。盯着 B 箱水位的历史，就能倒推出 A 箱的水量；
5. 换个测点（$y=x_1$ 装在 A 箱）：两行变成 $(1,0)$ 与 $(0.7,\,0)$，$\det=1\times 0-0\times 0.7=0$ → **不可观**。

最后两步放在一起读很有冲击力：**同一个系统，传感器挪个位置，答案就翻转**。可控与否长在输入端，可观与否长在输出端，两头互不通气。

### 实验 2：四份体检报告一次算齐

```python title="用 numpy 给双水箱做完全套体检"
import numpy as np                            # 数值库，第 21 章已正式引入

A_ok  = np.array([[0.7, 0.0], [0.3, 0.8]])    # array：把嵌套列表升级成能做矩阵运算的数组
A_cut = np.array([[0.7, 0.0], [0.0, 0.8]])    # 断管后的演化规则卡
B     = np.array([0.2, 0.0])                  # 泵只接 A 箱

def ctrb(A, B):
    # 可控性矩阵：把 B 和 AB 并排成两列（column_stack 按"列"拼接）
    return np.column_stack([B, A @ B])        # @ 表示矩阵乘法

def obsv(A, c):
    # 可观性矩阵：把 c 和 cA 上下各摞一行（vstack 按"行"堆叠）
    return np.vstack([c, c @ A])

for name, A in [("正常", A_ok), ("断管", A_cut)]:
    rc = np.linalg.matrix_rank(ctrb(A, B))    # matrix_rank：返回矩阵的秩
    print(name, "可控性秩 =", rc)

for name, c in [("测B箱", [0.0, 1.0]), ("测A箱", [1.0, 0.0])]:
    ro = np.linalg.matrix_rank(obsv(A_ok, np.array(c)))
    print(name, "可观性秩 =", ro)
```

四行输出就是完整病历：正常系统输入端满秩（能推到任何地方）；传感器装在 B 箱时输出端满秩（看得透内部），搬到 A 箱立刻降秩。断管系统更惨烈——输入端先天残废，把它留给练习收尸。

### 实验 3：判题小练兵

```exercise
# @title: 练习：给三个车间做可控性体检
# @check: 水箱 2
# @check: 小车 2
# @check: 断管 1
# @hint: 可控性矩阵的第二列应是 A 作用过一次之后的 AB；第三组的 AB 恰好和 B 平行，想想为什么。
import numpy as np                  # 数值库（第 21 章已登记）

def matvec(M, v):
    # 矩阵乘向量：结果第 i 个分量 = M 的第 i 行与 v 对应相乘再求和
    return [M[i][0]*v[0] + M[i][1]*v[1] for i in range(2)]

def ctrb_rank(M, v):
    ab = M                          # ← 问题在这：第二列照抄了第一列，忘了让 A 来接力
    cols = [np.array(v), np.array(ab)]   # column_stack 等着这两列入队
    return np.linalg.matrix_rank(np.column_stack(cols))

print("水箱", ctrb_rank([[0.7, 0.0], [0.3, 0.8]], [0.2, 0.0]))
print("小车", ctrb_rank([[1.0, 1.0], [0.0, 1.0]], [0.0, 1.0]))
print("断管", ctrb_rank([[0.7, 0.0], [0.0, 0.8]], [0.2, 0.0]))
```

修好之后对照物理直觉验证一遍："小车"是二次积分器（位置、速度各占一行），油门先推动速度、速度再积攒位置——两个方向都被 $B$ 直接或间接覆盖，秩必须是 2；"断管"的 AB 恰好是 B 的缩放拷贝，多一列也填不出新方向。

## 常见误区

:::warning[常见误区]

**误区一**："B 里出现 0 就没救了。"
零只说明"不直接"。接力通道 AB 才是真正的裁判：正文的健康水箱里，泵对 B 箱的全部影响都写在 AB 的那个 0.06 里。

**误区二**："换一组状态坐标，可控性就会变。"
不会。非退化的坐标变换相当于同时给 $B$、$AB$ 换一套基底，张成空间的维数原封不动。可控、可观是**结构性质**，不挑坐标系——这也是敢用秩当判据的理由。

**误区三**："秩不满就一切归零。"
秩判据裁决的是"完全可控／完全可观"；介于中间还有"够镇定""部分可观"等灰色地带（比如只需稳定到原点而不必到达每个点时，弱一点的系统也够用）。本书点到为止，记牢本课的判决范围即可。

:::

## 6. 练习

**练习 1**：亲手完成可观性体检的两个行列式：接 $y=x_2$ 得到的 $\begin{bmatrix}0 & 1\\ 0.3 & 0.8\end{bmatrix}$，以及接 $y=x_1$ 得到的 $\begin{bmatrix}1 & 0\\ 0.7 & 0\end{bmatrix}$。

<details>
<summary>点开查看逐步解答</summary>

按第二行减去 0.8 倍第一行的路子消元，或者直接展开：
前者 $\det = 0\times 0.8 - 1\times 0.3 = -0.3$，非零 → 可观；
后者 $\det = 1\times 0 - 0\times 0.7 = 0$ → 不可观。

再补一句物理话术：A 箱的水位变动必须经过 0.3 那条管道才能反映到 B 箱的读数上；传感器装在 A 箱时，读数从来不带 B 箱的信息，自然无从还原。
</details>

**练习 2**：给断管系统 $A=\begin{bmatrix}0.7 & 0\\ 0 & 0.8\end{bmatrix}$ 分别接 $y=x_1$ 和 $y=x_2$，验算两个可观性行列式。你发现了什么规律？

<details>
<summary>点开查看逐字解答</summary>

接 $y=x_1$：$(1,0)$ 与 $(0.7,0)$ → $\det = 0$；接 $y=x_2$：$(0,1)$ 与 $(0,0.8)$ → $\det = 0\times 0.8 - 1\times 0 = 0$。**双双不可观**。

规律：切断交叉项后两个状态各自演化、互不来往，单一输出最多看见其中一路——这正是练习 1 中"牵动链"的反面教材。可控性与可观性共享同一条命脉：**内部量之间的相互牵挂**。
</details>

```quiz
一个系统"可控但不可观"，最贴切的日常翻译是？
- 扳手什么都能拧动，但从仪表上永远猜不到里面发生了什么 [*]
- 仪表什么都能看见，可惜扳手怎么拧都没反应
- 既拧不动，也看不见
? 可控性由输入端拍板（B 和 AB 的秩），可观性由输出端拍板（C 和 CA 的秩），两端互为对偶、各自独立成立。
```

## 7. 选读：可控与可观是一对镜像

<details>
<summary>选读 · 对偶原理一页纸</summary>

把可控性判据里的字母集体"转置"：$B \to C^\top$、$AB \to (CA)^\top$，会得到

$$\begin{bmatrix} B & AB \end{bmatrix}^\top = \begin{bmatrix} C \\ CA \end{bmatrix}$$

也就是说，**原系统的可观性矩阵，恰是对偶系统 $(A^\top, C^\top)$ 的可控性矩阵**；而转置不改变秩，所以两个判决可以互相翻译。工程上的回报很实惠：为可观系统设计"状态重构器"（观测器）与为可控系统设计反馈增益，用的是同一套代数——卡尔曼滤波器的推导里还会遇到这面镜子（第 60 章工程控制论再会）。

</details>
