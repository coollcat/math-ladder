## 实战挑战 · 定速巡航的 PID 记账表

真实车辆的巡航控制器每隔一小段时间做一次决策。情境原创（经典控制教材题型）：目标车速 90 km/h，一段缓上坡让速度偏差（误差）逐拍记录为 6 → 3 → 1 km/h。控制器参数：比例增益 $K_p = 5$、积分增益 $K_i = 0.5$、微分增益 $K_d = 2$，决策间隔 $\Delta t = 2$ 秒。离散 PID 公式：

$$u = K_p\,e + K_i \times (\text{误差和}) \times \Delta t + K_d \times \frac{e_{\text{本拍}} - e_{\text{上拍}}}{\Delta t}$$

约定：第一拍没有"上一拍"，微分项记 0。请算出三拍各自的油门指令 $u_1, u_2, u_3$。第一拍已示范：

```exercise
# @title: 实战挑战：给巡航控制器记三笔 PID 账
# @check: 36.0
# @check: 21.0
# @check: 13.0
# @hint: 积分项 = 累计误差 × Ki × Δt；微分项 = （本拍误差 − 上拍误差）÷ Δt × Kd，误差在缩小所以微分为负；Ki=0.5 是小数，结果会带一位 .0。
kp = 5     # 比例增益
ki = 0.5   # 积分增益
kd = 2     # 微分增益
dt = 2     # 决策间隔（秒）

# 第一拍：误差 6，累计误差 6，无历史 → 微分项 0（已示范）
e1 = 6
print(kp * e1 + ki * e1 * dt)

# 第二拍：误差 3，累计误差 6+3=9，上一拍误差 6
e2 = 3
sum_e2 = 9
prev_e2 = 6
print()    # ← 补上第二拍油门指令

# 第三拍：误差 1，累计误差 6+3+1=10，上一拍误差 3
e3 = 1
sum_e3 = 10
prev_e3 = 3
print()    # ← 补上第三拍油门指令
```

```quiz
误差一路缩小到接近零时，三股力量各自在做什么？
- P 和 I 都在加油门，D 在踩刹车 [*]
- 三项全在踩刹车，因为误差快没了
- 只有 I 在工作，P 和 D 已经下班
? 误差为正说明还偏慢：P 继续补油、I 因历史欠账继续加码，而 D 看到"误差在快速缩小"会给出负修正提前收油——三者方向不同正是分工。
```

<details>
<summary>点开查看逐步解答</summary>

**第一拍（示范）**：$u_1 = 5\times6 + 0.5\times6\times2 + 0 = 30 + 6 = 36$。

**第二拍**：
1. 比例项 $5\times3 = 15$；
2. 积分项 $0.5\times9\times2 = 9$；
3. 微分项 $2\times\dfrac{3-6}{2} = -3$；
4. 合计 $u_2 = 15 + 9 - 3 = 21$。

**第三拍**：
1. 比例项 $5\times1 = 5$；
2. 积分项 $0.5\times10\times2 = 10$；
3. 微分项 $2\times\dfrac{1-3}{2} = -2$；
4. 合计 $u_3 = 5 + 10 - 2 = 13$。

读表：比例项随误差衰减，积分项因历史欠账仍在加码，微分项一路负值提前刹车——第 40 课仿真里"清误差但不冲头"的手感，就是这三列数字的合奏。
</details>

## 工程大题 · 四旋翼高度通道的稳定性验收

一台四旋翼在悬停附近做了高度通道系统辨识。采样周期为 0.05 秒，状态取 $x=(\Delta h,\Delta v)$：高度误差（正数表示低于目标）和竖直速度。设计后的闭环差分模型为

$$x_{k+1}=\begin{bmatrix}0.84 & 0.04\\ -0.30 & 0.62\end{bmatrix}x_k$$

飞控验收要求：每个离散特征值的模都小于 1，否则不能进入外场试飞。请算出闭环矩阵的迹、行列式、两个特征值和稳定判决。

```exercise
# @title: 工程大题：四旋翼高度通道能否放行
# @check: 1.46
# @check: 0.53
# @check: 0.74
# @check: 0.72
# @check: True
# @hint: 迹是主对角线之和；行列式是 ad-bc，不是 ac-bd。复判时看两个特征值的模是否都小于 1。
a, b, c, d = 0.84, 0.04, -0.30, 0.62
import math  # sqrt：开平方，用来解特征方程

tr = a + c                     # ← 问题在这：迹拿错了第二个对角元
det = a * c - b * d            # ← 行列式公式也用错了位置
disc = math.sqrt(tr * tr - 4 * det)
lam1 = (tr + disc) / 2
lam2 = (tr - disc) / 2
stable = abs(lam1) < 1 and abs(lam2) < 1

print(round(tr, 2))
print(round(det, 2))
print(round(lam1, 2))
print(round(lam2, 2))
print(stable)
```

<details>
<summary>点开查看逐步解答</summary>

$\tau=0.84+0.62=1.46$；
$\Delta=0.84\times0.62-0.04\times(-0.30)=0.5208+0.0120=0.5328$。

特征方程 $\lambda^2-1.46\lambda+0.5328=0$ 的判别式是
$1.46^2-4\times0.5328=2.1316-2.1312=0.0004$，所以
$\lambda_{1,2}=(1.46\pm0.02)/2=0.74,\ 0.72$。

两个模都小于 1，高度误差和速度模态都会衰减，`stable=True` 可以放行。这个例子也说明“闭环”很关键：开环的高度通道常有一个接近积分器的慢模态，反馈才把它搬进单位圆内。
</details>
