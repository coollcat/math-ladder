# LQR 与最优控制

## 1. 从一个场景开始

四旋翼悬停时，飞控每秒要做出上百次修正：偏了就打杆——但**打多重**是门学问。猛一点又快又准，电池却嗷嗷叫；温柔一点省电，姿态却慢悠悠晃半天。反馈能镇住系统（前面几课都学会了），可"既有力气又不浪费"这事还没人管。

这一课把这份挑剔写成一张评分表，然后让数学替我们挑出全场最优的答题策略。这就是 **LQR**（线性二次型调节器）：航天器姿态控制、无人机悬停、工业过程调节背后的公共大脑。

## 2. 直觉解释

把整个飞行任务想成一场持续扣分的考试：

- **跑偏扣分**：状态 $x$ 偏离目标越远、时间拖得越长，扣得越多；
- **用力扣分**：油门 $u$ 每多踩一格都要记油钱，踩大了还得交"执行器磨损费"；
- 两项都用**平方**计价：轻微偏差只轻罚，大偏差狠罚（平方对小错宽容、对大错重击）。

评分表长得像一张价目牌：$Q$ 是偏差的单价，$R$ 是油钱的单价。**"多快好省"里哪个字更值钱，全写在这两个字母里**。而所谓的最优反馈增益 $K$，就是让总扣分最少的答题策略——LQR 把"调参"升级成了"标价"。

## 3. 正式定义

连续时间线性系统 $\dot{x} = Ax + Bu$，LQR 的代价泛函：

$$J = \int_0^\infty \big( x^\top Q x + u^\top R u \big)\,\mathrm{d}t$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $J$ | 代价泛函 | 全程累计的总扣分，越小越好 |
| $Q$ | 状态罚阵 | 各个偏差分量的单价，常取对角阵 |
| $R$ | 控制罚阵 | 各路油门的单价 |
| $x^\top Q x$ | 偏差账 | 二次型：方向加权后的偏差平方 |

最优解是一个线性反馈 $u = -Kx$，而 $K$ 由一个著名的矩阵方程给出——**Riccati 代数方程** $A^\top P + PA - PBR^{-1}B^\top P + Q = 0$，随后 $K = R^{-1}B^\top P$。按本章合同，这尊方程**只报名字不推导**：它的机理可以完全托付给计算机迭代（实验 2 现场演示），你只需要记住一件事——$Q/R$ 这对比价左右一切。

**一维速写版**（计算机结论在标量情形退化出的现成公式）：对象 $\dot{x}=x+u$ 时，最优闭环衰减率 $\lambda_{\mathrm{cl}} = -\sqrt{1+\rho}$，增益 $k = 1+\sqrt{1+\rho}$，其中 $\rho = q/r$ 是偏差对油钱的比价。比价越高，衰减越猛、手也越重。

## 4. 分步例题

读一张计算机回传的价目响应表（双积分离散模型 $\ddot{p}\approx$ 油门，细节见实验 2）：

1. **油便宜**（$R=0.25$）：计算机给出的增益 $K=[1.00,\ 2.00]$——重拳出击，闭环谱半径 0.500，误差两个采样周期内近似摁死，代价 $J=4$；峰值油门 1.00；
2. **中间市况**（$R=1.0$）：$K=[0.649,\ 1.483]$，谱半径 0.649，代价涨到 $J\approx 5$，峰值油门降到 0.65；
3. **心疼油钱**（$R=4.0$）：$K=[0.378,\ 1.047]$，谱半径 0.756，收敛明显变缓，代价 $J\approx 6$，峰值只剩 0.38；
4. 读表口诀：$R$ 每 ×4，**增益全面缩水、响应整体放缓**；总代价虽然名义上升，但那是因为这张考卷本来就改用了更贵的油价记账——真实的感受是"少踩了很多油门、多晃了一点时间"。

顺带用第 30 课的工具复核第 3 行的出厂参数：把 $B K$ 从演化卡 $A$ 里扣掉得到闭环卡（手工圆整版见练习实验 3），其两个特征模 0.7 与 0.5 都在单位圆内——**最优方案首先必须合格于稳定性考试，其次才轮到省钱比赛**。

### 实验 2：请计算机现场解 Riccati

```python title="迭代 Riccati：改油钱单价看响应换挡"
import numpy as np                          # 数值库（第 21 章已登记）

dt = 0.5                                    # 采样周期
A = np.array([[1.0, dt], [0.0, 1.0]])       # 双积分器：位置和速度的演化卡
B = np.array([[0.0], [dt]])                 # 油门只直接推动速度
Q = np.eye(2)                               # eye(n)：n 阶单位阵当偏差单价表

for r_val in [0.25, 1.0, 4.0]:
    R = np.array([[r_val]])                 # 油钱单价，循环里逐档更换
    P = Q.copy()                            # copy：复制一份，免得弄脏原件
    for _ in range(2000):
        S = R + B.T @ P @ B                 # .T 取转置；@ 做矩阵乘法
        K = np.linalg.solve(S, B.T @ P @ A) # solve(系数, 右端)：解线性方程组
        P = A.T @ P @ A - A.T @ P @ B @ K + Q   # Riccati 方程的迭代步伐
    radius = float(np.max(np.abs(np.linalg.eigvals(A - B @ K))))
    x = np.array([[1.0], [0.0]])            # 初始偏差一米、初速为零
    J = 0.0                                 # 总账簿
    peak = 0.0                              # 油门峰值记录仪
    for _ in range(120):
        u = float((-K @ x)[0, 0])           # [0, 0]：取出一乘一的格子转成普通数
        J += float((x.T @ x)[0, 0]) + r_val * u * u
        if abs(u) > peak:
            peak = abs(u)
        x = A @ x + B * u
    print(f"R={r_val}: K=[{float(K[0,0]):.3f}, {float(K[0,1]):.3f}], "
          f"谱半径={radius:.3f}, 代价={J:.0f}, 峰值油门={peak:.2f}")
```

真机输出的三行就是 §4 那张表的原始出处：`R=0.25` 时迭代恰好收敛到教科书级的干净增益 `[1.000, 2.000]`。玩法建议：把 `r_val` 改成 16 或 0.01 再跑，观察谱半径往哪头爬、峰值油门往哪头跳；把 `Q` 第一行换成 `10.0` 则相当于宣布"位置偏差加价十倍"，看 $K$ 如何自动反应。

### 实验 3：判题小练兵

控制器装机后，出厂检验要在闭环矩阵上复测第 30 课的判决书：

```exercise
# @title: 练习：给装好的闭环系统做出厂检验
# @check: 1.2
# @check: 0.35
# @check: 0.7
# @check: 0.5
# @check: True
# @hint: 特征方程依旧是 λ² − trλ + det；判别式等于迹的平方减去"四倍"行列式，别把系数抄丢。
a, b, c, d = 0.85, 0.5, -0.105, 0.35
import math                     # sqrt 开平方的老朋友

tr = a + d                      # 迹 = 主对角线之和
det = a * d - b * c             # 行列式 = ad − bc
disc = math.sqrt(tr * tr - 2 * det)   # ← 问题在这：判别式的系数抄成 2 了
lam1 = (tr + disc) / 2
lam2 = (tr - disc) / 2
stable = abs(lam1) < 1 and abs(lam2) < 1

print(round(tr, 2))
print(round(det, 2))
print(round(lam1, 2))
print(round(lam2, 2))
print(stable)
```

这张闭环卡对应的正是 $R=4$ 档的方向（特征根圆整成 0.7 与 0.5 便于手算）：双重衰减、无一逃逸，盖放行章。若把两根改成 1.05 与 0.9 这类配置，同样的流水线立刻亮红灯——最优性与稳定性各审各的卷子。

## 常见误区

:::warning[常见误区]

**误区一**："经过数学认证的最优，肯定是最好的控制器。"
最优只在**你写下的 J 和模型世界里**成立。模型不准、扰动没进账、"最优"照样翻车——这正是下一课鲁棒性的主题。心里要装着这句话："最优解忠于考卷，现实不看考卷。"

**误区二**："Q、R 反正有标准答案，抄默认值就行。"
单价一错全盘歪：$R$ 相对太小会催出巨大的增益，执行器一饱和，纸面上的最优瞬间作废。工程做法是先按物理量纲归一化各分量偏差，再想一想"哪里偏 1 厘米最心疼"，价目牌才立得住。

**误区三**："最优反馈需要的状态现实中都能量到。"
$u=-Kx$ 要用到全部状态；传感器往往只能看见一部分。缺的那几样靠观测器估计出来——LQR 与卡尔曼滤波合体的版本叫 **LQG**（同样只报名字）；而"哪些状态估得出来"，恰好是第 50 课可观性体检回答过的问题。

:::

## 6. 练习

**练习 1**：用 §3 的一维速写公式手工标价：对象 $\dot{x}=x+u$，比价 $\rho = q/r = 4$。求最优闭环衰减率与增益，再把 $R$ 加倍（即 $\rho=2$）比较。

<details>
<summary>点开查看逐步解答</summary>

套公式 $\lambda_{\mathrm{cl}} = -\sqrt{1+\rho}$、$k = 1+\sqrt{1+\rho}$：
$\rho=4$ 时 $\lambda_{\mathrm{cl}} = -\sqrt{5}\approx -2.236$，$k\approx 3.236$；
$\rho=2$ 时 $\lambda_{\mathrm{cl}} = -\sqrt{3}\approx -1.732$，$k\approx 2.732$。
解读：油钱翻倍，衰减从 $e^{-2.24t}$ 放缓到 $e^{-1.73t}$，开局油门同步打折——一维世界里权衡规律的完整缩影。
</details>

**练习 2**：在实验 2 中完成两组对照并记录：(a) `r_val=16`；(b) 保持 `R=1.0` 但令 `Q=np.diag([10.0, 1.0])`（diag：把列表铺上对角线）。各自的三项指标朝哪个方向动？

<details>
<summary>点开查看逐步解答</summary>

(a) 增益进一步萎缩（$k_{\text{pos}}$ 掉到 0.2 左右），谱半径逼近 0.9，代价名义值更高、峰值油门更低——纯纯的"佛系模式"。参照 $R=4$ 已有的 0.756 可以读出趋势同向。完整数字以你机器上的输出为准，重点是三项指标的相对走向而非末位小数。
(b) 这一步与加大 $R$ 方向相反：偏差单项涨价等于变相宣布"油钱没那么金贵"，于是 $K$ 显著变大、收敛加快。两条路径合起来证明同一件事——**真正说话的是比价 $Q/R$**：把两张价目牌整体同乘一个常数（比如全部翻倍），比值纹丝不动，计算机解出的 $K$ 也分毫不变。
</details>

## 7. 选读：计算机是怎么"解"出 K 的

<details>
<summary>选读 · 迭代 Riccati 的账本解释</summary>

实验 2 里那个循环做了一件很朴素的事：把 $P$ 当作"距离终点还有无限远时，剩余代价的最优估值"来反复更新。每迭代一轮，相当于问一遍"再多看一步远，我的账目该改成多少"；$P$ 一旦不再变化（不动点），它自动满足 Riccati 方程，也就顺带交出了最优增益 $K=R^{-1}B^\top P$。这种"逐步精化账本"的套路与第 22 章的不动点迭代同宗，也与强化学习里的价值迭代隔海相望（第 50 章）。工程软件最终用的是更快更讲究的 Schur 分解法，但运行的仍是同一个道理。想继续深挖设计与滤波配伍的故事，第 60 章工程控制论设了专门席位。

</details>
