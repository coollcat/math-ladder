# 非线性与自适应控制：当线性化不够用

## 1. 从一个场景开始

把一根杆倒立着顶在手上。杆只歪一点点的时候，你按线性化模型整定一套 LQR（第 70 课），扶得稳稳当当。

可一旦杆歪到 40°，或者你手里托的东西忽然换了重量，那套参数就会越扶越歪——因为线性化是**只在平衡点附近生效的局部地图**，而大角度下 $\sin\theta$ 和 $\theta$ 差得越来越远。

这一课给出线性化失灵时的三条对策：**反馈线性化**（把非线性精确抵消）、**滑模控制**（硬把它按到一条滑面上）、**自适应控制**（一边干活一边在线估参数）。它们各自开出一张不同的地形图。

## 2. 直觉解释

先用三个生活动作把三条路分开：

- **反馈线性化**：桌子腿不齐，桌腿高低是"非线性"的。办法不是换桌子，而是量一下差多少、垫上等高的垫片——**用测量把那条弯的曲线精确拉直**。前提是差异必须是"量得出来的"。
- **滑模控制**：地面结冰，你没法精确预测脚下会滑多远。但你可以先使劲把冰球推上一条固定的轨道（滑面），只要上了轨道，它就只会顺着轨道滑向洞里。**代价是推的时候手会来回抖**。
- **自适应控制**：拎一个不知道多重的箱子。你不会先称重再走，而是走两步感受一下、估个大概，再调整用力。**控制器参数是边走边学的**。

三条路共享同一个前提：**模型不再可信**——要么非线性太强，要么参数根本不知道。而它们的分工可以一句话概括：反馈线性化要精确模型，滑模要只要扰动的界，自适应要的是"误差能反映参数错了多少"。

## 3. 正式定义

**仿射非线性系统**（单输入单输出）：

$$\dot{x}=f(x)+g(x)\,u,\qquad y=h(x).$$

**相对阶 $r$**：对输出反复求导，直到 $u$ 首次出现。用 Lie 导数 $L_f h=\dfrac{\partial h}{\partial x}f(x)$ 表示：

$$y^{(r)}=L_f^{r}h+\bigl(L_gL_f^{r-1}h\bigr)u,\qquad L_gL_f^{r-1}h\neq 0 .$$

只要这个系数不为零，就能解出**反馈线性化控制律**：

$$u=\frac{v-L_f^{r}h}{L_gL_f^{r-1}h},$$

代入后系统变成 $r$ 重积分器 $y^{(r)}=v$，取 $v=-\sum_{i=0}^{r-1}a_i y^{(i)}$ 即可把极点摆到任何想要的位置。

**滑模面**（二阶系统的经典取法，$e=x-x_d$ 是跟踪误差）：

$$s=\dot{e}+\lambda e,\qquad u=u_{\text{eq}}-\eta\,\operatorname{sign}(s),\qquad \eta>F\ge|f|.$$

等效项 $u_{\text{eq}}$ 负责让 $\dot{s}=0$；切换项用增益 $\eta$ 盖过扰动上界。到达条件写成 $s\dot{s}\le -|s|(\eta-F)$：只要 $\eta>F$，状态**有限时间**撞上滑面，随后按 $\dot e=-\lambda e$ 指数归零。

**自适应律**（单参数 MRAC）：参考模型 $\dot y_m=-a_m y_m+b_m r$（$a_m>0$），被控对象 $\dot y=ay+bu$ 里 $a,b$ 未知。取 $u=\theta_1 y+\theta_2 r$，用跟踪误差 $e=y-y_m$ 反过来调参数：

$$\dot\theta_1=-\gamma\,e\,y,\qquad \dot\theta_2=-\gamma\,e\,r,\qquad \gamma>0 .$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f,g,h$ | 向量场与输出 | $f$ 是非线性漂移，$g$ 是控制的入口方向 |
| $r$ | 相对阶 | 输出要导几次 $u$ 才露面；决定线性化后有几重积分器 |
| $L_f h$ | Lie 导数 | 沿 $f$ 方向的导数，$(L_fh)(x)=\nabla h\cdot f$ |
| $s$ | 滑模面 | 误差空间里那条"只要站上去就安全"的线 |
| $\eta$ | 切换增益 | 必须大于扰动上界 $F$，否则按不住 |
| $\Phi$ | 边界层厚度 | 用 $\operatorname{sat}(s/\Phi)$ 替换 sign，压抖振 |
| $\theta$ | 可调参数 | 控制器里在线更新的旋钮 |
| $\gamma$ | 自适应增益 | 学习率：误差把估计推多快 |

**三种方法适用边界对比**：

| 方法 | 需要知道什么 | 不怕什么 | 怕什么 |
| --- | --- | --- | --- |
| 反馈线性化 | 精确的 $f,g,h$ | 大范围非线性 | 模型失配、$g$ 过零（控制量爆掉） |
| 滑模 | 扰动上界 $F$ | 匹配扰动、参数慢变 | 抖振、未建模高频动态 |
| 自适应 | 结构形式（阶数） | 参数未知或缓变 | 无持续激励时参数不收敛 |

## 4. 分步例题

**例 1（反馈线性化，一步到位）**：系统 $\dot x=x^2+u$，取 $y=x$。

1. 求导：$\dot y=x^2+u$——$u$ 第一次求导就出现，所以相对阶 $r=1$；
2. 对照公式：$L_fh=x^2$，$L_gh=1$；
3. 解控制律：$u=v-x^2$；
4. 取 $v=-kx$（例如 $k=2$），闭环变成 $\dot x=-2x$；
5. 读结果：$x(t)=x_0e^{-2t}$，**从任何初值出发都指数归零**——那个讨厌的 $x^2$ 被精确抵消，与 $x_0$ 大小无关。

对照一下"只线性化"的做法：在 $x=0$ 处 $\dot x\approx u$，当 $x=1$ 时被忽略掉的 $x^2=1$ 与 $u$ 同量级，线性控制器只能靠把增益拧大去硬压，越压越费劲。这就是"线性化不够用"的字面含义。

**例 2（滑模，二阶系统）**：$\ddot x=f+u$，未知扰动满足 $|f|\le F$；目标 $x_d\equiv 0$。

1. 定义误差与滑面：$e=x$，$s=\dot e+\lambda e$；
2. 取控制 $u=-\lambda\dot e-\eta\operatorname{sign}(s)$；
3. 算 $s$ 的变化：$\dot s=\ddot x+\lambda\dot e=f+u+\lambda\dot e=f-\eta\operatorname{sign}(s)$；
4. 用 $V=\tfrac12s^2$ 验到达：$\dot V=s\dot s\le(F-\eta)|s|<0$（当 $\eta>F$）——$s$ 在有限时间内归零；
5. 上滑面以后 $s=0$ 即 $\dot e=-\lambda e$，误差按 $e(t)=e(0)e^{-\lambda t}$ 衰减；
6. 代入数：$e(0)=1$、$\dot e(0)=0$、$\lambda=3$ 给出 $s(0)=3$；取 $\eta=2>F=1$，滑模段的**时间常数是 $1/\lambda\approx0.33$**。

**例 3（自适应，单参数 MRAC）**：被控对象 $\dot y=ay+u$，真值 $a=2$ 但控制器"不知道"；参考模型 $\dot y_m=-3y_m+3r$，指令 $r\equiv1$。

1. 控制律取 $u=\theta y+3r$，闭环 $\dot y=(a+\theta)y+3r$；
2. 匹配条件：想让 $a+\theta=-a_m$，即 $\theta^*=-a_m-a=-5$；
3. 自适应律 $\dot\theta=-\gamma e y$，$e=y-y_m$；
4. 取 Lyapunov 函数 $V=\tfrac12e^2+\tfrac{1}{2\gamma}(\theta-\theta^*)^2$，可验证 $\dot V=-a_m e^2\le0$——误差不增；
5. 数值见实验 3：40 秒后 $\theta$ 收敛到 $-5.00$，跟踪误差 $0.00$。

注意第 3 步为什么能起作用：$r\equiv1$ 让输出稳态不为零，$y$ 始终在"提供信息"（这叫持续激励）。若把 $r$ 关掉，误差照样归零，参数却停在一个偏掉的位置——见误区三。

矩阵特征值是 $\pm\sqrt{9.8}\approx\pm3.13$，一正一负，正是**鞍点**。图中虚线附近有一条唯一趋向原点的稳定方向（$\omega=-\sqrt{g/l}\,\theta$），其余方向全部发散射出。这解释了两件事：为什么"扶稳"需要在特定方向上持续施力；以及为什么初值一大，线性化相图就完全对不上了——真实系统的相图在远处会弯，直线近似只在原点附近成立。

### 实验 2（python）：滑模抖振对比

同一套滑模控制器，一次用理想符号函数 $\operatorname{sign}(s)$，一次用边界层 $\operatorname{sat}(s/\Phi)$，数一数控制量翻转了多少次：

```python title="滑模抖振对比：理想 sign vs 边界层 sat"
# sliders: eta=2.0 [0.5:5:0.5]

lam = 4.0            # 滑模面 s = v + lam*x 的斜率
dt = 0.001           # 积分步长（越小越接近连续）
steps = 4000         # 总共模拟 4 秒

def run(boundary):   # boundary=0 用理想 sign；>0 用边界层 sat
    x, v = 1.0, 0.0  # 位置误差与速度
    flips, prev = 0, 0   # 切换次数与上一次的方向
    for _ in range(steps):
        s = v + lam * x                      # 滑模面取值
        if boundary == 0:
            sw = 1 if s > 0 else -1          # 理想开关：只看符号
        else:
            sw = max(-1.0, min(1.0, s / boundary))   # 边界层内线性过渡
        u = -1.0 - eta * sw                  # −1 抵消已知扰动，切换项压制未知部分
        v = v + dt * (1.0 + u)               # 牛顿第二定律：ẍ = f + u，取 f = 1
        x = x + dt * v                       # 位置积分
        if prev != 0 and (sw > 0) != (prev > 0):   # 方向变了就记一次抖振
            flips = flips + 1
        prev = sw
    return flips, x

f_sign, x_sign = run(0.0)
f_sat, x_sat = run(0.1)
print(f"理想 sign：切换 {f_sign} 次，末端误差 {abs(round(x_sign, 4))}")
print(f"边界层 sat：切换 {f_sat} 次，末端误差 {abs(round(x_sat, 4))}")
```

输出是 `理想 sign：切换 1746 次，末端误差 0.0` 与 `边界层 sat：切换 2 次，末端误差 0.0`。两条曲线的**跟踪效果几乎一样**，但理想开关在每个采样步都在疯狂翻转——这就是抖振：理论上完美的 $\operatorname{sign}$，落到数字实现里会磨损执行器、激发出被忽略的高频动态。把边界层拧薄（把 0.1 改小），切换次数会回升；拧厚则抖动更小但稳态误差变大——**抖振和精度是一笔可调的账**。

### 实验 3（python）：自适应参数收敛

让控制器在完全不知道 $a$ 的情况下，一边跟踪参考模型一边估出它：

```python title="MRAC：估计值一路追上真值"
# sliders: gamma=20.0 [2:50:2]

a = 2.0                    # 被控对象里的未知参数（控制器假装不知道）
a_m, b_m = 3.0, 3.0        # 参考模型的期望极点与增益（设计者指定）
r = 1.0                    # 常值指令：让被控对象跟到稳态值 1

y, y_m, th = 0.0, 0.0, 0.0 # 实际输出、参考输出、待估参数
dt = 0.001                 # 步长
steps = 40000              # 共 40 秒

for _ in range(steps):
    u = th * y + b_m * r                   # 控制律：拿"当前估计"当补偿用
    y = y + dt * (a * y + u)               # 被控对象 ẏ = a y + u（a 真值只有它自己知道）
    y_m = y_m + dt * (-a_m * y_m + b_m * r)   # 参考模型：我们要它长成的样子
    e = y - y_m                            # 跟踪误差
    th = th - dt * gamma * e * y           # 自适应律：误差带着状态一起把估计往真值推

print(f"参数估计 = {round(th, 2)}（真值 {round(-a_m - a, 2)}）")
print(f"跟踪误差 = {round(e, 5)}")
```

输出 `参数估计 = -5.0（真值 -5.0）` 与 `跟踪误差 = 0.0`。估计值从 0 出发，一路被误差推到真值 $-a_m-a=-5$，跟踪误差同步归零。把自适应增益 $\gamma$ 拖到 2：收敛变慢但过程更平缓；拖到 50：几秒就到位，但一开始有明显的过冲。**学习和稳定之争，全在这一个增益上**。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为反馈线性化把非线性删除掉了。" 它其实是**用模型把非线性精确抵消**：$u=v-x^2$ 里的 $x^2$ 来自模型。模型不准时抵消不干净，残差会原样进入闭环；而且当 $L_gL_f^{r-1}h$ 过零时，控制律要除以一个零——增益会爆掉。这是它和滑模、自适应最本质的区别：它要求模型精确。

**误区二**："你以为滑模对扰动完全免疫，所以越大越好。" 滑模段动力学确实与匹配扰动无关（$\dot e=-\lambda e$ 里没有 $f$），但对**未建模的高频动态**它非常敏感：切换频率一高，被忽略的传感器延迟、执行器带宽就会出来捣乱。抖振不只是"难看"，它是真实硬件上第一个坏掉的东西。

**误区三**："你以为自适应一定会把参数学成真值。" 参数收敛需要**持续激励**：信号必须足够丰富，才能把参数从数据里"解"出来。常值指令常常只能定出参数的某个组合（例 3 里若把 $r$ 关掉，$\theta$ 会停在一个偏掉的值上），而跟踪误差可能已经为零。**跟踪好 ≠ 参数对**，这是自适应控制最容易被误判的一条。

:::

## 7. 练习

**练习 1**：给定滑模面 $s=\dot e+\lambda e$，别把两项的顺序搞反，并算出滑模段的时间常数：

```exercise
# @title: 练习：滑模面与滑模段的衰减快慢
# @check: 3.0
# @check: 0.33
# @hint: 滑模面 s = ė + λ·e：误差的变化率在前、误差乘 λ 在后；一旦 s = 0，误差按 e^(-λt) 衰减，时间常数就是 1/λ。
lam = 3.0      # 滑模面斜率
e = 1.0        # 初始跟踪误差
e_dot = 0.0    # 初始误差变化率

s0 = e + lam * e_dot     # ← 错在这：两项次序反了
tau = lam                # ← 错在这：时间常数是 λ 的倒数

print(round(s0, 1))
print(round(tau, 2))
```

修好后前两行是 `3.0` 和 `0.33`：初始滑面值为 3，滑上滑面后误差按 $e^{-3t}$ 衰减，时间常数约 $0.33$ 秒。

**练习 2**：例 1 的系统改成 $\dot x=x^2+u$，但实际执行器只能给出 $-20\le u\le20$。取 $v=-2x$、$x_0=10$，反馈线性化给出的 $u=-2x-x^2$ 在起点是多少？执行器能实现吗？

<details>
<summary>点开查看逐步解答</summary>

1. **代入起点**：$u=-2\times10-10^2=-20-100=-120$；
2. **越限判断**：$|u|=120\gg20$，执行器给不出来；
3. **后果**：饱和的那段时间里非线性并没有被抵消，闭环退化成 $\dot x=x^2-20$，在 $x>\sqrt{20}\approx4.5$ 时仍然发散——**状态会继续长大，形成"越饱和越失控"的正反馈**；
4. **对策**：工程上常见的两条出路是先做增益调度（离平衡点越远越减小期望的收敛速度），或者直接改用滑模——滑模只要求扰动有界，不要求 $g$ 可逆且控制量无限制，代价才是抖振。
</details>

## 8. 选读：滑模到达时间的有限时间证明

<details>
<summary>选读 · 为什么滑模是"有限时间"而不是"渐近"</summary>

取 $V=\tfrac12s^2$。沿 $u=-\lambda\dot e-\eta\operatorname{sign}(s)$ 有 $\dot s=f-\eta\operatorname{sign}(s)$，于是

$$\dot V=s\dot s=sf-\eta|s|\le(F-\eta)|s|=-\sqrt2(\eta-F)V^{1/2}.$$

这是一条**有限时间**收敛不等式。对 $\dfrac{\mathrm dV}{\mathrm dt}\le-cV^{1/2}$ 两边积分（$c=\sqrt2(\eta-F)>0$）得 $\sqrt{V(t)}\le\sqrt{V(0)}-\dfrac{c}{2}t$，所以在

$$t_r\le\frac{\sqrt{2V(0)}}{\eta-F}=\frac{|s(0)|}{\eta-F}$$

之后 $V$ 归零——滑面在**有限时间**内被撞上，而不是像指数衰减那样"永远差一点"。这正是滑模控制敢于承诺"到点即止"的底气，也是它和 LQR 那类渐近稳定器在气质上最大的不同。

值得补一句前提：这条不等式里 $f$ 必须满足 $|f|\le F$（扰动有界），且 $f$ 出现在与 $u$ 同一个通道里（匹配条件）。若不匹配，滑模段动力学里会残留扰动项，$\dot e=-\lambda e$ 就不再干净。工业界偏爱"PID + 增益调度 + 前馈补偿"的组合，很大程度上就是在绕开这两条前提。

</details>
