# Pontryagin 极大值原理：最优控制的另一半地图

## 1. 从一个场景开始

一辆小车停在轨道右端 1 米处，速度为零。它的推进器只有"全速后退 / 全速前进"两个档位，推力大小固定为 1，**没得调**。问：怎么踩，才能在**最短时间**内把车停在原点？

先刹一半？执行器不给你"一半"。先往前冲一点再猛刹？那更慢。这道题的最优驾驶手册长得相当反直觉：**先全速倒车，到 1 秒整一脚切成全速正推，第 2 秒整准点停住**——全程只有一次"开关动作"，而且中途的推力从头到尾都是最大值。

LQR（第 70 课）给的是光滑的线性反馈 $u=-Kx$，它要多大给多大。可现实里的执行器带着硬上限 $|u|\le 1$。**控制一旦被关进笼子，微积分的老办法就哑了**——本课请出 Pontryagin 极大值原理，专门处理"控制有约束"的最优问题。

## 2. 直觉解释

变分法（第 43 章的拉格朗日乘子、第 26 章的泛函极值）判断极值的动作只有一个：**在候选解附近往两边各推一点点，如果一阶变化为零，它就是极值**。

这个动作有个前提：两边都得推得动。可最优控制顶在边界上时（$u=1$，护栏就在右边），它**只能往里推，不能往外推**——"双向微扰"的对称性没了，一阶条件随即失效。这不是技术细节，而是整个问题的性质变了：**最优解不再藏在内部，而是贴在边界上**。

Pontryagin 的替代方案很朴素：既然 $u$ 只能在一个允许集合里挑，那就别求导了，直接问——**在每一时刻，哪个允许的控制让哈密顿函数 $H$ 最大？** 答案就是最优控制。贴着边界的解自动被选出来，一点不别扭。

配角是**协态** $\lambda$：它是拉格朗日乘子的连续版，读作"影子价格"——当前位置偏差一单位，会让总账单多掏 $\lambda$ 那么多。它不随时间向前走，而由终端条件**逆流**传回来，所以叫协态方程。

## 3. 正式定义

系统 $\dot{x}=f(x,u,t)$，控制被限制在允许集合 $u\in U$（例如 $U=\lbrace u:|u|\le 1\rbrace$）。要最小化的代价是

$$J=\varphi\bigl(x(T)\bigr)+\int_0^T L(x,u,t)\,\mathrm{d}t .$$

**哈密顿函数**把账目与动力学合到一个式子里：

$$H(x,u,\lambda,t)=L(x,u,t)+\lambda^\top f(x,u,t).$$

**极大值原理**（Pontryagin，1956）的三条判据：

1. **状态方程**：$\dot{x}=\dfrac{\partial H}{\partial \lambda}=f(x,u,t)$（照抄原系统）；
2. **协态方程**：$\dot{\lambda}=-\dfrac{\partial H}{\partial x}$（影子价格的时间导数）；
3. **逐点最大化**：$u^*(t)=\arg\max_{u\in U} H\bigl(x^*(t),u,\lambda^*(t),t\bigr)$（不要 $\partial H/\partial u=0$，要"在允许集合里挑最大"）。

再补两条边界条件：起点 $x(0)=x_0$ 已知；终端那条叫**横截条件**——终端状态若自由，$\lambda(T)=\nabla\varphi(x(T))$，若终端状态被钉死，反过来把 $\lambda(T)$ 交给终端约束去定。另有一条"当 $H$ 不显含时间时 $H$ 沿最优轨线恒定"的守恒律，本课两个算例都靠它收网。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $x$ | 状态 | 要调度的物理量（位置、速度…） |
| $u$ | 控制 | 我们手里的旋钮，被限制在 $U$ 里 |
| $\lambda$ | 协态 | 状态的影子价格，由终端条件逆流而来 |
| $H$ | 哈密顿函数 | $L+\lambda^\top f$，逐点最大化的靶子 |
| $L$ | 运行代价率 | 每秒要付的账（最短时间里就是每秒 1 元） |
| $\varphi$ | 终端代价 | 终点的罚金，终端自由时才进场 |
| $U$ | 允许集合 | 控制能取的范围，约束住在这里 |
| $T$ | 终端时刻 | 终点时间，可固定也可自由 |

**与 LQR 的关系**（本课最重要的接口）：把 $U$ 放开成整个空间、取 $L=\tfrac12(x^\top Qx+u^\top Ru)$，逐点最大化退化成 $\partial H/\partial u=0$，一举解出 $u=-R^{-1}B^\top\lambda$；而 $\lambda$ 与状态成正比 $\lambda=Px$（$P$ 是 Riccati 解），于是又回到了 $u=-Kx$。**LQR 只是 Pontryagin 在"无约束 + 二次型"下的特例**，下一课会把这条特例读成现成公式。

## 4. 分步例题

**例 1（最短时间停车：bang-bang 是怎么被逼出来的）**

系统 $\dot{x}_1=x_2$、$\dot{x}_2=u$，$|u|\le1$；起点 $(x_1,x_2)=(1,0)$，终点 $(0,0)$；代价 $J=\int_0^T 1\,\mathrm{d}t=T$。

1. **写 $H$**：$L=1$，$f=(x_2,\,u)$，所以 $H=1+\lambda_1x_2+\lambda_2u$；
2. **协态方程**：$\dot\lambda_1=-\partial H/\partial x_1=0\Rightarrow\lambda_1=c$（常数），$\dot\lambda_2=-\partial H/\partial x_2=-c\Rightarrow\lambda_2(t)=d-ct$；
3. **逐点最大化**：$H$ 里只有 $\lambda_2u$ 含 $u$，于是 $u^*=\operatorname{sign}(\lambda_2)$。而 $\lambda_2$ 是一次函数，**在 $[0,T]$ 上至多变号一次**——所以最优控制在整段行程里至多切换一次。这就是"bang-bang"（砰砰控制）的来历；
4. **守恒律收网**：$H$ 不显含 $t$，沿最优轨线恒定，且终端 $x_2(T)=0$ 给出 $H=0$。在切换前的左段 $u=-1$、$x_2=-t$，代入 $H=0$ 得 $1-ct-(d-ct)\cdot(-1)=0$，即 $d=1$；切换时刻由 $\lambda_2=0$ 定为 $t_s=1/c$；
5. **解出全部参数**：右段 $u=+1$ 同样满足 $H=0$（自洽）；$x_2(T)=0$ 敲定 $T=2t_s$，$x_1(T)=0$ 敲定 $1-t_s^2=0$，于是 $t_s=1$、$T=2$、$c=1$；
6. **读结果**：$u=-1$ 打满 1 秒，再 $u=+1$ 打满 1 秒，准点停在原点。顺带一个漂亮的副产品：$\lambda_1=c=1$，而真实关系 $T=2\sqrt{x_1(0)}$ 求导正好是 $\mathrm{d}T/\mathrm{d}x_{1}(0)=1/\sqrt{x_1(0)}=1$——**影子价格确实就是"起点偏差多花的时间"**，数字对上号了。

**例 2（最速降线：变分法的老题，换一套新判据重做）**

一点从高处滑到低处（无摩擦），什么形状的轨道最快？取状态为水平位置 $x$、下落深度 $y$，速度由能量守恒给出 $v=\sqrt{2gy}$，控制就是速度的方向角 $\theta$：

$$\dot{x}=\sqrt{2gy}\cos\theta,\qquad \dot{y}=\sqrt{2gy}\sin\theta,\qquad J=\int_0^T 1\,\mathrm{d}t=T .$$

1. $H=1+\lambda_x\sqrt{2gy}\cos\theta+\lambda_y\sqrt{2gy}\sin\theta$；
2. $\dot\lambda_x=-\partial H/\partial x=0$，故 $\lambda_x$ 恒为常数——这正是"函数不显含 $x$"给出的第一条积分，与变分法的 Beltrami 恒等式同宗；
3. 这里 $\theta$ 没有约束，逐点最大化退回成 $\partial H/\partial\theta=0$，解出 $\tan\theta=\lambda_y/\lambda_x$：**速度方向由两个影子价格之比锁定**；
4. 再配合 $\dot\lambda_y=-\partial H/\partial y$ 积分，得到那条著名的**旋轮线**（摆线）：$x=R(\theta-\sin\theta)$、$y=R(1-\cos\theta)$；
5. 数值验证见实验 2：旋轮线的下降用时比直线短一截，"最快"两个字是量出来的。

## 5. 动手实验

### 实验 1：协态系统是一张鞍点相图

把一维 LQR 的哈密顿系统画在"状态 × 影子价格"平面上（取 $a=0$、$q=1$）：$\dot{x}=ax-\lambda$、$\dot\lambda=-qx-a\lambda$。横轴是状态偏差 $x$，纵轴是它的影子价格 $\lambda$：

```viz

  "matrix": [0, -1, -1, 0],

  "y0": 1

```

矩阵的两个特征值是 $\pm1$——一张**鞍点**。绿线（稳定方向 $\lambda=x$）上的初值一边走一边让状态与价格同步收缩；另一条方向一路发散。这不是巧合：稳定方向 $\lambda=Px$ 里的 $P$ 恰好是 Riccati 方程的解（这里 $P=1$），对应最优反馈 $u=-Kx$。**"最优"在相图上就是"被吸进原点的那个方向"**，其余方向统统被最优性淘汰。

### 实验 2：bang-bang 轨迹跑一遍

```python
import math

# sliders: x0=1.0 [0.2:4:0.2]

dt = 0.0005                                  # 欧拉步长：每步推进的时间
T = 2 * math.sqrt(x0)                        # 最短时间的闭式解 T = 2√x0
steps = int(round(T / dt))                   # 总步数（round：四舍五入取整）
x1, x2, t = x0, 0.0, 0.0                     # x1 位置、x2 速度、t 时间

for _ in range(steps):
    if t < T / 2:
        u = -1.0                             # 前半程：全速倒车，先把速度堆起来
    else:
        u = 1.0                              # 后半程：全速正推，把速度恰好抹平
    x2 = x2 + dt * u                         # 半隐式欧拉：先用新速度
    x1 = x1 + dt * x2                        # 再更新位置
    t = t + dt

print(round(x1, 3))                          # 末端位置
print(round(x2, 3))                          # 末端速度
print(round(t, 2))                           # 实际用时
```

输出里位置与速度都是 $10^{-3}$ 量级的小残差（欧拉法的毛边，步长减半就再小一半），用时则稳稳落在 `2.0`。把滑杆 $x_0$ 拖到 4：最短时间自动变成 4.0 秒——**距离翻四倍、时间才翻一倍**，因为推力的"攒速度—抹速度"两段是对称的，$T\propto\sqrt{x_0}$。

### 实验 3：旋轮线真的比直线快吗

```python
import math

g = 1.0                                      # 重力加速度（取 1 便于读比例）
R = 1.0                                      # 旋轮线的尺度参数
N = 4000                                     # 分段数：越多越接近真积分

# 旋轮线：从尖点 (0,0) 下滑到 θ=π 的最低点，弧长微元 ds = 2R sin(θ/2) dθ
T_cycloid = 0.0
for i in range(N):
    th = math.pi * (i + 0.5) / N             # 中点法取样，避开端点的零速度
    ds = 2 * R * math.sin(th / 2) * (math.pi / N)
    depth = R * (1 - math.cos(th))           # 该点的下落深度
    T_cycloid = T_cycloid + ds / math.sqrt(2 * g * depth)   # 速度 v=√(2gy)
print(round(T_cycloid, 4))

# 直线：从 (0,0) 到 (πR, 2R)，同一个积分 ∫ds/v 有闭式解
T_line = math.pi * math.sqrt(1 + (2 / math.pi) ** 2) / math.sqrt(g)
print(round(T_line, 4))
```

两行是 `3.1416` 与 `3.7241`——旋轮线省下约 16% 的时间。旋轮线开局"陡"得几乎竖直，正是为了尽快把速度攒起来；影子价格的比值 $\tan\theta=\lambda_y/\lambda_x$ 在图上就是**轨道切线越来越平缓**的过程。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为最优控制总是光滑的连续函数。" 一旦有控制上限、或者代价对 $u$ 是线性的，最优解往往**贴着边界跳**——bang-bang 的开关、阀门的全开全关、继电器的通断都是这样。光滑反馈 $u=-Kx$ 只是"没有上限"这个世界里的特产。

**误区二**："你以为把 $\partial H/\partial u=0$ 解出来就是最优控制。" 那只是"允许集合内部"的一阶条件。当解落在边界上（$|u|=1$）时，这个方程根本无解，或者解出来的 $u$ 超出了允许范围——此时必须回到"逐点最大化"的原话：**在允许集合里挑使 $H$ 最大的那个**。

**误区三**："你以为协态 $\lambda$ 是个计算时顺便出现的数学符号。" 它有明确的经济学含义：$\lambda_i(t)$ 就是"$t$ 时刻状态 $i$ 多一个单位，最优总代价将增加多少"。例 1 里 $\lambda_1=1$ 与 $\mathrm{d}T/\mathrm{d}x_1(0)=1$ 的一致，是这条解释的现场验证。

:::

<details>
<summary>点开查看逐步解答</summary>

1. **缩放观察**：令 $u=4w$（$|w|\le1$），系统变成 $\dot{x}_1=x_2$、$\dot{x}_2=4w$。这不改变"至多切换一次"的结构，只是把加速度放大；
2. **用实验 2 的闭式解**：这个问题的通式是 $T=2\sqrt{x_1(0)/u_{\max}}$（可从两段对称的抛物面积直接读出）；
3. **代数字**：$T=2\sqrt{1/4}=1.0$ 秒；
4. **验算**：半程 0.5 秒，速度峰值 $4\times0.5=2$；位移 $=2\times\tfrac12\cdot(\text{峰值速度})\cdot(\text{半程})=1$ ✓；
5. **读趋势**：推力放大 4 倍，时间只缩短一半——又一次 $\sqrt{\phantom{x}}$ 律。想让时间再砍一半，得把推力放大到 16 倍。
</details>

## 8. 选读：与 HJB、Bellman 是一枚硬币的两面

<details>
<summary>选读 · 开环协态与闭环价值函数</summary>

极大值原理给出的是**协态**：对一条已经确定的最优轨线，逐时刻配一个影子价格。HJB 方程（Hamilton–Jacobi–Bellman）给出的是**价值函数** $V(x,t)$：对每个可能的状态都提前算好"从这里出发，最优还能花多少"。两者的关系可以一句话说清：

- 沿最优轨线，协态 $\lambda$ 就是价值函数的梯度 $\nabla V$（影子价格 = 边际价值）；
- 把 $\lambda=\nabla V$ 代回逐点最大化条件，$u^*=\arg\max H$ 立刻变成 $u^*(x)=\arg\max\bigl[L+\nabla V^\top f\bigr]$——一个**状态反馈律**；
- 所以 HJB 是"全地图"，极大值原理是"一条航线"：前者信息更多、方程更难解（偏微分方程，维数灾难），后者只求一条轨线、方程是常微分方程组。

数一下账就明白工程师为什么两套都留着：状态维数 $n$ 时，HJB 要解 $n$ 维偏微分方程，而极大值原理只解 $2n$ 个一阶常微分方程（状态 $n$ + 协态 $n$），再加终端条件。

后一条支线通向第 50 章的强化学习：Bellman 最优方程 $V(s)=\max_a[\,r(s,a)+\gamma V(s')]$ 是离散版的 HJB，而"协态 = 价值的梯度"这条翻译，就是策略梯度里 **优势函数**（advantage）的理论出处。同一套数学，一个用微分方程写，一个用期望写。

</details>
