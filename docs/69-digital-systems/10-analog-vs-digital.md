# 从模拟到数字：为什么离散

## 1. 从一个场景开始

一张 CD 里存着 60 分钟音乐。声音本来是空气里**连续**变化的压强——每一瞬间都有值，值可以取无限多个数。可 CD 里只有两种东西：凹坑和平地，读出来是 0 和 1。一条无限细腻的连续曲线，怎么可能装进一个只有 0 和 1 的盒子里？

答案是：**不装全部，只装够用的那一部分。** 这一步"扔掉再编码"，就是从模拟到数字的全过程，也是整个数字系统世界的入口。

## 2. 直觉解释

把连续信号掰成数字，靠的是三把刀（第 61 章讲过第一把，第 68 章的 ADC 一课见过它们的电路形态）：

- **采样**（时间上离散）：不再每时每刻盯着信号，只在固定间隔的瞬间"看一眼"。每秒看 44100 次，就是 CD 的采样率。
- **保持**：看完这一眼，把读数撑到下一眼之前，信号变成一段一段的台阶（零阶保持）。
- **量化**（幅度上离散）：看一眼得到的数也还是连续的——所以规定"只能报有限几个电平"。8 个电平就报 0～7 号，每个读数四舍五入到最近的电平。

最后把电平编号写成二进制——**编码**。比如 8 个电平用 3 位二进制：0 号写成 `000`，7 号写成 `111`。

三把刀每挥一次都扔掉一点信息：采样扔掉"两次采样之间"的信息，量化扔掉"电平之间"的信息。**数字化本质上是可控的、有计划的扔信息**——只要扔掉的量足够小、扔的方法足够聪明，人耳人眼根本察觉不到。

## 3. 正式定义

设信号取值范围为 $[-1, 1]$，量化位数 $b$，则：

| 量 | 定义 | 含义 |
| --- | --- | --- |
| 采样率 $f_s$ | 每秒采样次数 | 时间方向的离散密度 |
| 电平数 $L$ | $L = 2^b$ | 幅度方向被切成多少级 |
| 台阶 $\Delta$ | $\Delta = \dfrac{2}{L - 1}$ | 相邻两级之间的距离 |
| 码字 $c$ | $c = \mathrm{round}\!\left(\dfrac{v+1}{2}\,(L-1)\right)$ | 采样值 $v$ 被归到的电平编号，$0 \le c \le L-1$ |
| 量化值 | $q = c\,\Delta - 1$ | 码字还原回电平 |
| 量化误差 | $e = v - q$，$|e| \le \Delta/2$ | 四舍五入的代价 |

**数据量**：采样率 × 位数 × 声道数 × 时长，单位是比特，除以 8 变字节。

采样率怎么选，第 61 章的奈奎斯特定理已经给了答案：$f_s$ 必须大于信号最高频率的两倍，否则混叠。量化位数怎么选，就是本课要回答的：位数每加 1，电平数翻倍、台阶减半、误差大约减半——但数据量也**精确地**翻倍。

## 4. 分步例题

**例 1**：一个采样值 $v = 0.8$，量化到 3 位（$L = 8$ 个电平）。求码字、量化值与误差。

1. 台阶：$\Delta = 2/(8-1) = 2/7 \approx 0.286$；
2. 码字：$c = \mathrm{round}\!\left(\frac{0.8+1}{2}\times 7\right) = \mathrm{round}(6.3) = 6$；
3. 量化值：$q = 6 \times \frac{2}{7} - 1 = \frac{5}{7} \approx 0.714$；
4. 误差：$e = 0.8 - 0.714 = 0.086$，不超过半个台阶 $\Delta/2 = 1/7 \approx 0.143$——量化误差的天然上界；
5. 编码：电平 6 号写成 3 位二进制就是 `110`。

**例 2**：CD 音质的一分钟立体声（44100 Hz、16 位、双声道）有多大？

1. 每个采样 16 位 = 2 字节；
2. 每秒：$44100 \times 2\ \text{字节} \times 2\ \text{声道} = 176400$ 字节；
3. 一分钟：$176400 \times 60 = 10\,584\,000$ 字节，约 10 MB；
4. 整张 CD 74 分钟约 780 MB——1990 年代"一张盘装一张专辑"的秘密，就是把量化位数和采样率卡在"人耳刚好听不出"的边界上。

```lab
  "spp": 8,

```

上面是原始曲线和采样点（琥珀色圆点），中间是零阶保持的青色台阶和量化后的蓝色粗台阶，最下面一行把每个采样点的电平写成了二进制码字。做三件事：

- 把位数从 2 拖到 6——蓝台阶越来越贴住青台阶，误差读数一路缩小；
- 把位数拖回 1——只剩"高 / 低"两个电平，一条正弦波被掰成了方波，这是"数字化等于扔信息"最极端的样子；
- 按住画布拖动探针，逐点读"原值 → 量化值 → 误差 → 码字"，找一个误差恰好等于半个台阶的位置。

### 实验 2：自己算（Python）

```python title="量化误差有多大：位数每加 1，误差大约减半"
import math                      # 数学库（卷一已引入）：用 sin 和 pi

def quant(v, bits):              # 把 [-1, 1] 里的值吸附到 2^bits 个电平之一
    n = 2 ** bits - 1            # 最大码字（电平数 = n + 1）
    c = round((v + 1) / 2 * n)   # 码字：0 到 n
    if c < 0:
        c = 0
    if c > n:
        c = n
    return c * (2 / n) - 1       # 码字换回电平

N = 64                           # 一个正弦周期取 64 个采样点
for bits in [1, 2, 3, 4]:
    err2 = 0.0
    for k in range(N):
        v = math.sin(2 * math.pi * k / N)
        e = v - quant(v, bits)   # 原值 − 量化值 = 量化误差
        err2 = err2 + e * e
    print(f"bits={bits}  台阶Δ={2 / (2 ** bits - 1):.3f}  误差RMS={math.sqrt(err2 / N):.4f}")
```

四行输出是台阶与误差的对照：bits=3 时误差 RMS 约 0.079，与理论值 $\Delta/\sqrt{12} = 0.286/3.46 \approx 0.082$ 正好吻合（选读里推这个公式）；bits=4 时误差掉到约 0.035——**位数加 1、台阶减半、误差大约减半**，而数据量精确地翻倍。这条"一半一半"的交换律，就是所有数字系统设计师天天在算的账。

::::warning[常见误区]

**误区一**："位数越多越好。"
你以为高保真就该无脑堆位数——其实位数每加 1，数据量精确翻倍、存储和传输成本翻倍，而 16 位与 24 位的差距早在人耳动态范围之外。工程选型的要点是"刚好够"，不是"越多越好"。

**误区二**："量化误差是随机的噪声。"
你以为误差像掷骰子——其实对固定的输入，误差是**完全确定的**台阶函数失真，会顺着系统变成谐波与交调失真（选读里有推导）。只有当信号变化足够"花"时，它才表现得像白噪声。

**误区三**："采样点之间用直线连回去就行。"
你以为恢复信号靠连线——其实采样定理保证的是**带限信号**能被完美重建（用 sinc 插值，不是直线）。若采样率不达标，再漂亮的连线也只是把走样的曲线描得光滑些（混叠，第 61 章实验 2）。

::::

**练习 2**（概念题）：电话语音的量化位数只有 8 位，比 CD 少一半，为什么打电话照样听得清？

<details>
<summary>点开查看解答</summary>

三个原因：其一，电话只传 300–3400 Hz 的频段（采样率 8000 Hz 就够，是 CD 的 1/5.5）；其二，语音的动态范围远小于交响乐，大部分时间信号幅度不大，8 位电平在小幅度区间反而够密；其三，电话系统用的是**非线性量化**（μ 律 / A 律压扩）：小信号处台阶细、大信号处台阶粗，等效于给小信号"多分几个电平"。可见"位数"从来不是孤立指标——配合信号本身的统计特性，8 位也能胜任。
</details>

## 7. 选读：量化误差功率为什么是 Δ²/12

<details>
<summary>选读 · 均匀量化误差的均方值</summary>

设台阶为 $\Delta$，信号在两个电平之间来回摆动且摆得足够"花"，误差 $e$ 可以近似看作在 $[-\Delta/2, +\Delta/2]$ 上**均匀分布**的随机变量。均匀分布的密度为 $1/\Delta$，于是误差功率

$$E[e^2] = \int_{-\Delta/2}^{+\Delta/2} e^2 \cdot \frac{1}{\Delta}\,de = \frac{1}{\Delta}\cdot\frac{2(\Delta/2)^3}{3} = \frac{\Delta^2}{12}$$

所以误差 RMS $= \Delta/\sqrt{12} \approx 0.289\,\Delta$。位数每加 1，$\Delta$ 减半，误差 RMS 减半，**信噪比提高约 $20\lg 2 \approx 6$ dB**——音频工程里"每位 6 dB"这句口诀的出处。严格说误差并不是均匀分布也不是随机的（它是输入的确定函数），但当信号复杂、台阶又细时，这个近似相当准，实验 2 的 bits=3 行已经验证过。
</details>
