# 寄存器与移位寄存器

## 1. 从一个场景开始

鼠标动一下，一串数据要从它肚子里的小芯片跑到主机里去——中间只隔着**一根导线**。八个位不可能并排走独木桥，只能一个跟着一个排队过。可到了主机那边，这八个位还得重新排成一排，当一个完整的数来用。

排队走、排队进、进来了再一字排开——干这两件事的，是数字系统里出场率最高的两种部件：**寄存器**（把位存住）和**移位寄存器**（把位排队挪）。

## 2. 直觉解释

**寄存器**没有神奇之处：上一课的 D 触发器，一个记一个位。八个触发器共用同一根时钟线，上升沿一到，八个同时把各自的 D 收进来——就像一排八格的信箱，邮差只敲一次铃，八格同时换信。**「一个寄存器存一个字节」翻译过来就是「八个触发器同步采样一次」。**

**移位寄存器**只多一个花样：每个触发器的 D 接的**不是外部输入，而是左边邻居的 Q**。时钟沿一到，大家同时把邻居的内容抄过来——整排位**整体挪一格**。挪动带来三个副产品，每个都值钱：

- **左移一位 = 乘 2**：二进制里 178 是 `10110010`，整体往高位挪一格、末尾补 0，变成 `101100100`，就是 356。和十进制「后面添个 0 = ×10」一模一样；
- **右移一位 = 整除 2**：挪出去的最低位丢掉，相当于 $178 \to 89$；
- **串行进出**：从一端挤进来一位，就得从另一端挤出去一位——挤出去的那串就是**串行输出**。一根导线传一个字节，靠的就是它。

循环移位（rotate）则是把挤出去的那位从另一头绕回来，一个位都不丢。

## 3. 正式定义

**寄存器**：$n$ 个 D 触发器共用时钟，第 $i$ 位 $Q_i$ 在时钟沿采样 $D_i$，全体同步更新：

$$Q_i^{+} = D_i, \qquad i = 0, 1, \dots, n-1$$

**逻辑左移**（shl）：位串整体往 MSB 走，右端补 0，数值上等于 $\times 2$；**逻辑右移**（shr）：往 LSB 走，左端补 0，数值上等于 $\lfloor \div 2 \rfloor$（只对无符号数）。

**循环移位**（rol/ror）：移出端的那一位绕回移入端，寄存器里 1 的个数不变。

**串行输入 / 串行输出**：每拍从一端注入一位 $\mathrm{Din}$，另一端吐出一位 $\mathrm{Dout}$。$n$ 位寄存器把一个 $n$ 位字从头送到尾，恰好要 $n$ 拍——这是串行链路的节拍本源。

| 模式 | 数值效果 | 位的信息 |
| --- | --- | --- |
| 左移（补 0） | $\times 2$ | 移出的 MSB 丢失 |
| 右移（补 0） | $\lfloor /2 \rfloor$ | 移出的 LSB 丢失 |
| 循环移位 | 无（位形重排） | 一个不丢 |
| 串行加载 | 无 | 从单根线进，$n$ 拍装满 |

## 4. 分步例题

**例**：串行线上按「先到的是最高位」送来字节 `11001010`，8 拍后 8 位寄存器里的值是多少？

1. 寄存器初始 8 位全 0，串行输入 $\mathrm{Din}$ 接在**右端**（低位端进），位整体往 MSB 方向推；
2. 第 1 拍：进 1，寄存器 `00000001`；
3. 第 2 拍：整体左挪一格、再进 1 → `00000011`；
4. 继续推下去：`00000110` → `00001100` → `00011001` → `00110010` → `01100101`；
5. 第 8 拍结束，寄存器就是 `11001010`，换算 $128+64+8+2 = 202$。最先发的那个 1 一共被推了 7 格，正好停在最左端。

**每拍「整体挪一格 + 进一位」重复 8 次，一字节就装满了**。反过来发送也一样：把 202 放进寄存器，取最右位当 $\mathrm{Dout}$，右移 8 拍，导线上就依次出现了这 8 个位。第 5 节的实验让你亲手跑这条流水线。

## 5. 动手实验

### 实验 1（lab）：一排位整体挪格子

```lab
{
  "type": "register-shift",
  "title": "8 位移位寄存器：每来一个时钟，位就整体挪一格",
  "bits": 8,
  "mode": "left",
  "pattern": "01011001",
  "serIn": 0,
  "speed": 1.6
}
```

- 初始值 89（`01011001`）。点「播放」，位整体往左挪、右端 Din 的 0 一个个补进来——第 1 拍变 178，**恰好翻倍**；第 2 拍本该是 356，可 8 位最多装 255，于是 MSB 被挤出门外、只剩 100——**这就是溢出**：寄存器位数固定，移出去的位真的丢了；
- 把模式切到「右移 ÷2」，重置后再播——89 变 44，数值逐拍减半，减到奇数时最低位被丢（不四舍五入）；
- 切「循环右移」，播 8 拍——位串转一整圈回到原样，一个位都不丢；
- 单击任意格子翻转它（并行写入），再把 Din 切到 1 连播几拍，看 1 是怎么从一端挤进来、把旧位从另一端挤出去的；底部那条串行输出历史，就是这根「单导线」上发出去的字节。

### 实验 2（python）：移位即乘除

```python title="左移一位 = ×2，右移一位 = 整除 2"
bits = [0, 0, 1, 1, 0, 0, 1, 0]      # 8 位寄存器，左端是 MSB，值为 50

def to_int(bits):
    v = 0
    for b in bits:
        v = v * 2 + b
    return v

print("初始:", to_int(bits), "→", "".join(str(b) for b in bits))
shl = bits[1:] + [0]                 # 左移：扔掉 MSB，右端补 0
print("左移:", to_int(shl), "→", "".join(str(b) for b in shl))
shr = [0] + bits[:-1]                # 右移：左端补 0，扔掉 LSB
print("右移:", to_int(shr), "→", "".join(str(b) for b in shr))
```

50 → 100 → 25，一行不多一行不少（选 50 当初始值是为了让左移不撞上 8 位上限 255；换成 178，左移挤掉 MSB 就只剩 100——见实验 1 的溢出）。**这就是为什么处理器乘除 2 的幂不用乘法器**：一条移位指令，一个时钟沿搞定。

```python title="串行发送一个字节：8 拍装满 8 位寄存器"
Din = [1, 1, 0, 0, 1, 0, 1, 0]       # 要送的字节，先发最高位
reg = [0] * 8
history = ["".join(str(b) for b in reg)]
for d in Din:
    reg = reg[1:] + [d]              # 左移：Din 从右端挤进来
    history.append("".join(str(b) for b in reg))
for line in history:
    print(line)
```

九行位形从 `00000000` 一路长成 `11001010`——第一拍进的 1 一共被挪了 7 格，正好停在最左端。数一数：**装满一个 8 位字，不多不少 8 拍**，这就是串行接口「波特率」在硬件层面的真正含义。

### 快问快答

```quiz
一个 8 位寄存器存着 89，右移一位后变成多少，丢掉了什么信息？
- 44，丢掉了原来的最低位 1 [*]
- 44.5，移位寄存器可以存小数
- 178，右移等于乘 2
? 89 是奇数（二进制 1011001），右移后最低位的 1 被挤出去丢弃，剩下 0101100 = 44。移位只做整数运算：右移 = 整除 2 向下取整，丢掉的那位不四舍五入。
```

::::warning[常见误区]

**误区一**：「移位寄存器是『移动的存储』，位会自己走。」
你以为位真的在物理挪动——其实每个触发器纹丝不动，动的只是**内容的归属**：时钟沿一到，每个触发器把邻居的值抄过来。这也解释了为什么必须全体同用一个时钟：只要有一个触发器迟到一拍，整排内容就错位。

**误区二**：「循环移位和普通移位差不多。」
你以为 rotate 只是 shr 的变体——其实用途完全不同：逻辑移位是**数值运算**（×2、÷2），补进去的 0 参与了数值；循环移位是**位形重排**（把某个位挪到指定位置去检查/修改），数值大小根本不关心。加密与哈希里反复出现的几乎都是循环移位。

**误区三**：「串行传输比并行慢，所以是落后技术。」
你以为 8 根线一起传一定更快——其实线一多，8 根线到达时间就难对齐（偏斜），频率一高并行线之间还互相干扰。现代高速链路（USB、PCIe、SATA）清一色串行，靠的是**更高的时钟频率**而不是更多的线。

::::

## 6. 练习

**练习 1**：串行线上按到达顺序读到了 8 个位 `wire`，约定**先到的是最低位**，重建这个字节。期望 `218`。这段代码把「先到的」当成了最高位，方向弄反了：

```exercise
# @title: 练习：串行接收——先到的是最低位
# @check: 218
# @hint: 第 i 个到达的位应该乘 2 的 i 次方，而不是被挤着往高位走。逐个累加：value = value + wire[i] * 2 ** i
wire = [0, 1, 0, 1, 1, 0, 1, 1]      # 按到达顺序排列，wire[0] 最先到

value = 0
for i in range(8):
    value = value * 2 + wire[i]      # ← 问题在这：这是把 wire[0] 当最高位
print(value)
```

**练习 2**：一个 8 位移位寄存器存着 `10010110`，做「循环左移 3 位」。写出结果位串并求其十进制值。

<details>
<summary>点开查看逐步解答</summary>

1. 原串 `10010110`，十进制 $128+16+4+2 = 150$；
2. 循环左移 1 位：`00101101`（MSB 的 1 绕到 LSB）；移 2 位：`01011010`；移 3 位：`10110100`；
3. 或者按位形理解：把最左 3 位 `100` 整体搬到最右——`10110100`；
4. 换算：$128+32+16+4 = 180$。

注意循环移位不守恒数值（$150 \to 180$），守恒的是**位的集合**——8 个位里还是恰好 4 个 1，一个不多一个不少，只是站的位置变了。

</details>

## 7. 选读：并行装载与「移位 ÷ 并行」双模式

<details>
<summary>选读 · 真实芯片里的移位寄存器为什么有两个工作模式</summary>

纯串行装填太慢（$n$ 位要 $n$ 拍），所以经典器件（如 74LS194）都带一根**模式控制线**：

- 模式 0：每个触发器的 D 接邻居——移位模式；
- 模式 1：每个触发器的 D 接各自的外部并行引脚——并行装载模式，一拍装满。

串并转换器的全部秘密就是切换这两个模式：**并行装载一拍收下整个字节 → 移位模式逐拍吐出**（并转串），或**移位模式逐拍收进 → 并行装载一拍交出**（串转并）。鼠标、键盘、老式游戏机的线缆里只有几根线，靠的就是接收端那颗「串转并」芯片。

这个「每格 either 抄邻居 or 收外部」的选择器结构，下节的计数器也会用到——计数器不过是「每格抄邻居时顺手做个异或」的移位寄存器变种。

</details>
