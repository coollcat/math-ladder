# 卡诺图与逻辑化简

## 1. 从一个场景开始

一个三人小组要表决：**至少两人同意**，提案才通过。用 A、B、C 记三人的票（1 同意），"通过"记作 F。上一课的办法是列真值表、把 1 的四行加起来：

$$F = \bar{A}BC + A\bar{B}C + AB\bar{C} + ABC$$

四个乘积项、12 个字面量，要 4 个三输入与门加一个四输入或门。可同样的逻辑，换个写法只要三个字面量的两倍：

$$F = AB + BC + AC$$

两种写法对全部 8 种输入的行为**一模一样**，但门的数量差了一截。省下来的门是省下来的真金白银——芯片上每一个门都占面积、耗电、添延迟。**卡诺图**就是把"找更短写法"变成一圈圈画格子的手艺。

## 2. 直觉解释

化简的原理上一课其实已经埋下了：$AB + A\bar{B} = A(B + \bar{B}) = A$——两项只差一个变量时，能合并并消掉它。

卡诺图的高明之处是**把这个"只差一个变量"变成看得见的相邻**。把真值表重排成网格，让任意相邻两格的二进制编号恰好只差一位（行列都按格雷码 00, 01, 11, 10 排）。这样一来：

- 相邻的格子 = 只差一个变量的最小项 = **可以合并**；
- 把 $2^k$ 个相邻的 1 圈成一个圈，就消掉 $k$ 个变量；
- **圈越大，消得越多**：8 个格子的圈消 3 个变量，剩一个光杆字母。

还有两个反直觉的地方：网格的**四个角是相邻的**（都只差一位），**最左列与最右列、最上行与最下行也是相邻的**——格雷码排布让边缘"卷"了起来。所以圈可以越过边界"翻"到另一头，这常常正是最大的圈藏身之处。

## 3. 正式定义

**最小项** $m_i$：$n$ 个变量的与项，每个变量恰好出现一次（原变量或反变量）。编号 $i$ 的二进制就是让这个与项为 1 的输入：例如三变量下 $m_5 = A\bar{B}C$（5 = `101`，约定 A 是最高位）。

**卡诺图**：真值表的格雷码重排。三变量 8 格，A 在左侧、BC 在顶部（按 00, 01, 11, 10）；四变量 16 格，AB、CD 同法。

**圈（蕴涵项）**：$2^k$ 个全为 1 的相邻格。$k$ 变量被消去，圈对应一个与项。

| 术语 | 定义 |
| --- | --- |
| 质蕴涵项 | 不能再扩大的圈（再扩一格就会圈到 0） |
| 本质质蕴涵项 | 覆盖了某个"只有它能覆盖"的 1 的圈——**必选** |
| 最小覆盖 | 用最少的圈盖住全部 1，得到最简与或式 |
| 无关项 X | 输入组合根本不会出现，格子里填 X，当作 1 或 0 都行——怎么让圈更大怎么来 |

## 4. 分步例题

**例**：化简三人表决器 $F = \Sigma m(3, 5, 6, 7)$。

1. **填格**：画三变量卡诺图（A 行、BC 列按 00, 01, 11, 10），在 3、5、6、7 四格填 1，其余填 0；
2. **找必选圈**：$m_3$（`011`）的相邻 1 只有 $m_7$（`111`）——两者圈成对，消去 A 得 $BC$。同理 $m_5, m_7$ 圈成对得 $AC$，$m_6, m_7$ 圈成对得 $AB$；
3. **识别本质**：$m_3$ 只有第一个圈能盖住，$m_5$、$m_6$ 也各只有一个圈能盖——三个圈全是本质质蕴涵项，一个都省不掉；
4. **写出结果**：$F = AB + AC + BC$；
5. **验收**：4 项 12 字面量 → 3 项 6 字面量，且逐行代入真值表核对无差（上一课的 Python 手艺现在正好用上）。

注意 $m_7$ 被三个圈共用——一个格子进多个圈毫无问题，圈与圈可以重叠；卡诺图不允许的是"一个 1 没被任何圈盖住"。

## 5. 动手实验

### 实验 1：拖着看（lab 组件）

```lab
{
  "type": "karnaugh",
  "title": "点格子变成 1/0/X，看化简器怎么圈、最简式怎么变；按住拖能刷一片",
  "vars": 3,
  "ones": [0, 1, 4, 5]
}
```

读数区实时显示最小项、质蕴涵项、最简与或式和门数对比。初始局面是 0,1,4,5 四个 1 排成两列——化简器一圈到底，给你 $F = \bar{B}$，12 个字面量压成 1 个。做三件事：

- 把 A=0 那一行剩下的两个 0 点成 1（局面变成 0,1,2,3,4,5），看最简式从 $\bar{B}$ 改写成 $\bar{A} + \bar{B}$；
- 切到 4 变量（16 格），把四个角各点成 1——体会"四角相邻"：化简器会把它们圈成一个翻过边的圈；
- 点工具条上的"奇偶校验"预设：棋盘格局面一个圈都圈不出来，门数对比栏会告诉你"直接加最小项"就是最短写法——**有些函数天生化简不动**。

### 实验 2：自己算（Python）

```python title="奇偶校验函数为什么圈不出来"
def parity(u):                   # 三位里 1 的个数是奇（1）是偶（0）
    return ((u >> 2) & 1) ^ ((u >> 1) & 1) ^ (u & 1)

pairs = 0
for u in range(8):
    for b in range(3):
        v = u ^ (1 << b)         # 翻转第 b 位 = 卡诺图上的相邻格
        if parity(u) != parity(v):
            pairs = pairs + 1
print("0、1 相异的相邻对：", pairs // 2, "对——想圈一个都圈不出来")
```

翻转任何一位，1 的个数的奇偶必定改变，所以 8 格里每一对相邻格都是一 0 一 1——24 次统计去掉重复，12 对全部相异。奇偶校验函数的卡诺图是完美棋盘，它**没有**任何相邻的两个 1，最简式就是全部四个最小项之和。第 35 章讲奇偶校验时会正式遇到它：棋盘格不是卡诺图的失败，是这个函数"天生高维"的签名。

### 快问快答

```quiz
卡诺图里填 X（无关项）的格子应该怎么处理？
- 当 1 或当 0 都行，选让圈更大的那个 [*]
- 一律当 1
- 一律当 0
- 必须整格扔掉，圈绕开它
```

::::warning[常见误区]

**误区一**："圈必须是规规矩矩的矩形。"
你以为越界的圈都非法——其实合法性看的是"$2^k$ 个两两相邻的格"，翻边、跨四角都算数。4 变量下有些圈视觉上断成两截，逻辑上却是一整块。

**误区二**："格子多就能圈大圈。"
你以为 6 个相邻的 1 能圈一圈——圈的个数必须是 2 的幂（1、2、4、8、16），6 格、10 格都圈不得。遇到 6 个相邻 1，正确做法通常是 4 格圈 + 2 格圈。

**误区三**："化简结果唯一。"
你以为最简式只有一个——本质质蕴涵项是必选的，但盖住剩下的 1 可能有多种同样省门的选择，最小覆盖并不唯一。两种"最简式"可以长得完全不同却同样好。

::::

## 6. 练习

**练习 1**：卡诺图上 $\Sigma m(0, 1, 4, 5)$ 四个 1 圈成一片，化简结果是 $\bar{B}$。下面代码却把化简式实现成了 $B$，检查器数出满盘不一致：

```exercise
# @title: 练习：核对化简式与原函数
# @check: 0 处不一致
# @hint: 圈住的是 B=0 的格子，化简式是 not B——代码里写反了
ones = [0, 1, 4, 5]              # 卡诺图上为 1 的最小项编号
bad = 0
for i in range(8):
    A, B, C = (i >> 2) & 1, (i >> 1) & 1, i & 1
    m = 1 if i in ones else 0    # 原函数：最小项之和
    s = 1 if B else 0            # ← 问题在这：圈出来的是 B̄，不是 B
    if m != s:
        bad = bad + 1
print(bad, "处不一致")
```

**练习 2**（概念题）：一个 4 变量函数的 16 格卡诺图上有 8 个 1，恰好是 C=1 的那两列：$\Sigma m(2, 3, 6, 7, 10, 11, 14, 15)$。这个函数能化简到什么程度？为什么？

<details>
<summary>点开查看解答</summary>

先圈四格：$(2,3,6,7)$ 消掉 A 得 $\bar{A}C$，$(10,11,14,15)$ 消掉 A 得 $AC$；再把两个四格圈合成一个**八格圈**（C=1 的整两列，$\bar{A}$ 与 $A$ 各占一半），A 被彻底消掉：

$$F = \bar{A}C + AC = (\bar{A} + A)\,C = C$$

一个 16 格真值表，最后一个字母写完。因为 8 个 1 恰好铺满"只跟 C 有关"的整片区域——输入的其他三位随便怎么变，输出只看 C。反过来，1 的分布越"碎"（如棋盘格），可合并的相邻对越少，式子越长。**化简的收益完全由 1 的分布形状决定。**
</details>

## 7. 选读：从卡诺图到机器化简

<details>
<summary>选读 · 质蕴涵、本质与最小覆盖（Quine–McCluskey 一瞥）</summary>

本课组件内部跑的是一套标准算法，人肉卡诺图只是它的可视化：

1. **枚举全部质蕴涵项**：从单点出发，凡能合并的最小项对（只差一位）就合并、打上已合并标记，反复进行到不能再合；活到最后的项就是质蕴涵。这一步在 4 变量内可以靠"看格子"，变量一多就要交给计算机（Quine–McCluskey 算法）；
2. **挑本质质蕴涵项**：建一张"最小项 × 质蕴涵"覆盖表，凡是只被一个 PI 覆盖的最小项，就把那个 PI 锁进答案；
3. **贪心补齐**：剩下还没盖住的 1，按"每新增一项盖住最多"逐个挑 PI，直到全覆盖。

严格的 3 步之后其实还该做**分支回溯**求严格最小覆盖（贪心可能差一步），工业工具（Espresso 启发式及其后代）在这一层下了几十年功夫。今天的 FPGA 综合器面对几十个输入的函数，早就不画图了——但你面试白板上画的那个圈，算法内核仍是这三步。
</details>
