# 计数器与时钟分频

## 1. 从一个场景开始

你手腕上的电子表，芯里震的是一根每秒 32768 次的石英晶振。可表盘要的是「秒」——每秒只走一格。从 32768 到 1，中间隔着 15 次「减半」。

谁来减半？不需要任何乘除电路：让上一课的触发器排成一行、首尾相接，让它们**自己数数**。数着数着你会发现，每一位输出的频率恰好是时钟的一半、四分之一、八分之一……**计数与分频，是同一件事的两个名字。**

## 2. 直觉解释

把寄存器的 D 输入从「外部数据」换成「自己的值加一」，它就从「存数」变成了「数数」：每个时钟沿值加 1，数到头再回零——这就是计数器。

奇迹发生在**每一位的节律**上。一个 4 位二进制计数器 `0000, 0001, 0010, 0011 …`，盯住最低位 $Q_0$ 看：0,1,0,1,0,1——翻转得最快，恰好是时钟频率的一半；$Q_1$ 是 0,0,1,1,0,0,1,1——再慢一半，四分之一；$Q_2$ 八分之一……**从低位到高位，每一位都是前一位的二分频**。

这不是巧合：低位每翻**两次**，才轮到高位翻**一次**（逢二进一嘛）。所以一排计数器天生就是一排分频器：

| 信号 | 频率 | 12 MHz 时钟下 |
| --- | --- | --- |
| CLK | 基频 | 12 MHz |
| $Q_0$ | ÷2 | 6 MHz |
| $Q_1$ | ÷4 | 3 MHz |
| $Q_2$ | ÷8 | 1.5 MHz |
| $Q_3$ | ÷16 | 750 kHz |

数到头的「回零」也自带用途：模 16 计数器从 15 回到 0 的那一拍，输出一个**进位脉冲**（RCO）。拿这个脉冲去触发下一级、去清零别的电路、去「进位」，计数器就从记录工具升级成了控制器。

## 3. 正式定义

**模 $N$ 计数器**：状态集合 $\lbrace 0, 1, \dots, N-1\rbrace$ 上的循环，每个时钟沿状态加 1，到 $N-1$ 后回 0：

$$s^{+} = (s + 1) \bmod N$$

**分频**：模 $N$ 计数器某一位（或回零事件）的重复频率是时钟的 $1/N$ 的某个整数比——模 16 的最低位是 ÷2，回零脉冲是 ÷16。

**BCD 计数器**：模 10 计数器，按二进制数 0–9，数到 9 回零（而不是模 16 的 15 回零）。三个 BCD 计数器串起来，就是十进制的时间：秒、十秒、分。

**回零脉冲（RCO）**：计数器处于最大值时的输出信号，下一拍回零时用它通知下一级「进位」。模 $N$ 计数器串 $k$ 级，整体就是模 $N^k$。

| 术语 | 含义 |
| --- | --- |
| 模（mod） | 循环长度，几进制就模几 |
| 回零 | 数到 $N-1$ 后跳回 0 的那一拍 |
| 分频系数 | 输出频率 = 时钟频率 ÷ n，记作 ÷n |
| 级联 | 用回零脉冲驱动下一级计数器，扩大计数范围 |

## 4. 分步例题

**例**：模 10（BCD）计数器接 1 MHz 时钟，问回零脉冲的频率是多少？

1. 计数器走完一个循环需要 10 个时钟周期（0→1→…→9→回零）；
2. 回零每循环发生一次，即每 10 个时钟脉冲一次；
3. 回零脉冲频率 $= 1\,\text{MHz} / 10 = 100\,\text{kHz}$；
4. 若再串一级模 10，输出 $= 10\,\text{kHz}$；串三级，$1\,\text{kHz}$——秒表、分表就是这么一层层分出来的。

**例 2**：石英钟方案里，32768 Hz 晶振要过几级二分频才到 1 Hz？

$32768 = 2^{15}$，所以恰好 **15 级 ÷2**，一拍不多一拍不少。为什么钟表业选 32768 这种怪数？就因为它是 2 的整数次幂里「对人眼够用又最省电」的那一档——**选晶振频率，本质是在选分频级数**。

## 5. 动手实验

### 实验 1（lab）：整块画布就是一张时序图

```lab
{
  "type": "counter-lab",
  "title": "4 位二进制计数器：每一位都是前一位的二分频",
  "mod": 16,
  "div": 6,
  "fclk": 12,
  "speed": 3
}
```

- 拖动琥珀色播放头逐拍走，对照 CLK 与 $Q_0$：CLK 两个周期，$Q_0$ 才走完一个完整方波——÷2；再看 $Q_1$、$Q_2$，一次减半；
- 数值计到 15 的下一拍，红色竖虚线一闪、RCO 拉高一拍——**回零脉冲就在这一拍**；
- 把 mod 切到 10（十进制 BCD）：数到 9 就回零，红色虚线提前了 6 拍出现；
- 「DIV ÷n」行开局就是 ÷6：拖它的把手拨到别的值再拖回来，那行输出始终是 CLK 的 ÷n 方波——计数模值与分频系数是两套独立的旋钮。

### 实验 2（python）：分频链与回零节奏

```python title="每一位输出都是二分频"
f = 12.0                            # 时钟频率（MHz）
print(f"CLK = {f} MHz")
for i in range(4):
    f = f / 2
    print(f"Q{i} = {f} MHz")
```

12 → 6 → 3 → 1.5 → 0.75 MHz，每一级恰好减半。一颗 12 MHz 的晶振过 4 级触发器就白得了 6 MHz、3 MHz、1.5 MHz、750 kHz 四路时钟——**数字系统里所有「低频时钟」都是这么免费搭出来的**。

```python title="模 10 计数器：数到 9 回零"
mod = 10
state = 0
seq = []
rco = []                            # 回零脉冲：下一拍要回零就提前拉高
for i in range(12):
    seq.append(state)
    rco.append(1 if state == mod - 1 else 0)
    state = state + 1
    if state == mod:
        state = 0
print("计数序列:", seq)
print("RCO 脉冲:", rco)
```

计数序列走到 9 的下一拍回 0，RCO 恰在 state=9 的那一拍拉高——**「我是最大值」就是「下一拍进位」的预告**。把 mod 改成 16 再跑一遍，两种进制回零点的差别一目了然。

### 快问快答

```quiz
8 kHz 的时钟接到计数器上，Q2 这一位的输出频率是多少？
- 1 kHz [*]
- 2 kHz
- 4 kHz
? Q0 是 ÷2 = 4 kHz，Q1 是 ÷4 = 2 kHz，Q2 是 ÷8 = 1 kHz。每位二分频：第 i 位就是时钟的 1/2^(i+1)。
```

::::warning[常见误区]

**误区一**：「计数器要靠一套『加法电路』才能加一。」
你以为得先做加法器再接寄存器——其实加一有专属捷径：从最低位起，把 1 变 0 的连续 tail 之后的第一个 0 变 1 即可（`0111 + 1 = 1000`），用异或门与进位链几根线就实现了。通用加法器是浪费。

**误区二**：「模 10 计数器就是模 16 计数器少用几个数。」
你以为 BCD 是「放着 10~15 不数」——其实必须在 9 之后**强制清零**，否则下一拍它会顺理成章地数到 10。模 $N$ 计数器 = 模 $2^k$ 计数器 + 一个「数到 $N-1$ 就请求回零」的检测电路，那个检测电路才是模值的本体。

**误区三**：「分频输出跟输入频率只是慢了，波形没别的差别。」
你以为 ÷2 只是频率减半——其实占空比、相位都跟着变化，而且级联分频之间有确定的整数关系。时钟树设计里正是靠这套「整数比家族」让全芯片共享一个晶振却各取所需；反过来说，任何两个频率如果不在一个二分频家族里，就得另起计数器链。

::::

## 6. 练习

**练习 1**：手表晶振 32768 Hz，经过 15 级二分频后输出 1 Hz 的秒脉冲。求输出频率。期望 `1.0`。这段代码级数数错了一级：

```exercise
# @title: 练习：从 32768 Hz 到 1 Hz
# @check: 1.0
# @hint: 32768 = 2 的 15 次方，所以要除以 2 十五次。range(15) 才是 15 级，range(14) 少一级
f = 32768.0            # 手表晶振（Hz）
for i in range(14):    # ← 问题在这：少除了一次
    f = f / 2
print(f)
```

**练习 2**：一个模 6 计数器接 6 MHz 时钟。求：(a) 一个循环需要多少个时钟周期；(b) 回零脉冲频率；(c) 若用回零脉冲再触发一个模 6 计数器，第二级回零脉冲频率又是多少？

<details>
<summary>点开查看逐步解答</summary>

1. 模 6 循环一遍 = 6 个时钟周期；
2. 回零脉冲频率 $= 6\,\text{MHz} / 6 = 1\,\text{MHz}$——这就是实验 1 里「DIV ÷6」那路输出；
3. 第二级循环 = 6 个「第一级回零脉冲」周期，频率 $= 1\,\text{MHz} / 6 \approx 166.7\,\text{kHz}$。两级模 6 级联 = 模 36，整体回零频率 $= 6\,\text{MHz}/36$——与逐级算的结果一致，因为 $N^k$ 级联就是模 $N^k$。

顺带一提：模 6 × 模 10 正是「十进制秒表」的标准拆法——个位模 10、进位模 6，凑出 0–59 秒。

</details>

## 7. 选读：行波计数器与同步计数器

<details>
<summary>选读 · 为什么老式计数器会「抖」一下</summary>

最朴素的接法是**行波计数器**（ripple counter）：不用公共时钟，让 $Q_0$ 的输出直接当 $Q_1$ 的时钟，$Q_1$ 当 $Q_2$ 的时钟……好处是零额外逻辑，坏处是进位要**一级一级传**：从 0111 翻到 1000，四个触发器依次晚一点点翻转，中间会短暂闪过 0110、0100、0000 这些「假状态」。

同步计数器把公共时钟还给所有人，用组合逻辑（就是那些异或与进位检测）直接算好每位下一拍该是什么——所有位同一拍换班，假状态只剩门延迟级的毛刺。数字越多的计数器，进位链越长，这个差别越大。

这跟第 40 课加法器里的进位问题是同一个权衡：**省逻辑就要忍受延迟串行，要速度就得提前算好进位**。第六卷里这个主题已经第三次出现了——它是数字工程的底色。

</details>
