# 同步状态机设计

## 1. 从一个场景开始

路口的红绿灯要按这样的规矩走：绿 30 秒、黄 5 秒、红 35 秒，循环往复。它不是计数器——计数只会加一；也不止是寄存器——寄存器只管存。它要做的是：**根据「现在处于哪个阶段」，决定「下一拍去哪个阶段、现在亮哪盏灯」**。

第 31 章你见过状态机的纸上形态：状态、转移、字母表。这一课把它接上时钟沿和输出引脚，让它变成真正会动、会亮的电路。**计数器是状态机里最无聊的一个**——它的「下一状态」永远机械地加一；状态机把这张表交还给设计者随意涂写。

## 2. 直觉解释

状态机电路 = **状态寄存器 + 一块组合逻辑**，一句话说尽：

- 状态寄存器（上一课的触发器排）记住「现在在哪」；
- 组合逻辑（第 20 课的门电路）查两张表：**现在的状态 + 现在的输入 → 下一状态**；以及 → **现在的输出**。

时钟沿一到，寄存器换班，机器跳到「下一状态」。所谓设计状态机，就是把这张转移表**涂对**。

涂表之前有一个选择题：输出从哪来？

- **Moore 机**：输出只看状态。状态里已经「腌」好了输出，输入变化要等下一个沿被吸收、机器跳了状态，输出才变——**慢一拍，但稳**。红绿灯是典型：什么灯亮只取决于在第几阶段；
- **Mealy 机**：输出 = 状态 + 输入一起决定。输入一变输出立刻能变，不必等时钟沿——**快一拍，但毛刺也可能跟着来**。序列检测器是典型：最后一个字符一到，立刻报警。

两者等价（可以互相转换），工程上按「要快还是要稳」挑。

## 3. 正式定义

**同步状态机**：五元组 $(S, I, O, \delta, \lambda)$，其中 $S$ 是状态集，$I$/$O$ 是输入/输出字母表，$\delta: S \times I \to S$ 是状态转移，$\lambda$ 是输出函数：

$$\text{Moore:} \quad \lambda: S \to O \qquad\qquad \text{Mealy:} \quad \lambda: S \times I \to O$$

与第 31 章 DFA 的差别只有两处：转移带**时钟沿**节拍（每个沿走一步），且多了输出函数（DFA 只回答「收不收」，这里要持续行动）。

**设计流程四步**：

1. **画状态图**：每个状态起名并写清「它记住的关键历史」（如「已连续收到 110」）；
2. **列转移表**：每个状态 × 每个输入 → 下一状态（+ 输出）；
3. **状态编码**：给每个状态分配一个位串。顺手编码（按表顺序）未必最省门，但先求对再求省；
4. **落地**：$k$ 位编码用 $k$ 个 D 触发器存状态，转移表烧进组合逻辑。

**以 1101 序列检测器（Mealy，允许重叠）为例**，四个状态记住「已匹配的前缀长度」：

| 状态 | 记住的历史 | 输入 0 → | 输入 1 → | 输出（Mealy） |
| --- | --- | --- | --- | --- |
| S0 | 还没对上 | S0 | S1 | 0 |
| S1 | 收到 1 | S0 | S2 | 0 |
| S2 | 收到 11 | S3 | S2 | 0 |
| S3 | 收到 110 | S0 | S1 | **1** |

最容易错的是 S3：收到 1 时**不能回 S0**——这个 1 同时是下一串 1101 的第一个字符，必须去 S1。**重叠检测的灵魂就在这一根边**。

## 4. 分步例题

**例**：用上面的状态机处理输入 `1101101`，从 S0 出发，输出串是什么？

1. S0 收 1 → S1，输出 0；
2. S1 收 1 → S2，输出 0；
3. S2 收 0 → S3，输出 0；
4. S3 收 1 → S1，**输出 1**——检测到第 1 串 `1101`（第 1–4 位）；
5. S1 收 1 → S2，输出 0；S2 收 0 → S3，输出 0；
6. S3 收 1 → S1，**输出 1**——检测到第 2 串（第 4–7 位，与第一串共享第 4 位的那个 `1`）。

输出串 = `0001001`。输入 7 位，检出 2 次——如果 S3 收 1 错回了 S0，第二串就漏了，输出会变成 `0001000`。第 6 节的练习让你亲手修出这个 bug。

**状态编码落地**：四个状态用 2 位编码（S0=`00`, S1=`01`, S2=`10`, S3=`11`），两个 D 触发器存编码，转移表化成两输出、三输入（2 位状态 + 1 位输入）的组合逻辑——第 30 课的卡诺图正好派上用场。

### 实验 3（python）：纯 Python 跑同一个检测器

```python title="1101 序列检测器（Mealy）：转移表就是设计本身"
def step(s, x):
    if s == 0: return 1 if x == 1 else 0
    if s == 1: return 2 if x == 1 else 0
    if s == 2: return 2 if x == 1 else 3
    return 1 if x == 1 else 0          # s == 3：重叠检测的关键一行

def out(s, x):
    return 1 if (s == 3 and x == 1) else 0

seq = "1101101"
s = 0
outputs = ""
for ch in seq:
    x = 1 if ch == "1" else 0
    outputs += str(out(s, x))
    s = step(s, x)
print(outputs)
```

输出 `0001001`，与手算逐位一致。这段代码和真实电路是**同构**的：`step` 是组合逻辑块，`s` 是状态寄存器，for 循环的每一轮就是一个时钟沿——把 `s = step(s, x)` 想象成沿上的换班，你已经用 Python 写了一遍数字电路。

```python title="模 3 计数器（Moore）：输出跟状态走"
s = 0                                # 状态 = 已收到 1 的个数 mod 3，输出就是状态值
seq = "1101010"
for ch in seq:
    s = (s + (1 if ch == "1" else 0)) % 3
    print(ch, "-> 状态", s, "· 输出", s)
```

每个状态停留一整拍、输出与状态同印——Moore 的节律。第 80 课的计数器就是这类机器里转移表最规矩的一员：$s^{+} = (s+1) \bmod N$。

### 快问快答

```quiz
Moore 机的输出由什么决定？
- 当前状态 [*]
- 当前输入
- 当前输入和当前状态
? Moore 机的输出函数 λ 只定义在状态上：输出挂在状态节点里，输入要等时钟沿被吸收、机器跳了状态才影响输出。Mealy 机的输出才由状态和输入共同决定，快一拍。
```

::::warning[常见误区]

**误区一**：「状态越多越保险，多画几个总没错。」
你以为状态宁多勿少——其实多余状态不仅是浪费：等价状态会让同一行为对应两条路径，验证与化简都变难。第 31 章的 DFA 最小化在这里同样适用——**状态数是设计质量的计分板**。

**误区二**：「Mealy 输出快，所以一律选 Mealy。」
你以为快就是好——其实 Mealy 输出直接跟着输入走，输入线上的毛刺会**不经过任何滤网**窜到输出。对外的控制信号（红绿灯、阀门）宁可慢一拍也要稳，选 Moore；内部数据通路里追时序，才轮到 Mealy。

**误区三**：「状态编码随便编，反正逻辑会算出来。」
你以为编码只是取名——其实编码决定组合逻辑的形状。两个「总是接连出现」的状态若编码只差一位（相邻编码），译码门就少一半；一种叫**独热编码**（每个状态一位、只热一个）的方案更是用「浪费位」换来了极简的转移逻辑。FPGA 里独热常常更快，卡诺图里相邻编码更省——涂表之前先想编码。

::::

## 6. 练习

**练习 1**：1101 检测器要支持**重叠检测**，期望输出 `0001001`。这段代码把 S3 收 1 后送回了 S0，重叠的那一串漏掉了：

```exercise
# @title: 练习：修好重叠检测
# @check: 0001001
# @hint: 检测到 1101 后输入的最后一个 1，同时是下一串 1101 的开头。S3 收 1 应该回到 S1，不是 S0
def step(s, x):
    if s == 0: return 1 if x == 1 else 0
    if s == 1: return 2 if x == 1 else 0
    if s == 2: return 2 if x == 1 else 3
    return 0 if x == 1 else 0          # ← 问题在这：回 S0 丢了重叠

def out(s, x):
    return 1 if (s == 3 and x == 1) else 0

seq = "1101101"
s = 0
outputs = ""
for ch in seq:
    x = 1 if ch == "1" else 0
    outputs += str(out(s, x))
    s = step(s, x)
print(outputs)
```

**练习 2**：一个自动售货机只收 1 元和 5 角硬币，饮料定价 2 元、不找零。画出状态图（用 0 元、5 角、1 元、1 元 5 角四个状态），并回答：投币序列 `5角, 5角, 1元` 出货发生在哪一步？

<details>
<summary>点开查看逐步解答</summary>

1. 状态 = 「已投入但未出货的总额」，封顶在 1 元 5 角（再多 5 角就出货，不需要更大的状态）；
2. 转移：0 元 --5角--> 5角 --5角--> 1元；从「1 元」再投 1 元、从「1 元 5 角」投 5 角，都当场凑满 2 元出货——四个状态各有一条「出货边」通回 0 元；
3. 序列 `5角, 5角, 1元`：0 → 5角 → 1元 → 投 1 元凑满 2 元 → **第三步出货**，机器回到 0 元；
4. 设计细节：从「1 元」投 5 角到「1 元 5 角」，从「1 元」再投 1 元应**当场出货**（不许停在 2 元状态，因为 2 元 = 出货后清零）。

这正是 Moore 机管「亮哪盏灯」、Mealy 边管「当场出货」的混合味道——真实售货机两种实现都有，取决于出货信号要不要抢在硬币落底之前。

</details>

## 7. 选读：从状态图到门电路的全程

<details>
<summary>选读 · 把 1101 检测器真的烧进门里</summary>

取编码 S0=00, S1=01, S2=10, S3=11（$Q_1 Q_0$）。转移表以 $(Q_1, Q_0, x)$ 为输入、$(D_1, D_0)$ 为输出（D 触发器的下一态方程）：

| $Q_1 Q_0$ | $x=0$ | $x=1$ |
| --- | --- | --- |
| 00 | 00 | 01 |
| 01 | 00 | 10 |
| 10 | 11 | 10 |
| 11 | 00 | 01 |

先把 $D_1$（下一态的高位）的 1 挑出来：01 收 1、10 收 0、10 收 1 三格。10 收 0 与 10 收 1 相邻可合并，化简得：

$$D_1 = Q_1\bar{Q_0} + \bar{Q_1}Q_0x$$

验证两个边界：11 收 1（应回 01，$D_1=0$）两项都灭 ✓；10 收 0（应去 11，$D_1=1$）第一项亮 ✓。

$D_0$ 的 1 分布在 00 收 1、10 收 0、11 收 1 三格——互不相邻，已是极小和：

$$D_0 = \bar{Q_1}\bar{Q_0}x + Q_1\bar{Q_0}\bar{x} + Q_1Q_0x$$

Mealy 输出只在「S3 且收 1」的瞬间亮：

$$Z = Q_1Q_0x$$

三个方程、十几根门线，检测器就烧好了。这张「转移表 → 卡诺图 → 方程」的流水线，就是第 20、30 课全部技术的合流处——状态图上一次灵光乍现的重叠修正（S3 收 1 回 S1），最终体现为 $D_1$ 里多出的那一项 $\bar{Q_1}Q_0x$。

</details>
