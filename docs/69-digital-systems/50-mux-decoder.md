# 多路选择器与译码器

## 1. 从一个场景开始

电视墙上接了四台游戏机，但投影仪只有一个 HDMI 口——中间那个切换器，按一下按钮，四路画面里恰好一路通到屏幕。单片机的引脚不够用、八块内存芯片挂在同一条总线上、CPU 要在四个寄存器里挑一个送进运算器——**"多选一"和"一选多"是数字系统里出现频率最高的两个动作**。

把它们做成标准零件：多路选择器（MUX）管多选一，译码器（Decoder）管一选多。这一课会看到一件漂亮事：它俩是**同一棵与门树的两半**。

## 2. 直觉解释

**多路选择器**像个旋转开关：N 路数据挤在入口，"选择线"报一个号码，只有那一路的数据能通到出口。2 根选择线可以报 4 个号码（00, 01, 10, 11），所以 2 根线管 4 选 1；3 根线管 8 选 1——选择线的位数 $k$ 与路数 $2^k$ 是指数关系。

**译码器**是反方向：$k$ 位二进制进去，$2^k$ 根输出线里**恰好一根**变高。3 位选择线值 5（`101`），译码器第 5 根输出亮，其余 7 根全灭。这种"一根线代表一个状态"的表示叫**一位热**（one-hot）——查表的时候不用算，看哪根亮就知道是哪个。

它们共享同一个数学零件：**最小项** $m_i$（上一课卡诺图的主角）。译码器的第 $i$ 根输出就是选择线的第 $i$ 个最小项；而 MUX 无非是把这 $2^k$ 个最小项分别跟各路数据相与、再全部或起来。选择不是魔法，是一棵与门树加一个或门。

## 3. 正式定义

设选择线 $S_1 S_0$（高位在前），四选一 MUX 的输出：

$$Y = D_0\,m_0 + D_1\,m_1 + D_2\,m_2 + D_3\,m_3$$

其中最小项 $m_0 = \bar{S_1}\bar{S_0}$，$m_1 = \bar{S_1}S_0$，$m_2 = S_1\bar{S_0}$，$m_3 = S_1 S_0$——任何时候恰好一个为 1。

| 器件 | 输入 | 输出 | 行为 |
| --- | --- | --- | --- |
| MUX（$2^k$ 选 1） | $2^k$ 路数据 + $k$ 位选择线 | 1 根 | $Y = \sum_i D_i \cdot m_i$，第 $S$ 路通 |
| 译码器（$k$ 线入） | $k$ 位选择线 + 使能 EN | $2^k$ 根 | $\mathrm{out}_i = EN \cdot m_i$，恰好一根亮 |
| 使能端 EN | 1 根 | — | 拉低时译码器全线熄灭、MUX 输出恒 0 |

**使能端**看着多余，其实是总线世界的命根子：八块内存芯片的输出并在一起时，靠译码器 + 使能保证**任何时刻只有一块**在说话，其余全部闭嘴（高阻态）——这就是**片选**。

## 4. 分步例题

**例 1**：四选一 MUX，数据 $D = (1, 0, 1, 0)$，选择线 $S_1 S_0 = 10$。求 $Y$。

1. 选择线值 $S_1 S_0 = 10$（十进制 2）；
2. 最小项：$m_2 = S_1\bar{S_0} = 1 \cdot 1 = 1$，其余三个最小项都是 0；
3. 只有第 2 路的门开着：$Y = D_2 = 1$；
4. 核对展开式：$Y = 1\cdot 0 + 0\cdot 0 + 1\cdot 1 + 0\cdot 0 = 1$ ✓。

**例 2**：三线译码器，$S_2 S_1 S_0 = 101$，使能 $EN = 1$。哪根输出亮？

1. $101$ 就是十进制 5；
2. 第 5 个最小项 $m_5 = S_2 \bar{S_1} S_0 = 1 \cdot 0 \cdot 1 = 1$；
3. 输出线 5 亮，0～4 与 6～7 共 7 根全灭。若把 $EN$ 拉低，8 根**全部**熄灭——"这个芯片现在不许说话"。

左边是 4 选 1 MUX，右边是同一组选择线驱动的译码器。读数区实时显示 MUX 输出、译码输出和展开式 $Y = D_0 m_0 + \cdots$。做三件事：

- 拨选择线到 10（点 S 的两位刷出 2），对照例 1 看两边的动作：MUX 放行第 2 路，译码器点亮第 2 根——**同一根选择线，两边同步**；
- 把使能 E 拉低：译码器一根不亮、MUX 输出恒 0——片选的全部含义就在这一下；
- 切到 3 位选择线（8 选 1），点译码器任意一根输出线拖着上下扫，看选择线怎么跟着变。

### 实验 2：自己算（Python）

```python title="3 线译码器：8 根输出，每行恰好一个 1"
for s in range(8):                   # 选择线 000 到 111
    s2, s1, s0 = (s >> 2) & 1, (s >> 1) & 1, s & 1
    out = ""
    for i in range(8):               # 逐根检查输出线
        # 第 i 根 = 与门：S 与 i 的每一位都相同（即 s 的最小项 m_i）
        same = (s2 == ((i >> 2) & 1)) and (s1 == ((i >> 1) & 1)) and (s0 == (i & 1))
        out = out + ("1" if same else "0")
    print(f"S={s2}{s1}{s0} → {out}")
```

八行输出每行恰好一个 1，且 1 的位置就是选择线的值本身——一位热表示"看位置就知道数值"。数一数门：每根输出线一个三输入与门，共 8 个与门；这就是译码器的全部成本，也是它能当"最小项发生器"用的原因（选读）。

### 快问快答

```quiz
一个 8 选 1 的多路选择器需要几根选择线？
- 3 根 [*]
- 8 根
- 2 根
? 2^k ≥ 8 需要 k = 3：选择线的 8 个二进制组合 000–111 恰好一一对应 8 路数据。反过来译码器也是 3 根进 8 根出——指数关系是这两个器件共同的骨架。
```

::::warning[常见误区]

**误区一**："译码器的输出线从 1 号开始编。"
你以为第 1 根线对应第一个状态——编号从 **0** 开始：全 0 的选择线点亮的是 0 号线。差一的错误在内存译码里会让 CPU 读写错位，格外致命。

**误区二**："使能端是可有可无的装饰。"
你以为没有 EN 一样用——多片芯片的数据脚并到同一根总线时，没有使能就会两片同时驱动、电流对撞。EN + 译码器是"任何时刻只允许一人发言"的仲裁硬件。

**误区三**："MUX 只能选数据信号。"
你以为选择线必须配数据线——选择线本身就是二进制数，译码器把它摊成最小项后，MUX 的数据端接上 0/1 常量就能**实现任何逻辑函数**（选读）。它在 FPGA 里有个更响亮的名字：查找表。

::::

## 6. 练习

**练习 1**：两片 4 选 1 MUX 拼成 8 选 1：三位选择线的最高位 S2 当片选（接两片的使能），低两位 S1S0 是片内路号。下面的代码把 S2 扔了，永远只在前四路里挑：

```exercise
# @title: 练习：把片选线接回去
# @check: 1
# @hint: 先用 s // 4 分片（0 → MUX1，1 → MUX2），再用 s % 4 定片内第几路，两段拼回完整地址
d = [1, 0, 1, 0, 0, 1, 1, 0]   # 八路数据：D0–D3 接 MUX1，D4–D7 接 MUX2
s = 5                           # 三位选择线 S2 S1 S0 = 101

sel = s % 4                     # ← 问题在这：只用了低两位，S2 这根片选线被扔了
Y = d[sel]
print(Y)
```

**练习 2**（概念题）：数码管显示数字 3（点亮 a、b、c、d、g 五段，熄灭 e、f）。为什么说驱动它的芯片本质是个译码器？

<details>
<summary>点开查看解答</summary>

BCD 译码器（如经典的 74LS47/48）输入 4 位二进制 0000–1001，输出 7 根线各管一段。它就是 $k=4$ 的译码器 + 每根输出按"哪个数字要点哪些段"定制：比如输入 0011（3）时 a、b、c、d、g 的与门导通。所谓"译码"，广义上就是把紧凑的二进制编码摊开成需要的控制线——内存片选、指令操作码分派（第 140 课）、数码管，全是同一件事的不同接线图。
</details>

## 7. 选读：MUX 是可编程的真值表

<details>
<summary>选读 · 查找表（LUT）思想</summary>

把一个 $n$ 变量函数的真值表接到 $2^n$ 选 1 MUX 的数据端，$n$ 个变量接选择线——选择线的每个组合恰好扫过真值表的一行，MUX 输出的就是那一行的函数值。**任何 $n$ 变量逻辑函数，不用化简、不用画图，接上去就对。**

代价是面积随变量数指数增长，所以工程上取 $n = 4$ 或 6 的"小颗粒"，再用大量 LUT 与连线资源拼出复杂函数——这正是 FPGA 基本单元（LUT，look-up table）的原理。FPGA 之所以"可编程"，根源就是这个上一课卡诺图化简到极致、这一课被 MUX 整包收编的事实：**逻辑函数 = 真值表 = 查表**。第 90 课的状态机会让你看到这些小颗粒怎么长成一台"会记忆"的机器。
</details>
