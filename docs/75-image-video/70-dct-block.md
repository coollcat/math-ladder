# DCT 与 8×8 块：能量集中

## 1. 从一个场景开始

一张 1200 万像素的照片，原始数据约 36 MB；发到朋友圈的那份 JPEG 只有 2 MB——**压缩了 18 倍，看起来却几乎没变**。这不是什么黑魔法，而是一场精确到 8×8 像素小方块里的算术：先把每块拆成"渐变的波"，再发现绝大多数波的分量小到可以直接扔。

扔得下手，靠的是一个惊人的事实：**自然图像的能量，天然挤在极少数系数上。** 这一课就来看这个"能量集中"是怎么发生的、为什么 DCT 是干这活儿的最佳选手。

## 2. 直觉解释

把图像切成 8×8 的小块，随便挑一块看：大概率是**平缓的**——像一段斜坡、一片渐变，最多带一点轻微的起伏。描述一段斜坡需要几个数？起点、坡度，完事。可 64 个像素的"逐像素账本"要记 64 个数。

DCT（离散余弦变换）就是那个换账本的人：它准备了一组 64 个 8×8 的**基图案**——全平、水平渐变、竖直渐变、各种粗细的波纹与格子（61 章 85 课见过它们的一维版本）。任何一块图像都能用这 64 个图案加权拼出来，权重就是 64 个 **DCT 系数**。

换账本本身一份数据也不省——省的是接下来的发现：**典型图像块里，代表"平缓成分"的左上角低频系数又大又多，代表"细密波纹"的右下角高频系数接近零**。把它们扔掉，重建出来的块肉眼看不出差别。这就是能量集中，是 JPEG 敢扔高频的全部底气。

你可能会问：上一课的 DFT 也是换基图案，为什么不用 DFT？关键在**边界**。DFT 假设信号周期延拓，块的首尾接不上就在边界猛跳一下，能量被迫漏进高频去"填那个坑"。DCT 假设块外是自己的**镜像**——首尾天然平滑接续，能量乖乖待在低频。数学上能证明：对高度相关的图像数据，DCT 的能量集中度几乎是最优的。

## 3. 正式定义

一维 8 点 DCT-II（正交归一版）：

$$C[u] = \alpha(u) \sum_{n=0}^{7} x[n] \cos\!\left(\frac{(2n+1)u\pi}{16}\right), \qquad \alpha(0) = \sqrt{\tfrac{1}{8}},\ \alpha(u{>}0) = \tfrac{1}{2}$$

二维版本就是对每行每列各做一遍（与上一课的 DFT 同款"先行后列"，把复指数换成余弦）。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $x[n]$ | 像素行 | 一条 8 点的信号（块的一行或一列） |
| $C[u]$ | DCT 系数 | 第 $u$ 号基波的权重；$u$ 越大频率越高 |
| $C[0]$ | 直流系数 | $\sqrt{8} \times$ 平均值——整块的"平均亮度" |
| $C[u], u{>}0$ | 交流系数 | 各号波纹的幅度，可正可负 |

**正交性**（能量守恒）：这套余弦基两两垂直，于是

$$\sum_{n=0}^{7} x[n]^2 \;=\; \sum_{u=0}^{7} C[u]^2$$

变换前后总能量一分不少——所以"前几个系数占的能量百分比"才有明确的含义：**那就是保留它们能还原出的信息份额**。

二维的 64 个系数排成 8×8 表：左上角 $C[0][0]$ 是直流，往右下频率越高。**Zigzag 扫描**（之字形从左上走到右下）把系数按"大概率先大后小"排成一串，后面的自然是小虾米——这是 JPEG 流程的读法。

## 4. 分步例题

**例**：一块纯平的图像行 $x = [64, 64, 64, 64, 64, 64, 64, 64]$。求它的 DCT。

1. **直流**：$C[0] = \sqrt{1/8} \times 8 \times 64 = 64\sqrt{8} \approx 181.0$——它就是"平均亮度 64"的另一种写法；
2. **交流**：$C[u] = \frac{1}{2} \cdot 64 \sum_{n} \cos\!\left(\frac{(2n+1)u\pi}{16}\right)$。这 8 个余弦的相位在半圆上均匀分布，$u = 1,\dots,7$ 时**和恰好为零**（想象 8 根均匀旋转的向量合力为零）；
3. **结论**：64 个像素 → 1 个非零系数。存这块图像只需存一个数——**变换没有压缩任何东西，但它把"没有信息"变得一眼可见**。真实的图像块不会这么干净，但方向一致：能量永远向左上角坍缩。

- 切到**整图**：全图逐块走流程，质量调低后块与块的接缝（方块效应）浮出水面。

### 实验 2（python）：一块斜坡的 8 个系数

```python
import math  # cos/sin/sqrt：DCT 核（61 章已引入）

def dct8(x):                        # 8 点 DCT-II（正交归一版）
    out = []
    for u in range(8):
        a = math.sqrt(1 / 8) if u == 0 else 0.5
        s = sum(x[n] * math.cos((2 * n + 1) * u * math.pi / 16) for n in range(8))
        out.append(a * s)
    return out

ramp = [128 + 8 * n for n in range(8)]      # 一块平缓的斜坡：128,136,...,184
C = dct8(ramp)

for u in range(8):
    print(f"|C({u})| = {abs(C[u]):7.1f}")

E = [c * c for c in C]
total = sum(E)
print(f"直流 C(0) 一家占总能量 {E[0] / total * 100:.1f}%")
```

八个系数里，偶数号全是 0（斜坡的对称部分只有"平均"那一项），奇数号也迅速衰减：51.5 → 5.4 → 1.6 → 0.4。**一个直流系数独占 98.6% 的能量**——这段斜坡用"平均值 + 一点点坡度"就能几乎完整地写出来。真实的图像块没这么纯净，但坍缩的方向分毫不差（练习 1 用真实数据验证）。

::::warning[常见误区]

**误区一**："DCT 压缩了图像。"
你以为变换本身减小了数据——DCT 是**可逆的换基**，64 个系数换 64 个像素，一个字节都不省。压缩发生在**之后的量化与丢弃**；DCT 的功劳只是把"谁不重要"排得明明白白。

**误区二**："能量集中是 DCT 发明的性质。"
你以为换了基能量就会集中——能量集中是**自然图像自身的相关性**（相邻像素都长得像）带来的；DFT、DCT、小波都在利用它，DCT 只是因为镜像延拓让边界不跳、漏进高频的能量最少，才成了 8×8 块的最佳选手。

**误区三**："块切得越大越好。"
你以为 16×16 或 64×64 能更充分地利用相关性——块越大，块内"平缓"的假设越容易破产（一块里既有天空又有树枝），而且边界的人工痕迹（方块效应）会连成更大的格子。8×8 是 1990 年代算力与视觉质量的折中，此后 30 年没换过。

::::

## 6. 练习

**练习 1**：下面是一块真实的图像数据（平缓为主、带一点纹理）。它的 DCT 系数中，前 3 个（$u=0,1,2$）攥住了总能量百分之多少？修好代码里的能量算法：

```exercise
# @title: 练习：一块真实图像的能量分布
# @check: 99.0
# @hint: 正交变换能量守恒：能量 = 系数的平方。|C| 只是幅度，不是能量——把 abs 换成平方再求和。
import math

def dct8(x):
    out = []
    for u in range(8):
        a = math.sqrt(1 / 8) if u == 0 else 0.5
        s = sum(x[n] * math.cos((2 * n + 1) * u * math.pi / 16) for n in range(8))
        out.append(a * s)
    return out

block = [52, 55, 61, 59, 79, 61, 76, 61]     # 一块真实的图像数据
C = dct8(block)

energy3 = sum(abs(C[u]) for u in range(3))           # ← 问题在这：|C| 不是能量
energy_all = sum(abs(C[u]) for u in range(8))
print(f"{energy3 / energy_all * 100:.1f}")           # 87.6——低估了集中程度
```

**练习 2**：8×8 块共有 64 个基图案。不写代码回答：(a) 直流基图案长什么样？(b) 只保留直流系数，重建出的块是什么？(c) 为什么 $k=1$ 的重建永远是一块纯色？

<details>
<summary>点开查看逐步解答</summary>

1. (a) 直流基是全 64 格等亮的平板——它对应"平均亮度"，不随位置变化；
2. (b) 只有直流时，重建 = 平均值铺满整块（实验 1 里 $k=1$ 的那坨纯色）；
3. (c) 直流系数只携带"平均"这一个自由度，其余 63 个自由度（波纹、边缘、纹理）全在交流系数里，一个不留就全丢。

**深一层**：64 个基图案两两垂直，意味着它们是这 64 维空间的一组坐标轴——像素坐标和 DCT 坐标只是**同一块数据的两套记账法**。"能量集中"说的是：在这套新坐标下，图像的点的位置离"平均"这根轴近、离高频那些轴远。

</details>

## 7. 选读：DCT 为什么比 DFT 更会攒能量

<details>
<summary>选读 · 镜像延拓与边界连续</summary>

对一段 8 点信号做 8 点 DFT，等于假设它周期延拓：信号首尾相接。若 $x[0] \ne x[7]$，接缝处跳变——而跳变在频域意味着**所有频率都要出力**（16 章讲过：方波的谱拖着一根缓慢衰减的尾巴）。能量就这样被人为灌进了高频。

DCT-II 的等价看法是：先把信号镜像成 16 点——$x[0],\dots,x[7],x[7],\dots,x[0]$——再做 16 点 DFT。镜像保证首尾衔接处零跳变，偶对称还让虚部全部抵消，剩下的 8 个独立实系数就是 DCT。边界平滑 → 谱尾收得快 → 能量更挤。

代价与回报：DCT 没有相位信息（不合适做旋转平移分析），但**对"局部平缓"的图像块，它是 K-L 变换（理论最优）的最好实数近似**——Natarajan 与 Ahmed 1974 年的这一发现，十年后长成了 JPEG。

另一个常被问到的点：既然块间不重叠，为什么 JPEG 不用更平滑的重叠变换？答案是兼容性与算力——8×8 独立块可以逐块流水线处理，1991 年的 DSP 芯片算得动；重叠变换（如现代 AV1 用的）要等到算力便宜了才轮得上。

</details>
