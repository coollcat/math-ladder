# 采样与量化：分辨率的两副面孔

## 1. 从一个场景开始

用手机拍电脑屏幕，照片上浮出一圈圈好看的波纹——屏幕上明明没有，是照片"长"出来的。另一天你把一张照片的对比度拉到极限，天空的平滑渐变里浮出一圈一圈的"年轮"。

两种毛病来自两个不同的环节：波纹是**采样**出的错，年轮是**量化**出的错。把数字图像从连续世界搬进表格要过这两道关卡，每道关卡都有自己的失真方式。

## 2. 直觉解释

61 章讲过：把连续的时间信号变成数字序列，要按固定间隔**打点**（采样），打点太稀就会把高频信号冒充成低频（混叠）。空间上的图像一模一样——只是"时间轴"换成了 $x$ 和 $y$ 两个方向：

- **空间采样**：决定网格打多密，即分辨率。打得太稀，规则纹理（栅栏、棋盘、布料）会冒充出原来没有的条纹——**摩尔纹**，就是时间域混叠的空间版；
- **幅度量化**：每个采样点的灰度要归到有限档位。档位太少，原本平滑的渐变会出现一圈圈假边界——**假轮廓**。

一句话：**采样管"格子有多密"，量化管"每格的数有多细"**。两副面孔合起来才是一张数字图的全部分辨率。

## 3. 正式定义

**空间采样**：从连续图像 $I(x, y)$ 每隔 $s$ 个单位取一个样本：

$$f[i, j] = I(i \cdot s,\ j \cdot s), \qquad 0 \le i < W,\ 0 \le j < H$$

**量化**：把连续灰度 $v \in [0, 1]$ 归到 $L$ 个档位之一，$\tilde{v} = \dfrac{\mathrm{round}(v \cdot (L-1))}{L-1}$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $s$ | 采样步长 | 步长越大，分辨率越低；取样相位不同，摩尔纹位置不同 |
| $L$ | 量化级数 | 只能取 $2^b$，如 256 级、16 级、4 级 |
| $b$ | 位深 | 每像素用的比特数，$b = \log_2 L$；8 位 = 256 级 |
| 字节数 | 存储代价 | $W \times H \times b / 8$；千万像素 8 位灰度约 10 MB |
| 混叠 | 采样的失真 | 高频纹理冒充低频条纹，拍出来就是摩尔纹 |
| 假轮廓 | 量化的失真 | 平滑渐变被切成台阶，浮出假边界 |

**61 章的采样定理在空间域照常成立**：想不混叠，采样频率必须高于图像最高空间频率的两倍。相机做不到时，工程手段是**先模糊再采样**（低通滤波），把高频先砍掉——手机相机里那层"光学低通滤镜"就是干这个的。

## 4. 分步例题

**例**：估算一张 1200 万像素、8 位灰度照片的存储量。

1. **采样数**：$W \times H = 12{,}000{,}000$ 个像素；
2. **每样本比特**：8 位灰度 → 每像素 $b = 8$ 比特；
3. **总比特**：$12{,}000{,}000 \times 8 = 96{,}000{,}000$ 比特；
4. **换算字节**：$96{,}000{,}000 / 8 = 12{,}000{,}000$ 字节，约 12 MB；
5. **推广**：彩色图 RGB 三通道各 8 位，每像素 24 比特，存储量翻三倍到 36 MB——这就是为什么相机必须先压缩再存 JPEG。

注意两步各自独立：把分辨率砍半（采样变稀），字节数除以 4（横竖各砍半）；把位深从 8 降到 4，字节数只除以 2。**空间换算按平方、幅度换算按线性**，这是估算时最容易搞错的差别。

## 5. 动手实验

### 实验 1（lab）：混叠与假轮廓，各归各管

```lab
{
  "type": "sampling-quantize",
  "title": "把空间分辨率和灰度级数分开看",
  "src": "scene",
  "step": 4,
  "levels": 8
}
```

上半行管采样：每隔 step 个像素取一点再放大回去。把取样相位左右拖——栅栏和棋盘上那些假条纹会**游走**，这就是摩尔纹随相位变化的现场；打开"抗混叠"开关（先模糊再取样），假纹消失、整体变糊——**先限带、后采样**的代价。下半行管量化：把灰度级数往下拖到 4，天空渐变里浮出一圈圈假轮廓，直方图塌成几根尖峰。

### 实验 2（python）：亲手量化一遍

```python title="把连续灰度归到 4 级，看看丢了什么"
def quant(v, levels):                # 把 0–255 的灰度归到 levels 级
    q = round(v * (levels - 1) / 255)   # 先映射到 0..levels-1 档
    return q * 255 // (levels - 1)      # 再映射回 0–255 的档位中心

for v in [10, 30, 64, 90, 120, 200]:
    print(v, "→", quant(v, 4))
```

六个输入里 10 和 30 落进同一档（都变 0），64、90、120 落进同一档（都变 85），只有 200 独占一档（170）。原本相差 90 的两个灰度量化后可能完全相同——**量化的本质是给"误差小于半档"发免死金牌**。级数拉回 256 再跑一遍，所有值原样返回：8 位深对 0–255 的灰度是"无损"的。

::::warning[常见误区]

**误区一**："分辨率越高，图一定越清晰。"
你以为堆像素万能——其实超过镜头光学分辨率之后，更多像素只是把同一片模糊放大得更细。真正决定"能看清多细的纹理"的是整条链路：镜头、抗混叠滤镜、传感器、显示，缺哪环哪环是瓶颈。

**误区二**："量化级数越多一定越好。"
你以为 16 位一定比 8 位好——其实人眼在正常观看条件下能分辨的灰度大约几百级，8 位往往已经够用。多出的位数要么白占存储，要么留给专业场合（暗部后期的余量）。量化级数的选择是**取舍**，不是军备竞赛。

**误区三**："摩尔纹是设备故障，修修就好。"
你以为波纹是镜头脏了或坏了——其实它是采样不足的**数学必然**，只要被拍纹理的空间频率超过采样极限就会出现。对付它的办法只有三类：让纹理更糊（抗混叠）、采样更密（高分辨率）、事后用算法压纹——没有"修好"一说。

::::

**练习 2**：一张 $512 \times 512$ 的图用 4 位深存储。(a) 总字节数？(b) 与 8 位深版本相比省了百分之几？(c) 4 位深的渐变会不会出假轮廓？

<details>
<summary>点开查看逐步解答</summary>

1. 每像素 4 比特，总数 $512 \times 512 \times 4 = 1{,}048{,}576$ 比特，除以 8 得 **131072 字节**（128 KB）；
2. 8 位版本是 $512 \times 512 = 262{,}144$ 字节（256 KB），4 位版正好省 **50%**——位深减半，存储线性减半；
3. 16 级灰度对平滑渐变（如天空、皮肤）**会**出明显的假轮廓：相邻档位差 $255/15 = 17$，人眼能察觉约 1–2 个灰度级的跳变，17 级一跳必然被看见。

所以 4 位深只适合灰度层次简单的图形（线稿、二维码），不适合照片——JPEG 舍弃色度精度时也是同一道算术。

</details>

## 7. 选读：空间频率与二维采样定理

<details>
<summary>选读 · 混叠把多高的频率冒充成多低</summary>

一维采样定理（61 章）：以 $f_s$ 采样时，频率高于 $f_s/2$ 的成分会折叠到 $|f - k f_s|$ 的低频位置上冒充自己。空间域把 $f$ 换成**空间频率**（每毫米多少条线，单位 lp/mm），定理逐字成立，只是 $x$ 和 $y$ 两个方向各管各的：

$$f_{\text{假}} = |f_{\text{真}} - k \cdot f_s| \qquad (k \text{ 取使结果落在 } [0, f_s/2] \text{ 的整数})$$

摩尔纹之所以"游走"，就是因为 $f_{\text{假}}$ 随采样相位与角度连续变化；摩尔纹之所以常带**彩色**，是因为红绿蓝子像素网格的周期略不同，三个通道折叠出的假纹频率错开了一点。二维与一维唯一的本质区别是：空间频率有**方向**，斜向纹理的折叠路径更花——这也是布料照片上的摩尔纹总呈放射状或彩色的原因。

</details>
