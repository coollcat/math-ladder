# 视频是图像序列：帧率

## 1. 从一个场景开始

老电影里马车启动的瞬间，车轮突然开始**倒转**；直升机纪录片里，旋翼有时慢得像静止。车轮明明一路向前，银幕上却往回滚——不是胶片剪错了，是你的眼睛被**采样**骗了。

视频不是连续的运动，是每秒 24 张静止照片的快速连放。只要你把"视频是图像序列"这句话当真，那 61 章采样定理的全部结论就原封不动地搬了过来——这一次，采样的对象是**时间**。

## 2. 直觉解释

声音采样：每隔 $1/f_s$ 秒记一个气压值，连起来播放。视频采样：每隔 $1/f_s$ 秒记一张照片，连起来播放。**帧率 $f_s$ 就是时间轴上的采样率**，每帧照片就是一个采样点。

61 章的核心结论立刻生效：想如实还原以频率 $f$ 变化的运动，帧率必须**超过两倍的 $f$**（奈奎斯特判据）。人眼能把 10~12 Hz 以上的离散画面融合成连续运动（视觉暂留），所以 24 fps 足够"看起来在动"；但 24 fps 只能如实记录**每秒变化不超过 12 次**的运动。转得太快的车轮、扇叶、螺旋桨——超过 12 圈/秒的部分，采样点根本"跟不上趟"，重建出来的运动就成了冒牌货：倒转、慢转，甚至纹丝不动。

这个冒牌货有专门的名字：**车轮倒转错觉**（wagon-wheel illusion）。它不是眼睛的错觉，是数学的必然——两帧之间车轮转了 300°，你的视觉系统把它读成转了 −60°，因为 300° 和 −60° 在离散采样下**长得一模一样**。

## 3. 正式定义

设运动以频率 $f$（周期/秒）变化，帧率为 $f_s$：

$$\text{奈奎斯特条件：} f < \frac{f_s}{2} \quad\Longrightarrow\quad \text{如实还原；超出的频率折回（混叠）：} \quad f_{\text{alias}} = \left(\left(f + \tfrac{f_s}{2}\right) \bmod f_s\right) - \tfrac{f_s}{2}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f_s$ | 帧率 | 每秒采多少帧：24（电影）/ 30、60（电视与游戏）/ 120（高刷屏） |
| $f_s/2$ | 奈奎斯特频率 | 帧率能如实记录的最快变化，24 fps → 12 次/秒 |
| $f$ | 运动频率 | 物体每秒重复多少个周期（旋转用圈/秒） |
| $f_{\text{alias}}$ | 混叠频率 | 折回 $\pm f_s/2$ 视界内的冒牌频率，负号 = 倒转 |

折叠公式的读法：先把 $f$ 加上半个采样率，对 $f_s$ 取余，再减回半个采样率——保证结果落在 $[-f_s/2, +f_s/2]$ 里。**符号为负就是倒转**：屏幕上"看起来倒转的圈速" $= |f_{\text{alias}}|$。

常见帧率的取舍一览：24 fps 是电影传统（胶片成本与"电影感"的折中）；30/60 fps 是电视与视频的标准；游戏追求 120 fps 以上，不只是流畅——低帧率下混叠还会让高速旋转的物体凭空变形。

## 4. 分步例题

**例**：车轮每秒转 20 圈，摄影机 24 fps 拍摄。银幕上的车轮怎么动？

1. **判据**：奈奎斯特频率 $= 24/2 = 12$ 圈/秒，而 $20 > 12$——如实还原失败，必有混叠；
2. **折叠**：$f_{\text{alias}} = ((20 + 12) \bmod 24) - 12 = 8 - 12 = -4$ 圈/秒；
3. **逐采样核对**：相邻两帧间隔 $1/24$ 秒，车轮转了 $20/24$ 圈 $= 300°$。而 $300° \equiv -60°$——采到的相位与"倒转 $60°$"完全相同；
4. **结论**：倒转 $60°$ 每帧 = 每秒倒转 $4$ 圈。**|−4| 就是观众看到的倒转速**。

### 实验 2（python）：一张折叠速查表

```python
fs = 24.0                     # 摄影机每秒 24 帧

def alias(f):                 # 折叠：把真实频率折回 ±fs/2 的"视界"内
    return (f + fs / 2) % fs - fs / 2

print("转速(圈/秒)   看起来")
for f in [6.0, 10.0, 14.0, 20.0, 30.0]:
    a = alias(f)
    print(f"{f:6.1f}      {abs(a):4.1f} 圈/秒 {'倒转' if a < 0 else '正转'}")
```

五行读出一个规律：**6 和 10 在 12 以内，安然无恙；14 和 20 超界，折回来变成 10 和 4，方向取负——倒转；30 更狠，折了整整一圈（24），剩 6 圈/秒正转**。同一辆车上三个轮子若转速不同，可以在同一帧画面里一个正转、一个倒转、一个静止——这不是特效，是折叠公式的三行输出。

::::warning[常见误区]

**误区一**："车轮倒转是人眼的错觉，问题出在眼睛。"
你以为该去研究视觉心理学——方向反了：这是**采样**的数学必然，摄影机只对"每 1/24 秒的相位快照"负责，而 300° 与 −60° 的快照完全相同。人眼直接看真实车轮（连续光）时确实也会偶发倒转错觉，但那是另一套机制；**录像里的倒转 100% 可以用折叠公式算出来**。

**误区二**："帧率越高一定越好。"
你以为 120 fps 全面碾压 24 fps——分辨力、流畅度确实随帧率上升，但 24 fps 的**快门模糊**让运动带上自然拖影，看久了反而"像电影"；60 fps 的锐利逐帧有时被观众形容为"像电视剧"。帧率是艺术风格参数，不只是技术指标（选读里算快门角）。

**误区三**："每帧画面清晰，视频就清晰。"
你以为逐帧检查都行——视频的病是**时间维**的：每帧都完美锐利、但帧率不足时，旋转与快速平移照样混叠变形。检查视频质量必须"播放着看"，逐帧看反而什么都发现不了。

::::

```exercise

# @check: 4.0

f = 20.0      # 车轮每秒转 20 圈
fs = 24.0     # 摄影机每秒拍 24 帧

alias = abs(f % fs)       # ← 问题在这：取余不等于折叠
print(alias)              # 输出 20.0，好像没混叠似的
```

**练习 2**：回答三问：(a) 60 fps 的游戏画面能如实显示每秒多少次的重复运动？(b) 24 fps 下车轮"看起来静止"对应的真实转速有哪些？(c) 为什么风扇调到某几档时，扇叶看着像停了？

<details>
<summary>点开查看逐步解答</summary>

1. (a) 奈奎斯特判据 $f < 30$ 次/秒；
2. (b) 视在频率为 0 ⟺ 折叠结果为 0 ⟺ $f$ 是 24 的整数倍：24、48、72…圈/秒（每帧转整圈，相位快照全部相同）；
3. (c) 家用风扇扇叶每秒几十转，恰落在市电拍摄（25/30 fps）的整倍数附近——每帧拍到几乎相同的相位，扇叶"冻结"。手机拍风扇偶尔"慢转"，是真实转速与整倍数略差一点、折叠后剩一个小频差。

**工程视角**：摄影师遇到旋转物体，优先**改快门**（加运动模糊掩盖混叠）或**换帧率**，而不是后期修复——混叠发生时信息在采样瞬间就已损失，事后无解。这与 61 章"抗混叠滤波要在采样前做"是同一条铁律的时间维版本。

</details>

## 7. 选读：快门角——帧率的另一半真相

<details>
<summary>选读 · 180° 快门与"电影感"的算术</summary>

帧率之外，每帧还有第二个时间参数：**快门开多久**。机械摄影机是旋转的遮光板（快门角），180° 意味着每帧周期里一半时间曝光、一半时间遮挡。24 fps + 180° 快门 → 每帧曝光 $1/48$ 秒。

这 $1/48$ 秒里物体还在动，于是每帧带一点**运动模糊**。快速运动物体的边缘在单帧里拖出 1~2 像素的影——单看是"糊"，连起来看，视觉系统把它解读成流畅的运动。这就是"24 fps 的电影感"的物理成分：不是帧率本身玄妙，是**帧率与快门角的组合**给出的模糊量恰好落在人眼舒适的区间。

数字化时代这条经验被换算成口诀：**快门速度 ≈ 2 × 帧间隔**（24 fps → 1/48 s，60 fps → 1/120 s）。游戏引擎里的"运动模糊"特效、视频 24 fps 转高刷时的插帧算法，都在努力伪造这层时间维的模糊——没有它，逐帧锐利的画面反而显得"数字味"。

反过来，高速摄影（1000 fps 起）必须用极短快门，每帧都近乎冻结——慢放时自然流畅，实放时却毫无模糊感、"太清楚而假"。模糊与清晰在时间维上是一对取舍，永远没有两头全占的设定。

</details>
