# 量化矩阵与 JPEG 取舍

## 1. 从一个场景开始

手机相册里把"画质"从 100% 拖到 10%，文件小了一个数量级；拖到 5%，照片上开始浮出一层若隐若现的方格，硬边旁边还爬着一圈水波。画质滑杆背后没有魔法，只有**一个 8×8 的数字表**在决定每个频率"除以几"。

上一课你看到能量挤在低频——那是"可以扔"的资格。这一课讲"怎么扔"：量化是 JPEG 流程里**唯一真正丢数据**的一步，而那张量化矩阵，其实是把人眼的工作特性翻译成了算术。

## 2. 直觉解释

DCT 把 8×8 块换成 64 个系数后，JPEG 对每个系数做一件粗暴的事：**除以一个步长，再取整**。步长是 1，几乎无损；步长是 100，比 50 小的系数统统归零。

步长该多大？问人眼：

- 对**低频**（大块的明暗、形状）——眼睛非常挑剔，除狠了立刻看出来，步长要小；
- 对**高频**（细密纹理、边缘细节）——眼睛相当迟钝，尤其是边上还爬着"振铃"也看不清，步长可以很大。

把 64 个步长写成一张表——**量化矩阵**：左上角数字小（低频精确保留），右下角数字大（高频批量归零）。这张表不是拍脑袋，是 1990 年代用大量人眼实验调出来的经验曲线。**质量因子**（就是相册里那个滑杆）则负责整体缩放这张表：质量高 → 表整体变小 → 保留得多；质量低 → 表膨胀 → 高频成片归零。

扔掉的信息去哪了？回不来了——取整是单向门。重建时把量化后的整数**乘回**步长，得到的是"格点上的最近值"，与原系数差的那一点就是永久损伤。损伤集中在哪、长什么样，实验里一眼可见。

## 3. 正式定义

**量化**：对每个 DCT 系数，

$$\hat C[u][v] = \mathrm{round}\!\left(\frac{C[u][v]}{Q[u][v]}\right), \qquad \text{重建：} C^*[u][v] = \hat C[u][v] \cdot Q[u][v]$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $C[u][v]$ | DCT 系数 | 上一课的产出，实数 |
| $Q[u][v]$ | 量化矩阵 | 8×8 步长表：左上小、右下大 |
| $\hat C[u][v]$ | 量化系数 | 整数——之后做熵编码的就是它 |
| $C^*[u][v]$ | 重建系数 | $\hat C$ 乘回步长，带量化误差 |

**质量因子**（JPEG 标准的缩放规则）：

$$S = \begin{cases} 5000/q, & q < 50 \\ 200 - 2q, & q \ge 50 \end{cases}, \qquad Q_{\text{实际}} = \mathrm{clamp}\!\left(\left\lfloor \frac{Q_{\text{基表}} \cdot S + 50}{100} \right\rfloor,\ 1,\ 255\right)$$

$q = 50$ 时表原样使用，$q \to 100$ 时全表趋近 1，$q \to 1$ 时全表顶到 255。

**保真度怎么量**——峰值信噪比 PSNR：

$$\mathrm{MSE} = \frac{1}{N}\sum_k (x_k - x_k^*)^2, \qquad \mathrm{PSNR} = 10 \log_{10}\!\left(\frac{255^2}{\mathrm{MSE}}\right)\ \text{dB}$$

255 是 8 位灰度的最大值；PSNR 每高 3 dB 意味着误差能量减半。它是粗糙的指标（它不懂人眼），但胜在客观、好算，工程上人手一个。

## 4. 分步例题

**例**：某系数 $C = 50$，落在步长 $q = 16$ 的量化格里。求量化结果、重建值与误差，并估算这一步长下的整体 PSNR。

1. **量化**：$50 / 16 = 3.125$，取整 → $\hat C = 3$；
2. **重建**：$3 \times 16 = 48$，误差 $|50 - 48| = 2$——系数被吸到了最近的格点上；
3. **整体误差**：系数若均匀分布，误差均匀落在 $\pm q/2 = \pm 8$ 之间（区间宽为 $q$），平均平方误差是这个区间的方差：$\mathrm{MSE} = \dfrac{q^2}{12} = 21.3$；
4. **PSNR**：$10 \log_{10}(255^2 / 21.3) = 34.8$ dB——对肉眼来说"挺好但可察觉"的水平；
5. **直觉核对**：步长翻倍到 32，MSE 变 4 倍，PSNR 掉 6 dB。**画质滑杆的每一格，背后都是这条 6 dB 规律。**

## 5. 动手实验

### 实验 1（lab）：质量因子滑杆就是这张表的总开关

```lab
{
  "type": "jpeg-quant",
  "title": "把质量因子往下拖：看系数怎么成片归零、块效应怎么长出来",
  "quality": 35,
  "view": "rec"
}
```

- 拖**质量因子**滑块（2–98）：下排右边的 8×8 量化网格里，`·`（零）从右下角向左上角推进——高频先死，直流活到最后；
- 在原图上**拖动**换块：平缓块的 · 多、纹理块的 · 少——同一张表，不同块死伤悬殊；
- 中间图切到**误差 ×4**：量化误差不是均匀的白噪，它贴着边缘和纹理走——高频被抹掉的地方，误差就是高频；
- 质量拖到 10 以下看两件"遗物"：**块效应**（8×8 方格，块间步长不连续所致）与**振铃**（硬边旁的水波，正是边缘那条方波谱的高频尾巴被砍断的表现——16 章的吉布斯现象在图像里借尸还魂）。

### 实验 2（python）：步长翻倍 = 掉 6 dB

```python
import math  # log10：算 PSNR（第 03 章已引入）

print(" 步长 q    MSE    PSNR")
for q in [4, 8, 16, 32, 64]:
    mse = q * q / 12                        # 均匀量化误差的方差
    psnr = 10 * math.log10(255 ** 2 / mse)
    print(f"{q:5}  {mse:6.1f}  {psnr:5.1f} dB")
```

五档步长，PSNR 从 46.9 dB 一路滑到 22.8 dB，而且**相邻两档永远差约 6 dB**——MSE 随 $q^2$ 增长，而 10·log₁₀(4) = 6.02。这条"6 dB 规律"是量化世界里最实用的心算：想在文件大小与画质之间挪一步，先想清楚步长该翻倍还是减半。也注意 MSE 单独一行：$q^2/12$ 只依赖步长，与图像内容无关——但**你能不能看出**误差，高度依赖内容（平坦区 22.8 dB 一眼假，草丛里同误差毫无破绽）。

::::warning[常见误区]

**误区一**："量化矩阵是数学推导出来的最优解。"
你以为表里那些数字有解析公式——它们是 1990 年代**人眼实验**调出来的经验值（ISO 标准里的 Annex K，"建议值"）。人眼对比敏感度曲线（73 章等响曲线的视觉表亲）是它的物理底色，但每个编码器都在偷偷微调自己的表。

**误区二**："PSNR 高 = 看起来好。"
你以为 35 dB 一定比 33 dB 好看——PSNR 逐像素算平方误差，完全不懂人眼"对结构敏感、对均匀误差迟钝"的脾气。一张 PSNR 更高但方块效应明显的图，观感可以远差于 PSNR 略低的图。学界为此发明了 SSIM 等感知指标，但 PSNR 因简单仍在工程里无处不在。

**误区三**："取整那一点点误差无所谓。"
你以为 round 最多差 0.5，乘回步长也才差 q/2——对单个系数没错，但注意**零是个特别大的格点**：高频步长大（比如 56），凡 |C| < 28 的系数统统归零。量化的主要产物不是"每个系数歪一点"，而是**高频系数整批阵亡**——块效应和振铃都是这场集体阵亡的遗像。

::::

## 6. 练习

**练习 1**：8 位灰度图在步长 $q = 16$ 的均匀量化下，PSNR 是多少？修好代码：

```exercise
# @title: 练习：量化步长与信噪比
# @check: 34.8
# @hint: 误差均匀分布在 ±q/2（区间宽是 q），平均平方误差是这个区间的方差 q²/12。检查你的 mse 是不是把平方弄丢了。
import math

q = 16                                # 量化步长（灰度级）

mse = q / 12                          # ← 问题在这：误差的"平方平均"不是 q/12
psnr = 10 * math.log10(255 ** 2 / mse)
print(f"{psnr:.1f}")                  # 46.9 dB——高得离谱
```

**练习 2**：量化矩阵左上角 $Q[0][0]$ 几乎总是 16（基表），而 $Q[7][7]$ 是 121。回答：(a) 直流系数为什么必须精确保留？(b) 一个 8×8 块经量化后只剩直流非零，它重建出来是什么样？(c) 整幅图都这样会看到什么？

<details>
<summary>点开查看逐步解答</summary>

1. (a) 直流是块的平均亮度。人眼对低频最敏感，且一个直流错 16 会让整块 64 像素集体偏亮/偏暗——64 个像素分摊它的罪证，无处遁形；
2. (b) 乘回步长后是一块**纯色平块**（直流铺满 8×8），所有交流细节清零；
3. (c) 每块都被压成 8×8 的纯色瓷砖，整幅图像马赛克——这正是极端压缩下"块效应"的机制：**不是图像变模糊了，而是图像变成了 8×8 的拼图**。

**顺带算一笔账**：只剩直流非零时，每块要存的是"1 个量化直流 + 63 个零"。63 个零太浪费，JPEG 用 Zigzag + 行程编码把它们压成"跳 63"一个符号——这就是 40 章熵编码的用武之地：量化造出大量的零，熵编码负责把零打包得又短又便宜。

</details>

## 7. 选读：误差的方差为什么是 q²/12

<details>
<summary>选读 · 从均匀分布推 MSE，以及 JPEG 之外的取舍</summary>

设系数真实值在量化格里均匀分布，重建值取格点中心，则误差 $e$ 均匀分布在 $[-q/2, +q/2]$。均匀分布的方差为

$$\mathrm{Var}(e) = \int_{-q/2}^{q/2} e^2 \cdot \frac{1}{q}\, de = \frac{1}{q} \cdot \frac{e^3}{3}\Big|_{-q/2}^{q/2} = \frac{q^2}{12}$$

这就是 MSE = $q^2/12$ 的来历——与 69 章 10 课"量化误差功率 $\Delta^2/12$"完全同款。它假设了两件事：系数在格内均匀、格与格之间误差独立。平坦区域里系数挤在 0 附近，实际误差更小；所以 $q^2/12$ 是保守（偏高）的估计。

率失真的眼光看整件事：量化是拿**失真 D ≈ q²/12** 换**码率 R**——高频归零后行程与熵编码的输出大幅缩短。熵与无损编码下界（第 40 章）是率失真的无损特例；有损版 R(D) 本体不在本书路线内，记住"失真越大、码率下限越低"的方向即可。JPEG 的画质滑杆就是在率失真曲线上滑动，而 75 章末尾的码率控制课会把这条曲线正式画出来：那里你会看到，视频编码器每秒都在做 JPEG 在这个滑杆上做的事——只是它根据画面复杂度**逐块自动选 q**，不再劳驾人手。

</details>
