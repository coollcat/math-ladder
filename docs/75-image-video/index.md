# 图像与视频

把 20 章"多元函数"那张曲面图竖起来对准眼睛，它就是一张灰度图。这一章的全部内容都从这一个视角出发：图像是 $z = f(x, y)$，视频是再加一维时间 $f(x, y, t)$。于是梯度变成边缘、卷积变成模糊与锐化、傅里叶变成频谱压制、采样定理变成分辨率与帧率——前面六十五章的每一件工具都在像素世界里找到了第二份工作。而 JPEG 与视频编码，则是信息论（40 章）最成功的落地。

## 方法主线

**函数 → 采样 → 变换 → 编码 → 序列。**

前三课确立"图像是离散的二元函数"与"人眼是不均匀的传感器"；四十到五十课是空间域分析：卷积与梯度这对搭档包办了绝大多数传统滤镜；六十到八十课转入变换域：二维傅里叶给视角，DCT 给能量集中，量化矩阵给"按人眼扔信息"的执行细则；九十到一百四十课加上时间轴：帧率是时间采样，帧间预测把"时间冗余"变成码率，GOP 与率失真把整个编码问题写成一道优化题。

## 实战挑战 · 4:2:0 省下了一半

1920×1080 的视频，YUV 4:4:4 每像素 3 字节；4:2:0 里色度在横竖两个方向都减半，每 4 个像素共用 1 组 U/V。下面这段代码把 4:2:0 的字节数算错了，修到输出 `2.0`：

```exercise
# @title: 实战挑战：色度子采样的压缩比
# @check: 2.0
# @hint: 4:2:0 = Y 全分辨率（每像素 1 字节）+ U/V 各占 1/4（合计 0.5 字节/像素）——每像素 1.5 字节
w, h = 1920, 1080

yuv444 = w * h * 3          # 每像素 3 字节：Y、U、V 都是全分辨率
yuv420 = w * h * 1          # ← 问题在这：4:2:0 不是只留 Y
ratio = yuv444 / yuv420
print(round(ratio, 1))
```

<details>
<summary>点开查看逐步解答</summary>

1. 4:4:4：三个分量都全分辨率，每像素 $3$ 字节；
2. 4:2:0：Y 全分辨率（1 字节/像素），U 与 V 横竖各减半——每 4 像素共用 1 组，合计 $0.25 + 0.25 = 0.5$ 字节/像素；
3. 每像素合计 $1.5$ 字节，压缩比 $= 3 / 1.5 = $ **2.0**；
4. 为什么敢这么砍：人眼对亮度敏感、对色度迟钝（进化使然）——这就是 30 课"基变换 + 人眼特性"的落地。初始代码算出 3.0，把"扔掉色度"错当成了"只留亮度"。

</details>
