# 全等三角形：形状的身份证

## 1. 从一个场景开始

工厂用同一套模具冲压了两批三角形钢板，一批在城东、一批在城西。验收员要确认"两批是同一块板"，却不许把钢板搬来搬去对叠——只带一把卷尺。量哪些数据、至少量几个数，才能放心拍板？

量少了，可能冤枉好板；量多了，白花工夫还容易抄错。这一课就回答这个问题：**判断两个三角形"一模一样"，最少要量哪几样**。

## 2. 直觉解释

先从剪纸说起：同一张纸连着剪出两个三角形，怎么确认它们完全一样？最朴素的办法是叠起来看——**完全重合**，一棱一角都不翘出来。

数学给这个日常动作起了正式名字：**全等**。而"叠"在数学里是一套规范的搬运动作：

- **平移**：整个图形滑过去；
- **旋转**：原地转个方向；
- **翻面**：像翻煎饼一样翻个身。

三条规矩只有一条：**只搬运，不拉伸、不撕扯**——这类搬运在几何里叫"刚体运动"。你其实早就用过它们：角度课证明内角和时，我们把两个角**平移搬运**到同一条直线上；[合并同类项与展开](../04-algebra/20-combine-expand.md)那课也见过同一标志——把 $k$ 拖到 5，整理前后的两条线**完全重合**。代数里恒等的标志是重合，几何里"形状身份相同"的标志也是同一个词。

## 3. 正式定义

**全等三角形**：若一个三角形经过平移、旋转、翻面后，能与另一个三角形**完全重合**，则称它们全等，记作 $\triangle ABC \cong \triangle DEF$。

| 符号/术语 | 含义 |
| --- | --- |
| $\cong$ | 全等符号，读作"全等于"；**书写顺序即对应关系**（$A$ 对 $D$、$B$ 对 $E$、$C$ 对 $F$） |
| 对应边 / 对应角 | 搬运后彼此落进同一个位置的边与角；找错"对家"是一切事故的起点 |
| 全等的性质 | 对应边相等，对应角相等——身份证的背面还印着这两条 |
| 判定 | 反过来：量出哪几样数据，就能**发证**？见下表 |

**三件判定工具**（数据从少到多排，每件都含**至少一条边**）：

| 判据 | 需要的数据 | 一句话直觉 |
| --- | --- | --- |
| SSS（边边边） | 三条边对应相等 | 三根定长木棒只能搭出一种三角形 |
| SAS（边角边） | 两边**及其夹角**对应相等 | 先锁死张口，再锁死两条臂长 |
| ASA（角边角） | 两角**及其夹边**对应相等 | 角度课的内角和铁律替你免费补齐第三个角 |

注意 ASA 的底气来自上一条铁律 $\angle A + \angle B + \angle C = 180°$：知道两个角，第三个角**没得选**。

## 4. 分步例题

**例**：验收员量得甲板三边为 6、8、10 dm；乙板抄录时手抖，顺序记乱了，记成 6、10、8 dm。两块板是同一块吗？

1. **排队配对**：按长短对齐——6 对 6、8 对 8、10 对 10，抄录顺序乱了不影响配对；
2. **对号入座**：三对边全部相等，SSS 判据成立；
3. **发证**：甲板 $\cong$ 乙板（全等），全程没用把两块板叠过一次——三卷数据就是身份证；
4. **性质兑现**：既然全等，对应角也自动相等——乙板的最大角与甲板的最大角一模一样；
5. **顺手彩蛋**：$6^2 + 8^2 = 36 + 64 = 100 = 10^2$，两块都是直角板——[面积与勾股定理](./20-area-pythagoras.md)那课 3-4-5 家族的翻倍亲戚。

一句总结流水线：**配对 → 套判据 → 发证 → 白拿对应角**。以后一切"不用叠怎么证明一样"的问题，都走这四步。

## 5. 动手实验

### 实验 1（viz）：随便拖，形状记得自己

```viz
{
  "type": "triangle",
  "title": "拖乱它，再想想怎么拼回去",
  "points": [[0.14, 0.70], [0.88, 0.62], [0.42, 0.12]]
}
```

怎么玩：按住彩色圆点把三个顶点拖到任意位置，三个角的读数跟着乱跳。现在做一个思想实验：只要把三条**边长**抄在本子上，无论画布清空多少次，拿着这卷数据的人都能拼出一只和你画布上**一模一样**的三角形——这就是 SSS 的唯一性。键盘路径：先点一下画布，按 `1`/`2`/`3` 选中顶点，方向键微调（Shift 更精细）。试着把某个顶点拖到几乎压进对边——三根"木棒"快拼不拢了，那是三角形存在的边界。

### 实验 2（python）：直角板的 SAS 验收单

直角三角形验收有捷径：直角先占住一个 90°，再量两条直角边——边角边（SAS）齐活，斜边则被勾股定理锁死。两块板一块量得直角边 3、4，另一块 4、3（抄录顺序恰好记反），验收一下：

```python title="直角三角板的 SAS 验收单"
import math   # 数学工具库：勾股课请出的老朋友

a1, b1 = 3, 4    # 甲板的两条直角边
a2, b2 = 4, 3    # 乙板的两条直角边（抄录时顺序记反了）

c1 = math.hypot(a1, b1)    # hypot(a, b)：勾股定理一步到位，直接给斜边
c2 = math.hypot(a2, b2)
print(round(c1))                  # round()：收掉小数尾巴再比对
print(round(c2))
print(round(c1) == round(c2))     # == 判断两边是否相等，结果是 True/False
```

输出 `5`、`5`、`True`：斜边相等，直角相等，两条直角边长短配对相等——SAS 发证。顺序记反根本不怕：**全等看成套数据，不看抄写顺序**，配对时按长短落座即可。

### 实验 3（python）：只给角，大小就锁不住

拖动滑块给两个角分配度数，看第三个角怎么被内角和"免费"补齐：

```python title="滑块实验：两角定第三角"
# sliders: a=50 [10:160:1], b=60 [10:160:1]
# a、b 由滑块注入（单位：度），代码里不用再赋值
c = 180 - a - b    # 内角和铁律倒扣：第三个角免费到账
print(c)

if c <= 0:         # if：两个角吃光了 180° 的预算
    print("这两个角凑不成三角形！把滑块调小些")
```

怎么玩：反复拖动 $a$、$b$，第三个角永远自动补齐——这就是 ASA 只需两个角一条边的底气。但注意：**角只锁形状，不锁大小**。两个三个角都对应相等的三角形，可以是边长 1 和边长 10 的两兄弟——叠是叠不拢的。全等判据里必须至少有一条边出场，道理就在这。

### 快问快答

```quiz
两个正三角形，三个角都对应相等（全是 60°），能断定它们全等吗？
- 能，角都相等当然全等
- 不能，大小可能不同 [*]
- 能，正三角形只有一种
? 三个角只能锁形状、锁不住大小：边长 1 和边长 10 的正三角形角度完全相同，却怎么搬都叠不拢。全等三判据（SSS/SAS/ASA）每件都至少含一条边，就是给大小上锁用的。
```

::::warning[常见误区]

**误区一**："你以为三个角对应相等就是全等。" 其实三个角（AAA）只锁形状：小照片和大海报角度一致，却不重合。要发全等证，必须至少有一条边到场（SSS、SAS、ASA 都满足）。

**误区二**："你以为随便两条边加一个角（SSA）也能判定。" 其实这是著名的歧义陷阱：同一组"边边角"数据有时能拼出两种不同的三角形。判据里的角必须是**两条已知边的夹角**（SAS），或**夹在两角之间的边**（ASA）——"夹"字不能丢。

**误区三**："你以为 $\cong$ 两侧的顶点顺序可以随便写。" 其实书写顺序就是对应关系的合同：$\triangle ABC \cong \triangle DFE$ 等于宣布 $B$ 对 $F$、$C$ 对 $E$。顺序一乱，后面所有的"对应边相等"都会张冠李戴。

::::

## 6. 练习

**练习 1（判题）**：继续验收那两块直角三角板（甲板直角边 3、4，乙板直角边 4、3）。下面的代码能跑但结果不对——写它的人把斜边当成了两条直角边**相加**，改到两条检查全部通过：

```exercise
# @title: 练习：斜边不是相加出来的
# @check: 5
# @check: 5
# @hint: 勾股定理说 c² = a² + b²，斜边要"平方相加再开方"，不是两条直角边直接相加。用 math.hypot(直角边1, 直角边2) 分别算两块板的斜边，round() 收整后再打印。
import math

a1, b1 = 3, 4    # 甲板的两条直角边
a2, b2 = 4, 3    # 乙板的两条直角边

c1 = a1 + b1     # ← 甲板斜边：两条直角边相加就对了吗？
c2 = a2 + b2     # ← 乙板斜边：同病相怜
print(round(c1))
print(round(c2))
```

<details>
<summary>点开查看逐步解答</summary>

斜边由勾股定理锁死：$c^2 = 3^2 + 4^2 = 25$，开方得 $c = 5$——不是 $3+4=7$。修正后的代码：

```python
import math

a1, b1 = 3, 4
a2, b2 = 4, 3

c1 = math.hypot(a1, b1)    # sqrt(3² + 4²) = 5.0
c2 = math.hypot(a2, b2)    # sqrt(4² + 3²) = 5.0
print(round(c1))
print(round(c2))
```

输出 `5`、`5`，两块板斜边相等，加上公共的直角与成对的直角边，SAS 发证 ✓。那组错误的 `7` 恰好撞上误区：把"边角的组合"当成了"长度的拼积"。
</details>

**练习 2**：已知 $\triangle ABC \cong \triangle DEF$，且 $AB = 5$、$BC = 9$、$\angle A = 40°$。$DE$、$EF$、$\angle D$ 各是多少？若 $\triangle ABC$ 的周长是 24，$\triangle DEF$ 的周长呢？

<details>
<summary>点开查看逐步解答</summary>

全等的性质是"照镜子"：对应位置上的东西全相等。按书写顺序对号：$A$ 对 $D$、$B$ 对 $E$、$C$ 对 $F$——

- $DE$ 与 $AB$ 对应：$DE = 5$；
- $EF$ 与 $BC$ 对应：$EF = 9$；
- $\angle D$ 与 $\angle A$ 对应：$\angle D = 40°$；
- 全等三角形能完全重合，周长自然分毫不差：$\triangle DEF$ 的周长也是 **24**。

做这类题的唯一纪律就是盯着书写顺序找"对家"，顺序读对了，答案全是白送的。
</details>

**练习 3**：判断并说理由："等腰三角形的两个底角相等。用全等的语言把这件事说清楚。"

<details>
<summary>点开查看逐步解答</summary>

对。设等腰三角形 $ABC$ 中 $AB = AC$，取底边 $BC$ 的中点 $D$，连 $AD$。对比 $\triangle ABD$ 与 $\triangle ACD$：

1. $AB = AC$（等腰的定义）；
2. $BD = CD$（$D$ 是中点）；
3. $AD = AD$（公共边——自己和自己当然相等）。

三对边对应相等，SSS 发证：$\triangle ABD \cong \triangle ACD$。于是对应角相等：$\angle B = \angle C$——两底角相等 ✓（顺手还赚到一个赠品：$\angle BAD = \angle CAD$，说明这条中线同时是顶角的平分线）。

这是全等的经典首战：**要证两角相等，先造一对全等三角形**。
</details>

## 7. 选读与边界

### 选读 · 为什么三根边长就锁死形状

<details>
<summary>选读 · 木棒拼装的唯一性</summary>

给定三根木棒（长度满足能拼拢），把最长的 $c$ 平放做底边：另一端分别以半径 $a$、$b$ 画弧——两条弧**至多交于直线上方的一点**。交点唯一，顶点的位置就唯一，形状自然被锁死。这就是 SSS 的全部秘密，也是"三角形稳定性"的真身：不是三角形结实，是**三边数据只许一种拼法**。

木门框斜着钉一根木条，就是把四边形框架切成两个三角形，借 SSS 锁死形状。而四边形天生多一处"活动关节"——伸缩门推得动、晾衣架拉得开，全是这处关节的功劳。四边形想领自己的身份证，条件要重新谈判——下一课就办这件事。

</details>

### 本课不管什么

- 只管**全等**（形状与大小双锁）；形状相同、大小成比例的"宽松版"是下一课的相似；
- 只管三角形；四边形的判定逻辑不同，别照搬；
- "边边角"（SSA）的歧义展开和直角三角形的特例（斜边直角边判定），留给三角章细谈。
