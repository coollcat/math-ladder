# 切线、弦切角与四点共圆

## 1. 从一个场景开始

自行车轮在地面上滚。轮子是个圆，地面是条直线——它们**只碰一个点**。为什么偏偏只碰一个点？因为在接触的那一瞬间，地面恰好**垂直**于通向轮心的那根辐条（半径）。

工程师吃透了这条性质：皮带必须沿**切线**方向绕上轮子才不打滑；砂轮打磨工件时，火星沿着切线飞出；相机镜头的遮光罩也按切线算角度。

这一课把"擦着圆边过去"这条线的规矩一次讲清，并顺手解决一个古老的问题：**四个点什么时候落在同一个圆上？**

## 2. 直觉解释

把一条直线从远处往圆平移，看交点个数怎么变：

- 离得远：**没有**交点；
- 切进来：两个交点（这条线叫**割线**）；
- 继续平移：两个交点沿着圆互相**靠拢**；
- 某一瞬间：两个交点**合并成一个**；
- 再往前：交点消失。

合并的那一瞬间，圆心到这条直线的距离恰好**等于半径**，而垂足就是那个唯一的公共点。所以"垂直于过切点的半径"不是谁规定的，它是"两个交点刚刚合并"的必然结果。

反过来说也成立：如果你画一条线，让它经过半径的**外端**，并且**垂直**于这条半径——由于圆心到它的距离正好等于半径，它除了这个端点之外再也碰不到圆，这条线就是切线。

## 3. 正式定义

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| 切线 | 切线 | 与圆**只有一个**公共点的直线 |
| 切点 | 切点 | 那个唯一的公共点，记作 $T$ |
| 切线长 | 切线长 | 圆外一点 $P$ 到切点 $T$ 的距离 $PT$ |
| 弦切角 | 弦切角 | 顶点在圆上，一边是**切线**、另一边是过切点的**弦** |
| 圆内接四边形 | 圆内接四边形 | 四个顶点都在同一个圆上的四边形 |

**切线的判定定理**：经过半径的外端，并且垂直于这条半径的直线是圆的切线。

**切线的性质定理**：圆的切线垂直于过切点的半径。

> 判定与性质互为逆命题：判定是"由垂直推相切"，性质是"由相切推垂直"。成对出现，一个负责**验收**、一个负责**计算**。

**切线长定理**：从圆外一点引圆的两条切线，它们的**切线长相等**；并且这一点与圆心的连线**平分**两条切线的夹角。

**弦切角定理**：弦切角等于它所夹的弧所对的**圆周角**。

拿上一课的正六边形先验一下：半径为 $2$ 的圆，取切点 $V_0 = (2, 0)$，过它的切线是竖直线 $x = 2$。弦 $V_0V_1$ 与半径 $OV_0$、$OV_1$ 围成等边三角形，故 $\angle OV_0V_1 = 60°$；切线又垂直于 $OV_0$，于是弦切角 $= 90° - 60° = 30°$。而上一课站在 $V_3$ 看同一条弦，算出的圆周角正是 $30°$ ✓。

**四点共圆的判定**（以下三条等价，任取一条即可发证）：

1. 一组**对角互补**的四边形是圆内接四边形；
2. 有一个**外角等于它的内对角**的四边形是圆内接四边形；
3. 存在一点到四个顶点**距离相等**（这是"共圆"二字的本义，也是计算的抓手）。

## 4. 分步例题

**例**：圆半径为 $5$，圆外一点 $P$ 到圆心 $O$ 的距离是 $13$。求从 $P$ 引出的切线长。

1. 设切点为 $T$，连 $OT$——由**性质定理**，$OT \perp PT$；
2. 认角色：三角形 $OTP$ 是直角三角形，斜边是 $OP = 13$，一条直角边是半径 $OT = 5$；
3. 列勾股关系：$PT^2 + 5^2 = 13^2$；
4. 求直角边（用**减法**）：$PT^2 = 169 - 25 = 144$，得 $PT = 12$；
5. 由**切线长定理**，从 $P$ 引出的另一条切线长同样是 $12$；
6. 自检：$PT = 12 < OP = 13$ ✓——切线长是直角边，必然短于斜边。

## 5. 动手实验

### 实验 1（viz）：切线长、半径、$OP$ 拼成的那块勾股

```viz
{
  "type": "pytha",
  "a": 5,
  "b": 12
}
```

怎么玩：把直角边 $a$ 当成**半径 5**、$b$ 当成**切线长 12**，斜边就是圆外那点到圆心的距离 $13$——橙 $25$ + 蓝 $144$ = 紫 $169$，正是例题的三个数。拖动端点改变半径：紫块（$OP$）固定时，半径变大，切线长就必须变短——圆越大，从同一点能"擦"出去的切线越短。

### 实验 2（python）：把两条切线画出来并验账

```python title="拖动 OP，看两条切线怎么摆"
import matplotlib.pyplot as plt    # 画图工具箱，第 0 章登场的老朋友

# sliders: d=13 [6:20:1]

r = 5                              # 圆的半径
OP = d                             # 圆外一点 P 到圆心的距离（滑块注入）
t = (OP ** 2 - r ** 2) ** 0.5      # 切线长 = √(OP² − r²)
x0 = r ** 2 / OP                   # 切点的横坐标：由 OT ⊥ PT 解出来的
y0 = r * t / OP                    # 切点的纵坐标

fig, ax = plt.subplots(figsize=(5.5, 5))
ax.add_patch(plt.Circle((0, 0), r, fill=False, color="#2563eb", lw=2))       # 圆
ax.plot([OP, x0], [0, y0], color="#dc2626", lw=2, label="切线 PT")           # 上面那条切线
ax.plot([OP, x0], [0, -y0], color="#d97706", lw=2, label="切线 PT'")         # 下面那条，与它对称
ax.plot([0, x0], [0, y0], color="#059669", lw=1.5, ls="--", label="半径 OT") # 半径垂直于切线
ax.plot([0, OP], [0, 0], color="#94a3b8", lw=1, ls=":")
ax.plot(0, 0, "o", color="#0f172a")
ax.plot(OP, 0, "o", color="#7c3aed")
ax.annotate("P", (OP, 0), xytext=(6, 6), textcoords="offset points")
ax.set_aspect("equal")             # 横纵同尺度，圆才不会被压成椭圆
ax.set_xlim(-r - 1, OP + 1)
ax.set_ylim(-r - 1, r + 1)
ax.legend()
plt.show()

print(f"切线长 {round(t, 3)}；勾股验账: PT² + r² = {round(t ** 2 + r ** 2, 6)}，OP² = {round(OP ** 2, 6)}")
print(f"切点 ({round(x0, 3)}, {round(y0, 3)}) 到圆心距离 {round((x0 ** 2 + y0 ** 2) ** 0.5, 6)}，应等于半径 {r}")
```

怎么玩：拖动滑块把 $P$ 推远，两条切线跟着变长，但**上下永远一样长**（切线长定理）。第二行是关键：切点到圆心的距离必须恰好是 $5$，说明切点真的落在圆上；第一行 $PT^2 + r^2 = OP^2$，说明 $OT \perp PT$——**切线长定理的本质就是勾股定理**。$P$ 拖到 $6$ 时切线长只剩 $\sqrt{36 - 25} \approx 3.32$，几乎擦着圆过去。

### 实验 3（python）：四点共圆——三点定圆，第四点来验收

判定的本义是"存在一点到四个顶点距离相等"。先让三个点定出一个圆，再把第四点拉过来量一量：

```python title="先由三点定圆，再验收第四点"
import math

def dist(p, q):                    # 两点距离：横差、纵差当直角边，勾股定理求斜边
    return math.sqrt((p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2)

A, B, C = (0, 0), (6, 0), (0, 4)   # 给定的三个点
# 外心：到三点距离相等的点。|OA|² = |OB|² 展开后 x² 抵消，只剩一个一次方程
x = B[0] / 2                       # x² = (x − 6)²  →  x = 3
y = C[1] / 2                       # y² = (y − 4)²  →  y = 2
O = (x, y)
R = dist(O, A)

print(f"三点所定的圆心 {O}，半径 {round(R, 4)}")
print("三点到圆心的距离:", [round(dist(O, p), 6) for p in (A, B, C)])

for name, D in [("矩形的第四角", (6, 4)), ("换个位置", (1, 1))]:
    gap = dist(O, D) - R
    print(f"{name} {D}: 距圆心 {round(dist(O, D), 4)}，与半径相差 {round(gap, 4)}")
```

怎么玩：三点到圆心的距离一模一样（三点定圆，别无分店）。第一个第四点 $(6, 4)$ 与半径相差 $0.0$——它正好落在圆上，于是 $A$、$B$、$C$、$D$ 四点共圆；这个四边形的四个角都是 $90°$，对角和为 $180°$，**对角互补**与**共圆**在这里说的是同一件事。第二个点 $(1, 1)$ 差了 $-1.3695$，落在圆内，四点不共圆。

改一改：把第四点换成 $(5, 5)$ 或 $(6, 3)$，用这一行数字判断它们共不共圆——$(5,5)$ 到 $(3,2)$ 的距离平方是 $2^2 + 3^2 = 13$，与半径平方相同，它共圆；$(6,3)$ 只有 $3^2 + 1^2 = 10$，落在圆内，不共圆。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为'只有一个公共点'能直接拿来算。" 其实那是**判定**的说法，算长度时必须换成**垂直**：连出过切点的半径，得到一个直角三角形，再用勾股定理。跳过这一步，题目就没有下手的缝。

**误区二**："你以为切线长定理说的是两条切线平行或对称。" 其实它保证的是**等长**；顺带（由全等）推出 $OP$ 平分两条切线的夹角。两条切线一般并不平行——它们是从同一点散出去的。

**误区三**："你以为四点共圆可以凭外观判断。" 四个点围出一个"圆乎乎"的形状不等于共圆。判据是**角**（对角互补）或**距离**（到同一点等距），不是眼力。

:::

**练习 2**：判断并说理由："一个平行四边形如果有一个角是直角，它的四个顶点就共圆。"

<details>
<summary>点开查看逐步解答</summary>

对。平行四边形有一个角是直角 → 由邻角互补（第 27 课），四个角**全是** $90°$，它就是矩形。

矩形两条对角线**互相平分且相等**，设交点为 $O$。由"互相平分"，$O$ 是两条对角线的中点；由"相等"，两条对角线长度相同，故 $O$ 到四个顶点的距离都等于**对角线的一半**——存在一点到四点距离相等，矩形四顶点共圆 ✓。

这正是实验 3 里那三个数：圆心 $(3, 2)$、半径 $\sqrt{13}$、第四角 $(6, 4)$ 与半径相差 $0.0$。换一个一般的平行四边形（比如实验里那种压扁的），对角线虽然仍互相平分却不相等，四个顶点到交点的距离两两不同，就不再共圆。

等价的角度说法：矩形的对角和为 $90° + 90° = 180°$，**对角互补** → 四点共圆。

</details>

## 8. 选读与边界

<details>
<summary>选读 · 三条定理的证明</summary>

**切线长定理**：设 $P$ 引出的两条切线切于 $T$、$T'$。

1. 由性质定理，$OT \perp PT$、$OT' \perp PT'$，两个都是直角三角形；
2. 各自用勾股定理：$PT^2 = OP^2 - r^2$，$PT'^2 = OP^2 - r^2$——**右边完全相同**，故 $PT = PT'$；
3. 再看三角形 $OPT$ 与 $OPT'$：$OT = OT' = r$、$PT = PT'$、$OP$ 公用 → 全等（SSS）；
4. 于是 $\angle TPO = \angle T'PO$，即 $OP$ 平分两条切线的夹角。

**弦切角定理**：设切线 $AT$ 与弦 $AB$ 夹成弦切角 $\angle BAT$（$A$ 是切点）。作直径 $AM$。

1. 由性质定理，$AT \perp AM$，故 $\angle BAT = 90° - \angle BAM$；
2. $\angle BAM$ 是一个**圆周角**，对着弧 $BM$，由上一课它等于 $\tfrac12\angle BOM$；
3. 又 $\angle AOB = 180° - \angle BOM$，故 $\tfrac12\angle AOB = 90° - \tfrac12\angle BOM = 90° - \angle BAM$；
4. 与第 1 步对照：$\angle BAT = \tfrac12\angle AOB$——等于**同弧所对的圆周角** ✓。

**四点共圆判定（对角互补版）**：设四边形 $ABCD$ 满足 $\angle B + \angle D = 180°$。过 $A$、$B$、$C$ 三点作圆（三点定圆），设射线 $AD$ 与该圆交于 $D'$。

1. 若 $D' \neq D$，则 $D'$ 落在 $A$ 与 $D$ 之间（或其延长线上）；
2. $ABCD'$ 内接于圆 → 由推论三，$\angle B + \angle AD'C = 180°$；
3. 与已知 $\angle B + \angle ADC = 180°$ 对比，得 $\angle AD'C = \angle ADC$；
4. 但 $\angle AD'C$ 是三角形 $CDD'$ 在 $D'$ 处的**外角**，外角等于两个不相邻内角之和，严格大于其中任一个，即 $\angle AD'C > \angle ADC$——**矛盾**；
5. 故假设不成立，$D$ 与 $D'$ 重合，即 $D$ 在圆上 ✓。

</details>

### 本课不管什么

- 只处理**一个圆**的切线；两个圆的公切线（内公切、外公切）不在本课范围；
- 切线的斜率、切点随角度变化的函数关系要用到三角函数与导数，第 7 章与第 13 章再见；
- 四点共圆的判定在**退化的四点**（有三点共线）时失效——三点共线定不出圆，本课的判据一律不适用。
