# 球的截面、球面距离与外接球

## 1. 从一个场景开始

从北京飞洛杉矶的航班，在地图上看航线是**往北凸的一条弧**，很多乘客以为被绕了远路。可飞行员坚持：这就是最短的。谁对？

飞行员对。问题出在地图上——地图把球面摊成了平面，摊的过程中距离被扭了。真实情况是：飞机不能钻进地底下走直线段（那条线段在球体内部），它只能贴着地表飞，而**球面上最短的路是一段弯的弧**。

第二个问题：拿一根吸管笔直插进一颗橙子，吸管穿过橙子的那一段有多长？橙子近似一个球，切面是个圆——可是这个圆有多大，取决于你插得离正中间多远。

这一课把球的三件家务事一次理清：**切开会得到什么**（截面）、**球面上怎么走路**（大圆与球面距离）、**一个多面体能不能塞进球里**（外接球）。三件事背后站着的还是那位老熟人——勾股定理。

## 2. 直觉解释

**球是什么？** 平面上"到定点距离等于定长的点的集合"叫圆；把"平面上"换成"空间中"，就是球。定点是**球心** $O$，定长是**半径** $R$。《空间直角坐标系》那一课的距离公式把这句话直接写成了方程：点 $P(x,y,z)$ 在球面上 $\iff (x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = R^2$。

**切开它。** 拿一把刀（一个平面）切下去，截面是什么形状？不用算，想象切苹果：不管从哪个方向切，看到的都是一块**圆**。这个直觉是对的，而且有理由——见下一节的直角三角形。

截面圆**不是**都一样大：正中间一刀（过球心）切出的最宽敞，半径就是 $R$；往边上挪，截面圆越来越小；挪到刚好擦着球面时，圆缩成一个点。

**球面上怎么走路？** 先记住：连接球面上两点的**直线段**穿过球体内部，飞机和轮船都走不了。能走的只有贴在球面上的曲线，其中最省路的是**大圆的劣弧**——大圆就是过球心的平面截出的那个最大的圆。

**外接球。** 一个多面体的所有顶点恰好都落在同一个球面上，这个球叫它的**外接球**，球心叫**外心**。钥匙只有一把：**球心到各个顶点的距离必须相等**。凡是能找到这样一个等距点的多面体（长方体、正方体、正棱柱、以及"有一条高、底面顶点共圆"的直棱柱与正棱锥），都有外接球。

## 3. 正式定义

**球**：空间中到定点 $O$ 的距离等于定长 $R$ 的点的集合。$O$ 叫球心，$R$ 叫半径。

**截面圆**：平面截球所得的圆。设球心到该平面的距离为 $d$（这个距离叫**弦心距**），截面圆半径为 $r$，则

$$\boxed{\,r^2 + d^2 = R^2\,}\qquad\text{即}\qquad r = \sqrt{R^2 - d^2}$$

理由是一个直角三角形：球心 $O$、截面圆心 $O'$、截面圆上任意一点 $P$。因为 $O'$ 是 $O$ 在平面上的垂足，所以 $OO' \perp O'P$；又 $OP = R$（半径）、$OO' = d$、$O'P = r$。勾股定理直接给出 $r^2 + d^2 = R^2$。

**大圆与小圆**：过球心的平面截得的圆叫**大圆**（$d = 0$，$r = R$）；不过球心的叫**小圆**。

| 符号 | 含义 | 备注 |
| --- | --- | --- |
| $R$ | 球半径 | 球心到球面上任一点的距离 |
| $d$ | 弦心距 | 球心到截平面的**垂直**距离，$0 \le d \le R$ |
| $r$ | 截面圆半径 | $r = \sqrt{R^2-d^2}$，随 $d$ 增大而减小 |
| 大圆周长 | $2\pi R$ | 地球约 $2\pi\times6371 \approx 40030$ 千米 |
| $d = R$ | 平面与球**相切** | 截面退化成一个点，不是圆 |

**球面距离**：球面上两点 $A$、$B$ 之间最短路径的长度，等于经过 $A$、$B$ 的**大圆的劣弧长**。设这段弧所对的**球心角**为 $\theta$（单位：度），则沿用第 35 课"按比例切圆"的老办法：

$$L = \frac{\theta}{360}\times 2\pi R$$

**外接球半径的两个主力模型**：

| 模型 | 关键图形 | 半径公式 |
| --- | --- | --- |
| 长方体（棱 $a,b,c$） | 体对角线 = 球的**直径** | $R = \dfrac{\sqrt{a^2+b^2+c^2}}{2}$ |
| 正棱柱（底面外接圆半径 $r_{底}$、高 $h$） | 轴截面矩形，其对角线 = 球的直径 | $R = \sqrt{\left(\dfrac{h}{2}\right)^2 + r_{底}^2}$ |
| 墙角模型（球与两两垂直的三个平面都相切） | 球心到墙角的距离 $d = \sqrt{3}\,R$ | $R = \dfrac{d}{\sqrt{3}} = \dfrac{\sqrt3}{3}d$ |

三个公式一条根：先找出一条**端点都在球面上、且过球心**的线段（它就是球的直径），再用勾股定理把它的长度算出来，最后**除以 2**。

## 4. 分步例题

**例 1（截面）**：半径 $R = 5$ 的球，被一个距球心 $d = 3$ 的平面所截。求截面圆半径与截面面积。

1. **认直角三角形**：$OO' = 3$、$OP = 5$、$\angle OO'P = 90°$；
2. **勾股求 $r$**：$r = \sqrt{5^2 - 3^2} = \sqrt{25-9} = \sqrt{16} = 4$；
3. **算面积**：$S = \pi r^2 = 16\pi \approx 50.27$。

检验两个极端：$d=0$ 时 $r=5$（过球心，最大）；$d=5$ 时 $r=0$（相切，退化成点）。两头都对得上，公式可信。

**例 2（长方体外接球）**：长方体三条棱分别为 **3、4、12**，求它的外接球半径与球面面积。

1. **认直径**：长方体的体对角线（从一个顶点到最远的那个顶点）穿过中心，两端都在球面上，所以它是外接球的**直径**；
2. **算体对角线**：两次勾股，$D = \sqrt{3^2+4^2+12^2} = \sqrt{9+16+144} = \sqrt{169} = 13$；
3. **折半得半径**：$R = \dfrac{13}{2} = 6.5$；
4. **球面面积**：$S = 4\pi R^2 = 4\pi\times 42.25 = 169\pi \approx 530.93$。

注意这里出现了一组漂亮的数：$3^2+4^2 = 5^2$，而 $5^2+12^2 = 13^2$——体对角线刚好是整数 13。

**例 3（正三棱柱外接球 · 轴截面法）**：正三棱柱底面边长 $a = 6$、高 $h = 4$，求外接球半径。

1. **找球心**：正棱柱一定有外接球，球心在上下底面中心连线的**中点**；
2. **取轴截面**：过柱高和底面正三角形的中心作一个截面，得到一个**矩形**——宽是底面外接圆的直径 $2r_{底}$，高是柱高 $h$，它的对角线正是球的直径；
3. **算底面外接圆半径**：正三角形边长 $a$，外接圆半径 $r_{底} = \dfrac{a}{\sqrt3}$，代入 $a = 6$ 得 $r_{底} = 2\sqrt3 \approx 3.464$。这条关系怎么来的？设中心为 $O$、顶点 $A$、对边中点 $M$：外心在三边的垂直平分线上，而正三角形里 $AM$ 既是高也是 $BC$ 的垂直平分线，故 $O$ 在 $AM$ 上。由勾股定理 $AM = \sqrt{a^2 - (a/2)^2} = \frac{\sqrt3}{2}a$，$OM = AM - OA = \frac{\sqrt3}{2}a - r_{底}$；再对直角 $\triangle OMB$ 用一次勾股：$r_{底}^2 = \left(\frac{\sqrt3}{2}a - r_{底}\right)^2 + \left(\frac{a}{2}\right)^2$，展开化简得 $\sqrt3\,a\,r_{底} = a^2$，即 $r_{底} = \dfrac{a}{\sqrt3}$；
4. **矩形对角线**：$D = \sqrt{h^2 + (2r_{底})^2} = \sqrt{16 + (4\sqrt3)^2} = \sqrt{16 + 48} = \sqrt{64} = 8$；
5. **折半**：$R = 4$。

**例 4（球面距离）**：地球近似半径 $R = 6371$ 千米。同一条经线上有甲、乙两地，纬度相差 **30°**。求它们的球面距离。

1. **认大圆**：经线本身就是大圆（任何一条经线圈都过地轴、也就过地心）；
2. **定球心角**：同一经线上，纬度差 = 球心角，$\theta = 30°$；
3. **按比例切大圆周长**：$L = \dfrac{30}{360}\times 2\pi\times 6371 = \dfrac{1}{12}\times 40030 \approx 3336$ 千米。

**例 5（对径点）**：地球正背面的两点（比如南极与北极），球面距离是多少？

球心角 $\theta = 180°$（两点与地心共线），走的是半个大圆：$L = \dfrac{180}{360}\times 2\pi R = \pi R \approx 20015$ 千米。

> **本课的边界**：例 4、例 5 之所以算得出来，是因为球心角 $\theta$ **一眼就能看出来**（同一经线、赤道、对径点）。若两点经纬度任给，求 $\theta$ 需要**余弦定理**或**向量夹角公式**——工具分别在第 7 章和第 11 章，那里会把这段路补足。

### 实验 3（python）：两张速查表——截面圆半径与球面距离

```python title="r² + d² 是否恒等于 R²？球心角已知时球面距离有多长？"
import math                       # 数学工具箱

R = 5.0                           # 球半径
for d in [0, 1, 3, 4, 5]:         # 平面到球心的距离（弦心距）
    r = math.sqrt(R * R - d * d)          # 截面圆半径：由勾股定理反解
    back = math.sqrt(r * r + d * d)       # 反推回球半径，应当恒等于 R
    print(d, round(r, 3), round(back, 3))

Re = 6371.0                       # 地球平均半径（千米）
for angle in [30, 60, 180]:       # 球心角（度）：同经线纬度差 / 赤道经度差 / 对径点
    arc = angle / 360 * 2 * math.pi * Re  # 弧长 = 圆心角占比 × 大圆周长
    print(angle, round(arc))
```

前五行是截面表：`0 5.0 5.0`、`1 4.899 5.0`、`3 4.0 5.0`、`4 3.0 5.0`、`5 0.0 5.0`。第三列始终是 5.0，反推无误；走势才是重点——$d$ 从 0 涨到 5，$r$ 从 5 一路掉到 0，最后一行 $r = 0$ 就是"刀与球相切"的瞬间，此时不再有截面圆。后三行是球面距离：`30 3336`、`60 6672`、`180 20015`，第一行是例 4 的答案，最后一行是半个大圆（约两万千米）。把 `angle` 改成 360 会得到 40030 千米，正是"绕地球一圈四万千米"的大圆周长。

### 实验 4（python）：外接球两种模型，一套动作

```python title="长方体：体对角线法；正三棱柱：轴截面对角线法"
import math

# 法一：长方体——体对角线就是外接球的直径
a, b, c = 3.0, 4.0, 12.0
body_diag = math.sqrt(a * a + b * b + c * c)      # 体对角线：两次勾股
R_box = body_diag / 2                             # 半径 = 直径的一半
print(round(body_diag, 1), round(R_box, 2))       # 13.0 6.5

# 法二：正三棱柱——轴截面（矩形）的对角线就是球的直径
a3, h = 6.0, 4.0                                  # 底面边长、柱高
r_base = a3 / math.sqrt(3)                        # 正三角形外接圆半径 = a/√3
axis_diag = math.sqrt(h * h + (2 * r_base) ** 2)  # 轴截面矩形的对角线
R_prism = axis_diag / 2                           # 再折半
print(round(r_base, 3), round(axis_diag, 3), round(R_prism, 3))
```

第一行输出 `13.0 6.5`：体对角线 13、半径 6.5，与例 2 手算一致。第二行输出 `3.464 8.0 4.0`：底面外接圆半径 $2\sqrt3 \approx 3.464$，轴截面对角线 8，半径 4——与例 3 一致。

两种模型的动作完全同构：**找一条过球心、两端在球面上的线段 → 勾股求长 → 除以 2**。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为球的截面都一样大。" 其实只有**过球心**的那一刀才切出半径 $R$ 的大圆；刀往边上挪，截面圆按 $r = \sqrt{R^2-d^2}$ 缩小，挪到 $d = R$ 就退化成一个点（平面与球相切，此时**没有**截面圆）。

**误区二**："你以为球面上两点之间最短的是连接它们的线段。" 那条线段钻进球体内部，飞机和轮船都走不了。球面距离是**大圆的劣弧**——注意是"劣弧"（不到半圈的那一段），绕大圆的另一侧走远路就反了。

**误区三**："你以为长方体的体对角线就是外接球的半径。" 它是**直径**：对角线两端各是一个顶点，中间过球心，长度等于 $2R$。忘了除以 2，半径和球面面积会一起错（面积错 4 倍）。

:::

## 7. 练习

**练习 1（判题）**：长方体三条棱为 **3、4、12**，求它的体对角线、外接球半径、外接球表面积。下面的代码能跑，但把直径当成了半径，表面积也少乘了一次 $R$——修正两处：

```exercise
# @title: 练习：长方体的体对角线与外接球
# @check: 13.0
# @check: 6.5
# @check: 531
# @hint: 体对角线 = √(a²+b²+c²)，它是外接球的直径，半径要再除以 2；球的表面积是 4πR²，R 要平方（写成 R ** 2）。
import math                       # 数学工具箱：sqrt 与 pi

a, b, c = 3, 4, 12                # 长方体的三条棱

body_diag = math.sqrt(a * a + b * b + c * c)   # 体对角线（两次勾股）
R = body_diag                     # ← 体对角线是直径，不是半径
S = 4 * math.pi * R               # ← 球面面积是 4πR²，这里 R 没平方

print(round(body_diag, 1))        # 第 1 行：体对角线
print(round(R, 2))                # 第 2 行：外接球半径
print(round(S))                   # 第 3 行：外接球表面积（收整）
```

<details>
<summary>点开查看逐步解答</summary>

1. **体对角线**：$D = \sqrt{3^2+4^2+12^2} = \sqrt{169} = 13.0$；
2. **半径**：它是直径，故 $R = 13.0 / 2 = 6.5$；
3. **球面面积**：$S = 4\pi R^2 = 4\pi \times 6.5^2 = 4\pi \times 42.25 = 169\pi \approx 530.93$，收整得 **531**。

若照错版那样取 $R = 13$，面积会算成 $4\pi\times13 \approx 163$（既没除以 2 又没平方），连量级都不对。

参考答案：

```python
import math

a, b, c = 3, 4, 12

body_diag = math.sqrt(a * a + b * b + c * c)
R = body_diag / 2                      # 直径折半才是半径
S = 4 * math.pi * R ** 2               # 4πR²：R 要平方

print(round(body_diag, 1))
print(round(R, 2))
print(round(S))
```
</details>

**趁热打铁**：

```quiz
用平面去截一个半径为 R 的球，让这个平面离球心越来越远，截面圆会怎么变？
- 越来越小；当平面与球相切时，截面退化成一个点 [*]
- 大小始终不变，都等于球半径
- 先变大后变小，中间某一处最大
? 截面圆半径满足 r² + d² = R²：d 越大 r 越小，中间那一刀（d = 0，过球心）才是最大的，此后只会一路缩小，d = R 时 r = 0。
```

**练习 2（自测）**：半径为 5 的球，被一个距球心 **4** 的平面所截。求截面圆半径与截面面积。另问：一个球放在墙角，与地面、两面墙都相切，量得球心到墙角的距离为 30 cm，球半径是多少？

<details>
<summary>点开查看逐步解答</summary>

**(1) 截面**：$r = \sqrt{5^2 - 4^2} = \sqrt{9} = 3$，面积 $S = \pi r^2 = 9\pi \approx 28.27$。

**(2) 墙角模型**：以墙角为原点、三条墙脚线为坐标轴（《空间直角坐标系》那一课的摆法）。球与三个坐标平面都相切，故球心到每个平面的距离都是 $R$，球心坐标为 $(R, R, R)$；由距离公式，球心到墙角（原点）的距离 $d = \sqrt{R^2+R^2+R^2} = \sqrt3\,R$。已知 $d = 30$，故 $R = \dfrac{30}{\sqrt3} = 10\sqrt3 \approx 17.32$ cm。

这条 $\sqrt3$ 值得背下来：墙角里的球，**球心到墙角的距离 = $\sqrt3$ 倍半径**。
</details>

## 8. 选读与边界

<details>
<summary>选读 · 为什么截面一定是圆</summary>

直觉说"切苹果总是圆的"，但直觉需要理由。设平面 $\alpha$ 截球（球心 $O$，半径 $R$）。

1. 从 $O$ 向 $\alpha$ 作垂线，垂足为 $O'$，记 $d = |OO'|$；
2. 任取截面与球面的交线上一点 $P$（即 $P$ 既在平面上又在球面上）。因为 $OO' \perp \alpha$ 而 $O'P$ 在 $\alpha$ 内，所以 $OO' \perp O'P$，$\triangle OO'P$ 是直角三角形；
3. 由勾股定理：$|O'P|^2 = |OP|^2 - |OO'|^2 = R^2 - d^2$；
4. 关键的一步：右边**与 $P$ 的取法无关**，是个常数。所以截面上所有这样的 $P$ 到 $O'$ 的距离都等于同一个 $\sqrt{R^2-d^2}$，而平面上到定点距离为定长的点的轨迹是圆。

第 4 步正是答案：不是碰巧，**恒定的 $R$ 与恒定的 $d$ 逼出了一个恒定的 $r$**。顺带把三个情形都收进来了：$d < R$ 时是真圆；$d = R$ 时 $r = 0$，只有一个点（相切）；$d > R$ 时根号里为负，平面与球没有交点。
</details>

### 本课不管什么

- **任给经纬度的球面距离**：需要余弦定理（第 7 章）或向量夹角（第 11 章）先算出球心角 $\theta$，本课只处理 $\theta$ 一眼可见的情形；
- **球的表面积公式从哪来**：$S = 4\pi R^2$ 本课直接用，它的证明（祖暅原理或积分）需要第 14 章的工具；体积公式 $V = \frac43\pi R^3$ 的来源见第 45 课选读；
- **球内接/外切多面体的其它情形**：比如正四面体的外接球、球的内接正方体，做法仍是"找直径 + 勾股"，但图形要复杂些，属于题型训练；
- **球面上的三角形**：球面三角形的内角和大于 180°，三角公式要另起一套，属于球面几何，本站不展开。
