# 空间直角坐标系

## 1. 从一个场景开始

电影票上的"5 排 3 座"能把你钉在影厅里唯一一个座位上（第 40 课）。可如果这家影院有 **4 层**呢？"5 排 3 座"会同时指向 4 个座位——每层一个。

再加一个数：**5 排 3 座，3 层**。三个数，位置唯一。

同样的麻烦出现在更值钱的地方：无人机在仓库里取货（哪一排、哪一列、哪一层货架）、医生在 CT 片上定位一个结节（左右、前后、上下）、GPS 报出的经纬度之外还得有海拔。平面上的两个数不够用了——**空间里的位置需要三个数**。

这一课做一件和第 40 课一模一样的事：给空间里的每个点发一个三位门牌号，把它**正式化**。发完之后，"两点相距多远"这个问题会再一次变成算术——勾股定理要被连着用两次；"两条线平不平行、垂不垂直"也会第一次变成**只看坐标的算术**。

前面《空间中的点、直线与平面》那一课已经顺手用过"三个数定位"，也用"平方直接相加"量过距离。本课是把那套用法立成规矩：**三根轴怎么摆、门牌号怎么读、距离与中点怎么算、平行垂直怎么用坐标判**。

## 2. 直觉解释

平面上我们画了两条互相垂直的数轴。空间里多出的是一个**上下的方向**——那就**再加一条数轴，竖起来**：

- 原来横着的还叫 **x 轴**，正方向朝右；
- 原来纵着的还叫 **y 轴**，正方向朝"里"（往画面深处走）；
- 新加的竖直那条叫 **z 轴**，正方向朝上。

三条轴两两垂直，共享同一个原点 $O$。这就是**空间直角坐标系** $O\text{-}xyz$。

怎么报门牌？**先 x、再 y、最后 z**：从原点出发，沿 x 轴方向走 $|x|$ 格（正右负左），沿 y 轴方向走 $|y|$ 格（正里负外），沿 z 轴方向走 $|z|$ 格（正上负下），落点就是 $(x, y, z)$。三步走完，位置唯一。

画在纸上有个麻烦：纸是平的，画不出三条真正互相垂直的轴。于是大家约定了一种**斜着画**的画法（见下表），看着歪，但它表示的仍是三个两两垂直、单位长度相同的方向——这就像地图把球面摊平会变形，可地球还是圆的。

| 约定 | 画法 |
| --- | --- |
| x 轴 | **水平向右**，长度不打折 |
| z 轴 | **竖直向上**，长度不打折 |
| y 轴 | 斜向右下方，与 x 轴成 $45°$（也可画成 $135°$），长度取**一半**；它代表"往画面深处"的方向 |
| 三轴关系 | 真实世界里两两垂直、单位长度相同；纸上只是投影 |

也就是说：纸上的 x 轴与 y 轴撑起"地面"（$xOy$ 平面），z 轴量高度。

这个"y 轴减半、斜 45°"的画法叫**斜二测画法**，是中国教材画立体图的标准姿势：平行于 x 轴或 z 轴的线段长度不变，平行于 y 轴的线段减半。它也解释了为什么课本上的正方体看着"歪"——不是画错了，是画法使然。

## 3. 正式定义

**空间直角坐标系**：空间中三条两两垂直、原点重合、单位长度相同的数轴构成的坐标系，记作 $O\text{-}xyz$，交点 $O$ 叫原点。

| 名称 | 定义 | 备注 |
| --- | --- | --- |
| 坐标 | 点 $P$ 对应的有序三元组 $(x, y, z)$ | 依次叫横坐标、纵坐标、竖坐标 |
| 原点 | 三轴交点，坐标 $(0, 0, 0)$ | 三个数全归零的家 |
| 卦限 | 三个坐标平面把空间分成的 8 块 | 三坐标同正的那块叫**第一卦限**；各书编号顺序略异，本课只用这一块 |
| 坐标平面 | $xOy$、$yOz$、$zOx$ 三个平面 | 其上分别有 $z=0$、$x=0$、$y=0$ |
| 轴上的点 | 有两个坐标为 0 的点 | **不属于任何卦限**，和第 40 课"轴上的点不算象限"一个道理 |

**空间两点距离公式**：设 $A(x_1, y_1, z_1)$、$B(x_2, y_2, z_2)$，则

$$|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$$

这个公式上一组课为了量线段（面对角线、体对角线）已经用过一次，那时只把它当一把尺子；这里把它立成规矩，并补上当时没提的两件事——下面的中点公式，以及平行与垂直的坐标判据。

**中点坐标公式**：线段 $AB$ 的中点 $M$ 为

$$M\left(\frac{x_1+x_2}{2},\ \frac{y_1+y_2}{2},\ \frac{z_1+z_2}{2}\right)$$

三个坐标各自取平均——它是第 40 课"两个门牌号取平均"的直接升级，三个方向各平一次，谁也不偏袒。

**方向向量与两条直线的位置关系**：一条直线可以用它上面任意两点之差来指方向。设 $\vec{u} = (a_1, b_1, c_1)$、$\vec{v} = (a_2, b_2, c_2)$ 是两条直线的方向（$\vec{u}, \vec{v}$ 都不是三个零）：

| 关系 | 坐标判据 | 口语版 |
| --- | --- | --- |
| 平行 | $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}$ | 三个对应分量成**同一个比例**；分母出现 0 时改说"存在非零常数 $k$ 使 $(a_1,b_1,c_1) = k(a_2,b_2,c_2)$" |
| 垂直 | $a_1a_2 + b_1b_2 + c_1c_2 = 0$ | 对应分量**相乘再求和**，和为零 |

平行的判据好懂：方向一样，就是整体放大或缩小了同一个倍数。垂直这条判据目前先当作**可以验证的坐标事实**收下——它不是凭空规定的，证明放在第 8 节选读里，只用勾股定理和上面的距离公式；到第 11 章，这个"相乘求和"会获得正式身份：它叫**点积**（数量积），垂直判据就是"点积为零"。

## 4. 分步例题

**例 1（距离）**：一间教室，以墙角为原点 $O$，两条墙脚线为 x 轴、y 轴，竖直向上为 z 轴（单位：米）。吊灯 $A$ 在 $(2, 3, 3)$，墙脚插座 $B$ 在 $(8, 7, 0)$。求 $A$、$B$ 相距多远。

1. **三维各作一次差**：$\Delta x = 8-2 = 6$，$\Delta y = 7-3 = 4$，$\Delta z = 0-3 = -3$；
2. **各自平方**：$36 + 16 + 9 = 61$（注意 $\Delta z$ 是负的，平方后照样是正的——距离不认方向）；
3. **开平方**：$|AB| = \sqrt{61} \approx 7.81$ 米。

顺手求中点：$M\left(\frac{2+8}{2}, \frac{3+7}{2}, \frac{3+0}{2}\right) = (5, 5, 1.5)$。

**例 2（平行与垂直）**：长方体 $ABCD\text{-}A'B'C'D'$，取 $A(0,0,0)$、$B(3,0,0)$、$D(0,4,0)$、$A'(0,0,2)$，于是 $B'(3,0,2)$、$D'(0,4,2)$。判断：① $AB$ 与 $AD$ 是否垂直？② $AB$ 与 $A'B'$ 是否平行？③ $AB$ 与 $AD'$ 是否垂直？

1. **写出方向**：$\overrightarrow{AB} = (3,0,0)$，$\overrightarrow{AD} = (0,4,0)$，$\overrightarrow{A'B'} = B'-A' = (3,0,0)$；
2. **① 验垂直**：$3\times0 + 0\times4 + 0\times0 = 0$ → **垂直**（墙脚的两条棱当然垂直）；
3. **② 验平行**：$\overrightarrow{AB}$ 与 $\overrightarrow{A'B'}$ 三个分量都是 $(3,0,0)$，比例为 $1:1:1$ → **平行**（上下底面对应棱）；
4. **③ 验垂直**：$\overrightarrow{AD'} = (0,4,2)$，则 $3\times0 + 0\times4 + 0\times2 = 0$ → **垂直**。

③ 值得多看一眼：$AB$ 同时垂直于 $AD$ 和 $AA'$（$\overrightarrow{AA'} = (0,0,2)$，同样验得 0），也就是一条棱垂直于底面内两条相交的棱——这正是《平行与垂直：线面与面面》里那条**线面垂直判定定理**的坐标版。那边靠图形推理，这边靠两次乘法求和，结论一致。

怎么玩：式子就是距离公式的变形——把 $|OP| = R$ 里的 $|OP|^2 = x^2+y^2+z^2$ 解出 $z$，得到 $z = \sqrt{R^2-x^2-y^2}$。**先看形状**：这张曲面上的每一点，到原点的距离都恰好是 $R$，一点不多一点不少。拖动鼠标旋转视角，确认它从任何角度看都是"鼓"的；再拖 $R$ 滑块，看整个球胀大缩小。这就是"距离公式"这个词组第一次在你眼前长成了实体。

### 实验 2（python）：距离公式 = 勾股定理用了两次

这个公式看着长，其实可以拆成两回熟悉的操作——先在地上量，再把高度加进来。让程序把"两次勾股"和"一次三差平方和"两条路各走一遍：

```python title="两次勾股：底面上量一次，再把高度接上去"
import math                       # 数学工具箱（第 3 章登场）

ax, ay, az = 2.0, 3.0, 3.0        # A：吊灯的门牌号
bx, by, bz = 8.0, 7.0, 0.0        # B：墙脚插座的门牌号

dx = bx - ax                      # 横向差：6
dy = by - ay                      # 纵向差：4
dz = bz - az                      # 竖向差：-3（向下）

flat = math.sqrt(dx * dx + dy * dy)        # 第一次勾股：只看地面投影，得 √(6²+4²)
dist = math.sqrt(flat * flat + dz * dz)    # 第二次勾股：把竖向那一维接上去
one_go = math.sqrt(dx * dx + dy * dy + dz * dz)   # 距离公式一步到位

print(round(flat, 3))             # 地面投影上的距离：7.211
print(round(dist, 3))             # 空间真实距离：7.81
print(round(one_go - dist, 10))   # 两种算法相差多少：0.0
```

输出 `7.211`、`7.81`、`0.0`。第三行的零是重点：**"两次勾股"和"一次三差平方和"完全等价**，距离公式不是新定理，只是把两步并成一步写。顺手验证方向无关性：把 A、B 对调，三个差全部变号，平方后一切照旧——距离只认长度，不认谁在前谁在后。

### 实验 3（python）：垂直判据不是规定，是可验证的事实

"相乘求和等于零"凭什么就是垂直？用勾股定理的**逆定理**查它：若 $\vec{u}$、$\vec{v}$ 从原点出发分别到达点 $A$、$B$，那么 $OA \perp OB$ 当且仅当 $|OA|^2 + |OB|^2 = |AB|^2$。让程序同时算这两笔账：

```python title="用勾股定理的逆定理，当场验证垂直判据"
import math

u = (2, 3, -1)                    # 第一条方向：从原点走到 A
v = (1, -2, -4)                   # 第二条方向：从原点走到 B

cross_sum = u[0] * v[0] + u[1] * v[1] + u[2] * v[2]   # 对应分量相乘再求和
leg_a = u[0] ** 2 + u[1] ** 2 + u[2] ** 2             # |OA|²：一条直角边的平方
leg_b = v[0] ** 2 + v[1] ** 2 + v[2] ** 2             # |OB|²：另一条直角边的平方
ab = (u[0] - v[0], u[1] - v[1], u[2] - v[2])          # A、B 两点的差
hyp = ab[0] ** 2 + ab[1] ** 2 + ab[2] ** 2            # |AB|²：斜边的平方

print(cross_sum)                  # 判据的结果：0
print(leg_a + leg_b)              # 两直角边平方之和：35
print(hyp)                        # 斜边的平方：35
```

输出 `0`、`35`、`35`。两笔账严丝合缝：$2\times1 + 3\times(-2) + (-1)\times(-4) = 2 - 6 + 4 = 0$，同时 $|OA|^2+|OB|^2 = 14 + 21 = 35 = |AB|^2$——勾股定理的逆定理说，这两件事必须同时发生。把 `v` 改成 `(1, 0, 0)` 再跑一次，`cross_sum` 变成 `2` 不为零，$14+1 = 15 \ne |AB|^2 = 22$，两边同时翻脸。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为三维的距离公式是另一条新定理。" 其实它就是平面距离公式多加了 $(z_2-z_1)^2$ 这一项，本质上还是勾股定理——只是要用两次（先地面、后高度）。二维、三维乃至一百维的距离公式是**同一个公式**换项数，第 11 章会见到它写成 $\|u\|$ 的样子。

**误区二**："你以为 $(1,2,3)$ 和 $(3,2,1)$ 差不多。" 三元组的三个位置分别管左右、里外、上下，换位等于把"5 排 3 座 3 层"念成"3 排 2 座 1 层"。与二元组一样，**顺序就是意义**。

**误区三**："你以为用坐标判断垂直必须先学点积。" 其实用距离公式加勾股定理的逆定理就能验（见实验 3）。点积是第 11 章给这套计算起的正式名字和便捷记号，不是前置条件。

:::

## 7. 练习

**练习 1（判题）**：求 $A(1, -2, 3)$ 与 $B(3, 0, -1)$ 的距离与中点。下面的代码能跑，但算距离时漏掉了第三个方向——补齐它，让三行输出都对：

```exercise
# @title: 练习：空间两点的距离与中点
# @check: 4.9
# @check: 2.0 -1.0 1.0
# @hint: 距离要把三个方向的差都放进平方和：math.sqrt(dx*dx + dy*dy + dz*dz)。中点是三个坐标各自取平均——mz 也要写成 (az + bz) / 2。
import math                       # 数学工具箱

ax, ay, az = 1, -2, 3             # A 的门牌号
bx, by, bz = 3, 0, -1             # B 的门牌号

dx = bx - ax                      # 横向差：2
dy = by - ay                      # 纵向差：2
dz = bz - az                      # 竖向差：-4

dist = math.sqrt(dx * dx + dy * dy)   # ← 第三个方向还没进来
mx = (ax + bx) / 2                # 中点横坐标：两数取平均
my = (ay + by) / 2                # 中点纵坐标
mz = az + bz                      # ← 取平均要除以 2

print(round(dist, 1))             # 第 1 行：A、B 的距离（保留一位小数）
print(mx, my, mz)                 # 第 2 行：中点的三个坐标
```

<details>
<summary>点开查看逐步解答</summary>

1. **三维各作一次差**：$\Delta x = 3-1 = 2$，$\Delta y = 0-(-2) = 2$，$\Delta z = -1-3 = -4$；
2. **平方求和**：$2^2 + 2^2 + (-4)^2 = 4 + 4 + 16 = 24$；
3. **开平方**：$|AB| = \sqrt{24} = 2\sqrt{6} \approx 4.899$，保留一位小数得 **4.9**；
4. **中点三个方向各平一次**：$\left(\frac{1+3}{2}, \frac{-2+0}{2}, \frac{3+(-1)}{2}\right) = (2.0,\ -1.0,\ 1.0)$。

漏掉 $\Delta z$ 时只算出 $\sqrt{8} \approx 2.83$——平地上量的数，当然比空间里的真实距离短。

**练习 2（自测）**：长方体 $ABCD\text{-}A'B'C'D'$ 中，$A(0,0,0)$、$B(2,0,0)$、$D(0,2,0)$、$A'(0,0,2)$。

① 判断 $AB$ 与 $AD$ 是否平行、是否垂直；
② 求 $A$ 到 $C'$ 的距离（$C'$ 是 $C$ 的正上方顶点）；
③ 这个长方体其实是正方体。它的外接球（八个顶点都在球面上）半径是多少？

<details>
<summary>点开查看逐步解答</summary>

先定出 $C'$ 的坐标：$C = B + D - A = (2,2,0)$，故 $C'(2,2,2)$。

1. **① 平行**：$\overrightarrow{AB} = (2,0,0)$、$\overrightarrow{AD} = (0,2,0)$。分量比里有分母为零，改用 $k$ 判据：若平行则应存在 $k$ 使 $(2,0,0) = k(0,2,0)$，可第一分量要求 $2 = k\times0$，无解，**不平行**。**垂直**：$2\times0 + 0\times2 + 0\times0 = 0$，**垂直**；
2. **② 距离**：$|AC'| = \sqrt{2^2+2^2+2^2} = \sqrt{12} = 2\sqrt3 \approx 3.46$。这就是棱长为 2 的正方体的**体对角线**，推广一步：棱长 $a$ 的正方体体对角线为 $\sqrt3\,a$；
3. **③ 外接球**：体对角线是外接球的**直径**（它的两个端点都是顶点、中间过正方体中心），故 $R = \dfrac{2\sqrt3}{2} = \sqrt3 \approx 1.73$。

②③ 这两条正是下一课《球的截面、球面距离与外接球》的主力工具，那里会把"体对角线 = 外接球直径"这件事讲透。
</details>

## 8. 选读与边界

<details>
<summary>选读 · 为什么"相乘求和为零"就是垂直</summary>

设 $\vec{u} = (a_1,b_1,c_1)$、$\vec{v} = (a_2,b_2,c_2)$ 都从原点 $O$ 出发，终点分别为 $A$、$B$，记 $T = a_1a_2 + b_1b_2 + c_1c_2$。用距离公式把 $|AB|^2$ 展开（三项各自完全平方）：

$$|AB|^2 = (a_1-a_2)^2 + (b_1-b_2)^2 + (c_1-c_2)^2$$
$$= (a_1^2 + a_2^2 - 2a_1a_2) + (b_1^2 + b_2^2 - 2b_1b_2) + (c_1^2 + c_2^2 - 2c_1c_2) = |OA|^2 + |OB|^2 - 2T$$

- 若 $T = 0$，则 $|AB|^2 = |OA|^2 + |OB|^2$，由勾股定理的**逆定理**，$\angle AOB = 90°$，即两方向垂直；
- 若两方向垂直，由勾股**定理**得 $|AB|^2 = |OA|^2 + |OB|^2$，代回上面的式子即 $T = 0$。

双向都对上了，判据成立——整个证明只用了距离公式（勾股定理两次）和代数展开，没有借助任何新工具。

顺便一提：由这个恒等式还能解出 $T = \frac{|OA|^2 + |OB|^2 - |AB|^2}{2}$——它完全由三条边的长度决定，这正是"夹角由三角形边长唯一确定"的坐标版。第 7 章会把它写成余弦定理，第 11 章会把它命名为点积。
</details>

### 本课不管什么

- **角有多大（异面直线所成角、线面角、二面角）**：本课的判据只能回答"垂直／平行"这种是非题。问"成多少度"要看同章《空间中的角》，那里用平移与平面角的办法处理，不需要三角函数；
- **平面与直线的方程**：本课用"两个点之差"表示方向，属于最原始的用法；把直线和平面写成方程、研究它们的交点与距离，是第 11 章的内容；
- **曲面的方程**：实验 1 里那个球只是碰巧能写成 $z = f(x,y)$，一般的曲面（比如马鞍面、环面）要等到第 20 章；
- **更高维**：四维及以上的点需要四个以上的坐标，距离公式照抄不误（多几项而已），但要认真处理它得有向量空间的语言。
