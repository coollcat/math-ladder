# 圆周率 π：所有圆共享的常数

## 1. 从一个场景开始

车轮滚一圈，车前进多远？给圆木桶箍一圈，要剪多长的铁条？这些问题看起来五花八门，答案却都卡在同一个地方：圆的周长怎么算？

更奇怪的是：随便找一个硬币、一个披萨、一个摩天轮，量出它们的周长和直径，把两数相除——你会得到**同一个数**。这个数是谁规定的？没有人。它是宇宙自带的常数：π。

## 2. 直觉解释

先建立一个"放大镜"直觉。把一张圆形照片放大 2 倍：直径变 2 倍，周长也跟着变 2 倍；放大 3 倍，两者都变 3 倍。**同时翻倍的量相除，比值纹丝不动。**

所以"周长是直径的几倍"这个问题，对一切圆的答案是同一个数。这个倍数有多大？想象让圆沿直尺滚动一圈：前进的距离就是周长，而你会在尺子上读到一个事实——**每个圆的周长里，都不多不少装着 3 个多一点直径**。

这个"3 点多多多少"，人类追了几千年：3.1、3.14、3.14159……它就是本课的主角 π。

## 3. 正式定义

**圆周率**：任一圆的周长 $C$ 与直径 $d$ 之比，记作 $\pi$（读作"派"）：

$$\pi = \frac{C}{d} \approx 3.14159265\cdots$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $d$ | 直径 | 过圆心的弦，$d = 2r$ |
| $r$ | 半径 | 圆心到边上任一点的距离 |
| $C$ | 周长 | 沿圆走一圈的长度 |
| $S$ | 面积 | 圆内部铺"地砖"的数量 |
| $\pi$ | 圆周率 | $C \div d$ 的固定比值 |

由定义立刻得到周长公式与面积公式：

$$C = \pi d = 2\pi r, \qquad S = \pi r^2$$

π 是无限不循环小数——和第 3 章选读里的 $\sqrt{2}$ 同属"无理数"家族，写不尽、也循环不起来。面积公式为什么长这样，第 7 节选读给完整来历。

## 4. 分步例题

**例**：直径 14 cm 的披萨，求它的周长和面积（用近似值 $\pi \approx \frac{22}{7}$）。

1. 认条件：直径 $d = 14$，则半径 $r = 14 \div 2 = 7$；
2. 算周长：$C = \pi d \approx \frac{22}{7} \times 14 = 44$ cm；
3. 算面积：$S = \pi r^2 \approx \frac{22}{7} \times 49 = 154$ cm²；
4. 心里有数：$\frac{22}{7}$ 比 π 略大，真值分别约 43.98 与 153.94——够用了。

## 5. 动手实验

### 实验 1（viz）：让圆在尺子上滚一圈

```viz
{
  "type": "piroll",
  "d": 2
}
```

怎么玩：点「再滚一圈」，看盘子滚过的距离（橙色胶带）恰好等于 3 个直径多一点；拖动滑杆换更大的盘子再滚——胶带变长了，但它始终是 **π 个直径**。

### 实验 2（python）：没有 math.pi 的日子

π 写不尽，可古人照样算圆——用分数当替身。祖冲之之前通行"疏率"，他本人给出精确到六位小数的"密率"：

```python title="用分数逼近 π"
rough = 3.14          # 粗略版：两位小数
shu = 22 / 7          # 疏率：约等于 3.142857
mi = 355 / 113        # 密率：祖冲之的招牌，约等于 3.1415929

print(rough)
print(shu)
print(mi)

d = 14                # 还是那个披萨：三种近似各算一遍周长
print(round(rough * d, 3))
print(round(shu * d, 3))
print(round(mi * d, 3))
```

怎么玩：观察三个近似值给出的答案有多接近——粗略版差了约 0.02 cm，密率只差不到 0.001 cm。

### 实验 3（python）：math.pi 正式登场

分数再好也是替身——π 本身无穷无尽，任何分数都只是权宜之计。于是 Python 把高精度的 π 直接内置进数学工具库：

```python title="math.pi：官方出厂的高精度 π"
import math

print(math.pi)                    # math.pi：圆周率本体，默认给到十几位精度
print(round(math.pi, 8))          # round 的第二个参数：保留几位小数

r = 7
C = 2 * math.pi * r               # 周长公式 C = 2πr
S = math.pi * r ** 2              # 面积公式 S = πr²
print(f"半径 {r}: 周长 ≈ {round(C, 3)}，面积 ≈ {round(S, 3)}")
```

怎么玩：对照实验 2——`355/113` 已经准到小数点后 6 位，而 `math.pi` 一出手就是十几位，从此不必再背任何近似值。

### 实验 4（python）：面积里也藏着同一个 π

```python title="面积 ÷ 半径的平方：又撞见同一个数"
import math

for r in [1, 2, 5, 10]:
    S = math.pi * r ** 2          # 各半径下的圆面积
    ratio = S / r ** 2            # 面积除以半径的平方
    print(f"r={r}: S={round(S, 2)}, S/r²={ratio}")
```

怎么玩：看最后一列——不管半径多大，比值始终停在 3.14159…。"π 是所有圆共用的常数"，现在面积也给出了同一个证据。

### 快问快答

```quiz
把一个圆的半径加倍，它的周长变为原来的几倍？
- 2 倍 [*]
- 4 倍
- π 倍
? 周长 = 2πr 与半径成正比，半径加倍周长加倍；变 4 倍的是面积。
```

:::warning[常见误区]

**误区一**："你以为 π 就是 3.14。" 其实 π 无限不循环，3.14 只是砍出来的近似；祖冲之在一千五百多年前就算到了 3.1415926 与 3.1415927 之间。

**误区二**："你以为大圆的 π 会更大一些。" 其实 π 是比值，与圆的大小毫无关系——变大的是周长和面积本身，常数只有一份。

**误区三**："你以为面积的公式也是 π 乘直径。" 其实那是周长公式；面积是 $\pi r^2$。拿 $r=5$ 试一试：$\pi d \approx 31.4$ 而 $\pi r^2 \approx 78.5$，差得远。

:::

**练习 2**：自行车车轮直径 0.7 米，车轮滚一圈自行车前进多远？（结果保留两位小数）

<details>
<summary>点开查看逐步解答</summary>

滚一圈前进的距离恰是周长：

$$C = \pi d \approx 3.14159 \times 0.7 \approx 2.20 \text{ 米}$$

验证代码：`print(round(math.pi * 0.7, 2))` 输出 `2.2`。想知道骑 1 km 车轮转几圈？用 $1000 \div 2.199$ 算出圈数即可。
</details>

**练习 3**：半径加倍后，圆面积变为原来的几倍？周长呢？

<details>
<summary>点开查看逐步解答</summary>

面积：$r$ 变成 $2r$，代入 $S = \pi r^2$ 得 $\pi (2r)^2 = 4\pi r^2$——**4 倍**。

周长：$\pi (2d) = 2\pi d$——**2 倍**。

规律：长度按倍数走，面积按倍数的平方走。这个"平方放大"还会在第 7 节选读里再露一面。
</details>

## 7. 选读：πr² 从哪里来

<details>
<summary>选读 · 把圆切成扇形，拼成一个矩形</summary>

把圆切成 8 个相同的小扇形，像掰橘子瓣一样交错拼起来，得到一个歪歪扭扭的"平行四边形"；切成 16 瓣再拼，边缘直了一些；切 100 瓣、1000 瓣……拼出的图形无限逼近一个真正的矩形。

矩形的两个尺寸各有来历：

- **底边**：一半扇形的弧朝上、一半朝下，底边总长是半个周长，即 $\pi r$；
- **高**：每片扇形的腰就是半径，高为 $r$。

于是面积 $= \text{底} \times \text{高} = \pi r \times r = \pi r^2$。

这套"无限切分再重拼"的手法，是人类第一次用无穷逼近计算面积——它是第 13、14 章微积分的预演，两千年前阿基米德就靠类似思想夹出了 π 的上下界。

</details>
