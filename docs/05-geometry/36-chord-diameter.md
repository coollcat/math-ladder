# 垂径定理：把圆对折的那条线

## 1. 从一个场景开始

博物馆收到一只破碎的汉代漆盘，只剩一小块弧形的边。修复师要在复制件上补出完整的圆盘——可圆心早就跟着碎片一起丢了。

他的办法只有两步：在残存的弧上量出两条**弦**，分别作它们的**垂直平分线**，两条线的交点就是圆心。为什么这么神？为什么两条"垂直平分线"偏偏会在圆心碰头？

答案藏在圆最朴素的一条规矩里——一条弦，和一条穿过它的直径，之间有一整套严丝合缝的关系。

## 2. 直觉解释

圆是**折叠对称**的图形：沿任何一条过圆心的直线对折，两边完全重合。这条过圆心的直线就是圆的一条对称轴。

现在在圆上任取两点 $A$、$B$，连成一条**弦**。把圆心 $O$ 分别与 $A$、$B$ 连起来，得到 $OA = OB = r$——三角形 $OAB$ 是一个**等腰三角形**。

等腰三角形有个老脾气：从顶点往底边作垂线，落点正好是底边的中点（左右两半完全对称，谁也不比谁多）。把这条"顶点到底边"的线延长成直径，就得到圆的规矩：

> 垂直于弦的直径，会把这条弦**平分**，还顺手把弦分出的两段**弧**也平分。

反过来说同样成立：如果一条直径**平分**了一条弦，那它必定**垂直**于这条弦。

更妙的是，"平分"这件事还自带一把算尺：圆心、弦的中点、弦的端点，三点围出一个**直角三角形**——勾股定理立刻上岗。

## 3. 正式定义

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| — | 弦 | 连接圆上任意两点的线段 |
| — | 直径 | 经过圆心的弦；是圆里**最长**的弦 |
| $d$ | 弦心距 | 圆心到弦的**垂线段**长度（不是斜着量） |
| $h$ | 半弦 | 弦被垂足分成的每一半 |
| $r$ | 半径 | 圆心到圆上任一点的距离 |
| $L$ | 弦长 | 整条弦的长度，$L = 2h$ |

**垂径定理**：垂直于弦的直径平分这条弦，并且平分这条弦所对的两条弧。

**逆定理**：平分弦（不是直径）的直径垂直于这条弦，并且平分这条弦所对的两条弧。

**推论（三个量一把勾股）**：半弦、弦心距、半径围成直角三角形，于是

$$h^2 + d^2 = r^2 \qquad\Longleftrightarrow\qquad L = 2\sqrt{r^2 - d^2}, \quad d = \sqrt{r^2 - \left(\tfrac{L}{2}\right)^2}$$

三个量里知道任意两个，第三个立刻可求。

**注意逆定理里那个括号**：被平分的弦不能本身也是直径。两条直径永远互相平分，但它们可以斜着交叉，谁也不垂直于谁。

## 4. 分步例题

**例**：半径 $r = 5$ cm 的圆中，一条弦的弦心距是 $d = 3$ cm，求这条弦的长。

1. 认角色：半弦 $h$、弦心距 $d$、半径 $r$ 围成直角三角形，斜边是 $r$；
2. 列勾股关系：$h^2 + 3^2 = 5^2$；
3. 求半弦：$h^2 = 25 - 9 = 16$，得 $h = 4$；
4. 回到整条弦：$L = 2h = 8$ cm；
5. 边界自检：$d = 0$ 时弦长 $= 2r = 10$（弦变成直径，最长）；$d = 5$ 时弦长 $= 0$（弦缩成一个点）。$d = 3$ 落在两者之间，答案 8 也落在 0 与 10 之间 ✓。

### 实验 1（viz）：半弦、弦心距、半径拼成一块勾股

```viz

  "b": 4

```

怎么玩：把直角边 $a$ 当成**弦心距 3**、$b$ 当成**半弦 4**，斜边正好是**半径 5**——三块正方形的面积永远对得上账（橙 $9$ + 蓝 $16$ = 紫 $25$）。拖着端点改 $a$：若紫块（半径）固定不动，$a$ 变大、$b$ 就必须变小——这正是"弦离圆心越远，弦越短"。

### 实验 2（python）：十二个整数点，逐条弦验账

半径 5 的圆上有十二个"整数点"——横纵都取自勾股数 3-4-5，勾股定理保证它们真的落在圆上。用它们连成弦，逐条查账：

```python title="弦心距与半弦的平方和，是不是恒等于半径的平方"
import math

r = 5
# 半径 5 的圆上十二个整数点：横纵取自 3-4-5 勾股数，勾股定理保证它们在圆上
pts = [(5,0),(4,3),(3,4),(0,5),(-3,4),(-4,3),(-5,0),(-4,-3),(-3,-4),(0,-5),(3,-4),(4,-3)]

def dist(p, q):                    # 两点距离：横差、纵差当直角边，勾股定理求斜边
    return math.sqrt((p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2)

print("十二点到圆心的距离（应全为 5.0）:")
print([round(dist(p, (0, 0)), 6) for p in pts])

print("从 (5,0) 出发，隔 k 个点连一条弦：")
for k in range(1, 7):
    A = pts[0]
    B = pts[k]
    M = ((A[0] + B[0]) / 2, (A[1] + B[1]) / 2)   # 弦的中点：横纵各取平均
    d = dist((0, 0), M)            # 弦心距：圆心到中点的距离
    h = dist(A, M)                 # 半弦长
    print(f"k={k}: 弦心距 {round(d, 3)}, 半弦 {round(h, 3)}, 弦长 {round(2 * h, 3)}, d²+h² = {round(d ** 2 + h ** 2, 6)}")
```

怎么玩：最后一列钉死在 $25 = r^2$，一条弦都没逃掉。把勾股定理**倒过来读**，这就是"圆心到弦的垂足恰好是弦的中点"的数值证据：三角形 $OMA$ 三边满足 $OM^2 + AM^2 = OA^2$，由勾股定理的逆定理（第 20 课），$M$ 处必是直角。再看前两列：$k$ 越大，弦心距越小、弦越长；$k = 6$ 时弦心距归零，弦长涨到 10——直径。

### 实验 3（python）：拖着弦心距看弦长

```python title="拖动弦心距 d，弦长跟着变"
import matplotlib.pyplot as plt    # 画图工具箱，第 0 章登场的老朋友

# sliders: d=3 [0:4:1]

r = 5                              # 圆的半径
h = (r ** 2 - d ** 2) ** 0.5       # 半弦 = √(r² − d²)；** 0.5 就是开平方

fig, ax = plt.subplots(figsize=(5, 5))
ax.add_patch(plt.Circle((0, 0), r, fill=False, color="#2563eb", lw=2))  # 圆：圆心 (0,0)、半径 r
ax.plot([d, d], [-h, h], color="#dc2626", lw=3, label="弦")             # 弦：竖在 x = d 上的线段
ax.plot([0, d], [0, 0], color="#059669", lw=2, ls="--", label="弦心距 d")  # 圆心到垂足
ax.plot([-r, r], [0, 0], color="#94a3b8", lw=1, ls=":", label="垂直于弦的直径")
ax.plot(0, 0, "o", color="#0f172a", label="圆心")
ax.set_aspect("equal")             # 横纵同尺度，圆才不会被压成椭圆
ax.set_xlim(-r - 1, r + 1)
ax.set_ylim(-r - 1, r + 1)
ax.legend()
plt.show()                         # 出图

print(f"弦心距 {d}，半弦 {round(h, 3)}，弦长 {round(2 * h, 3)}")
```

怎么玩：把 $d$ 从 4 拖到 0，弦从短短一根一路长成直径 10；红弦的中点始终落在绿虚线的右端——垂足就是中点，从没偏过。$d = 4$ 时弦长 $2\sqrt{25 - 16} = 6$，正是例题的邻居。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为只要垂直于弦，就能平分它。" 其实那条线还必须**过圆心**——随便画一条垂直于弦的直线，交点可以落在弦外、也可以落在弦的延长线上，什么也不会平分。定理的名字叫"垂**径**"，垂和径两个条件缺一不可。

**误区二**："你以为 $\sqrt{r^2 - d^2}$ 就是弦长。" 其实那是**半弦**。勾股关系里那条直角边是从垂足到端点的**半条**弦，求整条弦还要乘 2。$r = 5$、$d = 3$ 时它是 4，弦长是 8。

**误区三**："你以为平分弦就一定能推出垂直于弦。" 逆定理同样要求这条线**过圆心**，而且被平分的弦**不能自己是直径**：圆里任意两条直径都互相平分，可它们完全可以斜着交叉。

:::

**练习 2**：判断并说理由："过弦的中点作垂线，这条垂线一定经过圆心。"

<details>
<summary>点开查看逐步解答</summary>

对。设弦为 $AB$，中点为 $M$，连 $OA$、$OB$——它们都是半径，故 $OA = OB$。

在三角形 $OMA$ 与 $OMB$ 中：$OA = OB$、$AM = MB$、$OM$ 公用，三边对应相等，两三角形**全等**（SSS，第 22 课）。于是 $\angle OMA = \angle OMB$；而这两个角并在一起恰好是一个平角 $180°$，所以各为 $90°$。

$OM \perp AB$ 且 $M$ 是中点，说明 $OM$ 正是 $AB$ 的**垂直平分线**——圆心 $O$ 就在这条线上。这正是开头"两条弦的垂直平分线交点即圆心"的依据：每条弦的垂直平分线都过圆心，两条线的交点只能是圆心。

</details>

## 8. 选读与边界

<details>
<summary>选读 · 垂径定理的严格证明</summary>

**定理（正向）**：设直径 $CD$ 垂直于弦 $AB$，垂足为 $M$。

1. 三角形 $OMA$ 与 $OMB$ 都是直角三角形（$OM \perp AB$），斜边都是半径：$OA = OB = r$；
2. 分别用勾股定理：$AM^2 = r^2 - OM^2$，$BM^2 = r^2 - OM^2$；
3. 两式右边相同，故 $AM^2 = BM^2$，即 $AM = BM$——**平分弦**；
4. 再比较三角形 $OMA$ 与 $OMB$：$OM$ 公用、$AM = BM$、$OA = OB$，三边对应相等 → 全等（SSS）；
5. 于是 $\angle AOM = \angle BOM$。相等的**圆心角**所对的弧也相等（第 35 课的弧长公式 $L = \frac{\theta}{360}\cdot 2\pi r$）——**平分两条弧**。

**逆定理（反向）**：设直径 $CD$ 平分弦 $AB$ 于 $M$，且 $AB$ 不是直径。

1. $OA = OB = r$、$AM = MB$、$OM$ 公用 → 三角形 $OMA \cong OMB$（SSS）；
2. 于是 $\angle OMA = \angle OMB$，而二者合成平角 $180°$ → 各为 $90°$，即 $CD \perp AB$。

全程只用勾股定理与全等，一次三角函数都没请。

</details>

### 本课不管什么

- 只处理**同一个圆内**的一条弦；两圆相交的公共弦、连心线关系不在本课范围；
- 弦长与圆心角之间的换算要用 $\sin$，那是第 7 章三角函数的活儿——本课只走勾股这条路；
- 当 $d > r$ 时公式根号下为负，说明这条"弦"根本不存在（直线与圆没有交点）。
