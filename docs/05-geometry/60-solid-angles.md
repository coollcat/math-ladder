# 空间中的角：异面直线、直线与平面、二面角

## 1. 从一个场景开始

同一段楼梯，"它有多陡"说的其实是一个角：踏步方向与水平地面所成的角。屋顶的两个坡面之间也藏着一个角——瓦匠叫它"坡度"，几何里叫**二面角**。

可空间里的角有个麻烦：两条边常常**并不相交**。楼梯的方向线在半空，地面的方向线在脚下，量角器的中心该往哪儿搁？

答案是先"搬"：把其中一条直线沿着平行方向平移过去（平移不改变方向，也就不改变夹角），搬成两条相交的直线，量角器才落得下去。这一课干的就是这件事——三种空间角，三种"搬运 + 落位"的作法。

## 2. 直觉解释

角的度量只认**两条相交的射线**。所以三种空间角的做法可以一句话说完：**先把角的两条边搬进同一个平面，且让它们相交**。

- **异面直线所成角**：把其中一条平移到与另一条相交。平移不改变方向，所以夹角不变——依据就是"平行线的同位角相等"（见《角度与三角形》）。
- **直线与平面所成角**：斜线在平面上的**影子**（射影）。太阳正当头照下来，杆子的影子落在地面上，杆子与影子之间的那个锐角，就是直线与平面所成的角。三者构成一个直角三角形，勾股定理直接够用。
- **二面角**：一本摊开的书，两页纸之间的张口。拿一个**垂直于书脊**的平面切一刀，切出来的两条射线所成的角，就是它的大小。

三种角的取值范围各不相同，别混：异面直线所成角是 $(0^\circ, 90^\circ]$（只取锐角或直角），直线与平面所成角是 $[0^\circ, 90^\circ]$，二面角是 $[0^\circ, 180^\circ]$。

## 3. 正式定义

### 3.1 异面直线所成角

**定义**：已知两条异面直线 $a$、$b$。过空间**任意**一点 $O$ 作直线 $a' \parallel a$、$b' \parallel b$，我们把 $a'$ 与 $b'$ 所成的**锐角（或直角）**叫做异面直线 $a$ 与 $b$ 所成的角。若所成角是 $90^\circ$，就说 $a$ 与 $b$ **互相垂直**，记作 $a \perp b$。

| 符号 | 含义 |
| --- | --- |
| $O$ | 任取的"落脚点"，通常就选在其中一条直线上（省一次平移） |
| $a'$、$b'$ | $a$、$b$ 的平行线，它们相交于 $O$ |
| 取值范围 | $(0^\circ, 90^\circ]$——平移后若得到钝角，取它的补角 |

**为什么与 $O$ 的取法无关**：在两处取点作出的角，两组边分别平行且方向相同，由**等角定理**（如果一个角的两边和另一个角的两边分别平行并且方向相同，那么这两个角相等）知道它们相等。等角定理的证明是两次全等（《全等三角形》）——两边分别平行可以造出平行四边形，把角搬到一起比。

**求角三步**：① 平移——在某条直线上找一个"好点"，把另一条平行搬过来；② 落位——两条线落进同一个三角形；③ 算——用勾股定理算出三边，靠**等边、等腰直角、勾股逆定理**这些特殊情形读出角度。

### 3.2 直线与平面所成角

**定义**：平面的一条**斜线**与它在这个平面内的**射影**所成的锐角，叫做这条直线与这个平面所成的角。

| 情形 | 所成角 |
| --- | --- |
| 直线与平面平行，或直线在平面内 | $0^\circ$ |
| 直线与平面垂直 | $90^\circ$ |
| 斜交 | 斜线与射影的夹角，取锐角 |

**射影**是什么：设 $P$ 是平面外一点，$PO \perp \alpha$ 于 $O$，$A \in \alpha$，那么 $PA$ 叫平面 $\alpha$ 的斜线（$A$ 是斜足），$AO$ 叫斜线在平面上的射影。$PO$、$AO$、$PA$ 三条线构成直角三角形（直角在 $O$），所以求线面角的套路就是：**找垂足 → 连射影 → 解那个直角三角形**。

### 3.3 二面角及其平面角

**定义**：从一条直线出发的两个**半平面**所组成的图形叫二面角；这条直线叫二面角的**棱**，这两个半平面叫二面角的**面**。记作二面角 $\alpha\text{-}l\text{-}\beta$ 或 $A\text{-}l\text{-}B$（$A$、$B$ 分别在两个面内）。

**二面角的平面角**：在棱 $l$ 上任取一点 $O$，在半平面 $\alpha$ 内作射线 $OA \perp l$，在半平面 $\beta$ 内作射线 $OB \perp l$，则 $\angle AOB$ 叫做二面角的平面角。二面角的大小就用它的平面角来度量。

| 符号 | 含义 |
| --- | --- |
| $l$ | 二面角的棱 |
| $OA$、$OB$ | 分别在两个面内、**都垂直于棱**、从同一点出发的两条射线 |
| 取值范围 | $[0^\circ, 180^\circ]$ |

**为什么与棱上取点无关**：在两处取点作出的两个角，两组边分别平行且方向相同 ⇒ 等角定理 ⇒ 相等。这条性质的实用价值是：**棱上的点可以挑最好算的那个**——端点、中点、垂足，哪里方便放哪里。

**作平面角的三种常用办法**：

| 办法 | 做法 | 什么时候用 |
| --- | --- | --- |
| **定义法** | 直接在棱上取点，在两个面内各作一条垂直于棱的射线 | 图形里已经有现成的垂线时 |
| **垂面法** | 作一个垂直于棱的平面，它与两个面的**交线**所成的角就是平面角 | 能看到一个明显的"截面"时 |
| **三垂线法** | 用三垂线定理把垂线"搬"到另一个面里 | 图形里只有一个面内有垂线（见第 8 节选读） |

## 4. 分步例题

### 例 1：异面直线所成角（正方体）

正方体 $ABCD\text{-}A_1B_1C_1D_1$ 的棱长为 **1**，求异面直线 $AB_1$ 与 $BC_1$ 所成角的大小。

1. **平移**：$AB$ 与 $D_1C_1$ 平行且相等（都是棱），由《四边形家族》里"一组对边平行且相等的四边形是平行四边形"，四边形 $ABC_1D_1$ 是平行四边形 ⇒ $BC_1 \parallel AD_1$；
2. **落位**：于是 $AB_1$ 与 $BC_1$ 的夹角 = $AB_1$ 与 $AD_1$ 的夹角 = $\angle B_1AD_1$，落进 $\triangle AB_1D_1$；
3. **算三边**：三条边分别是正方体三个不同面上的面对角线，
$$AB_1 = AD_1 = B_1D_1 = \sqrt{1^2 + 1^2} = \sqrt2$$
   （$AB_1$ 在前面、$AD_1$ 在左面、$B_1D_1$ 在上底面，各用一次勾股）；
4. **读角度**：三边相等 ⇒ $\triangle AB_1D_1$ 是**等边三角形** ⇒ 每个内角都是 $60^\circ$。

答：异面直线 $AB_1$ 与 $BC_1$ 所成角为 **$60^\circ$**。全程没有量角器，只用了三次勾股定理。

### 例 2：直线与平面所成角（正方体）

同一正方体，求 $A_1B$ 与平面 $ABCD$ 所成角的大小。

1. **找垂足**：$A_1A \perp$ 平面 $ABCD$（竖直棱垂直于底面），故 $A_1$ 在底面上的射影是 $A$；
2. **连射影**：斜线 $A_1B$ 的射影是 $AB$，所求角就是 $\angle A_1BA$；
3. **解三角形**：在 $\triangle A_1AB$ 中，$\angle A_1AB = 90^\circ$（因为 $A_1A \perp$ 底面，$AB \subset$ 底面），且 $A_1A = AB = 1$；
4. **读角度**：两直角边相等 ⇒ 等腰直角三角形 ⇒ 两个锐角各 $45^\circ$。

答：$A_1B$ 与平面 $ABCD$ 所成角为 **$45^\circ$**。

### 例 3：二面角（四棱锥）

四棱锥 $P\text{-}ABCD$ 的底面 $ABCD$ 是边长为 **2** 的正方形，$PA \perp$ 平面 $ABCD$，$PA = 2$。求平面 $PBC$ 与平面 $ABCD$ 所成二面角的大小。

1. **认棱**：两个面的公共直线是 $BC$，二面角记作 $A\text{-}BC\text{-}P$，在棱上取点 $B$；
2. **在底面内作垂线**：底面是正方形 ⇒ $AB \perp BC$ ⇒ 射线 $BA$ 合格 ✓；
3. **在平面 $PBC$ 内作垂线**：需要一条从 $B$ 出发且垂直于 $BC$ 的射线，候选是 $BP$。先证 $BC \perp BP$：
   - $PA \perp$ 平面 $ABCD$，$BC \subset$ 平面 $ABCD$ ⇒ $PA \perp BC$；
   - 正方形 ⇒ $AB \perp BC$；
   - $PA$ 与 $AB$ 都在平面 $PAB$ 内且相交于 $A$ ⇒ 由线面垂直的判定定理，$BC \perp$ 平面 $PAB$；
   - $BP \subset$ 平面 $PAB$ ⇒ $BC \perp BP$ ✓（上一课 (2) 的同一条链子）；
4. **认平面角**：$BA$ 与 $BP$ 分处两个面内、都垂直于棱 $BC$、且都从 $B$ 出发 ⇒ $\angle PBA$ 就是二面角 $A\text{-}BC\text{-}P$ 的平面角；
5. **算角度**：在 $\triangle PAB$ 中，$PA \perp AB$，且 $PA = AB = 2$ ⇒ 等腰直角三角形，直角在 $A$ ⇒ $\angle PBA = 45^\circ$。

答：平面 $PBC$ 与平面 $ABCD$ 所成二面角为 **$45^\circ$**。

**回味**：三道例题用的工具完全一样——**勾股定理 + 特殊三角形（等边、等腰直角）+ 勾股逆定理**。凡是角度题给了具体长度，先往这三样上凑。

怎么玩：这张曲面由两个**半平面**沿 $y$ 轴拼接而成——$y$ 轴就是**棱**，左右两半就是二面角的两个**面**。拖 $a$ 看张口变化：

- $a$ 越小，两坡越平缓，张口越大（$a \to 0$ 时整张面摊平，二面角趋于 $180^\circ$）；
- **拖到 $a = 1$**，两坡各与水平面成 $45^\circ$，张口正好 $90^\circ$——这就是**直二面角**，此时两个面所在的平面互相垂直（上一课的面面垂直）；
- $a$ 继续加大，两坡变陡，张口继续收窄。

用垂直于棱的平面（垂直于 $y$ 轴的截面）切一刀，切出来的两条射线的夹角，就是**二面角的平面角**。拖动视角到正对棱的方向，你会直接看见这个角。

### 实验 2（python）：只用勾股，把"垂直"验给程序看

例 3 里" $BC \perp BP$ "这一步是关键。不用量角，用勾股逆定理把它变成一条算式：

```python title="平方和相等 ⟺ 直角"
import math                                   # 开方用 math.sqrt

pa = 2                                        # 侧棱 PA 的长
side = 2                                      # 底面正方形的边长

pb = math.sqrt(pa ** 2 + side ** 2)           # △PAB：∠PAB = 90°，PB 是斜边
ac = math.sqrt(side ** 2 + side ** 2)         # 底面对角线 AC = 2√2
pc = math.sqrt(pa ** 2 + ac ** 2)             # △PAC：∠PAC = 90°，PC 是斜边

print(round(pb, 2))                           # 2√2 ≈ 2.83
print(round(pc, 2))                           # 2√3 ≈ 3.46
print(round(side ** 2 + pb ** 2) == round(pc ** 2))   # BC² + PB² = PC² ? 是 ⟹ BC ⊥ PB
```

输出 `2.83`、`3.46`、`True`。最后一行是在 $\triangle PBC$ 里做勾股逆定理：

$$BC^2 + PB^2 = 4 + 8 = 12 = PC^2 \Rightarrow \angle PBC = 90^\circ \Rightarrow BC \perp BP$$

于是"射线 $BP$ 垂直于棱 $BC$"这件事被一条算式证实了，$\angle PBA$ 名正言顺地成了平面角。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为异面直线所成角可以是钝角。" 其实规定只取**锐角或直角**，范围 $(0^\circ, 90^\circ]$。平移之后若算出 $120^\circ$，答案是它的补角 $60^\circ$——你看到的可能是另一个方向的夹角。

**误区二**："你以为直线与平面所成角，是斜线与平面内随便一条直线的夹角。" 其实必须是与**射影**的夹角。射影与斜线之间的角，是斜线与平面内所有过斜足的直线所成角中**最小**的那一个（最小角定理，见第 8 节选读）；随便挑一条直线量出来只会更大。

**误区三**："你以为作二面角的平面角时，在棱上换一个点会量出不同的角。" 其实不会——两组射线分别平行且同向，由等角定理两角相等。换点的意义在于**挑一个好算的位置**（端点、中点、垂足），不是改变大小。反过来，只在一个面内作垂线、另一个面里随手画一条线，那就大错特错了：**两条射线都必须垂直于棱**。

:::

## 7. 练习

**练习 1（判题）**：正方体 $ABCD\text{-}A_1B_1C_1D_1$ 的棱长为 1。求异面直线 $AB_1$ 与 $BC_1$ 所成角。思路是：由平行四边形 $ABC_1D_1$ 得 $BC_1 \parallel AD_1$，角就落进 $\triangle AB_1D_1$；量出它的三条边，若三边相等则是等边三角形，每个内角 $60^\circ$。下面的代码把第三条边写成了棱长，三边便不再相等。改到输出三行正确结果：

```exercise
# @title: 练习：正方体中的异面直线所成角
# @check: [1.41, 1.41, 1.41]
# @check: True
# @check: 60
# @hint: 平移后角落在 △AB₁D₁ 里，它有三条边：AB₁（前面上的面对角线）、AD₁（左面上的面对角线）、B₁D₁（上底面上的面对角线）——三条都是面对角线 √(a²+a²)，一条棱长都不是。三边相等 ⟹ 等边三角形 ⟹ 每个内角 60°。
import math

a = 1                                              # 正方体棱长
diag = math.sqrt(a ** 2 + a ** 2)                  # 面对角线 √2

sides = [round(diag, 2), round(diag, 2), round(a, 2)]   # ← 第三条边 B₁D₁ 也是面对角线
print(sides)

equilateral = sides[0] == sides[1] and sides[1] == sides[2]
print(equilateral)

if equilateral:
    print(60)                                      # 等边三角形：每个内角都是 60°
else:
    print("三边不等，需要更多工具")
```

<details>
<summary>点开查看逐步解答</summary>

**(1) 为什么要平移**：$AB_1$ 与 $BC_1$ 是异面直线，量角器的中心无处安放。由 $AB \parallel D_1C_1$ 且 $|AB| = |D_1C_1|$，四边形 $ABC_1D_1$ 是平行四边形 ⇒ $BC_1 \parallel AD_1$。平移不改变方向，所以

$$\angle(AB_1,\,BC_1) = \angle(AB_1,\,AD_1) = \angle B_1AD_1$$

**(2) 量三边**：$AB_1$、$AD_1$、$B_1D_1$ 分别是正方体三个面上的面对角线，各用一次勾股：

$$AB_1 = AD_1 = B_1D_1 = \sqrt{1^2+1^2} = \sqrt2 \approx 1.414 \rightarrow \textbf{[1.41, 1.41, 1.41]}$$

初始代码把第三条写成了棱长 $a = 1$，于是三边不等、`equilateral` 为 `False`。

**(3) 读角度**：三边相等 ⇒ $\triangle AB_1D_1$ 是等边三角形 ⇒ 每个内角 $60^\circ$ ⇒ 输出 **`True`** 与 **`60`**。

修正版只改一处：

```py
sides = [round(diag, 2), round(diag, 2), round(diag, 2)]
```

顺手记一句：正方体里到处都是 $60^\circ$ 与 $90^\circ$——**面对角线凑等边三角形得 $60^\circ$**，**面对角线与棱凑等腰直角三角形得 $45^\circ$**。拿到长度先算三边，等边和等腰直角这两种"免费角度"最值得先查。

</details>

## 8. 选读与边界

<details>
<summary>选读 · 三垂线定理：把垂线从一个面"搬"进另一个面</summary>

**三垂线定理**：在平面内的一条直线，如果和这个平面的一条斜线的**射影**垂直，那么它也和这条**斜线**垂直。

已知 $PO \perp$ 平面 $\alpha$ 于 $O$，$PA$ 是斜线（$A$ 为斜足），$OA$ 是射影，$a \subset \alpha$ 且 $a \perp OA$。求证 $a \perp PA$。

1. $PO \perp \alpha$ 且 $a \subset \alpha$ ⇒ $PO \perp a$（线面垂直的定义）；
2. 已知 $a \perp OA$；
3. $PO$ 与 $OA$ 是平面 $POA$ 内两条**相交**直线（交于 $O$）⇒ 由线面垂直的判定定理，$a \perp$ 平面 $POA$（这里 $a$ 与 $PO$、$OA$ 未必相交，垂直一律按 3.1 的定义理解为方向垂直）；
4. $PA \subset$ 平面 $POA$ ⇒ $a \perp PA$（线面垂直的性质）。$\square$

把 1→4 倒着读就是**逆定理**：平面内一条直线若垂直于斜线，则它垂直于这条斜线的射影。

它跟本课的关系：作二面角的平面角时，常常只能在一个面里找到垂线，另一条垂线就靠三垂线定理"搬"过去——这就是前面表格里说的**三垂线法**。

另一件值得知道的事是**最小角定理**：斜线与射影的夹角，比斜线与平面内任何一条过斜足的直线的夹角都**小**。直觉上，影子是光线最"正"的那个方向，偏离它只会让夹角变大。这说明"线面角"这个名字取的是**最小**的那个角，定义不随意。

</details>

### 本课不管什么

- 只处理能靠**作法 + 特殊三角形（等边、等腰直角）+ 勾股逆定理**读出来的角；把任意一个角算成数字（比如 $\angle = 37^\circ$ 这种）要靠余弦，那是第 7 章的工具；用坐标与法向量一口气算出所有空间角的方法在第 11 章；
- 不涉及三角函数表、反三角函数与角度的近似计算；
- 不讨论异面直线的**距离**（公垂线段的长），那需要另外一套构造；
- 三垂线定理只是选读：它好用，但本站后续课程不把它当作必备工具。
