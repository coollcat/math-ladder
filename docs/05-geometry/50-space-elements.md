# 空间中的点、直线与平面

## 1. 从一个场景开始

教室的墙角：地面和一面墙交出一条横线，两面墙交出一条竖直线，天花板又和墙面交出一条横线——三条线撞在同一点。

现在换一个问题：地面上那条南北向的线，和墙面上那条竖直的线，它们相交吗？不相交。它们平行吗？也不平行——因为你找不出任何一块平面能把这两条线同时装进去。平面上"不相交就平行"的铁律，到了空间里第一次失灵。

这一课先把舞台搭起来：点、直线、平面这三个基本元素，管住它们的三条基本事实，以及空间中直线与直线的第三种关系——**异面**。

## 2. 直觉解释

把三个元素想成三样实物：

- **点**是针尖，只占位置，没有大小；
- **直线**是拉紧的细线，两头无限延长；
- **平面**是一块无限大的平板玻璃，没有厚度，向四面八方铺开。

课本里总把平面画成一个平行四边形，那只是"从斜上方看一块玻璃"的速写；真实的平面没有边界，也不会因为画得小就变小。

接下来是三条不用证明、直接接受的**基本事实**。每条都配一个伸手就能验的动作：

- 拿一块玻璃板去贴一根拉紧的线：只要线上有**两个点**贴住了，整根线就整整齐齐贴在板面上。（基本事实 2）
- 三脚架永远站得稳，四条腿的椅子常会晃：三个脚尖**不共线**，就锁定了唯一一块地板平面；第四只脚的落点未必在那块平面上，于是开始摇晃。（基本事实 1）
- 摊开一本书：两页纸各是一个半平面，它们唯一的公共部分就是书脊那条线。（基本事实 3）

## 3. 正式定义

| 元素 | 记法 | 说明 |
| --- | --- | --- |
| 点 | 大写字母 $A$、$B$、$C$ | 空间里用三个数的有序数组 $(x, y, z)$ 定位，是《平面直角坐标系》里数对 $(x, y)$ 的升级版 |
| 直线 | 小写字母 $l$、$m$，或 $AB$ | 两点确定，向两端无限延长 |
| 平面 | 希腊字母 $\alpha$、$\beta$、$\gamma$ | 无限大、无厚度；图形只是速写 |

**三条基本事实**（平面的地基）：

| 编号 | 内容 | 拿来干什么 |
| --- | --- | --- |
| 基本事实 1 | 过**不在一条直线上**的三点，有且只有一个平面 | 判定共面、确定一个平面 |
| 基本事实 2 | 如果一条直线上的**两点**在一个平面内，那么这条直线在这个平面内 | 判定"直线在平面内"，记作 $l \subset \alpha$ |
| 基本事实 3 | 如果两个不重合的平面有一个公共点，那么它们有且只有一条**过该点的公共直线** | 判定"两平面相交必交于一条直线" |

由基本事实 1 直接长出三条推论，它们才是日常最好使的三把钳子：

- **推论 1**：经过一条直线和这条直线外一点，有且只有一个平面；
- **推论 2**：经过两条**相交**直线，有且只有一个平面；
- **推论 3**：经过两条**平行**直线，有且只有一个平面。

推论 3 的可信度来自《四边形家族》那一课：两条平行直线意味着有一个平行四边形能把它们的方向对齐，而"共面"正是平行四边形成立的门槛条件。

**空间中两条直线的位置关系**——这张表只有三行，第三行是平面几何里没有的：

| 关系 | 是否共面 | 公共点个数 | 记法 |
| --- | --- | --- | --- |
| 相交 | 共面 | 恰 1 个 | $a \cap b = P$ |
| 平行 | 共面 | 0 个 | $a \parallel b$ |
| **异面** | **不共面** | 0 个 | — |

> **异面直线**：不同在任何一个平面内的两条直线。

**异面直线的判定定理**：过平面内一点与平面外一点的直线，和这个平面内不经过该点的直线是异面直线。

**怎么证（反证法）**：已知 $A \notin \alpha$、$B \in \alpha$，直线 $l$ 过 $A$、$B$，而 $a \subset \alpha$ 且 $B \notin a$。

1. 反设结论不成立：$l$ 与 $a$ **不是**异面直线，即它们共面，存在平面 $\beta$ 同时含 $l$ 与 $a$；
2. 由 $l \subset \beta$ 得 $A \in \beta$、$B \in \beta$，于是 $\beta$ 含直线 $a$ 与 $a$ 外一点 $B$；
3. 而 $\alpha$ 同样含直线 $a$ 与 $a$ 外一点 $B$。由推论 1，这样的平面**只有一个**，故 $\alpha = \beta$；
4. 于是 $A \in \beta = \alpha$，与已知 $A \notin \alpha$ 矛盾；
5. 反设破产，故 $l$ 与 $a$ 异面。$\square$

**空间两点的距离**——把《平面直角坐标系》那一课的距离公式再升一维：

$$|P_1P_2| = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2 + (z_1-z_2)^2}$$

| 符号 | 含义 |
| --- | --- |
| $(x_1,y_1,z_1)$、$(x_2,y_2,z_2)$ | 两点 $P_1$、$P_2$ 的空间坐标 |
| $\sqrt{\Delta x^2+\Delta y^2}$ | 第一次勾股：两点在水平面上的"底面对角线" |
| $\Delta z$ | 竖直方向的高度差，与上面那条底面对角线垂直 |

## 4. 分步例题

**例**：正方体 $ABCD\text{-}A_1B_1C_1D_1$ 的棱长为 **2**。

**(1)** 判断棱 $AB$ 与棱 $CC_1$ 的位置关系，并加以证明。

**(2)** 求体对角线 $AC_1$ 的长。

**(1) 的解法**：

1. 先猜：$AB$ 与 $CC_1$ 既不相交（隔着整个正方体），也不平行（一个横着一个竖着）——八成是异面；
2. 要证异面，用判定定理，得先挑一个平面。取 $\alpha =$ 平面 $BCC_1B_1$（右侧那一面）；
3. 逐条验：$CC_1 \subset \alpha$ ✓；$B \in \alpha$ ✓ 而 $A \notin \alpha$ ✓（$A$ 在左侧一面）；
4. 直线 $AB$ 恰好过 $A$（平面外一点）与 $B$（平面内一点），而 $CC_1$ **不经过** $B$ ✓；
5. 判定定理的条件全部满足 $\Rightarrow AB$ 与 $CC_1$ **异面**。

**(2) 的解法**：

1. 底面 $ABCD$ 是正方形，底面对角线 $AC = \sqrt{2^2+2^2} = 2\sqrt2$（《面积与勾股定理》）；
2. 竖直棱 $CC_1$ 与底面垂直，所以 $CC_1 \perp AC$，$\triangle ACC_1$ 是直角三角形；
3. 第二次勾股：$AC_1 = \sqrt{(2\sqrt2)^2 + 2^2} = \sqrt{8+4} = \sqrt{12} = 2\sqrt3 \approx 3.46$；
4. 验一笔：$AC_1^2 = 2^2 + 2^2 + 2^2 = 12$ ✓——三个两两垂直的方向，平方直接相加。

## 5. 动手实验

### 实验 1（lab）：拖一拖这块"玻璃板"

```lab

  "domain": 4,
  "height": 420,
  "params": { "a": 0.6, "b": -0.4 }

```

怎么玩：拖 $a$ 让平面绕 $y$ 轴翻转，拖 $b$ 让它绕 $x$ 轴翻转，按住画布拖动可以换视角。盯住两件事：**把 $a$、$b$ 都拖到 0，平面就躺成水平面 $z=0$**——这正是我们常拿来当"地面"的那张平面；而只要 $(a,b)$ 这一对数确定，过原点的这张平面就**唯一确定**。两个数字定一张平面，与"不共线三点定平面"（基本事实 1）是同一件事的两个说法：三点给出两个独立方向，两个数字给出这两个方向的斜率。

### 实验 2（python）：空间距离，勾股用两次

```python title="把三个方向的差合成一个距离"
import math                              # 数学库：开方用 math.sqrt

def dist(p, q):                          # def 定义一个函数：喂两个点，吐一个距离
    dx = p[0] - q[0]                     # 三个方向各差多少
    dy = p[1] - q[1]
    dz = p[2] - q[2]
    flat = math.sqrt(dx ** 2 + dy ** 2)      # 第一次勾股：水平面上的“底面对角线”
    return math.sqrt(flat ** 2 + dz ** 2)    # 第二次勾股：把它和竖直差再合一次

A  = (0, 0, 0)                           # 正方体的一个顶点
B  = (2, 2, 0)                           # 底面对角顶点
C1 = (2, 2, 2)                           # 最远的那个顶点

print(round(dist(A, B), 2))              # 面对角线：2√2 ≈ 2.83
print(round(dist(A, C1), 2))             # 体对角线：2√3 ≈ 3.46
print(round(dist(A, C1) ** 2))           # 2²+2²+2² = 12，三维版的“平方直接相加”
```

输出 `2.83`、`3.46`、`12`——与第 4 节手算逐项对上。把 `C1` 换成 `(2, 2, 5)` 再跑一次，看竖直方向拉长之后距离怎么变。

### 实验 3（python）：两个平面真的只交出一条线

基本事实 3 说：两个不重合的平面若有公共点，公共部分恰好是一条直线。让计算机把两张平面画出来，并把公共部分描成黑线：

```python title="z = x − y 与 z = −x + 2y 的交线"
import matplotlib.pyplot as plt          # 绘图库，第 0 章《matplotlib 入门》的老朋友

fig = plt.figure(figsize=(7, 5))         # 开一块画布
ax = fig.add_subplot(projection="3d")    # 首现参数 projection="3d"：把坐标面升成三维（matplotlib 自带，不必额外 import）

n = 9                                    # 每条边切 8 段，共 9 个格点
xs = [-2 + 4 * i / (n - 1) for i in range(n)]   # x：从 −2 均匀取到 2
ys = [-2 + 4 * j / (n - 1) for j in range(n)]   # y：同样从 −2 取到 2

X  = [[xs[i] for j in range(n)] for i in range(n)]               # 每个格点的 x 坐标
Y  = [[ys[j] for j in range(n)] for i in range(n)]               # 每个格点的 y 坐标
Za = [[xs[i] - ys[j] for j in range(n)] for i in range(n)]       # 平面 α：z = x − y
Zb = [[-xs[i] + 2 * ys[j] for j in range(n)] for i in range(n)]  # 平面 β：z = −x + 2y

ax.plot_surface(X, Y, Za, alpha=0.45, color="tab:blue")     # alpha=0.45：半透明，才看得见被挡住的那张
ax.plot_surface(X, Y, Zb, alpha=0.45, color="tab:orange")

# 联立两式：x − y = −x + 2y  →  2x = 3y  →  令 x = 3t、y = 2t，代回得 z = t
ts = [-0.6 + 0.2 * k for k in range(7)]                     # t 取 7 个值，描出一段交线
ax.plot([3 * t for t in ts], [2 * t for t in ts], ts, color="black", linewidth=3)

ax.set_xlabel("x")
ax.set_ylabel("y")
ax.set_zlabel("z")
ax.set_title("两个平面交于一条直线")
```

怎么玩：蓝橙两张平面彼此穿心而过，公共部分只有那一根黑线——不多不少一条。再把 `Zb` 的算式改成 `xs[i] - ys[j] + 1`（与 $\alpha$ 倾斜程度相同、只差一个高度）重新运行：黑线没了，两张平面变成永远不相交的**平行**平面。两不重合的平面，要么交于一条直线，要么平行，没有第三种。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为空间里两条直线不相交就平行。" 其实还有第三种——**异面**。平行的定义里写着"**同一平面内**且不相交"，而"共面"这个前提在空间里不再自动成立。

**误区二**："你以为任意三点都能确定一个平面。" 其实必须**不共线**：三点排成一条直线时，过它们的平面有**无数个**（想象一扇门绕着门轴转，转到哪一档都过这条轴线）。

**误区三**："你以为两条直线都垂直于同一条直线，它们就平行。" 在平面里对，在空间里错：正方体从同一个顶点 $A$ 出发的两条棱 $AB$ 与 $AD$ 都垂直于 $AA_1$，可它们**相交**于 $A$。少了"共面"这个前提，处处翻车。

:::

## 7. 练习

**练习 1（判题）**：正方体棱长为 2。下面的代码想依次算出面对角线、体对角线，并验证"体对角线的平方等于三个方向平方之和"，但体对角线那一步把勾股只用了**一次**（漏掉竖直方向），第三行跟着一起错。改到输出三行正确结果：

```exercise
# @title: 练习：面对角线与体对角线
# @check: 2.83
# @check: 3.46
# @check: 12
# @hint: 面对角线是底面上用一次勾股：face² = a² + a²。体对角线要再叠一次勾股：把面对角线和竖直棱组成新的直角三角形，body² = face² + a²（也就等于 a²+a²+a²）。三行都要收尾：前两行 round(x, 2) 保留两位小数，第三行 round(x) 收整。
import math

a = 2                                    # 正方体棱长
face = math.sqrt(a ** 2 + a ** 2)        # 面对角线：底面上用一次勾股
body = math.sqrt(a ** 2 + a ** 2)        # ← 体对角线：这一步漏掉了哪个方向？
print(round(face, 2))
print(round(body, 2))
print(round(body ** 2))
```

<details>
<summary>点开查看逐步解答</summary>

**(1) 面对角线**（第 1 行已经对了）：底面是边长 2 的正方形，对角线与两条边组成直角三角形，

$$face^2 = 2^2 + 2^2 = 8, \quad face = 2\sqrt2 \approx 2.828 \rightarrow \textbf{2.83}$$

**(2) 体对角线**：从面对角线再往上叠一次。竖直棱 $CC_1 = 2$ 与底面垂直，所以它与面对角线 $AC$ 垂直，$\triangle ACC_1$ 是直角三角形：

$$body^2 = face^2 + 2^2 = 8 + 4 = 12, \quad body = \sqrt{12} = 2\sqrt3 \approx 3.464 \rightarrow \textbf{3.46}$$

**(3) 平方和校验**（第 3 行）：$body^2 = 2^2+2^2+2^2 = \textbf{12}$，与 $face^2 + 2^2 = 8+4$ 完全一致 ✓

初始代码里 `body` 抄了 `face` 的算法，等于把竖直方向当成了 0，输出 `2.83` 与 `8`。修正版：

```python
import math

a = 2
face = math.sqrt(a ** 2 + a ** 2)
body = math.sqrt(face ** 2 + a ** 2)     # 第二次勾股：把面对角线与竖直棱合成
print(round(face, 2))
print(round(body, 2))
print(round(body ** 2))
```

顺手记一条：棱长 $a$ 的正方体，面对角线是 $\sqrt2\,a$，体对角线是 $\sqrt3\,a$——同样的套路在长方体上也成立，只是三个数字不必相等。

</details>

**练习 2（自测）**：判断对错并说明理由——"空间中两条没有公共点的直线一定平行。"

<details>
<summary>点开查看逐步解答</summary>

**错。** 没有公共点的两条直线有两种可能：共面 ⇒ 平行（平行定义里"同一平面内"这一条在起作用）；不共面 ⇒ **异面**。

反例就在正方体里：底面的棱 $AB$ 与顶面的棱 $B_1C_1$ 没有公共点，也不平行（$AB$ 沿东西向，$B_1C_1$ 沿南北向），它们是异面直线。判定的办法是第 3 节那条判定定理：取 $\alpha =$ 平面 $BCC_1B_1$，$B_1C_1 \subset \alpha$，$B \in \alpha$ 而 $A \notin \alpha$，$AB$ 过 $A$、$B$ 且不经过 $B_1C_1$ 上任何一点 $\Rightarrow AB$ 与 $B_1C_1$ 异面。

</details>

## 8. 选读与边界

<details>
<summary>选读 · 为什么"不相交即平行"在平面里成立、到空间里失灵</summary>

平面几何里，两条直线都被关在同一张纸（同一个平面）上，于是"共面"这个前提是白送的：不相交 ⇒ 平行，干净利落的二分法。

到了空间，直线多了一个自由度——**绕开彼此**。判定是不是异面，最实用的套路就是本课那条判定定理：把其中一条直线塞进一个平面 $\alpha$，再说明另一条直线只有**一个点**落在 $\alpha$ 里。做题时更好用的是它的一条等价形式：**若直线 $a \subset \alpha$，直线 $b$ 与 $\alpha$ 交于一点 $P$，且 $P \notin a$，则 $a$ 与 $b$ 异面。** 同样用反证法：设 $a$、$b$ 共面于 $\beta$。由 $b \subset \beta$ 得 $P \in \beta$；又 $a \subset \beta$ 且 $P \notin a$，于是 $\beta$ 是"直线 $a$ 加 $a$ 外一点 $P$"确定的那个平面（推论 1），而 $\alpha$ 也是，故 $\alpha = \beta$，从而 $b \subset \beta = \alpha$，与"$b$ 只交 $\alpha$ 于一点 $P$"矛盾。$\square$

</details>
