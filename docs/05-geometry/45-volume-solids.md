# 体积与立体几何

## 1. 从一个场景开始

工地一角堆着一座圆锥形的沙堆，底面摊开一片圆、尖顶高高耸起。司机想知道自己的卡车一趟能不能拉完，老板想知道该给供应商付多少吨的钱——可沙堆是"尖的"，长、宽、高三个数字里没有一个能直接给出答案。

面积告诉不了你：它只数了一层地皮。长度更不行。你需要的是**第三根标尺**——体积。

这一课就把三维世界里"装量"的度量规则一次讲清：柱体、锥体、球体的容积从哪里来？一堆形状千奇百怪的立体之间，藏着一个惊人平等的判据（卡瓦列里原理），它还是微积分求体积的直接前身。

## 2. 直觉解释

**体积就是数单位立方体。**

一块 $1\ \text{cm}^3$ 的积木是最小的"装量单位"。边长为 1 的正方体容纳 1 块；边长为 3 的正方体呢？底层铺 $3\times3=9$ 块、一共摞 **3 层**，总共 $9\times3 = 27$ 块。

看清楚了：这一句"$9$ 块一层、摞 3 层"展开写就是

$$V_{\text{正方体}} = (边\times边)\times边$$

先算**底面铺了多大面积**，再问**往上叠了几层**。这两个动作对**任何柱状物**都成立：只要上下的横截面一模一样，摞几层就乘几——把"层数"换成高度 $h$，就得到柱体体积的通用公式。

圆锥没有这份均匀：离底面越近横截面越大，越往尖顶越小。"每层多大"在变化——所以不能直接相乘，得想办法对付这族越来越小的圆片。往下看第 5 节实验：计算机替你把它们一片片摞出来。

至于球的公式，先不硬推。它藏在一条两千年前中国人就写进书里的平等法则之中，第 8 节选读揭晓。

## 3. 正式定义

**体积**：一个立体所占空间的大小，等于它恰好容纳的单位立方体数目（三维版的"面积数格子"）。

先把三员大将排排坐：

| 立体 | 体积公式 | 口语版 |
| --- | --- | --- |
| 柱体（棱柱 / 圆柱） | $V = S_{\text{底}} \times h$ | 底面积 × 层数 |
| 锥体（棱锥 / 圆锥） | $V = \dfrac{1}{3} S_{\text{底}} \times h$ | 同底等高的柱体打三分之一折 |
| 球 | $V = \dfrac{4}{3}\pi r^3$ | 半径立方的四分之三再乘 π |

| 符号 | 含义 |
| --- | --- |
| $S_{\text{底}}$ | 底面面积：圆柱给 $\pi r^2$；棱柱给底面多边形面积 |
| $h$ | 高：顶面到底面的垂直距离，不是斜着的棱长 |
| $r$ | 球或圆锥底面的半径 |

最后压轴的是本课的灵魂法条——**卡瓦列里原理**：

> 夹在两平行平面之间的两个立体，若被任一平行于这两平面的平面所截，截出的截面面积总相等，则两立体的体积相等。

一句话版本："**每层一样多，总数必然一样多**。"一摞硬币竖着推歪一点，每片面积没变、总容量照旧——形状大变，体积不变。判定从此不再依赖死记公式，而是比较"逐层账目"。

## 4. 分步例题

**例**：工地沙堆近似圆锥，底面半径 **2 米**、堆高 **1.5 米**。已知这种沙每立方米约重 1.5 吨，这座沙堆有多重？

1. **认形**：圆锥体；
2. **取公式**：$V=\dfrac{1}{3}\pi r^2 h$；
3. **算底面积**：$\pi r^2 = \pi\times2^2 = 4\pi \approx 12.57\ \text{m}^2$（上一课 π 的老朋友）；
4. **乘高再打折**：$V = \dfrac{1}{3}\times4\pi\times1.5 = \dfrac{1}{3}\times6\pi = 2\pi \approx 6.28\ \text{m}^3$——注意 $\times1.5$ 与 $\div3$ 凑成一对好搭档：先得 $6\pi$ 再除以三，心算也稳；
5. **换算质量**：$6.28\times1.5 \approx 9.42$ 吨。
6. **检验**：普通重型卡车限载约 10 吨——接近但略小于限值，"差不多正好一车"，与现实感吻合 ✓。

答：约 **9.42 吨**，一辆车能运走。回看第 2 步：如果没有那个 $\dfrac13$，答案会膨胀到 28.3 吨——三个卡车都拉不动。三分之一定生死，见误区一。

## 5. 动手实验

### 实验 1（viz）：球体积曲线——半径的三次方脾气

```viz

  "title": "球的体积 V = (4/3)πr³",
  "expr": "(4/3)*pi*x^3",
  "xmin": 0,
  "xmax": 4

```

怎么玩：读两个点做对比——半径 $r=1$ 时 $V\approx4.19$；半径加倍到 $r=2$ 时 $V\approx33.51$，整整 **8 倍**而不是 2 倍。曲线一路陡峭爬升的模样与抛物线的倔强如出一辙：相似三角形告诉你边长走一次方、面积走二次方（上一课的 $k^2$），这一课轮到**体积走三次方**。半径放大 $k$ 倍，球体积放大 $k^3$ 倍。

### 实验 2（python）：把圆锥切成一千层薄饼

圆锥每层截面大小不同，直接套不上"底 × 高"。那就暴力切片：把它切成 $n$ 薄层，每一小层当成一枚薄圆盘来记账：

```python title="切片累加：逼近圆锥体积"
import math                        # 数学工具库，取 π 用

r = 2                              # 圆锥底面半径（米）
h = 3                              # 圆锥的高（米）
n = 1000                           # 切成的层数——层越多越贴近真实体积

total = 0                          # 体积累加器，从零开始记账
thickness = h / n                  # 每一片薄饼的厚度
for i in range(n):                 # i 依次取 0,1,...,n-1，扫过每一层
    level = (i + 0.5) * thickness  # 该层中点离开锥尖的高度（取中点：每层不偏吃也不偏占）
    radius_i = r * level / h       # 截面半径随高度匀速长大，到 h 时恰为 r
    total = total + math.pi * radius_i ** 2 * thickness   # 圆盘面积 × 厚度，累进总收入

print(round(total, 2))             # 切片法的实测结果
print(round(math.pi * r ** 2 * h / 3, 2))   # 官方公式 (1/3)πr²h 的答案
print(round(math.pi * r ** 2 * h / 3 - total, 4))   # 两者相差多少（公式答案 − 切片总账）：小于万分之一就算几乎重合
```

两次输出都是 `12.57`（这正是 $\dfrac13\pi\times2^2\times3=4\pi$ 的样子），第三行的差值是 `0.0`——切片总账比公式答案只低了一丝丝（每层取中点都「偏瘦」一点点），差距不足万分之一，几乎无缝重合。

要点回味：真实体积是一个"无穷多层叠加"的理想极限，`n` 越大 `total` 靠得越近。这套"切薄 → 逐层累加 → 逼近精确值"的手艺有个大名鼎鼎的名字——**积分**；第 14 章将正式拜会它，而今天你已经徒手干了一遍雏形。

### 实验 3（python）：为什么锥是柱的三分之一

不用抽象证明也能眼见为实——程序在几个高度上抽查「锥截面 ÷ 柱截面」的比例：

```python title="同高处抽样：锥截面恒为柱截面的同一比例"
import math

r, h = 2, 3                        # 一柱一锥共享的底半径和高
picks = [0.25, 0.5, 0.75]          # 抽查三个相对高度：25%、50%、75%
ratios = []
for t in picks:                    # t 是“已爬到全高的比例”
    cone_area = math.pi * (r * t) ** 2      # 锥在该层的截面面积
    prism_area = math.pi * r ** 2           # 柱在此处截面面积永远不变
    ratios.append(round(cone_area / prism_area, 4))   # round(x, 4)：保留四位小数

print(ratios)                      # 观察输出规律
```

输出 `[0.0625, 0.25, 0.5625]`——抽查到的比例不多不少，正是三个位置各自的**平方**：$0.25^2$、$0.5^2$、$0.75^2$。规律浮出水面：爬到一半，截面只剩四分之一；越往尖顶，收得越狠。正是这套“随高度平方缩水的圆片”层层叠起，总账才恰好收束到 $\dfrac13$——0 到 1 上所有平方数的平均水平正是三分之一（选读节有完整账目）。

## 6. 常见误区

:::warning[常见误区]

**误区一**：“你以为圆锥大概是圆柱的一半。” 其实是**三分之一**：等底等高时倒三次才能灌满一筒。差一半又差一半，工程预算常栽在这个折扣上。

**误区二**：“你以为球体积里的 $r$ 可以用直径顶包。” 其实那是半径的位置：地球半径约 6371 千米、直径约 12742 千米，拿错编号体积直接错 8 倍（$2^3$）。

**误区三**：“你以为表面积大的容器更能装。” 其实用料与容量是两条独立战线：扁宽铁桶和细高管可以有几乎相同的表面积，装量却天差地别。刷漆问面积，灌水问体积。

:::

## 7. 练习

**练习 1（判题）**：一款圆柱形易拉罐，内半径 **3.6 cm**、深 **10 cm**。理论上它能装多少毫升（1 立方厘米 = 1 毫升）？推出“半径加倍”的加大款之后，它比常规款又多装多少毫升？下面的代码能跑，但有人把绕罐口的**周长**当成了底面积，加大款的差额也只是想当然搬了旧数——修正概念、补齐公式，让它打出三行正确答案：

```exercise
# @title: 练习：易拉罐的容量与加大款
# @check: 41
# @check: 407
# @check: 1221
# @hint: 圆柱的底面积是 πr²（不是周长 2πr！），容量 = 底面积 × 高，1 cm³ = 1 mL。加大款只换一个字母：r_big = 2 * r，用同一套 πr²h 重算新容量；第三行 = 新容量 − 旧容量，各行都过一遍 round() 收整。
import math                       # 取 π 用

r = 3.6                           # 常规款的内半径（厘米）
h = 10                            # 罐深（厘米）

base = 2 * math.pi * r            # ← 注释说它是“底面积”？先想清楚这一步到底算出了什么
volume = base * h                 # 容量 = 底面积 × 高
print(round(base))                # 第 1 行：常规款底面积（收整）
print(round(volume))              # 第 2 行：常规款容量（收整）

r_big = 2 * r                     # 加大款：半径翻倍
gain = volume                     # ← 直接搬旧容量当差额？新容量还没算呢
print(round(gain))                # 第 3 行：加大款比常规款多装多少（收整）
```

<details>
<summary>点开查看逐步解答</summary>

**(1) 治最大的暗坑：周长 ≠ 面积。** 罐底是一个圆，面积要用 $\pi r^2$；而 $2\pi r$ 是绕罐口一圈的**长度**（单位：厘米）。拿长度冒充面积，后面每一行都会跟着歪。

**(2) 常规款逐项核对**：底面积 $\pi\times3.6^2 = 12.96\pi \approx 40.72\ \text{cm}^2$，收整得 **41**；容量 $12.96\pi\times10 = 129.6\pi \approx 407.15\ \text{cm}^3$，也就是 **407 mL**。

**(3) 加大款老实重算**：半径换成 $7.2$，底面积升到 $\pi\times7.2^2 = 51.84\pi$，容量 $518.4\pi \approx 1628.60$ mL。多装的毫升数等于两本账相减：

$$518.4\pi - 129.6\pi = 388.8\pi \approx 1221.45 \rightarrow \textbf{1221}$$

顺手验一笔聪明账：半径翻倍则底面积扩到 $2^2 = 4$ 倍、高没动，新容量应为旧容量的 4 倍、差额恰是旧容量的 **3 倍**——$407.15\times3\approx1221.45$ ✓ 两本账严丝合缝。

参考答案：

```python
import math

r = 3.6
h = 10

base = math.pi * r ** 2                    # 底面积：πr² 才配得上这个名字
volume = base * h                          # 常规款容量
print(round(base))
print(round(volume))

r_big = 2 * r                              # 加大款半径
big_volume = math.pi * r_big ** 2 * h      # 同一套公式，换个大半径重跑
gain = big_volume - volume                 # 新账减旧账，才是真差额
print(round(gain))
```
</details>

**趁热打铁**：半径和体积谁脾气大，来一道一眼定乾坤的选择题：

```quiz
圆柱体的高不变、底面半径加倍。它的体积变成原来的几倍？
- 2 倍
- 4 倍 [*]
- 8 倍
? 底面积随半径走平方（πr²），高不动，体积就跟着放大成 4 倍；想要 8 倍得连高也一起加倍。
```

**练习 2（自测）**：一只篮球的外直径约为 **24 cm**，把它的内部灌满水，大约需要多少毫升？

<details>
<summary>点开查看逐步解答</summary>

1. **认形排坑**：球的公式吃**半径**——先把直径折半得 $r = 12$ cm（这正是前面误区二的陷阱现场）；
2. **半径立三次方**：$12^3 = 1728$；
3. **套球公式**：$V = \dfrac43\pi\times1728 = 2304\pi \approx 7238\ \text{cm}^3$；
4. **换单位对现实**：$1\ \text{cm}^3 = 1$ mL，约合 **7200 毫升**出头——七升有余，快赶上两瓶半大可乐，手感不亏 ✓。
</details>

## 8. 选读与边界

<details>
<summary>选读 · 祖暅原理与球的体积：一场跨越千年的接力</summary>

卡瓦列里原理公元 1635 年发表于欧洲，但早在南北朝，中国数学家祖冲之之子祖暅就写下过完全相同的表述——"幂势既同，则积不容异"，比西方早一千一百多年。

用它称一称球有多重。构造两只"零件盒"：

- 盒 A：底面半径 $R$、高 $R$ 的圆柱，从中间挖掉一只倒立的等底等高圆锥后剩下的部件；
- 盒 B：半球，半径 $R$。

在同一高度 $x$ 处横切一刀（$0\le x\le R$）：

- 盒 B 的截面是一张**圆片**，半径 $\sqrt{R^2-x^2}$（勾股定理给的！），面积 $\pi(R^2-x^2)$；
- 盒 A 的截面是圆环挖去圆盘：环外缘面积为 $\pi R^2$，圆锥截面半径为 $x$、洞掉的面积为 $\pi x^2$，剩下 $\pi(R^2 - x^2)$。

两盒在这一层的账目完全相等！由祖暅原理，半球体积 $=$ 盒 A 体积 $=$ 圆柱 $\pi R^3 -$ 圆锥 $\tfrac13\pi R^3 = \tfrac23\pi R^3$。全球翻倍：

$$V_{\text{球}} = \frac{4}{3}\pi R^3$$

圆周率、勾股定理、切片思想——三个老朋友在本公式里胜利会师。到了第 14 章，同样的截面账目会被写成"把无穷多个圆片面积相加"的积分符号，那里的计算将一步到位。
</details>

### 本课不管什么

- 只处理体积整洁的规则立体与"逐层可比"的组合体；任意旋转曲面围出的怪形体，交给第 14 章积分与第 20 章重积分；
- 表面积怎么最省料（比如什么形状的罐头用铁最少）是优化问题，需要导数站台；
- 密度均匀的假设被悄悄用了很多次；真实的非均质物料要走密度函数的路子。
