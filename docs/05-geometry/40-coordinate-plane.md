# 平面直角坐标系

## 1. 从一个场景开始

电影票上印着"5 排 3 座"。你拿着它进场，先数第 5 排，再数第 3 个座位——一个座位被**两个数**钉死了。只报一个数行不行？"第 5 排"坐得下几十个人；"第 3 座"每排都有一个。一个数描述不了平面上的位置，两个数才行。

这件事数学家想了很久，最后由笛卡尔拍板成一个流传至今的方案：画两条互相垂直的数轴，让平面上的**每个点**都领到一个数对门牌。这套方案叫**平面直角坐标系**——本章攒下的全部几何（角度、勾股、圆），下一章的函数图像，都要在这个舞台上开演。

## 2. 直觉解释

你已经会一条数轴：原点是家，正方向是右边，负数在左边（第 1 章的镜像数轴）。坐标系做的事简单粗暴——**再复制一条数轴，转成竖直的，两条十字交叉**：

- 横的那条叫 **x 轴**（横轴），正方向朝右；
- 竖的那条叫 **y 轴**（纵轴），正方向朝上；
- 交点还是原点 $(0, 0)$，两条轴把平面切成四块，叫四个**象限**。

平面上任何一点怎么报门牌？**先横后纵**：沿 x 轴数出"横向走几格"（右边记正、左边记负），再数"纵向走几格"（上正下负），写成数对 $(x, y)$。这一手你在第 4 章坐标纸速成课已经练过（钉体温单、读折线图）；今天给"先 x 后 y"正式发身份证：$(2, 5)$ 和 $(5, 2)$ 是两个不同的座位，顺序反了就坐错位置。

反方向也通：给你一个数对 $(3, -2)$，从原点出发"横 3 纵 −2"就能走到唯一的目的地。**数对 ↔ 点**，一对一，这就是坐标系的核心承诺。

## 3. 正式定义

| 名称 | 定义 | 备注 |
| --- | --- | --- |
| 坐标系 | 平面内两条互相垂直、原点重合的数轴 | 横轴叫 x 轴，纵轴叫 y 轴 |
| 坐标 | 点对应的有序数对 $(x, y)$ | $x$ 叫横坐标，$y$ 叫纵坐标 |
| 原点 | 两轴交点，坐标 $(0, 0)$ | 门牌号双双归零的家 |
| 象限 | 两轴把平面分成的四个区域 | 右上起**逆时针**编号：第一象限 $(+,+)$、第二 $(-,+)$、第三 $(-,-)$、第四 $(+,-)$ |
| 轴上的点 | $x=0$ 或 $y=0$ 的点 | **不属于任何象限**，别硬塞进四块里 |

符号速查：横坐标的符号告诉你**左右**（正右负左），纵坐标的符号告诉你**上下**（正上负下）。看到 $(-3, -2)$ 不用画图：横负在左、纵负在下——左下角，第三象限。

## 4. 分步例题

**例 1**：描出点 $(-2, 3)$。

1. 从原点出发，先沿横轴走：$-2$ 是负数，**向左** 2 格；
2. 再沿纵方向走：$+3$ 向**上** 3 格；
3. 落点在第二象限（左上），门牌号 $(-2, 3)$。

**例 2**：求点 $A(1, 2)$ 到点 $B(4, 6)$ 的距离。

1. 横向差：$4-1=3$ 格（右移 3）；纵向差：$6-2=4$ 格（上移 4）；
2. 横向和纵向差互相**垂直**——这不就是勾股定理的两条直角边吗！
3. 距离 $=\sqrt{3^2+4^2}=\sqrt{25}=5$。

坐标系干了一件漂亮事：把"两点距离"这个几何问题，改写成了"两次减法 + 一次勾股"的算术流程。第 5 章的勾股定理在这里拿到了新岗位，从此它在坐标系里有了大名鼎鼎的推广形态——**距离公式**。

### 实验 1（viz）：拖一个点，读门牌号


怎么玩：抓住蓝点 P 在平面里随便拖。读数实时更新：先横后纵的坐标、所在象限（轴上的点会特别声明"不属于任何象限"），还有紫色虚线——它与原点连线段的长 $\sqrt{x^2+y^2}$，正是例 2 距离公式的单点版。把点拖到四个象限各转一圈，注意坐标符号怎么跟着变。

### 实验 2（viz）：两点距离 = 勾股定理搬进坐标系

```viz
{
  "type": "coordplane",
  "title": "拖动 P 和 Q：Δx、Δy 当直角边",
  "range": 5,
  "pair": true
}
```

怎么玩：左上角实时显示 $\Delta x$、$\Delta y$ 和距离公式。把 Q 拖到 P 的正右方——$\Delta y$ 归零，距离退化成两次减法；再摆出 $\Delta x=3$、$\Delta y=4$ 的经典组合，距离恰好 5。试试让 $|\Delta x|$ 和 $|\Delta y|$ 一样大，观察"正方形对角线 $\sqrt{2}$ 倍边长"的老朋友。

### 实验 3（python）：把电影票钉上坐标系

```python title="五张电影票：每个数对在坐标系钉一个点"
import matplotlib.pyplot as plt    # 画图工具箱：第 0 章数据可视化课登场的老朋友

tickets = [(1, 2), (3, 1), (4, 5), (2, 4), (5, 3)]   # 五张票：有序数对 (x, y)，先横后纵
xs = []                            # 收集所有横坐标
ys = []                            # 收集所有纵坐标
for t in tickets:                  # 逐张拆票
    xs.append(t[0])                # t[0]：数对的第一位，当横坐标
    ys.append(t[1])                # t[1]：数对的第二位，当纵坐标

fig, ax = plt.subplots(figsize=(6, 6))   # 开一张正方形画纸
ax.scatter(xs, ys, s=130, color='#3b74d6')          # 在坐标平面钉点，s 是点的大小
for i in range(len(tickets)):       # 逐个点标注门牌号
    ax.annotate(str(tickets[i]), (xs[i], ys[i]), xytext=(7, 7), textcoords='offset points')
ax.axhline(0, color='gray')         # 画横轴：y=0 的水平线
ax.axvline(0, color='gray')         # 画纵轴：x=0 的竖直线
ax.set_xlim(-1, 6)                  # 横轴显示范围
ax.set_ylim(-1, 6)                  # 纵轴显示范围
ax.grid(True)                       # 打开网格，方便数格子
plt.show()                          # 出图
```

五个蓝点各就各位，每个点旁边挂着它的门牌号。换个玩法：把 `tickets` 改成你教室最后一排的真实座位号，看看"数对钉点"是不是和现实严丝合缝。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为 $(2, 5)$ 和 $(5, 2)$ 差不多。" 数对是**有序**的：第一位是横向路条、第二位是纵向路条，互换等于把"5 排 3 座"念成"3 排 5 座"——坐进别人怀里。先 x 后 y，这是全世界统一的交通规则。

**误区二**："你以为负坐标是'不能站的地方'。" 负号只说明方向：横负在左、纵负在下。温度零下、海平面以下、亏钱账本——负坐标和负数一样真实。四个象限平分整个平面，负区不比正区小。

**误区三**："你以为轴上的点也算象限成员。" $(3, 0)$、$(0, -2)$、$(0, 0)$ 都住在轴上——象限的四块地盘**不含边界**。考试里"点在第几象限"的问题，先查它有没有骑在轴上。

:::

## 7. 练习

**练习 1**：$A(2, 3)$ 与 $B(6, 6)$ 两点相距多远？下面的计数器差最后一步，补上：

```exercise
# @title: 练习：算出 A、B 两点的距离
# @check: 5.0
# @hint: dx²+dy² 是距离的平方——勾股定理的第三步还欠着：开平方。math.hypot(dx, dy) 一手包办两件事。
import math                       # 数学工具箱（第 3 章登场）

ax, ay = 2.0, 3.0                 # A 的门牌号
bx, by = 6.0, 6.0                 # B 的门牌号
dx = bx - ax                      # 横向差：4 格
dy = by - ay                      # 纵向差：3 格
dist = dx * dx + dy * dy          # ← 这是距离的平方，还没开方
print(round(dist, 1))
```

$\Delta x=4$、$\Delta y=3$，距离 $=\sqrt{4^2+3^2}=\sqrt{25}=5.0$。错版打印的是 $25.0$——勾股定理只到"斜边的平方"，最后一步开方把它交给 `math.hypot(dx, dy)`（它直接返回 $\sqrt{dx^2+dy^2}$，第 5 章算直角三角形时用过）。也可以手写 `math.sqrt(dx * dx + dy * dy)`，一码事。

<details>
<summary>点开查看逐步解答</summary>

1. 横向差：$\Delta x = 6-2 = 4$；
2. 纵向差：$\Delta y = 6-3 = 3$；
3. 勾股：距离 $=\sqrt{4^2+3^2}=\sqrt{25}=5$。

修正代码：`dist = math.hypot(dx, dy)` 或 `dist = math.sqrt(dx * dx + dy * dy)`。再验一遍方向无关性：交换 A、B，$\Delta x$、$\Delta y$ 全变负，但平方后一样——距离不认方向，只认长度。
</details>

**练习 2**（思考）：把点 $(3, -2)$ 沿对角线"翻"到原点对面（横纵全变号），得 $(-3, 2)$。这两个点的门牌号之间有什么规律？与原点连线的中点在哪？

<details>
<summary>点开查看逐步解答</summary>

横纵坐标恰好全变号：$(x, y)\to(-x, -y)$。沿"对角线翻折"走过原点，两点到原点距离相等（$\sqrt{x^2+y^2}$ 一样），方向恰好相反。连线的中点坐标是两个门牌号的平均：$\left(\frac{3+(-3)}{2}, \frac{-2+2}{2}\right)=(0,0)$——正是原点。这种"横纵全变号"的关系叫**关于原点对称**，函数图像的翻折变换（下一章）会原样重逢。
</details>

## 8. 边界之外

- **函数图像的主舞台**：下一章《函数与图像》把"输入-输出"过程画在坐标系里，每个输入 $x$ 和输出 $y$ 组成数对钉点——函数从此有了脸。坐标系不是几何的专利，它是整个"数形结合"的通用货币。
- **斜坐标系与极坐标**：两条轴不垂直行不行？（斜坐标，可行但算账费劲）干脆不用直角、用"距离+角度"报位置行不行？（极坐标，第 7 章 65 课登场）
- **三维与更高维**：空间里的点要三个数 $(x, y, z)$；机器人的位姿要 6 个自由度（第 65 章）；推荐系统里一部电影可以活在几百维的嵌入空间——"门牌号"思想一路升维，第 11、21 章的向量与基就是它的正式化。
