# 面积与勾股定理：a² + b² = c²

## 1. 从一个场景开始

一架 5 米长的梯子斜靠在墙上，梯脚离墙根 3 米——不爬上去量，你能算出梯子顶端够到多高吗？再比如：木工想检查墙角是不是标准的直角，只拿一把卷尺，在两边各量 30 厘米和 40 厘米，然后量两点间的距离。他在量什么？

两个问题的答案，都指向 2500 年前就刻在巴比伦泥板上的一条定律。

## 2. 直觉解释

**面积就是"铺地砖"。**

一块长 5 米、宽 3 米的矩形地板，每平方米铺一块砖，正好铺 $5 \times 3 = 15$ 块——矩形面积 = 长 × 宽，本质是在数格子。正方形是长宽相等的特殊矩形，面积 = 边 × 边，也就是"边的平方"，这正是"平方"这个词的来历。

沿矩形的对角线剪一刀，得到两个一模一样的直角三角形——所以：

$$\text{三角形面积} = \frac{\text{底} \times \text{高}}{2}$$

现在玩点更神奇的：在一个直角三角形的**三条边上各盖一个正方形**。量一量三块地的面积，你会发现一个惊人的规律——两条短边上正方形的面积之和，不多不少恰好等于斜边上那块。这就是本课的主角。

## 3. 正式定义

设直角三角形的两条**直角边**为 $a$、$b$，**斜边**（直角所对的那条，也是最长边）为 $c$，则：

$$a^2 + b^2 = c^2$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a$、$b$ | 直角边（中国古代叫勾、股） | 夹住直角的两条边 |
| $c$ | 斜边（古代叫弦） | 直角对面的边，最长 |
| $a^2$ | a 的平方 | 以 a 为边长的正方形面积 |

这条关系叫**勾股定理**（西方称毕达哥拉斯定理）。它是一座桥：知道任意两条边，第三条边就被锁死——

$$c = \sqrt{a^2 + b^2}, \qquad b = \sqrt{c^2 - a^2}$$

最著名的整数组是 $3^2+4^2=5^2$，即"勾三股四弦五"。

## 4. 分步例题

**例**：5 米的梯子斜靠墙，梯脚离墙 3 米，墙与地面垂直，梯子顶端离地多高？

1. 认角色：墙 ⊥ 地面，构成直角三角形；梯子是最长边，即斜边 $c = 5$；
2. 设顶端高度为 $h$，列勾股方程：$h^2 + 3^2 = 5^2$；
3. 算出平方项：$h^2 + 9 = 25$；
4. 移项（第 4 章的老动作）：$h^2 = 16$；
5. 开方、取正根：$h = \sqrt{16} = 4$ 米。

不用爬梯子，答案自己冒出来了。木工卷尺验直角用的也是它：若 $30\text{-}40\text{-}50$ 三段恰好满足勾股，墙角就是标准直角。

## 5. 动手实验

### 实验 1（viz）：三块正方形面积的跷跷板

```viz
{
  "type": "pytha",
  "a": 4,
  "b": 3
}
```

怎么玩：拖动直角边的端点改变 $a$、$b$，盯着三块正方形的面积数字——无论怎么拖，橙块 + 蓝块 永远恰好等于紫块。键盘也能走：先点画布，方向键左右改 $a$、上下改 $b$，按住 Shift 可细调；需要回到起点时用「重置」。这就是 $a^2+b^2=c^2$ 的面积版本。

### 实验 2（python）：先手搓一个斜边计算器

组件只是"看见"，代码才能"算出"。按定义手工实现三步流程——平方、相加、开方：

```python title="手搓版：sqrt(a*a + b*b)"
import math                     # 数学工具库，第 3 章引入的老朋友

a, b = 3, 4
c = math.sqrt(a * a + b * b)    # 平方 → 相加 → 开方：三步流水线
print(c)

x, y = 8, 15                    # 换一组更长的直角边试试
print(math.sqrt(x ** 2 + y ** 2))   # x ** 2 是乘方记号，等于 x 自乘
```

怎么玩：把最后两行的数字换成你喜欢的任何两条直角边，运行后对照实验 1 里拖出的读数。

### 实验 3（python）：math.hypot 正式诞生

刚才那个"三步流水线"用得实在太频繁，数学家干脆给它起了专有名字——hypotenuse（斜边）的前半截：

```python title="官方工具：math.hypot 一步到位"
import math

print(math.hypot(3, 4))             # hypot(a, b)：直接给出 sqrt(a² + b²)
print(math.hypot(8, 15))
print(round(math.hypot(8, 15)))     # round() 四舍五入到整数，甩掉小数尾巴

for triple in [(5, 12, 13), (8, 15, 17), (7, 24, 25)]:
    lhs = triple[0] ** 2 + triple[1] ** 2   # triple[0]/[1]：按下标取出第一、第二项；再平方相加
    rhs = triple[2] ** 2                    # c²
    print(triple, "→", lhs == rhs)
```

怎么玩：注意 `math.hypot(3, 4)` 与实验 2 手搓结果完全一致——hypot 不是新咒语，它就是你刚写过的三步流程打包成的官方快捷方式。循环里三组"勾股数"全部亮 `True`。

### 快问快答

```quiz
直角三角形两条直角边分别是 6 和 8，斜边是多少？
- 14
- 10 [*]
- 7
? 勾股定理：6²+8²=36+64=100=10²。斜边不是两条边相加（那是 14），要平方相加再开方。
```

:::warning[常见误区]

**误区一**："你以为 $a^2+b^2=c^2$ 对所有三角形都成立。" 其实这是**直角三角形专属**待遇：只要那个角不是 90°，等式立刻失效（钝角时 $c^2$ 偏大、锐角时偏小）。用之前先确认直角存在。

**误区二**："你以为 c 可以随便指一条边。" 其实 c 特指**直角对面**的那条（最长边）。位置一写错，等式就不成立了——先找直角，再认斜边。

**误区三**："你以为 $\sqrt{a^2+b^2}$ 可以拆成 $a+b$。" 第 3 章就核对过：$\sqrt{9+16}=5$，而 $3+4=7$。平方相加之后还要开方。

:::

**练习 2**：已知斜边 13、一条直角边 5，另一条直角边是多少？

<details>
<summary>点开查看逐步解答</summary>

反过来用勾股定理：

1. 列方程：$5^2 + b^2 = 13^2$
2. 算平方：$25 + b^2 = 169$
3. 移项：$b^2 = 144$
4. 开方取正：$b = \sqrt{144} = 12$

验证代码：`print(math.hypot(5, 12))` 输出 `13.0` ✓。这就是 5-12-13，另一组经典勾股数。
</details>

**练习 3**：判断并说理由："三边为 6、8、10 的三角形一定是直角三角形。"

<details>
<summary>点开查看逐步解答</summary>

对。勾股定理的**逆定理**同样成立：若最长边的平方等于另两边平方之和，则最长边对的那个角必是直角。

验证：$6^2 + 8^2 = 36 + 64 = 100 = 10^2$ ✓。木工的卷尺验直角法，用的正是这条逆定理。
</details>

## 7. 选读：拼图法证明

<details>
<summary>选读 · 一块大正方形，两种摆法</summary>

准备一个大正方形，边长 $a+b$，内部挖掉 4 个全等的直角三角形（两直角边恰为 $a$、$b$——"全等"下一课正式发证）。剩下的空白部分形状取决于你怎么摆这 4 个三角形：

- **摆法一**：4 个三角形贴着大正方形的四条边放置，中间留出一个边长为 $c$ 的斜置正方形。空白面积 $= c^2$；
- **摆法二**：把 4 个三角形两两拼成两个 $a \times b$ 的矩形，错开放置，空白处剩下一块 $a^2$ 正方形和一块 $b^2$ 正方形。空白面积 $= a^2 + b^2$。

两种摆法里，大正方形总面积相同、挖掉的 4 个三角形也相同，所以剩余空白必然相等：

$$c^2 = a^2 + b^2$$

整个证明只用到了"面积可以拼接计算"这一件事。据说毕达哥拉斯看到证明后宰了一百头牛庆祝——史称"百牛定理"。

</details>
