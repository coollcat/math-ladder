# 棱柱、棱锥、棱台的表面积

## 1. 从一个场景开始

包装厂接了两笔订单：一批**六棱柱**的茶叶罐、一批**金字塔形**的巧克力盒，客户要求外面整整包一层彩纸。采购员要报一个数：**这一批得买多少纸？**

体积回答不了这个问题——那是"能装多少"的账。包纸问的是"要糊住多大的一片面"，是**面积**的账。可立体图形的面是弯折的、斜着的，总不能拿尺子一片片去贴。

好消息是：柱、锥、台这三种形状都长得极其**规整**——把它们的侧面沿一条棱剪开、摊平到桌面上，会得到一批你能直接算面积的图形（矩形、三角形、梯形）。摊平之后，问题就退化成了"几个平面图形的面积加起来"。

这一课就干这件事：把三种立体的侧面**摊开来看**，把侧面积公式一个个推出来，再补上底面积得到表面积。

## 2. 直觉解释

**直棱柱：剪开摊平是一个大矩形。**

拿一个六棱柱的罐子，沿一条侧棱竖直剪开，把侧面摊平——六个侧面（每个都是矩形）肩并肩排成一条，拼成一个**大矩形**。

- 这个矩形的高 = 棱柱的高 $h$；
- 这个矩形的宽 = 六个底边依次接起来 = **底面周长** $C$。

所以侧面积 = 宽 × 高 = $C \times h$。一句话：**直棱柱侧面展开是一个矩形，一边是底面周长，另一边是高。**

**正棱锥：剪开摊平是一圈等腰三角形。**

正棱锥的顶点在底面中心正上方，各个侧面因此是**全等的等腰三角形**（底边是底面的一条边 $a$，腰是侧棱）。沿各条侧棱剪开摊平，得到 $n$ 个全等的三角形围成一朵花。

每个三角形的面积是 $\dfrac12 \times 底 \times 高$，这里的"高"是**侧面三角形的高**——注意它不是棱锥的高 $h$！它是从锥顶斜着往下、量到对边中点的那段距离，叫**斜高**，记作 $h'$。

于是侧面积 $= n \times \dfrac12 a h' = \dfrac12 \times (na) \times h' = \dfrac12 C h'$。

**正棱台：剪开摊平是一圈等腰梯形。**

用平行于底面的平面把正棱锥的头部切掉，剩下部分就是正棱台。它的侧面是 $n$ 个全等的**等腰梯形**：上底 $a'$、下底 $a$、高是斜高 $h'$。

每个梯形面积 $= \dfrac12 (a + a') h'$，加起来 $=\dfrac12 (C + C') h'$。

**看清楚三个公式共有的那个动作**：周长 × （某个高）。柱用**高** $h$，锥用**斜高** $h'$，台用**斜高** $h'$——因为柱的侧面是竖直的（矩形的高就是柱高），而锥、台的侧面是倾斜的（斜面的高比竖直的高要长）。混用这两个高，是本课最大的坑。

## 3. 正式定义

| 立体 | 侧面积 | 表面积 |
| --- | --- | --- |
| **直**棱柱 | $S_{侧} = C \cdot h$ | $S_{表} = S_{侧} + 2S_{底}$ |
| **正**棱锥 | $S_{侧} = \dfrac{1}{2} C \cdot h'$ | $S_{表} = S_{侧} + S_{底}$ |
| **正**棱台 | $S_{侧} = \dfrac{1}{2}(C + C') \cdot h'$ | $S_{表} = S_{侧} + S_{底} + S_{上底}$ |

| 符号 | 含义 | 易错点 |
| --- | --- | --- |
| $C$ | 底面周长 | 正 $n$ 边形底面边长 $a$ 时，$C = na$ |
| $C'$ | 棱台**上**底面周长 | 只有一个底的图形没有这一项 |
| $h$ | **高**：两底面之间（或顶点到底面）的**垂直**距离 | 竖直方向 |
| $h'$ | **斜高**：侧面等腰三角形（梯形）的高 | 斜面的高，**永远大于 $h$** |
| $S_{底}$ | 一个底面的面积 | 表面积为"侧 + 底"，别漏 |

**斜高怎么求**（这是本课的算力核心）。正棱锥/正棱台里，高 $h$、斜高 $h'$ 和底面的两条半径构成一个直角三角形：

| 立体 | 直角三角形 | 斜高公式 |
| --- | --- | --- |
| 正 $n$ 棱锥 | 直角边 $h$ 与 **底面内切圆半径** $r_{内}$ | $h' = \sqrt{h^2 + r_{内}^2}$ |
| 正四棱锥（边长 $a$） | 直角边 $h$ 与 $\dfrac{a}{2}$ | $h' = \sqrt{h^2 + \left(\dfrac{a}{2}\right)^2}$ |
| 正四棱台（下底 $a$、上底 $a'$） | 直角边 $h$ 与 $\dfrac{a-a'}{2}$ | $h' = \sqrt{h^2 + \left(\dfrac{a-a'}{2}\right)^2}$ |

想不起公式就画**轴截面**：过顶点（或上下底面中心）与对边中点竖切一刀，截面里的那个直角三角形的斜边就是斜高。

**两个"正"字前提**：上面三条公式只对**直**棱柱、**正**棱锥、**正**棱台成立。
- 斜棱柱的侧面是平行四边形，展开后不是矩形，$C\cdot h$ 会**少算**；
- 斜棱锥的侧面不是全等的等腰三角形，没有统一的斜高。

碰到"斜"的，老实一个面一个面算。

## 4. 分步例题

**例 1（正六棱柱）**：底面边长 $a = 2$、高 $h = 5$ 的正六棱柱，求侧面积与表面积。

1. **底面周长**：$C = 6a = 12$；
2. **侧面积**：$S_{侧} = C \cdot h = 12 \times 5 = 60$；
3. **底面积**：正六边形可以切成 6 个边长 $a$ 的正三角形。正三角形面积由勾股定理得 $\dfrac{\sqrt3}{4}a^2$（高 $=\sqrt{a^2-(a/2)^2} = \frac{\sqrt3}{2}a$，面积 $=\frac12 a\cdot\frac{\sqrt3}{2}a$），故 $S_{底} = 6\times\dfrac{\sqrt3}{4}\times 4 = 6\sqrt3 \approx 10.392$；
4. **表面积**：$S_{表} = S_{侧} + 2S_{底} = 60 + 12\sqrt3 \approx 80.78$。

**例 2（正四棱锥）**：底面边长 $a = 6$、高 $h = 4$，求侧面积与表面积。

1. **先求斜高**（不是高！）：轴截面里，直角边是 $h = 4$ 与 $\dfrac{a}{2} = 3$，故 $h' = \sqrt{4^2+3^2} = \sqrt{25} = 5$；
2. **底面周长**：$C = 4\times 6 = 24$；
3. **侧面积**：$S_{侧} = \dfrac12 C h' = \dfrac12\times 24\times 5 = 60$；
4. **底面积**：$S_{底} = 6^2 = 36$；
5. **表面积**：$S_{表} = 60 + 36 = 96$。

这组数（$a=6, h=4, h'=5$）是刻意挑的：侧面三角形的高恰好是 5，与第 20 课的 3-4-5 遥相呼应。

**例 3（正四棱台）**：下底边长 $a = 6$、上底边长 $a' = 2$、高 $h = 2$，求侧面积与表面积。

1. **轴截面**：一个等腰梯形，上底 2、下底 6、高 2。斜高是它的腰，横向落差为 $\dfrac{6-2}{2} = 2$；
2. **斜高**：$h' = \sqrt{2^2 + 2^2} = \sqrt8 = 2\sqrt2 \approx 2.828$；
3. **两个周长**：$C = 24$，$C' = 8$；
4. **侧面积**：$S_{侧} = \dfrac12 (24 + 8)\times 2\sqrt2 = 16\times 2\sqrt2 = 32\sqrt2 \approx 45.25$；
5. **表面积**：$S_{表} = 32\sqrt2 + 36 + 4 \approx 85.25$（两个底面都要加：下底 36、上底 4）。

怎么玩：横轴 $x$ 扮演"高 $h$"；拖 $a$ 改底面边长（默认 $a = 6$ 的正方形，周长 $C = 4a = 24$）。蓝色直线是**柱**的侧面积 $24h$——随高线性增长。橙色曲线是**锥**的侧面积 $12\sqrt{h^2+9}$。拖 $a$ 时两条线一起等比缩放，它们的**比值始终不变**——因为 $C$ 在两条公式里都只出现一次。

- 在 $h = 4$ 处读一下：蓝线 96，橙线 60——正是例 2 里的两个数，锥面省了整整 36；
- 把 $h$ 调到很小（比如 0.5）：锥的侧面几乎"趴"在底面上，斜高只降到 $h' \approx 3.04$，橙线仍有 36.5，而蓝线只剩 12——矮胖的锥相当费侧面；
- 把 $h$ 调到很大（比如 8）：蓝线 192、橙线约 102.5。注意这里**两条线并没有靠拢，而是稳定在 1:2 附近**——因为 $h$ 很大时 $h' = \sqrt{h^2+9} \approx h$，于是 $\dfrac{S_{锥}}{S_{柱}} = \dfrac{\frac12 C h'}{C h} \approx \dfrac12$。斜高与**高**的比值趋于 1，但柱的公式比锥的公式多着一个 $\dfrac12$，所以两条线差着整整一倍。

这个对比值得记住：体积上锥是柱的 $\dfrac13$（第 45 课），**侧面用料上可不是**——高越大，锥面用料越接近柱面的一半，而不是三分之一。

### 实验 2（python）：斜高 ≠ 高，差多少一张表看清

```python title="用错高会少算多少：正四棱锥侧面积对照表"
import math                       # 数学工具箱

a = 6.0                           # 底面边长
for h in [2.0, 4.0, 6.0, 10.0]:   # 取几个不同的高
    slant = math.sqrt(h * h + (a / 2) ** 2)   # 斜高：直角三角形 (h, a/2) 的斜边
    right = 0.5 * (4 * a) * slant             # 正确：用斜高
    wrong = 0.5 * (4 * a) * h                 # 错误：拿高顶替斜高
    print(h, round(slant, 3), round(right, 1), round(wrong, 1))
```

输出四行：`2.0 3.606 43.3 24.0`、`4.0 5.0 60.0 48.0`、`6.0 6.708 80.5 72.0`、`10.0 10.44 125.3 120.0`。

盯住第三列与第四列的差：$h = 2$ 时用错会少算 19.3（$43.3 \to 24.0$，差了四成多），$h = 10$ 时只少算 5.3（$125.3 \to 120.0$，差约 4%）。规律是：**矮胖的锥最经不起这个错误**——因为扁的时候 $h'$ 与 $h$ 差得最远（$h=2$ 时 $3.606$ 对 $2.0$），越尖越接近（$h=10$ 时 $10.44$ 对 $10.0$）。

### 实验 3（python）：展开图思想——逐个面加起来，验证周长公式

```python title="六棱柱：六个矩形逐个加，与「周长 × 高」是否一样"
import math

n = 6                             # 六棱柱
a = 2.0                           # 底面边长
h = 5.0                           # 高

one_face = a * h                  # 一个侧面是矩形：边长 × 高
total = one_face * n              # n 个侧面逐个加起来（展开图的算法）
formula = (n * a) * h             # 直接用「底面周长 × 高」
print(round(total, 1), round(formula, 1))   # 60.0 60.0

tri = math.sqrt(3) / 4 * a * a    # 边长 2 的正三角形面积（由勾股定理推出）
base_area = n * tri               # 正六边形 = 6 个这样的正三角形
surface = formula + 2 * base_area # 表面积 = 侧面积 + 两个底面
print(round(base_area, 3), round(surface, 2))
```

第一行输出 `60.0 60.0`——逐个面相加与"周长 × 高"完全相等，公式不是硬背的，它就是"把展开图拼成一个大矩形"这件事的简写。第二行输出 `10.392 80.78`：一个底面积 $6\sqrt3 \approx 10.392$，表面积 80.78，与例 1 手算一致。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为正棱锥侧面积公式 $\frac12 C h$ 里那个 $h$ 就是棱锥的高。" 其实是**斜高** $h'$——它是侧面三角形的高，从锥顶斜着量到底边中点，由勾股定理 $h' = \sqrt{h^2 + r_{内}^2}$ 给出，**永远比高 $h$ 大**。直接代入高，侧面积必然**少算**。

**误区二**："你以为任何棱柱都能用『底面周长 × 高』。" 只有**直**棱柱（侧棱垂直于底面）才行：此时侧面是矩形，展开才拼成大矩形。斜棱柱的侧面是平行四边形，它摊开后的高是"两底面之间的斜距"，比 $h$ 长，$C\cdot h$ 会少算。看到题面写"直棱柱/正棱柱"才敢用。

**误区三**："你以为算完侧面积就完事了。" 题目问**表面积**还要加上底面积：棱柱加**两个**底，棱锥加**一个**底，棱台加上、下**两个**底。反过来，若题目只问"侧面积"（比如只给罐子贴一圈标签、不封顶不封底），就千万别加。看清问的是哪一个。

:::

## 8. 选读与边界

<details>
<summary>选读 · 棱台侧面积公式从哪来（大锥减小锥）</summary>

棱台是用平行于底面的平面截掉小锥后剩下的部分。设原来的大正棱锥底面周长为 $C$、斜高为 $H'$；被截去的小锥底面周长为 $C'$、斜高为 $H'_{小}$。

因为截面平行于底面，由**相似**（第 25 课）知小锥与大锥的相似比为 $k = \dfrac{C'}{C}$，于是 $H'_{小} = kH'$。棱台的斜高是两者之差：

$$h' = H' - kH' = (1-k)H' \quad\Longrightarrow\quad H' = \frac{h'}{1-k}$$

侧面用"大减小"来算：

$$S_{侧} = \frac12 C H' - \frac12 C' (kH') = \frac12 C H' - \frac12 (kC)(kH') = \frac12 C H'(1 - k^2)$$

代入 $H' = \dfrac{h'}{1-k}$：

$$S_{侧} = \frac12 C\cdot \frac{h'}{1-k}\cdot (1-k)(1+k) = \frac12 C h'(1+k) = \frac12 (C + kC)h' = \frac12 (C + C')h'$$

正是第 3 节的公式。中间那步 $(1-k^2) = (1-k)(1+k)$ 的约分，是整个推导的关键。

顺带看两个退化情形：$k \to 0$（上底缩成一点）时公式变成 $\frac12 C h'$，即**棱锥**公式；$k \to 1$（上下底一样）时变成 $\frac12(2C)h' = C h'$，即**棱柱**公式——三条公式其实是一家子，棱台公式是通式。
</details>

### 本课不管什么

- **斜棱柱、斜棱锥、一般棱台**：没有统一的斜高，只能逐个面算面积再相加；
- **圆锥、圆台的侧面积**：形状上完全同构（$S_{侧} = \pi r l$、$\pi(r_1+r_2)l$，$l$ 是母线长），但它们是旋转体，弧长与展开扇形的处理另有一套说辞，本章不展开；
- **最短路径（立体表面上的爬行路线）**：把侧面摊平再连直线是经典技巧，需要展开图与勾股定理配合，属题型训练；
- **最省料问题**："给定体积，什么形状表面积最小"是优化问题，需要导数，第 13 章才有工具。

## 9. 下一站

几何篇到此收官：从角度、勾股、相似、圆 π，到平面坐标系、体积、空间坐标、球，再到柱锥台的用料账——丈量形状的十八般兵器已经齐了。可这些图形全都**静止**在那里：画好一个圆，它不会变。
