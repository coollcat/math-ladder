# 角度与三角形：内角和为什么恒是 180°

## 1. 从一个场景开始

钟表指向 3 点整，时针和分针的夹角是多少？木匠锯木头时随口说："甭管我锯出什么形状的三角形，三个角加起来准是 180 度。"——随便锯都成立？一个从不量角度的人，凭什么敢打包票？

这一课我们就把"角"到底是什么、以及这条 180° 规律的来历，一次弄清楚。

## 2. 直觉解释

**角不是长度，是"转过的量"。**

想象一根指针从指向 12 的位置开始转：

- 转到指向 3——扫过了四分之一圈，所以 3 点整的夹角是 $360° \div 4=90°$；
- 转到指向 6——扫过半圈；
- 转回 12——整整一圈。

角记录的就是这个**旋转量**。两条边画多长根本不重要，重要的是张口有多大。

再看三角形的三个内角。做个纸面实验：剪一个任意三角形，把它的三个角撕下来，往一条直线上拼——你会发现它们**不多不少恰好铺满一条直线**。而"铺满直线"的那个平角正是 180°。这不是巧合，选读部分会给出完整理由。

## 3. 正式定义

**角**：从同一点出发的两条射线张开的程度。顶点为 A、两边经过 B 和 C 的角记作 $\angle BAC$（简写 $\angle A$），用**度**（符号 °）计量，规定一整圈为 $360°$。

| 符号 | 读作 | 含义 |
| --- | --- | --- |
| $\angle A$ | 角 A | 顶点在 A 处的角 |
| $°$ | 度 | 旋转量的单位，一周 $=360°$ |
| $\triangle ABC$ | 三角形 ABC | 以 A、B、C 为顶点的三角形 |
| 平角 | 平角 | $180°$，两臂拼成一条直线 |

为什么一周定为 360？这来自古巴比伦的六十进制：360 能被 2、3、4、5、6、8、9、10、12……整除，切起来最方便，于是沿用至今。

**内角和定理**：平面三角形三个内角之和恒为 180°：

$$\angle A + \angle B + \angle C = 180°$$

按最大角的类型给三角形分类：

| 类型 | 特征 | 例子 |
| --- | --- | --- |
| 锐角三角形 | 三个角全部小于 $90°$ | $60°, 60°, 60°$ |
| 直角三角形 | 恰有一个角等于 $90°$ | $90°, 60°, 30°$ |
| 钝角三角形 | 恰有一个角大于 $90°$ | $100°, 40°, 40°$ |

注意每类最多只有一个"大角"——两个不小于 $90°$ 的角加起来就已达到 180°，第三个角就没地方待了。

## 4. 分步例题

**例**：三角形中两个角分别是 $65°$ 和 $48°$，求第三个角。

1. 写出铁律：$\angle A + \angle B + \angle C = 180°$
2. 代入已知：$65 + 48 + \angle C = 180$
3. 算出已知部分：$65 + 48 = 113$
4. 移项求解（第 4 章解方程的老套路）：$\angle C = 180 - 113 = 67°$

顺手分类：最大角 $67° < 90°$，三个角都是锐角——这是一个锐角三角形。

## 5. 动手实验

### 实验 1（viz）：拖顶点，看内角和

```viz
{
  "type": "triangle",
  "title": "拖动三个顶点",
  "points": [[0.18, 0.78], [0.85, 0.72], [0.45, 0.14]]
}
```

怎么玩：按住彩色圆点随意拖动三个顶点，把三角形拉得又扁又歪也没关系——顶部读数 $\angle A+\angle B+\angle C$ 始终钉死在 180°，下方还会实时判断它是锐角、直角、钝角还是接近压扁。键盘路径：先点一下画布，再按 `1`/`2`/`3` 选中顶点，用方向键微调（配合 Shift 更精细）。试着把某个角调到接近 90°，看看另外两个角之和是不是自动变成约 90°。

### 实验 2（python）：随机把 180° 拆成三角形

反过来玩：不看图形，直接把 180° 随机切成三份，每一份组合都应该是一个合法三角形，程序还能自动分类：

```python title="随机切 180°，自动分类三角形"
import random  # 随机数工具，第 0 章登场的老朋友

cut1 = random.randint(20, 140)        # randint(a, b)：含两端的随机整数——第一份的大小
rest = 180 - cut1                     # 切走一份后还剩多少度
cut2 = random.randint(20, rest - 20)  # 再切一份，但保证第三份至少剩 20°
ang3 = 180 - cut1 - cut2              # 最后一份：剩下的全部

print(f"三个内角: {cut1}°、{cut2}°、{ang3}°")
print(f"检查总和: {cut1 + cut2 + ang3}")

largest = cut1                        # 打擂台找最大角：先让 cut1 当擂主
if cut2 > largest:                    # 谁更大谁上台
    largest = cut2
if ang3 > largest:
    largest = ang3

if largest == 90:
    kind = "直角三角形"
elif largest > 90:
    kind = "钝角三角形"
else:
    kind = "锐角三角形"
print(f"分类: {kind}")
```

怎么玩：反复点击运行，每次得到形状不同的"纸片三角形"——但总和永远是 180，分类永远三者其一。

### 实验 3（python）：拖滑块，第三个角自动补齐

内角和定理的另一面是"锁死"：只要两个角定了，第三个角就没了自由。拖动滑块给 $\angle A$、$\angle B$ 分配度数，机器立刻补出剩下的 $\angle C$：

```python title="滑块实验：已知两角求第三角"
# sliders: a=65 [10:160:1], b=48 [10:160:1]
# a、b 由滑块注入（单位：度），代码里不用再赋值
c = 180 - a - b   # 内角和定理移项：C = 180° − A − B
print(f"A={a}°, B={b}° -> C={c}°")

if c <= 0:                     # if：两个角的和已经达到或超过 180°
    print("这两个角凑不成三角形！把其中一个调小些")
else:
    print(f"验算总和: {a + b + c}")
```

试一试：把 $a$、$b$ 都拖到 100 以上——第三个角变成负数，这三份度数就不再能围成三角形。这正是误区二那句"两个大角挤不进同一个三角形"的数值版：内角和定理不只用来算题，还负责把关。

### 快问快答

```quiz
一个三角形已经有两个直角，可能吗？
- 可能，只要第三个角很小
- 不可能，两个直角已占满 180° [*]
- 可能，只要它是特殊三角形
? 内角和恒为 180°：90 + 90 = 180 之后，第三个角只能是 0°，那就压扁成线段了。
```

:::warning[常见误区]

**误区一**："你以为角的大小跟边画多长有关。" 其实角只看旋转量（张口），边延长到天边度数也不变。

**误区二**："你以为三角形可以有两个钝角或直角。" 其实两个不小于 90° 的角加起来就不少于 180°，留给第三个角的空间只剩 0。

**误区三**："你以为内角和 180° 是大量测量后的近似规律。" 其实它是严格定理，对一切平面三角形精确成立——实验只是提供信心，证明才是保证。

:::

## 6. 练习

**练习 1**：一个直角三角形中，其中一个锐角是 $37°$，另一个锐角是多少度？下面的代码能跑但答案不对，改到通过：

```exercise
# @title: 练习：直角三角形的另一个锐角
# @check: 53
# @hint: 内角和 180，其中直角已占走 90——别忘了把它减掉
print(180 - 37)
```

<details>
<summary>点开查看逐步解答</summary>

直角占 $90°$，另一个锐角是：

```python
print(180 - 90 - 37)
```

输出 `53`，所以另一个锐角是 **53°**。验算：$90° + 37° + 53° = 180°$ ✓。
</details>

**练习 2**：等腰三角形顶角为 $40°$，两个底角各是多少？

<details>
<summary>点开查看逐步解答</summary>

等腰三角形两个底角相等，设每个为 $x$：

1. 列方程：$40 + x + x = 180$
2. 合并：$40 + 2x = 180$
3. 移项：$2x = 140$
4. 求解：$x = 70°$

验证：$40 + 70 + 70 = 180$ ✓。这是一个底角 70° 的锐角等腰三角形。
</details>

**练习 3**：判断并说理由："把三角形变大（边长翻倍），内角和也会翻倍。"

<details>
<summary>点开查看逐步解答</summary>

错。放大只是把图形整体拉伸相似，三个角**一个度数都不变**，内角和仍是 180°。

变的只是边长和面积——边长翻倍后面积变 4 倍，这正是下一课的主角。
</details>

## 7. 选读：为什么内角和恒是 180°

<details>
<summary>选读 · 把三个角"摊平"的证明</summary>

关键一步：把三角形 ABC 放在一条直线上——延长 BC 到 D，再过 C 作一条与 AB 平行的直线 CE。

平行线带来两个礼物（"内错角相等"，用尺规可严格验证）：

1. $\angle A = \angle ACE$（AB 与 CE 平行）；
2. $\angle B = \angle ECD$（同理）。

于是以 C 为顶点的三个角 $\angle ACB$、$\angle ACE$、$\angle ECD$ 恰好拼满一条直线：

$$\angle ACB + \angle A + \angle B = 180°$$

翻译一下：我们把 A 处的角和 B 处的角**平移搬运**到了 C 处，三个角摊成了一条直线。撕纸实验其实就是这个证明的手工版。

</details>
