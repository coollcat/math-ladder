# 圆周角：站在圆上看同一段弧

## 1. 从一个场景开始

球门宽 7.32 米，球员带球在场上跑。射门时真正要紧的不是离球门多远，而是**看球门的张角**有多大——角度越大，门显得越宽，越容易打进。

教练在场上画了一条弧线，说："沿这条弧跑，你看球门的张角处处相同；往里切一层，张角就整整齐齐地变大。"

凭什么？为什么圆弧上的点会共享同一个视角？答案是一个把"圆心"和"圆周"拴在一起的定理——圆周角定理。

## 2. 直觉解释

同一个角，可以有两种站法：

- **圆心角**：顶点站在圆心 $O$，两边是两条半径；
- **圆周角**：顶点站在圆周上，两边是两条**弦**。

关键直觉：把顶点从圆心**往外挪到圆周上**，张口会自动缩小，而且刚好缩成一半。

为什么是一半？作一条过顶点 $P$ 与圆心 $O$ 的直线，它再往前撞到圆上一点 $M$，于是 $PM$ 是一条**直径**。看三角形 $OAP$：$OA = OP$（都是半径），它是个等腰三角形，两个底角相等。而圆心角 $\angle AOM$ 正好是这个三角形的**外角**——外角等于两个不相邻内角之和，于是

$$\angle AOM = \angle OAP + \angle APO = 2\angle APO$$

一句话：**一个等腰三角形的外角，是它的底角的两倍。** 圆周角定理就是把这句话用两次（或一次），再把结果相加或相减。

## 3. 正式定义

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| 圆心角 | 圆心角 | 顶点在**圆心**，两边是半径 |
| 圆周角 | 圆周角 | 顶点在**圆上**，两边都与圆相交（都是弦） |
| 所对的弧 | 所对的弧 | 角的两条边之间夹住的那段圆周 |
| 圆内接四边形 | 圆内接四边形 | 四个顶点都在同一个圆上的四边形 |
| 外接圆 | 外接圆 | 经过四边形（或三角形）全部顶点的那个圆 |

**圆周角定理**：一条弧所对的圆周角，等于它所对**圆心角的一半**。

$$\angle APB = \frac{1}{2}\angle AOB \qquad (P \text{ 与 } O \text{ 在弦 } AB \text{ 的同侧约定见下})$$

**推论一（同弧等角）**：同弧或等弧所对的圆周角相等。

**推论二（直径对直角）**：直径（半圆）所对的圆周角是直角；反过来，$90°$ 的圆周角所对的弦是直径。

**推论三（圆内接四边形）**：圆内接四边形的**对角互补**；并且任何一个外角都等于它的**内对角**。

**务必说"同弧"而不是"同弦"**：一条弦把圆切成**两段**弧，站在两段不同的弧上，看到的是两个互补的角（$60°$ 与 $120°$）。说"同弦"会同时指到两个答案。

## 4. 分步例题

**例**：圆中圆心角 $\angle AOB = 120°$，点 $P$ 在**优弧** $AB$ 上，点 $Q$ 在**劣弧** $AB$ 上。求 $\angle APB$ 与 $\angle AQB$，并验证圆内接四边形 $AQBP$ 的对角和。

1. 认弧：$P$ 在优弧上，它看到的是**劣弧** $AB$，劣弧所对圆心角是 $120°$；
2. 套定理：$\angle APB = \dfrac{120°}{2} = 60°$；
3. $Q$ 在劣弧上，它看到的是**优弧** $AB$，优弧所对圆心角是 $360° - 120° = 240°$；
4. 再套定理：$\angle AQB = \dfrac{240°}{2} = 120°$；
5. 排顺序：沿圆周依次是 $A \to Q \to B \to P$，故四边形 $AQBP$ 的一组对角是 $\angle Q$ 与 $\angle P$；
6. 验账：$\angle AQB + \angle APB = 120° + 60° = 180°$ ✓——对角互补，与推论三严丝合缝。

## 5. 动手实验

### 实验 1（viz）：先看清"被看的那段弧"


怎么玩：橙色弧是圆心角 $120°$ 张出的那一段，读数告诉你它占整圆的 $\tfrac13$、弧长约 $6.28$，虚线弦长约 $5.20$。记住这段弧——下面要问的正是：**站到圆周上去看它，视角是多少？** 定理给出的答案是圆心角的一半，即 $60°$。

### 实验 2（python）：正六边形里，$30°$ 与 $60°$ 并排站着

正六边形的六个顶点都在同一个圆上，而且相邻两点的距离恰好等于半径。用它当"量角器"，全程不需要任何三角函数：

```python title="把圆周角与圆心角画在一起"
import matplotlib.pyplot as plt    # 画图工具箱

r = 2                              # 半径
s3 = 3 ** 0.5                      # √3：等边三角形的高，由勾股定理开出来
# 半径 2 的圆上六个点：相邻两点距离都等于半径，顺次连起来是正六边形
V = [(r, 0), (r/2, r*s3/2), (-r/2, r*s3/2), (-r, 0), (-r/2, -r*s3/2), (r/2, -r*s3/2)]

fig, ax = plt.subplots(figsize=(5.5, 5))
ax.add_patch(plt.Circle((0, 0), r, fill=False, color="#2563eb", lw=2))   # 外接圆
ax.plot([p[0] for p in V] + [V[0][0]], [p[1] for p in V] + [V[0][1]], color="#cbd5e1", lw=1)  # 六条边
ax.plot([V[0][0], V[3][0]], [V[0][1], V[3][1]], color="#94a3b8", lw=1, ls="--")   # 直径 V0V3
ax.plot([V[0][0], V[1][0]], [V[0][1], V[1][1]], color="#dc2626", lw=3)            # 被"看"的那条弦
ax.plot([V[3][0], V[0][0]], [V[3][1], V[0][1]], color="#059669", lw=2)            # 站在 V3 看弦
ax.plot([V[3][0], V[1][0]], [V[3][1], V[1][1]], color="#059669", lw=2)
ax.plot([V[4][0], V[0][0]], [V[4][1], V[0][1]], color="#d97706", lw=2)            # 站在 V4 看同一条弦
ax.plot([V[4][0], V[1][0]], [V[4][1], V[1][1]], color="#d97706", lw=2)
ax.plot(0, 0, "o", color="#0f172a")
for i, p in enumerate(V):          # 给六个顶点挂上名字牌
    ax.annotate(f"V{i}", (p[0], p[1]), xytext=(6, 6), textcoords="offset points")
ax.set_aspect("equal")             # 横纵同尺度，圆才不会被压成椭圆
ax.set_xlim(-r - 0.8, r + 0.8)
ax.set_ylim(-r - 0.8, r + 0.8)
plt.show()
```

怎么玩：绿色的是站在 $V3$ 看弦 $V_0V_1$ 的视角，橙色的是站在 $V4$ 看同一条弦的视角——**两条线的张口看起来一模一样**。而红色弦 $V_0V_1$ 与两条半径 $OV_0$、$OV_1$ 围成的三角形，三边都是半径，是个等边三角形，圆心角 $60°$。下面用数值把这件事钉死。

### 实验 3（python）：不用三角函数，也能把圆周角验一遍

```python title="用勾股定理与全等，验收圆周角定理"
import math

r = 2
s3 = 3 ** 0.5
V = [(r, 0), (r/2, r*s3/2), (-r/2, r*s3/2), (-r, 0), (-r/2, -r*s3/2), (r/2, -r*s3/2)]

def dist(p, q):                    # 两点距离：横差、纵差当直角边，勾股定理求斜边
    return math.sqrt((p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2)

V0, V1, V3, V4 = V[0], V[1], V[3], V[4]

print("六点到圆心的距离:", [round(dist(p, (0, 0)), 6) for p in V])
print("三角形 OV0V1 的三边:", [round(dist(V0, (0, 0)), 6), round(dist(V1, (0, 0)), 6), round(dist(V0, V1), 6)])

a, b, c = dist(V0, V1), dist(V1, V3), dist(V0, V3)
print(f"勾股逆定理: V0V1² + V1V3² = {round(a ** 2 + b ** 2, 6)}，V0V3² = {round(c ** 2, 6)}")

t1 = sorted([round(dist(V0, V1), 6), round(dist(V1, V3), 6), round(dist(V0, V3), 6)])
t2 = sorted([round(dist(V0, V4), 6), round(dist(V4, V1), 6), round(dist(V0, V1), 6)])
print("站在 V3 看的三角形三边:", t1)
print("站在 V4 看的三角形三边:", t2)
```

怎么玩：四行输出各说一件事。

1. 六点到圆心都是 $2.0$——它们真在同一个圆上；
2. $\triangle OV_0V_1$ 三边都是 $2.0$，是**等边三角形**，故圆心角 $\angle V_0OV_1 = 60°$；
3. $V_0V_3$ 是直径（长 $4$），而 $V_0V_1^2 + V_1V_3^2 = 16 = V_0V_3^2$——由**勾股定理的逆定理**，$V_1$ 处是直角。这就是推论二"直径所对的圆周角是直角"的数值现场；
4. 最后两行完全一样：$[2.0,\ 3.464102,\ 4.0]$。两个三角形三边对应相等 → **全等**（SSS）→ $V_3$ 与 $V_4$ 处那两个角相等，即推论一"同弧所对的圆周角相等" ✓。

至于这个角到底是多少度：站在 $V_3$ 的三角形是 $2 : 2\sqrt{3} : 4$，把它除以 $2$ 就是 $1 : \sqrt{3} : 2$——把等边三角形沿高对半切开的经典直角三角形，最短边（斜边的一半）所对的角是 $30°$。而圆心角是 $60°$：$30° = 60° \div 2$ ✓ 定理验毕，全程没请三角函数。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为同一条弦所对的圆周角都相等。" 其实一条弦把圆切成**两段弧**，站在两段不同的弧上，看到的是两个**互补**的角——$60°$ 与 $120°$。定理说的是"**同弧**所对的圆周角相等"，不是"同弦"。

**误区二**："你以为圆周角就是圆心角。" 其实它是圆心角的**一半**。忘记除以 2 是最经典的失分点：圆心角 $120°$ 对应圆周角 $60°$，反过来给圆周角 $60°$ 要先把圆心角还原成 $120°$。

**误区三**："你以为圆内接四边形任意两个角都互补。" 互补的只有**对角**（相隔一个顶点的那两个）。相邻的角是**邻角**，它们的和可以是任何值。

:::

<summary>点开查看逐步解答</summary>

1. **对角互补**（推论三）：$\angle C = 180° - 100° = 80°$；

## 8. 选读与边界

<details>
<summary>选读 · 圆周角定理的完整证明</summary>

设圆周角 $\angle APB$ 与圆心角 $\angle AOB$ 对着同一段弧 $AB$。把射线 $PO$ 延长，撞圆于 $M$，则 $PM$ 是直径。

**基础事实**：三角形 $OPA$ 中 $OP = OA = r$，是等腰三角形，故 $\angle OPA = \angle OAP$。而 $\angle AOM$ 是它的一个外角，外角等于两个不相邻内角之和：

$$\angle AOM = \angle OPA + \angle OAP = 2\angle OPA = 2\angle APM$$

同理，把 $A$ 换成 $B$ 得 $\angle BOM = 2\angle BPM$。

接下来分三种情况，区别只在于 $A$、$B$ 落在 $PM$ 的同侧还是异侧：

1. **圆心在圆周角的一条边上**（$M$ 与 $A$ 或 $B$ 重合）：基础事实本身就是结论，$\angle AOB = 2\angle APB$；
2. **圆心在圆周角内部**（$A$、$B$ 分居 $PM$ 两侧）：$\angle AOB = \angle AOM + \angle BOM = 2\angle APM + 2\angle BPM = 2\angle APB$；
3. **圆心在圆周角外部**（$A$、$B$ 在 $PM$ 同侧）：$\angle AOB = \angle AOM - \angle BOM = 2\angle APM - 2\angle BPM = 2\angle APB$。

**推论三的证明**：四边形 $ABCD$ 内接于圆，$\angle A$ 对着弧 $BCD$、$\angle C$ 对着弧 $BAD$。这两段弧首尾相接正好是**整个圆周** $360°$，于是

$$\angle A + \angle C = \tfrac12(\text{弧 } BCD) + \tfrac12(\text{弧 } BAD) = \tfrac12 \times 360° = 180°$$

外角等于内对角，则是"邻补角 $180° - \angle C$"与"$\angle A = 180° - \angle C$"两句话合起来的同一个数。

</details>

### 本课不管什么

- 只用角度，不涉及弧长与角度的互换——那是**弧度制**，第 7 章的入场券；
- 圆周角定理在圆被换成椭圆、抛物线时不成立，"同弧等角"是圆独有的性质；
- 顶点落在圆**内**（不是圆上）或圆**外**时的"视角公式"是另一套，本课不处理。

## 9. 下一站

站在圆周上看，视角是圆心角的一半。那如果一条边干脆不穿过圆，只是**擦着圆边过去**——那条线叫切线，它与圆只碰一个点。擦过去的角（弦切角）居然和圆周角严格相等，而圆外一点引出的两条切线长也严格相等。
