# 四边形家族：平行四边形的判定

## 1. 从一个场景开始

工厂要批量切一批平行四边形钢板（比如伸缩门的联动片）。验收员照旧只带卷尺，不许把钢板搬去和样品对叠。上一课三角形靠三条边就领到了身份证；可四边形天生比三角形多一处"会动的地方"——伸缩门推得动、晾衣架拉得开，全是它的功劳。

会动的图形，身份证怎么发？量哪些数据，才能拍板"这是一块端端正正的平行四边形"？

## 2. 直觉解释

先看平行四边形是怎么"生"出来的：拿一条线段，**沿着一个箭头平移**——线段滑过的两道轨迹彼此平行，起点连线与终点连线也彼此平行。一个平行四边形拔地而起。

所以它的名字就是定义：**两组对边分别平行**的四边形。

而判定它，靠的是一招"化归"：连一条**对角线**，四边形立刻切成两个三角形——上一课的全等三判据（SSS/SAS/ASA）重新上岗。三角形的身份证制度没有白建，四边形的一切判定都走全等这座桥。

内角和铁律也跟着扩军一次：连一条对角线，四边形分成两个三角形，每个内角和 180°——

$$\text{四边形内角和} = 180° + 180° = 360°$$

## 3. 正式定义

**平行四边形**：两组对边分别平行的四边形，记作 $\square ABCD$（顶点按顺序书写）。

性质与判定是一对镜子：**性质**是"是了之后必然有什么"，**判定**是"有了什么就能发证"。成对记，一面镜子两面看：

| 性质（是了必有） | 判定（有了发证） |
| --- | --- |
| 两组对边分别平行（定义） | 两组对边分别平行 |
| 两组对边分别相等 | 两组对边分别相等 |
| 一组对边平行**且**相等 | 一组对边平行且相等 |
| 两组对角分别相等 | 两组对角分别相等 |
| 对角线**互相平分** | 对角线互相平分 |
| 邻角互补（$\angle A + \angle B = 180°$） | ——（由对角判定推得） |

| 符号/术语 | 含义 |
| --- | --- |
| $\square ABCD$ | 平行四边形 ABCD，顶点沿边界顺序书写 |
| 对角线 | 不相邻两顶点的连线（$AC$ 与 $BD$），把四边形切成两个三角形 |
| 互相平分 | 两条对角线的**交点**把每条对角线分成相等的两段——不是两条对角线一样长 |
| 邻角 / 对角 | 共用一条边的两角是邻角；隔着一个顶点相对的是对角 |

## 4. 分步例题

**例 1（性质在算账）**：$\square ABCD$ 中 $\angle A = 65°$，求其余三个角。

1. **对角相等**：$\angle C = \angle A = 65°$；
2. **邻角互补**：$\angle B = 180° - 65° = 115°$（内角和倒扣一轮）；
3. **对角再兑现**：$\angle D = \angle B = 115°$；
4. **总账校验**：$65 + 115 + 65 + 115 = 360$ ✓——两个三角形的预算分毫不差。

**例 2（判定在验收）**：钢板四边形上量得对角线交点 $M$：$AM = 3$、$MC = 3$、$BM = 2.5$、$MD = 2.5$。它是平行四边形吗？

1. **逐条核对**：$AC$ 被分成 $3 = 3$，自身平分 ✓；$BD$ 被分成 $2.5 = 2.5$，自身平分 ✓；
2. **套判定**：对角线互相平分 → 发证，是平行四边形；
3. **白拿赠品**：既然是了，对边相等、对角相等全部到账——量四个数据，一整块钢板的账都能推出来。

## 5. 动手实验

### 实验 1（python 滑块）：拖一个角，锁死其余三个

平行四边形的四个角是一台联动机器：拖动 $\angle A$，看看谁跟着动、谁纹丝不动：

```python title="滑块实验：平行四边形的角度联动机器"
# sliders: a=65 [10:170:1]
# a 由滑块注入（单位：度），代码里不用再赋值
b = 180 - a                   # 邻角互补：内角和铁律倒扣一轮
print(f"对角 ∠C = {a}°")      # 对角相等：跟着 a 一起动
print(f"邻角 ∠B = ∠D = {b}°") # 另一对对角，永远与 a 凑成 180
print(f"四角总账: {a + b + a + b}")   # 无论如何拖，恒为 360
```

怎么玩：把 $a$ 拖到 90（矩形闪现）、拖到接近 10（挤成一把细刀）——对角永远与 $a$ 相同，邻角永远互补，总账永远 360。**角度任你拖，结构纹丝不动**：这就是"形状稳住、姿态自由"的平行四边形。

### 实验 2（python）：对角线"平分"验收器

最常见的验收误会在"平分"两个字上。先看一块**不合格**的板：

```python title="对角线验收器：这块板过不了关"
am = 3.0    # 对角线 AC 被交点 M 分成的上半段
mc = 3.0    # AC 的下半段
bm = 2.5    # 对角线 BD 的上半段
md = 4.0    # BD 的下半段——这里不对劲

print(am == mc)    # == 判断两段是否相等：AC 自己被平分了吗
print(bm == md)    # BD 自己被平分了吗
```

输出 `True` 和 `False`：$AC$ 平分了，$BD$ 没有——判定不过关，这不是平行四边形。把 `md` 改成 `2.5` 再跑一次，两道检查齐绿，发证。注意陷阱：$AC$ 总长 $6$ 与 $BD$ 总长 $6.5$ 本来就不必相等；**就算两条对角线总长恰好相等，也不叫平分**——平分是"每条自己被交点切成相等两半"。

### 快问快答

```quiz
一个四边形有一组对边平行，另一组对边相等——它一定是平行四边形吗？
- 一定是，凑够两条好事了
- 一定不是
- 不一定，可能是等腰梯形 [*]
? "一组对边平行且相等"才是发证条件——平行的一组与相等的一组必须是同一组。等腰梯形恰好是反例：上底与下底平行，两条腰相等，可它不是平行四边形。
```

::::warning[常见误区]

**误区一**："你以为一组对边相等就是平行四边形。" 等腰梯形两腰相等，却只有一组对边平行。发证条件要么是**两组**对边分别相等，要么是**同一组**对边"平行且相等"。

**误区二**："你以为对角线相等的四边形就是平行四边形。" 等腰梯形的对角线也相等。判定只认"**互相平分**"——交点切出来四段各自成对相等。

**误区三**："你以为四个角都是直角才算平行四边形。" 那是矩形——家族里态度最端正的成员，但平行四边形不挑角度：拖歪的、挤扁的，只要两组对边平行就还在家族里。

::::

## 6. 练习

**练习 1（判题）**：验收另一块板：交点把 $AC$ 分成 $3.0$ 和 $3.0$，把 $BD$ 分成 $2.5$ 和 $2.5$。下面的代码能跑但结论不对——写它的人把"互相平分"理解成了"两条对角线一样长"，改到两条检查全部通过：

```exercise
# @title: 练习：平分不是一样长
# @check: True
# @check: True
# @hint: 「互相平分」说的是每条对角线**自己**被交点分成相等的两段：分别比较 am 与 mc、bm 与 md。两条对角线总长一样不代表平分。
am = 3.0    # 对角线 AC 的上半段
mc = 3.0    # 对角线 AC 的下半段
bm = 2.5    # 对角线 BD 的上半段
md = 2.5    # 对角线 BD 的下半段

print(am + mc == bm + md)    # ← 写这行的人把「平分」当成了「一样长」
print(bm == md)              # 这行的思路是对的
```

<details>
<summary>点开查看逐步解答</summary>

第一行算的是总长：$3.0 + 3.0 = 6.0$ 与 $2.5 + 2.5 = 5.0$，并不相等，输出 `False`——可"总长相等"压根不是发证条件。要查的是**每条对角线自身是否被交点等分**：

```python
am = 3.0
mc = 3.0
bm = 2.5
md = 2.5

print(am == mc)    # AC 自己被平分了吗 → True
print(bm == md)    # BD 自己被平分了吗 → True
```

输出 `True`、`True`，对角线互相平分，发证 ✓。这块板总长 6.0 对 5.0"不一样长"，照样是堂堂正正的平行四边形——验收员的眼睛要盯在"切成两半"上。
</details>

**练习 2**：$\square ABCD$ 的周长是 28，其中 $AB = 6$，求 $BC$。

<details>
<summary>点开查看逐步解答</summary>

对边相等：$AB = DC = 6$，两条占去 $12$；剩下的预算分给另一对对边：

$$BC = AD = \frac{28 - 12}{2} = 8$$

校验：$6 + 8 + 6 + 8 = 28$ ✓。平行四边形的账本永远"成双成对"：知道一条边，对边白送。
</details>

**练习 3**：判断并说理由："两组对角分别相等的四边形，一定是平行四边形。"

<details>
<summary>点开查看逐步解答</summary>

对。设 $\angle A = \angle C = x$，$\angle B = \angle D = y$。四边形内角和 360°（本课开头刚扩军的铁律）：

$$2x + 2y = 360 \implies x + y = 180$$

也就是说**每个邻角都互补**。邻角互补正是"两组对边分别平行"在角度账本上的同一句话：$\angle A$ 与 $\angle B$ 凑成 180° 时，$AD$ 与 $BC$ 只能平行（把 $AB$ 平移搬运到 $DC$，对应角严丝合缝，两组对边自然对齐）。发证 ✓——严格版要等平行线的同旁内角定理，这里先用内角和平摊账本记账。

值得注意的是这条例外的堂兄弟："**一组**对角相等"发不了证——随便画个风筝形就有随便哪个角相等。
</details>

## 7. 选读与边界

### 选读 · 判定为什么都走全等这座桥

<details>
<summary>选读 · 绕 M 转半圈的发证术</summary>

以"对角线互相平分"为例。设对角线交于 $M$，已知 $AM = MC$、$BM = MD$。把 $\triangle ABM$ 绕 $M$ **旋转半圈**——全等课的刚体运动之一：

1. $A$ 走过半圈落到 $C$ 的位置（因为 $AM = MC$）；
2. $B$ 落到 $D$ 的位置（因为 $BM = MD$）；
3. $M$ 原地不动。

转完之后，$\triangle ABM$ 与 $\triangle CDM$ 完全重合 → 全等 → 对应角相等：$\angle MAB = \angle MCD$。这两个角是内错角（角度课选读里那件"平行线的礼物"，此处正式上岗）——内错角相等，$AB \parallel DC$；同理 $AD \parallel BC$。发证！

其余判定同款套路：连对角线 → 凑两个三角形全等（SSS、SAS、ASA 轮番出场）→ 对应边角相等 → 平行与相等互相兑现。**三角形的三判据，是四边形一切身份证的印钞机。**
</details>

### 选读 · 平行四边形的面积：剪一刀的老手艺

<details>
<summary>选读 · 挪一块，变矩形</summary>

沿平行四边形的一条高剪下一个直角三角形，平移拼到另一侧——歪的肩膀被"削平补齐"，变成一个矩形。面积原封不动：

$$\text{平行四边形面积} = \text{底} \times \text{高}$$

这正是[面积与勾股定理](./20-area-pythagoras.md)那课"沿对角线剪一刀"的同一门手艺：三角形是矩形的一半，平行四边形是矩形的挪位。梯形也能两枚同款拼成平行四边形——四边形家族的面积账，全走"剪拼"这条老路。

</details>

### 本课不管什么

- 只管"平行四边形"这一层发证；矩形、菱形、正方形的加码资格证是后续课的事（本课只在误区里点过名字）；
- 梯形（恰有一组对边平行）不展开，只在反例里露面；
