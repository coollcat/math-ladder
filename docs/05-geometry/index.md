# 几何入门：测量形状的学问

英文 geometry 的本义就是"丈量土地"：古埃及尼罗河每年泛滥一次，冲毁田埂，人们必须重新划分地界——测量形状的需求催生了这门最古老的数学。中国人则贡献了"勾三股四弦五"，比毕达哥拉斯早了几百年；天文学家靠同样的几何丈量了地球的周长和日月的高度。

本章十课，从"角"出发，经过测量与估算、三角形三边的惊天关系（勾股定理），给三角形发完"全等"与"相似"两级身份证、盘清四边形家族，抵达圆的核心常数 π，学会按比例切圆，最后把整个平面装进门牌号系统。它们是后面弧度制、三角函数乃至傅里叶变换的全部地基。

1. [角度与三角形](./10-angle-triangle.md)——角是"转过的量"；拖动顶点，亲眼见证内角和恒为 180° 的铁律；
2. [测量、单位与估算](./15-measure-units.md)——给数字配上单位和误差范围，让丈量变得可信；
3. [面积与勾股定理](./20-area-pythagoras.md)——从铺地砖到 $a^2+b^2=c^2$，斜边计算器 math.hypot 在此诞生；
4. [全等三角形：形状的身份证](./22-congruent-triangles.md)——验收"同一块板"只需三条边：SSS/SAS/ASA 三判据，全等是"完全重合"的正式名字；
5. [相似三角形与比例](./25-similar-triangles.md)——泰勒斯用一根木棍加两道影子称出金字塔的身高：形状相同、大小不同，去浮窗亲手放缩一把三角形，验证边长走 k、面积走 k²；
6. [四边形家族：平行四边形的判定](./27-quadrilaterals.md)——三角形稳、四边形晃：内角和与平行线的成果在此集中兑现，判定与性质成对登场；
7. [圆周率 π](./30-circle-pi.md)——所有圆共享的神秘比值，math.pi 正式登场；
8. [弧长与扇形面积](./35-arc-sector.md)——按比例切圆：一个比例号决定一切，弧度制的预告片；
9. [平面直角坐标系](./40-coordinate-plane.md)——两条数轴十字一搭，每个点领到先横后纵的数对门牌，勾股定理就地变身距离公式；
10. [体积与立体几何](./45-volume-solids.md)——一座圆锥沙堆该付多少吨的钱？把圆锥切成一千层薄饼累加出「三分之一折」，再让 plot 曲线演示体积随半径的三次方脾气。

学完本章，你会随身带上三件工具：角度、直角三角形的边长关系、还有 π——外加一张给平面所有点编号的坐标系。下一章《函数与图像》就要在这张坐标系舞台上，让几何第一次"动"起来。

## 实战挑战 · 云梯与墙角

> 改编自经典题型（初中数学"梯子滑动"模型，多省市中考常考）。

消防中队演习，一辆云梯车在楼下待命。云梯长 5 米，梯脚离墙根 3 米，墙面垂直于地面——梯子、墙、地面恰好围出一个直角三角形。

**(a)** 不爬上去量，算出云梯顶端能到多高。

**(b)** 消防员把顶端沿墙**下滑 1 米**（梯子长度不变），问梯脚要向**外**滑出多远？

**(c)** 概念思辨：木工只拿卷尺在墙角两边各量 30 厘米和 40 厘米，再量这两点间距，读到 50 厘米就宣布"标准直角"。他走的是定理还是逆定理？

把 (a)(b) 交给判题窗验证：

```exercise
# @title: 实战挑战：云梯的高度与滑动距离
# @check: 4
# @check: 1
# @hint: (a) 高度 = √(c² − a²)，用 math.sqrt 开方；(b) 下滑后顶端高度变成 height − 1，先用勾股定理反求新的梯脚距，再减去原来的 3 米。开方会带小数尾巴，包一层 round() 让输出对上期望行。
import math

ladder = 5      # 云梯长度：直角三角形的斜边 c
foot = 3        # 梯脚离墙根的距离：一条直角边 a

height = 0      # (a) 把云梯顶端能到的高度算出来，赋给 height
print(height)

new_height = height - 1   # 顶端下滑 1 米后的高度（这行不用改）
foot_new = 0              # (b) 下滑后梯脚离墙根多远？勾股定理反过来用
slide = foot_new - foot   # 滑动距离 = 新梯脚距 − 原梯脚距
print(slide)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 认角色：墙 ⊥ 地面，梯子是最长边即斜边 $c = 5$，梯脚距是另一条直角边 $a = 3$。勾股定理给出

$$height^2 + 3^2 = 5^2 \implies height = \sqrt{25 - 9} = \sqrt{16} = 4$$

顶端能到 **4 米**。

**(b)** 关键约束：下滑过程中**梯长不变**。新顶端高度 $4 - 1 = 3$ 米，新的梯脚距满足

$$foot\_new^2 + new\_height^2 = 5^2 \implies foot\_new = \sqrt{25 - 9} = 4$$

滑动距离 $= 4 - 3 =$ **1 米**。有趣的是：下滑前是"勾 3 股 4"，下滑后变成"勾 4 股 3"——两组勾股数互换了位置。

用 Python 一行行验算：

```python
import math

ladder = 5
foot = 3
height = round(math.sqrt(ladder ** 2 - foot ** 2))
print(height)

new_height = height - 1
foot_new = round(math.sqrt(ladder ** 2 - new_height ** 2))
print(foot_new - foot)
```

输出 `4` 与 `1`，和判题窗的期望一致 ✓。

**(c)** 木工是**先有三边、再反推直角**——由边定角，走的是勾股定理的**逆定理**（本目录 [面积与勾股定理](./20-area-pythagoras.md) 练习 3）。若方向反过来（已知直角推边长）才是定理本身。

</details>

## 实战挑战 · 勾股定理的平方陷阱

直角三角形两直角边为 3 和 4，斜边是多少？勾股定理说 $c^2 = a^2 + b^2$——别忘了最后还要开平方。下面这题把斜边算成了 $25$，修到输出 `5.0`：

```exercise
# @title: 实战挑战：勾股定理别忘了开根号
# @check: 5.0
# @hint: c² = a² + b² 求出的是斜边的平方，真正的斜边还要再开平方根。
import math

a, b = 3, 4          # 两条直角边
c = a * a + b * b    # ← 问题在这：这是 c²，不是 c
print(c)
```

<details>
<summary>点开查看逐步解答</summary>

勾股定理给出的是斜边的平方，要得到斜边本身必须开平方根：

```python
c = math.sqrt(a * a + b * b)   # 先算 a²+b²=25，再开根号
print(c)                        # 5.0
```

初始代码停在 $c^2 = 3^2 + 4^2 = 25$，少走最后一步。补上 `math.sqrt`，斜边 $c = \sqrt{25} = 5.0$——这正是经典的 3-4-5 直角三角形。

</details>
