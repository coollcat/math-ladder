# 平行与垂直：线面与面面

## 1. 从一个场景开始

装修师傅往书柜里塞一块隔板，动作只有两步：先拿水平尺确认隔板与地面**平行**，再检查托住它的立柱与地面**垂直**。两步一过，木板就稳了。他其实在用两条几何定理。可为什么"平行于地面内一条直线"就能断定整条直线平行于地面？为什么立柱只要和地面内**两条相交的**线都垂直，就敢说它垂直于整个地面？这两个"为什么"就是本课的全部内容。空间中的平行与垂直一共有四种组合：线∥面、面∥面、线⊥面、面⊥面，每一种都配一条**判定定理**（怎么认出来）和一条**性质定理**（认出来之后能推出什么）。四条定理、八种用法，把空间的骨架钉死。

## 2. 直觉解释

**直线与平面平行**：直线和平面没有公共点。可逐点检查"有没有公共点"是不可能的——判定定理说，只要这条直线平行于平面内**某一条**直线就够了。

**直线与平面垂直**：这是本课最"贵"的一条。定义要求直线垂直于平面内**每一条**直线——无穷多条，根本查不完。判定定理却说：只要垂直于其中**两条相交的**直线就够。为什么两个就够？因为方向：一条直线只能锁住一个方向，而平面是二维的，要把它整个"卡住"得两个不共线的方向——就像固定一扇门只需合页那条轴，而要让一块平板彻底不能动，需要两个不同方向的支点。

**平面与平面平行**：两个平面没有公共点。判定办法是把"面面"拆回"线面"——一个平面内的两条相交直线都平行于另一个平面。

**平面与平面垂直**：两个平面相交，且交出的那个"张口"是直角。判定办法极简：一个平面里只要立着一根垂直于另一个平面的柱子，两面就垂直。

## 3. 正式定义

先把位置关系排清楚。直线与平面：

| 关系 | 公共点 | 记法 |
| --- | --- | --- |
| 直线在平面内 | 无数个 | $l \subset \alpha$ |
| 相交 | 恰 1 个 | $l \cap \alpha = P$ |
| 平行 | 0 个 | $l \parallel \alpha$ |

平面与平面则只有两种：平行（无公共点）与相交（交于一条直线，上一课基本事实 3）。

### 3.1 直线与平面平行

**判定定理**：平面外一条直线与此平面内的一条直线平行，则该直线与此平面平行。

$$l \not\subset \alpha,\ a \subset \alpha,\ l \parallel a \ \Rightarrow\ l \parallel \alpha$$

**怎么证**：

1. $l \parallel a$ ⇒ 由推论 3（两条平行直线确定一个平面），存在平面 $\beta$ 同时含 $l$ 与 $a$；
2. $\alpha$ 与 $\beta$ 都含 $a$。若它们还有一个不在 $a$ 上的公共点，由基本事实 3，两平面的交线是过该点的**唯一**一条直线，可 $a$ 已经是公共直线了——矛盾。故 $\alpha \cap \beta = a$；
3. 反设 $l$ 与 $\alpha$ 有公共点 $Q$：$Q \in l \subset \beta$，故 $Q \in \alpha \cap \beta = a$，即 $Q \in a$；但 $Q$ 又在 $l$ 上，与 $l \parallel a$（无公共点）矛盾；
4. 故 $l$ 与 $\alpha$ 无公共点，即 $l \parallel \alpha$。$\square$

**性质定理**：一条直线与一个平面平行，则过这条直线的任一平面与此平面的**交线**与该直线平行。

$$l \parallel \alpha,\ l \subset \beta,\ \alpha \cap \beta = m \ \Rightarrow\ l \parallel m$$

**怎么证**：$l$ 与 $m$ 同在 $\beta$ 内；若它们有公共点 $P$，则 $P \in m \subset \alpha$ 且 $P \in l$，与 $l \parallel \alpha$ 矛盾；同一平面内无公共点 ⇒ 平行。$\square$ 这条性质是"从平行里**拽出**一条平行线"的常用手段：题目里只要出现"过这条直线作一个平面"，第一反应就去找交线。

### 3.2 平面与平面平行

**判定定理**：一个平面内的两条**相交**直线都平行于另一个平面，则这两个平面平行。

**怎么证**：反设 $\alpha$ 与 $\beta$ 相交于直线 $m$。由 $a \subset \alpha$、$\alpha \cap \beta = m$ 和线面平行性质定理得 $a \parallel m$；同理 $b \parallel m$。于是 $a \parallel b$（平行于同一直线的两条直线互相平行），与已知"$a$、$b$ 相交"矛盾。$\square$

**性质定理**：两个平面平行，则其中一个平面内的任意直线都平行于另一个平面；若第三个平面与这两个平行平面都相交，则两条交线互相平行。

**怎么想**：第一句是定义（没公共点）；第二句的反证只用一行——若两条交线相交，交点同时属于两个平面，与平行矛盾。

注意判定定理里的"**相交**"两个字是硬的：两条**平行**的直线都平行于另一个平面并不能推出面面平行（想想一扇半开的门：门上两条水平的线都平行于门框平面，门却与门框平面相交）。

### 3.3 直线与平面垂直

**定义**：如果直线 $l$ 与平面 $\alpha$ 内的**任意**一条直线都垂直，就说 $l$ 与 $\alpha$ 互相垂直，记作 $l \perp \alpha$。$l$ 叫垂线，交点叫垂足。

**判定定理**：一条直线与一个平面内的两条**相交**直线都垂直，则该直线与此平面垂直。

$$l \perp a,\ l \perp b,\ a \subset \alpha,\ b \subset \alpha,\ a \cap b = O \ \Rightarrow\ l \perp \alpha$$

**怎么想**（完整的证明放在第 8 节选读）：目标是"垂直于平面内**所有**直线"，手上只有两条。做法是取平面上**任意**一条直线 $g$，想办法把"垂直于 $a$、$b$"这两个已知条件**搬运**到 $g$ 上去——搬运的工具是全等三角形：先在 $l$ 上取一组关于 $O$ 对称的点 $A$、$A'$，用勾股定理（不是垂直平分线的性质！）得到 $AM = A'M$、$AN = A'N$，再经两次全等把这份"等距"传到 $g$ 上的点 $G$，得到 $AG = A'G$，于是 $\triangle AA'G$ 是等腰三角形，底边中线 $GO$ 也就是高，即 $l \perp g$。$g$ 是任意的，判定成立。

**性质定理**：垂直于同一个平面的两条直线平行。

**怎么想**：反设它们不平行，过其中一条直线的垂足作另一条的平行线，于是过同一点出现了两条垂直于该平面的直线，与"过一点有且只有一条直线垂直于已知平面"矛盾。

### 3.4 平面与平面垂直

**判定定理**：一个平面过另一个平面的一条垂线，则这两个平面互相垂直。

**性质定理**：两个平面垂直，则一个平面内垂直于**交线**的直线垂直于另一个平面。

**怎么想**：这两条是一正一反的搭档，但严格表述要用到"两个平面所成的角"——**二面角**，那是下一课的主角。本课只记用法：判定 = $l \perp \beta$ 且 $l \subset \alpha$ ⇒ $\alpha \perp \beta$（$\alpha$ 里立着一根 $\beta$ 的垂线）；性质 = $\alpha \perp \beta$、$\alpha \cap \beta = m$、$a \subset \alpha$、$a \perp m$ ⇒ $a \perp \beta$（在 $\alpha$ 里画一条垂直于交线的线，它立刻垂直于 $\beta$）。

| 定理 | 需要什么条件 | 一句话用途 |
| --- | --- | --- |
| 线面平行**判定** | 平面外一条 ∥ 平面内一条 | 证线面平行：去平面里找一条平行线 |
| 线面平行**性质** | 线面平行 + 过该线作平面 | 从平行里拽出交线，得到新的平行线 |
| 面面平行**判定** | 一个面内两条**相交**线都 ∥ 另一面 | 证面面平行：拆成两次线面平行 |
| 面面平行**性质** | 两面平行 | 一个面里的线都平行于另一面；交线互相平行 |
| 线面垂直**判定** | 垂直于面内两条**相交**线 | 证线面垂直：凑够两条相交的 |
| 线面垂直**性质** | 同垂直于一个面 | 得到两条直线平行 |
| 面面垂直**判定** | 一个面过另一个面的垂线 | 证面面垂直：找一个面的垂线落在另一个面里 |
| 面面垂直**性质** | 面面垂直 + 面内线 ⊥ 交线 | 得到一条线面垂直 |

## 4. 分步例题

**例**：四棱锥 $P\text{-}ABCD$ 的底面 $ABCD$ 是边长为 **3** 的正方形，$PA = 4$，量得 $PB = PD = 5$。

**(1)** 求证 $PA \perp$ 平面 $ABCD$；**(2)** 求证 $BC \perp$ 平面 $PAB$；**(3)** 求证平面 $PBC \perp$ 平面 $PAB$。

**(1) 的证法**——手里没有"垂直"这个已知条件，只有长度。把长度翻译成角度的桥梁是**勾股定理的逆定理**（《面积与勾股定理》的练习 3）：

1. 在 $\triangle PAB$ 中，$PA^2 + AB^2 = 4^2 + 3^2 = 16 + 9 = 25$，而 $PB^2 = 5^2 = 25$，两者相等 ⇒ $\angle PAB = 90^\circ$，即 $PA \perp AB$；
2. 在 $\triangle PAD$ 中同理：$PA^2 + AD^2 = 16 + 9 = 25 = PD^2$ ⇒ $\angle PAD = 90^\circ$，即 $PA \perp AD$；
3. $AB$ 与 $AD$ 都在平面 $ABCD$ 内，且相交于 $A$（正方形的两条邻边）；
4. 由线面垂直的判定定理，$PA \perp$ 平面 $ABCD$。$\square$

**(2) 的证法**——要在平面 $PAB$ 里凑出两条与 $BC$ 垂直的相交直线：

1. 由 (1)，$PA \perp$ 平面 $ABCD$；而 $BC \subset$ 平面 $ABCD$ ⇒ $PA \perp BC$（垂直的定义：垂直于平面内**一切**直线）；
2. 底面是正方形 ⇒ $BC \perp AB$（邻边互相垂直）；
3. $PA$ 与 $AB$ 都在平面 $PAB$ 内，且相交于 $A$；
4. 由判定定理，$BC \perp$ 平面 $PAB$。$\square$

**(3) 的证法**——这条是白送的：

1. 由 (2)，$BC \perp$ 平面 $PAB$；
2. 而 $BC \subset$ 平面 $PBC$，即平面 $PBC$ 经过了平面 $PAB$ 的一条垂线；
3. 由面面垂直的判定定理，平面 $PBC \perp$ 平面 $PAB$。$\square$

**回味**：三步一条链——**长度 →（勾股逆定理）→ 线线垂直 →（线面垂直判定）→ 线面垂直 →（面面垂直判定）→ 面面垂直**。每一步只用一条定理，链条里没有一个环节需要量角。

怎么玩：**只拖 $c$**，平面整体升降而倾斜程度不变——取不同 $c$ 得到的这一族平面彼此**平行**，这正对应面面平行的判定：倾斜方向（由 $a$、$b$ 锁定）相同的平面互不相交；**拖 $a$ 或 $b$**，倾斜方向一变，平面立刻与刚才那个位置相交，交出一条直线（上一课基本事实 3）。把 $a$、$b$ 都拖到 0，平面变成水平面 $z=c$，此时竖直方向与它**垂直**——而竖直方向要被卡死，得同时垂直于平面内两个不同的方向（沿 $x$ 的和沿 $y$ 的），这正是判定定理里"两条相交直线"的由来。

### 实验 2（python）：把"垂直"翻译成一条算式

第 4 节那条链子的每一环都能写成一次算术检查（勾股逆定理），让程序逐环验一遍：

```python title="平方和相等 ⟺ 垂直"
import math                               # 开方用 math.sqrt

pa, ab, ad = 4, 3, 3                      # PA = 4，底面是边长 3 的正方形
pb, pd = 5, 5                             # 实测的 PB 与 PD

print(pa ** 2 + ab ** 2 == pb ** 2)       # 16+9=25 ⟹ ∠PAB = 90°：PA ⊥ AB
print(pa ** 2 + ad ** 2 == pd ** 2)       # 同理 ⟹ PA ⊥ AD。两条相交直线都垂直 ⟹ PA ⊥ 底面

ac = math.sqrt(ab ** 2 + ad ** 2)         # 底面对角线 AC = 3√2
pc = math.sqrt(pa ** 2 + ac ** 2)         # PA ⊥ 底面 ⟹ PA ⊥ AC ⟹ PC² = PA² + AC²
print(round(pb ** 2 + ab ** 2), round(pc ** 2))   # △PBC 应满足 PB² + BC² = PC² ⟹ PB ⊥ BC
```

输出 `True`、`True`、`34 34`。最后那一行是关键：左边 $PB^2 + BC^2 = 25 + 9 = 34$，右边 $PC^2 = 16 + 18 = 34$，两者相等说明 $\triangle PBC$ 在 $B$ 处是直角，即 $BC \perp PB$，与第 4 节 (2) 的结论严丝合缝。**要点**：勾股逆定理是"从长度到垂直"的唯一桥梁，凡是要证垂直又给了一堆长度的题，先去凑平方和。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为判定线面垂直时，垂直于平面内一条直线就够了。" 其实必须垂直于**两条相交**的直线。只垂直于一条时，直线可以绕着那条直线旋转（想想一扇绕合页转的门：门边始终垂直于合页所在的那条线，门却不垂直于地面）。

**误区二**："你以为判定面面平行时，'一个平面内有两条直线平行于另一个平面'就够了。" 其实这两条必须**相交**。两条平行线可以属于一扇半开的门——它们都平行于门框平面，门却与门框平面相交。

**误区三**："你以为垂直于同一条直线的两个平面互相平行。" 其实它们可能相交：教室里相邻的两面墙都垂直于地面，但这两面墙彼此垂直相交。正确的方向反过来才成立——垂直于同一个**平面**的两条**直线**互相平行（性质定理）。

:::

<summary>点开查看逐步解答</summary>

**不一定。** "无数条"听起来很多，可它们可能全都互相平行——那只是**同一个方向**。正确的表述是：平面**外**一条直线与此平面内**一条**直线平行，则该直线与此平面平行；一条就够，前提是这条直线在平面外。

反例：若直线 $l \subset \alpha$（在平面内），那么 $\alpha$ 内有无数条直线与 $l$ 平行，但 $l$ 与 $\alpha$ 有无数个公共点，压根不是"平行"关系。判定定理开头"**平面外**"四个字不能省。

## 8. 选读与边界

<details>
<summary>选读 · 线面垂直判定定理：两个方向为什么能锁住一整张平面</summary>

已知 $l \perp a$、$l \perp b$，$a \subset \alpha$、$b \subset \alpha$，$a \cap b = O$。求证 $l \perp \alpha$。

**第 0 步（化归）**：若 $l$ 不过 $O$，过 $O$ 作 $l' \parallel l$。平行不改变与任何直线的夹角（同位角相等），故 $l' \perp a$、$l' \perp b$；先证 $l' \perp \alpha$，再由"平行线之一垂直于平面，另一条也垂直于该平面"得 $l \perp \alpha$。以下设 $l$ 过 $O$。

**第 1 步（对称取点）**：在 $l$ 上取两点 $A$、$A'$，使 $O$ 是 $AA'$ 的中点（两点分居平面两侧）。

**第 2 步（勾股给出等距）**：在 $a$ 上任取一点 $M$。因 $l \perp a$，$\triangle AOM$ 与 $\triangle A'OM$ 都是直角三角形，且 $AO = A'O$、$OM$ 公共：

$$AM^2 = AO^2 + OM^2 = A'O^2 + OM^2 = A'M^2 \Rightarrow AM = A'M$$

同理在 $b$ 上任取一点 $N$，有 $AN = A'N$。（注意这里用的是**勾股定理**两次，不是"垂直平分线上的点到两端等距"那条性质——后者正是本定理的推论，用了就是循环论证。）

**第 3 步（把等距传出去）**：设 $g$ 是 $\alpha$ 内过 $O$ 的任意一条直线（$\alpha$ 内任意直线都可平移到过 $O$，角只认方向）。在 $\alpha$ 内作一条直线，分别与 $a$、$b$、$g$ 交于 $M$、$N$、$G$（取一条不与三者中任何一条平行、且不过 $O$ 的直线即可）。由 $\triangle AMN$ 与 $\triangle A'MN$ **SSS 全等**得 $\angle AMN = \angle A'MN$；再由 $\triangle AMG$ 与 $\triangle A'MG$ **SAS 全等**（$AM = A'M$，$MG$ 公共，夹角相等——$G$ 在直线 $MN$ 上，落在 $M$、$N$ 之间时就是 $\angle AMN$，落在延长线上时同为它的补角）得 $AG = A'G$。

**第 4 步（等腰收口）**：$\triangle AA'G$ 中 $AG = A'G$，$O$ 是底边 $AA'$ 的中点，$GO$ 是底边中线。由 $\triangle AOG$ 与 $\triangle A'OG$ 全等（SSS）得 $\angle AOG = \angle A'OG$，两者互补故各为 $90^\circ$，即 $l \perp g$。

**第 5 步**：$g$ 是 $\alpha$ 内过 $O$ 的**任意**直线，故 $l$ 垂直于 $\alpha$ 内所有直线，即 $l \perp \alpha$。$\square$

整条证明只用到三件工具：勾股定理、SSS 与 SAS 全等、上一课的基本事实。**"两条相交"这个条件在第 3 步起作用**：$a$、$b$ 不平行，那条横切线才能同时切到两条，把等距从两个方向汇到 $g$ 上。

</details>

### 本课不管什么

- 只判断"平不平、垂不垂"，不涉及**多大角度**：线面角与二面角是下一课的内容；也不量距离（点到平面的距离、异面直线的公垂线长度）；
- 一切结论都靠基本事实与全等三角形推出，**不用向量、不用法向量**（第 11 章）；
- 面面垂直的两条定理只给了用法没给证明，因为严格的证明要借助下一课的二面角。

## 9. 下一站
