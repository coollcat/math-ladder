# 相似三角形与比例

## 1. 从一个场景开始

公元前 600 年左右的某个正午，泰勒斯站在金字塔脚下。法老不许人爬塔，可他只插了一根木棍，量了量棍子的影子、再量了量塔的影子，就报出了塔高——两千多年后才有人真正登上塔顶替他验收，误差出奇地小。

一根木棍加两道影子，凭什么能称出一座石头山的身高？

因为他手里握着本课的主角：**形状相同、大小不同**的两个三角形之间有一条铁律。这条铁律还是斜率、三角比这些大角色的共同源头——认识它，等于给后面一整批课程领了门票。

## 2. 直觉解释

想象把一张小照片等比例洗成大海报：放大几倍都好，五官的角度分毫未动。

先暴力做一组实验拿数据说话。取一个边长为 $3$、$4$、$5$ 的直角三角形，复制三份分别按倍数 $1$、$2$、$3$ 放大，逐条量出新边长：

| 边的位置 | ×1 | ×2 | ×3 |
| --- | --- | --- | --- |
| 最短边 | 3 | 6 | 9 |
| 另一直角边 | 4 | 8 | 12 |
| 斜边 | 5 | 10 | 15 |

三个不同的"家族"，但每一族内部都有同一件事在发生：**三条边全部乘了同一个数**（×1 族是 1、×2 族是 2、×3 族是 3），而三个内角从头到尾纹丝不动。

反过来看更清楚：不管放大多少倍，$6\div3 = 8\div4 = 10\div5 = 2$——**对应边的比值是一个常数**。大小由这个比值说了算，形状由角度说了算，两者各管各的。

那个代表放大幅度的常数，就叫做**相似比**。相似比一把抓：已知它和原三角形的任何一条边，新三角形的对应边立刻到账；反之，只要量得一对对应边就能反推整个家族的账目。第 2 节那张表的灵魂，正是下面要正式登记的规矩。

## 3. 正式定义

**相似三角形**：若两个三角形的**对应角相等**且**对应边成比例**，则称它们相似，记作 $\triangle ABC \sim \triangle A'B'$。

单行公式把两条要求一起写：

$$k=\frac{AB}{A'B'}=\frac{BC}{B'C'}=\frac{AC}{A'C'}$$

| 符号/术语 | 含义 |
| --- | --- |
| $\sim$ | 相似符号，读作"相似于"；顶点书写顺序即对应关系（$A$ 对 $A'$，以此类推） |
| $k$ | **相似比**：原三角形某边与放大版对应边之比，$k>1$ 表示被放大 |
| 对应边 / 对应角 | 在两个形状中扮演同一角色的边与角；找错"对家"是一切事故的起点 |
| 判定（AA） | 只要**两个角**对应相等，第三个角被"内角和 180°"自动锁定，两个三角形必相似 |

对实操来说 AA 是最常用的入场券：一根竖直木棍与一道影子构成的小三角形，和一座塔与其影子构成的大三角形，共享同一个阳光角与各自共享一个直角——两个角相等，相似成立。剩下的事全部交给比例。

顺带登记一条会反复出现的副产品：边长放大 $k$ 倍时，**面积放大 $k^2$ 倍**（后面圆与扇形的课还会再和这条规律打照面）。

## 4. 分步例题

**例**：重演泰勒斯的测量。正午的阳光下，一根**1.6 米**的木棍立在地上，影长**2 米**；同一时刻，金字塔的影长恰好测得 **18 米**。塔有多高？

1. **认图形**：木棍垂直于地面，塔也近乎垂直地面——两个三角形里各有一个直角；
2. **认角**：太阳离得极远，光线照到棍子和照到塔几乎完全平行，所以"阳光俯角"在两个三角形中相等；
3. **下结论**：两组角对应相等 → 由 AA 判定，小三角形 $\sim$ 大三角形；
4. **列比例**：棍高与塔高是对应边，两道影子也是对应边，于是

$$\frac{\text{塔高}}{\text{棍高}} = \frac{\text{塔影}}{\text{棍影}}$$

5. **代入解比例**：$\dfrac{h}{1.6} = \dfrac{18}{2} = 9$，得 $h = 1.6\times9 = 14.4$ 米；
6. **体感校验**：约四层楼高的石造建筑，放在古代已属奇迹级——数字不越界，答案可信。

一句总结流水线：**认角 → 判相似 → 摆对应 → 解比例**。以后遇到一切"够不着的高度"，都走这四步。

## 5. 动手实验

### 实验 1（python）：逐边核对比值表

把第 2 节的手工表格交给程序复核，顺便再试几个别的放大倍数：

```python title="放缩前后逐边算比值"
small = [3, 4, 5]                 # 小三角形的三条边长列表
big = [9, 12, 15]                 # 放大版对应的三角形——注意顺序是"同一条边对同一条边"

ratios = []                       # 收集三个比值
idx = 0                           # 手写的计数器下标，从 0 开始指向第一条边
for edge in big:                  # edge 依次是大三角形的每条边
    ratio = edge / small[idx]     # 与它同位置的那条小边相比；small[idx] 按下标取元素
    ratios.append(round(ratio, 2))    # round(x, 2)：保留两位小数；append 送进列表末尾
    idx = idx + 1                 # 下标推进一格，跟上大边的节奏

print(ratios)                     # 三项应当整齐划一
area_ratio = (9 * 12 / 2) / (3 * 4 / 2)   # 面积之比 = 大面积 ÷ 小面积（都是底×高÷2）
print(area_ratio)
```

第一行输出 `[3.0, 3.0, 3.0]`——三连号，比值恒定；第二行输出 `9.0`：边长 ×3 的家族，面积悄无声息地变成了 $9=3^2$ 倍。

### 实验 2（matplotlib）：三种尺寸、一张脸

数字之外亲眼看一看"保形放大"：同一个三角形分别放大 1、2、3 倍叠在一起。

```python title="放缩对比图：变的是大小，不变的是形状"
import matplotlib.pyplot as plt      # 绘图工具箱，第 0 课引入过

small = [[0, 0], [3, 0], [1, 2]]     # 三顶点列表；每个点是 [x, y]，外层套一层装点集
ks = [1, 2, 3]                       # 打算试验的三个放大倍数
palette = ["steelblue", "orange", "seagreen"]   # 三种颜色挨个领用
fig, ax = plt.subplots(figsize=(6, 4))          # 新建画布与坐标系；figsize 定图宽高
slot = 0                             # 当前用到的颜色编号，自己维护的小计数器

for k in ks:                         # 每个倍数画一只三角形
    pts = []                         # 收集放大后的顶点
    for p in small:                  # p 依次取 [0,0]、[3,0]、[1,2]
        pts.append([p[0] * k, p[1] * k])   # 横纵坐标同乘 k——这才是"保形"放大
    pts.append(pts[0])               # 把第一个点接到末尾，让折线闭合成三角形
    xs = []
    ys = []
    for q in pts:                    # 再把顶点拆成 x、y 两组平行列表供画线用
        xs.append(q[0])
        ys.append(q[1])
    ax.plot(xs, ys, color=palette[slot], label="k = " + str(k))   # 连点成线；label 进图例
    slot = slot + 1                  # 换下一个颜色槽位

ax.legend()                          # legend：调出角落里的图例盒
```

三只三角形嵌套而立，边与边的方向、夹角的模样完全一致——这就是"形状相同"的字面意思。你还可以脑补一幅反例：如果横坐标乘 2 而纵坐标乘 5，嵌套的图形会立刻歪斜拉扁，那就不叫相似了。

### 快问快答

```quiz
两个相似三角形的相似比是 1 比 3。大三角形的面积是小三角形的几倍？
- 3 倍
- 6 倍
- 9 倍 [*]
? 边长各乘 3，面积是两条边的乘积：3 × 3 = 9 倍——长度走一次方，面积走二次方。
```

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为看起来差不多就算相似。" 其实相似是角度与比例的双重铁律，不是目测印象。把长方形横向拉宽一点，四个角没变，但它已经不在原来的形状家族里了。

**误区二**："你以为随便拿两条边比一下就是相似比。" 其实必须**对应边**对**对应边**：最短对最短、最长对最长。交叉配对出来的数值毫无意义，只会误导后续计算。

**误区三**："你以为边长放大 k 倍，面积也放大 k 倍。" 其实面积跟着 $k^2$ 走：边长 ×3，面积 ×9。这也是为什么复印机没法用"加墨"来弥补大尺寸图纸的成本暴涨。

:::

## 7. 练习

**练习 1（判题）**：两只相似三角形。小的三边从短到长是 **3、4、5**；大的那只量得其**最短边为 9**。求大三角形的另两边与周长。下面的代码能跑但结果不对——写它的人以为相似放大是"垫高几厘米"，改到三条检查全部通过：

```exercise
# @title: 练习：放大要用乘法，不是加法
# @check: 12
# @check: 15
# @check: 36
# @hint: 相似是"等比放大"不是"等差垫高"：先算相似比 k = 9 ÷ 3 = 3.0，再让另两条边各自乘上 k。得到的是小数没关系，打印前包一层 round() 收整即可。
small = [3, 4, 5]                # 小三角形三边，由短到长排列
big_short = 9                    # 大三角形的最短边

growth = big_short - small[0]    # ← "长大了多少"？问问自己：相似放大到底是加还是乘？
big_mid = small[1] + growth      # ← 于是另两条边也被无差别地加了同样多的量
big_long = small[2] + growth     # ← 同病相怜的一条
print(round(big_mid))
print(round(big_long))

perimeter = big_short + big_mid + big_long    # 大三角形周长
print(round(perimeter))
```

<details>
<summary>点开查看逐步解答</summary>

1. **摆对应**：大三角形的 9 是最短边，与小三角形的 3 对应，于是相似比

$$k = \frac{9}{3} = 3$$

2. **等比放大**：另两边不再"垫高"，而是各乘 $k$：$4\times3 = 12$，$5\times3 = 15$；
3. **收周长**：$9 + 12 + 15 = 36$。

修正后的参考代码：

```python
small = [3, 4, 5]
big_short = 9

k_rate = big_short / small[0]      # 相似比：9 ÷ 3 = 3.0（用除法，不是减法）
big_mid = small[1] * k_rate        # 4 × 3.0 = 12.0
big_long = small[2] * k_rate       # 5 × 3.0 = 15.0
print(round(big_mid))
print(round(big_long))

perimeter = big_short + big_mid + big_long
print(round(perimeter))
```

输出依次是 `12`、`15`、`36`。"差值"与"比值"一字之差，放大出来就是两个物种——这正是相似定义里"成比例"三个字的分量。
</details>

**练习 2**：一棵大树在地面的影长 25 米；同一时刻，旁边一根 2 米高的竹竿影长 1 米。树有多高？

<details>
<summary>点开查看逐步解答</summary>

阳光平行光保证杆与树各自的"光路三角形"相似（思路与第 4 节例题相同）。竹竿这一对给出相似比关系：

$$\frac{\text{树高}}{\text{杆高}} = \frac{\text{树影}}{\text{杆影}} = \frac{25}{1} = 25$$

于是树高 $= 2\times25 = 50$ 米。

快速验证代码：`print(2 * 25 // 1)` 或者更直接 `print(2 * (25 / 1))`——都能打出答案。这棵树约十七层楼，现实中多半由好几段枝干接力；但几何不管这些，铁律只认影子。
</details>

**练习 3**：概念辨析：两个等腰三角形都有一个 40° 的角，能否断定它们相似？

<details>
<summary>点开查看逐步解答</summary>

不能一刀切。等腰三角形的 40° 角可能站在不同岗位上：若是**顶角** 40°，则两底角各 $(180-40)\div2 = 70°$，角组是 $(40°, 70°, 70°)$；若是**底角** 40°，则角组变成 $(40°, 40°, 100°)$。两种家族互不相同——只知道一个角的岗位不明，AA 判定凑不出"两个对应角相等"。此题提醒我们：判定相似之前，先把每个角的身份查清。
</details>

## 8. 选读与边界

### 选读 · 为什么两个角就够了

表面上"对应角全等且对应边成比例"要验一大串条件，实际判定却常只需两个角，理由藏在第 10 课那条内角和铁律里：三个角共享 180° 的总预算，知道其中两个，第三个就被强制锁定——**角的条件从不缺货**。

而一旦三个角全部对齐，边的比例会被"相似封闭性"接住：以其中一个三角形为模板，可以按任意选定边先拼出一个与第二个三角形对应边相等的仿作，其余两边被迫沿同样的比例收缩或伸展，最终与目标逐边重合（这正是[全等三角形](./22-congruent-triangles.md) SSS 判据的影子：三边数据锁死形状）。这是三角形独有的刚性——换成四个自由度更高的图形，两个角就拿不住整体了。

### 本课不管什么

- 管二维形状，不管立体：立体世界的对应物"相似体"边长立方会牵出体积比 $k^3$——那是下一章立体几何该报到的伏笔；
- 只在欧氏平面上讨论；投影、透视下的变形属于更高层的游戏；
- 相似给出形状，不给具体数值精度：需要角度的具体正负值（比如 30° 的高是多少倍底边），要等第 7 章的三角比出场。
