# 神经元、线性层与激活函数

## 1. 从一个场景开始

你的邮箱每秒都在做一道判断题：新来的这封邮件，是垃圾邮件吗？判断依据是一堆证据——出现"中奖"加三分，发件人在通讯录减五分，正文全是链接再加四分……把所有加减汇总成一个总分，超过某个门槛就扔进垃圾箱。

这个"加权打分 + 拍板"的结构，正是神经网络的最小零件：**人工神经元**。本课把它拆开看清楚——它凭什么能学，又为什么必须"弯一下"才有用。

## 2. 直觉解释

把神经元想象成一位**评委**：

- 每条**证据**（输入特征）$x_i$ 先乘上一个**权重** $w_i$——权重就是评委心里"这条证据值多少分"；
- 全部加权得分相加，再补一个**偏置** $b$——它是评委的"先入为主"：还没看证据就先带着的态度；
- 最后过一道**拍板器**（激活函数）：分数太负就"无感"，分数够正才"激动"。

一层里并排站多位评委，每人有自己的权重表和态度，各自给出自己的激动程度——这一排评委就叫一个**层**。

## 3. 正式定义

神经元先做加权求和：

$$z = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \vec w \cdot \vec x + b$$

再过激活函数 $\phi$ 得到输出 $a = \phi(z)$。两个最常用的激活函数：

$$\text{ReLU}(z) = \max(z,\ 0) \qquad \sigma(z) = \frac{1}{1+e^{-z}}$$

| 符号 | 含义 |
| --- | --- |
| $\vec x$ | 输入特征向量（证据列表） |
| $\vec w$ | 权重向量（各条证据的重要性） |
| $b$ | 偏置（不看证据的先天倾向） |
| $z$ | 加权总分（激活前的值） |
| $a$ | 激活后的输出（激动程度） |

ReLU 把负分全部清零（不激动），正分原样放行；sigmoid 是一条平滑的 S 形曲线，把任意分数压进 $0$ 到 $1$ 之间——正好可以当"概率"读。$e^{-z}$ 里的指数函数在第 12 章欧拉公式一课正式登场过。

## 4. 分步例题

**例**：垃圾邮件评委的权重是 $\vec w = (0.5,\ -0.4)$，偏置 $b = 0.3$。邮件特征 $\vec x = (2,\ 1)$：出现 2 次可疑词、发件人在通讯录。算神经元的输出。

1. 逐条加权：$0.5 \times 2 = 1$；$-0.4 \times 1 = -0.4$；
2. 相加再加偏置：$z = 1 - 0.4 + 0.3 = 0.9$；
3. ReLU 拍板：$0.9 > 0$，原样放行，输出 $a = 0.9$；
4. 若改用 sigmoid：$a = \sigma(0.9) = \frac{1}{1+e^{-0.9}} \approx 0.71$——可以读成"71% 像垃圾邮件"。

同一个 $z$，两种拍板器给出两种口味的答案：要"干脆"用 ReLU，要"百分比"用 sigmoid。

### 实验 2：手写一个神经元

```python title="用纯循环实现一个神经元"
w = [0.5, -0.4, 0.8]        # 权重表：每条证据的重要性
b = 0.3                     # 偏置：先天倾向
x = [2.0, 1.0, 0.0]         # 一封邮件的证据：2 次可疑词、在通讯录、0 个附件

z = b                       # 总分从偏置出发
for i in range(len(w)):     # len(w)：列表长度，range 依次给出下标 0,1,2
    z = z + w[i] * x[i]     # 累加：每条证据乘权重后加进总分

if z > 0:                   # ReLU 拍板：正分通过，负分清零
    a = z
else:
    a = 0.0

print("加权总分 z =", round(z, 2))
print("ReLU 输出 a =", round(a, 2))
```

这就是神经元的全部数学：一个点积加一次拍板。第 11 章的点积在这里变成了可学习的打分器。

### 实验 3：没有激活函数会怎样？

```python title="三层线性网络塌缩成一层"
# 两层"裸"线性变换（故意都不加激活）
w1, b1 = 2.0, 1.0           # 第一层的权重与偏置
w2, b2 = 3.0, -1.0          # 第二层的权重与偏置

x = 0.5                     # 输入
h = w1 * x + b1             # 第一层输出
y = w2 * h + b2             # 第二层输出
print("两层网络的输出:", y)

w_direct, b_direct = w1 * w2, w2 * b1 + b2   # 合并后的等效一层
y_direct = w_direct * x + b_direct
print("一层直通的输出:", y_direct)
```

两次输出完全相同：**线性的复合还是线性**。不管叠多少层"裸"网络，数学上等价于一层。激活函数就是把每层掰弯的那只手——没有它，深度只是幻觉。

### 快问快答

```quiz
如果把所有激活函数都去掉，一个十层的神经网络会变成什么？
- 一个更强大的非线性模型
- 等价于一个单层线性模型 [*]
- 无法计算，程序直接报错
? 线性变换的复合仍是线性变换：多层裸线性层会被合并成一层。非线性激活才是"深"的来源。
```

:::warning[常见误区]

**误区一**："权重越大，这条证据越重要。"——只在其他条件相同时对。若两条高度相关的证据同时出现，它们的权重会互相"重复计分"；而且量纲不同时权重数值不可比。

**误区二**："ReLU 把负数变成 0，所以丢信息了。"——对单个神经元看是的，但一层里多个神经元各管一片区域，负分信息由别的神经元负责表达。

**误区三**："sigmoid 输出越接近 1，事情越确定是真的。"——它只是模型的自信度，不是真实概率。自信满满的错误预测在深度学习里天天见。

:::

## 6. 练习

**练习 1**：神经元 $\vec w = (0.6,\ -0.2)$、$b = 0.1$，输入 $\vec x = (1,\ 2)$。心算 $z$ 和 ReLU 后的 $a$。

<details>
<summary>点开查看逐步解答</summary>

$z = 0.6 \times 1 + (-0.2) \times 2 + 0.1 = 0.3$。$0.3 > 0$，ReLU 放行，$a = 0.3$。
</details>

**练习 2**：把下面这个"忘了拍板、也忘了偏置"的神经元修好——目标输出是 ReLU 后的正确结果：

```exercise
# @title: 练习：修好这位评委
# @check: 0.9
# @hint: 第一处漏了偏置 b；第二处要求过 ReLU——正数放行，负数清零。
w1, w2 = 0.5, -0.4       # 两条证据的权重
b = 0.3                  # 偏置（先天倾向）
x1, x2 = 2.0, 1.0        # 证据取值

z = w1 * x1 + w2 * x2    # ← 问题在这：加权总分里少了一项
a = z                    # ← 问题在这：还没过激活函数
print(round(a, 2))
```

**练习 3**：概念辨析——为什么生物神经元有"全或无"的放电特性，而人工神经元常用 sigmoid 这种平滑函数？

<details>
<summary>点开查看逐步解答</summary>

生物神经元像 ReLU/阶跃：刺激够强就放电，否则沉默。但"够强"是个硬门槛，不可导——梯度下降需要处处有斜率可循（下一章见）。sigmoid 是阶跃函数的光滑化：保留"越强越活跃"的趋势，又在每个点都有导数，让"调权重"这件事有了方向感。工程上 ReLU 干脆利落算得快，sigmoid 平滑可解释，各有分工。
</details>

## 7. 选读：从生物神经元到人工神经元

<details>
<summary>选读 · 一段简史与它的局限</summary>

1943 年 McCulloch 与 Pitts 提出把神经元抽象为"加权求和 + 阈值触发"的逻辑单元；1958 年 Rosenblatt 的感知机让权重可以**从数据中学出来**，掀起第一波热潮。1969 年 Minsky 与 Papert 指出单层感知机连异或（XOR）都学不了，热潮跌入谷底——直到人们发现：**多加一层并插入非线性激活**，异或迎刃而解（本章第 40 课你会亲手训出它）。

也别神化类比：人工神经元丢掉了脉冲时序、抑制连接等几乎所有生物细节，它真正继承的只有"分布式加权投票"这一个想法。
</details>
