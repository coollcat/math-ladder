# 前向传播：数据流过网络

## 1. 从一个场景开始

一张手写数字图片有 $28 \times 28 = 784$ 个像素。识别它，意味着把 784 个数加工成一个答案："这是 7"。一位评委显然不够用——真实网络让**几百位评委组成流水线**：第一排看局部笔画，第二排组合成弧线与拐角，第三排投票出最终数字。

数据从入口流到出口的这一次加工，叫**前向传播**。本课用一个 2-2-1 的迷你网络把它手算到底。

## 2. 直觉解释

把多层网络想成一条**工厂流水线**：

- **第一车间**（隐层）：每位工位各领一份原料（输入向量），按自己的配方加权混合，过质检（激活）后交出半成品；
- **第二车间**（输出层）：把所有半成品当作新原料，再混合、再质检，产出成品；
- 每个车间的"全体配方表"就是**权重矩阵**——矩阵乘法一次算出全车间的产量，这正是第 11 章矩阵的用武之地。

关键规则只有一条：**下一层吃的不是原始数据，而是上一层激活后的输出**。信息就这样一层层改写，直到出口。

## 3. 正式定义

一个两层网络（1 个隐层）的前向传播：

$$\vec h = \phi(W_1 \vec x + \vec b_1), \qquad \hat y = W_2 \vec h + b_2$$

| 符号 | 形状 | 含义 |
| --- | --- | --- |
| $\vec x$ | $n$ 维 | 输入向量 |
| $W_1,\ \vec b_1$ | $m \times n$，$m$ 维 | 第一层的权重矩阵与偏置；第 $j$ 行是第 $j$ 位评委的配方 |
| $\vec h$ | $m$ 维 | 隐层输出（半成品） |
| $W_2,\ b_2$ | $1 \times m$，标量 | 输出层配方（回归问题不加激活） |

形状口诀：**左邻的列数必须等于右邻的行数**——上一层的输出维度就是下一层的输入维度。

## 4. 分步例题

**例**：2-2-1 网络，ReLU 隐层，线性输出。取

$$W_1 = \begin{pmatrix} 0.5 & -0.4 \\ 0.3 & 0.2 \end{pmatrix}, \quad \vec b_1 = (0.1,\ 0), \quad \vec x = (1,\ 2), \quad W_2 = (1,\ 1), \quad b_2 = -0.2.$$

1. 隐层第一位评委：$z_1 = 0.5 \times 1 + (-0.4) \times 2 + 0.1 = -0.2$；
2. ReLU 负分清零：$h_1 = \max(-0.2,\ 0) = 0$——这位评委对这封"邮件"无感；
3. 隐层第二位评委：$z_2 = 0.3 \times 1 + 0.2 \times 2 + 0 = 0.7$，ReLU 放行，$h_2 = 0.7$；
4. 输出层汇总：$\hat y = 1 \times 0 + 1 \times 0.7 - 0.2 = 0.5$。

注意第 2 步：ReLU 把一位评委"熄火"，网络因此学会了"这条证据不相关就忽略"。这种**条件性的沉默**，正是纯线性网络做不到的。

## 5. 动手实验

### 实验 1：线性层是一台空间变形机

```viz
{
  "type": "matrix",
  "title": "没有激活的一层 = 把整个平面拉斜",
  "a": 0.6,
  "b": -0.4,
  "c": 0.2,
  "d": 0.8
}
```

拖动四个矩阵元，小房子被旋转、剪切、压缩——但**永远不会弯折**。弯折来自激活函数：它在每层之后把空间沿坐标轴"折"一下，多折几次，才能折出任意复杂的形状。

### 实验 2：手写完整的前向传播

```python title="2-2-1 网络前向传播（纯循环版）"
W1 = [[0.5, -0.4], [0.3, 0.2]]   # 第一层权重：W1[j] 是第 j 位评委的配方
B1 = [0.1, 0.0]                  # 第一层偏置
x = [1.0, 2.0]                   # 输入向量

h = []
for j in range(len(W1)):         # 逐个评委计算
    z = B1[j]                    # 总分从偏置出发
    for i in range(len(x)):      # 累加每个输入的贡献
        z = z + W1[j][i] * x[i]
    if z < 0:                    # ReLU：负分清零
        z = 0.0
    h.append(z)                  # append：把结果接到列表末尾

y = -0.2                         # 输出层偏置 b2
for j in range(len(h)):          # 输出层：半成品的加权和
    y = y + h[j]

print("隐层输出 h =", [round(v, 2) for v in h])
print("网络输出 y =", round(y, 2))
```

对照 §4 的手算：$h = (0,\ 0.7)$、$y = 0.5$。机器算的和纸笔算的完全一致——前向传播没有任何魔法，只是**批量地重复点积**。

### 实验 3：网络的输出随输入怎么变？

```python title="扫描输入，画出输出曲线"
import matplotlib.pyplot as plt   # 第 0 章登场的画图库

W1 = [[0.5, -0.4], [0.3, 0.2]]
B1 = [0.1, 0.0]

def network(x1, x2):             # def：定义函数，之后可以反复调用
    hs = []
    for j in range(2):
        z = B1[j] + W1[j][0] * x1 + W1[j][1] * x2
        hs.append(max(z, 0.0))
    return hs[0] + hs[1] - 0.2

xs = []                          # 扫描 x2 从 -3 到 3
ys = []
for k in range(61):
    x2 = -3 + k * 0.1
    xs.append(x2)
    ys.append(network(1.0, x2))

plt.plot(xs, ys)
plt.axvline(1.5, color="gray", linestyle="--")   # axvline：竖直参考线，标出 ReLU 换段位置
plt.xlabel("x2")
plt.ylabel("network output")
plt.grid(True)
```

曲线不是直线！固定 $x_1=1$、扫动 $x_2$ 时，输出从 $x_2=-3$ 处的 $1.6$ 沿左支降到折点 $x_2=1.5$ 处的 $0.4$，再沿右支升到 $x_2=3$ 处的 $0.7$——这是一个 V 形分段。左支斜率是 $-0.2$；过了折点后第一位评委被 ReLU 压灭，右支斜率变成 $+0.2$。层数越多，这样的分段弯折就越丰富。

### 快问快答

```quiz
一个 3x4 的权重矩阵 W1 接在输入后面，输入向量必须是几维？
- 3 维
- 4 维 [*]
- 任意维都行
? 形状口诀：左邻列数等于右侧行数。W1 是 3 行 4 列，吃 4 维向量、吐 3 维向量。
```

:::warning[常见误区]

**误区一**："权重矩阵的行是输入维度。"——反了：$W_1$ 的**第 $j$ 行**属于第 $j$ 个神经元，行长等于输入维数。下标写错，形状立刻对不上。

**误区二**："偏置也是乘上去的。"——偏置是**加**上去的天生倾向，$z = \vec w \cdot \vec x + b$ 里它是独立一项，不参与乘法。

**误区三**："深 = 层多就行。"——层之间必须有非线性激活隔开，否则如实验 3 所示，一百层也塌缩成一层。

:::

## 6. 练习

**练习 1**：把 §4 网络的输入换成 $\vec x = (0,\ 0)$，手算 $\vec h$ 与 $\hat y$。

<details>
<summary>点开查看逐步解答</summary>

$z_1 = 0 + 0 + 0.1 = 0.1 > 0 \Rightarrow h_1 = 0.1$；$z_2 = 0 \Rightarrow h_2 = 0$；$\hat y = 0.1 + 0 - 0.2 = -0.1$。注意全零输入也会因偏置产生非零输出——偏置是"无中生有"的底噪。
</details>

**练习 2**：下面这段前向传播代码漏了输出层的偏置，请修好它（正确答案是 $0.5$）：

```exercise
# @title: 练习：补全前向传播
# @check: [0.0, 0.7]
# @check: 0.5
# @hint: 输出层公式是 y = h1 + h2 + b2，别把 -0.2 弄丢了。
W1 = [[0.5, -0.4], [0.3, 0.2]]
B1 = [0.1, 0.0]
x = [1.0, 2.0]

h = []
for j in range(2):
    z = W1[j][0]*x[0] + W1[j][1]*x[1] + B1[j]
    if z < 0:
        z = 0.0
    h.append(z)

o = h[0] + h[1]          # ← 问题在这：输出层还有偏置 b2 = -0.2 没加
print([round(v, 2) for v in h])
print(round(o, 2))
```

**练习 3**：若把隐层激活从 ReLU 换成 sigmoid（$\sigma(0)=0.5$），重算 §4 例题的 $\hat y$（提示：$\sigma(-0.2)\approx 0.45$，$\sigma(0.7)\approx 0.67$）。

<details>
<summary>点开查看逐步解答</summary>

$h_1 = \sigma(-0.2) \approx 0.45$，$h_2 = \sigma(0.7) \approx 0.67$，$\hat y = 0.45 + 0.67 - 0.2 \approx 0.92$。换拍板器不改变流程，只改变"激动程度"的表达方式——sigmoid 永远给正响应，ReLU 允许完全沉默。
</details>

## 7. 选读：为什么大网络偏爱矩阵形式？

<details>
<summary>选读 · 并行的秘密</summary>

逐个循环算 784 维输入 × 128 位评委需要约十万次乘法。写成矩阵乘法 $W\vec x$ 后，这些乘法**彼此独立**——GPU 上万个核心可以同时开工，时间几乎不随规模线性上涨。深度学习工程框架（PyTorch 等）的核心工作就是把一切运算整理成矩阵/张量形式交给硬件并行。本站为了透明教学坚持手写循环，但你要知道：工业实现里你写的 `layer(x)` 最终就是一块高度优化的矩阵乘法。
</details>
