# 学习率调度与训练诊断

## 1. 从一个场景开始

无人机从百米高空送外卖：离目标还远时全速俯冲，临近阳台却必须逐级减速、悬停微调——同一个油门用到底，要么一小时还在半空磨蹭，要么一头撞碎窗户。参数训练同款困境：损失面又阔又陡在前段、狭窄平缓在后段，**恒定的步长不可能两头都合适**。

上一课造好了能跑深路的引擎（残差）、稳压器（归一化）与起跑器（初始化）；本课负责驾驶技术：什么时候踩油门、什么时候松，以及——从仪表盘的抖动里读出车况。

## 2. 直觉解释

**核心直觉：学习率就是"对当前估计的不信任程度"，信任是挣来的。**

初期参数纯属瞎猜，值得大步跨越；越接近谷底，每一步都可能跨过山谷另一侧，就该收敛脚步。真实训练几乎从不使用固定学习率 $\eta$，而是让它随轮次 $e$ 演化：

| 调度 | 公式 / 规则 | 风格 |
| --- | --- | --- |
| Step decay | 每 10 轮 $\eta \leftarrow \eta\times0.5$ | 台阶式急刹 |
| Cosine | $\eta_e=\dfrac{\eta_0}{2}\Bigl(1+\cos\dfrac{e\pi}{E}\Bigr)$ | 先缓降后贴地 |
| Warmup | 前 $k$ 轮从 0 线性爬到 $\eta_0$ | 冷启动保护（大模型标配） |

warmup 的存在提醒我们调度不只是"递减"：初始阶段梯度噪声巨大、Adam 类优化器的动量统计还没热身，直接全速会把前期带偏——先小油门滑行。

## 3. 正式定义

把第 30 课的一维抛物线当测速跑道：$L(x)=x^{2}$，梯度为 $2x$，迭代

$$x_{t+1}=x_{t}-\eta\cdot 2x_{t}=(1-2\eta)\,x_{t} .$$

误差每步乘上 $|1-2\eta|$，三种命运泾渭分明：

| $\eta$ 取值 | 每步因子 | 行为 |
| --- | --- | --- |
| $<0.5$ | $\lvert1-2\eta\rvert<1$ | 平稳收敛 |
| $=0.5$ | $0$ | 一步到位 |
| $0.5<\eta<1$ | $-1<$ 因子 $<0$ | 收敛但来回过冲振荡 |
| $\geq1$ | $\lvert$因子$\rvert\geq1$ | 发散（≥1 后一路放大） |

**诊断表**——把上面四档翻译成损失曲线的仪表盘读数：

| 曲线长相 | 读作 | 处方 |
| --- | --- | --- |
| 锯齿剧烈、来回乱蹦 | 步子太大 | η 除以 3~10；或加 warmup |
| 光滑下降但迟迟不到 | 太保守 | η 放大，或换调度别恒定 |
| 前快后僵、平台高企 | 该刹不刹 | step/cosine 调度收尾 |
| 忽降忽升像心电图 | 学习率过大 + 数据噪声 | 减 η 同时检查批大小 |

## 4. 分步例题

取 $\eta=0.8$、起点 $x_0=5$。

1. 每步因子 $1-2(0.8)=-0.6$；
2. 轨迹：$5,\ -3,\ 1.8,\ -1.08,\ 0.648,\ \ldots$ —— 每步跨越谷底跳到对面，但幅度缩水 $0.6$ 倍；
3. 第 10 步幅值约为 $5\times0.6^{10}\approx0.0362$ —— 振荡着贴向零；
4. 结论：$\eta=0.8$ 属于"过冲式收敛"——能用，但若此时还想加速就得靠动量而非再加大 η（会冲进发散区）。

## 5. 动手实验

一维跑道上亲手换挡，看三档学习率的终局：

```python title="抛物线跑道的三种结局"
def run(eta, x0=5.0, rounds=12):
    xs = [x0]
    for _ in range(rounds):
        x_now = xs[-1]
        xs.append(x_now - eta * 2 * x_now)   # L=x² 的梯度是 2x
    return xs

for eta in [0.3, 0.8, 1.05]:
    traj = run(eta)
    last = abs(traj[-1])
    if last > 100:
        tag = "发散"
    elif abs(traj[-2]) < abs(traj[-1]):
        tag = "健康收敛（有过冲）" if eta > 0.5 else "平稳收敛"
    else:
        tag = "缓慢收敛"
    print("eta =", eta, "末端 |x| =", round(last, 4), "->", tag)

print("发散档末三位轨迹:", [round(v, 1) for v in run(1.05)[-3:]])
```

输出依次是"平稳收敛"、"健康收敛（有过冲）"、"发散"，最后一行能看到发散档在 ±(几十到上百)之间疯狂摇摆。

## 6. 常见误区

:::warning[常见误区]

- **"loss 一涨就是完蛋了"** —— 小幅回升常是大 η 下的正常过冲；要怕的是趋势性爆涨伴随数值 NaN。
- **"cosine 一定优于 step decay"** —— cosine 只是省去手工选台阶位置；数据集小、预算短时两者差距常小于随机种子波动。
- **"调不动先怪调度"** —— 排查顺序应是：数据管线→ 初始 loss 是否 ≈ ln(类别数) → 归一化统计是否泄漏 → 才轮到 η 家族。
- **"Warmup 是玄学"** —— 大 batch 下初始几步梯度分布极端、二阶矩统计未就绪（第 43 章 Adam 的 v_t 才刚起步），warmup 是实打实的数值保险。

:::

## 7. 练习

实现一个两级台阶调度：前 10 轮保持基准值，之后减半。初始代码写成了"永不减速"还错算了台阶边界——修到三条检查通过：

```exercise
# @title: 两级台阶调度器
# @check: 0.8
# @check: 0.4
# @check: 0.4
# @hint: 台阶规则是 epoch ≥ 10 就折半（只折一次）；判断条件要用 >= 并且只挂一个门槛
base = 0.8

def lr_at(epoch):
    return base                        # ← 恒定步长版本，还没接台阶逻辑

for e in [8, 15, 25]:
    print(lr_at(e))
```

<details>
<summary>点开查看逐步解答</summary>

补上台价函数（一次折半，from epoch 10 起）：

```python
def lr_at(epoch):
    if epoch >= 10:
        return base * 0.5          # 第二级：0.4
    return base                    # 第一级：0.8
```

三个打印位分别落在 `epoch = 8`（未及台阶 → `0.8`）、`epoch = 15`（已下第一级 → `0.4`）、`epoch = 25`（题设只有一级台阶，不再继续折 → `0.4`）。假如把条件写成 `>`，epoch 10 当轮就会踏空；写成嵌套两级 `>=20` 再折，第三行会变 `0.2`——判题第二、三条正是卡这两个方向的偏差。
</details>

## 8. 选读证明：Cosine 的一半高度在哪

<details>
<summary>选读：半个训练周期时学习率剩多少</summary>

$\eta_e=\dfrac{\eta_0}{2}(1+\cos(e\pi/E))$ 在半程 $e=E/2$ 处有 $\cos(\pi/2)=0$，故恰好衰减到 $\eta_0/2$——这解释了 cosie 日志里常见的"中点附近 loss 斜率明显放缓"现象：步长的地板效应出现得比想象早。若不想让尾段太冷，可以改用 $\eta_0\cdot[0.95^{e}]^{...}$ 形式的指数缓和或在 cosine 上叠加最小值限幅 $\eta_{\min}$。所有这些花样的共同目的只有一个：让有效步长单调可预期地逼近 0，同时前期不给足够能量翻越宽谷。
</details>
