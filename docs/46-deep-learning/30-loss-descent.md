# 损失函数与梯度下降

## 1. 从一个场景开始

洗澡时调水温：手一伸，太烫——往冷拧一点；又太冷——再回一点。你并没有水温的精确公式，只靠**偏差的方向和大小**反复微调，几秒钟就到了舒适区。

神经网络训练就是这场"蒙眼调温"：网络输出 $\hat y$ 与正确答案 $y$ 的差距告诉你该往哪边拧上百万个旋钮（权重）。第 43 章已经学过梯度下降的通用套路，本课把它装进神经网络——重点看**损失怎么设计、学习率在真实训练里表现如何**。

## 2. 直觉解释

两个角色登场：

- **损失函数** $L$：给当前所有参数打一个"错得有多离谱"的总分——它是参数空间的**海拔**。参数错配，山就高；
- **梯度下降**：蒙眼下山法。脚底能感知哪边更陡（梯度），就朝最陡的下坡方向迈一小步；步长叫**学习率** $\eta$。

山有多复杂？每个权重是一根水平轴，百万参数就是百万维地形。好消息：第 20 章的偏导数告诉我们，多维山坡上"最陡方向"就是负梯度，而且每一维可以分开感知。

## 3. 正式定义

对样本 $(\vec x, y)$，模型输出 $\hat y$，最常用的均方误差（MSE）：

$$L = \frac{1}{n}\sum_{i=1}^{n} (y_i - \hat y_i)^2$$

平方有两重用意：正负误差不抵消；处处光滑可导（绝对值在零点有个尖角，导数会断）。

梯度下降更新公式：

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

| 符号 | 含义 |
| --- | --- |
| $\eta$ | 学习率：每步走多远，全训练过程最重要的超参数 |
| $\dfrac{\partial L}{\partial w}$ | 损失对该权重的偏导数：这一维上的坡度 |
| $\leftarrow$ | "用右边的新值覆盖左边的旧值"，编程里的赋值 |

## 4. 分步例题

**例**：玩具损失 $L(w) = (w-3)^2$（谷底在 $w=3$）。起点 $w_0 = 0$，学习率 $\eta = 0.1$。

1. 求导：$\frac{dL}{dw} = 2(w-3)$；
2. 第 1 步：$w = 0 - 0.1 \times 2 \times (0-3) = 0.6$；
3. 第 2 步：$w = 0.6 - 0.1 \times 2 \times (0.6-3) = 0.6 + 0.48 = 1.08$；
4. 第 3 步：$w = 1.08 + 0.1 \times 2 \times (3-1.08) = 1.464$。

序列 $0,\ 0.6,\ 1.08,\ 1.464,\dots$ 步子越走越小，稳稳滑向谷底 $3$。注意坡度本身随接近谷底而变小——**离目标越远修正越大**，这是平方损失的温柔之处。

### 实验 2：学习率滑块——步子大了扯着蛋

```python title="滑块实验：不同学习率的下山轨迹"
# sliders: lr=0.9 [0.05:1.05:0.05]
import matplotlib.pyplot as plt

w = 0.0                    # 起点
path = [w]                 # 记录足迹
for step in range(12):
    grad = 2 * (w - 3)     # L(w)=(w-3)^2 的导数
    w = w - lr * grad      # 梯度下降一步
    path.append(w)

print("终点 w =", round(w, 3), "（谷底是 3）")
plt.plot(path, marker="o")
plt.axhline(3, color="gray", linestyle="--")
plt.xlabel("step")
plt.ylabel("w")
plt.title(f"lr = {lr}")
```

拖动 `lr` 感受三种命运：太小（如 0.05）磨磨蹭蹭半天到不了；合适（约 0.9）一步到位附近；超过 1 直接**来回震荡甚至飞出天际**——每步迈过了头还越迈越远。学习率不是越大越快。

### 实验 3：两个参数的下山与损失曲线

```python title="二维参数空间里的梯度下降"
import matplotlib.pyplot as plt

a, b = -2.0, 2.0           # 两个待学参数
lr = 0.15
losses = []
for step in range(30):
    # 玩具损失 L(a,b) = (a-2)^2 + 2*(b+1)^2，谷底在 (2, -1)
    ga, gb = 2*(a - 2), 4*(b + 1)
    a = a - lr * ga
    b = b - lr * gb
    losses.append((a-2)**2 + 2*(b+1)**2)

print("终点 (a, b) =", round(a, 3), round(b, 3))
plt.plot(losses)
plt.xlabel("step")
plt.ylabel("loss")
plt.grid(True)
```

损失曲线一路下滑但越来越平——下降空间在耗尽。真实训练里这条曲线是你的**心电图**：一路陡降说明在学；早早躺平可能是卡住或已收敛；忽上忽下多半是学习率太大。

### 快问快答

```quiz
把学习率设成超大（比如 100）最可能发生什么？
- 收敛得特别快
- 每步跨过头，来回震荡甚至发散 [*]
- 结果不变，只是浪费算力
? 更新量 = 学习率 x 坡度。步长远超山谷宽度时会从坡的一侧直接荡到另一侧更高处，损失不减反增。
```

:::warning[常见误区]

**误区一**："训练损失降到 0 就是最好的模型。"——损失为 0 只说明它背下了训练数据，遇到没见过的数据可能一塌糊涂（下一课专门拆解过拟合）。

**误区二**："学习率应该一开始就调到最优。"——常用策略是从大到小逐步降（调度器），先大步赶路后小步对表。

**误区三**："梯度指向损失最小的点。"——梯度只指**当前点的局部最陡方向**，它不知道全局地形；所以可能停在山谷小坑（局部极小）或平台（鞍点）里。深度网络的实践结论：小坑遍地但大多足够好用。

:::

## 6. 练习

**练习 1**：$L(w) = (w+1)^2$，从 $w=1$ 出发、$\eta=0.5$，手动走两步，落在哪？

<details>
<summary>点开查看逐步解答</summary>

$L'(w) = 2(w+1)$。第 1 步：$1 - 0.5 \times 2 \times 2 = -1$——正好落在谷底！第 2 步梯度为 0，原地不动。巧的是这个组合（曲率 2、步长 1）一步收敛。
</details>

**练习 2**：修好下面的一次梯度下降（正确答案 3.0）：

**练习 3**：有人训练时发现损失越跑越大，列出两条可能原因并各配一句对策。

<details>
<summary>点开查看逐步解答</summary>

原因一：学习率过大——每步震荡放大，对策是把 $\eta$ 除以 10 再试；原因二：代码把更新写成了 $w + \eta \nabla L$（梯度**上升**），对策检查符号，负号才是下山。此外数据有异常值也会推高 MSE，可检查数据或换对离群点更稳的损失（如绝对值误差）。
</details>

## 7. 选读：为什么偏偏是负梯度方向？

<details>
<summary>选读 · 最速下降的一行论证</summary>

从当前点出发走一小段 $\Delta \vec w$，损失变化近似 $L(\vec w + \Delta \vec w) \approx L(\vec w) + \nabla L \cdot \Delta \vec w$（第 20 章的多元泰勒展开）。固定步长 $\lVert \Delta \vec w \rVert$，要使增量 $\nabla L \cdot \Delta \vec w$ 最小，由点积不等式，当且仅当 $\Delta \vec w$ 与 $\nabla L$ 反向时取最小值 $-\lVert \nabla L \rVert \cdot \lVert \Delta \vec w \rVert$。所以负梯度是**单位步长内下降最快的方向**——这就是"最速下降"的名字来源。
</details>
