# 万能逼近的几何直觉

## 1. 从一个场景开始

外卖平台想预测"雨天每个街区的外卖量"。街区地图复杂得像一张揉皱的纸：学校门口是高峰、立交底下是洼地、居民区随饭点起伏。写一条全局公式显然不行；但可以换个思路——**把地图切成一小块一小块，每块单独定价**，块足够小时任何怪地形都能贴出来。

神经网络声称"几乎任意弯曲的规律都能学"，底气正来自这个朴素策略：**许多个简单零件的拼接，足以雕刻任意复杂的形状**。本课就来看这句大话为什么不是吹牛。

## 2. 直觉解释

**核心直觉：一个神经元是一道"坡坎"，多层堆叠就是在纸上反复折叠。**

回顾第 10 课的单个神经元：输出是 $\sigma(wx+b)$，其中 $\sigma$ 是 S 形激活函数。改变偏置 $b$，这道"坡"会左右平移：

- $b$ 很大时整片区域几乎全亮（输出接近 1）；
- $b$ 很小时整片几乎全黑（输出接近 0）；
- 只有边界附近有一道急剧过渡的斜坡。

于是**每个神经元画下一条分界线，把平面切成亮暗两半**。

两个这样的神经元做组合就有意思了：

- **求交（AND）**："坡 A 的地盘 **且** 坡 B 的地盘"——夹出一条窄带；
- **求并（OR）**："A 或 B 任一亮起"——铺开一片更大的区域。

第三层继续对这些"窄带/亮片"求交求并——可用的形状数量**爆炸式增长**：2 个坡 1 种带形，4 个坡约十几段阶梯，8 个坡就已经能勾出一朵云的轮廓。折纸的经验同理：折痕每翻倍一次，能围出的多边形角数就翻倍不止。深度正是这样一层层"翻折"输入空间的。

## 3. 正式定义

万能逼近定理（Cybenko 1989；Hornik 1991）说的是：

> 只要隐藏单元足够多，单隐层网络就能在任意有限区间上以任意精度逼近任何连续函数 $f$：存在权重使得 $\bigl\lvert f(x)-\hat f(x)\bigr\rvert<\varepsilon$ 对一切样本点成立。

三个必须咬文嚼字的细节：

| 词 | 它承诺了 | 它没有承诺 |
| --- | --- | --- |
| 连续函数 | 弯曲规律都能贴 | 不连续的跳变不在 guarantees 里 |
| 存在权重 | 这样的网络有 | 没告诉你怎么训练找到它 |
| 足够多单元 | 上限是通的 | 可能要多到天文数字 |

所以这个定理给出的其实是**表达能力的天花板**，而不是"三层一定比十层差"。深度学习真正的赌注在于：深层网络的"折叠复用"能用**指数级少**的神经元达到同样精度——表达能力之外还有效率。

## 4. 分步例题

**任务**：用两个阈值单元夹出"$2\le x\le 5$ 时输出 1"的一维窗口。

1. 单元 A：$\sigma(6(x-2))$ ——在 $x<2$ 时趋于 0、$x>2$ 后趋于 1 的上升沿；
2. 单元 B：$\sigma(6(5-x))$ ——相反方向，$x>5$ 后熄灭；
3. 输出层做 AND：两信号相乘再加负偏置，如 $\sigma\bigl(12(A+B-1.5)\bigr)$——只有 A、B 同时接近 1 时才点亮；
4. 代入检查：$x=3.5$ 时 $A\approx1$、$B\approx1$，输出 $\approx1$ ✓；$x=1$ 时 $A\approx0$，$12(0+B-1.5)<0$，输出 $\approx0$ ✓。

窗口宽度由 $w=6$ 控制：权重越大坡越陡、边界越锋利。

## 5. 动手实验

拖动陡度滑块，亲眼看"软阶梯"如何逼近"硬开关"：

```viz
{
  "type": "plot",
  "title": "上升沿 σ(w(x−2))：w 越大越像开关",
  "expr": "1/(1+2.71828^(−w*(x−2)))",
  "xmin": -2,
  "xmax": 6,
  "sliders": [
    { "name": "w", "min": 0.5, "max": 12, "step": 0.5, "value": 2 }
  ]
}
```

再用两个上升沿拼出 AND 窗口，对照上面例题的每一个数字：

```python title="两道坡夹一条窗"
import matplotlib.pyplot as plt   # 绘图模块，别名 plt 是全站惯例
s = lambda v: 1 / (1 + pow(2.718281828459045, -v))   # S 形激活；pow 幂运算（受管内置）

def window(x):
    a = s(6 * (x - 2))    # 左墙上升沿
    b = s(6 * (5 - x))    # 右墙下降沿
    return s(12 * (a + b - 1.5))          # AND 汇合层

xs = [i * 0.05 for i in range(160)]       # 从 0 到 8 每 0.05 取一点
ys = [window(x) for x in xs]
plt.plot(xs, ys)
plt.xlabel("x")
plt.ylabel("output")
plt.show()

for probe in [1.0, 3.5, 7.0]:             # 例题三处抽查点
    print(probe, round(window(probe), 2))
```

抽查点输出 `1.0 0.0`、`3.5 1.0`、`7.0 0.0`——窗口外的点全部熄灭，窗口内点亮。

## 6. 常见误区

:::warning[常见误区]

- **"万能逼近说明神经网络上限很高，所以永远不会欠拟合"** —— 定理只谈表达力，不管训练能否找到那些权重；拟合能力还受优化与数据量限制（第 50 课的主角）。
- **"隐藏单元越多越好"** —— 单元数是容量旋钮，拧太大很容易把噪声也背下来。
- **"S 形的肩部更重要"** —— 起作用的主要是那段陡坡提供的'开关'非线性；平坦区只是背景色。

:::

## 7. 练习

把下面逻辑门的"伪装神经元"补完整——初始代码两处偏置写反了，导致 AND 长成了 OR：

```exercise
# @title: 用偏置摆布 AND 与 OR
# @check: 0
# @check: 0
# @check: 1
# @hint: AND 的门槛高（两根都要点亮才够），OR 的门槛低（一根就够）；阈值不合适就调 −1.5 和 −0.5 这两个数
def gate_and(a, b):
    return 1 if (a + b - 0.5) > 0 else 0      # ← 门槛太低了，现在的表现更像 OR

def gate_or(a, b):
    return 1 if (a + b - 1.5) > 0 else 0      # ← 门槛太高了，什么都不亮

print(gate_and(0, 1))
print(gate_and(1, 0))
print(gate_or(1, 0))
```

<details>
<summary>点开查看逐步解答</summary>

修正版只需要交换两个门槛：

```python
def gate_and(a, b):
    return 1 if (a + b - 1.5) > 0 else 0     # 两根绳子都得绷紧，和要 > 1.5

def gate_or(a, b):
    return 1 if (a + b - 0.5) > 0 else 0     # 一根在拉就算，和只要 > 0.5

print(gate_and(0, 1))    # 0
print(gate_and(1, 0))    # 0
print(gate_or(1, 0))     # 1
```

第一轮三条打印变成 `0`、`0`、`1`——AND 收紧成双保险，OR 放宽成一票通。这一对偏置之门正是上一节"窗口 AND"输出层的雏形：神经网络的一切形状，最后都落到这类门槛数字上。
</details>

## 8. 选读证明：折叠视角下单元数的效率

<details>
<summary>选读：为什么"深"比"宽"省料</summary>

设用单调递增的连续分段线性函数做基本零件（ReLU 网络）。宽度为 $d$、深度为 $l$ 的网络能够表示的分段线性区域数按 $O(m^{dl})$ 规模随深度**指数放大**（Telgarsky 2016），其中 $m$ 是每层坡坎数。反过来要在单隐层内手工数出同样多的区域，就需要单元数 $k$ 满足大致 $k^{d}$ 同阶——同样的精细程度，宽而浅的网络需要指数级更多的元件。

直观比喻：同样折 10 次，每次折半（深），一张纸有 $2^{10}=1024$ 格；若规定只许平行折 10 道（浅），格纹最多也就几十块。折叠方式的组合性才是效率来源——这也是后面残差连接（保持信息通路）如此重要的伏笔。
</details>
