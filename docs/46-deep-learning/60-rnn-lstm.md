# RNN 与 LSTM：把时间卷进网络

## 1. 从一个场景开始

听歌猜下一句，你靠的不是当前那一个音，而是前奏攒下的全部记忆；读"小明把书放下，因为他累了"，判断"他"指谁需要回头看过前半句。本章到目前为止的选手全是"一眼定终身"：MLP 与卷积看的是当前输入（卷积看的是当前图片里的相邻像素），**没有先后、没有记忆**。

可语音、文本、股价、心电全是序列：同样的输入，位置不同含义就不同。把网络改造成"边读边记"的循环结构，是 2017 年 Transformer 之前整整一代人的序列方案——本章补上这承前启后的一环。

## 2. 直觉解释

循环神经网络（RNN）的公式马上给出，先把画面立起来：

- **同一枚印章反复盖**：第 48 课卷积用同一枚小印章盖遍全图（空间上的权值共享）；RNN 用同一组权重沿时间步一步步盖下去——"第 1 步的 h"和"第 100 步的 h"用的是同一套参数。序列可长可短，参数量纹丝不动；
- **一本滚动的剧情笔记**：每一步，网络一手看当前输入 $x_t$，一手翻看上一步记下的笔记 $h_{t-1}$，写出一版新笔记 $h_t$。笔记就是"记忆"——它被压成固定长度的向量，走到哪带到哪。

训练时把循环**沿时间展开**：复制 20 份同一张图，首尾相接排成一列深网（展开图），第 40 课的反向传播照用——梯度从损失出发一路传回第 1 步。要命的事就出在这条回传路上：**每跨一步都要乘一次同一组权重**，连乘 20 次，比第 65 课的深网问题来得更凶。

LSTM 的对策先把结论放在这：给网络配三扇门（遗忘、输入、输出），让"记什么、忘什么、用多少"变成可学习的开关，其中细胞状态用**加法**更新——相当于提前十几年给时间轴铺了一条残差式的高速路。

## 3. 正式定义

单层 RNN 每一步（$t=1,2,\dots,T$）：

$$h_t=\tanh(W\,h_{t-1}+U\,x_t+b)$$

| 符号 | 含义 |
| --- | --- |
| $x_t$ | 第 $t$ 步的输入（一个字 / 一帧声音） |
| $h_{t-1}\to h_t$ | 剧情笔记：上一步的隐状态，本步更新它 |
| $W$ | 跨时间步的权重：**每个时间步都用同一个**（权值共享的时间版） |
| $U, b$ | 输入的权重与偏置，同样全步共享 |
| $\tanh$ | 把笔记压进 $(-1,1)$，防止滚雪球 |

损失对远离出口的参数求导时（沿时间反向传播，BPTT），链式法则的因子里反复出现同一项：

$$\frac{\partial h_{t}}{\partial h_{t-1}}=W^{\mathsf T}\operatorname{diag}(1-h_t^2)$$

**T 步就是 T 个这样的因子连乘**。直觉刻度：$W$ 的尺度小于 1 时连乘指数坍缩（梯度消失，远处的字学不到）；大于 1 时指数膨胀（梯度爆炸，训练一步跳飞）。更麻烦的是 $\tanh$ 的饱和：笔记一旦接近 $\pm 1$，因子 $(1-h_t^2)\to 0$，连"大于 1"的那一支也终被拖回消失。三扇门的 LSTM（1997）就此登场：

$$f_t=\sigma(\cdot)\qquad i_t=\sigma(\cdot)\qquad o_t=\sigma(\cdot)\qquad c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t\qquad h_t=o_t\odot\tanh(c_t)$$

| 门 | 开度 $\to$ 作用 |
| --- | --- |
| 遗忘门 $f_t$ | 旧账 $c_{t-1}$ 保留几成（1 = 全留，0 = 全忘） |
| 输入门 $i_t$ | 新事 $\tilde c_t$ 记入几成 |
| 输出门 $o_t$ | 记忆 $c_t$ 暴露几成给外界当 $h_t$ |

细胞状态的更新是**加法**：遗忘门贴近 1 时，梯度沿 $c$ 这条线跨步几乎无损——这正是下一课残差连接的思想，提前 18 年出现在时间轴上。

## 4. 分步例题

**例**：最简 RNN 走四步。取 $W=0.6$（标量），$U=1$，$b=0$，输入 $x_1=1$，其余三步 $x=0$，$h_0=0$：

1. 第 1 步：$h_1=\tanh(0.6\times0+1)=\tanh(1)\approx0.7616$；
2. 第 2 步：$h_2=\tanh(0.6\times0.7616)\approx\tanh(0.4570)\approx0.4276$；
3. 第 3、4 步同法：$h_3\approx0.2511$，$h_4\approx0.1495$——输入只在第 1 步出现过，却一步步留在笔记里，只是**每步打个对折再乘 0.6**；
4. 反过来看梯度：每跨一步乘因子 $W(1-h_t^2)$，四步分别是 $0.252,\ 0.490,\ 0.562,\ 0.587$，连乘只剩 $0.041$——第 1 步的输入对第 4 步损失的发言权不足百分之五；
5. 刻度感：这样的因子连乘 20 步约 $0.6^{20}\approx3.7\times10^{-5}$（下节实测）——**"开头很重要"这件事，RNN 越读到后面越学不到**。

### 实验 2：手搓 RNN 前向 + 二十步梯度连乘实测

```python title="单元 RNN：前向走四步，梯度连乘看两种命"
import math                                 # math.tanh 已在第 40 课出生

w, u = 0.6, 1.0                             # 跨步权重与输入权重（标量版）
h = 0.0                                     # 初始笔记：一片空白
for xt in [1, 0, 0, 0]:                     # 输入只有第 1 步是 1
    h = math.tanh(w * h + u * xt)           # RNN 核心一行：旧笔记+新输入过 tanh
    print(round(h, 4))

def grad_product(w, steps):                 # 梯度因子连乘（输入为零的松弛段）
    hh = 0.0001                             # 笔记很小，尚未触发 tanh 饱和
    prod = 1.0
    for t in range(steps):
        hh = math.tanh(w * hh)
        prod = prod * (w * (1 - hh * hh))   # 每跨一步乘一次 W^T·diag(1-h^2)
    return prod

for w in (0.8, 1.2):
    vals = [round(grad_product(w, t), 4) for t in (5, 10, 20)]
    print(f"w={w}: 连乘 5/10/20 步 =", vals)
```

打印与例题严丝合缝：四步笔记 `0.7616, 0.4276, 0.2511, 0.1495`。连乘账更刺眼——$w=0.8$ 时二十步只剩 `0.0115`（正是 $0.8^{20}$，梯度蒸发百倍）；$w=1.2$ 时二十步膨胀到 `38.3`（爆炸）。小尺度下连乘就是 $w^t$ 本身：**1 的左侧是遗忘，右侧是雪崩**。

### 实验 3：LSTM 三扇门走账

给一帧具体的账：旧细胞账 $c=4$，候选新事 $\tilde c=2$，三扇门开度各为 $0.5,\ 0.2,\ 0.9$，逐项过账：

```python title="LSTM 一帧账本：忘多少、记多少、露多少"
import math

c_prev, cand = 4.0, 2.0                     # 旧细胞账、候选新事
f_gate, i_gate, o_gate = 0.5, 0.2, 0.9      # 遗忘/输入/输出门的 sigmoid 开度

c_new = f_gate * c_prev + i_gate * cand     # 加法记账：旧账打五折，新事记两成
h_new = o_gate * math.tanh(c_new)           # 输出门九成开：暴露九成记忆
print("c_new =", round(c_new, 4), "  h_new =", round(h_new, 4))
```

读账：$c_{\text{new}}=0.5\times4+0.2\times2=2.4$——旧账保留一半、新事记入零点四；输出门放行九成，$h_{\text{new}}=0.9\times\tanh(2.4)\approx0.8853$。对照裸 RNN 的"整本笔记每步重写"：LSTM 把"写入"与"擦除"拆成独立的可控开关，梯度也因此能沿加法线跨步流动。

::::warning[常见误区]

**误区一**："RNN 每个时间步有各自的权重。" 展开图看着像 20 层各管各的，其实全部时间步**共享同一组** $W, U, b$——正因为共享，序列任意长参数都不涨，也因为共享，梯度才连乘同一个 $W$。

**误区二**："梯度爆炸不算病，把它裁剪掉就没事了。" 梯度裁剪（超长就按比例缩回）确实能防训练炸飞，但治标不治本：被裁过的梯度等于没按真实地形走，且消失的那一支裁剪根本管不着——所以门控结构才是对症药。

**误区三**："LSTM 彻底解决了长程记忆。" 它把"能用"的范围从十几步拉长到几百步，代价是逐步串行、无法并行；几千步的依赖依旧吃力。Transformer 用注意力一步直达任意位置，正是从这条瓶颈上越过去的（第 47 章见）。

::::

## 6. 练习

**练习 1**（概念）：卷积（第 48 课）与 RNN 都讲"权值共享"，共享的方向有什么不同？各自换来了什么？

<details>
<summary>点开查看逐步解答</summary>

卷积在**空间**共享：同一枚核盖过图像每个位置，换来平移稳健与参数瘦身；RNN 在**时间**共享：同一组权重走过每个时间步，换来"序列任意长、参数不涨"。代价也成对出现：卷积的共享局限在局部邻域，RNN 的共享让梯度沿时间连乘——前者催生了堆叠与残差，后者催生了门控与注意力。
</details>

**练习 2**（判题）：实验 3 的账本已经摆好，但下面这段代码把门全绕开了——旧账原封不动全收、新事全额入账，账面立刻虚胖。修好门控那一行：

```exercise
# @title: 练习：把三扇门装回 LSTM 的账本
# @check: 2.4
# @check: 0.8853
# @hint: 加法记账一行：c_new = f_gate*c_prev + i_gate*cand；旧账打五折、新事记两成，输出门只影响 h。
import math                                 # 用 math.tanh 压缩输出

c_prev, cand = 4.0, 2.0                     # 旧细胞账、候选新事
f_gate, i_gate, o_gate = 0.5, 0.2, 0.9      # 三扇门的开度（不许动）

c_new = c_prev + cand                       # ← 错了：门全被短路，旧账新事全额入账
print(round(c_new, 4))

h_new = o_gate * math.tanh(c_new)
print(round(h_new, 4))
```

修好后输出 `2.4`、`0.8853`。短路版会打出 `6.0` 和 `0.9`：账面虚胖到接近 $\tanh$ 的天花板，记忆却毫无取舍——门控的全部意义，就是让"忘与记"成为可学习的决策。

**练习 3**：把实验 2 的 `grad_product` 换成 $w=1.05$ 跑 20 步，再跟 $w^{20}$ 对照；想想 50 步、500 步后这股慢火会发生什么。

<details>
<summary>点开查看逐步解答</summary>

$1.05^{20}\approx2.65$，与实测基本重合——小尺度下连乘就是 $w^t$。步数拉长后两件事发生：一是 $1.05^{500}\approx4\times10^{10}$，慢火也成爆炸；二是笔记 $h$ 被推大，$\tanh$ 进入饱和、因子 $(1-h^2)$ 变小，膨胀被一点点按回去。所以真实的 RNN 训练常见"先炸后瘫"的组合症状——梯度裁剪管前半场，LSTM 的门与饱和结构管后半场。
</details>

## 7. 选读：门控与残差，同一件事的两次发明

<details>
<summary>选读 · 加法线上的梯度通行证</summary>

对 LSTM 细胞状态 $c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t$ 求导：$\partial c_t/\partial c_{t-1}$ 里有一项对角阵 $\operatorname{diag}(f_t)$。训练会学会在关键路径上把 $f_t$ 顶到接近 1——此时梯度像走直通线一样跨步流过，几乎无衰减；需要遗忘时再把门拧小。对照下一课的残差块 $y=F(x)+x$：恒等线上的 $\partial y/\partial x$ 含一个实打实的 $+1$。同一个处方，1997 年开在时间轴（LSTM 的常数误差流水线），2015 年开在深度轴（ResNet）——深度学习反复回到这个朴素真理：**想保住信号，就修一条加法的高速路**。GRU 把三扇门精简为两扇（更新门兼管遗忘与输入），账本更薄、效果相当，是 LSTM 的常用平替。
</details>
