# 哥德尔不完备定理选讲

## 1. 从一个场景开始

1930 年代的数学家有一个宏伟梦想：为全部数学写一本"完美说明书"——里面每句真话都能被证明，而且这本说明书还能自证清白、说明自己不撒谎。希尔伯特把它叫作数学的"纲领"，连墓志铭都拟好了："我们必须知道，我们必将知道。"

1931 年，25 岁的哥德尔把梦敲碎了。他证明：只要这套系统强到能容纳算术——能数数、会加法乘法——就必然出现"明明是真话却永远证不出来"的句子，而且系统也没法在自己的地盘里证明自己前后一致。本章是可计算性之旅的收官站：停机问题挡住了机器的边界，不完备定理挡住了证明的边界，两者其实是同一堵墙的两面。

## 2. 直觉解释

从最老的自指句子玩起：

- "这句话是假的。" ——它真则假、假则真，逻辑当场死机；
- 改造一下："这句话**不可证明**。" ——注意这次的处境完全不同了：如果系统能证明它，那它说的是真话（因为被证出来了），可它的内容恰是"我不可证"；如果系统证不出它呢？那它说的恰恰兑现了。

第二种改造妙在不再伤及真假概念，只是给"证明"出了一道无解题。剩下唯一的逃生通道是：万一这个句子本身在系统看来就是胡话呢？哥德尔的杀招在这里登场——**把句子变成数字**。就像每个网页都有网址、每本书都有 ISBN，哥德尔发明了一套编号法，让每个符号、公式乃至"证明过程"都领到一个自然数。于是"关于数的命题"可以谈论另一条命题的编号，指着自己的鼻子说话不再是比喻，而是算术内部的合法操作。

与停机问题的分工也一目了然：对角线翻转用在了不同地点。停机问题让程序读自己的代码，不完备定理让证明谈论自己的编号；一个堵死"判定一切"，一个堵死"证明一切"。

## 3. 正式定义

**哥德尔编码**：固定一套形式语言的符号表，给每个符号配一个编号；长度为 $k$ 的公式串 $\langle s_0,s_1,\ldots,s_{k-1}\rangle$ 编码为

$$\mathrm{code}(F)=p_0^{\#(s_0)}\cdot p_1^{\#(s_1)}\cdots p_{k-1}^{\#(s_{k-1})}$$

其中 $p_i$ 是第 $i$ 个素数，$\#(s)$ 是符号 $s$ 的编号。素因子分解的唯一性保证可以无损解码回原式——数字与文本从此互译。

三个关键术语：

| 名词 | 含义 | 反面 |
| --- | --- | --- |
| 完备 | 每个真的闭语句都可证，或其否定可证 | 有"漏网真话" |
| 一致 | 推不出互相矛盾的成对结论 | 连什么都能证 |
| 足够强 | 能表达并操作自然数的加减乘 | 只能聊很浅的结构 |

**第一不完备定理**：任何一致且足够强的形式系统 $F$ 中，都存在一条闭语句 $G_F$ 使得 $G_F$ 与其否定都不可证（于是 $G_F$ 是"真但不可证"——它在标准自然数模型里取值为真）。

**第二不完备定理**：上述一致性本身——写成算术语句记作 $\mathrm{Con}(F)$——也无法在 $F$ 内部证明。想让系统为自己担保，只能搬出更强的系统，而更强的系统又需要更强者担保，节节后退没有尽头。

编码技术的另一个直接受益者是"可计算"的形式化：既然命题是数字，证明搜索就是在数字上跑程序——第 35 课停机问题里的图灵机与这里的公理系统说的是同一种方言。

## 4. 分步例题

构造那颗定时炸弹只需六步：

1. 编号：把 $F$ 的每条公式映射到自然数（见上节编码式）；
2. 表示："编号为 $n$ 的公式存在长度为 $m$ 的证明"是一句**纯算术**的话，可以在 $F$ 内部写出对应公式 $\mathrm{Proof}(n,m)$；
3. 对角线：手工造一条特殊公式，它的含义翻译过来是"编号等于我自己的那条语句不可证"——存在性由不动点技巧（同一套编码 + 代入）机械保证；
4. 叫它 $G_F$；
5. 若 $F$ 证明 $G_F$：则"$G_F$ 不可证"成为事实，而 $F$ 能表示这个事实，$F$ 推出了矛盾——违反一致；
6. 若 $F$ 证明 $\neg G_F$：等价于声称"找到了 $G_F$ 的证明编号"，可在标准自然数里实际核对那个编号并不存在，$F$ 再次撒谎——除非它不一致。

两条腿都被砍断，只剩中间态：$G_F$ 与 $\neg G_F$ 都推不出。而在我们头顶真实的自然数世界里它是真的——一段被证明"真诚却失语"的数学。

### 实验 2（python）：亲手做一次迷你哥德尔编码

```python title="玩具字母表的编号实验"
alphabet = {"S": 2, "0": 3, "+": 5}     # 字典：符号 -> 符号编号
primes = [2, 3, 5, 7]                    # 位置素数表：第 i 个字符用第 i 个素数承载

def encode(text):
    total = 1
    for i in range(len(text)):           # len(text)：字符串长度，range 按下标遍历
        ch = text[i]                     # text[i]：取出第 i 个字符
        total = total * primes[i] ** alphabet[ch]   # ** 是幂运算：素数的“符号编号”次方

    return total

print(encode("S0+S"))    # 四个符号：2^2 * 3^3 * 5^5 * 7^2
print(encode("+"))

# 解码演示：反复除以同一个素数，数清除干净用了几次幂
code = encode("S0+S")
exp_first = 0                            # 记录位置 0 的素数 2 的指数
while code % 2 == 0:                     # % 取余：能整除说明还有这一位信息
    code = code // 2                     # // 整除：剥掉一层素数 2
    exp_first += 1                       # exp_first += 1 即 exp_first = exp_first + 1

print(exp_first)
```

输出依次是 `16537500`、`32` 和 `2`：巨大整数虽然离谱，却真实载着完整句子——除回来看，第一个位置的指数恰好是符号 S 的编号 2。每个公式独占一个号码，两个公式永不撞号（算术基本定理），这就是"系统可以安全谈论自己"的全部技术底座。

:::warning[常见误区]

**误区一**："所有数学都不确定了。" 定理只约束**足够强且一致**的公理系统：欧氏几何可以做完备公理化，皮亚诺弱化版也有完备扩张。垮掉的只是"一套 package 通吃包括算术在内的一切"这种野心。

**误区二**："哥德尔句是玄学。" $G_F$ 展开之后是一条彻头彻尾的普通算术命题——关于某个大数的素因子和多项式方程有没有解那种级别，一点神秘主义成分都没有。

**误区三**："人脑优于机器，所以定理证明人类更强。" 这是对第一定理最常见的越界解读。定理管的是**形式系统的表达能力**，从没参与"人与机器谁更聪明"的竞赛；历史好几次有人借它宣传神秘主义，哥德尔本人明确拒绝。

**误区四**："第二定理告诉我们永远无法知道数学是否一致。" 可以在任何**更强**的系统里证明原系统一致——只是这套担保链条无限后撤，没有一个免费的终点。
:::

## 6. 练习与快问快答

先跑通下面这份编码器，再修掉它的病：`total` 那一行把幂运算写成了普通乘法——所有句子的编码瞬间缩水，还会意外撞号：

```exercise
# @title: 练习：修好像样的哥德尔编码器
# @check: 16537500
# @check: 32
# @hint: 第 i 个位置的贡献是「位置素数的（符号编号）次方」，不是位置素数乘符号编号；检查 ** 是否丢在了改写过程中。
alphabet = {"S": 2, "0": 3, "+": 5}
primes = [2, 3, 5, 7]

def encode(text):
    total = 1
    for i in range(len(text)):
        ch = text[i]
        total = total * primes[i] * alphabet[ch]   # ← 这里缺了一个关键动作

    return total

print(encode("S0+S"))
print(encode("+"))
```

<details>
<summary>点开查看逐步解答</summary>

补回幂运算即可：

```python
total = total * primes[i] ** alphabet[ch]
```

四个位置分别贡献 $2^2=4$、$3^3=27$、$5^5=3125$、$7^2=49$，总码 $4\times27\times3125\times49=16537500$。第二问 `+` 独占首位：$2^5=32$。若沿用错误版本会逐位退化成连乘，得到 $12600$ 与 $10$——数值骤缩不是毛病本身，真正的要害是编码失守：指数信息全丢，不同句子挤进同一个号码的概率大增，唯一分解的担保随之作废，整个"谈自己"的魔法立即熄火。
</details>

## 7. 选读：不完备、不可判定与真的层级

<details>
<summary>选读 · 三兄弟的家谱关系</summary>

三件事常被混为一谈：**不完备**（某系统里有真话证不出）、**不可判定**（没有总停机算法分辨任一命题的真假）、**真不可定义**（塔斯基：在系统内部无法定义"本系统内的真"）。家谱是递进的：先有编码术把语法数字化，塔斯基指出语义概念"真"没法在同一层语言里安放；哥德尔借用语法层的"可证"造出自指句，绕开了塔斯基的封锁；图灵再把"可证等价于存在有限证明对象"翻成停机问题，得到不可判定的机械版本。三层障碍层层加固：想靠升级判定器突破第一层的人，会在停机问题面前撞上同一堵墙（第 40 课归约的又一战果）；想要绝对真理的人则被塔斯基请到了更高的楼层。

尾声送给旅行者：从"能不能算"（第 15–45 课）到"能不能证"（本课）再到后续章节的"能不能学"（统计学习理论的极限），这条边界学路线将贯穿余下旅程。
</details>

## 8. 边界：本课不做什么

换一种说法收个尾：本课不解决任何具体猜想的证明问题——黎曼假设该证还得证；它划掉的是一个纲领性幻想：不存在一台万能证明机兼一套自洽说明书。识别边界后反而轻松了——第 56 章「AI for Math」正是在边界内起舞的工程学：让机器批量生成候选猜想、调度自动证明器、验证残差，人们学会了在没有完美判决台的比赛里打球。
