# 对象与态射：只保留箭头的世界

## 1. 从一个场景开始

第 33 章研究群时，真正干活的是同态映射：它告诉你两个群"结构相同"哪怕元素名字完全不同。把这条经验推到极致会怎样——**干脆把对象的内部全部涂黑**？不问集合里装了什么、群里有几个元素，只留下两样东西：点（对象）和点与点之间的箭头（态射）。

这不是偷懒，而是一次大胆的降维：地图不在乎两座城市由什么原子构成，只在乎公路怎么连。范畴论就是数学世界的纯路网图，而你会发现 Python 的函数、矩阵、类型转换器全都长着同一张箭头脸。

## 2. 直觉解释

以集合范畴 $\mathbf{Set}$ 为例：点是集合，箭头是函数。每个点有一支指向自己的自环箭头——恒等函数 $id_A$；首尾相接的箭头可以焊接：$f$ 接 $g$ 得到复合 $g\circ f$。

拿三个有限小集合练手：$A=\lbrace 1,2\rbrace$、$B=\lbrace u,v\rbrace$、$C=\lbrace 0,1\rbrace$。取函数 $f:A\to B$ 与 $g:B\to C$，则 $g\circ f:A\to C$ 自动存在；换一支 $f'$ 再接 $g$，得到另一支新箭头。箭头的库存和焊法，就构成了一个活生生的小世界。

再往抽象处走一步：群范畴里每个群塌缩成**一个点**，群元素全变成这支点的自环箭头，合成律就是群的乘法——第 33 章的整座大厦被折进一张只有一行的地图。偏序集也能当范畴：对象是元素，$x\le y$ 时恰好有一支箭头 $x\to y$。同一个语言，覆盖面大得惊人。

## 3. 正式定义

**定义（范畴）**：一个范畴由以下数据组成：

| 组成件 | 记号 | 说明 |
| --- | --- | --- |
| 对象 | $A,B,C,\dots$ | 不问内部结构，只是节点 |
| 态射 | $f:A\to B$ | 每支箭头有确定的起点与终点；全体记 $\mathrm{Hom}(A,B)$ |
| 复合 | $g\circ f:A\to C$ | 仅当 $f:A\to B$ 且 $g:B\to C$ 时可焊 |
| 恒等 | $id_A:A\to A$ | 每个对象自带 |

且满足两条公理：

$$g\circ(h\circ f)=(g\circ h)\circ f\qquad f\circ id_A=f=id_B\circ f$$

结合律说焊法不影响结果；单位律说恒等箭头是"白接"。注意两条公理只谈箭头，对对象内部只字未提——这就是"涂黑"的法律效力。

**重要口诀**：$g\circ f$ 读作"先走 $f$，再走 $g$"——顺序从右往左，与函数复合的传统写法一致，也是新手最容易踩的坑。

## 4. 分步例题

**例**：验证一个三对象自由范畴的合成表。设生成箭头 $a:A\to B$、$b:B\to C$（外加各对象的恒等）。

1. 列出全部态射：$id_A,id_B,id_C,a,b,b\circ a$——共 6 支；
2. 问 $A\to C$ 有几支？只有 $b\circ a$ 一支：生成箭头没有别的组合方式；
3. 验证单位律：$a\circ id_A=a$ ✓，$id_B\circ a=a$ ✓；
4. 验证结合律：这里只有一个非平凡三元组，$(b\circ a)$ 与谁结合都还原为自身 ✓；
5. 结论：这是一个合法的小范畴。"自由"指它只含公理逼出来的箭头，一根多余的都没有。

## 5. 动手实验

### 实验 1：亲手把箭头拼成合法函数

```viz
{
  "type": "set-mapper",
  "title": "函数即态射：左侧每点必须恰好引出一支箭",
  "left": ["1", "2", "3"],
  "right": ["u", "v"],
  "arrows": [[0, 0], [1, 1], [2, 1]]
}
```

点击中间的圆点增删箭头。组件实时判定当前关系是不是函数（态射）：每个输入必须恰好一支出箭——这正是 $\mathbf{Set}$ 范畴里"态射资格"的全部要求。试着删掉一支或加到两支，看判定怎么报警。

### 实验 2：用字典实现小范畴并核对公理

```python title="字典态射：先 f 后 g 的焊接术"
f = {1: "u", 2: "v", 3: "v"}   # 态射 f：输入数字，输出字母
g = {"u": 0, "v": 1}           # 态射 g：输入字母，输出数字

composed = {}                   # 准备存放复合结果 g∘f
for x in f:
    mid = f[x]                  # 先走第一步：查 f
    composed[x] = g[mid]        # 再走第二步：拿中间结果查 g
print(composed)

wrong_order = {}
for x in g:                     # 反过来"先 g 后 f"试试
    wrong_order[x] = f[g[x]]
print(wrong_order)
```

第二行代码能跑纯属侥幸——`g` 的键恰好都在 `f` 的值域里。顺序反了，终点对不上起点，范畴论管这叫"不可复合"；Python 用 KeyError 表达同一件事。

### 快问快答

```quiz
范畴论里的"态射"一定是集合之间的函数吗？
- 是，否则没法复合
- 不是，群同态、矩阵、单调映射都可以充当态射 [*]
- 是，但必须是双射
? 态射只需满足"可复合 + 结合律 + 单位元"，群同态与矩阵都是合法态射，甚至不必是映射。
```

:::warning[常见误区]

**误区一**："对象相等才重要。"
范畴论的价值观相反：对象相等几乎从不出现，**同构**（有来有回、来回都白接的一对态射）才是"一样"的正确说法。问"A 和 B 相不相等"没意义，问"它们之间有没有同构"才有意义。

**误区二**："$g\circ f$ 就是先 $g$ 后 $f$。"
符号从右往左读：$g\circ f$ 先执行 $f$。实验 2 的 `wrong_order` 就是这个坑的现场照片。

**误区三**："结合律是需要证明的深刻定理。"
在一般范畴的定义里它是**公理**——你要做的是检查手头的小范畴是否真的满足它（例题第 4 步那样逐个核对）；只有在 $\mathbf{Set}$ 这类具体范畴里，它能从函数合成的结合律推出来。

:::

## 6. 练习

**练习 1**：下面的程序想算复合 $g\circ f$ 在三个输入上的值，但焊接次序错了：

```exercise
# @title: 练习：按正确次序焊接态射
# @check: 5
# @check: 7
# @check: 7
# @hint: g∘f 表示先走 f 再走 g：先用 x 查 f 得中转站，再用中转站查 g。
f = {1: 2, 2: 3, 3: 3}   # 态射 f：三个输入各自的中转站
g = {2: 5, 3: 7}         # 态射 g：从中转站出发的第二程

for x in [1, 2, 3]:
    stop = f[f[x]]       # ← 问题在这：这算的是 f∘f 还是 g∘f？
    print(stop)
```

修好后输出 5、7、7：输入 1 经中转站 2 抵达 5；输入 2、3 都经站 3 抵达 7。初始代码连续走了两次 f，所以只会输出 3、3、3。注意 2 和 3 的像重合——态射不必单射，范畴论对此毫不介意。

**练习 2**：证明"单对象范畴"里的全体自环态射恰好构成一个幺半群（有结合乘法和单位元的代数结构），并指出第 33 章的哪个概念是它的特例。

<details>
<summary>点开查看逐步解答</summary>

只有一个对象 $*$ 时所有态射都是 $*\to *$，任意两支都可复合，所以复合是这些态射上的二元运算：结合律与单位律直接继承范畴公理——这正是幺半群的定义。反之任何一个幺半群都能立起一个单对象范畴。特例：把幺半群换成群（每个态射还可逆），就得到第 33 章"群同态即保结构映射"一课的单对象视角——群同态恰好是这类"一行范畴"之间的函子，这位主角在两步之后的[函子](./30-functors.md)课正式登场。
</details>

## 7. 选读：为什么"涂黑"反而看得更清

<details>
<summary>选读 · 结构主义的胜利</summary>

1945 年 Eilenberg 与 Mac Lane 提出范畴论，初衷很务实：给"自然"这个词下定义（两步之后的自然变换课见分晓）。但它迅速暴露出更大的野心——数学里大量定理的内容其实与对象内部无关，只与箭头的接线方式有关。拓扑里的连续映射、线代里的线性映射、逻辑里的推理规则，全都服从同一套复合语法；把语法抽出来，一条定理就能同时统治三个领域。这种"看结构不看材料"的哲学后来渗透进编程语言（接口与泛型）、物理（量子力学的组合语义）乃至机器学习的架构设计——泛性质留待后续课程，它会给你第一个震撼样本。

</details>
