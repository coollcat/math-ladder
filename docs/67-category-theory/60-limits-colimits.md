# 极限与余极限速览

## 1. 从一个场景开始

两家外卖平台的会员档案要合并，可它们各自只记录了与你绑定的**代理编号**，真正核对身份得经由共同的总库：平台甲说"编号 7 是你"，总库确认"编号 7 指向张三"；平台乙那边则要用另一个入口对上同一个真人。合并的关键动作因此只有一种——把两边各自指向同一条总库记录的条目**两两配对**。

这不是一次性的手工活，而是一台机器：给它一张"多箭头拼出的小图案"，它自动产出图案的**最佳观测台**（极限）或**最省料的焊接件**（余极限）。本课用五分钟走完这台机器的正反两面。

## 2. 直觉解释

先把"图案"这个说法钉牢：范畴里的一撮对象加几支箭头（比如三枚点、两条边）就是一个**图形**；把它搬进 $\mathcal C$ 里住下，得到一户"实拍住户"。所谓锥形，是站在图案上方造一座观测台 $W$，台上向每户居民各引一支下山道，且经过中转绕路的两条上下行永远重合（方形条件）。

- **极限 = 终端观测台**：在所有合格观测台中，没有任何一个能再瘦身的那个——别的观测台都能以唯一方式从山上接驳到它；
- **余极限 = 初始焊接件**：把图案各户按图上箭头**粘死**后得到的最小成品，任何其他焊法都只能以唯一方式从它这里继续加工。

三个世界的落地样本：
- **Set 世界**：最常见的极限是拉回方块（下图），元素就是"逐点对上暗号"的配对集；最常见余极限是推合——给并集贴上"经箭头认亲"的等价标签；
- **偏序世界**：极限退化为最大下界、余极限是最小上界——$\gcd/\mathrm{lcm}$ 那套方言又见面了；
- **Python 世界**：字典按键比对取交集就是一台微型拉回机：两个 key 表 + 各自指向同一 value 库，配对结果一目了然。

## 3. 正式定义

以图案取**余角形**（两支箭头共指一点）为例：$X\xrightarrow{f}Z\xleftarrow{g}Y$。

$$\mathrm{PB}=\lbrack(x,y)\in X\times Y:\ f(x)=g(y)\rbrack$$

它的两支投影 $p,q$ 自动满足 $f\circ p=g\circ q$；而对任何同时满足该等式的 $W$ 与 $l,r$：

$$\text{存在唯一 } \phi:W\to \mathrm{PB}\ \text{ 使 }\ p\circ\phi=l,\ q\circ\phi=r$$

```text
            W ──r──→ Y
            │        │
          l │        │ g        方形闭合即 f∘l = g∘r；
            ▼        ▼        拉回观测台是所有闭合方块的终端接收器。
            X ──f──→ Z
```

一般定义只需换掉图案：任意图形 $J$ 配函子 $D:J\to\mathcal C$，全体锥形经自然性方式串联成新范畴，其终对象叫 $\lim D$、初对象叫 $\mathrm{colim}\,D$（后者也写作余极限）。积、余积正是单点脱离型图案的特例——本课设备与上一课完全兼容。

## 4. 分步例题

设总库 $Z=\lbrace 1,2\rbrace$；平台甲的指派 $f:X\to Z$ 中，送到 $1$ 的有两位、送到 $2$ 的有一位；平台乙的指派 $g:Y\to Z$ 中，送到 $1$ 的有一位、送到 $2$ 的有两位。

1. 合法配对必须"同指一位真人"，按去向分柜台清点：去 $1$ 的档口提供 $2\times1=2$ 对，去 $2$ 的档口提供 $1\times2=2$ 对；
2. 合计 $2+2=4$ 组人马入驻观测台；
3. 抽查闭合条款任选一对 $(x,y)$：沿左路先降落到甲平台再查 $f$，与右路先归档乙平台再查 $g$，因配对规则恰好相等 ✓；
4. 观测台的两支投影分别摘出姓名字段——即是 $p$ 与 $q$；
5. 若某天总库新增第三个通道，机器无须返工：分柜清点、乘法汇总，照办即可。这个"分柜相乘求和"的公式正是 Set 世界拉回的心跳。

## 5. 动手实验

### 实验 1：微型拉回机当场开火

```python title="拉回：对上暗号的合法配对清单"
z_people = {1: "张三", 2: "李四"}         # 总库：编号对应真人

f_table = {"a1": 1, "a2": 1, "a3": 2}    # 平台甲：条目→总库编号
g_table = {"b1": 1, "b2": 2, "b3": 2}    # 平台乙：另一套条目→同一总库

matched = []
for x in f_table:
    for y in g_table:
        if f_table[x] == g_table[y]:     # 双方经各自映射落到同一编号才放行
            matched.append([x, y])
cone_ok = True
for item in matched:                     # 抽查闭合条款：左右两路的落点应一致
    if f_table[item[0]] != g_table[item[1]]:
        cone_ok = False
print(len(matched))
print(cone_ok)
```

输出 `4` 与 `True`：a1、a2 两位张三相的条目各与 b1 结成一对，a3 则与 b2、b3 各成一对——打印 `matched` 细看，配对清单恰好按总库编号分成两个柜组。

## 常见误区

:::warning[常见误区]

**误区一**："极限是一个过程，越跑越靠近某个值。"
分析课里的那类极限固然同名，此处却是一件**静态议价品**：它一次性包揽了"所有合格观测台的收编权"。之所以共用名字，是因为两者都在刻画"别处无法更优"的临界身份——注意区分语境即可，不必强行寻找函数式隐喻。

**误区二**："余极限就是把东西堆到一起。"
堆叠不消歧。两支源箭头若把同一成员发往不同批次，焊接件必须显式声明合并后果（等价闭包）；省略这一步的候选者连合格的锥形都算不上，更遑论初始地位。

**误区三**："学极限要先精通所有奇怪的小图案。"
不必。上手路径只有两种骨架：学会拉回/推合这两个最实用款，剩下的图案基本靠它们搭积木——本课刻意保持速览体质就是为了保住这种性价比视角。

:::

## 6. 练习

**练习 1**：有人按"分柜清点、汇总成交"写了一台拉回计数器，但柜内结账时把相乘误写成相加——每柜只收了"两边条目数之和"，账目立刻虚报：

```exercise
# @title: 练习：把分柜结账从相加改回相乘
# @check: 4
# @check: 4
# @check: True
# @hint: 每个编号柜里的配对数是"甲方条目数 × 乙方条目数"。聚合那行现在用的是加号；改成乘号后与逐对枚举的真相核对即可。
def fiber_sizes(tab, universe):
    row = {}
    for z in universe:
        hits = 0
        for key in tab:
            if tab[key] == z:
                hits += 1              # 同一柜号的登记条目逐一点名
        row[z] = hits
    return row

def pullback_total(f_tab, g_tab, universe):
    f_row = fiber_sizes(f_tab, universe)
    g_row = fiber_sizes(g_tab, universe)
    total = 0
    for z in universe:
        total += f_row[z] + g_row[z]   # ← 问题在这：柜内结账用了加法
    return total

UNIVERSE = [1, 2]
f_tab = {"a1": 1, "a2": 1, "a3": 2}
g_tab = {"b1": 1, "b2": 2, "b3": 2}

matched = 0                            # 兜底裁决：逐对枚举、同暗号才收
for x in f_tab:
    for y in g_tab:
        if f_tab[x] == g_tab[y]:
            matched += 1

print(pullback_total(f_tab, g_tab, UNIVERSE))
print(matched)
print(pullback_total(f_tab, g_tab, UNIVERSE) == matched)
```

修好后三行为 `4`、`4`、`True`：公式机改为 `f_row[z] * g_row[z]` 后，2×1 与 1×2 两柜各出两对，合计恰好等于枚举法的配对总数。初始版本账面报出 `6`（加法把 2+1 与 1+2 记串了行），被兜底裁决当场打脸 False。这正是分步例题那句心跳公式的代码化身：**分柜相乘、跨柜相加**。

**练习 2**（口头推理）：单点小图案（只有一个对象、零支箭头）送进极限机器会生产什么？对照上一课找答案。

<details>
<summary>点开查看逐步解答</summary>

图案退化为孤零零一个节点 $A$。锥形只剩一支山顶道 $W\to A$，唯一性条款对任何候选自动成立，于是争夺"最佳观测台"的条件被推到极致：必须让每支来自别处观测台的山道都能唯一接驳进来——胜者恰为 $A$ 自身（或与之同构者）。要注意这不是说"积是最小的极限家族成员"：积由**离散双点图案**（两个互不相连的对象）负责生产，单点图案只复制原件。这组对比恰好说明：图形的形状（几个点、几条边、怎么连）才是业务分类的唯一依据，构件内核不掺戏份。
</details>

## 7. 选读：对偶为什么总能兑现

<details>
<summary>选读 · 反转全部箭头之后</summary>

极限与余极限的关系不是并列合作而是镜像互换：在 $\mathcal C^{\mathrm{op}}$（把 $\mathcal C$ 的每一支箭头调头重铺的"倒影世界"）里，$\mathcal C$ 的极限恰好成为倒影世界的余极限。因此每证明一次关于锥形的定理，免费获得整套反向版本——这门"买一赠一"的会计技巧贯穿后续所有高级议题，比如[伴随函子](./65-yoneda-adjunctions.md)的双重性格都得靠它讲清——这口预告在下一课兑现。眼下你只需要带走一句座右铭：**凡言极限处，皆有倒影篇**。
</details>
