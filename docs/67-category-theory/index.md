范畴论不问"这个集合里有什么"，只问"东西之间怎么互相映射"。它把群、拓扑空间、类型系统和神经网络架构放进同一套箭头语言，是现代数学与编程语言共享的通用语法。

## 实战挑战 · 两支箭头的焊接次序实验室

**背景**。本章开篇一课立了一条新手最容易踩的规矩：$g\circ f$ 读作"先走 $f$，再走 $g$"——符号从右往左念，焊接次序一旦写反，箭头就会焊到错误的终点。现在轮到程序当裁判。全部戏码发生在一个只有一个对象的微型范畴里：成员集合 $\lbrace 1,2\rbrace$ 上的每支箭头都是自环，任何两支都能焊接（这正是后续幺半群话题的雏形）。

**题目**。盘两支箭头外加一位冒牌货：

- **翻转箭头 $f$**：输入 1 出 2、输入 2 出 1；
- **常值箭头 $g$**：无论输入谁都送往 1；
- 另有一支自称"恒等箭头"的 **ghost**，来历不明。

任务：(a) 真正焊出 $g\circ f$ 与 $f\circ g$，分别在输入 1、2 上打印取值——两种次序必须给出不同的结果；(b) 换上真恒等箭头，逐点核对单位律 $id\circ f=f=f\circ id$ 是否成立，打印布尔值。

```exercise
# @title: 实战挑战：箭头焊接工坊
# @check: 1 1
# @check: 2 2
# @check: True
# @hint: 口诀：符号从右往左读，g∘f 先走 f 再走 g。至于自称恒等的那一支，拿它焊完回不到原样，就别客气地换掉。
f = {1: 2, 2: 1}                # 态射 f：字典映射，输入 1 出 2、输入 2 出 1（翻转箭头）
g = {1: 1, 2: 1}                # 态射 g：无论输入谁都送往 1（常值箭头）
ghost = {1: 1, 2: 1}            # ← 坑 2 在这：这支自称"恒等箭头"，可它和 g 长得一模一样

gf = {}                         # 空字典：准备存放 g∘f 的焊接结果
for x in [1, 2]:                # for 循环：把名单上的输入挨个试焊
    mid = g[x]                  # 第一查竟然查了 g……
    gf[x] = f[mid]              # ← 坑 1 在这：锅里煮成了 f∘g，碗上贴的却是 g∘f
fg = {}
for x in [1, 2]:                # 这一锅想煮 f∘g，查表次序也要跟着标签走
    mid = f[x]
    fg[x] = g[mid]              # ← 别急着照抄上一锅：这支标签要的是另一种次序

law = ghost == f and f == ghost # == 会逐键比较字典是否相同，and 连接两个布尔
print(gf[1], gf[2])             # print 一次可接多个参数，各值之间自动补空格
print(fg[1], fg[2])
print(law)
```

<details>
<summary>点开查看逐步解答</summary>

**坑 1 · 组合次序写反。** 口诀只有一句：$g\circ f$ 从右往左念——先 $f$ 后 $g$。落到代码就是两次查表：先用 $x$ 查 $f$ 得中转站，再拿中转站查 $g$。初始代码两口锅的次序全煮反了，于是打印的"g∘f"其实是 $f\circ g$，反之亦然。修正后逐点跟踪一遍：$x=1$ 时 $f(1)=2$、$g(2)=1$，故 $g\circ f(1)=1$；$x=2$ 经中转站 $1$ 同样落到 $1$——$g\circ f$ 就是"全员发往 1"的常值箭头。反过来的 $f\circ g$ 却把两位都送到 $2$：先归拢到 $1$，再被翻转翻成 $2$。同一个对象上仅有的两支非常值合成，答案截然不同——次序即语义。

**坑 2 · 单位元误用。** 单对象范畴里人人都长自环，但配得上"恒等"头衔的自环只有一支：让每位成员原地不动的 $id=\lbrace 1:1,\ 2:2\rbrace$。ghost 与 $g$ 撞脸绝非巧合——它就是常值箭头换了件马甲。拿它冒充单位元，"焊完如同没焊"的性质当场破产，law 自然只剩 False。规范核法是逐点焊接两边：$id\circ f$ 得 $\lbrace 1:2,\ 2:1\rbrace$，$f\circ id$ 也是同一支——两边都与 $f$ 本尊逐键相等，单位律这才亮出 True。

顺带记一笔：单对象范畴的全部自环配上这套合成律，恰好凑成一个有结合律、有单位元的系统（幺半群）。ghost 冒充失败的那一刻，其实是在替单位元的存在性作证——自环可以有很多支，恒等永远只有一支。

参考答案（运行输出恰为 @check 三行）：

```python
f = {1: 2, 2: 1}                 # 态射 f：翻转箭头，1 与 2 互换
g = {1: 1, 2: 1}                 # 态射 g：常值箭头，谁都送往 1
ident = {1: 1, 2: 2}             # 恒等箭头 id：每位成员原地不动

gf = {}                          # 存放 g∘f：先 f 后 g
fg = {}                          # 存放 f∘g：先 g 后 f
for x in [1, 2]:
    mid = f[x]                   # 第一查必是 f——口诀从右往左念
    gf[x] = g[mid]
for x in [1, 2]:
    mid = g[x]
    fg[x] = f[mid]

left_side = {}                   # id∘f 的逐点焊接结果
right_side = {}                  # f∘id 的逐点焊接结果
for x in [1, 2]:
    left_side[x] = ident[f[x]]   # 先走 f，再过恒等闸门
    right_side[x] = f[ident[x]]  # 先白接，再走 f

law = (left_side == f) and (right_side == f)   # 字典 == 逐键比对，and 合成布尔
print(gf[1], gf[2])
print(fg[1], fg[2])
print(law)
```

</details>

## 实战挑战 · 态射复合的顺序

态射（函数）复合 $(g \circ f)(x) = g(f(x))$，是**先 $f$ 后 $g$**。设 $f(x)=x+1$、$g(x)=2x$，则 $(g\circ f)(3)=g(4)=8$。下面这题把复合顺序反了，修到输出 `8`：

```exercise
# @title: 实战挑战：态射复合的顺序
# @check: 8
# @hint: g∘f 表示先做 f 再做 g，即 g(f(x))，不是 f(g(x))。
def f(x):
    return x + 1

def g(x):
    return 2 * x

result = f(g(3))    # ← 问题在这：复合顺序反了
print(result)
```

<details>
<summary>点开查看逐步解答</summary>

$g \circ f$ 是先作用 $f$、再作用 $g$：

```python
result = g(f(3))    # f(3)=4，再 g(4)=8
print(result)       # 8
```

改完：$(g\circ f)(3) = g(f(3)) = g(4) = 8$。初始代码 `f(g(3)) = f(6) = 7`，算的是 $f\circ g$。范畴论里"态射的复合"与函数复合同一条规矩：写在右边的先作用。这个顺序是整个范畴论的地基——组合律、单位元、函子保复合，全都建立在"$g\circ f$ 先 $f$ 后 $g$"之上。

</details>
