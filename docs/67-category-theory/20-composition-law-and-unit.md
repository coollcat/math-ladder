# 组合律与单位元：范畴公理

## 1. 从一个场景开始

上一课把世界涂黑成点和箭头，承诺"任意首尾相接的箭头都能焊起来"。但一份焊接说明书要能投入使用，至少得回答两个问题：三段路接成一程，**先焊哪两段**有关系吗？以及，"原地不动"的那支白接箭头，**真的什么都不改变**吗？

这两个问题就是范畴的仅有两条公理。公理听起来像束缚，其实更像棋类规则——它们不告诉你棋盘上有哪些子，只保证游戏能玩下去、玩出结果时不出歧义。

## 2. 直觉解释

**结合律**说：焊法不影响成品。$f$ 接 $g$ 接 $h$ 三段连成一路，你可以先焊左边两段、也可以先焊右边两段，得到的箭头逐点行为完全一致——就像橡皮筋串联后总长度只有一种。

**单位律**说：每个对象自带一支白接线。把任何箭头跟白线焊在一起（不管白线在左还是在右），拿到的还是原箭头。白线不是"特殊成员"，只是每人必备的"接地桩"。

两条公理落到三个具体小世界里，风味各不相同：

- **Set 世界**（对象是集合、箭头是函数）：结合律就是函数复合的老性质；白线就是恒等函数；
- **偏序世界**（$x\le y$ 时恰有一支箭）：任何两支可焊的箭头结果被唯一性逼死——公理自动成立，一分力气都不用花；
- **Python 函数世界**：一支箭头就是一个字典或一个纯函数，焊法就是两次查表接龙，你马上就能亲手核。

## 3. 正式定义

上一课已给过定义骨架，这里把公理正式立碑。设 $\mathcal C$ 是一个范畴：

$$\text{结合律：}\quad (h\circ g)\circ f=h\circ(g\circ f)$$

$$\text{单位律：}\quad id_B\circ f=f=f\circ id_A\qquad(f:A\to B)$$

| 记号 | 读法 | 含义 |
| --- | --- | --- |
| $h\circ g$ | 先 $g$ 后 $h$ | 焊接从右往左读，次序即语义 |
| $(h\circ g)\circ f$ | 左先焊 | 先拼出 $h\circ g$，再与 $f$ 相接 |
| $id_B\circ f$ | 白线在左 | 经 $f$ 到达 $B$ 后原地不动 |
| $f\circ id_A$ | 白线在右 | 出发前原地不动 |

注意两件事：其一，公理是**等式的箭头版**——两个态射相等当且仅当它们作为整体不可区分，我们从不拆开看"点函数"；其二，每个对象有**自己的**白线 $id_A,id_B,id_C,\dots$，它们之间互不相干，只有落在同一对象上的自环们才会彼此焊接。

## 4. 分步例题

用最小的非平凡世界——有限集 $A=\lbrace 1,2\rbrace$ 的全部自环（单对象范畴）来体验公理。自环共有四支：恒等 $e$（人人原地）、翻转 $s$（1 与 2 对调）、常值 $k_1$（都送 1）、常值 $k_2$（都送 2）。

1. 任取两支都可焊（起点终点都是同一个点），比如先走 $s$ 再走 $k_2$：$x\xrightarrow{s}3-x\xrightarrow{k_2}2$，全程送 2，即 $k_2\circ s=k_2$；
2. 换个次序，先走 $k_2$ 再走 $s$：$x\xrightarrow{k_2}2\xrightarrow{s}1$，送 1，即 $s\circ k_2=k_1$；
3. 两行不同——这个世界的焊接**不交换**；但别慌，范畴从没承诺交换律；
4. 核结合律抽检三元组 $(k_2,s,s)$：$(k_2\circ s)\circ s=k_2\circ s=k_2$，而 $k_2\circ(s\circ s)=k_2\circ e=k_2$，两侧一致；
5. 核单位律：$e$ 在左右两侧都不改变对方 ✓。四支自环配上这套焊法，恰好凑成第 33 章运算律课上见过的那种"有结合二元运算 + 单位元"的系统——幺半群。它不是巧合，下一段展开。

### 实验 2：三条公理逐条代码核对

```python title="结合律与单位律暴力核对"
def comp(a, b):          # comp(a,b) 表示 a∘b：先走 b，再走 a
    out = {}             # 备好空字典盛放焊接结果
    for x in b:          # 逐个输入试焊
        mid = b[x]       # 第一程：查 b 得中转站
        out[x] = a[mid]  # 第二程：从中转站查 a
    return out

s = {1: 2, 2: 1}         # 自环 s：翻转
k1 = {1: 1, 2: 1}        # 自环 k1：全员发往 1
k2 = {1: 2, 2: 2}        # 自环 k2：全员发往 2

left = comp(comp(k2, s), s)      # (k2∘s)∘s：左两段先焊
right = comp(k2, comp(s, s))     # k2∘(s∘s)：右两段先焊
print(left == right)             # == 对字典逐键比较，相等得 True

idm = {1: 1, 2: 2}               # 恒等自环 e
unit_left = comp(idm, s) == s    # 白线在左不改样
unit_right = comp(s, idm) == s   # 白线在右也不改样
print(unit_left and unit_right)
```

第一行是结合律的一次实弹抽查（True）；第二行是单位律的双向核对（True）。换任何三元组重跑，结论不会变——但"抽查通过"和"对全部三元组证明"隔着一道墙，选读段聊这道墙。

## 常见误区

:::warning[常见误区]

**误区一**："范畴公理会限制箭头的'质量'。"
公理只管焊法和白线，不要求单射、满射、可逆。常值箭头 $k_1$ 把两位成员压扁成一位，照样是合法态射——质量问题留给同构与同态去分级。

**误区二**："既然单对象范畴等于幺半群，范畴就是换了包装的幺半群。"
反了：是把**幺半群**降维进范畴语言后只剩一行。多对象范畴才是本体——对象各不相同这一点，恰是幺半群语言装不下的信息（下一课函子的搬运能力正来自这里）。第 33 章研究的是单一运算的世界，范畴论让多个世界同框接驳。

**误区三**："两条公理取其一即可。"
砍掉结合律，焊接路径各有各的结果，"这一路"沦为"这几路"；砍掉单位律，对象可能"裸奔"——没有白线的对象接不上任何约定俗成的接口。两者合璧才是一套自洽语法。

:::

## 6. 练习

**练习 1**：下面的程序想核对结合律与"哪种查表方向才算 $a\circ b$"，但 `comp` 内部把两程查反了，导致输出与已知事实不符：

```exercise
# @title: 练习：把查表方向拧回来，重新亮灯
# @check: 1 1
# @check: True
# @check: True True
# @hint: comp(a,b) 应该先走 b：先用输入查 b 得中转站，再拿中转站查 a。现在内部却先用输入查 a。
def comp(a, b):
    out = {}
    for x in b:
        mid = a[x]       # ← 问题在这：竟然先查了 a
        out[x] = b[mid]
    return out

k1 = {1: 1, 2: 1}        # 常值 1 的自环
s = {1: 2, 2: 1}         # 翻转自环
idm = {1: 1, 2: 2}       # 恒等自环

probe = comp(k1, s)      # 理应等于 k1∘s = k1（k1 吞掉一切）
print(probe[1], probe[2])
print(probe == k1)

assoc_ok = comp(k1, s)[1] == k1[comp(s, idm)[1]]   # 公理的抽样检查
unit_ok = (comp(idm, s) == s) and (comp(s, idm) == s)
print(assoc_ok, unit_ok)
```

修好后输出 `1 1`、`True`、`True True`：$k_1\circ s$ 正确地塌回常值 1，抽样检查亮绿灯，单位律双侧同时成立。初始版本第二程改查 $b$，煮出来的其实是 $b\circ a$ 方向的产物，所以 `probe` 变成了翻转的痕迹而非常值。**练一点**：把 `idm` 故意换成 ghost 常值表，看哪行先报警。

**练习 2**（概念辨析）：群可以看作"只有一个对象、且每支自环都有逆"的范畴。那 **2** 个对象的自由偏序链（$a\le b$）呢？请指出它的全部态射数量，并说明结合律为何免费成立。

<details>
<summary>点开查看逐步解答</summary>

对象就两个：$a,b$。箭头只有三支：$id_a:a\to a$、$id_b:b\to b$、唯一一支 $a\to b$（由 $a\le b$ 配给）。总数 3 支。可焊的组合只有这些平凡情形，每种分组方式的落点都被"该跨度上仅此一支箭"钉死，于是 $(h\circ g)\circ f$ 与 $h\circ(g\circ f)$ 无论怎么算都得同一支——**唯一性替你证明公理**。这也是哈斯图世界里不必写乘法表的原因：订单太少，选择结构自动消歧。
</details>

## 7. 选读：从两条公理到整座高塔

<details>
<summary>选读 · 为什么偏偏是这两条</summary>

历史视角：1945 年 Eilenberg–Mac Lane 论文里，范畴的定义被刻意压到最瘦——瘦到除了公理什么都没有。留下来的两条各自承担一项不可替代的任务：结合律保证"一次设计，处处复用"——你封装好的任意拼接块可以在更外层继续无顾虑地拼接，编程语言里的组合子库正是吃这口红利；单位律则提供"中性基准点"，让"不变"成为可被指认的对象。砍任何一条，交换图这门后续图形代数立刻失去合法性——交换图的顶梁柱恰恰是"沿任一条边序走到终点答案唯一"。更深的闲话：这两条也是拓扑学"道路积"的同款公理（先走 $f$ 再走 $g$ 的路径类的结合与常数回路），范畴论可视为把"走路的艺术"抽象成了通用语法。

</details>
