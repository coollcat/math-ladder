# Yoneda 与伴随函子：范畴论的双核

## 1. 从一个场景开始

[泛性质](./50-universal-properties.md)的选读里留了一句预告："每个对象的全部本性都编码在'别人怎么看它'里——内部审计永远可以外包给外景调查"。这句话在本章半空悬了三课，本课来兑现：**Yoneda 引理**要说的是，一座城市的全部本性，就写在全城居民对它的目光里——菜单、灶台、老板娘统统可以遗忘。第二条主线来自[极限与余极限](./60-limits-colimits.md)选读的另一句预告："伴随函子的双重性格"。对偶手艺的最著名成品今天交货：**自由-遗忘对偶**。两句话拼成本课标题——**怎么看**（Yoneda）与**怎么来回翻译**（伴随），范畴论的双核。

## 2. 直觉解释

**核心直觉一：对象的身份证不在户口本上，在别人的探亲记录里。**

给对象 $C$ 装订一本"外景档案"：挨个询问每个探针对象 $X$——"你有多少支箭头指向 $C$、各沿哪些路线？"把全部答案装订成册，就是 $\mathrm{Hom}(-,C)$。Yoneda 引理断言：这本档案**完全**决定 $C$（同构意义下）——档案页页相同的两个对象必然同构，内部细节无须开箱验货。档案还能反向生成：把 $C$ 自己当模板，收集"从 $C$ 出发的全部出路"得到 $\mathrm{Hom}(C,-)$，这类以 $C$ 为模板的函子叫**可表函子**。

**核心直觉二：自由与遗忘，是一对互相成全的翻译官。**

**自由 monoid** $F(X)$：拿集合 $X$ 里的字母造出全部"词"（a、ab、baa……），除拼接外不附加任何乘法表——它是"最自由的乘法世界"。**遗忘函子** $U$ 反向抹掉乘法，把任何 monoid 打回"只是一堆元素"。这对搭档的神奇之处是一张双向通行证：

| 往词世界问 | 等价于 | 先在元素世界问 |
| --- | --- | --- |
| 词世界 $\mathrm{Free}(X)\to M$ 的保乘法映射 | $\Longleftrightarrow$ | 字母 $X\to U(M)$ 的普通函数 |

一支同态由它给字母的指派**唯一决定**（词像 = 字母像连乘），反过来每个指派都能合法扩张成一支同态。左闭右也闭：这正是**伴随函子** $F\dashv U$ 的 Hom 集合同构。

## 3. 正式定义

**Yoneda 引理**：对范畴 $\mathcal C$ 中对象 $C$ 与任意函子 $F:\mathcal C\to\mathbf{Set}$，

$$\text{Nat}\bigl(\mathrm{Hom}(C,-),\ F\bigr)\ \cong\ F(C).$$

| 记号 | 含义 |
| --- | --- |
| $\mathrm{Hom}(C,-)$ | 可表函子：以 $C$ 为模板的"出路档案生成器" |
| $\text{Nat}$ | 自然变换的集合（第 40 课那摞对照小册子的全体） |
| $\cong$ | 自然同构：一一对应且与箭头搬运兼容 |
| 直觉读法 | 从"出路档案"到 $F$ 的每种自然译法 = $F$ 在 $C$ 处的那一个成员 |

由它立刻得到 **Yoneda 嵌入**：$C\mapsto\mathrm{Hom}(-,C)$ 把对象送进函子世界且完全忠实——同构当且仅当档案相同。第 50 课"承认即同一"的孤例，至此升级成全景判据。

**伴随函子**：一对函子 $F:\mathcal C\to\mathcal D$ 与 $U:\mathcal D\to\mathcal C$ 若满足自然同构

$$\mathrm{Hom}_{\mathcal D}(F X,\ A)\ \cong\ \mathrm{Hom}_{\mathcal C}(X,\ U A)\qquad(\text{对 } X,\ A \text{ 双侧自然}),$$

就记 $F\dashv U$（$F$ 左伴随、$U$ 右伴随）。自由-遗忘是最小样板：左侧问"词世界的保乘法映射"，右侧问"字母的普通指派"，两侧一一对应。

## 4. 分步例题

有限集合世界样样可数。取三元集与二元集当探针：

1. **数 $\mathrm{Hom}(A_3,A_2)$**：每个输入位独立挑去处，逐位 $2$ 种、共 $3$ 位——$2^{3}=8$ 支函数；
2. **数 $\mathrm{Hom}(A_2,A_3)$**：反向即 $3^{2}=9$——底数是接收方、指数是探针，方向千万别站反；
3. **装订外景档案**：探针取 $1,2,3$ 元集逐个清点——$2$ 元对象报出 $[2,4,8]$，$3$ 元对象报出 $[3,9,27]$，单点对象报出 $[1,1,1]$；
4. **验明正身**：$2$ 元与 $3$ 元对象档案不同，绝不同构；把 $3$ 元对象成员换套名字（$a,b,c$ 换成 $x,y,z$），档案页页不变——同构。档案即身份证；
5. **伴随对拍**：字母表 $X=\lbrace a,b\rbrace$ 打进 $\mathbb{Z}/3$（余数加法世界）：普通函数 $X\to U(\mathbb{Z}/3)$ 逐位 $3$ 种、共 $3^{2}=9$ 支；同态 $\mathrm{Free}(X)\to\mathbb{Z}/3$ 同样恰 $9$ 支——每支由字母像唯一决定，两侧账本对齐。

第 3 步那行 $[1,1,1]$ 你应该眼熟：第 50 课资格年检里的终对象，在档案视角下原形毕露——"每格恰好一支"就是它的外景档案。

## 5. 动手实验

### 实验 1：外景档案局

```python title="Hom 集暴力枚举 + Yoneda 档案装订"
def all_maps(dom, cod):
    # 枚举从 dom 到 cod 的全部函数：逐个输入位安排去处
    maps = [[]]
    for _ in dom:                 # 每个输入位都要挑一个 cod 里的落脚点
        maps = [m + [v] for m in maps for v in cod]   # 双层列表推导：老清单每支接上每种去处
    return maps

A3 = ["a", "b", "c"]              # 三元集合
A2 = [0, 1]                       # 二元集合
print(len(all_maps(A3, A2)), len(all_maps(A2, A3)))   # 8 与 9：方向不同账不同

def profile(size_c):
    # 装订外景档案：探针依次取 1、2、3 元集，数各探针到目标的箭头
    target = list(range(size_c))  # 大小为 size_c 的目标对象
    return [len(all_maps([0], target)),
            len(all_maps([0, 1], target)),
            len(all_maps([0, 1, 2], target))]

for size in [1, 2, 3]:
    print(size, "号对象档案:", profile(size))
```

三行档案 $[1,1,1]$、$[2,4,8]$、$[3,9,27]$：单点对象的"每格恰好一支"正是终对象资格证的档案读法；档案随对象大小单调生长——这是 Yoneda 嵌入在有限世界的素颜照。

### 实验 2：自由-遗忘的两侧账本

```python title="伴随对拍：9 支函数 = 9 支同态"
M3 = [0, 1, 2]                    # 目标 monoid：Z/3（余数加法世界）

def madd(x, y):
    return (x + y) % 3            # % 取余：Z/3 的加法（超过 2 就绕回）

left = all_maps(["a", "b"], M3)   # 伴随左侧：字母到 U(Z/3) 的普通函数
print(len(left))                  # 9 支指派（右侧同态数应与它相等）

f = left[5]                       # 随手抽一支指派：a 与 b 各自的余数
print(f, madd(f[0], f[1]), madd(madd(f[0], f[0]), f[1]))
# 词像 = 字母像连乘：词 ab 映为两像相加，词 aab 为三像连加——指派一锁，整座词海的像全部就位
```

实测 $f=[1,2]$：词 $ab$ 的像 $0$、词 $aab$ 的像 $1$，与"连乘公理"逐位吻合。$9$ 支指派配 $9$ 支同态，两侧账本分毫不差——$F\dashv U$ 的 Hom 同构在有限世界完成对拍，"唯一扩张"从此不是口号。

```quiz
两个对象的 Yoneda 外景档案页页相同，能下什么结论？
- 它们必然同构 [*]
- 它们必然是成员名字相同的同一个集合
- 档案相同也可能毫无关系
? 档案相同即可断言同构（Yoneda 嵌入的完全忠实性）；但同构不要求成员同名——换套名字的同构对象共享同一份档案，这正是"承认即同一"的威力。
```

## 常见误区

::::warning[常见误区]

**误区一**："Yoneda 说对象由内部结构决定。"
方向反了：它说的是内部可以**整个遗忘**。档案（外部往来）相同则同构，内部细节自始至终无人查验。"涂黑内部"的立场在第 10 课立下，Yoneda 是它最深的一口井。

**误区二**："伴随就是两个函子互为逆运算。"
同构不在对象层，在 Hom 集层：$F\circ U$ 通常根本不是恒等——自由再遗忘，乘法表回不来，只剩字母表。先把它降级成"Hom 集一一对应"，才能升级成正确的伴随直觉。

**误区三**："数 Hom 集是数对象里的元素。"
Hom 的成员是**箭头**：$\mathrm{Hom}(A_2,A_3)$ 数的是 $9$ 支函数，不是 $2$ 个或 $3$ 个元素。底数接收方、指数探针——方向站反，档案整个报错（下面的练习专治这个病）。

::::

## 6. 练习

外景档案局的计数器坏了：底数和指数站反了位置。修好全部检查：

```exercise
# @title: 外景档案计数器的方向校正
# @check: 8
# @check: 9
# @check: [2, 4, 8]
# @hint: |Hom(A,B)| 的底数是接收方 B 的大小、指数是探针 A 的大小。档案行按探针 1、2、3 元从小到大排列。
def hom_count(size_a, size_b):
    return size_a ** size_b       # ← 底数与指数站反了？

def profile(size_c):
    return [hom_count(n, size_c) for n in [1, 2, 3]]

print(hom_count(3, 2))            # 三元探针打向二元对象
print(hom_count(2, 3))            # 二元探针打向三元对象
print(profile(2))                 # 二元对象的外景档案
```

修好后三行输出 `8`、`9`、`[2, 4, 8]`：底数换成接收方后，三探针打向二元对象是 $2$ 的 $3$ 次方、反向是 $3$ 的 $2$ 次方，档案恢复单调生长节奏。初始版本报 `9`、`8`、`[1, 4, 9]`——计数器把"谁看谁"整个演反，连终对象的档案都会被写歪。

**练习 2**（口头推理）：在自由-遗忘伴随里，为什么词 ab 的像一定等于 a 的像与 b 的像相乘，而不需要任何额外规定？

<details>
<summary>点开查看逐步解答</summary>

因为同态必须**保乘法**，而 $\mathrm{Free}(X)$ 里 $ab$ 的乘法恰好就是拼写层面的并置：$f(ab)=f(a\cdot b)=f(a)\cdot f(b)$——保乘法公理自动把整座无限词海的像全部锁死，额外规定无处安放。反方向（每个指派都能扩张）则由自由对象的泛性质担保：词与词之间除结合律外没有任何约束，把字母像逐位连乘即可定义一支合法同态，永不矛盾。"两侧皆闭"正是伴随与普通同构的区别——它是一张可以反复开工的翻译合同，不是一次性的巧合。

</details>

## 7. 选读：伴随为什么无处不在

<details>
<summary>选读 · 三对著名的伴随与一个预告</summary>

自由-遗忘只是双核之一的亮相，伴随的真正身份是**范畴论的分节号**。三对著名的例子：

- **柯里化**：$X\times A\to B$ 与 $X\to B^{A}$ 的兑换（[积、余积与指数对象](./55-products-coproducts-exponentials.md)的货架定理）就是伴随 $(\times A)\dashv(-)^{A}$。有限世界照样对拍：$2\times 2$ 元集到 $2$ 元集的函数有 $2^{4}=16$ 支，$2$ 元集打向"四元函数货架"的函数同样 $16$ 支——把本课实验 1 的 `all_maps` 换组参数即可复核；
- **极限与余极限**：常数函子与锥形收编机器之间也藏着伴随，[极限与余极限](./60-limits-colimits.md)那套"买一赠一"的对偶会计正是因此总能兑现；
- **自由-遗忘**：本课主角，从集合到 monoid、线性空间、群处处复制粘贴。

预告：下一课的主角 Monad 并非凭空发明的封装模式——**每一对伴随都免费赠送一台 Monad**（装箱与拆装的标准化动作正是伴随单位的化身）。双核在此合流：Yoneda 负责唯一性判定，伴随负责结构搬运，Monad 负责把搬运流程固化成管道。

</details>
