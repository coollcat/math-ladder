# Z 变换与零极点图入门

## 1. 从一个场景开始

老式收音机慢慢逼近某个电台的频率，先是若有若无的哼声，再靠近一点，声音像坐上滑梯一样陡然撑大——旋钮停驻的那个位置被称为谐振点。差分方程课看到过它的原型：反馈折扣越接近一，历史就越难散场。

要在开机前就知道这台机器会不会啸叫、会在什么频率上火，总不能每台都拿手拍一下听天由命。工程师的办法是给系统做一次**复平面体检**：把全部零件摆到一张图上，健康与否一目了然。这张图叫零极点图，绘制它的语言叫 Z 变换。

## 2. 直觉解释

第 28 章母函数做过一次思维跃迁：把数列 $1, 1, 1, \ldots$ 写成多项式 $1 + z + z^2 + \cdots = 1/(1-z)$，无穷序列瞬间折叠成一行分式。Z 变换对信号序列干的是同一件事：

- 序列 $h[0], h[1], h[2], \ldots$ 记作幂级数 $H(z) = h[0] + h[1]\,z^{-1} + h[2]\,z^{-2} + \cdots$；
- 一行递推差分方程，两边逐项变换后只剩有限几个 $b_k$ 与 $a_j$ 的加减乘除——无限记忆被收纳成分式；
- 分式**分子为零的位置叫零点**（输出在此消失），**分母为零的位置叫极点**（响应在此撑爆），把它们画在复平面上就是零极点图。

体检时最重要的地标是**单位圆**：让变量绕着它滚动，$z = e^{i\omega}$ 恰好扫遍一切数字频率——这层身份你在傅里叶章已经见过（欧拉公式连接指数与正弦）。于是单条规则管全局：**看每个极点站在圆内还是圆外**。

## 3. 正式定义

序列 $x[n]$ 的 Z 变换为

$$X(z) = \sum_{n} x[n]\, z^{-n}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $z$ | 复变量 | 复平面上的任意一点 |
| $\|z\| = 1$ | 单位圆 | $z = e^{i\omega}$ 的轨迹，圆上的取值即 DTFT 频谱 |
| 零点 | 分子为零处 | 该频率的输入被完全吞掉（第 50 号课的「灭点」就是踩在圆上的零点） |
| 极点 | 分母为零处 | 响应发散的方向；决定系统的命门 |

差分方程 $y[n] = x[n] + c\,y[n-1]$ 两边同乘规律整理后得 $Y(z)/X(z) = 1/(1 - c z^{-1})$：唯一极点在 $z = c$，呼应上一课「折扣系数当户口」的说法。使幂级数收敛的条件 $|cz^{-1}| < 1$ 翻译成户口政策便是：**极点必须住在单位圆内**。本课刻意不碰围线积分与收敛域的全部细节——搜证手段只需代入和因式分解。

## 4. 分步例题

**例**：判断滤波器 $y[n] = x[n] - 0.9\, y[n-1]$ 是否稳定，并找它的直流表现。

1. 取 Z 变换：$H(z) = 1/(1 + 0.9 z^{-1})$（注意减号翻进分母变成加号）；
2. 极点方程 $1 + 0.9 z^{-1} = 0$ 解得 $z = -0.9$：模长 $0.9 < 1$，在圆内——稳定；
3. 极点是负实数意味着逐拍反相拖尾：冲激响应 $(-0.9)^n$ 在正负之间衰减摆动，高频味道浓；
4. 直流（$z = 1$）处的增益为 $H(1) = 1/1.9 \approx 0.53$，慢变化被温和压低；若极点换成 $+0.9$，则 $H(1) = 10$，低频被放大十倍——同一个模长，户口角度不同，性格完全两样。

顺带体会零点：FIR 式 $H(z) = 1 - z^{-1}$ 有一个零点骑在 $z=1$ 上——直流彻底归零，这是一阶高通的骨架。

## 5. 动手实验

### 实验 1（viz）：极点迫近圆缘，峰越起越高

一阶 IIR $y[n] = x[n] + p\, y[n-1]$ 对数字频率 $\omega$ 的幅频响应为 $H(\omega) = 1/\sqrt{1 - 2p\cos\omega + p^{2}}$（变量 $x$ 已按 $\omega = 2\pi f$ 折算）。拖动极点半径 $p$：

```viz
{
  "type": "plot",
  "title": "极点越靠近单位圆，共振峰越尖",
  "expr": "1/sqrt(1 + p*p - 2*p*cos(2*pi*x))",
  "xmin": 0,
  "xmax": 0.5,
  "sliders": [
    { "name": "p", "min": -0.95, "max": 0.95, "step": 0.05, "value": 0.6 }
  ]
}
```

$p = 0.6$ 时曲线只是微微隆起的土坡；拖到 $0.95$，山体拔地而起又瘦成针峰——收音机的谐振感扑面而来；拖到负半区 $-0.95$，峰搬到最高频端去站岗。这就是第 50 号课说过的:「IIR 用极少系数做出很陡的选择」，其几何机关全写在极点到圆缘的距离里。

### 实验 2（python）：给两个户口画一张零极点图

```python title="零极点图 + 冲激响应对照"
import math                       # 用 pi、sin、cos
import matplotlib.pyplot as plt   # 画图库（此前课程已引入）

poles = [0.85 + 0j, 1.15 + 0j]    # 复数列表：一稳一炸的两个极点
zeros = [-1 + 0j]                 # 一个骑在圆上的零点：高频灭点

th = []                           # 单位圆的采样角度
for i in range(121):
    th.append(2 * math.pi * i / 120)
cx = []                           # 圆周的横坐标
cy = []                           # 圆周的纵坐标
for t in th:
    cx.append(math.cos(t))
    cy.append(math.sin(t))

plt.figure(figsize=(4.6, 4.6))    # 正方形画布配圆形舞台
plt.plot(cx, cy, color="gray")    # gray：单边灰线的画笔颜色
px = []                           # 极点的横坐标
py = []
for q in poles:
    px.append(q.real)             # .real：取复数的实部
    py.append(q.imag)             # .imag：取复数的虚部
plt.scatter(px, py, marker="x", color="red", s=90, label="poles")  # s：点的大小
zx = []; zy = []
for q in zeros:
    zx.append(q.real)
    zy.append(q.imag)
plt.scatter(zx, zy, marker="o", color="blue", s=90, label="zeros")
plt.axhline(0, color="lightgray") # axhline：画一条水平参考线
plt.axvline(0, color="lightgray")
plt.axis("equal")                 # 横纵等比例，圆才是圆
plt.legend()

N = 24                            # 冲激响应跑多少拍
hs1 = []
prev = 0.0
for n in range(N):
    x = 1 if n == 0 else 0        # 冲激只在第 0 拍敲门
    y = x + 0.85 * prev           # 圆内户口的回声
    hs1.append(y)
    prev = y
hs2 = []
prev = 0.0
for n in range(N):
    x = 1 if n == 0 else 0
    y = x + 1.15 * prev           # 圆外户口的回声
    hs2.append(y)
    prev = y

print("圆内极点末拍:", round(hs1[-1], 5))    # 下标 -1：取列表最后一个元素
print("圆外极点末拍:", round(hs2[-1], 2))

plt.figure(figsize=(7, 3))
plt.plot(range(N), hs1, marker="o", label="p=0.85 (in)")
plt.plot(range(N), hs2, marker="s", label="p=1.15 (out)")
plt.legend()
```

打印显示：圆内住户 23 拍后衰减到约 $0.85^{23} \approx 0.02$，圆外住户已膨胀到约 $1.15^{23} \approx 24.9$ 倍——同一张图上生死立判。蓝色圆圈落在 $z=-1$：比圆恰好踩灭高频成分，与实验 1 里 $p<0$ 时的高端余韵相克成趣。

### 快问快答

```quiz
把一个稳定滤波器的极点沿径向推向单位圆边缘，会发生什么？
- 幅频响应出现更陡更高的共振峰，冲激响应拖尾更长 [*]
- 滤波器相位立即反转
- 系统从 FIR 变成 IIR
? 极点离圆缘的距离控制峰值高度与记忆长度：越近尾巴散得越慢、峰越尖。跨过去才会真正爆炸。
```

:::warning[常见误区]

**误区一**：「零点也会决定稳定性。」
稳定性只由极点的户口发言，零点只负责挖灭点和整形。把所有零点挪出圆外，只要极点不出事，系统依旧稳如泰山。

**误区二**：「圆外极点只是响一点。」
不是声量问题，是增速问题：输出按指数增长直到溢出或削波，任何精度都救不了。手术方案只有移极点（改反馈系数）这一条路。

**误区三**：「算 Z 变换就得会围线积分。」
本课用到的全部工具是「写成幂级数 + 因式分解」。围线积分属于研究生课的优雅装备，工程判稳用不到它。

:::

## 6. 练习

**练习 1**：给四个极点办户口登记。求各自的模长（保留两位小数）并确认谁住进了圆内。代码能跑但半径算错了：

```exercise
# @title: 练习：谁的户口在圆内
# @check: 0.71
# @check: 0.9
# @check: 1.0
# @check: 1.2
# @hint: 复数模长是 sqrt(re*re + im*im)：先平方两项再开方。初版漏了开方
import math

pts = [(0.5, 0.5), (-0.9, 0.0), (0.8, 0.6), (0.96, -0.72)]   # 四个候选极点
for re, im in pts:                        # 元组解包：依次取出每一对的实部虚部
    mag = re * re + im * im               # ← 问题在这：少了一步开方
    print(round(mag, 2))
```

补上 `mag = math.sqrt(re * re + im * im)` 后输出 0.71、0.9、1.0、1.2。第三个正好踩线：模长等于一的临界户口不保证衰减，工程上一律按不稳定处理。第四个落在圆外，系数哪怕看起来很小也会拖垮整个系统。

**练习 2**：谐振器的极点是一对共轭复数 $0.8 \pm 0.3i$，它会在哪个频率附近唱歌？

<details>
<summary>点开查看逐步解答</summary>

半径 $\rho = \sqrt{0.64 + 0.09} = \sqrt{0.73} \approx 0.85 < 1$：稳定。极角 $\theta = \arctan(0.3/0.8) \approx 0.359$ 弧度，对应数字频率 $\omega = 0.359$（每周约 $2\pi/0.359 \approx 17.5$ 拍）。共轭双极点的几何规矩：**共振峰立在极角的正上方附近**，半径决定峰的高矮胖瘦。所以这间房子的烟囱位置不由反馈系数的大小单独说了算——虚部偏转了角度，实部按住了音量。
</details>

## 7. 选读：把三个家族放进同一张图

<details>
<summary>选读 · 滑动平均、IIR 谐振器与窗谱的原型机</summary>

滑动平均（M 点）的全部零点均匀散布在单位圆上（$z = e^{2\pi i k/M}$），因此它天生是什么都留不住、只会按键消音的「多孔板」——第 50 号课的灭点在这张图上终于现出真身。一阶 IIR 只有一个可移动极点，半径控峰高、角度控峰位；二阶谐振器用一对共轭极点把唱针精确安放到任意频率。把滤波器设计说穿，就是在复平面上一颗颗**摆放小钉子**：零点负责拆台（挖掉讨厌频段），极点负责捧场（顶起需要的频段），而单位圆是最重要的裁判席——DTFT 要的就是沿着圆环读取这些钉子合力的影子。下一课回到 FIR 家族正式装修。
</details>
