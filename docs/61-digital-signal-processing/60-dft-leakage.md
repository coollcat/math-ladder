# DFT 与频谱泄漏

## 1. 从一个场景开始

吉他调音器 App 把琴声对准 110 Hz 的标准音 A2——可屏幕上的频谱里，110 Hz 附近不是一根干净的针，而是一座**带一圈缓坡小山**的主峰，旁边还趴着几座更矮的假山。明明是单一频率的音，DFT 算出来的能量却撒了一地。

这不是数值误差，而是有限观察的宿命：**你只看了 0.5 秒，凭什么要求机器分辨出 109 和 111？** 本课解释这座小山的来历（频谱泄漏），以及为什么它是后面窗函数一课的伏笔。

## 2. 直觉解释

65 号课说过：DFT 的每个频率桶对应「在窗口内恰好振动整数个周期」的探针。这里藏着一条隐含假设——**DFT 默认你截取的这段信号会在窗外无限周期重复**。

- 若 5 Hz 音配 1 秒窗口（$f_s = N = 64$）：窗口内恰好 5 个整周期，首尾无缝对接，能量全部落进 5 号桶；
- 若是 5.5 Hz：窗口内 5.5 个周期，接缝处半个周期硬接下一个开头——**波形跳变**。这个跳变在傅里叶眼里就是一堆高频与邻频成分，能量从 5 号桶泼洒到邻居们头上。

泼洒出的形状像一座山：中央主峰（主瓣）+ 两侧递减的涟漪（旁瓣)。这就是**频谱泄漏**：信号的能量本来只在某根谱线上，被矩形窗口一切，就漏进了所有桶。

## 3. 正式定义

对 $N$ 点样本、采样率 $f_s$，第 $k$ 桶幅度沿用 65 号课的定义：

$$|X[k]| = \frac{1}{N}\left| \sum_{n=0}^{N-1} x[n]\, e^{-2\pi i kn/N} \right|$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\Delta f = f_s / N$ | 桶宽 | 相邻两桶相差的赫兹数 |
| 整数桶 | on-bin | 信号频率恰为 $\Delta f$ 整数倍，无泄漏 |
| 非整数桶 | off-bin | 信号骑在两桶之间，能量按泄漏模式分摊 |
| 主瓣 | main lobe | 泄漏图案中央的主峰，宽度由窗长决定 |
| 旁瓣 | side lobe | 主瓣两侧的次级波纹，高度由窗形状决定 |

关键事实：加窗（哪怕什么都没做，截断本身就是乘了一个矩形窗）在频域等于信号频谱与窗谱的**卷积**。矩形窗的窗谱是形如 $\sin(Nx)/\sin(x)$ 的尖峰函数——所以单频音的谱图必然被「盖章」成它的形状。桶上与否只决定盖得正不正：正盖时各瓣恰好叠回同一根线，歪盖时就露出山的真容。

## 4. 分步例题

**例**：$N = 64$、$f_s = 64$（桶宽恰好 1 Hz），输入为振幅 1 的纯正弦。比较 $f = 5.0$ 与 $f = 5.5$。

1. $f = 5.0$：整周期，全部能量进 5 号桶，$|X[5]| = 0.5$（另一半给了镜像桶），其余桶几乎为零；
2. $f = 5.5$：半周期错位。实测最强桶仍是 5 号（5 号与 6 号平分秋色），但幅度跌到约 $0.33$——峰变矮了；
3. 数一数泄漏范围：幅度超过 $0.05$ 的桶共有 **8 个**（1 号到 8 号一带），能量摊成一座小山；
4. 后果演示：若旁边还藏着一个幅度仅 0.1 的弱音，它的峰会被这座山整个淹没——泄漏不只是难看，还会**吃掉邻近的弱信号**。

## 5. 动手实验

### 实验 1（viz）：两个整桶频率的标准照

```viz

  "f1": 5,

  "a2": 0.25

```

这个控件内部就是 65 号课的离散投影。把两个频率都拖成整数时，谱峰干净利落各立一根，高度只随「份量」滑杆变化——两个成分在频域一目了然，谁也藏不住谁。

### 实验 2（python 滑块）：亲手量一座泄漏山

```python title="拖动信号频率 f（可骑在两桶之间），观察峰矮胖化"
# sliders: f=5.5 [4:8:0.5]
import math                      # 用 pi、sin、cos 和 hypot

N = 64                           # 窗口长度
fs = 64                          # 采样率：桶宽 = 1 Hz
x = []                           # 纯正弦的样本
for n in range(N):
    x.append(math.sin(2 * math.pi * f * n / fs))

def mag(k):                      # 第 k 桶幅度（65 号课原班机器）
    re = 0.0
    im = 0.0
    for n in range(N):
        ang = 2 * math.pi * k * n / N
        re = re + x[n] * math.cos(ang)
        im = im - x[n] * math.sin(ang)
    return math.hypot(re, im) / N

best = 1                         # 找最强桶
for k in range(1, N // 2):
    if mag(k) > mag(best):
        best = k

spread = 0                       # 数一数超过 0.05 的桶有几座
for k in range(1, N // 2):
    if mag(k) > 0.05:
        spread = spread + 1

print(f"最强桶: {best} 号, 幅度 {round(mag(best), 3)}")
print(f"幅度超 0.05 的桶数: {spread}")
```

拖动滑杆对比：f=5.0 时打印 `5 / 幅度约 0.5`、山只有 1 座桶；f=5.5 时峰矮到约 0.33、超过阈值的桶变成 8 个——泄漏山的宽度一目了然。再试 f=5.25（离 5 号桶只差四分之一桶）：峰回升到约 0.44、山体收窄到 4 个桶——峰的高矮随偏移量连续变化。**峰的高度与宽度在做交易**，总账（能量）基本守恒。

### 快问快答

```quiz
把 DFT 点数 N 加倍（窗口时长翻倍），对泄漏的影响是？
- 泄漏彻底消失
- 主瓣变窄：山更瘦更尖，但仍存在 [*]
- 峰变得更高更宽
? 窗长加倍让窗谱被横向压缩——主瓣宽度约减半，分辨相邻频率的能力增强。但只要信号频率不在整数桶上，泄漏机制本身不会消失，只能被压制。
```

:::warning[常见误区]

**误区一**：「谱峰旁边的涟漪是计算 bug 或精度不够。」
用再高的浮点精度算，泄漏纹丝不动。它是「有限长观察 + 周期延拓假设」的结构性产物——要改的是窗，不是算法。

**误区二**：「FFT 比 DFT 更准，能消除泄漏。」
FFT 只是算得快的 DFT，输出与逐桶投影完全一致（至多差浮点舍入）。快慢与准不准是两个正交的问题。

**误区三**：「补零能把频率看得更细。」
补零把 N 从 64 加到 1024，谱线确实变密了，但那是同一座山的**插值放大**——主瓣物理宽度由真实数据时长决定，一根秒针不会因为刻度盘画密了就变成秒表。想真正分辨 109 与 111 Hz，需要更长的实数据。

:::

## 6. 练习

**练习 1**：测量 off-bin 音的泄漏范围。代码能跑但第二行不对：

```exercise
# @title: 练习：量出泄漏山的地盘
# @check: 5
# @check: 8
# @hint: 0.4 的阈值连主峰（约 0.33）都够不着。泄漏山的大部分在 0.05 以上——把阈值改成 0.05 再数
import math

N = 64
fs = 64
x = []
for n in range(N):
    x.append(math.sin(2 * math.pi * 5.5 * n / fs))   # 骑在 5 号与 6 号桶之间的音

def mag(k):
    re = 0.0
    im = 0.0
    for n in range(N):
        ang = 2 * math.pi * k * n / N
        re = re + x[n] * math.cos(ang)
        im = im - x[n] * math.sin(ang)
    return math.hypot(re, im) / N

best = 1
for k in range(1, N // 2):
    if mag(k) > mag(best):
        best = k

count = 0                        # 泄漏地盘：幅度超阈值的桶数
for k in range(1, N // 2):
    if mag(k) > 0.4:             # ← 问题在这：阈值定得太高
        count = count + 1

print(best)
print(count)
```

把阈值改为 0.05 后输出 5、8：最强桶是 5 号（与 6 号几乎并列），而超过 0.05 的桶共 8 个——这就是例题里那座山的地盘。

**练习 2**：调音器要在 1 秒窗口内区分 440.0 与 440.5 Hz 的琴音，采样率取 44100 时做得到吗？

<details>
<summary>点开查看逐步解答</summary>

桶宽 $\Delta f = f_s/N = 44100/44100 = 1$ Hz，两音相差仅 0.5 Hz——不足一个桶，主瓣互相重叠根本分不开（且 440.5 骑桶正中，各自都是一座胖山）。可行方向有二：加长窗口到 2 秒（$\Delta f$ 减半）；或利用乐器泛音结构配合更高级的估计法。分辨率的天花板永远写着同一个词：**观察时长**。
</details>

## 7. 选读：矩形窗的频谱印章

<details>
<summary>选读 · Dirichlet 核</summary>

长度 $N$ 的矩形窗 $w[n]=1$ 的 DTFT 是 $W(\omega) = \sin(N\omega/2)/\sin(\omega/2)$（Dirichlet 核）：在 $\omega=0$ 处高达 $N$，两侧以 $1/\omega$ 衰减并摆动。截断信号的频谱等于真谱与 $W$ 的周期卷积——单根谱线被盖成 $W$ 的形状，这正是泄漏图案的解析来源。主瓣宽度 $\approx 2f_s/N$、第一旁瓣只比主峰低约 13 dB 且不随 N 变化——加长窗口瘦得了主瓣、压不下旁瓣；想把旁瓣摁下去，必须换窗的形状。下一课的 Hann、Hamming 就是为这件事登场的。

</details>
