# 自适应滤波选讲：跟着信号自我校准

## 1. 从一个场景开始

降噪耳机刚开机的那一秒，世界还没安静：麦克风里灌进地铁轰鸣，而耳机内部的滤波器对这条新路径一无所知——系数该设多少？安静下来之后你走进另一节车厢，反射面变了，最佳系数也变了。**出厂时焊死参数的滤波器在这里活不过三秒**。

视频会议的回声消除是同样的处境：对方房间的声学路径每换一间屋子就重排一次。这一课请出 DSP 工具箱里唯一会「自己拧旋钮」的选手——自适应滤波器，看它如何用一条极简的学习法则在噪声中边干活边自我校准。

## 2. 直觉解释

固定滤波器与自适应滤波器的差别，是一台收割机与一个学徒的差别：

| | 固定系数 | 自适应系数 |
| --- | --- | --- |
| 参数来历 | 设计期一次定终身 | 运行中逐样本微调 |
| 环境变了 | 靠人工重标定 | 自己跟上去 |
| 出错的表现 | 从头错到尾 | 误差当场暴露，当场修 |

学徒怎么知道自己错了？系统准备了一份**误差信号** $e$：想听到的与实际得到的之差。误差越大，说明旋钮离正确位置越远。学习法则因此朴素得像句口号——

**新位置 = 旧位置 + 步长 × 误差 × 输入**

误差指路，输入决定每个旋钮各自该转多少，步长管胆子大小。三个因子相乘，就是大名鼎鼎的 **LMS（最小均方）算法**的全部家当。

## 3. 正式定义

**LMS 更新式**（最小均方自适应滤波器，单权重版）：

$$w \leftarrow w + \mu\; e[n]\; x[n], \qquad e[n] = d[n] - w\,x[n]$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $x[n]$ | 参考输入 | 与待消干扰相关的已知信号 |
| $d[n]$ | 期望信号 | 观测到的混合体（有用内容 + 待消干扰） |
| $e[n]$ | 误差 | 减完剩下的部分——理想情况下只剩有用内容 |
| $\mu$ | 步长 | 每次修正的力度；大则快而晃，小则稳而慢 |
| 权重向量 | 多抽头扩展 | 单数 $w$ 推广成一组 $w_k$，法则逐项照抄 |

名字里的「最小均方」说的是它的目标：调整 $w$ 使平均误差能量 $E[e^2]$ 尽量小。对单权重而言这是个开口向上的抛物线碗，而 LMS 每一步都沿着碗壁向下蹭一点——正是最速下降思想的随机化版本。收敛的担保写在纸上：步长够小就稳，太大就在碗底两侧来回过冲甚至发散。

## 4. 分步例题

**例**：房间把参考信号原样放大了两倍（真增益 2），我们未知，瞎猜初始 $w_0 = 1$；步长 $\mu = 0.25$。依次来三个样本：$x = [2,\ 1,\ 2]$，对应的观测 $d = [4,\ 2,\ 4]$。

1. 第一样本：估计 $y = 1 \times 2 = 2$，误差 $e = 4 - 2 = 2$；更新 $w = 1 + 0.25 \times 2 \times 2 = 2$；
2. 第二样本：$y = 2 \times 1 = 2$，误差 $e = 0$——误差为零就不动：$w = 2$；
3. 第三样本：同样零误差，$w$ 稳如磐石。学徒三步出师。

这次一步登天有两分运气：真值恰好整除、样本提前对齐。一般情形下误差只是逐步缩小，权重以指数速度滑向真值——但方向感与这三个因子的分工永远不变。

### 实验 2（python）：给耳机装上学徒逻辑

```python title="LMS 干扰消除：盯着权重爬向真值"
import math                            # 用 pi、sin
import matplotlib.pyplot as plt

N = 240                                # 样本总量
noise_f = 0.05                         # 干扰频率：每 20 拍一圈
sig_f = 0.009                          # 有用信号的频率：慢慢呼吸的长波

xs = []                                # 参考通道：拾音器录到的干扰原形
for n in range(N):
    xs.append(math.sin(2 * math.pi * noise_f * n))

ds = []                                # 期望端：干净信号 + 两倍干扰的混合
for n in range(N):
    clean = 0.6 * math.sin(2 * math.pi * sig_f * n + 1.2)
    ds.append(clean + 2.0 * xs[n])     # 房间把干扰放大了 2 倍混进来

mus = [0.02, 0.15]                     # 两档步长：慢性子与急性子
ws_record = {}
for mu in mus:                         # 各跑一遍学徒流程
    w = 0.0                            # 开局两手空空
    track = []                         # 记录抽查时刻的权重
    errs = []
    checkpoints = [10, 60, 239]
    ci = 0                             # 指向下一个抽查时刻的游标
    for n in range(N):
        e = ds[n] - w * xs[n]          # 当前欠账
        w = w + mu * e * xs[n]         # 学习法则：误差 × 步长 × 输入
        if ci < len(checkpoints) and n == checkpoints[ci]:
            track.append(round(w, 3))
            ci += 1                    # 游标右移一格
        errs.append(abs(e))
    ws_record[mu] = track              # 字典按键存档
    print("mu =", mu, " 抽查权重:", track)

plt.figure(figsize=(7, 3))             # 看混合体的庞杂
plt.plot(ds, color="tomato", linewidth=1, label="mixed")
plt.legend()

plt.figure(figsize=(7, 3))             # 再看校准后的残差
w = 0.0
resid = []
for n in range(N):
    e = ds[n] - w * xs[n]
    w = w + 0.15 * e * xs[n]
    resid.append(e)
plt.plot(resid, color="seagreen", linewidth=1, label="error")
plt.legend()
```

终端打印两行抽查账：`mu = 0.02` 的权重第 10 拍才到 0.26、第 60 拍爬至 0.97，收尾冲到约 1.8；`mu = 0.15` 版三个抽查点早已站到真值附近（1.5 → 2.3 → 1.75），此后一直贴着 2 左右轻晃——步长大收敛快，代价是晃动也更明显。绿色残差曲线开头是原样的干扰身高，几十拍内塌成细窄毛边——塌下去的部分全被权重吞进，剩下的正是要保护的信号。

### 快问快答

```quiz
把步长调大一万倍会怎样？
- 收敛瞬间完成且从此高枕无忧
- 收敛很快，但会在真值附近来回震荡，太大甚至发散 [*]
- 结果和慢步长一样，只是浪费算力
? 步长决定每一次修正的冲程：大了惯性刹不住车。工程上流行按输入功率自动缩放的 NLMS 来折中。
```

:::warning[常见误区]

**误区一**：「误差越小说明学得越好。」
若参考通道本身泄漏了一点有用信号，把误差压到零会连信号一起误杀。前提永远是：误差里除了待消干扰应当尽量别有别的。

**误区二**：「白噪声也能这样抵消。」
LMS 吃的是相关性——参考与干扰若共享波形（哪怕差个倍数相位），可学；纯随机的白噪声与谁都不熟，找不到稳定的相关结构，只能靠 FIR 平均这类频域思路。

**误区三**：「训练完就可以拔掉学习回路。」
环境漂移才是自适应的主场。冻结权重的自适应器退化回普通滤波器，下一班车一换路线立刻失效。

:::

## 6. 练习

**练习 1**：例题那间放大幅度的房间换成反向（真增益仍是 2），学徒的方向感却拧反了。先把错误账跑通看看症状：

```exercise
# @title: 练习：把学习法则的方向扶正
# @check: 0.0
# @check: 2.0
# @hint: 误差指出还差多少，更新就该朝消灭误差的方向迈——检查式子里那个减号站哪边
mu = 0.25                              # 步长
xs = [2, 1, 2]                         # 参考样本
ds = [4, 2, 4]                         # 期望样本
w = 1.0                                # 初始瞎猜
for i in range(len(xs)):
    e = ds[i] - w * xs[i]              # 误差：想得到 − 实际得到
    w = w - mu * e * xs[i]             # ← 问题在这：往误差更大的方向走了
print(round(e, 3))
print(round(w, 3))
```

把负号改成加号后输出 0.0 和 2.0：第一拍 $e=2$ 把权重从 1 直送 2，随后两拍零误差封盘。原来的减号让权重一路滑进负值深渊（跑到 −3），这正是过冲发散的迷你现场。

**练习 2**：回声消除里，$d$、$x$、$e$ 分别扮演什么角色？

<details>
<summary>点开查看逐步解答</summary>

免提电话场景：扬声器播出的远端语音绕进麦克风形成回声。$x$ 是「远处的人说了什么」（参考，即扬声器激励信号），$d$ 是麦克风实际录到的混合体（本地人声 + 回声），$e$ 是滤除后的外送信号——理想状态下只剩本地人的发言送往远方。为什么耳机敢在噪声到达耳朵前出手？因为拾音麦克风先半步听到它，LMS 只需学习那条毫秒级的延迟路径即可抢跑成功。
</details>

## 7. 选读：LMS 在优化家族里的辈分

<details>
<summary>选读 · 从碗面到随机梯度</summary>

把 MSE 写成权重的函数，是一口标准二次碗：单权重时碗底解析可得（维纳解），多权重时得解线性方程组。梯度下降课的第 43 章教过「沿负梯度小步走」，LMS 的巧妙在于**不估全梯度**：每来一个样本就用瞬时乘积 $e\,x$ 当梯度的糙替身——省内存又天然在线，代价是路径带毛刺。稳定性上界 $\mu < 2/\lambda_{max}$ 里，$\lambda_{max}$ 是输入自相关阵的最大特征值；实务中用 NLMS 把步长按当前输入功率归一化，工程寿命大幅延长。要求更快更平滑时还有递推最小二乘（RLS）这位用计算换收敛速度的大表哥。至此，控制章的反馈思想与本章的学习法则完成了一次会师。

把碗底解析地钉死：定义输入自相关矩阵 $R = E[\vec x\,\vec x^{T}]$ 与互相关向量 $\vec p = E[d\,\vec x]$，均方误差就成了 $J(\vec w) = \sigma_d^2 - 2\vec p^{T}\vec w + \vec w^{T}R\vec w$。对它求导置零，得**维纳解** $\vec w^{*} = R^{-1}\vec p$——LMS 长跑的平均终点。一个二阶抽头的账：$R = \begin{pmatrix}1 & 0.5\\ 0.5 & 1\end{pmatrix}$、$\vec p = (0.75,\ 0.25)^{T}$ 时，$R^{-1} = \frac{4}{3}\begin{pmatrix}1 & -0.5\\ -0.5 & 1\end{pmatrix}$，代入得 $\vec w^{*} = (\tfrac{5}{6},\ -\tfrac{1}{6})^{T} \approx (0.833,\ -0.167)^{T}$，最小均方误差 $J_{\min} = \tfrac{5}{12} \approx 0.417$。LMS 带着毛刺的随机脚步，平均意义下正是朝这一点走的——"碗底解析可得"不是比喻，是收敛终点。
</details>
