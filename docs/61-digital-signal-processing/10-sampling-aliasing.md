# 采样与混叠：连续世界的数字快照

## 1. 从一个场景开始

视频里的汽车加速时，车轮先变快、然后仿佛停住、最后竟然**倒着转**。摄像机没有骗你——它每秒只拍 30 张照片，转得太快的轮辐在照片里插空成功，看起来就像在倒退。

脑电实验室里也有一模一样的陷阱：一台自制的低成本采集头带以 12 Hz 的采样率记录脑电，受试者明明闭眼放松（枕区应该出现 8~13 Hz 的 α 节律），屏幕上却画出一条约 2 Hz 的慢波——像深度睡眠。10 Hz 的 α 波没有消失，它**假扮成了低频**。

这就是本课的主角：**采样**把连续信号变成数字序列，而**混叠（aliasing）**是采样太慢时高频冒充低频的伪装术。看清它的规律，你就明白 CD 为什么每秒采 44100 次、临床脑电设备为什么至少要 256 Hz。

## 2. 直觉解释

采样就是按固定间隔给连续波形**拍快照**。设采样率是 $f_s$ Hz，每隔 $T = 1/f_s$ 秒记一个数。

关键问题：多密的快照才够？看两个正弦在采样点上撞衫：

- $f_s = 10$ Hz 时，采样点落在 $t = 0,\, 0.1,\, 0.2, \ldots$ 秒。13 Hz 与 3 Hz 的两条正弦在这串时刻上的样本**完全相同**：$\sin(2\pi \cdot 13 \cdot n/10) = \sin(2\pi n + 2\pi \cdot 3n/10)$，正弦的周期性把多出来的整圈吃掉了。
- 于是任何比 $f_s/2$ 更高的频率，都能找到一个 0 到 $f_s/2$ 之间的替身。替身频率叫**假频**（alias frequency）。

折叠规律一句话：**频率轴以 $f_s/2$ 为镜子**。超过镜子的成分被反射回来：第一折叠区里的 $f$ 变成 $f_s - f$；更高的继续往里折。13 Hz 在 $f_s=10$ 时折成 $|13-10| = 3$ Hz——正是上面那位替身。

## 3. 正式定义

**采样**：对连续信号 $x(t)$ 每隔 $T = 1/f_s$ 秒取一个值，得到序列 $x[n] = x(nT)$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f_s$ | 采样率 | 每秒采集的样本个数（Hz） |
| $T = 1/f_s$ | 采样间隔 | 相邻两个样本的时间差（秒） |
| $f_N = f_s/2$ | 奈奎斯特频率 | 可被正确观测的最高频率 |
| 假频 $\tilde{f}$ | alias | 超过 $f_N$ 的成分在样本里呈现的频率 |

**采样定理（奈奎斯特–香农）**：若信号最高频率为 $f_{max}$，则当

$$f_s > 2 f_{max}$$

时，采样不损失信息，原信号可由样本唯一重建；否则发生混叠。第一折叠区的假频公式：

$$\tilde{f} = |f_s - f| \qquad (f_N < f < f_s)$$

一般情形用折纸算法：把 $f$ 对镜子 $f_N$ 反复反射，直到落回 $[0, f_N]$ 区间（例题演示两次折叠）。注意定理要求**严格大于**：恰好压在 $2 f_{max}$ 上仍可能全军覆没——想想采样点全落在正弦的零点上会采到什么。

## 4. 分步例题

**例**：$f_s = 100$ Hz。判断以下成分是否混叠；若混叠求假频：(a) 40 Hz；(b) 60 Hz；(c) 130 Hz。

1. 先算镜子位置：$f_N = 100/2 = 50$ Hz；
2. (a) $40 \le 50$，安全，无混叠；
3. (b) $50 < 60 < 100$，第一折叠区：$\tilde{f} = |100 - 60| = 40$ Hz——与 (a) 那个真 40 Hz 在样本里**不可区分**；
4. (c) $130 > 100$，先减去一个整采样率：$130 - 100 = 30$，已落进安全区，故假频为 30 Hz；
5. 结论：采样后的频谱上看到 40 Hz（真假难辨！）与 30 Hz 两根峰。混叠的危险正在于此——它不是把高频变小或抹掉，而是让它**完好无损地顶替别人**。

## 5. 动手实验

### 实验 1（viz）：找出冒名顶替者

蓝线是一条真实的高频振动，橙线是一条低频正弦。先说读图：竖网格线只是时间参照（间隔自动取 0.2 秒），**不是采样点**；真正的采样时刻是每 0.1 秒一个。两条曲线在整个区间上还有别的交点，别被它们迷惑——要紧的是在每一个 0.1 秒的采样时刻，两者的**取值**是否相同；严格按采样时刻逐点对比，看下面的 Python 实验（红点把样本钉出来）：


默认 $f=13$、$a=3$ 时，两条曲线在整个区间里另有交点，光看图分不出谁是谁的替身；要紧的是在每个 0.1 秒的采样时刻两者取值完全相同——下面的 Python 实验把样本钉成红点，代表假频的蓝虚线会**精确穿过每一个红点**：采样器拿到的就是同一串数。把 $f$ 拖到别的整数再配 $a$：总能用 $a = |f - 10|$ 配上这种"样本级撞衫"。两条完全不同的连续曲线，在采样器眼里却是同一个东西。

### 实验 2（python 滑块）：看着频率折叠

```python title="拖动真实频率 f，看它折成多低的假频"
# sliders: f=7 [1:19:1]
import math                      # 数学工具库：用 pi、sin 和 floor
import matplotlib.pyplot as plt  # 画图库（卷一已引入）

fs = 10                          # 采样率：每秒 10 个样本
fold = ((f + fs / 2) % fs) - fs / 2   # 折叠公式：先把 f 卷回一个采样率的范围
fake = abs(fold)                 # abs 取绝对值：得到 [0, fs/2] 内的假频
print(f"真实 {f} Hz -> 样本呈现 {round(fake, 1)} Hz")

ts = []                          # 密集时间点：画真实曲线用
xs = []
for i in range(400):
    t = i / 200                  # 从 0 到 2 秒，步长 0.005 秒
    ts.append(t)
    xs.append(math.sin(2 * math.pi * f * t))

ns = []                          # 采样时刻
ys = []                          # 采样值
for n in range(21):              # 0 到 2 秒共 21 个采样点
    t = n / fs
    ns.append(t)
    ys.append(math.sin(2 * math.pi * f * t))

fs_line = []                     # 假频曲线（虚线对照）
for t in ts:
    fs_line.append(math.sin(2 * math.pi * fold * t))   # 用带符号的 fold 画线：频率与相位都和样本对齐

plt.figure(figsize=(7, 3))       # 新建画布并指定尺寸（英寸）
plt.plot(ts, xs, color="lightgray", linewidth=4, label="true")
plt.plot(ns, ys, marker="o", linestyle="", color="red", label="samples")
plt.plot(ts, fs_line, linestyle="--", color="steelblue", label="alias")
plt.axhline(0, color="gray", linewidth=0.8)
plt.legend()
```

灰粗线是真实振动，红点是每 0.1 秒采到的样本，蓝虚线是用假频画出的正弦。当 $f > 5$（奈奎斯特频率）时，蓝虚线会**精确穿过每一个红点**——样本里只剩假频活着。试试 $f=6, 9, 13, 18$ 各是什么假象；再注意 $f=15$ 时红点全为零（采样点恰落在波节上），信号整个消失。

### 快问快答

```quiz
采样率 100 Hz 时，混入的 60 Hz 工频干扰会在数据里伪装成多少 Hz？
- 60 Hz，干扰还是干扰
- 40 Hz [*]
- 50 Hz
? 第一折叠区公式：假频 = |采样率 − 真实频率| = |100 − 60| = 40。这是脑电与音频采集的经典事故：市电干扰被误读成真实的生理节律。
```

:::warning[常见误区]

**误区一**：只要比两倍略高一点点就够安全。
抗混叠滤波器不是悬崖，是缓坡——接近奈奎斯特频率的成分只能被压低、无法归零，仍会折进来。临床脑电的惯例是采样率至少取带宽上限的三倍上下（ACNS 建议常规脑电不低于 256 Hz），给滤波器的滚降留出跑道。

**误区二**：混叠把高频削弱了，影响不大。
恰恰相反：混叠后的假频**幅度完好**，还会精准地顶替同频带的真信号——50 Hz 干扰在低采样率下可以伪装出以假乱真的 α 波，比丢信息恶劣得多。

**误区三**：采坏了没关系，事后用数字滤波器修。
数字滤波器工作在采样之后的世界里，它看到的假频就是合法居民，无法驱逐。唯一可靠的闸门是采样**之前**的模拟抗混叠滤波器。

:::

## 6. 练习

**练习 1**：一台教学设备以 $f_s = 30$ Hz 采样。三个真实成分为 2、10、22 Hz。请打印三行：各自的假频（不混叠的输出它本身）。代码能跑但答案不对，改到通过：

```exercise
# @title: 练习：算出每个成分的假频
# @check: 2
# @check: 10
# @check: 8
# @hint: 奈奎斯特频率是 15。低于它的成分原样通过；22 落在第一折叠区（15~30），假频 = 30 - 22。通用折叠公式会得到浮点数，这里用 round(alias) 打印整数赫兹
fs = 30
for freq in [2, 10, 22]:
    alias = freq % fs            # ← 问题在这：取余不是折叠，22 % 30 还是 22
    print(alias)
```

改对后输出 2、10、8——22 Hz 的成分会顶着 8 Hz 的名义出现在数据里。通用写法是把频率对半采样率先减整周期、再做镜像反射，并用 `round(alias)` 输出整数赫兹；欢迎把循环改成函数处理任意大的频率。

**练习 2**：CD 系统规定人耳上限约 20 kHz，为什么选 44100 Hz 而不是刚好 40000？

<details>
<summary>点开查看逐步解答</summary>

44100 > 2 × 20000，满足定理还留出约 2000 Hz 的过渡带，让模拟抗混叠滤波器的缓坡有地方铺开（误区一）。至于 44100 这个怪数字本身：它是早期黑白录像机改造的数字录音机行频的公倍数——工程史的偶然，被标准冻结成了永恒。工程选型 = 数学下限 + 实现余量 + 历史惯性。

## 7. 选读：为什么样本里全是假频的天下

<details>
<summary>选读 · 频谱的复制粘贴</summary>

采样在频域的效应异常整齐：原信号的频谱会被**复制**到每个 $k f_s$（$k$ 为整数）处，像盖章一样铺满整条频率轴。若原频谱本来就限制在 $[0, f_s/2]$ 内，各份复印件互不重叠，用一个理想低通滤出主件即完美重建——这是定理成立的真正原因。反之复印件互相叠加，$f$ 与 $f_s-f$ 的能量混在同一根谱线上再也分不开。傅里叶视角一句话：**混叠 = 频谱复印过度导致的墨迹重叠**。

</details>
