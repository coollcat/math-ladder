# 冲激响应与差分方程

## 1. 从一个场景开始

把麦克风对着自家音箱，会议室会在某个瞬间爆出一声刺耳的长鸣——**啸叫**。原因是扬声器刚播出的声音被麦克风捡走、放大、又送回音箱：输出绕了一圈重新变成输入。只要这一圈循环下来每次都比上次更大，系统就在滚雪球；若每一圈都乘上一个小于一的折扣，雪球滚几圈就化了，一切平静。

这一个「把昨天的输出也记进今天的账」的小动作，写出来就是**递推的差分方程**。它是 IIR（无限冲激响应）滤波器的灵魂，也是第 50 号课结尾埋下伏笔的正式兑现。

## 2. 直觉解释

普通滤波器（FIR）像一张固定长度的购物清单：每个新样本进来，把窗口里几个历史输入加权求和，完事销账——**只记得输入**。

现在给系统加一条「回头看」的反馈线：

- 音箱的声音有一部分绕回麦克风——把**过去的输出**当作今天输入的一部分；
- 于是每个输出都是「新的外界刺激 + 自己历史的影子」，一行递推账就能永续记账，不需要存整个历史；
- 反馈折扣小于一时历史逐年褪色（稳），不小于一时历史越滚越大（啸叫爆炸）。

怎么快速摸清这样一个系统的脾气？沿用第 20 号课的老办法：**轻轻敲它一下**。冲激只在第 0 拍是 1，此后全程沉默——剩下的每一拍都在消化自己的历史，账目自己往下滚。这条从一击开始自行展开的序列就是**冲激响应** $h[n]$：它是系统的指纹，配合卷积承诺可以拼出一切输出的答案。

## 3. 正式定义

**差分方程（递推式）**：输出由当前与过去的输入、过去的输出线性组合给出

$$y[n] = \sum_{k} b_k\, x[n-k] \;-\; \sum_{j \ge 1} a_j\, y[n-j]$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $b_k$ | 输入侧系数 | 给历史输入分配的权重——FIR 的全套配方只是它的特例 |
| $a_j$ | 反馈系数 | 过去的输出以多大比例影响现在，系统的「记忆浓度」 |
| $x$、$y$ | 输入、输出 | 外部 stimulus 与系统回应 |
| 因果 | 只用过去 | 所有 $x[n-k]$、$y[n-k]$ 的下标都不越过当前时刻 |

一阶系统最干净：$y[n] = x[n] + c\, y[n-1]$。给一发冲激后输入彻底熄火，账目变成纯粹的自我滚动：$h[n] = c \cdot h[n-1]$，于是 $h[n] = c^n$——一条等比数列。$c < 1$ 时逐步衰减（稳定），$c > 1$ 时指数膨胀（啸叫），$c$ 为负则在正负之间交替摆动。

## 4. 分步例题

**例**：系统 $y[n] = x[n] + 0.5\, y[n-1]$，求冲激响应的前四拍。

1. 第 0 拍：$x[0]=1$，历史为空，$y[0] = 1 + 0.5 \times 0 = 1$；
2. 第 1 拍：$x[1]=0$，只剩历史的回声，$y[1] = 0 + 0.5 \times 1 = 0.5$；
3. 第 2 拍：吃的是上一拍的一半，$y[2] = 0.5 \times 0.5 = 0.25$；
4. 第 3 拍继续对折：$y[3] = 0.125$。于是 $h = [1,\ 0.5,\ 0.25,\ 0.125,\ \ldots]$——每拍乘 $0.5$ 的等比衰减。

反过来验证「指纹论」：把这些 $h$ 与任意输入做卷积，结果和逐拍递推严格一致。顺带偷看一眼台阶输入（从第 0 拍起一直顶着 1）：响应从 1 开始步步累加，最终逼近 $1/(1-0.5) = 2$——几何级数的部分和即将在第 7 节选读里换个身份登场。

## 5. 动手实验

### 实验 1（viz）：拖动公比，看记忆浓度

递推 $h[n] = r \cdot h[n-1]$ 展开就是一条等比数列。拖动公比 $r$ 相当于拧反馈系数 $c$：

```viz
{
  "type": "seq",
  "kind": "geom",
  "a1": 1,
  "r": 0.9,
  "n": 9
}
```

$r < 1$ 时柱条一路矮下去，这是「礼貌的回声」；$r = 1$ 时一排平顶（历史永不褪色）；$r$ 越过 1，柱条瞬间蹿高直到画布装不下——组件给它盖了一枚红色「爆炸」印章，这就是啸叫的数学长相。

### 实验 2（python）：冲激敲一下，台阶顶到底

```python title="同一台递推机，两种输入"
import matplotlib.pyplot as plt   # 画图库（此前课程已引入）

c = 0.8                           # 反馈系数：上一拍输出留下的成数
N = 12                            # 总共跑多少拍

hs = []                           # 冲激响应账本
prev = 0                          # 「上一拍的输出」，开局还没有历史
for n in range(N):
    x = 1 if n == 0 else 0        # 条件表达式：第 0 拍敲一下，其余静默
    y = x + c * prev              # 差分方程本体：新刺激 + 留下的历史
    hs.append(y)                  # append：把结果接到账本末尾
    prev = y                      # 本拍立刻成为「过去」

steps = []                        # 台阶输入的另一本账
ys2 = []
prev = 0
for n in range(N):
    steps.append(n)
    y = 1 + c * prev              # 台阶：从第 0 拍起一直顶着 1
    ys2.append(y)
    prev = y

show = [round(v, 3) for v in hs]  # 列表推导式：对每个元素套同一个格式化
print("h  =", show)
print("step 末值 =", round(ys2[-1], 3))

plt.figure(figsize=(7, 3))        # 新建宽 7、高 3 英寸的画布
plt.plot(steps, hs, marker="o", label="impulse")     # marker='o'：每个点画圆点
plt.plot(steps, ys2, marker="s", label="step")
plt.legend()
```

冲激那条曲线从 1 一路衰减到 $0.8^{11} \approx 0.09$：折扣机器的尾巴。台阶那条曲线爬向 $1/(1-0.8) = 5$ 的天花板，第 11 拍停在约 4.66——差一口气，因为历史还没流干。把 `c` 改成 `-0.9` 再跑：曲线变成正负交替的锯齿，这是负反馈在两根轨道之间荡秋千。

### 快问快答

```quiz
IIR 的「无限」冲激响应，指的是什么？
- 冲激响应的数值可能是无穷大
- 只要反馈系数不为零，理论上一发冲激的影响永远不会精确归零 [*]
- 系统的输出位数无限
? h[n] = c^n 只有在恰好某个时刻才严格为零。工程里数值会小到被噪声淹没，但「理论上拖尾」正是它与 FIR 的本质区别，也是为什么必须谈稳定性。
```

:::warning[常见误区]

**误区一**：「递推必须保存全部历史。」
不需要——一行上一拍的输出就够了。马尔可夫式的「下一拍只依赖当前状态」让 IIR 以极少的内存实现很深的记忆。

**误区二**：「反馈白赚算力，不要白不要。」
反馈确实能用三五个系数追平几十个抽头的陡峭 FIR，但代价是一张稳定性账单：任何一个折扣配猛了，系统就从滤波器变身扬声器杀手。

**误区三**：「 $h[n]$ 只能靠公式推导。」
工程现场常常直接**测**：往系统里打一发近似冲激（短促敲击、狄拉克脉冲音），录下输出即得指纹。鞋合不合脚，敲一下就知道。

:::

## 6. 练习

**练习 1**：修好这台冲激响应机。目标是打出 $y = x[n] + 0.5\, y[n-1]$ 的前三拍之外的完整衰减链。代码能跑但答案不对：

```exercise
# @title: 练习：反馈应该接谁？
# @check: 1.0
# @check: 0.5
# @check: 0.25
# @check: 0.125
# @check: 0.0625
# @hint: 差分方程的反馈项吃的是过去的「输出」，不是过去的输入。盯紧代码里乘 0.5 的对象是谁
xs = [1, 0, 0, 0, 0]                     # 冲激输入：只在第 0 拍敲门
hs = []                                  # 输出账本
prev_out = 0                             # 上一拍的输出
for n in range(len(xs)):                 # len：列表长度
    xin = xs[n]
    out = xin + 0.5 * xs[max(0, n - 1)]  # ← 问题在这：乘了上次的输入？
    prev_out = out                       # 存好本拍的输出，供下一拍使用
    hs.append(out)

for v in hs:
    print(v)
```

把更新式改成 `out = xin + 0.5 * prev_out` 后逐行输出 1.0、0.5、0.25、0.125、0.0625：反馈线接上了输出端，每拍留下前一拍的一半作为余温。原代码错把反馈接到输入端，冲激过后立即断粮，输出在第 1 拍就清零。

**练习 2**：反馈系数换成 $c = -0.5$ 时，冲激响应与台阶响应分别长什么样？

<details>
<summary>点开查看逐步解答</summary>

$h[n] = (-0.5)^n$：1、-0.5、0.25、-0.125……正负交替且幅值对折——回声「每拍翻一面墙」并衰减一半。台阶响应 $y[n] = 1 + (-0.5)\,y[n-1]$ 从 1 出发上下扇动，逐步夹向终值 $1/(1-(-0.5)) = 2/3$：因为每拍的新账都有反向旧账来对冲，最终稳态比 $c = 0.5$ 时更低也更晃。负反馈不改稳定性判据（仍看 $|c|$ 是否小于 1），只改变达标的路径姿势。
</details>

## 7. 选读：一行递推的两副面孔

<details>
<summary>选读 · 几何级数、幂级数与下一课的伏笔</summary>

台阶输入下 $y[n] = 1 + c\,y[n-1]$ 的闭式解是 $y[n] = (1 - c^{n+1})/(1 - c)$——几何级数部分和，所以天花板恰为 $1/(1-c)$。更有趣的是把冲激响应的全体值排成一串系数：$h[0] + h[1] z^{-1} + h[2] z^{-2} + \cdots = 1/(1 - c z^{-1})$。看到没有——**一行递推除以一行多项式**，无限长的 $h$ 被收纳成两个有限的字母。把变量限制在单位圆上滚动（$z = e^{i\omega}$，欧拉公式的老朋友），这串幂级数给出的正是滤波器的频率响应；而「幂级数什么时候收敛」的判据（$|cz^{-1}| < 1$）翻译过来就是 $|c| < 1$——稳定性问题忽然变成了级数敛散问题。这套「序列当系数、复数当变量」的记账法就叫 **Z 变换**，下一课的主角。它的血亲你其实见过：第 28 章母函数把数列写成多项式系数，用的同一枚硬币。
</details>
