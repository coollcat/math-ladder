# 多速率处理与重采样

## 1. 从一个场景开始

一首 44.1 kHz 的 CD 音乐要塞进仅支持 22.05 kHz 的老设备，最省事的念头是：**隔一个扔一个**，样本瞬间减半。听起来天衣无缝——直到放出来听见原本干净的三角铁泛音变成一缕若有若无的怪腔，混在人声里驱之不散。

修图软件缩小照片时也一样：隔行隔列粗暴抽像素，猫毛边缘立刻爬满摩尔纹。问题不在「扔」，在于没跟镜子打好招呼——第 10 号课讲过，任何超过新采样率一半的高频都会**乔装成低频**返回现场。本课给出重采样的全套安全规程：抽取与内插这对孪生动作的对偶账法。

## 2. 直觉解释

把信号想成走钢丝的演员，采样格网是脚下的钢索间距：

- **抽取（降采样）**＝把间距调宽。演员每步能迈的能量上限变小了，原本在大跨度区间里晃的高频身段无处安放——它们不会消失，而是按第 10 号课的镜像规则**折返伪装成低频**；
- **内插（升采样）**＝把间距调窄。新格网比旧格网更密，缝隙里空出来的位置若直接填零，频谱里会凭空多出一批镜像拷贝；用一台平滑滤波器把台阶磨圆才算完成搬家；
- 一句对偶口诀管住两头：**降先滤后丢，升先插零再滤**。丢和插都是粗活，滤才是防伪安检。

有个好用的视角叫**重采样率比**：输入率与输出率相除得到预算比 $R$。频率预算跟着 $R$ 同比例缩水或膨胀，内容本身不会凭空蒸发——所以质量问题的关键永远是那道截止线画在哪、坡有多缓。

## 3. 正式定义

**抽取（M 倍降采样）**：

$$y[m] = x[M m]$$

新采样率为 $f_s/M$，新的可用带宽上界随之降到 $f_s/(2M)$；此前的内容必须先用低通滤波器拦在门外。

**内插（L 倍升采样）**：先做零填充 $v[mL] = x[m]$（其余位置一律填 0），再过一台增益乘 $L$ 的低通「补形」滤波器，把插零造成的镜像谱清除，得到平滑加密的新序列。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $M$ | 抽取因子 | 每 $M$ 个保留一个，率比视角下输出率缩为 $1/M$ |
| $L$ | 内插因子 | 每个原始样本之间插入 $L-1$ 个待补位置 |
| 折叠公式 | 假频换算 | 假频 = 真实频率到「新采样率整数倍」的最近距离 |
| 截止线 | 抗混叠边界 | 低通必须卡在新奈奎斯特之下，坡越缓越安全 |

折叠公式就是本课的计算核心：记新率为 $F$，频率为 $f$ 的成分落在 $f \bmod F$ 处，一旦越过 $F/2$ 就按 $F$ 对称翻折回去。

## 4. 分步例题

**例**：把 $f_s = 40\,\text{kHz}$ 的音频降到 $20\,\text{kHz}$，信号里有 5 kHz 的人声主音和 17 kHz 的镲片泛音。

1. 求新规矩：新奈奎斯特频率 $= 20/2 = 10\,\text{kHz}$——这是所有成分的身高检票线；
2. 主音体检：5 kHz 远低于 10 kHz，顺利通过；17 kHz 超标，折叠：距离最近的新率整数倍是 20 kHz，假频 $= 20 - 17 = 3\,\text{kHz}$；
3. 后果与对策：3 kHz 正砸在人声最密集的音区——镲片的幽灵顶替人声上台。对策是在丢样本前先上一台截止 10 kHz 以下的抗混叠低通，让 17 kHz 出门之前就被压灭。

### 实验 2（python）：先滤后丢 vs 裸奔直丢

```python title="同一个 4 千赫座位：幽灵顶替与真身归位"
import math                            # 用 pi、sin 与 hypot

fs = 64                                # 原始采样率
N = 64                                 # 样本数，M=2 抽取后剩 32 个
w = [1, 4, 6, 4, 1]                    # 二项窗权重：中心大两边小的低通原型

sig = []                               # 原始信号：4 号真身 + 28 号捣乱者（玩具世界的赫兹）
for n in range(N):
    slow = math.sin(2 * math.pi * 4 * n / fs)      # 合法的低频主音
    rogue = 0.6 * math.sin(2 * math.pi * 28 * n / fs)  # 超出新奈奎斯特的捣乱者
    sig.append(slow + rogue)

def proj_amp(data, f, rate):
    s = 0.0                            # 与探测正弦的内积累计
    c = 0.0                            # 与探测余弦的内积累计
    for i in range(len(data)):
        ang = 2 * math.pi * f * i / rate
        s = s + data[i] * math.sin(ang)
        c = c + data[i] * math.cos(ang)
    return 2 * math.hypot(s, c) / len(data)

direct = []                            # 裸奔派：直接隔一个取一个
for m in range(N // 2):                # // 整除：新序列长度
    direct.append(sig[2 * m])

filtered = []                          # 规程派：先加权平滑，再取点
for m in range(N // 2):
    acc = 0.0
    for k in range(-2, 3):             # 偏移从 -2 到 2 扫过窗权
        j = 2 * m + k                  # 本拍对应的原样本位号
        if 0 <= j < N:
            acc = acc + w[k + 2] * sig[j]
    filtered.append(acc / 16)          # 权重总和 16，除回去保持尺度

a_raw = proj_amp(direct, 4, 32)        # 在新网格 4 千赫桶上读振幅
a_safe = proj_amp(filtered, 4, 32)
print("裸奔直丢，桶上振幅:", round(a_raw, 3))
print("先滤后丢，桶上振幅:", round(a_safe, 3))
```

打印约为 `0.4` 与 `0.925`：裸奔时 28 号捣乱者以**反相位**踩进新网格的 4 号座位，与真身对消掉一大半（只剩四成振幅）；先过二项低通——它的深坑恰好挖在捣乱者的频段上——幽灵近乎清零，4 号座的读数几乎恢复原貌。桶号还是那个桶号，谁坐上去却完全取决于工序顺序。

### 快问快答

```quiz
把 48 kHz 录音转成 16 kHz 发布稿，正确工序是什么？
- 隔两个取一个，省时省力
- 先用低通把 8 kHz 以上拦下，再隔两个取一个 [*]
- 升采样再截断，反正最后都要变小
? 新采样率 16 kHz 的一半只有 8 kHz：低于它的才能幸存。顺序颠倒，高频幽灵立刻反客为主。
```

:::warning[常见误区]

**误区一**：「抽取只是删数据，不影响已有内容的形状。」
删掉的样本正是重建高频所需的自由度。信息守恒：高于新奈奎斯特的部分必然换个频率回到带内——区别只在你是否提前把它送走。

**误区二**：「内插填零就是放大完成。」
插零制造的谱镜像是实打实的能量副本，听感发闷刺耳、看图像有细密鬼影。必须配合补形低通把镜像抹平，升采样才算闭环。

**误区三**：「图像放大用最近邻复制就够了。」
逐像素复制等于内插不做滤波的极端形态：马赛克楼梯正是那批未被磨平的镜像。双三次等算法本质上是一台更讲究的补形滤波器。

:::

## 6. 练习

**练习 1**：新采样率 40 Hz 下，三路成分会各自伪装成什么频率？代码能跑但中间一行不对：

```exercise
# @title: 练习：给三路成分办假频登记
# @check: 5
# @check: 10
# @check: 5
# @hint: 只取余数还不够：越过半率（20）的成分要按新采样率对称翻折回去
fs_new = 40                       # 重采样后的新采样率
tones = [5, 30, 45]               # 三路真实频率
for f in tones:
    ghost = f % fs_new            # ← 问题在这：余数不是终点，还要折叠
    print(ghost)
```

在循环里补一段 `if ghost > fs_new / 2: ghost = fs_new - ghost`，输出依次为 5、10、5。中排的 30 Hz 越过检票线对折成 10 Hz；45 Hz 余数为 5 且未过线，原样通过——但它是从上一圈绕回来的乘客，身份其实属于「一倍新率减五」的那份高频。

**练习 2**：反过来把 16 kHz 发布稿重制回 48 kHz，工序怎么倒腾？

<details>
<summary>点开查看逐步解答</summary>

角色切换成内插：令 $L = 3$，先把每个样本后面插两个零（长度立刻涨三倍）；此时频谱里除正主外还拖着两幅位于 $16k$ 与 $32k$ 附近的镜像；再用一台增益配平为 3 的低通——截止仍画在 8 kHz——把镜像抹平、台阶补圆。得到的是法律意义上合法的 48 kHz 音轨，只是 8 kHz 以上的内容当年已随抽取而去，宇宙没有后悔药：**升降不对称，有损的方向才是历史真相**。
</details>

## 7. 选读：多级分解与省算力的套路

<details>
<summary>选读 · 为什么改 48 倍速要分很多次半</summary>

一次性抽取 48 倍需要一台过渡带极陡的单级滤波器——阻带要快过山车，系数动辄上百。工程上的通行做法是多级接力：先 3 倍降到 16k，再两次 2 倍降到目标，每一级的减速温和、缓坡便宜，总乘加次数常常还不到单级方案的一小半。小波课的逐级平均/差分探针、以及所谓 CIC、半带滤波器之名，都属于这套「多快好省」的家族手册；初学阶段只需带走一句方法论——**大幅变速不要一口吃成胖子，分段消化每段都配齐安检**。
</details>
