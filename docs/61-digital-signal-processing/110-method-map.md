# 数字信号处理方法地图

## 1. 从一个场景开始

兵器架上摆了十几台机器：滤波器、变换器、抽样器、学习器……每一台都曾在某堂课里独当一面。可真到了项目桌上，最常见的第一反应是大脑一片空白：「我手里这摊问题，到底该推哪台机器上场？」

学完一章工具最大的风险，不是忘了定理，而是拿着锤子看什么都是钉子。本课不添任何新定理，只做三件事：把全章课程排成一张导诊地图、演练一遍两问分诊法、然后把容易踩的坑一次性列队展览。

## 2. 直觉解释

分诊只需连问两个问题：

**第一问——你要对信号做什么？**
- 只想**看清**它（里面有什么频率、何时发生了什么）：派分析类选手出场；
- 想**改变**它（去掉毛刺、删掉干扰、改变速度、压缩体积）：派改造类选手出场；
- 而**边运行边适应**属于第三种状态：环境会动的活儿，永远留给会自己学习的机器。

**第二问——信号的「形状」是什么样？**
平稳绵长的流水适合全局视角；突发短促的事件要求局部视野；二维排布的东西要用能搬动能量的正交基；两股未知来源缠在一起时，得请出统计独立性这种更高维的侦探手段。

两问答案往表上一对，科室基本锁定。剩下的分歧多半发生在「多种工具都能凑合」的地带——那时再比算力、延迟和可维护性，而不是比谁听起来高级。

## 4. 分步例题

**题 A**：手环心率显示在跑步时数字乱跳，且设备内存紧张。

1. 第一问：要**改变**信号（抹平毛刺），改造类；第二问：形状平稳缓慢、只需要有限窗口的历史；
2. 代价审查：IIR 省内存但相位会扭；心率波形还要展示细节，优先保相位的 FIR；
3. 处方：小型滑动平均，窗口长度卡在实时延迟可接受的范围。

**题 B**：一段现场录音疑似混入怪腔，领导要求「先确诊再动手」。

1. 第一问：要看**清楚**有什么频率——分析类；第二问：录音长而平稳，全局视角够用；
2. 但要提防诊室的假象：频率不落在整数桶上会泄漏，读数前先确认观察时长是否足够分辨可疑邻居；
3. 处方：DFT 长窗起步，需要盯时刻就升级成加窗的时频图。

**题 C**：免提电话开会半小时，对方房间中途挪了桌子。

1. 第一问：既要消除又要持续有效——环境在变，锁死参数必死；第二问：参考通道与回声高度相关，可学性满分；
2. 代价审查：重标定人工方案当场出局，得上会自动跟新的算法；
3. 处方：LMS 在线自适应，步长取中庸防震荡。

### 实验 2（python）：分诊台原型机

```python title="按症状开具科室单"
def triage(spectrum_mystery, rate_shift, drifting_world, rough_surface):
    # 优先级闸门：越结构性的问题越早分流
    if spectrum_mystery:
        return "dft-leakage"
    if rate_shift:
        return "multirate-resampling"
    if drifting_world:
        return "adaptive-filter"
    if rough_surface:
        return "fir-iir"
    return "convolution-lti"

cases = [
    ("噪声真假难辨，先开诊单看看频率", True, False, False, False),
    ("CD 音轨要喂给低端音箱", False, True, False, False),
    ("会议刚开始，回声路径又开始挪窝", False, False, True, False),
    ("手环数值一路抽风但环境没变", False, False, False, True),
]
for note, a, b, c, d in cases:       # 元组解包：一次领出整行参数
    print(triage(a, b, c, d), "|", note)
```

打印结果就是四次分诊：先查频谱、再管速率、然后交给学徒、最后才是手工打磨。这套 if 台阶只是决策表的雏形——真实工程还会叠加实时性预算、算力配额等第五第六个维度，但「先分类、后施治」的主轴不变。

### 快问快答

```quiz
哪一台机器最擅长在系统通电之前就回答「它会不会自己唱起来」？
- FFT：算出谱就知道
- Z 变换体检：看极点是否全都住在单位圆内 [*]
- 自适应滤波：跑两天看效果
? 频谱是工作时的表现，极点户口是出厂时的体质证明。稳定性是天生的判据，不靠事后观察。
```

:::warning[常见误区]

**误区一**：「有了 FFT 就万能了。」
FFT 只是快镜头不是手术刀：它能告诉你频率在哪，删掉它们仍然要回到滤波器、窗函数和重采样的地面战场。

**误区二**：「重采样随手扔几个样本无所谓。」
第 90 号课刚演示过幽灵顶替事故。凡是动格网的地方都必须配安检滤——这是全章唯一零例外的硬规矩。

**误区三**：「方法地图是一条通关路线。」
它是按需查阅的工具书，不是进度条。真实工作从来只摘用其中两三页，条条大路通罗马的前提是你知道罗马在哪张图的哪个坐标。

:::

## 6. 练习

**练习 1**：分诊台的分支被人调整过顺序，三位病号中一位被开错了科室单。找出并扶正优先级：

```exercise
# @title: 练习：谁的科室单开错了
# @check: fir-iir
# @check: multirate-resampling
# @check: adaptive-filter
# @hint: 规则手册写着：环境漂移属结构性顽疾，哪怕表面也有毛刺，也必须先送去会自我学习的科室
def clinic(need_new_rate, world_drifts, rough_signal):
    if need_new_rate:
        return "multirate-resampling"
    if rough_signal:
        return "fir-iir"
    if world_drifts:
        return "adaptive-filter"
    return "convolution-lti"

print(clinic(False, False, True))     # 毛刺单纯，环境稳定
print(clinic(True, False, True))      # 速率硬指标最先拦下
print(clinic(False, True, True))      # 又漂移又毛刺的双重病号
```

交换 `world_drifts` 与 `rough_signal` 两支的先后（漂移在前）后输出 fir-iir、multirate-resampling、adaptive-filter。原代码让「表面有毛刺」抢走了双重病号——毛刺只是症状，漂移才是病因，分诊永远先看病因。

**练习 2**：一个新的需求飘进来：「直播流要一边播放一边消除观众侧的电流声」。请用两问法给它挂号并说明理由。

<details>
<summary>点开查看逐步解答</summary>

第一问：要**改变**（消噪），而且观众设备五花八门、电流声路径人人不同——环境持续在变；第二问：若设备能提供电源频率附近的参考信号（多为 50 Hz 及其谐波），与干扰强相关、可学性好。结论：自适应滤波科（LMS 家族），必要时先用第九章工频经验限定搜索范围降负担。此题没有唯一科室属于正常现象——地图给出的是起手式，善后细节仍需工程裁量。
</details>

## 7. 选读：三条游览路线

<details>
<summary>选读 · 不同胃口的吃法</summary>

**工程速通线**（最快上手干活）：采样与混叠 → 卷积 → 冲激响应与差分方程 → Z 变换零极点 → FIR → 频谱泄漏 → 重采样。沿这条走完，滤波器设计与混叠事故排障已能独立应付。

**频谱纵深线**（分析偏执狂首选）：在速通线基础上补齐 FFT、窗函数、DCT 三课，理解快速算法、分辨率谈判与能量压缩的全部原理链，适合走向音频分析与数据科学。

**高阶漫游线**（研究向串门客）：完成速通线后直接跳乘小波、ICA、自适应三课，视野投向非平稳信号、盲源分离与在线学习，正好衔接后续各卷的机器学习地形。
</details>
