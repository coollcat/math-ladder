# IIR 滤波器设计：用反馈换陡峭

## 1. 从一个场景开始

你要做一个低通滤波器，要求"通带内平坦、截止后迅速掉下去"。

用 FIR（滑动平均）会很快发现一件事：**想让它陡，就必须长**。想要一个滚降足够陡的 FIR，抽头数可能要几百上千——延迟大、算得慢。

而同样指标的 IIR 滤波器，**只需要五六阶、十几个系数**。

代价是什么？这就是本课要算的账。

## 2. 直觉解释

FIR 只用**输入的历史**：

$$y[n] = b_0x[n] + b_1x[n-1] + \cdots + b_Mx[n-M]$$

IIR 多用了一样东西——**输出自己的历史**：

$$y[n] = \sum_k b_k\,x[n-k] \;-\; \sum_k a_k\,y[n-k]$$

输出又跑回来参与计算，这叫**反馈**。

反馈的好处是"记忆可以无限长"：FIR 的记忆长度就是抽头数，用完就忘；IIR 的输出被反复利用，一个阶数很小的系统也能有长长的冲激响应尾巴——**所以它陡、它省**。

但反馈是一把双刃剑：**如果反馈回路不稳，输出会越来越大直到爆掉**。FIR 从来不会有这个问题（它没有回路）。所以 IIR 设计的一半功夫，都花在保证稳定上。

## 3. 正式定义

**差分方程**（通用形式）：

$$\sum_{k=0}^{N}a_k\,y[n-k] = \sum_{k=0}^{M}b_k\,x[n-k], \qquad a_0 = 1$$

**系统函数**（对两边做 Z 变换）：

$$H(z) = \frac{b_0 + b_1z^{-1} + \cdots + b_Mz^{-M}}{1 + a_1z^{-1} + \cdots + a_Nz^{-N}} = \frac{B(z)}{A(z)}$$

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $b_k$ | 前馈系数 | 管零点（分子），决定"哪些频率被灭掉" |
| $a_k$ | 反馈系数 | 管极点（分母），**决定稳定与陡峭** |
| $N$ | 阶数 | 极点数，越高越陡 |
| $H(z)$ | 系统函数 | 输出的 Z 变换除以输入的 Z 变换 |
| $z_k$ | 极点 | $A(z)=0$ 的根，**必须都在单位圆内** |
| $\Omega_c$ | 截止频率 | 通带与阻带的分界 |

**双线性变换**（把模拟设计搬进数字）：

$$s = \frac{2}{T}\cdot\frac{1 - z^{-1}}{1 + z^{-1}}$$

它把 s 平面的左半平面**完整映射**到 z 平面的单位圆内——**模拟稳定 ⇒ 数字稳定**，这是这条路线最值钱的性质。

**Butterworth 幅频响应**（最平坦原型）：

$$|H(j\omega)|^2 = \frac{1}{1 + \left(\dfrac{\omega}{\omega_c}\right)^{2N}}$$

阶数 $N$ 决定滚降：远离截止频率处，衰减约 $-20N$ dB/十倍频。

## 4. 分步例题

**例 1（一阶 IIR 低通，手推一遍）**：取最简单的反馈形式

$$y[n] = (1-\alpha)x[n] + \alpha\,y[n-1], \qquad 0<\alpha<1$$

1. 极点位置：分母 $1 - \alpha z^{-1} = 0 \Rightarrow z = \alpha$；
2. 因 $0<\alpha<1$，极点在单位圆内——**稳定**；
3. 直流增益（令 $z=1$）：$H(1) = \dfrac{1-\alpha}{1-\alpha} = 1$——低频原样通过；
4. $\alpha$ 越接近 1，极点越靠近单位圆，**过渡带越陡但响应越慢**。

这就是"用反馈换陡峭"的最小例子：**一个乘加就做出了无限长的指数衰减记忆**。

**例 2（Butterworth 阶数估算）**：要求 $2\omega_c$ 处衰减至少 $40$ dB。

1. 由 $|H|^2 = \dfrac{1}{1+(\omega/\omega_c)^{2N}}$，取 $\omega = 2\omega_c$：$|H|^2 = \dfrac{1}{1+2^{2N}}$；
2. 换算 dB：$-10\log_{10}(1+2^{2N}) \le -40$，即 $1+2^{2N} \ge 10^4$；
3. $2^{2N} \ge 9999 \Rightarrow 2N \ge 13.3 \Rightarrow N \ge 6.65$；
4. 取 $N = 7$。

**7 阶 IIR 就够，而 FIR 要陡到同样程度通常要上百阶**——这个对比是 IIR 存在的全部理由。

**例 3（稳定性检查）**：二阶 IIR 的极点是 $z^2 + a_1z + a_2 = 0$ 的根。稳定的充要条件（Jury 判据的二维形式）：

$$|a_2| < 1, \qquad |a_1| < 1 + a_2$$

**设计完必须验这一步**——两个条件只要破一个，滤波器就会啸叫或溢出。

拖动 $n$ 从 1 到 8：曲线在 $\omega/\omega_c = 1$（截止点）都经过 $0.707$，但 $n$ 越大，向右掉得越快。**阶数就是陡峭度。**

现在跑一个真正的一阶 IIR，感受"反馈带来的长记忆"：

```python title="一阶 IIR 低通：一个乘加换来无限长记忆"
def iir_filter(x, alpha):
    """y[n] = (1-α)x[n] + α y[n-1]，反馈让它有无限长的冲激响应"""
    y = []
    prev = 0.0                    # 初始状态：上一次的输出
    for sample in x:
        cur = (1 - alpha) * sample + alpha * prev   # 反馈项 α·prev 就是记忆
        y.append(cur)
        prev = cur                # 把这次输出交给下一轮
    return y

# 冲激输入：只有一个 1，其余全是 0
impulse = [1.0] + [0.0] * 19
for alpha in [0.3, 0.8, 0.95]:
    h = iir_filter(impulse, alpha)
    tail = "  ".join(f"{v:.3f}" for v in h[:6])
    print(f"α = {alpha}：{tail} ...  （第 20 个样本 {h[19]:.6f}）")
```

看最后一列：$\alpha=0.3$ 时第 20 个样本几乎归零；$\alpha=0.95$ 时**还有 $0.377$** 没衰减完。**极点越靠近单位圆，尾巴越长、低频越陡，但响应越拖沓**——这就是设计的权衡。

再看 FIR 与 IIR 在同等"陡峭度"下的成本差：

```python title="同样陡度，FIR 要多少抽头？"
def fir_lowpass_ideal(cutoff, taps):
    """理想低通（sinc）加矩形窗：抽头越多越接近理想"""
    h = []
    center = (taps - 1) / 2
    for n in range(taps):
        x = n - center
        if abs(x) < 1e-9:
            h.append(2 * cutoff)
        else:
            h.append((2 * cutoff) * (__import__("math").sin(2 * 3.141592653589793 * cutoff * x) / (2 * 3.141592653589793 * cutoff * x)) * 2 * cutoff)
    return h

import math
for taps in [7, 31, 127]:
    h = fir_lowpass_ideal(0.2, taps)
    # 用第一个零点之后的旁瓣高度粗略衡量"陡不陡"
    peak = max(abs(v) for v in h[:taps // 2])
    print(f"FIR 抽头 {taps:>3}：主瓣峰值 {peak:.4f}")
print("而同样指标下 IIR 常只需 5~8 阶 —— 反馈把系数换成了计算量")
```

FIR 要靠增加抽头数才能靠近理想响应，IIR 用几个反馈系数就达到了——**代价是相位非线性**（各频率的延迟不同，波形会变形）。选谁，取决于你更在乎"省算力"还是"波形不变形"。

### 快问快答

```quiz
IIR 滤波器相比 FIR，最需要额外检查的是什么？
- 系数是否都是整数
- 极点是否都在单位圆内（稳定性） [*]
- 采样率是否足够高
? FIR 没有反馈回路，天然稳定；IIR 的反馈让系统可能发散，所以设计完成后必须检查极点模长小于 1。这也是双线性变换受欢迎的原因——它把稳定区域完整映射过来。
```

:::warning[常见误区]

**误区一**："IIR 什么都比 FIR 好，因为它省。" 
不是。IIR 的最大缺点是**相位非线性**——不同频率的信号延迟不一样，方波会被"拉歪"。通信、音频母带处理里常常宁可多花算力也要用线性相位的 FIR。**"省"和"保真"要按场景选。**

**误区二**："双线性变换只是换个变量，随便映射都行。" 
关键在一次"预畸变"：双线性变换会把模拟频率**非线性地压缩**到 $[0,\pi)$，所以设计前必须先把想要的数字截止频率**反算**成模拟频率（$\omega_a = \frac{2}{T}\tan\frac{\omega_d}{2}$）。漏了这一步，实际截止频率会明显偏移。

**误区三**："极点只要不在单位圆上就没事。" 
必须**严格在单位圆内**。极点在单位圆上（$|z|=1$）对应临界振荡——输出不衰减也不增长，理论上"勉强稳定"，工程上任何数值误差都会让它发散。设计要留裕度。

:::

**练习 2**：一个二阶 IIR 的反馈系数是 $a_1 = -1.2$、$a_2 = 0.5$。判断它是否稳定。

<details>
<summary>点开查看逐步解答</summary>

稳定条件：

$$|a_2| < 1 \quad\text{且}\quad |a_1| < 1 + a_2$$

代入：$|0.5| = 0.5 < 1$ ✓；$|-1.2| = 1.2$，而 $1 + a_2 = 1.5$，所以 $1.2 < 1.5$ ✓。

**两个条件都满足，滤波器稳定。**

再验证极点位置：$z^2 - 1.2z + 0.5 = 0$，判别式 $1.44 - 2 = -0.56 < 0$，共轭复根

$$z = \frac{1.2 \pm i\sqrt{0.56}}{2}, \qquad |z| = \sqrt{0.5} \approx 0.707 < 1 \;✓$$

极点模长 $0.707$，在单位圆内——与 Jury 判据一致。

```python
import math
a1, a2 = -1.2, 0.5
print("|a2| < 1 ?", abs(a2) < 1)
print("|a1| < 1+a2 ?", abs(a1) < 1 + a2)
# 极点模长：|z|² = a2（共轭复根时）
print("极点模长 =", math.sqrt(abs(a2)))
```
</details>

## 7. 选读：为什么双线性变换能保住稳定

<details>
<summary>选读 · 一次完整的平面映射</summary>

令 $z = e^{j\omega}$（单位圆上的点），代入双线性变换：

$$s = \frac{2}{T}\cdot\frac{1 - e^{-j\omega}}{1 + e^{-j\omega}}$$

分子分母同乘 $e^{j\omega/2}$：

$$s = \frac{2}{T}\cdot\frac{e^{j\omega/2} - e^{-j\omega/2}}{e^{j\omega/2} + e^{-j\omega/2}} = j\,\frac{2}{T}\tan\frac{\omega}{2}$$

**这是一个纯虚数**——也就是说，**z 平面的单位圆被映射成 s 平面的虚轴**。

- $|z| < 1$（单位圆内）$\Rightarrow$ $s$ 的实部为负（左半平面）；
- $|z| = 1$（单位圆上）$\Rightarrow$ $s$ 在虚轴上；
- $|z| > 1$ $\Rightarrow$ $s$ 右半平面。

**左半平面 ⇔ 单位圆内**，一一对应。所以只要模拟原型稳定（极点都在左半平面），变换后的数字滤波器必然稳定。

同时注意那个 $\tan(\omega/2)$：它是**非线性的**——模拟频率轴被"拉扯"着压进 $[0,\infty)$。这就是必须做预畸变的原因：想让数字滤波器在 $\omega_d$ 处截止，就得从 $\omega_a = \frac{2}{T}\tan(\omega_d/2)$ 出发去设计模拟原型。

**一个映射同时买到两样东西：稳定性保证 + 频率轴可预畸变校正。** 这就是双线性变换统治 IIR 设计半个世纪的原因。
</details>
