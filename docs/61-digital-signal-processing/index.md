## 实战挑战 · 一台自制脑电台的混叠诊断

> 场景说明：α 节律 8~13 Hz、临床脑电采样率下限（ACNS 指南要求常规脑电不低于 256 Hz）、假频折算公式「假频 = |采样率 − 真实频率|」均为公开文献与临床技术指南的标准表述。本题的头带参数为教学构造，情境原创。

你给实验室攒了一台单导联脑电头带，ADC 以 $f_s = 60$ Hz 直采，**忘了装抗混叠滤波器**。受试者闭眼放松，信号里实际混着三个成分：

- 2 Hz 的 δ 样慢波；
- 10 Hz 的 α 节律（闭眼枕区该有的那个）；
- 50 Hz 的市电工频残留（墙里电线漏进来的）。

数据导出后你看到一条奇怪的曲线：除了慢波，还有一条约 10 Hz 的「α 波」。请做诊断：

**(a)** 奈奎斯特频率是多少？打印它；
**(b)** 50 Hz 工频残留会伪装成多少赫兹的假频？打印它；
**(c)** 想让工频残留不混叠，采样率必须超过多少赫兹？打印这个门槛。

```exercise
# @title: 实战挑战：脑电台的混叠诊断
# @check: 30.0
# @check: 10
# @check: 100
# @hint: (a) 奈奎斯特 = 采样率的一半；(b) 50 超过了 (a) 的镜子，第一折叠区假频 = fs − f；(c) 定理要求采样率大于信号最高频率的两倍
fs = 60                   # 头带的采样率（Hz）
mains = 50                # 工频干扰的真实频率（Hz）

nyquist = fs              # ← 问题在这：镜子立在采样率的哪一处？
fake = mains % fs         # ← 问题在这：取余不是折叠
safe_rate = fs + mains    # ← 问题在这：定理说的是哪个数？
print(nyquist)
print(fake)
print(safe_rate)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 奈奎斯特频率 $f_N = f_s/2 = 60/2 = 30$ Hz——超过它的成分一律折叠。

**(b)** 50 Hz 落在第一折叠区（30~60），假频 $= |60 - 50| = 10$ Hz。灾难点在于：它与真实 α 节律同频！工频干扰顶替了 α 波的位置——你以为看到了放松的 α 节律，其实看的是墙里的市电。这正是临床设备必须先抗混叠滤波再采样的原因。

**(c)** $f_s > 2 \times 50 = 100$ Hz。工程上还要留余量给滤波器的缓坡滚降（ACNS 建议 256 Hz 起步）。

验证代码：

```python
print(60 / 2)      # 30.0
print(60 - 50)     # 10
print(2 * 50)      # 100
```
</details>

## 实战挑战 · 奈奎斯特频率是采样率的一半

奈奎斯特频率 $f_N = f_s/2$，是采样系统能忠实表示的最高频率。CD 音质采样率 $44100$ Hz，其奈奎斯特频率是 $22050$ Hz。下面这题忘了除以 2，修到输出 `22050`：

```exercise
# @title: 实战挑战：奈奎斯特频率是采样率的一半
# @check: 22050
# @hint: 奈奎斯特频率 = 采样率 ÷ 2，别忘了那个 2。
fs = 44100       # 采样率（Hz）
nyquist = fs     # ← 问题在这：漏了除以 2
print(nyquist)
```

<details>
<summary>点开查看逐步解答</summary>

奈奎斯特频率是采样率的一半：

```python
nyquist = fs / 2    # 44100 / 2
print(nyquist)      # 22050
```

改完：$f_N = 22050$ Hz——这也正是人耳听力的上限附近，CD 的 $44100$ Hz 采样率正是为此而选。初始代码输出 $44100$，等于把"采样率"和"可表示的最高频率"混为一谈。超过 $f_N$ 的信号会**混叠**成假低频，这是本章采样课的第一条铁律。

</details>
