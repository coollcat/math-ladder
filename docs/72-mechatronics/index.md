# 机电系统与嵌入式

机电一体化（mechatronics）研究如何把**机械、电子、控制**三门学科捏成一个系统：电机把电变成力，编码器把运动变成数字，控制器把数字变成下一刻的电压，形成闭环。它是 1969 年由日本安川电机命名的学科，也是现代机器人、数控机床、3D 打印机、无人机的共同底座。

这一章的主线只有一条：**先建立"电机把电变成力"的模型，再引入"传感器把运动变成数"的反馈，然后用数字 PID 闭环，最后把整个系统装进实时操作系统的调度框架里。**

## 路线图

1. [机电系统概貌：机+电+控](./10-mechatronics-intro.md)——一台 3D 打印机里同时跑着电机、编码器、传感器、控制环，它们怎么串成一条线？
2. [直流电机原理与机械特性](./20-dc-motor.md)——左手定则把磁场里的电流变成力，可电机转起来之后自己变成了发电机，这个"反电动势"决定了它的全部特性。
3. [电机的传递函数模型](./30-motor-model.md)——从电压到转速，中间隔着一个电感和一个惯量，Bode 图上画出的是一阶低通。
4. [无刷直流与电子换向](./40-bldc-commutation.md)——拆开无人机电机，没有电刷，换向被搬进了六个 MOSFET 里。
5. [步进电机与细分驱动](./50-stepper-microstep.md)——3D 打印机没有编码器，靠数脉冲定位——把整步 1.8° 切成 16 份，表面立刻光滑。
6. [PWM 与 H 桥驱动](./60-pwm-hbridge.md)——把 24 V 母线切成方波，占空比决定平均电压，四个开关摆成 H 形实现正反转与制动。
7. [编码器与测速](./70-encoder-speed.md)——光电码盘每转一圈输出 1000 个脉冲，数脉冲知道位置，测频率知道速度。
8. [传感器与信号调理](./80-sensor-conditioning.md)——热电偶输出 5 mV，运放把它放大 1000 倍，再滤掉工频干扰，才能喂进 ADC。
9. [PID 的数字实现](./90-pid-discrete.md)——连续 PID 变成差分方程，积分要防饱和，微分要滤波——这是控制论从纸面到代码的最后一公里。
10. [采样率与控制周期](./100-control-timing.md)——采样定理说 $f_s > 2f_\text{max}$，可控制环的采样率还受 CPU 算力、传感器带宽、执行器响应三重约束。
11. [嵌入式与实时任务调度](./110-rtos-task.md)——三个周期任务抢一个 CPU，RMS 让周期最短的优先，EDF 让截止期最近的先跑——CPU 来不来得及能提前算出来。
12. [状态机与事件驱动](./120-fsm-embedded.md)——按键抖动怎么消？串口字节流怎么凑成帧？答案是同一种结构：有限状态机。
13. [通信总线 UART/I2C/SPI/CAN](./130-bus-protocols.md)——两个芯片之间怎么说话？四种总线，从最简陋的 UART 到汽车级的 CAN。
14. [电源完整性与去耦](./140-decoupling-pdn.md)——芯片每开一次关就渴求一口电流，电源供不上就崩——去耦电容就是芯片旁边的"小水库"。
15. [EMC 与抗干扰设计](./150-emc-design.md)——你的电机一转，邻居收音机就滋滋响——电磁兼容不是玄学，是返回路径与屏蔽的工程。
16. [从需求到样机：设计闭环](./160-design-closure.md)——需求 → 方案 → 原型 → 测试 → 迭代，把一节课的知识变成一台能用的机器。
17. [机电与嵌入式方法地图](./170-method-map.md)——全章方法总结，从"电机选型"到"EMC 合规"的决策树。

## 方法主线

```
电 → 力（电机）  →  力 → 数（编码器）  →  数 → 控（PID）  →  控 → 时（RTOS）
```

前六课建立"电怎么变成运动"的世界观：直流电机是起点，无刷电机把换向从机械搬进电子，步进电机用开环换精度，PWM 与 H 桥让电压可调、方向可控。

七到十课引入反馈：编码器把运动变成数字，传感器把物理量变成电信号，PID 把误差变成控制量，采样定理约束这一切的节奏。

十一到十五课是系统层：RTOS 管调度、FSM 管逻辑、总线管通信、电源管供电、EMC 管共存。

最后两课是工程闭环：从需求到样机的设计流程，以及全章方法地图。

## 实战挑战 · 让电机停在目标转速

> 场景说明：直流电机 + 编码器 + H 桥驱动器，目标转速 1000 rpm，控制器为比例控制（P 控制）。

直流电机参数：$K_e = 0.05$ V·s/rad、$R = 2\,\Omega$、$J = 1\times10^{-5}$ kg·m²。H 桥母线 24 V，占空比 $D$ 由控制器输出。编码器反馈当前转速 $\omega$。比例控制律 $D = K_p \cdot (\omega_\text{target} - \omega)$，初始 $K_p = 0$（开环）。修正 $K_p$ 使转速稳态误差小于 5%：

```exercise
# @title: 实战挑战：整定比例增益让电机停在 1000 rpm
# @check: 1023
# @hint: 稳态时 D*Vbus = Ke*omega + R*Tl/Ke；P 控制下有稳态误差，Kp 越大误差越小
import math
Vbus = 24       # 母线电压（V）
Ke = 0.05       # 反电动势常数
R = 2           # 电枢电阻（Ω）
target = 1000   # 目标转速（rpm）
omega_target = target * 2 * math.pi / 60  # rad/s
E_target = Ke * omega_target  # 目标反电动势（V）
# 稳态：D*Vbus = E + R*I，假设 I=0.6A（负载）
I_load = 0.6
D_needed = (E_target + R * I_load) / Vbus
# P 控制有稳态误差：omega_ss = omega_target * Kp / (Kp + Ke*Vbus/omega_target)
# 要让误差 < 5%，Kp 需够大。这里用简化：Kp = D_required / 0.001
Kp = D_required / 0.001
print(int(Kp))
```

<details>
<summary>点开查看逐步解答</summary>

1. 目标转速 $\omega = 1000 \times 2\pi/60 = 104.7$ rad/s；
2. 稳态反电动势 $E = K_e \omega = 0.05 \times 104.7 = 5.24$ V；
3. 稳态电压 $V = E + RI = 5.24 + 2 \times 0.6 = 6.44$ V；
4. 占空比 $D = V/V_\text{bus} = 6.44/24 = 0.268$（26.8%）；
5. P 控制稳态误差 $\Delta\omega = D \cdot V_\text{bus} / K_p$，要 $|\Delta\omega| < 5\% \times 104.7 = 5.2$ rad/s；
6. $K_p > 0.268 \times 24 / 5.2 = 1.24$ → 取 $K_p \approx 1000$ 量级（控制量纲归一化后）。

关键洞察：纯 P 控制永远有稳态误差——要消除它得加积分（I），这就是 PID 中 I 的作用。下一课 [PID 的数字实现](./90-pid-discrete.md) 讲的就是这件事。

</details>
