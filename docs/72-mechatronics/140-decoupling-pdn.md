# 电源完整性与去耦

## 1. 从一个场景开始

MCU 从轻负载切到全速运算，电流在几个纳秒内从 20 mA 跳到 2 A。3.3 V 轨塌到 2.7 V：芯片复位、ADC 读数跳变、Flash 写入报废。稳压器就在 3 cm 外——为什么它救不了你？

因为稳压器"看见"变化并调整输出需要**微秒级**，而崩溃发生在**纳秒级**。这段时间差里，唯一能顶住电流的就是芯片电源脚旁边的那些小电容。它们的学名叫**去耦电容**，而整门学问叫**电源完整性（Power Integrity）**：让电源分配网络（PDN）在**每个频段**都表现得像个足够"硬"的电源。

## 2. 直觉解释

想象一栋楼的自来水系统。早上八点七楼集体开阀，水压瞬间掉的这一下：

- **水泵**（稳压器）要几秒后才能把压力顶回来——它管的是慢恢复；
- **楼顶水塔**（µF 级大电容）存了几分钟的水——它管的是分钟级波动；
- **你家水管旁的水锤罐**（nF 级陶瓷电容）只有一小口气——但反应是瞬间的，正好顶住"开阀那一下"。

三层各管一个时间尺度，谁也替代不了谁。这就是去耦设计"大电容管低频、小电容管高频"的分层逻辑。

还有一层更准确的视角：**电流突变是一个宽频信号**——快速边沿的谐波会铺开到很高的频率，这是傅里叶分析早就告诉过我们的老结论。稳压器在几百 kHz 以上阻抗越变越高，跟不上的频段就得靠电容顶上。所以"稳"的判据不是"存了多少电"，而是**从直流到几百 MHz，PDN 的阻抗都压在一条线以下**——这条线叫目标阻抗。

最后提醒一个坑：大电容和小电容不是和平共处——它们交界的地方会"打架"，顶出一个比谁都高的**反谐振峰**。峰值若超过目标阻抗，就是隐患，实验里你会亲手把它顶出来。

## 3. 正式定义

**目标阻抗**（允许纹波 $\Delta V$ 内承受动态电流 $\Delta I$）：

$$Z_{\text{tgt}} = \frac{\Delta V}{\Delta I}$$

**实际电容的阻抗**：真实电容是 $C$、等效串联电阻 $R_{\text{ESR}}$、等效串联电感 $L_{\text{ESL}}$ 的串联（第 68 章电容课与阻抗课的组合）：

$$|Z(\omega)| = \sqrt{R_{\text{ESR}}^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}$$

**自谐振频率**（感抗与容抗相等处，阻抗最低点）：

$$f_{\text{SRF}} = \frac{1}{2\pi\sqrt{LC}}$$

**电荷预算法**（时域视角，$n$ 颗并联分摊）：

$$C \ge \frac{\Delta I \cdot \Delta t}{\Delta V}$$

**反谐振峰**：大电容进入感性区后与小电容的容性区并联，等效为 $L_{\text{大}}$ 与 $C_{\text{小}}$ 的并联谐振，峰的频率约在

$$f_{\text{ar}} \approx \frac{1}{2\pi\sqrt{L_{\text{大}}\,C_{\text{小}}}}$$

峰高受两支路电阻（ESR）阻尼。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $\Delta V$ | 允许纹波 | 伏特 V | 电源轨允许的电压波动 |
| $\Delta I$ | 动态电流 | 安培 A | 负载电流的突变幅度 |
| $Z_{\text{tgt}}$ | 目标阻抗 | 欧姆 Ω | PDN 全频段必须低于的阻抗线 |
| $R_{\text{ESR}}$ | 等效串联电阻 | 欧姆 Ω | 电容的损耗，决定阻抗最低点的"谷底深度" |
| $L_{\text{ESL}}$ | 等效串联电感 | 亨利 H | 引线/焊盘/过孔带来的寄生电感 |
| $f_{\text{SRF}}$ | 自谐振频率 | 赫兹 Hz | 低于它呈容性、高于它呈感性的分界 |

## 4. 分步例题

**例**：MCU 允许 $\Delta V = 50$ mV，动态电流 $\Delta I = 2$ A，时钟沿带来的尖峰持续约 $\Delta t = 10$ ns。手头是 100 nF 陶瓷电容（ESL 约 3 nH）。做一遍去耦预算。

1. **目标阻抗**：$Z_{\text{tgt}} = 0.05/2 = 25$ mΩ——从直流到几百 MHz 都得压在这条线以下；
2. **电荷预算**：$C \ge \Delta I\,\Delta t/\Delta V = 2 \times 10^{-8}/0.05 = 400$ nF → **4 颗 100 nF**，分贴在几组电源脚旁（顺带把 ESR 也摊薄成 1/4）；
3. **自谐振频率**：$f_{\text{SRF}} = 1/(2\pi\sqrt{3\times10^{-9} \times 10^{-7}}) \approx 9.2$ MHz。低于 9.2 MHz 它是电容，高于它是"电感"——高频段它开始罢工；
4. **覆盖缺口**：9.2 MHz 以下交给 100 nF 还行，更低频段（电源纹波、负载缓变）交给一颗 10 µF 大电容；但两者交界处会顶出反谐振峰，**峰是否超过 25 mΩ，必须画阻抗曲线才能知道**——这正是接下来实验要干的事。

注意第 2 步与第 3 步的分工：电荷预算是**时域粗算**，告诉你"量够不够"；阻抗曲线是**频域细算**，告诉你"每个频段行不行"。两个视角互相印证，缺一不可。

图中红色虚线是目标阻抗（由 dv/di 算出），橙色曲线是电路引擎交流扫频算出的真实 PDN 阻抗，黄点标出反谐振峰。值得做的三件事：

- **把 esl 从 3 拖到 15**：高频段整条曲线翘起来——电容离电源脚太远（走线/过孔电感）时，容量再大高频也白搭。读数面板会直接提示"ESL 太大"；
- **切到"并 10 µF"**：低频段被大电容压下去，但大电容与小电容之间顶出一个**反谐振峰**——盯住黄点读数，看它是否越过红线。峰超标时的处方有三条：峰的位置补一级中间容值、加大 ESR 做阻尼、降 ESL；
- **把 dv 从 50 拖到 100**：红线整体抬高——放宽纹波要求，整个设计难度骤降。**指标松一寸，设计省一丈**，这就是上一章"指标分解"课程里说的权衡。

### 实验 2（python）：单颗电容的阻抗全景

```python title="一颗 100nF 陶瓷电容的一生"
import math                     # 数学库：sqrt / pi
C = 100e-9                      # 容量 100 nF
ESR = 0.020                     # 等效串联电阻 20 mΩ
ESL = 3e-9                      # 等效串联电感 3 nH
for f in (1e5, 1e6, 9.2e6, 1e8):        # 对数取样四个频点
    w = 2 * math.pi * f                 # 角频率 rad/s
    Z = math.sqrt(ESR**2 + (w*ESL - 1/(w*C))**2)  # 串联阻抗的模
    print("%8.2f MHz  |Z| = %9.1f mΩ" % (f/1e6, Z*1000))
f_srf = 1 / (2*math.pi*math.sqrt(ESL*C))
print("自谐振频率 ≈ %.1f MHz：谷底 |Z| = ESR = %.0f mΩ" % (f_srf/1e6, ESR*1000))
```

输出是一张"V 字账"：100 kHz 处 15.9 kΩ（纯容性，纯粹是容抗在扛），1 MHz 处 1.6 kΩ，9.2 MHz 处谷底 20 mΩ（ESR 定地板），100 MHz 处 1.9 Ω（已经变成电感，**罢工**）。所以"100 nF 去耦"这句话离开频率就是半句废话——**电容只在自谐振点附近是它自己**。

### 快问快答

```quiz
把允许纹波从 50 mV 放宽到 100 mV，动态电流仍是 2 A，目标阻抗和设计难度怎么变？
- 目标阻抗从 25 mΩ 变成 50 mΩ，达标更容易 [*]
- 目标阻抗不变，因为纹波和电流无关
- 目标阻抗变成 12.5 mΩ，设计更难
? 目标阻抗 = ΔV / ΔI = 100 mV / 2 A = 50 mΩ，比原来的 25 mΩ 宽松一倍。这就是「指标分解」的价值：芯片允许多大的纹波，直接决定 PDN 要花多少颗电容——指标松一寸，BOM 省一排。
```

:::warning[常见误区]

**误区一**：「一颗大电容包打天下。」
你以为 10 µF 比 100 nF"多 100 倍电"——但封装越大寄生电感越大，10 µF 的自谐振频率可能只有几百 kHz：**从那儿往上它就是一根电感**，对纳秒级电流跳变形同虚设。去耦必须分层：µF 级管低频，nF 级管高频，各守一段。

**误区二**：「去耦电容是给芯片储能的小电池。」
你以为它靠"存的电"撑住芯片——其实正解是**阻抗视角**：电容把电源脚与地之间的阻抗在某个频段压低，电流突变来时电压才不塌。储能视角只推出电荷预算法一个粗算式；阻抗视角才能解释为什么容值要错开、ESL 要压低、反谐振峰要盯住。**换视角，是你从"抄参考设计"到"会设计"的分水岭。**

**误区三**：「同值电容并得越多越好。」
你以为 8 颗比 4 颗稳——同值并联只是把阻抗曲线整体下移、ESR/ESL 摊薄，**反谐振峰的高度比例基本不变**，该超标的还是超标。正确做法是不同容值错开覆盖（容值差约一个量级），以及把 ESL 往死里压：贴得近、过孔短而粗、电源平面完整。数量堆过头，还吃 PCB 面积和装配良率。

:::

```exercise

# @check: 9.2
# @hint: f = 1/(2π·√(L·C))。L、C 都已是亨利/法拉，算出来就是 Hz；漏掉 2π 会大 6.28 倍
import math
L = 3e-9                      # ESL 3 nH
C = 100e-9                    # 容量 100 nF
f_MHz = 1 / math.sqrt(L * C) / 1e6    # ← 问题在这：漏了 2π 因子
print(round(f_MHz, 1))
```

**练习 2**：FPGA 内核轨 1.2 V 允许纹波 5%，动态电流 3 A，最快电流尖峰持续 8 ns。粗算需要多少去耦电荷？若用 47 nF 一颗，需要几颗？

<details>
<summary>点开查看逐步解答</summary>

1. 允许纹波：$\Delta V = 1.2 \times 0.05 = 0.06$ V；
2. 目标阻抗：$Z_{\text{tgt}} = 0.06/3 = 20$ mΩ；
3. 电荷预算：$C \ge \Delta I\,\Delta t/\Delta V = 3 \times 8\times10^{-9}/0.06 = 400$ nF；
4. 用 47 nF：$400/47 \approx 8.5$，取 **9~10 颗**，分布到各组电源脚；
5. 别忘了校核频段：47 nF 若 ESL 也是 3 nH，$f_{\text{SRF}} = 1/(2\pi\sqrt{3\times10^{-9}\times47\times10^{-9}}) \approx 13.4$ MHz——低于 FPGA 内核几百 MHz 的活动频段，**高频段还得靠更低 ESL 的封装与平面电容**。电荷预算只是第一道粗筛。

</details>

## 7. 选读：反谐振峰从哪里来

<details>
<summary>选读 · 两条阻抗曲线的"顶牛"</summary>

把大电容和小电容的阻抗各画一条曲线：小电容在自己的 $f_{\text{SRF}}$（比如 10 MHz）以上呈感性，阻抗随频率上升；大电容要到几百 kHz 以上才呈感性，所以**在 1~10 MHz 这一段它是"还没醒的电容"**，阻抗还在随频率下降。

两条曲线一交叉，并联电路就要出事。交叉点附近：大电容支路呈容性、阻抗 $Z_1 \approx 1/(\omega C_1)$，小电容支路也呈容性——此时两颗并联只是普通相加，曲线平平。真正的峰出现在**另一个交叉**：大电容已呈感性（$Z_1 \approx \omega L_1$），小电容仍呈容性（$Z_2 \approx 1/(\omega C_2)$）。并联总阻抗最大处，两条支路导纳抵消：

$$\frac{1}{\omega L_1} = \omega C_2 \quad\Longrightarrow\quad \omega = \frac{1}{\sqrt{L_1 C_2}}$$

这就是正文里 $f_{\text{ar}}$ 的来历：**大电容的电感和小电容的电容并联谐振**。峰的高度没有干净公式——它由两条支路的电阻（ESR）阻尼决定，ESR 越小峰越尖。这也解释了工程经验"容值错开一个数量级"：错得开，两条曲线的交叉点就被推离彼此的工作区，峰被压在目标阻抗以下。

真实 PCB 上还有第三、第四层（平面电容、封装内电容），每两层交界都可能顶一个小峰——所以电源完整性工程师的日常不是"选多大的电容"，而是**扫一条完整的阻抗曲线，把每个峰摁到红线以下**。

</details>
