# 无刷直流与电子换向

## 1. 从一个场景开始

拆开一颗无人机电机：三根线、一圈绕组、一块贴在转子上的磁铁——**没有电刷，没有换向器**。可直流电机靠电刷换向才能连续转，没有它，转子转到一半磁场就对齐卡死了。

再看电调（ESC）：里面是六个 MOSFET。答案就在这——**换向的活没有消失，只是从机械零件搬进了晶体管**。谁来告诉晶体管什么时候切？切早切晚会怎样？这就是本课的全部内容。

## 2. 直觉解释

先看有刷电机为什么能转：电刷+换向器是一套**机械自动开关**，转子转到哪，它就把电流方向换到哪，保证磁场永远"领先转子一点"。磁铁永远在追一个追不上的磁场——这就是转动的全部秘密。

无刷电机把这套开关换成六个晶体管，但晶体管没有手指、看不见转子，**必须有人告诉它转子的位置**：要么装霍尔传感器，要么从绕组里感应的反电动势里"听"出来。这就是无刷电机三根线之外还要多几根信号线的原因。

换向怎么换？最朴素的方案叫**六步换向**：三相绕组轮流"两通一悬空"——A 进 B 出、A 进 C 出、B 进 C 出……共六种组合。每切一步，定子合成磁场**跳 60°**。转子在后面追，永远差着一截——这个"差角"叫**转矩角**：差 90° 时拉力最足（正弦顶点），差到 0° 就是两块磁铁正对着顶牛，差过 90° 拉力变成拽后腿。切换太慢或负载太重，转子跟不上、差角越拉越大，一旦过 90°，转矩反向——这就是**失步**，电机一声哀鸣停摆。

## 3. 正式定义

**六步换向表**（+1 电流流入该相，−1 流出，0 悬空）：

| 步 | A | B | C | 记法 |
| --- | --- | --- | --- | --- |
| 1 | +1 | −1 | 0 | A+ B− |
| 2 | +1 | 0 | −1 | A+ C− |
| 3 | 0 | +1 | −1 | B+ C− |
| 4 | −1 | +1 | 0 | B+ A− |
| 5 | −1 | 0 | +1 | C+ A− |
| 6 | 0 | −1 | +1 | C+ B− |

每步定子合成磁场矢量跳转 **60° 电角度**；走完六步正好 360° 电角度（一个电周期）。

**电磁转矩**由转矩角决定：

$$T = T_{max}\sin\delta$$

其中 $\delta$ 为定子磁场领先转子 N 极的角度。$\delta = 90^\circ$ 转矩最大；$|\delta| > 90^\circ$ 转矩反向，转子被拽着倒转——失步。及时换向把 $\delta$ 控制在 $30^\circ \sim 90^\circ$ 之间摆动。

**换向步率与转速**（$p$ 为极对数，$n$ 为 rpm）：

$$f_{step} = 6p\,\frac{n}{60}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $\delta$ | 转矩角 | rad 或 ° | 定子磁场超前转子的角 |
| $T_{max}$ | 最大电磁转矩 | N·m | $\delta = 90^\circ$ 时的转矩 |
| $p$ | 极对数 | — | 转子上 N-S 磁极的对数 |
| $f_{step}$ | 换向步率 | 步/秒 | 每秒执行六步表的步数 |

## 4. 分步例题

**例**：一颗 $p = 7$（7 对极）的无人机电机，转速 6000 rpm。(a) 电频率与换向步率；(b) 每步留给控制器的时间；(c) $\delta = 60^\circ$ 时的转矩是最大值的多少？

1. **电频率**：$f_e = p \cdot n/60 = 7 \times 100 = 700$ Hz——转子每秒转 100 圈，磁场每圈扫过 7 个电周期；
2. **换向步率**：$f_{step} = 6 \times 700 = 4200$ 步/秒；
3. **每步时间**：$1/4200 \approx 238\ \mu s$——电调必须在 238 微秒内完成一次采样、判断、开关切换，这就是电调主频动辄几十 MHz 的原因；
4. **转矩**：$\sin 60^\circ = 0.866$，约为最大转矩的 87%。

**例 (b) 的反面**：同一颗电机若换向逻辑固定在每秒 100 步（以为转子只有一对极），定子磁场转速只够 857 rpm——转子被磁场甩下，$\delta$ 一路增大越过 90°，**失步**。极对数写错，电机根本转不起来。

### 实验 1（lab）：六步换向、转矩角与失步

```lab

  "type": "bldc-commutation",

  "sliders": [

    { "name": "Tl", "label": "负载转矩（N·m）", "min": 0, "max": 0.1, "step": 0.005, "value": 0.03 }
  ]
}
```

画布左边是三相绕组、定子合成磁场（紫虚线）与转子永磁体，右边是六步换向表，底部是转矩指示条。四件事值得做：

- **点"单步换向"**：一格格看换向表怎么走、合成磁场怎么跳 60°、转矩角怎么变——六步看懂，无刷电机就懂了一半；
- **拖高 rate**：转速跟着涨，转矩角稳定在 30°~90° 区间摆动；继续拖——某一下转子突然跟不上，转矩角越过 90°，读数栏亮出"失步"，转速崩塌；
- **拖大 Tl**：同样的换向频率，负载一重就失步——**能带多重的负载，取决于转矩角能维持在多大**；
- **盯转矩指示条**：它的长短就是 $\sin\delta$——换向刚发生时最长（90° 附近），转子追上来后变短（30° 附近），如此锯齿般起伏，这就是六步换向的转矩纹波。

### 实验 2（python）：转矩角表与换向预算

```python
import math                          # 数学库：提供 sin、radians

Tmax = 0.12                          # 最大电磁转矩 N·m
print("转矩角 δ   转矩 T")
for deg in [0, 30, 60, 90, 120]:     # 遍历几个典型转矩角
    T = Tmax * math.sin(math.radians(deg))
    print(f"{deg:4d}°   {T:.3f} N·m   {'(反向，已失步)' if deg > 90 else ''}")

p, n = 7, 6000                       # 7 对极，6000 rpm
f_e = p * n / 60                     # 电频率 Hz
f_step = 6 * f_e                     # 换向步率
print(f"\n电频率 {f_e:.0f} Hz，换向步率 {f_step:.0f} 步/秒")
print(f"每步预算 {1e6 / f_step:.0f} 微秒")
```

前半张表里 120° 那行转矩是负的——**转矩角过 90° 不只是"变小"，是变号**，磁场从推着转子变成拽着转子，这就是失步的数学面目。后半段算出 238 微秒的换向预算：真实电调用硬件比较器 + 定时器在几微秒内响应，软件循环根本来不及。

### 快问快答

```quiz
六步换向正常运转时，转矩角被控制在哪个区间内摆动？
- 0 度到 30 度
- 30 度到 90 度 [*]
- 90 度到 120 度
- 恒定在 90 度
? 每次换向磁场跳 60°，若在转矩角 30 度时切换，则跳到 90 度后转子逐渐追回到 30 度。区间太小则转矩不足，越出 90 度则失步——六步方案天生带着这根锯齿形的转矩纹波。
```

:::warning[常见误区]

**误区一**："没有电刷就没有转速上限。"
你以为去掉机械换向就一劳永逸——其实上限换了个地方：换向必须赶在转矩角越界**之前**发生，转速越高每步时间越短（例题里 238 µs），同时反电动势逼近母线电压、电流压不进去、转矩撑不住负载。机械极限变成了**时序预算 + 电压余量**的极限，一样存在。

**误区二**："六步换向的转矩是平滑的。"
你以为通电就平稳出力——其实电流是方波、磁场每步跳 60°，转矩随 $\sin\delta$ 锯齿般起伏，这正是无刷电机低速"咔咔"抖、云台用它嗡嗡响的原因。要平滑，得让磁场连续旋转而不是跳步——那就是 FOC（磁场定向控制），用正弦电流代替方波，思路与本章步进细分一脉相承。

**误区三**："无刷电机必须装霍尔传感器才知道转子位置。"
你以为位置反馈非传感器不可——其实转子一转，悬空那相绕组里就感应出反电动势，它的过零点就是转子位置的免费情报（**无感换向**）。代价是低速和启动时反电动势太小听不见，得靠强制开环"盲启动"。航模电调几乎全是无感方案。

:::

```exercise

# @check: 4200
# @hint: rpm 是「每分钟转数」，先除以 60 变成每秒转数；每圈对应 p 个电周期，每个电周期走 6 步
p = 7
n_rpm = 6000
f_step = 6 * p * n_rpm    # ← 问题在这：n_rpm 是每分钟的转数，没换成每秒
print(f_step)
```

**练习 2**：同一颗电机（$T_{max} = 0.12$ N·m）带 $0.06$ N·m 的负载，换向及时（$\delta$ 摆动于 30°~90°）。最坏时刻转矩角 30°，电磁转矩还剩多少？负载有没有被顶住？

<details>
<summary>点开查看逐步解答</summary>

1. $\delta = 30^\circ$ 时 $T = 0.12 \times \sin 30^\circ = 0.06$ N·m；
2. 恰好等于负载 0.06 N·m——**压线顶住**；
3. 也就是说这颗电机带 0.06 N·m 已经把换向区间用满：负载再大一点，30° 处转矩不够，转子被拖到 $\delta < 30^\circ$，下一轮换向角摆动区间整体下移，最终失步；
4. 工程结论：**按 $\sin 30^\circ = 0.5$ 折算，六步换向的可用转矩约取最大转矩的一半**——选电机要按这个折扣，而不是按 $T_{max}$。

顺带看清"失步"的机制：不是转矩突然消失，而是转矩角失去控制地滑走——转子减速、$\delta$ 继续增大、过 90° 后转矩反向进一步减速，正反馈崩塌。这与同步电机"牵出转矩"的失步是同一件事。

</details>

## 7. 选读：合成磁场为什么每步跳 60°

<details>
<summary>选读 · 矢量叠加一眼算出</summary>

三相绕组的磁场沿各自的**轴线**方向，A、B、C 轴线互差 120°。以第 1 步（A 进 B 出，C 悬空）为例，取 A 轴为 0°，则：

- A 相磁势：$+1 \times(\cos 0^\circ,\ \sin 0^\circ) = (1,\ 0)$；
- B 相磁势：$-1 \times(\cos 120^\circ,\ \sin 120^\circ) = (0.5,\ -0.866)$（电流反向，磁势也反向）。

合成矢量 $= (1.5,\ -0.866)$，模为 $\sqrt{1.5^2 + 0.866^2} = \sqrt{3} \approx 1.73$，方向 $\arctan(-0.866/1.5) = -30^\circ$。

对六步逐一做这个加法，会得到六个模长全为 $\sqrt{3}$、方向依次相差 60° 的矢量——**磁场的大小不变，只有方向在跳**。这就是六步换向的全部几何：用一个旋转的、幅值恒定的"电子磁铁"拖着转子走。

$\sqrt{3}$ 这个数还藏着六步方案的一个小账本：绕组只发挥了 $\sqrt{3}/\sqrt{3}$……换个说法——若三相同时通电并按正弦分配，合成矢量模可达 $3/2$，比六步的 $\sqrt{3} \approx 1.732$ 大 $1.5/1.732 \approx 0.866$ 倍？不对，正弦三相的合成是 $3/2 = 1.5$，反而**小**于 $\sqrt{3}$——但 FOC 赢在连续旋转、无纹波，赢的从来不是幅值而是平滑。顺带地，把 60° 的跳步改成 $360^\circ/N$ 的微步，就是下一课步进电机细分的思路：**同一种"追磁场"的物理，两种工程实现**。

</details>
