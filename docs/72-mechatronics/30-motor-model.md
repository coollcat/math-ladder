# 电机的传递函数模型

## 1. 从一个场景开始

上一课的 n–T 曲线能告诉你电机**最终**转多快，但机器人每个动作都在加速、减速——设计速度环之前，控制器必须先知道：我改一下电压，转速要**多久**才跟上来？50 毫秒还是 5 毫秒，直接决定了控制周期怎么选、增益敢开多大。

回答这个问题的工具你已经学过了：传递函数与 Bode 图。现在只差最后一步——把电机从"两条代数式"升级成"两条微分方程"。

## 2. 直觉解释

上一课的模型里有两个量是"瞬间就位"的：电压一变，电流立刻变；电流一变，转速立刻变。现实里各有一只手拦着它们：

- **电感**拦电流：电流是磁场里的"动量"，就像第 68 章说的，它有惯性，电压突变时电流只能爬着走——快慢由电气时间常数 $\tau_e = L/R$ 决定；
- **惯量**拦转速：转子有质量，转矩多余了它才加速，就像推车——快慢由机械时间常数 $\tau_m$ 决定。

于是电机是一个**双惯性系统**：电压先过电感的"关卡"变成电流，电流变成转矩，再过惯量的"关卡"变成转速。两个关卡串在一起，二阶系统就出来了。

但这两个关卡**通常差得很远**：小型电机的 $\tau_e$ 常在 1 ms 量级，$\tau_m$ 常在几十 ms 量级。爬坡时，快的关卡几乎是瞬间过完，全程都耗在慢的关卡上——所以很多场合干脆把电感忽略，模型降回一阶。**什么时候能降阶、什么时候不能**，正是这一课要练的判断。

## 3. 正式定义

**电枢回路方程**（KVL，含电感压降）与**转子动力学方程**（牛顿第二定律的转动版）：

$$L\frac{dI}{dt} = V - RI - K_e\omega$$

$$J\frac{d\omega}{dt} = K_t I - B\omega - T_L$$

零初始条件下做拉普拉斯变换，消去 $I(s)$，得电压到转速的**传递函数**：

$$\frac{\Omega(s)}{V(s)} = \frac{K_t}{(Ls + R)(Js + B) + K_tK_e}$$

分母是 $s$ 的二次多项式——二阶系统。当 $\tau_e \ll \tau_m$ 时，它近似因式分解为两个实极点，对应两个时间常数：

$$\tau_e = \frac{L}{R}, \qquad \tau_m = \frac{JR}{K_tK_e + BR}$$

稳态增益（$s \to 0$）：

$$\frac{\omega(\infty)}{V} = \frac{K_t}{K_tK_e + BR}$$

**Bode 图**上这是一条低通曲线：低频平直，先在机械极点 $1/(2\pi\tau_m)$ 处拐下 −20 dB/dec，再在电气极点 $1/(2\pi\tau_e)$ 处拐成 −40 dB/dec。**−3 dB 带宽由慢的那个极点决定**——控制指令的频率成分超过它，电机就跟不上了。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $J$ | 转动惯量 | kg·m² | 转子（含折算负载）的惯性 |
| $B$ | 粘性阻尼系数 | N·m·s/rad | 转速成正比的阻力 |
| $L$ | 电枢电感 | H | 绕组的电流惯性 |
| $\tau_e$ | 电气时间常数 | s | 电流跟随电压的快慢 |
| $\tau_m$ | 机械时间常数 | s | 转速跟随转矩的快慢 |
| $T_L$ | 负载转矩 | N·m | 外部阻力矩 |

## 4. 分步例题

**例**：$J = 5\times10^{-5}$ kg·m²，$B = 2\times10^{-4}$ N·m·s/rad，$R = 2$ Ω，$L = 2$ mH，$K_t = K_e = 0.05$，阶跃 $V: 0 \to 12$ V。

1. **电气时间常数**：$\tau_e = L/R = 2\times10^{-3}/2 = 1$ ms；
2. **机械时间常数**：$\tau_m = \dfrac{JR}{K_tK_e + BR} = \dfrac{10^{-4}}{2.5\times10^{-3} + 4\times10^{-4}} = \dfrac{10^{-4}}{2.9\times10^{-3}} \approx 34.5$ ms；
3. **两个极点相距约 35 倍**——判据：两实根分离，系统过阻尼，**阶跃响应没有超调**；
4. **稳态转速**：$\omega_\infty = \dfrac{K_t V}{K_tK_e + BR} = \dfrac{0.6}{2.9\times10^{-3}} \approx 207$ rad/s $\approx 1977$ rpm；
5. **忽略 L 行不行**：电流只在头几毫秒"迟到"，对 30 ms 尺度的转速爬升影响不到 3%——**电压→转速通道可以降一阶**；但若做电流环（第 68 章运放课里的带宽思维），$\tau_e$ 就是主角，不能丢。

第 3 步的结论值得划线：**"二阶"不等于"振荡"**。只有当两个极点靠近（复数化）才会振；电机这对极点天然分居两处，所以直流电机的阶跃响应老老实实地爬坡。

左图是 RK4 积分出的阶跃响应（带播放游标），右图是同一模型的 Bode 幅频，绿线紫线标出两个极点。三件事值得做：

- **拖大 J（比如到 30）**：机械极点左移，上升时间从 75 ms 拖到半秒——"负载惯量直接吃掉带宽"，这是伺服选型时惯量匹配的由来；
- **拖大 L（到 20 mH）**：电气极点向机械极点靠拢，两极点接近时曲线开始出现过冲——**亲手把一个过阻尼系统逼成欠阻尼**；
- **切换"一阶（忽略 L）"**：阶跃响应几乎重叠，但 Bode 图高频段少了一拐——降阶省的是模型复杂度，丢的是高频真相。

### 实验 2（python）：自己积分这对微分方程

```python title="前向欧拉积分电机二阶模型"
J, B, R, L, Kt, Ke, V = 5e-5, 2e-4, 2.0, 2e-3, 0.05, 0.05, 12.0
tau_e = L / R                                   # 电气时间常数
tau_m = J * R / (Kt * Ke + B * R)               # 机械时间常数
wss = Kt * V / (Kt * Ke + B * R)                # 稳态角速度

dt = 1e-4                                       # 步长 0.1 ms（远小于 tau_e）
w, I = 0.0, 0.0                                 # 初始静止、无电流
t10 = t90 = None                                # 10% 与 90% 时刻

for k in range(1, 3001):                        # 积分 0.3 s
    dI = (V - R * I - Ke * w) / L               # 电气方程右端
    dw = (Kt * I - B * w) / J                   # 机械方程右端（空载）
    I += dI * dt                                # 欧拉推进一步
    w += dw * dt
    if t10 is None and w >= 0.1 * wss:
        t10 = k * dt
    if t90 is None and w >= 0.9 * wss:
        t90 = k * dt

print(f"电气时间常数 tau_e = {tau_e * 1000:.1f} ms")
print(f"机械时间常数 tau_m = {tau_m * 1000:.1f} ms")
print(f"稳态转速 = {wss:.1f} rad/s = {wss * 60 / (2 * 3.14159265):.0f} rpm")
print(f"10-90% 上升时间 = {(t90 - t10) * 1000:.1f} ms")
```

打印结果：$\tau_e = 1.0$ ms、$\tau_m = 34.5$ ms、上升时间约 75 ms——大约是 $2.2\,\tau_m$，正是一阶系统的标准关系。慢极点说了算，快极点只负责开头一小段。想验证"降阶合理性"，把 `L` 改成 `0.2e-3` 再跑：上升时间几乎不动。

```quiz
两个时间常数相差很远的二阶系统，其阶跃响应的上升时间主要由谁决定？

```

:::warning[常见误区]

**误区一**："二阶系统一定振荡、一定超调。"
你以为 $s$ 的二次多项式等于振铃——其实只有**共轭复数极点**才振荡。电机这里两个实极点相距 35 倍，响应是老实的指数爬坡（过阻尼）。把 Bode 图上"−40 dB/dec 就会振"背成口诀，会漏掉一半真相：**斜率只说明有两个极点，振不振要看它们靠多近**。

**误区二**："电感才 2 mH，永远可以忽略。"
你在只看电压→转速通道——确实可以。但设计**电流环**时（现代伺服的标配，带宽几百 Hz 到几 kHz），电流就是被控量，$\tau_e = 1$ ms 决定了电流环带宽的物理上限。同一个元件，在两个通道里身份天差地别。**"能不能忽略"永远要问：相对于谁、在哪个频段**。

**误区三**："传递函数是拟合出来的曲线，换个电机就得重测。"
你以为它是黑盒建模——其实它是从 KVL 和牛顿第二定律**推**出来的：参数 $R$、$L$、$K_t$、$J$ 个个有物理含义、个个可独立测量。换一颗电机，改四个数，模型结构一行不动。物理模型与数据拟合的区别在于：前者敢外推，后者只敢内插。

:::

**练习 2**：同一台电机，若负载经减速器折算后惯量变为原来的 4 倍（$J = 2\times10^{-4}$ kg·m²），机械极点频率变为多少？对速度环设计意味着什么？

<details>
<summary>点开查看逐步解答</summary>

1. $\tau_m = \dfrac{2\times10^{-4} \times 2}{2.9\times10^{-3}} \approx 138$ ms（原来 34.5 ms 的 4 倍）；
2. 机械极点频率 $f_m = \dfrac{1}{2\pi\tau_m} = \dfrac{1}{2\pi \times 0.138} \approx 1.15$ Hz（原来约 4.6 Hz）；
3. −3 dB 带宽掉到 1 Hz 出头——**控制周期 1 ms 的循环里，对象自己 800 多 ms 才爬完**，增益稍大就震荡；
4. 工程对策：要么换大电机（降折算惯量比），要么把减速比往"惯量匹配"方向调，要么接受低带宽。

注意惯量是**从负载折算到电机轴**的：减速比 $i$ 下折算惯量除以 $i^2$——这就是为什么同样负载，加一级 10:1 减速，折算惯量就缩成百分之一。惯量匹配的经典结论（负载折算惯量在转子惯量的 1~10 倍之间）全部来自这道算术。

</details>

## 7. 选读：从方程组到传递函数

<details>
<summary>选读 · 手推分母，顺便看负载通道</summary>

对两条微分方程做拉普拉斯变换（零初始条件）：

$$Ls\,I(s) = V(s) - R\,I(s) - K_e\Omega(s)$$

$$Js\,\Omega(s) = K_t I(s) - B\Omega(s) - T_L(s)$$

第一式解出 $I(s) = \dfrac{V(s) - K_e\Omega(s)}{Ls + R}$，代入第二式：

$$(Js + B)(Ls + R)\,\Omega(s) = K_t\bigl(V(s) - K_e\Omega(s)\bigr) - (Ls + R)\,T_L(s)$$

移项合并即得**电压通道**：

$$\frac{\Omega(s)}{V(s)} = \frac{K_t}{(Ls + R)(Js + B) + K_tK_e}$$

以及**负载通道**：

$$\frac{\Omega(s)}{T_L(s)} = \frac{-(Ls + R)}{(Ls + R)(Js + B) + K_tK_e}$$

两个通道共享同一个分母——这叫**特征多项式**，系统的"性格"全在它身上。负载通道稳态增益为 $-\dfrac{R}{K_tK_e + BR}$：负载每加 1 N·m，转速跌多少，正是上一课机械特性那条直线的斜率。**频域模型与时域静态曲线，在这里严丝合缝地对上了**。至于 $K_tK_e$ 这一项为什么出现在"机械"的时间常数里：它是反电动势提供的电磁阻尼——转速一高，反电动势压电流，等效于给转子加了阻力。电机自己给自己 damping，这是它最优雅的地方。

</details>
