# 直流电机原理与机械特性

## 1. 从一个场景开始

无人机电机商铺页写着：KV 值 2450、空载电流 0.6 A、最大电流 22 A。同一颗电机，空载时电流不到 1 A，桨叶一卡死，电流瞬间冲到二十几安，电池线发烫，几分钟就要冒烟。

为什么电流会自己"看负载下菜"？答案是电机里藏着一个**自带的发电机**，转得越快，它反着顶电源顶得越狠。理解了这个"内鬼"，电机的一切选型参数——空载转速、堵转转矩、效率曲线——就全变成了三条公式。

## 2. 直觉解释

通电导线在磁场里受力（左手定则），这是电动机的一半；导线在磁场里**运动**会感应出电动势，这是发电机的另一半。直流电机里这两件事**同时发生**：电流推着转子转，转子一转就切割磁线、产生一个方向相反的电动势。

这个反电动势像一条**越转越紧的橡皮筋**：

- 刚上电时转子没转，反电动势为零，电源电压全砸在电阻上——电流最猛、转矩最大，转得越来越快；
- 转速升高，反电动势长大，把"留给电阻的电压"一点点抢回去——电流变小、转矩变小；
- 直到转矩刚好等于负载，转速就停在这里——**电机自己找到了自己的工作点**，不用任何人调节。

所以"负载变大转速掉、电流涨"不是电机的缺陷，而是这条自平衡链条的必然：负载大 → 转速被拖低 → 反电动势变小 → 电流变大 → 转矩顶住负载。一张 n–T 曲线（转速随转矩下滑的直线）就是这条链条的静态照片。

## 3. 正式定义

**直流电机三方程**（电枢回路 + 两条机电变换）：

$$T_e = K_t I \qquad E = K_e \omega \qquad V = E + IR$$

稳态时电磁转矩与负载转矩平衡（$T_e = T_L$），代入消去 $I$ 与 $E$，得**机械特性**：

$$\omega = \frac{V}{K_e} - \frac{R}{K_t K_e}\, T_L$$

这是横轴截距与纵轴截距都好记的**一条直线**：

- **理想空载转速** $\omega_0 = \dfrac{V}{K_e}$（$T_L = 0$，实际因摩擦略低）；
- **堵转转矩** $T_{st} = \dfrac{K_t V}{R}$（$\omega = 0$，此时电流 $I_{st} = V/R$ 不受反电动势任何限制）；
- 斜率 $\dfrac{R}{K_t K_e}$：**电阻越大，特性越"软"**（负载一压转速就掉）。

**效率**：

$$\eta = \frac{T_L \omega}{VI} = \frac{\text{机械输出功率}}{\text{电输入功率}}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $T_e$ | 电磁转矩 | N·m | 电流产生的转矩 |
| $K_t$ | 转矩常数 | N·m/A | 每安培电流换多少转矩 |
| $E$ | 反电动势 | V | 转动自己感应出的电压 |
| $K_e$ | 反电动势常数 | V·s/rad | 每rad/s转速感应多少伏 |
| $\omega$ | 机械角速度 | rad/s | $1\ \text{rad/s} = \dfrac{60}{2\pi}$ rpm |
| $R$ | 电枢电阻 | Ω | 绕组铜线电阻 |
| $V$ | 电枢电压 | V | 电源加在电机两端的电压 |

国际单位制下 $K_t$ 与 $K_e$ **数值相等**（见选读的证明），实验台里也取同一值。

## 4. 分步例题

**例**：$V = 12$ V，$R = 2$ Ω，$K_t = K_e = 0.05$，负载转矩 $T_L = 0.08$ N·m。求稳态电流、转速与效率。

1. **稳态电流**：$I = T_L / K_t = 0.08 / 0.05 = 1.6$ A；
2. **反电动势**：$E = V - IR = 12 - 1.6 \times 2 = 8.8$ V——电源电压的 73% 被反电动势"顶"回去了；
3. **转速**：$\omega = E / K_e = 8.8 / 0.05 = 176$ rad/s $\approx 1681$ rpm；
4. **对照两个极端**：理想空载 $\omega_0 = 12/0.05 = 240$ rad/s（2292 rpm），堵转转矩 $T_{st} = 0.05 \times 12 / 2 = 0.3$ N·m（堵转电流 6 A）；
5. **效率**：$\eta = \dfrac{0.08 \times 176}{12 \times 1.6} = \dfrac{14.08}{19.2} \approx 73\%$。

第 2 步那个 73% 值得盯一眼：反电动势"吃掉"的电压不是浪费，它乘上电流恰好等于机械输出功率——**反电动势是电能变成机械能的那扇门**（证明在选读）。

## 5. 动手实验

### 实验 1（lab）：转子受力 + n–T 曲线上的工作点

```lab

  "type": "dc-motor",

  "sliders": [
    { "name": "V", "label": "电枢电压 V", "min": 0, "max": 48, "step": 0.5, "value": 12 },
    { "name": "Tl", "label": "负载转矩", "min": 0, "max": 0.4, "step": 0.005, "value": 0.08 },
    { "name": "R", "label": "电枢电阻 R", "min": 0.2, "max": 8, "step": 0.1, "value": 2 },
    { "name": "Ke", "label": "电机常数 Ke=Kt", "min": 0.01, "max": 0.2, "step": 0.005, "value": 0.05 }
  ]
}
```

左边是转子在磁场里受力的动画（导体一侧 ⊗ 进纸面、一侧 ⊙ 出纸面，受力箭头长短随电流变），右边是 n–T 特性直线与红色工作点。三件事值得做：

- **拖大 Tl**：工作点沿直线左下滑，读数栏里电流涨、反电动势占电压的百分比降——把 Tl 拖过 0.3，工作点贴到横轴，读数栏亮出"已堵转"，此时电流就是纯 $V/R$；
- **拖大 R**：直线变陡（特性变软）——同样负载下转速掉得更狠，这就是"电源线要够粗"的物理原因；
- **拖 V**：整条直线**平行上移**，斜率不变——调速不改硬度，这句话是后面 PWM 调速的理论依据。

### 实验 2（python）：沿机械特性扫一遍，找最大功率点

```python title="机械特性扫描：转矩、转速与输出功率"
V, R, Kt, Ke = 12.0, 2.0, 0.05, 0.05    # 电压、电阻、两个电机常数（SI 下相等）
Tst = Kt * V / R                        # 堵转转矩
w0 = V / Ke                             # 理想空载角速度
import math                             # 数学库：提供 pi

print(f"理想空载 {w0 * 60 / (2 * math.pi):.0f} rpm，堵转转矩 {Tst:.3f} N·m")
best = (0.0, 0.0)
for i in range(11):                     # 转矩从 0 扫到堵转
    T = Tst * i / 10
    w = (V - T * R / Kt) / Ke           # 机械特性上的转速
    P = T * w                           # 机械输出功率
    if P > best[1]:
        best = (T, P)
    print(f"T={T:.3f} N·m  n={w * 60 / (2 * math.pi):5.0f} rpm  P={P:5.2f} W")

print(f"最大功率 {best[1]:.2f} W 出现在 T = {best[0]:.3f} N·m（堵转转矩的一半）")
```

跑完看最后两行：最大功率出现在**堵转转矩的一半**处，此时转速恰为空载的一半。代入验证：$T = 0.15$ 时 $\omega = 120$ rad/s，$P = 18$ W；而输入功率 $VI = 12 \times 3 = 36$ W——**最大功率点的效率只有 50%**。电动车急加速最费电、堵转工况纯属烧钱，都是从这条抛物线上来的。

### 快问快答

```quiz
转子被完全卡住不转时，电枢电流由什么决定？
- 电流为零，因为没有运动就没有做功
- 只由电枢电阻决定，等于 V 除以 R [*]
- 由负载转矩除以 Kt 决定
- 由反电动势决定
? 转速为零则反电动势为零，电源电压全部落在电阻上，电流就是 V/R。注意第三个选项在正常运转时是对的（稳态电流=负载转矩/Kt），堵转时它给出的也是 V/R——两句话在堵转点重合，但逻辑完全不同。
```

:::warning[常见误区]

**误区一**："电压决定转速，负载只决定电流。"
你以为 12 V 电机接 12 V 就有一个固定转速——其实**工作点由电压和负载共同决定**：机械特性是一条下斜的直线，负载多大，转速就沿直线掉到哪。选型时只看空载转速不看工作点转速，是烧电机和亏性能的双料捷径。

**误区二**："反电动势是一种损耗，越小越好。"
你以为 $E$ 抢走的 8.8 V 被浪费了——其实 $EI = 8.8 \times 1.6 = 14.08$ W 恰好等于机械输出功率 $T\omega = 0.08 \times 176$ W。**反电动势是能量转换的媒介，真正的损耗只有铜损 $I^2R = 5.12$ W**（加上未建模的铁损与摩擦）。想减小损耗，该降的是电阻和电流，不是反电动势。

**误区三**："启动电流就是额定电流，直接上电没事。"
你以为电机标 1.6 A 就只会吃 1.6 A——启动瞬间 $\omega = 0$、反电动势为零，电流是 $V/R$，本例就是 6 A，大电机可达额定的五到十倍。所以大功率直流系统要**软启动**（电压缓升）或限流，第 68 章的晶体管开关和本章后面的 H 桥，干的就是这个活。

:::

**练习 1**：同一颗电机（$V = 12$ V，$R = 2$ Ω，$K_t = K_e = 0.05$），负载改为 $T_L = 0.1$ N·m。求稳态转速（rpm）。这段代码忘了扣电枢电阻上的压降，修到输出 `1527.9`：

```exercise
# @title: 练习：负载下的稳态转速
# @check: 1527.9
# @hint: 先由 I = Tl/Kt 求电流，再算电阻压降 I·R，反电动势是「电压减去压降」剩下的部分，最后 E/Ke 得角速度
import math                      # 数学库：提供 pi

V, R, Kt, Ke, Tl = 12.0, 2.0, 0.05, 0.05, 0.1
I = Tl / Kt                      # 稳态电流
E = V                            # ← 问题在这：忘了减去 I * R
w = E / Ke                       # 角速度 rad/s
print(round(w * 60 / (2 * math.pi), 1))
```

**练习 2**：给这颗电机供电的电池与导线合计有 0.5 Ω 内阻（电枢回路总电阻变为 2.5 Ω）。同样的负载 $T_L = 0.1$ N·m 下，转速掉多少 rpm？

<details>
<summary>点开查看逐步解答</summary>

1. 稳态电流不变：$I = 0.1/0.05 = 2$ A（负载不变，稳态转矩方程没变）；
2. 反电动势变小：$E = 12 - 2 \times 2.5 = 7$ V；
3. 转速 $\omega = 7/0.05 = 140$ rad/s $\approx 1337$ rpm；
4. 对照练习 1 的 1527.9 rpm：**掉约 191 rpm（12.5%）**。

同一笔账从电源侧看：内阻上白白烧掉 $I^2 \times 0.5 = 2$ W，端电压跌了整整 1 V。导线细一米、电池虚标一点，机器性能就悄悄打折——**供电回路的电阻从来不是"细节"**。

</details>

## 7. 选读：为什么 Kt 与 Ke 必然相等

<details>
<summary>选读 · 一行能量守恒证明</summary>

把电功率账本摆开：

$$VI = I^2R + EI$$

左边是电源供入的功率，第一项是铜损，第二项去哪了？代入 $E = K_e\omega$：

$$EI = K_e \omega I = \omega \cdot (K_e I)$$

而机械输出功率是 $T_e\omega = (K_t I)\omega$。若 $K_t \ne K_e$，电功率与机械功率就对不上账——多出的能量无处可去，少的能量无中生有。所以国际单位制下**必然 $K_t = K_e$**，这不是巧合，是能量守恒逼出来的同一个常数：

$$\boxed{EI = T_e\omega \quad \Longleftrightarrow \quad K_t = K_e}$$

顺带解决上一节悬着的问题：反电动势"吃掉"的功率 $EI$ **逐字等于**机械功率 $T\omega$——它是电能过河的桥，不是河里的漩涡。厂牌数据表里 KV 值（rpm/V）与 $K_e$ 的换算 $K_e = \dfrac{60}{2\pi \cdot \text{KV}}$，以及" torque constant 与 back-EMF constant 数值相同"的注脚，全是这条守恒律的不同马甲。

</details>
