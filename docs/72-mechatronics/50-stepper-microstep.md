# 步进电机与细分驱动

## 1. 从一个场景开始

3D 打印机的喷头能精确停在 0.01 mm 的位置，可它身上没有编码器——没"眼睛"的电机怎么知道自己走到了哪？

答案在名字里：**步进电机**。它每收到一个脉冲就转一个固定角度，数脉冲就知道位置。可整步 1.8° 对应 0.09 mm 的直线位移，表面粗糙度不够。于是工程师把一个整步切成 16 份——每脉冲 0.1125°，分辨率翻 16 倍，3D 打印表面立刻光滑了。这就是**细分驱动**，本课的全部主角。

## 2. 直觉解释

把步进电机的转子想象成一根指南针：定子的两相绕组通电后产生磁场，指南针被吸引过去。每换一次电流方向，磁场转 90°，指针跟着跳一格——这就是**整步**。

整步的跳变很大：磁场从 0° 直接跳到 90°，指针"咔哒"一下猛甩过去，撞到磁场的方向后还会**弹几下才稳**——这就是步进电机低频振动的来源。在显微镜下看，转子的运动轨迹不是一条直线，而是一串带过冲的阶梯。

如果不去跳 90°，而是让电流不是方波而是**近似正弦**——每一步只让磁场旋转一个微小的角度呢？转子每步只挪一小截，几乎不弹。这就是**细分**：把一个整步切成 $m$ 份，磁场每次只转 $90°/m$，跳变缩成原来的 $1/m$。

但"近似正弦"有一个致命词：**近似**。微控制器只给得出量化的数字——它无法输出完美的连续正弦，只能输出一条"阶梯正弦"：在两个量化电平之间，电流保持不变，直到下一个微步才跳一格。转子因此不是均匀滑过，而是"挪—停—挪—停"。这个停顿叫**量化误差**，它决定了细分的极限。

## 3. 正式定义

步进电机的两相绕组 A、B 中的电流理想值是一个**连续旋转的电流矢量**：

$$
I_A = I_0 \sin\theta,\qquad I_B = I_0 \cos\theta
$$

其中 $\theta$ 是**电角度**（与机械角度的比值等于极对数），$I_0$ 是额定电流。电流矢量的合成方向就是定子磁场方向，转子始终被吸引到与磁场对齐的位置。

- **整步**：$\theta$ 每次跳 $90°$（四步一个电周期）。
- **$m$ 细分**：$\theta$ 每次跳 $90°/m$，需要 $4m$ 步走完一个电周期。

| 符号 | 含义 |
| --- | --- |
| $m$ | 细分数（1=整步，2=半步，…，16=1/16 微步） |
| $\theta_\text{step}$ | 步距角（机械），$\theta_\text{full} / m$ |
| $\theta_\text{full}$ | 整步步距角（常见 1.8°） |
| $N_\text{rev}$ | 每转步数 $= 360°/\theta_\text{step} = 200m$ |
| $f_\text{pulse}$ | 脉冲率 $= \text{步率} \times m$ |

量化误差：实际电角度 $\hat\theta$ 被量化到最近的微步格点：

$$
\hat\theta = \text{round}\!\left(\frac{\theta}{q}\right) \cdot q,\qquad q = \frac{90°}{m}
$$

位置误差峰峰 = $q = 90°/m$（电角度），机械上 = $\theta_\text{full}/m$。

## 4. 分步例题

**例**：一台 1.8° 整步步进电机，步率 100 整步/s，细分设为 1/16。求步距角、分辨率、脉冲率。

1. **步距角**：$\theta_\text{step} = 1.8°/16 = 0.1125°$。
2. **分辨率**：$N_\text{rev} = 360°/0.1125° = 3200$ 步/转（整步时 200 步/转）。
3. **脉冲率**：$f_\text{pulse} = 100 \times 16 = 1600$ 脉冲/s。
4. **转速**：$1600/3200 = 0.5$ 转/s $= 30$ rpm。
5. **位置误差**：$\pm 0.0563°$（半个步距角）。

虚线是理想正弦电流，实线是细分量化后的阶梯电流。细分数越高，阶梯越接近正弦，但脉冲率也成正比上升——微控制器的定时器要跟得上。

### 实验 2：自己算（Python）

```python title="细分量化误差与振动指数"
# 细分数 m 对步距角、分辨率、脉冲率的影响
import math
full_step = 1.8  # 整步步距角（度）
rate = 100       # 指令步率（整步/秒）
for m in [1, 2, 4, 8, 16]:
    step = full_step / m
    res = 360 / step
    pulse = rate * m
    vib = step / full_step * 100
    print(f"1/{m:<2}  步距角={step:.4f}°  分辨率={res:>5.0f}步/转  脉冲率={pulse:>5.0f}Hz  振动指数={vib:.1f}%")
```

## 6. 常见误区

:::warning[常见误区]
- **「细分越多精度越高」**——精度受限于机械摩擦和负载力矩。过细分时，微步之间的力矩差小于静摩擦，转子根本不动，只是"想动"。16 细分以上通常是"分辨率高但精度不变"。
- **「细分能提高最大转速」**——相反。脉冲率有上限（驱动器定时器频率），$m$ 越大，同样脉冲率下的转速越低。高细分低转速、低细分高转速，是工程取舍。
- **「步进电机不会失步」**——会。负载超过保持力矩、加速过快、电压不足都会失步。没有反馈的步进系统靠"开环信任"工作，一旦失步，后续位置全错。
:::


<details>
<summary>选读 · 细分为什么不能无限提高精度</summary>

微步的物理极限来自**静摩擦**。假设转子的静摩擦力矩为 $T_f$，保持力矩为 $T_h$。微步 $k$ 对应的力矩差为：

$$
\Delta T(k) = T_h \sin\!\left(\frac{90°}{m} \cdot k\right)
$$

当 $m$ 足够大时，$\sin(90°/m) \approx 90°/m$（弧度制），$\Delta T \propto 1/m$。一旦 $\Delta T < T_f$，转子就**不动**——电流变了但位置没变。这个临界细分数：

$$
m_\text{max} \approx \frac{T_h \cdot \pi/2}{T_f}
$$

典型值：$T_h = 0.5$ N·m、$T_f = 0.02$ N·m → $m_\text{max} \approx 39$。所以 16 细分常用、32 细分少见、256 细分纯属"分辨率虚高"。

</details>
