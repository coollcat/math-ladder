# 传感器与信号调理

## 1. 从一个场景开始

上一课你测好了电机转速，现在想给机械臂加一个力传感器。数据手册说：满量程输出 **10 mV**，叠加 **0.5 mV** 的噪声。而你单片机的 ADC 满量程 **3.3 V**——信号比量程小三百倍，直接接上去，12 位 ADC 只会在底部几个码值里打转，噪声跳动比信号本身还明显。

把毫伏级小信号变成 ADC 吃得下的伏级信号，中间这一段电路叫**信号调理链**：放大、滤波、搬移。它不是"加个运放"那么简单——增益给大了削波，给小了分辨率浪费；滤波器狠了响应慢，松了噪声淹没信号。**这一课全程都在两头打架。**

## 2. 直觉解释

想象你要用手机拍一只萤火虫（信号很弱），背景是城市夜景（噪声很强）。

- **放大**：把画面放大 100 倍。但手机屏幕亮度有限（ADC 量程）——放太大，萤火虫亮成过曝的白斑（**削波**），信息反而丢了；放太小，萤火虫只占屏幕一个像素（**浪费分辨率**）。理想是让"最亮的萤火虫"恰好撑满屏幕；
- **滤波**：夜景的光污染（带外噪声）是弥漫的，装一个"只让萤火虫波长通过"的滤镜（低通），背景暗下去、虫子凸显。但滤镜太窄，虫子自己忽明忽暗的细节也被抹平了（**响应变慢**）；
- **搬移**：萤火虫在画面很暗的下沿活动，而手机对暗部记录能力差——把它挪到画面中间（电平搬移到量程中央），上下都留余量。

信号调理链的每一环都在做同一件事：**在不丢信息的前提下，把信号映射到 ADC 最会"看"的那段区间**。

## 3. 正式定义

**调理链**（传感器 → 仪表放大器 → 低通 → 电平搬移 → ADC）的数学模型：

**放大**：仪表放大器对差分小信号放大 $G$ 倍（共模噪声被抑制——这正是[运放负反馈](../68-electronics/130-opamp-lab.md)练过的手段）：

$$A = G \cdot V_{sig}$$

**噪声经一阶低通**：设输入白噪声带宽 $B_{in}$，一阶低通的等效噪声带宽为 $\frac{\pi}{2}f_c$，输出噪声标准差

$$\sigma_{out} = G\,\sigma_{in}\sqrt{\min\!\left(1, \tfrac{\pi f_c / 2}{B_{in}}\right)}$$

——截止频率每降为 $1/k$，输出噪声降为 $1/\sqrt{k}$（功率减半，幅度才除以 $\sqrt{2}$）。

**量化**：$b$ 位 ADC、满量程 $V_{FS}$ 的最小码值

$$\mathrm{LSB} = \frac{V_{FS}}{2^b}$$

**不削波条件**（留 $3\sigma$ 余量）：

$$V_{ref} + A + 3\sigma_{out} \le V_{FS}, \qquad V_{ref} - A - 3\sigma_{out} \ge 0$$

**有效位数**（ENOB）：信号与噪声的功率比折算回位数（引用 40 章信息论的信噪比定义）：

$$\mathrm{SNR} = 20\lg\frac{A/\sqrt{2}}{\sigma_{out}}, \qquad \mathrm{ENOB} = \frac{\mathrm{SNR} - 1.76}{6.02}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $V_{sig}$ | 传感器输出幅值 | mV | 满量程对应的交流幅值 |
| $G$ | 仪表放大器增益 | — | 差分放大倍数 |
| $f_c$ | 低通截止频率 | Hz | 噪声与带宽的分界 |
| $V_{ref}$ | 电平搬移偏置 | V | 把信号中心挪到的位置 |
| $\sigma_{in/out}$ | 噪声标准差 | mV / V | 输入/输出噪声的 RMS 幅度 |
| $b$ | ADC 位数 | bit | 量化层数的对数 |

**ENOB 是最终成绩单**：标称 12 位的 ADC，若噪声占了 15 个 LSB，实际只有约 9 位有效——买位数买不到精度，噪声才说了算。

## 4. 分步例题

**例**：应变桥满量程 10 mV，输入噪声 0.5 mV RMS（带宽 5 kHz），$V_{FS} = 3.3$ V，12 位 ADC，$V_{ref} = 1.65$ V。选增益并评估。

1. **增益上限**（先不管噪声）：$2A \le V_{FS}$ 给出 $G \le 3.3/(2\times0.01) = 165$；
2. **留噪声余量**：取 $G = 150$，则 $A = 1.5$ V，占量程 $2A/V_{FS} = 91\%$；
3. **输出噪声**（取 $f_c = 200$ Hz）：$\sigma_{out} = 150 \times 0.5\,\text{mV} \times \sqrt{\frac{\pi \times 100}{5000}} = 75\,\text{mV} \times 0.2507 \approx 18.8\,\text{mV}$；
4. **削波校验**：$1.65 + 1.5 + 3\times0.0188 = 3.21 \le 3.3$ ✓ 刚好不削；
5. **ENOB**：$\mathrm{SNR} = 20\lg\dfrac{1.5/\sqrt{2}}{0.0188} = 20\lg(56.5) \approx 35$ dB，$\mathrm{ENOB} = (35-1.76)/6.02 \approx 5.5$ bit——**12 位 ADC 只干出 5.5 位的活**，噪声是瓶颈。

第 5 步是本课的"啊哈"时刻：分辨率瓶颈几乎从不在 ADC 位数，而在链路噪声。把 $f_c$ 从 200 Hz 压到 50 Hz，噪声降到 9.4 mV，ENOB 升到约 6.5 位；再想上去就得靠**过采样平均**（见选读）。

## 5. 动手实验

### 实验 1（lab）：一条链两头打架

```lab
{
  "type": "sensor-conditioning",
  "title": "信号调理链：放大-滤波-搬移-量化",
  "sig": 10,
  "noise": 0.5,
  "gain": 150,
  "fc": 200,
  "vref": 1.65,
  "bits": 12
}
```

画面从上到下：

- **信号链方框图**：传感器 → 仪表放大 → 低通 → 电平搬移 → ADC，每格实时显示当前参数；
- **主波形**：叠加噪声的正弦信号（灰带 = ADC 允许范围，斜线阴影 = 超范围区，红色粗点 = 被削波的采样点，虚线 = ±3σ 包络）；
- **底部台阶**：一段放大后的 ADC 码值——噪声让台阶来回跳，跳动的 LSB 数就是噪声的"脚印"。

三件事值得做：

- 把增益从 150 拖到 300：波形顶部底部钻进红色斜线区——**削波不是"变小声"，是把波形顶剪平**，信息永久丢失，状态栏立刻报警；
- 把 $f_c$ 从 2000 Hz 拖到 50 Hz：底部台阶的跳动肉眼可见地收敛，ENOB 读数一路爬升——但想一想：被测应变如果 100 Hz 就变了，50 Hz 的滤波器会把真实信号也抹掉；
- 把位数从 8 拖到 16：LSB 读数变小，但**噪声跳动读数纹丝不动**——位数再高也救不了噪声，这就是"买位数买不到精度"。

### 实验 2（python）：把例题的链路算一遍

```python title="调理链设计计算器"
import math                    # 数学库：log10、sqrt 等函数

VFS = 3.3       # ADC 满量程 V
B_in = 5000     # 输入噪声带宽 Hz

def chain(sig_mV, noise_mV, gain, fc, bits):
    # 一步到位算完整条链
    A = sig_mV * 1e-3 * gain                     # 放大后的信号幅值 V
    sig_factor = math.sqrt(min(1.0, (math.pi / 2) * fc / B_in))
    sigma = noise_mV * 1e-3 * gain * sig_factor  # 滤波后的输出噪声 V
    lsb = VFS / 2 ** bits                        # 最小码值 V
    snr = 20 * math.log10((A / math.sqrt(2)) / sigma)
    enob = (snr - 1.76) / 6.02
    return A, sigma, lsb, snr, enob

for fc in [2000, 200, 50, 10]:
    A, sigma, lsb, snr, enob = chain(10, 0.5, 150, fc, 12)
    print(f"fc={fc:>5} Hz: 噪声 {sigma*1000:5.1f} mV = {sigma/lsb:5.1f} LSB, "
          f"SNR {snr:4.1f} dB, ENOB {enob:4.1f} bit")
```

打印结果：截止频率每降一个数量级，噪声大约缩到原来的 1/√10，ENOB 爬升约 1.7 位。但**信号带宽也被同一条 $f_c$ 卡住**——若被测信号有 100 Hz 分量，你敢用 10 Hz 滤波器吗？这就是例题第 5 步说的权衡。

### 快问快答

```quiz
信号幅值和增益都不变，只把 ADC 从 12 位换成 16 位，输出噪声折算的 LSB 跳动会怎样？
- 噪声占的 LSB 数变成原来的 16 倍，ENOB 不变 [*]
- 噪声占的 LSB 数变成原来的 1/16，ENOB 明显提升
- 完全不变，因为噪声和位数无关
? LSB 缩小为 1/16，同样的噪声电压折算成 LSB 后跳动变为 16 倍——ENOB 只取决于信号与噪声电压之比，位数只决定"天花板"。16 位 ADC 配上 18.8 mV 噪声，有效位数还是 5.5。
```

:::warning[常见误区]

**误区一**："增益越大越好，反正 ADC 量程没用完。"
你只盯着利用率——其实增益的上限由**削波条件**锁死：$V_{ref} + A + 3\sigma \le V_{FS}$。更阴险的是传感器本身的非线性：把传感器推到满量程的 99% 才发现它的非线性误差在末端急剧增大。工程上常规留 10%~20% 余量，"刚好撑满"在纸面上最优、在现场翻车。

**误区二**："滤波器截止频率越低噪声越小，那压得越低越好。"
你只算噪声——其实 $f_c$ 同时卡住**噪声带宽和信号带宽**。被测信号最高有效频率是 $f_s$，滤波器就必须 $f_c \ge$ 若干倍 $f_s$（还要顾忌相位滞后，卷六 68 章的 RC 一阶响应讲过：截止附近相位变化最陡）。噪声与带宽是同一个旋钮的两端，不存在"只压噪声不压信号"的滤波器。

**误区三**："12 位 ADC 就有 12 位精度。"
你以为数据手册的位数是精度——其实那是**无噪声时的上限**。ENOB 公式告诉我们：噪声每占约 6 个 LSB，有效位数就掉 1 位。真实系统的 ENOB 落后标称位数 2~4 位是常态，而这已经是精心设计的结果。

:::

**练习 1**：传感器满量程 20 mV，ADC 满量程 3.3 V，信号双极性（要占满整个量程）。求增益上限。代码把"峰峰值"当成"幅值"，修到输出 `82`：

```exercise
# @title: 练习：增益上限
# @check: 82
# @hint: 双极性信号占满量程意味着峰峰值 2A = 20 mV 对应 3.3 V，所以 G = VFS / (2 × A)，不是 VFS / A
sig_mV = 20.0      # 满量程（峰峰值）mV
VFS = 3.3          # ADC 满量程 V
G = VFS / (sig_mV * 1e-3)   # ← 问题在这：把峰峰值当成了单边幅值
print(round(G, 0))
```

**练习 2**：噪声 0.5 mV RMS、增益 150、$f_c = 200$ Hz 时输出噪声约 18.8 mV。若用**过采样**：以 16 倍速率采样再对每 16 个样本取平均，输出噪声变成多少？相当于 ENOB 提升几位？

<details>
<summary>点开查看逐步解答</summary>

1. 平均滤波器对不相关的白噪声：$N$ 个样本平均后标准差降为 $\sigma/\sqrt{N}$；
2. $\sqrt{16} = 4$，噪声 $18.8/4 = 4.7$ mV；
3. SNR 提升 $20\lg 4 \approx 12$ dB，ENOB 提升 $12/6.02 \approx 2$ 位；
4. 代价：输出数据率降为 $1/16$，等效信号带宽也缩小 16 倍。

这就是"过采样 + 抽取（oversampling + decimation）"：**用速度换精度**。它成立的前提是噪声在 ADC 输入端确实近似白（各样本不相关）、且幅度大于 1 LSB（能抖动量化误差）——条件不满足时 16 倍过采样换不到完整 2 位，这是数据手册脚注里藏的坑。

</details>

## 7. 选读：为什么是 π/2 倍

<details>
<summary>选读 · 一阶低通的等效噪声带宽为什么是 (π/2)·fc</summary>

白噪声的功率谱密度在所有频率上均匀。低通滤掉的是"频率高于 $f_c$ 的噪声成分"，但一阶低通的幅频响应 $|H(f)| = \frac{1}{\sqrt{1+(f/f_c)^2}}$ 是**缓坡**而非砖墙：$f_c$ 以上它以 −20 dB/十倍频缓慢衰减，$2f_c$ 处还剩 0.45 倍幅度。

等效噪声带宽定义为：假设有一个"砖墙"滤波器，能让相同的噪声功率通过，其宽度是

$$B_{eq} = \int_0^{\infty} \left|\frac{H(f)}{H(0)}\right|^2 df = \int_0^{\infty} \frac{1}{1+(f/f_c)^2}\,df = \frac{\pi}{2}f_c$$

（积分用换元 $u = f/f_c$ 化为 $\int_0^\infty \frac{du}{1+u^2} = \pi/2$。）

所以一阶低通等效于一个宽 $\frac{\pi}{2}f_c \approx 1.57 f_c$ 的砖墙——比 $f_c$ 宽出 57%，全是缓坡"漏"出去的。二阶滤波器坡更陡，$B_{eq}$ 更接近 $f_c$；这也是为什么同样截止频率下，高阶滤波器的噪声抑制更好（代价是元件更多、相位滞后更集中）。

</details>
