# 编码器与测速

## 1. 从一个场景开始

你给直流电机配好了 PWM 与 H 桥，想让它稳稳转在 3000 rpm。可控制器怎么知道它现在转多快？电机不会说话——除非你在轴上装一个**编码器**，让它每转一圈向你"汇报"几千次。

新的问题立刻出现：汇报的方式只是数脉冲。数脉冲有两种姿势——**一段时间内数脉冲个数**，或者**两个脉冲之间数时钟个数**。前者在高速时准、低速时瞎；后者恰好相反。真实系统从 1 rpm 到 6000 rpm 都要测，怎么选？

## 2. 直觉解释

想象你在路边数车。

**M 法（数脉冲）**：站在那儿 10 秒，数通过了多少辆车，除以 10 秒得到车流密度。车流密集时，数错一辆车无所谓；可要是 10 秒只过了 2 辆车，多数少数一辆就是 50% 的误差——**被测越快，相对误差越小**。

**T 法（数时钟）**：掐表测相邻两辆车经过路灯杆的时间间隔。你的秒表有固定读数误差（比如 0.1 秒），车间隔 5 秒时误差只有 2%；可车一辆接一辆、间隔只有 0.3 秒时，0.1 秒的误差就是 33%——**被测越慢，相对误差越小**。

两条误差曲线一条往下走、一条往上走，中间必有一个交叉点：**低于它用 T 法，高于它用 M 法**。这就是机电系统里最经典的"分界换挡"。

还有一个细节：编码器输出 A、B 两路**错开四分之一周期**的方波。为什么费这个劲？因为一个周期只在上升沿计数，只能数 1 次还不知道方向；两路方波的所有边沿都算数，一个周期能数 **4 次**，分辨率翻四倍，还能由"A 先还是 B 先"判出转向。

## 3. 正式定义

**增量式正交编码器**：码盘上有 $N$ 线/转（PPR），输出 A、B 两路相位差 90° 的方波。**四倍频解码**后每转产生

$$n_c = 4N$$

个计数，角度分辨率为 $360°/n_c$。

**M 法（测频法）**：在闸门时间 $T_w$ 内计脉冲数 $m$，转速为

$$\hat{\omega} = \frac{60\,m}{4N\,T_w} \quad (\text{rpm})$$

误差来源是 ±1 个计数的量化误差，相对误差

$$\varepsilon_M = \frac{1}{m} = \frac{60}{4N\,T_w\,\omega} \times 100\%$$

——与转速 $\omega$ 成**反比**：转得越快越准。

**T 法（测周法）**：用频率 $f_c$ 的高频时钟填两个相邻脉冲之间的空档，计得 $M$ 个时钟，转速为

$$\hat{\omega} = \frac{60\,f_c}{4N\,M} \quad (\text{rpm})$$

相对误差（同样 ±1 计数量化）

$$\varepsilon_T = \frac{4N\,\omega}{60\,f_c} \times 100\%$$

——与转速 $\omega$ 成**正比**：转得越慢越准。

**分界转速**：令 $\varepsilon_M = \varepsilon_T$ 解出脉冲频率 $f^* = \sqrt{f_c/T_w}$，换算成转速即换挡点。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $N$ | 编码器线数 | 线/转（PPR） | 码盘刻线密度 |
| $T_w$ | 闸门时间 | 秒 s | M 法的计数窗口长度 |
| $f_c$ | 计数时钟 | 赫兹 Hz | T 法的"秒表"频率 |
| $m$ | 脉冲计数 | — | M 法闸门内数到的脉冲数 |
| $M$ | 时钟计数 | — | T 法两脉冲间的时钟数 |
| $\hat{\omega}$ | 转速估计 | rpm | 测量值（帽子表示估计） |

注意 $\hat{\omega}$ 戴着帽子——它是**采样**出来的估计值，和 61 章的采样定理同源：闸门时间 $T_w$ 就是测速环节的"采样周期"，速度变化快于 $1/T_w$ 时你测到的只是平均值。

## 4. 分步例题

**例**：编码器 $N = 1000$ PPR，$T_w = 10$ ms，$f_c = 8$ MHz。电机转速 1500 rpm，用哪种方法？误差各多少？

1. **每转计数**：$n_c = 4 \times 1000 = 4000$ 计数/转；
2. **脉冲频率**：$f = \dfrac{1500}{60} \times 4000 = 100\,\text{kHz}$；
3. **M 法**：$m = 100\,000 \times 0.01 = 1000$ 计数，误差 $\varepsilon_M = 1/1000 = 0.1\%$；
4. **T 法**：$M = 8\times10^6 / 10^5 = 80$ 计数，误差 $\varepsilon_T = 1/80 = 1.25\%$；
5. **结论**：此转速下 M 法误差是 T 法的 1/12.5，选 **M 法**。

再算分界点验证：$f^* = \sqrt{8\times10^6 / 0.01} \approx 89.4$ kHz，对应约 1341 rpm。1500 rpm 在分界点之上，确实是 M 法的地盘——与第 5 步结论一致。


画面分三层，从上到下：

- **码盘**在转，旁边是 A、B 两相方波——注意 B 相滞后 A 相四分之一周期，琥珀色竖线标出四倍频计数沿：每个上升/下降沿都数一次；
- **双对数误差图**是主菜：蓝线（M 法）从左上往右下走，绿线（T 法）从左下往右上走，交叉点就是换挡转速；绿色虚线标出当前转速在两条曲线上的位置；
- **读数面板**直接给出两种方法的误差和推荐算法。

三件事值得做：

- 把转速从 6000 rpm 一路拖到 10 rpm，看"推荐"一栏何时从 M 法翻成 T 法——交叉点在双对数图上是严格的一条竖线；
- 把闸门时间 $T_w$ 拖到 100 ms：M 法整条曲线下移（更准了），但代价是**测速延迟变大**——速度反馈环里这是实打实的相位滞后；
- 把 PPR 拖到 5000：两条曲线同时下移，但"最低可测转速"读数也变了——高线数编码器不是免费的，脉冲频率上限受输入电路约束。

### 实验 2（python）：把分界转速算出来

```python title="M 法与 T 法的误差曲线与交叉点"
N = 1000      # 编码器线数 PPR
Tw = 0.01     # 闸门时间 s
fc = 8e6      # T 法计数时钟 Hz

def err_M(rpm):
    # M 法误差：±1 个脉冲 / 闸门内脉冲数
    m = (rpm / 60) * 4 * N * Tw
    return 100.0 / m if m > 0 else float("inf")

def err_T(rpm):
    # T 法误差：脉冲频率 / 时钟频率（±1 个时钟的影响）
    return 100.0 * (rpm / 60) * 4 * N / fc

# 在对数网格上扫描转速，找两条误差曲线的交叉点
fstar = (fc / Tw) ** 0.5            # 分界脉冲频率（由 1/m = f/fc 解出）
rpm_star = fstar * 60 / (4 * N)     # 换算成 rpm
print(f"分界转速 ≈ {rpm_star:.0f} rpm（脉冲频率 {fstar/1000:.1f} kHz）")

for rpm in [30, 300, 1341, 3000, 6000]:
    print(f"{rpm:>5} rpm: M 法 ±{err_M(rpm):6.2f}%   T 法 ±{err_T(rpm):6.2f}%   "
          f"→ {'M 法' if err_M(rpm) < err_T(rpm) else 'T 法'}")
```

打印结果一目了然：30 rpm 时 T 法误差只有 M 法的约三百分之一，6000 rpm 时攻守易势。1341 rpm 附近两者几乎相等——这正是推导 $f^* = \sqrt{f_c/T_w}$ 的意义：**换挡点只由两个测量参数决定，与被测转速无关**。

工程实践里还有 **M/T 法**：高速段数脉冲、低速段数时钟，一条固件逻辑覆盖全量程——本质就是让程序在分界点两侧自动切换。

### 快问快答

```quiz
其他参数不变，把闸门时间 Tw 加倍，M 法的误差会怎样变化？
- 误差减半，但测速延迟也加倍 [*]
- 误差减半，且响应更快
- 误差不变，只是数得更多
? 误差 = 1/m，m 与 Tw 成正比，所以误差减半；但闸门本身就是平均窗口，速度反馈的延迟随之加倍——精度和实时性在打架，这正是下一课 PID 离散化要面对的权衡。
```

:::warning[常见误区]

**误区一**："1000 线的编码器，角度分辨率就是 1/1000 转。"
你以为线数就是分辨率——其实正交解码数的是 A、B 两相**所有**边沿，一个周期数 4 次，实际分辨率是 $1/(4N)$ 转。1000 PPR 编码器给的是 0.09°，四倍频不是玄学加成，而是把两路方波的信息榨干净。

**误区二**："T 法在低速更准，那我把时钟频率无限提高不就全速段都准了？"
你只看到误差公式里的 $f_c$ 在分母上——其实提高 $f_c$ 只改善 T 法，M 法的误差纹丝不动（它压根不用时钟），而且高速段脉冲间隔极短，需要 $f_c$ 高到不切实际才能维持 1 个时钟的精度。分界换挡（或 M/T 法）才是正解，单一方法通吃全量程在物理上做不到。

**误区三**："编码器输出的脉冲数就是真实位置。"
你以为数出来的就是事实——其实码盘有制造误差、计数沿有抖动、高速时还可能漏数。测量永远是估计：$\hat{\omega}$ 的帽子提醒你，速度环里反馈的是带噪声、带延迟的估计值，控制器设计必须把这个误差算进去。

:::

**练习 1**：M 法测得 25 ms 闸门内 750 个计数，编码器 500 PPR。下面代码忘乘四倍频，修到输出 `900`：

```exercise
# @title: 练习：从计数反推转速
# @check: 900
# @hint: 转速 = 60 × m / (4 × N × Tw)。别忘了四倍频：每转计数是 4N 而不是 N
m = 750        # 闸门内脉冲计数
N = 500        # 编码器线数 PPR
Tw = 0.025     # 闸门时间 s
rpm = 60 * m / (N * Tw)   # ← 问题在这：分母少了四倍频系数 4
print(round(rpm, 0))
```

**练习 2**：某个视觉云台要求速度分辨率优于 0.1 rpm，最低工作转速 10 rpm。若用 T 法、$f_c = 8$ MHz，编码器 PPR 至少选多少？

<details>
<summary>点开查看逐步解答</summary>

1. T 法在 10 rpm 处的计数 $M = \dfrac{f_c}{f} = \dfrac{8\times10^6}{(10/60)\cdot 4N} = \dfrac{1.2\times10^7}{N}$；
2. 分辨率 0.1 rpm ≈ 相对误差 $0.1/10 = 1\%$，即需要 $M \ge 100$；
3. $\dfrac{1.2\times10^7}{N} \ge 100 \Rightarrow N \le 1.2\times10^5$——这是上界不是下界！PPR 越**多**脉冲越**密**，T 法计数越少反而越不准；
4. 换个方向：PPR 太少则角度分辨率不够（$360°/(4N)$），且高速段 M 法变差。取 $N = 2500$：10 rpm 时 $M = 4800$，误差 0.02% ✓；角度分辨率 $360°/10000 = 0.036°$ ✓；
5. 校验高速端：6000 rpm 时脉冲频率 $(6000/60)\times 4 \times 2500 = 1$ MHz——需要确认输入比较器跟得上 1 MHz 方波，这是选型的真实约束。

这道题的陷阱在于：**"分辨率要求高"直觉上指向"买更高线数的编码器"，但 T 法恰好相反**。低速精度与高速能力是一对跷跷板。

</details>

## 7. 选读：M/T 法统一公式与等精度测量

<details>
<summary>选读 · 为什么 M/T 法能做到全速段"等精度"</summary>

M/T 法同时开两个计数器：闸门内数脉冲 $m_1$，同时用高频时钟数整个闸门时长 $m_2$（关键：闸门与脉冲沿**同步开启和关闭**，而非固定 $T_w$）。转速估计为

$$\hat{\omega} = \frac{60\,f_c\,m_1}{4N\,m_2}$$

为什么同步闸门能消灭 M 法的 ±1 误差？固定闸门在"何时开、何时关"上与脉冲无关，开闭瞬间各可能砍掉半个脉冲——这是量化噪声；同步闸门以脉冲沿为界，$m_1$ 是精确整数，±1 误差转移到 $m_2$ 上，而 $m_2$ 动辄数以万计，相对误差被压到 $10^{-4}$ 量级。

代价是闸门时长不再固定：转速越低闸门越长，延迟随转速变化。所以 M/T 法**不是免费的午餐**，它把"固定延迟 + 变精度"换成了"固定精度 + 变延迟"。伺服系统里通常再套一层插值滤波来平滑这个变化的延迟——每一层工程优化，都是在搬移而不是消灭矛盾。

</details>
