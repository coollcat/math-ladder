# 机电系统概貌：机、电、控怎样咬合成一台机器

## 1. 从一个场景开始

两台桌面机械臂，用的是同一款电机、同一块控制板。一台抓取零件稳稳当当，另一台每次都往一边偏两毫米。换电机？没用。换芯片？也没用。

差别不在任何一个零件上，而在零件之间的**连线方式**：一台把"看到的"送回给"发令的"，另一台只管发令、从不回头看。这一条从传感器绕回控制器的线，就是机电系统与"一堆机电零件"的分界线。

## 2. 直觉解释

把一台机器拆开数，不管多复杂，闭上眼睛都能数出**五个环节**：

- **传感器**是眼睛：把位置、转速、电流变成电信号；
- **控制器**是大脑：算出"现在差多少、下一步补多少"；
- **驱动器**是运动神经：把几毫安的控制量放大成几十伏、几十安的功率；
- **电机**是肌肉：把电能拧成转矩；
- **机械负载**是手臂本身：惯量、摩擦、传动比都长在它身上。

开环控制像**闭着眼睛倒水**：凭手感倒，杯子挪了你不知道，水洒了才知道。闭环控制是**盯着杯口倒**：眼睛不断把"还差多少"报给大脑，手上随时微调。有人碰了一下杯子（扰动），闭眼的照样洒，睁眼的几乎是浑然不觉地修正了。

注意"几乎是"三个字——闭环不是魔法，它把扰动压小了**很多倍**，但没有压成零。压小多少倍？这正是本章要量化的事。

## 3. 正式定义

机电系统的核心是一个**反馈回路**：设定值 $r$ 与测量值 $y$ 相减得偏差，控制器按偏差给出控制量，经驱动器放大后推动被控对象，传感器再把输出送回求和点。

本课用最简单的演示对象——一阶惯性环节加负载扰动：

$$\tau\frac{dy}{dt} + y = K_m u - T_d$$

**开环**（控制量恒定 $u = u_0$）的稳态输出：

$$y_{\text{开环}} = K_m u_0 - T_d$$

**闭环**（比例控制 $u = K_p(r - y)$）代入整理：

$$\tau\frac{dy}{dt} + (1 + K_p K_m)\,y = K_p K_m\, r - T_d$$

稳态解：

$$y_{\text{闭环}} = \frac{K_p K_m\, r - T_d}{1 + K_p K_m}$$

**扰动抑制**：同一个 $T_d$，在开环输出上全额出现，在闭环输出上只剩 $\dfrac{1}{1 + K_p K_m}$ 倍。这个倍数就是反馈"花掉"增益换来的抑制能力。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $r$ | 设定值 | — | 你想要的输出 |
| $y$ | 输出 | — | 机器实际的输出 |
| $u$ | 控制量 | — | 控制器发出的指令 |
| $K_p$ | 比例增益 | — | 偏差放大多少倍去推动对象 |
| $K_m$ | 对象增益 | — | 控制量到输出的静态放大 |
| $T_d$ | 负载扰动 | — | 折算到输出侧的外部扰动 |
| $\tau$ | 对象时间常数 | 秒 s | 对象自身的惯性 |

## 4. 分步例题

**例**：$K_m = 1$，$\tau = 0.4$ s，设定值 $r = 1$，比例增益 $K_p = 6$，扰动 $T_d = 0.5$。比较开环与闭环。

1. **开环**（$u_0 = 1$）：稳态 $y = 1 - 0.5 = 0.5$，误差 0.5；
2. **闭环**：稳态 $y = \dfrac{6 \times 1 - 0.5}{1 + 6} = \dfrac{5.5}{7} \approx 0.786$；
3. **闭环误差**：$1 - 0.786 \approx 0.214$，可拆成两笔——比例静差 $\dfrac{1}{1+K_p} = 0.143$，加扰动残留 $\dfrac{T_d}{1+K_p} = 0.071$；
4. **扰动对比**：扰动让开环输出跌 0.5，让闭环输出只跌 0.071——**缩小 $1 + K_p = 7$ 倍**。

第 3 步里那笔 0.143 的"比例静差"值得记住：纯比例控制的闭环对阶跃设定值永远差一截，这是后面 PID 课里"积分项"存在的理由。

## 5. 动手实验

### 实验 1（lab）：五个环节与开环/闭环对比

```lab

  "title": "机电闭环：扰动来了，开环与闭环差一个数量级",
  "sliders": [
    { "name": "Kp", "label": "控制器增益 Kp", "min": 0.5, "max": 20, "step": 0.5, "value": 6 },
    { "name": "Td", "label": "负载扰动 Td", "min": 0, "max": 1, "step": 0.05, "value": 0.5 }
  ]
}
```

三件事值得做：

- **点任一环节方块**：读数栏会告诉你它吃什么、吐什么、典型参数多大——控制器在毫安和毫秒的世界里工作，驱动器和电机在安培和千瓦的世界里工作，**它们中间隔着三个数量级的功率放大**；
- **切换开环/闭环**：盯住 1.5 秒处那条红色"扰动投入"竖线——开环模式下输出直接塌下去，闭环模式下只塌一小截就被顶回来；
- **拖大 Kp**：稳态误差读数跟着变小，但曲线的"纠回来"动作越来越猛——增益不是免费的，这个伏笔要到本章 PID 课才炸开。

### 实验 2（python）：自己把两个稳态算出来

```python title="开环 vs 闭环：同一个扰动，两种命运"
Km, tau, Kp, Td = 1.0, 0.4, 6.0, 0.5   # 对象增益、时间常数、增益、扰动
dt = 0.005                            # 仿真步长 5 ms（与实验台一致）

def run(closed, kp):                  # 定义一次仿真：closed 决定是否闭环
    y = 0.0                           # 输出初值为零
    for k in range(1, 2401):          # 跑 12 秒
        d = Td if k * dt > 1.5 else 0.0   # 1.5 秒后投入扰动（条件表达式）
        u = kp * (1 - y) if closed else 1.0
        y += dt * (u * Km - d - y) / tau  # 显式欧拉一步
    return y

y_open = run(False, 0)
y_closed = run(True, Kp)
y_big = run(True, 12)                 # 增益翻倍再试一次

print(f"开环稳态   y = {y_open:.3f}  误差 {1 - y_open:.3f}")
print(f"闭环 Kp=6  y = {y_closed:.3f}  误差 {1 - y_closed:.3f}")
print(f"闭环 Kp=12 y = {y_big:.3f}  误差 {1 - y_big:.3f}")
print(f"扰动跌落：开环 {Td:.3f}，闭环 {Td / (1 + Kp):.4f}（缩小 {1 + Kp} 倍）")
```

打印结果与第 4 节手算完全吻合：闭环误差 0.214、扰动跌落 0.071。注意最后两行的对比——**闭环的误差虽不为零，但扰动的"杀伤力"被砍掉了 6/7**。这就是反馈买卖的账：静差是纯比例控制的小毛病，扰动抑制才是它的大本事。

### 快问快答

```quiz
同一个负载扰动，闭环把它对输出的影响压缩为原来的多少分之一？
- 1/Kp
- 1/(1+Kp·Km) [*]
- 不变，反馈只加快响应
? 扰动通道的稳态增益从 1 变成 1/(1+Kp·Km)。注意分母是 1+Kp·Km 而不是 Kp——Kp 很小时反馈几乎没有抑制力，这正是"闭环"与"高增益"不能画等号的原因。
```

:::warning[常见误区]

**误区一**："做反馈控制必须先有精确的数学模型。"
你以为闭环是"先建模、后控制"——其实恰恰相反：**反馈正是对付模型不准的武器**。参数漂移 20%、负载不明、摩擦难测，只要回路增益够，这些不确定性对输出的影响都被压缩 $1+K_p K_m$ 倍。真要等模型完全精确才敢闭环，天底下就没有能用的机器了。

**误区二**："增益越大越好，误差越小越好。"
你只看到稳态误差随 $K_p$ 变小——但每一个真实对象都有惯性（本课的 $\tau$）甚至弹性，增益大到一定程度，"纠回来"的动作会变成"冲过头"，再变成来回震荡乃至发散。**增益的上限由动态特性决定，不是由误差指标决定**。这条线在哪里，正是本章传递函数模型一课要回答的问题。

**误区三**："机电系统 = 机械零件 + 电子零件拼起来。"
你以为难点在各自的原理——其实原理都学过了（力学在前几章、电路在第 68 章），**真正难的是接口**：控制器输出 3.3 V、20 mA，电机要 24 V、5 A；编码器一秒报一百万个边沿，控制器一毫秒才执行一次循环；信号地与功率地乱接一处，噪声直接淹没测量。机电工程一半的篇幅在讲接口，本章后半段（信号调理、总线、EMC）全是它。

:::

## 6. 练习

**练习 1**：$K_m = 1$，$K_p = 9$，扰动 $T_d = 0.45$。闭环把扰动对输出的影响压到多少？这段代码把分母写错了，修到输出 `0.045`：

```exercise
# @title: 练习：闭环的扰动残留
# @check: 0.045
# @hint: 扰动残留是 Td 除以 (1 + Kp)，不是除以 Kp。分母里那个 1 来自「输出本身也被反馈」——没有它，Kp 为零时反馈就凭空有了抑制力
Kp = 9.0
Td = 0.45
residual = Td / Kp    # ← 问题在这：分母少了 1
print(round(residual, 3))
```

**练习 2**：某传送带系统折算到输出侧的扰动为 0.6，要求闭环下扰动引起的输出跌落不超过 0.05。比例增益 $K_p$（设 $K_m = 1$）至少取多大？

<details>
<summary>点开查看逐步解答</summary>

1. 闭环扰动残留满足 $\dfrac{T_d}{1 + K_p} \le 0.05$；
2. 代入 $T_d = 0.6$：$1 + K_p \ge \dfrac{0.6}{0.05} = 12$；
3. 所以 $K_p \ge 11$；
4. 校验：$K_p = 11$ 时残留 $= 0.6/12 = 0.05$，恰好压线；工程上取 $K_p = 15$ 留余量（残留 0.0375）。

注意题目只约束了扰动指标——若还要求静差小，纯比例控制就要更大的增益，或者干脆等 PID 里的积分项来兜底。**指标拆开算、余量留出来**，是从做题到做工程的分水岭。

</details>

## 7. 选读：扰动怎么被"除以 1+Kp"的

<details>
<summary>选读 · 框图代数一行的推导</summary>

对闭环方程两边做拉普拉斯变换（零初始条件）：

$$(\tau s + 1 + K_p K_m)\, Y(s) = K_p K_m R(s) - T_d(s)$$

单独看扰动通道（令 $R = 0$）：

$$\frac{Y(s)}{T_d(s)} = \frac{-1}{\tau s + 1 + K_p K_m}$$

低频（$s \to 0$）增益为 $-\dfrac{1}{1 + K_p K_m}$——这就是"缩小 $1+K_p K_m$ 倍"的出处。高频时分母被 $\tau s$ 主导，增益趋近 $-\dfrac{1}{\tau s}$：**对变化极快的扰动，这个一阶对象本身就跟不上，反馈再强也来不及**。扰动抑制是有带宽的，这句话在后面的采样与控制周期课里还会回来。

顺带一提，控制理论把 $\dfrac{1}{1+L}$ 叫**灵敏度函数**（$L$ 为回路增益），它同时刻画扰动抑制与模型不确定性的衰减——同一个分母，管两件大事。

</details>
