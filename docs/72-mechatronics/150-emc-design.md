# EMC 与抗干扰设计

## 1. 从一个场景开始

功能全通过的样机送进 EMC 实验室，辐射发射超标 45 dB——在分贝世界里，这约等于强度差 200 倍。工程师查了两天，元凶是一根"能工作就行"的信号线：它的回流路径绕了远路，去程与回程圈出 20 cm² 的环路。产品只能改版布线，延迟两个月。

为什么"能工作"和"不干扰别人"差这么远？因为**电路工作只要求逻辑对，而辐射取决于你无意中造出的天线有多大**。这门课讲三件事：干扰的解剖结构（三要素）、辐射的粗算公式（小环天线）、以及一本以 dB 记账的整改账本。

## 2. 直觉解释

任何电磁干扰都由三件东西凑成，缺一不可：

**干扰源（发热的）→ 耦合路径（传播的）→ 敏感设备（受害的）**。

掐断任何一个，干扰就不成立。药方也只有四味：

- **屏蔽**：在路径上挡一堵导电的墙；
- **滤波**：在接口处只放"干净的"电流过；
- **接地**：给干扰电流一条回家的近路，别逼它走电缆；
- **缩环路**：让电流的去程和回程贴在一起。

其中**环路面积**是最容易被忽视、也最便宜的一味药。一根信号线总要有回流；去程与回程圈出的面积，就是一根"无意天线"——面积越大，它把磁场"甩"出去的本事越大。**扭绞一对线，去程回程反复贴紧换位，磁场互相抵消，等效面积直接砍一个量级。**

还有一条直觉：**频率越高辐射越凶**——同一根天线，频率翻一倍，辐射强四倍。所以"数字电路基频不高"是错觉：决定辐射的是**边沿的谐波**，时钟 100 MHz，它的 5 次、7 次谐波照样在数着你的超标量。

最后，整改不靠一招翻盘：超 45 dB，单靠屏蔽罩的 20 dB 不够，要**四味药按 dB 叠加**一起上——这正是下面要把账本算成 dB 的原因。

## 3. 正式定义

**小环天线远场辐射**（环路面积 $A$、频率 $f$、环路电流 $I$、观测距离 $r$；工程估算式，$E$ 以 µV/m 计、$f$ 以 MHz、$A$ 以 cm²、$I$ 以 mA、$r$ 以 m）：

$$E = \frac{1.316\times10^{-14}\, f^2 A\, I}{r}$$

**分贝换算**（dBµV/m，以 1 µV/m 为基准）：

$$E_{\text{dB}} = 20\log_{10} E$$

**辐射发射限值**（CISPR 32 Class B，@3 m）：

| 频段 | 限值 |
| --- | --- |
| 30–230 MHz | 40 dBµV/m |
| 230–1000 MHz | 47 dBµV/m |

**整改措施按 dB 相加**：$n$ 项措施的衰减 $G_1, G_2, \dots, G_n$（单位 dB）叠加后，总电平为

$$E_{\text{整改后}} = E_{\text{dB}} - \sum_i G_i$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $E$ | 辐射电场强度 | µV/m | 距环 $r$ 处的场强 |
| $A$ | 环路面积 | cm² | 电流去程与回程圈出的面积 |
| $f$ | 干扰频率 | MHz | 谐波频率，不是基频 |
| $I$ | 环路电流 | mA | 流过环路的电流 |
| $r$ | 测试距离 | m | 标准为 3 m |
| $E_{\text{dB}}$ | 分贝场强 | dBµV/m | 与限值同单位才能直接比 |

## 4. 分步例题

**例**：一块控制板，时钟 100 MHz，某回路 $A = 20$ cm²、$I = 20$ mA、测试距离 3 m。判断是否超标，并设计整改方案。

1. **原始电平**：$E = 0.01316 \times 100^2 \times 20 \times 20 / 3 \approx 17547$ µV/m；
2. **换 dB**：$E_{\text{dB}} = 20\log_{10}17547 \approx 84.9$ dBµV/m；
3. **对照限值**：100 MHz 落在 30–230 MHz 段，限值 40 dBµV/m，**超标 44.9 dB**——和开头场景一样惨；
4. **开药方（按 dB 记账）**：扭绞/缩环 −20 dB（面积 ÷10）、屏蔽 −20 dB、滤波 −15 dB、接地 −8 dB，合计 −63 dB；
5. **整改后**：$84.9 - 63 = 21.9$ dBµV/m < 40，**合格，余量 18.1 dB**。

注意第 4 步的顺序思想：**先缩环路（改布线，零 BOM 成本），再屏蔽（结构成本），最后才是滤波与接地**。dB 账本告诉你的不只是"够不够"，还有"最便宜的药先吃"。

画布上方是"干扰源 → 耦合路径 → 敏感设备"三要素与红色环路（面积越大、辐射弧越多）；下方是电平条与限值红线，四枚按钮各开一味药。值得做的三件事：

- **只点"扭绞"按钮**：环路面积直接 ÷10，电平掉 20 dB——**一颗螺丝没拧、一分钱没花**，这就是为什么缩环永远排第一；
- **把 f 拖过 230**：限值红线从 40 跳到 47，但电平以 $\propto f^2$ 涨得更快——频率每翻倍，超标恶化 12 dB；
- **四味药全开再看余量**：读数面板给出"余量"。工程上**余量留 6 dB 以上**才算稳（认证实验室之间、样机与量产之间都有偏差）。

### 实验 2（python）：把整改过程记成流水账

```python title="整改前后的一笔 dB 流水账"
import math                        # 数学库：log10
K = 0.01316                        # 小环远场系数（f:MHz, A:cm², I:mA, r:m）
A, f, I, r = 20, 100, 20, 3        # 环路面积/频率/电流/距离
level = 20 * math.log10(K * f * f * A * I / r)   # 原始辐射电平 dBµV/m
limit = 40 if f <= 230 else 47     # CISPR 32 Class B @3m 两段限值
print("原始电平 %.1f dBµV/m，限值 %d，超标 %.1f dB" % (level, limit, level - limit))
measures = [("扭绞缩环（面积÷10）", 20), ("金属屏蔽", 20), ("接口滤波", 15), ("改善接地", 8)]
cur = level
for name, db in measures:          # 一味药一味药地吃，账一行一行地记
    cur = cur - db
    verdict = "仍超标 %.1f" % (cur - limit) if cur > limit else "已合格（余量 %.1f）" % (limit - cur)
    print("%-20s −%2d dB → %6.1f，%s" % (name, db, cur, verdict))
```

输出复现了例题的全过程：超 44.9 dB → 扭绞后仍超 24.9 → 屏蔽后仍超 4.9 → 滤波后**已合格**（余量 10.1）→ 接地后余量 18.1。注意前两步"仍超标"：**整改中点不是终点**——dB 账本的价值是让你随时知道"还差多少、每味药贡献多少"，避免在 45 dB 的窟窿前病急乱投医。

### 快问快答

```quiz
其他条件不变，干扰频率从 100 MHz 提高到 200 MHz，辐射电平大约增加多少？
- 3 dB
- 6 dB
- 12 dB [*]
- 20 dB
? 辐射与频率平方成正比：频率翻倍，场强乘 4，而 20log10(4) = 12.04 dB。对照：面积或电流缩小 10 倍才是 −20 dB。记住两档换算——翻倍 6 dB（功率）对场强是 12 dB，十倍 20 dB 对场强是 20 dB。
```

:::warning[常见误区]

**误区一**：「过不了认证，最后加个屏蔽罩就行。」
你以为屏蔽是万能补丁——屏蔽罩有缝有线缆孔，**缝隙泄漏随频率升高急剧变糟**（缝像一个隙缝天线），线缆穿过屏蔽体还会把内部共模电流"天线"般带出去。环路面积和地平面在 layout 阶段就定死了，事后改不动。**EMC 是设计出来的，不是补出来的**；改版一次的成本是设计期注意的十倍以上。

**误区二**：「措施按 dB 线性叠加，多叠几层总够。」
数学上 dB 相加的前提是各措施**独立作用于同一机理**。实际里接地不良会把滤波器的共模电流引到电缆上重新辐射——滤波器变成"转发器"；屏蔽罩不接地等于一个谐振腔，有时反而放大。**措施之间有耦合，账本要靠近场探头和频谱仪实测校核，不能只靠加法。**

**误区三**：「我的时钟才 8 MHz，不用管辐射。」
你以为看基频——辐射看的是**边沿谐波的包络**：上升时间越短，谐波能量延伸越高（决定频谱上限的正是上一课提过的带宽-边沿关系）。8 MHz 时钟配 2 ns 边沿，谐波一直铺到几百 MHz。**决定你超不超标的从来不是"数字多快"，而是"边沿多陡"**——所以驱动器里有专门的边沿斜率控制寄存器，慢一点，安静很多。

:::

## 6. 练习

**练习 1**：A=20 cm²、f=100 MHz、I=20 mA、r=3 m 的原始辐射电平。下面代码把分贝换算的系数用错了，修到输出 `84.9`：

```exercise
# @title: 练习：场强换 dB 用错了系数
# @check: 84.9
# @hint: 场强是「幅值」量，分贝换算用 20·log10；用 10·log10 是功率（平方量）的规则
import math
A, f, I, r = 20, 100, 20, 3
E = 0.01316 * f * f * A * I / r            # 场强 µV/m
print(round(10 * math.log10(E), 1))        # ← 问题在这：10 应为 20
```

**练习 2**：一块板超标 52 dB。手头措施的报价：重新布线缩环（改版，−20 dB）、加屏蔽罩（结构，−20 dB）、接口滤波（BOM，−15 dB）、接地整改（工时，−8 dB）。要求余量至少 6 dB，给出最省钱的组合。

<details>
<summary>点开查看逐步解答</summary>

1. 需要 总衰减 ≥ 52 + 6 = 58 dB；
2. 逐项试组合：屏蔽 + 滤波 = 35 dB 不够；缩环 + 屏蔽 + 滤波 = 55 dB，差 3 dB；**全上 = 63 dB，余量 11 dB** ✓；
3. 有没有更便宜的？注意接地整改的 8 dB 最便宜（纯工时）：缩环 + 滤波 + 接地 = 43 dB 不够；缩环 + 屏蔽 + 接地 = 48 dB 不够；
4. 结论：**必须四味药全上**（63 dB，余量 11 dB），或者推动指标端——和客户确认限值等级/工作距离是否可放宽（Class A 场景限值宽松）；
5. 这道题的真正教训：**dB 的世界里没有奇迹**——单味药最多 20 dB，超 50 dB 一定意味着多味药 + 改版，**在原理图阶段就该把环路与接口规划好**，别把 50 dB 的窟窿留到认证前夕。

</details>

## 7. 选读：E ∝ f²·A·I/r 从哪里来

<details>
<summary>选读 · 小环天线（磁偶极子）的远场</summary>

载流小环在电磁学里等效为一个**磁偶极子**，磁矩 $m = I \cdot A$（电流 × 面积）。无线电波一课讲过波动辐射的基本结构：天线把束缚在电路里的场"甩"出去，甩出去的效率取决于天线尺寸相对波长的比例。

磁偶极子的远场（距离 $r \gg \lambda$）电场幅度为

$$E \;\propto\; \frac{k^2\, m}{r}, \qquad k = \frac{2\pi}{\lambda} = \frac{2\pi f}{c}$$

三个因子各就各位：

1. $k^2 \propto f^2$：**波数平方**——这就是"频率翻倍、辐射翻四倍"的来源；
2. $m = I A$：**环路面积与电流**——你布线时圈出的每一平方厘米都在给这根天线充值；
3. $1/r$：**远场衰减**——场随距离线性衰减（功率密度按 $1/r^2$），所以标准统一规定 3 m 测试距离才能互相比对。

把常数与单位换算（µV/m、MHz、cm²、mA、m）整理进一个系数，就得到正文里那个 $1.316\times10^{-14}$。它是**估算式**：真实板子上环不是理想小环、地上还有镜像抵消，实测与估算差 ±6 dB 很正常——**粗算定数量级，仪器定判决**，这是 EMC 工程的标准工作方式。

</details>
