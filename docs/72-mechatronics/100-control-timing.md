# 采样率与控制周期

## 1. 从一个场景开始

上一课的 PID 已经能跑了，还剩一个没敢碰的参数：**控制周期 $T_s$**。设成 1 ms？CPU 几乎全被控制环占满，别的任务没饭吃。设成 200 ms？省是省了——可同一个电机、同一套参数，只是把周期从 20 ms 拖到 200 ms，系统就先振荡、后发散，直接飞车。

采样定理（61 章）早就警告过：采样率不够，高频会伪装成低频。但控制回路比信号处理多一层凶险——**采样之后还有"保持"**：控制器在两次采样之间输出纹丝不动，这段时间对象在"闭着眼"演化。慢采样不只丢信息，还给回路**注入相位滞后**，而相位滞后正是稳定裕度的头号杀手。

这一课回答一个工程必答题：$T_s$ 到底怎么选？

## 2. 直觉解释

想象你开车，但只能**每 $T_s$ 秒睁一次眼**，其余时间握着方向盘不动。

- 睁眼频率高（1 ms）：跟连续开车几乎没差别——但"眨眼率"高耗神（CPU 占用）；
- 睁眼频率低（200 ms）：高速路上还行，弯道一来就糟——你看不见车已经偏了，等下次睁眼时偏差早已扩大，你猛打一把方向；下一睁眼发现打过火了，再反向猛打……**一睁一闭之间的"盲驾"，就是零阶保持**。

盲驾为什么 destabilizing？想想相位：你的修正总是**晚半拍**——平均而言，你的反应落在真实偏差后面 $T_s/2$ 秒。学过 52 章控制的同学对"相位滞后"应该肌肉紧张：每滞后 60°，稳定裕度就薄一层；滞后到 180°，负反馈直接变正反馈，修正变成帮倒忙。

所以选 $T_s$ 的本质是：**盲驾时间不能超过系统能容忍的滞后预算**。系统越快（带宽越高），越经不起闭眼——这就是"采样率取闭环带宽的 10~20 倍"这条工程铁律的来历。

## 3. 正式定义

**零阶保持（ZOH）**：控制器输出在 $[kT_s,\,(k+1)T_s)$ 内保持常数。它对回路的影响近似为一个纯延迟 $T_s/2$，在角频率 $\omega$ 处引入相位滞后

$$\varphi_{ZOH}(\omega) = \frac{\omega T_s}{2} \quad (\text{rad})$$

**一阶对象的精确离散化**：对象 $y' = (u-y)/\tau$ 在 ZOH 下的差分方程（[电机模型](./30-motor-model.md)的简化形态）：

$$y[k+1] = a\,y[k] + (1-a)\,u[k], \qquad a = e^{-T_s/\tau}$$

**纯比例闭环**（$u[k] = K_p(1 - y[k])$，目标值 1）的误差动态为 $e[k+1] = p\, e[k]$，**离散闭环极点**：

$$p = a - (1-a)K_p$$

稳定性判据（引用离散系统理论）：$|p| < 1$ 稳定；$-1 < p \le 0$ 振荡收敛（有超调）；$p \le -1$ 发散。注意**连续时任意 $K_p > 0$ 都稳定**的一阶对象，离散化后竟然会发散——离散化收窄了稳定域。

**临界周期**：令 $p = -1$ 解出 $a = \frac{K_p-1}{K_p+1}$，即

$$T_{s,crit} = \tau \ln\frac{K_p+1}{K_p-1} \quad (K_p > 1)$$

**工程经验法则**：采样频率取闭环带宽的 10~20 倍，

$$f_s = \frac{1}{T_s} \ge 10 \sim 20 \times f_{bw}, \qquad f_{bw} \approx \frac{1+K_p}{2\pi\tau}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $T_s$ | 控制周期 | 秒 s | 两次控制计算之间的间隔 |
| $a$ | 离散化系数 | — | $e^{-T_s/\tau}$，$T_s$ 越大越接近 0 |
| $p$ | 离散闭环极点 | — | 误差每拍衰减到 $p$ 倍 |
| $\tau$ | 对象时间常数 | 秒 s | 对象的"快慢" |
| $f_{bw}$ | 闭环带宽 | Hz | 系统能跟踪的最高频率 |

## 4. 分步例题

**例**：$\tau = 0.2$ s，$K_p = 4$。求临界周期、经验周期上限，以及 $T_s = 20$ ms、100 ms、110 ms 三个点的极点与稳定性。

1. **临界周期**：$T_{s,crit} = 0.2 \ln\frac{5}{3} = 0.2 \times 0.5108 = 0.1022$ s = **102.2 ms**；
2. **经验法则**：$f_{bw} = \frac{1+4}{2\pi \times 0.2} = 3.98$ Hz，$T_s \le \frac{1}{10 f_{bw}} = 25.1$ ms；
3. **$T_s = 20$ ms**：$a = e^{-0.1} = 0.9048$，$p = 0.9048 - 0.0952\times4 = 0.524$，$0 < p < 1$：单调稳定；
4. **$T_s = 100$ ms**：$a = e^{-0.5} = 0.6065$，$p = 0.6065 - 0.3935\times4 = -0.967$，$-1 < p < 0$：振荡收敛，超调严重；
5. **$T_s = 110$ ms**：$a = e^{-0.55} = 0.5770$，$p = 0.5770 - 0.4230\times4 = -1.115$，$p < -1$：**发散**。

对照三个数：经验法则给 25 ms（保守、留裕度），临界周期 102 ms（理论悬崖边）。100 ms 时离悬崖只差 2 ms 却已振荡得一塌糊涂——**工程上永远按经验法则选，离理论极限远一点**。

顺带算相位滞后验证直觉：$T_s = 100$ ms 时 $\varphi = \omega_{bw} T_s /2 = \frac{1+K_p}{\tau}\cdot\frac{T_s}{2} = 25 \times 0.05 = 1.25$ rad $\approx 72°$——早就越过 60° 的危险线了。

## 5. 动手实验

### 实验 1（lab）：把 Ts 从 1 ms 拖到发散

```lab
{
  "type": "control-timing",
  "title": "控制周期：从平稳到振荡到发散",
  "Ts": 20,
  "Kp": 4,
  "tau": 0.2
}
```

画面两层：

- **上：阶跃响应**。实线是当前 $T_s$ 的响应，灰色虚线是 1 ms 的参照组（近似连续控制）。横轴底部的短刻度线是采样节拍——每个节拍看一眼、算一次，中间盲驾；
- **下：$T_s$ 稳定性地图**。绿色区（$p>0$）单调、黄色区（$-1<p\le0$）振荡收敛、红色区（$p\le-1$）发散；绿虚线是经验法则画出的"安全线"，白线是当前 $T_s$ 的指针。

按顺序做：

- **把 Ts 慢慢从 20 ms 拖到 200 ms**：曲线先变得台阶粗糙（保持痕迹），然后开始振铃，进入红区后振幅指数放大——**同一个对象、同一个 $K_p$，只有 $T_s$ 在变**；
- **把 Kp 拖到 1 以下再扫 Ts**：地图整条变绿——临界周期公式里 $K_p \le 1$ 时取不到正数，任意 $T_s$ 都不发散（但太慢依然难用，稳定≠好用）；
- **把 Kp 拖到 8**：红区大幅左移，临界周期缩到几十毫秒——**增益越高，对采样率越敏感**，因为高增益系统"更急"，等不起盲驾；
- **看"相位滞后"读数**：把它和"稳定性"读数对照，>60° 时基本都已进入黄区。

### 实验 2（python）：亲手算离散极点

```python
import math                      # 数学库：exp、log、pi 等函数

tau = 0.2      # 对象时间常数 s
Kp = 4.0       # 比例增益

def pole(Ts):
    # ZOH 离散化后闭环误差 e[k+1] = p·e[k] 的极点
    a = math.exp(-Ts / tau)
    return a - (1 - a) * Kp

print(f"临界周期 = {tau * math.log((Kp + 1) / (Kp - 1)) * 1000:.1f} ms")
print(f"经验上限 = {1000 / (10 * (1 + Kp) / (2 * math.pi * tau)):.1f} ms（带宽的 10 倍采样）")
print()
for Ts in [0.001, 0.01, 0.02, 0.05, 0.1, 0.11, 0.2]:
    p = pole(Ts)
    verdict = "单调稳定" if p > 0 else ("振荡收敛" if p > -1 else "发散")
    print(f"Ts = {Ts*1000:6.0f} ms:  p = {p:+.3f}   {verdict}")
```

输出会显示极点从 0.6 左右（1 ms）一路滑到 −0.967（100 ms）再到 −1.115（110 ms）越过 −1。对照顶部两行：**经验法则的 25 ms 比临界值 102 ms 严了 4 倍**——这不是浪费，第 4 步的例题展示了贴着极限走（100 ms）的下场。

### 快问快答

```quiz
同一套系统，为什么提高 Kp 之后需要更短的 Ts 才稳定？
- 因为高增益让系统带宽更高，能跟踪更快的变化，盲驾半拍的滞后按比例变得不可容忍 [*]
- 因为 Kp 大了计算量也大，算慢了 CPU 跟不上
- 因为 Kp 大会放大量化噪声，必须快点采样去平均掉
? 相位滞后 ω·Ts/2 里的 ω 是回路穿越频率：Kp 越大穿越频率越高，同样的 Ts 折算成更多度的滞后。临界周期公式 τ·ln((Kp+1)/(Kp−1)) 随 Kp 增大而严格递减，也是同一件事的解析表达。
```

:::warning[常见误区]

**误区一**："采样率越高控制越好，CPU 反正越来越快。"
你只看到稳定裕度——其实采样率翻 10 倍，CPU 占用翻 10 倍（下一课的实时任务就要抢这份预算）；高频采样还把传感器噪声原封不动搬进控制量，等于给执行机构注入抖动；PWM 分辨率也限制着高频率下还能不能调出足够细的控制量。**带宽 10~20 倍是甜点区，不是下限的将就**。

**误区二**："系统稳定就说明 Ts 选对了。"
你以为不发散就及格——其实 $T_s = 100$ ms 的例子稳定（$p=-0.967$）却振铃得没法用，且抗扰恢复慢一拍就是一整个 $T_s$。选 $T_s$ 要问的是：**扰动抑制、噪声传递、离散化误差、CPU 预算**四个约束取交集，稳定性只是入场券。

**误区三**："采样慢点没关系，我可以在两次采样之间多做滤波/插值补偿。"
你以为软件能补回盲驾的信息——其实 $T_s$ 之内的对象动态**根本没被测量**，任何插值都是猜测；滤波器自己还引入额外滞后。信息一旦没采到，后处理变不出来——这是采样定理（61 章）的立场，也是它出现在本课 prereqs 里的原因。

:::

<summary>点开查看逐步解答</summary>

1. **临界周期**：$T_{s,crit} = 0.05\ln\frac{7}{5} = 0.05 \times 0.3365 = 16.8$ ms；

   - 相位滞后 $\frac{1+K_p}{\tau}\cdot\frac{T_s}{2} = 140 \times 0.0075 = 1.05$ rad ≈ 60°，已经踩线。
4. 结论：选 $T_s \approx 4$ ms。此时 $p = e^{-0.08} - (1-e^{-0.08})\times6 = 0.923 - 0.462 = 0.461$，单调、快速、离悬崖 3 个数量级远。

**"离理论极限多远"本身就是设计参数**——这就是鲁棒裕度思想在采样率上的体现。

## 7. 选读：临界周期公式的推导

<details>
<summary>选读 · 三行解出 Ts 的悬崖在哪</summary>

一阶对象 ZOH 精确离散：$y[k+1] = a y[k] + (1-a)u[k]$，$a = e^{-T_s/\tau}$。代入比例控制 $u[k] = K_p(1 - y[k])$：

$$y[k+1] = a y[k] + (1-a)K_p - (1-a)K_p\, y[k] = (1-a)K_p + \bigl[a - (1-a)K_p\bigr] y[k]$$

稳态值 $y^*$ 满足 $y^* = (1-a)K_p + p\,y^*$，解得 $y^* = \frac{(1-a)K_p}{1-p} = \frac{K_p}{1+K_p}$（与连续情况一致——比例控制消不掉稳态误差，采样不改变这一点）。令偏差 $\delta[k] = y[k] - y^*$：

$$\delta[k+1] = p\,\delta[k], \qquad p = a - (1-a)K_p$$

发散边界 $p = -1$：$a - (1-a)K_p = -1 \Rightarrow a(1 + K_p) = K_p - 1 \Rightarrow a = \frac{K_p-1}{K_p+1}$。两边取对数并乘 $\tau$：

$$T_{s,crit} = \tau \ln\frac{K_p+1}{K_p-1}$$

两个极限值得一看：$K_p \to 1^+$ 时 $\ln\frac{K_p+1}{K_p-1} \to \infty$——低增益永远不发散；$K_p \to \infty$ 时公式 $\to \tau \ln 1 = 0$——无限增益要求无限快采样，与"继电器bang-bang控制在连续时间才能成立"的直觉吻合。

顺带一提：极点 $p$ 从 $+a$（$K_p=0$）随 $K_p$ 线性递减穿过 0 进入负值——**振荡不是外界打扰出来的，是离散极点自己走到负半轴**。负极点意味着误差每拍变一次号，这正是你在实验里看到的振铃。

</details>
