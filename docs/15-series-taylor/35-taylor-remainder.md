# 泰勒余项：多项式差多远

## 1. 从一个场景开始

上一课的误差表现身说法：在 $x=0.5$，两项近似误差只有万分之三；到了 $x=6$，同样两项差出一百倍。计算器敢只算十来项就停机——它凭什么知道"停在 10 项，误差一定埋不进第 8 位小数"？靠感觉？不靠。数学家给泰勒多项式配了一块**误差仪表**：不用算出真值，就能先验地承诺"多项式最多差多远"。这块仪表叫**拉格朗日余项**，本课把它装进你的工具箱。

## 2. 直觉解释

余项就是**被丢掉的尾巴**。截断到 $x^5$，从 $x^7$ 起的所有项都被扔了——真误差就是这串被扔掉的项之和。

谁统治尾巴的大小？**被扔掉的第一个非零项**。因为阶乘分母暴涨得比任何幂都快，每一项都比前一项小一大截，尾巴里最大的就是排头兵——排头兵有多小，整条尾巴就差不到哪去。

更妙的是数学家不止满足于"量级估计"，他们写出了精确账本：

$$f(x) - P_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\,x^{n+1}$$

右边叫**拉格朗日余项**。那个 $\xi$ 是某个夹在展开点与 $x$ 之间的中间点——定理只承诺它存在，不告诉你住址。别嫌地址保密：算上保险根本用不着 $\xi$ 本人，只需要给 $\left|f^{(n+1)}\right|$ 找个天花板 $M$。

## 3. 正式定义

**带拉格朗日余项的泰勒公式**：设 $f$ 足够光滑，则

$$f(x) = P_n(x) + R_n(x), \qquad R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\,(x-a)^{n+1}$$

其中 $P_n$ 是 $n$ 次泰勒多项式，$\xi$ 夹在 $a$ 与 $x$ 之间。

| 符号 | 名字 | 一句话解释 |
| --- | --- | --- |
| $P_n(x)$ | n 次泰勒多项式 | 级数截断后的正式户 |
| $R_n(x)$ | 余项 | 真值减多项式值：被丢尾巴的精确记账 |
| $\xi$ | 中间点 | 夹在 $a$ 与 $x$ 之间，只承诺存在不给地址 |
| $M$ | 导数天花板 | $\left|f^{(n+1)}\right|$ 在这段区间的最大值 |

**上保险推论**：只要区间上 $\left|f^{(n+1)}\right| \le M$，就有

$$\left|R_n(x)\right| \le \frac{M\,\left|x-a\right|^{n+1}}{(n+1)!}.$$

$\sin$（以及 $\cos$）有个福利：偶次项系数全为 0，截到 $x^{2n-1}$ 的多项式其实就是个 $2n$ 次多项式，于是 $n$ 取 $2n$——余项按下一个非零项算：

$$\left|R\right| \le \frac{\left|x\right|^{2n+1}}{(2n+1)!}.$$

看穿零系数，白捡一次方，上界立刻紧一个量级。

## 4. 分步例题

**给 $\sin(1)$ 的三项近似上保险。**

1. 写多项式：$P = 1 - \dfrac{1}{6} + \dfrac{1}{120} = \dfrac{101}{120} \approx 0.841667$（截到 $x^5$，三个非零项）；
2. 定天花板：把 $P$ 看作 6 次多项式（$x^6$ 系数为 0），余项要看 7 阶导数。$\sin$ 求导四步一循环，7 阶导数是 $-\cos$，而 $\left|\cos\xi\right| \le 1$——取 $M=1$；
3. 算上界：$\left|R\right| \le \dfrac{1^7}{7!} = \dfrac{1}{5040} \approx 0.000198$；
4. 对拍真误差：$\left|\sin(1) - \dfrac{101}{120}\right| \approx 0.000196$——被 $0.000198$ 死死罩住；
5. 结论：全程没用过 $\sin(1)$ 的值，就敢担保误差小于万分之二——小数点后三位锁死。这就是"先验保险"：先承诺，后计算。

还是上一课那台机器，这次换一双眼睛：切换函数、拖动蓝点，专盯"误差"读数。两个必做任务：

- 固定蓝点在 $x=1.2$ 附近，把项数从 3 拉到 4——误差读数当场塌成 0.0000（读数只保留四位小数，"一加一项就塌零"正是砍掉两个以上数量级的铁证；精确数值见前面例题的账本）；
- 切到 $e^x$，把蓝点拖到 $x=3$：读出误差后心算一下"下一项量级" $\dfrac{3^{n+1}}{(n+1)!}$（$e^x$ 各阶导数全是 $e^\xi \le e^3 \approx 20$，$M$ 取 20 就够）——真误差果然被它罩住。

### 实验 2（python）：真误差 vs 上界，逐项对拍

```python title="拉格朗日上界给真误差上保险：sin 在 x=1 与 x=6"
import math

def taylor_sin(x, terms):
    total = 0.0                          # 多项式累加器
    for n in range(terms):               # terms 个非零项：x、x^3、x^5、...
        sign = (-1) ** n                 # (-1)**n：+1、-1 交替的符号开关
        total = total + sign * x ** (2 * n + 1) / math.factorial(2 * n + 1)
    return total

def upper_bound(x, terms):
    # sin 缺偶次项：把 P 视为 2*terms 次多项式，上界 = |x|^(2k+1)/(2k+1)!
    k = 2 * terms + 1
    return abs(x) ** k / math.factorial(k)

for x in [1.0, 6.0]:
    for terms in [2, 4, 8]:
        err = abs(taylor_sin(x, terms) - math.sin(x))   # 真误差：近似值离真值多远
        bound = upper_bound(x, terms)                   # 理论保险额度
        print(f"x = {x}, 取 {terms} 项: 真误差 {err:.2e}, 上界 {bound:.2e}, 罩住 {bound >= err}")
```

（`{err:.2e}` 是格式化写法：把数打成两位小数的科学计数法，比如 `8.14e-03` 就是 $8.14\times 10^{-3}$。）

读表：六行全部 `True`——上界无一失手。$x=1$ 时真误差与上界咬得极近（§4 例题的三项截断账：$1.96\times10^{-4}$ 对 $1.98\times10^{-4}$，只差 1%）；$x=6$ 时上界松一些（$2.05\times10^{+1}$ 对 $2.77\times10^{+1}$）——因为 $\xi$ 夹在 0 与 6 之间，总有 $\left|\cos\xi\right|$ 小于 1 的位置帮真误差"省钱"。松不是缺点：上界的本职是**不开先算就敢承诺**。

### 快问快答

```quiz
把 sin 的泰勒多项式截到 x 的 5 次方（含该次项），用拉格朗日余项估误差，分母上的阶乘应该是几的阶乘？
- 5 的阶乘：余项就是最后一项
- 6 的阶乘：多项式是 6 次的，余项看 6 次方
- 7 的阶乘：sin 没有偶次项，余项要看下一个非零项 [*]
? 截到 5 次方后多项式其实是 6 次的，但 6 次系数为零——余项按被丢掉的第一个非零项算，量级是 x 的 7 次方除以 7 的阶乘。
```

::::warning[常见误区]

**误区一**："你以为余项就是最后一项。" 其实余项的量级是**被丢掉的下一个非零项**：截到 $x^5$，上界是 $\dfrac{x^7}{7!}$，不是 $\dfrac{x^5}{120}$。保险额度看排头兵，不看队尾。

**误区二**："你以为上保险得先把 $\xi$ 找出来。" 其实永远不用——定理只承诺存在。整条流水线只需要导数天花板 $M$，而 $\sin/\cos$ 的 $M$ 干脆就是 1。

**误区三**："你以为上界松就是失败。" $x=6$ 处上界 27.77 罩着真误差 20.46，松了 35%——可它是唯一"一个字都不用算就能许诺"的额度。数值误差要算完才知道，保险额度在动手前就生效。

::::

## 6. 练习

**练习 1**：下面的代码在给 $\sin(1)$ 的三项近似配保险，能跑，但保险额度配错了。改到通过判题：

```exercise
# @title: 练习：给 sin(1) 的三项近似换上正确的保险
# @check: 0.000196
# @check: 0.000198
# @check: covered
# @hint: 截到 x 的 5 次方后，sin 的偶次项全为零——多项式其实是 6 次的，余项要看下一个非零项：x 的 7 次方除以 7 的阶乘
import math

x = 1.0
approx = x - x ** 3 / 6 + x ** 5 / 120   # 三项泰勒多项式（这行是对的）
err = abs(math.sin(x) - approx)          # 真误差（这行也是对的）
bound = x ** 5 / math.factorial(5)       # ← 保险额度配错了：这是"最后一项"，不是余项
print(round(err, 6))
print(round(bound, 6))
print("covered" if bound >= err else "leaked")
```

<details>
<summary>点开查看逐步解答</summary>

真误差与第三行本来就对：$\dfrac{101}{120}$ 与 $\sin(1)$ 差 $0.0001957$，四舍五入到 6 位是 `0.000196`。错在保险额度：$\dfrac{x^5}{5!}$ 是多项式的最后一项，而余项的量级是**被丢掉的下一个非零项**——$\sin$ 缺偶次项，下一项是 $x^7$：

```python
bound = x ** 7 / math.factorial(7)   # 上界 = 1/5040 ≈ 0.000198
```

四舍五入到 6 位是 `0.000198`。额度 $0.000198 \ge$ 真误差 $0.000196$，第三行打出 `covered`。上界只比真误差大 1%——$\sin$ 的余项公式紧得惊人。
</details>

**练习 2**：第 15 章 index 的实战挑战里，欧拉的阶乘级数只用了 19 轮就把 $e$ 锁死到十位小数。用余项公式解释这口气为什么这么足。

<details>
<summary>点开查看逐步解答</summary>

$e^x$ 在 $x=1$ 处截断到 $n$ 次，余项上界为 $\dfrac{e^\xi}{(n+1)!}$，而 $\xi \in [0,1]$ 时 $e^\xi < 3$，所以

$$\left|R_n(1)\right| < \frac{3}{(n+1)!}.$$

$n=19$ 时 $\dfrac{3}{20!} \approx 1.2\times 10^{-18}$——远小于 $10^{-10}$。也就是说**不用数到 19 也行**：解不等式 $\dfrac{3}{(n+1)!} < 10^{-10}$，$n+1 \ge 14$ 就够了（$14! \approx 8.7\times 10^{10}$）。欧拉锁死十位，理论上 14 轮就够——余项公式把"要加多少项"从玄学变成了可解的不等式。
</details>

## 7. 选读：拉格朗日余项从哪来

<details>
<summary>选读 · 柯西中值定理滚 n+1 轮</summary>

要给 $f(x) - P_n(x)$ 与 $(x-a)^{n+1}$ 的比值记账，反复使用柯西中值定理（它的正式舞台在卷二 [中值定理与洛必达法则](../19-real-analysis/35-mean-value-lhopital.md)）：两函数比值等于某中间点导数之比。

第 1 轮：分子 $f(x)-P_n(x)$ 在 $a$ 处为零（多项式贴着函数造），对分子分母用一次柯西中值——分子变成 $f'(\xi_1) - P_n'(\xi_1)$，分母变成 $(n+1)(\xi_1-a)^n$；

第 2 轮：在 $a$ 处分子分母**又**同时为零（$P_n$ 的前 $n$ 阶导数都在 $a$ 处与 $f$ 对齐），再滚一次——分子剩 $f''-P_n''$，分母掉下 $(n+1)n$；

如此 $n+1$ 轮后，$P_n$ 的 $(n+1)$ 阶导数是 0，分子只剩 $f^{(n+1)}(\xi)$，分母只剩 $(n+1)(n)\cdots 2\cdot 1 = (n+1)!$。每轮 $\xi$ 都换一次地址，最后一轮住下的那个，就是拉格朗日余项里的中间点。整套戏法的关键道具：**泰勒多项式是按"前 n 阶导数逐阶对齐"定制的，所以每轮柯西中值分子分母都同时归零**——余项公式不是从天而降的估计，是逐阶对齐的必然账单。

</details>
