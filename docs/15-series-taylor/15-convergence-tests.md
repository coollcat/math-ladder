# 收敛判别法：比较、比值与 p-级数分水岭

## 1. 从一个场景开始

第 14 章反常积分课埋过一句话：$\dfrac{1}{x^2}$ 从 1 到无穷积出有限面积，$\dfrac{1}{x}$ 却积出一望无际——"指数大于 1 收敛、不超过 1 发散"的分水岭当时只种下直觉，正课现在开讲。把积分换成求和：$\sum \dfrac{1}{n^2}$ 收敛，$\sum \dfrac{1}{n}$ 发散，同样的分水岭原样重现。

更要命的是竞速问题：拿到一个新级数，怎么不硬算就能判决命运？调和级数教会我们"通项变小"不算数，那什么才算数？本课发三件判官工具：**p-级数分水岭**（对照标准）、**比较判别法**（跟跑判决）、**比值判别法**（测衰减倍率）。它们合起来，能判决绝大多数见过会面的级数。

## 2. 直觉解释

**分水岭想象**：把级数想成一队人往一口井里填土，每人的土越带越少。填不填得满，不看"少不少"，看**少的速度**：按 $1/n$ 的速度变少——井永远差得远；按 $1/n^2$ 的速度变少——总土量封顶。$p = 1$ 恰好卡在临界线上：慢一分填不满，快一分能填满。

**比较判别法**像跟跑：你的每一步都不超过身边这位选手，他停在终点，你必然停在终点（他爆掉，你若每步都比他多，你也爆）。

**比值判别法**像看油门：每一步是上一步的多少倍？倍率稳定小于 1——几何级数式的雪崩式缩小，必停；稳定大于 1——越滚越大，必爆；恰好等于 1——仪表失灵，得换工具。

## 3. 正式定义

**p-级数**：

$$\sum_{n=1}^{\infty} \frac{1}{n^p} \qquad \begin{cases} p > 1 & \text{收敛} \\ p \le 1 & \text{发散} \end{cases}$$

$p = 2$ 时收敛（部分和封顶在 $\dfrac{\pi^2}{6} \approx 1.645$ 附近——这个精确值属于著名的巴塞尔问题，本书暂按下不表）；$p = 1$ 就是调和级数，发散；$p = \frac12$ 发散得更欢（部分和约 $2\sqrt{N}$ 地涨）。

**比较判别法**：设 $0 \le a_n \le b_n$（对足够大的 n 成立即可）：

| 基准级数 $\sum b_n$ | 跟跑者 $\sum a_n$ | 判决 |
| --- | --- | --- |
| 收敛 | 每项都更小 | 收敛 |
| 发散 | 每项都更大 | 发散 |

注意单向性：基准发散、跟跑者更小，**什么也判不了**（$\frac{1}{n^2} < \frac{1}{n}$，前者收敛后者发散——两边都有可能）。

**比值判别法**：算相邻项之比的极限 $L = \lim\limits_{n\to\infty} \dfrac{a_{n+1}}{a_n}$：

| $L$ 值 | 判决 | 理由 |
| --- | --- | --- |
| $L < 1$ | 收敛 | 项按 $(L+\varepsilon)^n$ 的几何速度缩小 |
| $L > 1$ | 发散 | 项越滚越大，通项连 0 都到不了 |
| $L = 1$ | 无结论 | 仪表失灵：$\sum\frac{1}{n}$ 与 $\sum\frac{1}{n^2}$ 的比值极限都是 1 |

## 4. 分步例题

**例 1**（比较）：判断 $\sum \dfrac{1}{n^2 + n}$ 的命运。

1. 找基准：分母多了一个 $n$，于是 $\dfrac{1}{n^2+n} < \dfrac{1}{n^2}$；
2. 基准 $\sum \dfrac{1}{n^2}$ 是 $p = 2 > 1$ 的 p-级数，收敛；
3. 跟跑者每项更小、基准收敛——收敛。精确版彩蛋：$\sum \dfrac{1}{n^2+n} = 1$（裂项相消）。

**例 2**（比值）：判断 $\sum \dfrac{2^n}{n!}$ 的命运。

1. 写比值：$\dfrac{a_{n+1}}{a_n} = \dfrac{2^{n+1}}{(n+1)!} \cdot \dfrac{n!}{2^n} = \dfrac{2}{n+1}$；
2. 取极限：$L = \lim \dfrac{2}{n+1} = 0 < 1$；
3. 判决：收敛——阶乘在分母里越长越快，把 $2^n$ 的指数脾气压得毫无还手之力。

**例 3**（比值失灵现场）：$\sum \dfrac{1}{n^2}$ 的比值是 $\dfrac{n^2}{(n+1)^2} \to 1$，$\sum \dfrac{1}{n}$ 的比值是 $\dfrac{n}{n+1} \to 1$——一个收敛一个发散，$L = 1$ 的仪表对谁都不给读数。幂函数对幂函数，请回比较判别法。

怎么玩：橙线（$p=2$）比蓝线（$p=1$）只矮一点，可正是这一点差距决定生死——14 章的"渐进像不代表同命"在这里重演。两条曲线下的面积对应各自的"连续版"积分：橙线封顶，蓝线无界。

### 实验 2（python 滑块）：亲手摸到 p = 1 分水岭

```python title="p-级数探针：拖动 p 找分水岭"
# sliders: p=1.5 [0.5:2.0:0.05]

n_max = 1000                        # 加到第一千项
total = 0.0                         # 部分和累加器（第 8 章的老手艺）
for k in range(1, n_max + 1):       # k 从 1 数到 1000
    total = total + 1 / k ** p      # 当前项是 1/k^p（** 是乘方）

print(f"p = {p}: 前一千项部分和 = {round(total, 3)}")
```

怎么玩：p 从 2.0 往下拖——$p=2$ 时部分和约 1.64（离 $\pi^2/6\approx1.645$ 已经不远）；$p=1.5$ 约 2.55；拖到 $p=1.0$，读数约 7.49，正是调和级数 $H_{1000}$；再往下 $p=0.5$，读数猛涨到约 61.8（$\approx 2\sqrt{1000}$）。**分水岭不在"数字大小"，在 $p$ 与 1 的相对位置**。

### 实验 3（python）：比值探针——三种衰减性格

```python title="相邻项之比：谁雪崩、谁踱步"
for n in [10, 100, 1000]:
    r_fact = 2.0 / (n + 1)                 # 2^n/n! 的相邻项之比
    r_pow2 = n ** 2 / (n + 1) ** 2         # 1/n^2 的相邻项之比
    r_harm = n / (n + 1)                   # 1/n 的相邻项之比
    print(f"n={n}: 阶乘款 {round(r_fact, 4)} | 1/n^2 款 {round(r_pow2, 4)} | 1/n 款 {round(r_harm, 4)}")
```

怎么玩：三列读数、三种性格——阶乘款的比值一路冲向 0（雪崩式收敛，比值判别法一锤定音）；两个幂函数款的比值都滑向 1（仪表失灵，判决要回 p-级数分水岭）。比值探针报"性格"，p-分水岭给"判决"，两件工具配合使用。

### 快问快答

```quiz
比值判别法算出 L 恰好等于 1，能下判决吗？
- 能：L=1 说明级数发散
- 能：L=1 说明级数收敛
- 不能：L=1 时仪表失灵，收敛发散都有可能 [*]
? 1/n 与 1/n^2 的比值极限都是 1，命运却一个发散一个收敛。L=1 是比值法的盲区，请改用比较判别法或 p-级数分水岭。
```

::::warning[常见误区]

**误区一**："你以为通项趋于 0 就稳了。" 调和级数通项 $\frac{1}{n} \to 0$ 照样发散——必要条件不等于判据，衰减的**速度**才是主角。

**误区二**："你以为基准发散，跟跑者必发散。" 比较判别法是单向的：$a_n \le b_n$ 且 $\sum b_n$ 发散时，跟跑者可收敛可发散（$\frac{1}{n^2}$ 和 $\frac{1}{n}$ 都比 $\frac{2}{n}$ 小）。方向别接反。

**误区三**："你以为 $L = 1$ 就当场判死。" $L=1$ 只说明比值法**说不了话**，不是发散判决书。幂对幂（$n$ 与 $n^2$ 只差一个常数次幂）是它的标准盲区。

::::

**练习 2**：用比较判别法判决 $\sum \dfrac{1}{n^3 + 1}$。

<details>
<summary>点开查看逐步解答</summary>

分母比 $n^3$ 还大，所以 $\dfrac{1}{n^3+1} < \dfrac{1}{n^3}$；基准 $\sum \dfrac{1}{n^3}$ 是 $p = 3 > 1$ 的 p-级数，收敛；跟跑者每项更小——**收敛**。口诀：分母多项式只留最高次项，与基准对表。
</details>

**练习 3**：$\sum \dfrac{3^n}{n!}$ 收敛还是发散？比值判别法走一遍。

<details>
<summary>点开查看逐步解答</summary>

$\dfrac{a_{n+1}}{a_n} = \dfrac{3^{n+1}}{(n+1)!} \cdot \dfrac{n!}{3^n} = \dfrac{3}{n+1} \to 0 < 1$——**收敛**。而且这个读数还预告了收敛的速度：过了 $n = 3$，项就开始雪崩式缩小。阶乘压指数，压得干脆利落。
</details>

## 7. 选读：p > 1 为什么封顶

<details>
<summary>选读 · 一条伸缩链锁住 1/n²</summary>

要证 $\sum \dfrac{1}{n^2}$ 收敛，不必知道精确和，只要把它锁在一个有限的天花板下。对 $n \ge 2$：

$$\frac{1}{n^2} < \frac{1}{n(n-1)} = \frac{1}{n-1} - \frac{1}{n}$$

右边是**伸缩链**：$\left(1 - \frac12\right) + \left(\frac12 - \frac13\right) + \left(\frac13 - \frac14\right) + \cdots$，中间项两两相消，整串和恰好等于 $1$。于是

$$\sum_{n=2}^{\infty} \frac{1}{n^2} < 1, \qquad \sum_{n=1}^{\infty} \frac{1}{n^2} < 2.$$

天花板 $2$ 一钉，收敛判决生效。而 $p = 1$ 的调和级数偏偏没有这样的天花板（第 10 课选读的分组证明让它每组都偷走半个 1）——分水岭两侧，一侧有界一侧无界。顺带一提：$\sum \frac{1}{n^2}$ 的精确值是 $\frac{\pi^2}{6}$——巴塞尔问题的答案，证明超出本书目前进度，先记下这笔悬案。

</details>
