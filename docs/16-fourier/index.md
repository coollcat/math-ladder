# 傅里叶：让波形露出频率配方

这是卷一的枢纽站，也是最惊人的一站。200 多年前傅里叶下一个赌注：**很广的一类周期波形——方波、锯齿、心电图、交响乐——都能拆成一堆不同频率的正弦波叠加**。圆滑的正弦怎么可能拼出棱角分明的方波？在一定条件下确实能，而且只需要一条规则：频率取整数倍，份量各就各位。

这个赌注后来成了现代世界的底层协议：

- **MP3** 把音乐拆成正弦成分，扔掉人耳听不见的那些，体积缩到十分之一；
- **JPEG** 对图像做同样的事，照片才能塞进手机；
- **降噪耳机** 分析噪声的频率配方，现场调一杯"反相位鸡尾酒"浇灭它；
- 甚至**量子力学**里，"粒子既有波动性"这句话的数学骨架就是本章的展开式。

从 $1+1$ 出发走了十五章，你手里的工具恰好在这章全部合流：第 7 章的正弦、第 11 章的基与坐标、第 12 章的欧拉公式、第 13~14 章的微积分——它们等这一刻很久了。

## 实战挑战 · 一段脑电的频率体检

> 场景说明：临床与神经工程把脑电（EEG）按频率分带——δ 带 1~4 Hz、θ 带 4~8 Hz、α 带 8~13 Hz、β 带 13~30 Hz（频带划分为通用约定）。本题信号为教学用合成数据，情境原创。

体检报告写着"闭眼静息"。你拿到一段 **128 点**的脑电采样，采样率 $f_s = 128$ Hz，恰好记录 1 秒。信号由三个正弦成分叠加而成：

- 成分一：振幅 0.4，频率 2 Hz；
- 成分二：振幅 1.0，频率 10 Hz；
- 成分三：振幅 0.3，频率 25 Hz。

实验里 $f_s = N = 128$，桶宽正好 1 Hz，所以 k 号桶就是 k Hz（65 号课的换算公式 $f = k\cdot f_s/N$）。你的任务：给这段脑电做一次"频率体检"，判断它像不像教科书里的闭眼 α 节律。

**(a)** 用 DFT 读出 10 Hz 成分的桶幅度，保留一位小数（提示：纯音恰落在整数桶上时，桶幅度 = 振幅的一半）；
**(b)** 找出最强成分所在的频带，按频带表打印它的英文名（delta / theta / alpha / beta 四选一）；
**(c)** 思辨：若采样率降到 100 Hz，一个真实的 60 Hz γ 波成分还能被正确观测吗？会变成什么？

```exercise
# @title: 实战挑战 · 一段脑电的频率体检
# @check: 0.5
# @check: alpha
# @hint: (a) 桶幅度 = 振幅的一半；(b) 先比较三个成分谁的振幅最大，再用频带表把它的频率翻译成英文名
import math                     # 数学工具库：用 pi、sin 和 hypot

N = 128                         # 采样点个数
fs = 128                        # 采样率（Hz）
sig = []                        # 脑电采样列表
for n in range(N):
    t = n / fs                  # 第 n 个采样点对应的时刻（秒）
    v = 0.4 * math.sin(2 * math.pi * 2 * t)      # 成分一：2 Hz
    v = v + 1.0 * math.sin(2 * math.pi * 10 * t) # 成分二：10 Hz
    v = v + 0.3 * math.sin(2 * math.pi * 25 * t) # 成分三：25 Hz
    sig.append(v)

def mag(k):                     # 第 k 个频率桶的幅度（65 号课的原班机器）
    re = 0.0                    # 实部账本
    im = 0.0                    # 虚部账本
    for n in range(N):
        ang = 2 * math.pi * k * n / N
        re = re + sig[n] * math.cos(ang)
        im = im - sig[n] * math.sin(ang)
    return math.hypot(re, im) / N

print(round(mag(10), 1))        # (a) 10 Hz 桶的幅度
print()                         # (b) 在引号里写出最强成分所在频带的名字
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 三个频率都落在整数桶上（k = 频率值），桶间正交互不串扰（20 号课），每个纯音的桶幅度都是振幅的一半：mag(2) = 0.2，mag(10) = **0.5**，mag(25) = 0.15。

**(b)** 振幅最大的成分是 1.0 @ 10 Hz；对照频带表，8~13 Hz 属于 **alpha** 带——这正是闭眼静息时枕区 α 节律的教科书表现，与体检报告吻合。

**(c)** 不能。奈奎斯特上限是 $\frac{f_s}{2} = 50$ Hz，60 Hz 的 γ 波超过了它，采样时会**混叠**成假扮的低频：$|60 - 100| = 40$ Hz 的假象（65 号课误区一）。于是谱图上会在 40 Hz 处立起一根冒牌峰——频率读数彻底失真：若只看谱峰位置，会把它当成一段真实存在的脑电活动。这就是临床 EEG 设备要用抗混叠滤波器先砍掉半采样率以上成分的原因。

验证代码：

```python
import math

N = 128
fs = 128
sig = []
for n in range(N):
    t = n / fs
    v = 0.4 * math.sin(2 * math.pi * 2 * t) + 1.0 * math.sin(2 * math.pi * 10 * t) + 0.3 * math.sin(2 * math.pi * 25 * t)
    sig.append(v)

def mag(k):
    re, im = 0.0, 0.0
    for n in range(N):
        ang = 2 * math.pi * k * n / N
        re = re + sig[n] * math.cos(ang)
        im = im - sig[n] * math.sin(ang)
    return math.hypot(re, im) / N

for f in [2, 10, 25]:
    print(f"{f} Hz 桶幅度:", round(mag(f), 2))
```
</details>

## 实战挑战 · 正交性：不同频率互不干扰

傅里叶能"拆波"的底气是正交性：不同频率的正弦在离散点上做内积，结果为零。下面这题把两个频率写成了同一个，内积立刻飙到 32，修到输出 `0.0`：

```exercise
# @title: 实战挑战：不同频率才正交
# @check: 0.0
# @hint: 要验证的是 sin 与 sin(2t) 的内积，两个频率不同才正交；现在两个因子都是 sin(t)。
import math

N = 64
s = 0.0
for n in range(N):
    t = 2 * math.pi * n / N
    s = s + math.sin(t) * math.sin(t)    # ← 问题在这：同频内积不为零
print(round(s, 4))
```

<details>
<summary>点开查看逐步解答</summary>

正交性要验证的是**不同频率**之间的内积：

```python
s = s + math.sin(t) * math.sin(2 * t)   # sin 与 sin(2t) 内积
print(round(s, 4))                      # 0.0
```

改完：$\sum_{n} \sin(\theta_n)\sin(2\theta_n) = 0$，`round` 后 `0.0`。初始代码两个因子都是 $\sin(t)$，变成"自己点乘自己"，和是 $\frac{N}{2}=32$。这正是傅里叶系数公式能"把信号投影到每根频率轴上、互不串扰"的数学根基——不同频率是正交坐标轴。

</details>
