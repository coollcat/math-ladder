# 正交性：为什么能拆

## 1. 从一个场景开始

交响乐现场，长笛、大提琴、定音鼓同时作响，空气里只有一团叠加的气压波。可你闭着眼也能听出"长笛在吹旋律、鼓在打拍子"——大脑天然在拆信号。傅里叶声称他的级数也能拆，而且拆得分毫不差。凭什么这么笃定？

答案只有两个字：**正交**。这是第 11 章埋下、一直没引爆的地基，现在点火。

## 2. 直觉解释

第 11 章说过：两个向量**垂直**（正交），当且仅当它们的点积为零——彼此在对方身上留下零投影，互不干扰；而向量与自己的点积是长度的平方，绝不为零。

把信号想成向量：取一个周期，切成 $N$ 个采样点，一段波形就是 $N$ 个数的列表——一个 $N$ 维向量。两个问题立刻可以问：

- $\sin(1\cdot x)$ 和 $\sin(2\cdot x)$ 这两个"向量"点积是多少？
- $\sin(1\cdot x)$ 和自己呢？

答案是惊人的整齐：**不同频率的正弦，点积恰好为零；自己乘自己，恰好是同一个常数**。也就是说，$\sin x, \sin 2x, \sin 3x, \ldots$ 是一组货真价实的**垂直坐标轴**。第 11 章说"傅里叶 = 换坐标系"——那句话的伏笔，在这里兑现。

## 3. 正式定义

取一个周期 $[0, \tau)$ 均匀切成 $N$ 份，第 $k$ 个采样点的角度为 $x_k = \dfrac{2\pi k}{N}$（$k = 0, 1, \ldots, N-1$）。定义两条波形的离散点积：

$$\langle u, v\rangle = \sum_{k=0}^{N-1} u(x_k)\,v(x_k)$$

则对 $1 \le m, n < N/2$ 有**离散正交关系**：

| 情形 | 结果 | 含义 |
| --- | --- | --- |
| $\sum_k \sin(m x_k)\sin(n x_k)$，$m \neq n$ | $\approx 0$（严格为 0） | 不同频率轴互相垂直 |
| $\sum_k \sin(m x_k)\sin(m x_k)$ | $= \dfrac{N}{2}$ | 自己的"长度平方"，与 $m$ 无关 |
| $\sum_k \cos(m x_k)\cos(n x_k)$，$m \neq n$ | $\approx 0$ | 余弦家族同样互相垂直 |
| $\sum_k \sin(m x_k)\cos(n x_k)$ | $\approx 0$ | sin 家族与 cos 家族也彼此垂直 |

（"$\approx$"只是浮点计算的呼吸声，数学上严格为零，选读部分给直觉。）这四行合起来宣布：sin 与 cos 全体构成一套互不干扰的正交坐标系——**每根频率轴上读到的坐标，不受其他轴上任何份量的污染**。

## 4. 分步例题

**例**：信号 $f(x) = \sin(2x) + 0.5\sin(5x)$，不拆它，直接"问"它：你在 2 号轴上占多少份量？

1. 把 $f$ 与轴向量 $\sin(2x)$ 做点积：$\sum_k f(x_k)\sin(2x_k) = \sum_k \sin^2(2x_k) + 0.5\sum_k\sin(5x_k)\sin(2x_k)$；
2. 用正交表查账：第一项是"自己乘自己"$=\dfrac{N}{2}$，第二项是异频点积 $=0$；
3. 于是总点积 $= \dfrac{N}{2}$，除以归一化因子 $\dfrac{N}{2}$ 得坐标 **1.0**——正是配方里那个系数；
4. 再问 3 号轴：$\sum_k f(x_k)\sin(3x_k) = 1\cdot 0 + 0.5\cdot 0 = 0$——不管别的轴上多热闹，空轴上读数永远是零。

第 3 步就是下一课"投影求系数"的全套原理：**点积一次，只读一根轴**。5 Hz 成分量再大，也丝毫不会串进 2 号轴的读数——这就是"互不干扰"的具体含义。

## 5. 动手实验

### 实验 1（viz）：乘积曲线的正负面积

```viz
{
  "type": "orthoproduct",
  "title": "sin(mx)·sin(nx)：异频正负相消，同频全为正",
  "m": 2,
  "n": 3
}
```

怎么玩：拖动 m、n 两个滑杆。蓝色曲线是被拆信号，橙色曲线是逐点乘积；蓝区和红区分别表示正负面积。只要 m ≠ n，正负区块成对抵消；把 n 拖到与 m 相等，乘积全部跑到零轴上方——"自己有长度"。顶部求和读数把“垂直”变成一个可检查的数。

### 实验 2（python）：数值核对正交表

```python title="在 64 个采样点上数值验证正交表"
import math                      # 数学工具库：用 tau 和 sin

N = 64                           # 一个周期的采样点数

def dot_sin(m, n):               # 自定义函数：sin(mx) 与 sin(nx) 的离散点积
    total = 0.0
    for k in range(N):
        x = math.tau * k / N     # 第 k 个采样点的角度，铺满一整个周期
        total = total + math.sin(m * x) * math.sin(n * x)
    return total

# 依次核对正交表的四种情形；abs 取绝对值，因为浮点残差可能带负号
checks = [[1, 2], [3, 5], [1, 4], [2, 2], [1, 1]]
for pair in checks:
    m = pair[0]
    n = pair[1]
    value = round(abs(dot_sin(m, n)), 6)
    print(f"S(m={m}, n={n}) = {value}")

# 再抽查 cos×cos 与 sin×cos 的跨族点积
cross_cc = 0.0
cross_sc = 0.0
for k in range(N):
    x = math.tau * k / N
    cross_cc = cross_cc + math.cos(1 * x) * math.cos(2 * x)
    cross_sc = cross_sc + math.sin(2 * x) * math.cos(3 * x)
print(f"cos(1x)·cos(2x) = {round(abs(cross_cc), 6)}, sin(2x)·cos(3x) = {round(abs(cross_sc), 6)}")
```

输出里三组异频点积全是 0.0，两组同频点积都精确等于 $\frac{N}{2}=32$——与 $m$ 取 1 还是 2 无关。你可以把 `checks` 改成任意你喜欢的组合再跑，规律纹丝不动。

:::warning[常见误区]

**误区一**："你以为正交就是'两个波毫无关系、不相干'。" 正交不是说波形处处错开或互不影响传播，而是说**逐点相乘再平均的结果为零**——它们在"点积"这台机器眼里互相隐形，仅此而已。

**误区二**："你以为打印出的 0.0 说明计算机碰巧算准了。" 反了——数学上严格为零，浮点只能给出 $\sim10^{-15}$ 量级的残渣。看到 $10^{-15}$ 别嫌小，那正是"严格成立"在机器里的签名。

**误区三**："你以为随便取 64 个点都能验证成功。" 必须均匀铺满**整数个周期**。若采样窗没对齐周期（比如把 64 写成 63），正交性当场失效——这个坑在 65 号课有个正式名字：频谱泄漏。

:::

## 6. 练习

**练习 1**：计算 $\displaystyle\sum_{k=0}^{63}\sin\Big(\frac{2\pi k}{64}\Big)\cdot\sin\Big(\frac{4\pi k}{64}\Big)$，输出绝对值保留一位小数。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：异频正弦的点积
# @check: 0.0
# @hint: 正交说的是「不同」频率之间互相垂直——检查循环里两根正弦是不是不小心用了同一个频率；另外结果套 abs 更稳妥，浮点残差可能带着负号
import math

total = 0.0
for k in range(64):
    x = 2 * math.pi * k / 64          # 第 k 个采样点的角度
    total = total + math.sin(x) * math.sin(x)   # 两根轴的频率都在这里
print(round(abs(total), 1))
```

改对后输出 0.0——2 号轴在 1 号轴上的投影为零。顺手把第二个 `math.sin(x)` 改成 `math.sin(2*x)` 之外再试试 `math.sin(3*x)`：照样是 0.0。但若改成 `math.sin(1*x)`，你会得到 32.0——自己跟自己可从不垂直。

**练习 2**：为什么同频点积恒等于 $N/2$，跟频率 $m$ 是 1 还是 5 都无关？

<details>
<summary>点开查看逐步解答</summary>

降幂公式 $\sin^2\theta=\frac{1-\cos 2\theta}{2}$（出生证明见第 7 章[倍角公式与降幂](../07-trigonometry/42-double-angle.md)）把每项拆成常数与二倍频余弦：求和后常数部分贡献 $\frac{N}{2}$，而 $\cos(2m x_k)$ 在整周期上求和必为零（它自己的"平均高度"是零）。于是剩下干净的 $\frac{N}{2}$——所有频率轴"长度相同"，这正是好坐标系该有的公平。
</details>

## 7. 选读：连续版的同一件事

<details>
<summary>选读 · 积分版正交性的几何直觉</summary>

让采样无限变密，求和就变成积分，离散正交升级为连续正交：对整数 $m\neq n$，

$$\int_0^{2\pi}\sin(mx)\sin(nx)\,dx = 0$$

几何图像：乘积 $\sin(mx)\sin(nx)$ 是一条忽正忽负的曲线——两个因子的步调时而一致（积为正）、时而相反（积为负）。在**完整周期**上，正区块与负区块面积成对出现、恰好抵消。而 $m=n$ 时乘积变成 $\sin^2\geq 0$，处处非负，积出 $\pi>0$——"自己"在这套度量下有实实在在的长度。

一句话总结：正交性不是数值巧合，而是"整周期上正负面积两两相消"的必然。第 14 章的积分工具到位后，用积化和差公式两行即可严格证明。
</details>
