# 采样与 DFT：计算机怎么做傅里叶

## 1. 从一个场景开始

前面几课的公式里满是连续的 $t$ 和无穷积分——可计算机只认识有限个数字。CD 存音乐的方式朴素到惊人：每秒测量空气压强 44100 次，把得到的一长串数字原样存盘。

为什么偏偏是 44100？采样会不会丢信息？还有，傅里叶变换那道积分，在机器里到底是怎么算出来的？本课回答这两个问题，并当场手搓一个最小可用的**离散傅里叶变换**。

## 2. 直觉解释

**第一件事：采样定理一句话。** 奈奎斯特告诉我们：想要不失真地记录信号，采样率必须**大于信号最高频率的两倍**。人耳听觉上限约 2 万赫兹，于是 CD 取 2×20000 再留些余量 = 44100 次/秒。低于两倍会怎样？高频成分会"假扮"成低频混进来（叫混叠）——车轮视频里倒转的辐条就是这个原理。

**第二件事：DFT 是离散投影。** $N$ 个采样点就是 $N$ 维空间里的一个向量（第 11 章的画面）。既然只有 $N$ 个数据，就只能问 $N$ 个频率问题：这 $N$ 个问题叫**频率桶**，编号 $k=0,1,\ldots,N-1$，每个桶对应"在窗口内恰好振动了 $k$ 个整周期"的探针。对每个桶做一次熟悉的投影——乘、加、归一化——读出份量。没有任何新数学，还是正交坐标那一套，只不过搬进了数字世界。

## 3. 正式定义

对 $N$ 个采样点 $x[0], x[1], \ldots, x[N-1]$，第 $k$ 个频率桶的 DFT：

$$X[k] = \frac{1}{N}\sum_{n=0}^{N-1} x[n]\,e^{-2\pi i kn/N}$$

用欧拉公式拆开（也是我们不用复数库时的算法）：

$$\mathrm{Re}\,X[k] = \frac{1}{N}\sum_n x[n]\cos\Big(\frac{2\pi kn}{N}\Big), \qquad \mathrm{Im}\,X[k] = -\frac{1}{N}\sum_n x[n]\sin\Big(\frac{2\pi kn}{N}\Big)$$

$$\lvert X[k]\rvert = \sqrt{\mathrm{Re}^2 + \mathrm{Im}^2}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $N$ | 窗口长度 | 参与分析的采样点个数 |
| $k$ | 频率桶编号 | 对应普通频率 $f = k\cdot f_s / N$（$f_s$ 为采样率） |
| $\lvert X[k]\rvert$ | 桶幅度 | 该桶频率上的份量；纯音恰落在桶上时等于振幅的一半 |
| 镜像桶 | 第 $N-k$ 桶 | 实信号的频谱左右对称，前半段已含全部信息 |

## 4. 分步例题

**例**：手算 $x=[0, 1, 0, -1]$ 的 1 号桶（$N=4$）。这串数其实是 $\sin\big(\frac{2\pi n}{4}\big)$ 的采样。

1. 写实部：$\mathrm{Re}\,X[1] = \frac14\sum x[n]\cos\big(\frac{\pi n}{2}\big) = \frac14\big(0 + 1\times 0 + 0 + (-1)\times 0\big) = 0$；
2. 写虚部：$\mathrm{Im}\,X[1] = -\frac14\sum x[n]\sin\big(\frac{\pi n}{2}\big) = -\frac14\big(0 + 1\times 1 + 0 + (-1)\times(-1)\big) = -\frac12$；
3. 合成模长：$\lvert X[1]\rvert = \sqrt{0^2 + 0.5^2} = 0.5$；
4. 解读：信号振幅为 1，桶幅度恰为一半——能量平分给了 $k=1$ 与它的镜像桶 $k=N-1=3$。峰立在哪个桶，一问便知。

这个控件内部就是离散投影：上图为 128 个采样点，下图为前 63 个实频率桶的幅度。拖动频率时，谱峰会搬到对应桶上，且始终干净利落——滑杆只给整数频率，而整数频率在窗口里恰好振完整数个周期、端端正正落进自己的桶（这正是整周期采样的好处）。想看窗口造成的泄漏，得把频率挪到两桶之间——这超出滑杆的能力范围，下面的 Python 版会带你亲手制造一次，顺带拆开每一层循环。

### 实验 2（python 滑块）：调两个频率，重找谱峰

```python title="手搓 O(N²) 的 DFT：拖动 f1 / f2，看谱峰搬家"
import math                      # 数学工具库：用 pi、sin、cos 和 hypot

# sliders: f1=5 [1:12:1], f2=12 [13:31:1]

N = 64                           # 采样点个数
fs = 64                          # 采样率：每秒 64 个点，正好记录 1 秒
x = []                           # 信号的采样列表
for n in range(N):
    t = n / fs                   # 第 n 个点的时刻
    v = math.sin(2 * math.pi * f1 * t)              # 成分一：f1 Hz 正弦
    v = v + 0.5 * math.sin(2 * math.pi * f2 * t)   # 成分二：f2 Hz，份量减半
    x.append(v)

def dft_mag(k):                  # 自定义函数：第 k 个频率桶的幅度
    re = 0.0                     # 实部账本
    im = 0.0                     # 虚部账本
    for n in range(N):           # 内层循环：对全部采样点投影
        ang = 2 * math.pi * k * n / N
        re = re + x[n] * math.cos(ang)
        im = im - x[n] * math.sin(ang)
    return math.hypot(re, im) / N

mags = []                        # 前半段所有桶的幅度
for k in range(N // 2):          # N//2 是整除取商：32
    mags.append(dft_mag(k))

best = 0                         # 先假设 0 号桶最强，再逐个挑战
for k in range(len(mags)):       # len：列表长度
    if mags[k] > mags[best]:
        best = k
print("最强峰: 桶 k =", best, "幅度", round(mags[best], 3),
      "即", best * fs / N, "Hz")

mags[best] = 0                   # 挖掉最强峰，再找一次
second = 0
for k in range(len(mags)):
    if mags[k] > mags[second]:
        second = k
print("次强峰: 桶 k =", second, "幅度", round(mags[second], 3),
      "即", second * fs / N, "Hz")
```

默认位置下两个峰干净利落地落在 $k=5$（幅度约 0.5）和 $k=12$（约 0.25）——正是配方里默认的 5 Hz 与 12 Hz，幅度各自等于振幅的一半。现在拖动 f1、f2 滑杆把两个成分挪到别的频率再跑：谱峰立刻跟着搬家，桶号始终恰好等于频率值——因为实验里 $f_s=N=64$，桶宽正好 1 Hz。试着把频率挪到两桶之间（比如 5.5）：峰会变矮变胖、能量撒进邻桶——这个现象叫**频谱泄漏**：有限窗口之下，非整周期成分的宿命。注意 f2 最大只能给到 31：奈奎斯特上限是 $\frac{f_s}{2}=32$，超过它的频率在采样时就已混叠成低频假象，DFT 无力回天。外层扫桶、内层扫点，两层循环共 $N^2/2$ 次乘加，这就是 **O(N²)** 的朴素 DFT。1965 年的 FFT 算法把它加速到 $O(N\log N)$——记住一句话即可：**DFT 是思想，FFT 是引擎**；两者理论上逼近同一个 DFT，有限精度下可能有极小的浮点舍入差。

### 快问快答

```quiz
采样率 64 Hz 时，最多能可靠分辨多少 Hz 的成分？
- 64 Hz
- 32 Hz [*]
- 128 Hz
? 奈奎斯特定理：可分辨的最高频率是采样率的一半。DFT 也只在前 N/2 = 32 个桶里放独立信息（后半段是镜像）——这就是实验里 f2 滑杆最大只给到 31 的原因。
```

:::warning[常见误区]

**误区一**："你以为峰在桶 5 就代表频率是 5。" 桶号要先换算：$f=k\cdot f_s/N$。实验里恰好 $f_s=N$ 才让桶号直接等于赫兹数；换个采样率，同样的桶对应完全不同的频率。

**误区二**："你以为后半段频谱是另一份新信息。" 实信号的频谱关于中点镜像对称：$k$ 号桶与 $N-k$ 号桶互为倒影（50 号课例题里那根"负频率"尖峰的真身）。所以工程上只看前半段。

**误区三**："你以为 FFT 是另一种变换、结果更准。" FFT 只是算得快的 DFT；理论输出相同，但有限精度下不同求和顺序可能带来极小舍入差。快到什么程度？百万点采样，O(N²) 要一万亿次运算，FFT 只要约两千万次——手机实时频谱因此成为可能。

:::

## 6. 练习

**练习 1**：找出下面纯余弦信号的频率桶。代码能跑但答案不对，改到通过：

```exercise
# @title: 练习：找到纯音的频率桶
# @check: 3
# @hint: 实信号的频谱以中点为镜对称——前半段与后半段各立着一根等高的峰。想报出「正主」而不是倒影，扫描该从哪半边开始？
import math

N = 16
xs = []
for n in range(N):
    xs.append(math.cos(2 * math.pi * 3 * n / 16))   # 纯余弦：藏在某个整数桶上

def mag(k):                      # 第 k 桶的幅度
    re = 0.0
    im = 0.0
    for n in range(N):
        ang = 2 * math.pi * k * n / N
        re = re + xs[n] * math.cos(ang)
        im = im - xs[n] * math.sin(ang)
    return math.hypot(re, im) / N

best_k = 0                       # 目前最强桶的编号
best_v = 0.0                     # 目前最强桶的幅度
for k in range(N // 2, N):       # 注意扫描的起点
    if mag(k) > best_v:
        best_k = k
        best_v = mag(k)
print(best_k)
```

改对后输出 3。改完顺手打印 `round(mag(13), 3)`——你会发现它也等于 0.5：那就是 3 号桶在镜子里的倒影 $N-3=13$。两根等高峰并存时，习惯上报前半段的那根。

**练习 2**：若把采样率提到原来的两倍而窗口时长不变，同样那个 5 Hz 的峰会挪到几号桶？

<details>
<summary>点开查看逐步解答</summary>

桶号翻倍。窗口时长不变意味着 $N$ 翻倍（比如从 64 到 128），桶宽 $f_s/N$ 保持 1 Hz 不变，所以 5 Hz 仍对应"每秒振动 5 个周期"的探针——但它的编号变成 $k=f\cdot N/f_s=10$。桶号不是信号的属性，而是"信号 × 仪器"的共同产物：换尺子，读数就变。
</details>
