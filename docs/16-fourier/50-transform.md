# 从级数到变换：当周期消失

## 1. 从一个场景开始

到目前为止一切顺利——只要信号有周期 $T$，我们就能给出它的谐波配料表。可现实里最重要的信号偏偏**不重复**：一段语音说完就完，一声枪响转瞬即逝，一张照片更没有"每隔几秒重播一次"的说法。

没有周期，就没有基频，没有"整数倍"，整套级数理论眼看要作废。数学家的应对方式优雅得近乎任性：**干脆让周期无限大**。本课就玩这场极限游戏。

## 2. 直觉解释

**游戏第一步：谱线挤成一团。** 周期为 $T$ 的信号，谱线只能立在 $\frac{1}{T}, \frac{2}{T}, \frac{3}{T}\ldots$ 这些格点上，相邻谱线的间距是基频 $\frac1T$。现在把 $T$ 拉长一倍——允许的频率格点立刻加密一倍，同时每根谱线的份量被摊薄。$T\to\infty$ 时：格点密不透风，**离散的柱状谱融化成一条连续曲线**。配料表从"清单"变成"函数"，这就是傅里叶变换 $F(\omega)$。

**游戏第二步：让公式瘦身。** 级数里 cos 和 sin 两套系数平行记账，略显臃肿。第 12 章欧拉公式说过 $e^{i\theta}=\cos\theta+i\sin\theta$——那节课结尾还专门剧透："这正是第 16 章傅里叶变换公式的长相。"今天兑现：

$$e^{-i\omega t}=\underbrace{\cos(\omega t)}_{\text{余弦账本}}-i\underbrace{\sin(\omega t)}_{\text{正弦账本}}$$

一个复指数同时探测 cos 与 sin 两根轴，两本账合成一本：$F(\omega)$ 的模长管份量、辐角管相位。

把第 12 章的单位圆请回来当视觉模型：让 $e^{i\theta}$ 的角度 $\theta=\omega t$ 随时间匀速增长，紫色的点就绕原点匀速转圈——它在纵轴上的影子画出 $\sin(\omega t)$，横轴上的影子画出 $\cos(\omega t)$。所谓探针 $e^{-i\omega t}$，就是同一根指针反着转：一次旋转，同时投出 cos 与 sin 两道影子。

怎么玩：紫色动点匀速逆时针转，右边摊开的橙色波浪是纵轴影子随时间的展开——正弦的出生录像。可拖动紫点停在任意角度、也可暂停细看：指针转过一整圈，波浪恰好走完一个周期。频率 $\omega$ 只决定指针转多快，不改变任何形状——这正是"探针只带频率信息"的视觉版。

## 3. 正式定义

对（可积的）信号 $f(t)$：

$$\text{正变换：}\quad F(\omega)=\int_{-\infty}^{+\infty} f(t)\,e^{-i\omega t}\,dt$$

$$\text{逆变换：}\quad f(t)=\frac{1}{2\pi}\int_{-\infty}^{+\infty} F(\omega)\,e^{i\omega t}\,d\omega$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\omega$ | 角频率 | 单位弧度/秒，与普通频率的关系 $\omega=2\pi f$ |
| $F(\omega)$ | 频谱（复值函数） | 频率 $\omega$ 成分的份量与相位 |
| $e^{-i\omega t}$ | 探测因子 | 同时投影到 cos 与 sin 两根轴的复合探针 |
| $\lvert F(\omega)\rvert$ | 幅度谱 | 该频率占多少份量 |
| $\dfrac{1}{2\pi}$ | 归一化因子 | 正逆变换成对出现，约定必须配平 |

不必背推导，读懂结构即可：正变换是"拿着频率 $\omega$ 的探针在整条时间轴上扫一遍，把逐点乘积积累起来"；逆变换是"把每根频率成分按份量重新堆回去"。

## 4. 分步例题

**例 1**：读出 $F(0)$ 的含义。

1. 代入 $\omega=0$：探针退化为 $e^{0}=1$；
2. 于是 $F(0)=\displaystyle\int f(t)\,dt$ ——信号曲线下的总面积；
3. 若 $f$ 只在宽度 $d$ 内为高 1 的矩形脉冲，则 $F(0)=d$；
4. 解读：零频率就是"完全不晃的成分"，即**直流分量**——$F(0)$ 越大，信号的平均底座越高。

**例 2**：纯余弦 $\cos(\omega_0 t)$ 的频谱长什么样？

1. 用欧拉公式拆开：$\cos(\omega_0 t)=\frac{1}{2}\big(e^{i\omega_0 t}+e^{-i\omega_0 t}\big)$；
2. 探针 $e^{-i\omega t}$ 扫到 $\omega=\omega_0$ 时，与第一项相乘得到恒定的 $1$——积分强烈共振；
3. 扫到 $\omega=-\omega_0$ 时轮到第二项共振；其余频率处处抵消为零；
4. 结论：频谱只在 $\pm\omega_0$ 处立起两根尖峰——**单一音调 = 一对对称谱线**（负频率那根先当作镜像伙伴记住，65 号课正式解释）。

## 5. 动手实验

实验 0（viz）已在第 2 节开场：那根绕单位圆匀速旋转的复指数指针，就是本课全部公式的视觉本体——先去把它转明白，下面的 Python 实验再验证它的代数身手。

### 实验 1（python）：验证打包公式

```python title="e^(-iθ) 与 cosθ − i·sinθ 对照"
import math

# Python 原生支持复数：1j 就是虚数单位 i（第 12 章用过），不需要任何库
for theta in [0.5, 1.0, 2.0, 3.0]:
    z = math.e ** (-1j * theta)   # 复指数：在复平面上旋转 -θ
    print(f"θ={theta}: 实部 {round(z.real, 6)} vs cos {round(math.cos(theta), 6)},"
          f" 虚部 {round(z.imag, 6)} vs −sin {round(-math.sin(theta), 6)}")
```

四行输出两两相等：复指数确实一手托着 cos、一手倒挂着 sin。傅里叶变换用它当探针，等于一次采样同时完成两笔投影。

### 实验 2（python）：看谱线如何挤成连续谱

```python title="周期拉长一倍：谱线加密一倍、份量摊薄一半"
import math                      # 数学工具库
import matplotlib.pyplot as plt  # 画图库

def ramp_lines(T, K):            # 自定义函数：周期 T 的锯齿波的前 K 根谱线
    N = 256                      # 一个周期的采样点数
    freqs = []                   # 各谱线的频率位置
    amps = []                    # 各谱线的份量
    for k in range(1, K + 1):
        total = 0.0
        for i in range(N):
            t = T * i / N        # 时间铺满一个周期 [0, T)
            f = 2 * t / T - 1    # 锯齿波：从 -1 匀速爬到 +1（每根谐波都不缺席）
            total = total + f * math.sin(2 * math.pi * k * t / T)
        freqs.append(k / T)      # 第 k 次谐波站在频率 k/T 上
        amps.append(abs(2 * total / N))
    return freqs, amps

for T in [2, 4]:
    lines = ramp_lines(T, 4)
    for idx in range(4):
        print(f"T={T}: f={lines[0][idx]}, |b|={round(lines[1][idx], 3)}")

plt.plot(ramp_lines(2, 20)[0], ramp_lines(2, 20)[1], "o", label="T=2")
plt.plot(ramp_lines(4, 40)[0], ramp_lines(4, 40)[1], ".", label="T=4")
plt.xlabel("频率")               # xlabel：给横轴写标题
plt.ylabel("份量")
plt.legend()
plt.grid(True)
```

输出与图都说明同一件事：$T$ 从 2 加到 4，谱线位置从 $\frac{k}{2}$ 变成 $\frac{k}{4}$——**加密一倍**；同一个频率上的份量恰好**减半**（对比两组输出里 $f=0.5$ 的两行：约 0.637 对约 0.318）。周期无限大时，柱子矮到贴地、密到无缝——连续谱诞生。（选锯齿波而非方波做演示，是因为方波只有奇次谐波，会有一半位置空号，看不清"变密"。）

:::warning[常见误区]

**误区一**："你以为变换只是换了个记号，还是原来那个世界。" 正变换之后自变量从时间 $t$ 换成了频率 $\omega$——你离开了时间的世界，站到了频率的世界回望同一个信号。两边描述同一事物，但横轴的意义彻底不同。

**误区二**："你以为 $F(\omega)$ 是复数意味着信号里有'复数值'。" 实信号照样拥有复值频谱。复数只是记账工具：模长记份量，辐角记相位，拆开读就行。

**误区三**："你以为 $\frac{1}{2\pi}$ 只是可有可无的系数。" 它保证逆变换能把原信号精确还原。不同的书可能把它挪到正变换或均分成两半——约定可以不同，但一对变换必须配平。

:::

## 6. 练习

**练习 1**：为什么非周期信号反而需要"所有"频率，而不只是整数倍？

<details>
<summary>点开查看逐步解答</summary>

整数倍约束来自"存在公共周期 $T$"：每个成员都要在 $T$ 内凑齐整数圈。当 $T\to\infty$，基频 $\frac1T\to 0$，"整数倍"失去参照物——任意频率都被允许，且彼此不再需要凑齐任何公共节拍。所以连续谱不是放宽了规则，而是规则随周期一起蒸发后的自然形态。
</details>

**练习 2**：枪声"啪"的一下极短促，它的频谱偏向高频还是低频？

<details>
<summary>点开查看逐步解答</summary>

偏向高频，而且铺得极宽。变换里有一条互反规律：**时域越窄，频域越宽**（反之亦然）。极短的脉冲几乎没有"节奏"可言，只能由一大片频率共同拼出；而悠长的纯音在时间上延展充分，频谱才能收拢成纤细的尖峰。例 1 里那个宽度 $d$ 的矩形脉冲，其频谱主瓣宽度就约与 $d$ 成反比。
</details>

**动手解**：用零点公式把"越窄越宽"算成数——正向拿脉宽算主瓣宽度，反向拿目标宽度反推脉宽，两个方向都过一遍手：

```exercise
# @title: 动手解：脉宽与主瓣宽度的双向换算
# @check: 100.0
# @check: 0.02
# @check: 50.0
# @hint: 零点等距落在 f = k/d，第一个零点（主瓣边界）就是 1/d。反向问"想要 50 Hz 收边"时，该对目标值做除法反解，不是照抄
# (a) 正向：枪声脉冲宽度 d = 0.01 秒，主瓣第一个零点在哪里？
d_a = 0.1                # ← 坑在这：题目给的是 0.01，先照题改对再算
print(round(1 / d_a, 1))
# (b) 反向：想让主瓣恰好在 50 Hz 处收边，脉宽要压到多少？并回算零点自检
target = 50
d_b = target             # ← 坑也在这：把"反比"写成了"正比"，该用 1 / target
print(round(d_b, 3))
print(round(1 / d_b, 1))
```
