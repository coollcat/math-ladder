# 周期信号与正弦基：傅里叶的赌注

## 1. 从一个场景开始

手机里存着一首歌，本质上是存了一长串数字（每隔一小段时间记录一次空气压强）。播放时，喇叭凭这串数字精确重建出鼓点、贝斯、人声全部叠加在一起的声波。工程师打开"频谱分析器"，屏幕上几根柱子一跳，就能说出"这里有个 440 Hz 的音，那里有个 50 Hz 的嗡嗡底噪"。

他们凭什么看得出来？因为 200 多年前，傅里叶下了一个惊人的赌注：**很广的一类周期信号，都可以写成一堆不同频率的正弦波加权相加的结果**。你可以先直观地把它想成分段光滑的工程信号；严格的收敛条件留到后面审判。这一章我们就来验证并兑现这个赌注——它是 MP3、JPEG、降噪耳机共同的底层原理。

## 2. 直觉解释

先定义主角：**周期信号**是每隔固定时间 $T$ 就原样重复一次的信号，比如音叉的振动、交流电、心跳的节律。

傅里叶赌注的关键在于选谁当"积木"。他选了正弦波，理由有三：

1. 正弦是最简单的振动——一个频率、一个振幅、一个相位，再无其他参数；
2. 现实世界的振动源（琴弦、音叉、LC 电路）天然就爱按正弦方式振动；
3. **正弦家族像一套互不干扰的坐标轴**——第 11 章"基与坐标"说过：平面上的任何向量都能用两个基向量加权表出。傅里叶宣布：信号的"向量空间"里，$\sin(1\cdot x), \sin(2\cdot x), \sin(3\cdot x)\ldots$ 就是那组基。**信号 = 向量，频率 = 坐标轴方向，系数 = 坐标**。拆信号，就是换一组坐标系读坐标。

于是"分析一个复杂波形"这件难事，被翻译成"读出它在每根频率轴上的坐标"这件简单事。

## 3. 正式定义

**周期性**：若存在最小正数 $T$ 使得对所有 $t$ 都有

$$f(t + T) = f(t)$$

则称 $f$ 为周期信号，$T$ 叫**周期**。

**傅里叶的赌注（级数形式预览）**：在适当条件下（先直观理解为分段光滑），周期为 $T$ 的信号可以写成

$$f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\Big[a_n\cos\Big(\tfrac{2\pi n}{T}t\Big) + b_n\sin\Big(\tfrac{2\pi n}{T}t\Big)\Big]$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $T$ | 周期 | 信号重复一次所需的时间 |
| $\omega_0 = \dfrac{2\pi}{T}$ | 基频（角频率） | 最慢那根正弦的角速度 |
| $n$ | 谐波编号 | 第 $n$ 根正弦的频率是基频的 $n$ 倍 |
| $a_n,\ b_n$ | 傅里叶系数 | 第 $n$ 个频率占多少份量（下一课学怎么求） |
| 谐波 | 泛音 | 频率恰为基频整数倍的正弦分量 |

注意硬性约束：所有成员的频率必须是基频的**整数倍**。这不是偏好，而是必需——只有整数倍才能保证每一项都以 $T$ 为公共周期，拼出的和才会"每隔 $T$ 就重复"。

## 4. 分步例题

**例**：信号 $f(t) = 3\sin(2\pi t) + 2\cos(4\pi t) + 0.5\sin(6\pi t)$，找出它的成分与周期。

1. 认出每个成员的频率：由 $\sin(2\pi f t)$ 的形状读出三个频率分别是 $f_1=1$、$f_2=2$、$f_3=3$（单位 Hz）；
2. 求基频：取三个频率的最大公约数——正是第 10 章 `math.gcd` 的思路——$\gcd(1,2,3)=1$；
3. 得周期：$T = 1/f_0 = 1$ 秒；
4. 写成分清单：1 Hz 占 3 份、2 Hz 占 2 份、3 Hz 占 0.5 份。这份"配料表"就是信号的**谱**（第 60 号课的主角）。

反过来，只要拿到配料表和份量，任何人都能把信号原样调出来——这就是合成与分解互为逆过程的味道。

## 5. 动手实验

### 实验 1（viz）：看着方波从正弦里长出来

```viz
{
  "type": "sines",
  "title": "方波的诞生",
  "terms": [1, 3, 5]
}
```

怎么玩：拖动 harmonics 滑杆增加谐波个数——蓝色细线是各次正弦谐波（频率 1、3、5……倍），深蓝色粗线是它们的总和。谐波越多，总和越像一个上下翻平的方波；但在跳变拐角处始终竖着一撮甩不掉的尖峰（先记住它，40 号课专门审判）。圆滑的正弦能拼出直角，眼见为实。

### 实验 2（python）：把方波和三角波装进采样列表

```python title="生成两种周期波形的采样列表"
import math                      # 数学工具库：用 pi、sin 和 tau
import matplotlib.pyplot as plt  # 画图库（第 0 章引入）

N = 64                 # 一个周期切成多少个采样点
square = []            # 方波的采样值列表
triangle = []          # 三角波的采样值列表
for k in range(2 * N):           # k 是采样序号，铺满两个周期
    x = math.tau * k / N         # 该采样点对应的角度（tau 就是 2π）
    s = math.sin(x)
    if s >= 0:                   # 方波：正弦为正站上高台 +1
        square.append(1)
    else:
        square.append(-1)
    phase = (x / math.pi) % 2    # 折算到 0~2 的相位，% 是取余数
    if phase < 1:                # 三角波前半段：匀速上坡
        triangle.append(2 * phase - 1)
    else:                        # 后半段：匀速下坡
        triangle.append(3 - 2 * phase)

print("方波前 16 个采样:", square[:16])   # 切片：取下标 0 到 15 的前 16 个采样
plt.plot(square, label="方波")     # 只给 x 列表时，横轴自动用序号 0,1,2...
plt.plot(triangle, label="三角波")
plt.axhline(0, color="gray", linestyle="--")   # 中轴虚线
plt.legend()
plt.grid(True)
plt.title("两种周期信号（横轴是采样序号）")
```

这两条棱角分明的曲线，在实验 1 里都已被证明是正弦叠出来的。你可以把 `N` 改成 8 再跑——采样变粗，波形立刻显出马赛克感，这正是 65 号课要谈的"采样分辨率"。

### 快问快答

```quiz
方波可以由哪些频率的正弦叠加而成？
- 随便什么频率，各掺一点都行
- 只能是基频的整数倍（谐波） [*]
- 只需要基频一根正弦就够了
? 谐波约束是傅里叶级数成立的前提：每个成员的周期都必须整除信号周期 T，否则总和拼不出"每隔 T 重复一次"这件事。
```

:::warning[常见误区]

**误区一**："你以为随便抓一把正弦相加就叫傅里叶级数。" 频率必须取基频的整数倍。掺进一个非整数倍的"野频率"，合成结果就不再以 $T$ 为周期——赌约直接作废。

**误区二**："你以为方波棱角分明，说明它跟圆滑的正弦没有血缘关系。" 直角恰恰是无穷多个圆滑正弦协作的成果；有限项只能逼近，永远带一点圆角和尖峰。

**误区三**："你以为周期就是式子里最短那个成分的周期。" 周期要取**所有成员共同**的重复长度。例题中三个成分的最小公共周期是 1 秒，而不是最快的 3 Hz 成分的 1/3 秒。

:::

## 6. 练习

**练习 1**：信号 $g(t)=\sin(\pi t)+\sin(2.6\pi t)$ 还是周期信号吗？如果是，周期是多少？

<details>
<summary>点开查看逐步解答</summary>

两个频率分别是 0.5 Hz 和 1.3 Hz。判断标准：频率之比必须是有理数（能写成整数比）。$0.5 : 1.3 = 5 : 13$——是！所以 $g$ 是周期信号，基频为两频率的最大公约数 0.1 Hz，周期 $T = 10$ 秒：每 10 秒里第一个成分正好重复 5 次、第二个正好重复 13 次，步调整齐归位。
</details>

**动手解**：周期不用嘴判——让代码逐点验证 T = 10 与 T = 9.9：

```exercise
# @title: 动手解：逐点验证周期
# @check: True
# @check: False
# @hint: 浮点数不能直接用 != 比较（第 2 章的 0.1 + 0.2！）；用 abs(差) > 1e-9 判断"不同"
import math
def g(t):
    return math.sin(math.pi * t) + math.sin(2.6 * math.pi * t)

same10 = True
same99 = True
for k in range(100):
    t = k / 10
    if g(t + 10) != g(t):
        same10 = False
    if g(t + 9.9) != g(t):
        same99 = False
print(same10)
print(same99)
```

**练习 2**：如果把实验 1 里的某个谐波频率悄悄改成 1.5 倍基频，合成波形会怎样？

<details>
<summary>点开查看逐步解答</summary>

合成结果将不再周期重复：1.5 倍谐波的周期是 $\tfrac{2}{3}T$，它与其他成员的"步点"永远错不开，整体找不到公共的重复长度。波形看起来会多出一种缓慢漂移的"晃动感"。这反过来说明：谐波约束不是数学家的洁癖，而是"周期"二字本身的逻辑要求。
</details>
