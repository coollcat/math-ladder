# 卷一枢纽站：线性、时移与回望

## 1. 从一个场景开始

列车缓缓驶入枢纽站。这一课不再赶路学新工具，而是做两件更奢侈的事：先把傅里叶已经就位的两条性质——**线性**与**时移**——放进同一张速查表并亲手验证，然后推开车窗，回望从 $1+1$ 一路走来的整条轨道——你会发现十五章的风景，此刻全部倒映在同一片湖面上。

## 2. 直觉解释：把变换当一台机器

把傅里叶变换想成一台机器：左边塞进时域信号，右边吐出频域信号。好机器都有稳定的操作手册——**你在一边做的动作，对应另一边某个规矩的动作**：

- 把两个信号**相加**再变换？等于各自变换后**相加**（线性）；
- 让录音**晚点播放**？配料一份不少，只是每样成分的**起步时刻**被改写（时移）;

频移和卷积定理也很重要，但它们各自值得专门展开；本课不把它们塞进首发速查表。

## 3. 正式定义：两条已验证的性质

记 $f, g$ 为信号，$F, G$ 为它们的变换，则：

| 性质 | 时域动作 | 频域响应 | 一句话 |
| --- | --- | --- | --- |
| 线性 | $a\,f(t)+b\,g(t)$ | $a\,F(\omega)+b\,G(\omega)$ | 各记各账，互不打折 |
| 时移 | $f(t-t_0)$ | $\lvert F\rvert$ 不变，相位添 $-\omega t_0$ | 迟到不改配方，只改起跑 |

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $t_0$ | 时移量 | 信号延播的时间 |

## 4. 最后一次实验：亲手验证两条性质

```python title="用 65 号课的 DFT 验证线性与时移"
import math                      # 数学工具库

N = 8                            # 8 个采样点的小信号足够了

def dft(xs):                     # 自定义函数：返回前半段各桶的 [实部, 虚部]
    out = []
    for k in range(N // 2):
        re = 0.0
        im = 0.0
        for n in range(N):
            ang = 2 * math.pi * k * n / N
            re = re + xs[n] * math.cos(ang)
            im = im - xs[n] * math.sin(ang)
        out.append([re / N, im / N])
    return out

def mag(pair):                   # 复数的模长
    return math.hypot(pair[0], pair[1])

f = []                           # 1 号频率的正弦
g = []                           # 2 号频率的正弦
for n in range(N):
    f.append(math.sin(2 * math.pi * n / N))
    g.append(math.sin(2 * math.pi * 2 * n / N))

h = []                           # 混合信号 h = 3f + 2g
for n in range(N):
    h.append(3 * f[n] + 2 * g[n])

F = dft(f)
G = dft(g)
H = dft(h)
print("|F[1]| =", round(mag(F[1]), 2), "|G[2]| =", round(mag(G[2]), 2))
print("|H[1]| =", round(mag(H[1]), 2), "|H[2]| =", round(mag(H[2]), 2))

same = True                      # 逐桶核对 H 是否等于 3F + 2G
for k in range(N // 2):
    if abs(H[k][0] - (3 * F[k][0] + 2 * G[k][0])) > 1e-9:   # 1e-9 即十亿分之一
        same = False
    if abs(H[k][1] - (3 * F[k][1] + 2 * G[k][1])) > 1e-9:
        same = False
print("H 的频谱 == 3F + 2G :", same)

gd = []                          # 把 g 延迟一个采样点（首尾相接绕回）
for n in range(N):
    gd.append(g[(n + 1) % N])    # % 取余：序号越过末尾就绕回开头
GD = dft(gd)
print("时移前后 |·[2]|:", round(mag(G[2]), 2), "vs", round(mag(GD[2]), 2))
```

输出印证了两条性质：混合信号的峰高恰好是 $3\times0.5=1.5$ 和 $2\times0.5=1.0$（线性），且逐桶严格等于 $3F+2G$；而延迟一拍之后，2 号桶的幅度纹丝不动（时移只动相位）。频移和卷积定理等你以后在专门课程里展开，再回头看会更清楚。

:::warning[常见误区]

**误区一**："你以为延迟播放会在频谱上留下'迟到'的痕迹。" 幅度谱完全看不出时移——信息全部藏进了相位谱。只看柱状图判断"谁先谁后"，注定扑空。

**误区二**："你以为这两条性质只是考试前的背诵材料。" 它们是查表词典：遇到新信号先问"它是谁的时移或线性组合"，往往一步就把陌生问题翻译成旧答案。

:::

## 6. 练习

**练习 1**：降噪耳机先分析环境噪声，再播放一个"反相声波"抵消它。这个过程用了本章哪些概念？

<details>
<summary>点开查看逐步解答</summary>

至少三层：采样（麦克风每秒几万次测量）；DFT/频谱分析（实时识别噪声的主要频率与各自的振幅、相位）；线性叠加（播放振幅相同、相位相差 π 的成分——第 7 章讲拍的时候见过反相抵消）。整个链条在毫秒内循环往复。你耳机里那个安静的世界，是本章全部知识的合奏。
</details>

**练习 2**：为什么说"时移不改幅度谱"能解释"听不出录音是从哪一秒开始的"？

<details>
<summary>点开查看逐步解答</summary>

一段音乐延迟三秒再放，每个音的频率与响度毫无变化——变化的只有它们出现的时刻。幅度谱记录"有哪些频率、各多少份量"，对"何时发生"天然失明；起始时刻的信息编码在相位谱的线性斜率里。所以看柱状频谱猜不出曲子进度，这是时移性质的日常显形。
</details>

**动手解**：手搓一个 8 点 DFT，复验这条性质：

```exercise
# @title: 动手解：时移不改幅度谱
# @check: True
# @hint: DFT 的时移是循环时移。普通补零延迟会把绕回的尾巴丢掉；把 shifted 改成整段向右滚两拍、末尾序号绕回开头，再保留浮点容差比较
import math
x = [1.0, 0.0, 0.5, 0.0, 0.2, 0.0, 0.5, 0.0]
N = len(x)

def amp(seq):
    out = []
    for k in range(N):
        re = 0
        im = 0
        for n in range(N):
            ang = 2 * math.pi * k * n / N
            re = re + seq[n] * math.cos(ang)
            im = im - seq[n] * math.sin(ang)
        out.append(math.hypot(re, im) / N)   # 与正文 DFT 一致：除以点数 N
    return out

shifted = [0.0, 0.0] + x[:6]   # 时移猜想：普通延迟两拍，但还没处理绕回
a = amp(x)
b = amp(shifted)
same = True
for k in range(N):
    if abs(a[k] - b[k]) > 1e-9:
        same = False
print(same)
```
