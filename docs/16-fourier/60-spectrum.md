# 频谱：信号的成分表

## 1. 从一个场景开始

在琴上同时按下三个键录音，打开音频编辑软件：波形视图里是一团无法辨认的乱麻——三个音挤在一起，谁也分不清谁。切到"频谱视图"，屏幕上齐刷刷立起三根柱子：440、554、653，高度清清楚楚。

同一份录音，两个视角，一个让人眼花缭乱，一个一目了然。这条柱状图叫**频谱**——信号的成分表。本课亲手把一团乱麻拆成三根柱子。

## 2. 直觉解释

傅里叶变换说：任何信号都能由频率成分拼装。那么**幅度谱 $\lvert F(\omega)\rvert$ 就是每个频率的用量清单**——像饮料瓶上的配料表："水 95%、糖 4%、香精 1%"。

两个视角各司其职：

| 你想知道… | 该看哪边 | 为什么 |
| --- | --- | --- |
| 什么时候响、响多久 | 时域（波形） | 事件发生在时间轴上 |
| 有哪些音高、哪些杂质 | 频域（频谱） | 成分排列在频率轴上 |
| 两个信号像不像 | 频域更稳 | 波形错半拍就面目全非，谱几乎不动 |

时域与频域是**同一个信号的两张照片**：傅里叶变换是可逆的，从频谱能完整还原波形——没有信息丢失，只有视角切换。

## 3. 正式定义

信号 $f(t)$ 的**幅度谱**定义为傅里叶变换的模：

$$\lvert F(\omega)\rvert = \sqrt{\big(\mathrm{Re}\,F(\omega)\big)^2 + \big(\mathrm{Im}\,F(\omega)\big)^2}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $F(\omega)$ | 复值频谱 | 第 50 号课的正变换结果 |
| $\lvert F(\omega)\rvert$ | 幅度谱 | 频率 $\omega$ 的份量大小 |
| $\arg F(\omega)$ | 相位谱 | 各成分的起步角度（本课先只看幅度） |
| 谱线 / 峰 | — | 幅度谱上的尖峰，对应一个强频率成分 |

纯余弦的幅度谱是两根对称尖峰（上一课例题已推）；多个纯音叠加时，线性（可加性）保证谱也跟着叠加——每根柱子各管各的音。

## 4. 分步例题

**例**：读出下面这份频谱对应的信号（三根柱：440 Hz 高约 0.5、554 Hz 高约 0.5、653 Hz 高约 0.25）。

1. 每根柱翻译成一个正弦：频率取柱的位置，振幅取柱的高度的两倍（桶幅度只有振幅的一半）；
2. 得配方：$\sin(2\pi\cdot440 t)+\sin(2\pi\cdot554 t)+0.5\sin(2\pi\cdot653 t)$；
3. 认出这是近似的 A4 + C#5 + E5 三和弦——三个音各自独立，互不干扰；
4. 反向验证：把配方重新合成波形，与原录音逐点比对，严丝合缝。

第 2 步就是"读配料表还原菜"的过程。工程上这叫**分析与综合**一对操作：变换过去叫分析，逆变换回来叫综合。

## 5. 动手实验

### 实验 0（viz）：先拧两个频率看谱峰

```viz
{
  "type": "spectrum",
  "title": "双音信号：时域乱麻 → 频域两根峰",
  "f1": 5,
  "a1": 1,
  "f2": 12,
  "a2": 0.5
}
```

拖动两组「频率 / 份量」滑杆：上图仍是难以直读的叠加波，下图立刻立起两根柱子。柱子位置报出频率，高度报出份量。无论怎么拧，两根谱峰始终又高又瘦、互不打扰——这个控件的频率只能一格一格取整数，窗口又恰好装下每个频率的整数个周期，谱峰永远端端正正落在自己的频率桶上，这正是整周期采样的红利。想见识有限窗口把峰撑胖的频谱泄漏，得让频率偏离桶心——下面的 Python 实验正是如此：440、554、653 Hz 在它 0.064 秒的窗口里都凑不齐整数个周期，扫出的谱峰因此拖着泄漏裙边；65 号课会正面审判这个现象。

```python title="合成三音和弦：时域一团麻，频域三根柱"
import math                      # 数学工具库：用 pi、sin 和 hypot
import matplotlib.pyplot as plt  # 画图库

fs = 8000                        # 采样率：每秒采 8000 个点
N = 512                          # 参与频谱分析的采样点个数
sig = []                         # 和弦信号的采样列表
for n in range(N):
    t = n / fs                   # 第 n 个采样点对应的时刻（秒）
    v = math.sin(2 * math.pi * 440 * t)          # 音一：440 Hz
    v = v + math.sin(2 * math.pi * 554 * t)      # 音二：554 Hz
    v = v + 0.5 * math.sin(2 * math.pi * 653 * t)  # 音三：份量减半
    sig.append(v)

fig, axes = plt.subplots(2, 1, figsize=(7, 5))   # 建 2 行 1 列两张子图
axes[0].plot(sig[:400], linewidth=0.6)           # 前 400 点约 0.05 秒的波形
axes[0].set_title("时域：一团乱麻", fontsize=9)

freqs = []                       # 扫描的频率列表
mags = []                        # 对应幅度列表
for f in range(400, 701):        # 从 400 到 700 Hz、逐 Hz 扫描
    re = 0.0                     # 实部账本：cos 投影累加
    im = 0.0                     # 虚部账本：sin 投影累加（带负号）
    for n in range(N):
        ang = 2 * math.pi * f * n / fs
        re = re + sig[n] * math.cos(ang)
        im = im - sig[n] * math.sin(ang)
    freqs.append(f)
    mags.append(math.hypot(re, im) / N)   # hypot：√(re²+im²)，复数的模长

axes[1].bar(freqs, mags, width=2.5)              # bar：画柱状图
axes[1].set_title("频域：三根柱子", fontsize=9)
plt.tight_layout()

print("440 Hz 读数:", round(mags[40], 3))   # 下标 440-400=40（逐 Hz 扫描，下标即频差）
print("554 Hz 读数:", round(mags[154], 3))  # 554-400=154
print("653 Hz 读数:", round(mags[253], 3))  # 653-400=253
```

上图乱作一团；下图三根柱子拔地而起，前两根几乎等高、第三根矮了一半——正是配方里那个 0.5 的份量。这段"扫频率、算投影、画柱子"的代码，就是一个最小可用的频谱分析仪——均衡器、变调器、降噪算法的核心循环与它同构。

### 快问快答

```quiz
频谱图上一根孤立的尖峰，对应时域波形里的什么？
- 一段完全静止的空白
- 一个纯音正弦的持续振动 [*]
- 一条笔直的水平线
? 每根谱线就是一个频率成分：单峰意味着信号是那个频率的纯音。它在时域里只是一根匀称的波浪线，毫不起眼；到频域才一眼认出本色。
```

:::warning[常见误区]

**误区一**："你以为频域处理会丢信息。" 只要保留完整的复数频谱（幅度+相位），逆变换能一字不差地还原信号。会丢信息的只是我们**主动扔掉**的部分——比如 MP3 删除听不见的成分，那是压缩策略，不是变换本身的损失。

**误区二**："你以为柱子高一倍听起来就响一倍。" 幅度谱是数学份量；人耳对不同频率的灵敏度不同（对 3 kHz 敏感、对 50 Hz 迟钝），响度还要经过"等响曲线"修正。频谱是物理，听感是生理。

**误区三**："你以为真实录音的谱线都是笔直细线。" 有限时长的记录会让谱线胖成一撮（主瓣+旁瓣），65 号课称之为频谱泄漏。想分辨 440 和 441 Hz？请把录音窗口拉长——时间换分辨率。

:::

## 6. 练习

**练习 1**：把音三的份量拧到 0.9，频谱仪在 653 Hz 处应读到多少？下面这台频谱仪已经对准 653 Hz，能跑但读数不对——改到通过：

```exercise
# @title: 练习：拧份量，看柱高
# @check: 0.45
# @hint: 频谱仪的读数约等于振幅的一半——先把 a3 改成题目要求的 0.9，想想 653 Hz 这根柱子该立多高
import math                      # 数学工具库：用 pi、sin 和 hypot

fs = 8000                        # 采样率：每秒 8000 个点
N = 512                          # 参与分析的采样点个数
a3 = 0.2                         # 音三的份量：题目要求改成 0.9

re = 0.0                         # 实部账本：cos 投影累加
im = 0.0                         # 虚部账本：sin 投影累加（带负号）
for n in range(N):
    ang = 2 * math.pi * 653 * n / fs   # 653 Hz 探针在第 n 个采样点的角度
    re = re + a3 * math.sin(ang) * math.cos(ang)  # 投影到 cos 轴：信号乘基函数再逐点求和
    im = im - a3 * math.sin(ang) * math.sin(ang)  # 投影到 sin 轴要带负号，与正文 DFT 的虚部口径一致
print(round(math.hypot(re, im) / N, 2))
```

改对后输出 0.45——桶幅度恰好是振幅的一半（另一半分给了它的镜像伙伴）。顺手把 a3 改回 0.5：读数变成 0.25，正是本课例题里第三根柱子的高度。

**练习 2**：音响的“低音增强”旋钮拧到底，鼓声和人声哪个变化更明显？为什么？

<details>
<summary>点开查看逐步解答</summary>

鼓声。低音旋钮的本质是给频谱的低频区乘一个大于 1 的系数（这就是频域处理的直观例子）。底鼓的能量集中在几十到两百赫兹，整体被抬高；人声基频多在 100~300 赫兹以上、能量主要落在中高频，受低频增益影响小。旋钮转的是频谱的某一区域，不是波形本身。
</details>

**练习 3**：MP3 为什么敢"扔掉"一部分频率成分，听感却几乎无损？

<details>
<summary>点开查看逐步解答</summary>

因为它扔的是心理声学认定"存了也白存"的成分：超过 20 kHz 的人耳盲区、被强音掩蔽的弱音（一个响音会盖住旁边频率相近的轻音）。频谱视角让这些判断变成简单的数值比较——在时域里做同样的事要难得多。这就是"换世界看问题"的红利：换个坐标，难题的形状变了。
</details>

## 7. 选读：换个坐标，长度不变

<details>
<summary>选读 · Parseval：时域能量等于频域能量</summary>

既然“换一组坐标轴读坐标”，就该有一条勾股定理的对应物。它叫 **Parseval 等式**：

$$\sum_{n=0}^{N-1}|x[n]|^2=\frac1N\sum_{k=0}^{N-1}|X[k]|^2.$$

左边是时域能量，右边是频域能量——换坐标系不改变向量长度，这正是“正交基”的定义性好处（第 26 章[从向量空间到函数空间](../26-functional-analysis/10-function-spaces.md) 与 [内积与 Hilbert 空间](../26-functional-analysis/40-inner-product-hilbert.md) 铺的就是这套记账法，到了[正交基与投影](../26-functional-analysis/45-orthogonal-bases-projection.md)它被明写成 Parseval 等式）。

**为什么成立**：$|X[k]|^2=X[k]\overline{X[k]}$，把定义代进去展开成双重求和，对 $k$ 求和时 $e^{2\pi i k(n-m)/N}$ 只在 $n=m$ 时不为零——又是正交性，其他项全灭，剩下 $\sum_n|x[n]|^2$。

**实跑对账**：取 $x[n]=0.6\sin(2\pi\cdot5t)+0.3\sin(2\pi\cdot12t)+0.2$、$N=64$，直接算两种能量，两边都得到 $16.96$。频域侧还能顺手读出三根柱：直流桶 $0.2$、5 Hz 桶 $0.3$、12 Hz 桶 $0.15$——每根都是振幅的一半，与正文的口径一致。

**工程含义**：压缩算法若声称“只删了 1% 的能量”，指的就是右边这一项的 1%。能量守恒让“丢了多少”变成一个可审计的数字，而不是感觉。

</details>
