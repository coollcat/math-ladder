# 傅里叶系数公式：读出坐标

## 1. 从一个场景开始

上一课证明了谐波是一组互相垂直的坐标轴。可坐标轴再好，若没有办法读出"信号在每根轴上占多少份量"，它就只是好看的摆设。

第 11 章的答案今天正式兑现：**想知道向量在某根轴上的坐标，就做一次投影**。傅里叶系数公式不是新发明，它就是点积投影换了一身衣服。

## 2. 直觉解释

回顾点积投影：向量 $\vec{f}$ 在单位轴 $\vec{e}$ 上的坐标等于 $\vec{f}\cdot\vec{e}$；若轴没归一化、长度平方为 $L$，就再除以 $L$。

把信号 $f$ 当作向量、第 $n$ 号正弦当轴：

- 点积：$\sum_k f(x_k)\sin(n x_k)$——上一课的机器；
- 轴长平方：$\sum_k \sin^2(n x_k) = \dfrac{N}{2}$——上一课查表所得；
- 坐标 = 点积 ÷ 轴长平方 $= \dfrac{2}{N}\sum_k f(x_k)\sin(n x_k)$。

这就是**离散版系数公式**：乘一遍、加起来、除以 $N/2$，三步读完一根轴的坐标。让采样无限变密，求和就升级成积分（第 14 章黎曼和的老路），得到连续版公式。整套操作没有任何新魔法——全是"垂直 ⇒ 投影干净"的直接后果。

## 3. 正式定义

周期为 $T$ 的信号 $f$，其 $n$ 次谐波系数：

$$a_n = \frac{2}{T}\int_0^T f(x)\cos\Big(\frac{2\pi n}{T}x\Big)\,dx \qquad b_n = \frac{2}{T}\int_0^T f(x)\sin\Big(\frac{2\pi n}{T}x\Big)\,dx$$

采样 $N$ 个点时的数值版（$x_k=\frac{2\pi k}{N}$）：

$$b_n \approx \frac{2}{N}\sum_{k=0}^{N-1} f(x_k)\sin(n x_k)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a_n$ | 余弦系数 | 信号在 $\cos(nx)$ 轴上的坐标 |
| $b_n$ | 正弦系数 | 信号在 $\sin(nx)$ 轴上的坐标 |
| $a_0/2$ | 直流分量 | 信号的平均高度（整条波形抬高多少） |
| $\frac{2}{T}$ 或 $\frac{2}{N}$ | 归一化因子 | 除以轴长平方，保证"满格才等于 1" |

## 4. 分步例题

**例**：手算三角波一个周期的 $b_1$（只用 8 个采样点的离散版）。三角波采样值为 $f_k = [0,\ 0.5,\ 1,\ 0.5,\ 0,\ -0.5,\ -1,\ -0.5]$，角度为 $x_k=\frac{2\pi k}{8}$。

1. 列出轴上的值：$\sin(x_k) = [0,\ 0.707,\ 1,\ 0.707,\ 0,\ -0.707,\ -1,\ -0.707]$；
2. 逐点相乘：$[0,\ 0.354,\ 1,\ 0.354,\ 0,\ 0.354,\ 1,\ 0.354]$——注意后半段负乘负得正；
3. 求和：$4\times 0.354 + 2\times 1 \approx 3.414$（精确值 $2+\sqrt{2}$）；
4. 归一化：$b_1 = \frac{2}{8}\times 3.414 \approx 0.854$。

对照：这条三角波的无穷项精确答案是 $b_1 = \dfrac{8}{\pi^2}\approx 0.811$。8 个采样点给出 0.854，偏差来自采样太稀——$N$ 越大，离散投影越贴近积分真值。方向对了，剩下的只是加密。

### 实验 3（python）：对方波逐轴投影

```python title="方波的傅里叶系数：数值 vs 理论"
import math                      # 数学工具库：用 tau、sin、cos 和 pi

N = 64                           # 一个周期的采样点数

def square_at(x):                # 自定义函数：返回方波在角度 x 处的取值
    if math.sin(x) >= 0:
        return 1.0               # 上半台阶
    return -1.0                  # 下半台阶

def bn(m):                       # 第 m 号正弦系数（离散投影）
    total = 0.0
    for k in range(N):
        x = math.tau * k / N
        total = total + square_at(x) * math.sin(m * x)
    return 2 * total / N         # 归一化：除以轴长平方 N/2

for m in [1, 3, 5]:
    theory = 4 / (math.pi * m)   # 无穷级数的理论值
    print(f"b_{m}: 数值 {round(bn(m), 3)} | 理论 4/({m}π) ≈ {round(theory, 3)}")
```

三行输出两两贴脸：离散投影给出的系数与理论值 $b_n=\dfrac{4}{n\pi}$ 只差千分之几——差距全部来自 64 个采样点的"马赛克"。注意只有奇数号轴上有份量，且号数越大份量越小：方波的配料表就此到手。

:::warning[常见误区]

**误区一**："你以为 $b_1=1.27$ 意味着信号里有 1.27 Hz 的频率。" 系数是**份量**，下标才是频率编号。$b_1$ 读作"1 号频率占 1.27 份"，别把坐标误当成坐标轴的名字。

**误区二**："你以为每个信号都要同时算 a 和 b 两套系数。" 对称性会偷懒：奇函数（如方波）只藏 sin 系数，偶函数只藏 cos 系数。先看一眼对称性，常常能白拿一半结果。

**误区三**："你以为离散求和就是精确积分。" 它是黎曼和的近似，采样越密越贴近真值。工程上够用了；数学上较真时，请回到连续版积分。

:::

## 6. 练习

**练习 1**：算出方波的 $b_1$，保留两位小数。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：方波的基频份量
# @check: 1.27
# @hint: 方波是奇函数，份量全藏在 sin 坐标轴上——检查你把信号投影到了哪根轴上
import math

N = 64
total = 0.0
for k in range(N):
    x = 2 * math.pi * k / 64     # 第 k 个采样点的角度
    if math.sin(x) >= 0:
        f = 1.0
    else:
        f = -1.0
    total = total + f * math.cos(x)   # 往哪根轴上投影？
print(round(2 * total / N, 2))
```

改对后输出 1.27。想加深体会：把投影目标从 sin 换成 cos 再跑一遍——奇函数方波在 cos 轴上是隐形的，读数直接归零。

**练习 2**：方波的 $a_0$ 是多少？为什么？

<details>
<summary>点开查看逐步解答</summary>

$a_0/2$ 是信号的平均高度。方波一半时间在 $+1$、一半时间在 $-1$，平均值恰为零，所以 $a_0=0$——直流分量为零，波形对称地骑在横轴上。若是被抬高的方波（比如在 0 和 2 之间跳），$a_0/2$ 就会等于 1，这个"底座"会被单独记在一根专属的零号轴上。
</details>
