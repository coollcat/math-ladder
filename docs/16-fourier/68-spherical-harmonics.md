# 球谐函数选讲：球面上的傅里叶

## 1. 从一个场景开始

一款 3D 游戏要给场景打光：光照来自四面八方，物件表面每个朝向接到的亮暗都不一样——"亮度随方向怎么变"是一个定义在**球面**上的函数。再往前一步，最新的三维重建技术（3D 高斯泼溅，你会在图形学卷遇到它）给场景里每团颜色都记一套"从不同角度看会有什么色差"的账本，账本用的语言正是本课的主角。

直线上的信号，第 20 课教会我们拆成 $\sin(k t)$、$\cos(k t)$；可现在信号铺在球面上，"频率"是什么？**球谐函数**（Spherical Harmonics，常缩写 SH）就是答案：它是**球面上的正弦基**——傅里叶那套"拆波"手艺，整体搬上海拔球面。

## 2. 直觉解释

先降半维找感觉：信号定义在一个**圆环**上（比如绕水平一圈的方向角 $\varphi$）。这就是老朋友了——绕一圈恰好一个波峰的是 $\cos\varphi$，两个波峰的是 $\cos 2\varphi$，第 20 课的正交性在圆环上原封不动：不同波峰数的两个 $\cos$ 绕圈点乘为零。

球面 = 无数个纬线圈叠起来。于是拆球面函数的思路是**两条轴分开算**：

- **经线方向**（绕圈 $\varphi$）：还是傅里叶，$\cos m\varphi$、$\sin m\varphi$，绕圈 $m$ 个波峰；
- **纬度方向**（从南极到北极 $\theta$）：换一套新基——**勒让德多项式**，可以粗略理解为"纬度方向上的正弦波"，只是球面几何让它们的形状略微鼓瘦不等宽。

两方向各选一个频率，相乘再归一，就得到一枚**球谐基函数** $Y_l^m$。全套基摆在一起，就是球面的"正弦家族"——任何足够光滑的球面函数都能按它展开，系数就是"球面频谱"。

## 3. 正式定义

（实数版）球谐基函数写成：

$$Y_l^m(\theta, \varphi) = N_l^m \, P_l^m(\cos\theta) \, \Phi_m(\varphi)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $l$ | 阶（degree） | "总频率"：$l$ 越大，明暗斑块越细碎；第 $l$ 阶是一整"带" |
| $m$ | 次数（order） | 带内的"方向编号"：$m = -l, \dots, l$，共 $2l+1$ 个 |
| $P_l^m$ | 勒让德多项式 | 纬度方向的基，交给纬度轴的"正弦家族" |
| $\Phi_m(\varphi)$ | 经线因子 | $\cos m\varphi$ 或 $\sin m\varphi$——绕圈方向的傅里叶 |
| $N_l^m$ | 归一化系数 | 让每枚基"长度"为 1，账目干净 |

对比一维傅里叶就懂了它的账本结构：直线上每个频率 $k$ 只有 $\sin$、$\cos$ 两个基；球面上第 $l$ 频率带是一个"能级壳层"，装着 $2l+1$ 枚基——$l=0$ 只有 1 枚（常数，均匀环境光），$l=1$ 有 3 枚（朝 $x$、$y$、$z$ 三个方向的偏置光），$l=2$ 有 5 枚……**低阶带管大尺度明暗，高阶带管锐利细节**——和傅里叶"低频管轮廓、高频管棱角"一脉相承。

正交性也原样搬来：两枚不同的球谐基在球面上点乘（加权积分）为零；同一枚自己乘自己等于 1。所以"投影读坐标"的配方不变——把球面函数与每枚基做内积，就得到它的球面频谱系数。

## 4. 分步例题

**例 1（圆环上的投影，先手算通经线方向）**：信号 $f(\varphi) = 1 + 0.4\cos 3\varphi$，在圆环上均匀采 $N = 8$ 个点。按第 30 课的配方，系数 $= \dfrac{2}{N}\sum_i f_i \cos m\varphi_i$（常数项不分半）：

1. $c_0 = \dfrac{1}{N}\sum f_i$：每个点先加 1，$0.4\cos 3\varphi$ 绕整圈求和为零 → $c_0 = 1$；
2. $c_1 = \dfrac{2}{N}\sum f_i\cos\varphi_i$：$f$ 里没有 $\cos\varphi$ 成分，正交性让它全程抵消 → $c_1 = 0$；
3. $c_3 = \dfrac{2}{N}\sum 0.4\cos 3\varphi_i \cdot \cos 3\varphi_i$：只有同频自己陪自己不为零，$\sum \cos^2 = N/2$ → $c_3 = 0.4$。

读出来的"环上频谱"是 $\lbrace c_0{=}1,\ c_3{=}0.4 \rbrace$——与配方完全一致，而且只用了 8 个点：正交性让采样极少也能读准坐标。

**例 2（纬度方向先认个脸）**：第 2 阶勒让德多项式 $P_2(x) = \tfrac{1}{2}(3x^2 - 1)$，输入 $x = \cos\theta$ 是纬度的余弦。$P_2(0) = -\tfrac{1}{2}$（赤道方向取负）、$P_2(1) = 1$（北极取正）、$P_2(0)$ 附近过零——它就是纬度方向那枚"两瓣"基：北极一瓣正、南极一瓣正、赤道一圈负。

### 实验（python）：环上投影与"截到低阶带"的重建

```python title="圆环傅里叶：投影读系数，再只用低频带重建"
import math
import matplotlib.pyplot as plt

N = 360                                          # 采样点：铺满整圈
f = []                                           # 原始信号：1 + 0.6cos5φ + 0.4sin2φ
phi = []
for i in range(N):
    p = 2 * math.pi * i / N
    phi.append(p)
    f.append(1.0 + 0.6 * math.cos(5 * p) + 0.4 * math.sin(2 * p))

def coef_cos(m):                                 # cos(mφ) 分量的投影系数
    s = 0.0
    for i in range(N):
        s = s + f[i] * math.cos(m * phi[i])
    return s * 2 / N

def coef_sin(m):                                 # sin(mφ) 分量的投影系数
    s = 0.0
    for i in range(N):
        s = s + f[i] * math.sin(m * phi[i])
    return s * 2 / N

print("c0 =", round(sum(f) / N, 2))              # 常数项：整圈平均
print("a1 =", round(coef_cos(1), 2), " b1 =", round(coef_sin(1), 2))
print("a2 =", round(coef_cos(2), 2), " b2 =", round(coef_sin(2), 2))
print("a5 =", round(coef_cos(5), 2), " b5 =", round(coef_sin(5), 2))

rec = []                                         # 只保留 l <= 2 的"低阶带"重建
for i in range(N):
    v = sum(f) / N
    v = v + 0.4 * math.sin(2 * phi[i])           # 2 号成分仍在带内，保得住
    rec.append(v)                                # 5 号成分被截掉：细节丢失

fig, ax = plt.subplots(figsize=(7, 3))           # 开画布
ax.plot(phi, f, label="original")                # 原始信号
ax.plot(phi, rec, label="l<=2 rebuild")          # 低阶带重建
ax.legend()                                      # 图例：认线用
plt.show()
```

怎么玩：投影系数一个个精确落网（$c_0{=}1$、$b_2{=}0.4$、$a_5{=}0.6$，其余为 0）——这就是"环上频谱"。重建图里，$l\le 2$ 的版本平滑但丢了 5 号高频的波浪：**截带 = 低通滤波**，跟 MP3 扔高频是同一件事。3D 游戏的预计算光照用 $l\le 2$ 的 9 枚球谐系数就能存下整个环境光的"主旋律"，省下几百张贴图——省的正是这里被截掉的细节。

::::warning[常见误区]

**误区一**："你以为球谐就是'球面上画正弦'。" 经线方向确实是 $\cos m\varphi$，但纬度方向是勒让德多项式，形状随纬度不均匀伸缩——照搬 $\cos(l\theta)$ 会把南极北极的账全算错。

**误区二**："你以为 $l$ 和 $m$ 是一回事。" $l$ 是"带"（频率档位），$m$ 是带内的"方向编号"，且 $|m| \le l$。第 $l$ 带有 $2l+1$ 枚基，这是球面比直线"富裕"的地方。

**误区三**："你以为截掉高阶带会引入噪声。" 恰恰相反——截带是**低通滤波**：重建永远比原信号更平滑，丢的是棱角，不是添了毛刺。吉布斯现象只在原信号有硬跳变时才登场。

::::

## 6. 练习

```exercise
# @title: 练习：环上投影读出球面频谱
# @check: 0.5
# @check: 1.0
# @hint: 投影采样必须铺满整圈（i 取到 N-1），再别忘了 2/N 的归一——少采一段，正交账就对不平。
import math

N = 360                                          # 整圈采样点数

def ring_coef(m):                                # m 号环频率的投影系数
    s = 0.0
    for i in range(300):                         # ← 问题在这：只采了 300 个点，没铺满整圈
        p = 2 * math.pi * i / N
        v = math.cos(3 * p) + 0.5 * math.cos(2 * p)
        s = s + v * math.cos(m * p)
    return s * 2 / N

print(round(ring_coef(2), 2))
print(round(ring_coef(3), 2))
```

<details>
<summary>点开查看逐步解答</summary>

把采样改成铺满整圈：

```python
    for i in range(N):                           # i = 0 .. N-1，一圈不缺
```

信号里 $\cos 2\varphi$ 的系数是 0.5、$\cos 3\varphi$ 的系数是 1.0，整圈正交性保证其余频率的账全部抵消：`ring_coef(2) = 0.5`、`ring_coef(3) = 1.0`。初始代码只扫了 300 个点（$300/360 = 5/6$ 圈），被丢掉的 $60°$ 弧段让正交性差一口气，两个读数都失真。这就是球谐工程实现的第一戒律：**投影采样必须闭合**——球面上对应"覆盖整个球面"。
</details>

**练习 2**：第 $l$ 阶球谐带有几枚基？一个用 $l \le 3$ 截断的环境光账本一共要存几枚系数（RGB 三通道按一枚算）？

<details>
<summary>点开查看逐步解答</summary>

第 $l$ 带 $2l+1$ 枚：$l = 0$ 有 1 枚、$l = 1$ 有 3 枚、$l = 2$ 有 5 枚、$l = 3$ 有 7 枚；$l \le 3$ 共 $1 + 3 + 5 + 7 = 16$ 枚。故 16 枚系数能存下任意方向光照的低频全貌——对比存一整张环境贴图（几十万像素），压缩比高达数万倍。这也是为什么从游戏引擎到 3D 高斯泼溅都愿意给每个"发光单元"挂一套 SH 系数。
</details>

## 7. 选读：从环到球，账本只多一个方向

把复指数版写全：$Y_l^m(\theta,\varphi) = N_l^m P_l^m(\cos\theta)\, e^{im\varphi}$——经线方向就是第 50 课的 $e^{im\varphi}$，纬度方向用伴随勒让德函数 $P_l^m$ 接管，归一化系数 $N_l^m$ 让整族基在球面上正交归一（权重就是球面面积元 $\sin\theta\, d\theta\, d\varphi$）。拉普拉斯方程在球坐标下分离变量，角度部分恰好解出这一族——所以静电势、引力势、氢原子电子云、宇宙微波背景，全都用同一套球谐记账：**凡是"球面上的场"，凡是解"球面上的泊松/拉普拉斯"，都是它的辖区**。3D 高斯泼溅给每团颜色存 $\lbrace Y_0^0,\ Y_1^{-1..1},\ Y_2^{-2..2} \rbrace$ 共 9 枚系数，就是"视角转一转，颜色怎么变"的低频答案。
