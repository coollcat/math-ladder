# 方波合成与吉布斯现象：磨不平的棱角

## 1. 从一个场景开始

19 世纪，数学家们为一个问题吵翻了天：方波的配料表明明写得很整齐——$\frac{4}{\pi}\big(\sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5}+\cdots\big)$，全是圆润的正弦，可方波是有直角的。**圆滑的东西无穷叠加，真能拼出笔直的台阶吗？**

1850 年代就有人发现不对劲：合成波形在跳变拐角附近总会冒出一个甩不掉的尖包。你加一百项、一万项，它还在那儿。这不是计算失误，而是本课的主角——**吉布斯现象**。

## 2. 直觉解释

先把上一课的配方拉满。拖动下面的滑杆，看方波如何随着谐波个数增加而逐渐成形：

```viz
{
  "type": "sines",
  "title": "方波的诞生",
  "terms": [1, 3, 5]
}
```

观察两个现象：

1. **整体越来越像**：谐波越多，平台越平、边沿越陡；
2. **拐角的尖包赖着不走**：靠近跳变处，曲线总要向上冲过头一截再荡回来。谐波翻倍，尖包**变窄**了，但**高度几乎不变**。

这就是部分和的两副面孔：在平滑区域它勤勤恳恳地逼近，在跳跃点旁边却永远保留约 **9% 的过冲**——只是把这 9% 挤进越来越窄的地盘里。

## 3. 正式定义

取方波 $f(x)$：在 $(0,\pi)$ 上为 $+1$，在 $(\pi, 2\pi)$ 上为 $-1$。它的 $M$ 项**部分和**（只加前 $M$ 个奇次谐波）：

$$S_M(x) = \frac{4}{\pi}\sum_{j=1}^{M}\frac{\sin\big((2j-1)x\big)}{2j-1}$$

**吉布斯现象**：当 $M\to\infty$，$S_M(x)$ 在所有连续点收敛到 $f(x)$，在跳跃点收敛到左右值的平均值 $0$；但在跳跃点两侧固定距离内，$S_M$ 的峰值恒为

$$S_{\max} \approx 1.179\times(\text{半台阶高度})$$

即过冲约为**跳跃幅度的 8.95%**，且不随 $M$ 增大而消失——只是峰的位置以 $\sim\frac{1}{M}$ 的速度向跳跃点挤压、变窄。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $S_M$ | 部分和 | 只用前 $M$ 个谐波的近似版方波 |
| 过冲 | overshoot | 冲出台阶顶的部分，约为跳幅的 9% |
| 收敛 | — | $M\to\infty$ 时逐点贴向原信号的行为 |

## 4. 分步例题

**例**：手算 $M=3$ 的部分和在第一个尖包顶点的值。

1. 写出三项：$S_3(x)=\frac{4}{\pi}\Big(\sin x+\frac{\sin 3x}{3}+\frac{\sin 5x}{5}\Big)$；
2. 找尖包位置：对 $x$ 求导后令其为零，得驻点 $x=\frac{\pi}{6}$（第一象限内 $\cos x+\cos 3x+\cos 5x=0$ 的解）；
3. 代入：$\sin\frac{\pi}{6}=0.5$、$\sin\frac{3\pi}{6}=1$、$\sin\frac{5\pi}{6}=0.5$，于是括号内 $=0.5+\frac{1}{3}+\frac{0.5}{5}=\frac{14}{15}$；
4. 算峰值：$S_3\big(\frac{\pi}{6}\big)=\frac{4}{\pi}\times\frac{14}{15}\approx 1.188$；
5. 算过冲比例：$(1.188-1)\div 2\approx 9.4\%$——三项时已接近传说中的 9%。

注意第 5 步除的是**跳跃幅度** 2（从 $-1$ 跳到 $+1$）。后面 python 实验会把 $M$ 加大到 81，你会发现这个百分比几乎不再挪窝。

## 5. 动手实验

实验 0（viz）已在第 2 节开场：那只方波合成器就是本课的互动主实验台——先去把 harmonics 拉满找手感，下面的 Python 实验接着把它推到极限、定量盯住尖包。

### 实验 1（python）：加大谐波数，盯住尖包

```python title="M=9、25、81 的部分和与峰值扫描"
import math                      # 数学工具库：用 pi 和 sin
import matplotlib.pyplot as plt  # 画图库

def partial(M, xs):              # 自定义函数：算 M 项部分和在一串 x 处的值
    ys = []
    for x in xs:
        total = 0.0
        n = 1
        while n <= M:            # 只扫奇次谐波 1,3,5,...,M
            total = total + math.sin(n * x) / n
            n = n + 2
        ys.append(4 * total / math.pi)
    return ys

xs = []
for i in range(1200):            # 在跳变点右侧铺一段细网格用于画图
    xs.append(i * 1.5 / 1199)

fig, axes = plt.subplots(3, 1, figsize=(7, 6))   # 建 3 行 1 列三张子图
for idx in range(3):
    M = [9, 25, 81][idx]
    axes[idx].plot(xs, partial(M, xs), linewidth=0.9)
    axes[idx].axhline(1, color="darkorange", linestyle="--", linewidth=1)
    axes[idx].set_xlim(0, 1.2)   # 放大跳变点附近
    axes[idx].set_ylim(-0.2, 1.35)
    axes[idx].set_title(f"M={M}", fontsize=9)
plt.tight_layout()               # 自动排版防重叠

# 细网格扫描找每个 M 的峰值，报告过冲百分比
for M in [9, 25, 81]:
    best = -99.0
    for i in range(1, 5000):
        x = i * math.pi / 5000   # 扫描 (0, π)，避开跳变点本身
        v = partial(M, [x])[0]
        if v > best:
            best = v
    pct = round((best - 1) * 50, 1)   # 过冲占跳跃幅度(=2)的百分比
    print(f"M={M}: 峰值 {round(best, 3)}, 过冲 {pct}%")
```

三张子图的橙色虚线是台阶顶：每一行都有一撮冲过虚线的尖包，从 M=9 到 M=81 尖包明显**变瘦**；但打印出的过冲百分比始终卡在 9% 左右，纹丝不动。把列表改成 `[9, 49, 199]` 再跑一次验证——这就是"压扁不压低"。

### 快问快答

```quiz
把谐波个数加到十万项，方波跳跃点旁的过冲会怎样？
- 完全消失，波形终于完美
- 缩小到可以忽略不计
- 高度仍约为跳跃幅度的 9%，只是变得更窄 [*]
? 这就是吉布斯现象：部分和在每个连续点都收敛，唯独跳跃点旁永远保留约 9% 的过冲，加多少项都只能压缩它的宽度。
```

:::warning[常见误区]

**误区一**："你以为过冲是程序 bug 或画图精度不够。" 换任何语言、任何精度重算，它都在——这是数学事实，不是工程瑕疵。当年吉布斯的文章正是为了回应"是不是算错了"的质疑。

**误区二**："你以为多加谐波终能消除过冲。" 无穷项之后，过冲高度锁定在跳幅的约 8.95%，唯一变化是宽度按 $1/M$ 收窄。能被消灭的是**宽度**，不是**高度**。

**误区三**："你以为真实方波里真有那撮尖包。" 过冲不属于方波，属于"用正弦模仿直角"这件事本身。信号发生器输出的方波干干净净——尖包只活在傅里叶近似的画像里。

:::

## 6. 练习

**练习 1**：为什么过冲的高度不变，宽度却随 $M$ 变窄？

<details>
<summary>点开查看逐步解答</summary>

直觉版本叫"面积守恒"：尖包多出来的那一坨凸起，必须由旁边凹下去的亏空来配平（否则平均值就对不上台阶）。$M$ 增大后，振荡被挤向跳跃点，凸起和亏空一起被压扁、变窄——但两者的**面积**大体不变，所以高度也大体不变。能量没处去，只能越藏越深。
</details>

**练习 2**：$M\to\infty$ 时，$S_M$ 在跳跃点 $x=\pi$ 本身收敛到几？

<details>
<summary>点开查看逐步解答</summary>

收敛到左右值的平均：$\frac{1+(-1)}{2}=0$。事实上级数在 $x=\pi$ 处每项都是 $\frac{4}{\pi}\cdot\frac{\sin(n\pi)}{n}=0$，总和自然是 0。这是傅里叶级数的通用约定：在跳跃点上，它给出两侧的"中间价"。有趣的是：虽然该点收敛正确，但它旁边的尖包依然存在——"这一点收敛"与"这一片收敛"是两回事。
</details>

**动手解**：把部分和程序搬到跳跃点上，亲眼看它收敛到"中间价"：

```exercise
# @title: 动手解：在跳跃点上求值
# @check: 0.0
# @hint: 题问的是跳跃点 x = π 本身；现在算的是平台中点 x = π/2，把 x 换成 math.pi 再跑
import math
M = 50
x = math.pi / 2
total = 0
for n in range(1, M + 1):
    total = total + 4 / math.pi * math.sin(n * x) / n
print(round(total, 2))
```

## 7. 选读：为什么会这样

<details>
<summary>选读 · 不均匀收敛</summary>

傅里叶级数是"逐点收敛"的：每个固定的 $x$ 各自独立地逼近目标。平滑区域里，各次谐波符号配合默契，残差随 $M$ 迅速衰减；但在跳跃点附近，为了让波形在极短距离内爬完 2 个单位的高度，各次谐波不得不"合力过冲再回摆"，这个合作过程需要越来越高的频率参与，于是残差衰减得极慢——表现为峰高不动、峰宽收缩。数学上这叫**不均匀收敛**：收敛速度随位置剧烈变化，最慢的地方恰好紧挨着不连续点。

小历史：这现象 1848 年由威尔布拉姆首先记录，1898 年吉布斯重新发现并澄清，后来以他的名字命名。它提醒所有工程师：**逐点收敛不等于整体一致贴近**——在信号处理里，这意味着"重建信号在跳变附近的局部行为要格外小心"。"一致贴近"的严格定义在第 19 章《Fourier 级数的分析视角》展开。
</details>
