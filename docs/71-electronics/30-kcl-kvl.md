# 基尔霍夫定律与节点分析

## 1. 从一个场景开始

一块开发板上同时跑着 12 V 的继电器、5 V 的逻辑电路和 3.3 V 的传感器。十几个节点、几十条支路，看起来像一团乱麻。

可工程师从不"猜"电流走向。他们只做一件事：**给每个节点写一句话，然后交给线性代数。** 那句话只有两个字——**守恒**。

## 2. 直觉解释

**KCL（电流定律）** 是水管三通的道理：三通接头处，流进来的水必须等于流出去的水。水既不会在接头里凭空产生，也不会消失——**电荷在节点上不堆积**。

**KVL（电压定律）** 是登山环线的道理：从营地出发，无论走哪条路、翻几座山，只要绕回营地，海拔的**总变化量为零**。电压就是"电的高度"，绕一圈回到原点，高度差之和必然是零。

这两条定律厉害在哪？它们**完全不问支路上是什么元件**。电阻、电容、二极管、晶体管、甚至一个黑盒子，只要它是个二端元件，KCL 和 KVL 就成立。于是分析电路被拆成两步：

1. 用 KCL/KVL 列出**拓扑约束**（有多少个方程）；
2. 用**元件自己的约束**（比如电阻的 $V = IR$）把方程里的电压、电流联系起来。

## 3. 正式定义

**基尔霍夫电流定律（KCL）**：对任一节点，流出的电流代数和为零

$$\sum_{k} i_k = 0$$

**基尔霍夫电压定律（KVL）**：沿任一闭合回路，电压降的代数和为零

$$\sum_{k} v_k = 0$$

**节点分析法（Nodal Analysis）**：选一个节点为**参考点**（地，0 V），其余节点电压 $v_j$ 为未知量，对每个非参考节点写 KCL：

$$\sum_{k} \frac{v_j - v_k}{R_{jk}} = i_{\text{注入},j}$$

写成矩阵就是 $\mathbf{G}\mathbf{v} = \mathbf{i}$，其中 $\mathbf{G}$ 是**电导矩阵**。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $i_k$ | 第 k 条支路电流 | 流出节点为正，流入为负 |
| $v_j$ | 节点 j 的电压 | 相对参考点（地）的电位 |
| $R_{jk}$ | 节点 j 与 k 之间的电阻 | 两节点之间每条支路各贡献一项 |
| $\mathbf{G}$ | 电导矩阵 | 对角线 = 该节点所有电导之和；非对角 = 相邻电导取负 |
| $\mathbf{i}$ | 注入电流向量 | 电流源注入为正 |

**为什么叫"电导矩阵"**：展开 $(v_j - v_k)/R_{jk}$ 后，$v_j$ 的系数是 $+1/R_{jk}$（电导），$v_k$ 的系数是 $-1/R_{jk}$。所以把每条支路的电导往矩阵里一填，线性方程组就自动写好了——这正是电路仿真器（SPICE）的核心。

## 4. 分步例题

**例**：电路如实验台所示——12 V 电源接在节点 1 与地之间，$R_1 = 100\ \Omega$ 跨接节点 1 与 2，$R_2 = 200\ \Omega$ 与 $R_3 = 300\ \Omega$ 分别把节点 2、节点 1 接到地。求各支路电流。

1. **选参考点**：地 = 0 V。节点 1 被 12 V 电源钳位，所以 $v_1 = 12$ V（**这类节点的方程可以省掉**）；
2. **对节点 2 写 KCL**：$\dfrac{v_2 - v_1}{R_1} + \dfrac{v_2 - 0}{R_2} = 0$；
3. **代入数字**：$\dfrac{v_2 - 12}{100} + \dfrac{v_2}{200} = 0$；
4. **移项**：$v_2\left(\dfrac{1}{100} + \dfrac{1}{200}\right) = \dfrac{12}{100}$，即 $v_2 \times 0.015 = 0.12$，得 $v_2 = 8.0$ V；
5. **回代求电流**：$i_{R1} = (12-8)/100 = 40$ mA，$i_{R2} = 8/200 = 40$ mA，$i_{R3} = 12/300 = 40$ mA；
6. **校验**：电源要供出 $40 + 40 = 80$ mA，而 $R_3$ 分支吃掉 40 mA、$R_1$ 分支吃掉 40 mA，收支平衡。

三个 40 mA 是精心挑的数字，真实电路里几乎不会这么巧——但**校验步骤不能省**，它是手算唯一的保险丝。

## 5. 动手实验

### 实验 1（lab）：点节点，看收支表

```lab
{
  "type": "kcl-kvl",
  "title": "基尔霍夫定律：每个节点的收支平衡表",
  "sliders": [
    { "name": "Vs", "label": "电源电压 Vs", "min": 0, "max": 24, "step": 0.5, "value": 12 },
    { "name": "R2", "label": "电阻 R2", "min": 50, "max": 600, "step": 10, "value": 200 }
  ]
}
```

**点画布上的节点圆点**可以切换观察对象。右侧列出该节点每条支路的"流出电流"：红色向右（真的流出），蓝色向左（其实是流入）。最底下那行 **Σ 流出 ≈ 0** 就是 KCL 的当场验算——读数里那串 $\pm 10^{-15}$ 量级的残差，是浮点运算的舍入噪声，不是错误。

做三个实验：

- 把 Vs 从 12 V 拖到 24 V——所有电流按比例翻倍，但节点电压之比 $v_2/v_1$ 纹丝不动。**线性电路的比例性**；
- 把 R2 从 200 Ω 拖到 400 Ω——$v_2$ 从 8 V 升到约 9.6 V，而 $i_{R2}$ 减半。分压比变了，KCL 依然成立；
- 点"地"节点——它的三条支路电流全为负（都在流入），求和仍为零。**参考点也要满足 KCL**，这正是"回路闭合"的代数表达。

### 实验 2（python）：把 KCL 写成矩阵并解出来

```python title="两节点电路：手搓一次高斯消元"
# 未知量 x = [v1, v2]，方程 G·v = i
# 节点 1：v1/300 + (v1-v2)/100 = iSrc   （iSrc 未知，改由 v1 = 12 直接给出）
# 节点 2：(v2-v1)/100 + v2/200 = 0

a = [[1.0, 0.0], [-1/100, 1/100 + 1/200]]   # 系数矩阵：第一行是 v1 = 12 的钳位方程
b = [12.0, 0.0]                             # 右端向量

# 高斯消元：先用第一行把第二行的 v1 消掉
f = a[1][0] / a[0][0]
for k in range(2):
    a[1][k] = a[1][k] - f * a[0][k]
b[1] = b[1] - f * b[0]

v2 = b[1] / a[1][1]      # 回代：此时第二行只剩 v2 一个未知量
v1 = b[0] / a[0][0]
print(f"v1 = {v1:.3f} V   v2 = {v2:.3f} V")

iR1 = (v1 - v2) / 100
iR2 = v2 / 200
iR3 = v1 / 300
print(f"iR1 = {iR1*1000:.1f} mA   iR2 = {iR2*1000:.1f} mA   iR3 = {iR3*1000:.1f} mA")
print(f"节点 2 的 KCL 残差: {iR1 - iR2:.2e} mA（非零就是算错了）")
```

输出 `v2 = 8.000 V`，三个电流全是 40.0 mA——与手算、与实验台完全一致。注意第一行那个"钳位方程" $v_1 = 12$：当节点上挂了理想电压源时，最省事的做法就是直接把它写成一个方程，这在 SPICE 里叫 **MNA（改进节点分析法）**，多出的那一行记录的是**流过电压源的电流**——实验台读数里的"V1（电源）"支路电流就是这么来的。

### 快问快答

```quiz
节点分析法为什么能少列很多方程？
- 因为它忽略了 KVL
- 因为节点电压自动满足 KVL，只需再补 KCL 就够了 [*]
- 因为它假设所有电阻相等
? 沿闭合回路走一圈，各段电压写成「相邻节点电压之差」时会自动两两抵消。也就是说，用节点电压作未知量，KVL 是免费满足的，剩下的只有 KCL 要写。
```

:::warning[常见误区]

**误区一**："KCL 说流进等于流出，所以我要先知道电流方向才能列方程。"
你以为必须先判断对方向——其实**参考方向可以随便定**。先给每条支路随便指一个箭头，按它列方程；解出来是正数就说明真实方向与假设一致，负数就说明相反。物理世界不看你画的箭头，只看方程自洽。

**误区二**："KVL 就是能量守恒，所以任何时候都成立。"
你以为它无条件成立——其实 KVL 的前提是**回路不包围变化的磁场**。变压器次级、长线圈附近、高频 PCB 上的大环路，都会出现"绕一圈电压不为零"的情况。工程上把它处理成一个额外的感应电动势项，本质上是法拉第定律在说话。

**误区三**："节点数越多方程越多，所以选网孔法更好。"
你以为两种方法的方程数差不多——其实对于平面电路，若节点数为 $n$、网孔数为 $m$，通常 $n$ 远小于 $m$。节点法还天然适合计算机（矩阵直接按"电导累加"填），所以 SPICE 系列仿真器一律用节点法，网孔法基本只出现在手算技巧里。

:::

## 6. 练习

**练习 1**：一条 R1–R2 串联的分压链（$v_1 = 12$ V 加在顶端，底端接地），求中间节点电压。这段代码把分压比写反了，修到输出 `8.0`：

```exercise
# @title: 练习：分压链中间节点的电压
# @check: 8.0
# @hint: 分压公式是 v2 = v1 × R下/(R上+R下)，R下 是与地相连的那个电阻。代码拿 R1（上面的）当成了分子
v1 = 12.0
R1 = 100.0      # 上端电阻（接 v1）
R2 = 200.0      # 下端电阻（接地）
v2 = v1 * R1 / (R1 + R2)   # ← 问题在这：分子应该是 R2
print(v2)
```

**练习 2**：在例题电路（$R_1=100$、$R_2=200$、$R_3=300$，$V_s=12$ V）中，电源一共供出多少电流？电源的输出功率是多少？$R_3$ 上消耗的功率是多少？

<details>
<summary>点开查看逐步解答</summary>

1. $v_1 = 12$ V，$v_2 = 8$ V（例题已解出）；
2. $i_{R1} = (12-8)/100 = 40$ mA，$i_{R3} = 12/300 = 40$ mA；
3. 对节点 1 写 KCL：电源供出的电流 = $i_{R1} + i_{R3} = 80$ mA；
4. 电源输出功率 $P = V \cdot I = 12 \times 0.08 = 0.96$ W；
5. $R_3$ 消耗 $P = V^2/R = 144/300 = 0.48$ W；
6. **功率守恒校验**：$P_{R1} = 0.04^2 \times 100 = 0.16$ W，$P_{R2} = 0.04^2\times200 = 0.32$ W，$P_{R3} = 0.48$ W，合计 $0.96$ W = 电源输出。**功率守恒是比 KCL/KVL 更狠的一道校验**——它连符号错误都能抓出来。

</details>

## 7. 选读：KCL 与 KVL 到底谁更"基本"

<details>
<summary>选读 · 两条定律的物理来源</summary>

**KCL** 来自电荷守恒，写成微分形式就是连续性方程：

$$\nabla \cdot \mathbf{J} + \frac{\partial \rho_v}{\partial t} = 0$$

即"流出某闭合面的电流 = 该区域内电荷量的减少率"。当区域内不积累电荷（$\partial\rho_v/\partial t = 0$）时，就是 KCL。所以严格说，**节点上若有电容，节点处的瞬时电流仍然满足 KCL**——因为电容极板上的电荷变化正是"流进去囤着"的那部分，它已经被 $\partial\rho_v/\partial t$ 这一项记账了。

**KVL** 来自静电场的保守性：$\mathbf{E} = -\nabla\phi$，沿闭合路径积分恒为零。而当存在变化磁场时，$\nabla\times\mathbf{E} = -\partial\mathbf{B}/\partial t \neq 0$，环路积分不再为零——这就是误区二提到的例外。

有趣的是，**KCL 比 KVL 更"抗造"**：即使在高频、存在寄生电容的电路里，只要把电容当成一条支路，KCL 依然精确成立；而 KVL 从一开始就要求"回路不包围变化磁通"。这也是为什么 SPICE 只用节点法（KCL）而完全不用网孔法（KVL）——不是图省事，是物理上更稳。

</details>
