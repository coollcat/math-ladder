# 有源滤波器设计

## 1. 从一个场景开始

心电信号（ECG）的频带是 0.05~150 Hz，幅度只有 1 mV 左右。而真实采集环境里有：

- **50 Hz 工频干扰**，幅度可能是信号的几十倍；
- **基线漂移**，呼吸导致的 0.1~0.5 Hz 慢变；
- **肌电噪声**，几十到几百 Hz 的宽带杂波。

任务：把 0.05~150 Hz 之外的东西全部挡掉，同时**不能**因为接上后级而改变前级的特性。

无源 RC 滤波器做不到第二点——一接负载，截止频率就跑（第 40 课的负载效应）。**运放的虚短与低输出阻抗，正是为了解决这个问题。**

## 2. 直觉解释

无源 RC 低通的问题在于"**谁都能影响它**"：负载电阻与滤波电阻并联，等效电阻变了，$\omega_c = 1/RC$ 跟着变。

有源滤波器的思路极其简单：**在 RC 网络后面加一个电压跟随器（或放大器）**。跟随器输入阻抗无穷大，所以对 RC 网络来说"什么都没接"；输出阻抗几乎为零，所以对后级来说"是个理想电压源"。**两头的互相干扰被彻底截断。**

再进一步：把电容放进**反馈支路**，增益就随频率变化——电容在高频时阻抗低，把增益"拉"下来。于是电路同时完成放大与滤波两件事。

**阶数**决定"挡得多狠"：

| 阶数 | 高频衰减斜率 | 含义 |
| --- | --- | --- |
| 一阶 | −20 dB/dec | 频率 ×10，幅度 ÷10 |
| 二阶 | −40 dB/dec | 频率 ×10，幅度 ÷100 |
| 四阶 | −80 dB/dec | 频率 ×10，幅度 ÷10000 |

## 3. 正式定义

**一阶有源低通**（反相放大器 + 反馈电容）：

$$H(j\omega) = -\frac{R_f}{R_1}\cdot\frac{1}{1 + j\omega R_f C_f}, \qquad f_c = \frac{1}{2\pi R_f C_f}$$

**二阶 Sallen-Key 低通**（单位增益缓冲 + 两级 RC）：

$$H(s) = \frac{1}{1 + \dfrac{s}{Q\omega_c} + \dfrac{s^2}{\omega_c^2}}, \qquad |H| = \frac{1}{\sqrt{(1-u^2)^2 + (u/Q)^2}}$$

其中 $u = f/f_c$。

**品质因数 $Q$ 与阻尼比的关系**（与第 80 课完全对应）：

$$Q = \frac{1}{2\zeta}$$

| $Q$ 值 | 名称 | 幅频特征 | 阶跃响应 |
| --- | --- | --- | --- |
| 0.707 | Butterworth（最平坦） | 通带最平，$f_c$ 处 −3 dB | 4.3% 过冲 |
| 0.577 | Bessel | 过渡最缓 | 几乎无过冲，相位最线性 |
| > 0.707 | Chebyshev 型 | 通带有纹波，$f_c$ 附近鼓包 | 明显过冲 |
| → ∞ | 无阻尼 | 尖峰无限高 | 持续振荡 |

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f_c$ | 截止频率 | 设计目标；$Q=0.707$ 时恰为 −3 dB 点 |
| $Q$ | 品质因数 | 决定截止点附近的形状 |
| $\zeta$ | 阻尼比 | $1/(2Q)$，与 RLC 二阶响应同一套数学 |
| 斜率 | 滚降率 | dB/decade，每阶 20 dB |

## 4. 分步例题

**例**：设计一个 $f_c = 1$ kHz 的二阶 Butterworth 低通（Sallen-Key，单位增益），取 $C_2 = 10$ nF。

1. **确定 $Q$**：Butterworth 要求 $Q = 0.707$；
2. **计算 $R$**：Sallen-Key 单位增益结构下，令 $R_1 = R_2 = R$，$C_1 = m C_2$（$m = 4Q^2$），有
   $$R = \frac{1}{4\pi f_c C_2 Q} = \frac{1}{4\pi\times1000\times10^{-8}\times0.707} = \frac{1}{8.885\times10^{-5}} = 11254\ \Omega$$
   取标准值 **11 kΩ**（1% 精度）；
3. **计算 $C_1$**：$m = 4\times0.707^2 = 2.0$，所以 $C_1 = 2\times10 = 20$ nF；
4. **校验**：重算 $f_c = \dfrac{1}{2\pi R\sqrt{C_1C_2}} = \dfrac{1}{2\pi\times11000\times\sqrt{2\times10^{-16}}} = \dfrac{1}{2\pi\times11000\times1.414\times10^{-8}} = 1024$ Hz（偏差 2.4%，可接受）；
5. **-3 dB 点**：Butterworth 时 $f_{-3\text{dB}} = f_c$，约 1 kHz；
6. **阻带衰减**：10 kHz（$u = 10$）时 $|H| \approx 1/u^2 = 0.01$，即 −40 dB——**二阶比一阶多压 20 dB**。

**注意第 2 步**：$C_1 = 2C_2$ 这个"不对称"不是笔误，而是实现 $Q = 0.707$ 的必要条件。若取 $C_1 = C_2$、$R_1 = R_2$，得到的 $Q$ 恰好是 0.5（过阻尼，过渡带过于平缓）。

## 5. 动手实验

### 实验 1（lab）：扫频真解 vs 理论公式

```lab
{
  "type": "active-filter",
  "title": "有源滤波器：−20 还是 −40 dB/dec",
  "sliders": [
    { "name": "lf", "label": "截止频率 log₁₀fc", "min": 1, "max": 5, "step": 0.01, "value": 3 },
    { "name": "Q", "label": "品质因数 Q（二阶）", "min": 0.3, "max": 5, "step": 0.01, "value": 0.707 }
  ]
}
```

实线是电路引擎逐点**扫频**得到的真解，灰色虚线是理论公式——两条应当重合。做三组对照：

- **一阶档**：斜率读数稳定在 −20 dB/dec，曲线在 $f_c$ 后单调下降；
- **二阶档**：斜率变成 −40 dB/dec，下降明显更陡。**这就是"多一阶"的全部价值**；
- **把 Q 从 0.707 拖到 3**：截止点附近鼓起一个大包（峰值约 $20\log_{10} 3 \approx 9.5$ dB），紫色 −3 dB 实测点明显右移。这就是 Chebyshev 型"用通带纹波换更陡过渡"的代价。

**关键观察**：$Q = 0.707$ 时 −3 dB 点几乎正好落在 $f_c$ 上；$Q$ 一变，两者就分家。所以**说"截止频率"时必须同时说清 $Q$**，否则没有意义。

### 实验 2（python）：一个公式画完整条 Bode 图

```python title="二阶低通的幅频响应：Q 决定形状"
import math

fc = 1000.0
print("f(Hz)     Q=0.5    Q=0.707    Q=2.0")
for f in [100, 500, 1000, 2000, 5000, 10000]:
    u = f / fc
    row = []
    for Q in [0.5, 0.707, 2.0]:
        mag = 1 / math.sqrt((1 - u * u) ** 2 + (u / Q) ** 2)
        row.append(20 * math.log10(mag))          # log10：常用对数，把幅度换成 dB
    print(f"{f:>6}  {row[0]:7.1f}   {row[1]:7.1f}   {row[2]:7.1f}")
```

六行输出把三种 $Q$ 的性格摆在一起：在 10 kHz 处三者都接近 −40 dB（高频渐近线相同，都由阶数决定）；差别全在 $f_c$ 附近——$Q = 2$ 在 1 kHz 处还有 +6.0 dB 的增益，而 $Q = 0.5$ 已经掉了 −6.0 dB。**$Q$ 管形状，阶数管斜率**，这两件事要分开看。

### 快问快答

```quiz
抗混叠滤波器为什么必须放在 ADC 之前，而不是之后再数字滤波？
- 数字滤波精度更高，放后面更好
- 采样是不可逆的：混叠一旦发生就再也无法用数字方法分开 [*]
- 因为模拟滤波器更便宜
? 高于奈奎斯特频率的成分在采样瞬间就被折叠成假的低频，与真实信号混在一起。事后的数字滤波器分不清「真的是 10 Hz」和「50 Hz 混叠成的 10 Hz」。所以必须在采样之前就把它们物理地挡掉。
```

:::warning[常见误区]

**误区一**："阶数越高越好，八阶一定能滤得更干净。"
你以为可以无限堆叠——**每多一阶就多一份代价**：元件公差被放大、运放的增益带宽积被吃掉、相位延迟增加（对控制系统的稳定性是致命的）、成本和功耗上升。工程上三到五阶是常见上限，超过就该考虑数字滤波了。

**误区二**："$f_c$ 就是 −3 dB 那个点。"
你以为这是定义——**只有 Butterworth（$Q = 0.707$）时它才成立**。$Q > 0.707$ 时截止点会鼓包，−3 dB 点右移；$Q < 0.707$ 时 −3 dB 点左移。这也是实验台把"截止频率"和"−3dB 实测"分成两行读数显示的原因。

**误区三**："运放是理想的，滤波器能一直衰减下去。"
你以为高频段会按 −40 dB/dec 无限延伸——真实运放在高频段**开环增益耗尽**，反馈失效，衰减曲线会"翘起来"甚至回升（$f$ 很高时运放的输入电容直接把信号耦合过去）。LM358 在 100 kHz 以上基本失去了滤波能力。**选型时 GBW 至少要大于 $f_c \times$ 增益 $\times 10$。**

:::

## 6. 练习

**练习 1**：用 $R = 10$ kΩ 的反相低通实现 $f_c = 1$ kHz，反馈电容该多大？这段代码忘了 $2\pi$，修到输出 `15.9`（nF）：

```exercise
# @title: 练习：1 kHz 低通需要多大反馈电容
# @check: 15.9
# @hint: 由 fc = 1/(2π·R·C) 反解 C = 1/(2π·R·fc)，结果的单位是法拉，要 ×10⁹ 换成 nF
import math

R = 10000.0     # 反馈电阻（Ω）
fc = 1000.0     # 截止频率（Hz）
C = 1.0 / (R * fc)     # ← 问题在这：分母漏了 2π
print(round(C * 1e9, 1))
```

**练习 2**：一个二阶 Sallen-Key 低通，$R_1 = R_2 = 11$ kΩ，$C_1 = 20$ nF，$C_2 = 10$ nF。(a) 截止频率是多少？(b) 实际的 $Q$ 是多少？(c) 若要求 $f_c = 2$ kHz 且保持同样的 $Q$，电阻该怎么改？

<details>
<summary>点开查看逐步解答</summary>

1. **截止频率**：$f_c = \dfrac{1}{2\pi R\sqrt{C_1C_2}} = \dfrac{1}{2\pi\times11000\times\sqrt{20\times10\times10^{-18}}}$

   $\sqrt{2\times10^{-16}} = 1.414\times10^{-8}$，所以 $f_c = \dfrac{1}{2\pi\times11000\times1.414\times10^{-8}} = 1024$ Hz；
2. **实际 $Q$**：单位增益 Sallen-Key 中 $Q = \dfrac{\sqrt{C_1/C_2}}{2} = \dfrac{\sqrt{2}}{2} = 0.707$ —— 正是 Butterworth；
3. **改到 2 kHz**：$f_c \propto 1/R$（$C$ 不变），所以 $R$ 要减半：$R = 11\times\dfrac{1024}{2000} = 5.6$ kΩ（取标准值 5.6 kΩ）；
4. **$Q$ 不变**：因为 $Q$ 只取决于 $C_1/C_2$ 的比值，与 $R$ 的绝对值无关。

**第 3、4 步揭示了一个实用的设计流程**：先用电容比定 $Q$，再用电阻绝对值定 $f_c$。两者**解耦**，可以分别调——这也是 Sallen-Key 结构流行了六十年的原因。

</details>

## 7. 选读：滤波器"原型"从哪来

<details>
<summary>选读 · Butterworth、Chebyshev、Bessel 的取舍</summary>

二阶低通的一般形式是 $|H|^2 = \dfrac{1}{(1-u^2)^2 + (u/Q)^2}$，不同 $Q$ 给出不同的"原型"：

**Butterworth（$Q = 0.707$）**：选择 $Q$ 使 $|H|^2$ 在 $u = 0$ 处的前 $2n-1$ 阶导数全为零——即"**最平坦**"。它在通带内没有任何起伏，代价是过渡带相对较缓。

**Chebyshev（$Q > 0.707$）**：允许通带内有等幅纹波（比如 ±0.5 dB 或 ±1 dB），换取**更陡的过渡带**。纹波越大，过渡越陡。适合"必须把某个干扰频率压死"的场合（如抗混叠）。

**Bessel（$Q = 0.577$）**：优化目标不是幅频，而是**相位线性**（群延迟最平坦）。它的幅频过渡最缓，但**阶跃响应几乎没有过冲**——因为所有极点都靠近实轴。适合"波形形状不能失真"的场合（如音频、脉冲信号、数据通信）。

**选型口诀**：

- 要通带平 → Butterworth；
- 要过渡陡 → Chebyshev；
- 要波形不失真 → Bessel。

**这个"三者不可兼得"的格局，与第 61 章窗函数的主瓣/旁瓣权衡是同一种结构性矛盾**——在一个域里变陡，必然在另一个域里付出代价。

</details>
