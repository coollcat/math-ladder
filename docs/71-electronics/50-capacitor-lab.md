# 电容：电压的惯性

## 1. 从一个场景开始

打开任何一块电路板，你会发现一个奇怪的规律：**几乎每一颗芯片的电源脚旁边，都蹲着一颗 0.1 µF 的小瓷片电容。** 有些板子上一颗芯片配三四颗。

它们不参与信号，也从来不在原理图的"功能部分"出现。可拿掉它们，电路就开始莫名其妙地复位、跑飞、死机。这些"多余的"元件在干什么？答案是一句话：**电容顶住的是电压。**

## 2. 直觉解释

把电容想成电路里的**水箱**（或者一个带隔膜的密闭容器）：

- 往里灌水，水位会**连续上升**——你没法让水位瞬间跳到某个值，除非用无穷大的流量猛灌；
- 水流停止后，水位**保持在那里**——水箱有记忆；
- 想让水位变化，就必须有水流；**水位变化越快，需要的水流越大**。

对应到电路：

| 水箱 | 电容 |
| --- | --- |
| 水位 $h$ | 电压 $v$ |
| 水流量 | 电流 $i$ |
| 储水量 | 电荷 $Q$ |
| 底面积 $A$（越大越难改变水位） | 电容量 $C$ |

核心结论：**电压不能突变**。想让电容两端的电压瞬间跳变，需要无穷大的电流——物理上做不到。反过来说，**电流却可以突变**（换相瞬间，电流立刻反转，而电压岿然不动）。

这就是"去耦电容"的工作原理：芯片突然要吃一个大电流脉冲时，远处的电源因为导线电感来不及响应，电压会瞬间塌陷；而紧贴芯片的那颗 0.1 µF 电容就像个小水池，就地供水，把电压顶住。

## 3. 正式定义

**电容** $C$：单位电压下储存的电荷量，单位**法拉**（F）

$$C = \frac{Q}{v}$$

**电容的伏安关系**（微分形式，本课的核心）：

$$i = C \frac{dv}{dt}$$

**积分形式**（电压是电流的历史积分）：

$$v(t) = v(t_0) + \frac{1}{C}\int_{t_0}^{t} i(\tau)\, d\tau$$

**储能**：

$$W = \frac{1}{2} C v^2$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $C$ | 电容 | 法拉 F | 1 F = 1 C/V；常用 µF、nF、pF |
| $Q$ | 储存电荷 | 库仑 C | $Q = Cv$ |
| $i$ | 电流 | 安培 A | 与电压的**变化率**成正比，与电压值无关 |
| $dv/dt$ | 电压变化率 | V/s | 就是"水位涨落的速度" |
| $W$ | 储能 | 焦耳 J | 与电压**平方**成正比 |

**串并联**：并联时电容相加 $C = C_1 + C_2$（极板面积变大）；串联时倒数相加 $\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2}$（极板间距变大）。**与电阻的规则正好相反。**

## 4. 分步例题

**例**：一颗 100 µF 的电容，两端电压以 2 V/ms 的速率线性上升。求流过它的电流。

1. 换算单位：$C = 100\ \mu\text{F} = 100 \times 10^{-6} = 10^{-4}$ F；$\dfrac{dv}{dt} = 2\ \text{V/ms} = 2 / 10^{-3} = 2000$ V/s；
2. 代入定义式：$i = C \dfrac{dv}{dt} = 10^{-4} \times 2000 = 0.2$ A；
3. **检验直觉**：0.2 A 是个不小的电流，而电容两端的电压可能只有 3 V——$i$ 与 $v$ 的**大小毫无关系**，只与 $v$ 的**变化率**有关。这是电容最反直觉的地方；
4. 储能校验：若此刻 $v = 3$ V，则 $W = \frac{1}{2}\times10^{-4}\times 9 = 450\ \mu$J；以 0.2 A 充电，功率 $P = vi = 3\times0.2 = 0.6$ W，而 $\dfrac{dW}{dt} = Cv\dfrac{dv}{dt} = 10^{-4}\times3\times2000 = 0.6$ W——一致。

**注意单位陷阱**：µF、nF、pF 之间的换算（$10^{-6}$、$10^{-9}$、$10^{-12}$）是电子学最常见的低级错误来源，没有之一。

## 5. 动手实验

### 实验 1（lab）：方波驱动下的电压与电流

```lab
{
  "type": "capacitor-lab",
  "title": "电容：电压连续，电流可以跳",
  "sliders": [
    { "name": "R", "label": "电阻 R", "min": 100, "max": 10000, "step": 100, "value": 1000 },
    { "name": "Cu", "label": "电容 C", "min": 10, "max": 1000, "step": 10, "value": 100 },
    { "name": "V", "label": "方波幅值 V", "min": 1, "max": 12, "step": 0.5, "value": 5 }
  ]
}
```

上方是驱动方波（灰虚线）与电容电压 $v_C$（绿实线），下方是电流 $i = C\,dv/dt$。盯住琥珀色的"换相"竖线看两件事：

- **绿线是连续的**，它从 0 圆滑地爬向 5 V，从不跳跃；
- **橙线（电流）在换相瞬间直接跳变**——上一刻还是 +5 mA，下一刻立刻变成 −5 mA。

这就是全章最重要的一幅图：**电压守规矩（连续），电流不守规矩（可跳变）。** 把 C 从 100 µF 拖到 1000 µF，绿线的爬升明显变慢（时间常数 $\tau = RC$ 变大十倍），而电流的峰值幅度不变——因为峰值由 $V/R$ 决定，与 $C$ 无关。

### 实验 2（python）：用差分近似微分

```python title="从离散样本里还原 i = C·dv/dt"
C = 100e-6            # 电容（F）
dt = 1e-4             # 采样间隔（s）
V = 5.0               # 方波幅值（V）

# 造一段指数上升的电压样本：v(t) = V(1 - e^{-t/RC})
R = 1000.0
vs = []
for k in range(600):
    t = k * dt
    vs.append(V * (1 - 2.718281828 ** (-t / (R * C))))
    # ** 是乘方运算：2.718 ** x 就是 e 的 x 次方

# 用「后向差分」近似导数：(v[k] - v[k-1]) / dt
for k in [1, 2, 10, 100, 300]:
    dvdt = (vs[k] - vs[k - 1]) / dt
    print(f"t={k*dt*1000:5.1f} ms  v={vs[k]:.3f} V  i={C*dvdt*1000:7.3f} mA")
```

五行的电流值一路递减：刚开始电压爬得最快、电流最大（约 5 mA $= V/R$），到 30 ms 时电压接近满幅、电流几乎为零。**电容充电时电流从大到小，电压从小到大**——两者恰好互补。这段循环里的后向差分，正是电路仿真引擎在每一步做的事情（真实引擎用更稳的后向欧拉法，但思想完全相同）。

### 快问快答

```quiz
一个 10 µF 的电容两端电压以恒定速率 5 V/s 上升，此时流过它的电流是多少？
- 2 µA
- 50 µA [*]
- 0.5 A
? i = C·dv/dt = 10 µF × 5 V/s = 10×10⁻⁶ × 5 = 5×10⁻⁵ A = 50 µA。注意它只取决于电压的变化率，与电容此刻的电压是 1 V 还是 100 V 毫无关系。
```

:::warning[常见误区]

**误区一**："电容通交流、隔直流，所以它像电阻一样'导通'高频。"
你以为电容有条"通路"——其实**电荷从未穿过中间的绝缘介质**。交流能"通过"是因为外部电路在反复充放电：极板上的电荷来来回回，导线里一直有电流，但介质里没有。这个区别在讨论击穿电压、漏电流时就变得至关重要。

**误区二**："电压不能突变，所以电容两端电压永远是连续的。"
你以为这是绝对的——其实那句话准确的表述是：**在电流有限的前提下电压连续**。如果有理想电压源直接并联在电容上（或者一个无穷大的电流脉冲），电压照样会跳。工程上，一个足够大的电流脉冲（比如 ESD 静电放电，瞬间几安培）就能在纳秒级把电压抬上去——这正是为什么电容也不能完全防住 ESD。

**误区三**："去耦电容越大越好。"
你以为 100 µF 一定比 0.1 µF 顶用——**恰恰相反**。大容量电解电容有较大的等效串联电感（ESL），在几十 MHz 以上它已经变成了电感，完全起不了去耦作用。所以真实设计是"大小搭配"：0.1 µF 瓷片管 10~100 MHz，10 µF 管中频，100 µF 以上电解管低频纹波。**频率不同，主角不同。**

:::

```exercise
dv = 2.0              # 电压变化（V）

print(round(i, 3))
```

**练习 2**：一颗 0.1 µF 的去耦电容被充到 5 V。若某芯片在 100 ns 内需要 50 mA 的额外电流，且这段时间全部由这颗电容供给，电容两端的电压会掉多少？

<details>
<summary>点开查看逐步解答</summary>

1. 由 $i = C\,dv/dt$ 得 $\Delta v = \dfrac{i\,\Delta t}{C}$；
2. 代入：$i = 0.05$ A，$\Delta t = 100\times10^{-9}$ s，$C = 0.1\times10^{-6}$ F；
3. $\Delta v = \dfrac{0.05 \times 10^{-7}}{10^{-7}} = 0.05$ V = 50 mV；
4. **结论**：5 V 电源掉 50 mV，约 1%——完全在数字芯片的容差范围内（通常是 ±5%）。

如果把电容换成 0.01 µF，电压会掉 500 mV，芯片就该复位了。这就是为什么**去耦电容的容量要从"允许的纹波"反推**：先定 $\Delta v$ 的预算，再用 $C = i\Delta t/\Delta v$ 算容量。

</details>

## 7. 选读：电容器为什么是"两块板"

<details>
<summary>选读 · 平行板电容公式从哪来</summary>

两块面积 $A$、间距 $d$ 的平行金属板，中间填介电常数为 $\varepsilon$ 的介质。设板间电压为 $v$，由高斯定律，极板上的面电荷密度

$$\sigma = \varepsilon \frac{v}{d}$$

总电荷 $Q = \sigma A = \dfrac{\varepsilon A}{d}\, v$，于是

$$C = \frac{Q}{v} = \varepsilon \frac{A}{d}$$

三个结论一眼可见：**面积越大电容越大**（所以电解电容把箔片卷起来）、**间距越小电容越大**（所以介质层要做到微米级）、**介电常数越大电容越大**（所以高容值的 MLCC 用 BaTiO₃，$\varepsilon_r$ 可达数千）。

顺带解释了两件事：

- **耐压**：$E = v/d$ 是介质中的场强，超过击穿场强就短路。所以要高耐压就得加大 $d$，而加大 $d$ 又会减小 $C$——**同样的体积里，容量和耐压是一对矛盾**；
- **电容的"记忆"**：$Q = Cv$ 说明电荷与电压一一对应，电荷留在极板上，电压就留在那里。这才是"电压不能突变"的物理根源——要让 $v$ 突变，就得让 $Q$ 突变，而 $Q$ 只能通过电流搬运，需要时间。

</details>
