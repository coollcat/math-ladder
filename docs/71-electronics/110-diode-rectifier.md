# 二极管与整流

## 1. 从一个场景开始

手机充电器把墙上 220 V / 50 Hz 的交流电变成 5 V 直流。这中间的第一步，也是最"暴力"的一步，靠的是一个只允许电流单向通过的器件：**二极管**。

它的 V-I 曲线既不是直线，也不是开关——**它是指数曲线**。而那句流传最广的话"硅二极管压降 0.7 V"，其实只是一个粗糙的工程近似。这个 0.7 从哪来？为什么有时是 0.3 V、有时是 1.0 V？

## 2. 直觉解释

二极管是电路里的**单向阀**：

- 正向（从阳极到阴极）加水压：阀门被顶开，水哗哗地过；
- 反向加水压：阀门被压死，一滴都过不去。

但真实阀门有个细节：**顶开它需要一点压力**。水压低于某个值，阀门纹丝不动；超过以后，稍微再加一点压力，流量就暴涨。这个"门槛压力"就是 0.7 V 的由来。

它不是硬门槛（阀门不是突然打开的），而是一条**指数曲线**：电压每增加约 60 mV，电流翻十倍。所以在 1 mA 时压降约 0.6 V，100 mA 时约 0.75 V——**变化十倍电流，压降只动 0.15 V**，这才是"0.7 V"这个近似能用的根本原因。

## 3. 正式定义

**Shockley 二极管方程**：

$$i = I_S\left(e^{v/(n V_T)} - 1\right)$$

其中**热电压**

$$V_T = \frac{kT}{q} \approx 25.85\ \text{mV} \quad (T = 300\ \text{K})$$

**半波整流 + 电容滤波**：

- 输入正半周且高于电容电压时，二极管导通，电容被充到峰值；
- 输入回落，二极管截止，电容独自向负载放电，直到下一个峰值。

**纹波估算**（负载 $R$、滤波电容 $C$、频率 $f$）：

$$V_r \approx \frac{V_p}{f\,R\,C}$$

**输出直流**（半波，扣掉二极管压降 $V_f$）：

$$V_{dc} \approx V_p - V_f - \frac{V_r}{2}$$

| 符号 | 名字 | 典型值 | 含义 |
| --- | --- | --- | --- |
| $I_S$ | 反向饱和电流 | 1N4148 约 2 nA | 越小越好，决定反向漏电流 |
| $n$ | 理想因子 | 1（硅管）~2（肖特基） | 偏离理想 PN 结的程度 |
| $V_T$ | 热电压 | 25.85 mV @25℃ | $kT/q$，随温度线性上升 |
| $V_f$ | 正向压降 | 硅 0.7 V、肖特基 0.3 V、LED 1.8~3.3 V | 工作点处的实际压降 |
| $V_r$ | 纹波峰峰值 | 设计目标通常 < 5% | 输出的"锯齿"幅度 |
| $V_{RRM}$ | 反向重复峰值电压 | 1N4007 = 1000 V | 反向耐压，超过就击穿 |

## 4. 分步例题

**例**：$V_p = 12$ V、50 Hz 半波整流，$R = 1$ kΩ，$C = 470$ µF，硅二极管。求纹波与输出直流。

1. **纹波**：$V_r \approx \dfrac{12}{50\times1000\times470\times10^{-6}} = \dfrac{12}{23.5} = 0.511$ V（峰峰值）；
2. **平均输出**：$V_{dc} \approx 12 - 0.7 - 0.511/2 = 11.04$ V；
3. **负载电流**：$I = 11.04/1000 = 11.0$ mA；
4. **纹波率**：$0.511/11.04 = 4.6\%$——刚好卡在常见的 5% 设计线内；
5. **二极管峰值电流**：导通角很窄，峰值电流远大于平均电流（约 $3\sim5$ 倍），选管时按**峰值**而非平均值；
6. **反向耐压**：截止时二极管要承受 $V_p + V_C \approx 12 + 11$ = 约 24 V，选 1N4001（50 V）绰绰有余。

**第 5 步是最容易翻车的地方**：电容越大、纹波越小，但导通角越窄、峰值电流越大。这就是为什么大容量滤波电容后面常要串一个小电阻或用电感做 $\pi$ 型滤波——为了把峰值电流压下来。


左边是二极管的 V-I 曲线：**0.6 V 以下几乎贴着横轴，0.7 V 附近陡然抬头，之后几乎垂直**。紫色的"膝点"虚线标在 0.7 V——注意曲线的实际拐弯区域相当宽，0.7 V 只是一个方便的记位点。

右边是整流波形：灰色虚线是输入正弦，绿色实线是输出。琥珀色标尺量出纹波峰峰值。做三组对照：

- **C 从 470 µF 拖到 47 µF**：纹波从 0.5 V 涨到约 5 V——输出几乎变成了"跟着正弦跑"；
- **R 从 1 kΩ 拖到 200 Ω**：负载电流涨五倍，纹波同步涨五倍。公式 $V_r \approx V_p/(fRC)$ 被直接验证；
- **f 从 50 Hz 拖到 400 Hz**：纹波缩小八倍。**这正是开关电源用几十 kHz 高频、从而把滤波电容缩到几十 µF 的全部秘密。**

### 实验 2（python）：纹波、电容、频率的三角关系

```python title="反推：想要 1% 纹波，电容该多大"
Vp, f, R = 12.0, 50.0, 1000.0
Vdc = Vp - 0.7                       # 粗估直流输出

print("目标纹波率   允许 Vr      所需 C")
for ratio in [0.20, 0.10, 0.05, 0.01]:
    Vr = ratio * Vdc
    C = Vp / (f * R * Vr)            # 由 Vr = Vp/(fRC) 反解 C
    print(f"   {ratio*100:4.0f}%      {Vr:6.3f} V   {C*1e6:8.0f} µF")
```

四行输出讲清了工频整流的窘境：要 5% 纹波就要 425 µF，要 1% 纹波更是要 2124 µF 的电解电容。这就是为什么老式线性电源又大又重，而现代开关电源（100 kHz）只需约两千分之一的电容就能达到同样效果——**频率是滤波器设计里最有力的杠杆**。

### 实验 3（python）：0.7 V 到底有多"准"

```python title="Shockley 方程：压降随电流怎么变"
import math

VT = 0.02585          # 热电压（V），25 ℃
IS = 2e-9             # 1N4148 的反向饱和电流（A）
n = 1.0

for i in [1e-6, 1e-4, 1e-3, 1e-2, 1e-1]:
    v = n * VT * math.log(i / IS + 1)      # Shockley 方程反解 v
    print(f"i = {i*1000:8.3f} mA  →  v = {v:.4f} V")
```

五档电流跨越十万倍，结电压只从 0.161 V 走到 0.458 V——**平均每十倍电流只增加 60 mV**。这就是"60 mV/decade"规则，也是"0.7 V"近似之所以好用的原因。

要留意这套数字只算了**理想结电压**（取 $n = 1$）。真实的 1N4148 还要串联几十欧的体电阻：10 mA 时结电压约 0.4 V，加上体电阻上的 0.2~0.3 V，总压降就落在 0.7 V 附近——**"0.7 V"是结特性与体电阻共同的结果**，不是一个基本常数。

### 快问快答

```quiz
把整流后的滤波电容从 470 µF 加大到 2200 µF，纹波和二极管峰值电流分别会怎样变化？
- 纹波变小，峰值电流也变小
- 纹波变小，但峰值电流变大 [*]
- 两者都不变
? 电容越大，放电越慢，纹波按 1/C 减小；但同时导通角变窄，同样的电荷必须在更短时间内灌进去，峰值电流反而上升。选型时二极管要按峰值电流而非平均电流来定。
```

:::warning[常见误区]

**误区一**："硅二极管压降恒为 0.7 V。"
你以为它是个常数——**它是个工作点函数**。1N4148 在 1 µA 时压降只有 0.2 V，在 100 mA 时约 0.9 V（还要加上体电阻的 $iR$ 项）。粗略计算用 0.7 V 没问题，但在检波、对数放大、精密整流这类场合必须回到 Shockley 方程。另外：**肖特基二极管是 0.3 V，LED 是 1.8~3.3 V**（颜色越偏蓝越高）。

**误区二**："整流后加个电容，输出就是平滑直流了。"
你以为电容把纹波滤掉了——**只是变小，不是消失**。纹波永远是 $V_r \approx V_p/(fRC)$，要彻底压平得靠稳压器（第 160 课）。更麻烦的是纹波会进入反馈环路：音频功放里的"交流声"、测量电路里的工频干扰，全都是它。

**误区三**："二极管反接就截止，所以反向可以随便接多高电压。"
你以为反向是绝缘的——**每个二极管都有反向击穿电压 $V_{RRM}$**。1N4001 是 50 V，1N4007 是 1000 V。超过就雪崩击穿，虽然齐纳二极管专门利用这个区域稳压，但普通整流管击穿后往往直接永久损坏。**选型时反向耐压要留 1.5~2 倍余量**，因为电网有浪涌。

:::

## 6. 练习

**练习 1**：$V_p = 12$ V、$f = 50$ Hz、$R = 1$ kΩ、$C = 470$ µF 的半波整流，纹波多大？这段代码把 µF 当成了 F，修到输出 `0.511`：

```exercise
# @title: 练习：整流纹波有多大
# @check: 0.511
# @hint: 纹波 ≈ Vp/(f·R·C)，C 的单位必须是法拉。470 µF = 470×10⁻⁶ F，代码直接把 470 代进去了
Vp = 12.0
f = 50.0
R = 1000.0
C_uF = 470.0
Vr = Vp / (f * R * C_uF)   # ← 问题在这：微法要换算成法拉
print(round(Vr, 3))
```

**练习 2**：用 1N4007（$V_f = 0.7$ V）做一个 220 V / 50 Hz 市电的半波整流，想要 12 V / 100 mA 的直流输出。估算所需的滤波电容，并指出这个方案的两个致命问题。

<details>
<summary>点开查看逐步解答</summary>

1. **峰值**：$220\ \text{V}_{\text{rms}} \times \sqrt{2} = 311$ V；
2. **纹波预算**：取 5%，$V_r = 0.05\times12 = 0.6$ V；
3. **负载电阻**：$R = 12/0.1 = 120$ Ω；
4. **电容**：$C = \dfrac{V_p}{f R V_r} = \dfrac{12}{50\times120\times0.6} = 3.3\times10^{-3}$ F = **3300 µF**；

**两个致命问题**：

- **效率灾难**：输入峰值 311 V，输出只要 12 V。多余的 299 V 全部落在调整元件上，$P = 299 \times 0.1 \approx 30$ W 变成热，而负载只要 1.2 W——效率 4%。这就是第 160 课要讲的线性稳压困境，也是必须用开关电源的原因；
- **安全**：220 V 直接整流，整个板子带高压，没有隔离变压器就是触电风险。真实 charger 用高频变压器做隔离 + 降压，这正是开关电源的核心价值。

</details>

## 7. 选读：PN 结为什么会单向导电

<details>
<summary>选读 · 从载流子浓度推出指数曲线</summary>

把 P 型半导体（空穴多）与 N 型半导体（电子多）贴在一起。交界面处，N 区的电子向 P 区扩散、P 区的空穴向 N 区扩散，在界面两侧留下不能移动的正负离子，形成一个**内建电场**（约 0.6~0.7 V，对硅而言）——这就是**空间电荷区**，也叫耗尽层。

**加正向电压**时，外电场削弱内建电场，耗尽层变窄，多数载流子被大量注入对方区域，形成扩散电流。能越过势垒的载流子数目由玻尔兹曼分布决定，正比于

$$e^{qv/kT}$$

这就是 Shockley 方程里那个指数的来源。**它不是经验拟合，而是统计物理的必然结果。**

**加反向电压**时，内建电场被加强，多数载流子更难过界，只剩下少数载流子的漂移电流——一个极小（nA 级）且几乎不随电压变化的常数 $I_S$。

顺带解释温度效应：$V_T = kT/q$ 随温度上升，而 $I_S$ 随温度**指数**上升（每升高 10℃ 约翻倍）。两者叠加的结果是：**温度升高时，同样电流下的正向压降下降约 2 mV/℃**。这个特性既是温度传感器（如二极管测温）的原理，也是功率器件热失控的根源。

</details>
