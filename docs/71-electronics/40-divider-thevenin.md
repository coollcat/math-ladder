# 分压、分流与戴维南等效

## 1. 从一个场景开始

一只电位器式角度传感器，用 1 kΩ 上拉、3 kΩ 下拉的分压网络把角度变成电压。万用表量空载输出：9.00 V，完美。焊到单片机的 ADC 输入脚上，读数却只有 6.5 V——**电压凭空少了 2.5 V。**

没有元件坏，也没有接错线。少的那部分，是被单片机自己的输入电阻"偷走"的。这场事故有个正式名字：**负载效应**。

## 2. 直觉解释

任何有两个端子的**线性**电路，从外面看进去，行为只有两种可能的表现：

- 不接东西时，两端有一个电压（**开路电压**）；
- 接上负载后，电压会掉一点，掉多少取决于负载拉了多少电流。

这两件事合起来，恰好等价于**一个理想电压源串联一个内阻**——这就是**戴维南等效**。

一个绝佳的类比是**干电池**：一节 5 号电池标称 1.5 V，那是它的开路电压；接上马达后电压掉到 1.2 V，因为电池内部有约 0.2 Ω 的内阻在分压。电池老化就是内阻变大——开路电压还是 1.5 V，一带载就垮。**"电压源 + 内阻"不是数学技巧，是真实世界的模样。**

## 3. 正式定义

**分压公式**（两个电阻串联，输出电压取自 $R_2$ 两端）：

$$V_{\text{out}} = V_s \cdot \frac{R_2}{R_1 + R_2}$$

**分流公式**（两个电阻并联，总电流 $I$ 分给 $R_1$）：

$$I_1 = I \cdot \frac{R_2}{R_1 + R_2}$$

注意分子是**对面那个**电阻——并联时电阻越大分到的电流越小。

**戴维南等效定理**：任意由独立源与线性电阻组成的二端网络，对外部负载而言等价于电压源 $V_{th}$ 串联电阻 $R_{th}$：

$$V_{th} = V_{\text{开路}}, \qquad R_{th} = \left.\frac{V_{\text{开路}}}{I_{\text{短路}}}\right|_{\text{独立源置零后看进去的等效电阻}}$$

**带载输出**（负载 $R_L$ 接在输出端）：

$$V_{\text{out}} = V_{th} \cdot \frac{R_L}{R_{th} + R_L}$$

**最大功率传输**：当 $R_L = R_{th}$ 时负载获得最大功率 $P_{\max} = V_{th}^2/(4R_{th})$，此时效率只有 50%。

| 符号 | 名字 | 求法 |
| --- | --- | --- |
| $V_{th}$ | 戴维南电压 | 输出端**空载**时的电压 |
| $R_{th}$ | 戴维南电阻 | 独立电压源短路、独立电流源开路后，从输出端看进去的等效电阻 |
| $R_L$ | 负载电阻 | 接在网络输出端的下一级 |
| $\Delta V$ | 负载误差 | $V_{th} - V_{\text{out}} = V_{th}\cdot R_{th}/(R_{th}+R_L)$ |

**$R_{th}$ 的求法口诀**："压源变导线，流源变断路，然后从端口往里数电阻。"

## 4. 分步例题

**例**：$V_s = 12$ V，$R_1 = 1\ \text{k}\Omega$（上拉），$R_2 = 3\ \text{k}\Omega$（下拉）。求戴维南等效，并算出接 $R_L = 2\ \text{k}\Omega$ 后的实际输出。

1. **求 $V_{th}$**（空载）：$V_{th} = 12 \times \dfrac{3}{1+3} = 9.0$ V；
2. **求 $R_{th}$**：把 12 V 电源短路成一根导线，从输出端看进去，$R_1$ 与 $R_2$ 变成并联：$R_{th} = \dfrac{1\times3}{1+3} = 0.75\ \text{k}\Omega = 750\ \Omega$；
3. **接上负载**：$R_L = 2$ kΩ 与 $R_2$ 并联，等效下拉电阻 $= \dfrac{3\times2}{3+2} = 1.2$ kΩ；
4. **算输出**：$V_{\text{out}} = 12 \times \dfrac{1.2}{1 + 1.2} = 6.545$ V；
5. **用戴维南验证**：$V_{\text{out}} = 9.0 \times \dfrac{2000}{750 + 2000} = 6.545$ V——**两条路完全一致**。

这就是定理的威力：第 5 步完全不需要知道网络内部长什么样，只用两个数（9 V、750 Ω）就复现了第 3、4 步的全部细节。误差 $9.0 - 6.545 = 2.455$ V，正是开头那个"凭空消失"的电压。

**工程结论**：想让负载效应小，就得 $R_L \gg R_{th}$（一般取 10 倍以上，误差降到 9% 以下）。这也是"输入阻抗要高、输出阻抗要低"这条金律的定量版本。

### 实验 1（lab）：原电路与等效电路，曲线重合吗

```lab
    { "name": "R2", "label": "下拉 R2", "min": 100, "max": 10000, "step": 100, "value": 3000 },
    { "name": "RL", "label": "负载 RL", "min": 100, "max": 20000, "step": 100, "value": 2000 }
  ]
}
```

用顶部的分段按钮在"原电路"与"戴维南等效"之间来回切——**右边那条 Vout-RL 曲线纹丝不动**，读数里"Vout（原）"与"Vout（等效）"的误差停在 $10^{-6}$ 量级。这就是等效的含义：**外部世界无法区分这两者**。

然后做三件事：

- 把 RL 从 100 Ω 拖到 20 kΩ——曲线从接近 0 V 爬升到逼近 $V_{th}$（虚线渐近线）。$R_L$ 越小，输出被拉得越狠；
- 找到紫色的"最大功率点"——它正好在 $R_L = R_{th} = 750$ Ω 处，对应 $V_{out} = V_{th}/2 = 4.5$ V；
- 把 R1 改成 100 Ω、R2 改成 9.9 kΩ——$V_{th}$ 变成 11.88 V，但 $R_{th}$ 只有 99 Ω。分压比变了，负载效应也变了，**两者是独立的两件事**。

### 实验 2（python）：负载误差到底多大才够用

```python title="扫描负载电阻，看误差何时降到可接受"
Vs, R1, R2 = 12.0, 1000.0, 3000.0
Vth = Vs * R2 / (R1 + R2)               # 空载电压
Rth = R1 * R2 / (R1 + R2)               # 源置零后看进去的电阻

print(f"Vth = {Vth:.3f} V   Rth = {Rth:.1f} Ω")
print("R_L/R_th    Vout     误差%")
for ratio in [0.1, 1, 3, 10, 100]:      # 负载与内阻的比值
    RL = ratio * Rth
    Vout = Vth * RL / (Rth + RL)
    err = (Vth - Vout) / Vth * 100
    print(f"{ratio:>6}    {Vout:6.3f}   {err:5.1f}%")
```

五行输出讲清了整件事：$R_L = R_{th}$ 时误差高达 50%（输出只剩一半，代价换来最大功率）；$R_L = 10 R_{th}$ 时误差 9.1%；$R_L = 100 R_{th}$ 时误差降到 1%。**"十倍法则"就是从这张表来的**——传感器接口设计里，ADC 的输入阻抗至少要取信号源内阻的十倍。

### 快问快答

```quiz
一个戴维南等效电路（Vth = 10 V，Rth = 100 Ω）要给负载供出最大功率，负载应该取多大？
- 越大越好，比如 100 kΩ
- 等于内阻，即 100 Ω [*]
- 越小越好，比如 1 Ω
? 最大功率传输定理：RL = Rth 时负载功率最大（此处为 10²/(4×100) = 0.25 W）。但要留意，此时效率只有 50%——另一半功率烧在内阻上。电力系统追求的是效率，所以它反其道而行，让负载远大于内阻。
```

:::warning[常见误区]

**误区一**："空载量到 9 V，接上负载自然还是 9 V。"
你以为电压源的电压是恒定的——其实**只有理想电压源才是恒定的**。任何真实信号源都有内阻，一带载就掉。传感器、运放输出、甚至电池，全都不例外。测量电路前先问一句："我的万用表输入阻抗有多大？"（一般是 10 MΩ，对大多数电路足够大，但对高内阻的 pH 电极就远远不够）。

**误区二**："$R_{th}$ 就是把独立源置零后数电阻，任何时候都这么算。"
你以为这一步永远有效——**含受控源（如晶体管的等效模型）时不能这么干**。受控源不能置零，必须保留，然后在端口外加一个测试电压 $V_t$、算流入电流 $I_t$，用 $R_{th} = V_t/I_t$ 求。这是模电里最容易翻车的一步。

**误区三**："最大功率传输定理说 $R_L = R_{th}$，所以任何时候都该这么配。"
你以为那是普适的最优——它只在**功率**这一个指标下最优，且效率恰好 50%。电力系统要的是效率（所以 $R_L \gg R_{th}$，让绝大部分功率送到负载）；射频与天线要的是功率（所以做阻抗匹配，让它等于 50 Ω）。**先说清优化目标，再谈"最优"。**

:::

**练习 1**：$V_s = 12$ V，$R_1 = 1$ kΩ，$R_2 = 3$ kΩ，接上 $R_L = 2$ kΩ 后的实际输出电压。这段代码忘了 RL 与 R2 并联，修到输出 `6.545`：

```exercise
# @title: 练习：带上负载后的输出电压
# @check: 6.545
# @hint: 接上 RL 后，下拉支路变成 R2 与 RL 并联，等效电阻是 (R2×RL)/(R2+RL)。代码直接拿 R2 当下拉电阻，等于假设负载不存在
Vs = 12.0
R1 = 1000.0
R2 = 3000.0
RL = 2000.0
low = R2                      # ← 问题在这：下拉支路应该是 R2 与 RL 的并联值
Vout = Vs * low / (R1 + low)
print(round(Vout, 3))
```

**练习 2**：一个信号源的开路电压为 2.0 V，接上 500 Ω 负载后输出降到 1.6 V。求它的戴维南电阻与短路电流。

<details>
<summary>点开查看逐步解答</summary>

1. $V_{th} = 2.0$ V（开路电压）；
2. 带载时 $V_{out} = V_{th}\cdot \dfrac{R_L}{R_{th}+R_L}$，即 $1.6 = 2.0 \times \dfrac{500}{R_{th}+500}$；
3. 化简：$\dfrac{1.6}{2.0} = 0.8 = \dfrac{500}{R_{th}+500}$，得 $R_{th} + 500 = 625$，所以 $R_{th} = 125\ \Omega$；
4. 短路电流 $I_{sc} = V_{th}/R_{th} = 2.0/125 = 16$ mA。

**"加一个已知负载、量一次电压"是实测 $R_{th}$ 的标准手法**——比"把源置零后数电阻"实用得多，因为你不必拆开设备、也绕开了受控源的坑。工程上管这叫"加载法"。

</details>

## 7. 选读：戴维南定理为什么成立

<details>
<summary>选读 · 用线性性三步推出等效电路</summary>

设二端网络内部全是独立源与线性电阻，端口电压为 $v$、端口电流为 $i$（取流出的方向）。节点分析告诉我们，端口的伏安关系是线性的，必可写成

$$v = A + B\, i$$

其中 $A$、$B$ 是常数。现在取两个特例：

1. **开路**（$i = 0$）：$v = A$，所以 $A = V_{th}$（开路电压）；
2. **短路**（$v = 0$）：$0 = A + B\, i_{sc}$，所以 $B = -V_{th}/i_{sc} = -R_{th}$。

于是 $v = V_{th} - R_{th}\, i$——这正是"电压源 $V_{th}$ 串联电阻 $R_{th}$"的端口方程。**两个特例定出两个常数，一条直线就被完全确定了。**

整个证明只用了"线性"这一个性质。所以定理的适用边界非常清晰：**网络必须是线性的**。一接上二极管，伏安关系不再是直线，戴维南等效就只在某个工作点附近局部成立（这就是后面"小信号模型"的思路）。

</details>
