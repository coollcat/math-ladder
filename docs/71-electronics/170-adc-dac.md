# ADC 与 DAC

## 1. 从一个场景开始

一个 12 位 ADC 配 3.3 V 参考电压，能把电压切成 $2^{12} = 4096$ 级，每级 0.8 mV。听起来精度很高。

可实际测出来，有效分辨率常常只有 10 位——**少了 2 位，误差大了 4 倍。** 少的那两位去哪了？

答案是：模拟到数字要过**两道门**，每道门都会丢东西。

- **采样**：把连续时间切成离散时刻。时间分辨率不够 → **混叠**（第 61 章讲过）；
- **量化**：把连续幅度切成离散台阶。幅度分辨率不够 → **量化噪声**（本课主题）。

第一道门由采样定理把关，第二道门由位数把关。**位数只是上限，不是保证。**

## 2. 直觉解释

把量化想成**把一个斜坡改造成楼梯**：

- 真实的模拟信号是平滑的斜坡；
- ADC 只能报出"你在第几级台阶上"，所以斜坡被拍成了一级级的阶梯；
- 台阶高度 = **量化步长 $\Delta$** = 满量程 ÷ $2^N$。

被"拍平"的那一小块就是**量化误差**，它永远在 $\pm\Delta/2$ 之间。

关键观察：**量化误差看起来像噪声。** 它是一种"因为信息被丢弃而引入的不确定性"——这正是第 40 章信息论里熵的概念在电路里的对应物。位数每加一位，台阶高度减半，不确定性减半，信噪比改善 6 dB。

## 3. 正式定义

**量化步长**（LSB，最低有效位对应的电压）：

$$\Delta = \frac{V_{ref}}{2^N}$$

**量化误差**：$e = v - Q(v) \in [-\Delta/2, +\Delta/2]$

**量化噪声**（在误差均匀分布、与信号无关的假设下）：

$$e_{rms} = \frac{\Delta}{\sqrt{12}}$$

**理想 ADC 的信噪比**（输入满量程正弦波）：

$$\text{SNR} = 6.02\,N + 1.76\ \text{dB}$$

**有效位数**（ENOB，把实测 SNR 反推回"相当于几位"）：

$$\text{ENOB} = \frac{\text{SNR}_{measured} - 1.76}{6.02}$$

**采样定理**（第一道门）：

$$f_s > 2 f_{max}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $N$ | 分辨率 | 位 | 8 / 10 / 12 / 16 / 24 常见 |
| $\Delta$ | 量化步长（1 LSB） | V | $V_{ref}/2^N$ |
| $e_{rms}$ | 量化噪声有效值 | V | 理论 $\Delta/\sqrt{12}$ |
| SNR | 信噪比 | dB | 理想 $6.02N + 1.76$ |
| ENOB | 有效位数 | 位 | **实测**性能，通常小于 $N$ |
| $f_s$ | 采样率 | Sa/s | 必须 > $2f_{max}$ |

## 4. 分步例题

**例**：12 位 ADC，$V_{ref} = 3.3$ V，输入满量程正弦波（峰峰值 3.3 V）。

1. **量化步长**：$\Delta = 3.3/4096 = 8.06\times10^{-4}$ V = **0.806 mV**；
2. **量化噪声**：$e_{rms} = 0.806/\sqrt{12} = 0.233$ mV；
3. **信号有效值**：满量程正弦的 $V_{rms} = \dfrac{3.3}{2\sqrt{2}} = 1.167$ V；
4. **理论 SNR**：$20\log_{10}(1.167/0.000233) = 20\log_{10}(5007) = 74.0$ dB，与公式 $6.02\times12 + 1.76 = 74.0$ dB 完全吻合 ✓；
5. **若实测 SNR = 62 dB**：$\text{ENOB} = (62-1.76)/6.02 = 10.0$ 位——**标称 12 位，实际只有 10 位**；
6. **丢失的原因**：参考电压漂移、积分非线性（INL）、微分非线性（DNL）、时钟抖动、电源噪声、前端运放的噪声……**位数只是"理想上界"。**

**第 5 步是硬件工程师的常识**：选 ADC 时不要看位数，要看数据手册里 SNR、INL、DNL 的实测曲线。一颗 16 位 ADC 用在不干净的参考电压上，有效位数可能不如一颗 12 位 ADC 配精密基准。

上图：灰色虚线是原始正弦，橙色阶梯是 DAC 用"零阶保持"重建出来的波形，琥珀色圆点是采样点，浅灰横线是量化电平。中图：量化误差（红色）。下图：各位的权重。

做三个实验：

- **bits 从 4 拖到 8**：台阶越来越细，红色误差波形的幅度肉眼可见地缩小。读数里的实测 SNR 会逼近理论值 $6.02N+1.76$——**每加一位改善 6 dB，这条规律被当场验证**；
- **bits 拖到 2 或 1**：阶梯粗得像楼梯，SNR 掉到十几 dB。1 位就是"比较器"——只有 0 和 1（这也是 $\Delta$-$\Sigma$ 型 ADC 的起点，它用极高的采样率换极高的分辨率）；
- **spc 拖到 1.5**：采样率低于奈奎斯特，读数亮起"⚠ 混叠"警告。此时阶梯完全看不出原始信号的形状——**第一道门没过，第二道门做得再好也没用。**

### 实验 2（python）：把 6.02 dB/bit 量出来

```python title="从量化误差反推 SNR，验证 6.02N + 1.76"
import math

Vref = 2.0                       # 满量程 ±1 V
for N in [4, 8, 12, 16]:
    step = Vref / (2 ** N)       # ** 是乘方：2 的 N 次方
    se = 0.0
    n = 0
    for k in range(2000):        # 对一整个周期采样，统计误差能量
        v = math.sin(2 * math.pi * k / 2000)
        q = round(v / step) * step     # 量化：四舍五入到最近的台阶
        se = se + (v - q) ** 2
        n = n + 1
    rms = math.sqrt(se / n)
    snr = 20 * math.log10((1 / math.sqrt(2)) / rms)   # 正弦有效值 = 1/√2
    print(f"N={N:>2}  Δ={step:.3e}  RMS={rms:.3e}  SNR={snr:6.2f} dB  (理论 {6.02*N+1.76:.2f})")
```

四行输出里，实测 SNR 与理论值的差从 N=4 时的 0.4 dB 缩小到 N=12 时的 0.01 dB——**位数越高，"量化误差均匀分布"这个假设越成立**，吻合得越好。**6.02 这个系数不是经验值**，它来自 $20\log_{10} 2$——位数加一，台阶减半，噪声减半，就是 6.02 dB。把这个数刻在脑子里，选 ADC 时一眼就能估出性能。

注意代码里用了 `round(...)` 做量化——它把连续值"吸附"到最近的离散台阶上，这就是量化的全部动作。

### 快问快答

```quiz
把 ADC 的分辨率从 12 位提高到 14 位，理想情况下信噪比会改善多少？
- 翻倍，即改善 3 dB
- 改善约 12 dB [*]
- 改善 20 dB
? 每增加一位，量化台阶减半、噪声减半，SNR 改善 20×log₁₀(2) ≈ 6.02 dB。加两位就是约 12 dB。这就是「6 dB 一位」这条工程口诀的来历。
```

:::warning[常见误区]

**误区一**："12 位 ADC 就能得到 12 位精度。"
你以为位数等于精度——**位数是"理想上限"，ENOB 才是实际值**。影响 ENOB 的因素有一长串：参考电压的温度漂移（50 ppm/℃ 的基准在 50℃ 变化下就贡献 0.25% 误差 = 8 位水准）、INL/DNL、时钟抖动、前端放大器噪声、电源纹波、甚至 PCB 布局。**一颗 12 位 ADC 做到 10 位 ENOB 是常态，做到 11.5 位需要精心设计和良好布局。**

**误区二**："提高采样率就能提高精度。"
你以为多采几个点更准——**采样率管的是时间（混叠），位数管的是幅度（量化），两者独立**。不过有个例外：**过采样 + 数字滤波**确实能换分辨率——把采样率提高 4 倍并做平均，噪声被压低一半，等效多赚 1 位。$\Delta$-$\Sigma$ 型 ADC 正是靠 64~256 倍过采样，用 1 位量化器实现 24 位分辨率。

**误区三**："参考电压用电源电压就行，反正有 3.3 V。"
你以为可以用电源当基准——**电源是噪声最大的地方**。开关电源的纹波、数字电路的同步噪声（几百 mV 量级）会直接灌进 ADC 的基准，把 12 位变成 8 位。精密测量必须用独立的**基准电压源**（如 TL431、REF3030、ADR4525），并且要单独去耦、单独走线。**参考电压的质量就是 ADC 精度的天花板。**

:::

## 6. 练习

**练习 1**：12 位 ADC，参考电压 3.3 V，一个 LSB 是多少毫伏？这段代码把 $2^N$ 写成了 $2N$，修到输出 `0.806`：

```exercise
# @title: 练习：12 位 ADC 的一个 LSB 是多少伏
# @check: 0.806
# @hint: 台阶高度 = 参考电压 ÷ 2^N，级数是 2 的 N 次方（4096），不是 2×N。最后 ×1000 换成毫伏
Vref = 3.3
N = 12
lsb = Vref / (2 * N)    # ← 问题在这：分母应是 2 ** N
print(round(lsb * 1000, 3))
```

**练习 2**：一个 16 位 ADC 的实测 SNR 为 82 dB。(a) 它的有效位数是多少？(b) 与理想 16 位相比损失了多少位？(c) 若把前端运放的噪声降低一半（其他不变），新的 SNR 大约是多少？

<details>
<summary>点开查看逐步解答</summary>

1. **ENOB**：$\text{ENOB} = (82 - 1.76)/6.02 = 13.3$ 位；
2. **损失**：$16 - 13.3 = 2.7$ 位，相当于噪声比理想大 $2^{2.7} \approx 6.5$ 倍；
3. **降噪后**：总噪声是"量化噪声 + 运放噪声"的功率和（不相关的噪声相加要用平方和）：

   设总量 $e_{tot}$、量化 $e_q$、运放 $e_a$，则 $e_{tot}^2 = e_q^2 + e_a^2$。

   理想 16 位 SNR 应为 98.1 dB，实测 82 dB，差 16.1 dB——说明运放噪声占主导：
   $e_a/e_q = \sqrt{10^{1.61} - 1} = \sqrt{39.8} = 6.3$（运放噪声是量化噪声的 6.3 倍）；
4. **运放噪声减半**：$e_a' = 3.15 e_q$，新总噪声 $= e_q\sqrt{1 + 9.9} = 3.30 e_q$，比原来（6.38 $e_q$）降低 $20\log_{10}(6.38/3.30) = 5.7$ dB；
5. **新 SNR**：$82 + 5.7 = 87.7$ dB，对应 ENOB $= 14.3$ 位。

**这道题揭示了 ADC 系统设计的核心规律**：改善**主导**噪声源才有意义。运放噪声占主导时，换更高位数的 ADC 毫无用处——这 2.7 位的损失不在 ADC 里，在前端。

</details>

## 7. 选读：为什么是 6.02，又为什么是 $\sqrt{12}$

<details>
<summary>选读 · 两个系数的来历</summary>

**$\sqrt{12}$ 从哪来**：量化误差在 $[-\Delta/2, +\Delta/2]$ 上均匀分布（当信号足够复杂、台阶足够细时这个假设很好）。均匀分布的方差是

$$\sigma^2 = \frac{1}{\Delta}\int_{-\Delta/2}^{\Delta/2} e^2\,de = \frac{1}{\Delta}\cdot\frac{e^3}{3}\Big|_{-\Delta/2}^{\Delta/2} = \frac{\Delta^2}{12}$$

所以 $e_{rms} = \Delta/\sqrt{12}$。

**6.02 从哪来**：满量程正弦（峰峰值 $V_{ref}$）的有效值是 $V_{ref}/(2\sqrt{2})$。于是

$$\text{SNR} = 20\log_{10}\frac{V_{ref}/(2\sqrt{2})}{\Delta/\sqrt{12}} = 20\log_{10}\frac{V_{ref}/(2\sqrt{2})}{V_{ref}/(2^N\sqrt{12})}$$

$= 20\log_{10}\left(2^N \cdot \dfrac{\sqrt{12}}{2\sqrt{2}}\right) = 20\log_{10} 2^N + 20\log_{10}(1.2247)$

$= 6.02\,N + 1.76\ \text{dB}$

第一项来自 $20\log_{10} 2 = 6.0206$（每加一位台阶减半），第二项来自 $\sqrt{12}/(2\sqrt{2}) = 1.2247$（均匀噪声与正弦有效值的比例）。

**这个假设什么时候失效**？当输入信号变化很慢、或者输入频率与采样率成简单整数比时，量化误差会变成**周期性的**而非随机的——它不再是"噪声"，而是**谐波失真**（听起来像刺耳的谐波而不是沙沙的底噪）。这就是高端音频里要加 **dither（抖动）** 的原因：故意掺入一点点随机噪声，把讨厌的谐波打散成均匀的底噪。

</details>
