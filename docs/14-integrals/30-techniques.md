# 不定积分与换元

## 1. 从一个场景开始

上一课的牛顿-莱布尼茨公式把积分题变成了"找原函数"题。可找原函数至今靠灵光一现——总不能每道题都现场发明吧？求导当年也这样：先有定义，后有规则表，从此告别硬算。现在轮到给"反求导"发装备了。

## 2. 直觉解释

把第 13 章的求导法则**倒着放电影**：

- 幂规则 $(x^n)'=nx^{n-1}$ 倒放：$x^4$ 的原函数？次数升一级、除以新次数——$\dfrac{x^5}{5}$；
- 和规则倒放：各项的原函数各自领走；
- 常数倍倒放：系数原封不动带出去。

复合函数的链式法则倒放，就是本课的主角**凑微分（换元法）**：看到"里层函数的导数 × 复合函数"手拉手出现，就把里层整个设成一个新变量。

## 3. 正式定义

$f$ 的**不定积分**记作

$$\int f(x)\,dx = F(x) + C, \qquad F' = f$$

注意它与定积分的区别：不定积分的结果是**一族函数**，定积分是一个**数**。

$+C$ 不是装饰。因为 $(F+C)'=F'=f$，任何原函数上下平移后仍是原函数——所以 $\int x^2dx$ 的完整答案是 $\frac{x^3}{3}+C$，代表一族竖移曲线。丢掉 $C$ 等于只交了家族中的一个成员，其余全体失踪。

**基本积分表**（求导规则表的镜像）：

| 不定积分 | 来源（哪条求导规则的倒放） |
| --- | --- |
| $\displaystyle\int x^n dx = \frac{x^{n+1}}{n+1}+C\ (n\neq -1)$ | 幂规则倒放 |
| $\displaystyle\int \big(f \pm g\big)dx = \int f dx \pm \int g\,dx$ | 和差规则倒放 |
| $\displaystyle\int c\,f(x)\,dx = c\int f(x)\,dx$ | 常数倍规则倒放 |
| $\displaystyle\int e^x dx = e^x + C,\quad \int \cos x\,dx = \sin x + C,\quad \int \sin x\,dx = -\cos x + C$ | 三大明星导数倒放 |

## 4. 分步例题

**例 1**：求 $\displaystyle\int (3x^2+1)\,dx$，并求导回验。

1. 拆开：$\displaystyle\int 3x^2dx + \int 1\,dx$；
2. 幂规则倒放：$3x^2$ 的原函数是 $3\cdot\dfrac{x^3}{3}=x^3$；$1$ 的原函数是 $x$；
3. 合并加 C：$x^3+x+C$；
4. **回验**（养成习惯）：$(x^3+x+C)'=3x^2+1$ ✓ 与被积函数一致。

**例 2（凑微分）**：求 $\displaystyle\int 2x\,(x^2+1)^5\,dx$。

1. 观察手拉手：被积函数里有复合函数 $(x^2+1)^5$，旁边恰好躺着它的导数亲戚 $2x$（$(x^2+1)'=2x$）——这是链式法则倒放的信号；
2. 设 $u=x^2+1$，则 $du=2x\,dx$；
3. 整体替换：$\displaystyle\int u^5\,du = \frac{u^6}{6}+C$；
4. 换回：$\dfrac{(x^2+1)^6}{6}+C$。回验：求导时链式法则给出 $6(x^2+1)^5\cdot 2x / 6 = 2x(x^2+1)^5$ ✓。

## 5. 动手实验

### 实验 1（viz）：+C 到底长什么样

```viz

```

怎么玩：拖动滑块 $c$，整条曲线上下平移——形状纹丝不动。这就是 $+C$ 的几何面目：原函数不是一个点，是一整个**平行曲线家族**，随便挑哪个成员去算定积分都一样（端点相减时平移量抵消）。

### 实验 2（python）：例 2 的结果数值验收

```python title="∫₀¹ 2x(x²+1)⁵ dx：切细条 vs 换元解析解"
def f(x):
    return 2 * x * (x ** 2 + 1) ** 5

w = 0.001                # 把 [0,1] 切成一千份，每份宽 0.001
total = 0
for k in range(1000):
    xm = (k + 0.5) * w   # 第 k 条的中点位置
    total = total + f(xm) * w
print(f"老实切一千刀 ≈ {round(total, 4)}")
print(f"换元解析解 (2⁶-1)/6 = {round((2 ** 6 - 1) / 6, 4)}")
```

两行都打印 `10.5`：解析解来自 $\dfrac{u^6}{6}$ 在两端取值相减——$u(1)=2$、$u(0)=1$，$\dfrac{2^6-1}{6}=10.5$。暴力与技巧再次会师。

:::warning[常见误区]

**误区一**："你以为 +C 可写可不写。" 这是初学第一大错。不定积分的答案是**一族函数**，漏掉 $C$ 就漏掉了整个家族；后续一旦拿它解方程、套初值条件，答案直接错位。写 $\int x^2dx=\frac{x^3}{3}+C$，一个字母都不许省。

**误区二**："你以为换元只是换个字母好看。" 换元的灵魂在微分也要跟着换：设 $u=x^2+1$ 后必须同步写出 $du=2x\,dx$，把被积表达式**整体**翻译成 $u$ 的语言。只换字母不换 $du$，式子就成了四不像。

**误区三**："你以为不定积分和定积分只是记号略不同。" 差得远：$\int f\,dx$ 是一族函数（带 $+C$），$\int_a^b f\,dx$ 是一个数（不许带 $C$）。前者是"反求导"，后者是"面积"，靠牛顿-莱布尼茨公式连成一条流水线。

:::

## 6. 练习

**练习 1**：用牛顿-莱布尼茨公式求 $\displaystyle\int_0^1(3x^2+1)\,dx$。下面代码里的原函数猜想能跑但少了东西，改到通过：

```exercise
# @title: 练习：∫₀¹(3x²+1)dx
# @check: 2.0
# @hint: 找原函数要逐项负责到底：3x² 的原函数是 x³，那常数 1 的原函数呢？有一项还没归队
def f(x):
    return 3 * x ** 2 + 1

def G(x):
    return x ** 3        # ← 这个原函数猜想完整吗？

print(round(G(1.0) - G(0.0), 1))   # 定积分取原函数两端值相减
```

改对后 $G(x)=x^3+x$，于是 $G(1)-G(0)=2$。这里不需要纠结 $+C$：定积分取原函数两端值相减，平移量恰好抵消。曲线 $y=3x^2+1$ 在单位区间下的面积也恰为 2。

**练习 2**：$\displaystyle\int \cos x\cdot\sin x\,dx$ 可以怎样凑微分？

<details>
<summary>点开查看逐步解答</summary>

两条路都通，正好互相打假：

- 路 A：设 $u=\sin x$，则 $du=\cos x\,dx$，积分变成 $\int u\,du=\frac{u^2}{2}+C=\frac{\sin^2 x}{2}+C$；
- 路 B：设 $u=\cos x$，则 $du=-\sin x\,dx$，积分变成 $-\int u\,du=-\frac{\cos^2 x}{2}+C$。

看着不一样？别忘了 $\sin^2 x+\cos^2 x=1$：两个答案只差常数 $\frac{1}{2}$——$+C$ 家族的不同记名方式而已。回验任意一个：对 $\frac{\sin^2x}{2}$ 求导得 $\sin x\cos x$ ✓。
</details>

<details>
<summary>选读 · 分部积分：乘积的对策</summary>

乘积求导有积规则 $(uv)'=u'v+uv'$，把它倒放就得到对付乘积积分的武器：**分部积分** $\int u\,dv = uv - \int v\,du$——把一半的积分麻烦转嫁成一次乘法。乘积积分没有像和差那样的拆分公式，分部积分就是最接近"乘积公式"的存在。完整的戏本——选股口诀、例题、判题练习与循环分部——已在下一课开演。
</details>
