# 部分分式：拆开有理函数

## 1. 从一个场景开始

上一次课的换元法遇上一道看似无害的题就熄火了：

$$\int \frac{dx}{x^2 - 1}$$

换元？$u = x^2-1$ 则 $du=2x\,dx$——可分子偏偏**没有**那个 $x$。分部积分？拆两下只会越积越凶。整整一章的手艺集体哑火。

关键洞察是把它交给代数处理。想想兑钱的场景：手里一张奇怪的"大钞" $\frac{1}{x^2-1}$，直接花不出去（积不动）；但它能兑换成两张标准面额的小票 $\frac{A}{x-1}$ 和 $\frac{B}{x+1}$——而这两张都是上一章表格里积起来飞快的老朋友。**微积分卡壳时，退一步找代数帮忙**，这就是部分分式，有理函数积分的万能钥匙。

## 2. 直觉解释

先在纸上倒着演一遍小学就会的动作——通分相加：

$$\frac{1}{x-1} + \frac{1}{x+1} = \frac{(x+1)+(x-1)}{(x-1)(x+1)} = \frac{2x}{x^2-1}$$

两个简单分式合并，生出了 $\dfrac{2x}{x^2-1}$ 这个更复杂的复合体。部分分式的全部思想就是**把这场合并倒放**：任何形如 $\frac{\text{分子}}{(x-a)(x-b)}$ 的复杂分数，都怀疑它原本是两张小票的合体。

怎么找到那两张小票？设 $\dfrac{1}{(x-1)(x+1)} = \dfrac{A}{x-1} + \dfrac{B}{x+1}$（系数待定），通分比对分子：要求 $A(x+1) + B(x-1)$ 对**所有** $x$ 恒等于 $1$。"对所有成立"是最强的承诺，也免费送来一批方程——代入任何一个顺手的 $x$ 就能逼出系数。直觉版实验在下一节等着你亲手拖出来。

## 3. 正式定义

**真分式前提**：被积函数须为真分式（分子的次数低于分母）。若是假分式，先用多项式除法把多余的多项式剥掉再谈拆分。

**基本定理**：若分母分解为若干**线性因子** $(x-a_i)$ 的乘积，则存在唯一的常数组，使得

$$\frac{P(x)}{(x-a_1)(x-a_2)\cdots} \;=\; \sum_{i} \frac{A_i}{x-a_i}$$

| 记号 | 名字 | 职责 |
| --- | --- | --- |
| $A_i$ | 待定系数 | 要用方程逼供出来的未知数 |
| 代根法 | 求 $A_i$ 的捷径 | 通分后令 $x=a_i$，让除一项外全部归零 |
| 恒等式 | 比对的依据 | 通分后的分子相等是"对每个 $x$"都成立的等式 |

（分母若有二次不可约因子 $x^2+px+q$，对应票据升级为 $\frac{Ax+B}{x^2+px+q}$，处理思路不变、配方技巧延伸到选读再补。）逐项积分的价值在于：每一张 $\frac{A}{x-a}$ 都是已会的基本款，积得 $\ln|x-a|$。

## 4. 分步例题

完整走通开场那道死题 $\displaystyle\int \frac{dx}{x^2-1}$：

1. **分解因式**：$x^2-1=(x-1)(x+1)$；
2. **设定票据**：$\dfrac{1}{x^2-1}=\dfrac{A}{x-1}+\dfrac{B}{x+1}$；
3. **通分比对**：右边合体后分子为 $A(x+1)+B(x-1)$，要求恒等于 $1$；
4. **代根逼供**：令 $x=1$，第二张票消失、只剩 $A\cdot 2=1$ ⇒ $A=\tfrac12$；令 $x=-1$，第一张票消失、$B\cdot(-2)=1$ ⇒ $B=-\tfrac12$；
5. **逐项收割**：

$$\int \frac{dx}{x^2-1} = \frac12\int\frac{dx}{x-1} - \frac12\int\frac{dx}{x+1} = \frac12\ln|x-1| - \frac12\ln|x+1| + C = \frac12\ln\left|\frac{x-1}{x+1}\right| + C$$

双保险回验：其一，把 $\tfrac12[\frac{1}{x-1}-\frac{1}{x+1}]$ 通分会还原出 $\frac{1}{x^2-1}$（拆分方向没搞反）；其二，答案求导应复原被积函数（链条闭合）。两头都对，这道上章的死题如今五步葬送。

### 实验 2（python）：恒等式的多点多照 + 战利品结算

```python title="抽查四个点验证拆分恒等式，再把定积分战果结清"
import math

def lhs(x):
    return 1 / (x ** 2 - 1)                       # 原始被积函数（注意 x=±1 是禁区）

def rhs(x):
    return 0.5 / (x - 1) - 0.5 / (x + 1)          # 拆出的两张"标准面额"

for xx in [0.0, 0.5, 2.0, 3.5]:                   # 多个抽查点逐一验证
    print(f"x={xx}: 原式 {round(lhs(xx), 6)} == 拆分 {round(rhs(xx), 6)}")

# 用拆分结果结算 ∫₂³ dx/(x²-1)：原函数是 (1/2)·ln|(x-1)/(x+1)|
val = 0.5 * math.log(abs((3 - 1) / (3 + 1))) - 0.5 * math.log(abs((2 - 1) / (2 + 1)))
print(f"∫₂³ dx/(x²-1) ≈ {round(val, 4)}")
```

前四行每行左右两数一字不差（恒等不是"某点碰巧"，是处处成约）；最后一行报出 $0.2027$——这张此前无解的定积分，钥匙一转即开。抽查点刻意绕开了 $x=\pm1$：在禁区上两式都会除以零报警，这不是bug而是数学本身的红线。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为任何分式都能立刻开拆。" 大钞要先鉴定真伪——分子次数不低于分母的**假分式**必须先做多项式除法，剥出一个多项式加一块真分式；否则设定的票据连形式都不合法，解出来的系数组必然自相矛盾。

**误区二**："你以为重复因子发一张票就够。" 分母里的 $(x-1)^2$ 需要**两张**：$\frac{A}{x-1}+\frac{B}{(x-1)^2}$。只发一张会在比对时发现方程数目不够、系数残缺。（完整的演示放在本课末尾选读。）

**误区三**："你以为通分后的分子等式只在某个 x 成立。" 它是**恒等式**——对区间内每个 $x$ 都成立。这正是代根法的合法性来源：既然总成立，当然可以挑最好算的 $x$（比如让某个因子归零的点）来审问它。把它当成普通方程只解一次，就浪费了这份火力。

:::

## 7. 练习

**练习 1**：结算实战战果。正文例题已经查明 $\dfrac{dx}{x^2-1}$ 的原函数是 $\dfrac12\ln\left|\dfrac{x-1}{x+1}\right|$。现在请用它精确算出 $\displaystyle\int_2^{3}\frac{dx}{x^2-1}$，并与黎曼和数值对照。下面的代码第一行给出的是"貌似合理"的原函数——它比正确值恰好大了整整一倍，暗坑在哪自己找；第二行的数值积分是无辜证人，改到两行对上为止：

```exercise
# @title: 练习：漏掉的二分之一
# @check: 0.2027
# @check: 0.2027
# @hint: 两张票各带系数 1/2 逐项积分，原函数应是 (1/2)·ln|(x-1)/(x+1)|——初始代码丢了系数，第一行恰是真值的二倍，和第二行证人对不上
import math

def anti(x):
    # 参考的"原函数猜想"：∫ dx/(x²-1) 应该是 ln|(x-1)/(x+1)| —— 少了点什么？
    return math.log(abs((x - 1) / (x + 1)))

a, b = 2, 3
val = anti(b) - anti(a)
print(round(val, 4))         # 牛顿-莱布尼茨路线

n = 200000                   # 数值自检：黎曼和硬切二十万刀
w = (b - a) / n
s = 0.0
for k in range(n):
    xx = a + (k + 0.5) * w   # 取每个小区间的中点作高度样本
    s = s + 1 / (xx ** 2 - 1) * w
print(round(s, 4))           # 无辜证人的证词
```

<details>
<summary>点开查看逐步解答</summary>

暗坑定位：例题的拆分给出的是 $\dfrac{1}{x^2-1} = \dfrac12\cdot\dfrac{1}{x-1}-\dfrac12\cdot\dfrac{1}{x+1}$——两张票各自带着系数 $\tfrac12$ 积分，于是原函数前面挂着 $\tfrac12$：$F(x)=\tfrac12\ln\left|\dfrac{x-1}{x+1}\right|$。初始代码把这个系数弄丢了，所以输出 $0.4055$，恰是真值的二倍。

修复一行即可通过：

```python
def anti(x):
    return 0.5 * math.log(abs((x - 1) / (x + 1)))   # 补上系数 1/2
```

结算：$F(3)-F(2)=\tfrac12\left[\ln\tfrac24-\ln\tfrac13\right]=\tfrac12\ln 1.5\approx 0.2027$；黎曼和证人同样报出 $0.2027$，两条路会师。
</details>

**练习 2**（思考）：为什么券 $\dfrac{1}{(x-1)^2}$ 明明也可以写成一堆 $\dfrac{A_k}{(x-1)^k}$ 里最简单的形式，却仍要坚持"每个幂次一张票"？用"逐项能不能积"这个标准掂量一下。

<details>
<summary>点开查看逐步解答</summary>

目标不是"少写几张纸"，而是**每一张票都必须是你积分表里有名字的熟客**。$\dfrac{1}{(x-1)^2}$ 本身确实是熟客（积得 $-\frac{1}{x-1}$），所以其实它可以独占整场演出——真正需要两张票的场景是像 $\dfrac{x+1}{(x-1)^2}$ 这种分子不再单一的货色：单张票写不出它的分子结构，必须 $\frac{A}{x-1}+\frac{B}{(x-1)^2}$ 组队才能配平。规矩的记忆口诀是：**线性因子几次幂，就从一比到几**——按需发牌，一张不多、一张不少。
</details>

## 8. 边界之外

- **二次不可约因子**（判别式小于零，如 $x^2+1$）：对应票据 $\frac{Ax+B}{x^2+px+q}$，求解仍是通分配平，但逐项积分要用配方法分成"对数票"与"反正切票"两股——那是三角替换的领地，点到为止。
- **覆盖法的心算版**：本课的代根法其实就是海维塞德覆盖法的书面化——用手"指住"某个因式再读出分子，熟练后可跳过通分直接心算系数；书面流程优先保证不丢步骤。
- **重复因子与复数根的全面战争**：当分子结构复杂、根为复数、或高次幂叠加时，手算很快失控。好消息是把这套"查表拆票"搬进工程界之后几乎全自动——第 22 章解微分方程、第 24 章拉普拉斯逆变换都在机器的流水线上重复今天的动作。
