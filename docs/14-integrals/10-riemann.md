# 面积与黎曼和

## 1. 从一个场景开始

矩形的面积是长×宽，三角形的面积是½底×高——可抛物线 $y=x^2$ 底下的那块"曲边"面积呢？边是弯的，任何现成公式都哑火。两千年前阿基米德靠切片法硬啃出了答案，但真正把这条路修成高速公路的，是黎曼的一个朴素想法：**弯的不会算，就先用直的凑，再让直的无限逼近弯的。**

## 2. 直觉解释

想求曲线下的面积？把底边切成许多窄条，每条上盖一个矩形：

- 矩形的高取曲线在该条上的某个值（比如左端点处的高度）；
- 每个矩形面积 = 高 × 宽，全部加起来，就是曲线下面积的**近似值**。

切得越细，矩形顶部的"台阶"就越贴住曲线——就像用马赛克拼一条弧线，瓷砖越小轮廓越真。切到无限细时，近似值的归宿就是**真实面积**。

## 3. 正式定义

对区间 $[a,b]$ 上的函数 $f$，**定积分**定义为黎曼和的极限：

$$\int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{k=0}^{n-1} f(x_k)\,\Delta x, \qquad \Delta x = \frac{b-a}{n}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\displaystyle\int$ | 积分号 | 拉长的字母 S，Sum（求和）的首字母 |
| $a,\ b$ | 下限、上限 | 从哪里积到哪里 |
| $f(x_k)$ | 样本高度 | 第 $k$ 个窄条上取的函数值 |
| $\Delta x$ | 条宽 | $(b-a)/n$，切成 $n$ 份后每份的宽 |
| $dx$ | 微分记号 | $\Delta x$ 无限细分后的化身 |

黎曼和三步曲：**分割**（切成 $n$ 条）→ **取样**（每条上选一点量高度）→ **求和取极限**（$n\to\infty$）。样本点选在条的哪一端本来会影响和——但极限一到，殊途同归。

## 4. 分步例题

**例**：先拿软柿子练手——求 $\displaystyle\int_0^2 x\,dx$。

1. 画图：$y=x$ 在 $[0,2]$ 下方围出的是一个直角三角形；
2. 量尺寸：底 = 2，高 = 2；
3. 套公式：$\frac{1}{2}\times 2\times 2 = 2$。

所以 $\displaystyle\int_0^2 x\,dx = 2$——几何抢先给出了答案，极限还没出场。

可换成 $y=x^2$，三角形没了，梯形也不是，几何集体失灵。这时只能请出黎曼和。它的精确答案是 $\dfrac{8}{3}$，下面亲手把它逼出来。

## 5. 动手实验

### 实验 1（viz）：黎曼和实验台

```viz
{
  "type": "riemann",
  "expr": "x^2",
  "xmin": 0,
  "xmax": 2,
  "n": 8
}
```

怎么玩，三件事：

1. **拉 N**：把矩形数从 8 一路拉到 60，盯住顶部读数——「误差」一路缩水，小于 0.01 时会变绿。这就是"$n\to\infty$"的肉眼版；
2. **切规则**：轮流按「左端点 / 中点 / 右端点」。同样的 N 下，中点的误差总是最小——对本课的 $x^2$ 这类凸函数，中点比条上的平均高度恒略矮，中点和因此恒偏低（反过来，把每条两端的曲线端点连成直线来算的梯形法则恒偏高——一低一高，正好把真值夹住）；对弯法不那么规律的一般函数，中点的偏差才可能一半偏高、一半偏低，部分互相抵消；
3. **对答案**：「真实面积」一栏显示的正是 $\frac{8}{3}=2.6667$。

### 实验 2（python）：手搓 rectangle_rule，三种采样同台

```python title="矩形法则逼近 ∫₀²x²dx：拖动 n 看三种采样收敛"
# sliders: n=12 [2:120:2]

def square(x):
    return x ** 2

def rectangle_rule(f, a, b, n, where="left"):   # 自定义函数：被积函数、下限、上限、份数、采样位置
    w = (b - a) / n          # 每个矩形的宽：区间总长除以份数
    total = 0
    for k in range(n):       # k 从 0 数到 n-1，正好 n 个矩形
        if where == "left":
            s = a + k * w            # 左端点
        elif where == "mid":         # elif 即 else if：再问一句
            s = a + (k + 0.5) * w    # 中点
        else:
            s = a + (k + 1) * w      # 右端点
        total = total + f(s) * w     # 累加：高 × 宽
    return total

exact = 8 / 3
lft = rectangle_rule(square, 0, 2, n, where="left")    # n 由滑块注入：拖动它，别在代码里赋值
mid = rectangle_rule(square, 0, 2, n, where="mid")
rgt = rectangle_rule(square, 0, 2, n, where="right")
print(f"n={n}: 左 {round(lft, 4)} | 中 {round(mid, 4)} | 右 {round(rgt, 4)} | 精确值 {round(exact, 4)}")
print(f"误差:左 {round(abs(lft - exact), 4)} | 中 {round(abs(mid - exact), 4)} | 右 {round(abs(rgt - exact), 4)}")   # abs：取绝对值，只关心误差大小
```

怎么玩：拖动滑块把 $n$ 从 2 一路拉到 120，每停一次就打印一行三连读数加一行误差。盯住误差行：**左端点永远偏低、右端点永远偏高**（函数递增嘛），真值被一低一高夹在中间；中点的误差始终最小。再做个定量游戏：把 $n$ 从 12 拉到 120（十倍）——左右端点的误差大约缩成十分之一，中点的误差却一口气缩到约原来的百分之一。误区二要讲的"$1/n$ vs $1/n^2$"账本，这张会生长的表格当场就能对账。

:::warning[常见误区]

**误区一**："你以为矩形之间有缝，所以和永远偏小。" 缝不背锅——矩形是紧挨着排的。偏不偏取决于采样点：递增函数左端点偏低、右端点偏高，一低一高恰好把真值夹住；而极限一到大家殊途同归。

**误区二**："你以为 N 翻倍，误差就减半。" 左右端点的误差大约与 $1/n$ 成正比：N 拉 10 倍误差才缩 10 倍；而中点误差与 $1/n^2$ 成正比，N 拉 10 倍误差缩 100 倍。采样规则不同，收敛速度天差地别——下一课末尾还会回来算这笔账。

**误区三**："你以为曲线在 x 轴下方时积分就出乱子。" 下方的高度是负数，高×宽自然是负的——定积分算的是**带符号的面积**：x 轴上方记正、下方记负。想要普通意义的"面积"，得对绝对值积分。

:::

## 6. 练习

**练习 1**：用中点法则算 $\displaystyle\int_0^1 x^3\,dx$（精确值应为 $\frac{1}{4}$）。下面的代码能跑但结果离谱——它只加了矩形的高，忘了一件事，补到通过：

```exercise
# @title: 练习：中点法则算 x³ 的积分
# @check: 0.25
# @hint: 面积 = 高 × 宽。现在 total 里累加的只有高——每个矩形的宽度 w 去哪儿了？
def cube(x):
    return x ** 3

def rectangle_rule(f, a, b, n):
    w = (b - a) / n
    total = 0
    for k in range(n):
        height = f(a + (k + 0.5) * w)   # 中点处的高：第 k 条的中线位置
        total = total + height          # ← 这里少了点什么？
    return total

print(round(rectangle_rule(cube, 0, 1, 1000), 4))
```

修好后输出 $0.25=\frac{1}{4}$——千个矩形就准到了四位小数，中点法则的性价比可见一斑。

**练习 2**：为什么中点法则比左右端点准得多？

<details>
<summary>点开查看逐步解答</summary>

单调函数上，左端点和系统性**偏低**、右端点和系统性**偏高**——每个矩形的偏差方向相同，只会叠加不会抵消。而中点上，每个矩形在中线两侧一边冒出曲线、一边够不着曲线，两笔盈亏大体相抵（对 $x^2$ 这类凸函数，相抵之后每条仍剩一点极小的欠缺——过剩的是梯形），首阶的大头偏差直接消失。结果是误差从 $1/n$ 的量级跳降到 $1/n^2$：同样切 100 条，左右端点还差在小数点后两位，中点已经稳稳站在四位开外。实验 1 里切一次规则就能亲眼对比。
</details>

<details>
<summary>选读 · 为什么连续函数一定可积</summary>

把同一套分割做两遍：样本全取各条最高点得"上和"，全取最低点得"下和"。真实面积被上下两个和夹在中间；函数连续时，条越细最高点与最低点贴得越近，上下和之差可以被任意压扁——两头夹逼，中间只剩一个数。这个数就是定积分。"够乖的函数必有积分"由此成立，也为下一课铺路：我们即将看到，求这个数根本不必真的切无穷刀。
</details>
