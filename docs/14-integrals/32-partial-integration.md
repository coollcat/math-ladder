# 分部积分：乘积法则的逆运算

## 1. 从一个场景开始

上一课的换元法收拾了复合函数，可它一碰到**乘积**就露怯。求 $\displaystyle\int x\,e^x\,dx$：凑微分？$e^x$ 的原函数还是 $e^x$，旁边没躺着谁的导数亲戚（$(e^x)'=e^x$，$du$ 凑不出来）；拆开？$\int u\,v\,dx$ 根本不等于两个积分的乘积。换元的老手艺当场哑火。

回想第 13 章：乘积求导当年靠**乘积法则** $(uv)'=u'v+uv'$ 救场。求导的规则表有多齐，反求导的规则表就该有多齐——把乘积法则**倒放**，就是本课的新武器：**分部积分**。

## 2. 直觉解释

分部积分的全部智慧是两个字：**转嫁**。手里这个乘积积分积不动？把它拆成两笔账——一笔简单到当场用**乘法**结清，另一笔踢给下一轮。只要踢出去的那笔比手里的轻，每一轮都在净赚；要是一脚踢出去个更重的，就叫"越积越凶"。

于是功夫全在一处：**选谁当转嫁担当、谁当留守担当**（下文叫"选股"）。选股的杠杆是求导——谁求一次导就变得服帖，谁去当转嫁担当：$\ln x$ 求导变 $\frac1x$，从"查无初等原函数"一步降级成普通分式，头号种子；幂函数求导降一次；$e^x$ 求导还在原地（派它毫无收益）；三角函数求导在 $\sin$ 与 $\cos$ 之间原地转圈，最不适合当转嫁担当。反过来，留守担当要"一积就老实"：幂函数、$e^x$、$\sin x$、$\cos x$ 都称职，而轮到 $\ln x$ 时你连它的原函数都写不出。

## 3. 正式定义

**分部积分公式**：设 $u=u(x)$、$v=v(x)$ 都可导，则

$$\int u\,dv = uv - \int v\,du$$

| 符号 | 名字 | 职责 |
| --- | --- | --- |
| $u$ | 转嫁担当 | 选**好求导**的那一半：求导后明显降级 |
| $dv$ | 留守担当 | 选**好积分**的那一半：当场积出 $v$ |
| $uv$ | 结算项 | 两个函数相乘，白拿，不用积分 |
| $\int v\,du$ | 转嫁后的新积分 | 必须比原来的好算，否则选股失败 |

**选股口诀**（谁当 $u$ 的优先级，从高到低）：

> **对数 > 幂 > 指数 > 三角**

越靠前的越"难积分、好求导"，请它当 $u$；越靠后的越"好积分"，让它当 $dv$。口诀不是玄学，就是第 2 节那张"求导服帖度"排名的浓缩。

<details>
<summary>选读 · 公式的三行推导</summary>

对乘积法则 $(uv)'=u'v+uv'$ 两边积分（导数相同的函数只差一个常数）：

$$uv = \int u'v\,dx + \int uv'\,dx + C$$

移项并把微分记号翻译过去（$uv'\,dx$ 即 $u\,dv$，$u'v\,dx$ 即 $v\,du$），常数 $-C$ 并入最后的 $+C$，公式到手。整套推导只用了一件旧家当：**积分是求导的逆操作**。
</details>

## 4. 分步例题

**例 1**：求 $\displaystyle\int x\,e^x\,dx$，并求导回验。

1. **选股**：幂 $x$ 与指数 $e^x$ 同台，口诀说幂在指数前——$u=x$，$dv=e^x\,dx$；
2. **备料**：$du=dx$，$v=\int e^x dx=e^x$（中途的 $v$ 取一个代表即可，不用 $+C$）；
3. **套公式**：

$$\int xe^xdx = x\,e^x-\int e^x\,dx$$

4. **收割**：$\int e^x dx=e^x+C$，合并得 $(x-1)e^x+C$；
5. **回验**（养成习惯）：$\big((x-1)e^x\big)'=e^x+(x-1)e^x=xe^x$ ✓。

**例 2**：求 $\displaystyle\int x\cos x\,dx$。

1. **选股**：幂 $x$ 排在三角 $\cos x$ 之前——$u=x$，$dv=\cos x\,dx$；
2. **备料**：$du=dx$，$v=\sin x$；
3. **套公式并收割**：$x\sin x-\int\sin x\,dx=x\sin x+\cos x+C$；
4. **回验**：$(x\sin x+\cos x)'=\sin x+x\cos x-\sin x=x\cos x$ ✓。

反骨验证：要是倒过来选 $u=\cos x$、$dv=x\,dx$，则 $v=\frac{x^2}{2}$，新积分 $\int\frac{x^2}{2}\sin x\,dx$——幂次不降反升。**选股失败的代价当场可见。**

**例 3**：求 $\displaystyle\int x\ln x\,dx$。

1. **选股**：对数排第一，哪怕它旁边只是个安分的幂——$u=\ln x$，$dv=x\,dx$；
2. **备料**：$du=\frac{1}{x}dx$，$v=\frac{x^2}{2}$；
3. **套公式**：

$$\int x\ln x\,dx = \frac{x^2}{2}\ln x - \int\frac{x^2}{2}\cdot\frac{1}{x}\,dx = \frac{x^2}{2}\ln x - \int\frac{x}{2}\,dx$$

4. **收割**：$\frac{x^2}{2}\ln x-\frac{x^2}{4}+C$；
5. **回验**：$\big(\frac{x^2}{2}\ln x\big)'=x\ln x+\frac{x}{2}$，减去 $\frac{x}{2}$ 后恰好 $x\ln x$ ✓。

### 实验 2（python）：例 1 的定积分战果验收

```python title="∫₀¹ x·eˣ dx：切一万刀 vs 分部积分解析解"
import math

def f(x):
    return x * math.exp(x)   # 被积函数

w = 0.0001                    # 把 [0,1] 切成一万份，每份宽 0.0001
total = 0
for k in range(10000):
    xm = (k + 0.5) * w        # 第 k 条的中点位置
    total = total + f(xm) * w
print(f"老实切一万刀 ≈ {round(total, 4)}")

ans = (1 - 1) * math.exp(1) - (0 - 1) * math.exp(0)   # 原函数 (x-1)·eˣ 代端点相减
print(f"分部解析解 = {round(ans, 4)}")
```

两行都打印 `1.0`：分部积分把 $\int_0^1 xe^xdx$ 变成"乘法结算 $xe^x\big|_0^1$ 减一笔好算的账"，答案干脆是 $1$。暴力与技巧再次会师。

## 6. 常见误区

::::warning[常见误区]

**误区一**："你以为选错 $u$ 无非多算两步。" 选反了是方向性事故：例 2 的反骨验证里，把三角当 $u$ 去收拾幂函数，新积分幂次不降反升。唯一的裁判标准：**分部一次后，新积分必须比旧的好算**；不然立刻换股重来。

**误区二**："你以为 $uv$ 写完就收工。" 公式是 $uv$ **减** $\int v\,du$——后半笔是转嫁出去的活儿，欠账不还答案就错。实验 1 亲眼看过：半成品 $xe^x$ 的斜率比被积函数整整多出一个 $e^x$。

**误区三**："你以为中途的 $v$ 和最终的 $+C$ 能互相豁免。" 中途的 $v$ 取哪个竖移代表都不影响结果（差的那项会被并进最后的常数），但**最后一步**的 $+C$ 一分不能少——分部只负责把难积分换成熟积分，收尾照样要交出整个曲线家族。

::::

## 7. 练习

**练习 1**：把例 1 的答案亲手验明正身。下面代码里的原函数猜想是只乘不减的半成品，改到三行输出两两咬合为止：

```exercise
# @title: 练习：给 x·eˣ 的原函数验明正身
# @check: 2.7183
# @check: 2.7183
# @check: 1.0
# @hint: 只乘不减是半成品：x·eˣ 的导数 (1+x)·eˣ 比 x·eˣ 多出一整个 eˣ——把分部公式里欠的 ∫eˣ dx 补上再合并同类项
import math

def f(x):
    return x * math.exp(x)   # 被积函数

def F(x):
    return x * math.exp(x)   # ← 自称的原函数：求导后真的等于 x·eˣ 吗？

x0 = 1.0
h = 0.000001                       # 用一小步差分近似求导：F'(x0) 约等于 (F(x0+h)-F(x0))/h
slope = (F(x0 + h) - F(x0)) / h
print(round(slope, 4))             # 数值求导读出的 F'(1)
print(round(f(x0), 4))             # 真正要匹配的被积函数值 f(1)

print(round(F(1.0) - F(0.0), 1))   # 用原函数结算定积分 ∫₀¹ x·eˣ dx
```

改对后 $F(x)=(x-1)e^x$：前两行都是 $2.7183$（斜率与高度咬合），第三行报出 $\int_0^1 xe^xdx=1$——实验 2 里切一万刀的战果，解析路一步到手。

**练习 2**：$\displaystyle\int x\sin x\,dx$ 的原函数猜想在符号上翻了车。分部时 $\sin x$ 的原函数带着一个负号，找找它丢在了哪：

```exercise
# @title: 练习：负号去哪了
# @check: 1.8186
# @check: 1.8186
# @hint: ∫sin x dx = -cos x，v 自带负号；先对现在的 F 用乘积法则求导，看看它到底是谁的相反数
import math

def f(x):
    return x * math.sin(x)   # 被积函数

def F(x):
    return x * math.cos(x) - math.sin(x)   # ← 求导后真的等于 x·sin x 吗？

x0 = 2.0
h = 0.000001                       # 用一小步差分近似求导
slope = (F(x0 + h) - F(x0)) / h
print(round(slope, 4))             # 数值求导读出的 F'(2)
print(round(f(x0), 4))             # 真正要匹配的被积函数值 f(2)
```

<details>
<summary>点开查看逐步解答</summary>

选股：$u=x$、$dv=\sin x\,dx$，则 $du=dx$、$v=\int\sin x\,dx=-\cos x$——负号就在这里。套公式：

$$\int x\sin x\,dx = -x\cos x + \int\cos x\,dx = \sin x - x\cos x + C$$

初始代码恰好写反成 $x\cos x-\sin x$，求导得 $-x\sin x$，与被积函数差一个负号。改正后 $F(x)=\sin x-x\cos x$，两行输出都是 $1.8186$ ✓。
</details>

**练习 3**（思考）：$\ln x$ 在基本积分表里查无此人，可 $\displaystyle\int \ln x\,dx$ 并不难——没有乘积，硬造一个。

<details>
<summary>点开查看逐步解答</summary>

把 $\ln x$ 写成 $\ln x\cdot 1$——乘积形式凭空出现：$u=\ln x$（对数优先），$dv=1\cdot dx=dx$。于是 $du=\frac1x dx$、$v=x$：

$$\int \ln x\,dx = x\ln x - \int x\cdot\frac{1}{x}\,dx = x\ln x - x + C$$

回验：$(x\ln x-x)'=\ln x+1-1=\ln x$ ✓。"好求导的当 $u$"这条口诀，连被积函数只有一个因子时都好用。
</details>

## 8. 边界之外

- **循环分部：踢出去的球弹回来了**。求 $\int e^x\sin x\,dx$（选读推导见下）：分部两次，弹回的积分恰是原题 $I$ 本身——移项解方程得 $I=\frac{e^x(\sin x-\cos x)}{2}+C$。积分能解方程，这是它最帅的瞬间。
- **表格法**：$\int x^2e^x dx$ 这类要连分部多次的题，把"求导列"与"积分列"并排竖式、斜对角相乘加减，一次排完——本质仍是本课公式的连击。
- **更远的回声**：第 26 章的变分法靠分部积分把导数"转嫁"给别的函数、让边界项当场蒸发；分布理论甚至直接拿它**定义**导数。这门转嫁的手艺，后面还有大场面。

<details>
<summary>选读 · 循环分部的完整推导</summary>

记 $I=\int e^x\sin x\,dx$。第一轮：$u=\sin x$、$dv=e^x dx$，得 $I=e^x\sin x-\int e^x\cos x\,dx$。

第二轮对付 $\int e^x\cos x\,dx$：$u=\cos x$、$dv=e^x dx$，得 $\int e^x\cos x\,dx=e^x\cos x+\int e^x\sin x\,dx=e^x\cos x+I$。

代回第一轮：$I=e^x\sin x-e^x\cos x-I$，移项 $2I=e^x(\sin x-\cos x)$，故 $I=\frac{e^x(\sin x-\cos x)}{2}+C$。

回验：对 $\frac{e^x(\sin x-\cos x)}{2}$ 求导得 $\frac{e^x(\sin x-\cos x)+e^x(\cos x+\sin x)}{2}=e^x\sin x$ ✓。两轮选股始终让指数当 $dv$、三角当 $u$——口诀全程在线。
</details>
