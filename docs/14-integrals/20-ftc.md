# 微积分基本定理

## 1. 从一个场景开始

上一课我们靠切矩形硬凑出了 $\int_0^2 x^2dx=\frac{8}{3}$——能赢，但赢得狼狈：换个函数就又得切无穷刀。牛顿和莱布尼茨看穿了背后的机关：**求曲线下面积，和"给函数找原函数"竟是同一个问题的两张面孔**。看清这一点的瞬间，无穷刀全都可以收起来了。

## 2. 直觉解释

定义一个"面积进度条"$F(x)$：从左端点出发，走到 $x$ 为止攒下的面积。

关键问题：这个进度条爬得有多快？想象 $x$ 处再往前挪一小步 $dx$：新增的那一小条面积 = 高 × 宽 = $f(x)\cdot dx$。所以：

$$F\text{ 的变化率} = f(x)$$

**累积面积的变化速度，恰好等于曲线在当前处的高度**——走得越高（曲线越高），面积攒得越快。而"$F$ 的导数是 $f$"正是上一章学过的语言：$F$ 是 $f$ 的**原函数**。

## 3. 正式定义

**微积分基本定理（两部分）**：

设 $f$ 在 $[a,b]$ 上连续。

**第一部分**：面积函数的导数是被积函数——

$$F(x)=\int_a^x f(t)\,dt \quad\Longrightarrow\quad F'(x)=f(x)$$

**第二部分（牛顿-莱布尼茨公式）**：若 $F'=f$，则

$$\int_a^b f(x)\,dx = F(b)-F(a)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f$ | 被积函数 | 曲线的高度，也是 $F$ 的导数 |
| $F$ | 原函数 | 求导后得到 $f$ 的那个函数 |
| $\displaystyle\int_a^x f(t)\,dt$ | 面积函数（变上限积分） | 从 $a$ 积到 $x$ 攒下的面积 |
| $F(b)-F(a)$ | 增量 | 原函数在两端的取值之差 |

一句话总结：**微分与积分互为逆操作**——先积后导还原自己（第一部分），先导后积只差端点相减（第二部分）。

## 4. 分步例题

**例**：用牛顿-莱布尼茨公式重算 $\displaystyle\int_0^2 x^2\,dx$。

1. 找原函数：谁求导得到 $x^2$？幂规则倒放，$\dfrac{x^3}{3}$ 求导得 $\dfrac{3x^2}{3}=x^2$ ✓；
2. 代上限：$F(2)=\dfrac{2^3}{3}=\dfrac{8}{3}$；
3. 代下限：$F(0)=0$；
4. 相减：$\dfrac{8}{3}-0=\dfrac{8}{3}\approx 2.6667$。

四步完事，没有一刀矩形。上一课实验台里那个千辛万苦逼近的 $2.6667$，如今抬手可得——这就是"基本"二字的分量。

## 5. 动手实验

### 实验 1（viz）：双面板亲眼看"斜率 = 高度"

```viz

  "type": "accumfunc",
  "expr": "sin(x)+1",
  "xmax": 6.28

```

怎么玩：拖动画布任意位置改变 $x$。上面板蓝色是 $f(x)=\sin x+1$，橙色阴影是从 0 到 $x$ 攒下的面积；下面板橙色实线是这个面积的累计值 $F(x)$。盯住两个联动读数：**下面板曲线此刻的陡峭程度，永远等于上面板曲线此刻的高度**——曲线高的地方面积涨得快，曲线贴地的地方面积原地踏步。

### 实验 2（viz）：换 $x^2$ 再验一次

```viz
{
  "type": "accumfunc",
  "expr": "x^2",
  "xmax": 2
}
```

把 $x$ 拖到最右端 $2$：读数显示 $\int_0^2 x^2 \approx F(2) = 2.667$——正是例题手算的 $\frac{8}{3}$。下面板在 $x=2$ 处的斜率则等于上面板高度 $f(2)=4$。

### 实验 3（python）：数值验收基本定理

```python title="∫₀²x²dx：切十万刀 vs 公式"
def f(x):
    return x ** 2

a, b, n = 0, 2, 100000   # 区间 [0,2] 切成十万份
w = (b - a) / n
area = 0
for k in range(n):
    area = area + f(a + (k + 0.5) * w) * w   # 中点小矩形逐条累加
print(f"老实切十万刀 ≈ {round(area, 4)}")
print(f"牛顿-莱布尼茨 = {round(8 / 3, 4)}")
```

两种算法打印出同一个 `2.6667`。但注意成本：一个循环十万次，一个四次代入——捷径的价值一目了然。

### 实验 4（python）：验证"下面板的斜率 = 上面板的高度"

```python title="面积函数 F(t)=t³/3 在各点的斜率 vs f 的高度"
def f(x):
    return x ** 2

h = 0.0001
for x in [0.5, 1.0, 1.5]:
    F_left = (x - h) ** 3 / 3    # 由本课结论，x² 的面积函数是 t³/3
    F_right = (x + h) ** 3 / 3
    slope = (F_right - F_left) / (2 * h)     # 用平均变化率逼近 F 在 x 处的斜率
    print(f"x={x}: F 的斜率 ≈ {round(slope, 4)}，f 的高度 = {round(x ** 2, 4)}")
```

三行输出里每行的两个数都相等：$0.25$、$1.0$、$2.25$。"斜率 = 高度"不是比喻，是可以逐点验收的等式。

### 快问快答

```quiz
已知 F'(x)=f(x)，那么 ∫ₐᵇ f(x)dx 等于？
- F(a) - F(b)
- F(b) - F(a) [*]
- F(b - a)
? 牛顿-莱布尼茨公式：上限代进去减去下限代进去。顺序颠倒符号就反；写成 F(b-a) 更是把减法错搬进了括号。
```

:::warning[常见误区]

**误区一**："你以为 $F(b)-F(a)$ 可以写成 $F(b-a)$。" 完全是两码事！以 $F=x^3/3$、区间 $[0,2]$ 为例：正确答案 $F(2)-F(0)=\frac{8}{3}$；错误写法 $F(2-0)$ 确实碰巧相同，可换成区间 $[1,3]$ 就穿帮了——$F(3)-F(1)=\frac{26}{3}$，而 $F(3-1)=F(2)=\frac{8}{3}$。**先各自代入，再做减法**，次序不可交换。

**误区二**："你以为常数因子进了积分会变卦。" 不会：$\int_a^b c\,f(x)\,dx = c\int_a^b f(x)\,dx$，常数自由进出；和差也能拆成积分的和差。这些与求导法则完全平行。要警惕的是另一头：**两个函数乘积的积分没有简单公式**（不能拆成积分的乘积），它的对策在下一课选读里。

**误区三**："你以为每个函数都能这样秒算。" 牛顿-莱布尼茨公式的门票是一张写得出名字的原函数。可有些大名鼎鼎的函数（下一课末尾的钟形曲线 $e^{-x^2}$）**根本没有初等原函数**——那时我们还得回头请矩形们出场。

:::

## 6. 练习

**练习 1**：物理应用。小球从静止匀加速下落，速度 $v(t)=10t$（米/秒）。用定积分求前 3 秒走过的路程，并说说为什么"速度曲线下的面积 = 路程"。

<details>
<summary>点开查看逐步解答</summary>

路程 $=\displaystyle\int_0^3 v(t)\,dt$。每一小段时间 $dt$ 里走过的距离 ≈ 当前速度 × 这段时长——这正是"高 × 宽"，全部加起来就是速度曲线下的面积。

计算：原函数 $F(t)=5t^2$（求导验证：$10t$ ✓），于是

$$\int_0^3 10t\,dt = 5\times 3^2 - 5\times 0 = 45 \text{ 米}$$

对照伽利略公式 $s=\frac{1}{2}at^2$（$a=10$）：$s=\frac{1}{2}\times 10\times 9=45$ ✓。两条路，同一个答案。
</details>

**动手解**：把上面的积分交给黎曼和，亲手算出 45——

```exercise
# @title: 动手解：黎曼和算路程
# @check: 45.0
# @hint: 每一小步累加的是"速度 × dt"；现在代码里漏乘了 dt，所以结果大得离谱
total = 0
dt = 0.001
for k in range(3000):
    t = k * dt
    total = total + 10 * t
print(round(total, 1))
```

**练习 2**：不同的书可能给出不同的原函数，比如 $x^3/3$ 与 $x^3/3+7$——它们算出的定积分会打架吗？

<details>
<summary>点开查看逐步解答</summary>

不会。直觉上：导数只记录"变化的方式"，把原函数整体上下平移，每一点的变化方式纹丝不动——所以 $x^3/3$ 加不加常数，求导都是 $x^2$（"导数相同 ⇒ 只差常数"的严格证明要用微分中值定理，留给后续卷册）。代入相减时常数自我抵消：

$$\left(\frac{b^3}{3}+7\right)-\left(\frac{a^3}{3}+7\right)=\frac{b^3}{3}-\frac{a^3}{3}$$

所以 $+C$ 在定积分里自动消失——这也是为什么牛顿-莱布尼茨公式只写差值、不提常数。定积分是一个**数**，与选哪个原函数无关。
</details>

<details>
<summary>选读 · 它凭什么叫"基本"定理</summary>

在牛顿之前，"求切线斜率"与"求曲线面积"是两门互不相认的手艺：前者属于几何学的难题，后者难倒了阿基米德以来所有想算曲边形的人。微积分基本定理证明这两件事互为逆操作——会求导就会算面积。两千年积累的两个难题被一行公式焊成了一门学问，微积分从此以一个整体的身份横扫物理与工程。"基本"二字，纪念的是这次统一。顺带一提：牛顿的老师巴罗已用几何方式瞥见这层关系，牛顿与莱布尼茨则各自把它锻造成了通用算法。
</details>
