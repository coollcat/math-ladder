# 数值积分：没有公式也要算

## 1. 从一个场景开始

概率论的头号明星是钟形曲线 $y=e^{-x^2}$——正态分布就靠它撑场子，它的积分无处不在。可数学家们试了几百年，得出一个哭笑不得的结论：**这个函数的原函数根本写不出来**（无法用有限个初等函数表达）。牛顿-莱布尼茨公式握在手里，门票却没有。怎么办？答案很计算机：**不找原函数，直接算面积**。

## 2. 直觉解释

采样点已经摆好了，差别只在"点与点之间怎么连线"：

- **梯形法则**：把相邻采样点用**直线段**连起来——曲线下变成一排梯形。比矩形强在"斜边贴着曲线走"；
- **辛普森法则**：相邻三个点确定一条**抛物线**，用抛物线弧代替曲线弧。弯曲本身被模仿了，自然更像；
- 中点矩形（上一课的老朋友）：每个窄条只看一眼中间的高度。

一句话：对曲线的"替身"求和——替身从水平线升级到斜线再到抛物线，一步比一步逼真。

## 3. 正式定义

把 $[a,b]$ 切成 $n$ 份，节点 $x_k=a+k\Delta x$，$\Delta x=\frac{b-a}{n}$。三个近似公式：

$$M_n=\Delta x\sum_{k=0}^{n-1}f\!\left(\tfrac{x_k+x_{k+1}}{2}\right)\qquad T_n=\frac{\Delta x}{2}\Big[f(x_0)+2f(x_1)+\cdots+2f(x_{n-1})+f(x_n)\Big]$$

$$S_n=\frac{\Delta x}{3}\Big[f(x_0)+4f(x_1)+2f(x_2)+4f(x_3)+\cdots+f(x_n)\Big]\quad(n\ \text{取偶数})$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\Delta x$ | 步长 | 每一小份的宽 |
| $x_k$ | 节点 | 第 $k$ 个采样位置 |
| $M_n,\ T_n,\ S_n$ | 三种估计 | 中点 / 梯形 / 辛普森 |
| $1,4,2,\ldots,4,1$ | 辛普森权重 | 来自逐段抛物线积分的系数 |

## 4. 分步例题

**例**：手算梯形法则估计 $\displaystyle\int_0^\pi \sin x\,dx$（精确值为 2），只切 2 刀。

1. 步长 $\Delta x=\dfrac{\pi}{2}$，节点 $x_0=0,\ x_1=\dfrac{\pi}{2},\ x_2=\pi$；
2. 量高度：$\sin 0=0$，$\sin\dfrac{\pi}{2}=1$，$\sin\pi=0$；
3. 套公式：$T_2=\dfrac{\pi/2}{2}\big[0+2\times 1+0\big]=\dfrac{\pi}{2}\approx 1.571$；
4. 对照真值 2：差了约 0.43。两刀的折线太粗糙——但流程已完整跑通，剩下的只是加密。

怎么玩：先在「中点 / 梯形 / 辛普森」之间切换，再拉大 N。水平小矩形、斜边梯形、抛物线弧三种替身的误差下降速度完全不同；辛普森常常用很少的采样点就把误差压到接近零——这正是本课要解释的“阶”的差距。

### 实验 2（python）：三种方法同台比武

```python title="∫₀π sin x dx = 2：三种方法误差表"
import math

def midpoint_rule(f, a, b, n):
    w = (b - a) / n
    total = 0
    for k in range(n):
        total = total + f(a + (k + 0.5) * w) * w   # 中点矩形：高 × 宽
    return total

def trapezoid_rule(f, a, b, n):
    w = (b - a) / n
    total = (f(a) + f(b)) / 2          # 两端点各记半份高度
    for k in range(1, n):              # range(1, n)：k 从 1 走到 n-1，遍历内部各点
        total = total + f(a + k * w)
    return total * w

def simpson_rule(f, a, b, n):
    w = (b - a) / n
    total = f(a) + f(b)                # 首尾两点权重为 1
    for k in range(1, n):
        if k % 2 == 1:                 # % 取余：余 1 即奇数号点
            total = total + 4 * f(a + k * w)   # 奇数号内点权重 4
        else:
            total = total + 2 * f(a + k * w)   # 偶数号内点权重 2
    return total * w / 3

target = 2.0   # ∫₀π sin x dx 的精确值
for n in [10, 100]:
    em = abs(midpoint_rule(math.sin, 0, math.pi, n) - target)   # abs：取绝对值——只关心误差大小，不管正负
    et = abs(trapezoid_rule(math.sin, 0, math.pi, n) - target)
    es = abs(simpson_rule(math.sin, 0, math.pi, n) - target)
    print(f"n={n}: 中点误差 {round(em, 4)} | 梯形误差 {round(et, 4)} | 辛普森误差 {round(es, 4)}")
```

怎么读这张表：$n=10$ 时中点误差约为梯形的一半，而辛普森直接小两个数量级；$n=100$ 时中点和梯形才刚摸到万分之一，辛普森的四位小数已经全是零（实际误差约 $10^{-8}$）——**抛物线替身的碾压局**。

:::warning[常见误区]

**误区一**："你以为步数翻倍，误差就跟着减半。" 不一定——每种方法的误差有自己的"阶"：梯形按 $1/n^2$ 缩水（翻倍变四分之一）、辛普森按 $1/n^4$（翻倍变十六分之一）。对照上面的误差表自己验一遍，比背结论踏实（选读有出处）。

**误区二**："你以为数值积分是没办法的办法。" 恰恰相反，工程上它是**常态**而非妥协：实验数据只有散点没有公式、原函数不存在（钟形曲线举手）、或者维度高到解析法崩溃——航天器轨道、气象模型、AI 训练里的积分几乎清一色数值方法。会"老实切刀"不是退路，是主业。

**误区三**："你以为 n 拉到天上去总没错。" 浮点数精度有限：几千万次累加的舍入噪声会反过来追上截断误差，n 再增大结果甚至可能变糟。数值方法讲究"够用且稳定"，不是无脑堆规模。

:::

## 6. 练习

**练习 1**：修好下面的辛普森法则——它能跑，但权重装反了，改到输出正确结果：

```exercise
# @title: 练习：修好辛普森法则
# @check: 2.0
# @hint: 口诀是 1、4、2、4、…、4、1：系数 4 属于奇数号内点、2 属于偶数号内点——现在正好颠倒了
import math

def simpson_rule(f, a, b, n):
    w = (b - a) / n
    total = f(a) + f(b)
    for k in range(1, n):
        if k % 2 == 1:
            total = total + 2 * f(a + k * w)   # ← 奇数号内点真的该配 2 吗？
        else:
            total = total + 4 * f(a + k * w)
    return total * w / 3

print(round(simpson_rule(math.sin, 0, math.pi, 10), 3))
```

修好后仅凭 11 个采样点就把 $\displaystyle\int_0^\pi \sin x\,dx$ 锁定到 $2.0$——对比例题里梯形两刀的 $1.571$，就知道好替身值多少钱。

**练习 2**：辛普森用的只是抛物线（二次曲线），凭什么这么准？

<details>
<summary>点开查看逐步解答</summary>

两个原因叠加。其一，过不在同一直线上的三点恰好只有一条抛物线，所以"每两格配一条替身弧"毫无歧义；其二，可以证明这套拼装不仅对二次多项式精确，**对三次多项式也分毫不差**（左右两半的高阶项恰好对消）——等于白赚一次精度，误差因此跳到与 $h^4$ 成正比。更深远的是思想本身：**用低次多项式局部冒充光滑函数**。这个念头在下一章将被推向极致——泰勒展开干脆用多项式冒充整个函数。
</details>

<details>
<summary>选读 · 误差阶数的来历</summary>

对足够光滑的 $f$，可以证明三种方法的误差满足：

$$|E_T|\le\frac{(b-a)\,\Delta x^2}{12}\max|f''|,\qquad |E_S|\le\frac{(b-a)\,\Delta x^4}{180}\max|f^{(4)}|$$

梯形的误差由 $f''$ 控制——曲线越弯、折线丢真越多；辛普森的误差由四阶导控制，而且步长是四次方：$\Delta x$ 减半，误差除以 16。中点法则与梯形同阶但符号相反、大小约为一半，这正是误差表里"中点≈梯形一半"的出处。至于左右端点矩形，它们连曲率都没利用，误差停在 $1/n$ 阶——黎曼实验台里它收敛最慢的原因就此揭晓。
</details>
