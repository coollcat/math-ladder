# 反常积分：对无穷做积分

## 1. 从一个场景开始

从 $x=1$ 出发往右铺一条无限长的地毯带，在位置 $x$ 处的厚度（高度）是 $\dfrac{1}{x^2}$——越远越薄，一千米外薄得可以忽略。问题来了：**这条无尽头的地毯，总共用了多少布？**

牛顿-莱布尼茨公式计算定积分时，两头都得是**具体的数**，而这里的上限是无穷大 $b\to\infty$——基本定理当场失语。可直觉又强烈暗示布是有数的：厚度衰减得太快了。这块"有限还是无底洞"的判决权，掌握在一个新的手续手里：**反常积分**。它是第 36 章连续分布、Gamma 函数的入场券，此前全站零命中。

## 2. 直觉解释

办法朴素得出奇：**先装作上限是个普通的数 $b$，老老实实算出面积，再让 $b$ 一路狂奔向无穷，看这个面积有没有归宿**。

把两条著名尾巴并排放：

| 上限 $b$ | $\displaystyle\int_1^b \frac{1}{x^2}\,dx = 1-\frac{1}{b}$ | $\displaystyle\int_1^b \frac{1}{x}\,dx = \ln b$ |
| --- | --- | --- |
| $10$ | $0.9$ | $2.3026$ |
| $100$ | $0.99$ | $4.6052$ |
| $10000$ | $0.9999$ | $9.2103$ |

左边那条锁死在 $1$；右边那条**永不封顶**，而且涨得越来越慢却从不认输。两条尾巴图像都"趴得很平"，命运却天差地别——差别不在"多快变矮"，而在**变矮的速度能不能追上宽度的增长**。

类比：往水池里滴水，每天水量减半——总量当然有底；但若每天只减少百分之一，水池终将漫出。无穷的世界里，"渐渐变小"和"足够快地变小"是两码事。

## 3. 正式定义

**第一类（无穷区间）**：对 $f$ 在 $[a,\infty)$ 上，

$$\int_a^{\infty} f(x)\,dx \;=\; \lim_{b\to\infty}\int_a^{b} f(x)\,dx$$

**第二类（无界函数）**：若 $f$ 在 $a$ 点附近爆炸（趋于无穷），则挖掉瑕点取极限：

$$\int_a^{b} f(x)\,dx \;=\; \lim_{\varepsilon\to 0^{+}}\int_{a+\varepsilon}^{b} f(x)\,dx$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\lim_{b\to\infty}$ | 极限审讯 | 上限先假装是数 $b$，最后逼它交代去向 |
| 收敛 | 极限存在 | 面积有个有限的归宿 |
| 发散 | 极限不存在或为无穷 | 无穷区间上的"面积"账本记不拢 |
| 瑕点 | 函数在此爆炸的点 | 第二类的麻烦源头，常藏在区间内部不易察觉 |

规程一句话：**极限站在积分门外把关，绝不许 $\infty$ 本尊混进式子里做减法**。两种反常共享同一句心法——先截断成普通定积分，再让截断参数走向危险端点。

## 4. 分步例题

**例 1（收敛）**：判 $\displaystyle\int_1^{\infty} \frac{1}{x^2}\,dx$ 的生死。

1. 截断：$\displaystyle\int_1^{b} x^{-2}\,dx$；
2. 原函数：幂规则倒放，指数 $-2$ 加一得 $-1$，除以 $-1$ ⇒ $-\dfrac{1}{x}$；
3. 代端点相减：$\left[-\dfrac{1}{x}\right]_1^{b} = -\dfrac{1}{b}-(-1) = 1-\dfrac{1}{b}$；
4. 审讯：$b\to\infty$ 时 $\dfrac{1}{b}\to 0$，极限 $=1$。**收敛，面积恰为一格**——一大片摊到无穷远的薄毯，总布料竟是一件衬衫。

**例 2（发散）**：判 $\displaystyle\int_1^{\infty} \frac{1}{x}\,dx$。

前三步照抄：原函数 $\ln b$，得 $\ln b - \ln 1 = \ln b$。第 4 步宣判：$b$ 翻倍 $\ln b$ 只加一个常数，但它**加个没完**——发散。比 $1/x$ 更陡（指数大于 1）的幂都步例 1 后尘收敛；不陡于 $1/x$ 的全部陪葬。这条分水岭在第 15 章还会以级数的面目重新开庭（那是后话，记住"$1/x$ 是生死线"这个直觉就够）。

### 实验 2（python）：b 一路翻倍，谁停谁疯

```python title="尾巴赛跑巡逻表：同一张表上两列数字定格 vs 爬升"
import math

def short_tail(b):
    # ∫₁ᵇ 1/x² dx 的现成答案（牛顿-莱布尼茨算好了）：等于 1 - 1/b
    return 1 - 1 / b

def log_tail(b):
    # ∫₁ᵇ 1/x dx 的现成答案：等于 ln(b) —— math.log 是自然对数
    return math.log(b)

for b in [10, 100, 10000, 100000000]:
    print(f"b={b}: 1/x² 攒下 {round(short_tail(b), 4)} | 1/x 攒下 {round(log_tail(b), 4)}")
```

怎么玩：观察第二列如何原地定格在 $0.9999\dots$，第四列却爬过 $9.21$ 还不肯停。想更刺激可以把循环里的名单改成 `[10, 10**10, 10**50]`——左列纹丝不动得像块石头（离 $1$ 还差不到小数点后五十位的一半），右列早爬上了珠峰。**"面积有归宿吗"不是嘴仗，是一张可以被数值表格步步紧逼的实证题。**

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为可以直接把 $\infty$ 当数代入。" $\displaystyle\int_1^{\infty} x^{-2}dx = \left[-\frac{1}{x}\right]_1^{\infty} = 0+1$ 这种写法把流程缩过头了——合法的操作只有"代 $b$、取极限"两步走，符号 $\infty$ 自始至终只是极限过程的标签，不是能做减法的数。

**误区二**："你以为图像趴得平就是收敛。" 实验 1 已亲眼看过：$1/x$ 趴得同样漂亮，账本照样崩盘。收敛与否取决于尾巴**衰减速度与增长宽度的军备竞赛**，眼睛只能看到"谁在前几名"，看不到终极结局。

**误区三**："你以为上下限正常就没有意外。" 第二类反常积分最阴险：比如 $\displaystyle\int_0^{2} \frac{dx}{(x-1)^2}$，端点岁月静好，函数却在区间内部的 $x=1$ 处爆炸——肉眼常规的黎曼和会无声地吞下毒药给出假值。动手前先扫描：被积函数在区间内**何处发飙**？

:::

## 7. 练习

**练习 1**：竖着炸的曲线也可能有穷面积。曲线 $y=\dfrac{1}{\sqrt{x}}$ 在 $x=0$ 处高耸入云（分母趋零），按理面积该无限？先挖掉瑕点旁一小条、算面积、再让缺口越缩越小来审判它。下面的代码能跑，但原函数写得不对——用幂规则倒放检查 $(\sqrt{x})'$ 到底是谁，改到通过：

```exercise
# @title: 练习：顶天立地的曲线，也可能只攒下一件衬衫
# @check: 1.937
# @check: 1.998
# @hint: 幂规则倒放：指数 -1/2 加一得 1/2，除以 1/2 即乘 2，原函数是 2·√x 而不是 √x——现在的 F 把每个面积都打了对折
import math

def F(x):
    return math.sqrt(x)          # ← 自称的原函数：(√x)' 真的等于 x^(-1/2) 吗？

eps1 = 0.001                      # 第一刀：在 x=0 旁挖掉宽 0.001 的一小条
eps2 = 0.000001                   # 第二刀：挖得更窄，逼近真实的总面积

print(round(F(1) - F(eps1), 3))   # 先算 [eps1, 1] 段的面积
print(round(F(1) - F(eps2), 3))   # 缺口缩小后，面积该稳定下来才对
```

参考结局：当原函数修对后，两行输出是 $1.937$ 与 $1.998$——缺口越缩越小，面积稳稳逼近一个不超过 $2$ 的终点：这块竖着炸开的区域居然**收敛**。（完整的极限值是多少？让 eps 再缩小一千倍试试。）

<details>
<summary>点开查看逐步解答</summary>

被积函数 $f(x)=x^{-1/2}$ 用幂规则倒放求原函数：指数 $-\tfrac12$ 加 1 得 $+\tfrac12$，除以 $\tfrac12$ 即乘 2，所以 $F(x)=2\sqrt{x}$（回验：$(2\sqrt{x})'=2\cdot\tfrac12 x^{-1/2}=x^{-1/2}$ ✓）。初始代码漏了系数 $2$，把每个面积都打了对折。

截断后按第二类反常积分规程办理：

$$\int_{\varepsilon}^{1} x^{-1/2}\,dx = 2\sqrt{x}\Big|_{\varepsilon}^{1} = 2 - 2\sqrt{\varepsilon}$$

让 $\varepsilon\to 0^{+}$：$\sqrt{\varepsilon}\to 0$，极限 $=2$。判定：$\displaystyle\int_0^{1} \frac{dx}{\sqrt{x}}$ **收敛于 2**——函数在左端点直冲云霄，云霄以下的总面积却是有限的。对照实验 2 的发现：横向无穷的 $1/x$ 发了疯，纵向无穷的 $1/\sqrt{x}$ 却乖乖收编；反常的两个方向各有各的性格。
</details>

**练习 2**（思考）：曲线 $\dfrac{1}{x^2}$ 在 $[1,\infty)$ 收敛，那 $\dfrac{1}{x}$ 能不能也这么安慰自己"长长的一段里它们差不多"？找一句数据反驳它。

<details>
<summary>点开查看逐步解答</summary>

不能。设想把两张图叠起来看 $x$ 很大处的差距：$1/x$ 与 $1/x^2$ 在 $x=10000$ 时分别约 $0.0001$ 和 $0.00000001$——单个点几乎重合，错就错在**每一小段的富裕都在累计**。巡逻表里右列从 $2.3$ 爬到 $4.6$ 再爬到 $9.2$，每次 $b$ 十倍它就固定加 $\ln 10\approx 2.3$；积累一万次就是 $23000$ 多。局部相似不代表全局同命——这正是"渐进性质决定不了求和命运"的又一证词。
</details>

## 8. 边界之外

三件事留给后面各章，现在只点名：

- **p-判别法全家福**。"指数大于 1 收敛、不超过 1 发散"这句直觉判断将在第 15 章以级数形式正式升堂（$\sum 1/n^p$ 同样的分水岭），那时还要添上更精细的比较手法——本章只负责把这个直觉种下。
- **两边都坏或区间内有瑕点的情形**。要拆成若干段分别审判，任何一段发散即整体发散；正负号交替时的条件收敛（如经典的 $\sin x / x$）需要更强的工具，此处不碰。
- **Gamma 函数与概率论**。第 36 章连续分布的密度函数、期望方差全部建筑在今天的"先截断再取极限"之上；连著名的伽马函数也是反常积分的一员大将。
