# 光速不变：为什么"同时"是相对的

## 1. 从一个场景开始

雷雨天，一列火车匀速驶过站台。两道闪电同时击中列车的车头和车尾——至少站台上的人是这样描述的。

车厢正中的乘客却说：车头那道闪电先到。站台正中的值班员坚持：两道光**同时**到达我这里。

两个人都不糊涂，仪器也没有误差。这一课要讲的，就是为什么"同时"这两个字必须标上"在谁的坐标系里"。

## 2. 直觉解释

先看声音。声音在静止的空气里以 340 m/s 传播——**这是相对于空气的**。你迎着声源跑过去，声音相对你的速度就变大；你跟着声源跑，它相对你就变慢。所以声学的世界里有一个"空气参考系"，速度可以随便加。

光如果也这样，就该有一个"以太"参考系。1887 年迈克尔逊和莫雷用干涉仪找它：地球以 30 km/s 绕日公转，如果以太存在，顺着地球运动方向和垂直方向的光速就该差一点点，干涉条纹会移动。他们测到的移动是**零**——小到光速的百亿分之一都不到。

于是光速成了这个世界上唯一不讲"相对于谁"的速度。这不是哲学的任性，是实验逼出来的公设：**只要你在惯性系里，量到的真空光速永远是同一个 $c$**。

这个公设有一个立刻的后果。判断两个事件是否"同时"，最可靠的办法是让光从两个事件出发、看它们是否同时到达中点。现在光速对谁都一样，而**中点会动**——"同时"这件事就随着观察者的运动分裂了。

## 3. 正式定义

狭义相对论建立在两条公设之上（$c$ 记真空光速）：

$$\text{(1) 相对性原理：一切惯性系里物理定律形式相同}\qquad \text{(2) 光速不变：一切惯性系里量到的光速都是 } c$$

设站台系 $S$ 中两个事件的间隔为 $(\Delta t,\ \Delta x)$，一列以速度 $v = \beta c$ 沿 $x$ 方向行驶的列车系记作 $S'$。两条公设联手给出的时间变换是

$$\Delta t' = \gamma\left(\Delta t - \frac{\beta \Delta x}{c}\right),\qquad \gamma = \frac{1}{\sqrt{1 - \beta^{2}}}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\Delta t,\ \Delta x$ | 站台系的间隔 | 两事件的时间差与距离差（同一参考系内量） |
| $\beta$ | 速度参数 | 列车速度除以光速，$0 \le \beta \lt 1$ |
| $\gamma$ | 洛伦兹因子 | 永远 $\ge 1$；$\beta = 0.6$ 时 $\gamma = 1.25$ |
| $c$ | 光速 | $299\,792\,458$ m/s，定义值，不带测量误差 |
| $\Delta t'$ | 列车系的时间差 | 同一个物理过程换个人来记，读数就变了 |

读法：$\Delta t' = \gamma \Delta t - \gamma\beta \Delta x / c$。第一项是大家都熟悉的时间流逝；**第二项才是新东西**——两个事件相距越远（$\Delta x$ 越大），它们的先后就越容易被运动"搅动"。同一地点发生的两件事（$\Delta x = 0$）人人同意先后，距离拉开之后，观点就分裂了。

## 4. 分步例题

**例**：列车长 2 光秒（约 60 万公里，为了算得好看，别当真车），以 $\beta = 0.6$ 向右行驶。站台系里两道闪电同时击中车头与车尾。车上正中的乘客认为它们差多久？

1. **写清两事件**：取车尾为起点。事件 A（车头）与事件 B（车尾）在站台系里 $\Delta t = 0$，间隔 $\Delta x = 2$ 光秒；
2. **算因子**：$\gamma = 1/\sqrt{1 - 0.36} = 1/0.8 = 1.25$；
3. **套公式**：$\Delta t' = 1.25 \times (0 - 0.6 \times 2) = -1.5$ 光秒。负号表示 $t'_A \lt t'_B$——**车头那击先发生 1.5 秒**；
4. **用光信号独立核对**：站台系里，车头那道光要追上车上的观察者（他正以 $0.6c$ 迎面赶来），解 $0.6ct = 1 - ct$ 得 $ct = 0.625$；车尾那道光要追上同一个观察者（他在逃），解 $0.6ct = -1 + ct$ 得 $ct = 2.5$。两个光信号到达车上观察者的时间差是 $2.5 - 0.625 = 1.875$ 光秒；
5. **换算回列车系**：列车系是运动的那个钟，读数要除以 $\gamma$：$1.875 / 1.25 = 1.5$ 光秒。与第 3 步严丝合缝。

站台观察者那边呢？两道闪光都要走 1 光秒到中点，**同时**到达。同一个实验，两套"到达时刻表"——这就是"同时性是相对的"最干净的版本。

## 5. 动手实验

### 实验 1（lab）：拖速度，看两击的先后翻转

```lab
{
  "type": "rel-simultaneity",
  "title": "拖列车速度：站台系同时的两击，在列车系里谁先谁后",
  "beta": 0.6,
  "offset": 0
}
```

- 先把 β 拖到 **0**：列车系同时线变成水平，两道闪电在两边眼里都是同时的——这是伽利略的世界；
- 把 β 拖到 0.6：橙色虚线（列车系的"同时线"）翘起来，读数条显示 $\Delta t' = -1.5$ 光秒，**车头先**；
- 把画布里的 **B 击（车尾那道闪电）上下拖**：这是在造"站台系里本来就不同时"的两击。拖到 $t_B = -2\beta = -1.2$ 光秒时，读数条的"谁先"变成**同时**——列车系也有自己的一套"同时"；
- 点**播放**：光从两击出发，站台观察者同时收到两条，车上观察者先收到车头那条。

### 实验 2（python）：把两个到达时刻算出来

```python title="车上观察者两次收到光的时刻"
beta = 0.6                    # 列车速度（以 c 为单位）
half = 1.0                    # 半列车长（光秒）

t_front = half / (1 + beta)   # 车头的光追上车上的观察者：解 βct = 1 − ct
t_rear = half / (1 - beta)    # 车尾的光追上来：解 βct = −1 + ct
print(f"车头 {t_front:.3f} 光秒，车尾 {t_rear:.3f} 光秒，差 {t_rear - t_front:.3f}")
```

输出 `车头 0.625 光秒，车尾 2.500 光秒，差 1.875`。三个数各有各的用处：$0.625$ 与 $2.500$ 是**站台系**读出的两个到达时刻，$1.875$ 是它们的差；而列车系里两击的时间差是 $1.875/\gamma = 1.5$ 光秒——**站台的时间差除以 $\gamma$ 才是车上钟的读数**，因为车上那只钟走得慢。反过来把 $\beta$ 改成 0，两个时刻都变成 1.0，差归零。

::::warning[常见误区]

**误区一**："同时就是同时，只是仪器不够准。"
你以为差的是一位小数——其实差的是**一整秒**（例题里 1.5 光秒）。相对论效应不是精度问题：它随 $\beta$ 连续变化，$\beta = 0$ 时严格为零，$\beta = 0.6$ 时就已经大到没法忽略。你必须先指定"在哪个参考系里同时"，这句话才有意义。

**误区二**："光速不变是因为光没有质量，所以不受运动影响。"
你以为这是从牛顿力学推出来的结论——方向反了：光速不变是**公设**，是实验（迈克尔逊–莫雷）请进来的前提，牛顿力学才是那个需要被修正的旧框架。而且这条公设约束的不是"光"这一种东西：引力波、任何无质量场，速度都是 $c$。

**误区三**："相对论说一切都是相对的。"
恰恰相反：狭义相对论建立在**最绝对**的东西上——光速对所有人一样。相对的是时间、长度、同时性这些"测量结果"，绝对的是 $c$ 与后面要讲的时空间隔。物理定律本身也没有变，变的只是坐标。

::::

## 6. 练习

**练习 1**：两座城市相距 $\Delta x = 1000$ km，在站台系里两道闪电**同时**击中它们。一列以 $\beta = 0.6$ 行驶的列车经过，车上的人认为两击差多久（微秒）？初始代码漏了 $\gamma$：

```exercise
# @title: 练习：车上的人认为两击差多久
# @check: -2501.73
# @hint: Δt′ = γ(Δt − βΔx/c)。Δt = 0，所以只剩 γβΔx/c 这一项。初始代码少了 γ = 1/√(1−β²) = 1.25，把这一乘补上；负号表示"车头方向那击先发生"。
c = 299792458.0        # 光速（m/s）
beta = 0.6             # 列车速度（以 c 为单位）
dx = 1.0e6             # 两道闪电的间距（m），站台系里同时发生

dt = -beta * dx / c    # ← 少了 γ：洛伦兹变换里 Δt′ 要再乘一个 γ
print(round(dt * 1e6, 2))   # 换算成微秒
```

初始代码输出 `-2001.38`：符号是对的（车头那击确实更早），数值小了 25%。补上 $\gamma$ 之后是 `-2501.73` 微秒。

**练习 2**：回答三问：(a) 为什么"同一地点发生的两件事"人人同意先后？(b) 若两击在站台系里**不同时**，车上的人有没有可能认为是同时的？(c) 要造出"车上认为同时"的两击，站台系里该让哪一击更晚、晚多少？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $\Delta x = 0$ 时 $\Delta t' = \gamma \Delta t$，正负号与 $\Delta t$ 完全一致——同一地点的事件不可能被"搅动"；
2. (b) 可以。$\Delta t' = 0$ 要求 $\Delta t = \beta \Delta x / c$，只要让**车尾那击晚一点**（$\Delta t$ 与 $\Delta x$ 同号）就能凑出来；
3. (c) 代入例题的数字：$\Delta t = 0.6 \times 2 / 1 = 1.2$ 光秒 —— 车尾那击比车头**晚 1.2 秒**发生（在站台系里）。这也正是 lab 里那个 $\Delta t' = 0$ 的位置：拖 B 击到 $t_B = -1.2$ 光秒。

**一句话总结**：同时性不是"事实"，是"约定 + 运动状态"的联合产物。$1.875$ 与 $1.5$ 是同一个物理过程的两个读数，差的那一个 $\gamma$ 就是下一课的主角。

</details>

## 7. 选读：以太的葬礼与"零结果"的重量

<details>
<summary>选读 · 迈克尔逊–莫雷实验：一次什么都没测到的测量，怎么改写了物理</summary>

1887 年，迈克尔逊与莫雷把一台干涉仪装在水银槽里（可以平稳旋转），让一束光分成两路：一路顺着地球公转方向，一路垂直。若以太是静止的介质，顺着走的那一路会"逆风"，两路光回来时就该有时差，干涉条纹随仪器旋转而移动。

他们预期条纹移动约 0.4 个条纹宽度，实际测到的上限是 **0.01 个**——比预期小 40 倍，落在噪声里。此后几十年，实验精度不断提高，直到今天（光学谐振腔实验）把"以太风"压到 $10^{-17}$ 的量级，依然是零。

物理学家试过打补丁：以太被物体拖着走（斐兹杰惹–洛伦兹收缩）、发射理论（光速相对于光源是 $c$）……前者被光行差与斐索流水实验夹死，后者被双星观测否决（如果光速相对于光源，快速远离的双星会看到"追上来"的光，实际没有）。

最后是爱因斯坦的做法：**把"零结果"当成原理**，不再解释它，而是从它出发。两条公设一写下来，洛伦兹变换、时间膨胀、$E = mc^2$ 全都自己长出来。这也是物理学里"零结果"最著名的一次胜利：一个灵敏到能看见百亿分之一的仪器，什么都没看见，于是整个以太被删掉了。

</details>
