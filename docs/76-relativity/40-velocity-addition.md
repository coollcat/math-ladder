# 速度合成与快度：为什么追不上光

## 1. 从一个场景开始

飞船以 $0.6c$ 掠过空间站，向前射出一枚同样 $0.6c$ 的探测器（相对飞船）。

空间站看到的速度是多少？日常直觉说 $1.2c$。可上一课刚说过：光速是所有速度的上限，$1.2c$ 根本不该存在。**要么公设错了，要么"速度相加"这条日常算术错了。**

正确答案是 $0.882c$。而更漂亮的是：换一把尺子去量——快度——加法又变回了一条笔直的直线。

## 2. 直觉解释

问题出在"速度"这个量的身份。速度是 $\Delta x / \Delta t$：**分子分母都是会随参考系变的**。两个系的长度刻度与时间刻度都不一样，凭什么指望它们的比值能简单相加？

正确的类比是**角度**。想想地球表面：一直朝东北走，不是"东 + 北"的简单叠加，而是方位角在旋转。角度能直接相加（转 30° 再转 30° 就是 60°），斜率不能。

相对论里"角度"的对应物叫**快度** $\phi$：它按 $\beta = \tanh\phi$ 换成速度。tanh 的曲线从 0 出发、在 1 处有水平渐近线——**无论 $\phi$ 加多少次，$\tanh \phi$ 永远够不着 1**。这就是"追不上光"的全部秘密：光速不是一道需要费力翻越的墙，而是一条永远靠近、永远不碰的渐近线。

## 3. 正式定义

设飞船相对空间站的速度为 $v = \beta_1 c$，探测器相对飞船的速度为 $u' = \beta_2 c$，则空间站看到的速度

$$\beta = \frac{\beta_1 + \beta_2}{1 + \beta_1\beta_2}$$

定义**快度** $\phi$ 为

$$\phi = \operatorname{artanh}\beta = \frac{1}{2}\ln\frac{1+\beta}{1-\beta},\qquad \beta = \tanh\phi$$

则两次合成只剩一个加法：

$$\phi_{\text{总}} = \phi_1 + \phi_2$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\beta_1,\ \beta_2$ | 两个速度参数 | 各自都以 $c$ 为单位，都在 $(-1, 1)$ 内 |
| $\beta$ | 合成速度 | 分母 $1 + \beta_1\beta_2$ 就是"来不及"的那一项 |
| $\phi$ | 快度 | 值域是整个实数轴，可正可负可无限大 |
| $\operatorname{artanh}$ | 反双曲正切 | $\tanh$ 的反函数，把 $(-1,1)$ 拉到整条实轴 |

三条性质，最好背下来：

1. **永不超光速**：$\tanh$ 的值域天然是 $(-1, 1)$，所以 $\beta$ 自动满足 $|\beta| \lt 1$，不需要额外检查；
2. **低速回伽利略**：$\beta_1\beta_2 \ll 1$ 时分母约为 1，加法退回日常算术。两辆车各 30 m/s，修正量是 $10^{-14}$ 量级；
3. **同向时 $c$ 是吸收元**：$\beta_2 = 1$ 时 $\beta = (1+\beta_1)/(1+\beta_1) = 1$。谁也别想把光加速到超过光速，光自己也不会因为"被追"而变快。

## 4. 分步例题

**例**：$\beta_1 = \beta_2 = 0.6$，求合成速度，并用快度核对。

1. **直接加**：$1.2$——超出光速，公设不答应，说明这个算法错了；
2. **套合成公式**：$\beta = 1.2 / (1 + 0.36) = 1.2/1.36 = 0.88235$；
3. **换成快度**：$\phi_1 = \operatorname{artanh}0.6 = 0.69315$，两个加起来 $\phi = 1.38629$；
4. **换回速度**：$\beta = \tanh 1.38629 = 0.88235$——与第 2 步完全一致，说明快度不是另一套物理，只是同一件事的另一组坐标；
5. **再叠一次**（第三枚 $0.6c$ 的探测器）：$\phi = 2.07944$，$\beta = \tanh 2.07944 = 0.96923$。三次叠加才到 $0.969c$；叠七次是 $0.999878c$——**永远差最后那一点点**。

## 5. 动手实验

### 实验 1（lab）：快度尺 vs 速度尺

```lab
{
  "type": "rel-rapidity",
  "title": "把两段快度接起来：加法在这里成立",
  "beta1": 0.6,
  "beta2": 0.6
}
```

- 第二行是核心：两段快度首尾相接，总长度严格等于 $\phi_1 + \phi_2$，**没有任何修正项**；
- 第三行换回速度看：绿色点是相对论合成（永远在光速墙左侧），红色点是伽利略合成 $\beta_1+\beta_2$。把两个滑块都拖到 0.6，红点直接冲出光速墙，读数条会写明"已经超过光速，物理上不可能"；
- 拖动第一行那两个圆把手，让 $\phi_2$ 变得很大（$\beta_2 \to 0.95$）：第二行的橙色段变得很长，而第三行绿色点只是**贴近**光速墙，从不越过。

### 实验 2（python）：叠七次 0.6c 会怎样

```python
import math                      # math.atanh 是反双曲正切（artanh）

beta = 0.6                       # 每次叠加的速度（以 c 为单位）
phi = math.atanh(beta)           # 换成快度：这一步之后加法就是普通加法

print("叠加次数   速度 β      快度 φ")
for n in range(1, 8):            # range(1, 8) 给出 1..7
    total = math.tanh(n * phi)   # 快度线性累加，再换回速度
    print(f"{n:^9d} {total:9.6f} {n * phi:9.4f}")
```

看第二列：$0.6 \to 0.882 \to 0.969 \to 0.992 \to 0.998 \to 0.9995 \to 0.99988$。**快度那一列是均匀的等差数列**（0.6931 的整数倍，这正是"直线"），速度那一列却在快速逼近 1 之后越爬越慢。同样七次叠加，快度涨了 7 倍，速度只从 0.6 走到 0.99988。

::::warning[常见误区]

**误区一**："相对论说速度不能超过光速，是因为加速到后来阻力变大。"
没有任何阻力。速度合成的分母 $1+\beta_1\beta_2$ 是**几何**带来的：两个快度相加之后，$\tanh$ 天然落在 $(-1,1)$。加速器里给粒子加油门，粒子感受到的是快度一直在正常增长（每加一份能量就涨一段快度），只是换回速度时永远差最后一点。

**误区二**："$0.6c + 0.6c = 0.882c$ 这个修正只在极大速度下才有。"
修正量 $\beta_1\beta_2$ 确实小，但"相对论只在高速才重要"是**对效应的误判**：速度合成的修正量到 $0.1c$ 时只有 1%，可原子钟的精度早就高于这个数。GPS 卫星的速度才 3.9 km/s（$\beta \approx 1.3\times10^{-5}$），修正量 $10^{-10}$，而正是这一项让定位每天偏 7 微秒——第 80 课要还这笔账。

**误区三**："快度只是换了个写法，没有什么新内容。"
它把非线性问题变成了线性问题，这是实打实的工具：粒子物理里束流的"快度分布"是画数据最常用的坐标，因为**快度差在沿束流方向的 boost 下不变**（$\phi$ 是平移，不是乘法）。同一个道理，第 77 章讲哈密顿力学时会以"正则变换"的面貌再次出现。

::::

## 6. 练习

**练习 1**：两级火箭都以 $0.6c$ 同向飞行，求地面看到的速度（保留六位小数）。初始代码用了伽利略加法：

```exercise
# @title: 练习：两级火箭的速度合成
# @check: 0.882353
# @hint: 用 β = (β₁+β₂)/(1+β₁β₂)。分母的 1+β₁β₂ 已经算好了：1 + 0.36 = 1.36，把 1.2 除以它就对了。也可以走快度：artanh(0.6) 加两次再 tanh 回来。
b1 = 0.6               # 第一级相对地面的速度
b2 = 0.6               # 第二级相对第一级的速度
b = b1 + b2            # ← 伽利略式相加
print(f"{b:.6f}")
```

初始代码输出 `1.200000`——比光速还快，直接违反公设。改成合成公式之后是 `0.882353`。

**练习 2**：回答三问：(a) 两个 $0.9c$ 同向合成的结果是多少？(b) $\beta_1 = 0.5$、$\beta_2 = -0.5$（反向）合成是多少，合理吗？(c) 快度 $\phi = 3$ 对应多大的速度？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $\beta = 1.8/(1+0.81) = 0.99448$——即使两个 $0.9c$ 相加也没到 $0.995c$；
2. (b) $\beta = 0/(1-0.25) = 0$。合理：两枚同速反向的火箭，地面看到的就是都停着——这也是"追不上光"的反面：方向相反时相减没有修正；
3. (c) $\beta = \tanh 3 = 0.99505$。反过来看：想把速度从 $0.995c$ 再往上推一点点，加的不是速度，是快度。

**工程视角**：加速器物理几乎只用快度与赝快度（$\eta$，用出射角代替速度）来画粒子分布。原因就是练习里的那条性质：**沿束流方向做 boost 时，快度只是整体平移，分布形状不变**。换成速度坐标，同一份数据会在不同能量的束流下被拉得面目全非。

</details>

## 7. 选读：快度就是洛伦兹变换的"转角"

<details>
<summary>选读 · 连续两次 boost 的合成与双曲转角</summary>

把洛伦兹变换写成矩阵形式（用光秒，$c = 1$）：

$$\begin{pmatrix} ct' \\ x' \end{pmatrix} = \begin{pmatrix} \gamma & -\gamma\beta \\ -\gamma\beta & \gamma \end{pmatrix}\begin{pmatrix} ct \\ x \end{pmatrix}$$

用快度替换 $\gamma = \cosh\phi$、$\gamma\beta = \sinh\phi$，矩阵立刻变成

$$\begin{pmatrix} \cosh\phi & -\sinh\phi \\ -\sinh\phi & \cosh\phi \end{pmatrix}$$

这和平面上的旋转矩阵 $\begin{pmatrix}\cos\theta & -\sin\theta \\ \sin\theta & \cos\theta\end{pmatrix}$ 长得几乎一样，只差一些正负号——这就是"双曲旋转"这个名字的来历。两个矩阵相乘，用 $\cosh$、$\sinh$ 的和角公式，直接得到

$$\phi_{\text{总}} = \phi_1 + \phi_2$$

**"快度相加"不是巧合，它就是角度相加。** 速度之所以不能相加，是因为 $\beta = \tanh\phi$ 是角度的非线性函数（就像斜率的相加要带 $1+mn$ 的分母，而角度不用）。

这也顺手解释了洛伦兹变换为什么成群：每个 $\phi$ 对应一个变换，"相乘 = 角度相加"意味着这族变换在乘法下封闭、有逆（$\phi \to -\phi$）、有单位元（$\phi = 0$），这正是群的定义。而快度就是群的参数——**一个连续的对称群，只有一个参数**。物理定律在这一切换下形式不变，这句话写成数学就是"定律是快度的平移不变量"。

</details>
