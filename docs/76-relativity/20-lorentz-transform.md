# 洛伦兹变换：保光速的唯一线性变换

## 1. 从一个场景开始

一束激光沿站台射出去。站台系的记录是 $x = ct$：每过 1 秒，光前进 30 万公里。

现在换到一列以 $v$ 同向行驶的列车上。按伽利略的换算 $x' = x - vt$，车上记到的是 $x' = (c - v)t$——光速变成了 $c - v$。追得越快，光越慢，只要开到 $0.9999c$，光就慢得像蜗牛。

上一课的公设说这不可能。那就只剩一个出路：**换算规则本身错了**。这一课把正确的规则找出来，并且说明为什么它是唯一的。

## 2. 直觉解释

先看两张"体检表"，一张给空间，一张给时间。

- 空间那栏：两把尺子相对运动时不会互相改变长度刻度（不然上一课的"同时"就无从谈起）——所以换算是**线性**的，不掺平方、不掺指数；
- 时间那栏：伽利略把时间当成人人共享的绝对钟。问题是"同时"已经分裂了，时间就必须和空间**混在一起**换算：$\Delta t'$ 里要出现 $\Delta x$，$\Delta x'$ 里要出现 $\Delta t$。

一句话：新的变换不是"把 $x$ 减掉一段"，而是**把时空网格整体剪切一下**。45° 的光线是这个剪切的"固定线"——无论怎么剪，光线的斜率都必须还是 1。下一课的 lab 里你会亲手拖这个剪切。

## 3. 正式定义

设列车系 $S'$ 以 $\beta = v/c$ 沿 $x$ 轴正方向相对站台系 $S$ 运动，两个系的**原点在 $t = t' = 0$ 重合**。洛伦兹变换（boost）为

$$x' = \gamma\left(x - \beta ct\right),\qquad ct' = \gamma\left(ct - \beta x\right),\qquad \gamma = \frac{1}{\sqrt{1 - \beta^{2}}}$$

逆变换只要把 $\beta$ 换成 $-\beta$（列车看站台，站台在往后退）：

$$x = \gamma\left(x' + \beta ct'\right),\qquad ct = \gamma\left(ct' + \beta x'\right)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $x,\ ct$ | 站台系坐标 | 习惯把时间乘上 $c$，这样两根轴的单位都是米 |
| $x',\ ct'$ | 列车系坐标 | 同一个事件的另一套读数 |
| $\beta$ | 速度参数 | $v/c$，$0 \le \beta \lt 1$ |
| $\gamma$ | 洛伦兹因子 | $1/\sqrt{1-\beta^2}$；$\beta \to 1$ 时发散 |
| $\beta ct$ | 混合项 | 时间坐标里混进了空间，空间坐标里混进了时间 |

**为什么唯一**：设线性变换 $x' = Ax + Bt$、$t' = Cx + Dt$。要求"光速不变"，就是把两条光线上的一切事件都映到光线上：$x = ct$ 与 $x = -ct$ 分别代入，立刻得到 $A = D$ 与 $B = Cc^{2}$。再要求逆变换形状相同（把 $\beta$ 换成 $-\beta$ 就回到原系），$A$ 只能是 $\gamma$。验算一下：把 $x = ct$ 代进去，得到 $x' = \gamma ct(1-\beta)$、$ct' = \gamma ct(1-\beta)$，两者严格相等——光速保住了。

## 4. 分步例题

**例**：站台系里有个事件 $E$：$t = 1$ 光秒，$x = 2$ 光秒。一列以 $\beta = 0.6$ 行驶的列车怎么看它？

1. **统一单位**：用光秒，$c = 1$，于是 $\beta ct$ 就是 $\beta t$；
2. **算因子**：$\gamma = 1/\sqrt{1-0.36} = 1.25$；
3. **算时间**：$t' = \gamma(t - \beta x) = 1.25 \times (1 - 1.2) = -0.25$ 光秒。**负的**——在这个观察者眼里，$E$ 发生在"现在"之前；
4. **算空间**：$x' = \gamma(x - \beta t) = 1.25 \times (2 - 0.6) = 1.75$ 光秒；
5. **核对不变量**：站台系 $t^{2} - x^{2} = 1 - 4 = -3$；列车系 $0.0625 - 3.0625 = -3$。**一模一样**——这正是下一章"时空间隔"的伏笔；
6. **负号合不合法**：$E$ 与原点之间的间隔是负的（类空），它与"现在"没有因果关系，所以谁先谁后可以随观察者变。若 $E$ 在光锥内（类时），任何观察者都会同意它发生在 $t' \gt 0$。

## 5. 动手实验

### 实验 1（lab）：拖 β 看时空网格被剪切

```lab
{
  "type": "rel-lorentz",
  "title": "拖 β：两套网格互相剪切，45° 的光锥纹丝不动",
  "beta": 0.6,
  "x": 1.0,
  "t": 0.5
}
```

- 先把 β 拖到 **0**：两套网格重合，回到伽利略世界；
- 把 β 拖到 0.6：蓝色网格被压成菱形。**注意 45° 虚线（光锥）还在原地**——两个系都把它当自己的对角线；
- 拖动画布上的红点 **E**：橙色虚线沿两组蓝网格线走到各自的坐标轴上，"数格子"的结果就是读数条里的 $x'$、$ct'$；
- 把 E 拖到光锥外侧（$|x| \gt |ct|$）再拖 β：$x'$、$ct'$ 都在变，而不变量 $c^{2}t^{2} - x^{2}$ 一动不动。

### 实验 2（python）：让光线自己检验变换

```python title="光速在洛伦兹变换下不变"
beta = 0.6
gamma = 1 / (1 - beta ** 2) ** 0.5

def boost(t, x):                       # 站台系 → 列车系（用光秒，c = 1）
    return gamma * (t - beta * x), gamma * (x - beta * t)

for x in [1.0, 2.5, 5.0]:              # 在光线上取三个事件：x = ct
    t = x                              # 光线上的事件满足 t = x
    tp, xp = boost(t, x)               # 变换到列车系
    print(f"x = {x:4.1f} → x′ = {xp:6.3f}，t′ = {tp:6.3f}，x′/t′ = {xp / tp:.3f}")
```

三行的最后一栏全是 `1.000`：光线上取三点，变换之后依然在光线上。换个不在光线上的事件（把 `t = x` 改成 `t = x / 2`）比值就不再是 1——那不是变换出错，是这些事件本来就不在光线上。真正该不变的是 $t^{2} - x^{2}$：加一行 `print(t*t - x*x, tp*tp - xp*xp)`，无论换成哪个事件、哪个 β，两个数永远相等。

```quiz
洛伦兹变换中，为什么 ct′ 那一行里会出现 βx？
- 因为时间膨胀需要额外的时间
- 因为"同时"是相对的，时间坐标必须混进空间 [*]
- 因为光速在所有参考系中都相同，所以时间必须保持不变

```

::::warning[常见误区]

**误区一**："洛伦兹变换就是 $x' = \gamma(x - vt)$、$t' = t$。"
少了一半。只改空间不改时间，光速照样不守恒。伽利略变换是洛伦兹变换在 $\beta \to 0$ 时的极限，两者差的就是 **$ct'$ 方程里的 $-\gamma\beta x$** 这一项。

**误区二**："$\gamma$ 是长度收缩的倍数，所以运动物体在运动方向上会真的被压扁。"
你以为尺子被物理压坏了——其实尺子什么感觉都没有。收缩是"同时"的相对性带来的**测量结果**：两端的位置必须同时读，而"同时"在两系里不是同一件事。同理，$\gamma$ 也不是"钟被拖慢了"，钟自己一切正常（下一课细讲）。

**误区三**："$t' \lt 0$ 说明时间倒流了。"
时间没有倒流，是**先后**换了。类空间隔的两个事件（$|x| \gt |ct|$）之间没有因果联系，谁先谁后本来就没有物理后果。反过来，任何有因果联系的两件事（类时）在任何惯性系里顺序都不会变——这一点在第 50 课的 lab 里可以亲手验证。

::::

## 6. 练习

**练习 1**：把事件 $(t, x) = (1, 2)$ 光秒从站台系换算到 $\beta = 0.6$ 的列车系，输出 $t'$ 与 $x'$。初始代码写成了伽利略变换：

```exercise
# @title: 练习：把事件换算到列车系
# @check: -0.25 1.75
# @hint: 两行都要动：t′ = γ(t − βx)，x′ = γ(x − βt)。用光秒时 c = 1，γ = 1.25。改完 t′ 是负数——这是对的，E 与原点之间是类空间隔。
beta = 0.6                 # 列车速度（以 c 为单位）
t, x = 1.0, 2.0            # 站台系里的事件坐标（光秒）
tp = t                     # ← 伽利略变换：时间不变
xp = x - beta * t
print(f"{tp:.2f} {xp:.2f}")
```

初始代码输出 `1.00 1.40`——它把时间当成了人人共享的绝对量。改完之后是 `-0.25 1.75`，并且请你顺手核对：$t^{2} - x^{2}$ 与 $t'^{2} - x'^{2}$ 必须相等。

**练习 2**：回答三问：(a) $\beta = 0.6$ 时 $\gamma$ 是多少？(b) 什么情况下洛伦兹变换退化回伽利略变换？(c) 事件 $(t,x) = (2, 1)$ 在 $\beta = 0.6$ 的列车系里 $t'$ 是多少，为什么这次是正的？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $\gamma = 1/\sqrt{1-0.36} = 1.25$；
2. (b) $\beta \to 0$ 时 $\gamma \to 1$，混合项消失，回到 $x' = x - vt$、$t' = t$。日常速度（比如 300 km/h 的列车，$\beta \approx 2.8 \times 10^{-7}$）下 $\gamma - 1 \approx 4 \times 10^{-14}$，任何仪器都测不出来——这就是为什么牛顿力学在生活里永远够用；
3. (c) $t' = 1.25 \times (2 - 0.6) = 1.75$ 光秒，正的。因为 $(2,1)$ 落在光锥内（$2^{2} - 1^{2} = 3 \gt 0$），是类时间隔，任何观察者都同意它发生在原点之后——先后不可翻转。

**工程视角**：粒子加速器里 $\beta = 0.999999$ 是常态，$\gamma \approx 700$。控制系统的时序、束流管上各探测器的"同时"判选，全都直接跑洛伦兹变换，没人会先试伽利略再修正——误差比信号大十几个数量级。

</details>

## 7. 选读：为什么"线性"这个要求这么强

<details>
<summary>选读 · 从"匀速直线运动还是匀速直线运动"到群结构</summary>

线性不是随口加的假设。惯性系的定义就是"不受力的物体走直线、走匀速"，而这条性质要**在任何惯性系里都成立**，坐标变换就必须把直线映成直线——只有线性（加平移）的变换做得到。这一步把无穷多种可能砍到只剩 4 个待定常数。

接着两条光线给出 $A = D$、$B = Cc^{2}$，再要求"逆变换形式相同"（相对性原理：列车看站台，规则不该变样），解出唯一的一族：

$$x' = \gamma(x - \beta ct),\quad ct' = \gamma(ct - \beta x)$$

一族里只有一个参数 $\beta$ ——这族变换的集合构成一个**群**（洛伦兹群）：连续做两次 boost，结果还是同族的 boost（这一点 40 课的快度会给出漂亮解释）；不做是恒等变换；每个都有逆。物理定律"对一切惯性系形式相同"，用群论的话说就是：**定律在洛伦兹群作用下不变**。这是 20 世纪物理学的主旋律：先找对称群，再写方程。

顺带一提，如果允许 $A \ne D$，你会得到一族"能保住光速但破坏相对性原理"的变换——它们把不同惯性系区别对待，需要一个特殊的"绝对参考系"。实验否定了它：站台上和列车上的物理定律，没有任何可测的差别。

</details>
