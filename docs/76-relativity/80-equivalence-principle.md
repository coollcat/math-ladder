# 等效原理与引力红移：广义相对论的门槛

## 1. 从一个场景开始

GPS 卫星上的原子钟，每天都比地面的钟**快 38 微秒**。

这个数字拆开来看更奇怪：卫星在 20200 公里高处，离地球远、引力弱，广义相对论说它该快 **45.7 微秒**；它以 3.87 km/s 绕地飞，狭义相对论说它该慢 **7.2 微秒**。两项一加，$45.7 - 7.2 = 38.5$ 微秒。

地面接收机靠光速传播的时间差定位：38.5 微秒乘以光速，**11.5 公里**。不做这项修正，GPS 每天早上就偏出十几公里，一天就彻底废掉。

而这一切的起点，是一个关于电梯的思想实验。

## 2. 直觉解释

**爱因斯坦的电梯**：一间封闭的电梯悬在太空里，以 $9.8\ \text{m/s}^{2}$ 向上加速。你在里面松开一个苹果——它"落"了，落法和你在地面上看到的一模一样。你没法用任何实验区分"我在加速"与"我站在地球表面"。

反过来：电梯缆绳断了，自由下落的电梯里，苹果飘着，任何力学实验都测不出引力——**引力被"消掉"了**。

于是有了**等效原理**：引力与加速度局部不可区分；等价地说，**自由下落的参考系就是局部惯性系**。

现在在加速的电梯里横着打一束光。光穿过电梯要花时间 $t = L/c$，这段时间里电梯向上加速了 $\frac{1}{2}at^{2}$——所以光在电梯里走的是一条**向下弯的抛物线**。等效原理说：引力场里光也会弯。

钟变慢是同一件事的另一个镜头。光从高处往低处落，在弯曲的路径上"掉"得更快（蓝移）；而频率就是钟的节拍：**低处的钟慢，高处的钟快**。用第 70 课的多普勒语言说：光从低处爬到高处，就等于从"发得快"的地方发到"收得慢"的地方，必然红移。

## 3. 正式定义

在弱引力场（$|\Phi| \ll c^{2}$）里，钟的速率差只取决于**引力势差**：

$$\frac{\Delta f}{f} = \frac{\Delta\Phi}{c^{2}}$$

均匀重力场（高度差 $h$，重力加速度 $g$）与球对称场（$r_{1} \lt r_{2}$）分别写成

$$\frac{\Delta f}{f} = \frac{gh}{c^{2}},\qquad \frac{\Delta f}{f} = \frac{GM}{c^{2}}\left(\frac{1}{r_{1}} - \frac{1}{r_{2}}\right)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\Delta f/f$ | 相对频移 | 无量纲；$10^{-13}$ 量级就需要原子钟才能看到 |
| $\Phi$ | 引力势 | 越靠近大质量天体越低（负得越多），钟越慢 |
| $g$ | 重力加速度 | 地表 $9.80665\ \text{m/s}^{2}$ |
| $GM/c^{2}$ | 地球的"半引力半径" | $4.435\times10^{-3}$ m，地球引力场的天然长度单位 |
| $R_{\oplus}$ | 地球半径 | $6.371\times10^{6}$ m |

圆轨道上的卫星（速度 $v = \sqrt{GM/r}$）要两项一起算：

$$\text{净速率} = \underbrace{\frac{GM}{c^{2}}\left(\frac{1}{R_{\oplus}} - \frac{1}{r}\right)}_{\text{广义相对论：高处的钟快}} - \underbrace{\frac{GM}{2rc^{2}}}_{\text{狭义相对论：动着的钟慢}} = \frac{GM}{c^{2}}\left(\frac{1}{R_{\oplus}} - \frac{3}{2r}\right)$$

令净速率为零，立刻得到 $r = \frac{3}{2}R_{\oplus} = 9557$ km ——**在 3186 公里的高度上，两个效应精确对消**。这是广义相对论少见的一个"整数答案"，也是检验两条公式是否都写对了的最好标尺。

## 4. 分步例题

**例 1（塔）**：一座 1000 米高的塔，塔顶的钟与塔底的钟一天差多少？

1. **算相对频移**：$\Delta f/f = gh/c^{2} = 9.80665 \times 1000 / (299792458)^{2} = 1.0911\times10^{-13}$；
2. **换成每天的时间差**：$\times 86400$ s $= 9.427\times10^{-9}$ s $= 9.43$ ns；
3. **物理读法**：塔顶的钟一天快 9.43 纳秒——相当于 300 年差 1 毫秒。这个量级今天已经不算稀奇：光晶格钟的稳定度到 $10^{-18}$，能分辨**1 厘米**的高度差（$gh/c^{2} \approx 1.09\times10^{-18}$）；1976 年美国把氢脉泽钟用火箭送到一万公里高空（Gravity Probe A），把引力红移验证到万分之一的精度。

**例 2（Pound–Rebka，1959）**：哈佛大学的塔高 22.5 米，用 $^{57}$Fe 的 14.4 keV γ 射线测引力红移。

1. **算预言值**：$\Delta f/f = 9.80665 \times 22.5 / c^{2} = 2.46\times10^{-15}$；
2. **难点**：这个相对频移比谱线的自然宽度还小两个数量级，静态测量根本看不出来；
3. **庞德与雷布卡的巧招**：让源以几厘米每秒的速度上下运动，用多普勒效应"扫描"过那个频率——把测量变成一个可调的比较；
4. **结果**：实测与预言相符到约 1%。这是引力红移第一次在地面实验室里被直接确认，比 GPS 早了 30 年。

## 5. 动手实验

### 实验 1（lab）：拖高度，看两个效应怎么打架

```lab
{
  "type": "rel-gravity-clock",
  "title": "拖游标：引力项与速度项，谁赢？",
  "h": 20200
}
```

- 蓝线（引力）随高度一路上涨，橙线（速度）一直是负的且变化缓慢——**因为 $1/r$ 衰减得慢，而 $1/R_{\oplus} - 1/r$ 在低处涨得快**；
- 拖到 $h \approx 3186$ km：绿线与零线相交，读数条给出净效应 $0.00\ \mu s/$天。这就是 $r = 1.5R_{\oplus}$；
- 拖到 20200 km（GPS 那条橙色虚线上）：读数条给出 $+45.72$、$-7.21$、$+38.51$ μs/天，以及"一天定位漂 11.55 km"；
- 把游标拖到 40000 km（同步轨道以外）：净效应涨到 $+47.75$ μs/天——**继续升高，收益就饱和了**，因为引力项趋近于常数 $GM/(R_{\oplus}c^{2}) = 60.1\ \mu s/$天，而速度项趋于 0。

### 实验 2（python）：四个高度的对照表

```python
c = 299792458.0          # 光速（m/s）
GM = 3.986004418e14      # 地球的 GM（m³/s²）
RE = 6.371e6             # 地球半径（m）
DAY = 86400.0            # 一天的秒数

print(" 高度(km)   引力项    速度项    净效应   （微秒/天）")
for hkm in [0.0, 3185.5, 20200.0, 40000.0]:
    r = RE + hkm * 1000                                  # 地心距
    gr = GM / c ** 2 * (1 / RE - 1 / r) * DAY * 1e6      # 引力项：高处钟快
    sr = -(GM / r) / (2 * c ** 2) * DAY * 1e6            # 速度项：圆轨道上的钟慢
    print(f"{hkm:10.1f} {gr:9.2f} {sr:9.2f} {gr + sr:9.2f}")
```

四行读出一个完整的故事：地面上（按圆轨道算）净效应 $-30.07$ μs/天；$3185.5$ km 处恰好归零；GPS 高度 $+38.51$；四万公里 $+47.75$，向 $+60.1$ 的天花板缓慢爬。**两个符号相反的效应、一条穿过零点的曲线**——这就是为什么 GPS 必须做修正，也是为什么"卫星越高钟越快"这话只在 3186 公里以上成立。

### 快问快答

```quiz
为什么 GPS 卫星上的钟比地面的钟快？
- 因为卫星离地球远，引力弱，广义相对论效应占了上风 [*]
- 因为卫星在真空中，没有空气阻力
- 因为卫星的原子钟精度更高
? 引力项 +45.7 微秒压过了速度项 −7.2 微秒，净效应是每天快 38.5 微秒。
```

::::warning[常见误区]

**误区一**："引力红移是光在爬坡时消耗了能量，所以变红。"
这个"光子有重量"的图像能给出正确答案（$h\nu/c^{2}$ 的等效质量 × $gh$），但只在弱场里凑巧对。真正的机制是**时钟速率不同**：不是光在旅途中丢了能量，是发射端与接收端的钟走得不一样快。判据很清楚：把光源和探测器都放在同一高度，无论中间经过什么，红移立刻为零。

**误区二**："等效原理说引力和加速度完全一样，所以引力可以被'消除'。"
只能**局部**消除。自由下落的电梯里，苹果飘着——但如果电梯足够大，你会发现两个相隔很远的苹果在下落时**互相靠近**（它们都朝着地心落）。这种"潮汐效应"是引力的不可消除部分，也正是时空弯曲的证据。等效原理是局部的，这个"局部"两个字后来长成了整个微分几何。

**误区三**："GPS 的 38 微秒是狭义相对论算出来的。"
恰恰相反，**大头是广义相对论**：45.7 μs 对 −7.2 μs，狭义相对论只占不到五分之一，而且符号是反的。如果只做狭义相对论修正，误差不是"小一点"，而是从 $+38.5$ 变成 $-7.2$——方向都错了。

::::

## 6. 练习

**练习 1**：1000 米高的塔，塔顶的钟相对塔底每天快多少纳秒？同时输出相对频移（六位有效数字）。初始代码把 $c^{2}$ 写成了 $c$：

```exercise
# @title: 练习：塔顶的钟快多少
# @check: 1.091137e-13 9.43
# @hint: 引力红移是 Δf/f = gh/c²，分母是光速的平方。算完乘 86400 秒换算成"每天差多少秒"，再乘 1e9 换成纳秒。
g = 9.80665               # 重力加速度（m/s²）
h = 1000.0                # 塔高（m）
c = 299792458.0           # 光速（m/s）
frac = g * h / c          # ← 分母应该是 c 的平方
print(f"{frac:.6e}", f"{frac * 86400 * 1e9:.2f}")
```

初始代码输出 `3.271146e-05 2826270432.73`——它说塔顶的钟一天快 28 亿纳秒，也就是**将近 3 秒**。那意味着塔顶的钟一年快 1000 秒，任何一块手表都能测出来，显然荒谬。改成 $c^{2}$ 之后是 `1.091137e-13 9.43`：一天 9.43 纳秒，与实验一致。

**练习 2**：回答三问：(a) 太阳表面的引力红移是多少（$M_{\odot} = 1.989\times10^{30}$ kg，$R_{\odot} = 6.957\times10^{8}$ m，$G = 6.674\times10^{-11}$）？(b) 什么高度上净效应为零？(c) 若 GPS 不做修正，接收机的钟每天要调多少微秒？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $GM/(R_{\odot}c^{2}) = 6.674\times10^{-11} \times 1.989\times10^{30} / (6.957\times10^{8} \times c^{2}) = 2.12\times10^{-6}$。太阳光谱线的红移约为百万分之二——这个量级 1920 年代就能测；
2. (b) $r = 1.5R_{\oplus} = 9557$ km，即高度约 **3186 km**；
3. (c) 卫星钟每天快 38.5 μs，接收机必须把这 38.5 μs 从时间差里扣掉；不扣的话，$38.5\ \mu s \times c = 11.5$ km，定位直接偏出城市。

**一句话总结**：狭义相对论告诉我们"运动的钟慢"，广义相对论补上"低处的钟也慢"。GPS 每天都在替这两条公式做实验，而它的账本上写得清清楚楚：$+45.7$ 与 $-7.2$，合计 $+38.5$。

</details>

## 7. 选读：从等效原理到弯曲时空

<details>
<summary>选读 · 引力不是力，是几何</summary>

等效原理的推论比它看起来的样子激进得多。既然自由下落的参考系是局部惯性系，那么**在自由下落的人看来，引力根本不存在**——他眼里的世界是狭义相对论的世界，一切按闵可夫斯基几何走。可地面上的我们明明感到重量（那是地板在推我们向上加速）。

爱因斯坦于是把账本反过来记：**引力不是一种力，而是"惯性系"这个概念的失效**。在地球周围，没有一个全局的惯性系；每一小块时空都有自己的局部惯性系，而它们互相之间是"错位"的。把无数个局部惯性系拼起来，拼出的几何不再是平坦的闵可夫斯基几何——**它是弯曲的**。

弯曲的量由物质决定，这就是爱因斯坦场方程：

$$G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^{4}}T_{\mu\nu}$$

左边是几何（$g_{\mu\nu}$ 与它导出的曲率 $G_{\mu\nu}$），右边是物质与能量。**"物质告诉时空怎么弯，时空告诉物质怎么走。"** 57 章讲过的第一基本形式、测地线、黎曼曲率，到这里全部派上用场：自由粒子走的是时空的测地线，光线走的也是——所以光会被太阳偏折 $1.75$ 角秒（1919 年爱丁顿的日食观测证实），所以水星近日点每世纪多进动 43 角秒。

三个后续，每一个都值得单开一章：

1. **引力时间膨胀是全局的**：GPS 的 45.7 μs 只是它在地球附近的一个小读数。若把钟放到黑洞附近，$\Delta f/f$ 可以接近 1——远处的人看你，你的钟几乎停住；
2. **引力波**：时空的弯曲可以波动，以光速传播。2015 年 LIGO 直接探测到两个黑洞并合的引力波，峰值应变 $10^{-21}$——相当于测量 4 光年外一个质子的直径变化；
3. **时空的奇点与视界**：把 $r = 2GM/c^{2}$（史瓦西半径）代进去，度规的一个分量发散——那不是"引力太大"，而是坐标选坏了；但视界确实是一张因果的分界线，与第 50 课的光锥是同一种几何。

在数学上，广义相对论是微分几何最好的应用场；在工程上，它已经进入日常生活——你的手机每天靠它定位。

</details>
