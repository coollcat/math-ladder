# 相对论多普勒与光行差

## 1. 从一个场景开始

天文学家在遥远星系的光谱里找到氢的 Hα 线——实验室里它在 656.3 纳米，天上来的是 **1312.6 纳米**，正好是两倍长。

另一件怪事：射电星系 3C 273 的喷流，一侧亮得像探照灯，另一侧几乎看不见。更离谱的是，有些喷流的"横向速度"算出来是光速的 6 倍多。

三件怪事，两个公式就够：**多普勒因子** $D$ 与**光行差**。它们都是四维动量的直接推论。

## 2. 直觉解释

经典多普勒（救护车）只说了一半：声源朝你冲来时波峰被挤密，频率变高。光的版本要多想一层——**源自己在动，它的钟也慢了**。所以：

$$\text{观测频率} = \frac{\text{被压缩/拉伸的几何因子}}{\text{时间膨胀因子}}$$

几何因子是 $(1 - \beta\cos\theta)$：迎面（$\theta = 0$）时波峰间隔被压到 $(1-\beta)$ 倍；背对（$\theta = 180°$）时被拉到 $(1+\beta)$ 倍。时间膨胀因子是 $\gamma$。

有意思的是正横方向（$\theta = 90°$）：几何因子是 1，什么压缩都没有，可**频率仍然变低**——纯时间膨胀的红移。这一项是经典波动理论无论如何给不出来的，也是狭义相对论最干脆的判决性证据之一（Ives–Stilwell 实验，1938 年用氢的极隧射线测到了它）。

光行差是同一件事的另一面：源在动，**光的来向也偏**。源系里朝四面八方均匀发光的物体，在实验室里光会全部挤向前方一个窄锥。这不是光被"吹歪了"，而是"同时"与"方向"在换系时一起转了。

## 3. 正式定义

设光源以 $\beta = v/c$ 运动，$\theta$ 是**速度方向与"源 → 观察者"连线的夹角**，定义**多普勒因子**

$$D = \frac{1}{\gamma\left(1 - \beta\cos\theta\right)},\qquad \nu_{\text{obs}} = D\,\nu_{\text{rest}},\qquad \lambda_{\text{obs}} = \frac{\lambda_{\text{rest}}}{D}$$

**光行差**（源系里偏离运动方向 $\theta'$ 的光，在实验室里变成 $\theta$）：

$$\cos\theta = \frac{\cos\theta' + \beta}{1 + \beta\cos\theta'}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $D$ | 多普勒因子 | $\gt 1$ 蓝移（靠近），$\lt 1$ 红移（远离），$=1$ 不动 |
| $\theta$ | 视角 | $\theta = 0$ 迎面冲来；$90°$ 正横掠过；$180°$ 转身而去 |
| $\gamma$ | 洛伦兹因子 | 时间膨胀的那一份——即使 $\theta = 90°$ 也照样生效 |
| $\theta'$ | 源系里的出射角 | 换成实验室角度要用光行差公式 |
| $\arccos\beta$ | 头灯半角 | 源系前半球的光在实验室里全挤进这个锥（$\beta \to 1$ 时趋近 $0$） |

三种特例值得背下来：

1. **迎面**（$\theta = 0$）：$D = \sqrt{(1+\beta)/(1-\beta)}$，$\beta = 0.6$ 时正好是 2——波长减半（蓝移）；
2. **背对**（$\theta = 180°$）：$D = \sqrt{(1-\beta)/(1+\beta)}$，同一个 $\beta$ 下是 $0.5$——波长加倍（红移）；
3. **正横**（$\theta = 90°$）：$D = 1/\gamma \lt 1$，**只有红移**。这一个数字是狭义相对论的签名。

## 4. 分步例题

**例**：$\beta = 0.6$ 的氢光源，静止波长 $\lambda = 656.3$ nm（Hα）。求迎面、正横、背对三种情形的观测波长。

1. **算因子**：$\gamma = 1.25$；
2. **迎面**（$\theta = 0$，$\cos\theta = 1$）：$D = 1/(1.25 \times 0.4) = 2$，$\lambda_{\text{obs}} = 656.3/2 = 328.15$ nm——从红光跑到了紫外边缘；
3. **正横**（$\theta = 90°$，$\cos\theta = 0$）：$D = 1/1.25 = 0.8$，$\lambda_{\text{obs}} = 656.3/0.8 = 820.375$ nm（浮点运算下程序会打印 820.37）——**即使"横着飞"也是红移**；
4. **背对**（$\theta = 180°$，$\cos\theta = -1$）：$D = 1/(1.25 \times 1.6) = 0.5$，$\lambda_{\text{obs}} = 1312.6$ nm——正好是开头那个星系；
5. **算红移量**：$z = \lambda_{\text{obs}}/\lambda_{\text{rest}} - 1 = 1/D - 1$。第 4 步给出 $z = 1$，第 2 步给出 $z = -0.5$（蓝移，负号是正常的）；
6. **再看头灯**：$\arccos 0.6 = 53.13°$——源系前半球的光在实验室里全挤进 $53°$ 的锥。把 $\beta$ 提到 0.99，这个角缩到 $8.1°$，亮度集中得像个手电筒。

## 5. 动手实验

### 实验 1（lab）：转一圈速度箭头，看谱线搬家

```lab
{
  "type": "rel-doppler",
  "title": "拖红色箭头：迎面蓝移、正横红移、背对更红",
  "beta": 0.6,
  "theta": 0
}
```

- 默认 $\theta = 0$（迎面）：四条实线整体压在虚线左边，Hα 从 656.3 跑到 328.15 nm；
- **把箭头拖到竖直**（$\theta = 90°$，正横）：实线跑到虚线**右边**——读数条给出 $D = 0.8$。这个"横着飞还变红"就是时间膨胀；
- 继续拖到指向右边（$\theta = 180°$）：谱线搬到 1312.6 nm，正好翻倍；
- 把 β 拖到 0.99 再重复一遍：迎面时 $D \approx 14$，Hα 直接移出左边框（画布上会标"移出左边"）；读数条"光行差"那一行会告诉你光被挤进了 $8.1°$ 的锥。

### 实验 2（python）：一张角度扫描表

```python
import math                     # math.radians 把角度换成弧度，math.cos 用弧度

beta = 0.6                      # 光源速度（以 c 为单位）
gamma = 1 / math.sqrt(1 - beta ** 2)
lam = 656.3                     # Hα 的静止波长（nm）

print("  θ        D        观测波长(nm)")
for deg in range(0, 181, 45):   # 0°、45°、90°、135°、180°
    theta = math.radians(deg)
    D = 1 / (gamma * (1 - beta * math.cos(theta)))   # 多普勒因子
    print(f"{deg:4d}° {D:8.4f} {lam / D:14.2f}")
```

五行的波长一路从 $328.15$ 涨到 $1312.60$，**中间经过 820.37**——正横那一行的红移（$D = 0.8$）是经典多普勒给不出的。把 `beta` 改成 $0.999$：迎面的 $D$ 变成 $44.7$，Hα（静止波长 656.28 nm）被压到 14.7 nm（远紫外），**蓝移 44.7 倍**；而 $\theta = 90°$ 那一行只剩 $0.0447$，同一根谱线被拉到 14.7 μm，**红移 22.4 倍**。两侧都被推得很远，但**迎面那一侧更极端**（44.7 倍对 22.4 倍）——这正是高能喷流的辐射几乎全集中在正前方的原因。

### 快问快答

```quiz
光源横向掠过观察者（速度与视线垂直）时，观察到的谱线会怎样？
- 完全不变，因为没有相对接近或远离
- 红移，因为光源的钟走得慢 [*]
- 蓝移，因为横向运动也会压缩波长
? 横向多普勒是纯时间膨胀效应，D = 1/γ < 1，只能红移。
```

::::warning[常见误区]

**误区一**："多普勒效应就是波长乘 $(1-\beta)$。"
那是经典公式，只在低速下近似成立。相对论版本是 $\lambda/\sqrt{(1+\beta)/(1-\beta)}$ 这种"几何 × 时间膨胀"的形式：$\beta = 0.6$ 迎面时经典给出 262.5 nm，正确值是 328.15 nm，差 25%。而且经典公式在 $\theta = 90°$ 给出"不变"，直接漏掉整个横向效应。

**误区二**："红移大就说明离得远。"
宇宙学红移确实对应距离，但前提是**已经扣掉了光源自身的运动**。一颗以 $0.6c$ 横着飞的恒星也有 $D = 0.8$ 的红移，它离我们可能只有几十光年。天文上区分这两者的办法是看谱线的**形状与其他证据**（比如宿主星系、光度距离），而不是只读一个波长。

**误区三**："光行差让光变亮，是因为光被聚拢了所以能量变多。"
聚拢的是**方向**，能量密度确实上升，但每个光子的能量也同时被 $D$ 改变（蓝移）——两件事一起贡献了亮度的 $D^{3}$（甚至 $D^{4}$）增强。所以头灯效应既有几何（挤进窄锥），也有能量（每个光子更蓝）。

::::

## 6. 练习

**练习 1**：$\beta = 0.6$ 的氢光源正对观察者飞来（$\theta = 0$），求 Hα（656.3 nm）的观测波长。初始代码用了经典公式：

```exercise
# @title: 练习：迎面飞来的 Hα 线
# @check: 328.15
# @hint: 相对论多普勒要用 λ_obs = λ√((1−β)/(1+β))（迎面时），它等于 λ/D。经典公式漏了时间膨胀，把 0.4 换成了 √(0.4/1.6) = 0.5。
beta = 0.6                 # 光源速度（以 c 为单位），正对观察者而来
lam = 656.3                # 静止时的 Hα 波长（nm）
lam_obs = lam * (1 - beta) # ← 经典多普勒，漏了时间膨胀
print(round(lam_obs, 2))
```

初始代码输出 `262.52`——蓝移过了头。正确值是 `328.15`：几何压缩因子是 0.4，时间膨胀让源的发波周期变长 1.25 倍，两者一除得到 0.5，正好是 $1/D$（$D = 2$）。

**练习 2**：回答三问：(a) 若观测到 Hα 跑到 1312.6 nm，$\theta$ 与 $\beta$ 可能是多少？(b) $\beta = 0.99$ 时头灯半角是多少？(c) 为什么射电喷流只有一侧亮？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $\lambda$ 翻倍意味着 $D = 0.5$，对应 $\beta = 0.6$ 且 $\theta = 180°$（转身而去），或任何满足 $\gamma(1-\beta\cos\theta) = 2$ 的组合；
2. (b) $\arccos 0.99 = 8.1°$。源系里朝前半球发出的光，在实验室里全落进这个 $8.1°$ 的锥；朝后半球的光被摊开到剩下的一整圈里；
3. (c) 喷流是双侧对称的，但只有朝向我们的那一侧处在头灯锥内：$D$ 大不止意味着更蓝，还意味着亮度按 $D^{3\sim4}$ 放大。另一侧的 $D$ 很小，同样功率的光被摊薄到几乎看不见。**这是几何与相对论的合成效果，不是喷流本身不对称。**

**工程视角**：$D$ 不只用于天文。粒子物理里"同步辐射的角分布"就是同一个头灯效应——$10$ GeV 的电子束在储存环里，辐射几乎全部朝前喷出，这是同步辐射光源亮度极高的根本原因，也是设计光束线时必须算进去的第一项。

</details>

## 7. 选读：视超光速——看上去比光快，其实没有

<details>
<summary>选读 · 表观横向速度 $v_{\text{app}} = \beta c\sin\theta/(1-\beta\cos\theta)$</summary>

有些类星体喷流的横向移动速度，按距离和角度一算，竟然是光速的好几倍。这并不违反相对论——**因为"横向速度"是用光到达我们的时间算的**。

设喷流以 $\beta$、角度 $\theta$（与视线夹角，$\theta$ 小意味着几乎正对我们）抛出一团物质。它在**垂直视线方向**上的位移是 $v t\sin\theta$（$t$ 是源系时间…换成实验室时间后同阶）。而我们看到这个位移所花的时间不是 $t$，是 $t - (v t\cos\theta)/c$：物质在朝我们跑，后面发出的光要少走一段路。

$$v_{\text{app}} = \frac{v\sin\theta}{1-\beta\cos\theta}$$

$\beta \to 1$ 且 $\theta$ 很小时，分母可以小到 $1/\gamma^{2}$ 量级，$v_{\text{app}}$ 就能远超 $c$。取 $\beta = 0.99$，扫一遍角度：$\theta = 5°$ 时 $6.27c$，$10°$ 时 **$6.87c$**（极大值附近），$20°$ 时回落到 $4.86c$。

这解释了观测上的两个特征：① 视超光速只在 $\theta$ 很小的喷流里出现；② 出现视超光速的源，其喷流必然又亮又蓝（头灯效应与蓝移同时到位）——**两个独立的相对论效应互相印证**，这也是天文学家确信这些数值不是测量错误的原因。

顺带说，这个公式在数学上只是"投影 + 光行时"两步，没有任何新奇物理。它提醒我们：**"看到的速度"不等于"物理的速度"**——把光的传播时间算进观测，是一切天文测量都要做的第一道还原。

</details>
