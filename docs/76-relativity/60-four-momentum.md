# 四维矢量与相对论动力学：E=mc² 的真身

## 1. 从一个场景开始

大型强子对撞机里，两束质子迎面对撞。对撞后探测器里飞出来的粒子，有些的质量是质子的**几十倍**——可撞进去的明明只有质子。

质量从哪来？从动能来。$E = mc^{2}$ 不是一句口号，它是一条**换算率**：能量和质量是同一个东西的两种单位，换算系数是 $c^{2}$（一个大到离谱的数，所以一点点质量就是惊人的能量）。

但这条公式常常被写错。真正的守恒律比"$E=mc^{2}$"更完整：能量与动量必须**合成一个四维矢量**一起守恒。这一课就把这个矢量拿出来。

## 2. 直觉解释

第 50 课已经知道：$ct$ 与 $x$ 会混着转。既然坐标这样，动量和能量凭什么例外？

把"能量"当成**时间方向上的动量**，把"动量"当成**空间方向上的动量**，两者组成一个四维矢量 $p^{\mu} = (E/c,\ p_{x},\ p_{y},\ p_{z})$。它和坐标矢量遵守同一套洛伦兹变换：

- 一列高速列车看你的能量，会看到你的能量里混进了动量（这是"多普勒"的另一种说法）；
- 反过来，你的动量里也混进了能量。

于是"能量守恒"和"动量守恒"不再是两条独立定律，而是**同一条守恒律在四个方向上的投影**——就像"合外力为零"在 $x$、$y$ 两个方向各给一个方程。

再补一个关键技巧：世界线要用**固有时 $\tau$** 来参数化。用坐标时间 $t$ 做参数，$\Delta t$ 会随参考系变；用 $\tau$ 做参数，得到的就是不折不扣的四维矢量。

## 3. 正式定义

粒子静止质量为 $m$，四维速度 $u^{\mu} = dx^{\mu}/d\tau$，四维动量

$$p^{\mu} = m\,u^{\mu} = \left(\frac{E}{c},\ p_{x},\ p_{y},\ p_{z}\right)$$

分量写开（$\beta = v/c$，$\gamma = 1/\sqrt{1-\beta^{2}}$）：

$$E = \gamma m c^{2},\qquad \mathbf{p} = \gamma m \mathbf{v},\qquad E^{2} = (pc)^{2} + (mc^{2})^{2}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p^{\mu}$ | 四维动量 | 洛伦兹矢量；换系时四个分量混着转 |
| $E$ | 总能量 | 含静止能 $\gamma mc^{2}$，不是"动能" |
| $\mathbf{p}$ | 相对论动量 | 比 $m\mathbf{v}$ 多一个 $\gamma$；高速时增长极快 |
| $m$ | 静止质量 | **洛伦兹不变量**，与速度无关（现代口径只认这个 $m$） |
| $u^{\mu}$ | 四维速度 | 用固有时参数化，所以是矢量而非"三维速度的包装" |

"色散关系" $E^{2} = (pc)^{2} + (mc^{2})^{2}$ 是全部动力学的总公式，三种情形：

1. **静止**（$p = 0$）：$E = mc^{2}$——这才是 $E = mc^{2}$ 的完整前提（它说的是静止能）；
2. **低速**：展开 $\gamma \approx 1 + \beta^{2}/2$，得 $E \approx mc^{2} + \frac{1}{2}mv^{2}$——静止能加上我们熟悉的动能；
3. **无质量**（$m = 0$）：$E = pc$。光子就住在这里，它没有静止质量，却带着动量。

## 4. 分步例题

**例**：一个电子（$m = 9.109\times10^{-31}$ kg）以 $\beta = 0.99$ 飞行，求总能量、动能与动量。

1. **算因子**：$\gamma = 1/\sqrt{1-0.99^{2}} = 1/\sqrt{0.0199} = 7.0888$；
2. **静止能**：$mc^{2} = 9.109\times10^{-31} \times (299792458)^{2} = 8.1871\times10^{-14}$ J（换成粒子物理的单位是 **0.511 MeV**，电子的"身份证"）；
3. **总能量**：$E = \gamma mc^{2} = 7.0888 \times 8.1871\times10^{-14} = 5.8037\times10^{-13}$ J $= 3.6224$ MeV；
4. **动能**：$K = E - mc^{2} = 4.9850\times10^{-13}$ J $= 3.1114$ MeV——**动能比静止能大 6 倍多**，所以这个电子"很相对论"；
5. **动量**：$p = \gamma m v = 7.0888 \times 9.109\times10^{-31} \times 0.99 \times 299792458 = 1.9165\times10^{-21}$ kg·m/s；
6. **核对不变量**：$E^{2} - (pc)^{2} = 6.7029\times10^{-27} = (mc^{2})^{2}$——一位不差。换任何参考系算，这个组合都是同一个数，它就是"质量"的现代定义。

## 5. 动手实验

### 实验 1（lab）：一维弹性碰撞里，谁守恒、谁不守恒

```lab
{
  "type": "rel-collision",
  "title": "拖两个速度把手做对撞：动量要带 γ 才守恒",
  "u1": 0.8,
  "u2": 0.0,
  "m1": 1,
  "m2": 2
}
```

- 先看默认状态（$u_1 = 0.8c$，$u_2 = 0$，$m_1 = 1$，$m_2 = 2$）：读数条里**相对论动量**与**总能量**撞前撞后完全相等；
- 再盯第三行"牛顿动量 $\Sigma mu$"：撞前 0.8，撞后 0.96——**对不上**。这不是实验误差，是"动量必须写成 $\gamma m u$"的直接证据；
- 把两个速度都拖到 0.9c 附近对撞：$\gamma$ 涨到 2.3，牛顿动量那一行差得更离谱；
- 点**播放**看动画：两球在质心系里只是各自掉头，所以弹性能与动量同时守恒——碰撞规则是用快度算出来的，精确到小数点后十几位。

### 实验 2（python）：用四维动量重新算一遍碰撞

```python
c = 1.0                                  # 用自然单位：c = 1，能量与动量同为 GeV
m1, m2 = 1.0, 2.0                        # 两个粒子的静止质量（GeV/c²）
u1, u2 = 0.8, 0.0                        # 撞前速度（以 c 为单位）
v1, v2 = -0.32432432432432434, 0.6423357664233577   # 撞后速度（由质心系掉头算出）

def gamma(u):                            # 洛伦兹因子
    return 1 / (1 - u ** 2) ** 0.5

def total(u_a, u_b):                     # 返回 (总能量, 总动量)
    return gamma(u_a) * m1 + gamma(u_b) * m2, gamma(u_a) * m1 * u_a + gamma(u_b) * m2 * u_b

E_b, p_b = total(u1, u2)                 # 撞前
E_a, p_a = total(v1, v2)                 # 撞后
print(f"总能量：{E_b:.6f} → {E_a:.6f}")
print(f"总动量：{p_b:.6f} → {p_a:.6f}")
print(f"不变量 √(E² − p²)（系统的静止质量）：{(E_b**2 - p_b**2) ** 0.5:.6f} → {(E_a**2 - p_a**2) ** 0.5:.6f}")
```

三行输出都是"撞前 = 撞后"：$3.666667$、$1.333333$、$3.415650$。第三行尤其值得看——**系统的静止质量 $3.4157$ GeV 比两个粒子静止质量之和 3.0 GeV 还大**：动能被"锁"进了复合系统的质量里。这正是对撞机里"撞出来的粒子比撞进去的重"的算术解释。

::::warning[常见误区]

**误区一**："$E = mc^{2}$ 说的是任何物体的能量。"
它说的是**静止能**。运动物体是 $E = \gamma mc^{2}$，把 $\gamma$ 丢掉会算出"高速电子能量与静止时一样"这种荒唐结果（这正是本课练习的初始错误）。带 $\gamma$ 的版本才是完整公式，"$E=mc^2$"只是它在 $v=0$ 时的特例。

**误区二**："质量随速度增加，所以高速时质量会变成无穷大。"
"动质量" $m_{\text{rel}} = \gamma m$ 是上世纪的旧写法，现在已被淘汰——它把 $\gamma$ 藏进 $m$ 里，看起来简洁，却让人误以为"物质的量"变了。准确说法是：**动量与能量随 $\gamma$ 增长，静止质量不变**。$\gamma \to \infty$ 说的是"要把有质量粒子加速到 $c$ 需要无穷多能量"，而不是"粒子变得无穷重"。

**误区三**："光子没有质量，所以没有动量，也不受引力。"
$m = 0$ 只意味着 $E = pc$：光子带着实打实的动量（太阳帆、光镊都靠它），在引力场里也会偏折（1919 年的日食观测）。它的"没有质量"是"没有静止质量"——光子从不停下来，静止质量对它本就是个没定义的概念。

::::

## 6. 练习

**练习 1**：一个电子以 $\beta = 0.99$ 飞行，求它的**总能量**（焦耳，两位有效数字的科学计数法）。初始代码只算了静止能：

```exercise
# @title: 练习：高速电子的总能量
# @check: 5.80e-13
# @hint: 总能量是 E = γmc²，不是 mc²。γ = 1/√(1−0.99²) ≈ 7.0888，把它乘到 mc² = 8.1871×10⁻¹⁴ J 上。输出用 f"{E:.2e}" 就是两位有效数字。
c = 299792458.0            # 光速（m/s）
m = 9.1093837015e-31       # 电子质量（kg）
beta = 0.99                # 电子的速度（以 c 为单位）
E = m * c ** 2             # ← 只算了静止能量，运动的电子总能量还要乘 γ
print(f"{E:.2e}")
```

初始代码输出 `8.19e-14`——那是电子静止时的能量（0.511 MeV）。补上 $\gamma$ 之后是 `5.80e-13` 焦耳，对应 $3.62$ MeV。顺便可以算 $K = E - mc^{2} = 3.11$ MeV，这就是加速器真正要"喂"给电子的能量。

**练习 2**：回答三问：(a) 质子（$mc^{2} = 938$ MeV）总能量为 9380 MeV 时，$\gamma$ 是多少？(b) 它的速度有多接近光速？(c) 静止质量 0 的光子，动量与能量什么关系？

<details>
<summary>点开逐步解答</summary>

1. (a) $E = \gamma mc^{2}$，所以 $\gamma = 9380/938 = 10$；
2. (b) $\gamma = 10$ 给出 $1-\beta^{2} = 0.01$，$\beta = \sqrt{0.99} = 0.99499$——已经"只差 0.5%"；
3. (c) $m = 0$ 时色散关系退化成 $E = pc$。太阳帆每吸收 1 焦耳的光，就获得 $1/c \approx 3.3\times10^{-9}$ kg·m/s 的动量——很小，但真空中没有阻力，长期累积有效。

**工程视角**：加速器用"每核子多少 GeV"给束流标能量，本质就是在报 $\gamma$。LHC 的质子束 $\gamma \approx 7000$，$\beta$ 与 1 的差只有 $10^{-8}$ 量级——所以束流管里所有粒子的**快度**都很大，而速度全都几乎一样，这正是同步加速器能把它们约束在同一条轨道上的原因。

</details>

## 7. 选读：为什么对撞机比固定靶厉害

<details>
<summary>选读 · 质心动能与"撞出来的新质量"</summary>

拿一束高能质子去轰一块静止的靶，靶里能产生的新粒子质量，取决于**质心系里有多少可用能量**——因为总动量必须守恒，质心系不动，多余的能量才"自由"。

用四维动量算一笔账。束流质子能量 $E$、动量 $p$，靶质子静止（能量 $mc^{2}$）。系统的不变量是

$$s = \left(E + mc^{2}\right)^{2} - (pc)^{2} = 2mc^{2}E + 2(mc^{2})^{2}$$

（用了 $E^{2} - (pc)^{2} = (mc^{2})^{2}$。）质心系总能量 $\sqrt{s}$ 才是有用的那部分：

$$\sqrt{s} \approx \sqrt{2mc^{2}E}\quad(\text{高能极限})$$

**平方根**——这就是固定靶的代价：束流能量提高 100 倍，可用能量只提高 10 倍。而对撞机里两个质子迎面而来，总动量为零，$\sqrt{s} = 2E$，能量**线性**地全部可用。这就是为什么现代高能物理一律用对撞机：同样打出一个新粒子，固定靶要多花几十倍的电费。

顺带说一句：$\sqrt{s}$ 这个量就是不变量 $E^{2} - (pc)^{2}$ 开方——和本课练习里核对的那个组合是同一个东西。**散射振幅只依赖不变量**，这是粒子物理整个形式体系的起点，而它在数学上只是"闵可夫斯基几何里，量长度要用 $E$ 与 $p$ 而不是 $x$ 与 $t$"。

</details>
