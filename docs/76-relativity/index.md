# 狭义相对论与时空几何

把 22 章"动力系统"里那个绝对的时间轴拆掉，会发生什么？这一章只做一件事：**把时间当成一根坐标轴**。于是 21 章的线性变换变成洛伦兹变换，57 章的度量变成闵可夫斯基度规，而"守恒律"变成四维矢量的一条分量式。八门课走完，你会拥有解释 GPS、μ 子、类星体喷流与引力红移的同一套工具——它们全都从一句话长出来：**真空光速对一切惯性系都是 $c$**。

## 路线图

1. [光速不变：为什么"同时"是相对的](./10-light-speed-postulate.md)——两道闪电、一列火车：同时性的分裂，是整章唯一的"新物理"。
2. [洛伦兹变换：保光速的唯一线性变换](./20-lorentz-transform.md)——线性 + 光速不变，两条件钉死一族变换；时空网格被剪切。
3. [时间膨胀与长度收缩：μ 子为什么活得那么久](./30-time-dilation.md)——光钟的斜边就是 γ；2.2 微秒的 μ 子怎么穿过 10 公里大气。
4. [速度合成与快度：为什么追不上光](./40-velocity-addition.md)——速度不能加，快度可以；光速是一条渐近线，不是一堵墙。
5. [闵可夫斯基时空：把时间装进度量](./50-minkowski-interval.md)——$s^{2} = c^{2}\Delta t^{2} - \Delta x^{2}$：那个减号把因果变成几何。
6. [四维矢量与相对论动力学：E=mc² 的真身](./60-four-momentum.md)——能量与动量是同一个四维矢量的分量；质量是 $E^{2}-(pc)^{2}$ 的平方根。
7. [相对论多普勒与光行差](./70-doppler-aberration.md)——横向也红移；头灯效应与视超光速，两个可以互相印证的预言。
8. [等效原理与引力红移：广义相对论的门槛](./80-equivalence-principle.md)——电梯思想实验、引力钟速、以及 GPS 账本上那 38.5 微秒。

## 方法主线

**公设 → 变换 → 不变量 → 动力学 → 引力。**

前两课把地基打完：10 课从迈克尔逊–莫雷的零结果立起"光速不变"，并用两道闪电说明"同时"必须标明参考系；20 课用"线性 + 保光速 + 逆变换同形"把变换唯一地定成洛伦兹boost，顺带给出这一章的几何语言（网格剪切、光锥不动）。

中间三课是同一件事的三个投影：30 课的 $\gamma$ 是钟与尺的读数（时间维），40 课的 $\phi = \operatorname{artanh}\beta$ 是速度的正确"角度"（把非线性问题拉直），50 课的 $s^{2}$ 是唯一真正不变的量——它同时决定了"谁能影响谁"（因果）与"谁走得最慢"（固有时）。

最后三课把几何交给动力学与引力：60 课把能量、动量装进四维矢量，于是 $E=mc^{2}$ 只是 $p^{0}$ 在静止时的读数；70 课把四维矢量投影到观测方向，得到多普勒因子与头灯效应；80 课用等效原理跨进广义相对论的门槛，并用 GPS 的 38.5 微秒替整套公式结账。

一条贯穿全章的纪律：**每个结论都要能落到一个真实可检验的数字上**。$\beta = 0.6$ 就写 $\gamma = 1.25$，μ 子就写 19.03 公里，GPS 就写 $+45.72$ 与 $-7.21$。相对论最容易变成"哲学空谈"，防止它的唯一办法是把小数点算到底。

## 生产状态

本章八门课程全线成型，八个专属 lab 组件全部就绪（全部是纯 canvas 绘制，不依赖外部资源与数值引擎）：

- `rel-simultaneity` 可以拖列车速度、拖车尾那道闪电的时间，看两击先后翻转，并播放光信号追上观察者的过程；
- `rel-lorentz` 的时空图能拖事件点，两套网格同时给出 $(x, ct)$ 与 $(x', ct')$，还画出 $c^{2}t^{2}-x^{2}=\pm1$ 的标尺双曲线；
- `rel-muon` 左边是光钟的"竖直光程 vs 斜边"，右边是 μ 子从任意高度下落，红叉标出"不做时间膨胀会死在哪"；
- `rel-rapidity` 用三行对照（快度尺 / 首尾相接 / 速度尺）把"加法在这里成立、那里失效"摆在一起；
- `rel-lightcone` 拖事件点即时判定类时、类光、类空，并显示换观察者后 $\Delta t'$ 的翻转与 $s^{2}$ 的不动；
- `rel-collision` 拖两个速度把手做一维弹性碰撞，读数条同时列出 $\Sigma\gamma mu$、$\Sigma\gamma m$ 与"对不上"的 $\Sigma mu$；
- `rel-doppler` 拖着速度箭头绕光源转一圈，四条巴尔末线实时红移/蓝移，含横向多普勒；
- `rel-gravity-clock` 是高度 vs 钟速的双曲线图，引力项、速度项、净效应三条线，游标可拖。

## 实战挑战 · GPS 的 38 微秒

GPS 卫星在 $r = R_{\oplus} + 20200$ km 的圆轨道上。它的钟相对地面每天**快 38.51 微秒**——这是两个符号相反的效应相加的结果。下面这段代码只算了其中一个，把它补全，让输出变成 `38.51`：

```exercise
# @title: 实战挑战：GPS 钟每天快多少微秒
# @check: 38.51
# @hint: 缺的是引力项：gr = GM/c² × (1/RE − 1/r)，它让高处的钟变快。速度项已经有了（负号正确）。两项都以"每天多少微秒"为单位：先算出无量纲的 Δf/f，再乘 86400 秒、乘 1e6 换成微秒。
c = 299792458.0        # 光速（m/s）
GM = 3.986004418e14    # 地球的 GM（m³/s²）
RE = 6.371e6           # 地球半径（m）
r = RE + 20200e3       # GPS 卫星的地心距（m）

v2 = GM / r            # 圆轨道速度的平方
sr = -v2 / (2 * c**2)  # ← 只算了狭义相对论那一项（钟慢）
print(round(sr * 86400 * 1e6, 2))
```

初始代码输出 `-7.21`：它认为卫星钟每天**慢** 7.21 微秒。照这个数去做修正，误差不是"小一点"，而是方向都错了——真实的净效应是**快** 38.51 微秒，两者相差 45.72（正是被漏掉的引力项）。

<details>
<summary>点开查看逐步解答</summary>

1. **分清两个效应**。卫星钟与地面钟的速率差有两部分：卫星离地心远、引力势高，钟走得**快**；卫星以 3.87 km/s 绕地飞，钟走得**慢**。谁大谁小要算出来才知道。

2. **引力项（广义相对论）**。弱场公式是 $\Delta f/f = \frac{GM}{c^{2}}\left(\frac{1}{R_{\oplus}} - \frac{1}{r}\right)$。代入数字：

$$\frac{GM}{c^{2}} = \frac{3.986004418\times10^{14}}{(299792458)^{2}} = 4.435\times10^{-3}\ \text{m}$$

$$\frac{1}{R_{\oplus}} - \frac{1}{r} = \frac{1}{6.371\times10^{6}} - \frac{1}{2.6571\times10^{7}} = 1.5696\times10^{-7} - 3.7635\times10^{-8} = 1.1932\times10^{-7}\ \text{m}^{-1}$$

两者相乘得 $5.291\times10^{-10}$，乘上一天的秒数 $86400$ 与 $10^{6}$，得到 **$+45.72$ 微秒/天**。

3. **速度项（狭义相对论）**。圆轨道速度 $v = \sqrt{GM/r}$，时间膨胀是 $\frac{1}{2}\beta^{2}$ 的量级：

$$\frac{\Delta f}{f} = -\frac{v^{2}}{2c^{2}} = -\frac{GM}{2rc^{2}} = -8.349\times10^{-11}$$

乘同样的换算因子，得到 **$-7.21$ 微秒/天**（初始代码算的就是这一项）。

4. **相加**：$45.72 - 7.21 = $ **$+38.51$ 微秒/天**。卫星钟快。接收机必须从卫星时标里减掉这 38.51 微秒，否则 $38.51\times10^{-6}\ \text{s} \times c = 11.55$ km 的定位误差每天累积。

5. **顺手看两件事**。其一，净效应写成一条公式：$\frac{GM}{c^{2}}\left(\frac{1}{R_{\oplus}} - \frac{3}{2r}\right)$，令它为零立刻得到 $r = \frac{3}{2}R_{\oplus}$——**3186 公里高度上两个效应精确对消**，你可以用 lab 里的游标验证。其二，为什么常说"38 微秒"而不是 38.51？因为 $R_{\oplus}$ 取的是平均半径 6371 km；改用赤道半径 6378 km 会得到 38.45。工程手册上写的 **38 微秒**就是它的通用简称。

</details>
