# 时间膨胀与长度收缩：μ 子为什么活得那么久

## 1. 从一个场景开始

宇宙线在 10~15 公里的高空撞出 μ 子。μ 子不稳定，静止时的平均寿命只有 **2.2 微秒**。

算一笔账：就算它以光速飞，$2.2\ \mu s \times c \approx 660$ 米——连一公里都不到，从 10 公里高空出发绝无可能活着落地。

但 1941 年罗西与霍尔的实验把计数器搬到山顶和海平面：**海平面的计数器照样收到大量 μ 子**。它不但活到了地面，数量还和理论预期对得上。这 15 倍的差距，就是这一课要还的账。

## 2. 直觉解释

先看一只"光钟"：两面镜子上下相对，一个光子在中间来回弹。光子从下镜到上镜、再回来，算**一 tick**。

- 钟不动时，光子走的是竖直的 $2D$，一 tick 用时 $2D/c$；
- 钟横向飞起来之后，在实验室看来，光子走的是**斜边**——镜子在它上行的这段时间里已经往右挪了一段。

光速不能变，路变长了，一 tick 就只能更久。用勾股定理就能算出放慢的倍数（下一课的 lab 会让你亲手拖这个三角形）。

关键在于：**这只钟不是特例**。任何周期过程——心跳、原子跃迁、μ 子的衰变——都可以当成一只钟。所以"运动的钟走得慢"不是某个机构的毛病，而是时间的通用性质。

μ 子那笔账于是有两种记法，两种都自洽：

- **实验室记法**：μ 子的钟走得慢，2.2 μs 被拉成 63.5 μs，于是一路飞了 19 公里；
- **μ 子记法**：我只活了 2.2 μs（自己的钟绝不会骗自己），但**迎面的 10 公里大气被压扁了**，只有 0.35 公里厚。

同一个物理事实，两套账本。到底哪本对？两本都对——这正是相对论最容易被误解的地方。

## 3. 正式定义

设物体以 $\beta = v/c$ 运动，$\gamma = 1/\sqrt{1-\beta^{2}}$：

$$\Delta t = \gamma\,\Delta \tau \quad(\text{时间膨胀}),\qquad L = \frac{L_0}{\gamma}\quad(\text{长度收缩})$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\Delta \tau$ | 固有时 | 跟着物体一起走的钟量到的间隔，**所有人里最短的那个** |
| $\Delta t$ | 坐标时 | 实验室系里两只同步的钟量到的间隔 |
| $L_0$ | 固有长度 | 物体静止时的长度（在它自己的系里量） |
| $L$ | 测量长度 | 实验室量到的长度，只在**运动方向上**收缩 |
| $\gamma$ | 洛伦兹因子 | $\ge 1$，是"慢了多少倍 / 短了多少倍"的同一个倍数 |

三条使用纪律，缺一条就会算错：

1. **固有时最长还是最短**：固有时是**最短**的。$\Delta t = \gamma \Delta \tau$ 里 $\gamma \ge 1$，所以运动的钟读数更小；
2. **收缩只发生在运动方向**：垂直方向的长度不变，所以球的"长度收缩"是压扁成椭球，不是整体缩小；
3. **测长度必须同时测两端**：$L = L_0/\gamma$ 的推导里，"同时"这一条会随参考系变——这也是为什么会出现"火车进隧道佯谬"这类题。

## 4. 分步例题

**例**：μ 子以 $\beta = 0.9994$ 从 10 km 高空竖直下落，固有寿命 $\tau = 2.2\ \mu s$。它能到地面吗？

1. **算因子**：$1 - \beta^{2} = 1 - 0.99880036 = 0.00119964$，$\gamma = 1/\sqrt{0.00119964} = 28.87$；
2. **实验室寿命**：$\Delta t = \gamma\tau = 28.87 \times 2.2\ \mu s = 63.52\ \mu s$；
3. **能走的距离**：$v\Delta t = 0.9994 \times 299792458 \times 63.52 \times 10^{-6} = 19.03$ km $\gt 10$ km，**到得了**（还有富余）；
4. **换个系核对**：在 μ 子看来，大气层以 $0.9994c$ 迎面扑来，厚度收缩成 $10/28.87 = 0.346$ km；而它自己只有 2.2 μs 可活，能走 $0.9994c \times 2.2\ \mu s = 0.659$ km。$0.659 \gt 0.346$，**同样到得了**；
5. **两套账对答案**：实验室算出来富余 $19.03 - 10 = 9.03$ km，μ 子算出来富余 $0.659 - 0.346 = 0.313$ km。两个富余量之比 $9.03/0.313 = 28.8$——正好是 $\gamma$。这就是"两套账本必须给出同一结论"的算术证明。

## 5. 动手实验

### 实验 1（lab）：光钟滴答与 μ 子下坠

```lab
{
  "type": "rel-muon",
  "title": "左边看光钟为什么慢，右边看 μ 子能不能落地",
  "beta": 0.6,
  "muonBeta": 0.9994,
  "h": 10
}
```

- 左栏：竖直虚线是"时钟自己看见的光程 $D$"，斜边是"实验室看见的光程 $\gamma D$"。光速不变，所以斜边越长、一 tick 越久。两根进度条同时跑：时钟自己走 1 格，实验室的时间已经过了 $\gamma$ 格；
- 把左侧 β 拖到 0.9：斜边几乎躺平，$\gamma = 2.29$，两条进度条差出一倍多；
- 右栏：红叉是"不做时间膨胀只能走 0.66 km"的位置，绿箭头是实际能走的 19.03 km。把 μ 子速度拖到 0.9（$\gamma = 2.29$）——绿箭头缩到 1.4 km 左右，**μ 子就死在大气层里了**；
- 点**播放**看它掉下去：注意两个钟的读数一直在分开。

### 实验 2（python）：一张"能不能落地"的速查表

```python
import math                     # math.sqrt 用来开平方

c = 299792458.0                 # 光速（m/s）
tau = 2.2e-6                    # μ 子的固有寿命（s）
h = 10.0e3                      # 生成高度（m）

print("  β        γ      实验室寿命(μs)   能走(km)  到地面？")
for beta in [0.9, 0.99, 0.999, 0.9994, 0.9999]:
    gamma = 1 / math.sqrt(1 - beta ** 2)   # 洛伦兹因子
    life = gamma * tau                     # 实验室里看到的寿命
    d = beta * c * life / 1000             # 这段时间能飞多远（km）
    ok = "是" if d >= h / 1000 else "否"     # 够不够飞完 10 km
    print(f"{beta:<8.4f} {gamma:8.2f} {life * 1e6:13.2f} {d:11.2f}  {ok}")
```

五行里藏着两件事。第一，**γ 对 β 极其敏感**：0.9 到 0.9999 只差 0.0999，γ 却从 2.29 涨到 70.71——想在相对论里"再快一点"，代价是能量的指数级上涨。第二，**0.99 以下全都到不了地面**（$\gamma = 7.09$ 只够走 4.63 km）。自然界替我们选了 0.999 以上的 μ 子来做这个实验，所以海平面的计数器才有信号。

### 快问快答

```quiz
μ 子以 0.9994c 从 10 km 高空落下。在 μ 子自己的参考系里，它为什么也能到达地面？
- 因为 μ 子自己的寿命变长了
- 因为大气层的厚度收缩到了约 0.35 km [*]
- 因为光速在 μ 子系里更快
? 固有时是最短的：μ 子只活 2.2 μs，是迎面而来的大气被压扁了 28.87 倍。
```

::::warning[常见误区]

**误区一**："运动的钟真的坏了/慢了，是物理损伤。"
钟自己一切正常，它量到的固有时最短也最"真"——$\Delta \tau$ 是不变量。慢的是**别人看它**的读数。"运动的钟走得慢"这句话里，"运动"和"慢"都相对于某个观察者，缺了参照就没意义。

**误区二**："长度收缩说明物体被压扁了，受力了。"
没有任何力。收缩是"同时"的相对性带来的测量规则：量长度必须同时读两端，而"同时"在两系里不是同一件事。μ 子从来没觉得大气被压扁过——它只知道大气冲过来时**短**，这就是测量结果。

**误区三**："既然双方都觉得对方的钟慢，那不是矛盾了吗？"
不矛盾。两个人要"对表"，必须各自把两只异地钟同步好，而同步规则依赖参考系——这正是"同时"相对性的直接后果。谁真的掉头回来、谁经历了加速，谁就年轻（双生子佯谬，见选读）。要让两只钟在同一地点直接比对读数，只有一个答案。

::::

## 6. 练习

**练习 1**：μ 子以 $\beta = 0.9994$ 飞行，用它的固有寿命 $2.2\ \mu s$ 算出实验室里能飞多远（公里，保留两位）。初始代码忘了 $\gamma$：

```exercise
# @title: 练习：μ 子能飞多远
# @check: 19.03
# @hint: 实验室寿命是 γτ，不是 τ。先算 γ = 1/√(1−0.9994²) ≈ 28.87，再乘到寿命上；最后别忘了乘 β 换算成实际飞过的距离。
c = 299792458.0        # 光速（m/s）
tau = 2.2e-6           # μ 子的固有寿命（s）
beta = 0.9994          # μ 子的速度（以 c 为单位）

life = tau             # ← 少了 γ：实验室里看到的寿命更长
print(round(beta * c * life / 1000, 2))
```

初始代码输出 `0.66`——它算出 μ 子只能走 660 米，于是"海平面不该有 μ 子"。补上 $\gamma$ 之后是 `19.03` 公里，比 10 公里的大气层还富余一倍，实验与理论立刻对上了。

**练习 2**：回答三问：(a) 一艘飞船以 $0.8c$ 飞过，地面观测者说飞船上的 1 秒等于地面的几秒？(b) 飞船上的宇航员量自己的飞船长 100 m，地面观测者量到多少？(c) 垂直方向的宽度会变吗？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $\gamma = 1/\sqrt{1-0.64} = 1/0.6 = 1.667$，飞船上的 1 秒 = 地面的 $1.667$ 秒（$\Delta t = \gamma \Delta \tau$）；
2. (b) $L = L_0/\gamma = 100/1.667 = 60$ **米**——只有沿运动方向的那一维收缩；
3. (c) 不变。收缩只作用在运动方向上，所以飞船看起来是被"压扁"，不是整体缩小。

**工程视角**：加速器里的粒子寿命被 $\gamma$ 拉长，这正是束流能绕环几百万圈的原因（否则束流在出弯前就衰变光了）。同步辐射光源、质子治疗设备的时序设计，都要把 $\gamma$ 写进寿命预算。

</details>

## 7. 选读：双生子佯谬与"固有时是路径长度"

<details>
<summary>选读 · 为什么回来的人更年轻：时空里的"三角形两边之和"是反的</summary>

哥哥坐飞船以 $0.8c$ 出门 4 光年再回来，弟弟在家等。谁年轻？

答案：**哥哥年轻**。用欧几里得几何类比最容易看清。在平面几何里，折线比直线长；但在闵可夫斯基时空里，**折线的固有时比直线短**——因为固有时是

$$\Delta \tau = \int \sqrt{1 - \beta(t)^{2}}\ dt$$

被积函数永远 $\le 1$，而且只在 $\beta = 0$ 时取等号。弟弟一路 $\beta = 0$，所以他经历的固有时**最长**；哥哥只要动过，就必然更短。

于是"双生子佯谬"根本不是佯谬：两人的处境**不对称**（一个掉头加速过，一个没有），所以结论不必对称。用数字核对：设单程 4 光年、速度 $0.8c$（$\gamma = 1.667$）。弟弟在自己家里量：往返 8 光年，除以 $0.8c$，共 **10 年**；哥哥的固有时是 $10/\gamma = $ **6 年**。出发时两人都 24 岁，重逢时哥哥 30 岁、弟弟 34 岁。

那"双方都看对方慢"怎么解释？因为哥哥在掉头的那一刻换了惯性系，"同时面"猛地扫过一大片——那一段跳变吃掉了差额。谁真正经历了加速，谁就欠下这笔账，物理上没有含糊。

</details>
