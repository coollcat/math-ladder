# 最大公约数与欧几里得算法

## 1. 从一个场景开始

给你一块 **21 米 × 15 米**的地板，要求用**正方形**地砖正好铺满——不许切割、不留缝隙。砖的边长取多少，才能用上"最大的正方形砖"？

边长必须同时量尽 21 和 15：取 5？21 ÷ 5 除不尽。取 3？两方向都正好。答案 3 米——但凭什么没有更大的？要是地板变成 123456789 × 987654321 厘米呢？

这个问题背后的数叫**最大公约数**（gcd），而回答"大数怎么办"的那条两千三百年前的算法，至今仍在每台计算机里奔跑。

## 2. 直觉解释

一个数的**因子**是能整除它的数（第 20 课的老朋友）。两个数各自的因子队伍里，**同时出现在两队**的那些叫**公因子**，其中最大的那个就是最大公约数。

换一副图像：因子是一把"量尺"，能整除就是"用这把尺子刚好量尽"。找公约数，就是在给 48 和 36 找一把**共同量尺**；找最大公约数，就是找**最长的那把共同尺子**。

铺地砖问题立刻翻译过来：正方形砖边长 $s$ 要恰好铺满 $a \times b$ 的矩形 ⟺ $s$ 同时整除 $a$ 和 $b$ ⟺ $s$ 是公因子。"最大的正方形砖"= 最长共同尺子 = gcd。

## 3. 正式定义

设整数 $a, b$ 不全为零。把 $a$ 与 $b$ 的所有公共因子中最大的那个记作

$$\gcd(a, b)$$

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $\gcd(a,b)$ | 最大公约数 | 公共因子队伍里的冠军 |
| $(a,b)=1$ | 互质（互素） | 公共因子只剩 1，如 $\gcd(8,15)=1$ |
| $\gcd(a,0)$ | 特例 | 规定等于 $a$ 本身 |

两条马上要用的性质：

1. 约分一步到位：$\dfrac{a}{b} = \dfrac{a \div g}{b \div g}$，其中 $g=\gcd(a,b)$，结果必为最简分数；
2. 边界约定 $\gcd(a, 0) = a$：$a$ 的每个因子都整除 0，公共因子就是 $a$ 自己的全部因子。

## 4. 分步例题

**例 1（笨办法）**：求 $\gcd(48, 36)$。

1. 列出 48 的因子：1, 2, 3, 4, 6, 8, 12, 16, 24, 48；
2. 列出 36 的因子：1, 2, 3, 4, 6, 9, 12, 18, 36；
3. 圈出两列都有的：1, 2, 3, 4, 6, 12；
4. 冠军是 **12**。顺手约分：$\frac{48}{36} = \frac{4}{3}$。

数字小还好，数字一大这招就跪了——下面请出主角。

**例 2（欧几里得的跳步）**：还是 $\gcd(48, 36)$。

1. 用 36 去除 48，余 12：$48 = 1 \times 36 + 12$；
2. 关键一跃：$\gcd(48,36) = \gcd(36,12)$——理由见选读，先信着用；
3. 继续：$36 \div 12$ 整除，$36 = 3 \times 12 + 0$，于是 $\gcd(36,12) = \gcd(12, 0)$;
4. 撞上边界：$\gcd(12, 0) = 12$。**完毕，答案 12**，全程没列过一张因子清单。


怎么玩：点「铺一块」，21×15 的矩形里会先塞进尽可能多的 15×15 大方块；剩下一块红虚线框出的窄条（15×6），算法立刻转身在窄条里继续塞 6×6……每一层换一种颜色。铺满的一刻显示 gcd = 3——开场那块地板，答案就是它。再试 `a=34, b=22` 或 `a=35, b=28`，观察"余数变除数"的每一次转身。

### 实验 2（python）：先把笨办法跑通

```python title="暴力枚举：把公约数全点一遍名"
def brute_gcd(big, small):         # 参数约定：big 放较大的数，small 放较小的
    best = 1                       # 公约数至少有 1，从它起步兜底
    for d in range(2, small + 1):  # 公约数不会超过较小者，试到这里就够
        if big % d == 0 and small % d == 0:
            # and：两边条件都成立才算命中——d 必须同时整除两个数
            best = d               # d 越试越大，最后记下的一定是冠军
    return best

print(brute_gcd(48, 36))
```

能跑，但想象参数换成十位大数：循环要转几十亿次。该欧几里得上场了。

### 实验 3（python）：手写两千三百年的老算法

```python title="欧几里得辗转相除"
def euclid_gcd(a, b):
    # 终止保证：每轮新的 b 是上一轮的余数，严格小于旧 b 且不为负，
    # 所以 b 一轮比一轮小，迟早减到 0——绝不会死循环
    while b != 0:
        q, r = divmod(a, b)        # divmod（上一课出生）：商和余数一次拿全
        print(f"{a} = {q} × {b} + {r}")
        a, b = b, r                # 同步换新：被除数←旧除数，除数←余数
        # ↑ 两个变量一起赋值，右边先用旧值算完再同时落位
    return a                       # 除数归零时，被除数就是 gcd

print(euclid_gcd(48, 36))
print(euclid_gcd(21, 15))
```

对照实验 1 的动画：代码里的每一行 `print` 正对应动画里"换一层颜色"的那次转身。数字缩水极快——哪怕一百位的数，也只要几百步。

### 实验 4（python）：math.gcd 出生证明

你刚手写的函数连 Python 官方都觉得好用，干脆收编进了标准库——这就是 **math.gcd** 的出生证明：一行顶二十行：

```python title="math.gcd：官方版"
import math

print(math.gcd(48, 36))                 # math.gcd(a, b)：现成的最大公约数
print(math.gcd(123456789, 987654321))   # 十位大数照样一瞬——试试暴力法要多久
print(math.gcd(8, 15))                  # 结果 1：这对数互质
```

从此写课程序一律用 `math.gcd`；理解它为什么对，靠的是你亲手写过的实验 3。

### 快问快答

```quiz
17 和 28 的最大公约数是多少？
- 17
- 4
- 1 [*]
? 17 是素数且不整除 28，公共因子只剩 1——这样的两数叫"互质"，两课之后解同余方程时它是关键角色。
```

:::warning[常见误区]

**误区一**："你以为 gcd(0, n) 没有定义，或者干脆等于 0。" 数学约定 $\gcd(0, n) = n$：n 的全部因子都整除 0，所以公共因子就是 n 的因子全体，冠军是 n。它不是例外，而是定义的一部分——欧几里得算法正是踩着这个边界自然停机的。

**误区二**："你以为必须先保证 a 比 b 大才能开始辗转相除。" 不用。若 a < b，第一步 $a \bmod b = a$，一轮之后自动完成交换——算法自带整理功能。

**误区三**："你以为余数变成 0 时答案是那个 0。" 恰恰相反——**答案是余数为零那一步的除数**。盯着递推链看：$\gcd(36, 12) \to \gcd(12, 0)$，最后活下来的非零数才是冠军。

:::

## 6. 练习

**练习 1（判题）**：用枚举法求 $\gcd(48, 36)$，输出整数：

```exercise
# @title: 练习：求 gcd(48, 36)
# @check: 12
# @hint: "or"太宽容——d 只要整除其中一个就被记下来了；两个条件都得满足，该换成哪个词？
a = 48
b = 36
best = 0
for d in range(1, a + 1):
    if a % d == 0 or b % d == 0:   # ← 这个逻辑词不对劲
        best = d
print(best)
```

初始代码输出 48——因为 48 整除它自己，单边条件就让它蒙混过关了。修好逻辑词后，只有真正的公约数才能登记入册。

**练习 2**：把分数 $\frac{84}{126}$ 约到最简。（提示：先求分子分母的 gcd）

<details>
<summary>点开查看逐步解答</summary>

$\gcd(84, 126)$：$126 = 1\times84+42$；$84 = 2\times42+0$ → gcd = 42。

分子分母同除 42：$\frac{84}{126} = \frac{2}{3}$。验证：2 与 3 互质 ✓。
</details>

**练习 3**：8 和 15 都是合数，它们互质吗？$\gcd(0, 7)$ 又是多少？

<details>
<summary>点开查看逐步解答</summary>

8 的因子 {1,2,4,8}，15 的因子 {1,3,5,15}，交集只有 {1} → $\gcd(8,15)=1$，**互质**——互质只看公共因子，不看双方素不素。

$\gcd(0,7) = 7$：按边界约定直接取非零的那个数。
</details>

## 7. 选读：为什么 gcd(a,b) = gcd(b, a mod b)

<details>
<summary>选读 · 一次"因子搬家"论证</summary>

记 $r = a \bmod b$，即存在整数 $q$ 使 $a = qb + r$，也就是 $r = a - qb$。

任取整数 $d$：

- 若 $d$ 同时整除 $a$ 和 $b$，则 $d$ 整除线性组合 $a - qb = r$；
- 反之若 $d$ 同时整除 $b$ 和 $r$，则 $d$ 整除 $qb + r = a$。

所以"$a,b$ 的公因子集合"与"$b,r$ 的公因子集合"**完全相同**——集合相同，最大的成员当然相同。递推链一路缩小，最终落到 $\gcd(g, 0) = g$ 收工。

顺带一提最坏情形：数学家拉梅证明，当输入是相邻的斐波那契数时步数最多，且步数与数字的位数成正比——这就是它能扛住百位大数的底气。另外，把这份递推倒着展开还能解出 $x, y$ 使 $ax + by = \gcd(a,b)$（扩展欧几里得算法），它是密码学 RSA 里"模逆元"的发动机，本站点到为止。

</details>
