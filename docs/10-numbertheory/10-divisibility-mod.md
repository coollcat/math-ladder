# 整除、余数与模运算

## 1. 从一个场景开始

今天是星期三。**100 天后是星期几？**

一天一天数要数到明年。聪明人的算法是：$100 \div 7 = 14$ 余 $2$——每过整周星期几不变，多出来的 2 天才是关键，周三加两天，星期五。搞定。

你看，这里根本没人在意商是 14。**真正的主角是被丢掉的余数**。这一课我们正式研究它："整除"意味着什么、余数怎么定义，以及为什么说挂钟是一台余数机器。

## 2. 直觉解释

看家里的挂钟：钟面只有 12 格。13 点的时候时针并不指"13"——根本没有这个格子，它绕回了 1。25 点同样指 1。**钟面把一切相差 12 的倍数的时刻折叠成了同一格。**

这就是**模运算**的世界观：数字不再排成一条无限长的直线，而是首尾相接排成一个圆圈。走 $m$ 步回到原地，于是"转了几圈"不重要，"落在哪一格"才重要。

第 1 章《除法与余数》已经给过带余除法：$a = q \cdot m + r$。现在换个眼光重看它——商 $q$ 是转的整圈数，余数 $r$ 就是圆盘上的落点。

## 3. 正式定义

**整除**：设 $a$ 是整数、$m$ 是正整数。若存在整数 $q$ 使

$$a = q \cdot m$$

则称 **$m$ 整除 $a$**，记作 $m \mid a$。此时 $a$ 是 $m$ 的**倍数**，$m$ 是 $a$ 的**因子**。整除就是"余数为 0"。

**取余（模运算）**：由第 1 章的带余除法，每个整数 $a$ 都能写成

$$a = q \cdot m + r, \qquad 0 \le r < m$$

且这种写法**唯一**。把这个唯一的余数记作 $a \bmod m$：

$$a \bmod m := r$$

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $m \mid a$ | $m$ 整除 $a$ | 余数为零，如 $7 \mid 91$ |
| $m \nmid a$ | $m$ 不整除 $a$ | 如 $7 \nmid 90$（余 6） |
| $a \bmod m$ | 取余 | $a$ 在 $m$ 格圆盘上的落点，范围 $0 \le r < m$ |
| $q$ | 商 | 转过的整圈数 |

两条马上要用的推论：

1. $m \mid a$ 当且仅当 $a \bmod m = 0$；
2. 多转整圈不改变落点：$(a + km) \bmod m = a \bmod m$——这正是"100 天后星期几"能秒算的原因。

## 4. 分步例题

**例 1**：$7$ 整除 $91$ 吗？

1. 试除：$91 \div 7 = 13$，恰好除尽；
2. 验收：$91 = 7 \times 13 + 0$，余数为 0；
3. 结论：$7 \mid 91$ 成立。

**例 2**：求 $100 \bmod 7$，并回答开场的问题。

1. 找贴着 100 不超的 $7$ 的倍数：$7 \times 14 = 98$（下一个 $105$ 就超了）；
2. 余数 $= 100 - 98 = 2$，即 $100 \bmod 7 = 2$；
3. 回答问题：周三加 2 天 = **星期五**。

**例 3**：$109 \bmod 12$？（钟面问题）

1. $12 \times 9 = 108$，贴着 109 不超；
2. 余数 $= 1$。过了 109 小时，钟面指着 1 点。

## 5. 动手实验

### 实验 1（viz）：会转圈的余数机器

```viz
{
  "type": "clockmod",
  "m": 12
}
```

怎么玩：右侧实时显示分解式 $n = q \times m + r$。先把滑杆 k 拧到 5，连按几下「+k 步」，盯住高亮的落点扇区——落点只跟总步数除以 12 的**余数**有关；再把滑杆 m 拧到 7，同一个按钮立刻变身"星期机"。一块圆盘，装下了本章的全部内容。

### 实验 2（python）：钟面上的加法

```python title="钟表只认余数"
hour = 9                    # 现在 9 点
later = 5                   # 过 5 小时
# % 是取余运算符：a % b 就是 a 除以 b 的余数（第 1 章露过面，今天正式上岗）
print((hour + later) % 12)

big = 100                   # 过 100 小时也一样算
print((hour + big) % 12)
```

不管加多大的数，结果永远落在 0 到 11 之间——**模运算自带"防溢出"结界**，数字再大也逃不出这 12 个格子。

### 实验 3（python）：divmod 的出生证明

需求先行：23 颗糖分给 4 个人，既想知道每人几颗、又想知道剩几颗——商和余数**一次全要**。以前得敲两遍：

```python title="商和余数，为什么要拿两次"
print(23 // 4)   # // 整除取商：每人分到几颗
print(23 % 4)    # % 取余数：最后剩几颗
```

这两个数明明出自同一个除法，却要分开问两次。于是 Python 把它们打包成了内置函数 **divmod**（division + modulo 的合成词）——想要"商和余数一起来"，就是它的出生证明：

```python title="divmod：一行拿全一对数"
result = divmod(23, 4)   # divmod(a, b)：同时返回 a÷b 的商和余数
print(result)            # 返回的是打包好的两个值：(商, 余数)

q, r = result            # 解包：把包里的两个值分别交给 q 和 r
print(q)
print(r)

for a in [17, 38, 100]:      # 三组数验证恒等式 a = q*b + r
    q, r = divmod(a, 4)      # 每轮重新解包
    print(f"{a} = {q} * 4 + {r}")
```

以后凡是"分糖""报数""翻页"这类既要商又要余的场合，一行 `divmod` 就够。

### 实验 4（python）：负数也能取余吗

```python title="-7 除以 3，余几？"
print(-7 % 3)    # Python 的答案：2
print(7 % -3)    # 除数为负时：-2
```

Python 的约定：**余数的正负号跟着除数走**。因为 $-7 = 3 \times (-3) + 2$——商向更小的方向取整，好让余数稳稳落在 $0 \le r < 3$ 里。各家语言吵出的不同版本，见本节末尾的选读。

### 实验 5（python）：余数周期表——换个 m 看循环

```python title="余数周期表：0 到 35 各自的落点"
# sliders: m=7 [2:12:1]

row = ""                       # 空字符串：攒一整行落点的容器
for n in range(36):            # 让 n 从 0 跑到 35，逐个问落点
    row = row + f"{n % m} "    # 字符串也能用 + 拼接：把每个余数接到行尾
print(row)
```

怎么玩：默认 $m=7$，从左往右数——每 7 个数必然从头再来，$0\sim6$ 循环个没完，这就是"周期"。把滑杆拧到 12，同一张表立刻变回钟面；拧到 2，整个世界只剩两格（偶数格与奇数格）。再竖着找出所有写着同一个余数的位置——比如落点为 3 的那些 $3, 10, 17, 24, \ldots$——它们是"同一格家族"，这个关系本章后面的《同余》一课会正式命名。

### 快问快答

```quiz
钟面只有 12 格，那么 27 点在钟面上显示为几点？
- 27 点
- 3 点 [*]
- 9 点
? 27 = 2×12 + 3：转了两整圈后落在第 3 格，即 27 mod 12 = 3。
```

:::warning[常见误区]

**误区一**："你以为 mod 的结果一定是非负数。" 在 Python 里确实如此（除数为正时），但**数学记号本身没有强制**：有的教材允许写 $-7 \equiv -1 \pmod 3$，因为 $-1$ 和 $2$ 相差一个除数的倍数、指的是同一个落点。见到负"余数"先查该书的定义，别急着判错。

**误区二**："你以为整除就是把除法算出一个整数。" $7 \div 2 = 3.5$，这叫除不尽；整除专指**余数为零**，而且只在整数范围内谈论。另外别漏了 $0$ 这个特殊户：任何正整数都整除 $0$，因为 $0 = m \times 0$。

**误区三**："你以为余数可以等于甚至超过除数。" 把 $100 \bmod 7$ 算成 9？那还能再剥掉一圈 7。合法余数必须满足 $0 \le r < m$——这条不等式是你免费的验算器。

:::

## 6. 练习

**练习 1（判题）**：求 $17 \bmod 5$，输出那个整数：

```exercise
# @title: 练习：17 mod 5
# @check: 2
# @hint: 单斜杠 / 会得到小数 3.4；只想要"剩下的尾巴"，请改用取余运算符 %
print(17 / 5)
```

初始代码用了单斜杠 `/`，吐出来的是精确除法的商 3.4。换成取余运算符，让它只交出那个小于 5 的尾巴。

**练习 2**：现在是 9 点，过 100 小时后钟面指向几点？

<details>
<summary>点开查看逐步解答</summary>

$(9 + 100) \bmod 12 = 109 \bmod 12 = 1$，指向 **1 点**。

也可以拆开走：$100 \bmod 12 = 4$，先走 4 小时到 1 点；剩下的 96 小时恰好 8 整圈，对落点毫无贡献。
</details>

**练习 3**：在模 12 的世界里，不同的落点共有几种？哪些整数与 5 落在同一格？

<details>
<summary>点开查看逐步解答</summary>

落点只能取 $0, 1, 2, \ldots, 11$，共 **12 种**。与 5 同格的是所有形如 $5 + 12k$ 的整数：$\ldots, -19, -7, 5, 17, 29, \ldots$

"无穷多个整数折叠进 m 个格子"——这正是本章最后一课《同余》要正式命名的关系。
</details>

## 7. 选读：负数的余数，各语言吵了一架

<details>
<summary>选读 · -7 mod 3 到底是 2 还是 -1？</summary>

数学上两种答案**都对**，因为它们相差整整一个除数：$2 - (-1) = 3$。只有规定"余数非负"时带余除法的结果才唯一；一旦放开这条限制，同一个整数可以配上好几个合法余数。

各家的取舍：

| 语言 / 环境 | $-7 \bmod 3$ | 约定 |
| --- | --- | --- |
| Python | $2$ | 跟**除数**同号 |
| C / Java / JavaScript | $-1$ | 跟**被除数**同号 |
| 数学教材（多数） | $2$ | 规定余数非负 |

跨语言编程时这是经典暗坑；读别人的证明时，先翻一眼它的定义页。本站从头到尾采用 Python 约定：只要除数是正的，余数一定是 $0$ 到 $m-1$。

</details>
