# 同余与应用：一个记号走天下

## 1. 从一个场景开始

三个风马牛不相及的问题：

1. 今天周三，100 天后是星期几？
2. 怎么把一句悄悄话加密，让偷看的人一头雾水？
3. 一千万个用户名，怎么一步定位它存在哪个抽屉里？

答案居然是同一个：**别管数本身多大，只问它除以某个数的余数**。第 1 个问题除以 7，第 2 个除以 26，第 3 个除以抽屉个数。这一课给这个共同套路起正式的名字——**同余**——然后一口气把三个问题全部解决。

## 2. 直觉解释

第 1 课说过：钟面把相差 12 的倍数的时刻折叠成同一格。"落在同一格"，就是本课的核心关系。

$$13 \equiv 1 \pmod{12}$$

读作"13 与 1 模 12 同余"。注意它比相等宽容：13 和 1 是两个不同的数，但在钟面的世界里它们**无法区分**。

这套语言无处不在：

| 应用 | 钟面大小 | 在算什么 |
| --- | --- | --- |
| 星期 | 7 格 | 天数 ÷ 7 的余数 |
| 凯撒密码 | 26 格 | 字母位置 + 密钥后绕圈 |
| 哈希分桶 | 表长格 | 键值 ÷ 桶数的余数决定放哪格 |

学会同余记号，这三件事会变成同一道题的三种皮肤。

## 3. 正式定义

设 $m$ 是正整数。若 $m$ 整除 $a - b$，即

$$a - b = km \quad (k \text{ 为整数})$$

则称 **$a$ 与 $b$ 模 $m$ 同余**，记作

$$a \equiv b \pmod{m}$$

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $\equiv$ | 同余 | "同一落点"，弱于等号的亲戚 |
| $(\bmod\ m)$ | 模 m | 以 $m$ 为钟面大小；整行式子都要在这个背景下读 |
| $a \bmod m$ | 取余运算 | 落点编号 $0 \le r < m$（第 1 课的定义） |

三种说法完全等价，随时互相翻译：

$$a \equiv b \pmod m \iff m \mid (a-b) \iff a \bmod m = b \bmod m$$

同余最迷人的一点：**加减乘都能像等式一样直接搬运**。若 $a \equiv b$ 且 $c \equiv d$，则 $a+c \equiv b+d$、$a \times c \equiv b \times d$（模 $m$）。所以大数幂的尾数问题能一路化简——$2026^5$ 的个位等于 $6^5$ 的个位，因为 $2026 \equiv 6 \pmod{10}$。

## 4. 分步例题

**例 1**：今天周三，100 天后是星期几？（用同余语言重做一遍）

1. 给星期编号：周一 $=1, \ldots,$ 周六 $=6$，周日 $=0$；今天是 $3$；
2. 化简天数：$100 \equiv 2 \pmod 7$；
3. 搬运加法：$3 + 100 \equiv 3 + 2 = 5 \pmod 7$；
4. 编号 5 = **星期五**。与第 1 课的答案严丝合缝。

**例 2**：凯撒密码，密钥为 3，加密 "HI"。

1. 字母表当 26 格钟面并从 0 编号：H 是 7，I 是 8；
2. 各自前移 3 格再取落点：$(7+3) \bmod 26 = 10$，$(8+3)\bmod 26 = 11$；
3. 编号 10、11 对应 K、L——密文 **"KL"**。解密就是倒转 3 格，X、Y、Z 往回绕圈也不怕。

## 5. 动手实验

### 实验 1（viz）：把钟表调成 7 格，复现星期问题

```viz
{
  "type": "clockmod",
  "m": 7
}
```

怎么玩：这块 7 格圆盘就是一个星期，但注意本课编号 0 是周日、3 是周三。先点「归零」，把 k 拧到 1 连按几下，体会"过 7 步必回原点"；再归零，用 k=3 按一次送到周三，接着把 k 改成 5 按两次（累计走 13 步），落点是 6——周三加 10 天正是周六。右侧的 $n = q \times m + r$ 就是"天数折算"的现场直播。

### 实验 2（python）：星期计算器

```python title="任意 N 天后是星期几"
# 给星期编号：周一=1、周二=2 …… 周六=6、周日=0（取余后正好落进 0..6）
today = 3                        # 周三

for days in [1, 7, 30, 100]:     # 四种"几天后"
    future = (today + days) % 7  # 总天数折进 7 格圆盘，读出落点
    print(f"+{days} 天 → 编号 {future}")
```

+100 天输出编号 5——星期五，和手算一致。改 `today` 或往列表里塞任何天数，公式永远一行。

### 实验 3（python）：凯撒密码机——密钥拧成旋钮

例 2 的密钥写死为 3。现在把它升级成一根滑杆，加密机变成旋钮收音机：

```python title="字母表是一个 26 格钟面"
# sliders: shift=3 [1:25:1]

secret = ""                      # 空字符串：攒结果的容器

for ch in "hi":                  # 逐个字符处理
    pos = ord(ch) - ord("a")     # ord 把字符变编号；相减得到字母在表中的位置（a→0）
    new_pos = (pos + shift) % 26 # 移位后在 26 格圆盘上取落点——越过 Z 自动绕回 A
    secret = secret + chr(ord("a") + new_pos)   # chr 把编号变回字符，再拼接起来

print(secret)
```

"hi" 在密钥 3 下变成了 "kl"。想破译任何凯撒密文？把密文塞进循环里的引号，然后拖动滑杆从 1 扫到 25——哪一档读出人话，密钥就是几。古典密码在"暴力搜索"面前不堪一击，这正是现代密码学必须另起炉灶的原因。

### 实验 4（viz）：字母表圆盘，亲手拧一拧

```viz
{
  "type": "caesar",
  "k": 3,
  "text": "ATTACK AT DAWN"
}
```

怎么玩：输入框里随便打大写单词，密文实时刷新；滑杆就是密钥 $k$。下方两排字母条是"明文字母表 → 密文字母表"的同余对照：每个字母的落点都按 $(\text{位置} + k) \bmod 26$ 计算。把 $k$ 拧到 0，上下两排完全对齐——用同余的话说：**加密是平移，解密是往回平移**，26 格钟面转一圈回到原点。

### 实验 5（python）：哈希分桶——用户名该进哪个抽屉

开场第三个问题还没兑现：一千万个用户名怎么快速定位？最朴素的玩具哈希先把名字里的字母编号加起来，再取余决定抽屉：

```python title="取余决定抽屉"
# sliders: buckets=8 [3:12:1]

names = ["alice", "bob", "carol", "dave", "erin"]

for name in names:             # 复用凯撒机里的逐字符循环
    total = 0                  # 每个名字都从零开始累加字母编号
    for ch in name:
        total = total + ord(ch)   # ord 在实验 3 出生：字母变编号
    print(f"{name} → {total % buckets} 号抽屉")
```

默认 8 个抽屉时，`alice` 和 `erin` 都落到 6 号——这叫**碰撞**。真实哈希函数会用更讲究的混合办法减少碰撞，可最后一步仍然是“折进有限个格子”：`位置 % 表长`。这就是同余在计算机系统里的日常岗哨。

### 实验 6（python）：解一道一千七百年前的方程组

《孙子算经》问："今有物不知其数，三三数之剩二，五五数之剩三……问物几何？"我们也来一道同款——求最小的非负整数 $x$，使得

$$x \equiv 3 \pmod 7 \qquad \text{且} \qquad x \equiv 2 \pmod 5$$

```python title="暴力搜索：同时满足两个余数条件"
answer = None                    # None 表示"还没找到"的占位符

for x in range(35):              # 两模数互质时，答案必在 0..34 中（共 7×5 个候选）
    if x % 7 == 3 and x % 5 == 2:  # and：两条余数条件都满足才算命中
        answer = x              # 记下第一个命中的——它自然是最小的
        break                   # break：提前跳出循环，后面的候选不必再看

print(answer)
print(answer % 7)                # 验收第一条
print(answer % 5)                # 验收第二条
```

答案是 **17**：17 除以 7 余 3、除以 5 余 2，两头都对。为什么敢保证 35 以内必有解？见选读的中国剩余定理。

### 快问快答

```quiz
记号 a ≡ b (mod m) 的含义是什么？
- a 和 b 相等
- m 整除 a − b [*]
- m 整除 a + b
? 同余比的是"同一个落点"：a 与 b 相差 m 的整数倍，比如 13 ≡ 1 (mod 12)，但 13 ≠ 1。
```

:::warning[常见误区]

**误区一**："你以为同余就是相等。" $\equiv$ 比 $=$ 宽容得多：$13 \equiv 1 \pmod{12}$ 但 13 和 1 是两个数。同余世界里"加减乘"可以照搬等式的规则，但"比较大小""做除法"要格外小心。

**误区二**："你以为同余式两边可以随便约分。" $4 \equiv 16 \pmod{12}$，两边"除以 2"得到 $2 \equiv 8 \pmod{12}$？错——2 和 8 不同余！只有当除掉的数与模数**互质**时约分才安全（比如模 12 时除以 5）。这就是为什么互质概念如此重要。

**误区三**："你以为 $x \equiv 3 \pmod 7$ 只有唯一解。" 它有无穷多个解：$3, 10, 17, 24, \ldots$ 每 7 个数就来一个。只有先限定范围（比如"最小的非负解"或"模 35 内的唯一解"），"解"字才有明确的所指。

:::

## 6. 练习

**练习 1（判题）**：约定周一=1 …… 周六=6、周日=0。今天周四（编号 4），求 45 天后的星期编号：

```exercise
# @title: 练习：45 天后是星期几
# @check: 0
# @hint: 别直接相加——先把 45 折进一周（45 mod 7），加上今天的编号后如果超出 0..6，再对 7 取一次余
today = 4                    # 周四
print(today + 45)
```

初始代码输出 49——编号早就冲出了 0..6 的圆盘。用取余把它折回去。

<details>
<summary>点开查看逐步解答</summary>

```python
print((today + 45) % 7)      # (4 + 45) % 7 = 49 % 7 = 0
```

输出 `0`，也就是**周日**。$45 \bmod 7 = 3$，周四加 3 天恰好绕回原点。
</details>

**练习 2**：用实验 3 的思路手工加密 "attack"（密钥仍为 3），再用代码验收。

<details>
<summary>点开查看逐步解答</summary>

逐字移位：a→d，t→w，t→w，a→d，c→f，k→n，密文 **"dwwdfn"**。

验收代码只需把实验 3 里的 `"hi"` 改成 `"attack"` 再跑一遍。历史上凯撒真的用过移位 3——放在今天，一秒钟就能被穷举攻破。
</details>

**练习 3**：求最小的非负整数 $x$，满足 $x \equiv 2 \pmod 3$ 且 $x \equiv 3 \pmod 4$。

<details>
<summary>点开查看逐步解答</summary>

满足第一条的是 2, 5, 8, 11, 14, …；满足第二条的是 3, 7, 11, 15, …

两列里第一个撞车的是 **11**：$11 = 3\times3+2 = 2\times4+3$。由于 $3 \times 4 = 12$ 且 3、4 互质，它在 0 到 11 内还是唯一解——中国剩余定理的小型现场。
</details>

## 7. 选读：中国剩余定理一句话

<details>
<summary>选读 · 为什么 35 以内必有且仅有解</summary>

《孙子算经》的原题是三模数版："三三数之剩二，五五数之剩三，七七数之剩二，问物几何？"答案是 23。

定理的现代表述：设 $m, n$ **互质**，那么方程组 $x \equiv a \pmod m,\ x \equiv b \pmod n$ 在 $0 \le x < mn$ 范围内**恰有一个解**。

为什么？把 0 到 $mn-1$ 排成 $n$ 行 $m$ 列的表格：沿行走，余数按模 $m$ 循环；沿列走，余数按模 $n$ 循环。因为 $m, n$ 互质，转满一圈前两种余数不会重复出现——于是每一对余数组合 $(a, b)$ 都恰好被一个格子占据。格子总数 $mn$，组合总数也是 $mn$，一一对应，不多不少。

这也解释了暴力搜索为何敢在 `range(35)` 里收工：7 与 5 互质，解在 35 个候选中恰好出现一次。而当年韩信点兵式的"大衍求一术"，本质上是用扩展欧几里得算法（gcd 课选读埋的那颗种子）直接构造出这个解，不用一格一格搜。

</details>

## 8. 下一站

数论到此收官。回望这一章：我们从"除不尽"出发，造出余数机器，筛出乘法世界的原子，借两千三百岁的辗转相除拿到最大公约数，最后用一个同余记号打通了日历、密码与哈希。你已经体会到：单个数字内部竟藏着如此深的结构。

但从下一章起，舞台要换灯光了。信号是一万条采样，图像是几百万个像素——一次只摆弄一个数的旧功夫不够使了。我们需要一门**成批处理对象**的数学：让数排成队（向量）、让变换打包执行（矩阵）、让"换一套基"变成一次乘法。这门语言叫线性代数，它是傅里叶变换登台前的最后一层台阶——在那里你会看到，"把信号拆成正弦波之和"其实只是"换了个坐标系"。
