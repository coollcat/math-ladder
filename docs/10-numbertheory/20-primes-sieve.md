# 素数与筛法

## 1. 从一个场景开始

化学家有元素周期表：花花世界的物质，拆到底全是 118 种元素的组合。数学家也有自己的周期表——**所有大于 1 的整数，拆到底全是一批"拆不动"的数的连乘**。

这批拆不动的数叫**素数**。它们有多少个？怎么成批把它们抓出来？两千多年前，希腊人埃拉托斯特尼发明了一把筛子，今天你可以在下面亲手摇一摇它。

## 2. 直觉解释

先看分类。拿"因子个数"当标尺给正整数分三类：

- **1**：只有 1 个因子（它自己）；
- **素数**（如 7）：恰好 2 个因子——1 和它自己，谁也插不进来；
- **合数**（如 12）：因子更多——$12 = 2 \times 2 \times 3$，能被拆开。

素数是**乘法世界的原子**：合数是化合物，总能分解成素数的乘积，而素数本身再无更小的乘法零件。

怎么成批找出原子？别一个一个考试，换个思路——**让已知的素数亲自动手**：2 出列，把它所有的倍数全部划掉；3 出列，划掉它的倍数……每一轮幸存的下一个人必然是新的素数（不然它的某个真因子早该把它划掉了）。这就是**筛法**。

## 3. 正式定义

设 $p$ 是大于 1 的整数。

- 若 $p$ 的因子恰有两个（$1$ 和 $p$ 本身），称 $p$ 为**素数**（质数）；
- 若 $p$ 大于 1 且不是素数，称 $p$ 为**合数**；
- **1 既不是素数也不是合数**。

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $p$ | 素数 | 恰有两个因子的数，如 $2, 3, 5, 7$ |
| $\pi(n)$ | 素数计数函数 | 不超过 $n$ 的素数个数，如 $\pi(10) = 4$ |
| $\sqrt{n}$ | 平方根 | 试除法的终点线（理由见第 4 节） |

为什么把 1 开除出素数队伍？因为素数要担当"唯一积木"的角色：若 1 算素数，$6 = 2 \times 3 = 1 \times 2 \times 3 = 1 \times 1 \times \cdots \times 2 \times 3$，分解方式就不唯一了。开除 1，才保住那条黄金定律——**每个大于 1 的整数都能恰好分解成一组素数的乘积**（算术基本定理）。

## 4. 分步例题

**例 1**：判断 91 是不是素数。

1. 找终点线：$\sqrt{91} \approx 9.5$，只需试除 2 到 9；
2. 依次试：不是 2 的倍数（奇）；各位数字和 $9+1=10$ 不是 3 的倍数；末位不是 0/5；
3. 试到 7：$91 = 7 \times 13$——抓到因子！**91 是合数**。（这个数长得极像素数，坑过无数人）

**例 2**：判断 97。

1. $\sqrt{97} \approx 9.8$，试除 2 到 9；
2. 奇数 ✓；数字和 $16$ 不被 3 整除 ✓；末位不是 0/5 ✓；$97 = 7\times13 + 6$、$97 = 8\times12+1$ 都有余 ✓；
3. 全部通过——**97 是素数**。

**例 3**：凭什么试到 $\sqrt{n}$ 就可以收工？

若 $n = d \times e$ 且 $d \le e$，则必有 $d \le \sqrt{n}$（否则两边都大于 $\sqrt{n}$，乘积就超过 $n$ 了）。也就是说**因子总是成对出现，较小的一只必然不超过平方根**——抓住小的那只，大的自动招供。91 的例子里，小因子 7 一露头，大因子 13 无需再找。

## 5. 动手实验

### 实验 1（viz）：亲手摇两千年前的筛子

```viz
{
  "type": "sieve"
}
```

怎么玩：点「单步」，2 号格变绿（它是素数），紧接着它的所有倍数被划线涂灰；再点一步，3 号格变绿、倍数尽灭……注意从 5 开始，划掉的格子明显稀疏了——因为 4、6 这些"半成品"早已阵亡。注意划线动作到 7 就到头了：任何 ≤100 的合数都含一个 ≤√100=10 的素因子，早被 2、3、5、7 代劳划掉。之后「单步」只剩一件事——把幸存的素数逐个翻绿，一直翻到 97。按「自动」看完整场大清洗。

### 实验 2（python）：先数因子，认识"两个因子"俱乐部

```python title="数一数每个数的因子个数"
def count_factors(n):          # def 定义函数：传入 n，返回它的因子个数
    count = 0
    for d in range(1, n + 1):  # 从 1 一路试到 n 本身
        if n % d == 0:         # % 取余：余 0 说明 d 整除 n，是个因子
            count = count + 1
    return count               # 把统计结果交回去

for n in [12, 17, 97]:
    print(n, count_factors(n))
```

17 和 97 的因子个数都是 2——它们就是素数。但逐个试除太费劲，接下来升级装备。

### 实验 3（python）：试除法判素 + 清点 100 以内的原子

```python title="试除法判素数：只查到平方根就停"
import math

def is_prime(n):               # 判素函数：返回 True 或 False
    if n < 2:
        return False           # 0 和 1 直接出局
    for d in range(2, math.floor(math.sqrt(n)) + 1):
        # math.sqrt 开平方；math.floor 向下取整；+1 让终点自己也被查到
        if n % d == 0:
            return False       # 抓到一个因子就宣判，立刻收工
    return True                # 全试完没发现因子，才是真素数

print(is_prime(91))
print(is_prime(97))
```

对照例题：91 被当场识破，97 通过审查。现在用它清点 100 以内全部素数：

```python title="π(100)：100 以内有几个素数"
import math

def is_prime(n):
    if n < 2:
        return False
    for d in range(2, math.floor(math.sqrt(n)) + 1):
        if n % d == 0:
            return False
    return True

primes = []                    # 幸存者名单
count = 0                      # 计数器
for n in range(2, 101):        # 从 2 到 100 逐个审问
    if is_prime(n):
        primes.append(n)       # append：把素数收进名单
        count = count + 1

print(count)
print(primes)
```

答案是 **25 个**——$\pi(100) = 25$。盯一眼名单：开头很挤（10 以内就有 4 个），越往后越稀疏，但永远数不完（选读部分给出欧几里得的漂亮证明）。

### 实验 4（python）：亲眼看因子成对出场

例 3 说"因子总是成对出现，小的那只不超过 $\sqrt{n}$"。拖动滑杆验一验：

```python title="因子配对清单：d × e = n"
import math

# sliders: n=91 [3:999:2]

print(f"{n} 的因子配对清单：")
for d in range(1, math.floor(math.sqrt(n)) + 1):
    # 只扫到 √n：小因子必在这一段，大因子靠除法自动招供
    if n % d == 0:
        print(f"{d} × {n // d} = {n}")   # // 整除取商：d 的搭档 e
```

怎么玩：`n=91` 吐出两对——$1\times91$、$7\times13$，小因子 7 一露头，13 自动现形；换 `n=97` 只剩孤零零的 $1\times97$，这正是素数的标志（除 1 和自己外凑不出第二对）；再试 `n=945`，配对一口气冒出一长串。注意滑杆步长是 2：只逛奇数——偶数的因子清单太长，会刷屏。

### 快问快答

```quiz
用试除法判断 n 是否素数，最多试除到多大就可以停？
- n 减 1
- n 除以 2
- 根号 n [*]
? 因子总是成对出现（d 配 e），较小的一只必然不超过根号 n——抓小放大，事倍功半。
```

:::warning[常见误区]

**误区一**："你以为偶数都不是素数。" 只有 2 是例外——**唯一的偶素数**。写判素程序时若先一刀切掉所有偶数，记得单独放行 2，否则它会蒙冤。

**误区二**："你以为 1 是最小的素数。" 定义要求**恰好两个**因子，1 只有一个。而且一旦把 1 请回来，"分解方式唯一"立刻崩塌（见第 3 节）——这不是口味问题，是为了保住算术基本定理。

**误区三**："你以为素数分布毫无规律，人类只能瞎撞。" 单个素数在哪里确实任性，但整体密度有定理管着：**素数定理**说 $n$ 很大时 $\pi(n) \approx \frac{n}{\ln n}$——比如十亿附近，平均每约 21 个数里就藏着一个素数。混乱之中有秩序。

:::

第 9 章的概率线索在这里轻轻回头：若把“抽到一个整数”想成一次观察，素数定理给出的就是长期频率式的直觉——十亿附近大约每 21 次抽查遇到一个素数。但这只是估计分布；筛法仍然逐一确定地检查，不靠运气漏掉任何一个。

## 6. 练习

**练习 1（判题）**：判断 97 是否素数，输出 `True`：

```exercise
# @title: 练习：97 是素数吗
# @check: True
# @hint: 循环从 1 起步就完了——1 整除一切，人人会被误判"合数"；起点改成 2，终点用 sqrt(n) 就够
import math

def is_prime(n):
    if n < 2:
        return False
    for d in range(1, n):      # ← 这个起点有毛病
        if n % d == 0:
            return False       # 找到因子：不是素数
    return True

print(is_prime(97))
```

初始代码输出 `False`——因为任何数都能被 1 整除，第一轮就全军覆没。修好循环范围后，输出布尔值 `True`（比输出字符串"是"更利于程序判断）。

**练习 2**：不用代码，心算 $\pi(50)$（50 以内素数个数），再用实验 3 的程序验收。

**练习 3**：筛法为什么比"对每个数独立试除"划算？

<details>
<summary>点开查看逐步解答</summary>

试除法是"零售"：每判断一个数都要从头花一遍钱。筛法是"批发"：划掉 2 的倍数这一下，一口气处理了 49 个数；每个合数都由它最小的素因子顺手带走，总开销摊下来远低于逐个审问。这种"用空间换时间、一次劳动多次受益"的思想，正是算法设计的灵魂之一。
</details>

## 7. 选读：素数无穷多——欧几里得的两千年名证

<details>
<summary>选读 · 反证法：名单之外总有下一个</summary>

假设素数只有有限个，全部名单是 $p_1, p_2, \ldots, p_k$。构造新数：

$$N = p_1 \times p_2 \times \cdots \times p_k + 1$$

$N$ 大于 1，所以必有素因子。可是 $N$ 除以名单上任何一个 $p_i$ 都**余 1**——名单全员都不是它的因子！于是要么 $N$ 本身是素数，要么它的素因子在名单之外。两种情况都与"名单已包含全部素数"矛盾。

所以素数有无穷多个。这条证明诞生于两千三百年前，至今仍是"反证法"的教科书范本——没有一行计算，却封死了所有退路。

</details>
