# 最小公倍数：钟表重逢问题

## 1. 从一个场景开始

钟楼上有两口钟：一口每 4 秒响一次，一口每 6 秒响一次。它们刚刚同时响过——下次再次同时响，是几秒之后？

天文馆里同款问题更壮观：两颗行星每隔一定周期回到同一方位，「大合」几年一遇，全看两个周期的公共节拍。答案都是 12——那个既能被 4 整除、又能被 6 整除的最小的数。

上一课我们往**小**里走，拿辗转相除抓到了最大公约数；这一课掉头往**大**里走，请出它的孪生兄弟——**最小公倍数**：通分的另一半、齿轮啮合的节拍器，还自带一条与 gcd 成对的漂亮恒等式。

## 2. 直觉解释

第 1 章立过名册：一个数的**倍数**是它跳着数的台阶。现在把两列台阶并排摆出来：

```
4 的倍数：4, 8, 12, 16, 20, 24, 28, 32, 36, ...
6 的倍数：6, 12, 18, 24, 30, 36, 42, ...
```

两列里第一个碰头的数是 **12**——这就是最小公倍数。此后每 12 个数撞一次：12, 24, 36, …撞车的时刻表全部由 12 说了算。两口钟同时响、行星再次并肩、齿轮再次对齿，问的都是同一件事：**两列倍数台阶的第一次重逢点在哪**。

和 gcd 对着看更有味道：gcd 找的是两把因子量尺里**最长的那把公共尺子**，拼命往小里缩；lcm 找的是两列倍数台阶的**第一次撞车点**，一个劲儿往大里迈。一个管约分，一个管通分——同一枚硬币的两面。

## 3. 正式定义

设 $a, b$ 是正整数。既是 $a$ 的倍数又是 $b$ 的倍数的数叫**公倍数**，其中最小的一个记作

$$\mathrm{lcm}(a, b)$$

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $\mathrm{lcm}(a,b)$ | 最小公倍数 | 两列倍数台阶的第一次撞车点 |
| 公倍数全体 | 无穷队伍 | 恰好是 $\mathrm{lcm}(a,b)$ 的全部倍数：$\mathrm{lcm}, 2\,\mathrm{lcm}, 3\,\mathrm{lcm}, \ldots$ |
| 对偶关系 | 与 gcd 对照 | gcd 往小走（最大的公共因子），lcm 往大走（最小的公共倍数） |

本课的主角是这条**对偶恒等式**：

$$\gcd(a, b) \times \mathrm{lcm}(a, b) = a \times b$$

先验一笔：$\gcd(12, 18) = 6$（上一课欧几里得一分钟搞定），$\mathrm{lcm}(12, 18) = 36$，而 $6 \times 36 = 216 = 12 \times 18$ ✓。知道任意两个，第三个当场现形。

## 4. 分步例题

**例 1（笨办法）**：求 $\mathrm{lcm}(12, 18)$。

1. 列 12 的倍数：12, 24, 36, 48, …；
2. 列 18 的倍数：18, 36, 54, …；
3. 第一个共同出现的是 **36**。完毕。

数字小还行，数字一大两列倍数要写一黑板——该上一课的遗产上场了。

**例 2（恒等式法）**：还是 $\mathrm{lcm}(12, 18)$。

1. 先算 $\gcd(12, 18)$：$18 = 1 \times 12 + 6$，$12 = 2 \times 6 + 0$，得 gcd = 6；
2. 代恒等式：$\mathrm{lcm} = \dfrac{12 \times 18}{6} = \dfrac{216}{6} = 36$ ✓；
3. 顺手接通第 2 章的老活：通分 $\frac{1}{12} + \frac{1}{18}$，公分母取 36，$\frac{3}{36} + \frac{2}{36} = \frac{5}{36}$。

**例 3（质因数视角）**：用第 20 课的分解说话：$12 = 2^2 \times 3$，$18 = 2 \times 3^2$。

1. gcd 取每个质数的**较低**次幂：$2 \times 3 = 6$；
2. lcm 取每个质数的**较高**次幂：$2^2 \times 3^2 = 36$；
3. 两者相乘：$6 \times 36 = 2^3 \times 3^3 = (2^2 \times 3) \times (2 \times 3^2) = 12 \times 18$——恒等式的质因数身份证：每个质数的次数被 gcd 拿走低的、lcm 拿走高的，两边拼起来不多不少，正好是 $a$ 和 $b$ 的全部次数。

## 5. 动手实验

### 实验 1（viz）：两列脚印，找重逢点

两台等差数列播放器，分别播 4 和 6 的倍数台阶：

```viz
{
  "type": "seq",
  "kind": "arith",
  "a1": 4,
  "d": 4,
  "n": 10
}
```

```viz
{
  "type": "seq",
  "kind": "arith",
  "a1": 6,
  "d": 6,
  "n": 10
}
```

怎么玩：上下两排柱子是 4 和 6 各自的脚印。肉眼对照两排柱高，第一个等高的值是 12——第一次重逢；往后 24、36、48 每 12 步撞一次。再把两个 d 拧到 3 和 5（互质）：第一次撞车出现在 15——互质的两数没有公共零件可省，lcm 就是乘积 $3 \times 5$。

### 实验 2（python）：穷举公倍数，验证"撞车时刻表全归 lcm 管"

```python title="4 和 6 的公倍数清点"
a = 4
b = 6

multiples_a = []                  # a 的倍数收集桶
m = a
while m <= 60:                    # while：条件成立就一直转，m 超过 60 才停
    multiples_a.append(m)         # append：往列表末尾追加
    m = m + a                     # 每次往前迈一步长

multiples_b = []                  # b 的倍数收集桶，同款流水线
m = b
while m <= 60:
    multiples_b.append(m)
    m = m + b

common = []                       # 公倍数收集桶
for x in multiples_a:             # 逐个检查 a 的倍数是不是也是 b 的倍数
    if x % b == 0:
        common.append(x)

print(common)
print(common[0])                  # 下标取第一个成员——最小公倍数
```

输出 `[12, 24, 36, 48, 60]` 和 12：撞车时刻表 12, 24, 36, …恰好是最小公倍数 12 的倍数。把范围上限改大再跑，规律不变——公倍数全体被 lcm 一手接管。

### 实验 3（python）：恒等式对拍机 + math.lcm 出生证明

```python title="抽查 900 对数：gcd × lcm = a × b 一例不破"
import math                       # math 模块：gcd（上一课出生）与 lcm（本课出生）都在这里

bad = 0                           # 反例计数器
for a in range(1, 31):
    for b in range(1, 31):
        g = math.gcd(a, b)        # 最大公约数：上一课的工具
        l = a * b // g            # 用恒等式算 lcm：// 是整除，保证结果不带小数尾巴
        if g * l != a * b:
            bad = bad + 1         # 恒等式若被打破，记一笔

print(bad)                        # 900 对里反例的个数
print(math.lcm(12, 18))           # math.lcm：官方版最小公倍数（本课正式登记的新工具）
print(math.lcm(4, 6, 12))         # 它还能一次吃多个参数
```

反例计数器报 0——900 对数里恒等式一次没破。你刚用恒等式手算的 lcm 好用得连 Python 官方都收编了：`math.lcm` 一行顶两步，参数还不限两个。从此写课程序一律用 `math.lcm`；它为什么可靠，靠的是你亲手对拍过的那 900 对。

### 快问快答

```quiz
gcd(8, 9) = 1（互质）。lcm(8, 9) 是多少？
- 1
- 8 × 9 = 72 [*]
- 17
? 互质即没有公共质因数可省，最小公倍数就是两者的乘积 72。恒等式也当场给出：1 × lcm = 8 × 9。
```

::::warning[常见误区]

**误区一**："你以为公倍数多得数不完，找最小的得碰运气。" 公倍数全体恰好是最小公倍数的倍数——找到第一次撞车点，往后全是它的整数倍。第 1 章 45 课埋的"公倍数 = 最小公倍数的倍数"这条规律，今天在实验 2 里验明正身。

**误区二**："你以为 lcm(a, b) = a × b 永远成立。" 只有互质时才对！$\gcd(12,18) \ne 1$，所以 $\mathrm{lcm}(12,18) = 36$ 而不是 216——直接相乘把 12 和 18 的公共部分 6 重复算了两次。普遍规律是恒等式 $\gcd \times \mathrm{lcm} = a \times b$，"互质时 lcm 等于乘积"只是它 gcd=1 的特例。

**误区三**："你以为 gcd 和 lcm 是两个不相干的概念。" 它们是同一份质因数清单的两次取值：gcd 每个质数拿较低次幂，lcm 拿较高次幂，两边相加不多不少正好凑成 a × b——这正是恒等式的来历（选读给出完整论证）。

::::

## 6. 练习

**练习 1（判题）**：用恒等式求 $\mathrm{lcm}(12, 18)$，输出一个整数：

```exercise
# @title: 练习：用 gcd 恒等式求 lcm
# @check: 36
# @hint: 上一课的 math.gcd 可以直接用；恒等式 lcm = a × b ÷ gcd——记得用整除 // 别留小数尾巴
a = 12
b = 18
lcm = a * b            # ← 直接相乘太天真：12 和 18 的公共部分被算了几次？
print(lcm)
```

初始代码输出 216——把公共因子 6 重复算了一遍。请 math.gcd 出场除掉它，36 才是正确的重逢点。

<details>
<summary>点开查看逐步解答</summary>

先求 gcd，再代恒等式：

```python
import math

a = 12
b = 18
lcm = a * b // math.gcd(a, b)
print(lcm)
```

$\gcd(12,18) = 6$，$\mathrm{lcm} = \frac{216}{6} = 36$。验算：$36 \div 12 = 3$ ✓、$36 \div 18 = 2$ ✓，而且 24、48 这些更小的候选都通不过双检。

</details>

**练习 2**：公交总站两条线路 6:00 同时发车：一路每 8 分钟一班，另一路每 12 分钟一班。下次同时发车是几点几分？

<details>
<summary>点开查看逐步解答</summary>

同时发车的时刻是 8 和 12 的公倍数，最早的一个是 $\mathrm{lcm}(8, 12)$。

恒等式法：$\gcd(8, 12) = 4$，$\mathrm{lcm} = \frac{8 \times 12}{4} = 24$ 分钟。

下次同时发车是 **6:24**。笨办法对一下账：8 的倍数 8, 16, 24, …，12 的倍数 12, 24, …，第一个碰头的是 24 ✓。

</details>

**练习 3**：通分 $\frac{1}{12} + \frac{1}{18}$，比较"公分母取 lcm = 36"与"公分母取 12 × 18 = 216"两条路，哪条更省力？

<details>
<summary>点开查看逐步解答</summary>

lcm 版：$\frac{1}{12} + \frac{1}{18} = \frac{3}{36} + \frac{2}{36} = \frac{5}{36}$，已最简。

乘积版：$\frac{18}{216} + \frac{12}{216} = \frac{30}{216}$，还得约分：$\gcd(30, 216) = 6$，$\frac{30}{216} = \frac{5}{36}$——殊途同归，但分子分母一路大号码。

这就是"通分找最小公倍数当公分母"的实战意义：第 2 章欠下的账今天还上——公分母选小了，约分的活儿在通分时就顺手干完了。

</details>

## 7. 选读：为什么 gcd × lcm = a × b

<details>
<summary>选读 · 质因数清单上的"分家协议"</summary>

第 20 课的算术基本定理保证：任何大于 1 的整数都能唯一分解成素数乘积。设

$$a = p_1^{\alpha_1} \times p_2^{\alpha_2} \times \cdots, \qquad b = p_1^{\beta_1} \times p_2^{\beta_2} \times \cdots$$

（某质数只在一边出现时，另一边的次数记 0。）gcd 每个质数取 $\min(\alpha, \beta)$，lcm 取 $\max(\alpha, \beta)$——较低次幂拼成公共因子，较高次幂拼成公共倍数。

关键一刀：对每一对次数恒有 $\min(\alpha, \beta) + \max(\alpha, \beta) = \alpha + \beta$（小的加大的，正好是两个之和）。所以 gcd 与 lcm 的质因数清单拼起来，每个质数的次数恰好是 $\alpha + \beta$——与 $a \times b$ 的清单完全一致。清单一致，数就相等：

$$\gcd(a, b) \times \mathrm{lcm}(a, b) = a \times b$$

互质特例：所有 $\min$ 都是 0，gcd = 1，于是 lcm = a × b。另外，67 章范畴论会把 gcd/lcm 请回去当"最大下界/最小上界"——往小走与往大走的对偶，今天已经把地基打好。

</details>
