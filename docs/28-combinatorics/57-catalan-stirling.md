# Catalan 数与 Stirling 数：两类会数数的数列

## 1. 从一个场景开始

写代码时漏了一个右括号，编译器会冷冷地说"括号不匹配"。可你想过没有：**n 对括号一共有多少种"配得上"的写法？**

$n=1$ 只有 `()`；$n=2$ 有 `()` `()` 和 `(())` 两种；$n=3$ 已经是五种了。这串数 1, 2, 5, 14, 42 长得像斐波那契的远房亲戚，却完全是另一号人物——它叫 **Catalan 数**，负责清点一大票看起来毫不相干的组合结构。

顺便还有第二位客人：把 4 个不同的人分成 2 组有几种分法？这属于 **Stirling 数** 的辖区。这一课把这两个"会数数"的数列请上台，让它们在递推与生成函数的灯光下各自表演。

## 2. 直觉解释

**Catalan 数的奇妙之处在于"同一个数管五件事"。** 同样是 5（即 $C_3$），下面五种说法数出的东西完全一样多：

| 五种面孔 | $n=3$ 时的具体样子 |
| --- | --- |
| $n$ 对括号的合法嵌套 | `((()))`、`(()())`、`(())()`、`()(())`、`()()()` |
| 含 $n+1$ 片叶子的满二叉树形状 | 五个不同的分叉轮廓 |
| 凸 $(n+2)$ 边形的三角剖分 | 五边形切出三个三角形，五种切法 |
| 不走下坡的路径（Dyck 路径） | 六步里三上一二……共五种 |
| 栈的进出序列 | 三个元素进出栈的合法顺序，五种 |

数的是不同的东西，答案却总是一样。这种现象在组合学里叫**同构**：两套结构之间存在一一对应。找到一个同构，就把一个"不认识的新问题"翻译成"已经会数的老朋友"——这是本课最值钱的思维方式。

**Stirling 数则专门管"分组"和"排圈"两件家务事**：第二类数"把 $n$ 个不同的东西分成 $k$ 个非空的堆"有多少种分法；第一类数"把 $n$ 个东西排成 $k$ 个圆圈"有多少种排法。前者关注谁和谁在一堆，后者还多问一句"圈里的顺时针次序"。

## 3. 正式定义

**定义一（Catalan 数）**：$C_n$ 满足递推

$$C_0=1,\qquad C_n=\sum_{i=0}^{n-1} C_i\,C_{n-1-i}\quad(n\ge1)$$

闭式（通项）为

$$C_n=\frac{1}{n+1}\binom{2n}{n}=\frac{(2n)!}{n!\,(n+1)!}$$

递推式的读法只有一句：**任何一个合法结构，都能在"第一件东西配对的时刻"被切成左右两半**，两半独立、规模互补，于是用乘法原理相乘、再用加法原理把切法相加。

**定义二（两类 Stirling 数）**：用 $S(n,k)$ 记第二类，$c(n,k)$ 记第一类（无符号）。

| 数列 | 递推 | 数什么 | $n=4$ 时的一行 |
| --- | --- | --- | --- |
| 第二类 $S(n,k)$ | $S(n,k)=S(n-1,k-1)+k\,S(n-1,k)$ | 把 $n$ 个不同元素分成 $k$ 个非空无序组 | $1\quad7\quad6\quad1$ |
| 第一类 $c(n,k)$ | $c(n,k)=c(n-1,k-1)+(n-1)\,c(n-1,k)$ | 把 $n$ 个不同元素排成 $k$ 个有向环 | $6\quad11\quad6\quad1$ |

两个递推的"系数"藏着故事的差别：第二类新元素的归宿是"挑已有的哪个组"（$k$ 种），第一类新元素的归宿是"插在已有队列的哪个空隙"（$n-1$ 种）。初值都是 $S(0,0)=c(0,0)=1$，其余边界为 0。

| 记号 | 名字 | 一句话 |
| --- | --- | --- |
| $C_n$ | 第 $n$ 个 Catalan 数 | $C_0,C_1,C_2,\dots=1,1,2,5,14,42,132,\dots$ |
| $\binom{2n}{n}$ | 中心二项式系数 | 通项里那个"先算大、再除小"的中间量 |
| $S(n,k)$ | 第二类 Stirling 数 | 分堆 |
| $c(n,k)$ | 第一类 Stirling 数 | 排圈 |

## 4. 分步例题

**例 1（手算 Catalan）**：从 $C_0=1$ 出发，用递推算到 $C_4$。

1. $C_1=C_0C_0=1\times1=1$；
2. $C_2=C_0C_1+C_1C_0=1+1=2$；
3. $C_3=C_0C_2+C_1C_1+C_2C_0=2+1+2=5$；
4. $C_4=C_0C_3+C_1C_2+C_2C_1+C_3C_0=5+2+2+5=14$；
5. 用闭式抽查 $C_4=\frac{1}{5}\binom{8}{4}=\frac{70}{5}=14$ ✓ 两条路对上。

**例 2（闭式与递推的分工）**：算 $C_{10}$。

1. 递推要一路算十行表；闭式一步到位；
2. $\binom{20}{10}=184756$，除以 $11$ 得 $16796$；
3. 所以 $C_{10}=16796$，约等于 $1.68\times10^4$；
4. 顺带看增长率：$C_{10}/C_9\approx3.77$，趋于 4——比 2 的幂快，比 3 的幂更快，这也是 Catalan 结构"看起来不多、其实爆炸"的根源。

**例 3（第二类 Stirling）**：用递推填出 $n=4$ 那一行。

1. 第 1 行：$S(1,1)=1$；
2. 第 2 行：$S(2,1)=1$、$S(2,2)=1$；
3. 第 3 行：$S(3,1)=1$；$S(3,2)=S(2,1)+2S(2,2)=1+2=3$；$S(3,3)=1$；
4. 第 4 行：$S(4,1)=1$；$S(4,2)=S(3,1)+2S(3,2)=1+6=7$；$S(4,3)=S(3,2)+3S(3,3)=3+3=6$；$S(4,4)=1$；
5. 核对意义：把 4 个人分成 2 组共 7 种——单独一人的有 4 种（余下三人一组），两两成对的有 3 种，合计 $4+3=7$ ✓。

**例 4（第一类 Stirling）**：同样填到 $n=4$。

1. $c(n,n)=1$（每个元素自己一圈），$c(n,1)=(n-1)!$——$n$ 个元素排成一个圆，固定一人破环后就是 $(n-1)!$ 种直线排列；
2. 于是 $c(2,1)=1$、$c(3,1)=2$、$c(4,1)=6$；
3. 中间格：$c(3,2)=c(2,1)+2c(2,2)=1+2=3$；$c(4,2)=c(3,1)+3c(3,2)=2+9=11$；
4. 得到第 4 行 $6\quad11\quad6\quad1$；验算总排列数 $6+11+6+1=24=4!$ ✓——**每个排列按"有几个环"被分进了恰好一个格子**。

## 5. 动手实验

### 实验 1（viz）：通项里的中间量长什么样

Catalan 的闭式 $\frac{1}{n+1}\binom{2n}{n}$ 里，$\binom{2n}{n}$ 才是"大头"。把 $n$ 与 $k$ 拖到 $4$ 和 $2$，看到的就是 $C_2$ 用到的中间量 $\binom{4}{2}=6$；而真正的 $C_2$ 只有 2——**恰好是 6 除以 $(n+1)=3$ 之后剩下的**。这个"除以 $n+1$"的修正项不是装饰，它正是"去掉不合法结构"的那一刀。

### 实验 2（python）：递推表与闭式表逐格对拍

```python
N = 8
cat = [0] * (N + 1)              # [0]*(N+1)：先摆好 N+1 个零格当存储区
cat[0] = 1                       # C_0 = 1：空结构算一种
for n in range(1, N + 1):        # range(1, N+1)：n 取 1 到 N
    total = 0
    for i in range(n):           # 把 n-1 切成 i 与 n-1-i 两半，逐刀累加
        total = total + cat[i] * cat[n - 1 - i]
    cat[n] = total
print(cat)

row = [1]                        # 杨辉三角的一行，从 (1+x)^0 开始
for step in range(1, 2 * N + 1):  # 连乘 2N 次 (1+x)
    grown = [0] * (len(row) + 1)
    for i in range(len(row)):
        grown[i] += row[i]                 # 第 i 个括号不交 x
        grown[i + 1] += row[i]             # 第 i 个括号交出 x
    row = grown
    if step % 2 == 0:                      # % 2 == 0：只在偶数行读数
        n = step // 2                      # // 整除：偶数行号除以 2
        print(n, cat[n], row[n] // (n + 1))   # row[n] 正是中心系数 C(2n,n)
```

第一行输出 `[1, 1, 2, 5, 14, 42, 132, 429, 1430]`——递推表。后面八行每行三个数，第二个（递推值）与第三个（把中心二项式系数除以 $n+1$ 的闭式值）**逐格相同**，例如最后一行 `8 1430 1430`。两条路线互相验证，说明通项不是碰巧。

### 实验 3（python）：两类 Stirling 数并排铺开

```python
N = 5
s2 = []                          # 第二类表：s2[n][k]
s1 = []                          # 第一类表：s1[n][k]
for n in range(N + 1):
    s2.append([0] * (N + 1))     # append：往列表末尾追加一行零
    s1.append([0] * (N + 1))
s2[0][0] = 1                     # 初值：0 个元素分成 0 组，算 1 种
s1[0][0] = 1

for n in range(1, N + 1):
    for k in range(1, n + 1):
        s2[n][k] = s2[n - 1][k - 1] + k * s2[n - 1][k]        # 自成一组 + 塞进已有 k 组
        s1[n][k] = s1[n - 1][k - 1] + (n - 1) * s1[n - 1][k]  # 自成一圈 + 插进已有圈的缝隙

print("两类 Stirling 数的行和：")
for n in range(1, N + 1):
    total2 = 0                   # 第二类行和：不限组数时的分堆总数（Bell 数）
    total1 = 0                   # 第一类行和：不限圈数时的排圈总数
    for k in range(N + 1):
        total2 = total2 + s2[n][k]
        total1 = total1 + s1[n][k]
    print(n, total2, total1)
print("S(4,2) =", s2[4][2], " c(4,2) =", s1[4][2])
```

五行行和依次是 `1 1`、`2 2`、`5 6`、`15 24`、`52 120`。左列是 Bell 数（不限组数时的分堆总数）；右列恰好是 $1!,2!,3!,4!,5!$——因为**每个排列按"有几个环"分组，正好把 $n!$ 个排列一次分完，不重不漏**。最后一行 `S(4,2) = 7  c(4,2) = 11`，与例 3、例 4 的手算分毫不差。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为 Catalan 数的闭式是 $\binom{2n}{n}$。" 少了一个关键的 $(n+1)$。$\binom{2n}{n}$ 数的是"随便怎么配都算"的全部写法，其中包含大量右括号提前用完的非法串；除以 $n+1$ 正是剔掉这些的结果。忘了它，$C_3$ 会算成 20 而不是 5。

**误区二**："你以为两类 Stirling 数只是同一个数列的两种写法。" 其实它们管的是两笔不同的账：第二类数"分堆"，第一类数"排圈"。判据是想清楚要不要看圈内次序：四个人分成两组是 7 种（第二类 $S(4,2)$），四个人排成两个环是 11 种（第一类 $c(4,2)$）。

**误区三**："你以为 Catalan 结构只有括号一种。" 括号只是最好讲的那张脸。二叉树、三角剖分、Dyck 路径、栈序列与它一一对应；考试里遇到陌生的"合法序列计数"，第一反应就该是"它能不能翻译成括号"。

:::

## 7. 练习

**练习 1**：下面这段代码算的是 $\binom{2n}{n}$，忘了 Catalan 闭式里那一步除法。补上它：

```exercise
# @title: 练习：给 Catalan 闭式补上分母
# @check: 1
# @check: 2
# @check: 5
# @check: 14
# @check: 42
# @check: 132
# @hint: 闭式是 C(2n,n) / (n+1)；注意除法要用整除 //，否则浮点数会带尾巴。
def choose(n, k):
    # 组合数 C(n,k)：分子 n×(n-1)×…×(n-k+1)，分母 1×2×…×k
    top = 1
    for i in range(k):
        top = top * (n - i)
    bottom = 1
    for i in range(1, k + 1):
        bottom = bottom * i
    return top // bottom

for n in range(1, 7):
    print(choose(2 * n, n))       # ← 问题在这：还差除以 (n+1)
```

初始代码打出 `2, 6, 20, 70, 252, 924`，是"任意配对"的总数；改完应为 `1, 2, 5, 14, 42, 132`。差值不是小数目——$\binom{2n}{n}$ 与 $C_n$ 相差整整 $(n+1)$ 倍，$n=6$ 时错了 7 倍。

**练习 2**（概念）：为什么 Catalan 递推式是 $C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}$，而不是 $\sum_{i+j=n}C_iC_j$ 之外的别的形式？（提示：拿括号串想想第一对括号的左右两半。）

<details>
<summary>点开查看逐步解答</summary>

以一个合法的 $n$ 对括号串为例，最左端那个 `(` 必然有唯一的配对 `)`。设它俩之间夹了 $i$ 对括号，那么它俩的右边还剩 $n-1-i$ 对。**中间那 $i$ 对必须自成合法串，右边那 $n-1-i$ 对也必须自成合法串**，否则整体不合法；反过来，任意两个合法串套起来也一定合法。于是每一种合法串都唯一对应一个 $i$ 与一对子串，规模互补为 $n-1$，这正是 $\sum_i C_iC_{n-1-i}$。同样的切法可以搬到二叉树（第一对是根）与 Dyck 路径（第一次回到地平线的时刻）上，答案当然一样——这就是五个模型同构的微观原理。
</details>

## 8. 选读：用生成函数一步解出 Catalan

<details>
<summary>选读 · 从 C(x) = 1 + x·C(x)² 到闭式</summary>

把递推 $C_n=\sum_{i+j=n-1}C_iC_j$ 装箱：设 $C(x)=\sum_{n\ge0}C_nx^n$。右边那个"下标和为 $n-1$ 的配对求和"正是卷积，于是

$$C(x)-1=x\,C(x)^2$$

一句代数变形就把整条递推收进了一个二次方程。解它（取常数项为 1 的那个根）：

$$C(x)=\frac{1-\sqrt{1-4x}}{2x}$$

下一步用广义二项式定理把 $\sqrt{1-4x}$ 逐项展开：$\sqrt{1-4x}=\sum_{n\ge0}\binom{1/2}{n}(-4x)^n$。第 $n+1$ 项的展开式经化简后正好是 $-\frac{1}{n+1}\binom{2n}{n}x^{n+1}$，代回去便得

$$C_n=\frac{1}{n+1}\binom{2n}{n}$$

**递推、代数、通项三样东西在同一页纸上闭合成环**：递推负责讲清楚"为什么这样数"，生成函数负责把"这样数"翻译成方程，通项负责给出可以一步算完的答案。Stirling 数也走同一趟：它们的生成函数分别是 $\prod$ 形式与对数形式，第一类与第二类在"换基"下互为逆矩阵——这块地图留给后续的枚举组合学课程。

</details>
