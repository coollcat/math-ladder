## 实战挑战 · 双色球头奖有多大

中国福利彩票"双色球"的公开规则：从 33 个红球中挑 **6 个**（号码**不计顺序**），再从 16 个蓝球中挑 **1 个**，7 个号全对即中一等奖。头奖概率是彩票店里流传最广也最常被算错的数字——错就错在"顺不顺序"这一念之间。情境改编自公开彩票规则与概率科普材料（非考题）。

**(a)** 红球共有多少种组合？
**(b)** 一注完整号码（红 + 蓝）共有多少种？
**(c)** 于是头奖概率的分母是多少？算完再感受一下这个数。

```exercise
# @title: 实战挑战：双色球头奖概率
# @check: 1107568
# @check: 17721088
# @hint: 彩票不计顺序：6 个红球的 720 种站姿算同一注。初始代码把顺序当了真。
ordered_red = 33 * 32 * 31 * 30 * 29 * 28   # 六个红球按顺序抽取的种数
blue_choices = 16                            # 蓝球从 16 个里挑 1 个

red_combos = ordered_red                     # ← 问题在这：还需除以 720 才是不计顺序的组合数
print(red_combos)
print(red_combos * blue_choices)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 若讲究顺序，红球有 $33 \times 32 \times 31 \times 30 \times 29 \times 28$ 种抽法；但同一组 6 个号码在开奖时被算了 $6! = 720$ 次"站姿"，所以组合数为

$$\frac{33 \times 32 \times 31 \times 30 \times 29 \times 28}{720} = \frac{797448960}{720} = 1107568$$

这正是 $C(33,6)$——第 20 课的组合公式在彩票店的实体化。

**(b)** 蓝球独立挑选、16 种可能，两阶段串联用乘法原理：

$$1107568 \times 16 = 17{,}721{,}088$$

**(c)** 头奖只有一种号码组合能命中，故概率为 $\dfrac{1}{17721088} \approx 0.0000056\%$。直观对比：比"从 1770 多万人的体育场里被随机点名"还难一点。每注 2 元、全包所有组合需约 3544 万元——期望收益为负是所有乐透型彩票的数学宿命。

验算习惯：先算排列再除以 $k!$ 的"两段式"，正是 [排列、组合与多重集](./20-permutations-combinations.md) 的核心动作；"红 × 蓝"的独立阶段则来自 [加法原理与乘法原理进阶](./10-count-principles.md)。
</details>

## 实战挑战 · 组合数别漏了分母

组合数 $C(n,k)=\frac{n!}{k!(n-k)!}$，分母里除了 $k!$ 还有 $(n-k)!$。下面算 $C(5,2)$ 漏了 $(n-k)!$，修到输出 `10`：

```exercise
# @title: 实战挑战：组合数别漏了分母
# @check: 10
# @hint: C(n,k) = n! / (k! · (n-k)!)，分母有两个阶乘。
def fact(m):              # 阶乘：1×2×…×m
    f = 1
    for i in range(1, m + 1):
        f = f * i
    return f

n, k = 5, 2
c = fact(n) // (fact(k))     # ← 问题在这：漏了 fact(n-k)
print(c)
```

<details>
<summary>点开查看逐步解答</summary>

组合数公式的分母是 $k!$ 与 $(n-k)!$ 的乘积：

```python
c = fact(n) // (fact(k) * fact(n - k))   # 120 // (2 * 6)
print(c)                                 # 10
```

改完：$C(5,2)=\frac{5!}{2!\cdot3!}=\frac{120}{2\times6}=10$。初始代码只除了 $k!$，得 $\frac{120}{2}=60$——那其实是"从 5 个里有序选 2 个"的排列数。组合与排列差的那一个 $(n-k)!$，正是"选出来之后不计顺序"的关键。

</details>
