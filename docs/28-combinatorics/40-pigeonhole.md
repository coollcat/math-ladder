# 鸽笼原理

## 1. 从一个场景开始

任意挑 13 个人，断言：**其中必有两人出生在同一个月**。

我根本不知道这 13 个人是谁、生日是几号——但断言稳如泰山。理由朴素到令人发笑：12 个月份是 12 只鸽笼，13 只鸽子往里塞，就算每个月都挤进一人，第 13 人无论去哪都会撞车。**不看过程、只数容器**——这种"以势压人"的论证就是鸽笼原理（抽屉原理），数学里最省力的重武器。

## 2. 直觉解释

原理的原始形态：$n+1$ 只鸽子飞进 $n$ 个笼子，必有一个笼子至少住 2 只。

它的加强版更常用："必有一个笼子**平均分以上**"。把 $N$ 只鸽子塞进 $k$ 个笼子，则存在一个笼子装了至少

$$\left\lceil \frac{N}{k} \right\rceil \quad \text{（向上取整）}$$

只。直觉：如果每个笼子都低于平均值，总数就够不到 $N$——平均数是下限的承诺，不是上限的许可。

使用套路只有两步，难点全在"找什么当笼子"：

1. **认鸽子**——要保证重复/存在的对象是什么；
2. **造笼子**——把对象按某个可数特征分类，且类数严格少于对象数。

## 3. 正式定义

**简单形式**：把 $n+1$ 个物件放入 $n$ 个盒子，则至少有一个盒子含两个及以上物件。等价说法：不存在从 $\lbrace 1,\dots,n+1\rbrace$ 到 $\lbrace 1,\dots,n\rbrace$ 的单射——逻辑章“单射需要输入不多于输出”的必然面。

**加强形式**：把 $N$ 个物件放入 $k$ 个盒子，则至少有一个盒子含至少 $\lceil N/k \rceil$ 个物件。反证一句话：若每盒至多 $\lceil N/k \rceil - 1$ 个，总数至多 $k(\lceil N/k\rceil - 1) < N$，矛盾。

它给出的永远是**存在性结论**：知道"有"，不告诉你"在哪"。想找出那个笼子，还得老老实实挨个查。

## 4. 分步例题

**例**：证明任取 5 个整数，必有两数之差被 4 整除。

1. 认鸽子：5 个整数；
2. 造笼子：按除以 4 的余数分类——余 0、1、2、3，恰好 **4** 只笼子（这是"同余"关系的等价类！逻辑章的伏笔在此回收）；
3. 5 只鸽子进 4 笼，必有两数同余；
4. 同余意味着两数之差是 4 的倍数。证毕——全程没碰任何具体数字。

再热身一题：370 人中必有两人同一天过生日？$370 > 366$，笼子是天数，直接套简单形式。

## 5. 动手实验

### 实验 1（viz）：月份里的撞车现场

```viz
{
  "type": "datachart",
  "title": "13 名队员的出生季度分布（某次点名）",
  "labels": ["一季度", "二季度", "三季度", "四季度"],
  "values": [5, 3, 2, 3]
}
```

13 根柱子踩着 4 个季度，总有一根不低于 $\lceil 13/4\rceil=4$——这份名单里第一季度有 5 人，撞车格外热闹。若换成更细的 12 个月份作鸽笼，加强形式也承诺 $\lceil 13/12 \rceil = 2$ 的月份永远存在；图上用季度，是为了让每个笼子都能在画布上站直。

### 实验 2（python）：穷举 1024 种可能，零例外

```python title="暴力核查“5 个整数必有差为 4 的倍数”"
violations = 0                    # 反例计数：先假设没有违规组合
for code in range(4 ** 5):        # 枚举 4^5 = 1024 种“五数各自余数”的组合
    residues = []                 # 解码出五个余数
    remaining = code
    for g in range(5):
        residues.append(remaining % 4)
        remaining = remaining // 4

    has_pair = False              # 是否存在两数同余
    for i in range(5):
        for j in range(i + 1, 5):
            if residues[i] == residues[j]:
                has_pair = True
    if not has_pair:
        violations = violations + 1

print(violations)
```

输出 `0`：1024 种余数组合里没有一种能避免同笼。机器替我们把所有反例可能性逐一枪毙——这就是鸽笼原理的"穷举影子"：定理说 0，程序也数出 0。

:::warning[常见误区]

**误区一**：你以为鸽笼原理会指出谁和谁撞笼。它只保证存在性；定位仍需检查。生日悖论算的是概率，鸽笼算的是必然——两者别混谈。

**误区二**：你以为笼子必须显而易见。"差被 4 整除"的笼子是余数、"朋友对数"的笼子是度数值——好的鸽笼论证全在构造上见功力。

**误区三**：你以为鸽子必须比笼子多才行。加强版只需数量超过 $k \times (m-1)$ 就能逼出"某笼至少 m 只"；比如 91 天里读书，必有连续多天合计……这类变体是竞赛题的常客。
:::

## 6. 练习

```quiz
黑袜 10 只、白袜 10 只混在黑暗抽屉里，至少取几只才能保证配成同色一双？
- 2 只
- 3 只 [*]
- 11 只
? 颜色只有两只笼子，取 3 只必有两只同色——运气最坏时前两只是一黑一白。
```

**练习 1**：证明在任何 6 人的聚会中，要么有三人互相认识，要么有三人互相不认识。（经典 Ramsey 问题 R(3,3)，提示：盯住其中一个人。）

<details>
<summary>点开查看逐步解答</summary>

任取一人甲，其余 5 人按"与甲认识 / 不认识"分成两笼，由鸽笼必有一笼至少 3 人。设 A、B、C 三人都认识甲：若 A、B、C 彼此互识，他们组成三人互识组；否则某两人互不相识，连同甲构成三人互不相识组。另一笼情形完全对称。两条路都逃不出结论——鸽笼负责分流，对称性负责复制答案。
</details>

**练习 2**：袜子程序的作者太乐观了。修成最坏情况思维：

```exercise
# @title: 黑暗中的最坏情况
# @check: 3
# @check: 12
# @hint: 最坏情况会先把“不利”的选项全部耗尽：配同色一双只需颜色数 +1；配出一双黑袜要先把 10 只白袜全部摸完，再多摸 2 只。
colors = 2
white_socks = 10

same_color_pair = colors          # ← 问题在这：抽 2 只可能一黑一白，并不保险
black_pair = white_socks          # ← 问题在这：白袜摸完还不够凑一双黑
print(same_color_pair)
print(black_pair)
```

修好后输出 `3` 和 `12`。第一行是纯鸽笼（2 色 + 1）；第二行是"指定款"版本——最坏情况下对手会把白袜一张张塞给你，你必须活到最后。

## 7. 选读：无限版鸽笼与数论的相遇

<details>
<summary>选读 · 把无穷只鸽子关进有限笼</summary>

把无穷多个自然数按奇偶分两类，必有一类含无穷多个数——这就是鸽笼原理的无穷形式，它是**拉姆齐理论**的起点：足够大的结构里，秩序无法逃避。数论中的经典应用：任取 $n+1$ 个不超过 $2n$ 的正整数，必有两数一个是另一个的约数（笼子造法：按"奇数核心"分组）。这些结果共同宣示一件事——只要容器不够多，混乱就注定局部塌缩成结构。
</details>
