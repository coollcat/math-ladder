# 加法原理与乘法原理进阶

## 1. 从一个场景开始

你要从家到新学校报到，行李很多，只能坐车：

- 线路一：直达校门的高铁有 **3** 个班次；
- 线路二：地铁 + 校巴的组合里，地铁有 **4** 班、每班地铁接驳的校巴各有 **2** 班。

问：总共有多少种走法？答案是 $3 + 4 \times 2 = 11$。一个加号、一个乘号，用在哪一步全凭一个判据——**这一步是"或"还是"且"**。整章组合数学都建立在这两个字的分辩上。

## 2. 直觉解释

- **乘法原理（串联）**：一件事分 $k$ 个阶段依次完成，各阶段的选择互不干扰，总数是各阶段方案数**相乘**。像流水线：每道工序都有多种做法，产品 = 所有工序选择的组合；
- **加法原理（并联）**：完成一件事有几条**互不重叠**的路线，任选其一即成，总数是各路线方案数**相加**。像分流河道：水走哪条都到海，但不能同时走两条。

两条合体就是树形图：从根出发每个分叉乘一次；不同主干之间加一次。而"至少""不都"这类别扭条件有个杀手锏——**补集计数**：先算全体，再减掉不合格的，常常比正面硬算省一半力气。

## 3. 正式定义

设事件 $A$ 可以由 $m$ 类互斥方式之一完成，第 $i$ 类内部又有 $n_i$ 种做法：

$$N(A) = n_1 + n_2 + \cdots + n_m$$

若 $A$ 必须依次经过 $k$ 个独立阶段，第 $i$ 阶段有 $s_i$ 种选择：

$$N(A) = s_1 \times s_2 \times \cdots \times s_k$$

使用前各自有一道安检：

| 原理 | 安检项 | 违反后果 |
| --- | --- | --- |
| 加法 | 各类**不重不漏**（划分！） | 重叠 → 重复计数；遗漏 → 少算 |
| 乘法 | 各阶段**独立**且后续选择不受先前影响 | 有依赖 → 不能直接相乘 |

补集公式：$N(\text{至少一个}) = N_{\text{全体}} - N(\text{都不})$。

## 4. 分步例题

**例**：某网站密码规则为"6 到 8 位，每位的字符来自 26 个小写字母"，且密码不能全由同一字母组成。求合法密码总数。

1. 按长度分类（加法）：6 位一类、7 位一类、8 位一类，三类互斥；
2. 每类内部按位置连乘：$26^6$、$26^7$、$26^8$；
3. 全体合计：$26^6 + 26^7 + 26^8$;
4. 减去违规项："全同字母"在每个长度下恰有 26 个（aaaaaa、bbbbbb……），共 $26 \times 3$ 个；
5. 合法数 $= 26^6 + 26^7 + 26^8 - 78$。分类管长度、乘法管位数、补集管禁令——三板斧各司其职。

## 5. 动手实验

### 实验 1（python）：密码空间有多大

```python title="位数变长一位，破解成本翻 26 倍"
letters = 26

total6 = letters ** 6        # ** 幂运算：26 的 6 次方
total7 = letters ** 7
total8 = letters ** 8
print(total6)
print(total7)
print(total8)

all_same = letters * 3       # 全同字母的违规密码：每种长度 26 个，共三个长度
legal = total6 + total7 + total8 - all_same   # 补集计数：全体减违规
print(legal)

ratio = total7 / total6      # / 除法：得到小数而不是整除
print(ratio > 25)            # 验证“多一位≈翻 26 倍”
```

最后一行输出 `True`。攻击者每多猜一位就多付 26 倍代价——这就是"加长胜过复杂"的密码学常识来源。

### 实验 2（matplotlib）：把决策过程画成树

```python title="两阶段决策树：4 条地铁 × 2 条校巴"
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot([0, 1], [0, 1.5], color="gray")          # plot 两点连线：根→地铁分支
ax.plot([0, 1], [0, -1.5], color="gray")
for m in range(4):                                # 地铁 M1~M4
    y_m = 1.5 - m * 1.0
    ax.text(1, y_m, "M" + str(m + 1), fontsize=11)
    for b in range(2):                            # 接驳校巴 B1/B2
        ax.plot([1.15, 2.15], [y_m, y_m + 0.35 if b == 0 else y_m - 0.35], color="#3b74d6", alpha=0.6)
    ax.scatter([1], [y_m], s=60, color="#e8871e")
ax.text(0, 0, "出发", fontsize=12)
ax.text(2.3, 0, "8 条换乘组合", fontsize=12)
ax.axis("off")                                    # 关闭坐标轴，纯示意图
```

树的每一层对应一个阶段；叶子总数 = 分支数的连乘。画不出树的超长流程，公式照样成立——树只是乘法原理的肉眼版。

:::warning[常见误区]

**误区一**：你以为分类重叠一点没关系，"大不了多算几个"。重叠会让某些对象被数两次，答案系统性偏大——必须改写成互斥类或动用容斥（本章稍后登场）。

**误区二**：你以为限制条件只影响一步。首位不能为 0 时，三位数是 $9 \times 10 \times 10$ 而不是 $10^3 - 1$：禁令改变的是那一格的可选数，再让乘法传播它。

**误区三**：你见到"至少一人"就想枚举恰好一人、恰好两人……其实补集往往一步到位。"至少一人命中" = 全部射击 − 全部脱靶。
:::

**练习 1**：车牌规则为"两个大写字母 + 三位数字，首位数字非零"。用本课三件套写出总数并化简。

<details>
<summary>点开查看逐步解答</summary>

字母位各 26 种、数字首位的 9 种、其余两位各 10 种，全程串联用乘法：$26 \times 26 \times 9 \times 10 \times 10 = 608400$。没有任何"或"出现，所以一次乘到底。
</details>

**练习 2**：衣柜里有 3 顶帽子和 4 条围巾，其中两套搭配被时尚警察禁止。合法搭配有多少种？程序想算第二行却抄错了：

```exercise
# @title: 禁止搭配要减在哪儿
# @check: 12
# @check: 10
# @hint: 先算自由世界的全部组合，再减去违禁的两套。初始代码第二行忘了做减法。
hats = 3
scarves = 4
forbidden = 2

all_pairs = hats * scarves     # 乘法原理：帽子围巾各选一

print(legal_pairs)
```

修好后输出 `12` 和 `10`。第一行是自由市场价，第二行是执法后的真实库存——补集思想的最小实现。

## 7. 选读：为什么"独立"如此重要

<details>
<summary>选读 · 乘法失效的现场</summary>

乘法原理要求后一阶段的选项集合不因前一阶段的选择而变化。抽牌不放回就是典型反例：第一张 52 选 1，第二张只剩 51 选——两阶段选项集不同，直接 $52 \times 52$ 就错了。处理办法有两条路：把"剩余牌数"写进下一阶段（逐步收缩），或者干脆换用排列组合公式一次性打包。下一课的主角正是后者。
</details>
