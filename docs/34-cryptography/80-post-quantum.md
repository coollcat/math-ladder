# 后量子密码：当 Shor 的机器真的造出来

## 1. 从一个场景开始

你电脑里的每一次 HTTPS 连接，都靠 RSA 或椭圆曲线锁住密钥。它们的底气来自同一句话：**大数分解和离散对数，用最快的经典计算机也要算上宇宙年龄那么久。**

但这句话里有个前提——"经典计算机"。

1994 年，Shor 写下一个量子算法：**分解大数与求离散对数，都能在多项式时间内完成**。也就是说，一旦足够大的量子计算机造出来，RSA 和 ECC **不是变弱，是直接失效**。

今天所有加密流量里被录下来的部分，都可能等着将来被解密——这就是"先存后解"（harvest now, decrypt later）的威胁。后量子密码不是赶时髦，是必须提前换锁。

## 2. 直觉解释

先纠正一个常见说法："量子计算机很快。"

**不对。** 量子计算机在大多数事情上并不快。它真正的本事是**利用问题的结构**：因数分解有一个隐藏的周期性，量子傅里叶变换能把这个周期"一次性读出来"，而经典计算机只能一次次试。

所以威胁不是均匀分布的：

| 类型 | 代表 | 量子威胁 |
| --- | --- | --- |
| 公钥（基于分解/离散对数） | RSA、ECC、DH | **致命**：Shor 算法多项式时间破解 |
| 对称（基于混淆与扩散） | AES | **可控**：Grover 只把暴力搜索开方，密钥加倍即可 |

后量子密码的任务是给公钥部分找**不依赖分解与离散对数**的新地基。目前最有希望的四条路线：

- **格密码**（Lattice）：在有噪声的线性方程组上做文章；
- **编码密码**：基于纠错码的译码困难性（第 35 章的老朋友）；
- **多变量密码**：解一堆二次多元方程组；
- **哈希签名**：只靠哈希函数（最保守，但签名很大）。

其中**格密码是当下的主力**，它的核心问题叫 **LWE**（Learning With Errors，带误差学习）。

## 3. 正式定义

**LWE 问题**：给定 $m$ 个方程

$$b_i = \langle \vec a_i, \vec s\rangle + e_i \pmod q$$

其中 $\vec a_i \in \mathbb{Z}_q^n$ 公开、$b_i$ 公开、$e_i$ 是**很小的噪声**，求秘密向量 $\vec s$。

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $n$ | 维度 | 秘密向量的长度，越大越安全 |
| $q$ | 模数 | 通常取素数 |
| $\vec a_i$ | 公开系数向量 | 每个方程随机生成，人人可见 |
| $\vec s$ | **秘密** | 要恢复的目标 |
| $e_i$ | 误差项 | 小整数（如 $\pm1$），**正是它让问题变难** |
| $b_i$ | 公开右端项 | $\langle\vec a_i,\vec s\rangle + e_i \bmod q$ |

**没有噪声会怎样？** 那只是解线性方程组——高斯消元几秒钟搞定。噪声的作用是：方程数即使超过未知数，**每一条都有点偏**，逐条消元会被噪声放大到面目全非。

**格视角**：$(a_i, b_i)$ 可以看成高维格中的一个点。噪声让目标点在格点附近晃，而"从格点附近找回格点"（最近向量问题 CVP）在高维下是**公认困难**的。

**为什么它让人放心**：LWE 有一个罕见的性质——**平均情形困难等价于最坏情形困难**（Regev 归约）。意思是：随机挑一个 LWE 实例如果容易解，那么**所有**格问题都容易解。这比 RSA 的处境强得多（RSA 只保证"随机实例难"）。

## 4. 分步例题

**例 1（小参数手算，体会噪声的破坏力）**：取 $n=2$、$q=97$、秘密 $\vec s = (3, 5)$。

1. 生成一个系数向量 $\vec a_1 = (11, 7)$；
2. 算内积：$11\times3 + 7\times5 = 33 + 35 = 68$；
3. 加噪声 $e_1 = 1$，得 $b_1 = 69 \bmod 97 = 69$。

再生成三条：$\vec a_2=(20, 4), b_2=78$；$\vec a_3=(3, 41), b_3=21$；$\vec a_4=(15, 22), b_4=54$。

**没有噪声时**，任取两条联立就能解出 $\vec s$。**现在每条都偏了一点点**，联立解出的结果会是另一个毫无意义的向量——错误被放大了。

**例 2（暴力破解的代价）**：秘密空间大小是 $q^n = 97^2 = 9409$。小维度下暴力枚举瞬间完成。

那么真实参数呢？Kyber（NIST 标准化的格密码 KEM）用 $n=256$ 或 $512$，$q=3329$。秘密空间大小约 $3329^{256} \approx 10^{898}$——**比可观测宇宙的原子数（约 $10^{80}$）还多出一整个银河系量级**。

**例 3（为什么是"平均≈最坏"这么强）**：RSA 的困难性假设是"随机大数难分解"，但从没排除"存在某些特殊数特别好分解"。LWE 的归约说：**你要么能解所有格问题，要么连随机实例也解不动**——中间地带不存在。这是它成为后量子主力军的理论理由。

## 5. 动手实验

先看噪声是怎么把可解的方程组变难的：

```python title="没有噪声 vs 有噪声：同一个方程组的两种命运"
import math

q = 97                            # 模数
s = [3, 5]                        # 秘密向量

# 无噪声：两条方程直接联立
a1, b1 = [11, 7], 68              # b1 = 11*3 + 7*5 = 68
a2, b2 = [20, 4], 78              # 但注意：真实场景里 b 是公开的，这里先手算好

def solve_noiseless(a1, b1, a2, b2, q):
    """用消元法解二元一次同余方程组（无噪声时才成立）"""
    # 消去第二个未知数：a1[k]*s[0] + a1[...] ... 用行列式法
    det = (a1[0] * a2[1] - a2[0] * a1[1]) % q
    if det == 0:
        return None
    inv = pow(det, -1, q)          # pow(x, -1, q)：模 q 下的乘法逆元
    x = ((b1 * a2[1] - b2 * a1[1]) * inv) % q
    y = ((a1[0] * b2 - a2[0] * b1) * inv) % q
    return [x, y]

print("无噪声：", solve_noiseless(a1, b1, a2, b2, q), " ← 正是 (3, 5)")

# 有噪声：每条 b 都偏了一点，同样的消元法给出完全错误的结果
b3, b4 = 69, 79                   # 加了 ±1 的噪声
print("有噪声：", solve_noiseless(a1, b3, a2, b4, q), " ← 已经不是 (3, 5) 了")
```

两组方程只差一点点，解出来却天差地别。**噪声破坏了线性结构**——这就是 LWE 的安全性来源。

再看维度增大时暴力搜索怎么失控：

```python title="暴力枚举的代价：维度一涨就完蛋"
q = 97
for n in [2, 3, 4, 5]:
    space = q ** n                # 秘密空间大小
    print(f"n = {n}：{space:>15,} 种可能")
```

$n=5$ 时已经是 85 亿种可能，$n=256$ 时连用科学计数法写出来都嫌长。

最后看一眼格密码"几乎实际可用"的规模感：

```python
q = 3329                          # Kyber 的模数
n = 256
print(f"秘密空间大小约 10^{round(n * __import__('math').log10(q)):,}")
print(f"对比：可观测宇宙原子数约 10^80")
```

```quiz
量子计算机对哪一类密码威胁最大？
- 基于大数分解和离散对数的公钥密码 [*]
- 基于混淆与扩散的对称密码
- 基于哈希函数的签名

```

:::warning[常见误区]

**误区一**："量子计算机什么密码都能破。" 
不是。它对**有隐藏周期结构**的问题特别有效（分解、离散对数）。对称密码只被 Grover 开方加速，AES-256 在量子时代依然安全。所以"后量子迁移"的重点是公钥体系。

**误区二**："后量子密码是量子密码。" 
这是两个完全不同的东西。**量子密码**（如量子密钥分发 QKD）用物理原理传输密钥；**后量子密码**是**用经典计算机跑的、抗量子攻击的经典算法**——它现在就能部署在你的浏览器里，不需要任何量子硬件。

**误区三**："等量子计算机造出来再换也不迟。" 
来不及。攻击者今天就可以录下你的加密流量，**等机器造好再解密**。而且密码迁移周期以十年计（历史参照：SHA-1 的退役花了十几年），现在开始换才是正常节奏。NIST 已在 2024 年发布了首批后量子标准。

:::

## 6. 练习

**练习 1**：下面的代码想从带噪声的 LWE 实例中恢复秘密（小维度下用暴力枚举是可行的）。但初始代码漏了噪声项，导致解出来是错误的向量。修到输出 `(3, 5)`：

```exercise
# @title: 练习：小维度 LWE 的暴力求解
# @check: (3, 5)
# @hint: b = (a·s + e) mod q；比较时必须容忍噪声——允许差值在 ±1 之内才算匹配，或直接把噪声减掉再比较
q = 97
observed = [((11, 7), 69), ((20, 4), 78), ((3, 41), 21)]   # (系数, 右端项)

def find_secret():
    for x in range(q):
        for y in range(q):
            if all((a[0] * x + a[1] * y) % q == b % q for a, b in observed):
                return (x, y)     # ← 这里要求完全相等，但每一条都带噪声
    return None

print(find_secret())
```

**练习 2**：估算一下，如果噪声 $e \in \lbrace-1,0,1\rbrace$，而方程有 100 条，一个随机猜测的 $\vec s$ 平均能满足几条方程？

<details>
<summary>点开查看逐步解答</summary>

对随机猜测的 $\vec s'$，每条方程算出的 $(a_i\cdot s'+ \text{噪声}) \bmod q$ 落在 $q$ 个值里，命中给定 $b_i$ 的概率是 $1/q$（假设均匀），加上噪声容忍的 3 个取值（$-1,0,1$），命中率约 $3/q = 3/97 \approx 3.1\%$。

100 条方程里平均命中约 3 条。

**但真实参数下 $q \approx 3329$、$n=256$，随机猜测几乎不可能同时满足哪怕两条。** 这正是 LWE 安全的经验直觉——约束的数量远超过随机碰撞的可能性。

```python
q = 97
print(f"单条命中率约 {3/q:.4f}，100 条平均命中 {100*3/q:.1f} 条")
```
</details>

## 7. 选读：格为什么这么难

<details>
<summary>选读 · 从"格点附近找点"到 SVP/CVP</summary>

**格**是一个由整数线性组合张开的高维离散点阵：

$$\Lambda = \left\lbrace\textstyle\sum_i z_i \vec b_i : z_i \in \mathbb{Z}\right\rbrace$$

（$\vec b_i$ 是格基向量。）

两个困难问题撑起了格密码：

**SVP（最短向量问题）**：在格中找到最短的非零向量。
**CVP（最近向量问题）**：给定空间中一点，找到离它最近的格点。

二维三维可以画图直观感受，一旦维度升到几百维，**最好的已知算法也需要指数时间**。LWE 就是把秘密藏进格点，再把噪声当成"离格点不远的扰动"，把问题归约成 CVP。

**格密码意外地实用**：CVP 视角还顺便带来了同态加密（在密文上直接做运算，结果解密后等于对明文做同样的运算）——这是隐私计算的核心原语。一个为了抗量子而找的地基，最后长出了另外一整片应用森林。
</details>
