# 平方根：已知面积求边长

## 1. 从一个场景开始

你要给一块**面积为 144 平方米**的正方形客厅铺地砖，得先知道边长才能买踢脚线。面积是现成的，边长却没人告诉你。

乘方课问"12 的平方是多少"；这一课把问题反过来："**谁的平方等于 144？**"反向提问在数学里从来不是小事——它往往逼出一个新符号、一套新工具，有时甚至逼出一类新的数。

## 2. 直觉解释

正方形面积 = 边长 × 边长。已知面积反推边长，就是在猜一个数：

- 试 $10$：$10\times10=100$，太小；
- 试 $13$：$169$，太大；
- 试 $12$：正好 $144$！边长 12 米。

如果面积换成 2 呢？$1^2=1$ 太小、$2^2=4$ 太大——答案夹在 1 和 2 **中间的某处**。这个"某处"既不是整数，也不是分数（选读部分证明），人类只好给它起了个专属名字：$\sqrt{2}$。

## 3. 正式定义

**平方根**：若 $b^2 = a$（$a \ge 0$），就称 b 是 a 的平方根，记正的那一个为

$$\sqrt{a}$$

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $\sqrt{a}$ | 根号 a | a 的**算术平方根**（非负的那个） |
| $a$ | 被开方数 | 必须非负 |

两条要点：

1. 正数的平方根其实有**一对**：$+2$ 和 $-2$ 的平方都是 4。但符号 $\sqrt{\phantom{x}}$ 按约定只指非负那个，就像"+"只指正方向。
2. 负数开不了平方：任何实数自乘都不小于零（第 1 章：平方拍扁符号）。

## 4. 分步例题

**例 1**：求 $\sqrt{144}$。
1. 用完全平方数缩小包围圈：$10^2=100$ 太小，$13^2=169$ 太大 → 锁定 10 到 13；
2. 检查候选：$11^2=121$，$12^2=144$ → 命中；
3. 所以 $\sqrt{144}=12$。

**例 2**：估计 $\sqrt{2}$ 到两位小数。
1. $1.4^2=1.96<2$，太小；$1.5^2=2.25>2$，太大 → 在 1.4 与 1.5 之间；
2. 加密一格：$1.41^2=1.9881$ 还小；$1.42^2=2.0164$ 过头 → 在 1.41 与 1.42 之间；
3. 取到两位小数：$\sqrt{2}\approx 1.41$。

这套"试、比、缩圈"的动作，就是下面实验的全部内容——也是一切计算器开方的原始思想。

## 5. 动手实验

### 实验 1：sqrt 的诞生——只用乘法和比较

不许用任何开方工具，只靠"乘一下、比一比"，把 $\sqrt{2}$ 逼到两位小数：

```python title="试数逼近根号 2"
best = 0.0                     # 记录目前最好的试探值
for i in range(1, 200):        # 依次尝试 0.01, 0.02, ..., 1.99
    g = i / 100                # i 除以 100：得到两位小数的试探值
    if g * g <= 2:             # 只用乘法和比较：还没超过 2 就记下来
        best = g               # 更新纪录保持者
print(best)
print(best * best)             # 验证：确实紧贴着 2 但没超过
```

得到 `1.41`。我们没用任何开方功能——只有乘法和比较，就把根号"造"了出来。这种笨办法正是数值方法的雏形（更聪明的逼近第 13 章讲）。

### 实验 3：宣布 math.sqrt 诞生

每次都手搓太累。Python 的数学工具箱里装着现成的开方函数：

```python title="math.sqrt：官方开方器"
import math                    # 导入数学工具库，之后就能用 math.sqrt 等功能

print(math.sqrt(2))            # sqrt(square root)：算术平方根，给出十几位精确值
print(math.sqrt(144))
print(math.sqrt(0.25))
```

对比实验 1 的 1.41：`math.sqrt(2)` 直接给到小数点后十几位。**sqrt 不是天上掉下来的，它是你刚写的试数循环的极限版**——当步长缩到无穷小时得到的答案。

顺带认识住在同一个工具箱里的两位邻居：`math.e` 是自然常数 e ≈ 2.718——"连续复利"步步逼近的那个极限（第 12 章欧拉公式会讲它为什么重要）；`math.exp(x)` 就是算 e 的 x 次方（等价于 `math.e ** x`，更快更稳）。它们和 `math.sqrt` 一样，`import math` 之后随时取用。

### 实验 4：int() 取整数部分

注意 `math.sqrt(144)` 打印的是 `12.0` 不是 `12`——它一律返回小数。想要干净的整数，请出新帮手：

```python title="int()：砍掉小数尾巴"
import math

side = math.sqrt(144)
print(side)
print(int(side))    # int(...)：取整数部分，直接砍掉小数——注意不是四舍五入
print(int(2.9))     # 证据：2.9 也被砍成 2，而不是 3
```

### 实验 5：画出逼近的足迹

```python title="试数一步步爬向真值"
import math
import matplotlib.pyplot as plt

xs = []
ys = []
best = 0.0
for i in range(1, 200):
    g = i / 100
    if g * g <= 2:
        best = g
    if i % 5 == 0:             # % 是取余数：i 能被 5 整除时记录一次，免得太密
        xs.append(i / 100)
        ys.append(best)

plt.plot(xs, ys, marker="o", markersize=3, label="guess")
plt.axhline(math.sqrt(2), color="tomato", linestyle="--", label="true sqrt(2)")
plt.xlabel("trial value")
plt.ylabel("best so far")
plt.legend()
plt.grid(True)
```

蓝点是"目前的最佳纪录"，红色虚线是真值 $\sqrt{2}$——足迹一格格爬向它然后贴住不动。**逼近是一个过程，sqrt 就是这个过程的终点站。**

### 实验 6（滑块）：二分法——每轮砍掉一半包围圈

实验 1 是一格一格爬：想多一位精度，得多爬十倍的路。聪明些的办法是每次只试包围圈的**正中间**——无论偏大偏小，都能扔掉一半圈子：

```python title="二分逼近根号 2"
# sliders: rounds=3 [1:9:1]

import math

lo = 1.0                    # 包围圈左端：1 的平方比 2 小
hi = 2.0                    # 右端：2 的平方比 2 大
for i in range(rounds):     # 一轮只做一件事：试中点、砍半圈
    mid = (lo + hi) / 2     # 中点是当前唯一的嫌疑犯
    if mid * mid < 2:
        lo = mid            # 中点太小：真根号 2 藏在右半圈
    else:
        hi = mid            # 中点不小：真根号 2 藏在左半圈
    print("第", i + 1, "轮:", lo, "< 根号2 <", hi)   # print 可收多个参数：逗号隔开依次打印

print(math.sqrt(2))         # 官方答案确实被夹在最后的小圈里
```

rounds=3 时圈宽只剩 0.125；拖到 9，圈宽约 0.002——**每加一轮，精度翻一倍**。这种"折半找答案"的策略叫二分法，比逐格试数高效得多；至于"想要某精度需要几轮"的账本，得等对数（本章 40 课）来记。

### 快问快答

```quiz
二分法每试一次中点，包含答案的包围圈宽度会变成？
- 原来的一半 [*]
- 原来的四分之一
- 不变，只是换位置
? 中点把圈切成左右两半，试一次就排除一半。所以提高精度不必从头再试——多拧几轮就行，这正是它比实验 1 快的原因。
```

:::warning[常见误区]

**误区一**："$\sqrt{a+b}=\sqrt a+\sqrt b$。"
拿数字当场戳穿：$\sqrt{9+16}=\sqrt{25}=5$，而 $\sqrt9+\sqrt{16}=3+4=7$。根号不能拆进加法里。

**误区二**："$\sqrt{4}= \pm 2$。"
4 的平方根确实有两个，但符号 $\sqrt{\phantom{x}}$ 按国际约定只指非负那个（所以叫**算术**平方根）。想要负的那个，自己写 $-\sqrt4$。

**误区三**："int() 是四舍五入。"
它是砍断：`int(2.9)` 得 2。真正的四舍五入另有其人（第 2 章 30 节已登场的 round）。需要"最接近的整数"时用 round，需要"只要整数部分"时用 int。

:::

**练习 2**：不用 math.sqrt，用试数法把 $\sqrt{10}$ 逼到两位小数。

<details>
<summary>点开查看逐步解答</summary>

```python
best = 0.0
for i in range(300, 400):      # 心算锁定范围：3.1 到 3.2 附近，减少无效尝试
    g = i / 100
    if g * g <= 10:
        best = g
print(best)                    # 3.16，因为 3.16^2 = 9.9856 < 10 < 3.17^2
```

先估范围再动手，能少试几百次——"缩小包围圈"本身就是重要的数学动作。

**练习 3**：判断并说理由："开平方一定让数变小。"拿几个数试试再下结论。

<details>
<summary>点开查看逐步解答</summary>

对大于 1 的数成立：$\sqrt{9}=3<9$。但 $0<a<1$ 时反号：$\sqrt{0.25}=0.5>0.25$，开方反而变大！

```python
import math
for a in [0.04, 0.25, 1, 9]:
    print(a, "→", math.sqrt(a))
```

直觉有适用范围——这是"多跑几组数"教给我们的事。
</details>

## 7. 选读：为什么 $\sqrt{2}$ 不是分数？

<details>
<summary>选读 · 一类新数字的出生证明</summary>

假设 $\sqrt{2}$ 可以写成分数 $\frac{p}{q}$（已约到最简）。两边平方：$p^2 = 2q^2$，于是 $p^2$ 是偶数，从而 p 必须是偶数（奇数的平方还是奇数）。设 $p = 2r$，代入得 $4r^2 = 2q^2$，即 $q^2 = 2r^2$，于是 q 也是偶数。p、q 都是偶数，与"已约到最简"矛盾。

所以 $\sqrt{2}$ 写不成任何分数——它是无限不循环的小数。传说毕达哥拉斯学派发现此事时大为震惊（他们相信"万物皆可用整数之比表达"），甚至将泄密者投入大海。这类数后来被称为**无理数**，它们不是秩序的破坏者，而是数轴上一直都在、只是迟迟未被命名的居民。

</details>
