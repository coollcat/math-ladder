# 分数指数：开一般次方

## 1. 从一个场景开始

$x^2$、$x^3$ 都好理解——指数是数出来的次数。可计算器上赫然写着 $9^{0.5} = 3$：**"半次方"是什么鬼？** 半个 9 自乘？这句话目前根本不通。

先别急着接受规定。下一节你会看到：一条你已经认识的旧规则会亲自逼出一个唯一答案——分数指数不是谁拍脑袋发明的，它是**被数学自己挤出来的**。

## 2. 直觉解释

回忆第 10 节的规则：同底数幂相乘，指数相加。现在大胆假设 $x^{0.5}$ 有意义，问它必须等于什么：

$$x^{0.5} \times x^{0.5} = x^{0.5+0.5} = x^1 = x$$

**谁自乘之后是 x？**——正是上一课的 $\sqrt{x}$！所以想让"指数相加"继续成立，就只剩一个选择：

$$x^{0.5} = \sqrt{x}$$

和第 10 节选读里 $a^0=1$ 的剧情一模一样：不是我们规定它如此，而是**旧规律不允许第二种可能**。负数、零次幂、分数指数——数系的每一次扩张都是这同一个故事。

## 3. 正式定义

对 $x \ge 0$：

$$x^{1/n} := \sqrt[n]{x}, \qquad x^{m/n} := \left(\sqrt[n]{x}\right)^{m}$$

| 记号 | 读法 | 含义 |
| --- | --- | --- |
| $x^{1/2}$ | x 的二分之一次方 | $\sqrt{x}$，开平方 |
| $x^{1/3}$ | x 的三分之一次方 | 开立方：三次自乘回到 x |
| $x^{m/n}$ | x 的 n 分之 m 次方 | 先开 n 次方，再 m 次方 |

Python 里照旧用 `**` 写：`x ** 0.5` 就是 $\sqrt x$。

一个边界说明：这里先把底数限制在 $x \ge 0$，因为这样每个分数指数都在实数里连续且唯一。奇数次方根以后可以扩展到负底数（比如 $\sqrt[3]{-8}=-2$）；而负底数配任意小数指数会走进复数世界，第 12 章再接住它。

## 4. 分步例题

**例 1**：$9^{0.5} = \sqrt 9 = 3$。

**例 2**：$8^{1/3} = 2$，因为 $2\times2\times2=8$（开立方）。

**例 3**：$16^{0.75} = 16^{3/4}$
1. 分母说"开四次方"：$\sqrt[4]{16}=2$（因为 $2^4=16$）
2. 分子说"再立方"：$2^3=8$
3. 所以 $16^{0.75}=8$

**例 4**：$4^{1.5} = 4^{3/2} = (\sqrt4)^3 = 2^3 = 8$。小数指数先化成分数再动手。

把滑块 p 从 0.5 一路拖到 3，曲线连续变形：p=0.5 是躺平的根号曲线；p=1 变成直线 $y=x$（不多不少的中间站）；p=2 立起成抛物线；p=3 更陡。**指数就是曲线的陡度旋钮**——而且它不只是整数档位，是连续可调的。

### 实验 2：与 math.sqrt 对照验收

上一课刚诞生的 `math.sqrt` 正好当裁判：

```python title="x ** 0.5 和 sqrt 是同一件事"
import math

for x in [2, 4, 9, 16, 100]:
    a = x ** 0.5               # 幂运算配小数指数：分数指数的直接实现
    b = math.sqrt(x)           # 上一课诞生的官方开方器
    print(f"x={x}: x**0.5={a}, sqrt={b}, 相等吗 {a == b}")
```

每一行都打印 True——两种写法殊途同归。

### 实验 3：旧规则在分数世界依然灵验

```python title="指数相加的规则不挑指数的出身"
import math

for x in [2, 5, 10]:
    product = (x ** 0.5) * (x ** 0.5)
    print(f"x={x}: 平方根自乘 = {product}")
```

乘积全部回到 x 本身（浮点误差在小数末梢）。这正是定义的来源：$x^{0.5}\cdot x^{0.5}=x^{0.5+0.5}=x^1=x$。

### 快问快答

```quiz
x^(1/3) 表示的是？
- x 除以 3
- 三次自乘后恰好等于 x 的那个数 [*]
- x 自己乘 3
? 定义说 x^(1/n) 是 n 次方根：n 个它连乘回到 x。比如 8^(1/3) = 2，因为 2×2×2 = 8。它是开方记号，跟除法是两回事。
```

:::warning[常见误区]

**误区一**："$x^{0.5} = x / 2$。"
指数 0.5 是"开平方"，不是"除以 2"。$9^{0.5}=3$ 而 $9/2=4.5$，差得远。记号里的数是**次数**，不是除数。

**误区二**："负数也能开平方，大不了得个负数呗。"
不行：任何实数自乘都非负，所以 $\sqrt{-4}$ 在实数范围内无解，`math.sqrt(-4)` 会直接报错。这个坑要等到复数（第 12 章）才填上。

**误区三**："指数律对所有运算都管用，比如 $x^{0.5} + x^{0.5} = x^1$。"
指数相加的规律只属于**乘法**。加法这边老老实实合并同类项：$x^{0.5}+x^{0.5}=2\,x^{0.5}$。别让新知识越界。

:::


**练习 2**：计算器验证 $64^{1/3}$ 时会看到 3.9999999999999996 这样的尾巴。运行下面代码，解释为什么。

<details>
<summary>点开查看逐步解答</summary>

```python
print(64 ** (1 / 3))
```

数学上的 $\sqrt[3]{64}$ 分毫不差地等于 4；可 `1/3` 在二进制浮点里存的是近似值（0.333...3 略有偏差），拿这个近似指数去算幂，结果就带出了小尾巴。这是**浮点数的本性**而非数学出错。第 2 章 30 节讨论过十进制下的同类现象。
</details>

**练习 3**：不用查表，只用"自乘验算"，判断 $32^{0.2}$ 是否等于 2。

<details>
<summary>点开查看逐步解答</summary>

$0.2 = 1/5$，所以问题是"谁五次自乘得到 32"。验算：$2^5 = 32$ ✓，所以 $32^{0.2}=2$。

```python
print(2 ** 5 == 32)
print(32 ** 0.2)     # 这次恰好显示干净的 2.0
print(64 ** (1 / 3)) # 换成 64 的立方根，就看到练习 2 的浮点尾巴
```

分数指数的计算可以完全化归为"底数的整数次幂是否命中目标"——乘方是开方的验钞机。
</details>

## 7. 选读：为什么"被逼出来"是一种证明？

<details>
<summary>选读 · 定义的一致性与唯一性</summary>

严格地说，我们上面的推理是：若要 $x^{m+n}=x^m x^n$ 对所有有理数成立，则 $x^{1/2}$ **只能**定义为 $\sqrt x$——这叫**唯一性**。但还欠一步：这样定义之后，规则真的处处成立吗？（会不会顾此失彼？）

答案是肯定的，验证思路是化为整数：$x^{a/b} \cdot x^{c/d} = (\sqrt[b]{x^a})(\sqrt[d]{x^c})$，通分成同次根后恰等于 $x^{(ad+bc)/bd}$。每一步只用整指数规律与根式性质，于是"指数相加"在整个有理数集上无缝衔接。

数学家扩张一个体系时的标准动作就这两步：**唯一性**（只有一种改法不破坏旧规则）与**一致性**（改完之后新旧场合全部兼容）。负数、零次幂、分数指数，乃至将来的复数，全是这套流程的重复播放。

</details>
