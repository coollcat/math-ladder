# 负整数指数幂：倒数换座位

## 1. 从一个场景开始

乘方课里，细胞每 20 分钟分裂一次，数量一路 $2, 4, 8, 16,\dots$ 往上翻。现在看反面：一片药的浓度进入身体后**每 4 小时减半**，一路 $1, \frac12, \frac14, \frac18,\dots$ 往下退。

翻倍我们有记号 $2^n$；减半翻下去，指数就得一路减到 0 以下——$2^{-1}$、$2^{-2}$ 这种写法冒了出来。「2 的负 2 次方」听着像"负的平方"，等于 $-4$ 吗？大错特错——它是 $0.25$。负号搬到指数的位置上，意思整个变了：它不是"变负"，而是一道**换座位**的指令。

## 2. 直觉解释

乘方课的选读修过一段台阶：$2^3 = 8 \to 2^2 = 4 \to 2^1 = 2 \to 2^0 = 1$——每往右一格，指数减 1、值除以 2。台阶没有理由停在 0，让它继续走：

$$2^{-1} = 1 \div 2 = \frac12, \qquad 2^{-2} = \frac14, \qquad 2^{-3} = \frac18$$

台阶走到 0 的右边，就从"越走越高"翻转为"越走越矮"——**负指数是台阶向左的自然延续**，不是新发明，是旧规律继续运转。

换个角度看这个负号：$2^{-3} = \frac{1}{2^3}$——分子上的 $2^3$ 被**换到了分母**，指数由负转正。负号就是"换座位"的手势：座位从分子换到分母，符号随之翻正。第 2 章的老朋友"倒数"也在这里返场：$2^{-1} = \frac12$ 正是 2 的倒数，而 $a^{-n} = \left(\frac{1}{a}\right)^n$——负 n 次方就是"连倒 n 次"。

## 3. 正式定义

对 $a \ne 0$ 和正整数 $n$，规定：

$$a^{-n} = \frac{1}{a^n}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a^{-n}$ | a 的负 n 次方 | $a^n$ 的倒数 |
| $a \ne 0$ | 底数非零 | 0 没有倒数，0 的负次幂无意义 |
| $\frac{1}{a^{-n}} = a^n$ | 换座位可逆 | 座位换回去，符号翻回来 |

顺手把指数律的另一半也补上。乘方课给过"同底数幂相乘，指数相加"；除法这边是对称的——**同底数幂相除，指数相减**：

$$\frac{a^m}{a^n} = a^{m-n}$$

$m - n$ 算出负数完全合法——负指数从此不再是一条孤零零的"规定"，而是指数律的**必然后果**（选读给出完整推理）。

## 4. 分步例题

**例 1**：把 2 的幂台阶从 $2^3$ 写到 $2^{-3}$。

$2^3 = 8 \to 2^2 = 4 \to 2^1 = 2 \to 2^0 = 1 \to 2^{-1} = \frac12 \to 2^{-2} = \frac14 \to 2^{-3} = \frac18$。

每往右一格除以 2；分母上的 $2, 4, 8$ 又是一段向下的"正指数台阶"。负指数的世界里住的全是分数，但没有一个是负数。

**例 2**：化简负指数幂。

1. $5^{-2} = \frac{1}{5^2} = \frac{1}{25}$（换座位：$5^2$ 下到分母）；
2. $(-2)^{-3} = \frac{1}{(-2)^3} = -\frac{1}{8}$（先按老规矩算 $(-2)^3 = -8$，再取倒数——奇数次幂的负号保留）；
3. $\frac{1}{10^{-2}} = 10^2 = 100$（座位换回去，符号翻正）。

**例 3（应用：科学计数法的小数端）**：把 0.003 写成"a × 10 的幂"。

1. 小数点向右挪，每挪一位乘 10：挪 **3** 位才变成 3；
2. 向右挪是乘 $10^3$，反过来说明 0.003 是 3 缩小 $10^3$ 倍：$0.003 = 3 \times 10^{-3}$；
3. 验收：$3 \times 10^{-3} = \frac{3}{1000} = 0.003$ ✓。

大数向左挪小数点，阶码是正的；小数向右挪，阶码就是负的——同一张"数量级名片"的两面。本章 50 课会正式给这套写法起名字（科学计数法），那里定义的阶码 n 写明是"整数"——负的那一半，刚才你已经会了。

### 实验 1（viz）：负半轴上的台阶

右半边是我们熟悉的爆炸增长；把视线移到纵轴左边——曲线一头扎向地面，越往左越贴，却**永远不碰**横轴。负指数的地盘里没有负数，只有越来越小的正数。

### 实验 2（viz）：把翻倍台阶拧反方向

```viz
{
  "type": "seq",
  "kind": "geom",
  "a1": 1,
  "r": 0.5,
  "n": 8

```

乘方课玩过的等比数列柱子，把倍率 r 从 2 拧到 0.5：爆炸当场变坍缩，柱子一格格矮下去——每矮一级就是指数往负的方向走一步。r < 1 时"越乘越小"，负指数把这条路走到了底。

### 实验 3：幂的台阶向左延伸

```python title="从 2^3 走到 2^-3"
for k in [3, 2, 1, 0, -1, -2, -3]:   # 列表里混进了负数：负的就是今天的主角
    print(f"2 的 {k} 次方 = {2 ** k}")   # ** 遇到负指数：不用装新语法，它直接认得
```

输出里 $2^0 = 1$ 站在正负的分界线上；再往右全是分数 $0.5, 0.25, 0.125$——与例 1 的手算台阶完全对齐。

### 实验 4：指数律对负指数也守约

```python title="新旧指数同台，规律不变"
left = pow(2, -2) * pow(2, 5)    # pow(a, n)：乘方课出生的内置函数，负指数也认
right = pow(2, 3)
print(left)            # 0.25 × 32
print(right)           # 8
print(left == right)   # 指数 -2 + 5 = 3：指数相加，分毫不差
```

输出 `True`——"指数相加"这条规律不分正负、一视同仁。这正是负指数合法性最强有力的背书（选读把它说全）。

### 实验 5（应用）：小数端科学计数法

```python title="0.003 = 3 × 10 的负 3 次方"
print(3 * 10 ** -3)     # 10 ** -3 是 0.001，乘 3 还原 0.003
print(7 * 10 ** -4)     # 同款：7 个 0.0001
```

两行分别输出 `0.003` 与 `0.0007`。小数端名片与 50 课的大数端名片拼在一起，10 的幂才算把数轴两头都管上了。

### 快问快答

```quiz
2 的负 2 次方等于多少？
- -4
- 0.25 [*]
- 4
? 指数上的负号是换座位指令，不是变负指令：2 的负 2 次方 = 1 除以 2 的 2 次方 = 0.25。底数为正时，负指数的结果全是正的分数。
```

::::warning[常见误区]

**误区一**："$2^{-2}$ 是负数，等于 $-4$。"
恰恰相反：$2^{-2} = \frac14 = 0.25$，是正的。底数为正，幂永远为正——指数上的负号只管"换座位"，不管"变符号"。

**误区二**："$a^{-n} = -(a^n)$。"
同一个坑的精确版：负号想改变正负，得待在数字前面（$-a^n$）；待在指数上，它只负责把 $a^n$ 搬进分母。

**误区三**："0 的负次幂也照算，$0^{-1} = 0$。"
$0^{-1} = \frac{1}{0^1} = \frac{1}{0}$——除以 0 没有意义。0 没有倒数，所以 0 的负指数幂无定义：底数非零是本课一切公式的入场券。

::::

## 6. 练习

**练习 1（判题）**：打印 $2^{-3}$，以及它的座位换回去的结果 $\frac{1}{2^{-3}}$。下面的代码能跑，但方向弄反了，改到通过：

```exercise
# @title: 练习：换座位
# @check: 0.125
# @check: 8.0
# @hint: 负号是换座位指令：2 ** -3 = 1/8；而 1 / 2 ** -3 把座位再换回去，结果回到 8
print(2 ** 3)
print(1 / 2 ** 3)
```

初始代码两行都是正指数，输出 8 和 0.125。把指数都添上负号——第一行换进分母变 0.125，第二行换出分母回到 8.0。一来一回，正好体验"换座位"的双向性。

<details>
<summary>点开查看逐步解答</summary>

```python
print(2 ** -3)      # 1/8 = 0.125：座位换到分母
print(1 / 2 ** -3)  # 1 ÷ (1/8) = 8.0：座位再换回去
```

第二行顺带验证了换座位的可逆性：$\frac{1}{a^{-n}} = a^n$ ✓。
</details>

**练习 2**：先猜再验：$(-2)^{-3}$ 等于多少？写出推理，再用一行代码验证。

<details>
<summary>点开查看逐步解答</summary>

先按老规矩算底数那边：$(-2)^3 = -8$（负底数奇数次幂为负）；再换座位取倒数：$(-2)^{-3} = -\frac18$。

```python
print((-2) ** -3)   # -0.125：负号来自底数，与指数上的负号无关
```

结果 $-0.125$ 是负的——但注意：让它变负的是**底数**的奇数次幂，指数上的负号只负责分数化。
</details>

**练习 3**：把 0.0007 写成 a × 10 的幂（a 介于 1 和 10 之间），并用代码验证。

<details>
<summary>点开查看逐步解答</summary>

小数点向右挪 **4** 位才变成 7，所以 $0.0007 = 7 \times 10^{-4}$。

```python
print(7 * 10 ** -4)   # 0.0007
```

输出与原数一模一样 ✓。规律总结：小数点向右挪几位，阶码就是负几——这和 50 课"大数向左挪几位，阶码就是正几"是同一条规则的两个方向。
</details>

## 7. 选读：为什么负指数是"别无选择"的？

<details>
<summary>选读 · 让指数律对一切整数成立</summary>

可以把 $a^{-n}$ 当成随便什么数 x 吗？不行——只要"同底数幂相乘，指数相加"想对**一切**指数成立，x 就被锁死了：

设 $x = a^{-n}$。那么 $a^n \times x$ 应当等于 $a^{n+(-n)} = a^0 = 1$（乘方课选读逼出的结论）。而"乘积为 1"意味着 x 只能是 $a^n$ 的倒数：$x = \frac{1}{a^n}$。没有第二种可能。

除法这边同样丝滑：按"同底数幂相除，指数相减"，$\frac{2^3}{2^5} = 2^{-2}$。直接硬算：$8 \div 32 = \frac14 = 2^{-2}$ ✓——两套动作殊途同归。

最后看 0 为什么救不回来：想让 $0^n \times x = 1$，就得让 0 乘一个数等于 1——但 0 乘任何数都是 0。所以负指数的世界必须把 0 拒之门外：**不是规定苛刻，是逻辑上无路可走**。

</details>
