# 三条曲线：谁长得快

## 1. 从一个场景开始

三位选手已在前几课登场：$y=x^2$（平方，越跑越快）、$y=\sqrt{x}$（开方，先猛后疲）、$y=2^x$（翻倍，每一步都复制自己）。

单看谁都正常。放进同一场比赛就出怪事：**开局垫底的翻倍选手，最终会甩开平方整整一个宇宙**——不是赢一点，是让其他人的数字小到没有意义。"指数碾压一切"这句话，值得你亲眼看着它发生。

## 2. 直觉解释

三条曲线的性格速写：

| 曲线 | 性格 | 生活原型 |
| --- | --- | --- |
| $y=x^2$ | 稳步加速，后劲来自"底数自己变大" | 越滚越大的雪球 |
| $y=\sqrt{x}$ | 开局最陡，随后越来越懒 | 刚开工干劲十足、逐渐摸鱼的活儿 |
| $y=2^x$ | 每走一步整体翻倍 | 利滚利、细胞分裂 |

关键区别在**机制**：平方和开方的每一步增量由 x 决定，而 $2^x$ 的每一步增量由**上一步的结果**决定——它拿全部家当下注。这种"自我繁殖"的结构，就是碾压的种子。

## 3. 正式观察语言

比较增长快慢 = 在同一个 x 处比较函数值的大小。"终将碾压"的准确含义：

$$\text{存在某个 } X,\ \text{使得 } x > X \text{ 之后恒有 } 2^x > x^2$$

注意措辞：不是"每一步都领先"，而是"**从某处起永远领先且差距拉大**"。前半程谁领先完全不重要——这是本课最重要的观念转变。

## 4. 分步例题

追踪 $x^2$ 与 $2^x$ 的战况：

1. $x=2$：$4$ 对 $4$，平手；
2. $x=3$：$9$ 对 $8$，**平方领先**；
3. $x=4$：$16$ 对 $16$，又平手；
4. $x=5$：$25$ 对 $32$，**指数首次反超**；
5. 此后再未交手：$64<256$，$100<1024$，……反超点在 $x\approx 4$ 附近，之后永不回头。

为什么永不回头？因为从这一刻起，翻倍的"新收入"（每次多出一整个 $2^x$）已经超过平方的"涨工资速度"——富者愈富，机制锁定胜局。

### 实验 1（viz）：同尺度赛跑与关键点探查

四位选手终于进同一个赛场。纵轴按当前“范围”自动定标，所以这不是四张各自舒服的小图，而是同一把尺子下的硬比较：

```viz

  "title": "同尺度增长赛跑",
  "range": 6,
  "probe": 4
}
```

先拖“探针”到 $x=2,3,4$，读数面板会把每条曲线的值和当前领先者报出来；两个红点就是 $2^x$ 与 $x^2$ 的交点。再把“范围”从 6 拧到 12：平方曲线很快被压成贴近地板的矮影，$\sqrt{x}$ 和对数几乎消失——这正是“终将碾压”在零等待画布里的样子。

### 实验 2：matplotlib 局部回放

```python title="全景与回放"
import math
import matplotlib.pyplot as plt

xs, sq, rt, ex = [], [], [], []    # 一次建四个空列表：x、平方、根号、翻倍
for i in range(41):
    x = i / 4                      # 步长 0.25，从 0 取样到 10
    xs.append(x)
    sq.append(x * x)
    rt.append(math.sqrt(x))
    ex.append(2 ** x)

for x in [2, 3, 4, 8, 10]:
    print(f"x={x}: 平方 {x * x} vs 翻倍 {pow(2, x)}")

fig, axes = plt.subplots(1, 2, figsize=(11, 3.8))   # 一行两列两张子图

axes[0].plot(xs, sq, label="y = x^2")
axes[0].plot(xs, rt, label="y = sqrt(x)")
axes[0].plot(xs, ex, label="y = 2^x")
axes[0].legend()
axes[0].grid(True)
axes[0].set_title("full: 0 to 10")

axes[1].plot(xs, sq, label="y = x^2")
axes[1].plot(xs, ex, label="y = 2^x")
axes[1].set_xlim(1, 5)             # 放大交点附近：两次追平、一次反超
axes[1].set_ylim(0, 40)
axes[1].legend()
axes[1].grid(True)
axes[1].set_title("zoom: the crossover")
```

右图放大了决胜瞬间：两条线在 x=2 与 x=4 两度相遇，随后分道扬镳再不相见。左图里 sqrt 曲线几乎贴地——它不是没在长，是被同框的巨人衬成了地板。

a=2 时两线纠缠着两次相遇（第 4 节战报里的 x=2 与 x=4）。慢慢拧大 a：反超来得越来越早、差距拉开越来越狠；反向拧到 1.2：画面最左边一小段仍是蓝线在上，两线恰好在 x=1.2 处相遇，随后橙线一路压住蓝线——真正的反超交点被挤到 x≈19.6，远在画面之外。**底数越小，碾压来得越晚；但只要 a>1，它就一定会来**——练习 3 会让你用 $1.5^x$ 亲手验证这个结论。

### 实验 4：用对数丈量差距

math.log 正好能量化"翻倍选手"的恐怖：

```python title="追上一百万各需多大代价"
import math

target = 1000000
print(f"x^2 追到一百万：需要 x = {math.sqrt(target)}")        # 1000
print(f"2^x 追到一百万：只需翻倍 {math.log(target, 2)} 次")   # 约 19.93
```

平方要跑到 1000 才够到一百万，翻倍只要约 20 步——**对数就是量"翻倍次数"的尺子**，上一课的工具在这里严丝合缝地接上了。

### 快问快答

```quiz
当 x 无限增大时，最终值最大的是哪条曲线？
- y = x^2，因为前期它经常领先
- y = x^0.5，因为它起步最陡
- y = 2^x，因为每步整体翻倍 [*]
? 前期领先说明不了结局。2 的 x 次方每一步都把全部身家翻一倍，一旦超过对手便永不回头——实验 2 的右图亲眼可见。
```

:::warning[常见误区]

**误区一**："开局领先的会一直领先。" 
sqrt 起步最陡却最先垫底；平方在 x=3 时还压着指数打。赛程越长，**机制**越比**起点**重要——投资、学习、技术积累同理。

**误区二**："看图就能断定以后谁在上面。" 
画布只有 10 宽，画外的事靠推理不靠瞪眼。这组曲线能说"永不回头"，是因为有第 7 节的机制论证，而不是图好看。

**误区三**："碾压只是险胜。" 
差得远：x=60 时 $2^{60}$ 约 $1.15\times10^{18}$，而 $60^2=3600$——相差十五个数量级。碾压的意思是让对手的存在失去意义。

:::

**练习 2**：把 $\log_2 x$ 加进同框图里，凑齐四位选手。

<details>
<summary>点开查看逐步解答</summary>

```python
import math
import matplotlib.pyplot as plt

xs, sq, rt, ex, lg = [], [], [], [], []
for i in range(41):
    x = i / 4
    if x >= 1:                     # log 只对正数有定义，跳过 0 附近
        xs.append(x)
        sq.append(x * x)
        rt.append(math.sqrt(x))
        ex.append(2 ** x)
        lg.append(math.log(x, 2))

plt.plot(xs, sq, label="x^2")
plt.plot(xs, rt, label="sqrt(x)")
plt.plot(xs, lg, label="log2(x)")
plt.plot(xs, ex, label="2^x")
plt.legend()
plt.grid(True)
```

四条曲线正好排成一条"增长速度链"：$\log_2 x < \sqrt{x} < x^2 < 2^x$。对数是最慢的那个——毕竟它是翻倍的反向操作。
</details>

**练习 3**：把 $2^x$ 换成 $1.5^x$ 再比一次：还会碾压吗？反超点推迟到哪里？

<details>
<summary>点开查看逐步解答</summary>

```python
for x in range(2, 40):
    if 1.5 ** x > x * x:
        print(f"1.5 的 {x} 次方首次反超 x 的平方")
        break                      # break：提前跳出循环
```

答案是 13。循环从 2 开始，是为了跳过 $x=1$ 那次还没落入平方领先区间的假反超；真正值得看的是“平方压住指数以后”的重新反超。底数从 2 缩水到 1.5，反超点从 4 推迟到 13——但**只要底数大于 1，碾压迟早到来**，只是晚点到。真正不会碾压的是底数恰好为 1：$1^x$ 永远原地踏步。
</details>

## 7. 选读：为什么指数必然碾压多项式？

<details>
<summary>选读 · 一场不对称的军备竞赛</summary>

看每一轮的"增长率"。对 $2^x$：下一轮除以本轮，$\dfrac{2^{x+1}}{2^x}=2$——增速恒定，永远是 2 倍。

对 $x^2$：$\dfrac{(x+1)^2}{x^2} = 1 + \dfrac{2}{x} + \dfrac{1}{x^2}$——增速随 x 变大而**退化趋向 1**（只比原地踏步好一点点）。

一边恒定 2，一边滑向 1：两军比值 $\frac{2^x}{x^2}$ 每轮至少乘上接近 2 的系数，一旦越过 1 就加速远离，永无归期。任何固定次数的多项式都一样下场；换成 $3^x$ 或 $1.1^x$ 只是改变反超时刻，不改变结局。

这就是计算机科学把算法分成"多项式级"和"指数级"的原因：前者可救，后者神仙难救。第 8 章讲完数列后，这套论证可以写成严格的归纳证明。

</details>
