# 幂函数族：指数固定，底数在动

## 1. 从一个场景开始

一块正方形铁皮，边长 $x$ 决定面积 $y=x^2$；换成一枚正方体铁块，棱长 $x$ 决定体积 $y=x^3$；再看一根弹簧，拉伸量 $x$ 与弹力 $y$ 成正比，$y=kx$。

三件事八竿子打不着，式子却是同一个模子刻出来的：**底数在变，指数站在旁边不动。** 上一课我们把指数调成了连续旋钮，这一课换一个方向——把指数钉死，看底数自由变化时，图像会连成一族什么样的曲线。

## 2. 直觉解释

对照着看两组式子最清楚：

- $y = x^2$：指数 2 固定，$x$ 在动——这是**幂函数**；
- $y = 2^x$：底数 2 固定，$x$ 在动——这是**指数函数**（上一课的主角）。

名字本身就是提示牌：**"幂函数"固定的是"几次幂"，"指数函数"固定的是"谁是底数"。** 谁坐在字母位置上、谁被写成常数，决定了函数长什么样。

把指数换成不同的常数 $a$，就得到一整族曲线：$a=1$ 是直线，$a=2$ 是抛物线，$a=3$ 更陡，$a=-1$ 是两支双曲线，$a=\frac12$ 是我们熟悉的根号曲线。它们的公共点少得出人意料——而正是这些少的公共点，把"幂函数"认成了一个家族。

## 3. 正式定义

**幂函数**：形如

$$y = x^{\alpha} \quad (\alpha \text{ 为常数})$$

的函数叫幂函数，其中 $x$ 是自变量，$\alpha$ 是固定的指数。**幂函数只要求底数是自变量，对常数 $\alpha$ 几乎不设限。**

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $x$ | 底数（自变量） | 动的那一项，取值范围受 $\alpha$ 限制 |
| $\alpha$ | 指数（常数） | 不动的那一项，可以取负数、分数 |
| $y$ | 幂值 | 函数值 |
| 定点 | $(1,1)$ | $1^{\alpha}=1$ 对任何 $\alpha$ 成立，曲线必过此点 |
| $\alpha > 0$ | — | 曲线还过 $(0,0)$，在 $[0,+\infty)$ 上递增 |
| $\alpha < 0$ | — | 曲线以两坐标轴为渐近线，在 $(0,+\infty)$ 上递减 |

**定义域随 $\alpha$ 而变**，这是幂函数最容易翻车的地方。把 $\alpha$ 写成分数，一眼就能看穿：

| $\alpha$ 的形式 | 例 | 定义域 |
| --- | --- | --- |
| 正整数 | $x^2,\ x^3$ | $\mathbb{R}$（全体实数） |
| 负整数 | $x^{-1}=\frac1x$ | $x \neq 0$ |
| $\frac{1}{n}$，$n$ 为奇数 | $x^{1/3}=\sqrt[3]{x}$ | $\mathbb{R}$ |
| $\frac{1}{n}$，$n$ 为偶数 | $x^{1/2}=\sqrt{x}$ | $x \ge 0$ |
| $\frac{m}{n}$（最简），$n$ 为偶数 | $x^{1/2}$ 这一型 | $x \ge 0$ |
| $\frac{m}{n}$（最简），$n$ 为奇数 | $x^{2/3}$ | $\mathbb{R}$ |

一句话记住：**分母是奇数就管得住负数，分母是偶数就只能管非负数**——正是上一课"奇偶分母"那条规矩搬到了定义域上。

## 4. 分步例题

**例 1（五条典型曲线同框）**：在第一象限里看 $y=x$、$x^2$、$x^3$、$x^{-1}$、$x^{1/2}$。

1. 五条曲线都过 $(1,1)$，因为 $1$ 的任何次方都是 $1$；
2. $x \to 0^+$ 时：$x,\ x^2,\ x^3,\ x^{1/2}$ 都从原点出发，只有 $x^{-1}$ 一头扎向 $+\infty$，贴着两轴飞走；
3. 在 $x>1$ 的**右段**：曲线按 $x^3 > x^2 > x > x^{1/2} > x^{-1}$ 从高到低排开——**指数越大，右段爬得越高**；
4. 在 $0<x<1$ 的**左段**：顺序整个倒过来，$x^{-1} > x^{1/2} > x > x^2 > x^3$——**指数越大反而越小**。

**例 2（判定义域）**：写出下列幂函数的定义域。

1. $y=x^{-2}$：负整数指数，等价于 $\frac{1}{x^2}$，要求 $x \neq 0$；
2. $y=x^{1/3}$：分母 3 为奇，可以开负数，定义域是 $\mathbb{R}$；
3. $y=x^{2/3}$：$2/3$ 最简且分母为奇，$\mathbb{R}$；
4. $y=x^{3/2}$：分母 2 为偶，$x \ge 0$。

**例 3（比大小，左段）**：不查表，比较 $0.5^{1/2}$ 与 $0.5^{2}$。

1. 底数 $0.5$ 落在 $(0,1)$ 里，记住"左段反序"；
2. 指数 $\frac12 < 2$，在左段里指数小的反而大；
3. 所以 $0.5^{1/2} > 0.5^{2}$。验算：$\sqrt{0.5}\approx0.707$，$0.5^2=0.25$，果然。

**例 4（比大小，右段）**：比较 $1.5^{1/2}$ 与 $1.5^{2}$。

1. 底数 $1.5 > 1$，落在"右段正序"；
2. 指数 $\frac12 < 2$，指数大的更大；
3. 所以 $1.5^{2} > 1.5^{1/2}$。

### 实验 1（viz）：拖动指数，看整族曲线变形


拖动滑杆 $a$，盯住三件事：① 所有曲线都在 $(1,1)$ 交汇，这是它们的"公共车站"；② $a>0$ 的曲线从原点附近升起，$a<0$ 的曲线从左上角俯冲下来；③ 把 $a$ 从小推到大，$x>1$ 那侧越来越高，$x<1$ 那侧越来越低。

### 实验 2（python）：两段结论真的相反

```python
exponents = [-1, 0.5, 1, 2, 3]      # 五个典型指数：负整数、分数、正整数
for x in [0.5, 2]:                  # 一个小于 1 的底数，一个大于 1 的底数
    print(f"x = {x}")
    for a in exponents:             # 对每个指数各算一次幂
        print(f"  a = {a}: x^a = {x ** a}")
```

$0.5$ 那一组里，$a$ 从 $-1$ 涨到 $3$，输出一路下跌（$2 \to 0.125$）；$2$ 那一组里，同样这几个 $a$ 让输出一路上涨（$0.5 \to 8$）。**同一条曲线族，落在 1 的左边还是右边，结论完全相反**——这就是例 1 第 3、4 步在数字上的复现。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为幂函数的定义域永远是全体实数。" 其实要看指数。$x^{1/2}$ 只能喂非负数（负数开偶次方在实数里没有答案），$x^{-1}$ 不能喂 $0$。**先化成分数、看分母奇偶，再定定义域。**

**误区二**："你以为 $y=x^0$ 也是一条正经的幂函数曲线。" $x^0=1$（$x\neq0$）是一条水平直线，既不过原点，也谈不上左右两段。本书讨论幂函数时默认 $\alpha \neq 0$，先把它请出房间。

**误区三**："你以为指数越大，函数值一定越大。" 这话只在 $x>1$ 时成立。在 $0<x<1$ 上恰好反序：$0.5^3 < 0.5^2$。**比大小先看底数在 1 的哪一侧，再决定顺序要不要翻。**

:::

**练习 2**：写出 $y=x^{-2}$、$y=x^{1/3}$、$y=x^{3/2}$ 的定义域，并用 Python 各取一个"可能出问题"的点验证。

<details>
<summary>点开查看逐步解答</summary>

1. $y=x^{-2}=\frac{1}{x^2}$：$x \neq 0$；
2. $y=x^{1/3}=\sqrt[3]{x}$：分母为奇，全体实数 $\mathbb{R}$；
3. $y=x^{3/2}=(\sqrt{x})^3$：分母为偶，$x \ge 0$。

`**` 遇到非法输入会直接报错或改走复数，正好当定义域的探测器：

```python
print(2 ** (-2))      # 0.25：x>0 一切正常
print(0 ** (-2))      # 会报 ZeroDivisionError：x=0 正是被排除的那个点
print((-8) ** (1/3))  # 负数配分数指数会给出复数，说明它不在实数定义域里
```

后两行是"反证"式的提示：定义域上**不允许**的那些点，代码一碰就露馅。第 12 章会正式接住复数这个概念。

</details>

## 8. 选读：为什么先只看第一象限

<details>
<summary>选读 · 幂函数的"出身"决定了它在哪半边活着</summary>

$\alpha$ 是一般实数时，$x>0$ 这一侧 $x^{\alpha}$ 总有意义；可 $x<0$ 那一侧要不要，得看 $\alpha$ 到底是谁：

- $\alpha$ 是有理数 $\frac{m}{n}$（最简）时，分母 $n$ 为奇才有实数答案——这是"开奇次方"的特权；
- $\alpha$ 是无理数（如 $\sqrt2$）时，$x<0$ 干脆没有实数定义。

所以负半轴的存活是**个别成员的私人特权**，不是家族的共性。研究幂函数的性质时，习惯先把地点定在第一象限：那里所有成员都活着，比较才有意义。第 6 章讲"函数图像与性质"时，这套"先问定义域、再看图像"的顺序会反复出现。

</details>
