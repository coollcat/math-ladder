# 指数函数与对数函数：一对镜像曲线

## 1. 从一个场景开始

把 1 万元存进一个年利率 8%、利滚利的账户。一年后是 $1.08$ 万，两年后是 $1.08^2$ 万……**x 年后是 $1.08^x$ 万**。注意这里的年数 x 不必是整数：三年零七个月照样有答案。指数位置上的未知数，已经从"数第几次"变成了一个可以连续滑动的旋钮。

反过来问一句：**多久能翻倍？** 这就是在解 $1.08^{?} = 2$，答案是 $\log_{1.08} 2 \approx 9$ 年——上一课那台"答案计数器"。

同一个存钱故事，一正一反两个问题。它们各自对应一条曲线，而这两条曲线互为镜像。这一课就是把这一对镜像钉死在坐标系上。

## 2. 直觉解释

前面几课把指数位置上的数从正整数一路放宽：先是 0，再是负整数（倒数），然后是分数（开方）。走到这一步，指数位置已经能站上任何实数了。**一旦它能连续滑动，$a^x$ 就不再是一串孤立的点，而是一整条连续的曲线**——每给定一个 x，就送出唯一一个 y。这样一台"输入 x、吐出唯一 y 的机器"，就叫**函数**（第 6 章会给这台机器正式命名）。

镜像这件事更妙。回头看上一课的核心动作：$2^3 = 8$ 改写成 $\log_2 8 = 3$，数字没变，是**位置换了**——3 从等号左边的肩膀上跳到了右边。放到坐标里看，就是把点 $(3, 8)$ 搬到了 $(8, 3)$：横纵坐标互换。

而"横纵坐标互换"在图上是什么？是**沿着那条 45° 的对角线照镜子**。把指数曲线上的每一个点都照一遍，照出来的影子连成的曲线，恰好就是对数曲线。

## 3. 正式定义

**定义一（指数函数）**：当 $a>0$ 且 $a\neq 1$ 时，形如

$$y = a^x \quad (x \in \mathbb{R})$$

的函数叫**指数函数**，其中 x 是自变量，a 是常数。

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $a$ | 底数 | 必须 $a>0$ 且 $a\neq 1$：负数底数遇到分数指数会出问题；$a=1$ 时曲线退化成一条平直线 |
| $x$ | 自变量 | 可以取**任意实数**（整数、负数、分数、无理数都行） |
| $y$ | 函数值 | 永远是正数，$y>0$ |
| 定义域 | $\mathbb{R}$ | x 想取什么就取什么 |
| 值域 | $(0,+\infty)$ | y 永远大于 0，取不到 0，也取不到负数 |
| 定点 | $(0,1)$ | 因为 $a^0 = 1$：无论底数是几，x=0 时都过这一个点 |
| 渐近线 | x 轴 | x 越来越小（趋向负无穷）时，y 无限贴近 0 但**永不相交** |
| 单调性 | $a>1$ 递增；$0<a<1$ 递减 | 底数大于 1 越乘越大，小于 1 越乘越小 |

**定义二（对数函数）**：当 $a>0$ 且 $a\neq 1$ 时，形如

$$y = \log_a x \quad (x > 0)$$

的函数叫**对数函数**。它是指数函数 $y=a^x$ 的**反函数**——两个函数把对方的输入输出原样还回去。

两个方向合起来就一句话：

$$a^{\log_a N} = N \quad (N>0) \qquad\qquad \log_a\left(a^{x}\right) = x$$

**对照表**（这是一课里最值得抄下来的一张表）：

| | $y = a^x$ | $y = \log_a x$ |
| --- | --- | --- |
| 定义域 | $\mathbb{R}$（全体实数） | $(0,+\infty)$（真数必须为正） |
| 值域 | $(0,+\infty)$ | $\mathbb{R}$ |
| 定点 | $(0,1)$ | $(1,0)$ |
| 单调性 | $a>1$ 递增，$0<a<1$ 递减 | 跟着底数走：$a>1$ 递增，$0<a<1$ 递减 |
| 渐近线 | x 轴（$y=0$） | y 轴（$x=0$） |
| 两者关系 | 关于直线 $y=x$ 对称 | 关于直线 $y=x$ 对称 |

定义域和值域**正好对调**，这正是"反函数"三个字的字面意思。

## 4. 分步例题

**例 1（描点看指数函数）**：画 $y=2^x$ 的几个点。

1. 取 $x=-2,-1,0,1,2,3$；
2. 逐个数：$2^{-2}=\frac14$，$2^{-1}=\frac12$，$2^0=1$，$2^1=2$，$2^2=4$，$2^3=8$；
3. 得到点 $(-2,0.25)$、$(-1,0.5)$、$(0,1)$、$(1,2)$、$(2,4)$、$(3,8)$；
4. 连成平滑曲线：**恒过 $(0,1)$**，越往右越陡，越往左越贴着 x 轴但永远不碰上它。

**例 2（底数小于 1 时）**：$y=\left(\frac12\right)^x$。

1. 因为 $\left(\frac12\right)^x = 2^{-x}$，它是把 $y=2^x$ 沿 y 轴翻了个面；
2. 所以它**单调递减**：$x$ 越大反而越小，$(0,1)$ 这个定点照样过；
3. 往右它贴着 x 轴，往左它一路冲上天。

**例 3（用镜像读对数）**：不求值，靠对称说出 $y=\log_2 x$ 上的几个点。

1. 指数曲线上的点是 $(0,1)$、$(1,2)$、$(2,4)$、$(3,8)$；
2. 横纵坐标互换：$(1,0)$、$(2,1)$、$(4,2)$、$(8,3)$；
3. 这几个点落在对数曲线上，也就是 $\log_2 1 = 0$、$\log_2 2 = 1$、$\log_2 4 = 2$、$\log_2 8 = 3$；
4. 看趋势：x 从 1 涨到 8（涨了 8 倍），y 才从 0 爬到 3——**对数爬得极慢**，这就是它敢给地震震级当尺子的资本。

**例 4（用恒等式）**：算 $2^{\log_2 5}$。

1. 套用 $a^{\log_a N} = N$，底数同为 2；
2. 直接得 $5$。不用先算出 $\log_2 5 \approx 2.32$ 再去乘方——**同一把底数下，这两件事互为撤销**。

### 实验 3（python）：复利与"多久翻倍"

```python title="复利：涨到多少，与多久翻倍"
import math                                   # 数学工具箱（第 3 章登场）

# sliders: rate=8 [1:30:1], years=10 [1:50:1]

P = 10000                                     # 本金：一万元
growth = 1 + rate / 100                       # 一年的增长因子：利率 8% → 1.08

amount = P * growth ** years                  # 指数函数：底数是因子，指数是年数
print(round(amount, 2))                       # 利滚利 years 年后的钱

doublings = math.log(2) / math.log(growth)    # 对数函数：翻倍需要的年数
print(round(doublings, 2))
```

默认参数输出 `21589.25` 与 `9.01`：一万元按 8% 滚十年变成 2.16 万，翻倍则要 9 年。**同一个式子的两个读法**——问"有多少钱"用指数函数，问"要多久"用对数函数。把 rate 拧到 20，翻倍时间缩到 3.8 年；拧到 2，要 35 年。

### 实验 4（python）：三把对数尺

```python title="半衰期 · 里氏震级 · pH"
import math

# 半衰期：碳-14 每 5730 年剩一半，两万年后还剩百分之几
print(round(100 * 0.5 ** (20000 / 5730), 2))

# 里氏震级：7 级地震的振幅是 5 级的多少倍（震级每差 1，振幅 ×10）
print(round(10 ** (7 - 5), 1))

# pH：pH=2 的溶液比 pH=5 的酸多少倍（pH 每差 1，浓度 ×10）
print(round(10 ** (5 - 2), 1))
```

输出 `8.86`、`100.0`、`1000.0`。三件事看着毫不相干，量它们的却是同一把尺子——**对数**。半衰期里它出现在指数上（衰减），震级和 pH 里它本身就是读数（把"差多少倍"压成"差几级"）。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为底数 a 只要不是 0 就行。" 其实必须 $a>0$ **且** $a\neq 1$。$a\le 0$ 时，像 $a^{1/2}$ 这种分数指数直接没有意义；而 $a=1$ 时曲线退化成一条水平直线 $y=1$，它压根没有反函数（一条横线照镜子还是横线，翻不出对数）。

**误区二**："你以为 $y=a^x$ 画到左边迟早会碰到 x 轴。" 其实永远碰不到。$a^x$ 恒为正，x 轴是它的**渐近线**：x 越小它越接近 0，但永远差那么一点点。这也是值域写成 $(0,+\infty)$ 而不是 $[0,+\infty)$ 的原因——0 是取不到的。

**误区三**："你以为 $y=a^x$ 与 $y=\log_a x$ 关于 x 轴（或者 y 轴）对称。" 其实它们关于**直线 $y=x$** 对称。沿 x 轴翻得到的是 $y=-a^x$（整个曲线翻到轴下方），沿 y 轴翻得到的是 $y=a^{-x}$（递增变递减）——两者都不是对数。判据很简单：看定点。指数过 $(0,1)$，对数过 $(1,0)$，这两个点是横纵坐标互换的关系，只有 $y=x$ 这面镜子做得到。

:::

**练习 2**：把 $y=2^x$ 上的五个点 $(0,1)$、$(1,2)$、$(2,4)$、$(3,8)$、$(4,16)$ 全部照进 $y=x$ 这面镜子，写出它们在对数曲线上的对应点，并说明为什么这样得到的点一定在 $y=\log_2 x$ 上。

<details>
<summary>点开查看逐步解答</summary>

1. **横纵坐标互换**：$(1,0)$、$(2,1)$、$(4,2)$、$(8,3)$、$(16,4)$；
2. **为什么一定在对数曲线上**：设指数曲线上的点是 $(x,\,2^x)$，即"2 的 x 次方等于 $2^x$"。交换坐标后得到 $(2^x,\,x)$，把它写成"横坐标 = t、纵坐标 = ?"的形式，令 $t = 2^x$，则纵坐标 $x$ 正是"2 的几次方等于 t"的答案——按对数的定义，它就是 $\log_2 t$；
3. **逐点验算**：$\log_2 1 = 0$、$\log_2 2 = 1$、$\log_2 4 = 2$、$\log_2 8 = 3$、$\log_2 16 = 4$，与上一步的纵坐标完全一致；
4. **顺带看出单调性**：横轴从 1 走到 16 翻了 16 倍，纵轴只从 0 爬到 4——两条曲线共享"底数大于 1 就递增"这条性质，只是一个快得吓人，一个慢得离谱。

</details>

**练习 3**：用 Python 验证恒等式 $a^{\log_a N}=N$：取 a 为 2、3、10，N 为 7、100，各算一次 $a^{\log_a N}$，看结果是否回到 N（允许极小的浮点误差，保留 6 位小数）。

<details>
<summary>点开查看逐步解答</summary>

```python
import math

for a in [2, 3, 10]:
    for N in [7, 100]:
        print(a, N, round(a ** math.log(N, a), 6))
```

六行结果分别是 `2 7 7.0`、`2 100 100.0`、`3 7 7.0`、`3 100 100.0`、`10 7 7.0`、`10 100 100.0`——**同底时，取对数和乘方互为撤销**。出现 6.999999 这种尾巴属于浮点误差，保留 6 位小数后已经看不出来。

</details>

## 8. 选读：利息越滚越细，会滚出一个新常数

<details>
<summary>选读 · e 的雏形就藏在复利里</summary>

假设年利率是 100%（方便起见），一年结一次息，一万元变两万，翻倍。如果半年结一次、每次 50% 呢？一年后是 $(1+0.5)^2 = 2.25$ 倍。拆得越细，年底越多：

$$ \left(1 + \frac{1}{n}\right)^{n} $$

n 是每年结息的次数。跑一下：

```python
for n in [1, 2, 10, 100, 10000]:
    print(n, round((1 + 1 / n) ** n, 6))
```

输出 `2`、`2.25`、`2.593742`、`2.704814`、`2.718146`。n 越大增长越慢，数字被**卡在某个上限附近**——它约等于 2.71828，就是自然常数 $e$。它为什么值得拥有一个字母、为什么 $\log_e$（写作 $\ln$）和 $e^x$ 会成为微积分里最舒服的一对，那是第 15 章的故事。

</details>
