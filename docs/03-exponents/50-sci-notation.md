# 科学计数法：给数字分级

## 1. 从一个场景开始

光速是 299792458 米/秒。地球质量约 5972000000000000000000000 千克——5.972 后面跟着 21 个零，一共 25 位。这样的数写出来像一条毛毛虫：既难抄写、更难比较。

问一个看似无聊的问题：299792458 和 59720...（共 25 位）这两个数，**哪个更大？** 答案显然，但"大多少"一时说不清。人类需要一个给数字**分级**的系统——就像给山峰标海拔一样。这一课造出它。

## 2. 直觉解释

比较大小靠的不是逐位读数，而是**数位数**：

- 3 位数和 5 位数比，不用看具体数字，后者必大；
- 每多一位数，就是乘了一次 10——跨上一级台阶。

10 的幂就是这组台阶的正式名字：$1, 10, 100, 1000, \dots$ 一个数的"数量级"，就是它站在第几级台阶上。科学计数法只做一件事：**把每个数写成"台阶号 + 台阶上的位置"**。

## 3. 正式定义

**科学记数法**：把正数 N 写成

$$N = a \times 10^n \qquad (1 \le a < 10,\ n \text{ 为整数})$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a$ | 尾数 | 台阶上的具体位置，介于 1 和 10 之间 |
| $n$ | 阶码 | 数量级——小数点挪过的格数 |
| $10^n$ | 10 的幂 | 台阶本身 |

Python 里这种数有专门写法：`3.5e8` 读作"3.5 乘 10 的 8 次方"，`e8` 就是"×10^8"的缩写。

## 4. 分步例题

**例 1**：把 299792458 写成科学记数法。
1. 小数点原本在最末尾：299792458.
2. 往左挪，每挪一位除以 10，数着挪了几次：挪 **8** 次后变成 2.99792458；
3. 所以 $299792458 = 2.99792458 \times 10^8$。数量级是 8。

**例 2**：把 $6.022 \times 10^{23}$ 还原成普通写法。
1. 阶码 23 表示小数点右移 23 位；
2. 6.022 右移 3 位得 6022，再补 20 个零；
3. 得到 602200000000000000000000——阿伏伽德罗常量，还是缩写顺眼。

## 5. 动手实验

### 观察：先看看 10 的幂长什么样

```viz

  "type": "plot",
  "title": "y = 10^x",
  "expr": "10^x",
  "xmin": 0,
  "xmax": 2
}
```

x 每走一格，高度放大 10 倍——这就是"数量级"的图形含义。本章最后一课会看到这类曲线在赛跑中的惊人后劲。

### 实验 2：位数与阶码的关系

```python title="10 的幂：一级级台阶"
for k in range(0, 9):
    p = pow(10, k)                    # 10 的 k 次方
    digits = len(str(p))              # str 先转成文字，len 数长度：就是这个数有几位
    print(f"10^{k} 是 {p}，共 {digits} 位")
```

规律一眼可见：$10^n$ 有 n+1 位。**阶码 = 位数 − 1**，所以"数数量级"和"数位数"是一回事。

### 实验 3：数量级探测器——本课的主算法

给定任意正整数 N，用循环找出满足 $10^n \le N < 10^{n+1}$ 的那个 n：

```python title="不断除以 10，数次数"
N = 350000000
n = 0                         # 阶码从 0 开始
m = N                         # 用副本 m 动手，保留原值 N
while m >= 10:                # 只要还不小于 10，就再降一级台阶
    m = m / 10                # 小数点左移一位
    n = n + 1                 # 台阶号加一
print(f"{N} = {m} × 10^{n}")
print(pow(10, n), "<=", N, "<", pow(10, n + 1))   # 验证定义里的不等式
```

循环结束时 $m$ 正是尾数（落在 1 到 10 之间），$n$ 就是数量级。这台探测器和对数课的减半计数器是亲兄弟——只是底换成了 10。事实上 $\log_{10} N$ 取整就等于这里的 n，两条路殊途同归。

### 快问快答

```quiz
Python 写法 3.5e8 代表哪个数？
- 3.5 乘 10 的 8 次方 [*]
- 变量 e 加 8 再与 3.5 运算
- 35 的 8 次方
? e8 连起来读作"乘 10 的 8 次方"，是写在数字尾巴上的整体记号，与名为 e 的变量毫无关系——正是误区三埋的坑。
```

:::warning[常见误区]

**误区一**："科学记数法随便写，比如 $35 \times 10^7$ 也行。" 
值确实相等，但标准形规定尾数必须在 $[1, 10)$ 内。不统一格式就没法一眼比数量级——规范不是洁癖，是为了可比。

**误区二**："8 和 80 差不多大。" 
在数量级的尺子上它们隔了一整级：80 是 8 的 10 倍。日常语言里"差不多"，数量级语言里差一代人。

**误区三**："`3.5e8` 是变量 e 的某种运算。" 
它是一个整体的字面量（literal），跟名为 e 的变量毫无关系。`e8` 连起来读作"乘 10 的 8 次方"。

:::

## 6. 练习

**练习 1**：求 500000000 的数量级 n（满足 $10^n \le N < 10^{n+1}$）。下面的代码能跑但边界条件写错了，结果差一，改到通过：

```exercise
# @title: 练习：数量级探测器
# @check: 8
# @hint: 当 N 减到 5 时已经不足一级台阶了，不该再除——想想循环继续的条件该拿谁、跟几比
N = 500000000
n = 0
while N > 1:
    N = N / 10
    n = n + 1
print(n)
```

**练习 2**：用实验 3 的探测器处理光速 299792458，打印它的尾数和阶码。

<details>
<summary>点开查看逐步解答</summary>

```python
N = 299792458
n = 0
m = N
while m >= 10:
    m = m / 10
    n = n + 1
print(f"{N} = {m} × 10^{n}")     # 约 2.99792458 × 10^8
```

浮点会带一点小尾巴（如 2.9979245800000004），属正常现象。对照例 1 的手算，一致。
</details>

**练习 3**：地球质量约 $5.97\times10^{24}$ 千克，月球约 $7.35\times10^{22}$ 千克。地球质量是月球的多少倍？只用心算 + 一行代码验证。

<details>
<summary>点开查看逐步解答</summary>

同底数幂相除指数相减：$\frac{5.97\times10^{24}}{7.35\times10^{22}} \approx 0.81 \times 10^{2} \approx 81$ 倍。

```python
print(5.97e24 / 7.35e22)
```

注意心算时真正干活的是阶码相减（24 − 22 = 2）——科学记数法让"倍数估算"变成小学题，这正是它的设计目的。
</details>

## 7. 选读：费米估算——数量级的实战威力

<details>
<summary>选读 · 不需要精确，只需要对的数量级</summary>

物理学家费米爱出怪题："芝加哥有多少钢琴调音师？"没人知道答案，但可以拆：城市约 300 万人 ≈ $3\times10^6$，约每 4 人一台琴 → $10^6$ 台量级；每台每年调 1 次 → $10^6$ 次工作量；调音师每人每年干 $10^3$ 次量级 → 需要 $10^3$ 人？实际约百人级——拆到每一步都只保数量级，误差居然只有几倍。

这套"数量级工程学"的底气就来自本课：只要阶码对了，尾数差个两三倍无伤大雅。科学研究的第一问从来不是"精确是多少"，而是"它是 10 的几次方"。下一课你会看到，把不同数量的增长曲线放进同一张图，谁碾压谁一目了然。

</details>
