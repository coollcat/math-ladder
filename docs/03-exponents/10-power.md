# 乘方：连乘的记号

## 1. 从一个场景开始

把一张纸对折一次是 2 层，对折两次是 4 层，对折十次呢？你得写 $2 \times 2 \times \cdots \times 2$ 写十个 2。国际象棋盘上放米粒：第 1 格放 1 粒、第 2 格放 2 粒、每格翻倍——写到第 64 格，式子长得能绕桌子一圈。

**同一个数反复相乘**这件事太常出现了，人类必须给它一个压缩记号。这个记号还藏着一个惊天特性：它增长的速度，将碾压你见过的任何算术运算。

## 2. 直觉解释

第 1 章说过：乘法是"同一个数反复相加"的压缩。现在更进一步：

- $3 + 3 + 3 + 3$ 压缩成 $3 \times 4$（3 被加了 4 次）；
- $3 \times 3 \times 3 \times 3$ 压缩成 $3^4$（3 被乘了 4 次）。

右上角的小数字记录"底下的数被自己乘了几次"。生活图像就是细胞分裂：1 变 2、2 变 4、4 变 8——分裂 n 代后共 $2^n$ 个。"对折 10 次"就是 $2^{10}$。

## 3. 正式定义

**记号**：n 个 a 相乘写作

$$a^n := \underbrace{a \cdot a \cdots a}_{n \text{ 个}}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a$ | 底数 | 被反复相乘的那个数 |
| $n$ | 指数 | 相乘的次数 |
| $a^n$ | 幂 | 整个运算的结果 |

读作"a 的 n 次方"；$a^2$ 读作"a 的平方"，$a^3$ 读作"a 的立方"（想想正方形面积与立方体体积）。规定 $a^1 = a$："只乘一次等于没加工"。

一条立刻能看出的规律：**同底数幂相乘，指数相加**：

$$a^m \cdot a^n = a^{m+n}$$

比如 $2^3 \times 2^2 = (2\cdot2\cdot2)\times(2\cdot2)$——左边一共 5 个 2 连乘，正是 $2^5$。（选读部分会看到这条规则还能逼出更多东西。）

## 4. 分步例题

**例 1**：计算 $2^{10}$。

1. 不硬乘，逐级翻倍：$2^1=2$
2. $2^2=4,\ 2^3=8,\ 2^4=16$
3. $2^5=32$（才五次就 32 了）
4. 继续：$2^6=64,\ 2^7=128,\ 2^8=256,\ 2^9=512$
5. $2^{10}=1024$

顺手验证规律：$2^{10} = 2^5 \times 2^5 = 32\times32 = 1024$ ✓（$10 = 5+5$）

**例 2**：负数当底数要小心括号。$(-2)^2 = (-2)\times(-2) = 4$（偶数次幂为正）；$(-2)^3 = -8$（奇数次幂为负）。而 $-2^2$ 按约定是 $-(2^2)=-4$：**先平方，后添负号**。Python 里也是同样的规矩。

### 实验 3：手搓连乘机——pow 的前身

Python 里怎么算乘方？按本站惯例，先不查资料，自己造一台"连乘机"：

```python title="用 for 循环手搓幂函数"
def my_pow(a, n):            # 定义函数：算 a 的 n 次方
    result = 1               # 从 1 出发：1 乘任何数不变（乘法的"白做起点"）
    for i in range(n):       # 循环 n 次
        result = result * a  # 累乘器：旧结果再乘一个 a，存回去
    return result

print(my_pow(2, 10))
print(my_pow(3, 4))
print(my_pow(5, 3))
```

对照第 0 章的累加器：加法从 **0** 出发（加 0 不变），乘法从 **1** 出发（乘 1 不变）。每种运算都有自己的"不起眼的起点"，学新运算时找它是个好习惯。

### 实验 4：官方写法 ** 登场

其实 Python 自带乘方记号——两个星号 `**`：

```python title="a ** n 就是乘方"
def my_pow(a, n):
    result = 1
    for _ in range(n):   # 下划线：表示这个循环变量不打算再用
        result = result * a
    return result

print(2 ** 10)   # 两个星号 ** 是 Python 的乘方记号：2 的 10 次方
print(my_pow(2, 10) == 2 ** 10)   # 手搓版和官方版一致吗？
print((-2) ** 4) # 底数是 -2 时必须带括号
print(-2 ** 4)   # 不带括号：先算 2 的 4 次方，再加负号 → -16
```

`my_pow` 与 `**` 结果完全一致——因为它们本来就是同一件事。

### 实验 5：宣布 pow() 诞生

`**` 已经很好用了，但 Python 还提供了一个内置**函数**版本来做同样的事：`pow(a, n)`（power，幂）。它不是天上掉下来的魔法——**就是你刚写的那个 for 循环**：

```python title="pow：内置的连乘机"
def my_pow(a, n):
    result = 1
    for _ in range(n):   # 下划线：表示这个循环变量不打算再用
        result = result * a
    return result

print(pow(2, 10))    # pow(a, n)：内置函数，返回 a 的 n 次方，无需导入直接可用
print(pow(2, 10) == 2 ** 10 == my_pow(2, 10))
```

三种写法，同一个 1024。今后随手计算用 `**`；需要"把'算几次方'当作工具传来传去"时用 `pow`。

### 快问快答

```quiz
2**3 + 2**3 等于多少？
- 2**6
- 2**4 [*]
- 4**3
? 两个相同的幂相加是把份数翻倍：2 的 3 次方再加一份还是 2 的 3 次方，共两份，即 2 乘 2 的 3 次方 = 2 的 4 次方 = 16。注意"相加"与"同底数幂相乘"是两回事：只有乘法才让指数相加。
```

:::warning[常见误区]

**误区一**："$2^3 \times 2^4 = 2^{12}$。"
指数记录的是"乘了几次"，合并的是**次数**：$2^3\times2^4$ 是 $(3+4)=7$ 个 2 连乘，即 $2^7=128$。指数相加，不是相乘。

**误区二**："$-3^2 = (-3)^2 = 9$。"
不带括号时先平方后取负：$-3^2 = -9$。想让 -3 当底数，必须写 $(-3)^2$。Python 对这两式的处理和数学约定完全一致。

**误区三**："$2^0 = 0$，零个 2 相乘嘛。"
恰恰相反：$2^0 = 1$。从 $2^3=8$ 开始每次指数减 1 就除以 2：$8, 4, 2, \boxed{1}, \frac12,\dots$ 选读部分给出完整推理。

:::

**练习 2**：抽查一万组随机数，验证 $a^m \cdot a^n = a^{m+n}$。

<details>
<summary>点开查看逐步解答</summary>

```python
import random

ok_count = 0
for trial in range(10000):
    a = random.randint(2, 9)
    m = random.randint(1, 6)
    n = random.randint(1, 6)
    if pow(a, m) * pow(a, n) == pow(a, m + n):
        ok_count = ok_count + 1

print(f"一万组中成立 {ok_count} 次")
```

全部成立。这不是实验凑巧，而是必然——左边是 m+n 个 a 连乘，右边也是。
</details>

**练习 3**：0.1 毫米厚的纸，对折 42 次后有多厚？（提示：总层数是 $2^{42}$ 层。）先猜个数量级再运行。

<details>
<summary>点开查看逐步解答</summary>

```python
thickness_mm = 0.1 * pow(2, 42)      # 总厚度（毫米）
thickness_km = thickness_mm / 1000 / 1000
print(thickness_km)                  # 约 44 万千米
```

约 44 万千米——超过地球到月球的距离（约 38 万千米）。42 次翻倍就能从一张纸摸到月亮，"指数爆炸"不是修辞。这种大数字怎么说才不累？本章 50 节的科学计数法专治此事。
</details>

## 7. 选读：$2^0 = 1$ 是谁规定的？

<details>
<summary>选读 · 让规律自洽，答案别无选择</summary>

列出事实：$2^3 = 8$，$2^2=4$，$2^1=2$。每往右一格，指数减 1、值除以 2。按这个节奏走下一步：$2^0 = 2/2 = 1$。

更有说服力的理由来自上一节的规律：$a^0 \cdot a^n = a^{0+n} = a^n$，两边约去 $a^n$ 得 $a^0 = 1$。也就是说，**只要"指数相加"想对所有指数成立，$a^0=1$ 就是被逼出来的唯一选择**。

顺着再走一步，指数就要减进负数了——负数地盘的台阶长什么样？通式长什么样？这里刻意不剧透，下一课就把这条路走完整。你看，我们没有发明任何新规定，只是让已有的规律继续运转——这个套路，下一课立刻再次上演。

</details>
