# 幂、根与对数：乘方的三副面孔

上一章你会算 $a \times b$ 了。这一章研究一个更猛的动作：**把同一个数连乘 n 次**。围绕它有三问：

1. [乘方：连乘的记号](./10-power.md)——$2^{10}$ 是什么？`pow()` 在这里诞生；
2. [负整数指数幂：倒数换座位](./15-negative-exponent.md)——指数减到负数怎么办？换座位到分母：$a^{-n}=\frac{1}{a^n}$；
3. [平方根：已知面积求边长](./20-sqrt.md)——谁的平方是 144？反向提问催生 `math.sqrt`；
4. [分数指数：开一般次方](./30-fractional-exponent.md)——指数律逼出 $x^{0.5}=\sqrt{x}$；
5. [对数：指数的反问句](./40-log.md)——"2 的几次方等于 8？"对数就是这句反问，`math.log` 在此诞生；
6. [科学计数法：给数字分级](./50-sci-notation.md)——用 10 的幂驯服天文数字，建立数量级直觉；
7. [三条曲线：谁长得快](./60-three-curves.md)——$x^2$、$\sqrt{x}$、$2^x$ 赛跑：指数终将碾压一切。

本章诞生三个工具：内置函数 `pow()`、数学库的 `math.sqrt` 与 `math.log`——照惯例，每个工具都先手写一遍再宣布。学完这章，你将拥有描述"增长"与"爆炸"的全部语言。

## 实战挑战 · 两场地震差多少

情境来自真实地震数据（2008 年汶川大地震为里氏 8.0 级），改编自经典题型——地震学里量地震用的正是本章的对数与幂。两个公式是对数尺子的标准用法（题面直接给出，不用背）：

- **里氏震级定义**：$M = \log_{10}\dfrac{A}{A_0}$，其中 $A$ 是这次地震记录到的最大振幅，$A_0$ 是标准地震的振幅；
- **古登堡–里克特能量公式**：$\log_{10}E = 4.8 + 1.5M$，其中 $E$ 是地震释放的能量（焦耳）。

设汶川地震震级 $M_1 = 8.0$，另一次地震震级 $M_2 = 6.0$。

**(a)** 汶川记录到的最大振幅是那次小地震的多少**倍**？（提示：由震级定义，$\frac{A}{A_0} = 10^M$，两式相除。）

**(b)** 汶川释放的能量是它的多少**倍**？（提示：对数相减时常数项抵消：$\log_{10}E_1 - \log_{10}E_2 = 1.5(M_1 - M_2)$。）

下面的代码方向对了但都没算到底，改到通过：

```exercise
# @title: 实战挑战：两级地震差多少
# @check: 100.0
# @check: 1000.0
# @hint: (a) 振幅比是 10 的"震级差"次方；(b) 能量的对数差是 1.5 × 震级差，倍数再还原回 10 的这个差次幂。10 ** 指数 一发入魂。
m_big = 8.0     # 汶川地震震级
m_small = 6.0   # 另一次地震震级

amp_ratio = m_big - m_small          # ← 这只是震级差，还不是振幅比
print(amp_ratio)

energy_log_gap = amp_ratio * 1.5     # ← 能量的对数差算出来了，可倍数还没还原
print(energy_log_gap)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 由震级定义：$\frac{A_1}{A_0} = 10^{M_1}$、$\frac{A_2}{A_0} = 10^{M_2}$，两式相除：

$$\frac{A_1}{A_2} = \frac{10^{8}}{10^{6}} = 10^{8-6} = 10^2 = 100$$

汶川的振幅是小地震的 **100 倍**。

**(b)** 对能量公式两边做减法，4.8 抵消：

$$\log_{10}E_1 - \log_{10}E_2 = 1.5 \times (8 - 6) = 3 \quad\Longrightarrow\quad E_1 = 10^3 \cdot E_2$$

汶川释放的能量是 **1000 倍**——这正是"选读：对数把乘法变成加法"的现实版本：震级只差 2（对数世界里的一小步），能量却差三个数量级。防灾标准因此对高震级格外敏感。

```python
m_big = 8.0
m_small = 6.0

amp_ratio = 10 ** (m_big - m_small)              # 振幅比：10 的震级差次方
energy_ratio = 10 ** (1.5 * (m_big - m_small))   # 能量比：对数差还原成幂
print(f"振幅比 {amp_ratio}")
print(f"能量比 {energy_ratio}")
```

输出 `100.0` 与 `1000.0`——末尾的 `.0` 是浮点的着装习惯，数值分毫不差。
</details>

## 章节大题：菌群的一昼夜

学完乘方的三副面孔，来给一支菌群的一昼夜做全程核算：1 个细菌每 20 分钟分裂一次，数量翻一番。下面的代码把**幂记号与指数律、对数的翻倍次数、数量级探测与阶码**一次全用上——它能跑，但报告三处全错。把它修到三行检查全部通过：

```exercise
# @title: 章节大题：菌群的一昼夜
# @check: 24小时个数: 4722366482869645213696
# @check: 破万亿轮数: 40
# @check: 阶码: 菌群 21, 地球 24
# @hint: 三处暗坑：翻倍 72 轮是 2 ** 72，乘个 2 只相当于分裂了一轮；math.log 报出的 39.86 是"理论交点"，细胞只会整轮整轮地翻，要用 while 循环数到真正过线的那一轮；探测器停下的条件该拿 m 跟 10 比——尾数住在 [1, 10) 这一级台阶上，跟 1 比会多下一级。
import math

# 第 1 问：一昼夜（24 小时）后菌群有多少个？
rounds = 3 * 24               # 每小时分裂 3 轮，一昼夜共 72 轮
colony = 2 * rounds           # ← 能跑，但"每轮翻倍"不等于只乘一次 2
print(f"24小时个数: {colony}")

# 第 2 问：第几轮首次突破一万亿（10^12）？
target = 10 ** 12
n_log = int(math.log(target, 2))   # ← 这是连续世界的"理论交点"，离过线还差一步
print(f"破万亿轮数: {n_log}")

# 第 3 问：菌群个数与地球质量（千克）比数量级
def order(x):                 # 数量级探测器：不断除以 10，数下了几级台阶
    k = 0                     # 台阶计数器
    m = x
    while m > 1:              # ← 边界条件抄错了，会多下一级台阶
        m = m / 10
        k = k + 1
    return k

earth = 5.97e24               # 地球质量约 5.97 × 10^24 千克
print(f"阶码: 菌群 {order(colony)}, 地球 {order(earth)}")
```

<details>
<summary>点开查看逐步解答</summary>

三处暗坑对应本章三课：

1. **幂记号**（10 课）：每轮翻一倍，72 轮就是 $2^{72}$ 个——`2 * rounds` 才乘了一次 2。它还顺守指数律：$2^{72} = 2^3 \times 2^3 \times \cdots$（24 个 $2^3$）$= 2^{3\times24}$，同底数幂相乘、指数相加；
2. **对数**（40 课）：$\log_2 10^{12} \approx 39.86$ 是连续世界里的理论交点；细胞只能整轮整轮地翻，$2^{39}$ 还不够、$2^{40} \approx 1.1\times10^{12}$ 才过线——所以答案是 40。这正是"连续答案"与"离散步数"差的那一步；
3. **阶码**（50 课）：探测器该在 $m < 10$ 时收手，留下的尾数正好落在 $[1, 10)$ 这级台阶上。菌群 $4.72\times10^{21}$ 的阶码是 21，地球质量的阶码是 24——纯比数字大小，地球仍高出一千倍（3 级台阶）。

修正后的关键代码：

```python
colony = 2 ** rounds          # 幂记号：72 轮翻倍

n = 0                         # 轮次计数器从 0 起步
cells = 1                     # 从 1 个细菌出发
while cells <= target:        # 还没过线，就再翻一倍
    cells = cells * 2
    n = n + 1                 # 数一轮

def order(x):
    k = 0
    m = x
    while m >= 10:            # 只要还不小于 10，就再降一级台阶
        m = m / 10
        k = k + 1
    return k
```

顺手用 math.log 验收第 2 问：`math.log(10 ** 12, 2)` 约 39.86，向上取整恰是 40——log 负责"大概第几轮"，循环负责"确切哪一轮"，本章的两件工具在这里各司其职。
</details>
