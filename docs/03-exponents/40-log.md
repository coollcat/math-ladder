# 对数：指数的反问句

## 1. 从一个场景开始

一个细胞每 20 分钟分裂一次（数量翻倍），现在有 1 个，问多久之后超过 10 亿个？

换个说法：**2 自乘多少次能到达 10 亿？** 也就是解方程 $2^{?} = 1\,000\,000\,000$。指数的位置上站着一个未知数——这种"反问"在数学里值得拥有自己的名字和符号。它的名字叫**对数**，它是密码学、算法复杂度、地震震级背后的共同主角。

## 2. 直觉解释

乘方是正向问："$2^3 = ?$"（答：8）。对数把问题反过来：

$$2^{\,?} = 8 \quad\Longrightarrow\quad \text{答案是 } 3$$

对数就是"**翻倍了几次**"的答案计数器。看这张对照表，两个方向互为镜像：

| 正向（乘方） | 反向（对数） |
| --- | --- |
| $2^3 = 8$ | $\log_2 8 = 3$ |
| $10^4 = 10000$ | $\log_{10} 10000 = 4$ |
| $3^2 = 9$ | $\log_3 9 = 2$ |

读法："$\log_2 8$"读作"以 2 为底 8 的对数"，意思就是"**2 的几次方等于 8**"。它不是新的运算规则，只是把乘方的答案栏挪到了问号位置。

## 3. 正式定义

**定义**：$\log_b N = x \iff b^x = N$（其中 $b>0,\ b\neq 1,\ N>0$）

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $b$ | 底数 | "反复自乘的那个数"，须为正且不等于 1 |
| $N$ | 真数 | 目标结果，必须是正数 |
| $x$ | 对数值 | 需要自乘的次数，可以是任意实数 |

两条立刻能写出的恒等式（都是定义的直接翻译）：

$$\log_b(b^x) = x \qquad b^{\log_b N} = N$$

## 4. 分步例题

**例 1**：$\log_2 32$
1. 问自己：2 自乘几次到 32？
2. 数翻倍：$2,4,8,16,32$——5 次
3. 所以 $\log_2 32 = 5$

**例 2**：$\log_3 81$
1. $3\times3=9,\ 9\times9=81$，即 $3^4=81$
2. 所以 $\log_3 81 = 4$

**例 3**：$\log_5 \frac{1}{25}$。目标比 1 小，说明要"反向自乘"（除以 5）：$5^{-2}=\frac{1}{25}$，所以答案是 $-2$。对数的值可以是负数、小数，只有**真数**必须为正。

## 5. 动手实验

### 实验 1：log 的诞生——不断除以 2，数次数

不用任何对数工具，只靠除法和计数，回答"2 的几次方等于 1024"：

```python title="减半计数器"
N = 1024
count = 0                     # 计数器：记录除了几次
m = N                         # 用副本 m 动手，保留原值 N
while m > 1:                  # while 循环：条件成立就一直重复
    m = m / 2                 # 每轮减半一次
    count = count + 1         # 数一次
print(f"{N} 需要翻倍 {count} 次才能从 1 到达")
```

打印 `10`——因为 $2^{10}=1024$。这台"减半计数器"就是对数的全部直觉：**对数 = 从 N 走回 1 需要减半的次数**。

### 实验 2：非整数答案暴露了对数的真面目

换 N=10 再跑一遍：计数器报 4。可 $2^4=16$ 早超过 10 了！真相是：$2^3=8$ 不够、$2^4=16$ 太多，**真正的答案在 3 和 4 之间的某个小数**。整数世界装不下它——就像 $\sqrt2$ 当年装不进分数。

```python title="精确答案需要新工具"
import math

print(math.log(10, 2))        # math.log(N, b)：以 b 为底 N 的对数，第二个参数是底数
print(math.log(1024, 2))
print(math.log(1000000000, 2))   # 开头场景的答案：约 29.9 次翻倍
```

`math.log(10, 2) ≈ 3.3219`——这就是夹在 3 和 4 之间的那个数。**log 就是你刚写的减半计数器的连续版**：允许"减半"走非整数步。

### 实验 3：细菌问题的完整答案

```python title="多久破 10 亿"
import math

hours = math.log(1000000000, 2) * 20 / 60   # 翻倍次数 × 每次 20 分钟，换成小时
print(hours)
```

约 9.97 小时。一天之内，一个细胞变成十亿大军——这就是对数尺子量出来的"爆炸的速度"。

### 实验 4（viz）：同框看"慢"

对数到底长得有多慢？把它和自己的老对手——直线——放进同一张图。机器内置的 log 是以 e 为底的，换底只需除一下：以 b 为底的对数就是 log(x)/log(b)（b 交给滑杆）。以 2 为底、以 10 为底实在太常用，Python 还备了专门函数 `math.log2(x)`、`math.log10(x)`——它们等价于 `math.log(x, 2)` 和 `math.log(x, 10)`：

### 实验 5：一张表量化"慢"

```python title="N 放大一百倍，翻倍次数只多一点点"
import math

print(f"{'N':>14}{'翻倍次数':>12}")      # {:>14} 右对齐占 14 格：把两列排成整齐的表
for k in range(1, 11):                  # k 取 1..10：造出 10 到 10^10 这串大数
    n = 10 ** k                         # ** 是乘方记号（本章 10 课登场）
    times = math.log(n, 2)              # 以 2 为底：N 是 2 的几次方（专门的 math.log2(n) 是等价写法）
    print(f"{n:>14}{times:>12.2f}")     # :>12.2f 右对齐 12 格、保留两位小数
```

规律藏在右列：N 每放大 **一百倍**（跳两级台阶），翻倍次数只增加约 6.6。从 10 到一百亿，N 涨了十亿倍，翻倍次数却只从 3.3 走到 33.2——这就是"对数把乘法压成加法"的直观模样（选读给出原理），也是它敢给地震震级、算法难度当尺子的资本。

### 快问快答

```quiz
log_2 64 等于多少？
- 32
- 6 [*]
- 12
? 它问的是"2 自乘几次到 64"：2→4→8→16→32→64，共翻倍 6 次。对数量的是次数——不是拿 64 去减、去除底数。
```

:::warning[常见误区]

**误区一**："$\log$ 是 l-o-g 三个量相乘。" 
log 是一整个函数名（英文"对数" logarithm 的缩写），像 sqrt 一样不可拆分。$\log_2 8$ 是一个整体，读作"以 2 为底 8 的对数"。

**误区二**："真数可以是零或负数。" 
不行。底 b 正数自乘永远得正数，所以 $b^x=N$ 里 N 必须为正。$\log_2 0$ 和 $\log_2(-8)$ 都无解。

**误区三**："math.log(x) 默认以 10 为底。" 
Python 里只给一个参数时，底是自然常数 e ≈ 2.718（第 15 章的主角），`math.log(100)` 得约 4.6 不是 2！想要常用对数必须显式写 `math.log(x, 10)`。

:::

**练习 2**：验证"减半计数器"与 math.log 在更多数字上一致（整数场合）。

<details>
<summary>点开查看逐步解答</summary>

```python
import math

for N in [8, 256, 4096]:
    count = 0
    m = N
    while m > 1:
        m = m / 2
        count = count + 1
    print(f"N={N}: 计数器 {count}, math.log {int(math.log(N, 2))}")
```

两边完全一致。手写的循环给出理解，官方函数给出效率——本站一贯的两条腿走路。
</details>

**练习 3**：把开头场景的问题做完：从 1 个细胞开始，每 20 分钟翻倍。写循环找出第一次**超过** 10 亿需要几轮分裂、折合多少小时。

<details>
<summary>点开查看逐步解答</summary>

```python
cells = 1
rounds = 0
while cells <= 1000000000:
    cells = cells * 2
    rounds = rounds + 1
print(rounds)                    # 30 轮
print(rounds * 20 / 60)          # 10 小时
```

30 轮 × 20 分钟 = 600 分钟 = 10 小时。注意 math.log 给的是 29.9——理论交点；而细胞只能整轮整轮地翻，第 30 轮才真正越过线。"连续答案"与"离散步数"差一步，正是练习里 while 循环与 log 函数的分工。
</details>

## 7. 选读：对数把乘法变成加法

<details>
<summary>选读 · 历史上最赚钱的一条公式</summary>

设 $M = b^x$，$N = b^y$。则 $M\times N = b^x \cdot b^y = b^{x+y}$，按对数定义取回指数：

$$\log_b(M \times N) = \log_b M + \log_b N$$

**乘法在对数世界里变成了加法。** 四百年前这可是天大的事：计算 $34702 \times 891$ 太难，查表取对数变成加法、算完再查回去就行。开普勒靠对数表整理行星轨道，拉普拉斯评价说"对数的发明把几个月的劳动缩短为几天"。今天你手机里的 FFT（第 16 章·卷一枢纽站）快到飞起，底层同样是对数在压低乘法次数。

</details>
