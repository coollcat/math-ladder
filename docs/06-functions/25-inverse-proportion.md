# 反比例函数：y=k/x 的双分支

## 1. 从一个场景开始

一段 24 公里的通勤路，怎么走完它？步行时速 4 公里，要 6 小时；骑车时速 12，要 2 小时；开车时速 48，只要半小时。速度翻倍，时间减半——但每一次，**速度 × 时间都死死等于 24**。

变化的两端此消彼长，乘积却按住不动。把"速度怎么随时间变"写成式子：$v = \dfrac{24}{t}$。这就是本课的主角——**反比例函数**：函数族三兄弟（一次、反比例、二次）里最讲究"礼尚往来"的一位，你多我少，总量恒定。

## 2. 直觉解释

[比、比率与正比例](../02-fractions/15-ratio-proportion.md) 那课的**正比例**是"商恒定"：路程 ÷ 时间恒定，图像是一条过原点的直线。反比例把恒定量从商换成了**积**：两个量相乘永远等于同一个数 $k$。

拿一块面积 24 平方米的长方形地来说：宽 3 米就得长 8 米，宽 6 米就得长 4 米，宽 12 米就得长 2 米。把所有"长 × 宽 = 24"的角落连成线，得到一条亭亭玉立的曲线——它有正式名字：**双曲线**。而且它天生**两副身段**：宽是正数时整个待在第一象限；要是允许"负的宽"（数学里 x 可以是负数），另一支就对称地住在第三象限。两支长得一模一样，却永不相逢。

## 3. 正式定义

$$y = \frac{k}{x} \qquad (k \neq 0)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $k$ | 反比例系数 | 两个量的恒定乘积；$k$ 变号，双曲线跳到对面象限 |
| $x \neq 0$ | 定义域 | 分母不能为 0——x=0 处函数**无定义**，两支因此永远断开 |
| 双曲线 | 图像的名字 | 两支对称张开的曲线；越走越贴近坐标轴，却永不相交 |

那两条被贴着却碰不到的坐标轴，有个专门的名字：**渐近线**——"无限靠近、永不相交"的引导线。第 6 章 45 课的圆锥曲线家族里，它会以另一副面孔正式重逢。

和正比例对账，一句话分家：**正比例管商恒定（一条过原点的直线），反比例管积恒定（绕开两轴的双曲线）**。

## 4. 分步例题

**例 1**：某反比例函数的图像经过点 $(3, 8)$，求表达式。

1. 反比例的全部家当是乘积恒定：$k = x \cdot y$；
2. 代入点：$k = 3 \times 8 = 24$；
3. 表达式：$y = \dfrac{24}{x}$；
4. 自检：把图像上任一点代回，乘积都得 24——比如 $x = 6$ 时 $y = 4$，$6 \times 4 = 24$ ✓。

**例 2**：给 $y = \dfrac{24}{x}$ 列一张函数值表，亲眼盯住乘积：

| x | 2 | 3 | 4 | 6 | 8 | 12 |
| --- | --- | --- | --- | --- | --- | --- |
| y | 12 | 8 | 6 | 4 | 3 | 2 |

每列上下相乘都是 24。再观察两端：x 越小 y 越冲越高（x=2 时已到 12），x 越大 y 越趴越低（x=12 时只剩 2）——两端都奔着坐标轴去，但谁也到不了：x 取不到 0，y 也永远除不尽到 0。这就是渐近行为的函数值表版。

## 5. 动手实验

### 实验 1（viz）：拖动 k，双曲线换装

```viz
{
  "type": "plot",
  "title": "y = k/x：双分支与两条渐近线（坐标轴）",
  "expr": "k/x",
  "label": "y = k/x",
  "xmin": -5,
  "xmax": 5,
  "sliders": [
    { "name": "k", "min": -6, "max": 6, "step": 1, "value": 2 }
  ]
}
```

三个挑战：

1. 拖大 k：两支离原点越撑越远——k 是"个头旋钮"；靠近 0：两支瘦成贴轴的细线；
2. 把 k 拖过 0 的瞬间：双曲线整体跳进第二、四象限——k 的符号管户口；
3. k 恰好取 0：图像塌成一条水平线（y=0），"乘积恒定"名存实亡——所以定义里钉死 $k \neq 0$。

### 实验 3（python）：乘积恒定的值表

```python title="长 × 宽 = 24，一行都不能少"
xs = [2, 3, 4, 6, 8, 12]     # 一排宽度的候选值

for x in xs:
    print(f"宽={x}  长={24 / x}  乘积={x * 24 / x}")
```

每行末尾的乘积都是 24.0——此消彼长的背后是铁打的乘积。把列表里加一个 5 试试：长变成 4.8，乘积纹丝不动。小数也逃不出这个恒等式。

### 实验 4（python）：把两支都画出来

```python title="y = 12/x 的两支：一、三象限各一支"
import matplotlib.pyplot as plt   # 画图库（第 0 章引入）

xs_right = []    # 右支（x 为正）的横坐标
ys_right = []    # 右支的纵坐标
xs_left = []     # 左支（x 为负）的横坐标
ys_left = []     # 左支的纵坐标

for i in range(1, 60):           # 从 1 开始：x=0 没有定义，必须绕开
    x = i * 0.25
    xs_right.append(x)
    ys_right.append(12 / x)
    xs_left.append(-x)
    ys_left.append(12 / (-x))

plt.plot(xs_right, ys_right, label="右支：第一象限")
plt.plot(xs_left, ys_left, label="左支：第三象限")
plt.axhline(0, color="gray", linestyle="--")   # 水平渐近线
plt.axvline(0, color="gray", linestyle="--")   # 竖直渐近线
plt.legend()
plt.grid(True)
```

两支隔轴相望、永不牵手：分母 0 是它们共同的禁区。盯着两端看——各自贴着灰虚线越走越近，却始终隔着一线之地。渐近线不是画出来的装饰，是这支曲线的"性格边界"。

### 快问快答

```quiz
反比例函数 y = k/x（k 大于 0）的图像穿过哪些象限？
- 第一、三象限 [*]
- 第二、四象限
- 只在第一象限
? 乘积恒为正，x 与 y 必须同号：x>0 时 y>0 落在第一象限，x<0 时 y<0 落在第三象限。k<0 时两支才搬到第二、四象限。
```

::::warning[常见误区]

**误区一**："反比例函数的图像是一条连着的弯线。" 它是**两支**断开的曲线：x=0 处分母为 0，函数无定义。别把 V 形、抛物线和它混为一谈——双曲线的"双"字就是户口。

**误区二**："y 随 x 增大而减小，处处如此。" 每一支**内部**成立；跨过 x=0 就翻车：y 从第三象限的深谷（负得很多）直接跳到第一象限的高峰（正得很大）。反比例函数是"分段变乖"的典型。

**误区三**："k 越大，曲线越高。" k 不改变"乘积恒定"的性格，只改变个头：|k| 越大两支离原点越远。真正分象限的是 k 的**符号**——正k 住一、三，负k 住二、四。

::::

## 6. 练习

**练习 1**：面积恒为 24 平方米的长方形，宽 3 米时长几米？宽 6 米呢？下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：面积恒定，长宽此消彼长
# @check: 8.0
# @check: 4.0
# @hint: 乘积恒定时，长 = 面积 ÷ 宽——初始代码把除法写成了乘法；Python 的除法结果自带 .0 小数尾巴，判题窗认的正是这个形式
area = 24        # 长方形面积恒为 24 平方米
width = 3        # 宽 3 米

length = area * width    # ← 长 = 面积 × 宽？乘积恒定还能这么算吗
print(length)
print(area * 6)
```

**练习 2**：反比例函数的图像经过 $(2, 6)$。求表达式，并算出 $x = 4$ 时的函数值。

<details>
<summary>点开查看逐步解答</summary>

先抓恒定乘积：$k = 2 \times 6 = 12$，表达式 $y = \dfrac{12}{x}$。

代 $x = 4$：$y = \dfrac{12}{4} = 3$。

用代码对账：

```python
print(12 / 4)
```

输出 3.0。顺带感受一下"此消彼长"：宽从 2 加到 4（翻倍），长从 6 减到 3（减半）——乘积稳如泰山。
</details>

**练习 3**：为什么 y = k/x（k > 0）的两支永不相交？用定义域和符号两条理由各说一句。

<details>
<summary>点开查看逐步解答</summary>

理由一（定义域）：两支分别住在 x>0 与 x<0 的地盘，而 x=0 处函数无定义——中间那道墙谁也穿不过去。

理由二（符号）：k>0 时乘积恒正，x 与 y 必须同号：第一象限支上 y 全是正数，第三象限支上 y 全是负数。一个只出正数、一个只出负数的两条曲线，想在某个点相遇，就得让那个点同时既正又负——做不到。

两条理由合起来正是渐近线的本质：不是"还没走到"，是"结构上不许"。
</details>

## 7. 选读：转 45°，双曲线露出真身

<details>
<summary>选读 · 平方差的一步搬家</summary>

$y = \dfrac{k}{x}$ 其实就是一条转过身的双曲线。令新横坐标 $u = x + y$、新纵坐标 $w = x - y$（相当于把坐标纸转了 45°），用[因式分解](../04-algebra/25-factoring.md)里的完全平方公式展开再相减：

$$u^2 - w^2 = (x+y)^2 - (x-y)^2 = 4xy = 4k$$

$u^2 - w^2 = 4k$ ——这正是[圆锥曲线](./45-conic-sections.md)里双曲线的标准造型 $u^2/a^2 - w^2/b^2 = 1$（这里 $a^2 = b^2 = 4k$，实虚轴一样长，所以渐近线互相垂直——恰好就是原来那两根坐标轴）。反比例函数与圆锥曲线的双曲线是同一族：一个用"乘积恒定"讲故事，一个用"距离之差"讲故事，转个身竟是同一条线。
</details>
