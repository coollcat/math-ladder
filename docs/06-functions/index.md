# 函数与图像：给数学装上眼睛

前五章我们一直在"算数"；从这一章起，数学第一次**看得见**。函数是一台机器——投进一个数，吐出一个数——而它的长相，就是图像。本章也是全书 plot 组件的主场：几乎每个概念都配一个可以拖动的滑块。

1. [函数是机器](./10-machine.md)——输入、加工、输出；顺便见证 abs、floor、ceil 三兄弟的诞生；
2. [绝对值方程与不等式](./15-abs-equations.md)——把 abs 的距离语义升级成解方程的尺子：两解、夹中间、奔两头；
3. [一次函数与斜率](./20-linear.md)——y=ax+b 的两个旋钮：倾斜与升降；
4. [反比例函数：y=k/x 的双分支](./25-inverse-proportion.md)——乘积恒定的双曲线两支：渐近线走廊与第一份"定义域"警示；
5. [二次函数与抛物线](./30-quadratic.md)——对称轴、顶点，以及那条著名的 U 形曲线；
6. [图像变换三件事](./35-transformations.md)——平移、翻折、缩放，日后波的振幅、频率、相位的预演；
7. [复合函数与反函数](./40-inverse-composite.md)——机器串流水线，以及如何倒带；
8. [圆锥曲线：椭圆、双曲线与抛物线](./45-conic-sections.md)——平面切圆锥切出的三类曲线，行星轨道的数学；椭圆家族肖像滑块随时就位；
9. [参数方程：用时间描述曲线](./50-parametric-equations.md)——y=f(x) 写不下的封闭曲线，引入参数 t 让抛物线逐帧回放。

学完这章，你会获得一种新直觉：看到式子，先想到图形。第 7 章的正弦波会把这一章的工具全部用上，卷一枢纽的傅里叶变换更是这套图像语言的阅兵式。

## 实战挑战 · 喷泉能喷多高、落多远

> 改编自经典题型（初中二次函数·喷水问题，$y=-x^2+4x$ 是这类题的经典设定）。

广场喷泉检修后重新开闸。以喷口正下方的地面为原点：水柱离喷口的**水平距离** $x$（米）与离地的**高度** $y$（米）满足

$$y = -x^2 + 4x$$

**(a)** 水柱最高能到几米？此时离喷口多远？（提示：最高点就是顶点）

**(b)** 水柱最终落回地面，落点离喷口多远？

**(c)** 概念思辨：第二天水压降低，表达式变成 $y = -x^2 + 2x$。水柱最远落点是变远了还是变近了？

把 (a)(b) 交给判题窗验证：

```exercise
# @title: 实战挑战：喷泉喷多高、落多远
# @check: 2
# @check: 4
# @check: 4
# @hint: 对称轴 x = −b/(2a)；最高点把对称轴代回 y = a*x**2 + b*x；落地点令 y = 0，即 x*(a*x + b) = 0 的非零根 x = −b/a。除法会出小数，包一层 round() 再打印。
a = -1          # 二次项系数：开口朝下
b = 4           # 一次项系数

top_x = 0       # (a) 最高点的横坐标：对称轴公式
print(top_x)

top_y = 0       # (a) 把 top_x 代回 y = a*x**2 + b*x，得最大高度
print(top_y)

far_x = 0       # (b) 落地点：y = 0 的非零根
print(far_x)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 认系数：$a = -1$，$b = 4$。对称轴（[二次函数](./30-quadratic.md) 第 3 节）：

$$x = -\frac{b}{2a} = -\frac{4}{2 \times (-1)} = 2$$

代回求高度：$y = -2^2 + 4 \times 2 = -4 + 8 =$ **4 米**。顶点 $(2, 4)$。

**(b)** 落回地面即 $y = 0$：

$$-x^2 + 4x = 0 \implies x(-x + 4) = 0 \implies x = 0 \text{（喷口，舍去）或 } x = 4$$

落点离喷口 **4 米**。注意两个根恰好关于对称轴 $x=2$ 对称——抛物线的对称性当场对账。

用 Python 验算：

```python
a = -1
b = 4
top_x = round(-b / (2 * a))
print(top_x)
print(a * top_x ** 2 + b * top_x)
far_x = round(-b / a)
print(far_x)
```

输出 `2`、`4`、`4`，与判题窗一致 ✓。

**(c)** 变近了。落点公式是 $x = -b/a$：$b$ 从 4 缩到 2，落点从 4 米缩到 **2 米**。直觉版：$b$ 管"往上冲的那股劲"，劲小了自然落得近。想动手验证？把判题窗里的 `b` 改成 2 重跑一遍即可。

</details>

## 章节大题：过山车轨道验收单

学完这一章，游乐园请你去验收一条过山车轨道。相比一次函数那条处处同样陡的直线（[20 课](./20-linear.md)），抛物线越走越陡——俯冲段要的就是这个脾气。图纸要求：轨道由基准抛物线 $y = x^2$ 经三旋钮改造而成，形如 $y = a(x-h)^2 + k$；已知谷底离地 1 米、恰好位于 $x = 2$ 的正上方，两根支架立在 $(0, 5)$ 与 $(4, 5)$ 两点。

下面的验收代码把**函数求值、顶点式、平移方向、反解系数、复合串联**一次全用上——它能跑，但四处检查没有一处对。把它修到四行检查全部通过：

```exercise
# @title: 章节大题：过山车轨道验收单
# @check: 顶点: (2, 1)
# @check: 系数 a: 1
# @check: 支架验收: True True
# @check: 串联复核: True
# @hint: 四处暗坑全在"方向"与"平方"上：右移是 x - h 不是 x + h（左加右减）；两台复合机器的挪法必须一致；反解 a 要拿高差除以水平距离的平方（用 // 整除，/ 会切出 .0）；顶点打印时横坐标在前——那是 h 不是 k。
def track(x):
    return a * (x + h) ** 2 + k   # ← 这条轨道造出来就歪了？查查平移方向

h = 2                              # 对称轴：两根支架的正中央
k = 1                              # 谷底离地高度

def f(u):
    return u ** 2 + k              # 外层机器：平方后再抬到谷底高度

def g(x):
    return x + h                   # ← 它得和 track 用同一种"挪法"吧？

a = (5 - k) // (0 - h)             # ← 高差有了，"水平距离"在公式里该是什么待遇？

print(f"顶点: ({k}, {h})")
print(f"系数 a: {a}")

p_ok = track(0) == 5               # == 判等：支架点真落在轨道上了吗
q_ok = track(4) == 5
print(f"支架验收: {p_ok} {q_ok}")

print(f"串联复核: {f(g(4)) == track(4)}")
```

<details>
<summary>点开查看逐步解答</summary>

四处暗坑对应本章四课：

1. **顶点别横纵颠倒**（[30 课](./30-quadratic.md) 的两步流程）：先定横坐标（对称轴 $h = 2$），再定纵坐标（谷底高度 $k = 1$）。初始代码打印成 (k, h)，正好装反；
2. **左加右减**（[35 课](./35-transformations.md) 误区一）：右移 2 格是 $(x-2)^2$，不是 $(x+2)^2$，所以 track 和 g 都要改成 `x - h`。有个隐蔽细节：在 $x=0$ 处 $(0+2)^2$ 与 $(0-2)^2$ 恰好相等，只验支架 P 根本抓不到方向错误——这正是验收必须动用另一侧支架 Q 的原因；
3. **反解 a 别忘平方**（缩放旋钮的来历）：把支架 P 代入 $5 = a(0-2)^2 + 1$，解得 $a = (5-1) \div 2^2 = 1$——高差除以水平距离的**平方**；漏了平方会得到 $-2$ 这种怪系数；
4. **串联先里后外**（[40 课](./40-inverse-composite.md)）：$f(g(4))$ 先算 $g(4) = 4 - 2 = 2$，再算 $f(2) = 2^2 + 1 = 5$，恰好等于轨道在 4 处的高度——"先挪后平方"正是这条轨道的装配顺序；哪台机器的挪法写反，复核立刻亮红灯。

修好后的完整代码：

```python
def track(x):
    return a * (x - h) ** 2 + k

h = 2
k = 1

def f(u):
    return u ** 2 + k

def g(x):
    return x - h

a = (5 - k) // (0 - h) ** 2

print(f"顶点: ({h}, {k})")
print(f"系数 a: {a}")

p_ok = track(0) == 5
q_ok = track(4) == 5
print(f"支架验收: {p_ok} {q_ok}")

print(f"串联复核: {f(g(4)) == track(4)}")
```

输出四行与判题窗逐字一致 ✓。三个旋钮各就各位：h 管"在哪"、k 管"多高"、a 管"多瘦"——到第 7 章，它们将改名换姓，叫振幅、频率与相位。
</details>
