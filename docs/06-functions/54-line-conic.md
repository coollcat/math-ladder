# 直线与圆锥曲线：设而不求

## 1. 从一个场景开始

隧道工程队在椭圆形截面的山体里沿直线掘进：入口、出口就是直线与椭圆的两个交点，掘进长度就是这两个交点连线的长度（弦长）。麻烦在于，交点坐标常常是无理数甚至写不出根式——可隧道长度必须报得出来。这一课的绝招叫**设而不求**：设出交点、列好方程，却从头到尾不真的把交点解出来，弦长照样到手。

## 2. 直觉解释

回忆上一课的直线与圆：联立、消元、判别式，三板斧。换成椭圆、抛物线，三板斧一样能用，只是消元后的二次方程更难看。但请注意一个代数事实：**想知道一根弦有多长，不需要知道两端在哪，只需要知道两根的"和"与"积"**。

二次方程 $Ax^2 + Bx + C = 0$ 的两根 $x_1, x_2$ 满足 $x_1 + x_2 = -\tfrac{B}{A}$、$x_1 x_2 = \tfrac{C}{A}$（韦达定理）。而弦长公式里出现的恰好是 $(x_1 - x_2)^2 = (x_1 + x_2)^2 - 4x_1 x_2$——完全由和与积决定。于是流程固定成四步：**设直线 → 联立消元 → 韦达写出和与积 → 代入弦长公式**。交点坐标从头到尾没露面。

## 3. 正式定义

**联立的标准流程**：直线 $y = kx + m$ 与圆锥曲线方程联立，消去 $y$ 得到关于 $x$ 的一元二次方程 $Ax^2 + Bx + C = 0$。

| 记号 | 名字 | 作用 |
| --- | --- | --- |
| $\Delta = B^2 - 4AC$ | 判别式 | $\Delta > 0$ 两个交点；$\Delta = 0$ 相切（一个）；$\Delta < 0$ 无交点 |
| $x_1 + x_2 = -\tfrac{B}{A}$ | 韦达和 | 弦中点的横坐标是它的一半 |
| $x_1 x_2 = \tfrac{C}{A}$ | 韦达积 | 与韦达和搭档造出 $(x_1 - x_2)^2$ |
| $(x_1 - x_2)^2 = (x_1+x_2)^2 - 4x_1x_2$ | 差的平方 | 全程不需要 $x_1, x_2$ 本尊 |

**弦长公式**（斜率 $k$ 存在时）：

$$|AB| = \sqrt{1 + k^2} \, |x_1 - x_2| = \sqrt{1 + k^2} \cdot \sqrt{(x_1 + x_2)^2 - 4x_1 x_2}$$

**面积表达**：把弦 $AB$ 当底、定点 $(x_0, y_0)$（比如原点）到直线 $Ax + By + C = 0$ 的距离 $d = \dfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$ 当高，$S = \tfrac{1}{2}|AB| \cdot d$。

## 4. 分步例题

**例**：直线 $y = 2x - 4$ 与抛物线 $y^2 = 4x$ 交于 $A$、$B$ 两点，求弦长，再求三角形 $OAB$（$O$ 为原点）的面积。

1. **联立消元**：把 $y = 2x - 4$ 代入 $y^2 = 4x$：$(2x - 4)^2 = 4x$，展开 $4x^2 - 16x + 16 = 4x$，整理得 $x^2 - 5x + 4 = 0$；
2. **验判别式**：$\Delta = 25 - 16 = 9 > 0$，确有两个交点；
3. **韦达**：$x_1 + x_2 = 5$，$x_1 x_2 = 4$，于是 $(x_1 - x_2)^2 = 25 - 16 = 9$；
4. **弦长**：$k = 2$，$|AB| = \sqrt{1 + 4} \times \sqrt{9} = 3\sqrt{5}$；
5. **面积**：原点到直线 $2x - y - 4 = 0$ 的距离 $d = \dfrac{4}{\sqrt{5}}$，$S = \tfrac{1}{2} \times 3\sqrt{5} \times \dfrac{4}{\sqrt{5}} = 6$。

事后验货（用求根公式真解一次）：$x = 1$ 或 $4$，交点 $(1, -2)$、$(4, 4)$——都在抛物线上（$(-2)^2 = 4$，$4^2 = 16$）✓，距离 $\sqrt{9 + 36} = 3\sqrt{5}$ ✓。这道题数字凑巧能解出来，但流程本身**一次没解过根**，下次遇到解不出的方程照样运转。

### 实验 2（python）：让韦达定理扫一遍截距

```python title="直线 y = 2x + m 与抛物线 y² = 4x"
import math                          # 数学库：sqrt 开平方

# sliders: m=-4 [-9:0:0.5]

# 联立 (2x+m)² = 4x，整理得 4x² + (4m-4)x + m² = 0，即 x² + (m-1)x + m²/4 = 0
S = 1 - m                            # 韦达和：x1 + x2 = -(m-1)
P = m * m / 4                        # 韦达积：x1 * x2 = m²/4
delta = (m - 1)**2 - 4 * P           # 判别式 Δ = (m-1)² - m²  展开 = 1 - 2m
if delta <= 0:
    print(f"m={m}: Δ={delta}，直线与抛物线没有两个交点")
else:
    diff2 = S * S - 4 * P            # (x1 - x2)²，不需要真解根
    chord = math.sqrt((1 + 2**2) * diff2)   # 弦长 = √(1+k²)·|x1-x2|，这里 k=2
    print(f"m={m}: 和={S}, 积={P}, 弦长={round(chord, 2)}")
```

拖动 $m$ 从 $-9$ 到 $0$：$m = -4$ 时弦长 $3\sqrt{5} \approx 6.71$（例题的答案）；$m$ 越接近 $0$，直线越贴近抛物线的顶点，弦反而越短（$m = 0$ 时缩到 $\sqrt{5} \approx 2.24$）；$\Delta$ 随 $m$ 增大而缩小，$m = 0.5$ 那一刻恰好相切，越过 $0.5$ 就连一个交点都没有了——**先查 $\Delta$ 再算弦长**，这个次序别颠倒。

::::warning[常见误区]

**误区一**："你以为联立完直接算弦长就行。" 消元后的二次方程若 $\Delta \le 0$，所谓两根是虚数，弦根本不存在。**先验判别式，再用韦达**，次序是安全带。

**误区二**："你以为弦长公式里的 $\sqrt{1+k^2}$ 可有可无。" 它来自两点间距离：$|AB| = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$，而 $y_1 - y_2 = k(x_1 - x_2)$，所以竖直方向也贡献长度。漏掉它，斜的弦一律被算短。

**误区三**："你以为抛物线和不相交的直线就一定'相离'。" 判别式那套话术对椭圆最贴切；抛物线有特例——与对称轴平行的直线（如 $y = 2$ 对 $y^2 = 4x$）只有一个公共点，却不是相切。说"相切"之前先确认直线确实"贴着"曲线。

::::

## 6. 练习

**练习 1**：直线 $y = x - 1$ 与抛物线 $y^2 = 4x$ 交于 $A$、$B$，求弦长 $|AB|$。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：不解根算弦长
# @check: 8
# @hint: y = x−1 代入 y²=4x 得 x²−6x+1=0，韦达和 6、积 1；(x₁−x₂)² = 和²−4·积 = 32。弦长公式别忘了因子 √(1+k²)，k=1 时是 √2，√(32×2)=8。
import math                          # 数学库：sqrt 开平方

# 联立 (x-1)² = 4x，整理得 x² - 6x + 1 = 0
S = 6                                # 韦达和 x1 + x2 = 6
P = 1                                # 韦达积 x1 * x2 = 1
k = 1                                # 直线斜率

diff2 = S * S - 4 * P                # (x1 - x2)²
chord = math.sqrt(diff2)             # ← 斜弦的长度只靠横向分量够吗？
print(round(chord))
```

<details>
<summary>点开查看逐步解答</summary>

1. 联立：$(x-1)^2 = 4x \Rightarrow x^2 - 6x + 1 = 0$，$\Delta = 36 - 4 = 32 > 0$，弦存在；
2. 韦达：$x_1 + x_2 = 6$，$x_1 x_2 = 1$，$(x_1 - x_2)^2 = 36 - 4 = 32$；
3. 斜率 $k = 1$，弦长 $= \sqrt{1 + 1} \times \sqrt{32} = \sqrt{64} = 8$。初始代码只算了横向分量 $\sqrt{32} \approx 5.66$，漏了竖直方向的贡献。

修正后的参考代码：

```python
import math

S = 6                                # 韦达和
P = 1                                # 韦达积
k = 1                                # 斜率

diff2 = S * S - 4 * P                # (x1 - x2)² = 32
chord = math.sqrt((1 + k*k) * diff2) # √(1+k²)·|x1−x2| = √64
print(round(chord))
```

输出 `8`，与判题窗一致 ✓。事后真解根：$x = 3 \pm 2\sqrt{2}$，对应 $y = 2 \pm 2\sqrt{2}$，两点距离 $\sqrt{(4\sqrt{2})^2 + (4\sqrt{2})^2} = 8$ ✓。这条弦所在的直线 $x - y - 1 = 0$ 恰好穿过焦点 $(1, 0)$——下一课会算出：过焦点的弦里，斜率 $k = 1$ 的这根恰好长 8。

</details>

**练习 2**：上题的弦 $AB$ 与原点 $O$ 构成的三角形面积是多少？直线是 $x - y - 1 = 0$，原点到它的距离 $d = \dfrac{1}{\sqrt{2}}$。

<details>
<summary>点开查看逐步解答</summary>

$S = \tfrac{1}{2} \times |AB| \times d = \tfrac{1}{2} \times 8 \times \dfrac{1}{\sqrt{2}} = \dfrac{4}{\sqrt{2}} = 2\sqrt{2}$。面积表达的一般套路：**弦当底、定点到直线的距离当高**——两个量都能用韦达与距离公式间接拿到，依然不用解交点。
</details>

## 7. 边界与适用条件

设直线为 $y = kx + m$ 时默认斜率存在；**竖直直线**（如 $x = t$）联立时直接代入 $x = t$ 解一元一次方程，不能用韦达那套，要单独处理。韦达定理依赖消元后是**二次**方程：若二次项系数 $A = 0$（直线平行于抛物线对称轴等情况），只剩一个交点，公式失效。判别式与交点个数的对应在椭圆上最干净；抛物线与双曲线各有特例（切线 vs 平行于轴/渐近线方向的直线），下结论前多看一眼曲线形状。

## 8. 选读：韦达定理的一行来历

<details>
<summary>选读 · 为什么两根之和恰好是 −B/A</summary>

设 $Ax^2 + Bx + C = 0$（$A \neq 0$）的两根为 $x_1, x_2$，由求根公式：

$$x_1 = \frac{-B + \sqrt{\Delta}}{2A}, \qquad x_2 = \frac{-B - \sqrt{\Delta}}{2A}$$

相加时根号项互相抵消：$x_1 + x_2 = -\tfrac{B}{A}$；相乘用平方差：$x_1 x_2 = \dfrac{B^2 - \Delta}{4A^2} = \dfrac{C}{A}$。所以韦达定理不是新知识，只是**求根公式的和与积被预先打包**。更优雅的证法是因式分解 $A(x - x_1)(x - x_2) = Ax^2 - A(x_1+x_2)x + Ax_1x_2$，与原式逐项对照系数即得——这也顺带说明结论对 $\Delta = 0$（重根）照样成立。
</details>
