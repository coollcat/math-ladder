# 函数是机器：abs / floor / ceil 的诞生

## 1. 从一个场景开始

自动售货机是台讲信用的机器：按 B3 掉可乐，按一百次也掉一百次可乐，从不闹脾气。数学把这种"投进去一个数、吐出来一个数"的装置叫做**函数**——它朴素得像铁皮盒子，却是整座数学大厦的传送带（卷一压轴的傅里叶变换，本质上就是一台喂进信号、吐出频谱的巨型售货机）。

本课还要办一场出生仪式：三个马上要天天用的工具——`abs`、`math.floor`、`math.ceil`——都在这一课正式诞生。

## 2. 直觉解释

一台函数机器长这样：

> 输入口 x → 加工车间 → 输出口 f(x)

两条铁律：

1. **一次只收一个数**，也只吐一个数；
2. **同样的输入永远得到同样的输出**——机器没有情绪，不看你脸色。

比如加工规则是"加 2"：投进 0 吐出 2；投进 5 吐出 7；再投一次 5，还是 7。

## 3. 正式定义

把加工规则写成式子：

$$f(x) = x + 2$$

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $f$ | 函数名 | 这台机器的名字 |
| $x$ | 自变量 | 投进去的数 |
| $f(x)$ | 函数值 | 机器吐出来的数 |

$f(5)$ 读作"f 在 5 处的值"，代入得 $f(5)=5+2=7$。注意 $f(x)$ 是"机器作用在 x 上"的意思，**不是** $f \times x$。

机器肯收的全部输入叫**定义域**，可能吐出的全部输出叫**值域**。本课先记住这两个名字。

## 4. 分步例题：三台经典机器

### 例 1 · 距离机器（先手工）

问：$-7$ 到 0 有多远？数轴上从 $-7$ 走到 0 要走 7 步。"到 0 的距离"记作 $|-7|$，读作"$-7$ 的绝对值"。距离不分方向，所以 $|-7|=7$、$|3|=3$。

手工造一台这样的机器：

```python title="手工版绝对值"
def my_abs(x):        # 自定义函数，第 0 章约定四见过
    if x >= 0:        # if：条件成立才执行这一支（第 1 章加法课首用过）
        return x      # 非负数离 0 的距离就是它自己
    else:             # else：条件不成立走另一支
        return -x     # 取相反数，负变正

print(my_abs(-7))
print(my_abs(3))
```

宣布：这台机器太常用，Python 自带成品 `abs()`。以后不必再自己造。

### 例 2 · 向左取整（先手工）

规则："在数轴上从 x 出发，**向左**走到最近的整数。"

- 从 2.9 向左走 → 踩到 2，停。结果 2。
- 从 2.1 向左走 → 还是 2。
- 从 $-2.5$ 向左走 → 穿过 $-2$ 一路到 $-3$ 才踩到整数。结果是 $-3$，不是 $-2$！

宣布：这就是 Python 的 `math.floor()`（地板）。它住在 math 模块里，用之前要 `import math`。

### 例 3 · 向右取整（先手工）

方向反过来："从 x 出发，**向右**走到最近的整数。"

- 从 2.1 向右走到 3；
- 从 $-2.9$ 向右走到 $-2$——注意是 $-2$ 不是 $-3$！

宣布：这就是 `math.ceil()`（天花板），和 floor 同住 math 模块。

一句话记住三兄弟：**abs 管距离（永远非负），floor 向左倒，ceil 向右够。**

## 5. 动手实验

### 实验 1：三个函数在一排数上的行为表格

```python title="一排数过三关"
import math  # 老朋友 math（第 3 章引入）：这回请出住在里面的 floor 和 ceil

numbers = [-2.5, -1.2, 0, 0.8, 2.9, 3]

for n in numbers:
    print(f"x={n}   abs={abs(n)}   floor={math.floor(n)}   ceil={math.ceil(n)}")
```

逐行读表：正小数的 floor 是左边那个整数；负小数的 floor 会"跌到更小的整数"——这正是向左的含义。而 ceil 对每个数都给出右边那个整数。

### 实验 2（python）：拖一个实数，四件工具一起出招

表格是死的，机器要喂活的输入。拖动滑块让 $x$ 扫过小数地带，盯着四个输出各自的反应：

```python title="滑块对照：abs / floor / ceil / round"
import math   # floor 和 ceil 住在 math 模块里

# sliders: x=2.6 [-5:5:0.1]
# x 由滑块注入，步长 0.1，可扫过正负小数
print(f"x = {x}")
print(f"abs(x)   = {abs(x)}")           # 距离：永远非负
print(f"floor(x) = {math.floor(x)}")    # 向左踩到最近的整数
print(f"ceil(x)  = {math.ceil(x)}")     # 向右够到最近的整数
print(f"round(x) = {round(x)}")         # 四舍五入：只认最近的那个
```

三个观察任务：

1. 把 x 拖进负数区（比如 -2.6）：floor 是 -3 不是 -2——"向左"在负数地盘最容易翻车（快问快答的主角就是它）；
2. 找出 floor 和 round 给出**不同**答案的位置（提示：默认的 x=2.6 就是一处——floor 咬死左边给 2，round 谁近跟谁给 3）；
3. 停在正好一半的 2.5 上看看 round：Python 遇到"两边一样近"会挑偶数那边，所以 round(2.5) 得 2。先见过这个怪癖，日后就不会怀疑机器坏了。

### 实验 3：floor 的楼梯

先玩零等待的网页版：蓝色楼梯是 floor 的图像，橙色虚线是对照直线 $y=x$。盯着整数附近看——楼梯每一级都贴着虚线，或比它更矮：

### 快问快答

```quiz
floor(-2.5) 等于几？
- -2
- -3 [*]
- 2
? floor 沿数轴向左取整。从 -2.5 向左走，最近的整数是 -3。"去掉小数部分得 -2" 是朝零截断的直觉，方向反了。
```

:::warning[常见误区]

**误区一**："abs(-7) 等于 ±7，两个答案都对。"
绝对值是**距离**，距离只有一个值：abs(-7)=7。它的输出永远非负。

**误区二**："floor 就是四舍五入。"
四舍五入看"最近"，floor 只看方向。floor(2.9)=2，哪怕 3 更近。

**误区三**："floor(-2.9)=-2，去掉小数部分就行。"
那叫朝零截断。floor 向左：floor(-2.9)=-3。（ceil 同理向右：ceil(-2.9)=-2。）

:::

## 7. 选读：高斯的地板与天花板

<details>
<summary>选读 · 记号 ⌊x⌋ 与 ⌈x⌉</summary>

数学书里 floor 写作 $\lfloor x \rfloor$、ceil 写作 $\lceil x \rceil$——像给数装了地板和天花板。这套符号高斯当年写作 $[x]$，如今通用的 $\lfloor x \rfloor / \lceil x \rceil$ 记号是 Iverson 在 1962 年定下的；编程世界嫌符号难打，改用英文单词命名，反而更直白。

再回味一下铁律二："同样输入必得同样输出"。这条纪律排除了"心情好就多加 1"的任性规则，也让函数成为可以放心组合、求反、画图的可靠对象——第 16 章傅里叶变换能被反复调用而不出错，靠的就是它。

</details>
