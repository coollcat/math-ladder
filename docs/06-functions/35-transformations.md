# 图像变换三件事：平移、翻折、缩放

## 1. 从一个场景开始

学会一条曲线，等于学会一整族曲线——只要会三招"整容术"：挪位置（平移）、照镜子（翻折）、拉伸（缩放）。第 7 章的正弦波、乃至卷一枢纽站的傅里叶变换，翻来覆去用的就是这三招。今天用抛物线当模特，把三件事一次看全。

## 2. 直觉解释

- **平移**：整条曲线搬家。每个点朝同一方向移动同样距离，形状纹丝不变；
- **翻折**：乘 $-1$ 上下颠倒——x 轴上方翻到下方，像沿 x 轴放了一面镜子；
- **缩放**：乘 a 变胖瘦。$\lvert a\rvert > 1$ 纵向拉长变"瘦"，$0 < \lvert a \rvert < 1$ 压扁变"胖"。

## 3. 正式定义

设基准函数为 $f(x)$（本课取 $f(x)=x^2$），则：

| 操作 | 表达式 | 效果 |
| --- | --- | --- |
| 上移 k 格 | $f(x) + k$ | 整体向上平移 |
| 右移 h 格 | $f(x - h)$ | 注意：x 里**减**是向右 |
| 上下翻折 | $-f(x)$ | 每个函数值变号 |
| 纵向缩放 | $a \cdot f(x)$ | $\lvert a\rvert$ 大于 1 拉高、小于 1 压矮 |
| 左右翻折 | $f(-x)$ | 每个输入先变号，图像沿 y 轴照镜子 |
| 横向缩放 | $f(a x)$ | $a>1$ 把图像向 y 轴压窄；$0<a<1$ 把图像拉宽 |

最容易记反的是"加在谁身上"：加在 x 上管左右，而且方向相反（左加右减）；加在整体上管上下。想右移 3 就写 $(x-3)^2$，不是 $(x+3)^2$。

## 4. 分步例题

描述 $y = -(x-1)^2 + 2$ 是怎样从 $y = x^2$ 变来的：

1. 平移：$(x-1)^2$ —— 向右挪 1 格，顶点到 $(1,0)$；
2. 翻折：$-(x-1)^2$ —— 开口朝下，顶点仍是最低点变成最高点；
3. 平移：$+2$ —— 整体上移 2 格，顶点落到 $(1,2)$。

读式子的顺序是从 x 的修改到整体的加减：先看括号里动了什么，再看外面加了什么。

### 实验 4（viz）：横向缩放——楼梯变窄或变宽

还是用楼梯看方向：拖动 $a$，蓝色楼梯的每一级宽度会跟着变。


$a=2$ 时，原来走到 $x=1$ 才升高的台阶，现在 $x=0.5$ 就升高了——图像被压窄；$a=0.25$ 则要等到 $x=4$，图像被拉宽。注意：对 $y=x^2$ 这种左右对称模特，$f(ax)$ 会恰好伪装成纵向缩放；换成分段或不对称曲线，才能看见它真正动的是输入。
这里的竖线也一样，只是连线辅助痕迹，不代表台阶之间的点都属于函数图像。

### 实验 5（python）：三条曲线同框对照

```python title="原版、翻折版、瘦身版"
import matplotlib.pyplot as plt

xs = []
for i in range(0, 61):
    xs.append(-3 + i * 0.1)

base = []
flipped = []
slim = []
for t in xs:
    base.append(t * t)
    flipped.append(-(t * t))
    slim.append(0.25 * t * t)

plt.plot(xs, base, label="y = x^2")
plt.plot(xs, flipped, label="y = -x^2 (翻折)")
plt.plot(xs, slim, label="y = 0.25*x^2 (变胖)")
plt.axhline(0, color="gray", linestyle="--")
plt.axvline(0, color="gray", linestyle="--")
plt.legend()
plt.grid(True)
```

三条曲线零点都在原点：翻折与缩放都不挪窝，只有平移才改变位置。

### 快问快答

```quiz
把 y = x^2 的图像右移 3 格，得到的是？
- y = (x - 3)^2 [*]
- y = (x + 3)^2
- y = x^2 + 3
? 左加右减：想右移就在 x 里减。(x+3)^2 其实是左移 3；x^2+3 则是上移 3。
```

```quiz
把 y = floor(x) 变成 y = floor(-x)，楼梯发生了什么？
- 上下颠倒
- 左右调头 [*]
- 整体向上平移一格
? f(-x) 改的是输入：原来的 x 换成相反数，所以图像沿 y 轴翻折。上下颠倒对应整体乘 -1。
```

:::warning[常见误区]

**误区一**："$(x+3)^2$ 是右移 3。" 
加在 x 上方向相反：$(x+3)^2$ 是左移。"左加右减"，减才是往右。

**误区二**："f(x)+3 和 f(x+3) 差不多。" 
完全不同的两个动作：前者整体上移 3（上下动），后者左移 3（左右动）。看清楚加号落在谁身上。

**误区三**："乘 a 只会让图变大。" 
$0<a<1$ 是压缩变胖；a 为负还附赠一次上下翻折。缩放的幅度看 $\lvert a \rvert$，方向看符号。

:::

<details>
<summary>点开查看逐步解答</summary>

$$y = -(x-2)^2 + 5$$

三步对应三个旋钮：$(x-2)$ 右移 2、负号翻折开口向下、$+5$ 上移 5，顶点 $(2,5)$。验证：代入 $x=2$ 得 $y=5$，是最高点。

## 7. 选读：为什么 f(x-h) 反而是右移

<details>
<summary>选读 · 曲线的"延迟满足"</summary>

直觉上"减 h 应该往左"才对，但事实相反。原因：令 $g(x) = f(x-h)$，那么 $g(h) = f(0)$——新函数要走到 $x=h$ 处，才复现出老函数在 0 处的值。整条曲线像是被推迟了 h 才上演：**延迟 = 右移**。

这个"相位延迟"的视角在第 7 章会原样重现：把正弦波写成 $\sin(x - \varphi)$，波就整体右移 $\varphi$——那时它叫相位。

</details>
