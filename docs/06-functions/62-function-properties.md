# 函数的三个脾气：单调、奇偶、周期

## 1. 从一个场景开始

手机里的运动 App 画出你今天的步数折线，蝴蝶的两只翅膀能严丝合缝地对折，钟摆每隔几秒就把相同的动作重演一遍。三张图三种脾气：步数图只升不降、蝴蝶左右镜像、钟摆循环往复。

数学给它们各起了一个名字——**单调性**、**奇偶性**、**周期性**。它们不是三道新题型，而是三副"看一眼图就能下判断"的眼镜。第 7 章的正弦波身上，三样脾气会同时出现；今天先分别认全。

## 2. 直觉解释

先不写式子，只说画面：

- **单调**：爬楼梯只上不下（递增），溜滑梯只下不上（递减），山路有起有伏则两者都不是。眼睛只做一件事——**从左到右扫，看有没有回头路**；
- **奇偶**：偶函数是"沿 y 轴放一面镜子"，左右两半照镜子重合；奇函数是"绕原点转半圈"，转 180° 后与自身重合。镜子放的位置不一样：一个在 y 轴上，一个在原点；
- **周期**：壁纸的花纹。把整张图沿 x 轴平移一格，花纹与原来**完全重合**——那一格的长度就是周期；平移半格对不上，说明半格不是周期。

三者描述的都是**一整段曲线的行为**，不是某一个点的性质：说 $f(2)=5$ 是报一个数，说 $f$ 递增是在描述一整段。

## 3. 正式定义

### 3.1 单调性

设区间 $D$ 在 $f$ 的定义域内，对 $D$ 中任意两个自变量 $x_1 < x_2$：

$$\text{恒有 } f(x_1) < f(x_2) \Rightarrow f \text{ 在 } D \text{ 上递增} \qquad \text{恒有 } f(x_1) > f(x_2) \Rightarrow f \text{ 在 } D \text{ 上递减}$$

| 符号 | 角色 | 说明 |
| --- | --- | --- |
| $D$ | 讨论的区间 | **必须先说清在哪个区间上**，脱离区间谈单调性没有意义 |
| $x_1, x_2$ | 任意两点 | "任意"两个字最重要：举一百个例子成立都不算，找出一个反例就推翻 |
| $=$ 的情形 | 常函数 | 若恒有 $f(x_1)=f(x_2)$，既不递增也不递减（本课只讲严格版本） |

三类基本函数的判断口诀：

| 函数 | 看什么 | 结论 |
| --- | --- | --- |
| $y = ax + b$ | 斜率 $a$ | $a>0$ 递增，$a<0$ 递减，$a=0$ 常函数 |
| $y = ax^2 + bx + c$ | 对称轴 $x=-\dfrac{b}{2a}$ | $a>0$：左减右增；$a<0$：左增右减 |
| $y = \dfrac{ax+b}{cx+d}$ | 交叉相乘之差 $ad-bc$ | $ad-bc>0$ 递增，$<0$ 递减；**只能在断点 $x=-\dfrac{d}{c}$ 两侧分开说** |

最后一行把第 4 课的反比例函数包了进去：取 $a=0,\ b=1,\ c=1,\ d=0$ 得 $y=\dfrac{1}{x}$，此时 $ad-bc = -1 < 0$，两支各自递减。推导见 §7 选读。

### 3.2 奇偶性

**前提**：定义域 $D$ 必须关于原点对称——$x \in D$ 时必有 $-x \in D$。前提不成立，奇偶性免谈。

$$\text{偶函数：} f(-x) = f(x) \qquad \text{奇函数：} f(-x) = -f(x)$$

| 类型 | 代数条件 | 图像特征 |
| --- | --- | --- |
| 偶函数 | $f(-x)=f(x)$ | 关于 **y 轴**轴对称 |
| 奇函数 | $f(-x)=-f(x)$ | 关于**原点**中心对称 |
| 非奇非偶 | 两条都不成立（含定义域不对称） | 无对称性 |

判定固定三步：**先看定义域 → 再算 $f(-x)$ → 与 $f(x)$、$-f(x)$ 比**。定义域不对称时，第一步就出局。

### 3.3 周期性

若存在**非零常数** $T$，使得对定义域内**每一个** $x$ 都有 $f(x+T) = f(x)$，则称 $f$ 为周期函数，$T$ 是它的一个周期；所有正周期中最小的那个叫**最小正周期**（如果存在）。

| 符号 | 角色 | 说明 |
| --- | --- | --- |
| $T$ | 周期 | 平移量；若 $T$ 是周期，则 $2T,\ 3T$ 也都是 |
| $x$ | 定义域内任意一点 | "每一个 $x$"缺一不可；只在一部分点上重合不算 |
| 最小正周期 | 最紧的一个 | 常函数（如 $y=3$）任何非零 $T$ 都是周期，**没有**最小正周期 |

第 7 章会见到最有名的周期函数 $\sin x$（最小正周期 $2\pi$）。本课先用一个不需要三角函数的例子：

$$f(x) = x - \lfloor x \rfloor \quad \text{（x 的小数部分）}$$

$\lfloor x \rfloor$ 是第 1 课就认识的 `math.floor`（向左取整）。$f(1.3)=f(2.3)=f(5.3)=0.3$——整数部分被减掉，剩下的"尾巴"每隔 1 重演一次，最小正周期是 1。

## 4. 分步例题

**例 1**：求 $f(x) = x^2 - 2x$ 的单调区间。

1. 认系数：$a=1>0$，$b=-2$，开口向上；
2. 定分界：对称轴 $x = -\dfrac{-2}{2\times 1} = 1$，把实数轴切成 $(-\infty, 1]$ 与 $[1, +\infty)$；
3. 判方向：$a>0$ 时"左减右增" → 左侧递减、右侧递增；
4. 自检：$f(0)=0$、$f(1)=-1$、$f(2)=0$，从 0 到 1 在降、1 到 2 在升 ✓。

**例 2**：判断 $g(x) = x^3 + 2x$ 的奇偶性。定义域 $\mathbb{R}$ 对称 ✓；$g(-x) = (-x)^3 + 2(-x) = -x^3-2x$，与 $-g(x) = -x^3-2x$ 相等 → **奇函数**。自检 $g(1)=3$、$g(-1)=-3$ 互为相反数 ✓。

**例 3**：判断 $h(x) = x^2 + x$ 的奇偶性。定义域 $\mathbb{R}$ 对称 ✓；$h(-x) = x^2 - x$，既不等于 $h(x)=x^2+x$（差 $2x$），也不等于 $-h(x)=-x^2-x$ → **非奇非偶**。自检 $h(1)=2$、$h(-1)=0$，既不相等也不相反 ✓。

**例 4**：验证 $T=1$ 是 $f(x)=x-\lfloor x\rfloor$ 的周期，而 $T=0.5$ 不是。

1. 由 $\lfloor x+1 \rfloor = \lfloor x \rfloor + 1$（整体右移一格，地板也升一级）；
2. 得 $f(x+1) = x+1-(\lfloor x \rfloor+1) = x - \lfloor x \rfloor = f(x)$ ✓；
3. 试 $T=0.5$：$f(0.3+0.5)=f(0.8)=0.8 \neq f(0.3)=0.3$ → 不是周期。

### 实验 4（python）：让机器报出单调性

```python title="机器版单调性裁判"
# sliders: h=2 [-3:3:1]       # 对称轴位置，拖动它看单调性怎么分区

def f(x):
    return (x - h) ** 2          # ** 是乘方：(x-h)²，对称轴就是 x = h

def trend(xs):
    up = True                    # 先假设一路上坡
    down = True                  # 再假设一路下坡
    for i in range(len(xs) - 1):
        d = f(xs[i + 1]) - f(xs[i])   # 后一个函数值减前一个
        if d <= 0:               # 只要有一次没升上去，就不是递增
            up = False
        if d >= 0:               # 只要有一次没降下来，就不是递减
            down = False
    if up:
        return "递增"
    if down:
        return "递减"
    return "有升有降"

left = []                        # 对称轴左侧：从 h-2 走到 h
right = []                       # 对称轴右侧：从 h 走到 h+3
for i in range(0, 21):
    left.append(h - 2 + i * 0.1)
    right.append(h + i * 0.15)

print(f"对称轴 x = {h}")
print("左侧:", trend(left))
print("右侧:", trend(right))
print("整段:", trend(left + right))
```

三行结论依次是"递减""递增""有升有降"：对称轴把整条曲线切成两半，**每一半单独看都有单一的单调性，合起来就没有了**。这就是"必须先说清区间"的含义。

一次函数没有这种麻烦：$y=ax+1$ 的斜率 $a$ 符号定了，整条直线的单调性就定了——$a>0$ 越往右越高，$a<0$ 越往右越低，中间没有可以分段讨论的拐点。**有拐点的函数才需要分区间说**。

### 快问快答

```quiz
关于反比例函数 y = 1/x 的单调性，下面哪句话是对的？
- 它在整个定义域上递减
- 它在负半轴和正半轴上各自递减，但不能跨过 x = 0 说递减 [*]
- 它在整个定义域上递增
? 取 x=-1 与 x=1：f(-1) = -1 小于 f(1) = 1，x 变大函数值也跟着变大，跨过断点"递减"当场失效。
```

::::warning[常见误区]

**误区一**："1/x 在定义域上递减。" 
两支各自递减没错，合起来说是错的：$x_1=-1 < x_2=1$，却有 $f(-1)=-1 < f(1)=1$，与"递减"要求的 $f(x_1)>f(x_2)$ 直接冲突。图像在中间断开的函数，**单调区间必须一段一段地写**。

**误区二**："直接算 $f(-x)$ 就能判奇偶，定义域不用管。" 定义域不关于原点对称时，$f(-x)$ 可能根本算不出来——比如 $y=\sqrt{x}$ 定义在 $x\ge 0$，$f(-1)$ 无意义。它是非奇非偶，但不是"算出来不相等"，而是**没资格参评**。

**误区三**："随便找个 $T$ 让一部分点重合，就是周期。" $f(x+T)=f(x)$ 必须对定义域内**每一个** $x$ 成立。另外常函数（比如 $y=3$）任何非零 $T$ 都满足式子，因此它**没有最小正周期**。

::::

## 6. 练习

**练习 1**：判断 $f(x)=x^4-3x^2$ 与 $g(x)=x^3-x$ 的奇偶性。下面的裁判程序能跑，但结论是错的，改到通过：

```exercise
# @title: 练习：机器判定奇偶性
# @check: f: 偶
# @check: g: 奇
# @hint: 采样点只给了 x=0 一个。在原点上，f(0) 与 -f(0) 只有在 f(0)=0 时才相等——这两个函数碰巧都过原点，于是双双被判成"偶"。把 xs 换成跨越原点两侧的一串数，例如 [-3, -2, -0.5, 0.5, 1.5, 2, 3]。
def f(x):
    return x**4 - 3*x**2

def g(x):
    return x**3 - x

def judge(fn, xs):
    even = True
    odd = True
    for x in xs:
        if abs(fn(-x) - fn(x)) > 0.000000001:
            even = False
        if abs(fn(-x) + fn(x)) > 0.000000001:
            odd = False
    if even:
        return "偶"
    if odd:
        return "奇"
    return "非奇非偶"

xs = [0]                 # ← 只测一个点，测得出什么？

print("f:", judge(f, xs))
print("g:", judge(g, xs))
```

**练习 2**：$T=1$ 是 $f(x)=x-\lfloor x\rfloor$ 的周期吗？$T=0.5$ 呢？下面的判据写歪了，改到通过：

```exercise
# @title: 练习：T=1 是这个锯齿的周期吗
# @check: T=1 是周期吗: True
# @check: T=0.5 是周期吗: False
# @hint: 周期说的是"把自变量平移 T 之后函数值不变"——平移发生在括号里面。现在这行比的是"f(x) 加上 T"与"f(x) 自己"，任何非零的 T 都会被判 False。把 f(x) + T 改回 f(x + T)。
import math

def f(x):
    return x - math.floor(x)          # 小数部分：f(1.3) = 0.3，f(5.3) = 0.3

def is_period(T):
    for x in [0, 0.25, 0.5, 1.3, 2.7, -1.4, -0.7, 3.99, 5.5, -3.25]:
        if abs(f(x) + T - f(x)) > 0.000000001:   # ← 周期是"自变量"平移，不是函数值平移
            return False
    return True

print("T=1 是周期吗:", is_period(1))
print("T=0.5 是周期吗:", is_period(0.5))
```

**练习 3**：$y = \dfrac{2x+1}{x-1}$ 的单调性如何？写出单调区间。

<details>
<summary>点开查看逐步解答</summary>

1. 认系数：$a=2,\ b=1,\ c=1,\ d=-1$，算 $ad-bc = 2\times(-1) - 1\times 1 = -3 < 0$ → 递减；
2. 找断点：分母为零处 $x = -\dfrac{d}{c} = 1$，把定义域切成 $(-\infty, 1)$ 与 $(1, +\infty)$；
3. 结论：**在 $(-\infty, 1)$ 与 $(1, +\infty)$ 上分别递减**，但**不能**说"在定义域上递减"。自检：$x_1=2,\ x_2=3$（同侧）得 $f(2)=5$、$f(3)=3.5$，确实在降；$x_1=0,\ x_2=2$（跨断点）得 $f(0)=-1$、$f(2)=5$，反而升了。

</details>

## 7. 选读：三个判据各自的来历

<details>
<summary>选读 · 从定义推到口诀（含分式的完整推导）</summary>

$$f(x_2) - f(x_1) = \frac{ax_2+b}{cx_2+d} - \frac{ax_1+b}{cx_1+d} = \frac{(ax_2+b)(cx_1+d) - (ax_1+b)(cx_2+d)}{(cx_1+d)(cx_2+d)}$$

取 $x_1<x_2$ 且都在断点 $x=-\dfrac{d}{c}$ 的同一侧：分子展开后 $acx_1x_2$ 与 $bd$ 双双抵消，剩下 $(ad-bc)(x_2-x_1)$；分母两个因子同号（同侧保证 $cx+d$ 符号一致），乘积为正。所以差值的符号完全由 $ad-bc$ 决定——这就是 §3.1 表格里那条口诀的出处。

**偶性 → 轴对称**：$(x, f(x))$ 在图上，由 $f(-x)=f(x)$ 知 $(-x, f(x))$ 也在，两点横坐标相反、纵坐标相同，正是关于 y 轴的镜像。**奇性 → 中心对称**：由 $f(-x)=-f(x)$ 知 $(-x, -f(x))$ 在图上，与 $(x, f(x))$ 横纵坐标双双相反，正是绕原点转 180°。**周期性 → 平移重合**：$f(x+T)=f(x)$ 意味着点 $(x, f(x))$ 右移 $T$、高度不变后仍在图上，整条曲线平移 $T$ 后与自身重合——这就是"壁纸花纹"的数学表达。

</details>
