# 直线与圆：给图形发身份证

## 1. 从一个场景开始

激光雕刻机给一枚圆形金属徽章刻花纹：激光是一条直线，徽章边缘是一个圆。光束可能完全打空、可能擦着边缘只留下一个刻点、也可能横穿徽章留下一道弦。三种结局取决于什么？答案藏在一个比值里：**圆心到直线的距离**除以**半径**。这一课先把直线和圆翻译成方程，再让方程替我们回答"位置"问题。

## 2. 直觉解释

第 6 章开头讲过一次函数 $y = ax + b$——那是把直线当"机器"看：输入 x，输出 y。但几何里直线还有别的身份证：

- **一点 + 一个方向**：知道直线经过 $(2, 3)$、还知道它"往上爬"的陡峭程度（斜率），直线就被钉死了——这是点斜式的来历；
- **两个身份互换**：$y = kx + b$ 竖不起来（竖直直线没有斜率），所以还需要一个"不挑方向"的一般式 $Ax + By + C = 0$，横平竖直都能装。

圆更省事：圆就是"到圆心距离恒等于半径"的点集体，把这句话用距离公式写出来，方程自己就冒出来了。

所以"光束打不打得到徽章"这种几何问题，从此可以翻译成"两个方程联立后解的情况"这种代数问题——坐标法的精神就在这一步。

## 3. 正式定义

**直线方程的三种写法**：

| 名称 | 形式 | 适用条件 | 备注 |
| --- | --- | --- | --- |
| 点斜式 | $y - y_0 = k(x - x_0)$ | 过点 $(x_0, y_0)$、斜率 $k$ | 竖直直线写不出（$k$ 不存在） |
| 斜截式 | $y = kx + b$ | 斜率 $k$、纵截距 $b$ | 点斜式取 $(0, b)$ 的特例 |
| 一般式 | $Ax + By + C = 0$ | $A$、$B$ 不同时为 0 | 横平竖直都能装，联立联它 |

**平行与垂直**（两直线斜率都存在时）：

- $l_1 \parallel l_2 \iff k_1 = k_2$（且不重合，即截距不同）；
- $l_1 \perp l_2 \iff k_1 \, k_2 = -1$。

若一条竖直（斜率不存在），则与它垂直的直线必水平（$k = 0$），与它平行的直线也竖直——这两个特例不能用上面的式子判，要单独看。

**圆的两种方程**：

| 名称 | 形式 | 要点 |
| --- | --- | --- |
| 标准方程 | $(x - a)^2 + (y - b)^2 = r^2$ | 圆心 $(a, b)$、半径 $r$，一眼读出 |
| 一般方程 | $x^2 + y^2 + Dx + Ey + F = 0$ | 当 $D^2 + E^2 - 4F > 0$ 时表示圆，圆心 $(-\tfrac{D}{2}, -\tfrac{E}{2})$，半径 $r = \tfrac{1}{2}\sqrt{D^2 + E^2 - 4F}$ |

**点到直线的距离公式**：点 $P(x_0, y_0)$ 到直线 $Ax + By + C = 0$ 的距离

$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

## 4. 分步例题

**例 1**：推导距离公式（平移法：把点临时挪到原点，算完再挪回来）。

1. **平移**：把整个画面平移，让 $P$ 落在原点。平移不改变距离，直线方程里的常数变成 $C' = Ax_0 + By_0 + C$，问题变成"原点到直线 $Ax + By + C' = 0$ 的距离"；
2. **作垂线**：设垂足 $H(x, y)$。直线 $l$ 的斜率是 $-\tfrac{A}{B}$（$B \neq 0$ 时），所以垂线 $OH$ 的斜率是 $\tfrac{B}{A}$，即 $H$ 在直线 $y = \tfrac{B}{A}x$ 上；
3. **联立**：把 $y = \tfrac{B}{A}x$ 代入 $Ax + By + C' = 0$，解出 $x = -\tfrac{AC'}{A^2 + B^2}$，$y = -\tfrac{BC'}{A^2 + B^2}$；
4. **算距离**：$d = |OH| = \sqrt{x^2 + y^2} = \dfrac{|C'|\sqrt{A^2 + B^2}}{A^2 + B^2} = \dfrac{|C'|}{\sqrt{A^2 + B^2}}$；
5. **挪回来**：代回 $C' = Ax_0 + By_0 + C$，得公式。（$B = 0$ 时直线是竖直线 $x = -\tfrac{C}{A}$，距离 $|x_0 + \tfrac{C}{A}|$，公式同样成立。）

**例 2**：判断直线 $3x + 4y - 20 = 0$ 与圆 $x^2 + y^2 = 4$ 的位置关系。

1. **读圆**：圆心 $(0, 0)$，半径 $r = 2$；
2. **算距离**：$d = \dfrac{|3 \times 0 + 4 \times 0 - 20|}{\sqrt{3^2 + 4^2}} = \dfrac{20}{5} = 4 > r = 2$，直线在离圆心 4 的地方跑，圆只够得着 2——**相离**；
3. **换常数对比**：把 $-20$ 换成 $-10$，$d = 2 = r$，**相切**；换成 $0$，直线过圆心，$d = 0 < r$，**相交**；
4. **规矩**：$d < r$ 相交、$d = r$ 相切、$d > r$ 相离。也可以联立方程看判别式 $\Delta$：$\Delta > 0$ 两个交点（相交）、$\Delta = 0$ 一个（相切）、$\Delta < 0$ 没有（相离）——两种判法该一致。

右侧会实时列出直线与圆的**交点坐标**。三个任务：

1. 先把 $k$ 拧到 $0$（水平线），再把 $m$ 从 1 慢慢拖到 2：交点从两个变成一个（直线擦到圆的顶上，$y = 2$ 恰好相切），再拖过 2 交点消失——相离；
2. 固定 $m = 1$，拧 $k$：无论怎么拧，只要直线还穿过圆内，交点就一直是两个——**相交还是相离，跟方向无关，只由圆心距决定**；
3. 拧出一条恰好相切的直线（比如 $k = 0$、$m = 2$ 或 $m = -2$），记下交点只有一个。

   顺带一提：$k \neq 0$ 时相切的临界值不再是 2，而是 $|m| = 2\sqrt{1 + k^2}$（圆心距 $d = \tfrac{|m|}{\sqrt{1+k^2}}$ 要恰好等于 $r = 2$）——斜率越陡，需要的 $|m|$ 越大。

### 实验 2（python）：五种直线的体检报告

```python title="圆 x²+y²=25 与直线 3x+4y+m=0 的位置"
import math                        # 数学库：sqrt 开平方

r = 5                              # 圆的半径
for m in [-30, -25, -15, 15, 25, 30]:   # 六个不同的截距，逐条体检
    d = abs(m) / math.sqrt(3**2 + 4**2) # 圆心(0,0)到直线的距离：分子是 |m|
    if d < r:                      # 距离小于半径：穿过圆
        chord = 2 * math.sqrt(r*r - d*d)  # 弦长 = 2·√(r²−d²)，勾股定理
        print(f"m={m}: 相交, d={d}, 弦长={chord}")
    elif d == r:                   # 距离恰好等于半径：擦边
        print(f"m={m}: 相切, d={d}")
    else:                          # 距离超过半径：够不着
        print(f"m={m}: 相离, d={d}")
```

六行报告排出来，$m = \pm 25$ 时 $d = 5 = r$ 恰好相切，两边分别是相交与相离——对称得很。再看弦长：$m$ 的绝对值越小直线越靠近圆心，弦越长，过圆心时弦最长（就是直径）。"圆心距定生死"在这里看得一清二楚。

### 快问快答

```quiz
两条直线互相垂直，且已知两条直线的斜率都存在。它们的斜率 k1 与 k2 一定满足什么关系？
- k1 = k2
- k1 · k2 = −1 [*]
- k1 + k2 = 0
- k1 · k2 = 1
? 斜率都存在时，垂直等价于斜率互为"负倒数"；若其中一条是竖直线（斜率不存在），口诀失效，但水平与竖直照样垂直。
```

::::warning[常见误区]

**误区一**："你以为两直线平行就是斜率相等，万无一失。" 斜率相等还要**截距不同**才算平行（重合时两方程是同一条线）；而且竖直直线没有斜率，两条竖直线平行却比不出 $k_1 = k_2$。

**误区二**："你以为 $k_1 k_2 = -1$ 判垂直百试百灵。" 它要求两条直线斜率**都存在**。一条水平（$k = 0$）一条竖直（$k$ 不存在）时乘积根本算不出来，但它们照样垂直——特例要先挑出来单独判。

**误区三**："你以为一般方程 $x^2 + y^2 + Dx + Ey + F = 0$ 一定是圆。" 要 $D^2 + E^2 - 4F > 0$ 才是圆；等于 0 时缩成一个点，小于 0 时**什么图形都不是**。配方前先查这一项。

::::

## 6. 练习

**练习 1**：点 $P(2, 1)$ 到直线 $3x + 4y - 20 = 0$ 的距离是多少？把算出的 $d$ 与圆 $x^2 + y^2 = 4$ 的半径 $r = 2$ 比大小，借用位置说法报结论（约定 $d < r$ 记"相交"、$d = r$ 记"相切"、$d > r$ 记"相离"）。提醒：这里比的是**点到直线**的距离，别和"点到圆心的距离"混为一谈。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：点到直线的距离体检
# @check: 2
# @check: 相切
# @hint: 距离公式的分子带绝对值 |Ax₀+By₀+C|，分母是 √(A²+B²)；初始代码忘了加绝对值。判断时拿 d 和半径比：d 小于 r 相交、等于 r 相切、大于 r 相离。
import math                     # 数学库：sqrt 开平方

A, B, C = 3, 4, -20             # 直线 3x + 4y - 20 = 0 的系数
x0, y0 = 2, 1                   # 点 P 的坐标
r = 2                           # 圆 x² + y² = 4 的半径

d = (A*x0 + B*y0 + C) / math.sqrt(A*A + B*B)   # ← 分子是不是少了点什么？
print(round(d))

if d < r:
    print("相交")
elif d > r:
    print("相离")
else:
    print("相切")
```

<details>
<summary>点开查看逐步解答</summary>

1. 分子要加绝对值：$|3 \times 2 + 4 \times 1 - 20| = |-10| = 10$，分母 $\sqrt{9 + 16} = 5$，所以 $d = 10 / 5 = 2$（初始代码没加绝对值，算出 $-2$，距离是长度不可能是负的）；
2. $d = 2$ 恰好等于半径 $r = 2$，所以是**相切**——点 $P(2, 1)$ 与圆心的距离 $\sqrt{4 + 1} = \sqrt{5} \approx 2.24$ 比 2 略大，但"点到直线的距离"和"点到圆心"是两码事，别混。

修正后的参考代码：

```python
import math

A, B, C = 3, 4, -20
x0, y0 = 2, 1
r = 2

d = abs(A*x0 + B*y0 + C) / math.sqrt(A*A + B*B)  # 分子套绝对值
print(round(d))

if d < r:
    print("相交")
elif d > r:
    print("相离")
else:
    print("相切")
```

输出 `2` 与 `相切`，与判题窗逐行一致 ✓。

</details>

**练习 2**：直线 $2x - y + 1 = 0$ 与直线 $x + 2y - 3 = 0$ 是什么关系？口算斜率验证你的判断。

<details>
<summary>点开查看逐步解答</summary>

第一条化成 $y = 2x + 1$，斜率 $k_1 = 2$；第二条化成 $y = -\tfrac{1}{2}x + \tfrac{3}{2}$，斜率 $k_2 = -\tfrac{1}{2}$。乘积 $k_1 k_2 = 2 \times (-\tfrac{1}{2}) = -1$，所以两条直线**垂直**。口诀的来历：一条直线的方向向量是 $(1, k_1)$——垂直意味着横纵互换再翻转符号，斜率恰好互为"负倒数"。
</details>

## 7. 边界与适用条件

本课的平行、垂直判据都默认**斜率存在**，竖直直线要单独讨论；点斜式、斜截式都写不出竖直直线，需要时用 $x = a$ 直接写。位置关系的两种判法（圆心距 vs 判别式）结论一致，但圆心距法更快，判别式法是下一课的主角——处理圆锥曲线时它不可替代。弦长公式 $2\sqrt{r^2 - d^2}$ 只对圆成立。

## 8. 选读：一般方程配方的全过程

<details>
<summary>选读 · 从 $x^2 + y^2 + Dx + Ey + F = 0$ 配回标准式</summary>

对 $x$、$y$ 分别配方（与第 6 章二次函数配方同一套手法）：

$$x^2 + Dx = \left(x + \frac{D}{2}\right)^2 - \frac{D^2}{4}, \qquad y^2 + Ey = \left(y + \frac{E}{2}\right)^2 - \frac{E^2}{4}$$

代回整理得：

$$\left(x + \frac{D}{2}\right)^2 + \left(y + \frac{E}{2}\right)^2 = \frac{D^2 + E^2 - 4F}{4}$$

右边必须**大于零**才有实数点集：大于 0 是圆（圆心 $(-\tfrac{D}{2}, -\tfrac{E}{2})$，半径 $\tfrac{1}{2}\sqrt{D^2 + E^2 - 4F}$）；等于 0 时左边两个平方和非负、只能同时为 0，图形缩成孤立一点；小于 0 时没有任何点满足方程。这也解释了为什么"三点定圆"总能成功：待定系数 $D$、$E$、$F$ 三个未知数，三个点恰好三条方程。
</details>
