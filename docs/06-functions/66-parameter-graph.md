# 含参函数的图像：让参数动起来

## 1. 从一个场景开始

一支手电筒从原点照出去，光束扫过一条固定的抛物线 $y = x^2 - 2x$。光束越陡，照到的点越多还是越少？

大多数时候光束和抛物线撞上两次：一次在原点，一次在别处。可当光束转到某个特定角度时，两次撞击**合并成一次**——光束变成了切线，擦着抛物线过去。再转过去，又变成两次。

这条会转的光束就是 $y = mx$：字母 $m$ 不再是固定的常数，而是一个**参数**。参数一动，图像就变；图像一变，交点个数、方程有没有解，全跟着变。今天要学的就是：怎么把"参数取什么值时如何如何"这类问题，翻译成看得见的图像语言。

## 2. 直觉解释

- **参数 = 旋钮**：式子里的 $m$ 拧到某个值，就得到一条确定的曲线；$m$ 从 $-3$ 拧到 $3$，得到的是一**族**曲线——像一叠透明胶片上各画一条，摞起来就是一支动画。
- **交点个数会在临界值处突变**：两个交点 → 一个 → 两个。中间那个"一个"的时刻，两条曲线不是"少了半个交点"，而是**相切**了。
- **分离参数 = 换个主角**：方程里有 $x$ 和 $a$ 两个字母，盯着 $x$ 解很别扭；改写成 $a = g(x)$ 之后，问题变成"$a$ 这个高度上，水平线能不能碰到曲线 $y=g(x)$"——一眼就看得出答案。

一句话记忆：**动点看相切，有解看交点。**

## 3. 正式定义

### 3.1 含参函数与图像族

形如 $y = f(x,\, m)$ 的函数叫**含参函数**，其中 $m$ 是参数（在讨论中暂时看作常量）。

| 符号 | 角色 | 说明 |
| --- | --- | --- |
| $x$ | 自变量 | 图像横轴上的量，真正"跑"起来的那个 |
| $m$ | 参数 | 每取一个值就定下一条曲线；变化得到**图像族** |
| 图像族 | 一叠快照 | 常画成"同一张图上多条曲线"或"一条会动的曲线" |

### 3.2 交点个数的三种翻译

方程 $f(x) = g(x,\, m)$ 的解、两条曲线的交点、一个新函数的零点，是同一件事的三种说法（第 64 课）：

$$\text{解的个数} = \text{交点个数} = h(x) = f(x) - g(x,\, m) \text{ 的零点个数}$$

当 $h(x)$ 是二次式 $Ax^2 + Bx + C$ 时，用**判别式** $\Delta = B^2 - 4AC$（第 4 章；联立与判别式的完整套路见[《直线与圆锥曲线：设而不求》](./54-line-conic.md)）分三档：

| $\Delta$ | 解的个数 | 图像上发生了什么 |
| --- | --- | --- |
| $\Delta > 0$ | 2 个交点 | 两条曲线**穿过** |
| $\Delta = 0$ | 1 个交点 | 两条曲线**相切**（重根） |
| $\Delta < 0$ | 0 个交点 | 两条曲线**擦肩而过** |

所以"求交点个数的临界值"，代数上就是**解 $\Delta = 0$**。

### 3.3 分离参数

把含参方程 $F(x,\, a) = 0$ 改写成

$$a = g(x)$$

则"存在 $x$ 使方程成立"$\iff$"$a$ 属于 $g$ 的**值域**"$\iff$"水平线 $y = a$ 与曲线 $y = g(x)$ **有交点**"。

| 步骤 | 操作 | 注意 |
| --- | --- | --- |
| 1 | 把 $a$ 单独留在等式一边 | 若需**除以含 $x$ 的式子**，必须单独检查该式为 0 的情形，否则会漏解 |
| 2 | 记右边为 $g(x)$，明确 $x$ 的范围 | 定义域一变，值域就变，答案跟着变 |
| 3 | 求 $g$ 在给定区间上的值域 | 二次函数用**配方 + 顶点 + 端点**三件套 |
| 4 | 值域就是 $a$ 的取值范围 | 端点能否取到，看区间是开是闭 |

## 4. 分步例题

**例 1（动直线）**：$m$ 取何值时，直线 $y = mx$ 与抛物线 $y = x^2 - 2x$ 只有一个交点？

1. 联立：$x^2 - 2x = mx$；
2. 移项：$x^2 - (2+m)x = 0$；
3. 提公因式：$x\bigl(x - (2+m)\bigr) = 0$，两根是 $x_1 = 0$ 与 $x_2 = 2+m$；
4. 判别："只有一个交点"即两根相等：$2 + m = 0$，得 $m = -2$；
5. 自检：$m=-2$ 时方程变成 $x^2 = 0$，是重根 $x=0$，交点 $(0,0)$——直线 $y=-2x$ 与抛物线在原点相切 ✓。换 $m=1$：$x=0$ 或 $x=3$，两个交点 $(0,0)$ 与 $(3,3)$ ✓。

**例 2（分离参数）**：方程 $x^2 - 2x + a = 0$ 在区间 $[0, 3]$ 上**至少有一个解**，求 $a$ 的取值范围。

1. 分离参数：把 $a$ 留在左边（这里本来就是移项），$a = -x^2 + 2x$，记 $g(x) = -x^2 + 2x$，$x \in [0, 3]$；
2. 配方：$g(x) = -(x-1)^2 + 1$，开口向下，顶点 $(1, 1)$；
3. 求值域：顶点横坐标 $x=1$ 落在区间内 → 最大值 $1$；两端 $g(0) = 0$、$g(3) = -9 + 6 = -3$ → 最小值 $-3$；
4. 结论：$g$ 在 $[0,3]$ 上的值域是 $[-3,\, 1]$，所以 $a \in [-3,\, 1]$；
5. 自检：$a = 1$ 时方程是 $(x-1)^2 = 0$，解 $x = 1 \in [0,3]$ ✓；$a = -3$ 时 $x^2 - 2x - 3 = 0$，解 $x = 3$ 或 $x = -1$，其中 $3 \in [0,3]$ ✓；$a = 2$ 时 $(x-1)^2 = -1$，无实数解——而 $2$ 确实不在 $[-3, 1]$ 内 ✓。

## 5. 动手实验

### 实验 1（lab）：拖 m，数交点

```lab
  "params": { "m": 1 },
  "height": 380

```

右边的**交点**一行会实时列出所有交点的坐标。三个任务：

1. 从 $m = 1$ 出发慢慢往小拖：两个交点中的一个（$x = 2+m$）会一路向左滑；
2. 拖到 **$m = -2$** 停住：两个交点合并成一个，"交点"一行从两颗缩成一颗，且落在 $(0, 0)$——这就是相切（滑块拖不准时，把 $m$ 拖到 $-2$ 后点一下式子输入框让它重新计算）；
3. 继续往下拖过 $-2$：交点又变回两个。

注意整个过程里，$x = 0$ 那个交点**始终没动**——因为抛物线过原点，而过原点的直线必然也过原点。动的只有另一个。

### 实验 2（lab）：分离参数——把水平线当电梯

把方程 $x^2 - 2x + a = 0$ 改写成 $a = -x^2 + 2x$ 之后，问题变成了：橙色水平线 $y = a$ 在抛物线 $y = -x^2 + 2x$ 的哪一段高度上，能碰到曲线？

```lab

  "funcs": ["-x^2 + 2*x", "0*x + a"],
  "view": [-1, 4],
  "params": { "a": 0 },
  "height": 380

```

拖 $a$ 从 $-3$ 升到 $1$：水平线与抛物线始终有交点——$a=1$ 时恰好**擦到顶点**（相切，一个交点），其余高度都是两个。继续抬到 $1$ 以上，水平线飘到顶点的上方，整条抛物线上都碰不到它（这就是"方程无解"）。

反过来压到 $-3$ 以下时，交点并没有消失，只是**挪到了区间 $[0,3]$ 的外面**——比如 $a=-4$ 时两个交点跑到 $x \approx -1.24$ 与 $3.24$，拖动画布才看得见。所以"在 $[0,3]$ 上有解"这个附加条件，正是把答案卡在 $[-3, 1]$ 的那把剪刀。

### 实验 3（python）：把参数扫一遍

```python title="交点个数一览表"
def count(m):
    # 联立 x^2 - 2x = m*x  =>  x^2 - (2+m)x = 0
    # 两根 x=0 与 x=2+m 之差是 2+m，判别式正是它的平方
    d = (2 + m) ** 2
    if d > 0:
        return 2
    if d == 0:
        return 1
    return 0

for m in [-4, -3, -2.5, -2, -1, 0, 1, 2]:
    print(f"m={m}: 交点 {count(m)} 个，横坐标 0 与 {2 + m}")
```

八行里只有 $m=-2$ 那一行报"1 个"，其余全是 2 个。整张表就是一句话：**判别式只在 $\Delta = 0$ 那一瞬间改变答案**。

### 实验 4（python）：分离参数后，值域交给机器

```python title="扫描求值域：a 能取到哪些高度"
def g(x):
    return -x**2 + 2*x           # a = g(x)，x 限定在 [0, 3]

lo = 999                         # 先放一个很大的数当"当前最小值"
hi = -999                        # 再放一个很小的数当"当前最大值"
for i in range(0, 301):
    x = i * 0.01                 # 0 → 3.00，步长 0.01
    v = g(x)
    if v < lo:                   # 发现更低的值就更新最小值
        lo = v
    if v > hi:                   # 发现更高的值就更新最大值
        hi = v

print(f"a 的范围: [{round(lo, 2)}, {round(hi, 2)}]")
```

输出 `a 的范围: [-3.0, 1.0]`，与例 2 手算的值域 $[-3, 1]$ 一致。把 `range(0, 301)` 改成 `range(0, 501)`（即把 $x$ 扫到 5）再看——最小值会掉到 $-15$，因为 $g(5) = -25 + 10 = -15$。区间一变，值域跟着变，**分离参数时千万别漏写 $x$ 的范围**。

### 快问快答

```quiz
过原点的直线 y = m x 与抛物线 y = x² − 2x 只有一个交点时，m 等于几？
- 0
- -2 [*]
- 2
? 联立得 x(x - (2+m)) = 0，两根是 x=0 与 x=2+m。m=-2 时两根重合为一个，正是相切的那一刻。
```

::::warning[常见误区]

**误区一**："交点从一个变成零个是可以一步到位的。" 
中间一定先经过两个交点**合并成一个**的相切状态。代数上对应判别式从正变负、途中穿过 $0$。所以求"临界值"就解 $\Delta = 0$，这是有依据的，不是巧合。

**误区二**："$\Delta = 0$ 就是没有交点。" 
恰好相反：$\Delta = 0$ 是**两个相等实数根**（重根），图像上是一个交点——相切。$\Delta < 0$ 才是没有交点。

**误区三**："分离参数时随便移项、随便除。" 
如果两边**除以含 $x$ 的式子**，必须先单独讨论它等于 0 的情形，那往往正是漏掉的解。安全的做法是先移项因式分解，把"除"这件事换成"提公因式"。

**误区四**："值域就是函数能达到的最小到最大。" 
值域依赖**区间**。同一个 $g(x) = -x^2 + 2x$，在 $[0,3]$ 上是 $[-3, 1]$，在 $[0,5]$ 上是 $[-15, 1]$。题目问"在某某区间上有解"，区间就是定义域，不写清就无从下手。

::::

**练习 1**：直线 $y = mx$ 与抛物线 $y = x^2 - 2x$ 的交点个数。下面的代码能跑，但结论不对，改到通过：

```exercise
# @title: 练习：动直线扫过抛物线，交点有几个
# @check: m=-3 时交点个数: 2
# @check: m=-2 时交点个数: 1
# @check: m=2 时交点个数: 2
# @hint: 联立 x^2 - 2x = m*x 得 x^2 - (2+m)x = 0，两根是 x=0 与 x=2+m。判别式等于"两根之差的平方"，也就是 (2+m)^2，不是 (2-m)^2。改完只有 m=-2 那一行是 1 个。
def count(m):
    d = (2 - m) ** 2          # ← 判别式是谁的平方？
    if d > 0:
        return 2
    if d == 0:
        return 1
    return 0

for m in [-3, -2, 2]:
    print(f"m={m} 时交点个数: {count(m)}")
```

**练习 2**：把例 1 里的直线抬高 1 格，改成 $y = mx + 1$——它和抛物线 $y = x^2 - 2x$ 的交点个数会随 $m$ 变化吗？

<details>
<summary>点开查看逐步解答</summary>

**不会**，无论 $m$ 取什么值，都恰好有 **2 个**交点。

1. 联立：$x^2 - 2x = mx + 1$；
2. 移项：$x^2 - (2+m)x - 1 = 0$；
3. 判别式：$\Delta = (2+m)^2 - 4 \times 1 \times (-1) = (2+m)^2 + 4$；
4. 判号：$(2+m)^2 \ge 0$，所以 $\Delta \ge 4 > 0$ **恒成立** → 永远两个不相等的实数根 → 永远两个交点。

自检：$m = -2$ 时方程是 $x^2 - 1 = 0$，解 $x = \pm 1$，交点 $(-1, 3)$ 与 $(1, -1)$ ✓。

这道题的意义在于提醒：**并不是每个参数都会引起交点个数的变化**。抬高 1 格之后，直线族全都从抛物线"内部"穿过去，永远割出两个交点。判断之前先算 $\Delta$，不要想当然。

</details>

## 7. 边界与适用条件

本课处理**一个参数**、**二次**联立方程的情形。以下内容刻意留白：

- **两个参数**（比如同时动 $m$ 和截距 $b$）：答案不再是几个孤立的临界值，而是参数平面上的一块**区域**，需要线性规划或不等式组，超出本课范围；
- **高次或超越方程**：联立后不是二次式时，判别式这把尺子失效，要改用单调性与零点个数分析（第 13 章导数才是趁手工具）；
- **相切点的切线方程**：本课只用"重根"判断相切，不求切线方程——那是导数的招牌应用；
- **区间限制下的交点**：例 2 已经演示了"区间决定值域"；若题目问"在 $[0,3]$ 上恰有一个交点"，则还要额外检查另一个交点是否落在区间外，不能只看值域。

## 8. 选读：为什么临界值总在相切处

<details>
<summary>选读 · 从"两个"到"零个"必须经过"一个"</summary>

设联立后得到二次方程 $Ax^2 + Bx + C = 0$，其判别式 $\Delta(m)$ 随参数 $m$ 连续变化。

二次方程的实数根个数只由 $\Delta$ 的**符号**决定：正 → 两个，零 → 一个，负 → 零个。如果某个 $m_1$ 处有两个交点、另一个 $m_2$ 处一个也没有，那么 $\Delta(m_1) > 0$ 而 $\Delta(m_2) < 0$。由于 $\Delta$ 随 $m$ 连续变化，从正走到负的路上必定经过 $\Delta = 0$ 的位置——那一刻两根相等，图像上就是**相切**。

反过来说也成立：相切之后再动一点参数，两条曲线要么分开（$\Delta < 0$，零个交点），要么重新穿过（$\Delta > 0$，两个交点）。所以：

$$\text{交点个数发生变化} \Longrightarrow \text{变化前的一瞬间必然相切} \Longrightarrow \Delta = 0$$

这就是"求临界值就解 $\Delta = 0$"的完整理由。本节课本上的"相切"两个字，代数上是"重根"，方程上是"判别式为零"，图像上是"两条曲线只碰一下"——同一件事的四副面孔。

</details>
