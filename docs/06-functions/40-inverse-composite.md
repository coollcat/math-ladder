# 复合函数与反函数：机器串联与倒带

## 1. 从一个场景开始

早上你先穿袜子、再穿鞋；晚上脱的时候，必须**先脱鞋、再脱袜子**——顺序完全反过来。这个生活常识里藏着本章的两个主角：

- **复合函数**：两台机器串成流水线，前一台的出口接后一台的入口；
- **反函数**：把流水线整体倒着开，一步步逆操作回去。

密码学里的"加密—解密"、日常的"打包—拆包"，用的都是这一对概念。

## 2. 直觉解释

**复合**：机器 g 的输出口接到机器 f 的输入口。投进 x，g 先加工，产物立刻喂给 f，最终吐出 $f(g(x))$。读法从里往外：**先 g 后 f**。

**反函数**：把 f 的每一步加工倒序撤销。$f(x)=2x+1$ 的加工步骤是"乘 2，再加 1"，那么倒带就是"先减 1，再除以 2"——顺序反转，一步不乱。这台倒带机记作 $f^{-1}$。

## 3. 正式定义

**复合函数**：

$$(f \circ g)(x) = f(g(x))$$

| 记号 | 含义 |
| --- | --- |
| $f \circ g$ | 复合："g 之流再入 f"，先 g 后 f |
| $f(g(x))$ | 内层 $g(x)$ 的结果作为外层 f 的输入 |

边界提醒：串联时还要确认“内层的出口接得上外层的入口”。本课的直线和抛物线都收所有实数，所以不用挑；日后遇到平方根、对数这类只在部分输入上工作的机器，就要先检查 $g(x)$ 是否落在 f 的定义域里。

**反函数**：若对任意 x 都有

$$f^{-1}\big(f(x)\big) = x \qquad \text{且} \qquad f\big(f^{-1}(x)\big) = x$$

则称 $f^{-1}$ 为 f 的反函数——加工与倒带互相抵消，绕一圈回到出发点。几何上，两者的图像关于直线 $y=x$ 镜像对称（本课末尾选读给理由）。

## 4. 分步例题

设 $f(x) = 2x + 1$，$g(x) = x - 3$，求 $f(g(5))$：

1. 算里层：$g(5) = 5 - 3 = 2$；
2. 喂给外层：$f(2) = 2 \times 2 + 1 = 5$；
3. 所以 $f(g(5)) = 5$。

换序对照：$g(f(5)) = g(11) = 8$。同样是 5 和 3、同样的两台机器，换个连接顺序结果就不同——**流水线不可随便换序**。

再求 f 的反函数：$y = 2x+1$ 的步骤是"乘 2、加 1"，逆序为"减 1、除 2"：

$$f^{-1}(x) = \frac{x - 1}{2}$$

## 5. 动手实验

### 实验 1（python）：数值验证流水线

```python title="先过 g，再过 f"
# sliders: x=5 [0:8:1]

def f(x):
    return 2 * x + 1

def g(x):
    return x - 3

print(f"g({x}) = {g(x)}")
print(f"f(g({x})) = {f(g(x))}")
print(f"g(f({x})) = {g(f(x))}")
```

默认 $x=5$ 时，第三行再次提醒：$f(g(5))=5$ 而 $g(f(5))=8$，顺序即命运。拖动输入 x，会看到两条流水线始终给出不同结果。

### 实验 2（viz）：换序的两条流水线，画出两条平行线

"顺序即命运"不止两个数，而是两条整线的错位。下面把两台机器也装上旋钮：$f(x)=mx+b$、$g(x)=x-c$。两种接法化简为：

- 先 g 后 f：$f(g(x)) = m(x-c)+b$
- 先 f 后 g：$g(f(x)) = (mx+b)-c$

不管把 m、b、c 拖到哪里，两条线化简后的斜率都等于同一个 m——**斜率相同就注定互相平行**，这跟 c 取什么值无关；$m\neq1$ 且 $c\neq0$ 保证的只是两条线不重合，c 真正决定的是它们竖直方向上隔多远。在 $x=5$ 处它们的高度正是 5 和 8，实验 1 打印的那对数字原来是这两条线的固定高度差 $c(m-1)$，默认参数下恰好是 3。

### 实验 3（python）：倒带回到出发点

```python title="加工之后逆操作"
# sliders: v=10 [-10:10:1]

def f(x):
    return 2 * x + 1

def inverse_f(x):      # 反函数：先减 1 再除 2
    return (x - 1) / 2 # 除法结果是 10.0 这种小数形式，数值上就是 10

print(f"f({v}) = {f(v)}，倒带回 {inverse_f(f(v))}")
```

拖动 v 会发现每个数都精确回家——$f^{-1}(f(v)) = v$ 不是口号，是可以逐个验收的合同。

### 实验 5（python）：交换坐标，跳到镜子对面

```python title="关于 y=x 的对称点"
import matplotlib.pyplot as plt

pxs = [1, 2, 3]
pys = [2, 4, 6]

# sliders: p=0 [0:2:1]

p = int(p)                       # 滑块给的是数，int() 把它变成可靠整数
x = pxs[p]                       # 方括号按位置取列表元素：位置从 0 开始
y = pys[p]

plt.plot([-6, 6], [-6, 6], linestyle="--", color="gray", label="y = x (mirror)")
plt.scatter([x], [y], s=90, label="points on y = 2x")
plt.scatter([y], [x], marker="s", s=90, label="swapped points")   # marker="s" 方块标记
plt.legend()
plt.grid(True)
```

拖动 p 可在三组点中切换：$(1,2),(2,4),(3,6)$ 都来自 $y=2x$；把它们坐标前后一换，方块点 $(2,1),(4,2),(6,3)$ 全部落在 $y=\frac{x}{2}$ 上，且与蓝圆点隔着虚线遥遥相望。

### 快问快答

```quiz
已知 f(x) = x + 3，g(x) = x * 2，复合 f(g(4)) 等于几？
- 11 [*]
- 14
- 10
? 从里往外：先 g(4) = 8，再 f(8) = 11。14 是顺序反过来 g(f(4)) 的结果。
```

:::warning[常见误区]

**误区一**："$f^{-1}(x)$ 就是 $\frac{1}{f(x)}$。" 
记号里的 $-1$ 表示"逆操作"，不是倒数。本课中 $f^{-1}(x)=\frac{x-1}{2}$，而 $\frac{1}{f(x)}=\frac{1}{2x+1}$，完全是两个东西。

**误区二**："f(g(x)) 和 g(f(x)) 相等。" 
流水线不可换序：例题里一个是 5、一个是 8。只有极少数特殊组合例外。

**误区三**："任何函数都能倒带。" 
倒带要求"一个输出只对应一个输入"。$y=x^2$ 里输出 4 来自 $\pm 2$ 两个入口，全局没法唯一倒带；补救办法是限定定义域（第 13 章会用到这招）。

:::

**练习 2**：求 $h(x) = x + 3$ 的反函数，并用代码验证 $h^{-1}(h(7)) = 7$。

<details>
<summary>点开查看逐步解答</summary>

$h$ 的步骤是"加 3"，逆序就是"减 3"：$h^{-1}(x) = x - 3$。

```python
def h(x):
    return x + 3

def inverse_h(x):
    return x - 3

print(inverse_h(h(7)))
```

输出 7。加减互逆是最简单的反函数：一条向左平移 3 格的直线，倒带就是向右平移 3 格。
</details>

## 7. 选读：为什么反函数图像关于 y=x 对称

<details>
<summary>选读 · 换位即照镜</summary>

设点 $(a, b)$ 在 f 的图像上，意思是 $b = f(a)$。倒带关系给出 $a = f^{-1}(b)$，也就是说 $(b, a)$ 在 $f^{-1}$ 的图像上。

$(a,b)$ 与 $(b,a)$ 这两点恰好关于直线 $y=x$ 镜像对称（沿对角线折叠正好重合）。所以整条曲线翻转后严丝合缝地压在反函数曲线上——实验 4 的双曲线、实验 5 里那些蓝点与方块，都是这个论证的具体化身。

</details>
