# 一次函数与斜率：两个旋钮一条线

## 1. 从一个场景开始

出租车的计价器是个老实人：起步价 8 元，之后每公里 2 元。行驶 x 公里，车费就是 $2x+8$ 元——输入里程，立刻吐出价格。

把所有可能的（里程，车费）点画到方格纸上，它们排成一条笔直的线。**一次函数**就是这条直线的代数化身，也是你遇到的第一台"带旋钮"的函数机器。

## 2. 直觉解释：两个旋钮

$$y = ax + b$$

- **a 控制倾斜**：a 越大线越陡；a 是负数就变成下坡；
- **b 控制升降**：b 增大 1，整条线原样向上平移 1 格。

电梯爬楼类比：b 是"你从几楼出发"，a 是"每向前横移一格要爬多高"。斜率因此也叫**变化率**——x 每增加 1，y 恰好增加 a。变化量一步不变，正是"直"的数学含义。

## 3. 正式定义

$$y = ax + b \qquad (a \neq 0)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a$ | 斜率 | 变化率：x 增加 1 时 y 的增加量 |
| $b$ | 截距 | x=0 时的 y 值，直线在 y 轴上的落脚点 |

已知直线上两点 $(x_1, y_1)$ 和 $(x_2, y_2)$，斜率为

$$a = \frac{y_2 - y_1}{x_2 - x_1}$$

关键事实：**无论挑哪两点，算出的 a 都一样**——这是直线区别于一切曲线的身份特征。

## 4. 分步例题

**例 1**：$y = 2x + 1$，求 $x=5$ 时的 y。
1. 代入：$y = 2 \times 5 + 1$
2. 先乘后加：$10 + 1$
3. 所以 $y = 11$

**例 2**：一直线过 $(0, 3)$ 和 $(2, 7)$，求表达式。
1. 求斜率：$a = \dfrac{7-3}{2-0} = 2$
2. 用点 $(0,3)$ 定截距：$x=0$ 时 $y=b=3$
3. 所以 $y = 2x + 3$

**例 3**：$a = -1$ 的直线什么走向？
每向右一步下降一格——下坡。a 的正负管上坡还是下坡，$|a|$ 管陡缓。

## 5. 动手实验

### 实验 1（viz）：拖动两个旋钮

```viz
{
  "type": "plot",
  "title": "y = a*x + b",
  "expr": "a*x + b",
  "xmin": -5,
  "xmax": 5,
  "sliders": [
    { "name": "a", "min": -3, "max": 3, "step": 0.5, "value": 2 },
    { "name": "b", "min": -4, "max": 4, "step": 1, "value": 0 }
  ]
}
```

三个挑战：

1. 只拖 a：观察直线绕点 $(0, b)$ 打转，a 拖过 0 的瞬间线躺平；
2. 只拖 b：整条线纹丝不变形地上下平移；
3. 找出"最陡的下坡"和"水平的线"，分别对应哪个 a 值？

边界说明：滑块里的 $a=0$ 是一台"躺平的机器"——它给出水平线 $y=b$，能帮你看清 b 只管高度；但按上面的正式定义，一次函数要求 $a \neq 0$，所以它是一次函数家族的边界外样品。

### 实验 2（python）：一族直线同框

```python title="只换 a：一族直线"
import matplotlib.pyplot as plt

xs = list(range(-5, 6))

for a in [0.5, 1, 2, -1]:
    ys = []
    for x in xs:
        ys.append(a * x + 1)
    plt.plot(xs, ys, label=f"a={a}")

plt.axhline(0, color="gray", linestyle="--")
plt.axvline(0, color="gray", linestyle="--")
plt.legend()
plt.grid(True)
```

四条线共用同一个 b=1，所以都在 $(0,1)$ 处穿过 y 轴；不同的只是倾斜程度和方向。

### 实验 3（python）：斜率的身份验证

```python title="任取两点，斜率都一样"
x1, y1 = 0, 3    # 同时给两个变量赋值（第 1 章见过）
x2, y2 = 2, 7
slope_a = (y2 - y1) / (x2 - x1)

x3, y3 = 5, 13
slope_b = (y3 - y1) / (x3 - x1)

print(f"用 (0,3) 与 (2,7) 算: 斜率 = {slope_a}")
print(f"用 (0,3) 与 (5,13) 算: 斜率 = {slope_b}")
```

两次结果都是 2——挑哪对点都一样，这就是"直"的数值证据。

### 实验 4（viz）：最小二乘——让直线追着数据跑

前面三个实验里数据都完美落在直线上，现实世界的观测点却总是歪歪扭扭。下面 6 个散点随便拖：拖动过程中蓝线立刻重新贴合，它永远停在对全体点"偏差最小"的位置，左上角同时报出这条线的表达式和平均误差。

```viz
{
  "type": "fit",
  "n": 6
}
```

试着把所有点排成一条整齐的直线，看平均误差一路跌向 0——那时表达式的斜率就是数据亲手选出的变化率：这便是斜率在噪声世界里依然站得住脚的原因。

### 快问快答

```quiz
在 y = ax + b 里把 b 从 1 拖到 3，图像会怎样？
- 变陡
- 绕原点旋转
- 整条直线向上平移 2 格 [*]
? b 管升降：b 增加 2，每个点的 y 都增加 2，整条线原样向上挪 2 格。管陡缓的是 a。
```

:::warning[常见误区]

**误区一**："b 也是斜率，b 越大越陡。"
陡度全由 a 决定；b 只负责把整条线上下搬。

**误区二**："a=-3 的线比 a=2 的平缓。"
看绝对值：$|-3|=3 > 2$，它其实更陡，只是方向朝下。

**误区三**："一次函数的图像都过原点。"
只有 b=0 那条过。b 是直线在 y 轴上的落脚点。

:::

**练习 2**：三点 $(0,1)$、$(2,5)$、$(4,9)$ 在同一条直线上吗？用斜率判断。

<details>
<summary>点开查看逐步解答</summary>

```python
s1 = (5 - 1) / (2 - 0)
s2 = (9 - 1) / (4 - 0)
print(s1 == s2)
```

两个斜率都是 2，所以三点共线（都在 $y=2x+1$ 上）。共线的判定就是"斜率处处相等"。
</details>

## 7. 选读：为什么两点确定一条直线

<details>
<summary>选读 · 两点的唯一性</summary>

给定两点，斜率 $a=\frac{y_2-y_1}{x_2-x_1}$ 被唯一确定（只要 $x_1 \neq x_2$）；再把任意一点代回 $y=ax+b$ 就解出唯一的 b。"两点定一线"由此成立——这也是为什么 ruler 一放上去就能画全：直线的每个点都被这两点提前锁定了。

反过来，如果三个点算出两种不同斜率，它们就必然拐了弯——这正是练习 2 判定法的原理。

</details>
