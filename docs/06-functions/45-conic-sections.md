# 圆锥曲线：椭圆、双曲线与抛物线

## 1. 从一个场景开始

夜晚拿一只手电筒照墙：正对墙照，光斑是圆；把筒身慢慢斜过去，圆被拉长成椭圆；再斜到筒口几乎贴着墙，光斑一侧拖出一条越来越宽的尾巴。一支光锥被墙这把"刀"切一刀，切口的形状随角度变脸——这就是本课三位主角共同的出身。

它们不只是光斑游戏：行星绕太阳走的是椭圆，卫星天线的锅盖剖面是抛物线，导航系统靠"到两座基站距离之差"画出双曲线。更妙的是，第 6 章讲过的那条抛物线（[二次函数与抛物线](./30-quadratic.md)），居然和圆是失散多年的亲戚——这一课让全家族同桌吃顿饭。

## 2. 直觉解释

先不背方程，动手玩三样玩具：

- **两颗钉子 + 一根绳**（画椭圆的园丁手法）：把绳两端钉在木板上，铅笔勾住绳子绷紧绕一圈——铅笔到两颗钉子的**距离之和**始终等于绳长，扫出的封闭曲线就是椭圆。
- **一副卡尺**（双曲线）：只盯着"离 A 点比离 B 点远出一截固定的量"，所有满足这个条件的位置连起来，是两条张开的喇叭口曲线——**距离之差**恒定的点集。
- **一根对折线**（抛物线）：到某个定点的距离与到某条定直线的距离**恰好相等**的点，集合起来是一条开口的弧——探照灯锅的内壁正是这种形状。

一句话记忆版：**椭圆管"和"，双曲线管"差"，抛物线管"比"**。三句话比三条方程好记得多，而第 3 节会把这三句话翻译成正式数学。

## 3. 正式定义

$$\text{椭圆：} \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \qquad \text{双曲线：} \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \qquad \text{抛物线：} y^2 = 2px$$

| 记号 | 名字 | 出现在 | 说明 |
| --- | --- | --- | --- |
| $a$ | 半长轴 / 实半轴 | 椭圆、双曲线 | 分母里最大的那位；决定"个头" |
| $b$ | 半短轴 / 虚半轴 | 椭圆、双曲线 | 椭圆里 $a^2 = b^2 + c^2$；双曲线里 $c^2 = a^2 + b^2$（顺序相反！） |
| $c$ | 半焦距 | 三者皆有 | 焦点到中心的距离，椭圆 $c^2=a^2-b^2$、双曲线 $c^2=a^2+b^2$ |
| $p$ | 焦参数 | 抛物线 | 焦点在 $(p/2, 0)$，准线是直线 $x = -p/2$ |
| $e$ | 离心率 | 椭圆、双曲线 | $e = c/a$，给整个家族排辈分 |

离心率是家族合影里的编年史：$e=0$ 是标准圆；$0<e<1$ 是椭圆，越接近 1 越扁；$e=1$ 恰好跨过门槛变成抛物线；$e>1$ 就是双曲线。一个数字，四副面孔。

## 4. 分步例题

**例**：园丁用两颗相距 6 厘米的钉子、一根长 10 厘米的细绳画椭圆。写出这条椭圆的标准方程。

1. **认绳长**：绳子绷紧时总量守恒，所以 $2a = 10$，得 $a = 5$；
2. **认钉距**：两颗钉子就是焦点，$2c = 6$，得 $c = 3$；
3. **补短轴**：椭圆的关系式是 $a^2 = b^2 + c^2$，所以 $b^2 = 25 - 9 = 16$，$b = 4$；
4. **写方程**：代入标准式得 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$，离心率 $e = c/a = 0.6$；
5. **回头对账**：顶点 $(5, 0)$ 到两个焦点 $(\pm 3, 0)$ 的距离分别是 2 和 8，加起来恰好是 10——与"绳长之和恒定"当场兑现。

五步流程今后可以倒着用：拿到方程，反推 a、b、c，就能说出焦点的位置和曲线的胖瘦。

### 实验 3（python）：绳圈经济学与行星档案

```python title="拧离心率旋钮，看椭圆的身材报告单"
import math                      # 数学库：sqrt 开平方
import matplotlib.pyplot as plt  # 画图库：把椭圆画出来

# sliders: a=5 [3:6:0.25], e=0.6 [0:0.9:0.05]

c = a * e                                        # 半焦距：钉距的一半，由离心率分配
b = math.sqrt(max(a * a - c * c, 0.0001))        # sqrt 开平方；max 兜底防负数炸机
print(f"a={round(a,2)}, b={round(b,2)}, c={round(c,2)}, e={e}")

xs = []                          # 收集上半条曲线的横坐标列表
top = []                         # 对应的纵坐标（正的那半条）
bot = []                         # 负的那半条
for i in range(121):             # 循环取 121 个采样点铺满横轴
    x = -a + (2 * a) * i / 120   # 从 −a 匀速走到 a
    xs.append(x)
    top.append(b * math.sqrt(max(1 - (x / a) ** 2, 0)))
    bot.append(-top[-1])         # 列表[-1] 取刚放进去的最后一个元素

plt.plot(xs, top)
plt.plot(xs, bot)
plt.axvline(c, color="orange", linestyle="--")    # 右焦点位置竖虚线
plt.axvline(-c, color="orange", linestyle="--")   # 左焦点位置竖虚线
plt.title(f"e={e} 的椭圆：橙虚线是两颗钉子")
plt.grid(True)

print("行星离心率档案：金星 0.007｜地球 0.017｜火星 0.093｜水星 0.206｜哈雷彗星 0.967")
print("地球近乎正圆，哈雷则又瘦又长——同一条公式，两种命运")
```

怎么玩：拧动 e，橙色虚线（两颗钉子）从中心慢慢滑向边缘，椭圆越来越瘦——轨道上的星球就住在这些曲线上。档案最后一行读一读：宇宙里既有金星的"规整派"，也有哈雷彗星的"狂野派"。

### 快问快答

```quiz
关于双曲线和它的渐近线，下面哪种说法是对的？
- 双曲线会穿过渐近线一次，然后再折回来
- 双曲线越走越贴近渐近线，但永远不相交 [*]
- 只要拉得足够远，双曲线最终会完全重合于渐近线
? 渐近线只是方向指引：距离可以无限缩小，却始终大于零。把它当成"贴着跑的赛道护栏"最形象。
```

:::warning[常见误区]

**误区一**："你以为椭圆就是压扁的圆，不算严格图形。" 其实椭圆的定义独立于"圆被压扁"：两定点距离之和恒定才是它的户口。圆只是 $e=0$ 时两颗钉子重叠成一团的特例——不是亲戚蹭饭，而是同一血统。

**误区二**："你以为双曲线是两条抛物线拼成的。" 两支双曲线有渐近线兜底且来自"距离之差"；抛物线既无渐近线也无第二支，来自"到点与到线的等距"。长得像不妨碍出身不同。

**误区三**："你以为 a、b、c 的关系三种曲线通用。" 方向恰恰相反：椭圆里 $a^2=b^2+c^2$（a 最大），双曲线里 $c^2=a^2+b^2$（c 最大）。用错一条，焦点立刻搬家。

:::

## 6. 练习

**练习 1**：教室黑板旁装一块椭圆形投影幕布：两颗挂钩钉相距 8（即 $2c=8$），挂绳绷紧后总长 10（即 $2a=10$）。算出短半轴 b 和以百分数计的离心率。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：给挂绳幕布算身材参数
# @check: 3
# @check: 80
# @hint: 椭圆的账本是"平方的减法"：a² = b² + c²，所以 b² = a² − c²，不是 a²+c²；离心率是小个子 c 站在大个子 a 身旁的比例 e = c/a，别写反分子分母。
import math                     # 数学库：sqrt 开平方

a = 5                           # 半长轴：挂绳长的一半
c = 4                           # 半焦距：两颗挂钩钉间距的一半

b = round(math.sqrt(a*a + c*c))  # ← 开根号之前，账本方向对吗？
print(b)

e_percent = round(a / c * 100)   # ← 谁除以谁？
print(e_percent)
```

<details>
<summary>点开查看逐步解答</summary>

第 4 节例题已经走通一遍流程，这里原样复用：

1. 认绳长：$2a=10 \Rightarrow a=5$；认钉距：$2c=8 \Rightarrow c=4$；
2. 补短轴按椭圆家规做**减法**：$b^2 = a^2 - c^2 = 25 - 16 = 9$，得 $b = 3$（初始代码把 $a^2$ 与 $c^2$ 相加再开方，算出 6——那是把"差的家规"错用了"和的家规"）；
3. 离心率是小焦距配大长轴：$e = c/a = 4/5 = 0.8$，换成百分数是 **80**（初始代码写成了 $a/c$，比例倒挂）。

修正后的参考代码：

```python
import math

a = 5                            # 半长轴：挂绳长的一半
c = 4                            # 半焦距：两颗挂钩钉间距的一半

b = round(math.sqrt(a*a - c*c))  # 平方做减法：a² − c²，再开方
print(b)

e_percent = round(c / a * 100)   # 离心率 = c ÷ a，换算百分数
print(e_percent)
```

输出 `3` 与 `80`，与判题窗逐行一致 ✓。对比第 4 节例题（a=5、c=3 → b=4、e=60%）：绳长没变、钉子挪近了一格，短半轴从 4 缩到 3——钉距越大绳子越"施展不开"，离心率从 0.6 涨到 0.8，幕布更瘦长。

</details>

**练习 2**：为什么卫星天线要把锅盖做成旋转抛物面？用一句话说出"平行入射 → 汇聚一点"的关键性质来源。

<details>
<summary>点开查看逐步解答</summary>

抛物线有光学独门绝技：**所有平行于对称轴射入的光线，反射后都恰好经过同一个焦点**。锅盖把这族抛物线绕轴转一圈，微波信号便齐刷刷汇聚到焦点上的接收器——同一性质反向使用，就成了探照灯把点光源投成平行光束。这道性质能用平面镜反射角守恒在纸面上推出，选读部分之外不多展开；此处只需记住："等距"定义生出聚焦天性。
</details>

## 7. 边界与适用条件

本课给出三类曲线的统一出身、标准方程与第一手感，但以下内容刻意留白：坐标轴不必水平时的一般式（需要旋转坐标系，属于线性代数章后话）；判别式分类一般二次方程的代数机器；准线—极坐标形式的优雅统一式（极坐标课会揭晓）；以及双曲三角函数与悬链线。另外，实验中滑块范围有限，极端参数（比如 b 远超 a）请自行心算验证而不必硬拽滑块。

## 8. 选读：从"和为定值"推出椭圆方程

<details>
<summary>选读 · 绳子如何变成平方和</summary>

设椭圆中心在原点、焦点 $(\pm c, 0)$，任取曲线上一点 $(x, y)$。"距离之和等于 $2a$" 写成：

$$\sqrt{(x-c)^2 + y^2} + \sqrt{(x+c)^2 + y^2} = 2a$$

把其中一个根号移到右边后整体平方，整理两次后，所有带根号的项都会消失，最终化简为：

$$\frac{x^2}{a^2} + \frac{y^2}{a^2 - c^2} = 1$$

令 $b^2 = a^2 - c^2$ 并注意 $y=0$ 时 $x=\pm a$、而 $y$ 能撑到的最大高度恰是 $b$，就得到标准式。"平方消根号"是化简的核心招数——它与二次函数配方同属一套代数基本功。
</details>
