# 轨迹方程：给动点上户口

## 1. 从一个场景开始

小狗被一根绳子拴在木桩上，绳子绷直时它能到的所有位置连成一个圆——这个圆就是小狗的"轨迹"。换到坐标纸上：无人机保持与两个基站的距离之**和**不变飞行，它的航线是椭圆；探照灯照到"与某个点、某条线距离相等"的所有位置，扫出抛物线。动点按条件运动留下的集体照片，写成一个方程，就是**轨迹方程**。本课解决"怎么求"，以及求完之后那条最容易丢分的纪律——**交代取值范围**。

## 2. 直觉解释

求轨迹方程本质上是把"条件"翻译两遍：

- 第一遍把条件里的**几何语言**（距离相等、斜率乘积、中点……）翻译成**坐标语言**（根式、分式、平均数……）；
- 第二遍把坐标语言**化简**成一个熟悉的方程，认出它是圆、椭圆还是抛物线。

三条常用路线：条件直接坐标化的走**直接法**；条件一出现"距离之和/差恒定、到点与线等距"就先想想是不是圆锥曲线的**定义**原话，认出来直接写方程走**定义法**；动点跟着另一条已知曲线上的点走的走**相关点法**——用动点坐标把"老点"表示出来，代进老点的方程。

## 3. 正式定义

| 方法 | 适用特征 | 流程 |
| --- | --- | --- |
| 直接法 | 条件能直接写成坐标等式 | 设 $(x, y)$ → 列条件 → 化简 → 查范围 |
| 定义法 | 条件是圆锥曲线定义的原话（和/差/等距） | 认出曲线 → 定 $a, b, c$（或 $p$）→ 直接写标准方程 |
| 相关点法 | 动点 $Q$ 随已知曲线上的点 $P$ 联动 | 设 $Q(x,y)$ → 用 $x, y$ 表示 $P$ → 把 $P$ 代入已知曲线方程 |

**铁律**：化简过程（平方、去分母、约分）可能**混进**不满足原条件的点，也可能**丢掉**斜率不存在的点。求出方程后必须回头对照原条件，交代 $x$、$y$ 的取值范围——"挖掉谁"要写明，轨迹才算上完户口。

## 4. 分步例题

**例 1（直接法 + 范围纪律）**：动点 $M$ 与定点 $A(-2, 0)$、$B(2, 0)$ 连线的斜率之积恒为 $-\tfrac{1}{2}$，求 $M$ 的轨迹方程。

1. **设点列条件**：设 $M(x, y)$。斜率存在要求 $x \neq \pm 2$，条件写作 $\dfrac{y}{x+2} \cdot \dfrac{y}{x-2} = -\tfrac{1}{2}$；
2. **化简**：两边乘 $2(x^2 - 4)$：$2y^2 = -(x^2 - 4)$，即 $x^2 + 2y^2 = 4$，标准式 $\dfrac{x^2}{4} + \dfrac{y^2}{2} = 1$；
3. **交代范围**：方程是椭圆，但斜率的分母不许为零——$x \neq \pm 2$，即 $A$、$B$ 两点本身不在轨迹上（此时 $y = 0$）。所以轨迹是**挖去长轴两端点 $(\pm 2, 0)$ 的椭圆**。少这一句，这道题在考场上就丢分。

**例 2（定义法）**：动点 $M$ 到 $F_1(-2, 0)$、$F_2(2, 0)$ 的距离之和恒为 6，求轨迹方程。

1. **认定义**："距离之和恒定"是椭圆的原话；检验 $2a = 6 > |F_1F_2| = 4$ ✓（不大于 4 时轨迹退化为线段或不存在）；
2. **定参数**：$a = 3$，$c = 2$，$b^2 = a^2 - c^2 = 5$；
3. **写方程**：$\dfrac{x^2}{9} + \dfrac{y^2}{5} = 1$，全体点都合法，无需挖点——定义法天然带范围。

**例 3（相关点法）**：$P$ 在圆 $x^2 + y^2 = 4$ 上运动，$A(6, 0)$ 是定点，$M$ 是线段 $AP$ 的中点，求 $M$ 的轨迹方程。

1. **设动点、表老点**：设 $M(x, y)$，中点公式反过来用：$x = \dfrac{x_P + 6}{2}$，$y = \dfrac{y_P}{2}$，即 $x_P = 2x - 6$，$y_P = 2y$；
2. **代入老点方程**：$(2x - 6)^2 + (2y)^2 = 4$；
3. **化简**：$4(x-3)^2 + 4y^2 = 4$，两边同除 4 得 $(x - 3)^2 + y^2 = 1$：半径 1、圆心 $(3, 0)$ 的小圆；
4. **查范围**：$P$ 走遍大圆时 $M$（它是 $P$ 的伸缩平移像）也走遍小圆，轨迹完整，无需挖点。

### 实验 2（python）：抽几个动点，验收轨迹

```python title="例 3：中点 M 是否真的落在小圆上"
# 在大圆 x²+y²=4 上取几个动点 P（用勾股数组凑的好点：1.2²+1.6²=4）
points = [(2, 0), (1.2, 1.6), (0, 2), (-2, 0)]
for xp, yp in points:                # 逐个取出动点 P 的坐标
    xm, ym = (xp + 6) / 2, yp / 2    # M 是 AP 的中点，A(6,0)
    on_small = (xm - 3)**2 + ym**2   # 代入小圆 (x-3)²+y²=1 的左边
    print(f"P=({xp},{yp}) -> M=({xm},{ym}), (x-3)²+y²={round(on_small, 2)}")
```

四行输出最右一列全是 1——任取的动点 $M$ 个个落在小圆 $(x-3)^2 + y^2 = 1$ 上，相关点法的产品抽检合格。反过来你也可以改 $P$ 的取法（比如只走半个圆），看 $M$ 的轨迹跟着缩成半个小圆——**轨迹的完整性由动点的活动范围决定**，这正是第 4 步查范围的原因。

::::warning[常见误区]

**误区一**："你以为方程求出来就万事大吉。" 化简中的平方、去分母会引入"增根"——比如例 1 的椭圆方程包含 $(\pm 2, 0)$，但它们使原条件的分母为零。**方程 + 范围**才是轨迹的完整答案。

**误区二**："你以为定义法看到'距离之和'就套椭圆。" 先核对 $2a$ 与 $|F_1F_2|$ 的大小：$2a > |F_1F_2|$ 是椭圆；$2a = |F_1F_2|$ 轨迹是**线段**；$2a < |F_1F_2|$ 无轨迹。差的情形（双曲线）同理要 $2a < |F_1F_2|$。

**误区三**："你以为相关点法就是把动点代进去。" 方向别反：是用**动点 $Q$ 的坐标**表示**已知曲线上的点 $P$**，再代 $P$ 进已知方程。把已知曲线的点代进未知条件，等于什么都没求。

::::

## 6. 练习

**练习 1**：$P$ 在圆 $x^2 + y^2 = 4$ 上运动，$A(6, 0)$ 为定点，$M$ 为 $AP$ 中点。例 3 已算出 $M$ 的轨迹是圆 $(x - h)^2 + y^2 = r^2$，求 $h$ 与 $r$。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：中点的轨迹圆
# @check: 3
# @check: 1
# @hint: 中点公式 x = (xP+6)/2 反解得 xP = 2x−6（别忘了乘 2），yP = 2y；代入 xP²+yP²=4 后两边同除 4，得 (x−3)²+y²=1。初始代码直接抄了 A 的横坐标和原圆半径，没做中点变换。
# 用中点公式反解：x = (xP + 6)/2  =>  xP = 2x - 6；yP = 2y
# 代入 xP² + yP² = 4：
# (2x - 6)² + (2y)² = 4  =>  4(x-3)² + 4y² = 4  =>  (x-3)² + y² = 1
h = 6                                # ← 圆心横坐标真的是 6 吗？
r = 2                                # ← 半径真的还是 2 吗？
print(h)
print(r)
```

<details>
<summary>点开查看逐步解答</summary>

1. 反解老点：$x_P = 2x - 6$，$y_P = 2y$（中点公式 $x = \tfrac{x_P + 6}{2}$ 两边乘 2 再减 6，初始代码偷懒直接抄了 $A$ 的横坐标 6 和原半径 2）；
2. 代入大圆：$(2x - 6)^2 + (2y)^2 = 4 \Rightarrow 4(x-3)^2 + 4y^2 = 4 \Rightarrow (x-3)^2 + y^2 = 1$；
3. 所以 $h = 3$、$r = 1$。抽检：$P = (0, 2)$ 时 $M = (3, 1)$，$(3-3)^2 + 1^2 = 1$ ✓。

输出的两行是 `3` 与 `1` ✓。几何直观：轨迹圆是大圆按比例 $\tfrac{1}{2}$ 缩小、再朝 $A$ 平移过来的像——圆心恰是"大圆圆心 $O$ 与 $A$ 连线的中点" $(3, 0)$。

</details>

**练习 2**：动点 $M$ 到点 $F(1, 0)$ 的距离与到直线 $x = -1$ 的距离相等，用直接法求轨迹方程，并说明定义法能一步写出答案的理由。

<details>
<summary>点开查看逐步解答</summary>

1. 直接法：$\sqrt{(x-1)^2 + y^2} = |x + 1|$，两边平方：$(x-1)^2 + y^2 = (x+1)^2$，展开消去 $x^2$：$-2x + y^2 = 2x$，即 $y^2 = 4x$；
2. 定义法：到定点与到定直线（定点不在直线上）等距，正是抛物线的定义原话——焦点 $(1, 0)$、准线 $x = -1$ 对应 $y^2 = 2px$ 的 $p = 2$，直接写 $y^2 = 4x$；
3. 范围：平方那一步两边都非负，没有增根；轨迹是整条抛物线，无需挖点。两种方法殊途同归，但定义法三步并作一步——**先认定义，能省一半代数**。
</details>

## 7. 边界与适用条件

三种方法不是三选一的闭卷考试：同一道题往往先用定义法认出曲线类型，再用直接法补细节。相关点法要求"老点"的轨迹方程**已知**或易求。化简中两边平方前先确认两侧同号（否则会引入增根）；斜率类条件自带 $x \neq x_0$ 的挖点；"轨迹"与"轨迹方程"是两回事——前者是曲线本身（含挖点），后者是那个方程，答题时两句都要说。

## 8. 选读：认曲线的速查表

<details>
<summary>选读 · 条件里的关键词 → 该认哪条曲线</summary>

| 条件关键词 | 曲线 | 速记 |
| --- | --- | --- |
| 到两定点距离之**和**恒定（大于两定点间距） | 椭圆 | "和" |
| 到两定点距离之**差**恒定（小于两定点间距） | 双曲线 | "差" |
| 到定点与到定直线距离**相等** | 抛物线 | "比"（等距） |
| 到定点距离恒定 | 圆 | 半径 |
| 到两定点连线**斜率之积**为负常数 | 椭圆（挖两端点） | 例 1 的变形 |
| 到两定点连线**斜率之积**为正常数 | 双曲线（挖顶点） | 符号决定胖瘦 |

斜率乘积那两行把例 1 的方法推广了：积为 $-\tfrac{b^2}{a^2}$（把两定点放在 $x$ 轴上对称位置）时轨迹是椭圆挖点，积为 $+\tfrac{b^2}{a^2}$ 时是双曲线挖点——点差法那课的推论在这里反过来用。至于动点带约束（比如还要在某直线上）的复合轨迹，属于解析几何综合题的领域，本课不展开。
</details>
