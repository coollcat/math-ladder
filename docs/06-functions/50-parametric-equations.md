# 参数方程：用时间描述曲线

## 1. 从一个场景开始

摩天轮转到最高点时，座舱正上方；转半圈后，它来到同一根立柱的另一侧，高度一样、左右相反。用上一课的椭圆方程描述它毫无压力——可是当你想知道"**第 10 秒时我挂在哪里**"，方程沉默了：静态的关系式里没有时间这个角色。

再看投篮：篮球离手的瞬间你只知道水平速度和竖直初速，此后每一刻它在哪儿、往哪儿飞。**一圈重游的轨迹写不成 y=f(x)**（同一个横坐标对应两个高度），但每分每秒的位置却清清楚楚。这一课就补上这个缺口：给曲线发一张时间表。

## 2. 直觉解释

$y=f(x)$ 像一张**合影**：所有瞬间叠在一张纸上，谁先谁后再看不出来。参数方程是一段**逐帧录像**——拿着秒表报坐标：

| 时刻 t | 横坐标 x | 纵坐标 y |
| --- | --- | --- |
| 0 秒 | 出发点横坐标 | 出发点高度 |
| 第 1 帧 | …… | …… |

先把暴力账本摆出来再谈规则。取 $g=10$、竖直初速 8、水平速度 5 的投篮：竖直上"每秒少 8 米的速度"，水平上一路匀速。

- **第 0 秒**：$(0,\ 0)$；
- **第 0.8 秒**：横向走到 $5 \times 0.8 = 4$，纵向 $8 \times 0.8 - 5 \times 0.8^2 = 3.2$——恰好抵达最高点；
- **第 1.6 秒**：纵向归零落回出手高度，横向已走出 $5 \times 1.6 = 8$ 米。

把三帧点连起来，一条开口向下的抛物线浮现——和 [二次函数与抛物线](./30-quadratic.md) 是老相识。新东西不是形状，而是**每一点都带着自己的时刻**。

## 3. 正式定义

$$\begin{cases} x = x(t) \\ y = y(t) \end{cases} \qquad (t \in T)$$

单行书写即：$x=x(t)$，$y=y(t)$，其中 t 取遍集合 T。

| 记号 | 名字 | 说明 |
| --- | --- | --- |
| $t$ | 参数 | 不一定是时间！任何能"顺藤摸瓜带出坐标"的量都行；本章为了直觉一律当秒表读 |
| $x(t),y(t)$ | 两个分量函数 | 各管一根轴；像两人接力，一个只报东西向、一个只报南北向 |
| $T$ | 参数范围 | 时间表的有效区间，比如从出手到落地 $T = [0, 1.6]$ |
| 消参 | 反向操作 | 设法从两条式子里消去 t，回到 $y=f(x)$ 的合影形式 |

投篮的时刻表正式化：$x = 5t$（水平匀速），$y = 8t - 5t^2$（竖直匀加速，系数 5 正是 $g/2$），$t \in [0,\ 1.6]$。

## 4. 分步例题

**例**：从上面的时刻表中消去参数 t，得到普通方程，并指出顶点与落点。

1. **解出 t**：由 $x = 5t$ 得 $t = x/5$（水平方向最"听话"，先拿它开刀）；
2. **代入**：$y = 8 \cdot \dfrac{x}{5} - 5 \cdot \left(\dfrac{x}{5}\right)^2 = \dfrac{8}{5}x - \dfrac{1}{5}x^2$；
3. **认亲戚**：这是二次函数 $y = ax^2 + bx$ 型，其中 $a = -\frac{1}{5}$、$b = \frac{8}{5}$——开口向下，对称轴 $x = -b/(2a) = 4$；
4. **读顶点**：对称轴对应 $t = x/5 = 0.8$ 秒，高度 $\frac{8}{5} \times 4 - \frac{1}{5} \times 16 = 3.2$ 米——与第 2 节手算的第 0.8 帧完全一致；
5. **读落点**：令 $y=0$ 得非零根 $x = 8$：出手 1.6 秒后，球落在前方 8 米处。

双向都通了：合影可拆成录像，录像也能合成合影。参数视角更"多产"——下一课你会见到**写不出合影**的曲线，只有录像能用。

## 5. 动手实验

### 实验 1（python）：频闪照片——疏密自动泄露快慢

```python title="等时间间隔拍下篮球位置：点的疏密就是速度"
import matplotlib.pyplot as plt  # 画图库

vx = 5                # 水平速度（米/秒），全程不变
vy = 8                # 竖直初速（米/秒）
g = 10                # 重力加速度：每秒竖直速度少 10

xs_path = []          # 存整条轨迹的横坐标列表
ys_path = []          # 存整条轨迹的纵坐标列表
for i in range(200):  # 循环 200 步铺出完整轨迹虚线
    t = 1.6 * i / 199
    xs_path.append(vx * t)
    ys_path.append(vy * t - 5 * t ** 2)

xs_flash = []         # 频闪点的横坐标
ys_flash = []         # 频闪点的纵坐标
for i in range(11):   # 每 0.16 秒曝光一次，共 11 帧
    t = 0.16 * i
    xs_flash.append(vx * t)
    ys_flash.append(vy * t - 5 * t ** 2)

plt.plot(xs_path, ys_path, linestyle="--", color="gray")
plt.scatter(xs_flash, ys_flash, s=80)     # s 控制点的大小
plt.title("每隔 0.16 秒闪一次灯的篮球轨迹")
plt.grid(True)

print(f"起点 {(xs_flash[0], ys_flash[0])}，终点 {(round(xs_flash[-1],1), round(ys_flash[-1],1))}")
print("看疏密：出发段挤、中段稀？调转方向验证你的猜想")
```

怎么玩：灰虚线是完整轨迹，圆点是每 0.15 秒一次的频闪记录。起点附近圆点挤作一团（那时慢）、中段稀疏（最快）——**录像比合影多出的正是这层节奏信息**，而节奏是任何 $y=f(x)$ 都保存不了的东西。

### 实验 2（python）：拖动秒表，逐帧回放

```python title="选定时刻的位置与速度方向"
import math                      # 数学库：sqrt 开平方
import matplotlib.pyplot as plt  # 画图库

# sliders: tt=0.5 [0:1.6:0.05]

vx = 5                                        # 水平速度恒定
vy = 8                                        # 竖直初速
g = 10                                        # 重力加速度

px = vx * tt                                  # 该时刻的横坐标
py = vy * tt - 5 * tt ** 2                    # 该时刻的纵坐标
vspd = vy - g * tt                            # 此刻竖直速度：初速减去掉的部分
speed = math.sqrt(vx * vx + vspd * vspd)      # sqrt 合成实际速率（斜边长）

path_t = []                                   # 轨迹横坐标列表
path_y = []                                   # 轨迹纵坐标列表
for i in range(181):
    t = i / 100
    path_t.append(vx * t)
    path_y.append(vy * t - 5 * t ** 2)

plt.plot(path_t, path_y, linewidth=1, color="gray")
plt.scatter([px], [py], s=90, color="red")    # 当前帧的红点
plt.annotate("",                               # 空文字 + 箭头：画速度方向箭头
             xy=(px + vx / 6, py + vspd / 6), # 箭头尖
             xytext=(px, py),                  # 箭头尾（当前位置）
             arrowprops={"arrowstyle": "->", "color": "orange"})
plt.axhline(0, color="black", linewidth=0.8)
plt.grid(True)

print(f"t={round(tt,2)} 秒：位置 ({round(px,2)}, {round(py,2)})，速率 {round(speed,2)}")
```

怎么玩：拖动 tt，红点沿轨迹滑行，橙色箭头实时指向下一步去处。注意两件事：**水平速度从不变化**（箭头的横向长度固定），以及当竖直速度恰好清零时（约 tt=0.8）箭头水平——那一刻球正在"翻越山顶"。公式读法：上升段 vspd 为正、下降段为负，符号自己会讲故事。

### 快问快答

```quiz
把 x = 3t、y = 5t 消去参数 t，得到的图形是什么？
- 一条过原点的直线 [*]
- 一条开口向上的抛物线
- 两段不相交的射线
? 由 x=3t 得 t=x/3，代入得 y=5x/3：一次函数图像当然是一条直线。加个平方项才会弯成抛物线。
```

:::warning[常见误区]

**误区一**："你以为参数方程里的 t 就是横坐标。" 多数时候不是：投篮的横坐标是 $5t$，t 只是幕后钟表。把 t 当 x 直接描点，等于把秒表读数钉在了地面上。

**误区二**："你以为一条曲线只有一套参数方程。" 走同一条路可以快走、慢走、倒着走：换一只钟（比如令 $u=2t$）立刻得到另一套同样合法的时间表。合影唯一，录像无数。

**误区三**："你以为落地时刻就是'竖直速度归零'的时刻。" 速度归零发生在**最高点**（往上抛的劲儿刚好用完），而落地要等**高度归零**——本题里前者是 0.9 秒、后者是 1.8 秒，整整差一倍。别把山脚和山顶混为一谈。

:::

## 6. 练习

**练习 1**：仍用这套投篮（vx=5、vy=8、g=10），算出落地点横坐标与最大高度（四舍五入）。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：投篮的落点与最大高度
# @check: 8
# @check: 3
# @hint: "落地"是高度 y 清零，不是竖直速度清零——两者差着整整一倍时间；修好时刻后，第二行会保持不变，想想为什么。
vx = 5               # 水平速度（米/秒）
vy = 8               # 竖直初速（米/秒）
g = 10               # 重力加速度

land_t = vy / g      # ← 你把哪个时刻当成了落地？
land_x = vx * land_t
print(round(land_x))

apex_t = vy / (g / 2)
apex_y = vy * apex_t - 5 * apex_t ** 2   # ** 表示乘方：5*t²
print(round(apex_y))
```

<details>
<summary>点开查看逐步解答</summary>

暗坑全部集中在第一行的时刻选择上：

1. **找对落地条件**：高度清零即 $8t - 5t^2 = 0$，提公因式得 $t(8 - 5t) = 0$，非零解 $t = 8/5 = 1.6$ 秒。初始代码写的 `vy/g` 是竖直速度清零的时刻 0.8 秒——那是**山顶**，不是山脚；
2. **重算横程**：$x = 5 \times 1.6 = 8$ 米 ✓（初始代码拿山顶时刻 0.8 去乘，得到 4 米——只走到半程）；
3. **顶点本来就在速度归零处**：竖直方向升至最高时速度恰为零，所以第二行用的 0.8 秒是对的，$8 \times 0.8 - 5 \times 0.64 = 3.2$，取整为 3 ✓。这就是提示里说的"第二行保持不变"——错误只在第一行，第二行本来就是对的时刻。

修正后的参考代码：

```python
vx = 5                            # 水平速度（米/秒）
vy = 8                            # 竖直初速（米/秒）
g = 10                            # 重力加速度

land_t = vy / (g / 2)             # 高度清零：由 8t − 5t² = 0 解出
land_x = vx * land_t
print(round(land_x))

apex_t = vy / (g / 2)             # 最高点：竖直速度清零处
apex_y = vy * apex_t - 5 * apex_t ** 2
print(round(apex_y))
```

输出 `8` 与 `3`。两个时刻为什么恰好差一倍？地面高度为 0 时抛体轨迹首尾对称——一半时间花在登顶，另一半对称地在下坡。

</details>

**练习 2**：甲、乙两位观察员沿同一直线路径前进：甲按 $x=t$、乙按 $x=t^3$ 报坐标（t 同步）。两人的合影有区别吗？"录像观感"差别在哪？

<details>
<summary>点开查看逐步解答</summary>

合影无区别：把乙的坐标列出来仍是整条直线的全体实数点，$x=t^3$ 与 $x=t$ 描出的是**同一条几何路径**。差别全在录像里：随着 t 匀速增长，$t^3$ 的脚印起步极慢、后来越跑越疯——频闪照片上前段密、后段稀。参数变了，路程没变，节奏大变。这正是"换一只合法时钟就得到一套新参数方程"的具体演示；选读部分说明这种换钟为何永远办得到。
</details>

## 7. 边界与适用条件

本课解决"封闭/往返曲线写不出 y=f(x)"的记录问题，但以下事情它不做也不装：沿曲线的实际里程要靠弧长积分（后续微分几何章）；给定光滑性条件的曲线拼接与贝塞尔样条是工程绘图章的地盘；三维运动需要三个分量式同时开工，方法平移但不展开；另外"两条参数轨迹何时相撞"要联立两组时间表逐时刻核对，不能只比较最终形状——同一张合影背后可以是两部毫不相干的剧本。

## 8. 选读：为什么人人都能"换一只钟"

<details>
<summary>选读 · 无穷多套时间表的小证明</summary>

设一条曲线已有参数方程 $x=x(t),\ y=y(t)$（$t \in T$）。任取一个严格递增的可逆函数 $\varphi$ 把新区间映射到 T（例如 $\varphi(u) = 2u$、$\varphi(u)=u^3$ 均合格），则

$$x = x(\varphi(u)), \qquad y = y(\varphi(u))$$

扫出的点集原封不动：旧时间表里的每个 t 都被新钟 u 唯一确定（递增保证单调、可逆保证不重不漏）。于是同一条曲线获得一套新的参数方程——只要换的那只钟"顺着走且走得开"，录像就是同一部片子的变速版。这也解释了为什么数学书里参数方程总是附带区间标注：**没有时间表的范围，坐标就无从谈起**。

</details>
