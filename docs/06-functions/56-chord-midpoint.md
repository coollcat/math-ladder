# 中点弦与点差法

## 1. 从一个场景开始

一座椭圆形温室（方程 $\dfrac{x^2}{4} + y^2 = 1$），园艺师要从棚内一点 $M(1, \tfrac{1}{2})$ 出发架一根直杆，两端恰好抵住椭圆骨架。杆的斜率取多少才能让 $M$ 不偏不倚站在杆的**正中间**？硬算交点当然可以，但有一招更快的：把两个"在曲线上"的方程**相减**，中点与斜率的关系会自己跳出来。

## 2. 直觉解释

设弦的两个端点是 $A(x_1, y_1)$、$B(x_2, y_2)$，都在椭圆上，所以两个坐标对都满足椭圆方程。把两个方程并排写着，然后**上式减下式**：

- 相同的部分（常数、单个的平方项）全部消掉；
- 剩下的部分恰好能**因式分解**成"（横坐标差）×（横坐标和）"与"（纵坐标差）×（纵坐标和）"两块。

而"横坐标差""横坐标和"分别连着**斜率** $k = \dfrac{y_1 - y_2}{x_1 - x_2}$ 与**中点** $x_M = \dfrac{x_1 + x_2}{2}$。于是相减一次，斜率与中点就挂上了钩——这就是点差法的全部秘密：**两式相减，造出"差与和"**。

## 3. 正式定义

以中心在原点的椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ 为例（双曲线、抛物线同理操作）：

| 步骤 | 操作 | 得到什么 |
| --- | --- | --- |
| 1 | 设端点 $A(x_1, y_1)$、$B(x_2, y_2)$，各自代入方程 | 两个等式 |
| 2 | 两式相减 | $\dfrac{x_1^2 - x_2^2}{a^2} + \dfrac{y_1^2 - y_2^2}{b^2} = 0$ |
| 3 | 平方差因式分解 | $\dfrac{(x_1-x_2)(x_1+x_2)}{a^2} + \dfrac{(y_1-y_2)(y_1+y_2)}{b^2} = 0$ |
| 4 | 除以 $x_1 - x_2$，认领 $k$ 与中点 $(x_M, y_M)$ | $k = -\dfrac{b^2 x_M}{a^2 y_M}$ |

**适用边界**（三条都要满足，否则点差法会"算出"假弦）：

1. 中点 $M$ 必须在椭圆**内部**（过外部点的直线与椭圆没有两个交点，弦不存在）；
2. 斜率必须存在（$x_1 \neq x_2$；竖直弦的中点在 $x$ 轴上，另判）；
3. 算出的直线要**回代联立验 $\Delta > 0$**，确认真有两交点。

顺手的推论：过中心 $O$ 与中点 $M$ 的直线（直径）斜率 $k_{OM} = \dfrac{y_M}{x_M}$，于是椭圆里 $k_{AB} \cdot k_{OM} = -\dfrac{b^2}{a^2}$——中点弦的斜率被中点方向完全决定。

## 4. 分步例题

**例**：椭圆 $\dfrac{x^2}{4} + y^2 = 1$，求以 $M(1, \tfrac{1}{2})$ 为中点的弦所在直线的斜率与方程。

1. **认参数**：$a^2 = 4$，$b^2 = 1$，中点 $x_M = 1$，$y_M = \tfrac{1}{2}$，且 $M$ 在椭圆内（$\tfrac{1}{4} + \tfrac{1}{4} = \tfrac{1}{2} < 1$ ✓）；
2. **套公式**：$k = -\dfrac{b^2 x_M}{a^2 y_M} = -\dfrac{1 \times 1}{4 \times \tfrac{1}{2}} = -\dfrac{1}{2}$；
3. **写方程**：点斜式 $y - \tfrac{1}{2} = -\tfrac{1}{2}(x - 1)$，即 $y = -\tfrac{1}{2}x + 1$；
4. **回代验货**：代入椭圆得 $\tfrac{x^2}{4} + \left(-\tfrac{x}{2} + 1\right)^2 = 1$，展开 $\tfrac{x^2}{4} + \tfrac{x^2}{4} - x + 1 = 1$，即 $x^2 - 2x = 0$，$\Delta = 4 > 0$ ✓；
5. **解出端点**：$x = 0$ 或 $2$，端点 $(0, 1)$、$(2, 0)$——中点恰是 $(1, \tfrac{1}{2})$ ✓，弦长 $\sqrt{2^2 + 1^2} = \sqrt{5}$。

第 4、5 步是点差法的**验收环节**：公式只负责"猜"，回代负责"证"。

## 5. 动手实验

### 实验 1（lab）：只有一条斜率配得上这个中点

```lab

  "funcs": ["sqrt(4 - x^2)/2", "-sqrt(4 - x^2)/2", "k*(x - 1) + 0.5"],
  "view": [-3, 3],
  "params": { "k": -0.5 },
  "height": 380
}
```

直线的方程是 $y = k(x - 1) + \tfrac{1}{2}$——永远经过 $M(1, 0.5)$，斜率 $k$ 由滑块控制。三个任务：

1. 把 $k$ 从 $-0.5$ 拧到 $0$：直线转平，两个交点越来越不对称，$M$ 明显偏离弦的中点；
2. 拧回 $k = -0.5$：交点恰好是 $(0, 1)$ 与 $(2, 0)$，$M$ 回到正中间；
3. 继续拧到 $k = 1$ 附近：交点跑到了 $M$ 的另一侧——**过定点的直线有无数条，但"以该点为中点"的弦只有一条**。

### 实验 2（python）：两条路算斜率，当场对账

```python title="点差法 vs 端点实际斜率"
import math                          # 数学库：sqrt 开平方

a2, b2 = 4, 1                        # 椭圆 x²/4 + y² = 1 的 a² 与 b²
xM, yM = 1, 0.5                      # 中点 M

k_diff = -b2 * xM / (a2 * yM)        # 点差法公式：k = -b²xM / (a²yM)

# 回代解端点：y = k(x-1)+0.5 代入椭圆，整理得 x²/4 + (k(x-1)+0.5)² = 1
# 用 k=-0.5 时化简为 x² - 2x = 0，两根 x=0 与 x=2
x1, y1 = 0, 1                        # 端点 A(0, 1)
x2, y2 = 2, 0                        # 端点 B(2, 0)
k_real = (y2 - y1) / (x2 - x1)       # 端点连线实际斜率

mid = ((x1 + x2) / 2, (y1 + y2) / 2) # 端点中点，验证是不是 M
chord = math.sqrt((x2-x1)**2 + (y2-y1)**2)   # 两点距离公式算弦长

print(f"点差法斜率: {k_diff}")
print(f"实际斜率:   {k_real}")
print(f"中点核对:   {mid}")
print(f"弦长:       {round(chord, 2)}")
```

两行斜率完全一致，中点恰是 $M(1, 0.5)$，弦长 $\sqrt{5} \approx 2.24$。点差法没解任何方程就把斜率报出来了——回代那一步只是确认弦真的存在。

::::warning[常见误区]

**误区一**："你以为点差法算出斜率就万事大吉。" 若中点在椭圆**外部**，公式照样会吐出一个数，但对应的直线与椭圆根本没有两个交点——弦不存在。回代验 $\Delta > 0$ 是必做步骤，不是走过场。

**误区二**："你以为弦的中点公式只管椭圆。" 相减的手法对双曲线、抛物线一样好使，只是公式里的系数不同（双曲线变成 $k = \dfrac{b^2 x_M}{a^2 y_M}$，符号翻正）。死记椭圆公式不如记**"相减、平方差、认领差与和"**这三步动作。

**误区三**："你以为以 $M$ 为中点的弦可以随便转。" 过 $M$ 的直线有无穷多条，但弦被 $M$ 平分的只有一条——因为斜率被公式唯一确定。滑块实验里拧出的其他交点组合，中点都不在 $M$。

::::

## 6. 练习

**练习 1**：沿用本课的椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 与中点 $M(1, \tfrac{1}{2})$，求这条弦的长度。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：给中点弦量长度
# @check: 2.24
# @hint: 点差法斜率 k = -b²xM/(a²yM)，b²=1、a²=4，结果是 −0.5（别丢负号）。端点是 (0,1) 和 (2,0)，弦长 = √(2²+1²) = √5，保留两位小数。
import math                          # 数学库：sqrt 开平方

a2, b2 = 4, 1                        # 椭圆的 a² 与 b²
xM, yM = 1, 0.5                      # 中点 M

k = b2 * xM / (a2 * yM)              # ← 符号对吗？点差法里斜率与中点"反向"
b = yM - k * xM                      # 直线 y = kx + b 过中点 M

# 回代：x²/4 + (kx+b)² = 1，整理成 (1/4 + k²)x² + 2kb·x + (b² - 1) = 0
A = 0.25 + k * k                     # 二次项系数
B = 2 * k * b                        # 一次项系数
C = b * b - 1                        # 常数项
disc = B * B - 4 * A * C             # 判别式，顺便检查弦是否存在
x1 = (-B + math.sqrt(disc)) / (2 * A)   # 求根公式解出两个端点的横坐标
x2 = (-B - math.sqrt(disc)) / (2 * A)
y1 = k * x1 + b
y2 = k * x2 + b

chord = math.sqrt((x2-x1)**2 + (y2-y1)**2)
print(round(chord, 2))
```

<details>
<summary>点开查看逐步解答</summary>

1. 点差法：$k = -\dfrac{b^2 x_M}{a^2 y_M} = -\dfrac{1 \times 1}{4 \times 0.5} = -0.5$（初始代码丢了负号，配出的是直线 $y = \tfrac{1}{2}x$——它的中点是原点 $(0, 0)$，根本不平分过 $M$ 的那条弦）；
2. 修正斜率后直线是 $y = -\tfrac{1}{2}x + 1$，回代得 $x^2 - 2x = 0$，端点 $A(0, 1)$、$B(2, 0)$，弦长 $= \sqrt{2^2 + 1^2} = \sqrt{5}$；
3. $\sqrt{5} \approx 2.236$，保留两位小数是 **2.24**（初始代码算出的 $\sqrt{10} \approx 3.16$ 是错误斜率对应的弦）。

修正后的参考代码只需把符号补上：

```python
import math

k = -1 * 1 / (4 * 0.5)               # 点差法：k = -b²xM/(a²yM) = -0.5
b = 0.5 - k * 1                      # y = kx + b 过 M(1, 0.5)

A = 0.25 + k * k
B = 2 * k * b
C = b * b - 1
x1 = (-B + math.sqrt(B*B - 4*A*C)) / (2 * A)
x2 = (-B - math.sqrt(B*B - 4*A*C)) / (2 * A)
y1, y2 = k * x1 + b, k * x2 + b

print(round(math.sqrt((x2-x1)**2 + (y2-y1)**2), 2))
```

输出 `2.24` ✓（求根公式解出 $x_1 = 2$、$x_2 = 0$）。顺带一提：$k_{OM} = 0.5 / 1 = 0.5$，$k_{AB} \cdot k_{OM} = -0.25 = -\dfrac{b^2}{a^2}$，与第 3 节的推论吻合 ✓。

</details>

**练习 2**：双曲线 $\dfrac{x^2}{4} - y^2 = 1$ 中，以 $M(3, 1)$ 为中点的弦存在吗？先用"中点是否在曲线内"直觉判断，再用回代验 $\Delta$ 确认。

<details>
<summary>点开查看逐步解答</summary>

1. 点差法公式（双曲线符号翻正）：$k = \dfrac{b^2 x_M}{a^2 y_M} = \dfrac{1 \times 3}{4 \times 1} = \tfrac{3}{4}$，直线 $y - 1 = \tfrac{3}{4}(x - 3)$，即 $y = \tfrac{3}{4}x - \tfrac{5}{4}$；
2. 回代：$\tfrac{x^2}{4} - \left(\tfrac{3x}{4} - \tfrac{5}{4}\right)^2 = 1$，整理得 $16x^2 - 4(9x^2 - 30x + 25) = 64$，即 $-20x^2 + 120x - 164 = 0$，$\Delta = 120^2 - 4 \times 20 \times 164 = 14400 - 13120 = 1280 > 0$，弦存在 ✓（$M(3,1)$ 代入左边得 $\tfrac{9}{4} - 1 = \tfrac{5}{4} > 1$，落在右支张口的内侧——双曲线含焦点的"内部"区域，直觉也对得上）。
</details>

## 7. 边界与适用条件

点差法处理的是"**弦的中点**"问题；反过来"过定点求弦"要走上一课的联立流程。竖直弦（$x_1 = x_2$）斜率不存在，相减后除以 $x_1 - x_2$ 那一步不合法，要单独讨论。中点在 $x$ 轴上（$y_M = 0$）时公式分母为零，对应的弦是水平弦，直接写 $y = 0$ 联立。最后再强调一遍：**相减给的是必要条件**，算出的斜率必须回代验证弦真实存在——这一步省掉，点差法就从捷径变成陷阱。

## 8. 选读：$k_{AB} \cdot k_{OM} = -\dfrac{b^2}{a^2}$ 为什么是定值

<details>
<summary>选读 · 中点弦斜率与"直径"斜率的乘积恒定</summary>

把点差法的结论 $k_{AB} = -\dfrac{b^2 x_M}{a^2 y_M}$ 两边除以中点方向斜率 $k_{OM} = \dfrac{y_M}{x_M}$：

$$k_{AB} \cdot k_{OM} = -\frac{b^2 x_M}{a^2 y_M} \cdot \frac{y_M}{x_M} = -\frac{b^2}{a^2}$$

$x_M$、$y_M$ 全部约掉——**与中点在哪无关**。这在射影几何里对应"共轭直径"：椭圆没有互相垂直的直径，但每对共轭直径的斜率乘积恒为 $-\tfrac{b^2}{a^2}$；圆是 $a = b$ 的特例，乘积 $-1$ 恰好退化成"垂直"——圆的共轭直径就是互相垂直的直径。下一课的"定值"问题，正是把这种"参数变、乘积不变"的现象正式当作研究对象。
</details>
