# 零点与二分法：把根夹出来

## 1. 从一个场景开始

方程 $x^3 - x - 1 = 0$ 的解是多少？

一元二次方程有求根公式（第 4 章），三次方程的公式长得吓人，而更多方程——包括 $x^3-x-1=0$ 这种看起来最朴素的——根本没法把解"写成"一个式子。可工程上天天要它的数值：桥梁的临界荷载、电路的静态工作点，全都是这样求出来的。办法不是硬算，而是**夹**：先证明解确实存在并落在某个区间里，再每次把区间砍掉一半。砍 20 次，区间只剩原来的百万分之一——要几位小数就有几位。

## 2. 直觉解释：猜价格游戏

想象一个游戏：我心里想一个 1 到 100 之间的整数，你每猜一次，我只回答"高了"或"低了"。

最笨的玩法是从 1 开始往上猜，平均要猜 50 次。聪明的玩法是每次猜**正中间**：猜 50，我说"高了"，范围立刻缩到 1–49；再猜 25……每猜一次，可能范围减半。100 以内最多 7 次必中（因为 $2^7 = 128 > 100$）。

二分法就是这个游戏，唯一的区别是"高了/低了"由**函数值的符号**来回答：$f(m) > 0$ 说明根在 $m$ 的某一侧，$f(m) < 0$ 说明在另一侧。

有两个前提缺一不可：

1. 答案确实在范围里（对应：**零点存在定理**）；
2. 每次问答都一定能把范围砍掉一半（对应：**函数连续**，图像一笔画不断）。

## 3. 正式定义

### 3.1 零点

使 $f(x) = 0$ 成立的**实数 $x$** 叫函数 $f$ 的零点。

请注意措辞：零点是**一个数**，不是图像上的一个点。图像上与之对应的是点 $(x, 0)$——它是图像与 x 轴的**交点**，而零点是这个交点的**横坐标**。

同一件事的三种说法：

| 说法 | 视角 | 记号 |
| --- | --- | --- |
| 方程 $f(x)=0$ 的**根** | 代数 | 解集中元素 |
| 函数 $f$ 的**零点** | 函数 | 一个数 $x_0$ |
| 图像与 x 轴**交点的横坐标** | 几何 | 点 $(x_0,\,0)$ |

### 3.2 零点存在定理

若函数 $f$ 在闭区间 $[a, b]$ 上**连续**，且

$$f(a) \cdot f(b) < 0$$

则 $f$ 在开区间 $(a, b)$ 内**至少有一个**零点。

| 条件 | 含义 | 缺了会怎样 |
| --- | --- | --- |
| 连续 | 图像在 $[a,b]$ 上一笔画到底，中间不断开 | 反例：$y=\dfrac{1}{x}$ 在 $[-1,1]$ 上端点异号，却在 $x=0$ 处断开飞走，**没有零点** |
| $f(a)f(b)<0$ | 端点异号，图像两端分居 x 轴两侧 | 若同号则定理不做任何承诺（可能仍有两个零点，见 §7 边界） |

定理只保证"至少有一个"，**不告诉你有几个，也不告诉你它在哪**。要几个、在哪，得另外判断。

### 3.3 二分法

在确认 $[a,b]$ 内有零点之后，反复执行：

| 步骤 | 操作 | 理由 |
| --- | --- | --- |
| 1 | 取中点 $m = \dfrac{a+b}{2}$ | 把区间一分为二 |
| 2 | 算 $f(m)$；若 $f(m)=0$，则 $m$ 就是零点，结束 | 撞上了就直接收工 |
| 3 | 若 $f(a)\cdot f(m) < 0$，令 $b = m$ | 左端点与中点异号 → 根在左半边，砍掉右半边 |
| 4 | 否则令 $a = m$ | 根在右半边，砍掉左半边 |
| 5 | 回到步骤 1 | 区间又短了一半 |

**精度估计**（这是二分法最实用的部分）：

- 每做一次，区间长度减半。做 $n$ 次后，区间长度为 $\dfrac{b-a}{2^n}$；
- 真根夹在区间内，所以取**中点**作近似根时，误差不超过区间长度的一半：

$$\bigl|\, \text{近似根} - \text{真根} \,\bigr| \le \frac{b-a}{2^{\,n+1}}$$

- 反解：要让误差小于 $\varepsilon$，需要

$$\frac{b-a}{2^{\,n}} < 2\varepsilon \quad\Longleftrightarrow\quad 2^{\,n} > \frac{b-a}{2\varepsilon}$$

停止条件就写在这里：区间长度小于 $2\varepsilon$ 时停手。注意那个因子 2——很多人拿区间长度直接和 $\varepsilon$ 比，会**多算一步**（见练习 2）。

## 4. 分步例题

求 $f(x) = x^3 - x - 1$ 在 $[1, 2]$ 上的零点（精确到 0.1）。

**第 1 步 · 验证定理条件**。$f(1) = 1 - 1 - 1 = -1 < 0$，$f(2) = 8 - 2 - 1 = 5 > 0$，端点异号 ✓；多项式处处连续 ✓。定理保证 $(1, 2)$ 内至少有一个零点。

**第 2 步 · 说明只有一个**（用上一课的单调性，全程不用导数）。设 $1 \le x_1 < x_2 \le 2$，则

$$x_2^3 - x_1^3 = (x_2 - x_1)(x_2^2 + x_1x_2 + x_1^2) \ge 3(x_2-x_1)$$

因为 $x_1, x_2 \ge 1$，乘积 $x_2^2$、$x_1x_2$、$x_1^2$ 每一项都不小于 1，括号里的和至少是 3。于是

$$f(x_2) - f(x_1) = (x_2^3 - x_1^3) - (x_2 - x_1) \ge 3(x_2-x_1) - (x_2-x_1) = 2(x_2-x_1) > 0$$

所以 $f$ 在 $[1,2]$ 上**严格递增** → 零点至多一个。合起来：**恰好一个**。

**第 3 步 · 开始砍区间**。

| 次数 | 中点 $m$ | $f(m)$ | 符号判断 | 新区间 |
| --- | --- | --- | --- | --- |
| 1 | 1.5 | 0.875 | $f(1)$ 与 $f(1.5)$ 异号 | $[1,\ 1.5]$ |
| 2 | 1.25 | $-0.296875$ | 同号 → 砍左边 | $[1.25,\ 1.5]$ |
| 3 | 1.375 | 0.224609375 | 异号 | $[1.25,\ 1.375]$ |
| 4 | 1.3125 | $-0.051513671875$ | 同号 → 砍左边 | $[1.3125,\ 1.375]$ |

**第 4 步 · 收工判据**。"精确到 0.1" 就是要求四舍五入到 0.1 不出错，即误差小于 $0.05$。3 次后区间长 $0.125$，中点误差 $\le 0.0625 > 0.05$，还不够；4 次后误差 $\le 0.03125 < 0.05$，够了。中点为 $\dfrac{1.3125+1.375}{2} = 1.34375$，所以零点约等于 **1.3**（精确到 0.1）。

**自检**：$f(1.3) = 2.197 - 1.3 - 1 = -0.103$，$f(1.4) = 2.744 - 1.4 - 1 = 0.344$，异号 → 根确实在 $(1.3, 1.4)$ 之间 ✓。

### 实验 4（python）：手写一遍二分法

```python title="20 步夹出 x³ - x - 1 的根"
def f(x):
    return x**3 - x - 1          # ** 是乘方：x³ 写作 x**3

lo = 1                           # 左端点：f(1) = -1
hi = 2                           # 右端点：f(2) = 5
print(f"起点区间 [{lo}, {hi}]，f(lo)={f(lo)}，f(hi)={f(hi)}")

for step in range(1, 21):        # 固定做 20 次，浏览器里别写无条件的死循环
    mid = (lo + hi) / 2          # 区间中点
    if f(lo) * f(mid) < 0:       # 左端点与中点异号：根藏在左半边
        hi = mid                 # 砍掉右半边
    else:
        lo = mid                 # 砍掉左半边
    if step <= 4:                # 只打印前四步，看清楚"砍半"的过程
        print(f"第 {step} 步: 区间 [{lo}, {hi}]")

print(f"20 步后近似根: {round((lo + hi) / 2, 6)}")
print(f"20 步后区间长度: {1 / 2**20:.3e}")   # :.3e 是科学计数法，保留三位小数
```

前四步依次把区间砍成 `[1, 1.5]`、`[1.25, 1.5]`、`[1.25, 1.375]`、`[1.3125, 1.375]`——和 §4 的表格逐格对得上。20 步后的近似根是 **1.324718**，区间长度只剩约 $9.537\times 10^{-7}$，也就是原来的百万分之一。

把 `lo`、`hi` 改成 $0$ 和 $1$ 再跑一次会怎样？$f(0)=-1$、$f(1)=-1$，端点**同号**，二分法会在错误的区间里乱砍一气，给出的"根"毫无意义。**先验证端点异号，再开砍**，这是使用二分法不可跳过的第一步。

### 快问快答

::::warning[常见误区]

**误区一**："零点就是图像与 x 轴的交点。" 交点是**点** $(x_0, 0)$，零点是**数** $x_0$。题目问"函数有几个零点"时回答的是一个整数，而不是坐标。

**误区二**："端点异号就一定有零点。" 必须再加"连续"：$y=\dfrac{1}{x}$ 在 $[-1,1]$ 上端点异号却在 $x=0$ 处断开，一个零点也没有（实验 2）。

**误区三**："区间长度小于 $\varepsilon$ 就可以停了。" 中点与真根的距离是区间长度的**一半**，所以要保证误差小于 $\varepsilon$，停止条件应是区间长度小于 $2\varepsilon$。直接和 $\varepsilon$ 比会多算一步——练习 2 专治这个手滑。

**误区四**："端点同号就没有零点。" 定理是**充分不必要**的：$y = (x-1)^2$ 在 $[0,2]$ 上两端都是 $1$（同号），却在 $x=1$ 处有一个零点——它只是"擦着"x 轴过去，没有穿越。二分法对这种零点无能为力。

::::

## 6. 练习

**练习 1**：用二分法求 $f(x)=x^3-x-1$ 在 $[1,2]$ 上的零点，做 4 次。下面的代码能跑，但区间一路往右跑出了根——改到通过：

```exercise
# @title: 练习：把区间砍向根，而不是砍离根
# @check: 区间: [1.3125, 1.375]
# @check: 中点: 1.34375
# @check: 区间长度: 0.0625
# @hint: 两个分支装反了：f(lo) 与 f(mid) 异号，说明根在 lo 与 mid 之间，这时该把上界 hi 缩到 mid；否则根在 mid 与 hi 之间，该把下界 lo 抬到 mid。改完每一步都应把 1.32 附近夹在中间（真根约 1.3247）。
def f(x):
    return x**3 - x - 1          # f(1) = -1，f(2) = 5，端点异号

lo = 1
hi = 2
for step in range(1, 5):         # 做 4 次二分
    mid = (lo + hi) / 2
    if f(lo) * f(mid) < 0:       # 左端点与中点异号：根在左半边
        lo = mid                 # ← 根在左半边，该砍掉的是右半边
    else:
        hi = mid

print(f"区间: [{lo}, {hi}]")
print(f"中点: {(lo + hi) / 2}")
print(f"区间长度: {hi - lo}")
```

**练习 2**：仍取区间 $[1, 2]$，要求近似根与真根的误差小于 $0.001$，至少要做多少次二分？

```exercise
# @title: 练习：要多少步才够精确到 0.001
# @check: 需要 9 步
# @hint: 中点与真根的距离只有区间长度的一半，所以要让误差小于 ε，判据是"区间长度 < 2ε"，不是"区间长度 < ε"。while 后面比的那个数少乘了个 2，于是多算了一步。
span = 2 - 1              # 初始区间 [1, 2] 的长度
target = 0.001            # 目标：误差小于 0.001
steps = 0

while span >= target:     # ← 该拿 span 和谁比？中点的误差是 span 的一半
    span = span / 2       # 每次砍半
    steps = steps + 1     # 累加器：旧值加 1 存回去

print(f"需要 {steps} 步")
```

**练习 3**：下面的说法对吗——"若 $f$ 在 $[a,b]$ 上连续且 $f(a)f(b) > 0$，则 $f$ 在 $(a,b)$ 内没有零点"。

<details>
<summary>点开查看逐步解答</summary>

不对。举个反例：$f(x) = (x-1)^2$ 在 $[0, 2]$ 上连续，$f(0)=1$、$f(2)=1$，乘积为 $1 > 0$，但 $f(1) = 0$——零点就在区间正中间。

原因不难理解：零点存在定理说的是"**端点异号就能推出有零点**"，这是**充分条件**而非必要条件；图像可以从上方俯冲下来**擦着**x 轴（相切）再回到上方，两端同号却碰到了 x 轴。实用推论：**用二分法之前先确认端点异号**——同号时它不会报错，只会一路砍向一个错误的答案。

</details>

## 7. 边界与适用条件

本课只处理"能夹住"的零点：连续、端点异号、且（若要求唯一）单调。以下内容刻意留白：

- **重根与相切、偶数个零点**：这两类情形端点都同号，二分法抓不到（$y=(x-1)^2$ 在 $[0,2]$ 上两端都是 1，却在 $x=1$ 处有零点）；得先分区间，让每段至多一个零点；
- **更快的方法**：牛顿法、割线法每步的精度提升远大于二分法，但要导数（第 13 章）且**不保证收敛**——二分法慢，却从不失手；
- **不证明零点存在定理**：它的证明要用到实数的完备性（任何有界单调数列必收敛），属于第 19 章实分析的地盘。本课只把它当作一件可以放心使用的工具。

## 8. 选读：二分法的第 n 步，误差到底是多少

<details>
<summary>选读 · 误差公式的一步一步</summary>

记初始区间为 $[a_0, b_0]$，长度 $L_0 = b_0 - a_0$，第 $n$ 次二分后的区间记作 $[a_n, b_n]$。由构造，$[a_{n+1}, b_{n+1}]$ 是 $[a_n, b_n]$ 的一半，所以

$$L_{n+1} = \frac{L_n}{2} \quad\Longrightarrow\quad L_n = \frac{L_0}{2^n}$$

设真根为 $x_0$。定理的保证在每一步都重新成立（$f(a_n)$ 与 $f(b_n)$ 始终异号），所以 $x_0 \in [a_n, b_n]$ 恒成立。取中点 $m_n = \dfrac{a_n+b_n}{2}$ 作近似，则 $m_n$ 与 $x_0$ 落在同一个长度为 $L_n$ 的区间里，距离不可能超过区间全长的一半：

$$|m_n - x_0| \le \frac{L_n}{2} = \frac{L_0}{2^{n+1}}$$

要它小于 $\varepsilon$，等价于 $2^n > \dfrac{L_0}{2\varepsilon}$——这就是 §3.3 那个公式。代入本课数字：$L_0 = 1$、$\varepsilon = 0.001$，得 $2^n > 500$；$2^9 = 512 > 500$ 而 $2^8 = 256 < 500$，所以 $n = 9$。

**"每步砍一半"意味着什么**：二分法每步只换来**一个二进制位**的精度。想把精度提高 10 位小数，就要多砍约 33 步。它稳，但不快——这就是为什么数值计算课还要教牛顿法。

</details>
