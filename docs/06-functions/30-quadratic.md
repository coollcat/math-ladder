# 二次函数与抛物线：增长开始加速

## 1. 从一个场景开始

篮球出手后划出一道弧线，喷泉的水柱在空中弯成拱门。伽利略发现：只要忽略空气阻力，一切抛体走的都是同一条曲线——**抛物线**。

直线的斜率处处相同，所以它只能"直"；上一课的双曲线确实弯了，但那是除法甩尾甩出来的弯。而 $x^2$ 的增长越来越快，图像自然越走越陡——由"加速"亲手弯出的曲线，就从这里开始。

## 2. 直觉解释：对称的 U 形

先看最简单的二次函数 $y = x^2$。算几个值：

| x | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| y | 9 | 4 | 1 | 0 | 1 | 4 | 9 |

$x=-3$ 和 $x=3$ 的函数值一样——因为平方把负号抹掉了：$(-3)^2 = 3^2$。左右完全镜像，图像是一条对称的 U 形；最低点 $(0,0)$ 叫**顶点**。

## 3. 正式定义

$$y = ax^2 + bx + c \qquad (a \neq 0)$$

| 符号 | 角色 |
| --- | --- |
| $a$ | 管开口方向（正朝上、负朝下）与胖瘦（$\lvert a \rvert$ 越大越瘦） |
| $b$ | 与 a 一起决定对称轴位置 |
| $c$ | 图像在 y 轴上的落脚点（x=0 时 y=c） |

抛物线最重要的两个坐标：

$$\text{对称轴：} x = -\frac{b}{2a} \qquad \text{顶点：} \left( -\frac{b}{2a},\; f\!\left(-\frac{b}{2a}\right) \right)$$

即：先把 $-\frac{b}{2a}$ 算出来当顶点横坐标，再代回函数求纵坐标。

## 4. 分步例题

求 $y = x^2 + 4x + 3$ 的对称轴与顶点：

1. 认系数：$a=1$，$b=4$，$c=3$；
2. 对称轴：$x = -\dfrac{4}{2 \times 1} = -2$；
3. 代回求纵坐标：$y = (-2)^2 + 4 \times (-2) + 3 = 4 - 8 + 3 = -1$；
4. 所以顶点是 $(-2, -1)$，开口向上。

自检：这条抛物线的零点是 $-1$ 和 $-3$（用第 4 章求根公式可验证），两者恰好关于 $-2$ 对称——对上了。

## 5. 动手实验

### 实验 1（viz）：拖动 b 和 c

```viz

  "title": "y = x^2 + b*x + c",
  "expr": "x^2 + b*x + c",
  "xmin": -6,
  "xmax": 6,
  "sliders": [
    { "name": "b", "min": -6, "max": 6, "step": 1, "value": 0 },
    { "name": "c", "min": -4, "max": 4, "step": 1, "value": 0 }
  ]
}
```

三个挑战：

1. 只拖 c：抛物线整体上下平移，形状不变；
2. 只拖 b：顶点沿一条向下弯的隐藏抛物线滑动——从左侧低处经过中腰，再滑到右侧低处；
3. 让顶点恰好落在 x 轴上（此时方程只有一个解），记下 b 与 c 的关系。

<details>
<summary>挑战 3 做完了吗？点开对答案</summary>

关系是 $c = \frac{b^2}{4}$：配方（见 §7 选读）可知顶点的纵坐标为 $c-\frac{b^2}{4}$，令它等于 0 就得到这个关系——比如拖到 b=2、c=1，抛物线变成 $(x+1)^2$，恰好吻在 x 轴上。

</details>

### 实验 2（python）：暴力扫描找最低点，再跟公式对质

```python title="扫描找最低点"
best_x = 0
best_y = 999999

for i in range(0, 601):
    x = -5 + i * 0.01          # 从 -5 开始，每次向右挪 0.01
    y = x * x + 4 * x + 3
    if y < best_y:             # 发现更低的点就记下来
        best_y = y
        best_x = x

print(f"扫描找到的最低点: x 约 {best_x:.2f}, y 约 {best_y:.2f}")   # :.2f 表示保留两位小数（第 5 章测量课用过）
print(f"公式给出的对称轴: x = {-4 / (2 * 1)}")
```

扫描是笨办法，公式是巧办法，两者答案一致——先暴力再相信公式，本站的老传统。

### 实验 3（viz）：预告片——顶点处坡度归零

最低点还有个隐藏特征：那里**一点坡度都没有**——左右两边都在上坡，最低点自己却是平的。下面这块组件借自第 13 章的导数课（看不懂术语没关系，会玩就行）：蓝色圆点可沿曲线拖动，绿色虚线是"贴着曲线摆的直尺"，顶部实时报出它的倾斜程度——「切线斜率」。

```viz
{
  "type": "derivative",
  "expr": "x^2 + x - 2",
  "a": 2,
  "xmin": -4,
  "xmax": 3
}
```

任务只有一个：拖着蓝点从右往左走，盯住切线斜率读数——在 $x=2$ 附近它陡峭上扬；越往左越缓和；恰好拖到 $x=-\dfrac{1}{2}$ 时读数变成 $0$，直尺放平。这个位置正是公式给出的对称轴 $-\dfrac{b}{2a}=-\dfrac{1}{2}$。"斜率为零的地方就是山顶或谷底"，第 13 章会把这句话锻造成一件大规模杀伤性武器；今天先收下这个画面。

### 快问快答

```quiz
抛物线 y = x^2 - 6x + 5 的对称轴是什么？
- x = 3 [*]
- x = -3
- x = 6
? 对称轴 x = -b/(2a)：这里 a=1、b=-6，代入得 x = -(-6)/(2*1) = 3。最容易丢的就是那个负号。
```

:::warning[常见误区]

**误区一**："对称轴是 $\frac{b}{2a}$。" 
必须带负号：$x = -\frac{b}{2a}$。本课练习专治这个手滑。

**误区二**："$-\frac{b}{2a}$ 就是顶点的 y 坐标。" 
它是顶点的**横坐标**（对称轴）；纵坐标要把它代回函数再算一遍。

**误区三**："a 只影响胖瘦。" 
a 的符号管开口方向（负则朝下），$\lvert a \rvert$ 才管胖瘦。

:::

## 6. 练习

**练习 1**：求 $y = x^2 + 4x + 3$ 的对称轴：

```exercise
# @title: 练习：抛物线的对称轴
# @check: -2
# @hint: 对称轴公式 x = -b/(2a)，其中 a=1、b=4。初始代码忘了变号；改完保持整数除法 //（如 -4 // 2）——若写成 / 会得到小数 -2.0，和期望行对不上
print(4 // 2)
```

**练习 2**：接练习 1，求这条抛物线的顶点坐标。

<details>
<summary>点开查看逐步解答</summary>

对称轴已在练习 1 求出：$x=-2$。代回：

$y = (-2)^2 + 4\times(-2) + 3 = 4 - 8 + 3 = -1$

所以顶点是 $(-2, -1)$。两步流程永远是：先 $-\frac{b}{2a}$ 定横坐标，再代回定纵坐标。
</details>

## 7. 选读：对称轴公式从哪来

<details>
<summary>选读 · 配方三步走</summary>

对 $y = x^2 + bx + c$ 配方：

$$y = \left(x + \frac{b}{2}\right)^2 + c - \frac{b^2}{4}$$

第一项 $(x+\frac{b}{2})^2$ 最小只能是 0，当且仅当 $x = -\frac{b}{2}$ 时取到。这就是对称轴 $-\frac{b}{2a}$ 在 $a=1$ 时的来历；一般情形先提出系数 a 再配方，结论同样成立。第 4 章求根公式的推导用的也是同一套配方手法。

</details>
