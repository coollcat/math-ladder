# 定点、定值与定直线

## 1. 从一个场景开始

自行车车轮的辐条有十几根，转动时每根的方向都在变，但它们全都穿过轴心——**轴心不动**。圆锥曲线的世界里也有这类"任凭参数怎么变，某个量岿然不动"的现象：动直线恒过某个定点（定点）、弦长乘积恒等于某个数（定值）、交点连线永远落在这条线上（定直线）。这一课学的不是新曲线，而是一套对付"不变量"的工作方法：**先猜后证**。

## 2. 直觉解释

"先猜后证"分两步：

- **猜**：把动直线的参数（比如斜率 $k$）换成两三个好算的特殊值，分别算出结果，找它们的公共点 / 公共值。特殊值是侦察兵，负责把答案的地形摸出来；
- **证**：带着参数 $k$ 完整算一遍，说明那个公共点 / 公共值**与 $k$ 无关**。这一步不能省——特殊位置猜出来的结论可能只是巧合。

为什么先猜是聪明的？因为带着参数硬算时你不知道终点在哪，化简容易迷路；先摸到答案，证明就变成"凑着答案走"，每一步都有靶子。这也是高考压轴题的标准打法。

## 3. 正式定义

| 目标 | 猜法 | 证法 |
| --- | --- | --- |
| 定点 | 取 $k$ 的两个特殊值，求两条特殊直线的交点 | 把直线方程整理成"含 $k$ 项 + 不含 $k$ 项"，令含 $k$ 的整体为零，解出与 $k$ 无关的点 |
| 定值 | 取特殊弦算出数值 | 用韦达定理把目标量写成参数表达式，化简后参数全部消去 |
| 定直线 | 取特殊情形看交点/交线落在哪 | 把交点坐标（用韦达表示）代入目标方程，验证恒成立 |

**取值范围与最值**：当目标量（如弦长）仍随参数变化时，把它写成参数的函数，用不等式（如均值不等式）夹出范围；**取等条件**必须指明对应的特殊情形，并检查该情形在题目允许范围内（比如斜率不存在时要单独补算）。

## 4. 分步例题

**例**：过抛物线 $y^2 = 4x$ 的焦点 $F(1, 0)$ 作斜率为 $k$ 的直线（$k \neq 0$），交抛物线于 $A(x_1, y_1)$、$B(x_2, y_2)$。证明 $x_1 x_2$ 是定值，并求弦长 $|AB|$ 的最小值。

1. **设直线**：$y = k(x - 1)$（过焦点，横截距锁定在 1）；
2. **联立**：代入 $y^2 = 4x$ 得 $k^2(x-1)^2 = 4x$，展开 $k^2 x^2 - (2k^2 + 4)x + k^2 = 0$；
3. **先猜**：$k = 1$ 时方程是 $x^2 - 6x + 1 = 0$，两根之积 $1$；$k = 2$ 时是 $4x^2 - 12x + 4 = 0$，即 $x^2 - 3x + 1 = 0$，两根之积还是 $1$。猜测：$x_1 x_2 = 1$；
4. **后证**：韦达积 $= \dfrac{k^2}{k^2} = 1$，与 $k$ 无关，**对一切 $k \neq 0$ 成立** ✓；
5. **求最值**：焦点弦有现成的焦半径公式 $|AF| = x_1 + \tfrac{p}{2} = x_1 + 1$（$p = 2$），于是 $|AB| = x_1 + x_2 + 2$。韦达和 $= \dfrac{2k^2 + 4}{k^2} = 2 + \dfrac{4}{k^2}$，所以 $|AB| = 4 + \dfrac{4}{k^2}$；
6. **夹范围**：$k^2 > 0$，故 $|AB| > 4$，但 $k$ 越大越接近 4——最小值取不到？别忘了 $k$ 不存在的情形：竖直线 $x = 1$ 与抛物线交于 $(1, \pm 2)$，$|AB| = 4$。**最小值 4 恰好由竖直弦（通径）取得**。若改用均值不等式：$x_1 + x_2 \ge 2\sqrt{x_1 x_2} = 2$，故 $|AB| \ge 4$，取等当 $x_1 = x_2 = 1$——同样是那条竖直线，两种说法在 $x_1 = x_2 = 1$ 处会师。

第 6 步是本题真正的陷阱：斜率参数化的盲区恰好在"斜率不存在"处，而最值偏偏藏在那里。

## 5. 动手实验

### 实验 1（lab）：绕着焦点转的弦

```lab
{
  "type": "see-function",
  "title": "抛物线 y² = 4x 与过焦点 F(1,0) 的动直线 y = k(x−1)",
  "funcs": ["2*sqrt(x)", "-2*sqrt(x)", "k*(x - 1)"],
  "view": [-1, 8],
  "params": { "k": 1 },
  "height": 380
}
```

拖动 $k$ 让直线绕焦点 $F(1, 0)$ 旋转：交点位置千变万化，但无论怎么转，两个交点的横坐标乘起来始终是 1——比如 $k = 1$ 时交点是 $x = 3 \pm 2\sqrt{2}$（乘积 1），$k$ 拧大时两个交点一起向 $x = 1$ 挤、弦越来越短，趋向竖直的通径（长 4）。

### 实验 2（python）：把乘积盯死在 1

```python title="扫一圈斜率，看 x1·x2 动不动"
for k in [0.5, 1, 2, 4, 10]:         # 五个不同的斜率
    # 联立 k²(x-1)² = 4x，整理得 k²x² - (2k²+4)x + k² = 0
    a = k * k                        # 二次项系数
    b = -(2 * k * k + 4)             # 一次项系数
    c = k * k                        # 常数项
    s = -b / a                       # 韦达和 x1 + x2
    p = c / a                        # 韦达积 x1 * x2
    ab = s + 2                       # 焦点弦长 |AB| = x1 + x2 + 2（p/2 = 1）
    print(f"k={k}: x1+x2={round(s, 2)}, x1*x2={p}, |AB|={round(ab, 2)}")

print("竖直弦 x=1: 交点 (1,2) 与 (1,-2), |AB|=4  ← 最短")
```

五行报告里 $x_1 x_2$ 一列纹丝不动全是 1——定值当场坐实；而 $|AB|$ 随 $k$ 增大一路滑向 4，却永远差一点：最小值 4 藏在"斜率不存在"的竖直弦里，参数化扫不到它，必须单独补算。

用两个特殊斜率算出弦长都是 8，能不能直接把"弦长恒为 8"写进最终答案？

::::warning[常见误区]

**误区一**："你以为特殊值算出来的就是答案。" 两个特殊值恰好重合也可能纯属巧合（比如恰好都落在对称位置）。猜完必须带参数一般证明——猜是罗盘，证才是路。

**误区二**："你以为 $y = k(x-1)$ 已经覆盖了所有过焦点的直线。" 它漏掉了竖直线 $x = 1$（$k$ 不存在）。最值问题里这个漏掉的成员常常正是取得最值的那个，必须补算。

**误区三**："你以为 $\Delta$ 不用管。" 定值证明默认弦存在，即 $\Delta > 0$；本题中 $\Delta = (2k^2+4)^2 - 4k^4 = 16k^2 + 16 > 0$ 恒成立，但别的题未必——证明里带一句 $\Delta$ 检查，才站得住。

::::

## 6. 练习

**练习 1**：动直线 $y = k(x - 2) + 3$（$k$ 取遍一切实数）恒过一个定点，求定点坐标。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：两条特殊线夹出定点
# @check: 2
# @check: 3
# @hint: 分别取 k=0 和 k=1 写出两条直线再联立：k=0 时 y=3；k=1 时 y=x+1。初始代码把 y = k(x−2)+3 展开时符号抄错了，注意是 −2k 加 3。
# k = 0 的特殊直线：y = k(x-2) + 3
k0 = 0
y0 = k0 * 2 - 2 * k0 - 3             # ← 展开 k(x−2)+3 时，常数项 +3 抄成了 −3？

# k = 1 的特殊直线：y = k1*x + b1
k1 = 1
b1 = -2 * k1 - 3                     # ← 常数项符号再查一遍

x = (y0 - b1) / (k1 - k0)            # 两条特殊直线都是 y = kx + b，联立解交点
y = k1 * x + b1

print(round(x))
print(round(y))
```

<details>
<summary>点开查看逐步解答</summary>

1. $k = 0$：$y = 3$（水平线）；$k = 1$：$y = x + 1$。联立 $3 = x + 1$ 得 $x = 2$，交点 $(2, 3)$——这就是候选定点；
2. **验证**（先猜后证的"证"）：$y = k(x-2) + 3 = kx + (3 - 2k)$，把 $(2, 3)$ 代入：右边 $= 2k + 3 - 2k = 3$ ✓，与 $k$ 无关，恒过 $(2, 3)$；
3. 初始代码把常数项抄成了 $-3$：$k = 0$ 的直线变成 $y = -3$、$k = 1$ 变成 $y = x - 5$，解出的是 $(2, -3)$——两条"特殊直线"本身就错了。

修正后输出的两行是 `2` 与 `3` ✓。定点问题的通用套路：**把方程整理成 $k \cdot(\cdots) + (\cdots) = 0$ 的形式，令含 $k$ 的括号整体为零**——这里 $y - 3 - k(x - 2) = 0$，令 $x - 2 = 0$ 且 $y - 3 = 0$，一步到位。

</details>

**练习 2**：沿用例题（焦点弦 $y = k(x-1)$ 与 $y^2 = 4x$），证明 $y_1 y_2 = -4$ 也是定值。

<details>
<summary>点开查看逐步解答</summary>

$y_1 = k(x_1 - 1)$，$y_2 = k(x_2 - 1)$，相乘：$y_1 y_2 = k^2 (x_1 x_2 - (x_1 + x_2) + 1)$。代入韦达：$x_1 x_2 = 1$，$x_1 + x_2 = 2 + \dfrac{4}{k^2}$，于是 $y_1 y_2 = k^2\left(1 - 2 - \dfrac{4}{k^2} + 1\right) = k^2 \cdot \left(-\dfrac{4}{k^2}\right) = -4$。与 $k$ 无关 ✓。一般地，$y^2 = 2px$ 的焦点弦恒有 $x_1 x_2 = \tfrac{p^2}{4}$、$y_1 y_2 = -p^2$，本题 $p = 2$。
</details>

## 7. 边界与适用条件

"先猜后证"的猜，只负责指路；没有一般证明的定点结论不能写进解答。用 $y = k(x - x_0) + y_0$ 设线时天然漏掉竖直线，涉及最值或"所有直线"的结论必须补算 $k$ 不存在的情形。定值的证明要交代 $\Delta > 0$（弦存在）。均值不等式夹范围时，取等条件对应的参数必须真的可取（本题取等在竖直线，需单独核验）。

## 8. 选读：抛物线焦点弦的"套餐"性质

<details>
<summary>选读 · 一根过焦点的弦，附赠多少定值</summary>

对 $y^2 = 2px$（$p > 0$）的焦点弦 $AB$（斜率存在时），韦达套餐一口气给出：

- $x_1 x_2 = \dfrac{p^2}{4}$（定值）；
- $y_1 y_2 = -p^2$（定值）；
- $\dfrac{1}{|AF|} + \dfrac{1}{|BF|} = \dfrac{2}{p}$（定值，焦半径倒数和）。以 $|AF| = x_1 + \tfrac{p}{2}$ 验证：$\dfrac{1}{x_1 + p/2} + \dfrac{1}{x_2 + p/2} = \dfrac{x_1 + x_2 + p}{x_1 x_2 + \tfrac{p}{2}(x_1+x_2) + \tfrac{p^2}{4}}$，代入 $x_1 x_2 = \tfrac{p^2}{4}$ 后分母化为 $\tfrac{p}{2}(x_1 + x_2) + \tfrac{p^2}{2} = \tfrac{p}{2}(x_1 + x_2 + p)$，与分子相除恰得 $\dfrac{2}{p}$ ✓。

所有这些"不变"都源自同一件事：直线过定点（焦点），联立后的方程系数被参数 $k$ 以特定方式牵制。反过来，"以 $AB$ 为直径的圆与其准线相切"这类定直线型结论，把韦达套餐代入圆心与半径就能验出来——工具还是那一套。
</details>
