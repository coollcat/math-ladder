# 绝对值方程与不等式：数轴上的距离

## 1. 从一个场景开始

车间里加工一批轴，图纸上写着：直径 20 毫米，误差不超过 0.5 毫米都算合格。验收员拿起卡尺，从不问"大还是小"——19.6 合格，20.4 也合格，19.2 报废。他只关心一件事：**离标准值多远**。

"距离不超过 0.5"翻译成数学，就是本课的主角 $\lvert x - 20\rvert \le 0.5$。绝对值当数字用我们早就会了（[函数是机器](./10-machine.md) 里 abs 生日那天说过：距离不分方向）；今天让它装着**未知数**上岗——绝对值方程与不等式，一套只用"距离"就能全部讲通的解法。

## 2. 直觉解释

把 $\lvert x - 2\rvert = 3$ 大声读出来："**x 到 2 的距离等于 3**"。

不用任何技巧，拿数轴走一遍：从 2 出发，距离它 3 步的地方有几个？向右 3 步到 5，向左 3 步到 $-1$——**恰好两个点**，所以方程恰好两个解。距离不分方向，解就成对出现，一边一个。

不等式同理："到 2 的距离小于 3"就是住在以 2 为中心、左右各 3 步的**线段内部**——从 $-1$ 到 5 之间的一切数。你已经在脑子里解完了一整章的题。

## 3. 正式定义

对中心 $a$ 与距离 $b$（$b > 0$）：

$$\lvert x - a\rvert = b \iff x - a = b \ \text{或}\ x - a = -b$$

| 形态 | 式子 | 解集 | 口诀 |
| --- | --- | --- | --- |
| 方程 | $\lvert x - a\rvert = b$ | $x = a - b$ 或 $x = a + b$ | 两头各一站 |
| 小于 | $\lvert x - a\rvert < b$ | $a - b < x < a + b$ | 夹在中间 |
| 大于 | $\lvert x - a\rvert > b$ | $x < a - b$ 或 $x > a + b$ | 奔向两头 |

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a$ | 中心 | "离**谁**的距离"里的那个谁 |
| $b$ | 距离 | "多远"，永远非负 |

三行口诀同根同源：绝对值抹掉正负号，于是"里面等于 $+b$"和"里面等于 $-b$"两条路都得查。小于取两条路**之间**，大于取两条路**之外**。

边界说明书：$b = 0$ 时方程只剩唯一解 $x = a$（到 a 距离为 0 的只有它自己）；$b < 0$ 时方程与小于型不等式**无解**——距离永远不为负（[函数是机器](./10-machine.md) 误区一的化身）。

## 4. 分步例题

**例 1**：解 $\lvert x - 2\rvert = 3$。

1. 认中心与距离：$a = 2$，$b = 3$；
2. 右站：$x = 2 + 3 = 5$；
3. 左站：$x = 2 - 3 = -1$；
4. 验算：$\lvert 5 - 2\rvert = 3$ ✓，$\lvert -1 - 2\rvert = \lvert -3\rvert = 3$ ✓——两个解都站得住。

**例 2**：解 $\lvert x + 1\rvert = 4$。

1. 先认中心：$x + 1 = x - (-1)$，中心是 $-1$ 不是 $1$——**加号背后藏着负中心**；
2. 两解：$x = -1 + 4 = 3$ 或 $x = -1 - 4 = -5$；
3. 验算：$\lvert 3 + 1\rvert = 4$ ✓，$\lvert -5 + 1\rvert = \lvert -4\rvert = 4$ ✓。

**例 3**：解 $\lvert x - 2\rvert < 3$，并把解集说成一句话。

1. 套"夹在中间"：$2 - 3 < x < 2 + 3$；
2. 即 $-1 < x < 5$；
3. 一句话：到 2 的距离小于 3 的点，是数轴上从 $-1$ 到 5 的**开区间**——两端 $-1$ 和 5 距离恰好 3，不算数。

## 5. 动手实验

### 实验 1（viz）：V 形山谷与警戒线

把距离画出来：蓝色 V 形是 $\lvert x - a\rvert$（谷底在中心 a），橙色水平线是警戒距离 $b$。**交点就是方程的解**，蓝线钻到橙线下方的地段就是 $\lvert x - a\rvert < b$ 的解区间：

```viz
{
  "type": "plot",
  "title": "y = |x-a| 与警戒线 y = b：交点就是解",
  "expr": "abs(x - a)",
  "label": "y = |x-a|",
  "expr2": "b",
  "label2": "y = b",
  "xmin": -8,
  "xmax": 8,
  "sliders": [
    { "name": "a", "min": -4, "max": 4, "step": 1, "value": 2 },
    { "name": "b", "min": 0, "max": 6, "step": 0.5, "value": 3 }
  ]
}
```

四个挑战：

1. 拖 a：V 形谷底整体平移，两个交点跟着跑——中心只管"在哪"，不管"多宽"；
2. 拖 b：水平线升降，两交点分开或靠拢——距离只管"多宽"；
3. 把 b 拖到 0：两个交点合并进谷底——方程唯一解的边界时刻；
4. 找出蓝线低于橙线的那一段：它的左右端点正是 $a - b$ 与 $a + b$。

### 实验 2（python）：滑块扫描，整数解自己报到

```python title="扫描 |x - a| = b 的整数解"
# sliders: a=2 [-4:4:1], b=3 [0:5:1]

for x in range(-10, 11):     # 让 x 从 -10 走到 10，逐个试
    if abs(x - a) == b:      # 距离恰好等于 b 的落点就是解
        print(x)
```

默认 $a=2$、$b=3$ 时打出 $-1$ 和 5，与例 1 逐字对上。拖动滑块：$b$ 归零只剩一个解；$a$ 挪到负数地盘，两解整体搬家——"中心加距离、中心减距离"的口诀在每一次拖动里都兑现。

### 实验 3（python）：把解区间涂上颜色

```python title="阴影地带就是 |x-2| < 3 的解区间"
import matplotlib.pyplot as plt   # 画图库（第 0 章引入）

xs = []      # 横坐标收集列表
ys = []      # 纵坐标：每个 x 处的距离
band = []    # 布尔标记：该点是否落在解区间

for i in range(121):
    x = -6 + i * 0.1
    xs.append(x)
    ys.append(abs(x - 2))
    band.append(abs(x - 2) < 3)   # 比较结果是 True 或 False

plt.plot(xs, ys, linewidth=2.5, label="y = |x-2|")
plt.axhline(3, color="darkorange", linestyle="--", label="y = 3")
plt.fill_between(xs, ys, 3, where=band, color="lightgreen", alpha=0.6)   # fill_between 首现：把两条线之间涂色；where= 只涂标记为 True 的段；alpha= 透明度
plt.legend()
plt.grid(True)
```

绿色阴影恰好铺在 $-1 < x < 5$ 上方——例 3 的解集从一行式子变成了看得见的地皮。把 `2` 改成别的中心、`3` 改成别的距离再跑一遍，阴影随迁。

### 快问快答

```quiz
解方程 |x - 2| = 3，x 的两个解是？
- 5 和 1
- 5 和 -1 [*]
- 5 和 -5
? 距离等于 3 的点在中心 2 两侧各一个：2+3=5 与 2-3=-1。漏掉负解是本课头号陷阱——距离不分方向，解就成对出现。
```

::::warning[常见误区]

**误区一**："$\lvert x - 2\rvert = 3$ 只有一个解 $x = 5$。" 绝对值抹掉正负号：里面的数可以是 3，也可以是 $-3$。两个都要查，漏一个就丢一半分——数轴上距离 2 恰好 3 步的点本来就有两个。

**误区二**："$\lvert x + 1\rvert = 4$ 的中心是 1。" 加号背后藏着负号：$x + 1 = x - (-1)$，中心是 $-1$。先化成"减法脸"再认中心，两解是 3 和 $-5$。

**误区三**："$\lvert x - 2\rvert < 3$ 的解是 $x < 5$。" 只报上界等于把下界弄丢了。"小于夹中间"：$-1 < x < 5$。数轴上一画就现形——距离小的点不可能单边分布。

::::

**练习 2**：解 $\lvert x + 4\rvert = 1$，并解释为什么中心是 $-4$。

<details>
<summary>点开查看逐步解答</summary>

先化成减法脸：$x + 4 = x - (-4)$，中心是 $-4$，距离 1。

两解：$x = -4 + 1 = -3$ 或 $x = -4 - 1 = -5$。

验算：$\lvert -3 + 4\rvert = 1$ ✓，$\lvert -5 + 4\rvert = \lvert -1\rvert = 1$ ✓。用代码逐个验收：

```python
print(abs(-3 + 4))
print(abs(-5 + 4))
```
</details>

**练习 3**：车床图纸要求直径 20 毫米、误差不超过 0.5 毫米。写出"合格"的绝对值不等式，并给出合格的直径范围。

<details>
<summary>点开查看逐步解答</summary>

合格 = 到 20 的距离不超过 0.5：$\lvert x - 20\rvert \le 0.5$。

套"夹在中间"（把小于换成小于等于，两端算数）：$19.5 \le x \le 20.5$。

回头对照场景：19.6 与 20.4 都在范围内（合格），19.2 出界（报废）——开场那位验收员的卡尺，原来一直在解绝对值不等式。
</details>

## 7. 选读：|x| 的分段身份证

<details>
<summary>选读 · 分段函数的正式记号</summary>

abs 生日那天（[函数是机器](./10-machine.md) 例 1），我们用 if/else 手工造过它。"分段"如今可以写成正式的数学记号——按 x 的取值范围分两行报账：

| 取值范围 | $\lvert x\rvert$ 的值 |
| --- | --- |
| $x \ge 0$ | $x$ |
| $x < 0$ | $-x$ |

这样的"按段给公式"的对象叫**分段函数**：一台机身装了两套加工规则，输入落在哪一段，就按哪一套干活。它与手工版 `my_abs` 的 if/else 一一对应：条件就是"段落边界"，两个分支就是两行公式。解 $\lvert x - 2\rvert = 3$ 时"里面的数等于 $\pm 3$"两条路，正是这两套规则各自的账。第 6 章 35 课聊图像变换时它还会客串一次——对分段函数做横向缩放，伪装就会当众拆穿。
</details>
