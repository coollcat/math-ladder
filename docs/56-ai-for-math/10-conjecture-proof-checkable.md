# 猜想、证明与可检验性

## 1. 从一个场景开始

1742 年，哥德巴赫在给欧拉的信里猜：任何大于 2 的偶数都能写成两个素数之和。近三百年过去，人类验证了 $4\times10^{18}$ 以内的所有偶数——**一个反例都没有**。可它至今仍是"猜想"，不是"定理"。

AI 时代这个问题变得尖锐：机器一天能验证的偶数比人类三百年还多，那它算"解决"了吗？答案是否定的，而理由恰恰是数学最迷人的结构：**无限面前，再多抽查也是零**。这一课把"猜想—证明—反例"三种状态的边界画清楚——它是理解 AI for Math 的地基。

## 2. 直觉解释

把全称命题想成一副无穷多的牌：

- **猜想** = 押注"每张都是红桃"。翻开一万张全中（数值实验），赌注更有底气，但下一张仍可能是黑桃；
- **反例** = 一张黑桃。只需一张，命题当场毙命——**证伪比证实便宜得多**；
- **证明** = 一台"永远不出黑桃"的机器：从公理出发、每步合法，逼着结论对整副牌成立。

机器擅长什么？翻牌速度（穷举验证）和造机器的手艺（形式化证明）。机器暂时不擅长什么？判断哪副牌值得押注——虽然这一点正在被改写（本章第 40 课）。

## 3. 正式定义

| 对象 | 定义 | 判定方式 |
| --- | --- | --- |
| 命题 $\varphi$ | 有明确真值的陈述；能否机械判定取决于语言和论域 | —— |
| 全称命题 $\forall n\,P(n)$ | 断言每个 $n$ 都满足 $P$ | 需要证明才能确立 |
| 反例 | 使 $P(n_0)$ 为假的具体 $n_0$ | 一个即推翻原命题 |
| 数值证据 | 满足 $P$ 的有限样本集合 | 支持信念，不改变真值 |

关键区分藏在**可检验性**里：

$$\text{有限域上的} \forall \text{命题可以穷举验证；无限域上只能靠证明。}$$

一个命题被验证一亿次和零次，其"已证状态"完全相同——这就是为什么哥德巴赫的 $4\times10^{18}$ 个成功案例在逻辑上价值为零。

## 4. 分步例题

一个被计算机亲手击毙的猜想：欧拉在 1769 年猜测——至少需要 $n$ 个 $n$ 次幂之和才能凑出一次 $n$ 次幂（费马大定理的高维推广）。对 $n=5$，即"四个五次幂之和不可能等于一个五次幂"。

1. 两百年间无人找到反例，猜想一度深信不疑；
2. 1966 年，Lander 与 Parkin 用计算机搜索到：

$$27^5 + 84^5 + 110^5 + 133^5 = 144^5$$

3. 左边是个 11 位数——不必背数字，下一节让 Python 替你逐位验算；
4. 猜想当场死亡，且死因无可辩驳：等式两边逐位相等；
5. 教训：**抽查两百年 < 一次精确反例**。数值证据的置信度再高，也不跨进"已证"的门。

## 5. 动手实验

### 热身：先看见“素数零件”

```viz
{"type":"sieve"}
```

筛子给出的只是有限范围内的素数表。它很适合当验证机的零件，但“100 以内没有反例”仍然不等于“所有偶数都能写成两个素数之和”。

### 实验 1：当一回反例猎手的公证员

```python title="验算欧拉猜想的著名反例"
lhs = 27 ** 5 + 84 ** 5 + 110 ** 5 + 133 ** 5   # ** 幂运算：整数精确计算
rhs = 144 ** 5
print(lhs)
print(rhs)
print("等式成立:", lhs == rhs)

# 对照组：换一组随机五次幂就凑不出来（感受这个等式多罕见）
a, b, c, d, e = 28, 85, 111, 134, 144
print("对照组:", a ** 5 + b ** 5 + c ** 5 + d ** 5 == e ** 5)
```

大整数运算是 Python 的母语，逐位精确——这正是机器适合当"反例公证员"的原因。

### 实验 2：亲手跑一遍"有限验证机"

```python title="哥德巴赫抽查机：50 以内的全部偶数"
def is_prime(m):
    # 试除法：从 2 找到 m-1，遇到因数就不是素数
    result = True
    for d in range(2, m):
        if m % d == 0:
            result = False
            break                       # break：提前跳出循环（找到一个因数就够了）
    return result

success = 0
fail_case = None                        # None 表示"还没有"
for even in range(4, 51, 2):            # 步长 2：只访问偶数
    found = False
    for p in range(2, even // 2 + 1):   # 只需搜到一半
        if is_prime(p) and is_prime(even - p):
            found = True
            break
    if found:
        success += 1                    # 复合赋值：计数器加一
    else:
        fail_case = even

print(f"50 以内验证通过 {success} 个偶数")
print(f"反例: {fail_case}")
```

24 个偶数全部通过，`fail_case` 保持 `None`。把上限改成 5000 再跑依然全绿——然后提醒自己：这与"证明了"的距离，恰好是 $5000$ 与 $\infty$ 的距离。

### 实验 3：判题小练兵

```exercise
# @title: 练习：修好素数检查器
# @check: True
# @check: False
# @hint: 一旦找到因数，结论应当翻转成“不是素数”，别忘了 break 的搭档是谁。
def is_prime(m):
    result = True
    for d in range(2, m):
        if m % d == 0:
            result = True               # ← 问题在这：找到因数后结论写反了
            break
    return result

print(is_prime(7))
print(is_prime(9))
```

修好之后 `is_prime(9)` 会正确返回 False：9 在 d=3 时被抓现行。这个十行小函数就是实验 2 的发动机——**自动化的前提是零件可靠**。

```quiz
机器检查了某个无限全称命题的前十亿个例子，而且全部通过。这能证明什么？
- 这个命题已经被证明了
- 只能得到“前十亿个例子成立”这条有限事实 [*]
- 只要例子足够多，就等价于数学归纳法
? 全称命题的论域通常没有上界。有限抽查可以增强信心、提供模式，但证明必须覆盖所有情况；归纳法的核心是归纳步，不是例子多。
```

## 常见误区

:::warning[常见误区]

**误区一**："验证了这么多例，差不多算证明了。"
数学里没有"差一点证明"。欧拉猜想活了两百年、扛过无数次人工抽查，死于一次精确计算。数值实验提供的是信心与线索，不是真值。

**误区二**："有反例的猜想毫无价值。"
反例本身就是知识：它划出了定理成立的边界。费马大定理对 $n=4$ 成立、欧拉猜想对 $n=3$ 成立——"在哪里断掉"往往比"断掉了"更有信息量。

**误区三**："AI 说得像证明，那就是证明。"
语言模型的自然语言推理可能藏着跳步甚至幻觉（本章后续课程专门剖析）。在数学语境里，只有通过形式化校验的推理链才有资格叫证明——这正是下一课的主角。

:::

## 6. 练习

**练习 1**：手写验证：$n^2$ 等于前 $n$ 个奇数之和，对 $n=1..6$ 各打印一行验证结果。

<details>
<summary>点开查看逐步解答</summary>

```python
for n in range(1, 7):
    total = sum(range(1, 2 * n, 2))   # 奇数 1,3,...,2n-1
    print(total == n * n)
```

六行全 True。它依然是有限验证——一般情形的证明要用归纳法（第 8 章），而"机器发现模式 → 人给出归纳证明"正是 AI for Math 最经典的分工。
</details>

**练习 2**：改造实验 2：统计每个偶数的表示方法数，找出"表示法最少"的偶数。

<details>
<summary>点开查看逐步解答</summary>

把内层的 `found/break` 改成 `count += 1` 并继续循环，外层用两个变量记录最小值及其主人（不要用 min 函数也行，手动比较更清楚）。50 以内冠军通常是 6 和 10 这类小偶数——表示法数量大致随偶数增大而增多，这正是哥德巴赫"看起来越来越稳"的统计学侧影。
</details>

**练习 3**：概念辨析：为什么"机器穷举到 $4\times10^{18}$"在新闻里常被写成"接近证明"？错在哪？

<details>
<summary>点开查看逐步解答</summary>

错在量级感：$4\times10^{18}$ 听起来浩大，但相对全体偶数占比为零——第一个未验证区间 $(4\times10^{18}, 4\times10^{18}+2)$ 就足以藏下反例。"接近"是心理印象不是逻辑范畴；逻辑上只有 0 和 1。这类措辞混淆了**归纳信心**与**演绎确定性**，恰是本课要钉死的分界线。
</details>

## 7. 选读：机器证明的两条路线

<details>
<summary>选读 · 判定 vs 搜索</summary>

历史上机器介入数学有两条路。**判定路**：四色定理（1976，Appel–Haken）把 1936 种构形逐一交给程序验证，人负责归约策略——争议在于"没人读得完"；2005 年前后该证明被完整搬进证明助手 Coq，争议才大幅平息。**搜索路**：罗宾斯代数公理的等式证明由 EQP/Otter 程序在 1996 年自动搜出，连人类此前都不知道这么短的证明存在。两条路的共同底座是同一个事实：**每一步是否合法，是可以机械判定的**——这是下一课的全部起点。
</details>
