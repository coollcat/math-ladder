# 猜想生成机

## 1. 从一个场景开始

拉马努金留给后世数千条公式，很多他自己也给不出证明——他说那是女神在梦中写给他的。2021 年，一群以色列研究者决定把"做梦"工程化：他们提出一套算法，专门扫描连分数结构里与 $\pi$、e 等常数高度吻合的候选公式，然后把筛出来的等式公之于众，号召人类来证明。论文发表在 Nature，项目名字就叫**拉马努金机**（Raayoni 等，Nature 590, 67–73, 2021）。

它找到的若干猜想后来真的被证明了，另一些至今悬而未决。这一课拆解这台机器的流水线——也是整个 AI for Math 的终极分工图：**机器负责"发现规律"，人负责"为什么"。**

## 2. 直觉解释

生成猜想的流水线只有四站：

1. **造候选**：按某个参数化模板批量生产表达式（比如连分数、多项式、递推数列）；
2. **数值匹配**：算出候选的值与目标常数的距离，距离小于阈值者晋级；
3. **高精度复核**：用几百位精度重算一遍，排除浮点巧合（巧合概率随精度要求指数下降）；
4. **移交人类**：贴上"猜想"标签，等待证明或反例。

关键在第 3 站：若把每一位小数近似看作独立比较，每多锁定一位，巧合概率约降到原来的十分之一；前 100 位仍吻合的候选就极其罕见。但“极其罕见”仍是概率语言，不是证明。**精度提高置信度，不改变真值**——这是实验数学的第一定价原则。

## 3. 正式定义

一个数值猜想的标准形态：

$$\left| \text{目标常数} - \text{候选表达式} \right| < \varepsilon \quad \text{时立案：猜测二者相等，等待证明或反例}$$

其中 $\varepsilon$ 是远小于机器精度的门槛。

| 概念 | 含义 |
| --- | --- |
| 连分数 | 形如 $a_0 + \frac{b_1}{a_1 + \frac{b_2}{a_2+\cdots}}$ 的嵌套表达，收敛极快 |
| 渐近分式 | 用有限截断逼近连分数所得的有理数 |
| 反例搜索 | 对猜想论域做系统扫描，专找不成立的那一项 |

猜想与定理的地位差异必须钉死：**未经证明，它不能被引用为依据**；但它可以合法地充当路标、灵感与检验其他理论的试金石。

## 4. 分步例题

手工复刻一次微型"猜想机"流程：目标是给 $\pi \approx 3.14159$ 找一个小分母的有理数近似。

1. 定模板：所有分数 $p/q$，$q \le 7$；
2. 扫描：$22/7 = 3.142857$，误差约 $0.00126$；
3. 对照：同范围内没有更近者——$3/1$ 误差 0.14，$25/8$ 超出 $q\le7$……
4. 升级预算：放宽到 $q \le 113$，冠军变成 $355/113 = 3.14159292$，误差骤降到 $3\times10^{-7}$；
5. 这两个渐近分式正是 $\pi$ 的连分数展开的前几站——**扫描器什么都没"懂"，但它把数学史上最著名的两个近似原样捡了回来。**

## 5. 动手实验

### 实验 1：给 e 当一回猜想猎手

```python title="扫描最佳有理近似：q ≤ 113 的 π 与 q ≤ 10 的 e"
E = 2.718281828459045     # 自然常数（题目方）
PI = 3.141592653589793    # 目标常数一：圆周率

best_p, best_q, best_err = 0, 0, 1e9      # 1e9 即 10^9：初始"最差纪录"
for q in range(1, 11):
    for p in range(1, 31):
        err = abs(p / q - E)
        if err < best_err:                # 打破纪录才更新
            best_p, best_q, best_err = p, q, err

print(f"e 的最佳近似: {best_p}/{best_q}")
print(f"误差: {round(best_err, 3)}")

# 放宽预算扫 π：q 到 113、p 到 400
bp, bq, be = 0, 0, 1e9
for q in range(1, 114):
    for p in range(1, 401):
        err = abs(p / q - PI)
        if err < be:
            bp, bq, be = p, q, err

print(f"pi 的最佳近似: {bp}/{bq}（误差 {be:.0e}）")
```

第二段会打印 355/113——数学史的名场面由两层循环复现。注意 19/7、355/113 都是连分数渐近分式：**暴力扫描与优雅理论殊途同归**，这正是拉马努金机的哲学。

### 实验 2：从数据里"提炼"一条定理级模式

```viz

  "kind": "arith",
  "a1": 1,
  "d": 2,
  "n": 8

```

柱子依次是奇数 1、3、5、7……把 $n$ 从小到大拨，顶部 $S_n$（前 n 项和）的读数一路报出 1、4、9、16——每一项都是完全平方数！用代码确认并记录这条"机器可发现的定理"：

```python title="验证前 n 个奇数之和 = n^2"
for n in range(1, 7):
    total = 0
    odd = 1
    for k in range(n):
        total += odd          # 累加当前奇数
        odd += 2              # 跳到下一个奇数
    print(total == n * n)
```

六行 True。归纳证明只需一步代数（第 8 章），但**注意到这个模式本身就是发现**——刚才的 seq 组件替你看了第一眼，代码替你盖了章。机器做这两件事都不费力，难的是拉马努金式的下一步：猜出它为什么对、以及它通向哪里。

## 常见误区

:::warning[常见误区]

**误区一**："机器给的公式精度这么高，肯定对。"
精度只能排除"普通巧合"，排除不了"精心构造的伪关系"。历史上确有仅在小数点后几十位吻合、第 60 位露馅的候选。猜想机器的产出必须走完形式化流程才算数。

**误区二**："猜想会泛滥，数学家要失业了。"
相反，猜想越多，**品味与筛选能力越稀缺**。拉马努金机的作者明确说他们的目标是给人类提供线索；后续 PNAS 论文（2024）甚至靠这些机器猜想发现了常数之间的新结构（保守矩阵场）。工具放大的是提问能力。

**误区三**："猜想生成与定理证明是两条平行线。"
它们正在闭环：生成的猜想喂给证明搜索器，证出来的定理反过来校准生成器的模板。本章四课连起来正是这个完整回路——可检验性 → 检查器 → 引导搜索 → 猜想供给。

:::

## 7. 选读：连分数为什么收敛这么快

<details>
<summary>选读 · 渐近分式的误差界</summary>

实数的连分数展开由不断取倒数余项生成；第 $k$ 个渐近分式 $p_k/q_k$ 满足 $|x - p_k/q_k| < 1/(q_k q_{k+1})$。由于分母增长极快（斐波那契级别），误差呈指数坍缩——这就是 355/113 能以三位分母拿到六位精度的原因。拉马努金机的 meet-in-the-middle 算法正是在这族分母上做双向匹配，把指数空间砍成平方根规模。数学结构（快收敛）与算法结构（MITM）咬合之处，恰是好工具诞生之地。
</details>
