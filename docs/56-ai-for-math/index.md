## 实战挑战 · 给猜想机器当审查员

2024 年 1 月，DeepMind 的 AlphaGeometry 登上 Nature：在汇集 2000–2022 年国际数学奥林匹克几何题的基准 IMO-AG-30 上，它在比赛时限内解出 25 题——此前最好的系统只能解出 10 题（Trinh 等，Nature 625, 2024）。2021 年，"拉马努金机"团队也在 Nature 发文：算法批量生成关于 π、e 的连分数猜想，其中一些后来被人类证明，另一些至今悬而未决（Raayoni 等，Nature 590, 2021）。

机器的两份产出都需要审查员。**第一份是猜想**："对所有非负整数 n，n² + n + 41 都是素数。"这是欧拉 1772 年记录的著名多项式——请当反例猎手：写一个试除判合数的函数，从 n = 0 开始逐个检查，找出第一个让多项式变成合数的 n，并打印那个合数。初始代码只扫到 40 个数就收工了。**第二份来自证明机器**，请回答下面的选择题。

```exercise
# @title: 实战挑战：抓住欧拉多项式的第一个反例
# @check: 40
# @check: 1681
# @hint: 反例藏在第 41 个检查点；1681 是哪个数的平方？把扫描上限扩大一格就能抓到。
def is_composite(m):
    d = 2
    while d * d <= m:        # 试除只需做到平方根
        if m % d == 0:
            return True      # 找到因数：是合数
        d += 1
    return False

found_n = None
value = None
for n in range(40):          # ← 问题在这：只扫了 0..39，范围太小
    poly = n * n + n + 41
    if is_composite(poly):
        found_n = n
        value = poly
        break

if found_n is None:
    print("未发现反例，猜想暂且成立")
else:
    print(found_n)
    print(value)
```

```quiz
AlphaGeometry 解几何题时，语言模型负责哪一段？
- 逐步执行严格的符号演绎
- 提议值得尝试的辅助构造点，严格演绎交给符号引擎 [*]
- 替人类裁判给证明打分
? 它是"直觉引擎"：语言模型提议辅助点，符号引擎保证每步合法。论文的消融实验显示抽掉任何一半，成绩都断崖式下跌。
```

<details>
<summary>点开查看逐步解答</summary>

把 `range(40)` 改成 `range(41)`（或更大），程序会立刻抓到 **n = 40**：

$$40^2 + 40 + 41 = 1600 + 81 = 1681 = 41^2$$

它恰好是 41 的平方——欧拉多项式对 n = 0..39 连续给出 40 个素数，然后在自家门口翻车。这个案例浓缩了本章第 10 课的全部要点：40 次成功（再多四十倍也一样）不能确立全称命题，而一个精确反例足以终结猜想。至于拉马努金机的产出，同样要经过这道"可检验性"的门：数值吻合只是立案，证明或反例才是结案。
</details>

深入原理：[猜想、证明与可检验性](./10-conjecture-proof-checkable.md)（为什么抽查不算证明）、[猜想生成机](./40-conjecture-generation-machine.md)（数值猜想的流水线）。

## 实战挑战 · 数值验证猜想：前 n 个奇数之和

猜想的数值验证是"AI for Math"的第一步：先拿计算机验算，再谈证明。猜想"前 $n$ 个奇数之和等于 $n^2$"，验证 $n=5$ 时 $1+3+5+7+9=25=5^2$。下面这题生成奇数时漏了减一，修到输出 `True`：

```exercise
# @title: 实战挑战：数值验证猜想
# @check: True
# @hint: 第 k 个奇数是 2k−1，别漏掉那个 −1。
n = 5
total = 0
for k in range(1, n + 1):
    total = total + 2 * k        # ← 问题在这：第 k 个奇数应为 2k−1
print(total == n * n)
```

<details>
<summary>点开查看逐步解答</summary>

第 $k$ 个奇数是 $2k-1$：

```python
total = total + (2 * k - 1)    # 1、3、5、7、9
print(total == n * n)          # 25 == 25 → True
```

改完：$1+3+5+7+9=25=5^2$，猜想通过验证。初始代码累加偶数 $2+4+6+8+10=30$，与 $25$ 不符。数值验证能快速筛掉错误猜想、给正确猜想壮胆，但它**不是证明**——$n=5$ 成立不代表所有 $n$ 成立，这就是"抽查不算证明"这一课的出发点。

</details>
