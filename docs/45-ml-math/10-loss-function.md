# 损失函数与经验风险

## 1. 从一个场景开始

你造了个房价估价模型。它给一套房报价 300 万，真实成交价 290 万——差了 10 万。这个"差 10 万"该记多少分的过？

- 差得多记重罚、差得少记轻罚？——需要一条**计分规则**；
- 全部房源的平均分才说明模型整体水平？——需要一个**总分**。

计分规则就是**损失函数**，平均分就是**经验风险**。第 41 章把"最小化经验风险"立为学习的正式目标；这一课我们亲手把目标函数写出来——因为**优化什么，决定学到什么**。

## 2. 直觉解释

把模型想象成打靶的射手，每次预测是一发子弹，靶心是真实值。计分规则至少两种：

- **绝对损失**：离靶心几环就扣几分——线性记账，公平冷淡；
- **平方损失**：偏差先平方再记——错得越远罚单越狠（差 2 倍罚 4 倍），对"离谱失误"零容忍。

两种规则塑造出两种射手性格：平方损失下的最优预测被大偏差牵着走（对离群点敏感），绝对损失则稳如老狗但处处计较。**没有普适最好的损失，只有匹配场景的损失**——这正是"损失函数是设计决策而非自然规律"的含义。

## 3. 正式定义

给定样本 $(x_i, y_i)$ 与模型预测 $\hat{y}_i=f(x_i)$：

| 名称 | 单样本损失 $L(y,\hat y)$ | 经验风险（训练集平均） |
| --- | --- | --- |
| 平方损失（L2） | $(y-\hat{y})^2$ | $$E_{mse}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2$$ |
| 绝对损失（L1） | $\lvert y-\hat{y}\rvert$ | $$E_{mae}=\frac{1}{n}\sum_{i=1}^{n}\lvert y_i-\hat{y}_i\rvert$$ |

训练 = 在模型的参数空间里**最小化经验风险**。两个立刻有用的事实：

- 平方损失下，用常数预测时最优常数是**均值** $\bar{y}$（对偏差平方求导置零即得）；
- 绝对损失下，最优常数是**中位数**（绝对偏差之和在数据点处取得折线拐点）。

## 4. 分步例题

**例**：三套房真实成交价为 $200, 260, 340$（万元）。某模型一口价报了 $260$。

1. 各处误差：$-60,\;0,\;80$；
2. 平方损失逐项：$3600,\;0,\;6400$；经验风险 $=\dfrac{10000}{3}\approx3333$；
3. 绝对损失逐项：$60,\;0,\;80$；经验风险 $=\dfrac{140}{3}\approx46.7$；
4. 换个角度验证"均值最优"：真实值的均值恰是 $\dfrac{800}{3}\approx266.7$，比 260 更低一点点——常数预测的世界里，均值就是平方损失的谷底；
5. 观察误差结构：那套 340 万的房子在平方账本上贡献了 $64\%$ 的总罚分——**一个离群点统治了整场考试**。

### 实验 2：扫描常数预测器，亲眼看谷底

```python title="扫一遍报价：平方损失的谷底在均值，绝对损失在中位数"
prices = [200, 260, 340]

def mse(guess):                     # 平方损失经验风险
    return ((guess - prices[0]) ** 2 + (guess - prices[1]) ** 2 + (guess - prices[2]) ** 2) / len(prices)

def mae(guess):                     # 绝对损失经验风险
    return (abs(guess - prices[0]) + abs(guess - prices[1]) + abs(guess - prices[2])) / len(prices)

best_mse_guess, best_mse_val = None, None
for k in range(2001):               # 报价从 150 扫到 350，步长 0.1
    guess = 150 + k * 0.1
    e = mse(guess)
    if best_mse_val is None or e < best_mse_val:
        best_mse_val, best_mse_guess = e, guess

print("平方损失最优报价:", round(best_mse_guess, 1), "谷底:", round(best_mse_val, 1))
print("均值对照:", sum(prices) / len(prices))
print("绝对损失在 260 处:", mae(260), "在 267 处:", mae(267))
```

扫描出的谷底落在均值 266.7 附近；而 `mae` 在 260 到 267 之间几乎不变——绝对损失的"平底锅"，正是它偏爱中位数的几何表现。

### 快问快答

```quiz
为什么说平方损失"对离群点敏感"？
- 因为它只看正误差
- 因为误差先平方，一个大误差的罚分按倍数平方放大，主导整个平均值 [*]
- 因为平方让数值变大所以更准
? 误差放大 k 倍，平方罚分放大 k^2 倍：一个 10 倍离谱的点贡献抵得上一百个普通点，训练于是围着它转。
```

:::warning[常见误区]

**误区一**："训练误差低就代表模型好。" 训练集上的经验风险只是模拟考：模型可以把答案背下来刷到接近零，换新数据原形毕露（过拟合，本章第四课的主角）。

**误区二**："损失函数只有一种正确选择。" 平方、绝对、Huber、交叉熵……各自编码不同的容错哲学。选损失 = 选价值观：你的业务更怕偶发大错还是常态小错？

**误区三**："损失为零说明学到了真理。" 若数据本身含噪声，零损失恰恰说明模型连噪声也背了下来。第 41 章讲过的不可约误差决定了任何模型的损失都有下限。

:::

## 6. 练习

**练习 1**（概念）：预测误差分别为 $+20,-10,+20$。心算 MAE；再说说为什么 MSE 是它的"放大版"。

<details>
<summary>点开查看逐步解答</summary>

MAE $=(20+10+20)/3\approx16.7$。MSE $=(400+100+400)/3=300$：同样的三个点，平方账本把 +20 那两个点的权重抬成主角。数值上 MSE 还丢了量纲（单位成了"万元的平方"），工程报告里常开根号还原成 RMSE。
</details>

**练习 2**（判题）：初始代码想算 MSE 却忘了平方、括号也放错了位置。请修好并补全最后一行判断：

```exercise
# @title: 练习：算对均方误差
# @check: 16.67
# @check: 300.0
# @check: True
# @hint: 先把每个误差平方再求和除以个数；MSE 对同一组数据的数值远大于 MAE。
errors = [20, -10, 20]

mae = (abs(errors[0]) + abs(errors[1]) + abs(errors[2])) / 3   # 绝对值求和再平均，这行是对的
print(round(mae, 2))

mse = errors[0] + errors[1] + errors[2] / 3       # ← 忘了平方，括号也错了
print(mse)

print(mse > mae)                       # 平方账本是否总是更重？
```

修好后输出 `16.67`、`300.0` 和 `True`：同一个误差表，两种账本相差一个数量级。

**练习 3**：实验 2 中把 prices 改成 `[200, 260, 340, 900]`（一套豪宅乱入）再跑：平方谷底挪向哪里？绝对谷底呢？

<details>
<summary>点开查看逐步解答</summary>

均值从 266.7 被拖到 425——平方谷底追着豪宅跑；而绝对损失的谷底落在中间两个数之间（260 与 340 之间任意位置都是最优），几乎纹丝不动。这就是统计里"**均值怕离群、中位数稳如山**"的训练版：损失函数决定了你的模型听谁的。
</details>

## 7. 选读：损失函数如何决定"最优常数"

<details>
<summary>选读 · 两行微积分</summary>

对常数预测 $c$，平方经验风险 $E(c)=\frac1n\sum(y_i-c)^2$ 求导：$E'(c)=-\frac2n\sum(y_i-c)$，置零得 $c=\bar y$（均值）。二阶导恒正确认是谷底。换成绝对损失 $E(c)=\frac1n\sum\lvert y_i-c\rvert$：它在每个数据点处有斜率跳变（左右导数各减 $\frac1n$），斜率由负转正的位置就是中位数——奇数个点时恰好是中间那个数，偶数个点时中间两点之间全是平底。**损失函数的形状直接雕刻解的位置**，这行小算式是整个监督学习的第一块积木。

</details>
