# 高斯过程：给函数本身先验

## 1. 从一个场景开始

传感器只在 9 个位置测过温度，你想知道整条温度曲线长什么样。常规回归会给你一条拟合线，再附上一句"误差大约正负多少"——但那是个**全局**的误差，它不会告诉你"哪一段最没把握"。

可现实里你最想知道的恰恰是这件事：**测点附近当然放心，两个测点中间那段敢不敢信？** 一个只能吐一条线、说不出哪里心虚的模型，在这儿不好用。

**高斯过程（Gaussian Process, GP）**的做法很激进：它不把参数当成随机变量，而是**直接给"整条函数"配一个概率分布**——一个函数空间上的先验。于是每一次预测都会连带吐出**逐点的不确定度**：测过的地方方差小，没测过的地方方差自动变大。**不确定性是这套方法自带的，不是事后补的。**

## 2. 直觉解释

**第一层：从有限维高斯爬到无限维。** 你熟悉的多维高斯分布，是由一个均值向量和一个协方差矩阵决定的。现在把"维度"换成"自变量 $x$ 的取值"：对每一个 $x$ 都有一个 $f(x)$，任意挑有限的 $n$ 个点出来，$(f(x_1),\dots,f(x_n))$ 就是一个 $n$ 维高斯。**高斯过程就是"任意有限个取值都联合高斯"的随机函数**——它能写下的不是某个分布的形状，而是"哪两个位置的函数值该有多像"。

**第二层：协方差函数 = 相似度设定。** 决定 GP 性格的全在一个函数 $k(x,x')$ 之上：它回答"当 $x$ 和 $x'$ 靠得近时，$f(x)$ 和 $f(x')$ 应该有多像"。常用的 RBF 核说：距离越近越像，且相似度随距离**平方指数**衰减——这让函数极其光滑。Matérn 核说：相似度按多项式衰减，函数允许有一点"粗糙"。**换核函数，就是换你对"函数该长多光滑"的信念。**

**第三层：看到数据，这个"函数的云"被拧细。** 训练前，所有光滑曲线构成一片弥漫的云；每看到一个测点，云就被"钉住"一下——经过该点的曲线权重大，其余的塌缩。**测点附近，曲线被拧得很细（方差小）；远离测点处，云重新散开（方差回到先验大小）。** 这就是它比普通回归多出来的那件东西：一张随位置变化的"把握程度"地图。

## 3. 正式定义

**高斯过程**：随机函数 $f$ 若对任意有限个点 $x_1,\dots,x_n$，向量 $(f(x_1),\dots,f(x_n))$ 都服从多元高斯，则称 $f$ 是一个高斯过程，记作

$$f \sim \mathcal{GP}\!\left( m(x),\, k(x, x') \right),$$

其中 $m(x)$ 是均值函数、$k(x,x')$ 是**协方差函数（核函数）**。常见选择：

$$k_{\text{RBF}}(x,x') = \sigma_f^2 \exp\!\left( -\frac{(x-x')^2}{2\ell^2} \right), \qquad k_{\text{M3/2}}(x,x') = \sigma_f^2\!\left( 1 + \frac{\sqrt{3}\,r}{\ell} \right) e^{-\sqrt{3}\,r/\ell},$$

这里 $r = |x - x'|$，$\ell$ 叫**长度尺度**（$\ell$ 越大，函数变化越慢、越平缓）。

**回归预测**：给定训练数据 $(X, y)$，并设观测带高斯噪声 $y = f(X) + \varepsilon$、$\varepsilon \sim \mathcal{N}(0, \sigma_n^2)$，则任意测试点 $x_*$ 处的后验预测分布为高斯

$$\mu_* = k_*^{\top} \left( K + \sigma_n^2 I \right)^{-1} y, \qquad \sigma_*^2 = k(x_*,x_*) - k_*^{\top} \left( K + \sigma_n^2 I \right)^{-1} k_*,$$

其中 $K$ 是训练点之间的协方差矩阵，$k_*$ 是测试点与训练点之间的协方差向量。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f$ | 随机函数 | 我们要推断的对象，一条未知曲线 |
| $m(x)$ | 均值函数 | 先验里函数的"默认形状"，常取 0 |
| $k(x,x')$ | 核函数（协方差） | 两个位置的函数值有多像，决定光滑度 |
| $\ell$ | 长度尺度 | 函数变化快慢，最重要的超参数 |
| $\sigma_f^2$ | 信号方差 | 函数值先验波动的幅度 |
| $\sigma_n^2$ | 噪声方差 | 观测噪声大小，控制"贴合数据"的程度 |
| $\mu_*,\ \sigma_*^2$ | 预测均值与方差 | 测点的估计值、以及那里的不确定度 |

两点观察：**① 预测方差公式里根本没有 $y$**——它只依赖 $x_*$ 和训练点的位置，所以"哪里没把握"在**看到观测之前**就已经由设计决定；**② 每个预测点都要解一次同规模的线性方程组**，计算量 $O(n^3)$，这是 GP 在大数据上最硬的瓶颈。

## 4. 分步例题

用单个训练点手推一次预测，把公式的每一个零件都摸一遍。取 RBF 核、$\ell = 0.8$、$\sigma_f^2 = 1$、噪声方差 $\sigma_n^2 = 0.01$。训练点 $(x_1, y_1) = (0,\ 1.0)$，想预测 $x_* = 0.4$ 处的函数值。

1. **算协方差零件**：$k(x_1,x_1) = 1$；$k(x_*,x_*) = 1$；$k(x_*,x_1) = k(0.4,0) = e^{-0.4^2/(2 \times 0.8^2)} = e^{-0.125} = 0.8825$；
2. **组矩阵**：$K + \sigma_n^2 I = [1.01]$（单点就是个数），$k_* = [0.8825]$，$y = [1.0]$；
3. **代入均值公式**：$\mu_* = 0.8825 \times \dfrac{1}{1.01} \times 1.0 = 0.8738$——离测点 0.4 处只比 1.0 略低，因为核还给出 0.88 的相似度；
4. **代入方差公式**：$\sigma_*^2 = 1 - \dfrac{0.8825^2}{1.01} = 1 - 0.7711 = 0.2289$，标准差 $\sigma_* \approx 0.478$；
5. **读出张力**：预测值 0.8738 离观测 1.0 不远，但**标准差不小**——单点外推本就心里没底；
6. **对比极端情形**：把 $x_*$ 推到 5.0（远到核早就衰减干净），$k(x_*,x_1) \approx 0$，于是 $\mu_* \approx 0$、$\sigma_*^2 \approx 1$——**预测回到先验均值 0，方差回到先验方差 1**。离数据越远越"不敢说话"，正是我们想要的行为。

### 实验 2（python）：9 个测点，预测均值与后验方差一起吐出来

下面用纯 Python（自己写一个高斯消元）跑一遍 GP 回归，不依赖任何外部库，把"解线性系统"这件事完全摊开：

```python
import math                       # 数学库

# 9 个测点，y ≈ sin(x) 并带一点观测噪声
X = [-3.0, -2.0, -1.5, -0.5, 0.0, 0.8, 1.6, 2.4, 3.0]
y = [-0.14, -0.91, -1.0, -0.35, 0.2, 0.85, 1.0, 0.7, 0.05]

def rbf(a, b, length, sf):
    # RBF 核：距离越近越像，相似度按平方指数衰减
    return sf * sf * math.exp(-(a - b) ** 2 / (2 * length * length))

length = 0.8                      # 长度尺度 ℓ
sf = 1.0                          # 信号标准差
sn = 0.1                          # 观测噪声标准差

n = len(X)
K = []                            # 训练点协方差矩阵 K + σn²I
for i in range(n):
    row = []
    for j in range(n):
        add = sn * sn if i == j else 0.0   # 对角线加噪声方差
        row.append(rbf(X[i], X[j], length, sf) + add)
    K.append(row)

def solve(mat, rhs):
    # 高斯消元（带部分主元）解 mat·x = rhs，返回解向量
    m = len(rhs)
    a = [mat[i][:] + [rhs[i]] for i in range(m)]   # 增广矩阵，不破坏原矩阵
    for col in range(m):
        piv = col
        for r in range(col + 1, m):                # 选绝对值最大的主元，稳住数值
            if abs(a[r][col]) > abs(a[piv][col]):
                piv = r
        a[col], a[piv] = a[piv], a[col]
        for r in range(col + 1, m):
            f = a[r][col] / a[col][col]
            for c in range(col, m + 1):
                a[r][c] = a[r][c] - f * a[col][c]  # 消元
    out = [0.0] * m
    for r in range(m - 1, -1, -1):                 # 回代
        s = a[r][m]
        for c in range(r + 1, m):
            s = s - a[r][c] * out[c]
        out[r] = s / a[r][r]
    return out

beta = solve(K, y)                # (K+σn²I)⁻¹ y，预测均值要用它
Xs = [-5.0, -2.5, -0.1, 1.9, 4.5] # 两个远离数据的点 + 三个数据附近的点
for x in Xs:
    kss = [rbf(x, xi, length, sf) for xi in X]   # 测试点与各训练点的协方差
    mu = 0.0
    for i in range(n):
        mu = mu + kss[i] * beta[i]               # 预测均值 = k*ᵀ(K+σn²I)⁻¹y
    alpha = solve(K, kss)                        # (K+σn²I)⁻¹k*
    quad = 0.0
    for i in range(n):
        quad = quad + kss[i] * alpha[i]          # k*ᵀ(K+σn²I)⁻¹k*
    var = rbf(x, x, length, sf) - quad
    if var < 0:
        var = 0.0                                # 浮点误差可能给出极小负数
    print(x, round(mu, 3), round(var ** 0.5, 3))
```

输出五组"测点位置、预测均值、后验标准差"：

`-5.0 / 0.009 / 0.999`、`-2.5 / -0.535 / 0.197`、`-0.1 / 0.088 / 0.088`、`1.9 / 0.968 / 0.115`、`4.5 / -0.123 / 0.969`。

逐条读：在 **-2.5** 处预测 -0.535（真值 $\sin(-2.5) = -0.599$ 附近），标准差只有 0.197；在 **1.9** 处预测 0.968（$\sin(1.9) \approx 0.946$），标准差 0.115——**数据附近的把握很大**。而把点推到 **-5.0** 和 **4.5**（远在数据之外），预测均值退回 0 附近，标准差涨到 **0.999 和 0.969**——几乎等于先验标准差 1。**"哪里没把握"由模型自动报出，不需要你另想办法估。**

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为 GP 的预测方差来自观测噪声。" 恰恰不是。后验方差公式 $\sigma_*^2 = k(x_*,x_*) - k_*^{\top}(K+\sigma_n^2 I)^{-1}k_*$ **里没有 $y$**——它只由测试点和训练点的**位置**、核函数、以及 $\sigma_n^2$ 决定，跟观测到的数值是多少毫无关系。所以"哪里没把握"在设计阶段就已确定；带噪声的观测值只影响均值 $\mu_*$。观测噪声 $\sigma_n^2$ 的作用是决定曲线**允许多靠近**训练点：$\sigma_n^2 \to 0$ 会插值穿过每个点（噪声大时这是过拟合），$\sigma_n^2$ 大则曲线更"不敢"贴合。

**误区二**："你以为 GP 和核岭回归/核 SVM 差不多，都是核方法。" 内核函数用法像，**输出完全不同**：核 SVM 给一个分类边界或点预测，核岭回归给一个点预测；**只有 GP 给出一整个后验分布，自带逐点方差**。要把 GP 与贝叶斯线性回归对上号也可以——取基函数 $\phi$、先验 $w \sim \mathcal{N}(0,\Sigma)$，边缘化掉 $w$ 后得到的正是核为 $k(x,x') = \phi(x)^{\top}\Sigma\,\phi(x')$ 的 GP。**GP 是贝叶斯线性回归的"无限维基函数"版**，只是不必写出 $\phi$ 长什么样。

**误区三**："你以为 GP 只是慢一点，大不了多跑一会儿。" 训练要分解 $n \times n$ 矩阵，复杂度 $O(n^3)$，预测每个点还要 $O(n^2)$。$n = 10^4$ 就已经吃力，$n = 10^6$ 直接不可行。工程上的出路是**稀疏/近似 GP**（诱导点、随机特征近似、KISS-GP），或者干脆换回神经网络。**GP 擅长的是小样本、要高可信度的场景（实验设计、超参数优化、空间插值），不是大数据训练场。**

:::

def rbf(a, b, length):
    d = a - b
    return math.exp(-(d * d) / (2 * length * length))

print(round(rbf(0.0, 1.6, 0.8), 3))    # 0.135

<details>
<summary>点开查看逐步解答</summary>

$\ell$ 从 0.8 涨到 3.0（接近 4 倍），核函数变得非常"宽"：相隔 3 个单位的点仍然高度相关。后果分两处：

**预测曲线更平缓**——因为核把远处的点也拉进来一起平均，函数被强迫"整体平滑"，很难在近距离上剧烈起伏。数据点之间本来能弯一下的地方，现在被远处的点"撑平"了。

**后验标准差整体变小、且变平**——远处的测试点（如 $x = -5$、$4.5$）与最近训练点的距离只有约 2、1.5，在 $\ell = 3$ 的核下仍算"近"，所以 $\sigma_*$ 会明显小于先验的 1，不再回到 1 附近。反过来说，**预测方差图上的"把握半径"被拉大了**，模型自信得超出数据支持的范围——这就是 $\ell$ 太大带来的过平滑风险。

实践中的对策：用**边际似然的梯度**自动优化 $\ell$（也叫"训练超参数"），而不是手工试。这也顺带解释了为什么 GP 与贝叶斯优化的关系那么近——下一站会看到。

</details>

## 8. 选读：从"无限的基函数"到稀疏 GP

<details>
<summary>选读 · GP 与贝叶斯线性回归的等价，以及 $O(n^3)$ 的出路</summary>

**等价性的证明思路。** 取一组基函数 $\phi(x) = (\phi_1(x),\dots,\phi_p(x))^{\top}$，让权重先验 $w \sim \mathcal{N}(0, \Sigma)$、观测 $y = \phi(x)^{\top} w + \varepsilon$。边缘化掉 $w$（用高斯积分），得到的 $f$ 的边缘协方差正好是

$$k(x, x') = \phi(x)^{\top} \Sigma\, \phi(x').$$

所以任何一个核都可以看成"某个（可能是无穷维的）特征映射的内积"——这正是[核技巧与 SVM 大间隔](./75-kernel-svm-margin.md)里 Mercer 定理的那句话。**区别在于：核岭回归只保留了"最优 $w$ 的均值"，而 GP 把整个后验协方差也留下了。** 这就是多出来的那点不确定性信息的来路。

**$O(n^3)$ 的三条出路。** 训练要把 $K + \sigma_n^2 I$ 分解，规模 $n^3$。工业界的三类近似：

1. **诱导点法（inducing points）**：挑 $m \ll n$ 个"代表点"，用它们近似整片数据的信息，复杂度降到 $O(nm^2)$——稀疏 GP 与 FITC 都属此列；
2. **随机特征近似（random Fourier features）**：用蒙特卡洛采样把无穷维特征压成几百维显式特征，再把 GP 退化成"几百维的线性回归"；
3. **结构化核（KISS-GP）**：如果网格规则，$K$ 是 Toeplitz/低秩结构，可实现近线性求解。

**一句话收束：** GP 的数学之美在于它把"不确定性"装进了模型内部；它的工程难点也全在那一个 $n \times n$ 矩阵上。**学会用它的边界——小 $n$、要高可信度、要逐点方差——比学会推它的公式更重要。**

</details>
