# 数据、假设类与泛化目标

## 1. 从一个场景开始

你的奶茶销量模型在 A 城训练，月均误差不到两杯；开到 B 域的第一周，预测全线跑偏——B 域的人根本不喝甜的。模型没坏、代码没错，可你优化了那么久的那个数字，**从来就不是你真正想要的数字**。

这一课把监督学习的目标正式写在纸面上：我们到底在最小化什么？训练集在这件事里扮演什么角色？以及"训练数据=线上数据"这条心照不宣的约定什么时候会塌。

## 2. 直觉解释

先换视角：**数据不是一堆数，是一台看不见的机器吐出来的样本**。每位顾客带着自己的口味（特征 $X$）走进来，产生一个真实销量（标签 $Y$）——全城所有人合起来构成一个概率分布 $P(X,Y)$。你手里的历史订单，只是这台机器吐出的有限一把球。

再换视角看"学习"：候选模型的全体像一份**应聘者花名册**（假设类）。招聘流程是让每人做一套抽来的卷子（训练集），按平均分录取——但你想雇的是**真本事**，不是这次抽考的成绩。卷子会抖动：换一套题，排名可能翻转。

于是监督学习的骨架三件套齐了：

- **目标**：在整个分布上的平均损失（期望风险）尽量小；
- **代理**：只考得到有限的题——用样本平均（经验风险）顶上；
- **约定**：正式考的出题套路和模拟考一致（训练分布 = 部署分布）。

B 域的故事就是约定的第三条崩了：出题人换了。

## 3. 正式定义

设特征的随机变量 $X$、标签的随机变量 $Y$，联合分布为 $P(X,Y)$；固定一个损失 $L$ 与候选函数 $f$。

$$R(f)=\mathbb{E}_{(X,Y)\sim P}\bigl[L(Y,f(X))\bigr]$$

这叫**期望风险**（真风险）：对整个分布求加权平均。手头只有 $n$ 条样本时能算的是**经验风险**：

$$\hat{R}_n(f)=\frac{1}{n}\sum_{i=1}^{n}L(y_i,f(x_i))$$

| 符号 | 含义 |
| --- | --- |
| $P(X,Y)$ | 数据生成分布：全城顾客与销量的总账本 |
| $\mathcal{F}$ | 假设类：花名册上所有候选函数的集合 |
| $R(f)$ | 期望风险：想最小的真目标 |
| $\hat{R}_n(f)$ | 经验风险：实际优化的代理目标 |

**学习问题**的形式化陈述：给定假设类 $\mathcal{F}$ 和训练样本，在 $\mathcal{F}$ 中挑一个经验风险最小的成员：

$$\hat{f}=\arg\min_{f\in\mathcal{F}}\hat{R}_n(f)$$

这一切成立的地基是一条**理想假设**：训练样本与部署时遇到的样本都从同一个 $P$ 里独立抽取。它最常见的三种死法：

1. **采样偏差**：历史贷款审批记录里，被拒的人根本没有后续表现——账本天生缺页；
2. **时间漂移**：消费习惯随季节、流行缓慢移动，昨天的 $P$ 不是今天的 $P$；
3. **反馈循环**：推荐系统只推用户爱点的，结果改变了用户行为本身——模型参与制造了自己的训练数据。

## 4. 分步例题

**例**：奶茶模型已定稿（对任何街区都报同一个数）。已知整城的单杯真实误差平方贡献后，B 域分布对应的期望风险是 $R=48$（单位：平方元）。三个抽样的成绩单：

1. 样本 A（4 条记录，误差 $-2,3,-5,4$）：$\hat{R}_A=(4+9+25+16)/4=13.5$；
2. 样本 B（同样 4 条，误差 $8,-9,-10,7$）：$\hat{R}_B=(64+81+100+49)/4=73.5$；
3. 样本 C（400 条随机记录）：算出 $\hat{R}_C=51.2$；
4. 读数：A 和 B 只换了 4 位顾客，估计值差了 60——小样本的经验风险是个抖动的尺子；
5. 收束：C 的 51.2 贴着 48——**同一台分布机器**，样本越多估计越稳；但无论多稳，$\hat R$ 终究只是 $R$ 的影子。

### 实验 2：300 次重复抽样，亲眼看经验风险抖动

```python title="同一模型、同一座城：300 份抽样的成绩散布"
import random

random.seed(2026)            # 固定随机种子：每次运行结果完全一致

# 整城误差袋：600 条记录的单件平方损失，当作 B 域总账本（示例值）
bag = [random.gauss(48, 20) for _ in range(600)]   # gauss(均值,标准差)：正态抽样

def sample_risk(n):
    picks = random.sample(bag, n)     # 从总账本里不放回地抽 n 条
    return sum(picks) / len(picks)

for n in [4, 16, 100]:
    risks = []
    for trial in range(300):          # 同一模型重复抽 300 份 size=n 的样本
        risks.append(sample_risk(n))
    spread = max(risks) - min(risks)  # 300 次成绩的最大落差
    avg = sum(risks) / len(risks)
    print(f"n={n:>3}: 平均 {avg:.1f} | 落差 {spread:.1f}")
```

三次读数的平均都停在 48 附近——经验风险是**无偏的**尺子；而落差随 $n$ 一路缩水：种子取 2026 时实测 $n=4$ 的落差约 55.8、$n=16$ 约 29.6、$n=100$ 约 8.3。$n=4$ 时换一次抽样成绩就能差出一截，$n=100$ 后几乎人人交同一张卷。所谓泛化鸿沟的不可消除部分，就藏在这些平均值之下。

### 快问快答

```quiz
模型在新市场表现崩盘，哪一步最先该被怀疑？
- 学习率设错了
- 训练分布与部署分布不再是同一个 P [*]
- 代码有 bug
? 首先核对协议：训练时的数据和上线后的数据是不是同一台机器吐的？分布漂移不会在任何训练日志里报警。
```

:::warning[常见误区]

**误区一**："我在训练集上降到很低，所以真实风险也很低。" 你优化的自始至终是 $\hat R$ 这个影子；影子贴近真身需要样本量与同分布假设同时在场，缺一个就成了第 40 课里背题的学生。

**误区二**："假设类越大模型越强，那就尽可能往花名册里塞。" 名册越长，越容易挑到"恰好适配本次抽考"的幸运儿——经验风险的糖衣越厚。容量管理（下一课的正则化）就是给名册立规矩。

**误区三**："加了监控就不用管分布假设。" 监控只能事后发现崩塌，救不了已经在线上犯错的决策；建模前写下你的 $P$ 如何失效场景清单，才是上游防线。

:::

**练习 2**（判题）：初始代码把"累计绝对误差的平均"当成了经验风险——忘了第 10 课定下的平方账本。请修好后再回答波动问题：

```exercise
# @title: 练习：修好经验风险，再看波动收窄
# @check: 13.5
# @check: 73.5
# @check: True
# @hint: 第 10 课的经验风险用的是平方损失；比较两个落差的办法是直接打印表达式 spread_small > spread_big。
errs_a = [-2, 3, -5, 4]        # 与例题同样的样本 A
errs_b = [8, -9, -10, 7]       # 样本 B

def emp_risk(errs):
    total = 0
    for e in errs:
        total = total + abs(e)          # ← 错了：这不是平方账本
    return total / len(errs)

print(emp_risk(errs_a))
print(emp_risk(errs_b))

risks_n4 = [13.5, 73.5, 31.5, 6.5]       # 四份 n=4 抽样的经验风险
risks_n100 = [47.8, 48.2, 46.9, 49.1]    # 四份 n=100 抽样的经验风险
spread_small = max(risks_n4) + min(risks_n4)     # ← 错了：落差应是最大减最小
spread_big = max(risks_n100) - min(risks_n100)
print(spread_small > spread_big)
```

前两行修好后与例题逐字吻合（13.5、73.5）；第三行把 `+` 改成 `-` 后输出 `True`——四条样本的成绩能在 6.5 到 73.5 之间乱跳，而百条样本的摆动只剩两个多点：波动带收窄不是修辞，是账本事实。
