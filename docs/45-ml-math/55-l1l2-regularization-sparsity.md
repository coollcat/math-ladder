# L1、L2 正则化与稀疏性

## 1. 从一个场景开始

银行的风控评分卡有个硬规定：进模型的字段**不许超过十二个**——监管要看懂每一项扣分理由，系统也只接这么多输入。可你用最小二乘在几百个候选字段上一拟合，冒出四十七个非零系数。

第 40 课说过"容量过剩会背噪声"，这一课给花名册装笼头：给损失加一项罚款（正则化），让不重要的特征自动归零。两种最常见的罚单——L1 与 L2——只在平方和绝对值一字之差，解出的模型性格却完全不同。

## 2. 直觉解释

把参数空间想象成一张地图：损失函数的等高线把谷底团团围住，而罚款是给"离原点太远的地方"加地租。**加了罚项的解，住在"损失等高线"与"允许半径"相切的位置。**

允许域的形状决定性格：

- **L2 罚** $w_1^2+w_2^2$ 的等高线是**圆**——处处光滑、没有角点。圆与损失椭圆相切，切点通常落在普通位置：每个系数都被压小，但几乎不会恰好为零；
- **L1 罚** $\lvert w_1\rvert+\lvert w_2\rvert$ 的等高线是**菱形**——四个尖角全部钉在坐标轴上。损失椭圆张着大嘴围过来，最先撞上的多半是一个角点：某个系数被**精确清零**，剩下的才是幸存者。

非零系数被大幅削减的性质叫**稀疏性**——它就是评分卡要的答案：模型自己筛字段。而税率 $\lambda$ 是简单性与拟合度之间的**汇率**：$\lambda$ 越贵，越愿意牺牲拟合换简洁。

## 3. 正式定义

在经验风险后面追加罚项：

$$E_{\lambda}(f)=\hat{R}_n(f)+\lambda\,\Omega(w)$$

| 罚项 | 公式 | 允许域几何 | 对系数的效果 |
| --- | --- | --- | --- |
| L2（岭） | $\Omega=\sum_k w_k^2$ | 圆球面 | 整体缩水，难有精确零 |
| L1（套索） | $\Omega=\sum_k \lvert w_k\rvert$ | 菱形（角点在轴上） | 压到零并焊死在零，产出稀疏解 |

$\lambda$ 是开关：$0$ 时退回第 20 课的原版最小二乘；越大越偏向"什么都不带"的空模型。它能被选出来靠的还是第 40 课的老裁判——验证误差（第 41 章从理论侧解释了为什么"损失+约束"能控容量）。在优化教材里 L1 罚不可导，相应工具叫次梯度（第 43 章 95 号那课的领土）；本章只用扫描和封闭解，不需要碰它。

## 4. 分步例题

**例**：两个点 $(1,1)$、$(2,2)$，模型 $\hat{y}=wx$（无截距），平均平方误差与 L2 罚合并为

$$E(w)=\frac{(1-w)^2+(2-2w)^2}{2}+\lambda w^2$$

1. 无罚情形：展开得 $E(w)=\frac{5}{2}(1-w)^2$，求导置零得 $w=1$——完美穿线；
2. 记账罚单：$\lambda w^2$ 的导数是 $2\lambda w$，总导数 $5(w-1)+2\lambda w=0$；
3. 解出 **$w=\dfrac{5}{5+2\lambda}$**：罚只改动了分母；
4. 代入读数：$\lambda=1$ 时 $w=5/7\approx0.714$；$\lambda=3$ 时 $w=5/11\approx0.455$；$\lambda\to\infty$ 时 $w\to0$；
5. 关键观察：无论汇率多高，分子始终是 5——L2 把系数**按比例缩水**却永远不清零。它削减的是影响力，不是人数。想要"开除"，需要 L1 的角点。

## 5. 动手实验

### 实验 1：一图流——软缩水对硬清零

横轴是税率 $\lambda$，纵轴是初始值为 $w_0$ 的那个系数的新报价。蓝线是 L2 的报价曲线，橙线是 L1 的报价曲线；两条线从同一点出发、出发斜率也相同——分化全在后续。

### 实验 2：冗余特征面前的分道扬镳

```python title="同一批数据扫税率：L1 开除一份冗余，L2 让大家平摊"
import matplotlib.pyplot as plt

a = [1.0, 2.0, 3.0, 4.0]           # 特征一：真身
b = [1.1, 1.9, 3.1, 3.9]           # 特征二：a 的近亲（高度相关）
ys = [2.1, 3.9, 6.0, 8.2]

def penal_risk(w1, w2, lam, kind):
    s = 0.0
    for i in range(4):
        err = ys[i] - w1 * a[i] - w2 * b[i]
        s = s + err * err
    if kind == "l1":
        return s / 4 + lam * (abs(w1) + abs(w2))
    return s / 4 + lam * (w1 * w1 + w2 * w2)

def best_weights(lam, kind):       # 网格搜索：在每个 λ 下试遍所有 (w1, w2)
    best, bw = None, None
    for i in range(-3, 23):        # 网格从 -0.39 到 2.86，步长 0.13（保证含 0）
        w1 = i * 0.13
        for j in range(-3, 23):
            w2 = j * 0.13
            val = penal_risk(w1, w2, lam, kind)
            if best is None or val < best:
                best, bw = val, (w1, w2)
    return bw

for kind in ["l1", "l2"]:
    pts = []
    for lam in [0, 0.5, 1, 2, 4]:
        w1, w2 = best_weights(lam, kind)
        pts.append((w1, w2))
        print(f"{kind} lambda={lam}: w1={w1:.1f} w2={w2:.1f}")
    wx = [p[0] for p in pts]
    wy = [p[1] for p in pts]
    plt.plot(wx, wy, marker="o", label=kind)

plt.axhline(0, color="gray", linestyle=":")   # 横轴 = w2 清零线
plt.xlabel("w1")
plt.ylabel("w2")
plt.legend()
plt.grid(True)
```

实测读数：$\lambda=0$ 时裸最小二乘漂在 $(1.7,\,0.4)$——高度相关的两份证据分账随意，数据稍动位置就变；随后 **L1 在 $\lambda=0.5$ 就把 $w_2$ 精确报到 0** 并从此焊死，独留真身上阵（税率抬到 4 也只是把幸存者压瘦到 1.8）；L2 则全程平摊缩水 $(1.0,0.9)\to(0.8,0.8)$，谁也不肯开除。图上灰色虚线就是稀疏所在——只有橙色路径真的抵达过那里。

### 快问快答

```quiz
评分卡要求"最多留十二个字段"，哪条路线最对口？
- 加大 L2 罚项直到只剩十二个
- 用 L1 正则化：许多系数会被精确压成零 [*]
- 把数据量翻十倍
? L2 只会把所有系数一起缩水、很少恰好为零；L1 的菱形角点天然落在坐标轴上，专治"人数超标"。
```

:::warning[常见误区]

**误区一**："L2 也让权重变小，所以也能做特征选择。" 变小与归零之间隔着性质鸿沟：L2 是按比例缩水，九十个小系数照样给你报九十项理由；能"开除人"的是 L1 角点的专利。

**误区二**："λ 越大模型一定越好。" 汇率过高的代价是欠拟合：全员清零的评分卡连收入都放走了。λ 的合法出处永远是验证集成绩，不是信仰。

**误区三**："稀疏特征筛完就可以扔掉正则化重新裸训。" 幸存字段的系数仍带着筛选过程的乐观偏差；严谨做法是把筛选规则连同训练流程整体固定下来再做评估——不然泄漏问题会在交叉验证里咬你一口（本章末课见）。

:::

## 6. 练习

**练习 1**（概念）：例题里若换成 L1 罚 $+\lambda\lvert w\rvert$，导数方程变成 $5(w-1)+\lambda\,\mathrm{sign}(w)=0$。说明为什么解要么是 $w=1-\lambda/5$，要么干脆是 $w=0$，中间没有别的状态。

<details>
<summary>点开查看逐步解答</summary>

$w>0$ 区域里 $\mathrm{sign}(w)=1$，解出 $w=1-\lambda/5$，当且仅当它还是正数才自洽；一旦汇率越过 $5$，这个正数支就作废，$w<0$ 支同理不可能（初始斜率为正谁也不会翻负号）。于是剩下的唯一住处是 $w=0$ 本身——绝对值的拐角在那里，导数方程失效但函数值占优。"清零然后焊死"不是比喻，是不等式的结论。</details>

**练习 2**（判题）：初始代码抄了例题公式却忘了罚项导数里的因子 2。修好再回答极端税率的下落：

```exercise
# @title: 练习：修好带罚项的最优系数
# @check: 0.714
# @check: 0.455
# @check: True
# @hint: 例题第 2 步：λw^2 的导数是 2λw，所以分母是 5 + 2*lam；最后一问直接比较 5/(5+2*lam) 与 0.05。
lam = 1                        # 先取汇率 λ = 1

def penalized_w(lam):
    return 5 / (5 + lam)       # ← 错了：漏了罚项导数的因子 2

print(round(penalized_w(lam), 3))
print(round(penalized_w(3), 3))

print(penalized_w(100) < 0.05)
```

修好后三行输出 `0.714`、`0.455`、`True`：汇率抬到 100 时系数虽被压进 0.05 以内，但公式保证它永远不为零——这正是实验 1 里蓝线的宿命。

**练习 3**：实验 2 中把 b 改成 `[0.5, 1.0, 1.5, 2.0]`（不再是 a 的近亲而是弱相关列）。重跑看看 λ=1 时 L1 还会不会清零？体会"稀疏发生在特征冗余时最容易"。

<details>
<summary>点开查看逐步解答</summary>

弱相关时特征二贡献了独立信息，L1 大多保留两个非零系数、只是各打折扣；而刚才能整列清零，是因为 $b\approx a$——同一份证据被记了两遍，罚单替你删掉了重复账目。实践中相关性越高的特征群，越常看到 L1 只留代表。</details>

## 7. 选读：软阈值算子——L1 报价机的机芯

<details>
<summary>选读 · 一维情形的精确解</summary>

单看一个固定坐标：设别处的组合已给出目标得分 $z$，该坐标单独解 $\min_w \tfrac12(z-w)^2+\lambda\lvert w\rvert$。分段去绝对值算一算，答案是**软阈值算子** $w^\ast=\mathrm{sign}(z)\,( \lvert z\rvert-\lambda)^{+}$：绝对值越过门槛的部分按差额放行，没越过的整段截零。对照 L2 的同款问题 $\min_w\tfrac12(z-w)^2+\lambda w^2$ 得 $w^\ast=z/(1+\lambda)$——纯比例缩水。实验 1 的两条曲线就是这两个公式的画像：L2 是缩放器、L1 是闸门。整套套索回归的训练过程，无非是在所有坐标上轮流拧这台闸门（第 43 章次梯度方法的用武之地）。</details>
