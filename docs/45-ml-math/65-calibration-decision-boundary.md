# 决策边界与概率校准

## 1. 从一个场景开始

医院的预警模型给两位患者打了分：老张 $p=0.94$、老李 $p=0.51$。系统按"超过 0.5 就通知随访"把两人都标红。三个月后复盘：老张确实需要干预，老李其实安好——但报告上写的都是"高风险"。**同一个阈值两端，误差的性质完全不同**：边界内的判断只需要站对队，可如果护士问"0.51 到底是多危险？"，模型必须报出一个当真的数字。

这一课把两件事拆开：**边界画在哪里**（决策），与**分数能不能当概率花**（校准）。

## 2. 直觉解释

第 30 课已经见过 sigmoid 与它的 0.5 参考线。现在补上两个常被忽略的事实：

- **阈值搬家 = 边界搬家**。逻辑回归的打分是直线 $t=wx+b$，若把行动门槛从 $\tau=0.5$ 调到 $0.8$，等于宣布"概率足够高才动手"，边界从 $t=0$ 滑到 $t=\log(4)\approx1.39$——特征空间里整条分界线被平移了。模型的输出没变，变的是你使用它的政策；
- **排名对 ≠ 数字对**。A 模型说老张 $0.94$、老李 $0.51$；B 模型说老张 $0.71$、老李 $0.23$。两个模型都答对了"谁更危险"，却在绝对高度上差了十万八千里。评分卡、榜单类应用只要前者；定价、资源分配、知情同意书要的是后者。

校准要回答的问题用一张图讲完：把预测分相近的患者归成一组，横轴放模型报价、纵轴放该组的真实发生率。完美模型的所有组都坐在对角线上；系统性偏离对角线的形状，就是谎话的形状。

## 3. 正式定义

固定二分类模型输出 $\hat{p}(x)$。

| 名称 | 定义 | 备注 |
| --- | --- | --- |
| 决策边界 | 集合 $\lbrace x:\hat{p}(x)=\tau\rbrace$ | 逻辑回归下即 $wx+b=\log\dfrac{\tau}{1-\tau}$ |
| 可靠性图 | 分桶后画（组内实测率, 组内预测均值）点列 | 对角线 $y=x$ 为满分参考 |
| Brier 得分 | $$\mathrm{Brier}=\frac{1}{n}\sum_{i=1}^{n}(\hat{p}_i-y_i)^2$$ | 第 10 课平方损失的概率版：同时管校准与分辨 |

"训练分布 = 部署分布"的假设在这里多一层含义：换一家病人构成不同的医院，即使模型排序能力不变，斜率也可能不再合适——校准是**关于这份分布**的承诺（第 50 课的语言：换了 $P$，欠的账要重新核对）。

## 4. 分步例题

**例**：社区医院按风险分 $t$ 把随访人群分成五档（结构与章首页实战挑战同款）。旧模型自诩分辨力强，置信曲线取 $\hat{p}=\sigma(1.5t)$。看最右一档（$t=2$，共 130 人）：

1. 模型报价：$\hat{p}=\sigma(3)=\dfrac{1}{1+e^{-3}}\approx0.953$——几乎拍胸脯；
2. 随访真相：130 人里确诊需要干预的有 105 人，实测率 $105/130\approx0.808$；
3. 差额 $0.808-0.953=-0.145$：模型把这档的风险**报高了约十五个百分点**；
4. 对照中档 $t=0$：报价 $0.500$ 对实测 $98/200=0.490$，只差 $-0.010$；
5. 读法：过度自信不是整体抬高或压低，而是**绕着中心拧螺旋**——越靠两端吹得越响，恰好中间还算诚实。

## 5. 动手实验

### 实验 1：拖动门槛，看边界随之搬家

蓝线是概率曲线 $p(x)$，橙线是你设定的行动门槛 $\tau$（水平线）。两条线的交点在横轴上的投影就是有效边界的位置。

$\tau=0.5$ 时边界正好落在 $c$；把门槛抬到 $0.95$，交点明显右移——做保守政策的成本是把更多真正需要的人关在门外。医疗与风控里"选哪个 $\tau$"从来不是数学题，是把漏报与误报摆上天平的政策题（章首页实战挑战算过这笔账）。

### 实验 2：亲手画出可靠性图

```python title="五档随访人群的可靠性表：好排名救不了错概率"
import math
import matplotlib.pyplot as plt

def sig(u):                       # sigmoid：以 e 为底的 S 形
    return 1 / (1 + math.exp(-u))

t_list = [-2, -1, 0, 1, 2]        # 各档的代表风险分
groups_n = [80, 130, 200, 160, 130]      # 各档随访人数
confirmed = [16, 43, 98, 106, 105]       # 其中确认需要干预的人数

preds = []                        # 模型报价（过度自信版：斜率 1.5）
obss = []                         # 实测发生率
for i, t in enumerate(t_list):
    preds.append(sig(1.5 * t))
    obss.append(confirmed[i] / groups_n[i])
    print(f"t={t}: 报 {preds[i]:.3f} | 测 {obss[i]:.3f}")

plt.plot([0, 1], [0, 1], color="gray", linestyle="--")   # 满分对角线
plt.scatter(preds, obss, color="tomato")                 # 五个档位各一个点
plt.xlabel("predicted")
plt.ylabel("observed")
plt.grid(True)
```

五个点整体趴在对角线下方且两端翘头：这就是"斜率吹牛"的标准画像。更扎心的是，把这些档按模型报价从小到大排、再按实测率从小到大排——顺序一模一样。**排序能力毫发无损，绝对数字全线失真**：榜单可以照发，报价单绝不能签。

### 快问快答

```quiz
两家模型 AUC 相同（排序一样好），为什么医院仍要挑校准好的那个？
- 因为校准好的跑得快
- 因为医生要拿概率数字做剂量、费用与知情同意的决定 [*]
- 因为校准好的不会出错
? 排序只解决"先看谁"；后续每一笔资源分配都消费的是数字本身。错的比例配上对的次序，照样造成实际伤害。
```

:::warning[常见误区]

**误区一**："0.5 是默认值所以总是对的。" 0.5 只是损失对称时的自然平衡点；筛查场景宁可错报一千不肯漏掉一个会把门槛往下拉，反方向的风控定价会往上抬。阈值是被业务代价决定的参数，不是出厂设置。

**误区二**："换个数据集重训一次就能顺便把校准做好。" 训练目标（如交叉熵）只在训练分布上兑现概率语义；部署分布一动，先检查漂移（第 50 课三死法），再做小成本的后期校准，比重训便宜得多。

**误区三**："Brier 低就说明模型校准好。" 它同时也奖励区分度高但狂妄的模型——两个成分混在一本账里，归因时要配着可靠性图一起读，别单凭一个总分定罪或洗白。

:::

## 6. 练习

**练习 1**（概念）：把门槛从 $\tau=0.5$ 提到 $\tau=0.9$，下列哪些量变了、哪些没变？(a) 模型输出的概率；(b) 边界位置；(c) 召回率；(d) 精确率的潜力。

<details>
<summary>点开查看逐步解答</summary>

(a) 不变——改门槛不动模型本身；(b) 变——边界向分数更高的一侧收缩（$\tau=0.9$ 的门槛分是 $\ln 9\approx2.20$）；(c) 几乎必然下降：更高的栏意味着更多人被拦在外面；(d) 有上升空间：能过新栏的多是真强者。这套联动正是"阈值=政策旋钮"的含义。</details>

**练习 2**（判题）：初始代码用模型自己的报价冒充了实测率，还把右端差额的方向写反了。请修好这两处：

```exercise
# @title: 练习：算出可靠性表的左端与右端差额
# @check: 0.153
# @check: -0.145
# @check: True
# @hint: 实测率 = 确诊人数 ÷ 随访人数；差额统一约定为 实测 − 报价。
import math

def sig(u):
    return 1 / (1 + math.exp(-u))

t_list = [-2, -1, 0, 1, 2]
groups_n = [80, 130, 200, 160, 130]
confirmed = [16, 43, 98, 106, 105]

preds = [sig(1.5 * t) for t in t_list]
obss = preds                                  # ← 错了：这是模型报价，不是随访真相

def order(vals):                              # 给一组数值排出名次（按下标的升序列表）
    return sorted(range(len(vals)), key=lambda k: vals[k])

gap_left = obss[0] - preds[0]
gap_right = preds[4] - obss[4]                # ← 错了：方向要与左端约定一致（实测 − 报价）

print(round(gap_left, 3))
print(round(gap_right, 3))

print(order(preds) == order(obss))            # 修复后这里应该仍是 True（排序不变）
```

修好后三行输出 `0.153`、`-0.145`、`True`：左端低报逾十五个百分点、右端高报约十四个百分点，而档位次序纹丝未动——本课标题的两半在这三行里各占一行。

## 7. 选读：Platt 缩放——给概率售后调音

<details>
<summary>选读 · 两参数修补</summary>

最常用的后期校准只有两颗螺丝：在新数据上拟合 $p^{\prime}=\sigma(A\cdot\logit(p)+B)$。$A$ 管"分辨率旋钮"、$B$ 管"整体偏置"——本例的病根正是 $A$ 太大，取 $A\approx 0.7/1.5\approx0.47$、$B=0$ 基本捋直对角线。这个形式你其实全套工具都有：logit 是线性变换（第 15 章）、拟合两参数是线性回归的老活（第 20 课）、外层套 sigmoid 只是回到第 30 课的家。校准不神秘，就是一次诚实的对表。</details>
