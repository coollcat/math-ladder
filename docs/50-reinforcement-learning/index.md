# 强化学习

强化学习面对的不是一次性分类，而是一串互相影响的选择：动作改变环境，环境再返回奖励和新状态。价值、策略和探索构成它的三角。

本章你会学到：

1. [序贯决策与反馈延迟](./10-sequential-decisions.md)——自动驾驶不能只问“这一秒方向盘打多少最舒服”；
2. [Agent、Environment、State、Action 与 Reward](./20-agent-environment.md)——游戏玩家盯着屏幕，按下按键，游戏改变画面和分数；
3. [Episode 与 Trajectory](./30-episode-trajectory.md)——一局棋有胜负，一局游戏会回到主菜单，一次推荐会话会结束；

5. [MDP 五元组](./50-mdp.md)——仓库每天决定补多少货：库存是状态，补货量是动作，缺货和仓储成本是奖励的反面；
6. [回报与折扣因子](./60-return-discount.md)——今天的 100 分和十年后的 100 分不一样值钱；

10. [Bellman 最优方程](./100-bellman-optimality.md)——导航软件在每个路口不是问“常走的路线怎么走”，而是问“从这里出发，哪条下一步能让总时间最短”；

## 实战挑战 · AlphaGo 的价值网络直觉

### 背景：一场被两亿人围观的序贯决策实验

2016 年 3 月 9 日至 15 日，DeepMind 的 AlphaGo 在首尔与李世石九段进行五番棋对决，最终以 4:1 获胜，全球超过 2 亿人观看了比赛。第二局 AlphaGo 下出令职业棋手沉默的第 37 手；第四局李世石还以颜色，下出被古力九段称为「神之一手」的第 78 手「挖」。据 DeepMind 团队赛后公开的说法（David Silver 在 Nature 新闻报道与 IEEE Spectrum 采访中的说明），这两手棋在 AlphaGo 看来都是「人类大约只有万分之一概率会下」的选点；哈萨比斯则在推特上透露：白 78 之后，AlphaGo 的价值网络一度仍自估胜率约七成，直到第 87 手左右才意识到自己早在第 79 手就已犯错。

这正是本章核心概念的一次公开演出：策略网络是动作规则 $\pi(a\mid s)$，价值网络则是状态价值 $V^\pi(s)$ 的工业级版本——给整个棋盘局面打一个胜率分。第 78 手的价值不在于这一步本身得分多少，而在于它把后续所有局面的 $V$ 全部改写：反馈延迟、Bellman 备份、探索与利用，全在这一手里。

下面题目的数字是教学简化，不是 AlphaGo 的真实内部数据；但每一问都对应本章的一门课。

### 题目

设某简化局面序列中，接下来三步的「局势收益」为 $0.5, 0, 1.0$，折扣因子 $\gamma=0.5$：

1. **折扣回报**：从现在起累计的折扣回报 $G$ 是多少？
2. **TD 误差**：神之一手落下后，旧估计 $V(s)=0.75$ 已经过时。这一手本身没有即时奖励（$r=0$），下一局面的真实价值为 $v_{next}=0.25$（同样按 $\gamma=0.5$ 折算）。TD 误差是多少？

$$V(s)\leftarrow V(s)+\alpha\,[\,r+\gamma V(s')-V(s)\,].$$

3. **一次更新**：取学习率 $\alpha=0.5$，按上式更新后的新估计是多少？

用纯算术完成下面的练习（不许 import，也不需要任何库）：

```exercise
# @title: 实战挑战 · 给第 78 手时刻算一笔账
# @check: 0.75
# @check: -0.625
# @check: 0.4375
# @hint: (1) 后两步收益分别乘 0.5 和 0.25；(2) 目标是 r 加 gamma 乘 v_next，再减去 v_old；(3) 新估计等于 v_old 加 alpha 乘 td。
payoffs = [0.5, 0.0, 1.0]   # 三步局势收益
gamma = 0.5                 # 折扣因子
v_old = 0.75                # 第 78 手前价值网络的乐观估计
r = 0                       # 这一手本身没有即时奖励
v_next = 0.25               # 意外落子之后的下一局面价值
alpha = 0.5                 # 学习率

g = payoffs[0] + payoffs[1] + payoffs[2]   # (1) 学生需按折扣因子折算后两步
td = v_next - v_old                        # (2) 学生需补上 r + gamma * v_next 作为目标
v_new = v_old                              # (3) 学生需写成 v_old + alpha * td
print(g)
print(td)
print(v_new)
```

<details><summary>点开查看逐步解答</summary>

**第 1 问（折扣回报）**：只有第一步权重为 1，后面依次乘 $\gamma$、$\gamma^2$：

$$G = 0.5 + 0.5\times 0 + 0.5^2\times 1.0 = 0.5 + 0 + 0.25 = 0.75.$$

远处的奖励不是不算，而是打折算——这就是第 60 课的几何级数直觉。

**第 2 问（TD 误差）**：目标由即时奖励加折算后的下一状态价值组成：

$$r + \gamma V(s') - V(s) = 0 + 0.5\times 0.25 - 0.75 = 0.125 - 0.75 = -0.625.$$

负号说明旧估计太乐观——正是第 78 手挖断之后发生的事。

**第 3 问（一次更新）**：新估计向目标方向拉一小步：

$$V_{new} = 0.75 + 0.5\times(-0.625) = 0.75 - 0.3125 = 0.4375.$$

注意一次更新只修正一部分：AlphaGo 从第 79 手撑到第 87 手才把估计修正过来，相当于价值网络用了多步才完成这次「改口」——小步修正、逐步逼近，正是第 130 课 TD 学习的样子。

</details>

## 实战挑战 · 火箭着陆的三笔账

火箭动力着陆和机器人控制一样，都是“现在的动作改变以后还能选什么”：早点强刹车费燃料，晚点刹车可能没有补救窗口。它还叠着一条通信功控约束——把电量花在下传遥测上，地面能更早诊断异常；但电量也是着陆控制的命脉。下面把这三件事压成一笔可手算的序贯决策账。

### 题目

某教学火箭的状态估计为 $V(s)=4$。接下来三步的即时评价是：

1. 低功率下传关键遥测：$r=2$；
2. 稳态下降：$r=-1$；
3. 最后一次反推着陆成功：$r=6$。

取 $\gamma=0.5$。另外，低功率遥测后进入的下一个状态真实价值为 $v_{next}=3$，旧估计 $V(s)=4$ 已经过时；学习率取 $\alpha=0.5$。

1. 这三步的折扣回报 $G$ 是多少？
2. 只看第一步遥测决策，TD 误差是多少？
3. 用 TD(0) 更新一次后的 $V(s)$ 是多少？
4. 若候选动作共 3 个、$\epsilon=0.3$，epsilon-greedy 给当前最优动作的总概率是多少？

```exercise
# @title: 实战挑战 · 遥测、下降与最后一推
# @check: 3.0
# @check: -0.5
# @check: 3.75
# @check: 0.8
# @hint: 折扣回报按 1、gamma、gamma 的平方加权；TD 目标是 r 加 gamma 乘 v_next；贪心概率等于利用份额加一份探索份额。
rewards = [2, -1, 6]   # 遥测、稳态下降、最后反推的即时评价
gamma = 0.5            # 折扣因子
v_old = 4              # 当前状态的旧价值估计
r = 2                  # 第一步低功率遥测的即时奖励
v_next = 3             # 下一个控制状态的真实价值
alpha = 0.5            # 学习率
n_actions = 3          # 候选动作数
epsilon = 30           # 总探索概率的百分数，对应 0.3

g = rewards[0] + rewards[1] + rewards[2]   # 学生需按折扣因子加权后两步
td = v_next - v_old                        # 学生需补上 r + gamma * v_next 作为目标
v_new = v_old                              # 学生需写成 v_old + alpha * td
greedy_prob = epsilon                      # 学生需改成利用份额加一份探索份额，再换回小数
print(g)
print(td)
print(v_new)
print(greedy_prob)
```

<details><summary>点开查看逐步解答</summary>

**折扣回报**：三步权重依次为 $1$、$\gamma$、$\gamma^2$：

$$G=2+0.5\times(-1)+0.25\times6=2-0.5+1.5=3.0.$$

**TD 目标**：第一步拿到遥测奖励 $r=2$，下一状态价值按 $\gamma=0.5$ 折回：

$$Y=r+\gamma v_{next}=2+0.5\times3=3.5.$$

**TD 误差**：目标比旧估计低，所以这次证据在提醒策略不要高估当前状态：

$$\delta=Y-V(s)=3.5-4=-0.5.$$

**一次更新**：只向目标移动一半距离，而不是直接改写为新目标：

$$V_{new}=V(s)+\alpha\delta=4+0.5\times(-0.5)=3.75.$$

**探索概率**：总探索份额 $\epsilon=0.3$ 平分给 3 个动作，每个得 $0.1$；贪心动作再加利用份额 $0.7$，所以是 $0.8$。

这个例子里通信功控不是额外装饰：若遥测奖励过高，策略会学会耗光电量刷数据；若过低，关键故障又可能传不回地面。奖励设计必须同时服务着陆安全和可诊断性。

</details>
