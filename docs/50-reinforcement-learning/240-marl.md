# 多智能体强化学习：一群学习者互相改变环境

## 1. 从一个场景开始

早高峰，导航软件给每个司机都推荐了"最快路线"。第一批人听劝绕进了那条小路，小路开始堵；软件看到小路变慢，又把后面的人劝回主路；主路因此更堵，于是又有人绕回小路……**每个司机都在根据路况学习，而路况正是所有司机的选择叠加出来的。**

这一课要处理的就是这个局面：环境里坐着的不只是物理规律，还有**别的学习者**。

## 2. 直觉解释

**第一层：单个智能体的世界观被打破了。** [Q-learning](./140-q-learning.md) 能收敛，靠的是一条隐含前提：环境是**平稳**的——$P(s'\mid s,a)$ 这张表不管过多久都一样。可是当对手也在学习时，从你的视角看，转移概率**每一轮都在变**（对手昨天爱出剪刀，今天爱出石头）。这叫**非平稳性**，它让"环境"变成了一个移动靶。

**第二层：非平稳的直接后果是"最佳回应在跑"。** 你的最优动作取决于对手的策略；对手的策略一改，你的最优动作立刻过期。猜拳就是极端例子：对手总出石头，你就该出布；他一发现，就改出剪刀；你再改出石头……**两支"最佳回应"互相追着跑，永不落地**。

**第三层：两条出路。** 一条是认了——干脆把对手当成环境的一部分，自己照常学，这叫**独立学习**（IQL）。它简单、能跑，但没有任何收敛保证，上面那个循环就是它会遇到的病。另一条是训练时给自己开"上帝视角"：训练阶段允许每个智能体看到全局状态、也允许用一个全局价值函数来打分，**执行阶段再退回去只用自己的局部观察做决策**——这就是**集中训练、分散执行**（CTDE）。"集中"解决的是**信用分配**（这一分团队奖励，到底算谁的功劳），"分散"保住的是部署时的现实约束（机器人之间不能实时共享全部信息）。

**第四层：三种关系，三套理论。** 队友（共享奖励）、对手（零和）、又敌又友（一般和）。合作时核心难题是信用分配；竞争时的解概念回到 [零和博弈与 minimax](../51-game-theory/25-zero-sum-minimax.md)；一般和时，稳定点要换成 Nash 均衡——而均衡本身在连续状态空间里就很难算。

## 3. 正式定义

多智能体场景的标准模型叫**马尔可夫博弈**（Markov game），$\langle N, S, \lbrace A_i\rbrace_{i\in N}, P, \lbrace R_i\rbrace_{i\in N}, \gamma\rangle$：

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $N=\lbrace1,\dots,n\rbrace$ | 智能体集合 | 一共几个学习者 |
| $s\in S$ | 全局状态 | 所有人共享的环境状态 |
| $a_i\in A_i$ | 第 $i$ 个智能体的动作 | 各自的选择 |
| $a=(a_1,\dots,a_n)\in A=\prod_i A_i$ | 联合动作 | 所有选择的组合，转移由它决定 |
| $P(s'\mid s,a)$ | 转移概率 | **依赖所有人的动作**——这是与单智能体 MDP 的第一处不同 |
| $R_i(s,a,s')$ | 各自奖励 | 每人一本账；合作时大家共用一本 |
| $\gamma$ | 折扣因子 | 同单智能体 |
| $\sigma_i:S\to\Delta(A_i)$ | 策略 | 通常还只能看到局部观察 $\tau_i$ |
| $V_i^{\sigma}(s)=\mathbb{E}\big[\sum_t\gamma^t R_i\big]$ | 各自的回报 | 注意上标 $\sigma=(\sigma_1,\dots,\sigma_n)$：**你的价值函数里装着所有人的策略** |

**非平稳性的形式化**：第 $i$ 个智能体眼中的有效转移是

$$P^{\,i}_{\sigma_{-i}^t}(s'\mid s,a_i)=\sum_{a_{-i}}\sigma_{-i}^t(a_{-i}\mid s)\,P(s'\mid s,(a_i,a_{-i})),$$

上标 $t$ 说明**这张表随训练轮次变化**。Q-learning 的收敛证明要求 Bellman 算子是一个固定的压缩映射；这里算子本身在动，证明的根基就没了。

**纳什均衡**：策略组合 $\sigma^*$ 满足对每个 $i$，$\sigma_i^*$ 都是对 $\sigma_{-i}^*$ 的最佳回应——没有人能单方面改策略让自己变好。单智能体 RL 的最优策略是"对固定世界最优"，多智能体的均衡是"对所有其他人最优"，后者的求解难度高得多。

**CTDE 与信用分配**：训练时用一个全局价值 $Q_{tot}(\tau,a)$，把它分解成每个智能体的贡献：

$$Q_{tot}(\tau,a)=f_\theta\big(Q_1(\tau_1,a_1),\dots,Q_n(\tau_n,a_n)\big),\qquad \text{执行时第 } i \text{ 个智能体只按 } Q_i \text{ 选动作}.$$

最朴素的分解是**加法**（VDN）：$Q_{tot}=\sum_i Q_i$；更强的是用一张以全局状态为输入的单调混合网络（QMIX），只要混合对每个 $Q_i$ 单调递增，全局最优的联合动作就等价于各人各选自己的 $Q_i$ 最大动作——这条性质叫 IGM，是 CTDE 能"训练看全局、执行只看局部"的理论依据。

## 4. 分步例题

**例一（手算）：匹配硬币里，两个独立学习者怎么把自己锁死。**

两个智能体各有两个动作：出正（H）或出反（T）。规则是"猜中对方的就算赢"：A 的收益矩阵（行=A 的动作，列=B 的动作）

$$A=\begin{bmatrix}+1 & -1\\ -1 & +1\end{bmatrix}\qquad(\text{B 的收益恰好取反，这是一个零和博弈}).$$

取 $\alpha=0.5$、$\gamma=0$（只看一步），双方 Q 表全从 $0$ 出发，且都按"账面最高分"贪心出招、平分时取 H。逐轮做**交替更新**（A 更新完，B 再更新）：

1. 第 1 轮 A 出 H、B 出 H，A 得 $+1$：$Q_A(H,H)\leftarrow 0+0.5(1-0)=0.5$；B 得 $-1$：$Q_B(H,H)\leftarrow -0.5$。
2. 第 2 轮：A 看账面 $Q_A(H,\cdot)=0.5>Q_A(T,\cdot)=0$，继续出 H；B 看 $Q_B(H,\cdot)=-0.5<Q_B(T,\cdot)=0$，改出 T。结果 $(H,T)$：A 得 $-1$，B 得 $+1$。更新得 $Q_A(H,T)=-0.5$、$Q_B(T,H)=0.5$。
3. 第 3 轮：A 依然出 H（$0.5$ 仍最高），B 依然出 T（$0.5$ 最高）。结果还是 $(H,T)$。更新得 $Q_A(H,T)=-0.75$、$Q_B(T,H)=0.75$。
4. **读结论**：从第 2 轮起 A 每轮都输，可它的账面照样指向前进的那一行——因为 $Q_A(H,\cdot)$ 的最大值是第 1 轮那段幸运经历留下的 $0.5$，而那是在"B 出 H"的旧环境里学到的。**每个 Q 值都在描述一个已经不存在的对手。**

第 4 条就是非平稳性的具体模样：不是收不收敛的哲学问题，而是**你的账本记录的是旧世界，你却拿它给新世界做决策**。真正破解这段锁死的办法有两个方向——自己加探索（把对方逼出固定套路），或者让对方也一起动（于是就有了循环）。

**例二（手算）：CTDE 怎么把一分团队奖励落到两个人头上。**

两个协作机器人共同完成任务，拿到团队奖励 $r=10$；当前各自的价值估计是 $Q_1=2$、$Q_2=6$。按 VDN 的加法分解，$Q_{tot}=Q_1+Q_2=8$。

1. 全局 TD 误差：$\delta=r-Q_{tot}=10-8=2$；
2. 取 $\alpha=0.25$，把同一个 $\delta$ 分给两个网络：$Q_1\leftarrow 2+0.25\times2=2.5$，$Q_2\leftarrow 6+0.25\times2=6.5$；
3. 新总分 $Q_{tot}=9$，更接近 $10$；两边的比例 $2.5:6.5$ 保持不变。

第 3 条既是加法分解的优点（账目守恒、好实现），也是它的短板：**它把团队奖励按既有比例摊派，而不是按"谁真正带来了增量"**。如果 $Q_1$ 一开始就偏小，它就会被长期低估，出现"出力的人和摸鱼的人分得一样多"的懒散智能体（lazy agent）。更精细的做法是反事实基线：把团队价值减去"别人不动、只换掉我的动作"后的平均价值，差额才算我的功劳——这条思路直接通向下面的 [合作博弈与 Shapley 值：功劳该怎么分](../51-game-theory/45-cooperative-shapley.md)。

## 5. 动手实验

### 实验 1（viz）：猜拳的收益矩阵为什么没有鞍点

行是你、列是对手，表里是你的得分。

```viz
{
  "type": "payoff-matrix",
  "title": "猜拳的零和收益矩阵：红色保底、蓝色封顶",
  "mode": "zero-sum",
  "rowNames": ["我出石头", "我出布", "我出剪刀"],
  "colNames": ["对手出石头", "对手出布", "对手出剪刀"],
  "payoff": [[0, -1, 1], [1, 0, -1], [-1, 1, 0]]
}
```

读图：每行最小值都是 $-1$（保底 $-1$），每列最大值都是 $+1$（封顶 $+1$），$-1<1$ ——**没有鞍点**。这说明任何固定出法都会被针对，所以均衡只能是随机的（为什么随机、按什么比例随机，是 [混合策略：把"随机"当成一种策略](../51-game-theory/22-mixed-strategy.md) 的主题）。而两个都靠贪心学习的智能体，正是绕在这道缝里循环。

### 实验 2（python）：独立学习为什么在零和博弈里打转

模拟两个独立 Q-learning 智能体玩猜拳。用固定种子的伪随机序列代替 `random` 库，保证每次跑出同一份结果：

```python
def random_list(seed, n):           # 线性同余发生器：从种子递推 n 个 0~1 的伪随机数
    out = []
    state = seed
    for _ in range(n):              # 下划线：循环变量用不到，只作计数占位
        state = (state * 1103515245 + 12345) % 2147483648
        out.append(state / 2147483648)
    return out

acts = ["R", "P", "S"]              # 石头 / 布 / 剪刀
beats = {"R": "S", "P": "R", "S": "P"}   # 谁克谁：出 R 能赢 S

def payoff(mine, theirs):           # 零和：赢 +1、输 -1、平 0
    if mine == theirs:
        return 0
    return 1 if beats[mine] == theirs else -1

def run(seed, rounds):              # 跑一场实验，返回终局片段与 A 的策略排序
    Q = {who: {a: {b: 0.0 for b in acts} for a in acts} for who in ["A", "B"]}
    last = {"A": "R", "B": "R"}     # 各自的"上一个动作"，用来猜对手
    rn = random_list(seed, 4 * rounds + 4)   # 每个智能体每轮用 2 个随机数，一次备好
    alpha, eps, tail = 0.3, 0.15, ""         # 学习率 / 探索概率 / 终局片段
    for t in range(rounds):
        picks = {}
        for idx, who in enumerate(["A", "B"]):  # A 用 rn[4t],rn[4t+1]；B 用 rn[4t+2],rn[4t+3]
            base = 4 * t + 2 * idx             # 两个智能体各用独立的随机数，避免同步探索
            if rn[base] < eps:                 # eps 概率随机探索
                picks[who] = acts[int(rn[base + 1] * 3)]
            else:                              # 否则贪心：挑账面最高的那一行
                picks[who] = max(acts, key=lambda a: Q[who][a][last[who]])
        a, b = picks["A"], picks["B"]
        ra, rb = payoff(a, b), payoff(b, a)          # 同一场的两个得分
        Q["A"][a][b] += alpha * (ra - Q["A"][a][b])  # 无折扣单步更新
        Q["B"][b][a] += alpha * (rb - Q["B"][b][a])
        last["A"], last["B"] = a, b
        tail = (tail + a + b)[-8:]                   # 只留最后 8 个字符（A B A B…）
    return tail, sorted(acts, key=lambda a: -max(Q["A"][a].values()))

print("种子 1 终局：", run(1, 400))
print("种子 7 终局：", run(7, 400))
```

两个种子跑出**不同的终局片段与不同的策略排序**，而且都没有落回某个稳定点——它们只是换了个姿势继续打转。这正是例一的循环：**两本账互相把对方写进了旧世界**。若是单智能体场景，同样的算法与同样的轮数早该安静下来了。

### 实验 3（python）：把对手冻住，账立刻就平了

只要让 B 的策略固定不动，A 的环境就恢复平稳，Q 值和策略都会迅速安静下来——这一半实验是"非平稳性才是病根"的对照：

```python
def run_frozen(seed, rounds, fixed_b):    # B 固定出 fixed_b，A 独立学习
    Qa = {a: {b: 0.0 for b in acts} for a in acts}
    rn = random_list(seed, 2 * rounds + 2)
    for t in range(rounds):
        if rn[2 * t] < 0.15:                                  # A 仍保留探索
            a = acts[int(rn[2 * t + 1] * 3)]
        else:
            a = max(acts, key=lambda x: Qa[x][fixed_b])       # 贪心：只看固定那一列
        r = payoff(a, fixed_b)
        Qa[a][fixed_b] += 0.3 * (r - Qa[a][fixed_b])
    return sorted(acts, key=lambda x: -Qa[x][fixed_b])

print("B 固定出布时 A 的排序：", run_frozen(7, 400, "P"))
print("B 固定出石头时 A 的排序：", run_frozen(7, 400, "R"))
```

对手一冻结，A 的账立刻就平了：对手固定出布时"剪刀"稳居第一，换成固定出石头则"布"稳居第一——**同一个算法、同一张收益表，只因为环境是否平稳，行为就完全两样**。这正是多智能体 RL 与单智能体 RL 的分水岭。

```quiz
多智能体强化学习里"非平稳性"指的是什么？
- 环境里的噪声太大，观测值抖动厉害
- 其他智能体也在学习，从我的视角看状态转移概率随训练轮次改变 [*]
- 奖励函数被写错了，导致目标不稳定
? 非平稳不是噪声，而是"环境里坐着别的学习者"：他们的策略在更新，我看到的有效转移 P(s'|s,a) 就跟着变。Q-learning 的收敛证明依赖固定的 Bellman 算子，算子一动就失去依据。
```

:::warning[常见误区]

**误区一**："你以为多智能体就是同时跑 $n$ 个单智能体程序。" 代码确实可以这么写，但**理论前提被换掉了**：单智能体的收敛保证全部建立在环境平稳之上。非平稳时不是"慢一点收敛"，而是可能永远打转（例一）。

**误区二**："你以为有了 CTDE，非平稳性就消失了。" CTDE 只是在**训练阶段**允许使用全局信息来算功劳；每个智能体执行时的价值 $Q_i$ 依然依赖别人的策略。它解决的是信用分配与信息约束的冲突，不是非平稳本身。而且分解还有额外要求：像 VDN 那样强行加法分解，会带来"按既有比例摊派"的偏差。

**误区三**："你以为共享奖励就等于团队一定学会合作。" 共享奖励只是把多本账合成一本，**信用分配**还得另做。分得不细，就会出现摸鱼搭便车的懒散智能体；分得太粗，又可能出现只会躲在后排刷分的"分数黑客"（回到 [奖励 hacking](./200-reward-hacking.md) 那一课的老问题）。

:::

## 6. 练习

**练习 1**（判题）：下面这段独立 Q-learning 的一步更新能跑，但更新错了格子——下标的内外层写反了，改到通过：

```exercise
# @title: 练习：独立 Q-learning 的一步更新
# @check: 0.3
# @check: 0.2
# @check: 0.1
# @hint: 外层下标是"我出的动作"，内层才是"对手的动作"。现在的 slot 取到了对手那一行的格子。
q_a = {"H": {"H": 0.2, "T": -0.4}, "T": {"H": 0.6, "T": 0.1}}   # A 的 Q 表
my_action, opp_action = "H", "T"    # 这一轮 A 出 H，对手出 T
r, alpha = 1.0, 0.5                 # 匹配成功，A 拿到 +1；学习率 0.5

slot = q_a[opp_action][my_action]   # ← 问题在这：内外层下标反了
q_a[my_action][opp_action] = slot + alpha * (r - slot)   # 单步更新：向目标 r 靠近

print(round(q_a["H"]["T"], 1))
print(round(q_a["H"]["H"], 1))
print(round(q_a["T"]["T"], 1))
```

修好后 $Q_A(H,T)$ 从 $-0.4$ 更新到 $0.3$，其余两格不动。**更新完再贪心一眼**：A 出 H 的账面最高是 $0.3$、出 T 是 $0.6$，所以下一步 A 会改出 T——而这一步正是"对手出 T"的旧世界教给它的。

**练习 2**（概念）：为什么说 IQL（独立学习）"能跑但没保证"？它简洁在哪、又缺了什么？

<details>
<summary>点开查看逐步解答</summary>

**简洁之处**：不用建模别人的策略、不用共享信息、不用设计价值分解，把对手当成会动的那部分环境就行。工程上极其容易起步，很多实际系统就是从 IQL 起步的。

**缺的是什么**：收敛保证。单智能体 Q-learning 的收敛定理要求 Bellman 最优算子是固定的压缩映射；IQL 里每个智能体用的目标 $r+\gamma\max_{a_i'}Q_i(s',a_i')$ 中，$s'$ 的分布由别人的策略决定，而别人的策略正在更新，于是算子随轮次变化。所以 IQL 常常"看起来在学、其实在追影子"，表现为策略周期性轮转（例一的猜拳循环）或收敛到某个依赖于初始化与学习率的怪点。

**工程上的折中**：给对手加"记忆"（把最近的对手动作放进观测，让环境"看起来"更平稳）、用 CTDE 做信用分配、或者干脆换个算法家族（比如基于策略的自我对弈）。**说到底都是同一件事：把别人的变化搬进我能观察到的地方，或者搬进训练阶段。**

</details>

<details>
<summary>选读 · 压缩映射为什么会失效，均衡概念怎么升级</summary>

**一、压缩映射为什么失效。** 单智能体 Q 迭代可以写成 $Q_{k+1}=\mathcal{T}Q_k$，其中 $\mathcal{T}$ 是 Bellman 最优算子，满足 $\|\mathcal{T}Q-\mathcal{T}Q'\|_\infty\le\gamma\|Q-Q'\|_\infty$——这一条不等式保证迭代收敛到唯一不动点。多智能体里，每个智能体的目标是把别人固定住才定义的，写成 $\mathcal{T}^{\,i}_{\sigma_{-i}}$。当 $\sigma_{-i}$ 也在更新时，序列变成 $Q_{k+1}=\mathcal{T}^{\,i}_{\sigma_{-i}^k}Q_k$，算子列不固定，Banach 不动点定理的前提（同一个算子）不成立。这不代表"一定发散"，而是"没有保证"。

**二、从最优策略到均衡。** 单智能体 RL 的答案是"最优策略"，多智能体里这个概念不存在（除非把别人写进状态）。合作情形可以把团队总回报当标量目标，退化成单智能体问题（这也是 CTDE 能在合作场景大放异彩的原因）；竞争与一般和情形则要解 Nash 均衡——在有限博弈里存在性由 [纳什均衡](../51-game-theory/20-nash-equilibrium.md) 保证，但计算属于 PPAD 类，且"多个均衡时选哪个"没有答案。此外还有更弱的解概念：相关均衡（允许用公共随机信号协调）、粗相关均衡（只要求不被单个动作的偏离改进），后者既更易计算，也和多智能体学习的实际收敛点更接近。

**三、一条工程经验。** 绝大多数能跑起来的多智能体系统，都不靠"证明收敛"，而靠**把非平稳性压到可接受范围**：中心化训练、对手建模、经验回放里保留不同时代的样本、参数共享、以及最重要的——**限制同时变化的变量个数**。
