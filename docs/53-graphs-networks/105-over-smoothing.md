# 多层 GNN 与过平滑

## 1. 开场钩子

直觉上，层数越多，模型越强。图网络却常常相反：堆太多层后，所有节点反复平均邻居，特征越来越像，分类边界反而糊掉。

这就是过平滑。它不是训练失败，而是重复传播的结构后果。

## 2. 直觉解释

链形三个节点的特征从 `[1, 2, 3]` 开始。做一次“自身加邻居的平均”，得到：

$$[1.5,\ 2.0,\ 2.5].$$

再做一次：

$$[1.75,\ 2.0,\ 2.25].$$

范围从 2 缩到 0.5。层数继续增加，差异会继续缩小；远处的信息确实传来了，但局部身份也被抹掉了。

## 3. 正式定义

对含自环的行归一化传播矩阵 $S$，多层无非线性模型可写成

$$H^{(k)}=S^kH^{(0)}.$$

若 $S$ 满足合适的遍历条件，则当 $k\to\infty$ 时，$S^kH^{(0)}$ 的行会趋向同一个由结构决定的向量。节点表示的方差随之下降。

常用诊断是相邻层特征变化或成对余弦相似度：

$$\text{smoothness}=\frac{1}{n}\sum_v\lVert h_v^{(k)}-h_v^{(k-1)}\rVert.$$

## 4. 分步例题

链形图 $A-B-C$ 使用含自环的平均聚合。

1. 初始：`[1, 2, 3]`；
2. 一层后 A 为 $(1+2)/2=1.5$，B 为 $(1+2+3)/3=2$，C 为 $(2+3)/2=2.5$；
3. 二层后 A 为 $(1.5+2)/2=1.75$，B 为 $(1.5+2+2.5)/3=2$，C 为 $(2+2.5)/2=2.25$；
4. 最大减最小从 2 变成 0.5。

## 5. 动手实验

### 实验 1（lab）：一层一层加，看节点怎么糊成一片

课程代码把 6 层的极差打印成表。下面这张卡把它做成一步步可以按的过程——**每按一次「加一层」就再做一次含自环的平均**，图上的数字、特征柱、两条诊断曲线同时更新：

```lab
{
  "type": "g53-smoothing-layers",
  "title": "多层平均把三个特征磨成同一个数",
  "nodes": ["A", "B", "C"],
  "edges": [[0, 1], [1, 2]],
  "h": [1, 2, 3]
}
```

从第 0 层的 `[1, 2, 3]` 开始连点 `加一层`，读数是 $1.5/2/2.5\to1.75/2/2.25\to1.875/2/2.125\to\cdots$，极差 $2\to1\to0.5\to0.25\to0.125$，**每层正好减半**。第 6 层已经缩到 $0.0313$，第 10 层只剩 $0.002$（$2/2^k$，每层除以 2）——图上三个数写到小数点后三位就是 `1.999 / 2.000 / 2.001`，肉眼再也分不开。这就是过平滑：**再堆层，网络学不到新东西了**。

右上那条红线是极差、右边那条蓝线是相邻层变化（$\text{smoothness}=(1/n)\sum_v|h_v^{(k)}-h_v^{(k-1)}|$）。两条形状几乎一样，都在指数下滑——它们其实是同一件事的两种量法。

再点 `打乱初始分配`：把起点翻成 `[3, 2, 1]`。第 10 层的极限方向还是 `0.333 : 0.333 : 0.334`，和原来一模一样——**极限由结构决定，与起点无关**，正文「$S^kH^{(0)}$ 的行会趋向同一个由结构决定的向量」说的正是这件事。点 `换一组特征` 换成更歪的起点 `[0, 5, 7.5]`：收敛过程更长，但终点还是那一组数。

### 实验 2（python）：把每层极差打成一行

下面代码最多传播 6 层并输出每层的极差。把层数调大、改图或改初始特征，观察差异收缩速度。

```python title="观察多层平均导致的过平滑"
H = [1.0, 2.0, 3.0]          # 初始节点特征
neighborhoods = [
    [0, 1],                   # A 的自环和唯一邻居 B
    [0, 1, 2],                # B 的自环和两个邻居
    [1, 2],                   # C 的邻居 B 和自环
]
max_layers = 6               # 层数上限：避免无限传播

initial_range = sorted(H)[-1] - sorted(H)[0] # 排序后取最大减最小
print(0, H, round(initial_range, 3))
for layer in range(1, max_layers + 1):
    nxt = []
    for i in range(len(neighborhoods)):
        total = 0.0
        for j in neighborhoods[i]:
            total += H[j] / len(neighborhoods[i]) # 含自身的普通平均聚合
        nxt.append(total)
    H = nxt
    current_range = sorted(H)[-1] - sorted(H)[0]
    print(layer, [round(value, 3) for value in H], round(current_range, 3))
```

工程上可用残差连接、门控自环、JK 聚合或更少层数缓解，但没有万能解。

## 6. 常见误区

:::warning[常见误区]

**误区一**：你把过拟合和过平滑混为一谈。前者训练好测试差，后者可能连训练表示都失去区分度。

**误区二**：你以为加深一定无用。配合残差、正则和任务设计，深层图模型仍可受益。

**误区三**：只看准确率。特征方差、邻居分布和同质化速度更能定位问题。

:::

## 8. 设计边界

过平滑说明感受野不是免费的。选择层数要同时考虑图的直径、任务需要多远的上下文、标签数量和特征噪声。深图模型应报告层数、传播矩阵和同质化指标。

## 9. 选读：极限为什么一定是全图平均

<details>
<summary>选读 · 从"越变越像"到"像成什么"</summary>

正文只说了"行会趋向同一个向量"，这里把那个向量算出来。

设传播矩阵 $S$ 是**双随机**的（行和、列和都为 1，含自环的对称归一化在正则图上就是这种），$\vec 1$ 是常数向量。显然 $S\vec 1=\vec 1$，所以 $\lambda_1=1$ 永远是一个特征值，$\vec 1$ 是它的特征向量。把初始特征按特征向量展开 $H^{(0)}=\sum_i c_i\vec v_i$，则

$$H^{(k)}=S^kH^{(0)}=\sum_i c_i\lambda_i^k\vec v_i\ \xrightarrow{k\to\infty}\ c_1\vec 1.$$

只要 $|\lambda_i|<1$（$i\ge2$），其余项全部衰减到零，极限就是常数向量——局部身份全部丢失，只剩**一个数**。那个数是多少？设 $\vec\pi$ 是 $S$ 的左平稳分布（$\vec\pi^{\top}S=\vec\pi^{\top}$，$\sum_i\pi_i=1$），则 $\vec\pi^{\top}H^{(k)}=\vec\pi^{\top}H^{(0)}$ 在每一步都成立，而 $H^{(k)}\to c\vec 1$，取内积即得 $c=\vec\pi^{\top}H^{(0)}$——**极限是初始特征的 $\vec\pi$ 加权平均**。衰减速度由 $|\lambda_2|$ 决定：它越接近 1，越难糊。

**实跑对账**：链 $A-B-C$ 上让 $S$ 的每一行取「自身 + 邻居」的平均，即第 1 行 $(1/2,1/2,0)$、第 2 行 $(1/3,1/3,1/3)$、第 3 行 $(0,1/2,1/2)$。它的左平稳分布是 $\vec\pi=(2/7,\ 3/7,\ 2/7)$——正好正比于加自环后的度 $(2,3,2)$，中间那个节点权重最大。三个特征值是 $1,\ 0.5,\ -0.167$，$|\lambda_2|=0.5$，每层把残差砍一半（负的第三特征值让抖动逐层反号地衰减）。

| 初值 $H^{(0)}$ | 第 2 层 | 第 5 层 | 第 10 层 | 极限 | $\vec\pi^{\top}H^{(0)}$ | 算术平均 |
| --- | --- | --- | --- | --- | --- | --- |
| $[1,2,3]$ | $[1.75,\ 2,\ 2.25]$ | $[1.969,\ 2,\ 2.031]$ | $[1.999,\ 2,\ 2.001]$ | $2$ | $2$ | $2$ |
| $[0,0,1]$ | $[0.167,\ 0.278,\ 0.417]$ | $[0.270,\ 0.286,\ 0.301]$ | $[0.2852,\ 0.2857,\ 0.2862]$ | $0.2857$ | $0.2857$ | $0.3333$ |

第一行两种平均**碰巧**相等（$1,2,3$ 关于 $2$ 对称）；第二行立刻露馅：极限是 $2/7\approx0.286$，不是 $1/3$。所以「过平滑把特征抹成平均值」这句要带定语——抹成的是**度加权**平均，不是算术平均。

**边界**：只有 $S$ **双随机**（行和列和都为 1，例如正则图上的对称归一化）时，$\vec\pi$ 才是均匀分布，两种平均才重合。图一旦度不均匀（真实网络的常态），低度节点在极限里的权重就被压小——它们的信息不只是被抹平，而是被**系统性压低**。

</details>
