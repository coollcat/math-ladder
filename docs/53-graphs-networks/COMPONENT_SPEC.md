# 第 53 章 · 图网络组件规格

> 状态：**未来组件设计稿，尚未实现。** 本文件只服务后续 `src/pyrunner/viz.js` 开发；第 53 章正式课当前不得引用这些 type。

## 0. 全局硬性约束

1. **图必须支持节点拖拽**：所有会绘制图结构的组件都要允许按住节点圆心修改其画布内 `x/y`。拖拽只改变布局坐标，不改变边集、权重或计算结果；释放后要保留位置直到重置。
2. **矩阵必须支持行列联动高亮**：所有会渲染矩阵的组件都要满足：
   - 悬停或键盘聚焦矩阵格子 `(i,j)` 时，高亮行 `i`、列 `j`，并在图上同时高亮对应有向关系；
   - 悬停或键盘聚焦图节点时，高亮矩阵对应行列；
   - 高亮状态必须有非颜色冗余（加粗描边、文字标签或焦点框），不能只靠色觉传达；
   - 触屏需要点选切换模式，不能只依赖 hover。
3. 组件继续遵守现有 viz 架构：
   - JSON 配置可被 `scripts/validate.mjs` 解析；
   - 渲染容器挂载在原生 code block 后方，不删除 React 节点；
   - 使用 `dataset` 防止 MutationObserver 重复绑定；
   - 支持暗色主题和移动端缩放，不产生横向滚动。
4. 所有动画、模拟和迭代都有上限，并提供“暂停 / 重置”。随机实验接受固定 `seed`。
5. 不使用 `input()` 或 `while True`；不引入新的 Python 运行时依赖。

## 1. `adjacency-matrix-lightup`

### 教学目标

让读者把边表、图和邻接矩阵看成同一对象的三种投影。

### 建议配置

```json
{
  "type": "adjacency-matrix-lightup",
  "title": "点亮邻接关系",
  "nodes": ["A", "B", "C", "D"],
  "edges": [[0, 1], [0, 2], [1, 3]],
  "directed": false,
  "seedLayout": [[40, 60], [180, 40], [80, 160], [220, 150]]
}
```

### 必备交互

- 图节点可拖拽，边实时跟随端点。
- 点击无向边可在矩阵 `(i,j)` 与 `(j,i)` 两格同时点亮；有向边只点亮单格。
- 矩阵格子和图边互为焦点目标。
- 提供“显示度数”开关：图上显示节点度，矩阵旁显示行和。
- 提供至少一个错误示例开关，例如缺少反向格，让学生识别有向化错误。

### 判定标准

- 四节点示例中，三条无向边应在矩阵中形成六个 1。
- 行列联动高亮的 DOM 焦点顺序稳定。
- 拖拽任一节点后，矩阵数值不变。

## 2. `graph-layout-dragger`

### 教学目标

证明基础图的几何本质由连接决定，而不是坐标。

### 建议配置

```json
{
  "type": "graph-layout-dragger",
  "title": "同一张图的不同画法",
  "nodes": ["首页", "商品", "帮助", "购物车"],
  "edges": [[0, 1], [0, 2], [1, 3], [2, 3]],
  "showDegrees": true
}
```

### 必备交互

- 每个节点都能独立拖拽 `x/y`。
- “打乱布局”只重排坐标；“重置布局”回到初始坐标。
- 可切换显示度数、邻接表和邻接矩阵。
- 若显示矩阵，必须满足全局行列联动规则。

### 判定标准

- 打乱后度序列保持不变。
- 删除一条边时，图和矩阵同步更新。
- 键盘用户可以用方向键移动选中节点至少一个像素步长。

## 3. `laplacian-spectrum-layout`

### 教学目标

展示 Laplacian 特征值与 Fiedler 向量如何给出切割证据和一维谱布局。

### 建议配置

```json
{
  "type": "laplacian-spectrum-layout",
  "title": "第二小特征值指出裂缝",
  "nodes": ["A", "B", "C", "D", "E", "F"],
  "edges": [[0, 1], [1, 2], [0, 2], [3, 4], [4, 5], [3, 5], [2, 3]],
  "normalization": "combinatorial",
  "vectorIndex": 1,
  "threshold": 0
}
```

### 必备交互

- 图节点可拖拽；谱坐标用节点右侧的短条表示，拖拽不改特征向量。
- 可选择 `combinatorial`、`random-walk`、`symmetric` 三种归一化。
- 特征值条形图可点击；点击后图按对应特征向量着色。
- Fiedler 向量阈值滑块实时改变正负分组，并统计切边数和组大小。
- 显示邻接矩阵或 Laplacian 时，行列联动高亮必须生效。

### 数值边界

- 浮点零用可配置 epsilon 判断，默认 `1e-10`。
- 重根附近的方向不稳定，UI 要提示“方向仅作结构证据”。
- 不同归一化的特征值不能直接横向比较。

### 判定标准

- 双三角默认示例的特征值约为 `[0, 0.438, 3, 3, 3, 4.562]`。
- 默认阈值为 0 时，分组是 `{0,1,2}` 和 `{3,4,5}`，切边数为 1。
- 删除桥后，次小特征值变为 0，且连通分量数变为 2。

## 4. `random-walk-particles`

### 教学目标

让转移概率、局部社区停留和长期频率可见。

### 建议配置

```json
{
  "type": "random-walk-particles",
  "title": "粒子在哪里停留",
  "nodes": ["A", "B", "C", "D"],
  "edges": [[0, 1], [1, 2], [2, 3], [3, 1]],
  "particles": 24,
  "stepsPerFrame": 1,
  "maxSteps": 600,
  "seed": 7
}
```

### 必备交互

- 图节点可拖拽，粒子和边跟随新坐标。
- 可调整粒子数、步速和最大步数；到达上限自动暂停。
- 固定种子输入；相同 seed、步数和起点必须得到相同访问计数。
- 每个节点显示当前人数和历史频率。
- 若渲染转移矩阵，悬停格子 `(i,j)` 时高亮该有向概率边。

### 判定标准

- 到达 `maxSteps` 后不再消耗 CPU。
- 重置会清空历史计数并恢复初始粒子分布。
- 相同 seed 下两次运行的历史频率一致。

## 5. `pagerank-flow`

### 教学目标

把阻尼拆成“沿链接流动”和“均匀 teleport”两股流量。

### 建议配置

```json
{
  "type": "pagerank-flow",
  "title": "链接流加传送流",
  "nodes": ["A", "B", "C"],
  "edges": [
    {"from": 0, "to": 1},
    {"from": 0, "to": 2},
    {"from": 1, "to": 2},
    {"from": 2, "to": 0}
  ],
  "damping": 0.85,
  "iterations": 100,
  "tolerance": 1e-12
}
```

### 必备交互

- 图节点可拖拽；节点半径映射 PageRank，出边宽度映射流量。
- 阻尼滑块范围建议 `0..0.99`，迭代上限固定且可调。
- 分层显示两种颜色：链接流和 teleport 流；图例不能只靠颜色。
- 可查看纯链接矩阵 $M$ 或 Google 矩阵 $G$；矩阵必须行列联动高亮。
- 每次更新显示残差、当前迭代数和总分是否为 1。

### 判定标准

- 三页示例在 `damping=0.85` 时收敛值应与课程幂迭代一致。
- 孤立节点不会导致 NaN；teleport 给它正分。
- `damping=0` 时三节点分数均为三分之一。

## 6. `gnn-message-passing`

### 教学目标

逐层展示邻居聚合、自环和归一化对节点表示的影响，并预警过平滑。

### 建议配置

```json
{
  "type": "gnn-message-passing",
  "title": "消息如何逐层扩散",
  "nodes": ["A", "B", "C", "D"],
  "edges": [[0, 1], [1, 2], [2, 3]],
  "features": [[1], [2], [3], [4]],
  "layers": 2,
  "aggregation": "mean",
  "selfLoop": true,
  "normalization": "symmetric"
}
```

### 必备交互

- 图节点可拖拽；节点颜色映射一维或二维特征。
- 层数滑块范围 `0..6`；播放器每层暂停一次，最多播放到配置层数。
- 可切换求和、平均、对称归一化三种聚合。
- 自环开关必须即时生效，并解释旧特征是否参与下一层。
- 若显示 $\tilde A$、$\tilde D^{-1}\tilde A$ 或 $\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$，必须行列联动高亮。
- 输出相邻层极差、平均成对余弦相似度和最大差异节点，帮助观察过平滑。

### 判定标准

- 三节点链形图、全 1 特征、两层对称归一化时，结果应能复现 `[0.908, 1.15, 0.908]` 的单层中间值逻辑。
- 关闭自环后，低度节点在多层传播中更容易丢失自身信息。
- 六层上限到达后自动停止。

## 7. 实现顺序建议

1. 先做一个共享 `GraphMatrixLab` 内部工具，统一节点拖拽、矩阵联动、焦点管理和主题样式。
2. 实现 `adjacency-matrix-lightup` 和 `graph-layout-dragger`，验证共享工具。
3. 实现 `laplacian-spectrum-layout`，接入纯 JavaScript 对称矩阵特征分解或预计算数据。
4. 实现 `random-walk-particles` 与 `pagerank-flow`，共用有限迭代器和 seed 工具。
5. 最后实现 `gnn-message-passing`，复用矩阵归一化和图层回放。
