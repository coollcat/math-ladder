# 图上的随机游走

## 1. 开场钩子

一个读者在知识图谱里随机点链接：在热门概念旁停留更久，还是被长链拖去冷门角落？单步无法预测，但几百个有上限的模拟步会显出稳定形状。

随机游走把图结构翻译成“时间都花在哪里”。

## 2. 直觉解释

规则很简单：站在一个节点，等概率选一条出边走过去。城市里的人随机换乘，网页冲浪者随机点超链接，蛋白质网络中的信号随机传给结合伙伴。

短时间结果依赖起点；长时间访问频率往往由结构决定。社区像一个浅盆，游走者容易留在里面。

## 3. 正式定义

设列随机矩阵 $P$ 的第 $j$ 列是从节点 $j$ 出发的分布。若当前位置为 $X_t$，则

$$\Pr(X_{t+1}=i\mid X_t=j)=P_{ij}.$$

$k$ 步后：

$$\vec p_k=P^k\vec p_0.$$

本课模拟都会设置固定种子和最大步数，保证实验可复现且不会无限运行。

## 4. 分步例题

四节点链 $A-B-C-D$ 的列随机矩阵为

$$P=\begin{pmatrix}0&0.5&0&0\\1&0&0.5&0\\0&0.5&0&1\\0&0&0.5&0\end{pmatrix}.$$

从 A 出发：

1. 一步后必到 B；
2. 两步后一半回 A、一半到 C；
3. 所以 $P^2\vec e_A=(0.5,0,0.5,0)$。

### 实验 1（lab）：走 400 步，频率自己贴到平稳分布

下面这张卡把课程最后那段代码做成了可以反复按的实验：三角形带一条尾巴到节点 3，固定种子 7，从节点 0 出发。

```lab

  "title": "三角形带尾巴：访问频率如何逼近平稳分布",
  "nodes": ["0", "1", "2", "3"],
  "edges": [[0, 1], [1, 2], [0, 2], [1, 3]],
  "seed": 7,
  "steps": 400
}
```

点 `再走 400 步`。右边四根柱子是实际到访频率，橙色横线是理论平稳分布 $\pi_i=d_i/\sum d$，也就是 $(0.25,0.375,0.25,0.125)$。走满 400 步时两者已经贴得很近；再走 400 步，柱子几乎不动了——**长跑抹掉起点**，这就是正文说的「长期频率由整个结构共同决定」。

注意节点 3：它只有一条边，$\pi_3$ 只有 0.125，是最少被访问的点，尽管它是唯一「没有选择」的节点。点 `换个起点` 从节点 3 出发再跑一遍，柱子还是一样——起点只影响开头几十步。

底部那个「总变差距离」是频率与 $\pi$ 的差距，一个数收口：刚走几步时它很大，走几百步后掉到 0.05 以下。最后点 `重置（同一种子）`，连点两次确认结果一模一样——**固定种子**是可复现的前提。

### 实验 2（viz）：最小的两节点游走

先看最小的两节点游走：拖动留守概率和幂次，观察一步位置如何变成长期节奏。

```viz
{
  "type": "matrix-power",
  "title": "两节点游走的重复转移",
  "pAA": 0.2,
  "pBB": 0.7,
  "power": 8
}
```

下面代码在同一个无向三角形加尾巴的图上游走。种子固定为 7，步数最多 400。你可以改起点或步数，但保留 `random.seed` 和 `for` 上限。

```python title="有种子、有上限的随机游走"
import random # random 模块生成可复现伪随机数

neighbors = {
    0: [1, 2],
    1: [0, 2, 3],
    2: [0, 1],
    3: [1],
}
start = 0
max_steps = 400          # 游走上限：防止浏览器卡住
random.seed(7)           # 固定随机序列，让每次输出相同

position = start
visits = {node: 0 for node in neighbors}
for step in range(max_steps):   # 只允许有限步
    visits[position] += 1       # 先记录当前站
    position = random.choice(neighbors[position]) # choice 从邻居中等概率选一个

total = sum(visits.values())
frequencies = {node: round(count / total, 3) for node, count in visits.items()}
print(visits)
print(frequencies)
```

节点 3 只有唯一出口，却不是最常访问点；长期频率由整个结构共同决定。

## 6. 常见误区

:::warning[常见误区]

**误区一**：你以为一次模拟就是概率。要固定种子重复足够多步，并报告不确定性。

**误区二**：你以为度高的节点一定频率最高。还要看它连向谁以及是否处在死胡同式结构里。

**误区三**：你以为无界循环没问题。课程代码必须用有限步数；真实工程也要设超时。

:::

## 8. 模拟边界

有限模拟有两个误差来源：随机波动和未到达的远区。报告结论时应说明种子、步数和起点；比较算法时要用同一套设置。

## 9. 选读：400 步够不够

<details>
<summary>选读 · 用二项分布算出模拟误差的量级</summary>

课程里说「比较算法时要用同一套设置」，这句话可以算得更细。跑到 400 步后，某个节点被访问的次数近似服从二项分布 $B(N,\pi_v)$（游走前后强相关，这只是一个**偏乐观**的近似），于是频率的标准差至少是

$$\sqrt{\frac{\pi_v(1-\pi_v)}{N}}.$$

把课程实验的 $N=400$ 和结构给出的长期频率 $\pi=0.375$（度数最高的那个节点，3/8）代进去：$\sqrt{0.375\times0.625/400}\approx0.024$。也就是说，**模拟 400 步，频率的抖动不可能小于 2% 量级**——真实抖动还要更大，因为相邻两步高度相关，有效样本数远少于 400。所以任何比这更小的差异都不该被当成结构信号，反过来，一个 5% 的差异也未必站得住。

想把误差压到一个百分点，$N$ 得涨到 $\pi(1-\pi)/0.01^2\approx2344$——误差按 $1/\sqrt N$ 缩小，成本却按 $N$ 涨，这是蒙特卡洛的固有交换比。

所以「再走 100 步」看到的频率变化，有多少是收敛、有多少是抖动，取决于这个量级。真要比较两套参数，正确做法是**固定种子、跑多次、比较均值**，而不是把一次 400 步的结果当成真值。

</details>
