# 消息传递

## 1. 开场钩子

谣言扩散、交通调度和蛋白质结合预测都有一个共同动作：每个节点先听邻居说话，再更新自己的状态。图神经网络把这个动作抽象成消息传递。

这一课先不谈训练，只看一层传播到底做了什么。

## 2. 直觉解释

一个节点的下一状态通常由三件事决定：

1. 自己当前的特征；
2. 从邻居收集来的消息；
3. 一个更新函数。

聚合方式可以是求和、平均或最大值。平均对度数不敏感，求和保留规模，最大值只抓最强信号。

## 3. 正式定义

设节点 $v$ 在第 $l$ 层的特征为 $\vec h_v^{(l)}$，邻居集合为 $N(v)$。消息传递可写成

$$\vec m_v^{(l+1)}=\text{AGG}_{u\in N(v)}\left(\vec h_u^{(l)}\right),$$

$$\vec h_v^{(l+1)}=\text{UPDATE}\left(\vec h_v^{(l)},\vec m_v^{(l+1)}\right).$$

若用平均聚合：

$$\vec m_v=\frac{1}{|N(v)|}\sum_{u\in N(v)}\vec h_u.$$

## 4. 分步例题

星形图中中心 C 的三个叶子特征分别是 $(1,0)$、$(0,1)$、$(1,1)$；中心自身是 $(4,0)$。

1. 若只聚合邻居，C 收到的平均消息是 $((1+0+1)/3,(0+1+1)/3)=(2/3,2/3)$；
2. 任一叶子只收到 C 的消息 $(4,0)$；
3. 若更新时把自身也平均进来（自环让 C 的邻居变成 4 个），结果是 $((4+1+0+1)/4,(0+0+1+1)/4)=(3/2,1/2)$；
4. 是否包含自环是建模选择，会明显改变结果。

## 5. 动手实验

### 实验 1（lab）：一层一层地听邻居说话

```lab
{
  "type": "graph-message-passing",
  "title": "逐层邻居聚合：同一层内先用旧特征算完，再整体换新",
  "mode": "message",
  "aggregation": "mean",
  "selfLoop": true
}
```

按下「单步」：小点沿箭头把**上一层**的特征送出去，节点这才换成新值——一层之内不会边算边覆盖（这正是"误区一"的现场）。「播放」自动连走多层，右侧矩阵是这一层实际使用的聚合器，悬停节点或矩阵格子会联动点亮行列与边。切换 SUM / MEAN / MAX：强度爆炸、度归一、只留最强信号，三种语义立刻分家；再关掉自环，看 D（没有入邻居）怎样只剩一个零向量。把层数一点点走上去，"最大变化"会越来越小、各节点的向量开始互相靠拢——那就是过平滑的现场。

### 实验 2（python）：只听邻居 vs 把自己也算进邻居

下面代码比较“只听邻居”与“把自己也算进邻居”。修改特征后观察两种语义的差别。

```python title="一层平均消息传递"
features = {
    "C": [4, 0],
    "L1": [1, 0],
    "L2": [0, 1],
    "L3": [1, 1],
}
neighbors = {
    "C": ["L1", "L2", "L3"],
    "L1": ["C"],
    "L2": ["C"],
    "L3": ["C"],
}

aggregate_only = {}
for node, neigh in neighbors.items():
    sums = [0.0, 0.0]
    for friend in neigh:
        sums[0] += features[friend][0] # 累加第一维消息
        sums[1] += features[friend][1]
    aggregate_only[node] = [
        value / len(neigh) for value in sums # 除以邻居数得到平均
    ]

print({node: [round(x, 3) for x in vec] for node, vec in aggregate_only.items()})
```

真实 GNN 还会在聚合后套权重矩阵和非线性函数；但结构信息已经在这张表里流动了一次。

## 6. 常见误区

:::warning[常见误区]

**误区一**：你以为所有节点同时收到新消息。一层内要用旧特征计算，不能边算边覆盖。

**误区二**：你以为平均和求和可以随意互换。它们对节点度和特征尺度的影响不同。

**误区三**：你忘记方向。有向图中入邻居和出邻居代表完全不同的信息来源。

:::

## 7. 练习

```exercise
# @title: 练习：计算纯邻居平均
# @check: {'C': [2.0, 2.0], 'L1': [4.0, 0.0], 'L2': [4.0, 0.0], 'L3': [4.0, 0.0]}
# @hint: 每个节点只平均邻居列表里的旧特征；输出要保留全部原始节点键名。
features = {
    "C": [4, 0],
    "L1": [1, 2],
    "L2": [2, 3],
    "L3": [3, 1],
}
neighbors = {
    "C": ["L1", "L2", "L3"],
    "L1": ["C"],
    "L2": ["C"],
    "L3": ["C"],
}

aggregated = {}
for node, neigh in neighbors.items():
    aggregated[node] = features[node] # 错误：把自身原样放进结果

print(aggregated)
```

<details>
<summary>点开查看逐步解答</summary>

C 的三条邻居消息是 `(1,2)`、`(2,3)`、`(3,1)`，平均后是 `(2,2)`。

每个叶子只有邻居 C，所以平均后是 `(4,0)`。输出应为 `{'C': [2.0, 2.0], 'L1': [4.0, 0.0], 'L2': [4.0, 0.0], 'L3': [4.0, 0.0]}`。

## 8. 表达边界

一维 Weisfeiler-Lehman 视角说明：普通消息传递难以区分某些规则对称结构。加权重、边特征、位置编码和高阶关系可以增强表达，但也增加数据和计算成本。

## 9. 选读：为什么有的图，消息传递永远分不开

<details>
<summary>选读 · 1-WL 测试与六边形反例</summary>

正文提到「普通消息传递难以区分某些规则对称结构」。这句话可以举出一个**最小的具体例子**。

取两个都是 6 个节点、每个节点度都是 2 的图：

- **$C_6$**：一个六边形，一条首尾相接的环；
- **$2C_3$**：两个分开的三角形，各自独立。

它们的度序列完全一样（全是 2），节点数、边数也一样。现在让所有节点的初始特征都取同一个值，跑一遍消息传递：每个节点的邻居特征集合还是同一个东西，于是**下一层所有节点依旧全相等**；再跑一层，还是如此。跑多少层都分不开。

这不是实现问题，而是一条结构性的上界。消息传递（等价于 1 维 Weisfeiler–Lehman 测试）能看到的只有**邻居特征的直方图**：在一个所有节点都同构的图里，任何一层读到的直方图都相同，所以两个图在它眼里是同一个东西。

但是 $C_6$ 和 $2C_3$ 一眼就能分：前者连通，后者有两个连通分量。**这个差别消息传递看不见，谱方法一眼就能看见**——$2C_3$ 的 Laplacian 有两个 0 特征值，$C_6$ 只有一个。这也正是本章为什么先讲 Laplacian 再讲 GNN：前者看全局结构，后者看局部聚合。

要突破这个上界，就得给模型**额外的信息**：节点的位置编码、边特征、高阶子结构、或者干脆换一个更贵的测试（k-WL）。代价是数据和算力，正文「加权重、边特征、位置编码和高阶关系可以增强表达，但也增加数据和计算成本」说的就是这个交换。

</details>
