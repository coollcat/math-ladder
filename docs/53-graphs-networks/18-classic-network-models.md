# 经典网络模型：随机图、无标度与六度分隔

## 1. 开场钩子

你在社交平台上刷到一位远房亲戚的共同好友；从北京飞乌鲁木齐，可能只需要在国内某个枢纽转一次；一段病毒视频能在几小时内传遍全球。

这三个场景共享一个反直觉的事实：**真实网络里的"距离"远比你想象的小，而"连接数"的分布远比你想象的极端。**

随手建一张随机图，你会发现它和真实网络长得**并不像**：随机图里没有超级枢纽，也没有明显的社区。这一课要拆开三张最经典的网络模型，看清"随机接线"和"真实网络"到底差在哪。

## 2. 直觉解释

**第一张模型：随机图（Erdős–Rényi）。** 最朴素的想法——$n$ 个节点，对每对节点以固定概率 $p$ 连一条边，各边**独立**。这叫 $G(n,p)$。

随机图有一个漂亮到近乎诡异的相变现象：当 $p$ 越过阈值 $1/n$ 附近时，**巨大的连通分量会"突然"出现**。$p$ 远小于阈值时，图是一地碎渣（最大连通块只有 $\log n$ 量级）；$p$ 略大于阈值时，一个包含绝大多数节点的巨块瞬间登场。**"突然连通"是随机图的招牌表演。**

但它的度数分布是二项分布（大 $n$ 时近似泊松），意味着**"平均度"就是"典型度"**：绝大多数节点的连接数都挤在均值附近，不存在粉丝过亿的超级节点。真实社交网络显然不是这样。

**第二张模型：无标度网络与优先连接。** 真实网络的度数分布是**幂律**：

$$P(k) \sim k^{-\gamma}, \qquad \gamma \in (2, 3] \ \text{常见}$$

幂律的尾巴极厚——度数为 $1000$ 的节点出现的概率，虽然小，但**比泊松分布下方圆几百个数量级的预测要大得多**。所以幂律网络里总有少数"超级枢纽"。

幂律从哪来？Barabási 与 Albert 在 1999 年给了一个极简的生成机制，两步：

1. **增长**：网络不是一次铺好，而是不断加新节点；
2. **优先连接**：新节点连到已有的节点 $i$ 的概率正比于 $i$ 当前的度：$\Pi(i) = k_i \big/ \sum_j k_j$。

这条规则就是"**富者愈富**"（也叫马太效应）。一旦某个节点侥幸领先，它后来被选中的概率就更大，优势自我强化——**幂律不需要任何外部设计，它是这条正反馈规则的自动产物。**

**第三张模型：小世界与六度分隔。** 1967 年 Milgram 的连锁信实验给出"六度分隔"的直觉：地球上任意两人之间的中间人链条平均约六步。1998 年 Watts 与 Strogatz 给出了能同时解释"短距离"和"高聚集"的模型：**从规则环状格点出发，以很小概率把边随机重连**。

结果非常反直觉：**只重连百分之几的边，平均路径长度就崩落得和完全随机图差不多，而聚集系数几乎不变。** 也就是说，"小世界"和"高聚集"不是对立的——真实社会网络两者都占。

| 模型 | 生成规则 | 度数分布 | 平均路径 | 像什么 |
| --- | --- | --- | --- | --- |
| ER 随机图 | 每对节点独立以 $p$ 连边 | 泊松（无枢纽） | 短（$\log n$） | 均匀混合的人群 |
| BA 无标度 | 增长 + 优先连接 | 幂律（有枢纽） | 极短 | 社交平台、互联网 |
| WS 小世界 | 规则环 + 少量随机重连 | 窄（初始近规则） | 极短 | 朋友网、电力网 |

## 3. 正式定义

**（1）Erdős–Rényi 随机图 $G(n,p)$**

$$P(\text{某对节点相连}) = p \quad \text{（各对独立）}, \qquad \mathbb{E}[|E|] = \binom{n}{2}p$$

度数的分布是二项分布，均值 $\bar k = (n-1)p$：

$$P(k) = \binom{n-1}{k}p^k(1-p)^{n-1-k} \ \xrightarrow{\ n \text{ 大}\ }\ \text{Poisson}(\bar k)$$

**（2）优先连接（BA 模型）**

每来一个新节点，连出 $m$ 条边，接到已有节点 $i$ 的概率为

$$\Pi(i) = \frac{k_i}{\sum_j k_j}$$

连续化近似下这个规则导出幂律 $P(k)\sim k^{-3}$（$\gamma = 3$ 是 BA 模型的解析结果）。

**（3）度分布的幂律刻画**

$$\log P(k) \approx -\gamma \log k + c$$

**幂律在双对数坐标下是一条直线**——这是判断一张真实网络"是否无标度"最常用的操作手段。斜率就是 $-\gamma$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $n$ | 节点数 | 网络规模 |
| $p$ | 连边概率 | ER 模型的唯一参数 |
| $k_i$ | 节点 $i$ 的度 | 连接数 |
| $\bar k = \frac{1}{n}\sum_i k_i = \frac{2|E|}{n}$ | 平均度 | 握手引理的直接推论 |
| $\gamma$ | 幂律指数 | 双对数图上的斜率绝对值；越小尾巴越厚 |
| $C$ | 聚集系数 | 邻居之间"也互相认识"的比例；$C_i = \frac{2e_i}{k_i(k_i-1)}$ |
| $L$ | 平均路径长度 | 全图所有节点对的平均最短距离 |

**两条结论**（关于鲁棒性的，这两条最实用）：

1. **对随机故障极其坚韧，对定点攻击极其脆弱**：幂律网络删掉随机节点（哪怕一大半），巨块依然健在——因为随机打中的大概率是那海量的低度节点；但**优先删度数最高的那些节点**，只要拿掉极少一批，网络立刻碎掉。这两句话合起来解释了很多工程现实：互联网对随机故障容忍度极高，但对枢纽机房的针对性打击毫无抵抗力。
2. **传染病阈值趋近于零**：在幂律网络里，由于存在高度枢纽，$\gamma \le 3$ 时流行病阈值在 $n\to\infty$ 时趋于 $0$。意思是**"接不接种都无所谓、反正传不起来"这种想法在无标度网络里站不住**——只要枢纽在，任何传染性都会扩散。这也是新冠期间"超级传播者"这个词被反复提起的数学背景。

## 4. 分步例题

**例一：ER 随机图的手算。**

$n = 10$ 个节点，$p = 0.3$。问：期望边数是多少？度数的均值与方差？

1. **期望边数**：$\binom{10}{2}p = 45\times 0.3 = 13.5$；
2. **平均度（握手引理）**：$\bar k = 2|E|/n = 2\times 13.5/10 = 2.7$，也可以直接从 $(n-1)p = 9\times0.3 = 2.7$ 得到 ✔；
3. **方差（二项分布）**：$\text{Var}(k) = (n-1)p(1-p) = 9\times0.3\times0.7 = 1.89$，标准差 $\approx 1.375$；
4. **读结论**：标准差和均值同量级（$1.375$ 对 $2.7$）——度数确实集中，**没有一万倍的离群点**。这就是随机图"没有超级枢纽"的定量含义。

**例二：BA 优先连接的第一步概率。**

从 $n=4$ 的小网络起步，度数分别为 $k = (4, 2, 1, 1)$，总度数和 $\sum k_j = 8$。一个新节点要连出 $m=1$ 条边。

1. **各自的被选中概率**：$\Pi = (4/8,\ 2/8,\ 1/8,\ 1/8) = (0.5, 0.25, 0.125, 0.125)$；
2. **最高度节点的优势**：它被选中的概率是最低度节点的 **4 倍**——正是它度数高的倍数；
3. **正反馈的后果**：若它被选中，度数变成 $5$，总数变成 $9$，下一次它的概率升到 $5/9 \approx 0.556$——**优势扩大了**；
4. **模拟验证**：连续加入 $1000$ 个节点后，前 $4$ 个老节点的度数会占据整张网络相当大的份额（下面的实验直接跑）。

**例三：小世界为什么只需重连一点点。**

规则环状格点，每节点连 $2$ 个邻居，$n = 100$。重连概率 $q = 0.05$ 时：

1. **聚集系数**：几乎全保留（只有 $5\%$ 的边被重连，绝大多数节点的"三角邻居"关系不动），$C$ 仍在 $0.7$ 以上；
2. **平均路径**：原本一圈走 50 步才能到对面，重连出的几条"远程捷径"把 $L$ 拉到个位数；
3. **读结论**：**"少数捷径"是平均路径的主导因素**——这跟"少数枢纽决定连通性"是同一个数学性格：图的极端性质由极少数"跨界"的连边决定。

### 实验 2（python）：三张模型各建一张小网

最直接的理解方式是造出来。下面用纯 Python 把 ER、BA、WS 三张模型各生成一张 $n=200$ 的图，比较**最大度、平均度、聚集系数、平均路径长度**四个指标：

```python title="三张经典网络模型的指标对照"
import random
import math

random.seed(11)
n = 200

def stats(adj, name):
    degs = [len(adj[i]) for i in range(n)]          # 每个节点的度数
    avg_deg = sum(degs) / n
    max_deg = max(degs)
    # 聚集系数：邻居之间也相连的比例
    clus = []
    for i in range(n):
        nb = list(adj[i])
        k = len(nb)
        if k < 2:
            clus.append(0.0)
            continue
        links = 0
        for a in range(k):
            for b in range(a + 1, k):
                if nb[b] in adj[nb[a]]:
                    links = links + 1
        clus.append(2 * links / (k * (k - 1)))
    avg_clus = sum(clus) / n
    print(name, "| 平均度 =", round(avg_deg, 2), "| 最大度 =", max_deg,
          "| 聚集系数 =", round(avg_clus, 3))
    return adj

# (1) ER 随机图：每对独立连边
p = 0.02
adj_er = [set() for _ in range(n)]
for i in range(n):
    for j in range(i + 1, n):
        if random.random() < p:
            adj_er[i].add(j)
            adj_er[j].add(i)
stats(adj_er, "ER 随机图   ")

# (2) BA 无标度：优先连接
m = 2                                               # 每个新节点连出 m 条边
adj_ba = [set() for _ in range(n)]
pool = []                                           # 重复列表：度数高就出现多次
for i in range(m + 1):                              # 起始小团
    for j in range(i + 1, m + 1):
        adj_ba[i].add(j)
        adj_ba[j].add(i)
for i in range(m + 1):
    pool.extend([i] * len(adj_ba[i]))
for new in range(m + 1, n):
    chosen = set()
    while len(chosen) < m:
        chosen.add(random.choice(pool))             # 按度数加权抽签 = 优先连接
    for t in chosen:
        adj_ba[new].add(t)
        adj_ba[t].add(new)
        pool.extend([new, t])                       # 双方度数各 +1
stats(adj_ba, "BA 无标度网")

# (3) WS 小世界：规则环 + 少量随机重连
half = 2
adj_ws = [set() for _ in range(n)]
for i in range(n):
    for d in range(1, half + 1):
        j = (i + d) % n
        adj_ws[i].add(j)
        adj_ws[j].add(i)
q = 0.05
for i in range(n):
    for d in range(1, half + 1):
        old = (i + d) % n
        if random.random() < q:
            new = random.randrange(n)
            if new != i and new not in adj_ws[i]:
                adj_ws[i].discard(old)
                adj_ws[old].discard(i)
                adj_ws[i].add(new)
                adj_ws[new].add(i)
stats(adj_ws, "WS 小世界网")

print()
print("看点：三者平均度接近，但最大度与聚集系数差出数量级——")
print("ER 最大度贴着平均度，BA 会出现远高于平均的枢纽，WS 聚集系数最高。")
```

跑出来的核心对比是：**三张图的平均度可以调成差不多，但最大度（枢纽）与聚集系数天差地别**。这说明"平均度"几乎不含信息——网络的性质藏在**分布的尾部**和**局部三角关系**里。

### 实验 3（python）：优先连接的"富者愈富"与鲁棒性实验

第一个实验看枢纽怎么长出来，第二个实验看它多脆弱：

```python title="枢纽的成长与针对性攻击"
import random

random.seed(5)
n = 500
m = 2
adj = [set() for _ in range(n)]
pool = []
for i in range(m + 1):
    for j in range(i + 1, m + 1):
        adj[i].add(j)
        adj[j].add(i)
for i in range(m + 1):
    pool.extend([i] * len(adj[i]))
for new in range(m + 1, n):
    chosen = set()
    while len(chosen) < m:
        chosen.add(random.choice(pool))
    for t in chosen:
        adj[new].add(t)
        adj[t].add(new)
        pool.extend([new, t])

degs = sorted((len(adj[i]), i) for i in range(n))
print("度数最小的 5 个节点：", [d for d, _ in degs[:5]])
print("度数最大的 5 个节点：", [d for d, _ in degs[-5:]])
print("最高度 / 平均度 =", round(degs[-1][0] / (sum(d for d, _ in degs) / n), 1), "倍")

def giant_size(alive):                              # 最大连通块的大小
    seen = set()
    best = 0
    for s in alive:
        if s in seen:
            continue
        stack = [s]
        seen.add(s)
        size = 0
        while stack:
            u = stack.pop()
            size = size + 1
            for v in adj[u]:
                if v in alive and v not in seen:
                    seen.add(v)
                    stack.append(v)
        best = max(best, size)
    return best

order = [i for _, i in sorted((len(adj[i]), i) for i in range(n))]   # 从低度到高度

# (a) 随机删掉一半节点
alive = set(range(n))
victims = set(random.sample(range(n), n // 2))
alive_r = alive - victims
print("随机删一半后，最大连通块 =", giant_size(alive_r), "/", len(alive_r))

# (b) 定点删掉度数最高的 25 个节点
alive = set(range(n))
top = set(order[-25:])                              # 度数最高的 25 个
alive_t = alive - top
print("定点删前 25 个枢纽后，最大连通块 =", giant_size(alive_t), "/", len(alive_t))
```

对比最后两行：**随机删掉 250 个节点，网络基本还连着；定点删掉最高的 25 个，网络碎得只剩小片。** 这就是"无标度网络对随机故障坚韧、对定点攻击脆弱"的可复现版本。

::::warning[常见误区]

**误区一**："你以为随机的网络就是真实网络的样子。" 恰恰相反：ER 随机图的核心特征是**没有枢纽、没有社区**，而真实网络的标志性特征正是**有枢纽（幂律）且有社区**。用 ER 做对照很有价值，但把它当"默认模型"会错得很彻底。

**误区二**："你以为幂律就是"头重脚轻、少数人掌握多数连接"的模糊说法。" 幂律是一个有明确检验手段的统计断言（双对数直线、斜率可估）。而且它**很难检验**：真实数据在尾部常常样本极少，许多"无标度"结论在严格统计复检后是有争议的。**看到"无标度"这个词，第一反应应该是"给出双对数图"**，而不是接受结论。

**误区三**："你以为优先连接是唯一能造出幂律的机制。" 它只是一个**极简且直觉**的例子。其他机制（适应度模型、边复制、优化驱动的等价生成）也能产出幂律。**生成机制与度数分布之间不是一一对应**——同一个分布可以有多种成因，这是网络科学里一个反复出现的提醒。

**误区四**："你以为小世界 = 完全随机连接。" 小世界最反直觉的地方正是：**只有极少数边被随机重连，平均路径就掉到随机图水平，而聚集系数几乎没动**。"短路径"和"高聚集"可以共存，这在纯随机图里是做不到的（随机图的聚集系数极低）。

## 6. 练习

**练习 1**（概念口答）：为什么"随机故障"和"定点攻击"在幂律网络上的效果差那么多？请从度数分布的形状解释。

<details>
<summary>点开查看逐步解答</summary>

关键在于**"随机抽一个节点，抽到高度枢纽的概率有多大"**。幂律分布下，度数为 $k$ 的节点占比正比于 $k^{-\gamma}$——低度节点占据绝对多数。所以随机抽样时，你打中的**几乎总是那些无关紧要的低度节点**，删掉它们对连通性几乎没有影响。

而"定点攻击"直接瞄准尾部那几个枢纽。**枢纽之所以关键，是因为大量节点之间的最短路都要穿过它们**——它们是网络里的"必由之路"。删掉一个度数为 $500$ 的节点，相当于一次性切断了与它相连的 $500$ 条边；这类边在随机删点中出现的概率极低。

用一句话概括：**幂律网络的脆弱性集中在极少数节点上，因此它"随机坚韧、定向易碎"。** 这个性质有直接的工程含义——关键基础设施（互联网骨干、电力枢纽、金融清算中心）的保护策略必须是"守住少数关键点"，而不是"平均加固所有环节"。

</details>

**练习 2**（判题）：ER 随机图的度数是二项分布，均值 $\bar k = (n-1)p$。下面这段代码算出来的**不是**度数分布的方差——它写成了某种"两头概率相乘"的东西：

```exercise
# @title: 练习：修对随机图的度数方差
# @check: 1.89
# @check: 2.7
# @hint: 度数是 (n-1) 次独立伯努利试验的成功次数：均值是 (n-1)*p，方差是 (n-1)*p*(1-p)。现在两个都在用错公式。
n_nodes = 10      # 节点数
p = 0.3           # 每对节点相连的概率

mean_deg = n_nodes * p                   # ← 问题在这：应当是 (n-1) * p
var_deg = n_nodes * p * p                # ← 问题在这：应当是 (n-1) * p * (1-p)

print(round(var_deg, 4))
print(round(mean_deg, 4))
```

两行分别卡住两个量：平均度应为 $(10-1)\times0.3 = 2.7$；度数方差应为 $9\times0.3\times0.7 = 1.89$。**注意"$n$ 还是 $n-1$"这个细节**：一个节点最多只能连到其余 $n-1$ 个节点，所以它是 $n-1$ 次伯努利试验，不是 $n$ 次。

## 7. 选读：生成模型这件事本身

<details>
<summary>选读 · 从"描述"到"生成"的一步</summary>

这三张模型在方法论上共享同一个立场：**不问"这张网络长什么样"，而问"什么样的规则能长出这样的网络"。** 这是从描述走到解释的一步，也是复杂网络这门学问区别于图论的地方——图论关心性质，网络科学关心**成因**。

这条路线的价值很实际。一旦有了生成模型，你就能：

- **做零假设检验**：观测到一个网络的聚集系数是 $0.4$，"这算高吗"？拿同规模、同度序列的随机化模型跑一千次，看 $0.4$ 落在分布的什么位置——这就是 [社区检测](./85-community-detection.md) 里模块度检验的思想基础；
- **做干预预测**：模拟"删掉这批节点"或"接种这批人"之后网络如何演化，这是传染病建模与基础设施规划的日常工具；
- **做基准对照**：机器学习里所有图神经网络的数据集都需要"和随机图比，模型学到了什么"这个参照系。

与本章后续的连接也很清楚：优先连接生成的幂律网络是 [度序列与中心性初步](./20-degree-centrality.md) 里"度数分布为什么长尾"的答案；小世界模型解释了为什么 [平均路径长度](#) 在真实图上总是比规则的图论上界小得多；而生成模型与真实数据的差异检验，正需要 [模块度](./90-modularity.md) 与谱方法（[谱聚类直觉](./60-spectral-clustering.md)）这样的工具。再往远处看，[随机游走](./65-random-walks.md)在无标度网络上的行为与在规则网格上截然不同——枢纽会大幅改变平稳分布的形态。

一个诚实的补充：这三张模型都是**极度简化的**。它们没有节点属性、没有边权、没有时间演化、没有方向——而真实的社交网络、互联网、生物网络全都有这些。它们的价值在于提供了一个"最简可解释"的起点，而不是终局答案。

</details>

## 8. 下一站

网络生成规则讲完了：随机图没有枢纽，优先连接长出幂律，少量重连造就小世界。这三张模型解释了网络的**形状从哪里来**，但还没回答**谁在结构上最重要**。

"最重要"其实是个比它听起来模糊得多的词——度最高算最重要吗？还是离所有人最近的那个？还是被最多重要节点指着的那个？下一课开始盘点这件事。
