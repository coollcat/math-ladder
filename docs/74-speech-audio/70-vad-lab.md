# 清浊音与端点检测

## 1. 从一个场景开始

你对语音助手说了一句话，然后安静下来——它是怎么知道你说完了？录音软件一键掐掉头尾的空白，靠的又是什么？

答案是一项便宜到几乎所有芯片都跑得起的旧手艺：**语音活动检测**（VAD）。它不认识词，不建模型，只用两把尺子逐帧量一量，就把一段音频干净利落地切成"静音—说话—静音"。VAD 每省下一秒静音，电话网络就少传一秒数据；唤醒词引擎每错切一次端点，后级的识别就多喂一口噪声。

## 2. 直觉解释

说话时的声音分三种脾气，两把尺子刚好把它们分开：

| | 声源 | 能量 | 过零率 |
| --- | --- | --- | --- |
| **浊音**（a、o、m） | 声带振动，像蜂鸣器 | 高 | 低（波形缓慢摆动） |
| **清音**（s、f、sh） | 气流挤过窄缝，像噪声 | 中等 | 高（波形疯狂抖动） |
| **静音** | 只有底噪 | 低 | 低 |

第一把尺子是**短时能量**：一帧之内样点平方的平均，取对数换成 dB。浊音声带全功率 buzzing，能量一骑绝尘。

第二把尺子是**短时过零率**：一帧之内波形穿过零线的次数，除以样点数。清音是气流摩擦出来的宽带噪声，高频成分多，波形每抖一下就过零一回；浊音被声道的低频共振峰托着，几毫秒才晃过一个零。

两把尺子各设一条阈值线：能量够高且过零率低 → 浊音；能量够高且过零率高 → 清音；两头都低 → 静音。**端点**就是判定翻转的位置——从静音翻进语音的那一帧是起点，翻回去的那一帧是终点。

## 3. 正式定义

把信号切成帧（25 ms、400 个样点 @16 kHz，帧移 5 ms），逐帧算：

**短时能量**（dB）：

$$E = 10 \cdot \log_{10}\left(\frac{1}{N}\sum_{n=0}^{N-1} s[n]^2\right)$$

**短时过零率**：

$$Z = \frac{1}{N}\sum_{n=1}^{N-1} \frac{|\operatorname{sgn}(s[n]) - \operatorname{sgn}(s[n-1])|}{2}$$

（相邻两样点符号相反记一次过零；$Z$ 的取值范围 0 到 0.5。）

**双阈值判决**（本课取值）：

| 判定 | 条件 |
| --- | --- |
| 静音 | $E < -30$ dB 且 $Z < 0.25$ |
| 清音 | $E \ge -30$ dB 且 $Z \ge 0.25$ |
| 浊音 | $E \ge -30$ dB 且 $Z < 0.25$ |

**端点检测**：在逐帧判定序列上找静音↔语音的翻转处；工程上还要加"连续 N 帧才翻转"的防抖（见选读）。

## 4. 分步例题

**例**：16 kHz 采样的 400 样点帧，三种典型帧的两把尺子读数（数值都可以动手算出来）：

1. **浊音帧**：幅度 0.3 的 140 Hz 蜂鸣。均方值 $\approx 0.3^2/2 = 0.045$（正弦的均方是幅度平方的一半），$E = 10\log_{10}(0.045) = -13.5$ dB；周期 114 个样点，一帧只晃 3.5 个来回，400 个样点里过零 6 次（第 7 次落在帧外不计），$Z \approx 0.015$。**判定：浊音**；
2. **清音帧**：幅度 0.08 的高频沙沙声（用 4000 Hz 正弦模拟宽带噪声的高频本性）。均方 $\approx 0.08^2/2 = 0.0032$，$E = -24.9$ dB；每样点过零 0.5 次，400 个样点里实际过零 199 次，$Z = 0.4975$。**判定：清音**；
3. **静音帧**：幅度 0.004 的底噪。$E = -51.0$ dB，$Z \approx 0.005$。**判定：静音**。

对着判决表走一遍：第 1 帧能量 -13.5 ≥ -30 且过零 0.015 < 0.25 → 浊音；第 2 帧能量 -24.9 ≥ -30 且过零 0.4975 ≥ 0.25 → 清音；第 3 帧两头都低 → 静音。

注意第 2 帧这个细节：清音能量 -24.9 dB，**并不比浊音低多少**——摩擦音不轻，只是缺少低频蜂鸣。指望单靠能量尺把清音从浊音里分出来，必败；这正是过零率必须上场的原因。

- 把红色能量阈值从 -30 拖到 -15：清音段（-24.9 dB 上下）整段被判成静音，端点把 /s/ 吃掉了——**能量阈值定太高的代价是吃清音**；
- 把紫色过零阈值拖到 0.1：浊音的余摆也被当成了清音——两条线要**配合**着调；

### 实验 2（python）：两把尺子亲手量

```python title="对三种典型帧各量一遍：能量与过零率"
import math

fs = 16000
N = 400

def measure(freq, amp):
    frame = [amp * math.sin(2 * math.pi * freq * n / fs) for n in range(N)]
    energy = 10 * math.log10(sum(x ** 2 for x in frame) / N)
    zcr = sum(1 for n in range(1, N)
              if (frame[n] >= 0) != (frame[n - 1] >= 0)) / N
    return round(energy, 1), round(zcr, 4)

for name, f, a in [("浊音 a", 140, 0.3), ("清音 s", 4000, 0.08), ("静音", 60, 0.004)]:
    e, z = measure(f, a)
    if e < -30 and z < 0.25:
        kind = "静音"
    elif z >= 0.25:
        kind = "清音"
    else:
        kind = "浊音"
    print(f"{name}  E={e:>6} dB  Z={z:<7} → {kind}")
```

三行输出与第 4 节的手算逐项一致：浊音 -13.5 dB / 0.015，清音 -24.9 dB / 0.4975，静音 -51.0 dB / 0.005（过零按样点对计，落在帧边界外的次数不算）。真实语音里还要加一道工序——先扫全段估出**背景噪声的能量水平**，把静音阈值定在它上方几个 dB（本课为了可复现用固定值 -30 dB）。

::::warning[常见误区]

**误区一**："过零率高就是频率高。"
你以为 $Z$ 与频率一一对应——那只对纯正弦成立（$Z \approx 2f/f_s$）。宽带噪声、方波、多个正弦叠加都会把过零率抬上天。$Z$ 是"高频含量"的粗糙代理，不是频率计。

**误区二**："清音很轻，能量低。"
你以为音量小就切得掉——摩擦音 /s/ 的能量常与浊音只差 10 dB 左右，远高于静音。VAD 的难点从来不是把语音从静音里分出来（那只需能量尺），而是**别把清音当静音**、别把呼吸声当语音。

**误区三**："阈值定死了就不动了。"
你以为出厂标定一次管终身——麦克风增益、环境底噪、说话人音量全在漂。工程实现都让能量阈值跟着背景噪声自适应（噪声底抬了 5 dB，阈值跟着抬），固定阈值只活在教科书例题里。

::::

## 6. 练习

**练习 1**：下面这帧浊音的能量读数不对。初始代码输出 -10.5，正确答案是 `-13.5`：

```exercise
# @title: 练习：短时能量算的是平均，不是峰值
# @check: -13.5
# @hint: 短时能量定义里是全帧样点平方的平均（1/N·Σs²），正弦的均方是幅度平方的一半；max(frame)**2 是峰值功率，比平均高 3 dB
import math

frame = [0.3 * math.sin(2 * math.pi * n / 50) for n in range(400)]

E = 10 * math.log10(max(frame) ** 2)   # ← 问题在这：取了峰值平方，不是平均
print(round(E, 1))
```

峰值口径比平均口径恒定高出约 3 dB（对正弦而言 $10\log_{10}2$）。单独看只是个偏置，但同一套代码混着量不同波形时，脉冲性的音会被系统性高估——定义里的 $1/N$ 不是随手写的。

**练习 2**：16 kHz 采样、400 样点的一帧里是频率 800 Hz 的纯正弦。求过零率，并用 $Z \approx 2f/f_s$ 验算。

<details>
<summary>点开查看逐步解答</summary>

1. 正弦每周期过零 2 次；周期 $= 16000/800 = 20$ 个样点；
2. 400 个样点含 20 个周期 → 过零 40 次 → $Z = 40/399 \approx 0.1$；
3. 公式验算：$2f/f_s = 2\times800/16000 = 0.1$ ✓（分母是 399 还是 400 只差最后一位小数）。

反着用更常见：VAD 实测到 $Z = 0.1$、且已知信号接近纯正弦，可估计其主频约 $Z f_s / 2 = 800$ Hz——过零率是不要钱的"粗糙频率计"。

</details>

## 7. 选读：防抖与迟滞

<details>
<summary>选读 · 为什么端点检测要"连看三帧才翻脸"</summary>

逐帧判定串出来的端点是毛糙的：浊音中间夹一两个能量瞬降的帧（爆破音闭合段），判定翻过去又翻回来，一段语音被切成三四截。工程上的标准补丁有两条：

**迟滞**（hysteresis）：进入语音用一条宽松阈值（能量 > 底噪 + 10 dB），退出语音用一条严格阈值（能量 > 底噪 + 20 dB）。于是"边缘上的模糊帧"不容易造成反复横跳——这套双阈值防抖与 52 章控制里施密特触发器是同一个思想。

**最小段长**：翻转后要求新状态至少持续 $N$ 帧（语音 ≥ 100 ms、静音 ≥ 200 ms）才算数，否则回滚。呼吸声、椅子响这类 50 ms 级的冒充者全被这条规则挡在门外。

再往上一层就是统计 VAD：把"能量、过零率、频谱斜率"打包成特征向量，用高斯混合或小型神经网络对"语音/噪声"做逐帧二分类——特征还是本课这两把尺子的后代，只是判决从手画阈值换成了学出来的边界。唤醒词引擎的"你还没开口"判得那么准，靠的是这一层。

</details>
