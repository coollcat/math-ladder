# MFCC：语音识别的老饭碗

## 1. 从一个场景开始

上世纪九十年代的语音识别机，内存以 MB 计，不可能把一整段波形原样塞给模型。工程师面前摆着 32 ms 一帧、每帧几百个频点的数据，他们要把它压成**十几个数**——既小到喂得起，又稳到让模型分得清"爸"和"爬"。

他们造出来的东西叫 **MFCC**（梅尔频率倒谱系数）。三十多年过去，深度学习横扫了语音识别的每个环节，可翻开今天任何一个端侧"唤醒词"模块，这十几个数仍是第一特征——小、稳、便宜，无人能取代。这一课把它从头到尾组装一遍：你会认出每一个零件，全部来自前三课。

## 2. 直觉解释

流水线六步，前四步是复习：

1. **分帧加窗**（20 课）：32 ms 一帧、10 ms 一挪，汉宁窗掐头去尾；
2. **功率谱**（30 课）：每帧做 DFT、取幅度平方——这一帧"哪些频率有多少能量"；
3. **梅尔滤波组**（40 课）：26 个三角滤波器把几百个频点压成 26 个梅尔能量 $E_0, \dots, E_{25}$；
4. **取对数**：$L_m = \log E_m$——新的一步，两重用意；
5. **DCT**（离散余弦变换）：把 26 个相关的数拧成 26 个几乎不相关的数，能量集中在前几个——新的另一步；
6. **砍维**：只留前 13 个系数，扔掉后面。

**取对数的两重用意**：其一，人耳对响度的感受本就是对数的——能量翻 10 倍，听起来只"响了一点"（73 章分贝课的同款逻辑）；其二，更深的：语音谱 = 源谱 × 声道响应（10 课），是**乘法**；取对数后变成 $\log(\text{源}) + \log(\text{声道})$，**乘法拆成了加法**——快变的源项和缓变的声道项从此可以被分开处理。

**DCT 的一重用意**：26 个梅尔能量彼此相关（相邻通道本来就是重叠的三角形），直接喂给模型是浪费。DCT（余弦版的正交变换）把这 26 个数重新表述成"从平缓到起伏"的 26 个分量——**低阶系数描述谱包络的总体形状（音色），高阶系数描述细刺（噪声多）**。能量高度集中在低阶，砍掉高阶几乎不丢信息。

## 3. 正式定义

记第 $m$ 个梅尔通道的对数能量为 $L_m$（$m = 0, \dots, M-1$，$M = 26$），**MFCC** 定义为 DCT-II：

$$c_j = \sum_{m=0}^{M-1} L_m \cos\left(\frac{\pi j (m + 0.5)}{M}\right), \qquad j = 0, 1, \dots, M-1$$

- 保留 $c_0$ 到 $c_{12}$ 共 13 维，就是经典的"一帧 13 个数"；
- $c_0 \propto$ 这一帧的对数总能量——它编码**响度**，不编码内容，很多识别系统把它丢弃或单独处理；
- $c_1$~$c_{12}$ 描述谱包络形状：低阶平缓（元音身份），高阶起伏（对噪声敏感）——**截断高阶顺带完成了一次去噪**；
- "倒谱（cepstral）"这个名字是 spectrum 的字母游戏：这是"频谱再做一次变换"得到的谱。

工程备注：取对数前给能量加地板 $\log(E_m + \epsilon)$（40 课选读），$\epsilon$ 常取 $10^{-10}$。

## 4. 分步例题

**例**：三通道玩具流水线。设某帧过完梅尔滤波组，三个通道的能量是 $E = [100, 1000, 10000]$（通道间差一个数量级——线性域的悬殊）。

1. **取对数**（用 $\log_{10}$ 好读数）：$L = [2, 3, 4]$——两个数量级的悬殊，在对数域只差 2 格；
2. **DCT**（$M = 3$）：
   $$c_0 = 2 + 3 + 4 = 9$$
   $$c_1 = 2\cos\frac{\pi}{6} + 3\cos\frac{\pi}{2} + 4\cos\frac{5\pi}{6} \approx 1.73 + 0 - 3.46 = -1.73$$
   $$c_2 = 2\cos\frac{\pi}{3} + 3\cos\pi + 4\cos\frac{5\pi}{3} \approx 1 - 3 + 2 = 0$$
3. **关键实验**：现在捂住嘴小声说——每个通道能量都变回原来的 $1/100$，$E' = [1, 10, 100]$，取对数 $L' = [0, 1, 2]$。再算一遍：$c_0 = 3$，但 $c_1$ 还是 $-1.73$、$c_2$ 还是 $0$；
4. **结论**：响度变化（整体乘一个常数）在对数域是**整体平移**，而 DCT 的 $c_0$ 恰好是"平移检测器"（它对常数最敏感），形状系数纹丝不动——**响度进 $c_0$，音色进其余系数**。识别"说了什么"的系统甚至扔掉 $c_0$。

六块图就是整条流水线，从左到右、从上到下：① 加窗后的一帧波形 → ② 它的功率谱 → ③ 过梅尔组后的 26 个能量 → ④ 取对数后的 26 个值 → ⑤ DCT 后的倒谱（紫色竖线右边被砍掉）→ ⑥ 留下的 13 维。做三件事：

- 拖波形条上的橙色指针换帧：元音段（③里能量集中在低频通道）和咝音段（能量涌向高频通道）的最终 13 维差得很远——**特征就是要把这种差别变得一目了然**；
- 在 ⑤ 里拖紫色竖线改保留维数：砍到 6 维曲线开始发糊，但 12~13 维已经稳稳区分开元音——这正是当年选 13 的来历；
- 点「用麦克风」对着说话，实时看自己的 13 维向量怎么随口型舞动。

### 实验 2（python）：亲手跑一遍玩具流水线

```python title="响度只进 c0，音色进形状系数——对数加 DCT 的分工"
import math

def dct3(L, j):
    return sum(L[m] * math.cos(math.pi * j * (m + 0.5) / 3) for m in range(3))

loud = [math.log10(e) for e in [100.0, 1000.0, 10000.0]]   # 响亮版的对数能量
soft = [x - 2.0 for x in loud]      # 能量 ×0.01 → 对数域整体平移 −2

for name, L in [("响", loud), ("轻", soft)]:
    print(f"{name}: c0={dct3(L, 0):.2f}  c1={dct3(L, 1):.3f}")
```

两行输出里 $c_0$ 从 9.00 掉到 3.00（整好差 2），$c_1$ 两人都是 $-1.732$——第 4 节的结论在代码里复现。真正的 MFCC 只是把 3 个通道换成 26、把"手算 DCT"换成同一公式的循环，骨架一模一样。

```quiz
为什么 MFCC 要把梅尔能量先取对数、再做 DCT，而不是直接用 26 个线性能量？
- 对数把「源×声道」的乘法拆成加法并贴合响度感知，DCT 去相关并把能量挤进低阶便于降维 [*]
- 只是为了把数值变小，省一点存储空间
- 因为神经网络只能处理对过对数的数
? 两步各司其职：对数负责"拆乘法 + 压数量级"，DCT 负责"拧掉相关性、让砍维不疼"。直接喂线性能量两样好处都拿不到。
```

::::warning[常见误区]

**误区一**："MFCC 是语音的一种频率。"
你以为 13 个数还是某种赫兹值——它们是**倒谱系数**，描述的是"对数谱的形状"，量纲既不是 Hz 也不是 dB。$c_1$ 大致对应"包络整体往高频翘还是往低频塌"的倾向，越往高阶描述的起伏越细。

**误区二**："13 个数里 $c_0$ 最重要，它是第一个。"
你以为排头兵最重要——$c_0$ 只编码这一帧的**响度**（对数总能量），对"说了什么"几乎没有贡献。很多识别流水线直接丢掉 $c_0$ 只用 $c_1$~$c_{12}$，或者单独把它交给与内容无关的模块（如响度归一化）。

**误区三**："能量取对数是天经地义，不用防零。"
你以为 $\log$ 随手就能用——静音帧或滤波器谷底能让 $E_m$ 恰好为 0，$\log 0$ 是负无穷，一帧坏数据就毒化整批特征。所有正经实现都先加地板：$\log(E_m + \epsilon)$。40 课选读埋的那颗钉子，在这里被敲进去。

::::

## 6. 练习

**练习 1**：某帧过完梅尔滤波组，三个通道的能量是 $[100.0, 1000.0, 10000.0]$。取对数再求和（玩具版的 $c_0$），输出应为 `9.0`。这段代码忘了流水线的第四步：

```exercise
# @title: 练习：先取对数，再求和
# @check: 9.0
# @hint: MFCC 流水线在梅尔滤波组之后是「取对数」——每个通道先过 log 再汇总
import math

energies = [100.0, 1000.0, 10000.0]   # 三个梅尔通道的能量（线性域）
total = sum(energies)    # ← 问题在这：直接求和，数量级原样悬着
print(round(total, 1))
```

改成 `total = sum(math.log10(e) for e in energies)`：$2 + 3 + 4 = 9.0$。线性域最猛的通道是最弱通道的 100 倍，对数域只领先 2 格——**取对数把"差两个数量级"压成"差两步"**，后面的模型才有得学。

**练习 2**：两个梅尔通道的对数能量 $L = [1, 2]$。手算 $c_0$ 与 $c_1$（$M = 2$ 的 DCT-II）。若响度减半、$L$ 变成 $[0, 1]$，哪些系数变了？

<details>
<summary>点开查看逐步解答</summary>

1. $c_0 = 1 + 2 = 3$；
2. $c_1 = 1\cdot\cos\frac{\pi}{4} + 2\cos\frac{3\pi}{4} = 0.7071 - 1.4142 = -0.7071$；
3. $L' = [0, 1]$：$c_0' = 1$，$c_1' = 0 \cdot \cos\frac{\pi}{4} + 1 \cdot \cos\frac{3\pi}{4} = -0.7071$——**$c_0$ 变了（3 → 1），$c_1$ 纹丝不动**；
4. 又一次验证"平移只进 $c_0$"：对数域整体加减常数，恰好落在 $c_0$ 这个"常数检测器"里，形状系数 immune。两通道的玩具都如此，26 通道的正式版只是把这条性质用满。

</details>

## 7. 选读：同态处理——"倒谱"名字的来历

<details>
<summary>选读 · 对数是拆乘法的钥匙（10 课伏笔的收线）</summary>

10 课选读留了个伏笔：语音谱是 $S_{\text{源}}(f) \cdot H_{\text{声道}}(f)$，乘积难拆。现在可以收线了：

1. 时域里语音 = 声门脉冲串 **卷积** 声道冲激响应（卷积定理：时域卷积 = 频域乘积）；
2. 对功率谱取对数：乘积变加法——$\log S = \log S_{\text{源}} + \log H$；
3. 对**对数谱**再做一次变换（DCT 是其纯实数版）：快变的谐波梳（源，音调）集中在高阶，缓变的包络（声道，元音）集中在低阶；
4. 留低阶 = 留元音身份；留高阶 = 留音高。**同态处理**（把卷积信号变回加法信号处理）由此得名，倒谱 = "对数谱的谱"。

1963 年 Bogert 等人造词 cepstral 时还顺手把 frequency 改叫 quefrency——这门学科从命名起就在玩 spectrum 的字母游戏。今天你算的 MFCC 就是这条五十年老流水线的工业版。至于深度学习时代为什么很多模型改吃语谱图原图（第 46 章讲），答案是：算力和数据都管够之后，网络想自己学"怎么拆"，不想再被人为的 DCT 拘着——但端侧唤醒词这类小模型，13 维老饭碗依然是最省粮的选择。

</details>
