# 基频与音高检测

## 1. 从一个场景开始

K 歌软件给你打的分，来自屏幕上那条随你歌声起伏的音高线。上一课的语谱图能给你一张"声音的照片"——哪些频率、什么时刻、多亮。但音高线问的是另一个问题：**这一瞬间，旋律在哪个音上？**

回答它只需要从频谱里挑出一个数：基频 $f_0$。挑得又快又准，调音器、修音软件、哼歌识曲全都有了地基。这件事比看上去微妙——频谱里明明有一排谐波峰，凭什么说"基频是那个"？

## 2. 直觉解释

元音是**周期信号**：声带每振动一次，波形就重复一遍。检测基频最朴素的思路不是去频谱里数峰，而是回到时域问一句话：

> 把波形平移多少个样点之后，能跟自己几乎重合？

这个"平移之后像不像自己"的打分器，就是**自相关函数**（61 章讲维纳解时见过的那台机器，这里用它最原始的一面）。周期是 $T$ 个样点，那么平移 $T$、$2T$、$3T$……全都重合，自相关在这些滞后处个个冒峰。挑出**最短的**那个显著峰，取倒数：

$$f_0 = \frac{f_s}{k_{\text{peak}}}$$

$f_s$ 是采样率（16 kHz 时每秒 16000 个样点），$k$ 是峰所在的滞后（样点数）。滞后是"多少个样点才重复一次"，除以采样率就换成了秒，再取倒数就是每秒重复多少次——频率。

## 3. 正式定义

对一帧信号 $s[0..N-1]$，滞后 $k$ 处的**归一化自相关**：

$$r[k] = \frac{\displaystyle\sum_{n=k}^{N-1} s[n]\,s[n-k]}{\sqrt{\displaystyle\sum_{n=k}^{N-1} s[n]^2 \;\cdot\; \sum_{m=0}^{N-1-k} s[m]^2}}$$

分子是"平移 $k$ 后的重叠乘积"，分母把重叠变短带来的能量损失补回去——不补的话，$k$ 越大 $r[k]$ 天然越小，峰会被压扁。

**基频检测** = 在 $[k_{\min}, k_{\max}]$ 里找 $r[k]$ 的最大峰，$f_0 = f_s / k$：

| 参数 | 换算 | 本课取值（16 kHz） |
| --- | --- | --- |
| 搜索下限 $k_{\min}$ | $f_s / f_{\max}$ | $16000/400 = 40$（人声最高约 400 Hz） |
| 搜索上限 $k_{\max}$ | $f_s / f_{\min}$ | $16000/110 \approx 145$（男低音约 110 Hz） |
| 帧长 $N$ | — | 240 样点（15 ms），要容得下至少两个周期 |

**八度错误**是这门手艺的头号陷阱：$r[k]$ 在 $T$、$2T$、$3T$ 处**全都接近满分**，归一化之后甚至分不出高下。搜索范围一旦把 $2T$ 放进来、又把 $T$ 排除出去，检测器就一本正经地报出低一个八度的音。反过来的"半八度错误"（挑到 $T/2$）少见，因为谐波串在半周期处不重合。

## 4. 分步例题

**例**：$f_s = 16000$，一帧元音的基频是 160 Hz。找峰，并演示两种挑法的天壤之别。

1. **周期换样点**：$T = 16000/160 = 100$ 个样点。$r[100]$、$r[200]$、$r[300]$ 处都是满分峰；
2. **正确的搜索范围**：基频预期在 110–400 Hz，对应 $k \in [40, 145]$。这个窗口里只有 $k=100$ 一个满分峰 → $f_0 = 16000/100 = 160$ Hz ✓；
3. **错误的搜索范围**：把下限随手写成 150（"避开主瓣就行"），窗口 $[150, 320]$ 里 $k=200$ 是唯一满分峰 → $f_0 = 16000/200 = 80$ Hz——**低了一个八度**，检测器毫无察觉；
4. **非整数的麻烦**：音叉 A4 = 440 Hz，$T = 16000/440 \approx 36.36$ 个样点——峰不在整数滞后上，$r[36]$ 和 $r[37]$ 各差一点。工程上的补救是**抛物线插值**：用峰两侧的值拟合一条抛物线，取顶点位置，把基频精度从"半个样点"提到"百分之几个样点"。

第 3 步是所有调音器都要设 $f_{\min}/f_{\max}$ 的原因：**搜索范围不是性能参数，是正确性参数**。

## 5. 动手实验

### 实验 1（lab）：把竖线拖到两倍滞后处，听音高掉一个八度

```lab

  "kind": "const",
  "fmin": 70,
  "fmax": 400

```

中间那条自相关曲线在 150 Hz 的一个周期处冒峰——把它拖到两倍滞后，底下的音高读数立刻掉一个八度。这就是八度错误的现场版：**倍周期处的峰是真的，只是不是你要的那个**。再玩两件事：

- 切到「掺噪声」，看清晰度一栏怎么塌——自相关扛得住噪声，扛不住共振峰的干扰；
- 把 $f_{\min}$ 拖大，看基频轨迹在低音区怎么"跳"到低八度——搜索范围每改一次，错峰的位置也跟着换。

### 实验 2（python）：十五毫秒的一帧里找峰

```python title="归一化自相关：两个一样高的峰，正是八度错误的温床"
import math

fs = 16000
# 一帧元音：基频 200 Hz（周期 80 个样点），带一个二分之一幅度的二次谐波
s = [math.sin(2 * math.pi * n / 80) + 0.5 * math.sin(4 * math.pi * n / 80)
     for n in range(240)]

def r(k):                    # 归一化自相关：分母补回重叠变短的能量损失
    num = sum(s[n] * s[n - k] for n in range(k, 240))
    et = math.sqrt(sum(x ** 2 for x in s[k:]))
    eh = math.sqrt(sum(x ** 2 for x in s[:240 - k]))
    return num / (et * eh)

print("r(80) =", round(r(80), 4), "  r(160) =", round(r(160), 4))
k = max(range(40, 146), key=r)        # 目标基频 110~400 Hz 对应的滞后窗
print("检测基频 =", round(fs / k), "Hz")
```

第一行是本课的题眼：$r[80]$ 与 $r[160]$ 打印出来**一样高**——倍周期处的峰货真价实。第二行检测出 200 Hz，靠的不是"峰最高"，而是**搜索窗只放行了一个满分峰**。把窗口改成 `range(100, 240)` 再跑一遍，它就换成报 100 Hz 了。

### 快问快答

```quiz
自相关检测器把峰挑在了 2 倍周期处（320 个样点而不是 160 个），采样率 16000 Hz，读出的音高会怎样？
- 低一个八度 [*]
- 高一个八度
- 不变
- 变成原来的 4 倍
? f0 = fs / k。滞后 k 翻倍，算出的频率减半——200 Hz 变 100 Hz，正好低一个八度。这是自相关法最经典的错误，靠收紧搜索范围（fmin/fmax）来防。
```

::::warning[常见误区]

**误区一**："音高就是基频的频率，基频峰一定出现在频谱上。"
你以为没有基频成分就测不出音高——其实人耳和自相关都能从一串泛音（1000、2000、3000 Hz……）里听出 1000 Hz 的"消失的基频"：自相关照样在 $T$ 处冒满分峰。**音高是感知量，基频是物理量**，两者通常一致，但机制不同。

**误区二**："归一化不归一化无所谓，峰总在那里。"
你以为不补分母也能挑对峰——其实不归一化的自相关随 $k$ 增大单调缩水（重叠变短），长周期的音（低音）天生吃亏，检测器会系统性地把低音报高。分母那两个平方和不是装饰。

**误区三**："帧长取短点，检测更灵敏。"
你想用 5 ms 的小帧追快旋律——但 $f_0 = 110$ Hz 的周期长达 9 ms，5 ms 的帧连**一个完整周期**都装不下，自相关在有效滞后范围内根本无峰可挑。帧长的下限由目标最低基频决定：至少两个周期，15 ms 起步。

::::

## 6. 练习

**练习 1**：修好这台会掉八度的检测器。初始代码输出 100，正确答案是 `200`：

```exercise
# @title: 练习：修好八度错误
# @check: 200
# @hint: r[k] 在每个整数倍周期处都有满分峰。搜索范围按目标基频段换算：110~400 Hz 对应 k 在 40~145 之间，别让 2 倍周期溜进来
import math

fs = 16000
# 一帧元音：基频 200 Hz（周期 80 个样点），人声目标段 110~400 Hz
s = [math.sin(2 * math.pi * n / 80) + 0.5 * math.sin(4 * math.pi * n / 80)
     for n in range(240)]

def r(k):
    num = sum(s[n] * s[n - k] for n in range(k, 240))
    et = math.sqrt(sum(x ** 2 for x in s[k:]))
    eh = math.sqrt(sum(x ** 2 for x in s[:240 - k]))
    return num / (et * eh)

k = max(range(100, 240), key=r)   # ← 问题在这：下限 100 样点 = 160 Hz，把真周期 80 排除在窗外
print(round(fs / k))
```

输出从 100 变成 200，只改了一个搜索范围——八度错误从来不是"峰找错了"，是**窗框歪了**。

**练习 2**：采样率 22050 Hz 的调音器在一帧自相关里测得最大峰在 $k = 71$ 个样点处（用抛物线插值修正到 71.0）。求基频，并判断它离标准音 $\mathrm{D}_4$（293.66 Hz）差多少音分。

<details>
<summary>点开查看逐步解答</summary>

1. $f_0 = 22050/71 = 310.56$ Hz，四舍五入报 310.6 Hz；
2. 音分差 $= 1200 \cdot \log_2(310.56/293.66) = 1200 \cdot \log_2(1.05756) \approx 1200 \times 0.0811 \approx 97$ 音分；
3. 一个半音 = 100 音分，所以它比 D4 高出**接近整整一个半音**——这正是 D#4（311.13 Hz）的位置，偏离只有约 3 音分（人耳在 400 Hz 附近可辨阈约 3~5 音分，基本听不出）。

注意第 2 步为什么必须用对数：音高感知是对数的（八度 = 频率翻倍），算"差多少"要用频率**比**，不能用电平式的减法。

</details>

## 7. 选读：从自相关到 YIN

<details>
<summary>选读 · 工业级音高检测还补了哪几刀</summary>

本课的自相关法在干净信号上已经够用，真实录音还要补三刀，刀刀都在堵本课留下的口子：

**一刀堵噪声**：先做**中心削波**——把幅度的绝对值低于某个阈值的样点直接置零，只留波峰过山车。谐波细节被扔掉，周期结构反而更突出，$r[k]$ 的峰更瘦更高。

**一刀堵倍周期**：**累积均值归一化差函数**（YIN 法的核心）不直接比"像不像"，而是比"差多少"，并给每个滞后除以"此前所有滞后的平均差"。于是 $2T$ 处哪怕同样完美，也会因为"多等了一个周期才等到第一个低洼"而被压下去——从机制上而不是从搜索范围上排掉八度错误。

**一刀堵跑调**：pYIN 干脆不挑单一峰，而是给每个滞后一个"是基频"的概率，再用隐马尔可夫模型（第 37 章）把整条轨迹的连续性管起来——突变到八度外的候选要交很大一笔"跳变税"。K 歌软件里那条又稳又滑的音高线，多半就是它画的。

顺带一提：这三种改进没有一种用到了新数学——归一化、累积平均、带转移代价的动态规划，全是本课程已经到手的基础件。

</details>
