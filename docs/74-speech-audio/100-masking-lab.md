# 心理声学与感知掩蔽

## 1. 从一个场景开始

地铁进站，广播声轰然抬起——你耳机里那首歌突然"少了一半"：贝斯还在，细节全没了。车走了，一切又回来。工程师会说：不是歌变差了，是**掩蔽**生效了——广播这个强音把一首歌的弱成分压到了你的听觉阈值之下。

这听上去是听歌的烦恼，其实是编码的馈赠。**凡是听不见的，就无需编码。** 40 章讲过：信息量由"能分辨多少种不同结果"决定——耳朵分不出的差异，在信息上就是零。MP3 能砍掉 CD 九成以上的数据，靠的不是更聪明的数学，而是先把这张"误差容忍地图"画出来：**每个频率、每个时刻，误差多大才刚能被听见。**

这一课画这张地图。它是 73 章等响曲线（安静环境下"多响才听得见"）的续篇——现在加上"已经有声音在场"的情形。

## 2. 直觉解释

内耳的基底膜是一台**频谱分析仪**：不同位置响应不同频率。但它的分辨率不是均匀的——一段膜管一个**临界频带**，落进同一带里的声音会互相干扰。这就是 73 章 40 课等响曲线的"时间续集"：等响曲线给的是**安静环境的底**（绝对听阈，ATH）；现在有一个强音在场，它所在频带及邻近区域的听阈会被**整体抬高**——抬高后的那条曲线叫**掩蔽阈值**。曲线以下，你什么都听不见。

三个实验事实决定了这条曲线的形状：

- **不对称**：低频强音对高频弱音的掩蔽拖得很远，反过来则不行。1 kHz 的强音上方 2 Bark 处，阈值只降 12 dB 就穿帮；下方 2 Bark 处却要降 28 dB——**高频弱音更容易被吃掉**；
- **强音越大，吃掉越多**：掩蔽量随掩蔽音强度超线性增长——抬 10 dB 不只把"保护区"抬 10 dB，还把范围拉宽；
- **底线是 ATH**：掩蔽阈值再怎么降，也不会低于安静环境的绝对听阈。

于是感知编码的全部依据就位：量化噪声只要**压在掩蔽阈值之下**，声学上就等于不存在。

## 3. 正式定义

**Bark 刻度**（把 Hz 换算成临界频带序号，Schroeder 近似）：

$$z(f) = 13\,\arctan(0.00076 f) + 3.5\,\arctan\!\left(\frac{f^2}{7500^2}\right) \quad (\text{Bark})$$

1 kHz ≈ 8.5 Bark；全可听域约 24 个临界频带。低频处 1 Bark 约百来赫兹，高频处一 Bark 能横跨几千赫兹——**耳朵天生"低频细腻、高频粗糙"**。

**扩展函数**（掩蔽音在 Δz Bark 外还能抬多高的阈值，dB）：

$$S(\Delta z) = 15.81 + 7.5(\Delta z + 0.474) - 17.5\sqrt{1 + (\Delta z + 0.474)^2}$$

$\Delta z > 0$ 表示探针在掩蔽音的**高频一侧**。$S(0) \approx 0$：贴着掩蔽音，阈值抬到与它一样高；两侧衰减速率不同——高频侧约每 Bark 降 10 dB 上下，低频侧陡到 25 dB 上下，这正是"不对称"的公式形态。

**掩蔽阈值**：

$$T(f) = \max\big(\text{ATH}(f),\; L_{\text{masker}} + S\big(z(f) - z(f_{\text{masker}})\big)\big)$$

$L_{\text{masker}}$ 是掩蔽音的声压级（dB SPL）。**判定**：探针声级 $> T$ 才听得到。

## 4. 分步例题

**例**：1 kHz、65 dB SPL 的强音在场。同一个 40 dB SPL 的探针音，放在它两侧各 2 Bark 处，命运完全不同。

1. **换算**：$z(1000) \approx 8.51$ Bark；高频侧 +2 Bark 落在约 1350 Hz，低频侧 −2 Bark 落在约 716 Hz；
2. **高频侧阈值**：$T = 65 + S(2) = 65 - 12.3 = 52.7$ dB。探针 40 dB < 52.7 → **听不到**；
3. **低频侧阈值**：$T = 65 + S(-2) = 65 - 27.6 = 37.4$ dB。探针 40 dB > 37.4 → **听得见**；
4. **结论**：同一个探针，放高频侧凭空消失，放低频侧安然无恙。这不是音量问题，是**衰减斜率不对称**——掩蔽的"保护区"朝高频方向拖出一条长尾。

顺手验一遍第三条事实：即使走到 3 Bark 之外，高频侧阈值仍有 $65 - 21.4 = 43.6$ dB——比安静环境里 1.4 kHz 附近的听阈（约 4 dB）高得多。**只要强音够响，"保护区"半径就大**；而无论怎么远，$T$ 最终都落在 ATH 上兜底。

## 5. 动手实验

### 实验 1（lab）：把探针拖到阈值以下，看它消失

```lab

  "title": "拖橙色三角定强音、拖圆点定探针：圆点沉入掩蔽阈值线下就听不见了；用「只听探针」做 A/B 对照",
  "maskF": 1000,
  "maskL": 65,
  "probeF": 1400,
  "probeL": 40
}
```

曲线就是掩蔽阈值 $T(f)$（虚线是绝对听阈 ATH，两者取高者）。三个必玩：

- **把探针圆点往下拖**：越过曲线的一瞬间它变红——声学参数没变，**知觉变了**。松手前点「只听探针」：它明明还在响，只是你听不见；
- **探针从 1400 Hz 拖到 700 Hz**：同样的强度，高频侧红、低频侧绿——第 4 节例题的不对称在你手里复现；
- **把掩蔽音抬到 85 dB**：整条阈值曲线不但抬高还变宽——超线性增长；探针想活命只能往远处逃或往低处躲。

### 实验 2（python）：亲手把掩蔽地图算出来

```python title="扩展函数表：距掩蔽音 ±3 Bark 的掩蔽阈值"
import math

def spread(dz):                  # 扩展函数：距掩蔽音 dz Bark 处的阈值抬升（dB）
    t = dz + 0.474
    return 15.81 + 7.5 * t - 17.5 * math.sqrt(1 + t * t)

masker = 65                      # 掩蔽音 65 dB SPL
for dz in [-3, -2, -1, 0, 1, 2, 3]:
    thr = masker + spread(dz)
    side = "低频侧" if dz < 0 else ("高频侧" if dz > 0 else "正上方")
    print(f"dz={dz:+d} Bark  掩蔽阈值 {round(thr, 1):>5} dB  ({side})")
```

七行输出画出完整的不对称：正上方 65.0，高频侧每 Bark 掉约 4~9 dB，到 +3 Bark 还剩 43.6；低频侧掉得狠得多，-2 Bark 已到 37.4。**同一份功率谱，耳朵在高频侧的"容错额度"比低频侧宽**——编码器照着这张表分配比特，省下的就是 MP3 砍掉的九成。

### 快问快答

```quiz
掩蔽阈值与绝对听阈（ATH）是什么关系？
- 掩蔽阈值永远不会低于 ATH [*]
- 掩蔽阈值就是 ATH 加一个固定偏移
- 有强音时 ATH 会降低
- 两者互不相干
? ATH 是安静环境的底，掩蔽阈值是在其上抬起来的曲线，两者取 max。再远的强音、再低的频带，阈值最起码也要守住 ATH——它决定了"高频段默认可以省很多比特"这类结论。
```

:::::warning[常见误区]

**误区一**："掩蔽就是大声音把小声音盖住了，小声音没传进耳朵。"
你以为这是能量层面的压制——不是：被掩蔽的探针照样激起了神经活动，只是大脑不报告。所以"删掉阈值以下的成分"对听感零影响，却对数据量影响巨大——这正是感知编码敢删的物理依据。掩蔽是**知觉**现象，不是声学现象。

**误区二**："掩蔽是对称的，两边差不多。"
你以为左右各让几 dB 就行——实测高频侧拖得远（约每 Bark 10 dB），低频侧陡得多（约每 Bark 25 dB）。编码器若用对称模型，低频侧的噪声会从掩蔽音"背阴面"漏出来。基底膜的行波从底端（高频）走向顶端（低频），低频能量在途会"路过"高频区留下掩蔽——不对称是解剖结构的直接后果。

**误区三**："阈值以下就绝对无声，所以编码器只需盯住掩蔽阈值。"
你以为画一条曲线就够了——掩蔽阈值之上还有**瞬时性**问题：掩蔽音刚起、刚落的前后几十毫秒里，阈值还没完全建立或已经失效（前向/后向掩蔽，见选读）。逐帧算阈值的编码器还要为"估算失手"留安全余量，否则突发段噪声露馅。

:::::

## 6. 练习

**练习 1**：算 2 Bark 处的掩蔽衰减。初始代码把两侧当成了对称：

```exercise
# @title: 练习：掩蔽的不对称
# @check: -12.3 -27.6
# @hint: Δz 的正负是信息不是误差：高频侧 +2 与低频侧 −2 要分别代入，t = dz + 0.474 不能先取绝对值
import math

def spread(dz):                  # 扩展函数：Δz Bark 处的阈值抬升（dB）
    t = abs(dz) + 0.474          # ← 问题在这：两侧斜率不同，不能取绝对值
    return 15.81 + 7.5 * t - 17.5 * math.sqrt(1 + t * t)

print(round(spread(2), 1), round(spread(-2), 1))
```

输出 `-12.3 -12.3`：两侧被"对称化"了。去掉 `abs`，t 分别是 2.474 与 −1.526，输出 `-12.3 -27.6`——低频侧的衰减比高频侧陡一倍还多。用对称模型做编码器，省下的比特会花在并不需要的地方，真正的漏洞却留在低频背阴面。

**练习 2**：编码器把某频带的量化噪声控制在掩蔽阈值下 6 dB。回答：(a) 若该频带的探针恰好停在阈值上，这 6 dB 买到了什么？(b) 若编码器高估了掩蔽量 8 dB，会听见什么？(c) 这解释了真实编码器里的哪个部件？

<details>
<summary>点开查看逐步解答</summary>

1. (a) 噪声距"刚能听见"还有 6 dB 余量——探针在阈值上时噪声仍不可闻；**余量买的是估算误差的保险**；
2. (b) 实际阈值比估计低 8 dB > 6 dB 余量：噪声冒出真实阈值 2 dB——临界带里出现可闻的嘶嘶声，通常先在高频背阴侧露馅；
3. (c) 真实编码器的**安全余量**（margin）：所有估计都有误差，感知编码必须在"多花比特"与"冒露馅风险"之间留缓冲。下一课会把它写成显式参数。

</details>

## 7. 选读：同时掩蔽之外——时间轴上的掩蔽

<details>
<summary>选读 · 前向/后向掩蔽与"预算外"的省法</summary>

本课的掩蔽发生在**同一时刻**（同时掩蔽）。人耳还有两条时间轴上的"余晖"：

- **前向掩蔽**：强音停下后，掩蔽效果还要延续几十毫秒（20 dB 级的掩蔽可持续 100 ms 上下）——耳朵的"恢复时间"；
- **后向掩蔽**：强音响起**之前**的极短窗（约 20 ms）内，弱音也会被吃掉——知觉的"提前掩蔽"，机制仍在争论，但现象稳定可测。

对编码器的意义：**省比特不必局限于强音出现的瞬间**。强音前后的弱成分区间都整段免编码——变换编码的帧间比特分配（预回声控制）就是靠这条：在强音来临前的帧里放心地把量化精度压低，反正前后窗内的误差都听不见。反过来说，若编码器**不懂**前向掩蔽，强音前一帧的高精度量化误差反而可能在强音结束后"存活的噪声"里露馅——预回声（pre-echo）伪影就是这么来的。

至此"哪里可以省"在频率轴与时间轴上都有了答案。把它们与 40 章的信息论合拢，就是下一课的感知编码器。

</details>
