# 语音合成与神经声码器

## 1. 从一个场景开始

你对着音箱说完指令，它回答「我在」——这两个字不是从任何录音里剪出来的，是机器**当场造**出来的。有声书 App 里十个小时的播音、导航里念出的每条街名，同源同理。

把一段话变成一段声，就是 TTS（文语转换）。上一课的 ASR 把声音变成文字，本课把流水线**倒过来走一遍**——倒着走才发现：每一段都有 ASR 里对应的工序，唯独「从特征到波形」这一步，难度是倒挂的。

## 2. 直觉解释

TTS 流水线四段，每段都有各自的道理：

1. **文本 → 拼音**（G2P）：查词典或用模型预测声母、韵母、声调——中文的「多音字」在这一步翻车（「行」读 xíng 还是 háng）；
2. **韵律规划**：每个音素念多长、基频 F0 怎么走——中文声调是命门，同一串音节，声调不对就不是那个词。这就是「音调」「语速」两个旋钮在管的事；
3. **声学模型**：把语言学特征变成**梅尔谱**——一条 40 维的「包络画像」，注意**不是波形**；
4. **声码器**：把梅尔谱变回波形，可以出声播放。

第 3、4 段的分家是最值得琢磨的设计：声学模型为什么不直接吐波形？因为波形是 16000 个样本/秒的微观决策，连相位都难学；梅尔谱丢掉相位、只留人耳敏感的包络——**把难题切开，每半都变简单**。最后一公里交给专职的声码器。

## 3. 正式定义

**声学模型**：$c \mapsto M$，语言学特征 $c$ 到梅尔谱 $M \in \mathbb{R}^{T \times 40}$ 的映射（$T$ 为帧数）。

**声码器**：$M \mapsto x$，梅尔谱到波形 $x[n]$ 的映射。两代技术：

- **参数声码器**（第 90 课）：用「源-滤波」参数（基频 + 共振峰包络）硬性重建——规则驱动，本课 lab 里的教具声码器就是这一族；
- **神经声码器**（本课主角）：从数据里学这个映射。**自回归**一族的代表 WaveNet 逐样本生成：

$$p(x) = \prod_{n=1}^{N} p(x_n \mid x_1, \dots, x_{n-1})$$

正是第 49 章[自回归模型](../49-generative-models/index.md)的链式法则在波形上的直接落地。新一代用扩散模型并行生成（49 章的扩散数学再就业）。

**音调与半音**：倍率 $r$ 对应的半音数是 $12\log_2 r$——倍率 2（一个八度）恰好 12 个半音。

**梅尔刻度**（第 40 课）：$m = 2595\log_{10}\left(1 + \dfrac{f}{700}\right)$，把人耳「低频挑、高频糙」的听感折成线性刻度。

## 4. 分步例题

**例 A**：把 lab 里的「音调」滑块拖到 1.5，相当于升几个半音？

1. $12\log_2 1.5 = 12 \times 0.5850 = 7.02$ 半音；
2. 7 个半音恰好是纯五度——所以「音调 ×1.5」听起来像把整句话移了五度，词没变、调门变了。

**例 B**：语速滑块拖到 1.8，每个音素的时长变成多少？

1. 语速 1.8 倍 = 时长 $\div 1.8 \approx 0.56$ 倍；
2. 梅尔谱图上表现为**横向压缩**——声学特征对时长的这种敏感，正是流水线里需要独立「时长模型」的原因：声学模型得先知道每个音素占几帧。

**例 C**：1000 Hz 在梅尔刻度上是多少？

1. $m = 2595\log_{10}(1 + 1000/700) = 2595\log_{10} 2.4286 \approx 1000$ mel；
2. 刻度就是照着「1000 Hz ≈ 1000 mel」标定的——公式不是巧合，是定义的回声。

## 5. 动手实验

### 实验 1（lab）：从文本到波形，逐段点开

```lab
{
  "type": "tts-overview",
  "title": "把音调拖到 1.5，听一听 F0 对合成结果意味着什么",
  "text": "数学语音真有趣",
  "pitch": 1.2,
  "speed": 1.0
}
```

四段流水线：文本→拼音、语言学特征（含 F0 曲线）、梅尔谱热图、波形试听。做三件事：

- 把「音调」拖到 1.5——梅尔谱**整体上下平移**（F0 变了），波形疏密跟着变，播放听听五度移调的效果；
- 把「语速」拖到 0.6 再拖到 1.8——音素被拉伸/压缩，梅尔谱横向伸缩：**这就是时长模型的工作对象**；
- 对比 lab 里的教具声码器与任何商用 TTS 的音色——教具一听就是机器人，差距全在声码器与韵律那两段。

### 实验 2（python）：音调倍率与半音

```python title="滑块倍率换算成乐理半音"
import math
for name, r in [("音调 ×0.6", 0.6), ("音调 ×1.2", 1.2),
                ("音调 ×1.5", 1.5), ("音调 ×1.6", 1.6)]:
    st = 12 * math.log(r, 2)
    print(f"{name}: {st:+.2f} 半音")
```

四行输出覆盖了滑块全程：0.6 倍约降一个大六度（−8.84 半音），1.6 倍约升一个小六度（+8.14 半音）。**对数刻度把「乘法关系」变成「加法刻度」**——这和 73 章分贝课的 dB 是同一个思想在乐理里的表亲。

### 实验 3（python）：声码器的算力账

```python title="自回归声码器的逐样本预算"
fs = 16000
for dur in [1, 10, 600]:
    print(f"{dur:>4} 秒语音 = {fs*dur:>8} 个波形样本")
```

1 秒 16000 个样本，就是自回归声码器 16000 次「逐样本前向」；一小时的有声书是 5760 万次。**波形生成是流水线里最贵的一段**——并行声码器（流匹配、扩散蒸馏）的全部商业价值，就是把这条账砍掉一个数量级。

### 快问快答

```quiz
神经 TTS 的声学模型输出的是？
- 直接输出一个个波形样本
- 梅尔谱：一条「包络画像」，波形细节交给声码器去补 [*]
- 拼音序列
? 波形要逐样本定 16000 个决策/秒、相位还难学；梅尔谱丢掉相位、只留人耳敏感的包络，把「最后一公里」留给专职声码器。分而治之，每一段都变简单。
```

::::warning[常见误区]

**误区一**："TTS 就是把录音剪来剪去。"
你以为合成靠素材库拼接——那是上个时代的主流量（拼接合成），录音师要录几万句才能拼出自然语音。神经 TTS 是**从头生成**：模型见过几百小时数据之后，任何没录过的句子都能造。

**误区二**："声学模型好了就万事大吉。"
你以为梅尔谱像就等于听得像——声码器决定**最后一公里**的音质：同一份梅尔谱，教具声码器合成出来是机器人，神经声码器出来是真人。流水线的短板永远在「最贵的那一段」。

**误区三**："把每个字念对就自然了。"
你以为 TTS 是朗读生词表——**韵律**（F0 走向、时长、停顿）才是自然度的分水岭：中文声调错了意思就错，节奏平了像机器报时。拼音只是入场券，韵律模型才是主角。

::::

## 6. 练习

**练习 1**：把「音调 ×1.5」换算成半音数，输出应为 `7.02`。下面这段代码底数用错了：

```exercise
# @title: 练习：这个音调滑块相当于几个半音
# @check: 7.02
# @hint: 半音数 = 12·log₂(倍率)。math.log 只给一个参数时底是 e，不是 2
import math

ratio = 1.5      # 「音调」滑块拖到 1.5
semitones = 12 * math.log(ratio)   # ← 问题在这：底数不对
print(round(semitones, 2))
```

**练习 2**：女声基频 220 Hz、男声 110 Hz，两者差几个半音？语速滑块 1.8 时，0.9 秒的一句话被压成多长？

<details>
<summary>点开查看逐步解答</summary>

1. 半音差：$12\log_2(220/110) = 12\log_2 2 = 12$——整整**一个八度**，这就是男女声最典型的音域距离；
2. 语速 1.8：$0.9 / 1.8 = 0.5$ 秒——时长与语速倍率成**反比**，而音调与倍率成**正比的对数**。两个旋钮一个线性一个对数，别记混。

**串起来的直觉**：语速管横向（时间轴拉伸），音调管纵向（F0 平移）——正好对应 lab 里梅尔谱热图的横向压缩与整体上移。

</details>

## 7. 选读：声码器谱系

<details>
<summary>选读 · 从 WaveNet 到扩散声码器</summary>

- **WaveNet（2016）**：把第 49 章的自回归链式法则原样搬到波形上，$p(x_n \mid x_{<n})$ 用膨胀因果卷积建模——音质里程碑，但逐样本生成太贵（见实验 3 的算力账），早期商用要靠几十块 GPU 集群；
- **流/流匹配一族（2018–2020）**：用可逆变换在「简单分布」与「波形分布」之间搭桥，生成可并行，音质略让；
- **扩散声码器（2021–）**：第 49 章的扩散数学再就业——把「从梅尔谱生成波形」当成从噪声逐步去噪的过程，质量与速度可调，蒸馏后能实时。

谱系的走向与图像生成完全同构：**自回归 → 流 → 扩散**。语音与图像在生成模型这里会师——本章与第 49 章是同一条数学的两次落地。

</details>
