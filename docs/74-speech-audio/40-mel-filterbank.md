# 梅尔刻度与听觉滤波组

## 1. 从一个场景开始

在钢琴上调个音：100 Hz 和 200 Hz，一耳朵的事；可 7000 Hz 和 7100 Hz，听半天也没觉得哪里不同。同样是差 100 Hz，低频端惊天动地，高频端无感。

这不是你的错觉，是耳蜗的构造：**底膜在低频端分得细、高频端分得粗**——人耳自带一把"低频精密游标卡尺 + 高频粗尺"的不均匀频率尺。机器想"像人一样听话"，就该先按这把尺子重新量频率。这把尺子叫**梅尔刻度**；按它摆放的一组滤波器，叫**梅尔滤波器组**——从上世纪八十年代到今天，几乎所有语音识别系统的第一道"感知整形"都是它。

## 2. 直觉解释

心理声学量过一个事实：人耳把可听频段（约 20 Hz~20 kHz）分成约二十几个**临界频带**——每个"频道"内几个音挤在一起就互相遮掩，分频道才听得开。关键在频道的**宽度**：低频端一个频道只有约 100 Hz 宽，高频端能宽到 2000 Hz 以上。

梅尔刻度做的事，就是把这些**宽度不一的频道拉成一样宽**：

- 1000 Hz 以下：近似线性——mel 数 ≈ Hz 数，尺子没怎么动；
- 1000 Hz 以上：对数压缩——Hz 涨得飞快，mel 涨得从容。

于是"人耳觉得均匀"的刻度被造了出来。把上节课的语谱图频率轴换成梅尔轴，图没变，但**每个格子上的信息密度和人耳的感受对齐了**——低频区（基音、第一共振峰的家）被放大镜照顾，高频区被粗略扫过。

## 3. 正式定义

**赫兹 ↔ 梅尔**（工程最常用的一对近似公式）：

$$\text{mel}(f) = 2595 \cdot \log_{10}\left(1 + \frac{f}{700}\right), \qquad f = 700 \left(10^{\text{mel}/2595} - 1\right)$$

几个锚点：mel(0) = 0，mel(1000) ≈ 1000（刻度在 1 kHz 处"归零对齐"），mel(400) ≈ 509，mel(4000) ≈ 2146，mel(8000) ≈ 2840。看得出 4~8 kHz 那整整 4000 Hz 只占约 700 mel——高频被狠狠压扁。

**梅尔三角滤波器组**：在梅尔轴上取 $M$ 个等间距的中心点（语音识别常用 $M = 26$），每个点上立一个三角形滤波器——底边跨过左右邻中心、顶点在自身中心、相邻滤波器**半重叠**：

$$E_m = \sum_{k} |X(k)|^2 \cdot H_m(k)$$

即把功率谱按每个三角的形状加权求和，得到 $M$ 个能量 $E_0, \dots, E_{M-1}$。一步干成三件事：**按人耳加权**（感知整形）、**把几百个频点压成 26 个数**（降维）、**把谱的细刺抹平只留包络**（平滑）。

## 4. 分步例题

**例**：0~8000 Hz 摆 26 个梅尔滤波器，看看它们落到赫兹轴上长什么样。

1. 总跨度：mel(8000) − mel(0) ≈ 2840 mel；
2. 27 个等距端点把轴分成 27 格：每格 $2840/27 \approx 105.2$ mel；
3. 1 号滤波器（最左）：底边 0 → 105.2 mel，折回赫兹是 0 → 68.5 Hz——带宽 **68.5 Hz**；
4. 26 号滤波器（最右）：底边 $25 \times 105.2 = 2630$ mel → $27 \times 105.2 = 2840$ mel，折回赫兹约 6519 → 8000 Hz——带宽 **1481 Hz**；
5. **对比**：同为"一格"宽，低频端 68.5 Hz、高频端 1481 Hz，差 **22 倍**；整条轴的中点（1420 mel）折回赫兹只到 **1767.8 Hz**——一半的滤波器挤在 0~1.8 kHz 里。

这就是"低频密、高频疏"的定量版：梅尔轴上人人平等，赫兹轴上重轻有别。

## 5. 动手实验

### 实验 1（lab）：一张图看两把尺子

```lab
{
  "type": "mel-filterbank",
  "title": "拖探针竖线：同一个通道，赫兹轴上挤、梅尔轴上齐",
  "nFilters": 26,
  "fmax": 8000,
  "probe": 1000
}
```

上行：26 个三角滤波器摆在**赫兹轴**上——左边挤成一摞，右边又宽又扁；中行：同一批摆在**梅尔轴**上——立刻变成等宽等高的整齐一排。这两张图的对比就是整节课的结论。做三件事：

- 拖橙色探针竖线：看同一个频率在第几号通道、通道带宽多少——探针放到 500 Hz 和放到 7000 Hz，读数里"局部密度"差出量级；
- 拖最右端的把手改 fmax：fmax 越小整组越往低频集中，语音识别常取 8000 甚至更低；
- 拖「滤波器个数」：个数加多通道变窄，但相邻通道越来越像——信息没多，冗余多了。

### 实验 2（python）：算一遍"第 1 通道 vs 第 26 通道"

```python title="梅尔等距 → 赫兹悬殊：滤波器带宽差多少倍"
import math

def hz2mel(f):
    return 2595 * math.log10(1 + f / 700)

def mel2hz(m):
    return 700 * (10 ** (m / 2595) - 1)

M, fmax = 26, 8000.0
dm = hz2mel(fmax) / (M + 1)                # 梅尔轴上相邻中心的间距
w1 = mel2hz(dm) - mel2hz(0)                # 1 号通道带宽（Hz）
w26 = mel2hz(27 * dm) - mel2hz(25 * dm)    # 26 号通道带宽（Hz）
print(f"第 1 通道带宽 {w1:.1f} Hz，第 26 通道带宽 {w26:.1f} Hz，"
      f"差 {w26 / w1:.0f} 倍")
```

输出里那个 22 倍，就是第 4 节手算的数值复核。再来一个直觉换算：mel(1000) ≈ 1000 意味着 1 kHz 以下尺子几乎没动；而 4~8 kHz 折算只占约 700 mel——**把频谱搬到梅尔轴，等于把人耳的注意力写进了坐标系**。

```quiz
把梅尔轴上等距排开的三角滤波器组画回线性赫兹轴，它长什么样？
- 低频挤、高频疏，像一把左密右疏的梳子 [*]
- 依然均匀分布，只是三角形变成了矩形
- 低频疏、高频挤，方向正好相反
? 梅尔刻度把人耳"低频精细、高频粗糙"的感受拉平了；拉平后再倒回赫兹轴，自然呈现低密高疏。
```

::::warning[常见误区]

**误区一**："梅尔刻度就是音高刻度。"
你以为 mel 管的是"调子多高"——mel 是**频率的心理标度**，回答的是"这个频率听起来离那个频率多远"。音高还依赖声强（同一纯音，声音越大显得调子略低），那是另一层感知现象。

**误区二**："滤波器越多越好，信息越全。"
你以为 26 换 64 稳赚——通道越多单个越窄，相邻通道的输出高度相关（几乎是同一个数复制两份），对噪声和音高微移反而更敏感。26 是"细节够用、冗余可控"的折中，多数系统还在它上面再砍到 13 维（下一课）。

**误区三**："fmax 拉满 20 kHz 才不丢信息。"
你以为截到 8 kHz 损失惨重——元音的三个共振峰几乎都住在 3.5 kHz 以下，电话线只传 300~3400 Hz 大家照样听得清。语音识别取 fmax = 8000 或更低，省下的算力买的是更低的通道密度与更稳的特征。

::::

## 6. 练习

**练习 1**：26 个滤波器摆满 0~8000 Hz 的梅尔轴，求整条轴中点（梅尔值）折回赫兹是多少，输出应为 `1767.8`。这段代码直接在赫兹轴上取了中点：

```exercise
# @title: 练习：梅尔轴的中点落在哪个频率
# @check: 1767.8
# @hint: 中点要在梅尔轴上取：先算 mel(fmax)，取一半，再用反变换折回赫兹
fmax = 8000.0
# 梅尔轴总长的一半对应多少赫兹？
f_mid = fmax / 2    # ← 问题在这：赫兹轴上的中点 ≠ 梅尔轴上的中点
print(round(f_mid, 1))
```

正确写法走两步：`mel_hi = 2595 * math.log10(1 + fmax / 700)` 得 2840.0，取一半 1420.0，再 `f_mid = 700 * (10 ** (mel_hi / 2 / 2595) - 1)` 得 1767.8。4000 和 1767.8 的差距，就是"人耳把一半注意力花在 0~1.8 kHz"这句话的数值版。

**练习 2**：梅尔值为 2000 对应多少赫兹？它落在哪个临界区域——人耳精细区还是粗糙区？

<details>
<summary>点开查看逐步解答</summary>

1. 反变换：$f = 700 \left(10^{2000/2595} - 1\right) = 700 \left(10^{0.7707} - 1\right) \approx 700 \times 4.898 = 3428.7$ Hz；
2. 3428.7 Hz 已在 1000 Hz 之上很远——**粗糙区**：从这里到 8000 Hz 还要走 840 mel，可赫兹上还剩 4571 Hz；
3. 对照第 4 节：0~1000 Hz 占 1000 mel、3429~8000 Hz 只占 840 mel——同为"一段感受距离"，赫兹宽度差 5 倍以上。工程含义：梅尔轴 2000 mel 以上（3.4 kHz 以上）的通道主要在描 /s/ 这类摩擦噪声，对元音识别贡献很小。

</details>

## 7. 选读：Bark 刻度与"取对数前的地板"

<details>
<summary>选读 · 两条感知尺与一个工程细节</summary>

梅尔不是唯一的感知频率尺。Zwicker 的 **Bark 刻度**把可听频段按临界频带直接编成 1~24 号（每号一个频带），物理意义更"耳蜗"；梅尔的公式简单、可逆、够准，工程上反而赢了。两者形状相近：都是 500 Hz 以下近线性、以上近对数。

另一个工程细节，下一课马上要用：滤波器组输出 $E_m$ 之后通常要**取对数**，但能量可能恰好为零（静音帧、深陷的谷）——$\log 0$ 直接爆炸。惯例是先加一个地板：$\log(E_m + \epsilon)$，$\epsilon$ 取 $10^{-10}$ 量级。这个看似不起眼的加法，是每份 MFCC 实现里都必有的一行。

</details>
