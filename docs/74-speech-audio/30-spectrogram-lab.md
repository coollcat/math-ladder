# 语谱图：声音的照片

## 1. 从一个场景开始

聋人乐队的鼓手靠地板的振动找节拍；鸟类的研究者把录到的鸣叫"翻译"成图来认物种；学外语的 App 让你把自己的发音和母语者的发音**画在一起对比**。它们看的都是同一张图：横轴时间、纵轴频率、颜色深浅是能量——**语谱图**，声音的照片。

机器读语音的第一眼也是这张照片。上一课你把信号切成了帧、每帧能算一条频谱；这一课把这些频谱**按时间排开、涂上颜色**，波形就变成了一张能"看图说话"的照片。

## 2. 直觉解释

做法朴素到只有三步：

1. 按上一课的办法把信号分帧（帧长、帧移、加窗）；
2. 每一帧做一次 DFT，得到一条频谱——把它**竖起来**当作一张图里的**一列**；
3. 帧往前挪，下一列贴在右边。成百上千列铺满，颜色编码每格的能量强弱。

读照片的口诀：

- **横条纹**：某几个频率上持续有能量——浊音的谐波！条纹的间隔就是基频 $f_0$，条纹越密音调越高；
- **横条纹整束上下弯**：共振峰在滑动——元音在切换；
- **竖直的黑条**：极短时间、宽频带的能量——爆破音（/p/ /t/ /k/）的瞬间；
- **乱纹**：无结构的宽带噪声——清音 /s/ /f/。

波形图只告诉你"什么时候响"，语谱图告诉你"**什么时候、什么频率、有多响**"——多了一个维度，声音就有了句法。

## 3. 正式定义

**短时傅里叶变换（STFT）**与**语谱图**：

$$X_m(k) = \sum_{n=0}^{N-1} x[mH + n]\, w[n]\, e^{-j 2\pi k n / N}, \qquad \text{Spec}(m, k) = 20\log_{10} |X_m(k)|$$

- $m$ 是帧号（时间轴）、$k$ 是频点（频率轴）：语谱图就是 STFT 模的分贝图；
- 只取幅度不取相位：语音识别几乎只关心"哪些频率有能量"，相位被丢掉——后面你会看到这是惯例而非偷懒；
- 颜色映射的动态范围（比如 60 dB）是可调的"曝光度"：压得越狠，弱成分越显形。

**时频账本**（20 课的两个分辨率在图上的化身）：

| 帧长 $N$ @16 kHz | 每列时间宽 | 频率格距 $\Delta f$ | 图上看什么最清 |
| --- | --- | --- | --- |
| 128（8 ms） | 细 | 125 Hz | 竖直的瞬态、爆破音 |
| 2048（128 ms） | 粗 | 7.8 Hz | 细密的谐波横条纹 |

帧长与时宽的乘积被不确定性钉死：**一列不可能同时"瞬间"又"单频"**。

## 4. 分步例题

**例**：16 kHz 采样的 0.5 秒语音，帧长 512、帧移 128。这张语谱图多大？

1. 总样点 $S = 8000$；帧数 $K = 1 + \lfloor (8000 - 512)/128 \rfloor = 1 + 58 = 59$ 列；
2. 每列时间宽 $512/16000 = 32$ ms，列间距 $128/16000 = 8$ ms；
3. 频率格距 $\Delta f = 16000/512 = 31.25$ Hz，取正频率共 $512/2 + 1 = 257$ 行；
4. 整图 **59 列 × 257 行**，每格一个分贝值——这就是机器眼里"0.5 秒声音"的全貌。

**读图练习**：想象说"/a/ — /i/ — /u/ — /s/"的语谱图。前三段都有横条纹（浊音、同一副声带所以间隔不变），但条纹束的位置不同：/a/ 段最亮的带子在 730 与 1090 Hz 附近，/i/ 段一条亮带蹿到 2290 Hz，/u/ 段两条带子挤到 300 与 870 Hz 以下；末段 /s/ 条纹消失、只剩一片乱纹。**条纹管音高，条纹束管元音，乱纹管清音**——一句话读图的全部要领。

上行波形、中行语谱图、下行**光标所在那一帧的频谱切片**——语谱图正是把这条条切片并排铺出来的。做三件事：

- 拖竖线从 /a/ 扫到 /i/：切片上的双峰从 (730, 1090) 滑向 (270, 2290)，中图上表现为亮带的上移；
- 把帧长拖短再拖长：帧短时竖直瞬态锐利、横条纹糊；帧长时条纹根根分明、瞬态拖泥——时频账本亲眼见；
- 点「用麦克风」对着话筒说 /a/ /i/ /s/：看自己的横条纹和乱纹（麦克风只做分析，不回放）。

### 实验 2（python）：亲手摸一列像素

```python title="一帧 64 样点的迷你频谱：语谱图的一个亮格是怎么来的"
import math

fs = 16000
frame = 64                       # 一帧 64 个样点（4 ms）
x = [math.sin(2 * math.pi * 2000 * n / fs) for n in range(frame)]

def mag(f):                      # 在频率 f 处"探"这帧的能量
    re = sum(x[n] * math.cos(2 * math.pi * f * n / fs) for n in range(frame))
    im = -sum(x[n] * math.sin(2 * math.pi * f * n / fs) for n in range(frame))
    return math.sqrt(re * re + im * im)

for f in [500, 2000, 3500]:
    print(f"f={f:>5} Hz  |X|={mag(f):.4f}")
```

这帧信号是干净的 2000 Hz 正弦（正好落在 $\Delta f = 16000/64 = 250$ Hz 的格点上），所以探针在 2000 Hz 处读到满值 $N/2 = 32$，在 500、3500 Hz 处读数是零——**语谱图在 (时间=这一帧, 频率=2000 Hz) 的格子上就是一个亮点**。真实的语谱图无非是把这样的探针铺满全部格点、再染上颜色。

```quiz
语谱图上浊音段的横条纹，相邻两条纹的间隔等于什么？
- 基频 f0：谐波间隔就是 f0 [*]
- 第一共振峰 F1
- 采样率的一半
? 浊音的频谱是一根根间隔 f0 的谐波，所以条纹密=音调高、条纹疏=音调低；共振峰管的是条纹"束"的明暗位置，别和条纹间隔混了。
```

::::warning[常见误区]

**误区一**："语谱图的纵轴是音高。"
你以为纵轴就是"调子"——纵轴是**频率**，上面同时住着谐波条纹（间隔 = $f_0$）和共振峰亮带（滤波器的峰）。音高只是从"条纹间隔"里**读出来**的信息，不是坐标轴本身。

**误区二**："帧长越大，照片越清楚。"
你以为参数往大调总是赚——帧长加一倍，频率细一倍，**时间糊一倍**：两帧之间发生的事（爆破、音高滑动）被平均进一列里。读瞬态用短帧（宽带谱图），读谐波用长帧（窄带谱图），没有全赢。

**误区三**："颜色亮 = 声音大。"
你以为亮格对应整段波形响——每个格子的颜色只代表**那一帧、那个频点**的能量。整帧响不响看上行波形；一个 6 kHz 的亮格完全可能出现在一段"听起来很轻"的清音里。

::::

## 6. 练习

**练习 1**：16 kHz 采 0.5 秒，帧长 512、帧移 128。求完整帧数（语谱图的列数），输出应为 `59`。这段代码没给最后一帧留位置：

```exercise
# @title: 练习：语谱图有多少列
# @check: 59
# @hint: 最后一帧也要完整装下 512 个样点才算数——从总样点里先扣掉一个帧长
samples = 8000    # 0.5 秒 @ 16 kHz
frame = 512
hop = 128
cols = samples // hop    # ← 问题在这：把 hop 当成了帧长在切
print(cols)
```

按 20 课的帧数公式：`cols = 1 + (samples - frame) // hop = 1 + 58 = 59`。顺带算算行数：$512/2 + 1 = 257$——59 列乘 257 行，就是这张照片的全部像素。

**练习 2**：一段录音的语谱图上，前半段横条纹间隔约 8.3 ms，后半段约 5.6 ms。两段的基频各是多少 Hz？说话人是升调还是降调？

<details>
<summary>点开查看逐步解答</summary>

1. 条纹间隔 = 谐波间隔 = $f_0$，但图上量到的是**时间**：间隔 8.3 ms → $f_0 = 1/0.0083 \approx 120$ Hz；间隔 5.6 ms → $f_0 = 1/0.0056 \approx 178$ Hz；
2. 后半段基频更高 → **升调**（比如"是吗？"的语调）；
3. 反过来也成立：读窄带语谱图时，"数条纹的疏密"就是在读音高曲线——声调语言的语调信息就住在条纹的疏密里。

</details>

## 7. 选读：宽带与窄带——同一句话的两张照片

<details>
<summary>选读 · 两种谱图各读各的</summary>

传统语音学把语谱图分成两派：

- **宽带谱图**（短帧，如 5 ms）：时间细、频率糊。谐波条纹黏成一团，但共振峰显现为清晰的**竖杠**（每根竖杠是一次声门脉冲激励后声道的"余振"），竖杠的间距 = 基频周期。读**共振峰走势**（元音、韵母）看它；
- **窄带谱图**（长帧，如 40 ms）：频率细、时间糊。共振峰糊成宽带，但谐波横条纹**根根数得清**，间隔 = $f_0$。读**音高曲线**（声调、语调）看它。

两张照片信息相同、读法互补——本质就是 20 课那笔时频交易换了个消费场景。工程上用哪张，取决于你要从图里抽什么特征。

</details>
