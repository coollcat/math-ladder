# 语音增强与说话人：从降噪到分离

## 1. 从一个场景开始

地铁里打电话，对方说"你那边能不能找个安静的地方"——其实你听见的是一整片轰隆，对方听见的却主要是你的声音。这中间的差别不是运气：手机在你说话的时候，**实时把不属于你的那部分声音按下去了**。

按下去的手法叫语音增强，第一站是最经典的降噪；比它更狠的一步是**分离**——同一段录音里两个人同时说话，要把它切成两轨。而在按下之前必须回答一个前置问题：**哪个声音是你？** 这一步叫说话人识别，靠的是把每段语音压成一个向量再比距离。

## 2. 直觉解释

**加性噪声模型**：麦克风收到的是 $y[n] = x[n] + d[n]$，干净语音 $x$ 与噪声 $d$ 直接相加。时域上分不开，但切一帧做短时傅里叶之后，两者仍是叠加的——频率一样、幅度相加。

**谱减法**：既然幅度相加，那把噪声的幅度**减掉**不就行了？先录一小段只有噪声的静音段当作"噪声画像" $\hat D$，之后每一帧都减去它。道理极简，坑也极深：减多了，某些频点变成负值（没意义）；每帧减的多少不一样，拼回去听起来像有人在水下弹钢片琴——这就是著名的**音乐噪声**。

**维纳滤波**：换个更体面的说法——不是"减"，而是"**按信噪比加权**"。某个频点信噪比高，就几乎原样保留；信噪比低，就悄悄调小。第 100 课讲过耳朵对同时出现的强音弱音有掩蔽效应：**增强的目标不是把噪声降为零，而是把它降到听不见的掩蔽门限以下**。

**说话人与分离**：同一句话，不同的人声道长度、共振峰位置不同——把这些差异压成一个固定长度的**说话人嵌入**（x-vector 一族），两段语音是不是同一个人就变成两个向量的夹角问题（第 20 课余弦相似度）。而多人混说时，若只知道"有几路信号、彼此独立"，就能用独立成分分析把混音拆开（第 61 章第 97 课 ICA 专治这个鸡尾酒会问题）。

## 3. 正式定义

**加性噪声与短时谱**：$y[n]=x[n]+d[n]$，分帧加窗后 $Y(k)=X(k)+D(k)$（$k$ 为频点）。

**谱减法**（带过减因子 $\alpha$ 与谱底 $\beta$）：

$$|\hat X(k)| = \max\bigl(|Y(k)| - \alpha\,|\hat D(k)|,\ \beta\,|Y(k)|\bigr)$$

**维纳滤波**：设先验信噪比 $\xi(k)=P_X(k)/P_D(k)$，增益

$$H(k)=\frac{\xi(k)}{1+\xi(k)},\qquad |\hat X(k)| = H(k)\,|Y(k)|$$

**说话人嵌入与余弦相似度**：把一段语音映成向量 $e\in\mathbb R^{d}$，

$$\mathrm{sim}(e_1,e_2)=\frac{e_1\cdot e_2}{\lVert e_1\rVert\,\lVert e_2\rVert}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $y[n]$ | 观测信号 | 麦克风录到的混合波形 |
| $x[n],\,d[n]$ | 干净语音 / 噪声 | 想留下的、想扔掉的 |
| $Y(k),\,X(k),\,D(k)$ | 短时频谱 | 一帧信号的傅里叶系数（复数） |
| $|\hat D(k)|$ | 噪声幅度估计 | 从静音段统计出来的"噪声画像" |
| $\alpha$ | 过减因子 | 减得比估计值多一点，宁可削语音也不留噪声 |
| $\beta$ | 谱底系数 | 给每个频点留个底，压住音乐噪声 |
| $\xi(k)$ | 先验信噪比 | 这一频点信号比噪声强多少倍 |
| $H(k)$ | 维纳增益 | $0\sim1$ 之间的"保留比例" |
| $e$ | 说话人嵌入 | 一段语音的固定长度指纹向量 |

两者的关系值得记一句：**谱减法是"减法"，维纳滤波是"乘法"**。当 $\xi$ 很大时 $H\to1$ 全保留，$\xi$ 很小时 $H\to0$ 全压制——它把"减多少"换成了一个连续可导的缩放系数，这正是它比硬减更稳的原因。

## 4. 分步例题

一帧 8 频点的带噪幅度谱 $|Y|=[3.0,8.0,6.5,4.0,2.0,1.5,1.0,0.6]$，噪声画像 $|\hat D|=[0.5,0.6,7.2,4.5,2.5,1.9,1.3,0.9]$。取 $\alpha=1.0$、$\beta=0.1$。

1. **逐点相减**：$2.5,\ 7.4,\ -0.7,\ -0.5,\ -0.5,\ -0.4,\ -0.3,\ -0.3$——后 6 个频点全是负的，说明这几格的"信号估计"还不如噪声大；
2. **求谱底**：$\beta|Y| = [0.3,0.8,0.65,0.4,0.2,0.15,0.1,0.06]$；
3. **半波整流 + 铺底**：每个频点取 $\max(\text{第1步},\text{第2步})$，得 $[2.5,\ 7.4,\ 0.65,\ 0.4,\ 0.2,\ 0.15,\ 0.1,\ 0.06]$；
4. **读结论**：前两个频点被完整保留（信噪比高），后 6 个被压到谱底——它们被认为是噪声主导；
5. **维纳视角复核**：第 3 个频点若 $P_X/P_D=0.1$，则 $H=0.1/1.1=0.091$，$|Y|\times H=6.5\times0.091\approx0.59$——与谱减法给出的 $0.65$ 同量级，两条路殊途同归。

## 5. 动手实验

### 实验 1（lab）：先学会在语谱图上分清"该留的"和"该扔的"

```lab
{
  "type": "spectrogram-lab",
  "title": "横条纹是浊音（要留），乱纹是清音/噪声（要压）",
  "kind": "vowels",
  "frameLen": 256,
  "hop": 64,
  "range": 50
}
```

拖竖线扫时间，盯住三种纹路：**横条纹**（一条条平行的亮线）是浊音 /a/ /i/ /u/，声带振动的谐波——增强时必须留住；**乱成一片的马赛克**是 /s/ 这类清音——它和噪声同住高频，是降噪最容易误伤的地方；**两段之间的纯黑**正好当噪声画像的来源。做三件事：

- 把帧长从 256 拖到 1024：频率看细了但时间糊成一团——短时分析的老规矩（第 20 课）；
- 拖到 64：时间清楚了，谐波条纹却糊掉。**增强要在哪一侧取帧长，取决于你想保护的是什么**；
- 反复对比 /s/ 段与噪声段的语谱：它们长得像不像？越像，纯靠幅度谱的降噪就越容易把它一起削掉。

### 实验 2（python）：亲手跑一遍谱减法

```python
mag_y = [3.0, 8.0, 6.5, 4.0, 2.0, 1.5, 1.0, 0.6]   # 带噪帧幅度谱（8 个频点）
mag_d = [0.5, 0.6, 7.2, 4.5, 2.5, 1.9, 1.3, 0.9]   # 噪声幅度谱估计（静音段统计而来）

alpha = 1.0     # 过减因子：减得比估计值多一点
beta = 0.1      # 谱底系数：给每个频点留 beta*|Y| 的底，压住音乐噪声

mag_hat = []          # 增强后的幅度谱
rectified = 0         # 统计有多少频点被"整流"了（说明它们被噪声主导）
for y, d in zip(mag_y, mag_d):        # zip：把两条谱并排拉链，逐点配对
    s = y - alpha * d                 # 谱减：幅度谱直接相减
    floor = beta * y                  # 铺底门限
    if s < floor:
        rectified = rectified + 1     # 这一格减成了负值，得靠谱底托住
    s = max(s, floor)                 # 半波整流 + 铺底：取两者较大的
    mag_hat.append(round(s, 2))       # 保留两位小数存进结果

print(mag_hat)
print("被整流频点数:", rectified)
```

输出 `[2.5, 7.4, 0.65, 0.4, 0.2, 0.15, 0.1, 0.06]` 与 `被整流频点数: 6`。**8 个频点里有 6 个被判成"噪声主导"**——这就是谱减法敢下手的地方，也正是它容易误伤 /s/ 的地方。把 `beta` 改成 0（不铺底）再跑，弱频点全落到 0，重建出来就是那片"水下钢片琴"。

### 实验 3（python）：维纳增益的连续缩放

```python
for xi in [0.1, 0.5, 1.0, 4.0]:        # xi：先验信噪比 P_X/P_D
    h = xi / (1.0 + xi)                # 维纳增益：信噪比越高，保留比例越大
    print(round(xi, 1), "→", round(h, 3))
```

输出四行：`0.1 → 0.091`、`0.5 → 0.333`、`1.0 → 0.5`、`4.0 → 0.8`。信噪比 1（信号与噪声等强）时保留一半——增益恰好落在 0.5，这是维纳滤波最好记的一个数。**它不像谱减法那样有"减成负数"的事故，因为 $H$ 天生落在 $(0,1)$ 里**。

### 快问快答

```quiz
谱减法最容易留下的"音乐噪声"，本质上是哪里来的？
- 每帧减去的噪声估计略有起伏，残留量随之抖成一段段断续的窄带音 [*]
- 麦克风采样率不足导致的混叠
- 相位估计错误带来的回声
? 噪声画像是一段统计平均值，真实噪声却帧帧不同；相减后残留的少量噪声在频率上忽高忽低，听起来就像随机敲击的乐音。谱底 beta 与过减因子 alpha 就是专门对付它的两个旋钮。
```

## 6. 常见误区

:::warning[常见误区]

**误区一**："降噪就是把噪声减到零。" 其实增强的目标是**降到掩蔽门限以下**（第 100 课）。噪声的残余只要听不见就够了；一味求"零噪声"只会把语音的弱频点一起削掉，反而更难听。工程上的评价指标也常是语音失真与噪声残留的折中，而不是"噪声越小越好"。

**误区二**："维纳滤波比谱减法高级，所以谱减法没用了。" 其实两者是**同一件事的两种取近似**：谱减法直接对幅度动手，维纳滤波按信噪比连续缩放。谱减法计算量极小、无需噪声与信号的功率谱模型，在嵌入式和实时通话里至今活跃。工具没有高低，只有假设是否匹配。

**误区三**："说话人识别就是在听内容。" 其实它听的是**与内容无关的声道特征**——同一句话由两个人说，文本一模一样，嵌入向量的夹角却能拉开很大；反过来，同一个人说不同内容，嵌入反而靠得很近。认出人靠的是"怎么说的"，不是"说了什么"。

:::

**练习 1**：给一帧做谱减法，注意"先相减、再半波整流铺底"的次序。下面的代码能跑，但输出里出现了负幅度谱——改到通过：

```exercise
# @title: 练习：给一帧做谱减法
# @check: [2.5, 7.4, 0.65, 0.4, 0.2, 0.15, 0.1, 0.06]
# @hint: 减成负值的频点没有意义，要用谱底 beta*|Y| 托住：对每个频点取 max(相减结果, 谱底)。
mag_y = [3.0, 8.0, 6.5, 4.0, 2.0, 1.5, 1.0, 0.6]
mag_d = [0.5, 0.6, 7.2, 4.5, 2.5, 1.9, 1.3, 0.9]
beta = 0.1

mag_hat = []
for y, d in zip(mag_y, mag_d):
    s = y - d              # ← 问题在这：少了一道"半波整流 + 铺底"

```

**练习 2**：某帧的一个频点满足 $|Y|=6.0$、$|\hat D|=5.0$，用谱减法（$\alpha=1$、$\beta=0.1$）和维纳滤波（取 $P_X/P_D=(6/5)^2-1=0.44$）各算一次该频点的增强幅度，比较两条路的差别。

<details>
<summary>点开查看逐步解答</summary>

1. **谱减法**：相减 $6.0-5.0=1.0$；谱底 $0.1\times6.0=0.6$；取 $\max(1.0,0.6)=1.0$——保留原值的 $1/6$；
2. **维纳滤波**：$\xi=(6/5)^2-1=0.44$（用功率比减 1 得到先验信噪比），$H=0.44/1.44=0.306$，$|\hat X|=6.0\times0.306=1.83$；
3. **比较**：维纳保留了 $1.83$，比谱减法的 $1.0$ 更"敢留"。原因在于 $\xi$ 是按**功率**算的：幅度比 $1.2$ 对应功率比 $1.44$，扣掉噪声那一份后还剩 $0.44$；
4. **结论**：两条路给出同量级但不同的答案，差异来自各自的统计假设。实际系统常把两者混着用：谱减定大方向，维纳做细调。

</details>

**练习 3**：两段语音的说话人嵌入分别为 $e_1=(1,0)$、$e_2=(1,1)$。用余弦相似度判断它们是不是同一个人的可能性大不大？

<details>
<summary>点开查看逐步解答</summary>

1. $\mathrm{sim}=\dfrac{1\times1+0\times1}{1\times\sqrt{2}}=\dfrac{1}{1.414}\approx0.71$；
2. 余弦相似度落在 $-1\sim1$：**越接近 1 越像同一个人**。$0.71$ 属于"有点像"，工程上通常用几十万条语音训练出的阈值（常在 $0.6\sim0.8$ 一带）来判决；
3. 关键提醒：相似度是**相对**的，必须和"同一个人的不同语句"（同人分布）与"不同人的语句"（异人分布）两条分布对照着看才有意义——这正是第 3 章判别式分类的思想。

</details>

## 8. 选读：从降噪到分离的两条岔路

<details>
<summary>选读 · 盲源分离与神经增强的分工</summary>

谱减与维纳都属于"**知道噪声画像、把它按下去**"的一族，前提是噪声比较平稳、且有一段静音可以统计。真实场景里这两个前提常常不成立。

一条岔路是**盲源分离**：不统计噪声画像，只假设"几路信号彼此统计独立"，用 ICA 直接从混音里解出各分量（第 61 章第 97 课）。它不需要"哪一路是噪声"的先验，代价是需要多麦克风、且信号要近似非高斯。

另一条岔路是**神经增强**：第 120 课讲过唤醒词系统怎么用滑窗与阈值做判决，把同样的思路套到增强上——训练一个网络直接预测每个时频点的"保留比例"（掩蔽），这张掩蔽图就是维纳增益 $H(k)$ 的学习版。第 50 课的梅尔谱与第 30 课的语谱图正是这类网络的输入面板。

两条路的出口其实是同一个：**给每个时频点算一个 $0\sim1$ 的权重**。区别只在权重是"按公式算的"还是"从数据学来的"。

</details>
