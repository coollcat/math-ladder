# 源-滤波器模型：人是怎样发声的

## 1. 从一个场景开始

同一副肺、同一副声带，你发"啊"和发"衣"，声音判若两音。更神奇的是：随便找一个人，让他把这两个音拖长了唱，你都能立刻听出哪个是"啊"哪个是"衣"——哪怕一个男低音和一个女高音来唱，元音的身份也不会认错。

音高明明差了好几倍，元音却还是同一个元音。这说明**"元音是什么"这个信息，不写在音高里**。它写在哪儿？答案是：写在声道的形状里。这一课要讲的源-滤波器模型，就是把"音高"和"元音"这两件事彻底拆开的第一把刀，也是整个语音技术（识别、合成、变声）共同的地基。

## 2. 直觉解释

把人想象成一件乐器：

- **声带是琴弦**：它一开一合地振动，决定每秒振多少次——这就是**基频** $f_0$，听感上是"音调多高"。男声约 100~150 Hz，女声约 200~300 Hz，童声更高。
- **声道是琴身**：从声门到嘴唇的那根"管子"（喉、咽、口腔，再加上可调度的舌头和嘴唇），它是一个共鸣腔，对某些频率格外偏爱、把他们放大，对另一些则压制。

73 章你已经见过这个分工：谐波频谱课告诉你周期源的谱是一根根等间隔的谐波；混响课告诉你空房间会给声音染上自己的"腔调"。发声是同一件事的现场版——**声带发出富含谐波的粗糙声源，声道这个"声学滤镜"给哪些谐波开多大的窗，就决定了听到的元音**。

舌头一抬，管子的形状就变，被偏爱的频率就挪位置——"啊"变"衣"改的不是源，是滤镜。

## 3. 正式定义

**源-滤波器模型**：语音信号 = 声源激励 × 声道滤波。在频域是乘法：

$$S_{\text{语音}}(f) = S_{\text{源}}(f) \cdot H_{\text{声道}}(f)$$

**声源（激励）分三类**：

| 类型 | 声源是什么 | 频谱长什么样 | 例 |
| --- | --- | --- | --- |
| 浊音 | 声带周期振动（声门脉冲串） | 间隔 $f_0$ 的谐波梳，幅度约按每倍频程 $-12$ dB 递减 | 元音、/m/、/z/ |
| 清音 | 某处收紧产生湍流 | 连续的白噪声，无谐波 | /s/、/f/、/h/ |
| 混合 | 两者叠加 | 谐波上铺一层噪声 | /v/、/l/ 的尾部 |

**共振峰**：声道频响 $H(f)$ 上的峰，从低到高记 $F_1 < F_2 < F_3 \cdots$。它们只由声道形状决定，与声带振动快慢无关。**元音的身份主要由 $F_1$ 和 $F_2$ 两个数决定**：

| 元音 | $F_1$ (Hz) | $F_2$ (Hz) | 口诀 |
| --- | --- | --- | --- |
| /a/ | 730 | 1090 | 开口大 → $F_1$ 高；舌位靠后 → $F_2$ 低 |
| /e/ | 530 | 1840 | — |
| /i/ | 270 | 2290 | 开口小 → $F_1$ 低；舌位靠前 → $F_2$ 高 |
| /o/ | 570 | 840 | — |
| /u/ | 300 | 870 | 双高舌位，两个峰都低 |

（男声常见值，取教学用整数；女声、童声整体偏高一些。）

## 4. 分步例题

**例**：男声 $f_0 = 120$ Hz 发 /a/（$F_1 = 730$、$F_2 = 1090$）。声源的哪几根谐波被放大得最狠？

1. 谐波频率 = $n \cdot f_0$，第 $n$ 根就是 $120n$ Hz；
2. 离 $F_1 = 730$ 最近的谐波：$730 / 120 \approx 6.08$ → 第 **6** 根，即 720 Hz；
3. 离 $F_2 = 1090$ 最近的谐波：$1090 / 120 \approx 9.08$ → 第 **9** 根，即 1080 Hz；
4. 换女声 $f_0 = 220$ 发**同一个 /a/**：$730/220 \approx 3.32$ → 第 3 根（660 Hz）；$1090/220 \approx 4.95$ → 第 5 根（1100 Hz）；
5. **对比结论**：被放大的谐波从 (6, 9) 搬到了 (3, 5)——谐波搬家了，但共振峰还是钉在 730 和 1090。音高变了、元音没变，因为**元音写在滤波器里，不写在源里**。

## 5. 动手实验

### 实验 1（lab）：亲手捏共振峰

```lab
{
  "type": "source-filter",
  "title": "拖中间图的 F1/F2 圆点、按元音预设：同一个声源怎么变出不同元音",
  "f0": 120,
  "vowel": "a"
}
```

三行图各看一件事：上行是声源（周期脉冲串还是噪声），中行是核心——灰色细线是声源的谐波梳，阴影是声道这个滤镜的频响，橙色粗线是两者乘出来的最终谐波；下行是输出波形。做三件事：

- 点元音预设按钮在 /a/ /i/ /u/ 之间跳：注意中行**阴影（共振峰）大搬家、谐波梳纹丝不动**——滤镜换了，源没换；
- 直接拖 $F_2$ 的圆点从 1090 拖到 2290：只改一个峰，/a/ 就滑向 /i/——这就是"元音身份主要看 F1、F2"的现场版；
- 把声源切成「清音」：谐波梳整个消失，频谱变成连续一片——没有周期源，就没有音高，但共振峰阴影还在。

### 实验 2（python）：谐波搬家，元音不搬

```python title="三副嗓子发同一个 /a/：被放大的谐波各是哪几根"
for name, f0 in [("男声", 120), ("女声", 220), ("童声", 300)]:
    n1 = round(730 / f0)      # 离 F1=730 最近的谐波序号
    n2 = round(1090 / f0)     # 离 F2=1090 最近的谐波序号
    print(f"{name}: f0={f0:>3} Hz → F1 附近第 {n1} 根（{n1*f0} Hz）,"
          f" F2 附近第 {n2} 根（{n2*f0} Hz）")
```

三行输出里，被放大的谐波序号一路变小（6→3、9→5……）：基频越高，谐波梳越稀疏，落在共振峰窗里的那根就离峰心越远——这正是"高音唱歌元音容易走样"的声学原因。但三行的共振峰始终是 730 和 1090，元音的身份没变。

::::warning[常见误区]

**误区一**："音高和元音是一回事，调子变了元音就变了。"
你以为 $f_0$ 变了元音就保不住——其实 $f_0$ 是**源**的属性，元音是**滤波器**的属性，两者独立。男声 120 Hz 和女声 300 Hz 发的 /i/，基频差 2.5 倍，$F_1/F_2$ 却几乎相同。音乐里歌手把一个元音从低音区唱到高音区，你仍能听清唱的是哪个字。

**误区二**："共振峰是声带发出来的频率。"
你以为共振峰来自声带振动——其实它是**声道这个共鸣腔的极点**，跟源无关。证据：吹空瓶子，嘴唇的气流噪声毫无音高，瓶子照样"嗡"出一个固定的共鸣频率。耳语更极端：声带完全不动（源没了），靠噪声冲刷共振峰，听者照样能分辨元音。

**误区三**："清音也有音高。"
你以为 /s/、/f/ 也有"调子"——它们是湍流噪声，频谱连续、没有谐波、没有 $f_0$。语调和音高只存在于浊音段。语音识别里的"清浊判别"（第 70 课）第一步就是区分这两种源。

::::

## 6. 练习

**练习 1**：男低音 $f_0 = 110$ Hz 发 /a/。求被 $F_1 = 730$ 放大得最狠的谐波序号，输出应为 `7`。这段代码截断取整，往低了取：

```exercise
# @title: 练习：哪根谐波落在共振峰里
# @check: 7
# @hint: 730/110 ≈ 6.64，离峰心最近的是第 7 根（770 Hz）——四舍五入，不是砍掉小数
f0 = 110      # 基频（Hz）
F1 = 730      # /a/ 的第一共振峰（Hz）
n = int(F1 / f0)    # ← 问题在这：int() 直接截断，6.64 被砍成 6
print(n)
```

验算一下：第 6 根是 660 Hz（差 70），第 7 根是 770 Hz（差 40）——四舍五入才真的选到离峰心最近的那根。把 `int` 改成 `round` 就对了。

**练习 2**：有人发了一个元音，测得 $F_1 = 270$ Hz、$F_2 = 2290$ Hz。这是本课表里的哪个元音？并回答：如果这人改用假声把 $f_0$ 提到原来的三倍，测到的 $F_1$、$F_2$ 会变成多少？

<details>
<summary>点开查看逐步解答</summary>

1. 查表：$F_1 = 270$、$F_2 = 2290$ 正是 **/i/**（开口最小、舌位最前）；
2. 共振峰由**声道形状**决定，与 $f_0$ 无关——所以 $F_1$、$F_2$ **纹丝不动**，还是 270 和 2290；
3. 变的只是谐波梳的间隔：从原来的 $f_0$ 变成 $3f_0$，落在共振峰窗里的谐波序号约缩为原来的 $1/3$。

这正是第 4 节例题结论的镜像用法：**用共振峰定元音，用基频定音高，两把尺子别混**。工程上的对应物是：变调不变字（音高变换保元音）之所以可行，就是因为源和滤波器可以分开处理。

</details>

## 7. 选读：把"乘在一起"的两样东西重新拆开

<details>
<summary>选读 · 为什么要拆、以及拆开的困难（MFCC 的伏笔）</summary>

模型说 $S_{\text{语音}}(f) = S_{\text{源}}(f) \cdot H_{\text{声道}}(f)$——但录音机给你的是**乘在一起的最终结果**。想分别研究"这人音调多高"（源）和"他发的什么元音"（滤波器），就得把乘积拆回去。

乘法很难拆。但如果先**取对数**，乘法就变加法：

$$\log S_{\text{语音}} = \log S_{\text{源}} + \log H_{\text{声道}}$$

"音调多高"（快速起伏的谐波梳）和"什么元音"（缓变的共振峰包络）在对数域里是**两个起伏快慢不同的成分**，可以再用一次变换把它们分开——这套操作有个正式名字叫**同态处理**，它的工程实现就是第 50 课的 MFCC。本课只需要记住伏笔：**语音天然是"乘法信号"，而对数是拆乘法的钥匙。**

</details>
