# 声码器：把语音压缩成参数

## 1. 从一个场景开始

深空探测器在几亿公里外向地球回传数据，带宽按比特计较。它录了一段 2 秒的语音想传回来：按 16 kHz/16 bit PCM 算那要 $16000 \times 16 \times 2 = 512000$ bit——而信道每秒只给几千比特。硬传要等上两分钟，还不许出错。

可语音有个别人没有的特权：**我们知道它是怎么造出来的**。声带振动当声源，声道当滤波器——这是第 10 课的源-滤波模型；声道可以折成十几个 LPC 系数——这是上一课的结论。既然"怎么造"都知道了，何必传"造出来的东西"？传一张**配方**就够了。

这就是**声码器**（vocoder）：分析端把语音压成一小袋参数，传输端只发这袋参数，合成端照方抓药把声音"重新表演"一遍。2 秒语音，512000 bit 的波形，换来一袋 14600 bit 的参数——35 倍的压缩，而听懂它毫无压力。

## 2. 直觉解释

前两课已经把语音拆成了两半：

- **声道**（说什么的共鸣腔）：上一课的 LPC 把它变成 $p$ 个系数——一张谱包络的"X 光片"；
- **激励**（怎么发声）：浊音是声带的蜂鸣，一个频率（基频 $F_0$）就够描述；清音是气流的摩擦，压根不需要频率，一个"清"字就够；再加一个增益 $G$ 管响度。

于是每 20 毫秒发一个参数包：

$$\lbrace \, a_1 \ldots a_p,\; F_0,\; \text{浊/清},\; G \,\rbrace$$

**接收端从零重建波形**：浊音就造一串相隔 $1/F_0$ 的脉冲，清音就造一段随机噪声，乘上增益，让它流过全极点滤波器 $1/A(z)$——声音回来了。注意这句话的分量：**传过来的从头到尾没有波形，波形是接收端现造的**。

> **参数就是语音。** 一句话不再是一串气压记录，而是几十帧"配方"——这就是声码器与一切波形编码的分水岭。

参数化之所以压得动，是因为它只保留**听感相关**的信息：共振峰在哪、声带抖多快、多响。波形里那 99% 的"精确到每一个样点"的细节，耳朵本来就懒得理会。

## 3. 正式定义

**帧**：语音是慢时变的，每 20 ms 取一帧（帧移 10 ms，帧与帧一半重叠），假设"这一帧里声道不动"。

**每帧参数与比特预算**（16 kHz 采样、$p = 12$ 阶的典型配置）：

| 参数 | 含义 | 典型比特 |
| --- | --- | --- |
| $a_1 \ldots a_p$ | 声道形状（先转反射系数再量化，见上课选读） | $p \times 5$ |
| $F_0$ | 基频（浊音帧才有意义） | 7 |
| V/UV | 清浊判决，1 bit | 1 |
| $G$ | 增益（响度） | 5 |

**码率**：

$$R = \frac{1000}{\text{帧移(ms)}} \times \text{每帧比特数}$$

**合成器**：激励 $e[n]$（脉冲串或噪声）流过全极点滤波器 $\hat{s}[n] = \sum_{k=1}^{p} a_k \hat{s}[n-k] + G\,e[n]$。这正是上一课 LPC 的**反向运转**：分析是"从信号解系数"，合成是"从系数造信号"。

## 4. 分步例题

**例**：算一遍完整账本（$f_s = 16000$，$p = 12$，帧长 20 ms、帧移 10 ms，系数 5 bit）。

1. **帧率**：帧移 10 ms = 每 160 个样点一帧 → $16000/160 = 100$ 帧/秒；
2. **每帧比特**：$12 \times 5 + 7 + 1 + 5 = 73$ bit；
3. **码率**：$100 \times 73 = 7300$ bit/s；
4. **对照 PCM**：$16000 \times 16 = 256000$ bit/s；压缩比 $256000/7300 \approx 35.1$；
5. **2 秒话音**：波形 $64000$ 字节 vs 参数 $1825$ 字节——一个邮件附件装下一整场发布会。

注意这个数字的历史分量：1970 年代 2400 bit/s 的军用保密电话就是靠这套账本活下来的——参数压到每帧 24 bit，剩多少算多少。

## 5. 动手实验

### 实验 1（lab）：听"原始"与"合成"的差别

```lab
{
  "type": "vocoder-lab",
  "title": "原声/合成声切换听差别；拖阶数、帧长、量化位数三个滑块，看码率怎么变、听感怎么塌",
  "order": 10,
  "frameMs": 20,
  "bits": 5
}
```

内置一句话（a→i→s→u 的音素轨迹），语谱图上红色播放头可以拖。三个必玩：

- **切「合成声」**：听得懂，但有"机器味"——激励是标准脉冲串，缺了真实声门的纹理。**可懂度保住了，自然度打折**，这一句就是所有参数声码器的墓志铭；
- **阶数从 10 拖到 4**：合成声发闷，共振峰丢包——上一课的"过拟合 vs 欠拟合"在这里用耳朵评分；再拖到 20：耳朵几乎分不出差别，码率却线性上涨；
- **量化位数拖到 3**：出现咔哒与抖动——直接量化 LPC 系数会让极点越界失稳（工程上都先转反射系数）；帧长拖到 40 ms：码率立刻减半，但 a→i 的过渡段糊成一团——**一帧内"声道不动"的前提被拉长了**。

### 实验 2（python）：亲手算一遍码率账本

```python title="声码器码率账本：帧率 × 每帧比特 = 码率"
fs = 16000                    # 采样率
frame_ms, shift_ms = 20, 10   # 帧长 20 ms，帧移 10 ms（帧长的一半）
p, coef_bits = 12, 5          # 12 个 LPC 系数，每个 5 bit
f0_bits, v_bits, gain_bits = 7, 1, 5

frames = 1000 / shift_ms                      # 每秒多少帧
bits = p * coef_bits + f0_bits + v_bits + gain_bits
rate = frames * bits                          # 声码器码率
pcm = 16 * fs                                 # 16 bit PCM 的码率
print(int(frames), bits, int(rate), round(pcm / rate, 1))
```

输出 `100 73 7300 35.1`：帧率、每帧比特、码率、压缩比。把 `shift_ms` 改成 20（帧移拉长一倍）再跑：码率 3650、压缩比 70.1——账面上白赚一倍，代价去实验 1 里用耳朵找。

### 快问快答

```quiz
把帧长从 20 ms 拉到 40 ms，码率立刻减半。这个便宜的主要代价是什么？
- 音素之间的快速过渡被抹平 [*]
- 基频测不准了
- 音量会变小
- 底噪被放大
? 帧越长，"一帧内声道不动"的假设破坏得越厉害：a→i 这类快速过渡发生在几十毫秒内，40 ms 一帧只能给出一个平均值——码率减半，过渡段糊掉。基频、音量、底噪与帧长关系不大。
```

:::::warning[常见误区]

**误区一**："声码器传的是压缩后的波形。"
你以为它是 MP3 的亲戚——恰恰相反：波形一个样点都没传，传的是参数，波形是接收端**现造**的。所以参数声码器的失真不是"噪声大"，而是"表演得不像真人"——机器味来自激励被简化成标准脉冲与均匀噪声。

**误区二**："压缩比越高越先进。"
你以为 70 倍碾压 35 倍——拉长帧长、砍系数、减比特都能刷账面数字，但听感会塌。参数编码的度量是**可懂度与自然度的权衡**：军标 2400 bit/s 图的是可懂，不耐听；码率预算要跟着用途走。

**误区三**："LPC 系数直接量化就行，5 bit 足够。"
你以为量化误差只是听感上的沙沙——直接量化 $a_i$，一个比特的抖动就可能把极点推出单位圆，合成瞬间啸叫。工程上先转反射系数（$|k_i|<1$ 天然稳定）再量化，这是上一课选读那条不等式的落地现场。

:::::

## 6. 练习

**练习 1**：算声码器的码率与压缩比。初始代码把帧移当成了帧长：

```exercise
# @title: 练习：算一遍码率账本
# @check: 100 73 7300 35.1
# @hint: 帧移是帧长的一半（10 ms），帧率 = 1000/帧移(ms)；每帧比特 = 12×5 + 7 + 1 + 5
fs = 16000
frame_ms, shift_ms = 20, 10
p, coef_bits = 12, 5
f0_bits, v_bits, gain_bits = 7, 1, 5

frames = 1000 / frame_ms                      # ← 问题在这：帧率按帧移算，不是按帧长
bits = p * coef_bits + f0_bits + v_bits + gain_bits
rate = frames * bits
pcm = 16 * fs
print(int(frames), bits, int(rate), round(pcm / rate, 1))
```

输出 `50 73 3650 70.1`：帧移写成帧长，帧率少了一半、码率跟着腰斩——账面上"白赚"的压缩比，其实是丢了一半的参数帧。修正一行，`100 73 7300 35.1` 才是与实验 1 语谱图对应的真账本。

**练习 2**：合成端拿到一帧参数 $\lbrace a_1{=}0,\ a_2{=}0,\ V{=}\text{浊},\ F_0{=}200\ \text{Hz},\ G{=}1\rbrace$。回答：(a) $1/A(z)$ 这时是什么滤波器？(b) 合成出来是什么声音？(c) 这帧参数描述的真实发音更像什么？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $A(z) = 1$ → $1/A(z) = 1$：直通，没有共振峰——12 阶全是零的"声道"什么形状也没有；
2. (b) 一串 200 Hz 的纯脉冲直通输出：一个嗒嗒作响的蜂鸣，没有任何元音色彩；
3. (c) 声道完全张开的极中性元音（类似轻声的"呃"）会接近这种平坦包络——但真实的它仍有残余共振，纯零系数只是模型端点。这题的教训：**元音的身份全部写在 $a_i$ 里**，激励参数只管"嗡不嗡、多快嗡、多响"。

</details>

## 7. 选读：从参数声码器到 CELP——激励的去处

<details>
<summary>选读 · "机器味"的病根与三代解法</summary>

参数声码器的可懂度很高，自然度却上不去，病根在**激励**：真实声门脉冲有形状、有抖动（基频微漂），清音也不是均匀噪声。把激励压成"标准脉冲 + 均匀噪声 + 1 bit 清浊"，等于把一支管弦乐队的打击乐部压成一台节拍器。

三代解法，一条主线——**把丢掉的激励细节逐步还回来**：

- **混合激励**：浊音不再是纯脉冲，加一点带通噪声；清浊之间允许连续过渡。MELP 标准（2400 bit/s）靠这一手明显去机器味；
- **残差码本（CELP）**：干脆别解析激励了——上一课说过，LPC 残差**就是**激励。预先备一本"常用残差形状"的码本，每帧只传"第几号形状 + 增益"；解码端拿码本条目过 $1/A(z)$。每帧十几个 bit 买回全部激励纹理，16 kbit/s 已能做到"几乎听不出是编码过的"；
- **分析-合成闭环**：CELP 的精髓是"试了再传"——编码端把每个候选残差真的合成一遍，与原波形比误差，挑最像的那个把编号发出去。这就是**分析-合成**（analysis-by-synthesis）：压缩决策本身建立在合成结果上。

再往上的码率盈余，就从激励转向感知——"哪些误差听不出来就不传"，这正是下一课掩蔽效应要回答的问题。

</details>

## 8. 下一站

声码器证明了"参数就是语音"，但它砍信息时用的是**均匀砍法**：每个系数 5 bit、每个频带一视同仁。可人耳对误差的容忍度极不均匀——有些频段错了 20 dB 都听不见。要精确地知道"哪里可以错、错多少"，得先给耳朵画一张**误差容忍地图**：心理声学与感知掩蔽。
