# 线性预测：用前几个样点猜下一个

## 1. 从一个场景开始

对着麦克风发一个"啊"，声卡每秒记下 16000 个数。相邻的数**长得惊人地像**——声带和口腔都是惯性系统，波形不可能一步跳很远。既然如此，与其老老实实存下每个样点，不如先存一条"猜测规则"，再存一点猜错的修正量。

猜得越准，修正量越小，数据越少。**线性预测编码**（LPC）把这门"猜"的手艺推到极致：用十来个系数概括声道的形状，用一小串残差概括声门的激励。1970 年代它让语音第一次被压进调制解调器，今天它仍是历代语音编码标准的骨架。

## 2. 直觉解释

LPC 的骨子里是两个你已经见过的思想。

**第一个是第 11 章的最小二乘**：用前 $p$ 个样点的加权和猜下一个，

$$\hat{s}[n] = a_1 s[n-1] + a_2 s[n-2] + \cdots + a_p s[n-p]$$

系数 $a_1 \ldots a_p$ 怎么定？让"猜错的平方和"最小——把 $s[n]$ 对它的前 $p$ 个样点做一次回归，解一组正规方程。61 章自适应滤波的维纳解 $w^* = R^{-1}p$ 与这里只差记号：那里的输入是参考信号，这里是信号自己的过去。

**第二个是第 10 课的源-滤波模型**：语音 = 声门激励 × 声道滤波。声道是几个共振腔，频谱上鼓起一串**共振峰**（F1/F2/F3，三个元音听起来不同的全部原因）。数学上一串共振腔恰好对应一个**全极点滤波器** $1/A(z)$——而"最小化预测残差"解出的那组 $a_i$，正是 $A(z)$ 的系数。换句话说：

> **线性预测在用最小二乘给声道拍 X 光片。**

拍出来的光滑包络线上的每个鼓包，就是一个共振峰。

## 3. 正式定义

对一帧信号，选阶数 $p$，最小化 $J = \sum_n e[n]^2$，其中 $e[n] = s[n] - \hat{s}[n]$。令各偏导为零，得**正规方程**（自相关法）：

$$\begin{pmatrix} r_0 & r_1 & \cdots & r_{p-1} \\ r_1 & r_0 & \cdots & r_{p-2} \\ \vdots & & \ddots & \vdots \\ r_{p-1} & r_{p-2} & \cdots & r_0 \end{pmatrix} \begin{pmatrix} a_1 \\ a_2 \\ \vdots \\ a_p \end{pmatrix} = \begin{pmatrix} r_1 \\ r_2 \\ \vdots \\ r_p \end{pmatrix}, \qquad r_k = \frac{1}{N}\sum_n s[n]\,s[n-k]$$

系数矩阵是**自相关矩阵**——就是 61 章维纳解里那口碗的 Hessian，托普利兹结构（沿对角线常数）让方程组有递推快解（见选读）。

**预测增益**——LPC 干得有多好的度量：

$$G = 10\log_{10}\frac{\operatorname{Var}(s)}{\operatorname{Var}(e)} \quad (\text{dB})$$

**阶数经验值**：$p \approx f_s/1000 + 2$。16 kHz 采样取 10~14 阶：每对（复）极点管一个共振峰，10 阶 = 5 对，管住 F1/F2/F3 还有富余。

## 4. 分步例题

**例 1**：二阶预测器能对一个纯音做到什么程度？设 $s[n] = \cos(\omega_0 n)$。三角恒等式给出恒等式：

$$\cos(\omega_0 n) = 2\cos(\omega_0)\cos(\omega_0 (n-1)) - \cos(\omega_0 (n-2))$$

也就是 $a_1 = 2\cos\omega_0$、$a_2 = -1$ 时**残差恒为零**——两个系数就把纯音吃得一干二净。取 $\omega_0 = 2\pi/50$（16 kHz 下 320 Hz）：$a_1 = 2\cos(2\pi/50) \approx 1.984$。实跑验证：整帧 400 个样点的最大残差约 $10^{-15}$，是机器精度的量级。极点在单位圆上（无阻尼振荡），"完美预测"与"永不衰减"是同一件事的两面。

**例 2**：还是这帧纯音，掺 5% 的观测噪声。LPC-2 解出 $a_1 = 1.656$、$a_2 = -0.673$，预测增益 19.6 dB——信号方差的约 99% 被两个系数吃掉，剩下的残差几乎全是那 5% 噪声。**可预测性就是结构**：纯音有结构（可预测），白噪声没结构（最优预测是 $a=0$，增益 0 dB）。

**例 3（选阶数）**：$f_s = 16000$，$p \approx 16 + 2 = 18$ 上限，但实际元音三个共振峰用 10~14 阶就饱和——下一节的实验里拖一下阶数游标，看收益曲线在哪个阶数躺平。

## 5. 动手实验

### 实验 1（lab）：一条包络贴住三个共振峰

```lab
{
  "type": "lpc-lab",
  "title": "拖阶数游标：p 太小包不住 F3，p 太大去拟合毛刺；再切 a/i/u 三个元音看包络怎么变",
  "order": 12,
  "vowel": "a",
  "noise": 0.02
}
```

锯齿线是 FFT 频谱，光滑曲线是 LPC 包络。三个必玩：

- 把阶数拖到 3：包络只鼓起一个包，F2、F3 全丢——合成出来发闷，这就是早期声码器"含着东西说话"的原因；
- 拖到 12 左右：三个鼓包正好贴住三个共振峰，再往上加阶，曲线开始去拟合频谱毛刺——**过拟合**在你拖动游标的瞬间发生；
- 切到 /i/（共振峰 270/2290/3010 Hz）：包络整体搬家。元音的区别就是这张"X 光片"的区别。

### 实验 2（python）：亲手解一次 2 阶正规方程

```python title="LPC-2：自相关、正规方程、预测增益一条龙"
import math

fs = 16000
# 一帧 320 Hz 纯音 + 5% 观测噪声（固定伪噪声，保证人人跑出同一串数）
x = []
for n in range(400):
    noise = ((((n * 73) % 17) - 8) / 8) * 0.05
    x.append(math.sin(2 * math.pi * 320 * n / fs) + noise)

def ac(k):                          # 自相关 r_k（除以 N）
    return sum(x[n] * x[n - k] for n in range(k, 400)) / 400

r0, r1, r2 = ac(0), ac(1), ac(2)

det = r0 * r0 - r1 * r1             # 解 2x2 正规方程
a1 = (r0 * r1 - r1 * r2) / det
a2 = (r0 * r2 - r1 * r1) / det

se = sum((x[n] - a1 * x[n-1] - a2 * x[n-2]) ** 2 for n in range(2, 400))
sv = sum(x[n] ** 2 for n in range(2, 400))
print(round(a1, 3), round(a2, 3), round(10 * math.log10(sv / se), 1))
```

输出 `1.656 -0.673 19.6`：两个系数 + 一次 2×2 求解，吃掉 19.6 dB。把 `320` 改成别的频率再跑，系数跟着变——它们记的正是"这帧信号的周期结构"。

### 快问快答

```quiz
16 kHz 采样、12 阶 LPC 的全极点模型，最多能贴住几个共振峰？
- 6 个 [*]
- 12 个
- 3 个
- 2 个
? 每对复极点管一个共振峰，12 阶 = 6 对极点 → 最多 6 个共振峰。经验公式 p 约等于 fs/1000 + 2 保证管住 F1~F4 还有富余；阶数再往上加，多出来的极点只会去拟合噪声。
```

::::warning[常见误区]

**误区一**："LPC 系数本身有明确的声音学含义。"
你以为 $a_5$ 管着什么共振腔——其实单个系数什么也不是。有声含义的是**整组系数决定的谱包络**：要谈共振峰，得先从 $A(z)$ 的根（或反射系数）里把峰位解出来。直接"读"系数是初学者最常掉进去的坑。

**误区二**："阶数越高，模型越准，效果越好。"
你以为 $p$ 越大越好——12 阶之后每加一阶都在让包络去贴噪声和毛刺，参数个数照涨、听感反而开始毛糙。阶数是"模型容量"的第一个活例子：**容量要匹配信号的结构，不是越大越好**。

**误区三**："残差是猜错的部分，是垃圾。"
你以为预测准了就赢了——恰恰相反：对语音，残差正是**激励**（声门脉冲串或摩擦噪声），是被模型"正规化"掉的声源。声码器（下一课）把残差的参数当宝贝传过去；只传声道不传激励，合成出来就是一串嗡嗡声。

::::

## 6. 练习

**练习 1**：亲手解 2 阶正规方程。初始代码输出 `1.0 -0.5`，正确答案是 `0.67 -0.33`：

```exercise
# @title: 练习：解 LPC-2 的正规方程
# @check: 0.67 -0.33
# @hint: 托普利兹矩阵 [[r0, r1], [r1, r0]] 的行列式是 r0^2 - r1^2，两个平方都不能少
r0, r1, r2 = 1.0, 0.5, 0.0    # 一帧信号的自相关 r0、r1、r2

det = r0 - r1                 # ← 问题在这：行列式应为 r0*r0 - r1*r1
a1 = (r0 * r1 - r1 * r2) / det
a2 = (r0 * r2 - r1 * r1) / det
print(round(a1, 2), round(a2, 2))
```

修正后 $a_1 = 2/3$、$a_2 = -1/3$：极点半径 $\sqrt{0.33} \approx 0.57 < 1$，滤波器稳定，代表一个位于 $f_s/5$ 附近的共振峰（$\arccos(1/3)/(2\pi) \cdot f_s \approx 3135$ Hz）。代数错一格，"声道"就换一个形状。

**练习 2**：例 1 的纯音预测器 $a_1 = 1.984$、$a_2 = -1$。求全极点模型 $1/A(z)$ 的极点位置，并解释为什么预测"完美"。

<details>
<summary>点开查看逐步解答</summary>

1. $A(z) = 1 - 1.984z^{-1} + z^{-2}$，特征方程 $z^2 - 1.984z + 1 = 0$；
2. 两根之积 $= 1$、判别式 $1.984^2 - 4 = -0.064 < 0$ → 共轭复根，模长 $\sqrt{1} = 1$：**极点在单位圆上**；
3. 相角 $\theta = \arccos(0.992) = 2\pi/50$——极点精确落在 320 Hz 的频率位置上；
4. 单位圆上的极点 = 无衰减的振荡 = 只要头两个样点对了，往后每一步都分毫不差。这就是"残差 $\sim 10^{-15}$"的极点语言翻译。

真实声道有耗散，极点半径略小于 1（0.9 左右），对应缓慢衰减的共振——这正是语音"自然度"所在，也是合成端要做半衰期控制的原因。

</details>

## 7. 选读：Levinson-Durbin 与反射系数

<details>
<summary>选读 · 快解、稳定性与量化安全</summary>

**递推快解**：正规方程的系数矩阵是托普利兹的，**Levinson-Durbin 递推**利用这一点从 1 阶解一路递推到 p 阶，计算量从 $O(p^3)$ 降到 $O(p^2)$。递推的中间产物是一串**反射系数** $k_1 \ldots k_p$——声管模型里每节声管交界处的"反射率"，这也是它们名字的来历。

**稳定性保险**：$\{a_i\}$ 对应的滤波器稳定，当且仅当每个 $|k_i| < 1$。正规方程直接解出的 $a_i$ 没有这条保证（数值误差可能让它悄悄越界），而反射系数天然带界——所以工程实现都存 $k_i$ 而不是 $a_i$。

**量化安全**：下一课的声码器要把系数发过信道。直接量化 $a_i$，一个比特的抖动就可能把极点推出单位圆，合成瞬间爆炸；量化 $|k_i|<1$ 的反射系数则永远不会失稳。这就是声码器注释里"先转反射系数再量化"的全部原因——一条不等式撑起一种工业实践。

</details>
