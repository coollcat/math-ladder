# 多项式除法：多项式的竖式

## 1. 从一个场景开始

小学写竖式除法：$634 \div 4$，你从百位开始，一位一位往下"除、乘、减、落"，最后商 $158$ 余 $2$。这套流程你闭着眼都能走。

现在换个被除数——不是 $634$，而是 $x^2+3x+5$；除数不是 $4$，而是 $x+1$。字母进了被除数，竖式还写得下去吗？

写得下去，而且**流程一模一样**：从最高次位开始，一位（一项）一位（一项）地"除、乘、减、落"。这一课就把算术竖式平移到多项式世界，造出多项式的竖式除法——它马上会在下一课的余数定理里当那块垫脚石。

## 2. 直觉解释

先看两种竖式的骨架有多像。数字版 $634 \div 4$ 的每一步：**看最高位**（6）→ **试商**（$6\div4$ 商 $1$）→ **乘回去**（$1\times4=4$）→ **减掉**（$6-4=2$）→ **落下一位**（拉下 3 变 23）→ 重复，直到位数用尽。

多项式版 $x^2+3x+5 \div x+1$ 完全同构：**看最高次项**（$x^2$）→ **试商**（$x^2\div x = x$）→ **乘回去**（$x\cdot(x+1)=x^2+x$）→ **减掉**（$x^2+3x$ 减去它剩 $2x$）→ **落下一项**（拉下 $+5$ 变 $2x+5$）→ 重复，直到次数用尽。

支撑这一切的是**除法分配律**：被除式是一堆项的打包，除式要分给**每一项**——分完第一项，剩下的再用同一个除式接着分。每分一轮，被除式的最高次就降一次，所以这套流程又叫**降次剥离**：一层一层往下剥，剥到剩下的"余式"比除式还矮为止。

## 3. 正式定义

对多项式 $f(x)$ 除以 $g(x)$，存在唯一的商 $q(x)$ 与余式 $r(x)$，使

$$f(x) = g(x)\cdot q(x) + r(x)$$

成立，其中 $r(x)$ 的次数**严格低于** $g(x)$ 的次数。

| 名称 | 记号 | 例（$x^2+3x+5 \div x+1$） |
| --- | --- | --- |
| 被除式 | $f(x)$ | $x^2+3x+5$ |
| 除式 | $g(x)$ | $x+1$ |
| 商式 | $q(x)$ | $x+2$ |
| 余式 | $r(x)$ | $3$ |

竖式四步口诀（每一轮重复一遍）：

1. **除**：被除式（当前剩下部分）的首项 $\div$ 除式的首项，得商的一项；
2. **乘**：商的这一项 $\times$ 整个除式，写在被除式下方对齐；
3. **减**：用上方减去下方（每一项都要减，符号别丢）；
4. **落**：落下来被除式的下一项，回到第 1 步。

停止条件就是定义里那句"$r$ 的次数低于 $g$"：当剩下的部分首项次数已低于除式首项，它整块就是余式，除法到此收工。这一条是防呆闸——再除下去商就要出现"分数系数"，账就不整齐了。

## 4. 分步例题

**例 1**：$(x^2+3x+5) \div (x+1)$。

1. 除：$x^2 \div x = x$，商的首项是 $x$；
2. 乘：$x\cdot(x+1) = x^2+x$；
3. 减：$(x^2+3x+5) - (x^2+x) = 2x+5$；
4. 除：$2x \div x = 2$，商的次项是 $2$；
5. 乘：$2\cdot(x+1) = 2x+2$；
6. 减：$(2x+5) - (2x+2) = 3$；
7. $3$ 的次数是 $0$，低于除式的 $1$ 次——收工。

结论：商 $x+2$，余 $3$。验收一条恒等式：$(x+1)(x+2)+3 = x^2+3x+5$ ✓（展开是合并同类项课的老手艺）。**商乘除式加余式，必须还原被除式**——这是长除法的验算法宝。

**例 2**：$(x^3-4x^2+x+6) \div (x-1)$。

1. 除：$x^3 \div x = x^2$；乘：$x^2(x-1) = x^3-x^2$；减：$(x^3-4x^2) - (x^3-x^2) = -3x^2$；落 $+x$；
2. 除：$-3x^2 \div x = -3x$；乘：$-3x(x-1) = -3x^2+3x$；减：$(x-3x) = -2x$；落 $+6$；
3. 除：$-2x \div x = -2$；乘：$-2(x-1) = -2x+2$；减：$6-2 = 4$；
4. $4$ 比除式矮——收工：商 $x^2-3x-2$，余 $4$。

记住这道题：下一课的余数定理会原样召回它，用一次代入偷看这里的余数。

## 5. 动手实验

### 实验 1（viz）：先复习"商与余数"的直觉

```viz

  "type": "divisionshare",
  "title": "发糖机：糖果总数 ÷ 人数",
  "total": 23,
  "people": 4
}
```

拖动滑块：23 颗糖分给 4 人，每人 5 颗、剩下 3 颗——商 $5$、余 $3$，且余数永远比人数小。多项式除法是同一个故事：$x^2+3x+5$ 这袋糖按"次数"分给 $x+1$，分到不能再分，剩下的就是余式——**余式必须比除式矮**，正如余数必须比除数小。

### 实验 2（python）：把竖式的每一步写进代码

```python title="逐层降次：竖式的代码化身"
# (x^2 + 3x + 5) ÷ (x + 1)，按竖式流程逐层降次
# 除式 x + 1 的首项是 x，所以每一轮都是"当前首项 ÷ x"

c2 = 1            # 被除式 x^2 的系数（高次在前）
c1 = 3            # x 的系数
c0 = 5            # 常数项

q2 = c2           # 竖式第 1 轮"除"：x^2 ÷ x，商首项系数
c1 = c1 - q2      # 乘回来的 x(x+1) = x^2 + x：x 项带来 q2 倍的 1，从 3 里减掉
# x^2 那一项在这一轮减法里清零；常数项 c0 不受第 1 轮影响，不动

q1 = c1           # 第 2 轮"除"：剩下的 2x ÷ x，商次项系数
c0 = c0 - q1      # 乘回来的 2(x+1) = 2x + 2：常数项带来 q1 倍的 1，从 5 里减掉

print(q2, q1)     # 商 x + 2 的两个系数（print 一次收两个值，用逗号隔开）
print(c0)         # 剩下的常数就是余数
```

输出 `1 2` 和 `3`——手工竖式算出的商与余数原样复现。每一行代码对应竖式的一步，降次剥离从此不再是纸上黑箱。

### 实验 3（python 滑块）：验算恒等式

```python title="商×除式 + 余式 = 被除式？"
# sliders: x=3 [-5:5:1]
# 对例 1 验算：(x+1)(x+2) + 3 = x^2 + 3x + 5
left = (x + 1) * (x + 2) + 3   # 商乘除式，再加余式
right = x*x + 3*x + 5          # 原被除式逐项硬算
print(f"x={x}: 左边 {left} | 右边 {right}")
print(left == right)           # 比较运算返回 True 或 False
```

拖动 $x$ 扫过整排整数，最后一行始终打印 True。恒等式对每个 $x$ 都成立——除法没做错一分的铁证。

- 余式的次数低于除式的次数时 [*]

::::warning[常见误区]

**误区一**："你以为缺项就不用管。" 多项式 $x^3-1$ 其实是 $x^3+0x^2+0x-1$——竖式对齐靠"次数归位"，缺的次项占着 $0$ 的坑。跳过它们，减法就会错位串行。

**误区二**："你以为'减'只减首项。" 第 2 步乘出来的整行都要被减：$(x^2+3x+5) - (x^2+x)$ 是两项同减，只减 $x^2$ 留着 $x$ 不管，后面整条账全歪。符号账本（第 2 章 05 号课的负负得正）在这里最吃紧。

**误区三**："你以为余式是'随便剩下的部分'。" 余式是定义强制的产物：次数必须低于除式。$x^2 \div (x+1)$ 的余数是 $1$ 不是 $x^2$——因为除了一轮后剩下的 $-x+0$ 还得继续除（商 $-1$ 余 $1$），剥干净为止。

::::

## 6. 练习

**练习 1**：$(x^2+5x+8) \div (x+2)$ 的商与余数是多少？下面的代码能跑，但两处都是"没剥完"的占位答案——按竖式走一遍再填：

```exercise
# @title: 练习：走一遍竖式
# @check: 1
# @check: 3
# @check: 2
# @hint: 首项 x^2 ÷ x 商 1；乘回 x(x+2)=x^2+2x，减剩 3x+8；再 3x ÷ x 商 3；乘回 3(x+2)=3x+6，减剩 2——商和余数都出来了。
qx = 1     # 商的 x 项系数
qc = 5     # ← 商的常数项：目前照抄了被除式的 5，它是竖式走完的答案吗？
rem = 8    # ← 余数：目前还是被除式原封不动的常数项
print(qx)
print(qc)
print(rem)
```

**练习 2**：用"商乘除式加余式"验算练习 1。

<details>
<summary>点开查看逐步解答</summary>

$(x+2)(x+3) + 2 = x^2+5x+6 + 2 = x^2+5x+8$ ✓。用代码抽查几个值：

```python
for x in [0, 2, -3]:                 # 抽三个测试值
    left = (x + 2) * (x + 3) + 2     # 商乘除式加余式
    right = x*x + 5*x + 8            # 原被除式
    print(left == right)             # 三组都应为 True
```

恒等式成立，除法无误。
</details>

**练习 3**：算 $(x^3-1) \div (x-1)$。提示：把缺的次项用 $0$ 补齐再走竖式。

<details>
<summary>点开查看逐步解答</summary>

把 $x^3-1$ 看成 $x^3+0x^2+0x-1$：

1. $x^3 \div x = x^2$；乘 $x^2(x-1) = x^3-x^2$；减：$0-(-1)=1$，剩 $x^2$；落 $0x$；
2. $x^2 \div x = x$；乘 $x(x-1) = x^2-x$；减：$0-(-1)=1$，剩 $x$；落 $-1$；
3. $x \div x = 1$；乘 $x-1$；减：余 $0$。

商 $x^2+x+1$，余 $0$——整除！恒等式 $x^3-1 = (x-1)(x^2+x+1)$ 是第 10 章整除性里的常客，这里已经能亲手推出来。
</details>

## 7. 选读：为什么竖式每一步都合法？

<details>
<summary>选读 · 减法不改变"被除式"的总量</summary>

竖式的核心动作是"从被除式里减掉除式与商的乘积"。每做一轮，写下的账目都保持同一个形状：

$$\text{当前剩下部分} = \text{被除式} - (\text{除式} \times \text{已写好的商})$$

左边每剥一层，右边"已写好的商"就多一项——两边始终相等，因为减法只是从等式两边同时拿走了同一块。流程结束时：

$$\text{余式} = \text{被除式} - \text{除式} \times \text{商}$$

移项就是定义里的 $f(x) = g(x)\,q(x) + r(x)$。竖式不是一套要背的咒语，而是"保持恒等"这条唯一戒律的机械执行。

至于为什么余式唯一：假如存在两套不同的"商 + 余式"，两式相减后除式会整除一个次数更低的式子——除非那个式子是 $0$，否则次数账算不平。所以竖式走到哪一步、商哪一项，都是唯一确定的，不存在"另一种竖法"。

</details>
