# 代数：式子与方程

前三章里，每个数都是具体的：3 就是 3。这一章我们迈出关键一步——让**字母**代替数，让式子先"活着"，再谈计算。等号和不等号也不再是"算出结果后填的符号"，而是**提问的方式**。这一章你会学到：

1. [用字母代替数](./10-letters.md)——给任意数留座位的艺术；
2. [坐标纸速成：数对与图像](./12-coordinate-paper.md)——两个数钉死一个点：把体温单钉成折线图，给函数图像提前打个样；
3. [合并同类项与展开](./20-combine-expand.md)——分配律的整理术：式子的收纳法；
4. [因式分解：反过来展开](./25-factoring.md)——展开的倒放：从面积反推边长；
5. [多项式除法：多项式的竖式](./26-polynomial-division.md)——算术竖式平移进字母世界：除、乘、减、落，一层层降次剥离；
6. [余数定理与因式定理](./27-remainder-theorem.md)——不真除的魔法：代一个数进去，余数当场现形；拖动 plot 曲线看它何时穿过零点，因式无所遁形；
7. [一元一次方程](./30-linear-equation.md)——解方程 = 问一条直线什么时候过零点；
8. [二元一次方程组与消元](./35-system-of-equations.md)——两张小票锁死两种单价：在卡片消元操作图里亲手搬走一个未知数，再看两条直线交出答案；
9. [不等式](./40-inequality.md)——解集是一片区域；小心乘负数时方向翻转；
10. [分式运算：通分与约分](./42-fraction-expressions.md)——字母下到分母：分数四则原样开工，分母归零处是禁地；
11. [二次方程与求根公式](./50-quadratic-formula.md)——四千年前的配方术，浓缩成一把万能钥匙；
12. [二次不等式与符号表](./55-quadratic-inequality.md)——方程管边界，不等式管地皮：抛物线两侧的符号账。

为什么值得爬这一级台阶？因为傅里叶变换把信号拆成一条条正弦波的组合，那本质上是在解一个"用字母写成的方程"。你现在练的每一次代入、每一次移项、每一次配方，都在为那次伟大的拆解做准备。

## 实战挑战 · 菜地面积的方程

情境改编自经典题型（人教版九年级"一元二次方程的应用"几何面积类，历年中考的常客）：

学校劳动基地开出一块长方形菜地，**长比宽多 3 米，面积为 40 平方米**。设宽为 $x$ 米，则长为 $x + 3$ 米，由"长 × 宽 = 面积"得：

$$x(x+3) = 40 \quad\Longrightarrow\quad x^2 + 3x - 40 = 0$$

**(a)** 算出这个方程的判别式 $\Delta = b^2 - 4ac$；
**(b)** 算出判别式的算术平方根；
**(c)** 求出符合实际的宽（米）——两个根里有一个是负数，记得按题意舍去。

系数已替你整理好（$a=1,\ b=3,\ c=-40$），下面的代码能跑但三步全错，改到通过：

```exercise
# @title: 实战挑战：从面积回到边长
# @check: 169
# @check: 13
# @check: 5
# @hint: (a) 判别式中间是减号 b² − 4ac；(b) delta ** 0.5 开平方后用 int() 收成整数；(c) 求根公式取正分支 (-b + sq) / (2*a)，负根不合题意。
a, b, c = 1, 3, -40   # 方程 x^2 + 3x - 40 = 0 的三个系数（已整理好）

delta = b**2 + 4*a*c   # (a) 判别式 ← 中间的符号错了，先跑一遍看看它给出了什么
print(delta)

sq = delta             # (b) 判别式的算术平方根 ← 这里还只是判别式本身
print(sq)

width = c              # (c) 宽是多少米？← 占位的错误答案，换成你的解
print(width)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 判别式：$\Delta = 3^2 - 4\times1\times(-40) = 9 + 160 = 169$。

**(b)** $\sqrt{169} = 13$（第 3 章的老朋友：完全平方数）。

**(c)** 代入求根公式：

$$x = \frac{-3 \pm 13}{2} \quad\Longrightarrow\quad x_1 = 5, \quad x_2 = -8$$

宽度不能是负数，取 $x = 5$：菜地宽 **5 米、长 8 米**。验算：$5 \times 8 = 40$ ✓。

```python
a, b, c = 1, 3, -40

delta = b**2 - 4*a*c          # 判别式：169
sq = int(delta ** 0.5)        # 算术平方根：13
width = (-b + sq) // (2 * a)  # 正分支：(−3 + 13) // 2 = 5
length = width + 3            # 长 = 宽 + 3

print(delta, sq)
print(f"宽 {width} 米, 长 {length} 米, 验算面积 {width * length}")
```

换一条路验证：第 25 课的因式分解也能解它——凑"和为 3、积为 −40"的数对，$(x+8)(x-5) = 0$ 给出同样两根。分解快而巧，公式稳而万能：两条路都通，正是本章把它们排在一起的理由。
</details>

## 章节大题：一张水费单的全章会诊

学完这一章，来给一张再普通不过的水费单做"全章会诊"。某市水价是"底费 + 按量"两段式：每月水费 $y = 8 + 3t$（元），$t$ 为当月用水吨数——底费 8 元、每吨 3 元，正是本章反复出现的"$b+ax$"形状。下面五小问依次用到**合并同类项、解一次方程（含 // 整除陷阱）、解不等式（含乘负翻面）、因式分解与判别式**；代码能跑，但六条检查全不过，改到全部通过：

```exercise
# @title: 章节大题：一张水费单的全章会诊
# @check: 三户总水费: 105
# @check: 李家用水: 9 吨
# @check: 预算内最多用: 30 吨
# @check: 水管冰点: t=5 时 w=-4, 成立吗: True
# @check: Δ = 1
# @check: 代回验证: 0 0
# @hint: 四个暗坑加两处手滑：① 每户各有自己的底费 8 元，不能把三个 8 合并成一个；② 先移项再做整除 (35 - 8) // 3，顺序反了结果就不对；③ 92 // 3 正好砍掉小数部分；④ 两边同除以 −4 不等号要翻面，且 t > 4 取不到 4 本身；⑤ Δ 中间是减号；⑥ 凑的两个数要"和为 9、积为 20"，代回原式都该归零。
a, b, c = 6, 9, 12          # 同一栋楼三户人家的用水吨数

total = 8 + 3 * (a + b + c)            # (1) 三户总水费 ← 底费真的一家一份吗？
print(f"三户总水费: {total}")

t_li = 35 // 3 - 8                     # (2) 李家缴了 35 元，用了几吨？← 移项和除法的顺序
print(f"李家用水: {t_li} 吨")

max_t = (100 - 8) / 3                  # (3) 预算至多 100 元，整数上限是多少吨？
print(f"预算内最多用: {max_t} 吨")

t_min = 4                              # (4) 水温 w = 16 - 4t，跌破 0 的最小整数小时数
w = 16 - 4 * t_min                     #     ← 除以 −4 时方向还记得翻面吗？
print(f"水管冰点: t={t_min} 时 w={w}, 成立吗: {w < 0}")

p, q = 2, 10                           # (5) x² - 9x + 20 = (x - p)(x - q)，凑这两个数
delta = (-9)**2 + 4 * 1 * 20           #     判别式 ← 中间的符号对吗？
left = p*p - 9*p + 20                  # 把 p 代回原式：分解对了就该等于 0
right = q*q - 9*q + 20                 # 把 q 代回原式
print(f"Δ = {delta}")
print(f"代回验证: {left} {right}")
```

<details>
<summary>点开查看逐步解答</summary>

**(1) 合并同类项**：三户各有一份底费，总水费是 $(8+3a)+(8+3b)+(8+3c)$——常数项归堆得 $24$，含字母的归堆得 $3(a+b+c)$，所以总价 $= 24 + 3\times27 = 105$ 元。错版只留了一个 8，那等于三户合用一个水表。

**(2) 解一次方程**：$8+3t=35$，先移项得 $3t=27$，再整除 $t=9$ 吨。错版把次序反了（先 35//3 再减 8）——移项在前、做除在后，顺序不能乱。

**(3) 预算不等式**：$8+3t \le 100 \Rightarrow 3t \le 92 \Rightarrow t \le 92/3 \approx 30.67$。吨数必须取整，向下取整得 **30 吨**——`92 // 3` 正好砍掉小数尾巴。这一问两边除的是正数，方向不翻。

**(4) 乘负翻面**：$16 - 4t < 0 \Rightarrow -4t < -16$，两边同除以 $-4$，不等号**翻面**得 $t > 4$；4 本身取不到（$w=0$ 只是贴住冰点，不算跌破），最小整数是 **5**，此时 $w=-4$。

**(5) 因式分解与判别式**：$\Delta = (-9)^2 - 4\times1\times20 = 1 > 0$，两个不相等的实根；凑"和为 9、积为 20"的数对，得 $x^2-9x+20=(x-4)(x-5)$——这两根正是第 50 课求根公式算出来的那两位。验法朴素而可靠：把 4 和 5 代回原式，双双归零。

修好后的关键行：

```python
total = 24 + 3 * (a + b + c)   # 三份底费都在
t_li = (35 - 8) // 3           # 先移项，后整除
max_t = (100 - 8) // 3         # 整数上限直接砍小数
t_min = 5                      # t > 4 里的最小整数
delta = (-9)**2 - 4 * 1 * 20   # Δ = 1 > 0：两个不相等实根
p, q = 4, 5                    # 和 9、积 20，代回全归零
```

一张水费单，从合并同类项一路考到判别式——本章六课全是它的侧面。
</details>
