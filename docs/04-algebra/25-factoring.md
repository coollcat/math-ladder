# 因式分解：反过来展开

## 1. 从一个场景开始

一块长方形菜地被拆成四小块：一块 $x^2$，两块长条，一个小角。你一眼看不出它的边长，却能数出总面积是 $x^2+5x+6$。

因式分解要做的就是**从面积反推边长**：

$$x^2+5x+6=(x+2)(x+3)$$

展开是"知道边长算面积"；分解是"看到面积猜边长"。它是乘法分配律的倒放。

## 2. 直觉解释

想象一个长方形：

- 横向边长是 $x+p$；
- 纵向边长是 $x+q$；
- 总面积就是 $(x+p)(x+q)$。

把它切开，会得到四块：

| 区域 | 面积 |
| --- | --- |
| 左下大方块 | $x^2$ |
| 右下长条 | $px$ |
| 左上长条 | $qx$ |
| 右上小角 | $pq$ |

所以：

$$(x+p)(x+q)=x^2+(p+q)x+pq$$

这句话是本课的发动机。分解 $x^2+bx+c$ 时，其实是在问：**哪两个数的和是 $b$，积是 $c$？**

## 3. 正式定义

**因式分解**：把一个多项式写成几个多项式相乘的形式。

动笔前先看一眼**公因式**：如果各项都含有同一个因数或字母，先把它请到括号外。比如

$$3x+6=3(x+2),\qquad 4x^2-2x=2x(2x-1)\text{。}$$

这一步不会把所有项都消掉，只是把公共部分放到外面；剩下的括号再按下面的方法继续观察。

对首项为 $x^2$ 的二次三项式：

$$x^2+bx+c=(x+p)(x+q)$$

其中两个关键条件同时成立：

1. $p+q=b$——中间一次项的系数；
2. $pq=c$——常数项。

这两个条件缺一不可。只凑出乘积，可能中间项不对；只凑出和，常数项也不对。

## 4. 分步例题

**例 1**：分解 $x^2+7x+12$。

1. 目标形式：$(x+p)(x+q)$。
2. 找乘积：$pq=12$。
3. 找和：$p+q=7$。
4. 检查数对：$2\times6=12$，且 $2+6=8$，不行；$3\times4=12$，且 $3+4=7$，可以。
5. 写答案：$x^2+7x+12=(x+3)(x+4)$。

**例 2**：分解 $x^2-x-6$。

这里 $b=-1$，$c=-6$。尝试 $p=-3$、$q=2$：

$$(-3)\times2=-6,\quad (-3)+2=-1$$

因此：

$$x^2-x-6=(x-3)(x+2)$$

负号不是额外新规则，它仍然服从"和与积"两条条件。

<details>
<summary>选读 · 两个高频形状</summary>

除了"找和与积"，还有两个形状值得认识。平方差来自和与差相乘：

$$(x+A)(x-A)=x^2-A^2$$

所以 $x^2-9=(x+3)(x-3)$。完全平方则是两条相等的长条：

$$(x+A)^2=x^2+2Ax+A^2,\qquad (x-A)^2=x^2-2Ax+A^2$$

例如 $x^2+6x+9=(x+3)^2$。看见这些形状可以先认出来；认不出来时，"和与积"或后面的求根公式仍然能接住它。
</details>

## 5. 动手实验

拖动 $p$ 和 $q$，先看右上小角的面积 $pq$，再看两条长条合并成 $(p+q)x$。

```viz
{
  "type": "factoring",
  "b": 5,
  "c": 6,
  "p": 1,
  "q": 6
}
```

挑战：把 $p,q$ 调成 2 和 3。你会看到四块面积正好拼回 $x^2+5x+6$。再把目标换成负常数项时，负数拼块会收进符号账本；这时看读数——$pq$ 决定常数符号，$p+q$ 决定中间项。

下面的程序不靠灵感，而是检查所有整数数对：

```python title="用穷举法找 p 和 q"
b = 7      # 中间项系数
c = 12     # 常数项
answers = []   # 空列表：准备存放所有可能的数对

for p in range(-12, 13):          # range 生成 -12 到 12 的整数
    q = c // p if p != 0 else 0   # 三元表达式：if 前的条件成立就取左边的值，否则取 else 后的值；p 为 0 时先给占位值
    if p != 0 and p * q == c and p + q == b:
        answers.append((p, q))    # append：把一对答案加到列表末尾

print(f"{b}x² + {c} 的整数分解辅助解：{answers}")
```

穷举不是最优雅的方法，但它暴露了本质：因式分解是一场受两个条件约束的搜索。

### 快问快答

```quiz
x² + 9x + 20 可以分解成下面哪一组？
- (x+4)(x+5) [*]
- (x+2)(x+10)
- (x-4)(x-5)
? 4×5=20，并且 4+5=9，两个条件都满足。
```

:::warning[常见误区]

**误区一**："只要乘积等于常数项就行。"
$2\times6=12$，但 $x^2+8x+12$ 不是 $x^2+7x+12$。中间项必须验。

**误区二**："因式分解改变了式子的值。"
在恒等变形里，$(x+3)(x+4)$ 和 $x^2+7x+12$ 只是同一块面积的两种名字。代任意 $x$ 都应相等。

**误区三**："所有二次三项式都能分解成两个整数一次因式。"
比如 $x^2+x+1$ 在整数范围内找不到合适数对。这时需要换用求根公式或其他工具，不必继续强行凑数。

:::

## 6. 练习

**练习 1**：分解 $x^2+8x+15$ 后，打印 $p$ 和 $q$ 的和。

```exercise
# @title: 练习：找 p + q
# @check: 8
# @hint: 常数 15 可分成 3×5；再检查 3+5 是否等于中间项系数 8。最后打印这个和。
p = 1
q = 15
print(p + q)
```

**练习 2**：用 Python 验证 $(x-3)(x+2)$ 展开后确实等于 $x^2-x-6$。

<details>
<summary>点开查看逐步解答</summary>

取三个不同的 $x$ 值分别代入两边。数值一致不能代替证明，但能快速发现符号错误。

```python
for x in [-4, 0, 5]:   # 列表里放几个测试值
    left = (x - 3) * (x + 2)
    right = x*x - x - 6
    print(f"x={x}: {left} / {right}")
```

三行输出两侧都相等。符号推导则来自分配律：$x^2+2x-3x-6=x^2-x-6$。
</details>

**练习 3**：为什么 $x^2+4x+5$ 不能在整数范围内分解成 $(x+p)(x+q)$？

<details>
<summary>点开查看答案</summary>

整数 $p,q$ 的积必须是 5，只可能是 $1,5$ 或 $-1,-5$。它们的和分别是 6 和 $-6$，都不是 4。两个条件无法同时成立，所以这条路走不通。
</details>

**练习 4**：分解 $12x^2+18x$ 时，先提公因式。括号外的系数是多少？括号里 $x$ 的系数和常数分别是多少？打印成两行。

```exercise
# @title: 练习：先提公因式
# @check: 6
# @check: [2, 3]
# @hint: 系数 12 和 18 的最大公因数是 6；两项还都有 x。提出 6x 后，剩下 2x 与 3。
common = 3
bracket = [4, 1]
print(common)
print(bracket)
```

<details>
<summary>点开查看逐步解答</summary>

$12x^2=6x\cdot2x$，$18x=6x\cdot3$，所以公共部分是 $6x$：

$$12x^2+18x=6x(2x+3)\text{。}$$

```python
common = 6
bracket = [2, 3]
print(common)
print(bracket)
```
</details>

## 7. 选读：为什么"和与积"足够？

<details>
<summary>选读 · 展开回看</summary>

按分配律逐步展开：

$$(x+p)(x+q)=x(x+q)+p(x+q)=x^2+qx+px+pq=x^2+(p+q)x+pq$$

合并同类项后，一次项系数只由 $p+q$ 决定，常数项只由 $pq$ 决定。所以只要这两处匹配，分解就正确。

反过来，若两个不同的整数数对有相同的和与积，它们其实是同一个数对——这是二次方程韦达定理的雏形，后面讲求根公式时会再次出现。
</details>
