# 二次不等式与符号表

## 1. 从一个场景开始

投篮出手后，球的高度近似是 $h = v_0 t - 5t^2$（$v_0$ 是出手竖直速度）。防守队员身高够不着 3 米以下，问：**球在 3 米之上的时间段有多长**？

$h > 3$ 里带着 $t^2$——第 40 课那套"移项、除系数"的一次不等式流程，碰到平方当场失灵：两边开方？平方数有两个根，方向全乱。答案是**一段时间**，不是一个点，也说不清在哪儿。

这课的解题思路特别诚实：解不了不等式，就先解它对应的**方程**（上一课的求根公式专管这个），再问一句"两根**之间**和**之外**，式子各取什么符号"。一张符号表把问题安排得明明白白。

## 2. 直觉解释

把 $x^2-x-6$ 画到坐标纸上（第 12 课的手艺现成）：它是开口向上的抛物线，与横轴交在 $x=-2$ 和 $x=3$ 两处。

现在读图回答三个问题：

- $x^2-x-6>0$，即曲线**在海平面以上**——横轴的哪一段？两根**之外**：$x<-2$ 或 $x>3$；
- $x^2-x-6<0$，曲线**沉在海平面以下**——两根**之间**：$-2<x<3$;
- $x^2-x-6=0$——恰好压在海平面上：$x=-2$ 或 $x=3$。

开口向上（$a>0$）的抛物线像一只碗：碗底沉在两根之间，碗沿翘在两根之外。所以"大于零取两边，小于零取中间"（$a>0$ 时）——这句话就是本课的全部地形学。第 40 课那句"方程管边界，不等式管地皮"在这里彻底兑现：求根公式量出边界，符号表圈出地皮。

## 3. 正式定义

解二次不等式的标准流程——先解方程，再列**符号表**：

| 步骤 | 动作 | 用到的家伙 |
| --- | --- | --- |
| 1. 标准形 | 移项让右边为 $0$，左边整理成 $a x^2+b x+c$，与 $0$ 比大小 | 第 30 课的移项 |
| 2. 求根 | 解对应方程 $a x^2+b x+c=0$ | 因式分解或求根公式 |
| 3. 符号表 | 数轴被两根切成三段，每段挑一个试探点代进去，记下符号 | 代入求值 |
| 4. 抄答案 | 按"大于取两边 / 小于取中间"（$a>0$）写下解集 | 本节地形学 |

符号表长这样（以 $x^2-x-6>0$ 为例，根是 $-2$ 和 $3$）：

| 区段 | 试探点 | 代入值 | 符号 |
| --- | --- | --- | --- |
| $x<-2$ | $-3$ | $9+3-6=6$ | $+$ |
| $-2<x<3$ | $0$ | $0-0-6=-6$ | $-$ |
| $x>3$ | $4$ | $16-4-6=6$ | $+$ |

为什么每段只需试**一个**点？因为二次式只在根处变号（选读里细说）：同一段里所有 $x$ 给出的符号必然相同。

**$a<0$ 怎么办**：两边同乘 $-1$ 化成 $a>0$——记得第 40 课的铁律，乘负数**不等号要翻面**。翻完再走流程，地形学照旧适用。

## 4. 分步例题

**例**：解不等式 $x^2-2x-3<0$。

1. 标准形：右边已是 $0$，且 $a=1>0$，直接开工；
2. 求根：分解 $x^2-2x-3=(x-3)(x+1)$，根为 $x=-1$ 和 $x=3$；
3. 符号表：
   - 取 $x=-2$：$(-2-3)(-2+1)=(-5)(-1)=5>0$；
   - 取 $x=0$：$(-3)(1)=-3<0$；
   - 取 $x=4$：$(1)(5)=5>0$；
4. 抄答案：要求 $<0$，取负号那一段——解集是 $-1<x<3$。

验算两头：$x=0$（区间里）原式 $=-3<0$ ✓；$x=5$（区间外）原式 $=12<0$ 不成立 ✓。若题目改成 $\le0$，两个根本身也进解集，答案写成 $-1\le x\le3$——空心实心（第 40 课的老规矩）在二次世界照样分毫不差。

## 5. 动手实验

### 实验 1（viz）：拖动系数，看地皮搬家

```viz
{
  "type": "plot",
  "title": "x^2 + bx + c 什么时候大于 0？",
  "expr": "x^2 + b*x + c",
  "xmin": -6,
  "xmax": 6,
  "sliders": [
    { "name": "b", "min": -6, "max": 6, "step": 1, "value": -2 },
    { "name": "c", "min": -5, "max": 5, "step": 1, "value": -3 }
  ]
}
```

默认位置 $b=-2,\ c=-3$：抛物线穿轴两次，海平面以上的两段横坐标就是解集。三个挑战：

1. 心算 $\Delta=b^2-4c$，再看曲线：$\Delta>0$ 两根分居、$\Delta=0$ 抛物线骑在轴上、$\Delta<0$ 整条飘在海平面之上；
2. 把 $c$ 拖到 $5$（$\Delta<0$）：曲线全程在横轴上方——$x^2+bx+c>0$ 的解集是**全体实数**，"$<0$"则**无解**；
3. 交换问法：把 ">0" 换成 "<0"，地皮跟着从两边搬到中间。

### 实验 2（python）：符号表生成器

```python title="三段数轴，逐段试探符号"
roots = [-2, 3]                        # x^2 - x - 6 的两个根
probes = [-3, 0, 4]                    # 每段挑一个试探点：左边、中间、右边

for x in probes:                       # 对每个试探点依次代入
    value = x*x - x - 6                # 二次式逐项硬算
    if value > 0:                      # if：按符号分拣（第 1 章介绍过的老朋友）
        sign = "正（海平面以上）"
    else:
        sign = "负（海平面以下）"
    print(f"试探 x={x}: 值 {value}, 符号{sign}")
```

输出按"正、负、正"排开——符号表一行行打在屏幕上，与纸上画的一模一样。

### 实验 3（python 滑块）：试探点进门检查

```python title="滑块实验：这个点在解集里吗"
# sliders: probe=4 [-5:5:1]
# 问：x^2 - x - 6 > 0 的解集是 x < -2 或 x > 3，probe 在里面吗？
value = probe*probe - probe - 6        # 试探点代进去
print(f"probe={probe}, 式子值={value}")
print(value > 0)                       # True 表示在解集里
```

拖动 `probe` 从 $4$ 滑到 $0$ 再滑到 $-4$：`True → False → True`。最后一步拖到 $-2$ 或 $3$——值恰好归零，`False`：严格大于号把边界关在门外。

### 快问快答

```quiz
不等式 x^2 - 4 > 0 的解集是？
- -2 < x < 2
- x < -2 或 x > 2 [*]
- x > 2
? 因式分解 (x-2)(x+2) > 0，开口向上：大于取两边。写成"两根之间"就把碗底和碗沿弄反了。
```

::::warning[常见误区]

**误区一**："你以为'大于'就取中间。" 中间是抛物线的**碗底**——开口向上时那里恰恰是负号地盘。地形学口诀挂在开口方向上：$a>0$ 时大于取两边、小于取中间；拿不准就老实画草图或列表。

**误区二**："你以为方程的根就是不等式的解。" 根只是**边界**。$x^2-x-6>0$ 的解是两段区域，$-2$ 和 $3$ 本身都不在内（代进去等于 $0$，不大于 $0$）。答完边界必须答地皮，才算解题完。

**误区三**："你以为 $\Delta<0$ 就该写'无解'。" 那只对一部分题成立：$a>0$ 且 $\Delta<0$ 时，曲线整条悬在海平面**上方**——">0"的解集是全体实数，"<0"才无解。无解与全解，方向取决于问号朝哪边。

::::

## 6. 练习

**练习 1**：解 $x^2-2x-3<0$ 的核心一步是符号表。下面的代码能跑，但式子符号错了——先修好，再让试探点 $x=0$ 替你回答：

```exercise
# @title: 练习：试探点替你验区段
# @check: True
# @check: False
# @hint: 原式是 x^2 - 2x - 3，常数项是减 3，不是加 3。x=0 应落在解集里（True），x=4 在解集外（False）。
x = 0
value = x*x - 2*x + 3   # ← 常数项的符号对吗？
print(value < 0)         # x=0 应当在解集 -1 < x < 3 里
print(4*4 - 2*4 - 3 < 0) # x=4 应当在解集外
```

**练习 2**：解 $-x^2+x+6>0$。提示：先两边同乘 $-1$ 化成开口向上——别忘了翻不等号。

<details>
<summary>点开查看逐步解答</summary>

两边乘 $-1$（第 40 课铁律：翻面）：$x^2-x-6<0$。这就是本课例题的镜像：根仍是 $-2$ 和 $3$，问"小于零"取中间，解集 $-2<x<3$。验算 $x=0$：$0-0-6=-6<0$ ✓。先化标准形再查表，负系数的二次不等式就不可怕。

```python
x = 0
print(-x*x + x + 6 > 0)   # True：0 在解集里
print(-x*x + x + 6)       # 6 > 0，与化简后的 -6 < 0 等价
```
</details>

**练习 3**（思考）：回看第 40 课的实验——一次不等式 $2x-k>0$ 的解集只有**一段**；本课 $x^2-x-6>0$ 的解集却有**两段**。段数由什么决定？

<details>
<summary>点开查看逐步解答</summary>

由曲线与横轴的**穿越次数**决定：直线最多穿一次，一次不等式的解集至多一段；抛物线最多穿两次，两根把数轴切成三段，取正取负各按地形挑——">0 取两边"天然给出两段，"<0 取中间"给出一段。$\Delta<0$ 时曲线不穿轴，解集要么全取（>0）要么空集（<0）。将来解更高次的不等式（第 13 章画函数图像定极值时会重逢），还是同一个思路：**先找全部零点，再逐段查符号**——那时"符号表"会升级成横扫一切次数的"穿根法"。
</details>

## 7. 选读：为什么二次式只在根处变号？

<details>
<summary>选读 · 符号表的合法性证明</summary>

设 $a>0$，$f(x)=ax^2+bx+c$ 有两个根 $x_1<x_2$，分解得 $f(x)=a(x-x_1)(x-x_2)$。符号由两个因式的正负配对决定：

- $x<x_1$：两个括号都是负，负负得正，$f>0$；
- $x_1<x<x_2$：左负右正，$f<0$；
- $x>x_2$：两个都是正，$f>0$。

三个区段的符号由因式配对**锁死**，段内任何 $x$ 的符号必然一致——这就是"每段试一个点就够"的理由。

$\Delta=0$ 时 $f(x)=a(x-x_1)^2$：平方永远非负，符号表退化成两段"正"，中间只在 $x_1$ 一点归零。$\Delta<0$ 时分解不出实根，$f(x)$ 与 $a$ 同号到底——配完方看得最清楚：$a\Big(x+\frac{b}{2a}\Big)^2+\frac{4ac-b^2}{4a}$，后面那块在 $\Delta<0$ 时是正的，整条曲线的最低点都悬在零之上。

将来第 13 章用导数研究函数增减时列的"一阶导数符号表"，正是本课这张表的高配版——工具换了，"分段试探、逐段记账"的心法一模一样。

</details>
