# 用字母代替数

## 1. 从一个场景开始

出租车起步价 8 元，之后每公里 3 元。走 1 公里是 $8+3\times1$，走 2 公里是 $8+3\times2$……每换一个里程就得重新说一遍，说到口干舌燥。

数学家的解决方案只有一步：把"公里数"这个每次都要换的位置，用一个字母占住——$8+3x$。一行写完，所有里程通吃。这个看似偷懒的动作，是人类数学史上最重要的一次升级。

## 2. 直觉解释

字母就是一个**留空的名字牌**：

$$8 + 3 \cdot \boxed{\phantom{x}}$$

牌子上写几，式子的值就跟着变：

| 放入 | 取出 |
| --- | --- |
| $x=1$ | $8+3\times1=11$ |
| $x=2$ | $8+3\times2=14$ |
| $x=7$ | $8+3\times7=29$ |

所以含字母的式子不是"一道题"，而是**一整族算术题的压缩包**。给它一个具体值、算出一个数的过程叫**求值**。

其实你早就用过字母：第 1 章加法课的 $a+b=b+a$ 里，$a$ 和 $b$ 就是"随便是谁"的名字牌。今天只是让它们正式上岗。

## 3. 正式定义

**代数式**：用运算符号把数和字母连接起来的式子，如 $2x+3y$。其中的字母叫**变量**。

**求值**：给每个变量指定数值，按运算优先级算出一个数。

两条记号约定（全世界的数学书都这么写）：

| 写法 | 读法 | 含义 |
| --- | --- | --- |
| $2x$ | "2x" | $2 \times x$：数与字母相乘，乘号省略 |
| $xy$ | "xy" | $x \times y$：字母与字母相乘，乘号省略 |

省略是为了少写字，但**省掉的乘号依然存在**：看到 $2x$，脑子里必须自动响起"2 乘以 x"。

## 4. 分步例题

**例**：求 $x=3,\ y=5$ 时 $2x+3y$ 的值。

1. 抄下式子：$2x+3y$
2. 代入（每个字母换成自己的数）：$2\cdot3+3\cdot5$
3. 先乘后加（优先级！）：$6+15$
4. 收工：得 $21$

注意第 2 步：代入时把乘号补回来再算，是最不容易出错的做法。四步流程"抄 → 换 → 算 → 报"，式子再长也一样。

## 5. 动手实验

### 实验 1：先把整族取值看一眼

含字母的式子喂进一串数、吐出一串结果——把"喂"当横轴、"吐"当纵轴描点连线，式子就有了形状。拖动滑块 $k$，看式子 $kx+3$ 的形状怎么变：

```viz

  "title": "kx + 3 的取值连成一条线",
  "expr": "k*x + 3",

  "xmax": 5,
  "sliders": [
    { "name": "k", "min": -3, "max": 5, "step": 1, "value": 2 }
  ]

```

$k$ 越大线越陡；$k$ 变成负数，整条线翻个身。**一个式子原来藏着无穷多次求值**，图像把它们一次摆完。"式子—图像"这条暗线，第 6 章函数章将全面展开。

### 实验 2：表达式机器（浮窗滑块版）

```python title="拖动滑块，机器实时吐出 2x+3y"
# sliders: x=2 [-5:5:1], y=-1 [-5:5:1]
# x 和 y 由滑块注入，代码里不用再赋值
result = 2*x + 3*y   # 求值：先乘后加
print(f"x={x}, y={y} 时，2x+3y = {result}")
```

### 实验 3：批量求值

机器的真正威力是批量生产：

```python title="给 x 喂一排数"
xs = [-2, -1, 0, 1, 2]   # 列表：一次装好五个输入
for x in xs:              # 对列表里的每个 x 依次做一遍
    print(f"x={x} -> {2*x + 3}")
```

观察输出：$x$ 每加 1，输出就加 3——增长是**均匀**的。这正是实验 1 那条线不弯的原因。

:::warning[常见误区]

**误区一**："$2x$ 是个二十多的两位数。"
$2x$ 是 $2\times x$ 的缩写，省略的只是乘号，乘法动作一分不少。

**误区二**："$x+x+x$ 可以写成 $x^3$。"
三个 $x$ 相**加**是 $3x$；$x^3=x\cdot x\cdot x$ 是三个 $x$ 相**乘**。复制的方式不同，产物完全不同（第 3 章乘方课讲过连乘才配得上指数）。

**误区三**："字母一旦定了值就永远是那个值。"
同一道题里，同一个字母必须始终代表同一个数（一字不二主）；但换一道题，$x$ 就可以重新指派。它是名字牌，不是终身编号。

:::

## 6. 练习

**练习 1**：求 $x=3,\ y=5$ 时 $2x+3y$ 的值。下面的代码能跑，但答案不对——查查哪里出了问题：

```exercise
# @title: 练习：代入求值
# @check: 21
# @hint: 题目要的是 x=3、y=5。检查一下前两行的赋值顺序——现在 5 给了 x、3 给了 y，正好放反了
x = 5
y = 3
print(2*x + 3*y)
```

跑通后再想一层：为什么放反了也照样输出一个数？因为求值从不拒绝任何输入——**错也会错得理直气壮**，这就是为什么验算永远是必要的。

**练习 2**：出租车费公式为 $8+3n$ 元（$n$ 公里）。问 $n=12$ 时车费多少？

<details>
<summary>点开查看逐步解答</summary>

```python
n = 12
fare = 8 + 3*n   # 先乘后加
print(fare)
```

结果是 44。抄式子 → 换值 → 先乘后加 → 报答案。
</details>

**练习 3**：苹果每千克 $a$ 元、梨每千克 $b$ 元，买 3 千克苹果、2 千克梨。总价怎么表示？当 $a=6,\ b=4$ 时是多少？

<details>
<summary>点开查看逐步解答</summary>

总价表达式：$3a+2b$。苹果钱归苹果钱、梨钱归梨钱——这正是第 20 课"合并同类项"的原型。

```python
a, b = 6, 4        # 一行同时给两个变量赋值
print(3*a + 2*b)   # 输出 26
```
</details>

## 7. 选读：字母不是一天学会的

<details>
<summary>选读 · 从修辞代数到符号代数</summary>

今天的我们觉得 $x$ 天经地义，但人类在这条路上走了两千多年。古巴比伦人解方程全靠一段话："某数的量，加上它的七分之一，等于六十……"这叫**修辞代数**——整道题没有半个符号。16 世纪的法国人韦达第一个系统地用字母表示已知量与未知量；笛卡尔定下"靠前的字母代表已知数、末尾的 $x,y,z$ 代表未知数"的惯例并沿用至今。

符号化为什么是革命？因为**规律一旦能用符号写下，就能被当作对象来摆弄**：移项、配方、消元，操作的都是符号本身，而不是某个具体的数。你接下来学的每一步变形，都在享受这场记号革命的红利。

</details>
