# 余数定理与因式定理

## 1. 从一个场景开始

质检站收到一道委托题：判断 $(x+5)$ 是不是多项式 $x^3+2x^2-13x+10$ 的**因式**。

按上一课多项式除法的老办法，得先做一次三次式除以一次式的竖式，商写三行、余数另起一行，草稿纸铺开一大片。可同事只瞟了一眼，十秒钟报出结论："是因式，放心拆。"

他没做除法。他把某个数**代了进去**——一次代入，余数当场现形。这节课就把这个"不真除"的魔法讲透：为什么代进去就知道余数？代的到底是谁？

## 2. 直觉解释

先老老实实暴力算一遍。让 $f(x) = x^3 - 4x^2 + x + 6$ 除以 $(x-1)$，竖式走完全程（上一课的例 2 刚算过它），得到：

$$f(x) = (x-1)(x^2-3x-2) + 4$$

商是 $x^2-3x-2$，余数是 $4$。

现在换个角度看它：**把 $x = 1$ 直接代进等式两边**。

右边第一项 $(x-1)$ 里藏着减号——代入 $x=1$ 后整块变成 $0$，商再长也全军覆没，只剩最后那个孤零零的常数：$0 \times (\text{什么}) + 4 = 4$。左边呢？$f(1) = 1 - 4 + 1 + 6 = 4$。

两边正好相等，而且**必然相等**。规律浮出水面：

> 想知道 $f(x)$ 除以 $(x-a)$ 的余数，不必除——把 $a$ 代进 $f(x)$，算出来的值就是余数。

商的内容根本不影响余数，因为带着 $(x-a)$ 的部分在代入时会**整体归零**。这就是长除法替我们白干的那一大半活儿。

## 3. 正式定义

**余数定理**：设 $f(x)$ 是一个多项式，把它除以一次式 $(x-a)$，所得的余数恒等于 $f(a)$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f(x)$ | 多项式 | 被除数，如 $x^3-4x^2+x+6$ |
| $a$ | 代入的数值 | 一次式 $(x-a)$ 里减号后面的那个数 |
| $q(x)$ | 商 | 多项式，本课可以不关心它的长相 |
| $r = f(a)$ | 余数 | 一个具体的数；代入即得 |

完整的恒等关系写成一行：

$$f(x) = (x-a)\,q(x) + f(a)$$

对一切 $x$ 都成立。

由它立刻得到一个超好用的推论——**因式定理**：

$$f(x) \text{ 能被 } (x-a) \text{ 整除} \iff f(a) = 0$$

换句话说："$x-a$ 是因式"当且仅当"$a$ 是 $f(x)$ 的根"。判因式不再需要除法，只需要**找根、验根**。

## 4. 分步例题

**例 1（求余数）**：求 $2x^3 - 3x + 5$ 除以 $(x-1)$ 的余数。

1. 认除式：$(x-1)$，代入的是 $a = 1$；
2. 代入：$f(1) = 2\times1 - 3\times1 + 5$；
3. 收账：$2 - 3 + 5 = 4$。
4. 结论：余数是 **4**，全程没碰长除法。

**例 2（因式定理降次）**：分解 $f(x) = x^3 - 2x^2 - 5x + 6$。

1. 试探根：先试最顺手的 $x=1$，$f(1) = 1 - 2 - 5 + 6 = 0$ ✓；
2. 因式定理启动：$(x-1)$ 是因式；
3. 拆掉一层：$f(x) = (x-1)(x^2-x-6)$（三次降成二次）；
4. 用第 25 课的手艺收拾二次：凑"和为 $-1$、积为 $-6$"的数对，得 $x^2-x-6=(x-3)(x+2)$；
5. 答案：$f(x) = (x-1)(x-3)(x+2)$。

注意第 3 步的分工：因式定理负责"从高往低砍一刀"，剩余部分的分解还是靠老手艺——它是降次的杠杆，不是万能钥匙。

### 实验 2（python）：暴力侦探，穷举所有整数根

下面的程序对 $-10$ 到 $10$ 的每个整数逐一代入，谁能让函数归零谁就是根：

```python title="用穷举法揪出全部整数根"
def f(x):                          # def 定义自己的函数：给一段公式取名字，随叫随到
    return x**3 + 2*x**2 - 13*x + 10   # return 把算出的值递回去

roots = []                         # 建一个空列表，准备收容所有根
for n in range(-10, 11):           # range 从 -10 数到 10（右端点不含）
    if f(n) == 0:                  # 只留能使函数恰好归零的候选者
        roots.append(n)            # append：把 n 加进列表末尾

print(roots)
print(f(-5), f(1), f(2))           # 再逐个验收这三个根，应当全为 0
```

输出 `[−5, 1, 2]` 和三个 $0$。对照实验 1 的曲线：程序穷举出来的根，正是图像穿零的三个位置。

### 实验 3（python）：验一下"代入即余数"

换一组系数更重的多项式，同时比较两种算法——硬代入和一环扣一环的"秦九韶"式累乘：

```python title="两条路，同一个余数"
a = 3                                        # 想代入的位置 x = 3
direct = 2*a**3 - 9*a**2 + 7*a - 11          # 直捣黄龙：把 3 塞进每一项分别算
horner = ((2*a - 9)*a + 7)*a - 11            # 秦九韶算法：从最高层往外一层层乘加，速度更快

print(direct)
print(horner)
print(direct == horner)                      # 两种路子算的余数必须一模一样
```

两行都输出 $-17$。这正是余数定理的工作现场：不管用什么姿势算，$f(3)$ 就是 $f(x)$ 除以 $(x-3)$ 的余数，连长除法的影子都不用见到。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为见到 $(x+5)$ 就该把 $5$ 代进去。" 其实一次式得先写成标准形状 $(x-a)$：$(x+5) = (x-(-5))$，真正该代的是 $-5$。**减号后面的数才是根**，负号一丢答案就反了。

**误区二**："你以为这套代换对付什么除式都灵。" 其实余数定理只在除式是**一次式** $(x-a)$ 时成立。除以 $x^2+1$ 这类二次式，一次代入爱莫能助。

**误区三**："你以为 $f(a)=0$ 就大功告成了。" 其实那只是确认了一个因式，多项式仍需继续降次、继续验证其余的根——一次归零不等于全部拆完。

:::

## 7. 练习

**练习 1**：判断 $(x+5)$ 是不是 $f(x)=x^3+2x^2-13x+10$ 的因式。下面的代码能跑但结果不对——有人在第一步就代错了数，改到三条检查全部通过：

```exercise
# @title: 练习：谁是伪装的因式
# @check: 120
# @check: 0
# @check: True
# @hint: 因式 (x + 5) 对应的根是 x = −5，不是 5——余数定理代的是"让它归零的那个数"，负号别丢！修好 root 后第二行自然归零，第三行的 True 随之而来。
def f(x):                              # 定义被检验的多项式
    return x**3 + 2*x**2 - 13*x + 10

rest_guess = f(5)                      # ← 错觉版：见 "x + 5" 就把 5 代了进去，看看它是多少
print(rest_guess)

root = 5                               # ← 经典陷阱就在这一行：这次该代谁？
rest_true = f(root)
print(rest_true)

is_factor = (rest_true == 0)           # 余数为 0 才有资格叫因式
print(is_factor)
```

<details>
<summary>点开查看逐步解答</summary>

1. 余数定理要求除式写成 $(x-a)$ 形状：$(x+5) = (x-(-5))$，所以验根要代 $a=-5$；
2. $f(5) = 125 + 50 - 65 + 10 = 120$——跟本题无关，它只是暴露了"代错人"的后果；
3. $f(-5) = -125 + 50 + 65 + 10 = 0$ → 余数为零 → $(x+5)$ 是因式 ✓；
4. 修正后的参考代码：

```python
def f(x):
    return x**3 + 2*x**2 - 13*x + 10

rest_guess = f(5)      # 120：代错的见证，保留作对照
root = -5              # 因式 (x + 5) ⇒ 根是 −5
print(rest_guess)
print(f(root))
print(f(root) == 0)
```

顺手补刀：实验 2 已穷举出三个根 $\lbrace-5,\ 1,\ 2\rbrace$，所以

$$f(x) = (x+5)(x-1)(x-2)$$

"判定单个因式"和"找出全部因式"，用的是同一台机器。
</details>

**练习 2**：用余数定理口算 $x^{45} - 1$ 除以 $(x-1)$ 的余数，再用 Python 验证你的答案。

<details>
<summary>点开查看逐步解答</summary>

余数 $= f(1) = 1^{45} - 1 = 0$——45 次的长除法被一次代入秒杀。

```python
n = 45
value = 1             # 1 的任何正整数次幂都是 1
for _ in range(n):    # 下划线 _ ：循环里不需要用到循环变量时的惯例写法
    value = value * 1 # 幂运算逐步累积，模拟 a 的 n 次方
print(value - 1)      # 输出 0：(x − 1) 整除 x⁴⁵ − 1
```

结论印在纸面上：$(x-1)\mid(x^{45}-1)$。这类"高次差一"的结构在第 10 章整除性里还会换装重现。
</details>

**练习 3**：概念辨析："若 $f(2) = 0$ 且 $f(3) = 0$，能否断定 $f(x)$ 至少是二次多项式？"

<details>
<summary>点开查看逐步解答</summary>

能（除了平凡例外）。一次多项式只有一个根，而这里 $2$ 和 $3$ 都是根，由因式定理 $(x-2)$ 与 $(x-3)$ 同时是因式，乘积至少给出 $(x-2)(x-3)$ 这个二次量。常数多项式不可能有两个不同根。所以 $f(x)$ 至少是**二次**的。反过来它也可能更高次——比如再添个因子 $(x+1)$ 变三次，两次归零只是次数的**下界**。
</details>

## 8. 选读与边界

### 选读 · 两行证明

按带余除法的定义，存在商 $q(x)$ 与余数 $r$ 使

$$f(x) = (x-a)\,q(x) + r$$

对一切 $x$ 成立。既然恒成立，那就挑最好欺负的位置——令 $x=a$：右边第一项 $(a-a)q(a) = 0$，于是 $f(a) = r$。余数定理到手。

再把 $r=f(a)$ 放回原式读一遍：$f(a)=0$ 时 $f(x) = (x-a)q(x)$ 恰是整除的定义，于是"$(x-a)$ 是因式 ⟺ $f(a)=0$"——因式定理同样到手。两个定理本来就是同一句话的正反面。

### 本课不管什么

- 除式必须是一次式 $(x-a)$：二次除式没有对应的"单点代入"；这是卡尺，不是瑞士军刀。
- 它只告诉我们余数与因式，**不负责完整求根**：三次以上的实根虚根去留，留给第 12 章复数与第 33 章的多项式环。
- 二项式展开、连分数逼近那样的下游技术，会在后面各章陆续回收这台机器。
