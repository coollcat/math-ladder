# 柯西不等式：两组平方和的乘积

## 1. 从一个场景开始

已知 $x^2+y^2=25$（点 $(x,y)$ 落在半径 5 的圆上），求 $3x+4y$ 的**最大值**。

试几个点：$(5,0)$ 给 $15$，$(0,5)$ 给 $20$，$(4,3)$ 给 $24$，$(3,4)$ 给 $25$。还能更大吗？$(2.5,\ \sqrt{18.75})$ 呢？一个一个试下去没有尽头。

第 57 课的基本不等式帮不上忙：它管的是两个数的**和**与**积**，而这里出现的是 $x^2+y^2$——两组**平方**。要收服它，得要一条"平方对平方"的新不等式，这就是**柯西不等式**。

## 2. 直觉解释

把四个数 $a,b,c,d$ 摆成两对，盯着这两个量看：

- 左边 $(a^2+b^2)(c^2+d^2)$：两组平方和**相乘**；
- 右边 $(ac+bd)^2$：交叉相乘之和的**平方**。

各展开一次（第 20 课的分配律）：

$$(a^2+b^2)(c^2+d^2) = a^2c^2 + a^2d^2 + b^2c^2 + b^2d^2$$
$$(ac+bd)^2 = a^2c^2 + 2abcd + b^2d^2$$

摆在一起看，两边**共用** $a^2c^2$ 与 $b^2d^2$ 这两块。真正要一较高下的，只剩剩下的部分：

$$\underbrace{a^2d^2 + b^2c^2}_{\text{左边剩下}}\qquad\text{对比}\qquad\underbrace{2abcd}_{\text{右边剩下}}$$

而左边剩下那两块，恰好能拼成一个**完全平方**：

$$a^2d^2 - 2abcd + b^2c^2 = (ad)^2 - 2(ad)(bc) + (bc)^2 = (ad-bc)^2$$

所以"左边比右边大多少"这个问题的答案是：**大了一个平方**。平方永远不小于 $0$，左边自然不会小于右边。柯西不等式不是一件新事实，它就是"平方非负"换了一身衣服。

## 3. 正式定义

**柯西不等式（二维形式）**：对任意实数 $a,b,c,d$，

$$(a^2+b^2)(c^2+d^2)\;\ge\;(ac+bd)^2$$

**取等当且仅当** $ad=bc$。

| 符号 | 含义 | 注意 |
| --- | --- | --- |
| $a,\ b$ | 第一对的两个数 | 任意实数，**不要求非负** |
| $c,\ d$ | 第二对的两个数 | 同上 |
| $a^2+b^2$ | 第一对的平方和 | 恒 $\ge0$ |
| $(ac+bd)^2$ | 交叉相乘之和的平方 | 恒 $\ge0$ |
| $ad=bc$ | 取等条件 | 两对**成比例**，不是两对相等 |

**证明（配方法）**，五步：

1. 展开左边：$(a^2+b^2)(c^2+d^2)=a^2c^2+a^2d^2+b^2c^2+b^2d^2$（分配律，第 20 课）；
2. 展开右边：$(ac+bd)^2=a^2c^2+2abcd+b^2d^2$（完全平方公式，第 50 课配方的老朋友）；
3. 相减，共用项两两抵消：

$$\text{左}-\text{右} = a^2d^2 - 2abcd + b^2c^2$$

4. 认出完全平方：$a^2d^2-2abcd+b^2c^2=(ad)^2-2(ad)(bc)+(bc)^2=(ad-bc)^2$；
5. 任何实数的平方都 $\ge0$（第 50 课的老底）：$\text{左}-\text{右}=(ad-bc)^2\ge0$，即左 $\ge$ 右。

取等当且仅当 $(ad-bc)^2=0$，即 $ad=bc$。

⚠️ **$ad=bc$ 不等于"$a=c$ 且 $b=d$"**。比如 $(a,b)=(1,2)$、$(c,d)=(2,4)$：$ad=1\times4=4$，$bc=2\times2=4$，取等成立——两对数字完全不同，只是**成比例**（后一对是前一对的 2 倍）。这才是柯西取等的真正含义。小字补一句严谨版：当 $a=b=0$ 时 $ad=bc$ 对任何 $c,d$ 都自动成立（此时柯西两边都是 $0$），"成比例"的说法在这时失灵——$ad=bc$ 本身才是取等的完整判据。

## 4. 分步例题

**例 1（求范围）**：已知 $a^2+b^2=1$，$c^2+d^2=4$，求 $ac+bd$ 的取值范围。

1. 代柯西：$(ac+bd)^2\le(a^2+b^2)(c^2+d^2)=1\times4=4$；
2. 开方（两边都非负）：$|ac+bd|\le2$，即 $-2\le ac+bd\le2$；
3. 检查两端够不够得着：取 $(a,b)=(1,0)$、$(c,d)=(2,0)$，得 $ac+bd=2$，且 $ad=0=bc$ ✓；把 $(c,d)$ 换成 $(-2,0)$ 则得 $-2$ ✓；
4. 结论：取值范围是 $[-2,\ 2]$，两端都取得到。

> 开方这一步必须走**绝对值**：$(ac+bd)^2\le4$ 说的是 $|ac+bd|\le2$，不是 $ac+bd\le2$。$ac+bd$ 完全可以是负的（把 $c,d$ 一起变号即可）。

**例 2（求最值）**：已知 $x^2+y^2=25$，求 $3x+4y$ 的最大值。

1. 认出"两组平方和"：把 $3x+4y$ 写成 $x\cdot3+y\cdot4$，取 $(a,b)=(x,y)$、$(c,d)=(3,4)$；
2. 代柯西：$(x^2+y^2)(3^2+4^2)\ge(3x+4y)^2$，即 $25\times25\ge(3x+4y)^2$；
3. 开方：$|3x+4y|\le25$，于是 $3x+4y\le25$；
4. 查取等：$ad=bc$ 即 $x\cdot4=y\cdot3$，也就是 $4x=3y$；与 $x^2+y^2=25$ 联立，$(x,y)=(3,4)$ 满足（$9+16=25$ ✓，$4\times3=3\times4$ ✓）；
5. 结论：最大值是 $25$，在 $(x,y)=(3,4)$ 取得。

验算另一个圆上点：$(0,5)$ 给 $3\times0+4\times5=20<25$ ✓。

**例 3（证明分式不等式）**：设 $a>0,\ b>0$，证明 $(a+b)\Big(\dfrac1a+\dfrac1b\Big)\ge4$。

1. 把左边摆成"两组平方和"的样子：取第一对 $(\sqrt a,\ \sqrt b)$、第二对 $\Big(\dfrac1{\sqrt a},\ \dfrac1{\sqrt b}\Big)$；
2. 代柯西：

$$\Big((\sqrt a)^2+(\sqrt b)^2\Big)\Big(\frac1{(\sqrt a)^2}+\frac1{(\sqrt b)^2}\Big)\ \ge\ \Big(\sqrt a\cdot\frac1{\sqrt a}+\sqrt b\cdot\frac1{\sqrt b}\Big)^2$$

3. 化简：左边正是 $(a+b)\Big(\dfrac1a+\dfrac1b\Big)$，右边是 $(1+1)^2=4$；
4. 取等：$ad=bc$ 即 $\sqrt a\cdot\dfrac1{\sqrt b}=\sqrt b\cdot\dfrac1{\sqrt a}$，交叉相乘得 $a=b$。

一句话记住：**$a^2+b^2$ 与 $ac+bd$ 同时出现，就往柯西上想**。

两个挑战：

1. 打开"极值"开关，看它标出的极大值是不是 $25\ @\ 3$；
2. 把式子改成 `3*x - 4*sqrt(25 - x^2)`（改走下半圈），峰挪到最右端 $x=5$（高 $15$）、谷出现在 $x=-3$（低 $-25$）——$|3x+4y|\le25$ 这个范围的下端，正是在这条曲线上取到的。

### 实验 2（Python）：把"大了一个平方"验上 256 遍

```python title="穷举 1~4 的所有四元组，差额恒等于 (ad − bc)²"
min_diff = None          # 见到的最小差额，先留空
zero_cases = 0           # 取等（差额为 0）的组数
total = 0                # 一共验了多少组
identity_ok = True       # 先假设「差额 = (ad−bc)²」成立，见到反例就翻成 False

for a in range(1, 5):                    # range(1, 5) 依次给出 1, 2, 3, 4
    for b in range(1, 5):
        for c in range(1, 5):
            for d in range(1, 5):
                diff = (a*a + b*b) * (c*c + d*d) - (a*c + b*d) ** 2
                if diff < 0:             # 柯西若成立，这一行永远不会执行
                    print("发现反例:", a, b, c, d)
                if diff != (a*d - b*c) ** 2:
                    identity_ok = False
                total = total + 1        # 累加器：旧值加 1 再存回去
                if diff == 0:
                    zero_cases = zero_cases + 1
                if min_diff is None or diff < min_diff:
                    min_diff = diff

print(f"验了 {total} 组，最小差额: {min_diff}")
print(f"取等（差额为 0）的组数: {zero_cases}")
print(f"差额恒等于 (ad−bc)² 吗: {identity_ok}")
```

三行输出：`验了 256 组，最小差额: 0`、`取等（差额为 0）的组数: 32`、`差额恒等于 (ad−bc)² 吗: True`。一次反例都没出现——$256$ 组里差额最小是 $0$，从没见过负数。

### 实验 3（Python 滑块）：自己填四个数

```python title="滑块实验：左边 − 右边 = (ad − bc)²"
# sliders: a=1 [-4:4:1], b=2 [-4:4:1], c=2 [-4:4:1], d=1 [-4:4:1]
left = (a*a + b*b) * (c*c + d*d)     # 柯西的左边
right = (a*c + b*d) ** 2             # 柯西的右边
gap = left - right                   # 差额

print(f"左 {left}, 右 {right}, 差额 {gap}")
print(f"(ad − bc)² = {(a*d - b*c) ** 2}")
print(f"相等吗: {gap == (a*d - b*c) ** 2}")
print(f"柯西成立吗（左 ≥ 右）: {left >= right}")
```

默认 $a=1,\ b=2,\ c=2,\ d=1$：左 $=(1+4)\times(4+1)=25$，右 $=(2+2)^2=16$，差额 $9$，而 $(ad-bc)^2=(1-4)^2=9$——对上了。把 $d$ 拖到 $4$：$ad=4$、$bc=4$，差额归 $0$，取等发生；再拖过 $4$，差额又变正，但**永远不会是负的**。

::::warning[常见误区]

**误区一**："你以为柯西不等式只对正数成立。"
其实 $a,b,c,d$ 可以是**任意实数**——差额是 $(ad-bc)^2$，平方对负数照样非负。真正要小心的是**开方那一步**：$(ac+bd)^2\le M$ 推出的是 $|ac+bd|\le\sqrt M$，即 $-\sqrt M\le ac+bd\le\sqrt M$；直接写成 $ac+bd\le\sqrt M$ 就漏掉了整个负半边，最小值也就说不出来了。

**误区二**："你以为取等是两对数字分别相等。"
取等条件是 $ad=bc$（两对**成比例**）。$(1,2)$ 与 $(2,4)$ 取等，$(1,2)$ 与 $(2,1)$ 不取等——后者 $ad=1$、$bc=4$，差着 $3$。用"数字一不一样"来判断取等，是这类题最常见的失分点。

**误区三**："你以为两边展开后就能直接比大小。"
$a^2c^2+a^2d^2+b^2c^2+b^2d^2$ 与 $a^2c^2+2abcd+b^2d^2$，光盯着这两堆看不出谁大（$abcd$ 完全可能是负的）。**必须把差凑成 $(ad-bc)^2$**，非负性才会现形。这一步叫配方，第 50 课推求根公式时你已经做过一次了。

::::

**练习 3**（思考）：已知 $0<x<1$，求 $\dfrac1x+\dfrac4{1-x}$ 的最小值。提示：柯西还有一个**分式形式** $\dfrac{p^2}{u}+\dfrac{q^2}{v}\ge\dfrac{(p+q)^2}{u+v}$（$u,v>0$），它本身就是柯西——取第一对 $\big(\frac p{\sqrt u},\frac q{\sqrt v}\big)$、第二对 $(\sqrt u,\sqrt v)$ 就能推出。

<details>
<summary>点开查看逐步解答</summary>

**先证分式形式**：取 $(a,b)=\big(\frac p{\sqrt u},\ \frac q{\sqrt v}\big)$、$(c,d)=(\sqrt u,\ \sqrt v)$，代柯西：

$$\Big(\frac{p^2}{u}+\frac{q^2}{v}\Big)(u+v)\ \ge\ \Big(\frac p{\sqrt u}\cdot\sqrt u+\frac q{\sqrt v}\cdot\sqrt v\Big)^2=(p+q)^2$$

两边除以 $u+v>0$ 即得。

**用它解题**：$\dfrac1x+\dfrac4{1-x}=\dfrac{1^2}{x}+\dfrac{2^2}{1-x}\ \ge\ \dfrac{(1+2)^2}{x+(1-x)}=\dfrac91=9$。

**查取等**：由上面的推导，取等条件是 $\dfrac p{\sqrt u}\cdot\sqrt v=\dfrac q{\sqrt v}\cdot\sqrt u$，化简成 $\dfrac pu=\dfrac qv$。这里即 $\dfrac1x=\dfrac2{1-x}$，交叉相乘得 $1-x=2x$，$x=\dfrac13$（在 $(0,1)$ 内 ✓）。

**验算**：$x=\dfrac13$ 时 $\dfrac1x+\dfrac4{1-x}=3+\dfrac4{2/3}=3+6=9$ ✓。

**最小值是 9，在 $x=\frac13$ 处取得。**

</details>

## 7. 选读与边界

<details>
<summary>选读 · 柯西的大家族</summary>

**与基本不等式的亲戚关系**：柯西的差额 $(ad-bc)^2\ge0$，其实用第 57 课的基本不等式也能直接看出来。要比较的是 $a^2d^2+b^2c^2$ 与 $2abcd$，而

$$a^2d^2\cdot b^2c^2=(abcd)^2$$

——这两块的**积**开方后正好是 $|abcd|$。开方的结果已经知道了，和就有下界：由 $\sqrt{XY}\le\dfrac{X+Y}{2}$ 取 $X=a^2d^2$、$Y=b^2c^2$：

$$a^2d^2+b^2c^2\ \ge\ 2\sqrt{a^2b^2c^2d^2}=2|abcd|\ \ge\ 2abcd$$

取等在 $a^2d^2=b^2c^2$ 且 $abcd\ge0$，合起来正是 $ad=bc$。两条路殊途同归。

**n 元形式**：把"两对"换成"两列各 $n$ 个"，形状一模一样：

$$(a_1^2+\cdots+a_n^2)(b_1^2+\cdots+b_n^2)\ \ge\ (a_1b_1+\cdots+a_nb_n)^2$$

证法照旧（展开、相减、凑成 $\sum_{i<j}(a_ib_j-a_jb_i)^2\ge0$），取等在两列数成比例。

**积分形式**：把求和换成积分，$\displaystyle\int f^2\cdot\int g^2\ \ge\ \Big(\int fg\Big)^2$——第 14 章算面积时会再见到它。

**本课不管什么**：只讲**二维**（两对、四个数）的形式与三种用法（求范围、求最值、分式形式）。$n$ 元形式与积分形式只作介绍、不作要求。把柯西翻译成**向量内积**的语言（$\vec u\cdot\vec v\le|\vec u|\,|\vec v|$）要等第 11 章有了向量才讲——本课刻意绕开了它，因为配方法已经够用，且不依赖任何还没学过的概念。

</details>
