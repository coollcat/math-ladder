# 合并同类项与展开

## 1. 从一个场景开始

超市小票不会这样打："酸奶3瓶、面包2个、酸奶5瓶、面包退1个"——它一定先归类再合计：酸奶共 8 瓶、面包共 1 个。归类前后，钱一分不差，账目却清爽百倍。

代数式 $3x+2y+5x-y$ 就是那张没归类的原始小票。整理成 $8x+y$ 后数值不变、一眼见底。这一课的两把刷子——**合并同类项**与**展开（去括号）**——其实是同一位老朋友的两副面孔：第 1 章乘法与分配律一课的 $a(b+c)=ab+ac$。

## 2. 直觉解释

**合并靠分类。** $3x$ 和 $5x$ 是同一类货——都是"$x$ 这种水果"，份数可以相加得 $8x$；而 $3x$ 和 $2x^2$ 是苹果和西瓜，合不到一起。

**展开靠拆包。** $3(x+2)$ 的意思是"礼包里有 $x$ 和 $2$ 两样东西，这样的礼包发 3 份"。收货的人实际拿到：$3x$ 和 $3\times2=6$——乘数要分发给括号里的**每一项**。

几何版一眼看懂：宽 $(x+2)$、高 3 的长方形，整体面积是 $3(x+2)$；切成左右两块看，是 $3x$ 加 $3\times2$——两种算法必然相等：

$$\underbrace{x}_{3x} + \underbrace{2}_{6}\;\bigg\rbrace \; 3$$

## 3. 正式定义

**项**：代数式中用加减号隔开的每一段（连符号一起算）。如 $3x-5y+2$ 有三项：$3x$、$-5y$、$+2$。

**同类项**：字母部分完全相同（字母一样、指数也一样）的项；所有不含字母的常数互为同类项。

| 法则 | 公式 | 本质 |
| --- | --- | --- |
| 合并同类项 | $ax+bx=(a+b)x$ | 分配律反着用 |
| 展开 | $a(x+y)=ax+ay$ | 分配律正着用 |
| 负号进括号 | $-(x-y)=-x+y$ | 用 $(-1)$ 去乘每一项 |

## 4. 分步例题

**例 1**：合并 $5x+2y-3x+y$。

1. 找同类：$5x$ 与 $-3x$ 一类；$2y$ 与 $y$ 一类
2. 系数相加：$(5-3)x+(2+1)y$
3. 写结果：$2x+3y$

**例 2**：展开 $-2(3x-4)$。

1. 把 $-2$ 分发给每一项：$(-2)\cdot3x$ 与 $(-2)\cdot(-4)$
2. 定符号（负负得正，第 2 章 05 号课的老规矩）：$-6x$ 与 $+8$
3. 写结果：$-6x+8$

每步只做一件事，符号单独核对一遍——展开题的错九成错在符号上。

### 实验 2：一万次抽查

```python title="随机抽查：(2x+3)+(5x-1) == 7x + 2 吗"
import random   # 随机数库，第 0 章介绍过

ok_count = 0
for trial in range(10000):
    x = random.randint(-9, 9)   # randint：取随机整数。别用小数抽查——两条求值路径的浮点尾差会让 == 偶尔失手
    if (2*x + 3) + (5*x - 1) == 7*x + 2:
        ok_count = ok_count + 1

print(f"10000 组随机数中成立 {ok_count} 次")
```

### 实验 3：滑块逐点对比

```python title="滑块实验：整理前 vs 整理后"
# sliders: x=-2 [-5:5:0.5]
before = (2*x + 3) + (5*x - 1)
after = 7*x + 2
print(f"x={x} 时：整理前 {before} | 整理后 {after}")
print("两者相等吗:", before == after)   # 比较运算返回 True/False
```

拖动 $x$ 扫过整个区间，最后一行始终打印 True。

:::warning[常见误区]

**误区一**："$3(x+2)=3x+2$。"
乘数要分发给括号里的每一项：$3(x+2)=3x+6$。只发第一项等于让第二项白排队。

**误区二**："负号只是个记号，不用管它。"
负号进括号要分发：$-(x-3)=-x+3$。它是隐藏的 $-1$，也要乘每一项。

**误区三**："字母一样就能合并。"
$3x$ 与 $2x^2$ 不能合成一个项——字母部分必须**完全相同**（含指数）才叫同类。同理 $x+y$ 也永远合不成一项。

:::

## 6. 练习

**练习 1**：合并 $(2x+3)+(5x-1)$ 后，$x$ 的系数和常数项分别是多少？分别打印出来。下面的代码能跑但把两类搅在一起算了：

```exercise

# @check: 7
# @check: 2
# @hint: 打印两行——x 的系数只归 x（2+5），常数项只归常数（3 减 1）
print(2+5-1)
```

**练习 2**：合并 $4a-2b-a+5b$。

<details>
<summary>点开查看逐步解答</summary>

$a$ 类：$4a-a=(4-1)a=3a$；$b$ 类：$-2b+5b=3b$。结果 $3a+3b$。

```python
for a, b in [(1, 2), (-3, 0.5), (10, 10)]:
    left = 4*a - 2*b - a + 5*b
    right = 3*a + 3*b
    print(left == right)   # 三组都 True
```
</details>

**练习 3**：展开并化简 $-3(2x-5)+4x$。

<details>
<summary>点开查看逐步解答</summary>

第一步展开：$-3(2x-5)=-6x+15$（注意 $(-3)\times(-5)=+15$）；第二步合并：$-6x+4x=-2x$。结果 $-2x+15$。
</details>

## 7. 选读：为什么只有同类项能合并？

<details>
<summary>选读 · 一个反证</summary>

假设允许异类合并，比如规定 $x+x^2$ 可以合成 $kx^2$（某个系数 $k$）。取 $x=1$：左边 $1+1=2$，右边 $k$，得 $k=2$。再取 $x=2$：左边 $2+4=6$，右边 $4k$，得 $k=\frac{3}{2}$。两次要求矛盾——所以这样的规则根本写不出自洽的定义。

而同类项合并不需要任何新约定：$ax+bx=(a+b)x$ 对每个 $x$ 都成立，因为它就是分配律的改写。**能合并的根源不是"长得像"，而是背后有分配律撑腰。**

</details>
