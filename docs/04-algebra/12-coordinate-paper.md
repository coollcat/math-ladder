# 坐标纸速成：数对与图像

## 1. 从一个场景开始

护士站有一张体温记录单，每两小时测一次：

| 时刻 | 8 点 | 12 点 | 16 点 | 20 点 |
| --- | --- | --- | --- | --- |
| 体温（°C） | 36.7 | 37.4 | 38.2 | 37.0 |

数字排成两行，看半天也说不清病情走势。值班医生拿到表格只做了一件事：在方格纸上把每组数字钉成一个点，再把点连起来——体温的起伏立刻现了形：中午起烧、傍晚到顶、夜里退烧。

这张方格纸就是本课的主角。它能把"两行数字"翻译成"一幅走势图"，也是将来一切函数图像的出生地。

## 2. 直觉解释

一个数钉不住平面上的位置。想象有人喊"横着走 3 格"——所有人走到同一列，站成一条竖线，人满为患；再补一句"竖着走 2 格"，每人落在唯一的格子里。

所以平面上定位要**两个数**：第一个管横着走多远（右正左负），第二个管竖着走多远（上正下负）。写成数对 $(9,\ 12)$ 的意思就是："横 9、纵 12"。体温单的每一组读数，都是这样一个数对：时刻管横、度数管纵。

约定只有一条，却万年不变：**先横后纵**。$(9,\ 12)$ 和 $(12,\ 9)$ 是两个不同的位置——顺序就是门牌，念反了就进错屋。

把每个数对按位置钉在方格纸上，再用线段依次连起来，表格就升级成了**折线图**。线的每一次爬升、每一个拐弯，都是数字关系的一幅肖像。

## 3. 正式定义

本课是速成班：只取"够用就走"的三件套，完整版（四象限、距离公式）留给第 5 章。

| 名称 | 含义 | 备注 |
| --- | --- | --- |
| 数对 $(a,\ b)$ | 有序的两个数 | $a$ 叫**横坐标**，$b$ 叫**纵坐标**；顺序不可交换 |
| 横轴与纵轴 | 方格纸底部与左侧的两条基准线 | 横轴上的数管左右，纵轴上的数管上下；交点是 $(0,\ 0)$ |
| 描点 | 数对 → 纸上的一个点 | 从原点出发，先横走 $a$ 格，再纵走 $b$ 格 |
| 折线图 | 相邻的点用线段依次相连 | 展示"一个量跟着另一个量怎么变" |

一句话总纲：**数对管定位，折线管走势**。

## 4. 分步例题

**例**：把体温单的前三次读数画成折线图。

1. 认数对：$(8,\ 36.7)$、$(12,\ 37.4)$、$(16,\ 38.2)$——每组都是"（时刻，体温）"；
2. 描第一个点：从原点横走 8 格，再纵走 36.7 格，钉下点 $A$；
3. 描其余各点：同法钉下 $(12,\ 37.4)$、$(16,\ 38.2)$；
4. 连线：$A\to B\to C$ 用线段依次相连；
5. 读图：线段一路爬坡，且 $B\to C$ 段更陡——午后升温在加速。

第 5 步就是折线图的威力：这层"升温在加速"的意思藏在数字堆里很难一眼看出，画到纸上却谁都能读。

## 5. 动手实验

### 实验 1（viz）：先横后纵，钉一个点

```viz
{
  "type": "coordplane",
  "title": "拖动点 P：横坐标管左右，纵坐标管上下",
  "range": 5
}
```

抓住蓝点在方格纸上拖动，左上角实时报出它的数对。三个挑战：

1. 把点拖到 $(3,\ 2)$，再拖到 $(2,\ 3)$——两个位置毫无瓜葛，这就是"有序"二字的分量；
2. 把横坐标拖成负数——横负在左，负数不只是数轴上的事；
3. 组件顺嘴报的"象限"和"到原点的距离"，是第 5 章坐标系的正菜，今天只取"先横后纵"这一勺。

### 实验 2（python）：把体温单钉成折线图

```python title="四组读数，一张走势图"
import matplotlib.pyplot as plt   # 画图库，第 0 章介绍过

xs = [8, 12, 16, 20]              # 横坐标列表：四次测量的时刻
ys = [36.7, 37.4, 38.2, 37.0]     # 纵坐标列表：与时刻一一对应的体温

plt.plot(xs, ys, marker="o")      # plot 画折线；marker="o" 让每个数据点额外画个圆圈
plt.axhline(0, color="gray")      # axhline：画一条水平参考线（这里是横轴）
plt.axvline(0, color="gray")      # axvline：竖直参考线（纵轴）
plt.grid(True)                    # grid：打开方格纸网格，方便逐格对位置
plt.show()                        # 出图
```

四个圆点被折线串起，白天的起伏一眼读完。改一改 `ys` 里的数字再跑一遍，看线怎么跟着变形——数据动，图跟着动，这就是"图像是数据的肖像"。

### 实验 3（python 滑块）：横竖滑块，亲手钉点

```python title="滑块实验：先横后纵"
# sliders: hx=3 [-5:5:1], vy=-2 [-5:5:1]
import matplotlib.pyplot as plt   # 画图库，第 0 章介绍过

print(f"数对 ({hx}, {vy})")       # f-string：把变量值嵌进文字里（第 0 章的约定）

plt.axhline(0, color="gray")      # 横轴
plt.axvline(0, color="gray")      # 纵轴
plt.grid(True)                    # 方格纸网格
plt.scatter([hx], [vy], s=140, color="tomato")   # scatter 画单个点：先给横坐标，再给纵坐标
plt.show()
```

拖动滑块 `hx` 和 `vy`，红点随之搬家。观察打印行：**永远先报 `hx` 再报 `vy`**——这就是"先横后纵"在代码里的样子。

### 快问快答

```quiz
数对 (2, 5) 和 (5, 2) 钉出来是同一个点吗？
- 是，两个数一样只是顺序不同
- 不是，先横后纵的顺序反了位置就变了 [*]
- 取决于方格纸的大小
? 数对是有序的：第一位管横、第二位管纵。(2, 5) 先横 2 再纵 5，(5, 2) 先横 5 再纵 2——两步都换了方向，落点自然不同。
```

::::warning[常见误区]

**误区一**："你以为 $(2,\ 5)$ 和 $(5,\ 2)$ 差不多。" 数对的顺序就是门牌：第一位横、第二位纵，互换等于把"8 点 36.7 度"记成"36.7 点 8 度"——账全乱了。先横后纵是全球统一规则。

**误区二**："你以为表格本身就是图。" 两行数字只能逐个查，走势全靠脑补；钉成折线后，趋势自己走到你眼前。表格是原材料，图才是肖像。

**误区三**："你以为折线上的每一段都是真实数据。" 线段只是把相邻两个实测点连起来的"助读桥"：8 点和 12 点**之间**体温到底怎么走，表格没说，折线也没说——它画的是趋势的示意，不是逐分钟的实况。

::::

## 6. 练习

**练习 1**：记录单上第三组读数是"20 点，37.0 度"。下面的代码能跑，但第二行打印的温度不对——查查哪个变量被填错了：

```exercise
# @title: 练习：把读数装进数对
# @check: 36.7
# @check: 37.0
# @hint: 数对约定是（时刻，体温）。第三行的两个变量——时刻和体温，是不是被填串了？
h1 = 8      # 第一组：时刻（横）
t1 = 36.7   # 第一组：体温（纵）

h3 = 20     # 第三组：时刻（横）
t3 = 20.0   # ← 第三组：体温（纵）。这个数对念得通吗？
print(t1)
print(t3)
```

跑通后再想一层：`t3 = 20.0` 单独看没有任何毛病——20 是个完全合法的数。错不在数，在**数对的位置**：它坐进了纵坐标的座位，含义就全变了。

**练习 2**：把实验 2 的体温单改成下面这张，重画折线并回答：体温从几点开始下降？

| 时刻 | 8 | 12 | 16 | 20 |
| --- | --- | --- | --- | --- |
| 体温 | 36.5 | 37.8 | 38.6 | 37.2 |

<details>
<summary>点开查看逐步解答</summary>

```python
import matplotlib.pyplot as plt   # 画图库
```

**练习 3**（思考）：折线图里 $A(8,\ 36.7)$ 到 $B(12,\ 37.4)$ 这一段，横坐标每前进 1 格，纵坐标大约爬多少？

<details>
<summary>点开查看逐步解答</summary>

横走 $12-8=4$ 格，纵爬 $37.4-36.7=0.7$ 度，平均每格爬 $0.7\div4=0.175$ 度。"横走一纵爬几"这个比值，衡量线段的陡峭程度——它就是将来一次函数里"斜率"的雏形，第 6 章函数课会给它正式编制。
</details>

## 7. 选读：为什么横轴坐"输入"的座位？

<details>
<summary>选读 · 先横后纵背后的分工</summary>

体温单里，时刻是**你说了算**的那个量（几点测就几点测），体温是**跟着变**的量（测出来是多少是多少）。画图时把"说了算"的放横轴、"跟着变"的放纵轴，这个分工让图像从左往右读起来正好是"输入 → 输出"的过程——和读书的顺序一致。

下一课起我们会大量处理"含字母的式子"：给 $x$ 一个值，式子吐出一个值——$x$ 是说了算的输入，式子值是跟着变的输出。到第 6 章函数课，"输入 → 输出"的每一对数都会被钉成点，千千万万个点连成曲线，**函数图像**就此诞生。本课的折线图正是它的前身：数据版画的是已测量的有限个点，函数版画的是所有可能取值连成的整条线。

先横后纵不是随便的规定：它让"横轴 = 输入"从第一张图起就刻进习惯，往后学函数时一个字都不用改。

</details>
