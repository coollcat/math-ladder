# 二元一次方程组与消元

## 1. 从一个场景开始

文具店收银机吐出两张小票：

- 第一张：**3 支笔和 2 本本子，共 19 元**；
- 第二张：**1 支笔和 1 本本子，共 7 元**。

每支笔、每本本子的单价各是多少？

上一课的天平只挂一个口袋，一个方程就能收拾。可这次天平上挂着**两样东西**：单看一张小票，$3x+2y=19$ 里藏着一对未知的组合——笔价上浮一元、本价就得跟着挪，怎么凑都行。单独一个方程锁不死答案。

可两张小票**并在一起看**，自由度瞬间被钉死。这中间的机关叫什么？——联立，消元。

## 2. 直觉解释

先暴力试探：假定笔价从 1 元开始往上爬，用第二张小票搭桥——"笔加本子一共 7 元"，于是每报一个笔价，本子价立刻被逼出来；再拿第一张小票验收总分对不对。

| 笔 $x$ | 本子 $y=7-x$（第二张票） | 验收第一张票 $3x+2y$ |
| --- | --- | --- |
| 3 | 4 | $9+8=17$ ✗ 偏少 |
| 4 | 3 | $12+6=18$ ✗ 还差一点 |
| **5** | **2** | $15+4=19$ ✓ 中了！ |

从头到尾只有一组 $(5,2)$ 同时喂饱两张小票。

画到坐标系里更妙：每个一次方程都是一条直线，$(5,2)$ 这一点**同时坐在两条直线上**——它就是交点。"解方程组"就是问：这两条线在哪里相逢？

那有没有不动笔的机器解法？有——既然 $y=7-x$ 已经把本子和笔绑在一起，就把它**整个塞进**另一条等式里换掉 $y$，只剩一个未知数的方程信手拈来。这一招叫**代入消元**，另一个变体叫**加减消元**，下文都练。

## 3. 正式定义

**二元一次方程组**：两个一次方程并列成组，共同使用两个未知数。一般形状：

$$a_1 x + b_1 y = c_1, \qquad a_2 x + b_2 y = c_2$$

| 符号/术语 | 含义 |
| --- | --- |
| $(x, y)$ | 一组**解**：未知数的一套取值 |
| 解集 | 所有解的集合；二直线的位置关系决定它是 1 组、0 组还是无穷多组 |
| 消元 | 通过变形让某个未知数整列消失，把二元问题压回熟悉的一元问题 |
| 回代 | 把已求出的一个未知数送回原方程，顺手取回另一个 |

消元的合法性全靠第 30 课的天平规则撑腰：

1. 两边同加减同一个数 → 等式不变；
2. 两边同乘同一个非零数 → 等式不变。

只要每一步都守规矩，新写下的等式与旧的是**同一条真理**——所以把两个方程相加相减、或者整体放大缩小，解集纹丝不动。这就是消元敢"减掉"一个未知数的底气。

## 4. 分步例题

**例**：文具店双票谜题——$3x + 2y = 19$ 且 $x + y = 7$，逐行走通"加减消元"。

1. **认目标**：两个未知数里，$y$ 在两式中系数分别是 $2$ 和 $1$——给它"配份"；
2. **放大**：把第二个方程两边同乘 2（天平规则 2），得 $2x + 2y = 14$；
3. **相减消元**：第一个方程减去它，左边 $3x-2x=x$、$2y-2y=0$——$y$ 整列蒸发！右边 $19 - 14 = 5$；
4. **收官**：剩下 $x = 5$。回代 $x+y=7$ 得 $y = 7 - 5 = 2$；
5. **验算**：$3\times5 + 2\times2 = 15 + 4 = 19$ ✓。验算一步不可省，它能当场抓住抄错符号的手滑。

答案：笔 5 元一支，本子 2 元一本。回头对比第 2 节的穷举表——直线思维绕一大圈才找到的交点，消元三步就走完了。

## 5. 动手实验

### 实验 1（viz）：消元实验室——看着直线一动不动

下面是本课的旗舰交互件。蓝橙两条直线各自代表一个方程，左上角的**增广矩阵**记录当前两个方程的系数账目。点「下一步消元」，系统按四步流程（归一 → 消去首项 → 回代）滚动演示：矩阵里的数字被你随意揉捏，但两条直线**在图上一毫米都不挪**——所有合法操作都在"保持解集"，紫色圆点始终钉在交点上。

```viz
{
  "type": "elimination",
  "matrix": [2, 1, 3, 4],
  "rhs": [7, 12]
}
```

怎么玩：拖动六个滑块改变四个系数和右端常数，先自己心算一下新的解，再点「下一步消元」逐步验证。两个彩蛋关卡：把系数拖成 `a=2, b=1, c=4, d=2`、`r1=7, r2=15`——左右翻倍对不上总账，画面会告诉你什么叫**无解**；再把 `r2` 改回 14，两条线重合成一条，**无穷多解**登场。三种结局（唯一 / 无 / 无穷多）全靠拖滑块亲手遇见。

### 实验 2（python）：鸡兔同笼，两重循环硬搜

经典名题：笼子里鸡兔共 35 个头、94 只脚。两只未知数谁都不肯单独露面，就让计算机把所有组合全部试一遍：

```python title="鸡兔同笼：35 个头、94 只脚"
heads = 35                    # 头的总数
legs = 94                     # 脚的总数

for chickens in range(heads + 1):        # 外层循环：鸡的数量从 0 到 35 全部试一遍
    for rabbits in range(heads + 1):     # 内层循环：兔的数量同样枚举——嵌套后共试 36×36 种组合
        if chickens + rabbits == heads and 2 * chickens + 4 * rabbits == legs:
            # and 连接两个条件：头数对 AND 脚数对，两者必须同时成立才算命中
            print("鸡", chickens, "只, 兔", rabbits, "只")
```

只有一行输出：`鸡 23 只, 兔 12 只`。数一数:$23+12=35$ 个头、$23\times2+12\times4=94$ 只脚——两组约束全中。**嵌套的两重 for 正是"两道约束都要满足"的代码化身**；而人工消元做的，是把上千次试探压缩成三步算术。

### 实验 3（python）：把方程组画出来

文具店双票问题的两条直线长什么样？各自移项解出 $y$，再请 matplotlib 上场：

```python title="两条直线的交点就是解"
import matplotlib.pyplot as plt      # 绘图工具箱，第 0 课引入过

xs = []                              # 收集横坐标：0 到 7 的整数
for v in range(8):
    xs.append(v)

ys1 = []
ys2 = []
for x in xs:
    ys1.append((19 - 3 * x) / 2)     # 第一个方程移项：y = (19 − 3x) ÷ 2
    ys2.append(7 - x)                # 第二个方程移项：y = 7 − x

fig, ax = plt.subplots(figsize=(6, 4))           # 新建画布；figsize 定图的宽高（英寸）
ax.plot(xs, ys1, marker="o", label="3x + 2y = 19")   # marker="o"：每个点画圆圈；label 写入图例
ax.plot(xs, ys2, marker="s", label="x + y = 7")      # marker="s"：方块标记区分第二条线
ax.scatter([5], [2], s=130, color="crimson", label="(5, 2)")   # scatter 专门画散点，标出交点
ax.legend()                          # legend：调出图例盒子
```

图中红线与橙线恰好在 $(5,2)$ 十字相会——消元求出的解，正是几何上的交点坐标。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为从一个方程里算出点什么就算解题了。" 其实解的定义是**同时满足所有方程**的那组值。单方程得来的任何结论都只是半成品，必须送回另外几个方程复检。

**误区二**："你以为两个方程打架就是题目印错了。" 其实"无解"是正经结果之一：两条平行线的存在是现实的常态（比如预算矛盾）。看到"荒谬式"如 $0 = 2$ 时不要慌，它在正大光明地宣布：此题无解。

**误区三**："你以为先消哪个未知数、先把哪个方程乘几倍会影响结果。" 其实顺序只是记账路径不同——保持解集的操作无论怎么排队，终点都停在同一组解上。选最好算的那条路即可。

:::

## 7. 练习

**练习 1（判题）**：动物园售票处。成人票 $a$ 元一位，儿童票 $b$ 元一位：张家 **2 大 3 小** 共付 60 元，李家 **1 大 2 小** 共付 34 元。求两种票价。下面的初稿思路完全跑偏——有人把张家那张票据截成两段乱猜，改到三条检查全部通过：

```exercise
# @title: 练习：两张家门票据锁死两种票价
# @check: 18
# @check: 8
# @check: 60
# @hint: 别把单个方程当独木桥：从李家票据 a + 2b = 34 移项出 a = 34 − 2b，把这整个表达式代进张家票据 2a + 3b = 60，就只剩 b 一个未知数了。求出 b 再回代取 a，最后用 2a + 3b 打印回代验证。
a = 30                  # ← 出发点就歪了：把"2a = 60"单独拆出来解，问过 b 的感受吗？
b = 60 - a              # ← 这个 60 凭什么是 b 的总账？拍脑袋不可取
print(a)
print(b)

receipt = 2 * a + 3 * b    # 验收：张家票据的总账必须是 60
print(receipt)
```

<details>
<summary>点开查看逐步解答</summary>

**(1) 代入消元路线**：李家票据给出 $a = 34 - 2b$。把它整个送进张家票据：

$$2(34 - 2b) + 3b = 60 \;\Longrightarrow\; 68 - 4b + 3b = 60 \;\Longrightarrow\; b = 8$$

**(2) 回代取回**：$a = 34 - 2\times8 = 18$。

**(3) 验收**：$2\times18 + 3\times8 = 36 + 24 = 60$ ✓。

成人票 **18 元**，儿童票 **8 元**。顺带做个体感检查：大人小孩单人差价 10 元，两家人的人口结构也配得上这个总价。

修正后的参考代码：

```python
# 李家票据先变形：a = 34 - 2b，整个代进张家票据
b = 8                  # 由 2(34 - 2b) + 3b = 60 化简得 68 - b = 60，解出儿童票 8 元
a = 34 - 2 * b         # 回代：成人票价
print(a)
print(b)

receipt = 2 * a + 3 * b    # 验收张家总账
print(receipt)
```

回头再看实验 2 的鸡兔同笼：把鸡设为 $c$、兔为 $r$，就是 $c + r = 35$ 与 $2c + 4r = 94$ ——同一个结构、同一门手艺。
</details>

**练习 3**：概念辨析：某同学声称"$(x,y)=(5,2)$ 是方程组的解，因为 $3\times5+2\times2=19$ 成立"。这个说法缺了什么？

<details>
<summary>点开查看逐步解答</summary>

缺**另一半验收**：他只对了第一张小票，还得确认第二个方程 $x + y = 7$ 也成立——好在本例 $5+2=7$ ✓，所以才真的算解。反之若有个同学猜到 $(5,2)$ 能喂饱第二张票就欢呼，同样是错的。判定的完整标准：**每一个方程都要过关，一个都不能少**。这道练习没有复杂计算，考的就是"联立"二字的分量。
</details>

## 8. 选读与边界

### 选读 · 消元为什么从不冤枉好人

每一次合法操作都是"单向透明"的：由方程变形得到的新方程，其解必然仍是原方程的解（操作性）；反过来，像"两边同乘非零数"这类步骤可以逆推回去，原方程的每个解也不会在变形途中丢失（可逆性）。先**增补信息不删减、再收缩证据链不假造**，两头堵死后，新旧方程组的解集必然一模一样。

把这套动作排成整齐的流水线——归一化首行、乘倍消首项、回代清零——就是未来第 21 章**高斯消元**的全部灵魂，只是那里换成任意多行，而这节课你已经徒手演完了它的二元彩排。

### 本课不管什么

- 只管**一次**关系：出现平方、绝对值或者两个未知数相乘，直线变曲线，本课工具需升级后才接得住；
- 三元以上要连环消元多次，工程做法留给线性代数；此处只管亲手上阵的默契；
- "约束是不等号"的场景不是本课地盘——不等式的世界下一课开场，最优分配则要等到第 43 章线性规划。
