# 一元一次方程

## 1. 从一个场景开始

"我心里想了一个数，乘 2 再加 3，得到 11——猜猜它是几？"

你几乎不假思索就能报出答案。但请注意：你刚才做的不是计算，是**倒着推理**——从结果反推输入。把这场猜数游戏写在纸上：

$$2x+3=11$$

这就是**方程**。它不是新运算，而是一个问题："$x$ 是谁的时候，这句话成立？"

## 2. 直觉解释

**天平图像**：等号是天平的支点，两边各放一堆砝码。想弄清左边那堆里 $x$ 有多重，你可以随便动天平——只要**两边同时**拿掉或加上同样的重量，平衡就不破。

还有一个更酷的视角（本课的主打）：把左边看成一个"高度记录仪" $f(x)=2x+3$，每喂一个 $x$ 它吐出一个高度。解方程 $2x+3=11$ 等价于问：这条直线**什么时候到达指定高度**；移项成 $2x-8=0$ 后，问题变成——

> **这条直线什么时候穿过海平面（零点）？**

## 3. 正式定义

**方程**：含有未知数的等式。使等式成立的未知数的值叫**解**，求解的过程叫**解方程**。

等式两条基本性质（天平规则）：

1. 两边同加减任意一个数，等式不变；
2. 两边同乘同一个数、或同除以一个**非零**数，等式不变。

由性质 1 得到日常最常用的速记——**移项法则**：

$$\text{某项跨过等号} \Longrightarrow \text{符号要变号} \quad(+3 \to -3)$$

移项不是新魔法，它只是"两边同减 3"的记账简写。

## 4. 分步例题

**例**：解方程 $3x-5=7$。

1. 目标：让 $x$ 单独站一边
2. 移项：$-5$ 跨过等号变 $+5$，得 $3x=7+5=12$
3. 两边同除以 3：$x=4$
4. 验算：$3\times4-5=7$ ✓

验算一步千万别省——它能当场抓住移项时忘变号的错误。

Python 小贴士（后面练习会用到）：

```python title="/ 与 // 的区别"
print((11 - 3) / 2)    # 除法 /：结果总带小数形式（显示 4.0）
print((11 - 3) // 2)   # 整除 //：只留商的整数部分，得 4
```

### 实验 1：拖动 b，看零点滑动


曲线穿过横轴的位置就是方程 $2x+b=0$ 的解。三个挑战：

1. 拖 $b=-6$：零点在哪？（心算验证：$x=-b/2=3$）
2. 把 $b$ 从左往右扫一遍：零点朝哪个方向跑？
3. 找到 $b=0$：直线正好骑在横轴上，零点是原点。

### 实验 2：试数逼近——机器版猜数

不用任何技巧，纯靠试数也能围堵出解：先找一个函数值为负的点和一个为正的点，解必然夹在中间，然后不断取中点收缩包围圈。

```python title="二分逼近：十轮围堵出解"
lo = 0          # 左端点：此处函数值小于 0
hi = 10         # 右端点：此处函数值大于 0
for step in range(10):      # 循环固定 10 轮
    mid = (lo + hi) / 2     # 取中点（/ 会产生小数）
    value = 3*mid - 5 - 7   # 中点处“左边减右边”，即 3x-5-7
    if value < 0:
        lo = mid            # 解在中点右边，左端推进
    else:                   # else：上面的条件不成立时走这里
        hi = mid            # 解在中点左边或恰在中点，右端收缩

print(f"最后的中点 ≈ {mid}")       # 已经非常接近真实解
print(f"与真实解 4 的差距 ≈ {mid - 4}")
```

十轮就把解逼到百分之一以内——**试数逼近**是计算机解方程的原型思路。这套试数功夫你在第 3 章 √2 一课已经见过，后面数值分析的章节里它还会大量出场。

### 实验 3（viz）：解方程天平

第 2 节画过的天平现在真摆在桌上：初始方程 $3x+3=12$，每个按钮都对两边做同一件事，「第 N 步」日志逐步记账，目标是让左边只剩一个光秃秃的 $x$。

```viz
{
  "type": "balance",
  "xs": 3,
  "num": 3
}
```

两条路都通向 $x=3$：先「÷x 系数」化成 $x+1=4$ 再减 1；或者连按三次「两边−1」得 $3x=9$ 再除——对照第 4 节例题你会发现，天平的每一步正是移项与两边同除的实物版。

### 快问快答

```quiz
把 x + 5 = 12 中的 +5 移到等号右边，应该写成？
- x = 12 + 5
- x = 12 - 5 [*]
- x = 5 - 12
? 移项的本质是"两边同时减 5"，所以 +5 到了对面就变成 −5——跨过等号必须变号。
```

:::warning[常见误区]

**误区一**："移项就是把数字搬个位置。"
搬的本质是两边同做一件事，所以**必须变号**。$2x+3=11$ 移成 $2x=11+3$ 得到的是假解 14——天平早就翻了。

**误区二**："解出来就完事了。"
要养成验算的习惯：把解塞回原方程，True 才是真解。误区一的错误靠这一步必被抓住。

**误区三**："所有方程都恰好一个解。"
一次方程（$a\neq0$ 时）确实恰好一个解，但这不通用——下一课的不等式解出一片区域，再下一课的二次方程有两个解甚至没有实数解。

:::


**练习 2**：出租车费公式 $8+3n$ 元（上一章的老朋友）。小李付了 23 元，他坐了几公里？

<details>
<summary>点开查看逐步解答</summary>

列方程：$8+3n=23$。移项：$3n=15$；除以 3：$n=5$。

```python
n = (23 - 8) // 3   # 先移项再整除
print(n)            # 5
```

代回去验算：$8+3\times5=23$ ✓
</details>

**练习 3**：用实验 1 的滑块找规律：方程 $2x+b=0$ 的解用含 $b$ 的式子怎么表示？

<details>
<summary>点开查看逐步解答</summary>

移项：$2x=-b$；除以 2：$x=-\dfrac{b}{2}$。

验证：$b=-6$ 时 $x=3$ ✓；$b=8$ 时 $x=-4$，滑块拖到 8，零点确实在 $-4$。**规律先行、公式随后**——这正是本章反复出现的节奏。
</details>

## 7. 选读：为什么一次方程必有唯一解？

<details>
<summary>选读 · 存在性与唯一性</summary>

设 $ax+b=0$ 且 $a\neq0$。存在性：两边减 $b$、除以 $a$，显式造出解 $x=-b/a$——构造即证明。唯一性：若有 $x_1,x_2$ 都满足，则 $ax_1+b=ax_2+b$，两边减 $b$ 得 $ax_1=ax_2$；因 $a\neq0$ 可除，得 $x_1=x_2$。

注意条件 $a\neq0$：若 $a=0$，方程退化为 $b=0$——要么恒成立（无穷多解），要么永不成立（无解）。**条件不是装饰，去掉它结论就塌**。这种"存在且唯一"的句式，后续讲极限与证明的章节里它还会反复登场。

</details>
