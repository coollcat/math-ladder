# 基本不等式：几何平均不超过算术平均

## 1. 从一个场景开始

你有 24 米篱笆，要用它围出一块**长方形**菜地（四面都围，长和宽自己定）。三种围法摆在这儿：

| 长 × 宽 | 周长 | 面积 |
| --- | --- | --- |
| 8 × 4 | 24 | 32 |
| 7 × 5 | 24 | 35 |
| 6 × 6 | 24 | 36 |

周长一分未变，面积却从 32 涨到 36。规律像是在说"**两个数越匀，积越大**"——可这是为什么呢？36 是不是到顶了？换成 6.5 与 5.5（周长仍是 24）再试：$6.5\times5.5=35.75$，反而小了回去。

一条叫**基本不等式**的式子，一句话就能把这一类"什么时候最大、什么时候最小"的问题全部钉死。

## 2. 直觉解释

画一个半圆，让它的直径长度正好是 $a+b$，再用一个分点把直径切成 $a$ 和 $b$ 两段。从分点竖一根垂线，直抵半圆的弧上：

```
                 P
           , - ~ ~ ~ - ,
         /        |       \
      A ·----a----+---b-----· B
                  ↑
           半弦 = √(ab)          半径 = (a+b)/2
```

这根竖着的线段（半弦）有多长？恰好是 $\sqrt{ab}$；而半圆的**半径**是 $\dfrac{a+b}{2}$。

> 注：半弦 $=\sqrt{ab}$ 这一步（直角三角形斜边上的高，是两段射影的比例中项）要等第 5 章讲相似三角形时才补得上证明。这里先让这张图替我们把结论记住。

竖线段无论怎么画，都**竖不过半径**——它最长的时候，正是分点滑到圆心、也就是 $a=b$ 的那一刻：

$$\sqrt{ab}\;\le\;\frac{a+b}{2}$$

左边叫**几何平均**（相乘再开方），右边叫**算术平均**（相加折半）。一句话：**几何平均永远不超过算术平均**。

## 3. 正式定义

**基本不等式（二元形式）**：对任意 $a\ge0,\ b\ge0$，

$$\sqrt{ab}\;\le\;\frac{a+b}{2}$$

**取等当且仅当** $a=b$。

| 符号 | 名字 | 怎么算 | 例子（$a=2,\ b=8$） |
| --- | --- | --- | --- |
| $a,\ b$ | 两个**非负**的数 | 题目给定 | 2 和 8 |
| $\sqrt{ab}$ | 几何平均，记作 $G$ | 相乘再开方 | $\sqrt{16}=4$ |
| $\dfrac{a+b}{2}$ | 算术平均，记作 $A$ | 相加再折半 | $\dfrac{10}{2}=5$ |
| $a=b$ | 取等条件 | 两者相等时不等式变成等式 | $2\ne8$，所以 $4<5$ |

**证明一（代数，配方法）**：任何实数的平方都不小于 $0$（第 50 课配方时就靠这一条）。

1. 从 $(\sqrt a-\sqrt b)^2\ge0$ 出发；
2. 展开（第 20 课的分配律）：$a-2\sqrt{ab}+b\ge0$；
3. 移项：$a+b\ge2\sqrt{ab}$；
4. 两边除以 $2$：$\dfrac{a+b}{2}\ge\sqrt{ab}$。

取等当且仅当 $(\sqrt a-\sqrt b)^2=0$，即 $\sqrt a=\sqrt b$，即 $a=b$。

**证明二（面积，弦图）**：画一个边长 $a+b$ 的大正方形，往里摆四个 $a\times b$ 的长方形，中间会空出一个边长 $|a-b|$ 的小正方形。两块算法必须给出同一个面积：

$$(a+b)^2 = 4ab + (a-b)^2 \;\ge\; 4ab$$

（最后那个 $\ge$ 用的还是"平方非负"。）两边开方得 $a+b\ge2\sqrt{ab}$，同样推出结论；中间那块小正方形缩成一个点——也就是 $a=b$——时取等。

一条走式子、一条走图形，两条路给出同一个答案。

⚠️ **$a,b\ge0$ 是硬条件**：负数在实数范围内没有平方根，$\sqrt{ab}$ 根本不存在；真让 $a=b=-1$ 硬套进去，$\dfrac{a+b}{2}=-1$ 反而**小于** $\sqrt{(-1)\times(-1)}=1$——不等式会整个反过来。

## 4. 分步例题

**例 1（积定和最小）**：已知 $x>0$，求 $x+\dfrac1x$ 的最小值。

1. 认类型：两个量是 $x$ 与 $\dfrac1x$，它们的**积**是常数 $x\cdot\dfrac1x=1$；
2. 代公式：$x+\dfrac1x\ \ge\ 2\sqrt{x\cdot\dfrac1x}=2\sqrt1=2$；
3. 查取等：$x=\dfrac1x\ \Rightarrow\ x^2=1\ \Rightarrow\ x=1$（$x>0$，负根舍去）；
4. 下结论：最小值是 $2$，在 $x=1$ 处取得。

验算三个点：$x=1$ 得 $2$；$x=2$ 得 $2.5$；$x=0.5$ 得 $2.5$。全都 $\ge2$，且只有 $x=1$ 撞线。

**例 2（和定积最大）**：24 米篱笆围长方形，最大面积是多少？

1. 设长 $a$、宽 $b$，则 $2(a+b)=24$，即 $a+b=12$——**和**是常数；
2. 代公式：$\sqrt{ab}\le\dfrac{12}{2}=6$，两边平方得 $ab\le36$（两边都非负，可以放心平方）；
3. 查取等：$a=b=6$，也就是围成正方形；
4. 下结论：最大面积是 $36$ 平方米。

**例 3（"1 的代换"）**：已知 $x>0,\ y>0$ 且 $x+y=1$，求 $\dfrac1x+\dfrac1y$ 的最小值。

1. 分子上的 $1$ 正好可以换成 $(x+y)$——这就是"1 的代换"：

$$\frac1x+\frac1y=\frac{x+y}{x}+\frac{x+y}{y}$$

2. 拆开：$\dfrac{x+y}{x}+\dfrac{x+y}{y}=1+\dfrac yx+\dfrac xy+1=2+\Big(\dfrac yx+\dfrac xy\Big)$；
3. 对 $\dfrac yx$ 与 $\dfrac xy$ 这两个数用基本不等式：它们俩的**积**是 $1$，所以和 $\ge2\sqrt1=2$；
4. 合起来：$\dfrac1x+\dfrac1y\ge2+2=4$，取等在 $\dfrac yx=\dfrac xy$，即 $x=y=\dfrac12$。

验算：$x=y=0.5$ 时得 $2+2=4$ ✓；换成 $x=0.2,\ y=0.8$（和仍是 1）得 $5+1.25=6.25>4$ ✓。

三句话记住三种用法：**积定和最小、和定积最大、1 的代换**。前两个其实是同一条不等式的两种读法（从左往右读、从右往左读），第三个是把题目化回这两种读法的手法。

### 实验 3（Python 滑块）：四个均值排队

```python title="滑块实验：调和 ≤ 几何 ≤ 算术 ≤ 平方"
# sliders: a=2 [1:9:1], b=8 [1:9:1]
import math                          # 数学库：math.sqrt 开平方（第 3 章诞生）

H = 2 * a * b / (a + b)              # 调和平均：2 ÷ (1/a + 1/b) 化到最简的样子
G = math.sqrt(a * b)                 # 几何平均：相乘再开方
A = (a + b) / 2                      # 算术平均：相加再折半
Q = math.sqrt((a*a + b*b) / 2)       # 平方平均：先平方、取平均、再开方

print(f"H={H:.4f}  G={G:.4f}  A={A:.4f}  Q={Q:.4f}")
print(f"H ≤ G ≤ A ≤ Q 成立吗: {H <= G and G <= A and A <= Q}")
```

默认 $a=2,\ b=8$ 时输出 `H=3.2000  G=4.0000  A=5.0000  Q=5.8310` 与第二行 `True`。把 $a$ 拖到 8（与 $b$ 相等）：四个值**全部变成 8.0000**——取等时整条链缩成一个点。这条链叫**均值不等式链**，证明放在选读里。

::::warning[常见误区]

**误区一**："你以为基本不等式对所有实数都成立。"
其实 $a,b\ge0$ 是硬前提。取 $a=b=-1$ 代进去：$\dfrac{(-1)+(-1)}{2}=-1$，而 $\sqrt{(-1)\times(-1)}=1$，不等式**整个反过来**。见到负数先问一句：这道题还能不能用它？

**误区二**："你以为算出下界就等于求出了最小值。"
下界必须**够得着**才算最小值。比如额外限定 $x\ge2$ 再问 $x+\dfrac1x$ 的最小值：基本不等式照样给出下界 $2$，可取等处 $x=1$ 根本不在允许范围里——真正的最小值落在边界 $x=2$ 上，是 $2.5$。**用完不等式必查取等条件**，这是本课最容易丢分的一步。

**误区三**："你以为'和最小'与'积最大'是两条要分开背的公式。"
其实它们是同一条 $\sqrt{ab}\le\dfrac{a+b}{2}$ 的两种读法：从左往右读（已知 $ab$）得和的最小值 $2\sqrt{ab}$；从右往左读（已知 $a+b$）得积的最大值 $\left(\dfrac{a+b}{2}\right)^2$。背一条、练两种读法就够。

::::

**练习 3**（思考）：例 1 里 $x>0$ 时 $x+\dfrac1x$ 的最小值是 $2$。如果额外限定 $x\ge2$，最小值变成多少？

<details>
<summary>点开查看逐步解答</summary>

**是 2.5，不是 2。** 基本不等式给出的下界 $2$ 只在 $x=1$ 处取等，而 $x=1$ 不在允许范围 $x\ge2$ 里。

在 $x\ge2$ 这一段上，$x+\dfrac1x$ 是**递增**的：$x$ 变大时，$x$ 这一半在长、$\dfrac1x$ 这一半在缩，而前者长得比后者缩得快。所以最小值落在最左端 $x=2$：$2+\dfrac12=2.5$。

```python
for x in [2, 3, 4, 5]:
    print(x, x + 1/x)      # 2 2.5 / 3 3.333… / 4 4.25 / 5 5.2：越往右越大
```

这正是误区二说的那件事：**不等式负责给下界，取等条件负责确认这个下界够得着**。够不着，就得回头看边界。

</details>

## 7. 选读与边界

<details>
<summary>选读 · 为什么 H ≤ G ≤ A ≤ Q</summary>

中间那一段 $G\le A$ 就是基本不等式本身，已经证过；补上首尾两环即可（设 $a>0,\ b>0$）。

**先证 $H\le G$**：$H=\dfrac{2ab}{a+b}$。由 $G\le A$ 得 $\sqrt{ab}\le\dfrac{a+b}{2}$，两边都为正，取倒数要翻面：$\dfrac1{\sqrt{ab}}\ge\dfrac{2}{a+b}$，再乘 $ab$：

$$\frac{ab}{\sqrt{ab}}\;\ge\;\frac{2ab}{a+b}\quad\Longrightarrow\quad \sqrt{ab}\;\ge\;H$$

**再证 $A\le Q$**：要证 $\dfrac{a+b}{2}\le\sqrt{\dfrac{a^2+b^2}{2}}$。两边都非负，平方：

$$\frac{(a+b)^2}{4}\le\frac{a^2+b^2}{2}\iff (a+b)^2\le2(a^2+b^2)\iff a^2+2ab+b^2\le2a^2+2b^2$$

移项得 $0\le a^2-2ab+b^2=(a-b)^2$，永远成立。

**取等**：四环的取等条件全是 $a=b$。链上任意一环取等，整条链就一起缩成一个点。

**本课不管什么**：只管**两个**数、且一次代换就能化归的标准型。三个及以上的均值不等式（例如 $\frac{a+b+c}{3}\ge\sqrt[3]{abc}$）、带权重的加权形式，以及需要多次变形或借助导数才能定出最值的问题，都不在本课范围内。

</details>
