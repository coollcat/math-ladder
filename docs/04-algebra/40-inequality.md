# 不等式

## 1. 从一个场景开始

电梯限重 1000 千克。可"总重**恰好**等于 1000 千克"几乎永远不会发生——真正要回答的是："什么情况下**超载**？"

等号回答"何时恰好"，不等号回答"哪一段都行"。生活里的约束几乎全是后一种：余额不低于、时间不超过、年龄至多。这一课你会发现：解方程的功夫全部适用，只多了一条**反直觉的翻面规则**。

## 2. 直觉解释

解方程 $3x-5=4$ 得到一个点 $x=3$；把等号换成大于号，$3x-5>4$ 的答案不再是点，而是数轴上的**一片区域**——所有让"左边更大"成立的 $x$，手拉手站成一段。

翻面规则用镜子看最直观：不等式就是"谁在谁的右边"。两边同乘 $-1$ 相当于把数轴**照一次镜子**——左右整体互换，原来靠右的（大）跑到左边去了。所以：

$$x>2 \quad\xrightarrow{\ \times(-1)\ }\quad -x<-2$$

大小关系跟着镜像一起翻转。乘正数不照镜子，方向自然不动。

## 3. 正式定义

| 记号 | 读法 | 含义 |
| --- | --- | --- |
| $x>2$ | x 大于 2 | $x$ 在 2 右边（不含 2） |
| $x\ge2$ | x 大于等于 2 | 含边界 2 |
| $x<2$、$x\le2$ | 小于、小于等于 | 同理向左 |

使不等式成立的所有值组成的集合叫**解集**——它通常是一片区域。

不等式的两条运算规则：

1. 两边同加减任意一个数：**方向不变**；
2. 两边同乘或同除以同一个**正**数：方向不变；同乘或同除以同一个**负**数：**方向必须翻转**。

例如 $x>2$ 两边乘 $-3$：得 $-3x<-6$。

## 4. 分步例题

**例**：解不等式 $3x-5>4$。

1. 移项（只是加减，不变号）：$3x>9$
2. 两边除以 3（正数，不翻转）：$x>3$
3. 解集是数轴上 3 右边的整片区域，不含端点 3。

对照一下：上一课方程 $3x-5=4$ 的解是孤零零的点 $x=3$——它恰好是这片区域的**边界**。方程管边界，不等式管整片地皮。

## 5. 动手实验

### 实验 1：零点视角看解集

把 $2x>k$ 移项成 $2x-k>0$：问"什么时候大于零"，就是问"直线哪一段**浮在海平面以上**"。拖动滑块 $k$ 观察分界点：

```viz
{
  "type": "plot",
  "title": "2x-k 什么时候大于 0？",
  "expr": "2*x - k",
  "xmin": -1,
  "xmax": 6,
  "sliders": [
    { "name": "k", "min": 0, "max": 10, "step": 1, "value": 7 }
  ]
}
```

曲线高于横轴的那段横坐标，正是解集；曲线穿过横轴的位置，正是边界 $x=k/2$。

### 实验 2：跟一条水平线比高低

同一道题还有第二种图像问法：$3x-5>4$ 可以读成"直线 $y=3x-5$ 什么时候**高过**水平线 $y=h$"。水平线的高度交给滑块，答案随你试探而移动：

```viz
{
  "type": "plot",
  "title": "3x-5 什么时候高于 h？",
  "expr": "3*x - 5",
  "label": "y = 3x-5",
  "expr2": "h",
  "label2": "y = h",
  "xmin": -1,
  "xmax": 5,
  "sliders": [
    { "name": "h", "min": -8, "max": 8, "step": 1, "value": 4 }
  ]
}
```

h=4 时，蓝线蹿到橙线上方的那段横坐标（$x>3$）就是解集；两线相交处 $x=3$ 恰是边界。再把 h 拖高或拖低，边界始终是 $x=(h+5)/3$。实验 1 问"什么时候在海平面以上"，本实验问"什么时候高过你指定的那条线"：一个比 0，一个比任意数，本质是同一个动作。

### 实验 3：比较式会说话

Python 里比较式本身就是一个"问题"，机器直接回答真或不成立：

```python title="比较的结果只有两种"
x = 4
print(x > 3)     # 大于成立 → 打印 True（真）
print(x <= 3)    # 小于等于不成立 → 打印 False（假）
print(2*x > 7)   # 先算左边再比较，本课练习的主角
```

### 实验 4：把解集涂在数轴上

```python title="滑块实验：解集是一片区域"
# sliders: t=3 [-5:5:1], probe=1 [-5:5:1]
import matplotlib.pyplot as plt   # 画图库，第 0 章介绍过

fig, ax = plt.subplots(figsize=(7, 2))
ax.axvspan(t, 6, color="honeydew")                   # axvspan(a, b)：给竖直条形区域涂色，这里涂出解集 x>t
ax.axvline(t, color="tomato", linestyle="--")        # 解集边界画成虚线（不属于解集）
ax.axvline(probe, color="steelblue", linewidth=3)    # 试探点画成竖线

if probe > t:                    # if：条件成立时执行缩进的下一行
    verdict = "在解集里"
else:                            # else：条件不成立时走这条路
    verdict = "不在解集里"

ax.set_title(f"解集 x > {t}：试探点 {probe} {verdict}", fontsize=10)
ax.set_xlim(-5, 6)
ax.set_yticks([])
```

两个挑战：把试探点 `probe` 拖过红色虚线，看判定翻转的瞬间；把边界 `t` 拖到 0 再拖到负数，观察绿区跟着搬家。

:::warning[常见误区]

**误区一**："两边乘负数，只是数字变个符号而已。"
整个大小关系镜像翻转：$x>2$ 乘 $-3$ 后是 $-3x<-6$，写成 $-3x>-6$ 方向就错了。这是本课唯一的"新规则"，也是出错率最高的一条。

**误区二**："解不等式也该得到一个确定的数。"
得到的是一片区域。答题时写清方向和是否含边界（$>$ 空心圈，$\ge$ 实心点）。

**误区三**："移项也要变不等号方向。"
移项是两边同加减——属于规则 1，**不翻面**。翻面只发生在乘除负数时。别把两条规则搅在一起。

:::

```quiz
不等式 x > 2 的两边同时乘以 -3，得到什么？
- -3x > -6（方向不变）
- -3x < -6（方向翻转） [*]
- -3x = -6
? 乘负数相当于照镜子：数轴左右互换后，原来"更大"的一方反而变小了。所以乘以负数必须改变不等号方向。
```

## 6. 练习

**练习 1**：$x=4$ 时，$2x>7$ 成立吗？让代码回答。下面的代码能跑但方向写反了：

```exercise

# @check: True
# @hint: 检查不等号方向——题目问的是"大于"，代码里写成了小于
print(2*4 < 7)
```

**练习 2**：解不等式 $-2x+1>7$。

<details>
<summary>点开查看逐步解答</summary>

移项（不翻面）：$-2x>6$；两边除以 $-2$（负数，**翻面**）：$x<-3$。

验算两头：$x=-4$（区域里）代入 $-2\times(-4)+1=9>7$ ✓；$x=0$（区域外）代入 $1>7$ 不成立 ✓。含负系数的不等式，翻面那一步务必放慢速度。
</details>

**练习 3**：货车限载 100 千克，已装 36 千克的货，每箱货重 8 千克。还能装几箱？

<details>
<summary>点开查看逐步解答</summary>

列不等式：$8n+36\le100$。移项：$8n\le64$；除以 8：$n\le8$。

注意箱数必须是整数，所以 $n$ 可取 $0,1,\dots,8$ 共九种装法。"解集是一片区域"+现实约束（整数），才是应用题的完整答案。
</details>

## 7. 选读：翻面规则能被证明吗？

<details>
<summary>选读 · 只用规则 1 推出规则 2</summary>

设 $x>y$，两边同时加上 $-x-y$（规则 1 说可以）：

$$x+(-x)+(-y) \;>\; y+(-x)+(-y)$$

左边剩 $-y$，右边剩 $-x$，于是 $-y>-x$，即 $-x<-y$——**乘 $-1$ 必翻面**已被证明。至于乘一般负数 $c=-k$：先按正数规则乘 $k$（不翻面），再乘 $-1$（刚证的翻面），两次合成"乘负数翻一次面"。

回头看，翻面根本不是新公理，而是"两边同加减"与"负数乘法符号法则"联手推出的必然。数学里最吓人的规则，往往都是这样纸老虎。

</details>
