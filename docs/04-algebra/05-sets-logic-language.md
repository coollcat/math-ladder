# 集合与逻辑用语：数学的第一套语法

## 1. 从一个场景开始

班主任手上有两张社团名单：数学社三名同学，辩论社三名同学。校长问："哪些同学两个社都参加了？至少参加一个的有几个？两个都没参加的又是谁？"

用日常话回答，越说越绕；换成两行符号，一眼见底。数学之所以能说得又快又准，靠的就是这套**把话变成符号**的语法。

## 2. 直觉解释

**集合**就是"把一些东西装进一个盒子"。装进去的东西叫**元素**；盒子可以整体去和别的盒子做运算：

- 两个盒子**重叠**的部分——交集；
- 两个盒子**合并**的部分——并集；
- 从一个盒子里**挖掉**另一个盒子的部分——差集（补集则是对着"全集"这个大盒子挖）。

**逻辑**给每个句子贴一个真假标签，再用连接词把句子拼起来：且、或、非、"如果……那么"。集合管"是什么东西"，逻辑管"这话对不对"——同一套语法的两个侧面。

## 3. 正式定义

**定义一（集合）**：把确定的、互不相同的对象看成一个整体，叫**集合**，里面的对象叫**元素**。$a$ 是集合 $A$ 的元素记作 $a \in A$，不是则记作 $a \notin A$。

集合的三要素：**确定性**（一个对象在不在盒子里，必须能说清）、**互异性**（同一个盒子不重复装）、**无序性**（装东西的顺序不影响盒子）。

两种写法：

| 写法 | 形式 | 例 |
| --- | --- | --- |
| 列举法 | $\lbrace a_1,\ a_2,\ a_3\rbrace$ | 数学社 $=\lbrace$小明, 小红, 小刚$\rbrace$ |
| 描述法 | $\lbrace x \mid x \text{ 满足的性质}\rbrace$ | 偶数集 $=\lbrace x \mid x=2k,\ k \in \mathbb{Z}\rbrace$ |

**定义二（集合的关系与运算）**：设 $A$、$B$ 是集合。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $A \subseteq B$ | 子集 | $A$ 里每个元素都在 $B$ 里 |
| $A \cap B$ | 交集 | 两个集合**公共**的元素 |
| $A \cup B$ | 并集 | 两个集合**全部**的元素（重复的只算一次） |
| $\complement_{U} A$ | 补集 | 全集 $U$ 中**不属于** $A$ 的元素 |

**定义三（命题与条件）**：能判断真假的陈述句叫**命题**。若"$p$ 成立"能推出"$q$ 成立"，记作 $p \Rightarrow q$。

| 关系 | 名字 | 记法 |
| --- | --- | --- |
| 有 $p$ 就够了 | $p$ 是 $q$ 的充分条件 | $p \Rightarrow q$ |
| 少了 $p$ 就不行 | $p$ 是 $q$ 的必要条件 | $q \Rightarrow p$ |
| 互为进退 | $p$ 是 $q$ 的充要条件 | $p \Leftrightarrow q$ |

**定义四（量词）**：$\forall$ 读作"对任意"，$\exists$ 读作"存在"。它们的否定要**换量词**：

$$\neg(\forall x\, P(x)) \iff \exists x\, \neg P(x), \qquad \neg(\exists x\, P(x)) \iff \forall x\, \neg P(x)$$

## 4. 分步例题

**例 1（交、并、补）**：全班 $U=\lbrace$小明, 小红, 小刚, 小丽, 小强$\rbrace$，数学社 $M=\lbrace$小明, 小红, 小刚$\rbrace$，辩论社 $D=\lbrace$小刚, 小丽, 小明$\rbrace$。

1. 交集 $M \cap D$：两边都出现的是小明、小刚，得 $\lbrace$小明, 小刚$\rbrace$，共 2 人；
2. 并集 $M \cup D$：把两边的名字全收进来并去重，得 $\lbrace$小明, 小红, 小刚, 小丽$\rbrace$，共 4 人；
3. 补集 $\complement_{U} M$：从全班挖掉数学社，得 $\lbrace$小丽, 小强$\rbrace$；
4. 两个都没参加：先并集再补，$\complement_{U}(M \cup D)=\lbrace$小强$\rbrace$。

**例 2（两种写法互译）**：小于 5 的正整数集合。

1. 列举法：$\lbrace1, 2, 3, 4\rbrace$；
2. 描述法：$\lbrace x \mid x \in \mathbb{Z}^{+},\ x<5\rbrace$——**论域和性质都要写全**，否则换个论域集合就变了。

**例 3（判断条件）**：设 $p$：$x>2$，$q$：$x>0$。$p$ 是 $q$ 的什么条件？

1. 由 $x>2$ 一定能推出 $x>0$，所以 $p$ 是 $q$ 的**充分**条件；
2. 由 $x>0$ 推不出 $x>2$（取 $x=1$，这是反例），所以**不必要**；
3. 结论：$p$ 是 $q$ 的**充分不必要条件**，记作 $p \Rightarrow q$ 而 $q \nRightarrow p$。

**例 4（写否定）**：写出"$\forall x>0,\ x^2>0$"的否定。

1. 全称量词换成存在量词：$\exists x>0$；
2. 结论取反：$x^2 \le 0$；
3. 合起来：$\exists x>0,\ x^2 \le 0$。这句话是假的，原命题是真的——命题与它的否定恰好一真一假。

### 实验 1（viz）：把五名同学分进四个区域

集合运算的另一种看法是**分类**：每个同学恰好落进一个区域。点一点箭头，看右下角的诊断：


四个区域把全班**不重不漏**地切开了——这正是交、差、补三种运算合起来的效果。哪个区域空着（没有箭头指向它），就说明对应的那道"筛子"筛不出人。

### 实验 2（viz）：p 推 q 与 q 推 p

充分、必要的差别全写在这张真值表里。点一点 p、q 两个格子，看 `[p=>q]` 那一列什么时候变成 F：

```viz
{
  "type": "truth-table",
  "title": "p=>q 与 q=>p：箭头是有方向的",
  "formula": "p=>q",
  "showColumns": ["p", "q", "not p", "p=>q", "q=>p"]
}
```

$p \Rightarrow q$ 只在"$p$ 真、$q$ 假"那一行是假——"说了下雨就带伞，结果下雨了却没带伞"才算撒谎。而 $q \Rightarrow p$ 是另一列，两列并不相同，这就是"充分不必要"在表格里的模样。

### 实验 3（python）：用集合算交并补

```python
math_club = {"小明", "小红", "小刚"}      # 花括号：集合字面量，重复的元素会自动去重
debate_club = {"小刚", "小丽", "小明"}

print(math_club & debate_club)            # & 交集：两边都有的人
print(math_club | debate_club)            # | 并集：至少参加一个的人
print(math_club - debate_club)            # - 差集：参加数学社但没参加辩论社
```

Python 把集合做成了内置类型，`&`、`|`、`-` 三个符号和纸上写的 $\cap$、$\cup$、$\setminus$ 一一对应。输出里名字的先后顺序可能每次不同——记住，集合本来就不讲究顺序（无序性）。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为 $\lbrace1,1,2\rbrace$ 和 $\lbrace1,2\rbrace$ 是两个不同的集合。" 集合讲**互异性**，重复写同一个元素不改变它，两者是同一个集合；同理 $\lbrace1,2\rbrace$ 与 $\lbrace2,1\rbrace$ 也是同一个。

**误区二**："你以为 $\in$ 和 $\subseteq$ 可以互换。" $a \in A$ 说的是"$a$ 这个**元素**在不在 $A$ 里"；$A \subseteq B$ 说的是"$A$ 这个**集合**整体装不装得进 $B$"。左边是元素对集合，右边是集合对集合，层次不同。

**误区三**："你以为否定就是把结论加个'不'字。" 全称命题"所有 $x$ 都满足"的否定是"**存在**某个 $x$ 不满足"——量词也要跟着换。只改结论、不换量词，是逻辑题最常见的丢分点。

:::

**练习 2**：判断"$x^2=1$"与"$x=1$"之间的充分、必要关系。

<details>
<summary>点开查看逐步解答</summary>

设 $p$：$x^2=1$，$q$：$x=1$。

1. 由 $q$ 能推出 $p$（$1^2=1$ ✓），所以 $q$ 是 $p$ 的充分条件；等价地说，$p$ 是 $q$ 的**必要条件**；
2. 由 $p$ 推不出 $q$：$x=-1$ 也满足 $x^2=1$，这是反例；
3. 结论：$p$ 是 $q$ 的**必要不充分条件**。从解集看更直观：$p$ 的解集 $\lbrace1,-1\rbrace$ 比 $q$ 的解集 $\lbrace1\rbrace$ 大——条件更宽，就更难当充分条件。

</details>

**练习 3（概念）**：写出"存在一个整数，它的平方是负数"的否定，并判断原命题与否定谁真谁假。

<details>
<summary>点开查看答案</summary>

否定：把 $\exists$ 换成 $\forall$、结论取反——"**对任意**整数，它的平方**不是**负数"。平方非负，所以这个全称命题为真，原命题为假。一真一假，正合"命题与它的否定恰有一个为真"。

</details>

**趁热打铁**：

```quiz
"x 大于 2" 是 "x 大于 0" 的什么条件？
- 充分不必要条件 [*]
- 必要不充分条件
- 充要条件
? 比 2 大必然比 0 大，所以"大于 2"能推出"大于 0"，它是充分条件；但比 0 大的数不一定比 2 大（比如 1），推不回去，所以不必要。合起来就是充分不必要条件。
```

## 8. 选读：朴素集合论为什么会翻车

<details>
<summary>选读 · 罗素悖论与"确定性"的边界</summary>

最早大家以为"任何一堆东西都能组成集合"。罗素提出一个刁钻的集合：$R=\lbrace$所有不属于自己的集合$\rbrace$。然后问：$R$ 属不属于自己？

- 若 $R \in R$，按定义 $R$ 不该属于自己，矛盾；
- 若 $R \notin R$，按定义它又该属于自己，还是矛盾。

两头都撞墙。毛病出在"任何一堆东西"这句话太宽松。现代数学改用**公理**来规定"什么样的东西才算集合"（如 ZF 公理系统），把 $R$ 这种自我指涉的构造挡在门外。第 18 章《数学语言与证明》会接着把命题、量词与各种证明方法讲成一套完整的工具。

</details>
