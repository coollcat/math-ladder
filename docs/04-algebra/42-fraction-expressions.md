# 分式运算：通分与约分

## 1. 从一个场景开始

第 2 章你练熟了 $\frac{1}{2}+\frac{1}{3}$：切法不同没法直接拼，通分成六分之几再相加。现在把分子里的数字悄悄换成字母：

$$\frac{1}{x}+\frac{1}{x+1}$$

$x$ 还没定值，这一加还加得动吗？加得动——而且**根本不需要知道 $x$ 是几**。通分的全过程（找公分母、改写分子、相加）一步都不碰"$x$ 到底等于多少"这个问题。字母只是名字牌（第 10 课的老规矩），分数的规则不在乎名字牌上写的是数还是式。

这一课把分数四则整套手艺平移到"字母分母"的世界，这门对象的大名叫**分式**。

## 2. 直觉解释

分式没有新规则，只有一条新提醒。规则原封不动：分母不同先通分、公因式可以约掉、乘是分子乘分子分母乘分母。这些动作全都建立在"分数基本性质"上——分子分母同乘（或同除以）一个**非零**的代数式，分式的值不变。

新提醒就藏在"非零"两个字里。数字分数的分母是 $3$、是 $7$，谁也不为 $0$，没人操这份心；可分式的分母是 $x-1$ 这样的活物——$x=1$ 时它就归零了。**分母为 $0$ 的分式没有意义**：不是无穷大，是"这场除法根本没法开问"。所以每拿到一个分式，先扫一眼分母——哪些值会让它归零，那些值一律谢绝入内。

至于通分与约分的直觉，数字版早就给过：通分是"把不同的切法统一切法"，约分是"分子分母里的公因式，上下同除、一笔勾销"。字母世界唯一的升级是：找公因式靠的是**因式分解**——上一课的硬功夫，在这里正式接活。

## 3. 正式定义

**分式**：形如 $\dfrac{A}{B}$ 的代数式，其中 $A$、$B$ 都是整式，且 $B$ 中含有字母。$B\neq0$ 是分式有意义的前提。

| 操作 | 规则 | 例子 |
| --- | --- | --- |
| 约分 | 分子分母同除以**公因式**（先因式分解再找） | $\dfrac{x+2}{x^2+2x}=\dfrac{x+2}{x(x+2)}=\dfrac{1}{x}$ |
| 通分 | 公分母取**所有出现过的因式、各取最高次数**的乘积 | $\dfrac{1}{x}$ 与 $\dfrac{1}{x+1}$ 的公分母是 $x(x+1)$ |
| 分式加减 | 先通分，再分子相加减 | $\dfrac{1}{x}+\dfrac{1}{x+1}=\dfrac{(x+1)+x}{x(x+1)}=\dfrac{2x+1}{x(x+1)}$ |
| 分式乘除 | 乘：分子乘分子分母乘分母；除：乘倒数 | 与数字版完全一致 |

**最简分式**：分子分母没有公因式（约到不能再约）的分式——对应数字世界的"最简分数"。

一条纪律：**约分约的是因式（乘在一起的整块），不是项（加减号隔开的段）**。$\dfrac{x^2+x}{x}$ 里 $x^2+x$ 得先分解成 $x(x+1)$，才能把 $x$ 约掉；看见加号就伸手约的，十有八九要翻车。

## 4. 分步例题

**例 1（约分）**：化简 $\dfrac{x^2+5x+6}{x+2}$。

1. 分子因式分解（找"和为 $5$、积为 $6$"的数对）：$x^2+5x+6=(x+2)(x+3)$；
2. 原式 $=\dfrac{(x+2)(x+3)}{x+2}$；
3. 约掉公因式 $x+2$，得 $x+3$（要求 $x\neq-2$，否则原分式无意义）；
4. 验收：代 $x=1$，原式 $=\dfrac{12}{3}=4$，化简式 $=4$ ✓。

**例 2（通分相加）**：计算 $\dfrac{1}{x-1}+\dfrac{1}{x+1}$。

1. 认分母：$x-1$ 与 $x+1$ 是两个不同的一次因式；
2. 定公分母：所有因式各取一遍——$(x-1)(x+1)$；
3. 改写分子：$\dfrac{x+1}{(x-1)(x+1)}+\dfrac{x-1}{(x-1)(x+1)}$（分母乘了什么，分子也要乘什么）；
4. 分子相加：$(x+1)+(x-1) = 2x$；
5. 结果 $\dfrac{2x}{(x-1)(x+1)}$，展开分母即 $\dfrac{2x}{x^2-1}$。要求 $x\neq1$ 且 $x\neq-1$。

第 5 步的两个"谢绝值"正是从两个因式各自归零读出来的——通分改写的每一步都踩在"$B\neq0$"的地基上。

### 实验 1（viz）：分母归零的地方，曲线断了


拖动 $a$：曲线在 $x=a$ 处断成两半，各自冲向天与地——那一根竖直位置就是"分母归零"的悬崖，任何点都住不上去。再拖 $k$：曲线整体抬高压低，但**悬崖的位置纹丝不动**——分母说了算的地方，分子管不着。这条"贴着悬崖立起来"的走向叫渐近线，第 6 章函数课会给它正式户口。

### 实验 2（python）：数字版与字母版，同一个答案

通分的手艺不分数字字母——两边互相验收：

```python title="x = 3 时，两条路算同一笔账"
x = 3
# 字母版：1/(x-2) + 1/(x+1) 通分后 = (2x - 1) / ((x-2)(x+1))
left = 1/(x - 2) + 1/(x + 1)          # 原式：两个分式分别求值再相加
right = (2*x - 1) / ((x - 2) * (x + 1))   # 通分合并后的结果
print(left, right)                     # 两个值应当完全一样
print(left == right)                   # 比较运算给出 True 或 False
```

两行都打印 $1.25$，比较给出 True。换几个 $x$ 的值再跑（避开 $x=2$ 和 $x=-1$——那是分母的悬崖），恒等式始终成立。

### 实验 3（python 滑块）：约分前后的曲线是同一条

```python title="滑块实验：(x^2+5x+6)/(x+2) 与 x+3"
# sliders: x=4 [-6:6:1]
left = (x*x + 5*x + 6) / (x + 2)   # 约分前：分式在 x 处的值
right = x + 3                       # 约分后：x + 3 在 x 处的值
print(f"x={x}: 分式 {left} | 化简式 {right}")
print(left == right)                # x 不等于 -2 时恒为 True
```

拖动试探点 $x$（别停在 $-2$），最后一行始终 True：约分没改变分式的值，只是换了个更清爽的写法。

### 快问快答

```quiz
x 取哪个值时，分式 (x - 1)/(x - 3) 没有意义？
- x = 1
- x = 3 [*]
- x = -3
? 分母归零分式才失义：x - 3 = 0 解得 x = 3。分子上的 x - 1 归零只让分式的值等于 0，那完全合法。
```

::::warning[常见误区]

**误区一**："你以为分子归零和分母归零是一回事。" 分子为 $0$（分母不为 $0$）时分式的值是 $0$，干干净净；分母为 $0$ 时分式**没有意义**，连值都谈不上。一个是合法的零，一个是禁地。

**误区二**："你以为带加号的项也能约。" $\dfrac{x+1}{x^2+1}$ 约"一个 $x$"得 $\dfrac{1+1}{x+1}$？大错——$x^2+1$ 是两项的**和**，里面根本没有 $x$ 这个**因式**。约分前先因式分解：$x^2+1$ 拆不开，那就一分都约不了。

**误区三**："你以为通分只改分母。" 分母乘了 $(x+1)$，分子也得乘上同一个 $(x+1)$——分数基本性质要求上下同乘。只妆点分母不动分子，分式的值当场就变了。

::::

## 6. 练习

**练习 1**：化简 $\dfrac{x^2+7x+12}{x+4}$，并在 $x=5$ 处验证。下面的代码能跑，但化简式写错了：

```exercise
# @title: 练习：约到底再验证
# @check: True
# @hint: 分子 x^2 + 7x + 12 找"和为 7、积为 12"的数对——3 和 4。约掉公因式后剩下的可别抄错。
x = 5
left = (x*x + 7*x + 12) / (x + 4)   # 原分式在 x=5 处的值
right = x + 4                        # ← 化简结果：真的是 x + 4 吗？
print(left == right)
```

**练习 2**：计算 $\dfrac{x}{x-2}-\dfrac{2}{x-2}$，并说出它的"谢绝值"。

<details>
<summary>点开查看逐步解答</summary>

分母已经相同，直接合并分子：$\dfrac{x-2}{x-2}=1$（$x\neq2$）。谢绝值读自分母：$x=2$。顺带一提，原式逐项算也一样：代 $x=5$，$\dfrac{5}{3}-\dfrac{2}{3}=1$ ✓。"同分母先合并、分子能约再约"是这类题的捷径。

```python
x = 5
print(x / (x - 2) - 2 / (x - 2))   # 输出 1.0
```
</details>

**练习 3**：有人声称 $\dfrac{x^2-4}{x+2}=x-2$ 对一切 $x$ 都成立。他说得对吗？

<details>
<summary>点开查看逐步解答</summary>

对**几乎**一切 $x$ 成立，唯独 $x=-2$ 除外：那里左边分母归零，分式根本无意义；右边倒是好好给出 $-4$。因式分解 $x^2-4=(x+2)(x-2)$ 再约分时，默认条件是 $x\neq-2$。恒等变形要带着"谢绝值"一起写——这也是将来分式方程验根（防"增根"）的思想种子。
</details>

## 7. 选读：公分母为什么要"最简"？

<details>
<summary>选读 · 能用就行 vs 最省力</summary>

通分 $\dfrac{1}{x-1}+\dfrac{1}{x+1}$ 时，公分母取 $(x-1)(x+1)$ 很省力；但取 $2(x-1)(x+1)$、甚至 $(x-1)^2(x+1)^3$ 行不行？行——分母统一了，加法照样合法，只是分子被拖进一堆多余的因数，最后还得费劲约回去。

**最简公分母**的原则是"每个因式只要最高次的一份"：因式出现过的次数取最大者，不多带一份。它让后续的加减省力、结果天然接近最简。这与数字世界取最小公倍数是同一条思想——第 10 章数论课会给"最小公倍"正式编制，眼下先用直觉。

顺带预告：通分的逆过程同样值钱。把 $\dfrac{2x}{x^2-1}$ 拆回 $\dfrac{1}{x-1}+\dfrac{1}{x+1}$ 的动作叫**部分分式**，它是积分学（第 14 章）拆解复杂分式的看家本领——今天学的通分正是那一课的地基。

</details>
