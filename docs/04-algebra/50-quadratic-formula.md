# 二次方程与求根公式

## 1. 从一个场景开始

一块长方形菜地，长比宽多 2 米，面积 24 平方米。宽是多少？设宽为 $x$：

$$x(x+2)=24 \quad\Longrightarrow\quad x^2+2x-24=0$$

$x^2$ 出现了，直线方法集体失效。这类问题四千年前的古巴比伦人就会解——泥板上没有符号，只有一套"补一补、拼一拼"的手艺。今天你将看到这条完整推理链，并把它浓缩成一把万能钥匙：**求根公式**。

## 2. 直觉解释

$x^2+2x$ 可以画成图形：边长 $x$ 的正方形，右边和上边各贴一条 $1\times x$ 的窄条——这是个缺了一角的"L 形"。缺的那块恰好是 $1\times1$ 的小方块。补上它：

$$x^2+2x+1=(x+1)^2$$

散装的 $x^2+2x$ 变成了整装的正方形 $(x+1)^2$！这个"补缺角"的动作叫**配方**。整装的正方形可以直接开方——解方程的大门就此打开。

## 3. 正式定义

对一般方程 $ax^2+bx+c=0$（$a\neq0$），先除以 $a$、把常数移到右边：

$$x^2+\frac{b}{a}x=-\frac{c}{a}$$

按直觉部分的办法补缺角（加上"一次项系数一半的平方"）：

$$x^2+\frac{b}{a}x+\Big(\frac{b}{2a}\Big)^2=\Big(\frac{b}{2a}\Big)^2-\frac{c}{a} \quad\Longrightarrow\quad \Big(x+\frac{b}{2a}\Big)^2=\frac{b^2-4ac}{4a^2}$$

两边开方（记得正负两个分支），整理后就是**求根公式**：

$$x=\frac{-b\pm\sqrt{\,b^2-4ac\,}}{2a}$$

根号里的部分叫**判别式** $\Delta=b^2-4ac$，它决定根的个数：

| $\Delta$ | 根的情况 | 图像上的含义 |
| --- | --- | --- |
| $\Delta>0$ | 两个不同的实数根 | 抛物线穿过横轴两次 |
| $\Delta=0$ | 恰好一个根 | 抛物线与横轴相切 |
| $\Delta<0$ | 无实数根 | 整条曲线悬在横轴上方或沉在下方 |

## 4. 分步例题

**例**：解开场那道题 $x^2+2x-24=0$。

1. 移常数到右边：$x^2+2x=24$
2. 补缺角（两边同加 $1^2$）：$x^2+2x+1=25$
3. 收成正方形：$(x+1)^2=25$
4. 开方，两个分支都要：$x+1=5$ 或 $x+1=-5$
5. 解得 $x=4$ 或 $x=-6$。按题意宽度取 $4$（米），验算：$4\times(4+2)=24$ ✓

数学答案有两个，现实答案挑合适的那个——**解完方程还要翻译回题目**。

## 5. 动手实验

### 实验 1：拖动滑块，看两个零点合成一个、再沉入水下

```viz

  ]
}
```

默认位置 $b=-2,\ c=-3$：抛物线穿轴两次（$\Delta=16$）。三个挑战：

1. 只把 $c$ 往上拖：两个零点互相靠拢；
2. $c=1$ 时（$\Delta=0$）：两点合成一点，曲线骑在横轴上——相切；
3. $c$ 再往上（$\Delta<0$）：整条曲线脱离横轴，"无实数根"原来是这幅画面。每一步都心算一下 $\Delta$ 对照。

### 实验 2：求根公式交给机器跑一遍

```python title="用公式解 x^2 + 2x - 24 = 0"
a, b, c = 1, 2, -24       # 多元赋值：一行同时给三个变量赋值
delta = b**2 - 4*a*c      # ** 是乘方运算符（第 3 章乘方课）；这里算判别式
root = delta ** 0.5       # ** 0.5 即开平方：delta 的平方根

x1 = (-b + root) / (2*a)  # 公式的 + 分支
x2 = (-b - root) / (2*a)  # 公式的 - 分支，两个都不能丢
print(f"x1 = {x1}, x2 = {x2}")
print(f"验算: {a*x1*x1 + b*x1 + c}, {a*x2*x2 + b*x2 + c}")   # 都应为 0
```

### 实验 3：判别式三连

```python title="Δ 决定根的个数"
for a, b, c in [(1, -2, -3), (1, -2, 1), (1, -2, 3)]:
    delta = b**2 - 4*a*c
    if delta > 0:               # if：条件成立时走这里
        kind = "两个不同实数根"
    elif delta == 0:            # elif：否则如果——上一个条件不成立时再试这个
        kind = "恰好一个根（重根）"
    else:                       # else：都不成立时走这里
        kind = "无实数根"
    print(f"a={a}, b={b}, c={c}: Δ={delta} -> {kind}")

print("(对照实验 1：把这三组系数依次填进滑块看看)")
```

:::warning[常见误区]

**误区一**："开方时取正的那个就行。"
$(x+1)^2=25$ 给出 $x+1=\pm5$，漏掉负分支就丢了一半的解。平方抹掉了正负，开方要把两个都请回来。

**误区二**："判别式小于 0 说明题目印错了。"
它只是宣布"实数范围内无解"——图像上是曲线整体浮起或沉底。这些"失踪的根"要等复数（第 12 章）来收留。

**误区三**："有了公式就不需要配方了。"
公式正是配方的产物（选读部分你会看到它还藏着更多秘密）；而形如 $x^2+px=q$ 的题直接配方反而更快。工具箱里多一件工具，从来不是坏事。

:::

```quiz
方程 x^2 - 4x + 4 = 0 的判别式等于多少？
- 0（抛物线与横轴恰好相切） [*]
- 32（两个不同的根）
- -32（没有实数根）
? Δ = (-4)^2 - 4*1*4 = 16 - 16 = 0。此时 x^2 - 4x + 4 = (x-2)^2，只有一个根 x=2——正是实验 1 挑战 2 里"两点合成一点"的画面。
```

**练习 2**：接着练习 1 解方程 $x^2-5x+6=0$。

<details>
<summary>点开查看逐步解答</summary>

$\Delta=25-24=1>0$，代入公式：$x=\dfrac{5\pm\sqrt1}{2}$，得 $x_1=3,\ x_2=2$。验算因式分解：$x^2-5x+6=(x-2)(x-3)$ ✓——两种方法殊途同归。

```python
a, b, c = 1, -5, 6
delta = b**2 - 4*a*c           # 1
x1 = (-b + delta**0.5) / (2*a) # 3.0
x2 = (-b - delta**0.5) / (2*a) # 2.0
print(x1, x2)
```
</details>

**练习 3**：实验 1 里 $b=-2$ 时，哪个 $c$ 让方程恰好有重根？

<details>
<summary>点开查看逐步解答</summary>

重根条件 $\Delta=4-4c=0$，解得 $c=1$。用代码扫一遍验证：

```python
for c in [-4, -3, -2, -1, 0, 1, 2, 3, 4]:
    delta = 4 - 4*c
    print(c, delta)   # 只有 c=1 时 Δ=0
```

此时 $x^2-2x+1=(x-1)^2$——配方视角下，"$c=$ 一次项系数一半的平方"正是补角成功的时刻。
</details>

## 7. 选读：公式里还藏着韦达定理

<details>
<summary>选读 · 两根之和与两根之积</summary>

把两个根相加：$\pm$ 分支一抵消，只剩 $x_1+x_2=-\dfrac{b}{a}$。相乘则用平方差 $(u+v)(u-v)=u^2-v^2$：

$$x_1\cdot x_2=\frac{(-b)^2-(\sqrt{\Delta})^2}{4a^2}=\frac{b^2-\Delta}{4a^2}=\frac{4ac}{4a^2}=\frac{c}{a}$$

这就是**韦达定理**：不解方程就能知道两根的和与积。数值验证一下练习 2：$x_1+x_2=3+2=5=-b/a$ ✓，$x_1x_2=6=c/a$ ✓。傅里叶变换要反复依赖"只看整体量、不逐个解根"的思想，这颗种子现在就埋下了。

</details>
