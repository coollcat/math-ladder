# 第 60 章专属组件规格

本文件只登记尚未实现的理想教具；正文当前只使用已实现 `viz` 组件和浮窗 Python。

## 公共需求

1. 所有组件用现有 `viz` JSON 围栏接入，失败时显示可读错误；
2. 支持鼠标、触屏和键盘操作，保存视图状态，路由重扫不重复绑定；
3. 暗色模式和移动端可用；动画与仿真必须有步进、暂停、终点和最大步数；
4. 频率平面、层级图和排队系统必须支持 x/y 双轴拖拽或行列联动；
5. 不引用未实现组件名作为正文 `viz type`。

## blackbox-io-probe

- 落点：20 黑箱建模。
- 配置：输入范围、探测点、噪声幅度、响应函数或数据表。
- 必做：在 x/y 平面拖动探针，显示局部割线增益、输出残差和适用区间；支持保存探测序列。

## bode-margin-lab

- 落点：35 频率响应。
- 配置：极点、零点、延迟、增益和穿越频率。
- 必做：幅值图与相位图按频率十字联动；点击任一频率同时显示增益裕度、相位裕度和到临界点的距离。

## nyquist-stability-tour

- 落点：40 Nyquist 判据。
- 配置：开环分子分母、右半平面极点数、参数扫描集合。
- 必做：复平面 x/y 拖拽缩放；高亮 $-1$ 包围关系；正负频率镜像同步；显示 $P$、$N$ 和 $Z$ 的符号约定。

## large-system-hierarchy

- 落点：55 与 60 分解协调。
- 配置：子系统节点、共享资源、时间尺度和边界变量。
- 必做：层级图行列联动，可拖动节点；选中联络线显示流量、价格和约束；调度/监督/局部三层按时间轴对齐。

## fault-tree-editor

- 落点：70 可靠性。
- 配置：顶事件、逻辑门、底事件概率和共因组。
- 必做：拖拽门与事件；枚举最小割集；高亮共因组并对比含/不含相关性的失效概率。

## queue-throughput-lab

- 落点：81 排队论。
- 配置：到达过程、服务分布、通道数、容量上限和优先规则。
- 必做：队列长度曲线与服务台状态行列联动；x/y 拖动选择观察窗口；实时显示利用率、吞吐量、平均等待和瓶颈环节。

## 集成顺序

先实现频率三件套（Bode、Nyquist、灵敏度联查），再实现层级图和排队实验室；黑箱探针可作为通用交互回填第 20 课。所有组件上线前必须通过路由切换、移动端、暗色模式和无重复注入测试。
