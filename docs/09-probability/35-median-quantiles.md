# 中位数、分位数与箱线图

## 1. 从一个场景开始

新闻标题："本市平均住房面积 92 平方米，居住条件宽裕。"评论区却炸了锅——一半家庭晒出的户型不到 70 平。是统计造假吗？不一定：三五个大平层一进场，平均数就被抬上了天。上一课我们亲眼见过"老板月薪五万把平均工资拽翻倍"的现场；那一课只是顺口提了一句"中位数更稳"，这一课就让这位**不被收买的裁判**正式上岗——它是谁、怎么算、有多少坑，以及如何用一张"箱线图"把一组数据的筋骨画在五根线里。

## 2. 直觉解释

**中位数 = 排队站中间的人。** 全体数据按从小到大列队报数，站在正中央的那位就是中位数：它左边和右边的人数永远相等。前面站着一位巨富还是一位普通人，都改变不了"谁在正中央"——队形只动了半步，中心纹丝不动。这正是它抗极端值的道理：均值是称出来的重心，砝码拖多远重心跑多远；中位数是数出来的人口，只认位置不认远近。

偶数个人排队时正中央空着怎么办？让**中间两位手拉手取平均**顶上。

再把这套"看位置"的眼光推广：把队伍切成四段，三个切口分别叫下四分位数 $Q_1$、中位数 $Q_2$、上四分位数 $Q_3$。加上最矮的和最高的共五个数，恰好勾出一组数据的全部骨架——这就是下一节箱线图的原料。

## 3. 正式定义

将 $n$ 个数据从小到大排序后：

| 名称 | 定义 | 备注 |
| --- | --- | --- |
| 中位数 $\mathrm{Med}$ | n 为奇数取正中央那个；n 为偶数取中央两个的平均 | 前 50% 的数据不超过它 |
| 下四分位数 $Q_1$ | 较小一半数据的中位数 | 四分之一的位置 |
| 上四分位数 $Q_3$ | 较大一半数据的中位数 | 四分之三的位置 |
| 四分位距 IQR | $Q_3 - Q_1$ | 中间那 50% 数据挤成的箱长 |
| 五数概括 | 最小值、$Q_1$、$\mathrm{Med}$、$Q_3$、最大值 | 一张箱线图的全部钢筋 |

先立一条诚实声明：$Q_1$、$Q_3$ 的切法在全世界的教材与软件里不止一个流派（要不要把中位数本人算进半边、小数组怎么处理），结论可能相差半个身位。本课统一采用对初学者最直观的**半边中位数法**，并如实告诉你它与某些软件口径的差别——中位数本身没有这个困扰，它的定义天下无歧义。

## 4. 分步例题

**例**：八名同学一分钟跳绳成绩（单位：个）：190, 122, 118, 135, 130, 138, 132, 125。

1. 排队：从小到大排成 118, 122, 125, 130, 132, 135, 138, 190；
2. 找中位（偶数个）：中央两位是 130 和 132，$\mathrm{Med} = \frac{130+132}{2} = 131$；
3. 对照均值：$\mu = \frac{1090}{8} = 136.25$——被 190 那位跳绳健将拽高了 5 个多个，而一半同学其实连 131 都没到；
4. 切两半找 $Q_1, Q_3$：较小四个 118, 122, 125, 130 的中位数为 $\frac{122+125}{2}=123.5$；较大四个 132, 135, 138, 190 的中位数为 $\frac{135+138}{2}=136.5$；
5. 组装五数概括与 IQR：最小值 118，$Q_1=123.5$，$\mathrm{Med}=131$，$Q_3=136.5$，最大值 190，$\mathrm{IQR}=13$；
6. 离群体检：正常须的伸展上限通常取 $Q_3 + 1.5 \times \mathrm{IQR} = 136.5 + 19.5 = 156$——190 远超上限，判定为离群点，画图时它会孤零零挂在须外打点示警。

一句话读数：这组水平整体落在 123 到 137 之间，中间那半撮人抱得很紧；唯一的异常值来自一个体力惊人的个体，而不是全班集体变强了。

### 实验 2（python）：亲手造一台中位数探测仪

库里明明有 `statistics.median` 一行搞定，为什么还要手写？因为"偶数个数"这道坎，只有亲自摔一跤才知道坑在哪：

```python title="中位数探测仪：奇偶分支一个都不能少"
import statistics                # 统计工具库（上一课正式登记过）

def my_median(xs):               # def 定义函数：起名备用（斐波那契课解锁的写法）
    s = sorted(xs)               # sorted：返回从小到大排好的新列表，原列表不动
    n = len(s)
    mid = n // 2                 # // 整除：n 除以 2 落在右半侧的那个索引
    if n % 2 == 1:               # % 求余：余 1 说明是奇数个
        return s[mid]            # 奇数个：正中央独中
    return (s[mid - 1] + s[mid]) / 2   # 偶数个：中央两位手拉手取平均

xs = [190, 122, 118, 135, 130, 138, 132, 125]   # 故意打乱顺序递进来
print(my_median(xs))             # 应打印 131：排序由机器代劳
print(my_median(xs[:7]))         # 切片 [:7] 取前 7 个：变成奇数个的局面
print(statistics.median(xs))     # 官方裁判出庭对账：必须与我方一致
```

小心 `mid` 的暗坑：Python 从 0 开始计数，偶数 8 个时 `mid = 4` 是**右半边的第一个**位置——漏减那个 1，答案就会偏向一边而不自知。

### 实验 3（python）：一张图看穿两组工资

沿用上一课的工资单，老板进场前后各画一张箱线图：

```python title="箱线图上岗：中位线稳如老狗"
import statistics
import matplotlib.pyplot as plt   # 绘图模块，约定别名 plt

staff = [5000, 6000, 7000, 8000, 9000]
boss_in = staff + [50000]         # 列表相加 = 拼接：老板进场，变成 6 个数

plt.boxplot([staff, boss_in])     # 一次画两张箱线图：每张自动装箱、竖须、打离群点
plt.xticks([1, 2], ["员工", "老板进场"])   # 给两根箱子挂名牌
plt.ylabel("月薪（元）")
plt.show()

print(statistics.mean(staff), statistics.median(staff))
print(statistics.mean(boss_in), statistics.median(boss_in))
```

读图对照打印：老板进场，均值从 7000 跳到约 14166，中位数只从 7000 挪到 7500（中央两位取平均）——图上第二根箱子里的黑线几乎没动，只是上须被撑长了一截。**新闻里看到"平均"，先想想箱线图长什么样。**

### 快问快答

```quiz
5 名员工月薪为 5000、6000、7000、8000、9000，老板月薪 50000 也加入统计。平均数与中位数各会发生什么？
- 平均数大涨，中位数只挪一小步 [*]
- 平均数和中位数都几乎不变
- 中位数直接跳到 50000
? 六个数排好队后正中央有两位：第 3 位 7000 和第 4 位 8000，手拉手取平均得 7500——中位数只挪了 500；而平均数被 50000 一脚从 7000 踢到约 14166。极端值收买得了重心，收买不了排在中间的人。
```

## 6. 常见误区

:::warning[常见误区]

- **"你以为偶数个时随便挑中间一个就行。"** 中央有两位，标准做法是取两位的平均（数学惯例）；漏掉任何一位，结果就系统性偏靠一边——实验 2 里那条 `mid - 1` 就是为它留的座位。
- **"你以为箱线图的须尖就是最大最小值。"** 默认须只伸到 $1.5\times\mathrm{IQR}$ 以内的最后一格；出了须的点单独打点，那不是画错了，是仪器在喊"这儿有个离群点，快看"。
- **"你以为 Q1、Q3 各软件一定算同一个数。"** 半边含不含中位数等刀法差异会让结果差半个身位；汇报时注明口径即可，别拿微小分歧当错误打架。

:::

## 7. 练习

**练习 1**：探测仪在偶数个数据时失灵了（能跑，但第二行结果不对）——把它修到通过：

```exercise
# @title: 练习：偶数个数据时谁来当家
# @check: 7000
# @check: 7500.0
# @hint: 偶数个时中央有两位：索引 mid 减 1 和 mid 这两位都得请出来取平均——现在只请了一位。
def my_median(xs):
    s = sorted(xs)
    n = len(s)
    mid = n // 2
    return s[mid]              # ← 能跑，但偶数个时结果偏了！

salaries = [9000, 5000, 8000, 6000, 7000]
team = salaries + [50000]      # 老板进场：现在是 6 个数
print(my_median(salaries))
print(my_median(team))
```

<details>
<summary>点开查看逐步解答</summary>

六个人的队伍排好后是 5000, 6000, 7000, 8000, 9000, 50000，正中央两位是 7000 和 8000，手拉手取平均得 $(7000+8000)/2 = 7500$。修复只需改最后的返回行：

```python
def my_median(xs):
    s = sorted(xs)
    n = len(s)
    mid = n // 2
    if n % 2 == 1:                     # 先分支再行动，像正文那样
        return s[mid]
    return (s[mid - 1] + s[mid]) / 2   # 中央两位各出一个代表
```

第一行的人员工资是 5 个奇数个数据，原代码侥幸答对（正中央就是 7000）；真正的考验全在第二行。判题器两行都要检查——侥幸过不了关。
</details>

**练习 2**：回到例题的跳绳数据。用五数概括和 1.5×IQR 法则，说明 190 为什么被判为离群点；再把 190 换成 150，重新走一遍流程，结论变化了吗？

<details>
<summary>点开查看逐步解答</summary>

190 的情形见例题第 6 步：须的上限 $Q_3+1.5\,\mathrm{IQR} = 156 < 190$，超界即离群。

换成 150 后重算：上半段变为 132, 135, 138, 150，$Q_3 = (135+138)/2 = 136.5$ 不变；上限仍是 156。此时 $150 < 156$，须内收容，不再单独打点——数据没有离散群变成一个温和的大个子，故事从"存在异常个体"变成"整体略有起伏"。同样的法则，换一个数就换了叙事，这正是 boxplot 想提醒的事。
</details>

## 8. 选读证明：中位数凭什么坐在绝对偏差的最小处

<details>
<summary>选读 · 一条关于"公平哨子"的小定理</summary>

设固定一点 $m$，计算所有数据到它的**绝对偏差之和** $\sum_{i=1}^{n}\lvert x_i - m\rvert$。问 $m$ 放在哪里这个总和最小？

直觉版论证：想象数轴上每个数据是一枚士兵，你手持一面旗从最左走到最右。旗右移一小步时，右侧每位士兵的偏差各减一点，左侧每位各增一点——总账的变化等于（左侧人数 − 右侧人数）× 步长。只要右边人更多，继续右移就赚；左边更多就该回撤；旗子停在**两边人数打平**的位置时再无改进余地——那个位置正是中位数 ∎。

这也解释了它的别名**L1 重心**：均值是最小化平方偏差（L2）的重心，两者是"惩罚制度"不同的两个最优解。均值怕远方的极端值，是因为平方把远距离罚得太狠；中位数按人头计票，谁也别想倚远卖乖。这为后续章节讨论稳健估计埋下了种子。

</details>
