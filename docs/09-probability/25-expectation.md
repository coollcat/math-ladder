# 期望：加权平均的随机版

## 1. 从一个场景开始

夜市上有个转盘：转一次花 2 元，指针停在「大奖」区送 10 元，停在「小奖」区送 5 元，其余地方空手而归。摆摊的老板从不担心赔本——不是他运气好，而是他心里有一本账：一晚上上千次转动，单次结果完全没法预言，可「平均每次赔出去多少钱」却精确得像乘法口诀。

保险公司敢白纸黑字承诺赔付，赌场敢开出赔率，彩票公司敢标 2 元一注，靠的都是同一本账。这本账的名字叫**期望**：把每个可能的结果，按它出现的概率加权，算出一个「平均一局」的归宿价。上一课大数定律告诉我们频率会稳住；这一课要算的是——稳住之后，平均一局到底值多少钱。

## 2. 直觉解释

先看你早就会的加权平均：期末总评 = 平时成绩 × 40% + 期末成绩 × 60%。这里的 40% 和 60% 是两块成绩的「话语权」——话语权大的那个数，把平均值拽得更狠。

随机试验里的每个可能结果，天然带着一份话语权，就是它的**概率**。把每个结果乘上自己的概率再全部加起来，得到的就是**期望**——概率版的加权平均。

用天平想更清楚：把转盘的三个奖金 0 元、5 元、10 元当砝码挂在数轴上，砝码重量分别是 0.8 份、0.15 份、0.05 份。天平平衡时支点的位置，就是期望。0.8 份的重量全压在 0 上，所以支点被死死拖向左边——最后落在 1.25 元附近，离 0 比离 10 近得多。

上一课的掷币机也能对上号：把正面记 1、反面记 0，期望就是 $1 \times 0.5 + 0 \times 0.5 = 0.5$——那台机器里蓝色频率曲线最后趴住的 0.5，正是期望这位「归宿」本人。频率向概率收敛，平均结果向期望收敛，是同一条定律的两副面孔。

## 3. 正式定义

设一个随机试验的全部可能结果为 $x_1, x_2, \ldots, x_n$，它们发生的概率分别为 $p_1, p_2, \ldots, p_n$，则**期望**定义为

$$E = x_1 p_1 + x_2 p_2 + \cdots + x_n p_n$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $x_k$ | 可能结果 | 试验可能出现的每一个数（奖金、点数……）|
| $p_k$ | 概率 | 结果 $x_k$ 的话语权；全部 $p_k$ 加起来必须等于 1 |
| $E$ | 期望 | 概率加权的平均：大量重复时「平均一局」的归宿 |

两条自查口诀：

1. 权重体检：$p_1 + p_2 + \cdots + p_n = 1$，加起来不是 1 就说明概率配错了；
2. 结果一个不漏：转盘里「空手」也是个结果（记 0 元），漏掉它期望就会虚高。

## 4. 分步例题

**例 1**：掷一颗均匀骰子，求点数的期望。

1. 列结果：$1, 2, 3, 4, 5, 6$；
2. 配权重：均匀骰子每个点数概率都是 $\frac{1}{6}$；
3. 加权求和：$E = (1 + 2 + 3 + 4 + 5 + 6) \times \frac{1}{6} = \frac{21}{6} = 3.5$；
4. 解读：**3.5 根本不是骰子能掷出的点数**。期望是大量重复后的平均归宿，不承诺任何一次的实际取值。

**例 2**：夜市转盘（转一次 2 元）：0.8 的概率空手（记 0 元），0.15 的概率中 5 元，0.05 的概率中 10 元。求每次的期望奖金。

1. $0 \times 0.8 = 0$；
2. $5 \times 0.15 = 0.75$；
3. $10 \times 0.05 = 0.5$；
4. 加总：$E = 0 + 0.75 + 0.5 = 1.25$ 元。

付 2 元、平均收回 1.25 元，平均每转净亏 0.75 元。一晚上 500 转，老板收 1000 元、平均赔出 $500 \times 1.25 = 625$ 元，稳稳落袋约 375 元。单次输赢全看运气，长期平均却分毫不差地执行期望——这就是「赔率」的来历。

## 5. 动手实验

### 实验 1（viz）：单骰机——亲眼看平均价趴向 3.5

```viz
{
  "type": "dice",
  "dice": 1
}
```

怎么玩：先点几下「掷 1 次」，左上角的均值读数会乱跳——1、5、2，毫无规律；再连点「+50」「+2000」，看着这条读数稳稳贴向理论值 3.5。掷 10 次时的均值和 3.5 相差很远很正常，样本一大，它就乖乖归位：这就是「期望 = 长期平均的归宿」的现场版，和上一课的频率收敛是同一个原理，只是这次收敛的是**平均数**而不是频率。

### 实验 2（python）：把转盘的期望账手算一遍

```python title="转盘期望：结果 × 概率，逐项累加"
probs = [0.8, 0.15, 0.05]            # 三个结果各自的概率
prizes = [0, 5, 10]                  # 对应的奖金（元）

total = 0
for k in range(len(probs)):          # len：列表里装了几个数，这里逐个下标过一遍
    total = total + prizes[k] * probs[k]   # 结果 × 概率，记进总账

print(total)                         # 平均每转的期望奖金
```

输出 1.25，与例 2 手算一致。把 `prizes` 换成你自己设计的奖金表试试——只要概率加起来是 1，这套流水线永远适用。

### 实验 3（python）：模拟一万次转盘，看平均价贴向 1.25

```python title="一万次转盘：累计平均的收敛曲线"
import random                        # 随机数机器（matplotlib 课出生）
import matplotlib.pyplot as plt

running = 0                          # 奖金累计器
avg_hist = []                        # 每一步的"到目前为止平均每次拿多少"

for i in range(1, 10001):            # 玩一万次，i 同时是"已玩局数"
    ticket = random.randint(0, 99)   # 抽一个 0..99 的号码：分三段当概率
    if ticket < 80:                  # 0..79 共 80 个号 -> 概率 0.8，空手
        prize = 0
    elif ticket < 95:                # 80..94 共 15 个号 -> 概率 0.15，中 5 元
        prize = 5
    else:                            # 95..99 共 5 个号 -> 概率 0.05，中 10 元
        prize = 10
    running = running + prize        # 累计进账
    avg_hist.append(running / i)     # 除以已玩局数 = 到目前的平均每转

plt.plot(avg_hist, color="steelblue", label="experiment")
plt.plot([0, 10000], [1.25, 1.25], linestyle="--", color="tomato", label="theory 1.25")
plt.legend()
```

蓝色曲线开头剧烈晃动（几局连不中也正常），几千局后一头扎向红色虚线 1.25。每次运行路径都不同，但归宿从不变——老板的 0.75 元利润就藏在这两条线之间。

### 快问快答

```quiz
转盘期望奖金 1.25 元，转一次付 2 元。连玩一万次后，你大概？
- 赚钱：一万次里总有几次中 10 元
- 平均每转亏 0.75 元，一万次亏约 7500 元 [*]
- 不赚不亏：期望会自己找平
? 每转的"平均账单"是 1.25 元，票面 2 元，差额 0.75 元就是摊主每转的利润。单次全看运气，长期平均忠实执行期望——大数定律在账本上打了卡。
```

::::warning[常见误区]

**误区一**："你以为期望 3.5 说明骰子最爱掷出 3 或 4。" 期望是加权平均的归宿，不是"最常见的结果"。均匀骰子六个点数地位完全相同，3.5 甚至不在可能结果里——"平均归宿"和"单次最可能"是两个问题，第 36 章随机变量课会给这对概念正式分工。

**误区二**："你以为期望 1.25 元就是玩几局就能收到 1.25 元。" 期望不是任何一局的支票，而是海量重复后的平均。前 10 局可能一分没中，也可能连中大奖；想让平均价贴住 1.25，得靠成千上万局新数据来摊平。

**误区三**："你以为亏 0.75 元一转，玩 4 次就精确亏 3 元。" 期望是比例的归宿，不是逐局结算的账单：4 局全空手、或某一局撞上 10 元都完全正常。只有局数越大，"实际平均每转"才越贴近期望。

::::

## 6. 练习

**练习 1（判题）**：本章实战挑战算过：双色球头奖概率是 $\frac{1}{17721088}$，一注 2 元，头奖封顶 1000 万元。只看头奖，一注彩票的"期望奖金"是多少？（保留两位小数）

```exercise
# @title: 练习：这注彩票平均值多少钱
# @check: 0.56
# @hint: 期望奖金 = 奖金 × 中奖概率；现在的代码把概率写死成了 1（必中头奖）——把 p_win 用进乘法
prize = 10000000          # 头奖封顶奖金（元）
p_win = 1 / 17721088      # 头奖概率（本章实战挑战的成果）
value = prize * 1         # ← 每一注都按"必中头奖"在算账，这可能吗？
print(round(value, 2))
```

初始代码输出 10000000.0——它假设你每注必中，账本瞬间变成天文数字。换成用真实概率加权：平均一注只值约 0.56 元，却要付 2 元。彩票公司靠这 1.44 元的差额运营，你买的是那亿分之一的梦，这笔账两不亏欠。

<details>
<summary>点开查看逐步解答</summary>

期望奖金 = 奖金 × 概率：

```python
prize = 10000000
p_win = 1 / 17721088
value = prize * p_win
print(round(value, 2))
```

$10000000 \times \frac{1}{17721088} \approx 0.5643$，保留两位小数为 **0.56** 元。净期望 = $0.56 - 2 = -1.44$ 元——负期望正是"久赌必输"的数学写法，而且输的是平均意义上的定数，不是情绪。

</details>

**练习 2**：抛两枚均匀硬币，数正面个数（可能是 0、1、2）。求正面个数的期望。

<details>
<summary>点开查看逐步解答</summary>

枚举 4 个等可能结果：（反，反）记 0；（正，反）和（反，正）记 1；（正，正）记 2。概率分别为 $\frac{1}{4}$、$\frac{1}{2}$、$\frac{1}{4}$，先做权重体检：$\frac{1}{4} + \frac{1}{2} + \frac{1}{4} = 1$ ✓。

$$E = 0 \times \frac{1}{4} + 1 \times \frac{1}{2} + 2 \times \frac{1}{4} = 0 + 0.5 + 0.5 = 1$$

期望正好是 1——直觉也对得上：两枚硬币平均各贡献 0.5 个正面，合起来 1 个。

</details>

**练习 3**：某游戏掷一颗骰子，掷出 6 点得 6 元，其余点数什么都不得。这个游戏的期望奖金是多少？入场费定成多少才对玩家"公平"？

<details>
<summary>点开查看逐步解答</summary>

只有两个结果：掷出 6（概率 $\frac{1}{6}$，得 6 元）和其他（概率 $\frac{5}{6}$，得 0 元）。

$$E = 6 \times \frac{1}{6} + 0 \times \frac{5}{6} = 1$$

期望奖金 1 元。所以入场费定 1 元时，长期平均下来双方不赚不亏——这就是"公平游戏"的定价法。低于 1 元玩家占便宜，高于 1 元庄家占便宜；夜市转盘 2 元对 1.25 元，正是庄家版定价。

</details>

## 7. 选读：期望的名字从哪来

<details>
<summary>选读 · 1654 年，赌徒的一封信</summary>

1654 年，法国贵族德·梅雷向数学家帕斯卡请教"分赌本问题"：甲乙两人赌局中断时，甲 2 胜乙 1 胜，赌金该怎么分才公平？按已赢局数 2:1 切开听着顺耳，却经不起推敲——如果继续赌，两人最终获胜的机会并不正好是 2:1。

帕斯卡与费马在通信中给出的答案开辟了一条新路：**按"如果赌完，各自最终获胜的概率"加权分钱**。这份"按概率配权的应得份额"，就是期望的雏形；后来的数学家（惠更斯专门写了小册子）把它提炼成今天的定义。E 这个字母来自 Expectation（期望）。

这套"按概率加权"的算法在后面的旅程里会反复返场：第 16 章的傅里叶系数本质上是信号与各谐波的加权平均；第 30 章分析哈希表时，"期望分析"会算出平均一次查找要几步；第 36 章随机变量登台后，期望将与方差配对，成为概率论的双主角。眼下你只需要握住一句话：**期望是概率加权的平均，长期平均的归宿**。

</details>
