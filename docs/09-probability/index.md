# 计数、概率与统计：驯服不确定性

彩票公司敢承诺上千万的头奖，保险公司敢白纸黑字写下赔付条款，气象台敢说"明天降水概率 90%"，医生敢依据一项检出率 99% 的检测下诊断——他们凭什么？没有谁预知未来，他们靠的是同一个事实：**单次的结果没法预言，但大量结果的集体行为精确得出奇**。随机不等于不可研究，它恰恰是数学研究得最透彻的对象之一。

## 实战挑战 · 计数、概率与统计

**改编自真实彩票玩法（中国福利彩票"双色球"；规则是公开事实，概率计算为经典题型）**。上一课我们算过单色版 33 选 6 的 1107568 种组合；真实的双色球还要再加一个蓝球。彩票公司敢明码标价，靠的就是把这道计数题算到底。

**题目**：双色球规则——红球从 01 到 33 里选 **6 个**（不讲顺序），蓝球从 01 到 16 里选 **1 个**。

- (a) 一注单式投注对应多少种等可能的开奖结果？
- (b) 单注中头奖（6 红 + 1 蓝全中）的概率是多少？
- (c) 只看蓝球的话，选中蓝球的概率又是多少？两个概率相差多少倍？

下面的代码把红球组合数算对了，但蓝球被偷懒成了 1 种。修到通过：

```exercise
# @title: 练习：双色球的头奖概率
# @check: 1107568
# @check: 17721088
# @check: 1/17721088
# @hint: 组合 C(33,6) 只数了红球；蓝球是从 16 个号里挑 1 个，有 16 种选法——乘法原理：分步相乘
def comb(n, k):
    result = 1
    for i in range(k):
        result = result * (n - i) // (i + 1)
    return result

red_ways = comb(33, 6)     # 红球：33 选 6 不排队
blue_ways = 1              # ← 蓝球真的只有 1 种可能吗？
total_ways = red_ways * blue_ways

print(red_ways)
print(total_ways)
print(f"1/{total_ways}")   # 头奖概率：全部等可能结果里只有那 1 种全中
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 红球 $C(33,6) = \frac{33 \times 32 \times 31 \times 30 \times 29 \times 28}{6!} = 1107568$ 种；蓝球 $C(16,1) = 16$ 种。按**乘法原理**分两步相乘：$1107568 \times 16 = 17721088$ 种等可能结果。

**(b)** 头奖只认其中 1 种结果，所以 $P(\text{头奖}) = \frac{1}{17721088} \approx 0.0000056\%$——约一千七百七十二万分之一。

**(c)** 只看蓝球：16 个号码挑 1 个，$P = \frac{1}{16} = 6.25\%$。它和头奖概率相差 $\frac{1/16}{1/17721088}=1107568$ 倍——多出来的正是红球组合数。这就是为什么彩票宣传总爱强调"中奖区间宽"：低门槛的小奖由蓝球撑门面，头奖的悬殊概率藏在乘法的第二步里。

验算代码：

```python
def comb(n, k):
    result = 1
    for i in range(k):
        result = result * (n - i) // (i + 1)
    return result

red = comb(33, 6)
total = red * 16
print(red)                 # 1107568
print(total)               # 17721088
print(f"1/{total}")        # 头奖概率 = 1/17721088
```

顺带一算：选中全部六个红球但不看蓝球时，概率是 $\frac{1}{1107568}$；二等奖还要求蓝球不中，所以是 $\frac{15}{17721088}$。买一注花 2 元；即使头奖封顶 1000 万元，仅头奖贡献的期望奖金也只有约 $0.56$ 元（"期望"这套按概率加权的平均算法，正是 [期望：加权平均的随机版](./25-expectation.md) 的主角）。完整奖金结构要另算，但仅这一项已经能看出赔率有多悬殊。

</details>

## 实战挑战 · 掷两枚骰子，和为 7

古典概型的铁律：概率 = 有利结果数 ÷ 全部结果数。掷两枚骰子共 $6\times6=36$ 种等可能结果，其中和为 7 的有 6 种。下面这题分母写错了，修到输出 `0.1667`：

```exercise
# @title: 实战挑战：骰子点数和为 7 的概率
# @check: 0.1667
# @hint: 两枚骰子共 6×6=36 种结果；分子已经是 6，把分母改对即可。
favorable = 0
for a in range(1, 7):          # 第一枚骰子的点数 1..6
    for b in range(1, 7):      # 第二枚骰子的点数 1..6
        if a + b == 7:         # 点数和为 7 就算一次有利
            favorable = favorable + 1

p = favorable / 35             # ← 问题在这：总数应该是 36
print(round(p, 4))
```

<details>
<summary>点开查看逐步解答</summary>

两枚骰子各有 6 个面，结果总数是 $6 \times 6 = 36$，不是 35：

```python
p = favorable / 36    # 6 种有利结果 ÷ 36 种总结果
print(round(p, 4))    # 0.1667
```

改完：$P(\text{和为 }7) = \frac{6}{36} = \frac{1}{6} \approx 0.1667$。这 6 种有利结果正是 $(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)$。古典概型"数两遍"——分子分母各数一遍——就是它全部的要领。

</details>
