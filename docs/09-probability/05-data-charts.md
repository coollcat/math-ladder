# 数据分类与直观统计

## 1. 从一个场景开始

班里收集了一周喝奶茶的数据：有人记录口味，有人记录杯数，有人只拍了小票。原始数据像一筐没有贴标签的积木——不是没用，而是还没分类。

统计的第一步不是画图，而是问：**我们到底想比较什么？** 是喜欢哪种口味的人最多，还是哪种口味的总销量最高？问题不同，同一堆数据会讲出不同重点。

## 2. 直觉解释

数据可以先按“类别”整理：

- 水果茶、珍珠奶茶、咖啡拿铁是**类别**；
- 每类出现的次数叫**频数**；
- 频数除以总数就是**占比**。

比如 20 杯饮品里有 8 杯水果茶：

$$\text{水果茶频数}=8,\qquad \text{占比}=\frac{8}{20}=40\%$$

条形图适合比较类别：柱子越高，代表数量越多。但柱子的高度必须从合理的起点开始，否则眼睛会被骗。

## 3. 正式定义

**分类数据**：只能归入不同类别，不能自然做加减的数据，如颜色、口味、交通方式。

**数值数据**：表示数量或测量结果，可以做加减比较，如身高、价格、天数。它的画法不同：通常先把数值分进相邻区间、数清各区间频数再作图（这样的图叫直方图），或沿时间轴连成折线——本课集中练分类数据的条形图，数值数据的图表留给后续课程。

有些类别自带顺序，例如“不满意、一般、满意”。它们仍可先按分类计数并画条形图；除非已经明确说明等级编码规则，否则不要把标签当成可以随意加减的数。

| 数据 | 类别 | 频数 | 占比 |
| --- | --- | ---: | ---: |
| 水果茶 | 水果茶 | 8 | 40% |
| 珍珠奶茶 | 珍珠奶茶 | 7 | 35% |
| 美式咖啡 | 美式咖啡 | 5 | 25% |

三列的关系是：

$$\text{占比}=\frac{\text{该类频数}}{\text{总频数}}\times100\%$$

## 4. 分步例题

**例**：小组记录 10 位同学上学方式：步行 4 人、骑车 3 人、坐车 2 人、轮滑 1 人。

1. 找出类别：步行、骑车、坐车、轮滑。
2. 数频数：4、3、2、1；检查总和 $4+3+2+1=10$。
3. 算占比：步行 $40\%$，骑车 $30\%$，坐车 $20\%$，轮滑 $10\%$。
4. 排序回答：“步行最多”比“大家上学方式很多”更精确。
5. 谨慎推广：这只是 10 位同学的小样本，不能直接断言全校都是步行最多。

## 5. 动手实验

柱子显示三类的固定频数；按钮会在“零基线”和“非零基线”之间切换。先看普通视图感受差距，再切换纵轴，看看同一个数据如何变得夸张。

```viz
{
  "type": "datachart",
  "labels": ["步行", "骑车", "坐车"],
  "values": [4, 3, 2]
}
```

零基线时，“步行比坐车多 2 人”只是温和的差别；非零基线可能让步行看起来像坐车的许多倍。看图前先读纵轴，是数据素养的基本动作。

下面的 Python 块把频数表重新算一遍：

```python title="从频数算百分比"
labels = ["步行", "骑车", "坐车", "轮滑"]   # 列表：按顺序存放类别名
counts = [4, 3, 2, 1]                       # 对应类别的出现次数
total = sum(counts)                         # sum：把列表里的数加起来

for i in range(len(labels)):                # len：列表长度；range 生成下标序列
    percent = counts[i] / total * 100       # / 得到比例，再乘 100 变成百分数
    print(f"{labels[i]}：{counts[i]} 人，{percent:.0f}%")   # :.0f 表示格式化成整数百分数

print(f"检查总数：{total}")
```

如果 `sum(counts)` 不等于你以为的样本人数，说明有漏记或重复记录。统计图出错，常常不是画图那一步，而是源头没核对。

### 快问快答

```quiz
下面哪一项最适合用条形图比较？
- 不同上学方式的人数 [*]
- 一位同学每天体温连续变化
- 一个正方形的边长和面积关系
? 条形图擅长比较互不相连的类别；连续变化更适合折线图，两个量的关系更适合函数图像。
```

:::warning[常见误区]

**误区一**：“柱子差一点，数量就差一点。”
如果纵轴不从 0 开始，视觉差距会被放大。先看刻度，再看柱子。

**误区二**：“频数高的类别一定更重要。”
“重要”取决于问题。销量最高的饮品不一定利润最高，也不一定是同学们最喜欢讨论的对象。

**误区三**：“图表看起来精确，所以结论可靠。”
图表只能忠实呈现样本。10 人的班级调查不能自动代表全校，更不能代表所有学校。

:::

## 6. 练习

**练习 1**：20 名同学选择社团：篮球 6 人、绘画 7 人、编程 4 人、合唱 3 人。打印编程社团的占比百分数数值。

```exercise
# @title: 练习：计算编程社团占比
# @check: 20.0
# @hint: 编程有 4 人，总人数是四类之和；先算 4/20，再乘 100。题目要求打印百分数的数值，不要带 % 号。
basketball = 6
art = 7
coding = 4
singing = 3
total = basketball + art + coding + singing
print(coding * 100)
```

<details>
<summary>点开查看逐步解答</summary>

总人数是 $6+7+4+3=20$。占比要拿编程人数除以总数，再乘 100：

```python
basketball = 6
art = 7
coding = 4
singing = 3
total = basketball + art + coding + singing
print(coding / total * 100)
```

</details>

**练习 2**：一张条形图的纵轴从 95 开始到 100，三个类别的真实值分别是 96、97、99。

<details>
<summary>点开查看逐步解答</summary>

真实差距只有 1 和 2；但从 95 起的纵轴会让 99 的柱子显得比 96 高很多。更公平的做法是从 0 开始画，或在标题里明确说明“纵轴不从 0 开始”并附上具体数值表。
</details>

**练习 3**：下面三种问题分别适合统计什么？

1. 同学们最喜欢哪种运动？
2. 一天中教室温度如何变化？
3. 学习时间越长，测验分数是否更高？

<details>
<summary>点开查看答案</summary>

1. 适合分类频数条形图；
2. 适合时间折线图；
3. 需要成对数值数据，后续可以用散点图或拟合直线观察趋势。
</details>

## 7. 选读：分类前的三个问题

<details>
<summary>选读 · 让数据开口前先提问</summary>

拿到原始数据前，先问三件事：

1. **单位是谁？** 统计“人”“杯”“次”会得到不同结论；
2. **时间范围是什么？** 只记录周五和记录一周，奶茶销量当然不同；
3. **有没有缺失？** 未填问卷的人不属于任何一个类别，直接丢弃可能造成偏差。

这三问不能保证结论正确，但能挡住大多数“看起来很漂亮”的粗心统计。
</details>
