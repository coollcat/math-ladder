# 排列与组合：数清楚每一种可能

## 1. 从一个场景开始

中国福利彩票的一种经典玩法：从 33 个号码里挑 6 个，全中即头奖。开奖前没人知道结果，但彩票公司敢精确承诺头奖奖金——因为它早就算清了一件事：**总共只有多少种选法**。

这个数字是 $1107568$，也就是说单注命中那一个红球组合的机会只有 $\frac{1}{1107568}$（下一课会把这种长期稳定的机会份额正式叫作概率），约百万分之一（精确地说是 111 万分之一）。它不是估出来的，是一步一步**数**出来的。本课就学这套数法：搭配、排队、组队，各有一把尺子。

## 2. 直觉解释

最基础的问题：早上穿衣服，3 顶帽子和 4 条围巾，能搭出几身造型？

答案是 $3 \times 4 = 12$：每选一顶帽子（3 种），围巾都有 4 条可选。这种"一步一步选，选择数相乘"的口诀叫**乘法原理**——它是所有计数的发动机。

再往前一步。班里要从 8 名志愿者里选 2 人：

- 选"正队长 + 副队长"：先正后副，名单有顺序；
- 选"两人小队"：一锅人，不分谁先谁后。

这两种数出来**不一样多**。"顺序要不要紧"就是排列与组合的分水岭——后面所有的公式都长在这句话上。

## 3. 正式定义

**乘法原理**：一件事分 $k$ 步完成，第 $i$ 步有 $n_i$ 种选法，则总方案数为

$$n_1 \times n_2 \times \cdots \times n_k$$

**阶乘**：为了写短连乘，数学家发明了记号 $n!$（读作"n 的阶乘"）：

$$n! = n \times (n-1) \times (n-2) \times \cdots \times 2 \times 1$$

**排列**：从 $n$ 个不同物件里有顺序地取出 $k$ 个排好，方法数记作 $P(n,k)$：

$$P(n,k) = \frac{n!}{(n-k)!} = \underbrace{n \times (n-1) \times \cdots}_{k \text{ 个因子}}$$

**组合**：只要其中 $k$ 个、不排顺序，方法数记作 $C(n,k)$：

$$C(n,k) = \frac{n!}{k!\,(n-k)!}$$

| 记号 | 名字 | 一句话含义 |
| --- | --- | --- |
| $n_1 \times \cdots \times n_k$ | 乘法原理 | 分步相乘 |
| $n!$ | 阶乘 | 从 $n$ 一路乘到 1 |
| $P(n,k)$ | 排列数 | 选 $k$ 个还要排队 |
| $C(n,k)$ | 组合数 | 选 $k$ 个不问次序 |

两者的关系一句话：**每个组合内部都有 $k!$ 种排队方式**，所以 $P(n,k) = C(n,k) \times k!$——这就是除以 $k!$ 的来历。

## 4. 分步例题

**例**：8 名志愿者里选 2 人，两种任务分别有多少种安排法？

1. **任务 A：选正、副队长**（顺序要紧）。第一个位置 8 种人选，第二个位置剩 7 种：$8 \times 7 = 56$，即 $P(8,2) = 56$；
2. **任务 B：选两人小队**（顺序不要紧）。先按任务 A 数出 56 张"有序名单"，但同一对人被数了 $2! = 2$ 次（甲正乙副、乙正甲副）；
3. 除掉重复：$56 \div 2 = 28$，即 $C(8,2) = 28$；
4. 对照公式：$C(8,2) = \dfrac{8!}{2!\,6!} = \dfrac{8 \times 7}{2 \times 1} = 28$。✓

判断口诀：**交换两个选中对象的位置，如果算成不同方案，用排列；如果无所谓，用组合。**

## 5. 动手实验

### 实验 1（viz）：排列与组合同框

左边是“只挑团队”：同一批圆点不管怎么换位置，都还是同一个组合。右边是“还要排队”：换个站位就是一条新的排列。先玩这组对照，再看下面的公式，就不容易把两者混起来。

```viz
{
  "type": "counting",
  "n": 6,
  "k": 2
}
```

把 $k$ 拖大，右边比左边涨得快得多。多出来的部分不是新的人，而是同一团队内部的排队方式。

### 实验 2（python）：math.factorial 的出生证明

想算 $15!$？手写连乘循环试试（拖动滑块换更大的 $n$，体会它涨得多快）：

```python title="没有阶乘记号的日子：手写循环连乘"
# sliders: n=15 [1:20:1]

product = 1                    # 连乘器：从 1 出发，逐个乘上去
for i in range(1, n + 1):      # range(1, n+1)：依次取 1, 2, ..., n
    product = product * i      # 把 i 乘进连乘器
print(product)
```

每遇到一个新数字都要重新跑一遍循环，啰嗦得让人起疑："连乘"这么常用的动作，该有个专属记号吧？

### 实验 3（python）：math.factorial 正式登场

Python 把这个动作做成了官方工具：

```python title="math.factorial：阶乘一键出厂"
import math

print(math.factorial(15))   # factorial：阶乘 n! 的官方实现，一行顶一个循环
print(math.factorial(0))    # 数学规定 0! = 1——选读里解释为什么必须这样定
```

从此计数公式都能一行落地。注意实验 2 的滑杆拧到 $20$ 时，$20!$ 已经超过 243 亿亿——阶乘比乘方爆炸得更凶（误区二细说）。

### 实验 4（python）：排列与组合落地，顺便算清彩票

```python title="彩票头奖概率：C(33,6) 分之一"
import math

def perm(n, k):    # P(n,k)：选 k 个还排队
    return math.factorial(n) // math.factorial(n - k)   # // 是整除：结果仍是整数

def comb(n, k):    # C(n,k)：选 k 个不排队
    return math.factorial(n) // (math.factorial(k) * math.factorial(n - k))

print(f"P(8,2) = {perm(8, 2)}")
print(f"C(8,2) = {comb(8, 2)}")

ways = comb(33, 6)
print(f"33 选 6 共 {ways} 种等可能组合")
print(f"单注命中头奖的概率 = 1/{ways}")
```

$1107568$ 种可能里挑那一种——相当于把一百多万张彩票铺满十张乒乓球桌，只许摸一张。现在你知道彩票公司的底气从哪来了。

### 实验 5（python 滑块）：双滑杆对照，“排队税”$k!$

```python title="同一个 (n, k)：P 与 C 差多少"
import math

# sliders: n=8 [6:12:1], k=2 [1:6:1]

p = math.factorial(n) // math.factorial(n - k)   # 排列 P(n,k)：选 k 个还要排队
c = p // math.factorial(k)                       # 组合 C(n,k)：再除掉组内的排队方式
print(f"P({n}, {k}) = {p}")
print(f"C({n}, {k}) = {c}")
print(f"P ÷ C = {math.factorial(k)} —— 恰好是 k!（每个组合内部的队形数）")
```

怎么玩：默认 $P(8,2)=56$、$C(8,2)=28$，正是第 4 节例题的两个答案，比值恰好是 $2!=2$。把 k 拖到 1：两数相等——只选一个人谈不上顺序，"排队税"是零；拖到 5、6：差距拉开到几十上百倍，队伍越长，"顺序要不要紧"的代价越恐怖。

### 快问快答

```quiz
从 8 名志愿者中安排任务，哪个说法正确？
- 选正、副队长有 56 种，选两人小队只有 28 种 [*]
- 两种安排都有 56 种
- 选正、副队长有 28 种，选两人小队反而有 56 种
? 先数有序名单得到 8 × 7 = 56；两人小队不分先后，同一对人被甲正乙副、乙正甲副数了两次，所以要除以 2!，得 28。
```

:::warning[常见误区]

**误区一**："反正都是选两个人，排列和组合一样。"
只要任务身份不同（正、副队长），交换两个人就算新方案；只是组队时才把内部队形折叠掉。

**误区二**："组合公式里的 $k!$ 可以忘掉。"
$P(n,k)$ 数的是队形，$C(n,k)$ 数的是团队。每个团队内部恰有 $k!$ 种队形，所以必须用 $P(n,k)$ 除以 $k!$。

**误区三**："空集没有东西可乘，所以 $0!$ 应该是 0。"
阶乘回答"排法数"。零个对象只有一种排法：什么都不做。下一节选读还会用组合公式验一遍。

:::

**练习 2**：判断下面该用排列还是组合，并说出理由：从 10 首歌里选 3 首做播放清单；从 10 首歌里选 3 首放进“今日推荐”集合。

<details>
<summary>点开查看逐步解答</summary>

播放清单有顺序，用排列：$P(10,3)=10\times9\times8=720$。

推荐集合不问顺序，先用排列数出 720 个有序方案，再除掉每个三人集合内部的 $3!=6$ 种排序：$C(10,3)=720\div6=120$。
</details>

## 7. 选读：为什么 0!=1，杨辉三角在哪里

<details>
<summary>选读 · 空队形与三角形种子</summary>

先看一个最小的组合：从 $n$ 个人里选 0 个人，显然只有“谁都不选”这一种办法，所以 $C(n,0)=1$。代入组合公式：

$$C(n,0)=\frac{n!}{0!\,n!}=1$$

要让等式成立，$0!$ 只能等于 1。也可以从排队的角度说：零个对象的排法只有一种——什么都不做。

再让组合彼此搭一层楼。从 5 个人里选 2 人时，可以盯住其中一个人“小安”：选小安，再从剩下 4 人里选 1 人；不选小安，则要从剩下 4 人里选满 2 人。一般写成单行递推就是：

$$C(n,k)=C(n-1,k-1)+C(n-1,k)$$

这里默认 $0 \le k \le n$；递推碰到边界时，把“选负几个人”或“选出比现有总数还多的人”这类不存在的选法记作 $0$。

把所有 $C(n,k)$ 按楼层摆开，每个数恰好是肩上两数之和——这就是中国的杨辉三角（欧洲称帕斯卡三角，杨辉早了近四百年）。它的系统展开会放到卷三的组合数学章；那里会把这颗种子长成二项式系数和递推实验。

</details>
