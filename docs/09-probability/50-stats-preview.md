# 正态、回归与独立性检验：统计三件常用工具

## 1. 从一个场景开始

三份材料摆在同一张办公桌上：

- **年级成绩单**：800 人的数学成绩近似钟形，均分 75、标准差 8。前 16% 的划线大概在哪？
- **广告报表**：过去 5 个月的广告投入与销售额，能画一条直线预报下个月吗？
- **药效报告**：服药组 100 人有效 60 人，对照组 100 人有效 45 人。这药真有效，还是随机波动？

这三问对应统计里最常用、也最早被需要的三件工具：**正态曲线**、**回归直线**、**独立性检验**。

先把话说在前面：它们在本站的系统讲解分别落在第 36 章（概率进阶）、第 38 章（统计推断）、第 45 章（机器学习数学）。**这一课的定位是"先会用、后溯源"**——把公式和判别口径交到你手上，能做题、能读懂报告，但不假装讲清了来龙去脉。每块末尾都标了去哪一章溯源。

## 2. 直觉解释

三件工具看着风马牛不相及，其实是同一个动作演了三遍：**先立一个模型，再量数据与模型的落差**。

| 工具 | 先假设的模型 | 拿什么量"落差" |
| --- | --- | --- |
| 正态曲线 | 数据服从一口钟 | 这个数离均值有几个 $\sigma$ |
| 回归直线 | 两列数据近似一条直线 | 每个点**竖着**到直线的距离 |
| 独立性检验 | 两个分类变量**无关** | 实际列联表与"无关时应有的样子"差多远 |

模型给出"本来应该是什么样"，数据给出"实际是什么样"，落差越大结论越强。区别只在量落差的那把尺子。

## 3. 正式定义

### (a) 正态曲线

若随机变量 $X$ 的密度曲线为下式，就说 $X$ 服从**正态分布** $N(\mu,\sigma^2)$：

$$f(x)=\frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mu$ | 均值 | 对称轴的位置，也是数据的重心 |
| $\sigma$ | 标准差 | 曲线的胖瘦：越大越矮胖 |
| $\sigma^2$ | 方差 | 标准差的平方，正态分布的第二个参数 |
| $f(x)$ | 密度 | **不是概率**；概率是曲线下方的面积 |

四条一眼可见的性质：钟形、单峰、关于直线 $x=\mu$ 对称、曲线与横轴之间的总面积等于 1。

**3σ 原则**（读钟形的口诀）：$\mu\pm\sigma$ 罩住 **68.3%**，$\mu\pm2\sigma$ 罩住 **95.4%**，$\mu\pm3\sigma$ 罩住 **99.7%**。

**标准化**：$Z=\dfrac{x-\mu}{\sigma}$ 把任何正态分布搬到标准正态 $N(0,1)$ 上，$Z$ 读出来就是"这个值离均值几个 $\sigma$"。$\mu=75$、$\sigma=8$ 时，$x=91$ 的 $Z=2$。

> **溯源**：密度里那个 $e$ 与 $\pi$ 从哪来、为什么总面积恰好是 1、三个百分数怎么积出来——第 36 章概率进阶。

### (b) 线性回归

对 $n$ 对数据 $(x_i,y_i)$，**最小二乘直线** $\hat y=a+bx$ 的斜率与截距为

$$b=\frac{\sum (x_i-\bar x)(y_i-\bar y)}{\sum (x_i-\bar x)^2},\qquad a=\bar y-b\bar x$$

**相关系数**（衡量点贴直线的紧密程度与方向）：

$$r=\frac{\sum (x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum (x_i-\bar x)^2\ \sum (y_i-\bar y)^2}}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\bar x,\ \bar y$ | 样本均值 | 两列数据各自的中心 |
| $b$ | 斜率 | $x$ 每多 1，$y$ 平均多 $b$ |
| $a$ | 截距 | $x=0$ 时直线的高度 |
| $\hat y$ | 预报值 | 把某个 $x$ 代进直线得到的估计，不是实测值 |
| $r$ | 相关系数 | $-1\le r\le1$；$|r|$ 越接近 1 越像直线，符号定方向 |

读 $r$ 的口诀：$r>0$ 同涨同落，$r<0$ 一涨一落；$|r|\ge0.75$ 算强，$0.3$ 上下算弱。注意 $r\approx0$ 只说明**没有直线关系**，不说明没有任何关系——点可能排成一个弯。

> **溯源**：为什么"竖着量距离、取平方和、再求最小"恰好给出上面两个式子（正规方程），以及 $r$ 为什么被夹在 $[-1,1]$ 之间——第 45 章机器学习数学。

### (c) 独立性检验

把两个分类变量交叉计数，得到 $2\times2$ **列联表**：

|  | 具有特征 $B$ | 不具有 $B$ | 合计 |
| --- | --- | --- | --- |
| 属于 $A$ 组 | $a$ | $b$ | $a+b$ |
| 不属于 $A$ 组 | $c$ | $d$ | $c+d$ |
| 合计 | $a+c$ | $b+d$ | $n$ |

**$\chi^2$ 统计量**（读作"卡方"）：

$$\chi^2=\frac{n(ad-bc)^2}{(a+b)(c+d)(a+c)(b+d)}$$

算出来后与临界值比一比就下结论：

| $P(\chi^2\ge k_0)$ | 0.10 | 0.05 | 0.010 | 0.001 |
| --- | --- | --- | --- | --- |
| 临界值 $k_0$ | 2.706 | 3.841 | 6.635 | 10.828 |

判据：$\chi^2>3.841$ 说"**有 95% 的把握认为两者有关**"；$\chi^2>6.635$ 则"有 99% 的把握"；$\chi^2\le2.706$ 时"没有充分证据认为有关"。

直觉在 $ad-bc$ 这一项：两组若真没差别，两行比例应相同，即 $\dfrac{a}{a+b}=\dfrac{c}{c+d}$，交叉相乘正是 $ad=bc$。所以 $|ad-bc|$ 越大，差别越不像随机波动。

> **溯源**：这个分式为什么服从 $\chi^2$ 分布、自由度为什么是 1、临界值表怎么算出来、$p$ 值的准确含义——第 38 章统计推断。

## 4. 分步例题

**例 1（正态）**：成绩 $X\sim N(75,\,8^2)$。

1. 定位：$91=75+2\times8=\mu+2\sigma$，即 $Z=2$；
2. $P(X>91)$：$\mu\pm2\sigma$ 罩住 95.4%，余下 4.6% 被对称性平分到左右两尾，右侧占 $2.3\%$；
3. 前 16% 的分数线：$\mu+\sigma=83$ 以上占 $(1-68.3\%)\div2=15.85\%\approx16\%$，故划线约在 **83 分**。

**例 2（回归）**：5 个星期的每周学习时长（百小时）与测验成绩：

| $x$ | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| $y$ | 50 | 55 | 62 | 68 | 75 |

1. 求中心：$\bar x=3$，$\bar y=62$；
2. 交叉乘积和：$(-2)(-12)+(-1)(-7)+0\cdot0+1\cdot6+2\cdot13=63$；
3. $x$ 的偏差平方和：$4+1+0+1+4=10$；
4. 斜率 $b=\dfrac{63}{10}=6.3$，截距 $a=62-6.3\times3=43.1$，得 $\hat y=43.1+6.3x$；
5. 相关系数：$y$ 的偏差平方和 $=144+49+0+36+169=398$，$r=\dfrac{63}{\sqrt{3980}}\approx0.9986$——极强正相关；
6. 预报：时长 6（百小时）时 $\hat y=43.1+6.3\times6=80.9$。

**例 3（独立性检验）**：调查 200 名学生的运动时长与近视情况：

|  | 近视 | 不近视 | 合计 |
| --- | --- | --- | --- |
| 运动 ≥1h | 30 | 70 | 100 |
| 运动 <1h | 50 | 50 | 100 |
| 合计 | 80 | 120 | 200 |

1. 对号入座：$a=30,\ b=70,\ c=50,\ d=50,\ n=200$；
2. 交叉落差：$ad-bc=30\times50-70\times50=-2000$（负号无关紧要，下一步要平方）；
3. 分母：$(a+b)(c+d)(a+c)(b+d)=100\times100\times80\times120=96000000$；
4. $\chi^2=\dfrac{200\times(-2000)^2}{96000000}=\dfrac{800000000}{96000000}\approx8.333>6.635$，**有 99% 的把握认为"运动时长"与"近视"有关**。

注意分寸：这句话只说"两者不独立"，**没有说**"运动少导致近视"。

- 拖 **m**：整口钟左右平移，形状分毫不变——$m$ 就是 $\mu$，只管位置；

- 把 $s$ 定在 1，在横轴上找到 $x=m$、$x=m\pm s$、$x=m\pm2s$，对照 3σ 表体会"±1σ 罩住中间那 68%"。

式子里的 $2.5066$ 是 $\sqrt{2\pi}$ 的近似值，$1/2.5066\approx0.3989$ 正是标准正态的峰高；`abs(s)` 只是防止把 $s$ 拖过 0 时曲线翻到横轴下面。

### 实验 3（python）：把例 2 的回归三件套手算一遍

```python title="最小二乘：斜率、截距、相关系数、预报"
import math                            # 数学库（第 3 章开方课出生）

xs = [1, 2, 3, 4, 5]
ys = [50, 55, 62, 68, 75]

mx = sum(xs) / len(xs)                 # x 的中心
my = sum(ys) / len(ys)                 # y 的中心

sxy = 0
sxx = 0
syy = 0
for i in range(len(xs)):
    sxy = sxy + (xs[i] - mx) * (ys[i] - my)   # 交叉乘积和
    sxx = sxx + (xs[i] - mx) ** 2             # x 的偏差平方和
    syy = syy + (ys[i] - my) ** 2             # y 的偏差平方和

b = sxy / sxx                          # 斜率
a = my - b * mx                        # 截距
r = sxy / math.sqrt(sxx * syy)         # 相关系数

print(round(b, 1))
print(round(a, 1))
print(round(r, 4))
print(round(a + b * 6, 1))             # 用直线预报 x = 6
```

输出 `6.3`、`43.1`、`0.9986`、`80.9`，与例 2 手算一致。

### 实验 4（python）：造一万名"学生"，数一数 ±σ 里真有 68% 吗

```python title="生成一万个正态数据，验证 3σ 原则"
import random                          # 随机数机器（第 20 课出生）
import statistics                      # 统计工具库（第 30 课出生）

data = []
for i in range(10000):
    data.append(random.gauss(75, 8))   # gauss(均值, 标准差)：造一个正态随机数

mu = statistics.mean(data)
sd = statistics.pstdev(data)

in1 = 0
in2 = 0
for x in data:
    d = abs(x - mu)                    # 这个数离均值多远
    if d <= sd:
        in1 = in1 + 1                  # 落在 ±1σ 内
    if d <= 2 * sd:
        in2 = in2 + 1                  # 落在 ±2σ 内

print(round(mu, 1))
print(round(sd, 1))
print(round(in1 / len(data), 3))
print(round(in2 / len(data), 3))
```

输出大约 `75.0`、`8.0`、`0.683`、`0.954`（每次略有出入）。再把 `8` 改成 `15` 跑一遍：$\mu$ 与 $\sigma$ 都变了，那两个比例却几乎不动——标准化 $Z=(x-\mu)/\sigma$ 已经把尺度信息整个除掉了，这正是它能通用的原因。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为 3σ 的三个百分数对任何数据都成立。" 它们只对**近似正态**的钟形数据成立。收入、房价、点击量这类右偏数据，$\mu\pm\sigma$ 罩住的比例会明显偏离 68%。用之前先看形状——[中位数、分位数与箱线图](./35-median-quantiles.md) 里的箱线图就是干这个的。

**误区二**："你以为回归直线能一路往外预报。" 直线是在观测到的 $x$ 范围内拟合出来的，往外**外推**极其危险：把例 2 的直线用到 $x=50$（五千小时），预报成绩是 $358$ 分。另外强相关不等于因果——冰淇淋销量与溺水人数高度正相关，共同的推手是气温。

**误区三**："你以为 χ² 越大，关系越强。" $\chi^2$ 同时受"关联强度"和"样本量"支配：样本翻 10 倍而关联强度不变，$\chi^2$ 也跟着涨。所以它回答的是"能不能排除随机波动"，不是"关联有多强"。

:::

## 7. 练习

**练习 1（判题）**：对 $x=[1,2,3,4,5]$、$y=[50,55,62,68,75]$，求最小二乘直线的斜率、截距，并预报 $x=6$ 时的成绩（各保留 1 位小数）。下面的代码把斜率的分母算错了，改到通过：

```exercise
# @title: 练习：最小二乘直线的斜率、截距与预报
# @check: 6.3
# @check: 43.1
# @check: 80.9
# @hint: 斜率 b = Σ(x−x̄)(y−ȳ) ÷ Σ(x−x̄)² —— 分母是 x 自己的偏差平方和，不是 y 的
xs = [1, 2, 3, 4, 5]
ys = [50, 55, 62, 68, 75]

mx = sum(xs) / len(xs)                 # x 的中心
my = sum(ys) / len(ys)                 # y 的中心

sxy = 0
sxx = 0
for i in range(len(xs)):
    sxy = sxy + (xs[i] - mx) * (ys[i] - my)   # 交叉乘积和
    sxx = sxx + (ys[i] - my) ** 2             # ← 这一行累加的是谁的偏差平方？

b = sxy / sxx                          # 斜率
a = my - b * mx                        # 截距
print(round(b, 1))
print(round(a, 1))
print(round(a + b * 6, 1))             # 预报 x = 6
```

初始输出 `0.2`、`61.5`、`62.5`——整条直线几乎躺平，因为分母错用了 $y$ 的偏差平方和（398）而不是 $x$ 的（10）。改对后输出 `6.3`、`43.1`、`80.9`。

<details>
<summary>点开查看逐步解答</summary>

1. $\bar x=3$，$\bar y=62$；
2. $\sum(x_i-\bar x)(y_i-\bar y)=63$，$\sum(x_i-\bar x)^2=10$；
3. $b=63/10=6.3$，$a=62-6.3\times3=43.1$；
4. $x=6$ 时 $\hat y=43.1+6.3\times6=80.9$。

修正代码：`sxx = sxx + (xs[i] - mx) ** 2`。顺手算相关系数：$r=\frac{63}{\sqrt{10\times398}}\approx0.9986$——极强正相关，用直线描述这批数据是合适的。

</details>

**练习 2（判题）**：200 名学生的运动时长与近视情况（列联表见例 3），求 $\chi^2$（保留 4 位小数）。下面的代码漏了公式最前面那个 $n$，改到通过：

```exercise
# @title: 练习：列联表的卡方统计量
# @check: 8.3333
# @hint: χ² = n(ad−bc)² ÷ [(a+b)(c+d)(a+c)(b+d)]；最前面那个 n 是样本总量，别漏乘
a = 30; b = 70        # 运动≥1h：近视 30 人，不近视 70 人
c = 50; d = 50        # 运动<1h：近视 50 人，不近视 50 人
n = a + b + c + d

chi2 = (a * d - b * c) ** 2 / ((a + b) * (c + d) * (a + c) * (b + d))
print(round(chi2, 4))
```

初始输出 `0.0417`——比 3.841 小得多，会误判成"无关"。乘上 $n=200$ 后得 `8.3333`，超过 6.635，结论是"有 99% 的把握认为两者有关"。

<details>
<summary>点开查看逐步解答</summary>

1. $ad-bc=30\times50-70\times50=-2000$，平方得 $4000000$；
2. 分母 $(a+b)(c+d)(a+c)(b+d)=100\times100\times80\times120=96000000$；
3. 乘上样本总量：$\chi^2=\dfrac{200\times4000000}{96000000}\approx8.3333>6.635$，有 99% 的把握认为两者有关。

修正代码：`chi2 = n * (a * d - b * c) ** 2 / ((a + b) * (c + d) * (a + c) * (b + d))`。

那个 $n$ 不是可有可无的：漏掉它，$\chi^2$ 会随样本量增大而**变小**——样本越多反而越难下结论，正好和统计直觉相反。

</details>

**练习 3**（思考）：某次考试 $X\sim N(70,\,10^2)$。85 分的 $Z$ 是多少？估计成绩落在 50 到 90 之间的比例；小李考了 90 分，他大约超过了百分之多少的同学？

<details>
<summary>点开查看逐步解答</summary>

1. $Z=\dfrac{85-70}{10}=1.5$，读作"85 分比均值高 1.5 个标准差"；
2. $50=\mu-2\sigma$，$90=\mu+2\sigma$，区间 $[\mu-2\sigma,\ \mu+2\sigma]$ 罩住 **95.4%**；
3. $Z=2$ 时右侧尾巴占 $4.6\%\div2=2.3\%$，小李大约超过了 $97.7\%$ 的同学。

这套估算依赖"成绩近似正态"这个前提；真实成绩常在低分段堆出一坨（偏态），那时 3σ 表只能给个粗数。

</details>

## 8. 选读与边界

**正态的 $e$ 与 $\pi$**。$e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ 来自"误差由大量微小独立因素叠加"这一假设；$\frac{1}{\sigma\sqrt{2\pi}}$ 则纯粹是**归一化常数**，为了让曲线下方总面积恰好等于 1（这个积分要用到 $\int_{-\infty}^{+\infty}e^{-t^2}dt=\sqrt{\pi}$，第 20 章多元微积分会算——$e^{-t^2}$ 没有初等原函数，得靠极坐标换元，第 14 章的一元积分拿它没办法）。所以 $\pi$ 在这里跟圆无关，是"面积归一"的副产品。

**最小二乘为什么竖着量**。因为回归的任务是"**已知 $x$ 预报 $y$**"，误差自然该沿 $y$ 方向量。若改成"点到直线的垂直距离"就成了另一件事（正交回归），答案不再是上面那两个公式。选什么尺子取决于你要预报谁——这一点在第 45 章讲损失函数取舍时会反复出现。

**临界值表是怎么来的**。假设两变量真的独立，反复抽样算出的 $\chi^2$ 会服从一个已知分布（自由度为 1 的 $\chi^2$ 分布）。3.841 就是"这个分布有 95% 的面积落在它左边"的分位点。所以"有 95% 的把握"的准确含义是：若两者真的无关，我们只有不到 5% 的机会看到这么大的 $\chi^2$——它**不是**"有关"的概率。这个差别正是第 38 章的主线。

</details>

**本课不管什么**：不推导正态密度的来历，也不计算三个百分数背后的积分；不证最小二乘的正规方程，不讲多元与非线性回归；不讲 $\chi^2$ 分布的来龙去脉、自由度与 $p$ 值的严格定义，也不处理多分类（$r\times c$）列联表；**不谈因果**——三件工具都只描述关联，因果识别要等第 42 章。

完整推导与理论分别在：**第 36 章**（概率进阶 · 正态分布与随机变量）、**第 38 章**（统计推断 · 估计、检验与 $p$ 值）、**第 45 章**（机器学习数学 · 最小二乘与回归）。
