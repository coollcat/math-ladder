# 离散型随机变量与分布列：给随机数造一张清单

## 1. 从一个场景开始

小林的罚球命中率长期稳定在五成。教练安排他一场罚 10 次，赛前问：「你能进几个？」

这个问题没法回答成一个数——他可能进 3 个，也可能进 8 个。但教练真正想要的不是某一次的答案，而是一张**清单**：进 0 个占多少概率、进 1 个占多少……一直到进 10 个。有了这张清单，"平均能进几个""发挥稳不稳""进 3 个以下的可能性多大"就全都能算出来。

[期望：加权平均的随机版](./25-expectation.md) 里我们每次临时枚举结果、临时加权；这一课把那套枚举固化成一张可反复使用的表，叫**分布列**。

## 2. 直觉解释

把随机试验想成一台老虎机：它每次吐出一个数，你没法预言这一次吐什么，但面板上写着每种数字的中奖率。这张"面板说明书"就是分布列，只有两行：上面一行是这个量**可能取到哪些值**（像一排价签），下面一行是每个值**各占多少概率**（像每种商品的销量份额）。

两行配对读：价签 × 销量份额 → 加权平均，正是上一课的期望。所以"按概率加权"换成分布列语言就是 $E(X)=\sum x_ip_i$。

第一件事永远是**体检**：下面一行加起来必须等于 1。加不出 1，说明漏了取值或抄错了概率——后面所有计算统统不成立。

## 3. 正式定义

**离散型随机变量**：取值能一个一个列举出来的随机变量，习惯用大写字母 $X$ 表示，它取到的具体数用小写 $x$ 表示。

**分布列**：把全部取值与对应概率列成的表。

| $X$ | $x_1$ | $x_2$ | $\cdots$ | $x_n$ |
| --- | --- | --- | --- | --- |
| $P$ | $p_1$ | $p_2$ | $\cdots$ | $p_n$ |

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $X$ | 随机变量 | 取值由随机试验决定的量 |
| $p_i=P(X=x_i)$ | 概率 | $X$ 恰好取 $x_i$ 的概率 |
| $\sum p_i=1$ | 归一性 | 必检项：所有概率之和为 1 |
| $E(X)=\sum x_ip_i$ | 期望 | 分布列上的加权平均，即重心 |
| $E(X^2)=\sum x_i^2p_i$ | 平方的期望 | 算方差时用的中间量 |
| $D(X)=E(X^2)-[E(X)]^2$ | 方差 | 分布散布多开；也记作 $\mathrm{Var}(X)$ |
| $\sigma=\sqrt{D(X)}$ | 标准差 | 回到原单位的"典型偏离量" |

方差的简便公式不是凭空来的，展开一遍就现形（记 $\mu=E(X)$）：

$$D(X)=\sum (x_i-\mu)^2p_i=\sum x_i^2p_i-2\mu\sum x_ip_i+\mu^2\sum p_i=E(X^2)-2\mu\cdot\mu+\mu^2\cdot 1=E(X^2)-\mu^2$$

第三步用了两条：$\sum x_ip_i=\mu$ 与 $\sum p_i=1$。

## 4. 分步例题

**例 1**：下面的表是不是分布列？若是，求 $E(X)$、$D(X)$ 与 $\sigma$。

| $X$ | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| $P$ | 0.1 | 0.2 | 0.4 | 0.2 | 0.1 |

1. 体检：$0.1+0.2+0.4+0.2+0.1=1.0$ ✓，是合法分布列；
2. 期望：$E(X)=0\times0.1+1\times0.2+2\times0.4+3\times0.2+4\times0.1=2.0$；
3. 平方的期望：$E(X^2)=0\times0.1+1\times0.2+4\times0.4+9\times0.2+16\times0.1=5.2$；
4. 方差：$D(X)=5.2-2.0^2=1.2$，标准差 $\sigma=\sqrt{1.2}\approx1.0954$。

盯住第 3、4 步的落差：$E(X^2)=5.2$ 比 $E(X)=2.0$ 大得多，减掉 $[E(X)]^2$ 才还原出真正的散布。**漏减这一项是本课最常见的错误**。

**例 2（两点分布）**：一次投篮，命中记 1、不中记 0，命中率 $p$。

| $X$ | 1 | 0 |
| --- | --- | --- |
| $P$ | $p$ | $1-p$ |

这就是**两点分布**（也叫 0-1 分布）。$E(X)=1\cdot p+0\cdot(1-p)=p$，$E(X^2)=1^2\cdot p+0^2\cdot(1-p)=p$，于是 $D(X)=p-p^2=p(1-p)$。

怎么读：$p(1-p)$ 在 $p=0.5$ 处最大（$0.25$），此时单次结果最没准；$p$ 越靠近 0 或 1，结果越确定（$p=0.9$ 时方差只有 $0.09$）。

**例 3（二项分布）**：把例 2 的投篮**独立**重复 $n$ 次，成功次数记作 $X$，这就是**二项分布** $X\sim B(n,p)$：

$$P(X=k)=C_n^k\,p^k(1-p)^{n-k},\qquad k=0,1,\ldots,n$$

公式是两块拼的：$C_n^k$ 数出"哪 $k$ 次成功"的挑法（[排列与组合](./10-counting.md)、[二项式定理](../08-sequences/25-binomial-theorem.md)）；$p^k(1-p)^{n-k}$ 是某一种具体排布的概率——**独立性**保证可以这样直接相乘。

**先给结论**：$E(X)=np$，$D(X)=np(1-p)$。

**验证（取 $n=2$ 手算）**：取值为 $0,1,2$，概率分别为 $(1-p)^2$、$2p(1-p)$、$p^2$（体检：$(1-p)^2+2p(1-p)+p^2=\big[(1-p)+p\big]^2=1$ ✓）。于是

- $E(X)=0+1\cdot2p(1-p)+2\cdot p^2=2p=np$ ✓；
- $E(X^2)=0+1\cdot2p(1-p)+4\cdot p^2=2p+2p^2$，故 $D(X)=(2p+2p^2)-(2p)^2=2p(1-p)=np(1-p)$ ✓。

一般情形的证明要用一点求和技巧，第 36 章会给；眼下先把这两条当工具使。

### 实验 2（python）：模拟一万次，看频率贴住分布列

```python title="一万次『抛 10 枚』：频率贴向理论概率"
import random                          # 随机数机器（第 20 课出生）

counts = [0] * 11                      # counts[k]：正面个数等于 k 的次数；[0]*11 造出 11 个 0
trials = 10000

for t in range(trials):                # 重复一万次试验
    heads = 0
    for i in range(10):                # 每次试验 = 抛 10 枚硬币
        if random.random() < 0.5:      # random() 给出 0~1 之间的随机数，小于 0.5 记正面
            heads = heads + 1
    counts[heads] = counts[heads] + 1  # 本次结果记进对应格子

for k in range(11):
    print(k, round(counts[k] / trials, 3))
```

打出 11 行「$k$ 与它的频率」：$k=5$ 那行贴着 $0.246$，$k=0$ 那行贴着 $0.001$。试验次数越多抖得越小——这还是大数定律，只是这次收敛的是**整张分布列**，不只是一个平均数。

### 实验 3（python）：分布列三件套——体检、期望、方差

```python title="分布列流水线：体检 → 期望 → 方差"
import math                            # 数学库（第 3 章开方课出生）

xs = [0, 1, 2, 3, 4]                   # 取值
ps = [0.1, 0.2, 0.4, 0.2, 0.1]         # 对应的概率

print(round(sum(ps), 6))               # 归一化体检：必须等于 1

mean = 0
for i in range(len(xs)):
    mean = mean + xs[i] * ps[i]        # E(X) = Σ 取值 × 概率

ex2 = 0
for i in range(len(xs)):
    ex2 = ex2 + xs[i] ** 2 * ps[i]     # E(X²) = Σ 取值的平方 × 概率

var = ex2 - mean ** 2                  # D(X) = E(X²) − [E(X)]²
print(round(mean, 4))
print(round(var, 4))
print(round(math.sqrt(var), 4))
```

输出 `1.0`、`2.0`、`1.2`、`1.0954`，与例 1 手算一致。换任何一张分布列进来，这套流水线一个字都不用改。

### 实验 4（python）：二项分布的概率与两条结论

```python title="B(n,p)：P(X=k) 与 np、np(1−p)"
def comb(n, k):                        # 组合数 C(n,k)：n 次里挑 k 次成功
    result = 1
    for i in range(k):
        result = result * (n - i) // (i + 1)
    return result

n = 10
p = 0.5

k = 3
pk = comb(n, k) * p ** k * (1 - p) ** (n - k)   # P(X=k) = C(n,k)·p^k·(1−p)^(n-k)
print(round(pk, 4))

print(round(n * p, 4))                 # E(X) = np
print(round(n * p * (1 - p), 4))       # D(X) = np(1−p)
```

输出 `0.1172`、`5.0`、`2.5`。把 `p` 改成 0.3 再跑：$E(X)$ 掉到 3，$D(X)$ 变成 $10\times0.3\times0.7=2.1$——命中率越低，进球数的波动越小（大多数场次都进不了几个）。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为概率那一行不必检查，加起来差不多就行。" 归一性 $\sum p_i=1$ 是分布列的准入证。加起来是 1.08 或 0.93，说明漏了取值或抄错了概率——用它算出的期望、方差全部作废。

**误区二**："你以为方差就是 $E(X^2)$。" 差一个 $[E(X)]^2$。例 1 里 $E(X^2)=5.2$ 而 $D(X)=1.2$，差了四倍多。它的隐蔽之处在于 $E(X^2)$ 恒为正、看着很像"散布"，只有当中心明明就在 0 附近时才会露出马脚。

**误区三**："你以为只要'每次成功概率相同'就是二项分布。" 二项分布还要求**各次独立**。从"3 红 2 白"的袋里**不放回**连摸 3 次，摸到红球的个数不是二项分布：第一次摸走红球后袋中比例就变了，后面各次不再独立（这类叫超几何分布，第 36 章出现）。

:::

## 7. 练习

**练习 1（判题）**：随机变量 $X$ 的分布列如下，求 $E(X)$ 与 $D(X)$（各保留 4 位小数）。下面的流水线只跑完了一半，改到通过：

| $X$ | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| $P$ | 0.1 | 0.2 | 0.4 | 0.2 | 0.1 |

```exercise
# @title: 练习：用分布列算期望与方差
# @check: 2.0
# @check: 1.2
# @hint: 方差 D(X) = E(X²) − [E(X)]²；现在的代码把 E(X²) 直接当成了方差，少减了均值的平方
xs = [0, 1, 2, 3, 4]                 # X 的取值
ps = [0.1, 0.2, 0.4, 0.2, 0.1]       # 对应的概率

mean = 0
for i in range(len(xs)):
    mean = mean + xs[i] * ps[i]      # E(X) = Σ 取值 × 概率

ex2 = 0
for i in range(len(xs)):
    ex2 = ex2 + xs[i] ** 2 * ps[i]   # E(X²) = Σ 取值的平方 × 概率

var = ex2                            # ← E(X²) 就是方差吗？还差一步
print(round(mean, 4))
print(round(var, 4))
```

初始输出 `2.0` 与 `5.2`——第二个数是 $E(X^2)$ 不是方差。改对后输出 `2.0`、`1.2`；要标准差再开一次根号，得 $\sqrt{1.2}\approx1.0954$。

<details>
<summary>点开查看逐步解答</summary>

1. 体检：$0.1+0.2+0.4+0.2+0.1=1$ ✓；
2. $E(X)=0\times0.1+1\times0.2+2\times0.4+3\times0.2+4\times0.1=2.0$；
3. $E(X^2)=0+0.2+1.6+1.8+1.6=5.2$，故 $D(X)=5.2-4=1.2$。

修正代码：`var = ex2 - mean ** 2`。

</details>

**练习 2（判题）**：抛 10 枚均匀硬币，正面个数 $X\sim B(10,\,0.5)$。求 $P(X=3)$、$E(X)$、$D(X)$。下面的计数器只数出了"有利的排法数"，还没变成概率：

```exercise
# @title: 练习：二项分布的概率、期望与方差
# @check: 0.1172
# @check: 5.0
# @check: 2.5
# @hint: 概率 = 有利排法数 ÷ 全部等可能结果数；10 枚硬币的全部结果是 2 的 10 次方，total 已经算好了
def comb(n, k):
    result = 1
    for i in range(k):
        result = result * (n - i) // (i + 1)
    return result

n = 10
p = 0.5

ways = comb(n, 3)                    # 10 次里挑 3 次正面：C(10,3) = 120
total = 2 ** n                       # 全部等可能结果：2^10 = 1024
pk = ways                            # ← 这是"排法数"还是"概率"？
print(round(pk, 4))

print(round(n * p, 1))               # E(X) = np
print(round(n * p * (1 - p), 1))     # D(X) = np(1−p)
```

初始第一行输出 `120`——那是"120 种排法"不是概率；除以 1024 才是 $0.1172$。后两行照 $E(X)=np$、$D(X)=np(1-p)$ 写，本来就是对的。

<details>
<summary>点开查看逐步解答</summary>

1. 抛 10 枚硬币有 $2^{10}=1024$ 种等可能结果；
2. 恰好 3 枚正面的排法有 $C_{10}^3=\dfrac{10\times9\times8}{3\times2\times1}=120$ 种；
3. $P(X=3)=\dfrac{120}{1024}\approx0.1172$，$E(X)=np=5$，$D(X)=np(1-p)=2.5$。

修正代码：`pk = ways / total`。

</details>

**练习 3**（思考）：下面这张表不是合法分布列。指出它的问题，并说明硬拿它算期望会错成什么样。

| $X$ | 1 | 2 | 3 |
| --- | --- | --- | --- |
| $P$ | 0.3 | 0.5 | 0.4 |

<details>
<summary>点开查看逐步解答</summary>

**问题**：归一性失败，$0.3+0.5+0.4=1.2\neq1$。

**后果**：硬算得 $E(X)=1\times0.3+2\times0.5+3\times0.4=2.5$。权重总和是 1.2 而不是 1，等于给每个结果都多发了一份话语权，平均值被放大到约 1.2 倍。除以 1.2 得约 $2.08$，才是"形状对、只是整体没归一"时的重心——但正确的做法是回头查表，不是事后除一个数：概率和为 1 是硬门槛，凑不出来就说明表错了（多半漏了某个取值，比如"取 0"这一类）。

</details>

## 8. 选读与边界

<details>
<summary>选读：分布列的另一半——连续型</summary>

本课只处理**离散型**：取值能一个一个数出来，概率用求和 $\sum$ 累加。

还有一整类量做不到：身高、体重、测量误差、灯泡寿命。它们在区间里连续取值，问"$P(X=170.0000\ldots)$ 是多少"，答案永远是 0——精确命中一个点有无穷多个竞争对手在分摊。描述它们的不是分布列，而是**密度曲线**：概率不再是"柱子的高度"，而是"曲线下方的面积"，工具从求和 $\sum$ 换成积分 $\int$。

[下一课](./50-stats-preview.md)要遇见的**正态曲线**，正是最重要的一条密度曲线，也是从"离散"跨到"连续"的第一站。

顺带留个伏笔：二项分布 $B(n,p)$ 的柱子，$n$ 越大越像一口钟——实验 1 那 11 根柱子的轮廓已经在往钟形长了。"不同的分布最后都长成同一口钟"叫**中心极限定理**，是第 36 章的主角。

</details>

**本课不管什么**：不证明二项分布 $E(X)=np$、$D(X)=np(1-p)$ 的一般情形（只手算验证了 $n=2$）；不涉及连续型随机变量、分布函数与密度函数；不讨论取值无穷多时求和的收敛问题；两点分布与二项分布的完整性质（可加性、众数、与泊松分布的关系）留给第 36 章。
