# 平均数、方差与标准差：数据的重心与散布

## 1. 从一个场景开始

两位同学五次测验的平均分都是 80：一位的成绩是 79, 80, 81, 80, 80，另一位是 60, 100, 95, 65, 80。平均分说了实话的一半——**中心在哪**；对另一半——**数据抱得多紧**，它一个字没提。而体检报告的参考范围、工厂的质检红线、基金的波动风险，全靠这"另一半"。

这一课给数据装上两根指针：一根指向重心，一根量出散开的半径。

## 2. 直觉解释

**平均数 = 重心。** 把每个数据看成放在横杆上的砝码，横杆恰好平衡的那个支点就是平均数——所以拖走一个极端砝码，支点会被拽着跑。

**散开程度怎么量？** 第一反应是"每个数离中心多远，加起来平均"。但偏差有正有负，直接相加会正负抵消（$-3$ 和 $+3$ 加成 0，假装很整齐）。改用**平方**：负号全部消失，离群点还被额外放大惩罚；代价是单位也跟着平方了，最后开一次根号请回原单位。

于是三件套成型：平均数定中心，方差量散布（平方单位），标准差把散布换回原单位——这就是 $\pm\sigma$ 阴影带的宽度。

## 3. 正式定义

给定 $n$ 个数据 $x_1, x_2, \ldots, x_n$：

$$\mu = \frac{x_1 + x_2 + \cdots + x_n}{n}, \qquad \sigma^2 = \frac{(x_1-\mu)^2 + (x_2-\mu)^2 + \cdots + (x_n-\mu)^2}{n}, \qquad \sigma = \sqrt{\sigma^2}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mu$ | 均值 | 数据的重心（平衡点）|
| $x_i - \mu$ | 偏差 | 每个数离开重心的距离，可正可负 |
| $\sigma^2$ | 方差 | 偏差平方的平均值，单位是原单位的平方 |
| $\sigma$ | 标准差 | 方差开根号，与原数据同单位的"典型距离" |

为什么用平方而不是绝对值？两个理由：一是负号自动消失，不用分段讨论；二是大偏差被平方放大（离中心 2 倍远，罚金变 4 倍），对离群点更敏感。至于除以 $n$ 还是 $n-1$ 的门道，选读里交代。

## 4. 分步例题

**例**：求经典数据 $2, 4, 4, 4, 5, 5, 7, 9$ 的三件套。

1. 求均值：$\mu = (2+4+4+4+5+5+7+9) / 8 = 40/8 = 5$；
2. 算偏差：$-3, -1, -1, -1, 0, 0, 2, 4$（自查：偏差之和恒等于 0 ✓）；
3. 平方累加：$9+1+1+1+0+0+4+16 = 32$；
4. 除以 $n$ 得方差：$\sigma^2 = 32/8 = 4$；
5. 开根号回原单位：$\sigma = \sqrt{4} = 2$。

五个固定动作，任何数据都照此办理——下一节你会看到，这种纯体力活正是交给库干的活。

## 5. 动手实验

### 实验 1（viz）：拖动数据点，三件套联动

```viz
{
  "type": "statdots",
  "n": 8
}
```

怎么玩：拖动任意蓝点。橙色三角是均值（重心跟着跑）；蓝色阴影带是"均值 ± 1 个标准差"；顶部三行读数实时刷新。

试两下：(1) 对称地挪动两侧的点——均值纹丝不动，但阴影变宽；(2) 把一个点远远拖走——看均值如何被拽偏、阴影如何被撑开。这就是"平均数会被极端值拉走"的直观版。

注意：阴影内"大约三分之二"的说法最适合对称钟形数据。这里是自由拖拽实验室，不是正态性证明；任意乱拖时，落在阴影里的数据比例可能明显偏离三分之二。

### 实验 2（viz）：两颗骰子的和——分布形状自己长出来

```viz
{
  "type": "dice",
  "dice": 2
}
```

怎么玩：先点几下「掷 1 次」，看柱子怎么歪歪扭扭地长；再连点「+50」「+2000」。橙色刻度是每个点数和的**理论概率**——为什么"7 点"最常见？因为拼出 7 的组合最多：$(1,6)(2,5)(3,4)(4,3)(5,2)(6,1)$ 共 6 种，而 2 和 12 各只有 1 种。掷得越多，柱子越服帖地贴上橙线（大数定律又立功了）。

同时盯住左上角读数：均值稳稳走向 $7$，标准差收敛到 $\sqrt{35/6} \approx 2.415$。单颗骰子的方差是 $35/12$，两颗独立骰子相加，方差恰好翻倍、标准差乘 $\sqrt{2}$——这背后是"独立随机变量方差相加"的性质，本课先记住这个事实，后续概率进阶讲随机变量与期望方差时会回来严格验证。

### 实验 3（python）：statistics 的出生证明——先手算一遍

流程固定五步，三个数就得写这么一串；三十个数呢？先体验这份重复劳动：

```python title="手算流程：均值、方差、标准差"
import math

xs = [2, 4, 9]
total = 0
for x in xs:                          # 第一步：求和
    total = total + x
mean = total / len(xs)                # 第二步：除以个数 -> 均值

spread = 0
for x in xs:                          # 第三步：偏差平方逐个累加
    spread = spread + (x - mean) ** 2 # (x-mean)**2：平方消掉负号

variance = spread / len(xs)           # 第四步：再除以 n -> 方差
std = math.sqrt(variance)             # 第五步：开根号 -> 标准差
print(mean, variance, std)
```

### 实验 4（python）：statistics 库正式登场

这套流程人人都要用，Python 官方把它做成了库：

```python title="statistics：一行一个统计量"
import statistics                     # 统计工具库：本课正式登记的新 import

xs = [2, 4, 4, 4, 5, 5, 7, 9]

print(statistics.mean(xs))            # mean：均值
print(statistics.stdev(xs))           # stdev：样本标准差——除以 n-1，用于"抽样估计更大的总体"
print(statistics.pstdev(xs))          # pstdev：总体标准差——除以 n，把手头数据当作全部
```

两个标准差只差一点点（数据越多越接近）。**本站统一使用 `pstdev`**：我们处理的都是手头的全部数据，不必背 $n-1$ 的额外心智负担（缘由见选读）。

### 实验 5（python）：一个极端值能拽走多少平均

```python title="工资单上的'被平均'"
import statistics

salaries = [5000, 6000, 7000, 8000, 9000]
print(statistics.mean(salaries))      # 五名员工的平均工资
salaries.append(50000)                # append：往列表末尾追加元素——老板进场
print(statistics.mean(salaries))      # 平均瞬间翻倍还多，但没人真的涨薪
```

平均值从 7000 跳到约 14166——"平均工资年年涨"的一种真相。极端值拽得动均值，却几乎撼不动中位数：六个数从小到大排队后，中间两个数是 7000 和 8000，取平均得 7500；老板的 50000 改变不了这两个位置。这是新闻里更诚实的指标之一——记住"均值怕极端值、中位数对远离中心的极端值更稳"这条对比即可。

### 快问快答

```quiz
把一组数据的每个数都加 10，它的标准差会怎样？
- 变成原来的 10 倍
- 变成原来的 10 倍再加一点
- 不变 [*]
? 整体平移不改变数据的抱团程度，标准差不变（均值倒是加了 10）。乘 10 才会把标准差也放大 10 倍。
```

:::warning[常见误区]

**误区一**："你以为方差大说明数据测错了。" 其实方差描述的是真实存在的波动，不是误差。股价方差大、心率方差大，恰恰是需要认真研究的信息本身。

**误区二**："你以为平均数总能代表'典型水平'。" 极端值会把它拽走：老板月薪 50 万的团队，"人均年薪百万"可能一半人只拿十几万。数据偏斜时先问一句：这个平均是被谁拉高的？

**误区三**："你以为方差和标准差随便报哪个都一样。" 数值上它们差一次开方，单位也不同：工资的方差单位是"元²"，标准差才是"元"。对外汇报请用标准差——它和数据同单位，能直接比较。

:::

**练习 2**：把一组数据的每个数都乘 2，均值和标准差各变成原来的几倍？

<details>
<summary>点开查看逐步解答</summary>

均值变为 2 倍（每个成员都翻倍，重心跟着翻倍）；标准差也变为 2 倍——所有偏差 $(x_i-\mu)$ 先翻倍，平方后变 4 倍，开根号正好还原为 2 倍。合并上一题的结论：对线性变换 $x \mapsto ax + b$，均值变 $a\mu + b$，标准差只认 $|a|$、完全无视 $b$。
</details>

**练习 3**：某项体检指标在健康人群中均值为 5.0、标准差为 0.8，参考范围取"均值 ± 2 倍标准差"，范围是多少？

<details>
<summary>点开查看逐步解答</summary>

下界 $5.0 - 2 \times 0.8 = 3.4$，上界 $5.0 + 2 \times 0.8 = 6.6$，参考范围为 $[3.4,\ 6.6]$。

"±2σ 能罩住绝大多数正常人"这件事并不是巧合，它依赖数据的分布形状——正态分布的著名性质，将在后续章节正式登场。
</details>

## 7. 选读：除以 n 还是 n−1

<details>
<summary>选读 · 样本标准差 stdev 为什么除以 n−1</summary>

统计里有个微妙区分：手里这批数据若是**全部研究对象**（比如全班成绩），直接除以 $n$ 就是总体方差，对应 `pstdev`；若只是**从更大总体抽出的样本**（比如随机抽查 1000 人估计全国身高），除以 $n$ 会系统性偏小——因为样本均值 $\bar{x}$ 本身是贴着这批数据造出来的，偏差们天然显得比真实情况更紧凑。

修正办法是除以 $n-1$（对应 `stdev`）。一个直观解释：$n$ 个偏差受"总和必为 0"这条约束捆绑，真正自由的只有 $n-1$ 个（自由度），用 $n-1$ 当分母才公平。样本越大两者差距越小；本站的数据都是"手头即全部"，统一用 `pstdev` 最省心。

</details>
