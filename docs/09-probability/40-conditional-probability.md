# 条件概率与独立性

## 1. 从一个场景开始

班主任拿着眼镜普查表宣布："全班 30 人，14 人戴眼镜。"接着补了一句："**其中**女生 8 人。"

就这一个"其中"，问题的世界被悄悄切小了：从"全班 30 人"缩到了"戴眼镜的 14 人"。在缩小的世界里再问"女生占多少"，答案和在原世界里问完全不同。这种"**在已知某件事发生的前提下**，另一件事的概率"就是**条件概率**——彩票课里算二等奖"6 个红球全中**而且**蓝球不中"时，其实已经在悄悄用它了，只是当时没点破名字。

## 2. 直觉解释

上一课统计说"均值会被极端值带跑"，条件概率则是另一句相反的话：**换一个队伍重新数，比例就换一副面孔**。

核心动作只有三个字：**缩小论域**。概率本来是"符合条件的情况数 ÷ 全体情况数"（第 20 课的古典定义）；一旦"已知 A 发生"，分母就不再是全体，而是"满足 A 的那部分队伍"。所有分子分母都在缩小后的世界里重新数。

| 问法 | 分母（论域） | 分子 | 直觉 |
| --- | --- | --- | --- |
| P(戴眼镜) | 全班 30 人 | 戴眼镜的 14 人 | 全班里随便拉一人，戴镜比例 |
| P(戴眼镜 \| 女生) | 女生 12 人 | 其中戴镜的 8 人 | 只在女生队伍里数 |
| P(女生 \| 戴眼镜) | 戴镜的 14 人 | 其中女生 8 人 | 只在眼镜队伍里数 |

竖线 "$\mid$" 读作"已知"或"条件下"。注意后两行：**同一个"8"除上了不同的分母**——条件方向一换，数字就两样，这是本课最重要的一个直觉。

## 3. 正式定义

对两个事件 $A$ 与 $B$（$P(A)>0$）：

| 名称 | 定义 | 备注 |
| --- | --- | --- |
| 条件概率 | $P(B\mid A)=\dfrac{P(A\text{与}B\text{同时发生})}{P(A)}$ | 古典概型下就是"缩小论域后重新数比例" |
| 独立 | $P(B\mid A)=P(B)$ | 知道 $A$ 发生与否，不改变 $B$ 的比例 |
| 独立的乘法形式 | $P(A\text{与}B)=P(A)\cdot P(B)$ | 与上一行等价，是"互不影响"的数学化 |

独立的直觉表述：掷一枚硬币正面朝上、明天是否下雨、抽到的扑克是不是红桃——这类"各管各的"事件，互相都不该改变对方的概率。**注意**：本课先给直觉与计数定义；严格的公理化版本（包括条件概率的三条性质）在第 36 章概率进阶展开。

## 4. 分步例题

**例**：回到普查表。女生 12 人（8 人戴镜），男生 18 人（6 人戴镜）。

1. 全班比例：$P(\text{戴镜})=\dfrac{14}{30}\approx 0.47$；
2. 按行缩论域：$P(\text{戴镜}\mid\text{女生})=\dfrac{8}{12}\approx 0.67$——女生里戴镜明显更普遍；
3. 反方向：$P(\text{女生}\mid\text{戴镜})=\dfrac{8}{14}\approx 0.57$——眼镜队伍里女生过半，但比例不同了；
4. 判独立：$0.67\neq 0.47$，即 $P(\text{戴镜}\mid\text{女生})\neq P(\text{戴镜})$——**"性别"与"戴镜"不独立**，知道性别确实改变了戴镜的预期。

一句话读表：那个"8"是全场最忙的数字——除以 12 是"女生里多少比例戴镜"，除以 14 是"戴镜里多少比例是女生"，除以 30 是"全班里两者同时发生的概率"。分数的**结构**（谁除以谁）比数字本身更值得盯住。

## 5. 动手实验

### 实验 1（viz）：亲手缩小论域

```viz
{
  "type": "condgrid",
  "title": "班级眼镜普查：点按钮缩小论域",
  "rows": ["女生", "男生"],
  "cols": ["戴眼镜", "不戴眼镜"],
  "counts": [[8, 4], [6, 12]],
  "unit": "人"
}
```

怎么玩：棋盘四格里躺着全班 30 人。先读全体比例；点「只看女生」——论域缩成第一行，比例跳到 $8/12$；再点「只看戴眼镜」——论域换成一列，比例变成 $8/14$。同一个格子、两套分母：**条件概率的"条件"就是你在挑选分母**。

### 实验 2（python）：把普查表交给计数器

```python title="一张普查表的四个条件概率"
girls_g = 8                    # 女生中戴眼镜人数
girls_n = 4                    # 女生中不戴人数
boys_g = 6                     # 男生中戴眼镜人数
boys_n = 12                    # 男生中不戴人数
total = girls_g + girls_n + boys_g + boys_n       # 全班 30 人
glasses = girls_g + boys_g                        # 戴镜总人数 14
girls = girls_g + girls_n                         # 女生总人数 12

p_glasses = glasses / total                        # P(戴镜)
p_glasses_given_girl = girls_g / girls             # P(戴镜 | 女生)
p_girl_given_glasses = girls_g / glasses           # P(女生 | 戴镜)
p_both = girls_g / total                           # P(女生且戴镜)

print(round(p_glasses, 3))
print(round(p_glasses_given_girl, 3))
print(round(p_girl_given_glasses, 3))
print(round(p_both, 3))
```

输出 `0.467`、`0.667`、`0.571`、`0.267`。四行四个分母：30、12、14、30——盯着分母读条件概率，永远不会迷路。顺手验一下乘法形式：$\frac{12}{30}\times\frac{8}{12}=\frac{8}{30}=0.267$，恰好等于第四行——"女生比例 × 女生中戴镜比例 = 两者同时发生比例"，这正是条件概率定义式变形后的模样。

### 快问快答

```quiz
已知事件 A 与 B 独立，下面哪条一定成立？
- A 和 B 不可能同时发生
- P(B|A) = P(B) [*]
- P(A|B) = 0
? 独立是"互不打扰"：知道 A 发生，B 的比例纹丝不动。它和"互斥"（不能同时发生）恰好相反——互斥是极强的影响。
```

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为 $P(A\mid B)$ 和 $P(B\mid A)$ 是同一个数。" 普查表实锤：$0.67\neq 0.57$。前者分母是女生队伍、后者是眼镜队伍——论域都不同，谈何相等。医疗检测里"检出阳性的人中真患病的比例"与"患病的人中检出阳性的比例"被混为一谈，是现实世界代价最高的统计错误之一（第 36 章贝叶斯定理专治这个）。

**误区二**："你以为独立就是互斥。" 恰好反了！互斥（$A$、$B$ 不能同时发生）意味着 $P(B\mid A)=0$——知道 $A$ 发生，$B$ 的概率直接归零，这是**最强的影响**，哪里独立。独立要求 $P(A\text{与}B)=P(A)P(B)$，通常两者完全可以同时发生。一句话：独立是"互不影响"，互斥是"你死我活"。

**误区三**："你以为条件概率刻画了因果。" "$P(\text{戴镜}\mid\text{女生})$ 高"不等于"是女生导致戴镜"——可能是年龄结构、用眼习惯等混杂因素在背后操盘。条件概率是缩小论域后的**描述**，因果要靠第 42 章的干预语言才能开口。

:::

## 7. 练习

**练习 1**：掷一颗骰子，已知点数大于 3，求点数是偶数的概率。下面的计数器把分母写错了，改到通过：

```exercise
# @title: 练习：已知点数大于 3，它是偶数的概率
# @check: 0.7
# @hint: "已知大于 3"这件事已经把论域缩小了——分母不该再是 6。数一数 known 队伍里有几个人。
rolls = [1, 2, 3, 4, 5, 6]     # 一颗骰子的全部可能：论域=6 种
known = []                     # 已知队伍：满足"大于 3"的点数
for n in rolls:                # 逐个过堂
    if n > 3:                  # 条件筛选：只收大于 3 的
        known.append(n)        # append：把 n 排到列表末尾
evens = []                     # 已知队伍里再筛偶数
for n in known:
    if n % 2 == 0:             # % 求余：余 0 即偶数
        evens.append(n)
prob = len(evens) / 6          # ← 分母错了：论域已经缩到 known
print(round(prob, 1))
```

论域分析：大于 3 的队伍是 $\lbrace 4, 5, 6 \rbrace$，其中偶数 $\lbrace 4, 6 \rbrace$ 占 2 个，所以 $P(\text{偶}\mid >3)=\dfrac{2}{3}\approx 0.67$，取一位小数 `0.7`。错版用 6 当分母算出 $0.33$——那是"不问条件、直接掷出偶数"的概率 $P(\text{偶})$，恰好把"缩小论域"这个动作整个漏掉了。

<details>
<summary>点开查看逐步解答</summary>

1. 条件"大于 3"把 6 种等可能结果缩成 3 种：4、5、6（这就是新论域，每种仍等可能）；
2. 新论域中偶数有 4、6 两种；
3. $P(\text{偶}\mid >3)=\dfrac{2}{3}$。

修正代码：`prob = len(evens) / len(known)`。对照定义式：$P(B\mid A)=\frac{P(A\text{与}B)}{P(A)}=\frac{2/6}{3/6}=\frac{2}{3}$——分子分母的 6 约掉了，留下的正是"队伍里的比例"。
</details>

**练习 2**（思考）：某病发病率 1%。体检：真患病的人 99% 被查出阳性；健康的人 99% 正确阴性。某人查出阳性，他真患病的概率是多少？先猜再算。

<details>
<summary>点开查看逐步解答</summary>

用 10000 人计数（条件概率的古典算法：先排队，再缩论域）：

1. 患病 100 人，其中 99 人检出阳性；健康 9900 人，其中 1% 误报 = 99 人阳性；
2. 阳性队伍共 $99+99=198$ 人——论域缩小到这支队伍；
3. 其中真患病的占 $\dfrac{99}{198}=\dfrac{1}{2}$。

一半阳性是误报！直觉觉得"99% 准的检测，阳性就该 99% 是病人"，但**罕见病把论域结构改了**：健康人基数太大，1% 的误报也堆出一支同样大的假阳性队伍。这道题的完整解法叫贝叶斯定理，第 36 章给它发正式证件；本课你已经能靠"排队 + 缩论域"裸算出来。
</details>

## 8. 边界之外

- **贝叶斯定理**：把 $P(A\mid B)=\frac{P(A\text{与}B)}{P(B)}$ 与 $P(B\mid A)=\frac{P(A\text{与}B)}{P(A)}$ 拼起来，得到"反向换算"的公式——第 36 章用它重做检测题、医学诊断与垃圾邮件过滤；第 39 章整个 Bayesian 统计大厦都压在这块基石上。
- **全概率与拆解**：当论域可以切成几支队伍（如男/女），总体概率 = 各队伍概率的加权平均——第 36 章的全概率公式，本质是"分队伍数格子"的代数化。
- **独立性升级**：多个事件两两独立还不够（可能"三个联合"出幺蛾子），相互独立的严格定义也在第 36 章；随机变量的独立则是第 37 章随机过程的入场券。
