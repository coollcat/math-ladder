# 概率与大数定律：随机里的秩序

## 1. 从一个场景开始

赌场老板从不知道下一把牌谁赢，保险公司不知道明天哪辆车出事，气象台也不知道明天几点开始下雨——但他们全都敢开出精确的价格，而且年年赚钱。

他们的底气不是水晶球，而是一条铁律：**单次结果无法预言，海量结果的平均行为却稳定得像物理定律**。这一课我们把这个"稳"字说清楚，并亲手把它掷出来。

## 2. 直觉解释

抛一枚硬币。抛 1 次：正面还是反面，天知道。抛 10 次：可能 7 次正面，运气说了算。可要是抛 100000 次呢？你会看到正面占比被一股看不见的力量按在 $0.5$ 附近，越抛贴得越紧。

在可重复的均匀试验里，理论概率是每种结果分到的份额；长期频率是我们能观察到的影子。换句话说：

> **概率 = 理论上的长期份额；频率 = 已经发生的次数 ÷ 总次数。**

频率是实验里量出来的数，每次都不同；概率是理论上的归宿，纹丝不动。大数定律保证的正是：只要实验次数够多，频率就会向概率靠近——赌场的利润、保险公司的精算表、民调的可信度，全建立在这条定律上。

## 3. 正式定义

最经典的场景是**古典概型**：试验只有有限个结果，且每个结果等可能。若事件 $A$ 包含其中 $m$ 个结果，总共有 $n$ 个等可能结果，则

$$P(A) = \frac{m}{n}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $P(A)$ | 概率 | 事件 $A$ 发生可能性的度量，介于 0 和 1 之间 |
| $n$ | 样本总数 | 全部等可能结果的个数（上一课的组合数常在这里出现）|
| $m$ | 有利结果数 | 属于事件 $A$ 的结果个数 |
| $f_k$ | 频率 | 前 $k$ 次实验中 $A$ 出现次数除以 $k$，随实验浮动 |

三条基本性质：$0 \le P(A) \le 1$；必然事件的概率为 1；所有基本结果的概率加起来等于 1。在本课的有限等可能场景里，$P(A)=0$ 就表示没有有利结果；更一般的概率模型留到后续章节讨论。

上一课的成果立刻上岗：掷两颗骰子共有 $6 \times 6 = 36$ 个等可能结果，"和为 7"占 6 个，所以 $P(\text{和为 }7) = \frac{6}{36} = \frac{1}{6}$。

## 4. 分步例题

**例**：掷一颗均匀骰子，求各事件的概率。

1. 列出全部等可能结果：$\lbrace1,2,3,4,5,6\rbrace$，故 $n = 6$；
2. 事件 $A$ =「掷出偶数」$= \lbrace2,4,6\rbrace$，$m = 3$，于是 $P(A) = \frac{3}{6} = \frac{1}{2}$；
3. 事件 $B$ =「点数大于 4」$= \lbrace5,6\rbrace$，$m = 2$，于是 $P(B) = \frac{2}{6} = \frac{1}{3}$；
4. 自查：六个基本结果的概率各为 $\frac{1}{6}$，总和 $\frac{1}{6} \times 6 = 1$ ✓。

注意第 4 步：算完概率先检查总和是否为 1，这是计数题最快的排错手段。

## 5. 动手实验

### 实验 1（viz）：狂掷硬币，亲眼看频率贴向 0.5

```viz
{
  "type": "coinlaw"
}
```

怎么玩：先点几次「掷 1 次」感受纯随机；再连点「+100」「+1000」，最后来一发「+100000」。蓝色曲线是"到目前为止的正面频率"，横轴是对数刻度，会随着总掷数继续压缩；绿色虚线是理论值 0.5。

每次重置后的路径都不一样——但不管走多歪，掷得越多它越服帖地趴在虚线上。这条蓝线就是大数定律本律。

### 实验 2（python）：掷骰子的频率表

上面的掷币机已经看过收敛，代码版能换骰子玩。拖动滑块改变实验规模 $n$，观察条形图如何被压平到理论线：

```python title="掷骰子：实验频率 vs 理论概率 1/6"
import random
import matplotlib.pyplot as plt

# sliders: n=600 [60:60000:60]

random.seed(20260826)                # 固定随机数起点：每次运行同一 n 都复现同一批骰子结果

counts = [0, 0, 0, 0, 0, 0]        # counts[i] 存点数 i+1 出现的次数
for trial in range(n):             # n 由滑块注入，拖动即改掷骰子次数
    face = random.randint(1, 6)    # randint(1, 6)：等价于掷一颗均匀骰子
    counts[face - 1] = counts[face - 1] + 1

freqs = []                         # 频率表：出现次数 ÷ 总次数
for c in counts:
    freqs.append(c / n)

plt.bar([1, 2, 3, 4, 5, 6], freqs, color="steelblue", label="experiment")  # bar：条形图（首现）
plt.plot([0, 7], [1 / 6, 1 / 6], linestyle="--", color="tomato", label="theory 1/6")
plt.ylim(0, 0.35)                  # ylim：固定纵轴范围，方便不同 n 直接对比
plt.legend()
```

$n=600$ 时六根柱子参差不齐；拖到几万次，它们齐刷刷压到红色虚线 $\frac{1}{6} \approx 0.167$ 上。没有哪根柱子"记得"自己之前偏高还是偏矮——修正靠的是新数据不断涌入，而不是旧偏差主动归还。

### 快问快答

```quiz
一枚公平硬币连着出了 5 次正面，第 6 次——
- 反面更可能出现：连了这么久该回补了
- 还是 50%：硬币没有记忆 [*]
- 正面更可能：手感来了
? 每次抛掷相互独立，第 6 次仍是 50%。大数定律靠大量新数据稀释旧偏差，从不承诺旧偏差会"被偿还"。
```

:::warning[常见误区]

**误区一**："你以为连输 10 把之后该赢了。" 这叫**赌徒谬误**。硬币、骰子、轮盘都没有记忆，每一局独立。大数定律说的是长期频率趋稳，从不是说短期偏差会被补偿——恰恰相反，前 10 次的偏差会被后面成千上万次的新数据摊薄到几乎看不见。

**误区二**："你以为掷 10 次 7 次正面就说明硬币有问题。" 小样本什么都干得出来：10 次里恰好 7 正的概率约 12%，"至少 7 正"也不过约 17%，一点也不稀奇。判断硬币是否公平要看的是几千几万次的频率，样本太小得出的任何结论都是噪音。

**误区三**："你以为降水概率 90% 就是明天下雨时间占九成。" 可以粗略理解为：在与今天相似的大量天气情形中，大约九成会出现雨。它不是"全国九成地方会下雨"，也不是"下雨时间占九成"。概率描述的是同一条件下大量重复时的稳定份额，不属于某一天的某一小时。

:::

## 6. 练习

**练习 1**：掷两颗骰子，和恰好为 7 的情况应占 36 种结果中的 6 种。下面的代码能跑但数少了——第二颗骰子偷懒没从头掷。改到通过：

```exercise
# @title: 练习：数出和为 7 的组合
# @check: 6
# @hint: 两颗骰子互不相干：内层循环也要让第二颗从 1 跑到 6 全部掷一遍，而不是接着第一颗往后数
count = 0
for a in range(1, 7):
    for b in range(a, 7):      # ← 这里真的枚举了第二颗骰子的全部结果吗？
        if a + b == 7:
            count = count + 1
print(count)
```

修好后对照：$6 / 36 = 1/6$，正是所有点数和中概率最大的一档（0 章的双骰子直方图早就画过这座山）。

两颗骰子是两步独立抽取。第二颗也要从 1 到 6 全部枚举：

```python
count = 0
for a in range(1, 7):
    for b in range(1, 7):
        if a + b == 7:
            count = count + 1
print(count)
```

**练习 2**："降水概率 70%" 到底是什么意思？

<details>
<summary>点开查看逐步解答</summary>

它的意思是：与今天条件相似的许多天里，大约七成下了雨。它**不**指"全国七成地方会下雨""下雨时间占七成"，也不指预报员有七成把握。概率描述的是同一条件下大量重复时的频率归宿——理解错这句天气预报，多半是把"单次"和"大量重复"搞混了。
</details>

**练习 3**：连续抛两次硬币，至少出现一次正面的概率是多少？

<details>
<summary>点开查看逐步解答</summary>

枚举全部 $2 \times 2 = 4$ 个等可能结果：（正,正）（正,反）（反,正）（反,反）。至少一次正面的占前三个，故概率为 $\frac{3}{4}$。

换个思路验证：反面-only 只有一种情形（反,反），概率 $\frac{1}{4}$；用"1 减去它"得 $1 - \frac{1}{4} = \frac{3}{4}$ ✓。这种"正难则反"的算法在概率题里经常事半功倍。
</details>

## 7. 选读：大数定律为什么成立

<details>
<summary>选读 · 频率凭什么越来越稳</summary>

直觉版论证分三步。第一，每次抛掷相互独立，前段的偏高偏低不会传染给后段；第二，正负两侧机会均等，偏差没有固定方向——把 $k$ 次结果记作 $+1$ 和 $-1$ 求和，总和只是围绕 0 上下波动，并不会主动把先前的偏差补回来；第三，也是最关键的：$k$ 次总和的典型波动只按 $\sqrt{k}$ 增长，除以 $k$ 得到频率后，典型误差就约为 $1/\sqrt{k}$——试验越多，它越小，曲线也就越贴住理论线。

雅各布·伯努利第一个严格证明了这件事（1713 年《猜度术》），前后花了二十年，他给它起名"黄金定理"。他证明的版本比这里的直觉粗糙得多，却开启了此后三百年概率论的严格化。至于那个神秘的 $\sqrt{k}$ 从哪来——两课之后讲标准差时它会自己走出来。

</details>

## 8. 下一站

频率稳住了，还有一个绕不开的实际问题：**平均一局值多少钱？** 赌场开赔率、保险定保费、彩票标价格，靠的都是同一个算法——把每个可能结果乘上它的概率再加总。这个"概率加权的平均账单"叫期望，它正是上一课那条蓝线最终趴住的归宿的数学名字。
