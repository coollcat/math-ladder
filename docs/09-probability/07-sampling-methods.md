# 抽样：从总体里挑出代表

## 1. 从一个场景开始

质检员面前是一万只刚下线的灯泡，要估出它们的平均寿命。一只只点着等它坏？等完这一万只，厂子也停产了。

现实里的调查几乎都做不到"全查"：全校几千名学生、一整批药片、一片森林里的树。于是只能**从里面挑出一部分代表全部**——这一个动作就是抽样。挑得好，一小勺汤尝出整锅的味道；挑得不好，结论能离谱到让人笑不出来。

## 2. 直觉解释

把总体想成一锅汤。想知道咸淡，舀一勺：

- 舀之前**先把锅搅匀**——这就是**随机**：每个位置的汤都有同样的机会进勺子；
- 如果汤是分层的（上层清、下层料），就**每层都舀一点、按比例配**——这是**分层抽样**；
- 如果图省事，只舀浮在表面那一层——这是**便利样本**，最容易骗人。

抽样最怕的不是勺子小，而是**系统性偏向**：只舀表面，勺勺都是清汤，舀一百勺也代表不了整锅。

## 3. 正式定义

**总体**：要研究的全部对象构成的集合。**个体**：总体中的一个对象。**样本**：从总体中抽出的一部分个体。**样本量**：样本里个体的个数，记作 $n$。

三种常用抽样方法：

| 方法 | 操作 | 适用与代价 |
| --- | --- | --- |
| 简单随机抽样 | 总体中每个个体被抽到的**机会相等**、相互独立；用抽签或随机数实现 | 最公平，但要求手上有完整名单 |
| 分层抽样 | 按重要特征**分层**，各层内随机抽取，名额**按人数比例**分配 | 层内差异小、层间差异大时最有效 |
| 系统抽样 | 把个体编号，按固定间隔 $k=N/n$ 等距抽取（起点随机） | 操作快；但名单顺序若与调查内容相关就会偏 |

符号表：

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $N$ | 总体容量 | 总体里一共有多少个个体 |
| $n$ | 样本量 | 抽出来多少个 |
| $k=N/n$ | 抽样间隔 | 系统抽样的步长 |
| 各层人数 | 分层依据 | 分层抽样中每一层的规模，决定该层的名额 |

分层名额的公式：

$$\text{某层名额} = n \times \frac{\text{该层人数}}{N}$$

## 4. 分步例题

**例 1（分层抽样）**：某校高一 400 人、高二 350 人、高三 250 人，共 $N=1000$ 人。要抽 $n=100$ 人做问卷，按年级分层，各层名额多少？

1. 算总人数：$N=400+350+250=1000$；
2. 算各层占比：高一 $40\%$、高二 $35\%$、高三 $25\%$；
3. 按比例分名额：高一 $100 \times 40\% = 40$ 人、高二 $35$ 人、高三 $25$ 人；
4. 检查名额之和：$40+35+25=100=n$ ✓（分层抽样的名额必须刚好分完）；
5. 各层**内部再随机**抽取——分层只负责分配名额，层内仍然要保证公平。

**例 2（系统抽样）**：800 名学生中抽 40 人。

1. 抽样间隔 $k = 800/40 = 20$；
2. 在 $1$ 到 $20$ 之间随机取一个起点，比如 7；
3. 依次抽 7、27、47、67、……每隔 20 号取一个，直到取满 40 人；
4. 起点随机是关键——固定从头取，就永远只覆盖名单的同一串位置。

**例 3（识别偏差）**：某网站弹窗问"你支持延长营业时间吗？"，统计出 90% 支持。这个样本可靠吗？

1. 谁看得见弹窗？深夜还挂在网上的用户——他们本来就更容易支持延长营业时间；
2. 谁愿意点？意见强烈的人更可能点。这是**自选择偏差**；
3. 结论：90% 是"愿意点弹窗的那批深夜用户"里的比例，不能代表全体用户。

## 5. 动手实验

### 实验 1（viz）：分层名额一眼看清

把例 1 的结果画成柱状图——**柱高之比就是各层人数之比**：

```viz
{
  "type": "datachart",
  "title": "分层抽样的名额分配（共抽 100 人）",
  "labels": ["高一", "高二", "高三"],
  "values": [40, 35, 25]
}
```

$40:35:25$ 恰好等于 $400:350:250$。分层的要义就在这个"比例不变"里：样本的层结构被原样**复制**成了总体的层结构。

### 实验 2（python）：让程序做一次分层抽样

```python
import random   # random：Python 标准库的随机数工具箱

# sliders: total_sample=20 [10:60:10]
# total_sample：本次要抽多少人，由滑块注入

strata = {"高一": 400, "高二": 350, "高三": 250}   # 字典：层名 -> 该层人数
N = sum(strata.values())                            # sum：把各层人数加起来，得到总体容量
picked = []                                         # 累加器：收集抽出的样本编号
for grade, size in strata.items():                  # items()：一次取出字典里的"键, 值"
    quota = size * total_sample // N                # 按比例分配名额；// 是整除，向下取整
    for _ in range(quota):                          # 下划线：这个循环变量不打算再用
        picked.append(f"{grade}-{random.randint(1, size)}")   # randint：在 1..size 里随机取一个编号

print(picked)
print(f"总体 {N} 人，样本 {len(picked)} 人")
```

把 `total_sample` 从 20 拖到 60，各层名额按 $4:3.5:2.5$ 自动放大，样本量始终贴着目标走（整除取整会差一两个人，属正常）。这段代码走完了例 1 的整套流程，只是把"手算比例"换成了公式。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为样本越大就越准。" 样本量只压得住**随机误差**，压不住**系统偏差**。1936 年美国《文学文摘》寄出上千万份问卷、收回两百多万份，照样预测错了总统——因为它抽中的是"有电话、有汽车、愿意回信"的人。

**误区二**："你以为随机抽样就是'随便挑'。" 站在食堂门口拦人、让志愿者报名，都是"随便"而不是随机：它们让某类人更容易进样本。**随机的前提是"每个个体机会相等"**，需要名单和明确的规则，不能随心所欲。

**误区三**："你以为分层抽样就是把名额在各层平均分。" 分层是按**比例**分，不是按层数平分。上例中高三只有 250 人，就该比高一拿得少；平均分会让 25% 的群体被过度代表。

:::


**练习 2**：某班 50 人，学号 1 到 50，要抽 5 人做访谈。写出一种系统抽样的具体方案，并说明起点为什么必须随机。

<details>
<summary>点开查看逐步解答</summary>

间隔 $k=50/5=10$。在 $1$ 到 $10$ 里随机取一个起点 $r$，然后抽学号 $r,\ r+10,\ r+20,\ r+30,\ r+40$ 这五人。

起点必须随机，是因为决定"抽到哪一串"的恰恰是它：若永远从头取（$r=1$），样本就固定成 1、11、21、31、41。万一学号恰好按入学成绩排，这一串就带上了成绩偏向。随机起点把这种系统性的侥幸抹平。

</details>

**练习 3（概念）**：要调查"本校学生对食堂的满意度"，说出一种容易产生偏差的具体做法，并给出改进方案。

<details>
<summary>点开查看答案</summary>

偏差做法：只在食堂门口拦人。改进：先按年级和性别分层，各层内用随机数抽人，再统一发问卷。

站在食堂门口会同时引入两重偏向——"经常来食堂的人"更容易被问到，"恰好此刻路过的人"也更容易被问到。这是一个叠了两种系统偏差的**便利样本**。

</details>

**趁热打铁**：

```quiz
想让样本的年级结构与全校保持一致，应当优先用哪种抽样方法？
- 分层抽样：按年级分层，各层按人数比例分配名额 [*]
- 便利抽样：课间拦下路过的同学
```

## 8. 选读：一次载入史册的抽样翻车

<details>
<summary>选读 · 1936 年：两百多万份问卷输给五千人</summary>

1936 年美国总统大选前，《文学文摘》杂志寄出约一千万份问卷，收回两百多万份，自信满满地预测兰登获胜。刚起步的盖洛普只抽了约五千人，却算对了罗斯福当选。

差别不在样本量，而在**抽样框**：《文学文摘》的名单来自电话册和汽车登记册，大萧条年代有电话和汽车的多是富人，整体偏向共和党；再加上"愿意寄回问卷"又是一层自选择。盖洛普则采用配额抽样，让各收入层、各地区按比例进入样本。

教训写进了每一本统计教材：**两百万人的"偏样本"，比不上五千人的"好样本"。** 所以拿到一份民调，先问它怎么抽的，再问它抽了多少。

</details>
