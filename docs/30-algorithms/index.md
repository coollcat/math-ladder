## 实战挑战 · 外卖骑手的送餐路线

**题型出处**：情境改编自考研数据结构的经典高频题型「最短路·手工模拟」（图的应用章的常客，历年真题反复考查）；本题路网数据为情境原创，未对应任何具体年份卷别题号。

外卖骑手小周从商圈配送站 $S$ 出发，要把晚餐送进四个小区。午高峰实时路况如下（单位：分钟，单向边）：

| 道路 | 耗时 |
| --- | --- |
| $S \to A$ | 4 |
| $S \to B$ | 1 |
| $B \to A$ | 1 |
| $B \to C$ | 4 |
| $A \to C$ | 3 |
| $A \to D$ | 8 |
| $C \to D$ | 2 |

按 Dijkstra 的节奏走一遍（29 章最短路径课的手工表格法）：

**(a)** 起点 $S$ 先落定；接着 $B$（当前距离 1）落定。用 $B$ 松弛邻居后，$A$ 的临时距离变成多少？

**(b)** 全部落定后，$C$ 的最短距离是多少？

**(c)** $D$ 的最短距离是多少？（提示：它最后是被哪个中间点救短的？）

第一问已示范写法——每问一行输出：

```exercise
# @title: 实战挑战：骑手的最短路线账本
# @check: 2
# @check: 5
# @check: 7
# @hint: 松弛就是"绕行是否比现有记录更短"。B 落定后 A 的候选是 直达 4 与 绕行 1+1；C 的两个候选殊途同归都是 5；D 要比较 绕 A 的 2+8 与 经 C 的 5+2。
s_a = 4    # S -> A 直达
s_b = 1    # S -> B 直达
b_a = 1    # B -> A
a_c = 3    # A -> C
b_c = 4    # B -> C
a_d = 8    # A -> D
c_d = 2    # C -> D

dist_a_after_b = s_a           # (a) ← 别忘了拿"绕行 B"来比一比
dist_c_final = b_c             # (b) ← 两个候选：经 A 的 2+3 与 经 B 的 1+4
dist_d_final = a_d             # (c) ← 经 C 的那条路还没被记上账！

print(dist_a_after_b)
print(dist_c_final)
print(dist_d_final)
```

<details>
<summary>点开查看逐步解答</summary>

初始化：$\text{dist} = [S{:}0,\ A{:}4,\ B{:}1,\ C{:}\infty,\ D{:}\infty]$。

1. 取最小未落定点 $B(1)$，松弛出边：$A \gets \min(4,\ 1{+}1) = 2$；$C \gets 1{+}4 = 5$；
2. 取 $A(2)$：$C \gets \min(5,\ 2{+}3)=5$（不变）；$D \gets 2{+}8=10$；
3. 取 $C(5)$：$D \gets \min(10,\ 5{+}2)=\mathbf{7}$——负权不存在时，Dijkstra 的贪心次序保证此刻的 7 就是终局；
4. 答案：(a) 2；(b) 5；(c) 7。完整路线 $S\to B\to A\to C\to D$ 合计 $1{+}1{+}3{+}2=7$ 分钟。

用代码复核全表：

```python
b_a = 1
a_c = 3
c_d = 2
dist_s, dist_a, dist_b, dist_c, dist_d = 0, 4, 1, 99, 99
dist_a = dist_b + b_a          # 松弛后 2
dist_c = dist_a + a_c          # 5
dist_d = dist_c + c_d          # 7
print([dist_s, dist_a, dist_b, dist_c, dist_d])
```

注意 $B\to C$ 的直连边（1+4=5）与 $S\to B\to A\to C$ 打平——最短路径不必唯一，但最短**值**唯一。
</details>

## 实战挑战 · 找最大值的比较方向

"打擂台找最大"是最朴素的算法：见一个更大的就换擂主。下面这题比较方向反了，把最小值当成了擂主，修到输出 `9`：

```exercise
# @title: 实战挑战：找最大值的比较方向
# @check: 9
# @hint: 擂主应该换成"更大"的值，比较符号用 >。
arr = [3, 1, 7, 2, 9, 4]
m = arr[0]               # 先让第一个元素当擂主
for x in arr:
    if x < m:            # ← 问题在这：方向反了，该找更大的
        m = x
print(m)
```

<details>
<summary>点开查看逐步解答</summary>

找最大值要"见大换擂主"：

```python
if x > m:        # 遇到更大的值就更新擂主
    m = x
print(m)         # 9
```

改完：遍历 $[3,1,7,2,9,4]$，擂主依次更新为 $3 \to 7 \to 9$，输出 `9`。初始代码用 `<`，擂主一路换成最小值 $1$。这个"打擂台"模式是线性扫描的鼻祖，本章排序、选最大、统计都从它变体而来——比较的方向，就是算法的灵魂。

</details>
