# 术语表

按主题分组的卷一关键术语。中文名加粗，括号里是英文，后面一句话说清它是啥。

## 数与运算

| 术语 | 一句话解释 |
| --- | --- |
| **交换律**（commutative law） | 交换两个数的顺序结果不变：$a+b=b+a$，乘法同理；减法除法没这待遇 |
| **分配律**（distributive law） | 乘法可以"分发"进括号：$a(b+c)=ab+ac$，展开式的依据 |
| **负数**（negative number） | 比 0 还小的数，表示"欠着的量"或相反方向 |
| **分数**（fraction） | 把整体切成几等份取其几，$\frac{a}{b}$ 同时也是"a 除以 b"的另一种写法 |
| **幂**（power / exponent） | 同一个数连乘的缩写，$a^n$ 表示 n 个 a 相乘 |
| **对数**（logarithm） | 指数的反问句："$a$ 的几次方等于 $x$？"答案就是 $\log_a x$ |
| **科学计数法**（scientific notation） | 把数写成"一位整数带小数 ×10 的幂"，如 $3\times10^8$，专治天文数字和细菌大小 |
| **方程**（equation） | 含未知数的等式，解方程就是找出让等号成立的那个值 |
| **不等式**（inequality） | 用小于、大于表示大小关系，它的解通常是一个范围而不是一个点 |
| **阶乘**（factorial） | 从 1 连乘到 n 记作 $n!$，如 $4!=24$，是排列组合的原材料 |

## 图形与几何

| 术语 | 一句话解释 |
| --- | --- |
| **内角和**（angle sum） | 三角形三个内角加起来恒等于 180°，边数更多的多边形可用 $(n-2)\times180^\circ$ 算 |
| **勾股定理**（Pythagorean theorem） | 直角三角形两条直角边的平方和等于斜边的平方：$a^2+b^2=c^2$ |
| **圆周率**（pi, $\pi$） | 圆的周长与直径之比，任何圆都一样，约等于 3.14159，是个无限不循环小数 |
| **弧长**（arc length） | 圆周上的一段长度，它占整圆的比例就是圆心角占 360° 的比例 |
| **弧度**（radian） | 另一种量角的单位：弧长恰好等于半径时对应的角就是 1 弧度，一整圈是 $2\pi$ |

## 函数与图像

| 术语 | 一句话解释 |
| --- | --- |
| **函数**（function） | 一台输入输出机器：每个输入只对应唯一输出 |
| **斜率**（slope） | 直线的倾斜程度：每向右走一格，升高几格 |
| **抛物线**（parabola） | 二次函数的图像，对称的 U 形曲线，扔出去的篮球走的就是这条路 |

## 三角函数与振动

| 术语 | 一句话解释 |
| --- | --- |
| **正弦**（sine, sin） | 单位圆上那一点的纵坐标；在直角三角形里就是对边比斜边 |
| **余弦**（cosine） | 单位圆上那一点的横坐标；在直角三角形里就是邻边比斜边 |
| **振幅**（amplitude） | 波上下摆动的最大幅度，决定声音有多响 |
| **频率**（frequency） | 每秒重复多少个完整周期，单位赫兹（Hz），决定音调高低 |
| **相位**（phase） | 波在一个周期里走到了哪个位置，决定几列波之间的错位关系 |
| **拍频**（beat frequency） | 两个相近频率叠加产生"嗡——嗡——"起伏，起伏速率等于两频率之差 |

## 数列与归纳法

| 术语 | 一句话解释 |
| --- | --- |
| **等差数列**（arithmetic sequence） | 相邻两项差恒定的数列，如 2, 5, 8, …（公差 3），楼梯式增长 |
| **等比数列**（geometric sequence） | 相邻两项比值恒定的数列，如 1, 2, 4, …（公比 2），滚雪球式增长 |
| **数学归纳法**（mathematical induction） | 多米诺证明法：证第一块会倒 + 每块倒下会推倒下一块，于是全部都倒 |
| **斐波那契**（Fibonacci sequence） | 每一项等于前两项之和的数列：1, 1, 2, 3, 5, 8, …，花瓣与兔子的数学 |

## 计数、概率与统计

| 术语 | 一句话解释 |
| --- | --- |
| **排列**（permutation） | 从 n 个里挑 k 个还要讲究顺序，"谁第一谁第二"有讲究就用它 |
| **组合**（combination） | 从 n 个里挑 k 个不排顺序，只看选了谁不看队形 |
| **大数定律**（law of large numbers） | 试验次数足够多时，频率会稳定地贴住概率——赌场的底气所在 |
| **标准差**（standard deviation） | 数据离平均值平均有多远，数字越大波动越剧烈 |

## 数论

| 术语 | 一句话解释 |
| --- | --- |
| **模运算**（modular arithmetic） | 只关心除以 n 的余数的算术，本质是"时钟算术"：13 点就是下午 1 点 |
| **素数**（prime number） | 大于 1 且只能被 1 和自身整除的数，是整数的原子 |
| **最大公约数**（greatest common divisor, gcd） | 能同时整除两个数的最大整数，欧几里得算法用余数迭代高效求出 |
| **同余**（congruence） | 除以同一个数余数相同就叫同余，记作 $a\equiv b \pmod{n}$ |

## 线性代数

| 术语 | 一句话解释 |
| --- | --- |
| **向量**（vector） | 既有大小又有方向的量，写成一组有序的数（坐标），空间里的箭头 |
| **点积**（dot product） | 对应坐标相乘再相加一个数，衡量两个向量方向有多"合拍" |
| **矩阵**（matrix） | 矩形的数字阵列，也可以读作"一次空间变换的操作说明书" |
| **线性变换**（linear transformation） | 保持加法和缩放关系的空间变换，旋转、拉伸、剪切都是 |
| **行列式**（determinant） | 方阵对应的一个数值，表示变换把面积/体积放大了几倍，为 0 说明空间被压扁了 |
| **基**（basis） | 张成整个空间所需的最少一组方向，换基就是换一套坐标系描述同一个世界 |
| **投影**（projection） | 把向量垂直压到某条直线或某个平面上留下的影子 |
| **正交性**（orthogonality） | 互相垂直、互不干扰，代数判据是点积为零——傅里叶分析的命脉 |

## 复数

| 术语 | 一句话解释 |
| --- | --- |
| **虚数单位**（imaginary unit） | 记作 $i$，定义为 $i^2=-1$，让负数也能开平方 |
| **虚数**（imaginary number） | 平方后仍为负数的数（形如 $bi$）；它住在实轴之外，是复数的构件 |
| **复平面**（complex plane） | 横轴放实部、纵轴放虚部的坐标系，复数从此变成平面上的点 |
| **共轭**（complex conjugate） | 实部不变、虚部变号的搭档：$a+bi$ 的共轭是 $a-bi$，复平面上关于实轴的镜像 |
| **极形式**（polar form） | 用模（离原点多远）和辐角（朝哪个方向）来定位一个复数 |
| **欧拉公式**（Euler's formula） | $e^{i\theta}=\cos\theta+i\sin\theta$，把指数与三角函数焊在一起的天桥 |

## 微积分

| 术语 | 一句话解释 |
| --- | --- |
| **极限**（limit） | 无限逼近时最终贴住的值，微积分的地基 |
| **导数**（derivative） | 瞬时变化率，几何上是图像在某点的切线斜率 |
| **链式法则**（chain rule） | 复合函数求导像剥洋葱：外层的导数乘以内层的导数 |
| **定积分**（definite integral） | 函数曲线下方夹出的（带正负号的）面积 |
| **黎曼和**（Riemann sum） | 用一排细长矩形逼近曲边面积，矩形越细越像，积分由此而生 |
| **微积分基本定理**（fundamental theorem of calculus） | 求导与积分互为逆运算：$\int_a^b F'(x)\,dx=F(b)-F(a)$ |
| **收敛**（convergence） | 无穷多项/次越加越贴近某个确定的目标值，如 $\frac12+\frac14+\frac18+\cdots=1$ |
| **发散**（divergence） | 不收敛：总和冲向无穷或来回晃荡没有归宿 |

## 级数与信号

| 术语 | 一句话解释 |
| --- | --- |
| **泰勒级数**（Taylor series） | 用多项式在某一点附近模仿光滑函数，次数越高模仿得越像 |
| **傅里叶级数**（Fourier series） | 在适当条件下，把周期信号拆成一堆不同频率正弦波的叠加——"波形鸡尾酒" |
| **DFT**（discrete Fourier transform） | 离散傅里叶变换：把 N 个采样点换算成各频率成分的配料表 |
| **频谱**（spectrum） | 信号的配方清单：每种频率成分各占多少份量，一眼看出信号由什么组成 |
