# 混沌：logistic 映射与倍周期分岔

## 1. 从一个场景开始

养殖场的工程师建了个极简模型预测鱼塘：明年鱼量比例 = 今年鱼量 × 出生推力 × 剩余空间。就一行乘法，纸笔都能算。可当"繁殖率"调到某个数值以上时，同一台电脑、同一个起点，只差把初值多写一个万分位——一百代之后两条轨迹彻底各奔东西。规则完全确定，未来却像掷骰子。这一课的目标，就是亲手把这个"确定的骰子"造出来。

## 2. 直觉解释

想象一根杠杆两端挂着两种力量：**出生推力**想让种群按比例翻上去，**拥挤压力**在空间不够时把它往下拽。写成一条迭代口号：

$$x_{n+1} = r\,x_n(1-x_n)$$

$x_n$ 是"今年种群占满塘的比例"，$1-x_n$ 就是"还空着的地皮"，$r$ 是同时拨动两个力的旋钮。

- $r$ 小（比如 2.5）：拥挤压得住冲动，几年后鱼量稳稳停在一个数上；
- $r$ 调大一点（3.2）：稳态反而失稳，鱼量隔年忽多忽少，进了一种"两年节拍"；
- 再大（3.5、3.55）：节拍再次翻倍，四年一轮、八年一轮……
- 越过某条线（约 3.57）：节拍变成"永不重复"，但仍被同一条乘法规则死死管着——这就是**混沌**。

这套"稳定—翻倍—再翻倍—乱舞"的阶梯叫**倍周期分岔**。你早在斐波那契递推里见过"上一代决定下一代"的味道，只不过那里的序列乖巧收敛，而这里会翻脸。

## 3. 正式定义

给定参数 $r\in(0,4]$，**logistic 映射**定义为 $f_r(x)=r\,x(1-x)$，自变量限制在区间 $[0,1]$ 内（种群比例）。反复应用 $f_r$ 得到轨道 $x_{n+1}=f_r(x_n)$。

**不动点**满足 $x^\ast=f_r(x^\ast)$，解二次方程得两个根：

$$x_1^\ast=0,\qquad x_2^\ast=\frac{r-1}{r}.$$

离散迭代的稳定性判据由 [平衡点与稳定性](./30-equilibrium-stability.md) 的姊妹版给出：不动点附近一步映射的放大倍数是导数绝对值，$|f_r'(x^\ast)|<1$ 则稳定，$>1$ 则失稳。代入 $f_r'(x)=r-2rx$：

$$\left|f_r'(x_2^\ast)\right|=|2-r|,\qquad \text{故 } 1<r<3 \text{ 时非零不动点稳定}.$$

$r$ 越过 3 后，判据告诉我们的唯一信息是"这里待不住了"。轨道于是搬去一个**两点轮换**：$a,b$ 使 $b=f(a),a=f(b)$；这就是**周期 2 吸引子**。继续加大 $r$，周期依序 $2\to4\to8\to16\cdots$ 翻倍，最终在 $r\approx 3.5699$ 之后轨道长期行为不再落入任何有限循环——**混沌区**（其间偶有周期 3 之类的小岛窗口）。

## 4. 分步例题

取 $r=3.2$、$x_0=0.2$，逐代迭代：

1. 第 1 步：$x_1=3.2\times0.2\times0.8=0.512$；
2. 第 2 步：$x_2=3.2\times0.512\times0.488\approx0.7995$；
3. 第 3 步：$x_3\approx0.5129$；第 4 步又回 $\approx0.7995$——节奏已经锁定；
4. 先用判据核对：$x_2^\ast=(3.2-1)/3.2=0.6875$，斜率 $f'(0.6875)=2-3.2=-1.2$，绝对值大于 1，所以零不动点与比例不动点都留不住轨道；
5. 结论：$r=3.2$ 的长期归宿是两值轮换（后面算准为 $0.513\leftrightarrow0.800$），这正是**一次倍周期分岔**后的世界。

注意分岔的准头：斜率恰好在 $-1$ 处穿越边界（即 $2-r=-1\Leftrightarrow r=3$），比在 $+1$ 处更危险——负方向的失稳正是"隔年振荡"的通道。

### 实验 2：八个增长率的归宿流水账

```python title="八个增长率参数的长期归宿账本"
rs = [2.5, 2.8, 3.1, 3.2, 3.5, 3.55, 3.83, 3.9]   # 待试的八个增长率

for r in rs:                                  # 外层循环挨个换参数
    x = 0.31                                  # 从 31% 的鱼塘饱和度出发
    for k in range(600):                      # range 生成 0..599：先扔掉六百步老底子
        x = r * x * (1 - x)
    tail = []                                 # 收敛后连续四次取值存进列表
    for k in range(4):
        x = r * x * (1 - x)
        tail.append(round(x, 3))              # append 把新样本接到表尾
    print(r, tail)                            # 正文引用的就是这批数字
```

输出（每个 `tail` 是连续四代的占比）：

- `2.5 [0.6, 0.6, 0.6, 0.6]`——稳如磐石的不动点；
- `2.8 [0.643, 0.643, 0.643, 0.643]`——仍是单点，只是位置更高了；
- `3.1 [0.558, 0.765, 0.558, 0.765]` 与 `3.2 [0.513, 0.799, 0.513, 0.799]`——两值交替，周期 2；
- `3.5 [0.827, 0.501, 0.875, 0.383]`——四个不同值循环，周期 4；
- `3.55 [0.887, 0.355, 0.813, 0.54]`——四次采样互不相同（其实是周期 8 的一半切片）；
- `3.83 [0.957, 0.156, 0.505, 0.957]`——混沌区里突然冒出的周期 3 小岛窗口；
- `3.9 [0.96, 0.151, 0.499, 0.975]`——不再有任何可辨节律。

### 实验 3：初值敏感性——蝴蝶效应现场

```python title="相差万分之一的两个鱼塘"
import matplotlib.pyplot as plt               # 绘图库，负责把轨迹画出来

r = 3.9                                       # 混沌区的代表参数
xa, xb = 0.2, 0.2001                          # 两个仅差 0.0001 的初始比例
sa, sb = [], []                               # 各自记录六十代轨迹

for k in range(60):
    xa = r * xa * (1 - xa)
    xb = r * xb * (1 - xb)
    sa.append(xa)
    sb.append(xb)

plt.plot(sa, label="start 0.2")               # label 为图例准备名字
plt.plot(sb, label="start 0.2001", linestyle="--")
plt.xlabel("generation")
plt.ylabel("population share")
plt.legend()
plt.title("同一条公式的两条命运")
plt.show()                                    # 渲染画布

diff = max(abs(a - b) for a, b in zip(sa, sb))    # zip 并行配对，找最大差距
print("最大偏离 =", round(diff, 3))
```

运行可见：前二十代两条曲线几乎重合，到第 60 代一个落在 $0.881$、另一个落在 $0.315$，随后任何一步的最大偏离都被拉开到接近满塘尺度（约 $0.85$）。短期预测影响不大，中期预测却是死刑判决——预报精度必须以指数速度追赶时间。回到 $r=2.5$ 重跑一遍，偏差永远缩在小数点后几位：敏感性不是公式的固有属性，而是参数走出某些区域后的赠品。

## 6. 常见误区

:::warning[常见误区]

**误区一**：你以为规则确定就必然可预测。倍周期阶梯之后的轨道每一步都严格按公式算出，却因为初值敏感而在中期彻底失控；"确定"与"可预报"是两回事。

**误区二**：你以为混沌就是随机。同一起点重跑一万遍得到一模一样的序列——它是可以被完整复算的"确定性骰子"，这也是混沌序列能充当伪随机数的原理。

**误区三**：你以为 $r$ 可以随便放大。实验时把 $r$ 调过 4，$x$ 一旦冲出 $[0,1]$ 就直接跳到负数并一路奔向负无穷——模型只在 $r\le4$ 内有意义。

:::

## 7. 练习

下面的代码想汇报 $r=3.2$ 的三个事实：不动点在哪、失稳的证据是什么、以及失稳后轨道真正搬去了哪。前三行是对的，最后一行想当然地认为"归宿仍是不动点"——请替换成老老实实的迭代：

```exercise
# @title: 练习：不动点失稳之后，长期归宿搬去了哪
# @check: 0.6875
# @check: -1.2
# @check: 799
# @check: 513
# @hint: 斜率比 -1 还小，说明不动点留不住轨道；学正文分步例题那样从 x=0.31 迭代几百步，把连续两次取值各放大一千倍打印成整数。
r = 3.2

star = (r - 1) / r                 # 非零不动点，这一行是对的
slope = r - 2 * r * star           # 不动点处斜率，这一行也是对的
print(round(star, 4))
print(round(slope, 4))

x = 0.31                           # ← 接下来：别再把 star 打印出来了
print(round(star, 3))              # 想当然：以为归宿仍是不动点
```

<details>
<summary>点开查看逐步解答</summary>

第一步：$x^\ast=(r-1)/r=(3.2-1)/3.2=0.6875$，这是"理论上的休息点"。

第二步：$f'(x^\ast)=2-r=-1.2$。绝对值超过 1 且方向为负——每次迭代不但放大误差还翻转符号，这正是"隔年振荡"的签名，而不是单调漂移。

第三步：失稳后轨道搬到周期 2 循环上。正确代码：

```python
r = 3.2

star = (r - 1) / r
slope = r - 2 * r * star
print(round(star, 4))          # 0.6875
print(round(slope, 4))         # -1.2

x = 0.31
for k in range(500):           # 老老实实迭代五百步
    x = r * x * (1 - x)

first = x                      # 循环里的第一个取值
second = r * first * (1 - first)
print(round(1000 * first))     # 799
print(round(1000 * second))    # 513
```

判断依据：输出对稳定，重跑得到同样两个数——$0.799\leftrightarrow0.513$；两值互代一步正好还原对方。把它们除以一千，就得到正文实验账本里 $r=3.2$ 那一行的轮换对。对照第四节的手算：比例不动点并不是终点，而是被加倍节拍取代了的"曾经的目标"。

</details>

## 8. 边界与选读

<details>
<summary>选读 · Feigenbaum 常数与周期三定理</summary>

1970 年代，Feigenbaum 发现相邻两次倍周期的间距之比趋于普适常数 $\delta\approx4.669$——无论换正弦映射还是别的单峰映射，这个比值都一样，倍周期阶梯有一种超越具体公式的"解剖学"。另外李天岩与约克证明了著名的"周期三意味着混沌"：只要某参数下出现稳定的周期 3 循环（比如 $r\approx3.83$ 的窗口），同一系统在同一区域内也必然存在任意周期的轨道与非周期的混沌轨道——小岛不是世外桃源，而是混沌的官方招牌。

</details>

本课只处理一个离散玩具映射：连续时间系统的混沌要等到洛伦兹方程那样的三维 ODE 才登场；定量刻画敏感性需要李雅普诺夫指数，刻画吸引子形状需要分形维数，这些都留给动力系统专题。真实生态也不会年复一年用同一条 $r$——下一课就把"物种互动"请回来。
