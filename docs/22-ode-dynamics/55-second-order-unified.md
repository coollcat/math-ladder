# 同一个二阶方程的三种外衣

## 1. 从一个场景开始

调琴师说：音叉敲响后声音会拖尾，尾音越长音色越"润"。电工说：收音机的选台回路也这样，电压一激就会嗡嗡振荡，电阻越大停得越快。建筑工程师说：摩天楼在风里摇晃也是同一个道理，装上阻尼器它就稳了。三个人用的仪器毫无交集，可如果把各自桌上的方程摆到一起——一模一样。这一课就来认领这份巧合：**同一个数学骨架，穿着三种行业的衣服**。认领了它，你学过一遍就等于学过三遍。

## 2. 直觉解释

上一课你已经跟 $my''+cy'+ky=F_0\cos(\omega t)$ 打过交道。当时的三兄弟各有名字：

| 机械振动 | RLC 电路 | 生活语言 |
| --- | --- | --- |
| 质量 $m$ | 电感 $L$ | 不愿意被推着跑的惰性 |
| 阻尼系数 $c$ | 电阻 $R$ | 把能量搅成热耗掉的家伙 |
| 劲度 $k$ | 电容倒数 $1/C$ | 扳回原位的回复本领 |
| 外力 $F(t)$ | 电源电压 $E(t)$ | 谁在持续折腾系统 |

对应关系不是修辞而是**逐字翻译**：方程 $Lq''+Rq'+\frac{1}{C}q=E(t)$ 描述电容上的电荷 $q$，它与 $mx''+cx'+kx=F$ 共享全部结构——电感的磁通不肯突变（惰性）、电阻烧掉能量（阻尼）、电容放回电荷（回复力）。梁弯曲的简化模型再把同样的结构搬上土木舞台。

更妙的是，真正决定"长相"的并不是这三个参数本身，而是它们的**两个比值**：

- 固有频率 $\omega_0=\sqrt{k/m}$：没人碰它时，它自己想念的节拍；
- 阻尼比 $\zeta=\dfrac{c}{2\sqrt{mk}}$：耗散扳腕子回复的胜算。

$\omega_0$ 决定振荡快慢，$\zeta<1$ 会荡、$\zeta=1$ 最快收场、$\zeta>1$ 一蹶不振。三种外衣之内，掌舵的始终只有这两位。

## 3. 正式定义

凡形如

$$ay''+by'+cy=f(t),\qquad a>0$$

的线性常系数二阶方程，两边除以 $a$ 都能化成**标准形**

$$y''+2\zeta\omega_0y'+\omega_0^2y=g(t).$$

| 记号 | 含义 |
| --- | --- |
| $\omega_0$ | 无阻尼固有频率，由 $\omega_0^2=c/a$（即 $k/m$）定义 |
| $\zeta$ | 阻尼比，$\zeta=b/(2\sqrt{ac})$ |
| 特征根 | $r=-\zeta\omega_0\pm\omega_0\sqrt{\zeta^2-1}$ |

判型只看 $\zeta$：小于 1 时根是复数、解里带着衰减的余弦（欠阻尼，会荡）；等于 1 是临界阻尼（最快回到零线且不过冲）；大于 1 时两个实根（过阻尼，慢性爬回）。上一课的共振结论也随字照译：外力频率靠近 $\omega_0$ 且 $\zeta$ 很小时，振幅巨大——调琴师听到的共鸣、电工怕的自激啸叫、土木人防的风致共振，全是同一句话。

## 4. 分步例题

**把一台电路翻译成一套弹簧**：设回路满足 $0.5q''+q'+12.5q=E(t)$。

1. 认骨架：二次项系数 $a=0.5$、一次项 $b=1$、零次项 $c_{stiff}=12.5$；
2. 对字典：质量 $m=0.5$ 千克、阻尼 $c_d=1$ 牛·秒/米、劲度 $k=12.5$ 牛/米；
3. 算节拍：$\omega_0=\sqrt{12.5/0.5}=\sqrt{25}=5$ 弧度/秒；
4. 算手感：$\zeta=\dfrac{1}{2\sqrt{0.5\times12.5}}=\dfrac{1}{2\times2.5}=0.2$;
5. 结论：欠阻尼，合闸后电荷来回震荡约五拍一轮、慢慢收干——工程师按 $\omega_0=5$ 选电台中心频率，按 $\zeta=0.2$ 预判拖尾长度。两种行业从此可以互相转包工程。

无论弹簧、电路还是高楼，欠阻尼响应都被夹在这条指数走廊 $\pm e^{-\zeta\omega_0 t}$ 里按自己的节拍晃。滑块 $w$ 相当于在搬动 $\sqrt{k/m}$，滑块 $d$ 相当于拧 $\zeta\omega_0$——旋钮只有两个，这就是"无量纲化"的威力：千行万行的物理参数账，最后只剩两位乘客。

### 实验 2 · 三件外衣当众报数

```python title="三个行业共用一对灵魂参数"
import math                                # math 提供 sqrt 开方

# (行业名, 惰性 a, 耗散 b, 回复 c)：三个系统的系数各不相同
systems = [
    ("spring 弹簧", 1.0, 2.0, 25.0),
    ("RLC 电路",   0.5, 1.0, 12.5),
    ("beam 梁",    2.0, 4.0, 50.0),
]

for name, a, b, c in systems:              # for 可直接按元组解包循环
    w0 = math.sqrt(c / a)                  # 固有频率 sqrt(k/m)
    zeta = b / (2 * math.sqrt(a * c))      # 阻尼比 b/(2*sqrt(ac))
    print(name, "omega0 =", round(w0, 3), "zeta =", round(zeta, 3))
```

三行输出都写着 `omega0 = 5.0`、`zeta = 0.2`——尽管第一列里设备的量纲天差地别。理论预测：把三套设备的响应曲线画在同一张图上，应当三条线完全重合。你还可以顺手把任一行的三个数整体乘 2 再跑一次，两个参数依旧纹丝不动——比例才是主角。

## 6. 常见误区

:::warning[常见误区]
- **你以为系数越大响应越猛，其实要看它是哪一挂**：加大劲度 $k$ 让回复更快（$\omega_0$ 升高），加大质量 $m$ 却让一切变慢变沉；两者单独都改变节奏，唯独**同步等比缩放三者**才不影响 $\omega_0$ 与 $\zeta$。
- **你以为临界阻尼是最快的"急刹车"，其实它的卖点是不反弹**：轻微欠阻尼更早穿过零线但会回弹几次；$\zeta=1$ 保证单调归位——电子秤指针要求快速且不再晃，选的就是临界附近。
- **你以为三种系统只是"像一像"，其实方程层面就是同一条**：字典表里的每一格对应的是同名系数而非类比修辞；正因如此，电路实验台上能替弹簧测出整套振动结论（这是机电模拟技术的立身之本）。
:::

## 7. 练习

一个隔震平台的参数登记如下，但负责计算的实习生把固有频率的方向写反了。请修正那一行，让报告通过审核：

```exercise
# @title: 固有频率方向修正报告
# @check: 5.0
# @check: 1.0
# @check: critical
# @hint: 惯性越大应当越迟钝——固有频率随 k 变大而变大、随 m 变大而变小，所以根号下应放 k 除以 m；算完 zeta 后对照三分法取名。
import math                    # math.sqrt 开方

# 平台等效参数：质量 4 千克、劲度 100 牛/米、阻尼 40 牛·秒/米
m = 4
k = 100
c = 40

omega0 = math.sqrt(m / k)      # ← 根号里的方向反了吗？
zeta = c / (2 * m * omega0)
print(round(omega0, 4))
print(round(zeta, 4))

if zeta < 1:                   # 阻尼比三分法自动判型
    status = "under-damped"
elif zeta > 1:
    status = "over-damped"
else:
    status = "critical"
print(status)
```

<details>
<summary>点开查看逐步解答</summary>

标准形的定义站这边：$\omega_0^2=k/m$——回复越强、惰性越小，节拍越快。修正如 `omega0 = math.sqrt(k / m)`，得 $\omega_0=\sqrt{100/4}=5.0$。

随之 $\zeta=\dfrac{40}{2\times4\times5}=1.0$ 整整压线：既不到欠阻尼的活跃、也没有过阻尼的拖沓，恰好**临界阻尼**，`status` 分支落到 `critical`。（初始的错误版本会给出 $\omega_0=0.2$、$\zeta=25$ 这种一眼荒唐的报告——把方向搞反的频率不是慢，是错得离谱。）工程上隔震平台最爱的就是这个点位：吸收冲击后立刻回到中线，绝不余震。

</details>

## 8. 边界与选读

本课的统一视图只罩住**线性常系数**的范围。摆幅一大，$\sin\theta$ 就不能近似成 $\theta$，单摆变成非线性选手，共用一个标准形的日子结束了；悬索桥的多模态耦合要用矩阵版的同类方程（特征模态分解后每个模态仍是本课标准形）；分布参数系统（真梁、真弦）则连续无穷个模态打包出现。此外，参数识别问题（从实测响应反推 $\omega_0,\zeta$）属于工程辨识课程的地盘。

<details>
<summary>选读 · 为什么比值掌舵：除以 m 之后的标度律</summary>

对方程 $ma''+ba'+ca=0$ 两边除以 $a$（惰性），得 $x''+\tfrac{b}{a}x'+\tfrac{c}{a}x=0$。可见绝对数值从第一步起就被扔掉了，幸存的只有每单位惰性的回复率与耗散率。把它们重新拼装：令 $s=t\,\omega_0$ 做时间缩放（用系统的"私有时钟"取代秒表），方程化为 $x''+2\zeta x'+x=0$——只剩唯一形参 $\zeta$。这解释了实验 2 里三套设备读数合一的原因：不同外衣只是同一无量纲动力学在不同单位制下的投影。量纲分析的这条纪律贯穿后续章节：先定标度、再看形状。

</details>
