## 实战挑战 · 探空火箭的发射账本

情境原创；公式出自齐奥尔科夫斯基 1903 年论文《利用喷气装置研究宇宙空间》（参见国家航天局官网《宇航之父：康斯坦丁·爱德华多维奇·齐奥尔科夫斯基》）。

学生航天社要发射探空火箭「阶梯一号」：起飞总质量 $m_0 = 2000$ 千克（含燃料 1500 千克），燃尽后干重 $m_f = 500$ 千克；发动机喷气速度 $v_e = 2400$ 米/秒，燃料按每秒 50 千克的恒定速率烧掉，共烧 30 秒。火箭垂直上升，重力加速度取 $g = 9.8$ 米/秒²，忽略空气阻力。齐奥尔科夫斯基公式直接给你（不必推导）：不记重力时的理想速度增量

$$\Delta v = v_e\,\ln\frac{m_0}{m_f}$$

本题需要的对数：$\ln 4 \approx 1.3863$。

**(a)** 求理想关机速度增量 $\Delta v$（保留到个位）；

**(b)** 理想值没有扣「重力损耗」。飞行中质量 $m(t)=m_0-50t$，净加速度为 $a(t)=v_e\cdot 50/m(t)-g$。用步长 $h=6$ 秒的 Euler 法模拟前两步（$t=0$ 到 $t=12$），打印每步结束时的速度。第一步骨架已示范且正确，第二段藏着两处错误：

```exercise
# @title: 实战挑战：火箭上升的两步 Euler 模拟
# @check: 3327
# @check: 301.2
# @check: 665.929
# @hint: 净加速度要减去 g；第二步开始前燃料又烧了 mdot*h 千克——先更新质量 m = m - mdot*h，再算这一步的加速度。
import math

ve = 2400     # 喷气速度（米/秒）
mdot = 50     # 燃料消耗率（千克/秒）
g = 9.8       # 重力加速度（米/秒^2）
h = 6         # 时间步长（秒）

ideal_dv = ve * math.log(2000 / 500)
print(round(ideal_dv))
m = 2000      # t=0 时的总质量（千克）
v = 0.0       # 起飞速度
a = ve * mdot / m - g
v = v + a * h
print(round(v, 3))

a = ve * mdot / m
v = v + a * h
print(round(v, 3))
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 质量比 $m_0/m_f = 2000/500 = 4$，于是

$$\Delta v = 2400\times\ln 4 \approx 2400\times 1.3863 \approx 3327\ \mathrm{m/s}$$

**(b)** 正确的两步账本：

- 第一步（$m=2000$）：推力加速度 $2400\times50/2000=60$，净加速度 $60-9.8=50.2$，$v_1 = 50.2\times6 = 301.2$；
- 第二步（$m=1700$）：推力加速度 $2400\times50/1700\approx70.588$，净加速度约 $60.788$，$v_2 = 301.2+60.788\times6\approx665.929$。

修正后的代码：

```python
import math

ve = 2400     # 喷气速度（米/秒）
mdot = 50     # 燃料消耗率（千克/秒）
g = 9.8       # 重力加速度（米/秒^2）
h = 6         # 时间步长（秒）

ideal_dv = ve * math.log(2000 / 500)
print(round(ideal_dv))       # 3327

m = 2000      # t=0 时的总质量（千克）
v = 0.0       # 起飞速度
a = ve * mdot / m - g
v = v + a * h
print(round(v, 3))           # 301.2

m = m - mdot * h            # 先更新质量：烧掉 300 千克
a = ve * mdot / m - g
v = v + a * h
print(round(v, 3))          # 665.929
```

对照着看：12 秒只攒到约 666 米/秒，而 30 秒烧完的理想增量有 3327 米/秒——重力每秒都在抽走 9.8 米/秒，这就是航天术语里的「重力损耗」；步长越小，Euler 账本记得越细。

工程哨卡：真实型号还要扣大气阻力、考虑推力随高度变化，并且像齐奥尔科夫斯基设想的「火箭列车」那样甩掉烧空的壳体——干重变小、质量比变大，同样的燃料能换更多速度。
</details>

## 实战挑战 · 欧拉法别丢了斜率

欧拉法一步：$y_{n+1} = y_n + f(t_n, y_n)\cdot h$，加的是"当前斜率 × 步长"。方程 $y'=y$ 在 $y(0)=2$、步长 $h=0.1$ 时，一步后 $y = 2 + 2\times0.1 = 2.2$。下面这题丢了斜率里的 $y$，修到输出 `2.2`：

```exercise
# @title: 实战挑战：欧拉法别丢了斜率
# @check: 2.2
# @hint: y' = y，斜率就是当前 y 值本身；加的是 y*h，不是光秃秃的 h。
y = 2.0          # 初始值 y(0) = 2
h = 0.1          # 步长
y_new = y + h    # ← 问题在这：漏了斜率的 y 因子
print(round(y_new, 2))
```

<details>
<summary>点开查看逐步解答</summary>

欧拉法的增量是"斜率 × 步长"，而 $y'=y$ 的斜率就是当前的 $y$：

```python
y_new = y + y * h    # y + f(y)·h = 2 + 2*0.1
print(round(y_new, 2))   # 2.2
```

改完：$2 + 2\times0.1 = 2.2$。初始代码 `y + h` 相当于把斜率当成了常数 1，只有当 $y=1$ 时才碰巧对。方程 $y'=y$ 的解是 $e^t$，精确值 $2e^{0.1}\approx2.21$，欧拉一步 $2.2$ 已相当接近——这正是本章数值解法"用斜率外推"的全部思想。

</details>
