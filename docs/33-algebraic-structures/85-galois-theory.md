# 伽罗瓦理论选讲：对称决定可解性

## 1. 从一个场景开始

二次方程 $ax^2+bx+c=0$ 的求根公式人人背过；三次、四次方程更难缠，但文艺复兴时期的数学家也硬生生捣出了含嵌套开方的公式。接下来五百年，无数人扑向五次方程——统统失败。

失败得如此整齐，反而让人起疑：会不会压根**没有**这种公式？答案由二十岁出头的伽罗瓦给出，而且凶悍得多：能不能用加减乘除加开方解出来，这件事被方程**根之间的对称**一手决定。对称性够嫩就放行，够乱就封死——本章前头一路铺垫的群论，在这一课结出最锋利的果实。

## 2. 直觉解释

从温柔的情况开始。$x^2-3x+2=0$ 的两个根是 $x_1=1$、$x_2=2$。把两个根对调位置看看：

| 表达式 | 原值 | 对调后 |
| --- | --- | --- |
| $x_1+x_2$ | $3$ | $3$ 不变 |
| $x_1\cdot x_2$ | $2$ | $2$ 不变 |
| $x_1-x_2$ | $-1$ | $1$ 变号 |

第一行正是韦达定理：有理数"看得见"的只有**对称的整体量**。求根公式的本质，就是一层层剥掉这些对称外衣：先对调两个根（剥一次平方根 $\sqrt{\Delta}$），再没有了——两层洋葱而已，所以二次方程人人能解。

再看劲敌。某特殊五次方程的根之间允许更狂野的重排：不仅能对调两个，还能把五个根整体转圈（第 70 课的置换语言一秒进场）。问题在于**剥壳操作的开方**只能对付"层层整齐堆放"的对称结构——像第 25 课钟面那种一圈到底的循环群每剥一层缩一截；而五个根的全对称群内部塞着一个拆不动的实心硬核。洋葱长成了实心疙瘩，刀再快也无从下口。这就是"五次方程没有根式公式"的全部直觉。

## 3. 正式定义

设 $K\subseteq E$ 是两个数域（四则运算自洽的集合）。保持 $K$ 中每个数不动、且保乘法加法的 $E$ 到自身的一一映射叫 **$K$-自同构**；全体自同构在复合下成群，记作

$$\mathrm{Gal}(E/K)=\lbrace \sigma:E\to E \mid \sigma \text{ 保运算且} \sigma(k)=k,\ \forall k\in K\rbrace$$

方程 $f(x)=0$ 在 $\mathbb{Q}$ 上添加所有根得到的域记作 splitting field；它的自同构群——根之间真实活着的重排全体——称为方程的 **Galois 群**。

**可解群**：群 $G$ 若有一条逐步递减的正规子群链，从 $G$ 一路拆到单位元，且相邻两层的商都是循环群，则称 $G$ 可解。想象洋葱层：每一刀切下一整圈循环的皮。

**定理（伽罗瓦）**：多项式方程可用根式求解当且仅当它的 Galois 群可解。

系数域取 $\mathbb{Q}$ 时，同态与核的语言接上：每个自同构固定基域，$\mathrm{Gal}(E/K)$ 对应"作用在根集上的陪集差"，第 45 课的同态视角在此全线复活。

## 4. 分步例题

**例（二次的完整解剖）**：$f(x)=x^2-2$，根为 $\pm\sqrt{2}$，splitting field 是 $E=\mathbb{Q}(\sqrt{2})=\lbrace a+b\sqrt{2}\mid a,b\in\mathbb{Q}\rbrace$。

1. 找映射：任何自同构必须固定全部有理数，所以 $a+b\sqrt{2}$ 的去向完全由 $\sqrt{2}$ 去哪决定；
2. 守规矩：$(\sqrt{2})^2=2$ 必须维持，于是 $\sqrt{2}$ 只能映到 $\pm\sqrt{2}$——恰有两种选择；
3. 得群：恒等映射 + 符号翻转，$\mathrm{Gal}(E/\mathbb{Q})\cong\mathbb{Z}_2$——一只第 25 课见过的最小循环群；
4. 解剖判决：$\mathbb{Z}_2$ 可解（一层皮），对应剥掉 $\sqrt{\Delta}$ 一步到位。事实与理论严丝合缝：二次方程有公式；
5. 对照验伤：一般五次方程的 Galois 群常充满整个 $S_5$（120 个元素），链条在第 60 层就撞上不可拆的单群 $A_5$——洋葱在此变质。而 Galois 群可解是根式解的**必要条件**，$S_5$ 不合格，全局判死。

### 实验 2（python）：验证 $\sqrt{2}$ 翻面确实保住乘法

```python title="符号翻转是一个货真价实的自同构"
def mul(p, q):
    # (a + b√2)(c + d√2) = ac + 2bd + (ad + bc)√2，只用列表首末两项存放
    return [p[0] * q[0] + 2 * p[1] * q[1], p[0] * q[1] + p[1] * q[0]]

def flip(z):
    # φ 把 √2 换成 −√2：只翻第二格，有理部分纹丝不动
    return [z[0], -z[1]]

lhs_a = [1, 1]     # 代表 1 + √2
lhs_b = [2, -1]    # 代表 2 − √2
product = mul(lhs_a, lhs_b)

left_side = flip(mul(lhs_a, lhs_b))     # 先相乘再翻面
right_side = mul(flip(lhs_a), flip(lhs_b))   # 各自翻面后再相乘
print(left_side == right_side)
print(flip(product))
print(flip([4, 0]))      # 有理数 4 应原地不动——这叫“固定基域”
```

两处输出 `True` 与 `[4, 0]`：翻面打乱了根的标签，却把等式的形状原样递给对方——这就是自同构。它只有翻与不翻两种活法（对应第 4 节），小小的 $\mathbb{Z}_2$ 温顺可解。

### 实验 3（python）：亲手数出一个五次方程的真实根

```python title="x^5 - 4x + 2 有几个实根？"
# 在 [-2.0, 2.0] 上铺 4001 个采样点，靠“相邻异号”计数穿零次数
xs = []
i = 0
while i <= 4000:                         # 有界 while：计数器保证循环必然结束
    xs.append(-2.0 + i * (4.0 / 4000))   # 手工 linspace：起点 + i × 步长
    i += 1

sign_changes = 0                          # 打擂台式计数器
prev = None                               # 记住上一个点的函数值符号
for x in xs:
    val = x ** 5 - 4 * x + 2              # x ** 5 即 x 的五次方
    if prev is not None and val * prev < 0:
        sign_changes += 1
    if val != 0:
        prev = val

print(sign_changes)
```

打印 `3`：三次穿零，即 $x^5-4x+2$ 恰有三个实根和一对共轭复根。这一眼信息即将在选读里引爆——配合艾森斯坦判别式的不可约性，它把方程的对称群钉死在整个 $S_5$ 上。

:::warning[常见误区]

**误区一**："次数低于五就有公式。" 准确说法是二三四次的 Galois 群恰好都可解。链条合格才放行，不是对次数开的绿灯。

**误区二**："没有根式公式等于永远解不了。" 数值近似、超越函数表达样样畅通。死的只是"加减乘除与有限次开方"这条特定的窄路。

**误区三**："Galois 群就是随便怎么交换都行的班子。" 它必须同时保住全部系数关系——很多看着无害的重排会因为破坏某个关系式而被开除出局。
:::

## 6. 练习与快问快答

初学者最常见的错误是把自同构写成"镜像大甩卖"——连同有理部分一起翻了。请修好这份坏掉的 $\varphi$：

```exercise
# @title: 练习：修好 Q(√2) 上的符号翻转
# @check: phi=[1, -1]
# @check: twice=[1, 1]
# @check: rational=[4, 0]
# @hint: 自同构必须逐字固定基域：a + b√2 里能变的只有带 √2 的第二格，a 是有理数动不得。
def flip(z):
    # ← 问题在这：两个格子都被翻了
    return [-z[0], -z[1]]

e = [1, 1]               # 表示 1 + √2
twice = flip(flip(e))    # 翻两次应该物归原主
print("phi=" + str(flip(e)))
print("twice=" + str(twice))
print("rational=" + str(flip([4, 0])))
```

<details>
<summary>点开查看逐步解答</summary>

正确写法是只翻第二格：

```python
def flip(z):
    return [z[0], -z[1]]
```

三行输出依次为 `[1, -1]`、`[1, 1]`、`[4, 0]`。初版代码连有理部分一起改邪归正，第一个突破口是有理数 `4` 被负成了 `-4`——违反了"$\forall k\in K$ 原地不动"的定义条款，它便连自同构的入场券都没拿到，更谈不上给方程做解剖。
</details>

## 7. 选读：x^5-4x+2 的死刑复核

<details>
<summary>选读 · 三实一复如何锁死 S₅</summary>

三条证据链并排摆好：

1. **不可约**：$x^5-4x+2$ 通过艾森斯坦判别式（素数 2 整除其余系数但 4 除不尽常数项），故在有理数上拆不开——根们过牢不可破的集体生活；
2. **传递性送五循环**：不可约使 Galois 群在五个根上传递行动，而传递群里必有阶为 5 的元素，在 $S_5$ 中形如五步轮换 $(r_1\,r_2\,r_3\,r_4\,r_5)$；
3. **三实一复送交换**：实验 3 数出的那对复根由复共轭负责互换，其余三个实根原地踏步——这正是单个对换（奇式重排）。

任何一个**传递**的置换群，只要手里握着哪怕一个对换，就能靠五循环把这枚对换搬运到全部十种位置，足以拼出完整的 $S_5$。最后一击：$A_5$ 单、不可解，已在本章前文登台亮相；$S_5$ 更不可解。死刑核准——正是一百九十年前埃瓦里斯特·伽罗瓦在决斗前夜信封里写下的判词。
</details>

## 8. 边界：本课不做什么

本课只验收了**根式可解性**这一件事：不给数值算法、不画根的分布地图、也不解决更高次中"哪些特例仍有公式"（比如缺三次项的 Bring 曲线另有机关）。环环相扣的五次以上世界，以及"可见对称"之外的可解性航标（模 $p$ 因子分解速查），都留给后续章节。你带走的核心资产是一句话：**工具的天花板写在对象的对称性里**。
