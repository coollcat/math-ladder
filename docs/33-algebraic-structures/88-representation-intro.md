# 表示论初步：把群变成矩阵

## 1. 从一个场景开始

本章前头，群元素一直是一串抽象符号：$r$、$r^2$、$(1\,2)$、$\sigma$。你能验证乘法表，却**看不见**它们。$C_3$ 的旋转和 $S_3$ 的一个对换，写在纸上都是字母，凭什么说它们不一样？

1896 年前后，Frobenius 和 Schur 给出一个漂亮的回答：**给每个群元素发一个矩阵当"证件照"**。旋转 120° 就发一张 $120^\circ$ 的旋转矩阵，它对平面做了什么，一眼就看清。更妙的是，群的乘法在矩阵这边自动变成矩阵乘法——于是整套线性代数（特征值、迹、不变量）瞬间为群论所用。

## 2. 直觉解释

这套"证件照"有三条纪律。

第一，**人手一张、可逆、大小一致**。每个群元素配一个同一尺寸的可逆矩阵，恒等元配单位矩阵。

第二，**乘法要保真**。先做 $g$ 再做 $h$，对应的矩阵必须正好是两张证件照的乘积：

$$\rho(gh) = \rho(g)\,\rho(h).$$

这就像翻译：翻译"先左转再前进"必须等于"翻译左转"再"翻译前进"，一个字都不能错位——顺序错了（矩阵不可交换）就会翻车。

第三，**允许"看不见全貌"**。同一群可以用很多尺寸的矩阵来演：$C_3$ 既能演成 $1\times1$（旋转变成乘一个复数 $\omega$），也能演成 $2\times2$（平面上真转 120°）。尺寸最小的那些碎片叫**不可约表示**，它们是搭建一切表示的"积木块"。

## 3. 正式定义

设 $G$ 是群，$V$ 是复数域上的线性空间。$G$ 在 $V$ 上的一个**表示**是一个群同态

$$\rho: G \to GL(V), \qquad \rho(gh)=\rho(g)\rho(h), \qquad \rho(e)=I .$$

$GL(V)$ 是 $V$ 上全体可逆线性变换（选定基后就是全体可逆矩阵），$\dim V$ 叫表示的**维数**。

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $\rho$ | 表示 | 把群元素送到可逆矩阵、并保住乘法的映射 |
| $V$ | 表示空间 | 矩阵作用的向量空间，$\dim V$ 就是表示维数 |
| $\rho(g)$ | 元素的像 | 群元素 $g$ 的"证件照"，一张可逆矩阵 |
| $\chi_\rho(g)$ | 特征标 | $\chi_\rho(g)=\operatorname{tr}\rho(g)$，只需一个数 |
| 置换表示 | 作用在集合上 | 群作用在 $n$ 元集合 $X$ 上，以 $X$ 为基，$\rho(g)$ 是置换矩阵 |
| 正则表示 | 作用在自己身上 | 取 $X=G$、$g$ 左乘每个元素，维数是 $|G|$ |
| 不可约 | 最小积木 | 没有非平凡不变子空间的表示，拆无可拆 |

**一个关键事实**：特征标只取迹。同一元素换一组基，矩阵会变，但迹不变——所以 $\chi_\rho$ 是表示的"不变量指纹"。

## 4. 分步例题

**例 1（$C_3$ 的一维表示）.** 取 $C_3=\lbrace e,r,r^2\rbrace$，$r^3=e$。令 $\omega=e^{2\pi\mathrm{i}/3}$，则 $\omega^3=1$、$1+\omega+\omega^2=0$。

1. 三个一维表示：$\rho_k(r)=\omega^k\ (k=0,1,2)$，需要 $\rho_k(r)^3=\omega^{3k}=1$ ✓；
2. 特征标分别是 $\chi_0=(1,1,1)$、$\chi_1=(1,\omega,\omega^2)$、$\chi_2=(1,\omega^2,\omega)$；
3. 验收：$\sum_{g}|\chi_k(g)|^2=1+1+1=3=|C_3|$——三条都过关，三个都是不可约的。

**例 2（$S_3$ 的特征标表）.** $S_3$ 有三个共轭类：恒等元（1 个）、对换（3 个）、三轮换（2 个）。用置换表示一步步切出积木：

1. 三张牌上的**置换表示**是 $3\times3$ 的，它的特征标是"被固定的点数"：$\chi_{\text{perm}}=(3,1,0)$；
2. 减去那个到处都有的**平凡表示**（每个元素都送 $1$）：$\chi_{\text{perm}}-\chi_{\text{triv}}=(3,1,0)-(1,1,1)=(2,0,-1)$，这是**标准表示**，二维；
3. 再加一个**符号表示**（偶置换送 $1$、奇置换送 $-1$）：$\chi_{\text{sign}}=(1,-1,1)$；
4. 三个积木全部到齐：$\chi_1=(1,1,1)$、$\chi_2=(1,-1,1)$、$\chi_3=(2,0,-1)$。

**例 3（验收）.** 用两类守恒律给上表盖章：

1. **维数平方和**：$1^2+1^2+2^2=6=|S_3|$ ✓；
2. **正交范数**（按类大小加权）：$1\cdot2^2+3\cdot0^2+2\cdot(-1)^2=4+0+2=6$ ✓，且三个特征标两两正交；
3. 结论：$\lbrace\chi_1,\chi_2,\chi_3\rbrace$ 是一张完整、无冗余的"积木清单"。

### 实验 2（python）：验证 $r^3$ 回到恒等元

```python title="用矩阵演完 C₃ 的一整个循环"
import math

def rot(deg):                         # 造一张逆时针转 deg 度的 2×2 旋转矩阵
    t = deg * math.pi / 180           # 角度换成弧度；math.pi 是圆周率
    return [[math.cos(t), -math.sin(t)],
            [math.sin(t),  math.cos(t)]]

def mul(A, B):                        # 2×2 矩阵相乘：行乘列再相加
    return [[A[0][0]*B[0][0] + A[0][1]*B[1][0], A[0][0]*B[0][1] + A[0][1]*B[1][1]],
            [A[1][0]*B[0][0] + A[1][1]*B[1][0], A[1][0]*B[0][1] + A[1][1]*B[1][1]]]

def trace(A):                         # 特征标：矩阵的迹 = 对角线元素之和
    return A[0][0] + A[1][1]

I = [[1.0, 0.0], [0.0, 1.0]]          # 单位矩阵，代表恒等元 e
R = rot(120)                          # 元素 r
R2 = mul(R, R)                        # 元素 r²
R3 = mul(R2, R)                       # 元素 r³，应当回到 e
print("r³ 回到 e:", round(R3[0][0], 3) == 1.0 and round(R3[1][0], 3) == 0.0)
print("chi =", int(round(trace(I))), int(round(trace(R))), int(round(trace(R2))))
```

输出 `r³ 回到 e: True` 与 `chi = 2 -1 -1`。第二行是二维表示的特征标：$\chi(e)=2$，$\chi(r)=\chi(r^2)=-1$（两次 $120^\circ$ 的迹都是 $2\cos120^\circ=-1$）。**一个符号 "$-1$"，就把整组旋转的指纹概括完了。**

### 实验 3（python）：三条特征标的集体体检

```python title="S₃ 的积木清单：正交范数逐个算"
sizes = [1, 3, 2]                     # 三个共轭类的大小：e×1、对换×3、三轮换×2
chars = {                             # 字典（首现）："名字 → 特征标三元组"
    "平凡": [1, 1, 1],
    "符号": [1, -1, 1],
    "标准": [2, 0, -1],
}
for name in chars:                    # 逐个表示体检
    norm = 0
    for i in range(3):
        norm = norm + sizes[i] * chars[name][i] ** 2   # 每类：类大小 × 特征标平方
    print(name, norm, norm == 6)      # 范数等于群阶 6 才不可约
```

输出三行 `平凡 6 True`、`符号 6 True`、`标准 6 True`：三条特征标的加权平方和都等于 $|S_3|=6$，谁也没混进可约的杂质。试着把"标准"那一行改成 $(3,0,-1)$（忘记减掉平凡表示），它会立刻打印 `False`——**正交关系是最便宜的可约性探测器。**

## 6. 练习

```exercise
# @title: 练习：用两条验收线检查 S₃ 的表示
# @check: dims_sq=6
# @check: norm=6
# @check: True
# @hint: 维数平方和用三个不可约表示的维数 [1, 1, 2]；正交范数里每个共轭类的大小是 [1, 3, 2]——对换有 3 个、三轮换有 2 个。
dims = [1, 1, 2]                      # 三个不可约表示的维数 = 它们在恒等元上的特征标
dims_sq = 0
for d in dims:
    dims_sq = dims_sq + d * d         # 维数平方和
print("dims_sq=" + str(dims_sq))

chi = [2, 0, -1]                      # 标准二维表示的特征标
sizes = [1, 1, 1]                     # ← 有错：这里应是每个共轭类的大小
norm = 0
for i in range(3):
    norm = norm + sizes[i] * chi[i] * chi[i]   # 按类大小加权的平方和
print("norm=" + str(norm))
print(norm == 6)                      # 等于群阶才不可约
```

<details>
<summary>点开查看逐步解答</summary>

只需改一个列表：

```python
sizes = [1, 3, 2]
```

两个验收线各管一件事：

- **维数平方和** $1^2+1^2+2^2=6=|S_3|$。这条式子保证你找齐了所有不可约表示，不多不少；
- **正交范数** $1\cdot2^2+3\cdot0^2+2\cdot(-1)^2=4+0+2=6$。这条式子对每个不可约表示都成立（等于群阶）。

初版把类大小全填成 1，相当于假设三个类各有 1 个元素；范数算成 $4+0+1=5\ne6$，于是最后一行打印 `False`——把不可约的标准表示误判成了可约。

**为什么要按类大小加权？** 因为特征标在同一个共轭类上取恒定值（同类的元素只是换了基，迹不变），求和时整类只算一次、但要乘上类里有几个元素。这把"对 6 个元素求和"压缩成了"对 3 个类加权求和"。

</details>

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为表示就是把群元素随便换成矩阵。必须**保住乘法**：$\rho(gh)=\rho(g)\rho(h)$。顺手编一套矩阵，一旦乘法表对不上，它连表示的入场券都拿不到。

**误区二**：你以为特征标依赖矩阵的具体写法。换一组基，$\rho(g)$ 会变成 $P^{-1}\rho(g)P$，可迹始终不变——所以 $\chi_\rho(g)$ 是表示的不变量，而不是某个矩阵的私事。

**误区三**：你以为维数越大表示越"完整"。恰恰相反：不可约表示按"维数平方和等于群阶"组织，维数越小的积木越基础；大表示只是积木的叠加，$\chi$ 里一眼就能看出重复次数。

:::

## 9. 选读：为什么维数平方和等于群阶

<details>
<summary>选读 · 用正则表示把两条验收线缝起来</summary>

两条验收线（$\sum \chi_i(e)^2=|G|$ 与正交关系）背后是同一个对象：**正则表示**。

让群 $G$ 左乘自己：取 $X=G$ 为基，$g$ 把基向量 $e_h$ 送到 $e_{gh}$。这个 $|G|$ 维的置换表示叫正则表示，记 $\rho_{\text{reg}}$。

1. **它的特征标极简**。$h\mapsto gh$ 只有 $g=e$ 时才把某个基向量留下来，其余全被搬走；所以 $\chi_{\text{reg}}(e)=|G|$，而 $g\ne e$ 时 $\chi_{\text{reg}}(g)=0$。
2. **它按积木分解**。一般理论（Maschke 定理）保证任何表示都能拆成不可约表示的直和。设第 $i$ 块积木出现了 $m_i$ 次，则 $\chi_{\text{reg}}=\sum_i m_i\chi_i$。
3. **每个积木出现 $d_i$ 次**。把上式和 $\chi_i$ 做内积，利用正交关系 $\langle\chi_i,\chi_j\rangle=\delta_{ij}$，算得 $m_i=\langle\chi_i,\chi_{\text{reg}}\rangle=\dfrac{1}{|G|}\sum_g \chi_i(g)^*\,\chi_{\text{reg}}(g)=\chi_i(e)=d_i$。
4. **两边在恒等元处对账**：左边 $\chi_{\text{reg}}(e)=|G|$，右边 $\sum_i m_i\chi_i(e)=\sum_i d_i^2$。于是

$$\sum_i d_i^2 = |G| .$$

一句话：**每个不可约表示在正则表示里恰好出现"它的维数"次**，把整块 $|G|$ 维的拼图填满，维数平方和自然等于群阶。这也解释了为什么不可约表示的日记里，$d_i$ 必须整除 $|G|$——那是一块块积木嵌进大盒子的必然结果。

</details>
