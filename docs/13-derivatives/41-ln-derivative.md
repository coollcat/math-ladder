# 对数的导数：ln x 的坡度是 1/x

## 1. 从一个场景开始

上一课三位明星——$\sin$、$\cos$、$e^x$——都领到了导数出生证，可对数家族一直没人领证。这不是漏发，是刻意留的悬念：第 14 章积分要把它当"已会的基本款"随手使用，本课先正式补上。

答案有两层意外。第一层：$e^x$ 求导是"复制自己"，它的撤销键 $\ln x$ 求导却变成一个分数——最亲密的两口子，脾气完全相反。第二层：$\dfrac{1}{x}$ 意味着**坡度由横坐标单独决定**——在 $x=1$ 处坡度是 1，在 $x=100$ 处坡度只剩 0.01。对数曲线"越爬越斯文"，这回有了精确刻度。

## 2. 直觉解释

先凭长相猜答案。$\ln x$ 的本职是把乘法变加法的翻译官（[第 3 章](../03-exponents/40-log.md)），图像上它是一条越爬越慢的爬坡路：永远在涨，却涨得越来越斯文。"永远在涨、涨得越来越慢"翻译成导数语言：**坡度恒正，但一路递减**。

什么函数长这样？$\dfrac{1}{x}$！在 $x$ 靠近 0 的地方它高高耸起（坡度猛），在 $x$ 很大的地方贴着地面（坡度近乎为零）。猜对没有？本课用两台实验当场对账：viz 双线同框看形状，浮窗数值求导逐点验数。

## 3. 正式定义

$$\frac{d}{dx}\ln x = \frac{1}{x} \qquad (x > 0)$$

| 函数 | 导数 | 一句话画像 |
| --- | --- | --- |
| $\ln x$ | $\dfrac{1}{x}$ | 坡度 = 1 ÷ 横坐标：右边越走越平 |
| $e^x$ | $e^x$ | 斜率 = 高度，自我复制（上一课） |

前提声明：定义域 $x > 0$——负数没有对数（第 3 章的误区讲过）。至于 $x < 0$ 的地盘怎么也纳入版图（$\ln|x|$ 的导数同样是 $1/x$），第 7 节选读交代，第 14 章积分要用到它。

## 4. 分步例题

**例 1**：求 $y = \ln x$ 在 $x = 1$ 处的切线。

1. 坡度公式：$k = \dfrac{1}{x} = \dfrac{1}{1} = 1$；
2. 切点：$(1, \ln 1) = (1, 0)$；
3. 切线：$y = x - 1$——斜率 1、恰好穿过原点右下方一格的 45° 直线。

**例 2**：求 $y = x^2 \ln x$ 的导数（乘积法则登场）。

1. 拆账：$u = x^2$，$v = \ln x$；
2. 各自求导：$u' = 2x$（幂规则），$v' = \dfrac{1}{x}$（本课新出生证）；
3. 乘积法则合账：$y' = 2x\ln x + x^2 \cdot \dfrac{1}{x} = 2x\ln x + x$。

**例 3**：求 $y = \ln(x^2 + 1)$ 的导数（链式法则登场）。

1. 认洋葱：外层 $\ln(\,\cdot\,)$，内层 $x^2 + 1$；
2. 外层导：$\dfrac{1}{x^2+1}$；内层导：$2x$；
3. 相乘：$y' = \dfrac{2x}{x^2 + 1}$。

## 5. 动手实验

### 实验 1（viz）：f 蓝 f' 橙——坡度恰好是 1/x 的高度

```viz
{
  "type": "plot",
  "title": "蓝 ln x 本尊，橙 1/x 是它的坡度",
  "expr": "log(x)",
  "expr2": "1/x",
  "label": "ln(x)",
  "label2": "1/x",
  "xmin": 0.2,
  "xmax": 8
}
```

怎么玩：蓝线是 $\ln x$ 本尊，橙线是它的坡度。视线沿蓝线从左往右扫：起点处陡得近乎垂直（橙线在那里高耸），到 $x = 8$ 已平得像地板（橙线贴地）。在 $x = 1$ 处，橙线的高度恰好是 1——而蓝线在这一点的**坡度**恰好也是 1（此刻蓝线正好穿过 x 轴，$\ln 1 = 0$）。注意本组件写的 log 就是自然对数 ln（以 e 为底）。

### 实验 2（python 滑块）：中心差分对拍 1/x

```python title="数值求导 vs 官方公式"
import math

# sliders: x=2.0 [0.3:6.0:0.1]

h = 0.0001    # 一小步：越小越贴近"一瞬间"（20 课导数定义里的 Δx）
slope = (math.log(x + h) - math.log(x - h)) / (2 * h)   # 中心差分：左右两点坡度的折中
exact = 1 / x                                           # 本课公式：理论坡度
print(f"x = {round(x, 2)}: 数值坡度 {round(slope, 5)} | 公式 1/x {round(exact, 5)}")
```

怎么玩：x 拖到 1，两边都是 1；拖到 0.5，坡度涨到 2；拖到 6，坡度只剩约 0.167。数值实验五位数对五位数，公式稳稳接住——$\ln x$ 的坡度就是 $\dfrac{1}{x}$。

### 实验 3（python）：ln 的切线长廊

```python title="在四个地点给 ln x 量坡度"
import math
import matplotlib.pyplot as plt   # 画图工具箱（00 章 20 课登场过）

xs = []
ys = []
x = 0.1
while x <= 8:                     # while：从 0.1 一路画到 8（00 章约定五的手艺）
    xs.append(x)                  # append：把横坐标记进清单
    ys.append(math.log(x))        # math.log：自然对数 ln（第 3 章登场过，默认底是 e）
    x = x + 0.05
plt.plot(xs, ys, color="steelblue", linewidth=2)

for x0 in [0.5, 1, 2, 4]:         # 在四个地点各画一小段切线
    k = 1 / x0                    # 切线斜率：本课的主角 1/x
    y0 = math.log(x0)
    plt.plot([x0 - 0.8, x0 + 0.8], [y0 - 0.8 * k, y0 + 0.8 * k], linestyle="--", color="tomato")
plt.grid(True)
plt.title("y = ln x 与它在不同地点的切线")
plt.xlabel("x")
plt.ylabel("y")
```

怎么玩：四段橙色虚线是 $\ln x$ 在 $x = 0.5, 1, 2, 4$ 处的切线。从左往右看：切线一段比一段**平**——斜率 2、1、0.5、0.25，正是 $\dfrac{1}{x}$ 在四个地点的读数。曲线永远在涨，但每一步都比上一步温柔。

### 快问快答

```quiz
ln x 在 x = 100 处的坡度是多少？
- 100
- 0.01 [*]
- e
? 坡度 = 1/x：x = 100 时恰好是 1/100。对数爬得越高越平，这里是精确刻度。
```

::::warning[常见误区]

**误区一**："你以为 ln 的导数也该复制自己。" 反函数的脾气通常和原函数相反：$e^x$ 越大越陡，$\ln x$ 越大越平。复制奇迹是 $e^x$ 独一份的，$\ln x$ 的答案是朴素的 $\dfrac{1}{x}$。

**误区二**："你以为底数无所谓。" 换底要补一个常数因子：$\log_2 x = \dfrac{\ln x}{\ln 2}$，所以 $(\log_2 x)' = \dfrac{1}{x\ln 2} \approx \dfrac{1.44}{x}$。底数不同，坡度差一个倍数——这就是数学家偏爱 e 的原因：只有 e 的底让公式零瑕疵。

**误区三**："你以为 x < 0 时这套彻底没戏。" 单独的 $\ln x$ 确实不收负数，但 $\ln|x|$ 两边通吃，导数同样是 $\dfrac{1}{x}$——第 14 章积 $\dfrac{1}{x}$ 时会正式请它出山。

::::

**练习 1**：$y = x \cdot \ln x$ 在 $x = e$ 处的导数是多少？下面的代码能跑但只算了一半，补全后运行并通过检查：

```exercise
y = 1 / x              # ← 只算了 (ln x)' 这一半，乘积法则还有另一半
print(round(y, 4))
```

**练习 2**：手算 $\log_2 x$ 在 $x = 8$ 处的导数。

<details>
<summary>点开查看逐步解答</summary>

换底：$\log_2 x = \dfrac{\ln x}{\ln 2}$，常数提出后导数为 $\dfrac{1}{x \ln 2}$。代入 $x = 8$：$\dfrac{1}{8 \times 0.6931} \approx 0.180$。底数 2 的对数在 8 处的坡度，比 ln 在 8 处（0.125）更陡——因为 $\log_2$ 的尺子刻度更密。
</details>

**练习 3**：用本课公式解释：为什么说 $\ln x$ 是"最斯文的攀爬者"？

<details>
<summary>点开查看逐步解答</summary>

它的坡度 $\dfrac{1}{x}$ 永远是正的（所以永不下跌），但随 $x$ 增大一路衰减（所以越爬越慢）：爬到 $x = 1000$ 时每前进一步的升高不足千分之一。对比幂函数 $x^2$——坡度 $2x$ 越爬越猛。一个永远减速、一个永远加速，导数一眼看穿两者的性格。
</details>

## 7. 选读：反函数求导一击

<details>
<summary>选读 · 从 e^x 的出生证倒推 ln 的</summary>

$\ln x$ 是 $e^x$ 的反函数：$y = \ln x$ 与 $e^y = x$ 是同一句话的两种写法。对等式 $e^y = x$ **两边同时对 x 求导**——左边是复合函数，要过链式法则：

$$e^y \cdot y' = 1 \quad\Longrightarrow\quad y' = \frac{1}{e^y} = \frac{1}{x}$$

最后一步把 $e^y$ 换回 $x$。反函数的导数就这么到手：**原函数导数的倒数**。顺便交代 $x < 0$ 的地盘：对 $x < 0$，$y = \ln(-x)$，链式法则给 $y' = \dfrac{1}{-x} \cdot (-1) = \dfrac{1}{x}$——两边共用同一条公式，合起来正是 $(\ln|x|)' = \dfrac{1}{x}$。第 14 章积分 $\dfrac{1}{x}$ 时，这份加宽的版图正好接住负数地盘。

</details>
