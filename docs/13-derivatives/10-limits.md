# 无穷逼近与极限：想多近有多近

## 1. 从一个场景开始

公元前 5 世纪，哲学家芝诺抛出一个困扰人类两千年的悖论：飞毛腿阿基里斯追乌龟，追上之前必须先到达乌龟刚才的位置；可他赶到时，乌龟又往前爬了一小段；再去追，乌龟又挪了一点……**要完成无穷多次追赶，所以永远追不上？**

可现实里阿基里斯一抬脚就超了。矛盾出在哪？出在"无限步一定走不完"这个想当然上。拆穿它的工具，就是本课的主角——**极限**。

## 2. 直觉解释

先看一个最简单的"无限步"：从 0 走到 1，第一步走一半（到 0.5），第二步再走剩下的一半（到 0.75）……每一步都只走剩余路程的一半。

| 步数 | 位置 |
| --- | --- |
| 1 | 0.5 |
| 2 | 0.75 |
| 3 | 0.875 |
| 26 | 约 0.999999985… |

步子永远走不完，位置却清清楚楚地奔向一个目的地：**1**。我们说"位置的极限是 1"——注意，不是"走到 1"，而是"想离 1 多近就能有多近"。

极限研究的就是这种**逼近的目的地**：过程可以永不停止，目的地却毫不含糊。

## 3. 正式定义

当 $x$ 从两侧任意接近 $a$ 时，若 $f(x)$ 想多近就能有多近地贴近某个值 $L$，就称"$x$ 趋于 $a$ 时 $f$ 的极限为 $L$"：

$$\lim_{x \to a} f(x) = L$$

| 符号 | 读法 | 含义 |
| --- | --- | --- |
| $\lim$ | 极限 | 逼近过程的目的地 |
| $x \to a$ | x 趋于 a | $x$ 无限接近 $a$，但**始终不等于** $a$ |
| $L$ | 极限值 | 函数值贴向的那个数 |

两个要点：① 过程中 $x \neq a$——极限只看 $a$ 的**附近**，不看 $a$ 本身；② $f$ 在 $a$ 处有没有定义都无所谓，丝毫不妨碍极限存在。

## 4. 分步例题

求 $\lim\limits_{x \to 2} \dfrac{x^2-4}{x-2}$。

1. **直接代入试试**：分子 $4-4=0$，分母 $2-2=0$，得到 $\frac{0}{0}$——卡死。函数在 $x=2$ 处根本没定义；
2. **换个思路：化简附近**。用第 4 章的因式分解：$x^2-4=(x+2)(x-2)$；
3. **约分**（只要 $x \neq 2$ 就合法）：原式 $= x+2$——原来它是一条直线，只在 $x=2$ 缺了一个点；
4. **看目的地**：$x=1.99$ 时值是 $3.99$，$x=2.01$ 时是 $4.01$——越靠越近，目的地显然是 $4$。

$$\lim_{x \to 2} \frac{x^2-4}{x-2} = 4$$

$\frac{0}{0}$ 不是"答案不存在"的判决书，只是"此路不通"的路标——绕到附近去看，局势一目了然。

## 5. 动手实验

### 实验 1（viz）：一条缺了针孔的直线

```viz
{
  "type": "plot",
  "title": "(x^2 - 4)/(x - 2)：其实就是 y = x + 2",
  "expr": "(x^2-4)/(x-2)",
  "xmin": -1,
  "xmax": 5
}
```

怎么玩：整条线就是 $y=x+2$，唯独 $x=2$ 那个点被抠掉了（画布上只是个针孔）。缺一个点，丝毫不影响这条线附近的走势——这正是极限的宽容：**我不要求你到场，我只看你邻居的表现。**

### 实验 2（viz）：左右探针同时夹逼

```viz
{
  "type": "limitprobe",
  "title": "从左右两侧逼近 x=2",
  "expr": "(x^2-4)/(x-2)",
  "a": 2,
  "xmin": -1,
  "xmax": 5
}
```

连按「h÷2」，红绿两个探针会从缺点的两侧贴上去。左侧读数 `3.9, 3.99, 3.999…`，右侧读数 `4.1, 4.01, 4.001…`——钳口越收越拢，共同目的地就是极限。紫色竖线永远可以穿过 $x=2$，但蓝色曲线在那个点留了一个小缺口。

### 实验 3（python）：左右夹击，逼出目的地

```python title="从两侧逼近 x=2"
def g(x):
    return (x * x - 4) / (x - 2)

for h in [1, 0.1, 0.01, 0.001]:   # h 是离 2 的距离，一步步缩小
    left = g(2 - h)               # 左侧试探点：比 2 小一点点
    right = g(2 + h)              # 右侧试探点：比 2 大一点点
    print(f"h={h}: 左侧 {round(left, 6)} | 右侧 {round(right, 6)}")
```

怎么玩：两侧的值像钳子一样往中间夹——`3.9/4.1` → `3.99/4.01` → `3.999/4.001`，钳口越收越拢，共同的目的地正是 **4**。顺便试一句 `print(g(2))`：程序会当场报错（除以零），可极限照样存在——那一个点的缺席无关紧要。

### 实验 4（viz）：拖动旋钮，亲手"补"出极限值

```viz
{
  "type": "plot",
  "title": "拖动 c：让 x+c 无缝盖住原函数",
  "expr": "(x^2-4)/(x-2)",
  "expr2": "x + c",
  "label": "原式",
  "label2": "x+c",
  "xmin": -1,
  "xmax": 5,
  "sliders": [
    { "name": "c", "min": 0, "max": 6, "step": 0.5, "value": 0 }
  ]
}
```

怎么玩：橙色虚线是化简候选 $y=x+c$，拖动滑块让它上下平移。$c=0$ 时两线斜着岔开；一路微调，**当且仅当 $c=2$ 时，橙虚线与蓝实线严丝合缝地重合**——化简后的直线恰好无缝顶替了原函数。此时 $x=2$ 处两条线的公共高度 $2+2=4$，正是例题算出的极限：求极限，就是在找"谁能完美补位"的那条曲线。

### 快问快答

```quiz
"x→2 时 g(x) 的极限是 4"，这句话的意思是？
- 把 x=2 代入 g 算出来的值
- x 无限接近 2 但不取 2 时，g(x) 想多近就能有多近地贴向 4 [*]
- g 必须在 x=2 处有定义且等于 4
? 极限描述的是逼近过程的目的地。本课的 g 在 x=2 处压根没定义，却毫不妨碍极限等于 4。
```

:::warning[常见误区]

**误区一**："你以为极限就是'达到'。" 其实 $x \to 2$ 只承诺"想多近有多近"，从不要求真的踩到那个点。极限是目的地的坐标，不是抵达的记录。

**误区二**："函数在这点没定义，极限就不存在。" 本课主角在 $x=2$ 处连定义都没有，极限照样是 4。极限考察的是**周边局势**，不是孤零零的一个点。

**误区三**："算出 0/0 就等于极限不存在。" 0/0 只是"直接代入失败"的信号灯，提示你换条路（化简、数值试探）再看附近——本课两例都是 0/0 型，极限都好好存在着。

:::

## 6. 练习

**练习 1**：同样的堵车路口换了个函数：$g(x)=\dfrac{x^2-9}{x-3}$。求它在 $x=3$ 处的极限。下面的代码能跑但答非所问，改到通过：

```exercise
# @title: 练习：x=3 处的极限
# @check: 6.0
# @hint: 别把 3 直接代进去——分母会归零。取一个离 3 很近的试探点（比如 3.001 或 2.999），看看打印值停在哪
def g(x):
    return (x * x - 9) / (x - 3)

print(round(g(4), 1))
```

跑通后不妨两侧各试几个点：不管从左边还是右边靠近 3，打印值都会停在同一个地方——这就是极限的"双向一致"。

**练习 2**："$g$ 在 $x=3$ 处根本没有定义"，那么"极限是 6"这句话还有意义吗？

<details>
<summary>点开查看逐步解答</summary>

完全有意义。极限只关心 $x=3$ **附近**的走势，而附近的值齐刷刷奔向 6。事实上我们可以人为补一句定义：令 $g(3)=6$，函数立刻在该点严丝合缝地接上，整条曲线变成干净的直线 $y=x+3$。

这种"缺一个点、极限来补位"的情形叫**可去间断点**——洞是可以补的。后面讲积分时你会看到：哪怕函数有一堆这样的洞，我们照样能对它做微积分。
</details>

<details>
<summary>选读 · 芝诺悖论到底错哪了</summary>

设开赛时阿基里斯落后乌龟 4 米，他的速度是乌龟的 2 倍。追到乌龟上一位置后，差距缩成 2 米；再追，差 1 米……差距序列 $4, 2, 1, 0.5, \dots$

第 8 章的等比数列求和公式告诉我们：这些差距**加起来**只有

$$4 + 2 + 1 + 0.5 + \cdots = \frac{4}{1-\frac{1}{2}} = 8 \text{ 米}$$

无穷多个正数相加，总和却是有限的 8 米；所需时间同样收敛到一个有限的值。芝诺的错误在于默认"无穷多步必耗无限时间"——他不知道**步子可以越迈越小，快到能在有限时间里踩完无穷步**。极限语言一出场，两千年的困惑一页纸化解。
</details>
