# 切线方程：从切点到公切线

## 1. 从一个场景开始

工厂要在一块金属板上铣出一条曲线边缘 $y = x^3 - 3x$，铣刀是直的，只能沿直线走刀。师傅给了你两个指令，差别只有一个字：

- 指令甲：**在 $x = 2$ 处**，沿切线方向走一刀；
- 指令乙：**经过点 $P(2, 2)$**，沿切线方向走一刀。

两条指令听起来像同一件事，答案却不是同一条直线——乙竟然能走出**两条**不同的刀路。差在哪儿？甲的切点已经告诉你了，乙的切点还得你自己去找。

这一课把"求切线"这件小事的三种问法一次讲透：切点已知、切点未知、两条曲线共用一条切线。

## 2. 直觉解释

切线是**割线的极限位置**：在曲线上取一点 $Q$，让 $Q$ 沿着曲线滑向 $P$，割线 $PQ$ 转到的那个极限位置就是切线。从这个画面能读出三件事：

- **斜率从哪儿来**：从切点来。切线的斜率是曲线在**接触点**处的坡度 $f'(x_0)$，与"这条直线还要经过谁"毫无关系；
- **切点是谁**：题目说"在点 $A$ 处"，切点就是 $A$；题目说"过点 $P$"，$P$ 只负责"你必须经过我"，切点另有其人；
- **能有几条**：过定点引切线，切点可以沿着曲线滑动，每滑到一个"高度和坡度都对得上"的位置就得到一条。所以切点未知时，答案可能不止一条。

一句话：**切点决定斜率，定点只提供方程。** 分不清这两件事，是这类题最大的失分点。

## 3. 正式定义

**切线方程（切点已知）**：曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处的切线为

$$y - f(x_0) = f'(x_0)\,(x - x_0)$$

| 符号 | 含义 | 易错提醒 |
| --- | --- | --- |
| $x_0$ | 切点的横坐标 | 必须是**接触点**，不是"直线经过的那个点" |
| $f'(x_0)$ | 切线斜率 $k$ | 由切点算出，与定点无关 |
| $f(x_0)$ | 切点的纵坐标 | 别忘了减去 $k x_0$ 才是截距 $b$ |

**三种问法对照**：

| 情形 | 已知 | 关键方程 | 未知量 |
| --- | --- | --- | --- |
| 切点已知 | 切点 $x_0$ | $y - f(x_0) = f'(x_0)(x - x_0)$ | 无，直接代 |
| 切点未知 | 切线过定点 $P(a,b)$ | $b = f'(x_0)(a - x_0) + f(x_0)$ | $x_0$：一个方程解一个未知数 |
| 公切线 | 两条曲线 $y=f(x)$、$y=g(x)$ | 斜率相等 + 截距相等，两个方程 | 两个切点 $x_1, x_2$ |

**判别式相切判据**（公切线的利器）：直线 $y = kx + b$ 与抛物线 $y = Ax^2 + Bx + C$ 相切，当且仅当把两者联立得到的二次方程**判别式为零**。这样不用先求切点，直接对 $(k, b)$ 列方程。

## 4. 分步例题

### 例 1（切点已知）：求 $f(x) = x^3 - 3x$ 在 $x = 2$ 处的切线

1. **求切点纵坐标**：$f(2) = 8 - 6 = 2$，切点是 $(2, 2)$；
2. **求斜率**：$f'(x) = 3x^2 - 3$，代入得 $f'(2) = 12 - 3 = 9$；
3. **代点斜式**：$y - 2 = 9(x - 2)$；
4. **整理**：$y = 9x - 16$。

三步就完事——切点已知是最省事的一种。

### 例 2（切点未知）：过点 $P(2, 2)$ 作 $y = x^3 - 3x$ 的切线

注意，$P(2,2)$ 恰好在曲线上（上一步刚算出 $f(2) = 2$），但这**不等于**它就是切点。

1. **设切点**为 $(t,\, t^3 - 3t)$，这里的 $t$ 是未知数；
2. **写切线**：斜率 $k = f'(t) = 3t^2 - 3$，切线为 $y = (3t^2 - 3)(x - t) + t^3 - 3t$；
3. **代入定点** $P(2,2)$（$x = 2$ 时 $y$ 必须等于 2）：

$$2 = (3t^2 - 3)(2 - t) + t^3 - 3t = -2t^3 + 6t^2 - 6$$

4. **解这个关于 $t$ 的方程**：$t^3 - 3t^2 + 4 = 0$，因式分解得 $(t - 2)^2(t + 1) = 0$，所以 $t = 2$ 或 $t = -1$；
5. **分别写切线**：
   - $t = 2$：切点就是 $P$ 自己，斜率 $9$，切线 $y = 9x - 16$（和例 1 同一条）；
   - $t = -1$：切点 $(-1, 2)$，斜率 $f'(-1) = 0$，切线 $y = 2$（一条水平线）。

**两条**。这就是为什么"过点 $P$ 的切线"和"在点 $P$ 处的切线"必须分开说。

### 例 3（计数）：过点 $P(2, b)$ 能作几条切线？

把例 2 第 3 步里的 $2$ 换成字母 $b$，得到同一个模板：

$$b = g(t) := -2t^3 + 6t^2 - 6$$

切线的条数就是方程 $g(t) = b$ 的**实根个数**。给它做一次单调性体检（第 50 课的预演）：

- $g'(t) = -6t^2 + 12t = -6t(t - 2)$，两个驻点是 $t = 0$ 与 $t = 2$；
- $g(0) = -6$ 是极小值，$g(2) = 2$ 是极大值；

于是水平线 $y = b$ 与 $g$ 的图像交几个点，就有几条切线：

| $b$ 的位置 | 交点个数 | 切线数 |
| --- | --- | --- |
| $b > 2$ | 1 | 1 条 |
| $b = 2$ | 2（一个切于峰顶） | 2 条 |
| $-6 < b < 2$ | 3 | 3 条 |
| $b = -6$ | 2（一个切于谷底） | 2 条 |
| $b < -6$ | 1 | 1 条 |

$b = 2$ 与 $b = -6$ 这两个"临界高度"正是极值本身——**计数问题的分界线，永远是极值**。

### 例 4（公切线）：求 $y = x^2$ 与 $y = -x^2 + 4x - 10$ 的公切线

两条抛物线一上一下（$y = x^2 \ge 0$，后者 $= -(x-2)^2 - 6 \le -6$），中间要架"斜桥"。

1. **设直线** $y = kx + b$，先要求它与 $y = x^2$ 相切：联立 $x^2 = kx + b$，即 $x^2 - kx - b = 0$，判别式 $k^2 + 4b = 0$，得

$$b = -\frac{k^2}{4}$$

2. **再要求它与第二条相切**：$-x^2 + 4x - 10 = kx + b$，整理成 $x^2 + (k - 4)x + (b + 10) = 0$，判别式为零：$(k - 4)^2 - 4(b + 10) = 0$；
3. **代入 $b$**：$(k - 4)^2 - 4\left(-\dfrac{k^2}{4} + 10\right) = k^2 - 8k + 16 + k^2 - 40 = 2k^2 - 8k - 24 = 0$，即 $k^2 - 4k - 12 = 0$；
4. **解出 $k$**：$(k - 6)(k + 2) = 0$，$k = 6$ 或 $k = -2$；对应的 $b = -9$ 或 $b = -1$。

两条公切线：$y = 6x - 9$（切 $y = x^2$ 于 $x = 3$，切另一条于 $x = -1$）与 $y = -2x - 1$（切 $y = x^2$ 于 $x = -1$，切另一条于 $x = 3$）。

### 实验 3（python）：切点在哪，切线跟到哪

```python title="拖动 t：切点一变，斜率截距全自动跟上"
# sliders: t=-1.0 [-2.5:2.5:0.1]

def f(x):
    return x ** 3 - 3 * x          # 本课主角曲线

def df(x):
    return 3 * x ** 2 - 3          # 坡度公式（30 课五件套的产物）

k = df(t)                          # 切点 t 处的坡度 = 切线斜率
b = f(t) - k * t                   # 切线 y = kx + b 必须经过切点 (t, f(t))
print(f"切点 t = {round(t, 2)}，切线 y = {round(k, 2)}·x + ({round(b, 2)})")
print("经过 P(2, 2)?", abs(k * 2 + b - 2) < 0.000001)
```

怎么玩：把 $t$ 停在 $-1$，输出 `切线 y = 0.0·x + (2.0)` 且判定为 `True`；拖到 $2$，输出 `y = 9.0·x + (-16.0)` 也是 `True`。**整个滑块区间里只有这两个 $t$ 值能让判定变成 `True`**——这就是"两条切线"的机器版答卷。

### 实验 4（python）：切线的条数，数给你看

```python title="把定点高度 b 代进去，机器直接报条数"
def g(t):
    # 切点参数为 t 的那条切线，在 x = 2 处的高度
    return -2 * t ** 3 + 6 * t ** 2 - 6

def count(b):
    cuts = 0
    prev = g(-4 + 0.0025) - b      # 取样点错开半格：免得正好落在根上
    i = 1
    while i <= 2000:
        x = -4 + i * 0.005 + 0.0025
        cur = g(x) - b
        if prev * cur < 0:         # 符号翻转 = 刚刚扫过一个根
            cuts = cuts + 1
        prev = cur
        i = i + 1
    return cuts

for b in [3, 0, -7]:
    print(f"P(2, {b}): {count(b)} 条切线")
```

输出依次是 `1 条`、`3 条`、`1 条`——与例 3 的表格严丝合缝（$b = 3$ 在极大值 $2$ 之上、$b = 0$ 夹在 $-6$ 与 $2$ 之间、$b = -7$ 在极小值 $-6$ 之下）。把 `b` 换成 `2` 再跑一次，你会看到它只报 `1` 条：峰顶那个**重根**触到横轴却不穿过去，数符号翻转的笨办法会漏掉它——这也提醒我们，临界高度得单独手算。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为'过点 $P$ 的切线'就是'以 $P$ 为切点的切线'。" 例 2 里 $P(2,2)$ 明明在曲线上，过它却能作两条切线——多出来的那条以 $(-1, 2)$ 为切点。判定方法只有一句：**题目说"在……处"才是指定切点，说"过……"就只是个约束条件**。

**误区二**："你以为切线只和曲线碰一下。" 切线是割线的极限位置，不是"只交一点"。$y = x^3 - 3x$ 在 $(-1, 2)$ 处的切线是 $y = 2$，而联立 $x^3 - 3x = 2$ 得 $(x + 1)^2(x - 2) = 0$——它还穿过 $(2, 2)$ 呢。反过来，直线与曲线只有一个交点也不一定相切。

**误区三**："你以为公切线总能找出来。" 例 4 里两条抛物线相距够远（一个 $\ge 0$、一个 $\le -6$），才有两条斜桥。若改成 $y = -x^2 + 4x - 1$，它的顶点抬到 $(2, 3)$，两条曲线直接相交，判别式方程组就无解了——**相切方程组解不出来，答案是"没有"，不是"我算错了"**。

:::

## 7. 练习

**练习 1**：下面的判别式筛子写反了一个符号，导致两条公切线都没被筛出来。修正它：

```exercise
# @title: 练习：公切线的判别式筛子
# @check: 6 -9.0 0.0
# @check: -2 -1.0 0.0
# @hint: y = kx + b 与 y = x² 相切 ⟺ x² - kx - b = 0 判别式 k² + 4b = 0，解出 b = -k²/4，负号别丢；判别式为 0 就是"筛中了"
def b_of(k):
    return k * k / 4          # ← 与 y = x² 相切时的截距 b，符号好像不对

for k in [6, -2]:
    b = b_of(k)
    disc = (k - 4) ** 2 - 4 * (b + 10)   # 与 y = -x² + 4x - 10 联立的判别式
    print(k, round(b, 1), round(disc, 1))
```

三列依次是：斜率 $k$、截距 $b$、判别式。判别式为 $0$ 说明这条直线同时擦到了两条曲线。现在代码会输出 `6 9.0 -72.0` 与 `-2 1.0 -8.0`——判别式都不是零，一条也没筛中。

<details>
<summary>点开查看逐步解答</summary>

$y = kx + b$ 与 $y = x^2$ 相切：联立 $x^2 - kx - b = 0$，判别式 $\Delta = k^2 + 4b = 0$，所以 $b = -\dfrac{k^2}{4}$。改掉那个负号即可：

```python
def b_of(k):
    return -k * k / 4

for k in [6, -2]:
    b = b_of(k)
    disc = (k - 4) ** 2 - 4 * (b + 10)
    print(k, round(b, 1), round(disc, 1))
```

输出 `6 -9.0 0.0` 与 `-2 -1.0 0.0`——$k = 6, b = -9$ 与 $k = -2, b = -1$，正是例 4 的两条公切线。

</details>

**练习 2**（思考）：把例 3 的定点从 $(2, b)$ 换成 $(0, b)$，切线还有几条？为什么这次答案与 $b$ 无关？

<details>
<summary>点开查看逐步解答</summary>

切线 $y = (3t^2 - 3)(x - t) + t^3 - 3t$ 在 $x = 0$ 处的高度是

$$(3t^2 - 3)(-t) + t^3 - 3t = -3t^3 + 3t + t^3 - 3t = -2t^3$$

令它等于 $b$：$t^3 = -\dfrac{b}{2}$。三次方程 $t^3 = c$ 对**任意**实数 $c$ 都恰好有一个实根，所以过 $y$ 轴上无论哪一点，都只能作**一条**切线。对比 $(2, b)$ 有三条的情形会发现：**计数问题的答案取决于定点相对曲线的位置**，换一个点，分界线就全变了。

</details>

## 8. 选读与边界

<details>
<summary>选读：为什么"三次曲线过一点能作三条切线"</summary>

一般地，过定点 $(a, b)$ 作 $n$ 次多项式曲线的切线，代入后得到的是一个关于切点参数 $t$ 的 **$n$ 次方程**，实根个数最多 $n$ 个，所以三次曲线最多三条、二次曲线（抛物线）最多两条。

抛物线的情况可以一眼看穿：设 $y = x^2$，切点参数 $t$，切线 $y = 2tx - t^2$，代入 $(a, b)$ 得 $t^2 - 2at + b = 0$——一个**二次**方程，判别式 $4a^2 - 4b$。于是：

- $b < a^2$（点在抛物线**下方**）：两条切线；
- $b = a^2$（点恰在曲线上）：一条，切点就是它自己；
- $b > a^2$（点在抛物线**上方**）：一条也没有。

"从抛物线外一点引切线"的古老几何题，用导数五秒钟就答完了。

</details>

本课不管三件事：

- **切线与曲线的交点个数**（误区二已说明它不是定义）；
- **竖直切线**。若 $f'(x_0)$ 不存在但趋于无穷（如 $y = \sqrt[3]{x}$ 在原点），切线是竖直的 $x = x_0$，点斜式用不上；
- **多元函数的切平面**。曲面 $z = f(x, y)$ 的"切线"升级成切平面，要用偏导数（第 20 章）。
