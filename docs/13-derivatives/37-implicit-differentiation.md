# 隐函数求导

## 1. 从一个场景开始

在圆 $x^2+y^2=25$ 上取一点 $(3, 4)$，问：这一点的切线斜率是多少？

你可能会说：先把 $y$ 解出来呗——$y=\sqrt{25-x^2}$，求导完事。可要是方程换成 $y^5 + xy + x = 7$ 这样的呢？五次方程**根本解不出 $y$**，铅笔写到纸穿也解不出来。但曲线就明明白白躺在那里，切线也真实存在——斜率不该因为"解不出 $y$"就消失。

这一课就要办成这件此前全站没人办成的事：**$y$ 藏在方程里不肯露面，我们照样把它的变化率审出来**。这套手艺叫隐函数求导，它正是上一课链式法则的第一份实战应用。

## 2. 直觉解释

先把困境说透。到目前为止我们求导的对象都是**显函数**：$y$ 单独站在等号左边，像一份写明配方的菜谱。而 $x^2+y^2=25$ 这类方程里，$x$ 和 $y$ 纠缠在一口锅里——但只要你沿着曲线走，每指定一个 $x$，对应的 $y$ 依然被方程**悄悄锁定**。

打个比方：$y$ 是一位戴着面具的舞伴。你看不见她的脸（解不出 $y$ 的表达式），但她的一举一动仍然跟着音乐（$x$）走。既然 $y$ 本质上是 $x$ 的函数，那么对方程**两边同时关于 $x$ 取变化率**就是完全合法的动作——只是遇到含 $y$ 的项时，要用链式法则替这位面具舞伴补挂一个 $\frac{dy}{dx}$。

拿最小的例子热身：$y^2 = x$（一个开口向右的抛物线）。让面积 $x$ 从 $4$ 挪到 $4.0401$，边长 $y$ 大约从 $2$ 挪到 $2.01$。检验一下比率关系：$2 \times y \times \Delta y = 2\times 2\times 0.01 = 0.04$，和 $\Delta x = 0.0401$ 几乎相等。也就是说 **$\Delta x$ 要靠"$2y$ 倍的 $\Delta y$"来凑**——两边的变化率之间有一条硬邦邦的比例链：

$$\frac{d}{dx}\left(y^2\right) = 2y\cdot\frac{dy}{dx}, \qquad \frac{d}{dx}(x) = 1$$

规律已经露头：**对含 $y$ 的部分求导，先按老规矩求，再乘上 $\frac{dy}{dx}$ 这个未知物**。剩下的活儿就是移项把它解出来。

## 3. 正式定义

若方程 $F(x, y) = 0$ 确定了一条曲线，且沿这条曲线（某一段范围内）每个 $x$ 恰好对应一个 $y$，就说 $y$ 是 $x$ 的**隐函数**——函数关系存在，但没写出显式表达式 $y=f(x)$。

**隐函数求导三步法**：

| 步骤 | 动作 | 关键提醒 |
| --- | --- | --- |
| ① 两边同时对 $x$ 求导 | 把 $y$ 当作 $x$ 的函数 | 含 $y$ 的每一项都要经链式法则挂上 $\frac{dy}{dx}$ |
| ② 整理 | 把带 $\frac{dy}{dx}$ 的项归到一边 | 此时 $\frac{dy}{dx}$ 只是个未知数，像解方程一样搬家 |
| ③ 解出 $\frac{dy}{dx}$ | 移项、约简 | 答案里允许出现 $y$——它的值由方程随时补充 |

莱布尼茨记号在这里格外顺手：$\frac{d}{dx}y^n = n y^{n-1}\cdot\frac{dy}{dx}$——外层幂规则照常执行，内层导数正是那个我们追捕的 $\frac{dy}{dx}$ 本尊。

## 4. 分步例题

**例 1**：对 $y^2 = x$ 求 $\frac{dy}{dx}$。

1. 两边对 $x$ 求导：左边 $2y\cdot\frac{dy}{dx}$（挂上链环），右边 $1$；
2. 解出：$\frac{dy}{dx} = \dfrac{1}{2y}$。

回验：上半支的显式身份是 $y=\sqrt{x}$，其导数恰为 $\dfrac{1}{2\sqrt{x}}$ ——和 $\dfrac{1}{2y}$ 一字不差。面具摘下来，两张脸相同。

**例 2**（主菜）：求圆 $x^2+y^2=25$ 在点 $(3, 4)$ 处的切线斜率。

1. 两边对 $x$ 求导：$2x + 2y\cdot\dfrac{dy}{dx} = 0$；
2. 解出通式：$\dfrac{dy}{dx} = -\dfrac{x}{y}$；
3. 代入点 $(3,4)$：斜率 $= -\dfrac{3}{4}$；切线即 $y - 4 = -\dfrac{3}{4}(x-3)$。

对比显式路线：要先声明自己在**上半圆**（$y=\sqrt{25-x^2}$），再用链式法则得 $-\dfrac{x}{\sqrt{25-x^2}}$，步骤更多还得分上下支讨论。隐式做法一步到位，而且同一个通式 $-\frac{x}{y}$ 对全圆处处有效——**这就是不解方程的回报**。

### 实验 2（python）：圆上巡逻，公式斜率对账数值斜率

```python title="沿着上半圆走一圈：-x/y 与体力差商逐点对账"
# 圆 x^2 + y^2 = 1 的上半支：给定横坐标 xx，纵坐标 yy = sqrt(1 - xx^2)
import math

h = 0.0001                   # 数值差商的探测距离：越小越接近真斜率
for xx in [0.0, 0.28, 0.6, 0.8]:
    yy = math.sqrt(1 - xx ** 2)                  # 曲线上的点 (xx, yy)，保证满足方程
    formula = -xx / yy                           # 隐函数求导给出的斜率公式：dy/dx = -x/y
    y_left = math.sqrt(1 - (xx - h) ** 2)        # 左邻点的纵坐标（数值检验员专用）
    y_right = math.sqrt(1 - (xx + h) ** 2)       # 右邻点的纵坐标
    numeric = (y_right - y_left) / (2 * h)       # 用左右邻点连线的斜率逼近真斜率
    print(f"x={round(xx, 2)}: 公式 {round(formula, 4)} | 数值 {round(numeric, 4)}")
```

每一行的两个数字都相同：$0$、$-0.2917$、$-0.75$、$-1.3333$。注意分工——公式 $-\frac{x}{y}$ 的推导**全程没碰过显式表达式**（只在方程两边动笔）；那个靠平方根反复计算的"数值检验员"，纯粹是事后请来对账的。第三列如果谁不服，还可以亲自验证 $x=0.6, y=0.8$ 时 $-\frac{0.6}{0.8}=-0.75$ 与图形的直观走向吻合：右上坡向右下坡过渡，恰好在这附近翻负。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为对 $y^2$ 求导就是 $2y$。" 必须是 $2y\cdot\frac{dy}{dx}$！$y$ 不是自由变量，它是 $x$ 的面具舞伴——凡是对 $y$ 下手的求导，都要经链式法则补挂一个 $\frac{dy}{dx}$。这是本课出错率的绝对第一名。

**误区二**："你以为解不出 $y$ 就无从下手。" 三步法的全部原料就是原方程本身。显式表达式只在"回验"时登场作证人，推导现场它一次都不需要出面。$y^5+xy+x=7$ 这种无解可寻的方程照样能审出 $\frac{dy}{dx}$。

**误区三**："你以为求出 $\frac{dy}{dx}$ 表达式就算完事。" 得分清要的是什么：问**导函数**，答案带 $y$ 属正常（如 $-\frac{x}{y}$）；问**某点切线斜率**，就必须把该点的横、纵坐标一起代入——只代 $x$ 忘代 $y$ 是高频翻车点。

:::

## 7. 练习

**练习 1**：双曲线 $xy = 4$ 上有点 $(2, 2)$（验证：$2\times 2=4$ ✓）。不许解出 $y$，用隐函数求导算出这点的切线斜率。下面的代码凭直觉猜了个答案——用乘积法则推一遍，改到正确：

```exercise
# @title: 练习：不给面具舞伴拍照也算出她的步态
# @check: -1.0
# @hint: 对 xy=4 两边关于 x 求导，乘积法则给出 y + x·dy/dx = 0（右边常数 4 的导数是零），于是 dy/dx = -y/x。把点 (2,2) 的两个坐标都代进去
x0 = 2.0
y0 = 2.0              # 曲线 xy = 4 上的一点

slope = 1 / x0        # ← 直觉猜的："y=4/x 就是倒数函数，坡度像 1/x"？请用求导验证它

print(round(slope, 1))
```

心算复核：两边对 $x$ 求导得 $y + x\cdot\frac{dy}{dx} = 0$，所以 $\frac{dy}{dx} = -\frac{y}{x}$；代 $(2,2)$ 得 $-1$。直觉答案 $+\frac{1}{2}$ 连符号都是反的——想象一下，曲线在该点其实是**下行**的。

<details>
<summary>点开查看逐步解答</summary>

设 $y=y(x)$（舞伴戴着面具但关系真实存在）。

1. 方程 $xy = 4$ 两边对 $x$ 求导。左边是乘积 $x\cdot y$，用乘积法则：$(x)' \cdot y + x\cdot (y)' = 1\cdot y + x\cdot\frac{dy}{dx}$；右边常数 $4$ 的导数为 $0$；
2. 得到 $y + x\cdot\frac{dy}{dx} = 0$；
3. 移项：$\frac{dy}{dx} = -\frac{y}{x}$；
4. 代入点 $(2, 2)$：斜率 $= -\frac{2}{2} = -1$。

有趣的对称美：对双曲线 $xy=4$ 来说，斜率公式 $-y/x$ 与圆的 $-x/y$ 正好互为镜像——前者"过象限角下行"，后者"绕圆周下行"。
</details>

**练习 2**（思考）：圆 $x^2+y^2=25$ 上哪些点的切线是竖直的？那时斜率公式发生了什么？

<details>
<summary>点开查看逐步解答</summary>

竖直切线意味着斜率无穷大。公式 $\frac{dy}{dx} = -\frac{x}{y}$ 的分母是 $y$：当 $y=0$（即 $x=\pm 5$，圆的最左与最右两点）时分母归零，斜率爆炸为无穷大——几何上切线正好竖直立起。这也预告了一个边界情况：在这些点上，"把 $y$ 看成 $x$ 的函数"这件事本身（局部地）走到了尽头，$x$ 反倒成了 $y$ 的函数。隐函数求导公式的失效位置，恰好标记着关系的换位处。
</details>

## 8. 边界之外

有三件事本课**不做也不许装做做了**：

- **一个方程不一定藏着函数**。$x^2+y^2=-1$ 连实数点都没有；有的方程在某些段里一段 $x$ 对应多个 $y$。"方程什么时候真的局部确定出 $y(x)$"这个问题要用第 20 章的**隐函数定理**回答，那需要偏导数的语言。
- **竖直切线与尖点**。$y=0$ 处 $\frac{dy}{dx}$ 爆炸，我们的公式在那里失语——不是曲线无斜率，而是 "$y$ 关于 $x$" 这个提问方向到了头。
- **多变量推广**。三元方程 $F(x,y,z)=0$ 决定曲面，其切平面与梯度是第 20 章的主菜；拉格朗日乘数法（第 43 章）更是把"约束下找最值"整个架在隐函数思想上。
