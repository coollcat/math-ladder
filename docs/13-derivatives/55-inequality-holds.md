# 恒成立问题：三种通法

## 1. 从一个场景开始

桥梁的主缆垂成一条曲线 $y = f(x)$。设计规范写道："**全跨范围内**，缆索不得低于安全高度 $a$。" 这句话翻译成数学，是对**每一个** $x$ 同时提出要求——只要有一个 $x$ 让缆索掉到 $a$ 以下，整份设计就作废。

这类"对一切都成立"的命题叫**恒成立问题**，它是高考导数压轴题最固定的面孔。难点不在求导，在于**把"对所有 $x$"这句话翻译成一个可以解的条件**。本课给三种通法：分离参数、最值法、端点效应；顺带把孪生兄弟"存在性"的区别讲清——"全都过关"和"有一个过关"，看的是两个不同的最值。

## 2. 直觉解释

把区间里每一个 $x$ 都想象成一个考生，$f(x)$ 是他的分数，分数线是 $a$。

- **恒成立**（$f(x) \ge a$ 对所有 $x$）：**全班都得上线**。那么只要盯住最差的那个——最低分都上线了，其余自然全过。所以看**最小值**；
- **存在性**（存在 $x$ 使 $f(x) \ge a$）：**有一个上线就行**。那么只要盯住最好的那个——最高分都上不了线，别人更没戏。所以看**最大值**。

至于"分离参数"，思路更简单：如果参数 $a$ 能从式子里单独摘出来（$a \ge g(x)$ 或 $a \le g(x)$），那就不必管 $f$ 长什么样，只要把右侧 $g$ 的**最大值或最小值**找出来即可。能分离就分离，因为分离之后求最值的对象往往比原式简单得多。

**端点效应**则是对付"分离不动"的硬骨头的：先让区间端点（往往是取等的那一点）给出一个**必要条件**，把参数范围砍到一半，再回头证明这一半范围里条件确实充分。

## 3. 正式定义

**四种命题的等价条件**（设 $f$ 在 $D$ 上连续、最值存在）：

| 命题 | 等价条件 | 记法 |
| --- | --- | --- |
| 任意 $x \in D$，$f(x) \ge a$ | $f_{\min} \ge a$ | 恒成立·下界 |
| 任意 $x \in D$，$f(x) \le a$ | $f_{\max} \le a$ | 恒成立·上界 |
| 存在 $x \in D$ 使 $f(x) \ge a$ | $f_{\max} \ge a$ | 存在性 |
| 存在 $x \in D$ 使 $f(x) \le a$ | $f_{\min} \le a$ | 存在性 |

| 符号 | 含义 | 备注 |
| --- | --- | --- |
| $f_{\min}$ / $f_{\max}$ | $f$ 在 $D$ 上的最小 / 最大值 | 候选点 = 驻点 + 不可导点 + **区间端点** |
| $\forall x \in D$ | 对每一个 $x$（恒成立） | 看最小值（下界型） |
| $\exists x \in D$ | 至少有一个 $x$（存在性） | 看最大值（f ≥ a 型） |
| 取等条件 | 使不等式恰好成等号的 $x$ | 恒成立题里它常是极值点或区间端点 |

**通法一 · 分离参数**：若原不等式可化为 $a \ge g(x)$ 对一切 $x \in D$ 成立，则 $a \ge g_{\max}$；若化为 $a \le g(x)$，则 $a \le g_{\min}$。**除过去时若除以含 $x$ 的式子，必须先确定它的符号**（正数不变号、负数要翻转）。

**通法二 · 最值法**：分离不动时，直接求 $f$ 在 $D$ 上的最值（单调区间 + 端点比较），再套上表里的等价条件。

**通法三 · 端点效应**：若不等式在区间端点 $x_0$ 处取等（$f(x_0) = 0$），则由端点处的各阶导数符号可**必要地**定出参数范围；再证该范围充分。

## 4. 分步例题

### 例 1（分离参数）：$\ln x \le ax - 1$ 对一切 $x > 0$ 恒成立，求 $a$ 的范围

1. **定定义域**：$\ln x$ 要求 $x > 0$，故只需在 $(0, +\infty)$ 上检查；
2. **把 $a$ 摘出来**：$ax \ge \ln x + 1$，由于 $x > 0$（**正数，除过去不变号**），得

$$a \ge \frac{\ln x + 1}{x} =: g(x)$$

3. **求 $g$ 的最大值**：$g'(x) = \dfrac{\frac{1}{x}\cdot x - (\ln x + 1)}{x^2} = \dfrac{-\ln x}{x^2}$。
   - $0 < x < 1$：$\ln x < 0$，故 $g' > 0$，$g$ 递增；
   - $x > 1$：$\ln x > 0$，故 $g' < 0$，$g$ 递减；
   - 于是 $g$ 在 $x = 1$ 处取最大值 $g(1) = \dfrac{0 + 1}{1} = 1$；
4. **下结论**：$a \ge g_{\max} = 1$。

取等检验：$a = 1$ 时不等式是 $\ln x \le x - 1$，在 $x = 1$ 处取等——直线 $y = x - 1$ 恰好是 $\ln x$ 在 $(1, 0)$ 处的切线（41 课的例 1）。**取等点就是切点**，这不是巧合：分离参数法的取等处，两侧的函数图像必定相切。

### 例 2（最值法）：$f(x) = x^3 - 3x^2 + 1$，$f(x) \ge m$ 在 $[-1, 2]$ 上恒成立，求 $m$ 的最大值

1. **求导**：$f'(x) = 3x^2 - 6x = 3x(x - 2)$；
2. **排单调区间**：在 $[-1, 0)$ 上 $f' > 0$（递增），在 $(0, 2)$ 上 $f' < 0$（递减）；
3. **列候选点**：驻点 $x = 0$，加上两个端点 $x = -1$、$x = 2$；
4. **算值比较**：$f(-1) = -1 - 3 + 1 = -3$、$f(0) = 1$、$f(2) = 8 - 12 + 1 = -3$；
5. **得最值**：$f_{\min} = -3$（**在两个端点同时取到**，两端一样低），$f_{\max} = 1$；
6. **套条件**：$f_{\min} \ge m \iff -3 \ge m$，故 $m \le -3$，$m$ 的最大值为 $-3$。

### 例 3（端点效应）：$e^x - 1 - x - ax^2 \ge 0$ 对一切 $x \ge 0$ 恒成立，求 $a$ 的范围

记 $F(x) = e^x - 1 - x - ax^2$，观察端点：$F(0) = 1 - 1 - 0 - 0 = 0$——**不等式在 $x = 0$ 处恰好取等**。这正是端点效应的入场信号。

**第一步：端点给必要条件。**

- $F(0) = 0$，$F'(x) = e^x - 1 - 2ax$ 故 $F'(0) = 0$，$F''(x) = e^x - 2a$ 故 $F''(0) = 1 - 2a$；
- 反设 $a > \dfrac{1}{2}$，则 $F''(0) = 1 - 2a < 0$。由于 $F''$ 连续，存在 $\delta > 0$ 使 $F''(x) < 0$ 在 $[0, \delta]$ 上恒成立；
- 于是 $F'$ 在 $[0, \delta]$ 上严格递减，$F'(x) < F'(0) = 0$（$x \in (0, \delta]$）；
- 于是 $F$ 在 $[0, \delta]$ 上严格递减，$F(x) < F(0) = 0$（$x \in (0, \delta]$）——与"恒非负"矛盾；
- 故必有 $a \le \dfrac{1}{2}$。

**第二步：证这个范围充分。**

- 设 $a \le \dfrac{1}{2}$。对 $x \ge 0$ 有 $e^x \ge 1$，故 $F''(x) = e^x - 2a \ge 1 - 2a \ge 0$；
- $F'' \ge 0$ ⇒ $F'$ 在 $[0, +\infty)$ 上递增，$F'(x) \ge F'(0) = 0$；
- $F' \ge 0$ ⇒ $F$ 在 $[0, +\infty)$ 上递增，$F(x) \ge F(0) = 0$ ✓

**答案：$a \le \dfrac{1}{2}$。** 注意两次用的都是同一条单调性定理（50 课），只是第一次反着用（导出矛盾）、第二次正着用（证明成立）。

### 例 4（恒成立 vs 存在性）：同一个 $f$，四种问法

仍取例 2 的 $f(x) = x^3 - 3x^2 + 1$ 与区间 $[-1, 2]$，已知 $f_{\min} = -3$、$f_{\max} = 1$：

| 问法 | 量词 | 等价条件 | 答案 |
| --- | --- | --- | --- |
| $f(x) \ge m$ 恒成立 | $\forall x$ | $f_{\min} \ge m$ | $m \le -3$ |
| 存在 $x$ 使 $f(x) \ge m$ | $\exists x$ | $f_{\max} \ge m$ | $m \le 1$ |
| $f(x) \le M$ 恒成立 | $\forall x$ | $f_{\max} \le M$ | $M \ge 1$ |
| 存在 $x$ 使 $f(x) \le M$ | $\exists x$ | $f_{\min} \le M$ | $M \ge -3$ |

同一个 $-3$ 与 $1$，四个问题四个方向。**"恒成立"和"存在"只差两个字，答案却从 $-3$ 跳到 $1$**——这之间的 $m \in (-3, 1]$ 全都满足"存在 $x$ 使 $f(x) \ge m$"，却一个也不满足"恒成立"。

### 实验 3（python）：把 $a$ 逼到墙角

```python title="扫描 (ln x + 1)/x 的最大值——它就是 a 的下限"
import math

best = -1000000.0          # 装最大值的罐子，先塞一个极小的数
best_x = 0.0
x = 0.01
while x <= 5:
    value = (math.log(x) + 1) / x      # 分离后右边那个式子
    if value > best:
        best = value
        best_x = x                     # 顺手记下最大值出现在哪儿
    x = x + 0.001

print(f"最大值 {round(best, 4)}，出现在 x ≈ {round(best_x, 3)}")
print("所以 a ≥", round(best, 4))
```

输出 `最大值 1.0，出现在 x ≈ 1.0` 与 `所以 a ≥ 1.0`——与例 1 的手算结果完全一致。把扫描上限从 $5$ 改成 $50$ 再跑一次，答案不变：$g$ 在 $x > 1$ 之后一路递减趋于 $0$，最大值牢牢钉在 $x = 1$。

"f(x) ≥ a 对区间内的一切 x 都成立"等价于什么？
- f 在区间上的最大值 ≥ a
- f 在区间上的最小值 ≥ a [*]
- 存在某个 x 使 f(x) ≥ a

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为恒成立就看最大值。" 恰恰相反：**恒成立看最小值**（下界型），存在性才看最大值。例 4 用同一组数字把四个方向列齐了——把"$\forall$"读成"$\exists$"，答案立刻从 $-3$ 变成 $1$。判定口诀：*全体过关看最差，有人过关看最好*。

**误区二**："你以为分离参数时除过去不用管符号。" 例 1 之所以能直接除，是因为 $x > 0$。若区间含负数，必须**分 $x > 0$ 与 $x < 0$ 两种情况**，后者的不等号要翻转；$x = 0$ 则要单独代回原式检验。分离参数的每一步"除以含 $x$ 的式子"都要先问一句"它在这儿是正还是负"。

**误区三**："你以为端点给出的条件就是答案。" 端点效应给的是**必要条件**，它可以把 $a$ 从"任意实数"砍到 $a \le \frac{1}{2}$，但砍完还得回头**证充分**（例 3 第二步用 $F'' \ge 0$ 一路推回去）。少了充分性，你只证明了"超出这个范围一定不行"，没证明"在这个范围里一定行"。

:::

## 7. 练习

**练习 1**：下面的代码想用分离参数求出 $a$ 的下限，但比较方向写反了，扫出一个负数。修正它：

```exercise
# @title: 练习：分离参数后，最大值说了算
# @check: a 的最小值 = 1.0
# @hint: ln x ≤ a·x - 1 分离成 a ≥ (ln x + 1)/x（x > 0，除过去不变号）；a 要同时扛住所有 x，所以取的是右侧的**最大值**，不是最小值
import math

best = -1000000.0            # 存极值的罐子
x = 0.01
while x <= 5:
    value = (math.log(x) + 1) / x      # 每个 x 都要求 a 不低于它
    if value < best:                   # ← 方向反了：这行在找最小值
        best = value
    x = x + 0.001
print("a 的最小值 =", round(best, 3))
```

现在它输出 `a 的最小值 = -1000000.0`——罐子里还是那个初值：方向一反，`value < best` 要求比 $-1000000$ 还小，而 $g$ 在扫描范围内最小也有约 $-360.5$（出现在左端 $x = 0.01$），一个数都装不进去。这明显不是 $a$ 该守的下限。

<details>
<summary>点开查看逐步解答</summary>

$a$ 要大于**每一个** $g(x) = \dfrac{\ln x + 1}{x}$，就得大于其中最大的那个。把比较符号反过来：

```python
import math

best = -1000000.0
x = 0.01
while x <= 5:
    value = (math.log(x) + 1) / x
    if value > best:                   # 找最大值
        best = value
    x = x + 0.001
print("a 的最小值 =", round(best, 3))
```

输出 `a 的最小值 = 1.0`，与例 1 一致。为什么错版输出的是 $-1000000$？**罐子的初值必须与寻找的方向配套**：找最大值要配一个极小的初值，找最小值要配一个极大的初值（如 $10^6$）。错版沿用了找最大值的极小罐子 $-10^6$，却去比较 `value < best`——$g$ 再小也小不过 $-10^6$，罐子原封不动，扫了个寂寞。另外注意：$g$ 在扫描范围内的最小值 $-360.5$ 出现在左端附近，而 $x \to 0^+$ 时 $g(x) \to -\infty$，真正的下界根本不存在。**恒成立问题的答案永远是"最紧的那个约束"，也就是最大值。**

</details>

**练习 2**（思考）：把例 2 的区间从 $[-1, 2]$ 换成 $[-1, 1]$，其余不变。$f_{\min}$ 与 $f_{\max}$ 各是多少？"存在 $x$ 使 $f(x) \ge m$"的答案会变吗？

<details>
<summary>点开查看逐步解答</summary>

单调性不变：$[-1, 0)$ 递增、$(0, 1]$ 递减。候选点是 $x = -1$、$0$、$1$：

$$f(-1) = -3,\quad f(0) = 1,\quad f(1) = 1 - 3 + 1 = -1$$

所以 $f_{\min} = -3$（在左端点），$f_{\max} = 1$（在 $x = 0$）。

- "$f(x) \ge m$ 恒成立"：$m \le -3$，**没变**；
- "存在 $x$ 使 $f(x) \ge m$"：$m \le 1$，**也没变**。

两个答案都没变，因为两端点里较矮的那个（$-3$）与驻点（$1$）都还在区间内。真正会改变答案的是缩到 $[0, 1]$：那时 $f_{\min} = -1$、$f_{\max} = 1$，恒成立的下界从 $-3$ 抬到 $-1$。**恒成立问题对区间端点极其敏感——端点正是最值最容易藏身的地方。**

</details>

## 8. 选读与边界

<details>
<summary>选读：端点效应为什么叫"端点效应"</summary>

例 3 的 $F(0) = 0$ 说明不等式在端点处**恰好取等**。既然 $F$ 在 $x = 0$ 处既等于零又要从此往上涨，那么它在 $0$ 处的"起步姿态"就被锁死了：一阶 $F'(0) = 0$（不能往下扎），二阶 $F''(0) \ge 0$（不能朝下弯）。$F''(0) = 1 - 2a \ge 0$ 立刻给出 $a \le \frac{1}{2}$——**端点处的高阶导数，把参数锁进了半个平面**，这就是"端点效应"这个名字的来历。

一般规律：若 $F(x_0) = F'(x_0) = \cdots = F^{(k-1)}(x_0) = 0$ 而 $F^{(k)}(x_0) \neq 0$，则 $F$ 在 $x_0$ 附近的首项是 $\dfrac{F^{(k)}(x_0)}{k!}(x - x_0)^k$。$F \ge 0$ 要求它非负，于是从"第一个不为零的导数"就能读出必要条件。这个展开叫泰勒展开，第 16 章会正式讲。

它的局限同样明显：**端点效应只在端点取等时才好用**。若不等式在区间内部取等（比如例 1 在 $x = 1$ 处），端点那点信息就毫无用处，必须回到分离参数或最值法。

</details>

本课不管三件事：

- **多参数恒成立**。含两个以上参数时要先固定一个，或借助几何意义（线性规划），超出本课范围；
- **整数参数**。"$a$ 为整数且恒成立"要在实数范围之外再取一次整，别漏掉最后一步；
- **开区间上的恒成立**。开区间未必有最小值，此时要改成看**下确界**（如例 3 的 $\frac{1}{2}$ 就取不到），结论从 $a \le g_{\min}$ 变成 $a \le \inf g$。
