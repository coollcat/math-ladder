# 双变量问题：极值点偏移与构造法

## 1. 从一个场景开始

一种药物的血药浓度按 $f(x) = x e^{-x}$ 变化（$x$ 是服药后的小时数）。浓度先升后降，峰值出现在 $x = 1$。现在医生问：浓度等于 $0.2$ 的两个时刻 $x_1 < x_2$，它们的**和**比 $2$ 大还是小？

这题麻烦在哪儿？方程 $x e^{-x} = 0.2$ 是个**超越方程**——$x_1$、$x_2$ 都写不出闭式解。你不可能"解出来再相加"。可题目恰恰要比较两个你算不出来的数。

这类题有个专名：**双变量问题**。它的解法不是硬算，而是"绕过去"——把两个变量并成一个，或者干脆绕开它们去比函数值。本课的三件武器：对称化构造、比值换元、构造函数。

## 2. 直觉解释

先看图像给的暗示。$f(x) = x e^{-x}$ 从原点出发急升到峰顶 $(1, \frac{1}{e})$，然后拖着一条**又长又平的下尾巴**缓缓趋近于 $0$。

拿一把水平尺在高度 $m$ 处横切过去：

- 左边那一段是"陡坡"，水平尺与它相交的位置离峰顶**很近**；
- 右边那一段是"缓坡"，同一个高度要在很远处才追上，交点离峰顶**很远**。

所以两个交点关于峰顶并不对称：**右边那个离得更远**，于是 $x_1 + x_2 > 2 \cdot 1 = 2$。

这个现象叫**极值点偏移**：两个解的中点 $\dfrac{x_1 + x_2}{2}$ 并不落在极值点 $x_0$ 上，而是往"缓坡那侧"偏。直觉已经告诉我们方向，剩下的活是**把它变成证明**——毕竟"尾巴更长"不是数学语言。

## 3. 正式定义

| 名称 | 内容 | 何时用 |
| --- | --- | --- |
| 极值点偏移 | $f(x) = m$ 的两解 $x_1 < x_2$，比较 $x_1 + x_2$ 与 $2x_0$（$x_0$ 为极值点） | 单峰函数、两解分列极值点两侧 |
| 对称化构造 | 构造 $F(x) = f(2x_0 - x) - f(x)$，在极值点**一侧**判号 | 极值点偏移的首选武器 |
| 比值换元 | 令 $t = \dfrac{x_2}{x_1} > 1$，两变量并成一个 | 两解同号、且方程能取对数 |
| 构造函数法 | 作差 $h = $ 左 $-$ 右，求导判号，配合端点值 | 换元后的收尾工序 |

| 符号 | 含义 | 备注 |
| --- | --- | --- |
| $x_0$ | 极值点横坐标，$f'(x_0) = 0$ | 偏移的参照中心 |
| $x_1, x_2$ | 方程 $f(x) = m$ 的两个解，约定 $x_1 < x_2$ | 通常**解不出来** |
| $2x_0 - x_1$ | $x_1$ 关于直线 $x = x_0$ 的**对称点** | 不是关于 $y$ 轴对称 |
| $t = x_2/x_1$ | 比值换元的新变量，范围 $t > 1$ | 约定 $x_1 < x_2$ 才保证 $t > 1$ |

**对称化构造的逻辑链**（以 $f$ 在 $(x_0, +\infty)$ 递减为例，记 $F(x) = f(2x_0 - x) - f(x)$）：

$$\text{在 }(0, x_0)\text{ 上 } F(x) > 0 \;\Longrightarrow\; f(x_1) < f(2x_0 - x_1) \;\overset{f(x_2) = f(x_1)}{=\Longrightarrow}\; f(x_2) < f(2x_0 - x_1) \;\overset{\text{递减}}{\Longrightarrow}\; x_2 > 2x_0 - x_1$$

最后一步就是 $x_1 + x_2 > 2x_0$。**全程没有解出任何一个根。**

## 4. 分步例题

### 例 1（对称化构造）：$f(x) = x e^{-x}$，两解满足 $x_1 + x_2 > 2$

**设题**：$0 < m < \dfrac{1}{e}$，方程 $x e^{-x} = m$ 有两解 $x_1 \in (0, 1)$、$x_2 \in (1, +\infty)$。

1. **确认单调性**：$f'(x) = e^{-x} + x(-e^{-x}) = e^{-x}(1 - x)$。在 $(0, 1)$ 上 $f' > 0$（递增），在 $(1, +\infty)$ 上 $f' < 0$（递减），峰顶 $x_0 = 1$，$f(1) = \dfrac{1}{e}$；
2. **搭桥**：$x_1 < 1$，故 $2 - x_1 > 1$，与 $x_2$ 同在递减区间 $(1, +\infty)$ 内。于是

$$x_1 + x_2 > 2 \iff x_2 > 2 - x_1 \iff f(x_2) < f(2 - x_1) \iff f(x_1) < f(2 - x_1)$$

（最后一步用了 $f(x_2) = f(x_1) = m$，即"两解等高"这个题眼。）

3. **构造并求导**：令 $F(x) = f(2 - x) - f(x) = (2 - x)e^{x-2} - x e^{-x}$，则

$$F'(x) = (1 - x)e^{x-2} - (1 - x)e^{-x} = (1 - x)\left(e^{x-2} - e^{-x}\right)$$

4. **判号**：在 $(0, 1)$ 上 $1 - x > 0$；又由 $x < 1$ 得 $x - 2 < -x$，故 $e^{x-2} < e^{-x}$，括号为负。于是 $F'(x) < 0$，$F$ 在 $(0, 1)$ 上**递减**；
5. **收口**：$F(1) = f(1) - f(1) = 0$，结合递减得 $F(x) > 0$ 对一切 $x \in (0, 1)$ 成立；
6. **代回**：取 $x = x_1$，得 $f(2 - x_1) > f(x_1)$，由第 2 步的等价链得 $x_1 + x_2 > 2$。

**数值验算**（$m = 0.2$）：$x_1 \approx 0.2592$、$x_2 \approx 2.5426$，和为 $2.8018 > 2$ ✓。而且 $m$ 越接近 $\frac{1}{e}$，两个解越靠近峰顶，和越接近 $2$（但始终大于 $2$）。

### 例 2（比值换元）：同一结论的第二条路

1. **取对数**：$x_1 e^{-x_1} = x_2 e^{-x_2}$ 两边取 $\ln$，得 $\ln x_1 - x_1 = \ln x_2 - x_2$，即

$$\ln\frac{x_2}{x_1} = x_2 - x_1$$

2. **换元**：令 $t = \dfrac{x_2}{x_1} > 1$，则 $x_2 - x_1 = x_1(t - 1)$，代入得 $x_1 = \dfrac{\ln t}{t - 1}$，从而 $x_2 = \dfrac{t\ln t}{t - 1}$；

$$x_1 + x_2 = \frac{(1 + t)\ln t}{t - 1}$$

3. **化归成一个单变量不等式**：要证 $x_1 + x_2 > 2$，即证

$$h(t) := (1 + t)\ln t - 2(t - 1) > 0 \qquad (t > 1)$$

4. **构造函数法收尾（作差 → 求导 → 判号）**：

$$h(1) = 0,\quad h'(t) = \ln t + \frac{1 + t}{t} - 2 = \ln t + \frac{1}{t} - 1,\quad h'(1) = 0$$

$$h''(t) = \frac{1}{t} - \frac{1}{t^2} = \frac{t - 1}{t^2} > 0 \quad (t > 1)$$

$h'' > 0$ ⇒ $h'$ 在 $(1, +\infty)$ 上递增，$h'(t) > h'(1) = 0$ ⇒ $h$ 递增，$h(t) > h(1) = 0$ ✓

**两条路的对比**：对称化构造全程不碰对数，靠"翻折 + 单调性"说话；比值换元把两个变量压成 $t$，剩下的活交给求导判号。换元之后那三步（作差、求导、判号）就是**构造函数法**的标准三连——它是所有换元题的收尾工序。

### 例 3（搬到新题）：$f(x) = \ln x - ax$ 的两零点满足 $x_1x_2 > e^2$

**设题**：$0 < a < \dfrac{1}{e}$ 时 $f(x) = \ln x - ax$ 有两个零点 $x_1 < x_2$（峰顶在 $x_0 = \dfrac{1}{a}$，峰值 $\ln\frac{1}{a} - 1 > 0$）。

1. **写出零点满足的关系**：$\ln x_1 = a x_1$、$\ln x_2 = a x_2$；
2. **作差定出 $a$**：$\ln\dfrac{x_2}{x_1} = a(x_2 - x_1)$。令 $t = \dfrac{x_2}{x_1} > 1$，则 $a = \dfrac{\ln t}{x_1(t - 1)}$；
3. **作和定出目标**：$\ln(x_1x_2) = \ln x_1 + \ln x_2 = a(x_1 + x_2) = a x_1(1 + t) = \dfrac{(1 + t)\ln t}{t - 1}$；
4. **搬用例 2 的结论**：$h(t) > 0$ 已经证过，故 $\dfrac{(1 + t)\ln t}{t - 1} > 2$，于是 $\ln(x_1x_2) > 2$，即

$$x_1 x_2 > e^2$$

**数值验算**（$a = 0.3$）：$x_1 \approx 1.63$、$x_2 \approx 5.94$，乘积约 $9.68 > e^2 \approx 7.389$ ✓。

**三题归一**：例 1、例 2 证的是同一件事，例 3 看起来是一道全新的题，最后却落在**同一个不等式** $(1+t)\ln t > 2(t-1)$ 上。这就是双变量问题的真相——**换元换到最后，大家共用一张底牌**。

### 实验 3（python）：解不出来，那就二分

```python title="拖动 m：机器报出两个解的和，与 2 比一比"
import math
# sliders: m=0.2 [0.05:0.35:0.01]

def f(x):
    return x * math.exp(-x)          # 峰顶在 x = 1，峰值 1/e ≈ 0.3679

lo = 0.001
hi = 1.0
for i in range(50):                  # 二分法：左半支递增，找 x1
    mid = (lo + hi) / 2
    if f(mid) < m:
        lo = mid
    else:
        hi = mid
x1 = (lo + hi) / 2

lo = 1.0
hi = 20.0
for i in range(50):                  # 二分法：右半支递减，找 x2
    mid = (lo + hi) / 2
    if f(mid) > m:
        lo = mid
    else:
        hi = mid
x2 = (lo + hi) / 2

print(f"m = {round(m, 2)}: x1 = {round(x1, 4)}, x2 = {round(x2, 4)}")
print(f"x1 + x2 = {round(x1 + x2, 4)}  >  2 ?  {x1 + x2 > 2}")
```

$m = 0.2$ 时输出 `x1 = 0.2592, x2 = 2.5426` 与 `x1 + x2 = 2.8018 > 2 ? True`。把 $m$ 从 $0.05$ 拖到 $0.35$，和从约 $4.55$ 一路降到约 $2.07$——**越来越接近 $2$，却永远够不着**。这正是例 1 的结论：$x_1 + x_2 > 2$ 严格成立，等号只在两个解合并于峰顶的极限情形 $m = \frac{1}{e}$ 时才取到（那时"两个解"已经不存在了）。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为得先把两个解求出来。" $x e^{-x} = 0.2$ 这类方程没有初等闭式解（它要用到一个叫朗伯 W 的特殊函数）。双变量问题的全部技巧，都是**绕开"解出根"这一步**：要么比较函数值（对称化构造），要么换元（比值换元）。硬要去解，就是把自己堵死在门口。

**误区二**："你以为'对称'是关于 $y$ 轴对称。" 对称化构造翻的是**关于直线 $x = x_0$** 的对称点，式子是 $f(2x_0 - x)$ 而不是 $f(-x)$。例 1 里 $x_0 = 1$，翻出来的点是 $2 - x$；若极值点在 $x_0 = \frac{1}{a}$（例 3），对称点就是 $\frac{2}{a} - x$。写错对称中心，整条逻辑链立刻断掉。

**误区三**："你以为 $t = \frac{x_2}{x_1}$ 的范围是整个 $(0, +\infty)$。" 因为约定了 $x_1 < x_2$ 且两者同号为正，所以 $t > 1$。这个方向不能颠倒：若改设 $t = \frac{x_1}{x_2}$，则 $0 < t < 1$，所有要证的不等式都要**反向重写**。例 2 中 $h'(t)$、$h''(t)$ 的符号判断全都是在 $t > 1$ 的前提下做的，方向一换，判号就跟着变。

:::

## 7. 练习

**练习 1**：下面的对称化构造把作差方向写反了，四个 $F$ 值全成了负数。改正它：

```exercise
# @title: 练习：对称化构造，用数字验一遍
# @check: x=0.1: F = 0.1937
# @check: x=0.26: F = 0.1049
# @check: x=0.5: F = 0.0314
# @check: x=0.9: F = 0.0002
# @hint: F(x) 应该是 f(2-x) - f(x)：把 x 关于极值点 1 翻到右边再作差；在 (0,1) 上它恒为正，且越靠近 1 越接近 0，符号反了就是四个负数
import math

def f(x):
    return x * math.exp(-x)      # 本课主角：峰顶在 x = 1

def F(x):
    return f(x) - f(2 - x)       # ← 作差的方向反了

for x in [0.1, 0.26, 0.5, 0.9]:
    print(f"x={x}: F = {round(F(x), 4)}")
```

<details>
<summary>点开查看逐步解答</summary>

对称化构造是"**翻折后的点** 减 **原来的点**"：

```python
import math

def f(x):
    return x * math.exp(-x)

def F(x):
    return f(2 - x) - f(x)       # 翻到右边，减去左边

for x in [0.1, 0.26, 0.5, 0.9]:
    print(f"x={x}: F = {round(F(x), 4)}")
```

四行输出是 `0.1937`、`0.1049`、`0.0314`、`0.0002`——**全部为正，且一路递减趋向 $0$**。这正是例 1 第 4、5 步的画面：$F$ 在 $(0, 1)$ 上递减，右端点 $F(1) = 0$，所以左侧处处为正。

最后那个 $0.0002$ 值得盯一眼：$x = 0.9$ 离峰顶只差 $0.1$，$F$ 已经小到万分之二。这说明 $x_1$ 越靠近峰顶，偏移越微弱——不等式仍然严格成立，但余量趋近于零。

</details>

**练习 2**（思考）：在例 1 中把函数换成 $g(x) = x^2 e^{-x}$（峰顶在 $x = 2$）。它的两个解 $x_1 < 2 < x_2$ 满足 $x_1 + x_2 > 4$ 还是 $< 4$？说出你的判断依据（不必完整证明）。

<details>
<summary>点开查看逐步解答</summary>

判断：$x_1 + x_2 > 4$。

依据是对称化构造的关键判号步骤。令 $G(x) = g(4 - x) - g(x)$，仍走例 1 的等价链，只需判 $G$ 在 $(0, 2)$ 上的符号。$g'(x) = e^{-x}(2x - x^2) = x e^{-x}(2 - x)$，在 $(0, 2)$ 上为正、$(2, +\infty)$ 上为负，峰顶确实是 $x_0 = 2$；但 $g$ 左侧从 $g(0) = 0$ 起步且 $g'(0) = 0$——起步是**二次**的，比 $x e^{-x}$ 的线性起步平缓，而右侧尾巴仍是指数衰减。两侧形态都变了，直觉靠不住，必须真算。

数值验算（$m = 0.2$）：$x_1 \approx 0.605$、$x_2 \approx 4.708$，和约 $5.313 > 4$ ✓。拆开看两侧：左距峰顶 $2 - 0.605 = 1.395$，右距峰顶 $4.708 - 2 = 2.708$——**右侧仍然更远，偏移方向仍朝右**，指数尾巴占上风，$x_1 + x_2 > 2x_0$ 的机制与例 1 相同。变了的只是左解：二次起步把它推得比 $x e^{-x}$ 情形（左距 $1 - 0.259 = 0.741$）更靠外，"和"因此更容易过线。可见偏移朝哪边、差多少，取决于**两侧增长/衰减形态的相对快慢**——这正是必须做完整判号、而不是靠看图猜的原因。

</details>

## 8. 选读与边界

<details>
<summary>选读：例 2 证的那个不等式，其实有个名字</summary>

例 2 的核心不等式 $h(t) > 0$ 可以改写成 $\dfrac{t - 1}{\ln t} < \dfrac{1 + t}{2}$（$t > 1$）。把 $t = \dfrac{b}{a}$（$0 < a < b$）代回去，就是著名的**对数均值不等式**的右半边：

$$\sqrt{ab} \;<\; \frac{b - a}{\ln b - \ln a} \;<\; \frac{a + b}{2}$$

中间那个量叫 $a$、$b$ 的**对数平均**，夹在几何平均与算术平均之间；左半边 $\sqrt{ab} < \frac{b-a}{\ln b - \ln a}$ 也能用同样的构造函数套路证出来（留作挑战）。这条不等式在高考双变量题里出场率极高：凡是要比较 $x_1 + x_2$、$x_1 x_2$、$\frac{1}{x_1} + \frac{1}{x_2}$ 的题，换元之后几乎都会撞上它——记住它，等于提前备好一张底牌。

</details>

本课不管三件事：

- **三个及以上变量**。本课所有技巧都是"两变量并成一变量"，三变量需要更复杂的对称化处理；
- **需要三阶以上信息才能定号的偏移**。若 $F(2x_0 - x) - F(x)$ 的前两阶导数都在对称中心处为零，就得继续往下求导，步骤更长但思路不变；
- **多元函数的极值点偏移**。曲面上的对应问题要用 Hessian 矩阵（第 20 章）。
