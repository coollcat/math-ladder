# 相关变化率

## 1. 从一个场景开始

消防队训练塔前立着一架 5 米长的梯子，底端离墙 3 米。安全员以每秒 0.4 米的速度把梯子底端往外拉——问：**此刻**梯子顶端沿墙下滑得有多快？

墙的高度和底距由梯子长度锁死，一个动另一个必须跟着动。但"跟着动"的节奏并不显然：底端匀速外拉，顶端可不是匀速下滑——越滑越快还是越滑越慢？这一课要建一套流水线，把"一个量的变化率"顺着关系方程传给"另一个量的变化率"。这套手艺叫**相关变化率**，它是链式法则在现实世界最忙碌的一个岗位。

## 2. 直觉解释

关键只有一句话：**两个量都被同一只秒表驱动**。底距 $x$ 是时间的函数，墙高 $y$ 也是时间的函数，而梯子长度给它们上了枷锁：

$$x^2+y^2=25$$

这正是[隐函数求导](./37-implicit-differentiation.md)那一课的圆方程——只不过当时我们审的是曲线上的斜率 $\frac{dy}{dx}$，今天审的是**两根钟表指针的联动**。既然方程两边都是时间的函数，那就让两边**同时对时间 $t$ 求导**：含 $x$ 的部分照常求、乘上 $\frac{dx}{dt}$；含 $y$ 的部分照常求、乘上 $\frac{dy}{dt}$（链式法则替每个"面具舞伴"挂上自己的链环）。左边的常数 25 求导归零——枷锁长度不变，正是它的"导数为零"把两个变化率拴在了一起。

打个比方：$x$ 和 $y$ 是一对被同一根横杆锁住的齿轮，你摇动其中一根，另一根的转速**不是你规定的**，而是被齿轮比（关系方程）算出来的。相关变化率就是在算这个齿轮比。

## 3. 正式定义

设 $x(t)$ 与 $y(t)$ 是随时间变化的量，由关系方程 $F(x(t), y(t)) = 0$ 锁定。已知其中一个变化率，对方程两边关于 $t$ 求导，即可解出另一个——这就是**相关变化率**问题。

**四步流水线**：

| 步骤 | 动作 | 关键提醒 |
| --- | --- | --- |
| ① 建关系方程 | 找出 $x$ 与 $y$ 之间**不随时间变**的契约 | 梯子长、容器体积公式、相似比例都行 |
| ② 两边对 $t$ 求导 | 每个变量都经链式法则挂上自己的 $\frac{d\,\cdot}{dt}$ | 此刻**只求导、不代数**，变量都还"活着" |
| ③ 代入瞬时值 | 把此刻的 $x, y$ 与已知变化率一起代入 | 顺序绝不能反：先求导，后代入 |
| ④ 解出目标 | 移项解出未知的那只"指针" | 注意符号与单位：负号表示在变小 |

## 4. 分步例题

**例**（梯子问题）：梯长 5 米，$x^2+y^2=25$；底端外拉速度 $\frac{dx}{dt}=0.4$ 米/秒，问底距 $x=3$ 时顶端下滑速度。

1. 关系方程已经就位：$x^2+y^2=25$；
2. 两边对 $t$ 求导（每个变量各挂各的链环）：

$$2x\cdot\frac{dx}{dt}+2y\cdot\frac{dy}{dt}=0$$

3. 代入瞬时值 $x=3$、$y=4$（由勾股补出）、$\frac{dx}{dt}=0.4$：
4. 解出：$\frac{dy}{dt}=-\dfrac{x}{y}\cdot\dfrac{dx}{dt}=-\dfrac{3}{4}\times 0.4=-0.3$ 米/秒。

顶端正以每秒 0.3 米下滑，而且注意公式 $\frac{dy}{dt}=-\frac{x}{y}\cdot\frac{dx}{dt}$：随着 $x$ 变大、$y$ 变小，下滑速度会**越来越快**——底端匀速，顶端从来不匀速。另外请看一眼 $-\frac{x}{y}$：[隐函数求导](./37-implicit-differentiation.md)那一课圆的切线斜率原封不动地回来了——隐函数求导和相关变化率本来就是同一枚硬币的两面，只是问的问题不同。

### 实验 1（viz）：一条高度曲线，一条速度曲线

```viz
  "label": "墙高 y",
  "label2": "下滑速度 dy/dt",

  ]

```

怎么玩：横轴是底距 $x$。蓝线是墙高（越往右梯子越平、墙高越低）；橙线是下滑速度 $\frac{dy}{dt}=-v\frac{x}{y}$——拖动滑块 $v$ 改变外拉速度，橙线整体被拉伸，但**形状不变**：靠近 $x=5$ 处急剧俯冲，那正是梯子放平前顶端狂滑的时刻。两条曲线在同一个 $x$ 处的读数配合公式，就完整回答了"此刻多快"。

### 实验 2（python）：数值检验员来对账

公式说 $\frac{dy}{dt}=-0.3$。请一位数值检验员：让时间真的往前迈一小步，看看墙高实际掉了多少。

```python title="让时间真的走 0.001 秒：实测下滑速度对账公式"
import math

x0 = 3.0                     # 此刻底距
v = 0.4                      # 底端外拉速度（米/秒）
dt = 0.001                   # 时间步长：迈一小步
y0 = math.sqrt(25 - x0 ** 2)             # 此刻墙高（勾股）
x1 = x0 + v * dt                         # 0.001 秒后的底距
y1 = math.sqrt(25 - x1 ** 2)             # 0.001 秒后的墙高
numeric = (y1 - y0) / dt                 # 实测速度：高度差除以时间差
formula = -(x0 / y0) * v                 # 相关变化率流水线的公式答案
print(round(numeric, 4))
print(round(formula, 4))
```

两行都是 $-0.3$。数值检验员的办法笨（真的让梯子动起来再量），但它不服公式不行——**先求导、后代入**的流水线算出的，正是时间流逝的真实节奏。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为先代入 $x=3$ 再求导也一样。" 这是本课头号错法。一旦代入，$x$ 就从变量降格成常数 3，对 $t$ 求导直接得零，整条联动链条当场断裂。口诀：**活时求导，死后代入**（求导时变量必须还活着）。

**误区二**："你以为算出 $-0.3$ 是算错了。" $\frac{dy}{dt}=-0.3$ 的负号是信息不是错误：墙高在减少。读变化率永远连着单位一起读——$-0.3$ 米/秒，方向向下。

**误区三**："你以为已知量和未知量都写在题目里。" 梯子问题里 $y=4$ 题目没直接给，它靠关系方程（勾股）在**代入的那一刻**补出来。流水线第 ③ 步常常需要先回到方程把瞬时值补齐。

:::

## 7. 练习

**练习 1**：球形气球被以 $100\pi$ 立方厘米/秒的速度充气（体积 $V=\frac{4}{3}\pi r^3$）。问半径 $r=5$ 厘米的此刻，半径增长多快？下面的代码猜了个答案——用四步流水线推一遍，改到通过：

```exercise
# @title: 练习：气球半径此刻涨多快
# @check: 1.0
# @hint: 两边对 t 求导：dV/dt = 4πr²·dr/dt（球面积 4πr² 会在链环上现身）。分母是 4πr²，不是 4πr。
import math

r = 5.0                       # 此刻半径（厘米）
dv = 100 * math.pi            # 充气速度 dV/dt（立方厘米/秒）

rate = dv / (4 * math.pi * r)  # ← 猜的"半径速度"？分母少乘了一个 r
print(round(rate, 1))
```

正确流程：$\frac{dV}{dt}=4\pi r^2\cdot\frac{dr}{dt}$，所以 $\frac{dr}{dt}=\dfrac{100\pi}{4\pi\cdot 25}=1$ 厘米/秒。直觉答案 $0.8$ 的分母用的是 $4\pi r$——那是链环上挂错了零件：对 $r^3$ 求导落下来的是 $3r^2$，配上系数 $\frac{4}{3}\pi$ 后恰好是球的**表面积** $4\pi r^2$。越吹越费气，正是因为"每厘米半径"的面积账单在膨胀。

<details>
<summary>点开查看逐步解答</summary>

1. 关系方程：$V=\frac{4}{3}\pi r^3$；
2. 两边对 $t$ 求导：$\frac{dV}{dt}=4\pi r^2\cdot\frac{dr}{dt}$；
3. 代入 $r=5$、$\frac{dV}{dt}=100\pi$：$100\pi=4\pi\cdot 25\cdot\frac{dr}{dt}=100\pi\cdot\frac{dr}{dt}$；
4. 解出 $\frac{dr}{dt}=1$ 厘米/秒。

顺便回答一个隐问题：充气速度恒定，半径速度却不是——$\frac{dr}{dt}\propto\frac{1}{r^2}$，气球越大半径长得越慢。生活经验（一开始鼓得飞快、后来慢悠悠）和公式严丝合缝。
</details>

**练习 2**（思考）：梯子问题里，$\frac{dy}{dt}=-\frac{x}{y}\cdot\frac{dx}{dt}$ 在 $x\to 5$（梯子放平）时趋向什么？现实中会发生吗？

<details>
<summary>点开查看逐步解答</summary>

$x\to 5$ 时 $y\to 0$，公式 $\frac{dy}{dt}=-\frac{x}{y}\cdot\frac{dx}{dt}$ 的分母奔向零，下滑速度趋向无穷大——梯子放平的瞬间顶端"无限快"。现实不会：梯子顶端会离开墙面（不再满足约束 $x^2+y^2=25$），或者梯子还没滑到那里就已经滑出去了。和[隐函数求导](./37-implicit-differentiation.md)那一课"竖直切线处公式失语"完全同构：**模型假设失效的位置，正是公式爆炸的位置**。
</details>

## 8. 边界之外

- **多于两个量**：三个量互相牵制（比如锥形水箱的水深、水面半径、体积）照样走流水线：一个关系方程、两边对 $t$ 求导、谁多谁少各按各的链环。多元推广的完整账本（Jacobian 矩阵）在第 20 章开工。
- **变化率本身是主角**：当关系方程干脆写成"变化率满足的方程"（如 $\frac{dy}{dt}=-0.5y$），问题就升级成微分方程——第 22 章的正餐。相关变化率是它最朴素的预备形态：先当一次"齿轮比计算员"，再去当"方程求解员"。
- **物理与工程**：雷达测速（角度变化率换算距离变化率）、相机跟拍（俯仰角速度）、电路充放电，全是"一个已知 $\frac{d}{dt}$，推另一个 $\frac{d}{dt}$"。
