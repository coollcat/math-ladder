# 求导法则：告别硬算

## 1. 从一个场景开始

上一课你用定义硬算了 $x^2$ 的导数——摊开差商、展开、约分、取极限，四步走完一身汗。要是换成 $x^{100}$ 呢？展开 $(x+h)^{100}$ 大约要写一百多项，牛顿看了都想转行。

数学家的对策从来都是一样的：**把重复劳动变成规则**。这一课之后，绝大多数求导题都只是流水线作业。

## 2. 直觉解释

先玩个"找规律"：$y=x^3$ 在几个点的斜率是 $3, 12, 27, 48$——恰好等于 $3x^2$ 在这些点的值！多试几个幂函数都会发现同一个模式：

$$\text{指数掉下来当系数，自己减一： } x^n \;\to\; n \cdot x^{n-1}$$

这就是**幂规则**。其余规则更像"加工守则"：

- **和差规则**：各拆各的，互不打扰——导数是个"老实"的运算；
- **乘积法则**：两台机器联动，口诀"前导后不导 + 后导前不导"；
- **商法则**：除法稍麻烦，一句带过（见正式定义）。

## 3. 正式定义

设 $f$、$g$ 可导，$c$ 为常数：

| 规则 | 公式 |
| --- | --- |
| 常数规则 | $(c)' = 0$ |
| 幂规则 | $(x^n)' = n \cdot x^{n-1}$ |
| 常数倍 | $(c \cdot f)' = c \cdot f'$ |
| 和差规则 | $(f \pm g)' = f' \pm g'$ |
| 乘积法则 | $(fg)' = f'g + fg'$ |
| 商法则 | $\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$ |

一句话点评商法则："上导下不导，减去上不导下导，除以分母的平方"——用得不多，需要时回来查表即可。

## 4. 分步例题

**例 1**：求 $f(x)=x^3+2x$ 的导数。

1. 和差规则放行：$f' = (x^3)' + (2x)'$；
2. 幂规则处理 $x^3$：得 $3x^2$；
3. 常数倍 + 幂规则处理 $2x$：$2 \cdot (x)' = 2 \cdot 1 = 2$（$x$ 就是 $x^1$，降次成 $x^0=1$）；
4. 合并：$f'(x)=3x^2+2$。

**例 2**：用乘积法则求 $(x^2 \cdot \sin x)'$。

1. 前导后不导：$(x^2)' \cdot \sin x = 2x\sin x$；
2. 后导前不导：$x^2 \cdot (\sin x)' = x^2\cos x$（$\sin$ 的导数先借用结论，本章第 40 课给出生证明）；
3. 相加：$2x\sin x + x^2\cos x$。

### 实验 2（python）：亲手猜出幂规则

```python title="y=x³ 在四个点的斜率（先猜规律）"
def cube(x):
    return x ** 3

h = 0.00001                            # 极小的步长：够短的观察窗
for a in [1, 2, 3, 4]:                 # 挨个点量斜率
    left = cube(a - h)                 # 左邻点的函数值
    right = cube(a + h)                # 右邻点的函数值
    slope = (right - left) / (2 * h)   # 两点夹住 a，连线斜率贴着切线
    print(f"x={a}: 斜率 ≈ {round(slope, 4)}")
```

输出 `3, 12, 27, 48`——正是 $3x^2$ 在这四点的值。"指数下来当系数、自己减一"，规律是你自己抓到的，不是背来的。

### 实验 3（python）：造一台数值求导器，验收乘积法则

```python title="数值答案 vs 公式答案"
import math

def numeric_deriv(fn, x, h=0.00001):
    # fn 是一个函数——没错，函数本身也能当参数传进另一台机器（高阶用法）
    # h=0.00001 是默认值：调用时不给第三个参数，它自动取十万分之一
    return (fn(x + h) - fn(x - h)) / (2 * h)   # 中心差分：左右夹住 x 量斜率

def u(x):
    return x ** 2
def v(x):
    return math.sin(x)
def uv(x):
    return u(x) * v(x)

p = 1.0
by_rule = 2 * p * math.sin(p) + p ** 2 * math.cos(p)   # 乘积法则公式
by_machine = numeric_deriv(uv, p)                      # 数值求导器独立测同一处
print(round(by_machine, 4))
print(round(by_rule, 4))
```

两行都打印 `2.2232`——公式算的和机器量的严丝合缝。这台 `numeric_deriv` 是本站的万用测斜仪，后面几课反复出场。

### 快问快答

```quiz
(uv)' 等于什么？
- u' · v'
- u'v + uv' [*]
- uv'
? 口诀"前导后不导 + 后导前不导"。u'v' 是全微积分最著名的错误——拿 u=x²、v=x 一验就穿帮。
```

:::warning[常见误区]

**误区一**："你以为乘积的导数等于导数的乘积。" 反例当场戳穿：$x^2 \cdot x = x^3$，导数是 $3x^2$；若按 $u'v'$ 算只得 $2x \cdot 1 = 2x$。正确答案是 $2x \cdot x + x^2 \cdot 1 = 3x^2$——乘积法则是**交叉**求导再相加。

**误区二**："你以为 $(x^n)' = n \cdot x^n$。" 指数要**降次**：$(x^3)' = 3x^2$，不是 $3x^3$。口诀后半句"自己减一"不能省。

**误区三**："你以为常数可以顺手扔掉。" $(5x^2)' = 5 \cdot 2x = 10x$——常数倍规则保证系数原样保留，扔掉它答案直接缩水五倍。

:::

**练习 2**：有人说"(uv)' 显然就该是 u'v'，多自然！"请用一个具体反例说服他。

<details>
<summary>点开查看逐步解答</summary>

取 $u=x^2$、$v=x$，则 $uv=x^3$，真正的导数是 $3x^2$。

- 按"$u'v'$"算：$2x \cdot 1 = 2x$ —— 错，差了一大截；
- 按乘积法则算：$u'v + uv' = 2x \cdot x + x^2 \cdot 1 = 3x^2$ —— 对上了。

一个反例足以否决一个"显然"。这也是本站一贯的工作流：猜想 → 数值抽查 → （选读）证明。
</details>

<details>
<summary>选读 · 乘积法则为什么长这样：一块矩形的故事</summary>

把 $uv$ 想成边长为 $u$、$v$ 的矩形面积。让 $x$ 增加一小格 $\Delta x$：横边伸长 $u'\Delta x$，竖边伸长 $v'\Delta x$，新增的面积有三块——右侧竖条 $u'v\,\Delta x$、顶部横条 $uv'\Delta x$，以及角落那个小方块 $u'v'\Delta x^2$。

两边同除 $\Delta x$ 再让 $\Delta x \to 0$：两条主条留下 $u'v + uv'$，而小方块带着 $\Delta x$ 因子被极限挤没了。乘积法则就是"矩形扩容"的账本——那块被挤掉的角落，正是 $u'v'$ 这个错误答案的全部来源。
</details>
