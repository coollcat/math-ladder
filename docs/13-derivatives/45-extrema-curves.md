# 极值、凹凸与曲线描绘

## 1. 从一个场景开始

一条山路蜿蜒起伏。你是勘路员，只拿到一张海拔-距离的算式 $f(x) = x^3 - 3x$（卷面越朴素越好），却要立刻回答三件事：**峰顶在哪？谷底在哪？整条路长什么轮廓？**

在全站的历史上，"找最值"一直靠撒网：代一批点进去比大小——能碰运气，却永远不知道是不是漏了更高峰、更深谷。导数学到现在，它终于要接下人生第一份正职工作：**不用撒网，用一支笔就把峰谷钉死**。优化理论的大门（第 43 章）也从这里推开第一条缝。

## 2. 直觉解释

想象你正沿着函数曲线徒步，从左往右走：

- 海拔一直在涨（$\frac{dy}{dx}>0$）：上坡；
- 海拔一直在跌（$\frac{dy}{dx}<0$)：下坡；
- **峰顶那一刻**：既不涨也不跌，坡度恰好归零——然后由涨转跌；
- **谷底那一刻**：同样坡度归零——但由跌转涨。

所以峰谷的藏身之处，就是**导数变号的地方**；而变号必须先经过 $f'=0$ 这道关卡。"坡度为零"是峰谷的必要登记手续，却不是身份证明——$y=x^3$ 在原点坡度也是零，可那里既非峰也非谷，只是个歇脚的平坡。

至于**凹凸**，那是二阶导数的辖区：曲线上弯成**碗状**（开口向上）时，坡度本身越走越大，$f''>0$；弯成**伞状**（开口向下）时，坡度越走越小，$f''<0$。碗底盛着极小值，伞顶撑着极大值。凹凸两态的换岗位置，叫**拐点**。

## 3. 正式定义

设 $f$ 在点 $c$ 附近有定义。

| 名称 | 定义 | 一句话记忆 |
| --- | --- | --- |
| 临界点 | $f'(c)=0$ **或** $f'(c)$ 不存在的点 | 峰谷的全部嫌疑名单 |
| 驻点 | $f'(c)=0$ 的点 | 坡度归零处，嫌疑最大但不定罪 |
| 极大值点 | 存在邻域，$f(c)$ 不小于左右邻近值 | 山头（局部冠军） |
| 极小值点 | 存在邻域，$f(c)$ 不大于左右邻近值 | 谷坑（局部垫底） |
| 凹凸性 | $f''>0$ 下凸（碗）；$f''<0$ 上凸（伞） | 二阶导管弯曲方向 |
| 拐点 | 凹凸性发生切换的点 | 碗与伞交接的把手 |

**一阶判别法**：$f'$ 在 $c$ 左侧为正、右侧为负 ⇒ 极大；左负右正 ⇒ 极小；同号 ⇒ 既非峰也非谷。

**二阶判别法**：若 $f'(c)=0$ 且 $f''(c)>0$ ⇒ 极小值点；$f''(c)<0$ ⇒ 极大值点。（相当于看脚下是碗还是伞。）

## 4. 分步例题

给 $f(x)=x^3-3x$ 做一次全套体检：

1. **求一阶导数并找驻点**：$f'(x)=3x^2-3=0$，解得 $x=\pm 1$ ——嫌疑名单只有两人；
2. **列一阶导数符号表**：
   | 区间 | $x<-1$ | $(-1,1)$ | $x>1$ |
   | --- | --- | --- | --- |
   | $f'(x)=3(x^2-1)$ | $+$ | $-$ | $+$ |
3. **判定身份**：在 $x=-1$ 处左正右负，先涨后跌 ⇒ **极大值点**，$f(-1)=2$；在 $x=1$ 处左负右正，先跌后涨 ⇒ **极小值点**，$f(1)=-2$；
4. **二阶导复核**：$f''(x)=6x$；$f''(-1)=-6<0$（伞顶 ✓）、$f''(1)=6>0$（碗底 ✓），两个判别法异口同声；
5. **凹凸与拐点**：$f''>0$ 当 $x>0$（右半段碗），$f''<0$ 当 $x<0$（左半段伞）；在 $x=0$ 处凹凸换岗且 $f(0)=0$ ⇒ 拐点是原点。

一句话描绘全貌："伞形爬到 $( -1, 2 )$ 的山头，翻过拐点，再沿碗底滑进 $(1,-2)$ 的谷坑后向上冲。"注意我们**没有代多少个点比大小**——两条符号表就交出了全部结构。

怎么玩：盯住橙色虚线（$f'$）穿越横轴的两个位置 $x=\pm1$——同一个竖直线向上望，蓝色实线恰好在左边登顶、右边触底。再观察蓝线中段平缓下滑的区域，对应橙色线沉在横轴下方（负号区）。**峰谷不是看出来的，是导数变号"判"出来的。**

### 实验 2（python）：二阶差分——不借公式，徒手摸出弯向

```python title="拖动 a 扫过整条曲线，差分符号就是凹凸晴雨表"
# sliders: a=-1 [-2.4:2.4:0.1]
def f(x):
    return x ** 3 - 3 * x          # 本课主角：左峰右谷的山路

def df2(x):
    return 6 * x                   # 解析的二阶导数：理论参照答案

h = 0.001                          # 差分步长：足够小才能代表"一瞬间"
second_diff = (f(a + h) - 2 * f(a) + f(a - h)) / (h * h)   # 二阶中心差分：坡度的坡度
if second_diff > 0.05:             # 差分明显为正：像一只碗
    shape = "碗状（下凸）"
else:
    shape = "伞状（上凸）"
print(f"a={round(a, 2)}: 差分 {round(second_diff, 3)} vs 解析 {round(df2(a), 3)}")
print(shape)
```

怎么玩，两条巡逻线：

1. **拖 $a$ 从负往正扫**：差分值与解析值始终相等（$6a$），形状报告随之从"伞状"翻转为"碗状"——翻转发生的瞬间就在 $a=0$ 附近，那里的差分几乎为零：**拐点的邻域，凹凸正在换岗**；
2. 公式 $(f(a+h)-2f(a)+f(a-h))/h^2$ 叫**二阶中心差分**，它是"把坡度的变化率交给计算机"的体力版——完全不知道 $f''=6x$ 也照样测出同样的数字。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为坡度为零就是峰或谷。" $y=x^3$ 在 $x=0$ 处 $f'=0$，却是单调上升路上的一个平坡——既非极大也非极小。定罪要靠符号表：$f'$ 必须真的**变号**才算数。

**误区二**："你以为嫌疑名单里只有 $f'=0$ 的点。" 绝对值函数 $f(x)=|x|$ 在 $x=0$ 处导数不存在（左右坡度一个是 $+1$ 一个是 $-1$，谁也不等于零），那里却分明是个尖尖的谷底。临界点包括"导数为零"和"导数不存在"两类。

**误区三**："你以为 $f''(c)=0$ 就一定是拐点。" $y=x^4$ 在 $x=0$ 处 $f''=0$，但它全程都是碗状，凹凸根本没换岗——只是个普通的碗底。判拐点的铁证仍是 $f''$ 的**变号**（或一阶导数由增转减/由减转增），"等于零"只是候选人资格。

:::

## 7. 练习

**练习 1**：还是这条山路 $f(x)=x^3-3x$，现在给两个驻点做正式体检。下面的体检员偷懒了——只要导数为零就一律盖"极小值"章，结果把左边的山峰也盖错了。改成真正查两侧符号的体检逻辑，改到通过：

```exercise
# @title: 练习：别急着给驻点盖章
# @check: -1
# @check: 1
# @hint: 体检员该向左右各探一小步 eps 读坡度符号：左正右负（先涨后跌）是山顶报 -1，左负右正（先跌后涨）是谷底报 1；只查 df(p)==0 两侧同号也照样放行了平坡
# 输出约定：-1 表示极大值点，1 表示极小值点，0 表示都不是
def f(x):
    return x ** 3 - 3 * x

def df(x):
    return 3 * x ** 2 - 3

eps = 0.0001        # 向左右各探头一步的距离，用来偷看邻域内的坡度方向

def kind(p):        # 体检员：p 是疑似驻点
    if df(p) == 0:
        return 1    # ← 只要坡度是零就宣布"极小值"？两边签名还没验呢！
    return 0

print(kind(-1))     # 应该输出 -1（这其实是山顶）
print(kind(1))      # 应该输出 1（真正的谷底）
```

心算复核：$f'$ 在 $x=-1$ 左侧为正右侧为负（先涨后跌）⇒ 极大 ⇒ 报 $-1$；在 $x=1$ 左负右正 ⇒ 极小 ⇒ 报 $1$。

<details>
<summary>点开查看逐步解答</summary>

体检的正确流程是站在 $p$ 上，向左右各探一小步 $eps$，读出坡度符号：

```python
def f(x):
    return x ** 3 - 3 * x

def df(x):
    return 3 * x ** 2 - 3

eps = 0.0001                      # 探头距离

def kind(p):                      # 体检员：验两边的"签名"
    left = df(p - eps)            # p 左边一点点处的坡度
    right = df(p + eps)           # p 右边一点点处的坡度
    if df(p) == 0 and left > 0 and right < 0:     # 先涨后跌 → 山头
        return -1
    if df(p) == 0 and left < 0 and right > 0:     # 先跌后涨 → 谷坑
        return 1
    return 0                       # 不变号：歇脚平坡，无罪释放

print(kind(-1))                    # -1
print(kind(1))                     # 1
```

这正是实验 2 思想的判题化版本：不再硬背公式，而是让导数的符号自己招供。练习里的老体检员漏掉的"left / right 两问"，恰恰是一阶判别法的全部内容。
</details>

**练习 2**（思考）：把体检对象换成 $g(x)=x^4$，驻点只有一个 $x=0$。符号表会给出什么判决？为什么它在"典型教材图"里常被误认成拐点？

<details>
<summary>点开查看逐步解答</summary>

$g'(x)=4x^3$：左侧为负、右侧为正 ⇒ 左负右正，标准的"先跌后涨"⇒ $x=0$ 是极小值点。它的 $g''(x)=12x^2$ 在 $0$ 处确实为零，容易让人误报"拐点"，但 $g''\ge 0$ 恒成立——曲线从未换过弯向（一直是碗），零只是候选资格，不是换岗证明。这也是误区三的活标本：单看某一点的公式值没有意义，要看它**两侧是否易帜**。
</details>

## 8. 边界之外

本课的工具收工前，交代清楚它不管的三件事：

- **局部 ≠ 全局**。极值是"附近一小段的冠军"，全局最值还须把所有极值候选与**区间端点**放在一起比较（闭区间上连续函数必有最值；开区间可能压根没有，比如 $y=x$ 在 $(0,1)$ 内无最大）。锯齿状的病态函数（处处不可导）更是一阶工具的盲区。
- **带约束的最值**。"容积定死求最省料"这类问题（见本章实战挑战）要把约束消元或交给第 43 章拉格朗日乘数法，单纯 $f'=0$ 不够。
- **多元函数**。两个以上变量的峰谷要用偏导数与 Hessian 矩阵（第 20 章），本课的一元符号表是它的热身操。
