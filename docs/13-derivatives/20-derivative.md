# 导数：瞬时变化率

## 1. 从一个场景开始

高速路上，时速表稳稳指着 72。可这一小时你并没有跑 72 公里，刚才这一秒也没跑 72 千米——"此刻的速度"到底是什么意思？按定义速度 = 路程 ÷ 时间，而"瞬间"里路程和时间双双归零：**又是那个 0/0**。

伽利略和牛顿都卡在这里，直到极限登场。这一课，我们给"瞬间"一个严格的定义。

## 2. 直觉解释

先退一步算能算的：把一段过程打包，**平均变化率 = 变化量 ÷ 时间差**。画在图上，就是曲线上两点连线的斜率（割线）。

现在把时间窗一步步缩小：两点不断靠近、再靠近……上一课说过，逼近有目的地——割线斜率的目的地，就叫**瞬时变化率**；那条贴身直线，就是曲线在该点的**切线**。

一句话：**导数 = 割线斜率在两点无限贴近时的极限。**

## 3. 正式定义

函数 $f$ 在 $x$ 处的**导数**：

$$f'(x) = \lim_{h \to 0}\frac{f(x+h)-f(x)}{h}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $h$ | 步长 | 一小段时间窗的宽度 |
| $f(x+h)-f(x)$ | $\Delta y$ | 函数值的变化量 |
| $\dfrac{f(x+h)-f(x)}{h}$ | 平均变化率 | 割线斜率 |
| $f'(x)$ | 导数（读"f 一撇"）| 瞬时变化率，切线斜率 |

另一种流行写法是莱布尼茨记号 $\dfrac{dy}{dx}$——它直接由 $\frac{\Delta y}{\Delta x}$ 把 Δ 换成 d 而来，那张"分数脸"时刻提醒你它的出身：**比值生出来的极限**。两种写法完全等价：$\dfrac{dy}{dx} = f'(x)$。

## 4. 分步例题

**例 1**：从定义推出 $f(x)=x^2$ 的导数。

1. 写出差商：$\dfrac{(x+h)^2 - x^2}{h}$；
2. 展开分子（第 4 章的功夫）：$x^2 + 2xh + h^2 - x^2 = h(2x+h)$；
3. 约掉 $h$（$h \neq 0$ 时合法）：得 $2x + h$；
4. 让 $h \to 0$：目的地是 $2x$。

$$\frac{d}{dx}\,x^2 = 2x$$

注意结果 $2x$ 里还带着 $x$——**每个点的斜率各不相同**：$x=1$ 处斜率 2，$x=3$ 处斜率 6，抛物线确实越往右越陡。

**例 2（物理版）**：小球下落，位移 $s(t)=t^2$（米）。$t=2$ 秒时的瞬时速度 $= s'(2) = 2 \times 2 = 4$ 米/秒；到 $t=3$ 秒变成 6 米/秒——越落越快，数字自己会讲故事。

## 5. 动手实验

### 实验 1（viz）：狂按 h÷2，亲眼看收敛

```viz
{
  "type": "derivative",
  "expr": "x^2",
  "a": 1,
  "xmin": -3.5,
  "xmax": 3.5
}
```

怎么玩：蓝色圆点沿曲线拖动（默认停在 $a=1$）；连按几次「h÷2」，盯着顶部数字——橙色**割线斜率** `3.5 → 3 → 2.5 → 2.2 → 2.1 → 2.05 → 2.01 → …` 一路俯冲向绿色**切线斜率** `2`，差值一路缩水。这就是"极限"两个字的可视化：割线永远到不了切线，但想多近有多近。

### 实验 2（python）：时间窗缩小，平均速度现出真身

```python title="s(t)=t² 在 t=2 秒附近的速度"
def position(t):          # 位移函数：t 秒走了 t² 米
    return t ** 2

for h in [1, 0.1, 0.01]:  # 时间窗 h 越缩越小
    avg = (position(2 + h) - position(2)) / h   # 平均速度 = 位移差 ÷ 时间差
    print(f"h={h}: 平均速度 {round(avg, 4)}")
```

怎么玩：`5.0 → 4.1 → 4.01 → …` 时间窗越小，平均速度越贴向 4——正是例 2 算出的 $s'(2)=4$。数值表格与代数推导在此会师。

### 快问快答

```quiz
f'(x) 到底是一个数还是一个函数？
- 一个固定的数，算一次就完事
- 一个新函数：每代入一个点，就得到该点的斜率 [*]
- 是曲线的最高点
? (x²)' = 2x 本身就是一条新曲线。说 f'(a) 才是指某个具体点的斜率（一个数）。
```

:::warning[常见误区]

**误区一**："你以为导数就是一个数。" $f'(x)$ 首先是**函数**——一台"斜率查询机"，喂进位置吐出斜率。只有写成 $f'(a)$ 代入具体的点，它才落地成一个数。

**误区二**："你以为 h→0 就是取 h=0。" 若硬取 $h=0$，分子分母同时归零，式子当场报废。导数是 $h$ **缩小过程的归宿**，恰恰要求 $h$ 全程不等于 0——上一课的原则在这里二次生效。

**误区三**："你以为所有光滑好看的曲线处处可导。" 折线 $y=|x|$ 在原点有个尖角：左边斜率恒为 −1，右边恒为 +1，左右对不上，导数不存在。**尖角处没有切线**，可导的前提是够光滑。

:::

## 6. 练习

**练习 1**：用"平均变化率"逼近 $g(x)=x^3$ 在 $x=2$ 处的导数。下面的代码能跑但除错了对象，改到通过：

```exercise
# @title: 练习：立方曲线在 x=2 的斜率
# @check: 12.0
# @hint: 平均变化率 = 函数值之差 ÷ 步长 h——现在代码里除的是 a，想想 Δy/Δx 的分母该是谁
def cube(x):
    return x ** 3

a = 2
h = 0.0001
slope = (cube(a + h) - cube(a)) / a
print(round(slope, 1))
```

改对之后不妨把 `a` 改成 1 或 3 再跑：答案分别贴向 3 和 27——正好等于 $3a^2$，下一课的幂规则已经在向你招手。

**练习 2**：$y=|x|$ 在 $x=0$ 处到底可不可导？

<details>
<summary>点开查看逐步解答</summary>

不可导。取 $h>0$ 算右侧差商：$\frac{|h|-0}{h}=+1$；取 $h<0$ 算左侧：$\frac{|h|}{h}=-1$。两侧的目的地一个是 +1 一个是 −1，凑不到同一个值——极限不存在，导数也就不存在。

几何直观：原点是尖角，任何过它的直线都会戳破曲线，"切线"立不起来。你可以回到实验 1，把表达式换成 abs(x)（组件支持），把蓝点拖到 0 附近亲眼验证。
</details>

<details>
<summary>选读 · 切线难题的两千年</summary>

古希腊人只会给**圆**定切线："垂直于半径的直线"，因为圆足够对称。可对抛物线、悬链线这类一般曲线，"切线是什么"吵了两千年——总不能靠"看起来相切"吧？

突破口出现在 17 世纪：费马与笛卡尔各自尝试用代数逼近，最终牛顿把它彻底讲清——**切线不是"碰一下的直线"，而是割线在两点重合过程中的极限位置**。这个定义的妙处在于把几何问题翻译成了极限问题，从此任何光滑曲线都有了唯一的切线；而"求切线"这件事，也升级成了一门通用机器：求导。
</details>
