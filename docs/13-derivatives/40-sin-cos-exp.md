# sin、cos 与 e^x 的导数：三大明星

## 1. 从一个场景开始

多项式的导数是"降次游戏"，可函数王国的三位贵族不吃这一套。它们仨的导数一个比一个离奇：$\sin x$ 求导后还是一条标准波；$e^x$ 更夸张——**求导之后纹丝不动，还是它自己**。

"自己复制自己"听着像段子，实则是全数学最重要的性质之一：连续复利、人口增长、神经网络，凡是"增长速度正比于当前总量"的地方，幕后主角都是它。

## 2. 直觉解释

把 $\sin x$ 的曲线想象成山路，在每个位置量一次坡度，再把坡度画成新曲线——你会得到一条形状眼熟的波：**正是 $\cos x$**。反过来对 $\cos x$ 做同样的事，得到倒扣的 $-\sin x$。波求导还是波，只是挪了相位——第 7 章的单位圆转圈，在这里悄悄兑现。

$e^x$ 则是另一路奇观：曲线上每一点的斜率恰好等于该点的高度。山脚处平缓（值小），山顶处陡峭（值大）——**长得越高，长得越快**，这就是"自我复制"的几何面目。

## 3. 正式定义

$$\frac{d}{dx}\sin x = \cos x, \qquad \frac{d}{dx}\cos x = -\sin x, \qquad \frac{d}{dx}e^x = e^x$$

| 函数 | 导数 | 一句话画像 |
| --- | --- | --- |
| $\sin x$ | $\cos x$ | 波的坡度是提前四分之一圈的波 |
| $\cos x$ | $-\sin x$ | 下坡时坡度取负 |
| $e^x$ | $e^x$ | 斜率 = 高度，自我复制 |

**前提声明**：这三条公式全部默认 $x$ 用**弧度**。若用角度制，$\sin$ 的导数会多出一个别扭因子 $(\sin x°)' = \frac{\pi}{180}\cos(x°)$——第 7 章弧度制课埋的伏笔，在此正式兑现：弧度制不是审美洁癖，它是让公式保持出厂简洁的原生单位。

## 4. 分步例题

**例 1**：求曲线 $y=\sin x$ 在 $x=\dfrac{\pi}{3}$ 处的切线斜率。

1. 明星导数第一条：$y'=\cos x$；
2. 代入：$\cos\dfrac{\pi}{3}=\dfrac{1}{2}$；
3. 结论：该点切线斜率恰为 $0.5$。

**例 2**：求 $y=x^2+e^x$ 的导数，并算它在 $x=1$ 处的值。

1. 和规则放行：$y'=(x^2)'+(e^x)'$；
2. 幂规则处理第一项：$2x$；
3. 第二项照抄：$e^x$；
4. 合并并代入：$y'=2x+e^x$，在 $x=1$ 处为 $2+2.718\approx 4.718$。

### 实验 2（python）：三条公式逐一数值验收

```python title="数值答案 vs 公式答案"
import math

def nd(fn, x, h=0.00001):   # 数值求导器（上一课的机器换个短名）
    return (fn(x + h) - fn(x - h)) / (2 * h)

print(f"sin 在 0.5: 数值 {round(nd(math.sin, 0.5), 4)} / 公式 {round(math.cos(0.5), 4)}")
print(f"cos 在 0.5: 数值 {round(nd(math.cos, 0.5), 4)} / 公式 {round(-math.sin(0.5), 4)}")
print(f"exp 在 1.0: 数值 {round(nd(math.exp, 1.0), 4)} / 公式 {round(math.exp(1.0), 4)}")
```

三行各自打印出两个相同的数：`0.8776`、`-0.4794`、`2.7183`——机器独立测出的斜率与公式给出的完全一致，三大明星导数验收合格。

### 快问快答

```quiz
e^x 的导数是什么？
- 还是 e^x [*]
- e^(x+1)
- x·e^(x-1)
? 幂规则管的是"底为变量"的 xⁿ；e^x 是"变量在指数"。它的每一点斜率恰等于自身高度——求导等于照镜子。
```

:::warning[常见误区]

**误区一**："你以为 $\sin$ 的导数是 $-\cos$。" 是 $\cos$！负号属于下一行：$(\cos x)'=-\sin x$。这两条只差一个符号，记串一处全盘皆输——实验 2 第一行的数值就是公证人。

**误区二**："你以为角度制下公式照样成立。" 度制的 $\sin$ 求导会背上 $\frac{\pi}{180}$ 的补丁。所有干净的微积分公式都以弧度为默认语言——这是第 7 章就预告过的"原生坐标系"。

**误区三**："你以为 $e^x$ 也该按幂规则降次。" $(x^n)'=nx^{n-1}$ 处理的是**指数固定、底是变量**；$e^x$ 是**底固定、变量在指数**，两个世界。后者求导不降次、不变样——它就是它自己。

:::

**练习 2**：为什么"$\dfrac{d}{dx}\sin x=\cos x$"必须在弧度制下才成立？

<details>
<summary>点开查看逐步解答</summary>

关键在差商里的小角近似：只有当 $h$ 以弧度计，才有 $\sin h \approx h$（第 7 章练习 3 的伏笔）。把它代进和角公式展开的差商：

$$\frac{\sin(x+h)-\sin x}{h}=\cos x \cdot \frac{\sin h}{h}-\sin x \cdot \frac{1-\cos h}{h}$$

$h\to 0$ 时两个括号分别奔向 $1$ 和 $0$，于是极限干净地等于 $\cos x$。若改用角度制，$\sin h^\circ\approx\frac{\pi}{180}h$，第一个括号的目的地变成 $\frac{\pi}{180}$——整条公式从此背着补丁过日子。
</details>

<details>
<summary>选读 · 为什么偏偏是 e 自己复制自己</summary>

其实任何指数函数都"近似复制自己"：$(a^x)' = a^x \cdot \ln a$——求导后还是自己，只是背了个系数 $\ln a$。系数恰为 1 的幸运儿只有一个：$\ln a = 1$ 即 $a=e$。

这不是巧合，而是 $e$ 的出身决定的。第 12 章见过连续复利：本金翻滚得越勤，年终收益越贴近 $e$ 倍——$e$ 本来就是"增长率与当前总量严格成正比"这件事的化身。所以"导数是自己"不是 $e$ 碰巧具备的性质，而是 $e$ 的**定义**在求导运算下的回声：唯一以自身增长率为刻度的底数。
</details>
