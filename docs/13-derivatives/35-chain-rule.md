# 链式法则：剥洋葱

## 1. 从一个场景开始

把车速从"千米每小时"换成"米每秒"，你其实做了两步换算：先乘 1000（千米变米），再除 3600（时变秒）。总换算率 $=1000 \times \frac{1}{3600}$——**两步的倍率相乘**。

这个小学就会的动作，藏着全微积分威力最大的定理：当变化穿过两层机器时，变化率要**沿途相乘**。它叫链式法则。

## 2. 直觉解释

第 6 章说过，复合函数是两台机器串成的流水线：$f(g(x))$ 先过内层 $g$，再过外层 $f$。现在问：输入 $x$ 动一点点，最终输出动多少？

- 内层机器放大 $g'(x)$ 倍：$x$ 的扰动变成 $u=g(x)$ 处的扰动；
- 外层机器接着放大 $f'(u)$ 倍。

两级齿轮串联，总传动比是两级之比相乘：

$$\big(f(g(x))\big)' = f'\big(g(x)\big) \cdot g'(x)$$

像剥洋葱：**外层先求导（里头照抄），再乘内层的导数**。一层一层剥，剥几层乘几个因子。

## 3. 正式定义

若 $u = g(x)$ 可导，且 $f(u)$ 在 $g(x)$ 处可导，则复合函数 $f(g(x))$ 的导数为：

$$\frac{d}{dx} f\big(g(x)\big) = f'\big(g(x)\big) \cdot g'(x)$$

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $g(x)$ | 内层 | 流水线第一台机器 |
| $f$ | 外层 | 第二台机器，吃的是中间结果 |
| $f'(g(x))$ | 外层导 | 对外层求导，**里面的 $g(x)$ 原样照抄** |
| $g'(x)$ | 内层导 | 第一台机器自己的放大率 |

莱布尼茨记号下它长得像个分数约分：$\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}$——好记（选读里说清它为什么"看着像、也真是"）。

## 4. 分步例题

求 $y=(x^2+1)^{10}$ 的导数。

1. **认出洋葱**：外层是"十次方机器"$u^{10}$，内层是 $u=x^2+1$；
2. **外层求导**（幂规则，内部照抄）：$10 \cdot u^9 = 10(x^2+1)^9$；
3. **乘内层导数**：$(x^2+1)' = 2x$；
4. **合并**：

$$y' = 10(x^2+1)^9 \cdot 2x = 20x(x^2+1)^9$$

要是按老办法展开 $(x^2+1)^{10}$ 再逐项求导，得写十一项二项式——链式法则四行收工。**能剥就不展开。**

单位换算回望：$\text{米/秒} = \text{千米/时} \times \underbrace{1000}_{\text{内层}} \times \underbrace{\tfrac{1}{3600}}_{\text{外层}}$——中间单位"米/时"就是那个中间变量 $u$。

## 5. 动手实验

### 实验 1（lab）：扰动穿过两级机器，两级倍率各自露脸

```lab
{
  "type": "chain-rule-pipeline",
  "mode": "chain",
  "title": "两级机器串联：扰动 Δx 依次被 g′ 和 f′ 放大",
  "x": 0.6, "dx": 0.8
}
```

怎么玩：上半屏是三张数值卡（$x \to u \to y$）夹着两台机器；机器格里的橙色割线量的是**实际步长比** $\Delta u/\Delta x$、$\Delta y/\Delta u$，红色虚线是**切线预测** $g'(x)$、$f'(u)$。下半屏把两笔账摆在一起对：默认 $x = 0.6$、$\Delta x = 0.8$ 时扰动太大，第二棒实测约 $27.6$ 而切线预测只有 $14.5$，两杆秤明显对不上——这正是"拿割线冒充切线"的代价。现在按「$\Delta x \div 2$」连按几下，或直接按「播放」让 $\Delta x$ 一路缩向 $0$：两条账每一轮靠近一点，最后在读数精度内合拢，$\Delta y/\Delta x$ 稳稳落在 $g'(x) \cdot f'(u)$ 上——「沿途相乘」不是口诀，是这一个极限过程。切到 $(x^2+1)^3$ 再玩一遍：内层导从常数 $2$ 变成 $2x$，把 $x$ 拖到负半轴，两根杆子会一起翻向左边（放大倍率为负 = 方向翻转），总倍率自动带着正确的符号。

### 实验 2（python）：数值验证"沿途相乘"

```python title="剥洋葱前后对照"
def f(x):                 # 复合函数：(2x+1)³
    return (2 * x + 1) ** 3

def df_chain(x):          # 链式法则：外层导 3(2x+1)² × 内层导 2
    return 3 * (2 * x + 1) ** 2 * 2

h = 0.00001               # 极小步长，用于数值估算斜率
p = 1.0                   # 考察点
numeric = (f(p + h) - f(p - h)) / (2 * h)   # 左右两点夹住 p 测斜率
print(f"x={p}: 数值 {round(numeric, 4)} / 链式法则 {round(df_chain(p), 4)}")
```

两个数字都是 `54.0`。做个破坏性对照：把 `df_chain` 里末尾的 `* 2` 删掉再跑——只剩 `27.0`，数值答案立刻翻脸。那一个 `× 2` 就是内层 $2x+1$ 的导数，丢了它，链式法则就断了链。

### 实验 3（python）：双滑块巡逻，换点换步长处处对账

```python title="拖 x 换考察点、拖 h 缩时间窗，链式法则随时待命"
# sliders: x=1 [0:2:0.25], h=0.01 [0.0001:1:0.0001]
def f(t):                     # 复合函数：(2t+1)³；参数叫 t，免得和滑块的 x 打架
    return (2 * t + 1) ** 3

def df_chain(t):              # 链式法则：外层导 × 内层导
    return 3 * (2 * t + 1) ** 2 * 2

numeric = (f(x + h) - f(x - h)) / (2 * h)   # 步长 h 的割线斜率，逼近 x 处的切线斜率
outer = 3 * (2 * x + 1) ** 2                # 外层导：u³ 的导数，里头照抄
inner = 2                                   # 内层导：2x+1 的导数是常数 2
print(f"x={x}, h={h}: 数值 {round(numeric, 4)} vs 链式 {round(df_chain(x), 4)}")
print(f"拆开对账：外层 {round(outer, 4)} × 内层 {inner} = {round(outer * inner, 4)}")
```

怎么玩，两条巡逻线：

1. **拖 $x$**（$h$ 保持很小）：不管停在 0、0.75 还是 2，第一行的两个数几乎重合（数值栏只在小数点后第四位多一丝零头）——链式法则不是只对一个点灵，处处可对账；
2. **拖 $h$**（$x$ 固定）：把 $h$ 从 0.01 一路拉大到 1，数值一栏的偏离逐步放大——时间窗太大，割线就冒充不了切线；再缩回小值，偏差重新消失。**"沿途相乘"是极限意义的等式，h 越小越是铁板钉钉。**

第二行还把答案拆成"外层 × 内层"两截——哪一步贡献了多少倍率，一目了然。

### 快问快答

```quiz
求 ((x²+1)^10)' 时最容易漏掉哪一步？
- 外层用幂规则降次：10(...)⁹
- 乘上内层的导数 2x [*]
- 把 10 次方先展开再求导
? 剥完外层洋葱必须乘内层导数——"忘乘内层"是全微积分出错率第一名。
```

:::warning[常见误区]

**误区一**："你以为剥完外层就完事了。" $(2x+1)^3$ 的导数不是 $3(2x+1)^2$——还差内层导数 $\times 2$。实验 2 已经让你亲眼见过这个错误的下场。

**误区二**："你以为外层导就是把 $g(x)$ 换成 $x$ 再求。" 正确形式是 $f'(g(x))$：对 $u^{10}$ 求导后，$u$ 要**原样放回** $x^2+1$。写成 $f'(x)\cdot g'(x)$ 是张冠李戴。

**误区三**："你以为复合就得硬展开。" $(x^2+1)^{10}$ 展开是十一项的二项式灾难。链式法则的存在意义就是让你**永远不必展开**——识别内外，两步收工。

:::

## 6. 练习

**练习 1**：求 $f(x)=(2x+1)^3$ 在 $x=1$ 处的导数。下面的代码剥了外层忘了内层，改到通过：

```exercise
# @title: 练习：补上断掉的链条
# @check: 54.0
# @hint: 外层 u³ 的导数是 3u²，这步代码做对了；但内层 2x+1 的导数是谁？把它乘上去
# 复合函数求导：外层与内层的导数都要算进去
def df(x):
    return 3 * (2 * x + 1) ** 2

# round(x, 1) 保留一位小数
print(round(df(1.0), 1))
```

心算复核：$f'(x)=3(2x+1)^2 \cdot 2$，代入 $x=1$：$3 \times 9 \times 2 = 54$。

**练习 2**：为什么"千米/时 → 米/秒"的两步换算是链式法则？中间量是什么？

<details>
<summary>点开查看逐步解答</summary>

设 $v$ 千米/时。第一步乘 1000 变成"米/时"，第二步乘 $\frac{1}{3600}$ 变成"米/秒"。总倍率 $= 1000 \times \frac{1}{3600} \approx 0.278$，与一步到位的结果完全一致。

对应关系：内层机器是"千米 → 米"，外层机器是"时 → 秒"；中间量"米/时"就是中间变量 $u$。链式法则说的"变化率沿途相乘"，在单位换算里你已经用了半辈子。
</details>

<details>
<summary>选读 · "分数约分"是巧合还是真理</summary>

莱布尼茨记号里 $\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}$，右边的 du 像"约"掉了——看着像分数戏法，其实是深刻事实的影子：当增量很小时，$\Delta u \approx g'(x)\Delta x$，而 $\Delta y \approx f'(u)\Delta u$。两式串联：

$$\Delta y \approx f'(u)\, g'(x)\,\Delta x$$

两边除以 $\Delta x$ 取极限（严格处理 $\Delta u$ 可能取零的技术细节要到后续课程），等号便精确成立。所以"约分"不是侥幸——它反映的是**扰动的放大倍率沿着流水线真实相乘**这一物理事实。
</details>
