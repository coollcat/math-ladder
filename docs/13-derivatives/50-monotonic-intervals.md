# 用导数求单调区间

## 1. 从一个场景开始

一架测绘无人机沿着程序设定的高度曲线飞行，地面站只拿到一条算式 $h(t)$，却要回答调度员的两个问题：**哪几段在爬升、哪几段在下降？** 要是航线上还挂着一个可调参数 $a$（比如配重），答案还得按 $a$ 的取值分情况给——因为 $a$ 一变，爬升段和下降段可能整段互换。

把高度值一个个代进去比大小是最笨的办法：代得再多也证明不了中间没有反复。导数给出的答案干脆得多——**看坡度符号**。这一课把这件事做成一条可复制的流水线，并配上含参情形的"分类讨论标准流程"。

## 2. 直觉解释

沿曲线从左往右走，脚下坡度的符号直接告诉你处境：

- 坡度处处为正 ⇒ 一直在爬 ⇒ **递增**；
- 坡度处处为负 ⇒ 一直在降 ⇒ **递减**；
- 坡度换号的位置，就是爬与降的**分界点**。

反过来想更清楚：如果函数在某段上递增，那么割线斜率 $\dfrac{f(x_2)-f(x_1)}{x_2-x_1} > 0$，让两点无限靠近，极限（也就是导数）必然 $\ge 0$。所以"递增 ⇒ $f' \ge 0$"是单向的倒推；我们真正要用的、**由导数推单调性**的方向，是下面这个定理。

有个细节要当场讲明：**单个点上导数为零，不影响整段递增**。$y = x^3$ 在 $x = 0$ 处坡度为零，但它从 $-\infty$ 一路涨到 $+\infty$。所以判据里允许零星的驻点，只要它们不把区间切成两块。

## 3. 正式定义

**单调性判别定理**：设 $f$ 在 $[a, b]$ 上连续、在 $(a, b)$ 内可导。

| 条件 | 结论 |
| --- | --- |
| 在 $(a, b)$ 内 $f'(x) > 0$ | $f$ 在 $[a, b]$ 上严格递增 |
| 在 $(a, b)$ 内 $f'(x) < 0$ | $f$ 在 $[a, b]$ 上严格递减 |
| 在 $(a, b)$ 内 $f'(x) \ge 0$（只在有限个点为零） | $f$ 在 $[a, b]$ 上递增 |
| 在 $(a, b)$ 内 $f'(x) = 0$ 恒成立 | $f$ 在 $[a, b]$ 上为常数 |

| 符号 | 含义 | 备注 |
| --- | --- | --- |
| $f'(x)$ | 坡度函数 | 判单调性的唯一依据 |
| 驻点 $x_0$ | $f'(x_0) = 0$ | 单调区间的候选分界点 |
| 分界点 | $f'$ 在其两侧异号的点 | 导数不存在的点也可以当分界点 |
| 单调区间 | 相邻两个分界点之间的一段 | **分开写，不取并集** |

**含参单调区间的分类讨论标准流程**（背下这七步，万题通用）：

| 步 | 动作 | 不做会怎样 |
| --- | --- | --- |
| 1 | 先写**定义域** | 定义域外的根不分区间，漏了就多分一层 |
| 2 | 求导并**因式分解** | 不分解就看不清符号 |
| 3 | 看最高次项系数是否可能为零 | 系数为零时 $f'$ 降次，图像类型整段改变 |
| 4 | 看判别式，确定根的个数 | 无根时 $f'$ 恒正或恒负，只有一段 |
| 5 | 用参数把根写出来 | — |
| 6 | **两根比大小** | 参数一动，左右次序可能互换 |
| 7 | 剔除定义域外的根，数轴标根逐段判号 | 这是最后一层，也是最容易少写的一层 |

## 4. 分步例题

### 例 1（无参）：求 $f(x) = x^3 - 3x^2 + 2$ 的单调区间

1. **定义域**：$\mathbb{R}$，没有坑；
2. **求导并分解**：$f'(x) = 3x^2 - 6x = 3x(x - 2)$；
3. **找根**：$x = 0$ 与 $x = 2$；
4. **标根判号**：$3x(x-2)$ 是开口向上的二次式，两根之外为正、两根之间为负：

| 区间 | $(-\infty, 0)$ | $(0, 2)$ | $(2, +\infty)$ |
| --- | --- | --- | --- |
| $f'(x)$ | $+$ | $-$ | $+$ |
| $f$ | 递增 | 递减 | 递增 |

答案：**增区间 $(-\infty, 0)$ 与 $(2, +\infty)$，减区间 $(0, 2)$**。注意两个增区间之间用"与"字，不能写成并集（见误区二）。

### 例 2（含参·两根比大小）：讨论 $f(x) = \dfrac{x^3}{3} - \dfrac{a+1}{2}x^2 + ax$ 的单调性

1. **定义域**：$\mathbb{R}$；
2. **求导**：$f'(x) = x^2 - (a+1)x + a$；
3. **分解**：$f'(x) = (x - 1)(x - a)$（交叉相乘验证：$1 \cdot a = a$，$1 + a$ 正是中间项系数）；
4. **最高次项系数**是 $1$，恒不为零，第 3 步跳过；
5. **两个根是 $1$ 与 $a$**。它们始终存在，但**谁大谁小要看 $a$**：

| $a$ 的范围 | $f'(x) = (x-1)(x-a)$ 的符号 | 结论 |
| --- | --- | --- |
| $a > 1$ | $(-\infty,1)$ 正、$(1,a)$ 负、$(a,+\infty)$ 正 | 增 $(-\infty,1)$、$(a,+\infty)$；减 $(1, a)$ |
| $a = 1$ | $(x-1)^2 \ge 0$，只在 $x = 1$ 处为零 | 在 $\mathbb{R}$ 上**递增** |
| $a < 1$ | $(-\infty,a)$ 正、$(a,1)$ 负、$(1,+\infty)$ 正 | 增 $(-\infty,a)$、$(1,+\infty)$；减 $(a, 1)$ |

**$a = 1$ 是独立的第三层**：两根重合，二次式化为完全平方，中间那段负号区**塌缩成一个点**，于是只剩一个区间。含参题漏掉"两根相等"这一层，是最经典的扣分。

### 例 3（含参 + 定义域）：讨论 $f(x) = \dfrac{x^2}{2} - (a+1)x + a\ln x$ 的单调性

1. **定义域**：$\ln x$ 要求 $x > 0$，这是本题的第一个约束；
2. **求导**：$f'(x) = x - (a+1) + \dfrac{a}{x} = \dfrac{x^2 - (a+1)x + a}{x} = \dfrac{(x-1)(x-a)}{x}$；
3. **约去恒正因子**：定义域内 $x > 0$，所以 $f'$ 的符号**只由分子 $(x-1)(x-a)$ 决定**；
4. **分层**：根还是 $1$ 与 $a$，但这次要先问"$a$ 在不在定义域里"：

| $a$ 的范围 | 分子符号（$x>0$） | 结论 |
| --- | --- | --- |
| $a \le 0$ | $x - a > 0$ 恒成立，符号 $= x - 1$ 的符号 | 减 $(0, 1)$；增 $(1, +\infty)$ |
| $0 < a < 1$ | 两根都在定义域内，$a < 1$ | 增 $(0, a)$、$(1, +\infty)$；减 $(a, 1)$ |
| $a = 1$ | $\dfrac{(x-1)^2}{x} \ge 0$ | 在 $(0, +\infty)$ 上**递增** |
| $a > 1$ | 两根都在定义域内，$1 < a$ | 增 $(0, 1)$、$(a, +\infty)$；减 $(1, a)$ |

对比例 2：$a \le 0$ 这一层是**定义域带来的**——根 $a$ 落在 $x \le 0$，被定义域挡在门外，压根不分区间，于是层数从三层变成四层。这就是标准流程第 7 步的价值。

### 实验 3（python）：让机器自己划出分界点

```python title="拖动 a：符号一翻转，就是一个分界点"
# sliders: a=2.0 [-1.0:3.0:0.5]

def dfp(x):
    return (x - 1) * (x - a)          # 因式分解后的导数：符号一眼看得出

cuts = []
prev = dfp(-3 + 0.0005)               # 取样点错开半格：免得正好落在驻点上
i = 1
while i <= 8000:
    x = -3 + i * 0.001 + 0.0005
    cur = dfp(x)
    if prev * cur < 0:                # 符号翻转 = 扫过一个分界点
        cuts.append(round(x, 1))
    prev = cur
    i = i + 1

print(f"a = {round(a, 1)}: 分界点 {cuts}")
if len(cuts) == 0:
    print("全区间递增")
else:
    print(f"增 (-∞, {cuts[0]}) 与 ({cuts[1]}, +∞)，减 ({cuts[0]}, {cuts[1]})")
```

怎么玩：$a = 2$ 时输出 `分界点 [1.0, 2.0]`；拖到 $a = 1$，输出变成 `分界点 []` 并给出"全区间递增"——机器自己撞上了那个必须单独成层的退化情形；再拖到 $a = -1$，分界点变成 `[-1.0, 1.0]`，左右端点自动换了位置。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为 $f'(x_0) = 0$ 就能切出一个单调区间。" $y = x^3$ 在 $x = 0$ 处导数为零，但它在 $\mathbb{R}$ 上严格递增。分界点的判定标准是 $f'$ **在两侧异号**，不是"在这一点的函数值为零"。$a = 1$ 时 $f' = (x-1)^2$ 触到横轴却弹回来，就没有分界点。

**误区二**："你以为两个增区间可以并起来写。" 例 1 不能写成"增区间为 $(-\infty, 0) \cup (2, +\infty)$"。单调性是**一整个集合上**的性质，并集上的任意两点必须都满足大小关系才行。反例就在例 1 里：取 $x_1 = -0.1$（在第一个增区间内）与 $x_2 = 2.1$（在第二个增区间内），

$$f(-0.1) = 1.969 \quad>\quad f(2.1) = -1.969$$

若在并集上递增，就该有 $f(x_1) < f(x_2)$，矛盾。中间那段下降把两个增段隔开了。**标准写法是两个区间分开列，用"与"或逗号连接。**

**误区三**："你以为分类讨论只要比两根大小。" 例 3 多出来的 $a \le 0$ 一整层，来自**定义域**：根算出来了，却落在定义域外，等于没有。凡是带 $\ln x$、$\dfrac{1}{x}$、$\sqrt{x}$ 的式子，第 1 步写定义域、第 7 步剔除域外根，一步都不能省。

:::

## 7. 练习

**练习 1**：下面的减区间定位器把两根的次序写死了，遇到 $a < 1$ 就给出"左端点比右端点大"的荒唐结果。改成先比大小：

```exercise
# @title: 练习：两根谁大，谁当左端点
# @check: a=2: 减区间 (1, 2)
# @check: a=0: 减区间 (0, 1)
# @hint: 减区间夹在两根之间，两根是 1 和 a；a < 1 时应该让 a 当左端点、1 当右端点（a = 1 时两根重合、没有减区间，本题不测它）
def interval(a):
    lo = 1        # ← 写死了：总把 1 当左端点
    hi = a        # ← 写死了：总把 a 当右端点
    return lo, hi

for a in [2, 0]:
    lo, hi = interval(a)
    print(f"a={a}: 减区间 ({lo}, {hi})")
```

现在第二行会输出 `a=0: 减区间 (1, 0)`——左端点比右端点还大，一看就不对。

<details>
<summary>点开查看逐步解答</summary>

减区间是两根之间的那一段，左端点必须取两根中**较小**的那个。用一次判断把两种次序分开：

```python
def interval(a):
    if a < 1:
        lo = a
        hi = 1
    else:
        lo = 1
        hi = a
    return lo, hi

for a in [2, 0]:
    lo, hi = interval(a)
    print(f"a={a}: 减区间 ({lo}, {hi})")
```

输出 `a=2: 减区间 (1, 2)` 与 `a=0: 减区间 (0, 1)`，与例 2 的表格一致。这一步就是在替标准流程第 6 步"两根比大小"做事——$a$ 跨过 $1$ 的那一刻，两根互换位置，减区间的写法随之改变。

</details>

**练习 2**（思考）：为什么例 3 中 $a = 1$ 时 $f(x) = \dfrac{x^2}{2} - 2x + \ln x$ 在 $(0, +\infty)$ 上递增，但它**不是**处处"严格"递增（即 $f'$ 在某点为零）？这与误区一是什么关系？

<details>
<summary>点开查看逐步解答</summary>

$a = 1$ 时 $f'(x) = \dfrac{(x-1)^2}{x}$，在 $x = 1$ 处等于零，其余各处严格大于零。按定理第 3 行（$f' \ge 0$ 且只在有限个点为零），结论是**递增**；它在 $x = 1$ 附近坡度为零却不换号，所以仍然严格递增（只是"这一瞬间没在涨"）。

这正是误区一的正面版本：**导数为零是分界点的必要条件，不是充分条件**。要否定分界点，必须检查两侧的符号——两侧同号就只是一个歇脚的平坡。把它和 45 课"极值的判定"对照着看：$x^3$ 在原点同样是"导数为零但不换号"，那里既非极值、这里也非分界，两个判据其实是同一条规则的两个用法。

</details>

## 8. 选读与边界

<details>
<summary>选读：定理为什么只在一个方向成立</summary>

严格递增 $\Rightarrow f' \ge 0$ 是能证的：递增意味着任意差商 $\dfrac{f(x+h)-f(x)}{h} \ge 0$（$h$ 正负皆然），令 $h \to 0$ 即得 $f'(x) \ge 0$。

反过来 $f' \ge 0 \Rightarrow$ 递增，靠的是**拉格朗日中值定理**：在 $[x_1, x_2]$ 上存在 $\xi$ 使 $f(x_2) - f(x_1) = f'(\xi)(x_2 - x_1) \ge 0$。这个定理要到第 19 章才严格证明，本课先用结论。

至于"$f' > 0$"换成"$f' \ge 0$ 且只在有限个点为零"仍然推出严格递增，则是把区间按那些零点切成有限多段，每段内部 $f' > 0$ 严格递增，再一段段接起来。

</details>

本课不管三件事：

- **区间端点怎么取**。本课一律开区间书写；闭区间、半开半闭的写法取决于教材约定，只要函数在端点连续，两种写法等价；
- **不可导的单调函数**。$f(x) = x + \sin x$ 之类处处可导没问题，但带尖点、跳跃的函数要另外处理；
- **多元函数的单调性**。那要换成方向导数与梯度（第 20 章）。
