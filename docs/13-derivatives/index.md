# 极限与导数：变化率的科学

前十二章我们一直在回答"它是几"；从这一章起，我们追问一个更锋利的问题："它变得有多快？"汽车仪表盘上的瞬时速度、账户余额的增长速率、火箭省油的最佳爬升角、ChatGPT 学习时的反向传播——背后全是同一个数学对象：**导数**。而称量"一瞬间"的天平，叫做**极限**。

这门手艺为什么值得学？三个事实：

- **物理学**：位置对时间的导数是速度，速度对时间的导数是加速度——牛顿发明微积分就是为了解释天体运行；
- **人工智能**：神经网络靠"梯度下降"学习，梯度就是多维版的导数——AI 每一步成长都在求导；
- **傅里叶变换**（第 16 章 · 卷一枢纽站）：它的许多性质（如 e^x 的优雅变身）要在你掌握 e^x 的导数之后才真正敞开。

## 实战挑战 · 最省料的易拉罐

> 改编自经典微积分优化题（MIT 18.01 等教材的"罐头设计"问题）

饮料公司要上一款新罐：容积定死 $V = 250\pi \approx 785$ 毫升（大号罐），铝皮越少成本越低。圆柱形罐由半径 $r$ 和高 $h$ 决定——$r$ 太小则罐子细高、侧面费料；$r$ 太大则上下底费料。最省料的比例存在吗？

**(a) 建模**：容积约束 $\pi r^2 h = V$ 把 $h$ 锁定为 $h = \dfrac{V}{\pi r^2}$。代入表面积（上下两个圆底 + 侧面展开的矩形）：$S = 2\pi r^2 + 2\pi r h$，得到只含 $r$ 的函数

$$S(r) = 2\pi r^2 + \frac{2V}{r}$$

**(b) 求最低点**：对 $S(r)$ 求导，令导数为零解出最优半径，并算出该半径下的表面积与罐高。下面的代码能跑但猜错了答案——手算出正确半径后替换它：

```exercise
# @title: 实战挑战：最省料的易拉罐
# @check: 5.0
# @check: 471.24
# @check: 10.0
# @hint: 令 dS(r) = 0：4πr = 2V/r²，两边乘 r² 再除以 4π 得 r³ = V/(2π) = 125。哪个数的立方是 125？
import math

V = 250 * math.pi   # 容积固定为 250π 立方厘米 ≈ 785 毫升

def S(r):
    # 表面积：上下底 2πr² + 侧面 2πrh，其中 h = V/(πr²) 已经代入
    return 2 * math.pi * r ** 2 + 2 * V / r

def dS(r):
    # S 的导数：第一项降次得 4πr，第二项把 2V/r 看成 2V·r⁻¹ 再降次
    return 4 * math.pi * r - 2 * V / r ** 2

# 解方程 dS(r) = 0 得 r³ = V/(2π)。把手算出的最优半径填到下面：
r_best = 3.0   # ← 随手猜的值，不对！
print(round(r_best, 1))
print(round(S(r_best), 2))                       # 最省料时的表面积
print(round(V / (math.pi * r_best ** 2), 1))     # 此时的高 h
```

**(c) 思辨**：算出的最优罐"高等于直径"，方头方脑——可货架上的易拉罐个个瘦高，为什么厂商不按最优解生产？

<details>
<summary>点开查看逐步解答</summary>

**(a) 消去 h**：约束 $\pi r^2 h = V$ 给出 $h = \dfrac{V}{\pi r^2}$，代进表面积：

$$S = 2\pi r^2 + 2\pi r \cdot \frac{V}{\pi r^2} = 2\pi r^2 + \frac{2V}{r}$$

**(b) 求导找谷底**。幂规则逐项处理（第二项先改写成 $2V \cdot r^{-1}$）：

$$S'(r) = 4\pi r - \frac{2V}{r^2}$$

令其为零：$4\pi r = \dfrac{2V}{r^2}$，两边同乘 $r^2$ 再除以 $4\pi$：

$$r^3 = \frac{V}{2\pi} = \frac{250\pi}{2\pi} = 125 \quad\Rightarrow\quad r = 5 \text{ 厘米}$$

此时 $h = \dfrac{250\pi}{\pi \cdot 25} = 10$ 厘米——**高恰好等于直径**，罐子从侧面看是个正方形！最小表面积 $S(5) = 50\pi + 100\pi = 150\pi \approx 471.24$ 平方厘米。用代码复核整条链路：

```python
import math

V = 250 * math.pi

def S(r):
    return 2 * math.pi * r ** 2 + 2 * V / r   # 表面积函数（与判题块一致）

def dS(r):
    return 4 * math.pi * r - 2 * V / r ** 2   # 导数：令它等于零即可解出最优半径

r_best = 5.0                          # 手算结果：r³ = V/(2π) = 125
h_best = V / (math.pi * r_best ** 2)  # 由容积约束反解出的高

print(round(r_best, 1), round(h_best, 1))   # 5.0 10.0 —— 高恰好等于直径
print(round(S(r_best), 2))                  # 471.24：最小表面积
print(abs(dS(r_best)) < 1e-9)               # True：谷底处导数确实为零
```

（顺带一提：$r^3=125$ 这种凑好的数字是教材惯例，真实容积照样同法炮制，只是立方根不再整数。）

**(c) 为什么现实不照抄最优解**。数学模型只计了"铝皮面积"，真实成本还有好几页账：罐口卷边和拉环工艺要求厚实的顶盖（顶盖往往比罐身贵一倍以上，于是厂商倾向缩小顶盖半径、把罐子拉高）；瘦高罐在运输箱里排布更省空间；细长圆柱更贴合手掌。工程师的真实工作正是像这样不断往模型里补充被忽略的代价——导数负责找谷底，建模者负责确认谷底挖对了地方。

</details>

## 实战挑战 · 差分商别忘了除 h

用数值差分逼近导数：$f'(x) \approx \frac{f(x+h) - f(x)}{h}$。分子是"函数值的差"，还要**除以步长 $h$**。下面这题漏除了，求 $f(x)=x^2$ 在 $x=3$ 的导数，修到输出 `6`：

```exercise
# @title: 实战挑战：差分商别忘了除 h
# @check: 6
# @hint: 差商 = (f(x+h) - f(x)) / h，除以 h 才是"变化率"。
def f(x):
    return x * x

x = 3
h = 0.0001
slope = (f(x + h) - f(x))    # ← 问题在这：漏了除以 h
print(round(slope))
```

<details>
<summary>点开查看逐步解答</summary>

差商的定义是函数值之差**除以**自变量的差：

```python
slope = (f(x + h) - f(x)) / h   # 差分 ÷ 步长 = 平均变化率
print(round(slope))             # 6
```

代值：$f(3+0.0001)-f(3) \approx 0.00060001$，除以 $h=0.0001$ 得约 $6.0001$，`round` 后为 `6`——正是 $f'(x)=2x$ 在 $x=3$ 的值。初始代码只算了分子（约 $0.0006$），`round` 直接归零。导数本质是"变化量 ÷ 变化量"的比值，漏除 $h$ 就把"斜率"算成了"高度差"。

</details>
