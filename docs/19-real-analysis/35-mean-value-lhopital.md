# 中值定理与洛必达法则

## 1. 从一个场景开始

你开着电动车跑一段 90 公里的山路，出发与到达之间的平均速度是每小时 45 公里——尽管仪表盘上的瞬时速度从来没停稳过。GPS 只靠沿途扫到的瞬时速度就能估出到达时刻，因为它相信一件事：**至少有一个瞬间，你的车速恰好等于全程平均速度**。「整体增量」和「局部速率」之间的这座桥，就是中值定理；而洛必达法则是它顺路捎回来的一件礼物——专门处理 $0/0$ 这种让人头痛的极限。

## 2. 直觉解释

想象把区间的两个端点 $A$、$B$ 连成一条弦。现在把这条弦**平移着往曲线方向推**：总有一刻它碰到曲线上某一点 $C$，在那里与曲线贴平——也就是说，曲线在 $C$ 处的切线与弦平行。

- 弦的斜率 $=\dfrac{f(b)-f(a)}{b-a}$：起点到终点整体的平均变化率；
- 切线斜率 $=f'(c)$：$c$ 点局部的瞬时变化率。

两斜率相等，正是"某个瞬间的速率等于平均速率"这句话的几何化身。

再看一个退化版本：如果端点一样高（$f(a)=f(b)$），弦是水平的，那么推过去的平行切线也水平——曲线在这一段内必有一条水平切线。这就是罗尔定理：上山再下山，途中必有一处既不上也不下。

## 3. 正式定义

| 符号 | 含义 |
| --- | --- |
| $f$ 在 $[a,b]$ 上连续 | 整个区间不断线，图像能一笔画到底 |
| $f$ 在 $(a,b)$ 上可导 | 区间内部每点的切线斜率存在 |
| $c$ | 由定理保证存在的某个内部点，**只承诺存在，不说在哪** |

**罗尔定理**：若 $f$ 在 $[a,b]$ 连续、$(a,b)$ 可导且 $f(a)=f(b)$，则存在 $c\in(a,b)$ 使 $f'(c)=0$。

**拉格朗日中值定理**：把条件放宽成两端不必等高，则存在 $c\in(a,b)$ 使

$$f'(c)=\frac{f(b)-f(a)}{b-a}.$$

**柯西中值定理**：换用两个函数 $f,g$，以 $g$ 为横轴重新丈量这段路，则存在 $c$ 使 $\dfrac{f'(c)}{g'(c)}=\dfrac{f(b)-f(a)}{g(b)-g(a)}$。

**洛必达法则**（柯西版本的直接应用）：当 $x\to a$ 时 $f$ 与 $g$ 都趋于 $0$（或都趋于无穷），且导数比的极限存在，则

$$\lim_{x\to a}\frac{f(x)}{g(x)}=\lim_{x\to a}\frac{f'(x)}{g'(x)}.$$

一句话解释它为什么合法：把 $f(a),g(a)$ 补成 $0$ 之后，比值变成"增量比增量"，柯西中值定理立刻告诉你这比值等于某点的导数之比——求极限的游戏于是转移到了分子分母各自变矮的速度上。

## 4. 分步例题

**例 1 · 找出那个神秘的 $c$**：取 $f(x)=x^2$ 于 $[1,4]$。

1. 平均变化率：$\dfrac{f(4)-f(1)}{4-1}=\dfrac{16-1}{3}=5$；
2. 瞬时变化率：$f'(x)=2x$；
3. 解方程 $2c=5$，得 $c=2.5$——恰好落在区间正中央。

（二次函数总有这种中点巧合；三次以上就没有了，稍后的实验会亲眼看到反例。）

**例 2 · 洛必达首秀**：求 $\displaystyle\lim_{x\to 0}\frac{\sin x}{x}$。

1. 代入 $x=0$：分子分母同时为 $0$，是 $0/0$ 未定式；
2. 分别求导：分子 $\cos x$，分母 $1$；
3. 新比值 $\dfrac{\cos x}{1}$ 在 $x\to0$ 时极限为 $1$；
4. 结论：原极限 $=1$。卷一"摸着凑"出来的那个 1，今天被一次求降维打击地解决了。

### 实验 2 · 洛必达逼近表

```python title="差商表：靠近 0 时 (e^(2x)-1)/x 的取值"
import math  # math 提供 exp（指数函数）等工具

for h in [0.1, 0.01, 0.001]:         # 依次取越来越小的试探点
    val = (math.exp(2 * h) - 1) / h  # 直接代入原式算差商
    print(h, "->", round(val, 4))    # round 保留四位小数
```

三次取点打印出 `2.214`、`2.0201`、`2.002`——一路收拢向 2。这正是洛必达一步给出的答案：$\dfrac{2e^{2x}}{1}$ 在 $x\to0$ 时等于 2。暴力表格与解析法则在这里握手。

## 6. 常见误区

:::warning[常见误区]
- **你以为凡是极限都能洛必达，其实只认两种牌型**：必须先是 $0/0$ 或 $\infty/\infty$ 未定式。像 $\lim_{x\to0}\frac{x}{2+\sin x}$ 分母根本不趋于 0，硬求导会得出荒谬结果。
- **你以为新比值的极限一定存在，其实它可能赖账**：经典例子 $\lim_{x\to\infty}\frac{x+\sin x}{x}$，求导后变成 $\frac{1+\cos x}{1}$ 在 $1$ 与 $2$ 间振荡、没有极限——此时洛必达的条件被破坏，不能下"原极限不存在"的结论（原式其实收敛到 1，用通项拆开即可看出）。
- **你以为中值定理会告诉你 $c$ 在哪，其实它只担保有人到场**：定理说"存在 $c$"，不给地址。只有二次函数这类特殊选手才恰好站在中点；一般函数的位置要用方程现解。
:::

## 7. 练习

下面的代码声称验证了 $f(x)=x^3$ 在 $[0,3]$ 上的中值点，但它把 $c$ 随手放在了区间正中央。请把它改成真正解方程的结果，使输出通过判题：

```exercise
# @title: 解出真正的中值点
# @check: 9.0
# @check: 1.73205
# @hint: 让 f'(c) = 3*c*c 等于割线斜率 slope，把 c 当未知数解出来；c 不必落在区间中点——那种巧合只属于二次函数。
import math  # math.sqrt 负责开方

a = 0
b = 3

slope = (b ** 3 - a ** 3) / (b - a)   # 割线斜率（这一行是对的）
print(slope)

c = (a + b) / 2                       # ← 想当然的中点
print(round(c, 5))
```

<details>
<summary>点开查看逐步解答</summary>

割线斜率是真算对的：$\dfrac{27-0}{3-0}=9$。错的是第二处：中值定理没有说过 $c$ 居中。正确的路线是把"$c$ 处的切线斜率等于割线斜率"翻译成方程：

1. 求导：$f'(x)=3x^2$；
2. 立方程 $3c^2=9$；
3. 解出 $c=\sqrt{3}\approx1.732$，它在 $(0,3)$ 内部——别忘了中值定理还要求 $c$ 属于开区间，负根 $-\sqrt3$ 要舍去。

修改一行即可：

```python
c = math.sqrt(slope / 3)   # 解 3*c^2 = slope
```

输出变为 `9.0` 和 `1.73205`。对比例 1：二次函数的 $c=2.5$ 恰好居中纯属巧合；三次函数立刻露出马脚——这正是"定理只保证存在、不预告位置"的活教材。

</details>

## 8. 边界与选读

本课把"局部导数"接上了"整体增量"，并用它一次性收割了 $0/0$ 极限。但有几件事它不做：泰勒级数那种"带余项的精细误差控制"已在 15 章的 [泰勒余项：多项式差多远](../15-series-taylor/35-taylor-remainder.md) 兑现——拉格朗日余项正是本课中值定理的高阶版（选读里柯西中值定理滚 n+1 轮的账单）；多元函数有自己版本的"沿方向的中值不等式"，不属于这里的单一变量叙事；洛必达也没有覆盖 $0\cdot\infty$、$\infty-\infty$ 这些需要先变形成未定式的牌型——变形本身常常比求导更考验功夫。

<details>
<summary>选读 · 从罗尔定理推出拉格朗日中值定理</summary>

构造辅助函数（把"弦高"从原函数身上减掉，剩下的图两端一样高）：

$$h(x)=f(x)-f(a)-\frac{f(b)-f(a)}{b-a}(x-a).$$

它是连续与可导性的继承者，且 $h(a)=h(b)=0$。罗尔定理出手：存在 $c\in(a,b)$ 使 $h'(c)=0$。而

$$h'(x)=f'(x)-\frac{f(b)-f(a)}{b-a},$$

令其为零，移项便得到中值等式。柯西版本同理：减去一条连接 $(g(a),f(a))$ 到 $(g(b),f(b))$ 的"参数化弦" $f(a)+t\,(g(x)-g(a))$，再用罗尔定理。整套戏法的核心道具只有一个：把待证结论伪装成一个两端等高的函数。

</details>
