# 单调有界必收敛与 Bolzano-Weierstrass

## 1. 从一个场景开始

Cauchy 判据查"项与项是否彼此靠近"，可它要求的信息并不总在手边。许多数列只肯交代两件更弱的事：**方向单一**（只涨不跌），以及**涨不出某个天花板**（有界）。比如前 n 个倒数平方之和

$$S_n = 1 + \frac14 + \frac19 + \cdots + \frac{1}{n^2}$$

只涨不跌，也永远涨不过 2。它收敛吗？单调有界定理担保：必收敛。再进一步——哪怕数列上蹿下跳、毫无方向，只要被关在有界区间里，Bolzano-Weierstrass 保证总能**抽出一个收敛子列**。上一课选读里借用的那个"B-W 性质"黑盒，今天正式开箱。

## 2. 直觉解释

**单调有界**像爬楼梯：每一级都比前一级高，但天花板就在头上。楼梯被迫贴着某个高度稳定下来——这个高度正是**上确界**（本章开篇那课的老朋友：最小的上界）。它比天花板略低的任何一层都会被某一级越过（否则那层才是天花板），所以越往后，各级全被挤进"上确界下方一条任意窄的带"里。

**Bolzano-Weierstrass**像人满为患的走廊：无穷多个人挤进一段有限走廊，把走廊对半分，必有一半挤了无穷多人；把这半截留下再对半分……每次都留下"无穷多人"的那一半。半截走廊越缩越短，最后夹出一个点——那附近人头攒动，从中按次序喊人排成一队，这支队伍（子列）就会收拢到那个点。

## 3. 正式定义

**单调有界定理**：单调递增且有上界的数列必收敛，极限等于它的上确界；单调递减且有下界同理。

**Bolzano-Weierstrass 定理**：有界实数列必含收敛子列。

| 对象 | 含义 |
| --- | --- |
| 单调 | 每一项不小于（或不大于）前一项 |
| 有界 | 全体项被关在某个有限区间里 |
| 子列 | 从原数列按原次序挑出的无穷多项，下标严格递增 |
| 上确界 | 最小上界，不必属于数列取值（本章开篇那课 $\sup$ 的用法） |

## 4. 分步例题

**例 1 · 给 $S_n = \sum_{k=1}^{n}\frac{1}{k^2}$ 开收敛证明。**

1. 单调：每加一项都是正数，$S_{n+1} > S_n$；
2. 有界：第 15 章的伸缩链已证 $\sum \frac{1}{n^2} < 2$（$\frac{1}{n^2} < \frac{1}{n(n-1)}$ 伸缩相消）——上界 2；
3. 单调有界定理出手：$S_n$ 收敛；
4. 注意判决与精确值解耦：部分和收敛到 $\frac{\pi^2}{6}$ 是巴塞尔悬案，但"收敛与否"不依赖悬案告破——定理只问方向和天花板。

**例 2 · 收敛到上确界。** $a_n = \dfrac{2n+1}{n+1}$。

1. 变形：$a_n = 2 - \dfrac{1}{n+1}$；
2. 单调递增：减掉的 $\frac{1}{n+1}$ 越来越少，剩下的越来越多；
3. 有上界：每项都小于 2，且 2 是最小上界；
4. 定理担保 $a_n \to 2$——极限恰是上确界，这正是定理承诺的归宿。

### 实验 3：Python 检查方向与天花板

```python title="部分和只涨不跌，也涨不过 2"
def S(n):
    total = 0.0
    for k in range(1, n + 1):        # k 从 1 数到 n
        total = total + 1 / (k * k)  # 第 k 项：1/k^2
    return total

print(round(S(50), 4))               # 五十项爬到 1.6251
print(round(S(1000), 4))             # 一千项 1.6439：还在涨，但明显涨不动了
print(round(S(1001) - S(1000), 6))   # 下一级增量：约百万分之一（打印成 1e-06）
print("bounded" if S(1000) < 2 else "overflow")
```

输出 `1.6251`、`1.6439`、`1e-06`、`bounded`。一千项离天花板 2 还差一截，但每级增量已缩到百万分之一——单调与有界合在一起，收敛不再是悬念。


<details>
<summary>点开查看逐步解答</summary>

把错的那行改回平方：

```python
total = total + 1 / (k * k)
```

一千项部分和为 $1.6439$（精确归宿 $\frac{\pi^2}{6} \approx 1.6449$ 已经不远）。错版 $\sum \frac{1}{2k}$ 是调和级数的一半，一千项已涨到 $3.7427$——超过 2 被判 `diverging`。一字之差：$\frac1k$ 型衰减保不住天花板，$\frac{1}{k^2}$ 型可以。单调有界定理管的是"方向与天花板"，每项衰减多快仍是级数自己的事。
</details>

## 7. 常见误区

::::warning[常见误区]

**误区一**：容易以为有界就必收敛。$(-1)^n$ 被关在 $-1$ 与 $1$ 之间却原地踏步——有界只保证（经由 B-W）抽得出收敛子列，不保证整列收敛。

**误区二**：容易把单调有界定理当成 Cauchy 判据的重复。两者出发点不同：Cauchy 查"项与项彼此靠近"，单调有界只查"方向 + 天花板"。实数里各收敛原理最终互相等价，但顺手场景不同——迭代法里单调有界往往最先到手。

**误区三**：容易从子列收敛反推整列收敛。子列只是挑出的模范生小队；要整列跟上，还需 Cauchy 性质或单调性这类"整队纪律"。

::::

## 9. 选读：二分抽子列——B-W 的证明骨架

<details>
<summary>选读 · 每一步都留下含无穷多项的那一半</summary>

设数列被关在 $[A,B]$ 里。二分成两半，至少一半含无穷多项，留下它；再二分、再留下……得到一串嵌套闭区间，长度按 $\frac{B-A}{2^n}$ 塌缩。本章开篇那课的区间套版本完备性保证它们交于一点 $L$。

抽子列：在第一个留下的区间里挑一项，下标记 $n_1$；在第二个区间里挑下标大于 $n_1$ 的一项（有无穷多项可选，必然办得到）；依次类推。子列的第 $k$ 项落在长度 $\frac{B-A}{2^k}$ 的区间里，且越来越贴近 $L$——子列收敛到 $L$。

上一课选读的坑就此填平：Cauchy 数列先有界，B-W 抽出收敛子列 $a_{n_k}\to L$，再用 Cauchy 性质把整条尾部拉向同一个 $L$。完备性、单调有界、Cauchy——三条收敛原理在此会师成同一张网，网眼就是实数轴没有洞。

</details>
