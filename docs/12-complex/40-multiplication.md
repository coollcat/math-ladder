# 复数乘法＝旋转＋伸缩

## 1. 从一个场景开始

第 1 章有个画面你一定记得：乘以 $-1$，就是把数轴上的点**甩到对面去**——转 180°。现在复平面铺开了，一个更大胆的问题冒出来：乘以 $i$ 是什么动作？

$i$ 的模是 1、辐角是 90°。如果"乘法 = 模长相乘 + 辐角相加"，那么乘 $i$ 就是**原地逆时针转 90°**——不伸不缩，纯转身。乘法竟然是一种几何运动？这一课把这句话变成铁律。

## 2. 直觉解释

把两个复数都写成极形式（上一课的身份证）：$z=r_1(\cos\theta_1+i\sin\theta_1)$，$w=r_2(\cos\theta_2+i\sin\theta_2)$。

直觉预言：相乘时长度该按比例叠起来（$r_1 r_2$），方向该把两个转角接龙（$\theta_1+\theta_2$）。下一节的代数展开会证明这个预言分毫不差：

$$|z\cdot w| = |z|\cdot|w|, \qquad \arg(zw) = \arg z + \arg w$$

于是每个复数都是一台"伸缩机 + 旋钮"：模长管放大几倍，辐角管拧多少度。特别地，单位圆上的复数（模为 1）是纯旋钮——$i$ 就是其中最顺手的一枚：转 90°。

## 3. 正式定义

对任意复数 $z=a+bi,\ w=c+di$，按普通展开并令 $i^2=-1$：

$$(a+bi)(c+di) = (ac-bd) + (ad+bc)\,i$$

注意实部里的减号和两个交叉项——它们正是"旋转"在代数里留下的指纹。

| 记号 | 名字 | 内容 |
| --- | --- | --- |
| 代数法则 | 展开式 | $(a+bi)(c+di)=(ac-bd)+(ad+bc)i$ |
| 模长定律 | 模长相乘 | $\lvert zw\rvert=\lvert z\rvert\lvert w\rvert$ |
| 辐角定律 | 辐角相加 | $\arg(zw)=\arg z+\arg w$ |

这两条定律还顺手带回一条老朋友：模长相乘和辐角相加都不在乎先后，所以复数乘法仍满足 $zw=wz$。第 11 章矩阵动作不可换序；这里的旋转伸缩又变得可以交换——差别就在于复数乘法只有“一个角度 + 一个倍率”这两个可交换的量。

下面的复平面上先拖动蓝色 $z$ 改变被乘向量；再按「交换 z 与 w」，两个因数会互换位置。你会看到紫色 $zw$ 箭头不动——这就是交换律在“旋转 + 伸缩”模型里的样子。

两条定律是**精确恒等式**，不是近似规律；选读部分用欧拉公式一步看穿它们的来历。

## 4. 分步例题

**例**：计算 $(3+4i)(1-2i)$，再用几何验算。

1. 展开：$3-6i+4i-8i^2$；
2. 化简 $i^2=-1$：$-8i^2=+8$；
3. 归拢：实部 $3+8=11$，虚部 $-6+4=-2$，得 $11-2i$；
4. 几何验算：$|z|=5$，$|w|=\sqrt5$，预测 $|zw|=5\sqrt5\approx11.18$；实测 $\sqrt{11^2+(-2)^2}=\sqrt{125}=11.18$ ✓；
5. 辐角验算：$\arg z\approx53°$，$\arg w\approx-63°$，相加 $\approx-10°$；实测 $zw$ 在第四象限贴着实轴，约 $-10°$ ✓。

## 5. 动手实验

### 实验 1（viz）：亲眼看旋转与伸缩

```viz
{
  "type": "complexmult",
  "z": [1, 0.5]
}
```

怎么玩：拖蓝色 z 点，滑杆定义绿色 w（模长与角度）。紫色粗箭头就是乘积 zw，橙色弧线演示辐角**接龙相加**；顶部读数实时验证两条定律 ✓。最值得玩的一步：把 w 调成 $|w|=1$、角度 $90°$——它就是 $i$！然后拖动 z 满场跑，看 zw 永远是 z 的 90° 旋转版。

### 实验 2（python）：i 的幂是一个四格钟

```python title="连乘 i，每四步回到原地"
p = 1 + 0j              # 起点：i 的 0 次幂
for k in range(9):
    print(f"i^{k}: 实部 {round(p.real)}, 虚部 {round(p.imag)}")
    p = p * 1j          # 每次多乘一个 i，相当于多转 90 度
# 1 → i → -1 → -i → 1 …… 周期恰好是 4
```

第 10 章的钟表回来了：$i$ 的幂按 $1, i, -1, -i$ 循环，问 $i^{2025}$ 等于几，就是在问 $2025 \bmod 4$ 的余数——余 1，所以答案是 $i$。指数世界里的"时钟"，齿轮只有四格。

### 实验 3（python）：两条定律的数值抽查

```python title="模长相乘、辐角相加，逐项核对"
import math

z = 3 + 4j
w = 1 - 2j
zw = z * w

# 定律一：模长相乘（abs 对复数求模长）
print(round(abs(z) * abs(w), 4), round(abs(zw), 4))     # 11.1803 11.1803

# 定律二：辐角相加（atan2 反查角度，再 degrees 换回度）
az = math.degrees(math.atan2(z.imag, z.real))
aw = math.degrees(math.atan2(w.imag, w.real))
azw = math.degrees(math.atan2(zw.imag, zw.real))
print(round(az + aw, 1), round(azw, 1))                  # -10.3 -10.3
```

### 快问快答

```quiz
复平面上，z = 1 + 2i 先拉伸 2 倍再逆时针转 90 度，等价于哪个算式？
- z * (2 + 2i)
- z * 2 * i [*]
- z + 2 + 2i
? "拉伸 2 倍再转 90 度"就是整体乘以 2i（模 2、角 90 度）。验证：(1 + 2i) * 2i = 2i + 4i² = -4 + 2i。
```

:::warning[常见误区]

**误区一**："你以为复数乘法是实部乘实部、虚部乘虚部。" 那样只会得到纯实数 $(ac)+(bd)i^2$ 的碎片。老实展开 $(a+bi)(c+di)$：交叉项 $ad$ 与 $bc$ 才是主角，旋转全藏在里面。

**误区二**："你以为 $i^4$ 会像 $2^4=16$ 那样长大。" $i$ 的模是 1，乘多少次长度都不变，只会在 $1,i,-1,-i$ 四格里打转（周期 4）。想让它长大，得乘模大于 1 的数。

**误区三**："你以为'辐角相加'超过 360 度就坏了。" 相加后转过头了就再绕一圈而已——辐角本来就是多值的（上一课选读），定律照常成立。

:::

**练习 2**：为什么"乘以 $i$"恰好是逆时针转 90°？

<details>
<summary>点开查看逐步解答</summary>

$i$ 的模为 1、辐角为 90°。乘法让模长相乘（$|z|\times1=|z|$，长度不变）、辐角相加（$\arg z+90°$，方向左转直角）——合起来就是纯旋转。

代数上同样可验：$(a+bi)\cdot i = ai+bi^2 = -b+ai$，即 $(a,b)\mapsto(-b,a)$，正是 90° 旋转的坐标公式。顺带一提：线性代数里的**旋转矩阵** $\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ 作用在向量 $(a,b)$ 上给出的也是 $(-b,a)$——矩阵乘法与复数乘法是同一件事的两套语言。
</details>

**练习 3**：口算 $i^{2026}$ 与 $i^{-1}$，说清用了哪条性质。

<details>
<summary>点开查看逐步解答</summary>

$i^{2026}$：$2026 \bmod 4 = 2$，转两格得 $-1$（也可以写成 $(i^2)^{1013}=(-1)^{1013}=-1$）。

$i^{-1}$：除以 $i$ 就是"倒着转一格"，得 $-i$；验算 $i\cdot(-i)=-i^2=1$ ✓，确实互为倒数。负指数在这里不是缩小，而是**反向旋转**。
</details>

## 7. 选读：欧拉公式一眼看穿乘法定律

<details>
<summary>选读 · 和角公式的免费赠品</summary>

用欧拉公式把两个极形式写成指数：

$$zw = r_1e^{i\theta_1}\cdot r_2e^{i\theta_2} = r_1 r_2\, e^{i(\theta_1+\theta_2)}$$

同底数幂相乘、指数相加——初中规则原封不动，两条定律一步到位。

再把两边同时展回三角形式对照左边 $(a+bi)(c+di)$ 的展开式，比较实部与虚部，还能白捡两条**和角公式**：

$$\cos(\theta_1+\theta_2)=\cos\theta_1\cos\theta_2-\sin\theta_1\sin\theta_2, \qquad \sin(\theta_1+\theta_2)=\sin\theta_1\cos\theta_2+\cos\theta_1\sin\theta_2$$

第 7 章硬记过的公式，原来是"辐角相加"换了件衣服。复数把指数、三角形、旋转缝成了同一块布。

</details>
