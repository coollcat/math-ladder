# 虚数单位 i：给负数开平方

## 1. 从一个场景开始

1545 年，意大利数学家卡尔丹诺遇到一道题："把 10 分成两部分，使两部分乘积为 40。"设一部分是 $x$，另一部分就是 $10-x$，用求根公式解到一半，根号里冒出 $-60$——按当时的常识，**负数没有平方根**，此路不通。

卡尔丹诺硬着头皮把"不可能的量"写进书里，自称是在"精神的折磨"中完成的。这道墙一堵就是三百年：$x^2=-1$ 到底能不能有解？

## 2. 直觉解释

这种尴尬我们不是第一次见，而每一次的破局方式都一样——**发明新的数**：

- 自然数里问 $3-5=?$ 无解 → 发明负数，问题消失；
- 整数里问 $3\div 4=?$ 无解 → 发明分数，问题消失；
- 现在轮到"负数的平方根"无解 → 老办法：再造一个。

关键转念在这里：不是数学出了错，而是**数轴这条一维的线太窄了**。所有实数都排在同一条线上，"平方为负"的数在这条线上根本没有立足之地。所以新来的 i 不是"虚构的怪物"，而是一把**升维钥匙**——转动它，数的舞台将从一条线展开成一个平面（下一课就铺这块平面）。

## 3. 正式定义

$$i^2 = -1$$

平方恰好等于 $-1$ 的新数 $i$，称为**虚数单位**。有了它，形如 $a+bi$ 的数叫**复数**：

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $i$ | 虚数单位 | 满足 $i^2=-1$ 的新数 |
| $a+bi$ | 复数 | 实部与虚部搭出的数，如 $3+4i$ |
| 实部 | $\mathrm{Re}$ | $a+bi$ 里的 $a$ |
| 虚部 | $\mathrm{Im}$ | $a+bi$ 里乘在 $i$ 前面的 $b$ |

运算规则只有一条：**把 i 当普通字母参与加减乘除，途中每出现一次 $i^2$ 就换成 $-1$**。比如 $(3i)^2 = 9i^2 = -9$。

## 4. 分步例题

**例 1**：解 $x^2 = -9$。

1. 两边开方：$x = \pm\sqrt{-9}$；
2. 把负号提出来：$\sqrt{-9}=\sqrt{9}\cdot\sqrt{-1}=3i$；
3. 结论：$x=\pm 3i$——两个根都住进了数轴之外的新大陆。

**例 2**：手算 $(1+i)^2$。

1. 当普通二项式展开：$(1+i)^2 = 1 + 2i + i^2$；
2. 遇到 $i^2$ 换成 $-1$：$= 1 + 2i - 1$；
3. 合并：$= 2i$。注意实部竟被吃光了——这是后面"旋转"故事的第一个伏笔。

## 5. 动手实验

Python 从出生起就内置了这套运算，一个库都不用导入。

先把 $i$ 放进复平面看一眼——它就是"从 1 向上转 90°"的那一步。拖动黑点转到 $(0,-1)$，你就找到了共轭 $\bar{i}=-i$：

### 实验 1（python）：虚数直接能算

```python title="Python 里虚数直接能算"
# 1j 是 Python 的虚数单位字面量：j 是工程师的习惯写法，对应数学课本里的 i
print(1j * 1j)               # (-1+0j)：括号里是「实部+虚部j」，正是 i² = -1

# 一般复数写成「实部+虚部j」，比如 1+2j；乘法自动按展开式合并
print((1 + 2j) * (1 + 2j))   # (-3+4j)：对照手算 1 + 4i + 4i² = -3 + 4i

# .real 取实部、.imag 取虚部（imaginary 的缩写），结果都是普通的 float
print((1 + 2j).real)         # 1.0
print((1 + 2j).imag)         # 2.0
```

两个细节：Python 用 **j** 不用 i（字母 i 早就被循环变量占用了）；输出格式 `(-3+4j)` 就是"实部+虚部j"的括号记法，虚部为 0 时也会写出来（`(-1+0j)`）。

### 实验 2（python）：i 的幂转圈圈——一台四格时钟

乘法登场。先玩最简单的一条：拿 i 连乘自己，看看各次幂落在哪：

```python title="i 的幂：每四步回到原地"
# sliders: p=1 [1:12:1]

z = 1j ** p                # ** 幂运算对复数同样适用：1j ** p 就是连乘 p 个 i
print(f"i^{p}: 实部 {round(z.real)}，虚部 {round(z.imag)}")
print(f"指数 {p} 除以 4 余 {p % 4}")   # % 取余（第 10 章的老朋友）负责解释周期
```

怎么玩：把滑杆从 1 拖到 12，读数按 $i \to -1 \to -i \to 1$ 打转，**周期恰好是 4**。问 $i^{2026}$ 等于几？根本不用连乘 2026 次——只问 $2026 \bmod 4$ 余几：余 2，转两格，答案 $-1$。第 10 章的四格挂钟在虚数世界里原样复活；下一课铺开复平面后你会看到，这四格其实是圆上的四个停靠点。

```quiz
- 写 1j [*]

```

:::warning[常见误区]

**误区一**："你以为 i 是数学家凭空捏造的假数。" 其实每个扩数时代都挨过骂：负数被叫过 absurde（荒谬）、无理数的传说里有人被扔下船。判断一个数该不该存在，标准是**自洽且有用**——如今 i 是量子力学与电路工程的日常用语。

**误区二**："你以为 Python 里直接写 i 就是虚数。" 裸写的 i 只会触发 NameError，或者更糟——悄悄撞上你自己的循环变量。虚数单位的官方写法是 `j`，且必须挂在数字后面（`1j`）。

**误区三**："你以为 $\sqrt{a}\cdot\sqrt{b}=\sqrt{ab}$ 对所有数成立。" 这条规则只保证对非负数合法！套用到负数会得出 $(\sqrt{-1})^2=\sqrt{(-1)(-1)}=\sqrt{1}=1$ 的鬼话，正确答案是 $i \cdot i = -1$。进入复数世界后，旧公式的适用范围要重新核对。

:::

**练习 2**：方程 $x^2=-1$ 有两个根 $i$ 和 $-i$。那到底谁是"真正的"$\sqrt{-1}$？

<details>
<summary>点开查看逐步解答</summary>

都是，而且**无法区分**。给 i 和 −i 各建一套运算系统，两边的一切定理逐字相同——没有任何实验、任何计算能把它们分辨开。选哪个当"正方向"纯粹是记号约定，就像数轴往右为正是约定一样。这种对称性恰恰说明复数世界比实数世界更匀称：$\sqrt{-1}$ 有两片叶子，而 $\sqrt{9}$ 在正数范围内只有一片。
</details>

## 7. 选读：一个"虚构"概念的三百年翻身史

<details>
<summary>选读 · 从"精神折磨"到登堂入室</summary>

1545 年卡尔丹诺写下"不可能的量"，仅供演算过关使用；
1637 年笛卡尔给这类数起了贬义名字 **imaginary**（想象的）——"虚数"这口锅从此背到现在；
1777 年欧拉引入记号 i，运算规则逐渐清晰；
1799 年高斯证明**代数基本定理**：任何 $n$ 次多项式方程在复数范围内恰有 $n$ 个根——也就是说，把 i 收编之后，代数从此**不再有解不出的方程**，这就是本章导语说的"闭合"。
最后补一刀几何解释（韦塞尔、阿尔冈、高斯）：把复数画成平面上的点，一切怪异瞬间落地生根——这正是下一课的内容。

</details>
