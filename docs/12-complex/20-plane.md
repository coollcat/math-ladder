# 复平面与共轭：给 i 铺一块地皮

## 1. 从一个场景开始

上一课说数轴"太窄"，装不下 $3+4i$。窄在哪？数轴只有**左右**一个方向。那就再让出一个方向：横的留给全体实数（老住户），竖的新盖一排——纯虚数街 $bi$。两轴交叉，每个复数就都有了精确的门牌号。

这块新地皮叫**复平面**。它不只是画图好看——共轭、模长、加法，全都将在上面露出真面目。

## 2. 直觉解释

把复数 $z = a + bi$ 画成点 $(a, b)$：

- **横轴**叫实轴，住着所有实数（虚部为 0 的复数）；
- **纵轴**叫虚轴，住着 $bi$ 这样的纯虚数。

三个动作立刻有了画面：

1. **照镜子**：$z = a+bi$ 沿实轴上下翻个面，得到 $a - bi$，记作 $\bar{z}$，读"z 共轭"。镜子就是实轴。
2. **量距离**：从原点到 $(a,b)$ 的直线距离是多少？勾股定理 $\sqrt{a^2+b^2}$——第 5 章的老朋友直接回归，这个距离叫**模长** $|z|$。
3. **走位移**：两个复数相加，就像平面上走两段位移：实部加实部、虚部加虚部，落点是"先走 z 再走 w"的终点——加法就是**平移**。

## 3. 正式定义

$$z = a+bi \;\leftrightarrow\; (a,\,b), \qquad \bar{z} = a-bi, \qquad |z| = \sqrt{a^2+b^2}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| 实轴 Re | 横轴 | 虚部为 0 的点组成，全体实数 |
| 虚轴 Im | 纵轴 | 实部为 0 的点组成，形如 $bi$ |
| $\bar{z}$ | 共轭复数 | 沿实轴镜像：虚部变号 |
| $\lvert z\rvert$ | 模 | $z$ 到原点的距离，$\sqrt{a^2+b^2}$ |

加法逐分量进行：$(a+bi)+(c+di) = (a+c)+(b+d)i$。

## 4. 分步例题

取 $z = 3+4i$：

1. 找位置：点 $(3,4)$ 在第一象限；
2. 求共轭：沿实轴往下翻 → $\bar{z} = 3-4i$；
3. 求模长：$|z|=\sqrt{3^2+4^2}=\sqrt{25}=5$——**3-4-5 直角三角形**又立功了；
4. 加法演示：$(3+4i)+(1-2i) = 4+2i$，落点向右挪 1、向下挪 2，标准的平移。

## 5. 动手实验

### 实验 1（viz）：拖着点逛复平面

```viz
{
  "type": "complexplane",
  "z": [1.5, 1]
}
```

怎么玩：拖动紫色 z 点满场跑。白色虚点是共轭 $\bar z$，永远贴着实轴与你镜像同步；紫色虚线圆的半径就是模长 $|z|$——注意无论怎么拖，圆始终穿过你的点。右上角按钮切换读数风格，「极形式」那一档下一课正式开讲，这里先混个脸熟。

### 实验 2（python）：abs() 升级了

```python title="abs() 遇上复数：求的是模长"
import math

z = 3 + 4j

# abs() 对实数是求绝对值；遇上复数它升级成"求模长"——到原点的距离
print(abs(z))                        # 5.0

# 手工验证：勾股定理 √(3²+4²)。math.hypot 是第 5 章引入的两边算斜边工具
print(math.hypot(z.real, z.imag))    # 5.0 —— 与 abs 一致

# .conjugate() 返回共轭复数：虚部变号，实部不动
print(z.conjugate())                 # (3-4j)

# 加法逐分量进行：像走两段位移
w = 1 - 2j
print(z + w)                         # (4+2j)
```

`abs` 我们早就认识，但它在复数上的这个新身份要专门记住：**对复数用 abs，得到的是模长 float**。

### 快问快答

```quiz
z = -2 + 3i 的共轭是？
- 2 - 3i
- -2 - 3i [*]
- 2 + 3i
? 共轭只翻虚部的符号，实部原地不动：-2 + 3i 沿实轴照镜子得 -2 - 3i。
```

:::warning[常见误区]

**误区一**："你以为 $|z|$ 就是'去掉负号'。" 那只是绝对值在一维上的特例。复数的模长是**到原点的直线距离**，永远非负；对 $-3-4i$ 和 $3+4i$ 它给出同一个值 5。

**误区二**："你以为共轭是实部虚部都变号。" 只有虚部变号——镜像线是**实轴**。$-2+3i$ 的共轭是 $-2-3i$，不是 $2-3i$。后者是关于原点的中心对称，另一回事。

**误区三**："你以为虚轴上的点不算'真正的数'。" 纯虚数 $3i$ 是复数家族的正式成员；实数只是虚部为 0 的特例。第 10 课已经说过：判断标准是自洽且有用，不是"看着眼熟"。

:::

## 6. 练习

**练习 1**：算出 $z=3+4i$ 到原点的距离。代码能跑，但结果不对，改到通过：

```exercise
# @title: 练习：z 离原点多远
# @check: 5.0
# @hint: 实部加虚部可不是距离！把整个 z 直接交给 abs()，它会返回模长
z = 3 + 4j

# 错误版本：把「实部 + 虚部」当成了模长（能跑，但答案离谱）
print(z.real + z.imag)
```

**练习 2**：不查任何资料，计算 $z\cdot\bar{z}$，你发现了什么？

<details>
<summary>点开查看逐步解答</summary>

展开：$(a+bi)(a-bi) = a^2 - (bi)^2 = a^2+b^2$——虚数部分全部消光，剩下一个正实数，而且恰好是 $|z|^2$！以 $3+4i$ 为例：$(3+4i)(3-4i)=9+16=25=5^2$。

"乘上自己的共轭就变成实数"是复数世界最常用的消虚部技巧，傅里叶章节里能量、振幅的计算全靠它。
</details>

## 7. 选读：共轭的三条好性质

<details>
<summary>选读 · 镜子不改变结构</summary>

共轭操作有三条恒等式，全部可以用展开验证：

1. $\overline{z+w}=\bar z+\bar w$——先加后照镜，等于先照镜后加；
2. $\overline{z\cdot w}=\bar z\cdot\bar w$——乘法同样与镜子交换顺序；
3. $|z|=|\bar z|$——镜子当然不改变到原点的距离。

前两条合起来说：共轭是复数世界的"对称变换"，它与加减乘除和平共处。第三条在模长估计里天天出场。将来学傅里叶变换时，"取共轭"会是你最顺手的扳手之一。

</details>
