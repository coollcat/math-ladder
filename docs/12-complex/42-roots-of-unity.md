# 单位根：乘法的循环舞蹈

## 1. 从一个场景开始

[复数乘法那一课](./40-multiplication.md)的实验 2 里有个小发现：连乘 $i$，每四步恰好回到 $1$——$1 \to i \to -1 \to -i \to 1$，像一座四格钟。换成连乘 $e^{i\pi/3}$ 呢？六步回原点。这些"转几步就回家"的数不是巧合，它们是一个家族。

这一课回答一个收束性的问题：**在复平面上，哪些数连乘自己 $n$ 次恰好回到 $1$？** 答案会像正多边形一样把单位圆均分——乘法即旋转的故事，在这里跳完最圆的一支舞。

## 2. 直觉解释：舞池上的 n 位舞者

把复平面想成舞池，[单位圆](./30-euler.md)是舞池中央的圆形跑道。乘法的铁律（40 课）：**模长相乘、辐角相加**——乘一个数，就是"伸长/缩短 + 转个角"。

想连乘 $n$ 次回到 $1$，两个条件立刻浮出水面：

- **模长必须正好是 $1$**。模大于 1 越乘越肥、小于 1 越乘越瘦，都回不到 1——所以候选人全体住在单位圆上，是"纯转身、不变形"的舞者；
- **每步的转角必须是整圈的 $n$ 分之一**。转角 $\theta$ 连加 $n$ 次要凑成整圈（或若干整圈）：$n\theta = 360° \times k$。

于是满足条件的数就是：**从 1 号位出发、每步恰好转一整圈的 $n$ 分之一的所有倍数**。它们站在 $0°, \frac{360°}{n}, \frac{2\times360°}{n}, \ldots$ 上——正好把圆周均分成 $n$ 份，站出一个**正 $n$ 边形**。$n$ 位舞者，一圈站满，谁都不多站、谁都不缺席。

## 3. 正式定义

**$n$ 次单位根**：满足 $z^n = 1$ 的复数。它恰有 $n$ 个解：

$$z^n = 1 \iff z = e^{2\pi i k / n}, \qquad k = 0, 1, 2, \ldots, n-1$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $z^n$ | 复数的 $n$ 次幂 | 同一个数连乘 $n$ 次（模长 $n$ 次方、辐角 $n$ 倍） |
| 单位根 | 本课主角 | $z^n = 1$ 的解，全体站在单位圆上 |
| $k$ | 舞者的编号 | 第 $k$ 位舞者从 $1$ 出发转了 $k$ 个基本步 |
| $w = e^{2\pi i / n}$ | 基本步 | 每步转一整圈的 $n$ 分之一；其余舞者全是它的幂 $w^k$ |

为什么解恰好是这 $n$ 个？欧拉公式（30 课）把单位圆上的点写成 $e^{i\theta}$，于是 $z^n = e^{in\theta}$；它要等于 $1 = e^{2\pi i \cdot k}$（转整数圈都回到原地），即 $n\theta = 2\pi k$。$k$ 是整数，但只有 $k = 0, 1, \ldots, n-1$ 给出**不同**的落点——第 $n$ 个步子就转回 $1$ 了。

## 4. 分步例题：三次单位根点名

**例**：解 $z^3 = 1$，找出全部三个解。

1. 定模长：$|z|^3 = |z^3| = 1$，而模是正数，故 $|z| = 1$——舞者必须上跑道；
2. 化极形式：$z = e^{i\theta}$（欧拉公式），则 $z^3 = e^{3i\theta}$；
3. 列条件：$e^{3i\theta} = 1$ 要求 $3\theta = 360° k$，即 $\theta = 120° k$；
4. 点名：$k=0$ 给 $z = 1$；$k=1$ 给 $\theta = 120°$，即 $-\dfrac12 + \dfrac{\sqrt3}{2}i$；$k=2$ 给 $\theta = 240°$，即 $-\dfrac12 - \dfrac{\sqrt3}{2}i$；
5. 验算：第二位舞者转三次 $= 360°$，模长 $1^3 = 1$——回到 $1$ ✓；三位舞者的站位恰好是正三角形。

顺手记一个彩蛋：三枚均分圆周的箭头首尾相接，合力为零——$1 + w + w^2 = 0$（练习 2 给两套证明）。

## 5. 动手实验

### 实验 1（viz）：舞池点名器

怎么玩：拖动圆上的点读出辐角。试试把点拧到 $60°, 120°, 180°, 240°, 300°$——这五个落点加上起点 $1$，就是六次单位根的完整名单（正六边形）；再拧到 $72°, 144°, \ldots$ 看五边形怎么站。感受一下"均分圆周"的强迫症式对称。

### 实验 2（python）：六位舞者巡礼

```python title="n=6：每位舞者连乘 6 次都回家"
import math

n = 6                                  # 先办六次单位的舞会
step = 2 * math.pi / n                 # 基本步：一整圈的六分之一（弧度）
for k in range(n):                     # k 从 0 走到 5：六位舞者逐个点名
    ang = k * step                     # 第 k 位舞者的转角：k 个基本步
    z = math.e ** (1j * ang)           # e^(iθ) 上跑道（欧拉公式的机器）
    zpn = z ** n                       # 连乘 n 次：和 1 比一比
    print(f"k={k}: 圆上位置 {round(z.real, 3)} {round(z.imag, 3)} | 离家距离 {round(abs(zpn - 1), 6)}")
```

六行输出，$k=0$ 到 $5$ 的圆上位置恰好是 $60°$ 步长的六边形顶点，最后一列离家距离**全部**打印 $0.0$——六位舞者连乘六次，人人回家（浮点世界判等不能直接写 `==`，量"离家距离"才是规矩，16 章会正式立约）。把 $n$ 改成 $5$ 或 $7$ 再跑：人数变了、队形变了，"全员回家"一条不少。

### 实验 3（python）：24 个候选角，谁有资格

```python title="每 15 度设一个检查站，筛出真正的单位根"
import math

n = 12                                  # 检验十二次方
qualified = []                          # 合格角度的名单
for d in range(0, 360, 15):             # 每 15 度设一个检查站：共 24 个候选
    z = math.e ** (1j * math.radians(d))   # radians 把度换算成弧度（第 7 章的翻译官）
    zpn = z ** n
    if abs(zpn - 1) < 1e-9:             # 1e-9 即十亿分之一：与 1 的距离比这更小才算回家
        qualified.append(d)             # append：把合格角度收进名单
print(qualified)
print(360 / n)                          # 理论步长：合格名单应当按它均分圆周
```

24 个候选里只有 12 个过关：`[0, 30, 60, 90, 120, 150, 180, 210, 240, 270, 300, 330]`——正好每 $30°$ 一个，正十二边形站满圆周。像 $15°$ 这种"半步"候选，转 12 次只到 $180°$（$-1$），回不了家，当场落选。


::::warning[常见误区]

**误区一**："你以为 $z^n = 1$ 只有 $z = 1$ 一个解。" 在实数里确实只有它；但复平面上模 1 的候选遍布圆周，凡转角是整圈 $n$ 分之一整倍数的全是解——一开口就是 $n$ 个。

**误区二**："你以为每个单位根的辐角只此一个答案。" $120°$ 与 $-240°$ 是同一位舞者（辐角多值，25 课选读讲过）。$k$ 从 0 到 $n-1$ 数一遍，只是给 $n$ 位舞者各发一张身份证，不是名单比人多。

**误区三**："你以为单位根连乘若干次会跑出圆外。" 模长恒为 1，乘多少次长度都不变——它永远在跑道上转圈。会"越滚越大"的是模大于 1 的数，与本家族无关。

::::

## 6. 练习

**练习 1**：求六次单位根里的"基本步" $w = e^{2\pi i/6}$，验证 $w^6 = 1$。下面的代码能跑但结果不对，修到通过：

```exercise
# @title: 练习：六步回原点的基本步
# @check: 0.5 0.866
# @check: 0.0
# @hint: 每步应转一整圈的六分之一：2π/6 弧度，现在少乘了一个 2；检验行用 abs(home - 1) 量"离家距离"（浮点不能直接判等）
import math

step = math.pi / 6               # ← 每步的转角：量一量这是整圈的几分之一
w = math.e ** (1j * step)

print(round(w.real, 3), round(w.imag, 3))
home = w ** 6
print(round(abs(home - 1), 6))   # 与 1 的距离：0.0 才算真的回到家
```

**练习 2**：三次单位根满足 $1 + w + w^2 = 0$。用几何和代数各给一套证明。

<details>
<summary>点开查看逐步解答</summary>

几何：三枚箭头 $1, w, w^2$ 分别指向 $0°, 120°, 240°$——均分圆周。把它们首尾相接：每走一枚就左转 120° 接上下一枚，三步正好闭合回起点，画出一个等边三角形。闭合回路意味着位移总和为零，合力自然是零。

代数：$w \neq 1$ 且 $w^3 = 1$，于是乘开验算 $(w - 1)(1 + w + w^2) = w^3 - 1 = 0$。两个数相乘得零、而 $w - 1 \neq 0$，只能是 $1 + w + w^2 = 0$。三枚均分箭头的"合力为零"，原来是因式分解的一个化身。
</details>

**练习 3**：$-1$ 和 $i$ 分别是几次单位根？$-1$ 什么时候能挤进 $n$ 次单位根的名单？

<details>
<summary>点开查看逐步解答</summary>

$(-1)^2 = 1$：负一是**二次**单位根，站位在 $180°$（正二边形就是一条来回的线段）。$i^4 = 1$：$i$ 是**四次**单位根（$90°$ 步，正四边形）。至于 $-1$ 何时入选 $n$ 次名单：需要 $(-1)^n = 1$，即 $n$ 是**偶数**——六次、八次舞会上它都在（$180°$ 恰是整圈的偶分之几）；奇数次舞会它永远缺席。对照实验 3 的名单：$n=12$ 时 180° 顺利过关，正是这个道理。
</details>

## 7. 选读：为什么恰好 n 个解，一个不多

<details>
<summary>选读 · 模运算的回声</summary>

条件 $n\theta = 360° k$ 里 $k$ 是任意整数，看似有无穷多组答案，但落点由 $\theta \bmod 360°$ 说了算——第 10 章的模运算在此回声：$k$ 与 $k + n$ 相差的转角是 $360°$，落在同一点上。所以不同舞者至多 $n$ 位；又因为 $k = 0, 1, \ldots, n-1$ 的转角互不相同（间隔 $360°/n$ 大于零），恰好 $n$ 位。不多、不少、不重复。

对照实数世界更见反差：在数轴上，"$1$ 开 $n$ 次方"只有 $1$ 一个答案（负数连偶次方根都没有，04 章判别式的老悬念）。升到复平面，同一个问题一下子开出 $n$ 朵花——**维度给方程松了绑**。这 $n$ 位舞者日后还要正式上岗：第 16 章傅里叶变换把信号按频率分班时，本质上是让采样点站上单位根的均分圆周。

</details>
