# 复数与欧拉公式——让代数闭合的最后一块拼图

数学家克罗内克放过一句狂话："上帝创造了整数，其余都是人造的。"照这个标准，本章主角大概是"人味"最重的一种数：它不是被发现的，而是被**逼出来的**——方程 $x^2=-1$ 在实数里无解，数学家硬是造了一个新数出来。

造出来之后，意外一个接一个：

- 三次方程的求根公式明明只涉及实数根，中间却**必须**路过负数的平方根才算得下去；
- "乘一个数"突然有了画面：可以是旋转，也可以是伸缩；
- 增长之数 e 与圆上的 cos、sin 被一条公式焊在一起，被称为"数学中最美的公式"。

如今这门学问早已不只是解方程的工具：**量子力学**的基本方程里全是它，**交流电路**工程师靠它算阻抗，第 16 章的**傅里叶变换**更是从头到尾用它说话。复数不是傅里叶枢纽的花瓶，而是主干道。

这一章你会拿到七件工具：

1. [虚数单位 i](./10-i.md)——三百年"不可能的量"，其实是一把升维钥匙；
2. [复平面与共轭](./20-plane.md)——数轴装不下，就铺一个平面；
3. [模、辐角与极形式](./25-polar.md)——用"方向 + 距离"给每个点换一套门牌号；
4. [欧拉公式](./30-euler.md)——e 的出生证明，以及 e^(iθ) = cosθ + i·sinθ；
5. [复数乘法＝旋转＋伸缩](./40-multiplication.md)——辐角相加、模长相乘；
6. [单位根：乘法的循环舞蹈](./42-roots-of-unity.md)——z^n = 1 的解均分单位圆，正 n 边形站上舞池；
7. [相量法：交流电路的复数语言](./45-phasors.md)——乘法即旋转开进交流电路，同频正弦合成三步收工；vecadd 里拖两枚相量看第三条边。

学完这章你会发现："数"从来不是一条线，而是一个平面；而且你将亲眼见到五大常数同框的那一幕。

## 实战挑战 · 一台设备的复阻抗体检

> 改编自大学电工基础经典题型（RLC 串联电路的复阻抗法），情境原创

家里的电器接在 220 V 交流电源上。电阻、电感线圈、电容对交流电的"阻挡本事"各不相同，工程师干脆把三者和成一个复数——**复阻抗**。对 R、L、C 的**串联**组合，题面直接给出所需公式：

$$Z = R + (X_L - X_C)\,j$$

其中 $R$ 是电阻（欧姆），$X_L = \omega L$ 叫**感抗**、$X_C = \dfrac{1}{\omega C}$ 叫**容抗**（都是正数，单位欧姆；$\omega$ 是交流电的角频率）。电工用 $j$ 而不用 $i$，免得和电流记号打架——Python 里恰好也写 $1j$。这个复数的**模长** $\lvert Z \rvert$ 管"总共挡了多少"，**辐角**管"电压超前电流多少"。

某小设备的串联模型实测：$R = 3\ \Omega$，$X_L = 9\ \Omega$，$X_C = 5\ \Omega$。

**(a)** 写出复阻抗 $Z$，并求它的模长 $\lvert Z\rvert$。
**(b)** 电源电压有效值 $U = 220$ V，电流有效值满足欧姆定律的推广版 $I = U / \lvert Z\rvert$（这里是普通的实数除法）。求 $I$。
**(c)** 思辨：调节频率让感抗恰好等于容抗时，虚部归零、$Z$ 只剩纯电阻。这时电路发生了什么？

下面的代码能跑，但第一行公式里藏着一个经典符号错——修到三行输出全部正确：

```exercise
# @title: 实战挑战：算出这台设备的复阻抗
# @check: (3+4j)
# @check: 5.0
# @check: 44.0
# @hint: 感抗和容抗在虚轴上是死对头——虚部该是 XL 减 XC，不是相加！改对 Z 之后，后两行会自动跟着变对
R = 3      # 电阻：3 欧姆
XL = 9     # 感抗 ωL：9 欧姆
XC = 5     # 容抗 1/(ωC)：5 欧姆
U = 220.0  # 电源电压有效值：220 伏

Z = R + (XL + XC) * 1j   # ← 复阻抗公式：检查虚部的加减号！
print(Z)
print(abs(Z))            # abs 对复数返回模长（复平面课的老朋友）
print(U / abs(Z))
```

```quiz
调节频率使感抗恰好等于容抗时，虚部归零、总阻抗只剩纯电阻。这时电路发生了什么？
- 断路：虚部没了，电流也跟着消失
- 谐振：阻抗降到最小，电流冲到最大 [*]
- 不变：实数和复数算出来一样
? 虚部抵消后 |Z| 只剩 R，比任何带电抗的时候都小，220 V 下电流达到最大值——这叫串联谐振。收音机拧台选频，拧的就是这个谐振点。
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 套公式：$Z = 3 + (9-5)j = 3+4j$。模长用勾股定理（或直接交给 `abs`）：$\lvert Z\rvert = \sqrt{3^2+4^2} = 5\ \Omega$——3-4-5 直角三角形在电路里又立功了。

**(b)** 电流有效值：$I = U/\lvert Z\rvert = 220/5 = 44$ A。

顺手把辐角也算出来：$\varphi = \arctan\dfrac{4}{3} \approx 53.1°$（用极形式一课的 `atan2(4, 3)` 一查便知）——电压的相位超前电流约 53 度，这是感性电路的指纹。用 Python 验算模长与电流：

```python
import math

R, XL, XC, U = 3, 9, 5, 220.0

Z = R + (XL - XC) * 1j    # 复阻抗：感抗减容抗
print(Z)                  # (3+4j)
print(abs(Z))             # 模长 5.0：总共挡了多少
print(U / abs(Z))         # 44.0 安培：欧姆定律的复数推广版
```

**(c) 谐振**。当 $X_L = X_C$ 时虚部抵消，$Z = R$ 达到全程最小值，于是同样电压下电流最大——这个现象叫**串联谐振**。收音机的调台旋钮就是在改变频率（或电容），让电路的谐振点对准某个电台的载波频率：对准的电台信号被放大得最响，其余频率的信号被甩在身后。一个虚部的正负号，撑起了整个无线电台的选择器。

</details>

## 实战挑战 · i² = −1 的符号账

复数乘法 $(3+4i)(1-2i)$ 展开后，交叉项 $-8i^2$ 因为 $i^2=-1$ 要变成 $+8$。下面这题把这笔账算反了，修到输出 `11 -2`：

```exercise
# @title: 实战挑战：i² = -1 的符号账
# @check: 11 -2
# @hint: 交叉项 4i·(-2i) = -8i²，而 i² = -1，所以 -8i² = +8。
re = 3 * 1 + 4 * (-2)    # ← 问题在这：-8i² 应得 +8，不是 -8
im = 3 * (-2) + 4 * 1
print(re, im)
```

<details>
<summary>点开查看逐步解答</summary>

$(3+4i)(1-2i) = 3 - 6i + 4i - 8i^2$，而 $i^2 = -1$，所以 $-8i^2 = +8$：

```python
re = 3 * 1 - 4 * (-2)    # 3 - 8·(-1) = 3 + 8 = 11
im = 3 * (-2) + 4 * 1    # -6 + 4 = -2
print(re, im)            # 11 -2
```

初始代码把 $i^2$ 当成 $+1$，实部算成 $3-8=-5$。改对符号后实部 $11$、虚部 $-2$。这一笔"$i^2=-1$"的账，正是复数乘法与实数乘法唯一的差别，也是本章欧拉公式能"瘦身"傅里叶变换的根源。

</details>
