# 相量法：交流电路的复数语言

## 1. 从一个场景开始

调音台上两条音轨同时推起：第一路吹出一列纯净的正弦波 $u_1(t) = 3\sin(\omega t)$；第二路调子完全相同，只是整体**提前了四分之一周期**：$u_2(t) = 4\sin(\omega t + 90^\circ)$。混到一起的合体波形，峰值是几？

逐时刻硬加当然可以（第 5 节真会这么验一次），但每做一步都要展开两个不同相位的正弦、再用和角公式归拢同类项。电网工程师面对的可是几十台带相位的发电机并网，这样的题每天成百上千道——硬算会疯。他们的办法出奇地优雅：**整个问题搬家，离开时间的世界，去复平面上算账**。搬运工就是乘法课那台机器——乘法即旋转。

## 2. 直觉解释

第 7 章在单位圆上见过这个画面：一枚箭头钉在原点匀速逆时针转，影子投在竖直墙上摆动——那正是标准正弦波。倒过来读就得到新眼光：**每一列 $A\sin(\omega t+\varphi)$ 波，都是一枚长度为 $A$、初始朝向 $\varphi$ 的箭头匀速旋转时投下的影子**。振幅管高矮、初相管起跑位置、频率管转多快，一张"放映机图纸"三个旋钮全齐了。

关键观察来了。两列波**同频**，意味着两枚箭头转速完全相同——它们之间的夹角永远不变，像两辆并排同速行驶的车。既然相对姿态是永恒的，我们干脆把电影胶片剪掉，只保留一张**定格照片**（取 $t=0$ 那一瞬间）：照片上每枚箭头只剩"长度 + 角度"两个数字，恰好构成一个复数的极形式！频率 $\omega$ 人人有份且人人相同，就从账本里整体约掉了。

于是一整套翻译合同成立：

- 时间世界里的同频正弦相加 ↔ 复平面上向量首尾相接；
- 相位提前 $90^\circ$ ↔ 相量原地转四分之一圈。

和角公式整包退货，剩下的只是复数四则运算。

## 3. 正式定义

**定义（相量）**：对固定角频率 $\omega$ 的正弦稳态信号 $u(t)=A\sin(\omega t+\varphi)$，它的**相量**是复平面上的定格照片

$$\dot{U} = A\angle\varphi = A(\cos\varphi + j\sin\varphi)$$

顺带认个门：数学课本把虚数单位写成 $i$，电工改叫 $j$——因为 $i$ 已经被电流占用；而 Python 的复数后缀恰好也叫 $j$（比如 `3+4j`），两边无缝衔接。乘法课验证过的"乘 $i$ 即转 $90^\circ$"，从本课起换工装登场。

| 三角世界 | 复数世界 | 一句话理由 |
| --- | --- | --- |
| 同频正弦相加 | 相量按复数加法合并（实部配实部、虚部配虚部） | 照片上的向量平行四边形 |
| 相位提前 $90^\circ$ | 乘以 $j$ | 模 1、辐角 $90^\circ$：纯转身不变形 |
| 对时间求导 | 乘以 $j\omega$ | 第 8 节选读揭晓来历 |

第三行就是这门手艺的出生证明：电感的电压跟着电流的**变化率**走（$v=L\,\mathrm{d}i/\mathrm{d}t$），三角世界里这是"对正弦求导"，相量世界里只是"乘一个 $j\omega$"——微积分当场降维成一次乘除法。复阻抗 $Z=R+j\omega L$ 由此出生，本章实战挑战里那只设备已经用它体检过一回；第 22 章 RLC 谐振将把这把快刀磨到飞起。

## 4. 分步例题

**例**：合成开场那两路信号 $3\sin(\omega t) + 4\sin(\omega t + 90^\circ)$。

1. 化装装箱：第一路 $\leftrightarrow 3\angle 0^\circ$，第二路 $\leftrightarrow 4\angle 90^\circ = 4j$；
2. 合影相加：$3 + 4j$——$\omega$ 全程不见踪影，它只决定整幅照片转多快，不改变照片本身；
3. 读回模长（新振幅）：$\sqrt{3^2+4^2}=5$；
4. 读回辐角（新初相）：$\arctan\dfrac{4}{3}\approx 53.1^\circ$（第 25 课的门牌号机器 `atan2(4,3)` 一查便知）;
5. 翻译回时间世界：合成波形 $u(t)=5\sin(\omega t + 53.1^\circ)$；
6. 常识复核：两路峰值各自是 3 和 4，答案既不是 7 也不是 4，而是 5——第 5 章 3-4-5 直角三角形又一次现场办公。合成的相位夹在两路之间，偏向力大的那路，合理。

一句话总结：装箱（模长×辐角）→ 复数加法 → 读回（勾股 + atan2），三步全是老朋友，和角公式一克都没用。

## 5. 动手实验

### 实验 1（viz）：两张定格照片拼成一张

```viz
{
  "type": "vecadd",
  "u": [3, 0],
  "v": [0, 4]
}
```

怎么玩：蓝色箭头当相量 $3\angle 0^\circ$，橙色当 $4\angle 90^\circ$，都可用鼠标拖动；紫色对角线就是相量和。读出它头顶的长度与角度，再按"模长 = 新振幅、角度 = 新初相"翻译回波形世界。初始摆位正好复现例题的 3、4、5 三角形；随手乱拖，平行四边形法则永远替你扛着和角公式。

### 实验 2（python）：两种算法的 200 点对质

```python title="相量合成机：逐点对质三角硬算"
import math
# sliders: a=3 [0:8:1], b=4 [0:8:1]

a = 3                                    # 甲路振幅（滑杆可调）
b = 4                                    # 乙路振幅（滑杆可调）
px = a * math.cos(0) + b * math.cos(math.pi / 2)   # 相量和的实部
py = a * math.sin(0) + b * math.sin(math.pi / 2)   # 相量和的虚部
peak = math.sqrt(px ** 2 + py ** 2)                 # 勾股定理读回合成振幅
phase = math.atan2(py, px)                          # atan2 反查合成初相

print(f"合成峰值 = {round(peak, 3)}")
print(f"合成初相 = {round(math.degrees(phase), 1)} 度")

worst = 0                                 # 记录两种算法的最大分歧
for i in range(200):
    t = i / 200                           # 一个周期里均匀撒 200 个采样瞬间
    slow = a * math.sin(2 * math.pi * t) + b * math.sin(2 * math.pi * t + math.pi / 2)
    fast = peak * math.sin(2 * math.pi * t + phase)   # 相量法的预报
    gap = abs(slow - fast)
    if gap > worst:
        worst = gap                       # 冠军分歧留档
print("最大偏差 =", worst)                 # 约 10^-16：浮点尘埃级，两条路线重合
```

滑杆拧一拧：a=1、b=1 时峰值约 1.414 而不是 2，初相正好 45 度；b 拧到 0 就退化回甲路本尊。改两个数字胜过听十遍"峰值不可直接相加"。

## 6. 常见误区

:::warning[常见误区]

- **"你以为任何两列正弦都能用相量相加。"** 合同的前提是**同频**：不同频的两枚箭头相对姿态随时间变个不停，任何一张定格照片都是失真的。第 7 章见过两列不同频波叠出的"拍"，那种交集要回到三角或频域另请高明。
- **"你以为相量箭头自己在转，或者它就是波形。"** 恰好相反：转动的是箭头的影子（波形），相量本身是一张静止的定格照片。会动的是电影，相量只存剧照。
- **"你以为乘 j 是给信号放大。"** $|j|=1$，长度纹丝不动，它只负责转身。想让振幅变大得乘模长大于 1 的复数——幅度和相位在这里永远各管各的。

:::

## 7. 练习

**练习 1**：下面这台合成器能跑，但两行输出都不对——找到那个度量衡级的错，修到通过：

```exercise
# @title: 练习：两路信号合体的峰值与初相
# @check: 5.0
# @check: 53
# @hint: 先把两路各装箱成相量再相加：4∠90° 的实部贡献为零，虚部才是 4；喂给 cos 和 sin 之前，记得用 math.radians 把 90 度换成弧度。
import math

ax = 3 * math.cos(0)               # 甲路相量 3∠0° 的实部
ay = 3 * math.sin(0)               # 甲路相量的虚部
bx = 4 * math.cos(90)              # ← 能跑，但有处单位没换！
by = 4 * math.sin(90)

sx = ax + bx                       # 相量加法：实部归实部
sy = ay + by
peak = math.sqrt(sx ** 2 + sy ** 2)         # 勾股定理读回合成振幅
angle = math.degrees(math.atan2(sy, sx))    # atan2 反查合成初相（度）

print(round(peak, 1))
print(round(angle))
```

<details>
<summary>点开查看逐步解答</summary>

`math.cos(90)` 里塞进去的是 **90 弧度**而不是 90 度——三角函数家族一律吃弧度。修复一行：

```python
bx = 4 * math.cos(math.radians(90))
by = 4 * math.sin(math.radians(90))   # radians：度换弧度的翻译官
```

修正后 bx 几乎为零（直角方向的实部贡献）、by 为 4，于是 sx=3、sy=4：峰值 $\sqrt{9+16}=5$，初相 $\arctan(4/3)\approx53.13°$ 取整 53。打印逐行为 `5.0` 与 `53`。
</details>

**练习 2**：音响接线时如果把其中一路接反（这路的相位差从 $0^\circ$ 变成 $180^\circ$），用相量的语言解释为什么声音常常明显变小；什么条件下会完全不响？

<details>
<summary>点开查看逐步解答</summary>

接反一路等于给它凭空加上 $180^\circ$ 初相，相量图上就是那枚箭头掉头指向对面：$\cos(180^\circ)=-1$，相量变为原来的相反数。若两路原设计同相等幅（两张相同的定格照片），掉头后两枚箭头首尾对顶，向量和恰为零——**完全消声**。降噪耳机的原理正是如此：麦克风采集环境噪声，当场造出一列反相波喂进耳朵，让相量自己打架抵消。两路不等长时剩下的是差值箭头，音量变小但不至于全灭。一方框图的加减号，背后全是这张照片上箭头的方向。
</details>

## 8. 选读：求导凭什么变成乘 jω

> 边界说明：相量速算只在**正弦稳态**里合法——信号早已稳定振荡且全体同频。开机瞬间的暂态过程不在任何一张定格照片里；含直流成分或非正弦的波形，要等第 16 章傅里叶变换把它们拆成一队纯正弦之后再个个发相量牌照。另外先说破一个工程口径：插座上的"220 V"指的是方均根有效值而非峰值，画波形时峰值约为它的 $\sqrt2$ 倍——别拿示波器读数去找茬。

<details>
<summary>选读 · 指数函数一句话看穿微分表</summary>

欧拉公式说 $\cos\theta + j\sin\theta = e^{j\theta}$（本章 30 课）。于是任何一个相量都可以补上一个旋转因子写成 $Ae^{j\varphi}e^{j\omega t}$——它是个在复平面上匀速转圈的数，虚部正是我们研究的正弦波。

指数函数有一条下一章就给出生证明的老规矩：求导不改种，只自乘斜率，即 $(e^{j\omega t})' = j\omega\, e^{j\omega t}$（见 [sin、cos 与 e^x 的导数](../13-derivatives/40-sin-cos-exp.md)）。这条规则放进旋转的世界里读：$|\,j\omega\,|=\omega$ 说的是求导让振幅放大 $\omega$ 倍；辐角加 $90^\circ$ 说的是 cos 与 sin 花式互变的真相——原来导数公式里的相位移动，就是乘上一个纯旋转因子 $j$。反过来积分为"除以 $j\omega$"。第 22 章给 RLC 电路列方程时，微分方程会因此塌缩成一行代数，答案用普通的除法就能端出来。

</details>
