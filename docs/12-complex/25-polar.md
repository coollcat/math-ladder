# 模、辐角与极形式：方向加距离

## 1. 从一个场景开始

给人指路有两种风格。城市里说"东经 116 度、北纬 40 度"；野外更常说"往东北方向，走 500 米"。前者是直角坐标，后者是**方向 + 距离**——对复平面上的点，第二套地址同样好使，而且在乘法面前威力惊人。

这套新地址的名字：模 $r$ 管距离，辐角 $\theta$ 管方向。

## 2. 直觉解释

站在原点看复平面上的点 $z$：

- **模** $r=|z|$：从原点拉到 $z$ 的绳子有多长（上一课的勾股公式）；
- **辐角** $\theta$：这根绳子从正实轴出发**逆时针转了多少角度**（第 7 章单位圆的量角方式）。

知道 $r$ 和 $\theta$，点就唯一确定。反过来用三角函数写出坐标：

$$z = r\,(\cos\theta + i\sin\theta)$$

这叫 $z$ 的**极形式**。特别留个心眼：当 $r=1$ 时，$z=\cos\theta+i\sin\theta$ 正好是**单位圆上的点**——上一课练习埋的种子发芽了，两课之后它要开出一朵大花。

## 3. 正式定义

设 $z=a+bi$ 非零，则存在唯一的 $r>0$ 和（在约定范围内的）$\theta$ 使

$$z = r(\cos\theta + i\sin\theta), \qquad r = \sqrt{a^2+b^2}, \qquad \tan\theta = \frac{b}{a}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $r$ | 模 | $\lvert z\rvert$，到原点的距离 |
| $\theta$ | 辐角 | 从正实轴逆时针转到 z 的角 |
| 极形式 | — | 用 $(r,\theta)$ 写出的 $z$ |
| 主值 | — | 辐角的约定代表，取 $(-180°,180°]$ |

一句带过多值性：辐角转一整圈回到原地，所以 $30°$、$390°$、$-330°$ 描述的是同一个方向——它们都"对"，程序里习惯取主值。

还有个坑：$\tan\theta = b/a$ 这个比值**分不清象限**——$(1,1)$ 与 $(-1,-1)$ 的比值都是 1，可它们相差 180°。手算靠画图补救，程序里有专门的官方工具（见实验 2）。

## 4. 分步例题

把 $z = \sqrt3 + i$ 改写成极形式：

1. 求模：$r = \sqrt{(\sqrt3)^2+1^2}=\sqrt4=2$；
2. 归一化坐标：$(\cos\theta,\sin\theta)=\left(\dfrac{\sqrt3}{2}, \dfrac12\right)$——正是第 7 章表格里 **30°** 的落点；
3. 所以 $\theta=30°$（即 $\pi/6$ 弧度）；
4. 结论：$z = 2(\cos 30° + i\sin 30°)$。

验算：$2\cos30° = \sqrt3$ ✓，$2\sin30° = 1$ ✓。

怎么玩：读数变成 $r(\cos\theta°+i\sin\theta°)$ 的样子，下方同时给出模和辐角。试试三件事：(1) 把点拖到紫色虚线圆半径为 1 的位置（就是单位圆），感受 $r=1$ 的特殊感；(2) 把点拖到实轴负半轴，看辐角跳成 180°；(3) 绕原点匀速转一圈，盯着辐角读数的连续变化与 ±180° 的跳变。

### 实验 2（python）：math.atan2 与 math.degrees 的出生证明

已知坐标反查角度，需要一个新工具。先看看为什么旧工具不够用：

```python title="只用比值会迷路，atan2 来救场"
import math

# 出生证明第一步：tanθ = 虚部/实部 这个比值会迷路。
# 用第 7 章的工具算两个不同方向的 tan：
for d in [30, 210]:
    t = math.sin(math.radians(d)) / math.cos(math.radians(d))
    print(f"{d}度方向的 tan = {round(t, 4)}")
# 两行一模一样！相除这一步把象限信息弄丢了——光看比值定位不了方向

# math.atan2(虚部, 实部)：官方反查工具。收两个参数所以认得全部四个象限，返回弧度
angle_rad = math.atan2(1, math.sqrt(3))

# math.degrees() 把弧度换回度：它是 math.radians 的反操作
print(round(math.degrees(angle_rad), 1))   # 30.0
```

### 实验 3（python）：极 ↔ 直角往返机

```python title="拖动 r 和 θ，看两套门牌互换"
import math

# sliders: r=2 [0.5:4:0.5], theta_deg=30 [0:360:15]

rad = math.radians(theta_deg)

# r·cosθ 是实部，r·sinθ 是虚部的系数；1j 充当 i
back = r * math.cos(rad) + (r * math.sin(rad)) * 1j

print(back)                                        # 极形式还原出的复数
print(round(back.real, 3), round(back.imag, 3))    # 直角坐标读数：a 和 b
check_deg = round(math.degrees(math.atan2(back.imag, back.real)), 1)
print(check_deg)     # 用 atan2 反查辐角再换回度——和 θ 对一下账（往返无损）
```

怎么玩：默认 $r=2$、$\theta=30°$ 正是例题——直角坐标读出 $(1.732,\ 1.0)$，即 $\sqrt3+i$。把 $\theta$ 拖过 $180°$：最后一行突然不再等于 $\theta$，而是差了整整 $360°$——atan2 只报主值，选读讲的"跳变"现场直播。再把 $r$ 拧到 $1$：你站上了单位圆，那是下一课的主角。

### 快问快答

```quiz
反查辐角时为什么必须用 atan2(虚部, 实部)，而不是拿比值去查表？
- 因为 atan2 算得更快
- 因为比值分不清相差 180 度的两个方向 [*]
- 因为 atan2 直接返回度数
? y/x 在互为对顶的方向上取相同值（如 30 度与 210 度）。atan2 收两个参数，象限一目了然。注意它返回的是弧度。
```

:::warning[常见误区]

**误区一**："你以为一个 atan 函数吃掉比值就够了。" 相除丢象限的坑上面亲眼见了：30° 和 210° 的 tan 完全相同。`math.atan2(y, x)` 收两个参数才认得全部四个象限。

**误区二**："你以为辐角有唯一标准答案。" 30°、390°、−330° 都指向同一根绳子的方向，数学上全都合法。只有约定了主值区间，程序里的比较和判等才能进行。

**误区三**："你以为求出 θ 后直接喂给 cos/sin 就行。" `math.cos`/`math.sin` 只认**弧度**（第 7 章第一大坑）。degrees 出来的数要么先 radians 回去，要么全程留在弧度世界。

:::

**练习 2**：单位圆上所有复数的极形式有什么共同点？用一个式子概括整族点。

<details>
<summary>点开查看逐步解答</summary>

单位圆上的点满足 $r=1$，于是整族点只需要一个参数就能写全：

$$z = \cos\theta + i\sin\theta, \qquad \theta \in [0°, 360°)$$

模恒为 1，只剩角度在动——"纯旋转"家族。请记住这个式子：下一课它将改写成 $e^{i\theta}$，成为数学史上最有名的公式之一。
</details>

## 7. 选读：程序为什么偏爱主值

<details>
<summary>选读 · 无穷多答案没法判等</summary>

辐角多值不是缺陷，是几何事实：转圈本来就没起点没终点。麻烦在于程序要比较、要判等、要排序，而"无穷多个等价答案"会让这些操作全部失效。于是约定**主值**：取 $(-180°, 180°]$ 中那一个，`math.atan2` 返回的正是它（弧度版）。

代价是主值在 ±180° 处有个跳变：从正实轴上方逆时针蹭过负实轴时，读数会从 +179.9° 突然翻到 −179.9°——点几乎没动，数字却翻了天。处理连续旋转的程序（游戏引擎、机器人）都要专门写代码缝合这道缝，这个细节我们记在心里，第 16 章讲相位时会再次遇到。

</details>
