# 第 31 章专属组件规格

本文件登记章内专属组件的需求与实现状态：**未实现**的组件，正文课程不得将其名称写成可用 `viz type`。

## 公共需求

1. 所有组件使用现有 `viz` JSON 围栏接入，渲染失败显示可读错误；
2. 状态节点支持鼠标、触屏和键盘拖动，保存节点 `x/y` 到组件内部状态，路由切换后重扫不重复绑定；
3. 运行头、栈指针、高亮路径必须有步进控制和可选动画；动画期间禁用重入按钮；
4. 暗色模式对比度达标，移动端优先支持纵向布局；
5. 动画尊重系统的 `prefers-reduced-motion` 设置：开启时直接跳到目标帧，但保留步进、高亮和文字说明；
6. 每个组件提供重置、随机样例和逐步执行；不接受 `while True` 式连续循环。

## dfa-runner ✅ 已实现（2026-08-28，已回填 30/50/65 三课）

- 目标：可视化五元组 $(Q,\Sigma,\delta,q_0,F)$。
- 配置：`states`、`alphabet`、`transitions`、`start`、`accepting`、`input`。
- 已做：拖动状态节点重排；步进 / 一键跑完 / 重置；读取头沿输入带前进；输入串可运行时改写（字母表过滤）；终点双圈绿=接受、红=拒绝，缺转移按「卡死=拒绝」处理。
- 说明：「点击边编辑转移」未做（转移表由 JSON 驱动，改转移即改课文规格）；公共需求中的「键盘拖动」「随机样例」对本组件豁免（拖动以鼠标/触屏为限，样例由课文 spec 固定以保证叙事一致）。
- 课程落点：30、50、65（均已回填）。

## nfa-guesser

- 目标：展示零条、一条或多条平行路径。
- 必做：同一输入同时维护可达状态集合；可展开具体路径；接受路径金色高亮，失败路径灰化。
- 课程落点：40、45、55。

## subset-construction

- 目标：左侧 NFA，右侧逐步生成子集 DFA。
- 配置：NFA 五元组和最大展开状态数。
- 必做：每一步显示旧集合、符号、合并结果和新状态名；可达子集队列可见；支持撤销一步。
- 课程落点：45、55。

## regex-nfa-map

- 目标：把正则表达式 AST 与 Thompson 构造片段联动。
- 配置：受控正则表达式，仅支持连接、选择、星号和字面量。
- 必做：选中子表达式时高亮对应片段；星号回路动画展示重复；不允许未转义危险输入直接求值。
- 课程落点：55、60。

## pda-stack

- 目标：有限控制加栈的同步动画。
- 配置：输入串、状态集、栈规则、初始栈底。
- 必做：push/pop 有高度变化和缓动动画；栈顶指针始终可见；每步列出 `(state,input,top)` 到 `(state',replace)`。
- 课程落点：70、75、90。

## parse-tree-builder

- 目标：手动和半自动构建 CFG 解析树。
- 配置：CFG、目标串、最大树深。
- 必做：拖动节点调整布局但不改变父子关系；选择产生式生成孩子；多棵树并排比较以演示歧义。
- 课程落点：75、80、85。
