# Fisher 信息：估计精度的尺子

## 1. 从一个场景开始

两家报社同一天发民调："支持率 55%"。A 报社抽了 400 人，B 报社抽了 900 人——直觉秒判 B 更硬气，可"硬气几倍"就说不清了。更根本的问题是：**有没有办法不看具体数据，就能预告"这台估计器最好能做到多准"？** 提前知道精度极限，才能反着算出"想要 ±3% 就得雇多少人"，而不是做完实验再听天由命。

答案是有的。费希尔在发明最大似然估计的同时，顺手造了这把尺子：**Fisher 信息**。它量的是"数据能把参数钉得多死"，并把答案写成了一个漂亮的不等式——估计精度的宇宙级限速牌。

## 2. 直觉解释

回到[最大似然估计](./50-mle.md)课的似然曲线。冠军固然站在峰顶，但真正的信息藏在**峰附近的坡度**里：

- 山峰又尖又陡：数据把参数夹得很紧，稍微挪动候选值，解释力就断崖式下跌——这手数据对参数**很有一票否决权**；
- 山峰又平又缓：一大片候选的解释力都差不多，数据分不清谁是谁——夹而不紧。

Fisher 信息度量的正是这条曲线在峰附近的**弯曲程度**（曲率）。谷底越弯，说明数据越能分辨参数的细微差别，估计就越准；曲率翻译成方差的语言，就是下面要请出的精度天花板。

还有一层味道：**稀有事件自带强信息**。若中奖率接近零，那么哪怕只抽中一枚，都足以把你对世界的想象掰弯一大截；而中奖率过半时，一枚样本根本掀不起波澜。信息的多少不只看样本量，还看参数站在哪里——这是新手最常忽略的一维。

## 3. 正式定义

单条观测的对数似然 $\ln L$ 关于参数二阶导数，取期望再变号，就是 **Fisher 信息**：

$$I_1(\theta)=-E\left[\frac{d^2}{d\theta^2}\ln L(\theta)\right]$$

$n$ 条独立观测的信息线性累加为 $n I_1(\theta)$。于是有了著名的**克拉美-罗下界**（CRLB）：任何无偏估计量的方差都压不破这条地板

$$\mathrm{Var}(\hat{\theta}) \ \ge\ \frac{1}{n\,I_1(\theta)}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $I_1(\theta)$ | 单样本 Fisher 信息 | 一枚观测平均能把 $\ln L$ 的峰压得多弯 |
| $n I_1$ | 总信息 | $n$ 枚独立观测攒下的家底 |
| CRLB | 方差下界 | 无偏估计方差的地板：只能逼近，不能穿透 |
| 标准误下界 | $\sqrt{\mathrm{CRLB}}$ | 误差带的物理最小半宽 |

三点阅读须知。第一，负号来自事实本身：峰顶的二阶导是负数（拱顶下凹），取负才让"信息"成为正量。第二，公式里的期望是在**真实参数**下取的——所以它是实验前的设计量，不偷看数据也算得出。第三，地板属于**无偏**估计者一族；有偏的估计量可以靠"故意歪一点"换取更小的散布，那是另一笔交易。

## 4. 分步例题

**例**：掷硬币，单次结果 $x\in\lbrace 0,1\rbrace$，中签概率 $p$。求 Fisher 信息与精度天花板。

1. 写对数似然：$\ln L = x\ln p + (1-x)\ln(1-p)$；
2. 一阶导：$\dfrac{x}{p}-\dfrac{1-x}{1-p}$；
3. 二阶导：$-\dfrac{x}{p^2}-\dfrac{1-x}{(1-p)^2}$；
4. 取期望变号：$E[x]=p$，代进去得 $I_1(p)=\dfrac{1}{p}+\dfrac{1}{1-p}=\dfrac{1}{p(1-p)}$；
5. 翻译成标准误：$\mathrm{SE}_{\min}=\sqrt{\dfrac{p(1-p)}{n}}$——**置信区间课那道标准误配方，原来一直是克拉美-罗地板本尊**！

对账时间：900 人访问、$\hat p=0.55$ 时，$\mathrm{SE}_{\min}=\sqrt{0.55\times0.45/900}=0.0166$，乘临界值 1.96 恰好是当年的"±3%"。当年当它是经验配方的附属品，今天知道了它的户口：不是习惯用法，而是**信息论意义上的物理极限**。

### 实验 3（python）：2000 场虚拟研究踩踩这块地板

```python title="频率估计的实际散布 vs 克拉美-罗地板"
import random                     # 随机库
import matplotlib.pyplot as plt   # 绘图库短名 plt

random.seed(2026)                 # 固定种子：每次运行长同一片云
p_true = 0.7                      # 世界真实的中奖率（模拟中我们全知）
n_samp = 25                       # 每场虚拟研究的样本量
studies = 2000                    # 重复多少场研究

phats = []                        # 存每场的频率估计
for s in range(studies):
    hits = sum(random.random() < p_true for _ in range(n_samp))   # 25 连抽里的命中数
    phats.append(hits / n_samp)

mean_hat = sum(phats) / len(phats)                                # 经验平均
var_emp = sum((v - mean_hat) ** 2 for v in phats) / len(phats)    # 经验方差
crlb = p_true * (1 - p_true) / n_samp                             # 方差地板

print(round(mean_hat, 4))
print(round(var_emp, 5))
print(round(crlb, 5))

plt.hist(phats, bins=24, color="steelblue")
plt.axvline(p_true, color="red")            # 真值红线
plt.axvline(p_true - crlb ** 0.5, color="gray", linestyle="--")   # 地板开根号：左右一个标准误
plt.axvline(p_true + crlb ** 0.5, color="gray", linestyle="--")
```

打印 `0.7028`、`0.00828`、`0.0084`：两千场研究的散布中心贴着真值 0.7，而经验方差 0.00828 与理论地板 0.0084 在万分之一的尺度上几乎重合（那一点点凹陷纯属蒙特卡洛抖动）。这不是巧合——伯努利世界的频率估计恰好是"有效估计"，被允许踩线奔跑。两条灰虚线按地板画出 ± 一个标准误的位置，直方图的肩膀几乎精准地长在那里。

### 快问快答

```quiz
把一项调查的样本量翻一倍，Fisher 信息和方差地板分别怎么变？
- 信息不变，地板抬高一倍
- 信息翻倍，地板压到一半 [*]
- 信息翻四倍，地板压到四分之一
? 独立观测的信息做加法：样本量翻倍则总信息翻倍，方差地板 1/(n·I) 相应减半。想让误差（标准误）减半才是平方税：方差要缩到四分之一，人力就得乘四。
```

:::warning[常见误区]

**误区一**："你以为 Fisher 信息是'数据里的信息总量'这种模糊修辞。" 它有精确身份：对数似然二阶导的（负）期望，量纲是"每参数的曲率"。同一个实验对不同参数、甚至同一参数在不同位置，信息都不同——离开模型和参数点谈"信息量"是没有意义的。

**误区二**："你以为 CRLB 是一切估计的天条。" 它只约束无偏估计者。允许带偏的估计可以牺牲准头换稳当（缩小散布），方差甚至能压到地板以下——偏差和方差是可以谈判的两种货币（第 41 章 bias-variance 的老主题在这里露出了数学地基）。

**误区三**："你以为精度只看样本量。" 信息公式里藏着参数位置 $p(1-p)$：估计极端比例时每枚样本都很"重"，但相对误差反而恶化。选样本量之前先想清楚要保的是绝对精度还是相对精度——同一份数据给不出两把尺同时及格的承诺。

:::

## 6. 练习

A 报社预算只够访问 400 人（真实支持率按一半预估）。主编写了两行"精度预告"，其中埋着一颗雷：

```exercise
# @title: 练习：算出这次民调的精度天花板
# @check: 0.025
# @check: 1600
# @hint: 单枚样本的信息是 1/(p*(1-p))，别忘了翻转分数；标准误下界 = 1/根号(n*信息)；想让标准误减半，人数要乘四
n_a = 400       # A 报社的样本量
p_guess = 0.5   # 支持率按一半预估

i1 = p_guess * (1 - p_guess)      # ← 单枚样本的信息量：写成了它自己的倒数？？
se_a = 1 / (i1 * n_a) ** 0.5      # 标准误下界 = 1 除以「总信息」的开方
print(se_a)

shrink = 2          # 主编想把标准误压到现在的二分之一
mult = shrink ** 2  # 方差要缩到四分之一 ⟹ 人数乘以 4（平方税）
need_n = mult * n_a
print(need_n)
```

<details>
<summary>点开查看逐步解答</summary>

雷在第二行：信息是 $p(1-p)$ 的**倒数**，改成 `i1 = 1 / (p_guess * (1 - p_guess))` 即可。修好之后：单枚信息 $i_1=1/0.25=4$，总信息 $4\times400=1600$，`se_a` 打印 `0.025`；第二问走的是不变的小方块定律，`1600` 原样通过。故事讲完：想让标题从 ±2.5% 变成 ±1.25%，访问员名单要做四倍扩张——**精度按平方根买单**，这就是每一份民调附注里"样本量"三个字的含金量。

</details>

**练习 2**：电梯故障台账：连续 100 天共报修 400 次，日均故障率估为每天 4 次。用泊松模型（单样本信息 $I_1=1/\lambda$）给日故障率造一条标准误。

<details>
<summary>点开查看逐步解答</summary>

计数总量 $K$ 服从泊松分布时，日均值估计 $\hat\lambda=K/T$ 的方差是 $\lambda/T$（$T$ 天相当于 $T$ 枚"天"样本：总信息 $T/\lambda$，取倒数即方差）。代入：$\mathrm{Var}=4/100=0.04$，标准误 $=0.2$ 次/天，诚实的汇报是"每天 4 ± 0.2 次"。注意泊松世界里相对误差 $0.2/4=5\%$ 完全由总次数决定——数得越多相对越稳，这层"计数的复利"在第 09 章的大数定律里早有伏笔。

</details>

**练习 3**：两家公司都想测一个约 1% 的罕见不良反应率。甲要求"估计值 ±0.2 个百分点以内"，乙要求"相对误差不超过 ±10%"。哪个要求对本实验更苛刻？用本题的两把尺说明。

<details>
<summary>点开查看逐步解答</summary>

粗算各自需要的样本量：达到 $\mathrm{SE}\le 0.002$，需约 $p(1-p)/0.002^2\approx 2475$ 人；达到 $\mathrm{SE}/p\le 0.1$，需约 $(1-p)/(p\times 0.01)\approx 9900$ 人。乙的要求苛刻四倍多——本体只有百分之一，允许 ±10% 的绳索其实细得可怜（±0.1 个百分点）。这是实验 2 里"两把不同的尺"的实战版：写需求时必须声明用的是哪一把，否则预算会议必然打架。

</details>

## 7. 选读：为什么公式里要"求导两次再取期望"

<details>
<summary>选读 · 曲率的平均主义</summary>

直接拿手上的数据算二阶导，结果会随运气上下乱跳——某个样本说曲线弯得厉害，可能只是它碰巧极端。取期望的用意是把运气过滤掉：剩下的是"在真实参数下，这类数据的典型弯曲力度"，一个先于实验、可以规划的设计常数。也正因为答案只依赖模型与参数位置而非手气，CRLB 才有资格当"实验前的预算工具"。这一手"先用期望抹平随机性，再做推断"的操作，你在期望与方差那章已经见过同款哲学。

</details>
