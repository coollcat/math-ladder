# 实验设计：随机化、区组与混杂

## 1. 从一个场景开始

上世纪九十年代，一项观察性研究得出过一个惊人结论：**接受激素替代疗法的女性，心脏病风险显著更低。**

研究样本很大，统计显著，发表在有声望的期刊上。于是数百万女性开始服用。

几年后，随机对照试验（RCT）给出的答案**完全相反**：激素替代疗法**增加**心血管风险。观察性研究怎么会错得这么离谱？

答案藏在一个没被记录下来的变量里：**愿意长期服用激素替代疗法的女性，本身就更可能是收入较高、定期体检、饮食运动更健康的那一群人。** 研究测到的是"健康人群的生活习惯"，不是"药物的效果"。这类变量叫**混杂变量**——它同时影响"谁接受处理"和"结果如何"，把两者的关系偷偷扭曲。

这一课要讲的就是：**怎么设计实验，才能让因果结论站得住脚。** 这是统计学里最不"数学"、却最容易出事的一章。

## 2. 直觉解释

**第一层：随机化为什么能解决问题。** 上一课的 A/B 测试说"随机分组是灵魂"，但要讲清它到底在做什么。

混杂变量的麻烦在于：它让两组**在处理之前就不一样**。激素研究里，"注重健康的女性"在服药组占比更高——之后两组的心脏病发病率差异，可能是这件事造成的，与药无关。

随机化的作用是把所有**已知和未知**的差异变量都变成"平均而言没什么差别"。这里的关键是**未知**两个字：你可以对年龄、收入做匹配，但你匹配不了"你没想到要测的那个变量"。随机化不需要知道你漏了什么，它对**所有**变量（包括你完全没意识到存在的那些）同时生效。**这是它无可替代的原因。**

用第 36 章的抽样语言说：随机分配让处理组与对照组的**协变量分布同分布**。于是组间差异的期望只剩下处理效应本身。

**第二层：区组——当随机化"运气不好"时。** 纯随机化有一个小毛病：小样本时它可能"分配得不巧"。比如 20 个人分两组，随机的结果是 A 组有 8 个男性、B 组只有 2 个——**均值上应当平衡，但这一次偏偏没平衡。**

**区组（blocking）**是对策：先把实验单元按一个已知的重要变量分层（比如按性别分），再**在每一层内部随机分配**。这样"性别"这个变量被彻底控制住，不会成为噪音来源。区组提高的是**精度**（缩小误差方差），而随机化保证的是**无偏**——两者解决的问题不同，常常要配合使用。

**第三层：析因设计——一次测多个因素。** 如果想知道"温度"和"压力"各自的影响，直觉做法是：固定压力不变，变温度测一轮；再固定温度，变压力测一轮。

**析因设计**说：不如把所有组合都跑一遍（比如 $2\times 2=4$ 种），这样不仅能估计每个因素的单独效应（**主效应**），还能估计它们**一起出现时的额外效果**（**交互作用**）。而且因为每个观测同时为两个因素提供信息，**它是更省实验次数的**。

**第四层：观察性研究为什么还重要。** 随机化这么强，为什么还要做观察性研究？因为**很多事不能随机**：不能随机让人吸烟、随机让人贫穷、随机让城市空气变差。这些场景只能靠观察性数据 + 更复杂的因果推断方法（这类方法本身依赖"无未测混杂"的假设——而激素研究的教训正是这个假设常常不成立）。

## 3. 正式定义

**（1）潜在结果框架（Rubin 因果模型）**

对每个单元 $i$，定义两个**潜在结果**：$Y_i(1)$ 是接受处理时的结果，$Y_i(0)$ 是未接受时的结果。个体因果效应是

$$\tau_i = Y_i(1) - Y_i(0)$$

**因果推断的根本问题：每个人只能被观察到一种结果。** 你看到了 $Y_i(1)$，就永远看不到 $Y_i(0)$——这是**反事实**（[可解释性：归因与反事实](../54-trustworthy-ai/40-attribution-counterfactual-xai.md)里也用同一个词）。

于是我们退而求其次，估计**平均处理效应**（ATE）：

$$\text{ATE} = \mathbb{E}[Y(1) - Y(0)] = \mathbb{E}[Y(1)] - \mathbb{E}[Y(0)]$$

**（2）随机化的识别定理**

$$\mathbb{E}[Y \mid T=1] - \mathbb{E}[Y \mid T=0] = \mathbb{E}[Y(1) - Y(0)] \iff (Y(1), Y(0)) \perp T$$

**处理分配 $T$ 与潜在结果独立**——这就是随机化给的保证。有了它，观察到的组间均值差**就等于** ATE；没有它，组间差里混着混杂偏差：

$$\underbrace{\mathbb{E}[Y\mid T=1] - \mathbb{E}[Y\mid T=0]}_{\text{观察到的差异}} = \underbrace{\text{ATE}}_{\text{想要的}} + \underbrace{\text{混杂偏差}}_{\text{不需要的}}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $T$ | 处理指示 | $1$ = 接受处理，$0$ = 对照 |
| $Y(1), Y(0)$ | 潜在结果 | 两种世界里的结果，只能观察到一个 |
| $\text{ATE}$ | 平均处理效应 | 全体单元因果效应的平均 |
| 混杂变量 $Z$ | 混杂因素 | 同时影响 $T$ 与 $Y$ 的变量；使 $\perp$ 失效 |
| $\tau$ | 主效应 / 交互作用 | 析因设计中单个因素的效应 / 因素组合的额外效应 |

**（3）区组设计的方差分解**

区组把总变异拆成三份：**区组间**、**处理间**、**残差**：

$$SS_{\text{总}} = SS_{\text{区组}} + SS_{\text{处理}} + SS_{\text{残差}}$$

检验处理效应的 $F$ 统计量用**残差**当分母：

$$F = \frac{MS_{\text{处理}}}{MS_{\text{残差}}}$$

**区组的价值在这里量化**：把"区组间"这份变异从残差里搬走，分母变小，$F$ 变大，检验更灵敏——这就是"区组提高精度"的账面含义。做法与 [方差分析（ANOVA）](./45-anova.md) 完全同构，只是变异的来源多了一个。

## 4. 分步例题

**例一：混杂偏差的显式账本。**

设想一个（虚构的）简化数据，看混杂变量如何伪造出效应。

| 群体 | 接受处理比例 | 心脏病发病率 |
| --- | --- | --- |
| 注重健康者 | $80\%$ 服药 | $2\%$ |
| 不注重健康者 | $20\%$ 服药 | $8\%$ |

设"注重健康"这个变量对发病率的效应是**主导的**（$2\%$ 与 $8\%$ 的差别完全来自它），而药物的真实效应为 $0$。

1. **服药组的发病率**：按比例加权，$0.8\times2\% + 0.2\times8\% = 1.6\% + 1.6\% = 3.2\%$；
2. **未服药组**：$0.2\times2\% + 0.8\times8\% = 0.4\% + 6.4\% = 6.8\%$；
3. **观察到的组间差**：$3.2\% - 6.8\% = -3.6\%$，即服药组发病率低 $3.6$ 个百分点——**看起来药有保护作用**；
4. **真相**：药物效应是 $0$。这 $-3.6\%$ 全部是混杂偏差——**观察到的差异 $=$ ATE $(0)$ $+$ 混杂偏差 $(-3.6\%)$**；
5. **随机化之后**：两组都变成 $50\%$ 注重健康者，服药组发病率 $= 0.5\times2\%+0.5\times8\% = 5\%$，未服药组同样是 $5\%$，差值 $0$ ✔。**混杂偏差被随机化清零。**

**例二：区组设计的方差收益。**

同一实验，一边用完全随机、一边用区组，看误差项的大小。

设"性别"是一个强影响变量：男性基线响应 $10$、女性 $20$，处理效应在两组都是 $+3$。

1. **完全随机（运气不好）**：A 组 $80\%$ 男性、B 组 $20\%$ 男性。A 组均值 $\approx 0.8\times13 + 0.2\times23 = 10.4+4.6 = 15.0$；B 组均值 $\approx 0.2\times13+0.8\times23 = 2.6+18.4 = 21.0$；
2. **观察到的组间差**：$21.0 - 15.0 = 6.0$，而**真实处理效应只有 $3.0$**——性别不平衡贡献了另外 $3.0$ 的假象；
3. **区组（按性别分层后组内随机）**：男性 A 组 $= 13$、男性 B 组 $= 13$；女性 A 组 $= 23$、女性 B 组 $= 23$。男女各自持平，合并差 $= 3.0$ ✔（**方向被修正**）；
4. **精度的收益**：由于每组内部男女比例一致，残差里不再包含"性别"这份大变异（$10$ 与 $20$ 相差 $10$，是残差的绝对主力），$MS_{\text{残差}}$ 显著变小，$F$ 随之变大；
5. **读结论**：**随机化解决"偏不偏"，区组解决"准不准"。** 两者一起用，才能既无偏又精确。

**例三：$2\times2$ 析因设计的效应分解。**

两个因素（温度高/低、压力高/低），四个格子的响应：

| | 压力低 | 压力高 | 行均值 |
| --- | --- | --- | --- |
| 温度低 | $10$ | $14$ | $12$ |
| 温度高 | $18$ | $26$ | $22$ |
| 列均值 | $14$ | $20$ | 总均值 $17$ |

1. **温度主效应**：行均值差 $22-12 = 10$；
2. **压力主效应**：列均值差 $20-14 = 6$；
3. **检查交互作用**：温度从低到高，在低压下响应涨 $8$（$10\to18$），在高压下涨 $12$（$14\to26$）——**涨的幅度不一样**，说明有交互；
4. **交互作用的数值**：把"温度高且压力高"的真实值 $26$ 与"各自加主效应"的预测 $\hat y = 10 + 10 + 6 = 26$ 对比——恰好相等（这个例子是**可加**的，交互为 $0$）。若把 $(16, 30)$ 换成 $(16, 32)$，预测值 $26$ 与真值 $32$ 差 $6$，这 $6$ 就是交互作用；
5. **读结论**：**主效应回答"某因素单拎出来多重要"，交互作用回答"两个因素撞在一起会不会不一样"。** 后者常常才是工艺优化的关键——一个真实的例子是"高温只在高压下才有效"。

### 实验 2（python）：随机化怎么"自动"平衡你没想到的变量

随机化最漂亮的地方是它对未观测变量也生效。下面模拟一遍：假设有一个**你完全不知道存在**的混杂变量（比如"健康意识"），看随机分组是否仍能让两组在它上面平衡：

```python title="随机化对未知混杂变量的自动平衡"
import random

random.seed(17)
n = 2000

# 生成人群：每个人有一个你"没测到"的健康意识分数
health = [random.gauss(0, 1) for _ in range(n)]      # 未观测的混杂变量
treated = [False] * n

for i in range(n):                                    # 关键一步：完全随机分配
    treated[i] = (random.random() < 0.5)

g1 = [health[i] for i in range(n) if treated[i]]
g0 = [health[i] for i in range(n) if not treated[i]]
print("处理组健康意识均值 =", round(sum(g1) / len(g1), 4))
print("对照组健康意识均值 =", round(sum(g0) / len(g0), 4))
print("两组差值 =", round(sum(g1) / len(g1) - sum(g0) / len(g0), 4))

# 对照：故意搞一个自选择的分组（健康意识高的人更可能进入处理组）
g1s, g0s = [], []
for i in range(n):
    p = 1 / (1 + pow(2.718281828, -health[i]))        # 逻辑函数：意识越高越可能被处理
    if random.random() < p:
        g1s.append(health[i])
    else:
        g0s.append(health[i])
print()
print("自选择分组：处理组 =", round(sum(g1s) / len(g1s), 4),
      "；对照组 =", round(sum(g0s) / len(g0s), 4),
      "；差值 =", round(sum(g1s) / len(g1s) - sum(g0s) / len(g0s), 4))
```

第一段的两组均值差只在 $-0.1$ 到 $+0.1$ 间随机抖动（抽样噪音量级）；第二段的差值稳定为**明显正数**——因为健康意识高的人被系统性地挑进了处理组。**随机化不需要"知道"健康意识是什么，它照样把平衡做掉了；自选择则相反，它会把每个你没想到的变量都变成偏差来源。**

### 实验 3（python）：区组设计把误差方差压下去多少

例二讲的是"区组让残差变小"，这里把它量化：比较完全随机与区组设计下的组间差估计，看**重复多次后的波动幅度**差多少：

```python title="区组设计：同样的处理效应，估计波动小多少"
import random

random.seed(23)
TRUE_EFFECT = 3.0        # 真实处理效应：两组都一样
BASE_M = 10.0            # 男性基线
BASE_F = 20.0            # 女性基线（性别是强影响变量）
N_PER_GROUP = 40
REPEATS = 2000

def once_randomized():
    # 完全随机：性别与处理分配无关，小样本下比例会歪
    resp_a, resp_b = [], []
    for k in range(N_PER_GROUP * 2):
        base = BASE_M if k % 2 == 0 else BASE_F     # 一半男一半女
        is_a = random.random() < 0.5
        val = base + random.gauss(0, 1) + (0 if is_a else TRUE_EFFECT)
        (resp_a if is_a else resp_b).append(val)
    return sum(resp_b) / len(resp_b) - sum(resp_a) / len(resp_a)

def once_blocked():
    # 区组：按性别分层，每层内部随机分配
    resp_a, resp_b = [], []
    for base in (BASE_M, BASE_F):
        for k in range(N_PER_GROUP):
            is_a = random.random() < 0.5
            val = base + random.gauss(0, 1) + (0 if is_a else TRUE_EFFECT)
            (resp_a if is_a else resp_b).append(val)
    return sum(resp_b) / len(resp_b) - sum(resp_a) / len(resp_a)

def spread(fn):
    ests = [fn() for _ in range(REPEATS)]
    mean = sum(ests) / len(ests)
    var = sum((e - mean) ** 2 for e in ests) / len(ests)
    return mean, var ** 0.5

ma, sa = spread(once_randomized)
mb, sb = spread(once_blocked)
print("完全随机：均值估计 =", round(ma, 3), "；标准差 =", round(sa, 4))
print("区组设计：均值估计 =", round(mb, 3), "；标准差 =", round(sb, 4))
print("波动缩小倍数 =", round(sa / sb, 2), "倍")
print("真实处理效应 =", TRUE_EFFECT)
```

三种输出的关键读法：**两个均值估计都接近 $3.0$（都无偏）**，但**区组的标准差明显更小**。这就是"随机化保证无偏、区组提高精度"的量化版本——性别这个 $10$ 分的强变量被关进了区组项，不再污染残差。

```quiz
随机化相比"对已知变量做匹配"，最不可替代的优势是什么？
- 它能同时平衡那些研究者完全没想到要测的变量
- 它让样本量看起来更大 [*]
- 它不需要任何统计假设就能算出 p 值
? 匹配只能处理你"想到了并测到了"的变量；随机化让处理分配与全部潜在结果（包括未观测混杂）独立，是对未知混杂唯一有效的普遍性手段。
```

::::warning[常见误区]

**误区一**："你以为样本大就能消除混杂。" 激素替代疗法的研究样本很大，混杂依然把它带偏了。**大样本缩小的是随机误差（方差），不缩小系统偏差。** 一个百万人的自选择样本，估计偏差可能比一个几十人的随机样本大得多——这是统计直觉里最容易出错的一条。

**误区二**："你以为随机化之后组间所有变量就完全一样了。" 随机化保证的是**期望上**平衡，不是**这一次**平衡。小样本时两组仍可能有可观的失衡（例二第一段就是）；而且**能否真正做到随机分配**本身常常是问题（流失、不依从、参与者中途退出，都可能让随机化名存实亡——这是临床试验里"意向治疗分析"要专门处理的麻烦）。

**误区三**："你以为区组和随机化是二选一。" 它们是**互补**的：区组在**层内部**随机，随机在**层之间**不做区分。只区组不随机，仍然可以自选择；只随机不区组，小样本时仍可能失衡、且残差里混着大变异。**区组是精度的投资，随机是无偏的底线。**

**误区四**："你以为 P 值小就说明效应真实且重要。" P 值衡量的是"如果无效，看到这么大差异的概率"，它**不告诉你效应有多大**（显著性 ≠ 重要性），也不告诉你**效应是什么造成的**。一个设计有缺陷的实验可以跑出极小的 p 值——**p 值是在设计给定的前提下算的，它不能反过来替设计背书。** 这是本课最该带走的一句。

**回归控制**的做法是把混杂变量 $Z$ 作为一列放进模型。它的有效性依赖一个不可检验的前提：**$Z$ 被完整、准确地测到了**，而且模型形式写对了（比如真的是线性关系）。如果 $Z$ 测错了（测量误差会带来新的偏差）、如果真实混杂是另一个你没想到的变量 $Z'$、如果关系是非线性的——控制就失效了，而且**失效时你往往不知道**。

**随机化**不进入模型，它作用在**分配机制**上：$T$ 由抛硬币决定，于是 $T \perp (Y(1), Y(0), Z, Z', Z'', \dots)$ ——对**所有**变量同时成立，包括你从未听说过、从未想到要测的那些。它的有效性不依赖任何"我们测全了"的假设。

用一个类比：回归控制是"把你想得到的所有嫌疑人都逐个排查一遍"；随机化是"把整个嫌疑名单（连同你没写上的名字）一次性全部排除"。**前者要求你的嫌疑名单完备，后者不需要。**

代价也要说清：随机化在很多现实场景不可行（不能随机让人吸烟），而且它对**不依从、流失、干预污染**很敏感——随机分配之后人们实际做了什么，仍可能破坏独立性。所以因果推断的完整图景是：能随机就随机，不能随机就明确写出并论证你的"无未测混杂"假设（这可能吗？只能靠敏感性分析说明"要多强的未知混杂才能推翻结论"）。

</details>

**练习 2**（判题）：下面这段代码想算**混杂偏差**，但它把"观察到的组间差"当成了偏差本身——真正的偏差要减掉真实效应：

```exercise
# @title: 练习：拆分观察到的组间差
# @check: -3.6
# @check: 0.0
# @hint: 观察到的组间差 = 真实效应 + 混杂偏差。真实效应是 0，所以混杂偏差 = 观察差 - 0。第二问是随机化后的纯净差值。
treat_rate_healthy = 0.8     # 处理组中"注重健康者"的占比
healthy_risk = 2.0           # 注重健康者的发病率（%）
unhealthy_risk = 8.0         # 不注重健康者的发病率（%）
true_effect = 0.0            # 药物的真实效应（本例为 0）

rate_treated = treat_rate_healthy * healthy_risk + (1 - treat_rate_healthy) * unhealthy_risk
rate_control = (1 - treat_rate_healthy) * healthy_risk + treat_rate_healthy * unhealthy_risk

observed_diff = rate_treated - rate_control     # 观察到的组间差
bias = observed_diff                            # ← 问题在这：忘了减掉真实效应

print(round(bias, 4))
print(round(observed_diff - bias, 4))           # ← 这一行修好之后应当输出真实效应
```

第一行要求输出掺杂在观察差里的**混杂偏差** $-3.6$（因为真实效应为 $0$，数值上恰好与观察差相等，但概念上必须写成 `observed_diff - true_effect`）；第二行修好后输出真实效应 `0.0`。**这道题的重点不在算术，而在把"看到的"和"真实的"分开记账这个习惯。**

## 7. 选读：从实验设计到因果推断

<details>
<summary>选读 · 设计是因果推断的第一道也是最强的一道防线</summary>

统计学的教科书常把因果推断放在"高级方法"的位置，但实际上**最好的因果推断发生在数据产生之前**——这就是实验设计这门学科的位置。

它和本章其他课的关系是这样一条链：**实验设计负责"让数据值得分析"**，而 [A/B 测试](./40-ab-testing.md)是实验设计在互联网场景的一个具体化身（在线实验的独特优势是能轻易做到真正的随机化，这是医学研究羡慕不来的）；[方差分析](./45-anova.md) 提供了分析多组实验的标准工具（区组设计的方差分解正是它的一个变体）；[多重检验与 FDR](./85-multiple-testing-fdr.md) 处理"一次实验看很多指标"的误报膨胀；[置信区间](./20-confidence-interval.md) 与 [假设检验](./30-hypothesis-testing.md) 则是收尾的裁决工具。**没有好的设计，后面四件工具都在给一个偏掉的答案算精度。**

从因果推断的现代发展看，实验设计的思想还在向观察性研究渗透：倾向得分匹配（模仿随机化的平衡效果）、工具变量（找一个只通过处理影响结果的变量）、断点回归（利用分配规则上的不连续）、双重差分（利用政策前后两组的变化差）。这些方法的共同思路都是**在观察性数据里人为制造出某种"准随机"的结构**——本质上都是在追求随机化那个理想性质。

一个实用的判断标准：**当你看到一项研究声称"控制了 XX 变量"时，第一反应应该是问"还有哪些变量是随机化才挡得住、而控制挡不住的？"** 这个问题的答案长度，直接决定这个结论的可信度。这与 [可信 AI](../54-trustworthy-ai/index.md) 那一章对模型评估的怀疑姿态是同一套方法论：**先问"这个结论是在什么条件下成立的"，再问"这个条件成立吗"。**

</details>
