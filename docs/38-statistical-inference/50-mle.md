# 最大似然估计：让数据为自己说话

## 1. 从一个场景开始

夜市口的套圈摊，你蹲在一旁看了三十局，路人中签 21 局。摊主咬定"我这摊就是难玩"；隔壁摊主撇嘴："他那摊明摆着七成中奖。"第 1 课的点估计会直接喊出 0.7，抽样那课也会告诉你这个数字大概抖多大。可是细想一层：**凭什么 0.7 就比 0.3 更像正确答案？** 总得有个裁判，能给任何一个候选比例打个分吧。

这一课就把这台打分机造出来。它叫**最大似然估计**（MLE），是整个统计学使用最广的参数估计器——民调、药效、点击率、乃至神经网络训练的底层损失，本质都是它在工作。原则只有一句话：**谁最能解释手上的数据，谁当选。**

## 2. 直觉解释

把每个候选比例当成一份"剧本"，然后问一个问题：**如果这份剧本是真的，看到我手上这一手数据的把握有多大？**

- 剧本 A："中奖率 0.3"。三十局里要连中二十一局？得烧了高香；
- 剧本 B："中奖率 0.5"。同样一手牌，运气也得爆表；
- 剧本 C："中奖率 0.7"。这一手在它眼里平平无奇，像极了普通的一天。

这三份把握程度就是各剧本的**契合度评分**，学名叫**似然**。三份评分摆在一起，C 完胜——于是我们宣布：估计中奖率 0.7。整个过程不诉诸直觉、不留人情分，只比较"哪个世界最容易长出我的数据"。和上一章造区间不同：置信区间问"参数大概在哪一带活动"；MLE 是先把所有候选拉上擂台，选出解释力冠军。

## 3. 正式定义

设观测为 $x$，待估参数为 $\theta$，**似然函数**定义为

$$L(\theta)=P(\text{观测到 } x \mid \theta)\qquad\text{（数据 } x \text{ 固定，} \theta \text{ 是自变量）}$$

**最大似然估计**是让 $L$ 冲到最高的那个参数：

$$\hat{\theta}_{\mathrm{MLE}}=\underset{\theta}{\arg\max}\ L(\theta)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $L(\theta)$ | 似然 | 参数取 $\theta$ 时，长出这手数据的把握 |
| $\arg\max$ | 最大化位置 | 让函数达到最大的**自变量**（注意不是最大值本身） |
| $\hat{\theta}$ | 帽子记号 | 用样本算出来的参数估计值 |
| $\ln L$ | 对数似然 | 把连乘拍平成连加，峰值位置纹丝不动 |

两条纪律要背下来。其一，**似然不是概率**：它描述的是"参数对这个数据的解释力"，不需要积分为一，取值也能大到天文数字或小到计算机都存不下。其二，实践中几乎总是对 $\ln L$ 动手而不是 $L$ 本身——几十个零点几的概率连乘会一路缩到浮点数都表示不了，取对数既防爆仓又方便求导。

## 4. 分步例题

**例**：$n=30$ 局中签 $k=21$ 局，求中奖率 $p$ 的最大似然估计。

1. 写似然：$L(p)=\binom{30}{21}p^{21}(1-p)^{9}$（前面的组合数是不随 $p$ 变化的常数因子，不影响冠军归属）；
2. 取对数：$\ln L=C+21\ln p+9\ln(1-p)$；
3. 求导置零：$\dfrac{21}{p}-\dfrac{9}{1-p}=0$；
4. 解方程：$21(1-p)=9p \Rightarrow 28p=21 \Rightarrow \hat{p}=0.7$；
5. 一般化：同样步骤对任意 $n,k$ 都给出 $\hat{p}=k/n$——**MLE 把"用频率估概率"这件朴素的事，变成了一个公理推论**。

四步模板固定：**写似然 → 取对数 → 求导置零 → 解出峰值**。能解方程的场合闭式求解；解不开的就上数值搜索——下面的实验两种都来一遍。

横轴是候选中奖率，纵轴是对应似然（$h$ 扮演命中频率，$m$ 扮演数据规模）。拖 $h$：山峰老实跟到 $h$ 处站定——MLE 忠于频率。再把 $m$ 从 10 拉到 60：山越来越瘦成一根针——**同样的命中率，更多的数据把候选圈得更死**。这正是第 1 课"标准误按 $\sqrt{n}$ 收窄"的老旋律，换成了似然语言重新唱一遍。

### 实验 2（python）：网格搜索当裁判

方程解不出的现实模型太多，所以工程师更爱直接招标：把 0 到 1 的候选比例切成一百格，逐个打分，最高分当选。

```python title="网格搜索：谁的剧本最配 21/30 这手数据"
import math                       # math.log：自然对数（第 03 章登场），连乘拍平成连加
import matplotlib.pyplot as plt   # 绘图库短名 plt（此前课程已引入）

k = 21                            # 三十局里中签的局数
n = 30

best_p = 0                        # 目前得分最高的候选比例
best_ll = -1e18                   # 目前最高分，从"负到天荒地老"起步
rows = []                         # 攒下 (候选, 得分) 二元组，回头画曲线

for i in range(1, 100):           # 候选从 0.01 扫到 0.99，步长 0.01
    p = i / 100
    ll = k * math.log(p) + (n - k) * math.log(1 - p)   # 对数似然打分
    rows.append((p, ll))          # 元组入队
    if ll > best_ll:              # 打擂台：出现高分就换庄家
        best_ll = ll
        best_p = p

print(best_p)
print(round(best_ll, 3))

xs = [r[0] for r in rows]         # 列表推导式：逐行取出第 0 号位置的候选
ys = [r[1] for r in rows]
plt.plot(xs, ys, color="steelblue", linewidth=2)     # 对数似然曲线
plt.axvline(k / n, color="tomato", linestyle="--")   # 红虚线立在 21/30 处
plt.xlabel("candidate p")
plt.ylabel("log-likelihood")
```

打印 `0.7` 和 `-18.326`：红虚线正好扎进曲线的最高点。对数似然的形状是一只单峰的"碗口朝下"的拱，求导置零找的就是这只拱的顶；而网格搜索连导数都不需要，靠笨笨的比较照样夺冠——**理论派和工程派殊途同归**。

### 快问快答

```quiz
似然 L 和概率 P 的关系，下面哪句是真的？
- L 固定数据考察参数，P 固定参数考察数据 [*]
- L 和 P 是同一个数，只是一个英文一个中文
- L 不管怎么算都不可能超过 1
? 方向是全部区别所在：概率是「参数定了，问数据的可能性」；似然是「数据到手了，反问哪个参数最有解释力」。多个稀有小概率相乘时 L 会小到计算机存不下——这正是改用对数似然的动机之一。
```

:::warning[常见误区]

**误区一**："你以为似然就是概率。" 方向相反。概率描述"给定参数后数据的可能性"；似然描述"给定这手数据后参数的解释力"。它不是 $\theta$ 的分布，不求和为一，也不能拿来做"P(参数是多少)"的断言——那是贝叶斯 posterior 的业务范围。

**误区二**："你以为 MLE 就是真值。" 它只是当前证据下的最佳辩护士。五局全中会把 MLE 推到 1.0 这个显然荒谬的角落；样本越小，冠军越容易得意忘形。这就是后面几课要给冠军配误差带的全部理由。

**误区三**："你以为求导置零万无一失。" 有的对数似然有好几个峰（混合模型最爱搞事），有的峰趴在边界上；导数为零的点也可能是谷底或平台。求不出解析解时，网格扫描这种笨办法反而最可靠——本课实验 2 就是你的保底工具。

:::

## 6. 练习

夜市继续营业：你换了个摊位蹲守，这次是 **四十局中了二十六局**。三位候选凑热闹——对面摊主赌咒发誓中奖率只有三成。把下面的病码修到通过：

```exercise
# @title: 练习：给候选剧本打分
# @check: 0.65
# @check: False
# @hint: 第 i 个候选的得分 = p 的命中次数次方 × (1-p) 的落空次数次方；病码把两位演员的角色对调了
k = 26            # 四十局中的命中数
n = 40

cands = [0.3, 0.5, 0.65]

best_score = 0    # 目前最高分
best_p = 0        # 最高分对应的候选

for p in cands:
    score = (1 - p) ** k * p ** (n - k)   # ← 命中次数套在了 (1-p) 头上，落空次数却归了 p
    if score > best_score:                # 高分换庄家的逻辑本身没错
        best_score = score
        best_p = p

print(best_p)
print(best_p == 0.3)                      # 摊主的三成说真的成立吗？
```

<details>
<summary>点开查看逐步解答</summary>

只需把病灶一行改成命中次数归 $p$、落空次数归 $(1-p)$ 的正确顺序：

```python
score = p ** k * (1 - p) ** (n - k)   # 命中率管命中次数，落空率管落空次数
```

跑通后打印 `0.65` 和 `False`：四十局中二十六的战绩让 0.65 以碾压优势夺魁，"只有三成"的说辞得分垫底。顺手验算手工路线：$\ln L$ 求导后 $26/p=14/(1-p)$，解得 $p=26/40=0.65$——与网格冠军一致，两个工具互相盖章。

</details>

**练习 2**：另一摊真来了位欧皇，五连中。MLE 直接跳到 1.0，明天这摊就要被挤爆。有什么便宜的办法不让极端样本牵着鼻子走？

<details>
<summary>点开查看逐步解答</summary>

经典土办法叫**拉普拉斯平滑**：假装开局前就已"看见"过一次中签一次落空，则估计改成 $(5+1)/(5+2)\approx 0.857$。它相当于往"一半一半"的中立先验收一点注——MLE 是彻底的现实主义者，样本少时容易被戏剧性劫持；垫一两票门票就能把结论拽回人间。大样本下这点修正会被稀释殆尽，这正是"小样本防极端、大样本信频率"的使用边界。

</details>

**练习 3**：把似然机器搬到连续世界：身高服从已知的钟形家族（标准差 $\sigma$ 已知），十个人的样本摆在桌上。$\mu$ 的 MLE 是谁？

<details>
<summary>点开查看逐步解答</summary>

正态密度的对数求和后含 $-\sum(x_i-\mu)^2/(2\sigma^2)$ 这一项，最大化等价于让平方偏离最小，解得 $\hat\mu=\bar{x}$——又是样本均值！三个完全不同的舞台（掷硬币、抽奖、量身高）里，MLE 反复把最朴素的统计量认证为官方答案：这不是巧合，而是"最贴合数据的解释"这一准则的自然回报。顺带一提：若 $\sigma^2$ 也未知，它的 MLE 恰好是第 1 课吐槽过的"除以 $n$"的方差版本——MLE 不许诺无偏，只许诺最能解释数据，这两件事并不总是一伙的。

</details>

## 7. 选读：为什么取对数不更换冠军

<details>
<summary>选读 · 单调变换的免死金牌</summary>

设 $g$ 是严格递增函数，则 "$L(a)\ge L(b)$" 与 "$g(L(a))\ge g(L(b))$" 永远同时成立或同时不成立——不等号两边被同向拉伸，大小秩序原封未动。$\ln$ 在正数域上严格递增，所以两个 $\arg\max$ 给出同一个冠军。同理，似然里那些不随参数变化的常数因子（比如二项式里的组合数）乘除谁都行：比例不变则排名不变。这套"合法的美颜术"是贯穿统计计算的通行证——后面学习生成模型时见到的各种目标函数，玩的还是同一招。

</details>
