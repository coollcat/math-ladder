# 非参数统计：不假设分布也能推断

## 1. 从一个场景开始

某实验室测了 20 个受试者的响应时间（秒）：

$$1.1,\ 1.4,\ 1.5,\ 1.7,\ 1.8,\ 1.9,\ 2.0,\ 2.0,\ 2.1,\ 2.2,\ 2.3,\ 2.4,\ 2.6,\ 2.8,\ 3.1,\ 3.3,\ 3.9,\ 4.6,\ 5.2,\ 7.4$$

先算两个"中心"：**均值 2.765 秒，中位数 2.25 秒**。差了半秒多。谁在撒谎？都不是——数据右端拖着一根长尾巴（最大 7.4），把均值拽向了右边，而中位数岿然不动。

问题来了。我们学过的 t 检验、置信区间，配方里都预定了"数据近似正态"。这份数据右偏得厉害，还带一个离群点，正态假设站不住。**难道换一份数据就要换一套数学？** 非参数统计给出的答案是：干脆别假设分布长什么样，用**名次**和**局部平均**这类不依赖具体分布形状的工具来推断。

## 2. 直觉解释

**第一层：把数值换成名次，扔掉形状。** t 检验要算均值和标准差，这两个量都被极端值牵着走——一个 7.4 就能让标准差膨胀一大截。非参数方法的招式是：**只看大小顺序，不看绝对数值**。把两组数据混在一起排队，谁排第几就是它的"秩"。再把"甲组名次和"与"乙组名次和"一比，就能判断两组是否系统性地一个偏大。名次只认顺序，一个离群值从 7.4 变成 74 也照样排在最后——**秩对极端值天然免疫**。

**第二层：直方图太粗糙，那就把每个数据点铺成一座小山。** 想看数据的分布形状，最原始的做法是画直方图：把数轴切成格子、数每格里有几个人。可格子的宽度是人为选的，换个宽度图形就变样。**核密度估计（KDE）**换了个思路：在每个数据点上放一座小山包（核函数），把 20 座小山的轮廓**叠加**起来。多个数据点挨得近，山包摞得高；落单的点，只贡献一个矮包。这样得到的曲线平滑、不依赖分箱，只在"山包多大"这一个参数上留自由度——这个参数叫**带宽** $h$。

**第三层：带宽是唯一的旋钮，也是最要命的旋钮。** $h$ 小，每个山包又尖又窄，曲线跟着数据抖成一串毛刺（过拟合）；$h$ 大，山包又矮又胖，曲线被抹得过分平滑，甚至把双峰糊成一个包（欠拟合）。**调带宽比挑核函数形状重要得多**——高斯核、矩形核、三角核给出的曲线差不了太多，但带宽差一倍，结论可能完全相反。

## 3. 正式定义

**经验分布** $\hat F$：把样本观测值各赋 $1/n$ 概率的离散分布，它是总体分布 $F$ 的替身（上一课的老朋友）。

**核密度估计（KDE）**：给定数据 $X_1,\dots,X_n$ 和核函数 $K$（常取标准正态密度），定义

$$\hat f_h(x) = \frac{1}{n h} \sum_{i=1}^{n} K\!\left( \frac{x - X_i}{h} \right).$$

**带宽** $h > 0$ 控制每个山包的宽度，也决定整条曲线的光滑程度。

**秩**：把 $n$ 个观测值从小到大排序，某个观测值的秩就是它的名次（最小者秩为 1）。

**秩和统计量**：设甲组有 $n_1$ 个、乙组有 $n_2$ 个。把两组混排后，甲组的秩之和记作 $R_1$。**Mann-Whitney $U$**（等价于 Wilcoxon 秩和检验）为

$$U = R_1 - \frac{n_1(n_1+1)}{2}.$$

在原假设"两组分布只在位置上相同"下，$U$ 的期望与标准差为

$$E[U] = \frac{n_1 n_2}{2}, \qquad \mathrm{SD}(U) = \sqrt{\frac{n_1 n_2 (n_1 + n_2 + 1)}{12}}.$$

样本不小的时候，$\dfrac{U - E[U]}{\mathrm{SD}(U)}$ 近似标准正态，可以直接读 p 值。

**非参数回归**（Nadaraya-Watson 局部平均）：对每个查询点 $x$，用它附近训练点的**加权平均**来估计响应

$$\hat m(x) = \frac{\sum_i K\!\left( \frac{x - X_i}{h} \right) Y_i}{\sum_i K\!\left( \frac{x - X_i}{h} \right)}.$$

$h$ 越大越平滑、越接近全局平均；$h$ 越小越贴着数据、越容易过拟合。LOESS 是它的加权最小二乘升级版。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $h$ | 带宽 | 核的宽度；KDE 与局部回归共用的"光滑旋钮" |
| $K(\cdot)$ | 核函数 | 每个数据点铺出的山包形状，通常取标准正态密度 |
| $\hat f_h(x)$ | 核密度估计 | 数据点在 $x$ 处的"密度贡献"之和 |
| $R_1$ | 甲组秩和 | 甲组名次相加 |
| $U$ | Mann-Whitney 统计量 | 由秩和经 $\frac{n_1(n_1+1)}{2}$ 修正而来 |
| $\hat m(x)$ | 局部平均估计 | 非参数回归在 $x$ 处的预测值 |

## 4. 分步例题

沿用上面 20 个响应时间，做两件事。

**（一）核密度估计在 $x=2.0$ 处的值。**

1. 取标准正态核 $K(u) = \frac{1}{\sqrt{2\pi}} e^{-u^2/2}$，带宽先取 $h = 0.3$；
2. 对每个数据点算 $u_i = (2.0 - X_i)/0.3$，再算 $K(u_i)$；
3. 把所有 $K(u_i)$ 求和、除以 $n h$。得 $\hat f_{0.3}(2.0) \approx 0.5105$；
4. 把 $h$ 换成 0.8 和 2.0，同样计算得 $0.3207$ 与 $0.1665$——**带宽越大，峰越矮越宽**；
5. 峰值高度降到一半以下不是"数据变了"，纯粹是被抹平了。所以报 KDE 时**必须同时报带宽**，否则数字没有意义。

**（二）两组响应时间的秩和检验。**

甲组（旧配方）$n_1 = 8$ 个，乙组（新配方）$n_2 = 8$ 个。混排后甲组的秩之和 $R_1 = 43$。

1. **修正成 $U$**：$U = 43 - \frac{8 \times 9}{2} = 43 - 36 = 7$；
2. **原假设下的标尺**：$E[U] = \frac{8\times 8}{2} = 32$，$\mathrm{SD}(U) = \sqrt{\frac{8 \times 8 \times 17}{12}} = \sqrt{90.67} \approx 9.52$；
3. **标准化**：$z = \frac{7 - 32}{9.52} \approx -2.63$；
4. **读 p 值**：翻标准正态表，$z = -2.63$ 落在左尾约 0.4% 的位置（双侧约 0.9%），低于 5% 阈值——两组差异显著；
5. **读法**：$U$ 远小于期望，说明甲组名次整体偏小，即**甲组响应时间系统性地更短**。全过程没用到均值、标准差、正态假设中的任何一个。

### 实验 2（python）：带宽三连，看曲线怎么被抹平

```python
import math

# 20 个响应时间（秒）：右偏，带一个离群点
sample = [1.1, 1.4, 1.5, 1.7, 1.8, 1.9, 2.0, 2.0, 2.1, 2.2,
          2.3, 2.4, 2.6, 2.8, 3.1, 3.3, 3.9, 4.6, 5.2, 7.4]
s = sorted(sample)
n = len(s)
mean = sum(sample) / n                              # 均值：被长尾拽高
median = (s[n // 2 - 1] + s[n // 2]) / 2            # 中位数：不受长尾影响
print(round(mean, 3))
print(round(median, 3))

def kde(x, data, h):
    # 核密度估计：每个数据点摆一座标准正态小山包，叠加后除以 n*h
    total = 0.0
    for xi in data:
        u = (x - xi) / h                            # 离得越远，山包贡献越小
        total = total + math.exp(-0.5 * u * u) / math.sqrt(2 * math.pi)
    return total / (len(data) * h)

print(round(kde(2.0, sample, 0.3), 4))              # 小带宽：尖
print(round(kde(2.0, sample, 0.8), 4))              # 中带宽
print(round(kde(2.0, sample, 2.0), 4))              # 大带宽：被抹平
```

输出 `2.765`、`2.25`、`0.5105`、`0.3207`、`0.1665`。第一对数字是这门课的开场矛盾：**均值 2.765 比中位数 2.25 高出半秒**，差距全来自那根长尾。后面三个数在同一个 $x=2.0$ 处给出 0.51、0.32、0.17——带宽从 0.3 加到 2.0，峰高降了三分之二。**记住一件事：报 KDE 的值必须连带宽一起报。**

### 实验 3（python）：不给分布也能判显著性

```python
import math

a = [3.1, 2.4, 2.9, 3.4, 2.2, 3.8, 2.7, 3.9]      # 甲组（旧配方）
b = [4.2, 3.6, 4.6, 3.3, 4.1, 4.8, 3.7, 4.3]      # 乙组（新配方）

combined = []
for v in a:
    combined.append((v, 0))                         # 0 号标签 = 来自甲组
for v in b:
    combined.append((v, 1))
combined.sort()                                     # 按数值排序，元组比较先比第一个元素

rank_a = 0
for i in range(len(combined)):
    if combined[i][1] == 0:                         # 甲组的名次
        rank_a = rank_a + (i + 1)                   # 名次从 1 开始

n1 = len(a)
n2 = len(b)
U = rank_a - n1 * (n1 + 1) / 2                      # 修正成 Mann-Whitney 的 U

mu_u = n1 * n2 / 2
sd_u = math.sqrt(n1 * n2 * (n1 + n2 + 1) / 12)      # 原假设下 U 的标准差
z = (U - mu_u) / sd_u
print(rank_a)
print(U)
print(round(z, 3))
```

输出 `43`、`7.0`、`-2.626`。甲组秩和 43、$U=7$，远低于原假设期望的 32；标准化后 $z \approx -2.63$——查标准正态表，这个值落在左尾约 0.4% 的位置（双侧约 0.9%），稳稳低于 5% 阈值。**全程只用排序和加法**——没有用到数据的均值、标准差，也没有"数据服从正态"这句话。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为非参数就是'没有任何假设'。" 每个非参数方法都带着假设，只是不假装知道分布的具体函数形式：秩检验假设两组**分布形状相同、只在位置上平移**（否则"位置差异"说不清）；KDE 假设密度足够光滑；局部回归假设响应随 $x$ 缓变。**"不假设分布形状"≠"不假设任何东西"**，把前提想清楚，结论才站得住。

**误区二**："你以为非参数一定更安全，所以无脑用它。" 稳健是要付学费的：当数据真的接近正态时，秩检验的**功效低于 t 检验**（同样样本量更难检出真差异）。非参数的代价是**效率损失**——它丢掉了数值大小里的一部分信息，只留顺序。经验法则：样本小、分布重尾或有离群点、或数据只是顺序量表时，非参数划算；样本大且明显近似正态时，经典方法更强。

**误区三**："你以为 KDE 的带宽随便调调就行。" 带宽比核函数形状重要得多。$h$ 太小，曲线抖成一串毛刺，你会"发现"根本不存在的多个峰；$h$ 太大，真正的双峰会被糊成一个包，你会错过结构。更要命的是**看着结果挑带宽**——那是在用数据自己决定答案。正规做法是用 Silverman 经验法则或交叉验证定 $h$，并且把选定的值随结论一起报出来。

:::

## 7. 练习

**练习 1**：下面这段秩和检验代码能跑，但它报出的 $U$ 忘记减掉修正项、把秩和当成了 $U$。修到输出 `43` 与 `7.0`：

```exercise
# @title: 练习：把秩和修正成 Mann-Whitney 的 U
# @check: 43
# @check: 7.0
# @hint: U = 甲组秩和 − n1(n1+1)/2。初始代码漏掉了那半截修正，报出的数比真实 U 大了 36。
a = [3.1, 2.4, 2.9, 3.4, 2.2, 3.8, 2.7, 3.9]
b = [4.2, 3.6, 4.6, 3.3, 4.1, 4.8, 3.7, 4.3]
combined = sorted(a + b)
rank_a = 0
for v in a:
    rank_a = rank_a + combined.index(v) + 1    # 名次 = 下标 + 1
n1 = len(a)
U = rank_a                                     # ← 漏了 n1(n1+1)/2 的修正
print(rank_a)
print(U)
```

<details>
<summary>点开查看逐步解答</summary>

补上修正项：

```py
U = rank_a - n1 * (n1 + 1) / 2    # 43 − 36 = 7.0
print(rank_a)                     # 43
print(U)                          # 7.0
```

为什么要减 $\frac{n_1(n_1+1)}{2}$？因为这个量是"甲组自己内部名次的最小可能和"。$R_1$ 减去它，剩下的才是**甲组每个成员在混排中"压过"乙组多少个**的计数总和——那才是可解释的差异度量。不减修正项，$R_1$ 会随 $n_1$ 增大而机械地变大，跨数据集就没法比了。

</details>

**练习 2**：某数据里有一个明显的离群点（比如响应时间 7.4 秒）。请说明：把 7.4 改成 74，对（a）样本均值、（b）样本中位数、（c）Wilcoxon 秩和检验的 p 值分别有什么影响？

<details>
<summary>点开查看逐步解答</summary>

**(a) 均值**：从 2.765 涨到约 6.085（多了 $(74-7.4)/20 \approx 3.32$ 秒）——被一个点彻底带偏。
**(b) 中位数**：纹丝不动，仍是 2.25。排序后 7.4 和 74 都稳稳排在最末，名次不变。
**(c) 秩和检验的 p 值**：完全不变。秩只看顺序，7.4 变成 74 依然排最后一名，所有秩原样不动，$U$、$z$、p 值一个数都不变。

这就是"非参数"四个字的实际含义：**换掉数值刻度、只保留顺序，推断结论不受极端值摆布**。代价是同一个 7.4 携带的"到底有多极端"的信息也被一并丢掉了。

</details>

## 8. 选读：非参数到底亏了多少

<details>
<summary>选读 · 渐近相对效率：3/π 那点事</summary>

"秩检验效率低"这句话有多严重？可以用**渐近相对效率**（ARE）量化：为达到同样的检验功效，秩检验相对参数检验需要多少倍的样本。

在数据**恰好服从正态分布**的理想情形下，Wilcoxon 秩和检验相对 t 检验的 ARE 是

$$\text{ARE} = \frac{3}{\pi} \approx 0.955.$$

也就是说，即使正态假设完全成立、t 检验占尽主场优势，秩检验也只多要 4.5% 的样本量——**代价小到几乎可以忽略**。而在**重尾分布**（比如 t 分布、柯西分布、混合正态）下，t 检验的方差被极端值拖垮，ARE 可以滚到 1.5 甚至无穷大——秩检验反手碾压。

这解释了一条实用经验：**只要不是"数据严丝合缝正态 + 样本极小"这种极端情况，用秩检验几乎不会亏**。反过来看，上一课 bootstrap 讲的"代入原则"和这里的"只留顺序"是同一套哲学的两个侧面：**都在回答"当总体分布不可知时，怎样让手头这点数据尽量说话"**。代价总是有的——信息被更粗地量化了——但只要粗化方式的损失可控，稳健性就赚回来了。

</details>
