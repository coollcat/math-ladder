# 充分统计量与最优检验

## 1. 从一个场景开始

质检员抽了 100 颗轴承。MLE 那一课教过：把"让数据最自洽"的参数选出来；假设检验那一课也立过裁决程序——定假设、算标准误、折算偏离、对红线裁决。但两笔账一直欠着：其一，100 个原始读数要锁进档案柜，还是写在报告单上的那几个数就够用了？**数据能不能无损压缩？** 其二，30 课的两类错误对照表里，"漏放真凶"的概率 $\beta$ 只被点了名——**红线到底画在哪，才算画得最强？**

这一课把两笔欠账一起结清：前者叫**充分统计量**，后者是**Neyman-Pearson 引理**给的最优判决规则——顺带把 30 课许诺的"功效四格"实验当场落成。

## 2. 直觉解释

**充分统计量：无损压缩包。** 抛 5 次硬币拿到"3 正 2 反"。哪些细节对辨认 $p$ 有用？直觉说：正面个数 $k=3$ 是全部家当，至于"正反正反正"还是"反反正正正"，在已知 $k$ 之后应当毫无差别。充分性的严格含义正是这条直觉：**给定 $T$ 的取值后，数据的剩余花样与参数无关**——压缩没有丢掉任何关于 $p$ 的东西。

**Neyman-Pearson：似然比裁判。** 两个剧本摆上擂台：$H_0$（公平硬币）与 $H_1$（偏心硬币）。对同一手数据各打一次分（似然），比值 $\Lambda$ 衡量"剧本 1 比剧本 0 多解释了多少"。$\Lambda$ 越大的数据，越像 $H_1$ 世界的产物——把拒绝域设在 $\Lambda$ 最大的那批数据上，是同一份"误判预算 $\alpha$"下抓到真效应概率最大的画法。这不是经验，是引理：**没有更好的画法**。

## 3. 正式定义

**充分统计量**：统计量 $T$ 充分，若条件分布

$$P(\text{数据}=x_1,\dots,x_n \mid T=t,\ \theta)$$

不依赖 $\theta$。参数能从 $T$ 里读出的，不多不少。

**似然比**：同一手数据在两个参数点上的解释力之比

$$\Lambda(x)=\frac{L(\theta_1\mid x)}{L(\theta_0\mid x)}$$

**Neyman-Pearson 引理**：检验"简单 $H_0$ vs 简单 $H_1$"时，把拒绝域取成 $\Lambda>c$（阈值 $c$ 配平第一类错误到 $\alpha$），则在一切第一类错误不超过 $\alpha$ 的检验中，它的功效最大。

四格账本（30 课对照表的定量版）：

| | 实际 $H_0$ 为真 | 实际 $H_1$ 为真 |
| --- | --- | --- |
| 拒绝 $H_0$ | 第一类错误，概率 $\alpha$ | 抓到效应：**功效** $1-\beta$ |
| 不拒绝 $H_0$ | 正确放行，$1-\alpha$ | 第二类错误，概率 $\beta$ |

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $T$ | 充分统计量 | 数据的无损压缩包；顺序细节对参数不再携带信息 |
| $\Lambda$ | 似然比 | 两剧本解释力之比；NP 判决的唯一依据 |
| $\alpha$ | 显著水平 | 拒绝域在 $H_0$ 世界里的触发概率上限 |
| $\beta$ | 第二类错误概率 | $H_1$ 为真却没拒绝的概率 |
| $1-\beta$ | 检验功效 | 真有效应时抓到它的概率——检验的抓捕率 |

## 4. 分步例题

**例**：抛 5 次硬币记正面数 $K$。$H_0$：$p=0.5$，$H_1$：$p=0.8$。

1. **逐手打分**：$H_0$ 世界里 $L_0=0.5^5$（与 $K$ 无关）；$H_1$ 世界里 $L_1=0.8^K\,0.2^{5-K}$。似然比
$$\Lambda(K)=\frac{0.8^K\,0.2^{5-K}}{0.5^5}=1.6^K\cdot 0.4^{5-K}$$
2. **看单调性**：每多一枚正面，$\Lambda$ 翻 $0.8/0.2=4$ 倍——判决只需数 $K$，$K$ 就是充分统计量；
3. **定拒绝域**：取 $\Lambda$ 最大的数据，即 $\lbrace K\ge 4\rbrace$，配平显著水平：$\alpha=P(K\ge4\mid H_0)=\binom{5}{4}0.5^5+0.5^5=6/32=0.1875$；
4. **算功效**：$P(K\ge4\mid H_1)=0.8^5+5\cdot0.8^4\cdot0.2=0.7373$，于是 $\beta=0.2627$；
5. **换档对比**：拒绝域收紧到 $\lbrace K=5\rbrace$：$\alpha=0.5^5=0.0313$，功效却跌到 $0.8^5=0.3277$——四格是跷跷板，$\alpha$ 压小、$\beta$ 抬头；
6. **充分性对账**：给定 $K=3$，五种正两个反共 $\binom{5}{3}=10$ 种排列，条件概率各 $1/10$，与 $p$ 无关——顺序信息对辨认 $p$ 毫无贡献，$T=K$ 名不虚传。

### 实验 2（python）：功效四格演武场

```python title="两个世界里各掷两万场五连抛，四格账当场结清"
import random

random.seed(7)                       # 固定种子：人人同一份战报
n = 5                                # 每场实验抛 5 次
rule = 4                             # 拒绝线：正面数 ≥ 4 就拒绝 H0
trials = 20000

reject_h0 = 0                        # H0 世界里的"拒绝"计数
for trial in range(trials):
    heads = 0
    for flip in range(n):
        if random.random() < 0.5:    # H0 世界：公平硬币
            heads = heads + 1
    if heads >= rule:
        reject_h0 = reject_h0 + 1

reject_h1 = 0                        # H1 世界里的"拒绝"计数
for trial in range(trials):
    heads = 0
    for flip in range(n):
        if random.random() < 0.8:    # H1 世界：p=0.8 的硬币
            heads = heads + 1
    if heads >= rule:
        reject_h1 = reject_h1 + 1

print(round(reject_h0 / trials, 4))      # 格一：经验 α（理论 0.1875）
print(round(1 - reject_h0 / trials, 4))  # 格二：1−α
print(round(reject_h1 / trials, 4))      # 格三：经验功效（理论 0.7373）
print(round(1 - reject_h1 / trials, 4))  # 格四：经验 β（理论 0.2627）
```

四个读数与例题的笔算逐格对上：这份拒绝域在两个世界里各是什么嘴脸，蒙特卡洛替你跑了一遍。把 `rule` 改成 5 再跑：格一缩到 0.03 一带、格三塌到 0.33 一带——跷跷板亲手可感。

### 实验 3（python）：给定战绩后，排列的"条件均匀性"

```python title="已知 3 正 2 反：10 种排列的条件概率与 p 无关"
n = 5
k_target = 3                         # 拿到手上的战绩：3 正 2 反
p_list = [0.3, 0.5, 0.8]             # 三个候选世界

total3 = 0                           # 先数五连抛里 3 正的排列数
for code in range(32):               # 0..31：每个整数编号一种正反序列
    heads = 0
    rest = code
    for pos in range(n):
        heads = heads + rest % 2     # % 2 取出最低位：1 记正面
        rest = rest // 2             # // 整除 2：把序列右移一位
    if heads == k_target:
        total3 = total3 + 1

print(total3)                        # 应报 10：C(5,3)
for p in p_list:
    joint = p ** k_target * (1 - p) ** (n - k_target)   # 任一 3 正序列的概率
    denom = total3 * joint                               # 全部 3 正序列的概率之和
    print(round(joint / denom, 4))   # 分子分母同涨同跌，p 当场消掉
```

三个世界里都报出 $0.1$——单序列概率 $p^3(1-p)^2$ 在分子分母里同时出现又同时消失。**"与 $p$ 无关"就是充分性的全部含义**，这份压缩确实一件不丢。

```quiz
- 加大样本量 [*]

```

::::warning[常见误区]

**误区一**："你以为充分统计量就是最好的估计量。" 充分性只承诺**压缩不丢参数信息**，不承诺无偏或低方差——MLE 课里"除以 n"的方差版本照样是充分统计量的函数却带偏。充分性是入选资格，不是冠军奖杯，选拔还要用下一课的尺子。

**误区二**："你以为 α 越小检验越强。" 例题第 5 步当场演示：α 从 0.1875 压到 0.0313，功效从 0.7373 塌到 0.3277。检验的强弱必须 α 与功效**成对汇报**，只报 α 的检验广告都是半张账单。

**误区三**："你以为拒绝线可以看完数据再调。" NP 引理的"最优"是对**事先配平的 α** 而言的合同条款；看完数据挪阈值，等于按战果改赛道——30 课"先定单双侧"的纪律，在这里升级成铁律。

::::

## 6. 练习

**练习 1**：把例题的四格账亲手结一遍。初始代码两处漏计、一处张冠李戴——修到三行检查全部通过：

```exercise
# @title: 练习：拒绝域 K≥4 的四格账
# @check: 18.75
# @check: 0.7373
# @check: 0.2627
# @hint: α 是 H0 世界里 K=4 与 K=5 两种构成之和（各 C(5,k)·0.5^5）；功效把同样的构成搬进 p=0.8 的世界；β 与功效拼成完整的 1
n = 5
p1 = 0.8
k_rule = 4                     # 拒绝线：正面数 ≥ 4 就拒绝 H0

alpha = 0.5 ** n               # ← 显著线：K≥4 有几种构成？只算了一种
power = p1 ** n                # ← 功效的构成同样被吃掉了几枚
beta = alpha                   # ← 第二类错误的账该从哪格里来？

print(round(alpha * 100, 2))
print(round(power, 4))
print(round(beta, 4))
```

修好后的三笔账：α = 18.75%、功效 = 0.7373、β = 0.2627——与例题逐格吻合。

**练习 2**：效应放大再验一次：$H_1$ 改成 $p=0.9$，拒绝域仍是 $\lbrace K\ge4\rbrace$，功效变成多少？

<details>
<summary>点开查看逐步解答</summary>

$P(K\ge4\mid p=0.9)=0.9^5+5\cdot0.9^4\cdot0.1=0.59049+0.32805=0.9185$。$\alpha$ 纹丝没动（它只住在 $H_0$ 世界里），功效却从 0.7373 爬到 0.9185——**效应离零假设越远，同一张网捞得越准**。这就是"最小可检效应"的来源：给定 $\alpha$、样本量与功效，能抓到的最小效应是被三条边锁死的第四条边。

</details>

**练习 3**：正态总体里，样本均值 $\bar{x}$ 是 $\mu$ 的充分统计量，样本最大值却不是。用"给定 T 之后剩余数据还依不依赖参数"各讲半句。

<details>
<summary>点开查看逐步解答</summary>

给定 $\bar{x}$：正态样本可分解为"均值 + 形状"，剩余的散布模式（各点到均值的偏差方向）的分布与 $\mu$ 无关——均值之外再无 $\mu$ 的消息，压缩无损。给定最大值：其余 $n-1$ 个观测挤在最大值下方的具体姿态仍随 $\mu$ 变化（$\mu$ 越高，整体水位越高），最大值丢掉了这批位置信息——有损压缩，故不充分。判据只有一条：**条件分布还看不看得出参数的影子**。

</details>

## 7. 选读：因子化定理与两条最优性的会师

<details>
<summary>选读 · 压缩的代数判据，与估计端的同一哲学</summary>

**因子化定理（Fisher–Neyman）**：$T$ 充分 ⟺ 似然能拆成

$$L(\theta;x)=g(T(x),\theta)\cdot h(x)$$

"装参数的包" $g$ 只经由 $T$ 接触数据，"参数无关的碎屑" $h$ 单独装袋。MLE 只读 $g$——所以**充分统计量是似然的合法压缩包**，任何推断都可在 $T$ 上无损进行。指数族分布（二项、泊松、正态……）的天然充分统计量就是其密度指数里的那几个积量和，这条定理是它们的出生证明。

**两条最优性会师**：检验端，NP 引理在"α 上限"的约束下榨干功效；估计端，Cramér–Rao 下界在"无偏"的约束下压出方差地板（见 [Fisher 信息](./60-fisher-information.md) 一课的定量账本，此处只挂链接不重记）。同一哲学的两面：**先立约束，再证没有更优**。加上本课的充分性（信息不浪费），估计与检验理论的铁三角就此合拢。

</details>
