# 置信区间：给猜测配一条误差带

## 1. 从一个场景开始

民调机构发布："候选人支持率 55%"。第二天对手阵营嘲讽"我们测的是 53%，你们造假"。谁错了？都没错——问题出在"55%"这个说法本身：它假装自己精确到个位，却没交代抖动幅度。诚实的写法是"55% ± 3%"，也就是一个**区间**。

点估计是一根针，置信区间是一条带。这一课讲带子怎么造、宽度由什么决定，以及那个连很多老手都会说错的解释问题。

## 2. 直觉解释

上一课的结论：样本均值 $\bar{x}$ 会围绕真值 $\mu$ 抖动，典型幅度是标准误 $\mathrm{SE}$。那么顺手一推——

> 真值大概率就在 $\bar{x} \pm 2\,\mathrm{SE}$ 这条带子里。

为什么敢加"大概"？因为抽样分布近似钟形（这是第 36 章已经严格化的中心极限思想），而钟形分布里约 95% 的质量落在中心两个标准误之内。"95%"就是这条带子的**置信水平**。

造带子的配方一句话：**估计值 ± 倍数 × 标准误**。倍数由置信水平决定：95% 用约 1.96，90% 用约 1.64，99% 用约 2.58。想要更宽的保险带，就提高倍数；想收窄带子，就加大样本量。

## 3. 正式定义

设点估计为 $\bar{x}$，标准误为 $\mathrm{SE}$，则 $\mu$ 的 **95% 置信区间**为：

$$\bar{x} \pm 1.96 \times \mathrm{SE} = \left[\bar{x} - 1.96\,\mathrm{SE},\ \bar{x} + 1.96\,\mathrm{SE}\right]$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $1.96$ | 临界值 | 钟形分布中央 95% 对应的横坐标（查表得来的常数） |
| $\bar{x}-1.96\,\mathrm{SE}$ | 下限 | 带子的左端点 |
| $\bar{x}+1.96\,\mathrm{SE}$ | 上限 | 带子的右端点 |
| 置信水平 | 方法成功率 | 长期反复使用此配方时，造出的带子盖住真值的比例 |

**正确解释（考试重点，也是人生重点）**："95%"修饰的是**配方**，不是某一条具体的带子。意思是：若把"抽样本→按配方造带子"重复一百次，大约有九十五条带子会盖住真值，另外五条会失手。而你手上这**一条**带子要么盖住了要么没盖住——真值是个固定的数，它不掷骰子。

## 4. 分步例题

**例**：访问 $n=900$ 名选民，支持率 $\bar{p}=0.55$。求支持率的 95% 置信区间（比例的标准误用 $\sqrt{\bar{p}(1-\bar{p})/n}$）。

1. 算比例的标准误：$\sqrt{0.55 \times 0.45 / 900}=\sqrt{0.2475/900}\approx 0.0166$；
2. 乘临界值：$1.96 \times 0.0166 \approx 0.033$；
3. 写出区间：$0.55 \pm 0.033$，即 $(51.7\%,\ 58.3\%)$；
4. 解读：对手的 53% 落在带内——两组数据并不矛盾，"造假"的指控不成立。重叠提示不矛盾；但严格比较两组时，最好对差值本身造区间，不能只拿“是否重叠”当最终裁决。

### 实验 2（python）：一百条带子，几条失手？

重复"抽样→造 95% 区间"一百次，把每条带画出来。真值固定在 $\mu=170$（红线）：

```python title="覆盖率模拟：真值 170，sigma=5，n=100"
import random                       # 随机库
import matplotlib.pyplot as plt     # 画图库

mu_true = 170        # 总体真实均值（模拟中我们全知）
sigma = 5            # 总体真实标准差
n = 100              # 每次抽取的样本量

fig, ax = plt.subplots(figsize=(7, 6))   # 建画布与画笔
miss = 0             # 失手计数：没盖住真值的区间个数

for k in range(100):
    total = 0
    for i in range(n):
        # random.gauss(mu, sigma)：从均值为 mu、标准差为 sigma 的
        # 正态（钟形）总体里随机抽一个数——首见 API
        total = total + random.gauss(mu_true, sigma)
    xbar = total / n
    half = 1.96 * sigma / n ** 0.5    # 半宽 = 1.96 * SE，SE = sigma/根号n

    # 连续比较：a <= b <= c 等价于 a <= b 且 b <= c（首见写法）
    covered = xbar - half <= mu_true <= xbar + half   # 判断带子是否盖住红线
    if not covered:
        miss = miss + 1
    color = "tomato" if not covered else "lightseagreen"   # 条件表达式：成立取前值，否则取后值
    # hlines(y, x1, x2)：在高度 y 处画一条水平线段（这里 y 是第 k 条带）
    ax.hlines(k, xbar - half, xbar + half, color=color)

ax.axvline(mu_true, color="red", linewidth=2)   # 竖直红线 = 真值
print(f"100 条带子中 {miss} 条没盖住真值")
```

跑几次：失手的通常是 3~8 条，围绕 5 波动。红线的含义很冷酷——**它从不移动**；移动的是带子。这就是"95% 属于方法而非属于某条带"的具象化。

### 快问快答

```quiz
我们算出「平均身高 170 到 174 厘米」这个 95% 置信区间。下面哪个理解是对的？
- 全体人口中约 95% 的人身高都在 170 到 174 厘米之间
- 若反复抽样并按同配方造区间，约 95% 的区间会盖住真实均值 [*]
- 真实均值有 95% 的概率落进这条已经造好的区间
? 第二种才是正解：95% 描述的是造区间的长期成功率。真值是固定的，不掷骰子；这个范围也不是个体的散布范围。
```

:::warning[常见误区]

**误区一**："你以为 95% 是'真值落进这条区间的概率'。" 区间造好后，真值要么在里面要么不在，概率是 0 或 1。随机的不是真值而是带子——95% 说的是"这样造的一批带子里约九成半能罩住它"。

**误区二**："你以为置信区间是数据的范围。" 它估的是总体参数（如均值），不是个体观测的散布。身高的 95% 区间宽 4 厘米，不代表 95% 的人身高挤在这 4 厘米里——个体散布由 $\sigma$ 描述，比区间宽得多。

**误区三**："你以为 99% 区间全面优于 95%。" 更高的置信水平靠加宽带子换来：99% 带更宽、更迟钝。区间宽度与把握程度是一对必须谈判的条件，没有免费的自信。

:::

**练习 1**：9 名学员的答题用时（分钟）为 `[8, 10, 11, 12, 12, 13, 14, 13, 15]`，已知总体标准差 $\sigma=6$。求均值 $\mu$ 的 95% 区间（临界值取整数 2）。下面的代码能跑但只打印了点估计——改到通过：

```exercise

# @check: 8.0
# @check: 16.0

```

**练习 2**：同一批数据，把置信水平从 95% 提高到 99%（临界值 2.58），区间变宽多少？

<details>
<summary>点开查看逐步解答</summary>

半宽从 $2\times 2=4$ 变为 $2.58\times 2=5.16$，区间从 $(8,16)$ 变为 $(6.84,17.16)$，总宽多出 2.32。把握与精度之间的汇率清晰可见：多要 4 个百分点的把握，付出 29% 的宽度。

</details>

**练习 3**：两项研究各给出"新法更快"的结论：研究 A 区间 $(2.1,\ 2.9)$ 分钟，研究 B 区间 $(1.2,\ 4.5)$ 分钟。哪项更值得相信？为什么不能只看中点？

<details>
<summary>点开查看逐步解答</summary>

两点重合都在 2.5 分钟，但 B 的带宽是 A 的近三倍，说明 B 的信息量小得多（可能样本少或波动大）。决策要看整条带：如果"有效果"的底线是快于 1 分钟，A 的下限 2.1 已经高于 1，可以放心排除；B 的下限 1.2 也高于 1，同样排除但没那么干脆。**区间思维比点值思维多回答了一层"我有多确定"。**

</details>

## 7. 选读：1.96 这个数字从哪来

<details>
<summary>选读 · 临界值的户口</summary>

钟形（正态）分布有个著名数值事实：中央约 95% 的概率质量落在距中心 1.96 个标准差之内（精确到 1.959964）。所以"95% 配方乘 1.96"其实是两件事的合成：抽样分布近似钟形 + 钟形的 95% 区间半径。同理 90% 对应 1.64、99% 对应 2.58——都是同一张表的三个格子。

严格版有两个前置条件：一是样本量够大（钟形近似才成立），二是标准误已知或样本足够大以致用 $s$ 代替 $\sigma$ 的误差可忽略。小样本时要用 t 分布的临界值替换 1.96（带子略宽以补偿额外不确定）——那是后续课程的内容，本站先建立几何直觉。

</details>
