# 统计推断与实验设计

统计推断是在不完全信息中做负责任的结论。本章把估计量、误差、检验力和实验设计放在一起，避免把 p 值当成魔法印章。

这一章按下面的路线图推进：

1. [从样本猜总体：点估计与标准误](./10-sampling-estimation.md)——工厂刚下线十万颗轴承，质检员不可能全部测量，只抽了 100 颗：平均直径 25.02 毫米；
2. [置信区间：给猜测配一条误差带](./20-confidence-interval.md)——民调机构发布："候选人支持率 55%"；
3. [假设检验与 p 值：统计裁决程序](./30-hypothesis-testing.md)——药店声称"排队不超过 8 分钟"；
4. [A/B 测试实战：从分组到决策](./40-ab-testing.md)——2007 年 12 月，奥巴马竞选团队的总部分成两派：顾问们坚信首页放上竞选演讲视频最能打动访客；
5. [最大似然估计：让数据为自己说话](./50-mle.md)——一枚硬币抛十次出七正，参数定成几才最配得上这份数据？“让眼前这些数据出现的概率最大”，一条原则终结主观争论；
6. [充分统计量与最优检验](./55-sufficiency-np.md)——数据能不能无损压缩而不丢参数信息？Neyman-Pearson 引理说：似然比最大的那批数据，就是同份 α 预算下最强的拒绝域，功效四格账当场结清；
7. [Fisher 信息：估计精度的尺子](./60-fisher-information.md)——两家报社同一天发“支持率 55%”，抽 400 人和抽 900 人的底气差多少？不用等实验做完，就能预告一台估计器的精度上限；
8. [Bootstrap 重采样：自己造误差带](./70-bootstrap-resampling.md)——猫咖老板娘算出会员月消费中位数 188.5 元，翻遍手册也查不到它的标准误公式——那就把手里的账单反复重抽，自己把误差带造出来；
9. [置换检验：不靠分布假设的显著性](./80-permutation-tests.md)——如果原假设说“标签无关紧要”，那就重排标签、直接制造原假设分布；
10. [多重检验与 FDR](./85-multiple-testing-fdr.md)——同时做一万次检验，假阳性必然刷屏，控制错误发现率是高吞吐科学的生存法则。

## 实战挑战 · 一场价值 6000 万美元的 A/B 测试

真实案例：2007 年 12 月，奥巴马竞选团队的网站首页要决定放什么按钮、配什么图。数据分析负责人丹·西罗克（Dan Siroker，后来创立 Optimizely）说服团队别再开会吵架，改做随机对照实验：**4 种按钮文案 × 6 种素材 = 24 个版本**，31 万余名访客被随机分流到各版本。这是 A/B 测试史上最著名的战例之一（出处：西罗克本人 2010 年公开复盘文章及 Optimizely 官方博客）。

结果：原始页注册率 **8.26%**（相当于每万名访客注册 826 人）；胜出组合「Learn More 按钮 + 全家福照片」注册率 **11.6%**（每万名 1160 人）。全战役期间落地页共收获约 1000 万个注册邮箱，团队估算若一直用原始页只能拿到约 712 万个。

**(a)** 每一万名访客，冠军组合比原始页多收多少个邮箱？第一问已示范：

```exercise
# @title: 实战挑战：算一算这场实验的战果
# @check: 334
# @check: 2880000
# @check: 60480000
# @hint: (b) 用 1000 万减去 712 万；(c) 多出来的邮箱数 × 每个邮箱平均带来的捐款额
print(1160 - 826)          # (a) 每万人的差距（已示范）
print()                    # (b) 全战役多收的邮箱个数
print()                    # (c) 按「每个新邮箱平均带来约 21 美元捐款」估算的总价值（美元）
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** $1160-826=334$ 人/万人。

**(b)** $10000000-7120000=2880000$ 个邮箱——西罗克原文给出的正是这个数（他按 280 万计，因基数有取整，量级一致）。

**(c)** $2880000 \times 21 = 60480000$ 美元，约合 6000 万。注意不同报道口径略有出入（WIRED 引用过 7500 万的口径），但都源于同一次实验的提升幅度。

统计哨卡：官方口径的 40.6% 是**相对**提升，来自未取整的原始注册率；若用上面的取整数 $11.6/8.26\approx 1.404$ 复算，则约为 40.4%。绝对差距只有 3.34 个百分点——汇报实验结果时两个口径必须同时给出，这正是第 40 课误区一的真人版。此外，24 个版本两两比较属于多重比较，胜出者的优势应当用新一轮流量复核后才全量上线（练习 3 的教训）。

```python
lift_ppm = (1160 - 826) / 826 * 100   # 相对提升的百分数
print(round(lift_ppm, 1))             # 约 40.4 —— 与官方口径 40.6% 基本吻合（基数取整所致）
```

</details>

```quiz
新闻标题写「按钮优化让注册率暴涨 40.6%」。这句话的正确理解是？
- 注册率从 8.26% 变成了 48.86%
- 新注册率约为原来的 1.4 倍，绝对差距是 3.34 个百分点 [*]
- 每 100 名访客中有 40.6 人被按钮打动
? 相对提升与绝对提升是两种货币：40.6% 说的是倍数关系，绝对差距只有 3 个多百分点。混淆两者是最常见的统计话术陷阱。
```

## 实战挑战 · 标准误别忘了开根号

置信区间的半宽 = $z^* \times \frac{\sigma}{\sqrt{n}}$。标准误是 $\frac{\sigma}{\sqrt{n}}$，不是 $\frac{\sigma}{n}$。样本均值 10、标准差 2、样本量 100 时，95% 区间是 $10 \pm 1.96\times0.2$。下面这题忘了开根号，修到输出 `9.61` 和 `10.39`：

```exercise
# @title: 实战挑战：标准误别忘了开根号
# @check: 9.61
# @check: 10.39
# @hint: 标准误 = σ / √n，分母是平方根，不是 n 本身。
import math

xbar = 10.0
sigma = 2.0
n = 100
se = sigma / n                    # ← 问题在这：该除以 sqrt(n)
ci_low = xbar - 1.96 * se
ci_high = xbar + 1.96 * se
print(round(ci_low, 2))
print(round(ci_high, 2))
```

<details>
<summary>点开查看逐步解答</summary>

标准误是 $\frac{\sigma}{\sqrt{n}}$：

```python
se = sigma / math.sqrt(n)    # 2 / 10 = 0.2
ci_low = xbar - 1.96 * se    # 10 - 0.392 = 9.608
ci_high = xbar + 1.96 * se   # 10 + 0.392 = 10.392
print(round(ci_low, 2))      # 9.61
print(round(ci_high, 2))     # 10.39
```

改完：95% 区间 $[9.61,\ 10.39]$。初始代码 `se = sigma/n = 0.02`，区间窄得离谱——样本量开根号带来的"均值的稳定性"被丢掉了。$\sqrt{n}$ 这个根号，正是"更多样本让估计更稳，但收益递减"的数学体现。

</details>
