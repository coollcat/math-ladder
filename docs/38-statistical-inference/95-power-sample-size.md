# 功效分析与样本量：实验要做多大

## 1. 从一个场景开始

一个团队花了六周跑完一个 A/B 实验，结论是"没有显著差异"。产品经理准备写进周报：**新版本对转化率没有影响**。

这个结论可能有三种完全不同的真相：

1. **确实没影响**——新版本真的和老版本一样；
2. **有影响，但样本不够**——真实提升确实存在，只是这个实验规模**根本探测不到**它；
3. **实验设计有问题**——指标定义错了、分流不随机、或者中途改过代码。

问题在于：**"没有显著差异"这个结论，把三种情况写得一模一样。** 一份只报告 p 值的分析，无法告诉你是哪一种。

要区分它们，需要回答一个 p 值从来不回答的问题：**如果效应真的存在，我这个实验有多大概率能发现它？**

这个概率叫**统计功效**（power）。这一课讲怎么算它，以及更实用的反向用法——**实验开始之前，先算出需要多少样本**。

## 2. 直觉解释

**第一层：四种结局，不是两种。** 一次检验其实有四格账（这和[充分统计量与最优检验](./55-sufficiency-np.md)里的功效四格是同一张表）：

| | 真实：无效应 | 真实：有效应 |
| --- | --- | --- |
| **判显著** | 第一类错误（$\alpha$，假阳性） | 正确检出（**功效** $1-\beta$） |
| **判不显著** | 正确（$1-\alpha$） | 第二类错误（$\beta$，漏报） |

$\alpha$ 是"冤枉好人"的概率，约定俗成定在 $0.05$；$\beta$ 是"放过坏人"的概率，约定俗成定在 $0.20$——**功效就是 $80\%$**。

**注意这两者是此消彼长的**：把 $\alpha$ 压得更小（比如 $0.01$），漏报就更多；想两个都低，只有一条路——**加样本**。这就是为什么样本量是实验设计里最贵的那个旋钮。

**第二层：功效由什么决定。** 凭直觉列出所有相关因素：

1. **效应大小** $\delta$：真实差距越大，越容易被发现（信号强）；
2. **噪音大小** $\sigma$：数据越抖，越难分辨（信噪比）；
3. **样本量** $n$：样本越多，均值的标准误越小（$\sigma/\sqrt n$，又是平方根律）；
4. **显著性水平** $\alpha$：门槛定得越松，越容易检出。

**关键洞察是把前三件事合起来看**：决定功效的其实是一个**比值**

$$\text{标准化效应量} = \frac{\delta}{\sigma/\sqrt n}$$

分子是"信号"，分母是"噪音"。功效就是"信号超过门槛"的概率。

**第三层：反解出样本量。** 把上式整理一下（要求这个比值至少达到某个由 $\alpha$ 和 $\beta$ 决定的临界值）：

$$n \approx \frac{(z_{1-\alpha/2} + z_{1-\beta})^2 \cdot 2\sigma^2}{\delta^2}$$

取 $\alpha=0.05$（$z \approx 1.96$）、功效 $80\%$（$z \approx 0.84$）：

$$n \approx \frac{(1.96+0.84)^2\times2\,\sigma^2}{\delta^2} \approx \frac{15.7\,\sigma^2}{\delta^2} \approx 16\,\frac{\sigma^2}{\delta^2}$$

**这就是 [A/B 测试实战](./40-ab-testing.md) 里那个系数 16 的来源。** 那两个加数分别管"别冤枉"和"别放过"，乘 2 是因为两组各有噪音。

**第四层：最要命的一条性质——平方反比。** 看公式：$n \propto 1/\delta^2$。

**想把能检测的最小效应减半，样本量要变成 4 倍。** 想减到三分之一，要 9 倍。

这一条几乎解释了在线实验里所有的资源争论。一个基线转化率 $5\%$ 的产品，想检出 $0.5$ 个百分点的提升，需要的样本量是检出 $1$ 个百分点时的**四倍**——很多团队正是在这里才发现，自己"想看清楚"的愿望根本不匹配流量规模。

## 3. 正式定义

**（1）单样本均值检验的样本量**

检验 $H_0: \mu = \mu_0$ 对 $H_1: \mu \neq \mu_0$，已知标准差 $\sigma$，要求能检出差异 $\delta$：

$$n = \frac{(z_{1-\alpha/2} + z_{1-\beta})^2\,\sigma^2}{\delta^2}$$

**（2）两样本比例比较的样本量**（每组）

比较两组比例 $p_A, p_B$，效应 $\delta = |p_B - p_A|$，用基线平均 $\bar p$：

$$n_{\text{每组}} = \frac{(z_{1-\alpha/2} + z_{1-\beta})^2\big[\bar p(1-\bar p) + \bar p(1-\bar p)\big]}{\delta^2} = \frac{2(z_{1-\alpha/2}+z_{1-\beta})^2\,\bar p(1-\bar p)}{\delta^2}$$

$\alpha=0.05$、功效 $80\%$ 时化简为 $n \approx 15.7\,\bar p(1-\bar p)/\delta^2 \approx 16\,\bar p(1-\bar p)/\delta^2$。

**（3）反推最小可检测效应（MDE）**

固定 $n$ 反解 $\delta$：

$$\text{MDE} = (z_{1-\alpha/2}+z_{1-\beta})\sqrt{\frac{2\bar p(1-\bar p)}{n}} \approx 4\sqrt{\frac{\bar p(1-\bar p)}{n}}$$

**（4）效应量的标准化形式**（Cohen's $d$）

$$d = \frac{\delta}{\sigma}$$

常见经验刻度：$d=0.2$ 小、$0.5$ 中、$0.8$ 大。用 $d$ 表示时样本量公式简化为

$$n_{\text{每组}} = \frac{2(z_{1-\alpha/2}+z_{1-\beta})^2}{d^2} \approx \frac{16}{d^2}\ (80\%\text{ 功效})$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\alpha$ | 显著性水平 | 假阳性率上限，常取 $0.05$ |
| $\beta$ | 第二类错误率 | 漏报率，常取 $0.20$ |
| $1-\beta$ | 功效 | 有效应时检出的概率，常取 $80\%$ |
| $\delta$ | 效应大小 | 想检测的真实差距（绝对尺度） |
| $d = \delta/\sigma$ | 标准化效应量 | 无量纲；跨研究比较用 |
| $\text{MDE}$ | 最小可检测效应 | 给定 $n$ 下功效恰为 $80\%$ 的那个 $\delta$ |
| $z_{1-\alpha/2}, z_{1-\beta}$ | 正态分位数 | $1.96$ 与 $0.84$（常用配置） |

**两条实用推论**：

1. **样本量对效应量是平方反比，对噪音方差是正比**——降低噪音（更好的测量、更同质的样本、区组设计）和增加样本量都是提高功效的手段，但**前者常常更便宜**。这就是[实验设计](./90-experimental-design.md)里区组设计的实战价值：它不增加样本，却直接缩小了 $\sigma^2$；
2. **事后的功效分析是没意义的**——如果你已经得到不显著的结果，去算"我的功效是多少"是循环论证（用了观测到的效应量来算功效，而观测到的效应量恰恰是被数据污染过的）。**功效分析必须在实验之前做**，这是它最容易被误用的一点。

## 4. 分步例题

**例一：两样本比例检验算样本量。**

基线转化率 $p_A = 10\%$，团队想检出 $p_B = 12\%$（绝对提升 $2$ 个百分点，相对提升 $20\%$）。$\alpha=0.05$、功效 $80\%$。

1. **效应量**：$\delta = 0.12 - 0.10 = 0.02$；
2. **基线项**：取 $\bar p = 0.11$，$\bar p(1-\bar p) = 0.11\times0.89 = 0.0979$；
3. **代入公式**：$n = 15.7\times0.0979/0.02^2 = 1.537/0.0004 \approx 3843$；
4. **结论**：**每组约 3900 人，共约 7800 人**；
5. **平方反比验证**：若改为检出 $1$ 个百分点（$\delta=0.01$），$\bar p = 0.105$，$\bar p(1-\bar p)=0.093975$，$n = 15.7\times0.093975/0.0001 \approx 14754$——**效应减半，样本量涨了约 3.84 倍**，与 $1/\delta^2$ 一致 ✔。

**例二：固定样本量反推 MDE。**

流量紧张的团队只能凑出**每组 1000 人**，基线 $p = 10\%$。问：这个实验能可靠检出多大的提升？

1. **代入 MDE 公式**：$\text{MDE} \approx 4\sqrt{0.1\times0.9/1000} = 4\sqrt{0.00009} = 4\times0.009487 \approx 0.0379$；
2. **读结论**：只能可靠检出约 **3.8 个百分点**的绝对提升，即相对提升约 $38\%$；
3. **这意味着什么**：如果新版本的真实提升是 $5\%$（绝对 $0.5$ 个百分点），这个实验**大概率（约 $80\%$ 以上）会给出"不显著"**——而这不是"新版本没用"，是**实验规模不够**；
4. **正确的沟通方式**：报告应当写成"本实验可检出 $\ge 3.8$ 个百分点的提升；观测到的不显著差异（$+0.4$ pp）**既不能排除小效应，也不能证实无效应**"；
5. **对照**：把一个"不显著"直接写成"新版本没有影响"，是把**功效不足**误读成了**效应不存在**——统计推断里最昂贵的一类错误。

**例三：$2\times2$ 的权衡表。**

同一个实验的需求变化如何影响样本量（基线 $p=10\%$，每组）：

| 想要的配置 | $\delta$ | 功效 | 每组 $n$ |
| --- | --- | --- | --- |
| 检出 $2$ pp，$80\%$ 功效 | $0.02$ | $80\%$ | $\approx 3843$ |
| 检出 $2$ pp，$90\%$ 功效 | $0.02$ | $90\%$ | $\approx 5142$（$z$ 换成 $1.645$） |
| 检出 $1$ pp，$80\%$ 功效 | $0.01$ | $80\%$ | $\approx 14754$ |
| 检出 $0.5$ pp，$80\%$ 功效 | $0.005$ | $80\%$ | $\approx 58\,000$ 以上 |

1. **功效从 $80\%$ 提到 $90\%$**：样本量涨约 $34\%$（$(1.96+1.645)^2/(1.96+0.84)^2 \approx 1.34$）；
2. **效应减半**：涨约 $4$ 倍；
3. **效应减到四分之一**：涨约 $16$ 倍——$n$ 破万、破十万；
4. **一句话总结这张表**：**"想看清楚"的精度要求每提高一档，成本跳一个数量级。** 这是所有实验平台必须让业务方理解的第一课。

### 实验 2（python）：用模拟验证功效公式

公式是推导出来的，但我们完全可以不改公式、直接模拟来验证它。下面做一件很有价值的事：**用蒙特卡洛模拟"重复做一万次实验"，数一数多少次正确地检出了真效应**——这个比例就是功效：

```python title="用一万次模拟实验验证功效公式"
import random
import math

random.seed(29)

p_a = 0.10          # A 组真实转化率
p_b = 0.12          # B 组真实转化率（真实效应 +2 个百分点）
n_per = 200         # 每组人数（故意先取小样本，看功效有多低）
trials = 10000      # 重复次数
alpha = 0.05

def one_trial(n):
    xa = sum(1 for _ in range(n) if random.random() < p_a)   # A 组成功数
    xb = sum(1 for _ in range(n) if random.random() < p_b)   # B 组成功数
    pa = xa / n
    pb = xb / n
    ppool = (xa + xb) / (2 * n)
    se = math.sqrt(ppool * (1 - ppool) * (1 / n + 1 / n))
    if se == 0:
        return False
    z = (pb - pa) / se
    return abs(z) > 1.96                                     # 双侧 5% 拒绝域

for n in [200, 1000, 3843, 8000]:
    detected = 0
    for _ in range(trials):
        if one_trial(n):
            detected = detected + 1
    print("每组 n =", n, "→ 实测功效 =", round(detected / trials, 4))

# 公式预测值
delta = p_b - p_a
pbar = (p_a + p_b) / 2
for n in [200, 1000, 3843, 8000]:
    n_formula = 15.7 * pbar * (1 - pbar) / (delta ** 2)
    print("每组 n =", n, "→ 公式所需样本为", round(n_formula), "（n 大于它则功效超过 80%）")
```

输出的对照很有说服力：**公式说需要约 $3843$ 人，模拟结果也正是在 $n\approx3843$ 附近功效跨过 $80\%$**。$n=200$ 时功效只有两成多——**这意味着五次实验里有四次会得出"不显著"，而那四次都是漏报。** 这就是"小样本实验跑不显著"的定量真相。

### 实验 3（python）：降噪与加样本，哪个更划算

功效有两个旋钮：加样本（$n\uparrow$）和降噪音（$\sigma\downarrow$）。两者对功效的贡献不同——$n$ 是平方根律，$\sigma$ 是线性：

```python title="加样本 vs 降噪音：同样是两倍，效果差多少"
# 用标准化效应量 d = delta / sigma 来比较
# n_per_group = 2 * (1.96 + 0.84)^2 / d^2
def n_needed(d):
    return 2 * (1.96 + 0.84) ** 2 / (d ** 2)

d0 = 0.5                      # 最初的标准化效应量
print("基准：d =", d0, "→ 每组需要", round(n_needed(d0)), "人")

# 路线一：样本量翻倍，噪音不变
n_new = n_needed(d0) * 2
d1 = math.sqrt(2 * (1.96 + 0.84) ** 2 / n_new)
print("样本翻倍后 → 等效 d =", round(d1, 4), "（相当于把可检效应缩小到原来的",
      round(d1 / d0, 4), "倍）")

# 路线二：把测量噪音降一半（sigma 减半 → d 翻倍）
d2 = d0 * 2
print("噪音减半后 → 等效 d =", round(d2, 4), "→ 每组只需", round(n_needed(d2)), "人")
print("样本量节省 =", round(1 - n_needed(d2) / n_needed(d0), 4))
```

对比两行结论：**样本量翻倍，可检测效应只缩小到 $1/\sqrt2 \approx 0.707$ 倍**；而**把测量噪音降一半（$d$ 翻倍），所需样本量直接降到四分之一**。这解释了一个常见的工程现实：**在实验里花力气改进测量精度、控制外部变量、做区组分层，往往比单纯加流量便宜得多。** 这正是[实验设计](./90-experimental-design.md)那一课存在的理由。

```quiz
一个 A/B 实验跑完得到 p = 0.31，报告写"新版本对转化率没有影响"。最大的问题是什么？
- p 值应该取单侧
- 缺少功效分析，无法区分"确实无效应"与"样本不足以检出效应" [*]
- 应该改用置信区间而不是 p 值
? 不显著只是"没有足够证据拒绝原假设"，不等于"证明了原假设"。没有事先的 MDE 计算，读者无法知道这个实验能检出多大的效应，因而无法判断"没检出"意味着什么。
```

::::warning[常见误区]

**误区一**："你以为不显著就等于无效应。" 这是统计学里最普遍的误读。"不显著"只说"证据不足"，不说"效应为零"。一个功效只有 $30\%$ 的实验，即使真实效应很可观，也有七成概率报告"不显著"。**正确表述是"本实验未检出显著差异（MDE = X）"，而不是"没有差异"。**

**误区二**："你以为事后算一下功效就能补救。" 事后（post-hoc）功效分析是**循环论证**：它要用"观测到的效应量"来算功效，而观测到的效应量本身就是数据的一部分。观测效应恰好落在临界值附近时，事后功效总在 $50\%$ 上下——这不提供任何新信息。**功效分析的正确时机是实验之前**，用于决定样本量。

**误区三**："你以为加样本总是能解决问题。" 加样本解决的是**随机误差**（方差），解决不了**系统偏差**。设计有偏（分流不随机、指标定义错、流失不均衡）时，样本加得越多，你对一个错答案的信心就越足。**先保证无偏，再谈精度**——这个顺序不能颠倒。

**误区四**："你以为显著性水平越高（$\alpha$ 越大）越好。" 放宽 $\alpha$ 确实能提高功效，但代价是假阳性率上升。更糟的是：如果团队同时监控很多指标、反复偷看结果（[A/B 测试实战](./40-ab-testing.md)的误区三），实际的假阳性率早就远超标称的 $\alpha$。**放宽门槛是拆东墙补西墙，加样本才是唯一没有副作用的做法——当然它最贵。**

**误区五**："你以为 $5\%$ 的提升就"值得上线"。" 统计显著和商业重要是两回事。$n$ 足够大时，$0.1$ 个百分点的提升也能"显著"，但它值不值得承担上线风险、维护成本、代码复杂度，是另一个层面的判断。**功效分析告诉你"能不能测出来"，成本收益分析告诉你"要不要测"。**

## 6. 练习

**练习 1**（概念口答）：为什么"降低测量噪音"和"增加样本量"对功效的贡献**不成比例**？请用公式说明。

<details>
<summary>点开查看逐步解答</summary>

看效应量的两种写法：

$$d = \frac{\delta}{\sigma}, \qquad n_{\text{每组}} \approx \frac{16}{d^2} = \frac{16\,\sigma^2}{\delta^2}$$

**样本量对 $\delta$ 是平方反比，对 $\sigma$ 是正比。** 具体对比：

- 想让可检测的 $\delta$ **减半**，$n$ 要乘 $4$（$1/\delta^2$）；
- 想让 $\sigma$ **减半**，所需 $n$ 要除以 $4$——**降噪的收益是样本量的平方级别**。

更直白地说：**$\sigma$ 出现在分子上是一次方，$\delta$ 出现在分母上是二次方**。降噪让分母（相对于信号的尺度）同步变小，效果不打折；而加样本只是在平均噪声上做 $1/\sqrt n$ 的缓慢削减。

**为什么降噪更便宜的第二个理由**是工程现实：加样本意味着更多的用户、更长的时间、更高的机会成本（多跑一周，竞争者可能已经上线了）。而降噪往往是一次性投入——改进测量仪器、统一实验流程、按关键变量分层（区组）、减少外部干扰（同一时段、同一渠道对比）。**这些投入一旦做好，之后每一个实验都受益。**

**第三个理由**与"平方根律"直接相关：样本量从 $10^4$ 涨到 $10^5$（十倍成本），精度只提升 $3.16$ 倍；而同样的钱如果能买到 $3.16$ 倍的噪音降低，效果完全一样——但后者往往没人做，因为它不显眼。这是实验设计里最被低估的一课。

</details>

**练习 2**（判题）：下面代码想算"检出 2 个百分点提升（基线 10%）所需的每组样本量"，但它把系数里的两个分位数搞混了，而且方差项写成了"两组共用一份"：

```exercise
# @title: 练习：修对两样本比例的样本量
# @check: 3843
# @check: 0.02
# @hint: 两组各有一份 p(1-p) 的噪音，所以系数是 2*(1.96+0.84)^2 ≈ 15.7；1.96 管显著性、0.84 管功效，不能调换成一个数。
p_a = 0.10          # A 组基线转化率
p_b = 0.12          # B 组目标转化率
z_alpha = 0.84      # ← 问题在这：95% 显著性应对应 1.96
z_beta = 1.96       # ← 问题在这：80% 功效应对应 0.84

pbar = (p_a + p_b) / 2
delta = p_b - p_a

n = ((z_alpha + z_beta) ** 2) * pbar * (1 - pbar) / (delta ** 2)   # ← 少了因子 2
print(round(n))
print(round(delta, 4))
```

两行分别卡住两个量：效应量应为 $0.02$；每组样本量应约为 $3843$。**注意两个细节**：一是分位数虽然加起来之和相同（都是 $2.8$），但概念上必须各自对应"管显著性"和"管功效"；二是两组各贡献一份方差，所以要有因子 $2$——少了它结果会差一半。

## 7. 选读：功效的语言为什么值得学

<details>
<summary>选读 · 从"p 值报告"到"设计报告"</summary>

功效分析的意义远不止"算个数"。它改变的是一份研究报告的**信息结构**。

一份只报 p 值的研究，读者能提取的信息极其有限：知道"是否显著"，不知道"效应可能是多大"（该给[置信区间](./20-confidence-interval.md)），也不知道"没显著意味着什么"（该给 MDE）。这三件事缺了任何一件，结论都无法被正确解读。

引入功效之后，报告会自然变成另一副样子：

1. **先声明目标**："本实验旨在检出 $\ge 2$ 个百分点的绝对提升（相对 $20\%$）"；
2. **再声明规模**："为此需要每组 $n=3900$，根据 $\alpha=0.05$、功效 $80\%$ 计算"；
3. **然后给出结果**："观测到 $+0.4$ 个百分点（$95\%$ CI: $[-0.9, +1.7]$），$p=0.55$"；
4. **最后给出可辩护的结论**："未检出显著差异；由于本实验可可靠检出 $\ge 2$ pp，**大于 $2$ pp 的效应基本可以被排除，但小效应仍无法判断**"。

第 4 条的表述与"没有影响"有天壤之别——**它把一个模糊的否定，换成了一句有明确边界的话。** 这正是统计推断这门学科想要达到的状态：不是给出确定性，而是给出**在给定规模下能说什么、不能说什么**的清晰划界。

这套语言在多个场景都有直接对应：临床试验必须事先注册样本量与主要终点（否则监管不认）；工业界实验平台通常强制要求预先声明 MDE（防止事后挑指标）；A/B 平台的"实验前样本量计算器"就是本课公式的直接产品化。而它与[多重检验与 FDR](./85-multiple-testing-fdr.md) 是同一条纪律线的两端：**一个管"不要漏掉真效应"，一个管"不要造出假效应"**——两者加起来，才能支撑"高频实验"这件事在组织里长期成立。

最后一点值得记住：**本课的所有公式都假设了一个具体的检验方式**（$z$ 检验、双侧、近似正态）。换成 $t$ 检验（小样本时更准确）、换成非参数检验（[置换检验](./80-permutation-tests.md)）、换成序贯设计，公式的系数会变——但"信号与噪音之比决定功效"这个骨架永远不变。**记住骨架，系数可以查表。**

</details>
