# 从样本猜总体：点估计与标准误

## 1. 从一个场景开始

工厂刚下线十万颗轴承，质检员不可能全部测量，只抽了 100 颗：平均直径 25.02 毫米。经理问三个问题——总体真实平均值是多少？这个 25.02 有多可信？如果再抽 100 颗，还会是 25.02 吗？

描述统计（第 9 章）告诉我们怎么总结手头数据；这一课开始回答更进一步的问题：**用手头的一小撮数据，反过来推测看不见的全貌**。这就是统计推断的第一步。

## 2. 直觉解释

把总体想成一锅汤，样本是一勺。想知道咸不咸，不必喝完整锅——尝一勺就行。但勺子有大有小：

- 勺子越大（样本量 $n$ 越大），尝出的味道越接近整锅；
- 换一勺再尝，味道会略有不同——**估计值天生会抖动**；
- 抖动的典型幅度是可以算出来的，它就是本课的主角**标准误**。

关键转念：别把 25.02 当成一个数，把它当成"无数个可能样本给出的答案之一"。反复抽样得到的估计值们自己会形成一个分布（抽样分布），这个分布的离散程度就量化了"这一勺有多靠谱"。

## 3. 正式定义

设总体的某个数字特征（如均值 $\mu$）未知。用样本算出的、用来猜测它的量叫**点估计量**：

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mu, \sigma$ | 总体参数 | 整锅汤的真实均值/标准差，通常未知 |
| $x_1,\ldots,x_n$ | 样本 | 从总体中随机抽出（独立、放回意义上可重复）的 $n$ 个观测 |
| $\bar{x}$ | 样本均值 | $\mu$ 的点估计：$\bar{x}=\frac{x_1+\cdots+x_n}{n}$ |
| $s$ | 样本标准差 | $\sigma$ 的点估计 |
| $\mathrm{SE}$ | 样本均值的**标准误** | $\mathrm{SE}=\dfrac{\sigma}{\sqrt{n}}$（$\sigma$ 未知时用 $s$ 代替） |

标准误公式是本课的顶梁柱，注意两点：它与总体波动 $\sigma$ 成正比（汤本身忽咸忽淡，一勺就更不准）；它与 $\sqrt{n}$ 成反比（精度走的是平方根慢车道——想要准一半，样本得翻四倍）。它是第 9 章大数定律"越抛越稳"的定量版本。

## 4. 分步例题

**例**：已知某自动灌装线每瓶体积的标准差稳定在 $\sigma=2$ 毫升。抽取 $n=16$ 瓶，样本均值 $\bar{x}=499.5$ 毫升。目标均值 500 毫升。估计值离目标有多远？这个距离算大还是小？

1. 写出标准误：$\mathrm{SE}=\dfrac{2}{\sqrt{16}}=\dfrac{2}{4}=0.5$ 毫升；
2. 计算偏离：$499.5-500=-0.5$ 毫升，即恰好偏离 1 个标准误；
3. 判断：按第 36 章抽样分布的经验（也是下一章置信区间的地基），单次抽样偏离 1 个标准误以内属于家常便饭，不能说明生产线坏了；
4. 反问一句：若只抽 4 瓶呢？$\mathrm{SE}=2/\sqrt{4}=1$ 毫升，同样的 0.5 毫升偏离只算半个标准误——**同样的差距，样本量不同，含义完全不同**。

## 5. 动手实验

### 实验 1（viz）：每一次拖动都是一次重新抽样

```viz
{
  "type": "statdots",
  "n": 10
}
```

怎么玩：把这 10 个蓝点当作一次抽到的样本，随手拖动它们——顶部读数里的样本均值 $\bar{x}$ 就是你的"点估计"。每换一种摆法，就相当于从总体里重新抽了一勺。盯住均值读数：它跟着数据抖动，这正是估计量的天生属性，不是你拖错了。

### 实验 2（python）：抽样分布搅拌机

固定一个"总体"（0 到 9 的均匀随机数），反复抽样本量为 $n$ 的样本、记下每个样本均值，看这些均值的散布范围：

```python title="一万次抽样，看样本均值的散布"
import random                     # 随机库：第 0 章已引入
import matplotlib.pyplot as plt   # 画图库：第 0 章已引入

# sliders: n=10 [2:100:1]

means = []                        # 存一万个样本均值的列表
for trial in range(10000):
    total = 0
    for i in range(n):            # 每次抽 n 个个体
        digit = random.randint(0, 9)   # 总体：0~9 等可能
        total = total + digit
    means.append(total / n)       # append：往列表末尾追加这个样本的均值

plt.hist(means, bins=40)          # hist：直方图，看均值们堆叠成什么形状
plt.title(f"{n} 个样本时，均值的散布")
```

拖动滑块把 $n$ 从 2 拉到 100：直方图从矮胖压成细高——散布宽度大约按 $1/\sqrt{n}$ 收缩，这就是标准误公式的肉眼版。

### 实验 3（python）：实测标准误，对照公式

```python title="散布宽度的实测值 vs sigma/sqrt(n)"
import random
import math                       # 数学库：开方用

sigma = math.sqrt(8.25)           # 总体 0~9 均匀分布的真实标准差（方差 8.25）

for n in [4, 16, 64]:
    means = []
    for trial in range(5000):
        total = 0
        for i in range(n):
            total = total + random.randint(0, 9)
        means.append(total / n)

    # 手算标准差（第 9 章的五步流程）：先求均值，再累加偏差平方
    m = sum(means) / len(means)           # sum：受管内置函数，第 0 章出生
    spread = 0
    for v in means:
        spread = spread + (v - m) ** 2
    measured = math.sqrt(spread / len(means))

    formula = sigma / math.sqrt(n)
    # f 字符串里 {x:.4f} 表示保留 4 位小数输出
    print(f"n={n}: 实测 {measured:.4f} | 公式 {formula:.4f}")
```

两列数字几乎重合——$\mathrm{SE}=\sigma/\sqrt{n}$ 不是理论家的装饰品，是能实测出来的物理量。

### 快问快答

```quiz
样本量翻四倍，标准误变成原来的几倍？
- 四倍
- 一半 [*]
- 不变
? 标准误与根号 n 成反比：n 翻四倍，根号 n 翻两倍，标准误减半。精度走的是平方根慢车道。
```

:::warning[常见误区]

**误区一**："你以为样本均值就是真值。" 它只是估计值，天生带抖动。负责任的说法永远带着误差范围："约 499.5，上下浮动约 1 毫升"。

**误区二**："你以为标准误就是标准差。" 标准差 $\sigma$ 描述**个体**的散布（一瓶和另一瓶差多少）；标准误 $\sigma/\sqrt{n}$ 描述**均值这个估计量**的散布（一批样本的均值和另一批差多少）。后者比前者小，且随 $n$ 缩小。

**误区三**："你以为想让误差减半就把样本量加倍。" 平方根律说不行：加倍只让标准误缩到原来的 $1/\sqrt{2}\approx 0.71$。减半需要四倍样本——调查公司报价比常人想象贵的原因之一。

:::


**练习 2**：两次民调各访问 400 人与 1600 人，估计值的"抖动幅度"之比是多少？

<details>
<summary>点开查看逐步解答</summary>

标准误之比 $=\sqrt{1600}/\sqrt{400}=40/20=2$。访问 1600 人的那次抖动只有一半。反过来说：想让民调误差从 5% 降到 2.5%，样本要从 400 加到 1600——电话费翻四倍，这是所有民调机构都面对的平方根税。

</details>

**练习 3**：质检员说"我抽了 3 颗轴承都没超差，所以整批合格"。用本课语言指出这句话的两个漏洞。

<details>
<summary>点开查看逐步解答</summary>

其一，样本太小：$n=3$ 时标准误高达 $\sigma/\sqrt{3}\approx 0.577\sigma$，估计极粗，坏批次的漏检概率很大。其二，"没抽到坏的"不等于"没有坏的"——点估计没说话之前，先要看抽样方案能不能代表总体（随机性）以及样本量够不够（精度）。推断的可信度由这两件事决定，不由"我感觉没问题"决定。

</details>

## 7. 选读：为什么偏偏是 $\sqrt{n}$

<details>
<summary>选读 · 平方根律的来源</summary>

把 $n$ 个独立观测的偏差想成 $n$ 个独立的"小抖动" $e_1,\ldots,e_n$，各自方差都是 $\sigma^2$。样本均值是它们的平均：$\bar{e}=(e_1+\cdots+e_n)/n$。独立变量的方差相加（可加性），于是

$$\operatorname{Var}(\bar{e})=\frac{\sigma^2+\cdots+\sigma^2}{n^2}=\frac{n\sigma^2}{n^2}=\frac{\sigma^2}{n}$$

开根号得 $\mathrm{SE}=\sigma/\sqrt{n}$。分母上是 $n^2$ 再开根号，而不是 $n$——平方根律的户口就在这一步。这也顺带解释了第 9 章埋的伏笔：两颗骰子和的标准差乘 $\sqrt{2}$，同一套方差可加性。

</details>
