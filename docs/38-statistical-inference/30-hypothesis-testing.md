# 假设检验与 p 值：统计裁决程序

## 1. 从一个场景开始

药店声称"排队不超过 8 分钟"。你连续一周暗中观察，抽样 36 人得到平均 9.2 分钟。药店喊冤："运气不好而已，再抽一次说不定还不到 8！"

怎么裁？靠嗓门没用，需要一套公认的裁决程序：先假设药店无辜，再看**如果假设成立，你抽到的这组数据有多离谱**。离谱到一定程度才定罪。这就是假设检验——统计学版的反证法。

## 2. 直觉解释

整套程序的剧本只有四步：

1. **立被告推定**：默认"没有效应"成立（排队就是 8 分钟、新药就是无效）。这个默认立场叫**零假设 $H_0$**；
2. **问极端度**：在 $H_0$ 的世界里模拟发牌，问"抽到像手上这么离谱（或更离谱）的数据"的概率是多少——这个概率就是大名鼎鼎的 **p 值**；
3. **设红线**：事先约定一个容忍线 $\alpha$（习惯取 0.05）：比这更离谱的事若发生，说明"运气不好"的解释站不住脚；
4. **裁决**：p 值小于红线就拒绝 $H_0$（数据显著）；否则说"证据不足"，注意这**不是**宣布 $H_0$ 为真，只是当庭证据不够。

一句话记牢 p 值：**在零假设成立的前提下，出现当前或更极端数据的概率**。它是关于数据的陈述，不是关于假设真假的陈述。

## 3. 正式定义

对均值的 z 检验（总体标准差已知情形）：

$$z=\frac{\bar{x}-\mu_0}{\sigma/\sqrt{n}}, \qquad p=P(\text{与 } z \text{ 同样极端或更极端} \mid H_0)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $H_0$ | 零假设 | "没有效应/没有差别"的默认立场 |
| $H_1$ | 备择假设 | 你想证明的命题："有效应" |
| $\mu_0$ | 检验值 | $H_0$ 里设定的参数值（如 8 分钟） |
| $z$ | 检验统计量 | 观测偏离按标准误折算后的倍数 |
| $p$ | p 值 | $H_0$ 下数据的离谱程度，越小越离谱 |
| $\alpha$ | 显著性水平 | 裁决红线，常取 0.05 |

两类错误对照表（记住谁是谁）：

| | 实际 $H_0$ 为真 | 实际 $H_0$ 为假 |
| --- | --- | --- |
| 拒绝 $H_0$ | **第一类错误**（错判无辜），概率至多 $\alpha$ | 正确裁决（检出效应） |
| 不拒绝 $H_0$ | 正确裁决 | **第二类错误**（漏放真凶），概率记为 $\beta$ |

经验法则：双侧检验中 $|z|>1.96$ 等价于 $p<0.05$——这正是上一课置信区间里那个 1.96 的又一次登场。

这张对照表目前只立了定性户口：两类错误的概率各是多少、拒绝域怎么画才把功效榨到最大，[充分统计量与最优检验](./55-sufficiency-np.md)一课会配一枚可动手的"功效四格实验"逐格结算。

## 4. 分步例题

**例**：继续开头的案子。$\bar{x}=9.2$，$\mu_0=8$，$\sigma=3$，$n=36$。

1. 写标准误：$\mathrm{SE}=3/\sqrt{36}=3/6=0.5$；
2. 算统计量：$z=(9.2-8)/0.5=1.2/0.5=2.4$；
3. 对红线：开头的问题只问“是否超过 8 分钟”，所以这是**单侧检验**；红线为 $z>1.645$，单侧 p 值约 0.008；
4. 裁决：拒绝“排队不超过 8 分钟”——若药店所言为真，36 人平均超过 9.2 分钟的概率不足 1%，冤枉它的风险很小但存在（这就是 $\alpha$）。

若质检方案事先关心“偏高或偏低”两个方向，就改用双侧判据 $|z|>1.96$ 和双尾 p 值约 0.016；本例结论不变。关键是：单侧还是双侧必须在看数据前定下，不能看到 9.2 偏高后再选对自己有利的方向。

四步模板固定：**定假设 → 算标准误 → 折算偏离 → 对红线裁决**。任何均值型问题都照此办理。

## 5. 动手实验

### 实验 1（python）：p 值亲手掷出来

一枚硬币抛 100 次，正面 65 次。公平硬币（$H_0$：正面概率 0.5）会这么离谱吗？直接把 $H_0$ 的世界模拟一万遍，数一数：

```python title="公平硬币下，100 抛里出现至少 65 或至多 35 次正面的频率"
import random                     # 随机库

extreme = 0                       # 记录同样离谱或更离谱的次数
for trial in range(10000):
    heads = 0
    for flip in range(100):
        if random.random() < 0.5:   # random.random()：返回 0 到 1 的均匀小数（首见）
            heads = heads + 1       # 小于 0.5 记作正面，模拟公平硬币
    # 与 65 一样极端：偏离中心 50 至少 15 个
    if abs(heads - 50) >= 15:       # abs：绝对值，第 6 章出生
        extreme = extreme + 1

print(extreme / 10000)            # 这就是经验 p 值
```

结果约 0.0035——公平硬币一万次里只摊上三十几次。所以 65 次正面是很强的"硬币有问题"证据。理论值 0.0035 也告诉我们：**p 值不是玄学，是可以掷出来的频率**。

### 实验 2（python）：零假设世界的全貌

把一万次试验的正面数画成直方图，亲眼看看"运气不好"能不好到什么程度：

```python title="H0 世界里正面数的分布"
import random
import matplotlib.pyplot as plt

results = []
for trial in range(20000):
    heads = sum(random.random() < 0.5 for _ in range(100))   # 生成器求和：每个 _ 代表一次抛掷
    results.append(heads)

plt.hist(results, bins=range(30, 72), align="left")   # bins 指定从 30 到 71 每格一柱
plt.axvline(65, color="tomato")    # 红线画在 65：我们观测到的位置
plt.axvline(50, color="gray", linestyle="--")
```

灰色虚线是 $H_0$ 的中心，红色竖线是观测值 65——它孤零零地站在右尾坡上，脚下已经没什么柱子了。"p 值小"就是"红线下方几乎没柱子"。

### 快问快答

```quiz
某实验算出 p 值等于 0.03。这句话的意思是？
- 零假设为真的概率是 3%
- 观测数据由纯运气造成的可能性有 3%
- 若零假设为真，出现当前这样极端或更极端的数据的概率是 3% [*]
? p 值是在「零假设成立」这个前提下的数据概率，方向不能反过来：它不是假设本身的概率。要谈假设的概率，得请出下一章的贝叶斯。
```

:::warning[常见误区]

**误区一**："你以为 p 值是零假设成立的概率。" 方向反了。p 值回答的是 P(数据这么极端 $\mid H_0$)，而你想知道的是 P($H_0 \mid$ 数据)——两者之间隔着贝叶斯公式（下一章的主角），不能直接划等号。

**误区二**："你以为不显著就证明了没有差异。" "证据不足"不是"证明无罪"。可能是效应真的不存在，也可能是样本太小、功效不足没探测到。法庭放人也不等于宣判清白。

**误区三**："你以为 p=0.049 和 p=0.051 有天壤之别。" 红线 0.05 是社会约定俗成，不是自然常数。两个 p 值描述的数据离谱程度几乎相同；把连续的证据强度硬切成"显著/不显著"两半，是大量伪发现的温床。

:::

## 6. 练习

**练习 1**：某流程改进后抽查 16 件，$\bar{x}=10.4$ 小时，$H_0$ 设定 $\mu_0=10$，$\sigma=2$。算 z 统计量并判断是否显著（红线 1.96）。下面的代码能跑但结论是错的——改到通过：

```exercise
# @title: 练习：z 统计量与裁决
# @check: 0.8
# @check: False
# @hint: z 是「偏离量除以标准误」：(xbar - mu0) / (sigma / sqrt(n))；显著判断是 abs(z) > 1.96
import math   # 开方用

xbar = 10.4   # 样本均值
mu0 = 10      # 零假设里的值
sigma = 2     # 总体标准差
n = 16        # 样本量

se = sigma / n                # ← 第一处问题：标准误忘了开根号
z = (xbar + mu0) / se         # ← 第二处问题：符号写反了
print(round(z, 2))
print(abs(z) < 1.96)          # ← 第三处问题：大于还是小于？
```

**练习 2**：把练习 1 的样本量从 16 改成 400（其余不变），重新裁决并解释变化。

<details>
<summary>点开查看逐步解答</summary>

$\mathrm{SE}=2/\sqrt{400}=0.1$，$z=0.4/0.1=4$，远超 1.96，显著。同样的 0.4 小时差距，小样本下被噪音淹没，大样本下清晰可辨——**检验看的是"信号相对噪音的倍数"，样本量决定噪音的大小**。这也解释了为什么"大样本什么都显著"：微小差异也会被放大过红线，此时该问的是差异有没有实际意义（效应量），而不是只看显著性。

</details>

**练习 3**：药检流程把 $\alpha$ 从 0.05 收紧到 0.001。第一类和第二类错误各如何变化？什么场合值得这么收紧？

<details>
<summary>点开查看逐步解答</summary>

红线更苛刻 → 更难拒绝 $H_0$ → 错判无辜（假阳性、批准无效药）减少；代价是漏放真凶（漏掉有效药）增多。批准上市这类"错误代价极高"的场景值得收紧；初筛探索类场景反而故意放宽红线多捞线索，后续再复核。两类错误是一对此消彼长的旋钮，不存在同时拧小的免费午餐——想两者都小，唯一出路是加大样本。

</details>

## 7. 选读：p 值的历史小插曲

<details>
<summary>选读 · 0.05 是怎么成为铁律的</summary>

费希尔在 1920 年代著书时随手建议：可以把 20 分之一（0.05）当作值得回头复查的门槛，并明确说过"应当根据具体问题灵活选择"。后人把它刻成石律、印进软件，久而久之演变成"p<0.05 即真理、否则即无物"的机械仪式。2016 年美国统计学会发表声明提醒全世界：p 值只是证据链中的一环，必须配合效应量、研究设计与可重复性一起阅读。本课教你的是这套程序的正确读法，不是教你对 0.05 顶礼膜拜。

</details>
