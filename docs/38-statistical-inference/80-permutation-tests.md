# 置换检验：不靠分布假设的显著性

## 1. 从一个场景开始

学校后勤花预算买了一批护眼灯，宣传说能延长晚自习的专注时间。总务主任想把话说得有底气，可经费只够请到 15 位志愿者：随机分两组，8 人坐在普通日光灯教室，7 人坐在护眼灯教室，一周后测每人当天最长专注分钟数：

| 组别 | 专注分钟 |
| --- | --- |
| 普通灯 | 32, 27, 35, 29, 30, 26, 33, 31 |
| 护眼灯 | 34, 39, 36, 41, 38, 40, 37 |

护眼灯组平均 37.86 分钟，普通灯组平均 30.38 分钟，差了近 7 分半。第 30 课的 z 检验公式此刻却很尴尬：它默认"样本均值的抖动服从正态分布"，而这层担保来自中心极限定理的大样本渐近——**n 都不到 10，天知道专注时长是什么分布**。

1950 年代之前，统计学家在这种小样本面前的办法只有硬查基于正态近似的 t 表。而更古老、更笨也更诚实的思路藏在第 09 章的计数原理里：既然原假设说的是"**灯光和成绩无关，标签随便贴**"，那就不妨亲手把标签撕下来重贴一万次，看看运气能把 7 分钟的差距伪造到什么程度。这条路不需要任何分布假设——**数据自己给自己当参考系**。

## 2. 直觉解释

把 15 个专注分钟数倒进一个碗里，两组的身份只是两张贴纸。若"贴纸无关紧要"为真，则任何一种重新分组——比如让 41 和 26 同坐护眼灯班——都和真实看到的那次分组一样可信。

- **每一次重贴标签，就是一场平行宇宙的排练**：假装这次随机分组倒霉透顶/走运到家，算出两种均值之差；
- 把上万个宇宙的差距画成直方图，就得到了"纯靠运气能造出多大差距"的经验答案；
- 最后回头看真实观测的那条 7.48 分钟线站在哪里：如果它孤零零杵在几千个宇宙之外，标签怕是并非无关；如果它缩在人堆里，就该给护眼灯退货。

这就是**置换检验**的全部灵魂：不用向正态分布借权威，而是用随机化本身的逻辑制造参照物。它笨得惊人——纯粹的重复打乱与计数——但正因为笨，它对小样本、怪形状分布几乎免疫。

## 3. 正式定义

设两组观测合并为池子 $\lbrace x_1,\dots,x_n\rbrace$（记号里的大括号读作"集合"），两组容量分别为 $n_A$、$n_B$。

**检验统计量**：选一个刻画"组间差距"的量，常用均值差

$$T=\bar{x}_B-\bar{x}_A$$

**原假设** $H_0$：所有观测来自同一个总体，标签可任意交换（可交换性）。

**置换分布**：在 $H_0$ 下，把池子里的值重新分为两组的所有 $\binom{n}{n_B}$ 种分法等可能，每种分法算出的 $T^{*}$ 全体构成置换分布。

**置换 p 值**：

$$p=\frac{\#\lbrace T^{*}\ge T_{obs}\rbrace}{\binom{n}{n_B}} \qquad \text{（单侧；双侧改用 } |T^{*}|\ge|T_{obs}| \text{）}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $T_{obs}$ | 观测统计量 | 真实数据算出的差距 |
| $T^{*}$ | 置换统计量 | 某个平行宇宙里伪造的差距 |
| $\binom{n}{n_B}$ | 世界总数 | 从 n 人里选对照组的所有方式数（第 09 章的组合数） |
| 可交换性 | 置换合法性 | $H_0$ 下标签像抽签一样可自由互换 |

注意 p 值的定义是**离散的比例**：世界总数有限，所以 p 值存在天花板——4 人两两分组时最极端也只有 $\frac{1}{6}$。样本越小，这根天花板越低，"再小的样本也能测出显著"是天真的幻想。

## 4. 分步例题

**例**：学习小组抽 4 位同学做微缩试点：随机 2 人周末多刷一套错题卷（干预组），另 2 人照旧（对照组）。周测分数照上文数据取个极简版——对照组 $8,9$ 分，干预组 $13,15$ 分。问干预差值是否"显著"？

1. 观测差距 $T_{obs}=14-8.5=5.5$；
2. 数清宇宙总数：从 4 人选 2 人当干预组，$\binom{4}{2}=6$ 种；
3. 逐个宇宙算差距 $\bar{x}_B-\bar{x}_A$：
 $\lbrace 8,9 \rbrace$ 得 $-5.5$；$\lbrace 8,13 \rbrace$ 得 $-1.5$；$\lbrace 8,15 \rbrace$ 得 $0.5$；$\lbrace 9,13 \rbrace$ 得 $-0.5$；$\lbrace 9,15 \rbrace$ 得 $1.5$；$\lbrace 13,15 \rbrace$ 得 $5.5$；
4. 数极端：$\ge 5.5$ 的只有最后一个——而且它恰是现实分组本身，所以单侧 $p=\frac{1}{6}\approx 0.1667$；
5. 解读：观测确实站在所有世界的最顶端，但**顶端也只有 $\frac16$ 的稀有度**。想在 $\alpha=0.05$ 的标尺下过关，需要的世界总数至少 20 个以上——这正是第 40 课"先按功效算样本量"的另一面镜子。

技巧提示：枚举时固定"选进干预组的两人"即可，$(甲,乙)$ 与 $(乙,甲)$ 是同一个世界；自己和自己配对的分法则根本不存在。

## 5. 动手实验

### 实验 1（python）：一万次重新洗牌，看 7 分钟能不能靠运气造出来

```python title="一万次重贴标签：观测差距在运气分布里的位置"
# sliders: trials=10000 [500:20000:500]
import random                     # 随机库（第 0 章登场）
import matplotlib.pyplot as plt   # 绘图模块起短名 plt

random.seed(2026)                 # 固定随机种子：谁的浏览器都长出同一张直方图
group_a = [32, 27, 35, 29, 30, 26, 33, 31]   # 普通灯组
group_b = [34, 39, 36, 41, 38, 40, 37]       # 护眼灯组
pool = group_a + group_b          # 合并名单，撕掉所有标签
n_pool = len(pool)
n_b = len(group_b)

def mean(xs):
    return sum(xs) / len(xs)

def diff(a_list, b_list):
    return mean(b_list) - mean(a_list)

t_obs = diff(group_a, group_b)    # 真实世界的差距，先存起来当标尺
wins = 0                          # 运气 ≥ 观测的平行宇宙计数
peaks = []                        # 每个宇宙伪造出的差距，攒着画直方图

for trial in range(trials):
    shuffled = pool[:]            # 浅拷贝：留好原件，别把观察数据弄脏
    for i in range(len(shuffled) - 1, 0, -1):      # Fisher-Yates 思路：从队尾往前，
        j = random.randint(0, i)                   # 每人跟身后某个幸运座位交换
        shuffled[i], shuffled[j] = shuffled[j], shuffled[i]
    fake_a = shuffled[:n_pool - n_b]   # 前 8 位贴“普通灯”
    fake_b = shuffled[n_pool - n_b:]   # 余下 7 位贴“护眼灯”
    d = diff(fake_a, fake_b)
    peaks.append(d)
    if d >= t_obs:
        wins = wins + 1

plt.hist(peaks, bins=40, color="steelblue")
plt.axvline(t_obs, color="tomato", linewidth=2)   # 红线：真实观测站的位置
print(f"观测差距 = {round(t_obs, 2)} 分钟")
print(f"置换 p 值 ≈ {wins / trials}")
```

红线在直方图右端孤零零杵着，绝大多数平行世界都够不到它：默认参数下的 1 万次洗牌中只有 **5 次**运气的差距追平或超过 7.48 分钟，置换 p 值 ≈ `0.0005`。可见两组成员的重叠薄得可怜——B 组最小的 34 也几乎顶到 A 组最大的 35。把 trials 滑块拉小到几百，数字会上下乱跳：这正是"比例估计"的蒙特卡洛噪音，拖大 trials 就安静下来。

### 实验 2（python）：不做抽样，直接清点全部 6435 个宇宙

```python title="C(15,7)=6435 个世界一个不落：精确 p 值当场算完"
pool = [32, 27, 35, 29, 30, 26, 33, 31, 34, 39, 36, 41, 38, 40, 37]
n_pool = len(pool)                # 15 人
n_b = 7                           # 护眼灯组人数

total_sum = sum(pool)
group_a = pool[:8]                # 原始普通灯组（前 8 位）
group_b = pool[8:]                # 原始护眼灯组
t_obs = sum(group_b) / n_b - sum(group_a) / (n_pool - n_b)
worlds = 0                        # 合法分法计数
hits = 0                          # 差距 ≥ 观测的分法计数

# 用二进制掩码点名：mask 的第 i 位是 1 就让第 i 人进 B 组
for mask in range(1 << n_pool):
    size_b = 0
    s_b = 0                       # B 组总分累加器
    for i in range(n_pool):
        bit = (mask >> i) % 2     # 取出第 i 位（0 或 1）
        if bit == 1:
            size_b = size_b + 1
            s_b = s_b + pool[i]
    if size_b != n_b:             # 人数不对的不是合法分组，跳过
        continue
    d = s_b / n_b - (total_sum - s_b) / (n_pool - n_b)
    worlds = worlds + 1
    if d >= t_obs:              # 与观测差距同一套算式，浮点行为分毫不差
        hits = hits + 1

print(f"世界总数 = {worlds}")
print(f"达标世界 = {hits}")
print(f"精确 p 值 = {round(hits / worlds, 5)}")
```

蒙特卡洛估出的 `0.0005` 旁边，现在有了确定性答案：**全部 $\binom{15}{7}=6435$ 个世界里只有 2 个**能达到观测差距，精确 p 值 $=\frac{2}{6435}\approx 0.00031$。两项互相印证——抽样估计绕着真值小幅打转。顺带看清成本曲线：n 翻倍会让世界数指数膨胀，60 对 60 的实验就有 $\binom{120}{60}\approx 10^{34}$ 个宇宙，那时就只能回到抽样路线了。"能枚举就不必抽样，不能枚举就抽样逼近"是这套方法的使用说明书。

## 6. 常见误区

:::warning[常见误区]

- **把置换偷换成有放回抽样。** 置换是把原件**整副借走、一枚不少地还回来**（无放回重排）；逐个名额独立抽人会把自己复制进样本，等于悄悄改换了模型——参考系都会变形，p 值自然失真。判据很简单：洗完牌后各数值的出现次数必须与原来一字不差。
- **事后挑单侧还是双侧。** 先看数据再决定"哪个方向的 p 小"等于偷偷多掷了一次骰子。口径应在看数据之前定死，或在文中同时汇报两个方向。
- **以为任何差距都能在小样本里"测出显著"。** 世界总数 $\binom{n}{n_B}$ 是 p 值的天花板：两个 4 人小组连理论极限 $\frac16$ 都越不过去。算不出显著先怀疑样本量，而不是逼着方法表演。

:::

## 7. 练习

下面这段初始代码想复刻例题的四人试点，但把"平行宇宙"数坏了：既让自己和自己配队，又把 $(甲,乙)$、$(乙,甲)$ 当成了两个世界。修好循环边界，让它输出正确的三个数字：

```exercise
# @title: 补课有没有用：把随机分组的全部可能试一遍
# @check: 6
# @check: 1
# @check: 0.1667
# @hint: 从 4 人里挑干预组只需要往后选同伴，(甲,乙) 和 (乙,甲) 是同一个世界；自己陪自己的分法根本不存在
scores = [8, 9, 13, 15]       # 对照组：8、9 分；干预组：13、15 分
obs = (scores[2] + scores[3]) / 2 - (scores[0] + scores[1]) / 2

worlds = 0                    # 平行世界总数 —— 初始版本数错了
hits = 0                      # 差距 ≥ 观测的世界个数
for i in range(4):
    for j in range(4):        # ← 只允许 i 之后的 j 入伙，同一世界才不会数两遍
        pair = [scores[i], scores[j]]      # 这两人进干预组……但自己陪自己也混进来了
        rest = []
        for k in range(4):
            if k != i and k != j:
                rest.append(scores[k])
        d = sum(pair) / 2 - sum(rest) / len(rest)
        worlds = worlds + 1
        if d >= obs:
            hits = hits + 1

print(worlds)
print(hits)
print(round(hits / worlds, 4))
```

<details>
<summary>点开查看逐步解答</summary>

修法只在第二层循环一行：`for j in range(i + 1, 4):`。其余逻辑原样保留：

```python
for i in range(4):
    for j in range(i + 1, 4):        # 只许 i 身后的人入伙
        pair = [scores[i], scores[j]]
        rest = []
        for k in range(4):
            if k != i and k != j:
                rest.append(scores[k])
        d = sum(pair) / 2 - sum(rest) / len(rest)
        worlds = worlds + 1
        if d >= obs:
            hits = hits + 1
```

跑通后打印 `6`、`1`、`0.1667`：六个世界、唯一达标的是现实分组本身、$p=\frac{1}{6}\approx 0.1667$。病码为什么能跑却不对？它总共数了 $4\times 4=16$ 轮：$(i,j)$ 与 $(j,i)$ 各报一次世界，还有 $i=j$ 的四次"自己和自己一组"——这些伪世界里元素被复制（16 轮里最大差值只爬到 5.0），于是分母虚胖成 16、命中翻倍成 2、p 被压成 0.125。错误的方向感正好提醒我们：**置换的两个前提是无放回、无重复**，破坏任何一个，参考系就不是原来的那个了。

</details>

```quiz
关于置换检验得到的 p 值，下列说法正确的是？
- 它是把观测差距套进正态分布公式算出来的尾部面积
- 它是重排标签的世界中，出现至少同样极端差距的比例 [*]
- 它是两组均值恰好相等的概率
? 参考系不是正态分布表，而是亲手制造的一万个平行宇宙：p 值回答"运气做到这份上的把握有多大"。也因为它只是比例，小样本下存在 1/世界数 的天花板。
```

## 8. 边界：它管不了什么

置换检验**不能**替你保证因果：如果分组本身没有随机化（老学员自选护眼灯教室），重排标签再多次也只能在你收集到的数据内部打转。它检验的是"标签与数值无关"，不是"两组总体方差相等"之类的参数命题——按方差设防的精细问题另有专门工具。它还沿**可交换性**这条腿走路：家庭成员聚在同一班级这类有结构的数据，随意洗牌会把结构信息搅碎，需要分层置换等变体处理。最后，别指望它在浏览器里免费吃下百万级重采样——世界太多时它和任何严肃计算一样要谈预算。
