# 高斯消元与解空间

## 1. 从一个场景开始

两条直线相交，答案是一个点；两条直线重合，答案是整条线；两条直线平行，答案不存在。高斯消元不是在“凑答案”，而是把方程组换成一套更容易读出这三种命运的说法。

## 2. 直觉解释

把两个方程写成两行：

```text
2x + 1y = 5
3x + 4y = 10
```

可以交换两行、把某行乘以非零数、把一行的倍数从另一行里减掉。这三个动作改变的是“说法”，不改变两条直线本身。

消元的目标是让第一行从 $x$ 开始读，第二行从 $y$ 开始读。形状像台阶后，解的类型一眼可见。

## 3. 正式定义

增广矩阵把系数和右端放进同一张表：

$$\left[\begin{array}{cc|c} 2 & 1 & 5 \\ 3 & 4 & 10 \end{array}\right]$$

行阶梯形满足：每个非零行的首项位置比上一行更靠右；全零行在最下方。若还能继续把每个主元上方的数也清零，就得到简化行阶梯形。

三种结局：

| 现象 | 几何意义 | 解集 |
| --- | --- | --- |
| 出现 $0=\text{非零}$ | 平行直线 | 无解 |
| 出现 $0=0$ | 两条直线重合 | 无穷多解 |
| 每列都有主元 | 唯一交点 | 唯一解 |

## 4. 分步例题

从 $\left[\begin{array}{cc|c}2&1&5\\3&4&10\end{array}\right]$ 开始。

1. 第一行除以 2：$\left[\begin{array}{cc|c}1&\frac12&\frac52\\3&4&10\end{array}\right]$；
2. 第二行减去 $\frac32$ 倍第一行：$\left[\begin{array}{cc|c}1&\frac12&\frac52\\0&\frac52&\frac52\end{array}\right]$；
3. 第二行除以 $\frac52$：$y=1$；
4. 回代第一行：$x=\frac52-\frac12\cdot1=2$。

每一步都在改写行，两条直线没有动。

### 实验 2：先看张成，再读自由度

```viz
{
  "type": "span-space",
  "title": "系数列能张成什么",
  "v1": [2, 3],
  "v2": [1, 4]
}
```

两个系数列独立时，左端 $\binom{5}{10}$ 一定能被它们唯一配出。把一个向量拖到另一个方向上，唯一解立刻消失。

### 实验 3：Python 消元流水线

```python title="二阶消元：先消再回代"
A = [[2, 1], [3, 4]]   # A[0] 是第一行，A[1] 是第二行
b = [5, 10]             # 右端常数

factor = A[1][0] / A[0][0]      # 第二行要减去几倍第一行
A[1][0] = A[1][0] - factor * A[0][0]
A[1][1] = A[1][1] - factor * A[0][1]
b[1] = b[1] - factor * b[0]
print(A)
print(b)

y = b[1] / A[1][1]
x = (b[0] - A[0][1] * y) / A[0][0]
print(f"x={x}, y={y}")
```

输出阶梯矩阵、右端列和唯一解。代码故意把循环写得笨一点，是为了让每个算术动作都看得见。

## 6. 练习

```exercise
# @title: 练习：消元并回代
# @check: x=2.0
# @check: y=1.0
# @hint: 先用第一行消去第二行的 x；再用第二行求 y，最后回代第一行。
A = [[1, 1], [2, 3]]
b = [3, 7]

factor = A[1][0] / A[0][0]
A[1][0] = 0
A[1][1] = A[1][1] - factor * A[0][1]
b[1] = b[1] - factor * b[0]

y = b[1] / A[1][1]
x = b[0] + A[0][1]
print(f"x={x}")
print(f"y={y}")
```

<details>
<summary>点开查看逐步解答</summary>

第二行减去 2 倍第一行后：

```text
[1  1 | 3]
[0  1 | 1]
```

所以 `y=1`。回代第一行：

```python
A = [[1, 1], [0, 1]]
b = [3, 1]
y = b[1] / A[1][1]
x = b[0] - A[0][1] * y
print(f"x={x}")
print(f"y={y}")
```

关键漏掉的是回代里的乘法 `A[0][1] * y`。

</details>

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为交换两行会改变方程组的解。其实只是改变阅读顺序，两条直线没有动。

**误区二**：你以为消出 $0=0$ 是失败。它说明两个方程给出同一个约束，解集是整条直线。

**误区三**：你以为消元只适合唯一解。恰恰相反，阶梯形最大的功劳是把无解和无穷解也变成可见形状。

:::

## 9. 选读：为什么行变换保持解集

<details>
<summary>选读 · 三类行变换的逆操作</summary>

交换两行可以换回来；某行乘以非零数 $k$ 可以乘以 $1/k$ 撤销；第二行减去 $k$ 倍第一行，可以再加回 $k$ 倍第一行。每个动作都可逆，而可逆操作不会把满足原方程组的点排除，也不会引入新点。因此解集在每一步都完全相同。

</details>
