# 哈密顿–雅可比方程与可积系统

## 1. 从一个场景开始

行星轨道为什么能被写成一个闭式公式？开普勒问题有两个"额外"的守恒量（能量、角动量，再加一个拉普拉斯–龙格–楞次矢量），恰好凑够了数，于是轨道是一个不再变化的椭圆，可以预测到永远。可太阳系里再加一个行星，这套完美就塌了——三体问题没有闭式解，轨道会在漫长的时间里变得混沌。

差别在哪？在于**能不能把整个运动拆成若干个互不干扰的"独立时钟"**。能拆的系统叫**可积系统**；拆不动的地方，就是混沌。这一课要给出"能拆"的精确判据，还要给出拆开之后那个最简单的图景：一堆匀速转动的圆。

## 2. 直觉解释

一个 $n$ 自由度的系统，相空间是 $2n$ 维的。想象它被一层层的**甜甜圈（环面）**填满，就像洋葱被一层层的膜填满：

- 每一层环面是一个"能量壳层"的内部结构；
- 系统在这层环面上运动，走的是一条**匀速直线**——不是弯曲的轨道，是笔直的、速度恒定的线；
- 由于环面两个方向都是"循环"的，这条直线缠着环面一圈圈绕下去：缠绕比是有理数就闭合，是无理数就把环面铺满。

于是"解运动方程"这件事被彻底简化成了两件事：**找出这些环面**（每个环面用一个"半径"标记），**算出直线在环面上两个方向的速度**（频率）。原来的 $2n$ 维微分方程，变成了 $n$ 个互不相干的匀速转动。

而"半径"这个量，正是这套图景里的主角——**作用量**。它是相轨道围出的面积除以 $2\pi$。

## 3. 正式定义

**哈密顿–雅可比方程**：找一个函数 $S(q, t)$（哈密顿主函数），使

$$\frac{\partial S}{\partial t} + H\!\left(q, \frac{\partial S}{\partial q}, t\right) = 0$$

它的意思是：把"动量"整体换成"某个函数的梯度"，$p_i = \partial S/\partial q_i$，让方程变成一个关于单个函数 $S$ 的一阶偏微分方程。若 $H$ 不显含时间，可以分离变量 $S = W(q) - Et$，得到**不含时**版本

$$H\!\left(q, \frac{\partial W}{\partial q}\right) = E$$

$W$ 叫哈密顿特征函数。解出 $W$ 就等于解出了整个运动。

**作用量–角变量**：对可积系统，定义

$$J_i = \frac{1}{2\pi}\oint p_i\,\mathrm dq_i, \qquad \theta_i = \frac{\partial W}{\partial J_i}$$

- $J_i$：**作用量**，等于第 $i$ 个相轨道围出的面积除以 $2\pi$，是运动常数；
- $\theta_i$：**角变量**，是环面上的角度坐标，取值范围 $[0, 2\pi)$。

换到这套坐标后，哈密顿量**只依赖作用量**：$H = H(J)$。于是正则方程立刻给出

$$\dot\theta_i = \frac{\partial H}{\partial J_i} = \omega_i(J) = \text{常数}, \qquad \dot J_i = -\frac{\partial H}{\partial\theta_i} = 0$$

**运动就是匀速直线**——这就是 §2 那幅图景的全部数学内容。

| 符号 | 名字 | 一句话含义 |
| --- | --- | --- |
| $S, W$ | 主函数 / 特征函数 | 哈密顿–雅可比方程的解，生成正则变换 |
| $J_i$ | 作用量 | 相轨道围出的面积 $/2\pi$，守恒 |
| $\theta_i$ | 角变量 | 环面上的角度，匀速转动 |
| $\omega_i$ | 频率 | $\partial H/\partial J_i$，环面上两个方向的"速度" |
| $\lbrace F_i, F_j\rbrace = 0$ | 对合 | 两个守恒量"互不干扰"的代数判据 |

**可积的判据（刘维尔–阿诺德）**：$n$ 个自由度的系统，如果能找到 $n$ 个**互相独立**且**两两对合**（$\lbrace F_i, F_j\rbrace = 0$）的守恒量，那么它就是可积的：相空间被 $n$ 维环面分层，运动是环面上的匀速直线，而且上述作用量–角变量一定存在。

注意"对合"这个词为什么必须出现：$n$ 个自由度当然可以有一堆守恒量，但它们若互相对合不了，就无法同时当作坐标轴用。**守恒量的数量够了还不够，还得它们彼此"和睦"。**

## 4. 分步例题

**例** 谐振子 $H = \tfrac12 p^2 + \tfrac12\omega^2q^2 = E$，求作用量 $J$ 与频率。

1. 把等能线写成椭圆标准形：$\dfrac{q^2}{2E/\omega^2} + \dfrac{p^2}{2E} = 1$，两个半轴是 $a_q = \dfrac{\sqrt{2E}}{\omega}$、$a_p = \sqrt{2E}$；
2. 椭圆面积：$A = \pi a_q a_p = \pi\cdot\dfrac{2E}{\omega} = \dfrac{2\pi E}{\omega}$；
3. 作用量 $J = \dfrac{A}{2\pi} = \dfrac{E}{\omega}$；
4. 反解出 $E = \omega J$，于是频率 $\omega_J = \dfrac{\mathrm dE}{\mathrm dJ} = \omega$——**正是振动频率**；
5. 数值：$E = 4$、$\omega = 2$，则 $J = 2$，相轨道面积 $2\pi J = 12.5664$。

第 4 步藏着一个漂亮的普遍事实：**频率 = 能量对作用量的导数**。这不是谐振子的特例，而是作用量–角变量的一般结论（$\dot\theta = \partial H/\partial J$）。把它倒过来写还有一个很实用的版本：**周期 $T = 2\pi\,\dfrac{\mathrm dJ}{\mathrm dE}$**——只要算出 $J(E)$ 再求一次导，周期就到手了，根本不用解轨道。

再顺手算一个常见的"量子味"应用：如果强行要求 $J = n\hbar$（$n$ 是正整数），那么 $E = n\hbar\omega$——这正是普朗克公式。旧量子论就是靠这条"作用量量子化"规则撑起来的。

左图是相空间的椭圆轨道（**面积恰好是 $2\pi J$**，读数栏里有），橙针以恒定角速度转——角变量 $\theta$ 永远匀速。右图把两个角变量各卷成一个圆周，合起来就是**环面**：**在右图上拖动**可以转视角，播放让红点自己在环面上爬。

盯住"缠绕比"那一栏：

- 设成 $1.5 = 3/2$：转两圈回到起点，轨道**闭合**；
- 设成 $\sqrt{2}\approx1.414$：读数会说"无理缠绕"，红点永不闭合，而是把环面越铺越密；
- 设成 $1$：闭合，而且是最简单的一圈。

把 $J$ 拖大：左边的圆变大，但**转速一点不变**（读数里 $\theta$ 的增长速度只由频率比决定）。这就是"作用量决定轨道大小、频率决定速度"的分工。

### 实验 2（python）：作用量与它的导数

```python
import math
E = 4.0                 # 谐振子的能量
omega = 2.0             # 角频率
J = E / omega           # 作用量 J = E/ω
print(f"作用量 J = {J}")
print(f"相轨道面积 = 2πJ = {2 * math.pi * J:.4f}")

# 频率就是 E(J) 的斜率：ω = dE/dJ
dJ = 1e-6               # 一个很小的增量，用来做数值微分
slope = ((J + dJ) * omega - J * omega) / dJ
print(f"dE/dJ 的数值值 = {slope:.6f}，与 ω = {omega} 一致")

# 半经典量子化：J = n·ħ 时 E = n·ħ·ω
hbar = 1.0
for n in (1, 2, 3):
    print(f"n = {n}：J = {n * hbar:.1f} → E = {(n * hbar) * omega:.1f}")
```

输出：`作用量 J = 2.0`、`相轨道面积 = 2πJ = 12.5664`、`dE/dJ 的数值值 = 2.000000，与 ω = 2.0 一致`，以及三行 $n = 1,2,3$ 对应的 $E = 2.0, 4.0, 6.0$。

这里的数值微分写得很朴素（就是"多算一点再相减"），因为 $E(J) = \omega J$ 是严格线性的——差分出来的斜率精确到浮点。对非线性的可积系统（比如单摆），$E(J)$ 是超越函数，那时"求导得频率"就从一句废话变成一件真功夫了。

::::warning[常见误区]

**误区一**："可积 = 能写出解的公式。"
定义不依赖"公式"。可积的精确含义是相空间**被环面分层**（存在足够多的对合守恒量）。有些可积系统的解只能用特殊函数写，有些甚至写不出闭式；反过来，能数值积分出漂亮曲线不等于可积——数值曲线在足够长时间后可能悄悄变成混沌。

**误区二**："混沌系统处处乱。"
不。KAM 定理说的是：轻微扰动一个可积系统时，**大部分**环面（那些缠绕比"足够无理"的）依然存活，只有有理缠绕比附近的环面被撕碎成混沌层。太阳系的稳定性讨论，就是在这个"大部分存活、少数破碎"的图景里进行的。

**误区三**："作用量 $J$ 就是能量。"
$J$ 与 $E$ 一一对应（可积系统里两者通过 $H(J)$ 互相决定），但它们是不同的量：$J$ 是**几何量**（面积除以 $2\pi$），$E$ 是**动力学量**（守恒的能量）。$E(J)$ 的斜率还承担着"频率"的角色——这个身份是能量所没有的。

**练习 2**：求单摆 $H = \tfrac12p^2 - \cos q$ 在小振动极限下的作用量与频率。

<details>
<summary>点开查看逐步解答</summary>

1. 小振动时 $\cos q \approx 1 - q^2/2$，于是 $H \approx \tfrac12p^2 + \tfrac12q^2 - 1$，即"谐振子减 1"；
2. 令 $E' = E + 1$ 表示相对最低点的能量，则等能线是半径 $\sqrt{2E'}$ 的圆，面积 $\pi\cdot2E' = 2\pi E'$；
3. 作用量 $J = E' = E + 1$，频率 $\omega = \dfrac{\mathrm dE}{\mathrm dJ} = 1$——**与振幅无关**，这是小振动的标志（等时性）；
4. 大振幅时这项就不再成立：真实频率随振幅**减小**（摆得越高越慢），因为 $E(J)$ 不再是直线。单摆的精确周期是 $T = 4K(k)/\omega_0$（$K$ 是第一类完全椭圆积分），振幅趋近 $\pi$ 时周期发散；
5. 一个可以拿去数值检验的近似式：$T \approx 2\pi\left(1 + \dfrac{\theta_0^2}{16}\right)$，$\theta_0 = 0.5$ rad 时给出 $1.0156\times2\pi$，比小振动周期长约 $1.6\%$。

**结论**：作用量–角变量不是"换套坐标"的形式主义——$E(J)$ 这条曲线的形状直接编码了频率如何随能量变化，而"频率依赖振幅"正是非线性系统最本质的特征。

</details>

## 7. 选读：作用量量子化的前世今生

<details>
<summary>选读 · 从玻尔–索末菲到 WKB</summary>

1913 年玻尔提出氢原子能级公式，1916 年索末菲把它推广成一条**作用量量子化**规则：

$$\oint p\,\mathrm dq = n h, \qquad n = 1, 2, 3, \dots$$

用本课的语言，就是 $J = n\hbar$。它对氢原子、谐振子、一维势井都给出正确的能级，甚至能算对塞曼效应的定性图景——这让它在 1913–1925 年间成了"量子论"的正式工具。

但它有三处结构性缺陷：多电子原子算不对、不能处理自旋、也无法回答"为什么只有某些轨道允许"。1925 年矩阵力学和 1926 年薛定谔方程出现后，玻尔–索末菲规则被"降级"了。

有意思的是，它并没有死。1926 年，WKB 近似（Wentzel–Kramers–Brillouin）证明：**在 $\hbar \to 0$ 的极限下，薛定谔方程的解可以写成 $e^{\mathrm iS/\hbar}$，而 $S$ 恰好满足哈密顿–雅可比方程**。于是玻尔–索末菲条件重新获得了身份——它是"半经典近似下单值性要求"的产物：波函数绕环面一圈必须回到自己，只有 $J = n\hbar$ 才做得到。

这条线索今天依然活着：半经典量子化是研究量子混沌的起点（Gutzwiller 迹公式把能级密度写成周期轨道的求和），也是分子光谱计算的标准工具。**一个 1916 年的老规则，活成了 21 世纪的常规方法**——它靠的正是本课这条"哈密顿–雅可比 → 作用量"的路。

</details>
