# 相空间与刘维尔定理：密度不可压

## 1. 从一个场景开始

没人能精确知道一摩尔气体里 $10^{23}$ 个分子的初始位置和速度。就算知道，也写不下。物理学家退一步：不追单个点，改追**一团**初始条件——用分布描述"我现在有多不确定"。

这一步退让立刻招来一个危险的问题：**这团不确定性会不会随时间自己糊开？** 如果会，那么"从微观分布推出宏观规律"这件事就永远做不成：今天的分布决定了明天的分布，但明天的分布已经和今天毫无相似之处。

刘维尔定理的回答干脆利落：**不会糊**。这团初始条件在相空间里占的体积，随时间的演化**分毫不差地守恒**。形状可以被拉得面目全非，体积一寸不让。粒子加速器里的"束流发射度"守恒、分子动力学的统计可靠性，都靠这条定理撑着。

## 2. 直觉解释

想象一池**不可压缩的水**。往水里滴一滴墨，然后随便搅：

- 墨迹的形状可以变成螺旋、变成细丝、变成任何你想要的怪样子；
- 但墨水的**体积**一点没变——不可压缩意味着你没法把它"搅小"。

刘维尔定理说的就是：哈密顿流是相空间里的不可压缩流。相空间里的"体积"（一维系统里就是面积）＝ $(\Delta q)(\Delta p)$ 这一类量。

再给一个对照：**阻尼摆**。它的"水池"底下有个排水口——相空间体积会一路缩下去，缩得干干净净（所有初始条件最后都停到同一个不动点）。所以不可压性不是"所有微分方程都有的性质"，它是**哈密顿系统独有的签名**。

顺带一提：不可压不代表"看不出变化"。墨迹虽然体积不变，却能越拉越细、越绕越长，最后均匀地铺满整个水池——这就是"混合"，也是热力学第二定律在微观层面的影子（见本课选读）。

## 3. 正式定义

$n$ 个自由度的系统，**相空间**是 $2n$ 维空间，坐标是 $(q_1,\dots,q_n,p_1,\dots,p_n)$。相空间里的一个点 = 系统的一个完整状态。

用**密度** $\rho(q, p, t)$ 描述"此刻系统落在各处"的分布（对一团初始条件而言，就是"这团点云在各处的疏密"）。$\rho$ 的演化由**刘维尔方程**给出：

$$\frac{\partial \rho}{\partial t} + \lbrace \rho, H\rbrace = 0$$

其中 $\lbrace\cdot,\cdot\rbrace$ 是泊松括号（下一课正式定义，这里先用它的展开式）：

$$\lbrace \rho, H\rbrace = \sum_{i}\left(\frac{\partial \rho}{\partial q_i}\frac{\partial H}{\partial p_i} - \frac{\partial \rho}{\partial p_i}\frac{\partial H}{\partial q_i}\right)$$

**等价说法（更直观）**：跟着相流走的时候，密度不变——

$$\frac{\mathrm d\rho}{\mathrm dt} = \frac{\partial \rho}{\partial t} + \sum_i\left(\frac{\partial \rho}{\partial q_i}\dot q_i + \frac{\partial \rho}{\partial p_i}\dot p_i\right) = 0$$

| 符号 | 名字 | 一句话含义 |
| --- | --- | --- |
| $\rho$ | 相空间密度 | 单位相体积里"有多少个状态"，不是概率本身 |
| $H$ | 哈密顿量 | 生成流的那个函数 |
| $\lbrace\cdot,\cdot\rbrace$ | 泊松括号 | 下一课的主角，这里只用它的展开式 |
| $\dfrac{\mathrm d\rho}{\mathrm dt}$ | 随流导数 | 站在一个相点上看的密度变化率 |

**为什么体积守恒**：把一团区域记作 $\Omega$，它的体积变化率等于"边界上的流速通量"，而这由流的散度决定。上一课已经算过正则方程的散度：

$$\frac{\partial \dot q}{\partial q} + \frac{\partial \dot p}{\partial p} = \frac{\partial^2 H}{\partial q\,\partial p} - \frac{\partial^2 H}{\partial p\,\partial q} = 0$$

散度为零 $\Longleftrightarrow$ 体积不变。混合偏导相等就够了吗？够了——这一条结论对任何哈密顿量都成立，不需要 $H$ 长什么样子。这是全部推导里最"便宜"也最漂亮的一步。

## 4. 分步例题

**例** 剪切流 $H = \tfrac12 p^2$，即 $\dot q = p$、$\dot p = 0$。取相空间里一个矩形：$q$ 方向宽 $2$、$p$ 方向高 $1$，面积 $A_0 = 2$。让它演化时间 $t = 3$。

1. 解方程：$p$ 是常数，$q(t) = q_0 + p_0\,t$——每条水平线上的点沿 $q$ 方向滑走，滑的距离与它自己的高度成正比；
2. 找四个顶点的新位置：$(0,0)\to(0,0)$，$(2,0)\to(2,0)$，$(0,1)\to(3,1)$，$(2,1)\to(5,1)$；
3. 用鞋带公式算新面积。按顺序 $(0,0),(2,0),(5,1),(3,1)$ 逐项算 $x_i y_{i+1} - x_{i+1}y_i$：

$$0,\quad 2,\quad 2,\quad 0 \;\Longrightarrow\; S = 4,\qquad A = \frac{|S|}{2} = 2$$

4. 结论：$A = A_0$。形状从"矩形"变成了"平行四边形"，面积一分未变。

这个例子还暴露了另一半事实：**形状确实在变**。初始时刻 $(0,0)$ 与 $(0,1)$ 两点相距 $1$；$t=3$ 后它们变成 $(0,0)$ 与 $(3,1)$，距离 $\sqrt{10}\approx 3.16$。靠得再近的点也会被逐渐拉开——体积不变，但"局部"会被撕得很细。这就是 §2 里那滴墨。

作为反面：带阻尼的振子 $\dot q = p$、$\dot p = -q - \gamma p$。它的散度是 $-\gamma$（不是零！），面积按 $e^{-\gamma t}$ 缩。取 $\gamma = 0.3$、$t = 6$，理论值 $e^{-1.8} = 0.1653$——数值实验会验到小数点后三位。

### 实验 2（python）：鞋带公式自己算一遍

```python
import math
N = 60                  # 点云取 60 个点，围成一个椭圆
rq, rp = 0.6, 0.4       # 椭圆的两个半轴
h = 0.002               # 步长
steps = 3000            # 一共 6 个时间单位

def area(pts):          # 鞋带公式：有序点列围出的面积
    s = 0.0
    for i in range(len(pts)):
        x1, y1 = pts[i]
        x2, y2 = pts[(i + 1) % len(pts)]    # % 取余：最后一个点接回第一个
        s += x1 * y2 - x2 * y1
    return abs(s) / 2

def evolve(damped):     # 演化一整段，返回（出发面积, 到达面积）
    pts = [(rq * math.cos(2 * math.pi * k / N),
            rp * math.sin(2 * math.pi * k / N)) for k in range(N)]
    a0 = area(pts)
    for _ in range(steps):
        nxt = []
        for q, p in pts:
            if damped:
                p2 = p + h * (-q - 0.3 * p)     # 阻尼：ṗ = −q − γp
                q2 = q + h * p2
            else:
                p2 = p                          # 剪切流：ṗ = 0
                q2 = q + h * p2                 # q̇ = p（用新 p，辛欧拉的写法）
            nxt.append((q2, p2))
        pts = nxt
    return a0, area(pts)

a0, a1 = evolve(False)
_, a2 = evolve(True)
print(f"出发时面积 {a0:.6f}")
print(f"哈密顿剪切流：{a1:.6f}，比值 {a1 / a0:.6f}")
print(f"带阻尼：      {a2:.6f}，比值 {a2 / a0:.6f}")
print(f"阻尼流的理论值 e^(−γT) = {math.exp(-0.3 * 6):.6f}")
```

四行输出：`出发时面积 0.752605`、`哈密顿剪切流：0.752605，比值 1.000000`、`带阻尼：0.124338，比值 0.165210`、`阻尼流的理论值 e^(−γT) = 0.165299`。

注意第三、四行的差：$0.165210$ 与 $0.165299$ 只差万分之五，这已经是"把连续的时间切成 3000 段"带来的离散误差。把 `h` 改成 $0.02$（`steps` 改成 300），阻尼那一行会明显偏离理论值——**但哈密顿那一行照样是 1.000000**，因为面积守恒不是数值巧合，而是格式本身的结构（第 60 课会讲这个结构）。

```quiz
- 体积不变，但形状可以无限拉伸折叠，"铺满"靠的是形状而不是体积 [*]

- 因为相空间本身在膨胀

```

::::warning[常见误区]

**误区一**："相体积不变，所以分布函数 $\rho$ 在空间上也不变。"
你以为墨迹的形状会保持——其实 $\mathrm d\rho/\mathrm dt = 0$ 说的是"**跟着一个点走**时密度读数不变"，不是"空间各点的密度不变"。点被拉走之后，原来位置的密度当然会变。前者叫细粒化密度守恒，后者根本不成立。

**误区二**："任何微分方程都保面积，这只是换了个说法。"
随手写一个 $\dot q = q$、$\dot p = p$，散度是 $2$，面积按 $e^{2t}$ 爆炸。保面积的**唯一**原因是正则方程的那对特殊结构（$\dot q = \partial H/\partial p$、$\dot p = -\partial H/\partial q$）。阻尼、摩擦、任何耗散都破坏它。

**误区三**："刘维尔定理是量子力学或者统计力学的专利。"
它 1838 年就出现了，纯粹是经典哈密顿力学的几何性质。统计力学用它，但用到的只是它的一个推论；数值积分界用它来筛选积分器（辛积分器的判据之一就是"近似保相体积"）。

::::

**练习 2**：对剪切流 $H = \tfrac12p^2$，把 §4 的矩形换成"$q$ 方向宽 $\Delta q$、$p$ 方向高 $\Delta p$"的一般矩形，验证面积仍然守恒；并解释为什么这**不**意味着"形状不变"。

<details>
<summary>点开查看逐步解答</summary>

1. 四条边的四个顶点是 $(q_0,p_0)$、$(q_0+\Delta q,p_0)$、$(q_0+\Delta q,p_0+\Delta p)$、$(q_0,p_0+\Delta p)$；
2. 演化 $t$ 之后逐点平移：$q \to q + p\,t$、$p \to p$。顶点变成 $(q_0+p_0t,\,p_0)$、$(q_0+\Delta q+p_0t,\,p_0)$、$(q_0+\Delta q+(p_0+\Delta p)t,\,p_0+\Delta p)$、$(q_0+(p_0+\Delta p)t,\,p_0+\Delta p)$；
3. 上边与下边都向右平移，但平移量相差 $\Delta p\cdot t$——矩形被剪成了平行四边形，底仍是 $\Delta q$、高仍是 $\Delta p$；
4. 平行四边形的面积 = 底 × 高 = $\Delta q\,\Delta p$，与出发时相同。线性代数的说法：这个映射的雅可比矩阵是 $\begin{pmatrix}1 & t\\ 0 & 1\end{pmatrix}$，行列式恒为 $1$；
5. 形状确实变了：初始相距 $\Delta p$ 的两个点，$t$ 之后相距 $\sqrt{(\Delta p\,t)^2 + (\Delta p)^2} = \Delta p\sqrt{1+t^2}$，随时间线性增长。**面积守恒与"局部拉伸"不但不矛盾，还是一枚硬币的两面**——正因为不可压，拉伸只能靠"变细"来补偿。

</details>

## 7. 选读：熵为什么会涨

<details>
<summary>选读 · 细粒化不变，粗粒化在涨</summary>

刘维尔定理说相体积（细粒化体积）严格不变，可热力学第二定律说熵只增不减。这两件事不冲突，关键在于**我们怎么看**。

想象初始时刻分布集中在一小块区域里（低熵）。随时间演化，这块区域被拉成极细的丝，缠满整个可达区域（§2 那滴墨）。**细粒化**分布依然只在丝上非零，体积没变、香农熵也没变；但任何真实的测量都只有有限分辨率——把相空间切成小格子（粗粒化），每个格子里"有丝经过"的比例越来越高。按格子数出的熵

$$S_{\text{粗}} = -k_B \sum_{\text{格子}} p_i \ln p_i$$

就这样一路涨到最大。**熵增不是动力学造成的，是"我们看不见丝的细节"造成的。**

这个视角还能解释可逆性佯谬：微观方程完全可逆（把 $t$ 换成 $-t$，轨道原样倒着走），但"丝被拉细"这件事在倒放时依然成立——细丝会重新聚拢回小块，只是这个"重新聚拢"要求初始条件精确到丝那么细，任何微小扰动都会毁掉它。统计力学的不可逆，是**初始条件的精度**带来的，不是方程带来的。

</details>
