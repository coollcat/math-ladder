# 哈密顿力学与对称性

同一套力学，换一副坐标，会露出完全不同的面孔。拉格朗日力学把运动压成一条"作用量取极值"的路径——那件事 22 章与 26 章已经讲透了；本章从那里接手，做的是**换记录方式**：把自变量从速度换成动量（勒让德变换），二阶方程就裂成一对对称的一阶方程；再往下，相空间、泊松括号、辛结构依次登场，力学于是从"解微分方程"变成了一句更硬的话：**找结构**。到了最后两课，结构甚至比解还值钱——辛积分器不是"更准"，而是"错得有纪律"；诺特定理不是"某些量恰好守恒"，而是"有多少对称就有多少守恒"。

这一章不重推欧拉–拉格朗日方程：它的来历请回看[从牛顿到拉格朗日](../22-ode-dynamics/65-newton-to-lagrange.md)与[变分法](../26-functional-analysis/95-calculus-of-variations.md)。本章只借它的两个结论：运动方程的形式，以及"共轭动量"的定义。

## 路线图

1. [勒让德变换：从速度换到动量](./10-legendre-transform.md)——把凸函数的信息从"逐点清单"换成"切线族清单"，斜率就是动量。
2. [哈密顿正则方程：二阶方程降成一阶对](./20-canonical-equations.md)——运动变成沿能量等高线走，方向处处垂直于梯度。
3. [相空间与刘维尔定理：密度不可压](./30-liouville.md)——一团初始条件的形状可以任意扭曲，面积一寸不让。
4. [泊松括号与守恒量](./40-poisson-brackets.md)——"守恒"从此是一次偏导运算，不需要解方程。
5. [诺特定理：对称就是守恒](./50-noether.md)——时间平移、空间平移、旋转各对应一个守恒量；对称破缺，守恒量立刻漏气。
6. [辛结构与辛积分：能量为什么不漂](./60-symplectic-integrator.md)——显式欧拉每步把相面积放大 1+h²，辛欧拉严格保面积。
7. [哈密顿–雅可比方程与可积系统](./70-hamilton-jacobi.md)——可积 = 相空间被环面分层 = 若干互不干扰的匀速转动。
8. [从粒子到场：作用量语言的门口](./80-field-gateway.md)——无穷多自由度 = 无穷多个振子，格点给了世界一个天然截断。

## 方法主线

**换变量 → 看相空间 → 造守恒量 → 认结构 → 走向无穷。**

前两课是准备：勒让德变换负责换坐标系，正则方程负责把动力学写成"相空间里的流"。三十与四十课研究这个流的性质：它不可压（刘维尔），它由括号生成（泊松）。五十课把括号与对称性接上，得到本章的哲学支点：守恒量不是运气，是对称的账。六十课转入数值：既然流有几何结构，积分器就该尊重它——这是本章唯一"可以立刻拿去用"的结论。七十课处理"什么时候整套运动能被拆开"，八十课越过有限自由度，落在场论的门口。

一条红线贯穿：**先找不变量，再谈计算**。相空间的面积、括号的代数、辛形式的几何、可积系统的环面——每一种不变量都对应一整套被简化的计算。

## 实战挑战 · 两个自由度的耦合振子

两块质量各为 $m$ 的滑块，各自被刚度为 $k$ 的弹簧连到墙上，中间再用刚度为 $k_c$ 的弹簧相连。取 $m = k = 1$、$k_c = 0.5$。它的两个**简正模**频率是

$$\omega_- = \sqrt{\frac{k}{m}}, \qquad \omega_+ = \sqrt{\frac{k + 2k_c}{m}}$$

下面这段代码把反相模的恢复力算成了 $k + k_c$，跑出来是 `1.000000 1.224745`。修到输出 `1.000000 1.414214`：

```exercise
# @title: 实战挑战：耦合振子的两个简正模频率
# @check: 1.000000 1.414214
# @hint: 反相运动时，两块质量反向移动同样的距离，中间的耦合弹簧被拉伸了两倍的位移，所以恢复力系数是 k + 2kc
import math
m = 1.0
k = 1.0
kc = 0.5
w_minus = math.sqrt(k / m)
w_plus = math.sqrt((k + kc) / m)    # ← 问题在这：反相模的恢复力少算了一份 kc
print(f"{w_minus:.6f} {w_plus:.6f}")
```

<details>
<summary>点开查看逐步解答</summary>

**1. 为什么两个模长这样。** 设两块质量的位移是 $x_1$、$x_2$，运动方程是

$$m\ddot x_1 = -(k + k_c)x_1 + k_c x_2, \qquad m\ddot x_2 = k_c x_1 - (k + k_c)x_2$$

- **同相模** $x_1 = x_2$：中间的弹簧长度不变（两端一起动），它对两块都不施力，每块只受自己那根墙弹簧控制，所以 $\omega_- = \sqrt{k/m} = 1$；
- **反相模** $x_1 = -x_2$：中间的弹簧被拉伸了 $2x_1$——**这是本题的关键**，所以作用在 1 号上的力是 $-kx_1 - k_c(2x_1) = -(k + 2k_c)x_1$，于是 $\omega_+ = \sqrt{(k + 2k_c)/m} = \sqrt{2} = 1.414214$。

**2. 换坐标就解耦。** 取 $q_s = \dfrac{x_1 + x_2}{\sqrt2}$、$q_a = \dfrac{x_1 - x_2}{\sqrt2}$，哈密顿量变成两个**互不相干**的谐振子：

$$H = \underbrace{\frac12\left(p_s^2 + \omega_-^2q_s^2\right)}_{\text{同相}}\; +\; \underbrace{\frac12\left(p_a^2 + \omega_+^2q_a^2\right)}_{\text{反相}}$$

每一项各自守恒，所以整个系统有两个独立的作用量 $J_s = E_s/\omega_-$、$J_a = E_a/\omega_+$——这正是第 70 课说的"可积"：$2$ 个自由度、$2$ 个对合守恒量，相空间被环面分层。

**3. 拍：能量在两块质量间来回搬。** 只把 1 号拉到位移 $1$ 处放手，解析解是

$$x_1 = \cos\frac{\omega_+ - \omega_-}{2}t\,\cos\frac{\omega_+ + \omega_-}{2}t, \qquad x_2 = \sin\frac{\omega_+ - \omega_-}{2}t\,\sin\frac{\omega_+ + \omega_-}{2}t$$

慢因子是包络，快因子在里面抖。包络周期（拍周期）$T_{\text{拍}} = \dfrac{2\pi}{\omega_+ - \omega_-} = 15.1690$：能量每 15.17 个时间单位在两块质量之间完成一次往返。

**4. 辛积分 vs 显式欧拉。** 用步长 $h = 0.05$ 走 2000 步（$t = 100$，约 6.6 个拍周期）：

```python
import math
m = 1.0         # 每块的质量
k = 1.0         # 连到墙的弹簧刚度
kc = 0.5        # 两块之间的耦合弹簧刚度
w_minus = math.sqrt(k / m)
w_plus = math.sqrt((k + 2 * kc) / m)
print(f"简正模频率：ω₋ = {w_minus:.6f}，ω₊ = {w_plus:.6f}")
print(f"拍周期 2π/(ω₊−ω₋) = {2 * math.pi / (w_plus - w_minus):.4f}")

def accel(x1, x2):      # 两块质量各自的加速度
    return (-(k + kc) * x1 + kc * x2, kc * x1 - (k + kc) * x2)

x1, x2, v1, v2 = 1.0, 0.0, 0.0, 0.0     # 1 号拉到位移 1 处，静止放手
h = 0.05
worst = 0.0
for _ in range(2000):
    a1, a2 = accel(x1, x2)
    v1 = v1 + h * a1        # 辛欧拉：先更新速度
    v2 = v2 + h * a2
    x1 = x1 + h * v1        # 再用**新**速度更新位置
    x2 = x2 + h * v2
    E = 0.5 * (v1 * v1 + v2 * v2) + 0.5 * k * (x1 * x1 + x2 * x2) + 0.5 * kc * (x2 - x1) ** 2
    worst = max(worst, abs(E - 0.75) / 0.75)
print(f"走 2000 步后：总能量 {E:.6f}（出发 0.75），最大相对偏离 {worst:.4f}")
```

输出：`走 2000 步后：总能量 0.752691（出发 0.75），最大相对偏离 0.0330`——百分之三的振荡幅度，而且**不随时间增长**（把 `range(2000)` 改成 `range(20000)` 试试，这个数还是差不多）。

把循环里那两行换个位置——先用**旧**速度更新位置，再更新速度（也就是显式欧拉的顺序，`x` 与 `v` 的更新行对调即可）：

```py
    x1 = x1 + h * v1        # 先用旧速度更新位置
    x2 = x2 + h * v2
    v1 = v1 + h * a1        # 再更新速度
    v2 = v2 + h * a2
```

同一个初始条件下，末态总能量会变成 `10779.079512`，最大相对偏离 `14371.1060`。**同样的方程、同样的步长，只换了两行的先后。**

**5. 这一题为什么配得上"实战"。** 它把本章三件事缝在一起：简正模 = 可积系统的最小例子；拍 = 两个频率之差决定的可观测现象；辛积分 = 结构比精度值钱。真实的分子动力学、轨道力学、电路仿真，用的都是这套逻辑的放大版。
