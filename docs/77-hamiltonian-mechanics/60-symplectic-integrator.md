# 辛结构与辛积分：能量为什么不漂

## 1. 从一个场景开始

要模拟太阳系十亿年的演化，选什么积分器？

直觉会说"选精度高的"：四阶龙格–库塔每步误差是 $O(h^5)$，比一阶欧拉精确得多。可是当天体力学家真的去算十亿年时，他们用的是**二阶**的蛙跳法（leapfrog）。原因很反直觉：RK4 每一步都更准，但它的误差**朝着同一个方向累积**——地球会缓慢地螺旋飞出去；蛙跳法每步粗糙，误差却在原处来回晃，十亿年后地球还在原来的轨道上。

分子动力学里同样的事：Verlet 积分器从 1967 年用到现在，靠的不是精度，是**结构**。这一课要讲清楚那个结构叫什么、为什么它比精度更值钱。

## 2. 直觉解释

把积分器看成**相空间里的一串搬动**：每走一步，就把整个相平面按某个规则挪一次。挪一次不要紧，挪几百万次就要命了。

现在看两种搬动的性格：

- **会放大的搬动**：每一步都把相面积悄悄乘以 $1+h^2$。走一步你看不出来（$1.0025$ 嘛），可走 5000 步就是 $264184$ 倍——**能量被"放大"了二十六万倍**，地球早被甩到银河系外。显式欧拉就是这种。
- **保面积的搬动**：每一步都不多不少地保持面积。既然面积不许变，轨道就不能螺旋向外（螺旋意味着面积在变）；它只能在原地"绕着一个稍微错位的椭圆"打转。

第二种性格的名字叫**辛**（symplectic）。辛积分器不是"更准"，而是**错得更有纪律**：它给出的数值轨道，严格地是另一个哈密顿量 $\tilde H$ 的精确轨道，而 $\tilde H$ 与真实的 $H$ 只差 $O(h)$。既然 $\tilde H$ 守恒，$H$ 就不可能漂走。

## 3. 正式定义

**辛形式**：相空间上把"$q$ 方向"和"$p$ 方向"配对的反对称双线性形式

$$\omega = \sum_{i=1}^{n} \mathrm dq_i \wedge \mathrm dp_i$$

它的矩阵写法是 $J = \begin{pmatrix} 0 & I \\ -I & 0 \end{pmatrix}$。**注意 $J^2 = -I$**：它扮演的角色就是"转 90 度"，这正是 §2 里"沿等高线走"的代数原因。

**保辛映射**：一个线性映射 $M$ 保辛，当且仅当

$$M^{\mathsf T} J M = J$$

**积分器**：把精确流 $\phi_h$ 换成近似映射 $\Phi_h$。两种一阶写法（$H$ 一般形式）：

$$\text{显式欧拉：} \quad p_{n+1} = p_n - h\frac{\partial H}{\partial q}(q_n, p_n), \qquad q_{n+1} = q_n + h\frac{\partial H}{\partial p}(q_n, p_n)$$

$$\text{辛欧拉：} \quad p_{n+1} = p_n - h\frac{\partial H}{\partial q}(q_n, p_n), \qquad q_{n+1} = q_n + h\frac{\partial H}{\partial p}(q_n, \mathbf{p_{n+1}})$$

两者的差别只有一处：辛欧拉的第二个方程用的是**刚更新过的** $p_{n+1}$。就这一处差别，决定了长期行为。

| 符号 | 名字 | 一句话含义 |
| --- | --- | --- |
| $\omega$ | 辛形式 | 相空间上"配对"位置与动量的结构 |
| $J$ | 辛矩阵 | $\omega$ 的矩阵写法，满足 $J^2=-I$ |
| $\Phi_h$ | 一步积分映射 | 把 $(q_n,p_n)$ 送到 $(q_{n+1},p_{n+1})$ |
| $\tilde H$ | 影子哈密顿量 | 数值轨道**真正**遵守的那个哈密顿量，$\tilde H = H + O(h)$ |
| $h$ | 步长 | 时间步 |

**核心定理（后向误差分析）**：若 $\Phi_h$ 是保辛的（并且足够光滑、接近精确流），则存在 $\tilde H = H + hH_1 + h^2H_2 + \cdots$，使得 $\Phi_h$ **恰好**是 $\tilde H$ 的精确流。

推论：$\tilde H$ 沿数值轨道严格守恒 $\Rightarrow$ $H = \tilde H + O(h)$ 的误差被框在 $O(h)$ 之内，**不随时间增长**。这就是"能量不漂"的全部理由。

**判据（一维）**：线性一步法保辛 $\Longleftrightarrow$ $\det \Phi_h = 1$（可逆 + 保面积）。高维时 $\det\Phi_h = 1$ 只是**必要**条件（保体积），完整的判据仍是 $M^{\mathsf T}JM = J$。下一节就用这个判据。

## 4. 分步例题

**例** 谐振子 $H = \tfrac12(p^2+q^2)$，两种一阶格式都写成矩阵，比较行列式。

1. **显式欧拉**：$q_{n+1} = q_n + hp_n$、$p_{n+1} = p_n - hq_n$，即
$$\begin{pmatrix} q_{n+1} \\ p_{n+1}\end{pmatrix} = \begin{pmatrix} 1 & h \\ -h & 1\end{pmatrix}\begin{pmatrix} q_n \\ p_n\end{pmatrix}, \qquad \det = 1\cdot 1 - h\cdot(-h) = 1 + h^2$$
2. **辛欧拉**：先算 $p_{n+1} = p_n - hq_n$，再代进去得 $q_{n+1} = q_n + h(p_n - hq_n) = (1-h^2)q_n + hp_n$，即
$$\begin{pmatrix} q_{n+1} \\ p_{n+1}\end{pmatrix} = \begin{pmatrix} 1-h^2 & h \\ -h & 1\end{pmatrix}\begin{pmatrix} q_n \\ p_n\end{pmatrix}, \qquad \det = (1-h^2)\cdot 1 - h\cdot(-h) = 1$$
3. **读出行列式的意思**：相面积每一步被乘以 $|\det|$。显式欧拉每步放大 $1+h^2$，辛欧拉**一步不多一步不少**；
4. **算总账**：取 $h = 0.05$，$1+h^2 = 1.0025$。走 5000 步（$t = 250$）：

$$1.0025^{5000} \approx 2.64\times10^{5}$$

初始能量 $0.5$ 会被放大到约 $1.32\times10^{5}$。而辛欧拉那 5000 步走完，能量还在 $0.5$ 附近——实测 $0.5069976$，偏差 $1.4\%$，且这个偏差**不随步数增长**。

5. **另一条直觉**：显式欧拉的矩阵特征值是 $1 \pm \mathrm ih$，模长为 $\sqrt{1+h^2} > 1$——每一步都把点往外推一点，这就是螺旋的来源。辛欧拉的特征值模长恰好为 $1$，点只能沿着"错位的椭圆"转圈。

左图画当前选中方法的轨道（灰虚线是参考解），**在左图上拖动**换初始条件。右图是本节最要紧的一张图：横轴时间、纵轴 $\log_{10}\left|\text{相对能量误差}\right|$（只看大小），三条曲线同时画：

- **显式欧拉**：一条一路爬升的直线——误差只涨不落；
- **辛欧拉**：一条**不涨的带子**，在固定高度上下振荡。它守恒的不是 $H$，而是那个与 $H$ 相差 $O(h)$ 的影子能量；
- **RK4**：每步都更准（带子整体更低），但它是**单调耗散**的——长时间看，误差一直朝一个方向爬。

把步长 $h$ 拖大：辛欧拉那条带子整体抬高（影子哈密顿量的偏差变大），但依然不涨；显式欧拉的斜率更陡。把"步数 N"拖到 6000，看三条线的分歧被拉得多开。

### 实验 2（python）：把 §4 的账算出来

```python
q1, p1 = 1.0, 0.0      # 显式欧拉的那一份
q2, p2 = 1.0, 0.0      # 辛欧拉的那一份
h = 0.05
n = 5000

def energy(q, p):      # H = (p² + q²)/2
    return 0.5 * (p * p + q * q)

for _ in range(n):
    q_old, p_old = q1, p1          # 显式欧拉：两条方程都用这一步开始时的值
    q1 = q_old + h * p_old
    p1 = p_old - h * q_old
    p2 = p2 - h * q2               # 辛欧拉：先更新动量
    q2 = q2 + h * p2               # 再用新动量更新位置

E1 = energy(q1, p1)
E2 = energy(q2, p2)
print(f"走 {n} 步（t = {n * h:.0f}）后：")
print(f"显式欧拉 E = {E1:.6e}（出发时 0.5）")
print(f"辛欧拉   E = {E2:.6e}（出发时 0.5）")
print(f"显式欧拉把能量放大了 {E1 / 0.5:.1f} 倍")
```

输出：`显式欧拉 E = 1.320920e+05（出发时 0.5）`、`辛欧拉   E = 5.069976e-01（出发时 0.5）`、`显式欧拉把能量放大了 264184.0 倍`。

那个 $264184$ 和 §4 第 4 步的理论值 $1.0025^{5000} \approx 2.64\times10^{5}$ 对上了——**显式欧拉的能量放大率不是巧合，就是它每一步的行列式连乘**。把 `n` 改成 10000：显式欧拉会变成 $10^{10}$ 量级（`E = ...` 开始出现科学计数法的巨大指数），辛欧拉仍然是 $0.5$ 上下。你也可以把 `h` 改成 0.01 再跑：显式欧拉 5000 步后只放大 $1.0001^{5000}\approx1.65$ 倍，看着"还挺准"——这就是它最危险的地方。

### 快问快答

```quiz
辛欧拉每步的误差比 RK4 大，为什么长时间模拟反而更可信？
- 因为它的误差有界、不累积：它精确守恒一个与 H 相差 O(h) 的影子哈密顿量 [*]
- 因为它的步长可以取得更大
- 因为 RK4 的公式有错误
? RK4 不是辛方法，误差单调耗散；辛方法的误差被影子哈密顿量框住，在 O(h) 内来回振荡而不增长。
```

::::warning[常见误区]

**误区一**："精度阶数越高越好。"
阶数只描述**单步**误差随 $h$ 的衰减速度，完全没说误差怎么累积。要跑 $10^9$ 步的场合，一个单调漂移的四阶方法会输给一个误差有界的二阶方法。选积分器先看结构（保辛？保体积？保动量？），再看阶数。

**误区二**："辛积分器能量严格守恒。"
不严格。它守恒的是**影子哈密顿量** $\tilde H$，真实能量 $H$ 会以 $O(h)$ 的幅度上下振荡。你在大图上看到的"带子"就是这段振荡。所以步长 $h$ 不能随便放大——$h$ 一大，影子哈密顿量偏离真实能量的幅度也跟着大，振荡幅度可能大到让轨道形状失真（虽然仍不会漂走）。

**误区三**："保辛就是保面积，所以对高维系统没意义。"
保面积只是 $n=1$ 时的说法。一般 $n$ 自由度下辛形式 $\omega$ 保的不是单个面积，而是所有 $2$ 维坐标平面上的面积之和结构（等价地说，是 $J$ 这个结构矩阵不变）。这个条件比"总体积不变"强得多：随便一个保体积的映射几乎一定不是辛的。

::::

## 6. 练习

**练习 1**：下面这段代码写的是**显式欧拉**（两条方程都用旧值），200 步后能量从 $0.5$ 涨到 `3.658009`。把它改成辛欧拉（先更新 $p$，再用**新** $p$ 更新 $q$），使输出变成 `0.483734`：

```exercise
# @title: 练习：把显式欧拉改成辛欧拉
# @check: 0.483734
# @hint: 把 q 的更新改成用刚算出来的 p（也就是把两行换个位置、去掉 q_old 这个中间变量）
q = 1.0
p = 0.0
h = 0.1
for i in range(200):
    q_old = q
    q = q + h * p       # ← 问题在这：用的是旧 p
    p = p - h * q_old
E = 0.5 * (p * p + q * q)
print(f"{E:.6f}")
```

**练习 2**：证明**隐式中点法** $z_{n+1} = z_n + h\,J\nabla H\!\left(\dfrac{z_n + z_{n+1}}{2}\right)$ 对线性系统保辛。

<details>
<summary>点开查看逐步解答</summary>

1. 对线性系统 $\nabla H(z) = Kz$（$K$ 对称），方程变成 $z_{n+1} = z_n + hJK\,\dfrac{z_n+z_{n+1}}{2}$；
2. 解出 $z_{n+1}$：$\left(I - \dfrac{h}{2}JK\right)z_{n+1} = \left(I + \dfrac{h}{2}JK\right)z_n$，即 $\Phi_h = \left(I - \dfrac h2 JK\right)^{-1}\left(I + \dfrac h2 JK\right)$；
3. 这是**凯莱变换**的标准形式：记 $A = \dfrac h2 JK$，则 $\Phi_h = (I-A)^{-1}(I+A)$；
4. 一维具体验算：取 $H = \tfrac12(p^2+q^2)$，此时 $K = I$、$JK = J = \begin{pmatrix}0&1\\-1&0\end{pmatrix}$，于是
$$I \mp \frac h2 J = \begin{pmatrix} 1 & \mp h/2 \\ \pm h/2 & 1\end{pmatrix}, \qquad \det\!\left(I \mp \frac h2 J\right) = 1 + \frac{h^2}{4}$$
5. 行列式相除：$\det \Phi_h = \dfrac{1 + h^2/4}{1 + h^2/4} = 1$，**保面积**（即一维下的保辛）；
6. 一般维数的情形：凯莱变换总满足 $(I-A)^{-1}(I+A)$ 的辛性（用 $A^{\mathsf T}J + JA = 0$ 这一个等式就能验完，而 $A = \frac h2 JK$ 在 $K$ 对称时恰好满足它）。顺带一句：这个映射在量子力学里叫 Crank–Nicolson，在流体里叫梯形法，在分子动力学里叫隐式中点法——**同一个映射，四个名字**。

</details>

## 7. 选读：好算法的标准是"解对了另一个问题"

<details>
<summary>选读 · 后向误差分析：比"误差小"更强的要求</summary>

数值分析里有一句被反复引用的箴言：**一个好的算法，不是"每一步都算得准"，而是"它给出的答案，是另一个邻近问题的精确答案"**（后向稳定）。这句话把"误差"从一个模糊的贬义词，变成了一个可以量化的对象。

辛积分器正是这句话最好的例证：它的输出是 $\tilde H$ 的精确轨道。因为精确轨道有一堆好性质（保能量、保相体积、保对称性、可逆），所以辛积分器也**继承**了这些性质——只是作用在 $\tilde H$ 上而不是 $H$ 上。反过来，一个单步精度极高的非辛方法（比如 RK4 用在保守系统上）没有任何这样的保证，它的误差会沿着某个方向缓慢堆积，最终毁掉长期结构。

这条思路还能往前走一步：如果你想守恒某个特定的量（比如角动量），就去设计一个**恰好**守恒它的积分器（这叫离散梯度法）；如果你想让算法严格可逆，就去设计对称的格式（比如蛙跳法）。这类方法统称**几何数值积分**，它是"离散化不应该破坏连续系统的几何结构"这一信念的产物——而它全部的词汇，都来自本卷前几课：相空间、辛形式、泊松括号、诺特定理。

</details>
