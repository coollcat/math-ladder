# 勒让德变换：从速度换到动量

## 1. 从一个场景开始

台球桌上两球相撞：动能会变成热，动量却分毫不差地守恒。可中学课本里的动量写作"质量乘速度"——既然质量是常数，"动量守恒"和"速度守恒"看上去差不多。真正把它们分开的是**质量不同的两个球**：轻球撞重球，速度变得面目全非，而 $mv$ 守着老账。

更麻烦的是，一旦动量不再是简单地把速度乘个质量——带电粒子在磁场里、或者速度接近光速时都是这样——我们就需要一台**换记法的机器**：把描述系统的自变量从"速度"整体换成"动量"，而且换完之后方程还要更好看。这台机器叫**勒让德变换**。

> 回扣一句：拉格朗日力学与最小作用量原理已经在[从牛顿到拉格朗日](../22-ode-dynamics/65-newton-to-lagrange.md)和[变分法](../26-functional-analysis/95-calculus-of-variations.md)里讲透了，本课**不重推**欧拉–拉格朗日方程，只把它当作已知的起点：$L(q, \dot q)$ 的运动方程由它给出。

## 2. 直觉解释

画一条向上弯的曲线（凸函数）。它有两种等价的描述方式：

- **按位置记**：横坐标取自变量，纵坐标取函数值——一份"逐点清单"；
- **按切线记**：先指定一个斜率，这条曲线上只有一处切线取这个斜率；把斜率当新的横坐标，把这条切线与纵轴的交点高度当作新的纵坐标。

第二种描述就是勒让德变换。信息一点没丢：只要曲线是凸的，这些切线就会把原曲线严丝合缝地"织"回来——曲线是切线族的包络。

对物理来说，**"斜率"就是动量**。拉格朗日量关于速度是凸的，它关于速度的斜率就是共轭动量。换完之后我们拿到一个新函数，它在动量坐标系里扮演原来那个函数在速度坐标系里的角色。换的不是物理，是记账方式；但换完之后，原来那个二阶方程会裂成一对漂亮的一阶方程。

## 3. 正式定义

设 $f(v)$ 是凸函数且可微。它的**勒让德变换**（也叫凸共轭）是

$$f^*(p) = \sup_{v}\left(p\,v - f(v)\right)$$

由于 $f$ 凸，括号里关于 $v$ 也是凹的，上确界在导数为零处取到：

$$p = f'(v) \quad\Longrightarrow\quad f^*(p) = p\,v(p) - f(v(p))$$

**物理版本**：对拉格朗日量 $L(q, v)$ 做同一个变换（$q$ 只是旁观参数），得到哈密顿量

$$p = \frac{\partial L}{\partial v}, \qquad H(q, p) = p\,v - L(q, v)\Big|_{v = v(p)}$$

| 符号 | 名字 | 一句话含义 |
| --- | --- | --- |
| $v$ | 速度（广义速度） | 原来的自变量，拉格朗日量对它求导 |
| $p$ | 共轭动量 | 新自变量，等于 $\partial L/\partial v$，不只是 $mv$ |
| $f, f^*$ | 函数与它的共轭 | 同一份信息的两种记法 |
| $\sup$ | 上确界 | 能取到的最大（下界最松的那个"最大"） |
| $q$ | 广义坐标 | 变换里只是被带着走的参数 |
| $L$ | 拉格朗日量 | 速度坐标系里的主角，通常是 $T - V$ |
| $H$ | 哈密顿量 | 动量坐标系里的主角，通常是 $T + V$ |

两条要记住的性质：

1. **对合**：$(f^*)^* = f$（凸函数）。换过去再换回来，原样奉还。
2. **斜率互换**：$f^*$ 的斜率是 $v$。因为 $(f^*)'(p) = v(p)$——把两边对 $p$ 求导，$p\,v'(p) + v(p) - f'(v)v'(p) = v(p)$，中间两项正好抵消。

## 4. 分步例题

**例** 取 $m = 2$ 的自由粒子，$f(v) = \tfrac{1}{2}mv^2$，在 $v = 3$ 处做勒让德变换。

1. 求斜率：$p = f'(v) = mv = 2 \times 3 = 6$；
2. 反解自变量：由 $p = mv$ 得 $v = p/m = 6/2 = 3$；
3. 算函数值：$f(v) = \tfrac12 \times 2 \times 9 = 9$；
4. 代定义式：$f^*(p) = p\,v - f(v) = 6 \times 3 - 9 = 9$。

第 3、4 步的数字不是巧合：对二次函数，$p\,v = mv^2$ 正好是 $f$ 的两倍，所以 $f^* = f$——**抛物线的共轭还是抛物线**。用公式验一遍：

$$f^*(p) = p\cdot\frac{p}{m} - \frac{1}{2}m\left(\frac{p}{m}\right)^2 = \frac{p^2}{2m}$$

代入 $p = 6$、$m = 2$，得 $36/4 = 9$，与第 4 步一致。

左图里**左右拖动**挪动切点：橙虚线是切线，它的斜率就是 $p$；灰虚线是过原点的直线 $pv$；曲线与直线之间的竖直间隙恰好是 $pv - f(v)$，也就是右图那个点的高度。把 $b$ 拖到 0，右图会还原成 $f^*(p) = p^2/(2m)$——和左图那条抛物线是同一个公式（只换了变量名），这就是"对合"的图形版。再把 $b$ 拖到 0.5，右图明显比左图矮胖：非线性把对偶形状拧歪了。

### 实验 2（python）：把三个数字算出来

```python
m = 2.0                 # 质量
v = 3.0                 # 速度
L = 0.5 * m * v ** 2    # 拉格朗日量（自由粒子只剩动能）
p = m * v               # 共轭动量 p = ∂L/∂v
H = p * v - L           # 勒让德变换
print(f"p = {p:.1f}，H = {H:.1f}")          # 冒号后的 .1f = 保留 1 位小数
print(f"对照 p²/(2m) = {p ** 2 / (2 * m):.1f}")

# 再用定义式 f*(p) = max_v (p·v − f(v)) 暴力扫一遍：最大值落在哪
best = -1e9             # 先放一个很小的数当擂主
best_v = 0.0
for i in range(-600, 601):          # v 从 −6 扫到 6，步长 0.01
    vv = i / 100                    # i 是整数，除以 100 变成浮点
    val = p * vv - 0.5 * m * vv ** 2
    if val > best:                  # 打擂台：更大的就替换
        best = val
        best_v = vv
print(f"扫描最大值 {best:.4f} 出现在 v = {best_v:.2f}")
```

三次输出分别是 `p = 6.0，H = 9.0`、`对照 p²/(2m) = 9.0`、`扫描最大值 9.0000 出现在 v = 3.00`。最后一行是定义式的**数值版**：把 $v$ 从 −6 扫到 6，最大的那个 $pv - f(v)$ 恰好出现在 $v = 3$，也就是 $p = f'(v)$ 的解处。把 `m` 改成 0.5 再跑，`p` 变成 1.5，可擂台仍然落在 `v = 3.00`——扫描出的位置永远跟着"你当初取的那个切点"走，因为 $p$ 和 $v$ 本来就由 $p = f'(v)$ 绑在一起。想换位置，改 `v`。

### 快问快答

```quiz
为什么勒让德变换要求原函数是凸的？
- 凸函数的导数单调，方程 p = f′(v) 才有唯一的解 v(p)，变换才是单值的 [*]
- 凸函数一定有最大值，取 sup 才存在
- 只有凸函数才能求导
? 凹函数或非凸函数的导数不单调，同一个斜率可能对应好几处切点，变换就成了多值关系，也就谈不上"换一套坐标"。
```

::::warning[常见误区]

**误区一**："勒让德变换就是把 $v = p/m$ 代进去化简。"
你以为这只是中学的代入消元——其实关键的一步是**反解**：从 $p = \partial L/\partial v$ 里解出 $v$ 作为 $p$ 的函数。这一步只有在 $L$ 关于 $v$ 是凸函数时才全局可做。相对论里 $L$ 关于 $v$ 依然凸（所以能做），但如果你把一个非凸的模型硬塞进来，反解会分叉，整个形式就崩了。

**误区二**："$H$ 就是能量。"
你以为哈密顿量天生等于动能加势能——其实只有在动能是速度的二次型、且约束不显含时间时才有 $H = T + V$。带电粒子在磁场里，$L$ 含速度的一次项，算出来的 $H$ 就不再等于 $T+V$；它依然是那个"守恒的哈密顿量"，但读数不等于动能加势能。

**误区三**："共轭动量就是 $mv$。"
你以为 $p$ 永远等于质量乘速度——其实 $p = \partial L/\partial v$ 才是定义。磁场里 $p = mv + qA$（多出一份"电磁动量"），相对论里 $p = \gamma mv$。把 $mv$ 当定义，会在这些地方算出错误结论。

::::

## 6. 练习

**练习 1**：下面这段代码把勒让德变换写成了 $p\cdot v$，跑出来是 `18.0`；按定义还必须**减去** $f(v)$。修到输出 `9.0`：

```exercise
# @title: 练习：m=2、v=3 时的勒让德变换
# @check: 9.0
# @hint: f*(p) = p·v − f(v)，而 f(v) = ½mv²。少了减号，结果正好翻倍
m = 2.0
v = 3.0
p = m * v           # 动量 = 质量 × 速度
fstar = p * v       # ← 问题在这：少减了 f(v)
print(fstar)
```

**练习 2**：取 $f(v) = \tfrac12 m v^2 + \tfrac14 b v^4$（实验 1 里那个四次项）。当 $b > 0$ 时，$f^*(p)$ 还能写成 $p^2/(2m)$ 吗？

<details>
<summary>点开查看逐步解答</summary>

1. 求导：$f'(v) = mv + bv^3$。它关于 $v$ 严格单调（$m > 0$、$b \ge 0$），所以能反解；
2. 反解没有初等闭式：要解三次方程 $bv^3 + mv = p$。这正是实验 1 里右图那条曲线为什么"变形"的代数原因；
3. 但在 $b$ 很小时可以展开。设 $v = p/m + \delta$，代进 $mv + bv^3 = p$ 得 $m\delta \approx -b(p/m)^3$，于是 $v \approx \dfrac{p}{m} - \dfrac{bp^3}{m^4}$；
4. 代入 $f^*(p) = pv - f(v)$ 并保留到 $p^4$ 项，得 $f^*(p) \approx \dfrac{p^2}{2m} - \dfrac{b\,p^4}{4m^4}$。

**结论**：$b>0$ 时不再是纯抛物线。四次项在高动量处**压低**了对偶函数——数值上你在实验 1 的右图里看到的"矮胖"，就是这一项的功劳。

**别把这个展开式当数值公式用**。取 $m = 1$、$b = 0.25$ 核对一下：$p = 0.5$ 时近似值 $0.121094$、真值 $0.121507$（差 $0.3\%$，很准）；$p = 2$ 时近似值 $1.000000$、真值 $1.581412$（差 $37\%$，已经不能用了）。原因是 $b$ 本身不算小，而 $p$ 又大——展开式只保证"$b$ 很小时成立"，它在这里的价值是告诉你**修正的方向**（压低），不是给你一个可代入的公式。想要准确值，就像实验 1 那样二分反解 $v$。

</details>

## 7. 选读：热力学里的四个势

<details>
<summary>选读 · 同一台机器，换的是内能</summary>

热力学第一定律写成 $\mathrm{d}U = T\,\mathrm{d}S - P\,\mathrm{d}V$：内能 $U$ 的自变量是熵 $S$ 与体积 $V$，它们的"斜率"分别是温度 $T$ 与负压强 $-P$。

于是可以对 $U$ 做勒让德变换，把自变量换成"实验里控制得住的"那两个量：

- 换掉 $V$（它的斜率是 $-P$）：$H_{th} = U - (-P)V = U + PV$，这就是**焓**；
- 换掉 $S$（它的斜率是 $T$）：$F = U - TS$，这就是**亥姆霍兹自由能**；
- 两个都换：$G = U - TS + PV$，这就是**吉布斯自由能**。

记号撞车不是巧合：热力学的"焓"、力学的"哈密顿量"，都来自同一台机器——把"广延量当自变量"换成"强度量当自变量"。化学反应在恒温恒压下往哪边走，由 $G$ 判据给出，正因为我们把温度、压强这两个**实验室里拧得动的旋钮**换成了自变量。

（数学上还有一条更细的对应：$U$ 关于 $S$ 的凸性 $\Leftrightarrow$ 热容为正 $\Leftrightarrow$ 系统稳定。凸性是勒让德变换的前提，这在热力学里就是稳定性条件。）

</details>
