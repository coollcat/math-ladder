# 诺特定理：对称就是守恒

## 1. 从一个场景开始

能量为什么守恒？

中学给的答案是"实验从来没发现例外"。这句话没错，但它不是解释——它只是把问题推给了"实验"。真正的原因藏在一句平淡的话里：**物理规律不随时间的推移而改变**。今天做的实验和明天做的、和一百年后做的，遵循同一套方程。就凭这一条，能量必须守恒。

同样的逻辑换两个方向：**空间是均匀的**（在北京做和在上海做一样）$\Rightarrow$ 动量守恒；**空间是各向同性的**（朝东做和朝北做一样）$\Rightarrow$ 角动量守恒。

1915 年，诺特（Emmy Noether）把这三句"物理直觉"变成了一条定理：**每一个连续对称，都对应一个守恒量**。这条定理是现代物理的地基——从流体力学到标准模型，"找守恒量"这件事从此被改写成了"找对称性"。

## 2. 直觉解释

想象一片地形，你是一个只会往下滚的小球。

- 如果地形沿**南北方向**是一条笔直的沟（往南走一百米，地势完全一样），那么无论你走到哪里，南北方向的"坡度"都是零——没有力推你往南，你在南北方向的动量就永远不变。
- 如果地形沿**东西方向**也是笔直的沟，东西方向的动量也守恒。
- 如果地形是一片**圆形**的碗（绕中心转一圈地势不变），那么"转动"这个方向没有力矩，角动量守恒。

把这三句话抽象一下：**对称 = 沿某个方向"平移"时地形不变 = 那个方向的坡度恒为零 = 那个方向没有力 = 那个方向的动量守恒**。

这里的"平移"是广义的：时间上的平移（今天和明天一样）对应的守恒量是能量；绕圆心的转动对应的守恒量是角动量。诺特定理就是把"平移"这个词的所有可能含义都算清楚，然后逐个给出守恒量。

## 3. 正式定义

**连续对称**指的是一个**单参数变换族** $T_\epsilon$（$\epsilon$ 是连续可调的旋钮，$\epsilon = 0$ 是恒等变换），它保持哈密顿量不变：

$$H\big(T_\epsilon(q, p)\big) = H(q, p) \quad \text{对一切 } \epsilon$$

**无穷小形式**：只看到一阶项，变换写成

$$\delta q_i = \epsilon\,\frac{\partial G}{\partial p_i}, \qquad \delta p_i = -\epsilon\,\frac{\partial G}{\partial q_i}$$

右边的 $(q,p)$ 位移恰好是"以 $G$ 为哈密顿量的流动"。这个 $G$ 叫对称的**生成元**。

**诺特定理（哈密顿版本）**：上面这个变换保持 $H$ 不变，当且仅当

$$\lbrace G, H\rbrace = 0$$

也就是说：**对称的生成元就是守恒量**。

| 对称性 | 旋钮 $\epsilon$ 是什么 | 生成元 $G$ | 守恒量 |
| --- | --- | --- | --- |
| 时间平移 | 把整个演化推迟 $\epsilon$ | $H$ | 能量 |
| 空间平移（$x$ 方向） | 全体位置右移 $\epsilon$ | $p_x$ | 线动量 |
| 空间旋转 | 全体绕原点转 $\epsilon$ | $L_z = xp_y - yp_x$ | 角动量 |
| 内部相位旋转 | 波函数整体乘 $e^{\mathrm i\epsilon}$ | 电荷 $Q$ | 电荷 |

**为什么成立**（一步）：变换是用 $G$ 生成的，所以"$H$ 在这个变换下不变"与"$H$ 沿 $G$ 的流不变"是同一件事，即 $\lbrace H, G\rbrace = 0$；由反对称性，这就是 $\lbrace G, H\rbrace = 0$，也就是 $G$ 守恒。

**反过来也成立**：若 $\lbrace G,H\rbrace = 0$，那么用 $G$ 生成的流保持 $H$ 不变。所以"守恒量"与"连续对称"是一一对应的**同一件事的两种说法**。

## 4. 分步例题

**例** 二维势场 $V = \tfrac12\big[(1+\varepsilon)x^2 + (1-\varepsilon)y^2\big]$，问角动量 $L_z = xp_y - yp_x$ 是否守恒。

预备（用基本括号算）：$\lbrace x, H\rbrace = p_x$、$\lbrace y,H\rbrace = p_y$，以及 $\lbrace p_x,H\rbrace = -\dfrac{\partial H}{\partial x} = -(1+\varepsilon)x$、$\lbrace p_y,H\rbrace = -(1-\varepsilon)y$。

1. 用莱布尼茨律把 $L_z$ 拆开：
$$\lbrace L_z, H\rbrace = x\lbrace p_y,H\rbrace + p_y\lbrace x,H\rbrace - y\lbrace p_x,H\rbrace - p_x\lbrace y,H\rbrace$$
2. 逐项代入：$= x\cdot\big(-(1-\varepsilon)y\big) + p_y p_x - y\cdot\big(-(1+\varepsilon)x\big) - p_x p_y$；
3. 合并：第一项与第三项给出 $\big[(1+\varepsilon)-(1-\varepsilon)\big]xy = 2\varepsilon\,xy$；第二、四项 $p_xp_y - p_xp_y = 0$ 正好抵消；
4. 结论：$\lbrace L_z, H\rbrace = 2\varepsilon\,xy$。

所以：

- $\varepsilon = 0$（圆对称的碗）：括号恒为零，**角动量守恒**；
- $\varepsilon \ne 0$（椭圆碗）：括号是 $2\varepsilon xy$，只在坐标轴上为零——一旦离开坐标轴，$L_z$ 就以 $\mathrm dL_z/\mathrm dt = 2\varepsilon xy$ 的速率变化，**不再守恒**。

数值感觉：$\varepsilon = 0.3$、在 $x = y = 1$ 处，$\mathrm dL_z/\mathrm dt = 0.6$。实验里从 $(x,y) = (1,0)$ 出发以初速 $(0,1)$ 跑，$L_z$ 出发时是 $1$，随后的偏离最大到 $2.33$——势场被拧成椭圆之后，角动量连符号都保不住。

### 实验 2（python）：数值盯住角动量

```python
import math
def accel(eps, x, y):        # V = ½(1+ε)x² + ½(1−ε)y² 的负梯度
    return (-(1 + eps) * x, -(1 - eps) * y)

def run(eps, h=0.001, steps=20000):
    x, y = 1.0, 0.0          # 初始位置
    vx, vy = 0.0, 1.0        # 初始速度
    L0 = x * vy - y * vx     # 角动量 z 分量
    worst = 0.0
    for _ in range(steps):
        ax, ay = accel(eps, x, y)
        vx2 = vx + h * ax    # 先更新速度（辛欧拉的写法）
        vy2 = vy + h * ay
        x = x + h * vx2      # 再用新速度更新位置
        y = y + h * vy2
        vx, vy = vx2, vy2
        worst = max(worst, abs((x * vy - y * vx) - L0))
    return L0, worst

for eps in (0.0, 0.3):
    L0, worst = run(eps)
    print(f"ε = {eps:.1f}：L 出发值 {L0:.4f}，全程最大偏离 {worst:.2e}")
print(f"周期对照：ε = 0 时圆频率 1，一圈 {2 * math.pi:.4f}")
```

输出：`ε = 0.0：L 出发值 1.0000，全程最大偏离 1.22e-14`、`ε = 0.3：L 出发值 1.0000，全程最大偏离 2.33e+00`。

第一行的 $1.22\times10^{-14}$ 是浮点数的舍入底噪——理论上严格为零，机器只能给到这个量级。第二行的 $2.33$ 则是真实的物理偏离，比舍入大了十四个数量级。**"守恒"与"不守恒"的差别，在数值上就是这么干脆。**

::::warning[常见误区]

**误区一**："诺特定理只说'对称蕴含守恒'。"
其实反过来也成立：**守恒量也蕴含对称**——每个守恒量 $G$ 都能生成一族保持 $H$ 不变的变换。所以在本课的语言里，"守恒量"和"连续对称"是同一件事的两个名字。找一个守恒量，就等于找到了一把可以自由转动的旋钮。

**误区二**："能量守恒来自'能量不生不灭'这类哲学原理。"
不是。能量守恒的直接来源是**时间平移对称**：方程不显含时间。反过来，如果物理规律随时间变化（比如一个正在变强的引力场），能量就不守恒——宇宙学里红移的光子就真的会丢能量，这不违反任何东西，因为宇宙在膨胀、时间平移对称在宇宙尺度上被破坏了。

**误区三**："对称性只跟守恒量有关。"
在现代物理里，对称性管的事情远不止守恒：**它决定相互作用的形式**。要求麦克斯韦方程组在洛伦兹变换下保持形式不变，电磁场的结构就被定死了；要求规范对称，传递相互作用的粒子（光子、胶子）就被强制存在。这条路上的终点是标准模型——而起点就是本课这条括号等于零。

::::

**练习 2**：用诺特定理判断——一个只依赖 $r = \sqrt{x^2+y^2}$ 的势场 $V(r)$，哪些量守恒？如果势场改成 $V = V(r) + ky$（在 $y$ 方向加一个均匀的"斜坡"），哪些还守恒？

<details>
<summary>点开查看逐步解答</summary>

1. $V(r)$ 对**任何**绕原点的旋转都不变，所以旋转对称成立 $\Rightarrow$ 角动量 $L_z$ 守恒；
2. $V(r)$ 也不含时间 $\Rightarrow$ 时间平移对称 $\Rightarrow$ 能量守恒；
3. 但 $V(r)$ 依赖 $x$ 和 $y$（都有），所以**平移**不是对称：把整个系统往右移一点，$r$ 会变。因此线动量**不**守恒；
4. 加上斜坡 $ky$ 后：沿 $x$ 方向平移 $\epsilon$，$V$ 不变 $\Rightarrow$ $p_x$ 守恒；沿 $y$ 方向平移，$V$ 变了 $k\epsilon$ $\Rightarrow$ $p_y$ **不**守恒，$\dot p_y = -k$；
5. 旋转还对称吗？把整个图形转一下，$ky$ 那一项会变成 $k$ 乘上新的 $y$ 坐标，一般不等于原来的 $ky$——所以 $L_z$ 也**不再守恒**。

**结论**：一个斜坡只留下一个方向的平移对称，也就只留下一个动量分量。这正是 §5 实验里那个"平移对称"模式在教的事：**你保留多少对称，就留下多少守恒量。**

</details>

## 7. 选读：从守恒量到守恒流

<details>
<summary>选读 · 场论里的"守恒"是局部的</summary>

对粒子，"电荷守恒"就是一句话：一个数不随时间变。可场论里的场充满整个空间，"某个地方有多少电荷"这种说法必须写成**密度**。于是守恒律升级为**连续性方程**：

$$\frac{\partial \rho}{\partial t} + \nabla\cdot\mathbf j = 0$$

电荷密度 $\rho$ 在某处减少，必定是因为有电流 $\mathbf j$ 从那里流出去——一个地方少了，另一个地方就多了，**整体总量不变**。诺特定理在场论里的表述就是：每个连续对称 $\Rightarrow$ 一个守恒流 $j^\mu$，满足 $\partial_\mu j^\mu = 0$。时间平移对应能量–动量张量，相位旋转对应电磁流。

这套语言最重要的推论是**局域性**：对称的旋钮不是"整体转一下"，而是"在每一点各转一个角度"（局域对称）。要求这种更强的对称性，就**必须**引入一个新的场来抵消"每点角度不同"带来的额外项——那个场就是光子（或胶子、$W/Z$ 玻色子）。标准模型里所有的相互作用，都是从这条思路里被"逼"出来的。

这条路的第一块砖头，就是本课那条 $\lbrace G, H\rbrace = 0$。

</details>
