# 吸收态：常返、暂过与逃逸时间

## 1. 从一个场景开始

大富翁棋盘上有一种格子，踩上去就出不来了——监狱会放人，但"破产出局"不会。现实世界到处是这样的终点站：公司破产、病人痊愈出院、棋局分出胜负。一旦进入，链条就永远停在那里：$P(\text{自己到自己})=1$。

这类**吸收态**改写了全部剧本：平稳分布不再唯一（每个黑洞都自成一个归宿），真正要问的问题变成两个——**最终被哪个终点吞没？平均挣扎多久才到？**赌徒在赌桌上的命运、粒子在势阱里的湮灭，全是这两道题的变装。

## 2. 直觉解释

把状态分成两种性格：

- **暂过态**（候车室）：迟早会离开且一去不返——游戏进行中的每个位置；
- **常返态**（终点站）：一旦到达就无限次回访；吸收态是最极端的常返态。

从候车室出发的命运由两个数字决定：

- **吸收概率** $h_i$：从状态 i 出发最终落入指定终点的机会；
- **期望吸收时间** $t_i$：从 i 出发到被任何终点吞没的平均步数。

计算它们不需要高深工具，只要一招**首步分析**："从 i 出发的总时长 = 走完第一步（恒为 1 步）+ 从落点继续的全部"。对赌徒破产问题（本金 i 元、目标 N 元、每局输赢 1 元），这招给出漂亮的结论：赢下整场的概率恰是 $i/N$——**起点离哪头近就偏向哪头**，公平得像天平。

## 3. 正式定义

状态 $j$ 是**吸收态**，当且仅当 $p_{jj}=1$（到达后永不离去）。

**首步分析方程**：设 $T$ 为首次进入吸收集的时刻，

$$t_i=E[T\mid X_0=i]=1+\sum_{k\ \text{暂过}} p_{ik}\,t_k, \qquad h_i=\sum_{k}p_{ik}\,h_k$$

边界条件：吸收态处 $t=0$；目标终点处 $h=1$、其余终点 $h=0$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p_{jj}=1$ | 吸收条件 | 自环概率顶格，出不去 |
| $h_i$ | 吸收概率 | 从 i 出发被指定终点吞没的机会 |
| $t_i$ | 期望吸收时间 | 从 i 出发到进任意终点的平均步数 |
| 首步分析 | 一层剥离法 | 用"第一步 + 余下期望"自指建模 |

注意方程是**联立的**：每个暂过态的 $t_i$ 都依赖邻居的 $t_k$，全体一起解线性方程组（小链可手工消元）。这与平稳分布方程同源——都是"当前量 = 邻居加权和"的自洽结构。

## 4. 分步例题

**例**：赌徒破产局：身上有 2 元，每局以 $\frac{1}{2}$ 赢 1 元或输 1 元，输光（0 元）或攒够 5 元收手。求赢的概率与平均总局数。

1. 状态 = 当前资金 $\lbrace0,1,2,3,4,5\rbrace$；吸收态：0 与 5；
2. 吸收概率首步分析：$h_i=\frac{1}{2}h_{i+1}+\frac{1}{2}h_{i-1}$，即差分为常数，解得 $h_i=\frac{i}{5}$；
3. 代入 $i=2$：赢面 $h_2=\frac{2}{5}=0.4$——比直觉的"五五开"低了一截，因为离输光更近；
4. 时长方程：$t_i=1+\frac{1}{2}t_{i+1}+\frac{1}{2}t_{i-1}$，配边界 $t_0=t_5=0$，解得 $t_i=i(5-i)$；
5. 代入 $i=2$：平均 $2\times3=6$ 局。"六局定生死，四成胜算"——这就是公平赌局的全部真相。

### 实验 2（python）：三千名赌徒的命运档案

```python title="蒙特卡洛赌徒破产：胜率与平均时长"
# sliders: money=2 [1:4:1], goal=5 [3:6:1]
import random

wins = 0
steps_total = 0
rounds = 3000                      # 模拟多少名赌徒各玩一局人生
for g in range(rounds):
    purse = money                  # 当前赌资
    for step in range(10000):      # 安全上限：理论上几乎用不到这么久
        if purse == 0 or purse == goal:
            break                  # 已进终点站，本局结束
        if random.random() < 0.5:
            purse = purse + 1      # 赢 1 元
        else:
            purse = purse - 1      # 输 1 元
    if purse == goal:
        wins = wins + 1
    steps_total = steps_total + step

print(f"{rounds} 名赌徒中获胜 {wins} 人，胜率 ≈ {round(wins / rounds, 4)}")
print(f"理论胜率 i/N = {round(money / goal, 4)}")
print(f"平均局数 ≈ {round(steps_total / rounds, 1)}，理论 i×(N−i) = {money * (goal - money)}")
```

拖动滑块改变出身与目标：胜率严格跟着 `money/goal` 走，平均时长在中间起步时最长——两头都是快结局，中间才是漫长的挣扎区。

### 实验 3（python)：画出几条随机轨迹看"候车室"

```python title="三条轨迹：暂过区的徘徊与终点的一锤定音"
import random
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 3, figsize=(10, 2.6), sharey=True)   # 三张子图共用纵轴
for ax in axes:
    purse = 2
    path = [purse]
    for step in range(200):
        if purse == 0 or purse == 5:
            break
        purse = purse + (1 if random.random() < 0.5 else -1)
        path.append(purse)
    ax.plot(range(len(path)), path, color="steelblue")
    ax.axhline(0, color="tomato", linestyle="--")
    ax.axhline(5, color="olive", linestyle="--")

plt.tight_layout()
```

三条轨迹各有性格：有的早早触线，有的在中段反复拉锯。共同点只有一个——**没有一条能永远悬在中间**：暂过态的平均停留时间有限（有限链的必然），"候车"只是延迟，不是豁免。

### 快问快答

```quiz
赌徒手里钱越多，距离目标又同样远时，平均还能玩多久？
- 钱越多玩越久
- 与起点到两端的两个距离之积成正比 [*]
- 和钱数无关，全看运气
? 公平局里 t(i) = i×(N−i)：离两端越远（居中）拖得越久，贴边则速战速决。这是首步分析方程的经典解。
```

:::warning[常见误区]

**误区一**："你以为吸收链也有'正常运转'的平稳分布。" 有，但它长成了退化形状：把全部质量堆在某一个吸收态上就是一组合法解，而且有无穷多组混合版本。"哪个终点占多少份额"由初始分布决定——这正是与遍历链最大的分野。

**误区二**："你以为期望时间有限意味着很快结束。" 有限但可以很大：某些参数下方差巨大，少数极端幸运（或倒霉）的轨迹把平均值拽得很长。报"平均 6 局"的同时最好补一句波动范围，否则听者会拿它当承诺。

**误区三**："你以为'迟早回到起点'和'吸收'矛盾。" 常返的定义是回访概率为 1；吸收态是常返的特例（回到自己）。而暂过态"迟早一去不返"也不等于"马上消失"——平均停留时间可以相当可观。三个概念各管一件事，别互相顶替。

:::

**练习 2**：把实验 1 的赌局改成不公平版：每局胜率只有 0.45。先猜猜胜率怎么变，再用滑块验证不了的部分动手改代码跑一遍。

<details>
<summary>点开查看逐步解答</summary>

不公平局的首步分析解为 $h_i=\dfrac{1-\rho^i}{1-\rho^N}$，其中 $\rho=\dfrac{\text{输率}}{\text{胜率}}=\dfrac{0.55}{0.45}\approx1.222$。代入 $i=2,N=5$：

$$h_2=\frac{1-1.222^2}{1-1.222^5}\approx\frac{1-1.494}{1-2.728}\approx\frac{0.494}{1.728}\approx0.286$$

胜率从 0.4 摔到约 0.28——轻微的规则倾斜经过“反复博弈”放大成显著的命运差距。赌场只需要 51% 对 49%，长期就能稳稳吃掉对手：吸收结构是任何微小优势的放大器。
</details>

## 7. 选读：吸收矩阵的分块解剖

<details>
<summary>选读 · 标准型与基本矩阵 N=(I−Q)^(-1)</summary>

把吸收链的转移矩阵按"暂过区 | 吸收区"重排成分块标准型：

$$P=\begin{pmatrix}Q & R\\ 0 & I\end{pmatrix}$$

其中 Q 是暂过态之间的内部流转，R 是跳向各终点的出口概率。代数上可以证明 $P^n$ 的左上块是 $Q^n$，于是暂过态的总访问次数矩阵收敛到所谓**基本矩阵**

$$N=I+Q+Q^2+\cdots=(I-Q)^{-1}$$

（Q 的谱半径小于 1 保证逆存在）。$N_{ij}$ 读作"从 i 出发一生中平均路过 j 多少次"；行求和即期望吸收时间，$NR$ 则给出各终点的吸收概率表。本课的首步分析方程组，正是 $(I-Q)t=\mathbf{1}$ 的逐行写法——两条路殊途同归，矩阵版本在大规模计算里更快。

大富翁完整棋盘有四十格外加三张机会牌的强制传送，它的转移矩阵正是这样一块带稀疏结构的大家伙——下一课我们用一个玩具版网页图体验幂迭代如何啃动它。
</details>
