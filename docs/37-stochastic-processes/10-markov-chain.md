# 马尔可夫链：状态与转移

## 1. 从一个场景开始

气象台预报明天下雨，用的是超级计算机和卫星云图。但如果把野心调小一点——只根据"今天是晴是雨"猜明天，一个两行的小表格就够了：晴天之后 80% 还是晴，雨天之后只有一半转晴。

别小看这张表。1906 年马尔可夫用它研究普希金《叶甫盖尼·奥涅金》里元音辅音的交替规律，开创了"随机过程"的百年传统；今天，同样的表格驱动着大富翁的棋子、网页的排名、基因序列的比对。本章的任务就是把这张小表格的全部威力榨出来。

## 2. 直觉解释

把系统可能处的每种情况画成**圆圈**（状态），圆圈之间连**箭头**（一步转移），箭头上标概率——这就是一张随机世界的地图。

- 天气模型：两个圈「晴」「雨」，晴到晴 0.8、晴到雨 0.2、雨到晴 0.5、雨到雨 0.5；
- 每个圆圈的**出箭头概率之和必须是 1**：明天总得落到某个圈里。

整张图压缩成**转移矩阵**：第 $i$ 行写清"从状态 $i$ 出发去各个状态的概率"。于是"预测明天"变成一次向量乘矩阵：

$$p_{t+1}=p_t\,P \qquad (\text{今天的分布乘以转移矩阵等于明天的分布})$$

而这一切成立的前提是一条看似健忘的假设——**马尔可夫性**：预测未来只需要现在，更早的历史可以全部烧掉。健忘不是缺陷，是建模的艺术：它把无限长的历史压缩成一个状态标签，让计算成为可能。

## 3. 正式定义

设状态空间为有限集 $\lbrace1,2,\dots,N\rbrace$，随机过程 $X_t$ 取值其中。

**马尔可夫性**：

$$P(X_{t+1}=j\mid X_t=i,\ X_{t-1},\dots,X_0)=P(X_{t+1}=j\mid X_t=i)$$

若右端还与 $t$ 无关（今天定义，天天适用），称**时间齐次**，此时

$$P=(p_{ij}), \qquad p_{ij}=P(X_{t+1}=j\mid X_t=i)$$

称为**转移矩阵**；每行求和恒为 1（行随机矩阵）。若时刻 $t$ 的状态分布是行向量 $p_t$，则演化规则就是上面的 $p_{t+1}=p_tP$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $X_t$ | 时刻 t 的状态 | 系统此刻在哪个圈里 |
| $p_{ij}$ | 转移概率 | 从 i 出发下一步到 j 的条件概率 |
| $P$ | 转移矩阵 | 第 i 行 = 从状态 i 出发的去向清单 |
| $p_t$ | 状态分布行向量 | 时刻 t 系统落在各状态的概率 |

约定全书用**行向量右乘**：$p_{t+1}=p_tP$，"第几行"就是"从哪出发"。有的教材用列向量左乘 $p_{t+1}=Pp_t$，只是排版习惯，内容完全等价——读任何文献先确认方向。

## 4. 分步例题

**例**：天气链 $P=\begin{pmatrix}0.8 & 0.2\\ 0.5 & 0.5\end{pmatrix}$（第一行=晴的去向，第二行=雨的去向）。今天必是晴天，问明后两天的分布？

1. 今天分布 $p_0=(1,\ 0)$：100% 在晴；
2. 明天：$p_1=p_0P=(1\times0.8+0\times0.5,\ \ 1\times0.2+0\times0.5)=(0.8,\ 0.2)$；
3. 后天：$p_2=p_1P=(0.8\times0.8+0.2\times0.5,\ \ 0.8\times0.2+0.2\times0.5)=(0.74,\ 0.26)$；
4. 观察趋势：雨天占比从 0 到 0.2 再到 0.26——在往上爬，但爬速越来越慢。它会停在哪里？停住意味着什么？这正是后面两课的悬念。

## 5. 动手实验

### 实验 1（viz）：拖着 steps 看分布自己走

正文那条天气链（晴 80% 留晴、雨 50% 转晴）在这里被搬上了滑块。**怎么玩**：拖 steps，从 0 一步步往上加——steps=0 时棒图只有「晴」一根（初始必为晴天）；每加 1，分布就左乘一次转移矩阵，你会看到「雨」那根从 0 慢慢冒头、随后两根都停在某个位置不再大幅移动。虚线是平稳分布的位置（它从哪来，下一课讲），读数里的「距平稳最大偏差」会随 steps 增大一路缩水——**这就是 §3 说的「初始分布的影响会耗尽」的直观版**。建议先只看 0~5 步，对照实验 2 的手算分布 $pP$、$pP^2$，两者必须逐位一致。

### 实验 2（python）：让天气自己下 60 天

```python title="模拟天气链：单条轨迹 + 长期晴天占比"
# sliders: days=60 [10:600:10]
import random

weather = ["晴", "雨"]
state = 0                          # 从晴天出发（0 号状态）
history = []

for day in range(days):
    history.append(weather[state])
    r = random.random()            # 掷一次 [0,1) 均匀小数来决定去向
    if state == 0:
        state = 0 if r < 0.8 else 1    # 晴天的出箭头：80% 留晴，20% 转雨
    else:
        state = 0 if r < 0.5 else 1    # 雨天的出箭头：对半开

sunny = 0
for w in history:
    if w == "晴":
        sunny = sunny + 1

print(f"{days} 天中晴天占比 ≈ {round(sunny / days, 4)}")
```

多跑几次：每天的阴晴毫无规律可言，但占比总是晃晃悠悠漂向 0.7 附近。这个神秘的数字不是巧合——30 课将精确解出它是 $\frac{5}{7}\approx0.7143$。

### 实验 3（python）：分布按 pP 一步步演化

```python title="不用模拟：直接用矩阵推演未来每一天"
import matplotlib.pyplot as plt

P = [[0.8, 0.2], [0.5, 0.5]]           # 行 = 出发状态，列 = 目的地
p = [1.0, 0.0]                         # 初始分布：100% 晴

rain_share = []                        # 记录每天"雨"的概率，画折线
for t in range(15):
    rain_share.append(p[1])
    nxt = [p[0] * P[0][0] + p[1] * P[1][0], p[0] * P[0][1] + p[1] * P[1][1]]
    p = nxt                            # 行向量 × 矩阵：新分布每个分量都是加权平均

plt.plot(range(15), rain_share, marker="o", color="steelblue")
plt.axhline(2 / 7, color="tomato", linestyle="--")   # 预告：雨天长期占比 2/7 ≈ 0.2857
plt.xlabel("day")
plt.ylabel("P(雨)")
```

蓝线爬向橙色虚线且在本例中从不越过——确定性工具居然能预言随机轨迹的**集体宿命**。虚线上的 $2/7\approx0.2857$ 是雨天长期占比（晴天对应 $5/7$）。这个比例是怎么算出来的？30 课见分晓。

### 快问快答

```quiz
下面哪种说法符合马尔可夫性？
- 明天天气由过去一周的天气共同决定
- 已知今天下雨，昨天的晴雨不再影响对明天的预测 [*]
- 明天和今天一定相反
? 马尔可夫性说的是"给定现在，未来与过去独立"——不是无视历史，而是历史的影响已经全部浓缩进今天的状态标签里。
```

:::warning[常见误区]

**误区一**："你以为转移矩阵每列加起来等于 1。" 行向量约定下是**每行**和为 1：每行的含义是"从这个状态出发的全部分去向"，总得去某处所以加满 1。列和一般不等于 1，混用行列方向是新手第一大坑。

**误区二**："你以为'健忘的链'太粗糙没法实用。" 遗忘是特性不是缺陷：只要把足够的信息塞进状态定义（比如状态改成"最近两天天气"共四种组合），许多看似依赖历史的系统都能被改造成马尔可夫链——状态设计本身就是建模功力。

**误区三**："你以为单条轨迹会收敛。" 收敛的是**分布**，不是某一条具体路径：实验 1 里天气序列永远上蹿下跳，稳定下来的只是"晴天占比"。混淆"轨迹收敛"与"分布收敛"会在后面吸收链一课付出惨痛代价。

:::

## 7. 选读：安德烈·马尔可夫和他的诗歌实验

<details>
<summary>选读 · 为赌徒发明的数学，先在文学里开了花</summary>

概率论诞生于赌博信件（帕斯卡与费马，1654），但直到二十世纪初，"独立性"仍是几乎所有理论的隐藏地基——大家默认每掷一次都该和之前毫无关系。马尔可夫偏不服气：他要在**前后相依**的世界里找秩序。1913 年他数了两万多个字母，验证《叶甫盖尼·奥涅金》的元音辅音交替是一条（近似）马尔可夫链，并用链的语言算出了极限比例——比柯尔莫哥洛夫公理化早二十年，随机过程就这样在一部俄国长诗里呱呱坠地。

有趣的是，马尔可夫当年研究链条的动机之一，是要反驳他的论敌涅克拉索夫——后者认为大数定律只对独立试验有效。马尔可夫证明相依序列同样有大数定律：一场学术骂战，意外地为现代随机过程奠基。
</details>
