# 更新过程：事件反复发生时的节拍

## 1. 从一个场景开始

写字楼里的共享打印机坏一次修一次：修好之后能安稳跑一阵，坏了就停机等维修。运维经理翻出过去两年的工单，发现**两次故障之间的间隔时长时短**——最短的三天，最长拖到两周。他关心两个很实际的问题：**一年大概要报修几次**？以及**随手走进机房看一台正在用的机器，它平均已经多久没修过了**？

第一个问题问的是"事件反复发生时的节拍"；第二个问题看起来只是随口一问，答案却反直觉——这正是本课的招牌戏。把故障、零件更换、保单理赔这类"修好又坏、坏了又修"的循环统一描述下来的工具，叫**更新过程**。

## 2. 直觉解释

**核心直觉：一串独立同分布的间隔，头尾相接铺满时间轴。**

想象一条传送带，每走过一段距离就"啪"地落下一个事件。每一段的长度是一次抽签：第 1 段抽到 $T_1$，第 2 段抽到 $T_2$……每次抽签互不影响，用的还是同一个分布。把这些间隔首尾相接，落点的位置

$$S_n = T_1 + T_2 + \cdots + T_n$$

就是一串**更新点**；到时刻 $t$ 为止一共更新了几次，记作 $N(t)$。整套机制只有两条约定：间隔**独立**、间隔**同分布**。至于这个分布长什么样，随便——均匀、正态、Gamma、三点分布都行。

**它和前一课的关系。** 如果那个间隔分布恰好是指数分布，这套机制就退化成一个"无记忆"的特殊情形——那正是接下来泊松过程那一课的主角。但现实里的零件寿命、机器故障间隔几乎都不是指数的：新机器不容易坏，用久了才容易坏。这种"越老越脆"的分布没有无记忆性，泊松的那套现成公式立刻失效。**更新过程就是把泊松放宽到"任意间隔分布"的推广。**

**更新定理：长期速率 = 1/平均间隔。** 不管间隔分布多古怪，只要平均间隔是 $\mu$，跑得够久之后，单位时间内的平均更新次数一定趋近 $1/\mu$。直觉上很自然：一百次更新一共用掉的时间平均是 $100\mu$，于是平均每 $\mu$ 时间更新一次。**速率只认平均间隔，其余细节全部在长期里被磨平。**

**检查悖论：随手一瞥，往往撞上"长"的那一段。** 站在时间轴上随机挑一个瞬间，它落在哪一段间隔里？**越长的间隔占据的时间越多，被随机点撞上的概率就越大。** 于是被撞上的那一段平均比普通的一段更长，落在它里面时"已经等了多久"（年龄）也就比"平均间隔的一半"更大。这就是为什么公交乘客总觉得"我等的这趟车特别难等"——不是错觉，是长度偏置。

## 3. 正式定义

设 $T_1, T_2, \dots$ 是一列**独立同分布**的非负随机变量，分布函数为 $F$，均值 $\mu = E[T_1] \in (0, \infty)$。令 $S_0 = 0$、$S_n = T_1 + \cdots + T_n$。

**更新过程**：计数过程 $\lbrace N(t) \rbrace_{t\ge0}$，其中

$$N(t) = \max\lbrace\,n : S_n \le t\,\rbrace$$

即时刻 $t$ 之前（含）发生的更新次数。每次更新发生在 $S_1, S_2, \dots$。

**更新函数**：$m(t) = E[N(t)]$，即"到时刻 $t$ 为止平均更新了几次"。它满足**更新方程**

$$m(t) = F(t) + \int_0^t m(t-s)\, \mathrm{d}F(s).$$

**基本更新定理**：当 $t \to \infty$，

$$\frac{m(t)}{t} \longrightarrow \frac{1}{\mu} = \frac{1}{E[T_1]}.$$

**二阶展开**（间隔连续、二阶矩有限）：长期看 $m(t)$ 几乎是一条直线，只比 $t/\mu$ 平移了一个常数：

$$m(t) \approx \frac{t}{\mu} + \left( \frac{\sigma^2}{2\mu^2} - \frac{1}{2} \right), \qquad \sigma^2 = \mathrm{Var}(T_1).$$

**更新报酬过程**：给第 $i$ 段间隔配一个报酬 $R_i$（独立同分布，且与 $T_i$ 允许相关），到时刻 $t$ 的累计报酬是 $R(t) = \sum_{i=1}^{N(t)} R_i$。长期报酬率为

$$\frac{R(t)}{t} \longrightarrow \frac{E[R_1]}{E[T_1]}.$$

**检查悖论**：在长期中随机取一个时刻，它离上一次更新已经过去的时长叫**年龄** $A$，则

$$E[A] = \frac{E[T_1^2]}{2\,E[T_1]} \;\ge\; \frac{\mu}{2},$$

等号只在间隔恒定时成立。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $T_i$ | 间隔 | 第 $i$ 段从上次更新到本次更新的时长，独立同分布 |
| $S_n$ | 第 $n$ 个更新点 | 前 $n$ 段间隔之和 |
| $N(t)$ | 计数过程 | 到 $t$ 为止的更新次数 |
| $m(t)$ | 更新函数 | $E[N(t)]$，平均更新次数 |
| $\mu,\ \sigma^2$ | 均值与方差 | 单个间隔的期望与方差 |
| $R_i$ | 报酬 | 每段间隔附带的收益或成本 |
| $A$ | 年龄 | 随机时刻离上一次更新过去的时长 |

## 4. 分步例题

某型号轴承的更换间隔近似在 $[1, 3]$ 天上均匀分布，即 $T \sim U(1,3)$，$\mu = 2$ 天，$\sigma^2 = \frac{(3-1)^2}{12} = \frac{1}{3}$ 天²。每次更换配件成本 80 元。

1. **长期更换速率**：套基本更新定理，$\frac{1}{\mu} = \frac{1}{2} = 0.5$ 次/天，也就是平均每两天换一次、每月约 15 次；
2. **算常数偏移**：$\dfrac{\sigma^2}{2\mu^2} - \dfrac12 = \dfrac{1/3}{2 \times 4} - \dfrac12 = \dfrac{1}{24} - \dfrac12 = -\dfrac{11}{24} \approx -0.458$；
3. **代入二阶展开**：$m(t) \approx \dfrac{t}{2} - 0.458$。取 $t=100$ 天，$m(100) \approx 50 - 0.46 = 49.54$ 次——**比朴素的 $t/\mu = 50$ 略少**，因为方差带来的修正项是负的；
4. **长期成本率**（更新报酬过程）：报酬就是更换成本 $R=80$ 元，与间隔独立，于是长期成本率 $= \dfrac{E[R]}{E[T]} = \dfrac{80}{2} = 40$ 元/天，每月约 1200 元；
5. **随机抽查的年龄**：$E[A] = \dfrac{E[T^2]}{2E[T]} = \dfrac{\mu^2+\sigma^2}{2\mu} = \dfrac{4 + 1/3}{4} \approx 1.083$ 天，**大于** $\mu/2 = 1$ 天。随手一瞥看到的机器，平均已经硬撑了 1.08 天——比"平均寿命的一半"更长。

第 5 步是检查悖论的定量版本：均匀分布的方差不算大，偏差只有 8%，但方向是确定的。间隔分布越"参差"，这个偏差越夸张。

### 实验 2（python）：亲手撞一次"长间隔"

造 3000 段 $U(1,3)$ 的间隔，然后随机撒 4000 个时刻，量它们各自落在多长的间隔里、以及"已经等了多久"：

```python
import random                     # 随机数库

random.seed(7)                    # 固定种子：每次运行看到同一批随机数
N = 3000                          # 造 3000 段间隔
times = []
s = 0.0
for i in range(N):
    s = s + random.uniform(1, 3)  # uniform(a, b)：区间 [a,b] 内均匀抽样
    times.append(s)               # 记录每个更新点
T = times[-1]                     # 观察窗总长度

span = []                         # 随机时刻所在间隔的长度
ages = []                         # 随机时刻的"年龄"
for _ in range(4000):
    x = random.uniform(0, T)      # 随机撒一个时刻
    prev = 0.0
    for t in times:               # 找到 x 之前最近的一个更新点
        if t > x:
            span.append(t - prev) # 这一段有多长
            break
        prev = t
    ages.append(x - prev)

print(round(s / N, 4))                       # 平均间隔
print(round(sum(span) / len(span), 4))       # 被撞上的间隔平均有多长
print(round(sum(ages) / len(ages), 4))       # 平均年龄
```

输出 `1.979`、`2.1628`、`1.0914`。逐行读：平均间隔约 **1.98 天**（理论值 2）；但随机时刻**撞上的那一段平均长 2.16 天**——显著大于平均间隔，因为长间隔占据的时间份额大；于是平均年龄约 **1.09 天**，**大于"平均间隔的一半"1 天**。检查悖论在数据里现形了。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为更新函数就是 $m(t) = t/\mu$。" 精确等式 $m(t) = \lambda t$ 只对指数间隔（泊松过程）成立。一般情形 $m(t)$ 会带一个常数偏移，离散间隔时甚至会有小幅振荡；更新定理保证的只是**比值** $m(t)/t \to 1/\mu$，不是逐点的线性等号。

**误区二**："你以为平均间隔 2 天，随机时刻平均就等了 1 天。" 长间隔更容易被随机时刻撞上（长度偏置），所以 $E[A] = E[T^2]/(2E[T]) \ge \mu/2$，等号只在间隔恒定时成立。你等的车总是比时刻表上的平均间隔更长——这不是运气问题，是数学必然。

**误区三**："你以为更新报酬率 = 平均报酬 × 更新速率。" 正确写法是 $\dfrac{E[R]}{E[T]}$，分子分母都是**单段**的期望，不能拆成"平均报酬 × 平均速率"。更要命的是，如果报酬与间隔**相关**（"用越久换一次越贵"），就必须用联合期望 $\dfrac{E[R]}{E[T]}$ 而不能分别取平均再相乘。

:::

## 7. 练习

**练习 1**：某种传感器的间隔只有两种可能：一半是 1 天、一半是 4 天。于是 $\mu = 2.5$ 天、$E[T^2] = 8.5$ 天²。下面的代码能跑，但把长期速率和平均年龄都算错了，修到输出 `0.4` 与 `1.7`：

```exercise
# @title: 练习：长期速率与随机时刻的年龄
# @check: 0.4
# @check: 1.7
# @hint: 长期速率 = 1/平均间隔（是倒数，不是平均间隔本身）；随机时刻的平均年龄 = E[T²]/(2E[T])，不是平均间隔的一半。
mu = 2.5                 # 平均间隔：一半 1 天、一半 4 天
sq = 8.5                 # 间隔平方的平均 E[T^2]
rate = mu                # ← 错了：长期速率应是 1/平均间隔
age = mu / 2             # ← 错了：平均年龄不是平均间隔的一半
print(round(rate, 4))
print(round(age, 4))
```

<details>
<summary>点开查看逐步解答</summary>

两处修正：

```py
rate = 1 / mu            # 0.4 次/天：基本更新定理
age = sq / (2 * mu)      # 8.5 / 5 = 1.7 天：检查悖论
print(round(rate, 4))    # 0.4
print(round(age, 4))     # 1.7
```

**速率**是平均间隔的倒数：平均 2.5 天来一次，长期就是 0.4 次/天。**年龄**用 $E[T^2]/(2E[T])$：$8.5 / (2 \times 2.5) = 1.7$ 天，比 $\mu/2 = 1.25$ 天大了近四成——因为一半的间隔长达 4 天，被随机时刻撞上的机会远多于它按时长该有的份额。间隔越参差，悖论越明显：这组分布"一半 1 天一半 4 天"，比均匀分布夸张得多。

</details>

**练习 2**：为什么更新定理的长期速率只跟平均间隔有关，而跟方差无关？请用大数定律说明：跑 $n$ 次更新用掉的时间是 $S_n$，$n$ 个更新里平均每个更新摊到多少时间？

<details>
<summary>点开查看逐步解答</summary>

$n$ 次更新消耗的总时间就是 $S_n = T_1 + \cdots + T_n$。由大数定律，$\dfrac{S_n}{n} \to E[T_1] = \mu$。于是**平均每个更新占用 $\mu$ 的时间**，反过来说单位时间内的更新次数趋近 $1/\mu$——这正是基本更新定理。

关键点在于：大数定律只认**一阶矩**（期望），方差、偏度、尾部形状全都进不了这个极限。方差出现在哪里？出现在二阶展开那个常数 $\sigma^2/(2\mu^2) - 1/2$ 里——它决定直线被平移多少，却改不了斜率。**一阶矩管速率，高阶矩管修正项**，这是概率论里反复出现的一条分工。

</details>

**趁热打铁**：

```quiz
公交发车间隔平均 10 分钟，但间隔有长有短。乘客随机到站，他平均要等的时间与 5 分钟相比如何？
- 恰好是 5 分钟
- 大于 5 分钟，因为长间隔更容易被乘客"撞上" [*]
- 小于 5 分钟
? 随机到站时刻落在哪一段间隔里，概率正比于该段长度，所以长间隔被撞上的机会更大。平均年龄（或平均等待）= E[T²]/(2E[T]) ≥ 平均间隔的一半，等号只在发车间隔完全恒定时成立。
```

## 8. 选读：更新定理为什么偏偏是 1/μ

<details>
<summary>选读 · 从夹逼到瓦尔德等式</summary>

把"到时刻 $t$ 为止发生了几次"挤在两个相邻更新点之间：

$$S_{N(t)} \le t < S_{N(t)+1}.$$

两边同除 $N(t)$：

$$\frac{S_{N(t)}}{N(t)} \le \frac{t}{N(t)} < \frac{S_{N(t)+1}}{N(t)}.$$

因为 $N(t) \to \infty$（间隔均值有限，无穷多个更新点必然铺满整条时间轴），左边由大数定律趋于 $\mu$。右边把分子分母配平一下写成 $\dfrac{S_{N(t)+1}}{N(t)+1} \cdot \dfrac{N(t)+1}{N(t)}$，第一个因子趋于 $\mu$、第二个因子趋于 1，所以右端也趋于 $\mu$。中间被夹住的 $\dfrac{t}{N(t)}$ 只能趋于 $\mu$，于是

$$\frac{N(t)}{t} \to \frac{1}{\mu}.$$

对期望取极限（需要一点一致可积性，属于技术细节）就得到 $\dfrac{m(t)}{t} \to \dfrac{1}{\mu}$。**瓦尔德等式**（$\mathbb{E}[S_{N(t)+1}] = \mu\, \mathbb{E}[N(t)+1]$）则是处理期望层面的那把钥匙，它把"随机个数的和"的期望换成"个数的期望 × 单段期望"——这也是更新报酬定理 $\dfrac{R(t)}{t} \to \dfrac{E[R]}{E[T]}$ 的同一台引擎。

顺带一句：更新报酬定理对"报酬与间隔相关"也照常成立，只要 $(R_i, T_i)$ 独立同分布。真正会在相关情形下翻车的是"分别取平均再相乘"这种偷懒写法。

</details>
