# 隐马尔可夫模型与 Viterbi 解码

## 1. 从一个场景开始

室友的真实心情你看不见，只能刷他的朋友圈：元气满满的照片，或深夜的 emo 文案。心情推动语气（状态发射观测），而心情本身遵从惯性——今天低落，明天多半还没缓过来（状态按马尔可夫链转移）。连看三天朋友圈：元气、emo、元气。问他这三天的心情到底是哪条序列？

第 35 章的编码理论里，我们至少还**知道**发出的比特是什么，只需对付信道翻转；现在连输入本身都成了谜。这类"状态藏在幕后、只放出一手带噪声的证据"的模型叫**隐马尔可夫模型**；把最可能的那条幕后序列找回来，用的工具就是本课主角 **Viterbi 算法**。

## 2. 直觉解释

给任何一条候选心情序列打分，用的是链式法则里最朴素的三连乘：

$$\text{得分}=\text{开局的底子}\times\text{逐日惯性}\times\text{逐日证据}$$

难点是分母级的组合爆炸：$N$ 种状态、$T$ 天，候选路径有 $N^T$ 条——$N=3$、$T=100$ 时就是天文数字。Viterbi 的破局口诀是动态规划那句老话：**最优路的任何前段，也是到该点为止的最优路。** 于是每天只需为每个状态记一笔"到此为止的最大得分"，再把接力棒交给明天：

- 第 $t$ 天**路过**状态 $j$ 的所有路径中，最优者的得分 $\delta_t(j)=\max_i \bigl[\delta_{t-1}(i)\cdot a_{ij}\bigr]\times b_j(o_t)$；
- 同时用回溯指针 $\psi_t(j)$ 记下"这一笔是谁传来的"；
- 走到最后一天，取 $\delta_T$ 中最大的那格，沿指针倒着走回起点。

$N^T$ 条路的战争被压缩成 $T\times N^2$ 次乘法——天数上百也照算不误。

## 3. 正式定义

一个 HMM 由三张表描述（沿用马尔可夫链的行向量约定）：

| 符号 | 名字 | 约束 |
| --- | --- | --- |
| $\pi_i$ | 初始分布 | 开局落在各隐藏状态的概率，总和为 1 |
| $a_{ij}=P(S_{t+1}=j\mid S_t=i)$ | 转移表 | **每一行之和为 1**（第一课铁律） |
| $b_j(o)=P(O_t=o\mid S_t=j)$ | 发射表 | 在状态 $j$ 下各观测值的概率，对每个 $j$ 行内和为 1 |

观测独立性假设：给定当天的隐藏状态，今天的观测与过去全部历史无关——证据的噪声来自信道，不来自阴谋。

**Viterbi 递推**（解码的最优路径问题）：

$$\delta_1(j)=\pi_j b_j(o_1),\qquad \delta_t(j)=\Bigl(\max_{1\le i\le N}\delta_{t-1}(i)\,a_{ij}\Bigr)b_j(o_t),\qquad \psi_t(j)=\arg\max_i \delta_{t-1}(i)a_{ij}$$

终点 $j^\star=\arg\max_j \delta_T(j)$ 沿 $\psi$ 回溯，得最大概率路径；它最大化的是**整条联合概率** $P(S_1,\dots,S_T,o_1,\dots,o_T)$，而不是每个位置各自最可能状态的拼接。

## 4. 分步例题

设定：心情「好 / 差」，开局 $\pi=(0.6,0.4)$；惯性极强 $a=\begin{pmatrix}0.9&0.1\\0.1&0.9\end{pmatrix}$（好→好 0.9，差→差 0.9）；发射 $b$：好心情发元气 0.65 / emo 0.35，差心情发元气 0.50 / emo 0.50。观测三天：**元气、emo、元气**。

| 第几天 | 观测 | $\delta$(好) | 来源 | $\delta$(差) | 来源 |
| --- | --- | --- | --- | --- | --- |
| 1 | 元气 | $0.6\times0.65=0.39$ | 起点 | $0.4\times0.50=0.20$ | 起点 |
| 2 | emo | $\max(0.351,0.02)\times0.35=0.12285$ | 好 | $\max(0.039,0.18)\times0.50=0.09$ | 差 |
| 3 | 元气 | $\max(0.110565,0.009)\times0.65=0.0718673$ | 好 | $\max(0.012285,0.081)\times0.50=0.0405$ | 差 |

终点上"好"以 $0.0718673$ 胜出，沿指针回溯：第三天的好来自第二天的好，第二天的好又来自第一天的好——**最可能路径是"好好好"**。

两个必看的对照。其一，只按当天发射挑状态会得到「好差好」（emo 当天发射确实偏向"差"，0.50 对 0.35）；其二，给这条贪心路径算**真正的联合概率**：$0.6\times0.65\times0.1\times0.5\times0.1\times0.65=0.0012675$，只有「好好好」$0.0718673$ 的五十六分之一。忽略惯性的解码输得毫无悬念：它凭想象免掉了两次 $\times 0.1$ 的过路费，而实际模型里那两步换乘贵得惊人。

## 5. 动手实验

### 实验 1（viz）：惯性 0.9 的分布走得多慢

正文设定里那条惯性极强的转移表（好→好 0.9、差→差 0.9）在这里上了滑块。**怎么玩**：拖 steps，从 0 开始加——组件固定从「必为好」出发（正文用的开局是 $\pi=(0.6,0.4)$，起点不同，但你看读数会发现两者最终去同一个地方）。这条链最值得看的是**慢**：因为两个状态都极恋家（0.9），质量从「好」流向「差」的速率被压得很低，拖到 steps=10 时「差」还没过 0.35，读数的距平稳偏差仍明显非零——对比上一课天气链十步就已贴住平稳分布，这正是「惯性极强」四个字的数值含义。虚线停在 $(0.5,0.5)$：转移矩阵对称，两状态对等的平稳分布，与起点无关。看懂「慢」之后再看实验 2：解码之所以必须考虑转移，就是因为这个 0.9 的过路费贵得值得建模。

### 实验 2（python）：小规模显式 DP——打表 + 回溯打印最优心情路径

```python title="小规模显式 DP：打表 + 回溯打印最优心情路径"
states = ["好", "差"]
start = [0.6, 0.4]
A = [[0.9, 0.1],                 # 转移表 A[i][j] = 昨天状态 i -> 今天状态 j
     [0.1, 0.9]]
B = [[0.65, 0.35],               # 发射表 B[j][o] = 状态 j 下发元气的概率 / 发 emo 的概率
     [0.50, 0.50]]
obs = [0, 1, 0]                  # 三天朋友圈：0 = 元气，1 = emo

delta = [start[i] * B[i][obs[0]] for i in range(2)]   # 第一天的开局分：先验 × 发射
prev = [[None, None] for t in range(len(obs))]        # prev[t][j]：第 t 天到达 j 的最优来源

for t in range(1, len(obs)):
    nxt = [0.0, 0.0]
    for j in range(2):
        best_i = 0                        # 记录"谁传来"最优
        best_v = 0.0
        for i in range(2):
            v = delta[i] * A[i][j]        # 前一天的分会乘上转移概率——一处都不能省
            if v > best_v:
                best_v = v
                best_i = i
        nxt[j] = best_v * B[j][obs[t]]    # 再过一遍当天的发射（信道）
        prev[t][j] = best_i
    delta = nxt
    print(f"第 {t + 1} 天得分：好={round(nxt[0], 4)} 差={round(nxt[1], 4)}")

last = 0 if delta[0] > delta[1] else 1
path_idx = [0] * len(obs)
path_idx[-1] = last                     # 终点先用胜者占住
for t in range(len(obs) - 1, 0, -1):    # 沿指针一步步往回走
    path_idx[t - 1] = prev[t][path_idx[t]]

route = ""                              # 字符串累加拼出路径名
for j in path_idx:
    route = route + states[j]
print(route)
print(round(delta[last], 6))
```

运行输出逐步得分 `0.1229 / 0.09` 与 `0.0719 / 0.0405`，最终打印路径 `好好好`、概率 `0.071867`。你可以把中间的某天观测改掉重跑，观察指针如何当场改判；也可以把起点换成 $(0.01,0.99)$，看看强惯性如何在一两天内扳回局面。

## 6. 常见误区

:::warning[常见误区]

- **"转移表随便填，反正是近似。"** 行和不满 1 的表程序照样跑、照样吐"漂亮"答案——这是静默错误。每处乘上的 $a_{ij}$ 是跨不同来源比较的分水岭，差之毫厘，回溯路径面目全非。动手前先按行求和自检。
- **"每天选发射概率最大的状态就行。"** 这是对三连乘的整体最优放弃了后两项：「好差好」就是这么诞生的。上下文的惯性项恰恰在弱证据日定乾坤。
- **"Viterbi 找到的是每天的真相。"** 它找的是**一整条联合概率最大的路径**，不是每个位置各自的后验众数；也不给出该路径的置信度。要软答案需要前向—后向算法，那是另一门课的故事。

:::

## 8. 选读：为什么贪心等不来全局最优

<details>
<summary>选读 · 一枚被贪心吞掉的金牌</summary>

最诱人的偷懒方案："每个格子反正只留最大的一条来源，那干脆每天全局只养一条最好的队。"不行，两者层次不同。Viterbi 的守则是**每格各留一条最优来源**——$N$ 条 lane 全程在场；一旦把裁员扩大成"全表只保当前的领头羊"，就会输给被暂时低估的分支。举一个两状态的迷你局：某天收工时两条 lane 的得分是 $\delta=(10,\ 9)$，明天只有一个目标状态 $x$ 可去，「二」来的转移概率是 1.0、「一」来的只有 0.5。若当场枪毙「二」，终极得分至多 $10\times0.5=5$；留着它就是 $9\times1.0=9$。落后一名的选手携带的**换乘优势**随时可以反超——所以一张都不能裁。这套"全员在场、终点裁决"的策略由安德鲁·维特比于 1967 年为卷积码译码提出，后来横扫语音识别、基因测序与输入法联想引擎；训练三张表的期望最大化版本叫 Baum-Welch 算法——真实世界里 HMM 常常连参数都要边听边猜。

</details>
