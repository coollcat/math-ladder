# 平稳分布与遍历性

## 1. 从一个场景开始

共享单车公司在每个街区投放车辆。单车的每一次骑行完全随机，可运营几个月后，各街区的**车辆占比**稳定得像刻在石头上——A 区永远约占三成。随机运动怎么会沉淀出固定比例？

答案是马尔可夫链理论的核心景观：对一大类链（包括前面两课的天气链），无论从哪个状态出发、走过多曲折的路，状态分布都会收敛到同一个向量 $\pi$。它叫**平稳分布**——时间尽头的不动点，也是"Google 怎么给网页打分"的数学起点。

## 2. 直觉解释

"平稳"的日常版是**收支平衡**：一个城市每天有人流入流出，若流入率恰好等于流出率，人口结构纹丝不动。把"城市"换成"状态"，把人流换成概率流：

- 状态 $i$ 的流出：$\pi_i\times$(从 i 出发的全部概率)，合计恰为 $\pi_i$；
- 状态 $i$ 的流入：所有邻居按各自概率汇入的总量。

两者相等时，分布 $\pi$ 穿过矩阵一步后分毫不变：

$$\pi P=\pi$$

而**遍历性**说的是更神奇的事：不需要真的让无穷多粒子同时跑——只放一只蚂蚁跑足够久，它路过各状态的**时间占比**就收敛到 $\pi$。空间上的全体平均（分布收敛）与时间上的长期平均（频率占比）给出同一个答案，这是随机世界版的"一生足够长就能尝遍人生百态"。

## 3. 正式定义

**平稳分布**：行向量 $\pi=(\pi_1,\dots,\pi_N)$ 满足

$$\pi P=\pi, \qquad \sum_i\pi_i=1, \qquad \pi_i\ge0$$

**遍历性定理**：有限链若**不可约**（任何状态都能到达任何状态）且**非周期**（不存在只能按固定间隔回访的状态），则对任意初始分布 $p_0$，

$$p_0P^n\xrightarrow{\;n\to\infty\;}\pi \qquad \text{且} \qquad \frac{1}{T}\sum_{t=1}^{T}\mathbf{1}\lbrace X_t=i\rbrace\xrightarrow{\;} \pi_i$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\pi P=\pi$ | 不动点方程 | 概率流进=流出；解出 π 还要归一化 |
| 不可约 | 全连通 | 图上任意两点互相可达，没有"死区" |
| 非周期 | 无节拍锁 | 回访某状态的步长不全是某个 d>0 的倍数 |
| 时间平均 | 遍历性右式 | 一条轨迹上停留占比的极限 |

两条守门条件缺一不可：上一课的双向开关链不可约却周期为 2，永不收敛；带吸收态的链不可约性破产，会卡在终点站。下一课专门处理那些"卡住"的链。

## 4. 分步例题

**例**：解天气链 $P=\begin{pmatrix}0.8 & 0.2\\ 0.5 & 0.5\end{pmatrix}$ 的平稳分布。

1. 写不动点方程第一行：$\pi_1=\pi_1\times0.8+\pi_2\times0.5$；
2. 移项整理：$\pi_1\times0.2=\pi_2\times0.5$，即 $\pi_2=\frac{2}{5}\pi_1$——**流出=流入**的平衡比例；
3. 补归一化：$\pi_1+\pi_2=1$，代入得 $\pi_1\times(1+\frac{2}{5})=1$；
4. 解出：$\pi_1=\frac{5}{7}\approx0.7143,\quad \pi_2=\frac{2}{7}\approx0.2857$；
5. 回收伏笔：10 课模拟里的"神秘占比"、实验图里橙色虚线的位置，全部对上了 ✓。

技巧提示：$N$ 个状态的不动点方程只有 $N-1$ 条独立（归一化顶替了多余的一条），所以永远用"方程组 + 求和为 1"联立。

### 实验 1（viz）：收敛到 π 是什么样子

### 实验 2（python）：幂迭代——不用解方程也能找到 π

```python title="从任意分布出发，反复乘 P 直到不动"
# sliders: steps=30 [1:60:1]
import matplotlib.pyplot as plt

P = [[0.8, 0.2], [0.5, 0.5]]
p = [0.05, 0.95]                   # 故意从一个很偏的初始分布出发

track = []                         # 记录每一步的 pi1 估值
for t in range(steps):
    track.append(p[0])
    p = [p[0] * P[0][0] + p[1] * P[1][0], p[0] * P[0][1] + p[1] * P[1][1]]

plt.plot(range(steps), track, color="steelblue")
plt.axhline(5 / 7, color="tomato", linestyle="--")
plt.xlabel("iteration")
print(f"{steps} 步后分布 ≈ {[round(v, 4) for v in p]}")
print(f"理论平稳分布 = {[round(5/7, 4), round(2/7, 4)]}")
```

不管初始点选在哪，蓝线都被吸向同一条橙色虚线——这就是收敛到平稳分布的全过程。这套"反复乘矩阵"的朴素算法有个正式名字：**幂迭代**（power method），PageRank 的引擎就是它。

### 实验 3（python）：一只蚂蚁的时间占比 vs 理论值

```python title="遍历性的蒙特卡洛验证：单条轨迹的停留占比"
import random

P_row = {0: [(0, 0.8), (1, 0.2)], 1: [(0, 0.5), (1, 0.5)]}   # 字典存出边：(目标, 概率)

state = 1                          # 从雨天出发
visits = [0, 0]                    # visits[i] 数状态 i 被访问的次数
for t in range(200000):
    visits[state] = visits[state] + 1
    r = random.random()
    acc = 0.0                      # 按累积概率选下一站：轮盘赌选择法
    for nxt, prob in P_row[state]:
        acc = acc + prob
        if r < acc:
            state = nxt
            break

print(f"晴天时间占比 = {round(visits[0] / 200000, 4)}")
print(f"理论值 5/7   = {round(5 / 7, 4)}")
```

一条轨迹、两种状态、二十万步：时间占比咬住 $\frac{5}{7}$。空间平均与时间平均在此合流——遍历性从定理变成了可以亲手复现的事实。

### 快问快答

```quiz
双向开关链 P=[[0,1],[1,0]]（每步必换房间）有满足 pi·P=pi 且分量和为 1 的解吗？
- 有，就是 (0.5, 0.5) [*]
- 没有
- 要看初始分布在哪
? 代入检查：pi·P=(pi2, pi1)，令其等于自身得 pi1=pi2=0.5，所以平稳解存在。但这条周期链不收敛到它——粒子永在两屋间摇摆。“存在”与“会到达”是两道关卡，非周期条件正是在这里把关。
```

:::warning[常见误区]

**误区一**："你以为 $\pi_i$ 是'第 i 天系统在 i 的概率'。" 它与具体日期无关：$\pi$ 是 $n\to\infty$ 时分布的归宿，也可以解读为长期时间占比。问"明天会不会下雨"请用 $p_tP$，问"长期雨季占几成"才轮到 $\pi$。

**误区二**："你以为解出 $\pi P=\pi$ 就万事大吉。" 不动点方程可能有很多解（吸收链有一整族），也可能存在却不被到达（上面的开关链）。"存在"、"唯一"、"可达"是三个独立关卡，遍历性定理一次打包的是全部三条。

**误区三**："你以为时间平均很快贴近 $\pi$。" 收敛速度由链的"混合快慢"决定：状态多、转移粘滞的链（比如洗牌问题）可能要几千几万步才混匀。蒙特卡洛估 π 时样本不够就开始下结论，量到的只是没混匀的暂态偏差。

:::

**练习 2**：证明"若 $\pi$ 是平稳分布且初始分布恰好取 $\pi$，则此后每一天的分布都是 $\pi$"。

<details>
<summary>点开查看逐步解答</summary>

归纳即可：第 0 天分布为 $\pi$；若第 $t$ 天分布为 $\pi$，则第 $t{+}1$ 天分布为 $\pi P=\pi$（不动点定义）。于是恒为 $\pi$。

这解释了名字里"平稳"二字的分量：它不仅是极限，还是一条**永不变形的驻波**——把整个系统初始化在 $\pi$ 上，随机性照常运转，宏观比例却凝固成雕像。
</details>

## 7. 选读：π 藏着特征值 1

<details>
<summary>选读 · 把不动点方程翻译成线性代数</summary>

把 $\pi P=\pi$ 转置成列向量语言：$P^\top\pi^\top=\pi^\top$——平稳分布正是转置矩阵**特征值 1 对应的特征向量**（再补归一化）。这不是巧合而是必然：行随机的 $P$ 必有 $P\mathbf{1}=\mathbf{1}$，转置后 1 成为 $P^\top$ 的特征值（Perron-Frobenius 定理保证它在谱半径位置）。

第 21 章高等线性代数的 [对角化一课](../21-linear-algebra-advanced/100-diagonalization.md) 讲过"矩阵幂由特征结构主导"；现在可以看懂它的概率版了：$P^n=\pi\mathbf{1}^\top+(\text{衰减项})$，衰减速度由第二大特征值的模掌管——20 课实验里"两行之差指数归零"，衰的就是那个分量。PageRank 把这个特征向量算到了千亿网页的规模，那是本章最后一课的故事。
</details>
