# 多步转移与 Chapman-Kolmogorov

## 1. 从一个场景开始

保险公司问精算师："30 天后仍在运营的客户还剩几成？"一天一天乘矩阵要乘三十轮。精算师微微一笑：让矩阵自己开平方、开立方——**两步转移概率不必走两步，一步算到位**。

这背后是随机过程里最优雅的恒等式：想从 $i$ 走到 $j$（比如走 $m+n$ 步），无论中途在哪个状态 $k$ 停留，把经过各个 $k$ 的路线概率加起来就是总概率。路径求和——这个思想日后会以无数种面目重现：费曼路径积分、隐马尔可夫的前向算法，都是它的远房子孙。

## 2. 直觉解释

走两步的所有路线可以画成一棵分叉树。以天气链为例，"今天晴 → 后天晴"有两条路线：

- 晴 → 晴 → 晴：$0.8\times0.8=0.64$
- 晴 → 雨 → 晴：$0.2\times0.5=0.10$

两条互斥，相加得 $0.74$——恰好是上一课 $p_2$ 的第一个分量！这不是巧合：**分布演化与多步转移是同一件事的两种记账法**。把全部路线的求和过程交给矩阵乘法自动完成，就得到矩阵幂 $P^2$。

下面的网页组件把这个过程做成了沙盘：调两个转移参数、拉大步数 $k$，看柱子如何被"折叠"到同一个终点。

## 3. 正式定义

记 $p_{ij}^{(n)}=P(X_{t+n}=j\mid X_t=i)$ 为 $n$ 步转移概率，其排成的矩阵即 $P^n$。

**Chapman-Kolmogorov 方程**：对任意 $m,n\ge1$ 与一切状态 $i,j$，

$$p_{ij}^{(m+n)}=\sum_{k}p_{ik}^{(m)}\,p_{kj}^{(n)} \qquad (\text{矩阵语言：} P^{m+n}=P^m P^n)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p_{ij}^{(n)}$ | n 步转移概率 | 从 i 出发恰走 n 步落在 j 的条件概率 |
| $\sum_k$ | 对中途站求和 | 全体可能的 m 步中转点，互斥故相加 |
| $P^n$ | 矩阵幂 | 同一转移矩阵自乘 n 次；行=起点，列=终点 |

推论一览：$P^0=I$（原地不动）；$P^{m+n}=P^mP^n=P^nP^m$（同一矩阵的自乘可交换）；于是 $p_t=p_0P^t$——**整条时间线被一次矩阵幂打包**。

## 4. 分步例题

**例**：天气链 $P=\begin{pmatrix}0.8 & 0.2\\ 0.5 & 0.5\end{pmatrix}$，手算 $P^2$ 并读出"雨天出发两天后转晴"的概率。

1. 写出目标分量：$(P^2)_{21}$ = 第二行第一列 = 雨→(晴或雨)→晴；
2. 列路线：雨→晴→晴 概率 $0.5\times0.8=0.40$；雨→雨→晴 概率 $0.5\times0.5=0.25$；
3. 相加：$0.40+0.25=0.65$；
4. 全矩阵同法（每个格子都做一遍路线求和）：

$$P^2=\begin{pmatrix}0.74 & 0.26\\ 0.65 & 0.35\end{pmatrix}$$

5. 自查：每行之和仍为 1 ✓（行随机的矩阵自乘后依然行随机——这不是巧合，是 C-K 方程的直接推论）。再注意新信息：不管今天晴还是雨，**两天后**晴的概率都在 0.65 到 0.74 之间——起点的影响正在衰减。

### 实验 2（python）：亲手实现矩阵幂并观察收敛

```python title="循环自乘：P 的幂次如何冻结成每行相同"
import matplotlib.pyplot as plt

P = [[0.8, 0.2], [0.5, 0.5]]

def matmul(A, B):                      # 2x2 矩阵乘法：行乘列再求和
    return [[A[i][0] * B[0][j] + A[i][1] * B[1][j] for j in range(2)] for i in range(2)]

M = [[1.0, 0.0], [0.0, 1.0]]           # 从单位阵开始，连乘 P 十次
row_diffs = []                         # 记录每次乘完后"两行之差"，看它如何归零
for step in range(10):
    M = matmul(M, P)
    row_diffs.append(abs(M[0][0] - M[1][0]))

plt.plot(range(1, 11), row_diffs, marker="o", color="steelblue")
plt.xlabel("power k")
plt.ylabel("row1 − row2 (first entry)")
print(f"P^10 第一行: {[round(v, 4) for v in M[0]]}")
print(f"P^10 第二行: {[round(v, 4) for v in M[1]]}")
```

两行之差按几何速度奔向零：$P^k$ 的每一行都冻结到同一行向量——它就是平稳分布 $(\frac{5}{7},\frac{2}{7})$ 的近似值。"行差归零"与"分布收敛"从此可以互相翻译。

### 快问快答

```quiz
关于矩阵幂 P^(m+n)，下面哪条等式成立？
- P^(m+n) = P^m · P^n，且顺序可以交换 [*]
- P^(m+n) = P^m + P^n
- P^(m+n) 只能用逐日模拟得到
? 同一个矩阵自乘满足交换律 P^m·P^n = P^n·P^m；但一般的两张不同矩阵相乘没有这份福利——顺序代表时间的先后。
```

:::warning[常见误区]

**误区一**："你以为 $n$ 步转移概率等于单步概率的 $n$ 次方。" 那只对"原地站岗"成立。正确关系是整座矩阵的 $n$ 次幂：$P^n$ 的每个分量都由路径求和而来，混合了所有中途可能。

**误区二**："你以为矩阵乘法可以随便换序。" $AB\ne BA$ 是常态；在马尔可夫语境里顺序就是时间：先乘 $P_1$ 再乘 $P_2$ 表示规则在半路发生了更换（非齐次链）。本课能写 $P^n$ 全靠"每天规则相同"这一前提。

**误区三**："你以为 $P^k$ 收敛是理所当然。" 反例现成：$P=\begin{pmatrix}0&1\\1&0\end{pmatrix}$ 是完美的双向开关，$P^k$ 在 $I$ 和 $P$ 之间永远摇摆——粒子在两个房间之间来回踱步，分布从不落定。收敛需要额外条件（不可约 + 非周期），这正是下一课的主角。

:::

**练习 1**：接着例题算"雨天出发两天后仍在下雨"。初始代码偷懒直接抄了单步概率：

```exercise
# @title: 练习：两天后还在下雨吗
# @check: [0.65, 0.35]
# @hint: 第二行两个分量各走一遍 C-K：到晴 = 0.5*0.8 + 0.5*0.5；到雨 = 0.5*0.2 + 0.5*0.5；装进列表打印
P_row_rain = [0.5, 0.5]              # ← 这是"一天"的去向，不是"两天"的
print(P_row_rain)
```

期望输出是完整的两天转移行 `[0.65, 0.35]`（列表打印格式照抄方括号与逗号空格）。修好后对照：两天后"仍在下雨"只有 0.35，比单步的 0.5 低了一截——雨天的宿命也在被链条稀释。

**练习 2**：三态电梯链（40 课末尾那张矩阵）里，从一层出发两层后到三层的概率是多少？

<details>
<summary>点开查看逐步解答</summary>

列路线：一层→二层→三层 概率 $0.3\times0.5=0.15$；其余路线（经留层或直达）要么为 0 要么不达三层。等等，还要查一层→一层→三层：$0.7\times0=0$；一层→三层→三层：$0\times0.6=0$。合计 $0.15$。

顺手验证 C-K 的矩阵版：$(P^2)_{13}=p_{11}p_{13}+p_{12}p_{23}+p_{13}p_{33}=0.7\times0+0.3\times0.5+0\times0.6=0.15$ ✓。零元素让路线树大幅剪枝——稀疏矩阵是计算者的好朋友。
</details>

## 7. 选读：图上的路径计数——整数版的 C-K

<details>
<summary>选读 · 当概率退化为 0/1，矩阵幂变成数路条</summary>

把转移概率全换成 0 或 1（有边记 1 无边记 0），转移矩阵就成了图的邻接矩阵 $A$。此时 $(A^n)_{ij}$ 不再是概率而是**恰好走 n 步从 i 到 j 的路线条数**——C-K 方程退化成朴素的组合事实："n 步路线 = 中途站枚举后首尾拼接"。

第 29 章《图论》 adjacency-algebra 一课已经埋过这条伏笔；马尔可夫链不过是给每条边涂上概率灰度后的连续版本。整数世界与概率世界共用一套代数骨架——这是线性代数横跨两个大陆的又一次胜利。想看它在排名算法里的终极形态？本章最后一课 PageRank 见。
</details>
