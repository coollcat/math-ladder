# 鞅直觉：公平游戏的账本

## 1. 从一个场景开始

赌桌上，朋友连输三局，把筹码一推："都连输三把了，下一把总该轮到我赢了吧？"——这句话是全世界赌徒的共同信仰，也是概率论反复没收的伪钞。真正的问题可以问得更精确：**给定你现在手里的一切信息，你财富明天的期望值是多少？**

如果游戏公平，答案出奇地平淡：**正好等于你现在的财富**。不因为连输而更高，也不因为连胜而更高。这个"下一步的条件期望等于当前值"的性质，就是随机分析的核心概念——**鞅**。它是一台期望守恒仪：无论路径怎么翻腾，条件期望的账本分文不动。

## 2. 直觉解释

**核心类比：公平游戏的账本只记现在，不记恩怨。**

想象一个会计，每晚给你算一条记录："按目前所知，你明天的期望身家是多少？"公平骰局里这个数字永远等于今晚的实际身家：

- 身家 100 元时记账"明日预期：100 元"；
- 连输三把跌到 97 元？账本冷冰冰改写"明日预期：97 元"——历史的亏损已经结清，不会预支任何补偿；
- 好运连击涨到 103 元？"明日预期：103 元"，凭过去三连胜也讨不到一分溢价。

**账本永不系统性上翘或下垂，这就是公平的全部数学含义。** 赌徒谬误在此现出原形：它假设账本会"找平"过去——可硬币没有记忆（第 37 章泊松课刚讲过无记忆性），第 $n$ 次投掷根本不知道前 $n-1$ 次的结果。会找平的是**频率**（大数定律管长期占比），不是**你的钱包**。

## 3. 正式定义

设 $\lbrace X_t\rbrace$ 刻画你的财富，$\mathcal{F}_t$ 表示"截至时刻 $t$ 的全部历史信息"。若对一切 $t$：

$$E[X_{t+1}\mid \mathcal{F}_t]=X_t$$

则称 $\lbrace X_t\rbrace$（关于这股信息流）是一个**鞅**。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mathcal{F}_t$ | 信息流 | 到此刻为止你知道的一切（输赢历史、掷出的点数……） |
| $E[X_{t+1}\mid\mathcal{F}_t]$ | 条件期望 | 拿着全部历史重新称量的"明天均值" |
| 鞅 | 公平游戏 | 明天的条件期望恰好等于今天 |
| **上鞅** | 庄家占优 | $E[X_{t+1}\mid\mathcal{F}_t]\le X_t$：账本只会往下写，比如抽水的赌场 |
| **下鞅** | 你占优 | $E[X_{t+1}\mid\mathcal{F}_t]\ge X_t$：账本只会往上写 |

记忆钩子：**上鞅往下漏**（水管在上游漏水）。公式的读法也值得停一秒——条件期望不是单一数字，而是"随历史变化的计算器"：同样问明天的均值，拿到不同历史，得到不同的数字；鞅说的是这串数字恰好逐格对齐今天的实际值。这台计算器已在[第 36 章的条件期望一课](../36-probability-advanced/42-conditional-expectation.md)领到正式户口。

## 4. 分步例题

**例**：你在玩押大小，每局筹码变动 $\pm b$（下注额自选 $b$），公平概率各半。当前身家 $W=30$ 元，此前连输四局。

1. 无论你怎么分析过往的四连败，下一局的输赢仍是各半——硬币不知道你的惨史；
2. 设下一局后身家为 $W'$：若胜则 $W'=30+b$，若负则 $W'=30-b$；
3. 按全部历史做条件平均：$E[W'\mid\text{历史}]=\frac12(30+b)+\frac12(30-b)=30$；
4. **加注也救不了**：$b$ 从上下式子里干净地消失了——你能自由选择的是波动的**幅度**，不是期望的**方向**。想靠改变下注额扭转期望，在鞅的世界里按定义就是徒劳。

顺手验证概念的方向感：换成庄家抽水 5%（净变动 $+0.95b$ 或 $-b$），则条件期望变为 $\frac12(29.85+... )<W$ 的形式——账本开始每期向下渗一点，财富过程从鞅降级成**上鞅**。真实赌场的长期宿命，两个词就说完了。

## 5. 动手实验

### 实验 1（python）：十条财富曲线与一条不肯动的红线

```python title="公平游戏：个体的狂野漂移 vs 集体的冻结均值"
# sliders: paths=10 [2:20:1]
import random                     # 随机库（第 0 章登场）
import matplotlib.pyplot as plt   # 绘图模块起短名 plt

random.seed(7)                    # 固定随机种子：人人看到同一片森林
steps = 100                       # 玩 100 局
initial = 100.0                   # 开局本金 100 元

rows = []                         # rows[k] 存第 k 位玩家的完整身家曲线
for k in range(paths):
    wealth = initial
    route = [initial]
    for t in range(steps):
        change = +1 if random.random() < 0.5 else -1   # 每局 ±1 元，各半
        wealth = wealth + change
        route.append(wealth)
    rows.append(route)
    plt.plot(route, linewidth=0.8)

line = []                         # 红线：同一时刻全体玩家的平均身家
for t in range(steps + 1):
    s = 0.0
    for k in range(paths):
        s = s + rows[k][t]
    line.append(s / paths)
plt.plot(line, color="red", linewidth=2.5)
print(round(line[steps], 3))      # 期末的平均身家——请对照起点 100
```

种子 7、十条路下的终点均值为 `101.9`——离开起点不到 2%，而个体终点早已四散奔逃（上限冲到 160 一带，也有玩家跌破 50）。红线被钉死在起点附近，正是鞅性质"集体层面零趋势"的可视化：**期望纹丝不动与个体动荡并不矛盾**，方差在膨胀而已。

### 实验 2（python）：给庄家 4% 抽水，看红线跪下去

```python title="不公平游戏：上鞅的平均线缓缓下沉"
import random
import matplotlib.pyplot as plt

random.seed(7)
steps = 100
paths = 200                       # 抽水很细，多雇些玩家才看得清趋势

sums = [0.0] * (steps + 1)        # 各时刻所有玩家身家的累计和
for k in range(paths):
    wealth = 100.0
    sums[0] = sums[0] + wealth
    for t in range(1, steps + 1):
        if random.random() < 0.48:            # 胜率只剩 48%
            wealth = wealth + 1               # 输了全是自己的钱…
        else:
            wealth = wealth - 1
        sums[t] = sums[t] + wealth

avg_line = []                     # 平均身家线
for t in range(steps + 1):
    avg_line.append(sums[t] / paths)
plt.plot(avg_line, color="red", linewidth=2.5)
plt.axhline(100, color="gray", linestyle="--")
print(round(avg_line[steps], 2))
```

打印 `96.35`：两百位玩家的人均身家一路阴跌约 4%——恰好接近每局 $-0.04$ 元抽水累计一百局的理论侵蚀量。灰虚线标着公平水位，红线再也无法靠近它。这一图胜过十句劝告：**别指望长期玩能"磨平"庄家优势，上鞅的时间越长，账本越低。**

## 6. 常见误区

:::warning[常见误区]

- **"连输这么多把，该轮到我了。"** 每局的条件期望永远锚定现在的身家，历史输赢既不欠你也不保佑你。赌徒谬误错在把"频率会回归"偷换成了"下个结果该补偿我"。
- **"只要期望为零，长期玩就不亏。"** 期望守恒指的是**条件均值**，不代表你的钱包原地踏步：波动让财富向两端扩散，一旦撞上"破产离场"或"见好就收"这类边界，游戏的对称性就被打破（详见选读）。
- **"鞅就是说序列均值不变。"** 平移到统计口径上：收敛或稳定的是条件期望这条**预报线**，不是 $X_t$ 本身的取值分布——单条路径可以一路上扬或一路下沉，只是"事先猜它怎么走"的最优猜测永远是当前值。

:::

## 7. 练习

某骰局规则：掷一颗骰子，出 6 点你赢 3 元，其余点数输 1 元。初始代码能跑但把这笔账算成了赚钱生意——修到两条检查全部通过：

```exercise
# @title: 这张赌桌是鞅吗
# @check: -0.3333
# @check: 上鞅
# @hint: 六个面等权：3×(1/6) 与 (−1)×(5/6)；单期期望若小于 0，财富的条件期望就压在当前值下面
win_amt = 3          # 出 6 号面的进账
lose_amt = 1         # 其余五个面的损失

ev = (win_amt + (-lose_amt)) / 2    # ← 两项加起来除以几？六个面有同等的发言权吗
verdict = "下鞅"                     # ← 方向词典复查一遍：ev≤0 对应哪一类？

print(round(ev, 4))
print(verdict)
```

<details>
<summary>点开查看逐步解答</summary>

六种等可能结果，权重各 $1/6$：

```python
ev = win_amt / 6 + (-lose_amt) * (5 / 6)   # = 0.5 − 0.8333… ≈ −0.3333
verdict = "上鞅"                            # 单期期望 −1/3 < 0 ⇒ 条件期望 ≤ 当前值
```

打印 `-0.3333` 与 `上鞅`。直觉版：每六局里大约五局都在掏一元、只有一局收回三元，人均每局亏损三分之一元——这正是"轮流坐庄也逃不过抽水"的骰子版本。方向词典再背一遍：期望向上爬是**下**鞅（账本只会往上写），向下渗是**上**鞅。名字反直觉，数值不骗人。

</details>

再来一道概念题：

```quiz
一枚公平硬币已连续抛出 5 次反面。按鞅的视角，第 6 次开出正面的概率是多少？
- 大于二分之一，物极必反
- 小于二分之一，反面手气正旺
- 恰好二分之一 [*]
? 每次投掷互相独立，历史连败只改变了"你"的情绪，不改变硬币的物理。若这游戏押的是你的身家，那么无论押多少、连输多少，下一刻身家的条件期望仍等于现在。
```

## 8. 选读：加倍下注为什么救不了上鞅

<details>
<summary>选读 · 可选停止定理的一瞥</summary>

著名的马丁格尔策略宣称能必胜：每次输掉就把注码翻倍，直到终于赢一把，"所有亏损连本带利一次收回"。用鞅语言当场拆穿：公平局面下无论采用什么下注规则（哪怕以过去的输赢为条件），任意**预先约定好的停止时刻**上的资金条件期望仍等于初始本金——这叫可选停止定理的思想雏形。加倍策略的诡计在于偷偷违约：它的"必胜"依赖两个无界前提——无限的本金和无上限的允许注额；现实中赌场限红与个人破产构成吸收壁（回想第 40 课赌徒破产的局面：有限资金对上游鞅，归零只是时间问题），理论上的翻盘窗口在实践中注定先撞墙。

数学上行文的下一步是把"何时停"精确化并升级成停时定理与 Doob 分解，由此长出随机积分与金融中无套利定价的第一性原理——那支笔会在随机分析卷正式落下；本课你只需带走一句话：**公平世界的账本，只对你此刻的身份负责。**

</details>
