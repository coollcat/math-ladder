# 时间序列与平稳性

## 1. 从一个场景开始

心电监护仪敢向医生承诺："过去一分钟的心跳规律，下一分钟大概率还适用。"可没有医生会拿婴儿第一年的身高增速去预测他二十岁的身高。同样是按时间排队的数字，为什么一类可以用历史推断未来，另一类就纯属自欺？

差别藏在一个词里：**平稳**。婴儿身高带着一路向上的趋势，统计规律本身在漂移；心跳围绕固定水平小幅抖动，规律稳如老狗。本课给"规律不漂移"这件事定出精确标准——它是用历史数据建模未来的地基，地基不稳，后续一切预测都是沙上筑塔。

## 2. 直觉解释

**核心类比：浪与潮位。**

海面的每一道浪都高矮不一，但整片海的"性格"——平均水位、浪高的量级、前后两秒浪的相关劲头——今天和昨天没什么两样。**平稳序列就是永远在原地拍打的浪**：单看每时每刻都不同，统计性格恒定。而潮位上涨的日子，水位整体在爬坡，用上午的均值估计下午就会系统性偏低——这就是**非平稳**。

把"性格"拆成三问，就是下面正式定义的三条：

1. 平均水平会不会漂？（涨潮？）
2. 波动的幅度会不会变大变小？（风浪渐起？）
3. 相隔一段时间的两个浪头，牵手的劲头是否只看间隔、不看日期？（早八点的浪和早九点的浪，关系规则一样吗？）

三条全过，才配叫（弱）平稳。

## 3. 正式定义

对时间序列 $\lbrace X_t\rbrace$，称其为**弱平稳**（协方差平稳），若：

$$E[X_t]=\mu\ (\text{与 } t \text{ 无关}),\qquad \mathrm{Var}(X_t)=\sigma^2<\infty\ (\text{与 } t \text{ 无关}),\qquad \mathrm{Cov}(X_t,X_{t+\tau})=\gamma(\tau)\ (\text{只依赖间隔 } \tau)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mu$ | 常数均值 | 整条序列绕着同一根水平线抖动 |
| $\sigma^2$ | 常数方差 | 抖动的力量规格不随时间升级 |
| $\tau$ | 滞后 | 两格读数相隔的距离 |
| $\gamma(\tau)$ | 自协方差 | "隔 τ 步牵手"的强度，只由间隔决定 |

第三条是灵魂：它说的是序列的"相关结构"有统一的时间汇率——周一与周二的挂钩方式，等于周三与周四的挂钩方式。

先拆掉一个撞名现场：第 30 课的**平稳分布** $\pi P=\pi$ 说的是马尔可夫链状态占比的长期不动点；本课的平稳说的是**序列自身的统计规律沿时间轴不变**。前者是终点站的客流比例，后者是列车运行图的稳定班次——两件事都要紧，别混为一谈。（更强的"严平稳"要求任意维分布整体搬移不变，弱平稳只在均值方差与二阶结构的层面要求，实用建模通常从弱平稳起步。）

## 4. 分步例题

目测判断不了，就动手切账：把序列从中间切两半，分别算前半段与后半段的均值和波动量（波动量取平方偏差的平均；为省事分母不减一，与第 09 章的样本方差口径略有出入，不影响比较）。四段小样如下。

| 序列 | 数据 | 前半均值 / 后半均值 | 前半波动 / 后半波动 | 裁决 |
| --- | --- | --- | --- | --- |
| A | $2,4,2,4$ | $3$ 与 $3$ | $1$ 与 $1$ | 三问全过 → 平稳范本 |
| B | $1,2,3,4$ | $1.5$ 与 $3.5$ | $0.25$ 与 $0.25$ | 均值劈叉 → 非平稳 |
| C | $1,2,1,9$ | $1$ 与 $5$ | $0$ 与 $16$ | 波动爆表 → 非平稳 |

三个教训一次集齐：B 型序列**波动规规矩矩却照样非平稳**（光盯波动会漏抓漂移）；C 型序列均值看着还行，振幅却在指数起飞；只有 A 型这种"围绕同一水平、同等力度抖动"的序列，才敢拿过去说未来。

## 5. 动手实验

```python title="三种序列的分期体检：白噪声 / 线性趋势 / 随机游走"
import random                     # 随机库（第 0 章登场）
import matplotlib.pyplot as plt   # 绘图模块起短名 plt

random.seed(42)                   # 固定随机种子：人人都长出同一条曲线
n = 120                           # 每条序列的长度

white = []                        # 白噪声：每天独立掷硬币决定 ±半格
for t in range(n):
    coin = 1 if random.random() < 0.5 else -1
    white.append(coin * 0.5)

trend = []                        # 趋势序列：每天固定上涨 0.05，再叠一点噪声
for t in range(n):
    wobble = random.random() - 0.5
    trend.append(t * 0.05 + wobble)

walk = []                         # 随机游走：今天的值 = 昨天的值 + 新噪声
w = 0.0
for t in range(n):
    w = w + (random.random() - 0.5)
    walk.append(w)

def mean(xs):
    return sum(xs) / len(xs)

def fluct(xs):                    # 波动量：平方离均差的平均
    m = mean(xs)
    acc = 0.0
    for x in xs:
        acc = acc + (x - m) ** 2
    return acc / len(xs)

half = n // 2                     # 整数除法：前半段的长度
for name, xs in [("白噪声", white), ("趋势线", trend), ("随机游走", walk)]:
    print(name,
          round(mean(xs[:half]), 2), round(mean(xs[half:]), 2),
          round(fluct(xs[:half]), 3), round(fluct(xs[half:]), 3))

plt.plot(white, linewidth=0.8, label="white")
plt.plot(trend, linewidth=0.8, label="trend")
plt.plot(walk, linewidth=0.8, label="walk")
plt.legend()                      # 图例：给三色线配上名牌
```

种子 42 下体检表打印结果为：白噪声 `0.02 / -0.03` 与 `0.25 / 0.249`，均值波动都在原地；趋势线 `1.44 / 4.51` 与 `0.787 / 0.816`——均值拉开 3 个身位而波动纹丝不动，正例题 B 型的真身；随机游走 `0.5 / 2.54` 与 `0.298 / 2.282`——后半段波动几乎是前半段的 7.7 倍，C 型患者的重度版本。金融教材反复念叨"研究收益率而非价格"，病根就在最后这一行：价格像随机游走一样越走方差越大，而它的一步差分（今天的价 − 昨天的价）恰好把随机成分剥出来单独成列，是恢复平稳的常用手术。

## 6. 常见误区

:::warning[常见误区]

- **"图看着挺平，应该平稳。"** 目测骗人：方差缓慢膨胀的序列前期安静期占满画布，看起来岁月静好；分期体检一算才现原形。判决靠数字分段对比，不靠气质。
- **"平稳性只关心均值稳不稳。"** 三条缺一不可：C 型数据均值优雅，方差翻着跟头涨；B 型数据方差漂亮，均值一路向北。任何一条漂移都足以让"用历史参数外推"失效。
- **"这词跟第 30 课的平稳分布是一回事吧。"** 不是。平稳分布谈链的**状态占比收敛到 π**；序列平稳性谈**时间轴上统计规律不自变**。一个关于空间占比，一个关于时间性格。

:::

## 7. 练习

某实习生想检验一段明显逐日上涨的销量序列是否平稳，却先做了一步"预处理"：把相邻两天的差取绝对值，再看这串差值的分期均值。他的代码能跑、结论还是错的——修到三条检查全部通过：

```exercise
# @title: 被 abs 抹平的趋势
# @check: 1.5
# @check: 5.5
# @check: False
# @hint: 平稳性检查的对象是原始序列本身：abs 会把"每天涨一格"翻译成"每天动一格"，趋势就此蒸发
raw = [0, 1, 2, 3, 4, 5, 6, 7]    # 八天销量：赤裸裸的线性上涨

def avg(lst):
    return sum(lst) / len(lst)

half = len(raw) // 2              # ← 别急着做差分花活；直接切原始序列
first = avg([abs(raw[t] - raw[t - 1]) for t in range(1, len(raw))])
second = first                    # ← 这两行算的是差值的波浪起伏，不是序列的水平漂移

verdict = True                    # ← 用「前半均值 ≈ 后半均值」重新裁决平稳与否

print(round(first, 2))
print(round(second, 2))
print(verdict)
```

<details>
<summary>点开查看逐步解答</summary>

修正后的计算直接落在原始序列上：

```python
half = len(raw) // 2              # = 4
first = avg(raw[:half])           # 前 4 天：(0+1+2+3)/4 = 1.5
second = avg(raw[half:])          # 后 4 天：(4+5+6+7)/4 = 5.5
verdict = abs(first - second) < 1.0   # 判据：均值搬家超过一格即非平稳 → False
```

打印 `1.5 / 5.5 / False`。实习生的 `abs(raw[t]-raw[t-1])` 是个温和的花活：连续上涨序列的一阶差全是 +1，取绝对值后变成恒定的 1，前后半段当然相等——于是"持续爬坡"被洗成了"原地颤动"。平稳性体检测量的是序列**水平的搬迁**与**振幅的膨胀**，任何先抹方向再验平的操作都是在销毁证据。

</details>

再来一道概念题：

```quiz
持有某股票十年。下列哪个序列更可能通过平稳性体检？
- 每日收盘价本身
- 每日收益率（今日收盘对昨日收盘的变化率） [*]
- 十年累计涨幅曲线
? 价格与累计涨幅都是"越走方差越大"的随机游走型选手；变化率才是剥掉累积效应后围绕固定水平抖动的那一层。
```

## 8. 选读：随机游走差一刀，为什么立刻回血

<details>
<summary>选读 · 一阶差分降伏随机游走</summary>

设随机游走 $X_t=X_{t-1}+\varepsilon_t$，其中各 $\varepsilon_t$ 独立同分布、均值零方差有限（本课实验里的 `random.random()-0.5` 就是这一族）。对新序列 $W_t=X_t-X_{t-1}$ 展开定义立得：

$$W_t=\varepsilon_t$$

随机游走的一切漂移与方差累积全部住在"相对于昨天的位移"之外——差分一刀切下去，剩下的只有当天那枚独立的噪声，天生满足弱平稳三条件：均值 $0$ 不随 $t$ 变，方差 $\mathrm{Var}(\varepsilon)$ 恒定，且任意间隔的自协方差为 $0$（独立教会的）。这也是单位根检验一族方法的原点：先怀疑序列带单位根（类似随机游走），再用差分降阶到平稳后才开始拟合。过度差分同样有代价——会把信号的高频成分错杀成噪声，手术次数不是越多越好。

</details>
