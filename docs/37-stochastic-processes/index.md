## 实战挑战 · 无线基站的三包缓存

一个真实通信系统里的缓存，就是一条带边界的随机游走。某无线基站为一路传感器保留 3 个包位；时隙开始时的排队包数是状态 $X_t\in\lbrace0,1,2,3\rbrace$。每个时隙**先发送**：非空队首以 $\mu=0.7$ 成功发出一包，失败则以 $0.3$ 留在原地；**后到达**：新包以 $\lambda=0.5$ 概率到来，若缓存已满则被拒绝。于是积压量是在 0 处反射、在 3 处可能被挡回的有限随机游走。

逐状态追踪可得到转移矩阵：

$$P=\begin{pmatrix}0.50&0.50&0&0\\0.35&0.50&0.15&0\\0&0.35&0.50&0.15\\0&0&0.35&0.65\end{pmatrix}$$

例如从“满缓存 3”出发：发送成功（0.7）后腾出一个位置，随后无论是否到包都只会在 2 或 3；发送失败（0.3）时仍在 3，新包必然被拒，所以留在 3。

**(a)** 写出满缓存状态的转移行。
**(b)** 用幂迭代求四个状态的长期占比，并给出满缓存概率。
**(c)** 求长期每时隙成功发送概率（吞吐量）。
**(d)** 求长期每时隙新包因满缓存被拒的概率（阻塞率）。

```exercise
# @title: 实战挑战：无线基站的三包缓存
# @check: [0.0, 0.0, 0.35, 0.65]
# @check: 0.3027
# @check: 0.4881
# @check: 0.0119
# @hint: 满缓存时只有“先发送失败”才会拒绝新包；平稳分布用幂迭代算，吞吐量用 μ 乘非空概率，阻塞率用 λ(1−μ) 乘满缓存概率
P = [
    [0.50, 0.50, 0.00, 0.00],
    [0.35, 0.50, 0.15, 0.00],
    [0.00, 0.35, 0.50, 0.15],
    [0.00, 0.00, 0.35, 0.50],   # ← 满缓存失败时仍应留在 3
]
p = [0.25, 0.25, 0.25, 0.25]

for step in range(5):            # ← 太短，还远没有混匀
    nxt = [0.0, 0.0, 0.0, 0.0]
    for i in range(4):
        for j in range(4):
            nxt[j] = nxt[j] + p[i] * P[i][j]
    p = nxt

throughput = 0.5 * (p[1] + p[2] + p[3])     # ← 发送成功率应是 μ=0.7
block_rate = 0.5 * p[3]                     # ← 还要乘上“发送失败”这个条件

print(P[3])
print(round(p[0], 4))
print(round(throughput, 4))
print(round(block_rate, 4))
```

<details>
<summary>点开查看逐步解答</summary>

满缓存一行是 $[0,\ 0,\ 0.35,\ 0.65]$：发送成功且无到包落在 2，概率为 $0.7\times0.5=0.35$；发送成功且有到包留在 3，概率也是 $0.35$；发送失败时到包必被拒，留在 3 的概率为 $0.3$。合并后就是 $0.35+0.3=0.65$。

幂迭代收敛到：

$$\pi\approx(0.3027,\ 0.4325,\ 0.1853,\ 0.0794)$$

因此满缓存概率约为 $0.0794$。吞吐量是“非空才可发送”乘以发送成功率：

$$0.7\times(0.4325+0.1853+0.0794)\approx0.4881$$

阻塞只在“开始时已满且发送失败”时发生，所以：

$$0.5\times0.3\times0.0794\approx0.0119$$

</details>

## 实战挑战 · 马尔可夫一步转移

转移矩阵 $P$ 的第 $j$ 列是从状态 $j$ 出发的去向。从分布 $\pi=(0.5,0.5)$ 出发，走一步得到 $\pi'=\pi P$。下面这题第二个分量把行列弄反了，修到输出 `0.55` 和 `0.45`：

```exercise
# @title: 实战挑战：马尔可夫一步转移
# @check: 0.55
# @check: 0.45
# @hint: 新分布每个分量 = 旧分布逐项点乘对应列；第二项应是 P[1][1]。
P = [[0.9, 0.1], [0.2, 0.8]]    # 转移矩阵（列随机）
pi = [0.5, 0.5]                  # 初始分布

new0 = pi[0] * P[0][0] + pi[1] * P[1][0]    # 0.5*0.9 + 0.5*0.2 = 0.55
new1 = pi[0] * P[0][1] + pi[1] * P[1][0]    # ← 问题在这：第二项应为 P[1][1]

print(round(new0, 2))
print(round(new1, 2))
```

<details>
<summary>点开查看逐步解答</summary>

一步转移是 $\pi' = \pi P$，每个分量都取**同一列**与分布的逐项乘积之和：

```python
new1 = pi[0] * P[0][1] + pi[1] * P[1][1]    # 0.5*0.1 + 0.5*0.8 = 0.45
```

改完：$\pi'_0 = 0.5\times0.9 + 0.5\times0.2 = 0.55$，$\pi'_1 = 0.5\times0.1 + 0.5\times0.8 = 0.45$。初始代码第二个分量误用 $P[1][0]$，得 $0.15$，两分量加起来不等于 1——马尔可夫链的分布必须处处归一，这个"守恒检查"正是找错的线索。

</details>
