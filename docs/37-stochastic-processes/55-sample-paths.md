# 样本路径与有限维分布

## 1. 从一个场景开始

打开外卖 App 追一单骑手的订单，你看到的只是几个打卡点：已接单、已到店、配送中、已送达。可骑手真实的这一天是**一整条轨迹**——哪条路、绕了哪个弯、在哪里等了三个红灯。前几课我们一直在问"第 $t$ 步落在各状态的概率是多少"，这是横着看时间轴的快照；这一课把镜头竖过来：盯住一次完整的演化过程本身。

随机过程有两个身份。它是一**族**随机变量（每个时刻抽一个），也是**一台生成曲线的机器**：每掷一次"命运骰子"，就吐出一整条确定的时间函数。想精确刻画这台机器，光有每个时刻的边缘分布远远不够。

## 2. 直觉解释

**核心类比：电影 vs 剧照。**

- 随机过程是一部随机的电影——掷一次骰子，得到一整卷胶片，这卷胶片就叫一条**样本路径**；
- 固定某个时刻截一张图，得到一张剧照——那是单个随机变量的分布，前面几课研究的全是剧照；
- 把所有胶片在同一时刻叠放，会看到一片上下翻腾的"云带"；把云带在无穷多个时刻的浓淡全部记录下来，你就握住了这部电影的**完整指纹**。

关键在于：指纹不是某几张剧照的拼接。同一部剧情片和同一部纪录片，可能每一帧里主角出现在画面中央的概率都一样（一维分布相同），但帧与帧之间的连贯方式天差地别。要区分它们，必须同时锁住**多个时刻的联合行为**。

## 3. 正式定义

设 $\lbrace X_t\rbrace_{t\ge0}$ 是概率空间上的随机过程。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\omega$ | 基本结果 | 命运骰子的一次具体投掷 |
| $X_t(\omega)$ | 样本路径 | 固定 $\omega$ 后，$t\mapsto X_t(\omega)$ 是一条普通的（分段）时间函数 |
| $(X_{t_1},\dots,X_{t_k})$ | 有限维随机向量 | 同时锁住 $k$ 个时刻的读数 |
| 有限维分布族 | 过程的指纹 | 一切形如 $P(X_{t_1}\in A_1,\dots,X_{t_k}\in A_k)$ 的概率 |

两条核心事实：

1. **指纹决定一切**：知道了全部有限维分布，过程涉及的任何统计问题（含极限行为）原则上都能作答；
2. **剧照定不了电影**：存在两个过程，任意单个时刻的分布完全相同，样本路径的性格却截然不同。

## 4. 分步例题

比较两位同学各造的过程。状态都是涨跌记号 $\varepsilon=\pm1$：

- **甲过程**：开市掷**一枚**硬币得 $\varepsilon$，令 $X_0=X_1=X_2=\varepsilon$（三个值绑定同涨同跌）；
- **乙过程**：开市独立掷**三枚**硬币，逐时刻给出 $X_0,X_1,X_2$，各自取 $\pm1$。

两者在每个时刻的边缘分布都一样：涨跌各半。现在算两道题。

1. **甲：三个值全为 $+1$ 的概率？** 全场只听一枚硬币：$\varepsilon=+1$ 即成，概率 $P=\dfrac{1}{2}$。
2. **乙：三个值全为 $+1$ 的概率？** 三枚独立硬币齐刷刷：$P=\left(\dfrac{1}{2}\right)^3=\dfrac{1}{8}$。
3. **再比一个更隐蔽的量**：$S=X_0+X_1+X_2$ 的方差。甲：$S=3\varepsilon$，而 $\varepsilon^2=1$ 恒成立，故 $E[S^2]=9$；乙：三个独立的 $\pm1$ 相加，方差 $1+1+1=3$。
4. **结论**：一维剧照完全无法区分甲与乙；多个时刻连起来看，两者的"粘法"才现出原形。

## 5. 动手实验

### 实验 1（python）：六条平行宇宙

```python title="掷六次骰子：六条 ±1 随机游走的样本路径"
# sliders: paths=6 [2:12:1]
import random                     # 随机库（第 0 章登场）
import matplotlib.pyplot as plt   # 绘图模块起短名 plt

random.seed(7)                    # 固定随机种子：每次运行重现同一批平行宇宙
steps = 200                       # 时间轴切成 200 格

rows = []                         # rows[k] 存第 k 条完整路径
for k in range(paths):
    pos = 0
    route = [0]
    for t in range(steps):
        step = 1 if random.random() < 0.5 else -1   # 掷硬币定下一步
        pos = pos + step
        route.append(pos)
    rows.append(route)
    plt.plot(route, linewidth=0.8)

avg = []                          # 集体平均：同一时刻对所有路径取平均
for t in range(steps + 1):
    s = 0
    for k in range(paths):
        s = s + rows[k][t]
    avg.append(s / paths)
plt.plot(avg, color="red", linewidth=2.5)   # 红线：6 条路的平均走向

up_end = 0                        # 数终点收在零线上方的路径条数
for k in range(paths):
    if rows[k][steps] > 0:
        up_end = up_end + 1
print(up_end)
print([rows[k][steps] for k in range(paths)])   # 列表推导：[表达式 for k in 序列] 一行收齐全部终点值
```

种子固定为 7 时输出：5 条收在零线上方，终点分别是 `[20, 2, 4, 28, 20, -10]`。看红线：集体平均几乎贴着零爬行（期望为 0 被"平均"兑现）；再看个体：同一个家庭里的兄弟，终点却散布在 $-10$ 到 $28$ 之间。横切一刀统计一个时刻，永远看不出这种"家族内的大分化"。

### 实验 2（python）：亲手数一个有限维分布

三步随机游走共 $2^3=8$ 种走法，枚举全部序列，考察事件"$X_1=-1$ 且 $X_2=2$"：

```python title="按排列清点：两个时刻的联合概率"
hits_joint = 0                    # 命中 (X1=-1 且 X2=2) 的走法数
hits_x1_neg = 0                   # 命中 X1=-1 的走法数
hits_x2_two = 0                   # 命中 X2=2 的走法数
total = 0                         # 总走法数
for s1 in [-1, 1]:
    for s2 in [-1, 1]:
        for s3 in [-1, 1]:
            total = total + 1
            x1 = s1
            x2 = s1 + s2
            if x1 == -1 and x2 == 2:
                hits_joint = hits_joint + 1
            if x1 == -1:
                hits_x1_neg = hits_x1_neg + 1
            if x2 == 2:
                hits_x2_two = hits_x2_two + 1
print(total)
print(hits_joint)
print((hits_x1_neg / total) * (hits_x2_two / total))
```

输出 `8 / 0 / 0.125`：联合概率是**零**，而两个边缘概率之积是 $0.125>0$。原因朴素极了：第一步若先向下（$X_1=-1$），两步之内最多爬回 $0$，根本到不了 $+2$。相邻时刻的命运是拴在一条绳上的——这正是有限维分布存在的理由。

## 6. 常见误区

:::warning[常见误区]

- **"每个时刻的分布都知道了，过程就算认识了。"** 甲乙过程的例子就是反例：一维分布相同、路径性格迥异。要拍电影，就得锁定联合分布，哪怕先从几个时刻的配对开始。
- **"既然每条样本路径实现后都是普通函数，随机性去哪了？"** 随机性发生在抽样之前：掷骰子选定 $\omega$ 是随机的；选完之后这条曲线就定型了。"随机"修饰的是选择机制，不是选出来的对象。
- **"不同时刻的 $X_t$ 各抽各的，独立就完事了。"** 同一条路径上相邻时刻强相关（实验 2 里"$先下后到不了 +2$"就是铁证）。把联合当成边缘相乘，是初学随机过程最贵的错误。

:::

## 7. 练习

回到分步例题的甲乙两过程。初始代码把两人算串了——它用"三枚独立硬币"的公式套到了只有一个硬币的甲头上，还把方差的账记成了波动幅度。修到四条检查全部通过：

```exercise
# @title: 谁把谁的硬币搞混了
# @check: 0.5
# @check: 0.125
# @check: 9
# @check: 3
# @hint: 甲只有一枚硬币，全涨即那枚硬币开出 +1；求和 S 甲 = 3ε，平方后期望吃满 ε²=1 这个恒等式
coin = 0.5         # 单枚硬币出正面的概率

# 甲过程：一枚硬币定全场（X0=X1=X2=ε，绑定同涨同跌）
p_alpha = coin ** 3          # ← 甲哪里来的三枚硬币？
var_alpha = 1 + 1 + 1        # ← 这是三条独立 contributions；甲的和是 3ε，想想 (3ε)²

# 乙过程：三枚独立硬币各管一个时刻
p_beta = coin ** 3           # 这行是对的，别动它
var_beta = 1 + 1 + 1         # 这行也是对的

print(p_alpha)
print(p_beta)
print(var_alpha)
print(var_beta)
```

<details>
<summary>点开查看逐步解答</summary>

修正后的关键两行：

```python
p_alpha = coin              # 甲的全涨概率 = 那唯一硬币出正面的概率 = 0.5
var_alpha = 9               # S甲 = 3ε ⇒ S甲² = 9ε² = 9 恒成立 ⇒ 方差恰为 9
```

其余不变。四条打印依次是 `0.5 / 0.125 / 9 / 3`。深挖一下第三行：甲过程里 $S$ 只取 $\pm3$，抖动幅度是乙过程的 $\sqrt{3}$ 倍——捆绑不是小事，它把三份不确定性合并成了一份但放大了振幅。比较过程时，请优先比较联合层面的量（协方差、和的方差），别被相同的一维 marginals 安抚。

</details>

## 8. 选读：谁给"指纹"发证

<details>
<summary>选读 · 相容性与柯尔莫哥洛夫扩展定理</summary>

随手写一族有限维分布是不够的，它们必须**互相咬合**：若已知 $(X_{t_1},X_{t_2})$ 的联合分布，把第二个坐标边缘掉，得到的必须是 $X_{t_1}$ 自己的分布——任何高维信息投影回低维都不能变形。全体 finite 维分布两两相容，就称该族满足柯尔莫哥洛夫相容性条件。

1933 年的柯尔莫哥洛夫扩展定理说：在一块足够肥的概率空间上，只要有限维分布族相容，必存在一个随机过程以它为指纹。这句话把"造过程"还原成"报指纹"，也顺带回答了本课开头的问题：**描述随机过程的正确语言是从任意有限时刻切入的联合分布**，而非无穷个边缘的堆叠。至于"冻结直线 vs 活蹦乱跳但每个时刻同分布"这类构造，正是利用相容性自由度换来了截然不同的路径几何——它们会在布朗运动一课重逢。

</details>
