# 点积：两个向量合不合拍

## 1. 从一个场景开始

游戏画面里，同一面墙为什么向阳面亮、背阳面暗？物理学家一句话点破：亮度取决于**光的方向**和**墙的朝向**有多"合拍"——正对阳光最亮，侧着照变暗，背对就黑。

"两个方向合不合拍"这件事，能不能用一个数来打分？能。这个数就是本课的主角：**点积**。它是向量世界里第一种乘法，也是图形学的光照公式和机器学习的相似度打分器共同的内核。

## 2. 直觉解释

把点积想象成一位裁判，专门给两支箭头的**配合程度**打分：

- 两支箭头方向一致（夹角是锐角）：配合默契，得**正分**，越一致分越高；
- 互相垂直（夹角 $90°$）：谁也不帮谁的忙，得 **0 分**；
- 方向相反（钝角）：互相拆台，得**负分**。

注意裁判很精明：它不光看方向，还把两支箭头的**长度**都算进总分——又长又齐的点积大，短小或拧巴的点积小。所以点积一个数里，同时装着"多长"和"多齐"两条信息。

## 3. 正式定义

设 $\vec{u} = (u_x, u_y)$，$\vec{v} = (v_x, v_y)$，夹角为 $\theta$（$0 \le \theta \le \pi$）。点积有两种等价的算法：

$$\text{分量式：}\quad \vec{u}\cdot\vec{v} = u_x v_x + u_y v_y$$

$$\text{几何式：}\quad \vec{u}\cdot\vec{v} = \lvert\vec{u}\rvert\, \lvert\vec{v}\rvert \cos\theta$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\vec{u}\cdot\vec{v}$ | 点积 | 一个标量（普通数字），不是向量！ |
| $\theta$ | 夹角 | 两支箭头转到重合所需的最小角 |
| $\lvert\vec{u}\rvert$ | 模 | 箭头长度 $\sqrt{u_x^2+u_y^2}$ |
| $\cos\theta$ | 余弦 | 合拍度：$1$ 全合拍、$0$ 垂直、$-1$ 反向 |

分量式好算——加乘而已；几何式好看透本质——夹角直接出现在公式里。两者数值永远相等（选读部分给理由），于是立刻得到全章最重要的判定之一：

$$\vec{u} \perp \vec{v} \iff \vec{u}\cdot\vec{v} = 0 \quad (\vec{u},\vec{v}\neq\vec{0})$$

垂直时 $\cos 90° = 0$，点积必然为零；反过来点积为零，夹角必是直角。"判垂直"从此不用量角器，一次乘加搞定。

## 4. 分步例题

**例 1**：求 $\vec{u}=(2,3)$ 与 $\vec{v}=(4,1)$ 的点积与夹角。

1. 分量式：$2\times4 + 3\times1 = 8 + 3 = 11$；
2. 算模长：$\lvert\vec{u}\rvert = \sqrt{4+9} = \sqrt{13} \approx 3.606$，$\lvert\vec{v}\rvert = \sqrt{16+1} = \sqrt{17} \approx 4.123$；
3. 几何式反解余弦：$\cos\theta = \dfrac{11}{3.606 \times 4.123} = \dfrac{11}{14.87} \approx 0.740$；
4. 查表或用单位圆估计：$\theta \approx 42°$——锐角，正分，两支箭头相当合拍。

**例 2**：判断 $\vec{a}=(1,2)$ 与 $\vec{b}=(-2,1)$ 是否垂直。

1. 点积：$1\times(-2) + 2\times1 = -2 + 2 = 0$；
2. 结论：点积为零且都不是零向量，**垂直**。全程没有量任何角度。

## 5. 动手实验

### 实验 1（viz）：拖出锐角、直角、钝角三种判决

```viz
{
  "type": "dotprod",
  "u": [4, 1],
  "v": [1, 2]

```

怎么玩：分别拖动蓝绿两支箭头，盯住点积读数的颜色——**锐角绿色（正）、直角灰色（零）、钝角红色（负）**。试着把两支箭头摆成精确的直角，读数会稳稳停在 $0$；橙色粗段是 $\vec{u}$ 在 $\vec{v}$ 上投下的影子，垂直时影子缩成一个点。这个"影子"下一课（投影）要正式登场，先混个眼熟。

### 实验 2（python）：验证两副面孔给出同一个答案

```python title="分量式 vs 几何式：数值对照"
import math   # 老朋友

# sliders: theta_deg=60 [10:80:5], phi_deg=20 [-80:80:5]

theta = math.radians(theta_deg)   # 角度转弧度（第 7 章的老规矩）
phi = math.radians(phi_deg)
u = [3 * math.cos(theta), 3 * math.sin(theta)]   # 长度 3、方向角 theta 的箭头
v = [4 * math.cos(phi), 4 * math.sin(phi)]       # 长度 4、方向角 phi 的箭头

comp = u[0] * v[0] + u[1] * v[1]                  # 面孔一：分量式
geo = 3 * 4 * math.cos(theta - phi)               # 面孔二：|u||v|cos(夹角)，夹角=θ−φ
print(f"分量式: {round(comp, 4)}")
print(f"几何式: {round(geo, 4)}")
```

怎么玩：随便拖动两个滑杆，两行输出始终相同——因为两支箭头的长度和夹角都是我们自己定的，几何式直接可用；分量式则完全不看角度，照样算出同一个数。

### 实验 3（python）：垂直判定 + zip 版点积函数

```python title="一次乘加，判尽垂直"

def dot(a, b):                     # def 定义函数：接收两个向量（列表）
    total = 0
    for x, y in zip(a, b):         # zip：首次登场！把两条列表按位置配成对，x、y 同时各取一个分量
        total = total + x * y      # 累加器：每对的乘积加进 total
    return total                   # 返回点积这个标量

pairs = [
    [[1, 2], [-2, 1]],   # 这对垂直吗？
    [[1, 2], [2, 4]],    # 这对呢？
    [[3, -1], [2, 5]],
]
for p in pairs:                    # p 依次取出列表中的每一对向量
    print(f"{p[0]}·{p[1]} = {dot(p[0], p[1])}")
```

输出里第一对恰好得 $0$——$(1,2)\perp(-2,1)$，不用作图一眼判出。第二对是平行的极端情形（$\vec{v}=2\vec{u}$），点积冲到最大。

### 快问快答

```quiz
两个非零向量的点积为 0，说明什么？
- 其中至少有一个是零向量
- 它们互相垂直 [*]
- 它们方向相反
? cos90°=0，所以垂直时点积必为零；反过来点积为零，夹角必是直角。这是线性代数判垂直的官方标准。
```

:::warning[常见误区]

**误区一**："你以为点积的结果还是向量。" 其实它是标量——一个没有方向的纯数字。名字里的"点"暗示了产物是一个点（数），而不是一支新箭头。

**误区二**："你以为点积大说明夹角大。" 其实恰恰相反：点积越正，夹角越小；变成负数，说明夹角超过了 $90°$。想单纯比较方向而不被长度干扰，要先把向量除以自己的模长（归一化）再点。

**误区三**："你想当然地以为 `[1,2]·[3,4]` 在 Python 里能直接算。" 其实 Python 没有"向量点乘"运算符，`*` 对列表会直接报错——老老实实写 `a[0]*b[0] + a[1]*b[1]` 或像实验 3 那样自己定义 dot 函数。

:::

## 6. 练习

**练习 1**：太阳光与某面墙的法线（朝外的垂直方向）夹角为 $60°$，另一面墙的法线与光线夹角 $30°$。哪面墙更亮？各是最大亮度的几成？

<details>
<summary>点开查看逐步解答</summary>

光照强度正比于法线与光线夹角的余弦。$60°$ 墙：$\cos 60° = 0.5$，五成亮；$30°$ 墙：$\cos 30° \approx 0.87$，接近九成亮。游戏引擎里每个像素的光照都在做这道题。
</details>

**练习 3**：已知 $\lvert\vec{m}\rvert = 5$、$\lvert\vec{n}\rvert = 3$、$\vec{m}\cdot\vec{n} = -7.5$，求夹角 $\theta$。

<details>
<summary>点开查看逐步解答</summary>

## 7. 选读：为什么两副面孔相等

<details>
<summary>选读 · 用余弦定理搭桥</summary>

把 $\vec{u}$、$\vec{v}$ 和差向量 $\vec{u}-\vec{v}$ 画出来，首尾相接围成一个三角形，两边 $\lvert\vec{u}\rvert$、$\lvert\vec{v}\rvert$ 的夹角正是 $\theta$。余弦定理说：

$$\lvert\vec{u}-\vec{v}\rvert^2 = \lvert\vec{u}\rvert^2 + \lvert\vec{v}\rvert^2 - 2\lvert\vec{u}\rvert\lvert\vec{v}\rvert\cos\theta$$

另一边，把左边逐分量展开（代数课的老手艺）：

$$\lvert\vec{u}-\vec{v}\rvert^2 = (u_x-v_x)^2 + (u_y-v_y)^2 = \lvert\vec{u}\rvert^2 + \lvert\vec{v}\rvert^2 - 2(u_xv_x + u_yv_y)$$

两个式子描述同一个东西，对比即得 $u_xv_x+u_yv_y = \lvert\vec{u}\rvert\lvert\vec{v}\rvert\cos\theta$。代数面孔与几何面孔在余弦定理处会师——这也解释了为什么"垂直 ⇔ 点积为零"和勾股定理是一枚硬币的两面。

</details>
