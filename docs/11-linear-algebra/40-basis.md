# 基与坐标：换一套语言说同一个点

## 1. 从一个场景开始

同一首曲子，可以写成简谱，也可以写成五线谱——纸上的符号完全不同，响起的音乐一模一样。坐标也一样：$(3, 2)$ 这个点，在"横竖两支箭头"的语言里念 $(3,2)$；换两支斜着的箭头当尺子，就得改口了。

**点没有变，变的是描述它的语言。**这一课讲清楚"语言"怎么定、怎么换——而这套手艺的终极应用，是把一段声音翻译成正弦波的坐标，那正是卷一枢纽傅里叶变换的内核。

## 2. 直觉解释

之前所有课里我们默认用 $\hat{\imath}=(1,0)$、$\hat{\jmath}=(0,1)$ 当尺子量坐标——它们叫**标准基**，相当于坐标世界的普通话。

但尺子可以自选。取 $\vec{b_1}=(1,1)$（指东北）和 $\vec{b_2}=(1,-1)$（指东南）当新尺子，问：$(3,2)$ 这支箭头是几份 $\vec{b_1}$ 加几份 $\vec{b_2}$？解一个二元方程：

$c_1\begin{pmatrix}1\\1\end{pmatrix} + c_2\begin{pmatrix}1\\(-1)\end{pmatrix} = \begin{pmatrix}3\\2\end{pmatrix}; \quad c_1=\tfrac52,\ c_2=\tfrac12$

于是在新语言里，同一个点要念成 $(2.5,\ 0.5)$。数字全换了，箭头纹丝没动。

这有什么用？想象一段三秒的声音波形：几千个采样点，是几千维空间里的**一个向量**，用的是"每个时刻的音量"这种笨语言。若换成"每个纯音成分占多少"的语言——正弦基——同样的声音只需十几个数就能说清。**换个好基，问题脱胎换骨**，这就是傅里叶变换的全部动机，而它的数学地基你在前四课已经备齐：向量是原料，点积是探针，矩阵是搬运工，基是语言。

## 3. 正式定义

一组**基**（basis）是张满整个平面的两支不共线箭头 $\vec{b_1}, \vec{b_2}$。任何向量 $\vec{v}$ 都能唯一分解成它们的组合：

$$\vec{v} = c_1\,\vec{b_1} + c_2\,\vec{b_2}$$

数组 $(c_1, c_2)$ 就叫 $\vec{v}$ 在基 $\vec{b_1}, \vec{b_2}$ 下的**坐标**。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\hat{\imath}, \hat{\jmath}$ | 标准基 | 横竖单位箭头，默认坐标系 |
| $\vec{b_1}, \vec{b_2}$ | 新基 | 自选的两支不共线箭头 |
| $c_1, c_2$ | 新坐标 | 组合配方："几份 $\vec{b_1}$ 加几份 $\vec{b_2}$" |


两个要点：其一，分解唯一（两支箭头不共线时），否则坐标就说不清了；其二，"不共线"正是[矩阵那一课](./30-matrix.md)行列式不为零的几何条件——$\det\begin{pmatrix} b_{1x} & b_{2x} \\ b_{1y} & b_{2y}\end{pmatrix} \neq 0$ 的基才配称基。

## 4. 分步例题

**例**：求 $\vec{v}=(3,2)$ 在基 $\lbrace(1,-1),\ (2,1)\rbrace$ 下的坐标。（这次故意选一支朝下的基。）

1. 列方程：$c_1(1,-1)+c_2(2,1)=(3,2)$，即 $c_1+2c_2=3$ 且 $-c_1+c_2=2$；
2. 消元：第二式给出 $c_1=c_2-2$，代入第一式得 $3c_2-2=3$；
3. 解出：$c_2 = \tfrac53$，$c_1 = -\tfrac13$；
4. 验算：$-\tfrac13(1,-1)+\tfrac53(2,1) = (-\tfrac13+\tfrac{10}{3},\ \tfrac13+\tfrac53) = (3, 2)$ ✓。

负系数完全合法：意思是"往 $\vec{b_1}$ 的反方向借一点"，几何上就是沿反方向走。

## 5. 动手实验

```viz
{
  "type": "basiscoords",
  "title": "同一个 v，两套基语言",
  "b1": [1, 1],
  "b2": [1, -1],
  "p": [3, 2]
}
```

怎么玩：拖动蓝色 `b1`、橙色 `b2` 和紫色 `v` 的端点。平行四边形的两条边会实时配平；顶部读数就是 `v` 在斜基下的坐标。把两支基拖到同一条直线上，`det` 归零——坐标机器当场失灵，这正是“基必须张满空间”的几何原因。

### 实验 1（python）：解方程翻译机

```python title="解方程：把 v 翻译成斜基的语言"

b1 = [1, 1]     # 新基一号：指向东北
b2 = [1, -1]    # 新基二号：指向东南
v = [3, 2]      # 点本身（老语言坐标）

# 设 v = c1*b1 + c2*b2，逐分量列方程：
#   x: c1 + c2 = 3
#   y: c1 - c2 = 2
c1 = (v[0] + v[1]) / 2   # 两式相加除以二，解出 c1
c2 = (v[0] - v[1]) / 2   # 两式相减除以二，解出 c2
print(f"c1={c1}, c2={c2}")

check = []               # 验算：拿新坐标拼回去，应还原出 (3, 2)
for i in range(2):
    check.append(c1 * b1[i] + c2 * b2[i])
print(check)
```

新坐标 $(2.5, 0.5)$ 与直觉部分的手算一致；验算行打印 `[3.0, 2.0]`，证明两种说法指向同一支箭头。

### 实验 2（python）：换基翻译机，随拖随译

```python title="任意点的换基翻译机"
# sliders: vx=4 [-6:6:1], vy=2 [-6:6:1]

v = [vx, vy]    # 要翻译的点（老语言）
b1 = [1, 0]     # 斜基一号：还是横向
b2 = [1, 1]     # 斜基二号：歪向东北

# 方程组（逐分量）：
#   x: 1*c1 + 1*c2 = vx
#   y: 0*c1 + 1*c2 = vy
c2 = vy         # 第二个方程不含 c1，直接读出 c2
c1 = vx - c2    # 回代第一个方程
print(f"({vx}, {vy}) 在斜基下说成 ({c1}, {c2})")

back = []       # 反向验证：新坐标拼回老语言
for i in range(2):
    back.append(c1 * b1[i] + c2 * b2[i])
print(back)
```

怎么玩：拖动滑杆观察规律——纵坐标不变时新旧 y 相同；点越靠右，新语言里的 $c_1$ 被 $c_2$ "吃掉"越多。注意默认点 $(4,2)$ 恰好念成 $(2,2)$：练习 2 会让你亲手复现这个巧合。

### 实验 3（python）：反着玩——拖动新坐标，重建老坐标

前两个实验都是"老坐标 → 新坐标"。现在倒过来：给你新语言里的坐标，把它拼回标准坐标——亲手体验一次"换坐标系"：

```python title="新坐标配方 → 标准坐标"
# sliders: c1=2.5 [-3:3:0.5], c2=0.5 [-3:3:0.5]

b1 = [1, 1]     # 新基一号：指向东北
b2 = [1, -1]    # 新基二号：指向东南

point = []                                # 准备装标准坐标的空列表
for i in range(2):
    point.append(c1 * b1[i] + c2 * b2[i]) # 配方：c1 份 b1 加 c2 份 b2，逐分量拼装
print(f"c1={c1}, c2={c2} 拼出标准坐标 {point}")
```

怎么玩：默认滑杆正是直觉部分那组答案 $(2.5,\ 0.5)$——落点 $(3.0,\ 2.0)$ 与第 2 节的手算严丝合缝。把 $c_1$ 拧到 $0$：只剩 $c_2$ 份 $\vec{b_2}$，点被摁到东南方向那条直线上——**系数归零，等于抹掉一个维度的话语权**。负系数也完全合法，落点会甩到基箭头的反方向去。

### 快问快答

```quiz
同一个向量换了一组基之后，什么变了？
- 向量本身跟着变了
- 坐标变了，向量本身没变 [*]
- 向量和坐标都没变
? 箭头的大小方向原封不动，变的只是报数方式——就像同一句话从普通话换成方言，意思没变。
```

:::warning[常见误区]

**误区一**："你以为换基后向量本身变了。" 其实变的只是描述语言。$(3,2)$ 与"斜基下的 $(2.5,0.5)$"是**同一支箭头**的两个名字，画出来重合。

**误区二**："你以为坐标是点的固有属性。" 其实坐标永远相对于某组基而言。只报坐标不说基，就像报价钱不带币种——"$3$" 是美元还是日元？

**误区三**："你以为随便两支箭头都能当基。" 若两支共线（互为倍数），平面张不满，无数点无法表示——对应[矩阵那一课](./30-matrix.md)行列式为零的压扁惨案。基的资格线就是不共线。

:::

## 6. 练习

**练习 1**：概念题——为什么说"傅里叶变换是一种换基操作"？用本课语言各说一遍两边在做什么。

<details>
<summary>点开查看逐步解答</summary>

本课：把向量 $\vec v$ 从标准基坐标翻译到 $\lbrace\vec{b_1},\vec{b_2}\rbrace$ 坐标，方法是解"几份加几份"的方程。傅里叶变换：把信号（以"每个时刻的音量"为坐标）翻译到"正弦波家族"这组基的坐标，方法是算信号与每支正弦波的点积（相似度）。两边结构完全同构——只是维数从 2 升到了几千。
</details>

**练习 2**：求 $\vec{v}=(4,2)$ 在基 $\lbrace(1,0),\ (1,1)\rbrace$ 下的坐标，按 `"2 2"` 格式打印。下面的代码能跑但结果不对，修到通过：

```exercise
# @title: 练习：把 (4,2) 翻译成斜基坐标
# @check: 2 2
# @hint: 第二个方程是 0*c1 + 1*c2 = v[1]，c2 应该等于 v 的 y 分量；解出 c2 再回代第一个方程
v = [4, 2]
b1 = [1, 0]
b2 = [1, 1]

# 方程组：
#   x: 1*c1 + 1*c2 = 4
#   y: 0*c1 + 1*c2 = 2
c2 = v[0]        # 这行抄错方程了！它读的是哪个式子？
c1 = v[0] - c2
print(c1, c2)
```

**练习 3**：在基 $\lbrace(2,0),\ (0,2)\rbrace$ 下，坐标 $(1,1)$ 对应老语言里的哪个点？这说明缩放坐标轴和换基是什么关系？

<details>
<summary>点开查看逐步解答</summary>

$1\cdot(2,0)+1\cdot(0,2)=(2,2)$。这组基只是把标准基拉长一倍，所以换基等价于一次对角矩阵变换 $\begin{pmatrix}2&0\\0&2\end{pmatrix}$——换基和线性变换是一体两面，区别只在"你站在格子这边还是箭头那边"看问题。
</details>

## 7. 选读：换基矩阵，一位常驻翻译官

<details>
<summary>选读 · 翻译官的列，是新基的老坐标</summary>

把新基向量 $\vec{b_1}, \vec{b_2}$ 用**老语言**写下坐标，竖排成两列，得到一张 2×2 数表 $P$——它是一位随身翻译官：给它新语言的坐标 $(c_1,c_2)$，算 $P\begin{pmatrix}c_1\\c_2\end{pmatrix}$ 就吐出老语言的坐标。道理恰是定义本身：$c_1\vec{b_1}+c_2\vec{b_2}$ 的逐分量展开，与矩阵乘向量的公式一字不差。

反过来（老翻新）需要解方程，对应矩阵的"逆"——两课之后的[逆矩阵课](./45-inverse-matrix.md)会把它正式造出来，到时你会发现：把本课的翻译官 P 倒过来用，就是那把反向钥匙。先记住方向感：**翻译官的列 = 新基的老坐标**。第 16 章傅里叶变换里，那张巨大的"正弦波坐标表"扮演的就是翻译官角色，而傅里叶系数公式就是它的"逐分量点积版"。今天解的二元方程，就是未来一切变换的原型。

</details>
