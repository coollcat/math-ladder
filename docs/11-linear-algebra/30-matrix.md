# 矩阵：让整个平面动起来

## 1. 从一个场景开始

在游戏里点一下"旋转"，屏幕上成千上万个顶点瞬间各就各位。引擎不可能逐个点手算——它只存了一张 **2×2 的数表**，四个数，就指挥了整个平面的舞蹈。

这张数表就是矩阵。别被它朴素的外表骗了：矩阵不是"把数字排整齐的表格"，而是**一份对整个平面动手脚的配方**——写清楚"每个点按什么规则搬走"。

## 2. 直觉解释

先看一个惊人的事实：想指挥全平面的点搬家，其实只需要说清**两个去向**。

- 横向单位箭头 $\hat{\imath} = (1, 0)$ 被搬到了哪？
- 纵向单位箭头 $\hat{\jmath} = (0, 1)$ 被搬到了哪？

为什么两个就够了？因为平面上任何点 $(x,y)$ 都能拆成 $x$ 份 $\hat{\imath}$ 加 $y$ 份 $\hat{\jmath}$（上一课的向量加法）。只要这两个"零件"的去向定了，所有点的去向都被锁定。

于是配方可以写成一张表——把 $\hat{\imath}$ 的落点 $(a,c)$ 竖着排成第一列、$\hat{\jmath}$ 的落点 $(b,d)$ 排成第二列：

$$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

**读矩阵先读列**：每一列就是一支基箭头的去向。矩阵作用在点上记作 $A\vec{v}$，意思是"按这份配方搬运 $\vec{v}$"。

## 3. 正式定义

设 $A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$，$\vec{v} = (x, y)$，定义矩阵乘向量：

$$A\vec{v} = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} ax + by \\ cx + dy \end{pmatrix}$$

口诀：**结果的每个分量 = 矩阵的一行与向量的对应相乘再相加**——正是上一课的点积！

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $A$ | 矩阵 | 变换配方；第 1 列是 $\hat{\imath}$ 的落点，第 2 列是 $\hat{\jmath}$ 的落点 |
| $A\vec{v}$ | 矩阵乘向量 | 点 $\vec{v}$ 被搬到的新位置 |
| $\det A = ad - bc$ | 行列式 | 面积缩放倍数；负号表示翻面 |

行列式值得单独一句直觉：变换前画一个 $1\times1$ 小方块，变换后它的面积变成 $\lvert ad-bc\rvert$ 倍；若 $ad-bc<0$，平面还被**翻了个面**（顺逆时针交换，手性反转）；若 $=0$，整个平面被压扁到一条线上——面积归零，信息塌方。

## 4. 分步例题

**例 1**：用配方 $A=\begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}$ 搬运点 $(1, 2)$。

1. 读列：$\hat{\imath}\to(2,0)$（横向拉长 2 倍），$\hat{\jmath}\to(0,3)$（纵向拉长 3 倍）；
2. 拆解点：$(1,2) = 1\cdot\hat{\imath} + 2\cdot\hat{\jmath}$；
3. 零件跟着走：$1\cdot(2,0) + 2\cdot(0,3) = (2,6)$；
4. 用公式验算：$ax+by = 2\times1+0\times2 = 2$，$cx+dy = 0\times1+3\times2 = 6$ ✓。

**例 2**：左转 $90°$ 的配方是 $\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$，作用于 $(2, 1)$。

1. 公式直算：$(0\times2+(-1)\times1,\ 1\times2+0\times1) = (-1, 2)$；
2. 几何检查：指东的箭头转四分之一圈该指北偏西？$(2,1)$ 在东北方向，左转后应到西北——$(-1,2)$ ✓；
3. 行列式 $= 0\times0-(-1)\times1 = 1$：旋转不改变面积，也不翻面。

怎么玩：拖动 $a,b,c,d$ 四根滑杆，网格和小房子跟着扭曲——你正在徒手编写变换配方。试试预设按钮：「左转90°」对照例 2；「剪切」让竖线齐齐歪斜但底边不动；「压扁」时盯住顶部行列式读数一路跌向 $0$。再注意两支粗箭头：蓝色是 $\hat{\imath}$ 的落点 $(a,c)$，橙色是 $\hat{\jmath}$ 的落点 $(b,d)$——**它们恰好就是矩阵的两列**。行列式为负的瞬间，观察小房子的门窗左右互换：翻面了。

### 实验 2（python）：手写矩阵乘向量

```python title="手写 matrix_vec_mult：双层循环"

A = [[2, 0], [0, 3]]   # 列表里套列表（首次登场！）：外层装行，每个小列表是一行
x = [1, 2]             # 要搬运的点 (1, 2)

def matrix_vec_mult(M, v):           # def 定义函数：M 是 2×2 配方，v 是二维点
    result = []
    for i in range(2):               # 外层循环：i 逐行走遍 M 的每一行
        total = 0
        for j in range(2):           # 内层循环：这一行的第 j 个元素 × v 的第 j 个分量
            total = total + M[i][j] * v[j]   # M[i][j] 读作"第 i 行第 j 列"
        result.append(total)         # 这一行的点积收进结果列表
    return result                    # 返回新位置（列表形式）

print(matrix_vec_mult(A, x))

result = matrix_vec_mult(A, x)
for i, row in enumerate(A):          # enumerate 首次登场：同时给出编号 i 和元素本身
    print(f"{row} 这一行贡献分量 {result[i]}")
```

输出 `[2, 6]` 与例 1 完全一致。双层循环就是公式 $ax+by,\ cx+dy$ 的逐条执行版。

### 实验 3（python）：顺序有讲究——AB ≠ BA

```python title="先剪切再旋转 vs 先旋转再剪切"

def apply(M, p):                     # 小工具：把配方 M 用在点 p 上
    return [M[0][0] * p[0] + M[0][1] * p[1],
            M[1][0] * p[0] + M[1][1] * p[1]]

shear  = [[1, 1], [0, 1]]            # 剪切：横向越高层越歪
rotate = [[0, -1], [1, 0]]           # 左转 90°
p = [1, 0]

print(apply(rotate, apply(shear, p)))   # 先剪切、后旋转
print(apply(shear, apply(rotate, p)))   # 先旋转、后剪切
```

两次结果一个是 `[0, 1]`、一个是 `[1, 1]`——**矩阵连做不满足交换律**，顺序不同结局不同（就像"先穿袜子再穿鞋"换不得）。矩阵乘法 AB 表示"先做 B 再做 A"——把两步合成一步的合账算术下一课（[35 课](./35-matrix-multiplication.md)）正式建账，本课知道顺序敏感即可。

### 快问快答

```quiz
矩阵 [[a, b], [c, d]] 中，哪一部分记录了 î=(1,0) 的落点？
- 第一行 (a, b)
- 第一列 (a, c) [*]
- 对角线上的 a 和 d
? 读列不读行：î 是第一支基箭头，它的去向写在第一列。第二列同理记录 ĵ。
```

:::warning[常见误区]

**误区一**："你以为矩阵乘法像数字乘法一样可交换。" 其实 $AB \neq BA$——实验 3 里换个顺序，同一个点落到两个不同位置。矩阵是"动作"，动作先后不可随意调换。

**误区二**："你以为矩阵只是排整齐的数字表格。" 其实排列方式本身就是信息：每一列是一支基箭头的落点。横着读行会错过"这个变换到底对平面做了什么"。

**误区三**："你以为行列式只是个凑出来的算式。" 其实它是面积缩放倍数：$\det = 2$ 面积翻倍；$\det < 0$ 翻面；$\det = 0$ 把平面压成一条线——这时无数个不同的点挤到同一处，去路和回路都断了。

:::

## 6. 练习

**练习 1**：写出"把横向压一半、纵向拉三倍"的矩阵，并算它的行列式。

<details>
<summary>点开查看逐步解答</summary>

$\hat{\imath}\to(0.5, 0)$、$\hat{\jmath}\to(0,3)$，故 $A=\begin{pmatrix} 0.5 & 0 \\ 0 & 3\end{pmatrix}$，$\det = 0.5\times3 - 0 = 1.5$。面积变 1.5 倍——一压一拉，净效果是 1.5。
</details>

**练习 3**：某配方把 $\hat{\imath}$ 送到 $(1, 1)$、把 $\hat{\jmath}$ 也送到 $(1, 1)$。写出矩阵、算行列式，并描述平面的下场。

<details>
<summary>点开查看逐步解答</summary>

$A=\begin{pmatrix} 1 & 1 \\ 1 & 1\end{pmatrix}$，$\det = 1-1 = 0$。两支基箭头被压到同一条直线 $y=x$ 上，全平面跟着压扁：面积清零，无数不同的点共享同一个落点。行列式为零是"信息丢失"的警报。
</details>

## 7. 选读：为什么两个基向量能锁定一切

<details>
<summary>选读 · 线性性：配方的合法性证明</summary>

我们声称：只要定好 $\hat{\imath}$ 和 $\hat{\jmath}$ 的落点，任意点的去向就被唯一确定。理由是"线性"这条游戏规则——先加后搬等于先搬后加，先伸缩后搬等于先搬后伸缩：

$$A(\vec{u}+\vec{v}) = A\vec{u} + A\vec{v}, \qquad A(k\vec{v}) = k\,(A\vec{v})$$

而任何点 $\vec v = x\,\hat{\imath} + y\,\hat{\jmath}$ 都是基向量的加减乘组合，于是

$$A\vec{v} = A(x\,\hat{\imath} + y\,\hat{\jmath}) = x\,A\hat{\imath} + y\,A\hat{\jmath}$$

落点只剩两个未知量，代入即得公式 $ax+by,\ cx+dy$。反过来说，凡是不遵守这两条规则的"搬运"（比如把所有点都吸到原点的漩涡），都无法写成 2×2 矩阵。"线性"二字正是线性代数的名字来源。

</details>
