# 投影：沿光线量影子

## 1. 从一个场景开始

正午的太阳悬在头顶，你的影子缩在脚边；傍晚阳光斜掠，影子被拖出去老长。影子的长短由什么决定？由**光的方向**和你**站的位置**共同决定。

数学家看影子看出了门道：影子是一支箭头（你到原点的位移 $\vec{u}$）在另一个方向（光线方向 $\vec{v}$）上**真正生效的那部分**。把它精确算出来，你就拿到了"最佳近似"这台机器的核心零件——数据拟合、噪声过滤，用的都是它。

## 2. 直觉解释

把 $\vec{u}$ 拆成两个互相垂直的部分：

$$\vec{u} = \underbrace{(\text{沿 } \vec{v} \text{ 的部分})}_{\text{影子}} + \underbrace{(\text{垂直于 } \vec{v} \text{ 的部分})}_{\text{不沾边的余量}}$$

影子部分和 $\vec{v}$ 指向同一条直线，所以它必然等于"某个倍数 × $\vec{v}$"。整个问题就缩成一件事：**求这个倍数 $t$**。

$t$ 怎么定？用前面学过的点积当裁判。$\vec{u}$ 与 $\vec{v}$ 越合拍（夹角越小），$\vec{u}\cdot\vec{v}$ 越大，$t$ 就越大；完全垂直时裁判打 0 分，影子消失；钝角时得负分，影子甩到 $\vec{v}$ 的反方向去。唯一还要修正的是 $\vec{v}$ 自身的长短——所以分母除掉一个 $\lvert\vec{v}\rvert^2$ 把它归一化。

## 3. 正式定义

向量 $\vec{u}$ 在非零向量 $\vec{v}$ 方向上的**投影**定义为：

$$\text{proj}_{\vec{v}}\,\vec{u} \;=\; \frac{\vec{u}\cdot\vec{v}}{\vec{v}\cdot\vec{v}}\;\vec{v}$$

分步拆解，一共三步：

| 步骤 | 算什么 | 公式 |
| --- | --- | --- |
| ① | 合拍程度 | $\vec{u}\cdot\vec{v} = u_xv_x + u_yv_y$ |
| ② | 归一化系数 | $t = \dfrac{\vec{u}\cdot\vec{v}}{\vec{v}\cdot\vec{v}} = \dfrac{\vec{u}\cdot\vec{v}}{\lvert\vec{v}\rvert^2}$ |
| ③ | 缩放成影子 | $\text{proj} = t\cdot\vec{v}$ |

符号表：$t$ 是标量系数，含义"$\vec{u}$ 相当于几份 $\vec{v}$"；投影结果是与 $\vec{v}$ 平行的向量；差向量 $\vec{u}-\text{proj}$ 与 $\vec{v}$ 垂直——这恰是点积判垂直的用武之地，也是下一节"最佳近似"的全部秘密。

## 4. 分步例题

**例**：求 $\vec{u}=(5,0)$ 在 $\vec{v}=(1,2)$ 方向上的投影。

1. 步骤①：$\vec{u}\cdot\vec{v} = 5\times1 + 0\times2 = 5$；
2. 步骤②：$\vec{v}\cdot\vec{v} = 1\times1 + 2\times2 = 5$，故 $t = \dfrac{5}{5} = 1$；
3. 步骤③：$\text{proj} = 1\times(1,2) = (1,2)$；
4. 几何检查：$(5,0)$ 沿东北向的 $(1,2)$ 放倒，落点 $(1,2)$ 到 $(5,0)$ 的连线 $(4,-2)$ 与 $\vec{v}=(1,2)$ 点积 $=4-4=0$ ✓ 垂直，说明影子放对了地方。

## 5. 动手实验

### 实验 1（viz）：盯住那截橙色影子

```viz
{
  "type": "projection",
  "title": "投影 = 直线上的最佳近似",
  "u": [5, 0],
  "v": [1, 2]
}
```

怎么玩：拖动蓝色 $\vec{u}$ 或绿色 $\vec{v}$。橙色粗段是投影，红色虚线是误差。盯着右上角“误差长度”：只有垂足能让它最小；把 $\vec{u}$ 拖到与 $\vec{v}$ 垂直时，影子缩成原点，误差长度等于 $\lvert\vec{u}\rvert$。“最佳近似”不再是一句抽象话，而是这条红虚线的最短时刻。

### 实验 2（python）：三步流水线算影子

```python title="投影计算器：点积 → 系数 → 缩放"
import math   # 本块其实只做加减乘除，math 只是老朋友打个招呼

# sliders: ux=5 [-6:6:1], uy=0 [-6:6:1], vx=1 [-3:3:1], vy=2 [1:3:1]

u = [ux, uy]                          # 被照射的箭头
v = [vx, vy]                          # 影子躺下的方向

dot_uv = u[0] * v[0] + u[1] * v[1]    # 第一步：u·v
vv = v[0] * v[0] + v[1] * v[1]        # 第二步的分母：v·v = |v|²
if vv == 0:                           # if 兜底：零向量没有方向，不能当投影目标
    print("v 是零向量，无法投影")
else:
    t = dot_uv / vv                   # 系数：u 相当于几份 v
    proj = []                         # 第三步：t 份 v 拼成影子
    for c in v:
        proj.append(t * c)
    print(f"系数 t = {round(t, 3)}")
    print("影子 =", round(proj[0], 2), round(proj[1], 2))
```

怎么玩：默认参数正是例题，$t=1.0$、影子 $(1.0,\ 2.0)$。把 `uy` 滑到 $\pm3$ 看 $t$ 变号；把 `vx` 设为 $0$、`vy` 保持 $2$，再让 `ux` 归零——垂直惨案现场，影子当场蒸发。

### 快问快答

```quiz
u=(3,4) 在 v=(2,0) 方向上的投影系数 t 是多少？
- 1.5 [*]
- 3
- 6
? u·v=6，v·v=4，t=6÷4=1.5。分母是模的平方——因为系数的单位是"整支 v"，不是"单位长度"。
```

:::warning[常见误区]

**误区一**："你以为公式分母是 $\lvert\vec{v}\rvert$。" 其实是 $\lvert\vec{v}\rvert^2 = \vec{v}\cdot\vec{v}$。分子 $\vec{u}\cdot\vec{v}$ 里已经藏着一个 $\lvert\vec{v}\rvert$，除掉平方后剩下的才是纯粹的"几份"。

**误区二**："你以为影子永远朝 $\vec{v}$ 的正方向。" 其实 $t<0$ 完全合法：夹角为钝角时，影子甩到 $\vec{v}$ 的反方向——负号就是方向的口令。

**误区三**："你以为垂直时还剩一点小影子。" 其实一丝都不剩：$t$ 精确等于 $0$。垂直成分与 $\vec{v}$ 方向彻底无关，这正是"分解"的价值所在。

:::

## 6. 练习

**练习 1**：概念题——为什么说"投影是 $\vec{u}$ 在 $\vec{v}$ 方向上的最佳近似"？如果不用垂足而随便取 $\vec{v}$ 上一点当近似，会发生什么？

<details>
<summary>点开查看逐步解答</summary>

从 $\vec{u}$ 减去任何"候选近似"会得到误差向量；只有候选取到垂足（即投影）时，误差才与 $\vec{v}$ 垂直、长度最短——偏离垂足越远，斜着量的误差越长。第 6 章 fit 组件里直线追着数据点跑、让总误差最小，追的就是同一个"垂足"。
</details>

**练习 2**：求 $\vec{u}=(5,0)$ 在 $\vec{v}=(1,2)$ 方向上的投影系数 $t$，打印出来应正好是 `1.0`。下面的代码能跑但结果不对，改到通过：


**练习 3**：把 $\vec{u}=(-2, 1)$ 投影到 $\vec{v}=(1,2)$ 上，并写出"影子 + 余量 = 原向量"的分解式。

<details>
<summary>点开查看逐步解答</summary>

$\vec{u}\cdot\vec{v} = -2+2 = 0$，所以 $t=0$，影子是零向量 $(0,0)$；余量就是 $\vec{u}$ 自己——它与 $\vec{v}$ 本来就垂直，一点"合拍成分"都提不出来。
</details>

## 7. 选读：最小二乘的内核就是投影

<details>
<summary>选读 · 一维情形：拟合直线 = 找一次投影</summary>

第 6 章 fit 组件玩过的游戏：给一堆散点，找最贴的直线。先看最简版本——过原点的直线 $y=kx$。把所有点的横坐标收进向量 $\vec{x}=(x_1,\dots,x_n)$，纵坐标收进 $\vec{y}$。取定 $k$ 后，误差向量是 $\vec{e} = \vec{y} - k\vec{x}$，总平方误差就是 $\lvert\vec{e}\rvert^2$。

什么时候 $\lvert\vec{e}\rvert^2$ 最小？直觉部分已经剧透：误差与 $\vec{x}$ **垂直**的时候。理由：若 $\vec{e}$ 还带着沿 $\vec{x}$ 的成分，把 $k$ 微调一点就能削掉它，误差还能更小；只剩垂直分量时，任何微调都只会添乱（勾股定理保证 $\lvert\vec{e}\rvert^2 = \lvert\text{垂直分量}\rvert^2 + \lvert\text{新添的}\rvert^2$）。于是令 $(\vec{y}-k\vec{x})\cdot\vec{x} = 0$，解出：

$$k = \frac{\vec{x}\cdot\vec{y}}{\vec{x}\cdot\vec{x}}$$

眼熟吗？这就是投影系数 $t$ 的公式！所谓"最优拟合直线的斜率"，不过是把 $\vec{y}$ 投影到 $\vec{x}$ 上的比例。多元回归、信号去噪，全是同一招在高维的重演——你在本章攒下的每件工具，届时都会重新上场。

</details>
