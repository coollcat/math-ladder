# 矩阵乘法：动作的接力

## 1. 从一个场景开始

游戏角色"边转身边跳跃"过独木桥，引擎要对几万个顶点连做两个动作：先剪切、再旋转。照[上一课](./30-matrix.md)的办法，每个点都得 apply 两次——两份配方，两遍搬运。能不能把两份配方**合并成一份**，一步到位？

能，而且合并的算术就是本课的主角：**矩阵乘法**。它不是"把数字乘起来"那么简单，而是"把两个动作接成一棒接力"。30 课实验 3 埋下的悬念——AB 到底怎么算——现在正式兑现。

## 2. 直觉解释：先盯住两支基箭头

复合动作"先 B 后 A"作用在整个平面上。想知道它等于哪个矩阵，只需要老办法：**盯住两支基箭头**。

- 纵向基箭头 $\hat{\jmath} = (0, 1)$ 先被 B 搬走：落到 B 的**第二列**上；
- 紧接着 A 再搬一次：把"B 的第二列"当作一个普通向量，用 A 搬——落点就是复合动作下 $\hat{\jmath}$ 的最终去向。

于是复合矩阵的每一列都有了清晰身份：

$$AB \text{ 的第 } j \text{ 列} = A \text{ 作用于 } B \text{ 的第 } j \text{ 列}$$

"先 B 后 A"记作 $AB$（从右往左读，就像函数 $f(g(x))$ 先算里面）。矩阵乘法根本不用死背表格——每一列都是一次"矩阵乘向量"，而那是上一课练熟的手艺。

## 3. 正式定义

设 $A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$，$B = \begin{pmatrix} e & f \\ g & h \end{pmatrix}$，定义矩阵乘法：

$$AB = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\begin{pmatrix} e & f \\ g & h \end{pmatrix} = \begin{pmatrix} ae + bg & af + bh \\ ce + dg & cf + dh \end{pmatrix}$$

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $AB$ | 复合矩阵 | "先做 B、再做 A"这一接力动作的合账 |
| $A$ 的第 $i$ 行 · $B$ 的第 $j$ 列 | 填格规则 | 对应相乘再相加，结果填进 $AB$ 的第 $i$ 行第 $j$ 列 |
| 读法 | 顺序约定 | 从右往左读：先 B 后 A |

口诀：**行乘列**——AB 的每一格 = A 的一行与 B 的一列做点积。检验一致性：第 1 列 $A\begin{pmatrix} e \\ g \end{pmatrix}$ 用上一课公式算，得 $\begin{pmatrix} ae+bg \\ ce+dg \end{pmatrix}$，正是展开式的第一列。

## 4. 分步例题：把 30 课的两步合成一步

取剪切矩阵 $S = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$ 和左转矩阵 $R = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$，合成"先剪切、后旋转"。

1. 认顺序：先 S 后 R，写成 $RS$（R 在左、S 在右）；
2. 第 1 列：$R \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$（R 把 $\hat{\imath}$ 送去哪，第一列就是哪）；
3. 第 2 列：$R \begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} -1 \\ 1 \end{pmatrix}$；
4. 合账：$RS = \begin{pmatrix} 0 & -1 \\ 1 & 1 \end{pmatrix}$。

验货：拿点 $(1, 0)$ 试——一步搬运 $RS\begin{pmatrix}1\\0\end{pmatrix} = \begin{pmatrix}0\\1\end{pmatrix}$；分步搬运先 $S$ 后 $R$ 也是 $\begin{pmatrix}0\\1\end{pmatrix}$。与 30 课实验 3 的第一个输出完全一致：**合成矩阵就是接力动作的合账本**。反过来先 R 后 S 合出的账是 $SR = \begin{pmatrix} 1 & -1 \\ 1 & 0 \end{pmatrix}$——两本账不同，这就是"AB ≠ BA"。

怎么玩：第一张是 $RS$（先剪切后旋转），第二张是 $SR$（先旋转后剪切）——正是例题手算出的两本合账。网格与小房子的形状肉眼可见地不同：**顺序不同，合成的动作就不同**。你也可以拖滑杆自己合账：先在心里算好 $R \cdot S$ 每一格，再拖出来对答案。

### 实验 2（python）：三重循环合账 + det 接力彩蛋

```python title="矩阵乘矩阵：行乘列的逐格记账"
S = [[1, 1], [0, 1]]                 # 剪切：横向越高层越歪（30 课登场过）
R = [[0, -1], [1, 0]]                # 左转 90°

def matmul(A, B):
    # 矩阵乘矩阵：AB 的 (i, j) 格 = A 的第 i 行与 B 的第 j 列的对应相乘再相加
    C = []                           # 合账本从空列表开始攒
    for i in range(2):               # 扫过 A 的两行
        row = []
        for j in range(2):           # 扫过 B 的两列
            total = 0
            for k in range(2):       # A 的第 i 行与 B 的第 j 列对应相乘
                total = total + A[i][k] * B[k][j]
            row.append(total)        # append：把这一格的账记进行里
        C.append(row)                # 整行装进合账本
    return C

def apply(M, v):
    # 矩阵乘向量：每个分量 = M 的一行与 v 对应相乘再相加（上一课的手艺）
    return [M[0][0] * v[0] + M[0][1] * v[1],
            M[1][0] * v[0] + M[1][1] * v[1]]

p = [1, 0]                           # 试金石小点
print(matmul(R, S))                          # 合账：先剪切后旋转
print(apply(R, apply(S, p)))                 # 分步：两棒接力
print(apply(matmul(R, S), p))                # 合账后一步到位

def det2(M):
    # 二阶行列式 ad − bc：面积缩放倍数（30 课误区三）
    return M[0][0] * M[1][1] - M[0][1] * M[1][0]

A = [[2, 0], [0, 3]]                 # 横 ×2 纵 ×3：面积放大 6 倍
B = [[5, 0], [0, 2]]                 # 横 ×5 纵 ×2：面积放大 10 倍
print(det2(A), det2(B), det2(matmul(A, B)))   # 6 10 60——面积接力：6 × 10 = 60
```

怎么玩：三行输出环环相扣——合账本、两棒接力、一步到位，落点完全一致；`matmul(R, S)` 打印的正是例题手算的 `[[0, -1], [1, 1]]`。彩蛋里 det(AB) = 60 = 6 × 10：面积倍率也接力（选读给理由）。

### 快问快答

```quiz
矩阵乘积 AB 的第二列等于什么？
- A 的第二列乘 B 的第二列
- A 作用于 B 的第二列（A 乘上 B 的第二列） [*]
- B 作用于 A 的第二列
? 合账先读右边的 B：B 先把 j 搬到自己的第二列，A 再搬一次——AB 的第 j 列就是 A 作用于 B 的第 j 列。
```

::::warning[常见误区]

**误区一**："你以为 AB 和 BA 是一回事。" 就算都是 2×2 方阵，两本合账也通常不同——例题里 $RS \neq SR$。"动作"的先后不可随意调换，就像先穿袜子再穿鞋换不得。

**误区二**："你以为 AB 是'先 A 后 B'。" 记号从右往左读：$AB$ 是**先 B 后 A**，和 $f(g(x))$ 先算 $g$ 一个道理。读反了，合成矩阵整个错位。

**误区三**："你以为行乘列可以随便配。" 必须是 A 的**行**配 B 的**列**——A 的行里每个元素与 B 的列里对应位置的元素相乘再相加。拿 A 的列去配 B 的行，算出来的格子整个是错的。

::::

**练习 1**：算出"先缩放后左转"的合账 $R \cdot S$（$S$ 横向 ×2 纵向 ×3）。下面的代码能跑但有一格抄错，改到通过：

# @title: 练习：合成先缩放后左转
# @check: 0 -3
# @check: 2 0
# @hint: RS 的 (i, j) 格 = R 的第 i 行与 S 的第 j 列对应相乘再相加；对照例题的四步，检查最后一行用的行和列对不对
S = [[2, 0], [0, 3]]    # 缩放：横向 ×2、纵向 ×3
R = [[0, -1], [1, 0]]   # 左转 90°

RS = [[0, 0], [0, 0]]   # 合账本：先剪切后……不对，先缩放后左转
RS[0][0] = R[0][0]*S[0][0] + R[0][1]*S[1][0]   # R 的第 1 行 · S 的第 1 列
RS[0][1] = R[0][0]*S[0][1] + R[0][1]*S[1][1]   # R 的第 1 行 · S 的第 2 列
RS[1][0] = R[1][0]*S[0][0] + R[1][1]*S[1][0]   # R 的第 2 行 · S 的第 1 列
RS[1][1] = R[1][0]*S[0][0] + R[1][1]*S[1][1]   # ← 抄错了：请按行乘列的规矩改

**练习 2**：等比缩放 $A = \begin{pmatrix} 3 & 0 \\ 0 & 3 \end{pmatrix}$ 和 $B = \begin{pmatrix} 2 & 0 \\ 0 & 2 \end{pmatrix}$，AB 与 BA 相等吗？

<details>
<summary>点开查看逐步解答</summary>

$AB = \begin{pmatrix} 6 & 0 \\ 0 & 6 \end{pmatrix} = BA$。两个都是"原地等比放大"，先放大几倍再放大几倍，与先后无关。可交换是**特例**：均匀缩放之间、以及旋转与同一角度的均匀缩放之间才互不吵架；一般动作（比如剪切、非均匀缩放）一掺和，顺序立刻要紧——第 11 章实战挑战的精灵变形台就是现成的例子。
</details>

**练习 3**：证明对任意向量 $\vec{v}$ 都有 $(AB)\vec{v} = A(B\vec{v})$。

<details>
<summary>点开查看逐步解答</summary>

按列读：$\vec{v} = x\hat{\imath} + y\hat{\jmath}$。$(AB)\vec{v}$ 把 $\vec{v}$ 拆成两份基箭头，各乘上 AB 的对应列；而 AB 的第 $j$ 列定义为 $A(B$ 的第 $j$ 列$)$，所以每一份都等于"A 搬完 B 搬过的箭头"——恰好是 $A(B\vec{v})$ 的展开。两边逐分量核对（$ae+bg$ 出现在同一格）即可收工。这条等式说明"合账"不是巧合，而是接力动作的本义。
</details>

## 7. 选读：行列式接力与方阵的幂

<details>
<summary>选读 · det(AB) = det(A)·det(B) 与 P^k</summary>

**面积接力**：$\det$ 是面积缩放倍数。先做 B（面积乘 $\det B$），再做 A（面积再乘 $\det A$），两步合起来的倍率自然是 $\det A \cdot \det B$——实验 2 彩蛋里 6 × 10 = 60 就是这条规律的数值版。行列式从"四数的算式"升级成"接力的账本"。

**同一动作连做**：$A$ 自己乘自己记作 $A^2$，连做 k 次记作 $A^k$——"每走一步转 10°"连走 36 步就是 $R^{36}$，恰好转一整圈回到原地。方阵的幂在数据的长期行为（比如第 37 章随机游走的平稳分布、第 21 章矩阵幂课）里是常客，这里先埋一颗种子。

**AB = I 的悬念**：如果接力后每根箭头都原路回家（$AB = I$，其中 $I$ 是"不动如山"的单位矩阵：对角线为 1、其余为 0，乘谁都不改变谁），B 就是 A 的"撤销键"。什么时候存在撤销键、怎么求它，涉及新的地盘——[45 课](./45-inverse-matrix.md)给撤销键正式出生（40 课选读先补方向感），这里只记一个念头：撤销键的存在性由 $\det$ 把守，$\det = 0$ 时平面被压扁，去路和回路都断了。

</details>
