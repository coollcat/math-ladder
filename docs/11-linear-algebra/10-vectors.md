# 向量：既有大小又有方向的量

## 1. 从一个场景开始

从家到学校，导航说"步行 800 米"。可如果你照着这 800 米随便挑个方向走，大概率到不了校门口——你还需要**朝哪边走**。

"走了多远"叫路程，一个数就够；"往哪走、走多远"叫位移，必须两个信息一起说。天气预报里"东风 5 级"、游戏里角色的"朝向与速度"，都是这种成双成对的量。数学家给它们起了名字：**向量**。这一章，我们要让整张平面都听向量的话。

## 2. 直觉解释

把位移画成一支箭头：箭头指向哪里，就是方向；箭头多长，就是大小。

一支从你家出发的箭头，平移到从邻居家出发——指的方向没变、长度没变，所以它还是**同一支**向量。向量只认两件事：大小和方向；起点在哪，它根本不在乎。

怎么用数把箭头写下来？借一张方格纸，约定"向东为正 $x$、向北为正 $y$"。于是"向东 3 步、向北 1 步"记作：

$$(3,\ 1)$$

这两个数叫**分量**——像点菜的配方：横向几份、纵向几份。任何箭头，只要报出这两个数，就完全确定了。

## 3. 正式定义

**向量**（vector）是既有大小又有方向的量，二维情形写作 $\vec{u} = (u_x, u_y)$。只表示大小的单个数（如温度）叫**标量**（scalar），用来和向量划清界限。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\vec{u}, \vec{v}$ | 向量 | 一支箭头，由分量 $(u_x, u_y)$ 确定 |
| $u_x, u_y$ | 分量 | 横向、纵向各走多少 |
| $\lvert \vec{u} \rvert$ | 模（长度） | 箭头长度，$\sqrt{u_x^2 + u_y^2}$（勾股定理） |
| $k$ | 标量 | 单纯的一个数 |

两种运算立刻登场：

- **加法**：$\vec{u} + \vec{v}$ = 分量各自相加。几何上，把 $\vec{v}$ 的尾巴接到 $\vec{u}$ 的头上（首尾相接）；或者画平行四边形取对角线——两种画法落点相同。

$$\vec{u}+\vec{v} = (u_x+v_x,\ u_y+v_y)$$

- **数乘**：$k \cdot \vec{u}$ = 分量各自乘 $k$。几何上把箭头拉长或压缩 $k$ 倍；$k<0$ 时还要掉头。

$$k\cdot\vec{u} = (k \cdot u_x,\ k \cdot u_y)$$

注意加法和数乘都是"老朋友"：逐分量的加法交换律、结合律原封不动地成立，因为每个分量都在做普通加法。

## 4. 分步例题

**例 1**：已知 $\vec{u} = (3, 1)$，$\vec{v} = (-1, 2)$，求 $\vec{u} + \vec{v}$。

1. 拆开分量：$\vec{u} = (3, 1)$，$\vec{v} = (-1, 2)$；
2. 横向相加：$3 + (-1) = 2$；
3. 纵向相加：$1 + 2 = 3$;
4. 合并：$\vec{u} + \vec{v} = (2, 3)$——落在平行四边形的对角线上。

**例 2**：求 $2\vec{v}$ 和 $\lvert \vec{v} \rvert$（仍用 $\vec{v}=(-1,2)$）。

1. 数乘：$2\vec{v} = (-2, 4)$，箭头拉长一倍、方向不变；
2. 模长套勾股定理：$\lvert \vec{v}\rvert = \sqrt{(-1)^2 + 2^2} = \sqrt{5} \approx 2.24$；
3. 顺便验证数乘对模的作用：$\lvert 2\vec{v} \rvert = \sqrt{20} = 2\sqrt{5}$，恰好翻倍。

## 5. 动手实验

### 实验 1（viz）：拖动箭头，看平行四边形法则

```viz
{
  "type": "vecadd",
  "u": [3, 1],
  "v": [-1, 2]
}
```

怎么玩：拖蓝色箭头 $\vec{u}$ 和绿色箭头 $\vec{v}$ 的端点，虚线自动补出平行四边形，紫色粗箭头永远是和向量 $\vec{u}+\vec{v}$。试着让 $\vec{v}=-\vec{u}$——和缩成了零向量，两支箭头互相抵消。

### 实验 2（python）：用列表表示向量——先踩坑，再自己造加法

```python title="列表当向量：+ 号的第一个坑"
u = [3, 1]    # 用列表表示向量：第 0 个元素是 x 分量，第 1 个是 y 分量
v = [-1, 2]

print(u + v)   # 直接用 + 相加？看看会发生什么
```

跑出来是 `[3, 1, -1, 2]`——四个数！在 Python 里，**列表的 `+` 是首尾拼接，不是分量相加**。数学课的"+"到了 Python 列表这里换了含义，这个坑必须绕过去。想真正做向量加法，得自己动手：

```python title="手写 vector_add：逐分量相加"

def vector_add(a, b):              # def 定义函数（第 0 章约定四）：接收两个向量
    result = []
    for i in range(len(a)):        # len(a) 是分量个数；range 给出下标 0、1
        result.append(a[i] + b[i]) # a[i] 取第 i 个分量；append 把结果追加进列表
    return result                  # return 把结果交还给调用者

u = [3, 1]
v = [-1, 2]
print(vector_add(u, v))            # 这才是真正的 u+v
print(vector_add([1, 2], [3, 4]))  # 对照实验 2 第一块：不再是拼接
```

### 实验 3（python）：数乘与模长

```python title="伸缩箭头，丈量长度"
import math   # math 库是老熟人（第 3 章起）

# sliders: k=0.5 [-2:2:0.25]

v = [3, -4]                        # 先算好这条原始箭头
scaled = []                        # 准备装数乘结果的空列表
for c in v:                        # c 依次是 v 的每个分量
    scaled.append(k * c)           # 每个分量都乘上 k

length = math.hypot(v[0], v[1])    # hypot：直角边求斜边，即 √(x²+y²)
new_len = math.hypot(scaled[0], scaled[1])
print(f"k={k}: {k}*v = {scaled}")
print(f"原长 {length} -> 新长 {round(new_len, 2)}")
```

怎么玩：拖滑杆改 $k$。$k=1$ 不变，$k=0$ 缩成零向量，$k=-1$ 长度不变但掉头；新长度永远等于 $|k|$ 乘以原长 5。

### 快问快答

```quiz
(3, 1) 加 (-1, 2) 等于多少？
- (4, -1)
- (2, 3) [*]
- (-3, 2)
? 横纵各加各的：x 为 3+(-1)=2，y 为 1+2=3。几何上这就是平行四边形对角线的落点。
```

:::warning[常见误区]

**误区一**："你以为 Python 里 `u + v` 就是向量加法。" 其实列表的 `+` 是**拼接**：`[1,2]+[3,4]` 得 `[1,2,3,4]`，四个分量，根本不是 `(4,6)`。要分量相加，请手写循环（就像本课的 `vector_add`）。

**误区二**："你以为向量有固定起点。" 其实起点无关紧要——只要大小、方向相同，就是同一个向量。$(3,1)$ 从原点出发还是从 $(10,7)$ 出发，都是那支箭头。

**误区三**："你以为负数倍只是换个长度。" 其实 $k<0$ 时除了长度变 $|k|$ 倍，方向还会**反转**：$-1 \cdot \vec{v}$ 就是把箭头掉个头。

:::

## 6. 练习

**练习 1**：判断题——"两支箭头长度相等，它们一定是同一个向量。"用一句话反驳或支持。

<details>
<summary>点开查看逐步解答</summary>

不支持。向量由大小**和**方向共同决定：向东 3 步与向北 3 步等长，却是两支不同的箭头。只有模相等不能保证向量相等。
</details>

**练习 2**：算出 $\vec{u}=(3,-1)$ 与 $\vec{v}=(2,5)$ 的和，按 `"5 4"` 的格式打印（x 与 y 之间空一格）。下面的代码能跑但结果不对，修到通过为止：

**练习 3**：轮船在静水中速度为向东 $4$ km/h，水流速度为向南 $3$ km/h，船实际朝哪个方向、多快？

<details>
<summary>点开查看逐步解答</summary>

两个速度都是向量，实际速度 = 船速 + 水速 $= (4, -3)$。大小 $\sqrt{4^2+3^2}=5$ km/h（经典 3-4-5 直角三角形），方向东偏南，角度 $\arctan(3/4)\approx36.9°$。首尾相接法则在真实河流里照样管用。
</details>

## 7. 选读：从大小和方向反推分量

<details>
<summary>选读 · 极坐标视角：一根箭头的两套身份证</summary>

前面我们用分量 $(x, y)$ 描述箭头；其实也可以用"长度 $\times$ 角度"描述它，两套证件可以互办签证。设箭头长 $r$、与 $x$ 轴夹角为 $\theta$（逆时针为正）。把它放到单位圆的语言里（第 7 章）：斜边为 $r$ 的直角三角形中，

$$x = r\cos\theta, \qquad y = r\sin\theta, \qquad r=\sqrt{x^2+y^2}, \qquad \tan\theta = y/x$$

验证一组：$r=2$、$\theta = 60° = \pi/3$ rad 时，$x = 2\times\tfrac12 = 1$，$y = 2\times\tfrac{\sqrt3}{2} = \sqrt3 \approx 1.73$。反过来用勾股定理收回长度：$\sqrt{1^2+(\sqrt3)^2} = 2$ ✓。这套"角度身份证"在第 12 章复数、第 16 章傅里叶变换里都会反复出场——先混个脸熟即可。

</details>

## 8. 下一站

向量会加了、会缩放了，可两个向量之间还没有"乘法"。数学家真的发明了一种乘法：它不输出箭头，只输出**一个数**——方向一致时是正的，垂直时是零，相反时是负的，连夹角都被它顺手编码了进去。图形学里的光照、机器学习里的相似度，全靠这一个数打分。
