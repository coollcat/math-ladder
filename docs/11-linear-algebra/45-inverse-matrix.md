# 逆矩阵：撤销键的出生课

## 1. 从一个场景开始

游戏里手一抖，把精灵转错了方向、还放大错了倍数——幸亏有 Ctrl+Z，一按回到从前。文档删错一段有撤销键，图片修坏了有撤销键，那[矩阵](./30-matrix.md)呢？矩阵是对整个平面动手脚的配方，把几千个顶点一次性搬了家——它配不配拥有一枚撤销键？

[矩阵乘法那一课](./35-matrix-multiplication.md)的选读埋过这个念头：如果接力后每根箭头都原路回家（$AB = I$），B 就是 A 的"撤销键"，只是当时说"本站暂不展开"。今天兑现承诺：撤销键什么时候存在、长什么样、以及它为什么会失灵。

## 2. 直觉解释：把动作倒放

撤销的原理从来只有一条：**反着做一遍**。加法的撤销是减法，乘法的撤销是除法；矩阵是动作，撤销就是把动作**倒放**。

倒放怎么做？还是 30 课的老办法：**盯住两支基箭头**。$A$ 把 $\hat{\imath}$ 搬到了哪，$A^{-1}$ 就得负责把它送回 $(1, 0)$；$\hat{\jmath}$ 同理。两个去向一定，整个倒放配方就锁定了。

看个现成的例子：$A = \begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}$ 把 $\hat{\imath}$ 送到 $(2, 0)$、把 $\hat{\jmath}$ 送到 $(0, 3)$——横向拉长 2 倍、纵向拉长 3 倍。倒放它：

- 把 $(2, 0)$ 送回 $(1, 0)$：横向**除以 2**；
- 把 $(0, 3)$ 送回 $(0, 1)$：纵向**除以 3**。

于是撤销键是 $A^{-1} = \begin{pmatrix} 0.5 & 0 \\ 0 & \tfrac13 \end{pmatrix}$。接力验算：先 $A$ 后 $A^{-1}$，$\hat{\imath}$ 从 $(1,0)$ 出发先到 $(2,0)$ 再回 $(1,0)$——每根箭头都原路回家，平面纹丝不动。

## 3. 正式定义

先给"什么都不做"正式命名：**单位矩阵** $I = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$（35 课选读露过面），乘谁都不改变谁——动作世界的"原地待命"。

**逆矩阵**：若存在矩阵 $B$ 使 $AB = BA = I$，则称 $A$ **可逆**，$B$ 记作 $A^{-1}$。对 2×2 矩阵，撤销键有现成公式：

$$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}, \qquad A^{-1} = \frac{1}{ad - bc}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix} \quad (ad - bc \neq 0)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $I$ | 单位矩阵 | 对角线为 1、其余为 0；"原地待命"动作 |
| $A^{-1}$ | 逆矩阵 | A 的撤销键：先 A 后 $A^{-1}$，一切原路回家 |
| $\det A = ad - bc$ | 行列式 | 撤销键的资格守门员：为 0 则撤销键不存在 |

口诀：**对角互换、副对角变号，再统一除以行列式**。守门员的铁律立在下节：$\det = 0$ 时公式当场爆炸（除以零），撤销键根本不存在——那时 $A$ 把整个平面压扁成一条线，无数不同的点挤到同一处，倒放时根本不知道谁该回谁家。

## 4. 分步例题

**例 1**：求 $A = \begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}$ 的逆，并逐格验算。

1. 算守门员：$\det A = 2\times3 - 0\times0 = 6 \neq 0$，有资格；
2. 套公式：$A^{-1} = \dfrac16 \begin{pmatrix} 3 & 0 \\ 0 & 2 \end{pmatrix} = \begin{pmatrix} 0.5 & 0 \\ 0 & \tfrac13 \end{pmatrix}$；
3. 验算四格（行乘列，30 课手艺）：$2\times0.5 = 1$；$3\times\tfrac13 = 1$；两个交叉格全为 $0$——$A A^{-1} = I$ ✓；
4. 几何读法：横拉 2 倍的撤销是横除 2，纵拉 3 倍的撤销是纵除 3——与直觉分毫不差。

**例 2**：求剪切配方 $A = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$ 的逆。

1. 守门员：$\det A = 1\times1 - 1\times0 = 1$；
2. 套公式：$A^{-1} = \begin{pmatrix} 1 & -1 \\ 0 & 1 \end{pmatrix}$；
3. 验算第一行第二格：$1\times(-1) + 1\times1 = 0$ ✓（其余三格同样逐格归位为 $I$）；
4. 几何读法：剪切把房子的顶往右推歪（底边不动），撤销键就是把顶往左推回——推歪多少，推回多少。

## 5. 动手实验

### 实验 1（viz）：正放与倒放，一对镜像配方

```viz
{
  "type": "matrix",

}
```

```viz
{
  "type": "matrix",
  "a": 1, "b": -1, "c": 0, "d": 1
}
```

怎么玩：第一张是剪切 $A$（例 2），小房子的顶被推向右边；第二张是 $A^{-1}$，顶被推回左边——一对镜像配方。你可以先在心里验算 $A \cdot A^{-1}$ 的四格，再拖滑杆对答案。胆子大的话把任意一张的滑杆拧到「压扁」附近：行列式读数跌向 $0$，想象一下"把压扁的世界复原"为什么注定做不到。

### 实验 2（python）：inv2 出厂检验

```python title="inv2：撤销键制造机"

A = [[2, 0], [0, 3]]   # 例 1 的缩放配方

def inv2(M):
    # 2×2 逆矩阵公式：对角互换、副对角变号，再统一除以行列式
    a = M[0][0]
    b = M[0][1]
    c = M[1][0]
    d = M[1][1]
    det = a * d - b * c            # 行列式：撤销键的资格守门员
    return [[d / det, -b / det], [-c / det, a / det]]

def matmul(A, B):
    # 矩阵乘矩阵：AB 的每格 = A 的一行与 B 的一列对应相乘再相加（35 课的手艺）
    C = []
    for i in range(2):
        row = []
        for j in range(2):
            total = 0
            for k in range(2):
                total = total + A[i][k] * B[k][j]
            row.append(total)
        C.append(row)
    return C

Ainv = inv2(A)
print(Ainv)                    # [[0.5, 0.0], [0.0, 0.3333333333333333]]：横除 2、纵除 3

check = matmul(A, Ainv)        # 出厂检验：A 搬过去，A⁻¹ 搬回来
for i in range(2):
    print(round(check[i][0], 3), round(check[i][1], 3))   # 1.0 0.0 / 0.0 1.0：正是 I
```

两行检验输出 $1.0\ 0.0$ 与 $0.0\ 1.0$——接力回到原点，公式通过出厂检验。换 $A = [[1, 1], [0, 1]]$（例 2 的剪切）再跑一遍，机器照样归位。

### 实验 3（python）：把 det 拧向 0，撤销键的悬崖

```python title="行列式趋近 0 时，撤销键元素爆炸"

def inv2(M):
    # 同实验 2 的公式（每个代码块是独立槽位，工具要随身携带）
    a = M[0][0]
    b = M[0][1]
    c = M[1][0]
    d = M[1][1]
    det = a * d - b * c
    return [[d / det, -b / det], [-c / det, a / det]]

# sliders: k=0.5 [0:1:0.05]

A = [[1, 1], [1, 1 + k]]       # 这一族配方的行列式恰好等于 k
det = A[0][0] * A[1][1] - A[0][1] * A[1][0]
print(det)

if det >= 0.05:
    Ainv = inv2(A)
    print(round(Ainv[0][0], 1), round(Ainv[0][1], 1))
    print(round(Ainv[1][0], 1), round(Ainv[1][1], 1))
else:
    print("det≈0：撤销键当场失效")
```

怎么玩：默认 $k=0.5$，撤销键是 $3.0\ {-2.0}$ 与 ${-2.0}\ 2.0$，还算温和。把滑杆拧向 $0$：元素一路飙升（$k=0.05$ 时已经涨到 $21.0$ 与 $20.0$）；拧到 $0$，公式除以零、守门员拦下一切——**逆矩阵元素的爆炸就是"平面正在被压扁"的数值警报**（21 章的"条件数"会把这条悬崖修成正式景点）。

### 快问快答

```quiz
矩阵 [[2, 4], [1, 2]] 有没有撤销键？
- 有，把每个元素都取倒数就行
- 没有：行列式为 0，平面被压扁了 [*]
- 有，但需要解方程慢慢找
? det = 2×2 − 4×1 = 0。两列都是 (1, 2) 方向，全平面被压到同一条直线上——倒放时无从分辨谁回谁家，撤销键不存在。
```

::::warning[常见误区]

**误区一**："你以为任何矩阵都有逆。" 只有 $\det \neq 0$ 的矩阵才配有撤销键。$\det = 0$ 意味着平面被压扁、信息丢失——压扁前的世界无法复原，就像泼出去的水。

**误区二**："你以为求逆就是把每个元素取倒数。" 撤销键长着固定模样：对角互换、副对角变号、再除以 $\det$。"逐个取倒数"只有对角矩阵这一个特例碰巧合法。

**误区三**："你以为 $A^{-1}A$ 与 $AA^{-1}$ 会像 $AB$、$BA$ 那样给出不同结果。" 只要逆存在，两个方向的接力都恰好回到 $I$——逆矩阵是矩阵世界里少数自带"双向通行证"的对象。

::::

```exercise
# @check: 1 -1
# @check: -2 3
# @hint: 行列式是 ad − bc（面积倍率，30 课的定义），不是 ad + bc；修好 det，四格自动归位
A = [[3, 1], [2, 1]]

b = A[0][1]
c = A[1][0]
d = A[1][1]

det = a * d + b * c      # ← 这行的加号不对劲！
inv = [[d / det, -b / det], [-c / det, a / det]]

```

**练习 2**：用两套语言（代数 + 几何）说明：为什么 $\det = 0$ 的矩阵注定没有撤销键？

<details>
<summary>点开查看逐步解答</summary>

代数：假如真有 $B$ 使 $AB = I$，两边取行列式，35 课的接力定律立刻发言：$\det(A)\cdot\det(B) = \det(I) = 1$。两个数相乘得 1，谁都别想是 0——所以 $\det A = 0$ 的矩阵连入场资格都没有。几何：$\det = 0$ 把全平面压到一条线上，$\hat{\imath}$ 和 $\hat{\jmath}$ 挤到同一个落点；倒放时看着这个落点，根本不知道该把它送回 $\hat{\imath}$ 家还是 $\hat{\jmath}$ 家——信息已经丢了，动作再也放不回去。
</details>

**练习 3**：左转 90° 的配方 $R = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$，用公式求 $R^{-1}$，并观察它和 $R$ 的长相有什么关系。

<details>
<summary>点开查看逐步解答</summary>

$\det R = 0\times0 - (-1)\times1 = 1$，套公式：$R^{-1} = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$。验算一格：$0\times0 + (-1)\times(-1) = 1$，四格归位为 $I$ ✓。看长相：$R^{-1}$ 恰好是 $R$ 沿对角线翻个面的样子（第一列竖着读变成第一行横着写）——这个动作叫**转置**，后文再正式认门。几何上一目了然：左转 90° 的撤销就是右转 90°，转角取负即可。
</details>

## 7. 选读：公式为什么会成立

<details>
<summary>选读 · 四格验算与守门员的必然性</summary>

**公式验算**：拿公式算 $A A^{-1}$，只盯第一行（第二行同理）：

$$A A^{-1} = \frac{1}{ad-bc}\begin{pmatrix} a & b \\ c & d \end{pmatrix}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix} = \frac{1}{ad-bc}\begin{pmatrix} ad-bc & -ab+ab \\ cd-cd & ad-bc \end{pmatrix} = I$$

对角线上恰好长出行列式本身，副对角线上恰好抵消为零——除以 $\det$ 后就是 $I$。$A^{-1}A$ 方向同理可验，所以双向通行证是真的。

**守门员的必然性**：不是公式"规定"了 $\det \neq 0$，而是撤销键的存在本身就逼出这条铁律——上面的反证（练习 2 的行列式接力论证）说明 $\det = 0$ 时连存在的资格都没有。30 课说"行列式为零是信息丢失的警报"，现在这句警报有了精确含义：**丢失的信息 = 无法撤销的动作**。

顺带补一句 35 课的悬念：$AB = I$ 时 $B$ 自动也是 $A$ 的撤销键，且 $BA = I$ 同样成立——对可逆方阵，"左逆"和"右逆"是同一张证件。

</details>
