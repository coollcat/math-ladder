# 自动微分与计算图重访

## 1. 从一个场景开始

气动工程师想把"升力对翼型十几个几何参数各有多敏感"列成一张表。手推偏导数意味着：每改一版模型，十几个公式全部重新推导——导数在这里是查表得到的死知识，改一个字就报废。

第 46 章已经给出解药的一半：把计算画成一张**计算图**，梯度沿图回传、流水线量产。本章把这台机器搬进科学计算车间，并补上另一半：**前向模式**——为什么它和反向模式是一对孪生兄弟、什么场合该派谁出场。

## 2. 直觉解释

计算图记住的是"谁参与了谁的计算"。在这张图上求导只有两种走法：

- **前向模式**：从入口出发，让数值和它的变化率并肩顺流而下。走完全图得到的问题是："某个输入动一小步，每个输出各跟着动多少？"
- **反向模式**：从出口出发，把"每个输出被要求变化多少"逆流分派回去。走完全图得到的问题是："任一输入动一小步，这一个汇总指标总共变多少？"

记账选择的口诀一句话：**输入少、输出多，用前向；输入多、输出少，用反向。**

深度学习面对的是百万参数挤进一个标量损失——反向模式一趟收齐全员梯度，碾压性胜出（第 46 章的主角）。科学计算里也有反过来的工况：一条光路追踪，一个入射角参数沿流水线牵动沿途几十个下游量——前向模式一趟全收，何必再逆流。

## 3. 正式定义

设映射 $F$ 把 $n$ 个输入映到 $m$ 个输出，**Jacobian 矩阵** $J$ 收纳全部一阶偏导：$J_{ij} = \partial F_i / \partial x_j$。

两个向量积给两种模式起了正式名字：

$$\text{JVP（前向）：} \; J v \qquad\qquad \text{VJP（反向）：} \; J^{\mathsf{T}} g$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $v$ | 切向量 | 给全体输入编好的一支进行曲：谁先动、动多少 |
| $g$ | 上游梯度 | 每个输出各自领到的变动指标 |
| $Jv$ | Jacobian 向量积 | 一趟前向扫出"沿 $v$ 方向，所有输出的联合变动" |
| $J^{\mathsf{T}}g$ | 反向量积 | 一趟反向扫出"$g$ 分派下来，所有输入的梯度" |

一句话版：**前向模式每趟算一个 JVP，反向模式每趟算一个 VJP。** 它们算的不是两回事，只是同一张表 $J$ 的行方向与列方向切片。

## 4. 分步例题

阻力加热模型：高速飞行器表面温升率 $q = c\,\rho\, v^3$，三个输入 $c$（阻热系数）、$\rho$（来流密度）、$v$（速度），一个输出 $q$。取 $c=0.5,\ \rho=1.2,\ v=2$。

1. 正向第一站：乘出 $\rho v^3$ 的雏形……整条链只有两次乘法，图小得可怜；
2. 全部局部斜率清点：$\partial q/\partial c = \rho v^3 = 9.6$；$\partial q/\partial\rho = c v^3 = 4.0$；$\partial q/\partial v = 3 c \rho v^2 = 7.2$；
3. **反向一遍（VJP）**：上游只给出一个指标 $\partial L/\partial q = 2$，逆流乘过去：三参数梯度一次到手 $19.2,\ 8.0,\ 14.4$；
4. **前向凑表（JVP）**：想拿满上一步的三个梯度，得分别沿 $(1,0,0)$、$(0,1,0)$、$(0,0,1)$ 跑三趟；
5. 结论：输出少输入多的本课模型天然归反向管；若反过来要沿 $v$ 扫出全航线的 $q,q^2,q^3$ 剖面，前向一趟就够。

### 实验 1：切线不是查出来的，是乘出来的

### 实验 2：差分验钞机 + 记账成本对账

```python title="数值差分 vs 链式连乘；顺便数一数谁的趟数少"
import math

c = 0.5        # 阻热系数
rho = 1.2      # 来流密度
v = 2.0        # 来流速度

def heat_rate(cc, rr, vv):            # 同一段"仿真代码"
    return cc * rr * vv ** 3          # ** 是幂运算：vv ** 3 即 vv 的三次方

eps = 0.0001                           # 微小扰动量，土办法逼近真实斜率
num_dc = (heat_rate(c+eps, rho, v) - heat_rate(c-eps, rho, v)) / (2*eps)
num_drho = (heat_rate(c, rho+eps, v) - heat_rate(c, rho-eps, v)) / (2*eps)
num_dv = (heat_rate(c, rho, v+eps) - heat_rate(c, rho, v-eps)) / (2*eps)

ana_dc = rho * v ** 3                  # ∂q/∂c：只剩 v³ 那一份
ana_drho = c * v ** 3                  # ∂q/∂ρ
ana_dv = 3 * c * rho * v ** 2          # ∂q/∂v

print("数值差分 :", round(num_dc, 3), round(num_drho, 3), round(num_dv, 3))
print("链式连乘 :", round(ana_dc, 3), round(ana_drho, 3), round(ana_dv, 3))
print("反向模式趟数: 1     前向模式凑齐全表需要: 3")
```

两组数字必须重合——这是第 46 章立下的"验钞机"纪律在多参数世界的延续。而账单右下角那行才是本章的重点：**谁 dominates，取决于输入输出的数量对比。**

### 实验 3：判题小练兵

```exercise
# @title: 练习：一趟 VJP 把责任分派到位
# @check: 19.2
# @check: 8.0
# @check: 14.4
# @hint: 上游指标统一是 2；三个局部斜率分别是 rho*v**3、c*v**3 和 3*c*rho*v**2，逐个相乘即可。
c = 0.5         # 阻热系数
rho = 1.2       # 来流密度
v = 2.0         # 来流速度
upstream = 2    # 上游梯度：总损失对输出 q 的要求

dc_local = c              # ← 问题在这：q 对 c 的斜率不是 c 本身，想想 v 去哪了
drho_local = c * v ** 3   # 已给对的示范：∂q/∂ρ
dv_local = 3 * c * rho * v ** 2

print(upstream * dc_local)
print(upstream * drho_local)
print(round(upstream * dv_local, 1))
```

修好后体会反向模式的机械感：出口只有一个数字 2，沿图乘一圈，三个方向的责任份额就自动落袋——不必对每个参数单独跑一遍仿真。

## 常见误区

:::warning[常见误区]

**误区一**："前向和反向算出来会不一样。"它们只是同一张 Jacobian 表的行列切片——答案不同只说明你把方向向量或上游梯度装错了位。

**误区二**："调用框架的 backward() 就不用懂模式选择。"科学计算常要把 VJP 接进自己的求解器循环（下一课 adjoint 就是它的化身）；选错模式，成本从一趟变百趟。

**误区三**："有自动微分了，数值差分该退休了。"差分是查账工具：任何手写敏感度代码上线前，都要像实验 2 那样跟中心差分对一遍账，误差应在 eps 的量级内。

:::

## 6. 练习

**练习 1**：手算 JVP：取切向量 $v=(1,1,0)$，问 $dq$ 沿这支进行曲变动多少？

<details>
<summary>点开查看逐步解答</summary>

就是各行偏导与 $v$ 对应相加：$9.6\times 1 + 4.0\times 1 + 7.2\times 0 = 13.6$。

前向模式里这笔加法在途中顺路完成——每个节点的伴随值都是"已走过的支路贡献之和"，这就是它与差分法的本质区别：**不重算，只携带。**
</details>

**练习 2**：把模型改成 $q = c\,\rho\, v^4$，重做一趟 VJP（上游仍是 2）。

<details>
<summary>点开查看逐步解答</summary>

局部斜率换成 $\rho v^4 = 19.2$、$c v^4 = 8.0$、$4 c \rho v^3 = 19.2$，分派后为 $38.4,\ 16.0,\ 38.4$。

指数升一阶，中间环节的局部斜率换血，但"逆流逐环相乘"的纪律纹丝不动——这正是记法可迁移的证据。
</details>

**练习 3**：概念辨析：为什么说 PINN 天生站在反向模式一边？

<details>
<summary>点开查看逐步解答</summary>

PINN 的自由度是网络参数（成千上万），而配点上打总分后进入损失的只是一个标量家族——标准的"输入多、输出少"。更妙的是不同残差项共享同一张前向图，反向还能合并记账。若反过来用前向模式对每个参数单独敏探，训练一轮回的路程就要翻几万倍。
</details>

## 7. 选读：两种模式各自的钱包

<details>
<summary>选读 · 成本与内存账</summary>

$n$ 个输入 $m$ 个输出的映射：拿满全部偏导，前向要 $n$ 趟、反向要 $m$ 趟，每趟成本约等于一遍原函数求值；深度学习 $m=1$ 所以反向独大，谱方法/地震成像里常见 $n=1$（单一扰动源）所以前向复活。内存上前向只需随身携带当前值与方向值，反向却必须存下全程中间值以便回头取局部斜率——省内存的对策叫检查点法（checkpointing）：每隔一段重存快照，回头时现场重算。本课只是点名这套账本，第 46 章实验 3 的手动链式法则就是它的最小骨架。

</details>
