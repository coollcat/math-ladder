# 科学计算与神经算子

科学机器学习处在两条传统的交汇处：一边是方程、守恒律和数值稳定性，另一边是数据和可微程序。本章研究它们何时互补，何时互相拖累。

这一章按下面的路线图推进：

1. [PINN：把物理方程写进损失函数](./10-pinn-physics-loss.md)——一根受热的金属杆，你只有三个温度传感器的读数——数据太稀，拟合出的曲线千奇百怪；
2. [逆问题与正则化](./20-inverse-problem-regularization.md)——把一杯清水倒进墨水里，瞬间扩散——正向过程顺滑无比；
3. [替代模型与降阶](./30-surrogate-reduced-order.md)——一套翼型气动仿真跑一次要 8 小时，而设计迭代需要试上万个外形——按部就班要算一个世纪；
4. [自动微分与计算图重访](./40-autodiff-revisit.md)——导数不是查表是流水线：同一张计算图，前向顺流、反向逆流，选错方向成本差百倍；
5. [Neural ODE 与连续深度](./50-neural-ode-intro.md)——把一层层展开成一条时间轴：残差网络的恒等跳跃，原来是欧拉法迈出的第一步；
6. [随机微分方程与 SDE 网络](./60-sde-networks.md)——给演化方程掺一点噪声：趋势回家，路上推搡，噪声尺度天生带根号；
7. [参数辨识与观测设计](./70-parameter-identification-design.md)——下一次测量值多少钱：先审布点与记账，再谈加钱买传感器；
8. [神经算子与函数到函数映射](./80-neural-operator-map.md)——学的不再是答案而是解法本身：把卷积搬进频率表，换网格也不认输。

## 实战挑战 · 热杆、烟羽与轨道衰减

这一章不是名词展览，而是三张真实工程账单：受热金属杆要用方程约束温度场；污染物烟羽要按流体平流推进；低轨卫星要从稀疏测高里反推阻尼。1922 年 Richardson 用纸笔做数值天气预报，6 小时预报算了约 6 周；现代方法先让方程当老师，再用廉价替身加速设计循环。

**流体切片**：四个格点的污染物浓度 $c = [3, 5, 8, 4]$，风以每小时一格的速度向右吹（最右边绕回最左边），写出一步后的新浓度数组。昂贵的真仿真在输入 1 处输出 4、在输入 3 处输出 12，据此训练的线性替身是 $y = 4x$；问它在输入 2 处的预测和绝对误差。第一小问已示范：

```exercise
# @title: 实战挑战：平流一步 + 替身误差
# @check: 4
# @check: 3
# @check: 5
# @check: 8
# @check: 1
# @hint: 周期边界右移一格 = 新数组的第 i 格取旧数组的左边邻居；替身误差 = |预测 − 真值|。
c = [3, 5, 8, 4]
new_c = [c[3], c[0], c[1], c[2]]   # 右移一格、首尾相接（周期边界）

print(new_c[0])                    # 新的第 1 格（已示范）
print()                            # ← 新的第 2 格
print()                            # ← 新的第 3 格
print()                            # ← 新的第 4 格

pred_surrogate = 5                 # ← 问题在这：替身是 y=4x，在 x=2 处应给多少？
true_value = 7                     # 真仿真给出的答案
print(abs(pred_surrogate - true_value)) # 替身误差：只看偏离幅度
```

**轨道反演切片**：一颗低轨卫星的雷达测高序列显示轨道缓慢衰减。把 380 km 参考高度之上的剩余高度近似成 $h(t)=22e^{-kt}$（单位 km，时间以天计），第 2 天测得剩余高度 20 km。下面的图默认 $k=0.05$，此时第 2 天剩余约 19.9 km，离观测的 20 km 只差一步。先拖动衰减率看轨迹，再由两个观测反推 $k$ 并预测第 10 天的总高度：

```exercise
# @title: 轨道反演：从两个测高估计衰减率
# @check: 0.048
# @check: 393.7
# @hint: 先求“剩余高度之比”，指数衰减率要除以两次观测相隔的天数；最后记得加回参考高度。
import math                       # 用自然对数 exp 和 log 做衰减模型

base_height = 380                 # 参考高度（km）
h0 = 22                           # 第 0 天在参考高度之上的剩余高度
h2 = 20                           # 第 2 天观测到的剩余高度
days_between = 2                  # 两次观测相隔天数

k = -math.log(h2 / h0)            # ← 问题在这：还没除以经过的时间
height_day10 = base_height + h0 * math.exp(-k * 10)
print(round(k, 3))
print(round(height_day10, 1))
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 右移一格、周期回绕：新数组第 1 格取旧的最后一格 4，第 2 格取 3，第 3 格取 5，第 4 格取 8 → `[4, 3, 5, 8]`。这就是平流方程 $\partial c/\partial t + u\,\partial c/\partial x = 0$ 在均匀风里的一步精确解。

**(b)** 替身由两点 $(1,4)$、$(3,12)$ 定出斜率 4：$\hat{y} = 4x$，在 $x=2$ 预测 8。真仿真给 7，误差 $8 - 7 = 1$——线性替身"大形势对、细节走样"，正是第 30 课单模态替身的翻版。修代码时注意 `pred_surrogate` 应写成 `4 * 2`。

**(c)** 由模型 $h(t)=22e^{-kt}$ 和第 2 天观测得 $20=22e^{-2k}$，即 $e^{-2k}=20/22$，两边取自然对数：$2k=\ln(22/20)\approx0.0953$，所以 $k=\ln(22/20)/2\approx0.0477$ 每天（代码里 round 到三位小数是 0.048）。第 10 天剩余高度为 $22e^{-10\times0.047655}\approx13.66$ km，加上参考高度得总高度 $\approx393.7$ km。常见错法是漏掉"除以相隔天数"，得到 $k\approx0.095$——那等于宣称卫星衰减得比观测快一倍，预测只剩 388.5 km，正是初始代码的输出。另一个坑是舍入太早：若先把 $k$ 舍入成 0.048 再代入预测式，会得 393.6 km——中间量保留全精度，只在最后一步舍入。真实定轨会用更多弧段、噪声模型和正则化，这里保留的是“稀疏观测反推参数”的最小骨架。
</details>
