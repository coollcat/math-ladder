# Neural ODE 与连续深度

## 1. 从一个场景开始

低帧率动画卡顿：12 帧每秒的画面里，人物是在"闪现"；240 帧每秒就丝滑成连续运动。残差网络有点像 12 帧动画——第 $k$ 层到第 $k+1$ 层是硬邦邦的一跳。

把帧率一路拉满会怎样？层与层之间的离散跳变，极限就是一条**连续的轨迹**。Neural ODE 的宣言只有一句：**深度可以不用数层数，而用时间来量。**

## 2. 直觉解释

残差块干的事是：$x_{k+1} = x_k + f(x_k)$。第 22 章欧拉法干的事是：$x(t+\Delta t) = x(t) + \Delta t\, f(x(t))$。两式并排放着：

> **恒等映射那一跳，就是 $\Delta t = 1$ 的欧拉步。**

所以"100 层网络"完全可以重新叙述为"时间从 0 跑到 100、步长取 1 的一条演化轨迹"。层数只是采样密度，真正被学习的是速度场 $f_\theta$ 本身——一套参数管到底，而不是每层各存一份权重。

收益立刻显现：求输出不再依赖"恰好几层"，而是解一个常微分方程；想要更精细就用更小的步长（自研求解器按需分配算力），显存也有省法（见选读的伴随状态）。代价同样实在：训练时你得挑数值求解器，这成了架构设计的一部分。

## 3. 正式定义

**神经 ODE** 把隐藏状态的演化写成常微分方程：

$$\frac{dx}{dt} = f_\theta(x, t), \qquad x(0) = x_{\text{in}}, \qquad \text{输出} = x(T)$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $x(t)$ | 隐藏状态 | 连续化的"当前特征"，活在与层数无关的空间里 |
| $f_\theta$ | 速度场 | 被学习的规律；神经网络扮演的角色 |
| $T$ | 终端时刻 | 相当于原网络的"总深度" |
| 求解器 | 数值积分器 | 新增的架构零件：步长与精度随任务调整 |

反向传播用的不是逐层回传，而是第 40 课 VJP 引擎驱动的**伴随状态**法：引入陪跑变量 $\lambda(t)$（"终点损失对当前状态的敏感度"），让它沿时间倒着演化一段方程即可——本课只点名不展开，那套推导自成一章。

## 4. 分步例题

取最透明的速度场 $f(x) = -x$（指数冷却），初值 $x_0=1$，走到 $t=1$：

1. 真解（连续深度）：$x(1) = e^{-1} \approx 0.3679$；
2. 一层跳到头（$\Delta t=1$）：$x_1 = 1 + (1)\cdot(-1)\cdot 1 = 0$——误差 $0.3679$；
3. 拆两层（$\Delta t=0.5$）：$x_1 = 0.5$，$x_2 = 0.25$——误差缩到 $0.118$；
4. 步长减半，误差也大约减半（一阶方法的标志）；
5. 结论：层数越密越接近同一条真轨迹——**层的数目不再是模型的一部分，只是计算预算。**

### 实验 2：同一套权重，层数翻倍试试

```python title="残差堆叠当欧拉法：层数加密逼近同一条曲线"
import math

lam = 1.0                      # 冷却速率：速度场 f(x) = -lam * x
total_time = 2                 # 相当于走完整个"网络深度"
truth = math.exp(-lam * total_time)     # math.exp：自然指数函数，连续深度的极限答案

for h in [1.0, 0.5, 0.25]:     # h 就是"每层的步长"：层数相应为 2 / 4 / 8 层
    steps = int(round(total_time / h))   # int()：把小数截成整数层数
    x = 1.0
    for k in range(steps):
        fx = -lam * x              # 这一层的"净作用"：速度场在该处的取值
        x = x + h * fx             # 残差更新式 = 向前迈一步的欧拉法
    err = abs(x - truth)
    print(f"步长 {h}: 终点 {round(x, 4)}  与连续极限差 {round(err, 4)}")
```

三条终点的差距每次减半——离散堆叠在向同一条连续轨迹收敛。这正是"换更深的网效果更好但没学新东西"在数学上的形状：变的只有步长，没变的是速度场。

### 实验 3：判题小练兵

```exercise
# @title: 练习：手推两个残差层
# @check: 1.1
# @check: 1.21
# @hint: 残差层是「加上本步增量」：先算增量 rate*x 再加回原值；第二层用第一层的新值接着来。
x = 1.0          # 初值 x_0
h = 0.5          # 步长（相当于 Δt）
rate = 0.2       # 速度场 f(x) = rate*x：增长率恒定的暖机阶段

inc1 = h * rate * x     # 第一层的增量
x1 = inc1               # ← 问题在这：残差层不是替换而是叠加，别忘了加上原来的 x

inc2 = h * rate * x1
x2 = inc2               # ← 问题在这：同理，第二层也要加上旧值

print(round(x1, 2))
print(round(x2, 2))
```

修好后的两次结果 $1.1$ 与 $1.21$，离连续极限 $e^{0.2}\approx 1.2214$ 已不远——只用了两层、一套共享的 rate。层数加密或改用高阶求解器还能再贴近。

## 常见误区

:::warning[常见误区]

**误区一**："权重共享说明模型变小了。"省下的是"每层独立权重"的参数账，换来的是一次前向要做多步求解的计算账——预算没有消失，只是换了科目。

**误区二**："既然能无限加密，那就往死里细分。"一阶方法步长太小会积累舍入误差，刚性速度场还会让显式欧拉失稳（第 23 章 CFL 的老朋友）；工程上换 RK45 这类自适应求解器才是正路。

**误区三**："伴随状态省内存是免费午餐。"代价是把终值问题再倒着积一遍（多一遍前向量的计算），而且某些非光滑速度场会让这段反向积分带偏梯度——这也是后来可逆块兴起的动机之一。

:::

- 被学习的对象变成了速度场 f，层数退化为计算预算里的步数 [*]

## 6. 练习

**练习 1**：手算：rate $=0.2$、$h=0.25$、$x_0=1$，推两个残差层并估计误差方向。

<details>
<summary>点开查看逐步解答</summary>

第一层：$1 + 0.25\times0.2\times1 = 1.05$；第二层：$1.05 + 0.25\times0.2\times1.05 = 1.1025$。

连续极限是 $e^{0.05}=1.0513$ 与合成 $e^{0.1}=1.1052$：每次都略低于真值——增益永远拿旧值乘，慢半拍，这是一阶显式方法的系统性落后（滞后的方向性偏差，不是随机误差）。
</details>

**练习 2**：把实验 2 的列表加一档 `h=0.125`，验证误差是否如约再次减半。

<details>
<summary>点开查看逐步解答</summary>

16 层后终点 $(0.875)^{16}\approx 0.1177$，与 $e^{-2}\approx 0.1353$ 相差约 $0.0176$——上一档误差 $0.0352$ 恰好的一半。"步长减半、误差减半"正是判断面前是不是一阶方法的最快体检。
</details>

**练习 3**：概念辨析：为什么说"选求解器"成了 Neural ODE 时代的新超参数？

<details>
<summary>点开查看逐步解答</summary>

传统网络的前向是一串固定算子，成本与精度事先锁死；Neural ODE 的前向是积分过程，容差、步长、显隐式与否共同决定"这条轨迹算得多认真"。训练里太粗会谎报损失地形，太细又烧钱——于是容差调度、稳定性约束挤进了调参清单，这是第 22 章的老知识与炼丹房的新接口。
</details>

## 7. 选读：伴随状态只点名

<details>
<summary>选读 · 反向传播的连续版</summary>

逐层存中间值的反向传播，在连续世界里升级为**伴随状态法**：定义 $\lambda(t)$ 为"终端损失对当前状态的敏感度场"，它满足倒计时方程 $\dfrac{d\lambda}{dt} = -\lambda^{\mathsf{T}} \dfrac{\partial f}{\partial x}$（末端条件由损失给出），跑完一遍就能用 VJP 攒出对全部参数的梯度。内存只需轨迹两端而非全程快照——代价是再来一遍反向积分。这套骨架与最优控制里的庞特里亚金原理血肉相连：优化界与控制界在这里隔空握手。展开推导留给更深一层的课程，此处请带走一件行李：**第 40 课的 VJP 不只是工具箱，它是把"链式法则"翻译成"方程"的语法书。**

</details>
