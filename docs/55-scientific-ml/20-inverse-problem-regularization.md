# 逆问题与正则化

## 1. 从一个场景开始

把一杯清水倒进墨水里，瞬间扩散——正向过程顺滑无比。可让你看着这杯淡蓝的水，反推"墨水最初从哪个点、以什么速度注入"，答案立刻变得千头万绪：无数种初始注入都能长成眼前这杯水。

这就是**逆问题**的处境：正向算子把差异抹平，逆向就要把差异找回来，而抹平丢掉的信息再也变不回来。更糟的是，观测里的一粒噪声，逆推后可能被放大成惊涛骇浪。**正则化**是驯服它的缰绳。

## 2. 直觉解释

逆问题的病根可以用一句话说清：

> 正向过程让某些"模式"衰减得很厉害；想复原它们就得除以一个很小的数——除数越小，噪声被放得越大。

想象隔着毛玻璃看条形码：细条纹（高频模式）几乎被抹没。硬要还原细条纹，等于拿放大镜盯着一粒灰尘（噪声）硬看出花纹。**正则化的立场**：与其追求完美复原，不如在"贴合数据"和"讲道理（平滑、小能量）"之间取一个稳健的折中——宁可钝一点，不要疯一点。

## 3. 正式定义

线性正问题 $y = Ax$（$A$ 是模糊/扩散等正向算子）。朴素反演 $\hat{x}=A^{-1}y$ 在 $A$ 病态时崩溃。**吉洪诺夫（Tikhonov）正则化**改为最小化：

$$\hat{x} = \arg\min_x \ \|Ax - y\|^2 + \lambda\,\|x\|^2$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $\|Ax-y\|^2$ | 数据项 | 复原结果要解释观测 |
| $\|x\|^2$ | 惩罚项 | 解的能量不能离谱（偏好小而平） |
| $\lambda$ | 正则强度 | 两股力量的汇率（与 PINN 的 λ 同一角色）|

最简单的标量版本一眼看穿：单传感器读数 $y$，$\hat{x} = \dfrac{y}{1+\lambda}$——λ 越大，估计越向零收缩。贝叶斯视角里它正是带高斯先验的最大后验（MAP）估计，λ 对应先验与噪声的方差比。

## 4. 分步例题

去模糊场景：模糊算子对第 $k$ 个正弦模式的幅度乘上因子 $b_k$（相邻平均会让快变纹波互相抵消）。设某模式 $b_k = 0.1$、真实幅度 $c = 1$、观测噪声 $\eta = 0.005$：

1. 观测到的幅度：$y = b_k c + \eta = 0.105$；
2. 朴素反演：$\hat{c} = y / b_k = 1.05$？别急——若噪声是 $-0.005$，则 $\hat{c} = 0.95$；
3. 噪声只有 ±0.005，反演回来却晃动 ±0.05：**放大了 10 倍**（正好 $1/b_k$ 倍）；
4. 若 $b_k = 0.001$，同样噪声会掀起 ±5 的巨浪——完全淹没真信号；
5. 岭修复（λ=0.01）：$\hat{c} = \dfrac{b_k\,y}{b_k^2 + \lambda} = \dfrac{0.1\times0.105}{0.01+0.01} \approx 0.53$，数值温和、偏差可控。放弃完美，换来稳定。

### 实验 2：逐模式的去模糊实验

```python title="三个频率分量：朴素反演 vs 岭修复"
import math

N = 32                       # 网格点数：决定各模式的模糊因子
ks = [4, 12, 15]             # 三个正弦模式的编号
c_true = [1.0, 0.3, 0.06]    # 真实幅度：高频本来就弱
noise = [0.002, -0.001, 0.003]   # 固定注入的微小观测噪声
lam = 0.01                   # 岭正则强度

for i in range(len(ks)):
    b = math.cos(math.pi * ks[i] / N)      # 模糊因子：相邻平均对幅度的折扣
    y = b * c_true[i] + noise[i]           # 观测到的幅度
    naive = y / b                          # 朴素反演：直接除回去
    ridge = b * y / (b * b + lam)          # 岭修复：分母垫底防爆炸
    print(
        f"k={ks[i]:2d} b={b:.3f} | 真={c_true[i]:.3f} "
        f"朴素={naive:.3f} 岭={ridge:.3f}"
    )
```

盯着 k=15 那行：模糊因子只有约 0.098，一粒 0.003 的噪声经朴素反演放大成 0.03 的偏差（真值才 0.06！）；岭修复把它压回可控范围。**病态程度藏在最小的那个 b 里。**

### 实验 3：判题小练兵

```exercise
# @title: 练习：两个传感器的岭估计
# @check: 0.5
# @check: -0.25
# @hint: 标量岭公式是 y/(1+λ)，分母里那个 1 别弄丢；负读数的收缩方向同样是向零。
lam = 3.0

def ridge(y):
    return y / lam                     # ← 问题在这：这不是岭估计的分母

print(round(ridge(2.0), 2))            # 传感器一：读数 +2.0
print(round(ridge(-1.0), 2))           # 传感器二：读数 -1.0
```

改对之后体会符号：第二个传感器读数是负的，估计 $-1/4 = -0.25$——正则化把所有估计往零拉，不管你原本在零的哪一侧。

## 常见误区

:::warning[常见误区]

**误区一**："训练误差最小的解就是好解。"
逆问题里拟合观测太容易做到——把噪声也一并"复原"进去了（过拟合的空间版）。选择 λ 必须留出验证数据，用没参与求解的观测来验收。

**误区二**："λ=0 最忠实于数据。"
λ=0 时确实回到无偏的最小二乘，但方差爆炸。均方误差 = 偏差² + 方差，正则化用一点偏差换大量方差——这笔交易在病态问题里几乎总是赚的。

**误区三**："惩罚项随便选个形式就行。"
$\|x\|^2$ 偏好平滑解；若真相是分片常数（比如断层图像），L1 型惩罚（全变差）才是对的先验。惩罚函数写的是你对解的**先验信念**，选错了信念，再强的数学也只是精确地算错。

:::

```quiz
把正则强度 λ 从 0 慢慢调大，标量岭估计一般会发生什么？
- 先越来越贴近观测给出的朴素解，再突然爆炸
- 从朴素解开始不断向零收缩 [*]
- 符号会翻转，正值变负值
? λ=0 是朴素最小二乘；λ 增大会加强对"解能量不要太大"的惩罚，因此估计单调收缩，用少量偏差换取更小的方差。
```

## 6. 练习

**练习 1**：手算：观测 $y=4$、λ=1，求岭估计；再问它比朴素估计损失了多少"忠实度"？

<details>
<summary>点开查看逐步解答</summary>

$\hat{x} = 4/(1+1) = 2$。朴素估计是 4，岭估计只有一半——偏差 2。换来的好处：若 $y$ 里混入 ±0.1 噪声，朴素估计跟着晃 ±0.1，岭估计只晃 ±0.05。稳定性翻倍，代价是系统性缩小。
</details>

**练习 2**：设计一个小实验：在实验 2 中给每个模式额外加一组"验证噪声"，扫描 λ ∈ {0.001, 0.01, 0.1}，选出验证误差最小的 λ。

<details>
<summary>点开查看逐步解答</summary>

思路骨架：复制一份 `noise` 改成验证扰动 → 对每个候选 λ 计算三模式的岭估计 → 与"真值+验证噪声"比对求总平方误差 → 取 argmin。你会看到 λ 太小时验证误差被噪声放大项主导，太大时被收缩偏差主导，中间存在谷底。这个"U 形曲线"是一切超参数选择的通用形状。
</details>

**练习 3**：概念辨析：正则化和上一课 PINN 的物理损失有什么血缘关系？

<details>
<summary>点开查看逐步解答</summary>

本质同源：都是在数据之外引入"额外的信念"来约束不唯一的解。Tikhonov 的信念是"解能量小"，物理损失的信念是"解满足方程"。事实上把 PDE 残差平方和写成罚项，就得到"方程即正则项"的观点——PINN 可以看作一种物理定制的高级正则化。
</details>

## 7. 选读：为什么说逆问题是"不适定"的

<details>
<summary>选读 · Hadamard 三条件</summary>

Hadamard 给"适定问题"立了三条：解存在、解唯一、解连续依赖于数据。热传导的逆问题（由终温反推初温）三条全破：终温相同的局面可以来自不同初温（唯一性破），且初温差异被扩散指数压扁后，任何微小的观测误差都对应天壤之别的初温（连续性破）。1970 年代 Tikhonov 与 Kirsch 等人发展的正则化理论，核心就是用一族良定问题逼近这个不适定问题——λ 控制逼近的距离。这套思想如今贯穿医学成像、雷达、地震勘探。
</details>
