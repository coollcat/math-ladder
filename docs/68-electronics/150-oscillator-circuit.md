# 振荡器与时钟

## 1. 从一个场景开始

单片机旁边总有一颗亮晶晶的金属封装小元件：**8 MHz 晶振**。它没有任何输入信号，却持续输出稳定的方波——整个系统的时间基准全靠它。

一块**没有交流输入的电路，凭什么自己产生交流输出？**

答案既意外又熟悉：它有一个**正反馈环**，而且这个环满足两个条件——信号绕一圈回来后既变大、又同相。这就是巴克豪森判据。

## 2. 直觉解释

回忆演唱会上的**啸叫**：麦克风对准音箱，音箱的声音又被麦克风拾到，绕一圈再放大……只要"绕一圈的增益 > 1"且"回来的声音与原来同相"，声音就会**自我放大**，直到功放限幅。

振荡器就是这个现象的**受控版本**，而且必须同时满足两条：

| 条件 | 内容 | 不满足时 |
| --- | --- | --- |
| **幅值条件** | 环路增益 $\lvert A\beta\rvert > 1$ | 扰动逐次衰减，电路稳定（不振荡） |
| **相位条件** | 环路总相移 $= 360°$（即 $0°$） | 回来的信号不同相，互相抵消 |

**注意这两个条件必须同时成立**，且成立在**同一个频率**上。这就是为什么振荡器有个确定的频率——不是电路"选"了它，而是只有那一个频率同时满足两条。

还有一个容易被忽略的第三件事：**幅度怎么停下来？** 若 $\lvert A\beta\rvert > 1$ 永远成立，幅度会指数增长到无穷。真实电路靠**限幅**（输出撞上电源轨）把环路增益"自动降到 1"，形成稳定的等幅振荡。

## 3. 正式定义

**巴克豪森判据**：负反馈系统 $G = A/(1+A\beta)$ 在 $1 + A\beta = 0$ 处分母为零、增益无穷，即

$$\lvert A\beta\rvert = 1, \qquad \angle A\beta = 360° \ (\text{即}\ 0°)$$

工程上起振要求 $\lvert A\beta\rvert > 1$（严格大于），稳幅时自动回到 $=1$。

**三级 RC 移相振荡器**（本课的具体例子）：

- 反相放大器提供 $180°$；
- 三级 RC 移相网络在特征频率上再提供 $180°$；
- 该频率处移相网络的衰减恰为 $1/8$，所以要求 $A > 8$。

$$f_0 = \frac{1}{2\pi R C\sqrt{6}}, \qquad \lvert \beta\rvert_{f_0} = \frac{1}{8}, \qquad A_{\min} = 8$$

**一般三级 RC 的频率响应**（每级 $H = jx/(1+jx)$）：

$$\lvert A\beta\rvert = A\left(\frac{x}{\sqrt{1+x^2}}\right)^3, \qquad \angle A\beta = 180° + 3\left(90° - \arctan x\right)$$

其中 $x = u/\sqrt{3}$，$u = f/f_0$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $A$ | 放大器增益 | 反相组态，自带 $180°$ |
| $\beta$ | 反馈网络传输系数 | 三级 RC，在 $f_0$ 处 $= 1/8$ |
| $A\beta$ | 环路增益 | 复数，判据的主角 |
| $f_0$ | 振荡频率 | 相位凑齐 $360°$ 的那个频率 |
| Nyquist / 极坐标图 | 环路增益轨迹 | 轨迹是否包围 $+1$ 点 |

## 4. 分步例题

**例**：三级 RC 移相振荡器，放大器增益 $A = 12$。(a) 是否满足起振条件？(b) 稳幅后输出如何确定？

1. **求 $f_0$ 处的环路增益**：$\lvert A\beta\rvert = A/8 = 12/8 = 1.5$；
2. **幅值条件**：$1.5 > 1$ ✓ **起振**；
3. **相位条件**：电路被设计成在 $f_0$ 处移相网络恰好给 $180°$，加上放大器的 $180°$，总计 $360°$ ✓；
4. **起振过程**：噪声里的 $f_0$ 分量每绕一圈放大 1.5 倍，幅度指数增长；
5. **稳幅**：幅度增长到接近电源轨时，放大器进入非线性（削顶），**有效增益自动降到 8**，环路增益回到 1，幅度稳定；
6. **输出波形**：由于靠削顶限幅，输出有明显失真（接近方波）。要低失真就得用**自动增益控制（AGC）**——例如用热敏电阻或 JFET 做可变电阻，让增益随幅度温和下降。

**第 5 步是全课最精妙的地方**：振荡器必须"非线性"才能稳定。纯线性系统要么衰减到零，要么增长到无穷——**只有非线性才能给出稳定的有限振幅。** 这与第 22 章的**极限环**是同一件事：非线性系统特有的、孤立的稳定周期解。

## 5. 动手实验

### 实验 1（lab）：极坐标图上的生与死

```lab
{
  "type": "oscillator-circuit",
  "title": "振荡器：环路增益要大于 1，相位要凑齐 360°",
  "sliders": [
    { "name": "A", "label": "放大器增益 A", "min": 1, "max": 30, "step": 0.1, "value": 12 },
    { "name": "u", "label": "频率 f / f₀", "min": 0.2, "max": 5, "step": 0.01, "value": 1 }
  ]
}
```

左上角的极坐标图（Nyquist 图）是判据的几何版本：绿色圆是**单位圆** $\lvert A\beta\rvert = 1$，琥珀色轨迹是环路增益随频率扫过的路径，圆点标出临界点 $+1$。**轨迹穿过正实轴的那一点若落在单位圆之外 → 起振。**

做三组对照：

- **A = 12**（默认）：轨迹在正实轴的交点约在 1.5 处，**包住了 $+1$ 点** → 起振。下方波形从微小幅度一路爬升、最后撞上红色 $\pm V_{sat}$ 虚线并稳住；
- **A = 6**：交点降到 0.75，**在单位圆内** → 不起振。波形会自己衰减到零，读数显示"$|A\beta| < 1$，电路稳定"；
- **u 偏离 1**：即使 $A = 12$，只要频率不在 $f_0$ 附近，相移就凑不齐 $360°$——读数会提示"幅值够但相位没凑齐，振荡会停在 $f_0$"。**振荡频率由相位条件挑出，不是由幅值条件挑出。**

点"播放"看完整的起振过程：从 0.05 V 的噪声起步 → 指数爬升 → 撞上限幅 → 稳幅。这就是极限环的诞生过程。

### 实验 2（python）：指数增长到限幅

```python title="环路增益 1.5 时，幅度如何爬升并稳住"
A = 12.0
loop = A / 8.0                 # f₀ 处的环路增益
amp = 0.05                     # 起始幅度（噪声底）
VSAT = 10.0

print("圈数   幅度")
for n in range(1, 26):
    amp = amp * loop
    if amp > VSAT:             # 撞上限幅：有效增益自动降为 1
        amp = VSAT
    if n % 5 == 0 or amp >= VSAT:
        print(f"{n:>4}   {amp:8.3f}")
        if amp >= VSAT:
            print("已限幅：环路增益自动降到 1，形成稳定振荡")
            break
```

十几圈就从 50 mV 爬到 10 V——每圈 ×1.5，指数增长快得惊人。而一旦撞限，幅度就**钉在那里不再变化**：非线性提供了"增益随幅度自动调节"的机制。

把 `A` 改成 8.1（勉强起振），需要几百圈才到限幅，波形也更接近正弦——**过驱动越小、失真越小，但起振越慢**。这是振荡器设计里最经典的一对矛盾。

### 快问快答

```quiz
一个振荡器已经满足幅值条件（环路增益大于 1），但相位条件没凑齐，电路会怎样？
- 在任意频率上振荡
- 不振荡；只有同时满足相位条件的那个频率才会起振 [*]
- 幅度无限增长
? 两个条件必须落在同一个频率上。相位条件负责「挑出」振荡频率，幅值条件负责「允许」它增长。相位不对时，绕一圈回来的信号与原信号不同相，只会互相削弱。
```

:::warning[常见误区]

**误区一**："环路增益越大，振荡越强越好。"
你以为 $A$ 越大越可靠——增益太大会让器件深度进入非线性，输出**严重削顶失真**（接近方波），而且起振时的冲击电流可能损坏器件。工程上取 $A\beta \approx 1.2\sim2$（刚刚够起振），再用 AGC 精细稳幅。这就是为什么高纯度信号源要用"文氏电桥 + 灯泡稳幅"这种精巧结构。

**误区二**："晶振和 RC 振荡器只是精度不同。"
你以为只是"准不准"——**晶振的 $Q$ 值是 RC 振荡器的上万倍**（石英晶体 $Q$ 可达 $10^4\sim10^6$，RC 网络只有几）。高 $Q$ 意味着极窄的选频特性，相位对频率极其敏感，频率被牢牢锁定。所以晶振的稳定度能做到 ppm 级，RC 振荡器只有 1%~5%。**$Q$ 值才是时钟精度的物理根源。**

**误区三**："振荡器只会出现在我故意设计的地方。"
你以为不设计就没事——**运放电路里的寄生振荡是模拟工程师的噩梦**。长走线的寄生电感、去耦不足导致的电源耦合、运放输出端的容性负载，都可能凑出一个意外的高频正反馈环。症状是：电路功能"看起来正常"，但输出上叠着几十 MHz 的小毛刺，或者莫名其妙发热。**解药永远是：完整接地平面、紧贴的去耦电容、输出端串小电阻（10~50 Ω）隔离容性负载。**

:::

## 6. 练习

**练习 1**：三级 RC 移相振荡器在 $f_0$ 处的衰减是 $1/8$，起振需要的最小增益是多少？这段代码把衰减写成了 $1/6$，修到输出 `8`：

```exercise
# @title: 练习：三级 RC 移相振荡器的起振门槛
# @check: 8
# @hint: 三级 RC 移相网络在相移恰为 180° 的频率上，衰减是 1/8；起振要求 A × (1/8) ≥ 1，即 A ≥ 8
atten = 1.0 / 6.0      # ← 问题在这：三级 RC 的衰减是 1/8，不是 1/6
A_min = 1.0 / atten
print(round(A_min))
```

**练习 2**：一个 RC 移相振荡器用了 $R = 10$ kΩ、$C = 10$ nF 的三级网络。(a) 振荡频率是多少？(b) 若放大器增益为 15，环路增益是多少？(c) 若想让频率减半，改哪个元件、改成多大？

<details>
<summary>点开查看逐步解答</summary>

1. **频率**：$f_0 = \dfrac{1}{2\pi RC\sqrt{6}} = \dfrac{1}{2\pi\times10^4\times10^{-8}\times2.449} = \dfrac{1}{1.539\times10^{-3}} = 650$ Hz；

   $\sqrt{6} \approx 2.449$ 这个因子是三级级联的结果——三级互相"加载"，不能用单级公式；
2. **环路增益**：$\lvert A\beta\rvert = A/8 = 15/8 = 1.875 > 1$ ✓ 起振（过驱动偏大，输出会明显削顶）；
3. **频率减半**：$f_0 \propto 1/(RC)$，所以把 $R$ 或 $C$ **加倍**。改 $C$ 更方便：$C = 20$ nF（或两颗 10 nF 并联），频率降到 325 Hz；
4. **注意**：改 $R$ 也可以，但 $R$ 同时决定了移相网络的输出阻抗与放大器的负载，影响增益。**改电容更安全**——这也是实际调试中的常用做法。

**顺带一提**：650 Hz 属于音频范围，这类 RC 振荡器在电子琴、蜂鸣器里很常见；而需要精确频率时必须换用晶振或陶瓷谐振器。

</details>

## 7. 选读：Nyquist 判据为什么看"包围"

<details>
<summary>选读 · 从极点到稳定判据</summary>

闭环系统 $G(s) = \dfrac{A(s)}{1 + A(s)\beta(s)}$ 的极点是 $1 + A\beta = 0$ 的根。若某个根有正实部，对应 $e^{\sigma t}$ 型增长——**不稳定，会振荡**。

Nyquist 判据是一种**不作弊的判断法**：它不直接求根，而是看开环函数 $L(s) = A(s)\beta(s)$ 沿 $s$ 平面虚轴（$s = j\omega$，$\omega$ 从 $-\infty$ 到 $+\infty$）走一圈时，在 $L$ 平面上画出的闭合曲线是否**包围**点 $-1 + 0j$。

包围的圈数 = 右半平面极点数的变化。对于本身稳定的放大器（开环无右半平面极点），**包围 $-1$ 点 ⟺ 闭环有右半平面极点 ⟺ 振荡**。

本课的极坐标图就是这个 $L(j\omega)$ 轨迹（注意组件的放大器自带 $180°$ 反相，所以临界点画在 $+1$ 而不是 $-1$）。

**这个判据的威力在于：它不需要知道系统的具体极点，只看一条可以实测的频响曲线。** 工程上甚至可以直接用网络分析仪测出环路增益的幅相曲线，然后看图判断——第 60 章 Bode 图上的"增益裕度"与"相位裕度"，正是 Nyquist 判据在对数坐标上的工程化表达。

</details>
