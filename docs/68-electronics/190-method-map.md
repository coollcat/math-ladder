# 电子设计方法地图

## 1. 从一个场景开始

桌上摊着一块不工作的板子。19 门课学完了，工具箱里塞满了：节点分析、戴维南等效、时间常数、相量、功率三角形、负载线、虚短、Q 值、巴克豪森判据、纹波公式、ENOB……

可现在的问题是：**先查哪一个？**

学完一章工具最大的风险不是忘了公式，而是"拿着锤子看什么都是钉子"。本课不添任何新定理，只做三件事：把全章课程排成一张**导诊地图**、演练一遍**分诊两问法**、然后把最容易踩的坑一次性列队展览。

## 2. 直觉解释

电子故障分诊只需连问两个问题：

**第一问——现象属于哪一类？**

| 类别 | 典型症状 | 谁负责 |
| --- | --- | --- |
| **静态/直流** | 电压不对、电流偏大、发热、不工作 | KCL/KVL、戴维南、晶体管工作点 |
| **动态/时域** | 上电过冲、响应太慢、振铃、毛刺 | 电容、电感、RC、RLC |
| **频域** | 噪声、干扰、衰减不够、相位偏移 | 相量、阻抗、滤波器、Bode |
| **能量/热** | 烫手、效率低、电池不耐用 | 交流功率、线性稳压、Buck |
| **边界** | 冒烟、复位、死机、读数跳变 | 二极管整流、电源纹波、ADC、PCB |

**第二问——信号的特征尺度是什么？**

- **幅度**：mV 级（热电偶）还是 A 级（电机驱动）？决定是精密模拟还是功率电子；
- **频率**：DC、工频 50 Hz、音频 20 kHz、射频 100 MHz？决定用集总参数还是分布参数、要不要考虑走线电感；
- **精度**：1% 还是 0.01%？决定要不要精密基准、低温漂电阻、四线测量。

两问答案往表上一对，科室基本锁定。剩下的分歧多半发生在"多种工具都能凑合"的地带——那时再比成本、体积、功耗和可维护性，而不是比谁听起来高级。

## 4. 分步例题

**题 A**：新板子上电后，3.3 V 电源轨冲到 4.4 V 再回落。

1. 第一问：**动态/时域**（上电瞬态）；第二问：时间尺度约几百 µs、幅度超出绝对最大额定值；
2. 定位：电源走线寄生电感 + 去耦电容构成 RLC。$\zeta < 1$ → 欠阻尼过冲；
3. 处方：查 [RLC 二阶](./80-rlc-ring.md) 的 $\zeta = R/R_c$，加大阻尼（串联几欧电阻）或**减小寄生电感**（缩短走线、加地平面）；
4. 同时查 [电容](./50-capacitor-lab.md)：去耦电容是否紧贴、是否大小搭配。

**题 B**：12 位 ADC 的读数一直跳，有效位数只有 9 位。

1. 第一问：**边界**（读数跳变）+ **频域**（噪声）；第二问：精度要求 0.1% 量级、采样率不高；
2. 逐层排查：① 参考电压干净吗（[ADC](./170-adc-dac.md)）；② 电源纹波多大（[电源稳压](./160-power-regulator.md)）；③ 前端有没有抗混叠滤波（[有源滤波](./140-active-filter.md)）；④ 地去耦与布局（[PCB](./180-pcb-flow.md)）；
3. 处方：**先换基准，再查布局，最后才考虑换更高位数的 ADC**——大多数"位数不够"其实是"噪声太多"。

**题 C**：继电器一断开驱动三极管就烧。

1. 第一问：**动态**；第二问：时间尺度 µs、幅度上百伏；
2. 定位：电感电流不能中断，靠杂散电容兜底 → $v_{pk} = i_0\sqrt{L/C_s}$；
3. 处方：续流二极管（[电感](./60-inductor-lab.md)），必要时加稳压管加快释放，再按 [晶体管](./120-transistor-switch.md) 重算过驱动。

## 5. 动手实验

### 实验 1（python）：给故障自动挂号

```python title="按症状开具科室单"
def triage(smoke, hot, too_slow, noisy, ringing):
    # 优先级闸门：越可能造成硬件损坏的越早分流
    if smoke:
        return "pcb-flow + power-regulator（先看电源与短路）"
    if hot:
        return "ac-power + power-regulator（算功耗与效率）"
    if ringing:
        return "rlc-ring（算 ζ 与过冲）"
    if noisy:
        return "active-filter + adc-dac（查噪声源与参考）"
    if too_slow:
        return "rc-step（算 τ 与建立时间）"
    return "kcl-kvl（静态工作点）"

cases = [
    ("上电就冒烟", True, False, False, False, False),
    ("7805 烫得不敢摸", False, True, False, False, False),
    ("电源轨冲到 4.4 V", False, False, False, False, True),
    ("12 位 ADC 只有 9 位", False, False, False, True, False),
    ("按键消抖不干净", False, False, True, False, False),
    ("输出只有理论值的一半", False, False, False, False, False),
]
for note, a, b, c, d, e in cases:      # 元组解包：一次领出整行
    print(triage(a, b, c, d, e), "|", note)
```

六行输出就是六张挂号单。**注意 if 台阶的顺序本身就是知识**：冒烟排第一、发热排第二，因为这两类问题会**继续损坏硬件**——分诊永远先看会不会死人，再看舒不舒服。

### 实验 2（python）：一张表把量级钉住

```python title="电子工程师脑内必备的数量级"
print("── 电压 ─────────────")
for name, v in [("硅二极管 Vf", 0.7), ("肖特基 Vf", 0.3),
                ("TTL 高电平", 3.3), ("市电峰值", 311), ("ESD 人体模型", 15000)]:
    print(f"{name:>12}: {v:>8.1f} V")

print("── 时间 ─────────────")
for name, t in [("继电器吸合", 3e-4), ("按键消抖", 1e-2),
                ("市电周期", 2e-2), ("MCU 指令周期", 6e-8), ("数字信号上升沿", 1e-9)]:
    print(f"{name:>12}: {t*1e3:>10.4f} ms")

print("── 经验系数 ─────────")
print("  1 oz 铜 10 mil ≈ 1 A    每加一位 ADC ≈ +6 dB")
print("  去耦电容走线 < 5 mm     三级 RC 起振门槛 A = 8")
```

三段输出是"工程直觉"的量化版本。**判断一个设计靠不靠谱，往往不需要精确计算，只需要看数量级对不对**——5 mm 的去耦走线和 1 A/10 mil 的线宽，属于那种"错了就会付出代价、但对了一辈子受用"的手感。

### 快问快答

```quiz
一块板子「功能看起来正常，但输出上叠着几十 MHz 的小毛刺，还莫名其妙发热」，最可能的原因是什么？
- ADC 位数不够
- 意外的寄生振荡：长走线电感、去耦不足、容性负载凑出了正反馈环 [*]
- 滤波电容太大
? 这是运放电路最隐蔽的失效模式。第 150 课的巴克豪森判据反过来用：不想要振荡，就得破坏「环路增益大于 1 且相移 360°」这两个条件。解药是完整接地平面、紧贴的去耦电容、输出端串 10~50 Ω 电阻。
```

:::warning[常见误区]

**误区一**："仿真过了，电路就没问题。"
你以为 SPICE 是真理——仿真的模型里没有**走线电感、焊盘电容、器件温升、电源内阻、元件公差**这些真实存在的东西。仿真的正确用法是"验证思路"，不是"替代测量"。**所有仿真结论都要回到示波器上确认一遍**，尤其涉及稳定性和 EMC 时。

**误区二**："精度不够就换更高位数的 ADC / 更快的运放 / 更大的电容。"
你以为换料是万能解——**先定位瓶颈，再换器件**。ADC 精度不足常常卡在参考电压或前端噪声上（换 16 位 ADC 毫无用处）；运放不够快常常是压摆率（SR）而不是带宽不够；电容不够大可能是因为放错了位置而不是容量不足。**"换更好的零件"是最贵的解法，通常也是最没用的。**

**误区三**："方法地图是一条通关路线。"
它是按需查阅的工具书，不是进度条。真实工作从来只摘用其中两三页。这张表真正想教的是**分诊的顺序**：先看会不会损坏硬件（冒烟、过压、过流、过热），再看功能是否正常，最后才优化性能。**顺序错了，会越修越坏。**

:::

## 6. 练习

**练习 1**：分诊台的分支顺序被人调乱了：把"读数有噪声"排在了"电源冲高"前面，导致双重故障的板子被开错了单。请把它扶正，使输出依次是 `pcb-flow`、`rlc-ring`、`adc-dac`：

```exercise
# @title: 练习：谁的科室单开错了
# @check: pcb-flow
# @check: rlc-ring
# @check: adc-dac
# @hint: 规则手册写着：上电瞬态过冲属于「会继续打伤后级器件」的硬件风险，优先级高于信号质量问题。交换 noisy 与 ringing 两支的先后
def triage(smoke, ringing, noisy):
    if smoke:
        return "pcb-flow"
    if noisy:
        return "adc-dac"
    if ringing:
        return "rlc-ring"
    return "kcl-kvl"

print(triage(True, False, False))    # 冒烟
print(triage(False, True, True))     # 又冲高又噪声
print(triage(False, False, True))    # 单纯噪声
```

**练习 2**：一块电池供电的传感器节点，用 3.7 V 锂电供电，要求 3.3 V / 50 mA 输出，续航六个月。请给出你的设计思路与取舍。

<details>
<summary>点开查看逐步解答</summary>

1. **先算能量预算**：六个月 ≈ 4380 小时，$50\ \text{mA}\times4380\ \text{h} = 219$ Ah——**任何电池都做不到**。所以结论是：**不能一直供电**。
2. **转向占空比**：若每 10 分钟只工作 1 秒，平均电流 $= 50\times(1/600) = 0.083$ mA = 83 µA，六个月需要 $0.083\times4380 = 365$ mAh。一节 18650（2500 mAh）绰绰有余；
3. **稳压方案选择**：
   - 线性 LDO：压差 0.4 V，效率 $3.3/3.7 = 89\%$，静态电流必须 < 5 µA（MCP1700 是 1.6 µA）✓；
   - Buck 开关：效率 90%+，但静态电流通常几十 µA，**在睡眠时反而是负担**；
   - **结论**：轻载长续航场景下，低静态电流的 LDO 优于 Buck；
4. **休眠功耗才是大头**：MCU 睡眠 2 µA、传感器断电、上拉电阻要在休眠时关掉（10 kΩ 上拉就是 370 µA！）；
5. **检查清单**：[电源稳压](./160-power-regulator.md) 的压差与静态电流、[ADC](./170-adc-dac.md) 的参考电压功耗、[电容](./50-capacitor-lab.md) 的漏电流（电解电容漏电可达 µA 级，要选瓷片）。

**这道题的价值在于"先算量级再动手"**：第一步算出的 219 Ah 直接否定了整个"持续供电"的思路，比任何器件选型都关键。

</details>

## 7. 选读：三条游览路线

<details>
<summary>选读 · 不同胃口的吃法</summary>

**工程速通线**（最快上手干活）：电荷电流 → 欧姆定律 → 基尔霍夫 → 戴维南 → 电容 → 电感 → RC → 晶体管 → 运放 → 电源稳压 → ADC。沿这条走完，你已经能设计一块带 MCU 的传感器板并完成调试。

**信号纵深线**（模拟偏执狂首选）：在速通线基础上补齐 RLC 二阶、相量阻抗、交流功率、有源滤波、振荡器五课。理解频率如何统治一切：从相量、功率三角形到 Q 值与 Bode 图，这条线直通通信系统与射频领域（第 62、63 章）。

**系统整合线**（做产品的读法）：速通线 + PCB 流程 + ADC/DAC，再补上电源稳压的深度。重点不在"算得准"，而在"能量够不够、噪声有多大、批量能不能做"——这条线通往第 72 章的机电系统与嵌入式设计。

**三条线最后都汇入同一句话**：电子设计的本质不是套公式，而是**在相互矛盾的约束之间做取舍**——精度与成本、速度与稳定、效率与纯净、性能与可制造性。地图能帮你找到工具，取舍只能靠你自己拍板。

</details>
