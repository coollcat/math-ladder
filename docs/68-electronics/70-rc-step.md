# RC 一阶响应与时间常数

## 1. 从一个场景开始

按下按键，单片机会读到好几次"按下"。不是按键在抖（虽然它确实在抖），而是——即使你用完美的开关给它一个干净的阶跃，RC 电路也要花一段时间才能把电压送到位。

这段时间有多长？工程上从不精确计算，只记三个数：**1τ 到 63%，2τ 到 86%，3τ 到 95%。** 就这三个数，撑起了从复位时序、按键消抖到采样保持电路的半壁江山。

## 2. 直觉解释

想象你在刷一面墙，**每一分钟刷掉剩余未刷部分的一半**。

- 第 1 分钟后：刷了 1/2，剩 1/2；
- 第 2 分钟后：又刷掉剩余的一半，累计 3/4；
- 第 3 分钟后：累计 7/8……

你永远不会"刷完"，但你很快就"看不出没刷完"。**这就是指数逼近的本质：每一步走的都是"剩余距离的固定比例"。**

RC 充电完全一样：电容电压与电源的**差值**就是那个"剩余距离"，电流正比于这个差值（$i = (V_s - v)/R$），所以电压以"与剩余差值成正比"的速度追赶——每一步吃掉剩余差值的同一个比例。

那个"比例"被打包成一个数：**时间常数 $\tau = RC$**。

## 3. 正式定义

**RC 一阶电路**：由 KVL 与元件关系联立

$$V_s = i R + v_C, \qquad i = C\frac{dv_C}{dt}$$

消去 $i$ 得一阶线性常微分方程：

$$RC\frac{dv_C}{dt} + v_C = V_s$$

**充电解**（初始电压 0）：

$$v_C(t) = V_s\left(1 - e^{-t/RC}\right)$$

**放电解**（初始电压 $V_0$）：

$$v_C(t) = V_0\, e^{-t/RC}$$

**时间常数**：

$$\tau = RC$$

**标准进度表**（工程上只需记住这几个数）：

| 时间 | 充电完成度 | 放电剩余量 |
| --- | --- | --- |
| $1\tau$ | 63.2% | 36.8% |
| $2\tau$ | 86.5% | 13.5% |
| $3\tau$ | 95.0% | 5.0% |
| $4\tau$ | 98.2% | 1.8% |
| $5\tau$ | 99.3% | 0.7% |

**反解时间**（已知目标百分比 $p$，求所需时间）：

$$t = -\tau \ln(1 - p)$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $\tau$ | 时间常数 | 秒 s | $\tau = RC$，走完剩余距离的 63.2% |
| $e$ | 自然常数 | — | 约 2.71828 |
| $V_s$ | 阶跃幅值 | 伏特 V | 最终趋于的稳态值 |
| $p$ | 完成百分比 | — | 0~1 之间的小数 |

## 4. 分步例题

**例**：$R = 10$ kΩ，$C = 100$ µF，输入从 0 V 阶跃到 5 V。问：(a) 时间常数；(b) 多久充到 90%；(c) 1 秒后电压多少？

1. **时间常数**：$\tau = RC = 10^4 \times 10^{-4} = 1.0$ s；
2. **充到 90%**：由 $1 - e^{-t/\tau} = 0.9$ 得 $e^{-t/\tau} = 0.1$，取对数 $-t/\tau = \ln 0.1 = -2.303$，所以 $t = 2.303\tau = 2.303$ s；
3. **1 秒后**（正好 $1\tau$）：$v = 5(1 - e^{-1}) = 5 \times 0.632 = 3.16$ V；
4. **校验**：3.16 V 是 5 V 的 63.2%——与表格第一行吻合。

注意 (b) 与 (c) 的对比很有意思：**充到 63% 只要 1 秒，充到 90% 却要 2.3 秒。** 越接近终点走得越慢，这就是指数逼近的代价。任何需要"精确到 1% 以内"的场合，都要留足 5τ。


图上有三条东西要看：

- **实线（橙）**是电路引擎一步步积分出来的数值解——它是"真实的"；
- **虚线（灰）**是解析公式 $V(1-e^{-t/RC})$——它是"理论的"；
- **紫色刻度线**标出 1τ/2τ/3τ/5τ 的位置与对应百分比。

两件事值得做：

- 盯着"偏差"读数：数值解与解析解的差在 $10^{-4}$ 量级。这不是公式错了，而是**后向欧拉法的一阶精度误差**——它证明了仿真可信，也提醒你仿真永远是近似；
- 用"放电"档看镜像过程：曲线从 V 掉到 0，1τ 处剩 36.8%。**充电与放电是同一条曲线上下翻转**，时间常数完全相同。

把 C 从 100 µF 拖到 500 µF，横轴的时间刻度自动放大五倍——**τ 完全由 RC 决定，与阶跃幅值 V 无关**。这是线性电路的比例性在起作用。

### 实验 2（python）：把指数解一步步迭代出来

```python title="后向欧拉：用递推代替微分方程"
R, C, V = 10000.0, 100e-6, 5.0      # 时间常数 τ = 1 s
tau = R * C
dt = 0.05                            # 时间步长（s）
v = 0.0                              # 电容初始电压
marks = [1, 2, 3, 5]

for step in range(1, 201):           # 跑 10 秒
    # 后向欧拉：用「下一步的电流」算下一步，比前向欧拉稳定
    v = (v + dt * V / (R * C)) / (1 + dt / (R * C))
    t = step * dt
    for m in marks:
        if step * dt <= m * tau < (step + 1) * dt:
            print(f"{m}τ ({t:.2f} s): v = {v:.3f} V = {v/V*100:.1f}%")

print(f"解析对照: 1τ = {V*(1-2.718281828**-1):.3f} V, 3τ = {V*(1-2.718281828**-3):.3f} V")
```

打印出的百分比是 62.3% / 85.8% / 94.6% / 99.2%——与表格的 63.2% / 86.5% / 95.0% / 99.3% 差不到一个百分点。这个系统性偏小不是错误，而是**后向欧拉的一阶精度**：它用下一步的电流代替本步，等于"慢了半拍"。把 `dt` 从 0.05 改到 0.005 再跑，偏差会缩到十分之一。

**这段循环正是电路仿真引擎在时域里做的事**——真实引擎用自适应步长与更高阶的积分法，但思想完全相同：把微分方程换成一步一步的递推。

### 快问快答

```quiz
一个 RC 电路的时间常数是 2 ms，输入从 0 阶跃到 3 V，6 ms 后电容电压约为多少？
- 1.90 V
- 2.85 V [*]
- 3.00 V
? 6 ms 是 3 个时间常数，完成度 95.0%，所以 v = 3 × 0.95 = 2.85 V。注意别把「95%」和「100%」混为一谈——剩下的 5% 看着少，在 8 位 ADC 上就是 13 个码字的误差。
```

:::warning[常见误区]

**误区一**："$\tau$ 是充满电所需的时间。"
你以为经过一个 $\tau$ 就充好了——其实 $\tau$ 只是"走完剩余路程 63.2%"的时间，**严格说电容永远充不满**（数学上是渐近的）。工程上约定 5τ 算"稳了"（99.3%），但这也只是约定：12 位 ADC 要求 0.024% 精度，得等到 8.3τ。

**误区二**："放电公式就是把充电公式里的 $e^{-t/\tau}$ 换成 $1-e^{-t/\tau}$。"
你以为两者对称——其实**完全不同的两件事**。充电是 $V_s(1 - e^{-t/\tau})$（从 0 趋向 $V_s$），放电是 $V_0 e^{-t/\tau}$（从 $V_0$ 趋向 0）。更一般的式子是 $v(t) = v(\infty) + [v(0^+) - v(\infty)]e^{-t/\tau}$——**三要素法**：先定终值、再定初值、最后套指数。这一条能通吃所有一阶电路。

**误区三**："时间常数越大，电路越慢，所以我选小一点的 R 和 C。"
你在只看响应速度——但 RC 电路常常是**滤波器**，滤得干净就必然慢。按键消抖要 10 ms 量级（滤掉机械抖动），电源去耦要 ns 量级（跟得上电流突变），采样保持要足够快又不失真。**慢不是缺点，是要付的价钱**：滤得越狠，响应越慢，这是一阶电路无法逃避的权衡。

:::

## 6. 练习

**练习 1**：$\tau = 1$ s 的 RC 电路，充到 90% 需要多久？这段代码把对数的参数写错了，修到输出 `2.303`：

```exercise
# @title: 练习：充到 90% 需要多久
# @check: 2.303
# @hint: 由 1 − e^(−t/τ) = 0.9 得 e^(−t/τ) = 0.1，所以 t = −τ·ln(0.1)。ln 里应是「还剩多少没充」，即 1 − 0.9 = 0.1
import math                      # 数学库（卷一已引入），提供 log 等函数

R = 10000.0
C = 100e-6
tau = R * C
target = 0.9
t = -tau * math.log(target)      # ← 问题在这：ln 的参数应是 1 - target
print(round(t, 3))
```

**练习 2**：一个上电复位电路要求 RESET 引脚在电源达到 90% 之前保持低电平，且复位脉冲宽度不少于 100 ms。若取 $R = 100$ kΩ，C 应选多大？

<details>
<summary>点开查看逐步解答</summary>

1. 电容电压充到 90% 释放复位，所需时间 $t = -\tau\ln(1-0.9) = 2.303\,\tau$；
2. 要求 $t \ge 0.1$ s，所以 $\tau \ge 0.1 / 2.303 = 0.0434$ s；
3. $C = \tau/R = 0.0434 / 10^5 = 4.34\times10^{-7}$ F = 0.434 µF；
4. 取标准值 **0.47 µF**（比计算值略大，留余量）；
5. 校验：$t = 2.303 \times 10^5 \times 0.47\times10^{-6} = 0.108$ s = 108 ms ≥ 100 ms ✓。

注意这里用到了"阈值取 90%"这个额外的假设——真实复位芯片（如 MAX809）内部用的是**带隙基准 + 比较器**，阈值精确且与 RC 的温漂无关。分立 RC 复位只在对成本极度敏感的场合使用，**因为它会随温度和器件公差漂移 ±30%**。

</details>

## 7. 选读：三要素法——一阶电路的通解

<details>
<summary>选读 · 一个公式通吃所有一阶电路</summary>

任何只含一个储能元件（一个 C 或一个 L）的电路，都可以化归为

$$\frac{dx}{dt} + \frac{1}{\tau}x = k$$

其通解有一个极其好记的形式：

$$x(t) = x(\infty) + \bigl[x(0^+) - x(\infty)\bigr]\, e^{-t/\tau}$$

三个要素，所以叫**三要素法**：

1. **终值** $x(\infty)$：把电容看成开路（电感看成短路），解一个纯电阻电路；
2. **初值** $x(0^+)$：电容电压（电感电流）不能突变，取换路前瞬间的值 $x(0^-)$；
3. **时间常数 $\tau$**：把独立源置零，从储能元件两端看进去的戴维南电阻 $R_{th}$，然后 $\tau = R_{th}C$（或 $\tau = L/R_{th}$）。

举例：电容初始 2 V，经 10 kΩ 电阻接到 5 V 电源，C = 100 µF。
- $x(\infty) = 5$ V；$x(0^+) = 2$ V；$R_{th} = 10$ kΩ，$\tau = 1$ s；
- $v(t) = 5 + (2-5)e^{-t} = 5 - 3e^{-t}$；
- 校验：$t=0$ 时 2 V ✓，$t \to \infty$ 时 5 V ✓。

**第 2 步里"从储能元件看进去的戴维南电阻"，正是上一课的分压/等效定理发挥作用的地方**——这就是卷六里"先讲等效、再讲动态"的编排理由。

</details>
