# 从原理图到 PCB

## 1. 从一个场景开始

板子打样回来了，焊好元件，一上电——**冒烟了。**

查了一下午才发现：原理图上那个三极管的符号，集电极和发射极画反了。改这个错误需要多久？

- 如果在**网表检查**阶段发现：改一下连线，30 秒；
- 如果在**焊接后**发现：割线、飞线、把三极管翻过来焊，半小时，且板子从此带着隐患；
- 如果在**量产后**发现：召回、改版、重新认证，几周到几个月。

同一个错误，**越往后发现的代价越大，而且是指数级的**。这就是本课唯一要讲的道理——以及一条能把这个代价压到最低的流程。

## 2. 直觉解释

把 PCB 设计想成**写文章**：

| 阶段 | 写文章的对应 | 改错成本 |
| --- | --- | --- |
| 原理图 | 列提纲 | 划掉重写一句话 |
| 网表检查 | 检查逻辑是否自洽 | 改几处引用 |
| 布局 | 排版布局 | 挪段落 |
| 布线 | 逐句写正文 | 重写整段 |
| DRC | 校对错别字 | 挑错别字 |
| 制板 | 印刷 | 重印 |
| 焊接测试 | 读者反馈 | 召回 |

关键差别在于：**写代码错了最多跑不通，写 PCB 错了会烧东西。** 所以电子设计发展出了一整套"提前检查"的机制：ERC（电气规则检查）、DRC（设计规则检查）、网表比对、3D 干涉检查。

**这些检查不是形式主义，每一条都对应历史上某一次真实的烧板事故。**

## 3. 正式定义

PCB 设计流程的七个阶段与各自的输入输出：

| # | 阶段 | 输入 → 产出 | 关键检查 |
| --- | --- | --- | --- |
| 1 | **原理图** | 想法 → 器件符号 + 连线 | 位号唯一、封装已指派 |
| 2 | **网表** | 原理图 → 元件清单 + 连接关系 | ERC 清零、BOM 完整 |
| 3 | **布局** | 网表 → 板上物理位置 | 信号流、去耦电容紧贴 IC |
| 4 | **布线** | 位置 → 铜箔连接 | 线宽按电流、地平面完整 |
| 5 | **DRC** | 布线 → 规则校验 | 线宽/间距/孔径/丝印 |
| 6 | **制板** | Gerber → 实物 PCB | 单位精度、钻孔文件、工艺边 |
| 7 | **焊接测试** | PCB + 元件 → 可工作板卡 | 分模块上电、AOI、飞线记录 |

**几条硬规则**（不是建议，是必须）：

1. **去耦电容紧贴 IC 电源脚**：走线电感会吃掉高频。经验值：电容到电源脚的走线总长 < 5 mm，过孔也算长度；
2. **完整地平面**：信号的回流路径总是走"电感最小"的路径，也就是**正下方**。地平面被割裂 → 回流绕大圈 → EMC 灾难；
3. **线宽按电流算**：1 oz 铜厚（35 µm）下，**10 mil（0.254 mm）约走 1 A**，且要留 50% 余量；
4. **先走电源与地，再走时钟与差分，最后走一般信号**；
5. **拐角用 45°**，避免直角（蚀刻均匀性与阻抗都更稳）。

## 4. 分步例题

**例**：一块 4 层板要给 2 A 的电机驱动供电，电源走线该多宽？

1. **基础规则**：1 oz 铜厚下 10 mil ≈ 1 A；
2. **基本宽度**：$2\ \text{A} \times 10\ \text{mil/A} = 20$ mil；
3. **留余量**（工程惯例取 1.5~2 倍）：$20 \times 1.5 = 30$ mil = 0.76 mm；
4. **温升校核**：IPC-2221 的经验公式给出，10 ℃ 温升下 2 A 需要约 30 mil（外层，1 oz）——与上面吻合；
5. **更省面积的做法**：若板子空间紧张，可改用 2 oz 铜厚（线宽可减半），或把这条走在内层并**开窗露铜加锡**（加厚导体）；
6. **别忘了过孔**：一个 0.3 mm 孔径的过孔大约只能过 1 A。**2 A 至少要放 2~3 个过孔并联**，且要查过孔的载流能力表。

**第 3 步的"余量"不是保守，是必要**：铜箔的实际厚度有 ±10% 公差，环境温度可能到 60 ℃，且铜的电阻率随温度上升。**按"刚好"设计的走线，在夏天会变成保险丝。**

## 5. 动手实验

### 实验 1（lab）：七段流程，点开看要点与坑

```lab

  "title": "从原理图到 PCB：七个阶段，代价递增",
  "step": 0

```

点方块或用方向按钮切换七个阶段，每个阶段都列出**要点**与**常见坑**。建议按这个顺序走一遍，并在每一站问自己一句"如果我这里偷懒，后面会付出什么代价"。

重点关注三站：

- **网表**：它是唯一真相——布线软件只认网表，不认你画得多漂亮。ERC 没清零就往下走，等于带着已知的定时炸弹开工；
- **布局**：去耦电容的位置**就是**去耦电容的功能。放远了等于没放，而这是新手板最常见的失败原因；
- **DRC**：清零只是及格线。真正要命的是那些 DRC 不检查的东西——器件 3D 高度与外壳干涉、丝印压在焊盘上、过孔盖油没勾。

### 实验 2（python）：一份 BOM 自检脚本

```python title="导出网表前，用几行代码先把低级错误挑出来"
refs = ["R1", "R2", "R3", "C1", "R3", "U1", "C2", "U1"]   # 位号清单
footprint = {"R1": "0603", "R2": "0603", "R3": "0603",
             "C1": "0603", "U1": "SOT-23"}      # 故意漏了 C2：它还没指派封装
no_fp = []

seen = []
dups = []
for r in refs:
    if r in seen:                 # 第二次出现 → 位号重复
        dups.append(r)
    else:
        seen.append(r)
    if not footprint.get(r):      # get：按键取值，取不到返回 None，not None 为真
        no_fp.append(r)

# 三元表达式：条件为真取冒号左边的值，为假取右边
print("重复位号:", dups if dups else "无")
print("缺封装:", no_fp if no_fp else "无")
print(f"唯一位号 {len(seen)} 个，共 {len(refs)} 条记录")
```

输出会点名 `R3` 与 `U1` 重复，并指出 `C2` 还没指派封装。**位号重复是网表阶段最阴险的错误**——两个物理元件被当成同一个，布线软件会把它们的引脚连在一起，而你在原理图上完全看不出来。

这类小脚本在现代 EDA 工具里已经被内置成 ERC 规则，但**自己写一遍能让你真正理解它在检查什么**——这正是"工具替代不了理解"的地方。

### 快问快答

```quiz
为什么去耦电容必须紧贴 IC 的电源脚，而不是随便放在板子上的电源入口？
- 为了省地方
- 走线本身有电感，距离越远高频阻抗越大，去耦在高频段就失效了 [*]
- 为了防止电容被碰掉
? 一毫米的走线约有 1 nH 电感，在 100 MHz 上就是 0.63 Ω。去耦电容要对抗的正是高频电流突变，走线电感会让它完全派不上用场。所以布局时的口号是「先电容后 IC」。
```

:::warning[常见误区]

**误区一**："原理图没错，PCB 就不会错。"
你以为原理图是终点——原理图只定义**连接关系**，不定义**长度、宽度、回路面积、寄生参数**。而高频与功率电路的性能，几乎全由这些"原理图上看不见"的东西决定。**一张完美的原理图配一块糟糕的板子，结果是一块糟糕的产品。**

**误区二**："DRC 清零了，板子就没问题了。"
你以为 DRC 是全能的——它只检查你**告诉它的规则**（线宽、间距、孔径、丝印）。它不会告诉你：去耦电容放得太远、地平面被割裂、差分对长度不匹配、发热元件挨着电解电容、晶振下方走了信号线。**DRC 是底线，不是天花板。**

**误区三**："先打一版试试，有问题再改。"
你以为快速迭代就行——打样周期 3~7 天、焊接调试 1~2 天，一轮就是一周多。更重要的是，**有些问题在"试"的时候不出现**：EMC 不合规、高低温失效、批量生产时的良率问题。所以电子设计强调"设计即正确"（design right first time），把力气花在前面的检查上，而不是后面的救火上。

:::

## 6. 练习

**练习 1**：这份 BOM 自检脚本把"先判断后记账"写成了"先记账后判断"，于是每个位号都会撞上自己。修到输出 `R3`：

```exercise
# @title: 练习：找出重复的位号
# @check: R3
# @hint: 判断「是否出现过」必须在把它记进 seen 之前做。代码把 append 提到了 if 前面，导致第一个元素必然被判为重复
refs = ["R1", "R2", "R3", "C1", "R3", "U1", "C2", "U1"]
seen = []
dup = ""
for r in refs:
    seen.append(r)              # ← 问题在这：先记账再判断，自己永远撞上自己
    if r in seen and dup == "":
        dup = r
print(dup)
```

**练习 2**：一块 1 oz 铜厚的双面板，要给 1.5 A 的电源走线，长度 50 mm。(a) 按经验规则走线至少多宽？(b) 这条走线的电阻大约多少？(c) 压降多大？是否可接受？

<details>
<summary>点开查看逐步解答</summary>

1. **线宽**：$1.5 \times 10 = 15$ mil（0.38 mm）；留 1.5 倍余量 → **22 mil（0.56 mm）**，取标准值 25 mil（0.64 mm）；
2. **截面积**：$25\ \text{mil} = 0.635$ mm，铜厚 35 µm，所以 $A = 0.635\times0.035 = 0.0222$ mm² $= 2.22\times10^{-8}$ m²；
3. **电阻**：$R = \rho l/A = 1.68\times10^{-8}\times0.05/(2.22\times10^{-8}) = 0.0378\ \Omega$；
4. **压降**：$V = 1.5\times0.0378 = 0.057$ V = 57 mV；
5. **结论**：5 V 电源上掉 57 mV（1.1%）完全可接受；但若是 1.8 V 的核心电压，1.1% 也在典型 ±3% 容差内 ✓。

**注意这里"余量"的意义**：如果按 15 mil 走，电阻变成 63 mΩ、压降 95 mV。对 5 V 无所谓，对 1.2 V 的核心电压就是 8%——**低压大电流场合的电源完整性，是另一门专门的学问**（第 72 章会展开）。

</details>

## 7. 选读：为什么地平面如此重要

<details>
<summary>选读 · 回流路径与回路面积</summary>

很多初学者以为"地"就是一个公共接地点，电流从负载流回电源"走哪条路都一样"。**大错特错。**

高频电流选择的路径是**电感最小**的那条，而不是电阻最小的。对一根走在地平面上方的信号线，电感最小的回流路径就是**正下方的地平面**——因为这样信号线与回流构成的**回路面积最小**，而回路电感正比于面积。

后果有两条：

1. **回路面积 = 天线效率**。面积越大，辐射越强、也越容易接收外界干扰。地平面被割裂（比如一条走线横穿地平面、或者密密麻麻的过孔把地掏成筛子）时，回流被迫绕大圈，EMC 性能断崖式下降；
2. **回路电感会破坏信号完整性**。$V = L\, di/dt$，一个 10 nH 的回路电感在 1 A/ns 的电流变化下就产生 10 V 的地弹（ground bounce）——足以让数字电路误判逻辑电平。

**实践准则**：

- 多层板至少留一整层做地，**不在地平面上走信号线**；
- 若必须换层，在信号过孔旁边放一个**地过孔**给回流提供通路；
- 高速信号线下方**永远**有连续的参考平面；
- 去耦电容的接地端到地平面的过孔要短、要多。

这些规则都不是玄学——**每一条都能用"回路电感"三个字解释清楚**。

</details>
