# 电感：电流的惯性

## 1. 从一个场景开始

用三极管驱动一只 12 V 继电器，电路简单到不能再简单。可每次断开继电器，驱动三极管就"啪"地一声失效——有时还伴随着一声脆响。

用示波器看一眼三极管的集电极：在关断的那一瞬间，那里出现了一个 **268 V 的电压尖峰**。电源只有 12 V，268 V 从哪来？

答案是：**电感不许电流中断。** 你强行切断它的电流通路，它就自己造出一个足够高的电压，把电流硬顶出去——哪怕要击穿空气。

## 2. 直觉解释

电感是电容的**镜像**。记住这张对偶表，模电就少背一半：

| | 电容 $C$ | 电感 $L$ |
| --- | --- | --- |
| 顶住的量 | 电压 $v$（不能突变） | 电流 $i$（不能突变） |
| 定义式 | $i = C\dfrac{dv}{dt}$ | $v = L\dfrac{di}{dt}$ |
| 储能 | $W = \frac{1}{2}Cv^2$ | $W = \frac{1}{2}Li^2$ |
| 阻碍的是 | 电压的变化 | 电流的变化 |
| 直流稳态 | 开路（隔直） | 短路（通直） |

直觉图像是**飞轮**（或者一长段高速流动的水）：

- 飞轮转起来以后，你没法让它瞬间停下——硬停它需要无穷大的力矩；
- 电流在电感里流动时建立了磁场，磁场储存着能量；你切断回路，磁场**必须**把能量释放出去；
- 释放的方式是：感应出一个电压，维持原来的电流方向，直到能量耗尽。

**电感是电流的飞轮，电容是电压的水箱。** 一个是动量，一个是弹性。

## 3. 正式定义

**电感** $L$：单位电流变化率下产生的感应电压，单位**亨利**（H）

$$v = L \frac{di}{dt}$$

**积分形式**：

$$i(t) = i(t_0) + \frac{1}{L}\int_{t_0}^{t} v(\tau)\, d\tau$$

**储能**：

$$W = \frac{1}{2} L i^2$$

**RL 电路的时间常数**（与 RC 对偶）：

$$\tau = \frac{L}{R}$$

**断电尖峰的估算**（能量从电感全部转入杂散电容 $C_s$）：

$$\frac{1}{2}Li_0^2 = \frac{1}{2}C_s v_{\text{pk}}^2 \quad\Longrightarrow\quad v_{\text{pk}} = i_0\sqrt{\frac{L}{C_s}}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $L$ | 电感 | 亨利 H | 常用 mH、µH |
| $i$ | 电流 | 安培 A | **不能突变**，是连续量 |
| $v$ | 电压 | 伏特 V | 可以突变，甚至可以反向、尖峰 |
| $di/dt$ | 电流变化率 | A/s | 变化越快，感应电压越高 |
| $\tau$ | 时间常数 | 秒 s | $\tau = L/R$，不是 $LR$ |

## 4. 分步例题

**例**：$L = 10$ mH、$R = 100\ \Omega$ 的继电器线圈接在 12 V 电源上。(a) 稳态电流多大？(b) 时间常数多长？(c) 突然断开，若杂散电容 $C_s = 2$ nF，尖峰多高？

1. **稳态电流**：电流稳定后 $di/dt = 0$，电感等效为短路，所以 $i_0 = V/R = 12/100 = 0.12$ A = 120 mA；
2. **时间常数**：$\tau = L/R = 0.010/100 = 10^{-4}$ s = 0.1 ms（继电器吸合大约在 3τ ≈ 0.3 ms 内完成）；
3. **储能**：$W = \frac{1}{2}Li_0^2 = 0.5 \times 0.01 \times 0.0144 = 7.2\times10^{-5}$ J = 72 µJ；
4. **尖峰**：$v_{\text{pk}} = i_0\sqrt{L/C_s} = 0.12 \times \sqrt{0.01/(2\times10^{-9})} = 0.12 \times \sqrt{5\times10^{6}} = 0.12 \times 2236 = 268$ V。

**72 µJ 的能量，12 V 的电源，打出 268 V 的尖峰。** 能量守恒从不算错——能量不变，但电压可以任意高，只要把能量塞进足够小的电容里（$W = \frac{1}{2}Cv^2$，$C$ 越小 $v$ 越夸张）。

**工程对策**：在继电器线圈两端**反向并联一只续流二极管**（比如 1N4148）。断电瞬间二极管导通，给电流提供一条续流回路，电压被钳在电源 + 0.7 V ≈ 12.7 V。代价是电流衰减变慢（$\tau = L/R$ 里的 $R$ 现在只有线圈电阻），继电器释放会延迟几毫秒。

## 5. 动手实验

### 实验 1（lab）：闭合与断开，两副面孔

```lab
{
  "type": "inductor-lab",
  "title": "电感：电流连续，电压可以尖峰",
  "sliders": [
    { "name": "L", "label": "电感 L", "min": 0.5, "max": 100, "step": 0.5, "value": 10 },
    { "name": "R", "label": "串联电阻 R", "min": 20, "max": 1000, "step": 10, "value": 100 },
    { "name": "Cs", "label": "杂散电容 Cs", "min": 0.2, "max": 20, "step": 0.2, "value": 2 }
  ]
}
```

先用"闭合开关"档看通电过程：

- 蓝线（电流）从 0 圆滑爬升到 $V/R$ 的渐近线，**从不跳跃**；
- 红线（电压）在合闸瞬间**直接跳到 12 V**，然后指数衰减到 0。

再用"断开开关"档看断电瞬间：红线不再温柔——它振荡并冲到几百伏。做两组对照：

- 把 L 从 10 mH 拖到 40 mH：储能按 $L$ 线性增加，尖峰按 $\sqrt{L}$ 增加（约翻倍）；
- 把 Cs 从 2 nF 拖到 8 nF：尖峰按 $1/\sqrt{C}$ **下降一半**——这就是为什么有时"故意加一点点电容"能压制尖峰，也是缓冲（snubber）电路的原理。

### 实验 2（python）：尖峰高度与杂散电容的关系

```python title="扫杂散电容，看尖峰如何被压下去"
import math

V = 12.0
R = 100.0
L = 10e-3              # 电感（H）
i0 = V / R             # 断开前的稳态电流（A）
W = 0.5 * L * i0 * i0  # 储存在磁场里的能量（J）

print(f"稳态电流 {i0*1000:.0f} mA，储能 {W*1e6:.1f} µJ")
print("Cs(nF)   尖峰(V)")
for Cs_nF in [0.5, 1, 2, 5, 10, 47]:
    Cs = Cs_nF * 1e-9
    vpk = i0 * math.sqrt(L / Cs)      # sqrt：开平方
    print(f"{Cs_nF:>5}    {vpk:7.1f}")
```

六行输出把这个反直觉的结论钉死：**杂散电容越小，尖峰越高**。加到 47 nF（相当于在触点两端并一颗 47 nF 的缓冲电容），尖峰从 537 V 降到 55 V。这就是为什么继电器触点要配 RC 缓冲、MOSFET 漏极要加吸收电路——**不是在"吸收"能量，而是在给能量一个更大的容器，让电压涨不起来。**

### 快问快答

```quiz
断开电感回路时出现高压尖峰，最常见的抑制手段是什么？
- 串联一颗大电阻，把电流限住
- 反向并联一只续流二极管，给电流留一条退路 [*]
- 并联一颗大电容直接把电感短路
? 电感要的是「电流不能中断」，不是「电压不能升高」。续流二极管在断电瞬间导通，让电流继续沿原方向环流，电压被钳在约 0.7 V + 电源电压，能量在线圈电阻上慢慢耗掉。
```

:::warning[常见误区]

**误区一**："电感的时间常数是 $\tau = LR$，跟 RC 一样是乘法。"
你以为是乘法——其实**是除法** $\tau = L/R$。检验量纲就知道：$L/R$ 的单位是 H/Ω = (V·s/A)/(V/A) = s，是时间；而 $LR$ 的单位完全不是时间。记法口诀：**电阻越大，电流衰减越快**，所以 $R$ 在分母上。

**误区二**："续流二极管会让继电器释放变慢，所以能不加就不加。"
你以为可以省——加了确实会变慢（因为电流衰减的 $\tau = L/R_{\text{线圈}}$ 比断电时大得多），但**不加的代价是三极管被击穿**。取舍很清楚：用一只几毛钱的二极管换掉一颗三极管，再用稳压管串联二极管（或用 TVS）可以兼顾速度——让续流电压升到 24 V 或更高，能量耗散加快，释放时间缩短。

**误区三**："电感的直流电阻很小，所以稳态时它相当于导线。"
你在直流下这么想没错，但别忘了**实际电感有寄生电容**。超过自谐振频率（SRF）以后，电感的行为会翻转成电容——一颗标称 10 µH 的电感在 50 MHz 上可能完全不是电感。这就是射频电路里电感选型必须查 SRF 的原因。

:::

## 6. 练习

**练习 1**：$L = 10$ mH 的电感，断开前电流 120 mA，杂散电容 2 nF。求尖峰电压。这段代码漏了开平方，修到输出 `268.3`：

```exercise
# @title: 练习：断电尖峰有多高
# @check: 268.3
# @hint: 能量从电感搬到电容：½Li² = ½Cv²，解出 v = i₀×√(L/C)。代码把根号丢了，直接用了 L/C
L = 0.010          # 电感（H）
C = 2e-9           # 杂散电容（F）
i0 = 0.120         # 断开前的电流（A）
v = i0 * (L / C)   # ← 问题在这：应该是 √(L/C)，即 (L/C) ** 0.5
print(round(v, 1))
```

**练习 2**：同样是 12 V / 100 Ω / 10 mH 的继电器，若在触点两端并联一颗 47 nF 的缓冲电容，电流衰减的时间常数大约变成多少？与不加缓冲时相比快了还是慢了？

<details>
<summary>点开查看逐步解答</summary>

1. 并联 47 nF 后，能量在 L 与 C 之间来回倒，形成 **LC 谐振**，振荡周期 $T = 2\pi\sqrt{LC} = 2\pi\sqrt{0.01 \times 47\times10^{-9}} = 2\pi \times 2.17\times10^{-5} = 136\ \mu$s；
2. 尖峰出现在**四分之一周期**处，约 $34\ \mu$s，峰值 55 V（实验 2 已算）；
3. 相比之下，不加缓冲时杂散电容只有 2 nF，尖峰在 $2\pi\sqrt{0.01\times2\times10^{-9}}/4 = 7\ \mu$s 内就冲到 268 V；
4. **结论**：加缓冲后尖峰从 268 V 降到 55 V，代价是电压变化变慢（7 µs → 34 µs）。

缓冲电路的全部艺术就在这笔交易里：**用时间换电压**。而判断标准永远是——后级器件能承受多高的电压、以及多快的边沿。

</details>

## 7. 选读：为什么电感会把电压举得这么高

<details>
<summary>选读 · 从法拉第定律看 v = L·di/dt</summary>

法拉第电磁感应定律说，线圈中的感应电动势等于磁通链的变化率的负值：

$$v = -N\frac{d\Phi}{dt}$$

而磁通 $\Phi$ 与产生它的电流成正比（在磁芯未饱和时）：$N\Phi = L\, i$，其中 $L = N^2/R_m$（$R_m$ 是磁路磁阻，$N$ 是匝数）。代入即得

$$v = -L\frac{di}{dt}$$

负号是**楞次定律**：感应电动势总是**反抗**电流的变化。电流要增大，它就产生反向电压顶住；电流要减小，它就产生同向电压维持——**这就是"惯性"这两个字的数学出处。**

注意匝数出现在平方项：$L \propto N^2$。所以电感量对匝数极其敏感（匝数翻倍，电感变四倍），这也是绕制电感时"多绕几圈"效果显著的原因。不过磁芯一旦饱和，$N\Phi$ 与 $i$ 不再成正比，$L$ 会骤降——开关电源的电感饱和是灾难性故障，会让电流直线飙升。

</details>
