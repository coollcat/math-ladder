# 交流功率与功率因数

## 1. 从一个场景开始

一家工厂的电费单上，除了"用了多少度电"，还有一项"功率因数调整费"——功率因数低于 0.9 要**加价**。

工厂老板不服：电表按有功电能（度）计费，我付了一分不少，凭什么罚款？

电力公司的回答是：**你只按"真正干的活"付钱，可我得按"搬运的总量"给你铺线路。** 变压器容量、导线截面、开关额定值，全都由总搬运量决定。你占用了双倍的容量，却只付一份的钱。

要理解这场争论，得先看懂一个反直觉的事实：**交流电路里，瞬时功率可以为负。**

## 2. 直觉解释

经典比喻是**一杯啤酒**：

- **液体部分** = **有功功率** $P$，真正解渴的东西（做功、发热、出力）；
- **泡沫部分** = **无功功率** $Q$，占着杯子却不管解渴（在电源与负载之间来回搬运）；
- **整杯容量** = **视在功率** $S$，你必须买一个能装下这么多泡沫的杯子。

为什么会有"泡沫"？因为电感和电容**不消耗能量，只是暂存能量**。半个周期里它们从电源吸收能量建立磁场/电场，另半个周期又把能量原封不动地送回来。这些能量在导线里来回跑，**占用了导线的电流容量，却一盏灯也没点亮。**

而 $p(t) = v(t)\cdot i(t)$ 为负的那些时刻，正是能量**从负载流回电源**的时刻。

## 3. 正式定义

设 $v(t) = \sqrt{2}V\sin\omega t$，$i(t) = \sqrt{2}I\sin(\omega t - \phi)$（$V$、$I$ 为**有效值**），则瞬时功率

$$p(t) = VI\cos\phi\,(1 - \cos 2\omega t) - VI\sin\phi\,\sin 2\omega t$$

它含有一个**直流分量**与一个**两倍频**分量。取平均：

**有功功率** $P$（单位 W，真正做功的速率）：

$$P = VI\cos\phi$$

**无功功率** $Q$（单位 var，来回搬运的速率）：

$$Q = VI\sin\phi$$

**视在功率** $S$（单位 VA，导线与变压器要承受的总量）：

$$S = VI = \sqrt{P^2 + Q^2}$$

**功率因数**：

$$\text{pf} = \cos\phi = \frac{P}{S}$$

**功率因数校正**（并联电容补偿感性负载）：

$$Q_C = P\left(\tan\phi_1 - \tan\phi_2\right), \qquad C = \frac{Q_C}{\omega V^2}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $P$ | 有功功率 | 瓦特 W | 真正转化为热、光、机械能的部分 |
| $Q$ | 无功功率 | 乏 var | 在电源与负载间往返，不做功 |
| $S$ | 视在功率 | 伏安 VA | $V_{\text{rms}}\times I_{\text{rms}}$，决定导线与变压器容量 |
| $\phi$ | 电压电流相位差 | rad | 感性负载 $\phi>0$（电流滞后），容性 $\phi<0$ |
| $\text{pf}$ | 功率因数 | — | $\cos\phi$，一般要求 ≥ 0.9 |

## 4. 分步例题

**例**：一台单相电机接在 220 V / 50 Hz 市电上，电流 5 A，电压超前电流 60°（$\phi = 60°$）。求 $P$、$Q$、$S$、pf，并计算把 pf 补到 0.95 所需的并联电容。

1. **视在功率**：$S = 220 \times 5 = 1100$ VA；
2. **有功**：$P = 1100\cos 60° = 1100 \times 0.5 = 550$ W；
3. **无功**：$Q = 1100\sin 60° = 1100\times0.866 = 952.6$ var；
4. **功率因数**：$\text{pf} = 0.5$——**远低于 0.9 的门槛，该罚款了**；
5. **补偿目标**：pf$_2 = 0.95$，对应 $\phi_2 = \arccos 0.95 = 18.19°$，$\tan\phi_2 = 0.3287$；
6. **需补无功**：$Q_C = 550\times(1.732 - 0.3287) = 550\times1.403 = 771.8$ var；
7. **电容值**：$C = \dfrac{771.8}{2\pi\times50\times220^2} = \dfrac{771.8}{1.521\times10^7} = 5.08\times10^{-5}$ F = **50.8 µF**；
8. **效果**：补偿后总电流从 5 A 降到 $S_2/V = (550/0.95)/220 = 2.63$ A——**线路电流几乎减半**，这正是电力公司真正在意的东西。

## 5. 动手实验

### 实验 1（lab）：p(t) 的两倍频与负半周

```lab

  "type": "ac-power",
  "title": "交流功率：有功、无功与功率三角形",
  "sliders": [
    { "name": "V", "label": "电压有效值 Vrms", "min": 1, "max": 400, "step": 1, "value": 220 },
    { "name": "I", "label": "电流有效值 Irms", "min": 0.1, "max": 20, "step": 0.1, "value": 5 },
    { "name": "phi", "label": "相位差 φ", "min": -90, "max": 90, "step": 1, "value": 30 },
    { "name": "f", "label": "频率 f", "min": 10, "max": 200, "step": 5, "value": 50 }
  ]
}
```

三条轨道从上到下：$v(t)$、$i(t)$、$p(t) = v\cdot i$。三个观察点：

- **$p(t)$ 的频率是电压的两倍**——两个正弦相乘产生了 $2\omega$ 分量（积化和差），它一周期要"鼓"两次；
- **$\phi \ne 0$ 时 $p(t)$ 有红色负半周**——这一段能量正在从负载流回电源，也就是"泡沫"在往返；
- 把 $\phi$ 拖到 0：$p(t)$ 负半周消失，最低点恰好贴住 0，$P = S$，功率因数 = 1；
- 把 $\phi$ 拖到 90°：紫色平均线降到 0，**一点有功都没有**，可电流照样在导线里流。

右侧的功率三角形把 $P$（横）、$Q$（纵）、$S$（斜边）画成直角三角形，$\phi$ 就是底角。拖动 $\phi$ 看三角形如何变形——这就是"啤酒与泡沫"的几何版本。

### 实验 2（python）：补偿电容一算就出

```python title="把功率因数补到 0.95，需要多大的电容"
import math

V, I, phi1_deg, f = 220.0, 5.0, 60.0, 50.0
phi1 = math.radians(phi1_deg)          # radians：角度转弧度
S = V * I
P = S * math.cos(phi1)
Q = S * math.sin(phi1)

for target in [0.8, 0.9, 0.95, 0.99]:
    phi2 = math.acos(target)           # acos：反余弦，由 cos φ 求 φ（弧度）
    QC = P * (math.tan(phi1) - math.tan(phi2))
    C = QC / (2 * math.pi * f * V * V)
    I2 = (P / target) / V              # 补偿后的线路电流
    print(f"pf={target:.2f}  需补 {QC:6.1f} var  C={C*1e6:5.1f} µF  电流 {I:.2f}→{I2:.2f} A")
```

四行输出把这笔经济账算得明明白白：补到 0.8 要 35.5 µF、电流从 5.00 A 降到 3.13 A；补到 0.95 要 50.8 µF、降到 2.63 A；补到 0.99 要 57.5 µF，却只再降到 2.53 A。

**补偿是边际收益递减的**：从 0.8 到 0.95 花了 15 µF 换来 0.5 A，从 0.95 到 0.99 花 7 µF 只换来 0.1 A。这就是"为什么标准是 0.9 而不是 1.0"的经济学答案。

### 快问快答

```quiz
一个感性负载并联补偿电容后，负载本身消耗的有功功率会怎么变化？
- 变少，因为电容分担了一部分电流
- 不变，电容只补偿无功，有功由负载自己决定 [*]
- 变多，因为总电流变大了
? 并联电容提供的是本地的无功电流，电源侧的总电流因此减小，但负载两端的电压与它自身的阻抗都没变，所以有功功率纹丝不动。补偿改善的是「线路效率」，不是「负载消耗」。
```

:::warning[常见误区]

**误区一**："功率因数低就是浪费电，电表会多走字。"
你以为低 pf 会让你多交电费——**民用单相电表只计有功电能**，pf 低不会让你多付一度电的钱。低 pf 的代价由**电网**承担：线路电流增大 → $I^2R$ 损耗增大、变压器容量被占用、末端电压跌落。所以罚款只针对工业用户（他们的用电量足以影响电网）。

**误区二**："补偿电容越大越好，把 pf 补到 1.0 最完美。"
你以为越接近 1 越好——**过补偿会反过来**。补过头后电路变成容性，$\phi$ 变负，$Q$ 反向流动，pf 数值又开始下降（只是方向反了）。更糟的是，补偿电容可能与系统电感在某次谐波频率上**谐振**，把谐波电流放大十倍，烧毁电容。工程上一般只补到 0.92~0.95，并且要串联电抗器做**失谐**处理。

**误区三**："$\text{pf} = \cos\phi$ 对任何负载都成立。"
你以为这是通用公式——它对**线性正弦**负载成立，对开关电源、变频器、LED 驱动这类**非线性**负载完全失效。这些负载的电流不是正弦（是尖脉冲），此时功率因数 = 位移因数 × 畸变因数，$\cos\phi$ 只算了前者。所以现代标准看的是**总谐波畸变 THD**，这也是"有源功率因数校正（PFC）"电路存在的原因。

:::

## 6. 练习

**练习 1**：220 V、550 W、952.6 var 的感性负载，要把 pf 补到 0.95，需要多大的并联电容？这段代码把无功全补掉了，修到输出 `50.8`：

```exercise
# @title: 练习：把功率因数补到 0.95 需要多大电容
# @check: 50.8
# @hint: 目标不是把无功清零，而是降到 P×tan(arccos 0.95)；需补量 Qc = Q − P×tan(φ₂)，再由 Qc = ωV²C 反解 C
import math

V = 220.0
P = 550.0
Q = 952.6
target = 0.95
phi2 = math.acos(target)          # 目标功率因数对应的相位角（弧度）
Qc = Q                            # ← 问题在这：不是把 Q 全部补掉
C = Qc / (2 * math.pi * 50 * V * V)
print(round(C * 1e6, 1))
```

**练习 2**：一台设备标称 1500 W，接在 220 V 市电上，功率因数为 0.7。(a) 线路电流多大？(b) 若补到 0.95，电流降到多少？(c) 若导线电阻为 0.5 Ω，补偿前后线路损耗各是多少？

<details>
<summary>点开查看逐步解答</summary>

1. **补偿前**：$I = P/(V\cdot\text{pf}) = 1500/(220\times0.7) = 9.74$ A；
2. **补偿后**：$I = 1500/(220\times0.95) = 7.18$ A；
3. **补偿前损耗**：$P_{\text{line}} = I^2R = 9.74^2\times0.5 = 47.4$ W；
4. **补偿后损耗**：$7.18^2\times0.5 = 25.8$ W；
5. **净收益**：省下 21.6 W，占负载功率的 1.4%——看似不多，但对一条上千米长的线路、或者几十台设备同时运行，年省电相当可观。

**这道题也揭示了功率因数的真正价值**：它不省"负载的电"，省的是"线路上的损耗"和"变压器的容量"。对单台设备，21.6 W 微不足道；对一座工厂，它是实打实的成本。

</details>

## 7. 选读：负功率到底意味着什么

<details>
<summary>选读 · 拆解 p(t) = v·i</summary>

用积化和差公式展开：

$$p(t) = \sqrt{2}V\sin\omega t \cdot \sqrt{2}I\sin(\omega t - \phi)$$

$$= 2VI \cdot \tfrac{1}{2}\bigl[\cos\phi - \cos(2\omega t - \phi)\bigr]$$

$$= VI\cos\phi - VI\cos(2\omega t - \phi)$$

第一项是**不随时间变化的常数**，正是有功功率 $P$——它始终为正（对感性负载），代表能量的净流向：从电源到负载。

第二项是**两倍频的余弦振荡**，其平均值为零。它代表能量在每个周期内"吸进去又吐出来"的那部分。当它的瞬时值大于第一项时，$p(t) < 0$，能量回流。

把第二项再展开：$\cos(2\omega t - \phi) = \cos 2\omega t\cos\phi + \sin 2\omega t \sin\phi$，第二部分的幅度是 $VI\sin\phi = Q$。**于是 $Q$ 就是那个"来回振荡"部分的幅度**——这不是巧合，而是 $Q$ 的物理定义：

$$Q = \omega\,(W_{L,\max} - W_{C,\max})$$

即无功功率等于角频率乘上磁场与电场储能峰值之差。电感"要"无功，电容"给"无功，两者相位相差 180°——**这就是为什么并联电容能补偿感性负载**：一个要一个给，就地结清，不必再来回跑腿。

</details>
