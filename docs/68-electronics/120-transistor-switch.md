# 晶体管：开关与放大

## 1. 从一个场景开始

单片机的 GPIO 引脚最多只能输出 20 mA——点亮一颗 LED 尚可，驱动一只 80 mA 的继电器远远不够。

你需要一个**用 20 mA 控制 80 mA** 的器件，而且它最好是"全有或全无"的：**要么完全断开，要么完全导通**，绝不含糊。

这就是三极管（BJT）作为**开关**的用法。而同一个器件，稍微改一下偏置，就能变成放大器：电流放大 $\beta$ 倍。开关与放大，看似两种功能，其实是同一条曲线的两段。

## 2. 直觉解释

把三极管想成**水龙头**：

- 拧动把手用的力气 = **基极电流** $I_b$（小）；
- 流出来的水量 = **集电极电流** $I_c$（大）；
- 拧一圈能出多少水 = **放大倍数** $\beta$。

但有个关键限制：**水管本身有粗细上限。** 你拧得再狠，流量也不可能超过管道能通过的极限。这个上限由外电路给出——集电极电阻 $R_c$ 与电源电压 $V_{CC}$ 决定了天花板：

$$I_{c,\max} = \frac{V_{CC} - V_{CE(sat)}}{R_c}$$

于是有了三个工作区：

| 区域 | 把手状态 | 表现 | 用途 |
| --- | --- | --- | --- |
| **截止区** | 完全没拧 | $I_c \approx 0$，$V_{CE} \approx V_{CC}$ | 开关"断开" |
| **放大区** | 拧了一部分 | $I_c = \beta I_b$，与 $R_c$ 无关 | 放大器 |
| **饱和区** | 拧到底 | $V_{CE} \approx 0.2$ V，电流由外电路决定 | 开关"闭合" |

**做开关要故意往饱和里推**（$V_{CE}$ 压到 0.2 V 以下，管耗才小）；**做放大要待在放大区**，且尽量坐在负载线中段。

## 3. 正式定义

**电流放大**（放大区）：

$$I_c = \beta I_b, \qquad I_e = I_c + I_b = (\beta+1)I_b$$

**饱和条件**（开关导通）：

$$I_b > \frac{I_{c,\max}}{\beta} = \frac{V_{CC} - V_{CE(sat)}}{\beta R_c}$$

**过驱动倍数**（工程上取 2~10）：

$$\text{ODF} = \frac{\beta I_b}{I_{c,\max}}$$

**负载线**（外电路约束，画在 $I_c$–$V_{CE}$ 平面上）：

$$I_c = \frac{V_{CC} - V_{CE}}{R_c}$$

**管耗**：

$$P = V_{CE} \cdot I_c$$

| 符号 | 名字 | 典型值 | 含义 |
| --- | --- | --- | --- |
| $\beta$（$h_{FE}$） | 直流电流放大倍数 | 100（小信号管） | **离散度极大**，同型号可差 3 倍 |
| $V_{BE}$ | 基极导通压降 | 0.7 V（硅） | 与二极管同机理 |
| $V_{CE(sat)}$ | 饱和压降 | 0.1~0.3 V | 开关导通时的残余电压，越小越好 |
| $I_{c,\max}$ | 外电路给出的电流上限 | 由 $R_c$、$V_{CC}$ 决定 | 撞上去就进饱和 |
| ODF | 过驱动倍数 | 工程取 2~10 | 越大越可靠地饱和 |

## 4. 分步例题

**例**：用 5 V 的 GPIO 驱动一只 12 V / 80 mA 的继电器，三极管 $\beta = 100$，$V_{CC} = 12$ V，继电器线圈电阻 150 Ω。

1. **先算集电极电流上限**：线圈电阻就是 $R_c$，所以 $I_{c} = (12 - 0.2)/150 = 78.7$ mA（接近 80 mA，合理）；
2. **放大区所需的基极电流**：$I_b = 78.7/100 = 0.787$ mA；
3. **过驱动**：取 5 倍，$I_b = 3.9$ mA（留足 $\beta$ 离散与温度漂移的余量）；
4. **基极限流电阻**：$R_b = \dfrac{V_{GPIO} - V_{BE}}{I_b} = \dfrac{5 - 0.7}{0.0039} = 1103\ \Omega$，取标准值 **1 kΩ**；
5. **实际基极电流**：$(5-0.7)/1000 = 4.3$ mA，过驱动倍数 $= 100\times4.3/78.7 = 5.5$ 倍 ✓；
6. **管耗校验**：$P = V_{CE(sat)} \times I_c = 0.2 \times 0.0787 = 15.7$ mW——**远低于小信号管的 300 mW 上限**；
7. **别忘了续流二极管**：继电器是电感，关断尖峰必须由并联的 1N4148 吸收（第 60 课）。

**第 3 步的"过驱动"是整个设计的灵魂**。如果只按 $I_b = 0.787$ mA 设计，那么一颗 $\beta$ 偏低的管子（比如 60）就会退出饱和，$V_{CE}$ 涨到 2 V，管耗变成 $2\times0.0787 = 157$ mW，管子发烫、继电器吸合无力。**过驱动就是用几毛钱的电流，买来对器件离散度的免疫。**

## 5. 动手实验

### 实验 1（lab）：负载线上的三个世界

```lab

  "type": "transistor-switch",
  "title": "晶体管：Ic = β·Ib，直到撞上天花板",
  "sliders": [
    { "name": "Ib", "label": "基极电流 Ib", "min": 0, "max": 300, "step": 1, "value": 40 },
    { "name": "beta", "label": "放大倍数 β", "min": 20, "max": 300, "step": 5, "value": 100 },
    { "name": "Rc", "label": "集电极电阻 Rc", "min": 100, "max": 5000, "step": 100, "value": 1000 },
    { "name": "Vcc", "label": "电源电压 Vcc", "min": 3, "max": 24, "step": 1, "value": 12 }
  ]
}
```

右侧的图是整课的核心：六条虚线是不同 $I_b$ 对应的输出特性曲线，琥珀色斜线是**负载线**（外电路的约束），绿点 Q 是**工作点**。

拖动 $I_b$ 从 0 到 300 µA，看 Q 点如何沿负载线移动：

- **$I_b = 0$**：Q 点坐在右下角（截止区），$V_{CE} = 12$ V、$I_c = 0$——开关断开；
- **$I_b = 60$ µA**：Q 点移到负载线中段（放大区），$I_c = 6$ mA $= \beta I_b$，$V_{CE} = 6$ V——放大器就该待在这；
- **$I_b > 120$ µA**：Q 点撞进左侧红色饱和区底纹，$V_{CE}$ 卡在 0.2 V，$I_c$ 不再增长——**天花板到了**，再多基极电流也没用。

把 $\beta$ 从 100 拖到 300，饱和点提前到 $I_b \approx 40$ µA。这就是为什么过驱动必须按**最小** $\beta$ 计算：$V_{CC}=12$、$R_c=1$ kΩ 时 $I_{c,\max} = 11.8$ mA，若 $\beta$ 只有 50，需要 $I_b \ge 236$ µA 才饱和。

### 实验 2（python）：过驱动倍数扫描

```python title="β 离散 ±3 倍时，过驱动够不够"
VCC, RC, VCESAT = 12.0, 1000.0, 0.2
ic_max = (VCC - VCESAT) / RC          # 外电路给出的电流天花板
Rb = 1000.0
Ib = (5.0 - 0.7) / Rb                 # GPIO 5 V 经 1 kΩ 限流后的基极电流

print(f"Ic,max = {ic_max*1000:.2f} mA   Ib = {Ib*1000:.2f} mA")
print("β      β·Ib      饱和?   过驱动倍数")
for beta in [30, 50, 100, 200, 300]:
    forced = beta * Ib                # 放大区「想要」的电流
    sat = forced >= ic_max
    odf = forced / ic_max
    print(f"{beta:>3}  {forced*1000:7.1f} mA   {'是' if sat else '否'}      {odf:5.2f}×")
```

五行输出把可靠性问题摆到台面上：即使 $\beta$ 掉到 30（数据手册里的最小值常常就是这么低），过驱动倍数仍有 **10.9 倍**——深度饱和，稳如磐石。

反过来问一句更有意思：**这个设计的 $\beta$ 下限是多少？** 令 $\beta I_b = I_{c,\max}$ 得 $\beta_{min} = 11.8/4.3 = 2.7$。也就是说，只要管子的 $\beta$ 大于 2.7 就一定能饱和——**它已经对 $\beta$ 的离散度完全免疫了**。代价只是 4.3 mA 的 GPIO 电流，而 GPIO 的上限通常是 20 mA，完全付得起。

### 快问快答

```quiz
把一个用于开关的三极管驱动到深度饱和，为什么反而比刚好饱和更好？
- 饱和越深放大倍数越大
- 饱和越深 V_CE 越小，管耗 V_CE×Ic 越低，且不受 β 离散影响 [*]
- 饱和越深开关速度越快
? 开关应用要的是「V_CE 尽量接近 0」。深度饱和把 V_CE 压到 0.1~0.2 V，管耗随之降到最低；同时过驱动让饱和状态不再依赖 β 的离散度。代价是退出饱和稍慢（存储时间），但继电器这类毫秒级应用完全不在乎。
```

:::warning[常见误区]

**误区一**："$\beta$ 是器件的精确参数，手册写 100 就是 100。"
你以为可以精确设计——**同一批 2N3904 的 $\beta$ 可能从 80 到 300**，而且随温度上升、随 $I_c$ 变化（小电流和大电流时都会下降）。所以任何依赖具体 $\beta$ 值的电路都是坏设计。**负反馈（第 130 课）正是为了绕开这个问题而生的**：它让增益只由电阻比决定，与 $\beta$ 无关。

**误区二**："饱和时 $V_{CE} = 0$，所以管子不发热。"
你以为饱和零损耗——**$V_{CE(sat)}$ 典型 0.1~0.3 V，功率管可能 1~2 V**。1 A 电流下 $0.3\times1 = 0.3$ W，小信号管立刻超标。这就是为什么大电流场合要用 **MOSFET**：它的导通电阻 $R_{DS(on)}$ 可以低到几 mΩ，1 A 时压降只有几 mV。**BJT 是电流驱动、有饱和压降；MOSFET 是电压驱动、有导通电阻**——选型口诀。

**误区三**："基极不接电阻，直接连 GPIO 就行。"
你以为 GPIO 会自己限流——**$V_{BE}$ 钳在 0.7 V，而 GPIO 输出 5 V，中间的 4.3 V 没有着落**。不串限流电阻，GPIO 会试图输出几十 mA 甚至上百 mA，轻则电压被拉塌、重则烧毁引脚。**基极电阻不是可选项**，它的值按第 4 步的算法确定。

:::

**练习 1**：驱动 80 mA 的继电器线圈，$\beta = 100$，理论上至少需要多大基极电流（mA）？这段代码写成了乘法，修到输出 `0.8`：

```exercise
# @title: 练习：驱动继电器要多大基极电流
# @check: 0.8
# @hint: 放大区关系是 Ic = β·Ib，所以 Ib = Ic/β，不是 Ic×β。这里 Ic 用 mA、结果也是 mA
Ic_mA = 80.0      # 继电器线圈电流（mA）
beta = 100.0
Ib = Ic_mA * beta / 1000.0   # ← 问题在这：应该是 Ic / β
print(round(Ib, 2))
```

**练习 2**：$V_{CC} = 5$ V，$R_c = 470$ Ω，$\beta = 150$，$V_{CE(sat)} = 0.2$ V。若基极串 4.7 kΩ 电阻接到 3.3 V 的 GPIO：(a) 基极电流多大？(b) 过驱动倍数是多少？(c) 若 $\beta$ 掉到 50，还能饱和吗？

<details>
<summary>点开查看逐步解答</summary>

1. **基极电流**：$I_b = (3.3 - 0.7)/4700 = 0.553$ mA；
2. **电流上限**：$I_{c,\max} = (5 - 0.2)/470 = 10.2$ mA；
3. **过驱动**：$\beta I_b = 150\times0.553 = 83$ mA，$\text{ODF} = 83/10.2 = 8.1$ 倍 ✓ 深度饱和；
4. **$\beta = 50$ 时**：$\beta I_b = 27.7$ mA，$\text{ODF} = 27.7/10.2 = 2.7$ 倍 —— **依然饱和** ✓；
5. **极端检查**：即使 $\beta$ 掉到 20，$20\times0.553 = 11.1$ mA 仍略大于 10.2 mA，勉强饱和。

**这个设计是稳妥的**：8 倍过驱动让它在 $\beta$ 从 20 到 300 的整个范围内都能可靠饱和。要付出的代价只是 0.55 mA 的 GPIO 电流——**在这个数量级上，可靠性远比省电重要。**

</details>

## 7. 选读：为什么 $\beta$ 这么不可靠

<details>
<summary>选读 · 从 Ebers-Moll 模型看 β 的来源</summary>

BJT 的集电极电流由发射极注入到基区的少数载流子决定，而基极电流是"补上基区中复合掉的那部分"所需的电流。所以

$$\beta = \frac{\text{到达集电极的载流子数}}{\text{基区中复合掉的载流子数}}$$

这个比值取决于两个**工艺参数**：基区宽度 $W_B$ 与少子扩散长度 $L_n$。粗略地

$$\beta \propto \frac{L_n^2}{W_B^2}$$

基区做得越薄、材料越纯，$\beta$ 越大。可这两个量在制造中无法精确控制——**同型号不同批次差 3 倍是常态，同一批次差 2 倍也不稀奇**。

此外 $\beta$ 还有三重依赖：

- **温度**：每升高 1℃ 增加约 0.5%~1%；
- **集电极电流**：小电流时表面复合占比上升、大电流时大注入效应，$\beta$ 在中间某处有个峰值；
- **$V_{CE}$**：Early 效应让 $I_c$ 随 $V_{CE}$ 缓慢上升（输出特性曲线上翘）。

**结论**：任何把 $\beta$ 当常数的电路都是脆弱的。真正的解法不是"挑管子"，而是**用负反馈让电路增益与 $\beta$ 无关**——这正是第 130 课运放电路的核心思想，也是模拟电路设计的第一原则。

</details>
