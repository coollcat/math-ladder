# 电子电路与电子设计 · 参考资料

本章涉及的核心论文、原著与延伸阅读，按课程推进顺序整理。

文献页面对所有人开放；带归档副本的条目，未登录点「原站下载」前往出处，登录后点「本地下载」直接取本站副本。

```paper
# @title: Die galvanische Kette, mathematisch bearbeitet（电路的数学研究）
# @authors: Georg Ohm（格奥尔格·欧姆）
# @year: 1827
# @venue: 柏林首版（德文）
# @tag: 原著
# @desc: 「电流正比于电压、反比于电阻」第一次被写成公式——第 2 课那颗 150 Ω 限流电阻的全部依据都在这里。
# @page: https://en.wikipedia.org/wiki/Ohm%27s_law
```

```paper
# @title: Ueber den Durchgang eines electrischen Stromes durch eine Ebene（论电流通过平面的传导）
# @authors: Gustav Kirchhoff（古斯塔夫·基尔霍夫）
# @year: 1845
# @venue: Poggendorff's Annalen der Physik
# @tag: 原著
# @desc: KCL 与 KVL 的出生证明：把「节点」和「回路」变成可列的方程，电路从此不再靠直觉，而是一门线性代数。
# @page: https://en.wikipedia.org/wiki/Kirchhoff%27s_circuit_laws
```

```paper
# @title: A Dynamical Theory of the Electromagnetic Field（电磁场的动力学理论）
# @authors: James Clerk Maxwell（麦克斯韦）
# @year: 1865
# @venue: Philosophical Transactions of the Royal Society
# @tag: 原著
# @desc: 把电、磁、光统一进一组方程；本章电容与电感的「惯性」只是它在集总参数电路里投下的影子。
# @page: https://en.wikipedia.org/wiki/A_Dynamical_Theory_of_the_Electromagnetic_Field
```

```paper
# @title: Stabilized Feedback Amplifiers（稳定化反馈放大器）
```
