# DC-DC 变换器：开关 + 储能如何改电压

## 1. 从一个场景开始

一块 12 V 铅酸电池要给 5 V / 2 A 的单片机供电。上一课的 7805 会怎样？它把多余的 $12-5=7$ V 全部烧成热，$P=7\times2=14$ W——**比负载拿到的 10 W 还多，效率只有 41.7%**，不加散热片十几秒就烫手。

换成一颗拇指大的 Buck 模块：输入 12 V、输出 5 V、2 A，效率 92%，摸上去温温的。同样是"把 12 V 变成 5 V"，它凭什么不烧东西？本课拆开这颗模块，回答一个问题：**开关加上电感和电容，怎么凭空把电压改掉？**

## 2. 直觉解释

线性稳压器靠"烧掉多余电压"工作，所以注定低效。DC-DC 变换器换了个思路：**让开关只工作在两个极端状态**。

Buck 降压的核心只有三个元件：一个开关（MOSFET）、一个电感、一个电容，外加一个续流二极管。

- **开关导通**：输入电压加在电感上，电感电流**线性上升**，同时向负载供电；
- **开关断开**：电感电流不能突变（这是第 60 课的"电流惯性"），它自己变成一个电源，经二极管给负载**续流**，电流**线性下降**。

一个周期里，电感电流先升后降，**平均值就是负载电流**。而输出平均电压由"导通时间占整个周期的比例"决定——这个比例叫**占空比** $D$。电感负责平滑电流、电容负责平滑电压，于是斩波后的方波被平均成了平稳的直流。

关键在开关本身：导通时它两端电压 $\approx 0$，断开时流过它的电流 $\approx 0$，两种状态下 $P=VI$ 都近似为零。**能量不是被烧掉，而是被电感暂时存起来又放出去**——这就是效率能突破 90% 的全部秘密。

## 3. 正式定义

**占空比**与**开关周期**：

$$D=\frac{t_{on}}{T},\qquad T=\frac{1}{f_{sw}}$$

**伏秒平衡**（连续导通模式 CCM 的稳态判据）：一个周期内电感两端的电压积分为零，

$$\int_0^T v_L(t)\,dt = 0$$

因为电感电流每周期回到起点，"充电的伏秒数"必须等于"放电的伏秒数"。

**Buck（降压）**：

$$V_{out}=D\,V_{in},\qquad \Delta I_L=\frac{(V_{in}-V_{out})\,D\,T}{L}$$

**Boost（升压）**：

$$V_{out}=\frac{V_{in}}{1-D},\qquad \Delta I_L=\frac{V_{in}\,D\,T}{L}$$

**CCM / DCM 边界**与**输出纹波**：

$$I_{crit}=\frac{\Delta I_L}{2},\qquad \Delta V_{out}\approx\frac{\Delta I_L}{8\,f_{sw}\,C}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $D$ | 占空比 | — | 导通时间占周期的比例，$0<D<1$ |
| $f_{sw}$ | 开关频率 | Hz | 每秒切换次数，典型 100 kHz~2 MHz |
| $\Delta I_L$ | 电感纹波电流 | A | 电感电流的峰峰起伏 |
| $I_{crit}$ | 临界电流 | A | 负载小于它就从 CCM 掉进 DCM |
| $V_{out}$ | 输出平均电压 | V | 由 $D$ 决定，与负载几乎无关 |
| $\eta$ | 效率 | — | $P_{out}/P_{in}$，理想为 1 |

注意 Buck 与 Boost 的分工：Buck 的 $D<1$ 只会**降**压，Boost 的 $1/(1-D)$ 只会**升**压。想要既升又降，得把两者串起来（Buck-Boost）。

## 4. 分步例题

**例**：Buck 变换器，$V_{in}=12$ V、$V_{out}=5$ V、$f_{sw}=500$ kHz、$L=10$ µH、$C=47$ µF、负载电流 $I_{out}=2$ A。求占空比、电感纹波、工作模式与输出纹波。

1. **占空比**：$D=V_{out}/V_{in}=5/12=0.4167$；
2. **周期**：$T=1/500\text{k}=2\ \mu\text{s}$，故导通时间 $t_{on}=0.833\ \mu\text{s}$；
3. **电感纹波**（伏秒平衡）：
$$\Delta I_L=\frac{(12-5)\times0.4167\times2\times10^{-6}}{10\times10^{-6}}=0.583\ \text{A}$$
4. **工作模式**：临界电流 $I_{crit}=\Delta I_L/2=0.29$ A。负载 2 A $\gg$ 0.29 A，**工作在 CCM**，公式有效；
5. **电感电流上下限**：谷值 $I_{out}-\Delta I_L/2=1.71$ A，峰值 $I_{out}+\Delta I_L/2=2.29$ A。选电感时**饱和电流必须大于峰值**；
6. **输出纹波**：$\Delta V_{out}=0.583/(8\times500\text{k}\times47\,\mu\text{F})=3.1$ mV，约为输出的 0.06%，很干净；
7. **反例**：若把 $L$ 换成 1 µH，$\Delta I_L=5.83$ A，而 $2I_{out}=4$ A $<\Delta I_L$——电流还没到周期结束就被负载抽干，**掉进 DCM**，此时 $V_{out}=DV_{in}$ 不再成立，输出电压会往上飘。

第 7 步是设计里最容易被忽视的一条：**电感太小，轻载时公式就失效**。

**Boost 对照**：$V_{in}=12$ V、$D=0.5$，则 $V_{out}=12/(1-0.5)=24$ V。$D$ 越接近 1，输出越高——但现实中 0.9 以上的 $D$ 会因寄生电阻急剧掉效率，升压比通常不超过 5~10 倍。

## 5. 动手实验

### 实验 1（viz）：两种变换器的电压增益

```viz

  "expr": "x",
  "label": "Buck: M = D",
  "expr2": "1/(1-x)",
  "label2": "Boost: M = 1/(1-D)",
  "xmin": 0,
  "xmax": 0.92
}
```

横轴是占空比 $D$，纵轴是电压增益 $M=V_{out}/V_{in}$。蓝线是 Buck：一条穿过原点的直线，$D=0.5$ 时增益刚好 0.5，**永远不超过 1**。橙线是 Boost：起点在 $M=1$，随 $D$ 增大**向上弯成双曲线**，$D=0.9$ 时已经到 10 倍，越靠右越陡——这就是"高升压比很难做"的图形证据：$D$ 想再挪一点点，增益就猛涨，容差和寄生参数会把输出搅得一团乱。

### 实验 2（python）：画出电感电流的三角波

```python title="Buck 的电感电流波形：一个周期先升后降"
import math                      # 数学工具库：用 pi
import matplotlib.pyplot as plt  # 画图库

Vin, Vout = 12.0, 5.0            # 输入、输出电压（V）
f_sw = 500e3                     # 开关频率 500 kHz
L, C = 10e-6, 47e-6              # 电感 10 µH、电容 47 µF
Iout = 2.0                       # 负载电流 2 A

D = Vout / Vin                   # 占空比：输出除以输入（Buck）
T = 1 / f_sw                     # 开关周期（秒）
dI = (Vin - Vout) * D * T / L    # 电流纹波峰峰值（伏秒平衡推导）
print("占空比 D =", round(D, 4))              # 0.4167
print("纹波峰峰 =", round(dI, 3), "A")        # 0.583
print("谷值 / 峰值 =", round(Iout - dI / 2, 3), "/", round(Iout + dI / 2, 3))  # 1.708 / 2.292
print("临界电流 =", round(dI / 2, 3), "A")    # 0.292
print("输出纹波 =", round(dI / (8 * f_sw * C) * 1000, 2), "mV")  # 3.1

# 画一个周期内的电感电流：前 D 段线性上升，后 (1-D) 段线性下降
ts = []                          # 时间轴（微秒）
iL = []                          # 电感电流轴（A）
N = 200                          # 采样点数
for k in range(N):
    frac = k / N                 # 归一化时间 0~1
    t = frac * T                 # 真实时间（秒）
    if frac < D:                 # 开关导通段：电流上升
        i = Iout - dI / 2 + (Vin - Vout) / L * t
    else:                        # 开关断开段：电流下降
        i = Iout + dI / 2 - Vout / L * (t - D * T)
    ts.append(t * 1e6)           # 换算成微秒
    iL.append(i)

fig, ax = plt.subplots(figsize=(7, 2.5))   # 一块画布
ax.plot(ts, iL, linewidth=1.5)             # 画电感电流三角波
ax.axhline(Iout, linestyle="--", linewidth=0.8)  # 虚线标出平均值 = 负载电流
ax.set_xlabel("时间 (µs)")                 # 横轴标签
ax.set_ylabel("i_L (A)")                   # 纵轴标签
plt.tight_layout()
```

输出的五个读数里，`0.4167` 是占空比、`0.583` 是纹波、`1.708 / 2.292` 是电流的谷值峰值、`3.1 mV` 是输出纹波。图上那条锯齿波纹围绕虚线上下摆动，**平均值恰好落在 2 A**——因为稳态下电容不积累电荷，电感送出的平均电流必须等于负载抽走的电流。把 $L$ 改小，锯齿变胖；把 $f_{sw}$ 调高，锯齿变瘦。这就是"电感管纹波、频率也管纹波"的手感。

## 6. 常见误区

:::warning[常见误区]

**误区一**："占空比 50% 就一定输出一半电压。"
你以为 $V_{out}=DV_{in}$ 是普适规律——它**只对 Buck、且只在 CCM 下成立**。Boost 在 $D=0.5$ 时输出是输入的 2 倍，Buck-Boost 是 $D/(1-D)$ 倍。更隐蔽的是：Buck 在轻载掉进 DCM 后，$V_{out}$ 会明显**高于** $DV_{in}$。用公式前先确认拓扑和工作模式。

**误区二**："开关频率越高越好，纹波小、体积小。"
你以为提频只有好处——**开关损耗正比于频率**（每切换一次，开关管的寄生电容都要充放一次电），磁芯损耗也随频率上升。提频的代价是效率下降、EMI 变强、驱动电路更贵。真实设计是在纹波、体积、效率、EMI 四者之间挑一个折中点。

**误区三**："电感随便选一个够大的就行。"
你以为只要 $L$ 大纹波就小——其实电感有两个硬指标：**饱和电流**要大于峰值电流（例题里的 2.29 A），否则磁芯饱和、电感量骤降、电流失控炸管；**直流电阻**决定铜损。选小了饱和，选大了体积和成本又上去了。电感是 Buck 里最需要认真算的元件。

:::


**练习 2**：同一个 Buck（$V_{in}=12$ V、$V_{out}=5$ V、$L=10$ µH、$C=47$ µF、2 A 负载），把开关频率从 500 kHz 提到 1 MHz，纹波电流、临界电流、输出纹波各变成多少？这样做有什么代价？

<details>
<summary>点开查看逐步解答</summary>

1. **纹波电流**：$\Delta I_L\propto T=1/f_{sw}$。频率翻倍，$\Delta I_L$ 减半：$0.583/2=0.29$ A；
2. **临界电流**：$I_{crit}=\Delta I_L/2=0.146$ A。CCM 的范围更宽了，轻载更不容易掉进 DCM；
3. **输出纹波**：$\Delta V_{out}=\Delta I_L/(8f_{sw}C)$。分子分母同时减半、加倍，共缩小 4 倍：$3.1/4=0.78$ mV；
4. **代价**：开关损耗近似正比于 $f_{sw}$，翻倍后开关管和驱动电路的损耗上升，效率可能掉几个百分点；同时 1 MHz 的方波谐波更容易辐射 EMI，PCB 布局要求更严。**"用频率换纹波"是一笔明码标价的交易。**

顺带一个结论：如果只允许改一个元件来把纹波压一半，**加大电感**和**提高频率**等价——但加电感只增加体积和成本，提频率要付出效率与 EMI。这正是电源工程师每天在做的取舍。

</details>

## 8. 选读：伏秒平衡是怎么给出 $V_{out}=DV_{in}$ 的

<details>
<summary>选读 · 从电感电压积分推出两个增益公式</summary>

稳态下电感电流每周期回到起点，所以**电流的净变化为零**。由 $v_L=L\,di_L/dt$ 得 $di_L = v_L\,dt/L$，对一周期积分：

$$\Delta i_L = \frac{1}{L}\int_0^T v_L\,dt = 0 \;\Longrightarrow\; \int_0^T v_L\,dt = 0$$

这就是**伏秒平衡**：导通段加的"伏秒"必须被断开段还回去。

**Buck**：导通段电感左端接 $V_{in}$、右端是 $V_{out}$，故 $v_L=V_{in}-V_{out}$，持续 $DT$；断开段电感经二极管接负载，$v_L=-V_{out}$，持续 $(1-D)T$。代入：

$$(V_{in}-V_{out})\,DT + (-V_{out})(1-D)T = 0$$

两边除以 $T$：$(V_{in}-V_{out})D - V_{out}(1-D)=0$，整理得 $\boxed{V_{out}=DV_{in}}$。

**Boost**：导通段电感一端接 $V_{in}$、另一端被开关短接到地，$v_L=V_{in}$，持续 $DT$；断开段电感与输入串联给电容充电，$v_L=V_{in}-V_{out}$，持续 $(1-D)T$。于是：

$$V_{in}\,DT + (V_{in}-V_{out})(1-D)T = 0 \;\Longrightarrow\; \boxed{V_{out}=\frac{V_{in}}{1-D}}$$

同一个"面积为零"的判据，换一下电压的取值，就得到两条完全不同的增益公式。**这就是 DC-DC 分析的全部套路**：先画电感电压在一个周期内的波形，再让正负面积相等。

</details>
