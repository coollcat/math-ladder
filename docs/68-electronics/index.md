# 电子电路与电子设计

电子学研究如何**约束电子的运动**，让它按人类的意图搬运能量与信息。它是卷六唯一一门"你做错了会冒烟"的学科——也因此，它是把前面五卷的数学第一次逼到必须兑现的地方。

这一章的主线只有一条：**先建立两个守恒律（KCL / KVL），再引入两个惯性元件（C / L），然后把交流、非线性、反馈、离散化逐层加上去。**

## 方法主线

**守恒 → 惯性 → 复数 → 非线性 → 反馈 → 离散。**

前四课建立"电路是一个线性方程组"的世界观；五六两课引入储能元件，方程变成微分方程；九十两课用复数把微分方程打回代数；十一、十二课承认世界是非线性的，用分段与工作点近似；十三到十六课用负反馈把"不确定的器件"变成"确定的系统"；最后三课把模拟世界交还给数字世界。

## 生产状态

本章十九门课程全线成型：地基四课（电荷电流 → 欧姆定律 → 基尔霍夫 → 戴维南），动态四课（电容 → 电感 → RC → RLC），交流两课（相量阻抗 → 交流功率），半导体三课（二极管 → 晶体管 → 运放），系统四课（有源滤波 → 振荡器 → 电源稳压 → ADC/DAC），工程两课（PCB 流程 → 方法地图）。

## 实战挑战 · 5 V 点亮一颗 LED

> 场景说明：红色 LED 正向压降约 2.0 V、额定工作电流 20 mA，5 V 逻辑电源供电，均为公开器件手册的典型值。本题的操作情境为教学构造。

手头有一颗红色 LED（正向压降 $V_f = 2.0$ V，想要 20 mA 的工作电流）和一个 5 V 电源。直连会烧，必须串一颗限流电阻。下面这段代码忘了考虑 LED 自己吃掉的那 2 V，修到输出 `150.0`：

```exercise
# @title: 实战挑战：5 V 点亮 LED 要串多大电阻
# @check: 150.0
# @hint: 电阻分到的是「电源电压减去 LED 正向压降」后剩下的那部分电压；欧姆定律 R = V/I，电流 20 mA 要先换成 0.02 A
Vcc = 5.0          # 电源电压（V）
Vf = 2.0           # LED 正向压降（V）
I = 20.0 / 1000.0  # 目标电流（A）
R = Vcc / I        # ← 问题在这：电阻两端的电压不是全部 5 V
print(R)
```

<details>
<summary>点开查看逐步解答</summary>

1. LED 导通后两端压降锁在 $V_f = 2.0$ V，剩下的 $5.0 - 2.0 = 3.0$ V 全部落在电阻上；
2. 串联电路电流处处相等，电阻上流过的也是 20 mA = 0.02 A；
3. 欧姆定律：$R = \dfrac{3.0}{0.02} = 150\ \Omega$；
4. 校验功率：$P = I^2 R = 0.02^2 \times 150 = 0.06$ W = 60 mW，远低于 1/4 W 电阻的额定功率，安全。

初始代码算出 250 Ω——它把 5 V 全部分给了电阻，电流会掉到 12 mA，LED 偏暗。这个"忘记扣掉器件自身压降"的错误，是电子学入门的第一号事故。

</details>
