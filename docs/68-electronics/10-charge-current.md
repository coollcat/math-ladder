# 电荷、电流与电压

## 1. 从一个场景开始

手机电池上印着"4000 mAh"，充电头写着"5 V / 2 A"。前者是**容量**，后者是**速率**——可它们之间只差一个时间单位：

$$4000\ \text{mAh} = 4\ \text{A} \times 1\ \text{h}$$

也就是说，这块电池理论上能用 4 A 放一小时、2 A 放两小时、或者 1 A 放四小时。**"安时"是电流乘时间**——它不是电流，也不是能量，而是电荷。要搞清楚这三个词到底谁是谁，得从"电到底是什么在流"说起。

## 2. 直觉解释

把电路想成一套**闭合的水管系统**：

| 水路 | 电路 | 直觉 |
| --- | --- | --- |
| 水压（水泵给的） | **电压** $V$ | 推动水流的"压力差"，两点之间才有意义 |
| 水流量（每秒流过多少升） | **电流** $I$ | 单位时间内通过某个截面的电荷量 |
| 阀门 / 管径的阻碍 | **电阻** $R$ | 阻碍流动的程度（下一课的主角） |
| 流过的总水量 | **电荷** $Q$ | 累计量，单位是库仑 |

关键的一条：**水不是"用完就没了"，水一直在管子里循环。** 电路同理——电池并不"消耗电子"，它只是像水泵一样给电子加压，让它们在闭合回路里转圈，把能量交给灯泡，再空着手回来。

那么"电流"就不是"电在流动的速度"，而是**电荷的流量**：每秒有多少库仑的电荷穿过这根导线的某个截面。

## 3. 正式定义

**电荷** $Q$：物体带电的多少，单位**库仑**（C）。基本电荷（一个电子所带电荷量的绝对值）

$$e = 1.602 \times 10^{-19}\ \text{C}$$

**电流** $I$：电荷通过某截面的速率

$$I = \frac{\Delta Q}{\Delta t}$$

单位是**安培**（A），$1\ \text{A} = 1\ \text{C/s}$。

**电压**（电位差）$V$：把单位电荷从一点移到另一点所做的功

$$V = \frac{W}{Q}$$

单位是**伏特**（V），$1\ \text{V} = 1\ \text{J/C}$。

| 符号 | 名字 | 单位 | 一句话含义 |
| --- | --- | --- | --- |
| $Q$ | 电荷 | 库仑 C | 有多少"电"，累计量 |
| $I$ | 电流 | 安培 A | 电荷流得多快，速率量 |
| $V$ | 电压 | 伏特 V | 每库仑携带多少能量 |
| $t$ | 时间 | 秒 s | 把速率换成累计量的钥匙 |
| $e$ | 元电荷 | 库仑 C | 一个电子的电荷量，$1.602\times10^{-19}$ |

**参考方向**：电流是有方向的量，但导线里真正移动的是**带负电的电子**，它从负极流向正极；而电路图上标的电流方向（**常规电流方向**）习惯上取反——从正极流向负极。这个历史上的约定错误沿用至今，全世界的电路图都在用"反的"方向，却丝毫不影响计算，因为所有公式只要**前后一致**就成立。

## 4. 分步例题

**例**：手机以 2 A 恒流充电 30 分钟。问：(a) 充入多少库仑？(b) 相当于多少个电子？(c) 每秒有多少电子穿过充电线？

1. 时间换秒：$t = 30 \times 60 = 1800$ s；
2. 电荷：$Q = I \cdot t = 2 \times 1800 = 3600$ C；
3. 电子数：$n = Q / e = 3600 / 1.602\times10^{-19} = 2.25 \times 10^{22}$ 个；
4. 每秒电子数：$I / e = 2 / 1.602\times10^{-19} = 1.25 \times 10^{19}$ 个/s。

第 (c) 问值得停顿一下：**每秒一亿亿个电子**。这就是为什么电路分析从不数电子，只处理"整体流量"——就像水文站只报流量（m³/s），不数水分子。

上半部是水箱、阀门和粒子流：水位 = 电压，阀门间隙 = 电阻的倒数，粒子推进速度 = 电流。下半部是电荷累积曲线 $Q(t)$——注意那条琥珀色的**割线**，它的斜率就是电流：把电压调大一倍，水粒子变快，曲线变陡；把阀门关小，曲线变平。**电压决定斜率，电阻决定斜率的斜率。** 点一下播放，看 $Q$ 如何线性爬升：直线上升对应恒定电流。

### 实验 2（python）：把电子数算出来

```python title="从电流反推电子的数量级"
QE = 1.602e-19      # 元电荷（C）；1.602e-19 是科学计数法，等价于 1.602 × 10⁻¹⁹
I = 2.0             # 充电电流（A）
t = 1800.0          # 充电时间（s）

Q = I * t           # 电荷 = 电流 × 时间（C）
n = Q / QE          # 电子个数

print(f"电荷 Q = {Q:.0f} C")              # :.0f 表示保留 0 位小数
print(f"电子数 n = {n:.3e} 个")            # :.3e 表示科学计数法、保留 3 位小数
print(f"每秒电子数 = {I / QE:.3e} 个/s")
```

三行输出对应例题的三个问题。把 `I` 改成 `0.001`（1 mA，一枚低功耗传感器的典型工作电流）再看——每秒仍有 $6.2\times10^{15}$ 个电子穿过。

### 实验 3（python）：电池容量的两种写法

```python title="mAh 与库仑的换算"
mAh = 4000.0                  # 电池容量（毫安时）
Q = mAh * 3600 / 1000         # 先把 mA 换成 A（÷1000），再把 h 换成 s（×3600）
print(f"{mAh:.0f} mAh = {Q:.0f} C")

hours = 2.0                   # 想让它撑 2 小时
print(f"平均可输出 {Q / (hours * 3600) * 1000:.0f} mA")
```

4000 mAh = 14400 C，撑两小时意味着平均输出 2000 mA。注意这里"容量"只是**电荷量**，不是能量——要算能量还得乘电压：一块 3.7 V、4000 mAh 的手机电池储存 $14400 \times 3.7 \approx 53$ kJ，约合 14.8 Wh。

:::warning[常见误区]

**误区一**："电流是电子在导线里飞奔的速度。"
你以为 2 A 意味着电子跑得飞快——其实电子在铜里的**漂移速度**大约只有 0.1 mm/s，比蜗牛还慢。电流大是因为**参与漂移的电子极多**（每立方厘米铜里约有 $10^{22}$ 个自由电子），不是因为单个电子跑得快。真正以接近光速传播的是**电场**（信号），而不是电子本身。

**误区二**："电压是某一点的 property。"
你以为"这根线上电压是 5 V"——其实电压永远是**两点之间**的差，就像高度差一样。说"5 V"是省略了参考点（工程上叫"地"，GND），默认以它为 0 V。换一个参考点，所有读数整体平移，但任何两点的差不变。

**误区三**："mAh 越大，电池存的能量一定越多。"
你以为 4000 mAh 就一定比 3000 mAh 耐用——其实容量只给电荷，能量还要乘**电压**。两节 1.5 V 干电池串联成 3 V，mAh 不变但能量翻倍；而一块 3.7 V 的锂电与一块 1.2 V 的镍氢电池，即使 mAh 相同，能量也差三倍。

:::

## 6. 练习

**练习 1**：一块电池在 60 分钟内放出了 5400 C 的电荷，求放电电流（安培）。这段代码直接拿分钟数除了，修到输出 `1.5`：

```exercise
# @title: 练习：5400 C 在 60 分钟内放完，电流多大
# @check: 1.5
# @hint: 安培的定义是「库仑每秒」，不是「库仑每分钟」。分钟要先乘 60 换成秒
Q = 5400        # 放出的电荷（C）
minutes = 60    # 放电时长（分钟）
I = Q / minutes # ← 问题在这：分母的单位必须是秒
print(I)
```

**练习 2**：一枚 1.5 V 的 5 号电池，把 1 C 电荷从负极搬到正极需要做多少功？若某电路以 50 mA 电流工作，这 1 C 能用多久？

<details>
<summary>点开查看逐步解答</summary>

1. 由 $V = W/Q$ 得 $W = Q \cdot V = 1 \times 1.5 = 1.5$ J——这就是"1.5 V"的物理含义：**每搬运 1 库仑电荷交付 1.5 焦耳**；
2. 由 $I = Q/t$ 得 $t = Q/I = 1 / 0.05 = 20$ s；
3. 验证功率一致性：$P = W/t = 1.5/20 = 0.075$ W，而 $P = VI = 1.5 \times 0.05 = 0.075$ W——两条路殊途同归。

三个公式 $I = Q/t$、$V = W/Q$、$P = VI$ 其实是同一件事的三种写法：**功率 = 电压 × 电流**，它是下一篇欧姆定律课的引子。

</details>

## 7. 选读：为什么"1 安培"要定义得这么奇怪

<details>
<summary>选读 · 从元电荷到安培的定义变迁</summary>

2019 年以前，"1 安培"的定义是：两根无限长平行导线相距 1 米，通以相同电流，若每米长度上的作用力恰为 $2\times10^{-7}$ N，则该电流为 1 A。这个定义依赖"无限长导线"这种不存在的东西，实验上极难复现。

2019 年 5 月 20 日起，国际单位制改用**固定元电荷的数值**：$e$ 被精确定义为 $1.602176634\times10^{-19}$ C，安培反过来由"每秒流过的元电荷个数"推导。于是"1 A"等价于每秒流过约 $6.242\times10^{18}$ 个元电荷。

这个改动在工程上没有任何可感知的影响，但它把电流单位锚定在了一个**基本物理常数**上——任何实验室只要能数得清电子（现在真的能，用单电子晶体管），就能复现安培。测不准的电子个数，成了定义本身。

</details>
