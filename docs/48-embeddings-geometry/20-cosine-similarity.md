# 余弦相似度

## 1. 从一个场景开始

流媒体网站要比较两位用户的口味。小明的打分向量是（爱情片, 动作片）$=[2, 9]$，小红是 $[4, 18]$——形状一模一样，只是小红手松，什么分都翻倍。

直接比数值：两点距离 $\sqrt{(2-4)^2+(9-18)^2}=\sqrt{85}\approx 9.2$，系统会说"这两人口味天差地别"。可谁都看得出他们是同一种影迷：爱情片少看、动作片狂热。**问题出在"长度"上——打分尺度是噪声，口味轮廓才是信号。**

## 2. 直觉解释

把每个用户向量想成一支从原点射出的箭：

- **方向**记录口味的"配方比例"；
- **长度**只记录话多话少、手松手紧。

比较两个人像不像，应该比较**两支箭的夹角**，而不是箭头的终点位置。夹角小 → 志趣相投；夹角 90° → 各看各的；夹角 180° → 完全反着来。

第 11 章点积课已经埋好了钥匙：$\vec u \cdot \vec v = \lVert\vec u\rVert \lVert\vec v\rVert \cos\theta$。把它倒过来解出 $\cos\theta$，就得到了一个"自动忽略长度"的相似度。

## 3. 正式定义

**定义**：两个向量 $u, v$ 的**余弦相似度**为

$$\text{sim}(u, v) = \frac{u \cdot v}{\lVert u\rVert \, \lVert v\rVert} = \cos\theta$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $u \cdot v$ | 点积 | 对应分量相乘再求和，衡量"对齐程度" |
| $\lVert u\rVert$ | 模长 | 向量长度 $\sqrt{u_1^2+\cdots+u_d^2}$，归一化时除掉它 |
| $\cos\theta$ | 夹角余弦 | 取值恒在 $[-1, 1]$ |

读数手册：

| 数值 | 几何含义 | 语义解读 |
| --- | --- | --- |
| $1$ | 夹角 $0^\circ$ | 同一方向：完全同好 |
| $0$ | 夹角 $90^\circ$ | 正交：互不相关 |
| $-1$ | 夹角 $180^\circ$ | 正好相反 |

为什么必须除以模长？因为点积同时受方向和长度影响：把小红向量放大十倍，点积涨十倍，但她的口味没变。除掉 $\lVert u\rVert\lVert v\rVert$ 之后，剩下的量只由夹角决定——这正是我们想要的"尺度免疫"。实践中常先把每个向量缩放成单位长度（归一化），之后点积就是余弦。

## 4. 分步例题

**例 1**：$u=[3,4]$，$v=[4,3]$。

1. 点积：$3\times4 + 4\times3 = 24$；
2. 模长：$\lVert u\rVert = \sqrt{9+16}=5$，$\lVert v\rVert = 5$；
3. 相似度：$24/(5\times5)=24/25=0.96$；
4. 反查角度：$\arccos(0.96)\approx 16^\circ$——非常接近的同好。

**例 2**：尺度免疫验证。把 $u$ 放大一倍成 $u'=[6,8]$ 再和 $v$ 比：点积变 $48$，模长积变 $10\times5=50$，比值仍是 $0.96$。**分子分母同步膨胀，余弦纹丝不动**——小明和小红终于被认成了同一类人。

### 实验 2（python）：实现余弦，并验证它对长度免疫

```python title="余弦相似度函数"
def cosine(u, v):
    dot = u[0]*v[0] + u[1]*v[1]          # 点积：对应相乘再相加
    nu = (u[0]**2 + u[1]**2) ** 0.5      # u 的模长（勾股定理）
    nv = (v[0]**2 + v[1]**2) ** 0.5
    return dot / (nu * nv)

print(round(cosine([3, 4], [4, 3]), 2))     # 例 1 的结果
print(round(cosine([1, 0], [0, 1]), 2))     # 垂直的两支箭
print(round(cosine([2, 1], [-2, -1]), 2))   # 正好相反的方向
print(round(cosine([6, 8], [4, 3]), 2))     # 把 [3,4] 放大一倍再比：还是 0.96 吗？
```

四行输出分别是 $0.96, 0.0, -1.0, 0.96$。最后一行就是"尺度免疫"的数值证明：坐标变了，相似度没变。

### 快问快答

```quiz
两位用户的余弦相似度算出来是 -0.9，最合理的解释是？
- 系统算错了，相似度不可能是负数
- 两人口味几乎处处相反，比如一个只看文艺片另一个只看动作片 [*]
- 两人看的电影数量差别很大
? 负号来自钝角：方向大体相反。长度差异（看得多少）恰恰会被余弦自动抹平。
```

:::warning[常见误区]

**误区一**："你以为余弦相似度就是皮尔逊相关系数。" 皮尔逊相关要先各自减去均值（中心化），相当于"余弦应用于去平均后的向量"；不减均值直接算的余弦和它是两回事。评分尺度整体偏高的问题，皮尔逊处理得更彻底。

**误区二**："你以为相似度为 0 就代表统计独立。" 余弦为零只说明这两条坐标轴上的方向正交，不代表两个随机变量独立。正交是无几何重叠，不是无信息关联。

**误区三**："你以为只看方向永远是对的。" 长度有时就是信号：销量向量的模长是市场规模，丢掉它会犯"把巨头部和精品小店排在一起"的错误。先想清楚业务里什么是噪声、什么是信号，再选度量。

:::

## 6. 练习

**练习 1**：下面的 `cosine` 能跑，但结果冲出了 $[-1,1]$——修到通过为止：

```exercise
# @title: 练习：把相似度关回笼子
# @check: 0.96
# @check: 0.0
# @check: -1.0
# @hint: 点积只完成了一半工作；还要除以两条向量模长的乘积，才能消去长度的影响。
def cosine(u, v):
    dot = u[0]*v[0] + u[1]*v[1]
    nu = (u[0]**2 + u[1]**2) ** 0.5
    nv = (v[0]**2 + v[1]**2) ** 0.5
    return dot            # ← 问题在这：没有除以 nu * nv

print(round(cosine([3, 4], [4, 3]), 2))
print(round(cosine([1, 0], [0, 1]), 2))
print(round(cosine([2, 1], [-2, -1]), 2))
```

**练习 2**：三位用户的（喜剧，悬疑）打分为 甲 $[5,1]$、乙 $[10,2]$、丙 $[1,3]$。用余弦找出甲的"口味双胞胎"，再用欧氏距离找一次，两次结论一样吗？

<details>
<summary>点开查看逐步解答</summary>

```python
def cosine(u, v):
    dot = u[0]*v[0] + u[1]*v[1]
    nu = (u[0]**2 + u[1]**2) ** 0.5
    nv = (v[0]**2 + v[1]**2) ** 0.5
    return dot / (nu * nv)

def dist(u, v):
    s = 0
    for k in range(len(u)):
        s = s + (u[k] - v[k])**2
    return s ** 0.5

A, B, C = [5, 1], [10, 2], [1, 3]
print(round(cosine(A, B), 3), round(dist(A, B), 2))   # 1.0 但距离 5.1
print(round(cosine(A, C), 3), round(dist(A, C), 2))   # 0.496 且距离 4.47
```

余弦说：甲和乙是双胞胎（方向全同）；欧氏说：甲离丙更近。乙只是"手更松的甲"——按业务问题选择度量：关心**品味结构**用余弦，关心**绝对行为量**用欧氏距离。
</details>

## 7. 选读：各向异性——当所有箭头挤成一束

<details>
<summary>选读 · 为什么真实词向量的余弦普遍偏高</summary>

理论余弦取值铺满 $[-1,1]$，但对许多训练出的词嵌入实测发现：随便抽两个词，余弦往往落在 $0.5$ 以上——所有箭头歪歪扭扭挤在一个窄锥子里。这种现象叫**各向异性**（anisotropy）：空间被模型用歪了，高频语法信息霸占了主方向，语义差异被压缩进残余的小夹角里。

后果是绝对读数失去意义："0.7 很像吗？"在这个模型里可能等于平均水平。工程对策包括中心化后再归一化、白化变换，或干脆改用"相对排名"而不是绝对阈值。教训与本章主线一致：**嵌入空间的几何性质是学出来的，不是天然保证的**——用之前先体检。

</details>
