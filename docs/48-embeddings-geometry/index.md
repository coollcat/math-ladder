## 实战挑战 · 词向量的国王算术

2013 年，Mikolov、Yih 与 Zweig 在 NAACL HLT 论文中报告了一个轰动结果：对训练好的词向量做**向量算术**，"king − man + woman" 得到的向量，最近的邻居竟是 "queen"。性别、王室地位这些抽象关系，竟然以稳定的"方向"形式活在坐标里（原论文用的是几百维真实词向量加余弦最近邻；下面是同款思想的教学版）。

情境设定：我们手工造一个 2 维语义宇宙——第一维是**性别**（男 +1 / 女 −1），第二维是**王室身份**（王室 +1 / 平民 −1）。四个词的坐标如下：

| 词 | 性别 | 王室 |
| --- | --- | --- |
| king | +1 | +1 |
| man | +1 | −1 |
| woman | −1 | −1 |
| queen | −1 | +1 |

请完成类比推理 king − man + woman = ?：

**(a)** 逐分量计算目标向量 target = king − man + woman；
**(b)** 分别算 target 到四个词向量的平方距离（逐维相减、平方、求和），打印四个数；
**(c)** 距离最小的那个词就是答案。第一行已示范：

```exercise
# @title: 实战挑战：king - man + woman = ?
# @check: 4
# @check: 8
# @check: 4
# @check: 0
# @hint: 类比运算是"减去 man 再加上 woman"——检查两行 target 计算里的加减号；平方距离不用开方就能比大小。
words = {"king": [1, 1], "man": [1, -1], "woman": [-1, -1], "queen": [-1, 1]}

tx = words["king"][0] - words["man"][0] - words["woman"][0]   # ← 问题在这：woman 前应是加号
ty = words["king"][1] - words["man"][1] - words["woman"][1]

for name in ["king", "man", "woman", "queen"]:
    w = words[name]
    d = (w[0] - tx)**2 + (w[1] - ty)**2    # 平方距离：逐维作差、平方、求和
    print(d)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** target 的两个分量：

$$\text{target} = [+1 - (+1) + (-1), \; +1 - (-1) + (-1)] = [-1, \; +1]$$

性别维度从男 (+1) 减去男再加女，落在 −1；王室维度全程保持 +1。"性别换掉、身份保留"——这正是类比的语义结构。

**(b)** 四个平方距离：

```python
words = {"king": [1, 1], "man": [1, -1], "woman": [-1, -1], "queen": [-1, 1]}
tx = words["king"][0] - words["man"][0] + words["woman"][0]
ty = words["king"][1] - words["man"][1] + words["woman"][1]

for name in ["king", "man", "woman", "queen"]:
    w = words[name]
    print((w[0] - tx)**2 + (w[1] - ty)**2)
# 输出: 4, 8, 4, 0
```

到 king 与到 woman 都是 4（各差两个维度之一），到 man 是 8。

**(c)** 唯一的 0 属于 **queen**——精确命中。真实词向量里没有这么干净的命中（所以论文用"余弦最近邻"而不是相等），但方向性结论完全一致：关系 ≈ 平移向量。

顺手验证另一条经典类比 Paris − France + Italy ≈ Rome（首都关系），你会发现同一套流程原封不动地工作。
</details>

## 实战挑战 · 急诊脑电片段检索

> 场景说明：θ 带（4~8 Hz）与 α 带（8~13 Hz）的划分是神经工程中的通用约定；本题的二维嵌入和四条模板均为教学构造。真实系统还要处理采样、伪迹、患者基线与在线校准。

急诊监护仪刚收到一段 10 秒脑电。为了把它和既往状态快速比对，前端模型先把每个片段压成一张“坐标卡”：第一维是 **α 带能量**，第二维是 **θ 带能量**。库里有四张已标注模板：

| 模板 | 含义 | 向量 |
| --- | --- | --- |
| A | 清醒闭眼 | $[8, 2]$ |
| B | 困倦过渡 | $[4, 5]$ |
| C | 浅睡慢波 | $[2, 6]$ |
| D | 眨眼伪迹 | $[1, 9]$ |

新片段被嵌成 $q=[7, 3]$。请用平方距离找出最像的历史模板，并判断它更像清醒 α 节律还是伪迹。下面的代码能跑，但距离公式把“作差”写成了“相加”：

```exercise
# @title: 实战挑战：给脑电片段找历史邻居
# @check: 2
# @check: 13
# @check: 34
# @check: 72
# @hint: 嵌入检索先比较“差多少”：每一维用模板减查询（或查询减模板），平方后再求和。
templates = {
    "A 清醒闭眼": [8, 2],
    "B 困倦过渡": [4, 5],
    "C 浅睡慢波": [2, 6],
    "D 眨眼伪迹": [1, 9],
}
query = [7, 3]

for name in templates:
    p = templates[name]
    d2 = (p[0] + query[0])**2 + (p[1] + query[1])**2   # ← 问题在这：这里不该相加
    print(d2)
```

<details>
<summary>点开查看逐步解答</summary>

平方距离不用开方就能比大小：

```python
templates = {
    "A 清醒闭眼": [8, 2],
    "B 困倦过渡": [4, 5],
    "C 浅睡慢波": [2, 6],
    "D 眨眼伪迹": [1, 9],
}
query = [7, 3]

for name in templates:
    p = templates[name]
    d2 = (p[0] - query[0])**2 + (p[1] - query[1])**2
    print(d2)
```

四个输出依次是 `2, 13, 34, 72`，最近邻是 **A 清醒闭眼**：它与新片段只在两条轴上各差 1。这个结果和临床直觉一致——片段的 α 能量明显高于 θ 能量，属于 α 占优图形，而不是以 θ/慢波为主的困倦或浅睡模式。

真实脑电嵌入不会只靠两个手工频带特征，还会在多通道、多频带和形态学特征上学出更高维表示；但“把片段变成向量，再找最近历史样本”的检索骨架是一样的。
</details>
