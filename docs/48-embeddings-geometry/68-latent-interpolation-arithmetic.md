# 潜在空间插值与向量算术

## 1. 从一个场景开始

动画师给两张关键帧之间补画面，行话叫"补间"（tweening）：第一秒角色张嘴大笑，第三秒恢复扑克脸，中间那一秒的样子软件自动脑补。用的人越来越多后，大家发现同一招也能用在 AI 生成的头像上——把"微笑版本"和"严肃版本"的两个编码拿来连线滑动，人物会连续地从笑转严肃，中途每一帧都还是"这个人"。

这就有点神奇了：两个编码本来就是两串数字，凭什么数字之间的**中间值**恰好对应一个仍然合理的对象？"沿直线走过去"这件事，暗地里对这张地图的结构做了一个大胆假设。这一课把假设摆上台面，看看它什么时候成立、什么时候让你当众出丑。

## 2. 直觉解释

把潜在空间想成一座城市的地铁图：车站是你训练时见过的样本，线路是数据天然聚集的轨道。

- **插值**就是买一张从 $a$ 站到 $b$ 站的车票，在两个站名之间匀速慢走；
- 如果两个站之间本来就有轨道（同类样本铺成的地带），沿途风景连贯——笑到一半的表情依然自然；
- 如果两个站在两条不相干的线路上（猫的照片与卡车的照片），直线就会把你甩进**无人区**：那里没有站台、没有住户，走出来的是四不像。

而上一课结尾的向量算术在这里给出第二把钥匙：king 到 queen 这类稳定位移对应**城市里反复出现的一条走廊**——语义方向。走廊之所以存在，是因为数据里这种变化模式被反复要求过；走廊之外的方向则没有承诺。

## 3. 正式定义

**定义**：设 $z_a, z_b$ 是两个嵌入向量，参数 $t \in [0, 1]$ 的**线性插值**

$$z(t) = (1 - t)\, z_a + t\, z_b$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $(1-t), t$ | 凸组合权重 | 全程非负且相加为一，$z(t)$ 始终落在两点的混合范围里 |
| $v = z_b - z_a$ | 差向量 | 从 $a$ 指向 $b$ 的方向；插值就是匀速沿 $v$ 平移 |
| $\lVert z(t) - z(s)\rVert$ | 弧上距离 | $t, s$ 相差多少，就走多远——速度恒定 |

两个必须诚实交代的陷阱：

1. **高维直线的狡猾**：上一章说过高维空间"体积逃向表面"。数据团多半是一层薄壳或薄膜，任意两点的欧氏连线是**抄近路的弦**，正中央恰恰可能穿过薄壳之外的空旷地带——二维看很自然的连线，千维下最常干的事就是闯红灯；
2. **方向的局部性**：语义方向只在数据支撑得住的区段上有效。出了熟悉的邻域，模型没有人管束，输出只会按记忆瞎编。

处理这两个陷阱的工具箱叫球面插值与测地路线，本课不深挖推导，只立牌子提醒：**直线是零信息路径，沿途没有质量保证。**

## 4. 分步例题

颜色是最安全的练习场：RGB 编码 $(r, g, b)$ 本身就是一个三维潜在空间，而且人人有视觉验收仪。把深海蓝 $[28, 66, 208]$ 渐变到铁锈红 $[217, 58, 42]$：

1. 取中点 $t = 0.5$：每个通道各让一半——$r: \frac{28+217}{2} = 122.5$，$g: 62$，$b: 125$；
2. 结果 $[122.5, 62, 125]$：红蓝势均力敌，绿作为第三者垫场——屏幕上这是一个中性紫灰色，符合直觉；
3. 取 $t = 0.25$（偏向蓝色）：$[169.75, 60, 83.5]$——蓝色占大头的过渡色；
4. 把 $t$ 从 $0$ 扫到 $1$ 就得到整条渐变带。颜色空间的坐标几乎处处有人居住（颜料可以任意调配），所以直线的每一步都落在"合法颜色"上——这正是它适合入门的原因，也是后面实验的主角。

## 5. 动手实验

### 实验 1（python）：亲手渲染一条插值渐变带

```python title="两端点定生死：RGB 插值渐变带"
import matplotlib.pyplot as plt

ca = [28, 66, 208]     # 起点：深海蓝
cb = [217, 58, 42]     # 终点：铁锈红
steps = 64             # 渐变带的采样数

band = []
for k in range(steps):
    t = k / (steps - 1)
    row = []
    for c in range(3):
        # 凸组合：起点份额随 t 缩小，终点份额随之涨起
        row.append(round((1 - t) * ca[c] + t * cb[c]))
    band.append(row)

# imshow 展示嵌套列表：外层是行，内层是像素——一列一种颜色
plt.imshow([band] , aspect="auto")   # aspect="auto"：允许压扁成色带
plt.axis("off")                      # 关闭坐标刻度，只留色带本体
```

试试把 `cb` 换成 `[240, 230, 140]`（浅米黄）：蓝到黄的直线中段会出现一段发灰发闷的颜色——两种颜料的"弦"路过了它们饱和度地图上的低洼地。颜色尚且如此，语义空间只会更严峻。

### 实验 2（python）：弦为什么爱穿空地——双弧线上的教训

```python title="两片薄弧之间，直线抄了近路"
import matplotlib.pyplot as plt

# 手工采样的两片弧线：同一批对象沿弯曲的薄壳分布（坐标已事先挑好）
ptsA = [[-2.0, 0.2], [-1.6, 0.85], [-1.0, 1.35], [-0.3, 1.62], [0.5, 1.58],
        [1.2, 1.25], [1.65, 0.7], [1.95, 0.15], [2.0, -0.35]]
ptsB = [[-2.0, 0.0], [-1.5, -0.5], [-0.9, -0.95], [-0.2, -1.3], [0.5, -1.5],
        [1.2, -1.55], [1.7, -1.35], [2.0, -1.0]]

for pts, col in [(ptsA, "tab:blue"), (ptsB, "tab:green")]:   # 一行拆两个变量：点集、颜色
    xs = [q[0] for q in pts]       # 列表推导：对 pts 里每个点取出横坐标
    ys = [q[1] for q in pts]
    plt.scatter(xs, ys, s=26, color=col)

za = ptsA[-1]                      # 上弧末端的样本（[-1] 表示倒数第一个）
zb = ptsB[0]                       # 下弧起点的样本
plt.plot([za[0], zb[0]], [za[1], zb[1]], color="tomato", linestyle="--")  # 插值路线
mid = [(za[0] + zb[0]) / 2, (za[1] + zb[1]) / 2]   # 插值的中点样本
plt.scatter([mid[0]], [mid[1]], s=130, marker="?", color="orange")  # 它离谁都不近

rounded = []
for v in mid:                      # 把每个分量四舍五入到两位小数再打印
    rounded.append(round(v, 2))
print("中点样本 =", rounded)
```

橙色的"中点样本"悬在两片薄壳夹出的空巷正中：最近的样本邻居也在一个身位之外，放在真实模型里它对应的那张"中间照片"只会四不像。别忘了这里维度才二维、弦才多长——上一章的高维数学说的是：**维度越高，体积越向薄壳之外逃逸，弦的腰腹就越空旷。**

### 快问快答

```quiz
在学好的潜在空间里，把两张人脸的编码取中点，得到的新面孔应该怎么理解？
- 它一定是数据集里某一张真实照片的复制
- 它是两端特征的平均化虚构样本，落在支撑数据的路径上才可信 [*]
- 中点等于均值，所以它在数学上没有定义
? 插值是凸组合，永远有定义；但"看起来像真人"取决于这条线段是否躺在数据分布的高密度带上——这是几何承诺，不是代数义务。
```

:::warning[常见误区]

**误区一**："你以为插值结果都该逼真。" 连续性由训练分布决定：同类样本间的直线大概率有支撑，跨大类（猫与卡车）的直线十有八九出鬼。先看两点在不在同一片社区，再谈补间。

**误区二**："你以为语义方向是无限长的滑轨。" king−queen 那样的方向是在有限区段内统计出来的平均效应，向外多推几步，性别轴就不再代表任何东西。方向的适用半径要用数据密度测量，不能凭一条好结果无限 extrapolate。

**误区三**："你以为向量算术取最近邻失败就证明方法破产。" 单次算术是噪声敏感的操作：常见做法是对一组类似关系取差向量的平均值再查询（原型法），或者干脆要求前几名邻居里有目标词才算命中。评价这类技巧要看统计总体，别跟单次抛硬币较劲。

:::

## 6. 练习

**练习 1**：下面的插值函数能跑，但调出来的颜色整个歪掉——把它修回凸组合：

```exercise
# @title: 练习：让中点落在线段中央
# @check: 169.75
# @check: 60.0
# @check: 83.5
# @hint: 凸组合里起点的权重是 1 - t，不是 0：先把两向量相加再乘 t，等于把起点也一起打折了。
ca = [217, 58, 42]     # 铁锈红
cb = [28, 66, 208]     # 深海蓝
t = 0.25               # 偏向起点一点的取值

mixed = []
for c in range(3):
    mixed.append((ca[c] + cb[c]) * t)   # ← 问题在这：这不是凸组合

print(round(mixed[0], 2))
print(round(mixed[1], 2))
print(round(mixed[2], 2))
```

**练习 2**：计算机图形学有一条知名的补救措施叫 slerp（球面插值）：不在平面直线行走，而是沿以原点为球心的圆弧走。结合归一化词向量总住在单位球面上的事实，说说它治的是什么病？

<details>
<summary>点开查看逐步解答</summary>

病根有两个。其一，长度漂移：线性插值 $z(t)$ 的模长随 $t$ 先缩后胀，中点附近反而比两个端点都短——对"余弦即相似度"的管线来说，长度失真是无谓噪声；slerp 让全程保持单位长度。其二，穿越低密度区：单位球面上两点间的直线切进去心深处（那里的点密度为零），而球面大圆弧始终贴着"人人居住"的外壳走。代价是需要知道夹角并处理反三角函数，且仍不保证贴合流形的真实曲率——它只是把"至少待在球面上"这一层最便宜的约束兑现了。真正的深度问题要交给下一课的流形假设。
</details>

## 7. 选读：语义方向的三种出身

<details>
<summary>选读 · 方向从哪里来，又凭什么不塌</summary>

潜在空间里的可用方向大致有三个来源：

1. **无监督自发涌现**：word2vec 的关系方向、GAN 的相位（旋转、厚度）方向——只要训练任务持续惩罚"该相邻却相邻远"，几何就被迫长出整齐的通道。第 20 课提过的各向异性是它的反面教材：当全部方向挤进一个窄锥，插值与算术同时失去分辨率。
2. **监督显式注入**：给人脸编码器喂"同一人"配对（对比学习，上一课），把身份做成主方向；StyleGAN 类模型则直接给风格层开独立输入口，"微笑度""年龄"成了旋钮而不是巧合。
3. **事后解读**：先训完再做"方向考古"——沿某个方向挪动观察输出变化，给方向贴标签。它揭示的是模型已有什么，不代表这个方向有多可靠。

工程建议照旧三点一线：查长度（是否归一化）、查锥角（各向异性体检）、查密度（方向沿线是否有样本支撑）。三项俱全再动手算术，成功率立刻不同。
</details>
