# 高维空间反直觉

## 1. 从一个场景开始

词嵌入动辄几百上千维。可我们关于"距离"和"靠近"的全部直觉，都来自二维地图与三维房间——一间屋子再大，总有远有近。

于是尴尬的问题来了：在一千维的空间里，随便抽两个点，它们离得"近"吗？直觉说"维度多，随机两点应该更容易离得远"。实验会告诉你一个更奇怪的事实：**在很高的维度里，几乎所有点对的距离都差不多——"最近的朋友"和"最远的陌生人"只差几个百分点**。这一课把三件反直觉的事一次看清。

## 2. 直觉解释

先玩一个思想实验：单位正方形里随机撒两个点，距离从 0（重合）到约 1.41 都可能出现，波动很大。换成十维立方体呢？一千维呢？每一维都贡献一段独立的随机偏移，**平方距离是一大把独立随机数之和**——第 36 章中心极限定理的舞台：大量独立贡献相加后，总量的**相对波动反而萎缩**，大约按 $\frac{1}{\sqrt{d}}$ 的速度衰减。

三个标志性现象由此涌现：

1. **距离集中**：随机点对之间的距离几乎都挤在同一个值附近；
2. **角度正交化**：两个随机向量的夹角压向 $90^\circ$——高维宇宙里"人人互相垂直"；
3. **体积逃向表面**：球的体积按半径的 $d$ 次方缩放，半径 $0.99$ 与 $1.0$ 的球在千维下体积差一个数量级，质量全贴在薄薄的壳上。

它们不是悖论，而是被严格证明、被工程反复验证的几何事实——统称**集中现象**；它给检索与统计带来的麻烦，被称为**维数灾难**。

## 3. 正式定义

设 $p, q$ 是 $d$ 维单位立方体中独立均匀分布的两个随机点。平方距离为

$$S = \sum_{k=1}^{d} \Delta_k^2$$

其中每个 $\Delta_k = p_k - q_k$ 是同一坐标轴上两份均匀随机数之差。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\Delta_k$ | 单轴偏移 | 第 $k$ 轴上的差距，各轴相互独立 |
| $S$ | 平方距离 | $d$ 个独立同分布项之和 |
| $\text{CV}$ | 相对波动（变异系数） | 标准差 ÷ 均值，衡量"参差不齐程度" |

中心极限定理给出定量结论：距离的相对波动 $\text{CV} \approx \dfrac{c}{\sqrt{d}}$（常数 $c$ 只由单轴分布形状决定）。同理可算：两个随机方向的夹角余弦集中在 $0$ 附近，波动同样是 $\frac{1}{\sqrt{d}}$ 量级。**维度是集中现象的燃料。**

## 4. 分步例题

**例**：估算 $d=10000$ 维时随机点对距离的整齐程度。

1. 相对波动的量级是 $c/\sqrt{d}$，取典型常数 $c\approx 0.6$；
2. 代入：$\frac{0.6}{\sqrt{10000}} = \frac{0.6}{100} = 0.006$；
3. 解读：若平均距离是 4.04，则绝大多数点对落在 $4.04 \pm 0.03$ 这条窄缝里；
4. 推论：最近邻与最远邻只差百分之几——"最近"这个概念失去了对比度，而上一课的分格检索也随之失灵（哪个桶里的点看起来都差不多远）。

同样三个数字在低维完全不是这副面孔：$d=4$ 时相对波动约 $0.3$，远近分明。

### 实验 2（python）：亲手制造集中现象

```python title="维度越高，距离越整齐"
import random
import matplotlib.pyplot as plt

def pair_distances(d, pairs):
    out = []                       # 存放 pairs 对点之间的距离
    for t in range(pairs):
        p = []
        q = []
        for k in range(d):
            p.append(random.random())   # 每一维都是 0 到 1 的均匀随机数
            q.append(random.random())
        acc = 0
        for k in range(d):
            acc = acc + (p[k] - q[k]) ** 2
        out.append(acc ** 0.5)
    return out

for d in [2, 10, 100, 1000]:
    ds = pair_distances(d, 400)
    total = 0
    for x in ds:
        total = total + x
    mean = total / len(ds)
    dev = 0
    for x in ds:
        dev = dev + (x - mean) ** 2
    std = (dev / len(ds)) ** 0.5
    print(f"d = {d}: 平均 {round(mean, 2)}, 相对波动 {round(std / mean, 3)}")

ds = pair_distances(1000, 2000)
plt.hist(ds, bins=40)          # hist：直方图，bins 指定柱数
```

输出形如：二维时相对波动约 0.42，十维 0.19，百维 0.06，千维 0.02——与 $0.6/\sqrt{d}$ 的预测吻合。直方图则从"宽坡"收窄成"针峰"。

### 快问快答

```quiz
在一万维空间里随机取两个向量，它们的夹角最可能接近多少度？
- 0 度，高维空间太拥挤
- 90 度，随机方向几乎必然近似正交 [*]
- 180 度，处处相反
? 随机向量的夹角余弦集中在 0 附近，波动约为 1/sqrt(d)。一万维下偏差只有百分之一量级——所以"人人互相垂直"。
```

:::warning[常见误区]

**误区一**："你以为距离集中是程序算错了。" 这是数学定理保证的现象，换语言、换机器、换库都会复现。该修的是直觉，不是代码。

**误区二**："你以为集中让嵌入检索彻底没用。" 失去对比度的是**随机点**；真实数据的嵌入集中在低维流形附近，同一语义簇内的相对排序依然清晰。检索靠的是"相对更近"，不是绝对距离值。

**误区三**："你以为二维画格子失败就能否定一切索引。" 分区方法在高维确实退化，但工程界还有树结构、量化压缩、图索引（如 NSW/HNSW 一类基于邻居图的导航）等武器——它们的设计目标恰恰是绕开集中现象设下的陷阱。

:::

## 6. 练习

**练习 1**：下面是从某个超高维空间采到的 8 对随机点的距离样本。算出平均距离和相对波动（标准差除以均值），亲眼看看它有多小。代码能跑但标准差恒为零——找找原因：

```exercise
# @title: 练习：给集中现象量体温
# @check: 4.04
# @check: 0.013
# @hint: 方差是"偏差平方之和除以样本数"再开方——现在的代码少除了样本数，把总平方和当成了方差。
distances = [4.02, 4.11, 3.98, 4.05, 4.08, 3.95, 4.01, 4.09]

total = 0
for d in distances:
    total = total + d
mean = total / len(distances)

dev_total = 0
for d in distances:
    dev_total = dev_total + (d - mean) ** 2
std = dev_total ** 0.5          # ← 问题在这：忘了先除以 len(distances)

print(round(mean, 2))
print(round(std / mean, 3))
```

**练习 2**：用相对波动公式 $c/\sqrt{d}$（取 $c=0.6$）估计：要让"最近邻与平均距离至少差 10%"，维度最多能到多少？

<details>
<summary>点开查看逐步解答</summary>

要让"最近"仍能比平均距离突出至少一成，相对波动就不能缩到 0.1 以下：要求 $\frac{0.6}{\sqrt{d}} \ge 0.1$，即 $\sqrt{d} \le 6$，解得 $d \le 36$。也就是说三四十维以上，随机点对的距离差异就开始淹没在波动里。真实系统当然工作在几百上千维——因为数据不是均匀随机的（流形假设救场），也因为检索算法专门针对集中现象做了设计。这道小题解释了为什么"降维"（PCA，第 21 章）常常是检索流水线的第一步。
</details>

## 7. 选读：集中的另一面——它是敌人也是朋友

<details>
<summary>选读 · 约翰逊-林登施特劳斯与随机初始化</summary>

集中现象并非只会添乱：

- **随机投影**：约翰逊-林登施特劳斯引理说，$n$ 个点可以被随机投影到仅 $O(\log n)$ 维的空间里，而所有两两距离的畸变都被控制在 $(1\pm\varepsilon)$ 内。它能成立，恰恰依赖高维随机方向的近似正交性——集中现象反过来成了压缩证书。
- **模型初始化**：训练神经网络的词嵌入表时，初始向量常取独立高斯随机数。由于角度集中，这些初始向量天然近似互相垂直，几乎不浪费表达空间——"白送的多样性"。
- **假设检验**：第 38 章的高维检验依赖统计量的集中性来界定误差棒。

同一个几何事实，在检索里是灾难，在压缩里是护身符。看清机制而不背结论，才能判断它在你的问题里站在哪一边。

</details>
