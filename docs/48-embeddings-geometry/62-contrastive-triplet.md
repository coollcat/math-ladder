# 对比学习与 triplet 损失

## 1. 从一个场景开始

相册 App 说要帮你把两万张照片按人物自动分堆。它没有人物名单，也没有任何标签——没人告诉模型"这人是妈妈"。可它偏偏分对了。

秘密在于一种更廉价的监督信号：**对样本的判断不需要认识谁，只需要知道"哪些是同一人、哪些不是"**。"同一人"这种弱信息可以靠时间戳、相机序列甚至点击行为免费获得。对比学习的全部野心就是：把这种廉价的同／异判断，炼成上一课词嵌入那样的通用坐标。

## 2. 直觉解释

把嵌入空间想象成一张拔河地图，每个样本是一个木桩。每一回合训练搬来三根桩：

- **锚点** $a$（anchor）：本次学习的参照者；
- **正例** $p$（positive）：和锚点同一阵营的伙伴；
- **负例** $n$（negative）：站在对面阵营的人。

然后两根绳子开工：一根橡皮筋把 $p$ 往 $a$ 身边**拉**；一根长杆把 $n$ 向外**推**。什么才算赢？规则写得像体育比赛——**负例必须比正例至少远出一个间隔 $m$**。达成后，损失记零，本回合收工；没达成，差多少就吃多少罚分。

这套语言叫**排序目标**：模型从不追求"把世界记住"，只追求"把队排对"——队形对了，检索、聚类、识别全是顺手的副产品。

## 3. 正式定义

**定义**：三元组 $(a, p, n)$ 与间隔 $m > 0$ 的 **triplet 损失**

$$L = \max\bigl(0,\; d(a, p) - d(a, n) + m\bigr)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $d(\cdot,\cdot)$ | 距离函数 | 常取欧氏距离或平方欧氏距离，全程不许换 |
| $m$ | 间隔 margin | 安全距离；也是"及格线"的松紧旋钮 |
| $\max(0,\cdot)$ | 铰链 | 无违规不发力——已排序的三元组贡献零梯度 |

三条分支读法：$L = 0$ ⇔ 三元组已经合格，拔河绳松开；$L > 0$ ⇔ 排序被破坏的程度就是罚分。梯度走两条路：正例沿"靠近锚点"、负例沿"远离锚点"的方向移动，锚点同步微调——这正是后面实验里那两张轨迹图的来历。

但经验法则很快会遇到一个尴尬：**随机抽的三元组十有八九天生合格**（随手抽个远处的负例当然够远），铰链闭合、梯度为零，训练在原地打转。所以成败的关键根本不在公式，而在**抽样策略**：太容易的负例是无效陪练，专挑最难的又容易被标注噪声带偏——中等偏难（semi-hard）的那一档最养人。

## 4. 分步例题

令 $m = 2$，某一步拿到三元组 $a=[0,0]$、$p=[3,4]$、$n=[5,0]$。

1. 算正例距离：$d(a,p) = \sqrt{3^2+4^2} = 5$；
2. 算负例距离：$d(a,n) = \sqrt{5^2+0^2} = 5$；
3. 代入：$L = \max(0,\; 5 - 5 + 2) = 2$——负例并没有比正例更远，秩序失效；
4. 解读这份罚单：模型会同时干两件事——把 $p$ 往锚点拽（$d(a,p)$ 减小）、把 $n$ 往外推（$d(a,n)$ 增大），只要两者合计改写量超过 $2$，罚单清零。注意 $m$ 是**差值门槛**：它衡量的是相对远近，跟绝对尺度无关，所以对"所有点挤成一团"的病态解免疫。

## 5. 动手实验

### 实验（python）：看橡皮筋与长杆各干了什么

把正例放在远处、故意让负例贴着锚点起跑——最糟糕的开局。然后只按上面那份"罚单"移动它们：

```python title="triplet 训练：拉动与推开的两条轨迹"
import matplotlib.pyplot as plt

a = [0.0, 0.0]                    # 锚点 anchor
p = [4.0, 4.5]                    # 正例：同类，却开局很远
n = [1.1, 0.8]                    # 负例：异类，竟贴身起跑
m = 1.0                           # 间隔 margin

def sq(u, v):
    return (u[0]-v[0])**2 + (u[1]-v[1])**2   # 平方距离：比大小不必开方

def loss(u_p, u_n):
    return max(0.0, sq(a, u_p) - sq(a, u_n) + m)

eta = 0.3                         # 每轮位移幅度（教学版学习率）
trail_p, trail_n = [], []         # 两条轨迹各自存点
for t in range(60):
    cur = loss(p, n)
    trail_p.append([p[0], p[1]])
    trail_n.append([n[0], n[1]])
    if cur == 0.0:
        break                     # 及格就收手：铰链关闭，不再产生拉力
    lp = (p[0]**2 + p[1]**2) ** 0.5      # p 到原点的长度
    ln = (n[0]**2 + n[1]**2) ** 0.5
    p = [p[0] - eta*p[0]/lp, p[1] - eta*p[1]/lp]   # 沿朝向锚点的方向拉近
    n = [n[0] + eta*n[0]/ln, n[1] + eta*n[1]/ln]   # 沿远离锚点的方向推出去

for tr, color, tag in [(trail_p, "tab:blue", "p"), (trail_n, "tab:red", "n")]:   # 一行拆三个变量：轨迹、颜色、标签
    xs = [pt[0] for pt in tr]          # 列表推导：对 tr 里每个点取出横坐标
    ys = [pt[1] for pt in tr]
    plt.plot(xs, ys, color=color)          # plot 连线画出迁移轨迹
    plt.scatter(xs, ys, s=18, color=color, marker="o")   # marker="o"：圆点记号标记途经站
    plt.annotate(tag, (xs[-1], ys[-1]))    # annotate：在终点旁标注字母

plt.scatter([a[0]], [a[1]], s=140, marker="*", label="anchor")
plt.legend()
plt.axis("equal")                 # axis equal：横纵比例一致，圆才是圆
```

蓝线是被橡皮筋拽回来的正例，红线是被长杆顶出去的负例，星号原地不动。真实训练里锚点也会被梯度轻推，这里特意把它按住不放——好让你看清另外两根桩各自的命运与步态。

### 快问快答

```quiz
训练进行到一半，随机再抽一批三元组时几乎全都落在损失为零的区域，最有效的下一步是什么？
- 把学习率放大一百倍，强行加大挪动幅度
- 改进抽样：主动挑选锚点附近一两步之内就有负例的"半困难"三元组 [*]
- 把间隔 m 调成零，让更多三元组及格
? 合格三元组梯度为零，属于无效陪练。困难负例挖掘让每个批次都聚焦在"还没拉开"的边界地带，这才是训练真正发生的地方。
```

:::warning[常见误区]

**误区一**："你以为 triplet 损失会鼓励所有点互相远离。" 它只维护**相对排序**：$n$ 只要比 $p$ 远过 $m$ 即可，至于全体是否聚成一坨、绝对距离多大，损失函数毫不过问。想要"全局铺开"还得加别的约束（比如中心损失或归一化）。

**误区二**："你以为最难的正负例越难越好。" 最难的一档往往来自标错的样本：那张被误认的合影会把橡皮筋朝错误方向死拽。工程实践偏爱 semi-hard——足够有挑战又不至于毒化数据。

**误区三**："你以为正例天然存在。" 挑哪个样本当 $p$ 本身就是建模决定：同一张脸的两个crop、同一篇文档的两段引用、随机裁剪的同一张图。没有可靠的正例构造，就没有可靠的对比学习——这是无标签能学表示的全部前提。

:::

## 6. 练习

**练习 1**：下面这段代码想复现第 4 步例题的罚单计算。它能跑，但罚单永远发不出来——修到通过为止：

```exercise
# @title: 练习：铰链该在什么时候打开
# @check: 5.0
# @check: 5.0
# @check: 2.0
# @hint: 罚分衡量"负例不够远"的程度：正例距离减负例距离之后，还应当给间隔留位置——那个 m 是要加上去的。
a = [0.0, 0.0]
p = [3.0, 4.0]
n = [5.0, 0.0]
m = 2.0

def dist(u, v):
    return ((u[0]-v[0])**2 + (u[1]-v[1])**2) ** 0.5

d_ap = dist(a, p)
d_an = dist(a, n)
loss = max(0, d_ap - d_an - m)    # ← 问题在这：间隔写成了减号
print(d_ap)
print(d_an)
print(loss)
```

**练习 2**：如果把实验中的推动方向改成"把负例推向某个固定角落"，而锚点永远在原点附近，会发生什么好事与坏事？

<details>
<summary>点开查看逐步解答</summary>

好事：实现极简，一轮训练必有位移，不会出现"全员及格原地待机"；坏事：角落在哪与语义无关——所有异类被机械赶去同一个下水道，两类以上物体的分布会互相叠挤，第二轮里新来的正负例关系立刻乱套。对比学习的优雅之处恰恰在于**排斥力由锚点的当前几何决定**（远离 $a$ 的方向），而不是人为指定的容器。多维空间里同理：被推开的负例分散在各个"远离锚点"的方向上，自然形成辐射状的结构。
</details>

## 7. 选读：从三元组到 InfoNCE

<details>
<summary>选读 · 一个批次的"全运会"赛制</summary>

逐三元组训练效率有限：每个锚点每回合只见一位对手。现代对比学习（SimCLR、MoCo 等一脉）换了赛制——**InfoNCE**：给定锚点，在一个批次的 $N-1$ 个候选里认出唯一正例。目标写成多分类交叉熵：

$$-\log \frac{\exp(d_a^+/\tau)}{\sum_i \exp(d_i/\tau)}$$

其中 $\tau$ 是温度系数：调低它等于自动放大难点配对的权重，相当于内置了困难挖掘。批次里其余 $N-2$ 个样本全体充当负例——一次前向传播办一场淘汰赛，GPU 不再空转。

三个实用注脚：其一，维度塌缩防御（相似向量全缩成一个点也能骗过低标准的损失）在三元组版本里靠间隔硬顶住；其二，大 batch 是隐形成本，MoCo 类方法用队列存旧样本缓解；其三，语言侧的 SimCSE 表明"同一句话两次 dropout 互为正例"都能凑效——再次印证正例构造即世界观。
</details>
