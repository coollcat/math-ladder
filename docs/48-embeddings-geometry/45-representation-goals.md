# 表示学习的目标与约束

## 1. 从一个场景开始

家具厂要把一车样品送去展销会：货车车厢的容积是固定的，而厂里的样品有几千件。你必须在装车前回答一个残酷的问题——**带走什么、丢掉什么**？

学表示就是装这辆车。上一课我们知道了嵌入是"把对象搬进向量空间"，但没说的是：向量维数 $d$ 就是车厢容积，它永远不够大。于是在写任何训练代码之前，先得想清楚这份表示要完成哪几件事。这一课把"好表示"的愿望清单和"维度假约"的代价摊在桌面上。

## 2. 直觉解释

好表示要同时满足三个愿望，像给仓库定三条入库规矩：

1. **语义近邻**：意思相近的对象坐标要近。"手机壳"和"手机膜"必须住邻居——否则推荐系统第一步就垮（第 10 课的主线）；
2. **组合结构**：语义关系应该表现为稳定的方向。用平面箭头说："男 → 女"这支箭，对"爸爸 → 妈妈"、"叔叔 → 婶婶"、"国王 → 女王"应该是**同一支箭**。关系被几何化了，新对象就能搭旧关系的便车；
3. **跨任务迁移**：同一张坐标卡既服务搜索、又服务分类、又服务推荐。好的表示关心的是"这个对象是什么"，而不是死记某一个具体问题的答案。

三愿望背后站着一位严厉的会计——**信息瓶颈**：$d$ 是固定的管道宽度，你从原始数据里灌进去的信息只能这么多，多一维都付不起账。愿望清单决定了该留下什么；瓶颈决定了注定要扔掉什么。

## 3. 正式定义

**定义**：表示学习是在维数 $d$ 受限时寻找映射 $f : X \to \mathbb{R}^d$，使其尽量满足三条性质。

| 愿望 | 几何表述 | 失效症状 |
| --- | --- | --- |
| 语义近邻 | 相似对的距离 $\lVert f(x)-f(y)\rVert$ 小 | 推荐系统推来毫无关联的商品 |
| 组合结构 | 关系对应平移向量：$f(x^*) \approx f(x) + v$ 对同类关系成立 | 类比推理失败，检索靠死记 |
| 跨任务迁移 | 同一向量在多个下游任务上可复用 | 换个任务就得重学全部坐标 |

**信息瓶颈视角**：设原始数据为 $X$、表示为 $Z=f(X)$。学表示 = 在"压缩"与"保留预测力"之间取平衡

$$\min_f \; I(X;Z) - \beta \, I(Z;Y)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $I(X;Z)$ | 互信息（压缩项） | 表示还挂着多少原数据的细节——越小越省管道 |
| $I(Z;Y)$ | 互信息（保留项） | 表示保住了多少对下游目标 $Y$ 的预测力 |
| $\beta$ | 权衡系数 | 你愿意为保留预测力支付多少带宽 |

$\beta$ 大：挤着也要记住任务要紧的信息；$\beta$ 小：图省事，把细节全丢了。真实训练没有显式写出这个式子，但每一个损失函数都在暗地里做这笔交易。

## 4. 分步例题

检验愿望二"组合结构"。某玩具系统给四位家庭成员发了三维坐标卡（第一轴性别：男 $+1$ / 女 $-1$；第二轴辈分：长辈 $+2$ / 晚辈 $0$；第三轴性格活跃度，满刻度 $10$）：

| 词 | 性别轴 | 辈分轴 | 活跃度轴 |
| --- | --- | --- | --- |
| 爸爸 | $+1$ | $+2$ | $+4$ |
| 妈妈 | $-1$ | $+2$ | $-6$ |
| 叔叔 | $+1$ | $+2$ | $+7$ |
| 婶婶 | $-1$ | $+2$ | $-3$ |

三根轴分工明确：前两条管身份，最后一条是个性。现在问"男转女"是不是一支稳定的箭：

1. 差向量一：爸爸 $-$ 妈妈。辈分轴 $2-2=0$ 不动，剩下性别与活跃度两轴各走一步：$[+1-(-1),\; +4-(-6)] = [2, 10]$；
2. 差向量二：叔叔 $-$ 婶婶，同样 $[+1-(-1),\; +7-(-3)] = [2, 10]$；
3. 两支箭完全一致——在这组坐标里，"换成女性"是一条固定的通道，换一对人照样能用；
4. 这正是愿望二的形状：关系不是记忆里的一行数据，而是空间里的一个方向。

## 5. 动手实验

### 实验 1（viz）：维度是统计预算，不是免费午餐

### 实验 2（python）：给两张组织方式做"愿望一体检"

```python title="同类该近异类该远：一个体检指标"
goods = [
    ["冰箱", 9.0, 1.0, "电器"], ["微波炉", 8.5, 2.2, "电器"], ["电风扇", 7.8, 0.8, "电器"],
    ["苹果", 1.2, 8.8, "食品"], ["面包", 2.0, 7.6, "食品"], ["酸奶", 0.6, 9.2, "食品"],
]

def ratio(points):
    # zip(*points)：把列表按列拆开——拿到所有横坐标、纵坐标与标签
    xs, ys, labels = list(zip(*[(p[1], p[2], p[3]) for p in points]))
    within = []   # 存放"同类点对"的距离
    between = []  # 存放"异类点对"的距离
    n = len(points)
    for i in range(n):
        for j in range(i + 1, n):
            d = ((xs[i] - xs[j])**2 + (ys[i] - ys[j])**2) ** 0.5
            if labels[i] == labels[j]:
                within.append(d)
            else:
                between.append(d)
    s_in, s_out = sum(within), sum(between)
    return (s_in / len(within)) / (s_out / len(between))   # 平均类内距离 ÷ 平均类间距离，越小越好

print(round(ratio(goods), 3))

scrambled = [["冰箱", 9.0, 1.0, "电器"], ["苹果", 9.2, 0.4, "食品"], ["微波炉", 1.5, 8.5, "电器"],
             ["面包", 1.0, 9.0, "食品"], ["电风扇", 8.8, 1.8, "电器"], ["酸奶", 2.2, 7.8, "食品"]]
print(round(ratio(scrambled), 3))
```

第一版把电器塞一角、食品塞另一角，比值远小于 1——愿望一达标；打乱后比值逼近甚至超过 1，同类的距离不比异类近，地图报废。**训练做的事，就是把一张乱图往左上角这张好图掰。**

### 快问快答

```quiz
表示的三个愿望同时成立时，模型最划算的表现是什么？
- 把训练集里每个对象的坐标一字不差背下来
- 新任务、新对象可以直接借用已有坐标里的方向和距离结构 [*]
- 维度越大越好，先把车厢塞满再说
? 结构化表示让"经验"可以搬运：学到"性别方向""风格方向"，遇到新词新产品就能零成本复用。死记训练集是过拟合，不是迁移。
```

:::warning[常见误区]

**误区一**："你以为加维度总是赚的。" 维度假约的另一面是统计饥饿：维度翻倍，喂饱每根轴所需的数据量跟着膨胀，尾部的稀疏维度还会放大高维反直觉（下一章细讲）。$d$ 是预算，花在哪里要想清楚。

**误区二**："你以为'相似'等于'有用'。" 近邻只兑现了愿望一。两件商品可以相似得像双胞胎却帮不了价格预测——好的表示还要看下游任务有没有赚到钱，这正是瓶颈式子里 $I(Z;Y)$ 那一项在说话。

**误区三**："你以为三愿望各自独立、缺哪个补哪个。" 它们互相拉扯：为了近邻讨好一个任务，可能牺牲组合结构的通用方向；过度追求迁移又会在具体指标上吃亏。表示设计是多目标的谈判桌，不是单科竞赛。

:::

## 6. 练习

**练习 1**：继续第 4 步例题的四人坐标，把代码跑通并修到两条差向量完全一致为止：

```exercise
# @title: 练习：让"男转女"成为同一支箭
# @check: [2, 10]
# @check: [2, 10]
# @hint: 差向量是"终点减起点"。盯着第二行的减法顺序：叔叔减婶婶，别减反了。
people = {
    "爸爸": [1, 2, 4],
    "妈妈": [-1, 2, -6],
    "叔叔": [1, 2, 7],
    "婶婶": [-1, 2, -3],
}

a = people["爸爸"]
b = people["妈妈"]
v1 = [a[0] - b[0], a[2] - b[2]]           # 爸爸 - 妈妈（性别轴、活跃度轴）
c = people["叔叔"]
e = people["婶婶"]
v2 = [c[0] - e[0], e[2] - c[2]]           # ← 问题在这：活跃度两数减反了，应为 c[2] - e[2]

print(v1)
print(v2)
```

改对后两行输出完全相同。真实的词向量不会这么精确一致，但"平均意义下的稳定方向"足以支撑类比推理——下一课你会看到它的成名之战。

**练习 2**：讨论题——"跨任务迁移"为什么天然要求组合结构？一个只擅长单一任务的表示，缺的是什么？

<details>
<summary>点开查看逐步解答</summary>

迁移的机制是**借用**：新任务来了，不可能重新长出一套坐标，只能复用旧空间里已有的距离和方向。组合结构保证这些方向承载的是抽象关系（"更贵""更相近""更正式"），而不是某个任务的私人切口。只服务单一任务的表示等于把答案直接焊进坐标里——换个提问方式立刻失灵。工程对照：预训练 + 微调范式之所以有效，正是因为预训练阶段攒下了大量可复用的"方向"，微调只需轻推几个参数。
</details>

## 7. 选读：愿望清单的极端版本——率失真

<details>
<summary>选读 · 当预算真的写在合同里时怎么算最优解</summary>

信息瓶颈思想在编码理论里有个亲兄弟：**率失真理论**。问题同样赤裸——给定码率 $R$（每个样本允许占多少比特）与失真度量，求最小可达失真 $D(R)$。曲线随 $R$ 单调下降：带宽越宽失真越小，且整段曲线没有跳跃可以投机。

把 $d$ 维连续向量看作 $R \approx d \cdot \text{精度比特}$ 的预算包，"该留什么"就有了定量判据：**按失真贡献排序，优先保留贡献大的自由度**。PCA 之所以常做流水线第一步（下一章还会见到），就是因为它对二次失真给出了逐分量排序——主成分是性价比最高的那部分车厢空间。

至于 Tishby 的信息瓶颈用于神经网络的说法，近年有争议（实验显示深层网络未必经历明显的压缩相变）。稳妥的态度：把瓶颈当**思考框架**——凡是声称"这个表示层很好"的理论，都要回答"它压掉了什么、保住了什么"。
</details>
