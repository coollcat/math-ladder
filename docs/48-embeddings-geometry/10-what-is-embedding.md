# 什么是嵌入

## 1. 从一个场景开始

购物 App 的首页写着"猜你喜欢"。你刚看完手机壳，它就推来手机膜、钢化膜、充电线——而不是拖把和酱油。可是在计算机内部，"手机壳"三个字只是一个编号，编号 48321 和编号 90517 之间没有任何天生的亲缘。

机器凭什么知道谁和谁像？答案是：先给每个对象发一张**坐标卡**——一串数字，比如 $[0.82, -1.3, 0.07, \ldots]$——再让"像不像"变成"坐标近不近"。这张坐标卡就是**嵌入**（embedding）。

## 2. 直觉解释

想象你要给全班同学排座位，但只有两条规则可用：横轴是"爱运动程度"，纵轴是"爱宅程度"。每个同学打两个分，就得到一个平面坐标——运动健将聚在右侧，游戏宅聚在上方。**人没变，但"谁跟谁合得来"变成了肉眼可见的距离。**

词也一样。语言学家 Firth 有句名言："看一个词的朋友，就知道它是谁。"（You shall know a word by the company it keeps.）"手机壳"和"手机膜"总出现在相似的句子里（保护、贴膜、摔坏），于是它们在语义地图上就该是邻居。这条信念叫**分布式假说**，是全部表示学习的地基：

> 意思相近的对象，出现在相似的上下文里；把它们放进同一个坐标系，就让"相似"有了数学形状——距离和方向。

关键一步是：这些坐标**不是人手打的分数**，而是从海量数据里自动学出来的（第 41 章的 ERM 框架提供了学习压力：让预测失败的坐标被调整）。

## 3. 正式定义

**定义**：给定对象集合 $X$（词、商品、用户、图片……），一个**嵌入**是从 $X$ 到 $d$ 维实向量空间的映射

$$f : X \to \mathbb{R}^d$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f(x)$ | 嵌入向量 | 对象 $x$ 的坐标卡，如 $[0.8, -1.3]$ |
| $d$ | 维度 | 坐标卡上的刻度数；词嵌入常用几十到几千维 |
| $\lVert f(x)-f(y) \rVert$ | 距离 | 衡量两对象的"不相似度" |

每一维没有义务对应一个人类能读懂的概念（比如"电子味"），它只需要**整体上**保住相似关系：原来像的，坐标近；原来不像的，坐标远。"意义"被翻译成了几何。

## 4. 分步例题

**例**：手工造一张微型语义地图。取两条轴：第一轴"动物性"（0 是纯机械，10 是纯生物），第二轴"体型"（0 小 10 大）。给四个词打分：

| 词 | 动物性 | 体型 |
| --- | --- | --- |
| 猫 | 8 | 2 |
| 狗 | 8 | 6 |
| 鲨鱼 | 8 | 9 |
| 手机 | 0 | 5 |

问：和"狗"最像的是谁？

1. 写出狗的坐标 $(8,6)$；
2. 逐个算欧氏距离（两点直线距离，第 5 章 $\text{hypot}$ 的老朋友）：
   - 到猫：$\sqrt{(8-8)^2+(6-2)^2}=\sqrt{16}=4$
   - 到鲨鱼：$\sqrt{(8-8)^2+(6-9)^2}=3$
   - 到手机：$\sqrt{(8-0)^2+(6-5)^2}=\sqrt{65}\approx 8.06$
3. 距离最小的是鲨鱼（3），所以在这张地图上"狗最像鲨鱼"——都算大型动物。

注意教训：**距离完全由你选的轴决定**。换两条轴（比如"能否当宠物"），答案立刻改变。真实词嵌入的过人之处在于：几千条轴都是从语料里学出来的，比人工拍脑袋全面得多。

### 实验 2（python）：给四件商品画语义地图

```python title="手工嵌入 + 散点图"
import matplotlib.pyplot as plt  # 画图库（第 0 章引入）

items = {
    "case": [3, 8],    # 字典 dict：键值对容器，这里"商品名 -> 特征坐标"
    "cable": [7, 4],
    "film": [2, 9],
    "mop": [1, 1],
}

xs = []   # 准备散点的横坐标列表
ys = []
for name in items:
    xs.append(items[name][0])
    ys.append(items[name][1])
    plt.text(items[name][0] + 0.15, items[name][1], name)  # text：在坐标旁标注文字

plt.scatter(xs, ys, s=90)   # scatter：散点图，s 是点的大小
plt.xlim(0, 10)
plt.ylim(0, 10)
plt.xlabel("durability")    # 第一轴：耐用度
plt.ylabel("beauty")        # 第二轴：美观度
plt.grid(True)
```

`film`（手机膜）和 `case`（手机壳）挤在左上角，`mop`（拖把）孤零零在角落——"推荐系统"的第一性原理不过如此：**把离查询点最近的几件推出去**。

### 快问快答

```quiz
嵌入向量的每一维通常代表什么？
- 一个人类能准确说出的属性，比如"颜色"
- 一条学出来的抽象方向，单维未必有可读含义 [*]
- 词在词典里的出现顺序
? 分布式表示里，单个维度往往不可解释，但整体方向与距离承载了语义。强行给每一维贴人类标签通常会失败。
```

:::warning[常见误区]

**误区一**："你以为嵌入的每一维都有明确含义，可以逐个解读。" 大多数维度是抽象方向的混合，单独拎出来常常不知所云。有意义的是**相对关系**（距离、夹角），不是单维数值。

**误区二**："你以为维度越高一定越好。" 高维带来表达力，也带来稀疏与计算代价，还会放大下一课之后讲的"高维反直觉"。工程上是在精度与成本之间折中，不是无脑堆维度。

**误区三**："你以为'相似'只有一种。" 距离度量不同，邻居就不同（本课用欧氏距离，下一课会换成余弦）。先问"按哪种意义相似"，再谈最近邻。

:::

## 6. 练习

**练习 1**：三件商品的二维特征如下：手机壳 $[3,8]$、充电线 $[7,4]$、手机膜 $[2,9]$（第一轴耐用度、第二轴美观度）。打印每两件的距离，找出该推荐给"正在看手机壳的用户"的那一件。代码能跑，但有两处距离公式写错了——改到通过：

```exercise
# @title: 练习：谁离手机壳最近
# @check: 5.66
# @check: 1.41
# @check: 7.07
# @hint: 距离衡量"差多少"：每个分量先相减、再平方、最后开方。对照已写对的 d_ab 检查另外两行。
a = [3, 8]   # 手机壳
b = [7, 4]   # 充电线
c = [2, 9]   # 手机膜

d_ab = ((a[0] - b[0])**2 + (a[1] - b[1])**2) ** 0.5   # 这一行是对的
d_ac = ((a[0] + c[0])**2 + (a[1] + c[1])**2) ** 0.5   # ← 问题在这：分量不该相加
d_bc = ((b[0] + c[0])**2 + (b[1] + c[1])**2) ** 0.5   # ← 这里也一样

print(round(d_ab, 2))
print(round(d_ac, 2))
print(round(d_bc, 2))
```

改对后观察：$d_{ac}=1.41$ 最小，手机膜是最佳推荐——虽然它在图上离原点更远。

**练习 2**：如果给"猫、狗、鲨鱼、手机"再加第三条轴"是否水生"（猫 0、狗 0、鲨鱼 10、手机 0），重算例题中狗到各词的距离，最近邻变了吗？

<details>
<summary>点开查看逐步解答</summary>

三维距离把每一轴的差平方后求和再开方：

```python
dog = [8, 6, 0]
cat = [8, 2, 0]
shark = [8, 9, 10]
phone = [0, 5, 0]

def dist(p, q):
    s = 0
    for k in range(len(p)):       # len(p)：数一数向量的维数
        s = s + (p[k] - q[k])**2
    return s ** 0.5

print(round(dist(dog, cat), 2))     # 4.0 —— 不变
print(round(dist(dog, shark), 2))   # 10.44 —— 被"水生"轴推开
print(round(dist(dog, phone), 2))   # 8.06 —— 不变
```

最近邻从鲨鱼变回猫。**加一条新轴 = 引入一种新的区分标准**，它会重新洗牌整个地图。真实嵌入模型成千上万条轴同时起作用，靠人工逐条设计是不可能的。
</details>

## 7. 选读：为什么叫"嵌"入

<details>
<summary>选读 · 从符号宇宙到向量宇宙的保距搬运</summary>

"嵌入"（embedding）本是拓扑学术语：把空间 $X$ 结构完好地放进空间 $Y$（第 58 章的同胚概念是它的极端版本）。机器学习借这个词，强调两件事：

1. **搬运**：离散的符号世界（词典里的字、目录里的商品）本来没有几何，嵌入把它们搬进连续的向量宇宙 $\mathbb{R}^d$；
2. **保值**：搬运必须保住我们关心的结构——语义相似关系变成距离相近。搬完之后结构散架的映射不配叫嵌入。

理想很丰满，现实是折中：$d$ 维空间塞不下任意复杂的相似结构（第 40 课会看到高维本身的怪脾气），所以真实嵌入只是"尽可能不失真"的有损压缩。评价一张嵌入地图好不好，最终要回到下游任务的表现——这正是第 41 章"泛化"思想的又一次登场。

</details>
