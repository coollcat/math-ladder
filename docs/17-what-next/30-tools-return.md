# 老工具的下一站

## 1. 螺旋上升：同一思想会反复回来

数学不是一条直线，而是一条盘山道：同一个思想每隔几卷就会回来一次，每次海拔更高、外衣更正式。本站把这个规律叫**螺旋上升**。这张课就是一张「重逢预报表」——告诉你卷一的每件老工具，会在后面哪座山上、以什么新名字与你会合。

先记住判断口诀：**遇到陌生的高级名词，先猜它是卷一哪件工具的长大版**——十有八九猜得中。

## 3. 重逢时的提醒

老工具回归时会**换外衣**：说法更严格、记号更抽象。两个心理准备：

- **名字可能全变**。卷一的「多项式逼近」到实分析里叫「一致收敛的幂级数展开」；卷一的「移项」到优化里叫「约束变换」。认出它们靠的是**结构**（谁对谁做什么操作），不是名字。
- **严格化会「推翻」一些直觉**。卷一说「可导就是光滑」，实分析会给你处处连续却处处不可导的怪物；卷一说「长度」，测度论会造出量不出长度的集合。这不是打脸——是把你卷一的直觉升级成知道**边界在哪**的直觉。

:::warning[常见误区]
「老工具已经学过，后面用到直接跳」——重逢课恰恰是收获最大的课：你带着具体的旧直觉去见严格版本，对照感远强于首学。跳过它们，省下的是两小时，错过的是整张知识网。
:::

## 4. 小测验

```quiz
- 乘法分配律
- 辗转相除求最大公约数
- 链式法则 [*]
- 大数定律
? 反向传播的本质就是链式法则：把「改一个输入如何影响最终输出」沿计算图逐层拆解相乘——只是规模放大到了几十亿个参数。
```
