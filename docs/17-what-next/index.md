## 实战挑战 · 五卷计数器

选路之前，先认一下山门的编号规矩。全站五个卷册按章号划分：卷一是 00–16，卷二是 18–26，卷三是 27–35，卷四是 36–42，卷五是 43 以后。下面的「计数器」能把任意章号翻译成它所属的卷册——但后两级台阶还没修好，请你补全，让 Transformer 所在的第 47 章正确报出归宿：

```exercise
# @title: 五卷计数器
# @check: 47 属于 卷五 应用 AI 与前沿
# @hint: 照着卷二、卷三的样子再补一级 elif：36 到 42 归卷四；剩下的（43 以后）全部归卷五，用一个 else 兜底即可。
ch = 47                      # 想查询的章号（Transformer 在第 47 章）

if ch < 18:
    vol = "卷一 数学地基"
elif ch <= 26:
    vol = "卷二 高等数学核心"
elif ch <= 35:
    vol = "卷三 离散数学与计算"
# ↓ 还差两级台阶：把卷四（36–42）和卷五（43 以后）补出来
elif ch <= 999:
    vol = "待补全"
print(ch, "属于", vol)
```

<details>
<summary>点开查看参考答案</summary>

最后两级是一个 `elif` 加一个 `else`：判断从上往下逐级排查，落到 36–42 之间的是卷四，凡是没被前面拦住的都归卷五。

```python
ch = 47                      # 想查询的章号

if ch < 18:
    vol = "卷一 数学地基"
elif ch <= 26:
    vol = "卷二 高等数学核心"
elif ch <= 35:
    vol = "卷三 离散数学与计算"
elif ch <= 42:
    vol = "卷四 概率统计与信息"
else:
    vol = "卷五 应用 AI 与前沿"
print(ch, "属于", vol)
```

运行输出：`47 属于 卷五 应用 AI 与前沿`。这套「逐级拦截 + else 兜底」的划分法，和第 0 章实战区判断成绩档位用的是同一个思想——老工具，对吧？
</details>

## 实战挑战 · 卷号判断的循环版

上面那题用 `if/elif` 逐级拦截；同一张卷册边界表，也能用**循环扫一遍**：把各卷末尾章号存成列表，从上往下找第一个"盖住当前章号"的边界。第 47 章应报出卷五。下面这题默认卷号写错了，修到输出 `5`：

```exercise
# @title: 卷号判断的循环版
# @check: 5
# @hint: 扫遍边界都不命中，说明落在最后的卷五；默认卷号应是 5，不是 0。
ch = 47                            # 想查询的章号
boundaries = [16, 26, 35, 42]      # 卷一~卷四的末尾章号
vol = 0                            # ← 问题在这：默认应是卷五 = 5
for i in range(len(boundaries)):   # 从卷一起逐级排查
    if ch <= boundaries[i]:
        vol = i + 1                # 命中第 i 个边界 → 属于第 i+1 卷
        break
print(vol)
```

<details>
<summary>点开查看逐步解答</summary>

扫遍四个边界都不命中，说明章号落在最后的卷五：

```python
vol = 5    # 默认卷五；命中边界再改成对应卷号
```

改完：$47$ 大于所有边界（$16,26,35,42$），循环不 `break`，输出 `5`。初始代码默认 `0`，把"漏网"的章号归进了不存在的卷零。这套"边界列表 + 循环扫描"与 `if/elif` 版殊途同归——都是把同一张版图翻译成代码，选哪种写法，取决于你想"逐条写死"还是"用数据驱动"。

</details>
