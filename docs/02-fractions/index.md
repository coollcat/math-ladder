## 实战挑战 · 并联电阻与分数加法

真实电子工程师在给电路配电阻时，几乎天天和分数打交道。情境改编自经典题型（初中物理·串并联电路，人教版九年级物理的常客）：

小明在拼装一台光控小台灯，手里有两只电阻：$R_1 = 6$ 欧姆、$R_2 = 3$ 欧姆。

**(a) 串联**：把两只电阻首尾相连（串联），总电阻等于各电阻之和——这条规则初中物理直接给出：$R_{串} = R_1 + R_2$。

**(b) 并联**：把两只电阻并排接入同样的两点之间（并联），总电阻的**倒数**等于各电阻倒数之和（公式初中物理会推导，这里直接拿来用）：

$$\frac{1}{R_{并}} = \frac{1}{R_1} + \frac{1}{R_2}$$

请算出：串联总电阻；$\frac{1}{R_1} + \frac{1}{R_2}$ 通分后的新分子与新分母；再约分求出并联总电阻 $R_{并}$。第一问已示范：

```exercise
# @title: 实战挑战：并联电阻里的分数加法
# @check: 9
# @check: 3
# @check: 6
# @check: 2
# @hint: (b) 分母 6 与 3 的最小公倍数是 6（两列倍数队伍第一个碰头的数）：把 1/3 化成 2/6 再相加；约分成 1/2 后，倒数关系反过来就是总电阻。
r1 = 6   # 电阻一的阻值（欧姆）
r2 = 3   # 电阻二的阻值（欧姆）

print(r1 + r2)   # (a) 串联总电阻 = 各电阻相加（已示范）
print()          # (b) 第 1 行：通分后的新分子
print()          # (b) 第 2 行：通分后的公分母
print()          # (b) 第 3 行：并联总电阻（欧姆）
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 串联：$R_{串} = 6 + 3 = 9$ 欧姆。

**(b)** 第一步通分——分母 6 与 3 的最小公倍数是 6（公倍数的名册立在第 1 章《因数与倍数》，它将在第 10 章《最小公倍数：钟表重逢问题》一课拿到正式编制），于是

$$\frac{1}{6} + \frac{1}{3} = \frac{1}{6} + \frac{2}{6} = \frac{3}{6}$$

新分子 3、新分母 6。第二步约分：$\frac{3}{6} = \frac{1}{2}$，即 $\frac{1}{R_{并}} = \frac{1}{2}$，所以 $R_{并} = 2$ 欧姆。

用第 20 课的通分公式交叉验算一遍（走另一条路，结果必须一致）：

```python
num1, den1 = 1, 6   # 1/6
num2, den2 = 1, 3   # 1/3

new_den = den1 * den2                 # 公式版公分母：18
new_num = num1 * den2 + num2 * den1   # 交叉相加：3 + 6 = 9
print(f"{new_num}/{new_den}")         # 9/18 —— 约分后同样是 1/2

r_parallel = new_den // new_num       # 倒数的倒数：18 // 9 = 2
print(r_parallel)
```

物理哨卡：并联总电阻应当**比任何一只分电阻都小**——$2 < 3 < 6$ ✓。分数算错时这个不等式最先报警。
</details>

## 章节大题：柠檬水档口的周末账本

这一章的装备全部到齐，来给柠檬水档口算一笔周末账。周五卖出 100 杯；周六、周日都比前一天多卖两成。下面的代码把**通分、倒数相乘、运算优先级、分数即除法、round 舍入、百分数的基数意识**一次全用上——它能跑，但四行输出没有一行是对的。把它修到四行检查全部通过：

```exercise
# @title: 章节大题：柠檬水档口的周末账本
# @check: 糖水总量: 7/12 升
# @check: 能装满: 6 杯
# @check: 单杯成本: 11.67 元
# @check: 两天累计涨幅: 44%
# @hint: 四处暗坑：异分母相加必须先通分（分子加分子、分母加分母是第 20 课点名的头号误区）；倒数相乘时新分母的整体要用括号抱住，否则从左往右算会多倒出好几杯；金额展示交给 round(x, 2)；两次增长各站在各自的基数上，百分数不能直接相加。
num1, den1 = 1, 3   # 第一锅糖水：1/3 升（分子、分母成对出场）
num2, den2 = 1, 4   # 第二锅糖水：1/4 升

mix_num = num1 + num2          # ← 暗坑①：分子加分子、分母加分母？
mix_den = den1 + den2
print(f"糖水总量: {mix_num}/{mix_den} 升")

p_num, p_den = 5, 2   # 大壶里的柠檬汁：5/2 升
c_num, c_den = 2, 5   # 一杯的量：2/5 升
cups = p_num * c_den // p_den * c_num   # ← 暗坑②：想按"颠倒相乘"写，却少了一对括号
print(f"能装满: {cups} 杯")

cost = 70 / 6                            # 六杯共用去原料 70 元
print(f"单杯成本: {cost} 元")             # ← 暗坑③：这么长的尾巴没法见客

base = 100        # 周五卖出的杯数
rise_sat = 20     # 周六比周五多卖两成
rise_sun = 20     # 周日比周六又多卖两成
total_rise = rise_sat + rise_sun         # ← 暗坑④：两次增长的基数可不是同一个人
print(f"两天累计涨幅: {total_rise}%")
```

<details>
<summary>点开查看逐步解答</summary>

四处暗坑对应本章四课：

1. **通分**（第 20 课）：$\frac{1}{3}$ 与 $\frac{1}{4}$ 的计数单位不同，不能分子加分子、分母加分母——那样得 $\frac{2}{7}$，比两个加数都小，一眼假。先通分到公分母 12：$\frac{4}{12}+\frac{3}{12}=\frac{7}{12}$；分子 7 与分母 12 没有公因数，已经是最简分数。
2. **分数即除法 + 倒数相乘**（第 10、20 课）+ **运算优先级**（第 08 课）：$\frac{5}{2}\div\frac{2}{5}$ 该颠倒相乘：$\frac{5}{2}\times\frac{5}{2}=\frac{25}{4}=6.25$，装满整杯能算 6 杯。分数线就是躺平的除号，写成一行整数运算时，新分母的乘积 $2\times 2$ 必须用括号抱住；漏掉括号就从左往右先算 25 // 2 再乘 2，得出 24 杯——两升半的壶倒出二十四杯，荒唐得一眼假。
3. **round 舍入**（第 30 课）：$70\div 6=11.666\ldots$ 是无限循环小数，直接打印没法见客；`round(cost, 2)` 保留两位小数得 11.67。（顺带复习：恰逢 .5 正中间时 Python 取最近的偶数，本题不沾边，放心用。）
4. **百分数的基数**（第 40 课）：第二次的两成站在周六的 120 杯上长：$100\to 120\to 144$，累计涨 44%，不是 40%。百分数只有在同一基数下才能相加。

修好后的关键代码：

```python
new_den = den1 * den2                    # 通分：公分母 3 × 4 = 12
new_num = num1 * den2 + num2 * den1      # 交叉相加：4 + 3 = 7（已是最简）
print(f"糖水总量: {new_num}/{new_den} 升")

cups = p_num * c_den // (p_den * c_num)  # 颠倒相乘再取整杯：25 // 4 = 6
print(f"能装满: {cups} 杯")

print(f"单杯成本: {round(cost, 2)} 元")   # 保留两位小数再见客

saturday = base * 120 // 100             # 多两成 = 乘 120 再除以 100
sunday = saturday * 120 // 100           # 第二次增长站在周六的基数上
print(f"两天累计涨幅: {sunday - base}%")  # 144 - 100 = 44
```

一条分数线牵出通分、倒数与优先级三件事，一次连涨戳破“百分数可以直接相加”的错觉——四行检查全绿，本章的语言就算真正带在身上了。
</details>
