# 负数的乘除

## 1. 从一个场景开始

气温每天下降 $2^\circ\text{C}$（记作 $-2$），3 天后共降了 6 度：$(-2)\times 3 = -6$，没有争议。可要是问：**3 天前**的气温比现在高多少？算式就成了 $(-2)\times(-3)$——负乘负，结果是正还是负？

课本上这叫"负负得正"，念起来像咒语。本站的规矩是不背咒语：这一课我们让这条法则**自己从规律表里长出来**。你会发现它根本轮不到谁来规定。

## 2. 直觉解释

先算能算的。乘法是连续相加，所以：

$$3\times(-2) = (-2)+(-2)+(-2) = -6$$

正数乘负数没问题。卡住的只有负乘负："$-2$ 加上自己负 3 次"这话没有意义。

换个思路——**别盯着个例，盯着变化**。固定一个因数为 2，让另一个因数每次减 1：

| 算式 | $2\times 3$ | $2\times 2$ | $2\times 1$ | $2\times 0$ | $2\times(-1)$ | $2\times(-2)$ |
| --- | --- | --- | --- | --- | --- | --- |
| 积 | $6$ | $4$ | $2$ | $0$ | $?$ | $?$ |

看这一行积的变化：**每往右一格，恰好少 2**。既然如此，越过 0 之后没理由变卦：继续少 2，就是 $-2$、$-4$。

于是 $2\times(-1)=-2$、$2\times(-2)=-4$——不是新规定，而是老规律的必然延续。

## 3. 正式定义

把上面的观察整理成**符号法则**：

| 因数符号 | 积的符号 | 例子 |
| --- | --- | --- |
| 同号（正×正、负×负） | 正 | $(-2)\times(-3)=6$ |
| 异号（正×负、负×正） | 负 | $(-2)\times 3=-6$ |
| 有因数是 0 | 0 | $(-5)\times 0=0$ |

数字部分照常相乘。用公式写：

$$(-a)\times b=-(a\times b), \qquad (-a)\times(-b)=a\times b$$

两条老相识前来会师：

1. **相反数回收**：上一章说过 $a+(-a)=0$ 且 $-(-n)=n$（相反数的相反数是自己）。注意"乘 $-1$"恰好就是"取相反数"这个动作：$(-1)\times n=-n$。所以 $(-n)\times(-1)= -(-n)= n$——负负得正只是它的特例。
2. **除法方向同理**：除法是乘法的逆运算，$a\div b$ 就是那个"乘上 $b$ 之后等于 $a$"的数。积的符号由因数符号决定，商的符号自然服从同一张表：

$$(-6)\div 2=-3 \quad(\text{异号得负})， \qquad (-6)\div(-2)=3 \quad(\text{同号得正})$$

验算：$(-3)\times 2=-6$ 成立，$3\times(-2)=-6$ 也成立。

## 4. 分步例题

**例 1**：计算 $(-4)\times(-5)$。
1. 判符号：同号 → 得正；
2. 算数字：$4\times 5=20$；
3. 合并：$+20$。

**例 2**：计算 $(-12)\div 3$。
1. 判符号：异号 → 得负；
2. 算数字：$12\div 3=4$；
3. 合并：$-4$。验算：$(-4)\times 3=-12$ ✓

**例 3**：连续相乘 $(-2)\times 3\times(-5)$。
1. 先算前两个：异号 → $-6$；
2. 再乘 $(-5)$：同号 → $30$。
3. 规律：**负因数有奇数个，积为负；有偶数个，积为正。**

## 5. 动手实验

先用图像找感觉：拖动系数 `k` 扫过正与负，看直线怎样绕原点翻面——"负负得正"就藏在斜率的符号里。

### 实验 1：先用直线找感觉，再打印符号矩阵

把 $-3..3$ 与 $-2..2$ 两两相乘，只记录每个积的符号，看看图案长什么样：

```viz
{
  "type": "plot",
  "title": "y = k·x：k 变号，直线翻面",
  "expr": "k*x",
  "xmin": -3, "xmax": 3,
  "sliders": [ { "name": "k", "min": -2, "max": 2, "step": 0.5, "value": -2 } ]
}
```

```python title="(-3..3) × (-2..2) 的符号矩阵"
for a in range(-3, 4):        # 外层循环：a 从 -3 数到 3（含头不含尾）
    line = ""
    for b in range(-2, 3):    # 内层循环：对每个 a，b 从 -2 数到 2
        p = a * b
        if p > 0:             # 分支判断：条件成立才执行下面缩进的行
            mark = "+"
        elif p < 0:           # elif＝“否则如果”：上一个条件不成立时再试这个
            mark = "-"
        else:                 # else＝“以上全不成立”时兜底
            mark = "0"
        line = line + mark    # 字符串也能当累加器：把符号一个个拼起来
    print(f"a={a}: {line}")
```

输出是一张符号地图：`+` 恰好铺满两条对角带（$a,b$ 同号的区域），`-` 占据另外两片，0 的行列清一色 `0`——**同号得正、异号得负**直接长在了图案里。

### 实验 2：完整的乘积矩阵

```python title="同一张矩阵，这次看乘积本身"
table = []
for a in range(-3, 4):
    row = []                  # 每行先备一个空列表
    for b in range(-2, 3):
        row.append(a * b)     # append：把乘积追加到当前行末尾
    table.append(row)

for row in table:
    print(row)
```

对照实验 1 的符号地图读数字：正数正好落在对角带上。你可以把 `range` 的范围改宽再跑一遍——图案会向外扩大，但“同号得正、异号得负、有零得零”的位置规则不变。

### 实验 3（滑块）：符号翻转台

规律表是静态的，现在给它装上手柄：把 $a\times b$ 的两个因数都交给滑杆，盯住最后一行的符号判决，慢慢把 a 或 b 拖过 0：

```python title="拖动因数穿过零点，看符号判决"
# sliders: a=2 [-5:5:1], b=-3 [-5:5:1]

p = a * b                  # 积：两个因数直接相乘（a、b 由滑杆注入，代码里不许再赋值）
print(f"{a} × {b} = {p}")
if p > 0:                  # 判决行：只看积的符号
    print("同号得正")
elif p < 0:
    print("异号得负")
else:
    print("有因数是 0：积为 0")
```

a 从 2 一路拖到 -5：判决在穿过 0 的那一瞬从"异号得负"翻成"同号得正"。符号法则不是背出来的口诀——它就是"因数是否跨过零点"的直接读数，与第 2 节那张规律表互为印证。

### 快问快答

```quiz
算式 (-2) × (-2) × (-2) 的结果是正数还是负数？
- 正数
- 负数 [*]
- 是 0
? 奇数个负因数连乘：前两个负负得正，再乘第三个又变回负，所以结果是 -8。
```

:::warning[常见误区]

**误区一**："负负得正是数学书规定的，背下来就行。"
它是规律表一步步逼出来的：因数每减 1，积必须按固定步伐变化，走进负数区后符号已无别的选择。规定的是步伐，不是结果。

**误区二**："负数相乘一定会越乘越小。"
不一定。$(-2)\times(-3)=6$ 反而变大；$(-2)\times 3=-6$ 才变小。先把符号判清楚，再单独算数字部分——符号和大小是两件事。

**误区三**：给除法的符号另编一套口诀。
不必。除法是乘法的逆运算："商 × 除数 = 被除数"，乘法那张符号表自动管住了商。

:::

**练习 1**：符号判断三连。第一题已示范：

```exercise
# @title: 练习：符号判断三连

print((-2) * 3)
print()  # (2)：自己出一道同号相乘、积为正数的算式
print()  # (3)：连乘四个负数，让积为正数
```

**练习 2**：水位每小时下降 3 厘米（记作 $-3$），问 4 小时**之前**的水位比现在高还是低多少厘米？先用符号法则算，再用生活常识检验。

<details>
<summary>点开查看逐步解答</summary>

算式：$(-3)\times(-4)=12$（同号得正）。常识检验：一直在降水位，那 4 小时前当然比现在高，高出 $3\times 4=12$ 厘米。两种算法一致——符号法则通过了现实校验。
</details>

**练习 3**：用"$(-1)\times n = -n$"解释为什么 $(-1)\times(-n)=n$。

<details>
<summary>点开查看逐步解答</summary>

$(-1)\times(-n)$ 就是"取 $-n$ 的相反数"。上一章证过 $-(-n)=n$（照两次镜子回到原处）。所以 $(-1)\times(-n)=n$。"乘 $-1$"与"取相反数"是同一个动作——这是后面代数章反复使用的视角。
</details>

## 7. 选读：为什么可以相信一张表格？

<details>
<summary>选读 · 规律归纳的逻辑地位</summary>

表格归纳提供的是强信念而非严格证明。严格版本要先把整数乘法形式化（沿用第 1 章"乘法出生证明"的思路扩展到负数区），验证分配律在负数上依然成立，然后推出 $(-a)b=-(ab)$ 与 $(-a)(-b)=ab$。有趣之处在于：一旦坚持"分配律不许破坏"，负负得正就是唯一自洽的选择——它是被体系逼出来的，不是谁拍脑袋定的。这种"为了保住更基本的性质而被迫接受结论"的推理模式，第 12 章复数登场时会原样重演。

</details>
