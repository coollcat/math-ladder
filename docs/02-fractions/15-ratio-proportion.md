# 比、比率与正比例

## 1. 从一个场景开始

菜谱写着：米 2 杯配水 3 杯。今晚客人翻倍，米下了 4 杯——水该放几杯？你的直觉秒答"6 杯"。这个直觉值得深挖：它背后是一条**锁死的倍数关系**，是全数学最常用的结构之一，也是将来理解频率、周期的第一块地基。

## 2. 直觉解释

三个词，一层比一层抽象：

- **比**：两个量的份数关系。米:水 $=2:3$，读作"二比三"，只关心配比，不关心总量；
- **比率（比值）**：把比换算成一个数。$3\div 2=1.5$——每 1 杯米配 1.5 杯水；
- **占比**：部分对整体的比。粥锅里总共 5 份，米占 $\frac{2}{5}$。

关键观察：$4:6$ 和 $2:3$ 是**同一个比**——两杯的份数关系没有因为客人变多而改变。把"同时乘同一个数、比值不变"推到极致，就得到本章主角：

**正比例**：两个量始终保持同一比值，一个量是另一个量的固定倍数。

## 3. 正式定义

**比与比值**：记 $a:b=\dfrac{a}{b}\ (b\neq 0)$。比号"："和分数线是同一个意思的两种写法。

**比例**：两个比相等的式子，如 $2:3=4:6$。判断方法：交叉相乘必须相等（$2\times 6 = 3\times 4$）。

**正比例**：若 $y=kx$（$k$ 为非零常数），称 $y$ 与 $x$ 成正比例，$k$ 叫**比例系数**。它的图像有两张身份证：**过原点** + **是一条直线**。

主打可视化来了——拖动滑块改变配比 $k$，看直线怎么转：

$k$ 变大，直线翘得更陡；但无论怎么拖，它都死死钉在原点上——"0 杯米配 0 杯水"，这就是过原点的物理含义。

## 4. 分步例题

**例 1**：把 $3:4$ 写成比值。
1. 换写法：$3:4=\frac{3}{4}$；
2. 结论：每 1 份对应 $\frac{3}{4}$ 份。

**例 2**：班里 40 人，16 人戴眼镜，求戴眼镜者的占比。
1. 部分比整体：$\frac{16}{40}$；
2. 分子分母同除以 8（第 20 课正式讲约分）：$\frac{2}{5}$；
3. 占比是 $\frac{2}{5}$（换成百分数说法就是 40%，40 课见）。

**例 3**：判断哪些成正比例。
1. 单价不变时，总价与数量：总价 $=$ 单价 $\times$ 数量 → 正比例 ✓
2. 正方形的周长与边长：周长 $=4\times$ 边长 → 正比例 ✓
3. 打车费与里程：起步价 12 元，费用 $=12+2.4\times$ 里程 → **不是**：里程为 0 时费用是 12 不是 0，不过原点 ✗

## 5. 动手实验

### 实验 1：菜谱表格——比值纹丝不动

```python title="米和水一起翻倍，比值一动不动"
rice_list = []
water_list = []
ratio_list = []

for x in range(1, 6):            # 做 1 到 5 份菜谱
    rice = 2 * x                 # 米：2 的 x 倍
    water = 3 * x                # 水：3 的 x 倍
    rice_list.append(rice)
    water_list.append(water)
    ratio_list.append(water / rice)   # / 得到小数比值

for i in range(5):
    print(f"米 {rice_list[i]} 杯, 水 {water_list[i]} 杯, 水/米 = {ratio_list[i]}")
```

不管做几份，水/米永远是 1.5。**总量在变，比值不动**——这正是正比例的操作定义，也是"客人翻倍水放多少"能秒答的原因。

### 实验 2：过原点的检验

```python title="打车费为什么不过原点"
mileage_list = [0, 1, 2, 3]
fare_a = []                      # 纯按里程：正比例候选
fare_b = []                      # 带起步价：嫌疑犯
for m in mileage_list:
    fare_a.append(2.4 * m)       # 只收里程费
    fare_b.append(12 + 2.4 * m)  # 起步价 12 元 + 里程费
print(f"里程 {mileage_list}")
print(f"无起步价: {fare_a}")
print(f"有起步价: {fare_b}")
```

`fare_b` 在里程 0 时已经收了 12 元——起点不在原点，正比例资格被一票否决。**检验口诀：先把量归零，看另一个量是否也归零。**

### 快问快答

```quiz
下列哪一组量成正比例？
- 人的年龄与身高
- 单价不变时，购买的总价与数量 [*]
- 正方形的面积与边长
? 总价 = 单价 × 数量，商恒定且过原点。面积 = 边长的平方：虽然也随边长增大，但增长速度越来越快，图像是曲线不是直线；年龄与身高则连固定比值都没有。
```

:::warning[常见误区]

**误区一**："3:4 就是具体的 3 个和 4 个。"
比表示的是**关系**而非数量：6:8、30:40 与 3:4 全是同一个比。抓住比值，就抓住了关系的本质。

**误区二**："只要一个变大另一个也变大，就叫正比例。"
还得**商恒定**。边长与面积会同增，但边长从 2 到 3 面积从 4 跳到 9——不同倍数，不成正比例。"同增"只是必要条件。

**误区三**："占比可以超过 100%。"
部分不可能超过整体，占比最大是 1（即 100%）。算出超过 1 时先回头查：是不是分子分母放反了。

:::

## 6. 练习

**练习 1**：判断 4:6 与 2:3 是否为同一个比。用"交叉相乘"验证——下面的代码能跑但打印的是错误的东西，请改成分别打印两组交叉乘积：

```exercise
# @title: 练习：交叉相乘验比例
# @check: 12
# @check: 12
# @hint: 写成 4:6 = 2:3 后，两个外项是 4 和 3，两个内项是 6 和 2——外项之积与内项之积各是多少？
print(4 + 6 + 2 + 3)
```

<details>
<summary>点开查看逐步解答</summary>

```python
print(4 * 3)   # 外项之积 = 12
print(6 * 2)   # 内项之积 = 12（即 2×6）
```

两次都打印 12 → $4:6 = 2:3$ 成立。交叉相乘是判等的最快通道，第 4 章解方程时它还会大显身手。
</details>

**练习 2**：地图比例尺为 1:50000，图上 3 厘米代表实际多长（厘米）？

<details>
<summary>点开查看逐步解答</summary>

实际距离 $=3\times 50000=150000$ 厘米（1.5 公里）。比例尺是正比例的直接应用：图上长度与真实长度比值恒定。
</details>

**练习 3**：汽车匀速行驶 2 小时行 150 千米。路程与时间成正比例吗？照这个速度 5 小时行多远？

<details>
<summary>点开查看逐步解答</summary>

匀速意味着速度（比值）恒定：$150\div 2=75$ 千米/小时，所以成正比例，速度就是比例系数。5 小时行 $75\times 5=375$ 千米。"速度"这个词，数学上就是一个比率。
</details>

## 7. 选读：无处不在的"每"

<details>
<summary>选读 · 比率是文明的通用语</summary>

单价（元/件）、速度（米/秒）、密度（克/立方厘米）、汇率、收视率……凡是带"每"字的量都是比率。人类发明"每"，是为了把不同的交易、不同的旅程放到**同一把尺子**下比较。更妙的是第 13 章的预告：导数的本质也是一种"每"——每一瞬间的变化率。可以说，从菜谱到微积分，"比值锁定"这根主线贯穿了整座数学阶梯。

</details>
