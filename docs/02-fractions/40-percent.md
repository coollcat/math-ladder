# 百分比

## 1. 从一个场景开始

手机电量 85%、降水概率 60%、商品"七五折"——全世界为什么都爱用"每一百"说话？因为比较。$\frac{17}{20}$ 和 $\frac{43}{50}$ 谁大？盯着看三秒未必有答案；可一旦都换算成"每一百"：85% 对 86%，一眼定胜负。

**百分数就是分母统一钉死为 100 的分数**——一个为比较而生的标准化记法。

## 2. 直觉解释

三种写法，同一个数：

```
        除以100            乘100
 分数 <--------> 小数 <--------> 百分数
 (3/4)          (0.75)          (75%)
```

- 分数擅长精确运算（上一课的主角）；
- 小数擅长机器存储与计算（上一课的结论）；
- 百分数擅长人类比较（本课主角）。

三者之间没有换算"魔法"，只有两条动作：除以 100、乘以 100。符号 % 读作"百分之"，本身就是 $\frac{1}{100}$ 的缩写——$45\% = 45\times\frac{1}{100} = \frac{45}{100} = 0.45$。

## 3. 正式定义

$$p\% := \frac{p}{100}$$

三角互化规则表：

| 从 | 到 | 动作 |
| --- | --- | --- |
| 百分数 | 小数 | 去掉 %，除以 100 |
| 小数 | 百分数 | 乘以 100，补上 % |
| 分数 | 百分数 | 先化小数，再乘 100 |

求"a 的 p%"：把"的"翻译成乘号——$a\times\frac{p}{100}$。

顺带认识它的弟弟千分号 ‰："每一千"，$\frac{p}{1000}$，人口统计里常见；逻辑与 % 完全相同，只是基准更大。

## 4. 分步例题

**例 1**：$45\%$ 化小数。
1. 去掉 % 号；
2. 除以 100：$45\div 100=0.45$。

**例 2**：$0.06$ 化百分数。
1. 乘 100：$6$；
2. 补 %：$6\%$。

**例 3**：$\frac{3}{4}$ 化百分数。
1. 化小数：$3\div 4=0.75$；
2. 乘 100 补 %：$75\%$。

**例 4**：求 80 的 45%。
1. "的"变乘号：$80\times\frac{45}{100}$；
2. 先约后乘：$\frac{80\times 45}{100}=\frac{3600}{100}=36$。

## 5. 动手实验

### 实验 1（viz + 抽查）：三角互化抽查

先用分数盘把三种写法放在同一只仪表上：拖动圆盘边缘的蓝点或下方滑杆，左侧扇形连续变化，右侧同步给出分数、小数和百分数三种读数。

```viz
{ "type": "fraction", "title": "分数 ↔ 小数 ↔ 百分数", "value": [3, 4] }
```

```python title="互化就是乘除 100"
print(45 / 100)                    # 百分数 -> 小数：除以 100
print(0.06 * 100)                  # 小数 -> 百分数：乘 100
frac_num = 3                       # 分数的分子
frac_den = 4                       # 分数的分母
percent_value = frac_num / frac_den * 100   # 分数 -> 百分数：先除再乘
print(f"{frac_num}/{frac_den} 即 {percent_value}%")

people = 240                       # 整除登场：人数不能是小数
bus_pct = 45                       # 坐公交的占 45%
bus_count = people * bus_pct // 100  # // 是整除：只留商、丢掉余数
print(f"坐公交的有 {bus_count} 人")
```

最后一行的 `//` 是老朋友回锅——第 1 章讲带余除法时它就正式登场过。$240\times 45\div 100=108$ 整好除尽时它和 `/` 结果一样，但保证输出整数——数人头的场合就该用它。

### 实验 2：占比条形图（plt.barh 首秀）

调查全班上学方式，用横向条形图把占比摆出来：

```python title="四种上学方式的占比条形图"
import matplotlib.pyplot as plt    # 导入画图库并起短名 plt

ways = ["walk", "bus", "car", "bike"]      # 方式名（图内文字用英文避免字体问题）
percents = [45, 30, 15, 10]                # 各方式占比（单位 %）

plt.barh(ways, percents, color="steelblue")  # barh：横向条形图，第一参数是类别、第二参数是长度
plt.xlabel("percent (%)")                  # 横轴标签：百分比刻度
plt.title("how students get to school")    # 图题
plt.grid(True, axis="x")                   # axis="x"：只画竖向网格线方便对刻度读数
```

四条横杠按长短排队，45% 与 10% 的悬殊一目了然——这正是百分数的使命：**把不可比的量放到同一把尺上**。试着改数据重跑，比如把 bus 提到 40 看图怎么变。

把 d 从九五折一路拧到五折：橙线岿然不动，蓝线越趴越低——但它始终是一条**过原点的直线**。打折没有改变正比例的身份（15 课的老朋友），折扣率就是它的斜率。顺手戳破误区二：七折对应斜率 0.7；谁要是按"乘 7"来算，蓝线立刻窜出天际。

### 快问快答

```quiz
0.6 化成百分数是？
- 0.6%
- 6%
- 60% [*]
? 小数化百分数要乘 100 再补 %：0.6 × 100 = 60。选 6% 的人是忘了乘满 100，选 0.6% 的是压根没动。
```

:::warning[常见误区]

**误区一**："连续涨 10% 两次等于涨 20%。"
基数变了：100 元涨 10% 变 110，再涨 10% 是在 110 上涨，得 121——总共涨了 21%。百分数相加只在**同一基数**下才有意义。

**误区二**："打七折就是乘 7。"
"折"说的是保留原价的比例：七折 $=70\%=0.7$ 倍。乘 7 会得到七倍的账单，老板狂喜。

**误区三**："求百分比要背一堆公式。"
核心只有一句：$p\%=\frac{p}{100}$，且"的"就是乘号。"80 的 45%"逐字翻译即 $80\times\frac{45}{100}$——公式恐惧症到此为止。

:::

## 6. 练习

**练习 1**：求 80 的 45%。下面的代码能跑但输出 36.0——多出的 .0 在"人数、件数"这类场景很扎眼。请改成用整除 // 让输出变成干净的 36：

```exercise
# @title: 练习：80 的 45%
# @check: 36
# @hint: "的"翻译成乘号；把最后的 / 100 换成整除 //，浮点就消失了。
print(80 * 45 / 100)
```

<details>
<summary>点开查看逐步解答</summary>

```python
print(80 * 45 // 100)   # 3600 // 100 = 36
```

`//` 丢掉的是余数部分；本题恰好整除所以无损。若结果真有余数（如 82 的 45%），先想清楚业务上该舍还是入，再用 round 收尾。
</details>

**练习 2**：一件外套原价 320 元，双十一降价 25%，又在此基础上返现 10%。最终价格是多少？

<details>
<summary>点开查看逐步解答</summary>

第一次：$320\times(1-0.25)=240$ 元；第二次基数变成 240：$240\times(1-0.10)=216$ 元。两次折扣**不能合并**成 35%（误区一的现实版）：$320\times 0.65=208$ 是错误答案。
</details>

**练习 3**：某班 40 人，视力正常占 30%，轻度近视占 45%，其余为高度近视。高度近视几人？占比多少？

<details>
<summary>点开查看逐步解答</summary>

高度近视占比 $=1-30\%-45\%=25\%$；人数 $=40\times 25\div 100=10$ 人。整体看作 100%，各部分占比之和必为 100%——这是检查占比题的第一道哨卡。
</details>

## 7. 选读：为什么偏偏是 100？

<details>
<summary>选读 · 基准的选择史</summary>

"per cent"源自拉丁文 per centum（每一百）。选 100 不是数学必然而是工程妥协：太小（每十）分辨率不够，太大（每万）口算吃力，而 100 恰好够用且人人会除。利息、税率、概率播报沿用至今。更精细的场合才升级到千分号 ‰（银行日息、啤酒酒精度的近亲）与基点 bp（万分之一，金融业最爱）。基准本身可以任意约定，真正不变的是思想——**统一分母，让比较零成本**。这个思想在统计学里叫标准化，在第 9 章概率定义（频率趋近的正是 0 到 1 之间的"占比"）中你会再次遇到它。

</details>
