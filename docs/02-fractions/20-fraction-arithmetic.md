# 分数四则运算

## 1. 从一个场景开始

半个披萨加三分之一个披萨，是几个？直觉脱口而出"$\frac{2}{5}$ 个"——**错了**。半张饼加小半张饼，怎么想也该比半张多，可 $\frac{2}{5}$ 还不到 $\frac{1}{2}$！

分数的加减法里藏着一个必须先解决的小麻烦：两块饼切法不同，没法直接拼。这一课就把这个麻烦连根拔掉，顺带把乘除一次讲齐。

## 2. 直觉解释

麻烦的根源：$\frac{1}{2}$ 是把整体切 2 份取 1 份，$\frac{1}{3}$ 是切 3 份取 1 份——**份数单位不同，不能直接数**。解法朴素得可爱：把它们切成同样的份数再拼。

文字图示（都改切成 6 格）：

```
1/2 = ▓▓▓ □□□   (6 格中涂 3)
1/3 = ▓▓  □□□□  (6 格中涂 2)
和   = ▓▓▓▓▓ □  (6 格中涂 5) -> 5/6
```

涂色格从"3+2=5"，总格还是 6 → 和为 $\frac{5}{6}$。这个"统一切成同样多份"的动作，学名叫**通分**；反过来"把 $\frac{6}{8}$ 缩写成 $\frac{3}{4}$"叫**约分**。两者用的是同一张通行证：

**分数基本性质**：分子分母同乘（或同除以）一个非零的数，分数值不变。理由现成：$\frac{a\times k}{b\times k}=(a\times k)\div(b\times k)=a\div b=\frac{a}{b}$——除法两边同乘 $k$ 再相除，等于没动。

## 3. 正式定义

设分数 $\frac{a}{b},\ \frac{c}{d}$（分母非零）：

| 运算 | 规则 | 备注 |
| --- | --- | --- |
| 加减 | 先通分成同分母，分子相加减 | $\frac{a}{b}\pm\frac{c}{d}=\frac{ad\pm cb}{bd}$ |
| 乘 | 分子乘分子，分母乘分母 | $\frac{a}{b}\times\frac{c}{d}=\frac{ac}{bd}$ |
| 除 | 除以一个分数 = 乘它的**倒数** | $\frac{a}{b}\div\frac{c}{d}=\frac{a}{b}\times\frac{d}{c}$ |

**倒数**：乘积为 1 的两个数互为倒数，$\frac{c}{d}$ 的倒数是 $\frac{d}{c}$。为什么"颠倒相乘"合法：因为 $(x\div y)\times(y\div x)=1$，除以 $\frac{c}{d}$ 与乘 $\frac{d}{c}$ 是同一个动作的两面。

符号法则自动继承第 05 课：负分数照常运算，先管数字后补符号即可。

## 4. 分步例题

**例 1（加法）**：$\frac{1}{2}+\frac{1}{3}$
1. 通分：公分母取 $2\times 3=6$，得 $\frac{3}{6}+\frac{2}{6}$；
2. 分子相加：$3+2=5$；
3. 结果 $\frac{5}{6}$，已最简。

**例 2（约分）**：$\frac{12}{18}$
1. 找公共因子：6；
2. 分子分母同除以 6：$\frac{2}{3}$。
3. 约到分子分母没有公共因子为止，叫**最简分数**。

**例 3（乘法）**：$\frac{3}{4}\times\frac{2}{5}$
1. 先约后乘更省力：4 与 2 约掉一半；
2. 得 $\frac{3\times 1}{2\times 5}=\frac{3}{10}$。

**例 4（除法）**：$\frac{2}{3}\div\frac{4}{5}$
1. 乘倒数：$\frac{2}{3}\times\frac{5}{4}$；
2. 约分：2 与 4 约；
3. 得 $\frac{5}{6}$。

## 5. 动手实验

### 实验 1（viz）：在圆盘上认约分与通分

第 10 课的分数圆盘请回来当探测器：初始就是 $\frac{6}{8}$，右侧立刻报出"可约分：3 / 4"——同一个数换了件小一号的衣服。

```viz
{
  "type": "fraction",
  "value": [6, 8]
}
```

多试几组：$\frac{2}{6}$ 会报"可约分"，$\frac{5}{7}$ 则保持沉默——沉默的那些就是最简分数。再玩一次"假通分"：从 $\frac{1}{2}$ 出发，分子分母轮流各加一档（$\frac{1}{2}\to\frac{2}{4}\to\frac{3}{6}$），眼睛盯住小数读数——始终是 0.500。**值没变，只是切法变细了**；加减法敢先通分再运算，底气就在这里。

### 实验 2：用整数对精确计算

圆盘给的是手感，这一实验要的是精确。Python 的 `/` 给出的是小数近似值，会丢掉分数的精确模样。用一对整数表示分子分母，让机器按通分规则精确演算：

```python title="通分算法：分子分母分开处理"
num1, den1 = 1, 2     # 同时赋值：逗号两侧一一对应，即 1/2
num2, den2 = 1, 3     # 即 1/3

new_den = den1 * den2                 # 新分母：分母相乘（通分）
new_num = num1 * den2 + num2 * den1   # 新分子：交叉相加

print(f"{num1}/{den1} + {num2}/{den2} = {new_num}/{new_den}")
print(f"对照小数近似: {num1 / den1 + num2 / den2}")   # 0.83... 只是近似值
```

第一行输出 $\frac{5}{6}$——精确、干净；第二行的 0.8333... 是同一答案的浮点影子。**要精确意义时操作整数，要看数量级时才用小数**，这个分工贯穿全书。

### 实验 3：乘法的面积模型验证

```python title="1/2 × 1/3 为什么等于 1/6"
# 把 6 格的长条横竖各看一遍：
# 横着涂 1/2 -> 3 格；竖着再叠 1/3 -> 只剩重叠部分
overlap_num = 1 * 1          # 重叠块的"分子"
overlap_den = 2 * 3          # 整体被切成 2×3 = 6 块
print(f"{overlap_num}/{overlap_den}")

grid = []
for row in range(2):         # 2 行
    line = ""
    for col in range(3):     # 3 列
        if row == 0 and col < 1:   # 只有左上角 1 块被双重选中
            line = line + "▓ "
        else:
            line = line + "· "
    grid.append(line)

for line in grid:
    print(line)
```

6 格中只有左上角 1 格同时属于"横着的 $\frac{1}{2}$"和"竖着的 $\frac{1}{3}$"——分子乘分子、分母乘分母，就是这块重叠地的记账方式。

### 快问快答

```quiz
1/2 + 1/3 等于多少？
- 2/5
- 5/6 [*]
- 1/6
? 分子加分子、分母加分母是把"份数大小"和"切的份数"搅在一起的典型错误。正确做法：通分成 3/6 + 2/6 = 5/6。
```

:::warning[常见误区]

**误区一**："分数加法就是分子加分子、分母加分母。"
反例就在眼前：$\frac{1}{2}+\frac{1}{3}=\frac{5}{6}$ 而非 $\frac{2}{5}$。不同分母意味着不同的计数单位，必须先通分。

**误区二**："约分会改变分数的大小。"
$\frac{6}{8}$ 与 $\frac{3}{4}$ 是同一个数的两个名字。同乘同除非零数不改变除法的结果——这是基本性质担保过的。

**误区三**："除以一个分数就是把它的分子分母颠倒后相减。"
方向完全错。是**颠倒后相乘**：$\frac{2}{3}\div\frac{4}{5}=\frac{2}{3}\times\frac{5}{4}$。依据是倒数的定义，不是口诀。

:::

**练习 2**：计算 $\frac{5}{6}-\frac{1}{3}$，结果化为最简分数。

<details>
<summary>点开查看逐步解答</summary>

通分：$\frac{1}{3}=\frac{2}{6}$；相减：$\frac{5}{6}-\frac{2}{6}=\frac{3}{6}$；约分：$\frac{3}{6}=\frac{1}{2}$。**算完别忘约分**——最简分数是本站的默认交付格式。
</details>

**练习 3**：一桶水 10 升，倒出 $\frac{2}{5}$ 后又倒入剩下的 $\frac{1}{3}$，最终比开始多还是少？

<details>
<summary>点开查看逐步解答</summary>

倒出 $\frac{2}{5}$ 剩 $\frac{3}{5}$，即 6 升；倒入其 $\frac{1}{3}$ 加回 2 升 → 8 升。少了 2 升。两次操作的基数不同（先是整桶、后是剩余量）——分数乘法的"基数意识"正是下一章百分数应用题的核心陷阱。
</details>

## 7. 选读：为什么分数乘法是"分子乘分子"？

<details>
<summary>选读 · 面积模型的完整版</summary>

把整体看成一块 $b\times d$ 的方格地（共 $bd$ 小格）。$\frac{a}{b}$ 是横向上占 $a$ 条带，$\frac{c}{d}$ 是纵向上占 $c$ 条带；两者的"交集"是一块 $a\times c$ 的矩形。于是乘积占有 $\frac{a\times c}{b\times d}$ 的地面——这正是 $\frac{ac}{bd}$。除法那边：由倒数定义 $(x\times y)\div y=x$，令 $y=\frac{d}{c}$ 即得"颠倒相乘"。几何与代数在此互相印证：分数运算规则没有一条是拍脑袋规定的。

</details>
