# 分数是除法的另一种写法

## 1. 从一个场景开始

3 张披萨，4 个人平分，每人几张？算式是 $3\div 4$——在只会整数的日子里，它被判了"除不尽、无解"。

这个"无解"其实是冤案。数学家的处理方式和发明负数时如出一辙：既然老数不够用，就**发明新记号收留它**。$3\div 4$ 的答案一直都在，它的名字叫 $\dfrac{3}{4}$。

## 2. 直觉解释

**分数线就是躺平的除号。** 把 $3\div 4$ 竖着写，除号变成一条横线，就成了 $\frac{3}{4}$——同一个动作的两种拼写。

在数轴上看（文字图示）：把 0 到 1 这一段切成 **4 等份**，每一份就是 $\frac{1}{4}$：

```
0 ──⊥────⊥────⊥────── 1
   1/4  2/4  3/4   (每格 = 1/4)
```

$3\div 4$ 的落点：从 0 出发向右走 3 个"四分之一格"，停在第 3 条刻度上——那个位置就叫 $\frac{3}{4}$。

再用披萨验证一遍：3 张各切 4 块，共 12 块；4 人平分，每人 3 块；每块是 $\frac{1}{4}$ 张 → 每人得到 $\frac{3}{4}$ 张。两条路都指向同一个答案。

## 3. 正式定义

$$\frac{a}{b} := a \div b \qquad (b \neq 0)$$

逐项说明：

| 名称 | 位置 | 含义 |
| --- | --- | --- |
| 分子 | 横线上方 | 被除数：取几份 |
| 分母 | 横线下方 | 除数：切成几份（"母"亲决定切法）|
| 分数线 | 中间 | 除号的竖版 |

为什么 $b$ 不能是 0？这不是禁令而是事实陈述：若 $\frac{3}{0}$ 有意义，就必须存在一个数 $c$ 使 $c\times 0=3$；但任何数乘 0 都是 0，这样的 $c$ 不存在。**0 作分母的分数没有定义**。

另外分数不挑大小：$\frac{8}{4}=2$ 说明整数也能穿分数的外衣；$\frac{7}{2}=3.5$ 说明分数完全可以比 1 大。

## 4. 分步例题

**例 1**：把 $1\div 3$ 写成分数。
1. 分子放被除数：1；
2. 分母放除数：3；
3. 得 $\frac{1}{3}$。

**例 2**：$\frac{7}{2}$ 到底有多大？
1. 写回除法：$7\div 2$；
2. 带余除法（第 1 章）：$7=2\times 3+1$，商 3 余 1；
3. 余下的 1 继续被 2 切：$\frac{7}{2}=3+\frac{1}{2}$，读作"三又二分之一"。

**例 3**：$\frac{3}{4}$ 和 $\frac{3}{5}$ 谁大？
1. 分子相同：都是取 3 份；
2. 分母大的切得更碎：$\frac{1}{5}<\frac{1}{4}$；
3. 同样拿 3 份，碎块拼起来更小 → $\frac{3}{4}>\frac{3}{5}$。

## 5. 动手实验

### 实验 1（viz）：发糖机僵局——整颗糖不许切

第 1 章的发糖机又来了，但这回故意使坏：默认装的是 3 颗糖、4 个人。盯住结论行——$3 = 4\times 0 + 3$：每人 **0** 颗，剩 3 颗。你也可以把糖果数拖来拖去，但只要它比人数少，商就永远是 0。

```viz
{
  "type": "divisionshare",
  "title": "发糖机：整颗的糖，不许切开",
  "total": 3,
  "people": 4
}
```

这就是开头场景里那桩"无解"冤案的现场：**整数除法在这里彻底哑火**——整颗发等于没发，剩下的糖又因为"不许切"卡在原地。解开死结只需要一步：允许把糖**切开再分**。下一实验的分数圆盘，就是那把刀。

### 实验 2（viz）：分数圆盘——那把刀

发糖机卡在"整颗不许切"，这把刀现在交到你手上：抓住圆盘边缘的蓝色圆点绕一圈（或拖下方滑杆），分子分母随你改，右侧同步刷新约分结果、小数和百分数三种写法。

```viz
{
  "type": "fraction",
  "value": [3, 4]
}
```

先把分子拖到 2，看 $\frac{2}{4}$ 自动约成 $\frac{1}{2}$；再拖回 3 回到本课主角 $\frac{3}{4}$。要是把分子拖满一整圈变成 $\frac{4}{4}$，它会告诉你"恰好一个整体"——分数记法连整数都收留（第 3 节说过）。

### 实验 3：切披萨模拟——块号列表

刀挥完了，回代码里精确记账：把 3 张披萨各切 4 块并编号 $1..12$，轮流发给 4 个人，打印每人拿到的块号：

```python title="切块编号：每人应得的块号列表"
slices_per_pizza = 4                  # 每张切 4 块
people = 4                            # 分给 4 个人
total = 3 * slices_per_pizza          # 一共 12 块

for person in range(1, people + 1):   # person 依次取 1..4
    my_blocks = []
    for block in range(person, total + 1, people):  # range 第三参数=步长：隔 people 个取一个
        my_blocks.append(block)
    print(f"{person} 号拿到 {len(my_blocks)} 块 -> 块号 {my_blocks}")

print(3 / 4)    # 除号 / 在 Python 里直接给出分数值（30 课细讲小数）
print(7 / 2)    # 整除不了的除法照样有答案
```

每人恰好 3 块，而每块是 $\frac{1}{4}$ 张——块号列表就是"$3\div 4=\frac{3}{4}$"的实物证据。最后两行顺便看到：Python 里分数线真的就是除号。

### 实验 4：数轴等分的文字图示

```python title="把 [0,1] 切 n 等份的刻度尺"
n = 4                                  # 试改成 3、5、8 再跑
scale = ""
for i in range(n):
    scale = scale + "----|"
print("0 " + scale + " 1")

marks = []
for i in range(1, n + 1):
    marks.append(f"{i}/{n}")
print("  " + "   ".join(marks))        # join：把列表里的字符串用指定符号粘起来
```

`join` 是新面孔：它把一个字符串列表按你给的连接符缝成一条。改 `n` 重跑，你会发现不管怎么切，最后一个刻度永远写作 `n/n`——也就是 1 自己。

### 快问快答

```quiz
关于 3/4 和 3÷4 的关系，下面哪个说法对？
- 3/4 是一种新的数，和除法无关
- 3/4 就是 3÷4 的另一种写法 [*]
- 分数只能表示比 1 小的数
? 分数线就是躺平的除号，两者是同一动作的两种拼写。而且分数能表示任意大小：7/2 = 3.5 比 1 大得多。
```

:::warning[常见误区]

**误区一**："除不尽 = 没有答案。"
整数范围内确实没有，但"没有整数答案"和"没有答案"是两回事。分数正是为这些除法准备的答案。

**误区二**："分数都是半个、三分之一个这种比 1 小的数。"
$\frac{7}{2}=3.5$ 也是分数。分子大于分母的分数（假分数）只是"切得碎的整数"，毫无特殊之处。

**误区三**："0 可以当分母，反正就是个数。"
0 作分母要求"某个数乘 0 等于非零数"，这种数不存在。不是不许写，是写了也不指任何东西。

:::

**练习 2**：比较 $\frac{5}{6}$ 与 $\frac{5}{7}$ 的大小，并说明理由。

<details>
<summary>点开查看逐步解答</summary>

分子相同（都取 5 份），分母大的切得更碎，所以 $\frac{5}{6}>\frac{5}{7}$。口诀：**同分子比分母，分母大反而小**——与同分母时的直觉正好相反，小心别串线。
</details>

**练习 3**：$\frac{9}{3}$、$\frac{12}{4}$、$\frac{100}{25}$ 各等于多少？它们说明分数的哪类特例？

<details>
<summary>点开查看逐步解答</summary>

分别是 3、3、4。当除法本来就能整除时，分数自动退化成整数——分数记法是除法的超集，老结果一个都不丢。这和"负数扩张后自然数运算照旧"是同一条设计原则。
</details>

## 7. 选读：带分数与假分数是一枚硬币的两面

<details>
<summary>选读 · 商余分离视角</summary>

第 1 章的带余除法说 $a=b\times q+r$（$r<b$）。两边同除以 $b$，得 $\frac{a}{b}=q+\frac{r}{b}$：商 $q$ 变成整数部分，余数 $r$ 变成真分数尾巴。所以"三又二分之一"与 $\frac{7}{2}$ 从来不用换算技巧，它们就是同一次除法的两种记账方式：一种把商和余数分开写，一种合并成一个分数。以后嫌带分数别扭的话，随时可以全部化回假分数处理——本章后续课程就是这么干的。

</details>
