# 小数与十进制

## 1. 从一个场景开始

电子秤显示 1.35 千克。小数点后面那两位是什么意思？为什么往右挪一位就"小十倍"？更实际的问题：计算器吐出 `0.8333333333`，可你只想留两位——**四舍五入**到底是谁在替你做、怎么做的？

这一课拆开十进制记数法的下半场，并当场见证一个新工具的诞生：`round()`。

## 2. 直觉解释

第 1 章说过位值系统：同一个数字 3，站在十位是 30，站在百位是 300。这套系统的精髓是**位置决定大小，相邻位差十倍**。

小数点只是把这条规则向右延续：

```
百位   十位  个位 . 十分位   百分位
100    10    1  | 1/10      1/10 × 1/10
```

所以 $3.14 = 3 + \frac{1}{10} + \frac{4}{100}$：向左逐位乘 10，过点之后向右逐位除以 10。小数不是新数——它是**分母恰为 10 的幂的分数的速记法**：$0.37=\frac{37}{100}$。

而一般分数（如 $\frac{3}{8}$）想穿小数外衣，直接做除法即可；有的分数永远除不尽（如 $\frac{1}{3}$），那就得请出本课第二主角：四舍五入。

## 3. 正式定义

**十进制小数**：形如 $\displaystyle a_0.a_1a_2\cdots a_n$ 的记数法，值为

$$a_0+\frac{a_1}{10}+\frac{a_2}{100}+\cdots+\frac{a_n}{10^n}$$

**分数化小数**两条路：

1. 化分母为 10 的幂：$\frac{3}{5}=\frac{6}{10}=0.6$；
2. 直接做除法：$\frac{3}{8}=3\div 8=0.375$。

除不尽时分两种命运：从小数点后某处开始**无限循环**（$\frac{1}{3}=0.333\cdots$），或永不循环（这类数叫无理数，第 3 章登场）。

**四舍五入**：保留到某一位时，看它右边第一位——小于 5 全舍，大于等于 5 进一。

**round(x)**：Python 内置的四舍五入工具。`round(x)` 取整；`round(x, n)` 保留 n 位小数。

## 4. 分步例题

**例 1**：把 $\frac{37}{100}$ 写成小数。
1. 分母已是 $100=10^2$；
2. 分子占两个小数位 → $0.37$。

**例 2**：手工四舍五入 2.71（保留一位小数）。
1. 要保留的是十分位的 7；
2. 看它右边的百分位：是 1；
3. $1<5$ → 舍去 → $2.7$。

**例 3**：手工四舍五入 3.6（取整）。
1. 看十分位：6；
2. $6\ge 5$ → 个位进一 → $4$。

## 5. 动手实验

### 实验 1：分数换小数，以及除不尽的那位常客

拖一拖分数盘，看它的"小数化身"。分母恰好是 10 的幂时，小数有限；换成 3、7 这类分母，尾巴就开始无限循环：

```viz
{ "type": "fraction", "title": "分数 ↔ 小数", "value": [3, 4] }
```


```python title="分数 -> 小数的两条路"
print(37 / 100)     # 直接除：Python 的 / 天生输出小数
print(3 / 5)
print(3 / 8)
print(1 / 3)        # 除不尽！看看 Python 给了什么
```

最后一行打出 `0.3333333333333333`——十几个 3 之后戛然而止。这不是循环小数的真身，只是浮点数**装不下就截断**了。屏幕上的小数永远是近似值，这个诚实的细节选读部分再展开。

### 实验 2：位值台阶——每往右一站，缩小十倍

第 2 节说"过点之后逐位除以 10"。拧动滑杆 d，让 Python 把前 d 个小数位的权重一级级打印出来：

```python title="小数位权重：一条向右下延伸的台阶"
# sliders: d=3 [1:6:1]

weight = 1                  # 个位的权重是 1
total = 0                   # 累加器清零：加法的"白做起点"
for k in range(1, d + 1):   # k 依次取 1..d：走过十分位、百分位……
    weight = weight / 10    # 每往右挪一站，权重就除以 10
    total = total + weight  # 把这一级的权重存进累加器
    print(f"第 {k} 位权重 = {weight}，累计 = {total}")
```

d=3 时累计停在 0.111。把滑杆拖满：0.111111——越来越贴近那个写不完的循环小数 $0.111\cdots=\frac{1}{9}$，而每一级新增的贡献只有上一位的十分之一。**有限小数只是无限台阶上截下的前几级**；既然常常截不断，就得学"截到合适位数"的手艺——这正是下一节四舍五入要办的事。

### 实验 3：round() 的出生证明

没有 round() 的日子里，四舍五入要靠手写分支。以"对 3.6 这类一位小数取整"为例：

```python title="手工版四舍五入：规则写成分支"
x = 3.6
if x >= 3.5:          # 十分位 >= 5，说明已越过 3.5 的中界线
    result = 4        # 进一
else:
    result = 3        # 舍去
print(f"{x} 四舍五入 -> {result}")

x = 3.4               # 换个数再走一遍流程
if x >= 3.5:
    result = 4
else:
    result = 3
print(f"{x} 四舍五入 -> {result}")
```

每换一个数就要抄一遍分支，太苦了。这种高频套路正是内置函数的诞生土壤——Python 把它收编为 `round()`：

```python title="round 登场：一行顶一段"
print(round(3.6))       # 不带第二个参数：取整
print(round(3.4))
print(round(2.71, 1))   # 第二个参数 n：保留 n 位小数
print(round(158, -1))   # n 为负：往十位、百位上舍入
```

对比两段代码：逻辑一模一样，代码量天差地别。这就是工具的价值——不是变魔术，是把你已经会的东西打包。

### 快问快答

```quiz
1/3 写成小数是？
- 0.3
- 0.33…（无限循环，写不完）[*]
- 除不尽所以没有小数写法
? 1/3 = 0.333…，3 无限重复。任何有限位数的小数都只是它的近似。Python 打印的一串 3 是浮点截断的结果，不是终点。
```

:::warning[常见误区]

**误区一**："0.333… 总有一天会停，或最后补个别的数字。"
省略号的含义就是**永远继续**。$\frac{1}{3}$ 不存在有限小数写法，这是除法竖式一步步逼出来的事实。

**误区二**："小数比整数低一等，是'不完整'的数。"
0.5 与 $\frac{1}{2}$ 是同一个数的两种拼写，与"完整与否"无关。位值系统里它们平起平坐，只是站的位置不同。

**误区三**："round 遇到恰好 .5 时一定进位。"
Python 的 round 对正好卡在中间的数会取**最近的偶数**：`round(2.5)` 是 2，`round(3.5)` 是 4。日常口诀"五入"只对大多数情形成立，精确场景要查文档。

:::

## 6. 练习

**练习 1**：让 Python 替你完成四舍五入。下面的代码能跑但什么都没做——请用 round 改写两行，使输出变成 4 和 2.7：

```exercise
# @title: 练习：让 round 替你四舍五入
# @check: 4
# @check: 2.7
# @hint: round(3.6) 直接取整；round(2.71, 1) 的第二个参数表示保留 1 位小数。
print(3.6)
print(2.71)
```

<details>
<summary>点开查看逐步解答</summary>

```python
print(round(3.6))      # -> 4
print(round(2.71, 1))  # -> 2.7
```

第一行验证了手工例 3；第二行验证了手工例 2。机器接管的正是你刚才手推的那套规则。
</details>

**练习 2**：把 $\frac{7}{20}$ 化成小数（提示：想办法让分母变成 100）。

<details>
<summary>点开查看逐步解答</summary>

分子分母同乘 5：$\frac{35}{100}=0.35$。也可以直接 $7\div 20=0.35$ 验算。两条路答案一致——分数与小数本是一体。
</details>

**练习 3**：打印 $\frac{1}{6}$ 与 $\frac{2}{3}$ 的小数形式，判断哪个是有限小数、哪个是无限循环。

<details>
<summary>点开查看逐步解答</summary>

```python
print(1 / 6)   # 0.16666... 循环节 6
print(2 / 3)   # 0.66666... 循环节 6
```

两者都除不尽，都是无限循环小数。规律预告：分母只含因子 2 和 5 的最简分数才能化成有限小数（因为 10 = 2×5）；其余都会进入循环。
</details>

## 7. 选读：0.1 + 0.2 为什么不等于 0.3？

<details>
<summary>选读 · 浮点数的第一课诚实</summary>

运行 `print(0.1 + 0.2)`，你会看到 `0.30000000000000004`。原因：计算机内部用二进制存数，而 0.1 在二进制下是无限循环小数（类似十进制的 $\frac{1}{3}$），存储时必然截断，误差就在相加时露出了马脚。这不是 Python 的 bug，是所有二进制浮点系统的共性。对策有二：需要精确分数意义时用整数运算（上一课的做法）；需要展示时用 round 控制位数。二进制世界的更多细节，等你学到进制转换时回头再看会更透。

</details>
