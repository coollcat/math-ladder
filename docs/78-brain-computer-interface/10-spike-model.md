# 神经元为什么放电：膜电位与积分点火

## 1. 从一个场景开始

一台脑机接口的电极阵列贴在运动皮层上，采集到的信号不是平滑的曲线，而是一串**全同的尖峰**：每一次放电的形状都一样，高度一样，宽度一样，像被同一个模子刻出来的。既然每个脉冲长得一模一样，那么"向左"和"向右"的区别，就只可能藏在**什么时候放、放多密**里面。

可要读懂这串密码，先得回答一个更靠前的问题：神经元**为什么**会放电？它凭什么在某个时刻突然"啪"一下，而不是一直安静地待着？

## 2. 直觉解释

把神经元想成一只**漏水的桶**。电流从顶上灌进来（来自其他神经元），桶底有个洞一直在漏（离子通道的漏电流）。水位就是**膜电位**。

- 灌得慢，漏得掉：水位停在某个高度不动，桶永远不满——神经元**一声不吭**；
- 灌得快：水位一路涨上去，涨到桶口那条线（**阈值**），"啪"，桶被倒空（**放电**），水位掉回桶底，重新开始涨。

于是放电这件事被拆成了两个可算的量：**涨到阈值的这段时间**（决定放电多密），以及**灌多快才涨得上去**（决定它到底响不响）。这就是本课全部的内容。

## 3. 正式定义

漏电积分点火模型（leaky integrate-and-fire，LIF）把上面那只桶写成一个一阶线性微分方程：

$$C\frac{dV}{dt} = -g_L\left(V - E_L\right) + I$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $V$ | 膜电位 | 状态变量，单位 mV |
| $C$ | 膜电容 | 攒电荷的能力，本节取 2 nF |
| $g_L$ | 漏电导 | 桶底洞的大小，本节取 0.1 μS |
| $E_L$ | 静息电位 | 没有输入时水位停的地方，$-65$ mV |
| $I$ | 注入电流 | 外界灌进来的电流，单位 nA |
| $V_{th}$ | 阈值 | 水位上限线，$-50$ mV |
| $V_{reset}$ | 重置电位 | 放电后水位掉回的位置，取与 $E_L$ 相同，$-65$ mV |
| $\tau_m = C/g_L$ | 膜时间常数 | 水位的"反应快慢"，本节 20 ms |
| $R = 1/g_L$ | 膜电阻 | 电流能顶起多高的水位，本节 10 MΩ |

**第一个结论（稳态电位）**：令 $dV/dt = 0$，得到水位最终会停的地方

$$V_\infty = E_L + R\,I$$

若 $V_\infty \le V_{th}$，水位永远够不到桶口——神经元**静息**。刚好够到的那一点电流叫**雷奥巴斯电流**：

$$I_{rheo} = \frac{V_{th} - E_L}{R}$$

**第二个结论（放电间期）**：解上面的微分方程，从 $V_{reset}$ 出发、以时间常数 $\tau_m$ 指数逼近 $V_\infty$：

$$V(t) = V_\infty + \left(V_{reset} - V_\infty\right)e^{-t/\tau_m}$$

令 $V(t) = V_{th}$ 解出两次放电之间的间隔（ISI），再过一遍就是**发放率**：

$$\Delta t = \tau_m \ln\frac{V_\infty - V_{reset}}{V_\infty - V_{th}}, \qquad r = \frac{1}{\Delta t}$$

把 $r$ 画成 $I$ 的函数，就是 **f–I 曲线**：$I$ 一过雷奥巴斯就从 0 跳起来，先陡后缓，最后被一条直线压住。

## 4. 分步例题

**例**：$\tau_m = 20$ ms、$R = 10$ MΩ、$E_L = V_{reset} = -65$ mV、$V_{th} = -50$ mV。问 $I = 2$ nA 时的发放率。

**第 1 步 · 算雷奥巴斯**：$I_{rheo} = 15\ \text{mV} / 10\ \text{M}\Omega = 1.5$ nA。低于 1.5 nA 一律不放电。

**第 2 步 · 算稳态电位**：$I = 2$ nA 时 $V_\infty = -65 + 10 \times 2 = -45$ mV。$-45 \gt -50$，过了阈值。

**第 3 步 · 算放电间期**：

$$\Delta t = 20 \times \ln\frac{-45 - (-65)}{-45 - (-50)} = 20\ln\frac{20}{5} = 20\ln 4 = 27.73\ \text{ms}$$

**第 4 步 · 换成发放率**：$r = 1000/27.73 = 36.07$ Hz。

**第 5 步 · 换个角度看**：$C = \tau_m/R = 2$ nF，把水位从 $-65$ 抬到 $-50$ 要充的电荷是 $C \times 15\ \text{mV} = 30$ pC。所以电流一大，发放率就逼近

$$r \approx \frac{I}{C\left(V_{th} - E_L\right)}$$

$I = 3$ nA 时这条渐近线给 100 Hz，而精确值是 72.13 Hz——渐近线只是上限，不是真值。

## 5. 动手实验

### 实验 1（lab）：拖电流，看它从沉默到放电

```lab
{
  "type": "bci-integrate-fire",
  "title": "上格是膜电位轨迹与脉冲标记，下格是 f–I 曲线；拖动画布或滑块改变注入电流",
  "I": 2.0,
  "tau": 20,
  "dV": 15
}
```

- 把电流拖到 **1.2 nA**：橙色虚线是稳态电位 $V_\infty = -53$ mV，稳稳压在红色阈值线下——轨迹是一条平掉的指数曲线，**一个脉冲都不出**；
- 拖到 **2 nA**：$V_\infty$ 升到 $-45$ mV，轨迹顶着阈值反复爬升、被重置，紫色脉冲标记等距排列，读数给出 27.73 ms / 36.07 Hz；
- 继续拖大：脉冲越来越密，f–I 曲线上的红点沿着曲线往右爬，灰色虚线（渐近线）从上方逼近它；
- 把**阈值**拖高（$\Delta V$ 变大）：雷奥巴斯竖线右移，f–I 曲线整体右移且压低——阈值越高越难放电，这条竖线就是"难"的刻度。

### 实验 2（python）：解析解与欧拉法互相对账

```python
import math                       # 标准库：对数

tau, R = 20.0, 10.0               # 膜时间常数 ms、膜电阻 MΩ
EL, Vth, I = -65.0, -50.0, 2.0    # 静息 mV、阈值 mV、注入电流 nA

# 解析解：从重置电位指数逼近稳态，解出跨过阈值的时刻
Vinf = EL + R * I
isi_analytic = tau * math.log((Vinf - EL) / (Vinf - Vth))
print(f"解析 ISI = {isi_analytic:.4f} ms，发放率 = {1000 / isi_analytic:.4f} Hz")

# 数值解：欧拉法直接积分微分方程，让膜电位自己撞上阈值
dt, V, spikes, t = 0.02, EL, [], 0.0
for _ in range(100000):           # 0.02 ms × 100000 = 2 s，够放七十多个脉冲
    V += dt * (-(V - EL) + R * I) / tau     # C dV/dt = -gL(V-EL) + I 的欧拉步
    t += dt
    if V >= Vth:                  # 撞上阈值：记录时刻并重置
        spikes.append(t)
        V = EL
gaps = [spikes[i + 1] - spikes[i] for i in range(len(spikes) - 1)]
print(f"数值 ISI = {sum(gaps) / len(gaps):.4f} ms，共 {len(spikes)} 个脉冲")
```

两种算法给出同一个数（27.7259 ms 与 27.7200 ms），差在千分之几——那是欧拉法用 0.02 ms 步长积分的离散误差。把 `dt` 改小一个量级，两条曲线会贴得更近。

### 快问快答

```quiz
注入电流刚好等于雷奥巴斯电流时，神经元会怎样？
- 以极低但稳定的频率持续放电
- 永远停在阈值下方，一个脉冲都不放 [*]
- 立刻进入高频放电
? 雷奥巴斯是"刚好够到、但永远到不了"的临界电流：V∞ 恰好等于 Vth，指数逼近只在无穷远处取等号，所以有限时间内不放电。
```

::::warning[常见误区]

**误区一**："只要有电流进去，神经元就会放电。"
你以为输入就是放电的开关——真正的开关是 $V_\infty$ 与 $V_{th}$ 的大小关系。$I = 1.2$ nA 时 $V_\infty = -53$ mV，指数曲线只会无限逼近它，**永远够不到 $-50$ mV**，于是一个脉冲都不出。"电流不够"不是"放电慢"，而是"根本不放电"，中间隔着一条雷奥巴斯的硬边界。

**误区二**："膜电位一到阈值就自动掉回静息，这是神经元的性质。"
你以为重置是生理事实——它是 LIF 的**建模假设**，是我们为了换到解析公式而人为加的一条规则。真实脉冲有 1~2 ms 的形状，之后还有几毫秒的不应期（选读里的 Hodgkin–Huxley 方程能自己长出这些）。把模型当本体，是这一课最容易踩的坑。

**误区三**："注入电流加倍，发放率就加倍。"
你以为 f–I 是直线——它一过雷奥巴斯就陡升，随后被 $I/\left(C\Delta V\right)$ 这条渐近线从上方压住。$I$ 从 2 nA 涨到 3 nA（+50%），发放率只从 36.07 Hz 涨到 72.13 Hz，而渐近线上限是 100 Hz：**加倍的电流换不来加倍的脉冲**，中间那段对数曲线才是真实形状。

::::

## 6. 练习

**练习 1**：算 $I = 2$ nA 时的放电间期与发放率。下面的代码把对数里的分子分母写反了，于是算出**负的**时间与负的频率：

```exercise
# @title: 练习：算放电间期与发放率
# @check: 27.73 ms
# @check: 36.07 Hz
# @hint: 指数从 V_reset 涨向 V∞，比值应该是「离阈值的距离」与「离重置电位的距离」相除：(V∞ − V_reset) / (V∞ − V_th)。
import math                       # 标准库：对数与指数
tau = 20.0        # 膜时间常数（ms）
R = 10.0          # 膜电阻（MΩ）
EL = -65.0        # 静息电位（mV），也是放电后的重置电位
Vth = -50.0       # 发放阈值（mV）
I = 2.0           # 注入电流（nA）

Vinf = EL + R * I                                     # 稳态电位
isi = tau * math.log((Vinf - Vth) / (Vinf - EL))      # ← 问题在这：分子分母颠倒了
print(f"{isi:.2f} ms")
print(f"{1000 / isi:.2f} Hz")
```

**练习 2**：回答三个问题。(a) $I = 1.2$ nA 时稳态电位是多少，为什么不放电？(b) 若把阈值从 $-50$ mV 抬到 $-45$ mV，雷奥巴斯变成多少？(c) 真实神经元的"放电后重置"和这个模型差在哪？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $V_\infty = -65 + 10 \times 1.2 = -53$ mV，**低于阈值 $-50$ mV**。指数曲线只会无限逼近 $-53$，永远够不到 $-50$，所以轨迹平掉、零脉冲；
2. (b) $I_{rheo} = \left(-45 - (-65)\right) / 10 = 2.0$ nA。阈值抬高 5 mV，雷奥巴斯从 1.5 nA 涨到 2.0 nA——**灵敏度直接掉了四分之一**；
3. (c) LIF 把放电当成"瞬间重置"，是一句**建模假设**，不是生物事实。真实神经元（Hodgkin–Huxley 模型）的脉冲有形状：钠通道打开让电位冲到 $+30$ mV 左右，钾通道随后把它压回去，还留下几毫秒的**不应期**。LIF 忽略了这些，换来的是"一个线性方程就能算出发放率"。作为解码器的前端模型，这笔买卖很划算；作为膜电位的定量描述，它不够用。

**为什么这条式子长这样**：$V(t)$ 距离 $V_\infty$ 的差每过 $\tau_m$ 就缩小到 $1/e$。所以"从 $V_{reset}$ 爬到 $V_{th}$"要走的不是线性距离，而是**对数距离**——这也是 f–I 曲线一开始陡、后来缓的根源（第 5 步的渐近线只是它的尾巴）。

</details>

## 7. 选读：从 LIF 到 Hodgkin–Huxley

<details>
<summary>选读 · 一个线性方程能扛多远</summary>

LIF 只有一条方程、一个状态变量，却能复现神经元的两个最基本的实验事实：**阈值**与**不应期**（只要在重置后加一段"锁死时间"）。它的缺点是所有非线性都被塞进了"到阈值就重置"这一条人造规则里。

Hodgkin 与 Huxley 在 1952 年用乌贼巨轴突给出了另一条路：不假设阈值，而是把膜电导写成**电压门控**的钠、钾通道：

$$C\frac{dV}{dt} = -\bar{g}_{Na}m^3h\left(V - E_{Na}\right) - \bar{g}_K n^4\left(V - E_K\right) - g_L\left(V - E_L\right) + I$$

其中 $m, h, n$ 各自满足一条一阶方程 $\dot{x} = \alpha_x(V)(1 - x) - \beta_x(V)x$——四条耦合的非线性常微分方程。这套方程能**自己长出**脉冲的形状、阈值和不应期，代价是没有解析解，只能数值积分（[ Euler 与 RK ](../22-ode-dynamics/60-euler-runge-kutta.md) 那一套正好用得上）。

对脑机接口来说，取舍很清楚：解码器需要的是"给定输入，脉冲什么时候来"的**快**模型，LIF 的解析 ISI 公式正是为此而生；而研究药物、通道病变这类问题时，才需要 HH 的细节。两条路都从同一个守恒式出发，差别只在漏电流那一项写成线性还是非线性。

</details>
