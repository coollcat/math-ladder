# 神经解码 I：贝叶斯解码与群体向量

## 1. 从一个场景开始

受试者想把手往**右前方 30°** 推。皮层里有一百多个神经元同时放电，每个都按自己的偏好方向"投票"。脑机接口要在几十毫秒内从这一百多串计数里读出一个角度，再把光标推出去。

问题是：单个神经元的放电是随机的（上一课的泊松抖动），100 个神经元就是 100 个独立的随机数。凭什么从一堆噪声里读出一个准确的方向？有两个思路：一个讲概率（贝叶斯），一个讲几何（群体向量）。它们其实是同一件事的两个侧面。

## 2. 直觉解释

**贝叶斯的路子**：把每个候选方向都摆出来，逐个问"如果受试者想的是这个方向，那我刚才数到的这串计数有多大概率出现？"——这个概率叫**似然**。哪个方向的似然最大，就猜哪个。这不需要任何新数学，就是上一课的泊松公式连乘。

**群体向量的路子**：把每个神经元想成一支**箭**。它有自己的偏好方向（箭头的指向），这次放了几个脉冲（箭头的长度）。把所有箭矢**加起来**，合力的方向就是答案。

为什么这两个办法会给出同一个答案？因为合力的方向恰好是"哪一种方向最能解释这批计数"的一种线性近似。下面我们会看到：**四个偏好方向均匀铺开的余弦调谐神经元，群体向量在数学上不偏不倚地指向真值**——这不是巧合，是可以一行一行算出来的。

## 3. 正式定义

### 贝叶斯解码

$N$ 个神经元、调谐曲线 $f_i(\theta)$、观察窗 $T$、观测到的计数 $k_1, \dots, k_N$。假设各神经元条件独立，似然是泊松概率的连乘：

$$P(k_1,\dots,k_N \mid \theta) = \prod_{i=1}^{N} e^{-Tf_i(\theta)}\frac{\left(Tf_i(\theta)\right)^{k_i}}{k_i!}$$

均匀先验下，后验正比于似然，归一化即可。取对数更方便（把连乘变成求和，也避开下溢）：

$$\mathcal{L}(\theta) = \sum_{i=1}^{N}\left[k_i\ln f_i(\theta) - T f_i(\theta)\right] + \text{常数}$$

对连续 $\theta$ 可以用网格近似：在 $0°\sim360°$ 上撒一圈候选，逐个算 $\mathcal{L}$，取最大的那个就是**最大似然估计**（ML）。

### 群体向量

每个神经元 $i$ 有偏好方向 $\varphi_i$，方向向量 $\mathbf{u}_i = \left(\cos\varphi_i, \sin\varphi_i\right)$。**先把基线扣掉再投票**：

$$\mathbf{v} = \sum_{i=1}^{N}\left(k_i - b\,T\right)\mathbf{u}_i, \qquad \hat\theta = \operatorname{atan2}\!\left(v_y, v_x\right)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $k_i$ | 计数 | 第 $i$ 个神经元在窗内放了几个脉冲 |
| $b$ | 基线发放率 | 与方向无关的那部分，$\theta$ 变它不变 |
| $bT$ | 基线计数 | 必须扣掉：它不含方向信息，留着只会把合力往中心拽 |
| $\mathbf{v}$ | 群体向量 | 合力矢量；方向是估计角度，长度反映"投票有多一致" |
| $\mathcal{L}(\theta)$ | 对数似然 | 贝叶斯解码要最大化的目标 |

**为什么必须扣基线**：若 $b = 0$，神经元在偏好方向的反面完全不放电，投票干净；若 $b \gt 0$，每个神经元无论方向都投出 $bT$ 的固定长度。当 $N$ 个偏好方向**均匀铺满一圈**时这些固定票恰好互相抵消（$\sum_i \mathbf{u}_i = 0$），扣不扣都一样；一旦偏好方向分布不均，基线就会把估计系统性拉偏——这是工程上最常见的静默错误。

## 4. 分步例题

### 例题 A：贝叶斯网格解码

**设定**：一个神经元，$r_{max} = 50$ sp/s、$\sigma = 30°$、偏好方向 $45°$；$T = 0.2$ s；观测到 $k = 8$ 个脉冲。候选网格取 $0°, 45°, 90°$，先验均匀。

**第 1 步 · 算各方向上的发放率**：

$$f(0°) = 50e^{-45^2/(2\cdot 30^2)} = 50e^{-1.125} = 16.2326,\quad f(45°)=50,\quad f(90°)=16.2326$$

**第 2 步 · 算期望计数 $\lambda = fT$**：分别为 $3.2465$、$10.0$、$3.2465$。

**第 3 步 · 算似然 $P(8\mid\lambda) = e^{-\lambda}\lambda^8/8!$**：

$$0.011909,\qquad 0.112599,\qquad 0.011909$$

**第 4 步 · 归一化成后验**：三者之和 $0.136417$，于是后验为 $0.0873$、$0.8254$、$0.0873$。**45° 拿到了 82.5% 的置信度**，另外两个方向各不到 9%。

一次试验、一个神经元，就已经把答案压到了 82.5%——这就是为什么脑机接口要一次用几十上百个神经元：每个都贡献一份独立的证据，后验会被迅速压成一个尖峰。

### 例题 B：四神经元群体向量

**设定**：四个偏好方向 $0°, 90°, 180°, 270°$；余弦调谐 $f_i = b + A\cos\left(\theta - \varphi_i\right)$，取 $b = A = 5$ sp/s；$T = 0.4$ s；真实方向 $\theta = 30°$。

**第 1 步 · 算四个发放率**：$f = 5 + 5\cos\left(\theta - \varphi_i\right)$

$$9.3301,\quad 7.5,\quad 0.6699,\quad 2.5 \ \left(\text{sp/s}\right)$$

**第 2 步 · 乘上 $T$ 换成计数**：$3.7321$、$3.0$、$0.2679$、$1.0$（共 8 个脉冲）。

**第 3 步 · 扣基线**：$bT = 2$，四个权重变成 $1.7321$、$1.0$、$-1.7321$、$-1.0$。

**第 4 步 · 沿两个坐标轴分别求和**（$\mathbf{u}_i$ 就是四个坐标轴单位向量，$\cos 90° = \cos 270° = 0$）：

$$v_x = 1.7321 + 0 + 1.7321 + 0 = 3.4641, \qquad v_y = 0 + 1.0 + 0 + 1.0 = 2.0$$

**第 5 步 · 读出角度与长度**：

$$\hat\theta = \operatorname{atan2}\!\left(2.0,\,3.4641\right) = 30.0°, \qquad \left|\mathbf{v}\right| = \sqrt{3.4641^2 + 2.0^2} = 4.0$$

**分毫不差。** 这不是运气：把 $f_i$ 代进去，$\sum_i \cos\left(\theta - \varphi_i\right)\mathbf{u}_i$ 在四个正交方向上只剩 $\frac{N}{2}\left(\cos\theta, \sin\theta\right)$，基线那一项因为 $\sum_i \mathbf{u}_i = 0$ 直接消失，于是 $\mathbf{v} = \frac{N}{2}AT\left(\cos\theta,\sin\theta\right) = 4.0 \times \left(\cos 30°, \sin 30°\right)$。**群体向量的长度正比于 $T$；若忘了乘 $T$（直接用发放率），方向还对，速度会凭空多出 $1/T = 2.5$ 倍。**

### 实验 1（lab）：拖真实方向，看群体向量跟不跟得上

- 先看**灰色虚线**（用期望计数的群体向量）：它与橙色真实方向**完全重合**——这就是例题 B 那条代数结论在 8 个神经元上的样子；
- 看**蓝色实线**（一次抽样的群体向量）：它绕着真实方向抖，抖的幅度随 $T$ 变大而缩小。点「重新抽样脉冲」多掷几次，体会一下解码器的随机性；
- 把 **N 从 8 拖到 4**：抖动明显变大（证据变少）；拖到 **24**：几乎贴住真实方向；
- 把 **jitter**（偏好方向不均匀度）拖大：灰色虚线也跟着偏了——四个偏好方向不再对称，$\sum_i \mathbf{u}_i\mathbf{u}_i^{\mathsf{T}}$ 不再是单位阵的倍数，"朝各方向投票"这句话本身就失衡了。右下角的 $|\mathbf{v}|$ 曲线同时从平直变成波浪：**解码器开始挑方向**；
- 再把 **N 拖到 4**，然后切分段按钮到「**不扣基线**」：橙色的真实方向没变，蓝箭却明显被拽偏——本课实测在这个参数下角度能差出二十几度。**这一条只有 jitter 拖大之后才看得见**：偏好方向均匀铺满一圈时 $\sum_i \mathbf{u}_i = 0$，那份固定票整体抵消，扣不扣一模一样（这正是它危险的地方：代码在均匀数据上测不出错，换一组电极就坏）。切回「扣掉基线 bT」，偏差立刻收回去。
- 看右下角的 $|\mathbf{v}|$ 曲线：jitter 为 0 时它是一条**平直线**（各向同性，转哪个方向都一样灵敏）；jitter 一大就起伏成波浪——解码器的灵敏度开始挑方向了。

### 实验 2（python）：后验、最大似然与群体向量一起算

```python
import math                        # 标准库：指数、阶乘、反三角

def pois(k, lam):                  # 泊松概率
    return math.exp(-lam) * lam ** k / math.factorial(k)

# --- 贝叶斯：网格上算似然，归一化成后验 ---
rmax, sigma, T, k = 50.0, 30.0, 0.2, 8
grid = [0.0, 45.0, 90.0]
lik = [pois(k, rmax * math.exp(-(th - 45.0) ** 2 / (2 * sigma ** 2)) * T) for th in grid]
post = [v / sum(lik) for v in lik]
print("后验：", [f"{th:.0f}° -> {p:.4f}" for th, p in zip(grid, post)])
print(f"最大后验方向 {grid[post.index(max(post))]:.0f}°，置信度 {max(post):.4f}")

# --- 群体向量：四个正交偏好方向 ---
pref = [0.0, 90.0, 180.0, 270.0]
b, A, T2, true_dir = 5.0, 5.0, 0.4, 30.0
counts = [(b + A * math.cos(math.radians(true_dir - p))) * T2 for p in pref]
dx = sum((c - b * T2) * math.cos(math.radians(p)) for c, p in zip(counts, pref))   # 扣掉基线
dy = sum((c - b * T2) * math.sin(math.radians(p)) for c, p in zip(counts, pref))
print(f"计数 {[round(c, 4) for c in counts]}")
print(f"群体向量 ({dx:.4f}, {dy:.4f})  长度 {math.hypot(dx, dy):.4f}  "
      f"方向 {math.degrees(math.atan2(dy, dx)):.4f}°")
```

后验那一行会打出 `45° -> 0.8254`；群体向量那一行会打出方向 `30.0000°`、长度 `4.0000`。把 `true_dir` 改成任意角度再跑一次，方向依然分毫不差。

### 快问快答

```quiz
偏好方向没有均匀铺满一圈，而且忘了扣掉基线计数——群体向量会怎样？
- 方向仍然准确，只是长度缩水
- 方向和长度都可能出错，估计被拉向偏好方向的质心 [*]
- 完全没影响，基线那部分会自己抵消
? 基线是一份与方向无关的固定票；只有 sum(u_i) = 0（偏好方向均匀铺满一圈）时它才自动抵消，否则会把合力整体拽偏。
```

::::warning[常见误区]

**误区一**："似然就是后验。"
你以为算出 $P(k\mid\theta)$ 就拿到了答案——似然只**正比于**后验。均匀先验下还差一步归一化；先验不均匀时还差乘以先验。练习 1 那段代码就是把似然直接当后验打印，于是三个候选的概率加起来远小于 1，而"哪个方向最可能"这个问题其实还能答对——**这正是这类错误最难被发现的原因**：排序对了，数值全错。

**误区二**："群体向量的长度越大，解码越准。"
你以为长箭头代表更有把握——长度主要反映**计数多不多**（正比于 $T$ 和 $N$），不反映估计准不准。更麻烦的是它在**非均匀偏好方向 + 未扣基线**时会系统地缩水，而方向可能同时被扭偏。要判断"这次解码可不可信"，得看后验的尖锐程度或残差，不能看箭头长短。

**误区三**："神经元越多，解码精度就线性变好。"
你以为插的电极翻倍、误差就减半——独立同分布时误差确实按 $1/\sqrt{N}$ 缩小（注意是平方根，不是线性）；而真实皮层里相邻电极的噪声高度相关，**有效独立通道数远小于电极数**，收益还会进一步打折。所以电极阵列的设计问题从来不是"越多越好"，而是"怎么在给定面积里放到最不相关的位置"。

::::

## 6. 练习

**练习 1**：算 45° 处的后验概率。下面的代码直接把似然当后验打印出来了，三个候选的概率甚至不加成 1：

```exercise
# @title: 练习：把似然归一化成后验
# @check: 0.8254
# @hint: 似然只正比于后验。均匀先验下要除以「所有候选方向的似然之和」，归一化之后三个数才会加起来等于 1。
import math                       # 标准库：指数与阶乘

def pois(k, lam):                 # 泊松概率 P(k | lam)
    return math.exp(-lam) * lam ** k / math.factorial(k)

rmax, sigma, T = 50.0, 30.0, 0.2  # 峰值率（sp/s）、调谐宽度（度）、观察窗（s）
grid = [0.0, 45.0, 90.0]          # 候选方向的离散网格
k = 8                             # 这一次试验观测到的脉冲数

lik = []
for th in grid:
    f = rmax * math.exp(-(th - 45.0) ** 2 / (2 * sigma ** 2))   # 该方向的发放率
    lik.append(pois(k, f * T))    # 似然 P(k | th)
post = lik[1]                     # ← 问题在这：似然不是后验，还差一步归一化
print(f"{post:.4f}")
```

**练习 2**：回答三个问题。(a) 例题 B 里若忘了扣基线（也就是把 $bT = 2$ 留在计数里），方向和长度会怎样？(b) 为什么 $|\mathbf{v}|$ 正比于 $T$，而方向与 $T$ 无关？(c) 偏好方向从 4 个加到 8 个（仍均匀、仍余弦调谐），$|\mathbf{v}|$ 变成多少？

<details>
<summary>点开查看逐步解答</summary>

1. (a) 方向**仍然是 30°**——四个偏好方向均匀铺开时 $\sum_i \mathbf{u}_i = 0$，那份固定票整体抵消掉了；长度从 4.0 变成 $4.0 + 0 = 4.0$ 也**不变**。所以在这个特例里扣不扣一样，这也正是它最危险的地方：**换一组不均匀的偏好方向，同样的代码就会开始偏**，而错误很难被察觉（实验里把 jitter 拖大就能看到）；
2. (b) 计数 $k_i = Tf_i$ 与 $T$ 成正比，合力里每一项都带 $T$，所以 $|\mathbf{v}| \propto T$；而角度是 $\operatorname{atan2}$ 的比值，$T$ 在分子分母里同时出现，直接约掉。物理上：**窗越长证据越多（向量越长），但"往哪边"这件事的几何不变**；
3. (c) 由 $\mathbf{v} = \frac{N}{2}AT\left(\cos\theta,\sin\theta\right)$，$N$ 从 4 到 8 则长度从 4.0 变 **8.0**——正比于神经元个数。这也是"多插电极"最直接的收益（但注意：真实数据里各神经元的噪声相关性会让收益**慢于线性**）。

**与最大似然的差别**：例题 A 里后验峰在 45°，群体向量的期望值也在 45°，两者重合。但调谐变窄或偏好方向变稀疏时，群体向量会因为"权重大的神经元被放大"而出现**系统性收缩**（估计长度偏小、方向向偏好方向的质心偏移），而 ML 不会。所以现代解码器多用后者，前者留作**快速的线性基线**——它只要一次矩阵乘法，微秒级就能出结果。

</details>

## 7. 选读：群体向量为什么会偏，怎么修

<details>
<summary>选读 · 收缩偏差与最优线性估计</summary>

把余弦调谐代进群体向量，可以得到它的期望值

$$\mathbb{E}[\mathbf{v}] = T\sum_{i=1}^{N}A\cos\left(\theta - \varphi_i\right)\mathbf{u}_i$$

若 $\varphi_i$ 均匀铺满一圈，$\sum_i \mathbf{u}_i\mathbf{u}_i^{\mathsf{T}} = \frac{N}{2}\mathbf{I}$，于是 $\mathbb{E}[\mathbf{v}] = \frac{N}{2}AT\left(\cos\theta, \sin\theta\right)$——一个**无偏**的估计。问题全在"均匀"这两个字上：

- **偏好方向不均匀**：$\sum_i \mathbf{u}_i\mathbf{u}_i^{\mathsf{T}}$ 不再是单位阵的倍数，而是一个**各向异性**的矩阵。群体向量的方向会被它扭一下，长度随方向起伏（实验里右下角那条波浪线）。修法是求逆：$\hat{\mathbf{v}} = \left(\sum_i \mathbf{u}_i\mathbf{u}_i^{\mathsf{T}}\right)^{-1}\sum_i k_i\mathbf{u}_i$，这就是 **最优线性估计**（OLE），它在"线性无偏"这一类里方差最小；
- **调谐曲线不是余弦**（比如高斯、或者带一个很大的基线）：每个神经元的权重曲线形状变了，线性求和不再等价于 ML。窄调谐时收缩最明显——估计长度普遍偏短，方向被拉向偏好方向的质心；
- **噪声相关**：真实皮层里相邻电极的噪声是相关的，独立假设失效。此时最优权重里还得多乘一个噪声协方差矩阵的逆（这已经是广义最小二乘的形状）。

**还有一条更根本的边界**：群体向量和 ML 都假设"每个神经元只对自己的偏好方向敏感"，也就是调谐曲线**不随刺激的其他属性而变**（比如同时编码方向与速度时，调谐曲线会随速度平移）。真实运动皮层的神经元确实有这种"增益场"结构，于是纯方向的解码器在变速任务上会掉精度。

**这一课最该带走的一句**：群体向量不是"另一种解码器"，而是**最大似然在一组特定假设下的线性影子**。知道假设是什么，就知道它什么时候会坏。

</details>

## 8. 下一站

群体向量和贝叶斯解码都是**逐帧独立**的：这一帧的观测只影响这一帧的估计。可光标是会动的——上一帧的位置强烈预示这一帧的位置。把"运动模型"这条时间上的先验加进去，就得到了脑机接口里真正在用的解码器：卡尔曼滤波。
