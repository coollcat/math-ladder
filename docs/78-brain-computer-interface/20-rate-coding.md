# 脉冲串的数学：发放率、调谐曲线与点过程

## 1. 从一个场景开始

同一段刺激重复 22 次，同一个神经元每次吐出的脉冲串**都不一样**：这次 9 个，下次 12 个，再下次 8 个。刺激一模一样，神经元也不是坏掉了——它在**掷骰子**。

那么"这个神经元正在被刺激"这句话，到底该翻译成什么数学对象？答案分两层：一层描述**它平均放多密**（发放率），一层描述**这个密度上叠了多大的随机性**（点过程）。把这两层分清楚，才谈得上后面从脉冲反推刺激。

## 2. 直觉解释

先把"脉冲串"看成一串**时间点**：$0.031$ s、$0.058$ s、$0.089$ s……除了时刻什么信息都没有。这样一串东西在数学上叫**点过程**。

再看神经元对什么的反应最强。运动皮层里有一批神经元，你让猴子朝不同方向推操纵杆，它的放电率画出来是一条**钟形曲线**：某个方向最旺，两边递减，反向最冷。这条曲线叫**调谐曲线**，那个最旺的方向叫**偏好方向**。

把这两件事合起来，就得到了本章后面所有内容的地基：**刺激先决定一条调谐曲线，调谐曲线的高度是"平均放多密"，而实际数到的脉冲数在这个平均值附近抖动**。抖动不是缺陷，它有个精确的名字——泊松噪声，而且它的大小被平均值完全钉死。

## 3. 正式定义

**第一层：发放率**。观察窗 $T$ 内数到 $k$ 个脉冲，最朴素的定义是 $r = k/T$（单位 sp/s）。它是估计量，不是真值。

**第二层：计数是泊松随机变量**。若脉冲以恒定速率 $r$ 独立地冒出来，则长度为 $T$ 的窗内计数满足

$$P(k) = e^{-\lambda}\frac{\lambda^{k}}{k!}, \qquad \lambda = rT$$

泊松分布最要命的一条性质是**均值等于方差**：$\mathbb{E}[k] = \operatorname{Var}[k] = \lambda$。所以 $k$ 的标准差是 $\sqrt{\lambda}$——**计数越大，相对抖动越小**（$\sqrt{\lambda}/\lambda = 1/\sqrt{\lambda}$）。这就是为什么长观察窗能把噪声压下去。

**第三层：调谐曲线**。以角度 $\theta$ 为刺激、偏好方向为 $\theta_0$，两种最常用的写法是

$$f(\theta) = r_{max}\exp\left(-\frac{\left(\theta - \theta_0\right)^2}{2\sigma^2}\right), \qquad f(\theta) = b + A\cos\left(\theta - \theta_0\right)$$

前者叫高斯调谐（$\sigma$ 是宽度），后者叫余弦调谐（$b$ 是基线、$A$ 是调制深度）。

**第四层：Fisher 信息**。它衡量"观测里含了多少关于刺激的信息"。对一个泊松计数神经元可以证明

$$J(\theta) = \frac{T\,f'(\theta)^2}{f(\theta)}$$

它的倒数给出估计误差的下界：$\operatorname{Var}[\hat\theta] \ge 1/J(\theta)$（Cramér–Rao 界）。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $r$, $f(\theta)$ | 发放率 / 调谐曲线 | 平均每秒几个脉冲 |
| $T$ | 观察窗 | 数脉冲的时间长度，秒 |
| $\lambda$ | 期望计数 | $\lambda = rT$，泊松分布的唯一参数 |
| $\sigma$ | 调谐宽度 | 高斯曲线的标准差，越小越"挑食" |
| $J(\theta)$ | Fisher 信息 | 单位 1/度²；越大越容易分辨邻近方向 |

## 4. 分步例题

**例**：$r_{max} = 50$ sp/s、$\sigma = 20°$、$T = 0.4$ s。问偏好方向上的期望计数，以及 Fisher 信息在哪里最大、有多大。

**第 1 步 · 偏好方向上的计数**：$f(\theta_0) = 50$，$\lambda = 50 \times 0.4 = 20$ 个脉冲。

**第 2 步 · 写出导数**：$f'(\theta) = -f(\theta)\cdot u/\sigma^2$，其中 $u = \theta - \theta_0$。

**第 3 步 · 看在偏好方向上**：$u = 0$ 时 $f' = 0$，于是 $J = 0$。**在自己最擅长的方向上，它反而提供不了任何一阶信息**——曲线的顶是平的，稍微动一点刺激，发放率几乎不变。

**第 4 步 · 找最优点**：把 $J = T f(\theta)u^2/\sigma^4$ 对 $u$ 求极值，得 $u^\star = \sqrt{2}\,\sigma = 28.28°$。

**第 5 步 · 代数化简**：在 $u^\star$ 处 $f = r_{max}e^{-1}$、$u^2 = 2\sigma^2$，于是

$$J_{max} = T\cdot r_{max}e^{-1}\cdot\frac{2\sigma^2}{\sigma^4} = \frac{2T\,r_{max}}{e\,\sigma^2} = \frac{2 \times 0.4 \times 50}{e \times 400} = 0.0368$$

注意 $\sigma^2$ 在分母上：**调谐越窄，信息越多，而且是按 $1/\sigma^2$ 涨**。窄调谐神经元是更精细的传感器，代价是它只覆盖一小段方向。

**第 6 步 · 余弦曲线对照**：取 $f = b + A\cos u$ 且 $b = A = 25$（峰值同样是 50 sp/s），在 $u = 90°$ 处 $f = 25$、$|f'| = 25$（$u$ 取弧度）。按 $J = T(f')^{2}/f$ 得 $J = 0.4 \times 625/25 = 10$，单位是 1/弧度²；换成与上一行同一把尺子（1/度²）：$10 \times (\pi/180)^{2} \approx 0.00305$。

拿它和高斯的 $J_{max} = 0.0368$（1/度²）比：**同样 50 sp/s 的峰值，高斯在最陡处给出的信息是余弦的约 12 倍**（$0.0368/0.00305 \approx 12$）。信息量由"相对斜率" $u/\sigma$ 决定——高斯在 $u^\star = \sqrt{2}\sigma$ 处的相对斜率是 $\sqrt{2}$，而余弦最陡处的相对斜率只有 1，再叠上 $\sigma = 20°$ 这个尺度，差距就出来了。**形状（陡峭程度）比峰值更决定信息量。**

## 5. 动手实验

### 实验 1（lab）：拖方向箭头，看栅格重掷

```lab

  "type": "bci-tuning-curve",
  "title": "左：极坐标上的调谐曲线，红点可拖；右上：22 次试验的脉冲栅格；右下：计数分布与实测计数",
  "theta": 40,
  "sigma": 30,
  "rmax": 50,
  "T": 1.0
}
```

- 把红点拖到**偏好方向**（0°）：栅格最密，计数分布的中心 $\lambda$ 最大，读数给出 Fisher 信息 $J = 0$——这正是第 3 步那个反直觉的结论；
- 拖到 **42°** 附近（实验里 $\sigma = 30$，最优点是 $\sqrt{2}\sigma \approx 42°$）：读数的 $J$ 顶到上界 $2T\,r_{max}/\left(e\sigma^2\right)$；
- 把 $\sigma$ 从 60° 拖到 10°：曲线变尖，$J$ 的上界按 $1/\sigma^2$ 猛涨，但紫色实测计数开始散得厉害（$\lambda$ 变小、相对抖动 $\sqrt{\lambda}/\lambda$ 变大）——**信息上界与有限样本的稳定性是两回事**；
- 把 $T$ 拉长：紫色刻度（每次试验的实测计数）越来越聚拢到红色虚线（$\lambda$）附近。长窗换稳定，这就是第 3 节那句"$\sqrt{\lambda}$ 抖动"的直接后果。

### 实验 2（python）：调谐曲线、计数分布与 Fisher 信息一起算

```python
import math                        # 标准库：指数、开方

rmax, sigma, T = 50.0, 20.0, 0.4   # 峰值率 sp/s、调谐宽度 度、观察窗 s

def rate(u):                       # 高斯调谐曲线，u 是相对偏好方向的偏移（度）
    return rmax * math.exp(-u ** 2 / (2 * sigma ** 2))

def fisher(u):                     # J = T * f'(u)^2 / f(u)
    f = rate(u)
    return T * (f * u / sigma ** 2) ** 2 / f

for u in (0.0, math.sqrt(2) * sigma, 2 * sigma):
    lam = rate(u) * T              # 该方向上的期望计数
    print(f"偏移 {u:5.2f}°  r = {rate(u):6.2f} sp/s  lambda = {lam:5.2f}  "
          f"sqrt(lambda) = {math.sqrt(lam):4.2f}  J = {fisher(u):.6f}")

best = 2 * T * rmax / (math.e * sigma ** 2)
print(f"信息上界 2T*rmax/(e*sigma^2) = {best:.6f}，最优点 sqrt(2)*sigma = {math.sqrt(2) * sigma:.2f}°")
```

三行输出里，中间那一行的 $J$ 最大（0.036788）；第一行的 $J$ 是 0.000000。而 `sqrt(lambda)` 那一列告诉你为什么长窗能压噪声：$\lambda = 20$ 时相对抖动只有 $1/\sqrt{20} \approx 22\%$。

::::warning[常见误区]

**误区一**："放得多的神经元就携带更多信息。"
你以为"更活跃 = 信息更多"——信息取决于**两个刺激下的分布差了多少**，不取决于绝对高度。把 $r_A$ 与 $r_B$ 一起调到 30 sp/s，两个分布仍然完全重合，互信息是 0；反过来，$r_A = 2$、$r_B = 0.5$ 这样低发放率的搭配，只要比值拉开，信息照样可观。

**误区二**："观察窗越长越好。"
你以为多记一会儿总是赚——总信息量确实单调涨，但**每脉冲效率在跌**（例题第 7 步：$I/\bar{k}$ 从 0.273 掉到 0.076）。更要命的是，"速率恒定"这个前提在长窗里先塌：注意力漂移、刺激适应都会让发放率自己变，这时拉长窗反而把不同状态混成一锅。脑机接口要 20 ms 出一帧，就是被这条约束逼出来的。

**误区三**："泊松噪声是模型不够精细造成的，换个模型就没了。"
你以为抖动是建模缺陷——它是**测量本身的物理属性**：同样的刺激重复 22 次，计数就是会变。模型能做的是**正确描述抖动的形状**（均值等于方差），而不是消灭它。换模型（比如加不应期）改变的是方差与均值的比值，不会让方差归零。

::::

## 6. 练习

**练习 1**：算 $u = \sqrt{2}\sigma$ 处的 Fisher 信息。下面的代码把采样点取在了偏好方向上，于是信息量算出来是 0：

```exercise
# @title: 练习：找 Fisher 信息最大的偏移
# @check: lambda = 20.0
# @check: J = 0.036788
# @hint: 调谐曲线的顶是平的，u = 0 处导数为零、一阶信息为零。把采样点搬到 u = sqrt(2)*sigma，那里 f' 与 f 的搭配最划算。
import math                       # 标准库：开方与指数
rmax = 50.0       # 峰值发放率（sp/s）
sigma = 20.0      # 调谐曲线的标准差（度）
T = 0.4           # 观察窗（s）

def rate(u):                      # u = 刺激方向离偏好方向的偏移（度）
    return rmax * math.exp(-u ** 2 / (2 * sigma ** 2))

lam = rate(0.0) * T               # 偏好方向上的期望脉冲数
u = 0.0                           # ← 问题在这：就在偏好方向上取信息量
fp = rate(u) * (-u / sigma ** 2)  # 调谐曲线的导数
J = T * fp ** 2 / rate(u)         # Fisher 信息
print(f"lambda = {lam:.1f}")
print(f"J = {J:.6f}")
```

**练习 2**：回答三个问题。(a) 为什么在偏好方向上 $J = 0$，那神经元岂不是"最擅长的事上最没用"？(b) 把 $T$ 从 0.4 s 拉到 1.6 s，$J_{max}$ 变成多少？(c) 泊松分布的方差等于均值，这一条如果被破坏（比如神经元有不应期），计数会偏大还是偏小？

<details>
<summary>点开查看逐步解答</summary>

1. (a) 一阶信息为零不等于没用。$J = 0$ 说的是"曲线在顶点处的一阶导数为零"，微小的刺激变化确实几乎不改变发放率；但把整条曲线的形状拼起来（很多神经元各自贡献一段陡坡），方向照样能解出来——这正是下一课**群体解码**要干的事；
2. (b) $J_{max} = 2T\,r_{max}/\left(e\sigma^2\right)$ 与 $T$ 成正比：$T$ 变 4 倍，$J_{max}$ 从 0.036788 变成 **0.147152**；按 Cramér–Rao 界，估计标准差降到一半——**四倍时间换一半误差**；
3. (c) 不应期让脉冲"互相排斥"，计数比泊松更**规整**，方差**小于**均值（欠离散，Fano 因子 $\lt 1$）。反过来，簇状放电会让方差大于均值。泊松只是最好用的基准，不是铁律。

**为什么公式里是 $f'^2/f$**：Fisher 信息是得分函数的方差，而泊松计数的得分函数正比于 $\left(k - Tf\right)f'/f$，取方差时 $k$ 的方差贡献出 $Tf$，乘上 $\left(f'/f\right)^2$ 就得到 $Tf'^2/f$。分子要陡（信息多），分母要小（噪声小），两者拉扯的结果就是第 4 步那个 $\sqrt{2}\sigma$。

</details>

## 7. 选读：泊松假设从哪来，什么时候会塌

<details>
<summary>选读 · 三个层次与 Fano 因子</summary>

**为什么计数会是泊松的**。若脉冲是一系列相互独立、速率恒定的事件，则计数服从泊松分布——这是[泊松过程](../37-stochastic-processes/70-poisson-process.md)的标准结论。生物上它对应一个图景：一个神经元的发放率由**成千上万个近乎独立的突触输入**叠加决定，"阈值被跨过"这件事近似成"常数速率 + 微小抖动"。所以泊松不是被推导出来的，而是被**近似**出来的。

**什么时候不成立**。用一个数字就能体检：**Fano 因子** $F = \operatorname{Var}[k]/\mathbb{E}[k]$。泊松是 $F = 1$。

- $F \lt 1$（欠离散）：不应期让脉冲互相排斥，计数变规整。皮层神经元在稳定刺激下常在 $0.5 \sim 1$ 之间；
- $F \gt 1$（过离散）：簇状放电，或者发放率本身在缓慢漂移（刺激没锁住、注意力波动）。这时把窗拉长反而更糟，因为"速率恒定"这个前提先塌了。

**第三层：时间精度**。本课只用了"窗内数几个"这一个统计量，等于假设脉冲的精确时刻不含额外信息。事实并非总是如此：在听觉与触觉通路上，**第一个脉冲的时刻**往往比计数更精确地编码刺激。要利用它就得把点过程写成条件强度 $\lambda(t)$，而不是一个常数——这是通往"点过程滤波解码"的入口。

对脑机接口的日常实践来说，结论很实用：**先数脉冲、看 Fano 因子**。接近 1 就用泊松模型（下一课直接上贝叶斯）；明显偏离就换窗长、换模型，否则解码器给出的置信度会系统性偏错。

</details>
