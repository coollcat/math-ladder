# 闭环脑机接口：刺激、辨识与自适应

## 1. 从一个场景开始

前面七课都在"读"：把神经信号解成意图。现在把线接回去——按解码结果实时给脑组织送电流（深部脑刺激、皮层微刺激、闭环神经调控）。系统立刻从"传感器"变成**控制器**。

一位工程师把反馈增益调到 1.2，觉得响应还不够快，继续往上拧。拧到 1.5，屏幕上的波形开始有节奏地晃；拧到 1.8，整个系统**自己振起来了**——刺激制造了它本来要压制的那个振荡。

更奇怪的是：同样的增益 1.5，在上一版固件里好好的。区别只有一个——**新版把反馈路径缩短了一个采样周期**。为什么"更快"反而会不稳定？

## 2. 直觉解释

先想清楚闭环在干什么。脑区有一个自己的"回弹"倾向：受了扰动之后，它自行衰减回基线。设这个衰减系数是 $a$（$0 \lt a \lt 1$，越小衰减越快）。刺激器做的事是"看到偏离就反向推一把"，推力是 $-g$ 乘以"它以为的当前偏离"。

- $g$ **太小**：推不动，扰动慢慢自己衰减掉——**稳，但没效果**；
- $g$ **刚好**：扰动被迅速压回去——**这就是我们要的**；
- $g$ **太大**：这一拍推过头，下一拍就往反方向偏，再下一拍推得更狠……**自己把自己推成了振荡器**。

**延迟**是这中间的隐形杀手。刺激器"以为的当前偏离"其实是 $τ$ 个采样周期**之前**的偏离。它在用旧地图指挥现在的交通：等它发现偏左了、往右推的时候，系统可能已经自己偏到右边去了——这一推不但没纠偏，反而**加了把火**。所以延迟越长，允许的增益越小。

这就是第 1 节那个怪现象的答案：**缩短延迟本身没错，错的是没有跟着下调增益**。

## 3. 正式定义

### 开环：辨识

刺激关掉，脑区自由衰减（用离散步表示，$t$ 是采样点序号）：

$$x_{t+1} = a\,x_t, \qquad x_t = a^{t}x_0$$

两边取对数，衰减变成一条**直线**：$\ln\left|x_t\right| = t\ln a + \ln\left|x_0\right|$。对 $\ln\left|x_t\right|$ 与 $t$ 做最小二乘，斜率就是 $\ln a$，取指数就辨识出 $a$。**这是所有闭环系统的第一步：先把对象认出来，再谈控它。**

### 闭环：带宽受限的反馈

刺激器用 $τ$ 个采样点之前的测量值做反馈：

$$x_{t+1} = a\,x_t - g\,x_{t-\tau}$$

特征方程（试 $x_t = z^{t}$ 代入）：

$$z^{\tau+1} - a\,z^{\tau} + g = 0$$

**闭环稳定 ⟺ 这个多项式的全部根都满足 $\left|z\right| \lt 1$。**

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a$ | 开环极点 | 脑区自身的衰减系数，$0 \lt a \lt 1$；由辨识得到 |
| $g$ | 反馈增益 | 刺激强度与解码偏差的乘积，工程师手里的那个旋钮 |
| $\tau$ | 反馈延迟 | 从测量到刺激生效，隔了几个采样周期 |
| $g_{max}\!\left(\tau\right)$ | 稳定边界 | 给定延迟下还能稳住的增益上界 |

### 三个可以直接手算的情形

**$\tau = 0$（无延迟）**：$z = a - g$，稳定条件 $\left|a - g\right| \lt 1$，即

$$g_{max} = 1 + a$$

**$\tau = 1$**：特征方程 $z^2 - az + g = 0$。两根都在单位圆内的 Jury 条件给出 $\left|g\right| \lt 1$ 且 $\left|a\right| \lt 1 + g$，对 $a \gt 0$ 就是

$$g_{max} = 1$$

**$\tau = 2$**：特征方程 $z^3 - az^2 + g = 0$，Jury 条件里最紧的那一条是 $\left|a g\right| \lt 1 - g^2$，解得

$$g_{max} = \frac{-a + \sqrt{a^2 + 4}}{2}$$

**看这条曲线的形状**：$a = 0.9$ 时，$g_{max}$ 从 1.9（$\tau = 0$）掉到 1.0（$\tau = 1$），再到 0.6466（$\tau = 2$）——**每多一个采样周期的延迟，增益预算就砍掉一大截**。这就是"带宽换增益"在闭环脑机接口里的具体价格。

## 4. 分步例题

**例**：$a = 0.9$。求 $\tau = 0, 1, 2$ 时的稳定增益上界，并判断 $\tau = 2$、$g = 0.8$ 稳不稳。

**第 1 步 · 零延迟**：$g_{max} = 1 + 0.9 = \mathbf{1.9}$。低于 1.9 都稳。

**第 2 步 · 一个周期延迟**：$g_{max} = \mathbf{1.0}$。**同一个脑区，同样的刺激器，仅仅因为反馈慢了一拍，能用的增益就少了一半。**

**第 3 步 · 两个周期延迟**：$g_{max} = \left(-0.9 + \sqrt{0.81 + 4}\right)/2 = \left(-0.9 + 2.1932\right)/2 = \mathbf{0.6466}$。

**第 4 步 · 验算 $\tau = 2$、$g = 0.8$**：$0.8 \gt 0.6466$，落在不稳定区。把 $a = 0.9$、$g = 0.8$ 代进特征方程 $z^3 - 0.9z^2 + 0.8 = 0$，三个根里有一对的模大于 1——**系统会自激**。实验里拖到这一点就能看见波形幅度一代比一代大。

**第 5 步 · 换一个稳的**：$g = 0.5$：$z^3 - 0.9z^2 + 0.5 = 0$，三个根的模是 $0.581$ 与一对 $0.9276$，全都小于 1——扰动被压回去了，系统稳定。但要注意：主导模 $0.9276$ 比开环（$g = 0$ 时 $z^2(z - 0.9) = 0$，主导模 $0.9$）**略慢**。**闭环换来的不是"衰减更快"，而是"能把状态拉向目标"**（调节与跟踪）。想让扰动同时收得更快，得用更小的增益：$g = 0.3$ 时主导模降到 $0.8004$，比开环还快；而一旦增益逼近 $g_{max}$，主导极点就往外推、裕度耗尽。

**第 6 步 · 读一条工程含义**：如果系统采样率是 1 kHz，$\tau = 2$ 就是 2 ms 的延迟。听起来微不足道，却直接砍掉三分之二的增益预算。所以闭环神经调控的硬件设计里，**"缩短环路延迟"几乎总是优先级最高的一项**——它比换更好的解码算法更能提升可用的控制带宽。

## 5. 动手实验

### 实验 1（lab）：把增益拖过边界，看它自激

```lab
{
  "type": "bci-closed-loop",
  "title": "上格：闭环波形（或开环辨识）；下格：数值扫出来的稳定边界 g_max(τ)，可直接拖圆点改参数",
  "a": 0.9,
  "g": 0.8,
  "tau": 2,
  "noise": 0.02,
  "mode": "loop"
}
```

- 默认参数 $a = 0.9$、$\tau = 2$、$g = 0.8$ 落在**红色阴影区**（不稳定区）：点播放，波形幅度一代比一代大，读数直接给"⚠ 已越过稳定边界：闭环自激"；
- 把 **g 拖到 0.5**：落回边界下方，波形几拍内衰减到零——闭环在干活；
- 把 **τ 从 2 拖到 0**：紫色边界线整体抬高到 1.9，红色阴影退到右上角。**注意 0.8 这个增益在原地就变安全了**——同一套参数，只因延迟变了，系统性格就变了；
- 拖下格里的圆点，**同时改 τ 和 g**：你会看到边界是一条约 1/τ 形状的下降曲线，前几个点掉得最狠；
- 切到「**开环辨识**」：刺激关掉，只留初始扰动。读数里的"辨识结果"是对 $\ln\left|x_t\right|$ 做最小二乘拟合出来的 $\hat{a}$，会贴着真实的 $a = 0.9$ 抖。把 **噪声 σ 拖到 0**：$\hat{a}$ 会精确等于 0.9。**把噪声拖大**：辨识误差上来，而真实系统里"辨识不准"会直接吃掉稳定裕度——你按估偏了的 $\hat{a}$ 去算边界，算出来的边界本身就偏了。

### 实验 2（python）：扫出稳定边界，与解析公式对账

```python
import math                        # 标准库：开方

def bounded(a, g, tau, n=4000):
    """递推 n 步，看扰动是在衰减还是在长大（衰减 = 闭环稳定）。"""
    x = [0.0] * (tau + 1)
    x[tau] = 1.0                   # 初始扰动：敲一下
    half, m1, m2 = n // 2, 0.0, 0.0
    for i in range(n):
        nxt = a * x[tau] - g * x[0]
        if abs(nxt) > 1e12:
            return False           # 已经炸了
        v = abs(nxt)
        if i < half:
            m1 = max(m1, v)
        else:
            m2 = max(m2, v)
        x = x[1:] + [nxt]
    return m2 < m1                 # 后半段包络更小 = 在衰减

def gain_max(a, tau, lo=0.0, hi=4.0, iters=24):
    """二分扫出给定延迟下的稳定增益上界。"""
    for _ in range(iters):
        mid = (lo + hi) / 2
        if bounded(a, mid, tau):
            lo = mid
        else:
            hi = mid
    return lo

a = 0.9
analytic = {0: 1 + a, 1: 1.0, 2: (-a + math.sqrt(a * a + 4)) / 2}   # 前三个延迟有闭式解
for tau in range(4):
    scanned = gain_max(a, tau)
    exact = f"{analytic[tau]:.4f}" if tau in analytic else "（无闭式，只能扫）"
    print(f"tau = {tau}  扫描 g_max = {scanned:.4f}  解析 = {exact}")
print(f"tau = 0, g = 1.5 稳定？{bounded(a, 1.5, 0)}")
print(f"tau = 2, g = 0.8 稳定？{bounded(a, 0.8, 2)}")
print(f"tau = 2, g = 0.5 稳定？{bounded(a, 0.5, 2)}")
```

前三个延迟的扫描值与解析值完全对上（1.9000 / 1.0000 / 0.6466），$\tau = 3$ 没有闭式解，扫描给出 0.4855——**每多一个采样周期的延迟，预算就再砍一刀**。后三行的判断依次是 `True`、`False`、`True`。

### 快问快答

```quiz
同一套闭环系统，只把反馈延迟从 0 个采样周期加到 1 个，稳定增益上界会怎么变？
- 不变，延迟只影响相位不影响幅度
- 从 1+a 掉到 1 [*]
- 从 1 涨到 1+a，因为延迟给了系统反应时间
? 零延迟时特征根是 a-g，稳定条件是 |a-g|<1 即 g<1+a；一个周期延迟后特征方程变成 z²-az+g=0，Jury 条件给出 g<1。延迟只会吃掉增益预算，不会增加。
```

::::warning[常见误区]

**误区一**："增益越大，控制越强。"
你以为刺激强度与纠偏能力成正比——$g$ 一旦越过 $g_{max}$，反馈的符号在延迟的作用下反转：**刺激本身就是振荡的能源**。这时再加增益，不是"控制得更狠"，而是"把振荡喂得更壮"。控制器设计里这条规律叫"增益不是免费的"，实验里红色阴影区就是它的地图。

**误区二**："延迟只是让响应慢一点，不影响稳定性。"
你以为延迟是速度问题、稳定性是增益问题——两者在同一个特征方程里。延迟在环路里引入**相位滞后**：等刺激起作用时，系统可能已经跑到反方向了。$a = 0.9$ 时把延迟从 0 加到 1 个采样周期，增益预算从 1.9 直接砍到 1.0，**几乎腰斩**，而系统本身一点没变。

**误区三**："把增益顶到稳定边界附近最划算。"
你以为离边界越近性能越好——边界是由**估计出来的** $\hat{a}$ 算的，而 $\hat{a}$ 有误差、$a$ 本身还会漂（电极阻抗、状态波动）。把 $g$ 定在边界的 95%，参数一漂就翻过界。工程惯例是留 30%~50% 裕度（$g \approx 0.5 \sim 0.7\, g_{max}$）：**纸面上的最优，在现实里是余量为零**。

::::

## 6. 练习

**练习 1**：$a = 0.9$、反馈延迟 $τ = 1$ 时，稳定增益上界是多少？下面的代码套用了**零延迟**的公式，算出 1.9：

```exercise
# @title: 练习：延迟一拍之后的稳定增益上界
# @check: 1.0000
# @hint: τ=1 时特征方程是 z² − a z + g = 0。两根都在单位圆内的条件是 |g| < 1 且 |a| < 1 + g——后一条对 a = 0.9 自动满足，真正卡住的是前一条。零延迟那个 1 + a 是 τ=0 专属的结论。
a = 0.9            # 脑区自身的衰减系数（开环极点）
tau = 1            # 反馈延迟（采样点）

gmax = 1 + a       # ← 问题在这：这是零延迟的结论，τ=1 时不管用
print(f"{gmax:.4f}")
```

**练习 2**：回答三个问题。(a) 为什么延迟变大时稳定增益上界会下降，从"推的时机"角度解释。(b) 采样率 1 kHz、$a = 0.9$，若想把增益用到 1.5，延迟最多能容忍几个采样周期？(c) 为什么实验里必须先做"开环辨识"？

<details>
<summary>点开查看逐步解答</summary>

1. (a) 反馈项 $-gx_{t-\tau}$ 用的是一份"过期"的测量。延迟越大，这份测量与当前状态的**相关性越差**：当系统已经越过零点往另一边走时，刺激器还在按旧信息往原来的方向推，这一推就是**正反馈**。数学上，延迟在特征方程里引入额外的根，把单位圆内的稳定区域压缩；物理上，**相位滞后吃掉了相位裕度**——这与[ PID 控制](../52-control/40-pid-control.md)里"延迟是环路稳定性的天敌"是同一件事；
2. (b) 逐条对照：$\tau = 0$ 时上界 1.9 ✓ 够用；$\tau = 1$ 时上界 1.0 ✗ 不够。所以**最多容忍 0 个采样周期的延迟**——1 kHz 下 1.5 这个增益要求环路延迟小于 1 ms。这就是为什么闭环神经调控的硬件会为"省下 0.5 ms"投入大量工程：它不是性能优化，而是**能不能用**的分界线；
3. (c) 因为稳定边界 $g_{max}\!\left(\tau\right)$ 是 $a$ 的函数，而 $a$ 是**每个受试者、每个电极位置、甚至每天都不一样**的（电极阻抗漂移、状态波动）。若不先辨识就照手册上的固定增益去刺激，等于拿别人的边界保护自己。辨识的做法就是把刺激关掉、敲一个已知扰动、看它怎么自由衰减——也就是本课实验里那个"开环辨识"模式。

**为什么判据要写成"后半段包络更小"**：靠近边界时增长极慢，若只判断"有没有超过某个大数"，有限步数内它根本涨不到阈值，会把实际不稳定的系统误判成稳定（$\tau = 0$ 时会把 1.905 当成安全）。改用"前后两半的包络峰值比较"，判据对**趋势**敏感而不是对**绝对值**敏感，精度能到 $10^{-4}$——这正是实验里扫描值与解析值能对上的原因。

</details>

## 7. 选读：自适应刺激与安全的边界

<details>
<summary>选读 · 边控边辨识、自适应增益与临床克制</summary>

**边控边辨识**。上面把"辨识"和"控制"分成了两步，但真实系统两件事得同时做：刺激不能停，可不停刺激就测不到自由衰减。标准解法是**把刺激信号当作已知输入**，用带输入的回归同时估计 $a$ 与 $g$（这就是系统辨识里的 ARX 模型），或者用递推最小二乘在线更新参数。这时"刺激"既是执行器也是**探测信号**——闭环系统的辨识问题天然比开环难，因为输入与噪声相关。

**自适应增益**。既然 $a$ 会漂，$g$ 就该跟着漂：

$$g_{t} = \rho \cdot g_{max}\!\left(\hat{a}_t, \tau\right), \qquad \rho \approx 0.5 \sim 0.7$$

留出 30%~50% 的裕度是工程惯例：$\hat{a}$ 有误差、延迟会抖动、模型本身也只是一阶近似。**把增益顶到边界的 100% 在纸面上最优，在现实里等于自杀**——这也是本课实验里红色阴影区存在的意义：它不是"效率低"，而是"别去"。

**临床上的克制**。闭环深部脑刺激（aDBS）已经在帕金森病的运动症状上进入临床研究阶段，它的思路与本课完全一致：用一个生物标志物（比如丘脑底核的 β 频段功率）当反馈量，按需调节刺激幅度，而不是全天恒定输出。可能的好处是**总刺激量下降、副作用（言语、情绪）减轻、电池寿命延长**。这里必须写清楚两件事：

1. 本课的所有方程都是**教学简化模型**。真实脑区不是一阶线性系统，刺激与响应高度非线性、非平稳，还会随电极位置与病程漂移；
2. 具体的刺激参数、适应证与疗效判断属于**临床决策**，由有资质的医生根据个体情况做出，任何从本课公式直接推出来的"应该调多大"都是没有依据的。这里能提供的只是一条数学直觉：**先辨识、留裕度、延迟最贵**。

**为什么延迟最贵**。把 $g_{max}\!\left(\tau\right)$ 曲线读成一句话：反馈的信息越旧，你能用的力度就越小。这条规律不限于神经调控——它在[ PID](../52-control/40-pid-control.md) 的整定规则里、在分布式系统的共识算法里、在人类伸手抓物时视觉反馈的 100 ms 延迟里，都以同一个形式反复出现。

</details>
