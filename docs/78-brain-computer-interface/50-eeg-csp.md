# 脑电的正问题与反问题：源定位与空间滤波

## 1. 从一个场景开始

受试者想象自己**左手**在动，头皮上 64 个电极同时记录。屏幕上那条曲线看上去和"想象右手"时几乎一样——都是几十微伏的抖动。可如果把它们按通道两两组合、加权相减，两类任务的区别会突然从噪声里跳出来。

为什么"加权相减"这么灵？因为头皮脑电**根本不是源的形状**：皮层里一小簇神经元同步放电，电流穿过脑脊液、颅骨、头皮，被抹平、被扩散，最后每个电极收到的是**所有源的混合**。想从 64 个混合信号里恢复源，面对的是一个严重欠定的反问题。而脑机接口的聪明之处在于：**它不解反问题**。

## 2. 直觉解释

先分清两个方向的问题：

- **正问题（forward）**：已知源在哪里、多强，算头皮上会测到什么。这是物理，有唯一答案，可以算；
- **反问题（inverse）**：已知头皮测到什么，反推源在哪里。这是"欠定"的——64 个电极要定出成千上万个皮层位置上的电流，解**无穷多**。工程上只能加先验（最小范数、稀疏性）挑一个"最像话"的解。

脑机接口绕开了这道难题。它不问"源在哪"，只问一个更弱、但足够用的问题：**在通道空间里，有没有一个方向，让两类任务的信号"分得最开"？**

打个比方：房间里两个人在说话，两支麦克风收到的是两个声音的混合。你不必算出他们各自站在哪，只要找到一个**拾音方向**，让甲的声音相对乙被放大最多。这个方向就是**空间滤波器** $\mathbf{w}$；而"放大倍数"用两类信号的**方差比**来量。

## 3. 正式定义

### 正问题

把皮层电流分布离散成 $M$ 个源，每个源有三维偶极矩 $\mathbf{s}_m$，头皮电压 $\mathbf{x}(t)\in\mathbb{R}^{C}$ 是所有源的线性叠加加噪声：

$$\mathbf{x}(t) = A\,\mathbf{s}(t) + \boldsymbol{\eta}(t)$$

$A\in\mathbb{R}^{C\times 3M}$ 叫**导联场矩阵**（leadfield）：它是正问题的全部内容，由头模型的几何与电导率决定（常用三层球模型或有限元头模型），一旦头模型定了，$A$ 就可以算出来——**正问题有唯一解，反问题没有**。

### 反问题

给定观测 $\mathbf{x}$ 求 $\mathbf{s}$：因为 $3M \gg C$，$A$ 的零空间非平凡，满足 $A\mathbf{s} = \mathbf{x}$ 的 $\mathbf{s}$ 有无穷多个。要挑一个，必须加先验——最小范数解 $\hat{\mathbf{s}} = A^{\mathsf{T}}\left(AA^{\mathsf{T}}\right)^{-1}\mathbf{x}$ 是最常见的一种。**这一步的准确性直接受头模型误差与噪声摆布，所以临床上从不单独相信它。**

### 空间滤波：CSP

设两类任务下的通道信号都已被带通滤波成零均值，各自的协方差矩阵

$$\Sigma_c = \mathbb{E}\!\left[\mathbf{x}\mathbf{x}^{\mathsf{T}}\right]_{c}, \qquad c \in \left\lbrace 1, 2 \right\rbrace$$

**共同空间模式**（common spatial pattern，CSP）要找的方向是让方差比最大化的 $\mathbf{w}$：

$$J(\mathbf{w}) = \frac{\mathbf{w}^{\mathsf{T}}\Sigma_1\mathbf{w}}{\mathbf{w}^{\mathsf{T}}\Sigma_2\mathbf{w}}$$

这是**广义 Rayleigh 商**。令梯度为零，得到**广义特征值问题**：

$$\Sigma_1\mathbf{w} = \lambda\,\Sigma_2\mathbf{w}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mathbf{x}(t)$ | 通道信号 | 一个时刻上 $C$ 个电极的电压 |
| $A$ | 导联场矩阵 | 正问题的全部；源 → 头皮的线性映射 |
| $\Sigma_1, \Sigma_2$ | 两类协方差 | 带通滤波后的零均值信号，$C\times C$ 对称正定 |
| $\mathbf{w}$ | 空间滤波器 | 投到一维：$y(t) = \mathbf{w}^{\mathsf{T}}\mathbf{x}(t)$ |
| $\lambda$ | 广义特征值 | 就是那对方向上的方差比 |
| $\log\left(\mathbf{w}^{\mathsf{T}}\Sigma_c\mathbf{w}\right)$ | 对数方差特征 | 送进分类器（LDA）的实际特征，压掉尺度差 |

矩阵 $\Sigma_2^{-1}\Sigma_1$ 一般**不对称**，所以它的特征向量不互相正交；但 $\lambda$ 全是实数，且**最大与最小的特征向量正交**（在 $\Sigma_2$ 内积下）。CSP 的常规用法就是取 $\lambda$ 最大和最小的几对方向，各算一个对数方差——**最大方向是"类 1 最旺"，最小方向是"类 2 最旺"，一头一个，信息互补。**

## 4. 分步例题

**例**：两通道脑电，两类的协方差矩阵取

$$\Sigma_1 = \begin{pmatrix} 5 & 3 \\ 3 & 5 \end{pmatrix}, \qquad \Sigma_2 = \begin{pmatrix} 5 & -3 \\ -3 & 5 \end{pmatrix}$$

求 CSP 方向与对应的方差比。

**第 1 步 · 写出广义特征方程**：$\det\left(\Sigma_1 - \lambda\Sigma_2\right) = 0$。

**第 2 步 · 展开**：

$$\left(5 - 5\lambda\right)^2 - \left(3 + 3\lambda\right)^2 = 0$$

**第 3 步 · 解两个根**：$5 - 5\lambda = \pm\left(3 + 3\lambda\right)$，得到 $\lambda_1 = 4$、$\lambda_2 = 0.25$。**两个根的乘积是 1**——因为 $\det\Sigma_1 = \det\Sigma_2 = 16$，这可以当验算。

**第 4 步 · 求 $\lambda_1 = 4$ 对应的方向**：代回 $\left(\Sigma_1 - 4\Sigma_2\right)\mathbf{w} = 0$，矩阵是 $\begin{pmatrix} -15 & 15 \\ 15 & -15 \end{pmatrix}$，零空间由 $\mathbf{w}_1 = \left(1, 1\right)^{\mathsf{T}}$ 张成，方向 $45°$。

**第 5 步 · 验证方差比**：$\mathbf{w}_1^{\mathsf{T}}\Sigma_1\mathbf{w}_1 = 1\times 8 + 1\times 8 = 16$，$\mathbf{w}_1^{\mathsf{T}}\Sigma_2\mathbf{w}_1 = 2 + 2 = 4$，比值 $\mathbf{4}$ ✓ 与特征值一致。

**第 6 步 · 单位化后算对数特征**：$\mathbf{w}_1/\lVert\mathbf{w}_1\rVert$ 下，类 1 方差 $16/2 = 8$、类 2 方差 $4/2 = 2$。取对数：

$$\ln 8 = 2.0794, \qquad \ln 2 = 0.6931$$

两个数的差就是 $\ln 4 = 1.3863$——**这正是那一课"SPD 流形上两点距离"的前身**（下一课会看到它就是两个 $1\times 1$ 协方差之间的仿射不变距离）。

**第 7 步 · 另一头**：$\lambda_2 = 0.25$ 给出 $\mathbf{w}_2 = \left(1, -1\right)^{\mathsf{T}}$，类 1 方差 2、类 2 方差 8，正好反过来。所以 CSP 的两个极端方向是**同一件事的两面**：一个说"类 1 在这里最旺"，另一个说"类 2 在这里最旺"。

## 5. 动手实验

### 实验 1（lab）：拖判别方向，看方差比爬坡

```lab

  "title": "左：两类散点与 1σ/2σ 椭圆，红点可拖；右上：J(φ) 曲线；右下：投影到 w 上的一维分布",
  "theta": 45,
  "aspect": 2,
  "n": 60,
  "phi": 30
}
```

- 红点就是 $\mathbf{w}$ 的方向。拖它转一圈，右上角的 $J(\varphi)$ 曲线上的红线跟着走：**只有一个角度能顶到峰值 4.0**（灰色小圆点标出的就是广义特征向量的位置，默认参数下正好 45°）；
- 转到 **−45°（也就是 135°）**：$J$ 掉到 0.25——那是另一个极端方向；
- 看右下角的**两个一维分布**：当 $\varphi$ 对准 45° 时两个峰分得最开；转开一点，两团立刻糊在一起。**空间滤波的全部效果就是这句话的可视化**；
- 把 **aspect** 从 2 拖到 1：两类协方差变成同一只圆，$J$ 变成恒等于 1 的平线——**没有可分的结构，CSP 也无能为力**（这就是"这个受试者今天不适合做运动想象"的数学形态）；
- 把 **θ** 拖小：两个椭圆的主轴夹角变小，最优方向仍稳在 $\theta$ 处，但峰值从 4 掉下来——**两类越像，可分性越差**。

### 实验 2（python）：扫一圈角度，找方差比的峰值

```python
import math                        # 标准库：三角函数

S1 = [[5.0, 3.0], [3.0, 5.0]]      # 类 1 协方差
S2 = [[5.0, -3.0], [-3.0, 5.0]]    # 类 2 协方差

def quad(S, w):                    # 二次型 w'Sw
    return w[0] * (S[0][0] * w[0] + S[0][1] * w[1]) + w[1] * (S[1][0] * w[0] + S[1][1] * w[1])

best = (0.0, 0.0)                  # （方差比, 角度）
for deg in range(0, 180):          # 扫半圈就够：w 与 -w 给出同一个比值
    w = [math.cos(math.radians(deg)), math.sin(math.radians(deg))]
    ratio = quad(S1, w) / quad(S2, w)
    if ratio > best[0]:
        best = (ratio, float(deg))
print(f"扫描得到的最大方差比 {best[0]:.6f}，出现在 {best[1]:.0f}°")

for deg in (45.0, 135.0):
    w = [math.cos(math.radians(deg)), math.sin(math.radians(deg))]
    v1, v2 = quad(S1, w), quad(S2, w)
    print(f"phi = {deg:5.1f}°  var1 = {v1:5.2f}  var2 = {v2:5.2f}  "
          f"ratio = {v1 / v2:.4f}  log-var-diff = {math.log(v1 / v2):.4f}")
```

扫描会在 45° 处找到 4.000000，与第 3 步手算的广义特征值分毫不差；135° 处的对数方差差是 $-1.3863$，正是它的镜像。

### 快问快答

```quiz
CSP 为什么不先解反问题（定位源），而是直接在通道空间找方向？
- 因为反问题在数学上无解
- 因为解码只需要「可分」，不需要「定位」；反问题严重欠定，加先验反而引入额外误差 [*]
- 因为空间滤波比源定位更省算力，精度一样
? 反问题欠定（解无穷多），要挑一个必须加先验，头模型误差会直接污染结果；而 CSP 只求一个让两类方差比最大的方向，绕开了整道难题。
```

::::warning[常见误区]

**误区一**："CSP 找到的方向就是源的位置。"
你以为那个空间滤波器指向大脑里放电的那一小块皮层——它只是**通道空间里的一个方向**，是几十个电极读数的加权组合。它常与某个解剖位置对得上号（比如感觉运动区上方那对电极），但那是事后解释，不是前提。而且 $C$ 个通道的 CSP 给的是 $C$ 个方向，其中只有少数几个与任务有关，其余多半在拟合噪声。

**误区二**："协方差矩阵的非对角项可以先忽略。"
你以为对角线才是"每个通道自己的能量"——练习 1 里那对矩阵的可分性**全部**藏在 $\pm 3$ 这两个非对角项里。非对角项是通道之间的**相关性**，而脑电的空间结构（两个电极同时看到同一个源）恰恰就表现为相关性。丢掉它，等于宣布所有通道互不相干，CSP 会退化成"挑一个方差最大的通道"。

**误区三**："特征用得越多越好。"
你以为把 $C$ 个方向全送进分类器能榨干信息——方向越多，每个方向的方差估计就越不稳，而分类器的参数量随之上涨。标准做法是只取 $\lambda$ 最大与最小的各 1~3 对（共 2~6 个特征），其余丢掉。这也是 CSP 最容易被滥用的一点：**在几十个通道、几十个试次的数据上取全部特征，训练集准确率能到 95%，测试集却接近随机**。

::::

**练习 1**：算方向 $\mathbf{w} = \left(1, 1\right)^{\mathsf{T}}$ 上的方差比。下面的代码只取了协方差矩阵的对角项，把**非对角项**丢掉了：

```exercise
# @title: 练习：算空间滤波方向上的方差比
# @check: 4.0000
# @hint: 二次型 w'Sw 要展开成 w0*(S00*w0 + S01*w1) + w1*(S10*w0 + S11*w1)。这两类协方差的可分性**全部**藏在 ±3 这两个非对角项里，只留对角项的话两只椭圆就长得一模一样了。
S1 = [[5.0, 3.0], [3.0, 5.0]]      # 类 1 的两通道协方差
S2 = [[5.0, -3.0], [-3.0, 5.0]]    # 类 2
w = [1.0, 1.0]                     # 待评估的空间滤波方向

def var(S, w):                     # ← 问题在这：只取了协方差的对角项
    return S[0][0] * w[0] ** 2 + S[1][1] * w[1] ** 2

print(f"{var(S1, w) / var(S2, w):.4f}")
```

**练习 2**：回答三个问题。(a) 例题里两个广义特征值的乘积为什么恰好是 1？(b) 如果两类协方差完全一样，CSP 会给出什么？(c) 为什么实际送进分类器的是**对数**方差而不是方差本身？

<details>
<summary>点开查看逐步解答</summary>

1. (a) $\lambda_1\lambda_2 = \det\Sigma_1/\det\Sigma_2$：两个特征值之积等于两矩阵行列式之比。这里 $\det\Sigma_1 = 25 - 9 = 16$、$\det\Sigma_2 = 25 - 9 = 16$，所以乘积是 1。**这是一条随手就能验算的恒等式**，工程上常用它检查协方差估计有没有出问题；
2. (b) $\Sigma_1 = \Sigma_2$ 时 $J(\mathbf{w}) \equiv 1$：任何方向的方差比都是 1，$J(\varphi)$ 是一条平线，最大的方向**不唯一**（整个单位圆都是解），分类器拿不到任何信息。这正是实验里把 aspect 拖到 1 看到的现象；
3. (c) 方差是"能量"，量纲是 $\text{µV}^2$，且随受试者、电极阻抗、当天状态整体缩放——一个受试者的方差可能是另一个的十倍。取对数把**乘性差异变成加性差异**（$\ln\left(cv\right) = \ln c + \ln v$），整体缩放变成每维一个常数偏移，线性分类器可以直接减掉；此外对数还让方差近似服从正态分布，满足 LDA 的假设。这两条理由合起来，就是"对数方差特征"成为 EEG 分类标准做法的原因。

**为什么最大与最小特征向量正交**：广义特征向量满足 $\mathbf{w}_i^{\mathsf{T}}\Sigma_2\mathbf{w}_j = 0$（$i\ne j$），也就是在 $\Sigma_2$ 定义的内积下正交。所以"类 1 最旺"的方向与"类 2 最旺"的方向在**白化后**是垂直的——一头一尾取两对方向，拿到的是互相独立的两份证据。

</details>

## 7. 选读：正问题里的头模型，与反问题的先验

<details>
<summary>选读 · 导联场怎么算，最小范数解为什么糊</summary>

**导联场矩阵 $A$ 的来历**。在准静态近似下（脑电频率低于 1 kHz，电磁波长远大于头部尺寸），皮层电流产生的电位满足泊松方程。三层同心球模型（脑、颅骨、头皮，半径与电导率给定）有**解析解**：每个偶极子源对每个电极的贡献可以写成一条闭式公式。真实头型要用边界元（BEM）或有限元（FEM），从 MRI 分割出头皮、颅骨、脑脊液几层，再数值求解。**颅骨是关键**：它的电导率只有脑组织的几十分之一，把源"糊"得最厉害，也是脑电空间分辨率只有厘米级的根本原因（相比之下，皮层脑电 ECoG 把电极放在颅骨内，分辨率能到毫米）。

**最小范数解为什么糊**。$\hat{\mathbf{s}} = A^{\mathsf{T}}\left(AA^{\mathsf{T}}\right)^{-1}\mathbf{x}$ 是所有满足 $A\mathbf{s} = \mathbf{x}$ 的解里**欧氏范数最小**的那一个。它天然偏爱"到处都有一点点电流"的解，而不是"某一小簇电流很强"——因为前者范数更小。结果是定位结果被抹成一团弥散的斑，深度越深糊得越厉害（深层源的导联场更弥散）。改进方向就是换先验：

- **L1 稀疏先验**：假设只有少数几个源在活动，解出的是几个点（代价是非凸或需迭代）；
- **低分辨率电磁断层扫描（LORETA）**：惩罚电流的空间二阶导，偏爱"平滑但不弥散"的解；
- **波束成形（beamforming）**：不解全局反问题，而是对每个候选位置设计一个空间滤波器，让该位置的贡献通过、其余方向尽量压制——形式上与本课的 CSP 是同一套"找方向"的思路，只是目标函数换成了"单位增益下的输出功率最小"。

**与脑机接口的关系**：运动想象的经典特征（µ 节律在感觉运动区的去同步）在[脑电节律与伪迹地图](../61-digital-signal-processing/96-eeg-rhythms.md)里讲过它的频谱长相。CSP 找到的那个方向，事后往往可以和"感觉运动区上方那对电极"对上号——**但这是解释，不是前提**。解码器不需要这个解释就能工作，这正是工程与神经科学的健康分工。

</details>
