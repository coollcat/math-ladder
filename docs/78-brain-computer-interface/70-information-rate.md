# 神经编码能传多少比特：互信息与容量

## 1. 从一个场景开始

一个神经元每秒最多放几百个脉冲。假设它负责区分两个方向——向左、向右。要传完"往哪边"这一个二元选择，理论上只需要 **1 个比特**。它需要放几个脉冲才够？

答案可能小得让你吃惊：在合适的参数下，**平均 2.5 个脉冲就能传出 0.48 比特**——不到一个脉冲一个比特，但只是"不到一半"。而无论你把观察窗拉多长、加多少神经元，这个数字**永远追不上 1 比特**。卡住它的不是神经元的能力，而是**问题本身只有 1 比特**。

这一课要做的事：把"脉冲串里有多少信息"变成一个可以算的数，然后看清楚那个天花板是怎么来的。

## 2. 直觉解释

信息论测量信息的方式很朴素：**看一件事被观测前后，不确定性减少了多少**。

- 观测前，你不知道受试者想往左还是往右，两种可能各一半——不确定性是 **1 比特**（这就是熵 $H(S)$）；
- 观测后，你数到了一串脉冲。如果两种刺激下的脉冲分布**完全重叠**（都是平均 3 个），你什么都没学到，不确定性一点没减；
- 如果两个分布**分得开**（一个平均 4 个、一个平均 1 个），数完之后你基本能猜对，不确定性大幅下降。

**互信息 = 观测前的不确定性 − 观测后的不确定性**。它有一个绝对上限：**不可能超过观测前的那份不确定性**，也就是 1 比特。无论神经元多厉害、你记录多久——它们只能把这 1 比特里的信息榨干，变不出第 2 比特来。

这就是为什么"神经编码效率"这个词有意义：你可以在坐标轴上画一条 1 比特的水平线，然后看实际的互信息曲线怎么爬向它。

## 3. 正式定义

### 互信息

刺激 $S$ 以 $p(s)$ 取值，响应 $R$（这里是脉冲计数 $k$）的分布为 $p(k\mid s)$：

$$I(S;R) = \sum_{s}p(s)\sum_{k}p(k\mid s)\log_2\frac{p(k\mid s)}{p(k)}, \qquad p(k) = \sum_{s}p(s)\,p(k\mid s)$$

三个等价写法，各有各的好用之处：

$$I(S;R) = H(R) - H(R\mid S) = H(S) - H(S\mid R)$$

- $H(R)$：**响应熵**——光看脉冲数的不确定性；
- $H(R\mid S)$：**噪声熵**——知道了刺激之后，脉冲数还剩多少不确定性（这是"噪声"）；
- 两者相减就是"刺激解释掉的那部分不确定性"，也就是**信号**。

### 两个等概率刺激的泊松信道

$s\in\left\lbrace A, B\right\rbrace$、$p = 1/2$；刺激 $s$ 下的期望计数 $\lambda_s = T r_s$。条件分布是泊松：

$$p\!\left(k\mid s\right) = e^{-\lambda_s}\frac{\lambda_s^{k}}{k!}, \qquad p(k) = \frac{1}{2}p\!\left(k\mid A\right) + \frac{1}{2}p\!\left(k\mid B\right)$$

$$I = \frac{1}{2}\sum_{k}p\!\left(k\mid A\right)\log_2\frac{p\!\left(k\mid A\right)}{p(k)} + \frac{1}{2}\sum_{k}p\!\left(k\mid B\right)\log_2\frac{p\!\left(k\mid B\right)}{p(k)}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $H(S)$ | 刺激熵 | 两个等概率刺激时恰好 1 比特，**这就是容量上限** |
| $H(R)$ | 响应熵 | 计数分布的整体不确定性 |
| $H(R\mid S)$ | 噪声熵 | 同一刺激下计数的抖动，**这部分是白花的** |
| $I(S;R)$ | 互信息 | 真正的信息量，单位比特 |
| $I/\bar{k}$ | 每脉冲比特数 | 平均一个脉冲换回多少信息，衡量"编码效率" |

**关键结构**：$I$ 随观察窗 $T$ 单调增长，但**饱和**——$T\to\infty$ 时两个泊松分布彻底分开，$I\to H(S) = 1$ 比特。**$I$ 也随刺激下的发放率差 $\left|r_A - r_B\right|$ 增长，两者相等时 $I = 0$**。

## 4. 分步例题

**例**：两个等概率刺激，$r_A = 4$ sp/s、$r_B = 1$ sp/s，观察窗 $T = 1$ s。求互信息。

**第 1 步 · 期望计数**：$\lambda_A = 4$、$\lambda_B = 1$。

**第 2 步 · 边缘分布**：$p(k) = \frac{1}{2}e^{-4}4^k/k! + \frac{1}{2}e^{-1}/k!$。例如 $k=1$：$p = \frac{1}{2}\left(0.0733 + 0.3679\right) = 0.2206$。

**第 3 步 · 算响应熵**：把 $p(k)$ 代进 $-\sum p\log_2 p$，得到 $H(R) = 2.9314$ 比特。**注意它远大于 1**——因为计数可以取 0、1、2、3……很多个值，响应本身的不确定性当然比"二选一"大得多。

**第 4 步 · 算噪声熵**：同一刺激下计数仍有抖动，$H(R\mid A) = 3.0104$、$H(R\mid B) = 1.8825$（泊松分布的熵，后者小是因为 $\lambda = 1$ 时计数几乎只取 0 和 1），平均得 $H(R\mid S) = 2.4465$ 比特。

**第 5 步 · 相减**：

$$I(S;R) = 2.9314 - 2.4465 = \mathbf{0.4849}\ \text{比特}$$

**第 6 步 · 换算每脉冲比特数**：平均计数 $\bar{k} = \frac{1}{2}\left(4+1\right) = 2.5$，于是 $0.4849/2.5 = 0.1940$ 比特/脉冲。

**第 7 步 · 看它怎么随 $T$ 涨**（固定两个发放率 4 与 1 sp/s）：

| $T$ (s) | 0.05 | 0.1 | 0.2 | 0.5 | 1 | 2 | 5 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| $I$ (bit) | 0.0341 | 0.0669 | 0.1288 | 0.2879 | 0.4849 | 0.7224 | 0.9515 |
| 平均计数 $\bar{k}$ | 0.125 | 0.25 | 0.5 | 1.25 | 2.5 | 5 | 12.5 |
| $I/\bar{k}$ | 0.273 | 0.268 | 0.258 | 0.230 | 0.194 | 0.144 | 0.076 |

两个趋势正好相反：**总信息随 $T$ 涨，每脉冲效率随 $T$ 跌**。短窗时"有没有脉冲"这一条二值信息最值钱（一个脉冲就能把 $T=0.05$ s 内的两种情形分开大半）；窗一长，后面那些补充证据每个都更廉价。**这就是"首脉冲编码"在信息论上的位置**。

**第 8 步 · 天花板**：$T = 5$ s 已经到 0.9515，还剩 0.05 比特。要真正到 1 比特需要无穷长的时间——因为泊松分布永远有两个尾巴重叠。

- 看右侧两个分布的重叠：$T$ 很小时两个分布几乎完全叠在一起（橙色与蓝色柱子重合、白色虚线轮廓是个单峰），$T$ 一长就分成两座山。**"重叠面积"就是互信息的几何含义**；
- 把 **rB 拖到 4**（两刺激发放率相同）：两个分布完全重合，读数给出 $I = 0.0000$——**神经元再能放也没用，它根本没区分这两件事**；
- 把 **rA 拖到 30**：两个分布迅速分开，$T = 1$ s 时互信息已经贴到 **1.0000**（$\lambda_A = 30$ 与 $\lambda_B = 1$ 几乎不可能混淆），**每脉冲比特数却跌到 0.065**——一个"喊得响"的神经元信息传得多，但每个脉冲都不值钱；
- 把 **N 从 1 拖到 20**：左下那条曲线告诉你有意思的事——**加神经元与拉长窗的效果几乎一样**（都是增加独立证据），而且同样被封在 1 比特。真实系统里加神经元是**唯一**能突破"单窗时长"限制的办法，但突破不了刺激本身的熵。

### 实验 2（python）：两种算法算同一个互信息

```python
import math                        # 标准库：对数、阶乘

def pois(k, lam):                  # 泊松概率
    return math.exp(-lam) * lam ** k / math.factorial(k)

def entropy(pk):                   # 香农熵（比特）
    return -sum(p * math.log2(p) for p in pk if p > 0)

lamA, lamB, K = 4.0, 1.0, 40        # 两个刺激下的期望计数；K 是求和截断

# 算法一：I = H(R) - H(R|S)
pk = [0.5 * pois(k, lamA) + 0.5 * pois(k, lamB) for k in range(K + 1)]
hR = entropy(pk)                                             # 响应熵
hRs = 0.5 * entropy([pois(k, lamA) for k in range(K + 1)]) \
    + 0.5 * entropy([pois(k, lamB) for k in range(K + 1)])   # 噪声熵
print(f"H(R) = {hR:.6f}   H(R|S) = {hRs:.6f}   I = {hR - hRs:.6f} bit")

# 算法二：直接按定义逐项求和
mi = 0.0
for k in range(K + 1):
    pa, pb = pois(k, lamA), pois(k, lamB)
    p = 0.5 * pa + 0.5 * pb
    if pa > 0:
        mi += 0.5 * pa * math.log2(pa / p)
    if pb > 0:
        mi += 0.5 * pb * math.log2(pb / p)
print(f"按定义逐项求和 I = {mi:.6f} bit")
print(f"平均计数 {0.5 * (lamA + lamB):.1f}，每脉冲 {mi / (0.5 * (lamA + lamB)):.4f} bit")
```

两种算法给出同一个数 `0.484908`——第一种更快（只需要两个一维数组），第二种更贴近定义、也更不容易写错。

### 快问快答

```quiz
把一个神经元的观察窗从 1 秒拉到 10 秒，互信息会怎样？
- 大致线性增长到 10 倍
- 增长但越来越慢，最终趋近于刺激的熵（此处 1 比特） [*]
- 不变，因为发放率是稳定的
? 窗越长，两个泊松分布重叠越少，但重叠永远不为零；I 单调增且以 H(S) 为上界，所以只能逼近 1 比特，不可能超过。
```

::::warning[常见误区]

**误区一**："响应熵 $H(R)$ 就是神经元传递的信息量。"
你以为响应变化越多、信息越多——$H(R)$ 里**混着噪声**。例题里 $H(R) = 2.9314$ 比特，互信息只有 0.4849 比特，差的那 2.4465 比特全是"同一个刺激下计数自己抖"贡献的。判据很简单：**信息量不可能超过刺激的熵**，两个等概率刺激就是 1 比特，任何算出大于 1 的数都说明忘了减噪声熵（练习 1 的 bug 正是它）。

**误区二**："互信息到 1 比特说明编码效率 100%。"
你以为贴到天花板就是完美编码——天花板 $\log_2 2 = 1$ 比特是**任务给的**，不是神经元挣来的。换成一个八方向的任务，天花板变成 3 比特，同一条曲线立刻显得"远远不够"。互信息要跟**同一个任务的上界**比才有意义；这也是为什么评估编码器时必须先声明刺激集合。

**误区三**："多记一会儿就能拿到更多信息，没有上限。"
你以为时间可以无限换信息——$I$ 虽然随 $T$ 单调增，但上界是 $H(S)$，而且增量衰减得很快（$T$ 从 1 s 到 5 s，只从 0.4849 涨到 0.9515，还差最后 0.05 比特要无穷长的时间去追）。真实系统还有一个更硬的约束：**刺激本身在变**。窗一长，"速率恒定"的前提先塌，测出来的就不是同一个信道了。

::::

## 6. 练习

**练习 1**：算 $\lambda_A = 4$、$\lambda_B = 1$ 时的互信息。下面的代码只算了响应熵 $H(R)$ 就当成互信息输出了，得到 2.9314——**比 1 比特的天花板还大，显然不可能**：

```exercise
# @title: 练习：算泊松信道的互信息
# @check: 0.4849
# @hint: 互信息是「响应熵 H(R) 减掉噪声熵 H(R|S)」。噪声熵是两个条件分布各自熵的平均，忘了减就会算出大于 1 比特的数——而两个等概率刺激最多只能传 1 比特。
import math                        # 标准库：对数

def pois(k, lam):                  # 泊松概率 P(k | lam)
    return math.exp(-lam) * lam ** k / math.factorial(k)

lamA, lamB = 4.0, 1.0              # 两个等概率刺激下的期望脉冲数
K = 40                             # 计数求和截断

hR = 0.0                           # 响应熵 H(R)
for k in range(K + 1):
    pk = 0.5 * pois(k, lamA) + 0.5 * pois(k, lamB)
    if pk > 0:
        hR -= pk * math.log2(pk)
mi = hR                            # ← 问题在这：忘了减掉噪声熵 H(R|S)
print(f"{mi:.4f}")
```

**练习 2**：回答三个问题。(a) 若两个刺激下的发放率都是 3 sp/s，互信息是多少，为什么？(b) 例题的 $H(R) = 2.9314$ 比特大于 $H(S) = 1$ 比特，这不矛盾吗？(c) 每脉冲比特数随 $T$ 下降，是不是说明"长窗更浪费"？

<details>
<summary>点开查看逐步解答</summary>

1. (a) **0 比特**。两个刺激产生完全相同的分布，$p(k\mid A) = p(k\mid B) = p(k)$，代进定义每一项的 $\log_2 1 = 0$。直观上：观测结果与刺激**统计独立**，看多少眼都没用。这正是实验里把 rB 拖到 4 时的读数；
2. (b) 不矛盾。$H(R)$ 是**响应**的熵，它衡量"脉冲数有多少种可能"——计数能取 0 到 15 甚至更多，不确定性当然大。$H(S)$ 是**刺激**的熵，只有两种可能。互信息受后者约束（$I \le H(S)$），不受前者约束。**把 $H(R)$ 当信息量是这一课最经典的错误**，练习 1 的 bug 就是它；
3. (c) 不是浪费，是**边际收益递减**。总信息一直在涨（0.0341 → 0.9515），只是每个新增脉冲带来的增量越来越小。反过来看，短窗时每个脉冲极贵——这正是"首脉冲"在感觉系统里被特别看重的原因（[脉冲串的数学](./20-rate-coding.md)选读里提过）。工程上要权衡的是：**你付得起多长的延迟**（脑机接口要 20 ms 出一帧，就只能用短窗），以及**每个脉冲的代谢成本**。

**为什么容量恰好是 $H(S)$**：数据处理不等式给出 $I(S;R) \le H(S)$——对 $R$ 做任何（确定或随机的）处理都不会增加关于 $S$ 的信息。脉冲串本身就是 $S$ 经过神经元这道"信道"之后的输出，所以它携带的关于 $S$ 的信息，上限就是 $S$ 自己的不确定性。**想传更多，只能扩大刺激集合**（三个方向就是 $\log_2 3 = 1.585$ 比特，八个方向 3 比特）——这也解释了为什么脑机接口从"二分类想象"走向"多方向连续解码"时，理论容量一下子宽松了很多。

</details>

## 7. 选读：每脉冲几个比特，以及大脑为什么不追求最大化

<details>
<summary>选读 · 稀疏编码与代谢账本</summary>

**现实的数字**。皮层神经元在自然刺激下的平均发放率常在 1~10 sp/s，而互信息量级是每脉冲 1~3 比特，或"每秒几比特"。这个数字看着可怜，但要放在约束里看：大脑的能耗预算极其紧张（约 20 W，占全身 20%），而**产生一个脉冲的代谢代价极高**——主要花在动作电位之后钠钾泵把离子泵回去。所以真正被优化的目标不是 $I$，而是**每焦耳多少比特**。

**稀疏编码的算术**。假设有 $N$ 个神经元共同编码，每个时刻只有一小部分在放电。用群体互信息可以说明：在"总脉冲数给定"的约束下，把脉冲分摊到很多神经元上（每个都很少放）比让少数神经元狂放能传更多信息——因为 $N$ 个独立通道的容量随 $N$ 增长，而过高的单神经元发放率会撞上不应期与代谢上限。这就是稀疏编码的信息论理由。

**冗余不是浪费**。上面那笔账只算了"单个神经元能传多少"。真实皮层里神经元之间噪声高度相关，单看每个通道的信息会高估总量；但**冗余也带来鲁棒性**——几个神经元同时坏掉，行为不受影响。信息论在这里给出的不是"最优解"，而是一张**权衡表**：独立 → 容量大但脆弱；冗余 → 容量小但抗损。脑机接口的电极阵列设计（间距、覆盖区域、数量）本质上是在这张表上选点。

**一条可操作的结论**：评估一个解码器时，"准确率"是任务相关的，而**互信息是任务无关的上界**。先算 $I(S;R)$ 你就知道这场仗最多能打到什么程度——如果它只有 0.2 比特，那"三分类准确率 95%"之类的指标一定来自别的地方（比如试次选择、或数据泄漏）。

</details>
