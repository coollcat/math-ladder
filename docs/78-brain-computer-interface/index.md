# 脑机接口的数学

把一个电极插进运动皮层，你会看到一串**全同的尖峰**。刺激、行为、意图——所有区别都只能藏在这些脉冲的**时刻与疏密**里。这一章要做的，就是把"藏在里面"翻译成可以计算的数学：先是编码（刺激怎么变成脉冲），再是解码（脉冲怎么变回意图），最后是闭环（意图怎么变回刺激）。整条链上的工具你都已经在前六卷见过：一阶常微分方程、泊松分布、贝叶斯、卡尔曼滤波、广义特征值、黎曼度量、互信息、反馈稳定性。这一章不给新工具，只把它们摆到神经科学的战场上。

脑电的频谱、节律带与伪迹识别，已经在 [脑电节律与伪迹地图](../61-digital-signal-processing/96-eeg-rhythms.md) 与 [独立成分分析](../61-digital-signal-processing/97-ica-blind-source.md) 里讲透了。本章不重讲那些内容，只按需引用；重心放在**神经编码、解码、空间滤波与闭环**的数学。

## 路线图

1. [神经元为什么放电：膜电位与积分点火](./10-spike-model.md)——一只漏水的桶：灌进来的电流与漏掉的电流拔河，赢了就放电。
2. [脉冲串的数学：发放率、调谐曲线与点过程](./20-rate-coding.md)——同样的刺激，每次数到的脉冲数都不一样：抖动有多大，信息就有多少。
3. [神经解码 I：贝叶斯解码与群体向量](./30-bayesian-decoding.md)——每个神经元朝自己的偏好方向投一票，合力的方向就是答案。
4. [神经解码 II：卡尔曼滤波与光标控制](./40-kalman-decoding.md)——先用惯性猜、再用观测修正：Q 与 R 的比值决定光标是抖还是黏。
5. [脑电的正问题与反问题：源定位与空间滤波](./50-eeg-csp.md)——不解反问题，只找那个让两类方差比最大的方向。
6. [协方差的几何：SPD 流形上的脑电分类](./60-spd-manifold.md)——协方差不住在平直空间里：算术平均会把"体积"吹胀。
7. [神经编码能传多少比特：互信息与容量](./70-information-rate.md)——响应熵减噪声熵；两个刺激的容量上限就是 1 比特。
8. [闭环脑机接口：刺激、辨识与自适应](./80-closed-loop.md)——增益拖过头就自激；而延迟会悄悄吃掉你的增益预算。

## 方法主线

**编码 → 解码 → 闭环。**

前两课立起编码端：一个线性微分方程给出"电流到脉冲"的映射（第 1 课），一个泊松点过程给出"脉冲串的随机性有多大"（第 2 课）。第三条到第四条转向解码端，而且是一条**从静态到动态**的轴线：群体向量与贝叶斯解码把每一帧当成独立问题（第 3 课），卡尔曼滤波则把"运动惯性"这条时间先验加进去，让上一帧的估计参与这一帧的判断（第 4 课）。第五条到第七条换了一种信号来源与分析层次：从颅内单神经元换到头皮脑电，问题从"解出连续方向"变成"找一个可分的方向"（第 5 课）；协方差本身是分类的对象，于是必须面对它们所处的弯曲空间（第 6 课）；再往上抽象一层，用信息论给整条编码链算一个**与任务无关的上界**（第 7 课）。最后第八课把输出接回输入，闭环的数学麻烦——延迟吃增益——登场。四条主线在此收口：**编码决定信息上限，解码逼近这个上限，闭环则要在这个上限与稳定性之间同时活着。**

## 生产状态

本章八门课程全线成型，八个专属 lab 组件全部就绪（无外部资源依赖，全部用 canvas 现场绘制与模拟）：

- 积分点火实验能拖电流看它从沉默到周期放电，并对照 f–I 曲线与雷奥巴斯竖线；
- 调谐曲线实验能把刺激方向在极坐标上拖一圈，22 次试验的脉冲栅格随之重掷，同时给出 Fisher 信息；
- 群体向量实验能拖真实方向，对比"期望群体向量"与"单次抽样群体向量"，并暴露偏好方向不均匀时基线带来的偏差；
- 卡尔曼光标实验是完整的四状态二维滤波，位置协方差椭圆实时演化，还能直接拖走真实光标；
- CSP 实验能转判别方向，看方差比沿 $J(\varphi)$ 爬坡、一维投影分布随角度合拢；
- SPD 流形实验把 $2\times 2$ 协方差的形状部分画在上半个平面里，背景是最近均值分类的判定地图，行列式那一维可单独拖；
- 互信息实验能拖观察窗与神经元个数，看信息怎么逼近 1 比特的天花板，并直接显示两个计数分布的重叠；
- 闭环实验的稳定边界由数值扫描现算，能拖圆点改增益与延迟，也能切到开环辨识模式看最小二乘拟合出的极点。

## 实战挑战 · 从发放率到光标速度

四个神经元，偏好方向分别是 $0°$、$90°$、$180°$、$270°$；余弦调谐 $f_i = b + A\cos\left(\theta - \varphi_i\right)$，基线 $b = 5$ sp/s、调制深度 $A = 5$ sp/s。受试者想去的方向是 $30°$，观察窗 $T = 0.4$ s，解码增益取 $2$ mm/s（每个脉冲权重换 2 mm/s 的光标速度）。

下面这段代码把**发放率**（sp/s）当成了**脉冲计数**（个）去算群体向量，于是光标速度多了 $1/T = 2.5$ 倍。修到输出 `8.00 mm/s`：

```exercise
# @title: 实战挑战：从发放率到光标速度的解码链
# @check: 方向 30.0 度
# @check: 光标速度 8.00 mm/s
# @hint: 解码链是「发放率 → 乘上观察窗 T 换成计数 → 加权求和得群体向量 → 乘增益得速度」。群体向量的方向与 T 无关（atan2 的比值把 T 约掉了），但长度正比于 T——漏掉这一步，速度就凭空大了 1/T 倍。
import math                        # 标准库：三角函数与开方

pref = [0.0, 90.0, 180.0, 270.0]   # 四个神经元的偏好方向（度）
b, A = 5.0, 5.0                    # 基线发放率、调制深度（sp/s）
T = 0.4                            # 观察窗（s）
true_dir = 30.0                    # 受试者真正想去的方向（度）
gain = 2.0                         # 解码增益（mm/s 每单位权重）

rates = [b + A * math.cos(math.radians(true_dir - p)) for p in pref]

dx = sum(r * math.cos(math.radians(p)) for r, p in zip(rates, pref))   # ← 问题在这
dy = sum(r * math.sin(math.radians(p)) for r, p in zip(rates, pref))
speed = math.hypot(dx, dy) * gain
print(f"方向 {math.degrees(math.atan2(dy, dx)):.1f} 度")
print(f"光标速度 {speed:.2f} mm/s")
```

<details>
<summary>点开查看逐步解答</summary>

1. **四个发放率**：$f_i = 5 + 5\cos\left(30° - \varphi_i\right)$，依次是 $9.3301$、$7.5$、$0.6699$、$2.5$ sp/s；
2. **换成计数**：乘上 $T = 0.4$ s，得到 $3.7321$、$3.0$、$0.2679$、$1.0$ 个脉冲（合计 8 个）；
3. **扣掉基线**：$bT = 2$，权重变成 $1.7321$、$1.0$、$-1.7321$、$-1.0$。这一步在本例中不影响结果——四个偏好方向**均匀铺满一圈**时 $\sum_i \mathbf{u}_i = 0$，基线那份固定票会整体抵消（[神经解码 I](./30-bayesian-decoding.md) 的误区卡片专门讲了它的危险性：换一组不均匀的偏好方向，同样的代码立刻开始偏）；
4. **沿两轴求和**：$v_x = 1.7321 + 0 + 1.7321 + 0 = 3.4641$，$v_y = 0 + 1.0 + 0 + 1.0 = 2.0$；
5. **读方向与长度**：$\operatorname{atan2}\left(2.0, 3.4641\right) = 30.0°$，$|\mathbf{v}| = \sqrt{3.4641^2 + 2^2} = 4.0$。方向**分毫不差**，这不是巧合：把余弦调谐代进去，均匀偏好方向下 $\mathbf{v} = \frac{N}{2}AT\left(\cos\theta, \sin\theta\right)$，长度 $\frac{4}{2}\times 5 \times 0.4 = 4.0$；
6. **乘增益得速度**：$4.0 \times 2 = 8.00$ mm/s。初始代码直接用发放率（$5 + 5\cos$）求和，长度变成 $10.0$，速度输出 $20.00$ mm/s——方向依然正确，**错误只体现在长度上**，这正是最容易被忽略的一类 bug。

**这一课串起了什么**：第 2 课的调谐曲线给出第 1 步，第 3 课的群体向量给出第 4、5 步，第 4 课的"计数与发放率差一个 $T$"在这里变成了一行实打实的代码。真实系统还会在末端接上卡尔曼滤波（把逐帧的速度估计平滑成连续轨迹）与闭环安全限幅——那是后面几课的事。

</details>
