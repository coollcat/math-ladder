# 神经解码 II：卡尔曼滤波与光标控制

## 1. 从一个场景开始

上一课的贝叶斯解码有个奇怪的地方：它对**每一帧都从零开始猜**。可光标是连续的——这一帧的位置几乎完全由上一帧的位置和速度决定，跟这一帧的神经观测关系反而没那么大。把每帧当独立问题解，等于把最可靠的那条信息扔掉了。

真实的脑机接口（比如让瘫痪受试者用光标打字的那些系统）用的解码器叫**卡尔曼滤波**。它每一帧只做两件小事：先用"运动惯性"猜一下光标去哪了，再用这一帧的神经观测去修正。这件工具你在[卡尔曼滤波](../52-control/87-kalman-filter.md)那一课已经推过一遍；本课只做一件事：**把它落到神经数据上**，看清三个矩阵 $F$、$Q$、$R$ 分别对应大脑里的什么。

## 2. 直觉解释

想象你在黑屋子里接一个抛过来的球，眼睛每隔一小会儿才闪一下。

- **预测**：两次闪光之间，你不会傻站着——你按"球会沿刚才的方向继续飞"把位置往前推。这就是 $F$（运动模型）。推得越远，不确定度越大，这就是 $Q$（过程噪声）在给协方差"充气"；
- **更新**：闪光一来，你看到球在某个位置，但闪光本身有噪（$R$，观测噪声）。你不会直接跳过去，而是**按可信度加权**：观测越脏，越信自己的预测；预测越不确定，越信观测。

这两步交替，就是卡尔曼滤波的全部。它之所以在脑机接口里特别合适，是因为 $F$ 和 $Q$ 能把"手会平滑地动、不会瞬移"这条常识写进数学里——**而神经观测只负责修正，不负责从零定位**。

## 3. 正式定义

### 状态与两个方程

把光标的状态取成"位置 + 速度"四个数：$\mathbf{x} = \left(p_x, p_y, v_x, v_y\right)^{\mathsf{T}}$。

$$\mathbf{x}_t = F\mathbf{x}_{t-1} + \mathbf{w}, \qquad \mathbf{w}\sim\mathcal{N}\!\left(\mathbf{0}, Q\right)$$

$$\mathbf{z}_t = H\mathbf{x}_t + \mathbf{q}, \qquad \mathbf{q}\sim\mathcal{N}\!\left(\mathbf{0}, R\right)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $F$ | 状态转移矩阵 | 匀速模型下把 $p \leftarrow p + v\Delta t$，一块固定的常数矩阵 |
| $Q$ | 过程噪声协方差 | 手可以"临时改变主意"的程度；越大越信新观测 |
| $H$ | 观测矩阵 | 只取位置那两个分量：$H = \left[\mathbf{I}_2\ \ \mathbf{0}_2\right]$ |
| $R$ | 观测噪声协方差 | 神经观测有多脏；可由校准阶段的残差估出来 |
| $\mathbf{z}_t$ | 神经观测 | 从脉冲计数线性读出的一对位置估计（见选读） |
| $P_t$ | 后验协方差 | 此刻对状态的不确定度，画出来就是那只误差椭圆 |

### 预测–更新两步

$$\text{预测：}\quad \hat{\mathbf{x}}^- = F\hat{\mathbf{x}}, \qquad P^- = FPF^{\mathsf{T}} + Q$$

$$\text{更新：}\quad K = P^-H^{\mathsf{T}}\left(HP^-H^{\mathsf{T}} + R\right)^{-1}$$

$$\hat{\mathbf{x}} = \hat{\mathbf{x}}^- + K\left(\mathbf{z} - H\hat{\mathbf{x}}^-\right), \qquad P = \left(\mathbf{I} - KH\right)P^-$$

$K$ 叫**卡尔曼增益**，就是第 2 节那个"按可信度加权"的具体权重。$\mathbf{z} - H\hat{\mathbf{x}}^-$ 叫**新息**：观测与预测之间的差——滤波器只对"出乎意料的部分"做出反应。

### 三个矩阵分别对应什么

- $Q$ **大** → 预测很快就不可信，$K$ 接近 1 → 估计跟着观测抖（**光标会抖**）；
- $Q$ **小** → 滤波器笃信"手在匀速飞"，$K$ 小 → 观测再吵它也不动（**光标发黏、跟不上**）；
- $R$ **大** → 观测不可信，等效于把 $Q$ 调小。

**它们是同一个旋钮的两端**，真正决定行为的是比值 $Q/R$。

## 4. 分步例题

先用标量版把两步算一遍（位置随机游走 + 带噪观测，[卡尔曼滤波](../52-control/87-kalman-filter.md)那一课的原型）。

**设定**：$q = 1\ \text{mm}^2$（过程噪声方差）、$r = 4\ \text{mm}^2$（观测噪声方差）、初值 $\hat{x}_0 = 0$、$P_0 = 1$；两帧的观测都是 $z = 3.0$ mm。

**第 1 帧**

1. 预测：$\hat{x}^- = 0$，$P^- = P_0 + q = 1 + 1 = 2$；
2. 增益：$K = 2/\left(2 + 4\right) = 1/3$；
3. 更新：$\hat{x} = 0 + \frac{1}{3}\left(3 - 0\right) = 1.0$；
4. 协方差：$P = \left(1 - \frac{1}{3}\right)\times 2 = \frac{4}{3} = 1.3333$。

**第 2 帧**

5. 预测：$\hat{x}^- = 1.0$，$P^- = \frac{4}{3} + 1 = \frac{7}{3} = 2.3333$；
6. 增益：$K = \frac{7/3}{7/3 + 4} = \frac{7}{19} = 0.3684$（**比第 1 帧更大**：预测走得越远越不可信，就越该听观测的）；
7. 更新：$\hat{x} = 1.0 + \frac{7}{19}\left(3 - 1.0\right) = \frac{33}{19} = 1.7368$；
8. 协方差：$P = \left(1 - \frac{7}{19}\right)\times\frac{7}{3} = \frac{28}{19} = 1.4737$。

**读一下这三个数**：两次同样的观测 $z = 3$，估计值却从 1.0 爬到 1.74。因为预测步一直把估计往"上一帧的自己"拉（$\hat{x}^- = 1.0$），而观测把它往 3.0 拉，平衡点就在中间——**这正是"惯性"在起作用**。若观测一直报 3.0，估计会收敛到 3.0；若观测只报一次就消失，估计会慢慢滑回去。

## 5. 动手实验

### 实验 1（lab）：拖噪声，看光标是抖还是黏

```lab
{
  "type": "bci-kalman-cursor",
  "title": "二维匀速模型：橙=真实光标，蓝=卡尔曼估计，粉圈=位置协方差（2σ），橙点是神经观测；拖动 q / r 改变滤波器性格",
  "q": 30,
  "r": 25,
  "rho": 0.6,
  "every": 2
}
```

- 点「播放」，看蓝色估计如何**贴着橙色真实轨迹**走，而橙色观测点（脏数据）在周围乱飞。粉圈是 $2\sigma$ 的位置不确定度：观测刚来时缩小，两帧之间被 $Q$ **充气**又慢慢变大；
- 把 **q 拖到很大**（比如 300）：粉圈撑开，蓝点开始跟着观测抖——滤波器变得神经质；
- 把 **q 拖到很小**（比如 1）：蓝点变得**发黏**，转弯处明显滞后于橙色真值。这就是"太信惯性"的代价；
- 把 **r 拖大**：效果与调小 q 相同——再次确认真正起作用的是比值 $Q/R$；
- 右上那四根柱子是当前的卡尔曼增益 $K$。它自己会稳定到一个**稳态值**（这一现象在[卡尔曼滤波](../52-control/87-kalman-filter.md)里讲过：$P$ 收敛后 $K$ 不再随时间变），所以实时系统可以事先把 $K$ 算好，每帧只做一次矩阵乘法；
- 拖动画布可以直接**拽走真实光标**：松手后看估计怎么追上来，那几帧的滞后量就是这套参数下的"跟手性"。

### 实验 2（python）：两步滤波与稳态增益

```python
q, r = 1.0, 4.0                    # 过程噪声方差、观测噪声方差（mm^2）
x, P = 0.0, 1.0                    # 位置估计初值、不确定度初值

for step, z in enumerate((3.0, 3.0), start=1):     # 两帧观测都报 3.0 mm
    P = P + q                         # 预测：均值不动（随机游走），不确定度长大
    K = P / (P + r)                   # 卡尔曼增益 = 预测不确定度 / 总不确定度
    x = x + K * (z - x)               # 更新：按增益把估计拉向观测
    P = (1 - K) * P                   # 更新：不确定度收缩
    print(f"第 {step} 帧  K = {K:.6f}  x = {x:.6f}  P = {P:.6f}")

# 稳态：反复预测+更新直到 P 不再变，此时的 K 就是实时系统预存的那一个
x, P = 0.0, 1.0
for _ in range(200):
    P = P + q
    K = P / (P + r)
    P = (1 - K) * P
print(f"稳态增益 K∞ = {K:.6f}（对应稳态不确定度 P∞ = {P:.6f}）")
```

输出会先给出 $1.000000$ 与 $1.736842$，再给出稳态增益 $K_\infty = 0.390388$。稳态由不动点方程 $P_\infty = \frac{\left(P_\infty + q\right)r}{P_\infty + q + r}$ 定出，代入 $q = 1$、$r = 4$ 得 $P_\infty^2 + P_\infty - 4 = 0$，即 $P_\infty = \frac{-1 + \sqrt{17}}{2} = 1.561553$，再回代就是 $K_\infty = 0.390388$。**注意它比前两帧的增益都小**：观测一直报同一个数时，滤波器越来越确信自己已经到位，于是每一帧只肯挪一小步。

### 快问快答

```quiz
过程噪声 Q 调得越小，解码出的光标会怎样？
- 更平滑，但转弯时明显滞后于真实意图 [*]
- 更抖，因为滤波器开始逐帧相信观测
- 与 R 无关，只影响初始收敛速度
? Q 小等于「笃信匀速惯性」，滤波器对观测的反应变迟钝：轨迹更平滑，代价是转弯滞后；真正与它对抗的是观测噪声 R，起作用的是比值 Q/R。
```

::::warning[常见误区]

**误区一**："卡尔曼滤波是一种平滑滤波，相当于给光标做低通。"
你以为它和滑动平均是同类——滑动平均是**固定的加权**，卡尔曼的权重 $K$ 由两个噪声方差**实时算出来**，而且预测协方差 $P$ 每一步都在根据模型变化。它更像"一个会自己算该信谁的估计器"：同一个滤波器，观测变脏时它会自动更信模型。把它当成低通，就完全丢掉了这套自适应机制。

**误区二**："$Q$ 和 $R$ 是两个独立的旋钮。"
你以为可以分开调——真正起作用的是**比值 $Q/R$**。实验里"把 $q$ 调小"和"把 $r$ 调大"产生几乎一样的轨迹，因为它们都降低了对观测的信任。工程上调参通常固定 $R$（校准阶段估出来），只调 $Q$ 一个标量。

**误区三**："卡尔曼滤波能纠正解码器的系统性偏差。"
你以为估计值最终会收敛到真实位置——它收敛到**模型与观测的加权折中**。若观测 $\mathbf{z}_t$ 本身带一个恒定偏差（电极漂移、校准不当），滤波器会忠实跟踪那个偏移的位置；稳态增益 $K_\infty \lt 1$ 意味着这个偏差**永远只是被缩小，不会被消除**。要消偏差得先修观测，或者显式给状态加一个偏置项。

::::

## 6. 练习

**练习 1**：用手写递推跑两帧标量卡尔曼，把每帧更新后的位置估计打印出来。下面的代码在预测步漏掉了过程噪声 $q$，于是第一帧估计明显偏小：

```exercise
# @title: 练习：两帧卡尔曼递推
# @check: 1.000000
# @check: 1.736842
# @hint: 预测步是「均值不动、不确定度长大」：P 要先加上 q。漏掉这一项，滤波器会以为自己比实际更有把握，估计就拉不到位。
q = 1.0            # 过程噪声方差（mm^2）：光标每一步能自己走多远
r = 4.0            # 观测噪声方差（mm^2）：神经观测有多脏
P = 1.0            # 位置估计的不确定度初值
x = 0.0            # 位置估计初值
for z in (3.0, 3.0):          # 两次神经观测都报 3.0 mm
    K = P / (P + r)           # ← 问题在这：预测步漏掉了过程噪声 q
    x = x + K * (z - x)       # 更新：按增益把估计往观测拉
    P = (1 - K) * P
    print(f"{x:.6f}")
```

**练习 2**：回答三个问题。(a) 第 1 帧的增益是 $1/3$，第 2 帧变成 $7/19 \approx 0.368$，为什么**变大**了？(b) 若把 $q$ 设成 0（认为手绝对匀速），两帧的估计会变成什么？(c) 为什么实时脑机接口可以预先算好一个常数增益？

<details>
<summary>点开查看逐步解答</summary>

1. (a) 因为预测步把不确定度**加了 $q$**：$P^-$ 从 2 涨到 $7/3$。预测走得越远越不可信，观测的相对可信度就上升，增益自然变大。这也是卡尔曼滤波的自动调节机制——**它自己知道什么时候该多听观测**；
2. (b) $q = 0$ 时预测不增加不确定度，第一帧 $K = 1/5 = 0.2$、$\hat{x} = 0.6$；第二帧 $P^- = 0.8$、$K = 0.8/4.8 = 1/6$、$\hat{x} = 0.6 + \frac{1}{6}\times 2.4 = 1.0$。这正是练习里那段"漏掉 $q$"的代码输出的数——**两帧估计 0.6 与 1.0，明显低估**，因为滤波器误以为自己很有把握，每次只肯挪一小步；
3. (c) $P$ 的递推**与观测无关**（只看 $F, Q, H, R$ 这四个矩阵），所以它会在若干帧内收敛到一个不动点 $P_\infty$，增益随之固定为 $K_\infty$。工程上在校准阶段解一次 Riccati 方程把 $K_\infty$ 算好、烧进固件，运行时每帧只剩一次矩阵乘法——这是脑机接口能做到"每 20 ms 出一帧"的关键。本课实验里右上那四根柱子稳定不动的现象，就是 $K$ 收敛的直接可视化。

</details>

## 7. 选读：从脉冲计数到观测向量，泊松那一步去哪了

<details>
<summary>选读 · 线性高斯近似与点过程滤波</summary>

卡尔曼滤波要求观测方程是**线性 + 高斯**的，可上一课告诉我们：脉冲计数服从泊松分布，均值等于方差——这是**异方差**（噪声大小随信号大小变），与"固定的 $R$"直接冲突。真实系统怎么处理？

**路子一：线性高斯近似（本课实验用的就是这个）**。把 $N$ 个神经元的计数先映射成一个"位置读数"：

$$\mathbf{z}_t = W\mathbf{k}_t + \mathbf{b}$$

$W$ 由校准阶段的最小二乘（或[最优线性估计](../21-linear-algebra-advanced/80-least-squares.md)）拟合出来。中心极限定理在这里救场：**几十上百个神经元的加权和**，其分布已经相当接近高斯，异方差也被平均掉。代价是"计数少时噪声更大"这一信息没被利用。

**路子二：先把方差稳住**。泊松变量的平方根近似是方差稳定的：$\sqrt{k}$ 的方差约为 $1/4$，与均值无关。先做 $k \mapsto 2\sqrt{k}$ 再送进线性高斯框架，$R$ 就真的接近常数了。这是一行代码的改动，在低发放率神经元上收益明显。

**路子三：点过程滤波（对待脉冲最诚实）**。不数计数，直接用每个脉冲的**精确时刻**构造条件强度 $\lambda_i(t)$，然后写贝叶斯递推：

$$p\!\left(\mathbf{x}_t \mid \mathcal{H}_t\right) \propto p\!\left(\mathbf{x}_t \mid \mathcal{H}_{t-1}\right)\prod_{i}\lambda_i(t)^{n_i(t)}e^{-\lambda_i(t)\Delta t}$$

它不再是高斯后验，只能用数值方法（拉普拉斯近似、粒子滤波）传播。好处是把"这一帧有没有脉冲"的全部信息都吃干榨净，尤其是在**低发放率**时明显更准；代价是算力。近年的实时脑机接口正朝这条路上走。

**选哪条？** 校准数据充足、神经元多、发放率不低 → 路子一足够，而且它快得可以忽略不计；神经元少或发放率低 → 路子三的增益才值得那份算力。任何一条路上，模型参数（$F, Q, R$ 或 $W$）都必须在**真正的闭环使用中**重新校准：开着光标让受试者追目标，用残差重估噪声，这就是下一课"闭环"的开头。

</details>
