# 数学归纳法：无穷步的通行证

## 1. 从一个场景开始

上一课的高斯公式 $1+2+\cdots+n = \frac{n(n+1)}{2}$，我们只在 $n=100$ 时验证过。可公式声称的是：**对每一个自然数**都成立——一亿、十亿、随便哪个。逐个验算？一辈子也验不完。

人类发明了一种只花三行推理、却能管住无穷多个结论的方法，名字叫**数学归纳法**。它的灵感你小时候就玩过：推倒第一块骨牌。

## 2. 直觉解释

一排无限长的多米诺骨牌，怎样才能保证**全部倒下**？只要两件事：

1. **第一块被推倒**；
2. **任意一块倒下时，它与下一块的间距足够近，能把下一块带倒**。

两件事同时成立，就没有任何一块能站着：第 1 块倒（事实 1）→ 带倒第 2 块（事实 2）→ 带倒第 3 块……像点燃的引信一样传遍整排。注意：**从头到尾没有碰过"无穷"这个怪物**，我们只保证了两个有限的事实，无穷张骨牌的命运就被锁定了。

## 3. 正式定义

要证明命题 $P(n)$ 对所有满足 $n \ge n_0$ 的自然数成立，只需两步：

| 步骤 | 内容 | 骨牌对应 |
| --- | --- | --- |
| 基础情形 | 验证 $P(n_0)$ 成立（通常是 $n=1$） | 推倒第一块 |
| 归纳步骤 | 假设 $P(k)$ 成立，推出 $P(k+1)$ 也成立 | 保证每块能带倒下一块 |

归纳步骤里那句"假设 $P(k)$ 成立"叫**归纳假设**——它不是耍赖地假设结论，而是把它当成临时踏板去够更高的台阶。两步齐备后即可宣布：对所有 $n \ge n_0$，$P(n)$ 成立。

少一步都不行：只做基础情形，是"抽查了一次"；只做归纳步骤，等于间距再合适却没人推第一块——整排骨牌纹丝不动。

## 4. 分步例题

**例**：用数学归纳法证明 $1 + 2 + \cdots + n = \dfrac{n(n+1)}{2}$。

记 $P(n)$ 为"$S_n = 1 + 2 + \cdots + n$ 等于 $\frac{n(n+1)}{2}$"。

1. **基础情形**：$n=1$ 时，左边 $=1$，右边 $= \frac{1 \times 2}{2} = 1$，相等 ✓；
2. **归纳假设**：设 $P(k)$ 成立，即 $S_k = \frac{k(k+1)}{2}$；
3. **推下一步**：$S_{k+1} = S_k + (k+1) = \frac{k(k+1)}{2} + (k+1) = \frac{(k+1)(k+2)}{2}$——这正是公式在 $n=k+1$ 处的样子 ✓;
4. 结论：基础与传导都落实，公式对所有 $n \ge 1$ 成立。∎

第 3 步的关键动作只有一次代数变形：把 $\frac{k(k+1)}{2} + (k+1)$ 通分提出公因式 $(k+1)$。整个证明没有出现"无穷"，却覆盖了无穷多个等式。

## 5. 动手实验

### 实验 1（viz）：亲手折断归纳链


怎么玩：点「推倒第一块」，看倒下的势头一路传到底；拖动滑杆把间距拉大再推——某一处够不着了，后面的骨牌全体幸存。**这就是归纳步骤断裂**：哪怕前面倒得再多，断口之后的结论一个都不保。「重站」复位后再试不同间距。

### 实验 2（python）：大规模抽查，然后保持清醒

```python title="高斯公式抽查一千次"
def gauss_formula(n):            # 定义函数：算公式的值
    return n * (n + 1) // 2      # // 是整除，结果不会丢精度

bad_count = 0                    # 记录"对不上"的次数
for n in range(1, 1001):         # n 从 1 到 1000
    total = 0
    for k in range(1, n + 1):    # 笨办法：一项一项加
        total = total + k
    if total != gauss_formula(n):
        bad_count = bad_count + 1

print(f"一千次抽查中不一致的次数: {bad_count}")
```

怎么玩：结果是 0——一千次全对。但请记住第 1 章的老话：抽查提供信心，不提供保证。真正的保证来自第 4 节那个三行证明；代码的价值在于**提前暴露公式写错**的情形（不信就把 `// 2` 删掉再跑）。

### 实验 3（python 滑块）：抽查"素数制造机"，亲手抓反例

误区一预告过那台传奇的"素数制造机" $n^2+n+41$。现在把它交到你手上：拖动起点，看它从哪里开始连续报对，又在哪里第一次翻车：

```python title="n²+n+41 从 start 一路查下去"
# sliders: start=0 [0:39:1]

for n in range(start, 46):             # 从起点 start 一路查到 n=45
    value = n * n + n + 41             # 那个"四十连中"的多项式
    factor = 0                         # 存找到的最小因数；0 表示还没找到
    for d in range(2, value):          # 试除法：从 2 起挨个问"你整除它吗"
        if value % d == 0:             # % 取余数：余 0 说明 d 整除 value
            factor = d
            break                      # 找到因数，提前收工
    if factor == 0:
        print(f"n={n}: {value} 是素数")
    else:
        print(f"n={n}: {value} = {factor} × {value // factor} ← 第一个合数！")
        break                          # 抓到反例，扫描结束
```

怎么玩：默认 start=0 时，屏幕会连刷**四十行"是素数"**——放在没有计算器的年代，谁敢怀疑它？然后第 41 行当场翻车：$1681 = 41 \times 41$（把 $n=40$ 代回去恰好凑出 $41^2$）。把 start 拖到 35 再跑：只中了五次就崩了；拖回 0，四十连中的假象又回来了。无论从哪站出发，翻车的总是同一站——**抽查一万次也堵不住第 10001 次**，这正是归纳法要解决的信任危机。

### 快问快答

```quiz
归纳法证明中，"假设 P(k) 成立"这一步是在干什么？
- 承认整个命题已被证明
- 把 P(k) 当临时踏板，去推导 P(k+1) [*]
- 检查 P(k) 是否真的成立
? 归纳假设只是工作假设：若它成立则下一步也成立。它必须搭配"基础情形"才构成完整证明。
```

:::warning[常见误区]

**误区一**："你以为验证了前一万项就算证明。" 其实有限次验证永远是抽查。数学史上著名的反例：多项式 $n^2+n+41$ 在 $n=0,1,2,\dots,39$ 连续四十个取值全是素数；可 $n=40$ 时它给出 $41^2=1681$，当场翻车。四十连中，不如归纳法一行推理。

**误区二**："你以为归纳步骤可以单独成立。" 骨牌实验已经演示过：间距全对但没人推第一块，整排照旧站立。基础情形不是走过场——有些公式恰好从 $n=2$ 才开始成立，漏查 $n=1$ 就会闹出笑话。

**误区三**："你以为归纳假设是'假设要证的结论'所以循环论证。" 循环论证是用结论证结论；归纳法只用 $P(k)$ 推 $P(k+1)$ 这一级台阶，起点由基础情形独立提供，链条有头有尾，逻辑闭合。

:::

**练习 2**：第 1 章曾发现"前 n 个奇数之和恰为 $n^2$"（25=5², 100=10²）。试用归纳法证明它。

<details>
<summary>点开查看逐步解答</summary>

记 $P(n)$：$1 + 3 + 5 + \cdots + (2n-1) = n^2$。

- 基础情形：$n=1$ 时左边 $=1$，右边 $=1^2=1$ ✓；
- 归纳步骤：假设前 k 个奇数之和为 $k^2$。第 $k+1$ 个奇数是 $2(k+1)-1 = 2k+1$，于是前 $k+1$ 个之和 $= k^2 + (2k+1) = (k+1)^2$ ✓。

两步俱全，命题对所有 $n$ 成立。第 1 章埋下的种子，今天正式开花。
</details>

**练习 3**：某同学想用归纳法证明"所有自然数都小于 100"，他这样设计：基础情形 $n=1 < 100$ ✓；归纳步骤：假设 $k<100$，则 $k+1<101<\dots$ 卡住了。问题出在哪？

<details>
<summary>点开查看逐步解答</summary>

归纳步骤推不过去：$k=99$ 时 $k+1=100$，不再小于 100——**传导在第 99 与第 100 块之间断了**，相当于骨牌间距过大。

这个例子还提醒我们：归纳法的结论范围与"传导能到达的范围"一致。"对所有 $n \le 99$ 成立"倒是真能证出来的——传导到哪，结论就跟到哪。
</details>

## 7. 选读：凭什么归纳法合法？

<details>
<summary>选读 · 最小反例论证</summary>

归纳法为什么可信？用"最小反例"反过来想一遍：假如归纳的两步都完成了，命题却仍对某个自然数不成立，那么"使 $P(n)$ 不成立的自然数集合"非空——而任何非空的自然数集合必有最小元素（这是自然数的核心性质，称**良序原理**）。

设最小的反例是 $m$。它不可能是 $n_0$，因为基础情形已验证 $P(n_0)$ 成立；也不可能是更大的数，因为 $m-1$ 更小、不是反例，即 $P(m-1)$ 成立，而归纳步骤保证 $P(m)$ 也随之成立——矛盾。

两头堵死，反例根本无法存在，命题对所有自然数成立。归纳法不是经验法则的放大，而是"自然数长什么样"这条公理的直接推论——这也是为什么皮亚诺公理体系（第 1 章选读提过）把它列为基本原理之一。

</details>
