# 递推数列求通项：把"下一步"翻译成"第 n 步"

## 1. 从一个场景开始

某款背单词 App 的签到奖励是这样定的：第 $n$ 天得到的金币数 $a_n$ 满足

$$a_{n+1} = 2a_n + 1, \qquad a_1 = 1$$

也就是"明天的金币 = 今天的金币翻一倍 + 1"。第一天 1 枚，第二天 3 枚，第三天 7 枚……第 30 天有多少枚？

一步步推当然能推出来，但要推 29 次，而且数字越滚越大。更要命的是：如果老板临时把规则改成"翻三倍加 5"，你又得从头推一遍。我们想要的是一张**直达电梯**——一个只含 $n$ 的公式 $a_n = f(n)$，代进 30 就出答案，改规则只需改两个数字。

## 2. 直觉解释

先别急着算，看清楚这条规则每走一步干了什么：**先乘 2，再平移 1**。任何"缩放 + 平移"的合成动作，都有一个特殊的点——**不动点**：一个数 $t$ 满足"乘 2 加 1 之后还是它自己"，即 $t = 2t + 1$，解得 $t = -1$。

不动点有什么用？把所有项的坐标原点搬到 $-1$ 上去试试：定义 $b_n = a_n - (-1) = a_n + 1$。那么

$$b_{n+1} = a_{n+1} + 1 = (2a_n + 1) + 1 = 2(a_n + 1) = 2b_n$$

看，$b$ 就是纯正的等比数列（公比 2）——"+1"这个小尾巴被坐标平移吸收掉了。**离不动点越远的部分，每步被放大 2 倍**；不动点本身纹丝不动。这就是全部秘密。

一句话记忆：**先找一个"站得住"的不动点，把原点挪过去，剩下的就是等比**。同样的思路还能对付更复杂的尾巴（多项式、指数式），只是"挪原点"要换成"挪一整条曲线"。

## 3. 正式定义

**一阶线性递推**：形如 $a_{n+1} = p\,a_n + f(n)$ 的递推关系，其中 $p$ 是常数，$f(n)$ 只依赖于 $n$、不含 $a$。它的每一步都是"先把上一项乘 $p$，再加上一个只与步数有关的量"。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p$ | 系数 | 每步对上一项的放大倍数（$p \neq 0$） |
| $f(n)$ | 自由项 | 每步额外加上的量，也叫"驱动项" |
| $c$ | 平移量 | 把它加到 $a_n$ 上之后，新数列变等比 |
| $t = -c$ | 不动点 | 满足 $t = pt + q$ 的常数，即 $t = \dfrac{q}{1-p}$ |

四类"尾巴"各有各的消法（$A$、$B$、$C$ 都是待定系数，靠对比两边系数解出来）：

| 类型 | 递推式 | 怎么把尾巴消掉 | 通项公式 |
| --- | --- | --- | --- |
| 常数尾 | $a_{n+1} = p a_n + q\;(p \neq 1)$ | 令 $c = \dfrac{q}{p-1}$，则 $a_n + c$ 是等比 | $a_n = (a_1 + c)\,p^{\,n-1} - c$ |
| 一次式尾 | $a_{n+1} = p a_n + kn + b$ | 令 $A = \dfrac{k}{p-1}$、$B = \dfrac{b+A}{p-1}$，则 $a_n + An + B$ 是等比 | $a_n = (a_1 + A + B)\,p^{\,n-1} - An - B$ |
| 指数式尾 | $a_{n+1} = p a_n + d\lambda^n\;(\lambda \neq p)$ | 令 $C = \dfrac{d}{p-\lambda}$，则 $a_n + C\lambda^n$ 是等比 | $a_n = (a_1 + C\lambda)\,p^{\,n-1} - C\lambda^n$ |
| 累加型 | $a_{n+1} - a_n = f(n)$ | 逐项相加，左边中间项正负抵消 | $a_n = a_1 + \sum\limits_{k=1}^{n-1} f(k)$ |
| 累乘型 | $\dfrac{a_{n+1}}{a_n} = f(n)$ | 逐项相乘，中间项上下约掉（要求各项非 0） | $a_n = a_1 \cdot \prod\limits_{k=1}^{n-1} f(k)$ |

前三类是同一招：**猜一个和 $f(n)$ 同形状的函数，加（减）到 $a_n$ 上，让新数列变成等比**，再用等比通项公式收工。常数尾看似最简单，反而最容易记成硬背的公式——记住它的来历是"平移到不动点"，就不会跟 $p=1$ 的情形打架（$p=1$ 时 $c$ 的分母为 0，公式直接报废，此时它就是等差数列）。

## 4. 分步例题

**例 1（常数尾）**：$a_{n+1} = 2a_n + 1$，$a_1 = 1$。

1. 求不动点：$t = 2t + 1 \Rightarrow t = -1$，于是 $c = -t = 1$；
2. 验证：$a_{n+1} + 1 = 2a_n + 2 = 2(a_n + 1)$——$\{a_n + 1\}$ 是公比 2 的等比；
3. 写等比通项：$a_n + 1 = (a_1 + 1)\cdot 2^{\,n-1} = 2 \cdot 2^{\,n-1} = 2^n$；
4. 解出：$a_n = 2^n - 1$。

检验：$n=1$ 得 1 ✓，$n=2$ 得 3 ✓，$n=3$ 得 7 ✓。所以第 30 天是 $2^{30} - 1 = 1073741823$ 枚。

**例 2（一次式尾）**：$a_{n+1} = 3a_n + 4n + 2$，$a_1 = 1$。

1. 读参数：$p = 3$，$k = 4$，$b = 2$；
2. 解待定系数：$A = \dfrac{4}{3-1} = 2$，$B = \dfrac{2 + 2}{3-1} = 2$；
3. 于是 $a_n + 2n + 2$ 是公比 3 的等比：$a_n + 2n + 2 = (1 + 2 + 2)\cdot 3^{\,n-1} = 5\cdot 3^{\,n-1}$；
4. 解出：$a_n = 5\cdot 3^{\,n-1} - 2n - 2$。

检验：$n=1$ 得 $5-2-2=1$ ✓；$n=2$ 得 $15-4-2=9$，而递推给 $3\times 1 + 4 + 2 = 9$ ✓；$n=3$ 得 $45-6-2=37$，递推给 $3\times 9 + 8 + 2 = 37$ ✓。

**例 3（指数式尾）**：$a_{n+1} = 2a_n + 3^n$，$a_1 = 1$。

1. 读参数：$p = 2$，$\lambda = 3$，$d = 1$，且 $\lambda \neq p$，可以用表中的公式；
2. 解待定系数：$C = \dfrac{1}{2-3} = -1$；
3. 于是 $a_n - 3^n$ 是公比 2 的等比：$a_n - 3^n = (1 - 3)\cdot 2^{\,n-1} = -2^n$；
4. 解出：$a_n = 3^n - 2^n$。

检验：$a_2 = 2\times 1 + 3 = 5 = 9 - 4$ ✓；$a_3 = 2\times 5 + 9 = 19 = 27 - 8$ ✓。

**例 4（累加型）**：$a_{n+1} - a_n = 2n$，$a_1 = 1$。

1. 把 $n = 1, 2, \dots, n-1$ 的等式全部写出来：$a_2 - a_1 = 2$，$a_3 - a_2 = 4$，…，$a_n - a_{n-1} = 2(n-1)$；
2. 全部相加，左边中间的 $a_2, \dots, a_{n-1}$ 一正一负全消掉，只剩 $a_n - a_1$；
3. 右边是 $\sum_{k=1}^{n-1} 2k = 2\cdot\frac{(n-1)n}{2} = n(n-1)$；
4. 所以 $a_n = 1 + n(n-1) = n^2 - n + 1$。

检验：$1, 3, 7, 13, 21, \dots$，相邻差为 $2, 4, 6, 8$ ✓。

**例 5（累乘型）**：$\dfrac{a_{n+1}}{a_n} = \dfrac{n}{n+1}$，$a_1 = 1$。

1. 把 $n = 1, \dots, n-1$ 的等式全部相乘；
2. 左边：$\frac{a_2}{a_1}\cdot\frac{a_3}{a_2}\cdots\frac{a_n}{a_{n-1}} = \frac{a_n}{a_1}$，中间全部约掉；
3. 右边：$\frac{1}{2}\cdot\frac{2}{3}\cdot\frac{3}{4}\cdots\frac{n-1}{n} = \frac{1}{n}$（同样上下约净）；
4. 所以 $a_n = \dfrac{1}{n}$。

检验：$1, \frac12, \frac13, \frac14, \dots$，验证 $\frac{a_2}{a_1} = \frac{1/2}{1} = \frac{1}{2} = \frac{1}{1+1}$ ✓。

### 实验 3（python）：递推与公式，两条路必须对上

```python title="递推 30 步 vs 一步到位"
p = 2                                # 每步放大倍数
q = 1                                # 每步加的常数
a1 = 1                               # 首项
c = q // (p - 1)                     # 待定系数 c = q/(p-1)，这里恰好整除

a = a1
vals = [a]
for n in range(1, 12):               # 从 a1 推到 a12，共 11 步
    a = p * a + q
    vals.append(a)
print("递推前 12 项:", vals)

def formula(n):                      # def 定义函数：输入序号 n，输出第 n 项
    return (a1 + c) * p ** (n - 1) - c

for n in [1, 6, 12, 30]:
    print(f"n={n}: {formula(n)}")

print("第 12 项对得上吗:", vals[11] == formula(12))
```

怎么玩：递推给出 $[1, 3, 7, 15, 31, 63, 127, 255, 511, 1023, 2047, 4095]$，公式在 $n=12$ 处也给出 4095，最后一行打印 `True`。把 `p`、`q` 改成别的数（比如 3 和 6——`q` 恰好能被 `p-1` 整除，代码里的 `//` 才不会把 `c` 磨掉零头；要是选 3 和 5，`c` 会被磨成 2 而不是 2.5，两条路当场分家）再跑一次，两条路依然吻合——**公式不是背下来的，是被递推反复验证出来的**。

### 实验 4（python 滑块）：累加型与累乘型

```python title="累加型与累乘型：把 n-1 步的账一次结清"
# sliders: N=8 [2:20:1]

# —— 累加型：a(n+1) - a(n) = 2n，a1 = 1 ——
a = 1
add_row = [a]
for n in range(1, N):                # 从 a1 走到 aN 只要 N-1 步，所以循环 N-1 次
    a = a + 2 * n
    add_row.append(a)
add_fml = []
for n in range(1, N + 1):
    add_fml.append(n * n - n + 1)    # 通项 n^2 - n + 1（例 4 的结论）
print("累加型 递推:", add_row)
print("累加型 公式:", add_fml)

# —— 累乘型：a(n+1) / a(n) = n/(n+1)，a1 = 1 ——
b = 1.0
mul_row = [1.0]
for n in range(1, N):
    b = b * n / (n + 1)              # 每一步乘上 f(n)
    mul_row.append(round(b, 4))      # round(x, 4)：保留 4 位小数，免得长尾刷屏
mul_fml = []
for n in range(1, N + 1):
    mul_fml.append(round(1 / n, 4))
print("累乘型 递推:", mul_row)
print("累乘型 公式:", mul_fml)
```

怎么玩：拖动 $N$，两行输出永远一模一样。注意循环只跑 $N-1$ 次——**从 $a_1$ 到 $a_N$ 是 $N-1$ 步**，和"第 1 排到第 100 排只迈 99 步"是同一个坑。

## 6. 常见误区

::::warning[常见误区]

- **"你以为 $a_{n+1} = p a_n + q$ 的通项公式对任何 $p$ 都能用。"** 其实 $p = 1$ 时 $c = \frac{q}{p-1}$ 的分母为 0，公式当场报废。此时递推就是 $a_{n+1} = a_n + q$——**等差数列**，通项 $a_n = a_1 + (n-1)q$，压根不需要待定系数。套公式之前先问一句"分母会不会是 0"，这是第 1 课就立下的规矩。
- **"你以为累加型要加到 $n$。"** 其实只加到 $n-1$：$a_n = a_1 + \sum_{k=1}^{n-1} f(k)$。从 $a_1$ 走到 $a_n$ 是 $n-1$ 步，等式也只写了 $n-1$ 条。检验办法：代 $n=1$ 回去，求和是空的，必须得 $a_1$。
- **"你以为待定系数时左边照抄 $An + B$ 就行。"** 其实左边是**下一步**，必须写 $A(n+1) + B$。展开对比后才得到正确的 $\;A = \frac{k}{p-1}$、$B = \frac{b+A}{p-1}$；漏掉那个 "+A"，解出来的 $B$ 会偏一步，越往后错得越离谱。

::::

**练习 2**：求递推 $a_{n+1} = 3a_n - 4n - 2$，$a_1 = 5$ 的通项。

<details>
<summary>点开查看逐步解答</summary>

1. 读参数：$p = 3$，$k = -4$，$b = -2$；
2. 待定系数：$A = \dfrac{-4}{3-1} = -2$，$B = \dfrac{-2 + (-2)}{3-1} = -2$；
3. 于是 $a_n - 2n - 2$ 是公比 3 的等比，首项 $a_1 - 2 - 2 = 1$；
4. 所以 $a_n - 2n - 2 = 3^{\,n-1}$，即 $a_n = 3^{\,n-1} + 2n + 2$。

检验：$a_1 = 1 + 2 + 2 = 5$ ✓；$a_2 = 3\times 5 - 4 - 2 = 9$，公式给 $3 + 4 + 2 = 9$ ✓；$a_3 = 3\times 9 - 8 - 2 = 17$，公式给 $9 + 6 + 2 = 17$ ✓。

**练习 3**：求递推 $a_{n+1} - a_n = 2n + 1$，$a_1 = 1$ 的通项，并猜猜它为什么这么眼熟。

<details>
<summary>点开查看逐步解答</summary>

累加型：$a_n = 1 + \sum_{k=1}^{n-1}(2k+1) = 1 + 2\cdot\frac{(n-1)n}{2} + (n-1) = 1 + n^2 - n + n - 1 = n^2$。

数列是 $1, 4, 9, 16, 25, \dots$——**完全平方数**。这不是巧合：$(n+1)^2 - n^2 = 2n+1$，所以"每次加一个奇数"恰好就是平方数的生成规则。第 1 章《加法》的练习里发现的"前 $n$ 个奇数之和等于 $n^2$"，在这里有了一个代数的说法。

</details>

## 8. 选读：当指数尾巴撞上公比

<details>
<summary>选读 · 共振：待定系数解不出来的那一种情况</summary>

第 3 节"指数式尾"那行写着条件 $\lambda \neq p$。撞车时会怎样？看这个例子：

$$a_{n+1} = 2a_n + 2^n, \qquad a_1 = 1$$

照原办法试：设 $a_{n+1} + C\cdot 2^{\,n+1} = 2(a_n + C\cdot 2^n)$，展开得 $a_{n+1} = 2a_n + 2C\cdot 2^n - C\cdot 2^{n+1} = 2a_n + 0$——**$C$ 被完全消掉了**，无论取几都构造不出 $2^n$ 这一项。原因很直白：我们要消掉的东西（$2^n$）和等比部分自己长的形状（也是 $2^n$）是同一个东西，平移不掉。

出路是**多乘一个 $n$**：改设 $a_n = n\cdot C\cdot 2^{n-1} + (\text{等比部分})$。代入 $a_{n+1} = 2a_n + 2^n$：

$$(n+1)C\cdot 2^n = 2\cdot nC\cdot 2^{\,n-1} + 2^n = nC\cdot 2^n + 2^n$$

两边消去 $nC\cdot 2^n$，得 $C\cdot 2^n = 2^n$，即 $C = 1$。于是 $a_n = n\cdot 2^{\,n-1} + K\cdot 2^{\,n-1}$，代 $a_1 = 1$ 得 $1 + K = 1$，即 $K = 0$：

$$a_n = n\cdot 2^{\,n-1}$$

检验：递推给出 $1, 4, 12, 32, 80, 192, \dots$，公式给出 $1\times 1, 2\times 2, 3\times 4, 4\times 8, 5\times 16, 6\times 32$ ✓。

这种"驱动项的频率和系统的固有频率相同"的现象叫**共振**——物理上推秋千推在点上会越荡越高，数学上表现为解里多出一个 $n$ 因子。第 61 章《冲激响应与差分方程》里它会换个名字重新登场。

**本课不管什么**：二阶及以上的递推（$a_{n+2} = p\,a_{n+1} + q\,a_n$，斐波那契就是它的明星成员）。它们要解一个叫**特征方程**的二次方程，是本站第 28 章《递推与特征方程》的正题，那里也会补上斐波那契通项公式（比奈公式）的完整推导。

</details>
