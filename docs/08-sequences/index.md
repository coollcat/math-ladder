# 数列与归纳法：一格一格的数学

第 6 章的函数是一条连绵不断的曲线——横轴上随便指一个点，它都有答案。但生活中很多问题只按"一格一格"发生：存钱按月结息、细胞按轮分裂、兔子按季生崽。把横轴切成格子、只在整数位置上取值的函数，叫**数列**——它是函数的离散表亲，却有自己的独门武器：**数学归纳法**。前 7 章我们验证规律靠抽查一万次，这一章你将学会一件更厉害的事：**用有限的三步推理，管住无穷多个结论**。归纳法就是通往无穷步的通行证。

1. [等差与等比](./10-arith-geom.md)——每次加固定值 vs 每次乘固定值，两种最朴素的生长节奏；
2. [求和记号 Σ](./11-sigma.md)——高斯的配对绝技，以及"把一串加法压缩成一个符号"的记号；
3. [数学归纳法](./20-induction.md)——推倒第一块骨牌 + 保证每块都能推倒下一块 = 推倒所有骨牌；
4. [二项式定理与杨辉三角](./25-binomial-theorem.md)——(a+b)^n 的展开通式，先猜规律再用归纳法盖章；counting 组件一枚一枚"数"出每个系数；
5. [斐波那契与递归](./30-fibonacci.md)——一对兔子繁衍出的数列，每一项都由前两项定义，黄金比在门口等你。

学完这章，你会拿到两件终身受用的工具：一眼看穿"加法生长"与"乘法生长"的公式；以及面对"对所有自然数都成立"这类断言时，一条严格证明的标准流程。下一章我们把这套离散的眼光投向另一类问题：一件事有多少种可能？——计数、概率与统计。

## 实战挑战 · 数列与归纳法

**改编自 2023 年高考北京卷第 14 题（"环权"问题）**：我国度量衡历史悠久，战国时期就出现了类似砝码的、用来测量物体质量的"环权"。一道真题把等差与等比缝在了同一串数里——这正是本章两种"生长引擎"的同台演出。

**题目**：考古队清理出 9 枚环权，质量（单位：铢）从小到大恰好构成数列 $a_1, a_2, \ldots, a_9$。已知**前 3 枚成等差数列**，**后 7 枚（从 $a_3$ 到 $a_9$）成等比数列**，且 $a_1 = 1$，$a_5 = 12$，$a_9 = 192$。

- (a) 求公比 $q$ 与第二枚的质量 $a_2$；
- (b) 求第 7 枚环权的质量 $a_7$；
- (c) 求 9 枚环权的总质量。

下面的代码能跑但结果不对（公比那步先算错了），把它修到通过：

```exercise
# @title: 练习：九枚环权
# @check: 48
# @check: 384
# @hint: q 的 4 次方等于 a9/a5 = 16，所以 q = 2（不是 4）；注意用 // 整除保持整数；a7 在等比段排第 5 位，指数是 4 不是 2；(c) 别忘了把 a3 本身也加进总数：先加前三枚，再从 a4 一路乘着累加到 a9
a1 = 1
a5 = 12
a9 = 192

q = 4                        # ← 第一步就错了：什么数的 4 次方等于 192/12 = 16？
a3 = a5 // q ** 2            # 由 a5 = a3 × q² 反推第 3 枚
d = (a3 - a1) // 2           # 前 3 枚成等差：a3 = a1 + 2d
a2 = a1 + d                  # 顺手把第 2 枚也请出来

a7 = a3 * q ** 2             # ← 第 7 枚在等比段里排第 5 位，指数该是几？

total = a1 + a2 + a3          # 前三枚先记上（别漏了 a3 自己）
g = a3                        # 从 a3 出发，沿等比段走到 a9
for i in range(6):
    g = g * q                 # 下一枚 = 当前 × 公比
    total = total + g

print(a7)
print(total)
```

<details>
<summary>点开查看逐步解答</summary>

**(a) 求公比与 $a_2$**：等比段里 $a_5$ 与 $a_9$ 隔了 $9-5=4$ 步，所以 $q^4 = \frac{a_9}{a_5} = \frac{192}{12} = 16$，得 $q = 2$（质量从小到大，取正根）。回推 $a_3 = a_5 \div q^2 = 12 \div 4 = 3$。前三枚成等差：$d = (a_3 - a_1)/2 = 1$，于是 $a_1, a_2, a_3 = 1, 2, 3$。

**(b) 求第 7 枚**：$a_7$ 在等比段（$a_3$ 起步）里排第 5 位，走 4 步：$a_7 = a_3 \times q^4 = 3 \times 16 = 48$。

**(c) 求总和**：等比段 7 项为 $3, 6, 12, 24, 48, 96, 192$，和为 $\frac{3(2^7 - 1)}{2 - 1} = 381$。注意这段从 $a_3$ 起步，而 $a_3$ 也是"前三枚"里的最后一枚；用它自己的求和结果时，只需再补上前面两项 $a_1+a_2=1+2=3$，总计 $381+3=384$。这样 $a_3$ 恰好只算一次。

验算代码：

```python
seq = [1, 2]
g = 3
for i in range(6):
    seq.append(g)
    g = g * 2

print(seq)          # [1, 2, 3, 6, 12, 24, 48, 96, 192]
print(seq[6])       # a7 = 48
total = 0
for v in seq:
    total = total + v
print(total)        # 384
```

自查：逐项检验——前三枚相邻差恒为 1 ✓；从第 3 枚起相邻比恒为 2 ✓。

</details>

## 实战挑战 · 从 1 加到 100 的边界

高斯小时候秒算的题：$1 + 2 + \dots + 100$ 等于多少？用循环累加时，最容易错的是**终点边界**——`range(1, 100)` 只走到 99。下面这题就栽在边界上，修到输出 `5050`：

```exercise
# @title: 实战挑战：range 的终点边界
# @check: 5050
# @hint: range(1, 100) 只生成 1 到 99；要含 100，终点得写 101。
total = 0
for n in range(1, 100):    # ← 问题在这：漏掉了 100 本身
    total = total + n
print(total)
```

<details>
<summary>点开查看逐步解答</summary>

Python 的 `range(a, b)` 生成 $a$ 到 $b-1$，**不含 $b$**。要累加到 100，终点必须写 101：

```python
for n in range(1, 101):    # 1 到 100（含两端）
    total = total + n
print(total)               # 5050
```

改完输出 $5050$，与高斯公式 $\frac{100\times101}{2}=5050$ 一致。初始代码停在 99，少了整整 100。边界"差一"是循环编程的头号陷阱，本章等差数列的"$n-1$ 步"易错点与此同源。

</details>
