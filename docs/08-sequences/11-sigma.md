# 求和记号 Σ：高斯的配对绝技

## 1. 从一个场景开始

十九世纪的德国小学课堂上，老师为了让学生安静一上午，在黑板上留了一道题：把 $1+2+3+\cdots+100$ 全加起来。几分钟后，一个九岁的男孩交出了答案：5050。

他没列竖式，甚至没怎么动笔。这个叫高斯的孩子用了一个所有同学都能看懂、却没人想到的招数。这一课我们先偷学这招，再认识数学家用它配套发明的一个记号：$\Sigma$（大写希腊字母，读作"西格玛"）。

## 2. 直觉解释

高斯的招数叫**配对**：把数列首尾两端各取一个凑成对——

$$1+100 = 101, \quad 2+99 = 101, \quad 3+98 = 101, \dots \quad 50+51 = 101$$

每一对的和都是 101，一共 50 对。所以总和 $= 50 \times 101 = 5050$。

换个角度看：把整串数**正着写一遍、倒着写一遍**，上下对齐相加——

$$\begin{aligned} S &= 1 + 2 + \cdots + 100 \\ S &= 100 + 99 + \cdots + 1 \\ 2S &= 101 + 101 + \cdots + 101 = 100 \times 101 \end{aligned}$$

两行错开的规律恰好互相补齐，这就是"倒序相加"。

## 3. 正式定义

**求和记号**：把"通项为 $a_k$ 的前 $n$ 项之和"压缩成一个符号：

$$S_n = \sum_{k=1}^{n} a_k$$

| 部件 | 名字 | 含义 |
| --- | --- | --- |
| $\Sigma$ | 求和号 | "下面这些统统加起来"的指令 |
| $k=1$ | 下标 | 计数器 k 从 1 开始报数 |
| $n$ | 上标 | 报到 n 为止（含 n 本身） |
| $a_k$ | 通项 | 把当前报到的 k 代进去得到的第 k 项 |

比如 $\displaystyle\sum_{k=1}^{4}(2k) = 2+4+6+8 = 20$：k 依次取 1, 2, 3, 4，每回算一次 $2k$，全加。

**等差数列前 n 项和公式**（倒序相加的成果）：上下两行逐位相加，每一位都是 $a_1 + a_n$，共 n 位，于是

$$S_n = a_1 + a_2 + \cdots + a_n = \frac{n(a_1 + a_n)}{2}$$

人话版：**总和 = 项数 × (首项 + 尾项) ÷ 2**，本质是"平均数 × 个数"。代 $a_n = a_1 + (n-1)d$ 进去，还能变形为 $S_n = \frac{n(2a_1 + (n-1)d)}{2}$——两个版本等价，按已知条件挑顺手的用。

## 4. 分步例题

**例**：求偶数列 $2 + 4 + 6 + \cdots + 100$ 的总和。

1. 认结构：这是 $a_1 = 2$、$d = 2$ 的等差数列；
2. 数项数：第 $n$ 项是 $2n$，令 $2n = 100$ 得 $n = 50$ 项；
3. 找尾项：$a_{50} = 100$；
4. 套公式：$S_{50} = \dfrac{50 \times (2 + 100)}{2} = 50 \times 51 = 2550$。

反过来也要会翻译：$\displaystyle\sum_{k=1}^{20}(3k+1)$ 读作"k 从 1 报到 20，每回算 $3k+1$ 再全加"，即 $4 + 7 + 10 + \cdots + 61$——首项 4、公差 3、恰好 20 项。**Σ 记号和普通加法写法必须能自由互译**，这是后面课程的语言基本功。

## 5. 动手实验

### 实验 1（viz）：盯住 Sₙ 怎么长个儿

```viz
{
  "type": "seq",
  "kind": "arith",
  "a1": 1,
  "d": 1,
  "n": 12
}
```

怎么玩：这是 $1, 2, 3, \dots$ 的楼梯。慢慢拖大 n，左上角的紫色数字 $S_n$ 跟着变：$n=3$ 时 $6$，$n=4$ 时 $10$……对照公式 $\frac{n(n+1)}{2}$ 心算验证几个。再把 d 拧成别的值，看 $S_n$ 的增速如何随公差改变。

### 实验 2（python）：累加器 vs 公式，殊途同归

笨办法是一个一个加；聪明办法是一行公式。结果必须一致——不一致说明有 bug：

```python title="两种算法对答案"
# sliders: n=100 [10:2000:10]

total = 0                        # 累加器清零
for k in range(1, n + 1):        # range 终点取不到，所以要写 n+1
    total = total + k            # 累加器：旧总和加上新的一项
print(f"循环累加: {total}")

formula = n * (n + 1) // 2       # 高斯公式；// 是整除，n(n+1) 必为偶数不会丢精度
print(f"公式直算: {formula}")
```

怎么玩：拧动滑杆，两行输出永远相同。循环要跑 n 圈，公式只算一步——当 n 是十亿时差距就是"跑几天"和"眨个眼"的区别。**先暴力、再找公式**，正是本站反复演示的数学工作流。

### 实验 3（python 滑块）：亲眼看见高斯的配对

公式背得再熟，不如亲眼看一遍配对过程。拖动滑杆换不同的 $n$，盯住每一对的和：

```python title="首尾配对：每一对的和都相等"
# sliders: n=10 [2:100:2]

half = n // 2                    # 整除：偶数 n 恰好配成 n/2 对
pair_sum = 1 + n                 # 每一对的和：最头上的 1 加最尾上的 n
shown = 0                        # 计数器：只打印前三对，免得刷屏
for k in range(1, half + 1):     # k 从 1 报到 half：逐对从头尾两端取
    if shown < 3:
        print(f"{k} + {n + 1 - k} = {pair_sum}")
        shown = shown + 1
print(f"... 共 {half} 对，每对的和都是 {pair_sum}")
print(f"总和 = {half} × {pair_sum} = {half * pair_sum}")
```

怎么玩：$n=10$ 时打印出 $1+10$、$2+9$、$3+8$——全是 11，共 5 对，$5 \times 11 = 55$ 与实验 2 的公式一致。把滑杆一路拖到 100：不管 $n$ 多大，"对和恒等于 $n+1$"纹丝不动——这就是高斯绝技的全部秘密，也是第 4 节公式 $\frac{n(n+1)}{2}$ 的直观来历。（滑杆步长为 2，只产生偶数 $n$，保证恰好两两配对；奇数的情形见误区二。）

### 快问快答

```quiz
Σ(k²)，k 从 1 到 4，等于多少？
- 30 [*]
- 24
- 100
? k 取 1、2、3、4，各项是 1、4、9、16，总和 30。先把每一项算出来再加，别急着套任何公式。
```

:::warning[常见误区]

**误区一**："你以为上标减下标就是项数。" 其实 $\sum_{k=1}^{n}$ 有 **n 项**而不是 $n-1$ 项——从 1 层楼走到 n 层楼，走的是 n 层。通用公式：项数 $=$ 上标 $-$ 下标 $+1$。

**误区二**："你以为配对法要求项数是偶数。" 其实奇数项时中间落单那一项恰好在正中央，它自己就等于平均值，倒序相加照样严丝合缝——公式对所有 n 成立。

**误区三**："你以为公式里的'首尾'只能是整个数列的第一项和最后一项。" 其实用的是"**这段**的首尾"：从第 5 项加到第 100 项，就用项数 96 乘 $(a_5 + a_{100})/2$。截取中间一段，公式照用。

:::

## 6. 练习

**练习 1**：用公式计算 $\displaystyle\sum_{k=1}^{20}(3k+1)$。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：Σ(3k+1) 等于多少
# @check: 650
# @hint: 通项是 3k+1，代码里丢了这个尾巴上的 +1；也可以套公式：首项 4、末项 61、共 20 项
n = 20
total = 0
for k in range(1, n + 1):
    total = total + 3 * k
print(total)
```

改完后再心算一遍检验：$3 \times \frac{20 \times 21}{2} + 20 = 630 + 20 = 650$ ✓。

**练习 2**：存款计划第一个月存 1000 元，以后每月比上月多存 500 元。一年下来总共存了多少？

<details>
<summary>点开查看逐步解答</summary>

等差数列：$a_1 = 1000$，$d = 500$，共 12 个月。

末项 $a_{12} = 1000 + 11 \times 500 = 6500$；总和 $S = \frac{12 \times (1000 + 6500)}{2} = 6 \times 7500 = 45000$ 元。
</details>

**练习 3**：为什么倒序相加后，上下两位相加总是同一个数？用第 5 项和倒数第 5 项举例说明。

<details>
<summary>点开查看逐步解答</summary>

设数列为 $a_1, \dots, a_n$。倒数第 5 项是 $a_{n-4}$，而 $a_5 + a_{n-4} = a_1 + 4d + a_n - 4d = a_1 + a_n$——公差带来的偏移正好互相抵消。

任何一对"位置对称"的项都如此：一个多走几步，另一个就少走几步，步数之和恒为 $n-1$。这就是每一列的和都等于 $a_1 + a_n$ 的原因。
</details>

## 7. 选读：等比数列也能求和

<details>
<summary>选读 · 错位相减法，以及 r=1 的特例</summary>

等比数列没法配对（每对的和都不一样），但可以**乘 r 再错开相减**。以 $r=2$、共 n 项为例：

$$S = a_1 + a_1 r + a_1 r^2 + \cdots + a_1 r^{n-1}$$

两边同乘 r：$rS = a_1 r + a_1 r^2 + \cdots + a_1 r^n$。两式上下对齐，中间一大段完全相同，相减全部消掉，只剩两头：

$$rS - S = a_1 r^n - a_1 \quad\Longrightarrow\quad S = \frac{a_1(r^n - 1)}{r - 1}$$

现在兑现上一课的警告：分母是 $r - 1$，当 $r = 1$ 时它等于 0，公式当场报废。而 $r=1$ 时数列就是同一个数抄 n 遍，$S = n \cdot a_1$，直接乘就行——特例根本不需要公式。

"乘一个数让大部分项错位抵消"，这招在第 15 章无穷级数里还要大显身手。

</details>
