# 裂项相消与倒序相加：让一长串加法自己塌掉

## 1. 从一个场景开始

老师在黑板上写下 99 个分数：

$$\frac{1}{1\times 2} + \frac{1}{2\times 3} + \frac{1}{3\times 4} + \cdots + \frac{1}{99\times 100}$$

通分？分母是 $2$ 到 $9900$ 的一大堆数，最小公倍数大得写不下。一项一项化成小数再相加？要按 99 次计算器，还一定会有舍入误差。

可是这串数的答案干净得离谱：**0.99**。不是约等于，是精确等于 $\frac{99}{100}$。

一堆分母互不相同的分数加在一起，怎么会得到这么整齐的结果？因为它们在相加的途中**互相抵消**了——中间的 97 项一片一片地塌掉，只剩两头的碎屑。这就是本课的主角：**裂项相消**。

## 2. 直觉解释

先看最关键的一步变形：

$$\frac{1}{1\times 2} = \frac{1}{1} - \frac{1}{2}, \qquad \frac{1}{2\times 3} = \frac{1}{2} - \frac{1}{3}, \qquad \frac{1}{3\times 4} = \frac{1}{3} - \frac{1}{4}$$

为什么成立？通分验证：$\frac{1}{2} - \frac{1}{3} = \frac{3-2}{2\times 3} = \frac{1}{6}$ ✓。

现在把它们按原样排好队相加：

$$\left(\frac11 - \frac12\right) + \left(\frac12 - \frac13\right) + \left(\frac13 - \frac14\right) + \cdots$$

看中间发生了什么：$-\frac12$ 和 $+\frac12$ 撞在一起抵消了，$-\frac13$ 和 $+\frac13$ 也抵消了……**每一个中间项都出场两次，一正一负，双双阵亡**。整条队伍排下来，只有第一个括号的"头" $\frac11$ 和最后一个括号的"尾" $-\frac{1}{100}$ 没有搭档，活了下来。

打个比方：每项都是"先存一笔、再取一笔"，而且第 $k$ 项取的钱恰好是第 $k+1$ 项要存的钱——中间的资金流全部对冲，账上最后只剩第一笔存款和最后一笔取款。

这种加法叫**裂项相消**（telescoping，直译"叠望远镜"）：把一项裂成两半，让相邻的两半互相吃掉，长长的一串像望远镜筒一样缩短成两截。

## 3. 正式定义

**裂项**：把通项 $a_k$ 拆成"同一个函数在两处取值之差"，即 $a_k = g(k) - g(k+m)$，其中 $m$ 是**跨度**（两处下标相差多少）。

| 部件 | 含义 | 例子 |
| --- | --- | --- |
| $a_k$ | 原来的通项 | $\frac{1}{k(k+1)}$ |
| $g(k)$ | 裂开后的"半项"函数 | $g(k) = \frac{1}{k}$ |
| $m$ | 跨度：同一项里两个下标差几 | $m = 1$ |
| 存活项 | 没有被抵消的那几项 | $\frac11$ 与 $-\frac{1}{n+1}$ |

**相消后的清点规则**（这是本课最该记住的一句话）：若 $a_k = g(k) - g(k+m)$，则

$$\sum_{k=1}^{n} a_k = \underbrace{\bigl[g(1) + g(2) + \cdots + g(m)\bigr]}_{\text{前 } m \text{ 项的"头"}} - \underbrace{\bigl[g(n+1) + g(n+2) + \cdots + g(n+m)\bigr]}_{\text{后 } m \text{ 项的"尾"}}$$

**跨度是 $m$，头尾就各留 $m$ 项**——中间的 $g(m+1)$ 到 $g(n)$ 全部出场两次、正负抵消。别凭直觉以为只剩一项头一项尾，那是 $m=1$ 时才有的好运。

三条常用裂项恒等式：

| 名称 | 恒等式 | 为什么成立 |
| --- | --- | --- |
| 相邻整数积 | $\dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}$ | 通分后分子 $(k+1)-k = 1$ |
| 跨度 $m$ 的一般式 | $\dfrac{1}{k(k+m)} = \dfrac{1}{m}\left(\dfrac{1}{k} - \dfrac{1}{k+m}\right)$ | 通分后分子 $m$，故须乘 $\frac1m$ 配平 |
| 根式有理化 | $\dfrac{1}{\sqrt{k} + \sqrt{k+1}} = \sqrt{k+1} - \sqrt{k}$ | 分子分母同乘 $\sqrt{k+1}-\sqrt{k}$，分母变成 $(k+1)-k = 1$ |

**倒序相加**：把和式 $S = a_1 + a_2 + \cdots + a_n$ 正着写一遍、倒着写一遍，上下对齐相加。它成立的**唯一条件是首尾配对之和 $a_k + a_{n+1-k}$ 好算**（最好是常数）：

$$2S = \sum_{k=1}^{n}\bigl(a_k + a_{n+1-k}\bigr)$$

第 11 课（[求和记号 Σ](./11-sigma.md)）用它推出了等差数列求和公式——因为等差里 $a_k + a_{n+1-k} = a_1 + a_n$ 恰好恒定。**但这一招的适用范围远不止等差**：只要能证明"首尾配对之和恒定"，管它是什么数列，一律 $2S = n \times (\text{那个常数})$。

## 4. 分步例题

**例 1（跨度 1）**：求 $\displaystyle\sum_{k=1}^{99}\frac{1}{k(k+1)}$。

1. 裂项：$\frac{1}{k(k+1)} = \frac1k - \frac{1}{k+1}$，这里 $g(k) = \frac1k$、跨度 $m = 1$；
2. 按清点规则：头留 $g(1) = 1$，尾留 $-g(100) = -\frac{1}{100}$；
3. 写出展开式确认（别偷懒，这一步能救你于系数错误）：
   $$\left(\frac11-\frac12\right)+\left(\frac12-\frac13\right)+\cdots+\left(\frac{1}{99}-\frac{1}{100}\right) = \frac11 - \frac{1}{100}$$
4. 结果：$1 - \frac{1}{100} = \frac{99}{100} = 0.99$。

**例 2（跨度 2，别漏系数）**：求 $\displaystyle\sum_{k=1}^{10}\frac{1}{k(k+2)}$。

1. 裂项：$\frac{1}{k(k+2)} = \frac12\left(\frac1k - \frac{1}{k+2}\right)$——注意前面那个 $\frac12$，因为 $\frac1k - \frac{1}{k+2} = \frac{2}{k(k+2)}$，多出来的 2 必须除掉；
2. 跨度 $m = 2$，所以头留 $g(1)+g(2)$、尾留 $g(11)+g(12)$（都带系数 $\frac12$）；
3. 展开核对：
   $$\frac12\left[\left(\frac11-\frac13\right)+\left(\frac12-\frac14\right)+\left(\frac13-\frac15\right)+\cdots+\left(\frac{1}{10}-\frac{1}{12}\right)\right]$$
   其中 $-\frac13$ 与 $+\frac13$、$-\frac14$ 与 $+\frac14$……一路抵消，活下来的是 $\frac11, \frac12$ 和 $-\frac{1}{11}, -\frac{1}{12}$；
4. 结果：$\frac12\left(1 + \frac12 - \frac{1}{11} - \frac{1}{12}\right) = \frac12\left(\frac{3}{2} - \frac{23}{132}\right) = \frac12 \cdot \frac{175}{132} = \frac{175}{264} \approx 0.6629$。

**例 3（根式有理化）**：求 $\displaystyle\sum_{k=1}^{99}\frac{1}{\sqrt{k} + \sqrt{k+1}}$。

1. 分子分母同乘 $\sqrt{k+1} - \sqrt{k}$：分母变成 $(\sqrt{k+1})^2 - (\sqrt{k})^2 = 1$，分子就是 $\sqrt{k+1} - \sqrt{k}$；
2. 于是通项裂成 $g(k+1) - g(k)$ 的形状，其中 $g(k) = \sqrt{k}$，跨度 $m=1$；
3. 展开：$(\sqrt2 - \sqrt1) + (\sqrt3 - \sqrt2) + \cdots + (\sqrt{100} - \sqrt{99})$，中间的根式成对抵消；
4. 结果：$\sqrt{100} - \sqrt{1} = 10 - 1 = 9$。

**例 4（倒序相加，不只是等差）**：设 $f(x) = \dfrac{4^x}{4^x + 2}$，求 $f\!\left(\frac{1}{1000}\right) + f\!\left(\frac{2}{1000}\right) + \cdots + f\!\left(\frac{999}{1000}\right)$。

1. 先算配对之和（这是倒序相加的入场券）：
   $$f(1-x) = \frac{4^{1-x}}{4^{1-x} + 2} = \frac{4/4^x}{4/4^x + 2} = \frac{4}{4 + 2\cdot 4^x} = \frac{2}{2 + 4^x}$$
   所以 $f(x) + f(1-x) = \frac{4^x}{4^x+2} + \frac{2}{4^x+2} = 1$——**恒定等于 1**；
2. 记所求为 $S$，倒着再写一遍：$S = f\!\left(\frac{999}{1000}\right) + \cdots + f\!\left(\frac{1}{1000}\right)$；
3. 两式相加，上下第 $k$ 位凑成 $f\!\left(\frac{k}{1000}\right) + f\!\left(1 - \frac{k}{1000}\right) = 1$，共 999 位；
4. $2S = 999 \times 1$，故 $S = \dfrac{999}{2} = 499.5$。

注意这一串数里没有任何两项相等，它既不是等差也不是等比——**倒序相加吃的是"首尾配对之和恒定"，不是"逐项之差恒定"**。

### 实验 2（python 滑块）：清点"谁活了下来"

```python title="跨度 1：中间项全军覆没，只剩一头一尾"
# sliders: N=6 [4:40:1]

# 先把展开式的开头和结尾打印出来
head = []
for k in range(1, 4):
    head.append("(1/" + str(k) + " - 1/" + str(k + 1) + ")")
print(" + ".join(head), "+ ... + (1/" + str(N) + " - 1/" + str(N + 1) + ")")
# " + ".join(head)：用加号把列表里的字符串串成一句（join 是字符串的方法）

# 逐个分母清点：k 在这个和里被加过几次、减过几次
alive = []
for k in range(1, N + 2):
    s = 0.0
    if k <= N:
        s = s + 1 / k          # 第 k 项贡献 + 1/k
    if k >= 2:
        s = s - 1 / k          # 第 k-1 项贡献 - 1/k
    if abs(s) > 0.0000000001:  # abs：绝对值（第 6 章登记过），用来判断"有没有剩下"
        alive.append(str(round(s, 4)) + " (分母 " + str(k) + ")")
print("活下来的项:", alive)
print("公式 1 - 1/(N+1) =", round(1 - 1 / (N + 1), 4))
```

怎么玩：默认 $N=6$ 时活下来的只有 `1.0 (分母 1)` 和 `-0.1429 (分母 7)`——正好一正一负两头。拖动 $N$ 到 20、40，活下来的永远只有这两项，只是尾项越来越接近 0。这就是"相消"二字的字面意思。

### 实验 3（python 滑块）：跨度 2，头尾各留两项

```python title="跨度 2：活下来的是四项"
# sliders: N=10 [3:40:1]

s = 0.0
for k in range(1, N + 1):
    s = s + 1 / (k * (k + 2))
print("硬加:", round(s, 6))

# 裂项：1/(k(k+2)) = (1/2) * (1/k - 1/(k+2))，跨度 m = 2
alive = []
for j in range(1, N + 3):                # j 是分母，逐个清点它有没有被抵消
    v = 0.0
    if j <= N:
        v = v + 0.5 / j        # 第 j 项的"头"
    if j >= 3:
        v = v - 0.5 / j        # 第 j-2 项的"尾"
    if abs(v) > 0.0000000001:
        alive.append(str(round(v, 4)) + " (分母 " + str(j) + ")")
print("活下来的项:", alive)
print("公式 (1/2)(1 + 1/2 - 1/(N+1) - 1/(N+2)) =", round(0.5 * (1 + 0.5 - 1 / (N + 1) - 1 / (N + 2)), 6))
```

怎么玩：默认 $N=10$ 时活下来四项——$+0.5$（分母 1）、$+0.25$（分母 2）、$-0.0455$（分母 11）、$-0.0417$（分母 12）。**跨度是 2，头尾就各留 2 项**，这正是第 3 节那条清点规则。两行输出（硬加 vs 公式）必须一致。

### 实验 4（python 滑块）：有理化与倒序相加，一次看两个

```python title="两种消法：一个靠裂项，一个靠配对"
# sliders: M=10 [4:400:2]

import math                                   # 数学库：开平方要用它

# —— 有理化型：1/(√k + √(k+1)) = √(k+1) - √k ——
s = 0.0
for k in range(1, M):
    s = s + 1 / (math.sqrt(k) + math.sqrt(k + 1))   # math.sqrt：开平方（第 3 章登记过）
print("有理化型 硬加  :", round(s, 6))
print("有理化型 公式  :", round(math.sqrt(M) - 1, 6))

# —— 倒序相加：f(x) + f(1-x) = 1 ——
def f(x):                                     # def 定义函数：输入 x，输出 f(x) 的值
    return 4 ** x / (4 ** x + 2)

pair = 0.0
for k in range(1, M):
    pair = pair + f(k / M) + f(1 - k / M)     # 每一对首尾之和
print("首尾配对之和   :", round(pair / (M - 1), 6), "（恒为 1 才能用倒序相加）")

total = 0.0
for k in range(1, M):
    total = total + f(k / M)
print("倒序相加 硬加  :", total)
print("倒序相加 公式  :", (M - 1) / 2)
```

怎么玩：把 $M$ 拖到 100、400，"首尾配对之和"那一栏**死死钉在 1.0 不动**——这才是倒序相加敢用的依据；而"硬加"与"公式 $(M-1)/2$"始终相等。$M$ 取奇数也一样成立（中间的 $x=0.5$ 那项自己等于 0.5，正好是配对和的一半），所以公式里没有奇偶之分。

## 6. 常见误区

::::warning[常见误区]

- **"你以为 $\frac{1}{k(k+2)} = \frac1k - \frac{1}{k+2}$。"** 其实右边通分后是 $\frac{2}{k(k+2)}$，**多了一个 2，必须乘 $\frac12$ 配平**。裂项之后养成一个习惯：把结果通分回去验一遍——三秒钟的事，能挡掉这类最高频的错误。
- **"你以为裂项之后只剩第一项的头和最后一项的尾。"** 其实跨度是 $m$ 时，**头尾各留 $m$ 项**。跨度 2 的 $\frac{1}{k(k+2)}$ 就留四项（实验 3 打印得清清楚楚）。想不踩坑，就把前 $m$ 个括号和后 $m$ 个括号老老实实写出来数一遍。
- **"你以为倒序相加只对等差数列有用。"** 其实它只要求**首尾配对之和好算**。例 4 里那串数毫无等差等比的影子，照样靠 $f(x)+f(1-x)=1$ 秒杀。反过来，如果配对之和随 $k$ 变化（比如等比），倒序相加就派不上用场——那时该上的是错位相减，下一课的正题。

::::

改完复核：裂项后 $= 1 - \frac{1}{100} = 0.99$ ✓。注意 `round` 只是把浮点误差抹平，真正的答案是精确的 $\frac{99}{100}$。

**练习 2**：求 $\displaystyle\sum_{k=1}^{10}\frac{1}{k(k+2)}$ 的精确值（用分数表示）。

<details>
<summary>点开查看逐步解答</summary>

裂项：$\frac{1}{k(k+2)} = \frac12\left(\frac1k - \frac{1}{k+2}\right)$，跨度 $m=2$，头尾各留 2 项：

$$\frac12\left[\left(\frac11 + \frac12\right) - \left(\frac{1}{11} + \frac{1}{12}\right)\right] = \frac12\left(\frac32 - \frac{23}{132}\right) = \frac12 \cdot \frac{198-23}{132} = \frac{175}{264}$$

化为小数约 $0.6629$。逐项硬加核对：$\frac13 + \frac18 + \frac{1}{15} + \cdots + \frac{1}{120} \approx 0.66288$ ✓。

**练习 3**：求 $\displaystyle\sum_{k=1}^{99}\frac{1}{\sqrt{k} + \sqrt{k+1}}$。

<details>
<summary>点开查看逐步解答</summary>

分子分母同乘 $\sqrt{k+1} - \sqrt{k}$：

$$\frac{1}{\sqrt{k}+\sqrt{k+1}} = \frac{\sqrt{k+1}-\sqrt{k}}{(k+1)-k} = \sqrt{k+1} - \sqrt{k}$$

于是

$$\sum_{k=1}^{99}\left(\sqrt{k+1} - \sqrt{k}\right) = (\sqrt2-\sqrt1) + (\sqrt3-\sqrt2) + \cdots + (\sqrt{100}-\sqrt{99}) = \sqrt{100} - 1 = 9$$

中间的 $\sqrt2, \sqrt3, \dots, \sqrt{99}$ 各出现一正一负，全部抵消。**答案是一个整数 9**——一堆带根号的分数加起来竟能这么干净，正是裂项的魅力。

</details>

## 8. 选读：三项连乘也能裂

<details>
<summary>选读 · 分母是三个连续整数时怎么办</summary>

跨度 1、2 都会了，遇到 $\frac{1}{k(k+1)(k+2)}$ 呢？思路不变：把它裂成"同一个函数在两处的差"。注意

$$\frac{1}{k(k+1)} - \frac{1}{(k+1)(k+2)} = \frac{(k+2) - k}{k(k+1)(k+2)} = \frac{2}{k(k+1)(k+2)}$$

多出一个 2，乘 $\frac12$ 配平：

$$\frac{1}{k(k+1)(k+2)} = \frac12\left[\frac{1}{k(k+1)} - \frac{1}{(k+1)(k+2)}\right]$$

这里 $g(k) = \frac{1}{2k(k+1)}$、跨度 $m=1$，于是头留 $g(1)$、尾留 $-g(N+1)$：

$$\sum_{k=1}^{N}\frac{1}{k(k+1)(k+2)} = \frac12\left[\frac{1}{1\times 2} - \frac{1}{(N+1)(N+2)}\right] = \frac14 - \frac{1}{2(N+1)(N+2)}$$

检验：$N=1$ 时左边 $\frac16$，右边 $\frac14 - \frac{1}{2\times 2\times 3} = \frac14 - \frac{1}{12} = \frac16$ ✓；$N=2$ 时左边 $\frac16 + \frac{1}{24} = \frac{5}{24}$，右边 $\frac14 - \frac{1}{24} = \frac{5}{24}$ ✓。

**本课不管什么**：不是所有分式都能裂。比如 $\frac{1}{k^2}$ 就没有简单的裂项写法，它前 $N$ 项的和也没有初等的闭式——这类"加不完的尾巴"正是第 15 章《无穷级数与泰勒展开》的研究对象，届时你会看到 $\sum \frac{1}{k^2} = \frac{\pi^2}{6}$ 这个惊艳的结论（欧拉 1734 年的成名作）——它的严格证明要用更高阶的工具，第 15 章会先把它郑重记作一笔悬案。

</details>

裂项是"在项的内部拆出缺口，让相邻项互相吃掉"。可有一类数列——**等差乘等比**，比如 $1\cdot 1 + 2\cdot 2 + 3\cdot 4 + \cdots$——项内拆不出任何缺口，相邻项也谁都吃不掉谁。对付它要靠另一招：整串乘上公比、错开一位、自己减自己。
