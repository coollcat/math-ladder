# 等差与等比：加法生长与乘法生长

## 1. 从一个场景开始

两种存钱方案摆在你面前：第一种，每月固定多存 500 元；第二种，每月余额翻一倍。一年之后谁更多？十年之后呢？

直觉会告诉你"翻倍肯定厉害"，但它到底厉害到什么程度、什么时候反超，靠拍脑袋是算不清的。这两种节奏——**每次加一个固定的数**和**每次乘一个固定的数**——是数学里最基础的两套生长引擎，几乎一切增长故事都是它们的变奏。

## 2. 直觉解释

把每一项画成一根柱子，两种生长一眼可辨：

- **等差**：每根柱子比前一根高出一截固定的量。柱顶连起来是一条直线——楼梯。
- **等比**：每根柱子是前一根的固定倍数。柱子先是慢吞吞，然后突然蹿天——爆炸。

一句话记忆：**等差走的是"加法台阶"，等比踩的是"乘法弹簧"**。它们的影子你其实都已见过：指数函数那条爆冲曲线是等比的连续版（第 3 章），直线那种均匀爬升是等差的连续版（第 6 章）。

## 3. 正式定义

**数列**：按顺序排好的一列数，记作 $a_1, a_2, a_3, \dots$，第 $n$ 个数叫第 $n$ 项，记作 $a_n$。

| 名称 | 定义 | 通项公式 | 例子 |
| --- | --- | --- | --- |
| 等差数列 | 从第 2 项起，每项与前一项之**差**都等于同一个常数 $d$（公差） | $a_n = a_1 + (n-1)d$ | $3, 7, 11, 15,\dots$（$d=4$） |
| 等比数列 | 从第 2 项起，每项与前一项之**比**都等于同一个常数 $r$（公比，$r \neq 0$） | $a_n = a_1 \cdot r^{\,n-1}$ | $2, 6, 18, 54,\dots$（$r=3$） |

通项公式为什么长这样？等差：从第 1 项到第 $n$ 项共迈了 $n-1$ 步，每步加 $d$，所以加 $(n-1)d$；等比：同样的 $n-1$ 步，每步乘 $r$，所以乘 $r^{n-1}$。**步数永远是 $n-1$ 而不是 $n$**——这是本章第一个易错点。

等比数列还有一个隐含门槛：首项也不能为 $0$。否则“第二项除以第一项”根本没有意义，公比无从谈起。所以完整条件是 $a_1 \neq 0$ 且 $r \neq 0$。

## 4. 分步例题

**例 1**：等差数列 $5, 9, 13, \dots$ 的第 10 项是多少？

1. 认参数：$a_1 = 5$，$d = 4$；
2. 套公式：$a_{10} = 5 + (10-1) \times 4$；
3. 计算：$= 5 + 36 = 41$。

**例 2**：细胞每半小时分裂一次（1 变 2），从 1 个细胞开始，8 小时后有多少个？

1. 分裂轮数：$8 \times 2 = 16$ 轮；
2. 每轮数量乘 2：这是 $a_1 = 1$、$r = 2$ 的等比数列；
3. 套公式：$a_{17} = 1 \times 2^{16} = 65536$（初始是第 1 项，16 轮后是第 17 项）。

## 5. 动手实验

### 实验 1（viz）：拧动等差旋钮

```viz
{
  "type": "seq",
  "kind": "arith",
  "a1": 1,
  "d": 2,
  "n": 8
}
```

怎么玩：拖动 d 滑杆看楼梯陡缓的变化；把 d 拧成负数，楼梯变成下坡；盯住左上角的 $S_n$（前 n 项和），感受它匀速增长。再把 a₁ 拉到负数——楼梯可以从地下室起步。

### 实验 2（viz）：拧动等比旋钮

```viz
{
  "type": "seq",
  "kind": "geom",
  "a1": 1,
  "r": 1.5,
  "n": 8
}
```

怎么玩：把 r 从 1.1 慢慢拧到 2，观察柱子从"温吞"到"爆冲"；再试试 $0 < r < 1$——每项越缩越小，趋向 0 但永远不为 0（这颗种子第 13 章极限课发芽）。对照实验 1：加法生长是匀速爬坡，乘法生长是加速起飞。

### 实验 3（python）：两条生长曲线同框

```python title="等差 vs 等比：前 20 项同台竞技"
import matplotlib.pyplot as plt  # 画图库

ns = []
diff_vals = []                   # 存等差数列的各项
geom_vals = []                   # 存等比数列的各项
a = 1                            # 公共起点 a1 = 1
d = 2                            # 等差公差
r = 1.5                          # 等比公比

for n in range(1, 21):           # n 从 1 数到 20
    ns.append(n)
    diff_vals.append(a + (n - 1) * d)     # 等差通项公式
    geom_vals.append(a * r ** (n - 1))    # ** 是乘方：r 的 (n-1) 次方

print(f"等差第20项: {diff_vals[19]}")     # 列表下标从 0 开始，第 20 项是 [19]
print(f"等比第20项: {round(geom_vals[19], 2)}")

plt.plot(ns, diff_vals, marker="o", label=f"arith d={d}")
plt.plot(ns, geom_vals, marker="s", label=f"geom r={r}")
plt.legend()
plt.grid(True)
```

怎么玩：起点相同的两个数列，前期等差还领先，十几项后被等比无情碾过。把 r 改成 1.05 再跑——公比只大一点点，反超照样发生，只是来得晚些。这就是"复利"可怕的原因。

### 快问快答

```quiz
等差数列 2, 5, 8, ... 的第 100 项是多少？
- 300
- 299 [*]
- 302
? a1=2, d=3，a100 = 2 + 99×3 = 299。别用 100×3——从第 1 项到第 100 项只迈了 99 步。
```

:::warning[常见误区]

**误区一**："你以为第 n 项是 $a_1 + nd$。" 其实步数是 $n-1$：第 1 项本身没迈任何步。检验最省事——把 $n=1$ 代回去必须得 $a_1$，代不回去就是公式错了。

**误区二**："你以为等比数列的 r 可以随便取。" 其实规定 $r \neq 0$：若 $r=0$，第二项往后全是 0，比值 $0 \div 0$ 根本无从谈起。

**误区三**："你以为以后学的'等比求和公式'能无脑套。" 其实用心记一句：那个公式的分母里有 $(r-1)$，当 $r=1$ 时分母为 0，公式当场报废——此时每一项都相等，前 n 项和就是 $n \cdot a_1$，直接乘就行。特例的来龙去脉下一课选读展开，现在先立规矩：**任何公式，套之前先查适用范围**。

:::

## 6. 练习

**练习 1**：礼堂第一排有 12 个座位，往后每排多 2 个，第 100 排有多少个座位？下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：第 100 排几个座位
# @check: 210
# @hint: 通项公式是 a1 + (n-1)*d——从第 1 排到第 100 排只迈了 99 步，代码里却按 100 步算了
a1 = 12
d = 2
print(a1 + d * 100)
```

**练习 2**：一张纸对折 1 次厚 2 层，对折 2 次厚 4 层……对折多少次后超过 100 万层？

<details>
<summary>点开查看逐步解答</summary>

层数是 $a_1 = 1$、$r = 2$ 的等比数列，对折 $k$ 次后有 $2^k$ 层。要 $2^k > 10^6$，即 $k > \log_2 10^6 \approx 19.9$，所以 **20 次**。

验证：`pow(2, 20)` 输出 `1048576`，刚好突破百万。对折 27 次厚度就超过珠峰——乘法生长的暴力，第 3 章《乘方》早已领教。
</details>

**练习 3**：等差数列的第 4 项是 11，第 9 项是 26，求首项与公差。

<details>
<summary>点开查看逐步解答</summary>

两项相减：$a_9 - a_4 = (a_1 + 8d) - (a_1 + 3d) = 5d = 26 - 11 = 15$，所以 $d = 3$。

回代：$a_1 = 11 - 3 \times 3 = 2$。检验：$2, 5, 8, 11, \dots$ 第 9 项 $2 + 8 \times 3 = 26$ ✓。

技巧总结：**已知任意两项，先相减消去 $a_1$ 求 $d$**——差值正好等于"间隔数 × d"。
</details>

## 7. 选读：等比数列的"折返跑"

<details>
<summary>选读 · 为什么 0 &lt; r &lt; 1 时数列不会消失</summary>

取 $a_1 = 1$、$r = 0.5$：$1, \; 0.5, \; 0.25, \; 0.125, \dots$ 每一项都严格大于 0——正数乘正数还是正数，永远除不尽也永远碰不到 0。但第 30 项已经小于十亿分之一，肉眼早看不见了。

"无限逼近 0 却永不到达"，这个现象当时看着像抬杠，它其实是整个微积分的地基概念**极限**。第 13 章我们会给它正式的定义；而它的求和版本（无穷多项加起来竟可能是个有限数！）将在第 15 章登场——那里你会看到 $0.999\cdots = 1$ 的完整解释。

</details>
