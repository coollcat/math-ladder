# 复变函数与映射

## 1. 开场钩子

把一张橡皮网格放进流水里，每个点都会被推到新位置。若这个推动规则恰好由复数运算给出，它就叫复变函数。真正奇怪的是：好的复变函数不是随便揉橡皮，而是在每个小邻域里做“旋转加伸缩”，几乎不撕裂也不折叠。

## 2. 直觉解释

一元实函数 $f(x)$ 把数轴上的点搬到数轴上；复变函数

$$w=f(z)=u(x,y)+i v(x,y),\qquad z=x+i y$$

把整个复平面搬进复平面。输入有两个坐标，输出也有两个坐标，所以最自然的图像不是一条曲线，而是一张“源平面到像平面”的地图。

乘法已经给了原型：乘以 $w_0$ 会把所有点旋转 $\arg w_0$ 并伸缩 $|w_0|$ 倍。复分析的许多奇迹，都从这里发芽。

## 3. 正式定义

设 $D$ 是复平面中的集合。若对每个 $z\in D$ 都有唯一的复数 $w=f(z)$，就称 $f$ 是 $D$ 上的复变函数。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $D$ | 定义域 | 允许输入的点集 |
| $u(x,y)$ | 实部函数 | 输出点的横坐标 |
| $v(x,y)$ | 虚部函数 | 输出点的纵坐标 |
| 像 $f(D)$ | 像集合 | 所有输出点组成的新区域 |

例：$f(z)=z^2$ 可写成 $u=x^2-y^2,\ v=2xy$。一个代数式，同时携带两张坐标账本。

## 4. 分步例题

取 $z=1+2i$，求 $f(z)=z^2$ 的像点。

1. 展开：$(1+2i)^2=1+4i+4i^2$；
2. 用 $i^2=-1$ 化简：得到 $-3+4i$；
3. 对照二元账本：$x=1,y=2$ 给出 $u=1-4=-3$，$v=2\cdot1\cdot2=4$；
4. 几何解读：点 $(1,2)$ 被映射到 $(-3,4)$，角度翻倍且模长平方。

## 5. 动手实验

### 实验 1（viz）：线性复映射的旋转与伸缩

```viz
{
  "type": "complexmult",
  "title": "拖动源点 z，看 w0*z 的像",
  "z": [1, 1],
  "wAbs": 1.25,
  "wDeg": 45,
  "caption": "乘以 w＝转 45°、伸长 1.25 倍——角度相加、长度相乘（拖蓝色 z 试试）"
}
```

拖动蓝色点 $z$，紫色粗箭头是 $w_0z$。增大 $|w|$ 会放大图形，改变角度会整体旋转。这就是线性复映射的基本动作。

> 本课先用“两个坐标账本”的直觉读网格变形；Jacobian 的正式定义会在后面的多元微积分章展开。

### 实验 2（viz）：非线性映射的网格变形

```viz
{
  "type": "jacobian-grid",
  "title": "z^2 把方格网弯成抛物线网",
  "fx": "u^2 - v^2",
  "fy": "2*u*v",
  "point": [1, 1]
}
```

白点是源平面的探针，紫点是被 $z^2$ 推到的像点。避开原点的小方格仍近似于旋转加拉伸；远离原点时整张网明显弯曲，但小格子仍然不折叠。原点本身是 $z^2$ 的临界点，不能当作保角样本。

### 实验 3（python）：批量追踪四个角点

```python title="把一个小正方形送进 f(z)=z^2"
# 列表里放四个复数，表示小正方形的四个角
corners = [1 + 1j, 1.2 + 1j, 1.2 + 1.2j, 1 + 1.2j]
for k in range(4):                 # range(4) 生成 0,1,2,3
    z = corners[k]                 # 取出第 k 个角点
    w = z * z                      # 复数乘法就是映射规则
    print(f"z=({round(z.real, 2)}, {round(z.imag, 2)}), w=({round(w.real, 2)}, {round(w.imag, 2)})")
```

四个像点仍按同样顺序连接时，构成一个小小的弯曲四边形。局部没有翻转方向，这正是后面“解析性”的几何影子。

:::warning[常见误区]

**误区一**：你以为复函数应该画成一条曲线。其实输入和输出都是二维的，完整对象是平面到平面的映射。

**误区二**：你以为 $f(z)=z^2$ 只会把角度翻倍。它还会让模长平方，并且整体网格随位置弯曲。

**误区三**：你以为任何二维函数都能这样看。只有写成 $u+iv$ 且性质足够规整的映射才进入复分析的主线。

:::

## 6. 练习

```exercise
# @title: 练习：修正 z^2 的实虚部分解
# @check: -3.0
# @check: 4.0
# @hint: u=x^2-y^2，v=2xy；初始代码里的 v 漏了系数 2。
x = 1.0
y = 2.0
u = x * x + y * y
v = x * y
print(round(u, 1))
print(round(v, 1))
```

<details>
<summary>点开查看逐步解答</summary>

$z^2=(x+iy)^2=x^2-y^2+2xyi$。所以 $u=x^2-y^2=1-4=-3$，$v=2xy=4$。

也可以直接算 `(1 + 2j) * (1 + 2j)`，结果同样是 `-3+4j`。
</details>

## 7. 选读：为什么不能只用一张图

<details>
<summary>选读 · 三维曲面不够用</summary>

如果把 $u(x,y)$ 和 $v(x,y)$ 分别画成两张高度曲面，需要四维空间才能同时展示它们。因此复函数常用三种压缩表示：

1. 源平面到像平面的箭头或网格映射；
2. 分别画等值线的“双地形图”；
3. 用颜色编码辐角的定义域着色。

第三种正是未来 `domain-coloring` 组件的目标：色相表示输出的角度，明暗表示输出的长度。
</details>
