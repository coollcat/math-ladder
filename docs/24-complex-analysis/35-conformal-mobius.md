# Möbius 变换：把圆还给你

## 1. 开场钩子

[上一课](./30-cauchy-riemann.md)的 Jacobian 网格告诉我们：解析映射在每一点都做"旋转加伸缩"，角度一个不丢。可那是局部的小动作——现在想要一台**整图搬运机**：把上半平面原封不动卷进单位圆盘，边界对边界，角度对角度。这门手艺的全部家当只有四个复数，写出来是一条分数式。它叫 Möbius 变换。

## 2. 直觉解释

把分数式拆成三块积木：平移、伸缩旋转、取倒数。代数上真身是

$$\frac{az+b}{cz+d}=\frac{a}{c}+\frac{bc-ad}{c^2}\cdot\frac{1}{z+d/c},$$

也就是"平移 $\to$ 取倒数 $\to$ 伸缩旋转 $\to$ 平移"。前后两块是刚体动作：直线还是直线，圆还是圆。真正有个性的是**取倒数**：它把 0 和无穷远互换，最贴近 0 的地盘被翻到最远处，于是直线（可以看作"经过无穷远的圆"）被翻成真正绕得起来时圆。

由此得到本课的主角口令：把无穷远也算进来后，**直线和圆是同一家族**——统称广义圆。Möbius 变换把广义圆整条整条地搬，谁也不改行：**圆还给你，直线也是圆**。

## 3. 正式定义

**定义（Möbius 变换）**：设 $a,b,c,d$ 为复数且行列式

$$ad-bc\neq 0,$$

$$f(z)=\frac{az+b}{cz+d}\qquad(cz+d\neq 0)$$

称为 Möbius 变换（分式线性变换），并约定 $f(-d/c)=\infty$、$f(\infty)=a/c$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $a,b,c,d$ | 四个系数 | 四个复数定一台搬运机；整体乘同一个非零复数不改变换 |
| $ad-bc$ | 行列式 | 为零时分母约掉分子，$f$ 塌成常数——必须排除 |
| $-d/c$ | 极点 | 唯一被甩到无穷远的点 |
| $f(\infty)=a/c$ | 无穷远的像 | 所有竖直线像圆的公共"集合点" |

三条核心性质，每条都能落地：

1. **可逆**：$f^{-1}(w)=\dfrac{dw-b}{-cw+a}$，其行列式仍是 $ad-bc\neq 0$——可逆的搬运机逆过来还是搬运机；
2. **复合封闭**：两台 Möbius 变换前后接手，结果仍是 Möbius 变换，且系数矩阵按普通矩阵乘法相乘；
3. **保圆又保角**：除极点外处处解析且 $f'(z)=\dfrac{ad-bc}{(cz+d)^2}\neq 0$，由上一课，每点的局部都是旋转加伸缩（保角）；整条直线与整条圆的像仍是直线或圆（保圆）。

## 4. 分步例题

**例 1（行列式体检）**：$f(z)=\dfrac{z+2}{2z+4}$。这里 $a=1,b=2,c=2,d=4$，行列式 $ad-bc=4-4=0$——分子分母成比例，$f$ 处处等于 $\tfrac12$（$z=1+i$ 与 $z=3$ 代入都只得 $0.5$）。四块积木塌成一块砖：不配叫搬运机。

**例 2（复合封闭）**：取 $f(z)=\dfrac{z+1}{z+2}$（矩阵 $\begin{pmatrix}1&1\\1&2\end{pmatrix}$）与 $g(z)=\dfrac{2z}{3z+4}$（矩阵 $\begin{pmatrix}2&0\\3&4\end{pmatrix}$）。矩阵相乘：

$$\begin{pmatrix}2&0\\3&4\end{pmatrix}\begin{pmatrix}1&1\\1&2\end{pmatrix}=\begin{pmatrix}2&2\\7&11\end{pmatrix},$$

预言 $g(f(z))=\dfrac{2z+2}{7z+11}$。代入 $z=1+i$ 验收：$f(1+i)=\dfrac{2+i}{3+i}=0.7+0.1i$，再送进 $g$ 得 $0.2306+0.0214i$；直接算 $\dfrac{2(1+i)+2}{7(1+i)+11}=\dfrac{4+2i}{18+7i}$，约分后同样是 $0.2306+0.0214i$ ✓。两个行列式 $1$ 与 $8$ 相乘，恰好是复合后的行列式 $22-14=8$。

**例 3（Cayley 变换：上半平面卷成圆盘）**：取

$$f(z)=\frac{z-i}{z+i},$$

行列式 $ad-bc=1\cdot i-(-i)\cdot 1=2i\neq 0$ ✓。逐点检查：

1. $f(i)=\dfrac{0}{2i}=0$：上半平面的"心脏"被送到圆盘中心；
2. 实轴试三点：$f(0)=-1$、$f(1)=-i$、$f(2)=0.6-0.8i$——模长全是 $1$，实轴整条被卷到单位圆上；
3. $f(2+i)=\dfrac{2}{2+2i}=\dfrac{1-i}{2}=0.5-0.5i$，模长 $\tfrac{\sqrt{2}}{2}\approx 0.707<1$：上半平面的点收进圆盘内部；
4. $f(3-i)=\dfrac{3-2i}{3}=1-\tfrac{2}{3}i$，模长平方 $\tfrac{13}{9}>1$：下半平面的点甩到圆盘外部；
5. 边界对应账本：实轴 ↔ 单位圆，上半平面 ↔ 圆盘内部，角度一点不丢。

## 5. 动手实验

### 实验 1（viz）：局部动作就是复数乘法

```viz

  "title": "Möbius 的局部戏法：乘一个复数",
  "z": [1, 1],
  "wAbs": 0.5,
  "wDeg": 90,
  "caption": "乘以 0.5i＝转 90°、缩 0.5 倍（拖蓝色 z 试试）——只要 f'(z) 非零，每点的局部动作都是这个"
}
```

拖动蓝点、改变 $|w|$ 与角度：小方格只会整体旋转伸缩，永不剪切。Möbius 变换在每一点的局部动作正是乘上 $f'(z)=\dfrac{ad-bc}{(cz+d)^2}$——例如 Cayley 变换在 $z=2+i$ 处 $f'=\dfrac{2i}{(2+2i)^2}=\dfrac14$，纯伸缩不转角。这就是保角性的代数化身。

### 实验 2（viz）：竖直线整条弯成圆

```viz
{
  "type": "jacobian-grid",
  "title": "(z+1)/(z+3) 把竖直线弯成一串圆",
  "fx": "(u^2+4*u+3+v^2)/((u+3)^2+v^2)",
  "fy": "(2*v)/((u+3)^2+v^2)",
  "point": [0, 1]
}
```

源平面每条竖直线都被弯成一段圆弧，而且**所有像圆都排队经过同一个点** $w=f(\infty)=a/c=1$——无穷远被送到 1，每条"经过无穷远的圆"（即直线）的像自然都要路过那里。看 $u=0$ 这条线：像圆以 $\tfrac23$ 为圆心、$\tfrac13$ 为半径，恰好从 $f(0)=\tfrac13$ 走到 $f(\infty)=1$。极点 $z=-3$ 站在图外，负责把地平线推向无穷。

### 实验 3（python）：Cayley 变换的边界点名册

```python title="实轴、圆内、圆外的点名记录"
# f(z) = (z - i)/(z + i)：把上半平面卷进单位圆盘
points = [0, 1, 2, 1j, 2 + 1j, 3 - 1j]   # 点名册：三个实数、上半平面的 i、上下半平面各一位
for z in points:
    w = (z - 1j) / (z + 1j)   # 复数除法直接用 /：Python 自动完成分母的共轭化
    print(f"z = {z}, |w| = {round(abs(w), 4)}")   # abs 对复数返回模长
```

输出点名册：

```text
z = 0, |w| = 1.0
z = 1, |w| = 1.0
z = 2, |w| = 1.0
z = 1j, |w| = 0.0
z = (2+1j), |w| = 0.7071
z = (3-1j), |w| = 1.2019
```

实轴三位 $|w|=1$ 全员过线；$i$ 本尊落在圆心 0；$(2+i)$ 只有 $0.7071$——被收进圆内；$(3-i)$ 高达 $1.2019$——被甩到圆外。边界对应不是口号，是可以逐点点名的账本。

```quiz
Möbius 变换 f(z)=(az+b)/(cz+d) 在什么情况下退化成常数？
- 当 a=0 时
- 当行列式 ad-bc=0 时 [*]
- 当 c=0 时
? ad-bc=0 意味着分子分母成比例，分数式约成一个常数，四个系数从此失去搬动整个平面的资格。
```

::::warning[常见误区]

**误区一**：你以为四个系数随便填都能当搬运工。行列式 $ad-bc=0$ 时分子分母成比例，整台机器塌成常数（例 1）；判据一个都不能少。

**误区二**：你以为 Möbius 变换只管圆、不管直线。直线是"过无穷远的圆"，同样在搬运清单上；$1/z$ 甚至把两种身份当场互换。

**误区三**：你以为极点是机器故障。极点 $z=-d/c$ 只是"发往无穷远的出口"，是边界对应里有编制的一员；Cayley 变换的极点 $z=-i$ 蹲在下半平面，把那半边撑到无穷远，圆盘外部因此装得下整个下半平面。

::::

## 6. 练习

```exercise
# @title: 练习：修好 Cayley 变换，给 (2+i) 点名
# @check: 0.5
# @check: -0.5
# @check: 0.7071
# @hint: f(z)=(z-i)/(z+i)，分子是 z-i 不是 z+i；修好后模长小于 1，说明上半平面的点被卷进了圆盘。
z = 2 + 1j               # 待点名的上半平面住户
w = (z + 1j) / (z + 1j)  # ← 问题在这：分子写错了，f(z) = (z - i)/(z + i)
print(round(w.real, 4))  # .real 取复数的实部
print(round(w.imag, 4))  # .imag 取复数的虚部
print(round(abs(w), 4))  # abs 对复数返回模长
```

修好后输出 0.5、-0.5 与 0.7071：$(2+i)$ 的像 $\dfrac{1-i}{2}$ 躺在半径 $\tfrac{\sqrt{2}}{2}$ 的同心圆上——圆盘点名通过。

<details>
<summary>点开查看逐步解答</summary>

分子改回 $z-i$ 后：

$$w=\frac{(2+i)-i}{(2+i)+i}=\frac{2}{2+2i}=\frac{1-i}{2}=0.5-0.5i.$$

模长 $|w|=\sqrt{0.5}\approx 0.7071<1$。作为对照，$(3-i)$ 的像是 $1-\tfrac{2}{3}i$，模长 $\sqrt{13}/3\approx 1.2019>1$——上下半平面被这条边界干净地分开，而 $f'(z)=\dfrac{2i}{(z+i)^2}$ 处处非零保证分开的方式是保角的。
</details>

## 7. 选读：矩阵视角与球极投影

<details>
<summary>选读 · Möbius 变换的户口本</summary>

**矩阵户口**：把 $f$ 记成矩阵 $\begin{pmatrix}a&b\\c&d\end{pmatrix}$，则：

1. 复合对应矩阵乘法（例 2 已验收）；
2. 可逆对应行列式非零，逆变换的矩阵恰是 $\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$；
3. 整体乘一个非零复数不改变换：八个实数扣掉这一层缩放，真正自由的只剩六个——恰好"三点定一变换"：指定三个点各自的去向，唯一确定一台 Möbius 搬运机。

**球极投影**：把复平面当作与球面在北极相切的桌面，从北极向桌面连线，每条线与球面交于一点——复平面连同无穷远点（北极）被卷成整个球面。在这个模型里，Möbius 变换对应球面的刚体旋转与共形伸缩的复合，再投影回桌面。这类变换不改变球面上的圆，而直线不过是过北极的那些特殊圆，于是"圆映成圆"一目了然；保角性同样免费——球面变换保角，球极投影也保角。Möbius 变换全部的优雅，都是球面几何在桌面上的投影。
</details>
