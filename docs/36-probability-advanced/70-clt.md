# 大数定律与中心极限定理

## 1. 从一个场景开始

全国身高千差万别：有人一米五，有人两米开外。可你随机抽 100 人算平均，再抽 100 人再算一次——两个平均值几乎一样，都贴着全国真值。抽样调查、工厂质检、A/B 测试，全人类都在靠这个事实吃饭。

第 09 章的大数定律说了前半句："平均会**停住**"。但停住之后呢？它围绕真值怎么摆动？摆多宽？形状是什么？后半句的答案是本卷最惊人的定理：不管总体长什么样，**样本平均值的分布都收敛到同一座钟形**。

## 2. 直觉解释

先复述前半句。抛硬币的频率曲线（第 09 章玩过）随次数增多越趴越低，最终焊死在 0.5 上：

```viz
{
  "type": "coinlaw",
  "title": "复习：大数定律——频率停得住"
}
```

后半句的新意在于**看"平均值的散布"本身**。把"抽 n 个求平均"这个动作重复几千次，得到几千个平均值，画直方图：

- $n=1$：直方图就是总体原样——骰子是平的，硬币是两根柱子；
- $n$ 增大：直方图向中间收缩，而且**轮廓越来越像钟形**；
- 关键定量：散布宽度不是按 $n$ 缩小，而是按 $\sqrt{n}$ 缩小——想精度翻倍，样本量要翻四倍。

最不可思议的是钟形从哪来：骰子的总体是平顶六边形，硬币的总体是两根柱子，形状八竿子打不着——但它们"平均值们"的直方图却长成同一座钟。杂乱的个体性在求和时互相抵消，剩下的公共骨架就是正态。

## 3. 正式定义

设 $X_1,\dots,X_n$ 独立同分布，均值 $\mu$、方差 $\sigma^2$ 都有限。记样本均值 $\bar{X}_n=\frac{X_1+\cdots+X_n}{n}$。

**大数定律**（强弱版本统称）：$n\to\infty$ 时 $\bar{X}_n$ 依概率（甚至几乎必然）收敛到 $\mu$——平均停得住。

**中心极限定理（CLT）**：

$$\frac{\bar{X}_n-\mu}{\sigma/\sqrt{n}} \xrightarrow{\;d\;} N(0,1), \qquad \bar{X}_n \approx N\!\left(\mu,\ \frac{\sigma^2}{n}\right)\ (n\text{ 大时})$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\bar{X}_n$ | 样本均值 | 一批 n 个结果的算术平均，本身也是随机变量 |
| $\sigma/\sqrt{n}$ | 均值标准误 | 样本均值的标准差；缩水速度由它掌管 |
| $N(0,1)$ | 标准正态 | $\mu=0,\sigma=1$ 的那座基准钟 |
| $\xrightarrow{d}$ | 依分布收敛 | 分布形状趋向一致，不逐点重合 |

两条定理分工明确：LLN 管"落点"（宽度趋于零），CLT 管"摆姿"（有限 n 时的完整分布）。前者是后者的极限余波。

## 4. 分步例题

**例**：掷一颗骰子的均值为 $\mu=3.5$、方差 $\sigma^2=\frac{35}{12}\approx2.9167$（40 课算过）。掷 100 颗取平均，$\bar{X}_{100}$ 超过 3.84 的概率大约多少？

1. 均值的标准误：$\sigma/\sqrt{n}=1.7078/10\approx0.1708$——比单颗骰子的散布缩了十倍；
2. 标准化：问"离重心几个标准误"？$z=\frac{3.84-3.5}{0.1708}\approx1.99$；
3. 查标准正态：超过 $1.99$ 个标准误的概率约 $0.023$；
4. 解读：一百颗骰子的平均值还想高过 3.84？不到 2.5% 的运气才够得着。若只掷一颗，超过 3.84 的概率是 $\frac{3}{6}=\frac{1}{2}$——平均化把"走运"变成了稀有品。

## 5. 动手实验

### 实验 1（python）：亲眼看钟形从平顶里长出来

```python title="CLT 实验室：样本均值的直方图 vs 正态叠加"
# sliders: n=5 [1:100:1]
import random
import math
import matplotlib.pyplot as plt

runs = 4000                       # 把"抽 n 个求平均"重复 runs 次
means = []
for r in range(runs):
    total = 0
    for t in range(n):
        total = total + random.randint(1, 6)
    means.append(total / n)

plt.hist(means, bins=60, density=True, color="steelblue", label="sample mean")

mu = 3.5                          # 理论钟形：μ 不变，宽度 σ/√n
se = math.sqrt(35 / 12 / n)
xs = []
ys = []
for k in range(200):
    x = mu + (k / 199 - 0.5) * 6 * se    # 在钟形±3个标准误内铺横轴
    xs.append(x)
    ys.append(math.exp(-((x - mu) ** 2) / (2 * se * se)) / (se * math.sqrt(2 * math.pi)))
plt.plot(xs, ys, linewidth=2.5, color="tomato", label="normal")
plt.legend()
```

`n` 从 1 拖到 30 再到 100：平顶六边形先是收窄成三角，然后被橙色理论钟一点点吞没。$n=1$ 时两者毫不相干——这正是 CLT 的深刻处：**它描述的是平均后的世界，与个体长相无关**。

### 实验 2（python)：不同总体，同一座钟

```python title="骰子总体 vs 偏斜总体：均值分布殊途同归"
import random
import math
import matplotlib.pyplot as plt

n = 30                            # 固定样本量，换两个完全不同的总体
runs = 4000
mean_a = []                       # 总体 A：公平骰子（对称）
mean_b = []                       # 总体 B：偏斜分布——90% 得 0，10% 得 10
for r in range(runs):
    sa = 0
    sb = 0
    for t in range(n):
        sa = sa + random.randint(1, 6)
        if random.random() < 0.1:
            sb = sb + 10
    mean_a.append(sa / n)
    mean_b.append(sb / n)

fig, axes = plt.subplots(1, 2, figsize=(9, 3))
axes[0].hist(mean_a, bins=40, color="steelblue")
axes[0].set_title("dice mean, n=30")
axes[1].hist(mean_b, bins=40, color="olive")
axes[1].set_title("skewed mean, n=30")
plt.tight_layout()
```

右边的总体歪得离谱（绝大多数是 0），可它 30 个一组的平均值照样端端正正一座钟。这就是 CLT 敢让全世界的统计学家睡好觉的原因：**只要样本够大，推断方法不必认识总体的真面目**。

### 快问快答

```quiz
样本量从 100 增加到 400，样本均值的标准误变成原来的几倍？
- 四分之一
- 一半 [*]
- 不变，标准误只和总体有关
? 标准误按根号 n 缩水：根号下 400 除以根号下 100 是 2，所以新标准误是旧的一半。想要精度翻倍，样本量要付四倍的代价。
```

:::warning[常见误区]

**误区一**："你以为中心极限定理说'数据多了就变正态'。" 它说的是**样本均值的分布**趋近正态，总体本身纹丝不动：掷一万次骰子，单次结果还是均匀的六种点数。混淆这两者会把"对均值做检验"错用成"给原始数据定形状"。

**误区二**："你以为任何 n 都能用正态近似。" 近似质量取决于总体的偏斜与尾部：对称总体 n 几十就够像样，重尾总体可能要成百上千。CLT 是极限定理，不是有限样本的保证书。

**误区三**："你以为大数定律保证'连输之后该赢了'。" LLN 说的是长期平均被海量**未来**数据摊薄，从不安排旧亏损被补偿。赌徒谬误在 09 章登过黑名单，学了极限定理也不许给它发新执照。

:::

## 6. 练习

**练习 1**：接着分步例题算下去。初始代码把标准误的公式写错了——忘了开根号这一刀：

```exercise
# @title: 练习：一百颗骰子的平均会多稳
# @check: 0.1708
# @check: 1.99
# @hint: 均值标准误 = σ/√n，σ 是方差开根号；z 分数 = (目标值 − μ) ÷ 标准误
import math

mu = 3.5
var = 35 / 12
n = 100

se = var / n                  # ← 这是方差的 n 倍缩小，不是标准差！
z = (3.84 - mu) / se
print(round(se, 4))
print(round(z, 2))
```

修好后对照例题：标准误约 0.17，z 约 1.99。把 `n` 改成 400 再跑一遍：标准误减半、z 加倍——根号法则亲手摸到了。

**练习 2**：某流水线单件重量均值 500 克、标准差 8 克。装箱 64 件，整箱平均重量低于 498 克的概率量级如何？（只需用 z 分数粗估）

<details>
<summary>点开查看逐步解答</summary>

标准误 $8/\sqrt{64}=1$ 克，于是 z = $(498-500)/1=-2$。低于均值两个标准误的概率约 2.3%。

反过来用这层关系设计质检线：把报警阈值设在"均值减 2 个标准误"，正常生产一天 1000 箱也只会误报约 23 次；想更严就挪到 3 个标准误（约 0.13%）。工业界的 ±2σ、±3σ 规则全是这道计算题的工程化身。
</details>

**练习 3**：为什么 CLT 里出现的是 $\sqrt{n}$ 而不是 $n$？

<details>
<summary>点开查看逐步解答</summary>

关键在方差的可加性：独立随机变量之和的方差等于各方差之和，所以 $n$ 个之和的方差是 $n\sigma^2$——**和**的标准差只涨 $\sqrt{n}$ 倍。而样本均值是"和除以 n"，除法把标准差又压回 $\sqrt{n}/n=1/\sqrt{n}$。

一句话记忆：波动按平方律积累、按根号消退。这也解释了实验里"精度翻倍要付四倍样本"的定价规则——它是平方与根号这对冤家的直接后果。
</details>

## 7. 选读：从棣莫弗到林德伯格

<details>
<summary>选读 · 一条定理的三百年升级史</summary>

CLT 的第一份证明属于棣莫弗（1733），对象只有伯努利硬币——他为了算赌博问题导出了正态积分，却没意识到自己手里握着一条普适定律。拉普拉斯把它推广到一般分布（1810s），李雅普诺夫给出严格条件（1900s 初），最后林德伯格与费勒厘清了现代版本的核心要求：**没有哪个单项能垄断总和**——每个贡献都要足够"小"。

这个"无霸主"条件解释了 CLT 的边界：金融收益率有暴跌跳空（单项可以巨大）、地震能量遵循幂律尾巴，它们的均值收敛远比正态慢甚至不收敛。学完下一卷随机过程再看这段历史，你会认出熟悉的主题：极限定理从来都有适用疆界，画出疆界的正是那些反例。

证明史的最后一块砖属于现代：把标准化和的特征函数逐点收敛到 $e^{-t^2/2}$，唯一性一出面，钟形即告锁定——那枚指纹的锻造车间在[特征函数一课](./66-characteristic-function.md)。
</details>
