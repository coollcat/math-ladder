# 期望、方差与矩

## 1. 从一个场景开始

游乐园有个转盘游戏：转一次花 5 元，转到"大奖"区赔 200 元。老板定价前要回答两个问题：**平均每转一次，玩家赚还是亏？亏多少？**——这决定生意能不能做。

但只算平均还不够。设想另一个游戏期望和它完全相同，却要么翻倍要么全亏：两家"平均水平"一样，体验天差地别。**中心在哪、散开多宽**——第 09 章为数据装的那两根指针，现在要装到随机变量身上。

## 2. 直觉解释

**期望 = 加权重心。** 第 09 章把平均数看成砝码横杆的平衡点；现在的差别只是：每个取值挂的砝码重量从"出现次数占比"换成了"概率"。掷骰子的重心：

$$E[X]=1\cdot\tfrac{1}{6}+2\cdot\tfrac{1}{6}+\cdots+6\cdot\tfrac{1}{6}=3.5$$

注意 3.5 根本不是骰子能掷出的点数——期望是概率的加权平均，不承诺任何一次的实际取值（术语表：期望是概率加权平均，不保证典型取值）。

**方差 = 重心周围的惯性。** 衡量取值围着重心散开多宽，做法与数据版一致：偏差平方再求加权平均。先玩一下熟悉的数据版教具找回手感：

## 3. 正式定义

设离散随机变量 $X$ 的分布列为 $p(x_k)$：

$$E[X]=\sum_k x_k\,p(x_k), \qquad \mathrm{Var}(X)=\sum_k (x_k-E[X])^2\,p(x_k)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $E[X]$ 或 $\mu$ | 期望 | 概率加权的平均取值；分布的重心 |
| $\mathrm{Var}(X)$ 或 $\sigma^2$ | 方差 | 偏差平方的期望；散布宽度（平方单位）|
| $\sigma=\sqrt{\mathrm{Var}(X)}$ | 标准差 | 回到原单位的典型偏离距离 |
| $E[X^m]$ | $m$ 阶矩 | 取值 $m$ 次方的期望；一阶矩是期望，二阶矩参与方差 |

方差有一条省力捷径，手算时几乎必用：

$$\mathrm{Var}(X)=E[X^2]-(E[X])^2$$

期望还有一条黄金性质——**线性性**：对任意常数 $a,b$ 和随机变量之和，$E[aX+bY+c]=aE[X]+bE[Y]+c$。它不需要任何独立性假设，是概率计算里最常用的一张免费牌。

## 4. 分步例题

**例**：转盘游戏：花 5 元转一次。转到"大奖"的概率 0.01，返 200 元；否则分文不返。设净收益为 $X$（负值表示亏损）。

1. 列出取值：中奖时净赚 $200-5=195$ 元；没中时净得 $-5$ 元；
2. 写出分布列：$P(X=195)=0.01$，$P(X=-5)=0.99$；
3. 算期望：$E[X]=195\times0.01+(-5)\times0.99=1.95-4.95=-3$；
4. 解读：每转一次平均亏 3 元。100 个人各转一次，庄家期望净赚约 300 元——单个人的输赢千差万别，长期平均却稳稳偏向庄家；
5. 再补一刀（选做）：$E[X^2]=195^2\times0.01+25\times0.99=380.25+24.75=405$，于是 $\mathrm{Var}(X)=405-(-3)^2=396$，标准差约 19.9 元——波动远大于均值，"暴富幻觉"正是高方差制造的。

## 5. 动手实验

### 实验 1（python）：蒙特卡洛验证"重心公式"

```python title="模拟掷骰子：频率平均收敛到期望 3.5"
# sliders: n=100000 [1000:500000:1000]
import random

total = 0
for trial in range(n):
    roll = random.randint(1, 6)
    total = total + roll        # 把每次点数累加进总账

print(f"{n} 次的平均点数 = {round(total / n, 4)}")
print(f"理论期望 E[X]   = {round((1+2+3+4+5+6) / 6, 4)}")
```

两行数字贴得越近，越说明"频率加权"在大量重复后会自动滑向"概率加权"——大数定律给重心公式背书。

### 实验 2（python）：方差捷径逐项核对

```python title="Var(X) = E[X²] − μ²，两种算法必须一致"
xs = [1, 2, 3, 4, 5, 6]
probs = [1/6] * 6               # 列表乘整数：六个 1/6 复制成一份完整分布列

mu = 0                          # 第一遍扫描：重心
for k in range(6):
    mu = mu + xs[k] * probs[k]

m2 = 0                          # 第二遍扫描：平方的期望 E[X²]
for k in range(6):
    m2 = m2 + xs[k] ** 2 * probs[k]

var_direct = 0                  # 定义版：偏差平方的加权平均
for k in range(6):
    var_direct = var_direct + (xs[k] - mu) ** 2 * probs[k]

print(f"E[X]={round(mu,4)}, E[X²]={round(m2,4)}")
print(f"定义版 Var = {round(var_direct, 4)}")
print(f"捷径版 E[X²]−μ² = {round(m2 - mu ** 2, 4)}")
```

两条路都落在 $35/12 \approx 2.9167$ 上。这个数请记住脸——中心极限定理一课它会以"骰子方差"的身份再度登场。

### 快问快答

```quiz
若 E[X] = 2，那么 E[3X + 5] 等于多少？
- 11 [*]
- 无法确定，要看 X 的分布列
- 7
? 期望的线性性不需要任何额外条件：E[3X+5] = 3·E[X]+5 = 11。重心整体拉伸平移，新重心跟着走同样的路线。
```

:::warning[常见误区]

**误区一**："你以为期望就是'最可能出现的值'。" 抛两次硬币正面个数的期望是 1，可 1 恰好是最典型的取值纯属巧合；彩票期望几十万，最可能的结局是一文不归。期望描述重心的位置，不描述"典型的一天"。

**误区二**："你以为 $E[X^2]=(E[X])^2$。" 平方的期望不等于期望的平方，两者之差恰好就是方差——除非方差为零（即毫无随机性），它们必然不等。实验 2 里 $E[X^2]\approx 15.17$ 而 $(E[X])^2=12.25$。

**误区三**："你以为 $E[g(X)]$ 总等于 $g(E[X])$。" 只有线性函数才有这张免检通行证。反例随手可得：$E[\frac{1}{X}] \ne \frac{1}{E[X]}$——保险精算和投资组合里大量误用都栽在这条上。

:::

## 6. 练习

**练习 1**：一张刮刮乐售价 5 元：0.01 的概率中 200 元（净赚 195），0.05 的概率中 10 元（净赚 5），其余情况无奖。净收益期望是多少？初始代码只算了"中奖时"的净赚部分，漏了人人都要承担的成本：

```exercise
# @title: 练习：刮刮乐值不值
# @check: -2.5
# @hint: 补上第三档"没中奖"：净收益 −5、概率 0.94，三档各乘概率再相加；或先算总返还期望再减售价 5
gain = 195 * 0.01 + 5 * 0.05     # 两档中奖的加权净赚，还没算"没中奖要亏的 5 元"
print(round(gain, 2))
```

答案 $-2.5$ 元意味着什么？对比上一节转盘游戏的 $-3$ 元：两者都负，且负得理直气壮——**所有商业游戏的期望都必须偏向庄家**，否则这门生意开不了张。

**练习 2**：已知 $E[X]=3$，$\mathrm{Var}(X)=4$。求 $E[2X+1]$ 与 $\mathrm{Var}(2X+1)$。

<details>
<summary>点开查看逐步解答</summary>

期望线性：$E[2X+1]=2\times3+1=7$。方差只认斜率、无视平移：$\mathrm{Var}(2X+1)=2^2\times4=16$（标准差从 2 变 8）。

记忆图景：整团概率云沿数轴平移 1 格，散布形状纹丝不动（所以常数项消失）；横向拉伸 2 倍，云也跟着拉宽 2 倍，而方差量的是"宽度的平方"，所以要乘 $2^2$。
</details>

**练习 3**：用二阶矩的语言解释：为什么 $\mathrm{Var}(X)\ge 0$ 永远成立？

<details>
<summary>点开查看逐步解答</summary>

按定义 $\mathrm{Var}(X)=E[(X-\mu)^2]$：被平均的对象 $(X-\mu)^2\ge0$ 是非负数的加权平均，自然非负。而由捷径式 $\mathrm{Var}(X)=E[X^2]-\mu^2$ 反过来读，就得到著名不等式 $E[X^2]\ge(E[X])^2$——它是柯西-施瓦茨不等式的特例，也是后续一切"方差非负"论证的总开关。
</details>

## 7. 选读："矩"这个名字从哪来

<details>
<summary>选读 · 从阿基米德的杠杆到概率论</summary>

"矩"（moment）借自力学：质量为 $m$ 的质点到支点距离为 $x$ 时，$mx$ 叫它对支点的**一阶矩**，决定杠杆平衡——期望 $E[X]$ 正是单位质量概率板的重心位置。$\sum x_k^2 p_k$ 对应**转动惯量**式的量，衡量质量（概率）离轴铺开的范围——方差。于是 $E[X^k]$ 统称 $k$ 阶矩：一阶定位置，二阶定胖瘦，三阶偏度管不对称，四阶峰度管尾巴轻重。

知道全部矩能否唯一确定分布？在温和条件下可以——这正是"矩方法"估计参数的理论根基，也是后续统计推断章节的一根暗线。至于更高阶的矩生成函数与特征函数，那是测度论卷册的剧情了。

</details>
