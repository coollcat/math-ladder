# 样本空间、事件与概率公理化

## 1. 从一个场景开始

第 09 章我们说"概率是长期频率的稳定值"，还亲手掷硬币验证过。但有个尴尬的问题一直悬着：有些事根本没法重复——"明天下雨的概率"、"这枚古币下次抛出正面的概率"。频率定义对它们无能为力。

1933 年，俄国数学家柯尔莫哥洛夫做了一件釜底抽薪的事：不再追问概率"是什么"，而是直接规定它必须满足哪几条规则。从此概率论有了和几何学公理一样的坚实地基，后面整卷的内容都盖在这块地基上。

## 2. 直觉解释

把一次试验的全部可能结果想象成**一整张地图**：

- **样本空间** $\Omega$：地图本身，所有可能结果的清单；
- **事件**：在地图上圈出的**一块区域**，比如"掷骰子掷出偶数"圈住 $\lbrace 2,4,6\rbrace$ 三格；
- **概率**：给每块区域配的**面积**，全图面积规定为 1。

"面积"这个类比一口气解释了全部规则：任何区域的面积不会是负数；全图面积为 1；两块不重叠的区域拼起来，面积就是各自相加。事件运算也和区域运算一模一样："或"是并集（拼图），"且"是交集（重叠部分），"不发生"是补集（剩下的地图）。

## 3. 正式定义

设 $\Omega$ 是样本空间，事件是 $\Omega$ 的子集。概率是从事件到实数的函数 $P$，满足柯尔莫哥洛夫三条公理：

$$P(\Omega)=1,\qquad P(A)\ge 0,\qquad A_1,A_2,\ldots\text{两两互斥}\Rightarrow P\left(\bigcup_i A_i\right)=\sum_i P(A_i)$$

第三条是可数可加性。取 $A_1=A$、$A_2=B$、其余为空集，就得到本课最常用的两事件版本。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\Omega$ | 样本空间 | 全部基本结果的集合 |
| $A, B$ | 事件 | $\Omega$ 的子集；"$A$ 发生"表示结果落在其中 |
| $\varnothing$ | 空集 | 不含任何结果的不可能事件 |
| $A^c$ | 对立事件 | $\Omega$ 里挖掉 $A$ 剩下的部分 |
| $P(A\cap B)$ | 交事件概率 | $A$、$B$ 同时发生的概率 |

从三条公理能免费推出一堆常用结论（选读部分给出推导）：

| 结论 | 内容 |
| --- | --- |
| 对立公式 | $P(A)+P(A^c)=1$，"正难则反"的依据 |
| 不可能事件 | $P(\varnothing)=0$（但反过来不成立！）|
| 单调性 | $A\subseteq B$ 则 $P(A)\le P(B)$ |
| 容斥公式 | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ |

## 4. 分步例题

**例**：掷两颗骰子，事件 $A$="点数和为偶数"，事件 $B$="至少一颗是 6 点"。求 $P(A\cup B)$。

1. 样本空间：$\Omega=\lbrace(1,1),\ (1,2),\ \dots,\ (6,6)\rbrace$ 共 $36$ 个等可能结果；
2. 数 $A$：两颗同为奇或同为偶，各有 $3\times 3=9$ 种，共 $18$ 种，$P(A)=\frac{18}{36}=\frac{1}{2}$；
3. 数 $B$：第一颗是 6 有 6 种、第二颗是 6 又有 6 种，$(6,6)$ 被算了两次，共 $11$ 种，$P(B)=\frac{11}{36}$；
4. 数交集 $A\cap B$：至少一个 6 且和为偶，另一个也得是偶数：$(6,2)(6,4)(6,6)(2,6)(4,6)$ 共 $5$ 种；
5. 容斥：$P(A\cup B)=\frac{18}{36}+\frac{11}{36}-\frac{5}{36}=\frac{24}{36}=\frac{2}{3}$。

注意第 4 步：直接算并集会手忙脚乱，容斥公式让"重复部分"显形后被精确减掉。

连点「+2000」，柱子贴上橙线的过程就是大数定律在给"每个结果等可能"背书。盯住最高的那根柱子：和为 7 的组合有 6 种，这正是第 09 章数过的老朋友。

### 实验 2（python）：用枚举机器验证容斥公式

```python title="36 个样本点上验证 P(A∪B) = P(A)+P(B)−P(A∩B)"
pairs = []                       # 样本空间：装 36 个 (a, b) 组合的列表
for a in range(1, 7):            # 第一颗骰子的 6 种点数
    for b in range(1, 7):        # 第二颗骰子独立地再掷 6 种
        pairs.append((a, b))     # append：往列表末尾追加一个元素；(a, b) 是元组——打包在一起的一对数

def prob(event):                 # def 定义函数：传入"判断条件"，返回该事件的概率
    hits = 0
    for p in pairs:
        if event(p):             # 条件成立说明这个样本点属于事件
            hits = hits + 1
    return hits / len(pairs)     # len：列表中元素个数

pa = prob(lambda t: (t[0] + t[1]) % 2 == 0)   # lambda：现写的小函数；% 取余数，余 0 即偶数
pb = prob(lambda t: t[0] == 6 or t[1] == 6)
pab = prob(lambda t: (t[0] + t[1]) % 2 == 0 and (t[0] == 6 or t[1] == 6))
pu = prob(lambda t: (t[0] + t[1]) % 2 == 0 or (t[0] == 6 or t[1] == 6))

print(f"P(A)={pa}, P(B)={pb}, P(A∩B)={pab}")
print(f"P(A∪B) 直接数 = {round(pu, 4)}")
print(f"P(A)+P(B)−P(A∩B) = {round(pa + pb - pab, 4)}")
```

两种算法每次都严丝合缝——容斥公式不是近似，是公理推出来的恒等式。

### 快问快答

```quiz
事件 A 与它的补集 A^c，两者的概率有什么关系？
- 都等于 0.5
- 加起来等于 1 [*]
- 谁大谁小要看运气
? 整张地图被 A 和它的补集不重不漏地瓜分，面积自然加满 1。"正难则反"用的就是这条。
```

:::warning[常见误区]

**误区一**："你以为 $P(A\cup B)=P(A)+P(B)$ 永远成立。" 只有 $A$、$B$ **互不相交**时才行。本课例题里直接相加得 $\frac{29}{36}$，多算出了重叠的 $\frac{5}{36}$。

**误区二**："你以为概率为 0 就是不可能发生。" 在连续场景（下一卷预告）里，"指针恰好停在 0.5" 概率为 0 却并非不可能。公理只保证反方向：不可能事件概率必为 0。

**误区三**："你以为样本空间随便怎么取都行。" 同一次试验既可以按"点数和"分类也可以按"奇偶"分类，但**计算前必须固定一种**并在全程保持一致，否则"等可能"三个字就失去了意义。

:::

## 6. 练习

**练习 1**：掷两颗骰子，"和为 7 或 11"是赌场 Craps 游戏的开门彩。下面的代码能跑但只数了和为 7 的——改到通过：

```exercise
# @title: 练习：数出"和为 7 或 11"的样本点
# @check: 8
# @check: 0.2222
# @hint: 条件要同时容纳两种和：a+b==7 or a+b==11；概率用命中数除以 36 并保留四位小数
count = 0
for a in range(1, 7):
    for b in range(1, 7):
        if a + b == 7:          # ← 只认了一种和，另一种漏了
            count = count + 1
print(count)
print(round(count / 36, 4))
```

修好后对照：$8/36 = 2/9 \approx 0.2222$，比"和为 7"单独出现的概率高出一截——赌场的开门彩其实没那么稀有。

**练习 2**：已知 $P(A)=0.6$，$P(B)=0.5$，$P(A\cap B)=0.3$。求 $P(A\cup B)$ 和"$A$ 不发生"的概率。

<details>
<summary>点开查看逐步解答</summary>

容斥：$P(A\cup B)=0.6+0.5-0.3=0.8$；对立公式：$P(A^c)=1-0.6=0.4$。

顺手验证一下数据自洽：$P(A\cup B)=0.8 \le 1$ ✓，且 $P(A\cap B)=0.3 < \min(P(A),P(B))=0.5$ ✓。算完概率先查这两条，能抓住大多数笔误。
</details>

**练习 3**：证明"若 $A\subseteq B$ 则 $P(A)\le P(B)$"。

<details>
<summary>点开查看逐步解答</summary>

把 $B$ 拆成两块不相交的区域：$B = A \cup (B\cap A^c)$，其中 $A$ 与 $B\cap A^c$ 无公共样本点。由第三条公理的两事件推论（有限可加性）：

$$P(B)=P(A)+P(B\cap A^c)$$

第二项非负（第二条公理），所以 $P(B)\ge P(A)$。三行搞定——这就是公理化的威力：结论从规则里自己长出来。
</details>

## 7. 选读：为什么需要公理化

<details>
<summary>选读 · 频率定义的裂缝与"古典型"的循环</summary>

公理化之前，概率有两种流行定义，各有致命伤。**频率定义**（概率=大量重复中的稳定频率）直观好用，但"明天降雨"这类不可重复事件没有频率可谈；而且"稳定"本身需要概率语言来描述，有循环定义之嫌。**古典定义**（等可能结果中有利数除以总数）只适用于有限对称场景，"等可能"三个字更是偷偷用了概率。

柯尔莫哥洛夫的妙处在于把概率降格为**测度**——和长度、面积同一族的量：非负、可加、整体为定值。至于概率"对应现实里的什么"，公理系统不表态；频率解释只是它在重复试验场景下的一条定理（大数定律）。这一步让概率论摆脱哲学包袱，得以在测度论的疆域里狂奔——第 25 章《测度与勒贝格积分》会再遇到这套思路的连续版本。

顺带一提，"不是所有子集都能当事件"也是测度视角的发现：存在无法配面积的病态集合（维塔利集）。公理化因此要求事件组成一个对补集和可数并对封闭的 σ-代数——本卷的例子都是有限样本空间，全部子集天然合格，不必操心。

</details>
