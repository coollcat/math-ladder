# 逆变换采样：从均匀分布制造随机性

## 1. 从一个场景开始

计算机里最便宜的东西是"均匀的随机"：`random()` 一按，0 到 1 之间人人平等。可模拟世界需要的口粮五花八门——排队论要指数分布的顾客间隔、金融压力测试要厚尾收益、游戏要按自定义权重掉宝。难道每种分布都要单独买一块硬件？

上一课例题其实已经把钥匙递到你手里了：对均匀随机数取一次负对数，得到的样本经检验完全服从指数分布。这不是巧合，而是一台通用机器：**一枚均匀随机数 + 一个 CDF 的反函数 = 任意分布的样本**。它叫逆变换采样，是蒙特卡洛方法的第一块积木——第 39 章 MCMC、第 49 章生成模型的一切花活，地基都是这一块。

## 2. 直觉解释

把连续分布的 CDF 想成一根从 0 平滑爬升到 1 的坡道。现在玩一个"抽屉投币"游戏：

1. 掷出均匀数 $u$，当作在纵轴上选了一个抽屉高度（低处抽屉被选中概率与高处**完全相等**）；
2. 从该抽屉水平走到坡道，落点就是样本 $y$。

为什么样本会服从 $F$？因为坡道**平缓的地段占掉的纵轴区间小、陡峭地段占的大**——密的地方样本天然扎堆，疏的地方稀稀拉拉。"纵轴均匀 → 横轴带权重"，正是密度信息换了个方向存进去的形象说法。

几何语言再压缩一句：$F$ 是单调上坡，反函数 $F^{-1}$ 就是把它折过来读——拿概率找分位数。平时查百分位表是"横轴进、纵轴出"；采样时反向刷卡："纵轴进、横轴出"。

## 3. 正式定义

**定理（逆变换采样）**。设 $X$ 是连续随机变量，CDF $F$ 严格增且连续，$U$ 在 $[0,1]$ 上均匀。定义

$$Y=F^{-1}(U)$$

则 $Y$ 与 $X$ 同分布。证明短得可以背下来：

$$P(Y\le y)=P(F^{-1}(U)\le y)=P(U\le F(y))=F(y)$$

最后一步用了均匀分布的基本性质 $P(U\le a)=a$；第二步是把 $F^{-1}$ "刷回原方向"。注意严格增性质只在保证 $F^{-1}$ 良定义时用得上；真实工程里 CDF 常有平台段，处理方式见边界一节。

离散版定理同样成立但要用**查表法**代替闭式反函数：把取值按顺序排好 $(x_1,x_2,\dots)$，累计概率表 $(p_1,\ p_1+p_2,\ \dots)$ 一路砌到 1；掷出 $u$ 后扫描表格，第一个累计值压过 $u$ 的行就是答案。数值实现时这一版比"找公式"更常用。

## 4. 分步例题

从头造一台指数分布发生器（参数 $\lambda$）：密度 $f(y)=\lambda e^{-\lambda y}$，累积函数

$$F(y)=1-e^{-\lambda y}, \qquad y\ge0$$

三步流水线：

1. **反解**：令 $u=1-e^{-\lambda y}$，移项得 $e^{-\lambda y}=1-u$，两边取自然对数
$$y=-\frac{\ln(1-u)}{\lambda}$$
2. **灌入均匀数**：$U$ 在 $[0,1]$ 均匀时，$1-U$ 也均匀——严谨公式里的 $1-u$ 可整体换成 $u$（两者同分布），工程惯例写作
$$Y=-\frac{\ln U}{\lambda}$$
3. **当场验两件货**：代入 $u=\tfrac12$ 得 $Y=\dfrac{\ln2}{\lambda}$——正是指数分布的中位数；再求均值 $E[Y]=\dfrac{1}{\lambda}$，和第 60 课的规格书一字不差。

顺手再造个玩具款巩固手感：设某怪分布 $F(y)=y^2$（$0\le y\le1$）。反解得 $y=\sqrt u$——均匀数的平方根就服从它，与上一课"$X^2$ 变换"互为镜像，两个方向都通了。

### 实验 2（python）：反演指数分布并给直方图验明正身

```python title="numpy.random.uniform 反演指数分布 λ=0.5：直方图 vs 理论密度"
import numpy as np                      # numpy 已在第 21 章登场；np 是约定短名
import matplotlib.pyplot as plt         # 绑图库短名 plt（此前课程已引入）

rng = np.random.default_rng(seed=2026)  # default_rng：新版随机数发生器；seed 固定保证可复现
N = 100000                              # 样本量
u = rng.uniform(size=N)                 # uniform：N 个 [0,1) 均匀随机数组成数组
lam = 0.5                               # 指数参数
y = -np.log(u) / lam                    # ← 本课主角一行：逆变换采样（log 逐元素自然对数）

mean_sim = np.mean(y)                   # mean：数组平均值
print(round(mean_sim, 4))               # 理论均值 1/λ = 2

plt.hist(y, bins=80, density=True,      # hist：直方图；bins 分桶数；density 归一成面积 1
         alpha=0.6, label="sample")     # alpha：透明度；label 供图例使用
ys = np.linspace(0, 12, 400)            # linspace：0 到 12 均匀切 400 个点
plt.plot(ys, lam * np.exp(-lam * ys), linewidth=2, label="theory")   # 理论密度曲线
plt.legend()                            # legend：显示对照表
```

运行后直方图的阶梯轮廓应当严丝合缝地贴着红色理论线，第一行打印贴近 $2.0$——十万枚均匀数经一次取对数完成"投胎"。把 `seed` 改掉再跑，形状不变、细节抖动换一批：这就是模拟的复现性与统计性兼得。

### 实验 3（python）：离散版查表采样器——按权重掉宝

```python title="四档掉宝权重 5:3:1:1 的查表采样器与频率体检"
import numpy as np

weights = [5, 3, 1, 1]                  # 各档位的相对权重
total_w = sum(weights)                  # 权重总和 = 10
cum = []                                # 累计概率表：[0.5, 0.8, 0.9, 1.0]
run_total = 0.0                         # 滚动累计器
for w in weights:
    run_total += w / total_w            # 归一后逐项累加
    cum.append(run_total)               # append：追加到累计表尾

rng = np.random.default_rng(seed=7)
N = 100000
draws = np.zeros(4)                     # 四个档位的计数桶清零
for i in range(N):
    u = rng.uniform()                   # 单个均匀数
    for k in range(4):                  # 扫描累计表
        if u < cum[k]:                  # 第一个压过 u 的行即命中档位
            draws[k] += 1               # 对应计数桶自增
            break                       # break：跳出本轮扫描

freqs = draws / N                       # 频率 = 计数除以总数
for k in range(4):
    print(k + 1, round(freqs[k], 4))
```

四个打印应分别贴着理论值 $0.5,\ 0.3,\ 0.1,\ 0.1$ 微微摆动。机器只认两种原料：一张排好序的累计表、源源不断的均匀数——现实里的宝箱、排队的顾客、文本生成的 token 采样，拆开全是这个骨架。

:::warning[常见误区]

**误区一**："省掉那一步开方/取对数。" 把例题偷懒成"$Y$ 大概就是均匀数乘点系数"，得到的仍是均匀分布的仿射亲戚——永远弯不出指数的形状。公式的每一刀都来自反解，不可凭感觉裁剪。

**误区二**："对 $\ln(0)$ 的边界无感。" 若实现里均匀数可能取到 0，$\ln 0$ 直接负无穷爆炸。工程惯例是确保区间为半开 $(0,1]$ 或夹逼一下下界——写采样器时先问一句"端点谁闭谁开"。

**误区三**："以为它能造一切分布。" 离散版要扫表、连续版要有能反解的 CDF；正态的 CDF 积不出来初等表达式（只能数值反解或改用技巧），多维联合更是整体出局。逆变换是第一块积木，不是全部乐高——后续积木在第 39 章。
:::

## 6. 练习与快问快答

初始代码把例题的流水线抄错了两处符号位置：除号被写成乘号、还有一个参数用错行——请按"反解 + 灌入"的正确工序修好它，结清中位数、上四分位数与另一组参数的三笔账：

```exercise
# @title: 练习：修好指数发生器，当场验三件货
# @check: 6.931
# @check: 13.863
# @check: 11.513
# @hint: 反解公式 y = −ln(1−u)/λ：对数里是 (1−u)，λ 在分母；ln2≈0.693，ln4≈1.386，ln10≈2.303。
import math                             # math 库已登场：log 是自然对数

def exp_quantile(u, lam):
    return -math.log(u) * lam           # ← 乘号该是除号，且对数括号里应为 1−u（见提示）

print(f"{exp_quantile(0.5, 0.1):.3f}")  # 中位数：一半寿命在它之前
print(f"{exp_quantile(0.75, 0.1):.3f}") # 上四分位数：75% 的样本不超过它
print(f"{exp_quantile(0.9, 0.2):.3f}")  # 换一组参数再验一遍
```

<details>
<summary>点开查看逐步解答</summary>

修正后的函数只有一行：

```python
def exp_quantile(u, lam):
    return -math.log(1 - u) / lam       # 反解 CDF：u = F(y) 解出 y
```

三行输出依次为：$-\ln(0.5)/0.1=\dfrac{\ln2}{0.1}\approx6.931$、$-\ln(0.25)/0.1=\dfrac{\ln4}{0.1}\approx13.863$、$-\ln(0.1)/0.2\approx11.513$。第一行正是例题说过的指数分布中位数 $\ln2/\lambda$；第二行说明"超过 75% 寿命"的上四分位是中位数的两倍整——指数分布尾部又垫出一层$\dfrac{\ln4}{\ln2}=2$的自相似。当初版本错在哪：`* lam` 相当于把尺度单位缩小了平方量级（量纲体检：λ 的倒数才是单位），而漏掉的 `1 - u` 则把"存量"误当成了"越过量"——两个方向各偏一次，答案自然面目全非。

</details>

## 7. 选读：正态怎么造？Box–Muller 预告

<details>
<summary>选读 · 当反函数没有闭式时</summary>

正态分布的 CDF 用误差函数表示、积不出初等式，直接反解走不通；数值求根当然可行但每步都要迭代。经典替代方案 Box–Muller 只用两次均匀数瞬间变出两个标准正态：

$$Z_1=\sqrt{-2\ln U_1}\cos(2\pi U_2), \qquad Z_2=\sqrt{-2\ln U_1}\sin(2\pi U_2)$$

看穿它的钥匙恰是本课与本课之前的联动：把两枚独立标准正态换成极坐标 $(r,\theta)$，则半径平方 $r^2/2$ 服从 $\lambda=1$ 的**指数**——所以 $-2\ln U_1$ 就是逆变换给的半径，角度 $2\pi U_2$ 天然均匀。你已经在上一课亲手推导过"均匀翻身为指数"这道前菜，这里只是让它转了个方向登场。多举一例：Marsaglia 极方法再用拒绝法砍掉三角函数，属于第 39 章拒绝采样的剧透了。
</details>

## 8. 边界：本课不做什么

本课生产的每个样本都是独立同分布的单一变量；样本之间的**相关性结构**（比如 jointly normal、时间序列的相关）超出管辖范围。目标分布若没有可逆 CDF 或二维以上联合形态，需要升级装备：接受-拒绝采样、重要性采样与 MCMC 家族都在第 39 章驻场。此外所有讨论都假定连续分布有密度的情形；重尾到均值不存在的病态对象可以照样采样，但均值类体检会失效，那是第 37 章稳定分布的话题。
