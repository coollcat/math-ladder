# 随机变量函数的分布

## 1. 从一个场景开始

传感器的电路噪声 $X$ 建模成均匀抖动，但仪器真正记录的是功率——噪声的**平方**。均分布的噪声平方出来还是均匀的吗？想回答"功率多大算异常"，你必须知道 $Y=X^2$ 的密度长什么样，可手里的规格书只写了 $X$ 的。

这类"已知输入的分布，求加工后输出的分布"的需求无处不在：温度计读数要过一道摄氏转华氏的仿射变换；蒙特卡洛里我们只有均匀随机数，指望把它的分布"掰弯"成指数、正态（下一课正题）；第 39 章贝叶斯后验里的参数变换、第 49 章生成模型在潜变量空间和观测空间之间的来回搬运，全都是同一道工序。本课先给你两台通用机器：离散的**查表法**与连续的**换元法**——后者那里有一个必须付的过路费叫雅可比，欠费就会得出"概率变多了"的荒谬结论。

## 2. 直觉解释

连续版的核心画面是**质量守恒的水渠**。把密度想成一串水滴按位置铺开（每处单位长度含 $f(x)\,dx$ 克），函数 $y=g(x)$ 是一段水管地形：平缓段（斜率小）把水滴挤密，陡峭段把它们拉稀。输出端的"水位密度"自然等于

$$f_Y(y)=\frac{f_X(g^{-1}(y))}{|g'(g^{-1}(y))|}$$

一句话：**源头密度除以当地坡度**。坡度就是汇率的倒数——地形拉伸一倍的地方水滴摊薄一半。这条分式也解释了为什么直接把 $f_X$ 搬进新坐标是错的：搬完总水量就不再是 1，守恒律当场破产。

还有一台更笨但更万能的机器，永远可用：CDF 法。不谈密度先问累积——$F_Y(y)=P(g(X)\le y)$，把不等式一路解回 $X$ 的世界再用旧分布结账，最后若需要密度就求导一次。例题用它完整走一遍。

## 3. 正式定义

**情形一（离散：查表法）**。设离散 $X$ 的分布列为 $p_X(x)$，令 $Y=g(X)$，则

$$p_Y(y)=P(Y=y)=\sum_{x:\,g(x)=y} p_X(x)$$

多个原像撞到同一个像时概率合并——这是"表会重贴、总量不增"的第一课。映射可逆时更简单：把每行 $(x,\ p)$ 直接改写为 $(g(x),\ p)$ 即可。

**情形二（连续单调：换元法）**。设 $g$ 可微且严格单调，$Y=g(X)$，则

$$f_Y(y)=f_X\!\left(g^{-1}(y)\right)\cdot\left|\frac{d\,g^{-1}(y)}{dy}\right|=\frac{f_X\!\left(g^{-1}(y)\right)}{\left|g'\!\left(g^{-1}(y)\right)\right|}$$

因子 $\left|\dfrac{dg^{-1}}{dy}\right|$ 就是**雅可比汇率**：面积元从 $x$ 世界搬到 $y$ 世界时的兑换比价，与第 20 章重积分换元里的雅可比行列式是一家人（那时管两块面积元，这里管两个线段元）。

**万能保底（CDF 法）**：

$$F_Y(y)=P(Y\le y)=P(X\in g^{-1}((-\infty,y]))\quad\text{解出后}\quad f_Y(y)=\frac{dF_Y(y)}{dy}$$

它不要求单调（非单调时自动把几个分支的贡献加总），选读给出对应的一般公式。

## 4. 分步例题

完整走一遍 CDF 法——顺便为下一课预埋一枚关键零件。设 $X$ 在 $[0,1]$ 上均匀分布，取 $Y=-\ln X$：

1. **支持范围**：$X\in(0,1]$ 时 $-\ln X$ 从 $\infty$ 一路降到 $0$，所以 $Y$ 取值在 $(0,\infty)$；
2. **列 CDF 方程**：
$$F_Y(y)=P(-\ln X\le y)=P(\ln X\ge -y)=P(X\ge e^{-y})$$
3. **用旧分布结账**：均匀分布下 $P(X\ge a)=1-a$（对 $0\le a\le1$），代入得
$$F_Y(y)=1-e^{-y}, \qquad y\ge0$$
4. **求导出密度**：
$$f_Y(y)=e^{-y}, \qquad y>0$$

这正是第 60 课介绍过的参数 $\lambda=1$ 的**指数分布**！均匀随机会经一次取对数翻身成寿命分布——这个零件下一课就叫它"逆变换采样"。先用数值实验确认我们没被骗。

### 实验 2（python）：数值验证例题的三件套

```python title="E[Y]=∫₀¹ (−ln x) dx 与 P(Y>1)：两条路线对账"
import math                             # math 库在第 03 章已登场（log = 自然对数）

N = 10000                               # 中点矩形的块数
total = 0.0                             # 均值积分的累计器
for i in range(N):
    x = (i + 0.5) / N                   # 每块的中点横坐标
    total += -math.log(x) / N           # 高度 × 宽度(=1/N)

tail_rect = 0.0                         # 尾概率积分器：P(Y>1)=∫₁^∞ e^{−y}dy 的离散化
M = 10000
for j in range(M):
    y = 1 + (j + 0.5) / M               # 从 1 开始向右铺矩形
    tail_rect += math.exp(-y) / M       # 密度 e^{-y} 乘宽度

tail_cdf = math.exp(-1)                 # CDF 路线：P(Y>1)=e^{−1} 一招封顶
print(round(total, 4))                  # ≈ 1.0，指数分布 λ=1 的期望恰为 1/λ
print(round(tail_rect, 4), round(tail_cdf, 4))
```

第一行打印约 $1.0$（矩形截断只差末位），第二行两个数在小数点后三位内握手：离散积分与 CDF 闭式互相背书。想再补一张照片：把"取负对数的均匀随机数"的大样本直方图与密度 $e^{-y}$ 叠画——那是下一课的主场作业，这里先立字据。

### 实验 3（python）：非单调也要守法——X 平方的两支贡献

```python title="X 在 [-1,1] 均匀、Y=X²：两分支密度相加后总面积必须回到 1"
# 理论：每个分支各贡献 1/(4√y)，合计 f(y)=1/(2√y)
# 数值检查 ∫₀¹ 1/(2√y) dy 是否等于 1
N = 10000
area = 0.0                              # 面积累计器
for i in range(N):
    y = (i + 0.5) / N                   # 在 (0,1) 内取中点避开 0 的除零
    area += 1 / (2 * y ** 0.5) / N      # 待验证密度的中点求和
print(round(area, 4))                   # ≈ 1.0 说明两支相加没有漏也没有多
```

若忘记"两个原像各交一份税"，只算单支会得到约 $0.5$ 的残废面积——守恒律一眼识破。平方前匀称、平方后偏科：均匀的对称噪声经过功率表就挤成了前重后轻的长尾，这正是开头传感器故事的答案雏形。

:::warning[常见误区]

**误区一**："直接把 f 搬家。" 认为输出密度就是旧密度在反函数处的取值就完事，忘了乘雅可比。检验法最朴素：算出来的密度积不出 1 就是欠费。第 6 节练习专治这一症。

**误区二**："公式只管单调，我就假装单调。" 平方函数把两个原像压到同一个像上，PDF 必须把几个分支**加总**；CDF 法天然处理这种情况——先把累积概率方程解干净，再看要加几支。

**误区三**："支持范围懒得验。" 取负对数只吃 $(0,1]$ 的自变量、产出 $(0,\infty)$；若不划范围，把负半轴也套进公式会得出荒谬的正密度。动笔第一步永远是问"新的取值世界到哪里为止"。
:::

## 6. 练习与快问快答

迎面撞上开头的传感器问题：$X$ 在 $[0,1]$ 上均匀，$Y=X^2$ 是它的功率读数。初始代码给功率记了两本账——均值账已经搭好且正确，但生存概率那行出了两个毛病：直接路线多套了一层根号（算成了别的东西），公式路线又把反函数错当成线性。请修好它们，让两张账页合拢：

```exercise
# @title: 练习：功率 Y=X² 的两条账本必须对得上
# @check: 0.3333
# @check: 0.5000
# @hint: P(X² ≤ t) = P(X ≤ 根号t)——先开方再查均匀分布；生存概率记得用 1 减去它。
import math                             # 第 03 章登场的自然库，这里只用 sqrt

N = 10000
total = 0.0                             # E[Y] = E[X²] 的中点矩形积分
for i in range(N):
    m = (i + 0.5) / N                   # 在 [0,1] 上的中点
    total += m * m / N                  # 高度 m² 乘步长 1/N

t = 0.25                                # 问"P(功率超过 0.25)"
survival_direct = 1 - math.sqrt(math.sqrt(t))   # ← 多套了一层根号
survival_formula = 1 - t                # ← 把 X² 的反函数错当成了线性

print(f"{total:.4f}")
print(f"{survival_direct * 0 + survival_formula:.4f}")
```

<details>
<summary>点开查看逐步解答</summary>

病根定位：累积方程 $P(X^2\le t)=P(X\le\sqrt{t})$ 只需要**一次**开方，于是两条路线都应写成：

```python
survival_direct  = 1 - math.sqrt(t)     # 去掉多余的那层 sqrt
survival_formula = 1 - math.sqrt(t)     # 平方的反函数是根号，不是恒等
print(f"{survival_direct:.4f}")         # 0.5000
print(f"{survival_formula:.4f}")        # 0.5000 —— 两本账合拢
```

均值账页不必改：中点矩形和恰好算的是 $\int_0^1 x^2\,dx=\dfrac13\approx0.3333$。换元公式给出第三方解释：$f_Y(y)=\dfrac{1}{2\sqrt{y}}$，尾部 $\int_{0.25}^{1}\dfrac{dy}{2\sqrt y}=1-\sqrt{0.25}=0.5$——三条路一分不差。初版代码里 `1 - t` 错得自然：它回答的其实是线性世界的另一个问题（"$X$ 超过 0.25"）。变换世界里，**每一个字母都要想清楚活在谁的坐标系**。

</details>

## 7. 选读：一般公式与非单调的分支加法

<details>
<summary>选读 · 若 g 的定义域被分成多个单调段</summary>

设每一段上都可逆，限制在各段上的反函数依次记作 $h_1,h_2,\dots$。像集同一点 $y$ 会收到每段的汇款：

$$f_Y(y)=\sum_k f_X(h_k(y))\cdot\left|h'(y)\right|_{k}$$

平方变换就是两条腿的特例：左腿反函数是负根号、右腿是正根号，导数绝对值同为 $\dfrac{1}{2\sqrt y}$；均匀密度 $\tfrac12$ 各交一份税，合计 $\dfrac{1}{2\sqrt y}$——实验 3 的理论骨架。这个求和形式也是多维版本在低维的真身：哪里有挤压折叠，哪里就要按比例补钱，二维及以上由第 20 章的雅可比行列式统一结账。
</details>

## 8. 边界：本课不做什么

单变量机器不解锁联合分布的整体搬运：两个变量同时变换要等二维雅可比上场（第 20 章工具可直接续杯）；"给定 Y 之后 X 怎么办"的条件分布变形也在门外。同理，我们只做确定性的函数加工——"反过来造一个指定分布的新变量"是另一道工序，那是下一课的职业描述。顺带备忘分布族的封闭性：正态过仿射仍是正态（参数搬家），均匀过任何仿射仍是均匀，但指数过了平方就会改姓——识别姓氏靠今天的公式，不靠气质。
