# 协方差与相关性：度量“一起动”

## 1. 从一个场景开始

上一课结尾埋了一颗种子：把两位变量拆开各看各的报表，会错过它们之间的全部私交。联合表已经把私交摊在纸面上了，可表格越宽越没法一眼读出"到底有多默契"。你需要一个数。

这个数的简历早就写好了两个上岗理由：投资里，两只股票同涨同跌的组合风险远大于互相补台的组合；机器学习里，几百个特征两两高度雷同时模型会被冗余信息灌晕。一个数字能不能把"一起动"的强度说清？这就是本课要发的那把尺子——先造**协方差**，再把它的量纲磨平成**相关系数**。

## 2. 直觉解释

什么叫"一起动"？回忆第 40 课处理单个变量散布的办法：先立重心（期望），再看每个点偏离重心多远。现在有两个变量 $X,Y$，各自有自己的重心 $\mu_X,\mu_Y$。让它们同时报偏离量：

- 该热的时候比平均更热、雨也下得比平时更狠——两个偏离**同号**，乘积为正；
- 天越冷人越爱喝热饮——一个正偏离配一个负偏离，乘积为负；
- 各动各的——正负掺半，加起来基本抵消成零。

所以"所有（偏离之积）的概率加权平均"天然带符号、带强弱：

$$\mathrm{Cov}(X,Y)=E[(X-\mu_X)(Y-\mu_Y)]$$

它与方差的血缘一眼可见：$\mathrm{Cov}(X,X)$ 就是 $\mathrm{Var}(X)$ 自己——协方差是把方差从单人照推广到了合影。

但它有个毛病：$X$ 用毫米、$Y$ 用千克计时，结果的单位就是"毫米·千克"，换个单位制数值全变，跨话题根本没法比大小。补救办法朴素得漂亮：除以两个标准差，把刻度统一磨成"多少倍标准差"。磨平之后的版本叫**相关系数** $\rho$，天生锁在 $[-1,1]$ 之间，从此任何两个变量都能公平对表。

## 3. 正式定义

设 $X,Y$ 的期望与方差都存在。

$$\mathrm{Cov}(X,Y)=E[(X-\mu_X)(Y-\mu_Y)]=E[XY]-\mu_X\,\mu_Y$$

第二个等式是实战主力：先算乘积的期望，再扣掉两个重心的乘积，免得逐点减均值。

| 名称 | 定义 | 备注 |
| --- | --- | --- |
| 协方差 | 上式 | 单位是两者单位的乘积 |
| 相关系数 | $\rho=\dfrac{\mathrm{Cov}(X,Y)}{\sigma_X\sigma_Y}$ | 无量纲，恒有 $-1\le\rho\le1$ |

三条常用性质：

1. **退化即方差**：$\mathrm{Cov}(X,X)=\mathrm{Var}(X)$；
2. **双线性**：常数可以提出来，和可以拆开——$\mathrm{Cov}(aX+b,\ cY+d)=ac\,\mathrm{Cov}(X,Y)$；
3. **独立推出不相关**：独立时 $E[XY]=\mu_X\mu_Y$，故 $\mathrm{Cov}=0$。**反之不成立**！零协方差只说明没有线性联动，而独立性要求整张联合表每格都对上乘法等式——误区一节有个三行反例亲手拆给你看。

相关系数只测**线性**联动：散点若整齐贴在一条直线上，$\rho$ 就顶到 $\pm1$；若贴在一条弯得很漂亮的抛物线上，$\rho$ 却可能纹丝不动地停在 0。这一点在选读里有精确解释。

## 4. 分步例题

回收上一课的条件世界：掷两枚骰子，红记 $X$、蓝记 $Y$，先看"至少一枚六点"世界里的 11 张入场券——$(6,1),\dots,(6,6),(1,6),\dots,(5,6)$，每张概率同为 $1/11$。

直觉预告：在这个世界里知道"红是小点数"，立刻逼出"蓝必是 6"——两者被压向跷跷板两头，应当负相关。按定义结账：

1. 边缘重心：$\displaystyle \mu_X=\frac{1+2+3+4+5}{11}+\frac{6\times6}{11}=\frac{51}{11}$，对称地 $\mu_Y=\dfrac{51}{11}$；
2. 乘积极矩：全部格子贡献合计 $\sum xy=216$，故 $E[XY]=\dfrac{216}{11}$；
3. 二阶矩：$\displaystyle E[X^2]=\frac{1+4+9+16+25+36\times6}{11}=\frac{271}{11}$；
4. 组装：
$$\mathrm{Cov}=\frac{216}{11}-\frac{2601}{121}=\frac{2376-2601}{121}=-\frac{225}{121}\approx-1.860$$
5. 标准化（两边边缘相同，$\sigma_X\sigma_Y=\mathrm{Var}(X)=\dfrac{380}{121}$）：
$$\rho=\frac{-225/121}{380/121}=-\frac{45}{76}\approx-0.592$$

从无条件的 $\rho=0$ 到条件世界的 $-0.59$——**限制事件本身能在独立的老朋友之间拧出实实在在的负联动**。这正是辛普森悖论一类"条件翻转"现象的微观发动机。

### 实验 2（python）：滚双骰数据对拍——独立读零，混进自己立刻翻正

```python title="20000 对双骰实测 cov(红, 红加蓝)，并给出理论锚点"
import random                           # 已在第 01 章出生的随机库

N = 20000                               # 投掷对数
sx = st = sxt = 0                       # 链式赋值：一行给三个累计器清零
for t in range(N):
    red = random.randint(1, 6)          # randint(a,b)：闭区间内取随机整数
    blue = random.randint(1, 6)
    total = red + blue                  # 人为造一个与 red 强联动的量
    sx += red                           # += 是累加简写：sx = sx + red
    st += total
    sxt += red * total

mx = sx / N                             # 样本版期望：累计值除以次数
mt = st / N
cov_rt = sxt / N - mx * mt              # 样本协方差 = 乘积均值 − 均值之积
print("cov(red,total) ≈", round(cov_rt, 4))
print("理论锚点:", round(35 / 12, 4))   # 单枚骰子的方差恰是 Cov(X, X+Y)
print("相关系数 =", round(1 / 2 ** 0.5, 4))   # ** 0.5 就是开平方
```

模拟出的协方差应当贴着理论值 $2.9167$ 微微抖动。这里藏着一个可以笔算的漂亮事实：$\mathrm{Cov}(X,X+Y)=\mathrm{Var}(X)$——"自己和自己之和"的协方差恰是自己的方差。而相关系数等于

$$\rho=\frac{\mathrm{Var}(X)}{\sigma_X\sqrt{2\,\sigma_X^2}}=\frac{1}{\sqrt{2}}\approx0.7071$$

对拍的意义在于校准手感：把代码里的 `total` 换成 `blue` 再跑一遍，这把尺子会**读零**（理论真值就是 0，模拟值只在末位打转）；一旦换成掺了自身的 `total`，读数立刻跳到 $0.7071$ 的档位。独立与联动的分水岭，一次对拍看得清清楚楚。

### 实验 3（python）：条件世界数值复盘

```python title="11 张入场券的协方差账本：亲手复算 −0.5921"
cells = []                              # 收集全部合法 (红, 蓝)
for r in range(1, 7):
    for b in range(1, 7):
        if r == 6 or b == 6:
            cells.append((r, b))        # append：往列表尾部塞元素

n = len(cells)                          # len：列表长度，这里是 11
acc_xy = acc_x2 = 0                     # 链式赋值：两个累计器同时清零
sx_acc = sy_acc = 0
for r, b in cells:                      # 元组解包：一轮拿出一对数值
    sx_acc += r
    sy_acc += b
    acc_xy += r * b
    acc_x2 += r * r

mean = sx_acc / n                       # 与例题的分步演算逐一对应
cov = acc_xy / n - mean * mean          # 乘积矩 − 重心之积
second_moment = acc_x2 / n              # 二阶矩 E[X^2]
var = second_moment - mean * mean       # 边缘相同 ⇒ σxσy 恰为 Var
rho = cov / var                         # 相关系数收尾
print(round(cov, 4), round(rho, 4))
```

输出 $-1.8595$ 和 $-0.5921$，与例题手算分数严丝合缝。想再玩一步：把条件换成"红蓝之和恰为 7"，重新列票再算——$\rho$ 会恰好等于 $-1$：一点配六点、二点配五点，七点的搭配是一根焊死的跷跷板，毫无商量余地。

:::warning[常见误区]

**误区一**："协方差的数字越大越合拍。" 绝对值带着量纲出场：身高（厘米）×体重（千克）算出的数和身高（米）×体重（千克）相差一百倍，说的却是同一件事。跨场景比强弱请一律用相关系数。

**误区二**："相关就是因果。" 冰淇淋销量与溺水人数双双入夏走高，$\rho$ 稳稳为正——真正的推手是藏在背后的气温（混杂因子）。因果语言需要干预实验，那是第 42 章的事。

**误区三**："协方差为零就独立。" 反例只需两行：$X$ 等可能取 $-1,0,1$，令 $Y=X^2$。$\mathrm{Cov}=E[X^3]-0\times E[Y]=E[X]=0$ 干净利落；但 $P(X=1,Y=1)=\tfrac13$ 而 $P(X=1)P(Y=1)=\tfrac13\times\tfrac23=\tfrac29$——独立性当场阵亡。弯曲的依赖关系，线性尺子看不见。
:::

## 6. 练习与快问快答

下面五对数据来自某网课"复习时长 $x$（小时）与随堂得分 $y$"的试点记录。初始代码能跑，但算协方差那一步多除了一个 $n$——分子已经是"偏差乘积之和"，一除再除就把人均账算薄了一层；请修正病根，并把相关系数一并结清：

```exercise
# @title: 练习：修好协方差的除法账，再磨出相关系数
# @check: 3.0000
# @check: 5.0000
# @check: 2.4000
# @check: 0.9487
# @hint: cross_sum 是偏差乘积的总和，除以对数 n 才是平均每人份的协方差；ρ 用它除以两个样本标准差的乘积，开平方可以写 (var_x * var_y) ** 0.5。
xs = [1, 2, 3, 4, 5]
ys = [2, 4, 6, 6, 7]
n = len(xs)

mean_x = sum(xs) / n                    # sum：内置累加函数（早已登场）
mean_y = sum(ys) / n

cross_sum = 0
sq_sum_x = sq_sum_y = 0                 # 同时累计偏差平方，省得二次循环
for i in range(n):
    dx = xs[i] - mean_x                 # dx：当前 x 相对重心的偏离量
    dy = ys[i] - mean_y
    cross_sum += dx * dy                # 偏离同号贡献正、异号贡献负
    sq_sum_x += dx * dx
    sq_sum_y += dy * dy

cov_xy = cross_sum / (n * n)            # ← 多除了一个 n，人均账被算薄了

var_x = sq_sum_x / n                    # 样本版方差
var_y = sq_sum_y / n
rho = cov_xy / ((var_x * var_y) ** 0.5) # ** 0.5 即开平方（幂运算写法）

print(f"{mean_x:.4f}")
print(f"{mean_y:.4f}")
print(f"{cov_xy:.4f}")
print(f"{rho:.4f}")
```

<details>
<summary>点开查看逐步解答</summary>

病根一行：`cov_xy = cross_sum / n`。分子逐项展开：$(-2)(-3)+(-1)(-1)+0\times1+1\times1+2\times2=12$，于是 $\widehat{\mathrm{Cov}}=12/5=2.4000$。两侧方差分别是 $10/5=2$ 与 $16/5=3.2$，所以

```python
rho = cov_xy / ((var_x * var_y) ** 0.5)   # 2.4 / sqrt(6.4) ≈ 0.9487
```

相关系数高达 $0.9487$：五个点几乎躺在一根直线上。顺手做个体检回应误区一——若把 $y$ 全部翻倍再算，协方差变成 $4.8$，可 $\rho$ 一位不动：换算单位改变不了"抱团程度"这件事本身。
</details>

## 7. 选读：为什么 ρ 天生被锁死在 ±1 之内

<details>
<summary>选读 · 两行半的不等式证明</summary>

对任意实数 $t$ 考虑非负量 $E[(t\,(X-\mu_X)+(Y-\mu_Y))^2]\ge0$——概率加权下每个平方项都不小于零。按双线性展开，它是关于 $t$ 的二次三项式：

$$\sigma_X^2\,t^2+2\,\mathrm{Cov}(X,Y)\,t+\sigma_Y^2\ \ge\ 0 \quad\text{对一切 } t \text{ 成立}$$

二次函数恒非负要求判别式不得超过零：

$$\mathrm{Cov}(X,Y)^2\le\sigma_X^2\,\sigma_Y^2$$

两边开方再除过去就是 $|\rho|\le1$（这是柯西–施瓦茨不等式的概率化身）。等号成立时判别式恰好为零——存在某个 $t^\ast$ 使那个加权平方项的期望为零，即随机变量 $t^\ast(X-\mu_X)+(Y-\mu_Y)$ 几乎处处为零；翻译过来就是 $Y=aX+b$ 的严格仿射关系。这正是"$|\rho|=1$ 当且仅当完美直线"的身份证明。第 21 章 PCA 本质上是在高维重复这个论证：找使投影方差最大的方向，柯西–施瓦茨反复登场。
</details>

## 8. 边界：本课不做什么

$\rho$ 度量的是**边际之间的线性关联**，管不了三件事：一是因果方向——它连箭头都没有；二是多维联动的整体结构——三只股票两两 $\rho$ 都不大，也可能三者合计仍共振，那时要升级成协方差矩阵（PCA 与深度学习初始化的主食）；三是时间序列里变量与自己过去值的牵连（自相关），留给第 61 章。另外"相关性消失了但信息还在"的非线性通道（互信息）要等第 40 章才拿到自己的量纲。
