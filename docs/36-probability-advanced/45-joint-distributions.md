# 联合分布：把两个随机变量摆上同一张表

## 1. 从一个场景开始

周末出门要看两件事：热不热（$X$：气温档位）、下不下雨（$Y$）。天气预报说"今天偏热的概率 60%、下雨的概率 30%"。你顺手算出"又热又雨"的概率是 $0.6\times0.3=18\%$——慢着！这个乘法只对"互不串门的事件"合法。南方梅雨季偏偏又闷又湿，高温和降雨是联手出没的；把两位变量拆开各看各的报表，会错过它们之间的全部私交。

把两个随机变量放上同一张统计表格、连同它们的合体动作一起记账——这就是**联合分布**。它是从单个变量的算术走向多元世界的第一级台阶。

## 2. 直觉解释

先玩骰子。掷两枚不同的骰子，红骰点数记 $X$、蓝骰点数记 $Y$。每一次投掷产生一张入场券 $(x,y)$，比如 $(3,5)$；全部可能正好铺满一张 $6\times 6$ 的桌子，36 个格子每格概率 $1/36$，边走边填就把二维世界看全了。

再看天气那种"有私交"的版本。假设连续记录了 200 天：

| | 下雨 | 干燥 | 行合计 |
| --- | --- | --- | --- |
| 偏热 | 45 | 75 | 120 |
| 凉爽 | 15 | 65 | 80 |
| 列合计 | 60 | 140 | 200 |

顺着读：格子里的数就是联合概率 $\times 200$。沿边缘合计一下——$P(X=\text{热})=120/200=0.6$、$P(Y=\text{雨})=60/200=0.3$——这正是当初两条单变量报表的来历：**边缘分布是把二维表格沿行或列压扁得到的影子**。而"影子加回来"却不等于原表：$0.6\times0.3=0.18$，可实际的又热又雨占 $45/200=0.225$——多出来的 0.045 就是两件事勾结的证据。

压扁丢掉什么？只剩行号列号你自己；压扁之前还能问"给定下了雨，还热的比例多大？"——这是第三种视角**条件分布**，捏着表格的一列重新按比例分蛋糕。

## 3. 正式定义

设 $X,Y$ 是同一实验产生的两个离散随机变量。**联合概率质量函数**：

$$p(x,y)=P(X=x,\ Y=y), \qquad p(x,y)\ge 0, \qquad \sum_x\sum_y p(x,y)=1$$

三个派生量各有名字和算法：

| 名称 | 定义 | 表格语言 |
| --- | --- | --- |
| 边缘分布 | $p_X(x)=\sum_y p(x,y)$ | 沿行/列合计后除以总数 |
| 条件分布 | $p(x\mid y)=\dfrac{p(x,y)}{p_Y(y)}$ | 固定一列，格内占比按新分母重算 |
| 独立性 | $p(x,y)=p_X(x)\,p_Y(y)$ 对一切 $(x,y)$ 成立 | 每格 = 行影 × 列影 |

独立性是对整张表的判定：只要**任何一格**破坏乘法等式，就宣告不独立。天气表中又热又雨一格就足以定罪。

连续情形一句话过渡：把表格换成密度曲面 $f(x,y)$，格内概率换成区域上的二重积分，"全体积为 1"；压扁操作变成对另一维积分，投影出的正是第 37 章布朗运动每个时刻都要面对的那类二元世界。本课表格玩法通关后，曲面只是换了套措辞。

## 4. 分步例题

用天气表完整结算三笔账：

1. **联合概率**：$P(X=\text{热},Y=\text{雨})=\dfrac{45}{200}=0.225$；
2. **验证边缘还原**：行合计给出 $p_X(\text{热})=(45+75)/200=0.6$，列合计给出 $p_Y(\text{雨})=(45+15)/200=0.3$——与开头的单变量预报完全吻合，说明这张二维表是那两句预报的"无损原件"；
3. **条件概率**：已知下雨这天还偏热的概率 $P(X=\text{热}\mid Y=\text{雨})=\dfrac{45}{60}=0.75$；
4. **独立裁决**：独立的话应等于先验 $p_X(\text{热})=0.6$。$0.75\neq 0.6$，且注意方向感——下雨时反而更偏热，正是伏天雷阵雨的生活常识被数字讲了出来。

四步连起来读一遍：联合是全景照片，边缘是两张剪影，条件是拉着别人合影时的真实姿态。

### 实验 2（python）：在"至少一枚六点"的世界里重建联合表

```python title="条件改写后的 36 格桌面：数出来、加边缘、测独立"
table = []                             # 双层列表当 6×6 表格，初始全 0
for i in range(7):
    table.append([0] * 7)

count = 0                              # 记录符合“至少一枚 6 点”的天数
for red in range(1, 7):                # 外层跑红骰 1..6
    for blue in range(1, 7):           # 内层跑蓝骰 1..6
        if red == 6 or blue == 6:
            count += 1                 # += 即自增：count = count + 1
            table[red][blue] += 1

row_sum = [sum(table[r]) for r in range(7)]    # sum 累加列表：每行的边缘计数
col_sum = []
for c in range(7):
    acc = 0                            # 手工累加器逐列汇总
    for r in range(7):
        acc += table[r][c]
    col_sum.append(acc)

print(count)                           # 总天数：桌面上所有非零格之和
print(row_sum[5], col_sum[5])          # 红=5 的天数 与 蓝=5 的天数，会不会一样？

joint66 = table[6][6] / count          # 联合 P(红=6 且 蓝=6)
p_red6 = row_sum[6] / count            # 边缘 P(红=6)
indep = p_red6 * p_red6                # 若独立应有的值：(6/11)^2 ≈ 0.2975
print(round(joint66, 4), round(indep, 4))
```

输出依次是 `11`、`1 1` 和 `0.0909 0.2975`：新世界里只剩下 11 张合法入场券，而 $(6,6)$ 一格独占 1/11≈0.09，远低于独立预言的平方 $(6/11)^2\approx0.2975$——**条件限制能把独立的老朋友瞬间掰成不独立**。这个反差请记住，协方差课还会回收它。

### 实验 3（python）：给天气表画一张颜色地图

```python title="联合表的 imshow 快照：颜色越亮概率越大"
import matplotlib.pyplot as plt        # 导入绑图库短名 plt（浮窗首装自动生效）

weather = [[45, 75], [15, 65]]         # 行=偏热/凉爽，列=下雨/干燥
plt.imshow(weather, cmap="viridis")    # imshow：二维列表涂成颜色地图，数值大→颜色亮
plt.colorbar(label="days")             # colorbar：右侧颜色刻度尺
plt.xlabel("rain / dry")
plt.ylabel("hot / cool")
```

左上角那格最亮——又热又雨 45 天一目了然。这类"二维直方图"是浏览联合分布最快的肉眼工具，第 55 课散点图登场前先用它练眼。

:::warning[常见误区]

**误区一**："看到两个概率就直接相乘。" 乘法只在独立的桌上合法；先查表再说话。多少安全事故、金融事故都始于把联动的变量当成各过各的。

**误区二**："把行占比当联合概率。" 45 天换来的 0.225 是除以全天数的联合值；若先按"下雨天 60 天"归一得到 0.75，那是条件值——分子相同、分母不同，问题问法一变答案就变。

**误区三**："边缘分布能还原联合分布。" 影子只是投影，同一对边缘下面能藏无数张性格迥异的桌面；信息在压扁时就永久丢掉了。
:::

## 6. 练习与快问快答

三个数字已帮你垫好（还是那张 200 天天气表：又热又雨 45、又热又干 75、凉雨 15、凉干 65），修正最后一行的病根——它把条件概率的分母误用了总天数：

```exercise
# @title: 练习：天气表的三种概率各就各位
# @check: 0.2250
# @check: 0.3000
# @check: 0.3750
# @hint: 条件概率的分母是"限制之后的那个小世界"的人数（本行+同列对方格…确切说是这一列的雨天总数 45+15），不再是全部 200 天。
TOTAL = 200
joint_hot_rain = 45 / TOTAL            # 又热又雨的联合概率（沿用全局总数）
marginal_rain = (45 + 15) / TOTAL      # 下雨的边缘概率：列合计除以总天数
conditional_rain_given_hot = joint_hot_rain * TOTAL / TOTAL   # ← 分母错位了

print(f"{joint_hot_rain:.4f}")
print(f"{marginal_rain:.4f}")
print(f"{conditional_rain_given_hot:.4f}")
```

<details>
<summary>点开查看逐步解答</summary>

第三行的正确姿态是用"偏热的小世界"做分母：

```python
conditional_rain_given_hot = 45 / (45 + 75)
```

三行答案分别来自 $45/200=0.225$（联合）、$60/200=0.3000$（边缘）与 $45/120\approx0.375$（条件）。三个分数共用同一个分子 45，差别全在分母——这正是联合/边缘/条件的"一块分子三口锅"。若把联合错误地充作条件，你会宣称"雨天必热"，误差直接把 37.5% 吹成 22.5%。
</details>

## 7. 选读：连续 twins 与一张著名的联合密度

<details>
<summary>选读 · 从表格到曲面只差一次积分</summary>

取一对独立的标准正态 $X,Y$，其联合密度是一个漂亮的旋转面：

$$f(x,y)=\frac{1}{2\pi}e^{-\frac{x^2+y^2}{2}}, \qquad \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} f(x,y)\,dx\,dy=1$$

边缘化一积分，指数里剩下的字母恰好让另一维恢复标准正态——连投影都完美对称。若换成相关版（协方差课的高斯 cousins，相关系数 $\rho$ 进入指数），等高线立刻从圆压成椭圆；圆变斜椭圆的角度信息，就是你以后在回归与 PCA 里天天打交道的联动强度。二元之下还有三元乃至无穷元：第 55 号课之后每升一层，不过是多写几重积分而已。
</details>
