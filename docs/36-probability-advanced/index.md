## 实战挑战 · 千人筛查：逐个验还是分组混检？

某单位组织 1000 名职工体检。已知该疾病患病率为 1%；所用试剂对患者的检出率（灵敏度）为 99%，但对健康人有 2% 的误报率。为控制成本，行政部提出**分组混检**方案：随机 10 人一组，先把 10 份血样混合化验一次——阴性则全组放行，阳性才对组内每人再单独化验一遍（共 11 次）。题境属高中概率常见的筛查题材（2023 年新高考Ⅱ卷第 19 题即以漏诊率、误诊率设问）；分组混合检验的思想源自 Dorfman 在 1943 年提出的分组检验模型，此后成为筛查统计的经典题型。

本题采用理想化混检假设：混合血样只要含有至少一例阳性就呈阳性，不考虑混合稀释带来的灵敏度损失。

**(a)**（已示范）任取一人检出阳性的条件下，他真患病的概率是多少？
**(b)** 全单位 1000 人中，预计检出阳性多少人？（保留一位小数）
**(c)**（已示范）某一组 10 人的混合血样呈**阴性**的概率是多少？（各人检测结果相互独立）
**(d)** 混检方案下，平均每人摊到几次化验？（保留四位小数；提示：先算每组期望次数）

```exercise
# @title: 实战挑战：千人筛查的成本账
# @check: 0.3333
# @check: 29.7
# @check: 0.7397
# @check: 0.3863
# @hint: (a) 后验=患者阳性贡献÷总阳性率；(b) 人数×总阳性率；(c) 全组无阳性即每人皆阴：(1−p_pos)^10；(d) 组期望=1+11×(1−阴性概率) 再除以 10——中间步骤别提前四舍五入
p_pos = 0.01 * 0.99 + 0.99 * 0.02      # 任一职工"检出阳性"的总概率（全概率公式）
print(round(0.01 * 0.99 / p_pos, 4))   # (a) 已示范：阳性者中真患者的后验
print(round(p_pos * 0, 1))             # (b)：预计阳性人数 = 人数 × 总阳性率
neg_prob = (1 - p_pos) ** 10           # 一组 10 人全部阴性的概率（已示范写法）
print(round(neg_prob, 4))              # (c) 已示范
print(round(0 - 0, 4))                 # (d)：人均化验次数 = 组期望次数 ÷ 10
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 全概率公式：$P(\text{阳性})=0.01\times0.99+0.99\times0.02=0.0099+0.0198=0.0297$。贝叶斯翻转：

$$P(\text{患病}\mid\text{阳性})=\frac{0.0099}{0.0297}=\frac{1}{3}\approx0.3333$$

一千人里约 30 个阳性，真患者只有约 10 人——20 课的基率谬误在真实体检数据里如约而至。

**(b)** $1000\times0.0297=29.7$ 人。

**(c)** 一组呈阴性要求 10 人个个阴性，每人阴性概率 $1-0.0297=0.9703$，独立性连乘：

$$0.9703^{10}\approx0.7397$$

约七成四的组能一次放行。

**(d)** 组期望化验次数 $=1+11\times(1-0.7397)\approx1+11\times0.2603\approx3.863$ 次，人均 $\approx0.3863$ 次。

对照两个方案：逐一检验人均恰 1 次；混检人均约 0.3863 次——**省下六成以上工作量**。直觉核对：患病率越低，"全阴组"越多，混检越划算；当患病率高到一定程度（本题框架内可算临界值），混检反而亏本——这正是 Dorfman 模型要回答的管理问题。

交叉验算（走另一条路，数字必须吻合）：

```python
p_pos = 0.0297
neg = (1 - p_pos) ** 10          # 0.73966...
per_head = (1 + 11 * (1 - neg)) / 10
print(round(per_head, 4))
```
</details>

## 实战挑战 · 质量抽检与 A/B 上线

工厂与产品团队每天都在用同一套概率语言做决定。下面两问分别来自质量抽检和在线实验：

**(a)** 某精密轴的直径目标是 50.00 毫米。当前工序的真实均值是 50.15 毫米，标准差 0.40 毫米。质检员随机抽 64 根取平均，若样本均值低于 50.00 毫米就停机检查。用中心极限定理估计这个误触发的概率（保留四位小数）。

**(b)** 一个购物页当前转化率为 8%。新按钮随机分到 1000 名访客，成交 100 单；同期的旧按钮也服务 1000 名访客，成交 80 单。用两个比例差的标准化分数衡量优势：先在“两组无差异”的零假设下估计合并比例，再算差值标准误和 z 分数（保留三位小数）。

```exercise
# @title: 实战挑战：抽检报警与 A/B 优势分
# @check: 0.0500
# @check: -3.0000
# @check: 0.0128
# @check: 1.563
# @hint: 均值标准误是 σ/√n，不是 σ/n；两个比例差的标准误用合并比例 p(1−p)(1/n_A+1/n_B)，最后一起开根号
import math

se_quality = 0.40 / 64                  # ← 把标准差缩小时漏了开根号
z_quality = (50.00 - 50.15) / se_quality

p_pool = (0.08 + 0.10) / 2              # 两组人数相同时，合并成功率就是平均
se_ab = math.sqrt(p_pool * (1 - p_pool)) * (1 / 1000 + 1 / 1000)   # ← 差值标准误少开了总根号
z_ab = (0.10 - 0.08) / se_ab

print(f"{se_quality:.4f}")
print(f"{z_quality:.4f}")
print(f"{se_ab:.4f}")
print(f"{z_ab:.3f}")
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 单根直径的方差是 $0.40^2$；64 根均值的方差缩小 64 倍，所以均值标准误是

$$\mathrm{SE}=\frac{0.40}{\sqrt{64}}=\frac{0.40}{8}=0.05$$

阈值 50.00 比真实均值低 $0.15$ 毫米，即低 3 个标准误：$z=-3$。正态近似下，

$$P(\bar X<50.00)\approx P(Z<-3)\approx0.00135\approx0.0013$$

也就是说，若工序真的保持在 50.15 毫米，64 根一组的抽样均值跌破报警线的概率约千分之一点三。

**(b)** 零假设下两组来自同一个 9% 成功率总体：$p_{\text{pool}}=(80+100)/2000=0.09$。每次访问可看作伯努利变量，方差是 $p(1-p)$；两组均值之差的方差就是两边方差各除以各自的样本量再相加：

$$\mathrm{SE}=\sqrt{0.09\times0.91\times\left(\frac1{1000}+\frac1{1000}\right)}\approx0.0128$$

观察到的提升是 $0.10-0.08=0.02$，因此

$$z=\frac{0.02}{0.0128}\approx1.563$$

z 约为 1.56，说明新按钮有正向信号，但按常见的单侧 5% 临界值（约 1.645）还差一小步；更稳妥的做法是扩大样本或延长实验。
</details>
