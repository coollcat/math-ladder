# 矩母函数：把矩打包成一个函数

## 1. 从一个场景开始

你已经会算期望、方差，还听说过更高阶的"矩"（比如刻画偏斜的三阶矩）。但每多要一阶矩就得重新做一遍积分或求和，像一家只肯单卖的面包店：想要全麦、想要牛角包，各排各的队。

更麻烦的是两个实际问题。其一：**分布鉴别**——只知道前几阶矩（均值、方差、偏斜……），够不够把分布认出来？其二：**独立变量之和**——两枚骰子求和要老实卷积一张 $6\times6$ 表格；十个变量相加呢？本课的主角把这两件事一起办了：**一个函数打包全部矩**，而且"和"在它手里退化成普通乘法。它叫**矩母函数**——矩的母亲。

## 2. 直觉解释

构造思路来自幂级数的"压缩法"。回想第 15 章：$e^x$ 的泰勒展开里，每一阶系数整整齐齐排着队。现在把随机变量塞进指数：

$$E[e^{tX}]=E\left[1+tX+\frac{t^2X^2}{2!}+\frac{t^3X^3}{3!}+\cdots\right]$$

期望逐项作用后得到

$$1+tE[X]+\frac{t^2E[X^2]}{2!}+\frac{t^3E[X^3]}{3!}+\cdots$$

看清楚了吗？$X$ 的所有阶矩 $E[X],E[X^2],E[X^3],\dots$ 全部在场，只是各自裹着一件 $\dfrac{t^k}{k!}$ 的外套。整个无穷队伍被压成一行 $M(t)=E[e^{tX}]$——想把哪阶矩取出来，对着它求导再把 $t$ 归零即可：

$$E[X^n]=M^{(n)}(0)$$

这就是"母函数"的含义：不是它生出了矩，而是矩藏在这件大衣的褶皱里。另一张王牌属于独立性：若 $X,Y$ 独立，则

$$E[e^{t(X+Y)}]=E[e^{tX}]\,E[e^{tY}]$$

乘积的期望拆成因子的期望之积（独立的福利）——**和的矩母 = 矩母的积**。第 10 个骰子加入时不再有 36 格表格，只有十连乘。中心极限定理的现代证明正是踩着这条路走完最后一公里。

## 3. 正式定义

**定义（矩母函数）**：设 $X$ 是随机变量。若对某个开区间 $(-h,h)$ 内的一切 $t$ 都有 $E[e^{tX}]$ 有限，则称

$$M_X(t)=E[e^{tX}]$$

为 $X$ 的矩母函数。逐次求导并在 $0$ 处取值，就依次掏出各阶矩：

$$M'_X(0)=E[X], \qquad M''_X(0)=E[X^2]$$

（一般地 $M^{(n)}_X(0)=E[X^n]$；求导与期望交换的合法性由"在原点附近收敛"这一条件兜底。）于是方差也有打包写法 $\mathrm{Var}(X)=M''_X(0)-(M'_X(0))^2$。

**和的封闭性**：$X,Y$ 独立时

$$M_{X+Y}(t)=M_X(t)\,M_Y(t)$$

**唯一性（重要的"但是"）**：若 $X,Y$ 的矩母函数在 0 附近一段区间上相等，则两者同分布——一张简历认领一个人。这个条件的"附近"二字不可删：有的变量各阶矩全存在、矩母却在任何 0 的邻域外爆掉，此时矩牌素描会认错人，选读里点名。

三个常用家族的矩母表（都值得亲手推一遍）：

| 分布 | $M(t)$ | 备注 |
| --- | --- | --- |
| 伯努利 $(p)$ | $1-p+pe^{t}$ | 两点加权 |
| 几何/指数一族 | $\dfrac{\lambda}{\lambda-t}$（$t<\lambda$） | 域有半径！ |
| 正态 $(\mu,\sigma^2)$ | $e^{\mu t+\frac{1}{2}\sigma^2 t^2}$ | 光滑无奇点 |

## 4. 分步例题

把一枚公平骰子的全部前二阶矩装进一个袋子：

1. **写出函数**：逐点加权
$$M(t)=\frac{e^{t}+e^{2t}+e^{3t}+e^{4t}+e^{5t}+e^{6t}}{6}$$
2. **一阶求导代零**：每一项求导后带出各自的点数，$M'(0)=\dfrac{1+2+3+4+5+6}{6}=3.5=E[X]$——老朋友如约现身；
3. **二阶求导代零**：导数再乘一次自身指数，$M''(0)=\dfrac{1+4+9+16+25+36}{6}=\dfrac{91}{6}\approx15.1667=E[X^2]$；
4. **组装方差**：
$$\mathrm{Var}(X)=\frac{91}{6}-3.5^2=\frac{35}{12}\approx2.9167$$
5. **验货**：这与第 40 课直接求和的结论一字不差。同一袋子里还躺着三阶以上：继续求导即可，不必再回原始表格。

顺走一遍独立性红利：两枚骰子之和的矩母就是本例的平方，展开后 $21/36$ 乘以……不必展开到底——中心极限定理课要用的只是"$10$ 枚之和 = 十连乘"这个形态本身。

### 实验 2（python）：数值验证 M′(0) = E[X]

```python title="差分近似一阶导数：对称式读出期望 3.5"
def mgf(t):                             # def 定义骰子矩母函数
    total = 0.0                         # 浮点累计器从 0.0 起步
    for k in range(1, 7):               # range(1,7)：整数 1..6
        total += (2.718281828 ** (t * k)) / 6   # e 的 t·k 次幂，除以概率 1/6
    return total

h = 0.001                               # 差分步长：太小浮点抖，太大公式歪
slope = (mgf(h) - mgf(-h)) / (2 * h)    # 对称差分：两侧斜率平均，误差相消
print(round(slope, 4))                  # 应当打印 ≈ 3.5

slope_one_side = (mgf(h) - mgf(0)) / h  # 单侧差分：省了一半信息
print(round(slope_one_side, 4))         # 会读到 3.50 开头的小偏差
```

两个打印都在追 $3.5$，但单侧版明显带着小尾巴——它把曲率的一部分误记进了斜率账。对称差分让误差正负相消，这正是数值世界里"双侧证据更稳"的日常。想亲手感受偏差来源：把 `h` 先改大成 0.1 再改小到 0.000001 观察两条读数的走向。

### 实验 3（python）：独立之和的十连乘 vs 暴力卷积

```python title="8 枚骰子之和的矩母 = 单枚矩母的八次方，求导直接读出重心"
def mgf(t):                             # 单枚公平骰子的矩母（例题同款）
    total = 0.0
    for k in range(1, 7):
        total += (2.718281828 ** (t * k)) / 6
    return total

h = 0.001                               # 差分步长
sum_mgf = mgf(h) ** 8                   # ** 8 即八次方：和的矩母 = 矩母之积
slope8 = (mgf(h) ** 8 - mgf(-h) ** 8) / (2 * h)   # 对称差分近似其导数
print(round(slope8, 4))                 # 理论值 8 × 3.5 = 28

mu_check = 8 * 3.5                      # 期望线性性给出的对照答案
print(mu_check)
```

两个打印都在说同一件事：和的重心是 28。乘法路线漂亮在**不需要任何表格**——若按老办法卷积，八枚骰子的分布表要摊开六万多项；矩母这边只是把同一个数连乘八次再弯一下腰。等中心极限定理登场，你会看到这连乘如何在极限里坍缩成那枚优美的钟形指纹。

:::warning[常见误区]

**误区一**："求导完忘了把 t 归零。" $M'(t)$ 本身是个函数，不是矩；规矩是先求导、后代入 $t=0$。发现算出的"期望"还在随 $t$ 变化，多半是漏了这半步。

**误区二**："幂次或系数丢了。" 二阶导链上常见两种掉线：忘乘两次指数里的系数 $k$（丢幂次），或者方差公式写成 $M''-(M')$ 却忘了给后者平方。对照第 4 步的笔算清单逐项点名即可排查。

**误区三**："任何分布都有全场有效的矩母。" 几何/指数家族的 $M(t)$ 只在 $t<\lambda$ 有定义——过了红线直接爆炸；柯西分布更是连一阶矩都不存在，母函数无从谈起。域受限不影响 0 附近取矩，但跨分布比较时要留意各自的适用半径。
:::

## 6. 练习与快问快答

接住实验 2 的靶子：下面初始代码已经把二阶矩的正确差分骨架搭好，但在最关键的一行——方差结算时——把"减去一阶矩的**平方**"写成了只减不平方，功率直接跑偏；请修正病根并结清三笔账：

```exercise
# @title: 练习：从矩母函数里请出 E[X]、E[X²] 与方差
# @check: 3.5000
# @check: 15.1667
# @check: 2.9167
# @hint: Var = M''(0) − (M′(0))²——第二个 M' 要整体平方；差分模板 (M(h)−2M(0)+M(−h))/h² 别抄成除以 2h²。
def mgf(t):                             # 骰子矩母函数
    total = 0.0
    for k in range(1, 7):
        total += (2.718281828 ** (t * k)) / 6
    return total

h = 0.001                               # 差分步长
m1 = (mgf(h) - mgf(-h)) / (2 * h)       # 一阶导数的对称差分
m2 = (mgf(h) - 2 * mgf(0) + mgf(-h)) / (2 * h * h)   # ← 二阶差分的系数错配

variance = m2 - m1                      # ← 幂次丢了：该减的是 m1 的平方

print(f"{m1:.4f}")
print(f"{m2:.4f}")
print(f"{variance:.4f}")
```

<details>
<summary>点开查看逐步解答</summary>

两处修正：

```python
m2 = (mgf(h) - 2 * mgf(0) + mgf(-h)) / (h * h)      # 分母不带那颗多出来的 2
variance = m2 - m1 * m1                              # 方差公式要的是平方项
```

修好后三行输出为 $3.5000$、$15.1667$、$2.9167$——与例题笔算完全一致。两处病根的诊断口诀：差分模板分母写成 $2h^2$ 会把结果整齐腰斩成 $7.5833$——对 $e^x$ 做 $(e^{h}+e^{-h}-2)$ 的泰勒展开，一次项自动消失、二次项系数恰是 1，所以正确分母就是 $h^2$ 原始体，多除的 2 没有任何物理来源；而方差公式 $\mathrm{Var}=M''(0)-(M'(0))^2$ 的平方来自"偏离自己重心"的二阶动差定义，抄写时丢掉幂次，得到的会是 $11.6667$ 这种"半个方差加一截均值"的四不像。
</details>

## 7. 选读：当矩母集体失灵时

<details>
<summary>选读 · 同矩不同分布的反例与特征函数预告</summary>

构造两个不同分布却共享所有阶矩的经典组合：取标准对数正态 $Z$，令 $W=Z\cdot\sin(\pi Z)\cdot\mathbf{1}_{Z>0}$ 一族做微扰，可以拼出一个非零随机变量 $V$，其各阶矩 $E[V^n]=0$ 全部为零。于是 $X$ 与 $X+cV$ （$c\neq0$）分布不同，矩牌素描却完全一致——因为它们的母级数在任何正半径上都把 $V$ 的贡献吞成 0。教训：**只有当 $M(t)$ 在 0 附近一片实数开区间内有效时，唯一性才签字画押**。

补救方案是把指数搬进复数：$\varphi_X(t)=E[e^{itX}]$（[特征函数](./66-characteristic-function.md)，下一课正式成课）。复指数自带模长 1 的护身符，$\varphi$ 对一切实数 $t$ 永远存在，且唯一性无条件成立——代价是要动用一点复分析肌肉（第 24 章的预备知识回收到概率场）。中心极限定理的现代证明正是让一串特征函数逐点逼近 $e^{-t^2/2}$：那根钟形的矩母指纹。

</details>

## 8. 边界：本课不做什么

矩母不是万能钥匙：其一，它的存在域可能受限（几何、指数家族），比较时不能拿全域假设说事；其二，多数矩的一致≠同分布（选读反例），真正的完备武器是[特征函数](./66-characteristic-function.md)；其三，多维联合分布要升级成多元矩母 $E[e^{t^\top X}]$，本课只在单变量演练。此外别把它与第 61 章的傅里叶变换族谱搞混——两者同宗（都是期望套指数），记号与用途各有分工。
