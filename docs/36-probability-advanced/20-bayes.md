# 条件概率、独立性与贝叶斯

## 1. 从一个场景开始

某疾病患病率是千分之一。有种检测：患者检出阳性的概率 99%，健康人被误报阳性的概率只有 1%。你体检阳性了——慌吗？

直觉喊"99% 完蛋了"。但把人群规模放进来算一笔账，答案会让人愣住：**真患病的概率不到一成**。这不是抬杠，而是医院复检制度、垃圾邮件过滤器、雷达预警系统每天都在用的数学。这一课把它算明白。

## 2. 直觉解释

条件概率就是**缩小论域**（术语表的说法）：听说"今天下雨"，再问"路面湿的概率"——你的世界从"所有日子"缩到"雨天的日子"，在这个小世界里数比例。

信息改变概率，这正是"条件"二字的含义。上面体检题的关键是被忽略的**基础比率**：一万个人里只有约 10 个真患者，却有约 100 个健康人被误报——阳性的世界里，健康人是患者的十倍。

## 3. 正式定义

**条件概率**：在 $P(B)>0$ 时，

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $P(A\mid B)$ | 条件概率 | 已知 $B$ 发生时 $A$ 的概率；论域已缩到 $B$ |
| $P(A\cap B)$ | 联合概率 | $A$、$B$ 同时发生 |
| $P(A)$ | 先验概率 | 没有任何额外信息时的概率 |
| $P(A\mid B)$（更新后）| 后验概率 | 看到证据 $B$ 之后更新的概率 |

两条核心推论：

- **乘法公式**：$P(A\cap B)=P(B)\,P(A\mid B)$；
- **独立性**：若 $P(A\cap B)=P(A)P(B)$（等价于 $P(A\mid B)=P(A)$），称 $A$ 与 $B$ 相互独立——证据不改变判断。

把论域按一组互斥的"原因" $H_1,\dots,H_n$ 切开，就得到两件重型武器：

$$P(B)=P(H_1)P(B\mid H_1)+\cdots+P(H_n)P(B\mid H_n) \qquad (\text{全概率公式})$$

$$P(H_i\mid B)=\frac{P(H_i)\,P(B\mid H_i)}{P(B)} \qquad (\text{贝叶斯公式})$$

## 4. 分步例题

**例**：两台机床生产同一零件。甲机床产量占 60%，次品率 1%；乙机床占 40%，次品率 2%。现在手里有一个次品，它来自甲机床的概率是多少？

1. 定原因与证据：原因 $H_1$="来自甲"（先验 0.6），$H_2$="来自乙"（先验 0.4）；证据 $B$="查出次品"；
2. 各原因下证据的可能性（似然）：$P(B\mid H_1)=0.01$，$P(B\mid H_2)=0.02$；
3. 全概率公式算证据总概率：$P(B)=0.6\times0.01+0.4\times0.02=0.006+0.008=0.014$；
4. 贝叶斯公式翻回去：$P(H_1\mid B)=\dfrac{0.006}{0.014}=\dfrac{3}{7}\approx 0.4286$。

注意第 4 步的反直觉之处：甲的次品率更低、产量更大，可"来自甲"的后验仍接近一半——因为分母里乙的贡献（0.008）比甲（0.006）还大。先验和似然要合起来看，单看哪一个都会误判。

## 5. 动手实验

### 实验 1（python）：拖动患病率，看后验怎么翻身

```python title="滑块实验：基础比率如何改写后验"
# sliders: p=0.001 [0.001:0.2:0.001], sens=0.99 [0.5:1.0:0.01]
import matplotlib.pyplot as plt   # matplotlib.pyplot 已在第 00 章正式引入

fp = 0.01                         # 假阳性率：健康人被误报的比例（固定）

true_pos = p * sens               # 真阳性贡献：患病率 × 灵敏度
false_pos = (1 - p) * fp          # 假阳性贡献：健康率 × 误报率
post = true_pos / (true_pos + false_pos)   # 贝叶斯公式：阳性者中真患者的占比

print(f"患病率={p}, 阳性后真患病概率 = {round(post, 4)}")

plt.bar([0, 1], [true_pos, false_pos], color=["steelblue", "tomato"])
plt.xticks([0, 1], ["真阳性", "假阳性"])      # xticks：给横轴刻度换名字
plt.ylabel("人群中占比")
plt.title(f"阳性人群的构成（后验 {round(post, 4)}）")
```

把滑块 `p` 从 0.001 拖到 0.2：柱子此消彼长，后验从不足 9% 一路爬到九成以上。**检测器没变，变的是人群**——离开基础比率谈"准确率 99%"毫无意义。

### 实验 2（python)：万人大筛查的完整账本

```python title="10000 人筛查：每个格子都数出来"
N = 10000          # 筛查总人数
p = 0.001          # 患病率

sick = round(N * p)                 # 真患者人数：约 10 人
healthy = N - sick                  # 健康人：约 9990 人
tp = round(sick * 0.99)             # tp=true positive：患者中被检出阳性的
fp = round(healthy * 0.01)          # fp=false positive：健康人中被误报的

print(f"患者 {sick} 人，其中阳性 {tp} 人")
print(f"健康 {healthy} 人，其中误报阳性 {fp} 人")
print(f"阳性总计 {tp + fp} 人，其中真患者占 {round(tp / (tp + fp), 4)}")
```

阳性队伍约 109 人，真患者挤在里面只占约 9%。"检出阳性"这个证据把患病概率从 0.001 提到 0.09——提升了 90 倍，却仍然远远不是"确诊"。医学上因此规定阳性必须复检：两次独立检测连乘下来，假阳性才会被压垮。

### 快问快答

```quiz
事件 A 与事件 B 互斥（不可能同时发生），它们独立吗？
- 独立，反正互不相干
- 不独立，除非其中一个概率为 0 [*]
- 题目没给数据，无法判断
? 互斥意味着 A 发生时 B 必不发生，即 P(A|B)=0，这通常狠狠改变了 P(A)——证据影响巨大，恰恰是最强的不独立。"互不相干"是日常语言陷阱。
```

:::warning[常见误区]

**误区一**："你以为 $P(A\mid B)$ 和 $P(B\mid A)$ 差不多。" 方向反了，结论天差地别：$P(\text{阳性}\mid\text{患病})=0.99$ 而 $P(\text{患病}\mid\text{阳性})\approx 0.09$，差了十倍。贝叶斯公式的全部意义就是把一个方向翻译成另一个方向。

**误区二**："你以为'检测准确率 99%'意味着阳性的人 99% 有病。" 准确率说的是似然 $P(\text{结果}\mid\text{真相})$，你要的是后验 $P(\text{真相}\mid\text{结果})$。中间隔着基础比率——这就是著名的**基率谬误**。

**误区三**："你以为独立和互斥是一回事。" 独立是"互不影响"（乘积关系），互斥是"不能共存"（交集为空）。两个正概率事件要么互斥要么独立，不可兼得。

:::

## 6. 练习

**练习 1**：接着分步例题的机床场景，把代码补完——初始版只会算"任取一件是次品"的总概率，第二行还不是后验：

```exercise
# @title: 练习：次品来自哪台机床
# @check: 0.014
# @check: 0.4286
# @hint: 后验 = 甲的贡献 ÷ 总概率，即 0.6*0.01 / total；保留四位小数交给 round(x, 4)
pa, pb = 0.6, 0.4       # 两台机床的产量占比
da, db = 0.01, 0.02     # 两台机床各自的次品率

total = pa * da + pb * db        # 全概率公式：任取一件是次品的概率
print(round(total, 4))
print(round(total, 2))           # ← 这只是换个精度重复第一行，还不是"来自甲"的后验
```

跑通后再想一步：如果两台机床次品率相同，后验会变成多少？为什么？（提示：那时证据 $B$ 不再偏爱任何一台——独立性思想的反面教材。答案是恰好等于先验 0.6。）

**练习 2**：某种二次检测：首次阳性后复查一次，两次独立（每次灵敏度 0.99、误报率 0.01，患病率仍取 0.001）。两次都阳性的条件下真患病概率是多少？

<details>
<summary>点开查看逐步解答</summary>

患者两次皆阳：$0.99^2=0.9801$；健康人连续两次误报：$0.01^2=0.0001$。全概率：

$$0.001\times0.9801+0.999\times0.0001=0.0009801+0.0000999=0.0010800$$

后验 $=\dfrac{0.0009801}{0.0010800}=0.9075$——从一次检测的 9% 跃升到 90% 以上。独立的重复证据按指数速度碾压不确定性：这就是"复检"制度的数学内核。
</details>

**练习 3**：证明：若 $A$ 与 $B$ 独立，则 $A$ 与 $B^c$ 也独立。

<details>
<summary>点开查看逐步解答</summary>

要证 $P(A\cap B^c)=P(A)\,(1-P(B))$。把 $A$ 切成两块不相交的部分：$A=(A\cap B)\cup(A\cap B^c)$，于是

$$P(A\cap B^c)=P(A)-P(A\cap B)=P(A)-P(A)P(B)=P(A)(1-P(B))$$

第二步用了独立性假设。结论符合直觉："$B$ 的消息不影响 $A$"，那么"$B$ 没发生"的消息同样不该影响。
</details>

## 7. 选读：托马斯·贝叶斯与他留下的谜题

<details>
<summary>选读 · 从一道遗作到一大学派</summary>

贝叶斯（Thomas Bayes, 1701–1761）是苏格兰长老会牧师，生前发表的数学论文只有一篇；让他名垂青史的公式出现在身后的遗稿里，由朋友普莱斯整理宣读。他当初关心的并不是医疗诊断，而是一个反向问题：**看到数据之后，对原因的信念该如何修正**。

这个问题后来裂成两大阵营。频率学派坚持概率只能描述可重复事件的长期频率，参数是固定的未知量；贝叶斯学派则干脆把"参数的不确定性"本身也当成概率分布，用先验承载旧知识、用数据滚动更新后验——本课的体检计算就是这个世界观的一次微缩演出。第 39 章《贝叶斯统计》将正面交锋这两种立场；届时你会发现，垃圾邮件过滤、A/B 测试、乃至 AI 里的大多数推断算法，都是今天这条公式的直系后代。

</details>
