# 连续分布：均匀、指数与正态

## 1. 从一个场景开始

公交站牌写着"高峰期平均每 5 分钟一班车"。你到站的时刻是完全随机的——等待时间可以取 0 到 5 分钟之间的**任何**实数：3 分钟，3.14159 分钟，3.1415926 分钟……数轴上密密麻麻没有缝隙。

第 09 章的分布列在这里失灵了：等"恰好 3 分钟"的概率是 0，因为实数有无穷多个邻居分摊概率。概率不再是一根根柱子，而必须铺成**一整条曲线**——这一课就是学习读曲线、用曲线。

## 2. 直觉解释

把直方图无限细分：组距越切越窄，柱顶的锯齿越来越平滑，极限是一条光滑曲线——**概率密度函数**。它的读法彻底换轨：

- 曲线的**高度**不是概率（它可以超过 1！）；
- **面积**才是概率："等待时间落在 2 到 3 分钟之间"= 曲线下从 2 到 3 那块的面积；
- 全线下的总面积恒等于 1（所有可能加满）。

"高度不是概率"最反直觉。想想密度和质量的关系：一根不均匀的细棒，某点的"密度"可以是每厘米 2 克，但任何零长度的点都不装质量。密度是概率的**浓度**，不是概率本身。

三位主角的性格一眼可辨：

| 分布 | 密度形状 | 典型剧情 |
| --- | --- | --- |
| 均匀 | 平顶矩形 | 完全随机的一段等待 |
| 指数 | 从高台滑落的斜坡 | 无记忆的寿命与间隔 |
| 正态 | 对称钟形 | 大量微小因素叠加的结果 |

正态的钟形从哪来？先卖个关子：实验 1 的滑块会告诉你它的全部形状参数只有两个——中心 $\mu$ 和宽度 $\sigma$。

## 3. 正式定义

**概率密度函数** $f(x)$：满足 $f(x)\ge 0$ 且

$$\int_{-\infty}^{\infty} f(x)\,dx = 1, \qquad P(a\le X\le b)=\int_a^b f(x)\,dx$$

三个家族的密度与均值方差一览：

$$f_{\text{均匀}}(x)=\frac{1}{b-a}\ (a\le x\le b), \qquad E=\frac{a+b}{2}$$

$$f_{\text{指数}}(x)=\lambda e^{-\lambda x}\ (x\ge0), \qquad E=\frac{1}{\lambda},\quad \sigma^2=\frac{1}{\lambda^2}$$

$$f_{\text{正态}}(x)=\frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{(x-\mu)^2}{2\sigma^2}}, \qquad E=\mu,\quad \sigma^2 \text{ 即名字里的 } \sigma^2$$

指数分布还有一张招牌：**无记忆性**。$P(X>s+t\mid X>t)=P(X>s)$——已经等了 t 分钟，再等 s 分钟的概率和从头等完全一样，设备不会"越老越接近报废"（那是另一族威布尔分布的剧本）。

## 4. 分步例题

**例 1**：公交等待时间近似 $U[0,5]$（分钟）。等车不超过 3 分钟的概率？

1. 认模型：均匀分布，密度是平顶矩形 $f(x)=\frac{1}{5}$；
2. 概率即面积：$P(X\le3)=\text{宽}3\times\text{高}\frac{1}{5}=0.6$；
3. 通式一句话：均匀分布里"长度占比 = 概率"。

**例 2**：某元件寿命服从指数分布，平均寿命 $1/\lambda=10$ 年。活过 10 年的概率？

1. $\lambda=0.1$；存活过 $t$ 的公式 $P(X>t)=e^{-\lambda t}$；
2. 代入：$P(X>10)=e^{-1}\approx0.368$；
3. 解读：**平均**寿命 10 年的元件，挺过 10 年的只有约 37%——指数分布右拖长尾，多数早夭，少数长寿把平均拉到了中位数右边。"平均"又一次骗过了直觉。

### 实验 2（python）：指数分布的蒙特卡洛体检

```python title="模拟无记忆的到达间隔：直方图 vs 理论密度"
# sliders: lam=0.5 [0.2:2.0:0.1], n=50000 [5000:100000:5000]
import random
import math
import matplotlib.pyplot as plt

gaps = []                          # 收集相邻两次事件的间隔时间
for i in range(n):
    u = random.random()            # 均匀小数；反变换法：−ln(u)/λ 给出指数间隔
    gaps.append(-math.log(u) / lam)

plt.hist(gaps, bins=60, density=True, color="steelblue", label="simulate")

xs = []                            # 理论密度曲线 λ·e^(−λx)
ys = []
for k in range(100):
    x = 10 * k / 99                # 取 0 到 10 的横轴范围
    xs.append(x)
    ys.append(lam * math.exp(-lam * x))
plt.plot(xs, ys, linewidth=2.5, color="tomato", label="theory")
plt.legend()
```

柱子服帖地贴上橙色斜坡（`lam` 拖大坡更陡）。代码里的 `-log(u)/lam` 是**反变换法**：均匀数经对数一弯折就变成指数寿命——下一章排队论全靠它造顾客。

### 快问快答

```quiz
连续随机变量 X 在一点处取值的概率 P(X = a) 等于多少？
- 等于密度函数在该点的值 f(a)
- 等于 0 [*]
- 要看具体分布才能算
? 单点没有宽度，曲线下的面积自然是 0。这也解释了为什么 P(X<=a) 与 P(X<a) 在连续场合毫无区别。
```

:::warning[常见误区]

**误区一**："你以为 $f(2)=1.3$ 说明'X=2 的概率是 130%'。" 密度可以大于 1，它只是浓度的度量；有意义的永远是区间上的积分面积。看到密度超过 1 不要惊慌，看到有人把 $f$ 值当概率报数才要惊慌。

**误区二**："你以为'平均寿命 10 年'就该有一半元件活过 10 年。" 例 2 刚刚数过：指数世界只有约 37% 能达标。对称的正态才是"平均即中位"的世界，指数的长尾专门制造这种错觉。

**误区三**："你以为'正态'是说其他分布不正常。" normal 在这里的意思是"基准形态"——因为大量独立微小干扰叠加后都汇入这个形状（第 70 课的中心极限定理给出解释），而不是给其余分布颁发不合格证书。

:::

## 6. 练习

**练习 1**：地铁班次使等待时间近似落在 $U[2,8]$（分钟）。求密度值与"等 3 到 5 分钟"的概率。初始代码把区间长度记错了：

```exercise
# @title: 练习：地铁等待时间
# @check: 0.1667
# @check: 0.3333
# @hint: 均匀分布密度 = 1/(上限−下限)，长度是 8−2 不是 8；概率 = 目标长度 × 密度
length = 8                  # ← 区间 [2, 8] 的长度应该是多少？
density = 1 / length
prob = 2 * density          # 等待落在 3 到 5 分钟：目标段长 2 分钟
print(round(density, 4))
print(round(prob, 4))
```

修好后自查：密度 $\frac{1}{6}\approx0.1667$ 远小于 1，但乘上目标长度照样给出合法概率——密度从来不需要"小于 1"，面积才需要。

**练习 2**：某网站访问间隔服从指数分布，平均间隔 30 秒。求间隔超过 1 分钟的概率。

<details>
<summary>点开查看逐步解答</summary>

$\lambda=1/30$（每秒）。$P(X>60)=e^{-60/30}=e^{-2}\approx0.135$。

有趣的对照：上一课泊松练习里"一分钟一条评论都没有"也是 $e^{-2}$——这不是巧合，而是同一枚硬币的两面：间隔全超一分钟 ⇔ 这一分钟零到达。指数计数与指数间隔的孪生关系，第 37 章泊松过程课将正式认亲。
</details>

**练习 3**：证明均匀分布 $U[a,b]$ 的期望是 $\frac{a+b}{2}$。

<details>
<summary>点开查看逐步解答</summary>

两条路都通。几何路：矩形区域的重心在正中央，期望作为"重心"自然是区间中点。积分路：

$$E[X]=\int_a^b x\cdot\frac{1}{b-a}\,dx=\frac{1}{b-a}\cdot\frac{b^2-a^2}{2}=\frac{1}{b-a}\cdot\frac{(b-a)(b+a)}{2}=\frac{a+b}{2}$$

第三步用了平方差公式。两种算法互为验算——几何直觉负责猜答案，积分负责盖章。
</details>

## 7. 选读：钟形公式里的 π 是谁请来的

<details>
<summary>选读 · 从棣莫弗的骰子到拉普拉斯的误差律</summary>

1733 年前后，棣莫弗研究抛硬币大量次数的问题时，为了逼近二项分布算出了一个含 $\sqrt{\pi}$ 的指数表达式——正态密度第一次现身时，只是个技术性配角。近百年后，高斯与拉普拉斯把它扶正：测量误差总呈现这种钟形，于是它得名"高斯分布"、"误差律"。最小二乘法、正态先验、统计检验，全都踩着这条钟形曲线起飞。

至于为什么偏偏是这个公式？两个硬指标缺一不可：其一，它是熵最大的连续分布（给定均值方差下最"不加假设"的形状）——信息论卷册会给这句话精确含义；其二，它是二项、泊松乃至几乎一切独立扰动之和的共同归宿。第二句话的名字叫中心极限定理——第 70 课的主角终于要登场了（下一课先交出矩母函数这把瑞士军刀）。

</details>
