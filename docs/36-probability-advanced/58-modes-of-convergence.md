# 随机变量的四种收敛：强弱有别

## 1. 从一个场景开始

大数定律说："样本均值收敛到期望。"中心极限定理说："标准化后的均值收敛到正态分布。"

两句都用了"收敛"这个词，但它们说的**根本不是同一种收敛**。大数定律要的是"样本均值几乎不再乱跑"，而中心极限定理说的是"分布形状越来越像钟形"——后者的样本值本身可以剧烈跳动（比如掷硬币的均值可以一会儿 0.4 一会儿 0.6），只要分布形状对就行。

"收敛"在概率论里至少有四种含义，它们之间有严格的强弱次序。分不清它们，就读不懂大数定律和中心极限定理的区别，也理解不了为什么蒙特卡洛方法能收敛。

## 2. 直觉解释

拿一群随机变量 $X_1, X_2, \dots$ 来说，说它们"趋于 $X$"至少有四种意思：

**第一种：几乎处处收敛**——把随机实验做一次，得到一条完整的样本路径 $X_1(\omega), X_2(\omega), \dots$，这条路径本身作为数列收敛到 $X(\omega)$。**除了极少数倒霉的 $\omega$，每条路径都收敛。**

**第二种：依概率收敛**——不要求路径收敛，只要求"偏离得远的概率越来越小"。$n$ 很大时，$X_n$ 掉在 $X$ 附近的概率趋近于 1，但它**可能偶尔跳得很远**。

**第三种：$L^p$ 收敛（均方收敛）**——要求"误差的能量"趋于零：$E|X_n - X|^p \to 0$。这管住了偏离的**幅度**，而不只是概率。

**第四种：依分布收敛**——最弱的一种。连 $X_n$ 和 $X$ 定义在不在同一个空间都不管，只要求它们的**分布函数**逐点收敛。这是中心极限定理用的口径。

关键区别在于：**前三种要求 $X_n$ 离 $X$ 越来越近，第四种只要求"长得越来越像"。**

## 3. 正式定义

设 $X_1, X_2, \dots$ 与 $X$ 是随机变量。

| 收敛方式 | 记号 | 定义 | 强度 |
| --- | --- | --- | :---: |
| 几乎处处收敛 | $X_n \xrightarrow{a.s.} X$ | $P\!\left(\lim_{n\to\infty} X_n = X\right) = 1$ | 最强 |
| $L^p$ 收敛 | $X_n \xrightarrow{L^p} X$ | $E|X_n - X|^p \to 0$ | 强 |
| 依概率收敛 | $X_n \xrightarrow{P} X$ | $\forall \varepsilon>0:\ P(|X_n - X| > \varepsilon) \to 0$ | 中 |
| 依分布收敛 | $X_n \xrightarrow{d} X$ | $F_{X_n}(x) \to F_X(x)$ 在 $F_X$ 的连续点处 | 最弱 |

**蕴含关系**（箭头方向表示"推出"）：

$$X_n \xrightarrow{a.s.} X \;\Longrightarrow\; X_n \xrightarrow{P} X \;\Longrightarrow\; X_n \xrightarrow{d} X$$

$$X_n \xrightarrow{L^p} X \;\Longrightarrow\; X_n \xrightarrow{P} X$$

**反向都不成立。** 也就是说，依概率收敛是最弱的"真的在靠近"，依分布收敛甚至连"靠近"都不要求。

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $\omega$ | 样本点 | 一次实验的完整结果，藏着整条序列 |
| a.s. | almost surely | 除零概率集合外处处成立 |
| $F_{X_n}(x)$ | 分布函数 | $P(X_n \le x)$，只关心分布形状 |
| $\varepsilon$ | 容差 | 定义里任意给定的小正数 |

## 4. 分步例题

**例 1（依概率收敛但不 a.s. 收敛：滑动窗口）**：在 $[0,1]$ 上均匀取点，定义一串"指示随机变量"，第 $n$ 个取的区间越来越窄但不断移动位置——比如 $[0,1]$、$[0,\tfrac12]$、$[\tfrac12,1]$、$[0,\tfrac13]$、$[\tfrac13,\tfrac23]$……

1. 每个变量取 $1$ 的概率（也就是区间长度）都在趋于 $0$；
2. 所以 $P(|X_n| > \varepsilon) \to 0$——**依概率收敛到 0**；
3. 但对任意一个固定的点 $\omega$，这个区间序列会**无穷多次**扫过它（因为区间宽度趋零、位置却一直在动），所以 $X_n(\omega)$ 会在 $0$ 和 $1$ 之间来回跳，**不收敛**；
4. 结论：依概率收敛**推不出** a.s. 收敛。

**例 2（均方不收敛：尖峰序列）**：设 $X_n$ 以概率 $1/n$ 取 $n$，以概率 $1-1/n$ 取 $0$。

1. **依概率收敛**？$P(X_n > \varepsilon) = 1/n \to 0$，是；
2. **均方收敛**？$E|X_n|^2 = n^2 \cdot \frac1n = n \to \infty$，**发散**；
3. 结论：依概率收敛**推不出** $L^2$ 收敛——因为"概率小"不等于"幅度小"，尖峰可以又矮又少，也可以又高又稀。

**例 3（依分布收敛但不依概率收敛）**：设 $X\sim N(0,1)$，令 $X_n = -X$ 对所有奇数的 $n$，$X_n = X$ 对偶数 $n$。

1. 每个 $X_n$ 都是标准正态（**分布完全一样**），所以 $F_{X_n} = F_X$ 处处成立——**依分布收敛**；
2. 但 $|X_n - X|$ 在奇数时等于 $2|X|$，它不趋于 $0$（除非 $X=0$）——**不依概率收敛**；
3. 结论：依分布收敛**推不出**依概率收敛。原因很直观：依分布只看"形状"，两个完全不同步的序列可以有一样的分布。

**例 4（两种大数律的区别）**：把上面的地图用在两个定理上：

- **弱大数律**说 $\bar X_n \xrightarrow{P} \mu$（依概率）；
- **强大数律**说 $\bar X_n \xrightarrow{a.s.} \mu$（几乎处处）——**更贵的结论**；
- **中心极限定理**说 $\sqrt n(\bar X_n - \mu)/\sigma \xrightarrow{d} N(0,1)$（依分布）——**最弱的口径，却能给出具体的分布形状**。

**这就是为什么 CLT 能算置信区间而大数律不能**：大数律只说"会靠近"，CLT 说了"误差长什么样"。

## 5. 动手实验

先看 Example 2 的尖峰序列——概率在消失，但动能（二阶矩）在爆炸：

```python title="尖峰序列：依概率收敛，但均方发散"
def peak_sequence(n):
    """以 1/n 的概率取 n，否则取 0。返回 (发生的概率, 平方的期望)"""
    p_hit = 1 / n                     # 取到尖峰的概率
    e_square = n * n * (1 / n)        # E|X|^2 = n² · (1/n) = n
    return p_hit, e_square

print(f"{'n':>8}{'命中概率':>16}{'E[X²]':>14}")
for n in [1, 10, 100, 1000, 10000]:
    p, e2 = peak_sequence(n)
    print(f"{n:>8}{p:>16.6f}{e2:>14.1f}")
```

看两列的分道扬镳：命中概率 $1/n$ 一路冲向 $0$（**依概率收敛**），而 $E|X|^2 = n$ 一路冲向无穷（**均方发散**）。

再看 Example 1 的滑动窗口——用一段确定性的区间序列模拟"每个点被扫过无数次"：

```python title="滑动窗口：每个点都被无穷多次扫到"
# 把 [0,1] 上的均匀点离散成 100 个格子，观察每个格子被区间覆盖的次数
m_grid = 100
count = [0] * m_grid                  # 每个格子被覆盖的次数

def window_sequence(max_len):
    """生成 [0,1]、[0,1/2]、[1/2,1]、[0,1/3]、[1/3,2/3]、[2/3,1] … 这串区间"""
    seq = []
    for length_k in range(1, max_len + 1):
        for j in range(length_k):
            seq.append((j / length_k, (j + 1) / length_k))
    return seq

for lo, hi in window_sequence(6):
    for i in range(m_grid):
        x = (i + 0.5) / m_grid
        if lo <= x < hi:
            count[i] = count[i] + 1

print("最少被覆盖次数：", min(count))
print("最多被覆盖次数：", max(count))
print("区间总宽度递减，但每个点都被反复扫到 → 不收敛，只是概率趋于 0")
```

每个格子都被扫到过多次——**区间的总长度趋零，但没有任何一个点能"安定下来"**。这就是依概率收敛与 a.s. 收敛的分界线。

最后看依分布收敛的经典画面——二项分布随 $n$ 变大而"钟形化"：

```python title="依分布收敛：二项分布越来越像正态"
import math

def binom_prob(n, k, p):              # 二项分布概率（用阶乘手算）
    c = math.factorial(n) // (math.factorial(k) * math.factorial(n - k))
    return c * (p ** k) * ((1 - p) ** (n - k))

for n in [10, 40, 160]:
    peak = binom_prob(n, n // 2, 0.5)
    print(f"n = {n:>4}：中心处概率 {peak:.5f}，分布宽度约 {math.sqrt(n * 0.25):.2f}")
```

$n$ 越大中心概率越低、分布越"散开"——**单个取值的概率在消失，但分布的形状越来越稳定地趋向钟形**。这正是依分布收敛的图景：不要求路径靠近，只要求形状对齐。

### 快问快答

```quiz
下面哪种收敛最弱，连"X_n 与 X 离得近"都不要求？
- 依概率收敛
- 依分布收敛 [*]
- 几乎处处收敛
? 依分布收敛只要求分布函数逐点趋于相同，X_n 和 X 甚至可以在完全不同的空间——比如 X_n = -X 时两者分布一样，但距离是 2|X|，一点都不近。它是四种里最弱的一种。
```

:::warning[常见误区]

**误区一**："依分布收敛说明两个随机变量越来越接近。" 
完全不是。$X_n = -X$ 时两者分布永远相同（依分布收敛），但 $X_n$ 和 $X$ 的距离始终是 $2|X|$。**依分布只关心分布形状，不关心样本值。**

**误区二**："依概率收敛就够强了，和 a.s. 差不多。" 
差很多。滑动窗口的例子是标准反例：概率趋于 0，但**每条样本路径都不收敛**。a.s. 是"路径级别的结论"，依概率是"时刻级别的结论"——前者管整条轨迹，后者只看某一时刻掉在远处的可能性。

**误区三**："均方收敛比依概率收敛弱，因为二阶矩条件更宽松。" 
反过来。$L^p$ 收敛是**更强的**条件（它推出依概率收敛），因为控制住了偏离的幅度而不仅是概率。尖峰序列就是"依概率收敛但均方发散"的活证据。

**误区四**："中心极限定理是大数定律的加强版。" 
两者回答不同问题。大数律说"均值会靠近期望"（依概率或 a.s.），CLT 说"靠近的速度与误差分布长什么样"（依分布）。**CLT 的收敛方式在定义上比大数律更弱**，但它给出了更多可用的结构信息。

:::

**练习 2**：判断下面两个序列分别是哪种收敛（可能会有多种成立）。

- (a) $X_n$ 以概率 $1/n^2$ 取 $n$，否则取 $0$；
- (b) $X_n$ 在 $[0, 1/n]$ 上均匀分布。

<details>
<summary>点开查看逐步解答</summary>

**(a)** 命中概率 $1/n^2 \to 0$，所以**依概率收敛到 0**。二阶矩 $E[X^2] = n^2 \cdot 1/n^2 = 1$，不趋于 $0$——**不均方收敛**。

再检查 a.s.：$\sum P(|X_n|>0) = \sum 1/n^2 < \infty$，由 Borel-Cantelli 引理，**几乎处处收敛到 0**（比 (例 2) 的 $1/n$ 强，因为概率下降得足够快）。

**(b)** $P(|X_n| > \varepsilon) \le P(X_n > \varepsilon)$，当 $1/n < \varepsilon$ 时该概率为 $0$——**依概率收敛到 0**。$E[X_n^2] = \frac{1}{3}\cdot\frac{1}{n^2} \to 0$，所以**也均方收敛**。而 $X_n$ 属于 $[0,1/n]$ 且这些区间嵌套递减，对每个 $\omega \ne 0$，最终 $1/n < \omega$，此时 $X_n \le 1/n < \omega$，所以**几乎处处收敛到 0**。这个序列四种收敛全占。

```python
# (a) 的判别关键：概率衰减速度
for n in [10, 100, 1000]:
    print(f"n={n:>5}  1/n = {1/n:.5f}   1/n^2 = {1/n**2:.7f}")
print("1/n 的和发散、1/n^2 的和收敛 → Borel-Cantelli 给出 a.s. 结论")
```
</details>

## 7. 选读：为什么 a.s. 更强——Borel-Cantelli 的作用

<details>
<summary>选读 · 从"概率趋于零"到"路径必收敛"</summary>

**Borel-Cantelli 引理**：若 $\sum_{n} P(A_n) < \infty$，则 $P(A_n \text{ 无穷多次发生}) = 0$。

用它可以把"每个时刻的概率"升级成"整条路径的行为"：

设 $A_n = \lbrace|X_n - X| > \varepsilon\rbrace$。如果 $\sum P(A_n)$ 收敛（对每个 $\varepsilon$），那么**偏离超过 $\varepsilon$ 的情况总共只会发生有限次**——于是从某个时刻起，$|X_n - X| \le \varepsilon$ 恒成立。对每个 $\varepsilon$ 都这样，就得到 $X_n \to X$ 几乎处处。

回到例 2：$\sum 1/n = \infty$，条件不满足，Borel-Cantelli 给不了 a.s. 结论；而如果概率是 $1/n^2$，$\sum 1/n^2 < \infty$，立刻升级为 a.s. 收敛。

这就是依概率与 a.s. 的**技术分界线**：

| 条件 | 结论 |
| --- | --- |
| $P(A_n) \to 0$ | 依概率收敛（只管单个时刻） |
| $\sum P(A_n) < \infty$ | a.s. 收敛（管整条路径） |

强大数律的证明正是走了这条路：先证明 $E|\bar X_n - \mu|^4 = O(1/n^2)$，再用 Borel-Cantelli 把"四次矩衰减"升级成"几乎处处收敛"。**多出的那一层"四次矩"论证，就是强大数律比弱大数律贵的地方。**
</details>
