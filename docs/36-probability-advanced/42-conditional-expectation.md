# 条件期望：随信息更新的均值

## 1. 从一个场景开始

傍晚骑车去江边，你估摸"平均要骑 26 分钟"——这是按全部历史天气算的总平均。手机忽然弹出预告："傍晚有雨。"你心里那个数字立刻跳到 34：雨天路滑、逆风，这是**只拿雨天的数据**重新平均的结果。过了一会儿导航又补一句"风向有利"，数字再挪一格。

同一个问题（要骑多久），答案跟着信息一层层更新。贝叶斯那一课已经教过信息如何改写**概率**；这一课把同一把手术刀架到**平均**身上：每换一层信息，就有一条重新称量的均值——它叫**条件期望**。

## 2. 直觉解释

**先热身：骰子被告知了奇偶。** 掷一颗骰子，点数记 $X$。朋友瞟了一眼，只说两个字："偶数。"此刻你手里的世界从六种点数缩成三种：2、4、6，个个等权。重新称量：

$$E[X\mid \text{偶}]=\frac{2+4+6}{3}=4$$

若他说"奇数"，同样的动作给出 3。注意 4 和 3 都不是"新的真均值"——它们是**同一条均值在不同信息层上的投影**：奇偶各占一半机会出场，把两层投影按出场概率合回去，$0.5\times4+0.5\times3=3.5$，正是期望课那个老重心。

**再放大：分年级的平均身高。** 全校平均身高只有一个数；但"一年级平均""二年级平均"……各有各的数。拿着"某学生是三年级"这条信息，你就该用三年级的平均，而不是全校的总平均。条件期望就是**把总平均拆成一排"分校区平均"**，谁出场就报谁的数。

## 3. 正式定义

设离散随机变量 $X,Y$。在 $Y=y$ 这个信息层上，按条件概率重新加权：

$$E[X\mid Y=y]=\sum_x x\,P(X=x\mid Y=y)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $E[X\mid Y=y]$ | 条件期望（一个数） | 已知 $Y=y$ 时 $X$ 的概率加权平均；每个 $y$ 各有一个 |
| $E[X\mid Y]$ | 条件期望（随机变量） | 把每个 $y$ 的答案挂到 $Y$ 的对应出口上，随 $Y$ 一起摆动 |
| $E[E[X\mid Y]]$ | 条件期望的期望 | 先按各信息层称量，再按 $Y$ 的分布做一次普通平均 |
| 总期望公式 | $E[X]=E[E[X\mid Y]]$ | 分组平均再加权合并，必须回到总平均 |

总期望公式值得单独写一遍：

$$E[X]=\sum_y E[X\mid Y=y]\,P(Y=y)$$

它就是"分年级平均 × 各年级人数占比，合回全校平均"。竖线 $\mid$ 读作"给定"：$E[X\mid Y=y]$ 是"给定 $Y=y$ 之后"的意思。

**最要紧的一步**：$E[X\mid Y]$（不写 $=y$）不是一个数，而是一台**随信息换挡的计算器**——$Y$ 掷出几，它就报几号答案。既然 $Y$ 是随机变量，这台计算器的读数也是随机变量。

## 4. 分步例题

掷两枚骰子，$X$ 记点数之和，$Y$ 记第二枚的点数。

1. **固定信息层**：已知 $Y=y$，第一枚骰子仍是均匀的 1 到 6，于是 $E[X\mid Y=y]=\dfrac{1+2+\cdots+6}{6}+y=3.5+y$；
2. **得到一台计算器**：把六个答案挂上六个出口——$g(1)=4.5,\ g(2)=5.5,\ \dots,\ g(6)=9.5$，即 $g(y)=y+3.5$；
3. **抬升成随机变量**：$E[X\mid Y]=Y+3.5$。第二枚掷出几，对总和的预报就抬到几加 3.5；
4. **双路对账（塔公式）**：$E[E[X\mid Y]]=E[Y]+3.5=3.5+3.5=7$。另一条路把 36 格桌面直接平均，同样得 7。两条路必须相遇——下一节的实验当场验收。

### 实验 3（python）：双路对账——直接平均 vs 分组再加权

```python title="同一笔总账走两条路，必须落到同一个 7"
import random

# 第一路：36 种组合全部摆开，直接平均
grand = 0
for first in range(1, 7):          # 第一枚骰子的六种点数
    for second in range(1, 7):     # 第二枚骰子的六种点数
        grand = grand + first + second
print(round(grand / 36, 4))        # 直接平均：总和除以 36 格

# 第二路：先算各出口的条件期望 g(y)=y+3.5，再按 P(Y=y)=1/6 加权
regroup = 0
for y in range(1, 7):
    regroup = regroup + (y + 3.5) / 6    # 每个出口的贡献 = 分组均值 × 出口概率
print(round(regroup, 4))           # 分组再加权：必须回到同一个数

# 蒙特卡洛：真掷十万次，频率平均也会滑向 7
total = 0
for trial in range(100000):
    d1 = random.randint(1, 6)      # randint(a,b)：取 a 到 b（含两端）的随机整数
    d2 = random.randint(1, 6)
    total = total + d1 + d2
print(round(total / 100000, 2))
```

三个读数都落在 7 附近。第二路不是重活一遍——它是**思维模板**：先固定信息分层称量，再按信息的分布合并。第 37 章鞅的定义、强化学习卷的价值方程，走的全是这条模板。

### 快问快答

```quiz
若 X 与 Y 相互独立，E[X|Y] 长什么样？
- 仍是随 Y 摆动的函数
- 退化成常数 E[X] [*]
- 一定等于零
? 独立时 Y 的任何信息都改不动 X 的分布：每个出口的分组平均都等于总平均，一排读数完全相同——计算器被压平成水平线。
```

::::warning[常见误区]

**误区一**："你以为 E[X|Y] 是一个数。" 只有写全 $E[X\mid Y=y]$ 才是一个数；$E[X\mid Y]$ 是挂在各出口上的一整排数，随 $Y$ 摆动。混用这两层记号，是后面鞅与随机分析路上最常见的绊脚石。

**误区二**："你以为总期望公式只是把同一笔账算两遍。" 它是"先分组、再合并"的思维模板，真正的用场在**算不动直接平均**的地方：分支过程、序贯决策、按状态预报的价值估计，都是分组容易、直接平均没门。

**误区三**："你以为 E[X|Y=y]=E[X] 就说明 X、Y 独立。" 这只说明**均值**不随信息变化（均值独立），比"不相关"强、比"独立"弱——分布的形状仍可以被 Y 改写。判断独立性，下一课教你查整张联合表。

::::

## 6. 练习

**练习 1**：回到第 2 节的奇偶热身。初始代码把"信息缩小世界"这件事做漏了——改到两行检查全部通过：

```exercise
# @title: 练习：被告知奇偶之后，均值走到哪
# @check: 4.0
# @check: 3.5
# @hint: 已知是偶数时世界里只剩 2、4、6 三个等权点数——平均要除以 3；总期望公式按"分组均值 × 出口概率"合并，奇偶两组的概率各是 1/2
ev_even = (2 + 4 + 6) / 6          # ← 偶数世界里，平均到底该除以几？
ev_odd = (1 + 3 + 5) / 6           # ← 奇数世界同款病
tower = ev_even + ev_odd           # ← 两组该按什么比例合并？

print(round(ev_even, 1))
print(round(tower, 1))
```

修好后的两个数：偶数世界 4.0，合并回 3.5——信息把均值从 3.5 拽到 4，塔公式又把它物归原主。

**练习 2**：两枚骰子，朋友透露"至少有一枚是 6 点"。此时点数和的期望是多少？（世界缩成 11 格）

<details>
<summary>点开查看逐步解答</summary>

合法组合 11 种：(6, y) 有六种，(x, 6) 另有五种，各占条件概率 1/11。点数和逐格相加：(6,1) 到 (6,6) 贡献 7+8+9+10+11+12=57，(1,6) 到 (5,6) 贡献 7+8+9+10+11=45，合计 102。于是

$$E[X\mid \text{至少一枚 6}]=\frac{102}{11}\approx 9.2727$$

比无条件期望 7 高出一大截——"出现 6 点"是抬高总和档位的信息。注意每个格子内部仍然均匀：条件化只改权重，不改格子里的算术。

</details>

**练习 3**：为什么 $E[E[X\mid Y]]$ 一定回到 $E[X]$？用"加权只是挪位置"讲一遍。

<details>
<summary>点开查看逐步解答</summary>

把总期望公式展开：$\sum_y E[X\mid Y=y]\,P(Y=y)=\sum_y\sum_x x\,P(X=x\mid Y=y)\,P(Y=y)$。而 $P(X=x\mid Y=y)\,P(Y=y)=P(X=x,\ Y=y)$——条件概率乘回出口概率，恰好还原联合概率；再对 $y$ 求和就把二维账本压回一行 $\sum_x x\,P(X=x)=E[X]$。全程没有任何新信息被创造或销毁，只是**先分组称量、再物归原主**。这也是它别名"塔性质"的由来：信息一层层搭上去，平均到底必须落回地面。

</details>

## 7. 选读：塔性质与"最好预测器"

<details>
<summary>选读 · 信息分层过筛，投影指哪打哪</summary>

**塔性质**：若信息 H 是 G 的一部分（先听细再听粗），则 $E[E[X\mid G]\mid H]=E[X\mid H]$。直觉就是分校区统计的常识：先按小区算平均、再按大区合并，等于直接按大区算。骰子例里，"两枚全知"是最细的一层，于是 $E[E[X\mid \text{全知}]\mid \text{只知第二枚}]=E[X\mid Y]=Y+3.5$。

**投影视角**：在方差有限的世界里，$E[X\mid Y]$ 是所有"只依赖 $Y$ 的函数"中离 $X$ 平方距离最近的那个——用现有信息能造出的**最好预测器**。回归分析的最小均方误差、维纳滤波、卡尔曼滤波，全都在这条投影原理上起高楼。

**户口落定**：第 37 章[鞅直觉](../37-stochastic-processes/90-martingale-intuition.md)里那条 $E[X_{t+1}\mid \mathcal{F}_t]=X_t$，当时只配了直觉版表格与"随历史变化的计算器"的说法——本课之后它有了正式户口：$\mathcal{F}_t$ 就是"截至 $t$ 的全部信息"这个出口集，鞅即"条件期望这台计算器的读数永远等于当前值"。后续强化学习卷的贝尔曼方程 $E[G_t\mid S_t=s]$，用的也是同一套记号。

</details>
