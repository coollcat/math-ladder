# 特征函数：矩生成武器的完全体

## 1. 从一个场景开始

上一课的选读里压着一张欠条：矩母 $M(t)=E[e^{tX}]$ 虽能打包全部矩，但它的存在域可能受限——几何、指数家族一到红线就爆炸；更糟的是"各阶矩全部对得上、分布却不同"的反例真能造出来，$M$ 这件大衣偶尔会认错人。柯西分布更是连期望都没有，矩母无从谈起。可分布识别、独立求和、中心极限定理的证明，都等着一件**对任何分布都签发**的完备武器。

欠条今天就兑。把指数里的 $t$ 换成 $it$——只动一个字母，上述麻烦全部烟消云散。换完之后的武器叫**特征函数**。

## 2. 直觉解释

欧拉公式（第 12 章）说 $e^{it}=\cos t+i\sin t$：复指数就是单位圆上转了 $t$ 弧度的一个点。于是 $e^{itx}$ 是"把取值 $x$ 乘上 $t$ 后搬到圆上转一圈的动作"，而

$$\varphi_X(t)=E[\cos(tX)]+i\,E[\sin(tX)]$$

是**两个投票箱的加权计票**：每个取值 $x$ 把一票投给 cos 箱（实部）、一票投给 sin 箱（虚部），权重是概率。整张分布被卷到单位圆上，特征函数就是它的**加权质心坐标**——随 $t$ 转动，扫出这条分布独有的"指纹轨迹"。

护身符在模长上：$\lvert e^{itx}\rvert=1$ 对一切 $x$ 恒成立（单位圆上的点不胖不瘦），加权平均的模长自然 $\le 1$。对比矩母里 $e^{tx}$ 的模长 $e^{tx}$ 会随 $x$ 爆炸——正是这一个字母的改动，让"期望不存在"这件事在特征函数的世界里**永远不会发生**。

## 3. 正式定义

**定义（特征函数）**：对任意随机变量 $X$（离散、连续、重尾一视同仁），

$$\varphi_X(t)=E\left[e^{itX}\right], \qquad t\ \text{为任意实数}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\varphi_X(t)$ | 特征函数 | 分布卷到单位圆上的加权质心；实部 cos 票、虚部 sin 票 |
| $\varphi(0)=1$ | 起跑线 | $t=0$ 时人人都是 1，一切指纹从这里出发 |
| $\lvert\varphi(t)\rvert\le 1$ | 护身符 | 模长永不过界——存在性无条件的根源 |
| $\varphi^{(n)}(0)=i^nE[X^n]$ | 取矩口诀 | 求导剥一层、代零取一件，再除掉 $i$ 的幂次 |

三条王牌性质，前两条与矩母同款，第三条是质的飞跃：

1. **独立和 = 乘积**：$X,Y$ 独立时 $\varphi_{X+Y}(t)=\varphi_X(t)\,\varphi_Y(t)$；
2. **取矩口诀**：$\varphi'(0)=iE[X]$、$\varphi''(0)=-E[X^2]$（$i^2=-1$ 自动进来）；
3. **唯一性无条件**：两条分布的特征函数对一切 $t$ 相等，当且仅当分布相同——不需要矩母那条"在 0 附近一片区间有效"的附加条款，认人从不出错。

## 4. 分步例题

**例**：标准正态密度 $p(x)=\frac{1}{\sqrt{2\pi}}e^{-x^2/2}$，求它的特征函数。

1. **密度恒等式**：先对密度求导，$p'(x)=-x\,p(x)$，即 $x\,p(x)=-p'(x)$——正态密度恰是自己导数的负倍；
2. **代入定义求导**：$\varphi'(t)=E[iXe^{itX}]=i\int x\,e^{itx}p(x)\,dx=-i\int e^{itx}p'(x)\,dx$；
3. **分部积分**：$\int e^{itx}p'(x)\,dx=\bigl[e^{itx}p(x)\bigr]_{-\infty}^{\infty}-it\int e^{itx}p(x)\,dx=0-it\,\varphi(t)$——边界项被高斯的细尾巴压成零；
4. **得微分方程**：$\varphi'(t)=-t\,\varphi(t)$，配初值 $\varphi(0)=1$；
5. **解出**：$\varphi(t)=e^{-t^2/2}$——钟形的指纹，还是一枚钟形。

矩当场验收：$\varphi'(0)=0$ 给出 $E[X]=0$；$\varphi''(0)=-1=-E[X^2]$ 给出 $E[X^2]=1$。指纹与分布互相盖章。

### 实验 2（python）：骰子的指纹，两个票箱分开计票

```python title="骰子特征函数在 t=1 处：实部与虚部各记一笔"
import math

t = 1.0                              # 问指纹在 t=1 处的读数
real_part = 0.0                      # cos 票箱：实部
imag_part = 0.0                      # sin 票箱：虚部
for k in range(1, 7):
    real_part = real_part + math.cos(t * k) / 6   # 每格把 cos 票投进实部
    imag_part = imag_part + math.sin(t * k) / 6   # 每格把 sin 票投进虚部

print(round(real_part, 4))           # 实部读数
print(round(imag_part, 4))           # 虚部读数
print(round((real_part ** 2 + imag_part ** 2) ** 0.5, 4))   # 模长：指纹离圆心多远
```

实部约 $-0.0459$、虚部约 $-0.0172$：指纹缩在原点附近一个模长约 0.049 的小点上——骰子分布铺满六格，六张选票来自圆上六个方向，质心自然贴着圆心。再把代码里的 `t` 改成 `0.0` 跑一遍：每格投出的票都是 $(\cos 0,\sin 0)=(1,0)$，指纹正好站在 $(1,0)$——起跑线 $\varphi(0)=1$ 亲手可触。

### 实验 3（python）：掷标准正态，cos 均值滑向指纹

```python title="蒙特卡洛对账：E[cos(tX)] 应滑向 e^{-t^2/2}"
import math
import random

random.seed(11)                      # 固定种子：人人同一片样本
n = 100000
acc = 0.0
for trial in range(n):
    x = random.gauss(0.0, 1.0)       # gauss(mu, sd)：抽一个均值 mu、标准差 sd 的正态数
    acc = acc + math.cos(x)          # 先验 t=1：给 cos(tX) 记一笔
print(round(acc / n, 4))             # 理论值 e^{-0.5} ≈ 0.6065

acc = 0.0
for trial in range(n):
    x = random.gauss(0.0, 1.0)
    acc = acc + math.cos(2 * x)      # 再验 t=2
print(round(acc / n, 4))             # 理论值 e^{-2} ≈ 0.1353
```

两个读数都该贴着理论指纹（$0.6065$ 与 $0.1353$）。顺带留意：对称分布的 $\sin$ 票箱均值恒为零——指纹整条躺在实轴上，这正是练习 2 的伏笔。

::::warning[常见误区]

**误区一**："你以为特征函数是条普通的实数曲线。" 它是复值的：实部是 cos 票箱、虚部是 sin 票箱。谈"大小"要用模长 $\lvert\varphi(t)\rvert$，单看实部会把指纹剪掉一半。

**误区二**："你以为 $E[e^{itX}]=e^{itE[X]}$。" 期望的线性免检只对**和与常数**有效，不认识复指数这种弯弯曲曲的函数。骰子的指纹在 $t=1$ 处约 $-0.046-0.017i$，而 $e^{3.5i}$ 的坐标完全是另一点——$X$ 在指数里搬不出来。

**误区三**："你以为有了矩母，特征函数只是锦上添花。" 65 课选读那对"同矩不同分布"的反例、几何与指数家族的存在域红线，全部被"无条件存在 + 无条件唯一"两个字治好。矩母是市区地图，特征函数是全国地图。

::::

## 6. 练习

**练习 1**：正态指纹公式的两处应用。初始代码把 $e^{-t^2/2}$ 抄丢了平方项——修到两行检查通过：

```exercise
# @title: 练习：正态指纹读数
# @check: 0.6065
# @check: 0.0111
# @hint: 标准正态的特征函数是 e^(-t²/2)——指数里 t 要先平方、再除以 2；t=3 时是 e^(-4.5)
import math

t1 = 1
phi1 = math.exp(-t1)                # ← 指纹公式 e^(-t²/2)：指数里漏了哪两步？
t2 = 3
phi2 = math.exp(-t2)                # ← 同款病

print(round(phi1, 4))
print(round(phi2, 4))
```

修好后的读数：$t=1$ 处约 0.6065，$t=3$ 处约 0.0111——指纹在三个标准误之外几乎归零，与"正态尾巴按平方指数收窄"的手感一致。

**练习 2**：对称分布的指纹长什么样？取 $X$ 以概率各半取 $-1$ 与 $+1$，亲手算 $\varphi(t)$，再解释为什么它没有虚部。

<details>
<summary>点开查看逐步解答</summary>

按定义加权：$\varphi(t)=\frac12e^{-it}+\frac12e^{it}=\cos t$。两点对称地立在圆上，$\sin$ 票一正一负恰好抵消，指纹整条躺在实轴上——只剩 cos 一条振动线。一般规律：**分布关于零对称 ⟺ 特征函数恒为实值**。反过来，实验 2 里骰子指纹的虚部不为零，正因为六格质心偏出了实轴。

</details>

**练习 3**：用取矩口诀从骰子指纹里读 $E[X^2]$：先说明 $\varphi''(0)=-E[X^2]$，再用 65 课的结论 $E[X^2]=91/6$ 对账。

<details>
<summary>点开查看逐步解答</summary>

逐次求导：$\varphi'(t)=E[iXe^{itX}]$，$\varphi''(t)=E[i^2X^2e^{itX}]$；代入 $t=0$，指数因子 $e^{0}=1$，而 $i^2=-1$，所以 $\varphi''(0)=-E[X^2]$——口诀里那个"除掉 $i$ 的幂次"就是在这里收账。骰子 $\varphi(t)=\frac{1}{6}\sum_k e^{itk}$，二阶导代零得 $\varphi''(0)=-\frac{1}{6}\sum_k k^2=-\frac{91}{6}$，于是 $E[X^2]=91/6\approx 15.1667$，与矩母课逐项求导的结果一字不差。两件武器取的是同一批货，只是付款币种不同。

</details>

## 7. 选读：反演一句话与 CLT 的最后一公里

<details>
<summary>选读 · 指纹能赎回本人，连乘能逼近钟形</summary>

**反演（一句话版）**：特征函数不仅认人，还能赎人——已知 $\varphi$，用一条傅里叶反演积分可以反算出分布（连续情形连密度都能积回来）。它与第 61 章信号处理的傅里叶变换同宗同源：特征函数就是概率分布的**频谱**，"时域卷积 = 频域相乘"翻译过来正是"独立和 = 指纹相乘"。

**CLT 的收官路线**：设 $X_1,\dots,X_n$ 独立同分布、均值 $\mu$、方差 $\sigma^2$。标准化和 $Z_n$ 的指纹按独立连乘展开：

$$\varphi_{Z_n}(t)=\left[\varphi\!\left(\frac{t}{\sigma\sqrt{n}}\right)\right]^n$$

对 $\log\varphi$ 在零点做泰勒展开：一阶项被 $E[X]=\mu$ 的中心化吃掉，二阶项恰好贡献 $-t^2/2\cdot\frac{1}{n}$，$n$ 次方后指数上只剩

$$\varphi_{Z_n}(t)\ \longrightarrow\ e^{-t^2/2}$$

——例题锻造的那枚正态指纹。无条件唯一性出面收案：逐点收敛的指纹只能属于标准正态。这正是 65 课"下一站"预告的连乘路线全程，也是本课"完备武器"名号的由来：没有它，钟形的现代证明缺最后一块砖。

</details>
