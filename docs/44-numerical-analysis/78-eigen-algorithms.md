# 特征值的数值解法：幂法与 QR 迭代

## 1. 从一个场景开始

搜索引擎要给上百亿张网页排座次：谁最重要？它不问内容，只看链接——**被重要页面链接的页面也重要**。把这句话写成算式，就是一张巨大的矩阵反复作用在一张"分数表"上，直到分数不再变化。

那张稳定的分数表，数学名字叫**主特征向量**。同一件事在结构工程里换个说法：桥梁被风一吹会晃，晃得最厉害的那个形状（主模态）与对应的频率，也是一对特征向量与特征值。

麻烦在于矩阵太大。把一亿阶矩阵的特征多项式写出来是痴人说梦，但**让矩阵去乘一个向量**却便宜得惊人——这正是数值方法的入口。

## 2. 直觉解释

上一课已经埋下伏笔：矩阵搬运一个向量时，会沿各条特征方向**各乘各的特征值**。把这句话再往前推一步就是全部秘密。

假设 $A$ 的特征值是 $\lambda_1,\lambda_2$，且 $|\lambda_1|>|\lambda_2|$。把初始向量拆成两条特征方向的叠加（系数记为 $a_1,a_2$），连乘 $k$ 次后

$$A^k v = a_1\lambda_1^k\,x_1 + a_2\lambda_2^k\,x_2 = \lambda_1^k\left(a_1 x_1 + a_2\Big(\tfrac{\lambda_2}{\lambda_1}\Big)^{k}x_2\right)$$

括号里第二项每乘一次就缩水一个因子 $\left|\lambda_2/\lambda_1\right|<1$。**乘得越多，它越接近消失，向量越长越贴住主方向 $x_1$**。所谓幂法，就是耐心地反复乘同一个矩阵。

唯一的技术麻烦是长度：每乘一次，向量长度就乘上 $|\lambda_1|$，几十步后浮点数直接溢出成 `inf`。对策朴素——**每步把向量按自己的最大分量归一化，只留下方向**。

## 3. 正式定义

设 $A$ 有唯一的主特征值（模最大者）$\lambda_1$，对应特征向量 $x_1$。

| 名词 | 记号 | 含义 |
| --- | --- | --- |
| 幂法 | $u=A v_k,\ \mu_k=\max_i|u_i|,\ v_{k+1}=u/\mu_k$ | 反复乘 $A$ 再归一化 |
| 收敛结果 | $\mu_k\to\lambda_1,\ v_k\to x_1$ | 尺度因子吐出特征值，向量吐出方向 |
| 收敛速率 | $\lvert\lambda_2/\lambda_1\rvert$ | 主次特征值差得越开越快 |
| Rayleigh 商 | $R(v)=\dfrac{v^{\mathsf T}Av}{v^{\mathsf T}v}$ | 用当前向量给出的 $\lambda$ 估计，对称阵收敛快一倍幂次 |
| 反幂法 | 对 $(A-\sigma I)^{-1}$ 用幂法 | 拿到最靠近 $\sigma$ 的特征值；$\sigma=0$ 时即最小特征值 |
| QR 迭代 | $A_k=Q_kR_k,\ A_{k+1}=R_kQ_k$ | 每轮做一次 QR 分解，$A_k$ 逐步上三角化 |

QR 迭代的关键事实只有一句：$A_{k+1}=R_kQ_k=Q_k^{\mathsf T}A_kQ_k$，是**正交相似变换**，特征值分毫不动。它不靠"追一个方向"，而是把整块矩阵慢慢磨成上三角——对角线上一格一格浮出特征值。

## 4. 分步例题

**例 1（幂法三步手算）**：取 $A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$，真特征值 3（方向 $(1,1)$）与 1（方向 $(1,-1)$），起跑向量 $v_0=(1,0)$。

1. 第 1 步：$Av_0=(2,1)$，最大分量 $\mu_1=2$，归一化得 $v_1=(1,\,0.5)$；
2. 第 2 步：$Av_1=(2.5,\,2)$，$\mu_2=2.5$，$v_2=(1,\,0.8)$；
3. 第 3 步：$Av_2=(2.8,\,2.6)$，$\mu_3=2.8$，$v_3=(1,\,0.92857)$；
4. 读数：$\mu$ 序列 $2\to2.5\to2.8\to\cdots$ 一路爬向 3，向量一路爬向 $(1,1)$。

**例 2（Rayleigh 商更快）**：拿上一例的 $v_1=(1,0.5)$ 算 $R(v)$。

1. $Av_1=(2.5,2)$；
2. 分子 $v^{\mathsf T}Av=1\times2.5+0.5\times2=3.5$，分母 $v^{\mathsf T}v=1+0.25=1.25$；
3. $R=2.8$——**只用一步就追上了幂法三步的 $\mu$**；
4. 原因：对称矩阵的 Rayleigh 商误差约按 $\left(\lambda_2/\lambda_1\right)^{2k}$ 缩小，是 $\mu$ 的平方速率。

**例 3（反幂法求最小特征值）**：把幂法用在 $A^{-1}$ 上，因为 $A^{-1}$ 的特征值是 $1/\lambda$，最大者 $1/1=1$ 正对应 $A$ 的**最小**特征值。

1. $A$ 的行列式为 3，$A^{-1}=\frac13\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$；
2. 从 $v_0=(1,0)$ 起：$A^{-1}v_0=(\frac23,-\frac13)$，$\mu=0.6667$，$v_1=(1,-0.5)$；
3. 再来一步：$v_2=(1,-0.8)$——方向正滑向 $(1,-1)$；
4. 读数：$\mu\to1$，故 $\lambda_{\min}=1/\mu\to1$，特征向量 $(1,-1)$。验算 $A(1,-1)=(1,-1)$ ✓。

**例 4（QR 迭代一步）**：对同一个 $A$ 做一次循环。

1. 对 $A$ 的列做 Gram–Schmidt，得 $Q=\begin{pmatrix}0.8944&-0.4472\\0.4472&0.8944\end{pmatrix}$，$R=\begin{pmatrix}2.2361&1.7889\\0&1.3416\end{pmatrix}$；
2. 令 $A_1=RQ=\begin{pmatrix}2.8&0.6\\0.6&1.2\end{pmatrix}$；
3. 核对不变量：迹 $=4$、行列式 $=3$，与原矩阵一致——**特征值没动，非对角元开始让位**；
4. 继续迭代，对角线就会分别停在 3 与 1 上。

### 实验 2（python）：幂法每次削减多少误差

```python
A = [[2.0, 1.0], [1.0, 2.0]]      # 对称 2×2 矩阵，真特征值 3 与 1
v = [1.0, 0.0]                    # 初始猜测：随便给一个单位向量

for step in range(1, 6):          # range(1, 6)：轮次 1 到 5
    u = [A[0][0] * v[0] + A[0][1] * v[1],    # 矩阵乘向量 u = A v
         A[1][0] * v[0] + A[1][1] * v[1]]
    mu = max(abs(u[0]), abs(u[1]))           # max/abs：取绝对值最大的那个分量当尺度
    v = [u[0] / mu, u[1] / mu]               # 归一化：只留方向，绕开浮点溢出
    Av = [A[0][0] * v[0] + A[0][1] * v[1],   # 再算一次 A v（这次是为了 Rayleigh 商）
          A[1][0] * v[0] + A[1][1] * v[1]]
    rq = (v[0] * Av[0] + v[1] * Av[1]) / (v[0] * v[0] + v[1] * v[1])
    print(step, round(mu, 4), round(v[1], 4), round(rq, 5))
```

五行输出里，`mu` 依次是 `2.0 / 2.5 / 2.8 / 2.9286 / 2.9756`——正朝 3 爬；`v[1]` 是 `0.5 / 0.8 / 0.9286 / 0.9756 / 0.9918`——正朝 1 爬，说明向量在转成 $(1,1)$；最后一列 Rayleigh 商走得最猛：`2.8 / 2.97561 / 2.99726 / 2.9997 / 2.99997`，**五步就咬住小数点后四位**，因为它的误差每步缩掉约 $\left(1/3\right)^2=1/9$。

### 实验 3（python）：纯 Python 的 QR 迭代

```python
def qr2(A):
    # 对 2×2 矩阵做 Gram–Schmidt：把两列变成互相垂直的单位列，装成 Q
    a1 = [A[0][0], A[1][0]]                  # 第一列
    a2 = [A[0][1], A[1][1]]                  # 第二列
    r11 = (a1[0] ** 2 + a1[1] ** 2) ** 0.5   # ** 0.5 即开平方，得到列长
    q1 = [a1[0] / r11, a1[1] / r11]
    r12 = q1[0] * a2[0] + q1[1] * a2[1]      # 点积 = a2 在 q1 上的投影长度
    w2 = [a2[0] - r12 * q1[0], a2[1] - r12 * q1[1]]   # 减去投影，剩垂直分量
    r22 = (w2[0] ** 2 + w2[1] ** 2) ** 0.5
    q2 = [w2[0] / r22, w2[1] / r22]
    return [[q1[0], q2[0]], [q1[1], q2[1]]], [[r11, r12], [0.0, r22]]   # 返回 Q, R

A = [[2.0, 1.0], [1.0, 2.0]]
for step in range(1, 6):
    Q, R = qr2(A)                            # 第一步：把 A 拆成 Q 乘 R
    A = [[R[0][0] * Q[0][0] + R[0][1] * Q[1][0], R[0][0] * Q[0][1] + R[0][1] * Q[1][1]],
         [R[1][0] * Q[0][0] + R[1][1] * Q[1][0], R[1][0] * Q[0][1] + R[1][1] * Q[1][1]]]
    print(step, round(A[0][0], 4), round(A[1][1], 4), round(A[0][1], 4))
```

每轮打印"先后两个对角元、再是右上角非对角元"。第一行 `1 2.8 1.2 0.6`，第二行 `2 2.9756 1.0244 0.2195`，非对角元迅速塌向 0，两个对角元分别就位到 3 与 1。这就是 QR 迭代的全部戏法：**每轮只做一次正交化与一次相乘，特征值自己爬出来**。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为幂法的收敛速度就是 $\lambda_1$ 的大小。" 其实决定速度的是比值 $|\lambda_2/\lambda_1|$。若主次特征值模长相等（例如 $A=\begin{pmatrix}0&1\\1&0\end{pmatrix}$，特征值 $\pm1$），比值等于 1，向量会永远在两方向之间摇摆，幂法彻底失效。

**误区二**："你以为不归一化也行，反正方向才是我们要的。" 方向确实不受影响，但长度按 $|\lambda_1|^k$ 指数增长。$|\lambda_1|=3$ 时四十步就是 $3^{40}\approx10^{19}$ 的尺度，稍大一点直接变成浮点的 `inf`，后续结果全是 `nan`。

**误区三**："你以为 QR 迭代做一轮就结束。" 一轮只完成一次相似变换，要反复迭代才收敛；而且它收敛的是**上三角形状**，特征值出现在对角线上，不是立刻给出整齐的对角阵。遇到模长相等的复特征值对，还得换成带双位移的 Francis 版本。

:::

## 7. 练习

**练习 1**：下面的幂法忘了归一化，跑出来的向量是"没剪过的原尺寸"。让它输出的向量退回单位尺度：

```exercise
# @title: 练习：给幂法装上归一化
# @check: 1.0
# @check: 0.976
# @check: 1.025
# @hint: 每次算完 Av，先求出它的最大分量（取绝对值比较），再把两个分量都除以它，然后才赋值给 v。
A = [[2.0, 1.0], [1.0, 2.0]]
v = [1.0, 0.0]
for step in range(4):
    Av = [A[0][0] * v[0] + A[0][1] * v[1],
          A[1][0] * v[0] + A[1][1] * v[1]]
    v = Av                      # ← 问题在这：长度没被拉回来
print(round(v[0], 3))
print(round(v[1], 3))
print(round(v[0] / v[1], 4))
```

初始代码四轮后打出 `41.0` 与 `40.0`——同一个方向被放大了 41 倍。修好后应为 `1.0`、`0.976`、`1.025`：分量比值 1.025 其实一直没变（归一化不影响方向），但**绝对数值回到了可读范围**，这才是一台能连跑一万轮的机器。

**练习 2**（概念）：为什么反幂法把 $\sigma$ 取在某个特征值附近时，会飞快地"锁定"那个特征值？

<details>
<summary>点开查看逐步解答</summary>

$(A-\sigma I)^{-1}$ 的特征值是 $\dfrac{1}{\lambda_i-\sigma}$。当 $\sigma$ 贴住某个 $\lambda_j$ 时，$|\lambda_j-\sigma|$ 极小，于是 $\dfrac{1}{|\lambda_j-\sigma|}$ 极大——它成了新矩阵的**主特征值**，幂法立刻朝它收敛。$\sigma$ 贴得越紧，主次比值越大，收敛越快；$\sigma$ 恰好等于特征值时理论上一步到位（实际用位移时通常取上一步的估计，称为 Rayleigh 商迭代）。这也解释了 $\sigma=0$ 的特例：此时最大的是 $1/|\lambda_{\min}|$，幂法交出的就是模最小的特征值。
</details>

## 8. 选读：QR 迭代其实是"同时跑一整套幂法"

<details>
<summary>选读 · 为什么磨三角和追方向是同一件事</summary>

对 $A$ 做一次 QR 迭代，等价于对**全部的坐标轴**同时推进一步幂法，再把它们正交化。这就是子空间迭代的观点：记 $V_k=Q_1Q_2\cdots Q_k$，可以证明 $V_k$ 的列张成的空间正是 Krylov 子空间 $\operatorname{span}\lbrace v,Av,\dots,A^{k}v\rbrace$ 的规范正交基。

于是收敛的判据完全一样，只是从"两个特征值之比"升级为"第 $j$ 个与第 $k$ 个特征值之比"：对角元按 $|\lambda_{i}/\lambda_{j}|^{k}$ 的速度分批就位，通常从模最大的那头开始。这带来两条实用推论：

- **降阶（deflation）**：某个对角元底下的元素全部小到阈值以下时，就可以把这行列"切下来"锁住，对剩下的子块继续迭代，省下大量计算；
- **位移加速**：把 $A-\sigma I$ 再迭代，能让最接近 $\sigma$ 的特征值抢先就位。这与反幂法用位移是同一招，合起来就是工程库里的隐式双位移算法，它至今是密集矩阵特征值求解的主力。

代价也要讲清楚：每轮 QR 分解本身约 $O(n^3)$，比幂法贵得多。工程上从不直接迭代原始稠密矩阵，而是先化成 Hessenberg 形（上三角再挂一条次对角），把每轮成本降到 $O(n^2)$——这一层优化属于数值线性代数的进阶话题。

</details>
