# 数值微分与数值积分

## 1. 从一个场景开始

车载记录仪每隔一段时间存一个位置读数，想知道**此刻的瞬时速度**怎么办？位置函数没有公式——只有一张离散的表。导数在纸上的定义是极限 $\lim_{h\to0}$，可表里相邻两行之间根本没有"无穷小的 h"。

数值分析的回答是：别追极限了，用**有限的小步长**去差分；同时另一头还有个反方向的坑等着——$h$ 不能太小。这一课的任务是把这架天平的两端都看清楚：太大输给弯曲、太小翻车在相消。顺路还要解决它的孪生兄弟：只知道几个采样值时，走过的总路程（积分）怎么估？

## 2. 直觉解释

**微分端**。最朴素的问法是"拿邻近两点连一条割线，让它冒充切线"。割线斜率与真切线的差距来自两点之间曲线的**弯曲**——这是截断误差，$h$ 越小它越小。听起来 $h$ 该一味往小里压？坏消息来了：

两个几乎相等的浮点数相减会发生**灾难性相消**（第 20 课的主角）：$f(x+h)$ 与 $f(x)$ 前 15 位有效数字几乎相同，相减后剩下的全是第 16 位起的浮点尘埃。再除以一个同样微小的 $h$，尘埃被猛烈放大。于是舍入误差随 $h$ 变小而**变大**。

一头增、一头减，总误差就是一条 V 形曲线——谷底才是最优步长，**不是越小越好**。

**积分端**。上一课拉格朗日插值的免费赠品：既然能在若干点上造出穿过它们的多项式，那就把多项式的面积当原函数面积的替身——

- 两点之间连直线 → **梯形法则**；
- 三点之间过一条抛物线 → **辛普森法则**，凭抛物线的对称性白赚两级精度。

## 3. 正式定义

以 $f(x)=\sin x$、$x=1$ 为例（真值 $\cos 1\approx0.5403023$）记两类误差的账：

| 名称 | 公式 | 误差行为 |
| --- | --- | --- |
| 向前差分 | $\dfrac{f(x+h)-f(x)}{h}$ | 截断 $O(h)$ |
| 中心差分 | $\dfrac{f(x+h)-f(x-h)}{2h}$ | 截断 $O(h^2)$，两侧弯曲对消一半 |
| 舍入账 | 相减损失约 $\varepsilon_{mach}\lvert f\rvert / h$ | $O(\varepsilon/h)$，随 $h\to0$ 爆炸 |
| 总误差 | 截断 + 舍入 | V 形；中心差分谷底 $h^\ast\sim\varepsilon_{mach}^{1/3}$ |

$\varepsilon_{mach}^{1/3}$ 的来历一目了然：令 $c_1h^2=c_2\varepsilon/h$ 两边相等解出 $h^3\propto\varepsilon$。按双精度 $\varepsilon\approx10^{-16}$ 算，谷底大约 $10^{-5}$ 到 $10^{-6}$——比机器精度本身粗十个数量级才最准，这就是"极限思想要让位于预算"的字面含义。

复合求积（区间切成 $n$ 段逐段套用）的两员主将：

$$T(h)=\frac{h}{2}\Big(f_0+f_n+2\textstyle\sum_{i=1}^{n-1}f_i\Big)\ (O(h^2)),\qquad S(h)=\frac{h}{3}\big(f_0+f_n+4{\textstyle\sum}_{odd}f+2{\textstyle\sum}_{even}f\big)\ (O(h^4))$$

## 4. 分步例题

**例**：估计 $I=\displaystyle\int_0^1\frac{dx}{1+x^2}$（精确值 $\pi/4\approx0.7853981634$），取 $n=4$、节点 $0,0.25,0.5,0.75,1$。

1. 算出五个函数值：$f=1,\ \frac{16}{17},\ \frac45,\ \frac{25}{41},\ \frac12$；
2. 梯形：$T=\frac{0.25}{2}(f_0+f_4)+0.25(f_1+f_2+f_3)\approx0.782794$ ——三位有效数字；
3. 辛普森：$S=\frac{0.25}{3}\left(f_0+f_4+4(f_1+f_3)+2f_2\right)\approx0.785392$ ——五位半，比梯形多挣约四百倍精度（误差 $6.0\times10^{-6}$ 对 $2.6\times10^{-3}$）；
4. 原因记账：分段线性连接的"折线屋顶"每段都亏一点弓形面积，亏得多；抛物线屋顶贴合曲率，一次曲率补偿抵四级精度；
5. 微分侧预演留给下一节：同一个 $\sin$ 在 $x=1$ 处的中心差分会随着 $h$ 缩小**先勇猛精进、后离奇变坏**——那张 V 形表格马上开演。

## 5. 动手实验

### 实验 1：V 形谷底搜寻

```python title="步长十倍递减：看着误差掉进谷底再爬出来"
import math                       # sin/cos 都是老朋友
import matplotlib.pyplot as plt   # 画图库（第 0 章登记）

true_d = math.cos(1.0)            # 导数真值当裁判
hs = []                           # 收集步长序列：0.1 起每次除以 10
errs = []
h = 0.1
while h >= 1e-16:                 # 一直探到机器精度的隔壁
    fd = (math.sin(1.0 + h) - math.sin(1.0 - h)) / (2 * h)
    hs.append(h)                  # append 把新元素挂到列表末尾
    errs.append(abs(fd - true_d))
    h = h / 10                    # 步长缩小十倍进入下一档

for i in range(len(hs)):          # 打印对齐的三列表
    print(f"{hs[i]:.0e}", f"{errs[i]:.2e}")
best_i = 0                        # 手动扫描找最小值所在下标
for i in range(1, len(errs)):
    if errs[i] < errs[best_i]:
        best_i = i
print("best:", f"{hs[best_i]:.0e}")

plt.loglog(hs, errs, marker="o")  # 双对数坐标：幂律显示为直线段
plt.xlabel("step size h")
plt.ylabel("abs error")
plt.grid(True)
```

f-string 里 `{x:.0e}` 表示科学计数法零位小数输出，如 `1e-05`。表格左段误差每档除以一百（$h^2$ 定律的现场执法），从 $10^{-6}$ 档起反向回升，最低点恰停在 $10^{-5}$ ——与理论谷底 $\varepsilon^{1/3}\approx4.8\times10^{-6}$ 隔壁。右半段的爬升没有任何算法能救：那是表示系统本身的税。

### 实验 2：差分的两种写法正面碰撞

```python title="同一道题：向前差分 vs 中心差分"
import math                       # sin/cos 与 pi 常数的供应处

hh = 0.001
fwd = (math.sin(1.0 + hh) - math.sin(1.0)) / hh            # 割线只用一侧
cen = (math.sin(1.0 + hh) - math.sin(1.0 - hh)) / (2 * hh) # 两侧取平均
print(round(fwd, 4))
print(round(cen, 4))
print(math.cos(1.0))                                       # 真值参照：cos 直接给出精确导数
```

同样的步长下两行输出 `0.5399` 与 `0.5403`：真值是 `0.5403023058681398`——中心差分前四位已经咬住，向前差分还差着四位外的尾巴。一倍的函数求值钱，买到一整级精度，这笔交易无脑划算；但等下一节练习会提醒你：它救不了谷底以下的舍入洪水。

### 实验 3：梯形与辛普森同台报价

```python title="n=4 分片复化求积对照"
import math                       # 需要 pi 当裁判

pts = [0.0, 0.25, 0.5, 0.75, 1.0]
fv = [1.0 / (1.0 + t * t) for t in pts]     # 列表推导式批量算函数值
width = pts[1] - pts[0]                     # 相邻节点间距 0.25
trap = width / 2 * (fv[0] + fv[4] + 2 * sum(fv[1:4]))   # 切片 [1:4] 取中间三值
simp = width / 3 * (fv[0] + fv[4] + 4 * fv[1] + 2 * fv[2] + 4 * fv[3])
pi4 = math.pi / 4                            # pi 常数由 math 提供
print(round(trap, 6), round(simp, 6), round(pi4, 6))
print(abs(simp - pi4) < 1e-4)                # 辛普森进得了万分之一门槛？
print(abs(trap - pi4) < 1e-4)                # 梯形呢？
```

两行布尔输出 `True` 和 `False`——同一批数据同一个门槛，只换屋顶形状就生死立判。辛普森的实际误差约 $6.0\times10^{-6}$，离门槛整整远着一个数量级余量；梯形的 $2.6\times10^{-3}$ 连门框都摸不着。

### 快问快答

```quiz
差分求导时步长该怎么选？
- 越小越接近极限定义，直接取 1e-16 最准
- 在截断误差与舍入误差的 V 形谷底附近取，量级约为机器精度的三分之一方 [*]
- 越大越好，省得两数相减出错
? h 太大输给曲线弯曲（截断），太小撞上灾难性相消（舍入）；总误差呈 V 形，谷底才是黄金步长。
```

:::warning[常见误区]

**误区一**："数值导数要逼近极限，所以 h 无限小。" 极限属于实数的理想世界；浮点世界里 h 小到一定程度后精度不升反降，谷底通常在 $10^{-5}$ 附近而非 $10^{-16}$。

**误区二**："辛普森只是梯形加个系数。" 它的本质是换了屋顶——三点抛物线插值替代两点连线，曲率信息进场才有四级精度的飞跃，系数表 $1,4,2,4,1$ 是这套几何的直接后果。

**误区三**："数据点加密总能改善积分。" 若函数本身有噪声（传感器抖动），插值型求积会把噪声照单全收；此时更聪明的路线是先平滑、或改走随机平均（下一课蒙特卡洛的正戏）。

:::

## 6. 练习

**练习 1**（概念）：为什么中心差分天然比向前差分高一阶？用"两侧弯曲方向相反"造一句直觉解释。

<details>
<summary>点开查看逐步解答</summary>

泰勒展开记账：$f(x+h)-f(x)/h$ 的领先误差项带 $+\frac{h}{2}f''(x)$；换成对称窗口后一侧展开贡献 $+\frac{h}{2}f''$、另一侧贡献 $-\frac{h}{2}f''$，两笔相加正好抵消，剩下 $-\frac{h^2}{6}f'''$ 当领头项——台阶从 $h$ 直接跨到 $h^2$。几何版说法：割线只听得见单边弯；两侧对称取样让左右弯互相作证、各自撒谎的部分对消。
</details>

**练习 2**（判题）：下面代码想用对称窗口求 $\sin$ 在 $1$ 处的导数，却把右端点写成了 $1.0$ 本身——退化成向前差分。修正为真正的中心差分并核对四位小数。

```exercise
# @title: 练习：补上中心差分的另一半窗口
# @check: 0.5403
# @check: True
# @hint: 对称取点 f(x + h) − f(x − h)，分母是 2·h。
import math

h = 0.001
fwd = (math.sin(1.0 + h) - math.sin(1.0)) / h          # 单侧参考版（留作对照）
diff_cen = (math.sin(1.0 + h) - math.sin(1.0)) / (2 * h)   # ← 错了：窗口没开到 x − h

print(round(diff_cen, 4))       # 四位小数见真章
print(abs(diff_cen - fwd) > 1e-5)   # 两种写法真的不同吗？
```

修好后第一行 `0.5403`，第二行 `True`——四位判定与判据双双通过：修正后的值已贴住真值的前四位，且确实不同于退化的单侧写法。

**练习 3**：把实验 3 的分片数翻倍（自己补节点 $0.125,0.375,\ldots$ 并改用 9 点列表），预测梯形误差缩到几分之一、辛普森又缩到几分之一，运行核对后再回头看理论指数是否兑现。

<details>
<summary>点开查看逐步解答</summary>

段数加倍即 $h$ 减半：梯形 $O(h^2)$ 误差应缩到 $\tfrac14$（实测 $\approx6.5\times10^{-4}$），辛普森 $O(h^4)$ 应缩到 $\tfrac1{16}$（实测 $\approx3.7\times10^{-7}$）——两份订单都被如约执行。想继续加分就再多切一档看四倍/十六倍的节奏是否持续：幂律的复利效应正是"加密网格"这门手艺的全部经济学。
</details>

## 7. 选读：理查森外推——把已知误差当零钱找赎

<details>
<summary>选读 · 误差的数学结构是最好的杠杆</summary>

若知道某算法误差干净地按 $ch^p$ 衰减（p 已知、c 不知），就可以跑两个步长 $h$ 与 $h/2$，把两者加权组合使 c 项正负对消：$I_{ext}=(2^pI_{h/2}-I_h)/(2^p-1)$。一步操作白赚一阶精度——这就是理查森外推，辛普森可以看作"梯形做一次外推后的升级款"，龙贝格求积则是外推叠外推的豪华套餐。它与第 22 章 RK 方法共享同一灵魂：**误差不是敌人，是可以算账开票的债务**。浮点世界唯一无法票据化的仍是那笔舍入税——所有外推技巧必须在触到机器地板之前止盈。

</details>
