# 条件数与敏感问题

## 1. 从一个场景开始

工地测量员要确定两根立柱各受多大的力，列出的平衡方程组是

$$x+y=2,\qquad x+(1+\varepsilon)y=2+\varepsilon\qquad(\varepsilon=10^{-10})$$

显然原本设计的答案是 $x=y=1$（把 $\varepsilon$ 当作设计余量补进去后方程完全一致）。可是传感器有一个刻度的读数偏差：第二个方程右端被记成了 $2+1.00000007\times10^{-7}$——改动只有**亿分之一量级**。解出来的立柱受力却变成 $y=1000$、$x=-998$：不但数值翻了三个数量级，方向都反了。

误差没有引人注目的来源：输入只抖了 $10^{-10}$，输出却翻了 $10^{3}$ 倍。这一课要回答的问题很根本——**有些题目天生自带放大镜**。这口锅不该算法背。

## 2. 直觉解释

把上面那两条直线画在同一张图上：

- 第一条 $x+y=2$ 斜率固定为 $-1$；
- 第二条 $x+(1+\varepsilon)y=\text{常数}$ 的斜率是 $-\dfrac{1}{1+\varepsilon}$，和第一条**几乎重合**。

两条近乎平行的直线求交点，就是病态问题的几何面目：交点位置由"两线几乎没差多少"的那个小差异决定，于是任何输入的抖动都被这个差异按比例放大。$\varepsilon$ 越小、直线贴得越近，杠杆越细长，末端甩得越远。

那么放大倍率能算吗？能——它就是**条件数** $\kappa(A)$：系数矩阵"多接近奇异"的一种标尺。

```viz

```

横轴想象成扰动 $\varepsilon$ 的倒数尺度、纵轴是解被推走的位置：曲线在左端疯狂上扬——**微小分母除出巨大结果**，与引子里"亿分之一进、千倍出"是同一张图的两种画法。

## 3. 正式定义

解线性方程组 $Ax=b$ 时，若 $A$ 可逆，定义（以无穷范数为例）

$$\kappa(A)\;=\;\lVert A\rVert\cdot\lVert A^{-1}\rVert\;\ge\;1$$

| 名词 | 含义 |
| --- | --- |
| 范数 $\lVert A\rVert_\infty$ | 每行绝对值之和的最大值，衡量矩阵"最大力气" |
| 条件数 $\kappa(A)$ | 输入相对误差到输出相对误差的最大放大倍率上限 |
| 病态系统 | $\kappa$ 巨大（如超过 $10^{8}$）：双精度下有效数字被吃掉大半 |
| 良态系统 | $\kappa$ 温和（接近 1）：怎么算都不太会错 |

**误差放大定理**：右端项扰动 $\delta b$ 引起的解的相对误差满足

$$\frac{\lVert \delta x\rVert}{\lVert x\rVert}\;\le\;\kappa(A)\cdot\frac{\lVert \delta b\rVert}{\lVert b\rVert}$$

一句话记住：**解的误差不超过"输入相对误差 × 条件数"**。它是题目本身的属性，换算法、换语言、换计算机都改变不了 $\kappa(A)$——所以发现结果离谱时，第一件事是查题不是查代码。

## 4. 分步例题

**例**：算出 $\varepsilon$ 病态矩阵的条件数并验证放大预言。

对 $A=\begin{pmatrix} 1 & 1 \\ 1 & 1+\varepsilon \end{pmatrix}$：

1. 行范数：第一行 $1+1=2$，第二行 $2+\varepsilon$，故 $\lVert A\rVert_\infty=2+\varepsilon$；
2. 求逆：$\det A=\varepsilon$，$A^{-1}=\dfrac{1}{\varepsilon}\begin{pmatrix} 1+\varepsilon & -1 \\ -1 & 1 \end{pmatrix}$；
3. 逆的行范数：两行分别是 $(2+\varepsilon)/\varepsilon$ 与 $2/\varepsilon$，取大者 $\lVert A^{-1}\rVert_\infty=(2+\varepsilon)/\varepsilon$；
4. 相乘得条件数 $\kappa=\dfrac{(2+\varepsilon)^2}{\varepsilon}\approx\dfrac{4}{\varepsilon}$：$\varepsilon=10^{-10}$ 时 $\kappa\approx4\times10^{10}$；
5. 验证预言：右端第二分量偏移 $\delta=2^{-6}=0.015625$，相对输入误差约 $\delta/\lVert b\rVert\approx0.4\%$；而解的第二分量从 $0$ 直接跳到 $\delta/\varepsilon=64$——实际放大远超 $\kappa$ 给出的保守下界，方向一致：**κ 是上保险的尺子，出事只会更狠**。

顺带留意第 2 步：逆矩阵的分母是 $\det A=\varepsilon$——行列式趋于零（奇异）的过程中条件数必然爆炸，这两个概念是同一枚硬币的两面。

## 5. 动手实验

### 实验 1：亲手摇动病态杠杆

下面的表格让 $\varepsilon$ 每次缩小 16 个二进制位幂（噪声门限以下也精确），右端扰动固定为 $2^{-2}$，观察解跑多远。取二的负幂做扰动是有意的：它们在浮点里**精确表示**，你看到的疯狂输出不含任何舍入尘埃——全是题目本身放大的。

```python title="epsilon 逐级缩小：解沿着杠杆飞出去"
for k in [-4, -8, -12, -16]:          # ε = 2^k 逐级变小
    eps = 2 ** k                      # 二的负幂：二进制世界的整数
    delta = 2 ** -2                   # 右端固定偏移 0.25
    y_out = delta / eps               # 解 = 扰动 ÷ ε：纯粹的杠杆公式
    x_out = 2 - delta / eps
    print("eps=2^", k, " 时解 =", x_out, y_out)
```

四行输出的 $y$ 依次是 $4, 64, 1024, 16384$：每缩小 $2^{4}$ 倍，输出就放大同倍数——杠杆严格按 $\frac{1}{\varepsilon}$ 定律工作。最后一步输入端的相对变化不足万分之一，输出却已经从"合理值"飞出了十六个数量级之外。

### 实验 2：良态对照——同样的扰动，稳如泰山

换成对角矩阵 $\begin{pmatrix} 2 & 0 \\ 0 & 2 \end{pmatrix}$（$\kappa=1$ 的模范生），同样大小的右端扰动会怎样？

```python title="kappa=1 的系统：扰动原样进出，不放大"
A_scale = 2.0        # 对角元：好系统的"劲度"
delta = 2 ** -6      # 与引子同款的小扰动
dy = delta / A_scale      # 解的变化 = 输入变化 ÷ 对角元
print(dy)                 # 只挪动了扰动的一半，风平浪静
print(delta / 2 < 0.01)   # 输入相对变化很小 → 输出也小
```

同样的输入抖动，良态系统里只是轻轻一晃。对照结论：**出问题先看条件数**——它区分了"代码写坏了"和"题目本来就脆"这两种完全不同的麻烦。

### 快问快答

```quiz
一个方程组的条件数高达十的五次方量级，最稳妥的判断是什么？
- 一定是程序里写了 bug
- 题目本身高度敏感：约 5 位有效数字可能在求解中丢失，应重新建模或提高精度 [*]
- 换一种编程语言就能消除敏感
? 条件数是系数矩阵自身的属性，刻画输入到输出的最大误差放大倍率；它与算法、语言、硬件无关。
```

:::warning[常见误区]

**误区一**："结果不对一定是算法不稳。" 先问题目稳不稳：条件数 $\kappa=10^{10}$ 时，再稳定的算法也只能保住大约 $16-10=6$ 位有效数字。锅要先分给题目。

**误区二**："条件数可以用 $\det A$ 大小判断。" 行列式有量纲、会随缩放整体乘个数；把它每行每列都除以自身长度后行列式才与病态挂钩。直接拿原始行列式的"小"说事会被单位选择骗到。

**误区三**："残差小就说明解准。" 病态系统里可以同时满足"残差几乎为零"与"解离真解十万八千里"——残差管的是 $Ax-b$，条件数管的才是 $x$ 本身。

:::

## 6. 练习

**练习 1**（概念）：把引子里系统的两个方程相减，直接导出 $y=\delta/\varepsilon$，解释为什么两线交点的高度恰好由这个商决定。

<details>
<summary>点开查看逐步解答</summary>

第二条减第一条：$(x+(1+\varepsilon)y)-(x+y)=(2+\delta)-2$，左边化简只剩 $\varepsilon y$，右边剩 $\delta$，于是 $y=\delta/\varepsilon$。这就是杠杆本体：**两线之间唯一的差别 $\delta$ 被"两线的间距" $\varepsilon$ 一除**，间距越小交点被顶得越高。几何（近平行）与代数（小分母）在这里是同一句话。
</details>

**练习 2**（判题）：初始代码想复现"微扰放大"，但把杠杆公式里的除号写成了乘号，输出温吞得像良态系统。请修正成真正的病态杠杆：判定值取二的负幂，全程无舍入干扰。

```exercise
# @title: 练习：修好病态杠杆的朝向
# @check: -14.0
# @check: 16.0
# @check: True
# @hint: 解 = 扰动 ÷ ε。ε 用 2 的负幂（2 ** -10），δ 用 2 ** -6，商是干净的 16。
eps = 2 ** -10        # ε 取二的负十次幂：浮点里精确表示
delta = 2 ** -6       # 右端项的小偏移，也是精确表示

y_out = delta * eps   # ← 错了：杠杆该把扰动除以 ε，不是乘
x_out = 2 - delta * eps

print(x_out)
print(y_out)
print(delta / 2 < 0.01)   # 输入端的相对变化确实不到百分之一
```

修好后三行输出 $-14.0$、$16.0$、`True`：输入不到 $1\%$ 的挪动把解踢到了 $y=16$、$x=-14$。所有数字都是二的幂的和差商，谁也没沾舍入的光——这才是"题目自带的放大"纯天然的模样。

**练习 3**：把练习 2 里 eps 改成 `2 ** -14`，先笔算预测 x_out 与 y_out，再运行核对（提示：仍是干净的二进制数）。

<details>
<summary>点开查看逐步解答</summary>

$\delta/\varepsilon=2^{-6}/2^{-14}=2^{8}=256$，故 $y_{out}=256.0$、$x_{out}=2-256=-254.0$。规律一目了然：指数相减。这类"二的幂账本"是把敏感性实验做干净的利器——输出爆炸完全来自题目，而非浮点噪声或代码手误。
</details>

## 7. 选读：条件数的其他面孔

<details>
<summary>选读 · 谱视角与“最坏方向”</summary>

$\kappa(A)=\sigma_1/\sigma_n$（最大与最小奇异值之比，第 21 章 SVD 的直接应用）还揭示了放大的**方向性**：沿最小奇异向量方向的输入扰动按 $\sigma_1/\sigma_n$ 放大，沿最大奇异向量方向则几乎无事——病态不是全方位的坏，而是某个特定方向上的坏。这也解释了为何同样的系统，有的数据让人翻车、有的安然无恙。减病的实用手段有二：改善方程本身的几何（无量纲化、变量替换），或干脆改问一个良态的问题（正则化，第 41 章过拟合治理的同族思想）。

</details>
