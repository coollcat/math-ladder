# 校准与过度自信：置信度要诚实

## 1. 从一个场景开始

医生助手说："这个肿瘤 92% 是恶性的。"这句话是可以被审计的——把所有被判"92% 恶性"的病例攒起来，恶性比例真的接近 92% 吗？如果只有七成是恶性，这个模型就是在**报虚价**：准确率可能不差，但它给出的置信度不能当真。

天气预报的降水概率、自动驾驶的障碍物置信度、风控的违约概率，全都面对同一个问题。**校准**研究的不是"答对多少"，而是"说出来的概率配不配得上实际频率"。

## 2. 直觉解释

把模型的置信度当成一种承诺：

> "凡是我说 70% 把握的题，我应该大约对 70%。"

- 兑现承诺 → **校准良好**；
- 总是说 90% 却只对七成 → **过度自信**（最危险：下游会盲目信任）；
- 说 50% 却几乎全对 → **信心不足**（浪费了模型的知识，决策者不敢用它）。

注意校准和准确率是两码事：一个全猜"是"的模型在正例占 80% 的数据集上有 80% 准确率，但它的"置信度 80%"毫无含金量。准确率看单点成绩，校准看**概率语言是否诚实**。

## 3. 正式定义

理想校准的定义：对所有被模型判为置信度 $p$ 的样本集合，

$$\Pr\bigl(Y = 1 \mid \hat{p} = p\bigr) = p$$

即"预测 $p$"与"经验频率 $p$"重合。实践中把 $\hat{p}$ 划分成 $B$ 个箱（bin），逐箱比较：

$$\mathrm{ECE} = \sum_{b=1}^{B} \frac{n_b}{N}\,\bigl|\,\mathrm{acc}(b) - \mathrm{conf}(b)\,\bigr|$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $n_b$ | 第 $b$ 箱样本数 | 落进该置信区间的题目数 |
| $N$ | 总样本数 | $\sum_b n_b$ |
| $\mathrm{acc}(b)$ | 箱内准确率 | 该箱答对比例 |
| $\mathrm{conf}(b)$ | 箱内平均置信度 | 模型在该箱的平均自报概率 |

ECE = 0 是完美校准；画成图（横轴置信度、纵轴准确率），完美校准就是对角线，这条图叫**可靠性图**。

## 4. 分步例题

某模型在 300 道验证题上的表现分三箱：

| 箱 | 自报置信度 | 题数 $n_b$ | 实际答对率 |
| --- | --- | --- | --- |
| 低 | 50% | 100 | 49% |
| 中 | 70% | 100 | 58% |
| 高 | 90% | 100 | 71% |

1. 各箱差距：$|0.50-0.49| = 0.01$；$|0.70-0.58| = 0.12$；$|0.90-0.71| = 0.19$；
2. 三箱样本数相同，权重都是 $100/300 = 1/3$；
3. $\mathrm{ECE} = (0.01 + 0.12 + 0.19)/3 = 0.32/3 \approx 0.107$；
4. 读法：平均而言，自报概率比现实乐观约 10.7 个百分点——典型的过度自信画像，且越自信偏差越大。

### 实验 2：手算两个模型的 ECE

```python title="对比校准良好与过度自信两个模型"
bins_conf = [0.5, 0.7, 0.9]        # 两模型共用的自报置信度
acc_good = [0.52, 0.69, 0.91]      # 模型 A：说到基本做到
acc_over = [0.49, 0.58, 0.71]      # 模型 B：嘴上说 90 只对七成
n_per_bin = 100                    # 每箱 100 题，权重相等

def ece(accs):
    total_gap = 0.0
    for i in range(len(accs)):
        gap = abs(accs[i] - bins_conf[i])   # abs：绝对值，只看偏离幅度
        total_gap = total_gap + gap * n_per_bin
    return total_gap / (n_per_bin * len(accs))

print(f"模型A（校准好）ECE = {round(ece(acc_good), 3)}")
print(f"模型B（过度自信）ECE = {round(ece(acc_over), 3)}")

# 可靠性草图：虚线是完美校准对角线
import matplotlib.pyplot as plt
plt.plot([0.4, 1.0], [0.4, 1.0], linestyle="--", color="gray", label="perfect")
plt.plot(bins_conf, acc_good, marker="o", label="model A")
plt.plot(bins_conf, acc_over, marker="s", label="model B")
plt.xlabel("claimed confidence")
plt.ylabel("actual accuracy")
plt.legend()
```

模型 A 的三点贴着对角线走，模型 B 整体趴在对角线下方——离线越远，虚价越大。真实项目里还会按置信区间切成十几个细箱再统计，原理不变。

## 常见误区

:::warning[常见误区]

**误区一**："准确率高就不用管校准。"
准确率回答"平均对多少"，校准回答"概率话术可不可信"。医疗、金融场景里后者往往更要命：一个 85% 准确但满嘴 99% 的模型，比 80% 准确却诚实标价的模型危险得多。

**误区二**："校准好的模型，每个预测都可信。"
校准是**群体性质**：它保证"所有自报 90% 的样本合起来约九成对"，不保证你手上这一条恰好属于那九成。个体决策还需要额外证据。

**误区三**："校准一次，终身有效。"
校准是在特定数据分布上测的。换医院、换客群、换季节，分布一漂移，老校准曲线立刻过期——可信 AI 必须定期复检（这正是本章"监控与审计"模块存在的理由）。

:::

## 6. 练习

**练习 1**：可靠性图上，一个模型的点全部落在对角线**上方**意味着什么？

<details>
<summary>点开查看逐步解答</summary>

实际准确率高于自报置信度——**信心不足**（underconfident）。比如自报 60% 的箱子实际对了 85%。它不会骗人，但会让下游低估模型能力、错失可用信息。温度缩放调低也能修这种毛病。
</details>

**练习 2**：把实验 2 的模型 B 换成"信心不足"版本 `acc_shy = [0.61, 0.83, 0.97]`，算 ECE 并判断方向。

<details>
<summary>点开查看逐步解答</summary>

各箱差距 0.11、0.13、0.07，ECE = 0.31/3 ≈ 0.103，量级与过度自信相当，但点全在对角线上方。ECE 本身不分方向，所以工程报告里总配上可靠性图一起看。
</details>

**练习 3**：概念辨析：为什么"训练时最大化准确率"天然容易造出过度自信的模型？

<details>
<summary>点开查看逐步解答</summary>

训练目标只奖励"分对"，从不惩罚"说话太满"：把置信度推到 99% 和停在 85%，只要类别没分错，损失函数一视同仁。于是优化器顺手把边际推到极致，置信度便脱离了频率语义。修复思路是显式加入校准目标或事后做温度缩放——总之，诚实是要单独付费的。
</details>

## 7. 选读：温度缩放一行公式

<details>
<summary>选读 · 给 logits 除个温度</summary>

深度网络输出类别前有一串打分（logits）$z$。事后校准最常用的招数是把 softmax 的温度从 1 调成 $T$：

$$\Pr(y=i) = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

$T>1$ 把概率压得更平（治过度自信），$T<1$ 拉得更尖（治信心不足）。只用一个验证集上的标量参数，就能显著压低 ECE——便宜到几乎所有上线模型都会顺手做一遍。（Guo et al., 2017 年提出后已成为工业标配。）

</details>
