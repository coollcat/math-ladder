## 实战挑战 · 分诊置信度、门禁攻击与信贷账本

两个真实事件给本章做了注脚。2016 年，CMU 研究团队在 ACM CCS 安全顶会发表论文《Accessorize to a Crime》（Sharif 等，2016）：用普通打印机打出彩色眼镜框，戴在脸上就能让人脸识别系统"指鹿为马"。2018 年 10 月，Reuters 调查报道披露亚马逊内部招聘 AI 因训练数据以男性简历为主，系统性地压低含"women's"字样简历的评分，项目最终废弃。

下面的章节大题把同一类失败模式放回三个关键系统：医院分诊要先看置信度是否诚实，人脸门禁要算攻击预算，银行信贷要审不同群体的待遇。数据是简化的教学账本，不是真实病人或客户记录。

现在请你同时当**模型审计员**、**安全顾问**和**公平审计员**。第一问检查医疗分诊模型：低置信箱有 100 人，置信度与实际恶性率差 0.08；高置信箱有 300 人，差距只有 0.04。第二问里，线性门禁模型中两张脸的得分差为 0.6，权重向量 $w = (3, 4)$，要算"骗过它最少要挪多远"。第三问审一份信贷账本：甲组 200 份申请（合格 120、不合格 80），算法通过其中合格的 96 份、不合格的 16 份；乙组 200 份（合格 60、不合格 140），通过合格 48 份、不合格 28 份。前两问已示范：

```exercise
# @title: 实战挑战：分诊、门禁与信贷的三本账
# @check: 0.05
# @check: 0.12
# @check: 0.56
# @check: 0.38
# @check: 0.8
# @check: 0.18
# @hint: ECE 要按箱内人数加权；通过率 = （通过的合格 + 通过的不合格）÷ 组内总数；TPR 分母是真实合格人数。
gaps = [0.08, 0.04]   # 分诊模型两个置信箱的 |实际恶性率 - 自报置信度|
counts = [100, 300]   # 低置信箱和高置信箱分别的人数

total_n = counts[0] + counts[1]
ece_val = (gaps[0] + gaps[1]) / 2    # ← 问题在这：忘了按箱内人数加权
print(round(ece_val, 2))             # (a) 医疗分诊模型的 ECE

w_norm = 5.0        # 权重向量 (3,4) 的长度：sqrt(9+16)
score_gap = 0.6     # 两张脸的得分差

print(round(score_gap / w_norm, 2))    # (b) 最小扰动（已示范）

# (c) 信贷账本：甲组
pass_a = (96 + 16) / 200               # 甲组通过率：分子是全部被通过的人
print()                                # ← 补上甲组通过率

# 乙组
pass_b = (48 + 28) / 200
print()                                # ← 补上乙组通过率

# 乙组的 TPR：通过的合格者 48 人 ÷ 乙组真实合格 60 人
print()                                # ← 补上乙组 TPR

print()                                # ← 补上两组通过率之差（甲 − 乙）
```

医疗那一问的关键和第 10 课相同：低置信箱人少但偏差大，高置信箱人多但偏差小，不能把两箱差距直接平均。信贷那一问则和第 30 课呼应：两组的判别力可以完全一样，选择率却因基率不同而拉开。

```quiz
这本账里，哪条公平口径意外地达标了？
- 通过率完全相等
- TPR 与 FPR 两组都一样（机会均等） [*]
- 三条口径全部达标
? 甲组 TPR=96/120=0.8、FPR=16/80=0.2；乙组 TPR=48/60=0.8、FPR=28/140=0.2。判别力一模一样，但两组合格率基数不同，通过率自然拉开——这正是第 30 课不可能性定理的现实长相。
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** $\mathrm{ECE} = (0.08 \times 100 + 0.04 \times 300)/400 = 20/400 = 0.05$。直接平均会得 0.06，高估了整体失准程度。

**(b)** 权重长度 $\sqrt{3^2+4^2}=5$；最小扰动 $0.6/5 = 0.12$。在百万维人脸空间里这相当于每维挪动微乎其微的一点点——对抗眼镜的打印图案就是这样一个精心挑过的"0.12 步"。

**(c)**
1. 甲组通过率 $(96+16)/200 = 112/200 = 0.56$；
2. 乙组通过率 $(48+28)/200 = 76/200 = 0.38$；
3. 乙组 $\mathrm{TPR} = 48/60 = 0.8$（顺带验证甲组 $96/120=0.8$、两组 FPR 分别为 $16/80$ 与 $28/140$ 都是 0.2）；
4. 通过率差 $0.56 - 0.38 = 0.18$。

后三行与第 30 课的分步例题逐位呼应：**判别力相等 ≠ 待遇相等**。基率差异会自动转化为结果差异，任何单一指标都无法同时安慰所有人。
</details>

## 实战挑战 · 校准误差要取绝对值

校准误差衡量"模型有多自信"与"实际有多准"的差距，要用**绝对值**。模型自信 60%、实际准确 80% 时，校准误差是 0.2。下面这题漏了绝对值，修到输出 `0.2`：

```exercise
# @title: 实战挑战：校准误差要取绝对值
# @check: 0.2
# @hint: 差距不分正负，用 abs(置信度 - 准确率)。
confidence = 0.6     # 模型平均自信度
accuracy = 0.8       # 实际准确率
gap = confidence - accuracy    # ← 问题在这：该取绝对值
print(round(gap, 2))
```

<details>
<summary>点开查看逐步解答</summary>

校准误差是差距的**大小**，不分方向：

```python
gap = abs(confidence - accuracy)   # |0.6 - 0.8|
print(round(gap, 2))               # 0.2
```

改完：$|0.6 - 0.8| = 0.2$。初始代码得 $-0.2$——误差为负说不通。这个模型"自信 60% 却对了 80%"是**欠自信**，与"自信 90% 只对 70%"的过度自信都是校准失衡。可靠性图与 ECE 度量，本质上就是把这条"差距的绝对值"在所有置信区间上平均。

</details>
