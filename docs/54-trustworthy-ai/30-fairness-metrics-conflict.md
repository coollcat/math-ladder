# 公平性指标的冲突

## 1. 从一个场景开始

一家公司想用算法初筛简历。审计员提出三个朴素要求：

1. **通过率要一样**——各组获邀面试的比例不应悬殊；
2. **该过的都要过**——真正合格的候选人，无论来自哪个组，被错杀的概率要一样；
3. **分数要诚实**——同一个"87 分"，在不同组里含义应该相同。

听起来人畜无害？数学家在 2016 年证明：只要两组的**真实合格率不同**、分类器又不完美，这三条就**不可能同时成立**（Kleinberg–Mullainathan–Raghavan；同年 Chouldechova 独立得到等价结果）。公平不是一道选择题，是一道**多选题且答案互斥**——你必须先决定牺牲谁。

## 2. 直觉解释

把筛选想象成一张漏网：

- **群体公平（demographic parity）**只看漏网口大小：各组捞上来的比例要相等；
- **机会均等（equalized odds）**看网的准头：真合格者被漏掉的比例（漏报率）、不合格者被误捞的比例（误报率）都要组间一致；
- **校准公平**看刻度：模型说"70% 合格"的人里，各组实际合格率都应是七成。

矛盾从哪来？设甲组合格率 60%、乙组 30%。若两网的准头完全一样（机会均等），那么合格者多的组自然捞得多——**通过率必然不等**，群体公平破产。反过来硬凑通过率相等，就必须对某组收紧或放松网眼，准头立刻失衡。基数不同 + 判决有误差 = 天生打架。

## 3. 正式定义

二分类混淆矩阵的四格：TP（真阳性）、FP（假阳性）、FN（假阴性）、TN（真阴性）。三条常用指标：

$$\mathrm{TPR} = \frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}}, \qquad \mathrm{FPR} = \frac{\mathrm{FP}}{\mathrm{FP}+\mathrm{TN}}, \qquad \text{选择率} = \frac{\mathrm{TP}+\mathrm{FP}}{N}$$

| 指标口径 | 要求 |
| --- | --- |
| 群体公平 | 各组选择率相等 |
| 机会均等 | 各组 TPR 与 FPR 都相等 |
| 校准公平 | 同一预测分数在各组的经验命中率相同 |

**不可能性定理（非形式陈述）**：当两组基率 $\Pr(Y=1)$ 不同且分类器非完美时，校准公平与 TPR 相等同时成立的代价是 FPR 不等；三者在一般情况下无交集。

## 4. 分步例题

两组各 100 人。甲组合格 60 人、乙组合格 30 人。某模型对两组使用完全相同的判别力（机会均等）：$\mathrm{TPR}=0.8$、$\mathrm{FPR}=0.2$。

1. 甲组通过数：合格者 $60\times0.8=48$，不合格者 $40\times0.2=8$，共 $56$ → 选择率 56%；
2. 乙组通过数：合格者 $30\times0.8=24$，不合格者 $70\times0.2=14$，共 $38$ → 选择率 38%；
3. 机会均等 ✓（两组 TPR/FPR 完全一致），但通过率差了 18 个百分点——审计报告会亮红灯；
4. 想让乙组也通过 56%？必须放宽网眼：比如 TPR 升到 1.0、FPR 升到 0.371（$30+26=56$），于是乙组误伤大增；
5. 结论：这份"公平套餐"只能点一样，菜单背后是价值判断，不是技术瑕疵。

### 实验 2：手搓混淆矩阵计算器

```python title="两组四格表 → 三种公平指标"
# 甲组：(TP, FN, FP, TN)
group_a = [48, 12, 8, 32]
# 乙组：与甲组同 TPR/FPR 的四格表
group_b = [24, 6, 14, 56]

def metrics(g):
    tp, fn, fp, tn = g          # 序列解包：一行拆出四个数
    tpr = tp / (tp + fn)        # 真阳性率：合格者被放行的比例
    fpr = fp / (fp + tn)        # 假阳性率：不合格者被误放行的比例
    sel = (tp + fp) / (tp + fn + fp + tn)   # 选择率：总体通过比例
    return round(tpr, 2), round(fpr, 2), round(sel, 2)

for name, g in [("甲组", group_a), ("乙组", group_b)]:
    print(name, "TPR/FPR/选择率 =", metrics(g))

print("机会均等达标:", metrics(group_a)[:2] == metrics(group_b)[:2])   # 切片取前两个
print("群体公平达标:", metrics(group_a)[2] == metrics(group_b)[2])
```

输出会显示一个刺眼的组合：`True` 与 `False` 并列——准头一模一样，待遇肉眼可见地不平等。这就是不可能性定理在数据里的长相。

### 实验 3：判题小练兵

```exercise
# @title: 练习：算乙组的 TPR 与选择率差距
# @check: 0.8
# @check: 0.18
# @hint: TPR 的分母是该组真实合格的人数 TP+FN；选择率差距用两组 (TP+FP)/N 相减。
a = [48, 12, 8, 32]    # 甲组 TP,FN,FP,TN
b = [24, 6, 14, 56]    # 乙组同款判别力

tpr_b = b[0] / (b[0] + b[1])       # 乙组 TPR：注意分母是合格者总数
sel_a = (a[0] + a[2]) / 100
sel_b = (b[0] + b[2]) / (b[0] + b[1] + b[2])
print(round(tpr_b, 2))
print(round(sel_a - sel_b, 2))
```

第二行的问题在于分母少算了 TN：选择率的分母应是全组人数。补上 `+ b[3]` 后，你会看到 0.56 对 0.38、差 0.18——与分步例题逐位吻合。

```quiz
两组的 TPR 和 FPR 都相等，但真实合格率不同，它们的选择率通常会怎样？
- 必然完全相等
- 通常不同，基率会把相同的判别力放大成不同的通过率 [*]
- 无法计算，必须先删除群体属性
? 选择率约等于 基率×TPR + (1-基率)×FPR。TPR/FPR 相同而基率不同时，这个加权结果一般不相等。
```

## 常见误区

:::warning[常见误区]

**误区一**："把敏感属性删掉就公平了。"
邮编、消费记录、休闲爱好都和群体身份强相关，是现成的代理变量。删字段只是把歧视藏进特征组合里，审计照样能从输出分布中读出来。

**误区二**："存在一个最公平的指标，选它就行。"
三个口径回答三种伦理直觉（结果均等 / 机会平等 / 诚实标价），互相冲突是定理而非工程缺陷。负责任的做法是把口径选择摆上台面，写进制度并接受外部审计。

**误区三**："数学上满足了指标，就万事大吉。"
指标是必要的体检项，不是充分的正义证明。历史偏见可能藏在"合格标签"本身（标签由过去的歧视性决策生成）——这时连完美的机会均等都只是在复刻昨天的不公。因果视角（第 42 章）是更深的追问起点。

:::

## 6. 练习

**练习 1**：把实验 2 中乙组换成"放宽网眼凑齐 56% 通过率"的版本 `[30, 0, 26, 44]`，重算三项指标，指出哪一项被牺牲了。

<details>
<summary>点开查看逐步解答</summary>

TPR = 30/30 = 1.0，FPR = 26/70 ≈ 0.371，选择率 56%。对比甲组的 FPR=0.2：**机会均等被牺牲**——为了表面上的通过率平等，乙组的不合格者被误放行得更多，最终受害的可能正是这些被推上不适岗位的候选人。
</details>

**练习 2**：若甲乙两组真实合格率相同（都是 45%），三个口径还冲突吗？

<details>
<summary>点开查看逐步解答</summary>

不冲突了。基率相同时，同一个判别器自动给出相同的 TPR/FPR 和相同的选择率——三条全部满足。不可能性定理的触发条件恰恰是"基率不同"。这也解释了为什么公平问题在现实中最棘手：历史造成的机会差异正是基率差异本身。
</details>

**练习 3**：概念辨析：校准公平与机会均等为何不能兼得？

<details>
<summary>点开查看逐步解答</summary>

设两组共享同一张分数表且校准。若再要求 TPR 相等而基率不等，可以推出两组的 FPR 必然拉开（否则分数分布无法同时满足两种约束）。直观版：诚实标价意味着高分人群的真实命中率一致；但两组合格者密度不同，要在同样的命中率下捞出同样比例的合格者，只能给两组配不同的"误伤率"。证明见 Kleinberg 等（2016）命题 3.1，本课只负责让你看见它的形状。
</details>

## 7. 选读：不可能性定理的证明骨架

<details>
<summary>选读 · 三行推出矛盾</summary>

记两组基率为 $p_1 \ne p_2$。校准给出：对任意分数值 $s$，$\Pr(Y{=}1\mid s)$ 组间相同。TPR 相等加上贝叶斯公式，会把每个 $s$ 处的似然比锁成常数；再把选择率分解为 $p\,\mathrm{TPR} + (1-p)\,\mathrm{FPR}$，代入常数似然比后可解出 $\mathrm{FPR}_1 = \mathrm{FPR}_2$ 当且仅当 $p_1 = p_2$ 或分类器完美（AUC=1）。于是基率不同 + 非完美 ⇒ 三条必有一条破。完整证明约半页纸，工具只有条件概率——第 36 章的你已经备好了全部装备。
</details>
