# 分布内、分布外与分布偏移

## 1. 从一个场景开始

某银行的风控模型在验证集上表现出色，上线三个月后坏账识别率却一路下滑。排查了一圈——代码没改、参数没动、预测规则一字未差。变的是**世界**：某类新客群大量涌入，而模型从没见过长成这样的人。

模拟考满分从来不能担保考试换了一张卷子。第 41 章讲过"训练误差与泛化鸿沟"，但那里默认一件更基础的事：**训练数据和将来遇到的数据来自同一个分布**。这一课讲的就是这个假设什么时候破、破了以后会发生什么。

## 2. 直觉解释

把模型的训练集想成一册**练习册**，线上真实流量是**高考卷**。

- 高考题和练习册长得差不多 → 模型正常发挥，我们说样本落在**分布内**（in-distribution）；
- 高考突然考了一道练习册里从未出现过的题型 → 样本落在了**分布外**（out-of-distribution，简称 OOD），模型可能仍然自信满满地胡答；
- 整门考试大纲改了（以前考技巧、现在考背诵）→ 这就是**分布偏移**（distribution shift）。

最危险的是第三种里的顽固分子：输入还是老样子，但**答案的规律本身翻了面**。垃圾邮件过滤器里"中奖"两个字十年前意味着诈骗，今天可能只是一场普通的电商促销——词没变，含义变了。

分界线没动，动的是世界；可代价由分界线承担。

## 3. 正式定义

数据满足同分布假设时，训练批与线上批各自的特征—标签对抽自同一个联合分布；分布偏移就是这个等式破裂的方式。按“哪里裂了缝”分三类：

| 偏移类型 | 变了什么 | 没变什么 | 生活剧本 |
| --- | --- | --- | --- |
| 协变量偏移 covariate shift | 输入分布 $P(X)$ | 规律 $P(Y \mid X)$ | 考生换了一批人，但"什么样的分数及格"没变 |
| 标签偏移 label shift | 标签比例 $P(Y)$ | 似然 $P(X \mid Y)$ | 垃圾邮件总量从一成涨到五成，骗术本身照旧 |
| 概念漂移 concept drift | 规律 $P(Y \mid X)$ 本身 | ——（可能输入都没怎么变）| 央行加息后，同样的负债收入比，违约概率整体上抬 |

一张图记三种画风：**横着挪**（协变量）、**竖着挪**（标签）、**整张桌子掀了**（概念）。判 OOD 则是一事：某条查询看起来就不像训练集里的东西，应该拒答或降级处理，而不是硬给一个高置信度的瞎猜。

三者可以叠加发生，且互相掩护：先来的协变量偏移会掩盖紧跟其后的概念漂移——等你发现规律也变了时，已经晚了一个季度。

## 4. 分步例题

一台极简评分器只有一条规则：分数 $x \ge 65$ 判"合格"。看两批十人小样：

| 批次 | 十人的分数 | 均值 | ≥ 65 的人数 | 通过率 |
| --- | --- | --- | --- | --- |
| 训练期 | 55, 58, 60, 62, 64, 66, 68, 72, 76, 85 | 66.6 | 5 | 0.5 |
| 三个月后 | 40, 44, 46, 48, 50, 52, 54, 56, 60, 70 | 52.0 | 1 | 0.1 |

1. 第一步确认分界线：阈值仍是 65，模型一行代码都没改；
2. 第二步数人头：训练批有 66, 68, 72, 76, 85 共 5 人过线，通过率 0.5；
3. 第三步数新批次：只有 70 一人过线，通过率跌到 0.1——**协变量偏移**的标准画像：人群均值挪走 14 分，规则的命运随之改写；
4. 追加一刀：如果监管同时把"合格线"的定义改成 50 分（外部环境改写 $Y$ 的含义），旧规则连对错的坐标系都失效了——这已经是**概念漂移**；
5. 结论：上线不是交付终点，而是分布监测起点。测试集只是抽取自过去的世界，生产环境永远在出下一张卷子。

## 5. 动手实验

### 实验 1：一根特征柱子量漂移

```viz
{
  "type": "datachart",
  "title": "特征『日均消费』的均值：训练集 42 元 → 三个月后 57 元",
  "labels": ["训练集", "三个月后的线上窗口"],
  "values": [42, 57]
}
```

第二根柱子比第一根高出三成多。单看哪一根都说不上异常，并排一看就该报警了——监控的本质就是**把这幅对比画挂在墙上**。

### 实验 2：手算两批考生在一条线下的命运

```python title="同一条及格线，两批考生"
train_scores = [55, 58, 60, 62, 64, 66, 68, 72, 76, 85]
live_scores = [40, 44, 46, 48, 50, 52, 54, 56, 60, 70]
line = 65                    # 模型的判别线：一年前定好的，至今未动

def pass_rate(scores):
    above = 0                # 计数器：过线人数清零起步
    for s in scores:         # for 循环逐个查看分数
        if s >= line:        # if 判断：达到判别线才算过
            above += 1       # += 累加：计数器加一，等价于 above = above + 1
    return above / len(scores)

print(round(pass_rate(train_scores), 2))
print(round(pass_rate(live_scores), 2))
```

输出 0.5 与 0.1。请体会这句话：两次计算的**函数完全相同**，不同的只是喂进去的那批人。

### 实验 3：线上准确率的周度曲线会自己招供

```python title="上线后每周的准确率，哪一周开始不对劲"
weekly_acc = [0.91, 0.90, 0.89, 0.87, 0.83, 0.78, 0.74]
baseline = sum(weekly_acc[:3]) / 3   # 切片取前三周求平均当基线
threshold = baseline - 0.05          # 容忍带：比基线低 5 个百分点就报警

import matplotlib.pyplot as plt      # 画图库，前面课程已介绍过
plt.plot(weekly_acc, marker="o")     # marker 让每个数据点带圆点
plt.axhline(threshold, linestyle="--", color="red")   # 画水平参考线
plt.xlabel("week")
plt.ylabel("accuracy")
```

红色虚线以下是警戒区。监控指标不用多花哨，一条带容忍带的曲线 + 一个响应流程，就胜过十个没人看的仪表盘。

### 实验 4：判题小练兵

```exercise
# @title: 练习：给特征漂移定级
# @check: 15.0
# @check: 3.0
# @hint: 标准化漂移 = 均值之差的绝对值 ÷ 训练期标准差；比值超过 2 就该拉响警报。
mean_train = 42.0    # 上线前训练集里“日均消费”的均值（元）
mean_live = 57.0     # 三个月后线上窗口的均值（元）
sd_train = 5.0       # 训练期的标准差：这个特征的正常波动幅度

diff = mean_live - mean_train
print(round(diff, 1))

z = diff             # ← 问题在这：还没除以波动尺度就想报警
print(round(z, 1))
```

均值挪了 15 元只是"数字"；除以标准差得到 3.0 才是"级别"——它意味着典型波动区间的三倍开外，按超过 2 即报警的约定必须响铃。固定阈值和标准化比值要搭配使用：不同特征波动脉搏不同，裸读元数会被"本来就是大数的特征"永久霸榜。

## 常见误区

:::warning[常见误区]

**误区一**："验证集够大就安全了。"
验证集再大也只是**旧世界的缩影**。它回答"模型记住了练习册没有"，回答不了"明年的考纲是什么"。防漂移靠的是持续采新血再测，而不是把旧血抽得更干。

**误区二**："分布外样本命中一次告警就是灾难。"
OOD 判定有误报和漏报，工程目标是**让它在坏事发生前多喊几嗓子并被听到**。第一反应应该是把这个样本转人工或标记低置信，而不是质疑整个模型。

**误区三**："漂移了就重训，重训完就完事。"
重训之前要先回答三问：漂的是输入、标签还是规律？有没有带偏见的新数据混进来？上一版为什么沉默？（第 30 课的教训：新分布里的"合格标签"本身就可能是历史偏见的复印件。）没有诊断的重训是把错误格式化一遍。

:::

## 6. 练习

**练习 1**：判断下列剧情各属于哪种偏移：(a) 平台主力用户从学生换成上班族；(b) 某病毒变异后症状谱改变，诊断规则的对应关系失效；(c) 双十一期间垃圾短信总量暴增。

<details>
<summary>点开查看逐步解答</summary>

(a) 输入人群构成变了、判定规律未变 → **协变量偏移**；(b) 特征到结论的映射被大自然改写 → **概念漂移**；(c) 标签的比例结构变化、单条骗术逻辑不变 → **标签偏移**。做题诀窍永远是先问一句：到底哪个条件分布动了？
</details>

**练习 2**：把实验 2 的训练批与线上批调换阈值试算：若阈值改为 52，两批通过率各是多少？这说明判别线的"体质"如何影响漂移敏感度？

<details>
<summary>点开查看逐步解答</summary>

阈值 52：训练批过线者 55,58,60,62,64,66,68,72,76,85 全体共 10/10 = 1.0；线上批 52,54,56,60,70 共 5/10 = 0.5。判别线越贴近某个批次的密度重心，对该批次的漂移越敏感——放在分布腰部位置的规则最容易被两头拉扯。
</details>

**练习 3**：概念辨析：为什么对抗样本（第 20 课）可以看成一种"自制的分布外"？

<details>
<summary>点开查看逐步解答</summary>

攻击者刻意把合法样本推过分界线附近的高曲率窄缝，构造出训练分布几乎不覆盖的点——像主动出一张刁钻卷。区别在于责任主体：漂移是大自然出的卷子，对抗样本是对手出的卷子。防御思路由此分化：前者靠持续采集新数据，后者靠对抗训练收紧边界几何。
</details>

## 7. 选读：为什么交换性和同分布在这里折断

<details>
<summary>选读 · i.i.d. 是谁的护身符</summary>

第 38 章检验、本章之后 conformal prediction 的覆盖保证，都建立在样本**独立同分布**（i.i.d.）或更弱的可交换性之上。协变量偏移破坏的是"新点与训练点同源"——线上世界的输入分布不再重合于训练世界的那一份，任何只数频率的保证书当场作废；概念漂移更进一步，把条件规律 $P(Y \mid X)$ 也换掉了。补救有两条路线：**重要性加权**（给稀有区域的老样本加大权重去逼近新分布）与**在线更新**（滑动窗口训练让规律追着世界跑）。两者都有代价——权重失控或追得太紧会把噪声也学进去。承认保证书的适用范围，是可信 AI 和普通机器学习在气质上的分水岭。
</details>
