# 对抗样本：一步之差的欺骗

## 1. 从一个场景开始

2016 年，CMU 的研究团队在 ACM CCS 会议（计算机安全顶会）上发表了一个令人脊背发凉的实验：给攻击者戴上一副**用普通打印机打出来的彩色镜框**，就能让最先进的人脸识别系统把他认成另一个人——论文标题就叫《Accessorize to a Crime》（Sharif 等，2016）。

镜框没有遮挡五官，人眼看着毫无异常；可它恰好是模型最怕的那种扰动。这种"人看不出、模型翻车"的输入叫**对抗样本**。它不是 bug，而是高维决策边界几何的必然产物。

## 2. 直觉解释

先看线性模型：得分 $s = w \cdot x + b$，正负号的分界是一个超平面。

想在不惊动人眼的前提下让分数变号，最优策略不是乱动 $x$，而是**沿 $w$ 方向推**——因为那是分数变化最陡的方向。每挪一单位距离，分数至少掉 $\|w\|$；只要原来离边界不够远，一小步就够了。

深度网络的道理类似，只是"哪个方向最陡"要靠梯度算出来。关键在于维度：输入有百万个像素时，"每维挪一点点"累积起来可以跨越巨大的决策距离，而每一维的变化小到肉眼无法分辨。**高维给了攻击者天然的藏身之处。**

## 3. 正式定义

对抗样本的构造是一个约束优化问题：

$$x_{\mathrm{adv}} = x + \delta, \qquad \|\delta\| \le \varepsilon, \qquad f(x_{\mathrm{adv}}) \ne f(x)$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $\delta$ | 扰动 | 加在原图上的微小修改 |
| $\varepsilon$ | 扰动预算 | 人眼察觉阈值内的最大步幅 |
| $f$ | 分类器 | 被攻击的模型 |

对应的防御目标写成极小极大博弈：

$$\min_\theta \ \max_{\|\delta\|\le\varepsilon} \ \mathrm{loss}\bigl(f_\theta(x+\delta), y\bigr)$$

这就是**鲁棒优化**：训练时不问"这个样本对不对"，而问"这个样本被允许范围内的最坏改动还能不能扛住"。内层 max 是攻击，外层 min 是防御。

## 4. 分步例题

二维线性分类器 $w = (3, 4)$、$b = 0$，点 $x = (-0.2,\ 0.1)$：

1. 算当前得分：$s = 3 \times (-0.2) + 4 \times 0.1 = -0.6 + 0.4 = -0.2$，判负类；
2. 想让它改判正类，沿 $w$ 方向走：每单位距离得分涨 $\|w\| = \sqrt{3^2+4^2} = 5$；
3. 需要把得分抬过 0，最小步长 $\|x^\star - x\| = |s| / \|w\| = 0.2 / 5 = 0.04$；
4. 具体走法：$\delta = 0.04 \times (w/\|w\|) = (0.024,\ 0.032)$，新点得分恰好为 0（再多半步就翻类）；
5. 对照：若不挑方向、只沿第一坐标硬推，需要挪 $0.2/3 \approx 0.067$——比最优方向多花 67% 的预算。**攻击的艺术就是找最省力的方向。**

## 5. 动手实验

### 实验 2：给线性分类器来一场小型攻击

```python title="ε-球内搜索：多少点能被翻转"
import random

random.seed(410)
w = [3.0, 4.0]     # 分类器权重
b = 0.0            # 截距
w_norm = 5.0       # 权重向量 (3,4) 的欧氏长度
unit = [w[0] / w_norm, w[1] / w_norm]   # 单位攻击方向：保证一步的距离可直接控制
eps = 0.06         # 扰动预算（欧氏距离的最大步幅）

def score(p):
    return w[0] * p[0] + w[1] * p[1] + b

flipped = 0
total = 300
for trial in range(total):
    p = [random.uniform(-1, 1), random.uniform(-1, 1)]   # 均匀撒点
    if abs(score(p)) > eps * w_norm: # 到边界距离超过 eps 的点不折腾
        continue
    # 贪心攻击：沿 ±w 方向各试一步，取能翻类的那个
    step = eps * 0.99
    cand_a = [p[0] + step * unit[0], p[1] + step * unit[1]]
    cand_b = [p[0] - step * unit[0], p[1] - step * unit[1]]
    if score(p) * score(cand_a) < 0 or score(p) * score(cand_b) < 0:
        flipped += 1

print(f"边界附近 300 点中被 ε 步内翻转: {flipped}")
```

固定种子下 24 个贴近边界的点全被翻转——注意候选点沿单位方向只移动了 `0.99 * eps`，真实位移严格小于 0.06。把 `eps` 缩到一半再跑，翻转数骤降：防御的第一性原理就是把样本推离边界（最大化 margin）。

### 实验 3：判题小练兵

```exercise
# @title: 练习：计算最小攻击步长
# @check: 2.0
# @check: 5.0
# @check: 0.4
# @hint: 向量长度是勾股定理 sqrt(w1*w1 + w2*w2)，不是分量相加；最小步长 = 得分绝对值 ÷ 权重长度。
w1, w2 = 3.0, 4.0
x1, x2 = -1.2, 0.4

score = w1 * x1 + w2 * x2          # 当前得分（负数 = 判负类）
print(round(-score, 1))            # 离边界还有多远（得分沟深）
w_norm = w1 + w2                   # ← 问题在这：这不是向量长度
print(round(w_norm, 1))            # 权重长度：决定"每走一步能换多少分"
min_step = abs(score) / w_norm     # 沿最优方向的最省力步长
print(round(min_step, 2))
```

修好之后三行分别是 2.0、5.0、0.4：得分沟深 2，权重长度 $\sqrt{3^2+4^2} = 5$，所以最省力的攻击只需挪 $2/5 = 0.4$。对照分步例题里"沿单坐标硬推要多花 67% 预算"——**挑对方向，攻击成本差近一倍**。

```quiz
线性得分 s = w·x + b 下，点到决策边界的最短欧氏距离是多少？
- abs(s) × norm(w)
- abs(s) / norm(w) [*]
- abs(s) - norm(w)
? 决策边界满足 w·x+b=0。沿单位化的 w 方向走，得分每单位距离变化 norm(w)，所以跨越边界所需距离是 abs(s)/norm(w)。
```

## 常见误区

:::warning[常见误区]

**误区一**："对抗扰动是人眼可见的大改动。"
在百万维图像里，$\varepsilon$ 可以小到每像素只变 1~2 个灰度级。总位移的"感知体积"与"决策距离"是两套度量——人眼的度量里隐形，模型的度量里惊天动地。

**误区二**："数据加够了，对抗样本自然消失。"
标准训练确实学不平坦的边界，但鲁棒泛化存在已知的天花板：抗扰动准确率与干净准确率之间存在权衡（这正是第 41 章泛化理论的对偶面）。更多数据有帮助，但不免费。

**误区三**："防御只要挡住梯度就行。"
把梯度藏起来（梯度掩蔽）常被当作防御卖，但攻击者可以用迁移攻击、黑盒查询绕开梯度。2016 年眼镜实验本身就有白盒/黑盒两个版本——评估防御必须按攻击者的真实信息量来。

:::

## 6. 练习

**练习 1**：手算：$w=(1,\ 1)$、$b=-1$，点 $(2,\ 2)$ 到决策边界的距离是多少？

<details>
<summary>点开查看逐步解答</summary>

得分 $s = 2+2-1 = 3$；$\|w\| = \sqrt{2}$；距离 $= 3/\sqrt{2} \approx 2.12$。

通用公式值得记住：**点到线性边界的距离 = $|w \cdot x + b| / \|w\|$**。margin 大小全由分母决定——权重越大，同样的输入离边界越"近"，越容易被骗。
</details>

**练习 2**：在实验 2 中把攻击策略换成"只动第一个坐标"（cand 改成 `[p[0]±step, p[1]]`），比较翻转数变化。

<details>
<summary>点开查看逐步解答</summary>

只动 $x_1$ 时每单位预算只能换 3 分得分（而不是 5 分），翻转数明显下降。这说明贪心方向选择的价值——也说明**非最优攻击仍是攻击**：安全评估不能赌对手犯蠢。
</details>

**练习 3**：概念辨析：对抗样本与第 41 章"泛化间隙"有什么联系？

<details>
<summary>点开查看逐步解答</summary>

两者都暴露了测试分布与训练优化的错位，但机制不同：泛化间隙来自"没见过的数据"，对抗样本来自"被设计过的数据"。后者更凶险，因为它主动挑选了你防线上最薄的一点。鲁棒优化相当于把"最坏情况"提前塞进训练，用牺牲平均性能换取下限保证。
</details>

## 7. 选读：为什么高维里总藏得住翻转点

<details>
<summary>选读 · 维度诅咒的另一面</summary>

直觉化论证：设模型在训练分布上表现完美，但决策边界是弯弯曲曲的低维曲面。随机方向的扰动落在边界上的概率随维度上升并不衰减，而"沿梯度方向"的一步几乎必然缩短到边界的距离。当输入维度 $n$ 很大时，$\varepsilon$-球内的方向数量呈指数爆炸，其中总存在既满足人眼不可见、又跨越边界的组合。Szegedy 等人在 2013 年首次系统报告这一现象，Goodfellow 等人 2015 年给出线性解释并提出快速梯度符号法——从此"攻与防"成为机器学习安全的固定剧目。

</details>
