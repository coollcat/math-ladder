# Conformal prediction 的覆盖保证

## 1. 从一个场景开始

分诊助手升级了：上一课治好了它的"虚报价"，现在它不仅说"恶性概率 92%"，还定期接受校准复检。外科医生追问了一个更刁的问题："92% 我听懂了——**这条预测的可信范围到底多宽？**你敢不敢给我一个区间，并担保它至少九成会罩住真实值？"

第 38 章的置信区间能造这种带子，但要先押上正态假设或大样本近似的筹码。如果样本只有十个、分布形状不明、还舍不得押注呢？Conformal prediction（保形预测）给出第三条路：**不假设正态，也要给出敢署名的区间。**

## 2. 直觉解释

整件事只需要三步，像给一批学生排成绩：

1. **打分**：用一套现成模型逐个算"不匹配分数"——回归里最常用绝对残差（真实值减预测值的绝对值）：猜得越离谱分越高；
2. **排序**：把这堆分数从小到大排队；
3. **取分位数**：按想兜住的把握挑一个名次，那个名次上的数就是半径 $q$。此后每条新预测都报 [ŷ − q, ŷ + q] 这么宽的带子。

为什么这样就能担保？把校准集想成一副洗匀的牌，新样本是牌堆里再摸出的一张：它和牌堆里任何一张身份平等。既然大约九成的老牌残差排在那个门槛之下，新这张也九成落进同一扇门——**排名换担保，几何零假设**。

全程没有高斯、没有中心极限，只用了一个比 i.i.d. 还弱一点的要求：**可交换性**——样本像洗匀的牌，谁先谁后不带信息。

## 3. 正式定义

取定错误率 $\alpha$（想要约 $1-\alpha$ 的覆盖率），校准集大小为 $n$：

$$k = \lceil(n+1)(1-\alpha)\rceil$$

q 就是校准分数里第 k 小的那一个。新预测区间记作 [ŷ(x) − q, ŷ(x) + q]，它满足有限样本覆盖保证：

$$\Pr(y \in C(x)) \ge 1-\alpha$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| ŷ(x) | 基础预测器 | 随便什么模型，哪怕是个黑箱，conformal 不看它的内脏 |
| 不匹配分数 | 分数函数 | 衡量"预测与真相差多远"；回归常用绝对残差 |
| $n$ | 校准集大小 | 专门用来定 $q$ 的那批数据 |
| 可交换性 | 交换前提 | 校准点与新点可以互换位置而不改变联合规律 |

三处必须诚实：

- 保证是**边际的**：对随机抽到的整体兑现"至少九成"，不承诺你手上某一条；
- 前提是**可交换**：一旦出现上一课的分布偏移、时间趋势，保证书作废；
- 交付物是**预测区间**：它如实报告不确定性的宽窄，但不是因果解释——问"为什么是这条区间"要回到第 42 章的工具箱。

## 4. 分步例题

护士站用小模型预估住院天数。拿 8 位已出院病人做校准集，他们的绝对残差升序排列后是：

$[0.5,\ 1.2,\ 1.8,\ 2.6,\ 3.3,\ 4.1,\ 5.0,\ 7.2]$（单位：天）

目标：覆盖率不低于 75%，即 $\alpha = 0.25$。

1. 算名次：$(n+1)(1-\alpha) = 9 \times 0.75 = 6.75$，向上取整得 $k = 7$；
2. 取分数：第 7 小的残差是 $q = 5.0$ 天；
3. 定区间：下一位病人的预估住院是 ŷ = 6 天 → 报告区间 [1.0, 11.0] 天；
4. 检查口径：若只对"误差不超过 5 天"负责，这个宽度可以背书；若护士站的工作节奏需要 ±1 天精度，这份数据说实话——模型撑不起；
5. 附注：名次公式里的 $+1$ 是给"新来的这一张牌"留的空位，细节见本课末尾选读。

### 实验 2：手工跑一遍 split conformal

```python title="三步法完整实现：n=8 的住院天数例子"
residuals = [0.5, 1.2, 1.8, 2.6, 3.3, 4.1, 5.0, 7.2]   # 已排序的绝对残差
n = len(residuals)
alpha = 0.25          # 目标错误率：想兜住至少七成半

raw = (n + 1) * (1 - alpha)   # 名次的原始值，可能是小数
k = int(raw)                  # int() 直接砍掉小数部分
if k < raw:                   # 只要没切干净就进一位——这就是向上取整
    k += 1
print(k)

q = residuals[k - 1]          # 第 k 小：列表从 0 数起，所以要减一
print(q)

pred_new = 6.0                # 下一位病人的模型预估住院天数
low = pred_new - q            # 区间下沿
high = pred_new + q           # 区间上沿
print(low, high)

fresh = [0.3, 0.8, 1.4, 2.0, 2.5, 3.1, 3.6, 4.2, 4.8, 5.4,
         2.2, 3.9, 4.5, 1.1, 0.6, 2.8, 4.0, 4.7, 12.0, 18.3]  # 后续 20 位真实残差
covered = 0
for r in fresh:
    if r <= q:                # 单侧口径：误差不超过半径 q 即罩住
        covered += 1
print(covered / len(fresh))
```

手备的 20 条后续残差里罩住 17 条，经验覆盖率 0.85，高出 0.75 的法定底线一截。真做研究时要把"抽 20 个"重复上千次看平均——边际保证是对无数次重来的平均兑现的，这里先让你看一次手感。

### 实验 3：判题小练兵

```exercise
# @title: 练习：换一批校准数据重定半径
# @check: 48.0
# @check: 5.6
# @check: 42.4
# @hint: 名次要向上取整；第 k 小在列表里是 residuals[k-1]，因为下标从 0 起数。
residuals = [0.4, 0.9, 1.5, 2.2, 2.9, 3.6, 4.3, 5.6, 7.7]
n = 9
alpha = 0.25                       # 同样追求 75% 覆盖
pred = 48.0                        # 新订单的模型预估处理时长（小时）

raw = (n + 1) * (1 - alpha)
k = int(raw)                       # ← 问题在这：直接砍掉小数会低估名次
print(pred)
q = residuals[k - 1]
print(q)

print(pred - q)
```

改对名次计算后输出 48.0、5.6 与 42.4：$10 \times 0.75 = 7.5$ 进位到 $k=8$，第 8 小的残差是 5.6。向下取整会把区间做得过窄——看似利落，实则在偷偷透支覆盖率。

## 常见误区

:::warning[常见误区]

**误区一**："有了 conformal 就不需要校准了。"
两者互补而非替代：校准管概率话术诚不诚实（第 10 课），conformal 管**区间的宽度有没有法律效力**。一个谎言连篇的分数照样能撑起形状完美却毫无意义的区间。

**误区二**："区间越窄模型越好。"
$q$ 是由校准残差喂出来的：窄区间可能只是因为校准那几天恰好风平浪静。宽度的诚实远比宽度的小巧珍贵——读报告的人有权知道带宽的真实底价。

**误区三**："它给了 ninety-percent 的答案，所以能回答'这个人为什么被拒'。"
覆盖保证是频率承诺，不是解释件。归因与反事实回答"原因与出路"（第 40 课），conformal 回答"这话说出来有多粗"。别让区间冒充理由。

:::

## 6. 练习

**练习 1**：同一个校准集，把 α 从 0.25 收紧到 0.05，k 会怎么变？用实验 2 的 8 条残差实际算出新区间。

<details>
<summary>点开查看逐步解答</summary>

$(8+1) \times 0.95 = 8.55$ → $k = 9$。此时第 9 小的分数超出了列表长度——工程约定是**穷尽所有已知残差**，即 $q$ 取最大值 7.2：想兜住更多就必须容忍最大的那位失败者。区间变为 $[6 - 7.2,\ 6 + 7.2] = [-1.2,\ 13.2]$ 天。负的下沿提醒我们：现实约束的截断应贴在业务边界上。
</details>

**练习 2**：分类问题里如何选不匹配分数？给出一条广告点击模型的可行方案。

<details>
<summary>点开查看逐步解答</summary>

最朴素的选择是**不给真标签的分数**：新样本拿不到输出集合 $C(x)$ 的资格线，就用校准集里"该类别的 1 减模型自报概率"当分数。若校准集中假货类的该分数第 $k$ 小为 0.31，则新样本凡是某类别得分扣剩超过 0.31 的都要剔除出许可清单。分数只要满足"真实标签的分数倾向于更小"即可成立。
</details>

**练习 3**：概念辨析：交换性与独立同分布差在哪里？举一个可交换但不独立的场景。

<details>
<summary>点开查看逐步解答</summary>

i.i.d. 要求每个样本既同分布又彼此独立；可交换性只要求**联合规律对顺序不敏感**——重新洗牌后的每一副牌都同样可信。抽样检查中不放回地抽取考生构成可交换但不独立的序列（抽走一人改变后续抽样的条件世界）。conformal 的证明只需要后者，这是它能承受比经典统计略粗原料的原因。
</details>

## 7. 选读：那个 +1 是留给谁的

<details>
<summary>选读 · 牌桌空位的一行论证</summary>

设校准分数与新样本分数合并后可交换，则新分数在这 n+1 张牌里占据的名次等可能地是 1 到 n+1 的任何一个。于是"新牌比老牌中第 k 小还大"的概率不超过 1 − k/(n+1)。代入 $k = \lceil(n+1)(1-\alpha)\rceil$ 后，失败率至多 α，即覆盖率至少 1−α。整个证明只用了"洗匀"一件事——若没有 +1 这个空位，名次统计会把新那张牌挤出牌桌，严格性随之漏气。
</details>
