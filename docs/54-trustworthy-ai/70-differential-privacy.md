# 差分隐私与隐私预算

## 1. 从一个场景开始

一家连锁诊所想公布季度统计："本月共接诊 100 人次"。数字本身很干净——可如果张阿姨的邻居记得她上周去过这家诊所，再对照"上一个没有她的月份公布的是 99"，两条公告一减，**她就暴露了**。删掉姓名、打乱顺序都挡不住这种对照攻击。

需要的承诺换一种说法：无论张阿姨的记录在不在数据库里，诊所对外公布的答案都应该**几乎看不出差别**。这就是差分隐私（differential privacy）：一个人的加入不该让世界看出痕迹。

## 2. 直觉解释

让回答变得"含糊而公平"的办法是掷骰子：

- 真实答案先算出来（比如计数 100）；
- 发布前往上面**加一点随机噪声**再报出去；
- 噪声不是拍脑袋加的：它按一个公开的配方生成，任何人都能核验它的松紧程度。

$\varepsilon$（epsilon）就是那把刻度尺：它衡量"一个人在场与否"最多能让某个答案的可信度变化几倍。

- $\varepsilon$ 很小（如 0.1）→ 答案噪声很大，围观者几乎无法判断某人在不在场，隐私强；
- $\varepsilon$ 较大（如 5）→ 回答贴近真值，分析者开心，但知情者也能从中读出个体痕迹，隐私弱。

直觉版承诺："无论你怎么聪明地拷问这一批答案，你对我这位朋友的下注倍数最多被放大 $\exp(\varepsilon)$ 倍。"计数类问题里一个人最多把总数改变 1，所以只需为这"一格"的敏感度付费。

## 3. 正式定义

设 $D$ 与 $D'$ 是一对**相邻数据集**：两者完全相同，只在一条记录上有出入（某人一场/某人不在场）。若机制 $M$ 对任何可能的输出集合 $S$ 都满足

$$\Pr(M(D) \in S) \le \exp(\varepsilon) \cdot \Pr(M(D') \in S)$$

就称 $M$ 满足 $\varepsilon$-差分隐私。

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $M$ | 随机化机制 | "真实值 + 受控噪声"整套流程 |
| $D$, $D'$ | 相邻数据集 | 只差一个人的两个世界 |
| $S$ | 输出集合 | 观察者可能看到的那一类答复 |
| $\varepsilon$ | 隐私损失上限 | 两世界概率比的最高允许倍数 |

**拉普拉斯机制**是计数问题最常用的兑现方式：查询对单人记录的敏感度记作 $\Delta$（计数查询里就是 1），给真值加上尺度为 $b = \Delta/\varepsilon$ 的拉普拉斯噪声即可。拉普拉斯噪声的形状像一座尖顶帐篷：尖顶立在全值的期望位置，两侧尾巴按 $\exp(-\lvert x-\mu \rvert/b)$ 的速度衰减，比高斯更厚重的尾部保证极端摆动足够常见。

**预算会累加**：同一群人身上发布的每一条答案都在花 $\varepsilon$，花的次数越多、单次金额越大，合起来的暴露风险越大——这是把"隐私当成会计科目"的组合直觉。

## 4. 分步例题

夜班诊所的人流账本：张阿姨在场时计数为 100，不在场为 99。取 $\varepsilon = 0.5$，则噪声尺度 $b = 1/0.5 = 2$。

用一串事先抽好、供人复核的拉普拉斯噪声（尺度 2）：`[+3.7, −2.9, +1.2, −5.1, +0.4]`：

1. 在场世界的五次发布：100 加各条噪声 → `103.7, 97.1, 101.2, 94.9, 100.4`；
2. 不在场世界：同样的噪声落到 99 上 → `102.7, 96.1, 100.2, 93.9, 99.4`；
3. 对照检验：两列答案逐行只差 1——单看任何一次发布，观测者的处境几乎相同；
4. 区分倍数：$\exp(0.5) \approx 1.65$，即无论分析者多狡猾，对"她在场吗"这个赌局的下注最多被推高约 1.65 倍；
5. 若想再稳一点，取 $\varepsilon = 0.1$ 得 $b = 10$：噪声幅度大了一个数量级，这就是第 5 段图表里那四笔晃动剧烈的发布。

### 实验 3：手跑一遍含噪账本

```python title="同一个问题，两本相邻的账"
true_with = 100        # 张阿姨在场时的真实计数
true_without = 99      # 她不在场时的真实计数
eps = 0.5              # 本月愿意支付的隐私损失
b = 1 / eps            # 拉普拉斯噪声尺度：Δ=1 的计数查询取 1/epsilon

pool = [3.7, -2.9, 1.2, -5.1, 0.4]    # 已按 Laplace(0, b) 抽好的一串噪声，便于核对
with_answers = []                     # 收集在场世界的发布结果
without_answers = []                  # 收集不在场世界的发布结果

for n in pool:                        # 同一批噪声喂进两个世界
    with_answers.append(round(true_with + n, 1))
    without_answers.append(round(true_without + n, 1))

print(with_answers)
print(without_answers)

factor = 2.718281828459045 ** eps     # ** 是幂运算：这里算 exp(epsilon)
print(round(factor, 2))
```

两行列表逐位对比：任何一个位置的差恰好是 1，但外面的人只看得见发布值，看不见对照列。第三行的 1.65 就是公式里那个区分倍数。

### 实验 4：判题小练兵

```exercise
# @title: 练习：这份隐私预算还够批准几次
# @check: 3
# @check: 0.75
# @hint: 预算按请求累加 epsilon；审批规则应该是"加上这笔仍不越过红线才放行"，先斩后奏会让总暴露失控。
budget = 1.0                        # 季度允许花费的总 epsilon
spends = [0.3, 0.25, 0.2, 0.4]      # 排队等候的四次查询报价

used = 0.0                          # 已花掉的预算（累加器）
count = 0                           # 已批准的查询数
for s in spends:
    used = used + s                 # ← 问题在这：不看红线照单全收
    count = count + 1

print(count)
print(round(used, 2))
```

修好的审批逻辑应该在每次放行前检查"花了这笔还在预算内吗"：0.3 与 0.25、0.2 相继获批后已花 0.75，第四次要价 0.4 会越线，必须拒收。数字背后是真金白银的风险——组合定理告诉你，总共 1.15 个 $\varepsilon$ 的暴露比 0.75 高出一个量级不止。

## 常见误区

:::warning[常见误区]

**误区一**："取 ε 小到接近零最安全。"
$\varepsilon$ 趋近 0 时保证完美，但答案也彻底随机，数据不再有用。差分隐私是一门**定价学**：在隐私与分析价值之间选一个敢写进制度的位置，而不是假装价格可以为零。

**误区二**："预算偶尔超支一点点没关系。"
每一条已发布的答案都是永久暴露，不能撤回。超支不像是信用卡晚还两天，更像锁坏了一格——组合定理按最坏情形累加，事后没法"补回"。

**误区三**："我做过匿名化了，已经够了。"
删姓名只是第一步。邮编、生日、就诊时间 triplet 式组合能把绝大多数人唯一锁定——2006 年 Netflix 影评与 1990 年人口普查的反推案例都是前车之鉴。差分隐私的优势正是对**任意辅助信息**都有数学兜底。

:::

## 6. 练习

**练习 1**：想再发布三个计数：门诊人次、输液人次、转诊人次，分别定价 ε 为 0.05、0.15、0.1。若本季度剩余预算 0.4，三问全发够不够？

<details>
<summary>点开查看逐步解答</summary>

合计 $0.05 + 0.15 + 0.1 = 0.3 \le 0.4$，全发后仍剩 0.1 余量。注意这里展示的是最宽松的串行组合上界：若三项查询作用在**互不重叠的人群子集**上，还有更省钱的并行组合可用（每个人至多被一项查询波及），预算开销可以降到单笔最大值。
</details>

**练习 2**：把手算例子里 $\varepsilon$ 从 0.5 改成 2，尺度 b 变成多少？观察一下两次实验里的回答风格会发生什么变化。

<details>
<summary>点开查看逐步解答</summary>

$b = 1/2 = 0.5$，噪声典型幅度缩小到原先四分之一。发布值将紧紧贴着 100 与 99 打转，分析者眉开眼笑——同时区分倍数涨到 $\exp(2) \approx 7.39$：懂行的人几乎可以从答案轮廓反推个体的存在与否。便利与保护之间的拉锯从未消失。
</details>

**练习 3**：概念辨析：为什么说差分隐私与第 34 章"一次一密"式的完美保密目标不同？

<details>
<summary>点开查看逐步解答</summary>

完美保密追求敌手学到**零比特**信息，代价是密钥至少和消息一样长，现实中难以用于统计分析。差分隐私退一步谈生意：允许学到一些群体规律，只为"认出任何单独一个人"的能力设置硬顶。它是统计学与密码学之间一座实用主义的桥。
</details>

## 7. 选读：另一种机制与另一条组合路

<details>
<summary>选读 · 高斯机制与并行组合</summary>

拉普拉斯机制对应 $\varepsilon$ 这一档严格口径；若允许多冒一点失败率 δ，可以用**高斯机制**：噪声换成正态分布，参数按 $(\varepsilon, \delta)$ 定标。它在数值分析上更好合并，是深度学习训练阶段差分隐私（DP-SGD 一族）的主力。组合方向上除了串行累加，还有并行组合：查询作用于把人群切成不相交小组的设计（例如每人只出现在一个部门的汇总里）时，总消耗不再是求和，而是单组最大值——工程师据此设计"每人每天只被计一次"的上报结构，能在同样预算下多攒几倍的查询次数。
</details>
