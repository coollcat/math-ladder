# 可解释性：归因与反事实

## 1. 从一个场景开始

贷款申请被拒，客户打电话来问："为什么？"监管也要求给得出理由。模型吐出的只是一个分数，可决定背后站着几十个特征、上亿个参数。**可解释性（XAI）**要回答两类问题：

- **归因**：这次拒贷里，每个因素各背多少锅？（向后看）
- **反事实**：改什么、改多少，结果会翻盘？（向前看）

一个是账本，一个是路标。两者都给了，"解释"才算闭环。

## 2. 直觉解释

**归因**像分账。总分是所有特征合力的结果，把总分减去基线（比如"平均水平申请人"的得分），再按每个特征的贡献拆开——线性模型里这笔账可以算得**一分不差**：

$$\text{贡献}_i = w_i \times \bigl(x_i - \text{基线}_i\bigr)$$

**反事实**像导航。"你的收入再加 2 万就会通过"比"你的收入权重是 0.25"有用得多——它是可行动的。好的反事实有三条要求：改动最小、能到达目标（有效性）、现实中做得成（可行性——"年轻 5 岁"不算建议）。

两者的分工：归因解释"为什么是这个结果"，反事实解释"怎样变成另一个结果"。监管与用户各取所需。

## 3. 正式定义

设模型 $f$，输入 $x$，参考基线 $x'$（可以是均值、中位数或"默认人"）。

**留一法归因**（leave-one-out）：

$$\phi_i = f(x_1,\dots,x_i,\dots,x_n) - f(x_1,\dots,x'_i,\dots,x_n)$$

即"把这个特征换成基线值，分数掉多少"。线性模型的留一法恰好等于 $w_i(x_i - x'_i)$，且所有 $\phi_i$ 加起来正好等于 $f(x)-f(x')$——账目守恒。

**反事实解释**是一个约束优化：

$$x^{\mathrm{cf}} = \arg\min_{z}\ \|z - x\| \quad \text{s.t.} \quad f(z) \ge \text{阈值}$$

距离用什么范数衡量、哪些特征允许动，都是建模者的伦理选择，不只是技术细节。

## 4. 分步例题

信用评分模型：$\text{score} = 0.25 \times \text{收入(万)} + 0.30 \times \text{年限} - 0.10 \times \text{负债(万)}$。申请人：收入 20、年限 6、负债 3；基线申请人：收入 12、年限 4、负债 5。

1. 申请人得分：$0.25\times20 + 0.30\times6 - 0.10\times3 = 5 + 1.8 - 0.3 = 6.5$；
2. 基线得分：$3 + 1.2 - 0.5 = 3.7$；总分差 $6.5 - 3.7 = 2.8$；
3. 分账：收入 $0.25\times8 = 2.0$；年限 $0.30\times2 = 0.6$；负债 $-0.10\times(-2) = +0.2$；
4. 守恒检查：$2.0 + 0.6 + 0.2 = 2.8$ ✓ 一分不差；
5. 反事实：通过线设在 7.0，还差 0.5 分。备选方案：收入加 2 万（$0.25\times2 = 0.5$）、年限加 1.67 年、负债减 5 万。哪个最可行？——这就是要交给业务约束的问题。

### 实验 2：归因账本 + 反事实搜索

```python title="线性评分的分账与最小翻盘改动"
w = [0.25, 0.30, -0.10]        # 各特征权重
names = ["收入", "年限", "负债"]
x = [20.0, 6.0, 3.0]           # 申请人特征
base = [12.0, 4.0, 5.0]        # 基线申请人
threshold = 7.0                # 通过分数线

def score(v):
    s = 0.0
    for i in range(len(w)):
        s = s + w[i] * v[i]
    return s

full = score(x)
print(f"申请人得分: {round(full, 2)}")

for i in range(len(w)):
    x_wo = x[:]                # 浅拷贝：复制一份列表再去改它
    x_wo[i] = base[i]
    phi = full - score(x_wo)   # 留一法：抽走第 i 个特征后掉多少分
    print(f"{names[i]} 贡献: {round(phi, 2)}")

# 反事实搜索：只调收入（万元），找最小整数步过线
delta = 0
while full + w[0] * delta < threshold:
    delta += 1
print(f"最少加 {delta} 万收入即可过线")
```

三行贡献相加恰好等于总分减基线分——线性世界的完美分账。非线性模型的对应物（SHAP）要靠更多假设才能守住这份守恒，代价是计算量暴涨。

### 实验 3：判题小练兵

```exercise
# @title: 练习：用留一法算年限的贡献
# @check: 6.5
# @check: 0.6
# @hint: 归因 = 完整得分 − 抽走该特征后的得分；谁减谁别写反。
w = [0.25, 0.30, -0.10]
x = [20.0, 6.0, 3.0]
base = [12.0, 4.0, 5.0]

def score(v):
    return w[0]*v[0] + w[1]*v[1] + w[2]*v[2]

full = score(x)
print(round(full, 2))

x_wo_year = [x[0], base[1], x[2]]     # 只把年限换成基线值
attr_year = score(x_wo_year) - full   # ← 问题在这：减数与被减数颠倒了
print(round(attr_year, 2))
```

改对方向后输出 6.5 与 0.6，和手算一致。再验证守恒：把三个特征轮流这样算一遍加总，应当等于 $6.5 - 3.7 = 2.8$。

```quiz
- 所有贡献必须都是正数
- 所有特征贡献相加等于完整预测与基线预测之差 [*]
- 贡献最大的特征一定是因果原因
? 对线性模型，每个贡献是权重乘以“样本值减基线值”；求和时常数项抵消，正好剩下 f(x)-f(x')。负贡献也是账本的一部分。
```

## 常见误区

:::warning[常见误区]

**误区一**："归因大就是因果性强。"
归因回答的是"这个输入对这次输出的功劳"，建立在特征相关之上。若收入与学历高度相关，功劳会在两者之间来回摊——它不是干预实验意义上的因果效应（想问因果，请回到第 42 章的反事实框架）。

**误区二**："给出反事实就算负责任。"
"年龄小 5 岁就能过线"在数学上是最短路径，在伦理上是灾难。可行的反事实必须附加行动约束（可改变的特征优先、不越法律红线），否则解释本身就成了歧视的说明书。

**误区三**："解释工具输出的就是真相。"
LIME/SHAP 这类事后解释可以被专门构造的模型欺骗——2020 年已有研究演示了"骗过 SHAP"的攻击。解释件和模型本体一样需要审计：换几种工具交叉验证、检查扰动下的稳定性。

:::

**练习 2**：把实验 2 的反事实搜索改成同时搜"收入加 X 万"和"负债减 Y 万"，找出改动总量最小的组合。

<details>
<summary>点开查看逐步解答</summary>

需要净涨 0.5 分。候选组合：收入 +2（总改动 2）；负债 −5（总改动 5）；收入 +1 且负债 −2.5？$0.25\times1 - (-0.10)\times(-2.5)\rightarrow 0.25 - 0.25$……注意负债减 2.5 万得分变化是 $-0.10\times(-2.5) = +0.25$，加上收入 0.25 恰好 0.5，总改动 3.5。所以单靠收入加 2 万最省。若引入"每年限只能加 0.5 年"之类的现实约束，答案立刻改变——约束不同，最短路径不同。
</details>

**练习 3**：概念辨析：对抗样本（上一课）与反事实解释有什么本质区别？

<details>
<summary>点开查看逐步解答</summary>

数学形式几乎同款：都是在输入空间里找"最小改动跨越决策边界"的点。区别在目的与服务对象——对抗样本为**攻击者**服务，要让机器犯错且人眼无感；反事实为**被决策者**服务，要给人一条可行动的路。同一枚硬币：理解了边界几何，既能造武器也能写说明书。
</details>

## 7. 选读：Shapley 值——从分赃到分账

<details>
<summary>选读 · 公平分账的四条公理</summary>

1953 年 Shapley 为合作博弈设计的分账方案：n 人合作产出了总值，按四条公理（效率：账目守恒；对称：干一样的活拿一样的钱；哑元：没贡献拿零；可加性：两场合并等于分别之和）推出唯一分配。2017 年起它被搬进机器学习当作归因金标准（SHAP）：把"特征子集"当玩家、"模型输出增量"当产出。代价是精确计算随特征数指数爆炸，实践中用采样近似。记住要点：**公理选定了账本格式，但填进账本的数字仍然依赖你给的基线和数据分布**——工具不会替你做价值判断。
</details>
