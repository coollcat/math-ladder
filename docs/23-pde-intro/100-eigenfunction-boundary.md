# 特征函数与边界：模态是被筛出来的

## 1. 从一个场景开始

同样是那根一米长的铜杆，换个玩法：这一次两端不插冰水，而是紧紧裹上绝热棉花——热量一点都跑不掉。上一课的正弦模态还有效吗？

答案是不完全有效。两端固定时，杆的两端被钉死在 0 度，只有"在端点处恰好为零"的正弦活了下来；两端绝热时，端点不许有温度梯度，活下来的是"端点处斜率为零"的余弦。**边界条件像一把筛子，而筛孔的形状由物理决定。** 本课把三种典型边界摆在一起，看清这把筛子怎么挑出一整族特征函数。

## 2. 直觉解释

把空间方程 $X''+\lambda X=0$ 想成一根绷紧的橡皮筋，边界条件就是两端的夹具：

- **两端固定**（Dirichlet）：两个端点被钉在 0 高度，橡皮筋只能在这些钉住的点之间鼓起。能站住的驻波是半波、全波、一个半波……第 $n$ 号就是 $n$ 个半波。
- **两端绝热**（Neumann）：端点不被钉住，但要求那里的斜率为零——橡皮筋在端点必须是平的。第 1 号就是"整根平平的"：一个常数。
- **左固定右绝热**（Mixed）：左端钉住、右端放平，能站住的是"四分之一波"家族：$\sin\frac{\pi x}{2L}$、$\sin\frac{3\pi x}{2L}$……

三种夹具，三套模态。共同点是：**编号越大，内部零点越多，空间形状振荡越密。**

## 3. 正式定义

统一记 $\omega_n$ 为第 $n$ 号模态的"空间频率"，三种边界下：

| 边界 | 条件 | 特征函数 $X_n(x)$ | 特征值 $\lambda_n$ | 内部节点 |
| --- | --- | --- | --- | --- |
| 两端固定 | $X(0)=X(L)=0$ | $\sin\dfrac{n\pi x}{L}$ | $\left(\dfrac{n\pi}{L}\right)^2$ | $n-1$ |
| 两端绝热 | $X'(0)=X'(L)=0$ | $\cos\dfrac{(n-1)\pi x}{L}$ | $\left(\dfrac{(n-1)\pi}{L}\right)^2$ | $n-1$ |
| 左固定右绝热 | $X(0)=X'(L)=0$ | $\sin\dfrac{(n-\frac12)\pi x}{L}$ | $\left(\dfrac{(n-\frac12)\pi}{L}\right)^2$ | $n-1$ |

三种情形都从 $n=1$ 开始编号，且内部零点个数一律是 $n-1$。

特别留意绝热族的第一号：$X_1=\cos 0=1$，$\lambda_1=0$。它的时间因子是 $e^{-k\cdot0\cdot t}=1$——**永不衰减**。这不是退化，而是守恒律在模态语言里的化身：热量跑不掉，那么总热量守恒，杆最终趋向的温度就是初始温度的平均值，而"平均值"正是那个常数模态携带的信息。

## 4. 分步例题

**例 1**：取 $L=1$，列出三种边界的前三个特征值。

1. 两端固定：$\lambda_1=\pi^2\approx9.870$，$\lambda_2=4\pi^2\approx39.478$，$\lambda_3=9\pi^2\approx88.826$；
2. 两端绝热：$\lambda_1=0$，$\lambda_2=\pi^2\approx9.870$，$\lambda_3=4\pi^2\approx39.478$；
3. 左固定右绝热：$\lambda_1=(\pi/2)^2\approx2.467$，$\lambda_2=(3\pi/2)^2\approx22.207$，$\lambda_3=(5\pi/2)^2\approx61.685$。

**例 2**：观察例 1 的两条规律。

1. 同一编号下，两端固定的 $\lambda$ 最大 → 同样形状衰减最快（两端是冰水，热量有出口）；
2. 两端绝热的 $\lambda$ 整体最小，且第 1 号为 0 → 没有出口，最终只剩平均温度；
3. 混合边界夹在两者之间：只开了一个出口。

### 实验 2：三种边界的特征值表

```python title="把三套特征值并排打印出来"
import math

L = 1.0

def lam_dirichlet(n):        # 两端固定：ω = nπ/L
    return (n * math.pi / L) ** 2

def lam_neumann(n):          # 两端绝热：ω = (n-1)π/L
    return ((n - 1) * math.pi / L) ** 2

def lam_mixed(n):            # 左固定右绝热：ω = (n-0.5)π/L
    return ((n - 0.5) * math.pi / L) ** 2

for n in range(1, 4):        # range(1,4) 依次生成 1、2、3
    print(n, round(lam_dirichlet(n), 3), round(lam_neumann(n), 3), round(lam_mixed(n), 3))
```

输出 `1 9.87 0.0 2.467`、`2 39.478 9.87 22.207`、`3 88.826 39.478 61.685`。三列并排看，绝热列整体右移一格——它的第 1 号是零，其余与固定列错开一位。

### 实验 3：绝热杆的常数模态就是守恒的平均温度

```python title="绝热边界下，总热量守恒、最终趋向平均值"
u = [0.0, 0.5, 1.0, 0.5, 0.0, 0.2, 0.4]   # 七个格点的初始温度
r = 0.2                                   # 差分比 r = k*dt/h^2，须不超过 0.5

def step(v):                              # def 定义函数：做一次显式时间推进
    out = v[:]                            # 切片复制：得到一份互不影响的副本
    for i in range(1, len(v) - 1):        # 内部点：与左右两邻交换热量
        out[i] = v[i] + r * (v[i - 1] - 2 * v[i] + v[i + 1])
    out[0] = v[0] + r * (v[1] - v[0])     # 左端绝热：边界通量为零，只与右邻交换
    out[-1] = v[-1] + r * (v[-2] - v[-1]) # 右端绝热，同理；-1 表示最后一个元素
    return out

def mean(v):
    return sum(v) / len(v)

print(round(mean(u), 4))                  # 初始平均温度
for _ in range(80):                       # 下划线变量名：这个计数用不到，只是占位
    u = step(u)
print(round(mean(u), 4))                  # 八十步之后的平均温度
print(round(max(u) - min(u), 4))          # 极差：衡量还剩多少"形状"
```

输出 `0.3714`、`0.3714`、`0.0061`。平均值纹丝不动（守恒律），极差从 1.0 缩到千分之六——所有衰减模态都死掉了，只剩那个 $\lambda=0$ 的常数模态站在原地。**这就是"绝热杆最终变成一潭温吞水平均温度"的模态解释。**

代码里两端那两行是"零通量"写法：端点只跟唯一的邻居交换热量，边界上没有进出的通道。若改成直接把邻居的值抄过来（`out[0] = v[1]`），平均值会缓慢漂移——离散格式也必须尊重守恒律，这是第 20 课通量记账在代码层面的回响。

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为绝热边界的 $\lambda_1=0$ 是没有信息的平凡解。它恰恰是最重要的一个：它代表守恒量。凡是"跑不掉"的物理量，都会在某个边界条件下产生一个零特征值模态。

**误区二**：你以为换边界会改变节点数规律。三种边界下第 $n$ 号模态的内部零点一律是 $n-1$ 个，变的是形状（正弦/余弦/四分之一波）和 $\lambda$ 的取值。

**误区三**：你以为 $\lambda$ 一定大于零。绝热族的 $\lambda_1=0$ 就在零上坐着；它是全场唯一不衰减的模态，决定了系统"最终剩下什么"。

:::

## 9. 选读：为什么每个 λ 只对应一个模态

<details>
<summary>选读 · 一维 Sturm-Liouville 问题的一句话结论</summary>

空间方程连同边界条件合称 Sturm-Liouville 问题。对一维情形有一条漂亮的结论：**特征值可以按从小到大排成一列 $\lambda_1<\lambda_2<\lambda_3<\cdots$，每个 $\lambda_n$ 对应（至多差一个常数倍的）唯一一个特征函数，且第 $n$ 个特征函数在区间内部恰有 $n-1$ 个零点。**

还有两条更深的性质，正是下一课的地基：

1. **正交性**：不同编号的特征函数"互相垂直"，即 $\int_0^L X_m X_n\,dx=0$（$m\neq n$）。这也是第 16 章傅里叶正交性的同一个故事换个场景。
2. **完备性**：任何合理的初始形状 $f(x)$ 都能写成这些特征函数的加权和 $f=\sum b_nX_n$。

正交性给出"怎么求系数"，完备性保证"一定能表示出来"。两者合起来，就是把上一课那一族孤立的模态，变成一套能对付任意初值的通用工具。

</details>
