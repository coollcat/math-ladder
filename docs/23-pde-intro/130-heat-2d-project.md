# 二维热扩散项目：涂一笔，看它自己摊开

## 1. 从一个场景开始

一滴墨水滴进一碗清水。它不是沿着一条线散开的——它向四面八方同时摊开，边缘越来越模糊，颜色越来越淡，直到整碗水变成均匀的一层浅灰。

第 50 课与 55 课在一根杆上把显式格式和稳定线讲透了。这一课把战场升到二维：网格变成方阵，每个格子有四个邻居，稳定线也因此收紧了一半。这是一节项目课——把前面所有零件（差分模板、稳定线、绝热与冷墙边界、均值性质）装到同一台机器上，亲手跑一遍。

## 2. 直觉解释

一维时，一个格点只跟左右两个邻居做买卖；二维时它有四个。买卖对象翻倍，意味着同样的时间步里，中心格要吐出（或吞进）两倍于前的差额——**步子迈得稍大一点，就会补偿过头**。

超调的后果很有画面感：中心格被四个邻居"抽干"之后反而比它们更冷，下一步邻居又被它抽回去……于是黑白相间地交替闪烁，数值迅速冲上天。这种"棋盘震荡"是二维显式格式送给每个初学者的见面礼。

安全线的数值从一维的 $\frac12$ 收紧到二维的 $\frac14$，规律是：

$$\text{一维（2 个邻居）}: r\le\tfrac12, \qquad \text{二维（4 个邻居）}: r\le\tfrac14, \qquad \text{三维（6 个邻居）}: r\le\tfrac16.$$

## 3. 正式定义

二维热方程 $u_t=k(u_{xx}+u_{yy})$ 在步长 $h$ 的方阵上，显式（向前欧拉）格式为

$$u^{n+1}_{i,j}=u^{n}_{i,j}+r\left(u^{n}_{i-1,j}+u^{n}_{i+1,j}+u^{n}_{i,j-1}+u^{n}_{i,j+1}-4u^{n}_{i,j}\right), \qquad r=\frac{k\,\Delta t}{h^{2}}.$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $r$ | 差分比 | 一步之内热量扩散的相对强度，唯一决定稳定性的量 |
| $4u_{i,j}$ | 中心自减项 | 四个邻居各拿走一份，中心共吐出四份 |
| $1/4$ | 稳定上限 | $r$ 超过它就出现棋盘震荡（选读给出推导） |
| 冷墙 / 绝热 | 两类边界 | 冷墙把边界钉在 0（热量外泄），绝热抄内侧一格（热量守恒） |

边界处理两行代码就够：冷墙是"边界格恒等于 0"，绝热是"边界格复制内侧一格的值"。

## 4. 分步例题

**例 1**：体检两个候选时间步。取 $k=0.5$、$h=0.1$。

1. $\Delta t_1=0.02$：$r_1=\dfrac{0.5\times0.02}{0.1^2}=1.0$，远超 $\frac14$ → 不可用；
2. $\Delta t_2=0.006$：$r_2=\dfrac{0.5\times0.006}{0.1^2}=0.3$，**仍然超过 $\frac14$** → 也不可用；
3. 想要安全，$\Delta t\le\dfrac{0.25\,h^2}{k}=\dfrac{0.25\times0.01}{0.5}=0.005$；
4. 教训：二维的安全线比一维苛刻一倍，凭一维的直觉选 $\Delta t$ 会踩雷。

**例 2**：用安全的 $r=0.2$ 更新一个内点。中心 $0.8$，四邻都是 $0.4$。

1. 四邻之和 $1.6$，中心四倍 $3.2$，差额 $-1.6$；
2. $u_{\text{新}}=0.8+0.2\times(-1.6)=0.8-0.32=0.48$；
3. 新值 $0.48$ 落在四邻（$0.4$）与中心（$0.8$）之间——**安全格式绝不会越过邻居的范围**，这正是"没有惊喜"的数值体现。

### 实验 1：在网格上涂一笔

### 实验 2：把 r 推过 0.25，看它炸开

```python title="同一份初始温度，两种 r 的三十步对照"
N = 7

def step(v, r):                               # 做一次二维显式推进
    new = [row[:] for row in v]               # 整表复制：新值必须基于同一批旧值
    for j in range(1, N - 1):
        for i in range(1, N - 1):
            nb = v[j - 1][i] + v[j + 1][i] + v[j][i - 1] + v[j][i + 1]
            new[j][i] = v[j][i] + r * (nb - 4 * v[j][i])
    for i in range(1, N - 1):                 # 上下绝热：边界行抄内侧一行
        new[0][i] = new[1][i]
        new[N - 1][i] = new[N - 2][i]
    return new

for r in [0.2, 0.3]:                          # 一个在线内，一个在线外
    v = [[0.0] * N for _ in range(N)]         # 列表推导：造一张全零表格
    for j in range(N):
        v[j][0] = 1.0                         # 左边界 = 1
        v[j][N - 1] = 0.0                     # 右边界 = 0
    v[3][3] = 2.0                             # 中心放一个尖峰，最容易诱发抖动
    for _ in range(30):                       # 下划线变量名：计数用不到，只是占位
        v = step(v, r)
    print(r, round(max(max(row) for row in v), 3), round(min(min(row) for row in v), 4))
```

输出 `0.2 1.0 0.0` 与 `0.3 72.216 -61.843`。安全那一档跑完仍严格待在 0 与 1 之间；超线那一档三十步就冲到了 ±70，负值温度在物理上根本不存在——**它炸了**。

### 实验 3：均值性质是一条越收越紧的绳

```python title="中心点与四邻平均的差距随步数收敛"
N = 7
v = [[0.0] * N for _ in range(N)]
for j in range(N):
    v[j][0] = 1.0
    v[j][N - 1] = 0.0
v[3][3] = 2.0                                 # 中心尖峰

def step(v, r):
    new = [row[:] for row in v]
    for j in range(1, N - 1):
        for i in range(1, N - 1):
            nb = v[j - 1][i] + v[j + 1][i] + v[j][i - 1] + v[j][i + 1]
            new[j][i] = v[j][i] + r * (nb - 4 * v[j][i])
    for i in range(1, N - 1):
        new[0][i] = new[1][i]
        new[N - 1][i] = new[N - 2][i]
    return new

for s in range(1, 61):                        # 推进六十步
    v = step(v, 0.2)
    if s in (1, 5, 20, 60):                   # in 判断成员资格：只看这四个时刻
        nb = v[2][3] + v[4][3] + v[3][2] + v[3][4]
        print(s, round(v[3][3], 4), round(abs(v[3][3] - nb / 4), 4))
```

输出 `1 0.4 0.0`、`5 0.1834 0.0086`、`20 0.3377 0.0108`、`60 0.4821 0.0012`。第二列是中心温度（一路回升，趋向稳态的 0.5），第三列是"中心 − 四邻平均"的差距——它稳定地缩小。**上一课的均值性质在这里是动态版本**：扩散的每一小步都在把差距往零拉。

# @check: 1.0

# @check: 0.3
# @check: False

h = 0.1           # 网格步长

dt2 = 0.006

修正版：

```python
k = 0.5
h = 0.1

dt1 = 0.02
dt2 = 0.006
r1 = k * dt1 / (h * h)
r2 = k * dt2 / (h * h)

limit = 0.25
print(round(r1, 3))      # 1.0
print(r1 <= limit)       # False
print(round(r2, 3))      # 0.3
print(r2 <= limit)       # False

r = 0.2
u_center = 0.8
nb = [0.4, 0.4, 0.4, 0.4]
u_new = u_center + r * (nb[0] + nb[1] + nb[2] + nb[3] - 4 * u_center)
print(round(u_new, 3))   # 0.48
```

```text
r₁ = 0.5 × 0.02 / 0.01 = 1.0   → 远超 0.25
r₂ = 0.5 × 0.006 / 0.01 = 0.3  → 仍超 0.25（这是最容易看走眼的一档）
安全 dt ≤ 0.25 × 0.01 / 0.5 = 0.005
更新 = 0.8 + 0.2 × (1.6 − 3.2) = 0.48
```

$r_2=0.3$ 是本题的陷阱：它小于一维的 0.5，看起来"挺安全"，可在二维已经越线。改用安全档后，新值 0.48 落在四邻与中心之间，没有越过任何邻居——安全格式的这个"不越界"性质，是判断代码对错最便宜的哨卡。

</details>

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为一维的稳定线 $\frac12$ 可以照搬到二维。邻居从 2 个变成 4 个，安全线从 $\frac12$ 收紧到 $\frac14$；三维再收到 $\frac16$。记住通式 $r\le\frac{1}{2d}$（$d$ 是维数）。

**误区二**：你以为"数值炸了"是舍入误差。它是格式本身的不稳定：每一步的误差被放大 $|G|>1$ 倍，几十步就能放大上万倍。减小的 $\Delta t$ 是唯一出路，加密网格反而会让允许的 $\Delta t$ 按平方缩小。

**误区三**：你以为绝热边界就是"不更新边界格"。正确做法是每步把边界格更新成内侧一格的值（零通量）。直接不动边界格等于在那里放了一圈固定温度的冷源，总热量会悄悄漏掉。

:::

## 9. 选读：1/4 是怎么算出来的

<details>
<summary>选读 · von Neumann 稳定性分析三步走</summary>

把数值解看成一列 Fourier 模式的叠加，只需考察单个模式 $u^n_{i,j}=G^n e^{\mathrm{i}(k_xi+k_yj)h}$ 的放大因子 $G$。

1. **代入格式**。四个邻居分别贡献 $e^{\pm \mathrm{i}k_xh}$、$e^{\pm \mathrm{i}k_yh}$，于是
$$G = 1+r\left(e^{\mathrm{i}k_xh}+e^{-\mathrm{i}k_xh}+e^{\mathrm{i}k_yh}+e^{-\mathrm{i}k_yh}-4\right) = 1+2r\left(\cos k_xh+\cos k_yh-2\right).$$

2. **化简**。用 $\cos\theta-1=-2\sin^2\frac{\theta}{2}$：
$$G = 1-4r\left(\sin^2\frac{k_xh}{2}+\sin^2\frac{k_yh}{2}\right).$$

3. **要求 $|G|\le1$**。括号的最大值出现在两个正弦都取 $\pm1$ 时（即网格能分辨的最高频率，$k_xh=k_yh=\pi$），此时 $G=1-8r$。条件 $|1-8r|\le1$ 给出 $0\le r\le\frac14$。

那个把 $G$ 推到最负的模式正是**棋盘模式**（相邻格一正一负交替），所以不稳定最先以黑白闪烁的形式现身——现象与推导完全对上。一维同样算一遍得到 $G=1-4r\sin^2\frac{kh}{2}$，上限 $\frac12$；三维得到 $\frac16$。

</details>
