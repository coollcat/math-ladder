# PDE 分类与方法地图

## 1. 从一个场景开始

你已经在三条完全不同的路上各走过一遭：第 70 课的弦在振动（信息沿着两条斜线跑）、第 40 课的热量在摊开（信息像墨汁一样瞬间渗透）、上一课的稳态铁板（根本不存在"传播"这回事，边界一动全场立刻响应）。

三条路的求解工具也完全不同：波动用特征线，扩散用分离变量，稳态用松弛迭代。这不是巧合——**方程的类别决定了它的脾气，也决定了该用哪把钥匙**。这一课把分类的判据和工具箱一起交给你。

## 2. 直觉解释

二阶 PDE 的分类，本质是在问一个几何问题：**扰动沿着哪些方向传播？**

- 椭圆型：没有传播方向。全场互相牵制，任何一处改动立刻反映到所有地方（像拉紧的膜）。
- 抛物型：只剩一个传播方向，而且单向——时间只往前走，不能倒带（像墨汁扩散）。
- 双曲型：有两条实实在在的传播路径，扰动以有限速度沿它们跑（像水波）。

判别式 $b^2-4ac$ 就是在数"有几条实的传播方向"：正数两条（双曲），零一条退化（抛物），负数一条都没有（椭圆）。这和二次曲线 $ax^2+bxy+cy^2=1$ 用同一个判别式分出双曲线、抛物线、椭圆，是同一件事的两次现身。

## 3. 正式定义

常系数二阶线性 PDE（两个自变量 $x$、$y$）写作

$$a\,u_{xx}+b\,u_{xy}+c\,u_{yy}+d\,u_x+e\,u_y+f\,u=g,$$

只看最高阶的系数三元组 $(a,b,c)$，判别式与类别：

| 判别式 $\Delta=b^2-4ac$ | 类型 | 代表方程 | 信息传播 | 定解条件的正确搭配 |
| --- | --- | --- | --- | --- |
| $\Delta>0$ | 双曲型 | $u_{tt}=c^2u_{xx}$ | 沿两条实特征线，有限速度 | 初值 + 初速度（两端不固定） |
| $\Delta=0$ | 抛物型 | $u_t=ku_{xx}$ | 单方向、不可倒带 | 初值 + 边界（时间只给一层） |
| $\Delta<0$ | 椭圆型 | $u_{xx}+u_{yy}=0$ | 无传播方向，全局耦合 | 只给边界（闭合一圈） |

双曲型的两条特征线由 $a(dy)^2-b(dx)(dy)+c(dx)^2=0$ 定出，斜率为

$$\frac{dy}{dx}=\frac{b\pm\sqrt{b^2-4ac}}{2a}.$$

一阶方程（如第 60 课的对流方程 $u_t+au_x=0$）不在二阶分类之内，它自有一条实特征线，用特征线法直接解。

## 4. 分步例题

**例 1**：给三个方程定性。

1. 波动方程写成 $u_{tt}-u_{xx}=0$，按 $(a,b,c)=(-1,0,1)$ 得 $\Delta=0-4(-1)(1)=4>0$ → 双曲；
2. 热方程写成 $u_t-u_{xx}=0$，$(a,b,c)=(-1,0,0)$ 得 $\Delta=0$ → 抛物；
3. Laplace 方程 $u_{xx}+u_{yy}=0$，$(a,b,c)=(1,0,1)$ 得 $\Delta=-4<0$ → 椭圆。

**例 2**：带混合导数的两个例子。

1. $u_{xx}+4u_{xy}+u_{yy}=0$：$\Delta=16-4=12>0$ → 双曲，两条特征线斜率 $\frac{4\pm\sqrt{12}}{2}=2\pm\sqrt3$；
2. $u_{xx}-2u_{xy}+u_{yy}=0$：$\Delta=4-4=0$ → 抛物，两条特征线合并成一条（斜率 $-1$）。

混合导数项 $u_{xy}$ 的存在，正是"坐标轴被拧歪了"的信号；分类判别式对你选的坐标系免疫。

## 5. 动手实验

### 实验 1：拖动 a、b、c，看判别式把平面分成三家

```viz
{

  "title": "PDE 分类：拖动系数，看点落在判别式的哪一侧",
  "a": 1,
  "b": 0,
  "c": -1
}
```

紫色虚线是 $b^2-4ac=0$ 的分界。点落在它两侧分别是双曲（波动）与椭圆（稳态），正好压在线上就是抛物（扩散）。三个按钮一键跳到三类代表方程；切到双曲时画布底部会读出两条特征线的斜率。

### 实验 2：给一张方程表自动定性

```python title="判别式分类器：批量定性并打印"
def classify(a, b, c):                        # a、b、c 是 u_xx、u_xy、u_yy 的系数
    disc = b * b - 4 * a * c                  # 判别式，只看最高阶项
    if disc > 0.05:
        return '双曲型'
    if disc < -0.05:
        return '椭圆型'
    return '抛物型'                            # 留一点容差，避开浮点毛刺

cases = [
    ('波动 u_tt - u_xx = 0', -1, 0, 1),
    ('热传导 u_t - u_xx = 0', -1, 0, 0),
    ('Laplace u_xx + u_yy = 0', 1, 0, 1),
    ('强混合 u_xx + 4u_xy + u_yy = 0', 1, 4, 1),
    ('退化   u_xx - 2u_xy + u_yy = 0', 1, -2, 1),
]
for name, a, b, c in cases:                   # 解包：一次取出名字与三个系数
    print(name, b * b - 4 * a * c, classify(a, b, c))
```

输出五行，判别式分别是 `4`、`0`、`-4`、`12`、`0`，对应双曲、抛物、椭圆、双曲、抛物。最后一行是重点：$u_{xx}-2u_{xy}+u_{yy}=0$ 判别式为零，两条特征线合并——它不是"没有特征线"，而是两条退化成一条。

### 实验 3：三类方程的信息传播体检

```python title="同一时刻，看扰动传到了多远"
import math

c = 1.0          # 波速
k = 0.1          # 热扩散率
t = 1.0          # 观察时刻

def wave(x):                                  # 右行波：初始的高斯包，中心在 0
    xi = x - c * t                            # 特征线坐标：只有它落在包内才非零
    return math.exp(-xi * xi / 0.02)

def heat(x):                                  # 热核：点源摊开后的温度分布
    return math.exp(-x * x / (4 * k * t)) / (2 * math.sqrt(math.pi * k * t))

for x in [0.0, 0.5, 1.0, 2.0]:
    print(x, round(wave(x), 8), round(heat(x), 8))
```

四行是 `0.0 0.0 0.89206206`、`0.5 0.00000373 0.47748641`、`1.0 1.0 0.07322491`、`2.0 0.0 0.00004050`——中间一列是波、右边一列是热。

读法：波在 $x=ct=1$ 处出现峰值 1.0，两侧按 $e^{-(x-ct)^2/0.02}$ 骤降，到 $x=2$ 已经是 $10^{-22}$ 量级（输出里的 `0.0`）；热那一列处处严格非零，从 0.89 一路衰减到百万分之四十。**双曲方程有清晰的波前，抛物方程只有指数小的尾巴**——这一区别决定了波动能画波前、扩散只能画等值线。

## 6. 练习

```exercise
# @title: 练习：给三个方程做分类体检
# @check: 双曲型
# @check: 抛物型
# @check: 椭圆型
# @hint: Δ = b² − 4ac。Δ > 0 是双曲（两条特征线），Δ = 0 是抛物，Δ < 0 是椭圆（没有实特征线）。
def classify(a, b, c):
    disc = b * b - 4 * a * c
    if disc > 0.05:
        return '椭圆型'      # ← 有错：Δ>0 应是双曲型，这里判反了
    if disc < -0.05:
        return '双曲型'      # ← 有错：Δ<0 应是椭圆型，同样判反了
    return '抛物型'

print(classify(-4, 0, 1))   # u_tt - 4u_xx = 0
print(classify(-3, 0, 0))   # u_t - 3u_xx = 0
print(classify(1, 0, 1))    # u_xx + u_yy = 0
```

```python
def classify(a, b, c):
```

```text
u_t  − 3u_xx = 0：a=−3, b=0, c=0 → Δ = 0 → 抛物型
u_xx + u_yy  = 0：a=1,  b=0, c=1 → Δ = 0 − 4 = −4 < 0 → 椭圆型
```

注意第一个方程的特征线斜率是 $\frac{0\pm4}{2(-4)}=\mp\frac12$，也就是 $t=\mp\frac{x}{2}$ 两条——波速是 2，与方程里那个 4（$=c^2$）对得上。

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为"抛物型"意味着有抛物线形的解。名字来自判别式与二次曲线的类比（$\Delta=0$ 对应抛物线），跟解的几何形状无关。

**误区二**：你以为热方程的传播速度有限。数学上它处处非零（无限传播），只是按指数衰减到可以忽略。模拟里看到的"波前"是数值精度的产物，不是物理定律。

**误区三**：你以为分类看的是整个方程。分类只看最高阶项的三个系数；一阶项、零阶项和右端项都不参与判别式，它们只影响解的细节，不改变方程的脾气。

:::

```quiz
- 椭圆型，零条
? Δ>0 时根号下为正，特征线斜率给出两条不同的实线，扰动沿它们以有限速度传播，典型代表是波动方程。
```

```quiz
椭圆型方程（比如 Laplace 方程）的定解条件该怎么给？

- 给初始值加初始速度
```

| 方法 | 适用锁型 | 本章出场 | 关键代价 |
| --- | --- | --- | --- |
| **特征线法** | 一阶方程、双曲型 | 60 对流、65 激波、75 达朗贝尔 | 特征线相交后失效（激波），需要额外的熵条件 |

| **有限差分** | 通用兜底 | 50 / 55 / 130 | 稳定性约束（$r\le 1/(2d)$），精度与网格代价 |
| **松弛迭代** | 椭圆型稳态 | 120 | 收敛慢（信息每轮只传一格），需超松弛或多重网格 |

选钥匙的顺序建议：**先看方程类别**（判别式）→ **再看区域几何**（规则域优先解析法）→ **最后看是否需要数值兜底**（几乎总要）。

还有一条跨章的经验：**先算解析特例，再上数值**。本章每一课都是先用解析解定标（特征值、热核、达朗贝尔），再用数值实验探索——没有解析解当尺子，数值结果的对错无从判断。
