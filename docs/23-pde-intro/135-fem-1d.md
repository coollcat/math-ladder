# 有限元入门：把连续切成小段再拼起来

## 1. 从一个场景开始

一根变截面的钢梁，中段还焊着两块加强板。你想知道它在自重下弯多少。方程还是那个方程，可截面系数 $p(x)$ 一段一段地跳，解析解写不出来。

第 50 课教过你差分：在网格点上用差商替导数。那办法能用，但遇到"材料在某处突然换掉"就头疼——差商要跨过界面取样，界面两侧的系数一平均，精度立刻掉档。

工程界换了个思路：**别急着在点上逼近导数，先把整根梁切成几十个小段，每段内部都当最简单的等截面杆处理，最后把所有小段"拼"回一根。** 这就是有限元（finite element method，FEM）。

## 2. 直觉解释

想象软绳上立着一串"帐篷"。在节点 $x_j$ 上方撑一顶高度为 1 的小帐篷 $\varphi_j$：它在自己节点顶着尖，在左右邻居处塌到 0，再远就是平的 0。任何分段线性的近似解都写成这些帐篷的线性组合

$$u_h = u_1\varphi_1 + u_2\varphi_2 + \cdots + u_n\varphi_n,$$

系数 $u_j$ 恰好就是解在节点上的高度。

```text
φ_j:          /\
             /  \            在 x_j 处 = 1
     \____  /    \  ____/    在 x_{j±1} 处 = 0
                               其余地方 = 0
```

帐篷的两片斜坡只在相邻两段里非零，所以每个节点只跟左右邻居发生关系——**这就是"局部"的来源**，也是刚度矩阵稀疏、能对付上百万个节点的原因。

## 3. 正式定义

考虑一维边值问题（热传导或杆的拉伸）：

$$-\,(p(x)\,u')' + q(x)\,u = f(x),\qquad u(0)=u(L)=0 .$$

$p$ 是传导系数（或截面刚度），$q$ 是散热项，$f$ 是外加热源（或外载）。

**第一步：弱形式。** 两边乘一个测试函数 $v$（同样要求 $v(0)=v(L)=0$），在 $[0,L]$ 上积分，再对第一项分部积分降一阶：

$$\int_0^L p\,u'v'\,dx + \int_0^L q\,u v\,dx = \int_0^L f v\,dx .$$

分部积分把 $u''$ 降成 $u'$，代价是搬出一个边界项 $[-p u' v]_0^L$；而 $v$ 在两个端点都为零，边界项自动消失。

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $u_h$ | 有限元解 | 分段线性的近似解，$u_h=\sum_j u_j\varphi_j$ |
| $\varphi_j$ | 帽子基函数 | 节点 $x_j$ 处那顶帐篷，满足 $\varphi_j(x_i)=\delta_{ij}$ |
| $v$ | 测试函数 | 用来"投影"方程的任意函数，本课取同一批 $\varphi_i$ |
| $K_{ij}$ | 刚度矩阵 | $K_{ij}=\int\big(p\varphi_i'\varphi_j'+q\varphi_i\varphi_j\big)\,dx$ |
| $F_i$ | 载荷向量 | $F_i=\int f\varphi_i\,dx$ |

**第二步：**把 $u_h$ 代入弱形式、并依次取 $v=\varphi_i\ (i=1,\dots,n)$，得到线性方程组

$$K\,u = F .$$

**第三步：组装。** 只在单个单元 $[x_e,x_{e+1}]$ 上积出它的 $2\times2$ 小矩阵，再把相邻单元在共享节点上的贡献**相加**。等截面、单元长 $h$ 的单元刚度矩阵是

$$K^{(e)}=\frac{p}{h}\begin{bmatrix}1&-1\\-1&1\end{bmatrix}.$$

它的每行和都是 0——这是"常数函数不产生能量"的代数影子，对应结构的刚性位移模式。

## 4. 分步例题

取 $p=1$、$q=0$、$f=1$，区间 $[0,2]$，两端固定 $u(0)=u(2)=0$，分成 2 个单元、3 个节点（$h=1$）。精确解为 $u(x)=\dfrac{x(2-x)}{2}$，在 $x=1$ 处 $u=0.5$。

1. **算单元矩阵**：两个单元完全相同，都是 $K^{(e)}=\begin{bmatrix}1&-1\\-1&1\end{bmatrix}$。
2. **组装成全局矩阵**（$3\times3$，节点 1 被两个单元踩到，贡献相加）：

$$K=\begin{bmatrix}1&-1&0\\-1&2&-1\\0&-1&1\end{bmatrix}.$$

3. **组装载荷**：单元载荷为 $\int f\varphi\,dx=\dfrac{fh}{2}[1,1]=[0.5,0.5]$；节点 1 收下左右各 0.5，故 $F=[0.5,\,1.0,\,0.5]$。
4. **施加边界**：$u_0=u_2=0$ 已知，删掉第 1、3 行与列，只剩中间一个方程

$$K_{11}u_1=F_1 \;\Longrightarrow\; 2u_1=1.0 \;\Longrightarrow\; u_1=0.5 .$$

5. **对答案**：$u_1=0.5$ 与精确解 $u(1)=0.5$ 一致。这一次节点值精确命中——但别高兴太早，节点之间的直线上近似解仍有偏差（误差阶见选读）。

### 实验 1（viz）：折线就是有限元解


每个紫点是一个节点，橙色折线就是几顶"帐篷"叠出来的近似解。两端被钉在 0（这就是 $u(0)=u(L)=0$）；把中间某点往上拖，等于给那个节点的系数 $u_j$ 加码。按播放：热扩散会把折角慢慢磨圆——真实解永远比折线更光滑。

### 实验 2（python）：画出几顶帐篷

```python title="帽子基函数 φ₀…φ₃ 长什么样"
import matplotlib.pyplot as plt   # 首次出现：约定短名 plt，后面都用它画图

def hat(j, xs, h):                # 在节点 j 处立一顶帐篷，返回它在各个 x 处的高度
    ys = []
    for x in xs:
        d = abs(x - j * h)        # abs：到本节点中心的横向距离（恒非负）
        ys.append(max(0.0, 1.0 - d / h))   # 离中心超过一个单元就塌回 0
    return ys

h = 1.0                           # 单元长度
xs = [i * 0.01 for i in range(301)]   # 在 0 到 3 之间铺 301 个采样点

fig, ax = plt.subplots(figsize=(7, 2.4))   # figsize：画布尺寸（英寸）
for j in [0, 1, 2, 3]:
    ax.plot(xs, hat(j, xs, h), label="φ" + str(j))   # 一条曲线 = 一顶帐篷
ax.legend()                       # 显示图例，区分四条曲线
ax.set_title("帽子基函数：每顶只在自己节点立起来")
plt.show()                        # 弹出画布
```

四顶帐篷并排站着，各自在自己节点高 1、在邻居节点为 0。相邻两顶只在共同的那一小段里同时非零——所以组装时只有"邻居"需要相加。

### 实验 3（python）：组装两个单元并求解

```python title="手工组装刚度矩阵，解出节点值"
p = 1.0                 # 传导系数
h = 1.0                 # 单元长度
f = 1.0                 # 均布载荷
n = 3                   # 节点数

K = [[0.0] * n for _ in range(n)]   # 列表推导：造一张 n×n 的全零表
for e in range(n - 1):              # e 是单元编号，单元盖住节点 e 与 e+1
    local = [[p / h, -p / h], [-p / h, p / h]]   # 这个单元的 2×2 刚度矩阵
    for i in range(2):
        for j in range(2):
            K[e + i][e + j] += local[i][j]   # += 把共享节点上的贡献累加

F = [0.0] * n
for e in range(n - 1):              # 单元载荷 f*h/2 平分给两端节点
    F[e] += f * h / 2
    F[e + 1] += f * h / 2

u1 = F[1] / K[1][1]                 # 两端固定，只剩中间节点 1 一个未知量
print("K=" + str(K))
print("F=" + str(F))
print("u1=" + str(u1))
```

输出 `K=[[1.0, -1.0, 0.0], [-1.0, 2.0, -1.0], [0.0, -1.0, 1.0]]`、`F=[0.5, 1.0, 0.5]`、`u1=0.5`。注意 $K_{11}=2$ 而不是 1——节点 1 被左右两个单元各贡献了一次，这正是"组装"里最容易被漏掉的一步。

## 6. 练习

```exercise
# @title: 练习：四个节点，组装并解出中间两个值
# @check: K=[[1.0, -1.0, 0.0, 0.0], [-1.0, 2.0, -1.0, 0.0], [0.0, -1.0, 2.0, -1.0], [0.0, 0.0, -1.0, 1.0]]
# @check: F=[0.5, 1.0, 1.0, 0.5]
# @check: u=[1.0, 1.0]
# @hint: 单元刚度矩阵是 [[1, -1], [-1, 1]]——第二行与第一行只差一个符号。写成同号会让矩阵失去对称性，解出来的位移正负打架。
n = 4                 # 节点数
h = 1.0               # 单元长度
f = 1.0               # 均布载荷

def elem_stiffness():
    # 一个单元的 2×2 刚度矩阵：对角为 1、非对角为 -1
    return [[1.0, -1.0],
            [1.0, -1.0]]      # ← 有错：第二行的符号应该相反

K = [[0.0] * n for _ in range(n)]
for e in range(n - 1):
    Ke = elem_stiffness()
    for i in range(2):
        for j in range(2):
            K[e + i][e + j] += Ke[i][j]   # 共享节点处累加

F = [0.0] * n
for e in range(n - 1):
    F[e] += f * h / 2
    F[e + 1] += f * h / 2

# 两端固定，解中间两个节点（下标 1、2）的 2×2 小系统
a11, a12 = K[1][1], K[1][2]
a21, a22 = K[2][1], K[2][2]
b1, b2 = F[1], F[2]
det = a11 * a22 - a12 * a21
u1 = (b1 * a22 - a12 * b2) / det      # 克莱姆法则，先算第一行
u2 = (a11 * b2 - b1 * a21) / det

print("K=" + str(K))
print("F=" + str(F))
print("u=[" + str(u1) + ", " + str(u2) + "]")
```

<summary>点开查看逐步解答</summary>

修正版只改一行：

```python
def elem_stiffness():
    return [[1.0, -1.0],
            [-1.0, 1.0]]
```

四个节点的编号是 0、1、2、3。单元 0 盖住 0–1，单元 1 盖住 1–2，单元 2 盖住 2–3：

- 对角项：节点 1、2 各被两个单元踩到，$1+1=2$；端点节点只被一个单元踩到，仍是 1；
- 载荷：每个单元 $fh/2=0.5$ 平分给两端，中间节点各收 $0.5+0.5=1.0$。

于是中间的 $2\times2$ 块是 $\begin{bmatrix}2&-1\\-1&2\end{bmatrix}$，右端为 $[1,1]$，解得 $u_1=u_2=1.0$。核对精确解 $u(x)=\dfrac{x(3-x)}{2}$：$u(1)=1$、$u(2)=1$，节点值再次精确命中。

若把单元矩阵写成同号，$K$ 不再对称，$u_2$ 会翻成 $-1.0$——位移正负打架，就是最直白的报警。

</details>

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为有限元只是差分方程的另一种写法。差分在网格点上逼近**强形式**（直接处理 $u''$），遇到材料界面要跨界面取样；有限元在积分（弱）形式上工作，只需在每个单元内部积分，材料突变天然被逐单元吸收。

**误区二**：你以为每个单元"各算各的"就行。共享节点的刚度必须**相加**。漏加等于那里没焊上——物理上成了两根悬空的短杆，矩阵也不再对称。

**误区三**：你以为节点越多越准、随便加密就好。线性单元在单元内部只有一次精度，整体误差按 $O(h^2)$ 缩小（选读里推导）；想要更高的收敛率，得提高单元阶数（二次单元），或者在解变化剧烈的地方局部加密。

:::

## 9. 选读：单元矩阵与误差阶

<details>
<summary>选读 · 从单元刚度矩阵到 O(h²) 收敛</summary>

**单元刚度矩阵怎么来的。** 长为 $h$ 的单元上，两顶帐篷是 $N_1(x)=1-\dfrac{x-x_e}{h}$、$N_2(x)=\dfrac{x-x_e}{h}$，它们的导数分别是常数 $-\dfrac{1}{h}$ 与 $\dfrac{1}{h}$。于是

$$K^{(e)}_{ij}=\int_{x_e}^{x_e+h} p\,N_i'N_j'\,dx=\frac{p}{h}\begin{bmatrix}1&-1\\-1&1\end{bmatrix}.$$

$p$ 为常数时积分只是乘上长度 $h$，这就是它形状如此干净的原因。

**误差阶。** 在单元 $[x_e,x_{e+1}]$ 上，分段线性插值 $u_h$ 与真解 $u$ 之差满足

$$|u(x)-u_h(x)|\le \frac{h^2}{8}\max|u''| .$$

$\dfrac{h^2}{8}$ 是线性插值误差的标准界：把每段单独估计、再取最大即可。把各段的平方误差加起来，整体 $L^2$ 误差就随 $h^2$ 一起缩到零。

**所以加密网格确实有效，但只用线性单元的话，把 $h$ 减半误差才降到四分之一**；要夺回更高的收敛率，就得请出二次、三次单元——那正是工程软件里"单元阶数"下拉框背后的全部代价。

</details>
