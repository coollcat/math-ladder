# 达朗贝尔解与初始形状

## 1. 从一个场景开始

琴师知道两件事：拨弦后弦的**初始形状**，以及松手瞬间每一点是否带有**初速度**。这两条定下后，弦此后一生的舞姿就完全确定了。达朗贝尔公式把"确定"写成一个不需要任何级数的闭式：想知道任意时刻的形状？回到初始时刻去"搬"数据就行。

## 2. 直觉解释

70 课说通解是右行波 $F$ 加左行波 $G$。现在反过来问：初始形状 $f$ 和初速度 $g$ 怎么分配给这两列波？

答案出奇地公平：

- 初始位移 $f$ 被**对半分**给左右两列波，各拿一半往相反方向跑；
- 初速度 $g$ 的贡献要在区间 $[x-at,\ x+at]$ 上**积分**——因为速度累积出来的位移要靠"扫过面积"来记账。

于是想知道 $u(x,t)$，只需回到 $t=0$，找出两个"影子位置" $x\pm at$ 处的初始位移，再补上初速度在两影子之间扫出的面积。

## 3. 正式定义

达朗贝尔公式（1747 年）：

$$u(x,t)=\frac{f(x-at)+f(x+at)}{2}+\frac{1}{2a}\int_{x-at}^{x+at}g(s)\,ds.$$

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $f$ | 初始位移 | $u(x,0)$，松手瞬间的形状 |
| $g$ | 初速度 | $u_t(x,0)$，每一点的初始速度 |
| $x\pm at$ | 影子位置 | 沿左右特征线回到 $t=0$ 的落脚点 |
| $\frac{1}{2a}\int g$ | 速度面积项 | 初速度在两影子间累积的位移 |

两条特征线 $x-at=$ 常数与 $x+at=$ 常数就是搬运工：把初始数据原封不动送到 $(x,t)$。

## 4. 分步例题

**例 1**：$f(x)=x^2$，$g=0$，$a=1$，求 $u(2,1)$。

1. 左影子 $x-at=2-1=1$，右影子 $x+at=2+1=3$；
2. 位移项 $\frac{f(1)+f(3)}{2}=\frac{1+9}{2}=5$；
3. $g=0$，积分项为零；
4. 所以 $u(2,1)=5$。

**例 2**：$f(x)=\sin x$，$g=0$，$a=1$。

1. $u=\frac{\sin(x-t)+\sin(x+t)}{2}$；
2. 用和差化积：$\sin A+\sin B=2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$；
3. 得 $u=\sin x\cos t$：各点只在自己的位置上下振动——这是**驻波**，形状不再左右奔跑。

对比 60 课的对流解：那里初值整体搬运、永不变形；这里两列半幅波错开跑动，叠加出"原地踏步"的新形态。

### 实验 2：初速度贡献的面积账

```python title="g=1 时初速度扫出的位移"
a = 1.0        # 波速
x = 2.0        # 观察点
t = 1.5        # 时刻

# 积分区间 [x-a*t, x+a*t] 的长度：扫过的"底边"
width = (x + a * t) - (x - a * t)
# g 恒为 1 时面积就是底边乘高，再乘系数 1/(2a)
u_velocity = (1 / (2 * a)) * width * 1.0
print(round(width, 3))
print(round(u_velocity, 3))
```

输出 `3.0` 和 `1.5`。初速度处处为 1 时，位移恰好是 $t$：整条弦被匀速抬起，与扫过面积成正比。

### 实验 3：闭式解逐点核对

```python title="数值采样对照公式"
import math

a = 1.0        # 波速
x = 1.0        # 观察点
t = 0.7        # 时刻

def f(s):      # def 定义函数：给定 s 返回初始位移 sin(s)
    return math.sin(s)

# 达朗贝尔公式：g=0 时只剩对半分的位移项
u_formula = 0.5 * (f(x - a * t) + f(x + a * t))
u_standing = math.sin(x) * math.cos(t)   # 例 2 的驻波形式
diff = u_formula - u_standing
print(round(u_formula, 3))
print(round(u_standing, 3))
print(round(diff, 3) + 0.0)
```

输出 `0.565`、`0.565`、`0.0`。闭式搬运与驻波形式在每一点重合：两种写法是同一个解。

## 6. 练习

```exercise
# @title: 练习：把初始位移搬到时刻 t
# @check: 1.0
# @check: 3.0
# @check: 5.0
# @hint: 影子位置是 x-a*t 与 x+a*t；g=0 时没有面积项，u 是两个影子位移的平均。
a = 1.0        # 波速
x = 2.0        # 观察点
t = 1.0        # 时刻

s_l = x + a * t       # ← 有错一：左影子沿左特征线回溯，应是 x-a*t
s_r = x - a * t       # ← 有错二：右影子沿右特征线回溯，应是 x+a*t
print(round(s_l, 3))
print(round(s_r, 3))

f_l = s_l ** 2        # 初始形状 f(s)=s 的平方在左影子的取值
f_r = s_r ** 2
u = f_l + f_r         # ← 有错三：达朗贝尔公式取平均，别忘除以 2
print(round(u, 3))
```

<details>
<summary>点开查看逐步解答</summary>

修正后的搬运账本：

```python
a = 1.0
x = 2.0
t = 1.0

s_l = x - a * t
s_r = x + a * t
print(round(s_l, 3))     # 1.0
print(round(s_r, 3))     # 3.0

u = (s_l ** 2 + s_r ** 2) / 2
print(round(u, 3))       # 5.0
```

```text
s_l = 2 - 1 = 1.0,  f(s_l) = 1
s_r = 2 + 1 = 3.0,  f(s_r) = 9
u = (1 + 9) / 2 = 5.0
```

观察点 $(2,1)$ 的位移，正是初始时刻两个影子位移的平均值。

</details>

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为初始位移整份交给一列波。达朗贝尔把它对半分：左右两列各带一半形状出发。

**误区二**：你以为初速度不起作用。$g$ 贡献的面积项常常才是解的主角，$g=0$ 只是特例。

**误区三**：你以为闭式解和分离变量是两种答案。它们只是同一解的两种记账方式，逐点必相等。

:::

## 9. 选读：公式如何同时满足两个初始条件

<details>
<summary>选读 · 代入 t=0 验证</summary>

令 $t=0$：两个影子都回到 $x$，位移项给 $\frac{f(x)+f(x)}{2}=f(x)$，积分区间缩成一点、面积为零——第一条初始条件满足。再对 $t$ 求导后令 $t=0$：位移项的导数 $\frac{-af'(x)+af'(x)}{2}=0$，面积项由微积分基本给 $\frac{1}{2a}\cdot 2a\,g(x)=g(x)$——第二条也满足。特征线搬运自动配平了两份数据。

</details>
