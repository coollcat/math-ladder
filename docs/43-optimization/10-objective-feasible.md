# 目标函数与可行域

## 1. 从一个场景开始

你是快递站的站长，手里有两辆货车。多派一辆车要多花油钱，但送得快、客户评分高；少派车省钱，投诉却会涨。你想问的其实是一句话：**在"能做的选择"里，哪个选择最合算？**

优化就是把这句话翻译成数学语言：先把"合算"写成一个函数，再把"能做"画成一片区域。

## 2. 直觉解释

想象一张地形图：海拔是你的"不满意程度"，你想走到**最低的山谷**。但地图上有些区域是私人领地、湖泊、悬崖——你不能去。剩下的可走区域，就是你的活动范围。

于是整个问题只剩两句话：

- 海拔怎么算？——**目标函数**；
- 哪里能站？——**可行域**。

最优解不一定在海平面最低处（那是无约束的世界），而是**可走区域里的最低点**。它经常贴着边界站着——边界在提醒你："是限制在决定答案。"

## 3. 正式定义

**目标函数** $f$：把每个候选方案映射成一个数的规则，数越小越好（约定：本站统一求最小值；最大化问题乘个负号即可）。

**可行域** $\Omega$：所有满足约束条件的方案的集合。"在 $\Omega$ 里找 $f$ 的最小值"写作：

$$\min_{x \in \Omega} f(x), \qquad \text{约束记作 } g_i(x) \le 0$$

| 术语 | 含义 |
| --- | --- |
| 可行点 | 属于 $\Omega$ 的方案 |
| 全局最优 | 整个 $\Omega$ 上 $f$ 取最小值的可行点 |
| 局部最优 | 只在它的小邻域内是最小的可行点 |
| 无解 | $\Omega=\varnothing$，约束互相打架 |

一个关键事实：**无约束最优点不在 $\Omega$ 内时，约束最优解通常落在 $\Omega$ 的边界上**——直觉部分那句话的正式版本。

## 4. 分步例题

**例**：某站长要决定甲、乙两种货箱各装多少（记为 $x,y$），装载成本 $f(x,y)=(x-2.5)^2+(y-2.5)^2$（越接近理想配比 2.5、2.5 越便宜）。但场地限制两种箱子都不能超过 2：$\Omega=[0,2]\times[0,2]$。

1. 先不管约束：无约束最优点在 $(2.5, 2.5)$；
2. 检查可行性：$2.5 > 2$，出界了——这个便宜捡不到；
3. 直觉猜测：既然想去 $(2.5,2.5)$ 但被墙拦住，最优解应该**贴在离它最近的墙角** $(2,2)$；
4. 验证：对任意可行点 $(x,y)$，有 $x\le 2 < 2.5$，所以 $(x-2.5)^2 \ge (2-2.5)^2$，$y$ 同理；两式相加正好说明 $f(x,y)\ge f(2,2)$；
5. 结论：约束最优在边界角上取得，$f(2,2)=0.25+0.25=0.5$，比够不着的 $0$ 大——**限制是有代价的**。

### 实验 3：网格搜索——让计算机枚举可行点

```python title="在方形可行域上撒网格找最低点"
best_x, best_y = None, None   # None 表示"还没有值"，先占位
best_f = None

for i in range(41):                  # 0 到 40，共 41 个格点
    for j in range(41):
        x = i / 20                   # 步长 0.05，铺满 [0,2]（除法保证 2.0 精确）
        y = j / 20
        f = (x - 2.5) ** 2 + (y - 2.5) ** 2
        if best_f is None or f < best_f:   # 第一次总能进入；之后只保留更小的
            best_f = f
            best_x, best_y = x, y

print("最优点:", best_x, best_y)
print("最小值:", best_f)
```

输出是 `(2.0, 2.0)` 和 `0.5`——和手推一致。网格搜索笨但稳：只要可行域能撒点，它就能给出近似答案，代价是精度受步长限制。

### 快问快答

```quiz
如果目标函数的无约束最优点在可行域外面，正确的做法是？
- 直接宣布问题无解
- 在可行域内寻找使目标函数最小的可行点，它常在边界上 [*]
- 把约束条件删掉不要了
? 约束不是装饰品：删掉约束等于换了一道题。可行域外的谷底够不着时，最好的可行点往往贴着边界。
```

:::warning[常见误区]

**误区一**：你以为"最优 = 函数本身的最低点"。无约束最低点若不可行，答案就得换——约束优化的答案是**可行域内**的最小值点。

**误区二**：你以为约束越多越好/越少越好。约束只负责圈地：多了可能把好区域切走、甚至切到无可行解（$\Omega=\varnothing$）；少了问题反而变难，因为可选方案暴增。

**误区三**：你以为局部最优就是全局最优。在地形图上，一个小坑洼也能自称"附近最低"。两者何时等价，下一课的**凸性**会给出干净利落的判据。

:::

## 6. 练习

**练习 1**（概念）：把下面每句话归档为"改目标函数"还是"改可行域"：(a) 老板说投诉也要扣钱；(b) 仓库通知乙箱最多改存 3 个；(c) 油价涨了。

<details>
<summary>点开查看逐步解答</summary>

(a) 改目标函数——评价标准里加了新项；(b) 改可行域——约束 $y\le 2$ 变成 $y\le 3$；(c) 改目标函数——成本系数变大。优化的两件套从此要分开看：**想优化什么**（目标）与**允许怎么做**（约束）。
</details>

**练习 2**（判题）：三个顶点围成的三角形可行域上有目标函数 $z=x+3y$。初始代码把目标写错、也忘了记录最大值，请修到全部命中：

```exercise
# @title: 练习：三角形可行域上的最大值
# @check: 4
# @check: 8
# @check: -1
# @check: 8
# @hint: 目标函数是 z = x + 3*y；每轮循环里用 if 比较 z 和 best，谁大存谁。
points = [[1, 1], [2, 2], [2, -1]]   # 可行域三个顶点（线性规划里最优解总在顶点取到）
best = 0                             # 用于记录目前见过的最大 z

for p in points:
    z = p[0] + p[1]                  # ← 错了：目标是 x + 3*y，这里漏了系数
    print(z)

print(best)                          # ← best 从未被更新，永远是 0
```

修好后四行输出依次是两个顶点的旧值修正、以及最终的最大值 $8$——它出现在顶点 $(2,2)$ 上。

**练习 3**：把实验 3 的网格步长从 0.05 改成 0.5 再跑一遍，看最优点会不会偏离 $(2,2)$。思考：网格法什么时候会完全错过真最优？

<details>
<summary>点开查看逐步解答</summary>

步长 0.5 时格点仍包含 $(2,2)$（因为 2 是 0.5 的倍数），答案不变。但若可行域右边界是 $x=2.1$，步长 0.5 的格点只能撒到 2.0，就会错过真正的边界最优点。**网格法的精度由步长决定，维度越高代价越大**——这正是后面要学梯度下降的理由：沿坡走比到处撒点聪明。
</details>

## 7. 选读：为什么线性目标的最优总躲在顶点

<details>
<summary>选读 · 一分钟看完论证思路</summary>

设可行域是多边形、目标是线性函数 $z=ax+by$。固定 $z=c$ 得到一条直线（等值线）；让 $c$ 变化，一族平行线扫过平面。多边形是"凸"的（下一课正式化），平行线族从一侧推进，最先碰到多边形的接触点必然是某个**顶点**（整条边重合时也算顶点取到）。所以只需检查有限个顶点——练习 2 正是这么干的。这就是线性规划的几何内核，高考里的"简单线性规划"考的就是它。

</details>
