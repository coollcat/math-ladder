# 优化

优化是把愿望写成一个目标函数，再在可行范围内找最好的选择。本章从等高线和下降方向开始，一路走到现代机器学习里的随机梯度和约束条件。

这一章按下面的路线图推进：

3. [梯度下降、学习率与收敛](./30-gradient-descent.md)——浓雾封山，你被困在半山腰，看不见谷底，只能用脚感受脚下的坡度；
4. [拉格朗日乘数法](./40-lagrange-multipliers.md)——你有 24 米围栏，要圈一块矩形菜园；
5. [一阶与二阶最优性条件](./50-optimality-conditions.md)——站稳的点先查坡度是否归零，再由 Hessian 验发"局部极小"证书；

## 实战挑战 · 货运配比与线性规划

真实场景：货运站调度员小周要安排甲、乙两种货箱的装车数（记为 $x,y$），站点的硬规矩是——两种箱数都不能是负数；甲箱最多装 3 组；两种合计至少 2 组；乙箱数不许超过甲箱数。每多一组甲箱贡献 1 分绩效、每组乙箱贡献 2 分，问怎样装车绩效最高？这也是调度和资源分配问题的共同骨架：目标打分，约束圈地。

这道题的数学骨架改编自 **2017 年高考数学北京卷第 4 题**（选择题）：

$$\max z=x+2y,\qquad x,y \ge 0,\quad x \le 3,\quad x+y \ge 2,\quad y \le x$$

**(a)** 可行域的四个顶点是 $(1,1)$、$(3,3)$、$(3,0)$、$(2,0)$。逐个算出目标函数 $z=x+2y$ 的值；**(b)** 报出最大值。第一项已示范：

```exercise
# @title: 实战挑战：非负约束下的最优配比
# @check: 3
# @check: 9
# @check: 3
# @check: 2
# @check: 9
# @hint: 目标是 x + 2*y；四个顶点各算一遍后取最大——线性目标的最优总在顶点上。
p1 = [1, 1]
p2 = [3, 3]
p3 = [3, 0]
p4 = [2, 0]

print(p1[0] + 2 * p1[1])   # (a)-1 顶点一的绩效，已示范
print()                    # (a)-2 顶点二的绩效
print()                    # (a)-3 顶点三的绩效
print()                    # (a)-4 顶点四的绩效
print()                    # (b) 四者中的最大值
```

<details>
<summary>点开查看逐步解答</summary>

四个顶点逐一验算：

| 顶点 | 来源 | $z=x+2y$ |
| --- | --- | --- |
| $(1,1)$ | 直线 $y=x$ 与 $x+y=2$ 的交点 | $1+2=3$ |
| $(3,3)$ | 直线 $x=3$ 与 $y=x$ 的交点 | $3+6=\mathbf{9}$ |
| $(3,0)$ | 直线 $x=3$ 与 $y=0$ 的交点 | $3+0=3$ |
| $(2,0)$ | 直线 $x+y=2$ 与 $y=0$ 的交点 | $2+0=2$ |

最大绩效 $z=9$，在 $(3,3)$ 取得：甲乙各装满 3 组。选读理由（本课第 7 节）：可行域是多边形、目标是线性函数时，等值线平移最先碰到的一定是某个顶点——所以只查四个角就够了。

调度员视角复核：把乙箱上限从"不超过甲"放宽为"不超过甲加 1"，新顶点 $(3,4)$ 出现，$z=3+8=11$——最优值涨 2，这就是约束放松的边际收益，与第 40 课拉格朗日乘子的影子价格思想遥相呼应。

```python
p2 = [3, 3]
print(p2[0] + 2 * p2[1])   # 9
print(3 + 2 * 4)           # 放宽后的新最优 11
```

</details>

## 实战挑战 · 梯度下降是往反方向走

梯度下降一步：$x \leftarrow x - \eta\,f'(x)$，是**减**学习率乘梯度。$f(x)=x^2$ 从 $x=3$ 出发、学习率 $\eta=0.1$，一步后应是 $2.4$。下面这题加错了方向，修到输出 `2.4`：

```exercise
# @title: 实战挑战：梯度下降往反方向走
# @check: 2.4
# @hint: 梯度指向上升最快方向，下降要"减去"它；符号是减不是加。
x = 3.0
lr = 0.1
grad = 2 * x           # f'(x) = 2x = 6
x_new = x + lr * grad  # ← 问题在这：该是减号
print(x_new)
```

<details>
<summary>点开查看逐步解答</summary>

梯度下降沿**负梯度**方向走：

```python
x_new = x - lr * grad   # 3 - 0.1*6
print(x_new)            # 2.4
```

改完：$3 - 0.1\times6 = 2.4$，离最小值 $x=0$ 更近了。初始代码 `x + lr*grad` 得 $3.6$——朝着梯度方向走是**爬坡**，$f(3.6)=12.96 > f(3)=9$，越走越糟。这个"减号"是梯度下降的灵魂：梯度指向上升，下降就要反着来。

</details>
