# 贝叶斯优化：只许试三十次怎么找最优

## 1. 从一个场景开始

你在调一个大模型的超参数：学习率、层数、正则强度，三个旋钮。每次完整训练要 6 小时、几百度电，预算只够**试 30 次**。网格搜索会把三十次均匀撒在方格里，多半落在"怎么调都不好用"的平淡区域；随机搜索好一些，但它同样不长记性——第十次试验对第十一次毫无帮助。

但真实训练出的曲线不那么随机：学习率在某个量级附近表现好，偏离一个数量级就崩——**"好区域"是连成片的**。既然相邻设置的结果相似，那试过几个点之后，不是就能推测"哪儿还没被挖过、而且很可能更好"吗？

贝叶斯优化（Bayesian Optimization, BO）就是这门"带着地图摸黑下山"的手艺：用最少的试验次数，在三十次里尽量把最优值挖出来。

## 2. 直觉解释

想象你雇了两个助手，一个**画地图的**，一个**挑地方的**。

- 画地图的（**代理模型**）拿已有观测当路标，在整张地图上画出"海拔估计"。它不只填一个数，还标注**可信度**：路标密集处画得实，没人去过的荒原画成一片模糊——模糊本身就是信息。
- 挑地方的（**采集函数**）每次只问一句："下一铲子挖哪儿最值？"它把所有候选点排成一张分数榜。榜单的算分逻辑里有两个互相拉扯的愿望：
  - **利用**：去预测海拔最高的地方（可能马上见收益，但也可能只是估计偏差）；
  - **探索**：去最模糊的地方（多半白挖，但挖中就是大发现）。

两个愿望的权重不是拍脑袋定的，而是由"估计均值 + 不确定度"共同算出来的一个分数。挖完一铲，数据多一条、地图更新一次，再挑下一处——三十次就这样花掉。

这一课就是把"画地图"和"挑地方"这两件事写成公式，并亲手跑一轮。

## 3. 正式定义

**黑箱问题**：我们要最大化 $f(x)$，但它没有解析式、没有梯度、每次评估都昂贵。能做的只是查询 $y_i=f(x_i)+\varepsilon_i$，且查询次数有硬预算 $N$（这里 $N=30$）。

**代理模型**：用**高斯过程**（GP）当作 $f$ 的先验。常用径向基核

$$k(x,x')=\exp\!\Big(-\frac{(x-x')^2}{2\ell^2}\Big)$$

给定观测 $\lbrace(x_i,y_i)\rbrace$，GP 给出任意新点处的后验

$$\mu(x)=k(x)^{\mathsf T}(K+\sigma_n^2I)^{-1}y,\qquad \sigma^2(x)=k(x,x)-k(x)^{\mathsf T}(K+\sigma_n^2I)^{-1}k(x)$$

一个廉价的"预测值 + 不确定度"搭档。**采集函数**把两者折成一个分数，两种最常用的折法：

$$\mathrm{UCB}(x)=\mu(x)+\kappa\,\sigma(x)$$

$$\mathrm{EI}(x)=\big(\mu(x)-f^{+}\big)\Phi\!\big(z\big)+\sigma(x)\varphi\big(z\big),\qquad z=\frac{\mu(x)-f^{+}}{\sigma(x)}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f^{+}$ | 已观测的最好值 | 目前的记录，是 EI 的基准线 |
| $\mu(x)$ | 后验均值 | 代理模型对 $f(x)$ 的最佳猜测 |
| $\sigma(x)$ | 后验标准差 | 这个猜测有多不可靠；没试过的区域最大 |
| $\varphi,\Phi$ | 标准正态的密度、分布函数 | 把"标准化后的差距"换算成概率与面积 |
| $\kappa$ | 探索系数 | UCB 的旋钮：越大越爱往不确定处跑 |
| $\mathrm{EI}(x)$ | 期望改进 | 在 $x$ 处挖一铲，期望能比记录好多少；小于 0 没意义，取 $\max(\cdot,0)$ |

**优化循环**（四步，跑 $N$ 轮）：

1. 撒 $n_0$ 个初始点（随机或拉丁超立方），测出 $y$；
2. 用全部观测拟合 GP 后验 $\mu,\sigma$；
3. 在候选集上最大化采集函数，得下一个试验点 $x^{+}$；
4. 真实评估 $f(x^{+})$，把新数据加入观测表，回到第 2 步。

代价主要在两步：GP 拟合每次约 $O(n^3)$（$n$ 是已有观测数，三十次时完全无所谓），采集函数最大化是廉价的一维/低维搜索。

## 4. 分步例题：手算两个候选点的 EI 与 UCB

已有观测的最好值 $f^{+}=1.2$。代理模型对两个候选点给出：

| 候选 | $\mu$ | $\sigma$ |
| --- | --- | --- |
| A | 1.5 | 0.4 |
| B | 1.0 | 1.0 |

1. **标准化差距**：A 的 $z=(1.5-1.2)/0.4=0.75$；B 的 $z=(1.0-1.2)/1.0=-0.2$；
2. **查正态表**：$\Phi(0.75)=0.7734$、$\varphi(0.75)=0.3011$；$\Phi(-0.2)=0.4207$、$\varphi(-0.2)=0.3910$；
3. **算 EI**：A 得 $(0.3)(0.7734)+(0.4)(0.3011)=0.2320+0.1204=0.3525$；B 得 $(-0.2)(0.4207)+(1.0)(0.3910)=-0.0841+0.3910=0.3069$。**A 略胜**——增益正、但不确定度小；
4. **算 UCB（取 $\kappa=2$）**：A 得 $1.5+2(0.4)=2.3$；B 得 $1.0+2(1.0)=3.0$。**B 胜出**——因为 UCB 给不确定度标了高价；
5. **换旋钮再看**：若把 $\kappa$ 降到 $0.5$，A 得 $1.70$、B 得 $1.50$，冠军又换回 A。同一个代理模型，**采集函数是探索与利用的调音台**：EI 天生折中（把"改进了多少"的整个分布积起来），UCB 则用一个显式旋钮 $\kappa$ 说话。

### 实验 2（python）：在候选网格上算出"下一个采样点"

下面代码第一次用到 `math.erf`——误差函数，它把正态曲线下的面积变成一行算术：$\Phi(z)=\tfrac12\big(1+\mathrm{erf}(z/\sqrt2)\big)$。有了它，EI 不用查表就能算。

```python title="一轮贝叶斯优化：EI 与 UCB 各自选哪个点"
import math
import matplotlib.pyplot as plt

def mu(x):
    """代理模型预测均值：x≈1 处有已知的好点"""
    return 0.8 * math.exp(-((x - 1) ** 2) / 0.5)

def sig(x):
    """代理模型预测标准差：x≈3.5 从没试过，最不确定"""
    return math.exp(-((x - 3.5) ** 2) / 1.2)

def Phi(z):
    """标准正态分布函数：erf 为误差函数，用 0.5*(1+erf(z/√2)) 换算"""
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))

def phi(z):
    """标准正态密度函数"""
    return math.exp(-z * z / 2) / math.sqrt(2 * math.pi)

FBEST = 0.5            # f⁺：目前最好的观测值

def ei(x):
    """期望改进：均值超出记录的部分 + 不确定度贡献"""
    m, s = mu(x), sig(x)
    z = (m - FBEST) / s
    return (m - FBEST) * Phi(z) + s * phi(z)

def ucb(x, kappa=2.0):
    """置信上界：均值加上 kappa 倍不确定度"""
    return mu(x) + kappa * sig(x)

xs = [i / 50 for i in range(0, 251)]     # 列表推导：把 0~5 切成 251 个候选点
best_ei = max(xs, key=ei)                # key= 指定比较依据：按 ei 值取最大
best_ucb = max(xs, key=ucb)
print("EI 选中:", round(best_ei, 2), " EI 值:", round(ei(best_ei), 4))
print("UCB 选中:", round(best_ucb, 2), " UCB 值:", round(ucb(best_ucb), 4))

fig, ax = plt.subplots(figsize=(7, 3))
ax.plot(xs, [mu(x) for x in xs], label="mu(x)")
ax.plot(xs, [ucb(x) for x in xs], label="UCB (kappa=2)")
ax.plot(xs, [ei(x) for x in xs], label="EI(x)")
ax.axhline(FBEST, color="gray", linestyle="--")   # axhline：画一条水平参考线
ax.legend()
```

运行结果是两种取向的分岔：EI 选中 `1.0`（把赌注压在已知好点上），UCB 选中 `3.5`（跑到完全没探过的荒原）。同一张地图、同一批数据，**换个采集函数就是换个人格**——工程上常把两者都跑一遍做对照。

### 快问快答

```quiz
贝叶斯优化里"代理模型"和"采集函数"各管什么？
- 代理模型负责挑点，采集函数负责拟合
- 代理模型给出每个候选点的预测均值与不确定度，采集函数把两者折成一个"值不值得试"的分数 [*]
- 两者都是用来替代梯度计算的
? 代理模型（通常是高斯过程）提供廉价预测与不确定度；采集函数把"均值高"和"不确定度大"换算到同一个尺度上，最大化它就是在探索与利用之间取舍。
```

:::warning[常见误区]

**误区一**："贝叶斯优化就是更聪明的随机搜索。" 随机搜索的每一次采样**互不影响**，模型不会因为试过而变聪明；BO 的全部价值在于把已有观测变成一张会随试验更新的地图。三十次预算里，前几次是"投资"，后面才开始收利息——所以它特别怕预算只有三五个点。

**误区二**："代理模型拟合得越准，优化越快。" 未必。若把 GP 的噪声设得极小、核宽设得极大，$\sigma(x)$ 会在观测点附近骤降到 0，采集函数被压平，算法就"自信地卡住"了。BO 要的是一张**知道自己哪里不知道**的地图，早熟比迟钝更危险。

**误区三**："非得用高斯过程。" GP 是最经典的选择（后验有闭式、天然带不确定度），但随机森林 + 分位数（SMAC）、树状 Parzen 估计（TPE）同样能提供"预测 + 不确定度"这对搭档。选谁取决于维度、离散变量的多少与实现成本，不变的是那条四步循环。

:::

## 6. 练习

**练习 1**（判题）：下面代码算候选点 $(\mu,\sigma)=(1.5,0.4)$ 的 EI，但最后一项写成了除以 $\sigma$——修好它让输出等于手工计算的结果。

```exercise
# @title: 练习：修好 EI 采集函数
# @check: 0.352
# @hint: EI = (μ − f⁺)·Φ(z) + σ·φ(z)；第二项是乘 σ，不是除。
import math

def Phi(z):
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))

def phi(z):
    return math.exp(-z * z / 2) / math.sqrt(2 * math.pi)

mu, sig, fbest = 1.5, 0.4, 1.2
z = (mu - fbest) / sig
ei = (mu - fbest) * Phi(z) + phi(z) / sig     # ← 问题在这：末端应乘 σ
print(round(ei, 3))
```

改完输出 `0.352`。原式的量纲是错的：$(\mu-f^{+})$ 与 $\sigma\varphi(z)$ 都带 $f$ 的单位，而 $\varphi(z)/\sigma$ 带 $f^{-1}$——一个"期望改进"绝不可能量纲颠倒，这也是检查公式时的第一道防线。

**练习 2**（概念）：如果两个候选点的 $\mu$ 完全相同，EI 会选哪一个？为什么这仍然是"理性"的？

<details>
<summary>点开查看逐步解答</summary>

选 $\sigma$ 更大的那个。$\mu$ 相同时 EI 退化成 $\sigma\cdot\varphi(z)$ 加上一个同号的常数项，随 $\sigma$ 单调增：估计一样好，那就去信息量最大的地方。这看起来像"舍高求谜"，其实是理性的：在同样乐观的两种可能里，挑那个"万一真是宝藏"收益更大的，同时也把地图画得更实、为后续几轮铺路——一次试验买到的是**两个**东西：一个观测值，和一次减少全局不确定度的机会。
</details>

**练习 3**（选做）：为什么 EI 的公式里是 $\max(f(x)-f^{+},0)$ 的期望，而不是直接期望 $f(x)$？

<details>
<summary>点开查看逐步解答</summary>

因为目标是"**改进**记录"，不是"取得高值"本身。$\mathbb E[f(x)]=\mu(x)$ 会让算法永远扑向均值最高的已知点，退化成贪婪；而 $\mathbb E[\max(f(x)-f^{+},0)]$ 只奖励"能刷新记录"的可能性——一个均值略低但可能大爆发的点因此获得了分数（这就是 $\sigma\varphi(z)$ 那一项的来源，它的推导用到了正态分布的正部期望 $\mathbb E[(Z)_+]=\varphi(z)-z(1-\Phi(z))$，与这里的写法等价）。顺带一个漂亮的性质：$\mathrm{EI}(x)\ge0$ 恒成立，所以它天然是一个"值得挖"的分数。
</details>

## 7. 选读：GP 后验与超参数

<details>
<summary>选读 · 均值方差从哪来，O(n³) 又贵在哪</summary>

GP 的核心假设是：任意有限个点上的函数值服从联合多元正态，协方差由核函数 $k$ 给出。于是"已知观测、求新点分布"就是一次条件分布的教科书计算——多元正态的条件分布仍是正态，其均值与协方差正是 §3 的两条公式。公式里 $(K+\sigma_n^2I)^{-1}$ 出现两次，$K$ 是 $n\times n$ 矩阵，求逆是 $O(n^3)$：这是 BO 的主要计算瓶颈，也是"观测超过几千条就该换近似方法"的原因。

核的两个超参数（长度尺度 $\ell$、噪声 $\sigma_n$）通常按边际似然最大化自动选——它们决定了地图的"粗糙程度"和"对观测的信任程度"，本质上是把模型选择外包给了优化器。另一个实践要点：BO 在高维（比如 20 维以上）会迅速失效，因为"没试过的区域"指数级变多，此时要么先用降维/嵌入把维度压下去，要么改用信任域式（TuRBO）的局部策略。
</details>
