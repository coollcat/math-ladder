# 一阶与二阶最优性条件

## 1. 从一个场景开始

浓雾散去前的一刻，你发现自己站在一块"四平八稳"的地方：往前迈、往后退、往左斜、往右斜——脚下的高度都纹丝不动。可以宣布"到谷底了"吗？

先别急。一块平地也可能是山顶的平台，甚至可能是马鞍的正中央：前后两个方向朝上坡，左右两个方向却朝下坡。本课教你给每一个"脚底平滑的点"开出一张体检报告：**第一项查坡度是否归零，第二项查四周曲率是不是处处向上**。

## 2. 直觉解释

一维世界你早就见过这套体检：$f'(x)=0$ 只是说"此处暂时平"，接下来要看二阶导 $f''$ 的符号——向上弯的是谷底，向下弯的是山顶，两样都不是的就是拐点。

多维世界的完全同款：

- **第一项体检**：梯度 $\nabla f$ 是所有方向的坡度打包（第 20 章）。$\nabla f = 0$ 表示沿任何方向迈步，高度的变化率都是零——这样的点叫**驻点**；
- **第二项体检**：Hessian 矩阵 $H$ 是二阶偏导的打包（第 21 章）。想知道"沿某方向 $v$ 弯向哪边"，就用量 $v^{\mathsf T} H v$ 读数：处处为正是碗底，处处为负是倒碗，有正有负是**鞍面**——薯片的形状，两个方向曲率相反。

体检结论分级：一阶通过只是候选资格；二阶通过才能颁发"局部极小"证书。而要升级成"全局极小"，还得请上一章的凸性出场盖章。

## 3. 正式定义

设 $f$ 在点 $p$ 附近可微（二阶条件还需二阶可微）：

$$\text{一阶必要条件：}\quad p \text{ 是局部极小点} \;\Longrightarrow\; \nabla f(p)=0$$

$$\text{二阶必要条件：}\quad p \text{ 是局部极小点} \;\Longrightarrow\; v^{\mathsf T} H(p)\, v \ge 0 \;\text{ 对一切 } v \text{ 成立}$$

$$\text{二阶充分条件：}\quad \nabla f(p)=0 \;\text{ 且 } v^{\mathsf T} H(p)\, v > 0 \;\text{ 对一切 } v\ne 0 \text{ 成立} \;\Longrightarrow\; p \text{ 是严格局部极小点}$$

二维情形有个快捷判据：记 $f_{xx}, f_{yy}, f_{xy}$ 为三个二阶偏导，令判别式 $D = f_{xx}\,f_{yy} - f_{xy}^2$：

| 体检读数 | 结论 |
| --- | --- |
| $D>0$ 且 $f_{xx}>0$ | 正定：严格局部极小 |
| $D>0$ 且 $f_{xx}<0$ | 负定：局部极大 |
| $D<0$ | 不定：鞍点 |
| $D=0$ | 退化：判不出来，需要更高阶信息 |

$D>0$ 相当于第 20 课二次型判据里的 $4ab-c^2>0$（同一件事的两副面孔）；"两个特征值全正"与"$D>0$ 且迹为正"互为翻译。

## 4. 分步例题

**例**：给 $f(x,y)=x^2+xy+y^2-6x-9y$ 的唯一驻点开体检报告。

1. **求梯度**：$\partial f/\partial x = 2x+y-6$，$\partial f/\partial y = x+2y-9$；
2. **一阶体检**：令两式同时为零，解方程组得 $x=1,\,y=4$——候选人是 $(1,4)$；
3. **抄 Hessian**：$f_{xx}=2$，$f_{yy}=2$，$f_{xy}=1$，即 $H=\begin{pmatrix}2&1\\1&2\end{pmatrix}$（常数矩阵，与位置无关）；
4. **算判别式**：$D = 2\times 2 - 1^2 = 3 > 0$，且 $f_{xx}=2>0$ ——正定，通过充分条件；
5. **发证**：$(1,4)$ 是严格局部极小，$f(1,4)=1+16+4-6-36=-21$。又因 $H$ 处处正定，$f$ 是严格凸函数（第 20 课），所以这还是**全局**最小值。

注意流程的分工：第一步只负责"提名候选人"，真正定案的是第二步之后的曲率检查。

操作指南：把 $b$ 从 $-0.5$ 拖到 $0.5$，红色的 saddle 变成绿色的 local minimum——这正是判别式 $D=4ab-c^2$ 由 $-2$ 翻成正的过程；再把 $a,b$ 同时拖成负数，得到 local maximum（倒碗）。组件把临界点固定在原点：这不是偷懒，而是**平移不改变体检结果**——任何二次函数都可以把坐标原点挪到自己的驻点上。

### 实验 2：手算版体检——网格找驻点 + 特征值验证

换一个非对称的目标 $h(x,y)=0.5x^2+2y^2-2x-8y$：先用笨办法撒网格找低点，再按例题的完整流程体检一遍。程序读数应与你的手算一致。

```python title="网格定位驻点，再用 Hessian 定案"
import math                                # 数学库：待会用 sqrt 开平方

best_x, best_y, best_h = None, None, None  # None 占位：表示“还没有找到”

for i in range(81):
    x = i * 0.1                            # 以 0.1 为步长扫过 [0, 8]
    for j in range(61):
        y = j * 0.1                        # 内层扫过 [0, 6]
        h = 0.5 * x * x + 2 * y * y - 2 * x - 8 * y
        if best_h is None or h < best_h:   # 第一次总能进入；之后只保留更小的
            best_h, best_x, best_y = h, x, y

print("网格最优点:", best_x, best_y)
fx = best_x - 2                            # 偏导 dh/dx = x - 2 在该点的值
fy = 4 * best_y - 8                        # 偏导 dh/dy = 4y - 8 在该点的值
print("此处梯度:", fx, fy)

fxx, fyy, fxy = 0.5, 4, 0                  # Hessian 三个元素（本题与位置无关）
det = fxx * fyy - fxy * fxy                # 行列式 D
trace = fxx + fyy                          # 迹：对角线之和
eig_lo = (trace - math.sqrt(trace * trace - 4 * det)) / 2   # 小特征值
eig_hi = (trace + math.sqrt(trace * trace - 4 * det)) / 2   # 大特征值
print("D =", det, "特征值:", eig_lo, eig_hi)
verdict = "正定 -> 严格局部极小" if eig_lo > 0 else "非正定"  # 三元表达式：条件成立取前者
print("结论:", verdict)
```

输出里网格恰好踩中 $(2.0,\,2.0)$，梯度归零，$D=2$、两个特征值 $0.5$ 和 $4$ 全为正——三个证据相互印证。观察一个细节：手工配方可得 $h=0.5(x-2)^2+2(y-2)^2-10$，最小的 $-10$ 正好由常数项保管。

### 快问快答

```quiz
在某个驻点上，Hessian 的两个特征值一个为正、一个为零，能下什么结论？
- 它一定是局部极小点
- 它一定是鞍点
- 判不出来，可能极小也可能不是，需要更高阶信息 [*]
? 二阶判据失灵（退化情形）：例如 f(x,y)=x^2+y^3 在原点，曲率一半一半，答案藏在三次项里。
```

:::warning[常见误区]

**误区一**："梯度为零的点就是要找的最小值。" 零梯度只代表驻点这一**候选资格**：山顶和马鞍同样满足。下结论必须再看二阶体检。

**误区二**："判别式 $D>0$ 就万事大吉。" 还要配 $f_{xx}$ 的符号：$D>0,f_{xx}>0$ 是谷底，$D>0,f_{xx}<0$ 是山顶——一对孪生兄弟只差一个方向。

**误区三**："通过二阶充分条件就拿到了全局最小。" 充分条件只保证**那一小块邻域**。要覆盖整个定义域，得借助凸性（第 20 课）或逐点比较，二者缺一不可。

:::

## 6. 练习

**练习 1**（概念）：$f(x)=x^3$ 与 $g(x)=x^4$ 在原点都满足 $f'(0)=0$ 甚至 $f''(0)=0$。为什么前者不是极小、后者是？

<details>
<summary>点开查看逐步解答</summary>

$x^3$ 在原点左侧为负、右侧为正——两侧高低互换，是标准鞍点；$x^4$ 则两侧都大于零，是真谷底。两者的二阶导同为零，所以二阶判据失效（$D=0$ 型退化）。教训有两个：**判据失灵不等于结论随便猜**；反过来，$x^4$ 这个真极小的存在也说明"体检不过关"不代表"一定不是极小"——必要条件的反面用不得。
</details>

**练习 2**（判题）：目标函数 $f(x,y)=x^2+y^2+xy-9x-12y$，代码已替你写好了 Hessian 三元素。初始代码留着猜测坐标、还把两种身份的标签贴反了，请修正后让四行输出全部命中：

```exercise
# @title: 练习：给驻点开体检报告
# @check: 2
# @check: 5
# @check: 3
# @check: minimum
# @hint: 驻点是方程组 2*x+y=9 与 x+2*y=12 的解；正定的读数是 D>0 且 fxx>0，对应的是谷底而不是山顶。
fxx, fyy, fxy = 2, 2, 1    # 本题 Hessian 的三个元素（不用改）

x = 4      # ← 猜测值：解出驻点横坐标后替换
y = 3      # ← 猜测值：解出驻点纵坐标后替换

D = fxx * fyy - fxy * fxy      # 二阶判别式
if D > 0 and fxx > 0:
    kind = "maximum"           # ← 错了：D>0 且 fxx>0 是正定，说的是谷底
elif D > 0 and fxx < 0:
    kind = "minimum"           # ← 错了：那是倒碗（负定）的身份
else:
    kind = "saddle"

print(x)
print(y)
print(D)
print(kind)
```

修好后输出 `2`、`5`、`3`、`minimum`。顺手验算终点：$f(2,5)=4+25+10-18-60=-39$，由于 $H$ 处处正定，这也是全局最小。

**练习 3**：用体检台组件核对第 20 课的老朋友：设 $a=2,b=3,c=4$，先用本课判据纸笔判断凸性与驻点类型，再用组件验证。

<details>
<summary>点开查看逐步解答</summary>

判别式 $D=4ab-c^2=24-16=8>0$ 且 $a=2>0$：驻点是正定谷底（组件显示 local minimum），并且 $H$ 处处正定所以整体凸。把 $c$ 推到 $5$：$D=24-25=-1<0$ 瞬间翻成 saddle。同一台设备，20 课用它讲凸性，本课用它讲分类——判据本来就是同一个。
</details>

## 7. 选读：为什么坡度必须归零

<details>
<summary>选读 · 一句话版本的反证</summary>

设 $p$ 是局部极小点但 $\nabla f(p)\ne 0$。任取一个与梯度夹角大于直角的方向 $v$（使 $\nabla f(p)\cdot v<0$），则从 $p$ 出发沿 $v$ 走一小步 $t$，一阶泰勒展开给出

$$f(p+t v)\approx f(p)+t\,\nabla f(p)\cdot v<f(p)$$

只要 $t$ 足够小，更高阶的展开项盖不住这一负的一阶项——邻域内竟有点更低，与"局部极小"矛盾。故 $\nabla f(p)$ 必须为零。二阶版本的思路相同：把展开多留一项 $t^2 v^{\mathsf T} Hv/2$，若某方向曲率为负，跨一小步立刻更矮。这也顺带解释了为什么判据分成两档——一阶保证"不降"，二阶保证"四周托底"。

</details>
