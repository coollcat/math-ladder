# 线性规划与单纯形法

## 1. 从一个场景开始

你是货运站的调度员。甲货箱每箱利润 3 千元、乙货箱每箱利润 2 千元，装车要守三条硬规矩：总装载不超过 4 车位、乙类加固件最多配 6 套（每只甲箱用 1 套、每只乙箱用 3 套）、两类都不能是负数。求利润最高的装箱方案。

把话翻译成数学：$\max z=3x+2y$，约束 $x+y\le4$、$x+3y\le6$、$x,y\ge0$。第 10 课已经给过"可行域"这个词；这一课的问题是——**在可行域里找最优，需要把整块区域都试一遍吗？**

答案是不需要：四条直线围出一个多边形，最优解**必然踩在某个顶点上**。整个线性规划（Linear Programming）的算法史，就是围绕"怎么聪明地访顶点"展开的。

## 2. 直觉解释

先玩一场扫雷：可行域是一张雷区地图，顶点就是旗子。目标函数 $z=3x+2y$ 的等值线是一族平行斜线（同一条线上利润相同），把这族线想象成一块木板，从远离可行域的地方缓缓平移过来——

- 木板第一次碰到可行域的那个接触点，就是最大值所在；
- 接触的只能是一个顶点（或一整条边，此时边的两个端点同样都是最优）。

为什么会这样？可行域是由半平面切的：每条约束砍掉平面的一半，砍剩下的区域是**凸多边形**（第 20 课的凸性在这里接管）。线性目标的等值线是直线族，凸多边形被一条直线"最后擦到"的位置必然在边界上，而边界是几条线段拼成的——直线与线段族的最后接触，只在端点（除非恰好平行于某条边）。所以不用扫整张地图，**数清所有顶点就够赢**。

单纯形法（simplex）做的事更省：它不枚举全部顶点，而是从某个顶点出发，沿着边走到目标值更高的邻居顶点，一步步"爬山"，直到无处可去——那就是最优。

## 3. 正式定义

**线性规划标准形**：

$$\max z=c^{\mathsf T}x \quad \text{s.t.} \quad Ax\le b,\; x\ge0$$

| 符号 | 名字 | 本例 |
| --- | --- | --- |
| $x=(x,y)^{\mathsf T}$ | 决策变量 | 每种箱子的数量 |
| $c$ | 目标系数向量 | $(3,2)$，利润单价 |
| $A x\le b$ | 不等式约束组 | 总车位、加固件两行 |
| 可行域 | 全部约束的交集 | 凸多边形 |
| 顶点 / 极点 | 不能表示成可行域内另两点连线中点的点 | 多边形的角 |

**顶点最优定理**：线性目标在非空有界凸多面体上的最大值必在某顶点取得。

**基本可行解视角**（下一节的判题练习要用）：把 2 个变量、不等式全改写为等式后，未知量多于方程——让其中一部分变量取零（非基变量），其余由方程组解出（基变量），恰是高斯消元（第 21 章）挑主元的老手艺。每个顶点都对应一种"两条边界同时绷紧"的选法。

## 4. 分步例题

继续用开头的例子。

1. 画边界直线：$x+y=4$ 与 $x+3y=6$，再添两条坐标轴，围出候选角点；
2. 两两求交，候选角点共有六个：$(3,1)$、$(4,0)$、$(0,4)$、$(6,0)$、$(0,2)$、原点——其中 $(0,4)$ 违反 $x+3y\le6$、$(6,0)$ 违反 $x+y\le4$，踢掉；
3. 剩下 4 个真顶点 $(0,0),(4,0),(0,2),(3,1)$，逐个代目标值：$z=0,\,12,\,4,\,11$；
4. 最大值 $z=12$ 在 $(4,0)$ 取得——**车位优先给单价高的甲箱**，尽管它每箱吃掉整整一个车位；
5. 顺手验证等值线直觉：直线族 $3x+2y=z$ 的斜率是 $-\dfrac32$，介于两条边界的斜率 $-1$ 和 $-\dfrac13$ 之间，不平行的保证使最优唯一地落在角上。

注意第 2 步不能省："假顶点"是没过全部约束门槛的交点，混进来会让答案错到离谱——下面的判题练习就在这里埋了坑。

### 实验 2（python）：暴力枚举顶点 vs 沿梯度瞎撞

```python title="两两求交找顶点，并对比'沿目标方向走到底'"
import math                                    # 数学库：hypot 算向量长度

LINES = [[1, 1, 4], [1, 3, 6], [1, 0, 0], [0, 1, 0]]   # 每行 a*x+b*y=c

def is_feasible(x, y):                         # def 自定义函数：查点是否过了所有约束关
    if x < -1e-9 or y < -1e-9:                 # 浮点比较留一点点余量防误杀
        return False
    for a, b, c in LINES:                      # for 循环逐条约束检查
        if a * x + b * y > c + 1e-9:
            return False
    return True

verts = []                                     # 收集可行的交点
for i in range(4):
    for j in range(i + 1, 4):
        a1, b1, c1 = LINES[i]
        a2, b2, c2 = LINES[j]
        det = a1 * b2 - a2 * b1                # 二元一次方程组的行列式
        if det == 0:                           # 平行线无交点
            continue
        x = (c1 * b2 - c2 * b1) / det          # 克莱姆法则解交点
        y = (a1 * c2 - a2 * c1) / det
        if is_feasible(x, y):
            verts.append((round(x, 6), round(y, 6)))

best_z = -1
for vx, vy in verts:                           # 只在顶点上比目标值
    best_z = max(best_z, 3 * vx + 2 * vy)      # max 是内置函数（第 19 章引入）
print("可行顶点:", verts)
print("最优 z =", round(best_z))

# 对照：沿着目标梯度的方向一路走，会停在哪？
g = (3.0, 2.0)                                 # 目标函数的梯度向量
length = math.hypot(g[0], g[1])                # 梯度取单位长度便于步进
px, py = 0.0, 0.0
for step in range(100000):                     # 小步前进，撞墙即停
    nx = px + g[0] / length * 0.001
    ny = py + g[1] / length * 0.001
    if not is_feasible(nx, ny):
        break                                  # break：提前跳出 for 循环
    px, py = nx, ny
print("沿梯度停在", round(px, 3), round(py, 3), "目标值", round(3 * px + 2 * py, 3))
```

运行结果：顶点枚举给出 $(4,0)$ 处 $z=12$；而"沿梯度蒙头走"停在约 $(2.0,\,1.33)$，目标值只有约 $8.67$——一头撞上 $x+3y=6$ 这堵墙就不动了，离真正的冠军差了一截。**直线目标没有"内部最优"，按方向冲不如按顶点跳。**

### 快问快答

```quiz
把某条约束从 x+y<=4 放宽成 x+y<=5，最优点还一定在原顶点上吗？
- 还在原处不动
- 会挪到新可行域的某个（可能不同的）顶点上 [*]
- 移到新可行域的正中心
? 约束一动，可行域换了一个多边形，等值线重新平移碰新的墙。每次放宽都可能诞生新顶点、抬高最优值——变化多少正是拉格朗日乘子/影子价格一课预告过的灵敏度问题。
```

:::warning[常见误区]

**误区一**："你以为最优点可能在可行域内部（比如资源均衡利用的点）。" 线性目标的等值线是平行直线族，最后的接触必在边界角上。想在"内部"见最优？那得靠非线性目标自己弯出来。

**误区二**："你以为沿目标梯度直冲就能到最优。" 实验 2 已经演示：撞上第一堵墙就卡死在边上（$z\approx8.7$）。方向告诉你"往上坡抬"，但抬到哪里停，是由顶点的几何决定的。

**误区三**："你以为非负约束只是客套的形式。" 没有 $x,y\ge0$，可行域朝无穷延伸，$z=3x+2y$ 可以跑到正无穷——两条坐标轴恰恰是把地图钉住的两面墙。

:::

## 6. 练习

**练习 1**（概念口答）：如果目标改成 $\max z=x+3y$，本例的最优顶点是哪个？

<details>
<summary>点开查看逐步解答</summary>

等值线斜率变成 $-\dfrac13$，恰好与边界 $x+3y=6$ **平行**！木板最后贴着这条边滑出去——边上每一个点都是最优。退化情形出现了：最优仍是顶点之一（比如 $(0,2)$ 或 $(3,1)$ 都给 $z=6$），但不再唯一。定理没有失效，只是"唯一性"缺了。
</details>

**练习 2**（判题）：下面这段代码想复现"顶点枚举"，但漏掉了对某条约束的资格复查，跑出了 5 个"顶点"和虚高的最优值 18。请补齐约束检查，让它输出正确的顶点个数与最优值。

```exercise
# @title: 练习：别把假顶点迎进门
# @check: 4
# @check: 12
# @hint: 直线 x+3y=6 与 x 轴的交点 (6,0) 根本越过了 x+y<=4 这堵墙——资格复查必须把所有约束都过一遍。
LINE1 = [1, 1, 4]                       # x + y = 4
LINE2 = [1, 3, 6]                       # x + 3y = 6

def ok(x, y):
    if x < 0 or y < 0:                  # 非负这两关没忘
        return False
    return True                         # ← 问题在这：两条斜边界的审查失踪了

pairs = [(LINE1, LINE2), (LINE1, [1, 0, 0]), (LINE1, [0, 1, 0]),
         (LINE2, [1, 0, 0]), (LINE2, [0, 1, 0]), ([1, 0, 0], [0, 1, 0])]

count = 0
best = 0
for (l1, l2) in pairs:
    a1, b1, c1 = l1
    a2, b2, c2 = l2
    det = a1 * b2 - a2 * b1
    if det == 0:
        continue
    x = (c1 * b2 - c2 * b1) / det
    y = (a1 * c2 - a2 * c1) / det
    if ok(x, y):
        count = count + 1
        z = 3 * x + 2 * y               # 目标函数逐点打分
        if z > best:
            best = z

print(count)
print(round(best))
```

补上 `x + y <= 4` 与 `x + 3*y <= 6` 的检查后，输出 `4` 和 `12`：假顶点 $(6,0)$（$z=18$）被正确拒收，冠军回归 $(4,0)$。

**练习 3**（选做）：三个产品的线性规划有 6 条边界直线，问两两交点至多几个？这说明顶点数随规模如何增长？

<details>
<summary>点开查看逐步解答</summary>

$\binom{6}{2}=15$ 个交点候选。一般地 $n$ 条直线贡献 $O(n^2)$ 个候选——枚举顶点虽好，规模一大就开始费劲，这正是单纯形法"沿边爬、不走回头路"的价值所在。
</details>

## 7. 边界与适用条件

- 本课的目标和约束都必须是**线性**的；一旦目标带平方或曲线约束，顶点定理作废，需回到 KKT/内点法的世界。
- 最优在顶点是**实数解**层面的结论。工厂可能要求"箱数为整数"——整数规划的可行集不再是凸多边形，难度等级直接跃升。
- 有界才谈最大值：约束不全时目标可以无限增大（无界），或根本没有公共区域（不可行），两者都要先诊断。
- 单纯形法在最坏情形下访问顶点数可能指数级，但工程实践快得惊人；内点法提供了多项式时间的另一条路——两条路线在求解器里并肩服役。

## 8. 选读：单纯形法一步的电影镜头

<details>
<summary>选读 · 从原点出发的一次换基</summary>

把不等式加松弛变量写成等式：$x+y+s_1=4$，$x+3y+s_2=6$。初始基本可行解取 $(s_1,s_2)=(4,6)$、决策变量为零——即原点顶点。

第一步问"哪个非基变量入基能涨分最快"：$y$ 的边际收益最高（每单位 2 分还要算它占用的资源代价），于是令 $y$ 从 0 开始上涨、相应的松弛量下降，第一个触底的松弛变量决定能涨多远——这叫**比率检验**。本例若选 $x$ 入基，比较 $4/1$ 与 $6/1$ 得上限 4，于是 $x=4$、$s_1=0$，一步跨到顶点 $(4,0)$，目标值直接封顶 12，下一步检验发现没有列还能改善——收工。

一进一出、向量消元的全套动作就是高斯消元的主元操作；"哪个邻顶点更优"被翻译成"哪一列的检验数为正"。数学没有新增魔法，只是把扫雷地图卷成了代数账本。
</details>
