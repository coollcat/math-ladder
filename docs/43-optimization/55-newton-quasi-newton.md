# 牛顿法与拟牛顿：二阶的加速度

## 1. 从一个场景开始

雾夜下山，你摸索出两代走法。第一代：每迈一步前用脚尖试探"此刻哪个方向朝下"，然后固定一小步挪过去——这就是第 30 课的梯度下降。第二代走法多了一个感觉：**顺便留意坡度本身在怎么变**。脚下越来越陡，说明谷还深，敢迈大步；坡度明显放缓，说明快到底了，及时收脚。

上一课的 Hessian 还只是裁判，负责给驻点验发证书；这一课让它亲自下场当发动机。你会看到：在病态山谷里锯齿撞墙的梯度下降，被牛顿法**一步送到底**。

## 2. 直觉解释

梯度下降的秘密藏在它的更新式里：$\theta \leftarrow \theta-\eta g$。把 $g$ 写开是 $\nabla f=H(\theta-\theta^*)$（在二次型上），代入整理得每步各方向乘 $(1-\eta\lambda_i)$——**所有方向共用同一个 $\eta$**。陡方向（$\lambda$ 大）必须小 $\eta$ 保命，缓方向（$\lambda$ 小）却被同一个 $\eta$ 拖慢，这就是病态山谷锯齿与龟速并存的病根。

牛顿法把"共用一步长"换成"按曲率开药方"：在当前点戴上一副二阶近视镜，镜中的地形是标准抛物面，而抛物面的谷底有闭式解——**跳过去就行**。换算到每个方向，步长恰好是 $1/\lambda_i$：陡的方向自动收脚，缓的方向自动放大，$\kappa$ 倍的曲率差距被倒数一次抹平。

至于"算 Hessian 太贵、不正定还会翻车"两桩心事，本课各给一句解法：不正定就加阻尼；不想算就让拟牛顿用位移记录**估**出它。

## 3. 正式定义

在当前点 $x_k$ 做二阶泰勒展开（$g=\nabla f(x_k)$，$H=\nabla^2 f(x_k)$）：

$$f(x_k+p)\approx f(x_k)+g^{\mathsf T}p+\tfrac12\,p^{\mathsf T}Hp$$

右端是 $p$ 的二次函数，对 $p$ 求导置零得 $Hp=-g$，于是：

$$\text{牛顿步：}\quad x_{k+1}=x_k-H^{-1}g$$

| 符号 | 含义 |
| --- | --- |
| $g$ | 当前梯度（坡度打包） |
| $H$ | 当前 Hessian（曲率打包，正定时可逆） |
| $H^{-1}g$ | 牛顿步：按曲率加权的最速方向 |
| $\lambda_i$ | $H$ 的特征值；牛顿法在每个特征方向上恰好走 $1/\lambda_i$ |

三个立即可用的推论：

1. **二次型一步收敛**：若 $f$ 本身就是二次函数，泰勒展开没有截断误差，牛顿步直达最小值——例题马上验证；
2. **梯度下降是冒牌牛顿**：把 $H^{-1}$ 换成单位阵 $I$，牛顿步就退化为 $x-\eta g$。GD 相当于假装所有方向曲率相同；
3. **不正定会翻车**：$H$ 有负特征值时 $-H^{-1}g$ 可能指向**上坡**。实用修正是阻尼一步：改走 $x_{k+1}=x_k-(H+\lambda I)^{-1}g$——$\lambda$ 调大，牛顿就温顺地退回梯度下降。

拟牛顿的念头由此而来：既想要 $H^{-1}$ 的好处，又不想付"算 $H$、存 $H$、求逆"三笔账——那就用每一步的位移对（走了多远 $s$、梯度变了多少 $y$）逐步把曲率**估**出来，代表算法叫 BFGS，第 5 节实验亲测。

## 4. 分步例题

**例 1**：目标 $f(x,y)=2x^2+2xy+2y^2$（Hessian $H=\begin{pmatrix}4&2\\2&4\end{pmatrix}$，处处正定），从 $x_0=(4,2)$ 出发走一步牛顿。

1. **算梯度**：$\nabla f=(4x+2y,\ 2x+4y)$，代点得 $g=(20,\ 16)$；
2. **求逆**：二阶阵逆公式 $\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$，$\det H=12$，故 $H^{-1}=\frac{1}{12}\begin{pmatrix}4&-2\\-2&4\end{pmatrix}$；
3. **乘出步长**：$H^{-1}g=\frac{1}{12}(80-32,\ -40+64)=(4,\ 2)$；
4. **迈步**：$x_1=(4,2)-(4,2)=(0,0)$——精确落在唯一谷底，$f(0,0)=0$。一步，无锯齿。

**例 2**：同一片病态山谷 $f=10x^2+y^2$，梯度下降步长 $\alpha=0.09$，起点 $(4,\ 0.8)$：

| 步数 $k$ | $x_k$ | $y_k$ | 损失 |
| --- | --- | --- | --- |
| 1 | $-3.2$ | $0.656$ | $102.83$ |
| 2 | $2.56$ | $0.5379$ | $65.83$ |
| 3 | $-2.048$ | $0.4411$ | $42.14$ |
| 20 | $0.0461$ | $0.0151$ | $0.0215$ |
| 牛顿 1 步 | $0$ | $0$ | $0$ |

注意 $x_k$ 的**符号每步翻转**：$0.09\times20=1.8>1$，陡方向每步乘 $(1-1.8)=-0.8$，来回横跳；缓方向乘 $0.82$ 慢慢蹭。二十步才把损失磨到 $0.02$，而牛顿一步归零——这正是例 1 结构的复写：$H^{-1}$ 把陡方向的大曲率除掉，谁也不用再迁就谁。

### 实验 2：锯齿、临界与发散——步长的毫厘之差

同一座山谷，三个步长只差百分之几，命运完全不同；最后让牛顿上场收尾：

```python title="GD 三档步长对质牛顿一步"
def gd(alpha, steps):                     # 定义一个跑 GD 的函数，参数是步长与步数
    x, y = 4.0, 0.8
    trail = []                            # 空列表：准备记录轨迹
    for k in range(steps):
        x = x - alpha * 20 * x            # f=10x^2+y^2 的两个偏导是 20x 与 2y
        y = y - alpha * 2 * y
        trail.append((round(x, 4), round(y, 4)))
    return trail

for a in (0.09, 0.10, 0.11):              # 三档步长：0.1 是陡方向的稳定临界
    t = gd(a, 20)
    print("alpha =", a, "第 1 步:", t[0], "| 20 步后:", t[-1])

x, y = 4.0, 0.8
x, y = x - 20 * x / 20, y - 2 * y / 2     # 牛顿一步：H=[[20,0],[0,2]]，逆是对角阵
print("牛顿一步落点:", x, y)
```

三行战报：$\alpha=0.09$ 第一步就翻到 $-3.2$（锯齿但还收敛）；$\alpha=0.10$ 恰在临界上，$x$ 的振幅一步不衰、永远横跳；$\alpha=0.11$ 每步放大 $1.2$ 倍，二十步后 $x=153.35$——**发散**。而牛顿一步 $(0.0,\ 0.0)$，连学习率这个参数都不存在。

### 实验 3：BFGS 两轮逼近逆 Hessian

不真算 Hessian，只用每步的位移 $s$ 与梯度变化 $y$ 更新一个近似 $M\approx H^{-1}$（BFGS 更新式），看看两轮之后它像不像真货：

```python title="BFGS 更新式：位移对喂出曲率"
def matvec(M, v):                         # 矩阵乘向量：两行各做一次点乘
    return [M[0][0] * v[0] + M[0][1] * v[1], M[1][0] * v[0] + M[1][1] * v[1]]

def dot(u, v):                            # 点乘：对应位置相乘再相加
    return u[0] * v[0] + u[1] * v[1]

H = [[4.0, 2.0], [2.0, 4.0]]              # 装作不知道它，只借它产梯度
p, M = [1.0, 0.0], [[1.0, 0.0], [0.0, 1.0]]   # 起点，近似阵从单位阵起步
for it in range(2):
    g = matvec(H, p)                      # 问一阶导（拟牛顿只消费梯度）
    Mg = matvec(M, g)
    d = [-Mg[0], -Mg[1]]                  # 沿近似阵的负梯度方向
    Hd = matvec(H, d)
    alpha = -dot(g, d) / dot(Hd, d)       # 精确线搜索：二次型上步长有闭式解
    p_new = [p[0] + alpha * d[0], p[1] + alpha * d[1]]
    g_new = matvec(H, p_new)
    s = [p_new[0] - p[0], p_new[1] - p[1]]       # 位移：这步走了多远
    yk = [g_new[0] - g[0], g_new[1] - g[1]]      # 梯度变化：坡度改了多少
    ys = dot(yk, s)                       # 位移对：曲率沿这一步的读数
    My = matvec(M, yk)
    rho = 1 + dot(yk, My) / ys            # BFGS 更新式（近似逆 Hessian 版）
    for i in range(2):
        for j in range(2):
            M[i][j] += (rho * s[i] * s[j] - My[i] * s[j] - s[i] * My[j]) / ys
    p = p_new
    print(f"轮{it + 1}: p=({p[0]:.4f}, {p[1]:.4f})",
          f"M=[[{M[0][0]:.4f},{M[0][1]:.4f}],[{M[1][0]:.4f},{M[1][1]:.4f}]]")
print("H^{-1} 真值 = [[0.3333,-0.1667],[-0.1667,0.3333]]")
```

第二轮打印的 $M$ 与真值**逐元素一致**，位置也恰好踩到 $(0,0)$：两维二次型，两次更新恰好榨干全部曲率信息。真实求解器还会加线搜索保护与非正定兜底，但"用一阶位移喂出二阶曲率"这个核心动作，十行就是全部。

### 快问快答

```quiz
在病态山谷里，梯度下降举步维艰的根源是什么？
- 学习率永远设不大
- 各方向曲率悬殊，一个步长伺候不了两种陡峭 [*]
- 梯度的方向总是算错
? 陡方向把步长上限压死，缓方向却渴求大步。牛顿步把每个方向的步长重标成 1/λ，曲率差距被倒数抹平。
```

::::warning[常见误区]

**误区一**："牛顿法永远比梯度下降快。" 单步看是碾压，总账要看代价：$H$ 的计算与存储是 $O(n^2)$、求逆是 $O(n^3)$——百万参数的网络里这是天文数字，所以深度学习退回一阶方法打天下。牛顿的主场是中小规模、二阶导好算的光滑问题。

**误区二**："H 不正定，牛顿法就死机了。" 死机不至于，是**方向可能掉头**（负曲率方向被指成下坡）。加阻尼 $(H+\lambda I)^{-1}$ 就地修复：$\lambda$ 从 0 调大，负特征值被逐渐垫正，极端情形平滑退化为梯度下降。

**误区三**："拟牛顿也是二阶方法，所以也得算 Hessian。" 恰恰相反——BFGS 全程只碰**一阶梯度**，曲率是从位移对 $(s, y)$ 里差分出来的。它叫"拟"牛顿，是因为吃到 $H^{-1}$ 的红利，而不是付了二阶导的账单。

::::

## 6. 练习

**练习 1**（概念）：用"每个方向自己的步长 $1/\lambda_i$"解释：为什么病态山谷里 GD 会锯齿，牛顿法却不会？

<details>
<summary>点开查看逐步解答</summary>

GD 各方向统一乘 $(1-\alpha\lambda_i)$：想让陡方向 $|\,1-\alpha\lambda_{\max}\,|<1$，$\alpha$ 就被 $\lambda_{\max}$ 压死；于是缓方向的因子 $(1-\alpha\lambda_{\min})$ 几乎不缩水——要么锯齿（$\alpha$ 大到陡方向翻面），要么龟速（$\alpha$ 小到缓方向寸行）。牛顿步在每个特征方向上恰走 $1/\lambda_i$：陡方向迈小步、缓方向迈大步，一步把椭圆地形"捏"成圆——没有任何方向需要迁就别的方向。
</details>

**练习 2**（判题）：一维也算牛顿：求 $g(x)=e^x-2x$ 的最小值点（即解 $e^x=2$，真值 $\ln 2\approx 0.6931$）。初始代码把更新式的除法写反了，跑起来会一路狂奔——修好后让两行输出命中：

## 7. 选读：为什么二次型一步收敛，以及不存 H 的第三条路

<details>
<summary>选读 · 一步收敛的证明与共轭梯度定位</summary>

若 $f$ 是二次型 $f(x)=\tfrac12(x-x^*)^{\mathsf T}H(x-x^*)$（$H$ 正定），则 $\nabla f(x)=H(x-x^*)$ 处处精确，牛顿步 $x-H^{-1}H(x-x^*)=x^*$ 一步命中——泰勒展开没有任何截断，近视镜里的抛物面就是真实地形。非二次函数上牛顿法是"局部二次型 + 反复重算"的迭代，经典结论是二阶收敛：误差位数每轮翻倍。

BFGS 有个漂亮的有限步性质：$n$ 维二次型配精确线搜索，最多 $n$ 次更新 $M$ 严格等于 $H^{-1}$——实验 3 的两轮对拍就是 $n=2$ 的现场。若连 $M$ 都不想存，还有共轭梯度法：只用一阶梯度与线搜索，让相邻搜索方向互相"共轭"（广义垂直），同样保证 $n$ 步精确解出 $n$ 维二次型——它是不存任何矩阵的"二阶红利代餐"，大规模稀疏问题的常客。本书点到定位为止，细节超出本书范围。

</details>
