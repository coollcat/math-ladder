# 内点法

## 1. 从一个场景开始

上一课单纯形法沿着多边形的边从顶点跳到顶点，几千个变量的规划问题眨眼就跑完。但如果约束有一百万条——比如全国电网的潮流调度——顶点数可能比宇宙中的原子还多，沿边爬山就变成了在沙漠里数沙粒。

1984 年贝尔实验室的 Karmarkar 提出了一种截然不同的走法：**不走边界，直接钻进可行域内部**，像在迷宫里架了一架直升机——不摸墙，从空中看路。这就是内点法（Interior Point Method）的起点。

## 2. 直觉解释

还记得上一课的等值线平移吗？木板从远处贴过来，最后碰到了顶点。内点法换了个玩法：它在可行域的**内部**放一颗球，让这颗球同时被所有约束墙推着、又被目标等值线拉着。球的平衡位置不是墙角，而是内部的某个"甜点"。

障碍函数就是那面"不让你碰墙"的隐形力场——离墙越近，斥力越猛，代价指数爆炸。它把有界的可行域"压缩"成无界的，让你永远在内部游荡却不会撞墙。

随着力场逐渐衰减（障碍参数 $\mu\to0$），这颗球被目标函数越拽越靠近最优墙角。球的轨迹画出一条弯弯的曲线，从可行域中心蜿蜒走向最优顶点——这条曲线叫**中心路径**（central path）。内点法就是沿着这条路径走迷宫的导航仪。

## 3. 正式定义

考虑线性规划标准形（沿用上一课的符号）：

$$\min\; c^{\mathsf T}x \quad \text{s.t.}\; Ax=b,\; x\ge0$$

**障碍函数**：对不等式约束 $x_i\ge0$ 添加对数障碍

$$\phi(x)=-\sum_{i=1}^{n}\ln x_i$$

障碍参数 $\mu>0$ 控制斥力强度，合成无约束子问题

$$\min\; \mu\, c^{\mathsf T}x+\phi(x)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mu$ | 障碍参数 | 越小斥力越弱，解越靠近边界 |
| $\phi(x)$ | 对数障碍 | 在 $x_i=0$ 处发散，阻止碰墙 |
| $x(\mu)$ | 中心路径上的点 | $\mu$ 子问题的最优解 |
| $s$ | 对偶松弛变量 | 互补松弛条件 $x_i s_i=\mu$ |

**中心路径**：对每个 $\mu>0$，上述子问题有唯一解 $x(\mu)$，所有这些点连成的曲线就是中心路径。当 $\mu\to0$ 时 $x(\mu)$ 收敛到原问题的最优解。

**互补条件**：在中心路径上满足 $XSe=\mu e$，其中 $X=\operatorname{diag}(x)$，$S=\operatorname{diag}(s)$，$e$ 是全 1 向量。

## 4. 分步例题

继续用上一课的例子：$\min\;-3x_1-2x_2$，约束 $x_1+x_2\le4$，$x_1+3x_2\le6$，$x_1,x_2\ge0$（改成 min 方便写障碍）。

1. 加松弛变量写等式：$x_1+x_2+s_1=4$，$x_1+3x_2+s_2=6$，$x_1,x_2,s_1,s_2>0$；
2. 取 $\mu=2$，解障碍子问题：令梯度 $\nabla(\mu c^{\mathsf T}x+\phi)=0$，得 $-\mu c_i+1/x_i=0$，即 $x_i=1/(\mu c_i)$——注意 $c$ 带负号，所以 $x_1=1/6$、$x_2=1/4$，再代入等式求 $s$；
3. 取 $\mu=0.5$，同样步骤得 $x_1=1/1.5\approx0.667$、$x_2=1/1.0=1$，更靠近边界了；
4. 取 $\mu=0.05$，$x_1\approx3.33$、$x_2\approx2.0$——已经贴近最优 $(4,0)$ 的方向；
5. 当 $\mu\to0$ 时，中心路径把我们拽到 $(4,0)$，目标值 $-12$——和单纯形法的答案一模一样，但全程没碰过任何一面墙。

### 实验 2（python）：追踪中心路径

```python title="用牛顿法追踪中心路径，看迭代点如何从内部逼近最优顶点"
import math

def phi(x1, x2, mu):
    """障碍子问题的目标：mu*c^T x 减去 mu 倍的障碍项
    障碍项把两条不等式约束的松弛变量也算进来：
    s1 = 4 - x1 - x2、s2 = 6 - x1 - 3*x2，都必须严格为正
    """
    s1 = 4 - x1 - x2
    s2 = 6 - x1 - 3 * x2
    return -3 * x1 - 2 * x2 - mu * (math.log(x1) + math.log(x2) + math.log(s1) + math.log(s2))

def grad_hess(x1, x2, mu):
    """梯度与 Hessian（2×2，手推：把 s1、s2 也当 x 的函数求导）
    d/dx1 的部分：-3 - mu/x1 + mu/s1 + mu/s2
    """
    s1 = 4 - x1 - x2
    s2 = 6 - x1 - 3 * x2
    g1 = -3 - mu / x1 + mu / s1 + mu / s2
    g2 = -2 - mu / x2 + mu / s1 + 3 * mu / s2
    h11 = mu * (1 / (x1 * x1) + 1 / (s1 * s1) + 1 / (s2 * s2))
    h22 = mu * (1 / (x2 * x2) + 1 / (s1 * s1) + 9 / (s2 * s2))
    h12 = mu * (1 / (s1 * s1) + 3 / (s2 * s2))
    return g1, g2, h11, h12, h22

# 沿中心路径追踪：mu 从 2 衰减到 0.001
x1, x2 = 0.5, 0.5          # 从可行域内部出发
mu = 2.0
path = [(x1, x2)]

while mu > 0.001:
    for _ in range(6):                       # 每个 mu 下做几步阻尼牛顿
        g1, g2, h11, h12, h22 = grad_hess(x1, x2, mu)
        det = h11 * h22 - h12 * h12
        d1 = (-g1 * h22 + g2 * h12) / det    # 解 2×2 方程组 H·d = -g
        d2 = (-g2 * h11 + g1 * h12) / det
        t = 1.0                              # 回溯直线搜索：保证一步不跨出边界
        while t > 1e-6:
            n1, n2 = x1 + t * d1, x2 + t * d2
            if (n1 > 0 and n2 > 0 and 4 - n1 - n2 > 0 and 6 - n1 - 3 * n2 > 0
                    and phi(n1, n2, mu) <= phi(x1, x2, mu)):
                break
            t = t * 0.5
        x1, x2 = x1 + t * d1, x2 + t * d2
    path.append((x1, x2))
    mu = mu * 0.5            # mu 每次减半

print("中心路径轨迹（每个 mu 一个点）:")
for i, (a, b) in enumerate(path):
    print(f"  mu≈{2 * (0.5 ** i):.4f}: x=({a:.3f}, {b:.3f})  目标={-3 * a - 2 * b:.3f}")
print(f"终点: x=({x1:.3f}, {x2:.3f})")
print(f"目标值: {-3 * x1 - 2 * x2:.3f}")  # 应接近 -12
```

运行结果：迭代点从 $(0.5, 0.5)$ 出发，沿中心路径逐步逼近 $(4.0, 0.0)$ 附近，目标值趋近 $-12$。全程 $x_1, x_2$ 始终为正——**没有一次碰过约束边界**，这正是"内点"之名的由来。

:::tip[这版代码为什么把 s₁、s₂ 也算进障碍项]
只对 $x_1,x_2>0$ 加障碍是不够的：那等于扔掉了 $x_1+x_2\le4$ 与 $x_1+3x_2\le6$，
子问题就变成无下界的 $\min -3x_1-2x_2$（$x$ 越大越好），牛顿法会一路冲到溢出、
`h = 1/x²` 变成 0 直接抛 ZeroDivisionError。
把两条不等式约束的松弛变量一起加进对数障碍，子问题才有唯一极小点，
中心路径也才真的通向 $(4,0)$——上表里每一行的目标值都在朝 $-12$ 靠近就是证据。
:::

### 快问快答

```quiz
内点法与单纯形法最大的结构差异是什么？
- 内点法用矩阵乘法，单纯形法用加减法
- 内点法在可行域内部行走，单纯形法在边界顶点间跳跃 [*]
- 内点法只能解线性规划
? 单纯形法沿多边形的边从顶点跳到顶点；内点法从内部出发、沿中心路径逼近最优。两条路各有适用场景，现代求解器常常两者并用。
```

:::warning[常见误区]

**误区一**："内点法比单纯形法快，所以单纯形法过时了。" 内点法的多项式复杂度保证了最坏情形的理论优势，但工程实践中单纯形法在中小规模问题上常更快——它能做热启动（改几条约束后从旧解继续），内点法每次要从头走中心路径。两者在商业求解器里是队友，不是替代关系。

**误区二**："障碍函数真的把约束删掉了。" 没有删，只是用指数惩罚把约束"软化"了——$x_i$ 不能真的等于零，只能无限接近。最终解在极限意义上才满足原始等式约束。实际实现中要设一个容忍度（比如 $\mu<10^{-8}$）才收工。

**误区三**："中心路径是直线。" 它是弯的——障碍函数是非线性的，子问题的最优解随 $\mu$ 变化走出来的轨迹通常是曲线。只有在极特殊的对称问题上才碰巧是直线。

:::

## 6. 练习

**练习 1**（概念）：为什么对数障碍用 $-\ln x$ 而不用 $1/x$？提示：比较两者在 $x\to0^+$ 时的梯度行为。

<details>
<summary>点开查看逐步解答</summary>

$-\ln x$ 在 $x\to0^+$ 时趋向无穷，梯度 $-1/x$ 也趋向无穷，但二阶导 $1/x^2$ 始终为正——保证了凸性。$1/x$ 虽然也趋向无穷，但它的二阶导 $2/x^3$ 在数值上增长更快，导致牛顿步长不稳定。对数障碍的"温和爆炸"恰好让牛顿法在中心路径上每步都有良好的收敛速率。
</details>

**练习 2**（判题）：下面的代码想实现内点法的核心迭代，但障碍参数的更新方向搞反了——修好它让终点逼近最优。

```exercise
# @title: 练习：修好内点法的 mu 衰减
# @check: 4.000
# @check: -12.000
# @hint: mu 应该从大到小衰减（乘以小于 1 的因子），这样障碍斥力逐渐减弱，解才趋向边界上的最优。
x1, x2 = 1.0, 1.0
mu = 1.0

for _ in range(50):
    for _ in range(10):
        g1 = -3 * mu - 1 / x1
        g2 = -2 * mu - 1 / x2
        h1 = 1 / (x1 * x1)
        h2 = 1 / (x2 * x2)
        x1 = x1 - g1 / h1
        x2 = x2 - g2 / h2
        x1 = max(x1, 1e-10)
        x2 = max(x2, 1e-10)
    mu = mu * 2.0            # ← 错了：mu 在膨胀而不是衰减

print(round(x1, 3))
print(round(-3 * x1 - 2 * x2, 3))
```

把 `mu * 2.0` 改成 `mu * 0.5` 后，输出 `4.000` 和 `-12.000`：障碍从强到弱、解从中心走到最优顶点。

**练习 3**（选做）：本课的牛顿迭代忽略了等式约束 $Ax=b$。如果真的要同时满足等式约束，需要在牛顿步中解一个带约束的线性系统。写出这个系统的 KKT 条件。

<details>
<summary>点开查看逐步解答</summary>

在中心路径上，KKT 条件为 $\mu c+X^{-1}e-A^{\mathsf T}\lambda=0$ 和 $Ax=b$，其中 $\lambda$ 是等式约束的拉格朗日乘子。牛顿步需要解一个 $(n+m)\times(n+m)$ 的线性系统（$n$ 个原变量、$m$ 个乘子），矩阵结构是 $\begin{pmatrix} X^{-2} & -A^{\mathsf T} \\ A & 0 \end{pmatrix}$——这就是实际求解器的核心计算量所在。
</details>

## 7. 选读：为什么内点法是多项式时间的

<details>
<summary>选读 · 复杂度简析</summary>

单纯形法的最坏复杂度是指数级的——Klee-Minty 反例构造了一个超立方体可行域，让单纯形法遍历所有 $2^n$ 个顶点。内点法绕过了这个陷阱：它不需要枚举顶点，而是沿中心路径用牛顿法迭代。

关键在于牛顿法的二次收敛性：在中心路径附近，每个 $\mu$ 下只需 $O(1)$ 步牛顿迭代就能达到足够精度。$\mu$ 从 $O(n)$ 衰减到 $O(\varepsilon)$ 需要 $O(n\log(1/\varepsilon))$ 次外层迭代，每次迭代的线性系统求解成本是 $O(n^3)$ 或更低（利用稀疏性）。总复杂度 $O(n^{3.5}\log(1/\varepsilon))$，1984 年震惊了整个优化界——这是第一个线性规划的多项式时间实用算法。

实际求解器（如 Gurobi、MOSEK）在内层用预测-校正步（Mehrotra 方法），在 $\mu$ 的选择上做自适应调整，使得常数因子远小于理论上限。
</details>
