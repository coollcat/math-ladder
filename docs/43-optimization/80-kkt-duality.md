# KKT 条件与对偶问题

## 1. 从一个场景开始

你在两个渠道投放广告，投入 $x,y$（单位：百万元），运营成本随投入平方增长 $x^2+y^2$——钱越花越贵。平台的硬规矩是：**总投放至少要达到 2**，否则不给流量扶持。

第 40 课的拉格朗日乘数法对付的是"总投放恰好等于 2"这种等式镣铐；可现实里的规矩几乎都长着不等号：预算不许超、产量至少达标、库存不能为负。不等号带来两种新局面——有些墙压根没碰到，有些墙被死死顶住。怎么判断墙的状态、怎么给墙定罪或赦免？答案是本课的主角：**KKT 条件**四道关卡，外加一个站在对手席位上的角色——**对偶问题**。

## 2. 直觉解释

先看懂不等号的脾气。问题变成 $\min x^2+y^2,\ x+y\ge 2$ 之后：

- 无约束时的谷底 $(0,0)$ 成本为零，可惜它在**墙外**（违反 $x+y\ge2$）；
- 于是最优解只能贴着墙站——就是第 40 课那个相切瞬间；
- 既然有墙顶着谷底往回推，这份"推力"必须存在且**方向合法**（$\lambda>0$）。反过来，假如无约束谷底本来就在界内，约束整堵墙形同虚设——此刻没有推力，$\lambda=0$。

这就是**互补松弛**的两档开关：要么墙没起作用（$\lambda=0$），要么乘子登场（$\lambda>0$ 且必贴墙）。两者同时成立是允许的，唯独不存在"没碰墙却憋着一股劲"或"顶着墙却宣称没用力"的矛盾状态。

对偶则是换个席位做买卖：你求最优成本，谈判对手只想给出一个**永远不超过真成本的保底报价**。他手里只有一个旋钮 $\lambda$——抬价需要付"乘子的租金"。凸的世界里公平公正：真最优恰好是对手能报出的最高价，一分不多一分不少。

## 3. 正式定义

标准形沿用第 10 课的约定：目标最小化，约束全部写成 $g_i(x)\le 0$。"至少"型要先翻面：$x+y\ge 2$ 等价于 $g(x,y)=2-x-y\le 0$——这一步是所有后续符号的地基。

**拉格朗日函数**与**对偶函数**：

$$L(x,\lambda)=f(x)+\sum_i \lambda_i g_i(x),\qquad q(\lambda)=\min_x L(x,\lambda)$$

最优点 $(x^\ast,\lambda^\ast)$ 必须同时通过 **KKT 四条件**：

| 条件 | 内容 | 白话 |
| --- | --- | --- |
| 平稳性 | $\nabla_x L=0$ | 站稳脚跟 |
| 原始可行 | $g_i(x)\le 0$ | 不许违规 |
| 对偶可行 | $\lambda_i\ge 0$ | 推力方向合法（墙上推、不拉） |
| 互补松弛 | $\lambda_i\, g_i(x)=0$ | 开关不同时开 |

**弱对偶定理**（几乎无条件成立）：对一切 $\lambda\ge 0$，

$$q(\lambda)\;\le\; f(x^\ast)$$

当问题为凸且存在严格可行点（Slater 条件）时，差额归零：$q(\lambda^\ast)=f(x^\ast)$，称为**强对偶**。对偶妙用之一在灵敏度：$\lambda_i$ 仍是影子价格——放松哪条约束最划算，看谁的乘子大。

## 4. 分步例题

**例**：完整走一遍场景里的玩具问题：$\min x^2+y^2$，s.t. $x+y\ge2$。

1. **转标准型**：$g=2-x-y\le0$，拉格朗日函数 $L=x^2+y^2+\lambda(2-x-y)$；
2. **平稳性**：$\partial L/\partial x=2x-\lambda=0$，$\partial L/\partial y=2y-\lambda=0$，解出 $x=y=\lambda/2$；
3. **分情况讨论互补松弛**（两档开关）：档一 $\lambda=0$ → 得 $x=y=0$，代回检验 $g=2>0$ 违反原始可行——**出局**；
4. **档二**：$g=0$（贴墙）→ 由 $2-x-y=0$ 与第 2 步得 $2-\lambda=0$，即 $\lambda=2$、$x=y=1$；逐条核对四条件全部通过 ✓；
5. **读出答案**：最优成本 $f^\ast=1+1=2$；影子价格 $\lambda^\ast=2$——门槛从 2 抬到 3，成本从 2 涨到 4.5：线性预估只报 $2\times1=2$ 的涨幅，多出来的 $0.5=(3-2)^2/2$ 是曲率的二阶修正；
6. **让对手报价**：内层先最小化 $x^2-\lambda x+y^2-\lambda y$（配方），得 $q(\lambda)=2\lambda-\dfrac{\lambda^2}{2}$。它是开口向下的抛物线，峰顶恰在 $\lambda=2$、峰值为 $2=f^\ast$ ——对手的最高保底价与你算的真成本**成交**，弱对偶升级成强对偶。

留意第 6 步的对称美：$q(0.5)=0.875$ 和 $q(3.5)=0.875$ 相等——偏离峰顶无论左右，报价只会变差。

### 实验 2：四条件体检台 + 对偶报价扫描

```python title="KKT 四条件逐条验收，再扫一遍对偶报价"
px, py = 1.0, 1.0                 # 宣称的最优点（先口头宣判，程序逐条验收）
lam = 2.0                         # 宣称的乘子

c1 = abs(2 * px - lam) < 1e-9 and abs(2 * py - lam) < 1e-9   # 平稳性：梯度整体归零
c2 = 2 - px - py <= 1e-9                                      # 原始可行：不得越界
c3 = lam >= 0                                                 # 对偶可行：只推不拉
c4 = abs(lam * (2 - px - py)) < 1e-9                          # 互补松弛：开关不同时开
print("平稳性:", c1, "| 原始可行:", c2, "| 对偶可行:", c3, "| 互补松弛:", c4)

def q(la):                        # 对偶函数：先把 x,y 这一层最小掉
    return 2 * la - la * la / 2

for la in [0.5, 2.0, 3.5]:        # 三份代表性报价单
    print("lambda =", la, "-> 保底 q =", round(q(la), 4))

best_lam, best_q = None, None     # 在 0 到 4 区间细扫，寻找最强保底价
honest = True                     # 记录是否出现“报价高过真最优”的丑闻
k = 0
while k <= 32:                    # 双保险写法：33 个报价点扫完即停
    la = k * 0.125                # 步长 0.125 的报价网格
    v = q(la)
    if best_q is None or v > best_q:
        best_q, best_lam = v, la  # 第一次总能进入；之后只保留更高保底
    if v > 2 + 1e-9:
        honest = False            # 只要有一格突破 2，弱对偶就翻了车
    k = k + 1
print("最强保底出现在 lambda =", best_lam, "值为", round(best_q, 4))
print("全程未突破真最优:", honest)
```

输出四条 `True` 同框出场；报价清单里 $\lambda=0.5$ 与 $3.5$ 都只有 $0.875$、峰顶 $\lambda=2.0$ 报出 $2.0$；网格扫描确认最强保底正中 $\lambda=2$、数值恰为真最优，并且没有任何一格突破 $2$——理论与程序双向闭环。

### 快问快答

```quiz
关于互补松弛 lambda*g=0，下列理解正确的是？
- 乘子和松弛量必须同时为零
- 每条约束都是二选一：要么没被贴住（对应乘子为零），要么贴死了墙（此时乘子可以大于零） [*]
- 它说明最优解永远在可行域内部
? 贴墙与否决定乘子生死：内部最优的约束全体哑火；只有真正发力的约束才配得上非零影子价格。
```

:::warning[常见误区]

**误区一**："拉格朗日函数照抄第 40 课，令偏导为零就行。" 等式版少了两件武器：$\lambda$ 必须非负、乘子与约束的搭配要过互补松弛。漏检这两项就会把不可行点当成最优——第 40 课的误区三在此正式兑现为课程。

**误区二**："符号约定是小事，公式的骨架对就行。" 有的教材写 $L=f-\lambda g$、约束取 $g\ge0$：照搬别家的公式而错配自家的约定，$\lambda$ 的符号立刻颠倒。动笔前先核对约定，胜过事后排查半天。

**误区三**："对偶报价最后总会等于真最优。" 那是凸问题的优待。非凸问题里缺口可能很宽：对手的保底再精明也够不着真值。弱对偶永远免费赠送，强对偶要看行情（凸性加 Slater）。

:::

## 6. 练习

**练习 1**（概念）：仓库选址线段版，成本 $f(x)=(x-4)^2$。情形甲：许可区 $x\ge1$（即 $g=1-x\le0$）；情形乙：禁区另一侧 $x\le1$（即 $g=x-1\le0$）。分别说出两道题里 KKT 条件的通场方式。

<details>
<summary>点开查看逐步解答</summary>

无约束最优都在 $x=4$。情形甲：$4\ge1$ 本来合法，最优留在 4、约束没碰墙——对偶可行自动满足、互补松弛由 $\lambda=0$ 兑现，这叫**inactive 案卷**。情形乙：4 出界，只能贴到 $x=1$；平稳性 $2(x-4)+\lambda=0$ 代入得 $\lambda=6>0$，四条件合规——**active 案卷**，影子价格 6 表示"禁区每放宽一米，成本约省 6"。有趣的是两案的最优值同为 9，差的只是那条墙扮演的角色。
</details>

## 7. 选读：强对偶为什么会在凸世界成交

<details>
<summary>选读 · 分离线的直觉一句话</summary>

把每个可行的 $x$ 映射成平面上的点 $(f(x),\ \lambda\cdot g(x))$——横轴是真值，纵轴是带惩罚的成绩。原问题的目标是压低横坐标，对偶问题从纵轴出发要求兜底；在凸问题里这两团点的分离直线恰好能摆到同时触碰两者的位置，于是 $q(\lambda^\ast)$ 与 $f(x^\ast)$ 会师，缺口清零。Slater 条件的作用只是保证这条分离线放得下去（存在严格内点，腾出调整余地）。这一机制的两个著名舞台：支持向量机把分类 margin 写成带不等式约束的凸二次规划，其稀疏支持向量正是互补松弛挑出来的"贴墙样本"；下一课的线性规划则在目标与约束全线笔直时，把对偶理论推演到可以在顶点上见分晓的程度——那里也是本套机器最漂亮的展示柜。

</details>
