# EM 算法：隐变量的坐标上升

## 1. 从一个场景开始

罐子里装着两枚不均匀的硬币 A 和 B，各自"出正面的概率"是未知数。每一轮你伸手抓一枚（抓到谁各占一半）、抛十次、记下正反面，再把硬币丢回罐里。几轮之后你手上攥着五串正反面——**每一轮用的是哪枚，没记，也永远补记不了**。

单枚硬币的偏置你本来会估：第 38 章的[最大似然估计：让数据为自己说话](../38-statistical-inference/50-mle.md)说过，抛十次出几个正面，偏置就往那个频率上猜。可现在账搅在了一起：那串「正正正反反……」到底是 A 抛的还是 B 抛的？不知道归谁，"数频率"三个字就落不了地——MLE 的打分机没坏，坏的是账本：**参数有两套，数据不知道记在谁名下**。

处理这种"糊涂账"的经典机器叫 EM 算法。这一课把它拆开看：其实是一对坐标上升——只是坐标不是 $x$ 和 $y$，而是"看不见的指派"与"看得见的参数"。

## 2. 直觉解释

先看清卡在哪里。假如知道每组归谁，估计就是"分组数频率"，小学难度；假如知道两枚硬币的偏置，判断每组归谁也不难——比一比两套剧本下谁更像这串数据（第 36 章贝叶斯的后验）。**偏偏是一边缺一半**：估参数需要指派，算指派又需要参数，鸡生蛋、蛋生鸡。

EM 的回答：先胡乱猜一组参数，然后让鸡和蛋轮流当起点，交替往前滚——

- **E 步（记账）**：按当前猜测给每组数据"分账"。不硬判归属，而是按把握比例记：这组九成像 A、一成像 B，就把九成正面记在 A 名下、一成记在 B 名下；
- **M 步（算账）**：每枚硬币只看自己名下的账数频率，给出新偏置——又回到小学难度；
- 新参数让下一轮的账分得更准，账越准、参数越贴心。滚雪球式交替，且每滚一轮，数据在模型眼里的"可能性"都更大一点。

一句话预告困难所在：把五组数据的可能性乘起来取对数，对数里面裹着一个"加号"——单硬币时代"对数摊平乘法"的好日子结束了。怎么在"和"上求导、怎么绕开它，正是接下来两节的主题。

## 3. 正式定义

记两组参数与一份看不见的东西：

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\theta_A,\ \theta_B$ | 两枚硬币的偏置 | 各自抛出正面的概率，待估 |
| $\pi$ | 抓到 A 的先验概率 | 每轮抓硬币时抓中 A 的机会，本课取 $1/2$ |
| $z_i$ | **隐变量** | 第 $i$ 组数据到底是谁抛的——看不见，$z_i\in\lbrace A,B\rbrace$ |
| $h_i,\ n_i$ | 正面数与抛掷数 | 第 $i$ 组的观测数据，本课 $n_i=10$ |
| $r_i$ | 责任（responsibility） | E 步算出的 $P(z_i=A\mid\text{数据}_i)$：第 $i$ 组归 A 的份额 |

五组数据的似然——每组是"A 剧本 + B 剧本"两种可能**相加**，五组之间相乘：

$$L=\prod_{i=1}^{5}\Big[\pi\,\theta_A^{h_i}(1-\theta_A)^{n_i-h_i}+(1-\pi)\,\theta_B^{h_i}(1-\theta_B)^{n_i-h_i}\Big]$$

第 38 章单硬币时，对数把乘法摊成加法、求导清清爽爽；如今对数里裹着加号，$\log(u+v)$ 没有拆解公式，求导后分母永远拖着一个五组共享的"和"——闭式解出不来，梯度下降也写不出干净的梯度。

EM 用两步闭式操作绕开这座山。**E 步**（固定参数，算责任；先验 $\pi$ 在分子分母间约掉）：

$$r_i=\frac{\theta_A^{h_i}(1-\theta_A)^{n_i-h_i}}{\theta_A^{h_i}(1-\theta_A)^{n_i-h_i}+\theta_B^{h_i}(1-\theta_B)^{n_i-h_i}}$$

**M 步**（固定责任，闭式更新；"加权数频率"）：

$$\theta_A^{\text{新}}=\frac{\sum_i r_i\,h_i}{\sum_i r_i\,n_i},\qquad \theta_B^{\text{新}}=\frac{\sum_i (1-r_i)\,h_i}{\sum_i (1-r_i)\,n_i}$$

两个坐标轮流登顶：E 步固定参数，把隐变量的**软指派**调到当前最优；M 步固定软指派，把参数送到该指派下的最大似然（第 38 章的数频率）。这就是**坐标上升**——对照第 30 课的梯度下降：不求导、没有学习率旋钮，每一步把一个坐标直接放到该坐标上的最高点，并且每一轮似然都单调不降（第 8 节选读给原因）。

## 4. 分步例题

正式数据十抛一组太长，先拿两组短数据（每组只抛 4 次）手算一轮 E + M：组 1 是「3 正 1 反」，组 2 是「1 正 3 反」。初始猜测 $\theta_A=3/4$、$\theta_B=1/4$，先验各半。

1. **E 步·组 1**：A 剧本打分 $(3/4)^3\times(1/4)=27/256$；B 剧本打分 $(1/4)^3\times(3/4)=3/256$。（组合数 $C(4,3)=4$ 与先验 $1/2$ 在两个剧本之间是公因数，相除时抵消。）责任 $r_1=\dfrac{27}{27+3}=\dfrac{9}{10}$；
2. **E 步·组 2**：对称地，$r_2=\dfrac{1}{10}$；
3. **M 步·A**：分子 $=0.9\times3+0.1\times1=2.8$，分母 $=4\times(0.9+0.1)=4$，故 $\theta_A=2.8/4=0.7$；
4. **M 步·B**：分子 $=0.1\times3+0.9\times1=1.2$，故 $\theta_B=1.2/4=0.3$；
5. **复盘**：A 承认了组 2 的一成股份，账本把它从 0.75 拉到 0.70；B 对称地挪到 0.30。这只是一轮——把新参数代回去重新分账、再算账，周而复始，参数一步步挪到更稳的位置（实验 3 会看到全过程）。

### 实验 2（python）：五组数据跑六轮 EM

回到正题的五组十抛数据（正面数 9、1、8、2、5），初始猜测沿用例题的 0.75 与 0.25：

```python title="EM 迭代：看两枚硬币的偏置怎么挪"
heads = [9, 1, 8, 2, 5]        # 五组数据：每组 10 次抛里的正面数
n = 10                         # 每组抛掷次数
ta = 0.75                      # 当前猜测：A 的偏置
tb = 0.25                      # 当前猜测：B 的偏置

for it in range(1, 7):                          # range(1, 7)：it 依次取 1 到 6，共跑 6 轮
    ra = []
    for h in heads:
        sa = ta ** h * (1 - ta) ** (n - h)      # ** 是幂运算：这份数据在"A 剧本"下的打分
        sb = tb ** h * (1 - tb) ** (n - h)
        ra.append(sa / (sa + sb))               # E 步：两份打分归一化成责任；append 把新元素接到列表尾
    num_a = 0
    num_b = 0
    den_a = 0
    den_b = 0
    for i in range(len(heads)):                 # len(heads)：列表长度，这里是 5
        num_a = num_a + ra[i] * heads[i]        # M 步分子：正面数按责任加权
        den_a = den_a + ra[i] * n               # M 步分母：抛掷数按同一份责任加权
        num_b = num_b + (1 - ra[i]) * heads[i]
        den_b = den_b + (1 - ra[i]) * n
    ta = num_a / den_a                          # 闭式更新：一步到位，没有学习率
    tb = num_b / den_b
    print(f"第{it}轮: A={ta:.4f} B={tb:.4f}")   # f-string 把变量嵌进文字；:.4f 表示保留四位小数
```

真机输出：第 1 轮 `A=0.7796 B=0.2204`，第 2 轮 `A=0.7799 B=0.2201`，第 3 轮起四位小数纹丝不动。第 1 轮大步、第 2 轮碎步、然后站定——越接近山顶步子越小，这是坐标上升的典型步态。另有一处细节：9 正与 8 正的两组几乎整组记给 A，可 A 最终停在 0.78 而不是这两组的频率 0.85——那组 5 正 5 反的数据责任恰好是对半 0.5，把 A 和 B 各往中间拽了一把。软指派不扔掉任何一组数据的"一点点话语权"。

### 实验 3（python）：每一轮似然都在爬坡

```python title="EM 的单调台阶：似然只升不降"
import matplotlib.pyplot as plt    # 绘图库：本课首次使用，负责画图

heads = [9, 1, 8, 2, 5]
n = 10
ta = 0.75
tb = 0.25

def mixture_like(a, b):
    # 混合似然：每组「A 剧本 + B 剧本」相加，五组连乘（省略与参数无关的组合数因子，不影响走势）
    p = 1.0
    for h in heads:
        pa = a ** h * (1 - a) ** (n - h)
        pb = b ** h * (1 - b) ** (n - h)
        p = p * (pa + pb)
    return p

likes = [mixture_like(ta, tb)]     # 第 0 轮：初始猜测处的似然
for it in range(6):
    ra = []
    for h in heads:
        sa = ta ** h * (1 - ta) ** (n - h)
        sb = tb ** h * (1 - tb) ** (n - h)
        ra.append(sa / (sa + sb))
    num_a = 0
    num_b = 0
    den_a = 0
    den_b = 0
    for i in range(len(heads)):
        num_a = num_a + ra[i] * heads[i]
        den_a = den_a + ra[i] * n
        num_b = num_b + (1 - ra[i]) * heads[i]
        den_b = den_b + (1 - ra[i]) * n
    ta = num_a / den_a
    tb = num_b / den_b
    likes.append(mixture_like(ta, tb))   # 每轮更新后补测一次似然

fig, ax = plt.subplots(figsize=(7, 3))   # subplots 建画布；figsize 是宽高（英寸）
rounds = list(range(7))                  # list(range(7))：得到 0 到 6 的整数列表
ax.plot(rounds, likes, marker="o")       # marker="o"：每个数据点画成圆点
ax.set_yscale("log")                     # 对数纵轴：似然只有 1e-12 量级，取对数才看得清爬坡
ax.set_xlabel("round")
ax.set_ylabel("likelihood")
ax.grid(True)
```

图像两级台阶：似然从 $6.4\times10^{-12}$ 爬到 $7.2\times10^{-12}$ 后贴平（第 2 轮起曲线已经水平）。对照第 30 课：没有学习率，所以不存在"步子太大跨过谷底"的戏剧性坠崖——坐标上升每一步都踩在该坐标的最高点上，只升不降。

### 快问快答

```quiz
EM 算法每一轮迭代，对数据的似然有什么保证？
- 可能升也可能降，全看学习率怎么调
- 单调不降，而且全程没有学习率这个旋钮 [*]
- 保持不变，只有隐变量的分账在变
? E 步与 M 步合起来每轮都不会让似然变差（选读一节给原因）；M 步是闭式解一步登顶，根本没有步长可言。
```

:::warning[常见误区]

**误区一**："你以为 EM 保证找到最好的那组参数。" 它只保证爬到**最近的**一座峰：局部极值甚至鞍点都可能收留它。实战套路是从多个随机初始猜测各跑一遍，留似然最高的那份答卷。

**误区二**："你以为 E 步是硬猜『这组就是 A 抛的』。" 软指派保留 9 比 1 的把握度，硬砍成 1 会弄丢信息——选做练习里会看到硬指派把 EM 钉死在原地的场面。软硬之差正是 EM 与另一族硬指派算法的分水岭。

**误区三**："你以为初始猜测随便填。" 取 $\theta_A=\theta_B$ 时责任永远是对半 0.5，M 步算回相同的参数——系统被对称性钉死在原地。初始猜测必须打破对称，实验 1 里那条躺平的曲线就是陷阱本身。

:::

按指派把五组数据分成 A 名下和 B 名下两堆，各自数频率：$\theta_A=$ A 名下正面总数除以 A 名下抛掷总数，B 同理——正是第 38 章单硬币 MLE 的原样。再对照 M 步公式：把责任 $r_i$ 全换成 0 或 1（硬指派），加权数频率就退化成普通数频率。**M 步 = "如果指派已知时的 MLE"**，E 步补上的只是"假如"二字：用 0 到 1 之间的责任代替不知道的真相。

**练习 2**（判题）：五组十抛的数据和 E 步算好的责任都给成硬数，请修好 M 步的加权账本，输出两枚硬币更新后的偏置。初始代码里 A 的分子漏乘了责任权重——它把五组的正面全揽到了自己名下：

```exercise
# @title: 练习：修好 M 步的加权账本
# @check: 0.7
# @check: 0.3
# @hint: A 的分子必须按责任 resp 加权——各组正面数乘 resp[i] 才是"替 A 攒下的正面数"。对照组：B 的两行已经写对了，照着补。
heads = [9, 1, 8, 2, 5]              # 五组数据：每组 10 次抛里的正面数
resp = [0.9, 0.1, 0.8, 0.2, 0.5]     # E 步已算好的责任：各组归 A 的概率份额（硬数）

num_a = 0                            # A 的加权正面数（M 步分子）
den_a = 0                            # A 的加权抛掷数（M 步分母）
num_b = 0
den_b = 0

for i in range(5):
    num_a = num_a + heads[i]                   # ← 错了：正面数没乘责任 resp[i]
    den_a = den_a + resp[i] * 10
    num_b = num_b + (1 - resp[i]) * heads[i]   # 对照：B 的分子按 (1-resp) 加权，写对了
    den_b = den_b + (1 - resp[i]) * 10

print(round(num_a / den_a, 2))       # 修复后输出 A 的新偏置，保留两位小数
print(round(num_b / den_b, 2))
```

修复只需给分子补上 `resp[i] *`：A 的加权正面数 $=0.9\times9+0.1\times1+0.8\times8+0.2\times2+0.5\times5=17.5$，加权抛掷数 $=0.9\times10+0.1\times10+0.8\times10+0.2\times10+0.5\times10=25$，故 $\theta_A=17.5/25=0.7$；B 的账本本来就对：$7.5/25=0.3$。带病版第一行会输出 1.0——A 把五组数据全吞下，偏置荒谬地变成百分之百，这正是"漏乘责任"的既视感。

<summary>点开查看逐步解答</summary>

硬指派：组 1 责任 0.9 砍成 1 整组归 A，组 2 整组归 B。M 步变成普通数频率：$\theta_A=3/4=0.75$，$\theta_B=1/4=0.25$——**和初始猜测一模一样，原地踏步**。软指派那边 $(0.9, 0.1)$ 至少挪到了 $(0.7, 0.3)$：软账本承认"组 1 有一成可能是 B 抛的"，硬账本把这一成话语权直接没收。初始参数恰好等于硬指派的频率时，硬指派 EM 就永远冻结——软指派的价值在这一步对比里看得分明。
</details>

## 7. 边界与适用条件

- EM 只保证爬上**最近的**一座峰：初始猜测决定命运，多重启取最优是标准操作；对称初始化（$\theta_A=\theta_B$）更是直接卡死。
- "似然单调不降"不等于"收敛到全局最大"，平坦的鞍面也能让它停住不再挪动。
- M 步的闭式解是伯努利这类分布的福利：换成 M 步没有解析解的模型，"M 步"内部还得再做一次数值优化，EM 的省心打了折扣。
- 两枚硬币越相似（混合越重叠），责任越接近对半，收敛越慢；两枚几乎无差别时，数据本身也带不出区分它们的信息——这不是算法的错，是问题的可辨识性到头了。
- A、B 的标签可以整体互换而似然不变：解天然成对出现，挑哪套都行，别指望算法替你"命名"。

## 8. 选读：为什么每一轮似然都不降

<details>
<summary>选读 · 一条下界撑住的单调性</summary>

给每组数据配一个任意的分账方案 $q_i$（对 A、B 各给一份非负份额，总和为 1），则恒有：

$$\ln L=\sum_i \ln\sum_z P(\text{数据}_i,z)\;\ge\;\sum_i\sum_z q_i(z)\,\ln\frac{P(\text{数据}_i,z)}{q_i(z)}$$

（$z$ 只取 A 或 B 两个值；右边叫**下界**，它与 $\ln L$ 的差距是一段 KL 散度——非负，第 40 章的老朋友——$q_i$ 越贴近真实后验，下界贴得越高。）

E 步取 $q_i$ 恰为当前参数下的后验责任：KL 项归零，下界**贴住** $\ln L$；M 步在下界里只动参数坐标，把它顶到该坐标的最高点，其余部分原封不动。先贴住、再抬高，天花板 $\ln L$ 只能跟着往上走——单调不降的全部秘密。这对"软指派 + 下界"的组合拳，正是生成模型里 ELBO 的直系祖先。

</details>
