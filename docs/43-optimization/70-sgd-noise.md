# 随机梯度下降与噪声

## 1. 从一个场景开始

连锁奶茶上新配方，想知道甜度调多少最讨喜。把全国门店当天卖出的十万杯逐一开盲测？成本荒谬。店长的实际做法：**随机请几位顾客试喝，听他们的平均意见调整配方**，隔一会儿再抽一轮。

第 30 课的梯度下降一直在"全量盲测"——每一步都老老实实算出**所有**样本的梯度。可神经网络的数据动辄百万条，每一小步都全查一遍就太奢侈了。把"抽检"思想搬进优化，得到的就是深度学习真正每天在用的引擎：**随机梯度下降**（Stochastic Gradient Descent，简称 SGD）。

## 2. 直觉解释

单个顾客的意见是**有噪声的**：有人嗜甜、有人怕胖，方向五花八门。但只要抽取公平，这些意见的**平均值恰好等于全体顾客的平均意见**——这叫无偏。所以噪声搅乱的是"每一次抽检的结果"，而不是"长远的方向"。

代价与好处各占一半：

- **代价**：轨迹不再是一条优雅的下坡曲线，而是蹦蹦跳跳地往谷底蹭——在谷底附近还会绕着最低点打转不落定；
- **好处**：便宜！一步只用几百条样本而非全部百万条；而且嘈杂的脚步反而可能帮我们从浅浅的小坑里颠出来。

那为什么后面所有实验还要固定随机种子？**为了比赛公平**——噪声是策略的一部分，裁判必须让每位选手拿到一模一样的抽签序列，别人才能复现你的成绩。

## 3. 正式定义

$n$ 个样本的第 $i$ 条损失记作 $f_i$，全体平均（经验风险）为

$$f(w)=\frac{1}{n}\sum_{i=1}^{n} f_i(w),\qquad \nabla f(w)=\frac{1}{n}\sum_{i=1}^{n} \nabla f_i(w)$$

真梯度就是单样本梯度的平均。SGD 每步只随机抽 $b$ 条（叫一个**小批量**），用它们的平均冒充真梯度：

$$\hat{g}= \frac{1}{b}\sum_{i \in S} \nabla f_i(w),\qquad \text{则 } E[\hat{g}] = \nabla f(w)\ (\text{无偏}),\qquad \mathrm{Var}(\hat{g}) \propto \frac{1}{b}$$

| 术语 | 含义 |
| --- | --- |
| 单样本梯度 $\nabla f_i$ | 一位"顾客意见"：又快又吵 |
| 小批量 $S$、批量大小 $b$ | 一次抽检的人数；$b=n$ 时退化为普通 GD |
| 无偏估计 | 平均意义下说真话：$E[\hat{g}]$ 正中靶心 |
| 方差 $\propto 1/b$ | 人越多集体意见越稳：标准差按 $\sqrt{b}$ 缩水 |

读法重点：方差随批量线性缩、标准差才开根号——翻倍人数只换来约七折噪声，大批量的回报是边际递减的。

## 4. 分步例题

三个样本 $(1,2),(2,1),(3,3)$，模型只有斜率 $a$ 一个参数，损失取平均平方误差 $\frac{1}{3}\sum (a x_i-y_i)^2$。

1. **求单样本梯度公式**：$\partial/\partial a\,(a x_i-y_i)^2 = 2(a x_i-y_i)\,x_i$；
2. **求整批梯度**：代入求和得 $\frac{2}{3}(14a-13)$——它过零的位置 $a^{\ast}=13/14\approx0.93$ 就是真谷底；
3. **看点状态**（$a=1$）：逐个算三位"顾客"的意见：
   $i{=}1$: $2(1-2)\times1=-2$；$i{=}2$: $2(2-1)\times2=4$；$i{=}3$: $2(3-3)\times3=0$；
4. **验证无偏**：三者平均 $(-2+4+0)/3=2/3$，而整批公式给出 $\frac{2}{3}(14-13)=2/3$ ——分毫不差；
5. **感受噪声**：三份意见有负有正还有零，幅度差一倍以上。若每次只抽一位顾客，走向会飘忽；但三千次抽签的平均注定压回 $2/3$。**每一次都是错的或歪的，长期平均却精确**——这就是 SGD 的赌约。

### 实验 3：噪声谱对比——人多真的更稳吗

固定种子实测：一千次"单顾客抽检"和一千次"64 人大团审"，看两种集体意见的散布宽度。

```python title="噪声谱：单样本 vs 批量 64 的散布对比"
import random                             # 随机库：负责公平抽签
import matplotlib.pyplot as plt           # 绘图库：直方图在这里

random.seed(3)                            # 固定种子：图形可复现
xs = [1, 2, 3]
ys = [2, 1, 3]

def grad_one(a, i):                       # 样本 i 的单点梯度
    return 2 * (a * xs[i] - ys[i]) * xs[i]

samples = []                              # 收集 1000 次单人意见
for k in range(1000):
    i = random.randint(0, 2)              # randint(a,b)：从 a 到 b 等概率抽整数（含两端）
    samples.append(grad_one(0.5, i))

g_full = (grad_one(0.5, 0) + grad_one(0.5, 1) + grad_one(0.5, 2)) / 3
print("整批梯度 =", g_full)

m = sum(samples) / len(samples)           # 抽样平均：应当贴近整批值（无偏）
var = sum((v - m) ** 2 for v in samples) / len(samples)   # 平方偏差的平均＝方差
print(f"批大小 1 ：均值 {m:.2f}，标准差 {var ** 0.5:.2f}")   # ** 0.5 即开平方

vals64 = []                               # 同样的实验换 64 人大团审
for k in range(1000):
    s = 0.0
    for b in range(64):                   # 内层循环：凑一批再取平均
        s = s + grad_one(0.5, random.randint(0, 2))
    vals64.append(s / 64)

m64 = sum(vals64) / len(vals64)
var64 = sum((v - m64) ** 2 for v in vals64) / len(vals64)
print(f"批大小 64：均值 {m64:.2f}，标准差 {var64 ** 0.5:.2f}")

fig, ax = plt.subplots(figsize=(7, 3))
ax.hist(samples, bins=30, alpha=0.6, label="batch=1")   # hist：直方图；alpha 调透明度
ax.hist(vals64, bins=30, alpha=0.6, label="batch=64")
ax.axvline(g_full, color="#b3261e", linewidth=2, label="true gradient")   # 真值竖线
ax.set_xlabel("gradient estimate")
ax.legend()
```

读数与理论对表：两个均值都贴着 $-4$（无偏名不虚传）；标准差从约 $3.76$ 缩到约 $0.46$——比值逼近 $\sqrt{64}=8$，正是"$1/b$ 进方差、$\sqrt{b}$ 出标准差"的活教材。直方图上红竖线是整批梯度 $-4$：窄箱稳稳簇拥在它周围，宽箱撒得到处都是。

### 快问快答

```quiz
既然批量越大方差越小，为什么不干脆每步都用全部样本？
- 因为全量计算不收敛
- 计算开销大，且适度的噪声有助于跳出浅坑、最后衰减学习率再收口 [*]
- 全量梯度的方向一定是错的
? 大批量是把方差调成零的同时把步数费用拉满；实践取中间批量，兼顾算力效率与探索能力。
```

:::warning[常见误区]

**误区一**："单样本梯度算错了，SGD 就是不精确的方法。" 每一步确实歪，但期望严格等于真梯度——不精确的是路径，不是目的地。判别关键永远看平均行为。

**误区二**："噪声纯属麻烦，越小越好。" 谷底附近的抖动帮助逃逸浅坑，还与泛化能力相关（选读）。只有训练收尾阶段需要衰减学习率让它安静下来。

**误区三**："SGD 里还有别的讲究，比如 shuffle，是为了增加花样。" 打乱样本顺序是保证抽签独立性、防止同一批始终成套出现的基本卫生措施，不是装饰。

:::

## 6. 练习

**练习 1**（概念）：某天店长抽到的三位顾客异口同声要求"更苦"。这是否证明配方的最优甜度该往苦调？

<details>
<summary>点开查看逐步解答</summary>

不一定。单次抽签的方向对了也不能定案，因为它是**有方差的估计**：这一轮三人恰好同口味完全可能只是巧合。正确的态度是长期主义——多抽几轮看平均，或者加大批量。对照第 4 步：意见 $-2,+4,0$ 里两人喊"降"、一人沉默，但真相由平均值说了算。
</details>

**练习 2**（判题）：下面代码想验证"五千次抽签的平均会聚到整批梯度附近"，却有两个疏漏：没固定随机种子（结果每次都变）、忘了把累加值除以次数。补好这两处，让三行输出命中：

```exercise
# @title: 练习：把嘈杂的抽签平均磨准
# @check: -3.0 0.0 -9.0
# @check: True
# @check: -4.0
# @hint: 在 import random 之后补一行 random.seed(0)；再把 total 改成 total / K 得到平均。第二行检查平均值是否落在真梯度 -4 的邻域窗口里。
import random
# ← 这里漏了一行：加上 random.seed(0)，否则每次运行的结果都不一样

xs = [1, 2, 3]
ys = [2, 1, 3]

def grad_one(a, i):
    return 2 * (a * xs[i] - ys[i]) * xs[i]   # 样本 i 的单点梯度

print(grad_one(0.5, 0), grad_one(0.5, 1), grad_one(0.5, 2))   # 三份单人意见

K = 50000                    # 抽签次数
total = 0
for k in range(K):
    i = random.randint(0, 2)              # 等概率抽 0 / 1 / 2
    total = total + grad_one(0.5, i)

g_hat = total                # ← 错了：还没除以 K 取平均
print(-4.2 < g_hat < -3.8)   # 链式比较：真梯度是 -4，抽查平均应落进这个窗口

g_full = (grad_one(0.5, 0) + grad_one(0.5, 1) + grad_one(0.5, 2)) / 3
print(round(g_full, 2))      # 整批梯度＝三份意见的平均
```

修好后输出 `-3.0 0.0 -9.0`、`True` 和 `-4.0`。第一行显示三份意见从小到大毫无规律；第二行的平均值被钉进真梯度附近的窗口——五万次嘈杂投票换来一次精确定位；第三行验证"整批恰为均值"的无偏定义本身。

## 7. 选读：噪声的另一副面孔

<details>
<summary>选读 · 方差收缩与"偏爱平坦"猜想</summary>

方差 $\propto 1/b$ 成立的前提是样本独立同分布抽取，这就是 shuffle 卫生的来源；相关性强的抽法会让有效批量打折。更耐人寻味的是泛化视角：在大批量或全量训练下，优化器容易滑向尖锐的极小值——周遭稍变损失陡增；带噪声的小批量路径则在抖动中被推离尖峰、更常停在**宽阔平坦**的盆地，这类盆地在新数据上的表现往往更好。一句话，SGD 的噪声既是负担也是正则剂——它用掉的计算折扣，一部分其实是花在了更稳健的落点上。这一现象至今仍是研究热点，此处只立路牌不下结论。

</details>
