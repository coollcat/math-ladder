# 量子纠错：不能克隆怎么备份

## 1. 从一个场景开始

硬盘会坏，所以重要文件复制三份，坏一份还有两份对上。可量子态**不能复制**——复制一个未知量子态在物理上是被禁止的（不可克隆定理）。

那量子计算机岂不是一被干扰就报废？

偏偏不是。办法不是"复制"，而是**编码**：把 1 个逻辑比特摊到 3 个物理比特上，$|0\rangle\to|000\rangle$、$|1\rangle\to|111\rangle$。三个比特里坏一个，多数表决还能救回来。

但麻烦紧接着来：量子比特不只翻转 **比特**（$X$），还会翻转**相位**（$Z$）。重复码对相位翻转**完全瞎**。这一课就讲三件事：怎么用"只测错误、不测数据"的办法纠错，为什么简单重复码不够，以及工程上怎么靠**码距**和**阈值**把错误率一路压下去。

## 2. 直觉解释

先看不可克隆为什么那么致命。克隆操作要是酉变换 $U$，就得同时满足 $U|0\rangle|0\rangle=|0\rangle|0\rangle$ 和 $U|1\rangle|0\rangle=|1\rangle|1\rangle$，配合线性性要求 $U(\alpha|0\rangle+\beta|1\rangle)|0\rangle=\alpha|00\rangle+\beta|11\rangle$——而真正的克隆该给出 $(\alpha|0\rangle+\beta|1\rangle)^{\otimes2}$，里面带着 $2\alpha\beta|01\rangle$ 这样的交叉项。**这两者不相等**，所以完美的克隆机不存在。

编码则完全合法。关键动作只有一条：**测量只能测"错误"，绝不能测"数据"**。

想象三个证人作证，你只问"他俩说的对不对得上"（比较关系），从不问"谁说的是真话"（绝对内容）。比较的答案不泄露**谁对**、也不泄露**他们说了什么**，但能精确指出**谁和别人不一样**。在量子语言里，问"对不对得上"就是测 $Z_1Z_2$ 与 $Z_2Z_3$ 这两个算符的本征值。

这就是量子纠错的全部魔法：**把错误信息搬进一个和数据正交的测量通道**，测完把它扔掉，错误就被定位并纠正了，而逻辑振幅 $\alpha,\beta$ 毫发无损。

## 3. 正式定义

**不可克隆定理**：不存在酉算子 $U$ 使 $U|\psi\rangle|0\rangle=|\psi\rangle|\psi\rangle$ 对所有 $|\psi\rangle$ 成立。证明一行就够：它必须同时对 $|0\rangle$ 和 $|1\rangle$ 成立，但酉性是线性的，而克隆是非线性的（上节）。

**三比特重复码**（码距 $d=3$）：

$$|0_L\rangle=|000\rangle,\qquad |1_L\rangle=|111\rangle,\qquad \alpha|0\rangle+\beta|1\rangle\ \longrightarrow\ \alpha|000\rangle+\beta|111\rangle .$$

逻辑算符（作用在编码子空间上相当于单比特门）：

$$X_L=X_1X_2X_3,\qquad Z_L=Z_1\quad(\text{与 }Z_1Z_2Z_3\text{ 同作用}) .$$

**稳定子与综合征**：编码子空间是这两个算符同时取 $+1$ 的本征空间

$$S=\langle Z_1Z_2,\ Z_2Z_3\rangle .$$

测量它们的本征值（记 $+1\to0$、$-1\to1$），得到**综合征** $(s_1,s_2)$：

| 错误 | $Z_1Z_2$ | $Z_2Z_3$ | 综合征 $(s_1,s_2)$ | 纠正动作 |
| --- | --- | --- | --- | --- |
| 无 | $+1$ | $+1$ | $(0,0)$ | 不动 |
| $X_1$ | $-1$ | $+1$ | $(1,0)$ | 施加 $X_1$ |
| $X_2$ | $-1$ | $-1$ | $(1,1)$ | 施加 $X_2$ |
| $X_3$ | $+1$ | $-1$ | $(0,1)$ | 施加 $X_3$ |

**相位翻转的漏网**：$Z_i$ 与 $Z_iZ_j$ 对易——上面这张表的每一格**都不动**。所以重复码看不见任何 $Z$ 错误。

**Shor 九比特码**（$[[9,1,3]]$）：先用三个重复码块保护相位（把 $Z$ 换成 $X$ 的基），再对三个块用重复码保护比特，合起来能纠正**任意单比特错误**（$X$、$Z$ 或 $Y$）。

**码距与纠错能力**：能纠 $t$ 个错误的码需要 $d\ge 2t+1$。$d=3$ 纠一位，$d=5$ 纠两位。

**阈值定理**：若物理错误率 $p$ 低于某个阈值 $p_{\text{th}}$，用级联码或表面码可以把逻辑错误率压到**任意小**（$p_L\sim C p^{\lceil d/2\rceil}$），代价是物理比特数随所需精度多项式增长。

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $X,Z,Y$ | Pauli 算符 | 比特翻转、相位翻转，以及两者叠加 $Y=iXZ$ |
| $X_L,Z_L$ | 逻辑算符 | 在编码子空间里扮演单比特门，是"数据"，绝不能测 |
| $Z_iZ_j$ | 稳定子生成元 | 只测"位置间关系"，对逻辑信息是盲的 |
| $(s_1,s_2)$ | 综合征 | 错误的指纹，不含 $\alpha,\beta$ 的任何信息 |
| $d$ | 码距 | 能纠 $\lfloor(d-1)/2\rfloor$ 位；$d$ 越大越贵 |
| $p_{\text{th}}$ | 阈值 | 低于它，加码层就能指数降错误率 |

## 4. 分步例题

**例 1（纠一个位翻转）**：编码逻辑 $1$ 得到 $|111\rangle$，信道把第一位翻成 $|011\rangle$。

1. 测 $Z_1Z_2$：第 1、2 位不同，本征值 $-1$，记 $s_1=1$；
2. 测 $Z_2Z_3$：第 2、3 位相同（都是 1），本征值 $+1$，记 $s_2=0$；
3. 查表：$(1,0)$ 对应"第一位出错"；
4. 施加 $X_1$，状态从 $|011\rangle$ 恢复到 $|111\rangle$；
5. 全程没有测量任何单个 $Z_i$，所以 $\alpha,\beta$ 没有被扰动——纠错对逻辑数据是"隐形"的。

**例 2（相位翻转为什么漏网）**：编码逻辑 $+$ 态 $|{+}_L\rangle=\frac{1}{\sqrt2}(|000\rangle+|111\rangle)$，信道施加 $Z_1$。

1. $Z|0\rangle=|0\rangle$、$Z|1\rangle=-|1\rangle$，所以只有含 $1$ 的分支变号：$Z_1|{+}_L\rangle=\frac{1}{\sqrt2}(|000\rangle-|111\rangle)=|{-}_L\rangle$；
2. 再测 $Z_1Z_2$：它同时作用在两个分支上，$|000\rangle$ 给 $+1$、$|111\rangle$ 也给 $+1$，本征值恒为 $+1$；
3. 同理 $Z_2Z_3$ 也恒为 $+1$，综合征 $(0,0)$——**"没检测到错误"**；
4. 但逻辑态已经从 $|{+}_L\rangle$ 变成了 $|{-}_L\rangle$，相当于一次**逻辑相位翻转** $Z_L$；
5. 结论：重复码只能防 $X$。要防 $Z$，只需把三个比特都过一遍 $H$——在 $X$ 基下，$Z$ 就变成了"位翻转"，同一套码照样能用。Shor 码做的正是这件事，外加一层块级保护。

**例 3（纠错能力与码距）**：多数表决失败的充要条件是**多于一半**的比特出错。

1. $d=3$：三位里坏两位或三位就失败，概率 $p_L=\binom32p^2(1-p)+p^3=3p^2-2p^3$；
2. $d=5$：五位里坏三位及以上才失败，领头项 $\binom53p^3=10p^3$；
3. $p$ 小时，$3p^2$ 与 $10p^3$ 的比说明：**每加一层码距，错误率就多乘一个 $p$**；
4. 交点处 $p$ 就是"这类码"的阈值形状（动手实验 1 把 $3p^2$ 与 $15p^3$ 画出来，交点在 $p=0.2$）；
5. **低于阈值，加码距就是稳赚**；高于阈值，码越大反而越糟——这就是阈值定理的全部直观。

**例 4（Shor 九比特码在保护什么）**：任意单比特错误都能写成 $X$、$Z$、$Y$ 的线性组合。

1. 相位部分：三个比特一组的重复码（在 $H$ 基下）挡住 $Z$；
2. 比特部分：三个块之间再用一次重复码挡住块级的 $X$；
3. 由于 $Y=iXZ$ 是 $X$ 与 $Z$ 的叠加，$X$、$Z$ 都能纠，$Y$ 自然也能纠；
4. 代价：1 个逻辑比特花掉 9 个物理比特，而且每次纠错还要测 8 个稳定子——**纠错本身很贵，但它是唯一能把噪声真正压下去的办法**。

### 实验 2（python）：三比特码诊断并纠正

把综合征表变成一段真代码，枚举三种单比特错误（不需要任何随机数）：

```python title="枚举所有单比特 X 错误：测综合征 → 查表 → 纠正"
def encode(bit):
    return [bit, bit, bit]       # 编码：|0_L>=|000>，|1_L>=|111>

def syndrome(state):
    # Z1Z2、Z2Z3 的读数：两位相同记 0（本征值 +1），不同记 1（本征值 −1）
    s1 = (state[0] + state[1]) % 2
    s2 = (state[1] + state[2]) % 2
    return s1, s2

# 字典：把综合征映射到"出错的位数"（0 起算）。get 是字典的查找方法
table = {(1, 0): 0, (1, 1): 1, (0, 1): 2}

for pos in range(3):
    state = encode(1)            # 逻辑 1 → [1, 1, 1]
    state[pos] = 1 - state[pos]  # 在第 pos 位注入一个比特翻转
    s1, s2 = syndrome(state)
    fix = table.get((s1, s2))
    state[fix] = 1 - state[fix]  # 施加 X 纠正
    print(f"注入 X{pos + 1}: 综合征({s1},{s2}) → 纠正第 {fix + 1} 位 → {state}")

# 再试试两个错误：码距 3 的码只能纠一位
state = [0, 0, 1]
s1, s2 = syndrome(state)
fix = table.get((s1, s2))
state[fix] = 1 - state[fix]
print(f"两个错误: 综合征({s1},{s2}) → 纠正第 {fix + 1} 位 → {state}（纠错了！）")
```

前三行分别是 `注入 X1/X2/X3`，综合征 $(1,0)$、$(1,1)$、$(0,1)$ 各自把错误定位到正确的位，三次都恢复成 `[1, 1, 1]`。最后一行却暴露了极限：两个错误（本来该是逻辑 1 的 $111$ 被翻成 $001$）给出的综合征和"第三位出错"一模一样，程序忠实地把第三位又翻了一次，结果变成了 `[0, 0, 0]`——**逻辑 1 摇身成了逻辑 0**。码距 3 只能纠一位，这不是 bug，是距离下界 $d\ge2t+1$ 的现身。

### 实验 3（python）：相位翻转为什么看不见

把编码子空间写成 $\psi=\alpha|000\rangle+\beta|111\rangle$，注入一个 $Z_1$，再看综合征：

```python title="Z 错误与稳定子擦肩而过"
words = ["000", "111"]      # 编码子空间的两个基码字
amps = [0.6, 0.8]           # 逻辑振幅 α、β（满足 0.36 + 0.64 = 1）

def synd(words):
    s1, s2 = 0, 0
    for word in words:      # 逐码字检查第 1-2 位、第 2-3 位是否成对相同
        if word[0] != word[1]:
            s1 = 1
        if word[1] != word[2]:
            s2 = 1
    return s1, s2

def z_on_first(words, amps):
    out = []
    for i in range(len(words)):
        sign = -1 if words[i][0] == "1" else 1   # Z|1> = −|1>，Z|0> = |0>
        out.append(sign * amps[i])
    return out

print("纠错前综合征:", synd(words))
amps2 = z_on_first(words, amps)
print("注入 Z1 后振幅:", amps2)
print("纠错后综合征:", synd(words))
print(f"逻辑态: ({round(amps2[0], 2)}, {round(amps2[1], 2)}) = (α, −β)，逻辑相位翻转")
```

四行输出：`(0, 0)`、`[0.6, -0.8]`、`(0, 0)`、`(0.6, -0.8) = (α, −β)，逻辑相位翻转`。注入前后综合征**纹丝不动**，错误却已经实实在在发生——逻辑振幅从 $(\alpha,\beta)$ 变成了 $(\alpha,-\beta)$。这就是"重复码看不见 $Z$"的账面证据；把它修好的办法就是实验 2 里那套码换个测量基（三个比特都过 $H$），这正是 Shor 九比特码的第一层。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为量子纠错就是多复制几份。" 不可克隆定理把"复制"这条路彻底封死。量子纠错做的是**把逻辑信息编码进纠缠子空间**，然后用对数据"盲目"的测量去定位错误。三份 $|000\rangle$ 看起来像复制，但它只在 $\lbrace|000\rangle,|111\rangle\rbrace$ 这个二维子空间里定义**一个**逻辑比特——剩下的六维空间全是"纠错用"的冗余，不是备份。

**误区二**："你以为测综合征会把逻辑态测坍缩掉。" 稳定子 $Z_iZ_j$ 与逻辑算符 $X_L$、$Z_L$ 都对易。按量子力学的测量理论，**对易的测量不会打扰彼此**——测综合征只会把状态投影到"某种错误模式"上，$\alpha,\beta$ 原样保留。这是量子纠错能成立的数学地基，也是它最反直觉的一点：**你可以测量，只要测的是错误**。

**误区三**："你以为三比特重复码能防住所有单比特错误。" 它只看得见 $X$。$Z$ 和 $Y$ 都会从它的综合征表里溜过去（实验 3 现场演示）。要挡住任意单比特错误，得把 $X$ 和 $Z$ 两类都覆盖——Shor 九比特码用两级重复码做到这点，而它仍然只是个"最小可用的样板"，离真正的容错还有距离。

**误区四**："你以为阈值定理承诺"噪声再大也能纠"。" 它只承诺**物理错误率低于阈值**时的指数下降。阈值本身还与门的保真度、测量速度、连接度有关；更关键的是，纠错电路自己也会出错，所以必须**容错**设计（用横向门、冗余综合征提取等手段防止单个故障扩散成逻辑错误）。"低于阈值"这四个字是整座大厦的地基。

:::

**练习 2**：用实验 2 的综合征表，回答：如果第一位和第二位同时翻转（$|111\rangle\to|001\rangle$），综合征会显示什么？码会怎么"纠正"？这说明 $d=3$ 的码在什么情况下必然失败？

<details>
<summary>点开查看逐步解答</summary>

1. **算综合征**：$001$ 的第 1、2 位相同（都是 0）→ $s_1=0$；第 2、3 位不同 → $s_2=1$，所以读数是 $(0,1)$；
2. **查表**：$(0,1)$ 在表里对应"第三位出错"；
3. **纠正**：程序施加 $X_3$，把 $001$ 变成 $000$；
4. **后果**：原始逻辑是 $|1_L\rangle=|111\rangle$，纠完却成了 $|0_L\rangle=|000\rangle$——**逻辑比特被翻反了**。这就是"纠错反而引入逻辑错误"；
5. **必然失败的判据**：只要真实错误数 $>t=\lfloor(d-1)/2\rfloor$，最近码字就可能选错。$d=3$ 时 $t=1$，所以**任何两位错误都可能致命**。这也解释了为什么工程上要堆码距：$d=5$ 才能容忍一个错误之后再来一个（这对长时间计算至关重要）。

</details>

## 8. 选读：稳定子码、表面码与容错

<details>
<summary>选读 · 从三比特到表面码的一条路</summary>

三比特重复码是一类更一般对象的特例：**稳定子码**。给定一组两两对易、且各自平方为 $I$ 的 Pauli 算符 $S_1,\dots,S_k$，把同时满足 $S_i|\psi\rangle=|\psi\rangle$ 的状态全体取出，就得到一个编码子空间。三比特码就是取 $S_1=Z_1Z_2$、$S_2=Z_2Z_3$，$2^3/2^2=2$ 维——正好装一个逻辑比特。

稳定子码一整套理论都在回答一个问题：**哪些错误"露馅"**。一个错误 $E$ 若与某个 $S_i$ 反对易，就会把对应本征值从 $+1$ 翻到 $-1$，留下指纹；若与所有 $S_i$ 对易却又不在稳定子群里，它就是"隐形杀手"——会悄悄改变逻辑态（实验 3 的 $Z_1$ 正是这种情况）。码距 $d$ 就等于"最轻的隐形杀手"的重量（非平凡逻辑算符的最小 Pauli 重量）：$d$ 越大，要多少位同时出错才能骗过所有稳定子。

**表面码**把这套代数搬到二维格子上：数据比特放在格点，稳定子放在面与边上（$X$ 型与 $Z$ 型各一组），综合征就是相邻稳定子的"点亮模式"。它的优点是**只用近邻门、阈值高（约 $1\%$）、码距靠扩大格子自然提升**，因此成了当前主流量子硬件（超导、离子阱）容错路线的首选。

**容错这层是更硬的门槛**：纠错电路自身也会出错，所以必须保证"一个部件故障最多造成一个可纠正的错误"，否则会雪崩。横向门（每个物理比特独立施加同一个门）是最安全的一类操作，但它能实现的门集合很有限，通用性的缺口靠魔术态蒸馏来补。整条链路——物理比特 → 稳定子测量 → 解码器 → 逻辑门 → 蒸馏——缺一环，阈值就塌。

一句话收尾：**纠错不是"让机器不出错"，而是"让错误以一个可被抓住的形状出现"**。数学上精巧，工程上昂贵，但它和 Shor 是同一份收益表的两面。

</details>
