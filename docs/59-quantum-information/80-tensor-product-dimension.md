# 张量积：维数爆炸从哪里来

## 1. 从一个场景开始

抛一枚硬币，可能的结果是 2 种；同时抛两枚，结果翻成 4 种；十枚就是 1024 种——经典世界里多枚硬币的组合数本来就在指数生长。真正吓人的是量子版本的账单：要**完整写下** 40 枚纠缠硬币的量子状态，得存大约 1 万亿个复数。一台普通笔记本的内存，在 40 这道坎前轰然跪地。

组合系统怎么拼、维数为什么偏偏相乘、这份"空间爆炸"又是加速的火种还是模拟的噩梦——本课把这本规模账从第一页算起。

## 2. 直觉解释

第 40 课已经提前摸过这个开关：两个比特的联合状态有四个基标签 $\lvert00\rangle,\lvert01\rangle,\lvert10\rangle,\lvert11\rangle$。现在把拼装规则说透：

- **独立世界相加、联合世界相乘**：左边一枚硬币的可能性（2）与右边一枚的可能性（2）不做加法做乘法，$2\times2=4$；
- 为什么是乘法？因为联合描述必须能区分"左 0 右 0"和"左 0 右 1"这样**逐格不同的组合**——格子总数天生就是每边选项数的连乘积，第 9 章的计数原理早已预报；
- 三枚硬币：标签 000 到 111 共 8 格；每添一枚，格子整体**翻倍**而非增加一行。10 枚＝1024 维复向量，20 枚＝超过一百万维。

所以"维数爆炸"不是隐喻，是乘法口诀：$\underbrace{2\times2\times\cdots\times2}_{n\ \text{个}}=2^n$。

## 3. 正式定义

**张量积**（⊗）：把左系统的每个分量与右系统的每个分量逐一交叉相乘，拼出联合向量：

$$\begin{pmatrix}a\\ b\end{pmatrix}\otimes\begin{pmatrix}c\\ d\end{pmatrix}=\begin{pmatrix}ac\\ ad\\ bc\\ bd\end{pmatrix},\qquad \lvert a\rangle\otimes\lvert b\rangle=\lvert ab\rangle=\lvert a\rangle\lvert b\rangle$$

| 记号 | 名字 | 含义 |
| --- | --- | --- |
| $\otimes$ | 张量积 | 组合系统的官方拼装运算 |
| $\lvert00\rangle$ 等 | 联合基 | 一个四维空间的四根坐标轴的名字 |
| $2^n$ | n 比特态维数 | 复向量的长度；写全状态需要这么多振幅 |
| 乘积态 / 纠缠态 | 能拆 / 不能拆 | 第 40 课的分界线，用 ⊗ 语言重述一遍 |

两条推论值得刻在桌上：其一，n 个比特的状态是 $2^n$ 维复向量——这是**模拟困难**的根源；其二，大多数联合态不能拆成 $\lvert\psi\rangle_A\otimes\lvert\phi\rangle_B$（自由参数对不上账），纠缠因此是常态而非装饰——这是**并行威力**的温床。同一朵花的两面。

## 4. 分步例题

**例 1**：把 $\lvert+\rangle\otimes\lvert0\rangle$ 展开成四维向量并读出测量分布。

1. 单态振幅：$\lvert+\rangle=(\frac{1}{\sqrt2},\frac{1}{\sqrt2})^T$，$\lvert0\rangle=(1,0)^T$；
2. 交叉相乘：依次得 $(\frac{1}{\sqrt2},\ 0,\ \frac{1}{\sqrt2},\ 0)^T$，对应标签 00,01,10,11；
3. 模平方：$P(00)=P(10)=\frac12$，另两项为 0——右币永远 0，左币五五开；
4. 读结构：可拆式 $\lvert+\rangle\lvert0\rangle$ 的分布里藏着独立性（左右各说各话），这正是"乘积态"三个字的账面含义。

**例 2**：算一笔 20 比特的存储账，看清笔记本为什么跪。

1. n=20 时维数 $2^{20}=1\,048\,576$——百万级，还算友好；
2. 每个振幅按双精度复数存 16 字节：约 16 MiB，一杯奶茶的时间都下载完了；
3. n=40：$2^{40}\approx1.1\times10^{12}$ 个振幅 ×16 字节 ≈ **16 TiB**——顶配工作站的全部内存只够装四分之一；
4. 结论立在数字上：直接模拟的路上，40 就是个人电脑的生死线。这也预告了最后一课的隐形传态与真实硬件为什么要"聪明着来"。

## 5. 动手实验

拖动滑块把指数账亲手滚一遍：每加一枚硬币，打印行数加一层、字节数翻一倍——眼见为实地体会"翻倍的空间"：

```python title="n 枚量子比特的内存台账"
# sliders: n_qubits=20 [1:30:1]

bytes_each = 16        # 双精度复数 = 8 字节实部 + 8 字节虚部
dims = 2 ** n_qubits            # 状态向量维数：乘法口诀的兑现
total_bytes = dims * bytes_each # 全存下来要多少字节
print(f"n={n_qubits:2d}  维数={dims:>12d}  内存={total_bytes / (2 ** 20):>10.1f} MiB")
```

拖到 27 前后还能扛（约 2 GiB）；继续往右，滑块还没到底、数字已经超出你家路由器几十辈子的流量。**这不是算力问题，是空间本身在抗议**——任何聪明的算法都得绕开"写全 2^n 振幅"这条直路。

### 快问快答

```quiz
三个各能取两值的量子比特放在一起，联合状态的维数是多少？
- 6
- 8 [*]
- 12
? 组合规则是相乘不是相加：2 × 2 × 2 = 8。三种思路里只有乘法对应"逐格组合"的计数直觉。
```

:::warning[常见误区]

**误区一**："你以为 n 个比特联合起来是 n 维。" 那是把可能性当成了坐标轴。真实的联合态活在 $2^n$ 维空间里——三枚硬币就要 8 根轴，这就是量子系统能'胖'过同尺寸经典对象的原因。

**误区二**："你以为张量积就是把向量首尾接长。" 接长是 4 维变 4 维的假动作；张量积是所有分量**交叉相乘**，维数才真正相乘。拿 $(1,2)\otimes(10,100)$ 手乘一次立刻见分晓。

**误区三**："你以为 $2^n$ 种可能意味着计算机器'免费并行算了 $2^n$ 遍'。" 测量只归还一个结果；并行的真实含义是上一课那套相位对账——设计得当的干涉让错误答案相消、正确答案相长。空间大只给了戏台，唱赢还得靠干涉剧本。

:::

## 6. 练习

**练习 1**：初始代码想报出 10 比特量子电路的规模账，但作者以为维数线性增长——修到两个输出正确为止：

```exercise
# @title: 练习：把翻倍的乘法口诀找回来
# @check: 1024
# @check: 1048576
# @hint: n 个比特的状态是 2**n 维复向量；作用在全态上的门矩阵每条边都要这么长，元素个数是维数的平方。
n = 10

amplitudes = n * 2          # ← 错在这：维数随位数翻倍，不是加倍
matrix_entries = amplitudes * 64   # ← 错在这：矩阵元素个数 = 边长的平方

print(amplitudes)
print(matrix_entries)
```

第二行的 1048576 就是 10 比特任意门的代价：一百万个复数系数才能完整定义一次合法变换——这是"通用门库那么小"反而珍贵的原因。

<details>
<summary>练习 1 解法</summary>

```python
n = 10

amplitudes = 2 ** n               # 维数：2 的 n 次方
matrix_entries = amplitudes ** 2  # 门矩阵：边长平方个元素

print(amplitudes)
print(matrix_entries)
```
</details>

**练习 2**：设两枚比特分别为 $\lvert\psi\rangle_A=(0.6,\ 0.8)^T$、$\lvert\psi\rangle_B=\lvert0\rangle$，手写联合振幅向量，再回答：测得左 0 右 0 和左 0 右 1 的概率各是多少？两者相等还是悬殊？说明了什么？

<details>
<summary>点开查看逐步解答</summary>

1. 交叉相乘：$(0.6\cdot1,\ 0.6\cdot0,\ 0.8\cdot1,\ 0.8\cdot0)=(0.6,\ 0,\ 0.8,\ 0)$；
2. 概率即模平方：$P(00)=0.36$，$P(01)=0$，$P(10)=0.64$，$P(11)=0$；
3. 左右完全不同调：右边钉死在 0，左边自顾自五五开抽签；
4. 这说明它是**乘积态**——两边概率互不沾染，信息也各自存放；对照第 40 课贝尔态的同步分布（00 与 11 各半、其余为零），"能不能拆成两个单态各自描述"正是纠缠与否的试金石。
</details>

## 7. 选读：纠缠是维数的"租客"

<details>
<summary>选读 · 大空间住不下大自由</summary>

粗暴的规模账有个可疑处：既然需要 $2^n$ 个振幅才能一般地描述状态，那 n 个比特岂不该承载天文数字的信息？答案是否定的——测量只能取出 n 个比特的经典结果。大空间里真正稀有的是**可分离的角落**：绝大多数方向都是纠缠区，参数互相咬死、无法归约为两侧的小账本。

换句话说：维数是房租，纠缠是住户，而我们能搬走的家具永远被测量上限压着。量子算法的艺术恰恰在这张力里舞动——让海量振幅集体为少数几个"正确答案"站队（用相位对账淘汰其余），最后只需一次性提取。经典超级计算机做不到这种"整层楼一起投票"，因为它的房间从来不多；而模拟量子机的困难，正是替它一间间付清这 $2^n$ 间房的房租。

</details>
