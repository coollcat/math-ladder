## 实战挑战

Alice 和 Bob 对比测量基后留下 5000 个筛后比特。窃听者 Eve 用拦截—重发攻击随机选基，其中约一半选错；她选错时会把原状态坍缩成随机答案再转发，Bob 在这些位置约有半数收到和 Alice 不同的比特。请算出这轮筛后通信的错误率和可疑错误数。

```exercise
# @title: BB84 窃听指纹
# @check: 1250
# @check: 0.25
# @hint: Eve 选错基只是让错误有机会出现；这一半位置里还要再有一半真的变成 Bob 的错码。
sifted = 5000
eve_wrong_basis = round(sifted / 2)

bob_errors = eve_wrong_basis          # ← 错在这：选错基不等于每次都造成错码
qber = bob_errors / sifted
print(bob_errors)
print(round(qber, 2))
```

<details>
<summary>点开查看逐步解答</summary>

Eve 选错的约 $2500$ 个位置会被重新随机化；其中约 $\frac12\times2500=1250$ 个会和 Alice 原比特不同。因此筛后误码率约为 $QBER=\frac{1250}{5000}=0.25$。公开比对一小部分筛后比特时，这么高的错误率会立刻暴露窃听者。

```python
sifted = 5000
eve_wrong_basis = round(sifted / 2)
bob_errors = round(eve_wrong_basis / 2)
qber = bob_errors / sifted
print(bob_errors)
print(round(qber, 2))
```
</details>

## 实战挑战 · 玻恩规则：概率是振幅的平方

玻恩规则：态 $|\psi\rangle = a|0\rangle + b|1\rangle$ 测量得到 $|0\rangle$ 的概率是 $|a|^2$，不是 $a$ 本身。均匀叠加态 $|\psi\rangle = \frac1{\sqrt2}(|0\rangle+|1\rangle)$ 测得 $|0\rangle$ 的概率是 $\frac12$。下面这题忘了平方，修到输出 `0.5`：

```exercise
# @title: 实战挑战：玻恩规则别忘平方
# @check: 0.5
# @hint: 概率 = 振幅的平方 |a|²，不是振幅 a 本身。
import math

a = 1 / math.sqrt(2)    # 振幅 1/√2
p = a                   # ← 问题在这：漏了平方
print(round(p, 3))
```

<details>
<summary>点开查看逐步解答</summary>

玻恩规则取振幅的**模平方**：

```python
p = a * a            # (1/√2)² = 1/2
print(round(p, 3))   # 0.5
```

改完：$|a|^2 = (\frac1{\sqrt2})^2 = 0.5$。初始代码输出 $0.707$，那是振幅本身——振幅可以是负的、复数，但概率必须是 $[0,1]$ 的实数，所以一定要取模平方。这条规则是量子力学从"叠加态"走到"观测结果"的唯一桥梁。

</details>
