# 量子傅里叶变换与相位估计：Shor 算法的引擎

## 1. 从一个场景开始

上一课把规模账算到了 40 个比特：要写全它的状态，得大约 16 TiB 内存。可账本大不等于答案好拿——**一次测量只归还一个基矢标签**。

Shor 算法要的是一段"周期"（第 85 课的三步归约里那个 $r$），而周期藏在振幅的相位里。相位是个连续量，测量却只给离散的格子。怎么把一个连续量从量子态里读出来？

答案就是本课的两台零件：**量子傅里叶变换**（QFT）把"藏在振幅里的相位"翻译成"看得见的频率峰"，**相位估计**再把它读成一个整数。它们是 Shor 真正的心脏。

## 2. 直觉解释

想知道一个齿轮转多快，笨办法是盯着它数圈数；聪明的办法是让它扫过一排梳齿，看它和哪一档**对上拍**。对上拍的那一档，就是它的转速。

QFT 干的就是"排梳齿"这件事。经典世界里，离散傅里叶变换把一段长度为 $N$ 的信号拆成 $N$ 个频率分量；量子版把这件事做成一个**酉矩阵**：对每个基矢 $|j\rangle$ 都配上一圈匀速旋转的相位 $e^{2\pi i jk/N}$。不同的 $j$ 转速不同——这正是"排梳齿"。

相位估计则是这样用的：

1. 准备一个 $t$ 个比特的**计数寄存器**，先均匀铺成所有可能值的叠加；
2. 让目标寄存器里那个"带着未知相位 $\varphi$ 的旋转" —— 受控地抄写到计数寄存器上：第 $j$ 个计数比特被抄 $2^j$ 次。抄完以后，计数寄存器的振幅里就写下了一串"频率为 $\varphi$ 的轮盘"；
3. 对计数寄存器做 **QFT 的逆**，轮盘的频率立刻变成一个整数峰：测量得到 $j$，就有 $\varphi\approx j/2^t$。

一句话：**受控-U 把相位写成频率，逆 QFT 把频率读成整数**。`t` 个比特把 $[0,1)$ 切成 $2^t$ 格——这就是精度 $1/2^t$ 的来源。

## 3. 正式定义

**量子傅里叶变换**（作用在 $N=2^n$ 维空间上，$\omega=e^{2\pi i/N}$）：

$$|j\rangle\ \longmapsto\ \frac{1}{\sqrt N}\sum_{k=0}^{N-1}\omega^{jk}\,|k\rangle .$$

它是酉变换（各行是复单位向量且两两正交），所以**可以逆、可以不破坏信息**。

**线路实现**（H 门 + 受控相位门）：对第 $j$ 个比特先做 $H$，再依次用更靠后的比特施加受控相位

$$R_k=\begin{pmatrix}1&0\\0&e^{2\pi i/2^k}\end{pmatrix},$$

最后把比特顺序**颠倒**一次。这些门全是小门，一共 $O(n^2)$ 个。

**相位估计**（输入 $U|u\rangle=e^{2\pi i\varphi}|u\rangle$，计数寄存器 $t$ 个比特）：

1. 计数寄存器置 $|0\rangle^{\otimes t}$，目标寄存器备好 $|u\rangle$；
2. 计数寄存器每个比特过一遍 $H$，得到 $\frac{1}{\sqrt{2^t}}\sum_{j=0}^{2^t-1}|j\rangle$；
3. 施加受控-$U^{2^j}$（第 $j$ 个计数比特当控制位）；
4. 对计数寄存器做逆 QFT，测量读出整数 $j$；
5. 输出 $\hat\varphi=j/2^t$。

**精度保证**：若 $\varphi=j^*/2^t$ 恰好落在格点上，测量以**概率 1** 命中 $j^*$；一般情况下以高概率读到一个最接近的格点，且 $|\hat\varphi-\varphi|\le\dfrac{1}{2^{t+1}}$。

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $N=2^n$ | 空间维数 | 傅里叶变换的规模，随比特数指数增长 |
| $\omega$ | $N$ 次单位根 | $\omega=e^{2\pi i/N}$，每个基矢的"转速"由它的幂次决定 |
| $\varphi$ | 未知相位 | 被估的对象，落在 $[0,1)$ 里 |
| $t$ | 计数比特数 | 决定精度 $1/2^t$，也决定读数的格点密度 |
| $j$ | 测量读到的整数 | $\hat\varphi=j/2^t$ 就是相位的估计 |
| $U^{2^j}$ | 受控幂 | 把相位放大 $2^j$ 倍抄进计数寄存器 |
| $R_k$ | 受控相位门 | QFT 线路里的最小零件，负责制造交叉相位 |

**与经典 FFT 的复杂度对比**：设 $N=2^n$。

| | 经典 FFT | 量子 QFT |
| --- | --- | --- |
| 输入 | 长度 $N$ 的数组（$N$ 个复数） | $N$ 维复向量（$2^n$ 个振幅） |
| 运算量 | $O(N\log N)$ | $O(n^2)$ 个门 |
| $N=1024$ 时 | $\approx 1.0\times10^4$ 次运算 | $\approx 100$ 个门 |

**注意这笔便宜不是白拿的**：QFT 的输出仍是 $N$ 个振幅，测量只能读出其中一个。它的价值在于"把相位信息集中到少数几个峰上"，而不是"一次性吐出整张频谱"。

## 4. 分步例题

**例 1（$N=4$ 的 QFT 矩阵）**：两比特的空间里，$\omega=e^{2\pi i/4}=i$。

1. 逐格代入 $(\text{QFT})_{jk}=\omega^{jk}/2$：第 0 行全是 $1/2$；第 1 行是 $1/2,\,i/2,\,-1/2,\,-i/2$；
2. 把 $|01\rangle$（即 $j=1$）代进去，读出第 1 列：$(1/2,\ i/2,\ -1/2,\ -i/2)$；
3. 写成态：$\text{QFT}|01\rangle=\frac12\bigl(|00\rangle+i|01\rangle-|10\rangle-i|11\rangle\bigr)$；
4. 读相位：四个振幅模长全是 $1/2$，但相位依次是 $0°,90°,180°,270°$ —— 一转正好走完一圈。

这就是"相位轮盘"的最小实物：**幅度平均，相位在转**。动手实验 1 会把这个结果原样打印出来。

**例 2（$\varphi=1/4$、$t=3$：一击命中）**：

1. 格点数 $2^t=8$，格距 $1/8$；
2. 把相位换算成格点：$\varphi\cdot2^t=\frac14\times8=2$，恰好是整数；
3. 于是测量以概率 1 读出 $j=2$（二进制 $010$）；
4. 估计 $\hat\varphi=2/8=1/4$，**误差为零**。

**例 3（$\varphi=1/3$、$t=5$：读到最近的格）**：

1. 格点数 $2^5=32$，格距 $1/32\approx0.031$；
2. $\varphi\cdot2^t=\frac{32}{3}\approx10.67$，不是整数——永远读不出精确值；
3. 最近的格是 $j=11$，测得概率约 $0.684$（次高的是 $j=10$，约 $0.171$）；
4. 估计 $\hat\varphi=11/32=0.34375$，与真值 $1/3\approx0.33333$ 相差约 $0.0104$，确实压在 $1/2^{t+1}=1/64\approx0.0156$ 以内。

**例 4（QFT 的门数账）**：$n$ 个比特。

1. 每个比特一次 $H$：$n$ 个门；
2. 每个比特要收到来自后面所有比特的受控相位：约 $n(n-1)/2$ 个门；
3. 合计 $O(n^2)$；$n=10$ 时约 $100$ 个门，而经典 FFT 要 $1024\times10\approx10^4$ 次运算。

**规模账在这里第一次翻了方向**：经典里 $N$ 越大越贵，量子里贵的是 $n=\log_2N$ 的平方。这正是 Shor 能在多项式时间里跑起来的底层原因。

## 5. 动手实验

### 实验 1（viz）：单比特 QFT 就是那次镜面反射

$N=2$ 时的 QFT 矩阵只有一个比特的门——它正好是 Hadamard 门 $H=\frac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$。把它的四格当实数填进去：

```viz

  "a": 0.7071,
  "b": 0.7071,
  "c": 0.7071,
  "d": -0.7071

```

网格被整体翻了个面：行列式是 $0.7071\times(-0.7071)-0.7071\times0.7071=-1$，**负一号就是"镜像"的签名**。$H$ 把一根轴上的差别搬到了另一根轴上——这正是"振幅的差别被翻成相位的差别"在最小规模下的样子。$N$ 一大，这面镜子就长成了 $2^n$ 维空间里的整圈相位轮盘。

### 实验 2（python）：4 维 QFT 矩阵与相位轮盘

把上面的例子 1 亲手跑一遍，看清"幅度平均、相位在转"：

```python title="手造 QFT 矩阵，看 |01> 被转成什么"
import math                          # 三角函数与 π 的老工具箱

def qft_matrix(N):
    """N×N 量子傅里叶矩阵：第 j 行第 k 列 = e^(2πi·jk/N) / √N"""
    M = []
    for j in range(N):
        row = []
        for k in range(N):
            ang = 2 * math.pi * j * k / N              # 该格元素的相位角
            # complex(实部, 虚部)：Python 内置的复数构造器，等于 cos + i·sin
            row.append(complex(math.cos(ang), math.sin(ang)) / math.sqrt(N))
        M.append(row)
    return M

N = 4
M = qft_matrix(N)
vec = [0, 1, 0, 0]                   # 输入基矢 |01>（振幅只落在第 1 格）

for j in range(N):
    acc = 0j                         # 0j 是复数零：累加器从 0+0i 起
    for k in range(N):
        acc = acc + M[j][k] * vec[k] # 矩阵乘向量：第 j 行与向量逐项相乘再相加
    # round(...)+0.0 把"-0.0"这类浮点负零归正，纯为好看
    print(f"|{j:02b}>  实部 {round(acc.real, 3) + 0.0:>5}  虚部 {round(acc.imag, 3) + 0.0:>5}  概率 {round(abs(acc) ** 2, 3)}")
```

四行分别是 `|00>` 实部 0.5、`|01>` 虚部 0.5、`|10>` 实部 −0.5、`|11>` 虚部 −0.5，概率全是 `0.25`。四个振幅一样大，但相位依次是 $0°、90°、180°、270°$ —— 把 $N$ 换成 8、16，这条"相位斜线"会继续加密，这正是傅里叶变换的骨架。

### 实验 3（python）：相位估计读数的分布

现在看相位估计到底能把 $\varphi$ 读多准：

```python title="两个相位，两种读数命运"
import math

def pe_probs(phi, t):
    """t 比特相位估计的输出分布：P(j) = |Σ_k e^(2πi·k(φ−j/N))|² / N²"""
    N = 2 ** t
    probs = []
    for j in range(N):
        acc = 0j                                    # 复数累加器
        for k in range(N):
            ang = 2 * math.pi * k * (phi - j / N)   # 第 k 项与"格点 j"的相位差
            acc = acc + complex(math.cos(ang), math.sin(ang))
        probs.append(abs(acc) ** 2 / N ** 2)        # abs(复数) 取模长，再平方得概率
    return probs

for phi, t in ((0.25, 3), (1 / 3, 5)):
    p = pe_probs(phi, t)
    best = 0                                        # 手写"找最大值"，不用额外工具
    for j in range(len(p)):
        if p[j] > p[best]:
            best = j
    print(f"φ={round(phi, 4)}  t={t}  读出 j={best}  概率={round(p[best], 3)}  估计 φ̂={round(best / 2 ** t, 4)}")
```

两行输出：`φ=0.25  t=3  读出 j=2  概率=1.0  估计 φ̂=0.25` 与 `φ=0.3333  t=5  读出 j=11  概率=0.684  估计 φ̂=0.3438`。第一行是"格点对齐"的完美情形，概率满格；第二行是非格点情形，读到最近格、概率约 $0.68$。把 `t` 从 5 加到 10，读出的是 $j=341$、$\hat\varphi=0.33301$，误差从 $0.0104$ 掉到约 $0.0003$，但峰高仍停在 $0.684$ 附近——**加计数比特买到的是"更准"，不是"必定命中"**。

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为 QFT 能一次性算出整张频谱。" 它确实只用 $O(n^2)$ 个门就"作用"完了 $N$ 维傅里叶变换，但**输出仍是 $N$ 个振幅，测量只给一个**。QFT 的用处是把信息集中到少数几个峰上（相位估计就是被集中的那一个峰），而不是把整张谱搬出来。任何"量子算得比经典快，因为并行算了 $N$ 遍"的说法，都在这一点上滑倒。

**误区二**："你以为相位估计只能读格点上的相位。" 当 $\varphi$ 不是 $2^{-t}$ 的整数倍时，读数会在最近的两个格点间分布（例 3 里 $j=11$ 拿 $0.684$、$j=10$ 拿 $0.171$）。**它给出的是高概率的近似，不是精确值**；要更准就加计数比特。工程上还会用连分数把 $\hat\varphi$ 反解回真正的有理数，那一步是纯经典运算。

**误区三**："你以为 QFT 就是给每个比特套一个 Hadamard。" 单比特时确实如此（实验 1），但两比特起就必须有**受控相位门** $R_k$——它们才是把"位置"翻译成"频率"的关键零件。只做 $H$ 的叠加得到的是均匀的"什么频率都有"，做不出峰。

:::

## 7. 练习

**练习 1**：把"相位被放大多少倍"和"能分辨的相位间隔"都改对：

```exercise
# @title: 练习：t 比特能把相位读到多细
# @check: 4.0
# @check: 0.125
# @hint: 相位被放大 2^t 倍：可读到的整数下标是 j = φ·2^t；能分辨的最小相位间隔是 1/2^t。
phi = 0.5
t = 3

j = phi * t            # ← 错在这：放大倍数是 2 的 t 次方，不是 t
res = 1 / t            # ← 错在这：分辨率是 2 的负 t 次方

print(j)
print(round(res, 4))
```

修好后是 `4.0` 与 `0.125`：$\varphi=0.5$、$t=3$ 时格点数 8，相位落在正中间的第 4 格；可分辨的最小间隔正好是 $1/8$。

**练习 2**：若把计数比特从 $t=4$ 加到 $t=5$，例 3 那种"非格点相位"的读出错误概率大致会怎样变化？为什么 Shor 只需要多项式个比特？

<details>
<summary>点开查看逐步解答</summary>

1. **误差来源**：$\varphi$ 落在两格之间时，读数以高概率落在最近的格；格距每加一个比特就缩小一半，所以估计误差 $|\hat\varphi-\varphi|$ 大约按 $1/2^t$ 缩小；
2. **峰高的长相**：单个格点的峰值概率会渐近到一个常数（例 3 里是约 $0.68$），并不会趋于 1——但读数与真值的**距离**在指数缩小，这才是精度保证 $1/2^{t+1}$ 的含义；
3. **对 Shor 的意义**：分解 $N$ 位大数只需 $t=O(N)$ 个计数比特就能以常数概率读准周期，失败就重跑，期望次数是常数；
4. **所以整条路是多项式的**：$O(n^2)$ 个 QFT 门 + $O(N)$ 个比特，全都随比特数多项式增长——这与 RSA 依赖的"经典指数时间"形成对照（第 34 章的老警报正是这么来的）；
5. **但别急**：这一切的前提是物理比特足够干净。真实机器的噪声会让相位读数先散掉，所以在 Shor 能跑之前，必须先把下一课的**量子纠错**装好。

</details>

## 8. 选读：门数为什么只花 O(n²)

<details>
<summary>选读 · 分而治之的相位账</summary>

经典 FFT 之所以能从 $O(N^2)$ 降到 $O(N\log N)$，靠的是把长度为 $N$ 的变换拆成两个长度为 $N/2$ 的子变换，递归地"分而治之"。量子 QFT 可以直接拆得更彻底，看一个比特的账：

把 $j$ 写成二进制 $j_1j_2\cdots j_n$，QFT 的输出可以整理成

$$\frac{1}{\sqrt N}\bigl(|0\rangle+e^{2\pi i\,0.j_n}|1\rangle\bigr)\otimes\bigl(|0\rangle+e^{2\pi i\,0.j_{n-1}j_n}|1\rangle\bigr)\otimes\cdots\otimes\bigl(|0\rangle+e^{2\pi i\,0.j_1j_2\cdots j_n}|1\rangle\bigr),$$

其中 $0.j_1j_2\cdots$ 表示二进制小数。**乘积形式**说明：每一个输出比特只依赖它自己那一位和"更靠后的若干位"——所以可以用一串 $H$ 加受控相位 $R_k$ 逐个建立，最后再翻转次序。

数一下：每个比特 1 个 $H$，加上来自后面比特的受控相位，总共 $n+(n-1)+\cdots+1=\dfrac{n(n+1)}{2}=O(n^2)$ 个门。这正是 QFT 相对经典 FFT 的"指数便宜"：**指数在规模里，不在门数里**。

但这份便宜有个无法回避的代价——$O(n^2)$ 个门作用在 $2^n$ 个振幅上，每个振幅都被"悄悄摸过"一遍。要让哪个相位真正显出峰来，还得靠受控-U 先把未知相位一遍遍抄上去。**准备比读取便宜得多，这大概是量子算法最常被误读的一件事**。

</details>
