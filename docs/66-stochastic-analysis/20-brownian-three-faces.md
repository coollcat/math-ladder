# 布朗运动的三副面孔

## 1. 从一个场景开始

上一课我们用一枚硬币造出了布朗运动。现在把显微镜架上去看看这个新同事的真面目：它有没有瞬移？曲线处处有切线吗？把它的时间轴放大一百倍，看到的还是不是"同一个家伙"？三个问题，三副面孔——每一副都不好惹：**连续**（没腿也能走遍天下）、**无处可微**（任何一点都找不到切线）、**自相似**（放大之后统计上还认得自己）。这一课把它们一次看清，因为后面整个随机微积分的大厦，都建在这三张脸的脾气之上。

## 2. 直觉解释

**核心直觉：一条"毛得没有尽头"的线，长度这个概念会当场破产。**

想想海岸线悖论：用 10 千米的尺子量是 5000 千米，换 1 千米的尺子量变成 6000 千米，尺子越短量出的海岸越长——因为短尺子能贴进更多海湾。布朗运动是把这毛病推到极致的海岸线。

- **面孔一 · 连续**：相邻时刻的位置差距被死死按住（增量方差随时长一起趋零），所以路径没有跳跃、抬笔不离纸。
- **面孔二 · 无处可微**：可微意味着小窗口里曲线越来越像一段直线。但布朗路径在任意小的窗口里仍然是一团新的毛刺——切线在每一点都被未来的噪声撕碎。
- **面孔三 · 自相似**：把时间轴拉长 $c$ 倍后观察 $B_{ct}$，它的典型幅度涨了 $\sqrt{c}$ 倍。也就是说，放大时间要**付出纵向的平方根代价**，付完之后的样子统计上和原来一模一样。

| 面孔 | 一句话人设 | 来自哪条公理/定理 |
| --- | --- | --- |
| 连续 | 不瞬移 | 公理直接声明 |
| 无处可微 | 每点都没有切线 | 深定理（选读给出论证思路） |
| 自相似 | 放大时间 ×c ≈ 放大幅度 ×√c | 由正态增量的方差可加性推出 |

## 3. 正式定义

**自相似律（面孔三的精确版）**：对任意 $c>0$，两个过程 $\lbrace B_{ct}\rbrace_{t\ge0}$ 与 $\lbrace\sqrt{c}\,B_t\rbrace_{t\ge 0}$ 有完全相同的统计规律（记作分布相等）。理由三步走完：

$$\operatorname{Var}(B_{ct})=ct=c\cdot t=\operatorname{Var}(\sqrt{c}\,B_t),$$

再注意到两者都是连续路径的高斯过程且均值同零、协方差结构一致，就完整匹配了。它经常写成缩放口诀：$B_{ct}\overset{d}{=}\sqrt{c}\,B_t$。

**无处可微（面孔二的精确版）**：称函数处处不可微，若在每一点 $t$ 上，差商极限

$$\lim_{h\to 0}\frac{B_{t+h}-B_{t}}{h}$$

都不存在有限值。注意强度：不是"个别坏点"，而是**一个切线制造厂都没有**。粗略账已经能预示结局——分子典型大小 $\sqrt{|h|}$，除以分母 $h$ 得到 $1/\sqrt{|h|}\to\infty$，而且这是在每个点上都发生的事。

## 4. 分步例题

**问**：你在屏幕上仔细端详布朗路径的 $[0,\,9]$ 时段，然后把观察窗收窄到 $[0,\,0.09]$ 这一细细的切片。切片时段缩到了百分之一，画面要怎么缩放才"像原来的样子"？

1. 时间尺度比 $c=100$；
2. 按自相似律，切片内位移的典型幅度是全图的 $\sqrt{c}=10$ 倍相对放大——纵向必须**压缩 10 倍**才能摆回同一屏幕高度；
3. 压缩完之后，切片的毛糙程度与原图如出一辙——你找不到任何一个"更平滑"的版本。

这就是为什么行情软件无论怎么切换秒线、分钟线，分析师都说不出"现在够细了"——自相似没有最底层，缩放的钱永远付不完。

## 5. 动手实验

下面这条主实验：生成一条极细的正态随机游走近似，然后连开三级放大镜。每次放大时间轴几百倍，同时按平方根价钱重新标定纵轴——你会亲眼看到"放大后还是它自己"。代码还会顺手报告每个窗口里最陡弦的斜率量级，给"无处可微"留下数字证据。

```python title="三级放大镜下的布朗路径"
import random                     # 标准库随机模块；seed 固定保证可复现
import matplotlib.pyplot as plt   # 绘图模块

random.seed(42)
N = 900000                        # 把 [0,1] 切成 90 万个微步，dt = 1/N
dt = 1.0 / N
path = [0.0]                      # path[i] = 前 i 个微步累计的位置
pos = 0.0
for k in range(N):
    pos += random.gauss(0.0, dt ** 0.5)   # gauss(mu, sigma)：抽正态数，步长 sqrt(dt)
    path.append(pos)

windows = [(0, N), (0, N // 900), (300000, 300030)]   # 三档观察窗：全图 / 缩百倍 / 再缩千倍量级
zooms = [1.0, 30.0, 173.2]        # 各窗口对应的纵向标定因子 √(宽度)，手工给出近似的√900≈30、√3万≈173.2
for i in range(3):
    a, b = windows[i]
    piece = path[a:b + 1]
    plt.subplot(3, 1, i + 1)      # subplot(行, 列, 序号)：把画布分成 3 行，取第 i+1 格
    plt.plot([a + j * dt for j in range(len(piece))], piece, linewidth=0.7)
    steep = max(abs(piece[j + 1] - piece[j]) for j in range(len(piece) - 1)) / (b - a) * len(piece)
    print("窗口", i + 1, " 最陡单位时长弦斜率量级 ≈", round(steep, 1))
plt.show()
```

读图要点：第二、第三幅并非更平滑，只是按 $\sqrt{\text{宽度}}$ 的价钱重新装裱过的同款毛刺。而打印出来的斜率量级一路不见收敛迹象——这就是面孔二在数据里的嘴脸。

再把两股"时间的速度"并排摆在一起看：线性走与平方根走，差距随时间越拉越大。

## 6. 常见误区

:::warning[常见误区]

- **"画不出来就是不存在"** —— 反了。差商在任何尺度下都有具体数值，崩掉的是它们共同的极限，不是数值本身。
- **"放大镜越精密越光滑"** —— 对光可以，对布朗运动不行：自相似保证每个分辨率下都是同级毛糙，不存在"足够细就变平"的那一天。
- **"无处可微 = 平均速度也没意义"** —— 分寸别过头。整段区间的总位移 ÷ 总时长依然是良好定义的平均速率；失效的是让区间收缩到一点的极限。

:::

## 7. 练习

同一帧真实的布朗路径快照存在字典 `SNAP` 里：键是窗口宽度 $h$，值是左端到右端的位移。计算弦斜率（位移 ÷ 宽度）本应看到它随窗口缩小而爆炸；初始代码却用了错误的归一化指数，把这场爆炸"洗平"了。修好它：

```exercise
# @title: 差商的爆炸现场
# @check: 0.3
# @check: -1.2
# @check: 8.0
# @hint: 可微性的试金石是 ΔB/h。若分子天生 ~ √h 的尺寸，除以 h 会得到什么趋势？换成除以 h^0.5 又会把信号洗成什么？
SNAP = {1.0: 0.30, 0.1: -0.12, 0.01: 0.08}   # 同一条真实路径在三档窗口上的位移快照

def chord_slope(h):
    return SNAP[h] / h ** 0.5    # ← 归一化指数选错：这会把发散洗成温吞水

print(round(chord_slope(1.0), 2))
print(round(chord_slope(0.1), 2))
print(abs(round(chord_slope(0.01), 2)))
```

<details>
<summary>点开查看逐步解答</summary>

正确的弦斜率就是朴素的 $\Delta B/h$：

```python
def chord_slope(h):
    return SNAP[h] / h           # 上升量除以时间宽度，这才是差商的本义

print(round(chord_slope(1.0), 2))      # 0.30 / 1   = 0.3
print(round(chord_slope(0.1), 2))      # -0.12 / 0.1 = -1.2
print(abs(round(chord_slope(0.01), 2))) # |0.08 / 0.01| = 8.0
```

斜率从 $0.3$ 冲到 $8$，大约每隔十倍窗口放大 $\sqrt{10}$ 倍量级——这正是 $\Delta B\sim\sqrt{h}$ 除以 $h$ 后剩下的东西。错版里那个 `/ h ** 0.5` 不是无害的小笔误：它把真实信号全部归一成常数，恰好抹掉了"不可微"的全部物证。以后看到有人对粗糙数据先做幂次归一再谈极限，先问一句指数从哪来。

</details>

## 8. 选读证明：为什么每个点都在跟切线作对

<details>
<summary>选读：Paley–Wiener–Zygmund 论证的思想骨架</summary>

证明的枢纽是一个放大的直觉：**不管在哪一点，只要窗口取得足够刁钻，路径就会在里面甩出足额的振荡。**

反设 $B$ 在某点 $t_0$ 可微，导数为有限数 $L$。那么存在小区间半径 $\delta$，使得区间内的所有弦斜率都被 $|L|+1$ 按住——即路径在这段邻域里的波形倾斜是有界的。

关键引理（帕利–维纳型）：取一列嵌套的细分网格，任一点落入"邻近折返网格点"的事件具有一致的概率下界。于是：把 $[0,1]$ 等分为 $n$ 段，事件

$$E_n=\lbrace\text{至少一个小区间内出现幅度超过 } C/\sqrt{n}\text{ 且由至少 } k\text{ 步完成的上冲}\rbrace$$

以趋于 1 的概率发生；而一旦某个这样的上冲落在 $t_0$ 的邻域之内，那段邻域的平均弦斜率就被迫越过界 $C/k$。让 $C$ 超过 $|L|+1$（这只是概率不为零的事件），便与"邻域内斜率被按住"矛盾。矛盾成立 ⇒ $t_0$ 处不可微。又因 $t_0$ 是随便挑的——没有一个点是清白的。

顺带一提面孔三的一条推论：若某随机过程满足 $X_{ct}\overset{d}{=}c^{H}X_t$（$H$ 叫 Hurst 指数），布朗运动对应 $H=1/2$。金融波动率建模中那些 $H\neq\tfrac12$ 的过程，正是靠调这颗旋钮来加重或减轻毛糙度的。

</details>
