## 前置回望

一元微积分早已备好全部原料：偏导数就是冻住其余变量后的普通导数，链式法则升级成 Jacobian，重积分沿用“切条求和”的老账本；卷一向量的点积则提供方向感的雏形。本章不做新发明，而是把这些单变量工具搬上高维地形。

## 实战挑战 · 浓雾搜救：跟着梯度找火源

情境原创，题型对标考研数学「方向导数与梯度」高频考点。

深夜山里两名远足者失联，他们生了一堆篝火取暖。热成像无人机把搜救区近似成一张温度地图：以篝火为原点，地表温度模型（摄氏度；坐标单位：十米）为

$$T(x,y) = 100 - 3x^2 - 4y^2$$

离火越近越热，原点处最热，为 100 度。无人机悬停在救援中转点 $P(1,1)$，电量只够再飞一小段，每一步都要问「往哪飞最值」。

**(a)** 求温度场在 $P$ 处的梯度 $\nabla T(1,1)$；

**(b)** 朝哪个方向飞升温最快？最大升温率是多少（度/十米）？把这个方向写成单位向量；

**(c)** 队长要求先沿「温度暂时不变」的方向横移侦察——找出一个方向导数为零的方向并验证；

**(d)** 若无人机沿正东 $(1,0)$ 飞，温度变化率是多少？

计算骨架已搭好，但藏着六处错误，请修到全部通过：

```exercise
# @title: 实战挑战：温度场的梯度与方向导数
# @check: -6
# @check: -8
# @check: 10.0
# @check: -0.6
# @check: -0.8
# @check: 0
# @check: -6
# @hint: T=100-3x^2-4y^2 对 x 求偏导时，100 和 -4y^2 都是常数、别丢负号；最大变化率不是分量相加。单位方向要把梯度除以它的长度；和 (-6,-8) 垂直的方向可试 (4,-3)。
x = 1   # P 点横坐标
y = 1   # P 点纵坐标

gx = 3 * x        # ← 有错一：对 x 的偏导是 -6x
gy = -4 * y       # 对 y 的偏导（这行是对的）
print(gx)
print(gy)

rate = gx + gy    # ← 有错二：最大变化率不是把两个分量相加
print(rate)

unit_x = 0.6      # ← 有错三：单位方向要保留梯度的符号
unit_y = 0.8      # ← 有错四：长度已经除过，方向也不能翻
print(unit_x)
print(unit_y)

probe_x = 4
probe_y = 3       # ← 有错五：这个候选方向应和梯度垂直
zero_check = gx * probe_x + gy * probe_y
print(zero_check)

east = gy         # ← 有错六：沿正东 (1,0) 的变化率只跟 gx 有关
print(east)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 固定另一个变量求一元导数：$T_x = -6x$，$T_y = -8y$；代入 $P(1,1)$ 得

$$\nabla T(1,1) = (-6,\,-8)$$

**(b)** 最快升温方向就是梯度方向 $(-6,-8)$；它的长度 $\sqrt{(-6)^2+(-8)^2}=10$，所以最大升温率为每十米 10 度，单位向量是 $(-6,-8)/10=(-0.6,\,-0.8)$——直指火堆。

**(c)** 方向导数为零当且仅当方向与梯度垂直。取候选 $(4,-3)$：$(-6)\times4+(-8)\times(-3)=-24+24=0$ ✓。它正是等温线 $3x^2+4y^2=c$ 在 $P$ 点的切向——沿等温线走，读数不动。

**(d)** 正东 $(1,0)$ 已是单位向量，变化率 $D=\nabla T\cdot(1,0)=-6$：向东每十米降温 6 度。

用 Python 全面复查：

```python
x, y = 1, 1
gx = -6 * x
gy = -8 * y
rate = (gx * gx + gy * gy) ** 0.5    # 最大变化率
unit_x = gx / rate                   # 单位方向分量
unit_y = gy / rate
zero_check = gx * 4 + gy * (-3)      # 与候选方向 (4,-3) 作点积
east = gx                            # 正东方向的变化率
print(gx)
print(gy)
print(rate)
print(unit_x)
print(unit_y)
print(zero_check)
print(east)
```

物理哨卡：全图最热点在原点，而梯度永远指向升温最快的方向——所以从任何一点出发，梯度都「指回」火堆；反过来沿 $-\nabla T$ 走会越来越冷。(b) 中方向带负号的物理含义就在这里。
</details>

## 实战挑战 · 偏导别丢常数项

$f(x,y)=x^2y+3x$ 对 $x$ 求偏导：把 $y$ 冻成常数，得到 $f_x = 2xy + 3$。下面这题丢了 $3x$ 求导出的 $3$，修到输出 `7`：

```exercise
# @title: 实战挑战：偏导别丢常数项
# @check: 7
# @hint: 对 x 求偏导时，3x 这项求导得 3，别丢掉。
x, y = 1, 2
fx = 2 * x * y          # ← 问题在这：漏了 3x 求导得到的 3
print(fx)
```

<details>
<summary>点开查看逐步解答</summary>

对 $x$ 求偏导时把 $y$ 当常数，逐项求导：$x^2y$ 得 $2xy$，$3x$ 得 $3$：

```python
fx = 2 * x * y + 3    # 2xy + 3
print(fx)             # 2*1*2 + 3 = 7
```

初始代码漏了 $3x$ 这一项的导数 $3$。代值 $f_x(1,2) = 2\times1\times2 + 3 = 7$。偏导的"冻住其他变量"常让人只盯着含 $y$ 的项，忘了纯 $x$ 项也要照常求导——这是多元微积分第一课的头号陷阱。

</details>
