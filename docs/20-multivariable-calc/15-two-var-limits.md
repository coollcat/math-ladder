# 二元极限与连续：路径一变命运就变

## 1. 从一个场景开始

高原上两道山脊交汇的垭口。向导从东山脊下来，报告"越走越接近 0.5"；另一支队伍沿谷底上来，报告"越走越接近 0"。同一个点，两份海拔报告。把 [多元函数与等高线](./10-multivariable-functions.md) 那张地图放大一看，这个点周围的等高线是一把扇形展开的直线——压根没有围出一个小圈。想问"这个点的高度趋于几"，得先回答"你从哪条路来"。一元极限那套"从左右两路夹击"的老办法，到了平面上突然失灵。

## 2. 直觉解释

一元极限逼近一个点只有两条路：从左边、从右边。两条路答案一致，极限就成立。

二元极限 $\lim_{(x,y)\to(a,b)}$ 的处境完全不同：平面上逼近一点的路有**无穷多条**——直线、折线、抛物线、螺旋线，条条合法。极限存在的门槛于是水涨船高：

> **所有路径必须异口同声**。只要有一条路报出不同的数，极限就不存在。

本课请出两位主角（在原点处都没定义，原点本身不参与讨论）：

$$f(x,y)=\frac{xy}{x^2+y^2},\qquad g(x,y)=\frac{x^2y}{x^4+y^2}.$$

$f$ 负责演示"路径一变命运就变"；$g$ 更狡猾——它能把整族直线都骗过去。

## 3. 正式定义

**二重极限**（同时逼近）：若存在数 $L$，使得对任意 $\epsilon>0$ 都能找到 $\delta>0$，只要 $0<\sqrt{(x-a)^2+(y-b)^2}<\delta$ 就有 $\lvert f(x,y)-L\rvert<\epsilon$，则称 $f$ 在 $(a,b)$ 的二重极限为 $L$。

定义管的是**圆盘**：$\delta$ 圈住的一整片点云全体达标，不是某几条路达标。这正是上一卷 [函数极限与连续性](../19-real-analysis/30-epsilon-delta-continuity.md) 那套 ε-δ 语言的升维版——把数轴上的距离 $\lvert x-a\rvert$ 换成平面上的距离。

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $(x,y)\to(a,b)$ | 二维逼近 | 点从四面八方涌向目标 |
| $\epsilon$ | 误差容限 | 先给出的读数精度要求 |
| $\delta$ | 半径 | 圆盘大小：盘内除圆心外全部达标 |
| 路径 | 一条逼近路线 | 趋于 $(a,b)$ 的任意连续走法 |

**累次极限**（先后结算）：先固定 $y$ 让 $x\to a$，得到一个关于 $y$ 的结果，再让 $y\to b$，记作 $\lim_{y\to b}\lim_{x\to a}f$。它只考**两条正交路线**；二重极限考**全部路线**——两场考试的难度不同。

**二元连续**：$f$ 在 $(a,b)$ 连续，当且仅当二重极限存在且等于函数值 $f(a,b)$。后面 [二重积分与 Fubini 直觉](./50-double-integrals.md) 说"对连续函数可交换积分顺序"、偏导课说"对可微的函数"——这些白纸黑字的前提里，"连续"这一半由这里发出通行证（"可微"的正式户口更靠后才会办理）。

## 4. 分步例题

**例 1 · 主角 f：路径一变命运就变**。考察 $f(x,y)=\dfrac{xy}{x^2+y^2}$ 在原点的极限。

1. 沿直线 $y=0$（横轴）：$f=0$，读数恒为 0，趋势是 0；
2. 沿直线 $y=x$：$f=\dfrac{x^2}{2x^2}=\dfrac12$，读数恒为 $\tfrac12$，趋势是 $\tfrac12$；
3. 沿一般直线 $y=kx$：$f=\dfrac{kx^2}{(1+k^2)x^2}=\dfrac{k}{1+k^2}$——斜率一换，答案就换；
4. 三条路三种归宿（0、0.5、0.4），圆盘定义不可能同时伺候三个 $L$：**二重极限不存在**。

顺带看穿它的几何秘密：沿射线 $y=kx$ 读数恒等于 $\dfrac{k}{1+k^2}$，与远近无关。所以 $f$ 的等高线是一族过原点的直线（扇形）——第 1 节那张地图画的就是它。

**例 2 · 主角 g：整族直线全放行，一条曲线逮住它**。考察 $g(x,y)=\dfrac{x^2y}{x^4+y^2}$ 在原点的极限。

1. 沿任何直线 $y=kx$：$g=\dfrac{kx}{x^2+k^2}\to 0$——整族直线异口同声报 0；
2. 累次极限也绿灯：固定 $y\ne0$ 先让 $x\to0$，得 0；固定 $x\ne0$ 再让 $y\to0$，也得 0；
3. 但沿抛物线 $y=x^2$：$g=\dfrac{x^4}{x^4+x^4}=\dfrac12$，读数**处处恰好是 1/2**；
4. 直线与累次的证词全是 0，曲线的证词是 1/2——二重极限仍不存在。

**例 3 · 连续通行证**。$h(x,y)=x^2+y^2$ 在原点：极限为 0，函数值也是 0，连续 ✓。主角 $f$ 在原点压根没定义，谈不上连续；就算好心补上 $f(0,0)=0$，极限本身都不存在，通行证还是发不出去。

### 实验 3：路径探针

```python title="路径探针：同一点，不同方向的读数"
import math

def f(x, y):
    return x * y / (x * x + y * y)    # 主角 f：原点处没定义

for r in [0.1, 0.01, 0.001]:          # 半径一路缩小：三路齐发逼近原点
    row = []
    for deg in [0, 45, 90]:           # 三条射线：横轴、对角线、纵轴
        rad = math.radians(deg)       # 角度转弧度
        row.append(round(f(r * math.cos(rad), r * math.sin(rad)), 3))
    print(r, row)                     # 每行报：同一半径上三个方向的读数

def g(x, y):
    return x * x * y / (x ** 4 + y * y)   # 主角 g：直线族测谎仪的漏网之鱼

print(round(g(0.1, 0.01), 3))         # 沿抛物线 y = x^2 的读数
print(round(g(0.01, 0.0001), 3))      # 半径再小十倍，读数纹丝不动
```

输出：三行 `[0.0, 0.5, 0.0]`——半径缩小十倍，对角线的读数死死停在 0.5，横轴纵轴停在 0。最后两行 `0.5`、`0.5` 是主角 g 沿 $y=x^2$ 的读数：距离越近，它越不像 0。

## 6. 练习

```exercise
# @title: 练习：修正函数，看路径翻脸
# @check: 0.0
# @check: 0.5
# @check: 0.4
# @hint: 分子是两个坐标的乘积 x*y，不是相加；分母 x*x + y*y 没问题。
def f(x, y):
    return x + y / (x * x + y * y)    # ← 有错：分子把乘法写成了加法

h = 0.001
print(round(f(h, 0), 3))              # 沿横轴 y=0 的读数
print(round(f(h, h), 3))              # 沿对角线 y=x 的读数
print(round(f(h, 2 * h), 3))          # 沿 y=2x 的读数
```

初始代码能跑，但三个读数是 `0.001`、`500.001`、`400.001`——把分子改回 $xy$ 后，三行变成 `0.0`、`0.5`、`0.4`：三条路三个归宿，极限不存在。

<details>
<summary>点开查看逐步解答</summary>

分子应为 $x\cdot y$：

```python
def f(x, y):
    return x * y / (x * x + y * y)
```

沿 $y=0$ 读数恒 0；沿 $y=kx$ 读数恒为 $\dfrac{k}{1+k^2}$：$k=1$ 给 0.5，$k=2$ 给 $\dfrac25=0.4$。三个读数各奔前程，圆盘定义找不到同时达标的 $L$。

可执行复查：

```python
def f(x, y):
    return x * y / (x * x + y * y)

h = 0.001
print(round(f(h, 0), 3))
print(round(f(h, h), 3))
print(round(f(h, 2 * h), 3))
```

</details>

**练习 2**（思考）：主角 g 沿每条直线都趋于 0，两个累次极限也都是 0，为什么二重极限仍不存在？

<details>
<summary>点开查看逐步解答</summary>

二重极限要求 $\delta$ 圆盘内**所有点**同时达标，而圆盘里既有直线上的点（读数近 0），也有抛物线 $y=x^2$ 上的点（读数恒 1/2）。取 $\epsilon=0.1$：无论 $\delta$ 多小，盘内总能找到抛物线上的点，读数离 0 至少 0.5——没有任何 $L$ 能同时讨好两边。累次极限与直线族都是"抽样检查"，圆盘定义才是"全员到齐"。

</details>

## 7. 常见误区

::::warning[常见误区]

**误区一**：你以为"上下左右四个方向一致"就能宣布极限存在。一元世界左右夹击就够了；平面上直线之外还有曲线——主角 g 被整族直线放行，却被 $y=x^2$ 一条曲线逮住。

**误区二**：你以为两个累次极限存在且相等，二重极限就存在。g 的两个累次极限都是 0，二重极限仍不存在。"先后结算"只考两条正交路线，"同时逼近"考全部路线，门槛天差地别。

**误区三**：你以为偏导数存在，函数至少在这里连续。给主角 f 补上 $f(0,0)=0$：沿两根坐标轴算"偏导"都能得到 0，可函数在这里连极限都没有——偏导只盯着两根坐标轴看路，连"连续"都保不住。

::::

## 9. 选读：圆盘里的 ε-δ 审判

<details>
<summary>选读 · 主角 f 为什么当场翻车</summary>

按圆盘定义审判 $f$：假设极限为 $L$，取 $\epsilon=0.1$。无论候选的 $\delta$ 多小，圆盘里总能找到两家人：横轴上的点（如 $(\delta/2,0)$，读数 0）与对角线上的点（如 $(\delta/2,\delta/2)$，读数 0.5）。0 与 0.5 距离 0.5，至少有一个离 $L$ 超过 0.25>0.1——这个 $L$ 出局。$L$ 是任取的，所以没有任何 $L$ 能过审，极限不存在。对比一元世界的判决书：那时只需管住左右两路，现在要管住**一整片点云**——这正是"高维极限更苛刻"的精确含义。

</details>
