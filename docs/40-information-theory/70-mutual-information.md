# 互信息：两个变量共享多少信息

## 1. 从一个场景开始

气象站的两个传感器都很诚实：温度计如实记录温度，湿度计如实记录湿度。可比对数据时你会发现，它们在偷偷剧透彼此——温度低的日子往往更干燥。两个都"没错"的变量之间，居然有一份额外的情报往来。

这份情报价值多少钱？前面几课我们学会了给"一个人的话"计价（自信息）、给"一群人的账本"计价（熵）、给"两张错的地图"记冤枉钱（交叉熵、KL 散度）。现在轮到最后一块拼图：**两个真实变量之间，平均共享几比特**。特征筛选、医学检验评价、神经科学的脑区耦合分析，用的都是这个量。

## 2. 直觉解释

互信息回答一个问题：**知道 Y 之后，X 的平均惊讶减少了几比特？**

三个锚点先钉死边界：

- 毫不相干的两件事（北京的气温、巴黎的一枚硬币）：听完硬币的结果再看气温，惊讶一点没少，共享 **0 比特**；
- 一一对应的映射（华氏度与摄氏度）：听清一个等于知晓另一个，共享的是**全部**不确定性；
- 中间地带（烟雾浓度与火情）：警报响了，起火的把握大增但未必坐实——共享的是介于 0 与全部之间的某个数。

一句话成型：**平均而言，Y 替 X 排除了多少悬念，两个变量就共享多少比特的信息**。悬念的消除不是一次性的——是把"事前整套惊讶"打折到"事后剩下的惊讶"，折扣的部分才归情报所有。

## 3. 正式定义

第 36 章你已经摆过 $X,Y$ 的**联合分布表** $p(x,y)$；这里补齐信息论口径的两件工具：联合熵 $H(X,Y)$ 与**条件熵** $H(X\mid Y)$——后者是"听完 Y 之后、平均还剩多少惊讶"。三者拼出主角：

$$I(X;Y)=\sum_{x}\sum_{y}p(x,y)\,\log_2\frac{p(x,y)}{p(x)\,p(y)}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p(x,y)$ | 联合概率 | 两件事一起发生的频率 |
| $p(x)\,p(y)$ | 独立性参照 | 假如二者毫无瓜葛，它俩同台的概率 |
| $\log_2\frac{p(x,y)}{p(x)p(y)}$ | 逐格共享度 | 该组合比"纯属巧合"多密了几倍 |
| $I(X;Y)$ | 互信息 | 联合与独立的 KL 散度，单位比特 |

同一个量的三种化身（全部相等，各有用场）：

$$I(X;Y)=D_{KL}(p(x,y)\Vert p(x)p(y))=H(X)+H(Y)-H(X,Y)=H(X)-H(X\mid Y)$$

第一式把互信息安放在上一课的地基上：它是"联合分布 vs 独立假象"的 KL 散度；第三式的减法最好背：**重叠部分只算一次，剪掉重复记账的就是共享量**。性质清单：非负且对称（$I(X;Y)=I(Y;X)$）；$I=0$ 当且仅当两变量独立；最强情形 $I=H(X)$，即 Y 把 X 的悬念包圆。

## 4. 分步例题

**例 1（满格共享）**：均匀四态密码 $X$（各 $\frac14$），$Y$ 是它的一一对应暗号。

1. 联合表只在四个对角格上有 $p=\frac14$，其余格子为 0（按约定记零）；
2. 每个存活格的"巧合倍率"：$\frac{1/4}{(1/4)(1/4)}=4$，$\log_2 4=2$ 比特；
3. 加权求和：$4\times\frac14\times2=2$ 比特；
4. 对照 $H(X)=\log_2 4=2$：满格 ✓ 听说暗号，密码零残悬念。

**例 2（部分共享）**：公平硬币 $X$，观测量 $Y$ 以翻转概率 $e=0.25$ 泄露它。

1. 事件前总悬念 $H(X)=1$ 比特；
2. 听过 $Y$ 之后还剩的条件熵 $H(X\mid Y)=h(0.25)\approx 0.811$ 比特（翻车风险自己贡献的那份悬念洗不掉）；
3. 相减得互信息：$1-0.811=0.189$ 比特——四分之一翻转率的信道，每次观测平均只递来约 0.19 比特情报。

眼熟吗？信道噪声课上它叫"容量曲线"；现在你知道了它的真实身份：这就是 $I(\text{发};\text{收})$ 本尊——噪声越大，输出替输入排除的悬念越少。选讲一小节还会回到这里兑现"最大值"的承诺。先动手往下走：下面用一张 2×2 表把三种算法摆在同一口锅里煮。

### 实验 2（python）：三种算法共同指认 0.189

```python title="同一张联合表上的三条算法路线"
import math   # 数学函数库

e = 0.25                                # 观测的翻转概率
joint = [[0.5 * (1 - e), 0.5 * e],      # 联合表：行是硬币 X，列是观测 Y
         [0.5 * e, 0.5 * (1 - e)]]

def entropy(probs):
    total = 0
    for p in probs:
        if p > 0:
            total = total - p * math.log2(p)
    return total

def marginals_from(joint):              # 从联合表抹出两条边际
    rows = [sum(row) for row in joint]  # 列表推导式：对每行求和，凑出 X 的边际
    cols = []
    for j in range(len(joint[0])):
        acc = 0                         # 列方向的游标累加器
        for i in range(len(joint)):
            acc = acc + joint[i][j]
        cols.append(acc)
    return rows, cols

px, py = marginals_from(joint)

def route_kl():                         # 路线一：联合对独立假象的 KL
    total = 0
    for i in range(2):
        for j in range(2):
            if joint[i][j] > 0:
                total = total + joint[i][j] * math.log2(joint[i][j] / (px[i] * py[j]))
    return total

flat = [joint[i][j] for i in range(2) for j in range(2)]   # 摊平成一整张表的取值
hx = entropy(px)                        # 边际熵 H(X)：只看硬币自己
hy = entropy(py)                        # 边际熵 H(Y)：只看观测自己
hxy = entropy(flat)                     # 联合熵 H(X,Y)：两件事捆在一起的总悬念

print(f"KL 路线     I = {round(route_kl(), 3)}")
print(f"H+H-H 路线  I = {round(hx + hy - hxy, 3)}")
print(f"H(X)-H(X|Y) = {round(hx - (hxy - hy), 3)}")
```

三条路径同时报出 0.189——不仅数值一致，连误差源头也一致（同一批双精度浮点）。顺手把 `e` 改成 0 或 0.5 再跑：0.189 应变成 1.0 或 0.0 附近的数值噪声残留。**理论保证非负，程序尾巴上的 ±ε 是机器的呼吸声，别把它当结论。**

### 快问快答

```quiz
两位助教统计发现：学习时长与考试成绩的相关系数恰好为 0。下列哪句成立？
- 时长与成绩毫不相干
- 二者仍可能存在非线性的强关联 [*]
- 相关数据出了错
? 相关系数只盯线性关系：抛物线形的"中等时长最危险"这种倒 U 关联照样让它归零。互信息不看形状只看联合分布——这时正是它上岗的时候。
```

:::warning[常见误区]

**误区一**："你以为互信息就是相关系数换了件衣服。" 相关系数只量线性、取值可有正负有界；互信息管一切统计依赖、恒非负、以比特为单位。U 型关系能让相关系数躺平归零，互信息却看得一清二楚。

**误区二**："你以为共享信息多就代表一方导致另一方。" 手表的心率数据和急诊挂号人数共享海量比特，谁也没推动谁。互信息捕捉的是不确定性上的共舞，因果问题要靠干预实验另起炉灶。

**误区三**："你以为只知道一边时算互信息没有意义。" 单边情况照样能算：$I(X;Y)=H(X)-H(X\mid Y)$ 翻译过来就是"在什么都没听到的前提下，这条情报的平均身价"。知道得越晚，惊喜不减反增的情形在数学上根本排不出来。

:::

**练习 1**：两张现成的联合表：一张是"暗号表"（一一对应），一张是"各掷各的硬币"。下面的代码能跑，但比值漏掉了半边参照——改到通过：

```exercise
# @title: 练习：巧合的价码要扣干净
# @check: 2.0
# @check: 0.0
# @hint: 参照物是「假如二者毫无瓜葛」的同框概率 p(x)*p(y)——分母必须同时挂上两个边际，少一半就会把共享情报错估成独立甚至倒贴。
import math   # 数学函数库

def mutual_info(joint):
    n = len(joint)
    px = []                       # 行边际
    for row in joint:
        px.append(sum(row))
    py = []                       # 列边际
    for j in range(n):
        col = 0
        for k in range(n):
            col = col + joint[k][j]
        py.append(col)
    mi = 0
    for i in range(n):
        for j in range(n):
            if joint[i][j] > 0:
                mi = mi + joint[i][j] * math.log2(joint[i][j] / py[j])   # ← 问题在这：分母只除了列边际
    return mi

secret = [
    [0.25, 0, 0, 0],
    [0, 0.25, 0, 0],
    [0, 0, 0.25, 0],
    [0, 0, 0, 0.25],
]

coins = [
    [0.25, 0.25],
    [0.25, 0.25],
]

print(mutual_info(secret))
print(mutual_info(coins))
```

<summary>点开查看逐步解答</summary>

两份结论相同，但对病人的先验而言"减少的惊讶"不同：A 流程里检查结果是唯一的剧透者，独享从 0.9 前提往确定方向推进的全部份额……哦不，反过来才准确：病人已有相当把握时，后续确证消息的增量互信息趋近于零；真正的大头在"把低怀疑推成高把握"的第一份证据。这就是序贯检验设计的通用法则：每一步选择让 $I(\text{新数据};\text{病情})$ 最大的检验，省下的是冤枉的复查费。

## 7. 选读：信道容量的正式户口

<details>
<summary>选读 · 你在第 40 课欠下的那张欠条</summary>

信道噪声课的选读里埋过一句：容量公式的严格身份是"互信息对输入分布取最大值"。现在兑付：$C=\max_{p(x)}I(X;Y)$——发信人挑选最有利于传输的输入分布，把共享信息的通道撑到最宽。二元对称信道的对称性让"五五开的输入"自动最优，于是最大化的结果退回 $1-h(e)$，老公式换了正装重新登场。更远的风景留给下一课的高潮：工程上真正的握手发生在"语言的困惑度"与"信道的容量"碰面之时——两条支流在同一片海汇合。

</details>
