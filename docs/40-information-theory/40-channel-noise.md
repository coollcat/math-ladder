# 信道与噪声：在有干扰的世界里通信

## 1. 从一个场景开始

你的耳机和手机之间隔着一张沙发、一堵墙，还有微波炉、WiFi 路由器在同一个频段上狂轰滥炸。可音乐照播、通话不断——这些比特是怎么穿过战场的？

第 35 章的纠错码课已经见过"用冗余换可靠"；这一课补上信息论的最后一块拼图：**给一条有噪声的水路算出运力上限**。香农 1948 年证明：只要传输速率低于某个数（信道容量），就存在让错误率任意小的编码方案。这个定理把"可靠通信"从祈祷变成了工程预算。

## 2. 直觉解释

最简单的战场模型叫**二元对称信道**：发送 0 或 1，每个比特以概率 $e$（翻转概率）被篡改，各比特遭殃与否互不相干。

直觉三连问：

- $e=0$：完美水路，发什么收什么，每比特稳拿 1 比特信息；
- $e=0.5$：接收端看到的与发送端完全无关——纯掷硬币。此时信道"运力"为零：输出里不包含任何关于输入的信息；
- $e=0.9$ 呢？看似灾难，其实把收到的结果**全部取反**就是 $e=0.1$ 的好信道！糟糕程度封顶在 0.5。

容量公式（对称二元信道的情形）：

$$C = 1 - h(e) \ \text{ 比特/信道用法}$$

其中 $h(e)$ 就是上一课的二元熵。翻译过来：**信道每用一次，先扣掉噪声制造的那份悬念，剩下的才是净信息**。噪声越大扣得越多；$e\to0.5$ 时扣光，容量归零。上一课熵管"源头有多能压"，这一课容量管"路上最多能运"——两条定理合璧，通信的全部预算表就齐了。

## 3. 正式定义

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $e$ | 翻转概率 | 每个比特被信道篡改的可能性 |
| $h(e)$ | 二元熵函数 | $-e\log_2 e-(1-e)\log_2(1-e)$ |
| $C=1-h(e)$ | 信道容量 | 该信道每次使用能可靠传送的最大比特数 |
| $R$ | 编码速率 | 信息比特占实际发送比特的比例 |

**有噪编码定理**（香农第二定理）：只要 $R < C$，就存在编码方式让错误率任意低；反之 $R > C$ 时错误率有不可突破的下限。注意定理说的是"存在"，没给施工图——具体的好码（汉明码、LDPC、极化码）是此后七十年一代代工程师的接力，第 35 章你已经见过前几位选手。

## 4. 分步例题

**例**：某蓝牙链路受干扰后比特错误率 $e=0.1$。

1. 查熵函数：$h(0.1)=-0.1\times\log_2 0.1-0.9\times\log_2 0.9\approx 0.469$ 比特；
2. 扣除噪声税：$C=1-0.469=0.531$ 比特/用法；
3. 解读：这条烂水路每传一个比特，平均只能净送 0.531 比特真信息。想可靠地跑 100 kbps 的音频，物理层至少要发约 188 kbps 的原始符号；
4. 工程对策预告：与其硬扛 10% 错误率，不如先降低 $e$ 本身——下一节实验里的重复码是最笨的办法，蓝牙的真本事（跳频）在本章挑战里揭晓。

### 实验 2（python）：重复码值不值

裸奔 vs 每比特发三遍多数表决，实测两种策略的错误率：

```python title="裸传 vs 三倍重复码：一万比特的实战记录"
import random   # 随机库

e = 0.1         # 信道的翻转概率
n_bits = 10000  # 发送的信息比特数

# 第一轮：不加保护直接发
errors_plain = 0
for i in range(n_bits):
    bit = random.randint(0, 1)     # randint(0,1)：等可能生成 0 或 1
    noisy = bit
    if random.random() < e:        # 以概率 e 被信道篡改一次
        noisy = 1 - bit
    if noisy != bit:
        errors_plain = errors_plain + 1

# 第二轮：每个比特发三份，收端少数服从多数
errors_coded = 0
for i in range(n_bits):
    bit = random.randint(0, 1)
    ones = 0                       # 三份拷贝里收到几个 1
    for j in range(3):
        r = bit
        if random.random() < e:
            r = 1 - bit            # 这一份被篡改
        ones = ones + r
    decoded = 1 if ones >= 2 else 0   # 多数表决：两票及以上才判 1
    if decoded != bit:
        errors_coded = errors_coded + 1

print(f"裸传错误率 {round(errors_plain / n_bits, 4)}")
print(f"重复码错误率 {round(errors_coded / n_bits, 4)}")
```

裸传错误率贴着 0.1，重复码掉到约 0.028（理论值 $3e^2(1-e)+e^3=0.028$）——代价是速率只剩三分之一。这笔账正是容量公式的具象化：想又快又稳，就得请出比"无脑复读"聪明得多的编码（汉明码、LDPC……第 35 章的老朋友们）。

### 快问快答

```quiz
某信道翻转概率恰好 0.5。为什么说它的容量为零？
- 因为信号衰减得太厉害
- 因为输出与输入毫无统计关联，看了等于没看 [*]
- 因为速度太慢
? e=0.5 时输出纯随机：无论发什么，收到 0 和 1 各半，条件熵吃光了全部不确定性。有趣的是 e>0.5 反而还有救——把输出整体取反即可。
```

:::warning[常见误区]

**误区一**："你以为有噪声就必然丢数据。" 香农第二定理的核心承诺：只要速率压在容量之下，错误率可以做到想要多小就多小。噪声决定的是**速率上限**，不是可靠性上限——深空探测器靠这一定理在亿万公里外传回照片。

**误区二**："你以为重传是万能解药。" 重传协议假设"上行确认消息能安全返回"。深空场景往返延迟以小时计、某些军事场景根本不允许回执，这时前向纠错（FEC）才是主角。每种手段都有主场，别拿着锤子看什么都像钉子。

**误区三**："你以为错误率 e=0.49 的信道几乎没法用。" 算账：$h(0.49)=-0.49\log_2 0.49-0.51\log_2 0.51\approx 0.9997$，容量 $1-h(0.49)\approx 0.0003$ 比特，确实惨淡但为正——理论上仍可通信，只是要付出三千多倍的冗余（净送 1 比特约需 $1/0.0003\approx 3300$ 次信道使用）。真正无救的只有 e=0.5 一个点；而且别忘了取反技巧：e>0.5 的信道翻转一下就是 e<0.5 的好信道。

:::

## 6. 练习

**练习 1**：某信道翻转概率 $e=0.25$，求信道容量。下面的代码能跑但忘了扣噪声税——改到通过：

```exercise
# @title: 练习：算信道的净运力
# @check: 0.19
# @hint: 容量 = 1 - h(e)；你算出的 h(e) 只是「噪声制造的悬念」，要从 1 里扣掉它
import math   # 数学函数库

e = 0.25                 # 翻转概率

def h(p):                # 二元熵函数
    return -p * math.log2(p) - (1 - p) * math.log2(1 - p)

capacity = h(e)          # ← 问题在这：这只是噪声税，不是净运力
print(round(capacity, 2))
```

<details>
<summary>点开查看判题参考实现</summary>

```python
import math   # 数学函数库

e = 0.25                 # 翻转概率

def h(p):                # 二元熵函数
    return -p * math.log2(p) - (1 - p) * math.log2(1 - p)

capacity = 1 - h(e)      # 从 1 比特里扣掉噪声税
print(round(capacity, 2))
```

先算噪声税 $h(e)$，再用 $1-h(e)$ 得到净运力。

</details>

**练习 2**：接上题，若想在此信道上可靠跑 100 kbps 的有效载荷，物理层至少要发多少原始比特？

<details>
<summary>点开查看逐步解答</summary>

$h(0.25)=0.811$，容量 $C=1-0.811=0.189$ 比特/用法。要净送 100000 比特/秒，物理层需发约 $100000/0.189\approx 529000$ 比特/秒——五倍多的开销买"可靠"二字。任何无线标准表格里的码率字段，背后都是这道除法。

</details>

**练习 3**：实验 2 中把重复次数从 3 提到 5（五票取多数），错误率和信息速率分别怎样变化？极限在哪里？

<details>
<summary>点开查看逐步解答</summary>

错误率再降一个数量级：需要至少 3/5 份同时出错，约 $10e^3\approx 0.0086$ 加更高阶项。但速率跌到 1/5。无限加下去：错误率趋近 0，速率也趋近 0——暴力复读是一条越走越窄的路，永远到不了"既快又准"。香农定理的深刻在于断言存在聪明得多的码能同时保住速率（贴近 C）与可靠，哈夫曼之于压缩、LDPC 之于纠错，都是把"存在"变成"到手"的里程碑。

</details>

## 7. 选读：容量公式的户口

<details>
<summary>选读 · 互信息的一脚门缝</summary>

严格定义下，信道容量是互信息 $I(X;Y)=H(X)-H(X\mid Y)$ 对输入分布取最大值。对二元对称信道，可以验证均匀输入最优，且 $H(X\mid Y)=h(e)$（收到后仍剩的悬念恰是噪声贡献的），于是 $C=1-h(e)$。本课刻意绕开了联合熵与条件熵那套形式化装置，只保留「输出消除多少输入悬念」的直觉版；等你学完互信息的正式定义（后续课程），回头再看这条公式会像看到老朋友换了正装。

</details>
