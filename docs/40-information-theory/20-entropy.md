# 熵：不确定性的期望

## 1. 从一个场景开始

两个频道任你订阅：甲频道每小时播一次"一切正常"（概率 0.999），乙频道滚动播报地震、股市熔断、彗星回归（个个都是小概率）。哪条频道更有信息量？

直觉秒答乙。但工程需要数字：**平均每条消息带多少比特？** 把每个可能消息的自信息按出现概率加权平均——这个平均值就是**熵**（entropy）。它是信源不确定性的总账，也是压缩极限、密码强度、甚至大脑信号复杂度的统一标尺。

## 2. 直觉解释

熵回答一个问题：**这个信源平均而言有多意外？**

- 只会说"是"的传声筒（一个结果概率为 1）：零惊讶，熵为 0；
- 公平硬币：正反各半，每条消息恰好 1 比特，熵为 1；
- 偏斜硬币（90% 正面）：多数时候说废话，偶尔才惊人——平均下来约 0.469 比特，比公平硬币"无聊"；
- 十个面几乎等可能的骰子：猜谁都费劲，熵接近 $\log_2 10\approx 3.32$。

规律浮出水面：**概率越摊得平，熵越大；越一家独大，熵越小**。均匀分布是不确定性的天花板，确定性分布是地板。第 35 章纠错码课已经预告过这位主角，今天正式发毕业证。

## 3. 正式定义

离散随机变量 $X$ 取值 $x_1,\ldots,x_n$，概率 $p_1,\ldots,p_n$，则**香农熵**定义为自信息的期望：

$$H(X)=-\sum_{i=1}^{n} p_i \log_2 p_i$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p_i$ | 分布 | 各结果的先验概率，$\sum p_i=1$ |
| $-\log_2 p_i$ | 自信息 | 第 $i$ 个结果被证实时的惊讶度 |
| $H(X)$ | 熵 | 平均惊讶度，单位比特/符号 |

约定 $p_i=0$ 时该项记 0（不会发生的结果不贡献悬念）。二元特例（伯努利分布）值得单独背下来：

$$h(p)=-p\log_2 p-(1-p)\log_2(1-p)$$

它在 $p=0.5$ 处取最大值 1 比特，在 $p=0,1$ 处归零——一条漂亮的拱形曲线，下面实验里亲手画。

## 4. 分步例题

**例**：某信源发出五种符号，概率依次为 $\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \frac{1}{16}, \frac{1}{16}$。

1. 逐项算自信息：$1, 2, 3, 4, 4$ 比特；
2. 逐项乘概率：$0.5\times1+0.25\times2+0.125\times3+0.0625\times4+0.0625\times4$；
3. 求和：$0.5+0.5+0.375+0.25+0.25=1.875$ 比特/符号；
4. 对照天花板：五个符号若均匀分布，熵为 $\log_2 5\approx 2.32$——实际分布偏斜，所以低于天花板 ✓（任何分布的熵都不超过均匀值，这条性质叫最大熵原理）。

顺手观察第 2 步：概率是 2 的负幂时，每一项都干净利落。真实世界（比如英文字母频率）没有这么整齐，但算法一模一样。

横轴是"正面概率"，纵轴是每次抛掷的平均不确定性。两端触地（结局早已注定）、中央登顶（最悬念迭起）。密码学要求密钥位逼近 0.5 这一段；而信号分析里熵突然掉向两端，往往意味着系统出了"一言堂"式故障——同一根曲线，两种用途。

### 实验 2（python）：给四个信源建总账

```python title="四种分布的熵对照"
import math                     # log2 在这里

def entropy(probs):             # 自定义函数：输入概率列表，返回熵
    total = 0                   # 累加器清零
    for p in probs:
        if p > 0:               # 约定 p=0 的项跳过
            total = total - p * math.log2(p)
    return total

sources = [
    ([0.5, 0.5], "公平硬币"),
    ([0.9, 0.1], "偏斜硬币"),
    ([0.25, 0.25, 0.25, 0.25], "四面色子"),
    ([0.7, 0.15, 0.1, 0.05], "偏心四面骰"),
]

labels = []                     # 给柱形图准备标签与数值
values = []
for probs, name in sources:
    labels.append(name)
    values.append(entropy(probs))
    print(f"{name}: H = {round(values[-1], 3)} 比特")   # values[-1]：负下标 = 列表最后一个元素（首见写法）

import matplotlib.pyplot as plt
plt.bar(range(len(labels)), values)          # len(labels)：数一数有几个信源
plt.xticks(range(len(labels)), labels)       # xticks：把横轴刻度换成文字标签（首见）
```

输出验证了直觉排序：四面色子 2.0（顶格）> 偏心四面骰 ≈ 1.319（约为天花板的 66%）> 公平硬币 1.0（顶格）> 偏斜硬币 ≈ 0.469（约为天花板的 47%）。**比较熵要连同符号数上限一起看**：偏斜硬币离它的天花板（1 比特）很远，才是真正"无趣"的信源。

### 快问快答

```quiz
把硬币从 50 对 50 调成 51 对 49，熵怎么变？
- 几乎不变 [*]
- 掉到原来的一半
- 升高一点
? 熵在 p=0.5 附近是平顶：h(0.51) 约 0.9997，肉眼难辨。拱形曲线的顶点附近变化极缓——这也是为什么伪随机数要拼尽全力才能逼近真随机。
```

:::warning[常见误区]

**误区一**："你以为熵是系统的混乱程度所以等于'脏乱'。" 熵度量的是**分布的摊平程度**，与物理上的脏乱无关，更不是贬义。脑电信号熵高恰恰说明信息丰富、状态健康；某些病变反而表现为节律单一、熵降低。

**误区二**："你以为熵取决于观测到的样本。" 熵属于**分布**（理论对象），手头样本只能给出估计。抛 10 次硬币 7 正 3 反不代表熵是 0.881——那是一个样本的说法，不是硬币的户口。

**误区三**："你以为不同符号数的信源可以直接比熵大小。" 八面骰熵 3、硬币熵 1，不能得出"骰子更随机所以更好"。可比的是各自相对天花板的比值（效率）：硬币 1/1 = 100%，八面骰 3/3 = 100%，两者同样"满格"。

:::

```python
import math   # 数学函数库

def entropy(probs):
    total = 0
    for p in probs:
        if p > 0:
            total = total - p * math.log2(p)
    return total

print(round(entropy([0.5, 0.5]), 2))
print(round(entropy([0.9, 0.1]), 2))
```

累加器必须在循环里吃进每一项 `-p * math.log2(p)`。

**练习 2**：一个信源只有两种结果，熵却测得恰为 1 比特。两概率分别是多少？

<details>
<summary>点开查看逐步解答</summary>

$h(p)=1$ 当且仅当 $p=0.5$（拱形顶点唯一）。所以是公平的五五开。反过来说：测到一个二元信源的熵明显低于 1，就等于断定它有偏——熵是最灵敏的"公平性探测器"，下一章的交叉熵会把它变成损失函数。

</details>

**练习 3**：医生连续记录某病人的心率变异性，白天熵 3.2 比特、深度麻醉下熵 1.1 比特。用本课语言解释这个指标在监护仪上的用途。

<details>
<summary>点开查看逐步解答</summary>

心率序列的熵衡量心跳间隔分布的"意外程度"：清醒状态下自主神经让节律丰富多变，熵高；深度麻醉或某些病变使节律锁死成单一模式，熵骤降。监护仪跟踪这个数字，就是在实时监测生理系统的"信息健康度"——熵掉下去就报警。这是 EEG/心率熵分析的最简版本，现代研究里还会结合频段分解做更细的诊断。

</details>

## 7. 选读：熵为什么长成期望的样子

<details>
<summary>选读 · 从公理推公式</summary>

香农当年的推导是倒过来的：先列出"不确定性度量"该满足的公理——(1) 连续依赖于概率；(2) 均匀分布时随符号数增加而增加；(3) 可分解：先掷硬币再按结果分支，总不确定性等于两部分之和。可以证明（用第 8 章的归纳法技巧）同时满足三条的函数**唯一**，且必为 $-C\sum p_i\log p_i$ 的形状——对数不是选择而是必然，单位由常数 C 定夺。物理学家玻尔兹曼早在 1870 年代就在统计力学里写下同款公式（差一个常数因子），所以冯·诺依曼建议香农干脆也叫它熵，顺带堵住记者追问"到底什么是熵"的嘴——这段对话是否真发生过已不可考，但两个熵的深层联系是真的。

</details>
