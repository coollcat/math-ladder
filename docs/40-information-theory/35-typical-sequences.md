# 典型序列：熵的下界为何可达

## 1. 从一个场景开始

抛一枚偏心硬币 100 次，正面概率 0.8。全部可能结果有 $2^{100}$ 条序列——约 $1.3\times 10^{30}$ 条，比可观测宇宙的恒星还多。可你实际抽到的序列几乎总是同一个模样：正面 70 到 90 个。

把"几乎总是"算到底，会撞见一个惊人的集中：**概率质量的绝大部分，压在一小块地盘上，而这块地盘只占全部序列的几十亿分之一**。香农把这块地盘叫典型集合——熵之所以配当压缩的下界、信道的容量，承重墙就是它。

## 2. 直觉解释

大数定律先上：抛得越长，正面占比越赖在 0.8 附近不动。"正面恰好 50 个"的序列并非不存在，但概率小到抽一万辈子也碰不上。于是给长序列分籍贯：**正面占比贴近 p 的，叫典型序列**。

第二层直觉更妙：典型序列们彼此的概率几乎一样——长序列之间的"贫富差距"被抹平了。全正面那条序列确实比任何一条典型序列都更常见，可它孤零零只有 1 条；典型序列浩浩荡荡，总质量的大头永远在集体阵容手里。这个"长序列之间概率拉平"的现象有个正式名字：**渐近均分性质**（AEP）。

最后一步是本课的核心账本：总质量约等于 1，每条典型序列的"单价"是 $2^{-nH}$——那么典型集的条数自然是 $2^{nH}$ 条。全部序列有 $2^n$ 条，典型集只占 $2^{-n(1-H)}$——熵越低、序列越长，这块地盘塌得越狠。

## 3. 正式定义

长度 $n$ 的硬币序列，正面个数 $k$ 满足 $|k/n - p| \le \delta$ 的称为（$\delta$-）典型序列。**渐近均分性质（AEP）**：当 $n\to\infty$，(1) 序列落在典型集内的概率趋于 1；(2) 每条典型序列的概率趋于同一个值 $2^{-nH}$；(3) 典型集条数趋于 $2^{nH}$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p$ | 正面概率 | 信源的分布 |
| $H=h(p)$ | 熵 | 每符号平均惊讶度（熵课的主角） |
| $2^{-nH}$ | 典型序列单价 | 每条典型序列概率的量级 |
| $2^{nH}$ | 典型集条数 | 扛起全部概率质量的那一窝 |
| $2^{-n(1-H)}$ | 占地比 | 典型集占全部 $2^n$ 条序列的比例 |

$$\text{占地比} = \frac{2^{nH}}{2^n} = 2^{-n(1-H)}$$

注意分子分母用的是同一个 $n$：序列每加长一位，全空间翻一倍，典型集只翻 $2^H$ 倍——只要 $H<1$，差距就指数拉开，这就是"坍缩"二字的全部含义。

## 4. 分步例题

**例**：偏硬币 $p=0.8$，数一数典型集的家底。

1. 算熵：$H = 0.8\times 0.3219 + 0.2\times 2.3219 = 0.7219$ 比特（逐项就是自信息 $-\log_2 p$ 的加权平均）；
2. 单价：每条典型序列的概率 $\approx 2^{-0.7219n}$；
3. $n=10$：典型集约 $2^{7.22} \approx 149$ 条；全空间 $2^{10}=1024$ 条；占地约 14.5%；
4. $n=100$：典型集约 $2^{72.19} \approx 5.4\times 10^{21}$ 条——听着浩浩荡荡？全空间 $2^{100}\approx 1.3\times 10^{30}$，占地 $4.3\times 10^{-9}$，约两亿四千万分之一；
5. $n=1000$：占地 $2^{-278}\approx 2\times 10^{-84}$——差距随 $n$ 指数拉开，"坍缩"到此肉眼可见；
6. 对照公平硬币：$p=0.5$ 时 $H=1$，占地比恒为 100%——均匀世界没有坍缩，"偏"才是坍缩的来源。

### 实验 2（python）：坍缩表

```python title="从 n=10 到 n=1000：典型集地盘的指数坍塌"
import math   # 数学函数库（log2 在这里）

def h_binary(p):                    # 二元熵函数：正面概率 p 的平均惊讶度
    return -p * math.log2(p) - (1 - p) * math.log2(1 - p)

print("公平硬币 H =", round(h_binary(0.5), 4))   # 1.0
print("偏硬币   H =", round(h_binary(0.8), 4))   # 0.7219

h = h_binary(0.8)                   # 下面反复要用
for n in [10, 20, 50, 100, 1000]:   # 逐个序列长度算占地比
    ratio = 2 ** (n * (h - 1))      # 2 的 n(H-1) 次方：典型集条数除以全空间条数
    print(f"n={n}: 占地比 {ratio}")
```

占地比从 14.5%（$n=10$）跌到 2.1%（$n=20$）、0.0065%（$n=50$）、$4.3\times 10^{-9}$（$n=100$）、约 $2\times 10^{-84}$（$n=1000$）。把两处 0.8 都换成 0.5 再跑：每一行都变成 1.0——均匀世界无坍缩。

### 实验 3（python）：抽样验证质量集中

```python title="两万条长 50 的序列：九成五的概率质量住在哪儿"
import random   # 随机库：模拟抛硬币

p = 0.8          # 正面概率
n = 50           # 每条序列的长度
trials = 20000   # 抽多少条序列

typical = 0                       # 典型序列计数器
for t in range(trials):
    heads = 0
    for i in range(n):
        if random.random() < p:   # 掷出 [0,1) 均匀小数，小于 p 即算正面
            heads += 1
    frac = heads / n              # 这条序列的正面占比
    if p - 0.1 <= frac and frac <= p + 0.1:   # 占比落在 0.7 到 0.9 之间：典型
        typical += 1

print(f"{trials} 条抽样中典型序列占 {round(typical / trials, 3)}")
```

每次运行都贴着 0.95（二项分布精确值 0.9507）：九成五的抽样落进正面占比 0.7 到 0.9 的窄带。这条窄带在全部 $2^{50}$ 条序列里占地多少？数一数：约 $2^{41.8}$ 条，占地 0.33%。**九成五的质量、千分之三的地盘**——把窗口拧紧、同时把 $n$ 加大，条数就贴向 $2^{nH}\approx 7.4\times 10^{10}$（占地 0.0065%），质量依然趋近 1。两头同时成立，这正是 AEP 的内容。

::::warning[常见误区]

**误区一**："你以为概率最大的那条序列是主角。" 全正面（概率 $0.8^{100}\approx 2\times 10^{-10}$）确实比任何一条典型序列都常见，可它只有 1 条，总质量的大头永远不在它手里；典型大军有 $2^{72}$ 条。单条明星比拼不过集体阵容。

**误区二**："你以为典型序列每条概率严格相等。" 渐近均分的关键词是"渐近"：每条概率 $\approx 2^{-nH}$，$n$ 越长贴得越紧。短序列仍有贫富差距——抛 4 次时全正面（0.41）与三正一反（0.10）还差四倍；谈"彼此一样"要在长序列极限下才成立。

**误区三**："你以为 $2^{nH}$ 是精确条数。" 它是量级估算：正式的 AEP 给出的是上下界 $2^{n(H-\varepsilon)}$ 到 $2^{n(H+\varepsilon)}$。要紧的是指数尺度——它与 $2^n$ 的鸿沟随 $n$ 拉开——不是个位数字。

::::

## 6. 练习

**练习 1**：偏硬币 $p=0.9$、序列长 $n=100$：熵是多少？典型集条数约为 2 的几次幂？占地比的对数是多少？下面的代码能跑但把熵当成了概率——改到通过：

```exercise
# @title: 练习：偏硬币的典型集家底
# @check: 0.469
# @check: 46.9
# @check: -53.1
# @hint: 熵不是概率本身：H = -p*log2(p) - (1-p)*log2(1-p)。占地比取以 2 为底的对数正好是 n*(H-1)。
import math   # 数学函数库

p = 0.9          # 正面概率
n = 100          # 序列长度

h = p            # ← 问题在这：熵被写成了概率本身

size_exp = n * h           # 典型集条数约为 2 的几次幂
ratio_exp = n * (h - 1)    # 占地比 2^{nH}/2^n 取以 2 为底的对数

print(round(h, 3))
print(round(size_exp, 1))
print(round(ratio_exp, 1))
```

<details>
<summary>点开查看判题参考实现</summary>

```python
import math   # 数学函数库

p = 0.9          # 正面概率
n = 100          # 序列长度

h = -p * math.log2(p) - (1 - p) * math.log2(1 - p)   # 二元熵

size_exp = n * h
ratio_exp = n * (h - 1)

print(round(h, 3))
print(round(size_exp, 1))
print(round(ratio_exp, 1))
```

把 `h = p` 换成熵公式即可：H(0.9)=0.469 比特，典型集约 $2^{46.9}$ 条，占地比 $2^{-53.1}$——一亿亿分之一的地盘。

</details>

**练习 2**：$p=0.8$、$n=100$ 时，"全正面"那条序列的概率是多少？它算典型序列吗？

<details>
<summary>点开查看逐步解答</summary>

$0.8^{100}\approx 2.1\times 10^{-10} = 2^{-32.19}$。它的每符号惊讶度只有 0.3219 比特，离 $H=0.7219$ 差着 0.4 比特——是"极端不典型"的序列。它比典型序列单价 $2^{-72.19}$ 贵 $2^{40}$（约一万亿）倍，可孤家寡人一条，总质量 = 单价 × 条数，仍可忽略：集体赢过明星。

</details>

**练习 3**：为什么"只给典型序列编号"就能把每符号平均码长压到 $H$ 比特附近？非典型序列怎么办？

<details>
<summary>点开查看逐步解答</summary>

典型集有 $2^{nH}$ 条，给它们编号需要 $nH$ 比特——这正是第 30 课信源编码定理"平均码长贴着熵"的直觉版。非典型序列的总质量随 $n$ 趋于 0，按"意外"处理：多花些比特也不伤平均账。$p=0.8$ 时每符号省下 $1-H=0.278$ 比特，长序列累计起来就是可观的压缩。

</details>

## 7. 选读：两种"典型"是同一件事

<details>
<summary>选读 · 从"频率贴 p"到"每符号惊讶度贴 H"</summary>

$p=0.8$ 的硬币：一条含 $k$ 个正面的序列，每符号平均惊讶度 $s = -\frac{1}{n}\log_2\left(0.8^k \cdot 0.2^{n-k}\right) = 2.3219 - 2\,\frac{k}{n}$（系数恰好凑整，因为 $\log_2 4 = 2$）。可见 $s$ 与正面占比 $k/n$ 只差一次线性换算："频率贴 p"与"每符号惊讶度贴 $H=0.7219$"是同一句话的两种说法。正式的 AEP 用熵窗定义：$T_\varepsilon$ 为每符号惊讶度与 $H$ 相差不超过 $\varepsilon$ 的序列集合，可证 $\Pr(T_\varepsilon)\to 1$ 且 $2^{n(H-\varepsilon)} \le |T_\varepsilon| \le 2^{n(H+\varepsilon)}$。香农第二定理的证明就站在这块跳板上：信道输出的长序列也只会落进 $2^{nC}$ 个典型"组"，消息数不超过组数，就能一组一个专属码字，把错误率压到任意小。

</details>

## 8. 下一站

信源这头的账算清了：长序列几乎都挤在 $2^{nH}$ 条的典型集里，熵的下界因此可达。把同一盏探照灯转向信道的输出端，就是香农第二定理的入口——接收端的长序列也只会落进有限个典型"组"里，消息只要不超过组数，就能一一分辨。下一课走进有噪声的信道，把"容量 = 1 − h(e)"从公式变成工程预算。
