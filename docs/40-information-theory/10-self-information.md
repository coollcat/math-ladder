# 什么是信息：惊讶可以度量

## 1. 从一个场景开始

两条消息摆在一起："明天太阳从东边升起"和"明天彩票中了头奖"。第一条你连转发都懒得转，第二条会让你手抖。可它们都是一句话，凭什么信息量差这么远？

1948 年，香农（Claude Shannon）给出了惊世骇俗的回答：**信息量就是收到消息时的惊讶程度，而惊讶程度可以被精确测量**——用概率的对数。这一步把"消息值多少钱"变成了可以加减乘除的数，整个数字时代（压缩、纠错、加密、通信预算）都站在这个度量上。

## 2. 直觉解释

先做定性分析。一条消息的信息量应该满足什么？

- **越罕见越有料**。"太阳东升"几乎必然发生，说出来不消除任何悬念；概率越小的事件被证实，消除的悬念越多。
- **独立事件的惊喜应当相加**。"今晚下雨"和"明天下雨"（假设互不影响）各自的消息合在一起，惊讶程度应该是两者之和。

第二条要求很挑剔：什么运算能把"概率的变小"翻译成"数值的变大"，还让相乘的概率对应相加的数值？答案只有一个——**对数**：

> **自信息** $I(x) = \log_2 \dfrac{1}{p} = -\log_2 p$

概率减半，信息加 1 比特；概率变成四分之一，信息加 2 比特。单位叫**比特**（bit），从此有了体温计。

## 3. 正式定义

设随机事件 $x$ 发生的概率为 $p(x)$，则它的**自信息**定义为：

$$I(x) = \log_2 \frac{1}{p(x)} = -\log_2 p(x)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p(x)$ | 先验概率 | 见到消息前你认为它发生的把握 |
| $I(x)$ | 自信息 | 该事件被证实后消除的不确定性，单位比特 |
| $\log_2$ | 以 2 为底的对数 | 保证"概率减半、信息加一比特"的标尺 |
| $I=0$ | 无新意 | $p=1$ 的必然事件，说了等于没说 |

三条快速校验：(1) 必然事件 $p=1$，$I=\log_2 1=0$ ✓；(2) 公平硬币的正面 $p=0.5$，$I=\log_2 2=1$ 比特——"一个比特"这个词的户口就在这里；(3) 概率任意小，$I$ 可以任意大，但永远不会是负数——消息只会带来非负的意外。

## 4. 分步例题

**例 1**：掷骰子掷出 6 点（$p=1/6$）。

1. 写倒数：$\frac{1}{p}=6$；
2. 取以 2 为底的对数：$I=\log_2 6\approx 2.585$；
3. 解读：这条消息携带约 2.585 比特——介于"两个比特能区分四种情况"与"三个比特能区分八种情况"之间。

**例 2**：连续两次公平硬币都是正面（$p=1/2\times 1/2=1/4$）。

1. 概率相乘：$p=0.25$；
2. 自信息：$I=\log_2 4=2$ 比特；
3. 对照加法：每次正面各带 1 比特，$1+1=2$ ✓——独立性下信息恰好可加，对数标尺的自洽性当场验证。

### 实验 2（python）：给现实世界的消息称重

```python title="从日常小事到彩票头奖：各自几比特"
import math   # 对数与阶乘都在这个库里

cases = [(0.5, "公平硬币正面"), (1/6, "骰子掷出 6 点"), (1/1000, "千分之一的抽签大奖")]

for p, name in cases:
    info = -math.log2(p)          # 自信息公式直接照抄
    print(f"{name}: 约 {round(info, 2)} 比特")

# 双色球头奖：33 选 6 再乘 16 种蓝球
red_combos = math.factorial(33) // (math.factorial(6) * math.factorial(27))
total_combos = red_combos * 16
info_jackpot = math.log2(total_combos)
print(f"组合总数 {total_combos}")
print(f"中头奖消息的信息量约 {round(info_jackpot, 1)} 比特")
```

头奖消息约 24 比特——听起来不多？对比一下：一张 100 万像素的灰度照片约 800 万比特。**头奖消息的稀有不在绝对信息量，而在它把约 1772 万分之一的概率质量集中到了一个点上**；照片则把海量比特均匀铺在每个像素上。两种"多"不是一种多，这个伏笔下一课（熵）正式解开。

### 快问快答

```quiz
某事件发生的概率从 1/4 变成 1/8（更罕见了）。它的自信息如何变化？
- 加 1 比特 [*]
- 翻一倍
- 不变
? 概率减半，自信息恰好多 1 比特——这是 log2 标尺的定义性性质。翻倍的是「倒数」，而信息是对数刻度上的差值。
```

:::warning[常见误区]

**误区一**："你以为信息量取决于消息的字数。" 度量的是概率的消除，不是篇幅。"地震了"四个字可能价值 20 比特，整版报纸的例行公报接近 0 比特。香农信息论只关心意外程度，不关心语义深浅。

**误区二**："你以为 24 比特的中奖信息比 800 万比特的照片'少得多'所以不值钱。" 比特数衡量的是不确定性消除的规模；价值、重要性属于语义领域，香农刻意不管。信息论的"信息"没有褒贬，只有多少。

**误区三**："你以为概率为 0 的事件自信息无穷大所以很重要。" $-\log_2 0$ 在数学上发散，但概率 0 的事件根本不会发生、也就没有消息可传。信息论里约定 $0\cdot\log 0=0$，把它请出场外。

:::

## 6. 练习

**练习 1**：抽签抽中"千分之一大奖"（$p=1/1000$）的自信息是多少比特？下面的代码能跑但用错了标尺——改到通过：

```exercise
# @check: 9.97

import math   # 数学函数库

info = round(math.log(p), 2)   # ← 问题在这：这是自然对数，不是比特

```

<details>
<summary>点开查看判题参考实现</summary>

```python
import math   # 数学函数库

p = 1 / 1000            # 中奖概率
info = -math.log2(p)    # 以 2 为底的对数取负，单位是比特
print(round(info, 2))
```

关键只有一步：把自然对数换成 `math.log2`，再添上负号。

</details>

**练习 2**：连续三次公平硬币全是反面，这条消息共几比特？它与"第一次是反面"那条消息相差几比特？

<details>
<summary>点开查看逐步解答</summary>

$p=(1/2)^3=1/8$，$I=\log_2 8=3$ 比特。单次反面 1 比特，故相差 2 比特。也可以逐条累加验证：1+1+1=3 ✓。独立性让信息像砖块一样可垒加——这正是工程上能把长消息拆成一个个比特分别传输的理论根基。

</details>

**练习 3**：医生说"这项检查结果很正常"。从自信息角度解释为什么这句话几乎不给诊断提供新信息。

<details>
<summary>点开查看逐步解答</summary>

"正常"是大概率结局（多数检查指标落在参考范围内的先验很高，比如九成以上），$I=-\log_2(0.9)\approx 0.15$ 比特，接近于零。反之若结果异常（先验仅百分之几），自信息高达四五比特——异常值才是信息的富矿。体检报告的价值集中在少数"惊讶"上，这个直觉正是下一课熵概念的入口。

</details>

## 7. 选读：为什么偏偏选以 2 为底

<details>
<summary>选读 · 单位是约定，形状是定理</summary>

对数底数只改变刻度的单位：以 2 为底得到比特（bit），以自然常数 e 为底得到奈特（nat），以 10 为底得到哈特莱（hartley），换算只是乘固定系数（1 奈特 ≈ 1.443 比特）。香农选 2 有工程私心：开关电路只有两个状态，比特正好对应一个继电器的一开一关，信息量可以直接数硬件。数学定理（如下一课的信源编码定理）在任何底数下都成立，只是常数跟着换底。全书的 Python 代码统一用 `math.log2`，与比特口径一致。

</details>
