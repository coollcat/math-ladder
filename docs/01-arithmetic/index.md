## 章节大题：发糖机的数学体检

学完四则运算，来给一台"自动发糖机"做一次完整体检。下面的代码把**除法与余数、负数与减法、运算优先级、判等验证**一次全用上——它能跑，但体检报告有三处不对。把它修到三行检查全部通过：

```exercise
# @title: 章节大题：发糖机体检报告
# @check: 分糖: 每人 5 颗, 还剩 3 颗
# @check: 验算: True
# @check: 对比: 10 和 16
# @hint: 三处暗坑：整除用 //（/ 会切出小数）；余数用 %；最后一组里 a 的那对括号必须摘掉——先乘除后加减会让两个式子分道扬镳。
candies = 23
people = 4

each = candies / people        # ← 糖果不能切开卖：这里该用整除
left = candies % people        # % 是"除完剩下的零头"
print(f"分糖: 每人 {each} 颗, 还剩 {left} 颗")

check = candies == people * each + left   # == 判等：两边相等时给出 True
print(f"验算: {check}")

a = (2 + 3) * 4 - 8 // 2       # ← 两行长得一模一样？其中一行不该有括号
b = (2 + 3) * 4 - 8 // 2
print(f"对比: {a} 和 {b}")
```

<details>
<summary>点开查看逐步解答</summary>

三处暗坑对应的正是本章三课：

1. **整除**（40 课）：`candies / people` 得 $5.75$，糖果要整颗分——改成 `candies // people` 得 $5$，`%` 给出余数 $3$；
2. **带余验证**：$23 = 4 \times 5 + 3$，这正是"商 × 除数 + 余数 = 被除数"，所以 `check` 为 `True`；
3. **优先级**（50 课）：`b` 保持括号得 $(2+3)\times4-8\,//\,2 = 20-4 = 16$；`a` 摘掉括号后按"先乘除后加减"：$2 + 3\times4 - 8\,//\,2 = 2 + 12 - 4 = 10$。

修好后的关键行：

```python
each = candies // people
a = 2 + 3 * 4 - 8 // 2
```

一个括号的位置就能让同一个式子差出 6——这就是"运算优先级不是装饰"的体检结论。
</details>

## 实战挑战 · 先乘除后加减的体检

同一串数字，运算顺序不同，结果天差地别。Python 严格遵守"括号 → 乘除 → 加减"的优先级。下面这个式子的结果算错了，修到输出 `11.0`：

```exercise
# @title: 实战挑战：先乘除后加减
# @check: 11.0
# @hint: 乘除优先于加减——3 * 4 和 6 / 2 要先算，再从左到右做加减。
result = (2 + 3) * 4 - 6 / 2    # ← 问题在这：括号改变了优先级
print(result)
```

<details>
<summary>点开查看逐步解答</summary>

没有括号时，乘除先于加减：

```python
result = 2 + 3 * 4 - 6 / 2    # 先算 3*4=12 和 6/2=3，再算 2+12-3
print(result)                  # 11.0
```

初始代码用括号把 `(2 + 3)` 提前了，结果变成 $5\times4-3=17$。去掉括号后：$2 + 12 - 3 = 11.0$。这是本章"运算优先级"最直白的现场版。

</details>
