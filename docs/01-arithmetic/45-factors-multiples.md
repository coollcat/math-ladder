# 因数与倍数：整除的语法

## 1. 从一个场景开始

15 颗糖要摆成**整齐的矩形**，每行必须一样多。试一试：摆 1 行 15 颗，行；摆 3 行每行 5 颗，也行；摆 2 行呢？每行 7 颗半——糖不能切，阵型当场崩了。

同样是 15 颗糖，有的行数陪它拼得出矩形，有的陪不出。能拼出的那几个数（1、3、5、15）是这个数的**乘法搭档**——数学给它们起了正式的名字：**因数**。这一课把乘法世界的这份"搭档名册"立起来，它是整除世界的语法书。

## 2. 直觉解释

上一课说除法是乘法的反问句。现在把反问推到底：

- 乘法问：$3 \times 5 = ?$（答案：15）
- **因数问**：$? \times ? = 15$——哪些数对能拼出它？（$1\times15$、$3\times5$）
- **倍数问**：$3 \times ? = ?$——3 能拼出哪些数？（3、6、9、12、15、…）

换个画面：因数是**拼图块**，倍数是**成品**：

$$15 = 3 \times 5$$

这一行式子同时说了两件事：3 和 5 是 15 的因数（能拼出它），15 是 3 的倍数（也是 5 的倍数）。当因数还是当倍数，取决于你站在乘号的哪一边。

再和上一课握个手：$15 \div 3 = 5$ 余 **0**——余数为零，拼图严丝合缝。这就是**整除**：不仅除得动，还分毫不剩。

## 3. 正式定义

对正整数 $a$ 和 $b$，若存在整数 $q$ 使

$$a = b \times q$$

就说 **b 整除 a**；此时 $b$ 和 $q$ 都是 $a$ 的**因数**，$a$ 是 $b$ 的**倍数**。

| 名字 | 角色 | 例（15 = 3×5） |
| --- | --- | --- |
| 因数 | 拼图块：参与相乘的数 | 3、5（1 和 15 也是） |
| 倍数 | 成品：相乘的结果 | 15 是 3 的倍数，也是 5 的倍数 |
| 整除 | 拼图无缝的资格证 | 3 整除 15（余数为 0） |

三条立刻能用的性质：

1. **因数成对**：$15 = 1\times15 = 3\times5$——找到一个因数，就免费得到它的搭档（搭档就是商）；
2. **因数有限，倍数无穷**：因数最大到 $a$ 自己，数得完；倍数一路往上没有尽头；
3. **1 和 a 都在名册上**：任何数都能被 1 和它自己整除——这对因数最不起眼，也最容易被漏掉。

## 4. 分步例题

**例 1**：找 36 的全部因数。

用**配对扫描法**：从 1 开始试乘，每命中一对就记下来，两头往中间会合。

1. $36 = 1 \times 36$ → 记下 1 和 36；
2. $36 = 2 \times 18$ → 记下 2 和 18；
3. $36 = 3 \times 12$ → 记下 3 和 12；
4. $36 = 4 \times 9$ → 记下 4 和 9；
5. $6 \times 6 = 36$ → 6 和自己配对，**相遇了**：再往后试 7、8…，搭档只会是已经记过的老面孔，不必再试；
6. 因数名册：1, 2, 3, 4, 6, 9, 12, 18, 36，共 **9 个**。

**例 2**：12 和 18 的"共同语言"。

12 的因数：1, 2, 3, 4, 6, 12；18 的因数：1, 2, 3, 6, 9, 18。两边都有的：1, 2, 3, 6——**公因数**；其中最大的 6，叫**最大公因数**。

倍数这边：12, 24, 36, 48, … 与 18, 36, 54, … 两边第一个共同出现的是 **36**——**最小公倍数**。

这对概念马上会在第 2 章开工：约分要约掉最大公因数，通分要找最小公倍数当公分母——今天先把名册立好，到时直接点名。

## 5. 动手实验

### 实验 1（viz）：整除探测器

拖动发糖机的滑块：当人数是糖果总数的**因数**时，余数一格归零、糖分得干干净净；人数不是因数时，余数立刻现形。余数就是"整除"的裁判。

```viz
{
  "type": "divisionshare",
  "title": "整除探测器：人数是因数时余数归零",
  "total": 24,
  "people": 8
}
```

把人数依次试 3、5、7、8：3 和 8 余数归零（是 24 的因数），5 和 7 有余数（不是）。滑杆能试到的是 2 到 8，其中归零的是 2、3、4、6、8——把滑杆够不着的 1、12、24 也数进来，归零的次数正好是 8——24 的因数个数（下一实验的收集器负责数全）。

### 实验 2（viz）：倍数尺

等差数列从 a1 出发每步加 d——把 a1 和 d 拧成同一个数，柱子就是它的**倍数表**：

```viz
{
  "type": "seq",
  "kind": "arith",
  "a1": 3,
  "d": 3,
  "n": 10
}
```

3, 6, 9, 12, …——3 的倍数台阶。把 d 拧到 4 就是 4 的倍数；想找 3 和 4 共同的倍数？数一数两边都出现的值：12, 24, …——最小公倍数 12 就在柱子间现形。

### 实验 3：因数收集器

```python title="把 36 的因数一网打尽"
n = 36
divisors = []                  # 空列表：备好一个空桶，准备装因数
count = 0                      # 计数器：顺便数一共几个

for d in range(1, n + 1):      # 候选搭档从 1 试到 n 自己（range 含头不含尾，所以 +1）
    if n % d == 0:             # 余数为 0：d 整除 n，d 是因数
        divisors.append(d)     # append：把 d 追加到列表末尾（matplotlib 课教过）
        count = count + 1      # 收一个、数一个

print(divisors)
print(count)
print(sum(divisors))           # sum：把因数全家加起来
```

因数全家和是 91。把 n 换成 7 再跑：名册只剩 1 和 7，孤零零一对。这种"因数少得可怜"的数，第 10 章会给它起一个响亮的名字——这里先混个眼熟。

### 实验 4：公因数收集器

```python title="两关连过：12 和 18 的公因数"
a = 12
b = 18
common = []                    # 公因数收集桶

for d in range(1, a + 1):      # 公因数不会超过较小的 a
    if a % d == 0:             # 第一关：d 要整除 a
        if b % d == 0:         # 第二关（if 里再套 if）：d 还要整除 b
            common.append(d)   # 两关都过，收进桶里

print(common)
```

输出 `[1, 2, 3, 6]`，与例 2 手算一致。把 b 换成 17 再跑：桶里只剩 1——连一个公共搭档都没有的两个数，第 10 章叫它们"互质"。

### 快问快答

```quiz
36 的因数一共有多少个？
- 无穷多个
- 9 个 [*]
- 18 个
? 配对扫描：1×36、2×18、3×12、4×9、6×6，相遇即收工，共 9 个。倍数才无穷无尽，因数最大到 36 自己，一定数得完。
```

::::warning[常见误区]

**误区一**："一个数的因数也有无穷多个。"
反了：无穷的是倍数。因数最大就是它自己，个数永远有限——36 的因数 9 个，数完收工。

**误区二**："15 的因数就是 3 和 5。"
漏了最不起眼的一对：1 和 15 自己。任何数至少有两个因数——1 和它本身。因数总是成队出现，配对扫描就是提醒你这一点。

**误区三**："15 ÷ 2 = 7.5，除动了，所以 2 是 15 的因数。"
因数的资格证是**余数为 0**。除得动但除不尽，只是打过照面，不算搭档。上一课的余数裁判在这里说了算。

::::

## 6. 练习

**练习 1（判题）**：24 的因数有几个？其中最大的是几？下面的代码能跑，但两行答案都不对，改到通过：

```exercise
# @title: 练习：24 的因数名册
# @check: 8
# @check: 24
# @hint: range 含头不含尾——24 自己也是 24 的因数，扫描的上界得写到哪？
n = 24
count = 0
biggest = 0
for d in range(1, n):
    if n % d == 0:
        count = count + 1
        biggest = d
print(count)
print(biggest)
```

初始代码只扫到 23，把 24 自己挡在门外——数出 7 个、最大 12。把上界补到 n + 1，名册才完整：8 个因数，最大的正是 24 自己。

<details>
<summary>点开查看逐步解答</summary>

```python
n = 24
count = 0
biggest = 0
for d in range(1, n + 1):      # 上界 +1：把 24 自己也算进候选
    if n % d == 0:
        count = count + 1
        biggest = d

print(count)    # 8：1, 2, 3, 4, 6, 8, 12, 24
print(biggest)  # 24
```

$24 = 1\times24 = 2\times12 = 3\times8 = 4\times6$，四对搭档共 8 个因数 ✓。
</details>

**练习 2**：口算 30 和 45 的公因数与最大公因数，再用实验 4 的收集器验证。

<details>
<summary>点开查看逐步解答</summary>

30 的因数：1, 2, 3, 5, 6, 10, 15, 30；45 的因数：1, 3, 5, 9, 15, 45。两边都有的：1, 3, 5, 15——最大公因数 **15**。

```python
a = 30
b = 45
common = []
for d in range(1, a + 1):
    if a % d == 0:
        if b % d == 0:
            common.append(d)
print(common)    # [1, 3, 5, 15]
```

第 2 章约分 $\frac{30}{45}$ 时，分子分母同除以 15 一步到位——最大公因数就是约分的"一步到位按钮"。
</details>

**练习 3**：100 以内，哪些数既是 4 的倍数又是 6 的倍数？说说它们的规律。

<details>
<summary>点开查看逐步解答</summary>

4 的倍数：4, 8, 12, 16, 20, 24, …；6 的倍数：6, 12, 18, 24, 30, …。两边都出现的：12, 24, 36, 48, 60, 72, 84, 96——恰好是**最小公倍数 12 的倍数**。

这不是巧合：一个公倍数想同时装下 4 和 6，它至少得是 12，往后每加一份还是 12 的倍数。"公倍数 = 最小公倍数的倍数"这条规律，第 2 章通分找公分母时全靠它。
</details>

## 7. 选读：配对扫描为什么数到 6×6 就能收工？

<details>
<summary>选读 · 相遇即停的原理</summary>

例 1 找 36 的因数，试到 $6\times6$ 就停了，理由是"再往后搭档都是熟面孔"。把这句话说严谨：

假设 $d > 6$ 还有一次命中，即 $36 = d \times q$。那么搭档 $q = 36 \div d < 6$——而 $q$ 在扫描前半程早已作为因数登场过，它的搭档正是 $d$。所以 $d > 6$ 的每次"新发现"，都只是把已记录的配对从另一头再念一遍。

这就是配对扫描的收工法则：**因数总是成对出现（d, a÷d），两把尺子从两头往中间量，相遇即停**。对 36 来说相遇点是 6——顺带一提，"自乘恰好得到 36 的那个数"正是后面要学的平方根概念的一个预告。第 10 章判断质数时，这套"只查到相遇点"的手法能把工作量砍掉一大半。

</details>
