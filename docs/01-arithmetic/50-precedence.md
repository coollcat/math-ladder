# 运算优先级与括号

## 1. 从一个场景开始

小明在便利店买了 **2 瓶水**和**1 包薯片**。水每瓶 3 元，薯片 8 元。他掏出手机列式：`2×3 + 1×8`。

如果他按**从左到右**直接算：$2\times3=6$，然后 $6+1=7$，然后 $7\times8=56$ 元——账目一下子多出了 42 元。

为什么大家习惯约定"先乘除、后加减"？这条规则不是随手排出来的，背后有一个很稳的理由。

## 2. 直觉解释

回到乘法的出身：**乘法是压缩的加法**。

$$3 + 4 \times 2 \quad\text{真正的意思是}\quad 3 + (4+4)$$

$4\times2$ 这一块本来就是"$4+4$"的缩写——它天生是一个**整体**，先把它还原成加法之前，式子根本没展开完。

所以"先乘除后加减"不是特权排序，而是**缩写要先拆包**：

- 没拆包（乘除）的部分先处理；
- 拆完之后大家都是加减，才轮到从左到右；
- 想让低级运算先走？用**括号**把它整个圈起来当一件东西。

## 3. 正式定义

运算优先级从高到低：

| 级别 | 运算 | 例 |
| --- | --- | --- |
| 1 | 括号 `( )` | `(2+3)*4` 里先算 `2+3` |
| 2 | 乘除 `* / // %` | 从左到右依次 |
| 3 | 加减 `+ -` | 从左到右依次 |

两条补充规则：

- **同级从左到右**：$12 \div 3 \times 2 = (12\div3)\times2 = 8$，不是 $12\div6=2$；
- **括号可以嵌套**：先算最内层，一层层向外剥。

## 4. 分步例题

**例 1**：计算 $2 + 3 \times 4 - 8 \div 2$。

1. 先乘除（从左到右）：$3\times4=12$；$8\div2=4$
2. 式子变为 $2 + 12 - 4$
3. 从左到右加减：$14-4=\boxed{10}$

**例 2**：计算 $(2 + 3 \times 4 - 8) \div 2$。

1. 最内层括号里仍是混合运算：先 $3\times4=12$
2. 括号内变 $2+12-8=6$
3. 最后除以 2：$\boxed{3}$

同一个数字串，只挪了一对括号的位置，答案从 10 变成 3。

## 5. 动手实验

### 实验：两种算法，一张图分胜负

账目多出 42 元，是因为他把 `a + b*x` 按**从左到右**读成了 `(a + b)*x`。把两种读法画进同一张图——蓝实线是通常采用的算法，橙色虚线是从左到右的直接算法，拖动滑块看它们怎样慢慢分开：

```viz

  "type": "plot",
  "title": "y = a + b*x 的两种读法",
  "expr": "a + b*x",
  "label": "先乘除后加减",
  "expr2": "(a + b) * x",
  "label2": "从左到右直接算",
  "xmin": 0,
  "xmax": 6,
  "sliders": [
    { "name": "a", "min": 0, "max": 9, "step": 1, "value": 2 },
    { "name": "b", "min": 1, "max": 9, "step": 1, "value": 3 }
  ]
}
```

同一串数字，两条命运，盯住三个细节：

1. **蓝线从 $a$ 出发，橙线从 0 出发且更陡**——括号（或它的缺席）决定了"谁先谁后"，也就决定了整条曲线；
2. **两线恰好在 $x=1$ 处交叉**：那一点两种算法都得 $a+b$，越远离它账错得越离谱；
3. **把 $a$ 拖到 0**：两条线重合——式子里没有加法项时，先算谁都无所谓。

所以"先乘除后加减"不是审美偏好，它是"乘法是压缩的加法、缩写要先拆包"的必然结果。

### Python 实验：让机器替你仲裁

```python title="同一串数字，三种读法"
a = 2 + 3 * 4          # 先乘后加
b = (2 + 3) * 4        # 括号强制先加
c = 2 + (3 * 4)        # 括号只是把默认顺序写明白
print(a)
print(b)
print(c == a)          # c 和 a 相等吗？
```

第三行输出 `True` 说明：**显式括号如果与默认优先级一致，不改变结果**——它是写给读代码的人看的说明书。

### 快问快答

```quiz
12 ÷ 3 × 2 的正确结果是多少？
- 2（先把 3×2 算出来）
- 8（从左到右：12÷3=4，再 ×2）[*]
- 18
? 乘除同级，同级按从左到右。"先乘除"指的是相对加减的级别，不是乘法比除法优先。
```

:::warning[常见误区]

**误区一**："先乘除后加减 = 先算所有乘法，再算所有除法。"
乘与除是同一级别！正确做法是从左到右扫过去，遇到乘或除就顺手算掉。

**误区二**："减号后面的乘法要连带符号一起先算。"
$10 - 2\times3$ 中先算的是 $+6$ 这块整体，减号等着：$10-6=4$。别把 $-$ 抢先作用到 $2$ 上。

**误区三**：负数参与时不带括号。
$10 \div -2$ 这种写法容易误读，写成 $10 \div (-2)$ 才清晰——括号是为读者服务的。

:::

## 6. 练习

**练习 1（判题）**：计算 $2 + 3 \times 4 - 8 \div 2$ 并打印：

```exercise
# @title: 练习：四则混战
# @check: 10
# @hint: 先把 × 和 ÷ 都处理掉，再从左到右加减
print((2 + 3 * 4 - 8) // 2)
```

初始代码给整个式子套了括号还强行整除——答案变成了 3。去掉错误括号、理顺顺序，改出 10。

<details>
<summary>点开查看逐步解答</summary>

```python
print(2 + 3 * 4 - 8 // 2)
```

过程：$3\times4=12$，$8\div2=4$，然后 $2+12-4=10$。
</details>

**练习 2**：只添加一对括号，使 $6 + 12 \div 3 \times 2$ 的值从 14 变成 12。

<details>
<summary>点开查看逐步解答</summary>

原式：$6 + ((12\div3)\times2) = 6+8=14$。
加成 $(6 + 12) \div 3 \times 2 = 18\div3\times2 = 12$ ✓。

一对括号挪动"先算谁"，答案立刻不同——这正是第 4 章《代数》里配方的雏形。
</details>

## 7. 选读：优先级是数学的"语法"

<details>
<summary>选读 · 如果没有约定会怎样？</summary>

没有统一优先级的数学世界，每个式子都要靠括号标明全部结构：$(2+(3\times4))-(8\div2)$。能写，但可读性崩溃。

约定优先级相当于自然语言里"形容词放在名词前"这类语法——**省略的信息由公共约定补齐**。不同语言约定不同（某些老计算器严格从左到右），所以跨工具核对公式时永远记得确认它的优先级表。Python 与数学课本的约定一致：幂 > 乘除 > 加减，同级从左到右（幂除外：它在 Python 中从右往左结合，到第 3 章讲幂时会专门提醒）。

</details>
