# 乘法与分配律

## 1. 从一个场景开始

食堂阿姨给你打了 **4 个盘子**，每个盘子里 **6 个包子**。包子总数是多少？

这个答案也许来得很快。我们可以放慢一点看看：问题里并没有出现"+"号，总数是怎么被算出来的？其实这里藏着一个很自然的压缩记号——先把同数的连加写短一点，它就是**乘法**。

## 2. 直觉解释

$6+6+6+6$ 写起来太长了。数学家发明了缩写：

$$6 \times 4 = 24$$

意思是"4 个 6 相加"。**乘法是同数连加的压缩记号**——它不是新运算，只是加法的快捷方式。

画成图形更清楚：把包子摆成 **4 行 6 列的点阵**，总数就是行数×列数。

## 3. 正式定义

**记号**：$a \times b$（也写作 $a\cdot b$ 或代码里的 `a * b`）表示 $b$ 个 $a$ 相加。相乘的两者叫**因数**，结果叫**积**。

由加法的性质可以推出乘法自己的三条性质：

| 性质 | 内容 | 一句话 |
| --- | --- | --- |
| 交换律 | $a\times b=b\times a$ | 点阵横着数竖着数都一样 |
| 结合律 | $(a\times b)\times c=a\times(b\times c)$ | 堆箱子的顺序不影响总箱数 |
| **分配律** | $a\times(b+c)=a\times b+a\times c$ | 大矩形可以切成两个小矩形 |

分配律是三者中最重要的——它是后面所有代数运算的引擎。

## 4. 分步例题

**例**：用分配律心算 $7 \times 13$。

1. 把 13 拆开：$13 = 10 + 3$
2. 代入分配律：$7\times13 = 7\times(10+3) = 7\times10 + 7\times3$
3. 分别计算：$70 + 21$
4. 合并：$91$

拆开好算的数再相乘——这就是分配律的日常用法。

## 5. 动手实验

### 实验：切矩形，亲手试分配律

上一节我们用分配律心算了 $7\times13$——现在亲手试一次。可以直接在矩形里拖动：横向移动会调整切点 $b$，纵向移动会调整高度 $a$；也可以拖动**紫色圆点**精确切分，或拖动**橙色圆点**改变高度。左块面积是 $a\times b$，右块面积是 $a\times c$。按钮能继续微调这两个量；「旋转竖向」则保持同一个点阵不变、只换一个观察方向，两个拖拽方向也随之互换：这时公式变成 $(b+c)\times a=b\times a+c\times a$。

```viz
{
  "type": "distributive",
  "a": 7,
  "b": 10,
  "c": 3
}
```

不管切点在哪里、高度是多少，也不管从横向还是纵向去数，$a\times b+a\times c=a\times(b+c)$ 都成立——分配律就是"面积的拼接不重不漏"，代数证明见第 7 节选读。你还可以顺手验证交换律：保持高度为 7 时，默认矩形是 7 行、每行 13 个；把同一个点阵旋转九十度，也可看作 13 行、每行 7 个——两种数法的面积都是 91。

### 实验：每张乘法表都是一条直线

拖动滑块换一张"乘法表"，看直线如何变陡：

```viz

  "expr": "a*x",

```

直线越陡，说明"每增加 1，跳得越多"。滑杆放宽到 0～12 之后还有两处好戏：把 `a` 拖到 **0**，直线趴平——"每步跳 0 个"的乘法表就是 $6\times0=0$（误区一的图像版）；再从 1 拖到 12，看直线家族的扇面怎么越张越开。这条规律在第 6 章《一次函数》会正式登场。

### Python 深入版：把多张乘法表画在同一张图上

```python title="九九乘法表的直线家族"
import matplotlib.pyplot as plt

for a in range(1, 10):        # a 取 1 到 9，共 9 张乘法表
    xs = list(range(0, 10))   # 横轴：0 到 9
    ys = []
    for x in xs:              # 纵轴：算出每个 x 的 a*x
        ys.append(a * x)
    plt.plot(xs, ys, label=f"{a}x")  # label 给这条线起名

plt.legend()                  # 显示左上角的线名对照表
plt.grid(True)
```

九条直线像扇子一样展开——斜率（陡峭程度）就是表里的那个 $a$。

:::warning[常见误区]

**误区一**："乘法一定比加法快出更大的数。"
$6\times1=6$ 和 $6+0=6$ 一样大；$6\times0=0$ 甚至比加 0 还"亏"。乘以 1 不变、乘以 0 归零，这两个特例要单独记住。

**误区二**：分配律写成 $a\times(b+c)=a\times b+c$。
切矩形时两块都要乘：右边是 $a\times c$，不是光秃秃的 $c$。

**误区三**：结合律和分配律混用。
结合律只连着**同一个运算**（全是乘）；分配律是**乘法和加法之间**的桥梁。

:::

## 6. 练习

**练习 1（判题）**：用分配律计算 $7 \times 13$ 并打印：

```exercise
# @title: 练习：切两块算 7 × 13
# @check: 91
# @hint: 把 13 拆成 10 和 3：先分别算 7*10 与 7*3，再把两块面积加起来。
print(7 * 10)
```

能跑但只算了左块，答案是 70——想想右边宽 3 的那一小块去哪了，改到通过为止。

<details>
<summary>点开查看逐步解答</summary>

$$7 \times 13 = 7 \times (10 + 3) = 7 \times 10 + 7 \times 3 = 70 + 21 = 91$$

代码可以写成 `print(7 * 10 + 7 * 3)`，也可以直接写 `print(7 * 13)`；前者正好对应“左块面积 + 右块面积”的矩形模型。
</details>

**练习 2**：用分配律心算 $6 \times 15$，再用 Python 验证。

<details>
<summary>点开查看逐步解答</summary>

$6\times15 = 6\times(10+5) = 60+30 = 90$。

验证：`print(6 * 15)` 输出 90。
</details>

## 7. 选读：分配律的"出生证明"

<details>
<summary>选读 · 为什么 a×(b+c)=ab+ac 对所有数成立</summary>

画一个高为 $a$、宽为 $b+c$ 的矩形。它由两块拼成：宽 $b$ 的块（面积 $a b$）与宽 $c$ 的块（面积 $a c$）。整体面积既等于 $a\times(b+c)$，又等于两块之和 $ab+ac$——同一块地的两种数法，所以相等。

这个论证对任意正整数都有效（把点阵摆出来即可），配合负数后的符号法则依然成立。分配律因此不是巧合，而是"面积的拼接不重不漏"这一事实的代数化身。

</details>
