# 除法与余数

## 1. 从一个场景开始

23 颗糖果要**平均分给 4 个人**，怎么分？

每人先拿 5 颗，发出去 20 颗——手里还剩 3 颗，不够再每人一颗了。这剩下的 3，数学里给它起了正式的名字：**余数**。除法的故事分两半：分掉的部分，和分不掉的部分。

## 2. 直觉解释

除法是乘法的反问句：

- 乘法问：$4 \times 5 = ?$
- 除法问：$? \times 4 = 23$——但这次没有整数答案！

整数世界里我们退而求其次，回答两个问题：

1. **最多能整分到多少**？（商）
2. **还剩多少**？（余数）

$$23 = 4 \times 5 + 3$$

除法有两种生活版本，本质相同：

- **平分**：23 颗糖分给 4 人 → 每人 5 颗；
- **分组**：23 人每 4 人一组 → 能分 5 组。

两种问法，同一个算式 $23 \div 4$。

## 3. 正式定义

对整数 $a$ 和正整数 $b$，存在**唯一**的商 $q$ 和余数 $r$，满足：

$$a = b \times q + r, \qquad 0 \le r < b$$

- $q$ 叫**商**（能整分到的最大份数）；
- $r$ 叫**余数**（分不掉的部分），必须比除数小——否则还能再多分一轮。

Python 为这两个数各配了一个运算符：

| 运算符 | 名字 | 例 | 含义 |
| --- | --- | --- | --- |
| `//` | 整除取商 | `23 // 4` → `5` | 只留"分掉的轮次" |
| `%` | 取余数 | `23 % 4` → `3` | 只留"剩下的尾巴" |

**注意 `//` 是两个斜杠**：单个 `/` 在 Python 里是另一种精确除法（会得到小数），那是第 2 章《分数与小数》的主角。本章只用整数世界。

## 4. 分步例题

**例 1**：$38 \div 6$ 的商与余数。

1. 背口诀找最接近的：$6 \times 6 = 36$，而 $6\times7=42$ 超了
2. 商取 $6$
3. 余数 $= 38 - 36 = 2$
4. 验收：$38 = 6\times6+2$ ✓，且 $2<6$ ✓

**例 2**：$24 \div 4$。

$4\times6=24$ 恰好整除，余数为 $0$。"没有剩余"就是余数等于零。

## 5. 动手实验

### 实验：先玩发糖机

```viz
{
  "type": "divisionshare",
  "title": "发糖机：糖果总数 ÷ 人数",
  "total": 23,
  "people": 4
}
```

拖动滑块改变糖果数与人数，盯住结论行里"商"与"余数"的实时变化——**余数永远小于人数**。

### Python 实验：模拟分糖的全过程

```python title="轮流发糖：看 % 的循环节奏"
# sliders: sweets=23 [1:60:1]
hands = [0, 0, 0, 0]        # 四个人的手里都是 0 颗

for sweet in range(sweets): # 逐颗发糖；sweets 由滑块注入，拖到几就发几颗
    hand = sweet % 4        # 第几号手？余数循环出现：0,1,2,3,0,1,...
    hands[hand] = hands[hand] + 1   # 对应的人多拿一颗

print(f"{sweets} 颗糖四人分别拿到: {hands}")
print(f"验证总数: {sum(hands)}")
```

余数 `% 4` 的结果按 `0,1,2,3,0,1,2,3…` 循环。拖动滑块换个糖果总数再跑：无论发多少颗，四个人手里的糖**最多只差 1 颗**——多的那几颗正是余数。这个循环节奏是"轮流、报数"类问题的通用钥匙，第 10 章《模运算》会把它玩出花来。

### 快问快答

```quiz
在 a = b*q + r 中，r 必须满足什么？
- r 可以是任何整数
- 0 ≤ r < b [*]
- r 必须等于 b
? 若 r ≥ b 就说明还能再分一轮，商 q 就该加一——所以余数必须小于除数。
```

:::warning[常见误区]

**误区一**："余数可以比除数大。"
余 5 个、每组 4 个？那还能再来一组！合法的余数范围是 $0 \le r < b$。

**误区二**：把 `//` 当成普通除法。
`7 // 2` 得 `3` 不是 `3.5`——它只保留整数商，尾巴交给 `%`。

**误区三**："除不尽就没办法算了。"
恰恰相反：商和余数**合在一起**才是完整答案，两者缺一不可。

:::


初始代码用了单斜杠，输出的是 9.4 这种小数——改成整除与取余的组合，让两行输出分别是商和余数。

<details>
<summary>点开查看逐步解答</summary>

```python
print(47 // 5)   # 商：5×9=45 不超
print(47 % 5)    # 余数：47-45=2
```

验收：$47 = 5\times9+2$，且 $2<5$ ✓。
</details>

**练习 2**：星期三是这个月的 10 号，那么这个月 31 号是星期几？（用余数思考）

<details>
<summary>点开查看逐步解答</summary>

从周三起算，天数差 $= 31 - 10 = 21$ 天。
$21 \% 7 = 0$ ——整周循环后落回原点，31 号也是星期三。
</details>

## 7. 选读：为什么商和余数是唯一的？

<details>
<summary>选读 · 唯一性论证</summary>

假设存在两组答案：$a=b\,q_1+r_1=b\,q_2+r_2$（都满足 $0\le r_i<b$）。两式相减得

$$b(q_1-q_2)=r_2-r_1$$

左边是 $b$ 的倍数，所以右边也必须是 $b$ 的倍数；但右边夹在 $(-b,\,b)$ 开区间内，其中唯一的 $b$ 的倍数只有 $0$。于是 $r_1=r_2$，进而 $q_1=q_2$。

"商与余数唯一"这条性质叫**带余除法**，它是第 10 章整除理论、辗转相除法乃至 RSA 加密的起点。

</details>
