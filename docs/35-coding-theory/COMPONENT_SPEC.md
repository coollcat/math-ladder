# 第 35 章 · 未来可视化组件规格

本文是生产规格，不是读者侧正式课。以下组件均未实现；正式课当前只使用既有 viz 与浮窗 Python。实现顺序建议：`noisy-channel` → `parity-checker` → `hamming-cube` → `linear-code-grid` → `syndrome-decoder` → `distance-sphere`。

## 通用硬性要求

1. **渲染方式**：新增渲染函数挂到 `src/pyrunner/viz.js` 的 `RENDERERS`，组件名使用 kebab-case；不得在课程文档中提前引用未实现类型。
2. **水合安全**：继续沿用 `pre.closest('.theme-code-block')` 定位容器；设置容器级 dataset 守卫；隐藏原生 pre，绝不 remove React 拥有的节点。
3. **双轴操作**：所有网格或空间图必须同时支持 x/y 双轴拖拽，以及点击格子/顶点翻转。触摸事件使用 Pointer Events 并调用 `setPointerCapture`。
4. **状态可读**：每个状态变化都显示二进制串、距离、校验子或方程结果；颜色之外必须提供文字或符号冗余，满足暗色模式和无障碍需求。
5. **稳定布局**：画布高度固定，格距由容器宽度和行列数推导；按钮不改变画布几何尺寸，避免拖拽中布局跳动。
6. **可重置**：提供“重置”和“随机注错”两类按钮；随机注错必须显示错误数量与位置，不能悄悄改变题目。

## noisy-channel

- **用途**：10 号课的零等待信道实验。
- **规格**：顶部为长度 8 的位带，滑杆控制 $p\in[0,0.30]$；“发送”后按独立 BSC 注入翻转，红色标记错误位，绿色标记正确位。底部滚动统计最近 100 块的平均错误数、全对块数和请求重传次数。
- **交互**：可直接拖动任意接收位覆盖噪声结果；拖动时该位不再计入本轮自动噪声统计。
- **验收**：$p=0$ 无红标；$p=1$ 全部反相；连点发送不会重复绑定事件。

## parity-checker

- **用途**：25 号课演示偶校验。
- **规格**：8 个数据位 + 1 个自动校验位。每格支持点击翻转；实时显示数据重量、校验位、接收总重量和校验子。下方列出奇数错报警、偶数错静默两种结果。
- **交互**：x/y 网格采用 3 行 3 列（最后一格为校验位）；支持横向/纵向扫过多位翻转模式，用于演示突发错误。
- **验收**：单错报警；任意两位同时翻转后校验子回到 0；第三行拖拽不越界到卡片外。

## hamming-cube

- **用途**：30/35 号课展示三维二元空间。
- **规格**：等轴投影绘制 8 个 3 位顶点，合法码字默认高亮。左侧 x/y 面板分别控制第一、第二坐标切片；右侧显示当前点到所有合法码字的 Hamming 距离表。
- **交互**：拖拽旋转必须拆成 x/y 双轴增量；单击顶点切换接收串。平票时至少两个候选同色并显示“平票”，不得自动裁决。
- **验收**：旋转后顶点标签不重叠；移动端最小命中区域不低于 32px；暗色模式下边线和文字仍可读。

## linear-code-grid

- **用途**：40/45 号课连接消息空间与码字空间。
- **规格**：左网格是消息 $\mathbb F_2^k$，右网格是由生成矩阵映射出的码字集合。默认示例 $k=2,n=5$，矩阵元素可点击在 0/1 间切换；非法矩阵（行相关）给出警告但不清空用户输入。
- **交互**：两个网格都必须支持 x/y 双向拖拽选择矩形区域；单击单元格翻转对应位。右网格同步显示逐位异或过程。
- **验收**：单位阵输出原消息映射；全零行导致维度警告；切换矩阵后旧高亮清空且无 MutationObserver 死循环。

## syndrome-decoder

- **用途**：50/70 号课统一展示校验子诊断。
- **规格**：上方是 7 位 Hamming 接收串，下方三条奇偶灯与三位校验子。支持“单错”“双错”“无错”三种预设；双错时明确提示地址可能误导。
- **交互**：位带支持横向拖拽连续翻转；校验子面板支持纵向拖拽在三组方程间查看参与的列；点击任一位也可直接翻转。
- **验收**：单错地址等于列编号；双错案例不宣称可靠纠错；重置后统计与日志全部清空。

## distance-sphere

- **用途**：55 号课展示半径 t 的 Hamming 球与球填充界。
- **规格**：二维剖面显示两个码字中心及各自半径 t 的离散点集；滑杆调整 $n\in[3,12]$ 和 $t\in[0,3]$。若两球重叠，用警示色并显示重叠计数；若超出总空间，显示球填充界失败。
- **交互**：x/y 双轴分别拖动左右球心；点击任意格点把它加入/移出候选接收点，面板解释它会被译给哪个中心或报告平票。
- **验收**：$t=0$ 只剩中心点；两心距离大于 $2t$ 时无重叠；公式区域实时显示 $t=\lfloor(d_{\min}-1)/2\rfloor$。
