# 计算机图形学

计算机图形学是应用最直观的线性代数之一：物体被矩阵移动，相机把三维场景压成二维像素，光栅化和着色再决定屏幕上的最终颜色。

这一章按下面的路线图推进：

1. [点、向量与屏幕坐标](./05-points-vectors-coords.md)——屏幕上的小房子在文件里就是一串顶点数字；点和向量长得一样，语义却不同；
2. [齐次坐标与仿射变换](./10-homogeneous-affine.md)——游戏引擎每秒要做上千万次这样的操作：把精灵平移到新位置，再旋转一个角度，顺便缩放一下；
3. [叉积与法向量](./15-cross-product-normals.md)——同一盏灯，照正脸晃眼、照斜面温柔，差别全在那根"朝外的针"：右手定则、面积含义与分量式记忆卡；配套 det-area 有向面积盘与三维法线拖视角实验；
4. [相机视图与透视投影](./20-perspective-projection.md)——站在笔直的公路中央向远方望：两侧的电线杆越远越矮、越靠越拢，最后在地平线上汇成一点；
5. [四元数：三维旋转的省心写法](./25-rotation-quaternion.md)——飞行游戏拉杆变侧滚不是 bug，是欧拉角的万向节死锁；四元数用四个数编码任意旋转；
6. [三角形光栅化与重心坐标](./30-rasterization-barycentric.md)——上一课结束时，游戏里的每个三角形都还带着三个"漂浮在连续空间里"的顶点；
7. [Bezier 曲线与 de Casteljau 套娃](./40-bezier-curves.md)——在 PS 里用钢笔工具画一条优雅的曲线：你只拖了几个控制点，曲线就温柔地跟着走——拉一下"手柄"，弧…；
8. [曲面细分选讲：递归中点的威力](./45-tessellation.md)——把一条曲线从中点切成两条精确的 Bezier，切到像素分不出为止；
9. [Phong 光照直觉](./50-phong-lighting.md)——同一个 3D 场景，关掉光照是一张扁平的剪纸；
10. [纹理采样、深度测试与混合](./60-texture-depth-blend.md)——一张贴图包住万物的 UV 地图术：顶点别图钉、重心配方勾兑坐标，最近邻与双线性的像素账、z-buffer 按片元记深度、alpha 混合的出场顺序陷阱；
11. [光线求交与路径追踪入门](./70-ray-intersection-pathtrace.md)——从眼睛反向出发的算账革命：光线撞向球与三角形的判别式，递归弹射几跳，蒙特卡洛平均把间接光照记进账本。
12. [图形学方法地图](./80-method-map.md)——实时还是离线？先分诊再开药：几何回矩阵、遮挡回深度、颜色回光照；
13. [可微分渲染：让画面倒过来教参数](./85-differentiable-rendering.md)——把反向传播接进渲染管线：画面差多少，参数该往哪动；
14. [NeRF 与体渲染：把场景装进一枚 MLP](./90-nerf-volume-rendering.md)——沿视线积雾的连续版 alpha 调酒：透过率连乘、位置编码递放大镜；

## 实战挑战 · 游戏引擎的精灵变身流水线

**背景**（情境原创，流程为通用游戏引擎渲染管线常识）：2D 游戏里每个精灵都挂着一张变换矩阵，每帧由引擎按「缩放 → 旋转 → 平移」的标准顺序合成。美术只负责拖参数，真正干活的是矩阵乘法——顺序错一点，精灵就飞出屏幕。本挑战全程纯手算矩阵乘法，不借助任何库。

**题目**：某精灵上的关键点 $P=(2, 1)$，引擎本帧的动作依次为：

- 缩放：放大 2 倍（S）；
- 旋转：绕原点逆时针 90°（R）；
- 平移：搬到 $(10, 5)$（T）。

已知三块矩阵：

$$S=\begin{pmatrix}2&0&0\\0&2&0\\0&0&1\end{pmatrix}\quad R=\begin{pmatrix}0&-1&0\\1&0&0\\0&0&1\end{pmatrix}\quad T=\begin{pmatrix}1&0&10\\0&1&5\\0&0&1\end{pmatrix}$$

- (a) 按正确作用顺序合成 $M = T\cdot R\cdot S$，写出第一行的三个元素；
- (b) 点 P 变换后的最终坐标？

(a) 已示范合成函数，但顺序装反了——先修顺序，再补齐打印：

```exercise
# @title: 实战挑战：谁把精灵传送出了地图
# @check: 10
# @check: 5
# @check: 8
# @check: 9
# @hint: 从右往左念：先 S 后 R 最后 T，所以 T 必须站在乘法最左边；对照第 10 课的组合规则。
def mul(a, b):                       # 3x3 矩阵乘法：行乘列累加
    out = []
    for r in range(3):
        row = []
        for c in range(3):
            s = 0
            for k in range(3):
                s = s + a[r][k] * b[k][c]
            row.append(s)
        out.append(row)
    return out

S = [[2, 0, 0], [0, 2, 0], [0, 0, 1]]
R = [[0, -1, 0], [1, 0, 0], [0, 0, 1]]
T = [[1, 0, 10], [0, 1, 5], [0, 0, 1]]

M = mul(S, R)      # ← 问题在这：这个顺序把平移也缩放旋转了
M = mul(M, T)

p = [2, 1, 1]                        # 齐次坐标的点
o = []
for r in range(3):
    s = M[r][0] * p[0] + M[r][1] * p[1] + M[r][2] * p[2]
    o.append(s)

print(M[0][2])   # (a)-1 合成矩阵第一行第三个元素
print(M[1][2])   # (a)-2 合成矩阵第二行第三个元素
print(o[0])      # (b)-1 终点 x
print(o[1])      # (b)-2 终点 y
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 正确顺序从右往左：先 S、再 R、最后 T。分两步乘：

$$R\cdot S=\begin{pmatrix}0&-2&0\\2&0&0\\0&0&1\end{pmatrix},\qquad M=T\cdot(R\cdot S)=\begin{pmatrix}0&-2&10\\2&0&5\\0&0&1\end{pmatrix}$$

第一行为 $(0,\ -2,\ 10)$。装反时得到 $\begin{pmatrix}0&-2&-10\\2&0&20\\0&0&1\end{pmatrix}$——平移量被旋转甩到负方向、又被缩放翻倍，精灵直接传送到 $(-12, 24)$ 出了地图。

**(b)** 用合成矩阵作用于 $(2,1,1)$：

$$x = 0\times2+(-2)\times1+10 = 8,\qquad y = 2\times2+0\times1+5 = 9$$

终点 $(8, 9)$。几何复核：点先放大到 $(4,2)$，转 90° 到 $(-2,4)$，再搬 $(10,5)$ 得 $(8,9)$ ✓——矩阵流水线与逐步动作完全一致。

完整修正代码只需改前两次矩阵乘法的顺序：先算 `T·R`，再左乘 `S`。
</details>

## 实战挑战 · 透视投影：除以深度 z

透视投影把三维点 $(x,y,z)$ 投到距离 $d$ 的屏幕上：$s_x = \frac{d\,x}{z}$、$s_y = \frac{d\,y}{z}$——**除以深度 $z$** 才有"近大远小"。点 $(2,4,8)$、屏幕距离 $4$ 时，投影是 $(1,2)$。下面这题漏除了 $z$，修到输出 `1.0 2.0`：

```exercise
# @title: 实战挑战：透视投影除以深度
# @check: 1.0 2.0
# @hint: 投影坐标 = d·x/z，别忘了除以 z。
x, y, z = 2.0, 4.0, 8.0    # 相机前方的三维点
d = 4.0                     # 投影平面到相机的距离
sx = d * x                  # ← 问题在这：漏了除以 z
sy = d * y / z
print(sx, sy)
```

<details>
<summary>点开查看逐步解答</summary>

透视投影的两个分量都要除以深度 $z$：

```python
sx = d * x / z    # 4*2/8 = 1.0
sy = d * y / z    # 4*4/8 = 2.0
print(sx, sy)     # 1.0 2.0
```

改完：$s_x = \frac{4\times2}{8} = 1.0$、$s_y = \frac{4\times4}{8} = 2.0$。初始代码 $s_x = 8$，把点投到了屏幕外。这个"除以 $z$"是透视投影的灵魂——$z$ 越大（越远），投影越小，两条平行铁轨才在远处汇成一点；少了它，透视就退化成正交投影。

</details>
