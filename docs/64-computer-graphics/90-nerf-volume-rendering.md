# NeRF 与体渲染：把场景装进一枚 MLP

## 1. 从一个场景开始

拍一圈照片，然后想从**任意没拍过的角度**看这件文物——新视角合成。传统路子要先建三角网格、展 UV、贴纹理，每一步都掉细节。2020 年 NeRF（Neural Radiance Field，神经辐射场）给出一条歪打正着的路：**不建模型，把整个场景塞进一枚 MLP**——输入一个空间点加观看方向，输出"这里有多浓、什么颜色"。训练完，从任何角度"渲染"这团雾，都像真的。

## 2. 直觉解释

把场景想象成**一团有颜色的雾**：有的地方浓（物体表面附近），有的地方稀（空气）。沿视线穿过这团雾，每一步问网络两个问题：

- "这里有多浓？"——密度 $\sigma$；
- "这个浓度是什么颜色？往这个方向看偏什么色？"——颜色 $c$，同一个位置从东看和从西看颜色可以不同（高光、镜面就是这种"方向账"）。

把这些浓度颜色沿视线**累积**起来，就得到这个像素的颜色：浓的地方挡视线、贡献多，稀的地方近乎透明。这套"沿射线积雾"的算法叫**体渲染**（volume rendering）——第 60 课的 alpha 混合是它的离散版，NeRF 用连续积分把它做精。

MLP 有个天生毛病：对输入的小抖动不敏感（输出平滑），于是"树叶的锯齿、蕾丝的花纹"这类高频细节学不像。**位置编码**把坐标先翻译成一摞不同频率的正弦波再喂进去——等于把"细看"的放大镜递给网络。

## 3. 正式定义

辐射场是一个函数 $f: (x, y, z, \theta, \varphi) \mapsto (c, \sigma)$：位置与视向进，颜色与密度出。位置先过位置编码：

$$\gamma(p) = \big(\sin(2^0 p), \cos(2^0 p), \sin(2^1 p), \cos(2^1 p), \dots \big)$$

沿视线方向 $d$ 取参数 $t$，像素颜色是加权平均：

$$C = \sum_{i} T_i \, \alpha_i \, c_i, \qquad T_i = \prod_{j < i} (1 - \alpha_j), \qquad \alpha_i = 1 - e^{-\sigma_i \delta_i}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\sigma_i$ | 密度 | 视线上第 $i$ 个采样点的"雾浓度" |
| $\delta_i$ | 步长 | 相邻两个采样点隔多远 |
| $\alpha_i$ | 不透明度 | 这一小段挡住视线的比例（$\sigma$ 越大、步子越长，越挡） |
| $T_i$ | 透过率 | 走到第 $i$ 段之前视线还剩多少：前面各段透明度的连乘 |
| $c_i$ | 颜色 | 该段贡献的颜色 |

读法与第 60 课的 alpha 调酒完全同构：**贡献 = 自己的不透明度 × 前面剩下来的透过率**；$T$ 一路连乘一路衰减，遇到浓雾（$\alpha$ 接近 1）瞬间归零——后面的东西全被挡住。

## 4. 分步例题

一条视线上采 2 个样本：$\alpha = [1.0,\ 0.5]$，颜色 $c = [0.2,\ 0.9]$。

1. 第 1 段：$T_1 = 1$（还没走过任何东西），贡献 $1 \times 1.0 \times 0.2 = 0.2$；
2. 透过率更新：$T_2 = 1 - 1.0 = 0$——第一段完全不透明，视线到此为止；
3. 第 2 段：贡献 $0 \times 0.5 \times 0.9 = 0$——它再亮也看不见；
4. 像素 $C = 0.2$。

把第一段换成半透明（$\alpha_1 = 0.5$）再看：$T_2 = 0.5$，$C = 0.2 \times 0.5 \cdot 1$ 记账为 $0.1$ 加 $0.9 \times 0.5 \times 0.5 = 0.225$，合计 $0.325$——半透明让后面的颜色**透**出来。体渲染的全部算术，就是这笔"透过率连乘 + 逐段贡献"的流水账。

### 实验（python）：沿视线做离散体渲染

```python title="体渲染：透过率连乘 + 逐段贡献"
import math
import matplotlib.pyplot as plt

def ray_color(density, colors):            # 一条视线：输入每段密度与颜色
    C = 0.0                                # 像素颜色账本
    T = 1.0                                # 透过率：从 1 起步
    for i in range(len(density)):
        contrib = T * density[i] * colors[i]        # 本段贡献 = 剩余透过率×不透明度×颜色
        C = C + contrib
        T = T * (1 - density[i])                    # 走过这段，透过率打折
    return C, T

# 视线 A：穿过浓雾中心（前段基本不透明）
dA = [0.9, 0.8, 0.7]
cA = [0.9, 0.6, 0.3]
CA, TA = ray_color(dA, cA)
print("视线A  颜色 =", round(CA, 3), " 末端透过率 =", round(TA, 3))

# 视线 B：只擦过稀雾边缘（几乎全透）
dB = [0.1, 0.1, 0.1]
cB = [0.9, 0.6, 0.3]
CB, TB = ray_color(dB, cB)
print("视线B  颜色 =", round(CB, 3), " 末端透过率 =", round(TB, 3))

# 密度剖面画出来：浓雾 vs 稀雾
fig, ax = plt.subplots(figsize=(7, 3))
ax.plot([0, 1, 2], dA, marker="o", label="ray A dense")
ax.plot([0, 1, 2], dB, marker="o", label="ray B sparse")
ax.set_ylim(0, 1)
ax.legend()
plt.show()
```

怎么玩：视线 A 的颜色 0.862 几乎全由前两段贡献（第三段透过率只剩 0.02，聊胜于无），末端透过率 0.006——雾浓处一挡到底；视线 B 颜色只有 0.168，透过率还剩 0.729——雾稀处"看得穿"。把 dA 改成 [0.3, 0.3, 0.3] 再跑：三段都能透光贡献，颜色反而接近平均——体渲染的"深度感"全部来自密度与透过率的这笔账。真实的 NeRF 每条视线采上百个点、每个点跑一次网络，训练一晚；这也就是为什么下一课要给它换台发动机。

::::warning[常见误区]

**误区一**："你以为 NeRF 里存着一张三角形网格。" 没有。网络存的是一个**连续场**——任何位置问它都答得上来，但没有任何显式几何；想拿回网格，得事后专门做"从密度场提取表面"这一步。

**误区二**："你以为位置编码是可有可无的预处理。" 没有它，MLP 的低频偏置会把整个场景糊成一团——这不是玄学，是神经网络近似理论的已知偏向；频率阶梯（$2^0$ 到 $2^{L-1}$）就是把"高频词汇表"直接递到网络嘴边。

**误区三**："你以为训练完就能实时渲染。" 渲染一个像素要沿视线查上百次网络——慢是 NeRF 的胎记。实时化的两条路：蒸馏成稀疏网络/哈希表，或者干脆换表示——下一课的 3D 高斯泼溅走的正是后一条。

::::

## 6. 练习

```exercise
# @title: 练习：手写位置编码
# @check: 0.84
# @check: 0.54
# @check: 0.91
# @check: -0.42
# @hint: 频率是 2^k（逐个翻倍），不是 2*k（等差）——k=1 时该用 sin(2p)，k=2 用 sin(4p)。
import math

p = 1.0                         # 一维坐标
L = 2                           # 编码层数：k = 0, 1

feats = []                      # 编码特征：sin(2^k p) 与 cos(2^k p) 交替
for k in range(L):
    w = 2 * k                   # ← 问题在这：频率要的是 2^k，写成了 2*k
    feats.append(math.sin(w * p))
    feats.append(math.cos(w * p))

for v in feats:
    print(round(v, 2))
```

<details>
<summary>点开查看逐步解答</summary>

频率阶梯是**指数**的：$w_k = 2^k$。

```python
    w = 2 ** k                  # 2^0=1, 2^1=2
```

修正后四项特征：$\sin(1) = 0.84$、$\cos(1) = 0.54$、$\sin(2) = 0.91$、$\cos(2) = -0.42$。初始代码的 $w = 2k$ 只给了 $0$ 倍频与 $2$ 倍频（$\sin 0 = 0$ 什么也没带），中频段全空——高频细节学不到，锅就在这一行。位置编码的"阶梯"必须一层比一层翻倍，才铺得满从粗轮廓到细纹理的整个频段。
</details>

**练习 2**：三个样本 $\alpha = [0.5, 0.5, 0.5]$、颜色 $[0.6, 0.0, 0.9]$，求像素颜色 $C$ 与末端透过率 $T$。

<details>
<summary>点开查看逐步解答</summary>

透过率：$T_1 = 1$，$T_2 = 0.5$，$T_3 = 0.25$，末端 $T = 0.125$。贡献：$1 \times 0.5 \times 0.6 = 0.3$；$0.5 \times 0.5 \times 0 = 0$；$0.25 \times 0.5 \times 0.9 = 0.1125$。合计 $C = 0.4125$。中段颜色是 0 却照样"挡光"——不透明度与颜色是两本独立的账，这一段贡献为零纯粹因为它自己没色，但它仍在替后面的颜色打折。
</details>

## 7. 选读：训练 NeRF 是在考什么

损失只有一条：**渲染出来的像素要像照片**（光度损失，上一课的碗）。训练流程=对每张已知照片的每个像素：从相机经像素发一条视线 → 采样上百点 → 每点过网络 → 体渲染出颜色 → 与照片比对 → 反向传播。难点在**采样效率**：均匀采点大多落在空气里白花钱，NeRF 用两级采样——先粗排一网格看密度分布，再在浓的地方精采（重要性采样）。后续工作把"百次网络查询"砍到个位数（Instant-NGP 的多分辨率哈希表），训练从一晚缩到几秒——但"沿视线查询"这个根本结构没变，替它换发动机的，是下一课。
