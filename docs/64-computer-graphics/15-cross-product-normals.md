# 叉积与法向量

## 1. 从一个场景开始

同一支手电筒，正对着纸照，纸面亮得晃眼；斜着照，同样的光就温柔下来。游戏里给一面墙上色时也在问同一个问题：**这块表面此刻"脸"朝着哪儿？**

[齐次坐标与仿射变换](./10-homogeneous-affine.md)解决了物体"在哪、怎么动"，可"朝向"始终没人作答。答案藏在一根从表面垂直戳出去的针里——**法向量**。本课的机器叫叉积：喂它两条边，它自动吐出这根针。

## 2. 直觉解释

拧螺丝的手早就懂叉积：螺丝刀顺时针拧，螺丝却沿"钻进木头"的方向前进——旋转决定了一个垂直于它的方向。把两个向量当作平行四边形的两条邻边搭起来，叉积交给你一件东西：

- **方向**：右手四指从向量 a 卷向 b，竖起的拇指就是 $a\times b$ 的指向（右手定则）；
- **大小**：恰好等于这个平行四边形的面积——两条边越接近垂直、越长，围出的面积越大。

面积还有一层隐含信息：一块斜板在地面上的影子越小，说明它翘得越高。叉出来的向量长度随倾斜程度变化，这正是后面光照课里"斜射变暗"的几何伏笔。

屏幕世界会把三维压扁成二维，叉积也随之退化成一个数：两条边的有向面积。正负号记录了两组向量的左右手性——下一门光栅化课判断"点在三角形内还是外"，全靠这个符号当裁判。

## 3. 正式定义

**叉积（cross product）**只对三维向量定义：$a\times b$ 是一个**向量**（注意：点积 $a\cdot b$ 的结果是一个数，两者别混），满足

$$\lVert a\times b\rVert=\lVert a\rVert\,\lVert b\rVert\sin\theta$$

| 性质 | 内容 | 一句话记忆 |
| --- | --- | --- |
| 方向 | 同时垂直于 a 与 b，符合右手定则 | 拇指定朝向 |
| 模长 | $\lVert a\rVert\lVert b\rVert\sin\theta$ = 平行四边形面积 | 面积打分 |
| 反交换 | $a\times b=-(b\times a)$ | 谁先谁后定正负 |
| 平行退化 | a 与 b 平行时结果为零向量 | 站不成四边形 |

第 11 章[点积](../11-linear-algebra/20-dot-product.md)量的是"同向程度"（乘 cosθ），叉积量的是"张开程度"（乘 sinθ）——一个管夹角余弦、一个管面积正弦，两台仪器各测各的。

**分量式记忆卡**（下标 x 对应代码里的 `a[0]`，以此类推）：写下链条 x→y→z→x 循环一圈，每个分量都是"下一个字母的 a 积再下一个的 b，减去次序对调的前积后减"，即

$$c_x=a_yb_z-a_zb_y\,,\qquad c_y=a_zb_x-a_xb_z\,,\qquad c_z=a_xb_y-a_yb_x$$

口诀只有一句：**x、y、z 轮转，前积后减；唯独中排，天生带反**。三行公式的减号位置看似杂乱，其实是同一个模式在三个循环起点上各抄一遍。

## 4. 分步例题

**例**：三角形顶点 $A=(0,0,0)$、$B=(2,0,0)$、$C=(0,2,1)$，求它的法向量与单位法线。

1. 造两条边向量：$u=B-A=(2,0,0)$，$v=C-A=(0,2,1)$；
2. 记忆卡逐分量：$n_x=u_yv_z-u_zv_y=0\times1-0\times2=0$；
3. 中排天生带反：$n_y=u_zv_x-u_xv_z=0\times0-2\times1=-2$；
4. 收尾：$n_z=u_xv_y-u_yv_x=2\times2-0\times0=4$，得 $n=(0,-2,4)$；
5. 模长与单位化：$\lVert n\rVert=\sqrt{20}$（用 $0.5$ 次幂计算即可），单位法线 $(0,-0.447,0.894)$。

验算哨卡：$n\cdot u=0$ 且 $n\cdot v=-4+4=0$——垂直性双双过关。附加彩蛋：$\lVert u\times v\rVert=\sqrt{20}\approx4.47$ 是平行四边形面积，所以这块三角形的面积正是它的一半 $\tfrac{\sqrt{20}}{2}$。法线不唯一：$-n$ 也垂直于表面，渲染时靠统一的顶点绕序约定固定朝外那根。

## 5. 动手实验

### 实验 1（viz）：二维叉积就是有向面积

```viz
{
  "type": "det-area",

```

怎么玩：拖动橙色端点改变两条"边"。绿色代表叉出的数为正、红色为负——**把两条边交换顺序，颜色立刻翻转**，这就是反交换律的具象化；把一条边拖到恰好与另一条共线，图形瘪成一条线、面积归零。屏幕上三角形判内外的"边函数"，用的就是这一个数。

### 实验 2（python）：三维法向量流水线，算出来再看清它

```python title="三维法向量流水线：算出它，再看清它"
import matplotlib.pyplot as plt      # 导入绘图库：负责把箭头画成三维图

# sliders: azim_deg=-60 [-180:180:10]

A = [0.0, 0.0, 0.0]                  # 三角形的三枚图钉（与例题同款）
B = [2.0, 0.0, 0.0]
C = [0.0, 2.0, 1.0]

def sub(p, q):                       # def 定义函数：返回位移 p - q
    return [p[0] - q[0], p[1] - q[1], p[2] - q[2]]

def cross(a, b):                     # 叉积三分量流水线：前积后减，中排带反
    return [a[1]*b[2] - a[2]*b[1],
            a[2]*b[0] - a[0]*b[2],
            a[0]*b[1] - a[1]*b[0]]

u = sub(B, A)                        # 边向量 AB
v = sub(C, A)                        # 边向量 AC
n = cross(u, v)                      # 法向量：同时垂直于两条边
norm = (n[0]**2 + n[1]**2 + n[2]**2) ** 0.5   # ** 0.5 即开平方：求模长
unit = [n[0]/norm, n[1]/norm, n[2]/norm]       # 除以模长：得到单位法线

print("u =", u)
print("v =", v)
print("法向量 n =", n)
print("模长（平行四边形面积） =", round(norm, 3))    # round 取三位小数

fig = plt.figure(figsize=(6, 5))     # 新建一块画布
ax = fig.add_subplot(projection="3d")          # 参数 projection="3d"：升成三维坐标面

o = [[0], [0], [0]]                  # 所有箭头的出发点 A
ax.quiver(o[0], o[1], o[2], [2*u[0]], [2*u[1]], [2*u[2]], color="tab:blue")
ax.quiver(o[0], o[1], o[2], [2*v[0]], [2*v[1]], [2*v[2]], color="tab:orange")
ax.quiver(o[0], o[1], o[2], [3*unit[0]], [3*unit[1]], [3*unit[2]], color="crimson")
# quiver 从(x,y,z)出发画一支方向为(dx,dy,dz)的箭头；边放大 2 倍、法线放大 3 倍便于观察

ax.text(2*u[0], 2*u[1], 2*u[2], " u", color="tab:blue")        # 在箭尖写名字
ax.text(2*v[0], 2*v[1], 2*v[2], " v", color="tab:orange")
ax.text(3*unit[0], 3*unit[1], 3*unit[2], " n", color="crimson")

ax.plot([A[0], B[0], C[0], A[0]], [A[1], B[1], C[1], A[1]],
        [A[2], B[2], C[2], A[2]], linestyle="--", color="gray")   # 首尾相接闭合三角形
ax.scatter([A[0], B[0], C[0]], [A[1], B[1], C[1]], [A[2], B[2], C[2]], color="black")

ax.set_xlabel("x"); ax.set_ylabel("y"); ax.set_zlabel("z")
ax.set_box_aspect([1, 1, 1])         # 三轴等比例，防止箭头被拉伸变形
ax.view_init(elev=18, azim=azim_deg) # elev 仰角、azim 水平方位角：拖滑块绕着看一圈
```

怎么玩：红色箭头就是机器吐出的法向量。拖动 `azim_deg` 让相机绕场景旋转：无论从哪个角度看，红色的针始终保持与灰色三角形"站着不相交"的姿态——垂直不是某个视角的巧合，而是三张投影片同时压扁成点的承诺。

### 快问快答

```quiz
向量 a 和 b 都躺在 xy 平面上（第三个分量全是 0），它们的叉积指向哪里？
- 也躺在 xy 平面内，同时垂直于 a 和 b
- 沿 z 轴向上或向下，正负号由分量计算决定 [*]
- 一定是零向量，因为二维没有真正的叉积
? 三组"前积后减"里，含 z 分量的项全部归零，只剩 cz = ax*by - ay*bx 存活。二维叉积并非消失，而是被压扁成这一个数——有向面积，正是下一门光栅化课边函数的灵魂。
```

:::warning[常见误区]

**误区一**："你以为叉积和点积只是符号差。" 点积产出一个数（角度计），叉积产出一个向量（面积＋拇指）。公式更不能串门：一个配 cosθ、一个配 sinθ，混背必翻车。

**误区二**："你以为 $a\times b=b\times a$。" 叉积反交换：交换两边等于让拇指倒插，$b\times a=-(a\times b)$。图形学里这直接翻译成"逆时针为正、顺时针为负"的生死线。

**误区三**："你以为算完就能拿去光照。" 光照模型要吃**单位法线**；忘记除以模长，亮度会随三角形大小漂移——大墙永远比小墙亮的灵异现象就这么来。

:::

## 6. 练习

**练习 1**：一块新板材的两条边已知：$u=(2,1,0)$、$v=(1,3,2)$。求叉积 $n=u\times v$ 的三个分量（打印三行整数）。代码能跑，但有个分量总不对劲：

```exercise
# @title: 练习：三条边向量过机器，谁被翻了牌
# @check: 2
# @check: -4
# @check: 5
# @hint: 记忆卡说"唯独中排，天生带反"。行列式按第一行展开时，中间那一项外面要多挂一个负号——逐行对照卡片查加减号。
def cross(a, b):                      # 三条流水线各管一个分量
    cx = a[1] * b[2] - a[2] * b[1]
    cy = a[0] * b[2] - a[2] * b[0]    # ← 这一行和另外两行的脾气不一样，查它
    cz = a[0] * b[1] - a[1] * b[0]
    return [cx, cy, cz]

u = [2, 1, 0]                         # 第一条边向量
v = [1, 3, 2]                         # 第二条边向量

n = cross(u, v)
print(n[0])
print(n[1])
print(n[2])
```

<details>
<summary>点开查看逐步解答</summary>

正确三分量为 $(2,-4,5)$：$n_x=u_yv_z-u_zv_y=1\times2-0\times3=2$；中间一行要先对调整序再做减法 $n_y=u_zv_x-u_xv_z=0\times1-2\times2=-4$；$n_z=u_xv_y-u_yv_x=2\times3-1\times1=5$。初始代码把中排写成了 $u_xv_z-u_zv_x=4$——恰好是正确值的相反数：丢掉的就是行列式展开里 j 位 cofactor 的那个负号。

修正只需把出错行换回 `cy = a[2] * b[0] - a[0] * b[2]`。最后上验算哨卡：$n\cdot u=4-4+0=0$，$n\cdot v=2-12+10=0$——修改后的 n 与两条边都垂直 ✓。
</details>

**练习 2**：屏幕上有个三角形，顶点 $A=(0,0)$、$B=(2,0)$、$C=(0,2)$（全部 $z=0$），视线从 $+z$ 方向来。仅凭叉积的正负号，如何一眼判定它是迎面还是背面？

<details>
<summary>点开查看逐步解答</summary>

按 $A\to B\to C$ 的顺序走，三角形落在屏幕上是**逆时针**。取 $u=B-A=(2,0,0)$、$v=C-A=(0,2,0)$，则 $u\times v=(0,0,u_xv_y-u_yv_x)=(0,0,4)$，指向 $+z$——与视线同侧，于是这块面正脸迎着你（正面）。若顶点绕序反过来，叉出的就是 $(0,0,-4)$，负号宣判它转过身去了。引擎每一帧扔掉所有"背对相机"的三角形，就省掉一半像素工作；整套机关只是本课这一个数的符号。
</details>

## 7. 边界与适用条件

- 叉积是**三维专属**工具（加上压扁版二维）；更高维度里"唯一的垂直方向"不复存在，想要推广得另请楔积，那是代数学家的地界。
- 它给出的是**一对候选方向**（±n）；哪个朝外不由数学定，而由绕序约定定——不同教材、引擎约定可能镜像，读外部资料先确认左右手系。
- 本课只负责生产法线，**不管明暗**：怎么用法线和光线算亮度，属于后面的 Phong 光照课；用边函数符号剔除背面，属于光栅化课。
- 物理里的力矩、洛伦兹力和这里是同一件数学器具，但符号约定同样依赖手性与坐标次序，跨领域引用时要先对表。

## 8. 选读：为什么偏偏是这三个分量

<details>
<summary>选读 · 从行列式里长出叉积</summary>

把 $a$、$b$ 塞进一张三行表格，第一行假装修饰成单位向量 $\mathbf{i},\mathbf{j},\mathbf{k}$，后两行放 $a$ 与 $b$，然后按第一行展开这张"伪行列式"：i 的系数是划去第一列的二阶行列式（$a_yb_z-a_zb_y$），j 的系数外层要挂负号（$-(a_xb_z-a_zb_x)=a_zb_x-a_xb_z$），k 的系数又是正号（$a_xb_y-a_yb_x$）。正负交替不是人为规定，而是排列奇偶性的自然节拍——这就是记忆卡口诀"中排带反"的血统证明。至于模长等于面积、方向符合右手，可以用两次点积验证：$(a\times b)\cdot a=(a\times b)\cdot b=0$，且 $\lVert a\times b\rVert^2=\lVert a\rVert^2\lVert b\rVert^2-(a\cdot b)^2$，右端恰是 $|a|^2|b|^2\sin^2\theta$。
</details>
