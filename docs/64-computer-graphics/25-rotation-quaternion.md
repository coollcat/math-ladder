# 四元数：三维旋转的省心写法

## 1. 从一个场景开始

飞行游戏里，你把机头拉起、再横滚、再偏航——连续几个动作之后，飞机突然不听使唤：拉杆变成侧滚。这不是程序 bug，而是**欧拉角**（用三个转角描述姿态）本身的死穴：某个特定姿态下，两个转轴重合，丢掉一个自由度。这叫**万向节死锁**（gimbal lock）。

游戏与航天领域的标准解法，是一种 1843 年发明、沉寂了一百多年又被计算机唤醒的数：**四元数**。它用四个数编码任意三维旋转，乘法拼接姿态，永不死锁。

## 2. 直觉解释

第 12 章的复数用两个数编码了**平面**旋转：乘以 $e^{i\theta}$ 就是转 $\theta$ 角。四元数是这件事的三维升级——给虚数单位从 1 个扩到 3 个（$i$、$j$、$k$，各管一根轴），一个四元数就是

$$q = w + x\,i + y\,j + z\,k,$$

写成列表就是 $[w, x, y, z]$。**单位四元数**（长度为 1）编码一个旋转：绕轴 $\vec u$ 转 $\theta$ 角，对应

$$q=\left[\cos\frac{\theta}{2},\ \sin\frac{\theta}{2}\,u_x,\ \sin\frac{\theta}{2}\,u_y,\ \sin\frac{\theta}{2}\,u_z\right].$$

注意那个"半角"：转 90 度的四元数里写的是 $\cos 45°$。为什么是半角？因为作用向量要**乘两次**（左乘一次、右乘共轭一次），两个半角凑成一个整角。

三个立刻要立起来的规矩：

1. 必须单位化才表示旋转（长度不是 1 的四元数会附带缩放）；
2. $q$ 与 $-q$ 是**同一个**旋转（都乘了 -1，作用不变）——所以四元数"双覆盖"三维旋转；
3. 共轭 $q^\ast=[w,-x,-y,-z]$ 是反向旋转，作用向量时它负责三明治的另一片。

## 3. 正式定义

四元数乘法（Hamilton 积），对 $[w_1,x_1,y_1,z_1]\times[w_2,x_2,y_2,z_2]$：

```text
w = w1·w2 − x1·x2 − y1·y2 − z1·z2
x = w1·x2 + x1·w2 + y1·z2 − z1·y2
y = w1·y2 − x1·z2 + y1·w2 + z1·x2
z = w1·z2 + x1·y2 − y1·x2 + z1·w2
```

用四元数旋转一个三维向量 $\vec v$ 的**三明治公式**：

$$\vec v' = q\,(0,\ v_x,\ v_y,\ v_z)\,q^\ast.$$

把 $\vec v$ 装进"实部为零"的纯四元数，左乘 $q$、右乘共轭 $q^\ast$，出来的纯四元数的向量部分就是旋转结果。

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $w$ | 实部 | $\cos(\theta/2)$，转角越大越接近 0 |
| $(x,y,z)$ | 向量部 | 转轴方向乘 $\sin(\theta/2)$ |
| $q^\ast$ | 共轭 | 向量部取负，表示反方向旋转 |
| 单位化 | $q/\|q\|$ | 用之前必做，否则旋转会带上缩放 |

## 4. 分步例题

**例 1**：绕 $z$ 轴转 90°。轴 $\vec u=(0,0,1)$、$\theta=90°$：

1. $q=[\cos45°,\ 0,\ 0,\ \sin45°]=[0.707,\ 0,\ 0,\ 0.707]$；
2. 取 $\vec v=(1,0,0)$（$x$ 轴方向），装进纯四元数 $(0, 1, 0, 0)$；
3. 三明治乘出来是 $(0, 0, 1, 0)$——向量部分 $(0,1,0)$：$x$ 轴转到了 $y$ 轴，正是绕 $z$ 逆时针 90°。

**例 2**：两个四元数相乘 = 两次旋转拼接。先绕 $z$ 转 90°（$q_1$）、再绕 $x$ 转 90°（$q_2$），合成姿态是 $q_2 q_1$（**先做的写在右边**，与矩阵从右往左同一习惯）。

### 实验 2：手搓四元数三明治

```python title="纯列表实现四元数乘法，把 x 轴转 90 度"
import math

def qmul(a, b):        # 四元数乘法（Hamilton 积）：a、b 都是 [w, x, y, z]
    w1, x1, y1, z1 = a
    w2, x2, y2, z2 = b
    return [w1*w2 - x1*x2 - y1*y2 - z1*z2,
            w1*x2 + x1*w2 + y1*z2 - z1*y2,
            w1*y2 - x1*z2 + y1*w2 + z1*x2,
            w1*z2 + x1*y2 - y1*x2 + z1*w2]

def qconj(q):          # 共轭：向量部分取负
    return [q[0], -q[1], -q[2], -q[3]]

half = math.cos(math.pi / 4)              # cos45° 与 sin45° 都是 √2/2
q = [half, 0.0, 0.0, math.sin(math.pi / 4)]   # 绕 z 轴转 90 度
v = [0.0, 1.0, 0.0, 0.0]                  # 纯四元数：实部为 0，向量部 (1,0,0)

qv = qmul(q, v)                 # 第一片面包
out = qmul(qv, qconj(q))        # 第二片面包：右乘共轭
print([round(x, 2) for x in out[1:]])     # out[0] 是实部，转完应为 0

wrong = qmul(qmul(qconj(q), v), q)        # 共轭放错一侧：反着转
print([round(x, 2) for x in wrong[1:]])
```

输出 `[0.0, 1.0, 0.0]` 与 `[0.0, -1.0, 0.0]`。第一行：$x$ 轴转到 $y$ 轴，正确；第二行：共轭放到了左边，转成 $-90°$，$x$ 轴转到了 $-y$。**三明治的顺序不是装饰，差一侧就是反方向。**

### 实验 3：欧拉角死锁 vs 四元数全程在线

```python title="连续三段旋转：四元数乘法一路拼下去"
import math

def qmul(a, b):
    w1, x1, y1, z1 = a
    w2, x2, y2, z2 = b
    return [w1*w2 - x1*x2 - y1*y2 - z1*z2,
            w1*x2 + x1*w2 + y1*z2 - z1*y2,
            w1*y2 - x1*z2 + y1*w2 + z1*x2,
            w1*z2 + x1*y2 - y1*x2 + z1*w2]

def qaxis(axis, deg):     # 绕单位轴 axis 转 deg 度的四元数
    h = math.radians(deg) / 2
    s = math.sin(h)
    return [math.cos(h), axis[0] * s, axis[1] * s, axis[2] * s]

qz = qaxis([0, 0, 1], 90)     # 偏航 90 度
qx = qaxis([1, 0, 0], 30)     # 俯仰 30 度
qy = qaxis([0, 1, 0], 60)     # 滚转 60 度

combo = qmul(qmul(qy, qx), qz)            # 从右往左依次做：先 qz，再 qx，最后 qy
norm = math.sqrt(sum(c * c for c in combo))   # 生成器表达式：四个分量平方和再开根
print([round(c / norm, 3) for c in combo])
```

输出 `[0.683, 0.5, 0.183, 0.5]`——三段绕不同轴的旋转拼成一个单位四元数，全程没有一个姿态让乘法失效。若用欧拉角走"先偏航再俯仰"的路径，俯仰一旦逼近 ±90° 就撞上死锁姿态（偏航轴与滚转轴重合），第三段就再也回不到正确航向了。

```text

```

右手系里逆时针转 90° 的顺序是 $x\to y\to(-x)\to(-y)$：$y$ 轴自然落到 $-x$ 轴。绕 $z$ 轴的旋转不改 $z$ 分量，把 $(0,0,0,1)$ 代进同一个三明治可以自己验证它原地不动。

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为随便一个四元数都能转。长度不是 1 的四元数旋转时会附带缩放（长度 2 的四元数把模型放大 4 倍）。每次插值、每次乘法之后都重新单位化，是引擎里的标准动作。

**误区二**：你以为 $q$ 和 $-q$ 是两种姿态。整体变号后三明治公式的作用完全相同——同一个旋转有两种四元数写法。做插值时若两端的符号相反，会绕远路，插值前先对齐符号。

**误区三**：你以为欧拉角公式可以照抄。转角顺序约定（XYZ 还是 ZYX、内旋还是外旋）不同引擎不同，同样的三个数姿态完全不同。抄公式之前先查文档的约定。

:::

## 9. 选读：为什么不会死锁

<details>
<summary>选读 · 死锁的根源与四元数的免疫</summary>

欧拉角把姿态拆成三次绕固定轴的旋转（例如先偏航、再俯仰、后滚转），本质是给三维旋转群装了一套"经纬度"坐标。任何球面坐标都有一个天生缺陷：**极点处经度失去意义**。当俯仰角到达 ±90°，偏航轴与滚转轴在空间里指向同一根线——这时改偏航和改滚转的效果一模一样，一个自由度丢了。这就是万向节死锁：不是实现 bug，是"用三个数描述三维旋转"这种参数化本身在极点退化。

四元数不存在坐标奇点，因为它不把旋转"拆成三次转动"，而是把整个姿态编码成四维单位球面上的一个点。三维旋转群（SO(3)）拓扑上等价于这个四维球面的"对径点粘合"版本——$q$ 与 $-q$ 粘成一点正是双覆盖的来源。单位四元数处处光滑、处处无退化，代价是四个数描述三个自由度（多一个约束）。

工程上的后续话题是 SLERP（球面线性插值）：在两个姿态之间沿四维球面的大圆走，转角均匀、路径最短——游戏里相机平滑转向的背后全是它。证明超纲，用法一句话：**插值用 SLERP，不要对四个分量各自做线性插值**（后者会经过长度小于 1 的四元数，转出来先加速再减速）。

</details>
