# 3D 高斯泼溅：一团椭球拼出照片级场景

## 1. 从一个场景开始

NeRF 把场景装进了网络，可渲染一个像素要沿视线问上百次网络——慢得没法上线。2023 年 3DGS（3D Gaussian Splatting，三维高斯泼溅）换了个朴素的表示：**把场景写成几十万枚带颜色的半透明椭球**，渲染时用第 30 课的老朋友光栅化把每枚椭球"泼"到屏幕上，再按深度做 alpha 混合。没有网络查询、没有光线步进——GPU 最擅长的平铺运算，帧率直接从"每秒几帧"跳到"每秒上百帧"。

## 2. 直觉解释

每枚 3D 高斯是一张"认知卡"，记四件事：

- **中心**：椭球悬在空间哪里（3 个数）；
- **形状**：椭球朝哪歪、三根轴多长——这正是第 21 课协方差矩阵的看家本领：协方差的**特征向量**给方向、**特征值**给轴长平方；
- **不透明度**：一个数，挡光多少；
- **颜色**：不是死板一个色值，而是第 16 章球谐函数的 9 枚系数——从不同角度看会微微变色（高光、反光全在这本"方向账"里）。

渲染时把椭球沿视线方向压扁成屏幕上一枚 2D 高斯斑，几十万枚斑块按深度从近到远排序、逐枚 alpha 混合——像素颜色就此落定。**训练**则由上一课的可微渲染总包：渲染与照片差多少，梯度就倒流回去调整每枚高斯的位置、形状、颜色；不够细致的地方自动"分裂"出新高斯（致密化），没用的自动剪掉。

## 3. 正式定义

以中心 $\mu$、协方差 $\Sigma$ 的三维高斯：

$$G(x) = \exp\left(-\tfrac{1}{2}(x-\mu)^{T} \Sigma^{-1} (x-\mu)\right)$$

协方差**不许随便填**——任意矩阵可能不对称、不正定（椭球退化成鬼影）。标准写法把 $\Sigma$ 拆成"旋转 × 缩放"：

$$\Sigma = R\, S\, S^{T} R^{T}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mu$ | 中心 | 高斯悬在空间的位置 |
| $\Sigma$ | 协方差矩阵 | 椭球的形状与朝向（对称正定） |
| $R$ | 旋转 | 用四元数存——第 25 课的老朋友 |
| $S$ | 缩放 | 三根主轴的半轴长 |
| $\alpha$ | 不透明度 | 泼到屏幕后挡光的比例 |
| $SH$ | 球谐系数 | 9 枚（$l \le 2$），存"颜色随视角怎么变" |

投影与合成：3D 高斯经相机变换后，在切平面用局部线性化（雅可比近似）压成 2D 高斯斑；像素颜色沿用第 90 课的体渲染账：

$$C = \sum_i c_i\, \alpha_i' \prod_{j<i}(1 - \alpha_j'), \qquad \alpha_i' = \alpha_i \cdot G_i^{2D}(\text{像素})$$

与 NeRF 的差别只在 $\alpha$ 的来源：那边是"密度 × 步长"，这边是"不透明度 × 2D 高斯在这枚像素上的高度"——账本结构一模一样。

## 4. 分步例题

把世界压成一维：像素 $p = 3$ 上泼两枚 1D 高斯。高斯一：中心 $\mu_1 = 2$、宽 $\sigma_1 = 1$、不透明度 $\alpha_1 = 0.6$、颜色 $c_1 = 1.0$；高斯二：$\mu_2 = 4$、$\sigma_2 = 1$、$\alpha_2 = 0.8$、$c_2 = 0$。

1. **高斯在像素处的高度**：$G_1(3) = e^{-\frac{(3-2)^2}{2}} = e^{-0.5} \approx 0.607$；$G_2(3) = e^{-\frac{(3-4)^2}{2}} = 0.607$；
2. **有效不透明度**：$\alpha_1' = 0.6 \times 0.607 = 0.364$；$\alpha_2' = 0.8 \times 0.607 = 0.485$；
3. **按深度排序**（近的先画）：高斯一更近（$z$ 小），先上；
4. **alpha 混合**：$C = \underbrace{1.0 \times 0.364}_{\text{高斯一}} + \underbrace{0 \times 0.485 \times (1 - 0.364)}_{\text{高斯二被剩透过率打折}} = 0.364$。

高斯二颜色是 0，但它不是白站：若它颜色是 0.9，贡献将是 $0.9 \times 0.485 \times 0.636 = 0.278$——"剩下的透过率"就是前面所有邻居给它留的窗口。

### 实验（python）：两枚二维高斯泼到像素网格

```python title="2D 泼溅：协方差整形、投影、alpha 混合"
import math
import matplotlib.pyplot as plt

W = 60                                  # 像素网格边长
img = [[0.0] * W for _ in range(W)]     # 灰度画布：先全黑

splats = [                              # 三枚"压扁的高斯"：(中心x, 中心y, 长轴半长a, 短轴半长b, 朝角t, 不透明度al, 亮度c)
    (20.0, 30.0, 12.0, 5.0, 0.5, 0.9, 1.0),
    (38.0, 22.0, 10.0, 6.0, -0.4, 0.8, 0.7),
    (33.0, 42.0, 8.0, 8.0, 0.0, 0.7, 0.4),
]

for cx, cy, a, b, th, al, c in splats:
    cos_t = math.cos(th)                # 旋转矩阵 R：把"横长椭圆"转到朝向 th
    sin_t = math.sin(th)
    for py in range(W):                 # 逐像素泼：算每像素处的 2D 高斯高度
        for px in range(W):
            dx = px - cx
            dy = py - cy
            u = cos_t * dx + sin_t * dy             # 旋到椭圆自己的坐标系
            v = -sin_t * dx + cos_t * dy
            g = math.exp(-(u * u / (2 * a * a) + v * v / (2 * b * b)))   # 椭圆高斯
            alpha = al * g                          # 有效不透明度 = 不透明度×高度
            img[py][px] = img[py][px] + c * alpha * (1 - img[py][px])    # alpha 混合：旧色被新色按比例盖

fig, ax = plt.subplots(figsize=(5, 5))
ax.imshow(img, cmap="magma", origin="lower")        # 像素画布直接上屏
ax.set_title("3 gaussian splats, alpha-blended")
plt.show()
```

怎么玩：三枚斜躺的椭圆斑按泼入顺序混合——后泼的透出先泼的（`1 - img` 就是剩余透过率）。把第二枚的 `al` 改成 0.3：它淡成一层薄纱，底色渗出；把两枚 `c` 都调成 1.0 再把顺序对调：混合结果**不变**——同色时顺序无感，可一旦颜色不同，顺序就是深度，混错了就穿帮（第 60 课的调酒陷阱在泼溅里原样复现）。真实 3DGS 对几十万枚高斯按深度**排序后**再混合，正是为了这一点。

::::warning[常见误区]

**误区一**："你以为协方差矩阵随便填就行。" 任意 $3\times3$ 矩阵可能不对称、不正定，"椭球"瞬间退化成无意义形状。参数化 $\Sigma = R S S^{T} R^{T}$ 把自由度交给四元数（旋转）与三个正数（轴长）——怎么调都合法，优化才稳。

**误区二**："你以为混合顺序无所谓。" 第 60 课的 alpha 调酒陷阱原样适用：颜色不同的高斯泼错了序，颜色就错。3DGS 专门有一步**按深度排序**；也正是这一步让"完全正确"与"够快"之间永远在拉扯（排序是逐 tile 并行做的）。

**误区三**："你以为每枚高斯只有一个颜色。" 颜色挂在球谐系数上（回看第 16 章）：同一个位置，正着看、斜着看、逆光看，颜色可以不同——高光与反射就是靠这 9 枚系数"低频地"记下来的。

::::

## 6. 练习

```exercise
# @title: 练习：给一枚像素做 alpha 混合账
# @check: 0.5625
# @check: 0.125
# @hint: 每画一枚高斯，剩余透过率都要乘 (1−α) 打折——"前面剩多少"决定"后面透出多少"。
alphas = [0.5, 0.5, 0.5]        # 三枚高斯的有效不透明度（近→远）
colors = [1.0, 0.0, 0.5]        # 各自的颜色

C = 0.0                         # 像素颜色账本
T = 1.0                         # 剩余透过率
for i in range(3):
    C = C + colors[i] * alphas[i]      # ← 问题在这：忘了乘剩余透过率 T
    T = T * (1 - alphas[i])

print(round(C, 4))
print(round(T, 3))
```

<details>
<summary>点开查看逐步解答</summary>

混合公式里每一项都要带上"走到这里还剩多少透过率"：

```python
    C = C + colors[i] * alphas[i] * T    # 贡献 = 颜色×不透明度×剩余透过率
    T = T * (1 - alphas[i])
```

修正后：贡献 $1 \times 0.5 \times 1 = 0.5$；$0 \times 0.5 \times 0.5 = 0$；$0.5 \times 0.5 \times 0.25 = 0.0625$，合计 $C = 0.5625$；末端透过率 $T = 0.125$。初始代码把每枚都按"全透过"记账，中间那枚没颜色也不打折，读数虚高成 0.75。**透过率连乘**是体渲染与泼溅共用的灵魂账本——第 90 课的 $T_i$ 与这里的 `(1 - α)` 是同一件事。
</details>

**练习 2**：一枚 2D 高斯，长轴半长 $a = 2$、短轴半长 $b = 0.5$。旋转前的形状矩阵是 $\mathrm{diag}(a^2, b^2)$，求它的两个特征值，并说说特征向量指向哪里。

<details>
<summary>点开查看逐步解答</summary>

对角矩阵的特征值就是对角元：$\lambda_1 = a^2 = 4$、$\lambda_2 = b^2 = 0.25$；特征向量分别是横轴方向与纵轴方向。这正是 3DGS 参数化的底层逻辑：**特征值 = 半轴长的平方，特征向量 = 椭球主轴方向**——第 21 课的谱定理在这里变成了"椭球的长相"。所以实现里不直接存 $\Sigma$，而存"旋转四元数 + 三个轴长"，从源头保证它永远是一枚规规矩矩的椭球。
</details>

## 7. 选读：训练一场景的完整流水线

从照片到 3DGS 场景的标准流程：**SfM 起步**——用多张照片估计相机位姿并撒出稀疏点云（机器人卷会专门讲这套几何）；**高斯初始化**——每个稀疏点安插一枚高斯；**可微渲染循环**——随机抽一张照片渲染比对，梯度经混合账本倒流，用 ADAM 同时更新每枚高斯的位置、四元数、轴长、不透明度与 SH 系数；**致密化与剪枝**——梯度大、欠拟合的区域克隆/分裂新高斯，长期"透明又没贡献"的剪掉。几百到几万轮迭代后，照片级的实时场景就练成了——机器人 SLAM 界已经把这条流水线搬上无人机，边飞边泼（机器人卷的 3DGS-SLAM 一课再叙）。
