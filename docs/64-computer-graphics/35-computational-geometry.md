# 计算几何：凸包、Delaunay 三角剖分与 Voronoi 图

## 1. 从一个场景开始

地图上撒了一把传感器。两个问题会立刻冒出来：**最外圈是哪几个**（把它们连起来就是覆盖范围）、**每个点的"辖区"怎么划**（离哪个传感器最近就归谁）。第一个问题的答案是凸包，第二个的答案是 Voronoi 图——它们看着是两件不相干的事，其实是同一块几何的两面。

更妙的是，两者中间夹着第三个东西：把相邻辖区的站点连起来，得到一张三角形网格，它**没有任何一个"瘦三角形"**。这张网格叫 Delaunay 三角剖分，是有限元网格、地形建模、路径规划的默认起点。

## 2. 直觉解释

**凸包 = 橡皮筋**。把平面当木板，把点当钉子，一根橡皮筋套住所有钉子后松手——它收紧成的形状就是凸包。它只留下"站得够外"的那几个点，其余全被包在里面。

**Voronoi = 势力范围**。每个站点向四周占地盘，谁离得近归谁。两个站点的分界线不是别的，正是**它们连线的中垂线**——线上任一点到两站点距离相等。多条中垂线一围，每个站点得到一块凸多边形（辖区）。

**Delaunay = Voronoi 的对偶**。把"辖区相接"的两个站点连一条边，得到的三角形网格就是 Delaunay。它有一个漂亮到不像话的性质：**每个三角形的外接圆内部，不含任何其它站点**——这叫空圆性质。为什么它偏爱"胖"三角形？因为空圆性质等价于**最大化最小角**：任何瘦长的三角形都能被翻边（flip）换成更胖的，而 Delaunay 已经是那个最优状态。数值计算里瘦三角形是灾难（插值误差大、有限元刚度矩阵病态），所以大家都要 Delaunay。

三个东西的关系一句话说完：**凸包是外边界，Voronoi 是分区，Delaunay 是接缝**。

## 3. 正式定义

**凸包**：给定点集 $P$，它的凸包是包含 $P$ 的最小凸集：

$$\mathrm{conv}(P)=\Bigl\lbrace\textstyle\sum_i \lambda_i p_i \ \Big|\ p_i\in P,\ \lambda_i\ge 0,\ \sum_i\lambda_i=1\Bigr\rbrace$$

**叉积判向**：三点 $o,a,b$ 的方向由二维叉积的 $z$ 分量给出：

$$\mathrm{cross}(o,a,b)=(a_x-o_x)(b_y-o_y)-(a_y-o_y)(b_x-o_x)$$

$\mathrm{cross}>0$ 表示 $o\to a\to b$ **左转**，$<0$ 右转，$=0$ 共线。这是第 15 课"有向面积"的原样复用——$\mathrm{cross}$ 的两倍就是三角形 $oab$ 的有向面积。

**Delaunay 三角剖分**：对点集 $P$ 的一个三角剖分，若每个三角形的**外接圆内部不含 $P$ 中其它点**，则称它是 Delaunay 三角剖分。判据是 in-circle 行列式：

$$\det\begin{pmatrix}a_x-d_x & a_y-d_y & (a_x-d_x)^2+(a_y-d_y)^2\\ b_x-d_x & b_y-d_y & (b_x-d_x)^2+(b_y-d_y)^2\\ c_x-d_x & c_y-d_y & (c_x-d_x)^2+(c_y-d_y)^2\end{pmatrix}>0$$

（三角形 $abc$ 逆时针时）。$>0$ 表示 $d$ 落在 $\triangle abc$ 的外接圆内。

**Voronoi 图**：站点 $p_i$ 的 Voronoi 单元是

$$V_i=\bigl\lbrace q \mid \lVert q-p_i\rVert\le \lVert q-p_j\rVert\ \ \forall j\neq i\bigr\rbrace$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mathrm{conv}(P)$ | 凸包 | 绷住点集的最紧凸多边形 |
| $\mathrm{cross}(o,a,b)$ | 叉积判向 | 正左转、负右转、零共线 |
| 外接圆 | circumcircle | 过三角形三顶点的唯一圆 |
| $V_i$ | Voronoi 单元 | 站点 $p_i$ 的最近邻管辖区域 |
| 对偶 | duality | 点 ↔ 面、边 ↔ 边的一一对应 |

三者的复杂度都是 $O(n\log n)$（凸包与 Delaunay 的最优界，Voronoi 由 Delaunay 对偶而来），空间都是 $O(n)$。

## 4. 分步例题

**例 A（手跑一遍凸包）**：点集 $(0,0),(4,1),(3,3),(1,2),(2,4),(5,2),(0,3)$。

1. 先按 $x$ 再按 $y$ 排序，得 $(0,0),(0,3),(1,2),(2,4),(3,3),(4,1),(5,2)$；
2. 从左往右扫，维护一个栈，只保留"左转"的点：$(0,0)\to(0,3)$ 左转？$\mathrm{cross}((0,0),(0,3),(1,2))=(0)(2)-(3)(1)=-3<0$，**右转，弹掉 $(0,3)$**；
3. 继续：栈里 $(0,0),(2,4),(3,3)$，遇 $(4,1)$ 时 $\mathrm{cross}=-9<0$，弹 $(3,3)$；遇 $(5,2)$ 时 $\mathrm{cross}((0,0),(4,1),(5,2))=3>0$，**留下**；
4. 下壳得 $(0,0),(4,1),(5,2)$；反向再扫一遍得上壳 $(5,2),(2,4),(0,3),(0,0)$；
5. 拼起来去重：凸包 = $(0,0),(4,1),(5,2),(2,4),(0,3)$，共 **5 个顶点**——$(1,2)$ 与 $(3,3)$ 被包在里面。

**例 B（一维辖区）**：两个站点在 $a=-1$ 与 $b=2$。

1. 分界线上任一点 $q$ 满足 $|q-a|=|q-b|$；
2. 一维时绝对值一去就得到 $q=(a+b)/2=0.5$；
3. 所以 $x<0.5$ 归 $a$，$x>0.5$ 归 $b$——**一维 Voronoi 就是取中点**；
4. 二维的推广：把"中点"换成"中垂线"，把"两条线的交点"换成"多条中垂线围成的多边形"。

### 实验 2（python）：Graham/Andrew 扫描真的能算出凸包

```python
pts = [(0, 0), (4, 1), (3, 3), (1, 2), (2, 4), (5, 2), (0, 3)]

def cross(o, a, b):        # 叉积判向：>0 左转、<0 右转、=0 共线
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    ps = sorted(set(points))          # set 去重，再按 (x, y) 排序
    if len(ps) <= 2:
        return ps
    lower = []                        # 下壳
    for p in ps:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()               # 不是左转就把上一个点弹出去
        lower.append(p)
    upper = []                        # 上壳：反向再扫一遍
    for p in reversed(ps):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]    # 去掉两个重复的端点

hull = convex_hull(pts)
print(len(hull))
print(hull)
```

输出 `5` 与 `[(0, 0), (4, 1), (5, 2), (2, 4), (0, 3)]`，正是例 A 手算的结果。**整个算法只有"排序 + 一次扫描 + 一个栈"**：每遇到一个点，就把栈顶那些"会让路径右转"的点连续弹掉。`<= 0` 里的那个等号负责处理共线点——它把共线中间点也弹掉，只留两端。把等号去掉，共线的点会全部保留在凸包上。

### 实验 3（python）：空圆性质——Delaunay 的身份证

```python
A = (0.0, 0.0); B = (4.0, 0.0); C = (0.0, 4.0)   # 逆时针排列的三角形

def in_circle(a, b, c, d):
    ad = (a[0] - d[0], a[1] - d[1])       # 三个顶点相对 d 的位移
    bd = (b[0] - d[0], b[1] - d[1])
    cd = (c[0] - d[0], c[1] - d[1])
    # in-circle 行列式：三行分别是 (位移, 位移的平方长度)
    det = (ad[0] * (bd[1] * (cd[0] ** 2 + cd[1] ** 2) - (cd[1] * (bd[0] ** 2 + bd[1] ** 2)))
           - bd[0] * (ad[1] * (cd[0] ** 2 + cd[1] ** 2) - (cd[1] * (ad[0] ** 2 + ad[1] ** 2)))
           + (ad[0] ** 2 + ad[1] ** 2) * (bd[1] * cd[0] - bd[0] * cd[1]))   # 沿第一行展开
    return det > 0

print(in_circle(A, B, C, (1.0, 1.0)))    # 圆内的点
print(in_circle(A, B, C, (5.0, 5.0)))    # 圆外的点
```

输出 `True` 与 `False`。$(1,1)$ 落在外接圆内（圆心 $(2,2)$、半径 $\sqrt8\approx2.83$，它到圆心只有 $\sqrt2\approx1.41$），$(5,5)$ 在外面（距离 $\sqrt{18}\approx4.24$）。**这个判据就是 Delaunay 的身份证**：算法不断检查"某点是否落在邻三角形的外接圆里"，是就翻边（flip）——把对角线换掉，直到所有三角形都通过检查。这正是第 43 章"局部调整直到全局最优"的又一个实例。

## 6. 常见误区

:::warning[常见误区]

**误区一**："凸包上的点越多越好。" 其实凸包是**最小的**凸集，点越多说明你的点集越接近圆形，而不是算法越强。极端情形（所有点共圆）下所有点都在凸包上，这是点的性质，不是算法的问题。

**误区二**："Voronoi 边界就是连接两个站点的线段。" 其实**是那条线段的中垂线**，不是线段本身。连线是"最近的两个站点之间的债"，中垂线才是"讨债的边界"。一维时它退化成中点，二维时它是一条直线，三维时它是一张平面。

**误区三**："Delaunay 三角剖分是唯一的，随便写个算法结果都一样。" 其实当四个点共圆时（例如矩形四角），对角线有两种选法、两条都合法——**退化情形下 Delaunay 不唯一**。工程实现要用确定性的打破平局规则（例如按点编号）保证同样输入给同样输出，否则同一份数据在两次运行中得到不同网格。

:::

**练习 2**：点集 $(0,0),(4,0),(4,4),(0,4),(2,2)$ 的凸包是哪几个点？$(2,2)$ 在不在凸包上？

<details>
<summary>点开查看逐步解答</summary>

1. 四个角点 $(0,0),(4,0),(4,4),(0,4)$ 围成一个正方形，任意一条边所在直线都把其余点挡在内侧——它们是凸包的顶点；
2. 检查 $(2,2)$：它在正方形内部（左右上下都在范围内），不可能出现在凸包边界上；
3. 用叉积复核：$\mathrm{cross}((0,0),(4,0),(2,2))=(4)(2)-(0)(2)=8>0$，$\mathrm{cross}((4,0),(4,4),(2,2))=(0)(2)-(4)(-2)=8>0$——对四条边都同侧，确认在内部；
4. 为什么这个情形要单独提：**正方形四角共圆**（外接圆就是那个圆），这正是上一节误区三说的退化情形——对角线有两种等价的取法，Delaunay 不唯一。

</details>

**练习 3**：一维上三个站点 $a=-2$、$b=2$、$c=6$。三个 Voronoi 单元的分界点是哪两个？

<details>
<summary>点开查看逐步解答</summary>

1. $a$ 与 $b$ 的中点是 $0$，$b$ 与 $c$ 的中点是 $4$；
2. 三段辖区分别是 $(-\infty,0)\to a$、$(0,4)\to b$、$(4,+\infty)\to c$；
3. 注意 $a$ 与 $c$ 的中点是 $2$，但它不是分界点——因为 $x=2$ 离 $b$ 更近（距离 $0$）。**Voronoi 分界只在"相邻"站点之间产生**，非相邻站点的中垂线可能整条都在别人的辖区里；
4. 这正是"最近邻"检索的几何底子：给定查询点，"谁是最近站点"的答案由一个分区函数直接给出——**第 48 章的近似最近邻索引（IVF、HNSW）本质上就是在高维里学着逼近这个分区**（见[最近邻检索](../48-embeddings-geometry/30-nearest-neighbor.md)）。

</details>

## 8. 选读：从 $O(n^2)$ 到 $O(n\log n)$

<details>
<summary>选读 · 分治、翻边与旋转卡壳</summary>

- **分治凸包**：把点集按 $x$ 一分为二，各自求凸包，再合并两条"上切线/下切线"。合并只需线性时间，于是 $T(n)=2T(n/2)+O(n)=O(n\log n)$——和归并排序同一个套路。Andrew 扫描（本课代码）换个角度达到同样的界，实现更短。
- **Delaunay 的翻边法**：先随便三角剖分，再反复检查每个三角形的空圆性质，不满足就翻对角线（flip）。翻边会单调地增大最小角，因此必然终止；用随机增量插入（Bowyer–Watson）可以做到期望 $O(n\log n)$。
- **旋转卡壳**：在凸包上同时转两条平行切线，就能一次扫出直径、最小外接矩形、最小宽度——全部线性时间。它是 43 章"几何量沿边界单调变化"这一思想的漂亮应用。
- **出口两条**：机器人路径规划先在障碍物顶点上造**可视图**（每个顶点间只要连线不穿障碍就连一条边），再用最短路算法求路线（见[规划：A* 与可视图](../65-robotics-motion/30-planning-astar.md)）；高维里 Voronoi 单元不再便宜（单元数按维数指数增长），于是检索改用近似索引——**几何给出精确答案的形状，工程在其中挑性价比**。

</details>
