# 曲面细分选讲：递归中点的威力

## 1. 从一个场景开始

上一课你已经会用 de Casteljau"套娃"求曲线上的点。现在把镜头拉远看整个流程：游戏引擎里一个光滑的角色曲面，最终都要被切成成千上万个小三角形交给显卡。**从一条光滑曲线到一堆碎小的多边形**，中间发生了什么？

答案出奇地朴素：把一条 Bezier 曲线**从中点切成两条更简单的 Bezier 曲线**，再对每条继续切，切到足够细，直接用控制多边形代替曲线——肉眼已经分不出差别。这一课（选讲）只要求你拿走一个动作：**递归中点**。

## 2. 直觉解释

de Casteljau 过程在 $t=0.5$ 时有一层特别漂亮的结构：每一步都取**中点**。取完之后，把每层的"左半边点"收集起来，恰好构成一条新 Bezier 曲线的控制点；"右半边点"构成另一条。

```text
原曲线：P0 ─── P1 ─── P2 ─── P3        （4 个控制点）

t=0.5 切一刀：
  左半：P0, A0, B0, C    （4 个控制点，形状 = 原曲线的前半段）
  右半：C, B1, A2, P3    （4 个控制点，形状 = 原曲线的后半段）
```

关键性质有两条：

1. **精确**：左右两段合起来与原曲线**完全重合**，这不是近似，是恒等变形；
2. **收敛**：每切一层，控制点都更"贴着曲线"。切五六层后，控制多边形与曲线的差异小于一个像素——这时直接画折线即可。

这就是"细分"（subdivision）的本名：不是逼近算法，而是一刀一刀**精确定义**曲线的过程。

## 3. 正式定义

三次 Bezier 曲线 $B(t)$（控制点 $P_0P_1P_2P_3$）在 $t=\frac12$ 处的分割：

```text
第一层（相邻取中点）：
  A0 = (P0 + P1) / 2
  A1 = (P1 + P2) / 2
  A2 = (P2 + P3) / 2
第二层：
  B0 = (A0 + A1) / 2
  B1 = (A1 + A2) / 2
第三层：
  C  = (B0 + B1) / 2          ← 曲线上的点 B(0.5)
左半控制点：[P0, A0, B0, C]
右半控制点：[C, B1, A2, P3]
```

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $A_i$ | 一层中点 | 相邻控制点的中点，共 3 个 |
| $B_i$ | 二层中点 | 一层结果的相邻中点，共 2 个 |
| $C$ | 曲线点 | $B(0.5)$，也是左右两段的公共端点 |
| 细分深度 | 递归层数 | 每深一层曲线段数翻倍、控制点更贴近曲线 |

一般 $t$（不必是 $\frac12$）时把"中点"换成"按 $t:(1-t)$ 分点"，公式照搬。

## 4. 分步例题

**例 1**：对上一课的曲线 $P_0=(0,0)$、$P_1=(0,2)$、$P_2=(2,2)$、$P_3=(2,0)$ 在 $t=0.5$ 分割。

1. 一层：$A_0=(0,1)$、$A_1=(1,2)$、$A_2=(2,1)$；
2. 二层：$B_0=(0.5,1.5)$、$B_1=(1.5,1.5)$；
3. 三层：$C=(1.0,1.5)$（与上一课 $B(0.5)=[1.0,1.5]$ 一致，互相印证）；
4. 左半控制点：$[(0,0),(0,1),(0.5,1.5),(1.0,1.5)]$；右半：$[(1.0,1.5),(1.5,1.5),(2,1),(2,0)]$。

**例 2**：数一数账。切 1 层得 2 段，切 2 层得 4 段，切 $n$ 层得 $2^n$ 段。

1. 深度 5 时已有 32 段折线；
2. 每段的最大偏差随深度**平方**缩小（控制点"贴曲线"的速度是二次的）；
3. 所以深度 5–6 就足以骗过眼睛——字体的轮廓渲染（TrueType）正是这套流程在每秒钟几百万次地跑。

## 5. 动手实验

### 实验 1：看骨架动，理解切分

```viz

```

把 t 滑块停在 0.5，彩色杆件显示的三层取点正是例 1 的 $A\to B\to C$。拖动任意控制点，分割结果实时重算——左层各点永远是"相邻两点按 t 分"。

### 实验 2：亲手分割并递归两层

```python title="t=0.5 分割一次，再对左半段分割一次"
def subdiv(points):                    # 在 t=0.5 分割一次，返回左右两组控制点
    left = [points[0]]
    right = [points[-1]]
    cur = points
    while len(cur) > 1:                # 每层：相邻取中点，直到只剩 1 个点
        nxt = []
        for i in range(len(cur) - 1):
            nxt.append([(cur[i][0] + cur[i + 1][0]) / 2,
                        (cur[i][1] + cur[i + 1][1]) / 2])
        left.append(nxt[0])            # 每层第一个中点归左段
        right.append(nxt[-1])          # 每层最后一个中点归右段（倒序收）
        cur = nxt
    right = right[::-1]                # 右段要翻转方向：从切点指向原终点
    return left, right

P = [[0.0, 0.0], [0.0, 2.0], [2.0, 2.0], [2.0, 0.0]]
L, R = subdiv(P)
print(L)
print(R)

L2, R2 = subdiv(L)                     # 再把左半段切一刀
print(len(L2), len(R2))                # 两条新段各 4 个控制点
print(R2[1])                           # 新切点 = 左半段的中点 B(0.25)
```

输出左半 `[(0.0, 0.0), (0.0, 1.0), (0.5, 1.5), (1.0, 1.5)]`、右半 `[(1.0, 1.5), (1.5, 1.5), (2.0, 1.0), (2.0, 0.0)]`；再切一刀后两条新段各 4 个控制点（`4 4`），`R2[1]` 读数 `[0.5, 1.375]` 是右段第二个控制点（层 1 中点按倒序收集的位置）。原曲线变成三段，每段都是一次干净的 Bezier——**递归中点没有引入任何误差，段数却按 2 的幂增长**。

### 实验 3：数像素级收敛

```python title="控制多边形离曲线有多远：随深度平方缩小"
P = [[0.0, 0.0], [0.0, 2.0], [2.0, 2.0], [2.0, 0.0]]

def bez(points, t):                    # de Casteljau 求曲线上一点
    cur = [p[:] for p in points]
    while len(cur) > 1:
        nxt = []
        for i in range(len(cur) - 1):
            nxt.append([cur[i][0] + (cur[i + 1][0] - cur[i][0]) * t,
                        cur[i][1] + (cur[i + 1][1] - cur[i][1]) * t])
        cur = nxt
    return cur[0]

def mid(a, b):
    return [(a[0] + b[0]) / 2, (a[1] + b[1]) / 2]

def subdiv_half(points):               # t=0.5 分割，返回左半控制点
    left = [points[0]]
    cur = points
    while len(cur) > 1:
        nxt = []
        for i in range(len(cur) - 1):
            nxt.append(mid(cur[i], cur[i + 1]))
        left.append(nxt[0])
        cur = nxt
    return left

def max_dev(points):                   # 中间控制点到曲线的最短距离（粗采样）
    dev = 0.0
    for i in range(1, len(points) - 1):
        best = 9.9
        for k in range(41):
            b = bez(points, k / 40)
            d = ((b[0] - points[i][0]) ** 2 + (b[1] - points[i][1]) ** 2) ** 0.5
            if d < best:
                best = d
        if best > dev:
            dev = best
    return dev

print(round(max_dev(P), 3))            # 原曲线：控制点离曲线最远多远
L = subdiv_half(P)
print(round(max_dev(L), 3))            # 切一刀后的左半段
L2 = subdiv_half(L)
print(round(max_dev(L2), 3))           # 再切一刀
```

输出 `0.845`、`0.204`、`0.048`。每细分一层，偏差大约缩到四分之一——**二次收敛**。照这个速度，切到第五层偏差已小于 0.003：以像素为单位早就不可能分辨了。

```python
P = [[0.0, 0.0], [0.0, 2.0], [2.0, 2.0], [2.0, 0.0]]
t = 0.5

def lerp(a, b):
    return [a[0] + (b[0] - a[0]) * t, a[1] + (b[1] - a[1]) * t]

A = [lerp(P[0], P[1]), lerp(P[1], P[2]), lerp(P[2], P[3])]
B = [lerp(A[0], A[1]), lerp(A[1], A[2])]
C = lerp(B[0], B[1])
left = [P[0], A[0], B[0], C]
print(left)    # [(0.0, 0.0), (0.0, 1.0), (0.5, 1.5), (1.0, 1.5)]
print(C)       # [1.0, 1.5]
```

```text
层1：A0=(0,1)  A1=(1,2)  A2=(2,1)
层2：B0=(0.5,1.5)  B1=(1.5,1.5)
层3：C=(1.0,1.5)
左段 = P0, A0, B0, C     （沿"每次都靠左"的路径收点）
右段 = C, B1, A2, P3     （沿"每次都靠右"）
```

左段收 $A_0$ 不是 $A_1$：三次"靠左"选择对应曲线的 $t\in[0,\,0.5]$ 那一半。拿错层的点，得到的折线整体偏移——正是初始代码的错法（$t$ 用了 0.5、点却按靠中收）。

</details>

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为分割是"用折线近似曲线"。分割是**恒等变形**：左右两段 Bezier 合起来与原曲线逐点重合。取多少层只是"什么时候停止"的工程决定，不引入误差。

**误区二**：你以为递归可以一直切下去。每切一层段数翻倍，深度 20 就是百万段——深度上限必须设（按屏幕误差或固定层数），否则内存先投降。

**误区三**：你以为只有 Bezier 能细分。细分的本质是"对控制点做局部平均"，Chaikin 算法、Catmull-Clark 曲面、Loop 曲面全是同一思想在不同维度的翻版——这一课的"递归中点"是整个细分曲面家族的种子。

:::

## 9. 选读：从曲线到曲面

<details>
<summary>选读 · 同一个动作怎么长成细分曲面</summary>

曲线的分割是一维动作：每层把"相邻两点取平均"。把它推广到网格曲面：对**每个面、每条边、每个点**分别做局部加权平均，得到一层更密的新网格——Loop 细分（三角网格）与 Catmull-Clark 细分（四边网格）就是这么定义的。

两者的共同结构：

1. **细化规则**（每层怎么加点）：边点 = 两端点与相邻两面的加权平均；
2. **平滑规则**（老点怎么挪）：每个老点向邻居的平均位置收缩一点；
3. **极限性质**：无限细分后收敛到一张光滑曲面（除少数"奇异点"外处处有确定的切平面）。

电影动画与高清建模里那些"随便雕刻都光滑"的模型，底层全是这套循环。它与本课唯一的区别是平均的权重表——思想完全一致：**用最朴素的局部平均，定义出全局光滑的几何**。

</details>
