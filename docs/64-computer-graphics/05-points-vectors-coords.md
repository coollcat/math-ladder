# 点、向量与屏幕坐标

## 1. 从一个场景开始

屏幕上那个"小房子"游戏模型，在文件里其实就是一串数字：`[[0,0],[4,0],[4,3],[2.6,3],[2.6,4.6],[0,3]]`。每个括号对是一个**顶点**（vertex），整个模型就是把顶点按顺序连起来的折线。

第 11 章学过的向量运算在这里全部要用，但多了两件图形学特有的讲究：**点和向量长得一模一样，语义却不同**；**屏幕的 y 轴朝下**，和数学课本相反。这两件事不分清，后面每一课都会摔跟头。

## 2. 直觉解释

**点回答"在哪里"，向量回答"往哪走、走多远"。**

- 点 $(3, 1)$：空间里一个位置，没有方向、没有长度。
- 向量 $(3, 1)$：一个位移——"向右 3、向下 1"，有方向、有长度。

两者都写成两个数，但运算含义不同：

```text
点 + 向量 = 点     （从位置 A 走一步，到达位置 B）✔
点 + 点   = ？     （"北京 + 上海"是什么？没有意义）✘
点 − 点   = 向量   （两点之间的位移，这是合法的）✔
```

第 11 章的点积在本章的图形学角色：**量夹角**。两个向量的点积大于零说明夹角是锐角——这一个事实撑起了第 50 课的整个光照模型。

## 3. 正式定义

设点 $P=(p_x,p_y)$、向量 $\vec v=(v_x,v_y)$：

| 运算 | 结果 | 几何含义 |
| --- | --- | --- |
| $P+\vec v$ | 点 | 从 $P$ 出发走 $\vec v$ 到达的新位置 |
| $P-Q$ | 向量 | 从 $Q$ 指向 $P$ 的位移 |
| $\vec u\cdot\vec v$ | 数 | $u_xv_x+u_yv_y$，量夹角：同向为正、垂直为零、反向为负 |
| $\|\vec v\|=\sqrt{\vec v\cdot\vec v}$ | 数 | 向量的模长（长度） |

**屏幕坐标系**：图形学的画布原点在左上角，$x$ 向右增、$y$ **向下**增。数学里的"逆时针 90 度旋转"在屏幕上看是顺时针——所有角度直觉都要过一遍这道换算。

## 4. 分步例题

**例 1**：点 $P=(1,1)$ 沿向量 $\vec v=(3,2)$ 移动，落在哪里？

1. $P+\vec v=(1+3,\ 1+2)=(4,3)$——点加向量还是点；

**例 2**：$\vec a=(2,1)$、$\vec b=(1,3)$。

1. $\vec a+\vec b=(3,4)$；
2. 点积 $\vec a\cdot\vec b=2\times1+1\times3=5$；
3. 模长 $\|\vec a\|=\sqrt{2^2+1^2}=\sqrt5\approx2.24$；
4. 点积为正 → 夹角是锐角（$\cos\theta=5/(2.24\times3.16)\approx0.707$，$\theta\approx45°$）。

### 实验 2：顶点表的算术

```python title="顶点的加法、点积与模长"
import math

a = [2, 1]       # 向量 a
b = [1, 3]       # 向量 b

s = [a[0] + b[0], a[1] + b[1]]            # 逐分量相加
dot = a[0] * b[0] + a[1] * b[1]           # 点积：对应分量相乘再求和
norm = math.sqrt(a[0] ** 2 + a[1] ** 2)   # ** 是幂运算；模长 = sqrt(x^2 + y^2)
print(s)
print(dot)
print(round(norm, 2))

# 点积为零的检验：换一个与 a 垂直的向量
perp = [-a[1], a[0]]                      # 垂直向量诀窍：交换分量、其中一个变号
print(perp, a[0] * perp[0] + a[1] * perp[1])
```

输出 `[3, 4]`、`5`、`2.24`、`[-1, 2] 0`。最后一行的 0 是垂直的判据——"交换分量、变一个号"这个构造法在求法向量时天天用（第 15 课的叉积是它的三维升级）。

```text
|a|   = sqrt(4+1) = sqrt(5) = 2.24
```

"点积是数不是向量"这一条写进了下面的误区清单——它太常见了，漏掉求和一步，点积就退化成了逐元素乘法。

## 7. 常见误区

:::warning[常见误区]

**误区一**：你以为点和向量是同一种东西。平移一个点，它挪位置；平移一个向量，它纹丝不动（位移不随起点变）。第 10 课的齐次坐标正是用"多写一个 1 或 0"把这两者的区别交给矩阵去管。

**误区二**：你以为点积的结果还是向量。点积是**一个数**（所以也叫标量积）；逐元素相乘得到的列表不是点积。

**误区三**：你以为屏幕坐标和数学坐标一样。屏幕 $y$ 轴向下，逆时针/顺时针全部颠倒，"往上移动"是 $y$ 减小。凡是从数学直觉搬过来的角度判断，都要先过这道检查。

:::

## 9. 选读：为什么屏幕 y 轴朝下

<details>
<summary>选读 · 历史惯性的一笔账</summary>

CRT 显示器的电子束从左上角开始逐行向右下扫描（显像管的偏转电路天然如此），图像内存的第 0 行对应屏幕最上面一行。于是"行号向下增长"成了图形内存布局的事实标准，坐标系也就跟着 $y$ 向下了。

OpenGL 选择把 $y$ 向上的数学坐标系暴露给开发者，在最后一步上传显存时再翻转；DirectX 与绝大多数 2D 库则直接用 $y$ 向下。两套约定并存的结果是：**纹理上传方向不对、图片倒置、旋转方向反了**是图形学新手的三大经典事故，根源都在这里。

工程对策很简单：画一张带不对称图案的测试图（例如字母 F——这也是本章组件内置 `letter-f` 模型的原因），任何方向性错误都会立刻现形。

</details>
