# 动态范围压缩与限幅

## 1. 从一个场景开始

录一期播客：嘉宾说话细声细气，笑起来却差点炸麦。播放时你要么把音量开大才能听清轻声部分、笑声一来又被震一下，要么调小音量、笑声安全了、人话却听不见。**动态范围太大**，收听设备与环境都伺候不起。

压缩器就是为这个场景生的：**轻的部分少抬举，响的部分往下按**——像一个反应极快的自动音量手。它不创造新声音（滤波管频率、混响管空间），只改一件事：**电平随时间的形状**。这与第 70 课的 ADSR 是同一个思想的两处落地——ADSR 捏的是每个音符"起音—衰减—延音—释放"的骨架，压缩器捏的是整段声音"大—小"的起伏。

## 2. 直觉解释

第 30 课讲过：人耳感知响度走的是对数刻度（分贝），所以压缩器的全部行为画在**分贝域**里，只是一条折线——

- 阈值以下：输入多大，输出就多大（1:1，不干预）；
- 阈值以上：斜率变成 $1/R$——**超出阈值的部分，每超出 R 分贝，只放行 1 分贝**。

分贝域里压缩原来是"斜率除法"，这就是第 03 章对数刻度的红利：乘除法被对数拉平成加减与斜率，一条折线就能描述全部行为。

"压多少"之外还有"多快压、多快放"：**启动时间 attack** 决定电平冲过阈值后多快开始按；**释放时间 release** 决定回落多快松手。快 attack 抹掉冲击感，慢 attack 保住"punch"——拍鼓的人对此感受最深。

## 3. 正式定义

**静态压缩曲线**（$x, y$ 均为 dBFS，$T$ 为阈值，$R$ 为压缩比，$R \ge 1$）：

$$y = \begin{cases} x & x \le T \\[4pt] T + \dfrac{x - T}{R} & x > T \end{cases} \qquad \text{增益衰减} \quad GR = x - y = \left(1 - \frac{1}{R}\right)(x - T)$$

| 参数 | 名字 | 典型值 | 管什么 |
| --- | --- | --- | --- |
| $T$ | 阈值 threshold | −30 ~ −6 dBFS | 多大算"响" |
| $R$ | 压缩比 ratio | 2:1 ~ 8:1 | 超出部分按几分之一放行 |
| knee | 拐点宽度 | 0 ~ 12 dB | 硬拐点直上直下，软拐点圆滑过渡 |
| attack | 启动时间 | 1 ~ 100 ms | 瞬态保不保 |
| release | 释放时间 | 50 ~ 500 ms | 松手快慢，太短会"抽吸" |
| makeup | 补偿增益 | 0 ~ 12 dB | 压完整体抬回响度 |

**限幅器（limiter）**：$R \ge 20:1$ 的极端压缩——曲线在阈值处近乎掰成直角，输出**永不**越过天花板。广播与流媒体用它当"防爆墙"。压缩比 $R = 1$ 则是不压的原样直线：**1 到 20 之间滑过去，就是从"温柔的抚平"到"无情的限高"**。

## 4. 分步例题

**例**：播客人声轨，$T = -20$ dBFS、$R = 3:1$。一段话的峰值冲到 $-8$ dBFS。问输出峰值与增益衰减。

1. 超出量：$x - T = -8 - (-20) = 12$ dB；
2. 放行：$12 / R = 4$ dB；
3. 输出：$y = T + 4 = -16$ dBFS；
4. 增益衰减：$GR = x - y = -8 - (-16) = 8$ dB（验算：$12 \times (1 - 1/3) = 8$ ✓）；
5. 解读：原本 12 dB 的"冒尖"被削成 4 dB，峰值动态从说话段与笑声段之间的 12 dB 间距压到 4 dB——配完 makeup 抬回来，轻声部分不用再把音量开到极限了。

## 5. 动手实验

### 实验 1（lab）：把压缩比拖到头，它就成了限幅器

```lab
{
  "type": "compressor-lab",
  "title": "把右端的方块往上拖，压缩比一路推到 20:1，听动态被拍平",
  "threshold": -30,
  "ratio": 8,
  "depth": 15
}
```

左上那条"输入 dB → 输出 dB"曲线就是压缩器的全部人格：圆点是阈值（横向拖它改 $T$），方块是压缩比（纵向拖它改 $R$），菱形是拐点宽度。曲线上的大圆点是当前工作点。做三件事：

- 把 $R$ 一路拖到 20:1——曲线在阈值处折成直角，这正是限幅器的形状；听感上"大起大落"消失；
- 把 attack 拖短——输入每个瞬态被立刻按住，声音变"钝"；拖长 attack——瞬态先冲出去再被拉回，声音保留"punch"；
- 把 depth 调大（脉动更深）——右下的增益衰减轨迹荡得更深，release 太短时能看见那条轨迹在"抽搐"，对应耳朵听到的抽吸感。

### 实验 2（python）：静态曲线查表

```python title="压缩器的输入输出对照表"
T = -20.0    # 阈值（dBFS）
R = 3.0      # 压缩比

for x in [-40.0, -30.0, -24.0, -20.0, -14.0, -8.0, -2.0]:
    over = max(0.0, x - T)      # 超出阈值的部分
    gr = over * (1 - 1 / R)     # 增益衰减：超出量被吃掉 (1-1/R)（over=0 时 gr=0）
    y = x - gr                  # 阈值以下原样放行（y=x）；以上 = T + (x-T)/R
    print(f"in {x:>5.1f} dB -> out {y:>6.1f} dB   GR {gr:>4.1f} dB")
```

前四行 GR 全是 0.0（阈值以下不干预），后三行 GR 依次 4.0、8.0、12.0 dB——**超出量每涨 6 dB，输出只涨 2 dB**（$6 \times (1 - 1/3)$），这正是 3:1 的斜率 $1/3$。拿这张表对着 lab 的曲线读，每个工作点都对得上。

### 快问快答

```quiz
把压缩比一路开到 20:1 甚至无限大，这台机器变成了什么？
- 静音器
- 限幅器：输出绝不越过阈值天花板 [*]
- 更温和的压缩器
? R=20:1 时超出 20 dB 只放行 1 dB，曲线在阈值处几乎折成直角；R 无限大就是理想限幅器。名字也换了叫法：压缩管"形状"，限幅管"底线"。
```

::::warning[常见误区]

**误区一**："压缩器就是把声音调小。"
你以为它是音量旋钮的自动版——它改的是**按电平分段的比例**：轻的动都不动，响的才被按比例削减，整体响度还要靠 makeup 抬回来。"压"字容易让人只看见"小"，其实压缩器最常见的效果反而是**听起来更响**（平均电平上去了）。

**误区二**："attack 越快越好，干净利落。"
你以为反应快总是美德——attack 1 ms 会把鼓槌敲下去的瞬态整个抹平，声音立刻"钝掉"。军鼓的爆发感恰恰活在最初几毫秒里。想要 punch：慢 attack（10–30 ms）让瞬态先过去，再按住余下的身体。

**误区三**："上无限个限幅器，就能把响度做到天上去。"
你以为动态可以无限牺牲——响度战争的代价是瞬态被磨平、动态被压成一条直线，听众只剩"响"而没有"力"。流媒体平台已按响度归一（约 −14 LUFS），**压得比平台目标更狠不会更响，只会更差**。

::::

## 6. 练习

**练习 1**：$T = -20$ dBFS、$R = 3:1$，输入峰值 $-8$ dBFS。求输出峰值（保留 1 位小数）。下面的代码算出了 +16 dB，越算越响，方向反了：

```exercise
# @title: 练习：超出部分要除以压缩比
# @check: -16.0
# @hint: y = T + 超出量/R。超出量要"按比例放行"（除以 R），不是再乘上去
threshold = -20.0    # 阈值（dBFS）
ratio = 3.0          # 压缩比
x_in = -8.0          # 输入电平（dBFS）

over = x_in - threshold            # 超出阈值的部分（dB）
out = threshold + over * ratio     # ← 问题在这：放行的是 over/ratio，不是 over*ratio
print(f"{out:.1f}")
```

修正后：$over = 12$ dB，$out = -20 + 12/3 = -16.0$ dBFS，增益衰减 8 dB。再校验一遍逻辑：输入 −8 比输出 −16 高 8 dB，压缩器在阈值以上"吃掉"了三分之二的超出量——斜率 $1/R = 1/3$，与第 03 章对数刻度上的斜率完全一致。

**练习 2**：接上题。若想让压缩后的峰值回到压缩前的 −8 dBFS，makeup 要加多少？这时轻声部分（原来 −40 dBFS、不触发压缩）被抬到了多少？

<details>
<summary>点开查看逐步解答</summary>

1. 峰值从 −16 回到 −8 需要 makeup = +8 dB；
2. 轻声 −40 dBFS 在阈值以下、压缩量为 0，makeup 照单全收：$-40 + 8 = -32$ dBFS；
3. 对比动态范围：压缩前峰值与轻声差 $-8 - (-40) = 32$ dB，压缩加 makeup 后差 $-8 - (-32) = 24$ dB；
4. 这就是压缩器的真实用途：**抬整体响度的同时缩小轻重间距**——32 dB 缩到 24 dB，轻声被"托"上来了，峰值却没超回去；
5. 顺手呼应第 70 课：ADSR 用四段时间捏单音的形状，压缩器用 T/R/attack/release 捏整轨的形状——"时间形状控制"是音频工程的一族概念，不是零散技巧。

</details>

## 7. 选读：侧链——让一个信号去压另一个信号

<details>
<summary>选读 · ducking 与广播的秘密</summary>

压缩器默认"自己测自己的输入电平"。若把检测口接到**另一路信号**上，就有了侧链（sidechain）：广播里主持一开口，背景音乐自动缩下去——音乐压缩器的检测口接的是人声轨，人声触发、音乐让路，行话叫 **ducking**（闪避）。电音里的"抽吸感"底鼓则是反着玩：让底鼓触发垫底铺底信号的压缩，每拍一次沉一下，节奏感是压出来的。

再进一步还有上压缩（upward compression）：把阈值以下的轻声**放大**而不是把响声压小，用于抢救气声台词。静态曲线族谱：往下压（本课）、往上抬、往下扩（noise gate，低于阈值直接关门）——都是"分贝域分段线性"这一个模型的变体。第 61 章讲过 FIR/IIR 的频域形状族，这里你看到的是电平域形状族，建模思路同源。

</details>
