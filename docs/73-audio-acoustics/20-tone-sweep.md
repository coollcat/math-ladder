# 频率、音高与八度

## 1. 从一个场景开始

合唱团排练，指挥说「各声部一起唱 A」。女高音唱 880 Hz，男低音唱 220 Hz，中间还有 440 的——四个声部频率各不相同，你听起来却是**同一个音**，而且和谐得毫无违和。

频率明明差了 4 倍，凭什么算「同一个音」？答案藏在耳朵的工作方式里：**它感知的不是频率的差，而是频率的比**。

## 2. 直觉解释

先做个思想实验。220 → 440（加 220），和 440 → 880（加 440），两次的**加法差**不同；但两次都是**翻倍**，你听到的音高跨距一模一样——都叫「高一个八度」。这说明音高这把尺子上的刻度，是按**乘法**排的：

- 频率 ×2 → 音高升一个八度；
- 频率 ×4 → 升两个八度；
- 频率 ×2^(1/12) → 升一个半音（钢琴相邻两键）。

「越加越多、感觉却一样」的刻度，你在第 03 章见过一次：对数。频率每翻一倍音高前进等距一步——**音高正比于频率的对数**。这也解释了为什么频谱图（第 50 课）、分贝（下一课）都爱用对数轴：对数轴是跟着耳朵的感觉长的。

钢琴一个八度 12 个键，就是把这「一步八度」**等比切成 12 份**，每份乘 $\sqrt[12]{2} \approx 1.0595$。相邻两键听起来跨距相等——尽管它们的频率差并不相等。

## 3. 正式定义

**八度等价**：频率比为 $2:1$ 的两个音，听感上属于「同一个音的上下两层」，音乐里记作高/低一个八度。

**十二平均律**：把一个八度按**等比**切成 12 个半音，相邻半音的频率比恒为

$$r = 2^{1/12} \approx 1.05946$$

从标准音 A4 = 440 Hz 出发，向上 $k$ 个半音的频率是

$$f = 440 \cdot 2^{k/12}$$

反过来，知道频率也能算它在音阶里的位置（MIDI 编号就是这么定义的）：

$$k = 12 \cdot \log_2\!\left(\frac{f}{440}\right)$$

| 量 | 名字 | 含义 |
| --- | --- | --- |
| $f$ | 频率 | 物理量，单位 Hz |
| 音高 | 感觉量 | 正比于 $\log_2 f$，耳朵的输出 |
| 八度 | ×2 | 频率翻倍，音名相同、层位加一 |
| 半音 | ×$2^{1/12}$ | 平均律的最小台阶，钢琴相邻两键 |
| A4 = 440 Hz | 标准音 | 全世界定音的公共锚点 |

## 4. 分步例题

**例**：从 A4 = 440 Hz 出发，求纯五度音（上方 7 个半音）E5 的频率。

1. **查台阶数**：A → A♯ → B → C → C♯ → D → D♯ → E，共 7 个半音；
2. **套等比公式**：$f = 440 \times 2^{7/12}$；
3. **算指数**：$2^{7/12} \approx 1.49831$；
4. **得出结果**：$440 \times 1.49831 \approx 659.26$ Hz。

注意每一步都是**乘**：如果错用加法把 440 均摊成 $440 + 440 \times \frac{7}{12} = 696.7$ Hz，得到的音就明显偏高——半音是等比台阶，不是等差台阶。

再验证一下八度：从 E5 再上 5 个半音到 A5，$659.26 \times 2^{5/12} \approx 880$ Hz——恰好是 A4 的 2 倍。12 个半音连乘 $\left(2^{1/12}\right)^{12} = 2$，严丝合缝。

## 5. 动手实验

### 实验 1（lab）：沿对数频率轴扫一遍，亲耳数台阶

```lab
{
  "type": "tone-sweep",
  "title": "沿频率轴拖动游标：听音高怎么按八度爬楼梯（台阶画在每次翻倍处）",
  "freq": 220
}
```

下方频率轴是**对数轴**——同样宽的一格，在 100 Hz 处代表几十赫兹、在 5000 Hz 处代表上千赫兹，但**听感跨距相同**。注意看两样东西：

- 音高台阶（八度）在轴上**等宽等高**：110、220、440、880、1760……每次翻倍，视觉上却像匀速爬楼——这就是「音高是对数的」的直接展示；
- 上方那个 20 ms 的小波形窗：频率爬得越高，窗里挤进的周期越多——220 Hz 时约 4.4 个周期，1760 Hz 时 35 个，周期 $T = 1/f$ 一目了然地变短。

慢慢拖、仔细听：每个八度台阶处，你会情不自禁地觉得「回到同一个音了」。

### 实验 2（python）：把一个八度的 12 个半音排出来

```python title="十二平均律：A4 到 A5 的全部半音"
import math  # 数学库（卷一已引入）

f0 = 440.0                    # 标准音 A4（Hz）
names = ["A4", "A#4", "B4", "C5", "C#5", "D5",
         "D#5", "E5", "F5", "F#5", "G5", "G#5", "A5"]
prev = None
for k, name in enumerate(names):
    f = f0 * 2 ** (k / 12)    # 上方 k 个半音：等比 ×2^(k/12)
    ratio = "" if prev is None else f"  相邻比 {f/prev:.5f}"
    print(f"{name:>4}  {f:8.2f} Hz{ratio}")
    prev = f
```

数一数输出：相邻比值清一色 1.05946——**等比数列**印在每两行之间。首尾两个数 440.00 与 880.00 之间恰好差 2 倍：12 个半音拼成一个完美八度。

顺带验证纯五度（第 4 节的例题）：

```python title="复核：A4 上方 7 个半音"
import math  # 数学库（卷一已引入）

f_e5 = 440.0 * 2 ** (7 / 12)
print(f"E5 = {f_e5:.2f} Hz")          # 659.26
print(f"E5 与 A4 之比 = {f_e5/440:.5f}")   # 1.49831，接近 3/2
```

比值 1.49831 与简单整数比 $3/2 = 1.5$ 只差千分之一——这就是纯五度听起来格外和谐的算术根源：**频率比越接近简单整数比，两个音越融合**（八度 2/1、纯五度 3/2、纯四度 4/3）。

### 快问快答

```quiz
一个音的频率变为原来的 4 倍，它的音高升高了几个八度？
- 4 个
- 2 个 [*]
- 1 个
? 每翻一倍升一个八度：4 = 2 的平方，所以升高 2 个八度。翻 3 倍就不是整八度了——只有 2 的整数次幂才落在台阶上。
```

::::warning[常见误区]

**误区一**：「音高和频率成正比，频率大几倍音就高几倍。」
你以为 2000 Hz 听起来「比 1000 Hz 高一倍」所以是线性——其实耳朵量的是 $\log_2$：1000 → 2000 与 2000 → 4000 才是等距。所有乐理的「距离」（八度、半音、音分）都定义在对数频率上。

**误区二**：「钢琴上相邻两键的频率差是相等的。」
你以为半音是等差台阶——低音区相邻两键差几赫兹，高音区差上百赫兹。相等的是**比值** $2^{1/12}$：频率是等比数列，频率差根本不均匀。

**误区三**：「440 Hz 和 441 Hz 听起来明显是两个音。」
你以为耳朵精确到 1 Hz——两者相差约 4 音分（1 音分 = 半音的百分之一），绝大多数人耳根本分不出。人耳对音高的分辨率大约 5～10 音分，调琴师还要靠「拍音」帮忙，不是靠绝对听感。

::::

**练习 1**：求 A4 = 440 Hz 上方 7 个半音（纯五度 E5）的频率，保留 2 位小数。这段代码把等比台阶错当成了等差：

```exercise
# @title: 练习：算纯五度的频率
# @check: 659.26
# @hint: 半音是等比台阶——上 k 个半音要乘 2 的 k/12 次方，不是把 k 平摊在频率上
f_a4 = 440.0    # 标准音 A4（Hz）
f_e5 = f_a4 * 7 / 12    # ← 问题在这：应该是乘 2 ** (7/12)
print(round(f_e5, 2))
```

**练习 2**：男低音唱 110 Hz、女高音唱 880 Hz。他们各唱的与标准音 A4 = 440 Hz 相距几个八度？

<details>
<summary>点开查看逐步解答</summary>

1. 看 440 → 110：$110/440 = 1/4 = 2^{-2}$，除以了 4，即**低两个八度**（A2）；
2. 看 440 → 880：$880/440 = 2$，翻了一倍，**高一个八度**（A5）；
3. 用对数式复核：$k = 12\log_2(110/440) = 12 \times (-2) = -24$ 个半音 = −2 八度；$k = 12\log_2 2 = 12$ 个半音 = +1 八度；
4. 三人频率比 $110:220:440:880 = 1:2:4:8$——全落在 2 的整数次幂上，所以听起来是「同一个音的一串楼层」，这正是合唱「八度叠唱」的算术骨架。

</details>

## 7. 选读：为什么翻倍听起来像「同一个音」

<details>
<summary>选读 · 八度等价的物理根源</summary>

八度等价不是文化约定，它有扎实的物理根基。大多数乐器的谐波（第 50 课的主角）是基频的**整数倍**：$f, 2f, 3f, 4f, \dots$。现在比较两个相隔八度的音：

- 低音的谐波列：$f,\ 2f,\ 3f,\ 4f,\ 5f,\ \dots$
- 高音的谐波列：$2f,\ 4f,\ 6f,\ \dots$

高音的每一条谐波都**恰好撞在低音谐波列的偶数项上**——两团频谱大面积重叠，听觉系统干脆把它们归成「同一族，差一层」。而频率比 1.87 的两个音（比如 440 对 823），谐波互相错开、打起「拍架」，听起来就是两个音。

顺带一提：把八度均分成 12 份后，纯五度（7 个半音）的比值 $2^{7/12} \approx 1.4983$ 与理想的 $3/2 = 1.5$ 差了约 0.11%——平均律是「让 12 个台阶都能循环使用」的妥协设计，每个音程都差一点，但差到耳朵不介意。这也是为什么同一架钢琴什么调都能弹，而更「纯」的纯律反而转个调就走音。

</details>
