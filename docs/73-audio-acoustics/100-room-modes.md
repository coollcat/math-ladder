# 共振与房间模式

## 1. 从一个场景开始

在两堵墙都是硬面的小房间里放低音，走到墙角，「嗡」地一下大得刺耳；退后半步，又弱了下去。换一首歌，嗡的音高还不太一样。设备没变、音量没变，变的是**你的位置**和**歌里的频率**。

上一课的均衡器在设备上挖坑，可这次的坑像是房间自己挖的。原因：**房间是一件乐器**。它有自己的一套固有频率，放音只要碰到其中一个，房间就跟着共振——22 章振动方程里的「本征模」，此刻正在你的卧室里现形。

## 2. 直觉解释

两面平行的硬墙之间，声波来回反射。当波长恰好「卡」进两墙之间——距离正好是半个波长的整数倍时，来回的波与反射的波**叠加成驻波**：某些位置永远振幅最大（波腹），某些位置纹丝不动（波节）。这与 22 章两端固定的弦是同一个数学：**边界条件挑出离散的固有频率**。

弦的固有频率是 $f_n = nv/2L$；房间沿长边方向也一样，声速换成本章的 $c = 343$ m/s：

$$f_n = \frac{n c}{2L}$$

5 米长的房间：$f_1 = 343/10 = 34.3$ Hz，然后 68.6、102.9……每一阶就是一个**轴向模式**。房子三维，于是模式由三个整数 $(n_x, n_y, n_z)$ 编号：一个非零是**轴向**（两面墙间），两个非零是**切向**（四面墙间），三个非零是**斜向**（六面墙间）——能量依次减弱，但频率栅格越来越密。

低频为什么最遭殃？频率低 → 模式稀疏 → 一根一根分得开，碰到哪根哪根嗡；频率高了 → 栅格密得连成一片，反而听不出单根模式。分界线叫**施罗德频率**。

## 3. 正式定义

**矩形房间的模态频率**：

$$f(n_x, n_y, n_z) = \frac{c}{2}\sqrt{\left(\frac{n_x}{L_x}\right)^2 + \left(\frac{n_y}{L_y}\right)^2 + \left(\frac{n_z}{L_z}\right)^2}$$

其中 $L_x, L_y, L_z$ 是三边长，$n_x, n_y, n_z$ 是非负整数（不全为零），$c \approx 343$ m/s（20 ℃ 空气）。

| 概念 | 定义 | 特点 |
| --- | --- | --- |
| 轴向模式 | 三个整数里只有一个非零 | 两面墙间来回反射，能量最强，最该治理 |
| 切向模式 | 恰有两个非零 | 绕四面墙，能量约为轴向的一半 |
| 斜向模式 | 三个都非零 | 六面墙斜穿，能量最弱 |
| 简并 | 两个模式频率几乎重合 | 方正房间大量简并，嗡上加嗡 |
| 施罗德频率 | $f_s \approx 2000\sqrt{T_{60}/V}$ | $T_{60}$ 混响时间、$V$ 房间体积；以下「一根一根」，以上连成混响 |

**治理的物理**：低频陷阱不是「吸走所有低音」，而是在波腹处（墙角、墙面）放厚吸声材料，把最扎眼的那几根模式的峰削平。音箱摆位同理：把低音单元挪离墙角，激励轴向模式的强度就下降——**治的是模式，不是频率**。

## 4. 分步例题

**例**：房间 $5.0 \times 4.0 \times 2.6$ m，混响时间 $T_{60} = 0.5$ s。求：(a) 长边前三个轴向模式；(b) 施罗德频率；(c) 这个房间该担心什么。

1. **轴向模式**：$f_n = n \times 343/(2 \times 5) = 34.3 n$，前三个是 **34.3、68.6、102.9 Hz**；
2. **施罗德频率**：体积 $V = 5 \times 4 \times 2.6 = 52$ m³，
$$f_s = 2000\sqrt{0.5/52} = 2000 \times 0.0981 \approx 196\ \text{Hz}$$
3. **结论**：196 Hz 以下、尤其是 34–103 Hz 这一段，模式一根一根数得清，低音会随位置大幅起伏——小房间听音的主要矛盾；196 Hz 以上模式密连成混响场，位置差异小，用上一课的均衡微调即可。

再看一个反面教材：如果把房间盖成 $5 \times 5 \times 2.6$，则 $(1,0,0)$ 与 $(0,1,0)$ 两个模式频率完全相同——**简并**。同频能量叠加，那一根嗡得比谁都狠。矩形好过正方形，长宽比错开是声学设计的第一条纪律。

左图是房间俯视图，红蓝格子是当前模式的声压分布（白线是节线）；右图是 300 Hz 以下的模态频率栅格，虚线是施罗德频率。做三件事：

- 鼠标掠过右图任一根竖线：选中那个 $(n_x,n_y,n_z)$，左图画出它的驻波形状——墙角永远是波腹；
- 把长边 Lx 从 5 m 拖到 7 m：低频栅格整体向左压缩，34.3 Hz 变成 24.5 Hz；
- 把房间拖成正方形 $5 \times 5$：数一数重合的竖线——简并出现了，这就是录音棚从不盖正方形房间的原因。

### 实验 2（python）：轴向模式的阶梯

```python title="5 米长边的轴向模式表"
c = 343.0      # 声速（m/s，20 ℃）
L = 5.0        # 长边（m）

for n in range(1, 6):
    f = c * n / (2 * L)      # 第 n 个轴向模式：半波长的整数倍卡进房间
    print(f"n={n}  f = {f} Hz")
```

五行输出：34.3、68.6、102.9、137.2、171.5 Hz——完美的等差阶梯，间隔恰是 34.3 Hz。把 `L` 换成 2.6（层高）再跑：第一根跳到 65.96 Hz——**层高越小，最低的模式越高**，这正是天花板低的房间低频相对干净的原因（麻烦全在长宽方向）。

::::warning[常见误区]

**误区一**："房间模式影响所有频率。"
你以为房间对全频段胡作非为——其实模式只在施罗德频率（本例约 196 Hz）以下「一根一根」作乱；以上模式密集到统计上连成均匀的混响场，位置差异消失。高频用均衡器调，低频要治模式，两套逻辑。

**误区二**："低频陷阱=把低音吸掉。"
你以为装了陷阱低音就没了——其实陷阱是放在波腹处的厚吸声体，目标是**削峰**：把 34.3 Hz 那根从「墙角震耳」削到「全屋均匀」。吸得过狠低音确实单薄，所以要按模式逐根对症。

**误区三**："换个好音箱就能解决。"
你以为低频嗡是设备问题——再贵的音箱也逃不过房间：只要强模式还在，听音位置就在替你「滤波」。摆位（人离墙、箱离墙）是免费的第一个手段，物理改造是第二个，器材排最后。

::::

## 6. 练习

**练习 1**：5 m 长边房间的最低轴向模式是多少赫兹？输出应为 `34.3`。这段代码把驻波的形状记错了：

```exercise
# @title: 练习：房间的最低「嗡嗡」频率
# @check: 34.3
# @hint: 两面硬墙间驻波的最低形态是「各半个波长」，即 L = λ/2 → f = c/(2L)，分母里那个 2 别丢。
c = 343.0      # 声速（m/s，20 ℃）
L = 5.0        # 房间长边（m）
f = c / L      # ← 问题在这：最低模是 λ = 2L，不是 λ = L
print(f)
```

**练习 2**：房间短边 4 m、层高 2.6 m。(a) 求短边的最低两个轴向模式；(b) 层高最低模式（约 65.96 Hz）与短边的哪一阶最接近？这说明挑房间尺寸时要注意什么？

<details>
<summary>点开查看逐步解答</summary>

1. 短边：$f_n = n \times 343/8$，前两个是 **42.875 Hz 与 85.75 Hz**；
2. 层高最低模式 65.96 Hz 落在短边一阶 42.875 与二阶 85.75 之间，都不算重合——$4/2.6 \approx 1.54$ 这个比例还算健康；
3. 但若层高恰是 2.5 m（最低模 68.6 Hz），就与长边二阶 68.6 Hz **完全简并**。挑尺寸的纪律：三边两两之比避开小整数比（1:1、1:2、2:3），经典推荐如 1.9 : 1.4 : 1 或 2.5 : 1.6 : 1。

</details>

## 7. 选读：施罗德频率是怎么算出来的

<details>
<summary>选读 · 从模式间隔到统计混响</summary>

低于 $f_s$ 时相邻模式的平均间隔大于半功率带宽（模式宽度由混响时间决定：$T_{60}$ 越长、阻尼越小，每根峰越尖），频率轴上能数清一根根峰；高于 $f_s$ 时模式密度（单位 Hz 内的模式个数）大到峰与峰互相重叠，统计上趋于均匀——混响场的定义。

施罗德 1954 年给出的判据是「三个模式挤进一根峰的宽度」，化简后就是 $f_s \approx 2000\sqrt{T_{60}/V}$。它解释了两件事：大音乐厅 $V$ 巨大，$f_s$ 只有几十赫兹，全频段都是统计混响，所以音乐厅不挑座位；小卧室 $V$ 只有几十立方米，$f_s$ 高达一两百赫兹，恰好把人耳最敏感的低频段罩进模式区——**小房间的声学问题，本质是体积问题**。

</details>
