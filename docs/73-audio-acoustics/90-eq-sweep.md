# 滤波与均衡

## 1. 从一个场景开始

音乐 App 的设置里有一个「均衡器」：一排竖着的推子，标着 60、230、910、3600……。把 1 kHz 那根往上推，人声立刻靠前；把 60 Hz 那根往下拉，轰隆隆的低音就干净了。录音棚的混音师整个下午都在拧这几个旋钮。

61 章讲过滤波器的数学（FIR/IIR、差分方程），那一课的滤波器是「纸上的」——输入信号，输出信号。均衡器是它的调音台化身：**不是让信号消失，而是在频谱上挖坑或堆包**。这一课让耳朵验收数学。

## 2. 直觉解释

把音色想成一座「谐波山脉」（上一课的配方单），均衡器就是刻山的工具：

- **中心频率**（freq）：刻刀落在哪——1 kHz 处堆一个包，还是 60 Hz 处挖一个坑；
- **增益**（gain）：刻多深/堆多高——用分贝计量，+8 dB 是隆起，−8 dB 是凹陷；
- **Q**：刻刀多宽——Q 越大，坑越窄越尖；Q 越小，坑越宽越平缓。

三者合起来叫**参量均衡**（parametric EQ）：三个参数都可独立调节，所以「参量」。它不像高音/低音两个旋钮那样只有模糊的两端——它可以在频谱的**任意位置**做**任意宽度**的**任意深度**手术。

刻完之后听起来如何？最诚实的检验是放一段**频谱平直的噪声**（白噪声）过去：进去是平的，出来在哪儿鼓、在哪儿瘪，一目了然——这正是下面 lab 的做法。

## 3. 正式定义

**参量均衡器**：由三个参数描述的峰形滤波器（工程实现常用双二阶结构 biquad）：

| 参数 | 名字 | 含义 |
| --- | --- | --- |
| freq | 中心频率 $f_0$ | 峰/谷所在位置（Hz，对数轴上移动） |
| gain | 峰值增益 $G$ | 中心处提升/衰减的分贝数，正=提升，负=衰减 |
| Q | 品质因数 | 峰的宽窄，$Q$ 越大包越窄；带宽近似 $BW \approx f_0/Q$ |

**分贝与幅度的换算**——这一课最要紧的一笔账：

$$\text{幅度比} = 10^{\,G/20} \qquad \text{（功率比才是 } 10^{\,G/10}\text{）}$$

所以 +6 dB 是幅度 ×2.0，+12 dB 是 ×3.98（约 4 倍），−12 dB 是 ×0.25。**对幅度用 20，对功率用 10**——分母差一倍，记混一次错一倍。

**半增益带宽**：增益降到峰值一半（比峰值低 3 dB）的那一段频宽，是 Q 最直观的画像——lab 里那两条灰色竖带就是它。

## 4. 分步例题

**例**：人声混在乐队里不够突出。决定在 1 kHz 处做参量提升 +12 dB，Q = 1.5。问：中心处幅度放大几倍？波及的频段大约多宽？

1. **幅度比**：$10^{12/20} = 10^{0.6} \approx 3.98$——中心频率处的谐波被放大到约 4 倍；
2. **带宽**：$BW \approx f_0/Q = 1000/1.5 \approx 667$ Hz——从约 700 Hz 到 1.7 kHz 都被波及；
3. **评估**：667 Hz 恰好盖住人声的主要共振区，但也会波及吉他与钢琴的同频段。工程上通常不先提人声，而是**先在别的轨上挖坑**（如在吉他轨 −3 dB），给人声腾地方——这叫「挖坑式混音」；
4. **副产物**：+12 dB 的提升同时抬了 4 倍的峰值电平，总输出更容易削波，所以推子抬完往往要整体补减几 dB。

### 实验 1（lab）：频响曲线与真实声音对账

```lab
  "freq": 1000,

```

上半张图是均衡器「纸上」的频响曲线（用双二阶公式精确算出），下半张图是**白噪声真的通过这个滤波器之后**测得的频谱。做三件事：

- 按住圆点横向拖：坑/包在频率轴上平移——注意横轴是对数的，高频端一格代表几 kHz；
- 把增益从 +8 拖到 −8：堆包变挖坑，实测谱同步塌下去；
- 把 Q 调大到 6：灰色半增益带收窄成一指宽——手术刀模式；Q 调小到 0.5，变成宽厚的「音染」。

两张图重合，说明均衡不是玄学：**频谱上挖了什么，耳朵就听到什么**。

### 实验 2（python）：增益旋钮底下是乘法

```python title="dB → 幅度比换算表"
for db in [-12, -6, 0, 6, 12]:
    ratio = 10 ** (db / 20)          # 幅度用 /20，功率才用 /10
    print(f"{db:>3} dB  →  幅度 x{round(ratio, 2)}")
```

五行输出：−12 dB → 0.25、−6 dB → 0.5、0 dB → 1.0、+6 dB → 2.0、+12 dB → 3.98。**每 6 dB 翻一倍**是幅度对数的节拍，记住它，推子上的数字就不再是咒语。把分母换成 10 跑一遍，+12 dB 会虚报成 15.85 倍——功率口径冒充幅度口径的经典错误。

### 快问快答

```quiz
均衡器把 1 kHz 提升 12 dB，中心频率处的幅度大约变成原来的几倍？
- 约 4 倍 [*]
- 12 倍
- 约 1.6 倍
? 幅度比 = 10^(12/20) ≈ 3.98。dB 对幅度是除以 20，对功率才是除以 10——这是本课最要紧的一笔账。
```

::::warning[常见误区]

**误区一**："+12 dB 就是声音变成 12 倍。"
你以为 dB 是线性刻度——其实它是对数的：+12 dB 的幅度是 3.98 倍、功率是 15.85 倍。反过来，−60 dB 听上去「只剩百分之一」，其实幅度已是千分之一。对数刻度是刻在耳朵上的。

**误区二**："Q 是越大越好，能精准手术。"
你以为 Q 拉满最专业——其实 Q 太大时滤波器冲激响应振铃变长（61 章 z 平面的语言：极点离单位圆近了），声音会「嗡」出金属尾音。混音里 Q 常用 1–3，手术刀只在消啸叫时用。

**误区三**：「重低音」就是把低频一路往上推。
你以为低频推子拉满是赚到——其实宽带提升会连带把浑浊的 200–300 Hz 也抬起来，低音反而糊。正确做法往往是在 250 Hz 附近先挖一点，再在 60–80 Hz 用窄 Q 补弹性，**先减后加**。

::::

## 6. 练习

**练习 1**：把 1 kHz 提升 12 dB，中心频率处幅度是原来的几倍？输出应为 `3.98`。这段代码用错了口径：

```exercise
# @title: 练习：+12 dB 是几倍
# @check: 3.98
# @hint: 幅度比的分母是 20；/10 算出来的是功率比。
db = 12
ratio = 10 ** (db / 10)    # ← 问题在这：这是功率口径
print(round(ratio, 2))
```

**练习 2**：降噪处理器对某频段衰减 −18 dB。该频段的幅度降到原来的百分之几？若原始幅度是 0.8，处理后是多少？

<details>
<summary>点开查看逐步解答</summary>

1. 幅度比 $10^{-18/20} = 10^{-0.9} \approx 0.126$——降到约 12.6%；
2. $0.8 \times 0.126 \approx 0.101$；
3. 直觉校验：−18 dB = 3 × (−6 dB)，每 −6 dB 幅度减半，三次就是 $0.8 \times \frac{1}{2}^3 = 0.1$——与换算一致。「每 6 dB 一半」永远可以用来心算。

</details>

## 7. 选读：白噪声与粉红噪声

<details>
<summary>选读 · 为什么 lab 的测试信号要两种</summary>

**白噪声**每赫兹功率相同——频谱是一字平线，像白光含所有颜色，因此最适合检验滤波器的形状：挖了什么坑、堆了什么包，一眼看穿。

**粉红噪声**每**倍频程**功率相同（频谱按 −3 dB/倍频程下滑）——低频段能量占比大得多。人耳对音高的感知恰是按倍频程组织的（上一课的音分就是倍频程的对数刻度），所以粉红噪声听起来「各频段一样响」，声学测量与调音现场都用它做参考信号。

lab 里那个「白噪声 / 粉红噪声」切换按钮不是摆设：白噪声看**曲线形状**，粉红噪声听**真实平衡**。两把尺子，量的是同一个滤波器。

</details>
