# 延迟、回声与梳状滤波

## 1. 从一个场景开始

对着山谷喊一声，半秒后原话弹回来——这是大自然给你的第一个音频效果器。录音棚里，工程师把它装进一条**延迟线**：声音进来，存几毫秒，再放出去，还可以把放出去的再喂回输入口，让回声一代一代传下去。

但很快有人发现了怪事：把延迟调短到几毫秒，"回声"听不见了，声音却变得像灌进**金属罐头**——某个音色怪腔怪调，某些频率被"挑走"了。时域里明明只是延迟，频率上却发生了真真切切的改变。这一课就是把这两副面孔对上号。

## 2. 直觉解释

第 16 章枢纽课有一条时移性质：**信号延迟不改幅度谱**，信息全藏在相位里。那么回声为什么能改变音色？关键在"延迟"只是搬家，**延迟了再与原声相加**，就是两列波按频率各自对位——同一频率下两个相位不同的分量相加，有的同相增强、有的反相抵消。增强与抵消的位置随频率周期排列，频谱于是长出**梳齿**。

再加上反馈（把输出再喂回延迟线），回声就不止一代：$1$ 代、$2$ 代、$3$ 代……无穷代按几何级数衰减地叠下去。时域里看，冲激响应是一串等间隔、逐级变小直至听不见的回声；频域里看，梳齿被反馈"磨"得越来越尖。**同一个东西，时域数回声，频域数梳齿**——这是傅里叶对偶在本章最可触摸的一次现身。

## 3. 正式定义

**反馈延迟线**（comb 的时域来源）：

$$y[n] = x[n] + g \cdot y[n-D]$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $D$ | 延迟量（样本数） | 单位换算：$D = t_{\text{delay}} \cdot f_s$ |
| $g$ | 反馈系数 | $0 \le g < 1$，越接近 1 尾巴越长 |
| $n - D$ | 往回看 D 拍 | 反馈回路：输出借自己的旧样本用 |

**冲激响应**（把上式递归展开）：$h[n] = \delta[n] + g\,\delta[n-D] + g^2\,\delta[n-2D] + \cdots$——第 $k$ 代的回声强度是 $g^k$。

**频响与两个设计公式**：

$$|H(f)| = \left|\frac{1}{1 - g\,e^{-j 2\pi f D T_s}}\right|, \qquad \text{齿距} = \frac{1}{t_{\text{delay}}}, \qquad \text{峰谷差} = 20\log_{10}\frac{1+g}{1-g}\ \text{dB}$$

齿距公式值得刻在脑子里：**延迟越短，齿越稀**。10 ms 延迟给 100 Hz 齿距（像均衡器），2 ms 给 500 Hz（像金属罐），1 ms 给 1000 Hz（"颤"成音色）。

## 4. 分步例题

**例**：采样率 48 kHz 的延迟效果器，$t_{\text{delay}} = 10$ ms，$g = 0.7$。问梳齿多密、峰谷差多大、第几代回声后彻底听不见（−60 dB）？

1. **齿距**：$1 / 0.01\,\text{s} = 100$ Hz——频谱每 100 Hz 一个峰一个谷；
2. **峰谷差**：$20\log_{10}\dfrac{1.7}{0.3} = 20\log_{10} 5.67 \approx 15.1$ dB——峰比谷响 15 dB，音色已被明显改写；
3. **回声寿命**：第 $k$ 代是 $0.7^k$，要求 $20\log_{10}(0.7^k) < -60$，即 $k \cdot 20\log_{10} 0.7 < -60$，$k > 60 / 3.10 = 19.4$，取 $k = 20$；
4. **结论**：20 代回声 × 10 ms = 0.2 s 后声音低于 −60 dB——反馈 0.7 的"尾巴"其实不到半秒，但每隔 100 Hz 的频谱雕琢已经让耳朵确信"这声音住在罐头里"。

## 5. 动手实验

### 实验 1（lab）：拖着听那把梳子张开

```lab
{
  "type": "delay-comb",
  "title": "把延迟从 10 ms 拖短到 2 ms，看梳齿变稀、听音色变金属",
  "time": 6,
  "fb": 0.75
}
```

上图时域：拖第一个回声的方块，横向改延迟、纵向改反馈——回声串立刻重排。下图频域：拖动时**梳齿的疏密直接跟着变**。做两件事：

- 延迟保持 10 ms，把反馈从 0.3 拖到 0.9——齿距不动，齿越来越尖（峰谷差从约 6 dB 爬到 26 dB）；
- 切到「脉冲串（听回声）」，延迟拖长到 50 ms 以上——梳齿挤成细密栅栏的同时，耳朵改口说"这是回声"。**分不清回声与音色的分界线，就在延迟几十毫秒附近**。

### 实验 2（python）：把梳齿的位置算出来

```python title="给定延迟与反馈，预报梳齿几何"
import math

D_ms = 5.0                                   # 延迟时间（ms）
g = 0.5                                      # 反馈系数
spacing = 1000 / D_ms                        # 齿距（Hz）：1 / 延迟秒数
pv = 20 * math.log10((1 + g) / (1 - g))      # 峰谷差（dB）

print(f"齿距 {spacing:.0f} Hz，峰谷差 {pv:.1f} dB")
for k in range(1, 6):
    print(f"第 {k} 个峰：{k * spacing:.0f} Hz")
```

输出：齿距 200 Hz、峰谷差 9.5 dB，峰在 200/400/600/800/1000 Hz。拿一把真均衡器对着这五个频率各推 5 dB，你就在物理世界里"演"出了这条反馈延迟线——时域与频域的等价，经得起对表。

### 快问快答

```quiz
把延迟从 10 ms 改成 2 ms，梳齿会怎么变？
- 变密，因为时间短了塞进的频率更多
- 变稀，齿距从 100 Hz 拉大到 500 Hz [*]
- 疏密不变，只是整体移位
? 齿距 = 1/延迟时间。延迟缩短 5 倍，齿距拉大 5 倍：10 ms 给 100 Hz，2 ms 给 500 Hz。直觉的"时间短 = 更密"恰好说反——这是本课最容易记错的一条。
```

::::warning[常见误区]

**误区一**："回声和混响差不多，都是声音拖尾。"
你以为拖尾巴的都是一类——回声是**离散可分辨**的反射（间隔几十毫秒以上，耳朵数得出个数）；混响是**密集不可分辨**的反射雾。延迟线的 $D$ 从 50 ms 缩到 5 ms，你听到的东西会从"回声"无缝切换成"音色"，但数学上只是梳齿从细栅栏变成宽梳子。

**误区二**："梳状滤波是均衡器故意做的音色。"
你以为金属罐音色是设计出来的——大多数场景它是**事故**：两支麦克风离人嘴距离不同、手机免提与墙面反射、同一声道复制一份延迟 3 ms 再叠回去。诊断口诀：音色出现**等间隔**的峰谷序列，先找"两条路径的时间差"。

**误区三**："反馈系数开到 0.99 更有气氛。"
你以为 $g<1$ 就安全——$g = 0.99$ 时峰谷差 $20\log_{10}(199/1) \approx 46$ dB，且能量在谐振频率上堆积，输入一停，余音嗡嗡近一秒才散。反馈 0.7 上下是音乐用途的甜点区，超过 0.9 就是在造哨子。

::::

## 6. 练习

**练习 1**：一台延迟效果器设 $D = 5$ ms，程序却报出齿距 0 Hz，错在这行单位换算：

```exercise
# @title: 练习：齿距算出 0 Hz，单位没换算
# @check: 200
# @hint: 齿距 = 1 / 延迟秒数。D_ms 的单位是毫秒，先除以 1000 换成秒——或者直接用 1000/D_ms 得 Hz
D_ms = 5.0                    # 延迟时间（ms）

spacing = 1 / D_ms            # ← 问题在这：1/D_ms 得到的是每毫秒，单位差了 1000 倍
print(f"{spacing:.0f}")
```

修正为 `spacing = 1000 / D_ms` 后输出 `200`：5 ms 延迟对应齿距 200 Hz，峰落在 200、400、600 Hz……拿它与第 90 课均衡器的刻度对一对，你会发现"毫秒级的路径差"和"听得出音色的频段"本来就是同一件事的两种单位。

**练习 2**：反馈 $g = 0.5$ 时峰谷差是多少 dB？比 $g = 0.7$ 的 15.1 dB 温和多少？

<details>
<summary>点开查看逐步解答</summary>

1. $g = 0.5$：$\dfrac{1+g}{1-g} = \dfrac{1.5}{0.5} = 3$，$20\log_{10} 3 = 9.5$ dB；
2. 与 $g = 0.7$ 的 15.1 dB 相比温和 5.6 dB——反馈差 0.2，音色改写力差一档半；
3. 极限感受：$g \to 0$ 时 $\dfrac{1+g}{1-g} \to 1$，峰谷差 $\to 0$ dB，梳子消失（单次延迟只动相位，正是第 16 章时移性质的回归）；$g \to 1$ 时峰谷差发散。
4. 设计手感的定量版：**延迟管齿距（音色往哪儿雕），反馈管齿深（雕多狠）**，两个旋钮各管各的。

</details>

## 7. 选读：更短的延迟——颤音与合唱的物理

<details>
<summary>选读 · 延迟小于 30 ms 之后，耳朵换了频道</summary>

延迟压到 30 ms 以内，回声再也无法被分辨，梳状滤波成为唯一可感知的效果——但只要让延迟时间**缓慢扫动**（比如 5 ms ± 1 ms 的低频摆动），梳齿就会跟着来回滑动，听感是"唰——唰——"的喷气机划空声，这就是 **flanger**；把延迟加宽到 20–30 ms 并做随机抖动、再多开几条，就成了**合唱（chorus）**：一个声音被克隆成一群略有先后、略有音差的"人"。

它们与第 60 课的拍频是近亲：两个稍有不同的声音叠加，时域看是"忽强忽弱"，频域看是"两条谱线的干涉"。区别只在载体的时间差：拍频靠频率差，flanger 靠延迟扫动。时延与频移，在对偶表上始终是一对邻居。

</details>
