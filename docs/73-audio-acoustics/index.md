# 音频与声学

前面五卷的数学大多"看得见"，这一章的数学要"**听得见**"。空气的压强波撞击耳膜，大脑把它翻译成音高、响度、音色与空间方位——每个环节背后都站着一位前五卷的老朋友：正弦波（07）、对数（03）、傅里叶（16）、微分方程（22）、卷积（61）。这一章不引入多少新数学，它做的是**把老数学接上耳朵**，让你第一次听见自己学过的东西。

## 方法主线

**波 → 对数 → 频谱 → 形状 → 滤波 → 空间。**

前两课建立"声音是波"的物理直觉与"耳朵是对数仪器"的度量框架；四十与五十课引入频谱视角——音色是配方，谐波的幅度表就是乐器的指纹；七十与八十课从分析转向合成：包络给骨架，加法给血肉；九十到一百二十课是处理——滤波切频段，卷积造空间，延迟与压缩整形时间与动态；最后两课把声音放进立体空间。

## 实战挑战 · 分贝的三笔账

分贝是这一章通用的度量语言，三笔账覆盖它的三个最常用场景：振幅减半掉多少 dB、60 dB SPL 对应多大的振幅比、两个独立等声源叠加涨多少 dB。下面这段代码三处全错，修到输出 `-6.0`、`1000.0`、`3.0`：

```exercise
# @title: 实战挑战：分贝的三笔账
# @check: -6.0
# @check: 1000.0
# @check: 3.0
# @hint: 声压（振幅）比用 20*log10，功率比才用 10*log10；60 dB 的振幅比是 10^(60/20)；两个独立等声源总功率翻倍，功率比 2 对应 +3 dB
import math

ratio = 0.5
db = 10 * math.log10(ratio)          # ← 振幅（声压）比，系数用错了
print(round(db, 1))

spl_db = 60.0
amp_ratio = 10 ** (spl_db / 10)      # ← 60 dB SPL 是声压级，换算公式用错了
print(amp_ratio)

two = round(20 * math.log10(2), 1)   # ← 两个独立等声源是功率翻倍，不是声压翻倍
print(two)
```

<details>
<summary>点开查看逐步解答</summary>

1. 振幅**减半**：$20\lg 0.5 = -6.02$ dB ≈ **−6.0 dB**——"-6 dB 就是一半"是音频工程师的口头禅；
2. $60$ dB SPL 的振幅比：$10^{60/20} = 10^3 = $ **1000 倍**——每 20 dB 声压差十倍；
3. 两个**独立**等声源：总功率翻倍（功率比 2），$10\lg 2 = 3.01$ ≈ **+3.0 dB**。注意不是振幅翻倍（那会 +6 dB）：不相干的两个声源，能量相加、振幅不相加。

初始代码的三处错误：功率比公式用到了振幅上（差了系数 2）、SPL 换算的分母用错（差了 6 个数量级）、声压翻倍冒充功率翻倍。三处都是"20 还是 10"的分账错误——分贝的全部玄机就在这个系数里。

</details>
