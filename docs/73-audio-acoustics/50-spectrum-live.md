# 谐波、音色与频谱

## 1. 从一个场景开始

小提琴和长笛演奏同一个 A4，440 Hz 分毫不差。蒙上眼睛你照样一耳分辨——**频率完全相同的两个声音，凭什么听上去是两个东西？**

第 07 章给过一句预告：波形形状不同。但「形状」是果不是因。这一课把因果说全：**每个乐音都不是一条正弦，而是一束正弦——一束频率成整数倍、各有各的强弱的正弦**。这束「配方」，第 16 章已经证明过它存在（傅里叶），现在轮到它解释音色了。

## 2. 直觉解释

把乐音想成一碗汤：你尝到的「味道」（音色）取决于**配料表**。配料表上写的是：

- **基频 $f$**：决定音高的那条正弦，必加的主料；
- **二次谐波 $2f$**、**三次谐波 $3f$**……：频率恰为整数倍的「影子正弦」，各带一个强度系数；
- 两件乐器的基频相同，差别全在**谐波的强弱配比**上：小提琴中频谐波饱满，长笛几乎只有基频加一点偶次谐波——耳朵尝一口就知道是谁家的汤。

**频谱**就是把配方摊开画的账本：横轴频率，每根谱线立在 $f, 2f, 3f, \dots$ 处，**高度是那条谐波的振幅**。波形图回答「压强随时间怎么晃」，频谱图回答「晃动由哪些频率配成」——同一碗汤的菜单与成品照。第 16 章的傅里叶级数告诉我们：周期信号总能这样拆，而且拆法唯一。

音色 = 频谱形状。这句话就是本课的一切。

## 3. 正式定义

**谐波列**：基频 $f$ 的乐音，其频谱成分落在 $f, 2f, 3f, \dots$（记 $k f$，称 $k$ 次谐波）上：

$$p(t) = \sum_{k=1}^{\infty} A_k \sin(2\pi k f t + \varphi_k)$$

**频谱**：把 $\lbrace |A_k|\rbrace$ 对着 $k f$ 画出的图（本课的组件直接对实时信号做傅里叶分析画出它）。

**音色**：频谱的形状（谐波配比），与音高（基频位置）和响度（总幅度）正交——三者合起来是「一个乐音」的三个坐标。

| 术语 | 名字 | 含义 |
| --- | --- | --- |
| $f$ | 基频 / 基音 | 音高的来源，频谱第一根线 |
| $kf$ | $k$ 次谐波 | 整数倍成分；$2f$ 二次谐波，以此类推 |
| $A_k$ | 谐波振幅 | 第 $k$ 条配料的分量——**音色的身份证** |
| 频谱 | 配料表 | 全部 $A_k$ 的分布图 |

两种教科书波形的配方（第 16 章系数公式的直接应用）：

- **方波**：只有**奇次**谐波，$A_k \propto 1/k$（1, 1/3, 1/5, 1/7…）；
- **锯齿波**：**全部**谐波都在，$A_k \propto 1/k$——所以它比方波「亮」得多。

## 4. 分步例题

**例**：220 Hz 的方波。写出它频谱的前三根谱线（频率与相对幅度）。

1. **列谐波频率**：方波只有奇次谐波——$f_1 = 220$ Hz、$f_3 = 660$ Hz、$f_5 = 1100$ Hz（偶次 $2f, 4f$ 处**空着**，谱线高度为零）；
2. **配幅度**：按 $1/k$ 衰减——$A_1 : A_3 : A_5 = 1 : \frac{1}{3} : \frac{1}{5} = 1 : 0.333 : 0.200$；
3. **合成时差个系数**：完整配方是 $\frac{4}{\pi}\left(\sin 2\pi f t + \frac{1}{3}\sin 6\pi f t + \frac{1}{5}\sin 10\pi f t + \cdots\right)$，那个 $4/\pi \approx 1.273$ 把总幅度凑到与方波同高；
4. **体感**：660 Hz 与 1100 Hz 的成分「藏」在同一个音里——它们不是你能单独听出的音，而是**音色的一部分**。长笛的频谱里这几根线近乎为零，这就是两件乐器同音不同色的算术差别。

## 5. 动手实验

### 实验 1（lab）：换波形，看频谱当场重排

```lab

  "wave": "sine",

```

上半屏是实时波形（时间域），下半屏是实时频谱（对数频率轴，20 Hz～20 kHz）。点「▶ 播放」后依次切换四种波形，边听边看：

- **正弦**：频谱只有一根孤零零的线立在基频上——最「干净」的音色（口哨接近它）；
- **方波**：基频后隔一根冒一根，谱线立在 1f、3f、5f 处——**奇次谐波，间隔空档**，听感「空嗡」；
- **锯齿**：谱线一根不落地排开——**全谐波**，听感最「明亮毛糙」（铜管与小提琴的近亲）；
- **三角**：谱线也在奇次上，但跌得飞快（约 $1/k^2$）——比特意压扁的方波柔和。

改一改频率再听：整片谱线**等比例左右平移**——基频搬家，配方形状（音色）不动。这正是「音高与音色是两个独立坐标」的现场证明。

### 实验 2（python）：亲手把方波的前三项配料加起来

```python title="方波 = 奇次谐波之和：叠加前三项看波形长什么样"
import math  # 数学库（卷一已引入）

f0 = 220.0                         # 基频（Hz）
T = 1 / f0
print("把 sin(f) + sin(3f)/3 + sin(5f)/5 叠加（系数 4/π），一个周期采样 8 点：")
for k in range(8):
    t = k * T / 8
    w = 2 * math.pi * f0 * t                   # 基波相位
    s = math.sin(w) + math.sin(3*w) / 3 + math.sin(5*w) / 5
    s = s * 4 / math.pi
    print(f"t = {t*1000:6.3f} ms   叠加值 = {s:+.3f}   （理想方波此处 = {'+1' if k%8<4 else '-1' if k%8<8 else 0} 或 0）")
```

看输出：靠近 0.568 ms 与 1.705 ms 的采样冲到约 ±1.02，1.136 ms 处 1.10——三项配料加起来已经**大致撑起一个方波的轮廓**（顶部略过冲，这是第 16 章讲过的吉布斯现象的影子）。谐波项数加得越多，边缘越陡、平台越平。

再列一张方波的配料表，核对你的判题答案：

```python title="方波 220 Hz 的前三根谱线"
import math  # 数学库（卷一已引入）

f0 = 220.0
for k in [1, 3, 5]:
    print(f"{k} 次谐波  频率 {f0*k:7.1f} Hz   相对幅度 1/{k} = {1/k:.4f}")
```

220、660、1100 Hz，幅度 1、0.333、0.200——与第 4 节手算一致。

### 快问快答

```quiz
220 Hz 的方波，它的频谱里会出现下面哪组频率的谱线？
- 220、440、660、880 Hz，一根不缺
- 只有 220、660、1100 Hz 这类奇数倍的谱线 [*]
- 只有 440 Hz 和 880 Hz 这类偶数倍的谱线
? 方波的傅里叶配方只含奇次谐波：基频与 3、5、7…倍频处有谱线，偶次处幅度为零。锯齿波才是全谐波。
```

::::warning[常见误区]

**误区一**：「频谱里的 660 Hz 是一个我能单独听出来的音。」
你以为谐波是混在乐音里的几个「小音」——耳朵不这么拆账。谐波列被听觉整合成**一个**有音高、有音色的整体，660 Hz 只贡献「这声音有点空、有点亮」的质感。只有刻意训练（或放慢十倍的频闪式聆听练习）才能部分地把谐波听成单独的音。

**误区二**：「音色由波形形状决定，所以记形状就够了。」
你以为「方波音色 = 方的」——形状只是配方叠加后的**结果**，同一形状在不同基频下要整个平移重画。真正可迁移、可比较的是**频谱配比**：它把「音色」从一幅二维图画升级成一份与音高无关的配方表。这就是频谱比波形更深一层的理由。

**误区三**：「谐波越多音色越准。」
你以为配方越长越像真乐器——真实乐器的音色还包括起振瞬态、轻微的谐波失谐与噪声成分（第 07 章的边界提示）。纯谐波堆出来的音「电子味」十足；谐波列只是音色的第一层模型，够用但不是全部。

::::

**练习 2**：把方波、锯齿波、正弦波按「谐波数量」从多到少排序，并各用一句话说出它们频谱的标志形状。

<details>
<summary>点开查看逐步解答</summary>

1. **锯齿波**：谐波最多——全部整数倍都在，幅度按 $1/k$ 缓降；频谱是一排密密当当的线；
2. **方波**：只有奇次谐波，幅度 $1/k$；频谱「隔一根冒一根」；
3. **正弦波**：谐波最少——只有基频一根线；
4. 所以排序是锯齿 > 方波 > 正弦；听感也从「最亮毛糙」到「空嗡」到「纯净」。谐波越多（且跌得越慢），高频成分越足，音色越亮——频谱形状与听感形容词可以互译，这正是音频工程师看谱听音的日常。

</details>

## 7. 选读：为什么乐器谐波是「整整齐齐」的整数倍

<details>
<summary>选读 · 边界条件锁定谐波列</summary>

谐波列的整数倍结构不是巧合，是**边界条件**的功劳。琴弦两端被固定（位移必须为零），允许驻留的波动形式只有「两端为节点」的那些：半波长恰好把弦长整数等分——波长 $\lambda_k = 2L/k$，频率 $f_k = k \cdot v/(2L)$，天生一列整数倍。管乐器同理：管口与反射端构成边界，允许的声波模式同样落在整数倍上。

所以「周期信号 = 谐波列」有两层来源：**物理上**，振动物体的边界条件天然制造整数倍模式；**数学上**，傅里叶保证任何周期函数都能如此分解。两层在第 16 章汇合——傅里叶级数之所以对声学处处好用，正因为真实发声体自己就是按整数倍振动的。

顺带一提：真实琴弦并非完全刚性固定，高次谐波会略微「跑音」（非整数倍），这类失谐恰恰是钢琴音色「暖」的来源之一——严格的整数倍是模型，轻微的失谐是生命。

</details>
