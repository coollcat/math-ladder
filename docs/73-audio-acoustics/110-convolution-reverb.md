# 混响与卷积混响

## 1. 从一个场景开始

同一副嗓子唱同一句歌，在浴室里唱，字字铿锵像加了合唱；走进大教堂，每个字都拖着长长的金色尾巴。声源没变，变的是**房间**。

上一课的房间模式讲了驻波怎么在矩形房间里"挑频率"，那是混响的骨架之一。现在把视角拉远：声音在房间里撞来撞去、成百上千条反射路径叠在一起，你听到的每一句都不是"裸声"，而是**干声与整个房间纠缠后的产物**。第 61 章第 20 课为此准备好了精确的语言——混响，就是干声与房间脉冲响应的**卷积**。

## 2. 直觉解释

在教堂里拍一下手，会发生三件时间上分开的事：

1. **直达声**：从手到耳朵的直线路径，最先到，能量最强；
2. **早期反射**：撞上第一排墙壁、天花板折返回来的十几个"散兵"，各差几毫秒；
3. **混响尾巴**：反射越弹越多、越叠越密，最终融成一片平滑衰减的"雾"，直到听不见。

这三段合起来，正是这个房间对"拍一下手"的完整回答——**房间脉冲响应**（Impulse Response，IR）。第 61 章说过：线性时不变系统被自己的冲激响应完全刻画，对任意输入的输出等于输入与 $h$ 的卷积。房间只要"够线性"（不炸耳朵时基本成立），这句话立刻兑现：

$$\text{湿声} = \text{干声} * h_{\text{房间}}$$

所以"给录音加混响"这件事，数学上只是**一次卷积**。整间教堂的声学性格，被压缩成一条几秒长的曲线——这就是卷积混响器的原理。

## 3. 正式定义

**房间脉冲响应** $h(t)$：在声源位置输入单位冲激，接收位置记录到的完整声压响应。典型结构：

| 成分 | 时间窗 | 作用 |
| --- | --- | --- |
| 直达声 | $t = 0$ | 定位声源、确定音色基准 |
| 预延迟（predelay） | 直达声与第一反射的间隔，约 5–30 ms | 暗示房间大小：越大厅，空档越长 |
| 早期反射 | 约 5–80 ms | 空间感的主要来源 |
| 混响尾巴 | 之后一路衰减 | 能量按指数规律消散 |

**卷积混响**：干声 $x(t)$ 与 IR 的连续卷积（离散实现即第 61 章的卷积和）：

$$y(t) = (x * h)(t) = \int x(\tau)\, h(t-\tau)\, d\tau$$

**混响时间 RT60**：声能密度衰减 60 dB（百万分之一）所需的时间。**赛宾公式**给出工程估算：

$$RT_{60} \approx 0.161 \, \frac{V}{A}, \qquad A = \sum_i \alpha_i S_i$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $V$ | 房间体积 | m³ | 越大越"荡" |
| $A$ | 总吸声量 | m²（赛宾） | 每块表面的吸声系数乘面积 |
| $\alpha$ | 吸声系数 | 0–1 | 1 = 全吸收（开口窗），0.01 = 硬混凝土 |
| $S_i$ | 表面积 | m² | 各块内表面 |

## 4. 分步例题

**例 1**：估算一座教堂的混响时间。体积 $V = 25000$ m³，石墙与彩窗的总吸声量 $A = 2000$ m²（赛宾）。

1. 代入赛宾公式：$RT_{60} = 0.161 \times 25000 / 2000 = 2.01$ s；
2. 与经验对照：大教堂实测 2–5 s，量级正确；
3. 解读：2 秒的尾巴对管风琴是恢弘，对布道是灾难——所以教堂里讲台附近必装吸声板。

**例 2**：一间卧室 $V = 45$ m³，窗帘、床铺、衣柜合计 $A = 18$ m²。

$RT_{60} = 0.161 \times 45 / 18 = 0.40$ s——这正是"卧室里唱歌字字清楚"的定量解释。家用录音室追求的也是这个量级：**语言与录音要干（0.2–0.5 s），音乐厅要润（1.8–2.2 s）**。

## 5. 动手实验

### 实验 1（lab）：拖着听，房间是怎么"长大"的

```lab
{
  "type": "convolution-reverb",
  "title": "拖动右边的方块拉长混响尾巴，拖动三角拉开预延迟，切三种声源听",
  "seconds": 2.5,
  "predelay": 0.03,
  "decay": 2,
  "src": "clap"
}
```

上图是 IR 的时域波形：左边那个孤立三角就是预延迟空档，后面那片逐渐变矮的噪声墙就是尾巴。中图是**能量衰减曲线**（EDC）——分贝对时间，斜率越平混响越长。做三件事：

- 把尾巴拖到最长，切到「击掌脉冲」——一声脆响被拉成绵长的"哗"，这就是卷积在时间上的铺开；
- 切到「白噪声」——持续输入被卷积后仍是持续声音，但音色变"空"了：房间挑走了它挑不动的频率；
- 拖大衰减指数（滑块）——包络从"缓缓落下"变成"陡然坠地"，对应 EDC 斜率变陡。

### 实验 2（python）：四间房间的赛宾体检

```python title="用赛宾公式给不同房间开处方"
rooms = [("卧室", 45, 18), ("录音棚", 180, 150), ("音乐厅", 12000, 1100), ("教堂", 25000, 2000)]
for name, V, A in rooms:
    rt = 0.161 * V / A
    tag = "语言/录音：干得正好" if rt <= 1.0 else ("音乐甜点区" if rt >= 1.8 else "不干不湿，鸡肋")
    print(f"{name:>4}: RT60 = {rt:.2f} s   {tag}")
```

四行输出：卧室 0.40 s、录音棚 0.19 s、音乐厅 1.76 s、教堂 2.01 s。**注意"合适"取决于用途**：同一个 2.01 s，对教堂布道要扣分、对管风琴要加分。声学设计的第一问从来不是"混响多长好"，而是"这房间用来干什么"。

### 快问快答

```quiz
把干声的音量放大 10 倍再过同一个房间，混响尾巴会怎么变？
- 尾巴被房间"压短"，因为大音量提前撞饱和了
- 整条尾巴也放大 10 倍，形状分毫不变 [*]
- 尾巴形状会乱掉，因为反射路径变了
? 房间是线性系统：输入整体缩放 k 倍，输出 y = x*h 也整体缩放 k 倍，h 本身纹丝不动。这就是第 61 章线性纪律在声学里的显形——房间不会因为你说得响就换一条反射路径。
```

::::warning[常见误区]

**误区一**："混响是效果器发明的。"
你以为"加混响"是录音棚的特效——其实**任何室内听到的声音都自带混响**，效果器只是把卷积做成了可以旋钮的产品。真正的问题从来不是"要不要混响"，而是"现在的混响合不合适"。

**误区二**："混响时间越长越高级。"
你以为大厅堂才显档次——语言录音、播客、监听棚里，2 秒的尾巴会把辅音糊成一锅粥。混响时间是为**用途**服务的参数：语言要短、音乐要中、管风琴才配得上 4 秒。

**误区三**："混响尾巴就是回声。"
你以为拖长的都是"回声"——回声是**离散可分辨**的反射（间隔约 50 ms 以上，耳朵能把它们数出来）；混响尾巴是**密集不可分辨**的反射雾。延迟短到分不清时，耳朵改听"音色"而非"回声"——下一课的梳状滤波正是这条分界线的物理。

::::

## 6. 练习

**练习 1**：某音乐厅 $V = 12500$ m³，总表面积 $S = 2500$ m²，平均吸声系数 $\alpha = 0.5$。求混响时间（保留 1 位小数）。这段代码算出来只有 0.8 s，明显太干：

```exercise
# @title: 练习：这座音乐厅的混响时间够不够
# @check: 1.6
# @hint: 赛宾公式的分母是"总吸声量" A = α·S（单位：赛宾），不是表面积 S 本身。先把 A 算出来
V = 12500        # 音乐厅体积（m³）
S = 2500         # 总表面积（m²）
alpha = 0.5      # 平均吸声系数

RT60 = 0.161 * V / S     # ← 问题在这：分母应该是总吸声量 A = alpha * S
print(f"{RT60:.1f}")
```

修正后：$A = 0.5 \times 2500 = 1250$ 赛宾，$RT_{60} = 0.161 \times 12500 / 1250 = 1.6$ s。低于音乐厅甜点区（1.8–2.2 s），工程师的处方是**减吸声**：把 $\alpha$ 降到 0.42，$A = 1050$，$RT_{60} = 1.9$ s——注意修法是动 $\alpha$ 或 $S$，体积 $V$ 在建筑落成后基本动不了。

**练习 2**：为什么卷积混响器对同一段干声用不同的 IR，"房间"听起来完全不同，而音高、旋律一个音都不变？

<details>
<summary>点开查看逐步解答</summary>

1. 旋律与音高由干声 $x(t)$ 携带，卷积不改变输入的基频序列——每个音该多高还是多高；
2. IR $h(t)$ 是一条**衰减包络 + 噪声样纹理**的曲线，它对输入的作用是"时间上铺开 + 高频先衰"；
3. 不同 IR = 不同铺开方式：预延迟长短改"房间大小感"，尾巴斜率改"余韵"，早期反射的稀密改"空间轮廓"；
4. 所以换 IR 只换"环境性格"，不换"演奏内容"。同一份 $x$，卷上教堂的 $h$ 就空旷，卷上卧室的 $h$ 就贴耳——这正是第 61 章"系统被冲激响应完全刻画"的听觉版。

</details>

## 7. 选读：IR 为什么长成"指数衰减的噪声"

<details>
<summary>选读 · 从无数反射到一条可合成的曲线</summary>

真实的 IR 是几千条反射的叠加，逐条记录既贵又没必要。观察它的统计结构：反射到达时刻越来越密（路径数指数增长），每条能量越来越弱，两者相抵后，**能量包络近似按指数衰减，纹理近似随机噪声**——大量独立反射叠加，中心极限定理在起作用。

于是工程上用三件套合成 IR：**预延迟（全零段）+ 早期反射（几根离散冲激）+ 指数衰减的白噪声**。本课 lab 组件用的正是这个配方（`makeImpulse`：包络 $(1-t/T)^k$ 乘噪声）。它抓住的是混响的统计本质，牺牲的是特定墙面的镜像细节——换来的是"任意房间，两秒合成"。

还可以再问一步：能量指数衰减意味着**每过同样时间掉同样的分贝数**，所以 EDC（分贝对时间）是一条直线，混响时间就是"这条直线掉 60 dB 的横跨距离"。赛宾公式与卷积实现，在这条直线上会师。

</details>
