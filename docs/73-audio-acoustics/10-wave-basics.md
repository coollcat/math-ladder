# 声音是空气的压强波

## 1. 从一个场景开始

把手掌贴在正在放歌的音箱前——掌心会感到一阵一阵的推力。发声的不是音箱的「电流」，也不是空气里飘过来的什么粒子，而是**纸盆在以每秒几百次的频率推挤空气**，这股推挤顺着空气一路传进你的耳道。

第 07 章我们已经认识过声音的**数学身份**：一条正弦曲线，频率决定音高。现在给它发一张**物理身份证**：在空气里，这条曲线到底是什么东西的起伏？答案是**压强**。

## 2. 直觉解释

想象一列很长的弹簧圈，你用手在末端沿**弹簧方向**推一下再拉一下：被推的地方线圈变密、被拉的地方变疏，这个「密—疏—密—疏」的花样会沿着弹簧跑出去。空气里的声音一模一样：

- 纸盆向前推 → 前方空气被**压缩**，压强比大气压略高（密部）；
- 纸盆向后退 → 那里空气变**稀薄**，压强略低（疏部）；
- 疏密相间的花样以约 343 m/s 的速度向外奔跑——这就是声音。

所以空气分子自己**并没有从音箱飞到你的耳朵**，它们只是在自己的小地盘里前后晃了晃，把「晃动」这个消息接力传了下去。传的不是物质，是**扰动**。

还有一个容易别扭的地方：第 07 章画在纸上的正弦曲线，纵轴是「上下」的——但空气并不上下运动，它沿传播方向**前后**振动（这种波叫**纵波**）。纸上那条正弦是**记账曲线**：横轴是位置或时间，纵轴记的是「这里的压强偏离大气压多少」。曲线的形状是正弦，运动的实体是压强。

## 3. 正式定义

**声波**：压强在静态大气压 $p_{\text{atm}}$ 附近的小幅振荡，沿传播方向的空间-时间分布可写成

$$p(x, t) = p_{\text{atm}} + \Delta p \cdot \sin\!\left(2\pi f t - \frac{2\pi}{\lambda}\,x\right)$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $p_{\text{atm}}$ | 大气压 | Pa | 约 $101325$ Pa，是「静默时的底座」 |
| $\Delta p$ | 声压振幅 | Pa | 压强偏离底座的最大幅度（第 30 课的主角） |
| $f$ | 频率 | Hz | 每秒振荡多少次，人耳可闻约 $20 \sim 20000$ Hz |
| $T = 1/f$ | 周期 | s | 振荡一次所需时间 |
| $\lambda$ | 波长 | m | 相邻两个密部（或疏部）之间的距离 |
| $v$ | 声速 | m/s | 疏密花样跑的速度，20 ℃ 空气约 343 |

三者被一条极简单的约束锁在一起——**一个周期里，波恰好跑出去一个波长**：

$$v = f \cdot \lambda \qquad \Longleftrightarrow \qquad \lambda = \frac{v}{f}$$

这条式子是全章用得最多的一把尺子：频率越高，波长越短。

## 4. 分步例题

**例**：求 20 ℃ 空气中标准音 A4（440 Hz）的波长。

1. **取声速**：$v = 343$ m/s；
2. **套公式**：$\lambda = v/f = 343 / 440 \approx 0.780$ m；
3. **体感一下**：不到 80 cm——和你张开的手掌到肘部差不多。也就是说，A4 的密部与疏部每隔不到一米交替一次。

同一个公式扫一遍可闻域的两端，会看到一个上千倍的跨度：

- $f = 20$ Hz（最低沉的隆隆声）：$\lambda = 343/20 \approx 17$ m，五层楼那么长；
- $f = 20000$ Hz（最尖的嘶嘶声）：$\lambda = 343/20000 \approx 0.017$ m，两厘米。

波长差了 1000 倍——这就是为什么给房间做隔音（对付低频）和给音箱排位（对付高频）要用完全不同的思路。

## 5. 动手实验

### 实验 1（lab）：疏密波亲眼看，还能亲耳听

```lab
{
  "type": "wave-basics",
  "title": "拖频率与振幅，看空气疏密波怎么跑（点「▶ 播放」同步发声）",
  "freq": 3,
  "amp": 0.8
}
```

画面里那条正弦是**压强随位置的分布**，下面的粒子带是空气本身：注意粒子并没有跟着波跑远，它们只是在原地附近小幅挪动，**密的地方挤、疏的地方散**——而「挤」这个花样在整体向右平移。做三件事：

- 拖**频率**：画面里完整波形的个数变多（波长变短），声音变尖——这正是 $\lambda = v/f$；
- 拖**振幅**：曲线起伏变大、粒子挤得更紧，声音变响——振幅管响度，第 30 课细讲；
- 拖**传播速度**：只改变花样跑多快，**不改变波长**——跑得快慢与花样多密是两回事。

### 实验 2（python）：把一条压强波采样出来看

```python title="对一个周期采样：压强起伏的正弦记账"
import math  # 数学库（卷一已引入）

f = 440.0                     # A4 的频率（Hz）
T = 1 / f                     # 周期（s）
print(f"440 Hz 的周期 T = {T*1000:.3f} ms，一个周期恰好振荡一遍：\n")
for k in range(9):
    t = k * T / 8                                    # 一个周期均分 8 份
    phase = 2 * math.pi * f * t                      # 相位（弧度）
    dp = math.sin(phase)                             # 压强起伏（归一化）
    print(f"t = {t*1000:6.3f} ms   相位 = {phase:5.2f} rad   压强起伏 = {dp:+.3f}")
```

压强从 0 出发，爬到 +1（最密）、回落穿过 0、跌到 −1（最疏），再回到 0——一个周期 $\frac{1000}{440} \approx 2.273$ ms 内恰好走完一整圈。**耳朵每秒要完成 440 圈这样的追踪**，而它对 20000 Hz 的声音要追两万圈——耳朵是个惊人的仪器。

再补一刀，把可闻域两端的波长都算出来：

```python title="可闻域两端的波长"
import math  # 数学库（卷一已引入）

for f in [20.0, 440.0, 20000.0]:
    lam = 343.0 / f           # λ = v / f
    print(f"f = {f:8.0f} Hz   波长 λ = {lam:8.4f} m")
```

20 Hz 对应 17.15 m，440 Hz 对应 0.7795 m，20000 Hz 只剩 0.0172 m——与第 4 节手算一致。

### 快问快答

```quiz
20 ℃ 空气中声速约 343 m/s。当一个声音的频率变为原来的 2 倍，它的波长怎么变？
- 变为原来的 2 倍
- 变为原来的一半 [*]
- 不变
? λ = v ÷ f。声速由空气决定、不变，波长与频率成反比：频率翻倍，波长减半。
```

::::warning[常见误区]

**误区一**：「声音是空气分子从音箱一路飞进耳朵。」
你以为听到远处说话是那边空气跑过来了——其实分子只在原地附近晃动不到一毫米，接力传下去的是**扰动**。判断波传播的标志是花样在跑，不是物质在跑：水波推着浮木上下晃，却不把它带走。

**误区二**：「纸上那条正弦曲线画的是空气上下飞舞的轨迹。」
你把纵波想象成了横波——空气是沿传播方向**前后**振动的，曲线上「上下」的那个维度记录的是**压强大小**。形状是正弦的是压强记账表，不是分子的运动轨迹。

**误区三**：「波长由声音有多响决定。」
你以为嗓门越大波长越长——波长只由 $\lambda = v/f$ 决定，跟振幅毫无关系。响度改的是 $\Delta p$（压强起伏的幅度），改波长只有两个办法：换频率，或换介质（水中声速约 1500 m/s，同样的 440 Hz 波长就变成 3.4 m）。

::::

## 6. 练习

**练习 1**：求 20 ℃ 空气里 440 Hz 的波长（保留 2 位小数）。这段代码把方向弄反了：

```exercise
# @title: 练习：算标准音的波长
# @check: 0.78
# @hint: 一个周期里波恰好跑出一个波长，所以波长 = 声速 ÷ 频率，不是相乘
v = 343.0      # 声速（m/s，20 ℃ 空气）
f = 440.0      # 标准音 A4（Hz）
lam = v * f    # ← 问题在这：波长应该是 v ÷ f
print(round(lam, 2))
```

算对之后再感受一下这个数：0.78 m。人耳要从 17 m（20 Hz）一直听到 0.017 m（20 kHz），跨度上千倍，而全套设备只是两片薄膜和一窝毛细胞。

**练习 2**：同样的 440 Hz，在水中（声速约 1500 m/s）波长是多少？

<details>
<summary>点开查看逐步解答</summary>

1. 公式不变：$\lambda = v/f$，只是换了介质的声速；
2. $\lambda = 1500 / 440 \approx 3.41$ m；
3. **频率没变**（振源每秒还是振 440 次），变的是波跑得更快、同样频率下波长被拉长——声波从空气进入水（或反之）时不变的是频率 $f$，变的是 $v$ 与 $\lambda$。

这也是声呐设计与水下通信必须重新算尺寸的根本原因：水里的「同一句话」，波长是空气里的 4 倍多。

</details>

## 7. 选读：声速为什么恰好是 343 m/s

<details>
<summary>选读 · 从理想气体推出声速</summary>

声音是压强扰动，传得多快由空气的「弹性与惰性」决定：压得越狠回弹越有力（弹性），空气越重追得越慢（惰性）。理论给出

$$v = \sqrt{\frac{\gamma R T}{M}}$$

其中 $\gamma$ 是绝热指数（空气约 1.4），$R$ 是气体常数，$T$ 是热力学温度，$M$ 是摩尔质量。取 $T = 293$ K（20 ℃）：

$$v = \sqrt{\frac{1.4 \times 8.314 \times 293}{0.029}} \approx \sqrt{117700} \approx 343\ \text{m/s}$$

注意 $v \propto \sqrt{T}$：气温越高声速越快。夏天的傍晚声音传得更远更「脆」，除了空气安静，也有声速这条物理原因。另外声波压缩空气的过程快得来不及换热（绝热），所以用的是 $\gamma$ 而不是等温的 1——这正是牛顿当年算出 290 m/s、差了 15% 的著名失误：他用了等温压缩。

</details>
