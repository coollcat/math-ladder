# 音频与声学方法地图

## 1. 从一个场景开始

朋友递来一段干瘪的人声录音，加一句"帮我弄好听点"。你打开本章的工具箱，里面躺着 14 门课的家伙：均衡、压缩、混响、延迟、声像……工具一多，最大的风险不是不会用，而是**拿着锤子看什么都是钉子**——先上个压缩、再贴个 EQ、补条混响，链路越接越长，声音越修越坏。

本课不添任何新定理，只做三件事：把全章排成一张**导诊地图**、演练一遍**分诊两问法**、把音频工程师脑内的数量级钉成一张速查卡。

## 2. 直觉解释：分诊两问法

**第一问——主诉属于哪一类？**

| 类别 | 典型主诉 | 本章负责的课 |
| --- | --- | --- |
| **听见** | 听不清、太吵太轻、音高不对 | 第 10、20、30、40、50、60 课 |
| **合成** | 声音没血肉、音色不像 | 第 70、80 课 |
| **处理** | 太干太湿、有回声、会炸、嗡嗡 | 第 90、110、120、130 课 |
| **空间** | 定位漂、声像糊、房间共鸣 | 第 100、140 课 |

**第二问——现象的特征尺度是什么？**

- **频率**（Hz）：嗡在 50 Hz 还是刺在 3 kHz？决定动均衡还是动音色；
- **时间**（ms）：0.6 ms 的双耳时差、20 ms 的预延迟、50 ms 的回声门槛——量级不同，耳朵听到的东西根本不同；
- **电平**（dB）：差 6 dB 还是差 32 dB？决定动不动压缩、动多狠；
- **方位**（度）：是声像问题还是房间问题？耳机里糊、音箱里清楚，多半是房间。

两问答案一对，"先抓哪个"基本锁定。剩下的分歧多半在"多种工具都能凑合"的地带——那时比的是**处理链的顺序**，而不是谁听起来高级。

## 4. 分步例题

**题 A**：播客导出后发现 50 Hz 电源嗡声很重，人声也偏轻。

1. 第一问：**处理**；第二问：频率尺度 50 Hz（市电哼声的指纹）+ 电平尺度（人声偏轻）；
2. **顺序是知识**：先用均衡在 50 Hz 附近窄口切除，再上压缩抬平均电平。反过来做，压缩器会把嗡声一起托起来，越压越嗡；
3. 处方链：切嗡（第 90 课）→ 压缩整形（[压缩与限幅](./130-compressor-lab.md)）→ makeup 抬响度。**先除害，再塑形。**

**题 B**：干声加了混响后咬字发糊，快节奏的段落更明显。

1. 第一问：**处理**（太湿）；第二问：时间尺度——糊的是辅音瞬态（几毫秒级）；
2. 定位：混响尾巴的早期反射抢在咬字后面 10 ms 就到，与辅音糊在一起；
3. 处方（[混响与卷积混响](./110-convolution-reverb.md)）：**预延迟拉到 20–30 ms** 给直达声让路，尾巴按曲速缩短——慢歌 2 s 的房间，快歌 0.8 s 就够。

**题 C**：成品总觉得"不够响"，把限幅器推到顶还是不响，反而发闷。

1. 第一问：**处理**（电平）；第二问：限幅器增益衰减已经常年 6 dB 以上——**瓶颈不在限幅器**；
2. 逐层回查：混音里低频堆太多？均衡先收（第 90 课）→ 动态没先管？压缩要在限幅**之前**（[压缩与限幅](./130-compressor-lab.md)）；
3. 结论：响度是**全链路的合力**，最后一级限幅器只是收尾的天花板——前面没理顺，天花板压得再低也只是闷。

## 5. 动手实验

### 实验 1（python）：一张表把数量级钉住

```python title="音频工程师脑内必备的数量级"
print("── 频率与波长（声速 343 m/s）────")
for name, f in [("市电哼声", 50), ("中央 A", 440), ("奈奎斯特(44.1k)", 22050), ("人耳上限", 20000)]:
    print(f"{name:>12}: {f:>6} Hz   波长 {343/f:>6.3f} m")

print("── 时间（毫秒）──────────────")
for name, t in [("A4 的周期", 1000/440), ("最大双耳时差", 0.656),
                ("回声分辨门槛", 50), ("典型预延迟", 20)]:
    print(f"{name:>12}: {t:>6.2f} ms")

print("── 电平与房间 ───────────────")
print("  听阈 0 dB SPL · 交谈约 60 · 痛阈 120 · 响度翻倍约 +10 dB")
print("  RT60: 卧室 0.4 s · 音乐厅 2 s · 大教堂 4 s 起")
```

三段输出是"工程直觉"的量化版。挑两条最值钱的：**20 kHz 的波长只有约 1.7 cm**——高频绕不过你的头，ILD 之所以存在，物理根子就在这个尺寸差；**最大双耳时差 0.66 ms** 比回声门槛 50 ms 小两个量级——所以"定位"与"回声"是两套完全不同的感知机制，也难怪声像旋钮给不出真方位。

### 实验 2（python）：给主诉自动挂号

```python title="按主诉开具科室单"
def triage(hollow, boomy, dry, harsh):
    # 顺序即知识：会"越修越坏"的先分流
    if boomy:
        return "eq（先切嗡声，再谈别的）"
    if harsh:
        return "eq + compressor（刺感先收频段，再压动态）"
    if hollow:
        return "delay-comb（查两条路径的时间差）"
    if dry:
        return "convolution-reverb（配一条 RT60 合适的 IR）"
    return "db-meter（先把电平表看明白）"

cases = [("有 50 Hz 嗡声", False, True, False, False),
         ("高频扎耳朵", False, False, False, True),
         ("声音像罐头", True, False, False, False),
         ("像在真空里唱歌", False, False, True, False),
         ("轻重听不出差别", False, False, False, False)]
for note, h, c, d, e in cases:
    print(triage(h, c, d, e), "|", note)
```

五行输出就是五张挂号单。**if 台阶的顺序本身就是本章的处事哲学**：嗡声与刺感排最前，因为它们会污染后面所有判断——先除害，再塑形，最后才谈风格。

### 快问快答

```quiz
一段人声 50 Hz 嗡声很重、整体又偏轻，处理链的第一刀落在哪里？
- 先上压缩器把整体抬起来，嗡声自然就小了
- 先用均衡在 50 Hz 附近窄口切除，再谈响度 [*]
- 直接加一条混响把嗡声盖掉
? 压缩器按电平工作、不分频率，先压会把嗡声一起托起来，越压越嗡；混响更是给嗡声"加房间"。本章的分诊原则：先除害（EQ 切频段），再塑形（压缩），最后谈风格（混响/延迟）。
```

::::warning[常见误区]

**误区一**："链路越长越专业。"
你以为每一级效果都在加分——每一级都有代价：EQ 有相位副作用、压缩有抽吸、混响会积泥。专业的标志不是挂了多少插件，而是**每说出一处处理，都能回答"它治什么、代价是什么"**。治不了主诉的效果，再高级也是负资产。

**误区二**："参数记不住，就没法干活。"
你以为干活靠背小数点——其实靠**数量级手感**：嗡声在百赫兹以下、刺感在几千赫兹、预延迟二十毫秒、双耳时差不到一毫秒。量级对了，微调交给耳朵；量级错了，调得再细也是南辕北辙。

**误区三**："方法地图是一条通关路线。"
它是按需查阅的工具书，不是进度条。真实项目只摘用其中两三页。这张表真正想教的是**分诊顺序**：先除害（嗡声、刺感、炸峰），再塑形（动态、频段），最后才谈风格（混响、声像、延迟）。顺序错了，会越修越坏。

::::

## 6. 练习

**练习 1**：分诊前先练换算：中央 A 是 440 Hz，它的周期是多少毫秒（保留 1 位小数）？下面的代码算出了 0.4：

```exercise
# @title: 练习：分诊前的换算——周期与频率
# @check: 2.3
# @hint: 周期 = 1/频率（单位秒），换算成毫秒再乘 1000。代码把分子分母放反了
f = 440.0           # 中央 A 的频率（Hz）

T_ms = f / 1000     # ← 问题在这：周期是 1000/f，不是 f/1000
print(f"{T_ms:.1f}")
```

修正后：$T = 1000/440 = 2.3$ ms。这个数值得钉进脑子：**A4 的周期 2.3 ms**，落在预延迟（20 ms）与双耳时差（0.66 ms）之间——同一把"毫秒尺"上，波形、混响、定位各占一段刻度，分诊时先把主诉换算到正确的刻度段。

**练习 2**：接手一条"人声干瘪、峰值会炸、房间嗡嗡"的三重主诉录音，写出你的处理链与每一步的理由。

<details>
<summary>点开查看逐步解答</summary>

1. **第一步：切嗡**（第 90 课均衡）——50/100 Hz 窄口衰减。理由：嗡声是"害"，会污染后面所有判断，尤其不能让它进压缩器被抬升；
2. **第二步：定电平**（第 30 课分贝 + [压缩](./130-compressor-lab.md)）——中等压缩比 3:1、attack 10–30 ms 保瞬态，把峰值间距收窄。理由：峰值不治住，后面的混响余量没法定；
3. **第三步：上空间**（[混响](./110-convolution-reverb.md)）——预延迟 20–30 ms、RT60 按语速选 0.6–1 s。理由：空间感放在链路后段，才不会被后续处理二次改写；
4. **第四步：收尾限幅**——只当天花板，不让它常年工作在深度衰减区；
5. **贯穿的顺序逻辑**：除害 → 塑形 → 风格 → 收尾。任何一步提前，都会被后面一步放大或抹掉——这张处方单就是分诊两问法的完整走一遍。

</details>

## 7. 选读：三条游览路线

<details>
<summary>选读 · 不同胃口的吃法</summary>

**制作速通线**（最快上手出活）：第 30 课分贝 → 第 50 课频谱 → 第 70 课 ADSR → [压缩与限幅](./130-compressor-lab.md) → [混响](./110-convolution-reverb.md) → [立体声声像](./140-panning-binaural.md)。走完这条，你已经有能力把一段干声做成像样的成品。

**声学纵深线**（想懂"房间"的读法）：第 10 课声波 → 第 40 课等响曲线 → 第 100 课房间模式 → [卷积混响](./110-convolution-reverb.md) → 第 90 课滤波均衡。重点在"声音与空间互相塑形"：从等响曲线的人耳偏见到驻波怎么挑频率，直通建筑声学与录音棚设计。

**信号处理换乘线**（往数学深处走的读法）：第 50 课频谱 → 第 90 课滤波 → [延迟与梳状](./120-delay-comb.md)，再换乘 [第 61 章·卷积与 LTI](../61-digital-signal-processing/20-convolution-lti.md) 与 [FIR/IIR](../61-digital-signal-processing/50-fir-iir.md)。你会发现本章每个音频效果器，都是第 61 章某个数学对象穿了件"能听"的外衣。

**三条线最后汇入同一句话**：音频工程的本质不是记住效果器，而是**在"听得见的物理"与"听得舒服的取舍"之间来回翻译**——地图帮你找到工具，翻译只能靠你的耳朵。

</details>
