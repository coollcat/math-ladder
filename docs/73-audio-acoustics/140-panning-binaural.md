# 立体声与双耳线索

## 1. 从一个场景开始

闭着眼，朋友在左边叫你——头一转就朝对了方向。这个毫不费力的动作背后，听觉系统每秒在做几十次精密测量：两只耳朵隔着一个头，收到的是**两个略有不同的信号**，大脑从差异里反推出方位。

而混音台上的声像（pan）旋钮也号称管"左右"：把信号左一点、右一点。它给的是真方位吗？戴上耳机转一转，你很快会发现"左右"听感始终**锁在脑袋正中间的一条线上**，永远不会绕到脑后。这一课就把"声像"与"双耳定位"这两件事掰开：它们都叫立体声，物理含量天差地别。

## 2. 直觉解释

两耳信号差在哪？两个来源：

- **时间差 ITD**：声源偏一侧，到远耳多走一段绕头弧线。声速 343 m/s、头宽约 17.5 cm，最大时间差不到 1 毫秒——但人耳对时间差的分辨本领约 10 微秒，绰绰有余；
- **强度差 ILD**：高频波长短（2 kHz 以上波长小于头径），**绕不过头**，远耳处在"声影区"，直接被挡掉一大截。低频则畅通无阻地绕过去，两耳响度几乎一样。

于是分工自然形成：**低频听时间差，高频听强度差**——duplex theory（复式理论）。中间 1.5–3 kHz 是尴尬地带：相位差开始"绕圈"混淆、头影效应又还没成型，两套线索都半身不遂，这是人耳水平定位最吃力的频段。

声像旋钮只做了其中一半的一半：按比例分强度，时间完全同步。它造的是"两耳强度差"，不是"绕头弧线"——所以耳机里它只能让声音在两耳之间滑动，永远滑不出脑内。

## 3. 正式定义

**等功率声像**（录音棚标准做法）：把单声道信号按

$$L = \cos\theta, \qquad R = \sin\theta, \qquad \theta = (pan + 1)\cdot\frac{\pi}{4}, \quad pan \in [-1, +1]$$

分给两个声道。设计要点是 $L^2 + R^2 = 1$ 恒定：不管声像在哪，**总功率不变**，听感只"移动"不"变响"。

**双耳线索**（真实听觉的物理）：

| 线索 | 公式 | 适用频段 |
| --- | --- | --- |
| 时间差 ITD | $ITD = \dfrac{a}{c}(\varphi + \sin\varphi)$ | 低频（< 1.5 kHz） |
| 强度差 ILD | $ILD \approx \min(20,\ 0.005 f)\cdot\lvert\sin\varphi\rvert$ dB | 高频（> 3 kHz） |

| 符号 | 名字 | 取值 | 含义 |
| --- | --- | --- | --- |
| $a$ | 头半径 | 0.0875 m | 成人头宽约 17.5 cm |
| $c$ | 声速 | 343 m/s | 常温空气 |
| $\varphi$ | 方位角（弧度） | 0 正前，±π/2 正左右 | Woodworth 球形头模型 |

ITD 公式里 $\varphi + \sin\varphi$ 的正弦项是**绕头弧线的修正**：声波沿头面绕行，多走的不是直线弦长而是弧长，正侧方时弧线最长。ILD 的 $\min(20, 0.005f)$ 是头影效应的经验近似——频率越高挡得越狠，到 4 kHz 以上顶格 20 dB。

## 4. 分步例题

**例 1**：声源在正右方（$\varphi = 90°$）。求 ITD。

1. 换弧度：$\varphi = \pi/2 = 1.5708$；
2. 代入：$ITD = \dfrac{0.0875}{343}(1.5708 + 1) = 2.551 \times 10^{-4} \times 2.5708 \approx 6.56 \times 10^{-4}$ s；
3. 即 **0.656 ms**——单耳比另一耳晚不到千分之一秒，大脑却拿它定出"正右方"，而它的分辨阈值只有约 10 µs：最大可用信号是阈值的 65 倍。

**例 2**：声源在右前方 30°，一个 2 kHz 的音。求两耳线索。

1. $\varphi = \pi/6 = 0.5236$，$ITD = 2.551\times10^{-4} \times (0.5236 + 0.5) \approx 0.261$ ms；
2. $ILD = \min(20,\ 0.005 \times 2000) \times \sin 30° = 10 \times 0.5 = 5$ dB；
3. 解读：2 kHz 恰在 duplex 缺口边缘——ITD 开始出现相位混淆（2 kHz 波长 17 cm，与头径同量级），ILD 只有 5 dB 还不强势。**把同一个音放到 500 Hz 或 6 kHz，定位都会更稳**：混音时"怕糊"的重要元素别搁在 1.5–3 kHz 正中，理由又多了一条。

### 实验 1（lab）：拖动声源，看两个线索各自怎么变

```lab
}
```

左上俯视图按住拖动：声源从头前方 −90° 绕到 +90°，右栏同步显示 ITD 与 ILD 的读数。做三件事：

- 双耳线索模式下把频率拖到 500 Hz 与 6 kHz 各听一次——同一个方位，低频那版"方位感"来自两耳波形的细微错位，高频那版来自一耳明显变闷；
- 切到「等功率声像」模式拖底部轨道——L/R 两条电平此消彼长，但**时间差恒为零**：这是混音台旋钮的真实物理；
- 把频率调到 2 kHz 附近、双耳模式转到 60°——读数还在，听感却开始含糊：duplex 缺口亲自验证。

### 实验 2（python）：ITD 随方位角铺开

```python title="从头前到正右方，时间差长到多少"
import math

a = 0.0875    # 头半径（m）
c = 343.0     # 声速（m/s）

for deg in [0, 30, 60, 90]:
    phi = math.radians(deg)
    itd_ms = a / c * (phi + math.sin(phi)) * 1000
    print(f"{deg:>3} deg:  ITD = {itd_ms:.3f} ms")
```

输出 0.000 / 0.261 / 0.488 / 0.656 ms——注意增长**先快后慢**（正弦项在 60° 后趋于饱和），方位角对时间差不是线性映射，正前方附近每转一度的时间差收益最大，这正是人耳对前方小角度偏移格外敏感的几何原因。

### 快问快答

```quiz
低频声音（比如 300 Hz 的低音）的水平方位，人耳主要靠什么线索定位？
- 强度差：低频也被头挡住一大截
- 时间差：低频波长远大于头，相位差清晰无歧义 [*]
- 都不行，低频听不出方位
? 低频波长（300 Hz 约 1.1 m）远大于头径，绕射畅通，两耳强度几乎相同——但相位差清晰可用；高频才主要靠强度差。这就是 duplex theory，也是"低音听不出方向"的严格版：不是没线索，是换了一种线索。
```

::::warning[常见误区]

**误区一**："声像旋钮就是方位控制。"
你以为 pan 打到右 = 声源在右边——它只造了强度差，时间完全同步，听感是"声音从脑内中间滑向右耳"，不是"声音在右前方 30° 的空间里"。真方位需要 ITD 与头相关滤波（HRTF），那是另一套技术。

**误区二**："等功率声像的中间比两边响 3 dB 是 bug。"
你以为 $L = R = 0.707$ 时和信号幅度 1.414 是算错——两路**相关**信号同相相加幅度翻 √2 倍是物理事实。等功率表保证的是**非相关**聆听场景（两音箱分居两侧）总功率恒定；换成线性 pan（$L+R = 1$）会让中间听感凹陷。两种表各有立场，混着用必出怪声。

**误区三**："相位差就是 ITD，直接给两耳加相位就行。"
你以为时间差可以无脑用相位表示——2 kHz 的一个周期只有 0.5 ms，而 ITD 最大 0.66 ms **超过一个周期**：大脑读到"落后 0.3 ms"与"提前 0.2 ms"无法区分，定位彻底混乱。这就是 ITD 只认低频的原因：**频率够低、周期够长，延迟才唯一对应相位**。

::::

## 6. 练习

**练习 1**：头半径 0.0875 m、声速 343 m/s，声源在正右方（90°）。求 ITD（单位 ms，保留 3 位小数）。下面的代码把方位角当弧度直接用了，算出 23 ms 的荒谬答案：

```exercise
# @title: 练习：正右方的双耳时间差
# @check: 0.656
# @hint: Woodworth 公式吃的是弧度：先用 math.radians(deg) 换算，再代入 (a/c)*(phi + sin(phi))
import math

a = 0.0875    # 头半径（m）
c = 343.0     # 声速（m/s）
deg = 90      # 方位角（度）

phi = deg                 # ← 问题在这：三角函数要弧度，不是度
itd_ms = a / c * (phi + math.sin(phi)) * 1000
print(f"{itd_ms:.3f}")
```

修正后：$\varphi = \pi/2$，$ITD = \dfrac{0.0875}{343}(\pi/2 + 1) \approx 0.656$ ms。对比一下把度当弧度的荒谬输出（23 ms，相当于声源绕到 8 米外）：单位守门在声学里不是学究气，0.656 ms 与 23 ms 之间隔着"定位"与"回声"两个世界。

**练习 2**：声源在 60°、频率 5 kHz，ILD 有多少 dB？若把频率换到 1 kHz 呢？

<details>
<summary>点开查看逐步解答</summary>

1. 5 kHz：$0.005 \times 5000 = 25$，顶格取 $20$；$ILD = 20 \times \sin 60° = 20 \times 0.866 = 17.3$ dB——远耳被头影按掉大半能量，线索强劲；
2. 1 kHz：$0.005 \times 1000 = 5$；$ILD = 5 \times 0.866 = 4.3$ dB——头几乎不挡，强度差聊胜于无；
3. 同一方位同一公式，仅因频率不同线索强度差 13 dB——**duplex theory 的量化解**：5 kHz 听 ILD，1 kHz 只能去听 ITD（此处约 0.488 ms）；
4. 混音启示：想让一个乐器"靠边站"，高频成分的 ILD 出力最多；低音乐器横向摆位天生模糊，别指望 pan 救它。

</details>

## 7. 选读：HRTF——把整个头装进滤波器

<details>
<summary>选读 · 从两条线索到两只耳朵的"指纹"</summary>

ITD 与 ILD 只是双耳线索的极简版。真实 ears 收到的信号还叠加了**躯干、外耳廓、头发**对声波的反射与共振——外耳那些沟回像迷宫，不同方向的声源在耳道口留下不同的"频谱签名"，并把脑后与头顶方向的线索补齐。全部滤波效应打包起来就是 **HRTF**（头相关传输函数）：一对随方向变化的复数频率响应，等价于——你已经猜到——**每个方向一条脉冲响应**，播放时与干声做卷积。

这也解释了为什么"耳机的 7.1 声道"容易、而"耳机里的真空间"难：前者只解决"几路信号"，后者要为**每个方向**准备一条 IR，且外耳几何人各不同，通用 HRTF 对一部分人有效、对另一部分人前后颠倒。空间音频的工程史，就是不断给卷积混响（第 110 课）的那条 $h$ 换上"你的头"的过程。

</details>
