# 等响曲线：人耳不平直

## 1. 从一个场景开始

深夜用小音量听歌，你总觉得「没劲」：鼓点软塌塌的，人声倒是清清楚楚。把音量拧大，低音忽然回来了，整个音乐「立体」起来。设备一个字没改，改的只有音量旋钮——**为什么音量小的时候，先消失的偏偏是低音？**

答案不在音箱，在你的耳朵：它对 2000～5000 Hz 出奇地敏感，对 100 Hz 以下和 15 kHz 以上却迟钝得多。而且这份「偏心表」还会随音量变化。上一课的分贝量出了「多响」，这一课要给耳朵本人画一张**体检报告**。

## 2. 直觉解释

想象一个实验（历史上真的做过）：先给你听一个 1 kHz、40 dB SPL 的纯音当参照，再换一个 100 Hz 的音，让你调到「听起来一样响」。你会把它调到约 55 dB SPL 才罢休——**不是你调错了，是耳朵对 100 Hz 天生迟钝 15 dB**。

把所有频率都这么测一遍，连成一条线：这条线上的每个频率，听起来的响度都一样——**等响曲线**。整个 0～120 dB 范围测下来，得到一族曲线。这族曲线有两个标志性形状：

- **两头翘起**：低频端和高频端都要大得多的声压级才追平 1 kHz——耳朵的「不敏感带」在图上隆起；
- **响度级越高越平**：音量很大时，曲线趋于平坦——大音量下耳朵的偏心被「拉直」了。

深夜小音量时你处在最下面那条陡峭的曲线上：低频要追赶的「欠账」最多，所以低音第一个阵亡；音量拧大，曲线变平，欠账缩小，低音复活。**变的是你处在哪条曲线上，不变的是耳朵的形状。**

## 3. 正式定义

**响度级**（单位 phon）：若某声音与 1 kHz、$L$ dB SPL 的纯音听起来一样响，它的响度级就是 $L$ phon。

**等响曲线族**：响度级为定值 $N$ phon 时，声压级 $L_p$ 随频率 $f$ 变化的曲线 $L_p(f)$。按定义，**每条曲线在 1 kHz 处的声压级恰好等于它的响度级**——这是 phon 与 dB SPL 的绑定锚点。

| 量 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $L_p$ | 声压级 | dB SPL | 物理量：压强比的对数（上一课） |
| $N$ | 响度级 | phon | 心理量：与 1 kHz 多少 dB 等响 |
| 听阈曲线 | 0 phon | — | 各频率「刚好能听见」的底线 |
| 痛阈 | 约 120 dB SPL | — | 上限，再响开始疼痛 |

读图要点（数据来自组件的解析近似）：

- **3～4 kHz 最敏感**：听阈最低到约 −5 dB SPL（耳道恰好在这一带共振，天然放大器）；
- **40 phon 曲线上**：100 Hz 要约 **55 dB**、30 Hz 要约 **83 dB**，而 3 kHz 只要 **34 dB**——同一主观响度，物理声压差了百倍；
- **80 phon 时**：100 Hz 只需约 88 dB SPL，欠账缩到约 8 dB（1 kHz 仍是 80 dB）——曲线变平。

**A 计权**：工程上把等响形状固化进测量仪表——低频按「耳朵的迟钝程度」扣分（100 Hz 约扣 19 dB，20 Hz 约扣 50 dB），读数记作 dBA。噪声法规写的都是 dBA，就是为了让仪表「替耳朵偏心」。

## 4. 分步例题

**例**：一间屋子里 40 phon 的声音，1 kHz 与 100 Hz 成分各需多大声压级？声压相差多少倍？

1. **1 kHz**：按定义，40 phon 曲线在 1 kHz 处等于响度级本身，$L_p = 40$ dB SPL；
2. **100 Hz**：查等响曲线（组件近似），约 $L_p \approx 55$ dB SPL；
3. **换算声压倍数**：两处声压之比 $= 10^{(55-40)/20} = 10^{0.75} \approx 5.6$；
4. **结论**：听起来一样响的两个频率成分，100 Hz 的**声压实际是 1 kHz 的 5.6 倍**——分贝差 15，线性世界差 5.6 倍。分贝刻度的「平」掩护着耳朵的「不平」。

## 5. 动手实验

### 实验 1（lab）：亲手抬一抬这族曲线

```lab
{
  "type": "loudness-contour",
  "title": "上下拖动换响度级，横向移动读频率：看等响曲线怎么翘、怎么变平",
  "phon": 40
}
```

横轴是对数频率（20 Hz～10 kHz），纵轴是声压级，一族曲线就是耳朵的「等响地图」。这个组件**故意不出声**：等响曲线要用真实声压级标定（20 µPa 基准加已知灵敏度的耳机），浏览器拿不到回放声压级，硬做「补偿试听」只会骗人——所以它只给你数。做三件事：

- **上下拖动**换响度级：看曲线族整体升降，同时注意曲线**在 1 kHz 处永远穿过「响度级」那个数**（定义锚点）；
- 横向移动到 100 Hz：读出「所需声压级」与「相对 1 kHz」的差——40 phon 下它欠 15 dB 上下；
- 把响度级拖到 80 以上：看欠账收窄、曲线变平——大音量下耳朵接近「平直话筒」，小音量时偏心最重。

### 实验 2（python）：声压翻几倍，响度才翻一倍？

```python title="等响的代价：+N dB 换来多少倍响度感觉"
import math  # 数学库（卷一已引入）

print(" 声压级    声压倍数    响度感觉")
for d in [3, 6, 10, 20]:
    p_times = 10 ** (d / 20)          # 声压倍数：10^(ΔdB/20)
    loud_times = 2 ** (d / 10)        # 响度倍数：约 2^(ΔdB/10)（心理声学幂律）
    print(f"+{d:>2} dB    x{p_times:6.2f}     x{loud_times:5.2f}")
```

对照读这张小表：

- **+6 dB**：声压翻倍，响度感觉只涨约 50%；
- **+10 dB**：声压涨到 3.16 倍，响度感觉**恰好翻倍**——心理声学里响度加倍的经验值就是 +10 dB；
- **+20 dB**：声压十倍，响度才 ×4。

所以等响曲线动辄 15～20 dB 的「低频欠账」，换算成响度感觉是 3～4 倍的落差——深夜小音量时低音的缺席，不是错觉，是这张表写明的。

### 快问快答

```quiz
40 phon 的等响曲线上，1 kHz 对应 40 dB SPL；同一条曲线上 100 Hz 附近大约需要多少声压级？
- 也是 40 dB，等响就是等声压级
- 约 25 dB，人耳对低频更敏感
- 约 55 dB，低频要更大声压才一样响 [*]
? 耳朵对低频迟钝：40 phon 曲线在 100 Hz 处要约 55 dB SPL 才与 1 kHz 的 40 dB 同响。曲线两头翘、1 kHz 处等于响度级。
```

::::warning[常见误区]

**误区一**：「两个声音声压级相同，听起来就一样响。」
你以为分贝相等响度就相等——上一课的结论只对同频率成立。40 dB 的 100 Hz 纯音比 40 dB 的 3 kHz 纯音**轻得多**。声压级是物理刻度，响度要查等响曲线。

**误区二**：「等响曲线是音响设备的缺陷，好设备能把曲线修平。」
你以为曲线属于器材——它属于**你的耳朵**，器材只是提供声压级。所谓「响度补偿/Loudness 按键」，原理恰恰是在小音量时**人为给低频加成**，替耳朵垫付欠账；大音量下反而要关掉它，因为耳朵自己已经变平了。

**误区三**：「phon 和 dB SPL 是同一个东西的两个名字。」
你看到 40 phon 与 40 dB 恰好相等就以为可互换——它们只在 1 kHz 处数值重合，这是**定义**绑定的锚点。换到 100 Hz，40 phon 对应 55 dB SPL，两个数立刻分道扬镳。dB SPL 量物理，phon 量感觉，桥就架在 1 kHz 这一根桩上。

::::

## 6. 练习

**练习 1**：响度级 40 phon 的声音，1 kHz 处的声压是多少帕（保留 3 位小数）？这段代码把声压级公式里的系数用错了：

```exercise
# @title: 练习：40 phon 的 1 kHz 声压
# @check: 0.002
# @hint: 声压 p = p0 · 10^(Lp/20)；指数里的分母是 20（声压级），写成 10 会把声压放大一百倍
p0 = 2e-5      # 基准声压（Pa）
lp = 40.0      # 响度级 40 phon，在 1 kHz 处声压级也是 40 dB SPL
p = p0 * 10 ** (lp / 10)    # ← 问题在这：应该是 lp / 20
print(p)
```

算对之后对照：40 dB SPL 的声压只有 0.002 Pa，是大气压（101325 Pa）的**五千万分之一**——耳朵用这样薄的扰动工作，而它还嫌低频不够响。

**练习 2**：为什么深夜听歌（小音量）觉得「缺低音」，而同一副耳机在白天大音量下低音饱满？用等响曲线的语言完整说一遍。

<details>
<summary>点开查看逐步解答</summary>

1. 小音量时，你坐在**最下面几条等响曲线**上（响度级 20～40 phon）；
2. 低频端的曲线**翘得最厉害**：100 Hz 的欠账有 15～20 dB 以上，而录音里的低音成分声压级本来就与中频相当，于是低于曲线、听不真；
3. 中频（人声、扫弦）落在耳朵最敏感的 2～5 kHz 附近，欠账小，照样清楚——所以「人声清楚、低音消失」；
4. 音量拧大 → 响度级升到 70～90 phon → 曲线变平、低频欠账收窄 → 低音「回来」；
5. 结论：变的不是设备（频响没动），是你所在的**等响曲线从陡峭换到了平坦**。这也是专业混音在中等偏大音量下做、家用欣赏常开「响度」补偿的统一原因。

</details>

## 7. 选读：等响曲线是怎么测出来的

<details>
<summary>选读 · Fletcher–Munson 到 ISO 226</summary>

1933 年 Fletcher 与 Munson 在贝尔实验室用大样本被试做了笨拙而漂亮的实验：给出 1 kHz 某声压级的参照音，再逐个频率让被试调另一个纯音「调到一样响」，记录声压级。换参照级重测，得到曲线族。1983 年 Robinson–Dadson 修订，2003 年 ISO 226 再次修订——每代曲线都在细节上挪动，但「两头翘、高响度变平、3～4 kHz 最敏感」的骨架从未变过。

本课组件用的是对听阈（MAF，最低可听声场曲线）的解析近似，再用随响度级衰减的系数把听阈「翘曲量」贴到各条等响曲线上——不是精确复刻 ISO 226，但三条定性结论与关键数字（100 Hz 在 40 phon 欠约 15 dB）都在正确范围内。

A 计权则是把 40 phon 反曲线的形状做成了滤波器：对 1 kHz 不动，对 100 Hz 衰减约 19 dB，对 20 Hz 衰减约 50 dB。它承认自己只是「平均耳朵」的一阶近似——所以法规里的 dBA 读数，本质上是把物理声压级按人的感受打折后的「耳朵本位制」。

</details>
