# 加法合成：音色是拼出来的

## 1. 从一个场景开始

上一课解决了「音怎么起落」，还剩另一半谜题：钢琴与长笛同时发 440 Hz 的音，音高、响度都一样，听起来还是不一样——为什么？

16 章的傅里叶级数给过答案的一半：**任何周期信号都能拆成一串正弦之和**。当时我们在「拆」——拿到复杂波形，求系数。现在把方向倒过来：给你一堆正弦和一张幅度配方单，**拼**出一个音色。拆解是分析，拼装是合成——这一课玩的是后者，也是最直观的一种：加法合成。

## 2. 直觉解释

把基频 $f$ 的整数倍想象成一座楼梯：$f, 2f, 3f, 4f, \dots$，每一级叫一个**谐波**。一个音色的秘密，就是**每级楼梯上放多重的正弦**——这张「幅度配方单」决定音色：

- 只放第 1 级 → 纯正弦，像音叉，干净但寡淡；
- 奇数级放 $1/n$，偶数级放 0 → **方波**，空洞明亮（16 章 40 课见过它的波形与 Gibbs 现象）；
- 奇数级放 $1/n^2$ → **三角波**，柔和近似正弦；
- 全部级放 $1/n$ → **锯齿波**，明亮饱满，弦乐器的常用原料。

管风琴是最古老的加法合成器：一排音管里，比主音管高八度、十二度的辅助音管齐鸣，就是在手动执行这张配方单。电子合成器只是把音管换成了振荡器。

## 3. 正式定义

**加法合成**：把若干个谐波正弦按指定幅度叠加成一个周期音色：

$$y(t) = \sum_{n=1}^{N} a_n \sin(2\pi n f t)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f$ | 基频 | 第 1 次谐波的频率，决定音高 |
| $n$ | 谐波次数 | 第 $n$ 次谐波的频率是 $nf$ |
| $a_n$ | 谐波幅度 | 配方单第 $n$ 行：第 $n$ 级放多重，$0 \le a_n \le 1$ |

三条口径：

1. **配方决定音色，基频决定音高**——同一张配方换基频，音色不变、音高平移；
2. 相位 $\varphi_n$ 也能进公式，但**人耳对相位几乎不敏感**，音色设计里通常不管它；
3. $N$ 取有限项是近似：项数越多波形边缘越陡。8 个谐波已足够让耳朵认出「这是方波」。

## 4. 分步例题

**例**：按方波配方（奇次、$a_n = 1/n$）取前 4 个奇次谐波，问 $t = T/4$ 处合成值是多少？

1. **确定时刻**：取 $T=1$，则 $t = 0.25$，第 $n$ 次谐波的相位角是 $2\pi n \times 0.25 = \dfrac{n\pi}{2}$；
2. **逐项求值**：$\sin\dfrac{n\pi}{2}$ 对 $n=1,3,5,7$ 依次是 $+1, -1, +1, -1$——谐波自带正负号；
3. **加权求和**：
   $$y = 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} = 0.7238$$
4. **对照真方波**：理想方波在 $T/4$ 处是 1，差了约 28%——这是 16 章 Gibbs 现象在采样上的样子。把 $n=9,11,13,\dots$ 继续加上去，这个值会一步步爬向 1。

**符号交替不是巧合**：偶次谐波幅度为零，奇次谐波的正负恰好把波形「压」出上下平顶——配方单上的正负号，就是波形的形状。

## 5. 动手实验

### 实验 1（lab）：拖杆搭音色，频谱当场对账

```lab
{
  "type": "harmonic-builder",
  "title": "照方波的配方拖杆：只留奇次、幅度 1/n",
  "base": 220,
  "nH": 8,
  "amps": [1, 0, 0.333, 0, 0.2, 0, 0.143, 0]
}
```

上图是叠加出的波形，下图一排杆是配方，橙色曲线是对合成波形做 FFT 的**实测谱**。做三件事：

- 预设选「方波」，核对波形：上下平顶、正负对称；
- 把 3 次谐波的杆拖到 0：波形立刻歪掉——**少一行配方，音色就换一种人**；
- 「清零」后只拉起 1 次谐波：纯音叉回来了。再逐级拉起 3、5、7 次，听音色一步步「变亮」。

橙色实测谱应当始终落在杆顶上——设了什么幅度，频谱里就真的只有那些频率。这是傅里叶级数最实在的一次「眼见为实」。

### 实验 2（python）：自己拼一个周期的方波

```python title="按配方叠加谐波，打印一个周期的采样值"
import math

ks = [1, 3, 5, 7]              # 方波只含奇次谐波
amps = [1/k for k in ks]       # 方波配方：幅度 1/n

for i in range(8):             # 一个周期采 8 个点
    t = i / 8
    y = 0.0
    for m in range(len(ks)):   # 逐项叠加：幅度 × 正弦
        y = y + amps[m] * math.sin(2 * math.pi * ks[m] * t)
    print(f"t={t:.3f}  采样值 = {round(y, 3)}")
```

八个采样值是 0.0、0.7、0.724、0.7、0.0、−0.7、−0.724、−0.7——一个「圆胖的方块」：正负对称（方波该有的样子），中间那对 0.724 正是第 4 节手算的值。把 `ks` 换成 `[1, 2, 3, 4]`、`amps` 换成 `[1/k for k in ks]` 再跑一遍，就得到了锯齿波——配方一换，音色跟着换。

### 快问快答

```quiz
方波的谐波配方是下面哪一种？
- 只有奇次谐波，幅度按 1/n 递减 [*]
- 所有谐波都有，幅度按 1/n 递减
- 只有偶次谐波，幅度全部相同
? 方波正负半周反对称，偶次谐波逐点抵消为零，只剩 1、3、5、… 次且幅度 1/n——这正是 lab 里「方波」预设的配方。
```

::::warning[常见误区]

**误区一**："谐波越多，音色一定越像。"
你以为 12 个谐波总比 8 个好——其实人耳的频率分辨力有限，8 个以上谐波的边际贡献很小。近似要为耳朵服务，不为波形图服务。

**误区二**："幅度可以是负数，表示「反着响」。"
你以为负幅度是另一种玩法——其实负幅度等价于该谐波相位反转 180°，而人耳对相位不敏感，听感几乎无差。配方单用 0 到 1 的正数就够。

**误区三**："加法合成太笨重，没人真用。"
你以为它只是教具——其实管风琴的音管组、电子琴的叠加音色、游戏机芯片音乐都是加法思路；而下一课的滤波器要先把锯齿波这种「谐波齐全」的原料造出来再砍。加法是理解一切音色的坐标系。

::::

## 6. 练习

**练习 1**：按方波配方取前 4 个奇次谐波，算 $t = T/4$ 处的合成值。输出应为 `0.724`。这段代码把各谐波的符号弄丢了：

```exercise
# @title: 练习：方波配方在四分之一周期处的取值
# @check: 0.724
# @hint: t=T/4 时第 n 次谐波的相位是 nπ/2，正弦值在 +1 与 −1 间交替——用 math.sin 让符号自己出来。
import math

ks = [1, 3, 5, 7]              # 前 4 个奇次谐波
amps = [1/k for k in ks]       # 方波配方：幅度 1/n
t = 0.25                       # 一个周期取 T = 1
y = 0.0
for m in range(len(ks)):
    y = y + amps[m]            # ← 问题在这：只加了幅度，没算每个谐波的相位贡献
print(round(y, 3))
```

**练习 2**：三角波的配方是奇次、$a_n = 1/n^2$。取前 4 个奇次谐波（$n = 1, 3, 5, 7$），算 $t = T/4$ 处的合成值。

<details>
<summary>点开查看逐步解答</summary>

1. 同样取 $T=1$、$t=0.25$，各次谐波的正弦值依次 $+1, -1, +1, -1$；
2. 幅度是 $1, 1/9, 1/25, 1/49$；
3. 合成 $y = 1 - \dfrac{1}{9} + \dfrac{1}{25} - \dfrac{1}{49} = 0.9085$；
4. 这个级数无限加下去收敛到卡特兰常数 $G \approx 0.9160$（17 章之后数学篇的老朋友）。对比真三角波在 $T/4$ 处的 1，只差 8%——$1/n^2$ 比 $1/n$ 收敛快得多，所以**三角波比方波「更接近」它的理想形**，听感也更柔和。

</details>

## 7. 选读：方波配方是算出来的，不是背出来的

<details>
<summary>选读 · 回到傅里叶系数</summary>

16 章 30 课的系数公式是 $a_n = \dfrac{2}{T}\displaystyle\int_0^T y(t)\sin(2\pi n f t)\,dt$。把理想方波（前半周期 +1、后半周期 −1）代进去：对偶数 $n$，正弦在前后半周各完成整数个摆动，积分正负相消为零；对奇数 $n$，两个半周贡献同号，积出 $a_n = 4/(n\pi)$，归一化到基波就是 $1/n$。

所以「奇次 1/n」不是经验口诀，而是**一次积分的结论**。同样地，三角波对偶数 $n$ 也是零，奇数 $n$ 积出 $8/(n^2\pi^2)$，归一化即 $1/n^2$——收敛快一档，波形就圆润一档。配方单的每一行，都是傅里叶分析替你预先算好的。

</details>
