# 拍频与音程

## 1. 从一个场景开始

调琴师给钢琴调音，从不看仪器：按下两个键，侧耳听——「还有拍，再紧一点」。两根弦的音高已经非常接近，可一起响起来时，声音却一鼓一鼓地起伏：「呜——哇——呜——哇」，像有人在慢速地推拉音量旋钮。

[07 章的《拍频》](../07-trigonometry/50-beats.md)我们已经算过这个现象的数学形状。这一次，它不只是纸面上的一道三角题——你可以亲手把它拖出来、听出来，还要用它回答一个音乐里最基本的问题：**两个音「和谐」与否，原来是频率比说了算。**

## 2. 直觉解释

两个频率相近的正弦波叠加，有时步调一致（同相，响度翻倍），有时步调相反（反相，互相抵消）。它们「一致」与「相反」交替出现的节奏，就是拍：

$$f_{拍} = |f_2 - f_1|$$

- 两支音叉 440 Hz 与 443 Hz → 每秒 3 拍；
- 差值越大，鼓包越密：超过约 20 Hz，一鼓一鼓的感觉消失，变成「粗糙」；再大就干脆听成两个分开的音。

为什么会这样？把两条正弦相加，用 07 章的和差化积：

$$\sin(2\pi f_1 t) + \sin(2\pi f_2 t) = 2\sin\!\big(2\pi \tfrac{f_1+f_2}{2} t\big)\cos\!\big(2\pi \tfrac{f_2-f_1}{2} t\big)$$

右边是「平均频率的快波 × 差值一半频率的慢包络」——**快波决定音高，慢波决定响度**。慢包络的绝对值每秒起伏 $|f_2-f_1|$ 次，这就是你听到的拍。

## 3. 正式定义

**拍频**：两个频率 $f_1$、$f_2$ 的纯音叠加，合成振幅以

$$f_{拍} = |f_2 - f_1|$$

的速率周期性涨落。

**音程**：两个音高之间的关系，用**频率比** $r = f_2/f_1$ 度量。悦耳的音程往往对应简单的整数比：

| 音程 | 频率比 | 听感 |
| --- | --- | --- |
| 同度 | 1:1 | 完全融合 |
| 纯四度 | 4:3 | 稳定 |
| 纯五度 | 3:2 | 稳定，最「空旷」 |
| 大三度 | 5:4 | 明亮 |
| 八度 | 2:1 | 听起来「是同一个音」 |

**音分**：把八度切成 1200 份的对数刻度，任意比的音分数为

$$n = 1200 \log_2 r$$

半音 = 100 音分。等程律取半音比为 $2^{1/12} \approx 1.0595$，所以等程纯五度是 700 音分，而真实的 3:2 是 702 音分——差 2 音分，人耳勉强能察觉，这就是钢琴「所有调都准、也都不完全准」的由来。

## 4. 分步例题

**例**：吉他手调弦：6 弦空弦按品格后应发 440 Hz，调音器实测 438 Hz。两根弦一起拨响会怎样？

1. **拍频**：$|440 - 438| = 2$，每秒 2 个鼓包——慢而清晰的「呜—哇」；
2. **调弦方向**：把弦调紧一点点，频率升向 440，拍变慢；完全重合时拍消失，调准了；
3. **复核音分差**：$1200\log_2(440/438) = 1200 \times 0.00662 \approx 8$ 音分——不到十分之一个半音，但拍把它放大成了听得见的「呼吸」。

**拍是极高精度的耳朵**：它把 8 音分的差异（约 0.5%）变成每秒 2 次的起伏（约 2 Hz 的慢信号），人耳对慢节奏的敏感远超对频率微差的敏感。

## 5. 动手实验

### 实验 1（lab）：把 f₂ 拖开，亲耳数拍

```lab
{
  "type": "beats-audio",
  "title": "拖动 f₂ 听拍：先数每秒几拍，再拖到听不出拍为止",
  "f1": 220,
  "df": 3
}
```

点「▶ 播放」，做三件事：

- 现在每秒 3 拍——跟着鼓包默数，验证 $f_{拍} = |f_2 - f_1|$；
- 把 f₂ 慢慢拖开：鼓包变密，超过约 20 Hz 后「一鼓一鼓」变成粗糙的嗡嗡声；
- 拖到差不多的整数比上（读数会提示「最近音程」），比如 3:2——拍消失了，只剩一个干净稳定的音。**和谐的本质是拍消失**。

### 实验 2（python）：把鼓包打印出来

```python title="两支音叉叠加：响度包络每秒 4 次起落"
import math

f1, f2 = 440.0, 444.0          # 相差 4 Hz → 应该每秒 4 拍

for k in range(9):
    t = k * 0.125              # 每八分之一秒看一眼
    env = 2 * abs(math.cos(2 * math.pi * 2 * t))   # 慢变的响度包络
    print(f"t={t:5.3f} s  响度包络 ≈ {round(env, 2)}")
```

九行输出在 2.0 与 0.0 之间交替：包络每 0.25 秒隆起一个鼓包，一秒正好 4 个——与拍频 4 Hz 严丝合缝。注意 0.0 与 2.0 之间不会出现别的数：鼓包与鼓包之间真的有一段完全安静的「节点」，这正是拍听起来一鼓一鼓的原因。

### 快问快答

```quiz
两支音叉分别发出 440 Hz 和 443 Hz，一起敲响，你听到的是什么？
- 每秒 3 次的强弱起伏 [*]
- 一个 883 Hz 的更高音
- 一个 3 Hz 的低音
? 拍频 = |443 − 440| = 3，合成振幅每秒涨落 3 次；快波决定音高（约 441.5 Hz），慢波决定响度。差值超过约 20 Hz 时拍才会消失。
```

::::warning[常见误区]

**误区一**："拍频是两个频率的平均。"
你以为 440 和 444 叠加听到 442 Hz 的音量恒定的音——其实音高部分确实是平均频率 442 Hz，但**响度在以差值 4 Hz 起伏**。拍不在音高里，在响度里。

**误区二**："差 2 Hz 的两个音听不出区别。"
你以为耳朵分辨不出 440 与 442——单独听确实难，但**一起听**时 2 Hz 的拍清晰可数。调琴师靠的不是分辨两个音，而是分辨它们的拍。

**误区三**："和谐是玄学，因人而异。"
你以为「好听」没有道理——其实简单整数比（3:2、4:3）的音程叠加时，谐波几乎逐条对齐，不产生持续拍；而复杂比（如 45:32）会产生大量慢拍，听感粗糙。和谐有物理基础，只是「喜欢」还有文化层。

::::

```exercise
beats = f2 - f1    # ← 问题在这：这只是 1 秒的拍数
print(beats)
```

**练习 2**：(a) 大三度的频率比是 5:4，它合多少音分？(b) 若基音是 220 Hz，三音是多少赫兹？

<details>
<summary>点开查看逐步解答</summary>

1. 音分 $n = 1200\log_2(5/4) = 1200 \times 0.32193 \approx 386$ 音分；
2. $f_2 = 220 \times 5/4 = 275$ Hz；
3. 顺带一验：等程大三度是 400 音分，比纯律的 386 音分**宽了 14 音分**——所以在大一和弦里，纯律的三音听起来更「甜」，这也是合唱团会自发往纯律靠的原因。

</details>

## 7. 选读：为什么等程律要放弃纯律

<details>
<summary>选读 · 2 的 1/12 次方与 3:2 的妥协</summary>

纯律音程好听，但没法循环：从 C 出发按 3:2 连升 12 次纯五度，得到的频率是 $(3/2)^{12} \approx 129.75$ 倍；而升 7 个八度只有 $2^7 = 128$ 倍。差了约 1.4%——「五度圈」转一圈回不了家。

等程律的解法是平均分配：让每个半音都等于 $2^{1/12}$，则 12 个半音恰好凑成一个八度，五度圈闭合。代价是每个纯五度从 702 音分被压到 700 音分，拍很轻微地存在着。**钢琴是用「处处都不完美」换「处处都能转调」**。

巴赫《平均律键盘曲集》正是这套体系的艺术宣言：任何调都能用，转调自由了，音乐的调性版图从此铺开。

</details>
