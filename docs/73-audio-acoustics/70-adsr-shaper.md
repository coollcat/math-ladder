# 包络 ADSR：声音的骨架

## 1. 从一个场景开始

电子琴与钢琴弹同一个中央 A，音高一样，响度也调到一样——可任何人闭着眼都能分清哪个是钢琴。差别在哪？不在「响不响」，而在**响度怎么随时间变化**：钢琴是「当」地一下砸出来、随即开始消退；小提琴是「拉」出来的，能稳稳站住，收弓时才离开。

如果把音量随时间的曲线画出来，乐器的「性格」就全在这条曲线上。这条曲线叫**包络**，合成器行业把它的四个抓手缩写成四个字母：ADSR。

## 2. 直觉解释

把一个音想象成开关一扇带缓冲的门：

- **A（Attack 起音）**：撞门的那一瞬间——多快从安静冲到最响？0.005 秒是敲击，0.35 秒是拉弓；
- **D（Decay 衰减）**：门的回弹——冲到峰值后掉多少、掉多快；
- **S（Sustain 延音）**：你推住门不让它关——按住琴键期间维持在什么**电平**；
- **R（Release 释放）**：松手——门缓缓合上要多久。

四个数一摆，音的「骨架」就定了：钢琴 $S=0$（没有延音，声音自己消失），管风琴 $S \approx 1$（按住多久响多久）。**音高是频率的事，音色的一半是包络的事**——这正是合成器能靠几个旋钮伪装千万种乐器的原因。

## 3. 正式定义

**包络**（envelope）：一个音的振幅随时间变化的分段函数 $e(t)$，ADSR 把它切成四段：

| 段 | 参数 | 含义 | 单位 |
| --- | --- | --- | --- |
| 起音 | $A$ | 从 0 冲到峰值的时长 | 秒 |
| 衰减 | $D$ | 从峰值掉到延音电平的时长 | 秒 |
| 延音 | $S$ | 按住期间维持的**电平**（占峰值的比例） | 0–1，无量纲 |
| 释放 | $R$ | 松手后从延音电平掉回 0 的时长 | 秒 |

分段表达式（设峰值 1）：

$$e(t)=\begin{cases} t/A, & 0 \le t < A \\[2pt] 1-(1-S)\dfrac{t-A}{D}, & A \le t < A+D \\[2pt] S, & A+D \le t < A+D+T_{hold} \\[2pt] S\left(1-\dfrac{t-A-D-T_{hold}}{R}\right), & A+D+T_{hold} \le t < A+D+T_{hold}+R \end{cases}$$

两个要点：

1. **$S$ 是电平，不是时间**。$A/D/R$ 是「多久」，$S$ 是「多响」——这是 ADSR 里最容易搞混的一处；
2. 打击类乐器（钢琴、拨弦）$S=0$：松不松手，声音都自己衰减；持续类乐器（管风琴、弦乐）$S$ 接近 1。

一个音的**总可闻时长**是 $A + D + T_{hold} + R$ 四段之和（$S$ 不占时长）。

## 4. 分步例题

**例**：弦乐预设 $A=0.35$，$D=0.2$，$S=0.8$，$T_{hold}=0.6$，$R=0.9$。问 $t=1.6$ s 时包络值是多少？

1. **定位段**：$A+D = 0.55$，$A+D+T_{hold} = 1.15$，$A+D+T_{hold}+R = 2.05$。$t=1.6$ 落在 $[1.15,\ 2.05)$ → **释放段**；
2. **进入释放多久**：$1.6 - 1.15 = 0.45$ s；
3. **线性下降**：$e = S\left(1 - \dfrac{0.45}{0.9}\right) = 0.8 \times 0.5 = 0.4$；
4. **解读**：松手 0.45 秒后还剩峰值 40% 的响度——弦乐的余韵比钢琴长得多（钢琴的 $S=0$，释放段从 0 开始，早就安静了）。

再验总时长：$0.35+0.2+0.6+0.9 = 2.05$ s——松手后 0.9 秒才完全安静。

## 5. 动手实验

### 实验 1（lab）：四个抓手，四种乐器

```lab
{
  "type": "adsr-shaper",
  "title": "切换预设听音头，再拖包络上的把手改性格",
  "preset": "弦乐"
}
```

上半是包络，下半是**实测输出电平**的滚动示波器——照着包络真发声，两条形状对得上。做三件事：

- 切到「钢琴」再切回「弦乐」：前者 $S=0$ 一泻到底，后者按住时稳稳一条平台线；
- 把弦乐的 A 把手拖到接近 0：拉弓变成敲击——**只动一个参数，乐器就换了一种身份**；
- 把 R 拖长：松手后的「尾巴」明显拖长，读数里的总时长跟着涨。

### 实验 2（python）：分段函数算包络

```python title="t 时刻包络值：弦乐预设的四段函数"
A, D, S, R, hold = 0.35, 0.2, 0.8, 0.9, 0.6   # 弦乐预设

def envelope(t):
    if t < A:                        # 起音：从 0 爬到峰值 1
        return t / A
    if t < A + D:                    # 衰减：从 1 掉到延音电平 S
        return 1 - (1 - S) * (t - A) / D
    if t < A + D + hold:              # 延音：按住不动
        return S
    if t < A + D + hold + R:          # 释放：从 S 掉回 0
        return S * (1 - (t - A - D - hold) / R)
    return 0.0                       # 早就松手了：安静

for t in [0.05, 0.175, 0.45, 0.8, 1.6, 2.5]:
    print(f"t={t:4.2f} s  包络 = {round(envelope(t), 2)}")
```

六行输出依次是 0.14、0.5、0.9、0.8、0.4、0.0：起音爬坡（0.14 → 0.5）、衰减回落（0.9）、延音平台（0.8）、释放收尾（0.4 → 0.0）——与第 4 节手算的 $t=1.6$ 处 0.4 完全一致。注意 $t=2.5$ 已经超出总时长 2.05 s，所以是 0.0。

### 快问快答

```quiz
ADSR 四个参数里，哪一个不是「时间」，而是「电平」？
- A（起音）
- S（延音） [*]
- R（释放）
? S 是按住琴键期间维持的响度电平（占峰值的比例），持续多久由 hold 决定；A、D、R 都是时长。钢琴 S=0 一泻到底，管风琴 S≈1 按住就响。
```

::::warning[常见误区]

**误区一**："S 是延音持续的秒数。"
你以为 S=0.8 表示延音 0.8 秒——其实 S 是**电平**（峰值的 80%），持续多久由你按住琴键的时长（hold）决定。ADSR 里三个是时间、一个是比例。

**误区二**："包络就是音色。"
你以为把钢琴的包络贴到正弦波上就像钢琴了——其实钢琴的「当」还来自谐波结构随时间的变化（高频成分衰减得比低频快）。包络是音色的一大半，但不是全部；下一课讲另一半。

**误区三**："起音越短越好，干脆利落。"
你以为 A=0 最爽利——其实起音过陡会让波形骤变，产生「咔哒」的爆音（宽带瞬态），还可能削波失真。真实的弦乐起音 0.1–0.4 秒，是音色温润的来源，不是缺陷。

::::

## 6. 练习

**练习 1**：钢琴预设 $A=0.005$，$D=1.4$，$S=0$，$T_{hold}=0.2$，$R=0.35$。敲一下琴键，这个音从响到完全消失一共多久？输出应为 `1.955`。这段代码忘了算「松手之后」：

```exercise
# @title: 练习：钢琴一个音能响多久
# @check: 1.955
# @hint: 总时长 = A + D + hold + R 四段全加；松手后琴弦还要余响 R 秒。
A = 0.005      # 起音（s）
D = 1.4        # 衰减（s）
S = 0.0        # 延音电平：钢琴没有延音
hold = 0.2     # 保持（s）
R = 0.35       # 释放（s）
total = A + D + hold      # ← 问题在这：还差释放段
print(round(total, 3))
```

**练习 2**：管风琴预设 $A=0.04$，$D=0.05$，$S=0.95$，$T_{hold}=0.8$，$R=0.12$。按住 3 秒再松手，问：松手瞬间与再过 0.06 秒的包络值各是多少？

<details>
<summary>点开查看逐步解答</summary>

1. 按住 3 秒早已进入延音平台（$A+D=0.09$ 秒就到了）：松手瞬间包络 $= S = 0.95$；
2. 松手后 0.06 秒，处于释放段（$R=0.12$，才走一半）：$e = 0.95 \times (1 - 0.06/0.12) = 0.475$；
3. 对比钢琴：同样松手，钢琴的包络本来就因 $S=0$ 而近乎无声——**持续乐器的生命在延音段，打击乐器的生命在音头**，这条分界就是 $S$ 是否为 0。

</details>

## 7. 选读：真实的衰减是指数，不是直线

<details>
<summary>选读 · 为什么 D 段画成斜线是一种近似</summary>

自由振动的琴弦，能量主要通过空气辐射与支撑点耗散，单位时间损失的能量与当前能量成正比——这正是指数衰减的微分方程（22 章的老朋友），声压按 $e^{-t/\tau}$ 掉下去，**按分贝计是线性的**：每过同样的时间就掉同样的 dB。

ADSR 用直线段近似它，是工程上的取舍：几段直线足够骗过耳朵，参数又直观好调。专业的采样回放（sampler）则直接录制真实乐器的自然衰减，或在 D 段后接一条指数尾巴。所以当你拖 lab 里的 D 把手时不妨想想：你调的不是「物理」，而是「耳朵愿意相信的物理」。

</details>
