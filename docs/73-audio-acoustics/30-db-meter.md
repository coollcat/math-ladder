# 振幅、声压级与分贝

## 1. 从一个场景开始

翻开环境噪声标准，你看到的不是「压强多少帕」，而是一串奇怪的数：图书馆 40、地铁进站 90、喷气式起飞 130——单位都是 **dB**（分贝）。

为什么不用帕斯卡直接量？因为耳朵的工作范围太离谱了：从能听见的极限（压强起伏约千万分之一大气压）到让人刺痛的巨响，**声压差了上百万倍**。用线性刻度，就像用毫米尺量地球到月亮的距离——数字大到失去直觉。对数登场了：第 03 章那把「把乘法压成加法」的尺子，恰好也是**耳朵自己感知响度的方式**。

## 2. 直觉解释

分贝不测任何新的物理量，它只是一种**记倍数的方式**：

- 振幅翻一倍 → 加 6 dB；
- 振幅十倍 → 加 20 dB；
- 振幅减半 → 减 6 dB；
- 振幅百分之一 → 减 40 dB。

在「倍数」的世界里，串联的乘法变成分贝的加法：先翻一倍再翻十倍，就是 6 + 20 = +26 dB。所以工程师调音台上的推子、声级计上的读数全是分贝——**加减法就能算乘除法**。

更妙的是，这把尺子跟耳朵的感觉对得上号。第 20 课说过音高是对数的（频率翻倍才升一个八度）；响度也一样——声压要翻好几倍，你才觉得「响了一点点」。**分贝不是数学家强加的记法，而是耳朵本来就活在对数世界里**。这是全章最漂亮的一次呼应：第 03 章学对数时你拿到的是一支笔，现在耳朵告诉你这支笔是它发明的。

## 3. 正式定义

**声压级**（Sound Pressure Level，SPL）：把声压 $p$ 与基准声压 $p_0$ 的比取对数：

$$L_p = 20 \cdot \lg\!\left(\frac{p}{p_0}\right) \ \text{dB}, \qquad p_0 = 20\ \mu\text{Pa} = 2\times10^{-5}\ \text{Pa}$$

$p_0$ 取的是**健康年轻人 1 kHz 的平均听阈**——所以 $0\ \text{dB SPL}$ 不是「没有声音」，而是「刚好能听见」。

**振幅比的分贝**（信号处理里更常用）：振幅 $a$ 相对参考振幅的比值，用

$$\text{dB} = 20 \cdot \lg\!\left(\frac{a}{a_{\text{ref}}}\right)$$

**为什么是 20 不是 10**：耳朵和扬声器关心的是**能量**，而声强正比于压强的**平方**。功率比用 $10\lg$，压强/振幅比是功率比的平方根，$\lg(\sqrt{x}) = \frac{1}{2}\lg x$，系数翻倍成 20。（选读里有完整推导。）

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $p$ | 声压 | Pa | 压强偏离大气压的幅度（第 10 课的 $\Delta p$） |
| $p_0$ | 基准声压 | 20 µPa | 1 kHz 听阈，分贝刻度的零点 |
| $L_p$ | 声压级 | dB SPL | 听得到的刻度读数 |
| a | 振幅（相对） | — | 波形起伏的幅度，与 $\Delta p$ 同角色 |

几把对齐直觉的刻度：0 dB SPL 听阈、40 dB 图书馆、60 dB 交谈、90 dB 地铁、120 dB 痛阈。**声压级每加 20 dB，声压就是 10 倍；每加 6 dB，声压翻一倍**——读完这张表，第 2 节的四条口诀全在眼前。

## 4. 分步例题

**例**：正常交谈的声压约 $p = 20$ mPa = $2\times10^{-2}$ Pa。求声压级。

1. **列比值**：$\dfrac{p}{p_0} = \dfrac{2\times10^{-2}}{2\times10^{-5}} = 10^{3}$；
2. **取常用对数**：$\lg(10^{3}) = 3$；
3. **乘 20**：$L_p = 20 \times 3 = 60$ dB SPL；
4. **反向练一次**：60 dB 的声音，声压是听阈的 $10^{60/20} = 10^3$ 倍——一千倍，可耳朵只觉得「比耳语响一些」。对数刻度把一百万倍的跨度压成了 0～120 的表盘。

## 5. 动手实验

### 实验 1（lab）：线性条挤成一团，对数条均匀铺开

```lab
{
  "type": "db-meter",
  "title": "拖振幅看三条带：上面挤成一团，中间均匀铺开——分贝为什么是对数尺子",
  "amp": 0.5
}
```

三条带子从上到下：① 线性振幅条（1 / 0.5 / 0.1 / 0.01 的刻度全挤在最左边一小段）；② 分贝条（同样的点变成 0 / −6 / −20 / −40 dB，**分布均匀**）；③ 换算曲线 dB = 20·lg a。做四件事：

- 在①里横向拖：想凑到左边那几个小刻度，手感「难挤」；换到②里拖：同样的目标手感均匀——**两种手感，同一组数**；
- 点 **×2** 按钮：听！声音没变尖，只变响了一档，读数精确地 +6.02 dB；
- 连点 **×10**：每次 +20 dB，乘法被钉死成了加法；
- 把振幅拖到 0.01 附近再拖回去，体会「分贝条上相邻刻度永远等距」与「线性条上越来越挤」的对照。

### 实验 2（python）：采样一段正弦，亲手算出它的分贝

```python title="对一段波形求有效值（RMS），再换成 dB"
import math  # 数学库（卷一已引入）

amp = 0.5                      # 波形振幅（相对满幅 1.0）
N = 1000                       # 采样点数
total = 0.0
for k in range(N):
    v = amp * math.sin(2 * math.pi * k / N)   # 采样一个完整周期
    total += v * v                            # 累计平方
rms = math.sqrt(total / N)                    # 均方根：有效振幅
print(f"峰值振幅 = {amp}    有效值 RMS = {round(rms, 4)}")
print(f"相对满幅的电平 = {round(20 * math.log10(rms), 2)} dB")
```

两个输出都值得嚼一嚼：

- **RMS = 0.3536**，恰好是 $0.5/\sqrt{2}$——正弦波的「有效振幅」总比峰值小，因为波形大部分时间在半山腰晃、只在瞬间碰到峰值。音响上的「功率」都按 RMS 计，这正是「有效值」的含义；
- **电平 ≈ −9.03 dB**：$20\lg(0.3536) = 20\lg(0.5/\sqrt2) = -6.02 - 3.01$。满幅 1.0 记作 0 dB，所以振幅 0.5 的正弦在电平表上读到 −9 dB——数字音频里的 dBFS 刻度就是这么来的。

### 快问快答

```quiz
一段音频的振幅变为原来的十分之一，用分贝表示电平下降了多少？
- 下降 1 dB
- 下降 10 dB
- 下降 20 dB [*]
? 振幅比用 20·lg：lg(0.1) = −1，20 × (−1) = −20 dB。乘除法在分贝世界里就是加减法。
```

::::warning[常见误区]

**误区一**：「dB 是一个绝对单位，100 dB 就是一个固定的声音。」
你以为分贝像米和千克一样自成一格——其实它是**比值**，必须带参考点才算数。dB SPL 以 20 µPa 为零点，数字音频的 dBFS 以满幅为 0，天线工程的 dBm 以 1 mW 为零点。同一个「90 dB」，参考不同含义完全不同；环境噪声标着 dB 不写参考时，约定俗成指 dB SPL。

**误区二**：「0 dB 就是安静得一点声音都没有。」
你以为 0 dB 是「无声」——它只是**等于基准**：20 µPa 的 1 kHz 正弦，恰好是健康人耳的平均听阈。比这更弱的声波真实存在，只是记成负分贝（ whale 的低鸣在水下可低至远小于 0 dB SPL 的参考，只是空气参考换不过来）。

**误区三**：「声音大了 3 dB，听起来响了一倍。」
你以为分贝翻倍等于响度翻倍——3 dB 只是**功率**翻倍（振幅 ×$\sqrt2$），耳朵几乎察觉不出。主观响度感觉要翻一倍，实测大约需要 +10 dB，也就是声压三倍多。分贝是物理刻度，响度是心理刻度，两者只在对数这点上同构。

::::

## 6. 练习

**练习 1**：振幅变为参考值的一半，电平下降多少 dB（保留 1 位小数）？这段代码用错了系数：

```exercise
# @title: 练习：振幅减半是多少 dB
# @check: -6.0
# @hint: 振幅（声压）比的分贝用 20·lg；10·lg 那个系数是给功率比用的
import math  # 数学库（卷一已引入）

a = 0.5    # 振幅变为参考的一半
db = 10 * math.log10(a)    # ← 问题在这：振幅比要用 20·lg
print(round(db, 1))
```

把这个 −6 dB 记牢：它是音频工程里出现频率最高的一个数。「调低一格 ≈ 掉 6 dB ≈ 声压减半」。

**练习 2**：痛阈约 120 dB SPL。求痛阈处的声压，是听阈（0 dB SPL，即 20 µPa）的多少倍？

<details>
<summary>点开查看逐步解答</summary>

1. 由定义反解：$p = p_0 \cdot 10^{L_p/20}$；
2. $p = 2\times10^{-5} \times 10^{120/20} = 2\times10^{-5} \times 10^{6} = 20$ Pa；
3. 与听阈之比 $= 10^6$——**一百万倍**。20 Pa 听起来只是「刺痛」，而不是「压强相当于两米深水底」：因为 20 Pa 相对 101325 Pa 的大气压，依然只是万分之二的小涟漪。声音的物理舞台，整个搭在大气压这个底座上薄得惊人的表皮里。

</details>

## 7. 选读：为什么振幅用 20、功率用 10

<details>
<summary>选读 · 平方关系给系数翻倍</summary>

贝尔的定义来自**功率**比：$\lg(P/P_0)$ 的单位是贝尔，十分之一是分贝，所以功率比的分贝是

$$10\lg\frac{P}{P_0}\ \text{dB}$$

耳朵与扬声器响应的是能量流（声强 $I$），而声强正比于声压的平方：$I \propto p^2$（可从 $I = p^2/(\rho v)$ 看出，$\rho$ 是空气密度、$v$ 是声速）。于是声压比的分贝

$$10\lg\frac{I}{I_0} = 10\lg\left(\frac{p}{p_0}\right)^{2} = 20\lg\frac{p}{p_0}$$

系数从 10 变成 20，不是新发明了一等单位，只是**同一把功率尺子量的对象换成了平方根**。信号处理同理：采样数据的「能量」是振幅平方和（第 5 节实验里的 `v*v` 再累加），所以振幅比换 dB 一律乘 20。记住配对口诀：**功率 10、振幅 20**，看到系数就能反推它量的是哪个量。

</details>
