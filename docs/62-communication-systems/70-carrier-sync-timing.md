# 载波同步与符号定时

## 1. 从一个场景开始

对讲机两头约好「每晚八点整、135.5 兆赫、上边见」。夜里你准时打开接收机，却听见一片怪声——对方其实一直在说话。问题出在两处看不见的对表：他的载波振荡器和你的差了几度相角，他的发送节拍和你的采样钟差了几个微秒。**接收端必须回答两个时间问题：载波相位对了吗？采样时刻对了吗？**答错任何一个，上一课那台无懈可击的最优接收机就在认真地批改错误的答卷。

## 2. 直觉解释

**第一问：转歪的星图。** 解调靠一支本地复制的小正弦波当参考笔。它的起点若与发送端差了一个固定角度 $\theta$，解出来的每个点都会绕原点整体旋转 $\theta$——星图还是那张星图、间距一毫米没变，可接收机的判决分界线还钉在原朝向上不动。转 $10^\circ$ 只是余量变薄；转到四十五度量级，不少点的安全余量已被吃光，噪声轻轻一推就串进邻居的门；转过九十度则成排星位互换档位，解码成了概率游戏。

**第二问：踩偏的鼓点。** 符号脉冲彼此首尾相连地排在时间轴上。采样时钟若提前或迟到 $\varepsilon$ 秒，采到的就不只是当前符号的正身，还有上一个符号拖着的尾巴与下一个符号探出的头——这份串味叫**码间串扰（ISI）**。眼睛再张的眼图也架不住总在眼角处采样。

两种病共用一种药方思路：拿已知的东西当尺子校准自己。这把尺子就是数据帧开头的**前导码**——一段双方都背得滚瓜烂熟的固定图案，误差一露头就现形。

## 3. 正式定义

设发送基带复包络为 $s(t)$（星座点序列的理想波形），存在载波相位差 $\theta$ 与定时偏差 $\tau$ 时，接收等效基带信号为

$$r(t) = s(t-\tau)\,\mathrm{e}^{\mathrm{j}\theta} + n(t)$$

| 符号 | 名字 | 造成的伤 |
| --- | --- | --- |
| $\theta$ | 载波相位差 | 星座整体旋转 $\mathrm{e}^{\mathrm{j}\theta}$，判决域错位 |
| $\tau$ | 符号定时偏差 | 采样落在过渡区，引入 ISI |
| 前导码 | 已知训练段 | 双方共用的对表基准 |
| 鉴相器 | 相位测量员 | 比较本地参考与信号的相差 |
| 迟早门 | 定时探测器 | 提前/迟到两处各采一次，比能量定向 |

两问的对表机制是闭环的：测出偏差 → 反向修正 → 再测。相位回路由三件套组成——鉴相器量出还差几度、环路滤波器掂量该信几分、压控振荡器轻轻拨动本地参考；定时回路与之对称，用迟早门量出该把采样时刻往前蹭还是往后挪。两者都不需要知道答案，只需要知道**现在歪向哪边**。

## 4. 分步例题

**例 A**：16-QAM 发送点 $(+3,+1)$，信道引入 $\theta = 90^\circ$ 的未知相位差。接收机按原朝向解码会发生什么？

1. 复数视角：乘 $\mathrm{e}^{\mathrm{j}90^\circ} = \mathrm{j}$，等于把整张平面逆时针拧 $90^\circ$；
2. 套上旋转口诀 $(x,y) \to (-y,\ x)$：发送星 $(3,1)$ 抵达接收机时已变成 $(-1,3)$；
3. $(-1,3)$ 恰好仍是合法星位，但它驮的比特被偷梁换柱：查格雷表，$-1 \to$ `01`、$+3\to$ `10`，读到的是 `0110` 而非原来的 `1011`——无噪声时错得整整齐齐，是确定性的冤案；
4. 与噪声叠加后更险恶：$\theta = 30^\circ$ 时同一颗星被拧到 $x \approx 3\cos 30^\circ - \sin 30^\circ \approx 2.10$，离电平分界线 $\pm 2$ 只剩约 0.1 的余量——噪声轻轻一笔就把它推进隔壁电平格。核心结论不变：**相位差不缩短星的间距，它篡改的是答题卡的归属**。

**例 B**：矩形脉冲宽 10 个样本、幅度 1，符号序列 $+1,-1$ 相邻。迟到的时钟在第 2 个符号中点采样，却晚偏 3 个样本：

1. 正确时刻采到纯 $-1$；
2. 迟到 3 格意味着过渡带已过 3 格：本符号贡献 $7/10$、前一符号贡献 $3/10$；
3. 采样值为 $0.7\times(-1)+0.3\times(+1) = -0.4$——前一个正号硬生生把负号磨钝了四成；
4. 若噪声恰好再来 0.5 的推动，这个 $-0.4$ 就要冒充 $+1$ 的邻居了：ISI 不缺杀伤力，缺的只是借口。

### 实验 1（viz）：整张星图随相位误差一起旋转

下面这颗紫色箭头就是接收星座里的某个点：蓝色点是发送的原始星位，绿色箭头是本地参考的角度。拖动角度滑块（即相位误差 $\theta$），紫色的合成点绕原点转动——转满 $90^\circ$ 它就冒名顶替邻星，转满 $180^\circ$ 则黑白颠倒：


盯住图上的辐角读数栏：加法关系一目了然（$\arg zw = \arg z + \arg w$）。同步系统要做的事，就是把绿色的角重新扳回零度。

### 实验 2（python）：一张 16-QAM 星图的旋转病历

```python title="相位误差 θ 取不同值时，多少颗星被判错"
import math                      # 用 sin/cos 做旋转
import matplotlib.pyplot as plt

lvls = [-3, -1, 1, 3]            # 每轴四个电平（40 号课同款）
xs = []                          # 全部星位的横坐标
ys = []                          # 全部星位的纵坐标
for i in lvls:
    for j in lvls:
        xs.append(i)
        ys.append(j)

thetas = [0, 15, 45, 90]         # 四档相位误差逐级加重
fig, ax = plt.subplots(figsize=(6.4, 6.4))          # subplots：一次领画布和坐标系
ax.scatter(xs, ys, color="steelblue", s=180)        # 原始星位打底
for t in thetas:
    rad = math.radians(t)        # radians：度数换弧度
    rx = []
    ry = []
    wrong = 0                    # 统计转入错误象限的星数
    for k in range(len(xs)):
        nx = xs[k] * math.cos(rad) - ys[k] * math.sin(rad)   # 平面旋转公式
        ny = xs[k] * math.sin(rad) + ys[k] * math.cos(rad)
        rx.append(nx)
        ry.append(ny)
        if math.floor(nx / 2) != math.floor(xs[k] / 2) or math.floor(ny / 2) != math.floor(ys[k] / 2):
            wrong = wrong + 1    # 电平档位跨格即为越界
    ax.plot(rx, ry, linestyle="", marker="o", markersize=5,
            label=f"θ={t}°")     # label 配合 legend 显示图例
    print(f"θ={t}° 有 {wrong}/16 颗星滑出原电平格")

ax.legend()                      # 图例：给每条曲线贴名字
```

打印记录会显示各档误差下有多少星位滑出原来的电平格（以实跑输出为准）。看图更直观：蓝色的骨架自始至终没有变形，橙红各档只是绕原点拧了不同角度——这就是「旋转不毁几何、只毁归属」的可视证据，也是同步失锁时不许硬解调的原因。

### 快问快答

```quiz
星座整体旋转与噪声雾一样都能造成误码，它们最本质的区别是什么？
- 旋转让星图变大，噪声让星图变小
- 旋转是确定性的系统偏差，可以测出并扭回来 [*]
- 没有区别，都是随机恶化
? 噪声每一笔都不同、只能用统计对付；而相位差一旦锁住就是常数，闭环回路总能把它驱赶回零。这也是为什么高阶 QAM 宁愿多付同步电路的钱也要省功率。
```

:::warning[常见误区]

**误区一**：「旋转过的星图只要放大镜像就能照常工作。」
接收机的判决域是用模板在**标准朝向**下定义的；把点集旋回去之前，最近邻判定全部失效。方案只有一条路：估计 $\theta$ 并补偿，没有任何免费镜像。

**误区二**：「定时偏一点点没关系，反正符号持续那么久。」
本课例 B 给了定量演示：矩形脉冲偏 3/10 就混入 30% 的邻居成分。真实成形脉冲（升余弦）在设计采样点上刻意归零旁瓣，定时必须钉在零交贡献的位置——挪动即沾毒。

**误区三**：「同步是开机时干一次的活。」
收发双方的晶振都在漂移，多普勒还会追加频移。同步回路必须终身在线、缓慢跟进；失联的报警不是崩溃而是性能阴跌——高速链路上表现为「明明信号满格却一直缓冲」。

:::

## 6. 练习

**练习 1**：一段 16-QAM 点被实测 $90^\circ$ 的相位误差污染。把 Astraea 号点拧回正北并解出比特：

```exercise
# @title: 练习：把转歪的星座拧回来
# @check: -3
# @check: -1
# @check: 0001
# @hint: 实测转了 90° 就要朝反方向拧回去：顺时针口诀是 (x,y) 变成 (y,-x)，别再逆时针转一圈
sync_err = 90                    # 实测载波相位误差（度）：90° = 乘以 j
rx, ry = 1, -3                   # 接收星座点（已被旋转污染）

# 记住两条口诀：逆时针 90° 是 (x,y)->(-y,x)；顺时针 90° 是 (x,y)->(y,-x)
cx = -ry                         # ← 问题在这：又逆时针转了一次，越转越歪
cy = rx                          # ← 问题在这：应该顺时针拧回去

level_bits = {-3: "00", -1: "01", 1: "11", 3: "10"}   # 字典：冒号配对的键值对
bits_x = level_bits[cx]          # 方括号按键取值：横轴电平的两位比特
bits_y = level_bits[cy]          # 纵轴同理

print(cx)
print(cy)
print(bits_x + bits_y)
```

初始代码输出 3、1、1011——把接收点又正着转了一圈。改成顺时针口诀 `(cx, cy) = (ry, -rx)` 后输出 −3、−1、0001：恢复出的正是 40 号课手算映射那一课的同款格雷查表流程；注意 90° 的整数倍旋转才能保持整数坐标精确无损，任意角度都得走实验 2 的三角函数路线。

**练习 2**：为什么接收机不干脆放弃锁相，改用不会旋转的调制方式？

<details>
<summary>点开查看逐步解答</summary>

不旋转的选项并不存在：任何「驮在一个高频正弦波上」的信号都继承了发送振荡器的相位。FSK 家族看似免于相位敏感，实则频移后仍需频率基准；OOK 对相位免疫却又退回抗噪最弱的深坑。工程真正的答案是承认现实——付出一点前导码和几行环路代码的成本，换取相位信息的全额红利；这笔账已在 30 号课埋伏：「PSK 功率效率最高，但要求时钟咬合得很准」。让渡的是复杂度，赎回的是吞吐。

## 7. 选读：锁相环的一瞥

<details>
<summary>选读 · 三件套闭环运转的直觉</summary>

完整的 PLL 是一场无声的追赶赛。鉴相器读出差角 $\theta_e$（发送端与本地参考的夹角），但它只会念数、不懂轻重缓急；环路滤波器是个急性子检测器——快抖动一律拦截，慢漂移如实上报，以防本地振荡器被单笔噪声吓得乱跳；压控振荡器拿到上禀的均值才拨针。三者合围，把 $\theta_e$ 逼进永远趋近零的死胡同。锁定后有两条经验规律值得带走：带宽越窄环越稳但追不上快速漂移（矛盾要靠设计折中），前导码的任务只是把这场追赶赛从遥远的出发点拉到决赛圈，正式数据一到即可平稳交接。
</details>
