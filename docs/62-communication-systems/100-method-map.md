# 通信系统方法地图

## 1. 从一个场景开始

本章开篇那条微信语音走完了它的全部旅程。十一门课各拆了一节车厢，现在把它们重新挂钩：你说的话如何变成比特，比特如何被压缩、加固、驮上载波，又如何在雾里被捞回、对表、表决、还原成声音——**从比特出发，回到比特**。这一课不再引入任何新工具，只做一件事：把地图铺开，让你合上课本也能从头讲到尾。

## 2. 直觉解释

把整条链路想成一条邮政流水线，三个家族分段承包：

- **减重家族**管「少寄纸」：信源编码把消息压到熵允许的最紧（信息论课程的地盘），基带码型则管导线上高矮胖瘦怎么排（脉宽与时钟的事）；
- **加固家族**管「防摔坏」：信道编码往包裹里塞结构化的缓冲物，星座映射决定每个包裹绑在哪颗星上，扩频与跳频让包裹混进人流躲开截击；
- **对表家族**管「别送丢」：匹配滤波在雾中辨认包裹形状，载波同步与符号定时保证分拣钟摆一致，判决算出最可能的原文。

接收端是同一条流水线的倒放镜像：解调的最近邻判定、纠错译码的多数表决、解压还原——一路逆向走回比特。理解全图的关键不是背站名，而是看清每一站的**发票**：它付出什么代价，换来什么保障。

## 4. 分步例题

**例**：端到端运费速算。一段 $480$ 比特的留言要走完整条流水线：经 $(7,4)$ Hamming 打包、64-QAM 映射、$1400$ 波特发送，全程耗时多少？

1. **信道编码站**：每码字容纳 $k=4$ 个信息位，共需 $480 \div 4 = 120$ 个码字，实际发射 $120 \times 7 = 840$ 位——冗余把账单抬高了七成五；
2. **星座映射站**：64-QAM 每符号驮 $\log_2 64 = 6$ 位，符号数 $840 \div 6 = 140$；
3. **发送计时**：波特率 $1400$ 即每秒 1400 个符号，用时 $140 \div 1400 = 0.1$ 秒；
4. **可靠性预估**：若裸链路每位出错概率 $10^{-3}$，不编码时期望坏 $0.84$ 位——十条留言几乎必有一条带伤；编码后仅当某码字内两位同时翻车才救不回，期望 $120 \times \binom{7}{2} \times (10^{-3})^2 \approx 0.0021$ 条——千分之二的残次率，是同一份功率下买到的安稳觉；
5. 注意第 1、2 步的谈判本质：Hamming 降价了吞吐（$\times 7/4$），64-QAM 又涨回来一部分（$\times 6/$符号）——**编码的冗余与调制的密度在同一笔带宽预算里讨价还价**，这正是全章反复出现的权衡语言的最后一章。

### 实验 1（python）：一次五微缩的全流程过关

```python title="明文进，明文出：中间全靠流程线挡刀"
import random                    # 随机数库
random.seed(2026)                # 固定随机种子：这段旅程人人走得一样
import matplotlib.pyplot as plt

P_FLIP = 0.15                    # 信道翻转概率（比前几课更狂暴）
REPEAT = 3                       # 重复编码：每个比特复读三遍

msg = "HI"                       # 待发的原始明文（信源产物）
raw = []                         # 明文展开成的比特串
for ch in msg:
    code = ord(ch)               # ord：字符换 ASCII 编号
    for b in range(8):
        raw.append((code >> (7 - b)) % 2)   # >> 右移：从最高位逐位顶出二进制

rescued = []                     # 表决后的恢复比特
flips_seen = 0                   # 途中被翻面的总次数
uncoded_err = 0                  # 不加冗余时（信第一枪）会残留的错误
coded_err = 0                    # 三重表决后仍翻不掉的残余错误
for i in range(len(raw)):
    bit = raw[i]
    triple = []
    for rep in range(REPEAT):
        got = bit
        if random.random() < P_FLIP:
            got = 1 - got        # 信道这一刀
            flips_seen = flips_seen + 1
        triple.append(got)
    if triple[0] != bit:         # 裸奔对照组：只信第一份送达件
        uncoded_err = uncoded_err + 1
    ones = sum(triple)
    guess = 1 if ones * 2 > REPEAT else 0   # 多数表决收官
    rescued.append(guess)
    if guess != bit:
        coded_err = coded_err + 1

out = ""                         # 还原明文的缓冲串
for ch_i in range(len(msg)):
    val = 0
    for b in range(8):
        val = val * 2 + rescued[ch_i * 8 + b]
    out = out + chr(val)         # chr：编号换回字符，ord 的逆操作
print(f"翻面 {flips_seen} 次；裸奔残留 {uncoded_err}/{len(raw)}，表决后残留 {coded_err}/{len(raw)}")
print(f"恢复结果：{out}")

plt.figure(figsize=(5.6, 2.6))
bars = ["裸奔（信第一枪）", "三重表决"]
heights = [uncoded_err / len(raw), coded_err / len(raw)]
plt.bar(bars, heights, color=["tomato", "seagreen"])   # bar：两根对比柱
```

六次翻面砸向这十六比特的旅程：裸奔的那一栏染了红（信第一枪就定终身），表决的那一栏贴地归零——`HI` 完璧归来。把 `REPEAT` 改回 1 再看：同一片海，立刻船沉。

:::warning[常见误区]

**误区一**：「把每节课都做到最优，链路自然最优。」
跨层之间全是合同纠纷：64-QAM 的密度红利会被更贵的编码开销吃掉，扩频的抗干扰收益要用额外带宽支付。工程选型永远在整条流水线上做联合优化，单点冠军未必入围决赛。

**误区二**：「这张地图就是通信技术的边界。」
它只是物理层的主干道。多址接入怎么把马路划成车道、网络层怎么寻址路由、加密怎么防扒手（那是第 34 章的地盘）、无线电波在真实空间怎么弯曲折射（下一章开启）——都在这堵墙外面等着。

**误区三**：「学完了就该能徒手调通一台调制解调器。」
真实芯片里有数百个本章未提的工程开关。地图的作用是在系统出问题时迅速定位「哪一站的心智模型」，而不是替代器件手册——知其所以然，查其所以然才快。

:::

## 6. 练习

**练习 1**：替另一条链路开发票——账目能跑但四个数全歪：

```exercise
# @title: 练习：一张端到端的运费账单
# @check: 120
# @check: 840
# @check: 140
# @check: 100
# @hint: (7,4) 码字只装 4 个信息位；发射位数要乘回码长 7；64-QAM 每符号驮 6 位；毫秒数 = 符号数 ÷ 波特率 × 1000
info_bits = 480                  # 信源交来的裸信息位数
baud = 1400                      # 每秒发出的符号个数

codewords = info_bits // 7       # ← 问题在这：每个码字装 4 个信息位，别拿长度 n 当分母
sent_bits = codewords            # ← 问题在这：忘了乘 7 补回校验位
symbols = sent_bits              # ← 问题在这：还没按 64-QAM 每符号 6 位折算
duration_ms = baud // symbols    # ← 问题在这：时间是符号数除以波特率，方向反了

print(codewords)
print(sent_bits)
print(symbols)
print(duration_ms)
```

修好后输出 120、840、140、100：$480 \div 4 = 120$ 码字、乘 7 得 840 发射位、按 6 位一符折成 140 符号、$140 \div 1400 \times 1000 = 100$ 毫秒。这四行就是第 4 节那道运费速算例题的整套流水账，能心算它，全图的站名就都活了。
