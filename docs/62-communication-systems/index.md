# 通信系统

通信系统的核心问题是在噪声和有限带宽中可靠传输信息。本章把消息变成信号，把信道变成概率与失真模型，再把接收变成检测、同步和纠错的闭环。

这一章按下面的路线图推进：

1. [通信链路与收发模型](./10-link-model.md)——按下微信的语音键，1 秒的声音开始了它的奇幻漂流：变成数字、打包、调制到高频、从天线射进空气，撞上墙…；
2. [基带脉冲与码型](./20-line-coding.md)——把比特直接变成导线上的高低电平（不驮载波），叫基带传输——USB、老式以太网、门禁卡都是这么干的；
3. [ASK、FSK 与 PSK](./30-ask-fsk-psk.md)——基带信号跑不远：频率太低的天线得有山那么高，而且直流成分一路衰减；

## 实战挑战 · 蓝牙跳频的抗干扰账本

> 场景说明：经典蓝牙 79 个 1 MHz 频道（2402–2480 MHz）、每秒 1600 跳、驻留 625 微秒，以及自适应跳频（AFH）自规范 v1.2 引入——均为蓝牙核心规范的公开参数；「一条约 20~22 MHz 宽的 Wi-Fi 频道大致压住 22 个蓝牙频道」是工程界常用的估算口径（802.11b 占宽恰为 22 MHz）。本题的占用数字为教学构造，情境原创。

你的蓝牙耳机在咖啡馆里与一台开着 Wi-Fi 热点的笔记本共存。热点占用的 20 MHz 频谱恰好盖住 22 个蓝牙频道。

**(a)** 每次跳频在频道上停留多少微秒？打印它；
**(b)** 不启用 AFH 时，每秒 1600 跳里期望有多少跳撞进 Wi-Fi 区？打印整数部分；
**(c)** 启用 AFH 把这 22 个频道拉黑后，还剩几个可用频道？打印它；
**(d)** 此后每个干净频道平均每秒被光顾几次？打印整数部分。

```exercise
# @check: 625
# @check: 445
# @check: 57
# @check: 28
# @title: 实战挑战：蓝牙跳频的抗干扰账本
# @hint: (a) 一秒有一百万微秒；(b) 总跳数乘撞区比例再取整；(d) 总跳数均摊给干净频道，用整除
hops = 1600              # 每秒跳频次数
busy = 22                # 被 Wi-Fi 盖住的频道数
total = 79               # 经典蓝牙频道总数

dwell = hops // 1000000      # ← 问题在这：谁除以谁？
busy_jumps = busy * total    # ← 问题在这：这只是频道乘积
clean = total + busy         # ← 问题在这：拉黑是加还是减？
visits = clean               # ← 问题在这：还没把总跳数摊下去
print(dwell)
print(busy_jumps)
print(clean)
print(visits)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** $1000000 \div 1600 = 625$ 微秒——游击战里每次驻留的时间窗。

**(b)** 撞区概率 $22/79 \approx 27.8\%$，期望撞区跳数 $1600 \times 22 // 79 = 445$：不设防时每秒有四百多次发射喂了 Wi-Fi，全靠重传硬扛。

**(c)** AFH 把坏频道从跳频表中除名：$79 - 22 = 57$ 个可用频道（收发双方同步更新信道图）。

**(d)** 原来的流量摊到幸存者头上：$1600 // 57 = 28$ 余 4——每个干净频道每秒平均光顾 28 次。对比 (b)：从「四百多次白打」到「零次撞区」，这就是自适应跳频的价值；代价是分母变小、序列变短，所以规范要求保留足够多的频道维持频率分集。

验证代码：

```python
print(1000000 // 1600)   # 625
print(1600 * 22 // 79)   # 445
print(79 - 22)           # 57
print(1600 // 57)        # 28
```
</details>

## 实战挑战 · 香农容量：别丢了那个 1

香农信道容量 $C = B\log_2(1+\text{SNR})$，对数里是 $1+\text{SNR}$。带宽 $1000$ Hz、信噪比 $1023$（即 $2^{10}-1$）时，$C = 1000\times10 = 10000$ bit/s。下面这题漏了 $1$，修到输出 `10000`：

```exercise
# @title: 实战挑战：香农容量别丢那个 1
# @check: 10000
# @hint: 公式是 log2(1+SNR)，先加 1 再取对数。
import math

B = 1000.0          # 带宽（Hz）
SNR = 1023.0        # 线性信噪比（= 2^10 − 1）
C = B * math.log(SNR, 2)    # ← 问题在这：漏了 1+SNR
print(round(C))
```

<details>
<summary>点开查看逐步解答</summary>

香农公式的对数里是 $1+\text{SNR}$：

```python
C = B * math.log(1 + SNR, 2)   # 1000 * log2(1024)
print(round(C))                # 10000
```

改完：$\log_2(1024) = 10$，$C = 1000\times10 = 10000$ bit/s。初始代码算 $\log_2(1023) \approx 9.998$，得约 $9998$。那个"$+1$"来自噪声与信号同处一个信道——当 SNR 很大时它几乎不影响结果，但在低信噪比下它保证容量永不越过 $\frac{B}{\ln2}$ 这条硬边界。这个 $1$，是香农极限的理论根基。

</details>
