# 单位圆上的 sin 与 cos：转圈转出来的函数

## 1. 从一个场景开始

摩天轮转到一半，朋友问你"现在离地面多高"。你没法直接量，但你知道自己**转了多少度**——而"转多少度"一旦说定，高度其实就唯一确定了。

这个"角度 → 位置"的对应关系，就是本章主角三角函数。它藏在钟表指针、游戏角色的旋转、秋千的摆动里——凡是会转圈、会摇晃的东西，背后都是它。

## 2. 直觉解释

把摩天轮缩小成半径为 $1$ 的圆（**单位圆**），圆心放在坐标原点。你从点 $(1, 0)$ 出发，沿圆逆时针转过角度 $\theta$，停在某个位置 $(x, y)$。

关键来了：$\theta$ 一旦确定，$(x, y)$ 就完全确定。横坐标 $x$ 和纵坐标 $y$ 都是 $\theta$ 的忠实随从——给它们各起一个名字：

- 横坐标叫 **cos θ**（余弦）：管左右；
- 纵坐标叫 **sin θ**（正弦）：管高低。

于是"算 sin 45° 是多少"这个问题，翻译过来就是："在单位圆上转 45°，落点有多高？"

## 3. 正式定义

在单位圆上，从 $(1,0)$ 逆时针旋转角 $\theta$ 后的落点为 $(x, y)$，则定义：

$$\cos\theta = x, \qquad \sin\theta = y$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\theta$ | 角度 | 转过的角，本课先用"度"记 |
| 单位圆 | 半径为 1 的圆 | 圆心在原点，$x^2 + y^2 = 1$ |
| $\cos\theta$ | 余弦 | 落点的**横坐标** |
| $\sin\theta$ | 正弦 | 落点的**纵坐标** |

立刻能白捡一条恒等式：落点在半径 1 的圆上，勾股定理说 $x^2 + y^2 = 1$，也就是

$$\cos^2\theta + \sin^2\theta = 1$$

对**任何**角度都成立。几个常用角度的落点：

| $\theta$ | $0°$ | $30°$ | $45°$ | $60°$ | $90°$ |
| --- | --- | --- | --- | --- | --- |
| $\cos\theta$ | $1$ | $\frac{\sqrt3}{2} \approx 0.866$ | $\frac{\sqrt2}{2} \approx 0.707$ | $0.5$ | $0$ |
| $\sin\theta$ | $0$ | $0.5$ | $\frac{\sqrt2}{2} \approx 0.707$ | $\frac{\sqrt3}{2} \approx 0.866$ | $1$ |

## 4. 分步例题

**例**：不查任何表，手算 $45°$ 的落点坐标。

1. 认形状：$45°$ 的落点在对角线 $y = x$ 上，横纵坐标相等；
2. 列方程：落点在单位圆上，故 $x^2 + y^2 = 1$；代入 $y = x$ 得 $2x^2 = 1$；
3. 解出来：$x^2 = \dfrac{1}{2}$，所以 $x = \sqrt{\dfrac12} \approx 0.7071$；
4. 结论：$(\cos 45°, \sin 45°) \approx (0.707, 0.707)$——又高又对称的位置。

再试 $30°$：把边长为 2 的等边三角形竖着对半切开，半个的高是 $\sqrt{2^2 - 1^2} = \sqrt3 \approx 1.732$，缩到单位圆（除以半径 2）得纵坐标 $\dfrac{1}{2}$、横坐标 $\dfrac{\sqrt3}{2} \approx 0.866$。表格里的数全部可以这么亲手造出来。

## 5. 动手实验

### 实验 1（viz）：拖着一个点转圈，看两个影子

```viz

  "mode": "wave"

```

怎么玩：紫色动点沿单位圆逆时针跑，蓝色横线段是 cos（横向投影）、橙色竖线段是 sin（纵向投影）；右侧同步摊开的就是正弦曲线。可拖动紫点停在任意角度；用键盘操作时，先聚焦画布，再按 ← / → 每次退回或前进 15°，也可以暂停/继续播放——看清"转圈"如何被拉直成"波浪"。

### 实验 2（python）：math.cos 与 math.sin 的出生证明

先回到没有官方工具的日子，用勾股定理手算一遍 45°，再看 Python 的正式版本：

```python title="先手算 45°，再请出 math.cos / math.sin"
import math

# 手算路线：45° 落点在对角线 y = x 上，且 x² + y² = 1（单位圆）
x = math.sqrt(1 / 2)   # 两边平方都是 1/2，开平方得到横坐标
print(round(x, 4))     # 约 0.7071 —— 这就是 cos 45° 的值

# math.cos 与 math.sin 正式登场！注意：它们吃的角度必须是「弧度」，不是「度」！
# 弧度是数学家的量角单位（20 课细讲）。math.radians() 是官方换算器：把「度」换成「弧度」
rad45 = math.radians(45)   # 45° 换成弧度，约等于 0.7854
print(math.cos(rad45))     # 官方答案：约 0.70710678，和手算一致
print(math.sin(rad45))
```

怎么玩：对照两段输出——手算只准到 0.7071，`math.cos` 一出手就是十几位。特别注意 `math.radians` 那一行：**直接把 45 喂给 `math.cos` 会得到完全不相干的数**，因为它以为你说的是 45 弧度。

### 实验 3（python）：特殊角度坐标表

```python title="五个常用角度的落点坐标"
import math

degs = [0, 30, 45, 60, 90]        # 一个列表装下五个常用角度
for d in degs:                    # 循环：逐个取出角度
    rad = math.radians(d)         # 度 → 弧度：喂给三角函数前必做的一步
    c = round(math.cos(rad), 3)   # 横坐标，保留三位小数
    s = round(math.sin(rad), 3)   # 纵坐标
    print(f"{d}度 -> (cos, sin) = ({c}, {s})")
```

怎么玩：对着第 3 节的表格核对每一行；再把列表改成 `[120, 180, 270]` 跑一次——看看圆的左半边和下半边，cos、sin 分别变成什么符号。

### 实验 4（python 滑块）：转一整圈，每 30° 打一次卡

```python title="πk/6 巡检：从 0° 一路转到 360°"
import math

# sliders: k=1 [0:12:1]

rad = k * math.pi / 6              # 角度 k·π/6 弧度：k 每加 1 就多转 30°
deg = k * 30                       # 同一个角的角度制写法
c = round(math.cos(rad), 3)        # 落点横坐标 cos
s = round(math.sin(rad), 3)        # 落点纵坐标 sin
print(f"k={k}: 转 {deg}° 后落点 = ({c}, {s})")
```

怎么玩：k 从 0 拖到 12，等于沿单位圆巡检一整圈（$\frac{\pi \cdot 12}{6} = 2\pi$）。盯三条线索：① $k=2$ 时回到第 3 节表格的 $60°$ 行；② 过了 $k=6$（半圈），cos 全部变负、sin 先负后正——对称性直接写在符号里；③ $k=12$ 的落点和 $k=0$ 一模一样：转满一圈，两个函数同时"归零重启"，周期性亲眼可见。（若打印出的 sin 是 `-0.0` 别慌——那是浮点的"负零"，数值上与 0 相等，纯属机器的小脾气。）

### 快问快答

```quiz
想在 Python 里算 sin 30°（三十度），正确的写法是？
- math.sin(30)
- math.sin(math.radians(30)) [*]
- math.sin(30 * 180 / math.pi)
? math.sin 只认弧度：直接喂 30 相当于问"转了约 1719°"的位置。要么先 radians 换算，要么喂 math.pi/6。
```

:::warning[常见误区]

**误区一**："你以为 `math.sin(30)` 算的是 sin 30°。" 其实参数是**弧度**——30 弧度约合 1719°，答案毫不相干。这是新手第一大坑，也是本课反复强调的原因。

**误区二**："你以为 sin、cos 只在直角三角形里有意义。" 其实"对边比斜边"那套只是角度不超过 90° 时的特例；单位圆定义让任意角度都有值，连负角、超过 360° 都照算不误。

**误区三**："你以为 (sin θ, cos θ) 这个顺序无所谓。" 其实横坐标永远是 cos、纵坐标永远是 sin。顺序背反，整张图左右错位。

:::

**练习 2**：θ 从 0° 涨到 90° 时，sin θ 从 0 涨到 1，cos θ 从 1 跌到 0。为什么它们必然一涨一跌？

<details>
<summary>点开查看逐步解答</summary>

落点沿着四分之一圆弧从 $(1, 0)$ 走到 $(0, 1)$：这一路上横坐标只能缩水、纵坐标只能上涨。更硬的理由是恒等式 $\cos^2\theta + \sin^2\theta = 1$——两者平方和钉死为 1，一个变大另一个就必须让位。
</details>

**练习 3**：用单位圆解释为什么 $\sin(-30°) = -\sin(30°)$，并顺手写出 $\cos(-30°)$ 等于什么。

<details>
<summary>点开查看逐步解答</summary>

负角是顺时针转：$-30°$ 的落点与 $+30°$ 的落点关于 x 轴上下镜像。镜像翻转的是纵坐标——所以纵坐标 sin 变号，横坐标 cos 不变。结论：$\sin(-\theta) = -\sin(\theta)$，$\cos(-\theta) = \cos(\theta)$，后者对所有角度成立。
</details>

## 7. 选读：余弦的"余"字来历

<details>
<summary>选读 · 余弦 = "余角"的正弦</summary>

对照第 3 节的表会发现一组巧合：$\cos 30° = 0.866 = \sin 60°$，$\cos 45° = \sin 45°$，$\cos 60° = 0.5 = \sin 30°$。这不是巧合，而是恒等式：

$$\cos\theta = \sin(90° - \theta)$$

几何原因：在单位圆上，$\theta$ 与它的**余角**（加起来凑成 $90°$ 的搭档）落点关于对角线 $y = x$ 镜像，镜像恰好交换横纵坐标。英文 cosine 里的 "co-" 正是 complementary（互余）的缩写——"余弦"就是"余角的正弦"。所以特殊值其实只需背 sin 一张表，cos 表是白送的。

</details>
