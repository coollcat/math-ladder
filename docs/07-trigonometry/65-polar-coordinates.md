# 极坐标：平面的第二套门牌号

## 1. 从一个场景开始

机场塔台对着夜航的飞机喊话："航向东北偏东，离跑道头还有 10 公里。"注意塔台的说法——它报的是**一个方向加一段距离**，而不是"你现在的横坐标是 7.99，纵坐标是 6.02"。后一句话也对，但没人这么导航。

这背后是给平面上发门牌号的**两套并存体系**：

- **直角坐标** $(x, y)$：像棋盘上的地址——先往东走几格、再往北走几格。曼哈顿式的城市用它最顺手；
- **本课主角**：像罗盘上的地址——朝某个方向走多远。郊区、雷达、天文台都爱用它。

还有一个更隐秘的动机：有些曲线用 $y=f(x)$ 的账本**根本记不下来**。比如让半径随角度起伏的玫瑰线，同一个 $x$ 要对应好几个 $y$，函数机器直接罢工。换上门牌体系呢？它一行就写完了——先把答案剧透在这里：$r=\sin(3\theta)$。

## 2. 直觉解释

单位圆早就替我们打好了地基（[单位圆上的 sin 与 cos](./10-unit-circle.md)）：角 $\theta$ 转到哪里，$\cos\theta$ 是它的**东西影子**、$\sin\theta$ 是**南北影子**。所谓"极坐标"，只是把这套影子反过来用：

> 已知方向角 $\theta$ 和走出的距离 $r$——那么脚下位置不过是"影子各拉长 $r$ 倍"。

两类门牌的对照表：

| 问题 | 直角坐标答法 | 本课答法 |
| --- | --- | --- |
| 想去仓库 | 向东 2.12 格再向北 2.12 格 | 面向东偏北 45°，直走 3 公里 |
| 描述半径为 5 的圆 | $x^2+y^2=25$（还得拆成上下两个函数） | $r=5$（三个字符完事） |
| 描述一条从原点出发的射线 | $y=kx$ 只管一半，另一半得另开一条 | $\theta=60°$（角度钉死，射线自现） |

看出味道了吗？**谁到原点近、谁绕圈，谁的账本就更省字**。极坐标不是取代直角坐标，而是给"圆形世界"发的专用简化版合同。

## 3. 正式定义

在平面上取定点 $O$（叫**极点**，相当于原点）和一条以 $O$ 为端点、指向正东的射线（叫**极轴**）。平面上任意一点用一对数

$$(r, \theta)$$

来登记：$r$ 是该点到极点的距离（**极径**），$\theta$ 是从极轴逆时针转到所在方向的角（**极角**）。它与直角坐标的换算是两条恒等式：

$$x = r\cos\theta \qquad y = r\sin\theta$$

反向翻译时，勾股定理给出 $r=\sqrt{x^2+y^2}$（[面积与勾股定理](../05-geometry/20-area-pythagoras.md) 里 `math.hypot` 就是这两步打包）；而 $\theta=\operatorname{atan2}(y, x)$——上一课刚上任的全象限罗盘正好收编进编制（[反三角函数](./55-inverse-trig.md)）。

必须诚实声明一件事：**这门牌并不唯一**。转满一圈回到原地（$\theta$ 加减 $360°$ 不改位置），甚至允许 $r<0$——负号的意思是"沿指定方向的反面走"。为了让地址唯一可查，约定一种**标准格式**：$r \geq 0$，且 $\theta$ 取 $0°$ 到 $360°$（编程中常保留 `atan2` 输出的 $-180°$ 到 $180°$ 写法）。后面的判等一律按标准格式执行。

三类样板曲线的两本账对照（本课要动手验证前两行）：

| 曲线 | 直角账本 | 本课账本 |
| --- | --- | --- |
| 圆心在原点、半径 5 | $x^2+y^2=25$ | $r=5$ |
| 从原点出发、仰角 60° 的半支线 | $y=\sqrt{3}\,x$（只覆盖右半侧） | $\theta=60°$ |
| 玫瑰线（半径随角起伏的花） | 写不出单一的 $y=f(x)$ | $r=\sin(3\theta)$ |

## 4. 分步例题

**例 A（正向翻译）**：把极坐标 $(10,\ 37°)$ 换成直角坐标。

1. 认角色：$r=10$ 是斜边长度，$\theta=37°$ 是与正东方向的夹角；
2. 东向影子：$x = 10\cos 37° \approx 10 \times 0.7986 \approx 8$；
3. 北向影子：$y = 10\sin 37° \approx 10 \times 0.6018 \approx 6$；
4. 结论：$(x, y) \approx (8, 6)$——眼熟吗？这正是"勾六股八弦十"倒过来读（[面积与勾股定理](../05-geometry/20-area-pythagoras.md)），极坐标是那根 10 米长梯子的另类问法。

**例 B（反向翻译）**：把点 $(x, y)=(-\sqrt{3},\ 1)$ 换成极坐标的标准格式。

1. 先算距离：$r=\sqrt{(-\sqrt{3})^2+1^2}=\sqrt{3+1}=2$；
2. 再算方向：该点在第二象限，$\operatorname{atan2}(1, -\sqrt{3})=150°$；
3. 对账：这恰是单位圆上的老熟人 $\cos 150°=-\frac{\sqrt{3}}{2}$ 的两倍版——特殊角一到极坐标里照样灵；
4. 结论：$(r, \theta)=(2,\ 150°)$。

两道例合起来就是一句口诀：**去程乘影子、回程查罗盘**。

怎么玩：横竖轴仍是熟悉的直角坐标，图中曲线却是极坐标眼中的"一条水平直线"——$r=rr$ 在直角账本里被拆成上下两个带根号的函数，而在极账本里只是一句"$r=$ 常数"。把 $rr$ 拖大拖小，感受这种"画圆不用碰公式"的爽快；反向思考：直角世界里最简单的竖线 $x=3$，在本课账本里反而要说一段啰嗦的话。**两套门牌各有主场**。

### 实验 2（python）：玫瑰线罗盘——一片花瓣是怎么长出来的

```python title="r = sin(petal·θ)：极径随角起伏的开花过程"
import math                        # 数学库：sin 取正弦、tau 是整圈弧度
import matplotlib.pyplot as plt    # 画图库

# sliders: petal=5 [1:9:1]

ths = []                           # 存角度（弧度）的列表
rrs = []                           # 存对应极径的列表
n = 400                            # 一整圈的采样密度：400 个脚印
for i in range(n + 1):
    t = math.tau * i / n           # tau = 2π，把 i/n 平铺到 [0, 1] 整圈
    r_now = math.sin(petal * t)    # ★ 主角合同：半径随角度按正弦起伏
    ths.append(t)
    rrs.append(r_now)

plt.figure(figsize=(5, 5))         # 新建一张方形画布，防止花被压扁
plt.subplot(projection="polar")    # 关键开关：坐标系切换成"罗盘模式"
plt.plot(ths, rrs)
plt.title(f"r = sin({petal}·θ)，共数数几片花瓣")
```

怎么玩：运行后得到默认的五瓣玫瑰。拖动 `petal` 重新运行，先猜再验：花瓣数会乖乖等于你设的值吗？留意两个现象——奇数档（3、5、7）花瓣正好同数；偶数档却会**翻倍**（设 4 出来 8 片）。背后的魔法正是 $r<0$：正弦下半程取到负半径时，笔尖被甩到对面去接着画，于是又补出另一批花瓣。"负半径不是错误，是调头令"，在这里看得一清二楚。

### 快问快答

```quiz
把点 (x, y) = (0, −2) 翻译成「正半径、0° 到 360°」标准格式的极坐标，应该是？
- (2, 270°) [*]
- (2, 90°)
- (−2, −90°)
? 该点在正南方向：atan2 报 −90°，加上整圈 360° 得标准格式 270°。(2, 90°) 指向北；(−2, −90°) 是"负半径调头"后的别名，虽然指同一块地，但违反了本次约定的标准格式。
```

:::warning[常见误区]

**误区一**："你以为 $(r,\theta)$ 是每块地的唯一身份证。" 极地址自带无数别名：$\theta$ 加减整圈不变，$r$ 变号再配半圈角也回到原点。判两点是否同位，别比对数组字符串——要么双双化成标准格式再比，要么干脆换算回 $(x,y)$ 用小数差体检。

**误区二**："你以为 $\cos$ 管南北、$\sin$ 管东西。" 单位圆上横影子归 $\cos$、纵影子归 $\sin$（[单位圆上的 sin 与 cos](./10-unit-circle.md) 表格）；放大 $r$ 倍后管辖权不换人。影子一旦认错主人，$(8, 6)$ 就被染成 $(6, 8)$——下面的练习就埋了这个坑。

**误区三**："你以为 atan2 的两个参数随便排。" 顺序契约是**先 y 后 x**（[反三角函数](./55-inverse-trig.md) 第 6 节练习的同款陷阱）。$(8,6)$ 与 $(6,8)$ 差出一个镜像象限，37° 会变成 53°——罗盘读数错一位，目的地全体搬家。

:::

## 6. 练习

**练习 1**：快递无人机基地位于极点。去程指令是"极径 10 米、方位角 37°"；回程时货箱停在了直角坐标 $(8, 6)$ 处。完成双向翻译：求货箱的 $(x, y)$，再把货箱位置译回标准格式 $(r, \theta)$。下面的代码能跑但四处都不对，修到四行检查全部通过：

```exercise
# @title: 练习：无人机门牌双向互译
# @check: 8
# @check: 6
# @check: 10
# @check: 37
# @hint: 四处暗坑全是"张冠李戴"家族：cos 是东西影子、sin 是南北影子；勾股流水线平方相加之后别忘了开方（math.hypot 两步打包）；atan2 的座位次序是先吃 y 后吃 x。
import math                      # 数学库：三角、开方与 atan2 都在里面

# —— 第一段 · 去程：(r, θ) → (x, y)，已知 r=10 米、方位角 37 度 ——
rr = 10                          # 极径：离基地的距离
ang = 37                         # 方位角（单位：度）

x = rr * math.sin(math.radians(ang))   # ← 往东多少米，该问哪条影子？
y = rr * math.cos(math.radians(ang))   # ← 往北呢？
print(round(x))
print(round(y))

# —— 第二段 · 回程：(x, y) → (r, θ)，货箱停在 (8, 6) ——
px, py = 8, 6                    # 双变量打包赋值：一次发放两个坐标
r_back = px * px + py * py       # ← 勾股三步流水线是不是漏了一步？
print(round(r_back))

t_back = math.degrees(math.atan2(px, py))   # ← atan2 先接哪个坐标？
print(round(t_back))
```

<details>
<summary>点开查看逐步解答</summary>

四处暗坑逐一点名：

1. **影子认错主**：$\cos$ 管东、$\sin$ 管北（误区二）。正确写法 $x=10\cos 37°\approx 7.986$、$y=10\sin 37°\approx 6.018$；初始代码让两位影子互换了工牌，所以打印成 $(6, 8)$——数值都在场，只是住错了家门；
2. **开方缺席**：$r$ 是距离，得做满"平方→相加→开方"全流程。初始代码停在第二步报出 $8^2+6^2=100$，正确值 $r=\operatorname{hypot}(8,6)=10$（三步流水线可以直接交给[面积与勾股定理](../05-geometry/20-area-pythagoras.md) 登场的 `math.hypot(px, py)` 打包）；
3. **座位坐反**：`atan2` 先吃 y 后吃 x（误区三）。初始代码 $\operatorname{atan2}(8,6)\approx 53.13°$ 把镜像错当真身，正确的是 $\operatorname{atan2}(6,8)\approx 36.87°$；
4. **单位报关**：`atan2` 返回弧度，出门前必须过 `math.degrees`（[弧度制](./20-radian.md)的老合同）——初始代码这一步倒是没忘，属于运气好的正确行。

修正后的参考代码：

```python
import math                      # 数学库：三角、开方与 atan2 都在里面

rr = 10                          # 极径：离基地的距离
ang = 37                         # 方位角（单位：度）

x = rr * math.cos(math.radians(ang))   # 东向：cos 影子拉长 rr 倍
y = rr * math.sin(math.radians(ang))   # 北向：sin 影子拉长 rr 倍
print(round(x))
print(round(y))

px, py = 8, 6                    # 双变量打包赋值：一次发放两个坐标
r_back = round(math.hypot(px, py))     # hypot：sqrt(x²+y²) 官方快捷方式
print(r_back)

t_back = round(math.degrees(math.atan2(py, px)))   # 先 y 后 x！
print(t_back)
```

输出 `8`、`6`、`10`、`37`，与判题窗逐行一致 ✓。去程与回程互为镜子：6-8-10 这组勾股数换上门牌制服依然认识。

</details>

**练习 2**：$(2, 60°)$ 与 $(2, -300°)$ 记的是同一块地吗？两种办法证明你的判断。

<details>
<summary>点开查看逐步解答</summary>

**是同一块地。**

- **办法一（标准化）**：$-300°$ 加上整圈 $360°$ 得 $60°$——整圈别名按定义不改位置，所以两者都是标准格式下的 $(2, 60°)$；
- **办法二（换算复核）**：把两组各自代入 $x=r\cos\theta,\ y=r\sin\theta$，得到的 $(x,y)$ 完全相同（$\cos$ 与 $\sin$ 以 $\tau$ 为周期），位置重合。

这个练习也是"极地址非唯一"的自我提醒：只要涉及比较，先走标准化流程。

## 7. 边界与适用条件

本课解决的是**平面上的第二套门牌**：两套地址的双向互译、三样样板曲线（同心圆、射线族、玫瑰线），以及它最风光的应用预告——行星轨道（见下一节）。没解决的也一并交代：三维空间要用"球坐标"升级版（多元微积分章再说）；极坐标下怎样算切线斜率、扇形面积，那是微积分的地盘；玫瑰线的"奇偶翻倍"规律本课只观察、不作一般性证明。另外记住两套账本的接口税：跨体系解题时来回换算要付费（每一步都有精度与出错风险），能用一套账本记到底的题目别中途搬家。

## 8. 选读：圆锥曲线的极形式为什么惊人地简单

回到[圆锥曲线：椭圆、双曲线与抛物线](../06-functions/45-conic-sections.md)那块挂绳幕布：椭圆 $a=5,c=4$，于是 $b=3$、离心率 $e=\frac{4}{5}$。直角账本是五件套齐上阵：$a,b,c$ 配上 $x^2,y^2$。现在把**极点搬到右焦点上**、$\theta$ 从指向近日端的方向量起，同一块幕布只剩一行：

$$r = \frac{9}{5 + 4\cos\theta}$$

分子是 $b^2=9$，分母是 $a$ 与 $c\cos\theta$ 的和解。敢这么写就要经得起对账，抽三个方向验明正身：

- $\theta=0°$：$r=\frac{9}{9}=1$，即 $a-c$——幕布最近点，正是彗星掠日的**近日距**；
- $\theta=180°$：$r=\frac{9}{1}=9$，即 $a+c$——**远日距**；
- $\theta=90°$：$r=\frac{9}{5}=1.8$。换个身份复核：此时点在焦点正上方，折回中心坐标是 $(4,\ 1.8)$，代入直角方程 $\frac{4^2}{25}+\frac{1.8^2}{9}=\frac{16}{25}+0.36=\frac{16}{25}+\frac{9}{25}=1$——分毫不差，两本账指的确实是同一块地。

最后一行的通式值得抄在扉页：$r=\dfrac{b^2}{a+c\cos\theta}$。天文学家的轨道手册全用这种一行式书写，因为开普勒定律关心的"到太阳的距离随方向变化"，本来就是一场极坐标阅读。至于这行式子的来历——用[解三角形](./45-solving-triangles.md)的余弦定理在"焦点–中心–曲线点"三角形上轮转变形一轮就能逼出来，完整推导留在下卷圆锥曲线专题。
