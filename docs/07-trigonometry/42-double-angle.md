# 倍角公式与降幂：和角公式的 b=a 特例

## 1. 从一个场景开始

[和角公式](./40-angle-addition.md) 给了我们一本"两次旋转"的账本：$\sin(a+b)$、$\cos(a+b)$ 都能拆成只含 $a$、$b$ 各自的横纵坐标的乘积组合。四张面孔里，有一个特例出场率高得吓人——让 $b = a$，"先转 a 再转 a"，**同一个角转两次**。

这就是**倍角**：已知一个角的正弦余弦，不查表直接算出它的两倍角。更妙的是把公式反着读，$\sin^2 a$、$\cos^2 a$ 这些"二次式"能降回一次——**降幂公式**。第 16 章傅里叶的正交性练习，靠的正是这件幕后工具。

## 2. 直觉解释

和角公式说的是"接力"；令 $b = a$，接力双方变成同一人自己接自己：

- 正弦版 $\sin(a+a) = \sin a \cos a + \cos a \sin a$——两个**一模一样的异名乘积对**相加，合并成 $2\sin a \cos a$；
- 余弦版 $\cos(a+a) = \cos a \cos a - \sin a \sin a$——同名乘积对自己减自己，得到 $\cos^2 a - \sin^2 a$。

先泼冷水立个警示牌：$\sin 2a$ **不等于** $2\sin a$。拿 $a = 30°$ 当场对质：$\sin 60° \approx 0.866$，而 $2\sin 30° = 1$——差得不是一点半点。倍角公式给的才是真账：$2 \times \dfrac12 \times \dfrac{\sqrt3}{2} = \dfrac{\sqrt3}{2} \approx 0.866$ ✓。

## 3. 正式定义

$$\sin 2a = 2\sin a \cos a$$

$$\cos 2a = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 a$$

| 记号 | 名字 | 来历 |
| --- | --- | --- |
| $\sin 2a$ | 正弦倍角公式 | 和角公式取 $b=a$，两项合并 |
| $\cos^2 a - \sin^2 a$ | 余弦倍角·减形态 | 和角公式取 $b=a$，直接抄 |
| $2\cos^2 a - 1$ | 余弦倍角·余弦形态 | 用 $\sin^2 a = 1 - \cos^2 a$ 消掉正弦 |
| $1 - 2\sin^2 a$ | 余弦倍角·正弦形态 | 用 $\cos^2 a = 1 - \sin^2 a$ 消掉余弦 |

把 $\cos 2a$ 的三形态反解一步（把 $\cos 2a$ 挪项），得到**降幂公式**：

$$\sin^2 a = \frac{1 - \cos 2a}{2} \qquad \cos^2 a = \frac{1 + \cos 2a}{2}$$

三形态不是三条公式要背，是**同一件事的三种写法**：手头只有 $\cos^2$ 就用余弦形态，只有 $\sin^2$ 就用正弦形态，两个都有就用减形态。降幂公式则是把倍角公式**倒着读**——二次降一次，没有新知识，只有新方向。

## 4. 分步例题

**例 1**：手算 $\sin 60°$（只用 $30°$ 的特殊值）。

1. 拆角：$60° = 2 \times 30°$，套正弦倍角公式；
2. 代入：$\sin 60° = 2 \sin 30° \cos 30° = 2 \times \dfrac12 \times \dfrac{\sqrt3}{2}$；
3. 收尾：$= \dfrac{\sqrt3}{2} \approx 0.866$；
4. 对账：[单位圆](./10-unit-circle.md) 的特殊值表里 $\sin 60°$ 正是 $\dfrac{\sqrt3}{2}$——倍角公式从已知角滚出新角，与和角公式同款威力。

**例 2**：已知 $\sin a = 0.8$、$\cos a = 0.6$（第一象限），求 $\sin 2a$ 与 $\cos 2a$。

1. 正弦倍角：$\sin 2a = 2 \times 0.8 \times 0.6 = 0.96$；
2. 余弦·减形态：$\cos 2a = 0.6^2 - 0.8^2 = 0.36 - 0.64 = -0.28$；
3. 交叉验算·余弦形态：$2 \times 0.6^2 - 1 = 0.72 - 1 = -0.28$ ✓；
4. 交叉验算·正弦形态：$1 - 2 \times 0.8^2 = 1 - 1.28 = -0.28$ ✓——三形态当场会师。

量级自检：$a$ 约 $53°$，$2a$ 约 $107°$ 已进第二象限——正弦仍为正（0.96 ✓），余弦转负（$-0.28$ ✓）。数和象限两头都对得上。

**例 3**：用降幂公式把 $\sin^2 a$ 改写成一次式，并在 $a = 30°$ 处验收。

1. 套公式：$\sin^2 a = \dfrac{1 - \cos 2a}{2}$；
2. 代 $a = 30°$：$\dfrac{1 - \cos 60°}{2} = \dfrac{1 - 0.5}{2} = 0.25$；
3. 直接算对照：$\sin^2 30° = \left(\dfrac12\right)^2 = 0.25$ ✓——二次式真的降成了一次。

### 实验 3（python）：四万组随机角的三重体检

```python title="倍角三形态 + 降幂，一起过堂"
import random                   # 随机数库（第 0 章已登场）
import math                     # 数学库：sin、cos、tau（第 7 章正式登场）

ok_sin = 0                      # 计数器：正弦倍角通过组数
ok_cos = 0                      # 计数器：余弦倍角（减形态）通过组数
ok_pow = 0                      # 计数器：降幂公式通过组数

for trial in range(40000):      # 循环四万次试验
    a = random.uniform(0, math.tau)   # 在一整圈里随机取角（和角公式课同款）
    s = math.sin(a)
    c = math.cos(a)
    if abs(math.sin(2 * a) - 2 * s * c) < 0.000000001:
        ok_sin = ok_sin + 1
    if abs(math.cos(2 * a) - (c * c - s * s)) < 0.000000001:
        ok_cos = ok_cos + 1
    if abs(s * s - (1 - math.cos(2 * a)) / 2) < 0.000000001:
        ok_pow = ok_pow + 1

print(f"sin(2a) 侧: {ok_sin} / 40000")
print(f"cos(2a) 侧: {ok_cos} / 40000")
print(f"降幂公式侧: {ok_pow} / 40000")
print(round(math.sin(math.radians(30)) ** 2, 4))        # sin²30°：直接算
print(round((1 - math.cos(math.radians(60))) / 2, 4))   # 降幂公式：同一题另一种算法
```

三行计数器都该是 `40000 / 40000`——零例外。最后两行是例 3 的机器复核：直接平方与降幂改写给出同一个 0.25。"降幂"不是近似技巧，是精确的恒等变形。

::::warning[常见误区]

**误区一**："你以为 $\sin 2a = 2\sin a$。" 开场 $30°$ 的对质已经击毙它：0.866 与 1 不是同一个数。倍角公式每一项都是乘积对，"提出去 2"是分配律的手滑，不是三角恒等式。

**误区二**："你以为 $\cos 2a$ 只有一种写法。" 它有三副面孔（减、余弦、正弦形态），恒等但各有擅场：手头只有 $\cos^2 a$ 就选 $2\cos^2 a - 1$，只有 $\sin^2 a$ 就选 $1 - 2\sin^2 a$。背死一条，另两条场景就得硬算。

**误区三**："你以为降幂公式是新一族要背的公式。" 它就是 $\cos 2a$ 的三形态挪项反解——二次降一次的"倒读版"。第 16 章正交性求和时，靠它把 $\sin^2$ 拆成"常数 + 二倍频"两件干净行头。

**练习 2**：用降幂公式证明 $\sin^2 a + \cos^2 a = 1$——第 7 章开篇就认识的基本恒等式，这回换个工具再验一遍。

<details>
<summary>点开查看逐步解答</summary>

两条降幂公式相加：

$$\sin^2 a + \cos^2 a = \frac{1 - \cos 2a}{2} + \frac{1 + \cos 2a}{2} = \frac{2 - \cos 2a + \cos 2a}{2} = \frac{2}{2} = 1$$

一正一负的 $\cos 2a$ 当场对消。基本恒等式、倍角公式、降幂公式三方互为因果——工具滚工具，账本自洽。
</details>

**练习 3**：把例 2 换成第二象限的 a：$\sin a = 0.8$、$\cos a = -0.6$。$\sin 2a$ 与 $\cos 2a$ 变成多少？哪个量翻了符号？

<details>
<summary>点开查看逐步解答</summary>

套同一套公式：

$$\sin 2a = 2 \times 0.8 \times (-0.6) = -0.96 \qquad \cos 2a = (-0.6)^2 - 0.8^2 = 0.36 - 0.64 = -0.28$$

$\cos 2a$ 纹丝不动（它只吃平方，符号免疫），$\sin 2a$ 从 0.96 翻成 $-0.96$（两个因子一负一正，乘积变号）。象限信息藏在 cos 的正负号里——这就是为什么验算永远要做两遍：一遍算数值，一遍查象限。
</details>

## 7. 选读：降幂公式为什么是傅里叶的幕后功臣

<details>
<summary>选读 · 二次式的"平均高度"</summary>

$\sin^2 a$ 这类二次式在求和时最磨人：它永远非负，一项项加起来越滚越大，看不出周期。降幂公式一出手：

$$\sin^2 a = \frac{1 - \cos 2a}{2} = \frac12 - \frac{\cos 2a}{2}$$

二次式拆成两件干净行头：一块恒定的 $\dfrac12$（"平均高度"），加一块频率翻倍的余弦（在完整周期上求和为零）。于是 $\sin^2$ 在整周期上的平均恰好是 $\dfrac12$——所有频率轴"长度相同"的公平，就建立在这半格上。

第 16 章[正交性](../16-fourier/20-orthogonality.md)练习 2 的"同频点积恒等于 N/2"，用的正是这条：降幂公式把"平方求和"翻译成"常数求和 + 归零项求和"。半角公式（$\sin\dfrac{a}{2}$、$\cos\dfrac{a}{2}$ 的表达式）也不过把它再倒读一次，本课不多展开。
</details>
