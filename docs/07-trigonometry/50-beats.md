# 波的叠加与拍音：两列波相遇

## 1. 从一个场景开始

调音师给钢琴调音时有个神秘操作：同时敲响标准音叉和一根琴弦，然后侧耳听——"嗡——嗡——嗡"，声音像呼吸一样一起一伏。拍速快，说明弦偏得多；拍得越慢，说明越准；完全安静，调音完成。

没人给他报频率数据，他全靠这个"呼吸声"把琴调准。两列波相遇时到底发生了什么？

## 2. 直觉解释

先立一条铁律——**叠加原理**：两列波相遇时互不侵犯，重叠位置的位移直接**相加**。你高我高就更高，你上我下就抵消。

现在让两列振幅相同、频率接近的波（比如每秒 4 次 和 5 次）并肩出发：

- 出发瞬间它们步调一致（同相）：相加后振幅翻倍，声音最响；
- 每过一点时间，快的波就比慢的波多跑一段：错开半圈时（反相）互相抵消，一片寂静；
- 错开一整圈后又恢复同步，重新变响。

于是合成的声音**忽强忽弱**。强弱循环的速度取决于两列波"互相甩开"的速度——频率差越大，拍得越急。

## 3. 正式定义

设两列同方向传播的正弦波 $y_1 = A\sin(2\pi f_1 t)$ 与 $y_2 = A\sin(2\pi f_2 t)$，由叠加原理：

$$y = y_1 + y_2 = 2A \cdot \sin\big(\pi(f_1+f_2)t\big) \cdot \cos\big(\pi(f_1-f_2)t\big)$$

这里的化简用了“两列波振幅相等”这个条件。若振幅不相等，拍频仍是 $\lvert f_1-f_2\rvert$，但低谷不会再安静到零；完全抵消是等幅反相的特殊边界。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| 叠加原理 | 波的第一法则 | 重叠处位移直接相加，互不损耗 |
| $f_1, f_2$ | 两列波的频率 | 单位赫兹（Hz），每秒振动的次数 |
| $\Delta f$ | 频率差 | $\lvert f_1 - f_2\rvert$ |
| 拍频 | 强弱起伏次数 | 等于 $\Delta f$：每秒"呼吸"$\Delta f$ 次 |
| 包络线 | 声音的轮廓线 | $2A\left|\cos\big(\pi \Delta f \cdot t\big)\right|$，上下对称外壳到中轴的距离 |

读式子的诀窍：把它看成**两个因子的乘积**——快速振荡的 $\sin(\pi(f_1{+}f_2)t)$ 负责"发声"，缓慢变化的 $\cos(\pi(f_1{-}f_2)t)$ 负责拧动"音量旋钮"。耳朵捕捉到的正是那个旋钮的速度。

## 4. 分步例题

**例**：标准音 440 Hz 的音叉，与一根略高的琴弦同时敲响，每秒听到 3 次强弱起伏。求琴弦频率。

1. 认条件：拍频 = 频率差 = 3 Hz；
2. 列方程：$\lvert f_{\text{弦}} - 440 \rvert = 3$；
3. 解出两个候选：$f_{\text{弦}} = 443$ 或 $437$；
4. 定夺：调音师知道这根弦偏高，取 $443$ Hz。

注意第 3 步：光听拍只能告诉你"差多少"，分不清偏高还是偏低——还得靠经验或再对照一个参考音。

## 5. 动手实验

### 实验 1（viz）：看着两列波"呼吸"

```viz
{
  "type": "beats",
  "f1": 4,
  "f2": 5
}
```

怎么玩：上面两条细波是原始的两列波，下面紫色粗波是它们的和，橙色虚线是包络线。拖动 f2 靠近 f1——包络被拉长、拍变慢；拉到相等时合成一条稳定的波（拍消失）；拉开差距——包络越来越密。底部实时报告拍频。

### 实验 2（python）：真实拍音的波形图

```python title="440 与 443 叠加的前 0.3 秒"
import math                      # 数学工具库：用 pi、sin、cos
import matplotlib.pyplot as plt  # 画图库

f1 = 440                         # 标准音的频率
f2 = 443                         # 偏高 3 赫兹的那根弦

ts = []                          # 时间采样点列表
ys = []                          # 合成波形列表
env_hi = []                      # 包络上沿
env_lo = []                      # 包络下沿
for i in range(5000):            # 取足够密的采样点，画清每一次振动
    t = i * 0.00006              # 时间从 0 铺到 0.3 秒
    ts.append(t)
    ys.append(math.sin(2 * math.pi * f1 * t) + math.sin(2 * math.pi * f2 * t))
    env = 2 * abs(math.cos(math.pi * (f2 - f1) * t))   # 包络：和角公式的馈赠
    env_hi.append(env)
    env_lo.append(-env)

plt.plot(ts, ys, linewidth=0.5, label="合成波")   # linewidth：线条粗细
plt.plot(ts, env_hi, linestyle="--", color="darkorange", linewidth=1.5, label="包络")
plt.plot(ts, env_lo, linestyle="--", color="darkorange", linewidth=1.5)
plt.xlabel("时间（秒）")          # xlabel：给横轴写标题
plt.legend()
plt.grid(True)
```

怎么玩：橙色虚线的"喇叭口"在 0.3 秒内先收拢（t=1/6 秒处最静）再张开——这正是例题里那 1 次完整呼吸的一部分（拍频 3 Hz，一次呼吸要 $\frac13$ 秒）。把 `f2` 改成 450 再跑：包络挤成一团密纹，拍快得像警报。真实世界里这已是刺耳的拍频，调音师永远在把它往慢里磨。

### 快问快答

```quiz
标准音 440 Hz 与另一根弦同时响，每秒听到 2 次强弱起伏，这根弦的频率可能是？
- 882 Hz
- 442 Hz [*]
- 220 Hz
? 拍频是频率差：440 与 442 相差 2。882 是把两个频率相加的陷阱答案——拍是"错齐速度"，不是新音高。
```

:::warning[常见误区]

**误区一**："你以为拍音是一个新频率的声音。" 其实空气里自始至终只有原来的两个频率在振动；$\lvert f_1 - f_2\rvert$ 是**响度起伏**的速度，不是某个新的音高。

**误区二**："你以为两列波相遇会像台球一样撞开。" 其实波互不侵犯：重叠处位移相加，穿过彼此后各走各的路。石头砸进水里激起两圈涟漪，穿过之后涟漪完好如初。

**误区三**："你以为两列波叠加必然更响。" 相位相反时恰好完全抵消，可以安静到零——降噪耳机就是主动发出"反相声波"来吃掉噪声的。叠加的结果可强可弱，全看相位。

:::


**练习 2**：两列振幅相同的正弦波，频率相同但相位差恰好半圈（$\pi$ 弧度），叠加的结果是什么？

<details>
<summary>点开查看逐步解答</summary>

任何时刻一个在波峰、另一个就在对称的波谷，位移严格互为相反数，相加恒为 0——**完全抵消**。这就是降噪耳机的数学内核：麦克风拾取环境噪声，扬声器立刻播放一个相位翻转的副本，两者在你耳边相加归零。
</details>

**练习 3**：为什么专业调音师宁可听"拍"，也不只凭音高记忆判断偏差？

<details>
<summary>点开查看逐步解答</summary>

人耳对"每秒几次起伏"这种节奏极其敏感，对绝对音高的记忆却相当模糊。听拍把"频率偏了多少"转换成了"数节拍"：差 3 Hz 就是每秒 3 下，差 0.5 Hz 就是两秒一下，逼近零的过程听得清清楚楚。本质上是把一个难判别的量（频率误差）映射到了一个好判别的量（时间节奏）——这是实验科学的老套路。
</details>

## 7. 选读：包络公式三行推出

<details>
<summary>选读 · 和角公式交作业了</summary>

[和角公式那一课](./40-angle-addition.md)的公式稍作加减就能得到"化和公式"：

$$\sin\alpha + \sin\beta = 2\sin\Big(\frac{\alpha+\beta}{2}\Big)\cos\Big(\frac{\alpha-\beta}{2}\Big)$$

代入 $\alpha = 2\pi f_1 t$、$\beta = 2\pi f_2 t$：

$$y(t) = 2\cos\big(\pi(f_1 - f_2)t\big)\cdot\sin\big(\pi(f_1 + f_2)t\big)$$

前一个因子 $\cos(\pi\Delta f \cdot t)$ 变化极慢，是"音量旋钮"；它的绝对值每 $\frac{1}{\Delta f}$ 秒走完一轮"最强→最强"，所以每秒拍 $\Delta f$ 次。后一个因子以平均频率高速振荡，负责填充细节。一条乘法分配律式的改写，把调音师的耳朵讲明白了——这就是和角公式的现实出场费。

</details>
