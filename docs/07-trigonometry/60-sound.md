# 从波到音：频率是音高，波形是音色

## 1. 从一个场景开始

钢琴和小提琴演奏同一个音，频率分毫不差，你却能一耳朵分辨谁是谁——它们到底差在哪？

答案有两层。第一层你已经会了：频率决定**音高**，440 Hz 就是国际标准音 A4。第二层才是本课的主菜：除了频率，每件乐器还偷偷携带一份自己的"波形配方"——这份配方，有个如雷贯耳的名字：**谐波**。顺着它走下去，就是卷一信号与变换枢纽的大门。

## 2. 直觉解释

空气里的声音就是压强的快速起伏，起伏快慢（频率）被耳朵翻译成高低：

- **频率 ↔ 音高**：振动越快，音越高。男低音百来赫兹，女高音上千赫兹；
- **八度 ↔ 翻倍**：频率恰好翻倍的两个音，听起来像"同一个音，升高一层"——440 Hz 与 880 Hz 同时按下毫无违和。音乐里的"高一个八度"，数学上就是 $\times 2$；
- **音色 ↔ 波形形状**：纯正弦波又细又干净，像口哨；小提琴的波形却带着锯齿花边。形状不同，嗓音就不同——许多看起来很怪的周期形状，都能由一条**基频正弦**加上它的整数倍"影子"（谐波）拼出来。
- 边界提示：真实乐器的音色还包括起音、衰减和轻微噪声；钢琴这类乐器的泛音也可能略偏离整数倍。“谐波配方”是抓住主干的第一层模型，不是全部声学细节。

## 3. 正式定义

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $f$ | 基频 | 决定音高的主振动频率，A4 = 440 Hz |
| 八度 | 倍频关系 | 频率变为 $2f$ 即高一个八度，$4f$ 高两个 |
| $kf$（$k=2,3,\dots$） | 谐波 | 基频的整数倍成分，$2f$ 称二次谐波，以此类推 |
| 音色 | 波形配方 | 基频与各次谐波的"配料比例"，每种乐器一份 |

核心事实（本章只展示、第 16 章证明）：对很广一类周期波形（例如工程里常见的连续分段光滑波形），**都可以写成若干条正弦波的叠加**

$$y(t) = A_1\sin(2\pi ft) + A_2\sin(4\pi ft) + A_3\sin(6\pi ft) + \cdots$$

第一项叫基音，其余全是谐波。两件乐器频率相同而音色不同，差别全在各次谐波的配比上。

## 4. 分步例题

**例**：已知标准音 A4 = 440 Hz，求比它高两个八度的音、以及低一个八度的音。

1. 高一个八度：$440 \times 2 = 880$ Hz（记作 A5）；
2. 再高一个：$880 \times 2 = 1760$ Hz（记作 A6）；合起来 $440 \times 2^2 = 1760$；
3. 低一个八度：除以 2，$440 \div 2 = 220$ Hz（记作 A3）；
4. 检查方向：频率越高音越高，1760 应该听起来"尖"，220 听起来"沉"——符合直觉。

顺便看一眼这串数：220、440、880、1760……每次乘 2，一步一个台阶。这个"每次乘同一个数"的模式叫等比数列——别急着深究，下一章它是主角。

## 5. 动手实验

### 实验 1（viz）：亲手给正弦波"整容"

```viz
{
  "type": "sines",
  "title": "方波的诞生",
  "terms": [1, 3, 5]
}
```

怎么玩：拖动 harmonics 滑杆增加谐波个数——浅色细线是各个成分（1、3、5……倍的奇数谐波），粗蓝线是它们的合影。加得越多，曲线越接近横平竖直的"方波"。这就是音色的来源：**配方越复杂，波形越有性格**。

### 实验 2（python 滑块）：基频的倍频家族同框

```python title="f / 2f / 3f 同框：验证八度就是乘 2"
import math                      # 数学工具库：用 sin 和 pi
import matplotlib.pyplot as plt  # 画图库

# sliders: f=220 [110:440:55]

harmonics = [1, 2, 3]            # 倍数列表：基频的 1、2、3 倍
colors = ["steelblue", "orange", "purple"]

for k in range(3):               # 循环画三条曲线，k 取 0、1、2
    fq = f * harmonics[k]        # 当前音的实际频率 = 基频 × 倍数
    xs = []
    ys = []
    for i in range(400):         # 三条曲线共用同一个时间窗（前 10 毫秒）
        t = i * 0.000025         # 采样步长：0.000025 秒
        xs.append(t)
        ys.append(math.sin(2 * math.pi * fq * t))
    plt.plot(xs, ys, color=colors[k], label=f"{fq} Hz")

plt.xlabel("时间（秒）")          # xlabel：给横轴写标题
plt.legend()
plt.grid(True)
print(f"基频 {f} 的家族: {f}, {2*f}, {3*f}")
```

怎么玩：同样 10 毫秒的窗口里，数一数三色曲线各挤了几个周期——蓝、橙、紫的周期个数恰是 $1:2:3$，因为频率是 $f, 2f, 3f$。其中蓝到橙频率恰好翻倍，这就是八度；无论把 f 滑杆拖到哪（110 是低音 A2，440 就是标准音 A4），"翻一倍 = 高八度"这条铁律都原样成立——倍频关系跟基频具体是多少毫无关系。

### 快问快答

```quiz
男低音约 110 Hz，女高音唱同一音名时约 220 Hz，两者相差多少？
- 半个八度
- 一个八度 [*]
- 两个八度
? 频率恰好翻倍就是一个八度。判断八度永远看"几倍"，而不是"差了多少赫兹"。
```

:::warning[常见误区]

**误区一**："你以为声音越大，音调越高。" 其实响度归振幅管，音高归频率管——第 30 课那两个独立旋钮，在耳朵里也互不干涉。吼得再响也不会变成女高音。

**误区二**："你以为'高八度'只是'稍高一点的同个音'，没有数学含量。" 其实频率严格翻倍，一步就是一倍。大脑对"2 倍频"的归类本能是全人类共有的，一切音律理论都从它出发。

**误区三**："你以为每种音高只有一条正弦波。" 其实纯正弦只有音叉和合成器能发出来；真实乐器的波形都是基频与谐波的合影。波形形状才是音色的身份证，频率只是身份证上的出生日期。

:::

**练习 2**：为什么相差整八度的两个音，听起来如此相似，甚至常被当成"同一个音"？

<details>
<summary>点开查看逐步解答</summary>

设低音基频为 $f$，其谐波列是 $f, 2f, 3f, 4f, \dots$；高音基频为 $2f$，谐波列是 $2f, 4f, 6f, \dots$——恰好整个落进低音频偶数号的位置。两条谐波链几乎完全重叠，耳朵自然判定"同类"。所以八度感不是哪种文化的约定俗成，而是谐波结构的物理事实。
</details>

**练习 3**：列出基频 220 Hz 与基频 440 Hz 两件乐器的谐波列前四项，指出哪些频率是两边共有的。

<details>
<summary>点开查看逐步解答</summary>

220 的谐波列：$220, 440, 660, 880, \dots$；440 的谐波列：$440, 880, 1320, 1760, \dots$。共有成员是 $440, 880, \dots$，即 220 列的全部**偶数号**谐波。

共同谐波越多，两个音融合得越好——这正是"协和音程"的底层原理之一，也是和弦配置的经验法则背后的数学。
</details>

## 7. 选读：八度之间的 12 级台阶

<details>
<summary>选读 · 十二平均律，以及门口的傅里叶</summary>

一个八度之内，钢琴放了 12 个半音键。规矩是：相邻两个半音的频率**比值**全部相同——每按一个键，频率乘 $2^{1/12} \approx 1.05946$。这样走上 12 级，恰好乘出 $2^{12/12} = 2$，严丝合缝落进下一个八度。

盯住这个结构：每一项都等于前一项乘同一个固定的数。这种数列叫**等比数列**——下一章《数列与归纳法》的主角提前客串。当年数学家为了给键盘"平均分工"，硬是把音乐问题做成了指数问题。

再看另一个方向：实验 1 里那条越拼越方的曲线演示了一个大胆的断言——任何周期波形都能拆成正弦波的合影。这条断言叫**傅里叶级数**，第 16 章正式兑现。届时你会发现，本章练的每一件兵器——单位圆、弧度、振幅频率相位、和角公式、叠加原理——全都排上了用场。

</details>
