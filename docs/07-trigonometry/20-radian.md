# 弧度制：拿弧长当量角器

## 1. 从一个场景开始

为什么一圈偏偏是 360 度？这是四千年前巴比伦人玩六十进制的遗产——跟圆本身的性质没有半点关系。长度有米，重量有千克，都是"贴着测量对象"定出来的单位；唯独角度，我们一直在用一个外来户口。

数学家的做法很直接：不满意，就另立一套贴着圆本身性质的单位。这一课的弧度制，会让角度第一次**和长度直接挂钩**。

## 2. 直觉解释

回忆[单位圆那一课](./10-unit-circle.md)（半径为 1）。你站在 $(1, 0)$ 沿圆走，走出一段弧，回头看看自己转了多少角度——你会发现一件妙事：

**在半径为 1 的圆上，走过的弧有多长，就等于转了多少角度。**

走 1 个单位长的弧 = 转"1 份"角（后来叫 1 弧度）；走半个周长 $\pi \approx 3.14$ = 转了半圈；走完整圈 $2\pi \approx 6.28$ = 回到起点。

也就是说，角度不再是抽象的"多少度"，而是实实在在的**路程**。这套记法就叫弧度制，单位是"弧度"（radian，简写 rad，经常干脆省略不写）。

## 3. 正式定义

半径为 $r$ 的圆上，弧长 $s$ 对应的圆心角（弧度）定义为：

$$\theta = \frac{s}{r}$$

半径取 1 时 $\theta = s$，弧长即角度。由此得到两套单位的换算关系：

$$180° = \pi \text{ rad}, \qquad 360° = 2\pi \text{ rad} = \tau$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\theta$ | 弧度角 | 弧长 ÷ 半径，纯数字无单位 |
| $s$ | 弧长 | 沿圆走的路程 |
| $r$ | 半径 | 与弧长配套 |
| $\pi$ | 圆周率 | 半圈 = $\pi$ rad = $180°$ |
| $\tau$ | 一整圈 | $\tau = 2\pi \approx 6.28$，"数学家的 360" |

由比例关系立刻写出双向换算公式：

$$\text{弧度} = \text{度} \times \frac{\pi}{180}, \qquad \text{度} = \text{弧度} \times \frac{180}{\pi}$$

## 4. 分步例题

**例 1**：把 $90°$ 换成弧度。

1. 套公式：$90 \times \dfrac{\pi}{180}$；
2. 约分：$90$ 与 $180$ 约掉一半，得 $\dfrac{\pi}{2}$；
3. 结论：$90° = \dfrac{\pi}{2}$ rad $\approx 1.571$。

**例 2**：把 $\dfrac{3\pi}{2}$ rad 换回度。

1. 套反向公式：$\dfrac{3\pi}{2} \times \dfrac{180}{\pi}$；
2. $\pi$ 消掉，$\dfrac{3}{2} \times 180 = 270$；
3. 结论：$\dfrac{3\pi}{2}$ rad $= 270°$——三个直角，指针指在"9 点"方向。

怎么玩：波形从 0 出发，在 $x = \pi \approx 3.14$ 处归零，在 $x = 2\pi \approx 6.28$ 完成第一个完整周期——12.56 正好装下**两个周期**。注意横轴刻度全是 $\pi$ 的倍数：这才是正弦波的"原生坐标系"。

### 实验 2（python）：math.tau 正式登场

想表达"转一整圈"，你只能写 `2 * math.pi`——乘号、数字、常数三件套缺一不可。这个高频组合值得一张官方身份证：

```python title="math.tau：一整圈的官方常数"
import math

print(math.tau)           # math.tau：一整圈的弧度数，等于 2π ≈ 6.2832
print(math.radians(180))  # 半圈：约 3.1416 —— 这就是 π 本尊

# 常用角度换算表：弧度 = 度 × π ÷ 180
degs = [0, 30, 45, 60, 90, 180, 360]
for d in degs:            # 循环取出每个角度
    rad = d * math.pi / 180   # 手动套换算公式
    print(f"{d}° = {round(rad, 4)} rad")
```

怎么玩：核对换算表——$30° \approx 0.5236$、$360° \approx 6.2832$ 与 `math.tau` 完全一致。以后写代码想转一圈，直接用 `math.tau` 比 `2 * math.pi` 更一目了然。

### 实验 3（python）：弧度 × 半径 = 弧长

```python title="弧度制的福利：弧长一步到位"
import math

# sliders: theta_deg=60 [10:350:5], r=1 [1:3:1]

theta = theta_deg * math.pi / 180   # 先把角度换算成弧度
arc_len = theta * r                  # 弧度制福利：弧长 = 弧度角 × 半径
print(f"{theta_deg}° = {round(theta, 4)} rad")
print(f"半径 {r} 时，弧长 ≈ {round(arc_len, 4)}")
```

怎么玩：拖动滑杆对照第 5 章扇形课的公式 $L = \frac{\theta}{360}\cdot 2\pi r$——两种算法结果相同，但弧度版连 360 都不用出现了。默认参数下 $60° \approx 1.0472$ rad，半径 1 时弧长恰好也是 1.0472：角度就是路程。

### 实验 4（viz）：扇形组件重访——半径 1 时，弧长就是角度

第 5 章量扇形用的老朋友回来了，这次把半径拧到 1，用弧度的眼光重看它：

```viz
{
  "type": "sector",
  "theta": 180,
  "r": 1
}
```

怎么玩：拖动"半径"到 1（单位圆！），再拖动"角度"。橙色圆弧的读数会告诉你一件惊人的事：**半径为 1 时，弧长 L 的数值就等于角度本身**——$180°$ 时 $L \approx 3.14 = \pi$，$90°$ 时 $L \approx 1.57 = \frac{\pi}{2}$。这不是巧合，这正是弧度的定义：角度就是单位圆上走过的路程。再把角度一路拖到 $350°$：弧长逼近 $2\pi r \approx 6.28$——还记得圆周率课上"周长是直径的三倍多"吗？转满一圈的路程恰好是 $\tau$。

### 快问快答

```quiz
180° 用弧度表示是多少？
- 1 rad
- π rad [*]
- 2π rad
? 一整圈是 2π（也就是 math.tau），半圈自然是 π。顺带记住：1 rad ≈ 57.3°。
```

:::warning[常见误区]

**误区一**："你以为 π 就等于 180°。" 其实 π 是个数（3.14159…），"180°" 只是它在角度制下的化名。严谨的说法是"$\pi$ **rad** = $180°$"——rad 可以省略，但概念上它是弧度制的一员。

**误区二**："你以为转一整圈是 360 rad。" 其实一圈只有 $\tau = 2\pi \approx 6.28$ 弧度。360 是老习俗，6.28 才是数学原生值。

**误区三**："你以为弧度和度随便混用、公式都一样。" 其实用度数参与运算前必须先换算——[单位圆那一课](./10-unit-circle.md)的 `math.sin(30)` 错误就是没换算的结果。后面章节的许多漂亮公式也都默认弧度制。

:::

**练习 2**：钟表的分针走了 25 分钟，针尖转过了多少弧度？

<details>
<summary>点开查看逐步解答</summary>

分针 60 分钟转一整圈 $\tau = 2\pi$，所以 25 分钟转过

$$\frac{25}{60} \times 2\pi = \frac{5\pi}{6} \approx 2.618 \text{ rad}$$

验证代码：`print(round((25 / 60) * math.tau, 3))` 输出 `2.618`。
</details>

**练习 3**：既然度数也能用，数学家为什么非要另立弧度制？

<details>
<summary>点开查看逐步解答</summary>

三个理由层层递进：① 定义干净——弧度就是"弧长 ÷ 半径"，不需要人为规定的 360；② 公式变短——弧长直接是 $\theta \cdot r$（本课实验 3），省掉 $\frac{\pi}{180}$ 因子；③ 最关键的伏笔：只有在弧度制下，当 $x$ 很小时才有 $\sin x \approx x$，将来第 13 章还会看到 $(\sin x)' = \cos x$ 这样的极简导数公式——换成度数，处处都要背着一个难看的换算系数。
</details>

## 7. 选读：τ 党的宣言

<details>
<summary>选读 · "π 是错的"？一场真实的数学论战</summary>

2010 年前后，数学家 Bob Palais 与 Michael Hartl 发起了著名的 "Tau Manifesto"：圆的自然属性跟着**半径**走（周长 $C = 2\pi r$），可常数却按直径定义成 $\pi = C/d$，于是"一整圈"永远得写成别扭的 $2\pi$。

他们的主张：把一整圈命名为 $\tau = 2\pi$。从此一圈 $\tau$、半圈 $\tau/2$、四分之一圈 $\tau/4$——数字与直观完全对齐；而 $\pi$ 记法里四分之一圈偏偏是"$\pi/2$"，处处差着因子 2。Python 把 `math.tau` 收入标准库，正是这场运动的余波。

当然，$\pi$ 党依然人多势众——毕竟两者只差一个常数因子。重要的不是站队，而是你心里清楚：**一整圈到底是 6.28，不是 360，也不是 3.14**。

</details>
