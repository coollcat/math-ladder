# 正切：影子之比与坡度

## 1. 从一个场景开始

山路上常见一块黄底黑字的坡度牌："10% 下坡"。意思是：水平方向每前进 100 米，路面就下降 10 米。司机关心的是"陡不陡"——而"陡不陡"既不单看升降（10 米不算什么），也不单看前进（100 米也不算什么），而是这两个数的**比值**：10 ÷ 100 = 0.1。

"竖直变化 ÷ 水平变化"这把比值尺子，量遍一切"斜"的东西：坡道、屋顶、大坝、滑雪道，连一次函数的斜率也是它。数学给这个比值起了正式的名字——**正切**，记作 tan。上一课转单位圆时，sin 管高低、cos 管左右，各管一根影子；正切管第三件事：**两根影子之比**。

## 2. 直觉解释

回到[单位圆](./10-unit-circle.md)。转过角度 $\theta$ 后，落点是 $(x, y)$：横坐标 $x = \cos\theta$ 是横向影子，纵坐标 $y = \sin\theta$ 是纵向影子。正切的定义朴素到只有一句：

**tan θ = 纵影子 ÷ 横影子。**

- 角度小：落点靠右又靠下，横影子长、纵影子短，比值接近 0——路面几乎是平的；
- 角度到 45°：两根影子一样长，比值恰好是 1；
- 角度逼近 90°：落点冲向正上方，横影子缩向 0——"除以一个越来越小的数"，比值一路暴涨；
- 到 90°：横影子正好是 0，**除以零**——正切在这一刻没有定义。

所以 tan 的脾气和 sin、cos 完全不同：后两位最多在 $-1$ 到 $1$ 之间打转，tan 却能冲到任意高。它量的不是"位置"，是"陡"。

## 3. 正式定义

$$\tan\theta = \dfrac{\sin\theta}{\cos\theta} = \dfrac{y}{x} \qquad (\cos\theta \neq 0)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\tan\theta$ | 正切 | 纵影子 ÷ 横影子，衡量"陡不陡" |
| $\cos\theta \neq 0$ | 前提 | 横影子不能为 0：$\theta \neq 90°, 270°, \dots$ |
| 坡度 i% | 工程写法 | $\tan(\text{坡角}) = \dfrac{i}{100}$ |

用单位圆特殊值现场制造 tan 的特殊值——每一格都是 sin 行除以 cos 行：

| $\theta$ | $0°$ | $30°$ | $45°$ | $60°$ | $90°$ |
| --- | --- | --- | --- | --- | --- |
| $\sin\theta$ | $0$ | $\frac12$ | $\frac{\sqrt2}{2}$ | $\frac{\sqrt3}{2}$ | $1$ |
| $\cos\theta$ | $1$ | $\frac{\sqrt3}{2}$ | $\frac{\sqrt2}{2}$ | $\frac12$ | $0$ |
| $\tan\theta$ | $0$ | $\frac{\sqrt3}{3}\approx 0.577$ | $1$ | $\sqrt3\approx 1.732$ | 不存在 |

## 4. 分步例题

**例 1**：手算 tan 60°。

1. 查上表（或亲手造）：$\sin 60° = \dfrac{\sqrt3}{2}$，$\cos 60° = \dfrac12$；
2. 相除：$\dfrac{\sqrt3/2}{1/2} = \sqrt3$；
3. 结论：$\tan 60° = \sqrt3 \approx 1.732$——每水平前进 1 米爬升 1.732 米，相当陡。

**例 2**：坡度牌的应用。某山路坡度 10%（坡角的正切为 0.1），汽车水平前进 50 米，升高了多少？

1. 正切的定义：$\tan(\text{坡角}) = \dfrac{\text{升高}}{\text{水平前进}}$；
2. 代入：$0.1 = \dfrac{h}{50}$；
3. 解出：$h = 50 \times 0.1 = 5$ 米。

留个悬念：这块牌子对应的"坡角"到底是多少度？由比值反查角度是反三角函数的活儿——55 课的 atan2 专管这件事。

## 5. 动手实验

### 实验 1（viz）：tan 与 sin 同框——90° 前的分道扬镳

```viz
{
  "type": "plot",
  "title": "蓝 tan 越靠近 90° 越疯，橙 sin 温吞",
  "expr": "tan(x)",
  "expr2": "sin(x)",
  "xmin": -1.45,
  "xmax": 1.45
}
```

怎么玩：横轴是弧度（$90° \approx 1.571$ 弧度，画到 $\pm 1.45$ 是为了不撞上爆炸墙）。两条线在 $x=0$ 附近几乎贴在一起——小角度时 $\sin\theta \approx \tan\theta$，量坡度的两种算法不分彼此；越往右，sin 还慢悠悠爬向 1，tan 已经垂直起飞。这就是"陡"的数学长相。

### 实验 2（python 滑块）：逐点对拍 tan = sin ÷ cos

```python title="手算比值，对拍官方 math.tan"
import math

# sliders: deg=45 [0:89:1]

rad = math.radians(deg)                  # 度 → 弧度：喂给三角函数前的固定工序
t_hand = math.sin(rad) / math.cos(rad)   # 手算：纵影子 ÷ 横影子
t_off = math.tan(rad)                    # 官方工具 math.tan 正式登场（同样只吃弧度）
print(f"{deg}°: 手算 {round(t_hand, 6)} | 官方 {round(t_off, 6)}")
```

怎么玩：deg 拖到 0，两条路都给 0；拖到 45，双双给 1；拖到 89，tan 冲到约 57——横影子只剩 0.017，"除以小数"的威力现场表演。滑杆特意停在 89：如果你手动改成 90，Python 不会报错，而是吐出一个约 $1.6 \times 10^{16}$ 的天文数字——浮点世界里的 cos 90° 不是精确的 0（约为 $6.1 \times 10^{-17}$），"除零的爆炸"被机器演成了"除以一粒尘埃"。数学上，tan 90° 就是**没有定义**。

### 实验 3（python）：tan 的全貌——一节一节，无限重复

```python title="画出完整的 tan：分支与爆炸墙"
import math
import matplotlib.pyplot as plt   # 画图工具箱（00 章 20 课登场过）

bx = [[]]                         # 每条分支的横坐标清单（先备一条空分支）
by = [[]]                         # 同一条分支的纵坐标清单
cur = 0                           # 当前分支的编号
x = -6.9                          # 从 −6.9 弧度画到 6.9 弧度
while x <= 6.9:                   # while：还没画到右边界就继续（00 章约定五的手艺）
    t = math.tan(x)
    if abs(t) > 8:                # 值冲出 ±8：撞上爆炸墙了
        if len(bx[cur]) > 0:      # len：数一数当前分支攒了几个点
            cur = cur + 1         # 当前分支到此为止
            bx.append([])         # append：往清单末尾追加一条空分支
            by.append([])
    else:
        bx[cur].append(x)         # 把这个点记进当前分支
        by[cur].append(t)
    x = x + 0.02                  # 步子迈小一点，曲线才平滑

for i in range(len(bx)):          # 一条一条分支分别连线
    plt.plot(bx[i], by[i], color="tomato")
for wall in [-4.71, -1.57, 1.57, 4.71]:   # 四堵爆炸墙：±π/2 与 ±3π/2
    plt.plot([wall, wall], [-8, 8], linestyle="--", color="gray")   # 两点连一条竖直虚线
plt.grid(True)
plt.title("y = tan(x)：180° 一节，无限重复")
plt.xlabel("x (radians)")
plt.ylabel("tan x")
```

怎么玩：tan 的完整图像是一节一节的"爬山分支"，灰色虚线是每节的爆炸墙（cos 在那里为 0）。盯住一件事：每堵墙左右两侧，曲线一头从负无穷蹿上来、一头朝正无穷冲出去——**每一节都在重演同一场爆炸**，因为 tan 的周期是 180°（练习 3 给理由）。

### 快问快答

```quiz
tan 90° 为什么不存在？
- 因为 sin 90° 等于 1
- 因为 cos 90° 等于 0，除以零没有定义 [*]
- 因为 tan 90° 等于 0
? tan = sin ÷ cos。90° 时横影子 cos 缩到 0，除以零在数学里没有定义——图像冲天只是"越来越陡"的趋势，不是函数值。
```

::::warning[常见误区]

**误区一**："你以为 tan 90° = ∞。" 其实 90° 处正切**没有定义**——不是"等于无穷大"，而是"这个点根本不在函数的地盘上"。图像冲天描述的是趋势，不是取值。

**误区二**："你以为 math.tan 也吃度。" 一样只吃弧度！`math.tan(45)` 算的是 45 弧度（约 2578°）的正切，答案毫不相干。先过 `math.radians` 再进门。

**误区三**："你以为坡度 10% 就是 sin 10°。" 坡度百分数的定义是 tan（升高 ÷ 水平前进），不是 sin（升高 ÷ 斜面长）。小角度时两者数值接近（10% 坡的坡角约 5.7°，$\sin 5.7° \approx 0.0995$），但身份不同。

::::

**练习 2**：坡度 12% 的大桥引桥，水平前进 80 米，桥面升高多少米？

<details>
<summary>点开查看逐步解答</summary>

坡度 12% 意思是 $\tan(\text{坡角}) = 0.12$。由正切定义：升高 = 80 × 0.12 = **9.6 米**。
</details>

**练习 3**：用单位圆解释：为什么 tan 的值转半圈（θ → θ + 180°）一模一样？

<details>
<summary>点开查看逐步解答</summary>

转半圈后落点从 $(x, y)$ 走到 $(-x, -y)$——横纵影子同时变号。比值 $\dfrac{-y}{-x} = \dfrac{y}{x}$ 原封不动：分子分母一起翻号，商不变。所以 tan 的周期是 180°，图像每 180° 重演一节。
</details>

## 7. 选读：正切就是斜率

<details>
<summary>选读 · 一次函数斜率的大团圆</summary>

第 6 章说一次函数 $y = ax + b$ 的 a 叫斜率："x 每增加 1，y 增加 a"。现在给它一个三角身份：直线与 x 轴正方向的夹角叫**倾角** $\varphi$，则

$$a = \tan\varphi$$

理由：沿直线水平前进 1，竖直恰好前进 a——"竖直 ÷ 水平"正是正切的定义。tan 管陡不陡、斜率也管陡不陡，它们是同一个概念的两次报名。55 课的 arctan 把这件事反过来用：给斜率反查倾角。

</details>
