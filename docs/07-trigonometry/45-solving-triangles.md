# 解三角形：正弦定理与余弦定理

## 1. 从一个场景开始

河对岸立着一座信号塔。你在 A 点测得视线方向的仰角，往前走 30 米到 B 点再测一次——塔脚在水里，谁也无法拎着尺子游过去量高度，可两个观测点加上塔顶已经围出一个完整的三角形：**知道了两角一边，其余的边和角全都可以"算"出来**。

航海定位、隧道掘进、GPS 三边交汇，干的全是这件事。勾股定理只伺候直角三角形（[面积与勾股定理](../05-geometry/20-area-pythagoras.md)），而现实世界里的三角形大多不长直角。这一课补齐两件通用工具：余弦定理管"边角互换"，正弦定理管"边角成对查询"。

## 2. 直觉解释

先暴力拆解：任何斜三角形，从任一顶点往对边作一条高，立刻裂成**两个直角三角形**——勾股定理加正弦定义，理论上就能啃下一切。麻烦只在于步骤啰嗦。

拿最关心的问题试刀：已知两边 $b$、$c$ 和它们的夹角 $A$，第三边 $a$ 是多长？把高作在 $c$ 边上：

- 直角三角形①给出：高 $h = b\sin A$，靠外的那段底 $= b\cos A$；
- 直角三角形②里剩一段底 $= c - b\cos A$；
- 对②用勾股定理：$a^2 = h^2 + (c - b\cos A)^2$；
- 展开合并（$\sin^2 + \cos^2 = 1$ 帮忙消掉一项）：

$$a^2 = b^2 + c^2 - 2bc \cos A$$

看最后一行——当 $A = 90°$ 时 $\cos A = 0$，公式瞬间缩水成 $a^2 = b^2 + c^2$：勾股定理原封不动地站在里面。**新公式不是推翻老朋友，而是把老朋友装进了更大的口袋。**

## 3. 正式定义

$$a^2 = b^2 + c^2 - 2bc\cos A \qquad \text{（余弦定理）}$$

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} \qquad \text{（正弦定理）}$$

| 记号 | 含义 | 使用场景 |
| --- | --- | --- |
| $a, b, c$ | 三条边的长度 | 惯例：顶点 A、B、C 的对面那条边用对应小写字母 |
| $\cos A$ | 夹角 A 的余弦 | 已知两边夹角求第三边；或三边齐全反查角 |
| $\sin A$ | 角 A 的正弦 | 已知两角任一边求其余；或两边一对角查角 |
| 主打句式 | —— | "知三求三"：六个量凑够三个独立信息，整个三角形被钉死 |

分工口诀：**画得出夹角用余弦（SAS、SSS），配得成对边对角用正弦（AAS、ASA）**。三角形内角和恒为 180° 是这两条定理之外永远免费的第三个条件。

## 4. 分步例题

**例**：一块三角形花坛，两条邻边分别是 3 米与 8 米，夹角恰好 60°。求第三边长。

1. **认阵型**：两边带夹角——SAS 阵型，请出余弦定理；
2. **代入**：$a^2 = 3^2 + 8^2 - 2 \times 3 \times 8 \times \cos 60°$；
3. **查表**：单位圆里 $\cos 60° = 0.5$（[单位圆上的 sin 与 cos](./10-unit-circle.md) 的表格第一排就躺着它），于是 $a^2 = 9 + 64 - 48 \times 0.5 = 49$；
4. **开方**：$a = 7$ 米——连小数都没出，漂亮；
5. **回头对账**：三角形不等式检查 $3 + 7 > 8$ 成立；若把本题当 SSS 反查角，也会精确还原 60°，双向闭环。

第 4 步隐藏着这道题被设计出来的机关：作者先挑好三边 3、7、8，再反解出 $\cos A = (9 + 64 - 49)/48 = 0.5$——甜点是人造的，路是真走的。

怎么玩：横轴是夹角（单位度）。默认 b=3、c=8 时在 x=60 处曲线的高度正是 7——分步例题被原样画了出来。拧到 x=90：读数变成 $\sqrt{3^2+8^2}\approx 8.54$，勾股定理当场接管；继续拧向 180°，两臂展平、第三边逼近 $b+c=11$ 却永远够不着。曲线全程爬升没有回头路：**夹角越大，对边越长**，这便是"大角对大边"的函数版。

### 实验 3（python）：三边齐全，把每个角都请出来

```python title="SSS 反查全部角度"
import math                             # 数学库：acos 反查角度、degrees 换算度数

a = 5                                   # 边 a：对着角 A
b = 6                                   # 边 b
c = 7                                   # 边 c

cos_A = (b*b + c*c - a*a) / (2*b*c)     # 余弦定理变形：解出角 A 的余弦值
ang_A = math.degrees(math.acos(cos_A))  # acos 吃 −1..1 的余弦、吐出弧度；degrees 把弧度翻成度
print(round(ang_A))

cos_B = (a*a + c*c - b*b) / (2*a*c)
ang_B = math.degrees(math.acos(cos_B))
print(round(ang_B))

cos_C = (a*a + b*b - c*c) / (2*a*b)
ang_C = math.degrees(math.acos(cos_C))
print(round(ang_C))

print(round(ang_A + ang_B + ang_C))     # 内角和免费体检
```

怎么玩：跑一次得到 44、57、78，最后一行印着 180——三兄弟在对账。这是 `math.acos` 第一次上岗：上一节我们只会"由角度算余弦"，它是倒带的查询键（真正的反函数专门课紧随其后）。试着把三条边改得不合法（比如 1、2、9），`math.acos` 会收到一个超出 −1 到 1 的荒谬输入直接报警——**边界本身就是检验器**。

### 快问快答

```quiz
"知道两条边和其中一条的对角"（SSA 阵型）能唯一确定三角形吗？
- 能，和其他阵型一样唯一
- 不能，有时能拼出两种不同的三角形 [*]
- 不能，任何情况下都拼不出来
? SSA 是出了名的歧义阵型：那根对边太短时，圆规转一圈能交出锐角、钝角两个落点。正弦定理算出的角可以有两个互补的候选——这就是勘测队员宁可绕路也要测出夹角的原因。
```

:::warning[常见误区]

**误区一**："你以为 SSA 一定唯一。" 对边短于已知边的“垂直投影”时出现双解：同一个数据包能搭出一锐一钝两个三角形。用正弦定理解题后必须先问一句"互补的那个角也能合上吗"，否则导航会把你引到湖对岸的同名街道。

**误区二**："你以为随便编三条边都有三角形。" 必须满足"任意两边之和大于第三边"；把它代进余弦定理，表现为某个 $\cos$ 值冲出 −1 到 1 的合法区间——数学库当场罢工，这其实是好事。

**误区三**："你以为数学库里的角天生是度。" `math.acos` 返回弧度，忘了用 `math.degrees` 翻译就直接打印，会把 60 度错读成约 1.05——弧度制的老规矩在这里照旧生效（[弧度制](./20-radian.md)）。

:::

## 6. 练习

**练习 1**：航海图上，灯塔 L 与礁石 R 相距 8 海里，货船 P 距灯塔 3 海里，P 与 R 间的张角 PLR 为 60°。求船到礁石的距离 PR，并用另一组数据复检勾股退化情形（两边 6 与 8、夹角 90°）。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：船离礁石还有多远
# @check: 7
# @check: 10
# @hint: 余弦定理的核心项是 2bc·cosA——初始代码丢了 cos 因子，等于把夹角当成 60 度也没用的"满额扣减"；90 度那一问是免费的体检台，改对了它自然亮绿灯。
import math                     # 数学库：sqrt 开平方

def third_side(b, c, angle_deg):            # def 定义函数：打包可复用的计算流程
    return round(math.sqrt(
        b*b + c*c - 2 * b * c))             # ← 缺了什么关键因子？

print(third_side(3, 8, 60))                 # 主问题：60 度夹角
print(third_side(6, 8, 90))                 # 体检：直角应退化为勾股定理
```

<details>
<summary>点开查看逐步解答</summary>

1. **找回 cos 因子**：余弦定理 $a^2 = b^2+c^2 - 2bc\cos A$ 里，减掉的是 $2bc$ **乘以** $\cos A$ 的份额；丢掉因子等于假设 $\cos A = 1$，也就是把夹角当成 0°——三角形的两臂焊死重叠，荒谬感从答案 5（应为 7）中肉眼可见。
2. **主问题核对**：$3^2+8^2 - 2\times3\times8\times0.5 = 73 - 24 = 49$，开方得 7 ✓。
3. **勾股体检**：夹角 90° 时 $\cos A = 0$，修正后的公式只剩 $b^2+c^2 = 36+64 = 100$，开方恰为 10 ✓——这正是 [面积与勾股定理](../05-geometry/20-area-pythagoras.md) 的熟面孔，旧定理在新定律下的进场券验讫。

修正后的参考代码：

```python
import math                     # 数学库：sqrt 开平方

def third_side(b, c, angle_deg):
    cos_A = math.cos(math.radians(angle_deg))   # 角度换弧度后再取余弦
    return round(math.sqrt(
        b*b + c*c - 2 * b * c * cos_A))

print(third_side(3, 8, 60))
print(third_side(6, 8, 90))
```

输出 `7` 与 `10`，与判题窗逐行一致 ✓。

</details>

## 7. 边界与适用条件

本课公式只在**平面欧氏几何**内成立：球面航线、曲面工件上的三角形各有自己的球面/双曲版本，那里的内角和甚至超过 180°。数值上也要留个心眼——极小的角度会让正弦定理除数逼近零，浮点误差被放大；真要精算远航定位，得升级到最小二乘类的整体拟合。另外，面积公式、海伦公式与外接圆半径公式都是本课公式的近亲，此处只借力不展开证明。

## 8. 选读：用"面积对账"推出正弦定理

<details>
<summary>选读 · 三种算法算同一块地</summary>

三角形还是那个三角形，面积却有三套写法：以边 $c$ 为底、$b\sin A$ 为高，得 $\frac{1}{2}bc\sin A$；轮换两条边，又得到另外两套。同一块地，三种丈量：

$$S = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ca\sin B$$

三式同时除以公共因子 $\frac{1}{2}abc$，右边的边长成对相消，只留下：

$$\frac{\sin C}{c} = \frac{\sin A}{a} = \frac{\sin B}{b}$$

取倒数、调整次序，即正弦定理。整条证明只用了一次"同一条高写出两种报法"的观察，外加一步公平的分除。

至于三段相等的比值究竟等于谁？答案是外接圆直径 $2R$：把直径与圆周角拼成直角三角形，$\sin(\text{圆周角}) = \frac{\text{对边}}{2R}$ 一眼可读。这条古典路线等圆的知识攒够了再去验收也不迟。
</details>
