# 三角函数与振动：会转圈的数学

前六章的图形都是静止的——画一条直线、一条抛物线，它们就停在那里。这一章，数学第一次**动起来**：让一个点沿单位圆匀速转圈，再把它的影子摊平，就得到一条永不停歇的波浪线。别小看它——声音是空气在这样振动，潮汐是月亮带着海水这样起落，家里的交流电每秒就这样起伏 50 次。

振动是一门通用语言：说话、音乐、地震波、无线电……全都在说它。本章终点你会拿到一句惊人的断言：**很广一类复杂的周期波，都是一堆正弦波的合影**——这正是卷一枢纽站傅里叶变换的全部秘密。下一章我们先去《数列与归纳法》领一件趁手的武器：数学归纳法。

## 实战挑战 · 电网上的正弦波

> 改编自经典题型（高中物理·正弦交流电模型，u = 311sin(100πt) V 是教材与试题的经典设定）。

我国家庭插座里的电压随时间起伏，瞬时值近似为

$$u(t) = 311 \cdot \sin(100\pi t) \quad (\text{伏})$$

其中 $t$ 以秒计。311 只是电压峰值——插座标称的"220 V"是另一回事（有效值，高中物理会讲），这里只玩波形本身。

**(a)** 这路交流电的频率是多少赫兹？（对照 [波的解剖学](./30-wave-anatomy.md)：括号里 $100\pi$ 扮演的是角频率 $B$）

**(b)** 在 $t = \dfrac{1}{200}$ 秒这一瞬间，电压是多少伏？

**(c)** 邻居家的备用发电机频率略高，是 52 Hz。两台发电机并网前若同时接示波器，会看到"拍"。拍频是多少？

把三问一起交给判题窗：

```exercise
# @title: 实战挑战：电网上的正弦波
# @check: 50
# @check: 311
# @check: 2
# @hint: 频率 = 角频率 ÷ 2π；t = 1/200 秒时相位 ωt = 100π × 1/200 = π/2，恰好转到最高点；拍频 = 两频率之差的绝对值。除法会出小数尾巴，包一层 round() 再打印。
import math

omega = 100 * math.pi   # 角频率 ω（弧度/秒）：来自 u = 311·sin(ωt)
grid = 52               # 备用发电机的频率（Hz）

freq = 0                # (a) 这路交流电的频率
print(freq)

t = 1 / 200             # 四分之一周期的时刻（这行不用改）
u = 0                   # (b) 此刻的电压瞬时值：311·sin(ω·t)
print(u)

beat = 0                # (c) 并网前的拍频
print(beat)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 波的解剖学告诉我们 $T = \dfrac{2\pi}{B}$、$f = \dfrac{B}{2\pi}$。这里 $B = 100\pi$：

$$f = \frac{100\pi}{2\pi} = 50 \text{ Hz}$$

每秒 50 个周期——这正是"市电 50 Hz"的出处。

**(b)** 先算相位：$\omega t = 100\pi \times \dfrac{1}{200} = \dfrac{\pi}{2}$，即转了四分之一圈。单位圆上 $\sin\dfrac{\pi}{2} = 1$（[单位圆](./10-unit-circle.md) 的表格第一行就写着它），所以

$$u = 311 \times 1 = 311 \text{ V}$$

这一瞬间恰好压在**波峰**上。顺带看清了：峰值 311 V 比铭牌上的 220 V 高——有效值与峰值差着 $\sqrt{2}$ 倍，那是高中物理的故事。

用 Python 一路验算（复制进浮窗运行；`math.sin` 要到本章第 10 课才正式登场）：

```
import math

omega = 100 * math.pi
freq = round(omega / (2 * math.pi))
print(freq)

u = round(311 * math.sin(omega * (1 / 200)))
print(u)

print(abs(52 - freq))
```

输出 `50`、`311`、`2`，与判题窗一致 ✓。（`math.sin(math.pi / 2)` 精确等于 1.0，round 后稳稳落在 311。）

**(c)** 拍频 = 频率差（[波的叠加与拍音](./50-beats.md)）：$\lvert 52 - 50 \rvert =$ **2 Hz**——示波器上的包络每秒"呼吸"两次。

</details>

## 章节大题：调音师的全套账单

学完本章，来替调音师把一次调音的**全套账单**算完。下面的代码把**波形读式（$A\sin(\tau f t)$ 的两个成分）、单位圆特殊值、和角公式、拍频、八度与谐波**一次全用上——它能跑，但账单上有三处错。把它修到四行检查全部通过：

```exercise
# @title: 章节大题：调音师的全套账单
# @check: 成分: 220 Hz 振幅 1.0 | 222 Hz 振幅 0.5
# @check: 和角: sin(30°+60°) = 1.0, 公式成立: True
# @check: 拍频: 每秒 2 次
# @check: 八度: 2 倍频 -> 高 1 个八度, 第 2 谐波
# @hint: 三处暗坑：math.sin 只认弧度，90 得先过 math.radians 再进门；拍是两个频率互相追赶的声音，取决于「差」而不是「和」；高一个八度是频率乘 2——倍数不等于八度的个数。
import math

# —— 第一笔账：读出合成波的两个成分 ——
# 标准音叉与一根略走音的弦同时响，空气里的合成波：
# y(t) = 1.0·sin(220·τ·t) + 0.5·sin(222·τ·t)，其中 τ = math.tau = 2π（第 20 课登场过）
f1 = 220      # 第一成分频率：括号里除掉 τ 后剩下的系数（读式见第 30 课）
a1 = 1.0      # 第一成分振幅：sin 前面的系数
f2 = 222      # 第二成分频率
a2 = 0.5      # 第二成分振幅
print(f"成分: {f1} Hz 振幅 {a1} | {f2} Hz 振幅 {a2}")

# —— 第二笔账：用和角公式核对一个特殊角 ——
deg_a = 30    # 已知角 a（注意单位是度！）
deg_b = 60    # 已知角 b（注意单位是度！）
lhs = math.sin(deg_a + deg_b)          # ← sin(90)？先想想 math.sin 吃的是什么单位
rhs = (math.sin(math.radians(deg_a)) * math.cos(math.radians(deg_b))
       + math.cos(math.radians(deg_a)) * math.sin(math.radians(deg_b)))
print(f"和角: sin({deg_a}°+{deg_b}°) = {round(lhs, 4)}, 公式成立: {abs(lhs - rhs) < 1e-9}")

# —— 第三笔账：调音师听到的「呼吸声」 ——
beat = f1 + f2   # ← 拍频该用加法还是……？
print(f"拍频: 每秒 {round(beat)} 次")

# —— 第四笔账：调准之后，对照高音区的标准音 440 Hz ——
times = 440 // f1     # 440 是 220 的几倍（// 整除，保住整数）
octaves = times       # ← 频率是 2 倍，就等于「高 2 个八度」吗？
harmonic = times      # 它同时是基频的第几号谐波？
print(f"八度: {times} 倍频 -> 高 {octaves} 个八度, 第 {harmonic} 谐波")
```

<details>
<summary>点开查看逐步解答</summary>

三处暗坑对应的正是本章三条主线：

1. **度与弧度**（[10](./10-unit-circle.md)、[20 课](./20-radian.md)）：`math.sin(90)` 把 90 当成 **90 弧度**——相当于转了 14 圈半，落点毫无特殊可言（≈ 0.894）。角度必须先过 `math.radians()` 才能进门：$\sin\dfrac{\pi}{2} = 1$，正是单位圆表格最顶上的那个最高点。右边按和角公式（[40 课](./40-angle-addition.md)）展开后，拿 30°、60° 的单位圆特殊值手算也对得上：$\frac{1}{2}\times\frac{1}{2} + \frac{\sqrt{3}}{2}\times\frac{\sqrt{3}}{2} = \frac{1}{4} + \frac{3}{4} = 1$。
2. **拍频是「差」不是「和」**（[50 课](./50-beats.md)）：两列波一快一慢，耳朵数的是它们每秒「错齐」几步——$\lvert 222 - 220 \rvert = 2$ 次呼吸。442 是把两列波的步数加在一起，那是在给新音高报候选，跟拍无关。
3. **八度看「几倍」，不看个数**（[60 课](./60-sound.md)）：高一个八度 = 频率 $\times 2$。440 = 220 × 2 只翻了一倍，所以高 **1** 个八度——"八度"的八指音阶里的第八级，跟乘 8 或者"倍数就是八度数"都没关系。同一个二倍频换个身份叫**二次谐波**（基频的整数倍影子），八度和谐波在这笔账里相遇。

修好后的关键行：

```python
lhs = math.sin(math.radians(deg_a + deg_b))
beat = abs(f2 - f1)
octaves = 1
```

结清账单后的彩蛋：如果另取一根已准的 440 Hz 弦来对照这根 222 Hz 的弦，拍频是 $\lvert 440 - 222\rvert = 218$ Hz，快得耳朵跟不上；而真正调准到同频时拍频为 0。相差整八度的两条谐波链几乎完全重叠（60 课选读），所以 220 Hz 与 440 Hz 听上去像"同一个音的高层"。这正是调音师收工时要分辨的三种状态：拍慢、拍停、八度融合。
</details>
