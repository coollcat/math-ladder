# 反三角函数：arcsin、arccos 与 atan2

## 1. 从一个场景开始

游戏里你点击了屏幕左上方的一棵树，角色要转身面向它——程序手里有的是坐标差：树在角色左边 4 米、前方 3 米。可是**电机需要的是角度**："向逆时针转多少度？"由 dy 与 dx 求出角，就是本课要造的那台机器。

上一课我们已经提前用过它一次：余弦定理拼出一个余弦值后，是 `math.acos` 把角度请回来的（[解三角形](./45-solving-triangles.md) 实验 3）。今天把这一族查询键正式配齐——sin 的倒带机、cos 的倒带机，以及编程界专治四象限迷路的 atan2。

## 2. 直觉解释

单位圆上，$\sin\theta$ 是那个点的纵向影子（[单位圆上的 sin 与 cos](./10-unit-circle.md)）。正向问法你早会了：报角度，答影子。反向就麻烦：

$$\sin\theta = 0.5 \quad \Rightarrow \quad \theta = \text{？}$$

单位圆上影子高度为 0.5 的点有**两个**：$\theta = 30°$ 和 $\theta = 150°$。就像问"时针指着 10 点是几点"——上午 10 点还是晚上 10 点？光靠影子分不清。

办法很朴素：**指定一条"官方街道"**。约定 $\arcsin$ 永远回答"离横轴最近的那位"，也就是落在 $-90°$ 到 $90°$ 之间的主值。至于另一位，可以借助规律自己找回来（选读部分给公式）。三个函数各圈一块地盘，圈完以后反函数才真正合法——这是[复合函数与反函数](../06-functions/40-inverse-composite.md)"先裁剪、再倒带"原则的第二次上演。

## 3. 正式定义

$$\arcsin: [-1, 1] \to \left[-\frac{\pi}{2}, \frac{\pi}{2}\right] \qquad \arccos: [-1, 1] \to [0, \pi] \qquad \operatorname{atan2}(y, x) \to (-\pi, \pi]$$

| 函数 | 回答的问题 | 官方街道（值域） | 小脾气 |
| --- | --- | --- | --- |
| $\arcsin(x)$ | 谁的正弦是 $x$ | $-90°$ 到 $90°$ | 输入必须在 $[-1,1]$，越界即报错 |
| $\arccos(x)$ | 谁的余弦是 $x$ | $0°$ 到 $180°$ | 同样的输入边界 |
| $\arctan(x)$ | 斜率是 $x$ 的直线多陡 | $-90°$ 到 $90°$ | 分不清方向相反的两条射线 |
| $\operatorname{atan2}(y,x)$ | 指向 $(x,y)$ 的方位角 | $-180°$ 到 $180°$ | 吃**两个**参数，认得全部四个象限 |

数学库一律返回**弧度**，打印前要用 `math.degrees` 翻译成度（[弧度制](./20-radian.md)的老合同）。还有一个热身组合拳：对同一个输入恒有 $\arcsin(x) + \arccos(x) = \frac{\pi}{2}$——两条官方街道恰好互补。

## 4. 分步例题

**例**：单位圆上一点 $P$ 位于左上方，$\left(-\dfrac{1}{2}, \dfrac{\sqrt{3}}{2}\right)$。分别用 arcsin、arccos 读出它的身份，并核对谁是真身。

1. **算输入**：该点的横坐标是余弦值、纵坐标是正弦值：$\cos\theta = -0.5$，$\sin\theta = \frac{\sqrt{3}}{2} \approx 0.866$；
2. **查 arccos**：$\arccos(-0.5)$ 官方街道在 $0°$ 到 $180°$，答案 $120°$——它就是真正的 $\theta$；
3. **查 arcsin**：$\arcsin(0.866)$ 官方街道在 $-90°$ 到 $90°$，答案 $60°$——注意！真身明明是 $120°$；
4. **对账**：$60°$ 是 $120°$ 关于竖直轴的双胞胎兄弟（两者的正弦相同），不在 arcsin 的管辖区内；
5. **教训**：反函数只保证返回**官方街道上的住户**。想找回真身，要么换用合适的函数，要么利用对称关系补一步修正。

同样的规矩在第四象限更凶险：指向 $(4, -3)$ 与 $(-4, 3)$ 的两条射线斜率互为相反数都谈不上，`atan` 只吃比值会把它们弄混——这就是下一节 atan2 出场的原因。

## 5. 动手实验

### 实验 1（viz）：盯着影子重演，理解"必须剪一刀"

```viz
{
  "type": "unitcircle",
  "mode": "wave"
}
```

怎么玩：右侧波纹是纵影子随角度摊开的记录。暂停按钮让转动停下，也可以直接抓着紫点拖动。观察：同一高度的水平线在一圈内穿过波形**两次**——这就是"影子反查角度必然撞双胞胎"的画面证据；而 arcsin 只截取最靠近横轴的那半段窗口。看完再想一步：横向影子 cos 要用哪半段当官方街道才不重不漏？

### 实验 2（python）：拖动输入，读两位查询键的答复

```python title="同一个输入，arcsin 与 arccos 各自的主值"
import math                      # 数学库：asin/acos 反查、degrees 换算度数
import matplotlib.pyplot as plt

# sliders: v=0.5 [-1:1:0.05]

deg_asin = math.degrees(math.asin(v))   # asin：正弦的反查键，只答 −90..90 度
deg_acos = math.degrees(math.acos(v))   # acos：余弦的反查键，只答 0..180 度
print(f"asin({v}) ≈ {round(deg_asin, 1)}°")
print(f"acos({v}) ≈ {round(deg_acos, 1)}°")
print(f"两者之和 = {round(deg_asin + deg_acos, 2)}（理论恒为 90）")

xs = []                          # 横轴采样列表
ys = []                          # 正弦值列表
for i in range(400):             # 循环铺满大约 −2π 到 2π 一整张波形
    x = -6.28 + 12.56 * i / 399
    xs.append(x)
    ys.append(math.sin(x))

plt.plot(xs, ys, linestyle="--", color="gray")
plt.axvspan(-1.57, 1.57, color="orange", alpha=0.25)  # axvspan 竖向涂色带；alpha 是透明度
plt.axhline(v, color="red")                            # 当前输入对应的水平线
plt.axhline(0, color="black", linewidth=0.8)
plt.title("灰虚线一圈重演两次，橙区内才是 asin 的官方街道")
plt.grid(True)
```

怎么玩：拖动 v，红线扫过波形，每个位置与虚线交出两个交点，而涂色区里只有一个。两把查询键的对账行始终 90——互补这件事不依赖你的选择。把 v 拖到 −1 或 1 极限端也安全：官方街道特意把两端收编进来了。

### 实验 3（python）：四象限罗盘——atan 与 atan2 的对决

```python title="四个目标方向的完整读数对比"
import math                              # 数学库：atan2 全象限方位、atan 老式反正切

targets = [[-4, 3], [-4, -3], [4, 3], [4, -3]]   # 列表套列表：一次装下四个目标
for dx, dy in targets:                   # 循环解包：每轮取一对横纵坐标
    good = round(math.degrees(math.atan2(dy, dx)))   # atan2 认得四个象限
    naive = round(math.degrees(math.atan(dy / dx)))  # atan 只看比值，象限信息全丢
    print(f"目标 ({dx}, {dy})：atan2 报 {good} 度｜裸 atan 报 {naive} 度")

print("角色在原点面朝正东：负角顺时针转、正角逆时针转")
```

怎么玩：跑一遍就能看到两侧同构的惨案——左侧两个目标（西半边），裸 atan 把西北误报成东南偏北、把西南误报成东北偏南，恰好转错了 180 度；右侧两个目标两种算法一致。**比值丢了符号之外的象限记忆，atan2 用两个参数把地图原样还给你。**

:::warning[常见误区]

**误区一**："你以为 $\sin^{-1}$ 表示 $1/\sin$。" 反三角记号里的 $-1$ 是"倒带"标记（[复合函数与反函数](../06-functions/40-inverse-composite.md)），不是倒数指数：$\arcsin(0.5)=30°$ 而 $1/\sin(0.5)\approx 2.09$——两者毫无关系，连单位都不同。

**误区二**："你以为 asin 直接给出所有可能的角度。" 它只负责官方街道。开口朝钝角的三角形题目里，正弦定理算出的锐角主值往往不是你要的那个，互补钝角才是真身（SSA 双解就是它的后遗症）。

**误区三**："你以为 atan 和 atan2 差不多，顺手就用。" 左半平面的目标会被裸 atan 整体歪 180 度；x 还可能为零直接除零崩机。凡是从坐标差求方位的场景，写 atan2 不用犹豫。

:::

## 6. 练习

**练习 1**：巡逻机器人接到两个目标点的相对偏移：A 在西偏北 $(dx=-4, dy=3)$，B 在西偏南 $(dx=-4, dy=-3)$。机器人当前面朝正东，求两次应转到的方位角（单位度，四舍五入）。下面的代码能跑但结果不对，改到通过：

```exercise
# @title: 练习：别让机器人原地打转
# @check: 143
# @check: -143
# @hint: 目标都在西半边——比值只记得"陡不陡"，不记得"朝哪边"；哪个函数吃了两个参数还记得家在哪个象限？
import math                                   # 数学库：atan2 全象限方位角

angle_a = math.degrees(math.atan(3 / -4))     # ← 目标 A：这台老仪器可靠吗？
print(round(angle_a))

angle_b = math.degrees(math.atan(-3 / -4))    # ← 目标 B：同样的问题再来一次
print(round(angle_b))
```

<details>
<summary>点开查看逐步解答</summary>

1. **诊断病情**：目标 A 与 B 都在西半平面。裸 `atan` 只接收一个比值：$3/(-4)$ 与 $(-3)/(-4)$，它算出的都是"和正东夹角不足 90 度"的锐/钝混淆值——因此输出 ±37，正确的应是 ±143，误差恰好 180 度，即方位整个转反。
2. **对症下药**：`atan2(dy, dx)` 同时拿到两个参数，内部先分辨象限再反查主值：$\operatorname{atan2}(3,-4) = 143°$（东北…准确说是西北方向）、$\operatorname{atan2}(-3,-4) = -143°$（西南偏南，等价于顺时针转 143 度）。
3. **顺带体检**：右半平面时两种算法一致（实验 3 的后半场），所以这类 bug 只在"身后"的目标暴露——测试点没跨过 y 轴，就永远发现不了。

修正后的参考代码：

```python
import math                                   # 数学库：atan2 全象限方位角

angle_a = math.degrees(math.atan2(3, -4))     # 西偏北：第二象限主值
print(round(angle_a))

angle_b = math.degrees(math.atan2(-3, -4))    # 西偏南：第三象限，负角表示顺时针
print(round(angle_b))
```

输出 `143` 与 `-143`，与判题窗逐行一致 ✓。机器人这回直达目的地，不再表演原地 360 度回旋。

</details>

**练习 2**：为什么 arcsin 的官方街道偏偏选在 $-90°$ 到 $90°$，而不是别的 180 度长条？

<details>
<summary>点开查看逐步解答</summary>

街道的唯一硬指标是：任何合法输入都要在里面找到**唯一且能找得到**的答案。正弦在每个恰好 180 度宽的区间上都恰好覆盖 $[-1,1]$ 一次，候选街区理论上不止一条；选 $[-90°, 90°]$ 是因为它的成员"离横轴最近"——夹角小的一支（锐角与其镜像），数值最小、用途最多，工程上绝大多数待解角都落在那里。其他街道自然也能用，只是要额外声明换算规则——数学家的默认地址簿选择了大家最常拨号的那一页。
</details>

## 7. 边界与适用条件

本课的三台查询键都有专属管辖：超出 $[-1,1]$ 的输入立刻抛错（这不是缺陷而是诚实）；复数情形、多值辐角分支切割属于复分析章的语言；$\tan^2$、$\sec$ 这类次生函数的反函数日常几乎用不到，都是通过变形回到三主角。另外，`atan2` 的参数顺序是先 y 后 x——顺序记反是历史悠久的经典事故，判题窗也不会替你兜底。

## 8. 选读：arcsin(x) + arccos(x) 为什么恒等于 π/2

<details>
<summary>选读 · 互余三角形的一句话证明</summary>

任取 $x \in [-1, 1]$。画一个直角三角形：斜边为 1，某直角边长为 $x$。设角 A 对着这条边、角 B 是第三个角，于是

$$\sin A = x \quad\Rightarrow\quad A = \arcsin(x)$$

同一条边换个身份是角 B 的邻边：$\cos B = x$，且 B 落在 $[0°,90°]$ 内——恰好在 arccos 的官方街道上，故 $B = \arccos(x)$。而直角三角形的内角和给出 $A + B = 90° = \frac{\pi}{2}$，代入即证。实验 2 里那行永远不变的 90，就是这个几何事实的数值回声。
</details>
