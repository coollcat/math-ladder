# 波的解剖学：振幅、频率、相位

## 1. 从一个场景开始

调音台上有一排推子：有的管音量大小，有的管音调高低。把一段正弦波交给音响师，他也会问同样三个问题：**这波多高？多密？跟节拍器对齐了吗？**

这三个问题对应公式里的三个字母。[单位圆那一课](./10-unit-circle.md)负责"造出"波浪，这一课给你控制波浪的三个旋钮。

## 2. 直觉解释

把 $y = \sin(x)$ 当成"素颜波"，所有修饰都靠三件事：

- **多高**——整条波上下拉伸：波峰更高、波谷更深，这是**振幅**；
- **多密**——整条波横向压缩或拉开：波挤在一起就是"抖得快"，这是**频率**；
- **错位**——整条波左右平移：本来 0 点起跑，现在提前或延后出发，这是**相位**。

眼熟吗？这正是第 6 章"图像变换三件事"：纵向缩放、横向伸缩、水平平移。当时练的是抛物线，现在原样用在正弦波上——连"左加右减"的老坑都一模一样。

## 3. 正式定义

$$y = A \cdot \sin\big(B(x - \varphi)\big), \qquad \text{周期 } T = \frac{2\pi}{B}$$

| 符号 | 名字 | 作用 | 对应第 6 章变换 |
| --- | --- | --- | --- |
| $A$ | 振幅 | 波峰高度 $\pm A$，纵向拉伸 | 缩放 |
| $B$ | 角频率 | 横向压缩，$B$ 越大波越密；若横轴是时间 $t$，单位是 rad/s | 缩放（横向） |
| $\varphi$ | 相位 | 向右平移 $\varphi$，起跑位置 | 平移 |
| $T$ | 周期 | 波形重复一次所需的横向长度 | 由 $B$ 决定 |

读式子的口诀：**括号外管高低，括号内管横竖**——括号外的 $A$ 拉伸高度，括号内的 $B$ 与 $\varphi$ 分管疏密和左右。

## 4. 分步例题

**例**：不画图，说出 $y = 0.5 \cdot \sin\big(2(x - \frac{\pi}{4})\big)$ 的全部身世。

1. 看振幅：$A = 0.5$，波峰在 $0.5$、波谷在 $-0.5$——比素颜波矮一半；
2. 看频率：$B = 2$，周期 $T = \dfrac{2\pi}{2} = \pi \approx 3.14$——密度翻倍；
3. 看相位：$\varphi = \dfrac{\pi}{4}$，整条波向右挪约 $0.785$——本该在 0 的上升点推迟到了这里；
4. 汇总：一条矮一半、密一倍、右挪四分之一个周期的正弦波。

检查量级：横轴上从 $\frac{\pi}{4}$ 到 $\frac{\pi}{4} + \pi$ 应恰好完成一次全振动，与"密一倍"吻合。

## 5. 动手实验

### 实验 1（viz）：行波的三根推子

```viz
{
  "type": "wave",
  "A": 1,
  "f": 1,
  "phi": 0
}
```

怎么玩：拖动 A——波峰上下长个儿；拖动 f——波长变短、波变密（绿色标尺就是一个波长的距离）；拖动 phi——整条波左右滑移。三个旋钮各管各的，互不打架。这个组件横轴铺的是弧度，所以这里的 `f` 就是公式里的角频率 $B$，不是以赫兹计的每秒次数；换成真实时间后要用 $f_{\text{Hz}} = B/\tau$ 换算。

### 实验 2（viz）：静态坐标里的同一件事

```viz
{
  "type": "plot",
  "title": "y=a·sin(b·x) 与素颜波对照",
  "expr": "a*sin(b*x)",
  "label": "a·sin(b·x)",
  "expr2": "sin(x)",
  "label2": "素颜波 sin(x)",
  "xmin": 0,
  "xmax": 12.56,
  "sliders": [
    { "name": "a", "min": 0.2, "max": 2, "step": 0.1, "value": 1 },
    { "name": "b", "min": 0.25, "max": 4, "step": 0.25, "value": 1 }
  ]
}
```

怎么玩：橙色虚线是永远不动的"素颜波" $\sin(x)$，蓝色实线是化妆后的 $a\cdot\sin(bx)$。把 b 从 1 拉到 2——橙线原地踏步，蓝波的波峰个数却翻了倍：这就是"$B$ 在横轴上做除法"。再把 a 拉小，蓝波整体压矮、波峰始终以自己的振幅为界。两线对照，三个旋钮谁动了、谁没动一目了然；也可与实验 1 的动图互为印证。

### 实验 3（python）：滑杆版三旋钮

```python title="三旋钮一起拧：y = A·sin(B·(x − phi))"
import math                      # 数学工具库：用 pi 和 sin
import matplotlib.pyplot as plt  # 画图库

# sliders: A=1 [0.2:2:0.1], B=1 [1:4:0.25], phi=0 [0:6.28:0.31]

xs = []
ys = []
for i in range(200):             # 循环取 200 个采样点
    x = i * 12.56 / 199          # 横轴铺满 0 到 4π，约两个基准周期
    xs.append(x)
    ys.append(A * math.sin(B * (x - phi)))   # 三旋钮标准波形

T = 2 * math.pi / B              # 周期公式：波形重复一次的横向长度
print(f"A={A}, B={B}, phi={round(phi, 2)}, 周期 T ≈ {round(T, 3)}")

plt.plot(xs, ys)
plt.axhline(0, color="gray", linestyle="--")   # 灰色虚线当中轴
plt.grid(True)
plt.title(f"y = {A}·sin({B}·(x - {round(phi, 2)}))")
```

怎么玩：浮窗里拧动 A、B、phi 三个滑杆，第一行输出实时报告周期。把 B 拧到 2 验证练习 1 的答案；把 phi 拧到 6.28 观察波形几乎转回原地——因为一整圈正好是 τ。

### 快问快答

```quiz
把 y = sin(x) 改成 y = sin(x - 1)，波形会怎样？
- 向左平移 1
- 向右平移 1 [*]
- 整体抬高 1
? 左加右减：x 里减 1 是向右挪 1（第 6 章"延迟上演"）。想整体抬高 1 得写在括号外面。
```

:::warning[常见误区]

**误区一**："你以为 sin(2x) 的周期还是 2π。" 其实是 $\pi$：$B$ 在横轴上做的是**除法**，$T = 2\pi / B$。$B$ 越大波越密、周期越短——方向和直觉相反，与"左加右减"同款陷阱。

**误区二**："你以为振幅越大，波跑得越快。" 其实 $A$ 只管多高，$B$ 才管多密，两个旋钮完全独立。现实中也一样：嗓门大小和音调高低本来就是两码事。

**误区三**："你以为 $\sin(x + \varphi)$ 是右移 $\varphi$。" 其实括号里加是**左移**（延迟上演的反面）。想右移就写 $\sin(x - \varphi)$——所以标准形式里相位前面是个减号。

:::

**练习 2**：完整描述 $y = 3 \cdot \sin\big(2(x - \frac{\pi}{6})\big)$：振幅、周期、相位各是多少？波峰最高到几？

<details>
<summary>点开查看逐步解答</summary>

逐项读取：振幅 $A=3$；周期 $T = \dfrac{2\pi}{2} = \pi$；相位 $\varphi = \dfrac{\pi}{6}$，即向右平移约 $0.52$。波峰最高点为 $+3$，波谷最低点为 $-3$。

验证代码：`print(round(2 * math.pi / 2, 4))` 输出 `3.1416`。
</details>

**练习 3**：如果振幅 $A$ 取负数，比如 $y = -\sin(x)$，得到的波形相当于对 $y = \sin(x)$ 做了什么？

<details>
<summary>点开查看逐步解答</summary>

乘 $-1$ 让每个函数值变号——整条波沿 x 轴**上下翻折**（第 6 章的翻折术）。有趣的是，翻折后的正弦波也可以看成相位挪了半圈的原波：$\sin(x - \pi) = -\sin(x)$。所以"倒放的波"与"错开半圈的波"是同一条曲线的两种说法——下一课的和角公式会把这种换算变成正经工具。
</details>

## 7. 选读：周期公式为什么是 2π/B

<details>
<summary>选读 · 从"重复条件"推出 T = 2π/B</summary>

正弦的本性是：自变量每增加 $2\pi$，函数值原样重演一遍。要让 $g(x) = \sin(Bx)$ 也重演，需要自变量内部恰好凑出 $2\pi$：

$$g(x + T) = \sin\big(B(x+T)\big) = \sin(Bx + BT)$$

令 $BT = 2\pi$ 即得 $T = \dfrac{2\pi}{B}$。物理学家把这时的 $B$ 叫**角频率** $\omega$（每秒转过的弧度），而普通频率 $f = \omega / \tau$ 是"每秒转几圈"，单位赫兹（Hz）——最后一课聊音高时这对双胞胎还会登场。

</details>
