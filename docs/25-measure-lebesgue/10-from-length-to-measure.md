# 从长度到测度

## 1. 从一个场景开始

一根线段的长度你量了十几年：区间 $[a,b]$ 的长度是 $b-a$。现在换个问法——**一个点**的长度是多少？一万万个点挤在一起呢？$[0,1]$ 里全体有理数摊开来的"总长度"呢？

直觉在这里开始漏气：有理数密密麻麻无处不在，可它们好像又"没占地方"。要回答这类问题，不能靠感觉，得先立规矩：**长度必须满足哪些公理，才能既不矛盾、又能算出所有我们关心的集合？** 这门"长度的法律"就是测度论。

## 2. 直觉解释

先看我们对长度的三条朴素信念：

1. **空无一物就是零**：空集的长度是 0；
2. **不相交就相加**：两段不重叠的线拼在一起，长度等于各自长度之和；
3. **区间量端点**：$[a,b]$ 的长度是 $b-a$。

前两条对**有限个**集合毫无争议。真正的分水岭在第 2 条要不要推广到**无穷多**个集合：

- 可数无穷多个长度为 0 的点，加起来是多少？
- 一列越来越小的区间套住一个点，剩下的长度是多少？

有限相加管不了这些问题。数学家的选择很果断：把"可加"直接升级为**可数可加**——可数多个两两不交的集合，长度可以逐个相加。这一步升级立刻逼出一个惊人的推论：单点长度必须是 0，于是**可数个点的总长度永远是 0**，哪怕它们稠密如有理数。

## 3. 正式定义

**定义（测度的公理）**：设 $\Omega$ 是一个集合，$\mu$ 是给 $\Omega$ 的一部分子集指定非负数值的规则。若它满足：

| 公理 | 内容 | 人话 |
| --- | --- | --- |
| 零空集 | $\mu(\varnothing)=0$ | 空无一物长度为零 |
| 可数可加 | 两两不交的 $A_1,A_2,\dots$ 满足 $\mu\bigl(\bigcup_n A_n\bigr)=\sum_n \mu(A_n)$ | 不相交就逐个加，无穷列也一样 |
| 区间基准 | 在数轴上 $\mu([a,b])=b-a$ | 长度与常识一致 |

满足这些规则的 $\mu$ 叫**测度**；能被 $\mu$ 赋值的集合叫**可测集**（哪一些子集有资格拿到值，下一课细讲）。

两条立刻能推出的结论：

$$\mu(\lbrace x\rbrace)=\lim_{n\to\infty}\Bigl[x-\tfrac{1}{n},\,x+\tfrac{1}{n}\Bigr]\le \lim_{n\to\infty}\frac{2}{n}=0$$

单点测度为 0；再由可数可加性，任何可数集（比如全体有理数）的测度都是 0。"稠密"与"有长度"从此彻底脱钩。

## 4. 分步例题

**例 1**：求重叠区间的并集长度。$A=[0,3]$、$B=[2,5]$。

1. 各自长度：$3$ 与 $3$；
2. 直接相加得 6——但重叠段 $[2,3]$ 被数了两次；
3. 重叠段长度为 1，扣掉一次：$6-1=5$；
4. 验证：$A\cup B=[0,5]$，长度恰为 5 ✓。测度论里这叫容斥：$\mu(A\cup B)\le\mu(A)+\mu(B)$，相等当且仅当几乎不重叠。

**例 2**：点集 $\lbrace1,\tfrac12,\tfrac13,\dots\rbrace$ 加上 0，总长度是多少？

1. 每个点是单点，测度 0；
2. 这是**可数**个点；
3. 由可数可加性：$0+0+0+\cdots=0$；
4. 总长度 0——尽管这些点会无限逼近 0，"占地"仍是零。

### 实验 2：把"长度相加"画出来

```python title="区间拼接：长度守恒的小账本"
import matplotlib.pyplot as plt  # 导入画图库，plt 是约定短名

pieces = [(0, 3), (2, 5), (7, 8)]   # 三段线段，每项是 (起点, 终点)
fig, ax = plt.subplots(figsize=(7, 2))   # 建一块画布，figsize 是宽高（英寸）

for k, piece in enumerate(pieces):       # enumerate：同时拿到序号 k 和元素 piece
    lo = piece[0]                        # piece[0] 是这段的起点
    hi = piece[1]                        # piece[1] 是这段的终点
    ax.barh(k, hi - lo, left=lo, height=0.4)   # barh：画横放的矩形条，left 是左端位置
    ax.text((lo + hi) / 2, k + 0.28, str(hi - lo), ha="center")  # 长度标在条上方

total = 0                                # 累加器：先归零
for lo, hi in pieces:
    total = total + (hi - lo)            # 每段长度逐个累加
print(f"三段长度相加 = {total}")
ax.set_xlim(-0.5, 9)
ax.set_ylim(-0.7, 2.6)
ax.invert_yaxis()                        # invert_yaxis：把纵轴反过来，第 0 行画在最上面
```

三段各自长 $3,3,1$；账本合计 7。把它们首尾焊成一条线再量，还是 7——有限相加的守恒律一眼可见。真正的问题是：这张账本敢不敢记无穷多行？

### 快问快答

```quiz
在满足上述公理的长度体系里，[0,1] 中全体有理数的总长度是多少？
- 和 1 差不多，因为它们处处稠密
- 恰好是 0，因为可数个零测度点相加仍为零 [*]
- 无法计算，公理没有覆盖这种集合
? 有理数集可数，拆成可数个单点后每点测度为 0，可数可加性给出总和 0。
```

:::warning[常见误区]

**误区一**："无穷多个 0 相加不一定等于 0 吧？"
可数多个 0 相加**恰好是 0**——这是公理的直接推论，不是直觉题。真正危险的区域在不可数：不可数个零测集的并可以有大测度（比如区间由不可数个点组成），那里直觉和公理都会沉默。

**误区二**："既然是'长度的法律'，那每个子集都该领到长度。"
这正是下一课要粉碎的幻想：存在无法被任何合理测度赋值的集合。公理化的一部分工作恰恰是**划定哪些集合有资格谈长度**。

**误区三**："测度论只是把黎曼积分换了个说法。"
黎曼积分切的是横轴（30 章 50 课的上下的夹逼），而测度先把"哪些集合有长度"这个地基打牢。地基不同，能处理的函数天差地别——第 40 课你会看到 Dirichlet 函数在新世界里温顺如羔羊。

:::

## 6. 练习

**练习 1**：修好下面这段"重叠记账"。两个区间各长 3，但它们的并集不是 6：

```exercise
# @title: 练习：重叠区间的真实长度
# @check: 6
# @check: 5
# @hint: A=[0,3] 与 B=[2,5] 的重叠部分是 [2,3]，长度为 1；并集恰好是连续区间 [0,5]。
a_lo, a_hi = 0, 3   # 区间 A 的左右端点
b_lo, b_hi = 2, 5   # 区间 B 的左右端点

naive = (a_hi - a_lo) + (b_hi - b_lo)   # 各管各的总长：把重叠数了两遍
overlap = a_hi - b_lo                   # ← 重叠段的长度，想想它等于几
union_len = naive                       # ← 问题在这：并集长度应该扣掉一次重叠
print(naive)
print(union_len)
```

修好后输出 6 和 5。公式版写法是 $\mu(A\cup B)=\mu(A)+\mu(B)-\mu(A\cap B)$——概率论里的加法公式就是它的直系后代。

**练习 2**：用可数可加性解释：为什么"长度为正的点"在一个区间里至多可数多个？

<details>
<summary>点开查看逐步解答</summary>

把区间按长度切片：长度落在 $(\tfrac{1}{k+1},\tfrac{1}{k}]$ 里的点至多 $k$ 个——再多的话总长度就超过区间长了。每个切片里只有**有限**个点，可数个有限片拼起来至多可数。所以"带正长度的点"是稀有动物；区间里绝大多数成员都是零测的单点。这也预告了康托集的怪诞：下一课它一个点都不缺地不可数，却照样零测。
</details>

## 7. 选读：为什么需要"可数"，而不止"有限"

<details>
<summary>选读 · 可数可加性买到了什么</summary>

只要求**有限**可加的长度理论轻松愉快、永不矛盾，但它算不出极限过程的结果：区间套 $\bigl[x-\tfrac1n,x+\tfrac1n\bigr]$ 收缩到一个点，有限可加说不出这点面积去哪了。可数可加性把"取极限"合法化——它是让测度能与微积分对话的最低成本投资。

代价在 1905 年到账：Vitali 构造出 $[0,1]$ 的一个子集，任何把它平移拼回区间的尝试都逼出自相矛盾的长度。结论不是"长度理论错了"，而是**不可能给所有子集同时发长度**。出路有两条：缩小候选集合（Borel 集 / Lebesgue 可测集，下一课），或者放弃平移不变（第 60 课概率视角会再遇到这个抉择）。MIT 6.436J《概率基础》第 2 讲正是用同样的论证引出 sigma 代数的必要性。

</details>
