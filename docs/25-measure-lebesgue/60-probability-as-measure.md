# 概率论的测度论视角

## 1. 从一个场景开始

掷一次硬币，正面概率 $\tfrac12$——小学就会。可现在把实验改成**无限次**掷硬币。样本空间里每个结果是一条无限长的正反序列，比如"反正反正反……"。问：

- 某一条**特定**无限序列出现的概率是多少？
- "第 $k$ 次才第一次掷出正面"的概率是多少？
- "**迟早**会掷出正面"的概率是多少？

初等概率在这里集体哑火：单条序列说不清，"迟早"这种事件涉及无穷次操作。测度论接管后一切豁然开朗——概率不过是**总质量为 1 的测度**，而我们已经花了整整一章学会怎么称量它。

## 2. 直觉解释

把无限硬币实验翻译成测度论的三件套：

1. **样本空间** $\Omega$：全体无限 01 序列（0 反 1 正）。它是不可数集；
2. **事件**：先只谈"柱集"——规定好前 $n$ 位、后面随便的那些序列集合。例如"前三位是正反正"就是一个柱集；
3. **概率**：前 $n$ 位每有一种定法，就占掉总质量的 $\bigl(\tfrac{1}{2}\bigr)^{n}$——公平硬币的对称性直接给出柱集的测度。

妙处在于这套构造与 $[0,1]$ 的勒贝格测度是**同一件事**：把 01 序列当成二进制小数 $0.\omega_1\omega_2\omega_3\ldots$，"前 $n$ 位定死"恰好对应数轴上长度 $2^{-n}$ 的小区间。无限硬币空间与均匀分布的区间互为化身——概率论从此站在勒贝格的地基上。

小例外也要点名：形如 $0.01111\ldots$ 与 $0.10000\ldots$ 的二进制双写只发生在可数个端点上，其总测度为零，因此不影响上面的概率账。

## 3. 正式定义

**定义（概率空间）**：三元组 $(\Omega,\mathcal{F},P)$，其中 $\mathcal{F}$ 是 $\Omega$ 上的 sigma 代数（事件的合法名单），$P:\mathcal{F}\to[0,1]$ 满足

$$P(\varnothing)=0,\qquad P(\Omega)=1,\qquad P\Bigl(\bigcup_{n}A_n\Bigr)=\sum_{n}P(A_n)\ \text{（两两不交时）}$$

与第 10 课的测度公理逐字对照，只多了总质量为 1 这一条。

**定义（柱集与其概率）**：固定前 $n$ 位为指定图案的事件称为柱集，其概率为

$$P(\text{前 } n \text{ 位恰为给定图案})=2^{-n}$$

**推论（首次正面）**："第 $k$ 次才首次正面"要求前 $k-1$ 次全反面且第 $k$ 次正面，由独立性（柱集相乘）

$$P(\text{首次正面在第 } k \text{ 次})=\Bigl(\frac{1}{2}\Bigr)^{k}$$

这些事件两两不交，且它们的并是"迟早出现正面"。可数可加性给出

$$P(\text{迟早正面})=\sum_{k=1}^{\infty}\Bigl(\frac{1}{2}\Bigr)^{k}=1$$

几何级数收口于 1——**必然事件**。而它的补集"永远全是反面"只剩单独一条序列，概率为 0。

## 4. 分步例题

**例**：算"第 3 次才首次正面"并核对总账。

1. 前 2 次必须全反面：占位概率 $(\tfrac12)^2=\tfrac14$；
2. 第 3 次正面：再乘 $\tfrac12$，得 $\tfrac18$；
3. 通式：$P(k)=2^{-k}$，即 $1, \tfrac12,\tfrac14,\tfrac18,\dots$ 的一半接一半；
4. 总账：$\sum_{k\ge1}2^{-k}=1$（首项 $\tfrac12$、公比 $\tfrac12$ 的几何级数），所有可能性恰好分光全部质量，无遗漏无重复 ✓。

### 实验 2：滑块核算部分和

```python title="迟早正面：几何级数的部分和"
# sliders: K=10 [1:20:1]
total = 0.0                  # 部分和累加器
records = []                 # 记录每一步的部分和
for k in range(1, K + 1):
    total = total + (1 / 2) ** k   # (1/2)**k：Python 里幂用两个星号
    records.append(round(total, 4))

print(f"k=1 时部分和: {records[0]}")
print(f"K={K} 时部分和: {total}")
```

输出显示部分和从 0.5 起步，十步之内爬到 0.9990…。质量一格格归位，永远差一点点又永远在逼近——这就是可数可加性的数值面孔。

### 快问快答

```quiz
在无限掷硬币模型里，某一条特定的无限序列（比如永远正面）的概率是多少？
- 二分之一，因为每次都是公平硬币
- 无穷小但不是零，毕竟它也是一种结果
- 恰好为零，但它并非不可能发生 [*]
? 单序列对应二进制展开里的一个点，是零测集；概率为零描述的是测度，不是逻辑上的不可能。
```

:::warning[常见误区]

**误区一**："概率为零就是不可能发生。"
零测与空集是两码事。"永远反面"概率为 0，却明明白白躺在样本空间里；反过来"掷出正面"概率 1，也不排除出现反面的世界线。测度语言里 0 和 1 只管"几乎"。

**误区二**："每个样本点都该分到一份正概率。"
不可数样本空间做不到：若每个点的概率都是正数，可数个点加起来早就爆表。正确做法是把质量分配给柱集这类"块状事件"，单点只配零测。

**误区三**："无限次实验嘛，概率就是有限情形取个极限，不用新数学。"
恰恰相反：给全体子集分配满足直觉的概率已被证明不可能（MIT 6.436J《概率基础》第 2 讲的标准反例）。sigma 代数不是学究气，而是让"无限次掷硬币"这件事本身变得合法的唯一出路。

:::

## 6. 练习

**练习 1**：下面的程序想算"迟早正面"的部分和，但起点站错了台：

```exercise
# @title: 练习：首次正面的概率总账
# @check: 0.5
# @check: 0.999
# @hint: "第 k 次才首次正面"的概率是 (1/2)**k，k 从 1 开始数；从 k=0 起算会把"还没掷就正面"也记一笔。
K = 10                          # 累加前 K 种情况
first_term = (1 / 2) ** 0       # ← 问题在这：k 应该从几开始？
print(first_term)

total = 0.0                      # 部分和
for k in range(K):               # ← 这里 k 的取值范围对吗？
    total = total + (1 / 2) ** k
print(round(total, 4))           # round(x, 4)：四舍五入到 4 位小数
```

修好后输出 0.5 与 0.999：首项是"第一次就正面"的 $\tfrac12$；前十项合计 $1-2^{-10}$，离必然一步之遥。

**练习 2**：算"前 $n$ 次全是反面"这个柱集的概率（取 $n=10$），再解释：为什么"永远全是反面"那一条单独的序列概率为 0，却同时住在每一个这样的柱集里？

<details>
<summary>点开查看逐步解答</summary>

柱集"前 $n$ 位定死为全 0"的概率是 $2^{-n}$：$n=10$ 时即 $\tfrac{1}{1024}\approx 0.000977$。$n$ 每加 1，柱子细一半；这些柱集一层套一层，交出"永远全反面"的单点集。由可数可加性推出的测度连续性，单点概率不超过任意 $2^{-n}$，只能是 0。于是：这条序列真实存在于样本空间（不是不可能），却分不到任何质量（零测）——"概率为零"与"不会发生"从此划清界限。
</details>

## 7. 选读：为什么不能给所有子集发概率

<details>
<summary>选读 · sigma 代数的必要性</summary>

设想我们贪心一点，想让"均匀"对所有子集生效：任何集合 $A$ 与它整体翻转 01（XOR 一个固定串）之后的像 $A\oplus b$ 应该等概率——这是硬币公平性的极限形态。MIT 6.436J 第 2 讲证明：把序列按"只差有限位"分团、再用选择公理每团挑一名代表组成集合 $A$，则 $A$ 与它的可数多个平移像拼起来既不多不少地覆盖全空间，又被要求每份概率相等——设这个概率为 $p$，可数可加性给出 $1=0$ 或 $1=\infty$，两头堵死。结论：**不存在**定义在全体子集上、同时满足平移不变与可数可加的均匀概率。唯一的出路是收缩事件名单到 sigma 代数——柯尔莫哥洛夫 1933 年的公理化因此成为现代概率的开山之作。

</details>
