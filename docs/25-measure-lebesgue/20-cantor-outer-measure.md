# 康托集与外测度

## 1. 从一个场景开始

拿一根 $[0,1]$ 长的铁丝，从正中间剪掉开区间 $(\tfrac13,\tfrac23)$，剩下两段；再把每段的中三分之一剪掉，如此无穷无尽。问：**最后剩下的铁丝有多长？**

把每一步剩下的长度加一加：$\tfrac23$、$\tfrac49$、$\tfrac{8}{27}$……一路奔向 0。直觉说："剪了可数多次，什么都没剩。"可是仔细看看那些剩下的点——它们不但没消失，还**多到数不过来**。长度归零与点的无穷多，居然能同时成立。

## 2. 直觉解释

这个幸存者集合叫**康托集** $C$。它有两个互相打脸的属性：

- **长度是 0**：每轮剪掉的部分加起来恰好补回整根铁丝；
- **点不可数**：每个幸存点都能用一个三进制小数刻画（只含数字 0 和 2），而第 27 章的对角线论证告诉我们这种点比有理数还多。

怎么给"任意集合的长度"一个不依赖运气的工作定义？康托尔和勒贝格的思路是**从外面盖**：想量一个集合，就用一列开区间把它整个罩住，记下区间的总长；罩法千千万，取最省的那种——总长的下确界就是它的**外测度**。

- 单个点：罩进长 $\varepsilon$ 的小区间里，$\varepsilon$ 想多小有多小 → 外测度 0；
- 有理数集：逐个罩进小气泡，总长照样可以压到任意小 → 外测度 0；
- 区间 $[a,b]$：谁也骗不了，罩布总长至少 $b-a$ → 外测度 $b-a$。

外测度对**一切**子集都有定义——代价是它在部分集合上不满足可加性。哪些集合"行为良好"？下一课的可测性条件会给出甄别标准；本课先专心玩转零测集。

## 3. 正式定义

**定义（Lebesgue 外测度）**：对数轴的任一子集 $A$，

$$m^*(A)=\inf\Bigl\lbrace\sum_{k=1}^{\infty}(b_k-a_k)\;:\;A\subseteq\bigcup_{k=1}^{\infty}(a_k,b_k)\Bigr\rbrace$$

即：用**可数多个开区间**覆盖 $A$，各区间长度求和，取所有覆盖方案的下确界。这里的 $\inf$ 表示“最大下界”：它压住每一个覆盖总长，而任何更小的数都会被某个覆盖方案穿过。本课先把这个精确记号当作实数完备性送给我们的工具；严格证明在第 19 章展开。符号逐一说明：

| 记号 | 含义 |
| --- | --- |
| $m^*(A)$ | 集合 $A$ 的外测度 |
| $(a_k,b_k)$ | 第 $k$ 块开区间"罩布"，长度 $b_k-a_k$ |
| $\inf$ | 所有覆盖总长的最大下界：再省也省不过它 |

**定义（零测集）**：若 $m^*(A)=0$，称 $A$ 为零测集。零测集的任何子集自动零测，可数个零测集之并仍零测。

**康托集的构造**：$C_0=[0,1]$；$C_{n+1}$ 是从 $C_n$ 的每一段挖去中间三分之一后剩下的并集。康托集为 $C=\bigcap_n C_n$，其第 $n$ 步剩余总长为

$$\text{len}(C_n)=\Bigl(\frac{2}{3}\Bigr)^{n}\;\longrightarrow\;0$$

于是 $m^*(C)=0$：康托集是零测却不可数的怪物。

## 4. 分步例题

**例**：算前四步的剩余长度，并核对挖掉的总长。

1. 第 0 步：$C_0=[0,1]$，总长 1；
2. 第 1 步：挖掉 1 段长 $\tfrac13$，剩 $2\times\tfrac13=\tfrac23$；
3. 第 2 步：挖掉 2 段各长 $\tfrac19$，共 $\tfrac29$，剩 $\tfrac23-\tfrac29=\tfrac49$；
4. 第 3 步：挖掉 4 段各长 $\tfrac1{27}$，剩 $\tfrac8{27}$；规律：第 $n$ 步剩 $(\tfrac23)^n$；
5. 挖掉的总长 $=1-\lim_n(\tfrac23)^n=1$：剪掉的碎片恰好拼回整根铁丝，一点没浪费。

### 实验 1：保留比例怎样决定长度崩塌


把保留比例 `r` 拉低，曲线更快贴到零；康托集每代取 $r=\tfrac23$，所以剩余长度按 $(\tfrac23)^n$ 崩塌。

### 实验 2：亲手挖出康托集的前六代

```python title="康托集前六代的遗迹图"
import matplotlib.pyplot as plt  # 导入画图库

segments = [(0.0, 1.0)]              # 当前一代还活着的线段，初始只有 [0,1]
fig, ax = plt.subplots(figsize=(7, 4))

for gen in range(6):                 # 一共画 6 代
    y = -gen                         # 第几代就画在第几行（往下生长）
    for lo, hi in segments:
        ax.hlines(y, lo, hi, linewidth=3)   # hlines：在高度 y 处画横线段
    survivors = []                   # 准备下一代的名册
    for lo, hi in segments:
        third = (hi - lo) / 3        # 三等分这一段
        survivors.append((lo, lo + third))            # 左侧幸存段
        survivors.append((hi - third, hi))            # 右侧幸存段
    segments = survivors             # 名册换代

ax.set_ylim(-5.5, 0.5)
ax.set_yticks([])
ax.set_title("Cantor set: each generation keeps the two side thirds")
```

每一行都比上一行细碎，但永远没有"最后一根"。盯住位置 $\tfrac12$：它在第一代就被挖走了；而位置 $\tfrac14=(0.020202\ldots)_3$ 用纯 0 和 2 写成三进制，永远幸存。

### 快问快答

```quiz
康托集的长度为 0，那么它里面大约有多少个点？
- 只剩端点那可数多个
- 空空如也，什么都剩不下
- 不可数多个，和整个实数区间一样多 [*]
? 每个幸存点对应一串由 0 和 2 组成的三进制小数，这种串与二进制小数一一对应，构成不可数集。
```

:::warning[常见误区]

**误区一**："长度为 0 的集合顶多可数几个点。"
康托集当场反驳：零测与不可数互不冲突。零测只管"占地"，不管"人数"。第 27 章的可数性工具正是分辨这两件事的显微镜。

**误区二**："外测度就是测度，随便哪个集合都能量。"
外测度对一切子集有定义，但它在某些集合上**不可加**——两个不相交的集合，外测度之和可能超过并的外测度。真正满足公理的"测度"只在可测集上营业。

**误区三**："挖掉的是开区间，端点留下了，所以剩下的主要是端点。"
端点只是幸存者里的名门望族（可数），大量幸存点的三进制展开既不以 0 结尾也不以 2 结尾——比如 $\tfrac14$。别用有限经验猜无穷结构。

:::

## 6. 练习

**练习 1**：下面程序想算第 n 代康托集的剩余总长，但比例设错了——把"每段保留的比例"找出来：

```exercise
# @title: 练习：康托集的剩余长度
# @check: 0.6667
# @check: 0.1317
# @hint: 每次挖掉中三分之一，一段变成两段各占原长的 1/3——所以整体保留的是 2/3，不是 1/3。
stages = [1, 5]          # 想算第 1 步和第 5 步的剩余长度
keep = 1 / 3             # ← 问题在这：每挖一次，总长乘上的比例是多少？
for n in stages:
    print(round(keep ** n, 4))   # round(x, 4)：把 x 四舍五入到小数点后 4 位
```

修好后输出 0.6667 与 0.1317——第 5 代只剩原长的约 13%，且随代数指数衰减到 0。

**练习 2**：证明"可数个零测集之并仍零测"（提示：给第 k 个集合配一块总长不超过 $\tfrac{\varepsilon}{2^k}$ 的罩布）。

<details>
<summary>点开查看逐步解答</summary>

设 $A_1,A_2,\dots$ 都零测，要罩住并集 $A$。给 $A_k$ 选一列开区间罩布使总长小于 $\tfrac{\varepsilon}{2^k}$（零测保证做得到）。把所有罩布摞在一起仍是**可数多块**开区间，总长不超过 $\sum_k \tfrac{\varepsilon}{2^k}=\varepsilon$。于是 $m^*(A)\le\varepsilon$；$\varepsilon$ 任取正数，故 $m^*(A)=0$。几何级数第一次在测度论当苦力，以后它会常来。
</details>

## 7. 选读：什么样的集合才配叫"可测"

<details>
<summary>选读 · Carathéodory 判别法一览</summary>

外测度人人可量，但它只在"好集合"上可加。Carathéodory 1918 年给出甄别条件：集合 $E$ 称为可测，若对**任何**试验集 $T$ 都有

$$m^*(T)=m^*(T\cap E)+m^*(T\setminus E)$$

人话：拿 $E$ 当刀，切任何集合 $T$ 都能切成两块且长度无损耗——这把刀才算干净。全体可测集组成 sigma 代数（对可数并与补封闭），外测度限制在其上恰好满足上一课的全部公理。区间、开集、闭集全部通过检验；康托集作为闭集也可测，测度即其外测度 0。至于通不过检验的"坏集合"（Vitali 型），它们的构造需要选择公理，本站按下不表。

</details>
