# 混合策略：把"随机"当成一种策略

## 1. 从一个场景开始

税务机关不可能查遍每一份申报——查账要人手、要时间；纳税人也不会一直老实——但也不敢一直逃税，因为补税加罚款比老老实实交税贵得多。

于是双方都在猜：税务局猜"哪一批人最可能作假"，纳税人猜"这个季度查得严不严"。**任何一方把做法固定下来，就会被对方吃透**：申报永远规范，税务局就不查你；稽查永远盯着同一类人，其他人就放心作假。这一课的答案是——**双方最后都会"掷骰子"，而且骰子的配重是可以精确算出来的**。

## 2. 直觉解释

**第一层：随机化不是偷懒，是武器。** [纳什均衡](./20-nash-equilibrium.md) 已经亮出了这张牌：纯策略能被看穿，随机化让对手的"针对"失效。这里要把"随机"从一个模糊的直觉，变成一个**可以解出来的数**。

**第二层：配重由什么决定？——由对方的收益决定。** 这是全课最反直觉的一点。我混多少（比如"几分之几的时间选上行"），**不是**为了让我的收益最大，而是为了让对手"无论选哪一列都一样赚"——也就是让对手对你的几个纯策略**无差异**。对手一旦有所偏爱，他就会把概率全押到更赚的那一边，你的随机就白设了。所以：

$$p^\ast \text{ 由对手的收益矩阵决定},\qquad q^\ast \text{ 由我的收益矩阵决定}.$$

**第三层：几何图像。** 横轴是我混的概率，纵轴是对方选不同纯策略的期望收益；**交点就是均衡**（第 20 课已经用过这张图）。这一课把这张图翻译成闭式公式，并处理一个 20 课没展开的问题：**双方都在混**时该怎么联立。

**第四层：随机化到底有多"稳"？** 均衡点像一个天平上的平衡位置：一旦偏离，对手就会用**纯策略**惩罚你——所以混合均衡是一个"只有精确配重才成立"的严格等式。这份脆弱在现实中随处可见：职业球员刻意用赛前定好的随机序列，就是为了避免下意识形成规律。

## 3. 正式定义

**混合策略**：给每个纯策略分配一个概率。第 $i$ 个玩家的纯策略集是 $A_i$，混合策略 $\sigma_i$ 是概率单纯形上的一个点：

$$\Delta(A_i)=\Big\lbrace p:A_i\to[0,1]\ \Big|\ \sum_{a\in A_i}p(a)=1\Big\rbrace.$$

**期望收益**（按第 36 章期望的定义加权）：

$$u_i(\sigma_i,\sigma_{-i})=\sum_{a_i\in A_i}\sum_{a_{-i}\in A_{-i}}\sigma_i(a_i)\,\sigma_{-i}(a_{-i})\,u_i(a_i,a_{-i}).$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\sigma_i$ | 混合策略 | 我的一整套概率配重，纯策略是它的特例（某个概率为 1） |
| $\sigma_{-i}$ | 对手们的策略组合 | 除我之外所有人的选择 |
| $u_i(\cdot)$ | 期望收益 | 所有组合按双方概率加权的结果 |
| $\mathrm{BR}_i(\sigma_{-i})$ | 最佳回应**对应** | $\arg\max_{\sigma_i}u_i(\sigma_i,\sigma_{-i})$——是一个**集合**，可能包含多个策略 |
| $\mathrm{supp}(\sigma_i)$ | 支撑集 | 概率严格大于 0 的那些纯策略 |
| $(\sigma_1^\ast,\dots,\sigma_n^\ast)$ | 混合纳什均衡 | 每人的策略都是对他人策略的最佳回应 |

**无差异原理**（求解一切混合均衡的总钥匙）：在均衡里，

- **支撑集内**的每个纯策略，收益必须**彼此相等**，且等于该玩家的均衡期望收益；
- **支撑集外**的纯策略，收益**不高于**它。

为什么？若支撑集里两个策略收益不等，玩家就会把概率从差的那个挪到好的那个，均衡被破坏。反之，只要对方"怎么选都一样"，我混不混都无所谓——这正是对方无法针对我的原因。

**2×2 的闭式解**：行玩家收益矩阵 $A=\begin{bmatrix}a&b\\c&d\end{bmatrix}$（行=上行/下行，列=左列/右列），列玩家收益矩阵 $B=\begin{bmatrix}e&f\\g&h\end{bmatrix}$（同样的行列约定）。设行玩家混上行的概率为 $p$、列玩家混左列的概率为 $q$，则

$$q^\ast=\frac{d-b}{(a-b)+(d-c)}\quad(\text{让行玩家两行无差异}),\qquad p^\ast=\frac{h-g}{(e-f)+(h-g)}\quad(\text{让列玩家两列无差异}).$$

分母是"两步的收益差之和"，只要它不为 0，$2\times2$ 博弈总有唯一的全混均衡（与纯均衡可能并存）。

**存在性**（Nash, 1950）：每个**有限**博弈都至少有一个混合策略纳什均衡。求解不总是容易（大博弈里属于 PPAD 类难题），但"不会空手而归"这一点有定理担保。

## 4. 分步例题

**例一：猜拳为什么必须各出三分之一。**

$3\times3$ 的收益矩阵（行=我，列=对手，赢 $+1$、输 $-1$、平 $0$）：

$$M=\begin{bmatrix}0&-1&1\\1&0&-1\\-1&1&0\end{bmatrix}.$$

1. 设我以 $\tfrac13$ 均匀出拳。任取对手一个纯策略，例如对手永远出石头：我的期望 $=\tfrac13(0)+\tfrac13(1)+\tfrac13(-1)=0$；
2. 对手出布、出剪刀同样算得 $0$——**对手三个纯策略收益全相等**，按无差异原理，他混不混都一样（都被压到 0）；
3. 反向同理：对手均匀出拳时，我的三个纯策略收益也都是 $0$；
4. 于是 $(\tfrac13,\tfrac13,\tfrac13)$ 与 $(\tfrac13,\tfrac13,\tfrac13)$ 互为最佳回应，是混合均衡，均衡值 $0$；
5. 对照：把 $\tfrac13$ 换成任何别的配重（比如 $0.5/0.3/0.2$），对手立刻改出你最疏于防守的那一种，你的期望就掉到负数——**这一个配重就是平衡点本身**。

**例二：税务稽查的配重（带数字的完整算例）。**

纳税人（行）可选择诚实或逃税；税务局（列）可选择稽查或不查。设应纳税款 $T=30$、罚款 $F=60$、一次稽查的成本 $c=10$（数字为教学简化）。四格的收益（先写纳税人，再写税务局）：

| | 稽查 | 不查 |
| --- | --- | --- |
| **诚实** | 纳税人 $-30$；税务局 $30-10=20$ | 纳税人 $-30$；税务局 $30$ |
| **逃税** | 纳税人 $-30-60=-90$；税务局 $30+60-10=80$ | 纳税人 $0$；税务局 $0$ |

于是 $A=\begin{bmatrix}-30&-30\\-90&0\end{bmatrix}$（纳税人），$B=\begin{bmatrix}20&30\\80&0\end{bmatrix}$（税务局）。

1. 求纳税人的诚实概率 $p^\ast$（使税务局两列无差异）：
$$p^\ast=\frac{h-g}{(e-f)+(h-g)}=\frac{0-80}{(20-30)+(0-80)}=\frac{-80}{-90}=\frac{8}{9}\approx 0.889.$$
   直觉：诚实概率高到让税务局"查与不查差不多"，税务局才懒得把精力全压上来。
2. 求税务局的稽查概率 $q^\ast$（使纳税人两行无差异）：
$$q^\ast=\frac{d-b}{(a-b)+(d-c)}=\frac{0-(-30)}{\big(-30-(-30)\big)+\big(0-(-90)\big)}=\frac{30}{90}=\frac13.$$
3. 回代验证无差异：纳税人诚实 $=-30$；逃税 $=\tfrac13(-90)+\tfrac23(0)=-30$ ✔。税务局稽查 $=\tfrac89(20)+\tfrac19(80)=\tfrac{160+80}{9}=\tfrac{80}{3}\approx26.67$；不查 $=\tfrac89(30)=26.67$ ✔。
4. 读结论：**逃税概率 $=1-p^\ast=\dfrac{c}{T+F}=\dfrac{10}{90}=\dfrac19$**，**稽查概率 $=q^\ast=\dfrac{T}{T+F}=\dfrac{30}{90}=\dfrac13$**。两张公式一句话：罚款越重、稽查成本越低，均衡里的逃税就越少、稽查也越少。均衡值 $\tfrac{80}{3}\approx 26.67$ 是税务局能拿到的最好保底（因为纳税人已经混到让他无计可施）。

第 4 条是本课最实用的收获：**规则一改（加大罚款、降低稽查成本），均衡概率立刻跟着动**——这正是机制设计关心的杠杆。

### 实验 3（python）：2×2 公式 + 无差异回代

```python
def equilibrium_2x2(A, B):         # A 行玩家收益，B 列玩家收益，都按 [[左上,右上],[左下,右下]] 排
    a, b = A[0][0], A[0][1]
    c, d = A[1][0], A[1][1]
    e, f = B[0][0], B[0][1]
    g, h = B[1][0], B[1][1]
    q = (d - b) / ((a - b) + (d - c))    # 列玩家混"左"的概率：让行玩家两行收益打平
    p = (h - g) / ((e - f) + (h - g))    # 行玩家混"上"的概率：让列玩家两列收益打平
    return p, q

A = [[-30, -30], [-90, 0]]         # 纳税人：行=诚实/逃税，列=稽查/不查
B = [[20, 30], [80, 0]]            # 税务局

p, q = equilibrium_2x2(A, B)
print("纳税人诚实概率 p* =", round(p, 4))                  # 期望 8/9
print("税务局稽查概率 q* =", round(q, 4))                  # 期望 1/3

row_up = q * A[0][0] + (1 - q) * A[0][1]     # 纳税人"诚实"的期望
row_down = q * A[1][0] + (1 - q) * A[1][1]   # 纳税人"逃税"的期望
print("纳税人两侧期望 =", round(row_up, 4), round(row_down, 4))   # 应当相等

col_l = p * B[0][0] + (1 - p) * B[1][0]      # 税务局"稽查"的期望
col_r = p * B[0][1] + (1 - p) * B[1][1]      # 税务局"不查"的期望
print("税务局两侧期望 =", round(col_l, 4), round(col_r, 4))       # 应当相等
```

四行输出正好是无差异原理的两条等式在数字上成立：**两侧打平 ⇒ 谁都不想改 ⇒ 均衡**。

### 实验 4（python）：随机化把"保底"抬高了多少

```python
RPS = [[0, -1, 1], [1, 0, -1], [-1, 1, 0]]    # 行玩家收益矩阵
MIX = [1 / 3, 1 / 3, 1 / 3]                   # 均匀混合

def expected(mine, theirs):                   # 期望收益：所有组合按双方概率加权求和
    total = 0.0
    for i in range(3):
        for j in range(3):
            total += mine[i] * theirs[j] * RPS[i][j]
    return total

worst_pure = max(min(row) for row in RPS)     # 保底（maximin）：每行取最小，再在行里取最大
print("纯策略的保底 =", worst_pure)                              # -1
print("均匀混合 vs 均匀对手 =", round(expected(MIX, MIX), 4))    # 0
print("均匀混合 vs 偏重布的对手 =", round(expected(MIX, [0.2, 0.6, 0.2]), 4))   # 仍是 0
print("纯出石头 vs 偏重布的对手 =", round(expected([1, 0, 0], [0.2, 0.6, 0.2]), 4))  # -0.4
```

最后两行是随机化的全部价值所在：**均匀混合把结果稳稳锁在 $0$（对手怎么调都一样），而任何一个纯策略都会被针对到亏钱**。保底从 $-1$ 抬到 $0$，抬起来的这一段，就是"随机"这个策略的报价。

```quiz
在 2×2 博弈里，行玩家混合策略的配重 p* 是由什么决定的？
- 由行玩家自己的收益矩阵决定：让行玩家自己赚得最多
- 由列玩家的收益矩阵决定：让列玩家的两个纯策略收益相等 [*]
- 由双方收益矩阵的平均值决定
? 无差异原理：我要混，必须让对手"怎么应对都一样赚"，否则他会全押更赚的那一边，我的随机立刻失效。所以我的配重由对手的收益矩阵决定，而对手的配重由我的收益矩阵决定——这是混合均衡里最容易记反的一条。
```

:::warning[常见误区]

**误区一**："你以为混合策略是'没想好就随便选'。" 上面那个 $\tfrac89$ 是唯一的平衡点：低一点税务局该多查、高一点税务局该少查，只有这一个配重能让对方无从下手。而且必须**真随机**——职业球员用赛前写好的随机序列，就是在防止下意识暴露规律。

**误区二**："你以为混得越多、自己的收益就越高。" 均衡里的混合**不提高**你的期望收益，它提高的是**保底**（worst case）。猜拳均匀混合的期望永远是 0，一分不多；它换来的是"对方再怎么研究你也打不穿"。混合是把下限抬到上限，不是把上限抬高。

**误区三**："你以为我的混合比例应该多分给'我更擅长'的那一手。" 比例是由**对方**的收益算出来的，与你自己的强弱无关。点球例子里射手混多少由门将的收益决定；税务例子里纳税人诚实的概率由税务局的收益（稽查成本、罚款）决定——**你能拿多少取决于对手的账本**，这是博弈论最反直觉也最重要的一课。

**误区四**："你以为混合均衡和纯均衡一样稳。" 纯均衡只要"不偏离"，混合均衡还要"精确到小数点"。现实中学习、情绪、疲惫都会造成偏差，于是最优回应互相追逐——这正是 [多智能体强化学习](../50-reinforcement-learning/240-marl.md) 里非平稳性的来源。

:::

## 6. 练习

**练习 1**（判题）：下面的公式能跑，但把分子写反了，算出来的"概率"是负数——修到通过：

```exercise
# @title: 练习：用无差异条件求列玩家的混合比例
# @check: 0.67
# @check: 6.0
# @hint: 让行玩家两行打平：q*a + (1-q)*b = q*c + (1-q)*d，解得 q = (d - b) / ((a - b) + (d - c))。现在是 (b - d)。
A = [[4, 10], [8, 2]]            # 行玩家收益：行=上/下，列=左/右

def indifference_q(A):           # 返回列玩家混"左"的概率，使行玩家两行无差异
    a, b = A[0][0], A[0][1]
    c, d = A[1][0], A[1][1]
    return (b - d) / ((a - b) + (d - c))     # ← 问题在这：分子写反，结果成了负数

q = indifference_q(A)
print(round(q, 2))
print(round(q * A[0][0] + (1 - q) * A[0][1], 2))    # 均衡时行玩家的期望收益
```

修好后 $q^\ast=\tfrac23\approx0.67$，行玩家的均衡收益 $=\tfrac23\times4+\tfrac13\times10=6$——落在纯策略保底 $\max(\min(4,10),\min(8,2))=2$ 与封顶 $\min(\max(4,8),\max(10,2))=8$ 之间，符合 [minimax 定理](./25-zero-sum-minimax.md) 的预期。

**练习 2**（概念）：为什么说"均衡混合比例由对手的收益决定"？用自己的话解释，并说明如果由自己的收益决定会出什么问题。

<details>
<summary>点开查看逐步解答</summary>

**理由**：混合的目的是让对手**无从针对**。对手能被针对的前提，是他的某个纯策略明显更赚；只要他还能分辨出"该选哪个"，他就会选那个，你的随机配重就失去意义。所以正确的做法是**把对手的所有纯策略收益拉平**——而这需要解的是对手的收益方程，与我的收益无关。

**反过来会出什么问题**：假设我按"自己最赚"来配重，比如把概率全押到我收益最高的那一手。对手看一眼就明白了，直接出针对那一手的动作，我的期望收益掉到最低。**"按自己收益配重"本质上是纯策略思路的延续，它已经被反例（猜拳固定出拳）打死过一次了。**

**一个便于记忆的对照**：我的收益由**对手的混合**决定（对手混得对不对，决定我能拿多少）；我的混合由**对手的收益**决定（我混得对不对，决定对手能不能针对我）。两条线索交叉，才构成双向的"互为最佳回应"。

补充一句工程上的提醒：真实对局里人的随机性并不完美（点球射手的实际分布常偏离理论配重），所以理论还负责给出"偏离的代价有多大"——这个代价在均衡附近是二阶小的，这也是为什么它虽然脆弱，却仍然有用。

</details>

## 7. 选读：存在性、"奇数个均衡"与弱最优回应

<details>
<summary>选读 · 为什么混合均衡一定存在，以及它有多脆弱</summary>

**一、存在性来自不动点。** 把"最佳回应"看成一个**集值映射**：给定对手的混合策略 $\sigma_{-i}$，返回所有能最大化我收益的混合策略的集合。这个映射把凸紧集（概率单纯形）映到自身的凸子集，满足角谷不动点定理的条件，于是必有不动点——不动点就是"每个人都对自己看到的对手做最佳回应"的策略组合。这份论证同时也解释了为什么**有限**是关键词：无限博弈需要额外的紧性与连续性假设。

**二、$2\times2$ 的均衡个数是奇数。** 由无差异原理推下去，$2\times2$ 博弈的均衡必然是：两个纯均衡（可能退化）、或一个纯均衡加一个全混均衡、或只有全混均衡——总数总是奇数（Wilson 奇性定理在更一般情形下推广了这一点）。这给了一个实用的排查法：如果你只找到一个均衡，多半还剩一个没找到。

**三、弱不等式与"没被用到的牌"。** 无差异原理只说支撑集内**取等号**；支撑集外的纯策略只要求**不超过**均衡收益。这条弱不等式很有用：它意味着均衡利用的往往只是策略集的一小部分。求均衡的算法（如 Lemke–Howson）正是在"支撑集"这层组合结构上做文章。

**四、脆弱性与学习动态。** 混合均衡在理论上是一次性、完全理性的解；而在重复互动里，玩家靠学习动态逼近它时，均衡附近会出现**循环与漂移**（猜拳的"最佳回应追逐"就是最简版本）。所以现代文献很少只问"均衡是什么"，还会问"在什么动态下会靠拢、会不会绕圈"——这条线索一直通到多智能体的收敛问题。

</details>
