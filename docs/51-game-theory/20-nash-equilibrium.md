# 纳什均衡

## 1. 从一个场景开始

点球大战。门将扑向哪边，取决于他认为你会往哪射；你射向哪边，又取决于你认为他会扑哪边——**没有一招永远正确**（上一课的占优策略在这里集体失业）。

那什么叫"踢得合理"？1950 年前后，普林斯顿的博士生约翰·纳什给出了一个惊人的答案：合理的结局不是"某一方赢"，而是一个**谁都不想单方面变招的状态**。这个概念后来拿下诺贝尔奖，渗进了经济学、生物学、计算机科学的地基。

## 2. 直觉解释

把均衡想象成一张躺稳的桌子：每人都可以把自己的策略挪一下试试——只要**没有任何人**能通过单独改变选择而多赚，整张桌子就静止了。这就是纳什均衡：**互相都是对方的最优回应**。

两个立刻要纠正的误读：

1. 均衡不等于皆大欢喜。囚徒困境唯一的均衡就是那个双输格——"稳定"与"美好"是两回事；
2. 稳定可以靠**掷骰子**实现。剪刀石头布若固定出拳必被看穿；合理玩法是三分之一概率各出一样——这种带随机性的策略叫**混合策略**，它让对手的任何预判都落空。

混合均衡的求解钥匙只有一句话：**要让对方愿意掷骰子，必须让对方的几种纯策略收益打平**（无差异条件）——否则对方就会把概率全押到更赚的那一边，你的随机就白设了。

## 3. 正式定义

**纯策略纳什均衡**：策略组合 $(i^\ast, j^\ast)$ 是均衡，当且仅当

$$R[i^\ast][j^\ast] \ge R[i][j^\ast] \ \text{对一切 } i, \qquad C[i^\ast][j^\ast] \ge C[i^\ast][j] \ \text{对一切 } j$$

即：给定对方不变，任何人单方面偏离都不增收益。

**混合策略**：给纯策略分配概率（行玩家出 $i$ 的概率 $p$，列玩家出 $j$ 的概率 $q$），收益按第 36 章期望的定义加权平均。混合均衡满足同一句"单方面偏离无利可图"，只是对象换成了概率分布。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $q$ | 对方出"左"的概率 | 行玩家收益公式的自变量 |
| $p$ | 我出"左"的概率 | 由对方的无差异条件解出 |
| 无差异条件 | 求衡器的天平 | 令对方两种纯策略期望收益相等 |

纳什的存在性定理保证：有限博弈必有混合策略均衡——所以这套方法永远不会空手而归。

## 4. 分步例题

点球博弈：射手选射左/射右，门将选扑左/扑右。射手收益矩阵（进球价值）：

| | 扑左 | 扑右 |
| --- | --- | --- |
| **射左** | 2 | 8 |
| **射右** | 6 | 4 |

1. 设门将扑左概率为 $q$。射手"射左"的期望收益：$2q + 8(1-q) = 8 - 6q$；
2. "射右"的期望收益：$6q + 4(1-q) = 4 + 2q$；
3. 无差异条件：$8 - 6q = 4 + 2q$，解得 $q = 0.5$——门将应以对半开的比例扑左右；
4. 对称地，令门将无所谓（他的失球期望打平）：设射手射左概率 $p$，$2p + 6(1-p) = 8p + 4(1-p)$，解得 $p = 0.25$——射手该四分之一射左、四分之三射右（他射右更准，所以多射右边）；
5. 自查：在 $(p, q) = (0.25, 0.5)$ 处双方都懒得偏离 → 混合纳什均衡达成，此时射手期望进球 $8-6\times0.5 = 5$。

## 5. 动手实验

### 实验 1（viz）：两条收益线的交点就是答案

### 实验 2（python）：数值验证交点

```python title="扫描 q，找两条线的最小距离"
best_q = 0
diff_min = 99

for k in range(101):
    q = k / 100                       # 门将扑左的概率从 0 试到 1
    left_gain = 8 - 6 * q             # 射左的期望收益
    right_gain = 4 + 2 * q            # 射右的期望收益
    d = abs(left_gain - right_gain)   # abs：绝对值（第 6 章引入）
    if d < diff_min:
        diff_min = d
        best_q = q

print(f"无差异点 q* = {best_q}")
print(f"此时射手期望收益 = {round(8 - 6 * best_q, 2)}")
```

输出 $q^{\ast} = 0.5$、期望收益 $5$——与手算完全一致。代数、几何、数值三路会师。

### 快问快答

```quiz
求混合均衡时为什么要让对方"两种纯策略收益相等"？
- 这样比赛最公平
- 若不等，对方会把全部概率押到更赚的那边，我的随机分配立刻失效 [*]
- 相等能让总收益最大化
? 你的混合策略只有在对方"怎么应对都一样赚"时才防得住对方。无差异条件正是把"防得住"翻译成方程。
```

:::warning[常见误区]

**误区一**："你以为均衡一定是双赢结局。" 均衡只承诺"稳定"，不承诺"美好"。囚徒困境的坏结局之所以顽固，正因为它也是稳定的。

**误区二**："你以为混合策略等于乱踢。" 点球手的 $0.25/0.75$ 是精心计算的比例，且每一步都要真随机（职业球员刻意用赛前决定的序列避免下意识模式）。"看似随意"底下是精确的概率配平。

**误区三**："你以为多个均衡时理论会告诉你选哪个。" 协调博弈（如两人约在东门还是西门碰头）可以有两个纯均衡加一个混合均衡；哪个会实现，理论保持沉默，现实靠惯例与文化聚点拍板。

:::

## 6. 练习

**练习 1**：换了位射手后收益矩阵变为：射左行 $[6, 10]$、射右行 $[8, 5]$。扫描新的无差异点——代码能跑但两条收益线抄串了行，修到通过：

```exercise
# @title: 练习：新射手的无差异点
# @check: 0.71
# @hint: 射左收益 = 6*q + 10*(1-q)；射右收益 = 8*q + 5*(1-q)。对照矩阵逐项检查系数。
best_q = 0
diff_min = 99

for k in range(1, 100):
    q = k / 100
    left_gain = 6 * q + 10 * (1 - q)
    right_gain = 10 * q + 6 * (1 - q)     # ← 问题在这：系数不是这一行的
    d = abs(left_gain - right_gain)
    if d < diff_min:
        diff_min = d
        best_q = q

print(round(best_q, 2))
```

修好后得到 $q^\ast = 0.71$：这位射手左脚太准，门将被迫七成一的概率扑向左边。

**练习 2**：验证 $(0.25, 0.5)$ 确实是例题博弈的均衡：在该点上分别计算射手改纯射左、纯射右的收益，确认都不超过混合时的 5。

<details>
<summary>点开查看逐步解答</summary>

门将已按 $q=0.5$ 骰子行动时：射手机械射左的期望 $= 2\times0.5+8\times0.5=5$；机械射右 $=6\times0.5+4\times0.5=5$。两者恰好都等于混合策略下的 5——射手确实没有偏离动机。反过来固定 $p=0.25$ 算门将两侧的失球期望同为 5。双向核查通过，这正是"互为最优回应"的含义：

```python
p, q = 0.25, 0.5
shooter_left = 2 * q + 8 * (1 - q)
shooter_right = 6 * q + 4 * (1 - q)
keeper_left_cost = -(2 * p + 6 * (1 - p))    # 用失球负值表示门将收益
keeper_right_cost = -(8 * p + 4 * (1 - p))
print(shooter_left, shooter_right)           # 5.0 5.0 —— 打平，射手不动
print(keeper_left_cost, keeper_right_cost)   # -5.0 -5.0 —— 打平，门将不动
```
</details>

## 7. 选读：为什么存在性值得一个定理

<details>
<summary>选读 · 纳什定理与不动点</summary>

"每个有限博弈都有混合均衡"并不显然：策略空间是连续的概率单纯形，收益又是相互纠缠的多项式，凭什么一定存在互相锁死的不动点？纳什借用了拓扑学的角谷不动点定理：把"最优回应"看成集值映射，均衡就是这个映射的不动点——就像把两张地图叠放，总有一点上下重合。

两点提醒：其一，存在性不谈唯一性也不谈如何找到它（计算均衡在大博弈里是出了名的难题，属于 PPAD 类）；其二，有限博弈之外（如无限重复博弈、连续动作空间）需要额外条件。对学习者而言，记住那句操作口诀就够用大半场：**写收益线、令其相等、解出概率、回代验证**。

</details>
