# 收益矩阵与占优策略

## 1. 从一个场景开始

学校门口两家奶茶店同日开业。甲店老板夜里盘算："明天降价促销吗？"——可这个问题的答案取决于乙店明天降不降。你降他不降，你独占客流；他也降，两家一起利润腰斩；你不降他降，客人跑光……

普通优化题里，目标函数安安静静等你来最大化。而这里，**你的最优选择取决于别人的选择，别人的最优又取决于你**——函数自己会动。博弈论就是研究这种"会动的优化"的数学。20 世纪 50 年代，兰德公司的研究者设计了一个后来由塔克以"囚徒困境"之名讲遍世界的经典场景，把这种困境浓缩进了四格小表。

## 2. 直觉解释

把所有可能性装进一张二维表格：行是你能出的招，列是对方能出的招，每个格子写上双方的得失。这张表叫**收益矩阵**——它就是这场对局的完整规则书。

读表的口诀是"**钉死对方，比较自己**"：假设对方出某招不变，逐个试自己的招，看哪个收益高。如果在每一种"对方怎么出"的情形下，你的某一招都稳赢另一招，那它就是你的**占优策略**——无论世界怎么变，它都不吃亏。

囚徒困境之所以著名，是因为它的矩阵里藏着一个惊人的组合：双方都有干净的占优策略，各自执行后却落进一个"明明有更好结局却到不了"的格子。个人理性与集体理性第一次正式闹掰。

## 3. 正式定义

一个双人博弈由三件套 $(N, S, u)$ 描述：

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $N = \lbrace 1, 2 \rbrace$ | 参与者 | 谁在玩 |
| $S_1, S_2$ | 策略集 | 各自可选的行动清单 |
| $u_1, u_2$ | 收益函数 | 每种策略组合下各自的得失 |

以 $2 \times 2$ 博弈为例，行玩家收益记作 $R[i][j]$（第 11 章矩阵的老朋友）：行选 $i$、列选 $j$ 时行玩家的所得；列玩家同理用 $C[i][j]$。

**占优策略**（严格版）：行玩家策略 $i^\ast$ 占优，当且仅当对列玩家的**每一个**策略 $j$ 都有

$$R[i^\ast][j] > R[i][j] \quad \text{对所有 } i \neq i^\ast$$

翻译：不管对方怎么出，$i^\ast$ 都严格更赚。"每一个"三个字是灵魂——只赢一种情形不算占优。

## 4. 分步例题

审讯室版本的经典矩阵（数字为收益，越大越好）：

| | 乙：抵赖 | 乙：坦白 |
| --- | --- | --- |
| **甲：抵赖** | 各得 3 | 甲 0，乙 5 |
| **甲：坦白** | 甲 5，乙 0 | 各得 1 |

1. 钉死乙选"抵赖"：甲抵赖得 3，坦白得 5 → 坦白胜；
2. 钉死乙选"坦白"：甲抵赖得 0，坦白得 1 → 还是坦白胜；
3. 两种情形都赢 → "坦白"是甲的严格占优策略；
4. 表格对称，乙的占优策略同样是"坦白"。双双执行，结局是右下格（1, 1）。

回头看左上格：若两人都咬牙抵赖，各得 3——比 (1, 1) 好得多。可是没有任何机制保证走到那里：单方面偷偷坦白的人会从 3 涨到 5。**这格诱惑就是"困境"二字的来源**：结构逼着理性人走向集体次优。

## 5. 动手实验

### 实验 1（python）：让机器替你读表

```python title="自动检测占优策略"
row_payoff = [[3, 0], [5, 1]]    # 行玩家收益：row_payoff[行][列]
col_payoff = [[3, 5], [0, 1]]    # 列玩家收益（同一局）

names = ["抵赖", "坦白"]

dominant = True                  # 先假设"坦白"(下标1)严格占优，再找反例
for j in [0, 1]:                 # 钉死列玩家的每一种出招
    if row_payoff[1][j] <= row_payoff[0][j]:
        dominant = False         # 只要有一局不严格更赚，就推翻

print(f"行玩家的'坦白'是否严格占优: {dominant}")

for i in [0, 1]:                 # 换列玩家来比一遍
    if col_payoff[i][0] >= col_payoff[i][1]:
        print(f"行选{names[i]}时, 列玩家的占优选择是 抵赖")
    else:
        print(f"行选{names[i]}时, 列玩家的占优选择是 坦白")
```

三行输出把例题的四步推理全部自动化——博弈再大，这套"钉死对方、比较自己"的逻辑照用不误。

### 实验 2（python）：给矩阵画热力图

```python title="收益热力图"
import matplotlib.pyplot as plt

payoff = [[3, 0], [5, 1]]        # 行玩家视角

plt.imshow(payoff, cmap="YlGn")  # imshow：把二维列表画成色块图，数值越高越绿
plt.colorbar(label="row payoff")
plt.xticks([0, 1], ["col: deny", "col: confess"])
plt.yticks([0, 1], ["row: deny", "row: confess"])

for i in range(2):               # 在每格里标数字
    for j in range(2):
        plt.text(j, i, str(payoff[i][j]), ha="center", va="center", fontsize=16)
```

绿色从左下角向右上角漫开：背叛的诱惑与互相背叛的低谷一眼可见。

### 快问快答

```quiz
囚徒困境里两人都选择占优策略后，结局为什么被称为"困境"？
- 因为收益矩阵算错了
- 个人理性的选择叠加成了集体次优：明明存在对双方都更好的格子却停不住 [*]
- 因为警察一定会重审第二次
? 单方面偏离到"合作格"的一方会从 1 涨回 3 的机会被对方利用，所以谁也不敢先动。结构本身锁死了结局。
```

:::warning[常见误区]

**误区一**："你以为占优策略一定带来好结果。" 恰恰相反，囚徒困境里两个占优策略相遇于全场第二差的格子。占优是对个人而言的安全，不是集体的福音。

**误区二**："你以为博弈都是零和——我赢就是你输。" 囚徒困境是典型的非零和：总收益在不同格子里是 6、5、2 不等，存在双赢空间也存在双输空间。商业、生态、外交大多是这类混合动机博弈。

**误区三**："你以为收益必须用钱衡量。" 收益只需满足"序数可比"（能排出偏好顺序）。坐牢年限、声誉损失、良心不安都可以折成收益数字进表——矩阵关心的是偏好的形状，不是计量单位。

:::

## 6. 练习

**练习 1**：价格战矩阵如下——行玩家（甲店）收益 `row_payoff`，列玩家（乙店）收益 `col_payoff`。代码想找出**乙店**在每种情况下的最佳回应，但 else 分支忘了改——修到通过：

```exercise
# @title: 练习：轮到列玩家做选择
# @check: 低
# @check: 低
# @hint: 固定行玩家的出招，比较 col_payoff[i][0] 与 col_payoff[i][1]，谁大选谁。
row_payoff = [[8, 2], [10, 4]]   # 行玩家收益：[甲高价/低价] x [乙高价/低价]
col_payoff = [[8, 10], [2, 4]]   # 列玩家收益：同一个格子里乙的所得

for i in [0, 1]:
    if col_payoff[i][0] > col_payoff[i][1]:
        best = "高"
    else:
        best = "高"              # ← 问题在这：两个分支答案一样了
    print(best)
```

修好后两行都是"低"：降价也是乙店的占优策略——这场价格战和囚徒困境是同一个结构的换装出场。

<summary>点开查看逐步解答</summary>

最后一轮没有未来，就是一次性囚徒困境 → 双双坦白。倒数第二轮：反正下一轮已注定互咬，本轮的合作换不来任何回报 → 又互咬。如此逐轮向前传染，**整个链条 unraveling（拆解）到底**：知道确切结束时间的重复博弈，退化成一连串一次性博弈。这个反直觉结论将在本章第三课被"未知终点"翻案——未来的影子才是合作的氧气。

## 7. 选读：从四格到世界

<details>
<summary>选读 · 结构识别：T、R、P、S 记号</summary>

学界习惯用四个字母给对称博弈的收益排序命名：

- $T$（Temptation）：对方合作我背叛的诱惑收益；
- $R$（Reward）：双方合作的奖励；
- $P$（Punishment）：双方背叛的惩罚；
- $S$（Sucker）：对方背叛我却合作的傻瓜收益。

囚徒困境的定义式只有一行：$T > R > P > S$（本课数字：$5>3>1>0$）。改一两个不等号就换了一个世界：若 $T>R>P>S$ 且再加 $R>\frac{T+S}{2}$，仍是标准囚徒困境；若 $S>P$ 变成"怯懦博弈"（Chicken，斗鸡）；若单方面背叛占不到便宜（$T < P$）而合作回报又最高（$R$ 最大），则是猎鹿博弈——信任足够就合力追大鹿，不够就各自抓兔子。**记住四个字母的顺序，就能辨认生活中大多数两难结构**——这是本章后续课程反复引用的坐标系。

</details>
