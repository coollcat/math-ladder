# 在线学习与无悔算法

## 1. 从一个场景开始

你替一家私募做执行顾问。每天开盘前必须从两位明星分析师里挑一位，照他的建议操作一天，收盘即结账——对就少亏，错就挨一刀。两位各有信徒、互不服气；更麻烦的是市场风格隔一阵就变脸：上半年封神的那位，下半年把把踏空。

"事后诸葛亮"人人会当：一百二十个交易日跑完，翻开账本总能圈出账面最漂亮的那位。可你的决策必须**每天做**，而且当天不许未卜先知。有没有一套纪律，保证无论市场怎么刁难，你的总成绩永远贴着那位事后最优的专家？

这就是在线学习的奠基问题。它的答案只有一行代码的心跳：**谁错，就把谁的信任打折**。

## 2. 直觉解释

给每位专家记一份权重，初始各一票。每天三步：

1. **跟随**：站到加权多数那一边去行动；
2. **结算**：当晚公布每位专家当天是对是错；
3. **配重**：错了的那位，权重乘上一个固定折扣（比如砍半），对的坐庄不动。

信任像复利倒着长：一贯糟糕的专家按指数衰减，几十天后基本销声匿迹；而你自己因为永远站在多数一边，几乎不需要比全场最好的人多亏多少。

先立好本课要量化的那个词——**遗憾**（regret）：跑完全部 $T$ 天后，你的累计损失减去"事后回看时那位最好的单个专家"的累计损失。数级直觉摆在一起看：全押任何一位、或者五五开瞎跟，在对抗性的行情里都可能每天白白多亏常数份，$T$ 天下来遗憾是**线性**的 $\Theta(T)$；乘法权重却能把遗憾压进 $\sqrt{T}$ 量级。$T=120$ 时线性账单上百，平方根账单十几——平方根对线性的胜利，和上一章画过的每条增长曲线如出一辙。

顺带对照第 50 章的老朋友：[多臂老虎机与 regret 预告](../50-reinforcement-learning/160-bandit-regret.md)的世界里，拉哪台机器有多疼要靠你去试，难题是**探索**；而这里每位专家的对错每晚都公开张榜，没有未知报酬要试探，难题变成**聚合**——同样的 $\sqrt{T}$ 刻度，换了一副对抗的面孔。

## 3. 正式定义

记观察期为 $T$ 天，共 $N$ 位专家；第 $t$ 天专家 $i$ 的损失 $\ell_t(i)$ 取 0（说对）或 1（说错）。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $T$ | 观察期 | 一共玩多少天 |
| $N$ | 专家数 | 本课 $N=2$ |
| $\ell_t(i)$ | 当日损失 | 记 0 为对、1 为错 |
| $\eta$ | 学习率 | 说错一次权重乘 $(1-\eta)$，折扣力度 |
| $w_i$ | 权重 | 你对专家 $i$ 当前流动的信任 |

更新规则与跟随分布一气呵成：

$$w_i \leftarrow w_i \,(1-\eta)^{\ell_t(i)}$$

**遗憾**的形式化定义（左端是我们的总损失，右端扣除事后最优那位专家的总损失）：

$$R_T \;=\; \sum_{t=1}^{T} \ell_t(\text{alg}) \;-\; \min_{i} \;\sum_{t=1}^{T} \ell_t(i)$$

**无悔界**（Hedge 定理）：对任意 $\eta \in (0,1)$ 都有

$$R_T \;\le\; \frac{\ln N}{\eta} \;+\; \eta\, T$$

两项一个是"起步学费"、一个是"钝感税"，方向相反。取二者平衡点 $\eta$ 为 $\ln N/T$ 开平方的量级，代入得干净的结果：

$$R_T \;\le\; 2\,\sqrt{T \ln N}$$

最惊人处在于这条界的对手设定：行情可以是**知道你全套算法的恶意对手**，专门往你的软肋打。界照样成立。这是对统计学习的一次升维——不求市场仁慈，只求平均每天亏不掉多少。

## 4. 分步例题

两位天气预报员，五天实录。规则：跟随权重更大的一方（平票听 A 的）；说错一次权重砍半。初始权重 $(1, 1)$。

| 天 | A 预报 | B 预报 | 真相 | 加权多数跟着谁 | 我们 | 收盘权重 (A, B) |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 晴 | 雨 | 雨 | 平票 → A（晴） | ✗ | (0.5, 1) |
| 2 | 晴 | 雨 | 雨 | B（1 > 0.5，报雨） | ✓ | A 又错：(0.25, 1) |
| 3 | 雨 | 晴 | 雨 | B（1 > 0.25，报晴） | ✗ | B 补罪：(0.25, 0.5) |
| 4 | 雨 | 晴 | 雨 | B（0.5 > 0.25，报晴） | ✗ | (0.25, 0.25) |
| 5 | 晴 | 晴 | 晴 | 全体晴 | ✓ | 不动：(0.25, 0.25) |

算账：我们错了 3 次（第 1、3、4 天）。A 共错 2 次、B 也错 2 次，事后最强专家亏 2。遗憾 $= 3 - 2 = 1$，而理论预算 $\ln 2/\eta + \eta T \approx 0.69/0.5 + 2.5 \approx 3.9$——远未超支。

读表的三个瞬间值得咀嚼：第 1 天平票踩坑，是开局无知交的学费；第 2 天 B 两连胜看似封王，可权重榜一动不动（他没犯错就没有加减）；第 4 天两人权重已经打平，**冠军的宝座从来不是永久的，谁犯错谁的信任缩水**。五天里没有一个人被永久判负——这就是下一节模拟里"风水轮流转也扛得住"的全部底气。

## 5. 动手实验

### 实验 1（python）：120 天的赛道实录

剧本是定死的（零随机、结果每次一模一样）：专家 A 的翻车窗口在第 25 到 54 天，隔天必错；轮到专家 B 挨打的窗口在第 65 到 94 天；其余日子两人都只是偶尔失手（每逢第 9 天的同一个位置）。看看死忠粉和聚合者的最终差距：

```python
title="120天赛道实录：死忠粉 vs 乘法权重"
import matplotlib.pyplot as plt   # 绘图库：折线和坐标轴交给它

n = 120                           # 观察期长度（天）
la = []                           # 专家A的每日损失列表：1 表示那天说错
lb = []                           # 专家B的每日损失列表
for t in range(n):                # range(n)：依次取 0 到 n-1
    # 条件表达式："1 if 条件 else 0"，条件成立记 1（错），否则记 0
    ea = 1 if (25 <= t < 55 and t % 2 == 0) or t % 9 == 4 else 0
    eb = 1 if (65 <= t < 95 and t % 2 == 1) or t % 9 == 4 else 0
    la.append(ea)                 # append：把当日损失追加到列表末尾
    lb.append(eb)

eta = 0.3                         # 学习率：错一次砍掉这一份额度的 eta 成
wa = 1.0                          # 专家A的当前权重
wb = 1.0                          # 专家B的当前权重
ours = 0                          # 我们的累计损失
a_cum = 0                         # 专家A的累计损失
b_cum = 0                         # 专家B的累计损失
line_ours = []
line_a = []
line_b = []

for t in range(n):
    if wa >= wb:                  # 权重大者说了算；平票跟随 A
        mine = la[t]
    else:
        mine = lb[t]
    ours += mine                  # += ：累加简写，旧值加上右侧再存回
    a_cum += la[t]
    b_cum += lb[t]
    if la[t] == 1:
        wa = wa * (1 - eta)       # 说错的专家按折扣降权
    if lb[t] == 1:
        wb = wb * (1 - eta)
    line_ours.append(ours)
    line_a.append(a_cum)
    line_b.append(b_cum)

best_end = a_cum                  # 先假设 A 是事后最强，若 B 更省再替换
if b_cum < best_end:
    best_end = b_cum

print("专家A 总损失 =", a_cum)
print("专家B 总损失 =", b_cum)
print("我们的总损失 =", ours)
print("事后最强专家 =", best_end)
print("我们的悔恨 =", ours - best_end)
print("理论预算上限 =", round(2 * (n * 0.69) ** 0.5, 1))    # 近似 2*sqrt(T*lnN)

xs = list(range(n))               # list(range(n))：横轴的天数序列
plt.figure(figsize=(7, 3))        # 新建一幅宽 7、高 3 英寸的画布
plt.plot(xs, line_ours, label="hedge (ours)")
plt.plot(xs, line_a, label="expert A")
plt.plot(xs, line_b, label="expert B")
plt.axhline(best_end, linestyle="--", linewidth=1, label="best single")   # axhline：水平参考线
plt.legend()
plt.xlabel("day")
plt.ylabel("cumulative loss")
```

账面照录：A 合计 27、B 合计 26、我们 27、事后最强 26、**悔恨只有 1**，理论预算约 18.2。图上是两条爬梯子的橙绿曲线——第 25 天过后 A 连滚带爬往上蹭、B 尚且安详；第 65 天起轮到 B 上刑。而蓝色那道乘法权重的台阶只在开局平票吃过一口，之后几乎整程贴着"当时更靠谱的那条"飞行。这不是运气好：哪怕把对手换成会读心的恶意市场，$\sqrt{T}$ 的预算也照付不误。

### 实验 2（viz）：平均每天的悔恨终将贴地

把无悔界除以天数，得到"每天平均多亏多少"的理论上界：蓝线 $2\sqrt{(\ln 2)/x}$ 随天数滑落。橙色水平线是天真策略（全押某位、或五五开硬刚）面对针对性安排时的常数级日伤。读图：蓝线越过第 11 天后就永远压在水平线下——**天数越长，平均每天的悔恨越接近零**。"无悔"说的是这件事，不是从未输过。

### 快问快答

```quiz
市场风格隔一阵就变，昨天还封神的专家今天就哑火。乘法权重凭什么不怕"风水轮流转"？
- 它每隔几天就把全部权重清零重新起跑
- 它会在中途直接改押当时排名靠后的黑马博反弹
- 权重从不清零：对方犯错时你的相对份额自动抬头，轮流挨打的序列自己会把队列洗回来 [*]
? 惩罚永远是相对的、逐日的，没有任何判决是永久的。旧的掉队者只要歇够了，就能凭对手的新失误卷土重来——这正是它能应对对抗环境的本钱。
```

:::warning[常见误区]

**误区一**："你以为'无悔'是说天天都赢。" 相反，实验里我们也亏了 27 天里整整 27 次。无悔约束的是**总账差距**：$R_T$ 除以 $T$ 趋于零，每个交易日摊到的悔恨薄到可以忽略。

**误区二**："你以为聪明人应该早早认准赢家然后死磕。" 实验里的"死忠粉"谁都没占到大便宜——任何一个固定的锚点都会被错峰的翻车窗口反复敲打。聚合的意义正是拒绝当靶子，这与纳什均衡课"混出概率才稳得住"一脉相承。

**误区三**："你以为学习率越敏感越好。" 把折扣从砍半改成砍九成，适应确实快了，但对手只需偶尔制造两次假摔就能把你的信任荡成秋千。学习率是"反应速度 × 抗噪能力"的公共旋钮，练习 2 会让你亲手掂量它。

:::

## 6. 练习

**练习 1**：把分步例题的账再自己跑一遍——但这份代码把奖惩方向写反了：预测错的人不减反增。修到四行输出全部正确为止：

```exercise
# @title: 练习：五天预报的重配重
# @check: 2
# @check: 1
# @check: 0.5
# @check: 0.25
# @hint: 方向反了——预测错的专家应当降权（权重乘 0.5），现在却在乘 2。两条错误分支都要改；计数器逻辑保持原样。
preds_a = ["晴", "雨", "雨", "雨", "晴"]    # 专家A每天的预报
preds_b = ["雨", "雨", "晴", "晴", "晴"]    # 专家B每天的预报
truths = ["雨", "雨", "雨", "雨", "晴"]     # 每天的真相
wa = 1.0                                    # A 的权重（初始各一票）
wb = 1.0                                    # B 的权重
our_miss = 0                                # 我们自己的失误计数器
ma = 0                                      # A 的失误计数器
mb = 0                                      # B 的失误计数器

for t in range(5):                          # 循环处理五天
    if wa >= wb:                            # 平票或 A 更可信时跟随 A
        guess = preds_a[t]                  # 列表按下标取元素：第 t 天的预报
    else:                                   # 否则跟随 B
        guess = preds_b[t]
    if guess != truths[t]:
        our_miss += 1                       # 我们的预测和真相不符，记一笔
    if preds_a[t] != truths[t]:
        ma += 1
        wa = wa * 2                         # ← 问题在这：错的竟然翻倍，方向反了
    if preds_b[t] != truths[t]:
        mb += 1
        wb = wb * 2                         # ← 这行同样要把 2 改成 0.5

best_miss = ma                              # 先记下 A 的错误数
if mb < best_miss:                          # 谁错得少谁是"事后最强专家"
    best_miss = mb

print(our_miss)
print(best_miss)
print(round(wa, 2))                         # round：四舍五入到小数点后两位
print(round(wb, 2))
```

修好后输出 2、1、0.5、0.25：我们仅失误 2 次，事后最强的专家错 1 次，遗憾为 1，仍在 $\ln 2/\eta + \eta T \approx 3.9$ 的预算之内。而反向版本会让输家的权重膨胀到 2 和 4——"越错越红"，账本一眼假。

**练习 2**：沿用这份数据，把学习率换个挡位重估无悔预算：$\eta = 0.9$（急脾气）与 $\eta = 0.2$（慢性子）分别给出多宽的界？哪种离最优平衡点更近？

<details>
<summary>点开查看逐步解答</summary>

无悔界是 $\ln 2/\eta + \eta T$，代入 $T = 5$、$\ln 2 \approx 0.69$：急脾气 $\eta=0.9$ 时 $0.77 + 4.5 = 5.27$；慢性子 $\eta=0.2$ 时 $3.47 + 1 = 4.47$。理论平衡点在 $\eta^\ast = \sqrt{\ln N / T} \approx 0.37$ 处，最小值 $2\sqrt{T\ln 2} \approx 3.7$。两头都比中间松——太钝则学不到，太急则被噪声牵着走。这个"起点学费与钝感税"的权衡，就是 bandit 探索参数的同族命题。
</details>

## 7. 选读：平方根是从哪里长出来的

<details>
<summary>选读 · 势函数论证的五步骨架</summary>

整条证明盯着一个叫"势函数"的记账指标 $\Phi_t$：全体权重之和。第一步，每轮结算只会让 $\Phi$ 缩水或原地不动，缩多少能用当天的总损失写出来（损失越大、割得越多），这是一条下界；第二步，任何单个专家 $i$ 无论表现如何，它的权重至多被同一条更新公式衰减，于是它的份额 $w_i/\Phi$ 有保底——把它从第一天排到最后一天，得到另一条上界。第三步把两条放一起，遗憾值被夹进 $\dfrac{\ln N}{\eta}$ 与 $\eta T$ 的夹缝；第四步对 $\eta$ 求平衡得 $2\sqrt{T \ln N}$。第五步则是所有在线学习的家谱：Littlestone–Warmuth 的加权多数、Freund–Schapire 的 Hedge、多臂老虎机的 $\sqrt{KT}$、甚至 AdaBoost 的误差界，都是同一具骨架穿不同戏服——指数加权的聚合力，在最坏情况下仍然神通广大。

</details>
