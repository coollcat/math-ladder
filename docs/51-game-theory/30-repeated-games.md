# 重复博弈与合作

## 1. 从一个场景开始

景区门口的餐馆敢宰客：游客吃完就走，再也不会来。小区门口的早餐店却把豆浆称得足足的：街坊邻居天天见面，一次缺斤短两传遍整栋楼。

**同一个人，换个场合就换了良心？** 不必诉诸道德——是博弈结构变了。一次性囚徒困境里背叛稳赚（上一课已推演）；但当同一局游戏要反复玩、且没人知道哪天散场时，"未来的影子"开始改变今天的算盘。1980 年，政治学家阿克塞尔罗德组织了一场计算机锦标赛：邀请各路博弈论专家提交程序，在重复囚徒困境里互相厮杀。夺冠的是最短的程序——四行 FORTRAN 的"以牙还牙"。

## 2. 直觉解释

重复博弈里，每一步棋都自带两张账单：今天的收益单，和"对方将如何记仇/报恩"的未来单。背叛多赚眼前 2 分，却可能招来永远的合作终止——值不值，取决于你把未来打几折。

这个折扣就是**贴现因子** $\delta$：明天的 1 分钱在心里等于今天的 $\delta$ 分。$\delta$ 接近 1 = 高瞻远瞩；接近 0 = 及时行乐。合作的存亡全系于一条分界线：**当未来足够重要（$\delta$ 足够大），长期合作流的价值压倒一次背叛的甜头**——理性人开始讲信用。

以牙还牙（Tit-for-Tat）的策略只有两条：第一步合作；之后照抄对方上一手。它善良（先伸手）、可激怒（立刻报复）、宽容（对方回头我立刻翻篇）、清晰（谁都看得懂）——四个品质恰好是锦标赛冠军的共同配方。

## 3. 正式定义

无限重复的囚徒困境（每轮收益 $T=5, R=3, P=1, S=0$），贴现因子 $\delta \in (0,1)$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\delta$ | 贴现因子 | 未来收益的"汇率"，$0<\delta<1$ |
| 触发策略 | 惩罚机制 | 一旦被背叛就永久转向互骗（本课用最狠的版本） |
| 合作流价值 | 长期账本 | $\dfrac{R}{1-\delta}$：等比级数求和（第 8 章公式） |

**合作条件推导**：一直合作的总价值 $V_C = R + \delta R + \delta^2 R + \cdots = \dfrac{R}{1-\delta}$。若本轮偷偷背叛：今天拿 $T$，明天起对方触发报复、永堕 $P$，总价值 $V_D = T + \dfrac{\delta P}{1-\delta}$。合作划算当且仅当

$$\frac{R}{1-\delta} \ge T + \frac{\delta P}{1-\delta}$$

代入 $R=3, T=5, P=1$ 化简得 $3 \ge 5(1-\delta) + \delta$，即

$$\delta \ge \frac{1}{2}$$

**耐心过半，合作诞生**——这就是"无名氏定理"精神的缩影：只要未来足够重要，连最自私的玩家也会自愿结盟。

## 4. 分步例题

两位店主，每轮合作各赚 $R=3$；背叛者单轮独赚 $T=5$，此后互骗各得 $P=1$。

1. 眼光短浅型（$\delta = 0.4$）：合作流 $= \frac{3}{0.6} = 5$；背叛流 $= 5 + \frac{0.4\times1}{0.6} \approx 5.67$ → 背叛更香，信用体系崩塌；
2. 着眼长远型（$\delta = 0.6$）：合作流 $= \frac{3}{0.4} = 7.5$；背叛流 $= 5 + \frac{0.6\times1}{0.4} = 6.5$ → 合作胜出，豆浆足两；
3. 临界点核对（$\delta = 0.5$）：两边都是 $6$ ——与上一课导出的门槛严丝合缝；
4. 解读：$\delta$ 从 0.4 挪到 0.6，同样的矩阵、同样自利的玩家，行为模式完全翻转。**制度设计的杠杆不是改造人性，而是提高人们眼中的 $\delta$**：会员制、押金、声誉评分，都是在给"下一次"加码。

## 5. 动手实验

### 实验 1（python）：复现锦标赛的核心对局

```python title="三种相遇，三种命运"
R, P, S, T = 3, 1, 0, 5          # Axelrod 1980 锦标赛的收益设定

def move_tft(my_last, opp_last):
    if my_last is None:
        return "C"
    return opp_last              # 以牙还牙：照抄对方上一手

def move_alld(my_last, opp_last):
    return "D"                   # 死硬背叛派

def match(strat_a, strat_b, rounds):
    la = None
    lb = None
    score_a = 0
    score_b = 0
    for t in range(rounds):
        ma = strat_a(la, lb)
        mb = strat_b(lb, la)
        if ma == "C" and mb == "C":
            score_a += R; score_b += R
        elif ma == "D" and mb == "D":
            score_a += P; score_b += P
        elif ma == "D":
            score_a += T; score_b += S
        else:
            score_a += S; score_b += T
        la = ma
        lb = mb
    return score_a, score_b

print("tft vs alld:", match(move_tft, move_alld, 100))
print("tft vs tft :", match(move_tft, move_tft, 100))
print("alld vs alld:", match(move_alld, move_alld, 100))
```

输出三组总分：对死硬派 99 对 104（小输但没输惨）；镜像相遇 300 对 300（满载而归）；两个死硬派互撞 100 对 100（双输地板）。**冠军不靠赢每一局，靠不把局面做坏。**

### 快问快答

```quiz
已知双方都知道博弈恰好在第 100 轮结束，会发生什么？
- 前 99 轮合作、最后一轮互咬
- 从第一轮就互咬：逆向归纳把合作逐轮拆光 [*]

? 最后一轮没有未来，等同一次性博弈；倒数第二轮预见到这点也失去合作理由……链条逐轮回卷到底。"确定的终点"是合作的毒药。
```

:::warning[常见误区]

**误区一**："你以为以牙还牙是无敌策略。" 它怕噪声：一次误会（比如信号传输错误）会让两个 TFT 陷入交替报复的死循环。后续研究普遍改推更宽容的变体（如"以牙还牙但偶尔原谅"），阿克塞尔罗德本人也强调冠军属于"当时的生态"，不是永恒真理。

**误区二**："你以为合作出现说明玩家善良。" 全程零道德假设：合作只是自利者在特定参数下的最优解。参数一变（$\delta$ 掉下门槛），同一批"好人"立刻翻脸——这正是模型的冷峻之处，也是它解释力所在。

**误区三**："你以为重复次数越多越好合作。" 关键不是次数而是**不确定的终点**。固定 100 轮反而拆台；"每天可能继续"的无穷影子和随机终点才能撑起合作。商业上对应的就是：别让合作伙伴知道你哪天撤资。

:::

## 6. 练习

**练习 1**：修好这台"长期账本计算器"。它能跑，但背叛流的惩罚项忘了打折——导致结论错得离谱：

```exercise
# @title: 练习：给未来打个折
# @check: 6.0
# @check: 6.0
# @check: 7.5
# @check: 6.5
# @hint: 背叛后的互骗收益也要按等比级数折现：T + delta*P/(1-delta)。对照合作流的写法补全。
R = 3
P = 1
T = 5

for delta in [0.5, 0.6]:
    coop_value = round(R / (1 - delta), 2)
    cheat_value = round(T + P, 2)          # ← 问题在这：惩罚项没有乘 delta/(1-delta)
    print(coop_value)
    print(cheat_value)
```

四行输出正是例题的三组对照外加临界点：$\delta=0.5$ 时两线持平，$\delta=0.6$ 时合作反超。

**练习 2**：把实验 1 的对手换成"前 50 轮合作、之后突然转黑"的骗子策略，算一算 TFT 的最终得分，并解释哪一步让它止损。

<details>
<summary>点开查看逐步解答</summary>

```python
turn = {"n": 0}                        # 用字典当轮次计数器：函数要跨轮记住状态

def move_traitor(my_last, opp_last):
    turn["n"] += 1                     # 每被调用一次就是新的一轮
    if turn["n"] <= 49:
        return "C"                     # 前 49 轮伪装合作
    return "D"                         # 第 50 轮起突然转黑

# 若要重跑一遍，先把 turn["n"] 归零
print(match(move_tft, move_traitor, 100))   # (197, 202)
```

直接按规则手推更快：第 1 到 49 轮双方互合（各 $49\times3=147$）；第 50 轮骗子突袭（TFT 得 $S=0$，骗子得 $T=5$）；从第 51 轮起 TFT 照抄对方的 D，进入互骗直到第 100 轮（各 $50\times1=50$）。TFT 总分 $147+0+50=197$，骗子 $147+5+50=202$。

关键一步在第 51 轮：TFT **只被占一轮便宜**，立刻降级为互骗止损。宽容与报复的平衡正是它的生存智慧；若改成"永不原谅"的触发策略，得分同样是 197——但对偶发误会的恢复力会差得多。

## 7. 选读：无名氏定理在说什么

<details>
<summary>选读 · 可行集与均衡集的天壤之别</summary>

一次性博弈的均衡收益集往往又小又糟（囚徒困境只有 $(P,P)$）。"无名氏定理"（folk theorem，因多人独立发现而得名）宣告：在无限重复且 $\delta$ 足够大时，任何"每人不低于底线收益"的可行收益组合，都能被某个均衡实现——包括 $(R,R)$ 的合作天堂，也包括各种精心设计的奖惩轨道。

它同时是希望与警告：希望在于，合作秩序不需要中央强制，互惠机制自己立得住；警告在于，坏均衡同样可以自我维持（长期互吓、默契卡特尔）。理论本身不替我们挑结局——挑选发生在规则设计层面，这正是下一课机制设计要接手的活。

</details>
