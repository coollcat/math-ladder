# 合作博弈与 Shapley 值：功劳该怎么分

## 1. 从一个场景开始

三个人合伙做成了项目，拿到 100 万奖金。可如果拆开来看：A 单干能挣 30 万，B 单干 20 万，C 单干只有 10 万；A 和 B 一起能挣 60 万，A 和 C 一起 45 万……钱不是按人头平均掉的，合作带来了**额外的收益**。这笔额外的钱是谁挣来的？

一个自然的想法是"按贡献分"，但**贡献是多少，取决于你站在哪个队伍里**：C 和 A 搭伙时，C 带来 15 万；C 和 B 搭伙时只带来 15 万；而 A 在已经有 B、C 的队里还能再添 65 万。谁先来、谁后到，边际贡献完全不同。这一课给出一个不依赖名次、也不靠"感觉"的分法——**Shapley 值**。

## 2. 直觉解释

**第一层：只认"联盟的价值"。** 把注意力从"谁强谁弱"挪开，改成问每**一个可能的合作组合**值多少钱。这个"组合 → 价值"的字典叫**特征函数**；只要能列出它，分配问题就有了原始素材。

**第二层：功劳 = 边际贡献，但边际贡献依赖顺序。** 想象大家**一个接一个**加入团队。轮到你入场时，团队因为你多赚了多少，就是你这一次的边际贡献。问题在于：先来后到会改变这个数——你越晚加入，能"蹭"到的既有基础越厚，边际贡献可能越大或越小。

**第三层：把所有顺序都试一遍，取平均。** Shapley 的解法朴素到近乎粗暴：把 $n!$ 种加入顺序**全部列出来**，每个人在每个顺序里算一次边际贡献，再对所有顺序取平均。它等价于一句更文雅的话——**你的功劳 = 你平均而言给随机一个联盟带来的增量**。

**第四层：为什么是"平均"？** 因为平均是唯一一种"不偏袒任何名次"的算法。下面第 3 节的四条公理会把这份直觉钉成定理：满足这几条常识的分法**存在且唯一**。

## 3. 正式定义

**合作博弈**由一个玩家集合 $N$（$|N|=n$）和**特征函数** $v:2^{N}\to\mathbb{R}$ 组成，其中 $v(\varnothing)=0$；子集 $S\subseteq N$ 叫**联盟**，$v(S)$ 是联盟 $S$ 单独合作能创造的价值。

**Shapley 值** $\phi_i(v)$ 有两种等价写法。**按排列（推荐用来理解）**：

$$\phi_i(v)=\frac{1}{n!}\sum_{\pi\in \Pi(N)}\Big[v\big(P_i^{\pi}\cup\lbrace i\rbrace\big)-v\big(P_i^{\pi}\big)\Big],$$

其中 $\Pi(N)$ 是全部 $n!$ 个加入顺序，$P_i^{\pi}$ 是在顺序 $\pi$ 里排在 $i$ **之前**的人。**按联盟**：

$$\phi_i(v)=\sum_{S\subseteq N\setminus\lbrace i\rbrace}\frac{|S|!\,(n-|S|-1)!}{n!}\Big[v(S\cup\lbrace i\rbrace)-v(S)\Big].$$

两个式子只差一个"先固定顺序再数人"还是"先固定联盟再数顺序"，值完全相同。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $N,\ n$ | 玩家集、人数 | 参与者全体；$n!$ 是全部加入顺序数 |
| $v(S)$ | 特征函数 | 联盟 $S$ 合作能产生的价值；$v(\varnothing)=0$ |
| $S\cup\lbrace i\rbrace\setminus S$ | 边际贡献 | $i$ 加入前 vs 加入后的价值差 |
| $\phi_i$ | Shapley 值 | 玩家 $i$ 应得的份额，是对所有顺序取的平均边际贡献 |
| $\frac{\vert S\vert!(n-\vert S\vert-1)!}{n!}$ | 权重 | 联盟 $S$ 在全部顺序里出现的次数占比 |

**四条公理**（它们一起**唯一确定**了 Shapley 值）：

1. **有效性（Efficiency）**：$\sum_i\phi_i(v)=v(N)$——分完，一分不多一分不少；
2. **对称性（Symmetry）**：两个玩家在所有联盟里可互换（贡献处处相同），则分得相同；
3. **哑元（Dummy）**：对任何联盟都没有边际贡献的人，得 0；
4. **可加性（Linearity）**：两个博弈相加，Shapley 值也相加。

## 4. 分步例题

沿用开头的特征函数（单位：万元）：

$$v(\varnothing)=0,\quad v(A)=30,\ v(B)=20,\ v(C)=10,\quad v(AB)=60,\ v(AC)=45,\ v(BC)=35,\quad v(ABC)=100 .$$

**第一步：列出全部 $3!=6$ 个加入顺序，逐个算边际贡献。**

| 顺序 | 第 1 人（+增量） | 第 2 人（+增量） | 第 3 人（+增量） |
| --- | --- | --- | --- |
| A B C | A +30 | B +$(60-30)=30$ | C +$(100-60)=40$ |
| A C B | A +30 | C +$(45-30)=15$ | B +$(100-45)=55$ |
| B A C | B +20 | A +$(60-20)=40$ | C +$(100-60)=40$ |
| B C A | B +20 | C +$(35-20)=15$ | A +$(100-35)=65$ |
| C A B | C +10 | A +$(45-10)=35$ | B +$(100-45)=55$ |
| C B A | C +10 | B +$(35-10)=25$ | A +$(100-35)=65$ |

**第二步：把每个人的六次边际贡献加起来除以 6。**

- $\phi_A=(30+30+40+65+35+65)/6=265/6\approx44.17$；
- $\phi_B=(30+55+20+20+55+25)/6=205/6\approx34.17$；
- $\phi_C=(40+15+40+15+10+10)/6=130/6\approx21.67$。

**第三步：验算有效性。** $44.17+34.17+21.67=100.00$ ✔——正好是联盟总价值，不差分毫。

**第四步：用联盟公式复核 $\phi_A$。** 枚举 $S\subseteq\lbrace B,C\rbrace$ 共四种，权重按 $|S|!(2-|S|)!/3!$：

$$\phi_A=\underbrace{\tfrac26\,(30-0)}_{S=\varnothing}+\underbrace{\tfrac16\,(60-20)}_{S=\lbrace B\rbrace}+\underbrace{\tfrac16\,(45-10)}_{S=\lbrace C\rbrace}+\underbrace{\tfrac26\,(100-35)}_{S=\lbrace B,C\rbrace}=10+\tfrac{40}{6}+\tfrac{35}{6}+\tfrac{130}{6}\approx44.17 .$$

与排列法一致。注意 $\phi_C$ 明显低于单干价值 $10$ 对应的"感觉"，因为 C 的补位作用在 A、B 已到齐时只剩 10 万——**末位入场的边际贡献被压薄，是 Shapley 值最反直觉、也最公平的地方**。

## 5. 动手实验

### 实验 1（viz）：同一个联盟只有一种，入伙顺序却有六种

```viz
{
  "type": "counting",
  "title": "三个玩家：联盟 C(3,3)=1，加入顺序 P(3,3)=6",
  "n": 3,
  "k": 3
}
```

把 $n$ 和 $k$ 拖一拖：左边"组合"面板问的是"哪些人凑一队"，右边"排列"面板问的是"按什么顺序入队"。Shapley 值恰恰是对**右边这 6 条顺序**取平均——组合告诉我们联盟值多少，排列告诉我们功劳怎么摊。人数一涨，$n!$ 立刻爆炸（$n=10$ 就是 360 万条），这正是后面"算不动就采样"的根源。

### 实验 2（python）：枚举所有排列，让程序替你取平均

```python title="Shapley 值：6 条顺序逐一累加边际贡献"
from itertools import permutations      # 排列生成器：标准库自带（第 32 章引入过）

value = {                               # 特征函数：联盟（玩家名排序拼成的字符串）→ 价值
    "": 0,
    "A": 30, "B": 20, "C": 10,
    "AB": 60, "AC": 45, "BC": 35,
    "ABC": 100,
}

def v(members):                         # 把玩家元组排序拼成键再查表
    return value["".join(sorted(members))]

players = ["A", "B", "C"]
totals = {p: 0.0 for p in players}      # 字典推导：每人先开一个累加格

orders = list(permutations(players))    # 全部 3! = 6 个加入顺序
for order in orders:
    arrived = ()                        # 已入伙的人（空元组起步）
    for who in order:
        gain = v(arrived + (who,)) - v(arrived)   # 边际贡献：加入后 − 加入前
        totals[who] += gain             # += ：累加简写
        arrived = arrived + (who,)      # 元组拼接要加逗号，否则是字符串

for p in players:
    print(p, "Shapley 值 ≈", round(totals[p] / len(orders), 2))
print("总和", round(sum(totals.values()) / len(orders), 2))
```

输出 $A\approx44.17$、$B\approx34.17$、$C\approx21.67$，总和 100——和手算一字不差。改一改 `value` 字典就能秒算别的分账规则：比如把 $v(AC)$ 从 45 提到 55，你会看到 $\phi_A$ 上升、$\phi_B$ 下降，而总和始终锁死在 100。

### 实验 3（python）：三种分法，谁最服众

```python title="平均分 vs 按单干分 vs Shapley"
import matplotlib.pyplot as plt

players = ["A", "B", "C"]
standalone = [30, 20, 10]          # 单干价值（也常被当成"按个人能力分"）
shapley = [44.17, 34.17, 21.67]
equal = [100 / 3, 100 / 3, 100 / 3]   # 平均分

plt.bar([p + "-均分" for p in players], equal, width=0.25, label="均分")
plt.bar([p + "-单干" for p in players], standalone, width=0.25, label="按单干")
plt.bar([p + "-Shapley" for p in players], shapley, width=0.25, label="Shapley")
plt.legend()
plt.ylabel("万元")
```

三组柱子摆在一起：均分让 A 吃亏（A 单干就值 30，却只能拿 33.3）、C 占便宜；按单干分总和只有 60，20 万的合作红利无人认领；只有 Shapley 既分满了 100 万，又让"合作红利"按边际贡献落到人头。

Shapley 值对"加入顺序"取平均，最想解决的问题是什么？
- 让算得慢，显得算法高级
- 边际贡献会随先来后到变化，取遍所有顺序的平均才能不偏袒任何名次 [*]
- 让每个人的分配额都相等

## 6. 常见误区

:::warning[常见误区]

**误区一**："你以为该按'单干能力'分。" 单干价值只说明"你自己能挣多少"，不说明"合作里缺了你损失多少"。上面的 $C$ 单干只有 10，但在 $\lbrace A,B\rbrace$ 已成形的队伍里补位时几乎不增厚贡献，最终 $\phi_C\approx21.67$ 反而高于单干；而 A 是"关键先生"，$\phi_A\approx44.17$ 远超其单干 30。**看的是边际贡献，不是个人实力**。

**误区二**："你以为 Shapley 值"唯一"就等于"绝对公平"。" 唯一是**相对于那四条公理**而言：换一套公理就会得到别的解（比如核（core）、核仁（nucleolus））。Shapley 值只保证"满足这四条常识的分法只有它"，不保证它讨好所有人。

**误区三**："你以为算 Shapley 值只要枚举 $2^n$ 个联盟就够了。" 联盟确实只有 $2^n$ 个，但**排列有 $n!$ 个**；$n=20$ 时 $20!\approx2.4\times10^{18}$，天文数字。所以真实应用（如特征归因）大多**采样若干排列做蒙特卡洛近似**，用精度换可行——这正是 SHAP 库的做法。

:::

## 7. 练习

**练习 1**（判题）：下面的程序忘了除以排列数，输出的是"边际贡献总和"而非平均值——修到通过：

```exercise
# @title: 练习：把 Shapley 值除以排列数
# @check: 44.17
# @check: 34.17
# @check: 21.67
# @hint: 每个玩家在 6 个顺序里的边际贡献之和，要除以顺序数 6 才是平均值。现在只累加没除法。
marginals = {                      # 每人 6 次边际贡献（对应上一节表格的每一列）
    "A": [30, 30, 40, 65, 35, 65],
    "B": [30, 55, 20, 20, 55, 25],
    "C": [40, 15, 40, 15, 10, 10],
}
for name in ["A", "B", "C"]:
    total = 0
    for m in marginals[name]:
        total += m
    print(round(total, 2))         # ← 问题在这：应先除以顺序数 6
```

修好后输出 $44.17,\ 34.17,\ 21.67$。不除 6 的话和是 $265$、$205$、$130$，加起来 $600$——正好是联盟价值的 6 倍，"有效性"一眼就被破坏。

**练习 2**（概念）：为什么说 Shapley 值"不偏袒名次"？用上面的 $\phi_C$ 说明。

<details>
<summary>点开查看逐步解答</summary>

在 6 个顺序里，C 有时第一个入场（拿到自己的独立价值 10），有时最后一个入场（在 $\lbrace A,B\rbrace$ 已成形后只补 40）；同一个 C，边际贡献在 10 到 40 之间浮动。如果规则规定"永远按 A、B、C 的顺序分配"，C 就被钉死在最后一个位置、只拿 40，等于默认给 C 加了一个不利的名次权重。**对全部 $n!$ 个顺序取平均，等价于给每个名次相同的出现机会**，谁也无法靠"我该排第几"影响自己的份额——这就是"不偏袒名次"的含义，也呼应了对称性公理。

</details>

**练习 3**（概念）：特征函数 $v(S)$ 一定得是"真金白银"吗？举一个不是钱的例子。

<details>
<summary>点开查看逐步解答</summary>

不必。$v$ 只要求"给每个联盟一个实数分数"，具体是什么由问题决定。比如：$S$ 是一组特征，$v(S)$ 是"只用这组特征训练出的模型准确率"——这时 Shapley 值告诉你每个特征对准确率的平均贡献，就是 **SHAP 特征归因**的合法性来源。数据估值的 **Data Shapley** 里，$v(S)$ 则是"用数据子集 $S$ 训练后验证集的收益"。同一个数学结构，换一个 $v$ 就换了一个应用领域。

</details>

## 8. 选读：从分奖金到可解释 AI

<details>
<summary>选读 · SHAP、Data Shapley 与"核心"的边界</summary>

**一、SHAP：把特征当玩家。** 模型给一个样本的预测 $f(x)$ 可以写成"基准值 + 各特征贡献之和"：把特征集合 $N$ 当成玩家，$v(S)=$ 只用特征子集 $S$ 时的（期望）预测。Shapley 值保证 $\sum_i\phi_i=f(x)-\mathbb{E}[f]$，且贡献满足对称、哑元、可加——这正好对应"特征重要性的四条常识"。它比"删掉特征看变化"（leave-one-out）稳得多：后者忽略了特征之间的交互，而 Shapley 对每个联盟都算了增量。代价是精确计算要 $2^n$ 次模型推理，于是 SHAP 用采样近似 + 对特定模型族的解析简化（如 TreeSHAP）把它压到可用。

**二、Data Shapley：给训练数据定价。** 把"每个训练样本"当玩家，$v(S)=$ 只用子集 $S$ 训练后的测试表现。得到的 $\phi_i$ 可用来清洗噪声标签、做数据市场定价。它比"留一法"（删掉一个样本重训）贵得多，但能正确分摊"多个样本冗余提供同一信息"时的功劳。

**三、核心（core）与核仁（nucleolus）。** Shapley 值不是唯一的"公平分法"。**核心**要求没有任何子联盟能靠单干拿到比分配更多的钱（$\sum_{i\in S}\phi_i\ge v(S)$ 对一切 $S$ 成立），但核心可能是空的、也可能很大。**核仁**则是在核心非空时按"最不公平的联盟"逐层最小化——它是另一个满足有效性与对称性的解，却在取舍上与 Shapley 不同。选哪个，取决于你把哪条公理排在第一位。

</details>
