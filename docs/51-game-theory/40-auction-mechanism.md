# 拍卖与机制设计初见

## 1. 从一个场景开始

你每打开一次搜索结果，幕后就有一场拍卖：几家广告主为"这个位置的这一秒"密封出价，毫秒之间定胜负、定价格。谷歌每年经手的这类拍卖以百亿次计。

拍卖规则千奇百怪：现场举牌越喊越高（英式）、价格从高往低降先按停者得（荷兰式，全球鲜花市场的日常）、密封信封比谁价高付谁的价（第一价）、以及最反直觉的一种——**出价最高者赢，但只付第二高的价钱**。最后这种是 1961 年维克里教授在论文里系统分析的"第二价格拍卖"，它藏着一个漂亮的机关：**说真话是每个人的最优策略**。本课拆解这个机关，并顺藤摸到它的学科母题——机制设计。

## 2. 直觉解释

普通拍卖里报高价的冲动人人都有：多喊一点，赢得更稳。第二价拍卖却把这套算盘拆了——因为你付的价钱**与你自己的报价无关**：

- 报低了自己的估值：可能把本该到手的便宜货拱手让人（赢了本来净赚，输了白亏）；
- 报高了自己的估值：赢得更"稳"了，可一旦别人的最高价落在你的估值之上，你就得溢价买单；
- **如实报出自己的估值：两头的好处全占，两头的风险全无。**

规则的作者维克里做的事，本质上是上一课思想的反向应用：博弈论分析"给定规则大家怎么玩"；**机制设计**倒过来问"想要大家好好玩，该立什么规矩"。让真话成为占优策略的性质，叫**激励兼容**——它是机制设计的圣杯之一。

## 3. 正式定义

设你的私人估值（这件东西对你真实值多少）为 $v$；其他所有人的最高报价为 $m$。第二价拍卖中你报价 $b$ 的结局：

$$\text{净利润} = \begin{cases} v - m & b > m \quad (\text{赢，付对手的最高价 } m) \\ 0 & b < m \quad (\text{输}) \end{cases}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $v$ | 私人估值 | 只有你自己知道的真实心理价位 |
| $b$ | 报价 | 你写在纸上的数字，可以撒谎 |
| $m$ | 第二高价 | 成交价 = 对手最高报价，与你无关 |

**定理（Vickrey, 1961）**：报 $b = v$ 是弱占优策略。论证三行：

1. 若 $v > m$：报真值赢、赚 $v-m$；报低于 $m$ 则白白输掉这份利润；报更高不改变付款额，纯多余；
2. 若 $v < m$：报真值输、保住 0；报高于 $m$ 会以 $m-v>0$ 的亏损接盘；报更低同样无事发生；
3. 三种偏离在一切情形下都不会更好，有的明显更糟 → 真话占优。∎

## 4. 分步例题

你的估值 $v=80$，对手们的最高报价 $m=60$。

1. 如实报 80：成交，付 60，净赚 20 ✓；
2. 谨慎压价报 50：出局，净赚 0——那 20 元利润被自己的"聪明"弄丢了；
3. 激进抬价报 100：本场仍付 60、赚 20，看似无害——但换一天 $m=85$ 时，你会以亏 5 接盘；而如实报 80 的你那天安然置身事外；
4. 结论：抬价只在"本来就赢定了"的场景里重复既有利润，却在"对手突然变强"的场景里制造新亏损——**虚高没有回报，只有悬崖**。这正是 eBay 把二价逻辑做成自动代理出价的原因。

对照记忆：第一价密封拍卖（付自己的报价）没有这份诚实红利——报 80 必付 80 白忙一场，理性玩家必须**故意压价**（bid shading）。同一样商品、两种规则、两副面孔：策略由机制塑造。

## 5. 动手实验

### 实验 1（python）：扫描报价，画出那条悬崖

```python title="报价扫描：虚高的代价"
import matplotlib.pyplot as plt

v = 80        # 你的真实估值
m = 60        # 对手们的最高报价（也是成交价）

bs = []
profits = []
b = 40
while b <= 100:              # while：条件成立就继续循环
    if b > m:
        profit = v - m       # 赢了：付的是对手的最高价 m
    else:
        profit = 0           # 输了：分文不损也分文不得
    bs.append(b)
    profits.append(profit)
    b += 1                   # 手动迈步，否则死循环

plt.plot(bs, profits, linewidth=2)
plt.xlabel("your bid")
plt.ylabel("net profit")
```

图像是一条平台加一道悬崖：从 61 到 100 全都稳赚 20——**没有任何一个报价能让你多赚一分钱**；而一旦某天 $m$ 冲过 80，悬崖底下就是亏损区。

### 实验 2（python）：三人竞拍结算器

```python title="谁赢？付多少？"
valuations = {"甲": 70, "乙": 60, "丙": 40}   # 各自的真实估值
bids = {"甲": 70, "乙": 75, "丙": 45}         # 实际报价（乙撒谎抬价了）

top_name = ""
top_bid = 0
for name in bids:                             # 第一遍扫描：找最高报价者
    if bids[name] > top_bid:
        top_bid = bids[name]
        top_name = name

runner_up = 0                                 # 第二遍扫描：找其余人里的最高价
for name in bids:
    if name != top_name and bids[name] > runner_up:
        runner_up = bids[name]

print(f"赢家 {top_name}, 成交价 {runner_up}")
print(f"赢家净利 {valuations[top_name] - runner_up}")
```

乙靠虚高抢下商品，却要付出 70——超过自己估值 60，**净亏 10**。若他当初如实报 60，甲会以 60 成交、乙全身而退。谎言的账单精确到个位数。

### 快问快答

```quiz
第二价拍卖里，把自己的报价压到估值之下会发生什么？
- 省钱：反正付的是别人的价
- 可能输掉本来能净赚的交易，且省不下任何成本 [*]
- 让对手放松警惕，长期有利
? 成交价只取决于对手。压价唯一的效果是把"对手最高价低于你估值"的部分交易白白送走。
```

:::warning[常见误区]

**误区一**："你以为两种密封拍卖策略相同。" 第一价必须压价（付的就是你嘴里的数），第二价必须诚实（你嘴里的数不影响付款）。混淆两者是拍卖实战中最昂贵的错误之一。

**误区二**："你以为'讲真话占优'说明参与者品德高尚。" 与道德无关：这是规则把撒谎的每一种路径都堵死后剩下的唯一解。机制设计追求的正是这种**不依赖人性假设**的稳健。

**误区三**："你以为好机制一劳永逸。" 维克里原文专门警告过"托价"共谋风险；多物品、多轮次、预算约束下的二价拍卖也会出现新的操纵空间。机制设计是一场持续的军备竞赛，广告位拍卖几十年来规则改了一代又一代。

:::

## 6. 练习

**练习 1**：下面的结算器能跑，但把赢家自己的报价当成了成交价——修到通过：

```exercise
# @title: 练习：成交价由别人决定
# @check: 乙
# @check: 70
# @check: -10
# @hint: 二价规则付的是"除赢家外最高的那个报价"。现在 runner_up 直接抄了 top_bid。
valuations = {"甲": 70, "乙": 60, "丙": 40}
bids = {"甲": 70, "乙": 75, "丙": 45}

top_name = ""
top_bid = 0
for name in bids:
    if bids[name] > top_bid:
        top_bid = bids[name]
        top_name = name

runner_up = top_bid            # ← 问题在这：把最高价当成了第二高价
for name in bids:
    if name != top_name and bids[name] > runner_up:
        runner_up = bids[name]

print(top_name)
print(runner_up)
print(valuations[top_name] - runner_up)
```

修好后输出乙、70、-10——虚高报价把自己推进了亏损区。

**练习 2**：若三位玩家全部如实报价，谁赢？付多少？各自的净利是多少？

<details>
<summary>点开查看逐步解答</summary>

全员真话时报价即估值：甲 70 最高，成交价为第二高的 60（乙的报价），净利 $70-60=10$；乙丙不出局也不掏钱，各得 0。对比练习 1 里乙撒谎的结局（甲出局、乙亏 10）：同一批人、同样的估值，**规则面前一句真话就把总福利从 -10 搬到了 +10**。这就是激励兼容的经济学含义：不需要监管抓谎，机制自动奖励诚实。
</details>

**练习 3**：广告位拍卖常被称作"二价的亲戚"。想一想：为什么平台愿意采用"次高价格付费"而不是"价高者全额支付"？

<details>
<summary>点开查看逐步解答</summary>

三点动机：(1) 诚实出价让广告主不必花精力研究彼此、只需表达真实价值，长期留在平台；(2) 结算价反映市场对曝光机会的普遍定价，波动更平滑；(3) 全额支付的博弈会诱导复杂的压价博弈与试探循环，平台反而难以预测收入。当然真实系统（广义二价拍卖 GSP）处理多个广告位时只是"近似激励兼容"——这是教科书结论进入现实后的第一道裂缝，也是机制设计研究至今活跃的原因。
</details>

## 7. 选读：收入等价定理一句话

<details>
<summary>选读 · 四大基准拍卖为何收入相同</summary>

直觉上英式、荷兰式、第一价、第二价的卖家收入应当天差地别。1981 年的三位经济学家（Myerson、Riley-Samuelson 各自独立）证明了一个惊人的基准结论：若投标者的估值独立同分布、风险中性、人数相同，则四种拍卖给卖家带来的**期望收入完全相等**。

直觉版本：每种规则下，"谁能拿走商品"都由相对实力决定，期望成交价都被压到"第二强的估值"附近——规则改变的是路径与风险分配，不改期望总量。定理的价值在于划定边界：想真正提高收入必须改动前提（吸引更多投标者、利用关联估值、设置保留价……），而不是在同族规则里挑挑拣拣。这也是为什么现代拍卖设计的大戏都演在"改前提"的舞台上——频谱拍卖、组合拍卖、广告位位置折扣，无一例外。

</details>
