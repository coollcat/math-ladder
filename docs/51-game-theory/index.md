## 实战挑战 · 审讯室里的两难

囚徒困境是 20 世纪 50 年代兰德公司研究者设计的经典博弈，后经塔克以"囚徒困境"之名讲遍世界；下面采用中文教材常见的数字版本（**经典题型**，非特定考年考题）。

背景：甲乙两人因涉嫌合伙作案被捕，审讯隔离进行。检察官给出同样的"政策"：

| | 乙：抵赖 | 乙：坦白 |
| --- | --- | --- |
| **甲：抵赖** | 两人各判 1 年 | 甲判 10 年，乙当场释放 |
| **甲：坦白** | 甲当场释放，乙判 10 年 | 两人各判 8 年 |

约定：**收益 = 刑期取负号**（坐牢是损失，数字越大越好：0 好于 −1，−1 好于 −8）。

**(a)** 双方都坦白的总收益是多少？双方都抵赖呢？
**(b)** 甲若偷偷坦白（乙抵赖），收益比守约时变化多少？乙被背叛后，收益比合作时变化多少？（两问都按"后来的收益 − 原来的收益"来算）
**(c)** 用 (b) 的两个数字解释：为什么无论对方怎么选，"坦白"都是占优策略？第一问已示范：

```exercise
# @title: 实战挑战：把困境算成数字
# @check: -16
# @check: -2
# @check: 1
# @check: -9
# @hint: 收益 = 负的刑年。(c) 的两个数分别是 0 - (-1) 与 (-10) - (-1)。
print((-8) + (-8))   # (a) 双坦白的总收益（已示范）
print()              # (a) 双抵赖的总收益
print()              # (b)-1 甲偷坦白比守约多赚多少
print()              # (b)-2 被背叛的乙比合作少赚多少
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 双坦白总收益 $(-8)+(-8) = -16$；双抵赖 $(-1)+(-1) = -2$——集体层面差了整整 14 年牢狱。

**(b)** 甲偷坦白得 0、守约得 −1，收益变化 $0-(-1)=+1$；乙被背叛得 −10、合作本可得 −1，收益变化 $(-10)-(-1)=-9$（负号表示比原来少赚 9）。

**(c)** 把 (b) 写成通用判断：给定乙任何选择，甲改判"坦白"要么多赚 1（乙抵赖时），要么持平（乙也坦白时）——**从不吃亏**。对乙同理。于是双双坦白是各自理性的唯一稳定点（纳什均衡），尽管它比双双抵赖差得多。

这就是囚徒困境的全部张力：**个人每一步都算对了，合起来却输掉了 14 年**。出路不在说服谁高尚，而在改变结构——把博弈重复起来、让未来的影子生效（见 [重复博弈与合作](./30-repeated-games.md)），或者干脆由机制设计者改写规则（见 [拍卖与机制设计初见](./40-auction-mechanism.md)）。
</details>

## 实战挑战 · 占优策略的判断方向

占优策略：不管对手出什么，它都严格更好。玩家 A 的收益矩阵 $A=\begin{pmatrix}3&0\\5&1\end{pmatrix}$（行 0=合作、行 1=背叛），背叛在每一列都大于合作，是占优策略。下面这题把"更好"当成了"不占优"，修到输出 `True`：

```exercise
# @title: 实战挑战：占优策略的判断方向
# @check: True
# @hint: 若背叛在某列"更好"，占优成立；应检查的是"背叛是否不更优"。
A = [[3, 0], [5, 1]]    # A 的收益：行=自己的策略，列=对方策略

dominates = True
for j in range(2):
    if A[1][j] > A[0][j]:    # ← 问题在这：把"更好"当成了"不占优"
        dominates = False
print(dominates)
```

<details>
<summary>点开查看逐步解答</summary>

占优要检查"是否存在某列背叛**不更优**"：

```python
if A[1][j] <= A[0][j]:    # 背叛 ≤ 合作 才说明不占优
    dominates = False
print(dominates)          # True
```

改完：第 0 列 $5 > 3$、第 1 列 $1 > 0$，背叛在每列都严格更好，`dominates` 保持 `True`。初始代码把"背叛更好"误判成"不占优"，第一列就翻车。占优策略是博弈论最稳的入场券：一旦存在，理性玩家无需猜测对手——这正是纳什均衡最简单的情形。

</details>
