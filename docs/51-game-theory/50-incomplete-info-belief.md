# 不完全信息与信念更新

## 1. 从一个场景开始

德州扑克的单挑局。对面那位玩家突然把整摞筹码推了进来——悍跳全下。你手里是一副中等偏上的牌，弃，还是跟？

前一课的[拍卖与机制设计初见](./40-auction-mechanism.md)已经点破过现实的一角：广告主互相不知道对方的估值。[纳什均衡](./20-nash-equilibrium.md)那套配平概率的手艺虽好，却默认了一件事——**双方的收益矩阵人人都看得见**。而此刻你面对的更大空洞是：你连"对面坐的是谁"都不确定。他是九死一生才肯出重手的紧凶型？还是三分钟不诈一次就手痒的松浪型？

这一类"有人知道、有人不知道"的对局叫**不完全信息博弈**，是博弈论的常态而非例外。好消息是，第 36 章的[条件概率、独立性与贝叶斯](../36-probability-advanced/20-bayes.md)早已替你备好了唯一的钥匙——本课要做的，是把这把钥匙插进策略互动的锁孔里：**当你推理的时候，对方也在推理你**。

## 2. 直觉解释

把不确定性拆成三层：

- **类型**：对方抽到的"底牌人设"。他自己看得见，你看不见——它是这场博弈里唯一被藏起来的东西；
- **信号**：你能观测到的一切行动。每一次加注、每一次犹豫，都是他从自己的类型里发出来的电报；
- **信念**：你对各类型可能性的概率配比。每次收到新信号，就用贝叶斯法则重新配一遍重。

拿概率树画出来更直白。先验先把树干劈成两大枝：

```
你是谁？（先验）
├─ 紧凶型  3/4
│    └─ 会悍跳全下的概率  2/3
└─ 松浪型  1/4
     └─ 会悍跳全下的概率  1（他就没怂过）
```

观测到他真的悍跳全下了：把"不悍跳"的那些枝叶整个砍掉，剩下的枝按面积重新归一化——松浪枝从 1/4 涨到了 1/3。再来一次强硬动作？砍第二次，涨到 1/2。**证据不能凭空创造类型，但它会不断搬运枝干的粗细**。

一句话记住本课的心法：在人人都会算计的牌桌上，贝叶斯法则之所以仍然成立，恰恰因为对方也在算——他的最优策略本身就是一份可供更新的证据。

## 3. 正式定义

不完全信息博弈引入三个记号。设类型 $\theta$ 取两个值：松浪或紧凶。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\theta$ | 类型 | 参与者的私人信息（这里是"是什么风格的玩家"） |
| $\pi_0$ | 先验 | 见到任何信号前，你认为对方是某类型的概率 |
| $s$ | 信号 | 能被观测的行动（加注、全下、求职者的证书……） |
| $L_s$ | 似然 | 某个**类型**发出这个信号的概率 $P(s \mid \theta)$ |

看到信号 $s$ 之后，用贝叶斯公式把先验 $\pi_0$ 换成后验 $\pi_1$：

$$\pi_1 = \frac{\pi_0 \cdot P(s \mid \text{松浪})}{\pi_0 \cdot P(s \mid \text{松浪}) + (1-\pi_0) \cdot P(s \mid \text{紧凶})}$$

分母没有魔法：它只是把两种来源的可能性相加、重新归一化，让概率回到 1。

**贝叶斯纳什均衡**一句话版：每个参与者拿着自己类型对应的策略行动，同时用贝叶斯法则给别人的类型维持一套信念；给定这套信念，**没有任何人想单方面改招**。策略与信念互相咬合——这正是"他算的时候也在算你"的形式化。

与混合策略课的血缘一目了然：那里随机的是**动作**，这里随机的是**身份**；两次都是让对方的推断落进同一条期望收益的算式。

## 4. 分步例题

设定（教学简化：把"牌力强弱"折进类型的收益里，专心看信念怎么走）。对手二选一：紧凶型占先验 $3/4$，松浪型占 $1/4$。信号 $s_1$ = "悍跳全下"，其似然为 $P(s_1 \mid \text{松浪}) = 1$、$P(s_1 \mid \text{紧凶}) = 2/3$（紧凶型偶尔也演一手诈唬，但他更爱拿真货推）。

1. **列先验**：$\pi_0 = 1/4$（这是松浪型的份额）；
2. **第一次更新**：代入公式，分子 $\frac{1}{4}\times 1 = \frac{1}{4}$，分母 $\frac{1}{4}\times 1 + \frac{3}{4}\times \frac{2}{3} = \frac{3}{4}$，于是 $\pi_1 = \frac{1/4}{3/4} = \frac{1}{3}$。悍跳这个动作确实偏袒松浪型——但似然差不算悬殊，所以只搬动了不多的重量；
3. **第二次更新**：纠缠几手后他又顶住压力再次重注（信号 $s_2$），似然变为 $P(s_2 \mid \text{松浪}) = 1/2$、$P(s_2 \mid \text{紧凶}) = 1/4$。把上一轮的后验当新先验：$\pi_2 = \frac{\frac{1}{3}\cdot\frac{1}{2}}{\frac{1}{3}\cdot\frac{1}{2} + \frac{2}{3}\cdot\frac{1}{4}} = \frac{1/6}{1/3} = \frac{1}{2}$。证据一致时，信念沿似然比一路滚上去；
4. **决策**：池子里已有 40 个筹码，跟注还需再投 10。若对手是松浪型（诈唬居多），跟下这注净得 30；若是紧凶型亮出真家伙，净亏 10。跟注的期望收益是 $\pi_2\times 30 + (1-\pi_2)\times(-10)$，弃牌则稳拿 0；
5. **门槛**：跟注划算的条件是期望收益大于零，即 $30q - 10(1-q) > 0$，解得 $q > 1/4$。第一次更新后的 $q=1/3$ 已经过线，第二次更新后的 $q=1/2$ 更是把结论焊死——**跟**。

注意这笔账里没有一个数依赖"对手人品"：类型只是参数，信念只是账本，决策只是比较。换了数字，机器照样转。

### 实验 2（python）：两轮证据链跑完再决定

```python
title="从先验到跟注：两轮贝叶斯更新"
q = 1 / 4                        # 先验：对面是松浪型的概率
l1_loose = 1                     # 信号一"悍跳全下"在松浪型手里的似然
l1_tight = 2 / 3                 # 同一信号在紧凶型手里的似然
q1 = (l1_loose * q) / ((l1_loose * q) + (l1_tight * (1 - q)))   # 贝叶斯：分子除以两类之和
print("第一轮后验 =", round(q1, 4))        # round：四舍五入保留小数点后 4 位

l2_loose = 1 / 2                 # 信号二"顶住再加"的松浪侧似然
l2_tight = 1 / 4                 # 同一信号的紧凶侧似然
q2 = (l2_loose * q1) / ((l2_loose * q1) + (l2_tight * (1 - q1)))
print("第二轮后验 =", round(q2, 4))

gain_win = 30                    # 跟注并且赢了：净得的池子差额
loss_lose = -10                  # 跟注却输了：付出的跟注额（负号表示亏损）
ev_call = q2 * gain_win + (1 - q2) * loss_lose   # 期望收益：按当前信念加权平均
print("跟注期望 =", round(ev_call, 2))
print("弃牌期望 = 0")
if ev_call > 0:                  # if：条件成立就走下面这支，否则走 else 支
    print("决策: 跟注")
else:
    print("决策: 弃牌")
```

输出与手算严丝合缝：第一轮后验 $0.3333$、第二轮后验 $0.5$、跟注期望 $10.0$、弃牌期望 $0$——决策给出"跟注"。试着把 l2 的两个似然改成相同数值再跑一次：更新失效、后验原地踏步，你会亲眼看到"无差异的信号不含信息"。

### 快问快答

```quiz
某种行动在两种类型手里的发生概率完全相同，这次观察对你的判断有多大影响？
- 让对应的那个后验立刻翻倍
- 毫无影响：似然相同意味着该信号区分不了类型，后验停在先验不动 [*]
- 取决于对方是不是故意做给你看的
? 更新的动力来自似然差。两只勺子舀出来的汤一样多，天平纹丝不动——这也是为什么毫无成本的姿态当不了可靠信号。
```

:::warning[常见误区]

**误区一**："你以为先验随便设设，反正会被证据冲掉。" 小样本下先验举足轻重：要把一个极端先验稀释掉，需要的是似然比的多次方。扑克老手花几百手牌建立"人设"，就是在给自己和对手写先验。

**误区二**："你以为对手知道你在贝叶斯更新，整套方法就作废了。" 恰恰相反。他的策略反过来成为你的新证据——正因为理性玩家"什么样的类型玩什么样的动作"，你的每次观测才带着信息。互洽正是贝叶斯纳什均衡的本义。

**误区三**："你以为信息不对称只能被动挨打。" 你同样可以设计并发出自己的信号：慢打强牌、示弱诱敌、主动摊一次牌换取长期的解读权。信号是一门双向生意的学问，选读段有它的经济学原型。

:::

## 6. 练习

**练习 1**：招聘市场上，简历里主动附上一篇项目复盘文档是个信号。踏实型附文档的概率是 1，话术型只有 1/4；HR 的先验是踏实型 2/3。规则：踏实的把握不低于八成才给面试机会。下面的代码能跑，但两个似然站错了岗——修到通过：

```exercise
# @title: 练习：简历附页背后的信念更新
# @check: 89
# @check: 给面试机会
# @hint: 贝叶斯分子的似然要用"目标类型（踏实型）"的那份：P(文档|踏实)=1、P(文档|话术)=1/4。现在两者放反了位置。
prior_q = 2 / 3                        # 先验：候选人是踏实型的概率
l_doc_good = 1                         # 踏实型会附上复盘文档的概率
l_doc_bad = 1 / 4                      # 话术型也会这么包装的概率

posterior = (l_doc_bad * prior_q) / ((l_doc_bad * prior_q) + (l_doc_good * (1 - prior_q)))   # ← 问题在这：两个似然互相站错了岗
pct = int(round(posterior * 100))      # int(...)：取整数部分；先 round 到个位防 89.9999
print(pct)

if pct >= 80:
    verdict = "给面试机会"
else:
    verdict = "先进备选池"
print(verdict)
```

修好后输出 89 和"给面试机会"。对照运行错误版本时的 33："似然抄串行"能让评估结果整整颠倒过来——招聘官和扑克玩家犯的是同一种病。

**练习 2**：这位候选人在追问环节又贡献了一个信号："细节对答如流"，已知 $P(\text{对答如流} \mid \text{踏实}) = 1/2$、$P(\text{对答如流} \mid \text{话术}) = 1/5$。请在 89 的基础上接着往下算，并判断名额归属。

<details>
<summary>点开查看逐步解答</summary>

把百分比翻成记账方便的赔率形式：修正版的先验赔率是 $(2/3):(1/3) = 2:1$，吃过第一个文档信号后变成 $2\times(1/(1/4)) = 8:1$。第二个信号的似然比是 $(1/2)/(1/5) = 5/2$，于是新赔率 $8\times 5/2 = 20:1$，后验 $= 20/21 \approx 0.952$，远超八成线——**面试机会，而且是抢着给的那种**。这就是陪率法的优雅之处：不用每次都写完整分数，只做乘法。
</details>

## 7. 选读：从信念均衡到信号的世界

<details>
<summary>选读 · 海萨尼转换、精炼与斯宾塞的教育信号</summary>

海萨尼 1967 年给出的处理办法干净利落：请出一位虚拟的"自然"玩家，在开局先偷偷抽取每个人的类型再发牌。于是**所有博弈都变回了完全信息博弈**——只不过有一部分是"自然对私人保密"的。在这个框架下求出的均衡要求策略与信念互洽；当同一局面存在多套互洽的信念时（理论并不禁止），还需要额外的精炼标准来筛选"讲道理"的那个——这是今天研究前沿仍在打磨的领域。

信号经济学的原型来自斯宾塞 1973 年的教育市场模型：能力高的人拿文凭更轻松（成本更低），于是"愿意为文凭吃苦"本身成了能分离类型的可靠信号。反过来看本课的纪律就有了价格：**没有成本差的信号一文不值**——话术型要是也能零成本秀出复盘文档，HR 就会把这份文档连同整个信号系统一起扔掉。拍卖场上的每一次抬价也是一枚信号，竞拍者实时做着本课的更新运算；信息的好处与"赢家诅咒"的危险都在那条曲线上。

</details>
