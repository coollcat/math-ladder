# 注意力之外：线性 RNN、状态空间与 RWKV

## 1. 从一个场景开始

[KV cache 那一课](./90-kv-cache-inference-cost.md)算过一笔账：注意力的计算量随序列长度**平方**增长，因为每个新 token 都要回头和全部历史各算一次相似度。上下文 1 万 token 时还能忍，到了百万 token——一次前向传播要处理 $10^{12}$ 量级的配对关系，显存先投降。

而另一边，[RNN 那一课](../46-deep-learning/60-rnn-lstm.md)留下的教训是：循环结构天然只要 $O(T)$——每来一个新 token，只更新一次隐状态，成本与长度无关。它输给注意力，输在**训练时无法并行**与**长程记忆会衰减**这两件事上。

于是有了一条看起来像倒退的思路：能不能把循环捡回来，但让它**好训练**、**记得住**？这一课讲这条线的数学骨架，以及它如何一路走到 S4、Mamba 与 RWKV。这不是「谁取代谁」的站队题，而是一道清晰的交换题：**用什么数学，换来了什么复杂度**。

## 2. 直觉解释

想象一排**漏水的桶**。每个桶有自己的漏洞大小：漏得快的桶几步就空了（只记得最近的事），漏得慢的桶能存很久（记得遥远的事）。新信息进来时先倒进所有桶，每过一步所有桶同时漏掉一部分。

这就是线性循环的全部机制：一组带各自衰减率的记忆格。它比 LSTM 的门简单得多——没有“要不要忘”的判断，只剩“按多大比例漏”。看似简陋，但当格子的数量够多、衰减率各不相同时，这一排桶能同时记住毫秒级和分钟级的模式。

真正难的不是这个递推（它简单得可疑），而是**训练**。深度学习靠梯度下降，而梯度下降希望一次喂一大批样本并行算。朴素循环必须一步一步串行，这正是当年 RNN 难以和注意力竞争的关键原因。于是工程智慧集中到一个问题：**怎样在不改变模型结果的前提下，把沿时间轴的串行依赖重写成可并行计算的形式？**

如果递推矩阵不随 token 改变，它就是**线性时不变**系统（LTI）：输出可以展开成输入序列与一个固定核的卷积。用 FFT 算卷积是 $O(T\log T)$；用并行扫描也能把串行深度压到 $O(\log T)$，而总工作量仍是 $O(T)$。一旦衰减、输入矩阵或读出矩阵随 token 改变，系统就变成**线性时变**，固定卷积核不再适用，需要 selective scan 之类的新算法。

## 3. 正式定义

**状态空间模型**（SSM）：维护一个隐状态 $h_t$，每步先按矩阵 $\bar A$ 衰减、再混入新输入：

$$h_t=\bar A\,h_{t-1}+\bar B\,x_t,\qquad y_t=C\,h_t$$

其中 $h_t\in\mathbb{R}^{D}$ 是固定大小的状态向量——**这是与注意力最本质的区别**：注意力保存全部历史（$T$ 个键值对），SSM 只保存一个定长摘要。

**对角形式**是最常用也最好算的特例：取 $\bar A=\operatorname{diag}(a_1,\dots,a_D)$，各通道解耦成独立的标量递推：

$$h^{(d)}_t=a_d\,h^{(d)}_{t-1}+b^{(d)}_t$$

每个通道就是一节「衰减 + 输入」的漏桶，衰减因子 $a_d\in(0,1)$ 决定这一格的记忆长度：$|a_d|$ 越接近 1 记得越久，越接近 0 忘得越快。

**记忆的半衰期**：若只给一个脉冲输入（$x_1=1$，之后全 0），第 $t$ 步的状态是 $a^{\,t-1}$。令它衰减到一半，解出步数：

$$t_{1/2}=\frac{\ln 0.5}{\ln a}$$

$a=0.9$ 时半衰期约 6.6 步，$a=0.99$ 时约 69 步，$a=0.5$ 时只有 1 步。一排不同 $a$ 的桶，就是一组不同时间尺度的记忆。

**复杂度的交换**：对时不变的线性递推，训练侧可以用 FFT 卷积 $O(T\log T)$，或用并行扫描降低串行深度；推理侧每生成一个 token 只做一次状态更新，额外时间是 $O(1)$。注意力训练要形成 $T\times T$ 的配对关系，朴素实现是 $O(T^2)$；推理每步要读取长度 $T$ 的 KV cache。**线性模型用“固定大小、可能丢信息的状态摘要”换来了便宜推理**——摘要丢掉的信息回不来，这是这笔交换的代价，不是免费的午餐。

## 4. 分步例题

取二维对角 SSM：$\bar A=\operatorname{diag}(0.9,\,0.5)$，$\bar B=(1,1)^{\mathsf T}$，$C=(1,1)$。输入一个脉冲 $x_1=1$，之后全 0。逐步算：

**第 1 步**：$h_1=(0.9\cdot0+1,\ 0.5\cdot0+1)=(1,\ 1)$，输出 $y_1=1+1=2$。

**第 2 步**：$h_2=(0.9\cdot1,\ 0.5\cdot1)=(0.9,\ 0.5)$，$y_2=1.4$。

**第 3 步**：$h_3=(0.81,\ 0.25)$，$y_3=1.06$。

注意两条通道的分岔：慢通道（$a=0.9$）三步后还剩 0.81，快通道（$a=0.5$）只剩 0.25。同一个脉冲，两格记忆以不同速度遗忘，输出 $y_t$ 是它们之和——一个先快后慢的衰减曲线。若把 $C$ 改成 $(1,-1)$，输出变成两通道之差，形状立刻不同：**同样的记忆格，不同的读出方式，得到不同的时间响应**。这是线性模型表达力的来源，也是它「线性却不太弱」的原因。

## 5. 动手实验

### 实验 1（lab）：完整 KV、固定状态与 RWKV 门控的记忆赛跑

```lab
{
  "type": "rwkv-memory-runner",
  "title": "同一段历史，三种记忆方式：谁还能精确取回“金额”？",
  "decay": 0.82,
  "boost": 2.4
}
```

五幕把抽象的状态压缩变成可比较的三排权重：完整 KV 为每个 token 保留一张精确卡；固定状态按 $a^{\text{age}}$ 衰减；RWKV 风格再用内容门控提高关键 token 的保留率。拖动“每步保留率”和“关键 token 加成”，观察记忆从最近几步滑向更远处时怎样变淡。画面也会强调边界：**权重高不等于摘要可读**，固定状态擅长携带总体语境，不保证精确检索。这正解释了为什么现实中会出现“线性层 + 少量注意力层”的混合架构。

### 实验 2（python）：半衰期就是记忆长度

把 §4 的单通道案例交给滑块。拖 decay 看「半衰期步数」怎么变——衰减因子从 0.5 挪到 0.99，半衰期从 1 步跳到几十步：

```python title="对角 SSM 单通道：脉冲响应与半衰期"
# sliders: decay=0.9 [0.30:0.99:0.01]
d = decay                 # 衰减因子 a：每步保留多少记忆
seq = [1, 0, 0, 0, 0]     # 一个脉冲进来，之后全零
h = 0.0                   # 隐状态（标量版的一格漏桶）
ys = []
for x in seq:
    h = d * h + x         # 线性状态更新：先衰减，再进新输入
    ys.append(round(h, 3))
print("脉冲响应", ys)

h = 1.0                   # 换算半衰期：从 1 衰减到 0.5 要几步
steps = 0
for i in range(1000):
    if h <= 0.5:
        break
    h = d * h
    steps = steps + 1
print("半衰期步数", steps)
```

decay=0.9 时脉冲响应是 `1.0, 0.9, 0.81, 0.729, 0.656`，半衰期 7 步；拖到 0.5 则是 `1.0, 0.5, 0.25, 0.125, 0.062`，半衰期 1 步——几乎立刻忘光。把 decay 拖过 0.9 再看半衰期的**非线性跳变**：0.9→7 步，0.95→14 步，0.99→69 步。这就是为什么现代线性模型要给每个通道配一组精心设计的衰减率，而不是全都取同一个值。

### 快问快答

- **线性模型训练时真的不用串行吗？** 不用。把递推逐步展开会发现每步输出都能写成「输入序列与一个固定核的卷积」，卷积可以一次算完——这正是 S4 路线的核心发现。
- **那推理呢？** 生成时每个新 token 都依赖上一步的输出，这一步天然串行。但每步只更新一次状态，$O(1)$，不像注意力要回看全部历史。

:::warning[常见误区]

- **「线性 = 表达力弱」**：不对。单个通道确实只是一格漏桶，但 $D$ 个通道配不同衰减率、再经 $C$ 线性组合，能合成相当丰富的时间响应（§4 已见分岔）。弱的是「单通道」，不是「线性」。
- **「可并行训练 = 可并行推理」**：两回事。训练的并行靠的是把递推**重写成卷积/扫描**这种可一次性计算的等价形式；推理的生成过程本质串行。混为一谈会误以为线性模型推理也能并行提速。
- **「RWKV 就是去掉注意力的 Transformer」**：不准确。RWKV 把注意力改写成**带位置衰减的加权求和递推**（WKV），相当于给注意力做了一个线性化的重写——它保留了「按相关性加权历史」的思想，只是把计算顺序换成了可递推的形式。删掉注意力容易，能并行训练又 $O(T)$ 推理才是难点。
- **「状态固定大小 = 一定省钱」**：只对了一半。省的是计算与 KV cache，但**摘要是有损的**。任务若需要精确检索远处细节（「文档里第 3 行写的是哪个数字」），固定摘要可能力不从心；这正是混合架构（几层注意力 + 多层线性循环）出现的动机。

:::

概念题：

```quiz
线性循环模型推理时能做到每步 O(1)，根本原因是哪一条？
- 它把整段历史压缩成一个固定大小的状态向量，新 token 只需更新这个向量 [*]
- 它把序列切成了很多小段分别处理
- 它的矩阵比注意力的小
? 固定大小的隐状态是关键：无论历史多长，摘要始终是同一个小向量，每步只做一次线性更新。注意力保存的是全部历史的键值对，每来一个新 token 都要与全部历史配对，成本随长度增长。切小段是另一类做法（分块注意力的思路），矩阵大小与成本没有必然关系。
```

## 7. 选读：三条路线的数学分岔

三条路线共享 §3 的骨架，分歧在「怎么让 $\bar A,\bar B,\bar C$ 变得有用」：

- **S4（2021）**：把状态矩阵约束成**对角加低秩修正**的结构，使递推可以改写成固定卷积核，并由 FFT 高效计算。它展示了“强结构约束 + 好的参数化”可以在长序列上兼顾效果与速度，但并不是“任意约束都不损失表达力”的普遍定理。代价是系统仍以时不变为主，遇到内容决定记忆方式的任务不够灵活。
- **Mamba（2023）**：把步长 $\Delta_t$、输入矩阵 $B_t$ 与读出矩阵 $C_t$ 都做成输入相关。离散化后

$$\bar A_t=\exp(\Delta_t A),\qquad \bar B_t\approx \Delta_t B_t,$$

所以衰减本身也逐 token 变化：模型可以“看到重要的就多记、看到冗余的就多忘”。代价是固定卷积核失效，改用 selective scan 保住训练并行度。
- **RWKV（2022 起）**：走的是注意力线性化路线。最核心的 WKV 状态可以抽象成“按位置衰减的加权记忆”：

$$S_t=a_t\odot S_{t-1}+b_t\odot x_t,\qquad y_t=c_t^{\mathsf T}S_t.$$

早期版本的 $a_t$ 主要由固定时间衰减 $e^{-w}$ 给出，后续版本加入 token shift、动态门控与矩阵状态，使“记什么、记多久、怎样读出”更依赖当前内容。它和 SSM 共享“固定状态递推”的计算外形，但参数化与训练核来自注意力视角，不是 S4 的一个小变体。

三条路线应这样比较：

| 路线 | 状态怎样变化 | 训练怎样并行 | 主要代价 |
| --- | --- | --- | --- |
| S4 | 结构化、时不变衰减 | 固定核卷积 / FFT | 对内容变化不够敏感 |
| Mamba | 输入相关的选择性衰减 | selective scan | 实现复杂，状态仍是有损摘要 |
| RWKV | 注意力式衰减记忆 + 门控 | 并行前缀核 / 分块计算 | 近似与数值稳定性更复杂 |

共同点不是“同一套矩阵约束”，而是都试图把**随历史增长的精确回看**压缩成**固定大小但可训练的状态更新**。
