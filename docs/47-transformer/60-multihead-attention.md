# 多头注意力的子空间分工

## 1. 从一个场景开始

读一句话「小猫跳上桌子打翻了花瓶」——你需要同时记住好几件事："谁跳"是句法关系，"跳上桌子"要看紧邻搭配，"打翻了花瓶"的主语隔着几个词还得找回来。一次注意力会议只有一个打分口径，很难样样兼顾。

上一课的选读埋了伏笔：与其办一场大会，不如**把$d$维空间切成几份，同时开几桌小会**——每一桌（每一个"头"）专注一种关系，散会后把各桌笔记拼回一本总账。这一课把这笔账算清：空间怎么切、各桌怎么分工、拼回去时参数如何不涨。

## 2. 直觉解释

一家编辑部审一篇稿子：

- 只派一位全能编辑，他要在语法、事实、文笔之间来回切换，哪个都看得不深；
- 主编换了个思路：派三位**专职编辑**并行审稿——语法编辑盯着相邻词语搭不搭，事实编辑核对远处的指代与出处，文体编辑专扫罕见词与修辞——每人只在稿件的一页上圈画（子空间），互不打扰；
- 最后主编把三份批注**并排放在一起**（拼接），再做一次综合裁定（线性融合）定稿。

实践观察（把训好的模型的各头注意力图画出来看）发现那些"头"确实自发长了性格：有的几乎只看相邻几个词（受第 50 课位置编码影响的**局部位置头**），有的专门追踪长距离指代，有的对齐句中的罕见词——没有人手工规定分工，是训练逼出来的自然分化。

## 3. 正式定义

对同一个输入 $X$，先用$h$组小矩阵把它投进$h$个低维子空间（每组维度 $d_k = d_{model}/h$），各组独立跑全套自注意力，再拼接融合：

$$\text{head}_i = \text{Attention}\!\left(QW_i^{Q},\ KW_i^{K},\ VW_i^{V}\right)\qquad \text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\,W_O$$

| 符号 | 形状 | 含义 |
| --- | --- | --- |
| $W_i^{Q},W_i^{K}$ | $d_{model}\times d_k$ | 第$i$头的投影：把$d$维坐标搬进自己的小房间 |
| $W_i^{V}$ | $d_{model}\times d_k$ | 第$i$头的价值投影；本课取 $d_v=d_k=d_{model}/h$ |
| $\text{head}_i$ | $n\times d_k$ | 第$i$头的输出：一桌小会的会议纪要 |
| $\text{Concat}$ | $n\times(d_h\cdot h)$ | 把$h$份纪要**横向并排**放，不做任何运算 |
| $W_O$ | $(d_h\cdot h)\times d_{model}$ | 输出融合层：学着把各头贡献重新混回$d$维 |

**参数账**：每头三块投影共 $3d\times d_h$，$h$ 头合计 $3d^2$；加上融合层 $d\times d$ 总计 $4d^2$——与"一大桌单头注意力"的四块矩阵 $4d^2$ 完全持平。**切多桌不涨账**：花的钱一样，买到的关系种类更多。

## 4. 分步例题

**例**：句子「猫 追 球」（沿用上一课的角色表）。$d_{model}=4$，$h=2$，每头 $d_h=2$。

1. 切分：把每个词的 4 维向量切成前后两半——前两维是"谁的动作"子空间（头 1 的地盘），后两维是"语序位置"子空间（头 2 的地盘）；
2. 头 1 打分：它的缩放分数恰好是上一课的 $(6,2,4)\div 2=(3,1,2)$，配比算过：$(0.665,\ 0.090,\ 0.245)$——这一头在看施动关系，注意力集中在"猫"身上；
3. 头 2 打分：缩放分数为 $(0.0,\ 2.0,\ 0.5)$，指数 $(1.000,\ 7.389,\ 1.649)$，归一化配比 $(0.100,\ 0.736,\ 0.164)$——这一头把票集中押给了居中的"追"，在核对词序节奏；
4. 各头加权自己的价值表：头 1 沿用上一课的 $V=\ [(1,2),(0,1),(3,0)]$ 得输出 $(1.400,\ 1.420)$；头 2 的价值表换成 $\ [(0,1),(2,1),(1,0)]$，输出 $0.100\,(0,1)+0.736\,(2,1)+0.164\,(1,0)=(1.636,\ 0.836)$；
5. 拼接：并排成 4 维 $(1.400,\ 1.420,\ 1.636,\ 0.836)$——注意此刻还没完，还要乘 $W_O$ 完成"主编综合裁定"才算这一层的正式输出。

同一个"追"，头 1 看到的是动作链，头 2 看到的是座位表——两份情报拼接后，新表示才既有语义又有语序。

### 实验 2：同一句话，两张完全不同的注意力地图

```python title="两头分工对比：局部位置头 vs 语义配对头"
import math
import matplotlib.pyplot as plt

words = ["小", "猫", "追", "球"]
# 打分矩阵手工贴好（真实模型里由 W_Q/W_K 从数据中学出）
scores_near = [                 # 头 A：几乎只看左右紧邻
    [2.0, 1.5, 0.5, 0.0],
    [1.5, 2.0, 1.5, 0.5],
    [0.5, 1.5, 2.0, 1.5],
    [0.0, 0.5, 1.5, 2.0],
]
scores_pair = [                 # 头 B：专拉远距离的动宾/施受配对
    [2.0, 0.0, 2.5, 0.0],
    [0.0, 1.0, 2.5, 0.0],
    [2.5, 0.0, 2.0, 0.0],
    [0.0, 0.0, 2.5, 2.0],
]

def row_softmax(mat):
    out = []
    for scores in mat:
        m = max(scores)                # 防溢出的减最大值技巧（上一课见过）
        exps = [math.exp(s - m) for s in scores]
        total = sum(exps)
        out.append([e / total for e in exps])
    return out

fig, axes = plt.subplots(1, 2, figsize=(9, 4))    # 一排两张子图
for ax, mat, name in [(axes[0], row_softmax(scores_near), "头A 局部位置"),
                      (axes[1], row_softmax(scores_pair), "头B 语义配对")]:
    ax.imshow(mat, cmap="viridis")                # imshow：二维列表当图像渲染
    ax.set_xticks(range(4)); ax.set_yticks(range(4))
    ax.set_xticklabels(words); ax.set_yticklabels(words)
    ax.set_title(name)

plt.tight_layout()
```

左图的亮块黏在对角线上——每个词主要照看自己和邻居；右图的亮块出现在"小↔追""猫↔追""追↔球"这种跨距配对上。同一句话、同样的输入端，两桌会议交出完全不同的地图，这就是"分工"最直观的样子。

### 快问快答

```quiz
把 d 维切成 h 个头后，投影矩阵的总参数量相比同样预算的单头大会怎样？
- 翻 h 倍
- 大致持平：切分只是换了组织方式，每头矩阵都被等比例缩小 [*]
- 减半
? 每头投影是 d×(d/h)，h 头合计仍是 d×d 量级；再加一块 d×d 融合层，总账与单头方案同为约 4d²，计算量基本不变。
```

:::warning[常见误区]

**误区一**："头越多一定越聪明。"——收益递减明显：常用模型从 8 头到 96 头不等都好用，实践中不少头高度冗余，剪掉一部分性能几乎不掉。

**误区二**："多头拼接完就直接交给下一层。"——还差一次 $W_O$ 融合：拼接只是把各桌笔记**并排摆放**，没有混合；$W_O$ 才是让各头贡献可学习组合的那一笔。

**误区三**："每个头都对应一种干净的语法功能。"——分工是统计倾向而非契约：不少头的功能相互纠缠，还会随训练进程漂移，解读时要谨慎下结论。

:::

## 6. 练习

**练习 1**：上一课说过多头"总算力几乎不变"，现在请你复述这份账：$h$ 头各 $d_h=d/h$ 维投影，加上拼接后的融合层，参数总量是多少？

<details>
<summary>点开查看逐步解答</summary>

每头三块投影 $3\times d\times d_h$，$h$ 头合计 $3d^2$；融合层 $d\times d$ 一块。总计 $4d^2$，与"单头大注意力"（三块 $d\times d$ 投影 + 一块 $d\times d$ 输出层）完全一致。省的不是参数而是**表达的多样性**——同样的钱买了$h$种关系通道。
</details>

**练习 2**：两桌小会的配比请你算齐——重点体会"每头独立归一"：

```exercise
# @title: 练习：两桌小会各自记账
# @check: 0.665
# @check: 0.736
# @check: 1.0
# @hint: 照抄 w1 那行，把参数换成头 2 的分数调用同一个函数。头 2 的配比自己也构成一张完整的概率表——三个数之和应为 1。
import math

scaled_h1 = [3.0, 1.0, 2.0]        # 头 1 的缩放后打分（上一课的结果）
scaled_h2 = [0.0, 2.0, 0.5]        # 头 2 的缩放后打分

def head_weights(scores):
    m = max(scores)                # 减最大值防溢出
    exps = []
    for s in scores:
        exps.append(math.exp(s - m))
    total = sum(exps)
    return [e / total for e in exps]

w1 = head_weights(scaled_h1)
print(round(w1[0], 3))             # 头 1 押给"猫"的份额（已示范）
w2 = [0.0, 0.0, 0.0]               # ← 问题在这：用同一个函数算出头 2 的配比
print(round(w2[1], 3))             # 头 2 押给"追"的份额
print(round(sum(w2), 3))           # 自己这场会议自己的概率表总和
```

**练习 3**：概念题——如果把"h 个头"理解成"h 个评审"，为什么最后还要乘 $W_O$，而不是把各头输出取平均？

<details>
<summary>点开查看逐步解答</summary>

平均相当于固定等权混合，等于宣布每桌会议同等重要。而 $W_O$ 是可学习的：模型可以学会"这个头看指代很靠谱给它高权重、那个头当前语境帮不上忙就压低"，甚至让各头在不同维度上的贡献错峰互补。不学权重的等权平均浪费了"分头"的价值。
</details>

## 7. 选读：头们到底学会了什么？

<details>
<summary>选读 · 分工观察的正确打开方式</summary>

研究者常用的三招：①按注意力熵排序——低熵头往往锁定极少数固定位移（典型位置头），高熵头负责"广泛传阅"；②按互斥关键词过滤——找出对 rare token、引号、句号的反应异常强的头；③剪枝回归测试——逐个关头看整体性能掉不掉。结论很有趣：语言结构与语言学没有一一对应，工程师眼里它们更像一组**可互换的功能组件**，总之"分工自发涌现、个体并不神圣"。
</details>
