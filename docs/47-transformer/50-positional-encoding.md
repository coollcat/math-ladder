# 位置编码

## 1. 从一个场景开始

「狗咬人」是新闻，「人咬狗」也是新闻——但显然不是同一条。上一课结尾留了个致命盲区：自注意力对输入的**排列完全无感**，把句子词序打乱重算，打分表纹丝不动。可语言的意义恰恰长在顺序里。

补救思路直白：给每个位置发一张**座位号卡片**，加到词向量上，让模型"看得见"谁坐在哪。问题是怎么设计这张卡片——要唯一、要有远近感、还不能破坏并行计算。

## 2. 直觉解释

最土的方案是直接写位置编号：位置 0 记 $(0)$、位置 1 记 $(1)$……缺点致命：第 500 号比第 499 号"大很多"，模型会误以为数值大小有意义，而且推理时遇到没见过的超大编号就抓瞎。

Transformer 论文的方案是**正弦波时钟**：

- 每个维度是一条不同波长的正弦/余弦波；
- 短波维度像秒针：相邻位置相位差明显，负责精细区分近邻；
- 长波维度像时针：几十步之内几乎不变，负责粗定位大范围；
- 合起来，任意位置都有一组独一无二的相位读数——就像"3 点 45 分 12 秒"唯一对应一个时刻。

更妙的是正弦的旋转性质：位置 $pos + k$ 的编码是位置 $pos$ 编码的某个固定旋转（选读给出理由），于是"相对位移 $k$"变成了线性操作，模型学相对关系比学绝对门牌容易得多。

## 3. 正式定义

位置 $pos$、维度对 $i$ 的编码（$d$ 为词向量维数）：

$$PE(pos, 2i) = \sin\!\left( \frac{pos}{10000^{2i/d}} \right) \qquad PE(pos, 2i+1) = \cos\!\left( \frac{pos}{10000^{2i/d}} \right)$$

最终输入为 $\vec x_{pos} + PE(pos, \cdot)$——**逐元素相加**，不是拼接。

| 性质 | 解释 |
| --- | --- |
| 有界 | 取值永远在 $[-1, 1]$，不会随位置数膨胀 |
| 唯一 | 不同位置的完整向量互不相同 |
| 波长几何级数 | 从 $2\pi$ 到约 $10000 \times 2\pi$，短波管细节、长波管大局 |
| 相对性 | 固定偏移 $k$ 对应一个与 $pos$ 无关的线性变换（选读） |

## 4. 分步例题

**例**：迷你版只用两个维度：维度 0 用波长 $2\pi$ 的 $\sin$，维度 1 用波长 $8\pi$ 的 $\sin$（即 $PE(pos) = (\sin(pos),\ \sin(pos/4))$）。

1. 位置 0：$(\sin 0,\ \sin 0) = (0,\ 0)$；
2. 位置 1：$(\sin 1,\ \sin 0.25) \approx (0.841,\ 0.247)$；
3. 位置 2：$(\sin 2,\ \sin 0.5) \approx (0.909,\ 0.479)$；
4. 观察：短波维从 0.841 跳到 0.909（变化快，能区分近邻），长波维只从 0.247 挪到 0.479 的四分之一节奏（变化慢，编码大势）。两组读数组合，每个位置都有独特指纹。

横轴是位置，纵轴是编码值。波长 $w=1$ 时相邻位置读数剧烈跳变（秒针）；$w=20$ 时曲线平缓如缓坡（时针）。真实模型让几十条这样的波按几何级数排开，同时拥有所有刻度。

### 实验 2：画出完整的编码指纹图

```python title="正弦位置编码矩阵热力图"
import math
import matplotlib.pyplot as plt

D = 16                    # 维度总数
POS = 40                  # 句子最长位置数
pe = []                   # pe[pos] 是位置 pos 的编码行
for pos in range(POS):
    row = []
    for i in range(D):
        wl = 10000 ** ((i // 2) * 2 / D)   # //：整除；波长按几何级数增长
        if i % 2 == 0:
            row.append(math.sin(pos / wl))
        else:
            row.append(math.cos(pos / wl))
    pe.append(row)

plt.imshow(pe, cmap="viridis", aspect="auto")
plt.colorbar(label="value")
plt.xlabel("dimension")
plt.ylabel("position")
```

这张条纹图是 Transformer 论文里的名场面：左侧高频条纹快速闪烁，右侧低频条纹缓慢流动。每一**横行**是一个位置的独有指纹；相邻两横行图案相似但相位微移——远近感就藏在这微移里。

### 快问快答

```quiz
把「我爱数学」三个词的嵌入向量直接相加作为句子的表示，词序信息会怎样？
- 自动保留在求和结果里
- 完全丢失：加法交换律保证任何顺序的和相同 [*]
- 部分保留
? 加法与顺序无关，纯词袋表示天然排列不变。注意力打分同样如此，所以必须外挂位置信息。
```

:::warning[常见误区]

**误区一**："位置编码和词向量拼接成长向量。"——原始论文是**逐元素相加**：两者维度相同、直接叠加。拼接会瞬间翻倍维度并增加参数，后来的变体才偶尔采用。

**误区二**："正弦编码必须配固定权重。"——它只是初始化方案之一；BERT/GPT 系多用**可学习的位置嵌入**（一张普通查表），效果相当。近年 RoPE（旋转位置编码）把相对位置做进注意力的打分环节，成为主流大模型的标配。

**误区三**："位置信息让模型知道'第几句话'。"——标准编码只区分 token 序列内的位置，文档级结构（段落、章节）需要额外手段（分隔符或分段编码）。

:::

## 6. 练习

**练习 1**：为什么位置编号不适合直接当编码？至少给出两条理由。

<details>
<summary>点开查看逐步解答</summary>

①数值无界且随文本长度膨胀，与有界的词向量叠加后尺度失衡；②模型会把编号差误当语义距离（位置 10 与位置 11 的"距离"未必该等于 20 与 21 的）；③外推灾难：训练最长 512，推理来一篇 1024 长文，超出范围的编号从没见过。
</details>

**练习 2**：亲手生成两行的编码指纹并确认它们不同：

```exercise
# @title: 练习：生成位置指纹
# @check: 0.841
# @check: 0.479
# @check: True
# @hint: 第二处照抄第一处，把下标换成 [2][1]。sin 的参数是 pos / scale，和正文的迷你版一样取 1 与 4。
import math   # math.sin 已在第 7 章登场

positions = [0, 1, 2]
scales = [1.0, 4.0]              # 正弦内部除数：对应 sin(pos) 和 sin(pos/4)

pe = []                          # pe[位置][维度]
for pos in positions:
    row = []
    for scale in scales:
        row.append(math.sin(pos / scale))
    pe.append(row)

print(round(pe[1][0], 3))        # 位置 1、维度 0（已示范）
print(0)                         # ← 问题在这：位置 2、维度 1 的值（保留三位小数）
print(pe[1] != pe[2])            # 两行指纹必然不同
```

**练习 3**：概念题——把一句话的两个词互换位置后再做自注意力，哪些量变了、哪些没变？

<details>
<summary>点开查看逐步解答</summary>

不加位置编码时全部不变（排列不变性）；加上位置编码后，每个位置的输入向量变了 → q/k/v 全变 → 打分表与输出表示全变。位置编码的作用正是把"顺序"注入这套原本盲视顺序的运算。
</details>

## 7. 选读：相对位置的旋转表达

<details>
<summary>选读 · RoPE 的一句话直觉</summary>

把二维词向量看成复数乘 $\cos\theta + i\sin\theta$（第 12 章的老朋友）：给位置 $pos$ 的查询乘上角度 $\theta \cdot pos$ 的旋转，则两个位置的点积自动只依赖**角度差** $\theta(pos - k)$——绝对位置被消去，相对位移浮出水面。这就是 RoPE（旋转位置编码）的核心：不改架构、不添参数，把"座位号"变成"转了多少度"，外推到更长序列也更稳。现代开源大模型几乎清一色采用它。
</details>
