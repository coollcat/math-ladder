# 模仿学习与行为克隆：看一遍，学就会

## 1. 从一个场景开始

想让机器人学会拧瓶盖：强化学习（第 50 章）要试错千万次——真实机器人摔一瓶碎一瓶，仿真器里又学不会真实的手感。可人类师傅示范五遍，五分钟。**模仿学习**（imitation learning）把训练信号从"奖励"换成"示范"：老师做了什么，就学着做什么。其中最朴素的门派叫**行为克隆**（Behavior Cloning，BC）——把示范当成一堆"看到什么 → 该做什么"的标注数据，然后用第 46 章的监督学习照单全收。它简单到近乎天真，也把这一门派的天生陷阱一并带来。

## 2. 直觉解释

BC 的流水线：演示者操作机器人（或手柄遥控），系统录下每一拍的**观察** $o_t$（相机画面、关节角）与**动作** $a_t$；训练一个策略网络 $\pi_\theta$，让它背下这张对照表。训练完，机器人执行 $\pi_\theta(o)$——像被克隆了老师的手。

监督学习的老熟人全数到场：损失是"输出的动作与老师差多少"（回归），优化是梯度下降，泛化靠数据覆盖。但机器人不是静态数据集——**它执行自己的动作，会走到老师从没走过的状态**：方向盘偏了一点，画面就进入示范集里没有的境地，BC 从没学过"怎么回来"，只会把错误放大。这是模仿学习的头号大敌，**分布偏移**（covariate shift），解法在下一拍：DAgger 让老师在机器人自己走出的路上继续批改作业。

## 3. 正式定义

行为克隆的目标函数就是监督回归：

$$\min_{\theta} \sum_{t} \lVert \pi_\theta(o_t) - a_t^{expert} \rVert^2$$

DAgger（Dataset Aggregation）迭代补上"自己走出来的路"：

| 轮 | 做什么 | 收什么 |
| --- | --- | --- |
| 1 | 用示范数据训练 $\pi_\theta$ | 一份"照抄能力" |
| 2 | 让 $\pi_\theta$ 自己执行，老师**旁观**每一步 | 一份"你走歪时该怎么做"的新标注 |
| 3 | 新旧数据合并重训 | 策略在自己会到达的状态上也被教过 |

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $o_t$ | 观察 | 相机画面 / 关节读数等策略的输入 |
| $a_t$ | 动作 | 老师执行的动作（关节速度、末端位移） |
| $\pi_\theta$ | 策略网络 | 从观察到动作的映射 |
| 分布偏移 | covariate shift | 执行态偏离训练分布：BC 一错就进入没学过的境地 |

与第 50 章 RL 对照着记：RL 问"怎么做分最高"（试错 + 奖励），BC 问"老师此刻做了什么"（对照 + 拟合）——**RL 学目标，BC 学影子**。

## 4. 分步例题

最朴素的 BC 策略是**最近邻查表**：示范集三笔账——观察到 $1$ 做动作 $0.5$、观察 $2$ 做 $1.0$、观察 $3$ 做 $1.5$（比如"手离杯子多远就伸多快"）：

1. 新观察 $o = 2.6$：与三笔账的距离是 $1.6$、$0.6$、$0.4$ → 最近邻是 $3$，输出动作 $1.5$；
2. 新观察 $o = 4.0$：跑出了示范集——最近邻仍是 $3$，硬输出 $1.5$；可"正确答案"也许是 $2.0$。BC 不会外推，**示范集的边界就是它的世界边界**；
3. 危险在执行时滚雪球：机器人在 $o = 4.0$ 处按老黄历做了 $1.5$，下一拍可能来到 $5.2$——越走越远的陌生地界，每次都从更错的账本里查表。这就是分布偏移的具象画面，也是 DAgger 要掐灭的火苗。

## 5. 动手实验

### 实验（python）：训一个线性 BC 策略，看它在示范范围内外怎么表现

```python title="行为克隆：拟合示范，然后在示范边界外翻车"
import math
import matplotlib.pyplot as plt

def expert(o):                                   # 老师的真技能（三次曲线，学生不知道）
    return 0.5 * o * o * o

obs = []                                         # 示范数据：观察在 [-1, 1] 内采集
acts = []
for i in range(40):
    o = -1.0 + 2.0 * i / 39
    obs.append(o)
    acts.append(expert(o))

w, b = 0.0, 0.0                                  # 学生策略 pi(o) = w*o + b：一开始什么都不会
lr = 0.1
for epoch in range(300):
    gw = 0.0
    gb = 0.0
    for i in range(len(obs)):
        pred = w * obs[i] + b                    # 学生当前的动作
        err = pred - acts[i]                     # 与老师的差
        gw = gw + err * obs[i]                   # 损失对 w 的梯度（链式法则）
        gb = gb + err
    w = w - lr * gw / len(obs)
    b = b - lr * gb / len(obs)
print("学到的策略: pi(o) =", round(w, 3), "* o +", round(b, 3))

tests = [-0.5, 0.5, 1.5, 2.0]                    # 前两个在示范范围内，后两个在外面
for o in tests:
    print("o =", o, " 学生 =", round(w * o + b, 3), " 老师 =", round(expert(o), 3))

fig, ax = plt.subplots(figsize=(7, 3))
xs = []
for i in range(81):
    xs.append(-2.0 + 4.0 * i / 80)
ax.plot(xs, [expert(x) for x in xs], label="expert")            # 老师的真技能
ax.plot(xs, [w * x + b for x in xs], label="BC student")        # 学生的策略
ax.scatter(obs, acts, s=8, color="#c0392b", zorder=3)           # 示范数据只撒在 [-1,1]
ax.legend()
plt.show()
```

怎么玩：示范范围内学生贴着老师走（三次曲线在 $[-1,1]$ 上被直线近似得有模有样）；一出边界（红点区之外），两条线立刻分道扬镳——学生照着自己的直线走，老师按真实规律走，差得越走越远。**曲线没问题，边界才要命**：把示范采集范围扩大到 $[-2, 2]$（改 `range(40)` 里那行采集区间）再跑，同样的学生立刻表里如一——治分布偏移的第一方子永远是覆盖。真 DAgger 则是把"学生自己走出来的 $o$"交回老师标注，专往这条边界上撒新数据。

```quiz
DAgger 在模仿学习里补的课是？
- 给示范数据加噪声让网络更强壮
- 让专家对"机器人自己执行时到达的状态"也给出标注 [*]
- 把损失函数换成更光滑的版本
? 分布偏移的病灶是"机器人会去的状态没被教过"：DAgger 让策略自己开路、专家随行批改，新数据恰好撒在它会到的地方——对症下药。
```

::::warning[常见误区]

**误区一**："你以为 BC 学的是任务，其实它学的是录像。" 示范里有什么它抄什么：演示者手的影子、遥操作手柄的抖动、相机支架的晃动都会被当成"技能的一部分"。经典翻车是"路虎车模型学会了认草丛里的阴影判断方向"——**因果混淆**：它模仿的是与动作相关的画面偶然特征，不是驾驶本身。清理数据分布、多视角采集、加动作一致性约束，都是在给"影子"断粮。

**误区二**："你以为数据多了就行。" 多而不**覆盖**没有用：一万条同一视角的直线演示，教不会转弯。BC 的泛化半径由示范状态覆盖的"疆域"决定——先想清楚执行时会到哪，再去采哪。

**误区三**："你以为不用奖励就免了 reward shaping 的麻烦。" 奖励没了，示范质量成了新的单点依赖：老师自己都开得歪歪扭扭，学生克隆得惟妙惟肖。工程上常是"BC 先会走、RL 再精修"：克隆出一个及格起点，奖励再从那里往上磨——两个门派从来不是二选一。

::::

## 6. 练习

```exercise
# @title: 练习：最近邻 BC 查表
# @check: 0.5
# @check: 1.0
# @check: 1.0
# @hint: 最近邻取的是"距离最小的示范"——别把 min 写成 max，也别把动作取成了最远那笔的。
demos = [(1.0, 0.5), (2.0, 1.0), (3.0, 1.5)]     # (观察, 老师动作) 的示范账本

tests = [0.2, 1.9, 2.4]                          # 三个新观察

def bc_policy(o):                                # 最近邻行为克隆
    best = demos[0]
    bd = abs(o - best[0])
    for d in demos:
        dist = abs(o - d[0])
        if dist > bd:                            # ← 问题在这：挑成了距离最"大"的示范
            bd = dist
            best = d
    return best[1]

for o in tests:
    print(bc_policy(o))
```

<details>
<summary>点开查看逐步解答</summary>

最近邻要的是**距离最小**：

```python
        if dist < bd:                            # 比当前最近的更近才换
            bd = dist
            best = d
```

修正后：$0.2$ 最近邻是 $1.0$ → 动作 $0.5$；$1.9$ 与 $2.4$ 最近邻都是 $2.0$ → 动作 $1.0$，输出 `0.5 / 1.0 / 1.0`。初始代码用 `>` 挑出了**最远**的示范：$0.2$ 被答成 $1.5$——查表查成了"反查表"。顺带留意 $1.9$ 与 $2.4$ 拿到同一个动作：最近邻策略是**阶梯状**的，示范排得越密，阶梯越细腻；排得稀，动作就一格一格地跳。
</details>

**练习 2**：老师只在 $o \in [0, 1]$ 内示范过，机器人执行时漂到了 $o = 1.6$。最近邻 BC 会怎么做？DAgger 会怎么改这个结局？

<details>
<summary>点开查看逐步解答</summary>

最近邻 BC 拿 $o = 1.0$ 那笔账硬套——不管 $1.6$ 处正确动作是什么，它只会重复边界上的旧答案，而且执行后可能漂得更远（偏移滚雪球）。DAgger 的改法：让 $\pi_\theta$ 继续开，老师**只在旁边标注**"在 $1.6$ 这里我该做 a"——这笔"你会到、但我没演示过"的账入了数据集，下一轮训练的覆盖疆域就含着 $1.6$ 了。一句话：BC 的课都上在示范集里，DAgger 把课补到执行分布里。
</details>

## 7. 选读：从克隆到融合，再到动作生成

BC 与 RL 的现代联姻：**RLHF 式微调**（第 50 章）先克隆出及格策略、再用偏好奖励精修；机器人侧同款流程叫 "BC 先行 + 域内 RL 打磨"，真实机器人上试错成本被压到最低。动作表示也在升级：把动作建模成**扩散去噪**（第 40 课的手艺）而非回归单值，一个观察对应的多条合理动作路径（绕左绕右都行）不再被均成一团糊——Diffusion Policy 因此成为示教技能库的新宠。再往上叠一层语言，就是下一站之后的主角：视觉-语言-动作模型让"把杯子放到水槽边"这种指令直接变成动作序列——示范、指令、奖励三条训练信号，正在汇成同一条河。
