# LQR 回望与 MPC 入门：会看路面的控制器

## 1. 从一个场景开始

仓库物流无人机要穿过一条窄走廊：前方两秒是弯道，拐完还得在限停线前刹住。上一课的计算力矩控制是"走一步看一步"的即时抵消——它对前方的弯道一无所知，等误差冒出来再纠。而第 52 章的 LQR 虽然会算最优增益，却有两个先天设定：系统得先线性化，而且**没有约束**——它敢输出"推力 150%"这种物理上不存在的命令。

把两者各自的短板一次补齐的，是本课主角：**模型预测控制**（MPC，model predictive control）——每一步都对着未来一小段路面解一次最优，还顺手把"走廊宽度""电机上限"这些约束当成交卷规则。

## 2. 直觉解释

先回顾 LQR 的世界观：线性系统、无限时域、代价里"误差平方加控制平方"，解一个代数方程（Riccati），得到一条恒定增益的反馈律 $\tau=-Kx$——一次付清，终身有效。代价是它必须"装瞎"：看不见约束，也懒得管非线性。

MPC 的世界观是开车：

- **预测模型**：给我未来 $N$ 步的候选操作，我能把车况一路推演出去（模型就是计算力矩课里那个被抵消干净的线性替身）；
- **代价函数**：这 $N$ 步里误差吃多少罚、控制费多少油，加总打分；
- **滚动求解**：解出这 $N$ 步里最划算的操作序列，**只执行第一步**，然后窗口前移一步，重新看路、重新求解。

"只执行第一步"是灵魂：世界会偏离预测，与其相信两秒前的计划，不如每步都重新规划——计划赶不上变化，那就让计划本身跟上变化。约束则是白送的：解优化时把"推力不得超过上限""倾角不许超过 $35^\circ$"直接写成边界，控制器就再也不会开出物理上不存在的药方。

## 3. 正式定义

**LQR 回顾**：线性系统 $\dot x=Ax+Bu$，代价 $\int(x^TQx+u^TRu)\,dt$，最优控制 $u=-Kx$，$K$ 由代数 Riccati 方程唯一给出（$Q$ 罚误差、$R$ 罚费油，是工程师手调的两个旋钮）。

**MPC**：每个采样时刻求解有限时域优化

$$\min_{u_0,\dots,u_{N-1}}\ \sum_{k=0}^{N-1}\left(e_k^T Q e_k+u_k^T R u_k\right)$$

满足预测动力学与全部约束，执行 $u_0$ 后窗口滚动。

| 对比项 | LQR | MPC |
| --- | --- | --- |
| 时域 | 无限 | 有限（$N$ 步）+ 滚动 |
| 约束 | 不支持 | 显式写进优化 |
| 在线计算 | 几乎为零（增益离线算好） | 每步解一次优化 |
| 适用 | 线性化点附近巡航 | 有约束、有预知路况的跟踪 |

诚实边界：MPC 的"每步解优化"是真金白银的算力——算力不够或窗口太短，它反而不如 LQR 便宜省心；无约束时大窗口 MPC 的第一步会退化成 LQR 增益，两代本是一家。

## 4. 分步例题

**例**：误差双积分器（把时间步长归一成 $1$）：速度积分控制、位置积分速度。当前 $x=1$、$\dot x=0$。两步窗口、只罚末端与控制：代价 $=x_1^2+x_2^2+u_0^2+u_1^2$。求最优第一步。

1. 推演状态：$x_1=x_0+\dot x_0=1$；$\dot x_1=u_0$；$x_2=x_1+\dot x_1=1+u_0$；
2. $u_1$ 不影响 $x_1,x_2$，纯挨罚 → 最优 $u_1=0$；
3. 代价化简：$J=1+(1+u_0)^2+u_0^2$；
4. 对 $u_0$ 求导取零：$2(1+u_0)+2u_0=0$ → $u_0=-0.5$；
5. 对比只看一步的贪心（最优 $u_0=0$）：MPC 因为看见了 $x_2=1+u_0$，**提前半格刹车**。窗口越长，这种"未卜先知"越接近 LQR 的全局最优。

## 5. 动手实验

例题的代价函数是一条抛物线，谷底恰在 $u_0=-0.5$——"提前刹车"不是玄学，是求导：

### 实验 1（python）：滚动 MPC 仿真——误差每步减半

```python title="两步窗口 MPC：滚动执行第一步"
x, v = 1.0, 0.0                                 # 初始误差 1、误差速度 0（归一化双积分器）
marks = []
for step in range(7):                           # 滚动 7 步
    marks.append(round(x, 3))
    u = -(x + 2 * v) / 2                        # 两步窗口的解析最优：提前刹车那半格
    v = v + u                                   # 模型：速度积分控制
    x = x + v                                   # 模型：位置积分速度
print(f"误差轨迹: {marks}")
```

误差序列 $1,\ 0.5,\ 0.25,\ 0.125,\dots$——每步精确减半。这不是巧合：窗口恒为两步时，"提前刹车"的力度自动与当前状态成正比，滚动 MPC 步步都是同一个最优比例。

### 实验 2（python）：给控制戴上镣铐

```python title="控制上限 0.3：猛刹车自动变匀减速"
limit = 0.3                                     # 控制上限（推力/力矩配额）
x, v = 1.0, 0.0                                 # 同样的初始误差
marks = []
for step in range(7):
    marks.append(round(x, 3))
    u = -(x + 2 * v) / 2                        # 同一个解析解：第一步它想要 -0.5
    u = min(max(u, -limit), limit)              # 关键一步：夹进物理允许的范围
    v = v + u
    x = x + v
print(f"受限误差轨迹: {marks}")
```

第一步无约束解想要 $-0.5$，被夹成 $-0.3$；误差先被匀速拉回，一旦解析解重新落回界内，立刻恢复"每步减半"的节奏。LQR 会理直气壮地输出 $-0.5$ 然后看着执行器撒谎，MPC 把"做不到"写进规则——**约束不是麻烦，是物理**。

## 6. 练习

```exercise
# @title: 练习：两步窗口的最优第一步
# @check: 贪心控制 = 0.0
# @check: MPC 第一步 = -0.5
# @check: 窗口末端误差 = 0.5
# @hint: 两步推演 x2 = x + 2v + u；代价里带 u 的是 x2² + u²，对 u 求导取零得 u = -(x + 2v)/2，只写 -x/2 会漏掉速度那一半。
x, v = 0.8, 0.1                                 # 当前误差与误差速度

u_greedy = 0.0                                  # 贪心：只看一步，控制为零
u_mpc = -x / 2                                  # ← 错误行
x2 = x + 2 * v + u_mpc                          # 窗口末端误差

print(f"贪心控制 = {round(u_greedy, 1)}")
print(f"MPC 第一步 = {round(u_mpc, 1)}")
print(f"窗口末端误差 = {round(x2, 2)}")
```

修好那行（补上 $2v$）：最优第一步 $-0.5$，末端误差压到 $0.5$——速度残存 $0.1$ 说明下一窗口还有活干，滚动起来正是实验 1 的减半节奏。

## 7. 选读：无约束时 MPC 就是 LQR

把约束全部拿走、窗口 $N$ 拉长、系统线性：滚动优化的第一步 $u_0$ 会收敛到 $u=-Kx$，$K$ 正是代数 Riccati 给出的那条增益——MPC 是 LQR 的"有约束、有限视野"推广，LQR 是 MPC 的"无约束、无限视野"极限。工程分工由此清晰：巡航段用 LQR 白嫖算力，进场段（约束多、路况明确）切 MPC 买精度，切换点就是第 52 章与本课的交界。
