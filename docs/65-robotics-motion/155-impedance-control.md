# 力与阻抗控制：给机械臂装上手感

## 1. 从一个场景开始

让机械臂用砂纸打磨一扇曲面木门：位置控制（第 100 课）会把末端死死钉在预设轨迹上——木头凸一点，机械臂硬顶，要么磨穿要么报警；木头凹一点，砂纸悬空空转。人手打磨时做的事完全不同：**手贴着面走，感受到阻力就退让，阻力小了就压紧**——控制的目标根本不是"位置"，而是"手感"。**阻抗控制**（impedance control，Hogan 1985）把这层手感写成数学：不去命令位置，而是命令"位置误差与力的关系"——像给机械臂接上一根虚拟的弹簧加阻尼器。

## 2. 直觉解释

第 52 章的反馈控制问的是"怎么把误差压到零"，可与人、与柔弱物体打交道时，误差**不该**被压到零：推人一把，机械臂该顺从地让开；推一面墙，才该顶住。阻抗控制把末端当成一个**可调软硬的虚拟质量块**：

$$\text{你推它 } \Rightarrow \text{ 它按 } F = m\,\ddot{x} + c\,\dot{x} + k\,(x - x_0) \text{ 退让}$$

三个旋钮对应三种手感：刚度 $k$ 大 = 硬（顶得住，适合精密压装）；阻尼 $c$ 大 = 稳（不颤不晃，适合打磨）；虚拟质量 $m$ 管"多快响应你的推"。调这三个数，同一台机械臂能从"铁棒"变成"手握的铅笔"。

与它对偶的是**导纳控制**（admittance）：测力传感器读到多少力，就反向修改位置指令——"力进门，位置出门"；阻抗则反过来"位置偏差进门，力出门"。刚的机器人用导纳（六维力传感器读得出、位置指令改得动），柔的驱动（串弹关节）用阻抗。本课主线是阻抗，对偶关系记进选读。

## 3. 正式定义

任务空间的阻抗律（一维写法）：

$$F = m\, \ddot{x} + c\, (\dot{x} - \dot{x}_0) + k\, (x - x_0)$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $F$ | 末端受力 | 环境或人施加给机械臂的力 |
| $x_0, \dot{x}_0$ | 虚拟轨迹与速度 | "愿意待"的参考位置——只是参考，不是命令 |
| $k$ | 虚拟刚度 | 偏离参考 1 米要花的力：$k$ 越大越硬 |
| $c$ | 虚拟阻尼 | 速度阻力的系数：消振定音 |
| $m$ | 虚拟质量 | 加速难度：响应灵敏度的旋钮 |

实现上把 $F$ 折算成关节力矩（第 80 课的雅可比转置：$\tau = J^{T} F$），叠进动力学补偿里——位置控制退居二线，只当阻抗律的"执行器"。

## 4. 分步例题

打磨任务：虚拟参考 $x_0 = 0$，刚度 $k = 10$ N/m、阻尼 $c = 2$ N·s/m、$m = 1$。某一瞬环境把末端顶到 $x = 1.2$ 米、速度 $v = 0.5$ m/s：

1. 弹簧项：$k\,(x - x_0) = 10 \times 1.2 = 12$ N——位置偏离的"回弹力"；
2. 阻尼项：$c\,\dot{x} = 2 \times 0.5 = 1$ N——速度相关的"黏滞力"；
3. 合计：$F = 12 + 1 = 13$ N——机械臂以 13 牛的力"顶着"当前位形；环境要让它退让，就得压过这笔账；
4. 换手感：把刚度调到 $k = 20$，同样的偏差回弹 24 N——末端"硬"了一倍，压装零件时更顶得住，打磨时则容易顶伤表面。**同一条公式，旋钮一拧，性格全变。**

## 5. 动手实验

### 实验（python）：不同刚度/阻尼下的"手感"复现

```python title="阻抗控制：环境按压下的退让曲线"
import math
import matplotlib.pyplot as plt

dt = 0.01                                        # 仿真步长（秒）
m = 1.0                                          # 虚拟质量

def simulate(k, c, steps=600):                   # 人手以恒力 5 N 压机械臂
    x = 0.0                                      # 当前位置
    v = 0.0                                      # 当前速度
    F_push = 5.0                                 # 环境施加的恒力
    traj = []
    for i in range(steps):
        F_imp = -k * x - c * v                   # 阻抗力：弹簧回弹 + 阻尼消振
        a = (F_push + F_imp) / m                 # 牛顿第二定律合成加速度
        v = v + a * dt
        x = x + v * dt
        traj.append(x)
    return traj, x

for k, c in [(10, 2), (40, 2), (10, 12)]:        # 三种手感：软 / 硬 / 软但黏
    traj, xf = simulate(k, c)
    print(f"k={k:>3} c={c:>2}  稳态退让 = {round(xf, 3)} m")

fig, ax = plt.subplots(figsize=(7, 3))
for k, c in [(10, 2), (40, 2), (10, 12)]:
    traj, xf = simulate(k, c)
    ax.plot([i * dt for i in range(len(traj))], traj, label=f"k={k}, c={c}")
ax.set_xlabel("t (s)")
ax.set_ylabel("x (m)")
ax.legend()
plt.show()
```

怎么玩：恒力 5 N 压下来，三条曲线三种性格——软臂（k=10）退让 0.5 米（$F = kx \Rightarrow x = 5/10$），硬臂（k=40）只让 0.125 米；k=10、c=12 的"黏稠版"退让同样 0.5 米但**不颤**（阻尼把超调吃掉了）。把 `c` 调到 0.5 再跑：末端振着到位——阻尼太小，虚拟弹簧自己弹钢琴。打磨选软而黏，压装选硬而稳，拖地选软而快——阻抗旋钮就是机器人的"性格设定器"。

```quiz
阻抗控制与位置控制最根本的分歧是？
- 一个用 PID 一个用 MPC
- 位置控制命令"必须到达的位置"，阻抗控制命令"受力与位置偏差的关系" [*]
- 一个控制关节一个控制末端
? 位置控制把误差当敌人（压到零），阻抗控制把误差当合同（力与偏差按 F=kx+c·v 结算）——后者才谈得上"顺从"与"手感"。
```

::::warning[常见误区]

**误区一**："你以为刚度越硬越好。" 硬臂压装是稳，可安全性的账立刻翻脸：人被 40 N/m 硬度的臂碰一下，反弹力几乎全额奉还；协作机器人的刚度普遍调低，宁可精度让步也要"撞人不疼"。刚度是精度与安全的天平，不是性能参数。

**误区二**："你以为阻尼只是'消振的小配角'。" 阻尼管的其实是最危险的一段——接触瞬间。刚度切换、撞上工件的刹那，动能全靠阻尼吸收；$c$ 太小，轻则振荡磨花表面，重则弹跳失控。工程口诀：先给足阻尼再谈刚度。

**误区三**："你以为阻抗律算出的 F 会自动执行。" $F$ 是末端坐标系里的力，执行要过两道翻译：$F \to$ 关节力矩用雅可比转置 $\tau = J^T F$（第 60 课奇异位形处 $J^T$ 会把力放大成关节过载）；而力矩指令只有配上动力学补偿（第 80 课三栏账）才真正等于 $F$——没补偿的重力会让"虚拟弹簧"松紧失真。

::::

## 6. 练习

```exercise
# @title: 练习：按阻抗合同算力
# @check: 13.0
# @check: 25.0
# @hint: 弹簧项管位置偏差、阻尼项管速度，两笔账各归各——别把系数配错了对象。
k = 10.0                                         # 虚拟刚度（N/m）
c = 2.0                                          # 虚拟阻尼（N·s/m）
x = 1.2                                          # 末端被顶到的位置
x0 = 0.0                                         # 虚拟参考位置
v = 0.5                                          # 末端速度

F = k * v + c * (x - x0)                         # ← 问题在这：刚度配给了速度，阻尼配给了位置
print(round(F, 1))

k2 = 20.0                                        # 调硬一档再算一次（速度项不变）
F2 = k2 * v + c * (x - x0)
print(round(F2, 1))
```

<details>
<summary>点开查看逐步解答</summary>

阻抗合同的两笔账各归各位：弹簧管位置、阻尼管速度。

```python
F = k * (x - x0) + c * v        # 10×1.2 + 2×0.5 = 12 + 1 = 13.0
F2 = k2 * (x - x0) + c * v      # 20×1.2 + 1 = 25.0
```

正确读数 `13.0 / 25.0`。初始代码把系数交叉错配（$10 \times 0.5 + 2 \times 1.2 = 7.4$）：刚度没管住位置、阻尼没管住速度，"手感"彻底变味。阻抗律的三个系数与三个状态量（$x$、$v$、$a$）一一对应，错配一档，机器人的性格就换了一个。
</details>

**练习 2**：打磨时想让末端以 3 N 的恒力贴住曲面（刚度 k=10 的虚拟弹簧），参考位置 $x_0$ 应设在哪里？曲面若凹凸起伏 ±2 毫米，实际贴压力会怎么变？

<details>
<summary>点开查看逐步解答</summary>

$F = k(x - x_0) \Rightarrow x_0 = x - F/k = x - 0.3$：参考位置设在接触点后方 0.3 米处，让弹簧天然"想压进去" 3 N。曲面起伏 ±2 mm 时，$x$ 随之浮动，贴压力按 $\Delta F = k \Delta x = 10 \times 0.002 = 0.02$ N 波动——不到设定值 ±1%，砂纸几乎察觉不到。这正是阻抗控制送打磨行业的第一份礼物：**把"恒力贴面"翻译成"位置松一点 + 弹簧收账"**；若想要 ±0 起伏，就得请六维力传感器做力外环（导纳那一路）了。
</details>

## 7. 选读：导纳、变阻抗与安全合规

阻抗与导纳是一条频谱的两端：**阻抗控制**读位置/速度、出力，适合自身柔顺的执行器（串弹关节、直驱电机电流环）；**导纳控制**读力传感器、改位置指令，适合传统刚硬的工业臂——力传感器贵，但导纳在刚性接触下容易抖（位置环带宽与力环打架），这是两条路线各自的阿喀琉斯之踵。更进一步是**变阻抗**：刚度阻尼随任务相位在线调度——接近段软（安全）、接触后渐硬（稳定）、拧螺丝时沿旋转轴软沿轴向硬（顺从该顺从的方向）；协作机器人拖动示教（手抓着臂走一遍）就是变阻抗的明星应用：空载时把刚度调到近零，机械臂"soft 得像没骨头"，人牵哪它去哪——示教轨迹再交给第 160 课的模仿学习去学。力控的尽头是人机共处：ISO/TS 15066 把功率与压力限值写进规范，数学上正是给阻抗律加了第四个旋钮——**安全边界**。
