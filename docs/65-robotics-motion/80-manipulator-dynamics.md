# 机械臂动力学方程：一本三栏的力账

## 1. 从一个场景开始

调试车间里那台二连杆机械臂悬在半空，屏幕上一动不动，示波器却显示两个电机都在持续出力。工程师凑近一看参数表，厂家给出的模型是三栏联写的一行：

$$M(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau$$

三个字母管三件事。上一课我们把欧拉-拉格朗日流水线跑了一半，这一课把流水线跑完——你会看到这行"成品账"每一栏从哪来、怎么读，以及为什么机械臂静止时电机也得干活。

## 2. 直觉解释

三个栏目的分工：

- **$M(q)$ 质量矩阵**——管"推起来多重"。关键在括号里的 $q$：惯量随姿势变。手臂伸直时甩肩膀，末端质量离轴最远，肩膀觉得"沉"；折叠后再甩，同一个肩膀突然"变轻"。哑铃不换，杠铃杆的长短在变。
- **$C(q,\dot q)\dot q$ 科氏与离心项**——管"转着转冒出来的假力"。旋转系统里的小脾气：甩动整条臂时，肘关节自己也会被甩着跑；洗衣机脱水桶把水压向桶壁，就是同一族力。它们只在有速度时出现。
- **$g(q)$ 重力项**——管"举着多费劲"。它是上一课势能 $V(q)$ 的坡度：姿势定了，这一栏就定了，与速度无关。

右边 $\tau$ 是电机力矩。方程读作：**电机出的力，一部分用来加速（$M$），一部分用来喂养旋转的假力（$C$），剩下的用来对抗重力（$g$）**。上一课静止悬空却耗电的谜底就在第三栏——手臂横着举，哪怕不动，电机也得一直扛着重力。

## 3. 正式定义

把二连杆（质量集中在杆端的"哑铃"模型）的欧拉-拉格朗日流水线跑完，会得到

$$M(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau$$

其中质量矩阵显式为

$$M=\begin{pmatrix}(m_1+m_2)L_1^2+m_2L_2^2+2m_2L_1L_2\cos\theta_2 & m_2L_2^2+m_2L_1L_2\cos\theta_2 \\ m_2L_2^2+m_2L_1L_2\cos\theta_2 & m_2L_2^2\end{pmatrix}$$

| 栏目 | 读法 | 要点 |
| --- | --- | --- |
| $M(q)$ | 惯量仪表盘 | 对称、正定；含 $\cos\theta_2$ 项——**惯量随姿势变** |
| $C(q,\dot q)\dot q$ | 速度耦合项 | 只在 $\dot q\ne0$ 时出现；公式不必背，会读就行 |
| $g(q)$ | 势能坡度 | $g_1=\partial V/\partial\theta_1$、$g_2=\partial V/\partial\theta_2$ |
| $\tau$ | 电机账单 | 控制的抓手：能直接下命令的只有它 |

两个读数术语：**肩关节的有效惯量**就是 $M_{11}$（甩肩膀实际感觉到的沉）；$M$ 行列式恒正，所以给定 $\tau$ 总能唯一解出 $\ddot q$——第 60 课的克莱姆法则又要上岗。

## 4. 分步例题

**例**：取 $m_1=m_2=L_1=L_2=1$。读两个姿势的账。

1. 伸直（$\theta_2=0$）：$\cos0=1$，$M_{11}=2+1+2=5$，$M_{12}=2$，$M_{22}=1$；
2. 直角（$\theta_2=90^\circ$）：$\cos90^\circ=0$，$M_{11}=3$，$M_{12}=1$，$M_{22}=1$；
3. 有效惯量从 5 掉到 3——**折叠手臂让肩膀变轻**，全是那个 $\cos\theta_2$ 交叉项在干活；
4. 再看水平伸直悬停（$\theta_1=\theta_2=0$，手臂水平指向前）：重力项 $g_1=(1+1)\cdot9.8\cdot1+1\cdot9.8\cdot1=29.4$，$g_2=9.8$；
5. 于是静止悬停也要求 $\tau=(29.4,\ 9.8)$ 牛·米——一动不动，电机照样满头汗。

### 实验 1（python）：重力补偿——静止也要出力

```python title="任意姿势悬空静止：组装 g(q)，读出保持力矩"
import math                                     # 三角函数标准库

# sliders: th1=0 [-90:90:15], th2=0 [-150:150:15]

g = 9.8                                         # 重力加速度
m1, m2 = 1.0, 1.0                               # 大臂、小臂质量（杆端哑铃）
L1, L2 = 1.0, 1.0                               # 大臂、小臂长度

r1 = math.radians(th1)                          # 肩角（从水平方向量起，与正运动学课一致）
r2 = math.radians(th2)                          # 肘角
g1 = (m1 + m2) * g * L1 * math.cos(r1) + m2 * g * L2 * math.cos(r1 + r2)    # 重力项：势能对肩角的坡度
g2 = m2 * g * L2 * math.cos(r1 + r2)            # 重力项：势能对肘角的坡度

print(f"悬空静止所需力矩: 肩 {round(g1, 2)}, 肘 {round(g2, 2)} 牛·米")
```

默认姿势（水平伸直）读数是 $(29.4,\ 9.8)$——例题的手算版。把 `th1` 拖到 $90^\circ$（手臂竖直指上）：两个读数趋近 0，胳膊"站在"骨骼上，电机放假。

### 实验 2（python）：同样的力气，两个姿势两种命运

```python title="给定 tau=(3,3)，克莱姆法则解加速度：伸直 vs 直角"
import math                                     # 三角函数标准库

g = 9.8                                         # 重力加速度
m1, m2, L1, L2 = 1.0, 1.0, 1.0, 1.0             # 质量与杆长（杆端哑铃）
w1, w2 = 1.5, 2.0                               # 关节角速度：两臂正在甩动
tau1, tau2 = 3.0, 3.0                           # 两个电机给的力矩

for deg2 in [0, 90]:                            # 两个肘角姿势：伸直 / 直角
    r1, r2 = 0.0, math.radians(deg2)            # 肩角固定水平，肘角换姿势
    c2, s2 = math.cos(r2), math.sin(r2)
    M11 = (m1 + m2) * L1**2 + m2 * L2**2 + 2 * m2 * L1 * L2 * c2    # 质量矩阵对角线 1
    M12 = m2 * L2**2 + m2 * L1 * L2 * c2        # 质量矩阵交叉项（对称）
    M22 = m2 * L2**2                            # 对角线 2
    h = -m2 * L1 * L2 * s2                      # 科氏耦合系数（含 sin 肘角）
    cor1 = h * (2 * w1 * w2 + w2**2)            # 方程 1 的科氏离心项
    cor2 = -h * w1**2                           # 方程 2 的科氏离心项
    gv1 = (m1 + m2) * g * L1 + m2 * g * L2 * math.cos(r1 + r2)      # 肩角水平时 cos(r1)=1
    gv2 = m2 * g * L2 * math.cos(r1 + r2)       # 肘重力项
    b1, b2 = tau1 - cor1 - gv1, tau2 - cor2 - gv2                   # 右边账：力矩减去假力与重力
    det = M11 * M22 - M12**2                    # 行列式：克莱姆法则的分母
    a1 = (b1 * M22 - M12 * b2) / det            # 肩角加速度（克莱姆第一行）
    a2 = (M11 * b2 - M12 * b1) / det            # 肘角加速度（克莱姆第二行）
    print(f"肘角 {deg2}°: 肩加速度 {round(a1, 2)}, 肘加速度 {round(a2, 2)} 弧度/秒²")
```

同样的 $(3,3)$ 力矩：伸直时肩加速度约 $-12.8$（重力碾压电机，臂在坠），折叠成直角后约 $-3.7$——质量矩阵变轻，同样的力气明显更"管用"。这就是为什么高级控制器恨不得实时重算 $M(q)$：**不是力越大越好，是姿势决定力值不值钱**。

## 6. 练习

```exercise
# @title: 练习：算全水平伸直的账
# @check: 肩关节有效惯量 = 5.0
# @check: 肩保持力矩 = 29.4
# @check: 肘保持力矩 = 9.8
# @hint: M11 的交叉项是 2 倍的 m2·L1·L2·cos(th2)，漏掉 2 倍是本课最常见的笔误；水平姿势角度都是 0，cos 全取 1；保持力矩就是重力项 g1、g2。
import math                                     # 只用到 cos

m1, m2, L1, L2 = 1.0, 1.0, 1.0, 1.0             # 质量与杆长
g = 9.8                                         # 重力加速度
th1, th2 = 0.0, 0.0                             # 水平伸直：肩角、肘角全为 0

M11 = (m1 + m2) * L1**2 + m2 * L2**2 + m2 * L1 * L2 * math.cos(th2)   # ← 错误行
g1 = (m1 + m2) * g * L1 * math.cos(th1) + m2 * g * L2 * math.cos(th1 + th2)
g2 = m2 * g * L2 * math.cos(th1 + th2)

print(f"肩关节有效惯量 = {round(M11, 1)}")
print(f"肩保持力矩 = {round(g1, 1)}")
print(f"肘保持力矩 = {round(g2, 1)}")
```

修好那个 2 倍：$M_{11}=5$。肩要扛 29.4 牛·米——一根 1 米、2 公斤的"手臂"水平伸着，抵得上一名工人端着三大瓶矿泉水不动。

## 7. 选读：为什么 M 一定对称正定

动能可以写成 $T=\frac12\dot q^T M(q)\dot q$ 的二次型。动能永远是正数（除非全系统静止），所以 $M$ 正定；而"混合偏导相等"（$\partial^2 T/\partial\dot q_1\partial\dot q_2=\partial^2 T/\partial\dot q_2\partial\dot q_1$）保证了 $M$ 对称。惯性耦合是相互的：甩肘会带肩，甩肩也会带肘，天道对称。至于 $C$，它由 $M$ 对 $q$ 的偏导按克里斯托费尔符号组装而成——工程上不必手推，读得出它的物理身份就够了。

## 8. 下一站

这本账最难读的地方是强非线性：$M$ 随 $q$ 变、$C$ 与速度相乘。下一课的计算力矩控制反其道而行——控制器的第一条命令就是 $\tau=M(q)(\dots)+C\dot q+g$，把三栏一口气全部抵消，机械臂瞬间"退化"成最好伺候的双积分器。
