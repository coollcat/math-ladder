# 视觉伺服：用像素误差直接开车

## 1. 从一个场景开始

机械臂要把螺丝刀对准一颗只有几毫米的螺丝。传统做法要先在"世界坐标"里闭环：手眼标定、求出螺丝的三维位置、规划、执行——每一环都有标定误差，层层叠起来毫米级对准就成了玄学。**视觉伺服**（visual servoing）换了个釜底抽薪的思路：**误差别换算，就在像素里闭环**——目标特征在画面里的落点与期望落点差多少像素，控制律直接从这个像素差算出相机该怎么动。像素差归零，对准就完成；至于螺丝在世界坐标里究竟在哪，根本不用回答。

## 2. 直觉解释

普通的控制闭环在"米"里（第 52 章），视觉伺服把传感器塞进回路最里层：相机看一眼 → 算像素误差 → 动一下 → 再看一眼。中间那个"像素差 → 速度"的翻译官叫**图像雅可比**：它回答"相机往右挪 1 厘米，画面里这个点会移动几像素"。翻译公式里藏着主角——**深度 $Z$**：

$$\dot{s} = \frac{v_x}{Z} \quad (\text{横向速度 } v_x \text{ 引起的像素速度，焦距归一})$$

同样的相机速度，**近处的特征在画面里跑得快，远处的跑得慢**——你横移镜头时近处树飞掠而过、远山纹丝不动，就是这条公式的日常显形。控制时它是双刃剑：深度估准了，闭环又稳又快；深度估错了，增益就错——太猛会过冲，太怂会磨蹭。

## 3. 正式定义

特征向量 $s$（若干特征点的像素坐标），期望位形 $s^{*}$，定义图像误差 $e = s - s^{*}$。图像雅可比 $L_s$（interaction matrix）联系相机速度 $v$ 与特征速度：

$$\dot{e} = L_s\, v$$

控制律取比例型（第 52 章的 P 控制搬进图像空间）：

$$v = -\lambda\, L_s^{+}\, e$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $s$ | 特征向量 | 当前画面里特征点的像素坐标 |
| $e$ | 图像误差 | 与期望像素位置的差 |
| $L_s$ | 图像雅可比 | 每行一个特征："相机单位速度 → 该点像素速度" |
| $L_s^{+}$ | 伪逆 | 特征多于自由度时取最小二乘（第 21 章） |
| $\lambda$ | 增益 | 每拍敢消掉多少误差 |
| $Z$ | 特征深度 | 雅可比里的主角：估不准，增益就不准 |

单点单轴的分量形式最直观：$\dot{s}_x = \dfrac{v_x}{Z} + (\text{旋转项})$——本课只保留平移主项，把旋转留进选读。

## 4. 分步例题

相机以 $v_x = 0.3$（米/秒）横移，画面里两个特征：A 深 $Z_A = 1$ 米、B 深 $Z_B = 3$ 米（焦距归一 $f = 1$）：

1. A 的像素速度：$\dot{s}_A = \dfrac{0.3}{1} = 0.3$ /秒；
2. B 的像素速度：$\dot{s}_B = \dfrac{0.3}{3} = 0.1$ /秒——**同一台相机，一个速度，画面里却是两档快慢**；
3. 若要把两个特征各自从位移 $2$ 拉回 $0$：恒速走 3 秒，A 走完 $0.3 \times 3 = 0.9$、B 只走 $0.1 \times 3 = 0.3$——B 还剩大半路。想让 B 也在 3 秒内归零？把速度提到 $v_x = 0.9$，可 A 就要过冲飞出画面；
4. 出路就是控制律本尊：**按各自的 $Z$ 分配增益**——$v = \lambda Z e$ 让两个特征的收敛速度脱钩。深度不是麻烦，是雅可比递给控制器的钥匙。

### 实验（python）：比例控制律在图像空间收敛

```python title="IBVS：按深度分配增益的两个特征"
import math
import matplotlib.pyplot as plt

lam = 1.0                                        # 增益
dt = 0.1                                         # 控制周期（秒）

sA = 2.0                                         # 特征 A 的像素误差（深 1 米）
sB = 2.0                                         # 特征 B 的像素误差（深 3 米）
ZA = 1.0
ZB = 3.0

histA = [sA]
histB = [sB]
for k in range(40):
    vA = lam * ZA * sA                           # 控制律：速度 = 增益×深度×误差
    vB = lam * ZB * sB
    sA = sA - vA / ZA * dt                       # 像素速度 = v/Z（图像雅可比主项）
    sB = sB - vB / ZB * dt
    histA.append(sA)
    histB.append(sB)

print("A 末误差 =", round(sA, 4), " B 末误差 =", round(sB, 4))

fig, ax = plt.subplots(figsize=(7, 3))
ax.plot([i * dt for i in range(41)], histA, label="feature A (Z=1)")
ax.plot([i * dt for i in range(41)], histB, label="feature B (Z=3)")
ax.legend()
ax.set_xlabel("t (s)")
ax.set_ylabel("pixel error")
plt.show()
```

怎么玩：控制律里的 $Z$ 在"速度生成"与"像素折算"两处相除相抵，两个特征以同样的指数速率奔向零（4 秒后误差只剩初始的 1.5%）——**按深度分配增益，深浅特征就同步收敛**。把 `vB` 那行的 `ZB` 去掉（改成 `lam * sB`）再跑：B 的增益只剩 A 的三分之一，曲线拖出一条长尾——这就是"深度估错一档、收敛慢三倍"的实况。

```quiz
视觉伺服把控制误差定义在哪里？
- 世界坐标里末端与目标的三维距离
- 图像里特征落点与期望落点的像素差 [*]
- 关节角度与期望角度的差
? 误差活在像素里，好处是绕开手眼标定与三维重建的层层误差；代价是要靠图像雅可比把像素差翻译成相机速度——深度 Z 的估计质量决定翻译质量。
```

::::warning[常见误区]

**误区一**："你以为误差在图像里收敛，运动就是直线。" 像素空间的直线路径，映射回世界坐标可能是条诡异的弧——末端可能擦过障碍、闯出工作空间。IBVS 管"像素漂亮"不管"笛卡尔体面"，工程上要再加位姿/关节限位的护栏（或用混合法把两套误差加权）。

**误区二**："你以为深度估不准只是慢一点。" $Z$ 错得离谱时增益等效地错：太大→振荡过冲（第 52 章 P 控制的老病），太小→磨蹭；更糟的是多特征场景里，错误的 $Z$ 让伪逆把速度分给错误的方向，特征在画面里**绕远路**甚至发散。深度来自立体匹配、已知模型或第 135 课的三角测量——伺服前先问一句"Z 哪来的"。

**误区三**："你以为特征越多越好。" 特征排布不当，图像雅可比会**降秩**（比如所有特征共线且同深），伪逆病态，某些方向的速度不可控——第 60 课奇异位形的图像版。挑特征的口诀：散开、有深度差、别太靠画面边缘。

::::

## 6. 练习

```exercise
# @title: 练习：近特征与远特征的赛跑
# @check: 1.1
# @check: 1.7
# @hint: 每步的像素位移 = 速度/深度——除以 Z 这一下别丢，丢了两个特征就跑成一样快。
v = 0.3                                          # 相机恒速（米/秒）
dt = 1.0                                         # 每步 1 秒
sA = 2.0                                         # 特征 A 位移（深 1 米）
sB = 2.0                                         # 特征 B 位移（深 3 米）

for k in range(3):
    sA = sA - v                                  # ← 问题在这：忘了除以各自的深度
    sB = sB - v

print(round(sA, 2))
print(round(sB, 2))
```

<details>
<summary>点开查看逐步解答</summary>

像素速度是 $\frac{v}{Z}$，各走各的：

```python
    sA = sA - v / 1.0                            # 每秒走 0.3 像素
    sB = sB - v / 3.0                            # 每秒只走 0.1 像素
```

三步之后：A 从 2 走到 $2 - 0.9 = 1.1$，B 只走到 $2 - 0.3 = 1.7$——近的先到，远的还在半路。初始代码让两者同速（都按 0.3 走），输出 `1.1 / 1.1`：深度这一档信息被抹平。图像雅可比的全部几何，就浓缩在那个"除以 $Z$"里——它同时是"近快远慢"现象的原因与控制律分配增益的依据。
</details>

**练习 2**：想让深 3 米的特征 B 与深 1 米的 A 在同一拍里消掉同样多的误差，B 的控制速度该是 A 的几倍？这个倍数与哪条公式有关？

<details>
<summary>点开查看逐步解答</summary>

3 倍。像素速度 $\dot{s} = v/Z$：要 $\dot{s}_B = \dot{s}_A$，需 $v_B / 3 = v_A / 1$，即 $v_B = 3 v_A$——正是控制律 $v = \lambda Z e$ 的来历：增益按深度放大，深浅特征同步收敛。同一条公式，正读是现象（近快远慢），反读是设计（按深度补增益）。
</details>

## 7. 选读：旋转项与手眼标定

完整点特征的图像雅可比是 $2 \times 6$（相机六个自由度进、两个像素导数出）：平移项之外还有旋转项 $x y \omega_z - (1 + x^2)\omega_y + \dots$——旋转引起的像素流动随特征在画面里的位置而变，这正是"转头时近处景物横扫"的几何。实际系统还要先过**手眼标定**这关：相机装在手上（eye-in-hand）还是装在工地（eye-to-hand），决定雅可比左乘还是右乘一个外参——标定把"相机的像素"与"机器人的关节"接上头，AX=XB 方程一族经典解法（Tsang-Lenz / Park-Martin）用的正是第 25 课四元数的旋转平均。工程上最省心的路线是混合伺服：图像误差管方向、位姿约束管安全，两本账一起收。
