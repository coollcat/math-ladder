# SLAM 现代后端：位姿图优化与 ICP 点云配准

## 1. 从一个场景开始

第 125 课的扫地机用滤波法 SLAM 活了下来，但它有个天生短板：**只顾眼前**——滤波器每一步都在"丢弃过去"，误差一旦走进状态就再难整体翻案。绕客厅跑一圈回到起点，里程计的漂移让"回环"对不上：地图上同一个墙角出现了两份，错位半米。现代 SLAM 的后端换个哲学：**别急着一步一定，把所有测量都记成账，最后一起算总账**——这就是位姿图优化；而"两帧点云怎么对齐"这个总账里最常见的零件，由 ICP（Iterative Closest Point，迭代最近点）来铸造。

## 2. 直觉解释

**位姿图是一张弹簧网**。每个节点是一个时刻的位姿；每条边是一条"相对运动的测量"：里程计说"从第 5 拍到第 6 拍我前进了 0.3 米"（相邻边，很密但不准），回环检测说"第 500 拍的位置其实就与第 1 拍重合"（回环边，很稀但一锤定音）。优化就是让整张网**弹到误差平方和最小的形状**：回环边一收紧，积累了一整圈的漂移被均匀摊回去，重影的墙角咔哒一声合拢。

**ICP 是两片点云的对接器**。里程计给你"大致对齐"的两帧激光扫描，ICP 负责精修：反复做三件事——**配对**（每点找对面云里离它最近的点）、**求解**（算出让配对误差最小的刚体平移/旋转）、**套用**（挪过去再看）。像双手对齐两摞纸：对一看、挪一挪、再对一看，几轮就严丝合缝。

## 3. 正式定义

位姿图优化把整条轨迹当一次大最小二乘：

$$\min_{T_1, \dots, T_n} \sum_{(i, j)} e_{ij}^{T}\, \Omega_{ij}\, e_{ij}, \qquad e_{ij} = \big( T_i \ominus T_j \big) \ominus z_{ij}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $T_i$ | 节点位姿 | 第 $i$ 拍机器人在哪、朝哪 |
| $z_{ij}$ | 相对运动测量 | 边记录的"从 $j$ 到 $i$ 的相对运动" |
| $e_{ij}$ | 边误差 | 测量与当前位姿差多少 |
| $\Omega_{ij}$ | 信息矩阵 | 这条边有多可信（协方差的倒数）——回环边权重大 |

ICP 的一轮迭代（平移版）：

$$t \leftarrow \frac{1}{N} \sum_{i} \big( q_i - p_i \big), \qquad p_i \leftarrow p_i + t$$

其中 $q_i$ 是 $p_i$ 的最近邻配对点——**配对**求出平均错位 $t$，**套用**后再重新配对，直到 $t$ 缩到忽略不计。

## 4. 分步例题

**ICP 手走两轮（一维平移）**：运动点云 $P = [0, 1, 2]$，目标点云 $Q = [0.5, 1.4, 2.7]$（大致对齐、尚未精准）：

1. **第一轮配对**：$0 \to 0.5$（差 0.5，比到 1.4 近）；$1 \to 1.4$（差 0.4）；$2 \to 2.7$（差 0.3）；
2. **求解**：平均错位 $t = \frac{0.5 + 0.4 + 0.7}{3} = 0.533$；**套用**：$P \leftarrow [0.533, 1.533, 2.533]$；
3. **第二轮配对**：$0.533 \to 0.5$（差 0.033）；$1.533 \to 1.4$（差 0.133）；$2.533 \to 2.7$（差 0.167）；
4. **求解**：$t = \frac{0.033 + 0.133 + 0.167}{3} \approx 0.111$——错位从 0.533 缩到 0.111，两轮就咬到毫米级。配对、求解、套用，三拍循环直到 $t$ 归零。

**位姿图一句话例题**：一维走廊里机器人走了 10 拍回到原点。里程计相邻边说"每拍 +1.05 米"（有 5% 高估），累计漂到 10.5；回环边说"末位 = 起点"。优化没有偏袒谁：把 0.5 米的矛盾按信息矩阵权重摊到 10 条边上——每条边微调一点，轨迹整体"缩"回闭环。

## 5. 动手实验

### 实验（python）：二维 ICP 迭代收敛 + 位姿图回环拉直

```python title="ICP 三拍循环与回环误差摊账"
import math
import random
import matplotlib.pyplot as plt

random.seed(5)

# ---- 第一幕：ICP 对齐两片点云 ----
target = [(random.uniform(0, 5), random.uniform(0, 5)) for _ in range(40)]
moving = [(x + 0.6, y - 0.4) for x, y in target]        # 目标云整体错位 (0.6, -0.4)

def nearest(p, cloud):                                   # 最近邻配对
    best = cloud[0]
    bd = (p[0] - best[0]) ** 2 + (p[1] - best[1]) ** 2
    for q in cloud:
        d = (p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2
        if d < bd:
            bd = d
            best = q
    return best

shift = (0.0, 0.0)
for it in range(5):                                      # ICP 三拍循环
    sx = 0.0
    sy = 0.0
    for p in moving:
        q = nearest(p, target)                           # 1) 配对
        sx = sx + q[0] - p[0]
        sy = sy + q[1] - p[1]
    shift = (sx / len(moving), sy / len(moving))         # 2) 求解：平均错位
    moving = [(p[0] + shift[0], p[1] + shift[1]) for p in moving]   # 3) 套用
    print("ICP 第", it + 1, "轮  本轮修正 =", (round(shift[0], 3), round(shift[1], 3)))

# ---- 第二幕：位姿图把回环误差摊回去 ----
n = 10                                                   # 十拍的走廊轨迹
poses = [0.0]                                            # 里程计航位推算（每拍 +1.05）
for i in range(1, n):
    poses.append(poses[-1] + 1.05)
poses[0] = 0.0
loop_err = poses[-1] - 0.0                               # 回环边说：末位应为 0
fixed = [p - loop_err * i / (n - 1) for i, p in enumerate(poses)]   # 误差按边摊匀
print("里程计末位 =", round(poses[-1], 2), " 摊账后末位 =", round(fixed[-1], 2))
print("摊账后每拍位置 =", [round(p, 2) for p in fixed])

fig, ax = plt.subplots(figsize=(7, 3))
ax.plot(poses, marker="o", label="odometry")
ax.plot(fixed, marker="s", label="after loop closure")
ax.legend()
plt.show()
```

怎么玩：ICP 五轮把错位 $(0.6, -0.4)$ 一路修正到小数点后三位——配对、求解、套用的三拍循环自己会收敛；位姿图那幕里，0.5 的回环矛盾被均匀摊进十拍，末位精确归零，中间每拍只挪一点点——**没有哪条边被宣布"错的"，只有整体最小的那组位姿**。真实的 g2o/GTSAM 后端做同一件事，只是节点是 2D/3D 位姿、边是带信息矩阵的完整约束。

::::warning[常见误区]

**误区一**："你以为 ICP 从任意错位都能收敛。" 最近邻配对只在"已经大致对齐"时才有意义：初始错位一大，点配到错误的邻居上，ICP 一头扎进错误的局部极小（两片云"错位锁定"）。工程上先给粗对齐（里程计、特征匹配），ICP 只负责精修；错位大时用多分辨率版本先粗后细。

**误区二**："你以为位姿图会指出哪条边'错了'。" 优化不给判决，只给折中：一条错误的高权重边（错误的回环检测）会把整条轨迹**整体拽歪**——比漂移更难看。所以回环检测自己要先过严苛验证，优化器还要配鲁棒核（Huber 等）给"离群边"降权。

**误区三**："你以为 ICP 配上的点对是真对应。" 最近邻只是"眼下最像"，不是"真的一样"——配对里混着大量错配，平均错位因此有偏。鲁棒 ICP 用截断/加权的错位统计（只信误差小的配对），或者干脆多轮迭代让错配比例轮轮下降。

::::

## 6. 练习

```exercise
# @title: 练习：平移版 ICP 的一轮求解
# @check: True
# @check: 0.0
# @check: 1.0
# @hint: 求解那一步是"平均"错位——求和之后别忘了除以点数，否则修正量会放大三倍。
moving = [(0.0, 0.0), (1.0, 0.0), (2.0, 0.0)]    # 运动点云
target = [(0.0, 1.0), (1.0, 1.0), (2.0, 1.0)]    # 目标点云（在正上方 1 米）

pairs = []                                       # 最近邻配对结果
for p in moving:
    best = target[0]
    bd = (p[0] - best[0]) ** 2 + (p[1] - best[1]) ** 2
    for q in target:
        d = (p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2
        if d < bd:
            bd = d
            best = q
    pairs.append((p, best))

match_ok = all(p[0] == q[0] and q[1] == 1.0      # 检查配对：x 对齐、且都配到上方那排
               for p, q in pairs)

sx = 0.0
sy = 0.0
for p, q in pairs:
    sx = sx + q[0] - p[0]
    sy = sy + q[1] - p[1]
shift = (sx, sy)                                 # ← 问题在这：忘了除以点数

print(match_ok)
print(round(shift[0], 1))
print(round(shift[1], 1))
```

<details>
<summary>点开查看逐步解答</summary>

三对最近邻分别是 $(0,0) \to (0,1)$、$(1,0) \to (1,1)$、$(2,0) \to (2,1)$——各归各，`match_ok = True`。错位总和是 $(0, 3)$，但那是**三对错位的总和**，单点平均错位才是修正量：

```python
shift = (sx / len(pairs), sy / len(pairs))       # (0.0, 1.0)
```

修正后平移 $(0.0, 1.0)$ 一步到位，两片云严丝合缝。初始代码直接用总和，修出 $(0, 3)$——点云被弹飞三米。ICP 的"求解"永远是**平均**（等价于最小二乘解：平方误差对 $t$ 求导置零，解恰为均值差），这一除是它的数学身份。
</details>

**练习 2**：里程计每拍 +1.05、共 10 拍，回环边要求末位回到 0。若把回环边的权重调成"无限大"（信息矩阵取巨大值），优化结果变成什么样？这说明回环边该配什么样的权重？

<details>
<summary>点开查看逐步解答</summary>

回环边无限硬，末位被钉死在 0，0.5 米的矛盾**全额**压给里程计边——轨迹形状由回环单独决定，里程计的中间信息作废。现实里回环检测也有噪声（认错门的案例不少），无限信任它等于把系统交给最冒险的测量。信息矩阵的正确写法是"按各自协方差倒数的比例分账"：里程计漂多少、回环准多少，都写进权重里让优化自己去称。弹簧网的比喻再次生效：**硬弹簧压塌软弹簧，图纸就再也不是各测量的共识。**
</details>

## 7. 选读：旋转的账要记在流形上

平移好办（向量加减），旋转没有加法交换律——两个旋转"叠加"要用矩阵/四元数乘法，直接把欧拉角当向量做最小二乘会算出鬼。现代后端在**李群流形**上优化：每轮迭代在当前位姿的"切空间"里解一个小修正量（第 57 章微分几何的 $\exp/\log$ 映射登场），再指数映射回流形——第 125 课 EKF"在估计点拍平"的思想，在图优化里以流形的形式重生。此外，第 39 章 95 号课的因子图正是位姿图的数学母体：节点是随机变量、边是因子、信息矩阵就是高斯因子的精度——SLAM 后端、传感器融合、VIO，共用同一本贝叶斯账。
