# SLAM：边建图边找自己

## 1. 从一个场景开始

一台扫地机器人开机，被放进了从没见过的客厅：地图是一片空白，里程计说"我走了两米"，可它连起点在哪都不知道。要定位先得有地图——不知道墙在哪，距离读数没法解释；要建图先得定位——不知道自己在哪，量出来的墙也钉不到图上。鸡生蛋，蛋生鸡。

**SLAM**（同时定位与建图）把这个死结当成一个估计问题一起解。而解锁要用的两件工具，都是上一课卡尔曼滤波的"非线性续作"：**粒子滤波**——用几百个假想位姿当选票，谁跟观测对得上谁活下来；**EKF**（扩展卡尔曼滤波）——把弯的观测曲线在当前估计点拍平成切线，再照旧走卡尔曼的五件套。

## 2. 直觉解释

**卡尔曼的舒适区，与它的裂缝**。上一课的滤波只养一朵高斯云：一个中心加一团胖瘦。可"我到灯塔 2 米"这句话天生有两个答案——灯塔左边 2 米或右边 2 米，一朵云装不下两坨候选；测距读数又是距离公式 $\sqrt{\Delta x^2 + \Delta y^2}$ 这类弯曲线，上一课那套直线的更新公式一上去就拧巴。**裂缝出在"单峰"与"线性"两个前提上。**

**粒子滤波是选票民主**。它干脆不坚持云的形状：撒下几百个假想位姿（粒子），每个粒子就是一张"我在这儿"的选票。每一步三连：**撒票**——按里程计让整批粒子挪窝，顺手抖点噪声；**称重**——按"这个假想位姿该读到什么 vs 实际读到什么"给每张票打分；**重采样**——按权重复印选票，票多的繁衍、票少的出局。信念想分叉就分叉，想坍缩就坍缩，云的形状从来不由公式规定。

**EKF 是切线世界观**。非线性既然绕不开，就在当前估计点把弯曲线**拍平成切线**，切线斜率（雅可比）替换线性卡尔曼里的常数增益，五件套照旧。代价是每走一步都得重新拍平：小步长下切线贴着曲线走，步子一大，曲率就开始咬人。协方差椭圆也随切线方向变形——每次观测沿切线的法向把椭圆压扁，每次预测沿运动方向把它拉长。

**SLAM 把鸡和蛋塞进同一个状态向量**。位姿未知、地标也未知，那就把"我在哪"与"墙在哪"打包成一个更长的状态一起估：定位误差与地图误差本是同一枚硬币的两面。一旦机器人重访旧地标（**闭环**），新旧观测互相印证，位姿与地图一起校准——误差越大，这一次闭环兑现的修正越爽快。

## 3. 正式定义

贝叶斯滤波的递推只有两步——**预测**与**更新**：

$$\bar{p}(x_t) = \int p(x_t \mid x_{t-1})\, p(x_{t-1} \mid z_{1:t-1})\, dx_{t-1}$$

$$p(x_t \mid z_{1:t}) \propto p(z_t \mid x_t)\, \bar{p}(x_t)$$

上一课的卡尔曼滤波是它在"线性 + 高斯"世界里的解析解；两种非线性续作是同一递推的不同算法化：

- **粒子滤波**：用粒子集 $\lbrace x^{(i)}, w^{(i)} \rbrace_{i=1}^{N}$ 近似信念云，积分换成粒子平均，权重按观测打分后归一化，再按权重重采样；
- **EKF**：只养一朵高斯云，非线性函数在估计点泰勒展开到一阶——观测模型拍平为 $h(x) \approx h(\hat{x}) + H(\hat{x})(x - \hat{x})$，运动模型同理，随后逐字套用上一课的五件套。

| 记号 | 名字 | 读法 |
| --- | --- | --- |
| $x_t$ | $t$ 时刻状态 | "我现在在哪"；SLAM 里再打包上地标坐标 |
| $u_t$ | 里程计输入 | "我猜我走了这一步"（会漂） |
| $f(x, u)$ | 运动模型 | 按输入递推下一时刻的假想位姿 |
| $h(x)$ | 观测模型 | "若我真在 $x$，传感器该读到什么" |
| $w^{(i)}$ | 第 $i$ 张选票的权重 | $\propto p(z_t \mid x^{(i)})$：该粒子对观测的解释力 |
| $H = \partial h/\partial x$ | 观测雅可比 | 把弯的观测拍平成切线的斜率 |
| $F = \partial f/\partial x$ | 运动雅可比 | 把弯的运动拍平成切线的斜率 |

## 4. 分步例题

**例 1（五张选票手走一遍）**：走廊长 10 米，灯塔立在 $L = 4$ 米处；机器人真实位置 2 米（读者全知，机器人不知）。为能手算，观测先取"整米粗筛"口径——粒子到灯塔的距离四舍五入后与读数相等才有票：

1. **开局撒票**：均匀撒 5 张 $\lbrace 0, 2, 4, 6, 8 \rbrace$——纯瞎猜，毫无立场；
2. **观测"到灯塔 2 米"**：距离各为 $4, 2, 0, 2, 4$，对上读数的只有 2 与 6——信念云**分裂成两坨**（左 2 右 6，等权），这正是高斯一朵云装不下的多峰；
3. **运动"向右 1 米"**：整批粒子平移，候选变 $\lbrace 3, 7 \rbrace$——猜测跟着里程计走，漂移也照走不误；
4. **观测"到灯塔 1 米"**：$|3-4|=1$ 对上，$|7-4|=3$ 出局——只剩 3，定位坍缩；
5. **重采样**：5 张票全印在 3 附近；同一本账还顺手钉死了"灯塔在 4 米"——位姿与地标，一起水落石出。

**例 2（EKF 把弯的测距拍平）**：机器人沿 $x$ 轴走，灯塔挂在墙上 $(0, 4)$，测距 $h = \sqrt{x^2 + 16}$。位姿估计 $x = 3$ 时 $h = 5$：

1. 雅可比 $H = \partial h/\partial x = x/\sqrt{x^2+16} = 0.6$——切线斜率；
2. 小步试探 $x = 3.1$：真实 $h(3.1) = \sqrt{25.61} \approx 5.0606$，切线预测 $5 + 0.6 \times 0.1 = 5.06$——误差仅 0.0006，切线几乎贴着曲线；
3. 大步试探 $x = 4$：真实 $\sqrt{32} \approx 5.657$，切线预测 $5 + 0.6 \times 1 = 5.6$——误差 0.057，曲率开始咬人；
4. 解读：EKF 每次只在当前估计点拍平，**步子小则灵、步子大则谎**——这就是它对"预测不能太莽"的执念来源。

### 实验 1（python）：两百张选票的三步重采样

```python title="一维地标粒子滤波：撒票、称重、重采样"
import math
import random

random.seed(11)                                    # 固定随机种子：每次运行结果一致

L = 4.0                                            # 灯塔位置（真值，机器人并不知道）
N = 200                                            # 粒子数：200 张"我在这儿"的选票
particles = [random.uniform(0, 10) for _ in range(N)]   # 开局均匀撒票：走廊上到处都是猜测

def weigh(ps, z, sigma):                           # 按观测给每张选票称重
    ws = []
    for x in ps:
        e = z - abs(x - L)                         # 残差：读数减去该粒子预测的"到灯塔距离"
        ws.append(math.exp(-e * e / (2 * sigma * sigma)))   # 高斯核：残差越小票越重
    total = sum(ws)                                # 权重总和：归一化的分母
    return [w / total for w in ws], total

def resample(ps, ws):                              # 轮盘赌重采样：权重大的票被复制得多
    keep = []
    total = sum(ws)
    for _ in range(len(ps)):                       # 播 N 轮：下标用不上，用 _ 占位
        u = random.random() * total                # 转一次轮盘：指针落在 u 处
        acc = 0.0
        pick = ps[len(ps) - 1]                     # 兜底：指针擦边时默认留下最后一张票
        for i in range(len(ps)):
            acc = acc + ws[i]                      # 累积权重：把票一张张码上秤
            if acc >= u:                           # 秤面第一次压过 u：当前这张票中选
                pick = ps[i]
                break
        keep.append(pick)
    return keep

sigma = 0.5                                        # 测距噪声宽度：0.5 米

ws, total = weigh(particles, 2.0, sigma)           # 第 1 步观测："我到灯塔 2 米"
particles = resample(particles, ws)
left = 0                                           # 数一数灯塔左侧（x < 4）的候选有几张
for x in particles:
    if x < 4:
        left = left + 1
print(f"第 1 步 归一化权重总和 = {round(sum(ws), 4)}（称重账要平）")
print(f"第 1 步 重采样后：灯塔左侧 {left} 张，右侧 {N - left} 张")

particles = [x + 1.0 for x in particles]           # 运动：机器人自报"向右走 1 米"，整批粒子跟着平移
ws, total = weigh(particles, 1.0, sigma)           # 第 2 步观测："我到灯塔 1 米"
particles = resample(particles, ws)
mean = sum(particles) / N                          # 粒子平均：定位报告
var = 0.0
for x in particles:
    var = var + (x - mean) ** 2                    # 累加器：离平均的平方距离
var = var / N
print(f"第 2 步 归一化权重总和 = {round(sum(ws), 4)}（称重账要平）")
print(f"第 2 步 重采样后：估计位置 = {round(mean, 2)} 米，粒子标准差 = {round(math.sqrt(var), 2)} 米")
```

怎么玩：归一化权重总和两步都稳稳等于 1.0——称重的账先要平。第一步"到灯塔 2 米"把 200 张票分成左右两坨（98 与 102，距离观测天生左右对称）；第二步运动 1 米后再听"到灯塔 1 米"，右坨（离灯塔 3 米）对不上被筛出局，信念云从开局约 2.9 米的标准差坍缩到 0.43 米，估计 3.11 米贴着真位 3 米。把第二次观测改成 2.0 再跑：右坨也有解释力，云会重新分叉——证据说了算。

## 6. 练习

```exercise
# @title: 练习：给三张选票称重
# @check: w0 = 0.574
# @check: w1 = 0.348
# @check: w2 = 0.078
# @hint: 高斯核只给"相对票重"：w ∝ exp(-e²/2)。归一化要除以权重总和，不是除以粒子张数——除错了对象，票就永远平不了账。
import math

errors = [0.0, 1.0, 2.0]                  # 三个粒子的观测残差：读数减粒子预测

ws = []
for e in errors:
    ws.append(math.exp(-e * e / 2))       # 高斯核称重：σ 取 1，残差越小票越重

norm = [w / len(ws) for w in ws]          # ← 问题在这：除以的是粒子张数，不是权重总和

for i in range(3):
    print(f"w{i} = {round(norm[i], 3)}")
```

修好那行（分母换成权重总和）：三张票分到 0.574、0.348、0.078——残差为 0 的粒子拿走近六成选票，权重只看**相对**含金量，总和永远归一。

**练习 2**：重采样的轮盘赌手算一次。四个粒子的归一化权重为 0.1、0.4、0.3、0.2，累计秤面为 0.1、0.5、0.8、1.0。本轮摇出的指针 $u = 0.55$，哪张票中选？

<details>
<summary>点开查看逐步解答</summary>

秤面第一次压过 0.55 的是第三个粒子（累计 0.8）——第 3 号中选。指针落在 0 到 0.1 之间才是 1 号、0.1 到 0.5 之间是 2 号……权重 0.4 的粒子占据秤面最宽的一段，也就最常被复印。200 轮摇下来，每个粒子的期望复印次数恰好等于它的权重——这就是"按权重复印"的算术本质。
</details>

**练习 3**：机器人报"向右走了 1 米"，但里程计有漂移；粒子滤波怎么把这份"不信任"写进算法？

<details>
<summary>点开查看逐步解答</summary>

运动那一步不是让整批粒子精确平移 1 米，而是平移之后再**各自抖一点噪声**（按运动模型的不确定度撒开）：真实位置 3 米的粒子有 3.1 的、也有 2.9 的。这份撒野让下一轮观测称重时，估计有资格被微调——里程计负责把票驮到大致对的地方，观测负责把票洗干净。只有平移没有噪声的粒子群，会在几轮之后集体锁死在错误的位姿上。
</details>

## 7. 选读：把地图也塞进状态向量

EKF-SLAM 的做法简单粗暴：状态向量扩成"位姿 + 所有地标"，$\lbrack x, y, \theta, m_1, m_2, \dots \rbrack$，协方差矩阵随之长出**位姿-地标交叉块**——它记录着"这个地标的误差有多少要赖在位姿误差头上"。定位一旦修正，交叉块把修正传给每一个见过它的地标；反之亦然。这就是"鸡蛋同解"的账本形态：不是两个问题，是一个大问题的两块对角。代价是账本按地标数平方膨胀——大地图养不起，于是有了 FastSLAM 的分工：粒子管位姿，每个粒子各挂一张"若我真在这儿，地图长这样"的小账本，把耦合拆成条件独立。另一个隐忧在重采样本身：反复复印赢家会让粒子多样性缩水（粒子贫化），工程上靠低方差采样与注入噪声续命——民主也需要防"赢者通吃"。

滤波法 SLAM 就地解开了"鸡生蛋"，但它的账本只记当下：误差进了状态就难整体翻案，地图也只是稀疏的坐标。现代 SLAM 的另一半故事——把所有测量放在一起算总账，把地图织成照片——从"相机位姿怎么从照片里解出来"开始。
