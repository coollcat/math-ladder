# 梁的剪力图与弯矩图

## 1. 从一个场景开始

一根 6 m 长的钢梁，中间吊 2 吨，两端简支。要给它选截面，工程师第一个问题永远是：**这根梁最危险的截面在哪儿？**

直觉说"跨中"，可一旦重物不在正中，直觉就错了——最大弯矩会跟着重物跑，跑到你没加固的那个位置。

不用猜。把内力沿梁长画出来，曲线的峰值自己会告诉你答案。

## 2. 直觉解释

拿一根塑料尺，两手各托一端，中间往下压——尺弯了。现在把两手靠拢，只托中间那一小段，再压，尺几乎不弯。

为什么？因为"弯曲"这件事，本质上是**梁的一侧被拉长、另一侧被压短**。拉得多厉害、压得多厉害，取决于你**离支点有多远**：手越靠拢，力臂越短，需要的内力越小。

梁内部有两个内力，可以用一个动作体会：

- 用剪刀在梁中间某处"咔嚓"剪断，左右两半要**互相顶住不滑开**——这个竖向的内力叫**剪力** $V$；
- 同时它们还要**互相掰住不转开**——这个内力矩叫**弯矩** $M$。

把 $V$ 和 $M$ 沿梁长逐点画出来，就是这一课的两张图。它们不是画着好看的：**弯矩最大的截面就是梁最危险的地方**，截面选型全靠它。

## 3. 正式定义

**截面法**：在距左端 $x$ 处把梁截开，取左半段为隔离体，则截面上的内力等于**左半段所有外力**的反向合力与合力矩：

$$V(x) = \sum F_y^{\text{左}}, \qquad M(x) = \sum \left(F^{\text{左}} \times \text{到截面的力臂}\right)$$

**微分关系**（梁的平衡方程，全课最重要的一条）：对长度为 $dx$ 的微段列平衡，得

$$\frac{dV}{dx} = -q(x), \qquad \frac{dM}{dx} = V(x)$$

其中 $q(x)$ 是分布载荷集度（向下为正时取负号，取决于约定）。

**积分形式**（微积分基本定理的直接应用）：

$$V(x) = V(0) - \int_0^x q(s)\,ds, \qquad M(x) = M(0) + \int_0^x V(s)\,ds$$

**三条看图口诀**：

1. 分布载荷是剪力图的**斜率**——有均布载荷，剪力图就是斜线；
2. 剪力是弯矩图的**斜率**——剪力为正，弯矩在涨；
3. 因此，**弯矩取极值的地方，剪力必然为零**（或在该处跳变穿过零）。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $V$ | 剪力 | N | 截面上的竖向内力 |
| $M$ | 弯矩 | N·m | 截面上的内力矩 |
| $q$ | 分布载荷集度 | N/m | 均布载荷时 $q$ 为常数 |
| $P$ | 集中力 | N | 使剪力图**突跳**，弯矩图出**折角** |
| $M_0$ | 集中力偶 | N·m | 使弯矩图**突跳**（本组件不含） |

## 4. 分步例题

**例**：简支梁 $L = 6$ m，全跨均布 $w = 5$ kN/m，另在跨中 $a = 3$ m 处有集中力 $P = 20$ kN。求支座反力、关键截面的 $V$ 与 $M$、最大弯矩。

1. **支座反力**：总载荷 $wL + P = 30 + 20 = 50$ kN，载荷关于跨中对称，故
   $$R_{左} = R_{右} = 25\ \text{kN}$$
2. **剪力**（从左往右走）：
   $$V(0^+) = +25\ \text{kN}, \quad V(3^-) = 25 - 5\times 3 = +10\ \text{kN}$$
   跨过集中力，$V$ **向下突跳** $P$：$V(3^+) = 10 - 20 = -10$ kN；
   $$V(6^-) = -10 - 5\times 3 = -25\ \text{kN} \xrightarrow{\text{右支座}} 0 \ \checkmark$$
3. **弯矩**（对截面左侧取矩）：$M(x) = R_{左}x - \dfrac{wx^2}{2} - P(x-3)\cdot H(x-3)$
   $$M(3) = 25\times 3 - \frac{5\times 3^2}{2} = 75 - 22.5 = 52.5\ \text{kN·m}$$
4. **最大值**：$x<3$ 时 $V>0$，弯矩在涨；$x>3$ 时 $V<0$，弯矩在落。**峰值正好落在 $x = 3$ m**，即 $M_{\max} = 52.5$ kN·m；
5. **校验**：$M(0) = 0$、$M(6) = 25\times 6 - \dfrac{5\times 36}{2} - 20\times 3 = 150 - 90 - 60 = 0$ ✓ 简支端弯矩必须为零，这是免费的校验。

注意 $V$ 在集中力处是**跳过零**而不是"经过零"：它从 $+10$ 直接跳到 $-10$。所以弯矩图在这里不是平滑的顶点，而是一个**尖角**——工程上管这叫弯矩图的折点，它照样是极值。

三格上下对齐：载荷图、剪力图 $V(x)$、弯矩图 $M(x)$，中间那条**琥珀色虚线**标出弯矩极值的位置。四件事建议亲手做：

- **把 $P$ 拖到 0**：只剩均布载荷时，$V$ 是一条从左 $+15$ kN 斜到右 $-15$ kN 的直线，它在跨中**平滑地过零**；而 $M$ 的顶点正好落在同一个 $x = 3$ m 上。这就是 $\dfrac{dM}{dx} = V$ 最干净的一次演示；
- **把 $P$ 加回来**：$V$ 在 $x = a$ 处竖直掉下去 20 kN（突跳），$M$ 在那里出现一个尖角。读数里"M 极值处 V"显示的是 $\pm 10$ kN 而不是 0——**因为它是跳过去而不是走过来的**；
- **拖 $a$ 从 1 到 5**：看弯矩峰值如何跟着集中力跑。峰值最大出现在 $a = L/2$（跨中），此时 $M = PL/4 + wL^2/8$，这是最不利的布置；
- **切到"悬臂梁"**：$V$ 图从固定端的满值线性收敛到自由端的 0，$M$ 图是抛物线且**整条都是负的**（受拉侧翻转）。悬臂梁的最大弯矩永远在固定端，这也解释了为什么悬臂的 root 最粗。

**关于符号**：组件内部把向下的载荷记为负，所以支座反力读数显示为 $-25.00$ kN、弯矩图画在轴线下方。工程书上更常见的写法是"向下载荷取负、向上反力取正"，与这里**整体差一个负号**。零点位置、极值大小、危险截面的判断完全不受影响——**先写清约定，符号就不再是问题**。

### 实验 2（python）：用积分从载荷推出两张图

```python title="积分链：载荷 → 剪力 → 弯矩"
# sliders: a=3.0 [0.2:5.8:0.1]
L, P, w = 6.0, 20000.0, 5000.0   # 跨度（m）、集中力（N）、均布载荷（N/m）
a = 3.0                          # 集中力位置（m）
n = 600                          # 把梁切成 600 段
dx = L / n

R0 = (w * L * (L / 2) + P * a) / L        # 对右支座取矩 → 左反力
RL = w * L + P - R0                       # 竖向平衡 → 右反力

V = []
M = []
v, m = R0, 0.0
for i in range(n + 1):
    V.append(v)
    M.append(m)
    m += v * dx                  # 弯矩是剪力的积分（微积分基本定理）
    v -= w * dx                  # 剪力是分布载荷的积分
    if abs((i + 1) * dx - a) < dx / 2:
        v -= P                   # 跨过集中力，剪力突跳

iM = 0
for i in range(1, n + 1):        # 找弯矩最大的截面
    if M[i] > M[iM]:
        iM = i
ana = R0 * a - w * a * a / 2     # 解析值：截面左侧所有力对该截面取矩
print(f"反力 R左 = {R0 / 1000:.2f} kN, R右 = {RL / 1000:.2f} kN")
print(f"Mmax = {M[iM] / 1000:.2f} kN·m 位于 x = {iM * dx:.2f} m")
print(f"该处剪力 V = {V[iM] / 1000:.3f} kN，紧邻其左侧 V = {V[iM - 1] / 1000:.3f} kN")
print(f"解析值 M(3 m) = {ana / 1000:.2f} kN·m，累和偏高 {100 * (M[iM] - ana) / ana:.2f}%")
```

输出：`R左 = R右 = 25.00 kN`、`Mmax = 52.58 kN·m 位于 x = 3.00 m`、该处 $V$ 从 $+10.05$ 跳到 $-10.00$ kN、`解析值 52.50 kN·m，累和偏高 0.14%`。

最后那 0.14% 不是 bug 而是**左端点黎曼和的一阶误差**：我们用"每格起点的剪力"代表整格，$n$ 越大偏差越小。把 `n` 改成 6000 再跑，偏差会缩到十分之一——这就是数值积分的收敛阶在起作用。

### 快问快答

```quiz
一根简支梁只受沿全跨的均布载荷，关于剪力图与弯矩图的形状，正确的是？
- 剪力图是水平直线，弯矩图是斜直线
- 剪力图是斜直线，弯矩图是抛物线，且弯矩最大处剪力为零 [*]
- 剪力图是抛物线，弯矩图是三次曲线
? 分布载荷是剪力图的斜率，所以 V 是一次函数；剪力又是弯矩图的斜率，所以 M 是二次函数。跨中剪力过零的地方，正是弯矩取极值的地方。
```

:::warning[常见误区]

**误区一**："最大弯矩总在跨中。"
你在用对称性的经验代替判据——**最大弯矩在 $V = 0$ 的截面**，跨中只是"载荷对称时"的特例。一个 40 kN 的集中力放在 $a = 1$ m 处（$L = 6$ m、无均布载荷），弯矩峰值就跑到 $x = 1$ m，数值 33.3 kN·m；而真正的跨中只有 20 kN·m。**按跨中设计会低估四成**。吊车梁、楼面梁的"最不利布置"计算，就是在枚举载荷位置找这个峰值。

**误区二**："集中力处弯矩图也有突变。"
你把剪力图和弯矩图记混了——**集中力让 $V$ 突变、$M$ 只出折角**（斜率变了，值连续）；只有**集中力偶**才会让 $M$ 突变。判别方法很简单：把微分关系 $\dfrac{dM}{dx} = V$ 想成"斜率"，$V$ 跳一级，$M$ 的斜率就跳一级，函数本身还是连着的。画完图后检查简支端 $M$ 是否回到零，能一次抓出大半的积分错误。

**误区三**："剪力图和弯矩图的符号，书上都统一。"
你以为有唯一标准——其实**符号约定有两大流派**：一派"使梁下挠为正"（弯矩图画在受拉侧、正值画在下方，土建常用），一派"使梁上凸为正"（机械常用）。两者只差一个整体负号，零点和极值位置一模一样。真正会出事的是**同一道题里混用两套约定**：剪力图按土建画、弯矩图按机械读，得出的"危险侧"就会反过来。做题前先写一句"我采用哪套"，比事后纠结符号强。

:::

```exercise
# @title: 练习：跨中集中力的最大弯矩
# @check: 30000.0
# @hint: 两支座各分一半 P，弯矩从端点 0 直线升到跨中：Mmax = (P/2) × (L/2) = P×L/4
P = 20000.0     # 集中力（N）
L = 6.0         # 跨度（m）
Mmax = P * L    # ← 问题在这：跨中弯矩是 P×L/4，不是 P×L
print(round(Mmax, 1))
```

**练习 2**：把跨中那个 20 kN 换成 40 kN 并移到 $a = 1$ m 处（$L = 6$ m，无均布载荷）。求最大弯矩的位置与数值，并与"跨中"对比。

<details>
<summary>点开查看逐步解答</summary>

1. 支座反力：对右支座取矩，
   $$R_{左}\cdot 6 = P\,(L-a) = 40\times 5 = 200 \ \Rightarrow\ R_{左} = 33.33\ \text{kN},\quad R_{右} = 6.67\ \text{kN}$$
2. 剪力：$x<1$ 时 $V = +33.33$ kN；跨过集中力后 $V = 33.33 - 40 = -6.67$ kN，直到右支座处跳回 0 ✓；
3. 因为 $V$ 是从正**跳**到负，弯矩峰值就在集中力所在的 $x = 1$ m：
   $$M_{\max} = R_{左}\,a = 33.33\times 1 = 33.3\ \text{kN·m}$$
4. 跨中的弯矩（作对比）：
   $$M(3) = R_{左}\times 3 - P\times(3-1) = 100 - 80 = 20\ \text{kN·m}$$
5. **峰值在 $x = 1$ m 而不是跨中，数值 33.3 kN·m 比跨中高 67%**。若按"最大弯矩在跨中"的直觉配截面，会低估三分之二；
6. 校验（这条不要省）：$M(6) = 33.33\times 6 - 40\times 5 = 200 - 200 = 0$ ✓。简支梁两端弯矩必须为零，这是**一条白送的复查条件**；
7. 顺带看出规律：集中力离跨中越远，$M_{\max} = P\,a(L-a)/L$ 越小。把手推车、吊车的轮压**摆到跨中**，才是让梁最吃力的布置——做强度校核时，就要找这种最不利工况。

</details>

## 7. 选读：微分关系是怎么推出来的

<details>
<summary>选读 · 微段平衡给出 dV/dx = −q 与 dM/dx = V</summary>

在梁上取一段长度 $dx$ 的微元，左截面内力为 $V$、$M$，右截面（坐标增量为正方向）为 $V + dV$、$M + dM$，微元上受分布载荷 $q\,dx$（取向下为正）。

**竖向平衡**：
$$V - (V + dV) - q\,dx = 0 \ \Rightarrow\ \frac{dV}{dx} = -q$$

**对左截面形心取矩**（忽略 $q\,dx$ 对自身作用点的二阶小量）：
$$M + (V+dV)dx - (M + dM) - q\,dx\cdot\frac{dx}{2} = 0$$

丢掉二阶小量 $q\,dx^2/2$ 与 $dV\,dx$（两个一阶小量之积），得
$$V\,dx - dM = 0 \ \Rightarrow\ \frac{dM}{dx} = V$$

两条关系合起来就是 $\dfrac{d^2M}{dx^2} = -q$，也就是后面"梁的挠度"一课的出发点：$EI\,y'' = M(x)$。

这也解释了为什么集中力处 $V$ 跳、$M$ 连续：把集中力看成 $q$ 的一个脉冲（狄拉克函数），对 $\dfrac{dV}{dx} = -q$ 积分一次，$V$ 得到有限跳跃；再对 $\dfrac{dM}{dx} = V$ 积分，$M$ 只得到斜率的改变，函数值连续。

</details>

## 8. 下一站

弯矩图到手了，可真正的答案往往不是"哪里最危险"，而是"**它下垂了多少毫米**"。把 $M(x)$ 除以 $EI$ 再积分两次就得到挠度曲线——$\dfrac{d^2y}{dx^2} = \dfrac{M}{EI}$，这是一门货真价实的常微分方程，而且带两个边界条件。
