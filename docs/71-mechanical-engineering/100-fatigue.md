# 疲劳与 S-N 曲线

## 1. 从一个场景开始

一根旋转传动轴，材料的屈服强度 600 MPa，工作应力幅只有 220 MPa——静强度安全系数接近 3，教科书式的安全设计。

它服役三个月后断了，断口平齐、没有颈缩，看不出任何"过载"的痕迹。金相分析给出的结论是疲劳。

**关键数字是：220 MPa 的应力幅，被反复施加了大约一千万次。** 疲劳失效看的从来不是"力有多大"，而是"重复了多少次"——这是静强度思维完全覆盖不到的失效模式。

## 2. 直觉解释

拿一枚回形针。

用力慢慢掰，掰到 90° 它都不会断。但如果你在 30° 附近来回折，**二十几次就断了**——用的力小得多，只是重复了。

每一次往复，材料内部都有一点点不可逆的滑移积累下来。这些微小损伤**单次看不见，但会累加**。累加到某个临界值，一条裂纹开始稳定扩展；等剩下的截面撑不住了，就一次性脆断——所以疲劳断口总是一片光滑（裂纹慢慢磨出来的）加一片粗糙（最后瞬间撕开的）。

于是工程师用一张图记录这件事：**横坐标是循环次数 $N$（对数），纵坐标是应力幅 $S$（对数）**，测出来的点连成一条直线——这就是 S-N 曲线。

真正可怕的是这条线的"平"：在双对数坐标上，应力降低一点点，寿命就翻好几倍。**这意味着疲劳寿命对载荷极其敏感**，也意味着按平均值估算的寿命，可能和真实寿命差好几倍。

## 3. 正式定义

**Basquin 关系**（S-N 曲线在双对数坐标上的解析式）：

$$S = S_f\, N^{b} \qquad (b < 0)$$

反解得到给定应力幅下的寿命：

$$N = \left(\frac{S}{S_f}\right)^{1/b}$$

**疲劳极限** $S_e$：当 $S \le S_e$ 时，认为寿命无限（工程上约定 $N > 10^7$ 次即不再破坏，这个门槛叫**循环基数**）。

**Goodman 平均应力修正**：应力幅 $\sigma_a$ 与平均应力 $\sigma_m$ 共同决定安全性——

$$\frac{\sigma_a}{S_e} + \frac{\sigma_m}{S_{ut}} \le 1$$

等价写法：当前 $\sigma_m$ 下的许用应力幅

$$\sigma_{a,\text{allow}} = S_e\left(1 - \frac{\sigma_m}{S_{ut}}\right)$$

**Miner 线性累积损伤**（变幅载荷谱）：

$$D = \sum_i \frac{n_i}{N_i}, \qquad D \ge 1 \text{ 时失效}$$

合金钢的一组典型参数（$S_f = 1400$ MPa，$b = -0.085$，$S_e = 280$ MPa，$S_{ut} = 800$ MPa）：

| $N$（循环数） | $10^3$ | $10^4$ | $10^5$ | $10^6$ | $10^7$ |
| --- | --- | --- | --- | --- | --- |
| $S$（MPa，Basquin 值） | 778 | 640 | 526 | 433 | 356 |

注意最后两行：**Basquin 直线在 $10^7$ 处给出 356 MPa，但疲劳极限只有 280 MPa**。工程上取更保守的那个——低于 $S_e$ 就按无限寿命处理，所以这条 S-N 曲线实际是一条斜线加一条水平线。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $S$（$\sigma_a$） | 应力幅 | 帕 Pa | $(\sigma_{\max}-\sigma_{\min})/2$，**疲劳只看这部分** |
| $\sigma_m$ | 平均应力 | 帕 Pa | $(\sigma_{\max}+\sigma_{\min})/2$，拉平均应力有害 |
| $N$ | 循环数 | 次 | 到破坏为止的循环次数 |
| $S_f$ | 疲劳强度系数 | 帕 Pa | Basquin 直线在 $N=1$ 处的外推值 |
| $b$ | Basquin 指数 | — | 钢约 $-0.085$，铝约 $-0.11$ |
| $S_e$ | 疲劳极限 | 帕 Pa |  steels 有，铝/铸铁没有 |
| $S_{ut}$ | 抗拉强度 | 帕 Pa | 静强度指标（上一课的邻居） |
| $D$ | 累积损伤 | — | Miner 判据，$D=1$ 为失效 |

## 4. 分步例题

**例**：某合金钢零件 $S_f = 1400$ MPa，$b = -0.085$，$S_e = 280$ MPa，$S_{ut} = 800$ MPa。工作应力循环为 $\sigma_a = 350$ MPa、$\sigma_m = 100$ MPa。求寿命、Goodman 判定，以及把 $\sigma_a$ 降到多少才安全。

1. **Basquin 寿命**：$N = (350/1400)^{1/(-0.085)} = 0.25^{-11.76} = e^{11.76 \times 1.386} = e^{16.31} = 1.21\times10^{7}$ 次；
2. **与疲劳极限比较**：$\sigma_a = 350 > S_e = 280$，所以是**有限寿命**，$1.21\times10^{7}$ 次有效；
3. **Goodman 判定**：$\dfrac{350}{280} + \dfrac{100}{800} = 1.25 + 0.125 = 1.375 > 1$ → **会疲劳失效**；
4. **该 $\sigma_m$ 下的许用幅值**：$\sigma_{a,\text{allow}} = 280 \times (1 - 100/800) = 280 \times 0.875 = 245$ MPa；
5. **结论**：$\sigma_a$ 必须降到 **245 MPa 以下**，$1.375$ 的比值意味着要砍掉 $(1.375-1)/1.375 = 27\%$ 的应力幅；
6. **代价核算**：降到 245 MPa 后，寿命变成 $N = (245/1400)^{-11.76} = 0.175^{-11.76} = e^{11.76 \times 1.743} = e^{20.50} = 8.0\times10^{8}$ 次——**比原来多了 66 倍**。这就是双对数直线的威力：应力幅降 30%，寿命涨两个数量级；
7. **工程解读**：如果设备每天运行 8 小时、转速 1500 r/min，那么 $8\times60\times1500 = 7.2\times10^{5}$ 次/天。$1.21\times10^{7}$ 次只够 **17 天**——这就解释了开头那根轴为什么三个月就断了。

左半屏是双对数 S-N 曲线，右半屏是 Goodman 图。四件事值得做：

- **盯住左图的琥珀色工作点**：当前 $\sigma_a = 350$ MPa 落在 Basquin 直线上，水平虚线对应它、圆点标出寿命位置。读数显示约 $1.2\times10^{7}$ 次；
- **把 σa 从 350 拖到 220**：跌破绿色虚线（$S_e = 280$ MPa）后，读数直接从数字变成"**无限寿命**"。再往下拖，圆点一直贴在右边界不动；
- **盯住右图**：Goodman 直线从 $(0, S_e)$ 连到 $(S_{ut}, 0)$，下方绿色三角是安全区。当前点 $(100, 350)$ 落在直线的**上方**，圆点是红色——这就是第 3 步算出的 $1.375$。把 $\sigma_a$ 拖到 245，圆点正好压在直线上；
- **只动 σm**：从 100 拖到 400，紫色竖线（该 $\sigma_m$ 下的许用幅值）会从 245 MPa 一路缩到 140 MPa。**平均应力一分钱不花地把你的许用应力幅砍掉一半**——这就是拉平均应力的代价，也是为什么压应力（喷丸、滚压、预紧螺栓）能显著延长疲劳寿命。

最后切一下材料：

- **铝合金**（$S_e = 90$ MPa，$S_{ut} = 320$ MPa）：安全区小得多，而且真实铝合金**没有疲劳极限**，S-N 曲线会一直缓慢下降，必须在图上指定"10⁷ 次下的条件疲劳极限"才有意义；
- **铸铁**：$S_e = 120$ MPa、$S_{ut} = 300$ MPa，安全区几乎是钢的一个零头。

### 实验 2（python）：三段判据串成一条设计流水线

```python title="Basquin 算寿命、Goodman 判平均应力、Miner 累加损伤"
# sliders: sa=350 [10:700:5]
Sf = 1400e6                  # Basquin 强度系数（帕）
b = -0.085                   # Basquin 指数（负数）
Se = 280e6                   # 疲劳极限（帕）
Sut = 800e6                  # 抗拉强度（帕）
sa = 350e6                   # 工作应力幅（帕）
sm = 100e6                   # 工作平均应力（帕）


def life(S):                 # 由 Basquin 反解寿命：N = (S/Sf)^(1/b)
    return (S / Sf) ** (1 / b)


print("σa(MPa)   寿命")
for mp in [220, 280, 350, 400, 500]:
    S = mp * 1e6
    tag = "无限寿命（低于 Se）" if S <= Se else f"{life(S):.3e} 次"
    print(f"{mp:6d}   {tag}")

ratio = sa / Se + sm / Sut                       # Goodman 判据
allow = Se * max(0.0, 1 - sm / Sut)              # 该 σm 下的许用应力幅
print(f"\n工作点 σa={sa / 1e6:.0f} MPa, σm={sm / 1e6:.0f} MPa")
print(f"Goodman 比值 = {ratio:.3f} → {'安全' if ratio <= 1 else '会疲劳失效'}")
print(f"该 σm 下许用应力幅 = {allow / 1e6:.1f} MPa")

# Miner 线性累积损伤：一天之内两段载荷谱
blocks = [(400e6, 2000), (300e6, 50000)]         # (应力幅, 每天循环次数)
D = 0.0
for S, n in blocks:
    D += n / life(S)
print(f"\n每天累积损伤 D = {D:.4e} → 预计 {1 / D:.0f} 天 ≈ {1 / D / 365:.1f} 年")
```

输出大概是：寿命表依次是 `无限寿命 / 无限寿命 / 1.211e+07 / 2.517e+06 / 1.823e+05`（最后一行 500 MPa 撑不到二十万次），Goodman 比值 `1.375 会疲劳失效`，许用幅值 `245.0 MPa`，日损伤 `1.47e-03` → 约 **681 天**。

这段代码把三件事串成了一条流水线：**查寿命（Basquin）→ 判平均应力（Goodman）→ 累加谱载（Miner）**，真实的疲劳校核就是这么走的。

把 `blocks` 里第一项改成 `(400e6, 20000)`（每天高应力循环翻十倍）再跑，寿命会掉到 200 天左右——**高应力段虽然只占循环数的 4%，却吃掉了一半以上的损伤**。这就是为什么减振、降载、避免冲击比加大截面更有效。

### 快问快答

```quiz
某钢制零件的工作应力幅为 200 MPa，材料疲劳极限为 280 MPa。下面哪种说法正确？
- 应力幅低于疲劳极限，绝对不会疲劳失效
- 只有在平均应力足够小、且满足 Goodman 判据时，才谈得上无限寿命 [*]
- 只要静强度安全系数大于 2 就不会疲劳
- 疲劳极限是材料常数，与表面质量和尺寸无关
? 200 MPa 虽低于 280 MPa 的疲劳极限，但 Goodman 判据是 σa/Se + σm/Sut ≤ 1；有拉平均应力时许用幅值要降到 Se(1−σm/Sut)，200 MPa 完全可能越线。而且疲劳极限本身只是「10⁷ 次循环不破坏」的工程约定，不是字面意义的永远。
```

:::warning[常见误区]

**误区一**："工作应力远低于屈服强度，就永远不会疲劳失效。"
你在用静强度思维看疲劳——疲劳是**局部、累积、循环**的过程，与屈服强度没有直接关系。应力集中（孔、台阶、键槽、刀痕、夹杂物）会让局部应力达到名义值的 2~4 倍，裂纹就在那里起。工程上的疲劳极限 $S_e$ 通常只有抗拉强度的 0.3~0.5 倍，而且**必须再乘上一串修正系数**（表面质量、尺寸、温度、可靠性）才能用。名义应力"看起来很安全"是疲劳事故最常见的开场白。

**误区二**："所有材料都有疲劳极限，低于它就无限寿命。"
你以为钢的经验可以外推——**只有钢和钛合金有明显的疲劳极限**。铝合金、镁合金、铸铁的 S-N 曲线会一直缓慢下降，不存在真正的水平段。对它们必须说清"$N = 5\times10^8$ 次下的条件疲劳极限"，否则数字毫无意义。这也是为什么飞机（铝合金为主）采用**安全寿命/损伤容限**设计并强制定期探伤，而钢制桥梁可以按"无限寿命"设计。

**误区三**："疲劳寿命是材料的一个确定数值。"
你以为查表就得到一个数——同一批试样在完全相同的应力水平下，寿命可以相差 **一个数量级**。S-N 曲线本身是**对一批数据的统计拟合**（这正是它归到统计推断章下的原因），工程图纸上的曲线通常是**存活率 97.7%（−2σ）的下限**。所以疲劳设计必须同时给出可靠度，并且高频次的关键件要做**无损探伤 + 定期更换**，而不是"算出来够就不管了"。

:::

**练习 2**：某零件材料参数同上，一天的工作谱为：$\sigma_a = 450$ MPa 循环 500 次，$\sigma_a = 320$ MPa 循环 20000 次。求每天累积损伤与预计寿命（天）。若要求寿命达到 10 年（3650 天），所有应力幅需整体下调百分之多少？

<details>
<summary>点开查看逐步解答</summary>

1. $N_1 = (450/1400)^{-11.76} = 0.3214^{-11.76} = e^{11.76 \times 1.135} = e^{13.35} = 6.30\times10^{5}$ 次；
2. $N_2 = (320/1400)^{-11.76} = 0.2286^{-11.76} = e^{11.76 \times 1.476} = e^{17.36} = 3.47\times10^{7}$ 次；
3. 每天损伤：$D = \dfrac{500}{6.30\times10^{5}} + \dfrac{20000}{3.47\times10^{7}} = 7.94\times10^{-4} + 5.76\times10^{-4} = 1.370\times10^{-3}$；
4. 预计寿命：$1/D = 730$ 天 ≈ 2.0 年；
5. 要撑 3650 天，需要 $D \le 1/3650 = 2.74\times10^{-4}$，即损伤降为原来的 $2.74/13.70 = 0.200$ 倍；
6. 设应力幅整体乘以 $k$。由 $N \propto S^{1/b} = S^{-11.76}$，寿命变为 $k^{-11.76}$ 倍，损伤变为 $k^{11.76}$ 倍。令 $k^{11.76} = 0.200$，得 $k = 0.200^{1/11.76} = e^{\ln 0.200 / 11.76} = e^{-1.609/11.76} = e^{-0.1369} = 0.872$；
7. **结论：应力幅只需下调 12.8%，寿命就能从 2 年拉到 10 年。**

第 6 步是这道题的精髓：双对数 S-N 曲线上，寿命对载荷的敏感度是 $|1/b| \approx 12$ 次方。**降载 13% 换 5 倍寿命**，比换材料、加截面都划算——这也是为什么减振和降低动载在疲劳问题里永远是第一选择。

## 7. 选读：为什么是幂律，以及 Miner 从哪来

<details>
<summary>选读 · 双对数直线与线性累积损伤的来历</summary>

**为什么 S-N 在双对数坐标上是直线？** 假设每次循环造成的损伤增量正比于当前的损伤、也正比于应力幅的某个幂次：

$$\frac{dD}{dN} = C\,\sigma_a^{\,m}$$

从 $D=0$ 积分到失效（$D=1$），得 $1 = C\sigma_a^m N$，即

$$\sigma_a^m N = \text{常数} \quad\Longrightarrow\quad \sigma_a = (\text{常数})^{1/m} N^{-1/m}$$

对比 Basquin 的 $S = S_f N^b$，立刻看出 $b = -1/m$。钢的 $b = -0.085$ 对应 $m \approx 11.8$——**这就是练习 2 里那个"12 次方敏感度"的来源**。所以幂律不是凑出来的经验式，它有"损伤速率是应力的幂函数"这个假设在背后。

取对数：$\log S = \log S_f + b \log N$。在 $(\log N, \log S)$ 平面上这就是一条直线，斜率 $b$。实验数据点在双对数纸上确实近似共线——**这就是为什么疲劳试验报告一律用双对数坐标**，也是为什么把 $\log S$ 对 $\log N$ 做线性回归（统计推断章的最小二乘）是求 $S_f$ 和 $b$ 的标准做法。

**Miner 法则从哪来？** 上面那个式子可以写成"在应力 $S_i$ 下，一次循环消耗总寿命的 $1/N_i$"。Miner 假设**不同应力水平下的损伤可以线性相加，且与加载顺序无关**：

$$D = \sum_i \frac{n_i}{N_i}$$

$D = 1$ 时失效。这个假设粗糙但极其好用，至今仍是所有工程疲劳规范的骨架。

它哪里不对？两个已知的系统性偏差：

- **顺序效应**：先高后低（高应力先萌生裂纹，低应力再扩展）实测 $D_f < 1$；先低后高（低应力"锻炼"产生残余压应力）实测 $D_f > 1$。真实构件的 $D_f$ 常在 $0.6\sim1.5$ 之间；
- **低于疲劳极限的载荷**：Miner 认为它们零损伤，但高应力之后的低应力照样能扩展已有裂纹。

所以 Miner 给的是**量级正确的估算**，设计时必须配合安全系数（关键件常取 $D_f = 0.3\sim0.5$ 就判废）和定期探伤。现代方法（裂纹扩展 Paris 律 $da/dN = C\Delta K^m$）能处理顺序效应，但需要断裂力学和初始缺陷尺寸——那是研究选修的内容。

</details>
