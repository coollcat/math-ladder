# 热传递：导热、对流与辐射三条路

## 1. 从一个场景开始

一杯热咖啡放在桌上，会怎样？它在冷却——**但热量究竟是怎么"走"出去的？**

贴着杯壁的咖啡把热传给杯壁（**导热**），杯壁把热传给流动的空气（**对流**），同时杯子和咖啡都在向房间辐射红外线（**辐射**）。三条路同时开工。

而驱动这一切的，只有一件事：**温度差**。没有温差，热传递立刻停摆——这是热力学第二定律最朴素的样子。

## 2. 直觉解释

三条路可以用三个类比记住：

**导热**——像传递接力棒。热量从"热的地方"一个分子一个分子地传给邻居，分子本身不搬家。金属里还有自由电子帮忙，所以金属导热快（也能导电，这不是巧合）。

**对流**——像搬家公司。流体自己带着热跑：热空气上升、冷空气补位，形成环流。**没有流体流动就没有对流**。这也是为什么风扇能让人凉快——它增强了对流。

**辐射**——像太阳光。不需要任何介质，真空中也能传。**所有有温度的物体都在辐射**，温度越高辐射越猛（四次方！）。

## 3. 正式定义

**傅里叶定律（导热）**：

$$q = -kA\frac{dT}{dx}$$

负号表示热从高温流向低温。$k$ 是导热系数（W/(m·K)）。

**牛顿冷却定律（对流）**：

$$q = hA(T_s - T_\infty)$$

$h$ 是对流换热系数，**它不是材料的性质，而是"整个流动状况"的打包结果**（受流速、黏度、几何形状影响）。

**Stefan–Boltzmann 定律（辐射）**：

$$q = \varepsilon\sigma A(T^4 - T_{sur}^4)$$

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $q$ | 热流率 | 单位时间通过的热量（W） |
| $k$ | 导热系数 | 材料属性，金属大、保温材料小 |
| $h$ | 对流系数 | 流动条件决定，空气自然对流约 5–25 |
| $\varepsilon$ | 发射率 | 0~1，理想黑体为 1 |
| $\sigma$ | Stefan–Boltzmann 常数 | $5.67\times10^{-8}$ W/(m²·K⁴) |
| $T$ | 绝对温度 | **必须用开尔文**，四次方项对数值极敏感 |
| $R$ | 热阻 | $R = \Delta T/q$，与电路电阻同构 |

**热阻串联**（多层壁稳态导热）：

$$q = \frac{T_{hot} - T_{cold}}{\sum R_i}, \qquad R_{cond} = \frac{L}{kA}, \qquad R_{conv} = \frac{1}{hA}$$

**集总参数模型**（牛顿冷却，一阶 ODE）：

$$\rho c V\frac{dT}{dt} = -hA(T - T_\infty)$$

解得指数衰减，时间常数 $\tau = \dfrac{\rho cV}{hA}$。

## 4. 分步例题

**例 1（单层壁导热）**：玻璃窗 $A = 2\ \text{m}^2$、厚 $L = 6$ mm、$k = 0.8$ W/(m·K)，室内 $20°C$、室外 $-5°C$。

1. 热阻 $R = L/(kA) = 0.006/(0.8\times2) = 0.00375$ K/W；
2. 温差 $\Delta T = 25$ K；
3. $q = 25/0.00375 \approx 6667$ W。

**单层玻璃损失 6.7 kW**——这就是双层玻璃存在的理由（中间夹一层空气，$k$ 从 0.8 掉到 0.026）。

**例 2（多层壁：热阻串联）**：墙由三层组成——内抹灰 $L_1=0.02, k_1=0.8$；砖 $L_2=0.24, k_2=0.6$；外保温 $L_3=0.05, k_3=0.04$。取 $A=1\ \text{m}^2$，内外温差 $20$ K。

1. $R_1 = 0.02/0.8 = 0.025$；
2. $R_2 = 0.24/0.6 = 0.40$；
3. $R_3 = 0.05/0.04 = 1.25$；
4. $R_{total} = 1.675$ K/W，$q = 20/1.675 \approx 11.9$ W。

**保温层只占厚度的 16%，却贡献了 75% 的热阻**——工程直觉：**最外层的低 $k$ 材料决定了整面墙的保温性能**。

**例 3（辐射为什么高温才主导）**：一块 $A=1\ \text{m}^2$、$\varepsilon=0.9$ 的板，分别计算在 $27°C$（300 K）与 $927°C$（1200 K）时的辐射功率（对 $0$ K 环境）。

- 300 K：$q = 0.9\times5.67\times10^{-8}\times(300^4 - 0) \approx 413$ W；
- 1200 K：$q = 0.9\times5.67\times10^{-8}\times 1200^4 \approx 105\,700$ W。

**温度涨 4 倍，辐射涨 $4^4 = 256$ 倍**。所以常温设备散热主要靠对流，而炉子、发动机排气管的红热部分主要靠辐射——**工程上要按温度区间选主导机理**。

现在把多层壁热阻串联算清楚，并找出"哪一层决定保温"：

```python title="多层壁：热阻串联与界面温度"
def wall_profile(layers, T_hot, T_cold, A):
    """layers: [(厚度 m, 导热系数 k)]，返回每层热阻、热流与界面温度"""
    Rs = [L / (k * A) for L, k in layers]
    R_total = sum(Rs)
    q = (T_hot - T_cold) / R_total
    temps = [T_hot]
    for R in Rs:
        temps.append(temps[-1] - q * R)      # 每层降的温度 = q × 该层热阻
    return Rs, R_total, q, temps

layers = [(0.02, 0.8), (0.24, 0.6), (0.05, 0.04)]   # 抹灰、砖、保温
Rs, Rt, q, temps = wall_profile(layers, 20.0, 0.0, 1.0)

print(f"总热阻 {Rt:.4f} K/W，热流 {q:.2f} W")
for i, (R, (L, k)) in enumerate(zip(Rs, layers)):
    share = R / Rt * 100
    print(f"  第{i+1}层（厚 {L*100:.0f} mm, k={k}）：R={R:.4f}（占 {share:.1f}%）"
          f"  {temps[i]:.2f}°C → {temps[i+1]:.2f}°C")
```

输出会显示保温层占了约 75% 的热阻——**"最不导热的层说了算"**，这是保温设计的第一原则。

再做集总参数冷却的显式迭代（欧拉法，回扣第 22 章）：

```python title="牛顿冷却：用欧拉法迭代出温度曲线"
import math

rho, c, V = 7800.0, 460.0, 1e-4        # 钢球：密度、比热、体积
h, A = 25.0, 0.01                       # 对流系数、表面积
T0, T_inf = 200.0, 25.0                 # 初温、环境温度
tau = rho * c * V / (h * A)             # 时间常数
print(f"时间常数 τ = {tau:.2f} s")

dt = 0.5
T = T0
t = 0.0
rows = []
while t < 200:
    dT = -h * A * (T - T_inf) / (rho * c * V) * dt    # 显式欧拉一步
    T = T + dT
    t = t + dt
    if abs(t % 20) < dt / 2:
        rows.append((round(t), round(T, 2)))

print(f"{'t (s)':>8}{'T (°C)':>10}{'理论值':>12}")
for tt, TT in rows:
    theory = T_inf + (T0 - T_inf) * math.exp(-tt / tau)
    print(f"{tt:>8}{TT:>10.2f}{theory:>12.2f}")
```

迭代结果与解析解 $T = T_\infty + (T_0-T_\infty)e^{-t/\tau}$ 几乎重合——**数值法与解析法互相验证**，这也是第 22 章欧拉法在工程里的第一次真实兑现。

最后看辐射比导热的"四次方优势"：

```python
sigma = 5.67e-8
eps, A = 0.9, 1.0
print(f"{'温度 °C':>10}{'温度 K':>10}{'辐射功率 W':>14}")
for celsius in [27, 127, 327, 727, 927]:
    T = celsius + 273.15
    q = eps * sigma * A * T ** 4
    print(f"{celsius:>10}{T:>10.1f}{q:>14.1f}")
print("注意 927°C 与 27°C 的比值 —— 温度涨 4 倍，辐射涨约 256 倍")
```

### 快问快答

```quiz
室温下的散热器，主要靠哪种方式把热送出去？
- 辐射，因为常温物体也在辐射红外线
- 对流，空气流动带走了大部分热量 [*]
- 导热，因为金属导热快
? 常温下导热的温差与面积都有限，而辐射功率在低温度时很小（与 T⁴ 成正比）。散热器的主要散热路径是空气流过翅片表面时的对流，这也是翅片要增大表面积的原因。
```

:::warning[常见误区]

**误区一**："辐射一定要高温才发生。" 
所有有温度的物体**都在**辐射，包括你自己（红外热像仪就是这么看你的）。只是辐射功率 $\propto T^4$，低温时小到可忽略——**"可忽略"不等于"不发生"**。

**误区二**："$h$ 是空气的常数。" 
$h$ 不是材料属性，是**流动条件的打包结果**。同一块板，静止空气里 $h \approx 5$，吹风扇时 $h$ 可以到 100，强制水冷能到上万。所以查表得到的 $h$ 必须看清适用条件。

**误区三**："温度翻倍，辐射翻倍。" 
是 $2^4 = 16$ 倍。四次方意味着**高温区间辐射会突然变成主角**——炉膛、燃烧室、发动机排气的高温段，设计时根本不能忽略辐射。

**误区四**："热阻串联和电路一样可以随便加。" 
公式形式一样，但热传递多了一条**并联的辐射通路**，而且对流和辐射会互相影响（表面温度改变会同时改变两者）。另外接触面之间还有**接触热阻**（两表面不可能完美贴合），工程上常被忽略但可能是主要误差来源。

:::

## 7. 选读：为什么对流系数这么难算

<details>
<summary>选读 · 边界层是全部麻烦的来源</summary>

导热有漂亮的公式（$R = L/kA$），为什么对流只能给一个经验系数 $h$？

因为**对流 = 导热 + 流体搬运**，而流体搬运的细节由边界层决定。

贴着壁面的一薄层流体是几乎不动的（**速度边界层**），热量在这层里只能靠**导热**穿过；而这层有多薄，取决于流体是层流还是湍流：

- **层流边界层**：厚度大、导热路径长 → $h$ 小；
- **湍流边界层**：涡旋把热量"搅拌"上去，层变薄 → $h$ 可以大好几倍。

于是计算 $h$ 就变成了计算边界层——而边界层方程没有一般解析解，只能靠无量纲数关联式。工程上用的经典形式是

$$Nu = \frac{hL}{k} = C\cdot Re^m\cdot Pr^n$$

其中 $Nu$ 是 Nusselt 数（无量纲的 $h$）、$Re$ 是上一课的雷诺数、$Pr$ 是普朗特数（动量扩散与热扩散之比）。$C,m,n$ 由实验拟合——**这就是为什么查表得到的每个 $h$ 公式都拖着一串适用条件**。

看清这条链：**流态 → 边界层厚度 → 导热路径 → $h$ → 换热量**。上一课的雷诺数在这里第二次登场，它不是只用来"判断层流湍流"，而是整条换热计算链的入口。
</details>
