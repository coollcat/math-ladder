# 流体基础：连续性、伯努利与雷诺数

## 1. 从一个场景开始

一根水管，中间捏细一段。为什么**捏细的地方水流更快**？为什么**那里的压强反而更低**，甚至能把旁边的液体吸上来？

固体力学里你学会了问"这根杆会不会断"；流体力学要问的问题完全不同——**它连形状都不固定，你抓不住任何一个"质点"**，只能跟踪流量、压强和速度场。

这一课把流体力学最基础的三件工具搭起来：**连续性方程**（质量守恒）、**伯努利方程**（能量守恒）、**雷诺数**（判断流态的无量纲尺子）。

## 2. 直觉解释

**连续性**说白了就是"不能凭空多出来或消失"。

水在管子里流，如果细的地方流速不变，那就意味着细段的流量比粗段小——水在管子里堆积起来了。但水几乎不可压缩，堆不住，所以**细处必须流得更快**。这和高速公路收窄车道时的堵车逻辑正好相反：车能堆积，水不能。

**伯努利**说的是"能量的三份账"。

一段流体带着三种能量走：**压强能**（被后面推着）、**动能**（跑得快）、**势能**（站得高）。总账守恒——**其中一份变大，另一份必然变小**。所以流速快的地方，压强能就得让位，压强就低。这就是"捏细管子会吸东西"的原因，也是机翼升力和喷雾器的共同原理。

**雷诺数**回答的是"流得顺不顺"。

水流得快、管子粗、黏性小的时候，流动开始变得混乱、出现涡旋——从**层流**变成**湍流**。判断标准不用靠眼睛看，算一个无量纲数就行。

## 3. 正式定义

**连续性方程**（不可压缩流体）：

$$A_1v_1 = A_2v_2$$

即 $Q = Av = $ 常数（体积流量守恒）。截面变小，速度必须变大。

**伯努利方程**（理想不可压缩流体，沿一条流线）：

$$p + \tfrac12\rho v^2 + \rho g h = \text{常数}$$

| 符号 | 名字 | 说明 |
| --- | --- | --- |
| $p$ | 压强 | 单位体积的压强能（Pa） |
| $\frac12\rho v^2$ | 动压 | 单位体积的动能 |
| $\rho g h$ | 静压 | 单位体积的重力势能 |
| $A$ | 截面积 | 管道横截面（m²） |
| $v$ | 流速 | 沿流向的平均速度（m/s） |
| $Q$ | 体积流量 | 每秒通过的体积（m³/s） |
| $\mu$ | 动力黏度 | 流体"内部摩擦"的强度 |

**雷诺数**：

$$Re = \frac{\rho v L}{\mu} = \frac{vL}{\nu}$$

其中 $L$ 是特征长度（管流里取直径），$\nu = \mu/\rho$ 是运动黏度。

| 流态 | 判据（圆管） |
| --- | --- |
| 层流 | $Re < 2300$ |
| 过渡区 | $2300 < Re < 4000$ |
| 湍流 | $Re > 4000$ |

**沿程损失**（达西–魏斯巴赫，工程落点）：

$$h_f = f\cdot\frac{L}{D}\cdot\frac{v^2}{2g}$$

$f$ 是摩擦系数（层流时 $f = 64/Re$，湍流查 Moody 图）。**管道设计必须算它**，否则选出来的泵压不够。

## 4. 分步例题

**例 1（变径管：流速与压强一起算）**：水平水管，粗处 $D_1 = 100$ mm、$v_1 = 1$ m/s、$p_1 = 200$ kPa，细处 $D_2 = 50$ mm。取水密度 $\rho = 1000\ \text{kg/m}^3$。

1. 截面比：$A \propto D^2$，所以 $A_1/A_2 = (100/50)^2 = 4$；
2. 由连续性：$v_2 = v_1\cdot A_1/A_2 = 4$ m/s；
3. 水平管 $h_1 = h_2$，伯努利给 $p_1 + \frac12\rho v_1^2 = p_2 + \frac12\rho v_2^2$；
4. 代入：$p_2 = 200000 + \frac12\cdot1000\cdot(1^2 - 4^2) = 200000 - 7500 = 192500$ Pa。

**细处流速 4 倍，压强降了 7.5 kPa**——管子越细，吸力越强。

**例 2（文丘里管测流量）**：例 1 里若细处接一根竖直测压管，高度差

$$\Delta h = \frac{p_1 - p_2}{\rho g} = \frac{7500}{1000\times9.8} \approx 0.765\ \text{m}$$

**由高度差反推流量**，这就是文丘里流量计的全部原理——**不需要装任何电子元件，只靠几何与伯努利**。

**例 3（雷诺数判断流态）**：水在 $D = 20$ mm 管内以 $v = 0.5$ m/s 流动，$\nu = 1\times10^{-6}\ \text{m}^2/\text{s}$（20°C 水）。

$$Re = \frac{0.5 \times 0.02}{10^{-6}} = 10\,000$$

$Re = 10^4 > 4000$，**湍流**。若把流速降到 $0.05$ m/s，$Re = 1000 < 2300$，变回层流。

**同一个管子，快慢不同就是两种物理。** 这是流体力学最反直觉的地方：方程是同一个，但湍流至今没有解析解。

横轴是流速，纵轴是动压。流速翻倍（1→2），动压涨 4 倍——**这就是细处压强骤降的幕后推手**。

现在把例 1 完整算一遍，并扫一遍管径：

```python title="变径管：连续性 + 伯努利一次性算清"
rho = 1000.0                          # 水的密度 kg/m³
g = 9.8

D1, v1, p1 = 0.10, 1.0, 200000.0      # 粗段：直径 0.1 m、流速 1 m/s、压强 200 kPa
D2 = 0.05                             # 细段直径

A1 = 3.141592653589793 * (D1 / 2) ** 2   # 圆面积 π(d/2)²
A2 = 3.141592653589793 * (D2 / 2) ** 2

v2 = v1 * A1 / A2                     # 连续性方程：A1v1 = A2v2
p2 = p1 + 0.5 * rho * (v1 ** 2 - v2 ** 2)   # 伯努利（水平管，势能项抵消）

print(f"粗段：A = {A1:.6f} m², v = {v1} m/s, p = {p1/1000:.3f} kPa")
print(f"细段：A = {A2:.6f} m², v = {v2} m/s, p = {p2/1000:.3f} kPa")
print(f"压强下降 {(p1 - p2)/1000:.3f} kPa，等效水柱高 {(p1-p2)/(rho*g):.4f} m")
```

再扫一遍"细段直径"，看吸力怎么随管径放大：

```python
rho, g = 1000.0, 9.8
D1, v1, p1 = 0.10, 1.0, 200000.0
A1 = 3.141592653589793 * (D1 / 2) ** 2

print(f"{'细段直径 mm':>12}{'流速 m/s':>12}{'压强 kPa':>12}{'水柱高 m':>12}")
for D2 in [0.09, 0.075, 0.06, 0.05, 0.04, 0.03]:
    A2 = 3.141592653589793 * (D2 / 2) ** 2
    v2 = v1 * A1 / A2
    p2 = p1 + 0.5 * rho * (v1 ** 2 - v2 ** 2)
    if p2 < 0:
        print(f"{D2*1000:>12.0f}{v2:>12.2f}{'——':>12}{'空化！':>12}")
        continue                          # 压强不可能为负：液体已汽化（空化）
    print(f"{D2*1000:>12.0f}{v2:>12.2f}{p2/1000:>12.2f}{(p1-p2)/(rho*g):>12.4f}")
```

D2 缩到 30 mm 时压强算出负值——**物理上不可能**。真实情况是水在那一处**汽化**（空化），产生气泡并侵蚀管壁。伯努利方程在这里给你发出了一条真实的工程红线：**水泵与阀门不能装在过细的喉部**。

最后算雷诺数，看同一根管子的两种流态：

```python
nu = 1e-6                             # 20°C 水的运动黏度 m²/s
D = 0.02
print(f"{'流速 m/s':>10}{'Re':>12}{'流态':>10}")
for v in [0.02, 0.05, 0.1, 0.2, 0.5, 1.0]:
    Re = v * D / nu
    state = "层流" if Re < 2300 else ("过渡" if Re < 4000 else "湍流")
    print(f"{v:>10.2f}{Re:>12.0f}{state:>10}")
```

同一个管子，流速从 0.02 升到 1.0，雷诺数跨过层流、过渡、湍流三档——**流态由无量纲数决定，而不是由"水还是油"决定**。

### 快问快答

```quiz
管子变细时，为什么流速必须变大？
- 因为细处的压强更大，推着水快跑
- 因为不可压缩流体不能堆积，通过的体积流量必须相等 [*]
- 因为摩擦力在细处更小
? 连续性方程 A1v1 = A2v2 表达的是体积流量守恒。水几乎不可压缩，细处的截面小了，单位时间要过同样的体积，速度就得相应地提高。
```

:::warning[常见误区]

**误区一**："流速快所以压强也大。" 
正好相反。伯努利方程说的是总账守恒，**动压越大，压强能越小**。捏细软管时水喷得又快又急，但你从侧面感觉那里的"压力"反而更低——这正是雾化器和化油器的工作基础。

**误区二**："伯努利方程随便用。" 
它的适用条件是：**理想（无黏性）流体、不可压缩、定常流动、沿同一条流线**。真实管道有黏性摩擦，所以工程上要在伯努利两侧加上损失项 $h_f$，否则算出来的压强会偏高。

**误区三**："同一根管子里的流动，流态是固定的。" 
不是。流态由 $Re = vL/\nu$ 决定——**同一根管子，流速变了流态就变**。而且湍流不是"更快"，是"更混乱"：一旦跨过临界雷诺数，压降会突然按 $v^{1.75\sim2}$ 上升，泵的功率需求也跟着跳。

**误区四**："缩小管径总能让流量变大。" 
不会。管径缩小会让阻力（沿程损失 $\propto 1/D^5$）急剧上升，**总流量反而可能下降**。系统里实际流量由泵的扬程曲线与管路阻力曲线的交点决定——这是流体系统设计里最常被忽略的一点。

:::

**练习 2**：一根消防水带，出口直径从 65 mm 换成 25 mm 的喷嘴，泵送流量 $Q = 0.005$ m³/s。求两种情况的流速，并判断喷嘴处会不会出现空化（假设入口压强 400 kPa，忽略高度差与损失）。

<details>
<summary>点开查看逐步解答</summary>

流量相同，管径从 65 mm 变 25 mm，面积比是 $(65/25)^2 = 6.76$。

**没有喷嘴时**：$A = \pi(0.0325)^2 = 3.318\times10^{-3}$ m²，$v = Q/A = 1.51$ m/s。

**加喷嘴后**：$A = \pi(0.0125)^2 = 4.909\times10^{-4}$ m²，$v = 0.005/4.909\times10^{-4} = 10.19$ m/s。

**压强**（伯努利）：

```python
rho = 1000.0
Q = 0.005
for D in [0.065, 0.025]:
    A = 3.141592653589793 * (D / 2) ** 2
    v = Q / A
    p = 400000 - 0.5 * rho * v ** 2      # 从静止压 400 kPa 起算
    print(f"D={D*1000:.0f} mm  v={v:.2f} m/s  p={p/1000:.2f} kPa")
```

喷嘴处 $v \approx 10.2$ m/s，$\frac12\rho v^2 \approx 51.9$ kPa，压强从 400 kPa 降到约 348 kPa——**远大于零，不会空化**。

但如果把入口压强降到 100 kPa，喷嘴处就会出现负压（物理上意味着空化），消防水枪此时会喷出断续的汽水混合物。**这就是高压水枪必须有最小工作压力的原因。**
</details>

## 7. 选读：伯努利与欧拉方程的关系

<details>
<summary>选读 · 从牛顿第二定律到伯努利</summary>

伯努利方程不是凭空冒出来的，它是**牛顿第二定律在流线上的积分**。

取一小段流体，长度 $\delta s$、截面积 $A$。沿流向的合力来自两侧压强差（$-\frac{dp}{ds}\delta s\cdot A$）和重力分量。牛顿第二定律给出**欧拉方程**：

$$\rho\frac{Dv}{Dt} = -\frac{dp}{ds} - \rho g\frac{dh}{ds}$$

定常流动时 $\frac{Dv}{Dt} = v\frac{dv}{ds}$（速度只随位置变），代入：

$$\rho v\frac{dv}{ds} = -\frac{dp}{ds} - \rho g\frac{dh}{ds}$$

两边同乘 $ds$ 并沿流线积分：

$$\int \rho v\,dv = -\int dp - \int \rho g\,dh$$

$$\frac12\rho v^2 = -p - \rho g h + C$$

移项就是伯努利方程：

$$p + \tfrac12\rho v^2 + \rho gh = C$$

**看清两个前提是怎么进来的**：① "定常"让 $\partial v/\partial t$ 消失；② "无黏"让剪切应力项整项不见。真实流动里这两项都在，所以工程上只能把它们打包成损失项 $h_f$ 加在等式右边。

**这也说明了为什么伯努利方程"算不准真实管道"**——它本身就是理想化的产物，不是万能的。
</details>
