# 扭转与轴设计

## 1. 从一个场景开始

一根直径 40 mm 的实心钢传动轴，长 1.2 米，传递 400 N·m 的扭矩。算下来最大剪应力只有 31.8 MPa，钢的许用剪应力是 160 MPa——**强度富余五倍**，看起来非常安全。

可装到设备上，末端的编码器却报出角度偏差：整根轴扭转了 **1.39°**。对伺服系统来说这已经超出定位精度要求了。

强度够了，刚度不够。而扭转刚度的旋钮，是直径的**四次方**。

## 2. 直觉解释

把一根圆轴想象成**一捆套在一起的薄壁圆管**。

扭起来之后，每一层圆管都转过**同一个角度** $\phi$（它们被胶合在一起，是同一根轴）。但外层的管子走的路程更长——周长是 $2\pi r$，所以它扭得更"斜"。

越斜，剪应变越大；剪应变越大，剪应力越大。于是：**剪应力从圆心（为零）一路线性涨到外表面（最大）。**

这就是扭转最重要的图像——**圆心那块材料几乎在偷懒**。既然中心贡献小，那就把中心挖掉做成空心轴：重量省一大截，强度和刚度损失却很小。

至于"四次方"：外圈材料既离得远（应力 $\propto r$），力臂也长（力矩 $\propto r$），两个 $r$ 相乘再沿面积积分，就攒出了 $d^4$。

## 3. 正式定义

**剪应力沿半径线性分布**（$r$ 为该点到轴心的距离）：

$$\tau(r) = \frac{T\,r}{J}, \qquad \tau_{\max} = \frac{T\,R}{J} = \frac{T\,c}{J}$$

**扭转角**（等截面、等扭矩，长度 $L$）：

$$\phi = \frac{TL}{GJ} \quad(\text{弧度}), \qquad \frac{\phi}{L} = \frac{T}{GJ}$$

**极惯性矩**（扭转惯量）：

| 截面 | 极惯性矩 $J$ | 抗扭截面系数 $W_t = J/c$ |
| --- | --- | --- |
| 实心圆，直径 $d$ | $J = \dfrac{\pi d^4}{32}$ | $W_t = \dfrac{\pi d^3}{16}$ |
| 空心圆，外径 $d_o$ 内径 $d_i$ | $J = \dfrac{\pi(d_o^4 - d_i^4)}{32}$ | $W_t = \dfrac{\pi(d_o^4-d_i^4)}{16\,d_o}$ |

**抗扭刚度** $GJ/L$（单位 N·m/rad），与它配套的**强度条件**和**刚度条件**：

$$\tau_{\max} \le [\tau], \qquad \frac{\phi}{L} \le \left[\frac{\phi}{L}\right]$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $T$ | 扭矩 | 牛·米 N·m | 由功率和转速换算：$T = 9550\,P/n$（$P$：kW，$n$：r/min） |
| $J$ | 极惯性矩 | m⁴ | $\propto d^4$，只跟截面几何有关 |
| $G$ | 剪切弹性模量 | 帕 Pa | 钢约 79 GPa，铝 26 GPa |
| $\tau$ | 剪应力 | 帕 Pa | 与拉压的正应力垂直方向不同 |
| $\phi$ | 扭转角 | 弧度 rad | 两端面的相对转角 |
| $c$（或 $R$） | 外半径 | 米 m | $\tau$ 最大的位置 |

## 4. 分步例题

**例**：实心钢轴 $d = 40$ mm，$L = 1.2$ m，$T = 400$ N·m，$G = 79$ GPa，$[\tau] = 160$ MPa。求最大剪应力与扭转角，并判断是否满足 $[\phi/L] = 0.5\ ^\circ/\text{m}$ 的刚度要求。

1. **极惯性矩**：$J = \dfrac{\pi d^4}{32} = \dfrac{\pi \times 0.04^4}{32} = \dfrac{\pi \times 2.56\times10^{-6}}{32} = 2.513\times10^{-7}$ m⁴；
2. **最大剪应力**（$c = d/2 = 0.02$ m）：$\tau_{\max} = \dfrac{Tc}{J} = \dfrac{400 \times 0.02}{2.513\times10^{-7}} = 3.183\times10^{7}$ Pa $= 31.8$ MPa；
3. **强度校核**：$31.8 \le 160$ MPa ✓，强度利用率只有 **19.9%**；
4. **扭转角**：$\phi = \dfrac{TL}{GJ} = \dfrac{400 \times 1.2}{79\times10^{9} \times 2.513\times10^{-7}} = \dfrac{480}{1.985\times10^{4}} = 2.418\times10^{-2}$ rad $= 1.385^\circ$；
5. **刚度校核**：$\phi/L = 1.385 / 1.2 = 1.154\ ^\circ/\text{m} > 0.5\ ^\circ/\text{m}$ ✗ **刚度不合格**；
6. **改法一（加粗）**：需要 $\phi/L$ 降到 0.5，即 $J$ 提高到 $1.154/0.5 = 2.31$ 倍。$J \propto d^4$，所以 $d' = 40 \times 2.31^{1/4} = 40 \times 1.233 = 49.3$ mm，取标准值 **50 mm**；
7. **改法二（换材料？）**：铝的 $G = 26$ GPa，只有钢的 1/3，换铝刚度直接差三倍——**传动轴不换铝，这是硬规矩**；
8. **改法三（空心化）**：保持外径 50 mm，钻一个 $d_i = 25$ mm 的中心孔。$J = \dfrac{\pi(0.05^4 - 0.025^4)}{32} = \dfrac{\pi(6.25\times10^{-6} - 3.906\times10^{-7})}{32} = 5.749\times10^{-7}$ m⁴，比实心 50 mm 的 $6.136\times10^{-7}$ 只小 **6.3%**，但截面积（重量）省了 **25%**。

结论：**扭转设计里，重量可以按 $(d_o^4 - d_i^4)/d_o^4$ 打折，而刚度几乎不受影响**——这就是汽车传动轴、自行车中轴、飞机操纵杆全都是空心管的道理。

画面分三块，各有各的话要说：

- **上方是轴本身**：三条纵向"纤维线"扭成螺旋，中间那条（轴线）几乎不动，越靠外扭得越明显。右侧的端面圆盘上，**琥珀色半径线**相对虚线（未扭转）转过的角度就是 $\phi$，旁边的圆弧把转角画出来；
- **下方是 $\tau(r)$ 分布**：从圆心（零）到外表面（最大）的一条直线，外表面标出 $\tau_{\max}$ 并与许用值比对，超了会变红。这条直线的**斜率就是 $T/J$**——这正是多元微积分里的梯度：应力沿半径方向的变化率处处相等；
- 读数里的"极惯性矩 $J$"后面永远跟着"（$\propto d^4$）"这个提示。

三件事值得做：

- 把 **d 从 40 拖到 80**（翻倍）：$\tau_{\max}$ 变成 $1/8$，$J$ 涨 16 倍。这就是四次方的威力；
- 把 **L 从 1.2 拖到 2.4**：$\tau_{\max}$ **一点没变**（强度与长度无关），但 $\phi$ 翻倍。**强度看截面，刚度还要看长度**——这是初学者最容易混的一点；
- 切换**材料**：钢 → 铝（$G$ 从 79 掉到 26 GPa），$\tau_{\max}$ 不变（$J$ 没变），但 $\phi$ 涨到 3 倍。**换材料只改刚度，不改扭转强度**，因为 $\tau = Tr/J$ 里压根没有 $G$。

### 实验 2（python）：按刚度和强度两个条件挑直径

```python title="选轴径：强度够不够，刚度够不够"
# sliders: d=40 [10:120:1]
G = 79e9                     # 钢剪切弹性模量（帕）
T = 400.0                    # 扭矩（牛·米）
L = 1.2                      # 轴长（米）
tau_allow = 160e6            # 许用剪应力（帕）
twist_allow = 0.5            # 许用单位长度扭转角（度/米）

print(" d(mm)   τmax(MPa)  强度   φ/L(°/m)  刚度")
for d in [30, 35, 40, 45, 50, 55]:
    J = 3.141592653589793 * (d / 1000) ** 4 / 32
    tau = T * (d / 2000) / J                      # τ = T·c/J，c = d/2
    phi = T * L / (G * J)                         # 扭转角（弧度）
    per_m = phi * 180 / 3.141592653589793 / L     # 换算成度/米
    ok_s = "OK" if tau <= tau_allow else "超"
    ok_t = "OK" if per_m <= twist_allow else "超"
    print(f" {d:5d}   {tau / 1e6:8.1f}   {ok_s}   {per_m:8.3f}   {ok_t}")

# 反解：刚度要求的最小直径
J_need = T * L / (G * (twist_allow * 3.141592653589793 / 180) * L)
d_need = (J_need * 32 / 3.141592653589793) ** 0.25
print(f"\n刚度要求的最小直径 d = {d_need * 1000:.1f} mm → 取标准值 50 mm")
```

输出会清清楚楚地告诉你一件事：**强度那一列从 $d = 30$ mm 起就全是 OK，刚度那一列却一直到 50 mm 才合格。** 传动轴的设计几乎总是被刚度（而不是强度）支配——这也是为什么轴看起来总是"粗得没必要"。

最后反解出来的 49.3 mm 与手算一致。把 `twist_allow` 从 0.5 改成 0.25 再跑，最小直径会变成 $49.3 \times 2^{1/4} = 58.6$ mm——**精度要求翻一倍，直径只涨 19%**，这是四次方给你的折扣。

### 快问快答

```quiz
一根传动轴强度和刚度都刚好合格。现在把轴长增加一倍，其他都不变，会发生什么？
- 剪应力和扭转角都翻倍
- 剪应力不变，扭转角翻倍 [*]
- 剪应力翻倍，扭转角不变
- 两者都不变
? τ = T·c/J 里没有长度 L，所以剪应力与长度无关；φ = TL/(GJ) 正比于 L，长度翻倍转角就翻倍。记住这个对照：强度看截面，刚度看截面加长度。
```

:::warning[常见误区]

**误区一**："直径翻倍，轴的承载能力翻倍。"
你以为线性关系——其实 $J \propto d^4$，直径翻倍让 $\tau_{\max}$ 降到 $1/8$、扭转角降到 $1/16$。这是机械设计里**性价比最高也最容易被低估的杠杆**。反过来说也成立：直径缩一点点，刚度就塌一大截，所以轴的磨损、腐蚀、加工刀痕都必须计入最小直径，不能按名义尺寸算。

**误区二**："空心轴省材料，所以强度也按比例省。"
你以为挖掉 50% 面积就损失 50% 强度——其实**外圈材料贡献最大**，挖掉中心只损失很少。外径 50 mm、内径 25 mm 的空心轴，面积省 25%，而 $J$ 只损失 6.3%。空心化的真正限制不是强度，而是**薄壁屈曲**（壁太薄会像易拉罐一样局部皱掉）和加工成本——这就是工程上常见 $d_i/d_o \approx 0.5\sim0.7$ 的原因，再薄就要额外校核稳定性了。

**误区三**："换更硬（更高强度）的钢，轴就能传更大扭矩。"
你在混用两个概念——$\tau = Tr/J$ 里**没有材料参数**。换 40Cr 调质钢把 $[\tau]$ 从 160 提到 300 MPa，确实能传更大扭矩（强度条件放宽），但**扭转角一点都不会变**，因为所有钢的 $G$ 都是 79 GPa 上下。所以：**精度不够就加粗或缩短，别去换钢号。**

:::

<details>
<summary>点开查看逐步解答</summary>

1. $J = \dfrac{\pi(d_o^4 - d_i^4)}{32} = \dfrac{\pi(0.06^4 - 0.04^4)}{32} = \dfrac{\pi(1.296\times10^{-5} - 2.56\times10^{-6})}{32} = \dfrac{\pi \times 1.04\times10^{-5}}{32} = 1.021\times10^{-6}$ m⁴；

5. 刚度损失：$\dfrac{1.272 - 1.021}{1.272} = 19.7\%$（扭转角相应增大到 $1/0.803 = 1.245$ 倍）；

## 7. 选读：从剪应变积分出 T = GJ·(dφ/dx)

<details>
<summary>选读 · 圆轴扭转的三个假设与一次积分</summary>

圆轴扭转的整套公式建立在三个假设上，全都来自"圆截面 + 弹性小变形"：

1. **横截面保持平面且仍为平面**（不像非圆截面那样会翘曲）；
2. **半径保持直线**；
3. **相邻截面只相对转过一个微小角度** $d\phi$。

取距轴心 $r$ 处的一段纵向纤维，长度为 $dx$。两端截面相对转过 $d\phi$ 后，这段纤维被剪斜了，剪应变（小角度下就是那个斜角的正切）：

$$\gamma(r) = \frac{r\,d\phi}{dx} = r\,\theta, \qquad \theta \equiv \frac{d\phi}{dx}$$

注意 $\gamma$ 对 $r$ 是**线性**的——这正是多元微积分里"方向导数/梯度为常数"的典型例子：$\partial\gamma/\partial r = \theta$，处处相同。

代入剪切胡克定律 $\tau = G\gamma$：

$$\tau(r) = G\,\theta\,r$$

这就是 $\tau$ 沿半径线性分布、圆心为零、外表面最大。**注意这里 $G$ 出现了，但它只决定"给定转角下产生多大应力"，不决定"给定扭矩下产生多大应力"**——这就是误区三的根源。

现在把这个应力对轴心取矩并沿整个截面积分，它必须等于外加扭矩 $T$：

$$T = \int_A \tau(r)\, r\, dA = \int_A G\theta r \cdot r\, dA = G\theta\int_A r^2 dA = G\theta\, J$$

其中 $J \equiv \int_A r^2 dA$ 就是**极惯性矩**（对圆截面算出来是 $\pi d^4/32$）。于是

$$\theta = \frac{d\phi}{dx} = \frac{T}{GJ}$$

对 $x$ 积分（等截面、等扭矩时 $T/GJ$ 是常数）即得 $\phi = TL/(GJ)$。

最后把 $\theta = T/(GJ)$ 代回 $\tau = G\theta r$：

$$\tau(r) = \frac{T r}{J}$$

**$G$ 消掉了。** 三步走完，整课的公式全部就位。顺带说明为什么非圆截面（方轴、花键）不能用这套公式：假设 1 不成立，截面会翘曲，$J$ 也不再是简单的 $\pi d^4/32$，必须查表或用有限元。

</details>
