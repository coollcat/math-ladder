# 齿轮传动与传动比

## 1. 从一个场景开始

一台电机每分钟转 3000 圈，车轮只需要每分钟 100 圈，还得把扭矩放大三十倍。一级齿轮？小齿轮得小到只剩几个齿，齿根会被"啃"掉（根切），装都装不上。

于是工程师把几级齿轮串起来：每一级只减一点点，串够级数就到了。可串的时候你会发现一件怪事——**中间那几个齿轮的大小，居然完全不影响最终的总减速比**。

再往后，同样的三个齿轮换个固定件，减速比从 4 变成 1.33 甚至变成倒转。这不是魔术，是**行星轮系**：它把"传动比"从一个固定数字，变成了一种可以现场切换的选择。

## 2. 直觉解释

齿轮的核心只有一句话：**啮合的地方，两个轮的线速度必须相等**。轮子上一点的线速度是 $\omega r$，而齿轮的半径严格正比于齿数 $z$（因为齿必须一样大才能咬上）。于是

$$\omega_1 z_1 = \omega_2 z_2 \quad\Longrightarrow\quad \frac{\omega_1}{\omega_2} = \frac{z_2}{z_1}$$

**转速与齿数成反比**——就这么简单。

中间齿轮为什么"白搭"？因为串联时各级速比是相乘的，而中间那个齿轮的齿数**同时出现在前一级的分子和后一级的分母上，被约掉了**：

$$\frac{z_2}{z_1}\times\frac{z_3}{z_2}\times\frac{z_4}{z_3} = \frac{z_4}{z_1}$$

它唯一的作用是让转向多反一次（所以叫**惰轮**）。这跟等比数列里连乘时中间项相互抵消是同一回事——你在第 08 章见过的花样。

行星轮系的直觉则完全不同：它不是"一串"，而是一个**三明治**。中间的三个元件（太阳轮、齿圈、行星架）互相牵制，**谁被按住不动，谁就是基准**，剩下的两个之间的速比随之改变。

## 3. 正式定义

**模数 $m$**：$m = d/z$，即每个齿分摊到的分度圆直径。两个齿轮能啮合的**前提**是模数相同（单位 mm）。

**定轴轮系**（各轮轴线固定）：

$$i_{1n} = \frac{\omega_{入}}{\omega_{出}} = \frac{z_{末}}{z_{首}},\qquad \text{转向} = (-1)^{\text{外啮合次数}}$$

**行星轮系**（单排：太阳轮 $Z_s$、齿圈 $Z_r$、行星架 $C$），核心是**韦利斯公式（转化机构法）**——给整个轮系加上 $-\omega_C$ 的转速，把行星架"变成"固定的：

$$\frac{\omega_s - \omega_C}{\omega_r - \omega_C} = -\frac{Z_r}{Z_s} = -k$$

代入不同的固定条件：

| 固定件 | 输入 → 输出 | 传动比 $i$ | 备注 |
| --- | --- | --- | --- |
| 齿圈（$\omega_r = 0$） | 太阳 → 架 | $i = 1 + k$ | 最常用，同向大减速 |
| 太阳（$\omega_s = 0$） | 齿圈 → 架 | $i = 1 + \dfrac{1}{k}$ | 减速比小 |
| 行星架（$\omega_C = 0$） | 太阳 → 齿圈 | $i = -k$ | 反向，退化为定轴 |
| 任意两件锁死 | — | $i = 1$ | 整体回转（直接档） |

**单级合理范围**：直齿圆柱齿轮单级 $i \approx 3 \sim 5$（过大则小轮齿数过少、体积悬殊）；总减速比大时要**分级串联**，且每级速比尽量取成等比数列，让各级尺寸均匀。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $z$ | 齿数 | 正比于半径，决定转速比 |
| $m$ | 模数 | $m=d/z$；啮合的必要条件是模数相同 |
| $i$ | 传动比 | $\omega_{入}/\omega_{出}$；$>1$ 为减速增扭 |
| $k$ | 行星排特性参数 | $k = Z_r/Z_s$，通常取 $2\sim4$ |
| $Z_s, Z_r$ | 太阳轮 / 齿圈齿数 | 行星排的两个"端" |

## 4. 分步例题

**例**：输入 $n = 100$ rpm。(a) 三级定轴轮系 $Z_1{:}Z_2{:}Z_3 = 20{:}40{:}30$，求总传动比与输出转向；(b) 末轮换成 60 齿后如何；(c) 行星排 $Z_s=24$、$Z_r=72$，齿圈固定，求架的输出转速。

1. **(a) 总传动比**：$i = z_{末}/z_{首} = 30/20 = 1.5$；
2. **输出转速**：$n_{出} = 100/1.5 = 66.67$ rpm；
3. **转向**：共 2 次外啮合，$(-1)^2 = +1$ → **与输入同向**。中间那个 40 齿的齿轮只贡献了一次反向，把两级各自的一次反向抵消掉了；
4. **(b) 改成** $20{:}40{:}30{:}60$：$i = 60/20 = 3.0$，$n_{出} = 33.33$ rpm，3 次外啮合 → **反向**。注意 $z_2$、$z_3$ 全程没进过结果；
5. **(c) 行星排**：$k = Z_r/Z_s = 72/24 = 3$，齿圈固定、架输出时 $i = 1+k = 4$，故 $n_C = 100/4 = 25$ rpm，与太阳轮**同向**；
6. **对比**：同样是这三个齿轮，若固定行星架（退化成定轴），$i = -k = -3$，输出 $33.3$ rpm 且**反向**。**一套硬件，三种速比**——这就是自动变速箱和混合动力耦合机构的物理基础。

定轴模式下（上面那排齿轮，橙色圆点是啮合点，辐条看转向）：

- 切「齿圈固定 / 太阳固定 / 行星架固定」，看读数栏的 $i$ 在 $1+k$、$1+1/k$、$-k$ 之间跳；
- 拖 `Zr` 让 $k$ 从 3 涨到 5，齿圈固定的减速比立刻从 4 涨到 6——**$k$ 就是行星排的"性格参数"**；
- 盯住行星架连杆的转速：它比太阳轮慢得多，这正是减速器要的。

### 实验 2（python）：一张表算全两种轮系

```python title="定轴轮系与行星排：速比一次算清"
import math                        # 数学库：pi，用于转速与角速度的换算

def gear_train(z, rpm):
    """定轴轮系：返回总传动比、输出转速、转向"""
    out = rpm
    sign = 1
    for i in range(len(z) - 1):
        out = out * z[i] / z[i + 1]      # 线速度相等 → 转速反比于齿数
        sign = -sign                     # 每经过一次外啮合，转向反一次
    return z[-1] / z[0], out, ('同向' if sign > 0 else '反向')

for z in ([20, 40], [20, 40, 30], [20, 40, 30, 60]):
    i, out, d = gear_train(z, 100.0)
    w = 2 * math.pi * out / 60           # 输出角速度（rad/s）
    print("Z = %-16s i = %.4f | 输出 %6.2f rpm = %.2f rad/s | %s"
          % (str(z), i, out, w, d))

Zs, Zr, rpm = 24, 72, 100.0
k = Zr / Zs                              # 行星排特性参数
print("行星排 k = %.3f | 齿圈固定 i = %.3f → %.2f rpm | 太阳固定 i = %.3f → %.2f rpm | 架固定 i = %.3f（反向）"
      % (k, 1 + k, rpm / (1 + k), 1 + 1 / k, rpm / (1 + 1 / k), -k))
```

四行输出把两件事钉死了：

- **前三行里的 $z_2$、$z_3$ 从来没出现在 $i$ 里**——$20\to40\to30$ 得 1.5，$20\to40$ 得 2.0，差值只来自末轮；
- **最后一行是一个硬件的三种命运**：$4.000$、$1.333$、$-3.000$。真实变速箱就是靠几组离合器/制动器来决定"按住谁"，从而在不切断动力的情况下换挡。

把 `Zr` 改成 120（$k=5$）再跑，齿圈固定的减速比变成 6；但注意 $k$ 也不能无限大——齿圈越大，行星轮越小、轴承越难布置，工程上 $k$ 通常取 $2\sim4$。

### 快问快答

```quiz
一个单排行星轮系，太阳轮 30 齿、齿圈 90 齿，齿圈被固定，太阳轮输入、行星架输出。行星架的转速与转向是？
- 输入转速的 1/3，同向
- 输入转速的 1/4，同向 [*]
- 输入转速的 1/3，反向
? k = Zr/Zs = 90/30 = 3，齿圈固定时 i = 1 + k = 4，所以行星架转速是输入的四分之一，且与太阳轮同向。架固定时才是反向的 −k，别把两种固定方式搞混。
```

:::warning[常见误区]

**误区一**：「多加几个中间齿轮，就能把传动比做得更大。」
你以为齿轮越多减得越多——其实中间轮（惰轮）的齿数在连乘时**分子分母各出现一次，直接约掉**。$i$ 只由首末两轮齿数决定，中间轮唯一的贡献是**多反一次向**。想加大减速比，只能改末轮（或分级）。

**误区二**：「行星轮系里固定哪个件只是安装方式不同，速比差不多。」
你以为它只是装法问题——其实**固定件决定了一切**：齿圈固定 $i = 1+k$，太阳固定 $i = 1+1/k$，架固定 $i = -k$。以 $k=3$ 为例，三者分别是 4、1.33、$-3$，差了三倍还带反向。设计行星排的第一步永远是**明确谁固定、谁输入、谁输出**。

**误区三**：「总减速比 30 就用一级 30 的齿轮，最省零件。」
你以为级数越少越省——其实单级 $i > 5$ 会带来小齿轮齿数过少（根切、强度不足）、大齿轮直径过大（箱体装不下）、啮合线速度过高等一串问题。工程做法是把 30 拆成 $3\times3.2\times3.1$ 三级串联，且**各级速比取成等比数列**，让每一级的尺寸和受力都接近。

:::

**练习 2**：需要总减速比 $i = 24$，单级速比不超过 4.5。请给出分级方案与各齿数（小轮不少于 17 齿）。

<details>
<summary>点开查看逐步解答</summary>

1. **先定级数**：$4.5^2 = 20.25 < 24$，两级不够；三级则每级 $i = \sqrt[3]{24} = 2.88$，在合理区间内 → **分三级**；
2. **分配速比**：取等比数列 $3.0 \times 2.8 \times 2.86 \approx 24$；为整数齿方便，取 $3.0 \times 3.0 \times 2.67$；
3. **配齿数**（小轮 $\ge 17$）：第一级 $17{:}51 = 3.0$；第二级 $18{:}54 = 3.0$；第三级 $18{:}48 = 2.67$。总 $i = 3\times3\times2.67 = 24.0$ ✓；
4. **校验模数与中心距**：三级取同一模数 $m=2$ mm，则中心距分别为 $\frac{m(z_1+z_2)}{2} = 68$、$72$、$66$ mm。若要求各级中心距相等（同轴式减速器），就得反过来**先定中心距再凑齿数**——这是真实设计里最花时间的部分；
5. **别忘了效率**：三级各按 98% 计，总效率 $0.98^3 = 0.941$。输出扭矩 = $i \times \eta \times T_{入} = 24 \times 0.941 = 22.6$ 倍，**比理想值少 6%**。

**这道题的教训**：减速比不是"算出来就行"，它是**齿数（整数）、中心距、模数、强度、效率**五个约束同时满足的结果。这也是为什么工程上大量使用标准减速器而不是自己配齿。

</details>

## 7. 选读：韦利斯公式——给轮系加上负的架转速

<details>
<summary>选读 · 转化机构法为什么成立</summary>

行星轮系的困难在于行星轮**一边自转一边公转**，轴线在动，定轴轮系的公式直接用不了。

解法是**相对运动**：给整个轮系叠加一个 $-\omega_C$ 的公共转速。这样一来：

- 行星架的转速变成 $\omega_C - \omega_C = 0$ → **架"固定"了**；
- 所有齿轮之间的**相对**运动关系不变（齿轮啮合是相对运动，与整体一起转多少无关）；
- 于是可以套用定轴轮系公式，只不过式子里所有转速都换成"相对架的转速"。

太阳轮与齿圈之间通过行星轮相连，是**一次内啮合 + 一次外啮合**，净效果为两次反向中的一次，符号为负：

$$\frac{\omega_s - \omega_C}{\omega_r - \omega_C} = -\frac{Z_r}{Z_s} = -k$$

三个推论直接可得：

1. 齿圈固定（$\omega_r = 0$）：$\dfrac{\omega_s - \omega_C}{-\omega_C} = -k \Rightarrow \omega_s = (1+k)\omega_C$，即 $i = \omega_s/\omega_C = 1+k$ ✓；
2. 太阳固定（$\omega_s = 0$）：$\dfrac{-\omega_C}{\omega_r - \omega_C} = -k \Rightarrow \omega_r = (1+\frac{1}{k})\omega_C$；
3. 架固定（$\omega_C = 0$）：$\dfrac{\omega_s}{\omega_r} = -k$，退化为普通定轴轮系。

**这个"加一个公共转速把动坐标系变成静坐标系"的手法，是第 65 章机器人运动学里相对位姿变换的机械版本**——换个参考系，难题就变成已经解过的题。

</details>
