# 压杆稳定与屈曲

## 1. 从一个场景开始

一根直径 30 mm 的实心钢杆，长 2 米，两端铰接。它能承受的临界压力只有 **20.6 kN**——相当于 2 吨。

可这根杆的截面积是 707 mm²，按 250 MPa 屈服强度算，压碎它需要 177 kN。也就是说：**它只用了材料强度的 12% 就失效了，而且失效方式是"突然整个弯出去"。**

这不是强度不够，是**直的那个平衡状态消失了**。为什么"消失"会有一个精确的临界值？答案藏在一个特征值问题里。

## 2. 直觉解释

想象一根细长的塑料尺，你从两端慢慢压它。

一开始它只是被压短一点点——**直的状态是稳定的**：你推它一下让它侧弯，松手后它弹回来。

压力加到某个值后，情况变了：你轻轻一碰，它就保持住一个弯的形状不回来了。再加大，它自己就弯了。**直的状态还在，但它变成了一个"站在山顶上的球"。**

数学上这叫**分岔**：在临界载荷 $P_{cr}$ 以下，方程只有一个解（$\delta = 0$）；跨过 $P_{cr}$ 之后，同一个载荷下冒出**两个新解**（向左弯、向右弯）。图上画出来就是一个 Y 字形——这就是分岔图。

为什么是长杆才这样？因为**弯着储存能量**比**压着储存能量**更划算：弯曲能 $\propto EI/L^3$，压缩能 $\propto EA/L$，细长杆的 $I/A$ 太小，稍微弯一点就能省下大量压缩能。压杆"逃"向弯曲，是能量最低原理的必然。

## 3. 正式定义

**欧拉临界载荷**（两端铰支）：

$$P_{cr} = \frac{\pi^2 E I}{L^2}$$

更一般地用**有效长度系数** $K$ 把端部约束折算进去：

$$P_{cr} = \frac{\pi^2 E I}{(K L)^2}$$

| 端部约束 | 有效长度系数 $K$ | 物理含义 |
| --- | --- | --- |
| 两端铰支 | $1.0$ | 基准 |
| 一端固定、一端自由 | $2.0$ | 悬臂柱，最弱 |
| 两端固定 | $0.5$ | 最强 |
| 一端固定、一端铰支 | $0.7$ | 居中 |

**长细比**（slenderness ratio）与**临界应力**：

$$r = \sqrt{\frac{I}{A}}, \qquad \lambda = \frac{KL}{r}, \qquad \sigma_{cr} = \frac{P_{cr}}{A} = \frac{\pi^2 E}{\lambda^2}$$

**欧拉公式的适用范围**（这是最容易忘的一条）：

$$\lambda_p = \pi\sqrt{\frac{E}{\sigma_y}}$$

只有当 $\lambda \ge \lambda_p$（等价于 $\sigma_{cr} \le \sigma_y$）时，欧拉公式才成立。$\lambda < \lambda_p$ 的短粗杆在屈曲前就先屈服了，必须改用 Johnson 抛物线或直线经验公式。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $P_{cr}$ | 欧拉临界载荷 | 牛 N | 分岔发生的载荷 |
| $K$ | 有效长度系数 | — | 端部约束折算，见上表 |
| $I$ | 截面惯性矩 | m⁴ | **用最小的那个**（弱轴！） |
| $A$ | 截面积 | m² | — |
| $r$ | 回转半径 | 米 m | $r=\sqrt{I/A}$，圆截面实心杆 $r = d/4$ |
| $\lambda$ | 长细比 | — | 越大越"细长"，越容易屈曲 |
| $\lambda_p$ | 转折长细比 | — | 欧拉公式与经验公式的分界 |

## 4. 分步例题

**例**：实心圆钢杆，$d = 30$ mm，$L = 2$ m，两端铰支，$E = 210$ GPa，$\sigma_y = 250$ MPa。求 $P_{cr}$、长细比、临界应力，并判断欧拉公式是否适用。

1. **截面几何**：$A = \dfrac{\pi d^2}{4} = \dfrac{\pi \times 0.03^2}{4} = 7.069\times10^{-4}$ m²；$I = \dfrac{\pi d^4}{64} = \dfrac{\pi \times 0.03^4}{64} = 3.976\times10^{-8}$ m⁴；
2. **回转半径**：$r = \sqrt{I/A} = \sqrt{3.976\times10^{-8} / 7.069\times10^{-4}} = \sqrt{5.625\times10^{-5}} = 7.50\times10^{-3}$ m $= 7.5$ mm（正好是 $d/4$，可以当作快速校验）；
3. **长细比**：$K = 1.0$，$\lambda = KL/r = 2.0 / 0.0075 = 266.7$；
4. **转折长细比**：$\lambda_p = \pi\sqrt{E/\sigma_y} = \pi\sqrt{210\times10^9 / 250\times10^6} = \pi\sqrt{840} = 91.1$；
5. **判定**：$\lambda = 266.7 > 91.1$，**欧拉公式适用**（细长杆）；
6. **临界载荷**：$P_{cr} = \dfrac{\pi^2 \times 210\times10^9 \times 3.976\times10^{-8}}{2^2} = \dfrac{8.241\times10^{4}}{4} = 2.06\times10^{4}$ N $= 20.6$ kN；
7. **临界应力**：$\sigma_{cr} = P_{cr}/A = 2.06\times10^{4} / 7.069\times10^{-4} = 29.1$ MPa，只有屈服强度 250 MPa 的 **11.6%**；
8. **如果两端改成固定**？$K = 0.5$，$P_{cr}$ 变成 $1/0.5^2 = 4$ 倍 $= 82.4$ kN。**约束比加粗管用得多**，而且几乎不增加重量。

左边是压杆本身，右边是 $P$-$\delta$ 分岔图。四件事值得做：

- 把 **P/Pcr 从 0.8 慢慢拖到 1.2**：左边的杆在跨过 1.0 的瞬间突然弯出去，颜色从绿变红。右边图上，绿色实线（$\delta = 0$ 的稳定支路）在 $P_{cr}$ 处**分出两条紫色支路**——这就是分岔点；
- 注意分岔后支路的形状：$\delta \propto \sqrt{P/P_{cr} - 1}$，是**平方根**，不是线性。载荷刚过临界一点点，侧移就长得飞快；
- 只把 **L 从 2 m 拖到 4 m**：$P_{cr}$ 掉到 $1/4$（分母上是 $(KL)^2$）。这是所有细长压杆设计里最敏感的参数；
- 只把 **d 从 30 mm 拖到 60 mm**：$I \propto d^4$，所以 $P_{cr}$ 涨 **16 倍**，但重量也涨了 4 倍——**划算，但不免费**。

再看读数里的"长细比 $\lambda$"和"转折长细比 $\lambda_p$"：

- 切到**木材**（$E = 11$ GPa，$\sigma_y = 40$ MPa）：$\lambda_p = \pi\sqrt{11/0.04} = 52$，比钢小得多，所以木杆很容易跌出欧拉区；
- 把 **L 拖到 0.3 m**：$\lambda$ 会掉到 $\lambda_p$ 以下，读数直接提示"欧拉公式不适用，屈曲前已屈服"——**这时候公式算出来的 $P_{cr}$ 是假的，别再用**。

### 实验 2（python）：扫一遍长细比，找出欧拉区的边界

```python title="扫杆长：Pcr 与屈服载荷谁先到"
# sliders: L=2 [0.3:6:0.05]
E = 210e9                    # 钢弹性模量（帕）
sy = 250e6                   # 屈服强度（帕）
d = 0.030                    # 圆截面直径（米）
A = 3.141592653589793 * d ** 2 / 4
I = 3.141592653589793 * d ** 4 / 64
r = (I / A) ** 0.5           # 回转半径 = d/4
K = 1.0                      # 两端铰支
P_yield = sy * A             # 压到屈服所需的载荷
lam_p = 3.141592653589793 * (E / sy) ** 0.5

print(f"截面积 A = {A * 1e6:.1f} mm²   回转半径 r = {r * 1000:.2f} mm")
print(f"屈服载荷 = {P_yield / 1000:.1f} kN   转折长细比 λp = {lam_p:.1f}")
print()
print(" L(m)   λ      Pcr(kN)   σcr(MPa)  判定")
for L in [0.5, 1.0, 1.5, 2.0, 3.0, 4.0]:
    lam = K * L / r
    Pcr = 3.141592653589793 ** 2 * E * I / (K * L) ** 2
    scr = Pcr / A
    ok = "欧拉区" if lam >= lam_p else "欧拉失效（先屈服）"
    print(f" {L:4.1f}  {lam:6.1f}  {Pcr / 1000:8.2f}  {scr / 1e6:8.1f}  {ok}")
```

跑出来会看到：$L = 0.5$ m 时 $\lambda = 66.7 < 91.1$，欧拉公式**不适用**——按公式算出的临界应力高达 466 MPa，已经远超 250 MPa 的屈服强度，这根"短粗杆"在屈曲前就先被压屈服了。从 $L = 1.0$ m 起（$\lambda = 133$）才进入欧拉区。而在欧拉区内部，$P_{cr}$ 从 $L = 1.0$ 的 82.4 kN 一路掉到 $L = 4.0$ 的 5.15 kN——**16 倍的差距，全靠一个 $1/L^2$**。

这段代码还揭示了一件反直觉的事：**在欧拉区里，$P_{cr}$ 与强度 $\sigma_y$ 完全无关**。你把钢从 Q235 换成高强度合金钢，$\sigma_y$ 翻倍，$P_{cr}$ 一动不动——因为 $E$ 没变。**细长压杆提高强度是白花钱，要加粗或加中间支撑。**

```quiz
- 2 倍

```

:::warning[常见误区]

**误区一**："杆越粗越安全，所以 $P_{cr}$ 正比于截面积 $A$。"
你以为抗屈曲和抗拉一样看面积——其实 $P_{cr}$ 里出现的是**惯性矩 $I$，而且是两个方向中较小的那个**。同样截面积，圆管远比实心圆强（材料挪到外圈，$I$ 大涨）；矩形截面平着放和立着放，临界载荷能差好几倍。**设计压杆时必须先问：它最可能朝哪个方向弯？** 然后确保那个方向的 $I$ 够大。

**误区二**："欧拉公式就是压杆强度的通用公式，套进去就行。"
你以为算出来多少就能用多少——欧拉公式**只在临界应力低于比例极限（近似取 $\sigma_y$）时成立**，即 $\lambda \ge \lambda_p = \pi\sqrt{E/\sigma_y}$。短粗杆（$\lambda < \lambda_p$）在屈曲之前材料就先屈服了，真实临界载荷远低于欧拉值，必须用 Johnson 抛物线或行业经验公式。**用错公式的后果是严重高估承载能力。** 本课的 lab 读数会明确告诉你"适用/不适用"——养成看的习惯。

**误区三**："载荷到了 $P_{cr}$，杆就断了。"
你以为临界载荷是破坏载荷——其实**屈曲是失稳，不是断裂**。跨过 $P_{cr}$ 后直杆弯成弧形，材料往往还完全在弹性范围内，卸载后它能弹回直线。真正致命的是：弯曲后产生附加弯矩，变形越大弯矩越大，**在恒载下也会不断发展直到彻底垮掉**。所以工程上要的不是"刚好不超 $P_{cr}$"，而是安全系数（常见 2~3.5，视规范而定）。另外初始不直、载荷偏心、残余应力都会让实际临界值显著低于理论值——欧拉公式给的是**理想直杆的上限**。

:::

## 7. 选读：用能量法推出 π²EI/L²

<details>
<summary>选读 · 一个正弦假设，一条能量平衡，就是全部</summary>

两端铰支的杆屈曲时，最自然的形状就是半个正弦波。设侧移

$$y(x) = a\sin\frac{\pi x}{L}$$

$a$ 是幅值（待定）。现在比较两条能量路径。

**弯曲应变能**（上一课的 $EI v''$ 派上用场了）：$y'' = -a(\pi/L)^2\sin(\pi x/L)$，且 $\int_0^L \sin^2(\pi x/L)\,dx = L/2$，于是

$$U = \frac{1}{2}EI\int_0^L (y'')^2 dx = \frac{1}{2}EI \cdot a^2\frac{\pi^4}{L^4}\cdot\frac{L}{2} = \frac{EI\,a^2\pi^4}{4L^3}$$

**外力的势能**：压力 $P$ 作用点随侧移而下降。曲线比直线长出的量，在小变形下是

$$\Delta = \frac{1}{2}\int_0^L (y')^2 dx = \frac{1}{2}a^2\frac{\pi^2}{L^2}\cdot\frac{L}{2} = \frac{a^2\pi^2}{4L}$$

所以外力做功 $W = P\Delta = \dfrac{P a^2 \pi^2}{4L}$，总势能

$$\Pi(a) = U - W = \frac{a^2}{4}\left(\frac{EI\pi^4}{L^3} - \frac{P\pi^2}{L}\right)$$

**稳定性判据**：$a = 0$（直杆）是稳定平衡，当且仅当 $\Pi$ 在 $a=0$ 处取极小，即括号为正；一旦括号变负，$\Pi$ 随 $a$ 增大而减小，直杆就守不住了。临界发生在括号为零：

$$\frac{EI\pi^4}{L^3} = \frac{P\pi^2}{L} \quad\Longrightarrow\quad P_{cr} = \frac{\pi^2 EI}{L^2}$$

括号正好为零时，所有 $a$ 的 $\Pi$ 都相同——**这就是分岔**：系统对幅值"无所谓"了。

再往前一步就是特征值问题。若不预设正弦形状，把 $EIy'''' + Py'' = 0$ 配上铰支边界条件 $y(0)=y(L)=0$、$y''(0)=y''(L)=0$ 离散化，得到的正是矩阵特征值问题 $K\mathbf{y} = P\,K_g\mathbf{y}$，**最小的那个特征值就是 $P_{cr}$**，对应特征向量就是一阶屈曲模态——lab 里画的那条半正弦。二阶模态是整周期正弦（中间有个反弯点），对应 $4P_{cr}$，但它要先越过一阶才可能到达。

</details>
