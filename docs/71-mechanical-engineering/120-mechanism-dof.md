# 平面机构与自由度

## 1. 从一个场景开始

同样的四根杆、四个销轴，有人装出来的是**能连续运转的曲柄摇杆**，有人装出来的是**推不动的三角形**，还有人装出来的是**一推就乱晃的松散架子**。

零件一个不差，差别只在**怎么连**。

在画第一张受力图之前，机械工程师永远先问同一个问题：**这套东西到底有几个自由度？** 答案决定它需要几个原动件、能不能有确定的运动——而这句话，其实是一个图论里的**数边问题**。

## 2. 直觉解释

把机构拆成零件摊在桌面上。

- 一个自由的平面刚体可以怎么动？**左右平移、上下平移、绕自身转动**——正好 **3 个自由度**（还记得力与力矩那课里"平面力系三个平衡方程"吗？三个方程对应三个自由度，这不是巧合）；
- 现在把其中一个零件钉死在地上当**机架**：它的 3 个自由度没了，而且**其他所有零件的位置都以它为参照**。这就是公式里 $n-1$ 而不是 $n$ 的原因；
- 每用一个销子把两个构件铰接（**低副**），这两个构件之间就只剩下"相对转动"这 1 个自由度——原本 2 个构件有 $2\times3 = 6$ 个自由度，铰完之后只剩 $3 + 1 = 4$ 个，**被吃掉了 2 个**；
- 齿轮啮合、凸轮接触（**高副**）只限制沿公法线方向的移动，切向还能滑，**只吃掉 1 个**。

于是数自由度就变成了图论里的**数度问题**：构件是顶点、运动副是边，把"边吃掉的自由度"从"顶点自带的自由度"里减掉即可。这和握手定理（度数之和 = 边数的两倍）是同一类记账游戏——**每一条边被两个端点共享，所以要按 2 倍来算。**

## 3. 正式定义

**Grübler（平面机构自由度）公式**：

$$F = 3(n - 1) - 2j_1 - j_2$$

等价写法（$n$ 为活动构件数时）：$F = 3n - 2j_1 - j_2$，但本课统一**把机架计入 $n$**，用上面那一式。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $n$ | 构件数 | **含机架**（固定不动的那个也算一个构件） |
| $j_1$ | 低副数 | 转动副、移动副——面接触，每个约束 **2** 个自由度 |
| $j_2$ | 高副数 | 齿轮啮合、凸轮接触——点/线接触，每个约束 **1** 个自由度 |
| $F$ | 自由度 | 独立运动参数的个数 |

**结果的读法**：

| $F$ | 含义 | 该怎么做 |
| --- | --- | --- |
| $F = 1$ | 一个原动件即可确定运动 | 最常见、最理想 |
| $F = 2, 3\dots$ | 需要同样多个原动件 | 装一个电机就会"乱动" |
| $F = 0$ | 不是机构，是静定结构 | 桁架——这正是想要的 |
| $F < 0$ | 超静定结构，有冗余约束 | 刚性好，但要求加工精度，装不上就别硬装 |

**常见机构的账**（可以当成心算校验表）：

| 机构 | $n$ | $j_1$ | $j_2$ | $F$ |
| --- | --- | --- | --- | --- |
| 铰链四杆 | 4 | 4 | 0 | 1 |
| 曲柄滑块 | 4 | 4 | 0 | 1 |
| 凸轮从动件 | 3 | 2 | 1 | 1 |
| 齿轮副 | 3 | 2 | 1 | 1 |
| 五杆机构 | 5 | 5 | 0 | 2 |
| 六杆机构 | 6 | 7 | 0 | 1 |

## 4. 分步例题

**例**：某自动送料机构由 6 个构件组成（含机架），全部用转动副连接，共 7 个转动副。判断它的自由度，并分析装错时的两种情况。

1. **代入公式**：$n = 6$，$j_1 = 7$，$j_2 = 0$，所以 $F = 3(6-1) - 2\times7 = 15 - 14 = 1$；
2. **解读**：$F = 1$ 意味着**只需要一个原动件**（一台电机或一个气缸），整个机构的所有构件就有了确定的运动规律——这是最理想的机构；
3. **错法一：多装一个销轴**（$j_1 = 8$）：$F = 15 - 16 = -1$。多了一个冗余约束，机构**完全动不了**。实际表现是：装配时最后一个销子死活穿不进去，硬敲进去后机构卡死，电机堵转烧毁；
4. **错法二：漏装一个销轴**（$j_1 = 6$）：$F = 15 - 12 = 3$。需要 **3 个原动件**才有确定运动。装一台电机的话，机构会在运转中"自己找姿态"——同一输入下每次停的位置都不一样，这就是典型的**运动不确定**；
5. **工程对策**：$F \le 0$ 时要靠**加工精度**（同轴度、孔距公差）来保证能装上，或者干脆在结构中引入弹性/可调环节；$F \ge 2$ 时要么补原动件（多加电机、加弹簧闭合），要么改成 $F=1$ 的拓扑；
6. **一个数字检查**：只有低副（$j_2 = 0$）时，$F = 1$ 要求 $3(n-1) - 2j_1 = 1$，即 $j_1 = (3n-4)/2$。$j_1$ 必须是整数，所以 **$n$ 必须是偶数**。四杆、六杆、八杆都有 $F=1$ 的纯低副方案，而三杆、五杆、七杆**没有**——想要奇数构件的 $F=1$ 机构，必须引入高副（凸轮、齿轮）。

这样玩最有收获：

- **先逐个点上方六个预设**（铰链四杆、曲柄滑块、凸轮从动件、齿轮副、五杆、自定义）。注意滑块只在预设模式下显示——**真实机构的副数是结构定的，不是可以随便拖的数**；
- **看凸轮那一页**：$n=3$、$j_1=2$、$j_2=1$，$F = 6 - 4 - 1 = 1$。图上标着"高副（点接触）"的琥珀色圆点就是那 1 个约束——**只吃掉 1 个自由度，所以三构件就能凑出 $F=1$**；
- **看五杆那一页**：$F = 12 - 10 = 2$，图上直接红字写着"需要两个原动件才有确定运动"。这就是并联机器人、五杆机构的本质；
- **切到「自定义」，滑块解锁后自己凑一组**：调到 $n = 4$、$j_1 = 4$、$j_2 = 0$，你会重新得到 $F = 1$——这就是四杆机构。再调成 $n = 5$、$j_1 = 6$、$j_2 = 0$ 得到 $F = 0$（桁架！），$n = 5$、$j_1 = 5$、$j_2 = 0$ 得到 $F = 2$。

**把读数里的"自由度 F"和顶部横幅对着看**：公式里的三个数各减一点，$F$ 就跳一次。这比背公式管用得多。

### 实验 2（python）：扫一遍，看看哪些组合能凑出 F = 1

```python title="扫描 n 与 j₁：F=1 的组合在哪里"
print("只用低副时，F = 1 需要哪些 (n, j₁) 组合？")
for n in range(3, 9):
    hits = []                                    # 收集所有让 F=1 的 j₁
    for j1 in range(0, 15):
        F = 3 * (n - 1) - 2 * j1
        if F == 1:
            hits.append(j1)
    if hits:
        print(f" n = {n}: j₁ = {hits[0]}   → {n} 杆机构")
    else:
        print(f" n = {n}: 无解（纯低副凑不出 F=1）")

print()
print("常见机构对照表")
cases = [
    ("铰链四杆", 4, 4, 0),
    ("曲柄滑块", 4, 4, 0),
    ("凸轮从动件", 3, 2, 1),
    ("齿轮副", 3, 2, 1),
    ("五杆机构", 5, 5, 0),
    ("六杆机构", 6, 7, 0),
]
for name, n, j1, j2 in cases:
    F = 3 * (n - 1) - 2 * j1 - j2
    if F == 1:
        note = "一个原动件即可确定运动"
    elif F > 0:
        note = f"需要 {F} 个原动件"
    else:
        note = "不是机构（静定/超静定结构）"
    print(f" {name}：n={n} j₁={j1} j₂={j2} → F = {F}　{note}")
```

第一段输出会露出一个漂亮的规律：

```
n = 3: 无解（纯低副凑不出 F=1）
n = 4: j₁ = 4   → 4 杆机构
n = 5: 无解（纯低副凑不出 F=1）
n = 6: j₁ = 7   → 6 杆机构
n = 7: 无解（纯低副凑不出 F=1）
n = 8: j₁ = 10   → 8 杆机构
```

**只有偶数构件数才有纯低副的 $F=1$ 方案。** 这就是第 4 步那个 $(3n-4)/2$ 必须为整数的直接后果。三构件、五构件要凑出 $F=1$，必须引入高副——凸轮和齿轮的存在不是巧合，是奇偶性逼出来的。

对照表里"凸轮从动件"和"齿轮副"的 $F$ 都是 1，但它们的 $j_2 = 1$；**高副那一项的系数是 1 而不是 2，正是它们能用 3 个构件成事的原因。**

### 快问快答

```quiz
三个构件用同一根销轴铰接在一起（复合铰链），这个连接处应该算几个低副？
- 1 个
- 2 个 [*]
- 3 个
? k 个构件在同一点铰接，形成的是 k−1 个转动副。三个构件共销 → 2 个低副。把复合铰链当成 1 个副是数错自由度最常见的原因：少算 1 个低副会让 F 虚增 2，把「动不了」的结构误判成「能动」。
```

:::warning[常见误区]

**误区一**："有几个销子就数几个低副。"
你以为一一对应——**$k$ 个构件在同一根销轴上铰接（复合铰链），算的是 $k-1$ 个低副，不是 1 个**。三个构件共点就是 2 个转动副。这是数错自由度最常见的原因，而且它总是让 $F$ **偏大**，于是你以为机构能动，实际装出来推不动。数之前先在图上把每个铰点周围的构件数清点一遍。

**误区二**："公式算出 $F=1$，机构就一定能正常动。"
你在相信一个理想化公式——Grübler 公式对三类东西视而不见：**局部自由度**（凸轮从动件底部的滚子自转，不影响输出运动，应当先"焊死"滚子再数）、**虚约束**（平行四边形机构里那根平行的冗余杆、两个轴承支撑同一根轴，实际只起一个的作用，应当先删掉）、**复合铰链**（见上）。标准做法是先做三步预处理——去掉局部自由度、去掉虚约束、把复合铰链展开——**再**代入公式。跳过预处理，公式给的就是个错数。

**误区三**："$F = 0$ 或 $F < 0$ 说明设计失败了。"
你以为机构才是"对"的——$F = 0$ 是**静定结构**（桁架），$F < 0$ 是**超静定结构**，两者恰恰是结构工程师想要的：它们把材料搭成不活动的刚性骨架，用最少的材料扛住载荷（还记得桁架那一课吗？）。反过来，$F$ 太大才是麻烦：多自由度意味着要么加原动件（成本），要么加弹簧/重力闭合（不可靠）。**所以"该动的地方 $F\ge1$，不该动的地方 $F\le0$"才是好设计。**

:::

**练习 1**：下面这段代码把高副的系数写成了 2（和低副一样）。修到输出 `1`：

```exercise
# @title: 练习：高副只约束 1 个自由度
# @check: 1
# @hint: 低副（转动副、移动副）是面接触，约束 2 个自由度；高副（齿轮啮合、凸轮接触）是点/线接触，只约束 1 个。公式是 F = 3(n−1) − 2j₁ − j₂，最后一项系数是 1
n = 3                        # 凸轮机构：机架 + 凸轮 + 从动件
j1 = 2                       # 低副：凸轮−机架（转动）、从动件−机架（移动）
j2 = 1                       # 高副：凸轮与从动件的点接触
F = 3 * (n - 1) - 2 * j1 - 2 * j2   # ← 高副的系数应是 1，不是 2
print(F)
```

**练习 2**：一台小型装配机械臂，由 7 个构件组成（含机架），其中转动副 8 个、移动副 1 个、齿轮高副 1 个。求自由度并判断需要几个原动件。若实测发现装一台电机后运动不确定，可能是什么原因？

<details>
<summary>点开查看逐步解答</summary>

1. 低副数：$j_1 = 8 + 1 = 9$（转动副与移动副都是低副，各约束 2 个自由度）；高副数 $j_2 = 1$；
2. 代入：$F = 3(7-1) - 2\times9 - 1 = 18 - 18 - 1 = -1$；
3. **结论：$F = -1$，这是超静定结构，不是机构**——它根本不该动，装电机是设计错误；
4. 等等，先别下结论。**$F = -1$ 更可能意味着数错了**，而不是设计成了结构。回头检查：8 个转动副 + 1 个移动副 + 1 个齿轮副，在 7 构件上是不是有复合铰链？假设有两个铰点是三构件共销，那么真实的 $j_1 = 9 + 2 = 11$，$F = 18 - 22 - 1 = -5$，更负了——说明问题不在复合铰链；
5. 换个方向检查**虚约束**：如果机械臂里有一根平行的冗余连杆或一个冗余导轨，删掉它后 $n = 6$、$j_1 = 8$、$j_2 = 1$，则 $F = 15 - 16 - 1 = -2$。仍然不动。看来这确实是一台**结构**（比如一个带齿轮的刚性支架）；
6. 若题目要求它能动，正确做法是**减约束**：去掉 1 个低副（$j_1 = 8$）得 $F = 18 - 16 - 1 = 1$ ✓，正好一个原动件；
7. **关于"运动不确定"**：如果实测真的能动却不确定，说明实际自由度 $F \ge 2$，与计算值矛盾。可能原因：(a) 某个连接其实没有真正约束住（销孔间隙过大、键松动、导轨脱开），(b) 齿轮高副实际没有啮合（齿侧间隙过大），(c) 数的时候把某个"虚约束"当成了真实约束。**公式算的是设计意图，实测暴露的是制造现实**——两者不一致时，先去现场看销子有没有松。

</details>

## 7. 选读：Grübler 公式的一步推导，以及它和图论的关系

<details>
<summary>选读 · 从「每个刚体 3 个自由度」数到 F</summary>

**推导**。设机构有 $n$ 个构件（含机架），$j_1$ 个低副、$j_2$ 个高副。

第一步：如果所有构件互不连接，总自由度是 $3n$。

第二步：把机架固定，它的 3 个自由度归零；同时**其余构件的位置都要相对机架来描述**，所以机架不再单独贡献。这一步扣掉 3 个，剩 $3(n-1)$。

第三步：每个低副（转动副或移动副）连接两个构件，约束它们之间的**两个**相对自由度（转动副：锁住两个方向的相对平移；移动副：锁住一个平移加一个转动）。所以扣 $2j_1$。

第四步：每个高副（点/线接触）只约束**沿公法线方向**的一个相对移动，切向仍可相对滑动、也可相对转动。所以扣 $j_2$。

合起来：

$$F = 3(n-1) - 2j_1 - j_2$$

**与图论的关系**。把机构画成一张图：构件是顶点 $V$，运动副是边 $E$。那么 $|V| = n$，$|E| = j_1 + j_2$（不考虑复合铰链时）。Grübler 公式可以对着这张图重写：

$$F = 3(|V| - 1) - 2|E| - j_2$$

这和握手定理 $\sum \deg(v) = 2|E|$ 是同一类记账：**每条边被两个端点共享，所以对总数的贡献是 2 倍。** 低副贡献的"2"正来自这里——它是一条被两个构件共享的、削掉两个自由度的边。

复合铰链则对应"一条超边（hyperedge）连接 $k$ 个顶点"，它等价于 $k-1$ 条普通边——这就是误区一的图论解释。

顺带说明它和空间机构的关系：空间里每个刚体有 **6** 个自由度（3 个平移 + 3 个转动），公式升级为

$$F = 6(n-1) - \sum_i c_i$$

其中 $c_i$ 是第 $i$ 个运动副提供的约束数（1~5）。平面版本只是"所有运动副的轴线都平行/垂直，导致其中 3 个约束被自动满足"的特例。**六自由度机械臂、Stewart 平台用的就是空间版本**——但记法完全一样：先数总自由度，再逐条边扣掉它约束掉的那几个。

</details>
