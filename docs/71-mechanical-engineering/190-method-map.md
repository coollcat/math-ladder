# 机械工程方法地图

## 1. 从一个场景开始

车间里停着一台不转的输送机：电机发烫，滚筒轴断了，断口上有一圈一圈像贝壳纹路的花纹。18 门课学完了，工具箱里塞满了：静力平衡、自由体图、弯矩图、应力应变、挠度、屈曲、扭转、S-N 曲线、尺寸链、自由度、四连杆、凸轮、齿轮、带链、振动、有限元……

可现在的问题是：**先翻哪一课？**

学完一整章工具最大的风险从来不是忘了公式，而是"拿着锤子看什么都是钉子"。本课不添任何新定理，只做三件事：把全章课程排成一张**导诊地图**、演练一遍**分诊两问法**、再把最容易踩的坑一次性列队展览。

## 2. 直觉解释

机械故障分诊只需连问两个问题。

**第一问——现象落在哪一类？**

| 类别 | 典型症状 | 谁负责 |
| --- | --- | --- |
| **静力/强度** | 变形、裂纹、断裂、异响卡死 | 静力平衡、应力应变、扭转、材料 |
| **刚度/变形** | 下垂、晃动、定位不准 | 弯矩图、挠度、材料本构 |
| **失稳** | 细长件突然弯折、压不垮却自己弯了 | 屈曲 |
| **寿命** | 反复载荷下毫无征兆地断 | 疲劳 S-N |
| **运动与传动** | 转不动、速比不对、抖动、打滑 | 自由度、四连杆、凸轮、齿轮、带链 |
| **振动** | 抖、噪声、读数跳 | 隔振、共振 |
| **制造与装配** | 装不上、间隙大、互换性差 | 公差与尺寸链 |
| **形状太复杂** | 以上方法都下不了手 | 有限元 |

**第二问——特征尺度是什么？**

- **载荷量级**：N 级（仪表）还是 kN 级（压力机）？决定是"精确建模"还是"够粗够快"；
- **时间尺度**：静态、缓慢循环（疲劳）、冲击（韧性）、高频（振动与噪声）？**同一根轴在这四种工况下是四道完全不同的题**；
- **几何尺度**：长细比多大、壁厚多薄、跨度多长？决定是强度问题还是稳定问题。

两问答案往表上一对，科室基本锁定。剩下的分歧多半发生在"几种工具都能凑合"的地带——那时再比成本、体积、重量和可维护性，**而不是比谁听起来高级**。

## 4. 分步例题

**题 A**：输送机的滚筒轴运转三个月后断了，断口有贝壳状花纹，工作时载荷平稳。

1. 第一问：**寿命**类（反复受载、无预兆断裂）；第二问：时间尺度是"循环"（每天几千次），载荷量级中等；
2. 定位：贝壳纹是**疲劳断口**的典型形貌（裂纹逐圈扩展留下的痕迹）→ [疲劳 S-N](./100-fatigue.md)；
3. 处方：① 数裂纹源，若起源于**轴肩圆角**，那就是应力集中 + 表面质量的问题；② 查轴的**弯扭组合**应力幅（[扭转](./90-torsion.md) + [弯矩图](./60-beam-diagram.md)）；③ 用 Goodman 判据校核平均应力的影响；
4. **别急着换材料**：疲劳寿命对**表面粗糙度、圆角半径、过盈配合的微动磨损**比对材料牌号敏感得多。

**题 B**：给设备垫了橡胶隔振垫，振动反而变大。

1. 第一问：**振动**类；第二问：时间尺度是高频（压缩机 25 Hz 左右）；
2. 定位：测出 $f_n$，算 $r = f/f_n$。若 $r$ 落在 $1 \sim \sqrt{2}$，隔振垫就是放大器 → [振动与隔振](./170-vibration.md)；
3. 处方：把 $f_n$ 降到 $f/2.5$ 以下（换更软的垫或加重底座），**而不是加大阻尼**——阻尼只在过共振时救急；
4. 顺带查一遍支撑结构：垫子下面如果是薄钢板，钢板自己在振，那就该查 [梁的挠度](./70-beam-deflection.md) 与 [屈曲](./80-buckling.md)。

**题 C**：3D 打印的支架在孔边开裂，仿真显示应力远低于材料屈服强度。

1. 第一问：**形状复杂 + 强度**；第二问：几何尺度上有尖角（孔边），打印件还有各向异性；
2. 定位：孔边是**应力集中**处，理论应力集中系数 $K_t$ 可达 3；而打印件的实际强度可能只有标称值的一半 → [应力应变](./40-stress-strain.md) + [材料本构](./50-material.md)；
3. 处方：① 加圆角 / 加厚孔边；② 对打印件**按实测强度**而不是 datasheet 校核；③ 若用有限元，先做网格收敛性研究（[有限元](./180-fem.md)），孔边是典型的**奇点陷阱**——网格越密应力越高，永远不收敛。

## 5. 动手实验

### 实验 1（python）：给故障自动挂号

```python title="按症状开具科室单"
def triage(cyclic_crack, shaking, oversize, snaps_at_once):
    # 优先级闸门：越是「会继续坏下去、会伤人」的越早分流
    if snaps_at_once:
        return "stress-strain（静强度不够，先看名义应力）"
    if shaking:
        return "vibration（算 r = f/fn，验 √2 门槛）"
    if cyclic_crack:
        return "fatigue（数裂纹源，查 S-N 与 Goodman）"
    if oversize:
        return "tolerance（尺寸链，极值法还是统计法）"
    return "force-moment（回到受力图）"

cases = [
    ("运转三个月后断，断口有贝壳纹", True, False, False, False),
    ("又抖又裂", True, True, False, False),
    ("装配时有的装得上有的装不上", False, False, True, False),
    ("一启动就崩了", False, False, False, True),
]
for note, a, b, c_, d_ in cases:      # 元组解包：一次领出整行
    print(triage(a, b, c_, d_), "|", note)
```

四行输出就是四张挂号单。**注意 if 台阶的顺序本身就是知识**：一次性崩断排第一（静强度都不够，谈什么寿命），振动排第二（它既掩盖裂纹又加速裂纹），然后才是疲劳与公差。**分诊永远先看会不会继续坏、会不会伤人，再看舒不舒服。**

### 实验 2（python）：把量级钉在脑子里

```python title="机械工程师脑内必备的数量级"
print("── 应力（MPa）─────────")
for name, v in [("Q235 屈服", 235), ("6061 铝屈服", 276),

    print("%-24s %6.0f" % (name, v))

print("── 频率（Hz）─────────")
for name, f in [("电机 3000 rpm", 50), ("电机 1500 rpm", 25),

    print("%-24s %6.1f" % (name, f))

print("── 经验系数 ─────────")
print("  孔边 Kt ≈ 2~3        轴肩 Kt ≈ 1.5~2.5")
print("  隔振要求 r ≥ 2.5     链速波动 ∝ 1/Z²")

```

三段输出是"工程直觉"的量化版本。**判断一个设计靠不靠谱，往往不需要精确计算，只需要量级对不对**：断口应力 235 MPa 对 Q235 就是临界；设备固有频率 5 Hz 对 25 Hz 的激振就是安全。**错了会付出代价、对了一辈子受用的，正是这些数字。**

# @check: fatigue

### 快问快答

```quiz
一根细长压杆在远低于材料屈服强度的载荷下突然弯折，最应该翻哪一课，第一步做什么？
- 应力与应变：重新核算名义应力
- 压杆稳定与屈曲：先算长细比，再判断欧拉公式是否适用 [*]
- 梁的挠度：把它当成受弯构件重算
? 失稳与强度是两回事：强度不够才会屈服，失稳是「平衡形式本身变得不稳定」，载荷可以远低于屈服。第一步永远是算长细比 λ = μL/i，再比较 λp = π√(E/σy) 判断欧拉公式是否成立。
```

:::warning[常见误区]

**误区一**：「有限元算过了，设计就没问题。」
你以为彩色云图是真理——模型里没有**焊缝缺陷、表面粗糙度、装配预应力、材料批次差异、温度**，而真实世界全是这些东西。仿真的正确用法是"比较方案的优劣"，不是"证明设计合格"。**所有仿真结论都要回到试验和测量上确认一遍。**

**误区二**：「强度不够就换更贵的材料、加厚、加密网格。」
你以为"加料"是万能解——**先定瓶颈，再动参数**。疲劳断裂常常卡在表面质量和圆角（换高强钢毫无用处）；刚度不足常常是截面形状的问题而不是厚度（改 $I$ 比加厚有效得多）；仿真不准常常是边界条件错了（加密网格毫无用处）。**"加更好的材料"是最贵的解法，通常也最没用。**

**误区三**：「方法地图是一条通关路线。」
它是按需查阅的工具书，不是进度条。真实工作从来只摘用其中两三页。这张表真正想教的是**分诊的顺序**：先看会不会继续坏、会不会伤人（断裂、失稳、共振、过载），再看功能对不对（速比、行程、同步），最后才优化性能（重量、成本、寿命）。**顺序错了，会越修越坏。**

:::

## 6. 练习

**练习 1**：一根两端铰支的圆截面压杆，长 $L = 1500$ mm、直径 $d = 20$ mm、材料 $E = 200$ GPa、$\sigma_y = 235$ MPa。该先查强度还是先查屈曲？这段代码把回转半径算错了，修正后应输出 `先查屈曲（λ = 300，λp = 92）`：

```exercise
# @title: 练习：回转半径算错了
# @check: 先查屈曲（λ = 300，λp = 92）
# @hint: 回转半径 i = √(I/A)，不是 I/A。实心圆杆的 I/A = d²/16，所以 i = d/4 = 5 mm
import math                        # 数学库：pi / sqrt

L, d, E, sy = 1500.0, 20.0, 200000.0, 235.0
A = math.pi * d * d / 4                       # 截面积
I = math.pi * d ** 4 / 64                     # 惯性矩
i = I / A                                     # ← 问题在这：i 应为 math.sqrt(I / A)
lam = L / i                                   # 长细比
lp = math.pi * math.sqrt(E / sy)              # 欧拉公式适用的临界长细比
print(("先查屈曲（λ = %.0f，λp = %.0f）" % (lam, lp)) if lam > lp
      else ("先查强度（λ = %.0f，λp = %.0f）" % (lam, lp)))
```

**练习 2**：一台带式输送机，电机 $1440$ rpm、扭矩 $5$ N·m，要求滚筒 $90$ rpm，中心距约 $600$ mm，每天运行 $16$ 小时。请给出传动方案与校核清单。

<details>
<summary>点开查看逐步解答</summary>

1. **先算总传动比**：$i = 1440/90 = 16$。查 [齿轮](./150-gear-train.md)：单级不超过 4.5，故至少三级（$16^{1/3} = 2.52$）；
2. **选传动形式**：$600$ mm 的中心距，齿轮箱 + 链传动是常见组合——减速箱内做两级（$i=4$），外露段用链传动（$i=4$）。**带传动要排除**：打滑会让输送量随负载漂，且 $16$ 小时连续运行的皮带寿命与张紧维护都麻烦（[带链](./160-belt-chain.md)）；
3. **链轮齿数**：小链轮取 $Z_1 = 21$，大链轮 $Z_2 = 84$。查 $84 \le 120$ ✓（超过 120 会因链条伸长而跳齿）。链速波动 $\pm0.56\%$，对输送机可接受，若要求更稳则取 $Z_1 = 25$；
4. **算扭矩与强度**：输出扭矩 $T = 5\times16\times\eta$，三级齿轮 $\eta = 0.97^2$、链 $\eta = 0.96$ → $T = 5\times16\times0.903 = 72$ N·m；按此校核 [扭转](./90-torsion.md) 的 $\tau = Tr/J$ 与轴的强度；
5. **查寿命**：每天 $16$ 小时、$90$ rpm → 每年约 $5.3\times10^7$ 次循环，属于**高周疲劳**范畴，轴的圆角处必须校核 [疲劳](./100-fatigue.md)，且**按无限寿命设计**（应力幅低于疲劳极限）；
6. **查振动**：电机 $24$ Hz、链传动的啮合频率 $= Z_1 n/60 = 21\times1440/60 = 504$ Hz。前者要查机架的 $f_n$ 是否撞车（[隔振](./170-vibration.md)），后者是噪声源，靠齿数与润滑改善；
7. **最后才是装配**：链中心距可调（补偿链条伸长），电机与减速箱之间用联轴器并留出对中公差（[公差](./110-tolerance.md)）。

**这道题的价值在于"顺序"**：传动比 → 形式 → 强度 → 寿命 → 振动 → 装配。每一步都可能推翻前面的选择，所以真实设计是**螺旋式**的，不是一条直线走到底。

</details>

## 7. 选读：三条游览路线

<details>
<summary>选读 · 不同胃口的吃法</summary>

**结构强度线**（做承力件的读法）：力与力矩 → 自由体图 → 桁架 → 应力应变 → 材料本构 → 弯矩图 → 挠度 → 屈曲 → 扭转 → 疲劳 → 有限元。这条线回答"它会不会坏"，终点是疲劳与断裂力学——**绝大多数真实失效都发生在这里**。

**运动与传动线**（做机器的读法）：自由度 → 四连杆 → 凸轮 → 齿轮 → 带链 → 振动。这条线回答"它怎么动"，终点是动力学与振动控制——**速度一上去，所有静态设计都要重算一遍**。

**制造落地线**（做产品的读法）：在强度线上补公差与尺寸链，在传动线上补振动与噪声，再补有限元做形状优化。重点不在"算得准"，而在"批量能不能做、成本能不能降、坏了好不好修"。

**三条线最后都汇入同一句话**：机械设计的本质不是套公式，而是**在相互矛盾的约束之间做取舍**——强度与重量、精度与成本、刚度与隔振、同步与过载保护。地图能帮你找到工具，**取舍只能靠你自己拍板**。

</details>
