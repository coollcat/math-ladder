# 机械振动与隔振

## 1. 从一个场景开始

一台精密测量仪放在车间里，隔壁有一台每分钟 1500 转的压缩机。仪器读数一直在跳，工程师在脚下垫了四块橡胶——**读数跳得更厉害了**。

橡胶垫是"隔振器"，怎么会让振动变大？因为隔振有个门槛：**只有当机器的转速高于某个值时，软垫才开始隔振；低于它，软垫是放大器。** 那个门槛不是经验的模糊地带，而是一个精确的数字：$\sqrt{2}$。

而如果你在第 68 章学过 RLC 电路，这一课你会觉得眼熟到不自然——**弹簧、质量、阻尼器，和电感、电容、电阻，写出来的方程是同一个。**

## 2. 直觉解释

先建立一个画面：**一个重物挂在弹簧上，中间并联一个"活塞在油缸里"的阻尼器**。

- **弹簧**储存位移的能量：拉开它，它想回来；
- **质量**储存速度的能量：动起来了，它想继续；
- **阻尼**只做一件事：把能量变成热，让振动衰减。

你手压一下再松开，重物会以某个固定的频率来回晃——这个频率**只由 $k$ 和 $m$ 决定**，跟你压多重无关，叫**固有频率**。晃动的快慢是系统自己的脾气。

外界的激振则是另一回事。如果你按**自己的节奏**去推：

- 推得**很慢**（远慢于固有频率）：重物老老实实跟着你走，幅度几乎一样 → 传递率 $\approx 1$；
- 推得**刚好合拍**（等于固有频率）：每一次都推在"顺势"的方向上，能量持续累积，幅度可以放大几十倍 → **共振**；
- 推得**很快**（远快于固有频率）：重物因为惯性来不及动，几乎待在原地 → **隔振**。

中间那条分界线就是 $r = \sqrt{2} \approx 1.414$。**慢于它，软垫放大；快于它，软垫隔振。**

## 3. 正式定义

**单自由度受迫振动**（基础激励，即振源来自地基）：

$$m\ddot{x} + c\dot{x} + kx = c\dot{y} + ky$$

**固有频率与临界阻尼**：

$$\omega_n = \sqrt{\frac{k}{m}},\qquad f_n = \frac{\omega_n}{2\pi},\qquad c_c = 2\sqrt{km} = 2m\omega_n,\qquad \zeta = \frac{c}{c_c}$$

**频率比与位移传递率**：

$$r = \frac{f}{f_n},\qquad T = \frac{X}{Y} = \sqrt{\frac{1 + (2\zeta r)^2}{(1-r^2)^2 + (2\zeta r)^2}}$$

**三条硬结论**：

1. **$T < 1 \iff r > \sqrt{2}$**：所有阻尼比的曲线都在 $r=\sqrt{2}$、$T=1$ 处交于一点；
2. **共振峰**在 $r \approx \sqrt{1-2\zeta^2}$ 处，峰值 $T_{\max} \approx \dfrac{1}{2\zeta\sqrt{1-\zeta^2}}$，小阻尼下近似 $T_{\max} \approx 1/(2\zeta)$；
3. **阻尼是双向的**：$r < \sqrt{2}$ 时加大阻尼**压低**共振峰（好事）；$r > \sqrt{2}$ 时加大阻尼反而**抬高** $T$（坏事）。

**力-电压类比**（与第 68 章 RLC 的对应关系，两边方程逐项同构）：

| 机械量 | 电路量 | 说明 |
| --- | --- | --- |
| 力 $F$ | 电压 $v$ | 都是"势"（激励源） |
| 速度 $\dot{x}$ | 电流 $i$ | 都是"流" |
| 质量 $m$ | 电感 $L$ | 都抗拒**变化**（惯性 / 感抗） |
| 阻尼 $c$ | 电阻 $R$ | 都把能量变成热 |
| 弹簧刚度 $k$ | $1/C$ | 弹簧越硬 $\Leftrightarrow$ 电容越小 |
| 位移 $x$ | 电荷 $q$ | 位移是速度的积分，电荷是电流的积分 |
| $\omega_n = \sqrt{k/m}$ | $\omega_0 = 1/\sqrt{LC}$ | 同一个公式 |

**这意味着第 68 章的整套结论可以整搬过来**：RLC 的谐振峰 = 机械共振，品质因数 $Q = 1/(2\zeta)$，Bode 图上 $-40$ dB/dec 的高频滚降 = 隔振区 $T \approx 1/r^2$。

## 4. 分步例题

**例**：设备 $m = 20$ kg，四个橡胶垫总刚度 $k = 20$ kN/m，阻尼比 $\zeta = 0.1$。(a) 固有频率与临界阻尼；(b) 车间激振 $f = 12.6$ Hz 时隔掉多少；(c) 若把阻尼比提到 0.5 会怎样；(d) 若激振降到 5 Hz 会怎样。

1. **固有频率**：$\omega_n = \sqrt{20000/20} = 31.62$ rad/s → $f_n = 31.62/6.283 = 5.03$ Hz；
2. **临界阻尼**：$c_c = 2\sqrt{20000\times20} = 1265$ N·s/m，故实际阻尼 $c = 0.1\times1265 = 126.5$ N·s/m；
3. **(b) 频率比**：$r = 12.6/5.03 = 2.5 > \sqrt{2}$ ✓ 在隔振区。代入 $T = \sqrt{(1+0.25)/(27.56+0.25)} = \sqrt{1.25/27.81} = 0.212$ → **隔掉 78.8%**；
4. **(c) 加大阻尼到 0.5**：$T = \sqrt{(1+6.25)/(27.56+6.25)} = \sqrt{7.25/33.81} = 0.463$ → 只隔掉 53.7%。**阻尼加大，隔振效果明显变差**——这正是"垫了橡胶反而更糟"的一种成因；
5. **(d) 激振降到 5 Hz**：$r = 5/5.03 \approx 1.0$ → **共振**，$T \approx 1/(2\times0.1) = 5.1$，振幅被放大五倍。此时唯一出路是**错开频率**（改刚度）或**加大阻尼**（$\zeta = 0.5$ 时共振峰降到 1.41）；
6. **工程结论**：隔振设计的第一步永远是**算出 $f_n$，确认它远低于激振频率**（通常要求 $r \ge 2.5$，即 $f_n \le f/2.5$），而不是先挑"软一点还是硬一点"的垫子。

上半部分是"机器在振动的地基上"的动画：地基按 $100\%$ 的幅度上下动，质量块的幅度就是 $T\times100\%$。下半部分是传递率曲线。

- **把 `r` 从 0 慢慢拖到 4**：质量块的振幅先是和地基同步（$T\approx1$），到 $r\approx1$ 时**猛地放大**（质量块边框变红），过了 $r=\sqrt{2}$ 那条绿色虚线后才开始收缩，最后几乎不动；
- **绿色底纹就是隔振区**（$r>\sqrt{2}$、$T<1$），淡色虚线是其它阻尼比的曲线，**它们全都在同一点穿过 $T=1$**；
- **在 $r=2.5$ 处把 `zeta` 从 0.02 加到 0.8**：工作点沿着虚线**往上爬**——阻尼在隔振区是帮倒忙的；
- **再回到 $r=1.0$ 处加 `zeta`**：峰值应声下落——同一个参数，在两个区域的作用完全相反。

最后做一次"设计动作"：把 `m` 从 20 加到 80 kg，$f_n$ 立刻降到一半（$f_n\propto 1/\sqrt{m}$）。**加重设备本身就是一种隔振手段**——所以精密仪器都装在沉重的花岗岩底座上。

### 实验 2（python）：把三条结论一次扫出来

```python title="传递率：r、ζ 与设计门槛"
import math                        # 数学库：sqrt / pi / hypot

m, k = 20.0, 20000.0
fn = math.sqrt(k / m) / (2 * math.pi)          # 固有频率（Hz）
wn = 2 * math.pi * fn                          # 固有角频率（rad/s）
print("fn = %.3f Hz | ωn = %.1f rad/s | 临界阻尼 cc = %.0f N·s/m"
      % (fn, wn, 2 * math.sqrt(k * m)))

def T(r, zeta):
    """基础激励下的位移传递率"""
    num = math.sqrt(1 + (2 * zeta * r) ** 2)
    den = math.hypot(1 - r * r, 2 * zeta * r)  # hypot(a,b) = √(a²+b²)
    return num / den

print("\n  r     ζ=0.02   ζ=0.10   ζ=0.50")
for r in (0.5, 1.0, 1.414, 2.5, 4.0):
    print("%6.3f %8.3f %8.3f %8.3f" % (r, T(r, 0.02), T(r, 0.10), T(r, 0.50)))

zeta = 0.05
r = 1.0
while T(r, zeta) > 0.2:                        # 想隔掉 80%，需要多大的频率比
    r += 0.01
print("\n隔掉 80%%（T ≤ 0.2）需要 r ≥ %.2f，即 fn ≤ f / %.2f" % (r, r))
```

最重要的一行是表格里的 $r = 1.414$：**三种阻尼比下的 $T$ 分别是 1.000、1.001、1.000**——它们在同一点穿过 $T=1$，这就是 $\sqrt{2}$ 法则的数值证据。

再看两端的对比：$r=1.0$ 时阻尼从 0.02 提到 0.5，$T$ 从 25 降到 1.41（救了命）；$r=4.0$ 时同样的改动，$T$ 从 0.068 涨到 0.266（效果差了四倍）。**同一个参数，两个区域，结论相反。** 设计时第一件事是问"我在哪一侧"，而不是"阻尼要不要加"。

### 快问快答

```quiz
一台设备装上隔振器后振动反而变大，激振频率是 12 Hz，测出系统固有频率是 10 Hz。最合理的第一步处理是什么？
- 换成更软的隔振器，把固有频率降下来 [*]
- 换成阻尼大得多的隔振器
- 把设备固定得更牢，取消隔振
? r = 12/10 = 1.2，还在 √2 以下的放大区，此时软垫确实是放大器。加阻尼只能压一点峰（且设备通常工作在放大区边缘），正确做法是把 fn 降到 12/2.5 ≈ 4.8 Hz 以下，让 r ≥ 2.5 真正进入隔振区。
```

:::warning[常见误区]

**误区一**：「隔振垫越软越好，垫上就一定隔振。」
你以为软就等于隔——其实**只有在 $r > \sqrt{2}$ 时才隔振**。软垫把 $f_n$ 降下来，确实能增大 $r$，但如果你降得不够（或者原本就很软，$r$ 反而落在 $1\sim\sqrt{2}$ 之间），机器会从"共振"变成"放大"。**软垫不是万能药，它是把工作点沿曲线往右推的一种手段**——推到哪儿必须算。

**误区二**：「阻尼大一点总归是好事。」
你以为阻尼只负责消耗能量——它在**隔振区**是负担：$r=4$、$\zeta$ 从 0.02 提到 0.5，$T$ 从 0.068 涨到 0.266，隔振效果差了近四倍。真实设计里的做法是**用小阻尼的橡胶/金属弹簧做隔振，另外配阻尼器专门对付启停过共振的那一瞬间**（启动时会扫过 $r=1$，那时必须靠阻尼）。

**误区三**：「机器振动的频率就是它的固有频率。」
你以为这两个是一回事——**振动频率等于激振频率**（电机转速、压缩机冲程、路面不平度），而**固有频率是系统的属性**，只由 $k$ 和 $m$ 决定。振动学里绝大多数事故，都出在"这两个频率意外撞到了一起"。所以设计流程是：先查清激振频率有哪些，再让 $f_n$ 躲开它们。

:::

**练习 2**：一台 $200$ kg 的设备，车间激振频率 $25$ Hz（压缩机 $1500$ rpm），阻尼比 $\zeta = 0.05$。要求隔掉 $80\%$ 以上，请给出隔振器刚度与校核要点。

<details>
<summary>点开查看逐步解答</summary>

1. **先定频率比**：由实验 2 的结论，$T \le 0.2$ 需要 $r \ge 2.48$（$\zeta = 0.05$）；
2. **反求固有频率**：$f_n \le 25/2.48 = 10.1$ Hz，取 $f_n = 10$ Hz；
3. **反求总刚度**：$k = m(2\pi f_n)^2 = 200\times(62.83)^2 = 7.90\times10^5$ N/m。**四个支点平分，每个 $1.97\times10^5$ N/m**；
4. **校核静态变形**：$\delta = mg/k = 1962/7.90\times10^5 = 2.5$ mm —— 这个数很关键：橡胶垫压缩 2.5 mm 是合理的，若算出 25 mm 说明垫子太软（会摇晃失稳），算出 0.2 mm 说明太硬（装了等于没装）；
5. **查共振穿越**：启动时转速从 0 升到 1500 rpm，必然扫过 $f_n = 10$ Hz。此时 $\zeta=0.05$ 的共振放大倍数 $T_{\max} \approx 1/(2\times0.05) = 10$，需要在几分钟内快速通过，或临时加大阻尼；
6. **别忘了第二阶**：这是单自由度模型的答案。真实设备有六个自由度（三平动三转动），还有设备本身的柔性模态——**完整的隔振设计要查到第二、第三阶固有频率**。

**这道题想说的是**：隔振不是"挑个软垫"，而是**先算 $f_n$，再反求 $k$，再用静态变形校核能不能做出来**，最后还要检查启停时会不会在共振点上待太久。

## 7. 选读：传递率公式是怎么来的

<details>
<summary>选读 · 用复数一次解出 T</summary>

设基础位移 $y = Y e^{j\omega t}$，质量块位移 $x = X e^{j\omega t}$，代入运动方程

$$m\ddot{x} + c\dot{x} + kx = c\dot{y} + ky$$

利用 $\frac{d}{dt} \to j\omega$，得

$$\left(-\omega^2 m + j\omega c + k\right)X = \left(j\omega c + k\right)Y$$

于是传递函数

$$\frac{X}{Y} = \frac{k + j\omega c}{k - \omega^2 m + j\omega c}$$

取模，并用 $r = \omega/\omega_n$、$c = 2\zeta m\omega_n$ 化简：

$$T = \left|\frac{X}{Y}\right| = \frac{\sqrt{k^2 + (\omega c)^2}}{\sqrt{(k-\omega^2 m)^2 + (\omega c)^2}} = \sqrt{\frac{1 + (2\zeta r)^2}{(1-r^2)^2 + (2\zeta r)^2}}$$

**这就是第 68 章相量法的翻版**：把微分方程换成代数方程，复数除法取模得幅值、取辐角得相位。

两个推论：

1. **$T=1$ 的条件**：令 $T^2 = 1$，即 $1+(2\zeta r)^2 = (1-r^2)^2 + (2\zeta r)^2$，$(1-r^2)^2 = 1$，解得 $r = 0$ 或 $r^2 = 2$ → $r = \sqrt{2}$。**与 $\zeta$ 无关**，所以所有曲线交于一点；
2. **高频渐近**：$r \gg 1$ 时 $T \approx 1/r^2$，即每倍频程衰减 12 dB——与二阶低通滤波器完全一致的滚降斜率。

</details>
