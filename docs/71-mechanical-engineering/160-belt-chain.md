# 带传动与链传动

## 1. 从一个场景开始

洗衣机里电机离滚筒有半米远，中间靠一根皮带；摩托车的发动机离后轮也有半米，中间靠一根链条。两件事看起来一模一样：隔空把运动和力送过去。

可是皮带会**打滑**——皮带机卡料时电机照转、滚筒不动，电机因此活了下来；链条从来不打滑，但骑摩托车的人都知道，链条在小链轮上会**一顿一顿地抖**，转速越高抖得越凶。

一个靠摩擦、一个靠啮合。这两个选择各自标好了价格：**摩擦型给你免费的过载保护，却偷走一点同步；啮合型给你严格的同步，却带来周期性的速度脉动。**

## 2. 直觉解释

先想皮带：把它想象成一根**绕在两个轮子上的橡皮筋**。静止时两端张力相同（初拉力 $F_0$）。一开机，主动轮要把带往自己这边拽，于是**进入的一边被拉紧（紧边 $F_1$），离开的一边变松（松边 $F_2$）**。

传递的力不是 $F_1$，而是**两边之差** $F_e = F_1 - F_2$——松边在往回拉，是"内耗"。

那这个差最大能有多大？关键的反直觉点来了：**它由摩擦封顶，而且是指数式的**：

$$\frac{F_1}{F_2} = e^{\mu\alpha}$$

$\alpha$ 是带绕在小轮上的包角（弧度）。包角从 120° 加到 180°，比值从 $e^{0.3\times2.09}=1.87$ 涨到 $e^{0.3\times3.14}=2.57$——**多绕一点，能力涨得比线性快**。这就是为什么张紧轮总被放在松边外侧：它不是"压紧"，而是**增大包角**。

再想链条：链条不是绕在圆上，而是绕在一个**正多边形**上（每个齿对应一条边）。链节一会儿在"边的中点"（离中心近），一会儿在"顶点"（离中心远），于是链条的线速度一会儿快一会儿慢——这就是**多边形效应**。齿数越少，多边形越"棱角分明"，抖得越厉害。

## 3. 正式定义

**欧拉公式（挠性体摩擦）**：带在即将打滑的临界状态下

$$\frac{F_1}{F_2} = e^{\mu\alpha}\quad(\alpha\ \text{用弧度})$$

**初拉力约束**（带长近似不变，紧边多拉多少松边就少多少）：

$$F_1 + F_2 = 2F_0 \;\Longrightarrow\; F_2 = \frac{2F_0}{1 + e^{\mu\alpha}},\quad F_1 = e^{\mu\alpha}F_2$$

**有效拉力与功率**：

$$F_e = F_1 - F_2 = 2F_0\,\frac{e^{\mu\alpha}-1}{e^{\mu\alpha}+1},\qquad P = F_e\,v$$

**弹性滑动 vs 打滑**：弹性滑动是带的弹性变形引起的**局部、不可避免**的微量滑动（约 $1\%\sim2\%$），它决定了带传动**不能保证严格同步**；打滑是有效拉力超过摩擦极限后的**整体滑动**，会发热、磨损、烧毁带。

**多边形效应**：链轮分度圆半径 $R = \dfrac{p}{2\sin(\pi/Z)}$（$p$ 为节距、$Z$ 为齿数）。瞬时链速

$$v = R\omega\cos\beta,\qquad \beta \in \left[-\frac{\pi}{Z},\ \frac{\pi}{Z}\right]$$

速度波动（峰谷差）：

$$\frac{\Delta v}{v} = 1 - \cos\frac{\pi}{Z} \approx \frac{\pi^2}{2Z^2}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $F_1/F_2$ | 紧边 / 松边拉力 | 主动轮"进"的一侧是紧边 |
| $F_0$ | 初拉力 | 静止时带内的张力，靠张紧维持 |
| $\mu$ | 摩擦系数 | 橡胶-铸铁约 0.3；带型与轮面决定 |
| $\alpha$ | 包角 | 带绕在**小轮**上的角度，小轮上更小 |
| $F_e$ | 有效拉力 | 真正传递的圆周力，$F_1 - F_2$ |
| $Z$ | 链轮齿数 | 越少多边形效应越强，通常 $\ge 17$ |

## 4. 分步例题

**例**：$\mu = 0.3$，小轮包角 $\alpha = 160^\circ$，初拉力 $F_0 = 400$ N，带速 $v = 5$ m/s。求能传多少力与多少功率；若要传 $500$ N 会怎样？

1. **把包角换成弧度**：$\alpha = 160^\circ \times \pi/180 = 2.793$ rad；
2. **欧拉比值**：$e^{\mu\alpha} = e^{0.3\times2.793} = e^{0.838} = 2.311$；
3. **松边拉力**：$F_2 = \dfrac{2\times400}{1+2.311} = 241.6$ N；
4. **紧边拉力**：$F_1 = 2.311\times241.6 = 558.4$ N；
5. **有效拉力**：$F_e = 558.4 - 241.6 = 316.8$ N，**功率** $P = 316.8\times5 = 1584$ W $\approx 1.58$ kW；
6. **要传 500 N**：$500 > 316.8$，摩擦撑不住 → **打滑**。两条出路：把 $F_0$ 提到 $400\times500/316.8 = 631$ N（轴承受力跟着涨，寿命下降），或者**增大包角**（加张紧轮，或把小轮挪远一点）；
7. **链传动对照**：同样的中心距换链条，$Z = 17$ 时速度波动 $\pm0.85\%$，$Z = 25$ 时降到 $\pm0.39\%$。链不受摩擦封顶，能传的力只受链条抗拉强度和铰链比压限制——但它给不出精确的传动比。

带传动模式下（红边是紧边，蓝边是松边，黄色弧是包角）：

- 拖动 `mu` 从 0.05 到 0.8，看读数栏的 $F_1/F_2$ 从 1.15 一路飙到十几——**指数关系不是线性的**，摩擦系数翻倍，能力远不止翻倍；
- 拖动 `alpha`，注意图上同时标出了**实际几何包角**（由两个轮的大小和中心距算出）。小轮上的包角总是更小，**打滑总是先从松边一侧的小轮开始**；
- 拖动 `F0`：$F_1$、$F_2$ 一起涨，但比值不变——**初拉力提高的是容量，不是效率**，代价是轴和轴承一直承受 $2F_0$。

链传动模式下（左边是链轮多边形，右边是 $v(\theta)$ 曲线）：

- 拖 `Z` 从 40 往 6 拉，看右边那条紫色的瞬时链速曲线从近乎平直变成明显的"驼峰"；
- 读数栏的**速度波动**按 $1/Z^2$ 缩放：$Z=17$ 时 $\pm0.85\%$，$Z=11$ 时 $\pm2.03\%$；
- $Z < 13$ 时读数栏会提示"齿数偏少：高速时噪声与冲击大"——这就是摩托车链条在低速时安静、高速时"哗哗"响的原因。

### 实验 2（python）：两个公式的量化对照

```python title="欧拉公式与多边形效应：一口气扫完参数"
import math                        # 数学库：exp / cos / pi / radians

def belt(mu, alpha_deg, F0, v):
    """返回欧拉比值、紧边、松边、可传功率（W）"""
    e = math.exp(mu * math.radians(alpha_deg))     # 注意：包角必须用弧度
    F2 = 2 * F0 / (1 + e)
    F1 = e * F2
    return e, F1, F2, (F1 - F2) * v

for mu in (0.15, 0.3, 0.5):
    e, F1, F2, P = belt(mu, 160.0, 400.0, 5.0)
    print("μ = %.2f | e^(μα) = %5.3f | F1 = %6.1f N | F2 = %6.1f N | Fe = %6.1f N | P = %.2f kW"
          % (mu, e, F1, F2, F1 - F2, P / 1000))

print("── 链传动：多边形效应（波动 ∝ 1/Z²）──")
for Z in (11, 17, 25, 33):
    fluct = 1 - math.cos(math.pi / Z)              # 峰谷波动
    print("Z = %2d | 链速波动 ±%.2f%%（峰谷 %.2f%%）" % (Z, fluct * 50, fluct * 100))
```

上半段三行把"摩擦封顶"讲透了：$\mu$ 从 0.15 涨到 0.5（3.3 倍），可传功率从 $0.83$ kW 涨到 $2.41$ kW（2.9 倍），**而不是跟着线性涨**——因为 $F_2$ 也在变小，紧边的增量没有全部变成有效拉力。

下半段四行是链的价格表：$Z$ 从 11 加到 33（3 倍），波动从 $\pm2.03\%$ 降到 $\pm0.23\%$（约 $1/9$）——**平方律**。所以链传动的选型规则很简单：**小链轮齿数别太小，但也不宜过大**（齿数太多则链条磨损后容易"爬齿"跳齿，通常取 $17\sim25$）。

### 快问快答

```quiz
带传动在额定载荷下工作时，紧边拉力 800 N、松边拉力 400 N。此时若负载突然加倍，最可能发生什么？
- 有效拉力跟着加倍，带不打滑
- 所需有效拉力超过摩擦极限，带开始整体打滑 [*]
- 松边拉力变成零，但传动继续
? 欧拉公式给的是比值上限 F1/F2 = e^(μα)。这里比值已经是 2，说明已接近极限（初拉力固定时两边之和不变），负载加倍就得突破这个比值上限，只能靠整体打滑。这正是皮带机卡料时保护电机的机制。
```

:::warning[常见误区]

**误区一**：「带打滑是故障，说明初拉力没调够。」
你以为打滑一定是坏事——其实摩擦封顶是带传动**内置的过载保护**：卡料时电机照转，不会烧。把初拉力一味加大来"杜绝打滑"，等于亲手拆掉这层保护，代价还要由轴承和轴去付（它们一直承受 $2F_0$）。正确做法是**按需要的过载倍数留出可控的打滑点**。

**误区二**：「包角取 180° 就行。」
你以为两轮直径相近就是 180°——其实**包角要按小轮算**，而小轮上的包角总是更小：$\alpha_{小} = 180^\circ - 2\arcsin\frac{D_2-D_1}{2C}$（$C$ 为中心距）。传动比越大、中心距越短，小轮包角越小，**打滑永远从小轮开始**。这也是为什么大传动比的带传动必须加张紧轮。

**误区三**：「链传动不打滑，所以高速平稳性比带好。」
你以为啮合就等于平稳——其实链条绕在正多边形链轮上，瞬时链速按 $\cos\beta$ 周期性波动，产生**周期性的惯性力与冲击**。$Z=11$ 时波动达 $\pm2\%$，在高速下就是噪声、振动和链条疲劳的来源。带传动有弹性滑动不同步，但它**吸振**，所以高速轻载反而常用带（如汽车正时皮带、砂轮机）。

:::

**练习 2**：一台链传动输送机，小链轮转速 $600$ rpm，要求链速波动不超过 $\pm0.5\%$，且链条节距 $p = 12.7$ mm。请给出齿数选择与校验要点。

<details>
<summary>点开查看逐步解答</summary>

1. **按波动定齿数**：$\pm\frac{1}{2}\left(1-\cos\frac{\pi}{Z}\right) \le 0.005$，即 $1 - \cos(\pi/Z) \le 0.01$，$\cos(\pi/Z) \ge 0.99$，$\pi/Z \le 0.1415$ → $Z \ge 22.2$，取 **$Z = 23$**（奇数齿还能让磨损更均匀）；
2. **算分度圆直径**：$R = \dfrac{p}{2\sin(\pi/Z)} = \dfrac{12.7}{2\sin(7.83^\circ)} = \dfrac{12.7}{2\times0.1362} = 46.6$ mm，分度圆直径 $D = 93.2$ mm；
3. **算链速**：$v = \dfrac{Z\,p\,n}{60\times1000} = \dfrac{23\times12.7\times600}{60000} = 2.92$ m/s，在中低速范围，链条寿命可观；
4. **校验多边形效应**：$1-\cos(\pi/23) = 0.93\%$，峰谷波动 0.93%，即 $\pm0.46\%$ ✓ 满足要求；
5. **别忘了另一头**：小链轮齿数定了，**大链轮的齿数不能超过 120**（否则链条磨损伸长后极易跳齿），所以单级链传动的传动比通常 $\le 6\sim7$。

**这道题的核心是"指标反求"**：波动要求直接决定了最小齿数，齿数又决定了分度圆直径和链速，而链速反过来约束链条寿命。**所有参数是一张网，动一个就得全查一遍。**

## 7. 选读：欧拉公式——从一段微元积分出来

<details>
<summary>选读 · 为什么是 e 的指数</summary>

取带上对应圆心角 $d\theta$ 的一小段微元，设它两端的张力为 $T$ 与 $T+dT$，轮面对它的正压力为 $dN$，摩擦力为 $\mu\,dN$。

微元在法向与切向分别平衡（忽略离心力，低速时成立）：

$$dN = T\,d\theta\quad(\text{法向：张力方向变化产生的向心分量})$$
$$dT = \mu\,dN = \mu T\,d\theta\quad(\text{切向：摩擦刚好平衡张力增量})$$

第二式就是 $\dfrac{dT}{T} = \mu\,d\theta$，两边从松边积到紧边：

$$\int_{F_2}^{F_1}\frac{dT}{T} = \mu\int_0^{\alpha} d\theta \;\Longrightarrow\; \ln\frac{F_1}{F_2} = \mu\alpha \;\Longrightarrow\; \frac{F_1}{F_2} = e^{\mu\alpha}$$

三个值得记住的点：

1. **指数来自"每一步的增量正比于当前值"**——这与第 03 章的复利、第 22 章的指数增长是同一个微分方程 $dT/d\theta = \mu T$；
2. **与带宽、带长、轮径全都无关**——只取决于 $\mu$ 和 $\alpha$。这是那种"看起来太简单以至于不敢信"的结论，但它被实验反复验证；
3. **高速时要加离心修正**：带绕轮运动产生离心力，抵消了一部分正压力，可用的摩擦随之下降——这就是带传动有**推荐带速上限**（通常 $v \le 25$ m/s）的原因。

</details>
