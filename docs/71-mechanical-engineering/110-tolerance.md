# 公差配合与尺寸链

## 1. 从一个场景开始

一台减速机的输出轴上串着五个零件：壳体、垫片、齿轮、隔套、端盖。每个零件出厂都**检验合格**——尺寸全都落在自己的公差带里。

装起来之后，轴承游隙不是卡死就是松旷，装配线上的返工率超过 20%。

问题出在：五个零件各自"合格"，但它们串成一条**封闭的尺寸链**之后，误差会累加。而累加的方式有两种算法，结果差一倍——**选哪种，决定了你的公差是省钱还是浪费。**

## 2. 直觉解释

想象五个人排成一列，每人被蒙着眼往前走一步。

**最坏情况**：五个人全都朝同一个方向多走了半步——队伍总长偏差就是五个人的误差之和。但这需要五个人"串通好"往同一边偏，**概率极小**。

**现实情况**：有人走多了、有人走少了，**误差会互相抵消**。多数时候队伍总长偏差远小于最坏值。这就是**随机误差的抵消效应**——多个独立误差相加时，它们不是按数值相加，而是按**方差**相加。

于是出现两种算法：

- **极值法**（worst case）：$T = \sum |t_i|$，把误差直接相加。保证 100% 合格，但公差被压得极紧，加工成本高到离谱；
- **统计法**（RSS）：$T = \sqrt{\sum t_i^2}$，平方和再开根号。允许极个别装配超差，换来公差放松近一倍。

关键权衡是：**极值法买的是"绝对不出事"，代价是每一环都要加工得很准；统计法赌的是"极端巧合很少发生"，代价是要有过程能力管控。**

## 3. 正式定义

**尺寸链**：若干个相互关联的尺寸首尾相接形成的封闭链。链上每个尺寸叫一个**环**，最后一个被"挤出来"的尺寸叫**封闭环**（比如装配间隙）。

**极值法**（保守，100% 覆盖）：

$$T_{\text{worst}} = \sum_{i} |t_i|$$

**统计法 / 均方根法**（RSS = root sum square）：

$$T_{\text{RSS}} = \sqrt{\sum_{i} t_i^2}$$

**为什么是平方而不是直接相加？** 因为**独立随机变量的方差可加**：

$$\sigma_X^2 = \sum_i \sigma_i^2 \quad\Longrightarrow\quad \sigma_X = \sqrt{\sum_i \sigma_i^2}$$

若各环公差按 $\pm 3\sigma$ 覆盖（即合格率为 99.73%），则 $\sigma_i = t_i/3$，封闭环的

$$\sigma_X = \frac{T_{\text{RSS}}}{3}$$

**装配合格率**（封闭环落在允许公差 $\pm T_0$ 内的概率）：

$$P = P(|X| \le T_0) = 2\Phi\!\left(\frac{T_0}{\sigma_X}\right) - 1$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $t_i$ | 第 $i$ 环公差 | 毫米 mm | 通常按 $\pm 3\sigma$ 标注 |
| $T_{\text{worst}}$ | 极值法合成公差 | 毫米 mm | 最坏情况的封闭环波动 |
| $T_{\text{RSS}}$ | 统计法合成公差 | 毫米 mm | $3\sigma$ 意义上的波动 |
| $T_0$ | 允许的封闭环公差 | 毫米 mm | 设计要求（如轴承游隙范围） |
| $\sigma_X$ | 封闭环标准差 | 毫米 mm | $\sigma_X = T_{\text{RSS}}/3$ |
| $\Phi$ | 标准正态分布函数 | — | 概率章已学的正态曲线下面积 |

**RSS 的三个前提**（不满足就不许用）：各环**独立**、各环尺寸**服从正态分布**、生产过程**受控且居中**（无漂移）。

## 4. 分步例题

**例**：五个环的公差依次为 $\pm0.10$、$\pm0.05$、$\pm0.12$、$\pm0.08$、$\pm0.06$ mm，设计要求封闭环公差 $T_0 = \pm0.35$ mm。分别用两种算法校核。

1. **极值法**：$T_{\text{worst}} = 0.10 + 0.05 + 0.12 + 0.08 + 0.06 = 0.41$ mm **> 0.35** → 判废；
2. **统计法**：$T_{\text{RSS}} = \sqrt{0.10^2 + 0.05^2 + 0.12^2 + 0.08^2 + 0.06^2} = \sqrt{0.0100 + 0.0025 + 0.0144 + 0.0064 + 0.0036} = \sqrt{0.0369} = 0.1921$ mm；
3. **两者之比**：$0.1921 / 0.41 = 46.9\%$——统计法只用了极值法**不到一半**的公差预算；
4. **封闭环标准差**：$\sigma_X = T_{\text{RSS}}/3 = 0.1921/3 = 0.0640$ mm；
5. **装配合格率**：$T_0/\sigma_X = 0.35/0.0640 = 5.47$ 个标准差。$P = 2\Phi(5.47) - 1 = 1 - 4.6\times10^{-8}$，**等于 100.0000%**；
6. **矛盾的解释**：极值法说"最坏能偏 0.41 mm，超差了"，统计法说"超差概率不到亿分之一"。都对，只是回答的问题不同——**极值法回答"最坏能坏到哪"，统计法回答"有多大概率坏"**；
7. **工程决策**：这批零件按统计法放行。但前提是**过程能力指数 $C_{pk} \ge 1.33$ 且每批抽检**——一旦发现某个供应商的尺寸分布漂移（比如模具磨损让中心偏了），RSS 的前提立刻失效，必须退回极值法或换供应商。

- **看读数里"RSS / 极值"这一栏**：五环时约 47%，环数越多这个比值越小（$n$ 个相等环时是 $1/\sqrt{n}$）。**这就是统计法的价值随链长增长**；
- **把 T0 从 0.35 拖到 0.20**：极值条早已越过标线（判废），但底部密度曲线仍显示合格率 99.8% 左右——**这个区间正是统计法唯一能救场的地方**；
- **把 T0 拖到 0.10**：合格率掉到 88% 上下，底部密度曲线露在 $\pm T_0$ 之外的两块尾巴变得肉眼可见。**这时候统计法也救不了，必须收紧公差或改设计（加调整垫、改成可调结构）。**

### 实验 2（python）：蒙特卡洛验证——误差真的会互相抵消吗

```python title="抽一万次装配，看看极值法有多保守"
# sliders: T0=0.35 [0.05:1:0.01]
import random                                    # 随机数库（第 0 章已引入）

random.seed(7)                                   # 固定随机种子，结果可复现
tols = [0.10, 0.05, 0.12, 0.08, 0.06]            # 五个环的公差（±mm）
T0 = 0.35                                        # 允许的封闭环公差（mm）
N = 20000                                        # 抽样次数

worst = 0.0                                      # 极值法：误差绝对值之和
sq = 0.0                                         # 统计法：平方和
for t in tols:
    worst = worst + abs(t)
    sq = sq + t * t
rss = sq ** 0.5

inside = 0                                       # 落在 ±T0 内的装配数
peak = 0.0                                       # 抽样里出现的最大偏差
for _ in range(N):
    x = 0.0
    for t in tols:
        x = x + random.gauss(0.0, t / 3)         # 每环按 ±3σ 覆盖的正态分布抽样
    if abs(x) > peak:
        peak = abs(x)
    if abs(x) <= T0:
        inside = inside + 1

print(f"极值法 Σ|t|      = ±{worst:.4f} mm")
print(f"统计法 √(Σt²)    = ±{rss:.4f} mm  （RSS/极值 = {rss / worst * 100:.1f}%）")
print(f"σ_封闭环 = RSS/3 = ±{rss / 3:.4f} mm")
print(f"抽样 {N} 次：合格率 {inside / N * 100:.2f}%  实测最大偏差 {peak:.4f} mm")
```

跑出来的结果会让你对极值法彻底改观：**两万次抽样里，实测最大偏差只有 0.27 mm，从没接近过极值法预言的 0.41 mm**，合格率 100.00%。

为什么极值法永远到不了？因为要让五环同时取到各自的最大值且同向，概率是 $(1/2)^5 \times (\text{各环取极值的概率})$，比中彩票还难。**极值法保证的是"理论最坏"，而理论最坏在量产里几乎不发生。**

把 `T0` 改成 0.20 再跑，合格率仍有 99.86%；改成 0.12 才跌到 94%。**这就是统计法敢放松公差的底气。**

但请注意代码里 `random.gauss(0.0, t / 3)` 的均值是 0——它假设了**加工过程完全居中**。把 `T0` 设成 0.12、再把某一环的抽样均值从 `0.0` 改成 `0.5 * t`（模拟刀具磨损让尺寸中心往一边偏），合格率会从 94% 掉到 **82%**；偏移到 `1.0 * t` 时只剩 50%。**RSS 的前提一旦破了，算出来的数字就成了幻觉。**

:::warning[常见误区]

**误区一**："统计法算出来更宽松，所以一定用它。"
你在只看数字——RSS 建立在三个前提上：**各环独立、尺寸服从正态分布、过程受控且居中**。只要有一条不满足，实际合格率就会远低于计算值。典型翻车场景：同一台机床连续加工的两件（误差正相关，不独立）、供应商为"凑合格"把尺寸都做到公差带边缘（分布变成双峰）、刀具磨损导致尺寸中心缓慢漂移（不居中）。**用 RSS 就必须配套 SPC 过程管控**，否则老老实实用极值法。

**误区二**："把每个环的公差都收紧一半，装配合格率就能翻倍。"
你以为线性——在 RSS 下，所有环等比收紧 $k$ 倍，合成公差也收紧 $k$ 倍，确实线性。但**加工成本随公差收紧是超线性上涨的**（IT6 比 IT8 贵好几倍）。更有效的做法是先找出**贡献最大的那一环**：RSS 里每个环的贡献是 $t_i^2$，所以 $t=0.12$ 那一环的"权重"是 $t=0.05$ 那一环的 **5.8 倍**。把最大的一环减半，效果远好过把五个环都减一点点。

**误区三**："公差越小，产品质量越高。"
你在追求一个不存在的目标——公差是**成本**，不是质量。过紧的公差带来：加工成本飙升、废品率上升、装配反而更困难（零件之间的配合失去了自适应能力）。真正的高质量设计是**在满足功能的前提下把公差放到最松**，并用结构手段（调整垫片、弹性元件、定位销、选配分组）来吸收累积误差。**能靠结构解决的，不要靠加工精度去扛。**

:::

<details>
<summary>点开查看逐步解答</summary>

1. 极值法：$T_{\text{worst}} = 0.15 + 0.10 + 0.20 + 0.05 = 0.50$ mm > 0.30 mm → **(a) 不合格**；
2. 统计法：$T_{\text{RSS}} = \sqrt{0.15^2 + 0.10^2 + 0.20^2 + 0.05^2} = \sqrt{0.0225 + 0.0100 + 0.0400 + 0.0025} = \sqrt{0.0750} = 0.2739$ mm；
3. 封闭环标准差：$\sigma_X = T_{\text{RSS}}/3 = 0.0913$ mm；
4. 标准化：$T_0/\sigma_X = 0.30/0.0913 = 3.29$；
5. 合格率：$P = 2\Phi(3.29) - 1 = 2 \times 0.99950 - 1 = 0.9990$，即 **99.90%**；
6. 结论：**(b) 统计法判定合格**，但每 1000 台会有约 1 台超差——这个数字必须能被售后体系吸收；
7. 若要提高到 99.99%（$z = 3.89$），需要 $\sigma_X \le 0.30/3.89 = 0.0771$，即 $T_{\text{RSS}} \le 0.231$ mm。把最大的一环 $\pm0.20$ 收紧到 $\pm0.13$ 即可：$\sqrt{0.0225+0.0100+0.0169+0.0025} = \sqrt{0.0519} = 0.2278$ mm ✓。

第 7 步再次印证"先动最大的一环"：只改一环（从 0.20 到 0.13）就跨过了两个数量级的合格率；而如果把四环各收紧 10%，$T_{\text{RSS}}$ 只从 0.2739 降到 0.2465，仍然不达标。

## 7. 选读：为什么独立误差按平方相加

<details>
<summary>选读 · 方差可加性的一步证明，以及 ±3σ 从哪来</summary>

设各环误差 $X_1, X_2, \dots, X_n$ 相互独立、均值为 0、方差为 $\sigma_i^2$。封闭环误差

$$X = X_1 + X_2 + \cdots + X_n$$

取方差（这是概率章"和的方差"那一节的核心结论）：

$$\operatorname{Var}(X) = \operatorname{Var}\!\left(\sum_i X_i\right) = \sum_i \operatorname{Var}(X_i) + \sum_{i \ne j} \operatorname{Cov}(X_i, X_j)$$

**独立性让所有协方差项 $\operatorname{Cov}(X_i, X_j) = 0$ 全部消失**，于是

$$\sigma_X^2 = \sum_i \sigma_i^2 \quad\Longrightarrow\quad \sigma_X = \sqrt{\sum_i \sigma_i^2}$$

再代入"各环公差按 $\pm3\sigma$ 覆盖"的约定（$\sigma_i = t_i/3$）：

$$3\sigma_X = 3\sqrt{\sum_i (t_i/3)^2} = \sqrt{\sum_i t_i^2} = T_{\text{RSS}}$$

**这就是 RSS 公式的全部来历。** 注意两个关键假设各自负责什么：

- **独立性**负责把交叉项归零 → 决定了"平方"；
- **$3\sigma$ 约定**负责让 $\pm3\sigma$ 和公差数值对上 → 决定了"开根号后还是用同一套单位"。

如果各环**正相关**（比如同一台设备、同一把刀、同一批次材料加工出来的零件），协方差项为正，真实方差比 RSS 大：

$$\sigma_X^2 = \sum_i \sigma_i^2 + \sum_{i \ne j} \rho_{ij}\sigma_i\sigma_j$$

极端情况（完全正相关，$\rho = 1$）时 $\sigma_X = \sum_i \sigma_i$——**正好退化成极值法**。所以极值法和 RSS 不是两种互不相干的方法，而是"相关系数 $\rho$ 从 1 到 0"这根谱线的两个端点。**工程上的所有中间情况，都可以用这个式子估算。**

**为什么是 $\pm3\sigma$？** 因为 $\pm3\sigma$ 覆盖正态分布的 99.73%，单件废品率约 0.27%。配合过程能力指数 $C_{pk} \ge 1.33$（相当于 $\pm4\sigma$ 的能力去保证 $\pm3\sigma$ 的公差），就把中心漂移的安全余量也留出来了。如果供应商的 $C_{pk} < 1$，说明过程本身就不稳定，**这时候算出的所有 RSS 数字都不作数**。

</details>
