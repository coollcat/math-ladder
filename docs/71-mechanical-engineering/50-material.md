# 材料本构与弹性模量

## 1. 从一个场景开始

回形针弯一次就再也掰不直了，可弹簧钢片弯成九十度、松手之后弹回原样，一次、一万次都不走形。

两者都是钢，都经历了"被弯曲"，**差别不在于受了多少力，而在于力把它推到了曲线上的哪一段**。

这一段差别写在一张图上：应力-应变曲线。它是每种材料的身份证，也是这一课的全部内容。

## 2. 直觉解释

把材料的"性格"想成一条路，你沿着路往前走，脚下的应变是位置，身边的应力是坡度：

- **起步是一段笔直的上坡**（弹性段）。走多远都能回头——松手就沿原路滑回起点，什么都不留下；
- **然后路突然变平**（屈服平台）。你继续往前走，坡度几乎不涨，人却走了很远。这一段走过的路**回不去了**：回头时你不会沿原路返回，而是从当前位置沿一条新的斜坡滑下去，滑到坡底时发现——**回不到出发点了**；
- **接着路又开始上坡**（强化段）。材料"越拉越硬"，但这时的你已经带着一身永久变形；
- **最后路断了**（断裂）。

那个"回不到出发点的距离"，就是**残余变形**。回形针掰不直，是因为你把它推过了第 2 段的起点。

## 3. 正式定义

**工程应力-应变曲线**：把试样拉伸到断裂，记录 $\sigma = F/A_0$ 与 $\varepsilon = \Delta L/L_0$（下标 0 表示**原始**截面积与原始长度，所以叫"工程"量）。

曲线上的关键站点：

| 站点 | 定义 | 低碳钢典型值 |
| --- | --- | --- |
| 比例极限 | $\sigma$-$\varepsilon$ 保持直线的上限 | $\approx 200$ MPa |
| 屈服强度 $\sigma_y$ | 开始产生显著永久变形的应力 | 235 MPa |
| 屈服平台 | 应力几乎不涨、应变猛涨的一段 | 应变约 0.1%~1.4% |
| 条件屈服 $\sigma_{0.2}$ | 无明显屈服点时，取残余应变 0.2% 对应的应力 | 铝合金 240 MPa |
| 抗拉强度 $\sigma_u$ | 曲线最高点的应力 | 400 MPa |
| 断裂延伸率 $A$ | 断裂时的总应变 | 26% |

**卸载定律**（这一课最要紧的一条）：从曲线上任意一点 $(\varepsilon, \sigma)$ 卸载时，路径**近似沿斜率为 $E$ 的直线**回到零应力，于是

$$\varepsilon_{\text{弹性回复}} = \frac{\sigma}{E}, \qquad \varepsilon_{\text{残余}} = \varepsilon - \frac{\sigma}{E}$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $E$ | 弹性模量 | Pa | 弹性段斜率，也是卸载路径的斜率 |
| $\varepsilon_y$ | 屈服应变 | — | $\sigma_y/E$，低碳钢约 0.118% |
| $\varepsilon_{\text{残余}}$ | 残余应变 | — | 卸载后回不来的那部分 |
| $\sigma_{0.2}$ | 条件屈服强度 | Pa | 无明显屈服点材料的替代指标 |
| $A$ | 断裂延伸率 | — | 塑性指标，$A > 5\%$ 称为塑性材料 |

## 4. 分步例题

**例**：低碳钢（$E = 200$ GPa、$\sigma_y = 235$ MPa、$\sigma_u = 400$ MPa、断裂延伸率 $26\%$）被拉到 $\varepsilon = 12.99\%$，此时 $\sigma = 352.6$ MPa。求卸载后的弹性回复与残余应变。

1. **弹性回复的那部分**（卸载时沿斜率 $E$ 走回去）：
   $$\varepsilon_e = \frac{\sigma}{E} = \frac{352.6\times 10^6}{200\times 10^9} = 1.763\times 10^{-3} = 0.176\%$$
2. **残余应变**（回不来的那部分）：
   $$\varepsilon_r = \varepsilon - \varepsilon_e = 12.987\% - 0.176\% = 12.811\%$$
3. **解读**：拉到 13% 时，卸载后**只有 0.176% 弹回来，12.8% 永久留下**。回形针掰不直的定量答案就在这里；
4. **对比**：若只拉到 $\varepsilon = 0.1\%$（低于屈服应变 0.118%），则 $\sigma = E\varepsilon = 200$ MPa，$\varepsilon_e = 200/200000 = 0.1\% = \varepsilon$，残余为 **0**——完全弹回；
5. **校验**：屈服应变 $\varepsilon_y = \sigma_y/E = 235/200000 = 0.118\%$。第 4 步的 0.1% 落在它之下（弹性），第 1 步的 13% 远在它之上（塑性），与两条结论一致 ✓。

注意一个反直觉的事实：**弹性回复的那部分应变几乎是个常数**（0.117%~0.192%），不管你拉到多远。因为 $\sigma$ 在屈服之后涨得很慢，而 $E$ 是个巨大的数——所以"能弹回来的"永远只有千分之一量级。

## 5. 动手实验

### 实验 1（lab）：拖着材料走完一生

```lab
  ]
}
```

图上有五样东西，按它们出现的顺序看：

- **主曲线**（粗线）是材料的完整一生，圆点标出比例极限、屈服平台、强化、颈缩各阶段；
- **橙色点**是当前工作点，**橙色虚线**是从它出发的**卸载路径**；
- **底部的双色标尺**：绿色是"弹性回复"那段，红色是"残余"那段——这两段的长度对比，就是本课的第 4 步例题；
- **右侧"断裂"标记**是曲线终点，越过它 `sigmaAt` 返回"已断裂"。

四件事建议亲手做：

- 把 `t` 从 0 慢慢拖到 0.01（应变 0.26% 以内）：卸载虚线几乎垂直下降，残余标尺是空的——**这是弹性区**，怎么拉怎么回；
- 拖到 `t ≈ 0.5`：这就是例题的状态。把"残余 12.8%"与"弹性回复 0.18%"这两条标尺比一比，你会对"塑性"有体感；
- 拖到 `t > 0.95`：应力反而**下降**（颈缩），试样局部变细了，工程应力算出来自然变小；
- 切换**灰铸铁**：整条曲线几乎没有塑性段，断裂延伸率只有 0.6%，$t$ 稍微一动就断。**脆性材料断前没有任何预兆**——这是压力容器严禁使用脆性材料的根本原因。再切到**橡胶**：拉到 500% 还能完全回来，残余恒为 0，这就是超弹性。

### 实验 2（python）：卸载为什么回不到原点

```python title="卸载路径：沿斜率 E 回去，剩下的就是残余"
E, sy, su, eu = 200e9, 235e6, 400e6, 0.26   # 低碳钢：模量、屈服、强度、断裂延伸率


def sigma_at(e):
    if e <= 0.0:
        return 0.0
    if e >= eu:
        return None                          # 已断裂
    ey = sy / E                              # 屈服应变
    if e <= ey:
        return E * e                         # 线弹性段：应力与应变成正比
    esh = max(ey * 8, 0.014)                 # 屈服平台的终点应变
    if e <= esh:
        return sy                            # 平台：应力不涨，应变猛涨
    return sy + (su - sy) * ((e - esh) / (eu - esh)) ** 0.45   # 强化段


for t in (0.02, 0.05, 0.2, 0.5, 0.8):
    e = t * eu * 0.999                       # 当前总应变
    s = sigma_at(e)
    res = max(0.0, e - s / E)                # 卸载沿斜率 E 回到零，回不去的就是残余
    print(f"ε = {e * 100:6.3f}%  σ = {s / 1e6:6.1f} MPa  残余 = {res * 100:6.3f}%  弹性回复 = {(e - res) * 100:.3f}%")
```

输出里那列"弹性回复"几乎纹丝不动（0.117% → 0.192%），而"残余"从 0.4% 一路涨到 20.6%。

**这解释了金属成形工艺的全部逻辑**：冲压、折弯、拉深都是**故意把材料推过屈服点**，让它保留你想要的形状；而弹簧、膜片、弹性夹则必须全程待在弹性段，一旦越过 $\sigma_y$ 就永久失效。设计弹簧时的许用应力，通常取 $\sigma_y$ 的一半以下。

### 快问快答

```quiz
把一根低碳钢拉杆拉到 13% 应变后卸载，关于卸载过程正确的说法是？
- 卸载沿原加载曲线原路返回，应变全部恢复
- 卸载近似沿一条斜率为 E 的直线回到零应力，只有约 0.18% 的应变能恢复 [*]
- 卸载后应力回到零，应变也回到零
? 卸载时材料按弹性规律回复，路径近似平行于最初的弹性直线（斜率为 E）。能弹回的应变是 σ/E，本例约 0.18%，其余约 12.8% 是永久的残余应变。
```

:::warning[常见误区]

**误区一**："屈服强度就是材料坏掉的应力。"
你以为到了 $\sigma_y$ 就断——其实**屈服只是"开始留永久变形"，离断还远得很**。低碳钢 $\sigma_y = 235$ MPa、$\sigma_u = 400$ MPa，中间还有 70% 的余量。真正的问题是：绝大多数零件**不允许永久变形**（齿轮咬合不准、密封面压不平、导轨失了精度），所以设计上对 $\sigma_y$ 取安全系数，而不是对 $\sigma_u$。

**误区二**："热处理能把钢的弹性模量提上去。"
你在指望淬火改变刚度——**$E$ 是原子间结合力的宏观体现，热处理几乎动不了它**。淬火能把 $\sigma_y$ 从 235 MPa 提到 1000 MPa 以上（强度翻四倍），可 $E$ 依然稳稳地是 200~210 GPa。后果很实际：一根又细又硬的高强度钢轴，**刚度并不比低碳钢轴高**，受力时照样弯那么多。要提高刚度只能改截面（增大 $I$ 或 $A$）或换材料（钢换钨、加碳纤维）。

**误区三**："残余应变是缺陷，越少越好。"
你在单纯追求弹性——其实**塑性是结构的安全储备**。正因为钢能屈服，超载时它会先明显变形、发出预警，还能通过塑性重分布把局部高峰应力"削平"传给邻居；而灰铸铁、陶瓷这类脆性材料没有这段，应力一超就直接崩。塑性也是汽车碰撞吸能区、抗震结构"大震不倒"的物理基础。

:::

**练习 2**：铝合金没有明显的屈服平台，工程上用 $\sigma_{0.2}$（残余应变 0.2% 对应的应力）作为条件屈服强度。请说明这个指标是怎么"量"出来的。

<details>
<summary>点开查看逐步解答</summary>

1. 在应力-应变图上，把**横轴上的 $\varepsilon = 0.002$** 处做一个标记；
2. 过这一点**作一条平行于弹性段直线（斜率为 $E$）的直线**——它代表"如果从这个应变水平卸载"会走的路径；
3. 这条斜线与实验曲线的交点，其纵坐标就是 $\sigma_{0.2}$；
4. 它的含义是：**加载到这个应力再卸载，恰好留下 0.2% 的残余应变**；
5. 为什么要这么绕？因为铝合金、高强钢、不锈钢的曲线是**连续过渡**的，没有屈服平台，"从哪里开始屈服"没有肉眼可辨的点。用 0.2% 这个约定的残余量，就能给所有材料一个**可复现、可比较**的强度指标；
6. 附带的好处：0.2% 的永久变形对多数机械零件来说已经"看得出来了"，作为许用上限在工程上是合理的。

</details>

## 7. 选读：真应力、真应变与颈缩

<details>
<summary>选读 · 为什么工程应力在断裂前反而下降</summary>

工程应力用**原始**截面积 $A_0$ 计算。可试样被拉长时是**均匀变细**的：体积近似不变，$A_0L_0 = AL$，于是真实截面积 $A = A_0L_0/L = A_0/(1+\varepsilon)$。

改用**瞬时**截面积与瞬时长度，就得到真应力与真应变：

$$\sigma_{\text{真}} = \frac{F}{A} = \sigma(1+\varepsilon), \qquad \varepsilon_{\text{真}} = \ln(1+\varepsilon)$$

在均匀变形阶段 $\sigma_{\text{真}} > \sigma$，两者差别随应变增大。

到了某个临界点，变形不再均匀：试样某一处开始**局部变细**（颈缩），此后所有变形都集中在颈部。此时即使材料本身还在强化（真应力继续上升），$F$ 却因为颈部的真实面积急剧缩小而下降，于是**工程应力曲线掉头向下**——这就是组件里 `t > 0.95` 时看到的下弯。

判断颈缩何时开始有个漂亮的准则：**当真应变的强化速率追不上面积缩减速率时**，即 $\dfrac{d\sigma_{\text{真}}}{d\varepsilon_{\text{真}}} = \sigma_{\text{真}}$ 时开始颈缩。这也是金属成形（拉深、冲压）的极限判据：一旦出现颈缩，下一步就是开裂。

</details>
