# 力、力矩与静力平衡

## 1. 从一个场景开始

一台小型塔吊的吊臂长 20 m，最远端能吊起 3 吨；可它尾部那块配重只有 8 吨，整机的重心还老老实实待在塔身里。

如果只看"力的大小"，8 吨压不住 3 吨乘以那么长的吊臂——**但塔吊并没有翻**。

秘密在于：让物体转起来的不是力，是**力乘以力臂**。这一课要把"推"和"拧"这两件事彻底分开。

## 2. 直觉解释

推过门的人都知道一件事：**同样的力，离门轴越远越好推。**

- 手指顶在门轴边上推：使出吃奶的劲，门纹丝不动；
- 手掌按在门把手上推：一根手指就开了。

力一点没变，变的是"力作用线到转轴的距离"。这个距离有个专门的名字，叫**力臂**；而"力 × 力臂"这个组合量，叫**力矩**。

第二个直觉：**力的方向要和门面垂直才最有效。** 你要是斜着推门，一半的力气花在"把门往门轴里压"上，门轴会把它原封不动地还给你，一点转动效果都没有。所以力矩里真正起作用的，只是**垂直于杆方向的那一份力**。

把这两条合起来："拧"的效果 = 力的大小 × 力臂长度，而力臂是**转动轴到力的作用线的垂直距离**。

## 3. 正式定义

**力**是向量（见向量一课），记为 $\vec F$，单位是牛顿 N。它既有大小又有方向，可以正交分解：

$$\vec F = F_x \hat{\imath} + F_y \hat{\jmath}, \qquad |\vec F| = \sqrt{F_x^2 + F_y^2}$$

最后这个求长的式子就是勾股定理——桁架里每根杆的方向余弦都要靠它算。

**力矩**（对点 $O$ 取矩）定义为位置向量与力的叉积：

$$\vec M_O = \vec r \times \vec F$$

在平面问题里它退化成一个带符号的标量：

$$M_O = F \cdot d$$

其中 $d$ 是**力臂**：点 $O$ 到力 $\vec F$ 作用线的垂直距离。若力与位置向量的夹角为 $\theta$，则 $d = |\vec r|\sin\theta$。

**正负号约定**（全章统一）：使物体**逆时针**转动的力矩取正，顺时针取负。

**静力平衡**：一个刚体既不平移也不转动，当且仅当

$$\sum \vec F = 0 \quad \text{且} \quad \sum M_O = 0$$

两条缺一不可——$\sum \vec F = 0$ 只保证"不平移"，$\sum M_O = 0$ 才保证"不转动"。取矩的点 $O$ 可以任选，**平衡时它对任何点都成立**，所以挑一个能消掉最多未知量的点最省事。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $\vec F$ | 力 | N | 向量，可分解可合成 |
| $\vec r$ | 位置向量 | m | 从取矩点指向力的作用点 |
| $M_O$ | 力矩 | N·m | $F\cdot d$，逆时针为正 |
| $d$ | 力臂 | m | 取矩点到**力的作用线**的垂直距离 |
| $\theta$ | 夹角 | rad | 力的方向与 $\vec r$ 的夹角，$d = |\vec r|\sin\theta$ |

## 4. 分步例题

**例**：一根 6 m 长的水平梁，铰支点装在 $x_p = 3$ m 处。三个竖直向下的力分别作用在 $x = 1$（400 N）、$x = 3$（600 N）、$x = 5.2$（300 N）。问梁会不会转？若会，第三个力改成多大才配平？

1. **求合力**（竖直方向）：$\sum F_y = -400 - 600 - 300 = -1300$ N，支点要给出 **1300 N 向上**的反力，梁才不往下掉；
2. **对支点取矩**（逆时针为正，向下力在支点左侧产生正力矩）：
   $$M_1 = (1 - 3)\times(-400) = +800\ \text{N·m}$$
   $$M_2 = (3 - 3)\times(-600) = 0$$
   $$M_3 = (5.2 - 3)\times(-300) = -660\ \text{N·m}$$
3. **合力矩**：$\sum M = 800 + 0 - 660 = +140$ N·m $> 0$——**梁会逆时针转起来**；
4. **配平**：令 $\sum M = 0$，解出第三个力
   $$F_3 = -\frac{(1-3)\times(-400) + 0}{5.2 - 3} = -\frac{800}{2.2} = -363.6\ \text{N}$$
   即第三个力应该是 **363.6 N 向下**，而不是 300 N；
5. **校验**：$(5.2-3)\times(-363.6) = -800$，与 $M_1 = +800$ 正好抵消 ✓。

注意第 2 步里那个 600 N 的力：**它正好压在支点上，力矩为零**。这不是巧合而是杠杆的全部秘密——把重物挂在支点正上方，它再重也不会让梁转。

### 实验 1（lab）：拖着力看力矩怎么变

  "xp": 3,

图上有四样东西值得盯：

- **三支彩色箭头**是三个力：**拖箭头尖端**改大小和方向，**拖根部圆点**改作用位置；
- **橙色箭头**是支点反力——它永远是"合力取负"，你改任何一个力，它立刻跟着反向等大；
- **读数里的 ΣM(支点)** 是本课主角，它不为零时，"状态"一栏会明说往哪边转；
- **底部的"配平最后一个力"按钮**直接解出让 $\sum M = 0$ 的 $F_3$，你可以拿它验证第 4 步的 363.6 N。

三件事建议亲手做一遍：

- 把支点滑块拖到 **2.89 m** 附近（也就是例题算出的合力作用点），ΣM 会自己掉到零——**不动一根手指头，光挪支点就把梁配平了**；
- 把某个力拖成斜的：你会发现只有**竖直分量**进 ΣM，水平分量只进 ΣFx。这就是"力臂取垂直距离"的直接体现；
- 点"全部归零"，再把 $F_1$ 单独拖到 900 N，看 ΣM 与到支点的距离成正比——力矩对距离是**线性**的。

### 实验 2（python）：合力作用点其实就是加权平均

```python title="配平支点：合力作用点是力的加权平均"
# sliders: xp=3.0 [0.3:5.7:0.05]
loads = [(1.0, 400.0), (3.0, 600.0), (5.2, 300.0)]  # (作用位置 m, 向下的力 N)
xp = 3.0                       # 支点位置（m）

M = 0.0                        # 合力矩，逆时针为正
for x, F in loads:
    M += (x - xp) * (-F)       # 向下为负；力在支点左侧时 (x-xp)<0，乘积为正
Fy = 0.0                       # 合力
num = 0.0                      # 位置 × 力 的累加
tot = 0.0                      # 力的累加
for x, F in loads:
    Fy += -F
    num += x * F
    tot += F

xc = num / tot                 # 加权平均位置 = 合力作用点
print(f"ΣM(支点 {xp} m) = {M:.1f} N·m")
print(f"ΣFy = {Fy:.0f} N，支点反力 = {-Fy:.0f} N 向上")
print(f"合力作用点 x = {xc:.3f} m（支点移到这里即配平）")
```

输出是 `ΣM = 140.0 N·m`、`支点反力 1300 N`、`合力作用点 x = 2.892 m`。

最后一行是这一课最实用的一句话：**合力作用点 = 各力位置按大小加权平均**。吊车要算能不能吊，先把所有重力（含吊臂自重）折算成"总重 + 重心位置"，再看看重心的铅垂线有没有落在支腿围成的多边形里——这就是倾覆校核的全部。

### 快问快答

```quiz
同样 100 N 的力作用在门上，哪种情况力矩最大？
- 垂直门面推，作用在离门轴 0.2 m 处
- 垂直门面推，作用在离门轴 0.8 m 处 [*]
- 斜着 30 度推，作用在离门轴 0.8 m 处
? 力矩等于力乘以力臂，力臂是转轴到力的作用线的垂直距离。垂直推且最远时力臂是 0.8 m，力矩 80 N·m；斜着推时有效力臂只有 0.8 乘 sin30 度，即 0.4 m。
```

:::warning[常见误区]

**误区一**："合力为零，物体就平衡了。"
你以为 $\sum \vec F = 0$ 就够了——其实**这只是不平移的条件**。一对大小相等、方向相反但不在同一条直线上的力，合力严格为零，可它们构成一个纯力偶，会让物体一直转。汽车方向盘就是这么转的：两只手合力为零，方向盘却转得飞快。判据必须两条都写：$\sum \vec F = 0$ **且** $\sum M = 0$。

**误区二**："力臂就是支点到受力点的距离。"
你以为量一段杆长就行——其实力臂是支点到**力的作用线**的**垂直**距离，不是到作用点的距离。扳手上斜着施力时，明明手还在扳手末端，有效力臂却只剩 $L\sin\theta$。$\theta = 30^\circ$ 时力矩直接腰斩，这也是为什么拧螺丝时总要求套筒与螺栓同轴。

**误区三**："力矩有固定的转动方向，符号我背下来就行。"
你以为逆时针为正是一条物理定律——其实**符号只是记账约定**，真正重要的是"你自己这套账要自洽"。工程上也常用"顺时针为正"，甚至按"使梁下挠为正"来记。换约定只会让所有数值整体变号，零还是零，极值的位置一个都不会变。做题时先写下约定，比背符号重要得多。

:::

## 6. 练习

**练习 1**：用 200 N 的力扳一把 0.3 m 长的扳手，但力与扳手轴线夹 30 度。这段代码没做投影，修到输出 `30.0`：

```exercise
# @title: 练习：斜着扳扳手，力矩还剩多少
# @check: 30.0
# @hint: 有效力臂 d = L 乘 sin(θ)，θ 是「扳手轴线」与「力的方向」的夹角；只有垂直分量才产生转动
import math                 # 数学库（卷一已引入），提供 sin 与角度换算

F = 200.0                   # 手施加的力（N）
L = 0.3                     # 扳手长度（m）
theta = 30.0                # 力与扳手轴线的夹角（度）
M = F * L                   # ← 问题在这：没有投影，把整根扳手长当成了力臂
print(round(M, 1))
```

**练习 2**：一根 4 m 长的水平杆，左端铰支，在 $x = 1$ m 处挂 500 N、$x = 4$ m 处挂 300 N。若只允许在 $x = 2$ m 处再加一个竖直力，这个力该多大、朝哪个方向，杆才不转？

<details>
<summary>点开查看逐步解答</summary>

1. 对左端铰支点取矩（逆时针为正，向下力为负）：
   $$M = (1-0)(-500) + (4-0)(-300) + (2-0)F = -500 - 1200 + 2F$$
2. 令 $\sum M = 0$：$2F = 1700$，得 $F = 850$ N；
3. $F$ 为正表示**向上**（因为我们约定向下力写成负值）；
4. 校验：$\sum F_y = -500 - 300 + 850 = +50$ N，所以铰支座要给出 50 N **向下**的反力——铰支座既能推也能拉，完全可以做得到；
5. 如果支点换成只能向上顶的辊支座，这 50 N 就无处可去，方案不成立。**约束能提供什么方向的力，决定了方案可行与否**，这正是下一课的主题。

</details>

## 7. 选读：力矩为什么是叉积

<details>
<summary>选读 · 从二维标量到三维向量</summary>

平面问题里我们把力矩当成一个带正负号的数，是因为所有转动都绕同一根轴（垂直于纸面）。一旦进入三维，转动轴的方向本身就是信息，力矩必须是向量：

$$\vec M_O = \vec r \times \vec F, \qquad |\vec M_O| = |\vec r|\,|\vec F|\sin\theta$$

叉积的模正好等于"力的大小 × 力臂"，因为 $|\vec r|\sin\theta$ 就是力臂 $d$。

由此还能得到一条很有用的性质：**力矩的大小与取矩点在力的作用线上的位置无关**。把取矩点沿着力的作用线随便滑动，$\vec r$ 变化的那部分与 $\vec F$ 平行，叉积为零，力矩纹丝不动。

推论很实用：算力矩时，你可以把力沿着它的作用线**滑到任何方便的位置**再算。例题里那个作用在 $x = 5.2$ 的竖直力，滑到梁上任何一点都是同一个竖直方向，力臂永远是它到支点的水平距离。

</details>
