# 凸轮与从动件

## 1. 从一个场景开始

发动机的一个气门要在曲轴转过 $0.02$ 秒的时间里抬起 8 毫米、保持开启、再精确落回，每分钟重复三千次，误差不能超过头发丝的几分之一。

四连杆做不到这件事——它能给出「转多少度对应摆多少度」，但给不出「在中间稳稳停一段」这种动作。于是工程师换了件工具：把这条「转角 → 位移」的曲线**直接刻在一块金属的边缘上**，这就是凸轮。

问题随之而来：曲线可以画得很漂亮，但机器跑起来会**抖、会响、会卡死**。决定这三件事的，不是曲线的形状本身，而是它的**斜率**和**斜率的变化率**。

## 2. 直觉解释

凸轮干的事，是把一张「时间表」变成金属轮廓。轮廓上每一点的极径就是 $r_b + s(\theta)$：基圆半径加上这一角度该抬起的量。

关键在于把注意力从「位移」挪到**速度**和**加速度**上：

- **速度**就是斜率。速度突然从 0 跳到某个值，等于给从动件一记锤击——叫**刚性冲击**，理论上加速度无穷大；
- **加速度**是斜率的变化率，它正比于惯性力 $ma$。加速度左右横跳，惯性力就左右横跳，机构开始嗡嗡响——叫**柔性冲击**；
- 想彻底安静，就得让加速度曲线也连续（比如摆线规律、多项式规律）。

第三个量常被忽略：**压力角**。它是「凸轮推的方向」和「从动件该走的方向」之间的夹角。这个角越大，越多的推力被浪费成侧向的挤压力，轻则磨损，重则**从动件直接卡在导路里不动**（自锁）。

## 3. 正式定义

**基圆半径 $r_b$**：凸轮最小的向径。**升程 $h$**：从动件的最大位移。**推程角 $\beta$**：推程所占的凸轮转角。

**位移规律**：推程段内令无量纲角 $t = \theta/\beta \in [0,1]$，则

| 规律 | 位移 $s/h$ | 无量纲速度 $v^\* = \frac{\beta}{h}\frac{ds}{d\theta}$ | 无量纲加速度 $a^\* = \frac{\beta^2}{h}\frac{d^2s}{d\theta^2}$ | 冲击 |
| --- | --- | --- | --- | --- |
| 等速 | $t$ | $1$ | $0$（端点阶跃） | **刚性** |
| 等加速等减速 | $2t^2$，$t<\tfrac12$；$1-2(1-t)^2$，$t\ge \tfrac12$ | $4t$ / $4(1-t)$，峰值 $2$ | $\pm 4$ | **柔性** |
| 简谐 | $\frac12(1-\cos \pi t)$ | $\frac{\pi}{2}\sin \pi t$，峰值 $\frac{\pi}{2}$ | $\frac{\pi^2}{2}\cos \pi t$，峰值 $\frac{\pi^2}{2}$ | 端点柔性 |

**实际速度/加速度**（凸轮角速度 $\omega$，单位 rad/s）：

$$v = \frac{h}{\beta}\,v^\*\,\omega, \qquad a = \frac{h}{\beta^2}\,a^\*\,\omega^2$$

**压力角**（对心直动从动件，偏置距 $e=0$）：

$$\alpha = \arctan\frac{ds/d\theta}{r_b + s}$$

直动从动件许用值通常取 $\alpha \le 30^\circ$（摆动从动件可放宽到 $45^\circ$）。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $r_b$ | 基圆半径 | 越小机构越紧凑，但压力角越大 |
| $h$ | 升程 | 从动件总行程 |
| $\beta$ | 推程角 | 抬升所占转角；$\beta$ 越小动作越急 |
| $\alpha$ | 压力角 | 传力方向的浪费程度，超限即卡滞 |
| $\omega$ | 凸轮角速度 | rad/s；注意 $a \propto \omega^2$，提速代价是平方的 |

## 4. 分步例题

**例**：$r_b = 40$ mm，$h = 25$ mm，$\beta = 180^\circ$，转速 $n = 600$ rpm。比较三种规律的最大速度、最大加速度与最大压力角。

1. **角速度**：$\omega = 2\pi n/60 = 62.83$ rad/s；
2. **等速**：$v^\* = 1$，$v_{\max} = \frac{h}{\beta}\cdot 1 \cdot \omega = \frac{25}{\pi}\times 62.83 = 500$ mm/s；$a^\*$ 在段内为 0，但**推程起点速度从 0 跳到 500 mm/s**，加速度理论无穷大 → 刚性冲击；$\alpha_{\max} = \arctan\frac{7.96}{40 + 0} = 11.2^\circ$（推程起点，$s=0$ 时分母最小）；
3. **等加速等减速**：$v^\*_{\max} = 2$ → $v_{\max} = 1000$ mm/s；$a^\*_{\max} = 4$ → $a_{\max} = \frac{25}{\pi^2}\times 4 \times 62.83^2 = 40.0\ \text{m/s}^2 \approx 4.1g$；$\alpha_{\max} = 16.9^\circ$；
4. **简谐**：$v^\*_{\max} = \pi/2$ → $v_{\max} = 785$ mm/s；$a^\*_{\max} = \pi^2/2$ → $a_{\max} = 49.3\ \text{m/s}^2 \approx 5.0g$；$\alpha_{\max} = 13.8^\circ$；
5. **结论**：等速的位移曲线最"朴素"，却是**唯一会在端点产生刚性冲击**的一种；简谐的加速度连续，但峰值加速度反而最大（$\pi^2/2 \approx 4.93 > 4$）——**平顺不等于力小**，这是选型时最容易搞混的一点。

再看转速的影响：把 $n$ 从 600 提到 1200 rpm，三种规律的 $a_{\max}$ 全部**翻四倍**（$a\propto\omega^2$）。这就是为什么高速发动机必须用更"软"的规律（多项式、摆线），而不只是把凸轮做得更硬。

左边是凸轮本体（橙色廓线 + 红色从动件），右边三行依次是 $s(\theta)$、$v(\theta)$、$a(\theta)$。用顶部的三个按钮切换规律，盯住三件事：

- **切到等速**：$v$ 曲线在推程起点和终点是**竖直的一条跳变**——这就是刚性冲击的来源；$a$ 图在这一瞬间理论上是一根无穷高的线；
- **切到等加速等减速**：$v$ 变成三角形（连续了），但 $a$ 变成方波——**加速度在四个点反复跳变**，柔性冲击；
- **切到简谐**：三条曲线都连续光滑，但右下角标注会告诉你 $a$ 的峰值并不小。

拖动 `rb` 时请盯住黄色标注的 $\alpha$：把基圆从 40 mm 缩到 22 mm，$\alpha$ 会迅速越过 30°，读数栏跳出「⚠ 偏大，易卡滞」。**这就是紧凑化设计的硬边界**。

把 `beta` 从 180° 拖到 60° 再看一次：同样的升程要在三分之一的转角内完成，$v$ 和 $a$ 全都涨到三倍——**「急」是要拿惯性力去换的**。

### 实验 2（python）：三种规律的数值体检

```python title="位移规律：速度、加速度、压力角一次算清"
import math                        # 数学库：pi / sin / cos / radians / atan2 / degrees

rb, h, beta_deg = 40.0, 25.0, 180.0
beta = math.radians(beta_deg)
n = 600.0                                     # 凸轮转速（rpm）
omega = 2 * math.pi * n / 60                  # 角速度（rad/s）

def law(name, t):
    """返回无量纲位移 S、无量纲速度 V、无量纲加速度 A"""
    if name == '等速':
        return t, 1.0, 0.0
    if name == '等加速等减速':
        if t < 0.5:
            return 2 * t * t, 4 * t, 4.0
        return 1 - 2 * (1 - t) ** 2, 4 * (1 - t), -4.0
    return (0.5 * (1 - math.cos(math.pi * t)),
            (math.pi / 2) * math.sin(math.pi * t),
            (math.pi ** 2 / 2) * math.cos(math.pi * t))

for name in ['等速', '等加速等减速', '简谐']:
    vmax = amax = alpha = 0.0
    for i in range(1, 1000):                  # 扫推程段内部，端点另说
        t = i / 1000
        S, V, A = law(name, t)
        s = h * S
        ds = (h / beta) * V                   # ds/dθ，单位 mm/rad
        vmax = max(vmax, abs(ds))
        amax = max(amax, abs(A))
        alpha = max(alpha, math.degrees(math.atan2(ds, rb + s)))
    print("%-8s v = %6.1f mm/s | a = %5.2f m/s² | αmax = %.1f°"
          % (name, vmax * omega, amax * (h / beta ** 2) * omega ** 2 / 1000, alpha))
```

三行输出把三种性格钉死了：**等速 $a = 0.00$** 是假象——它的加速度全集中在推程的两个端点上（速度从 0 突变），采样扫不到；**等加速等减速的 $a$ 只有 40 m/s² 但两处跳变**；**简谐最平顺却要承受 49 m/s² 的峰值惯性力**。

最后一行值得单独记住：把 `n` 改成 1200 再跑，三个 $a$ 值全部变成四倍。**提速一倍，惯性力涨四倍**——这是所有凸轮、所有往复机械共同的账。

### 快问快答

```quiz
对一个对心直动从动件盘形凸轮，保持升程和推程角不变，只把基圆半径缩小，压力角会怎样变化？
- 变小，因为从动件行程变短了
- 变大，因为同样的 ds/dθ 除以了更小的 rb + s [*]
- 不变，压力角只取决于位移规律
? α = arctan((ds/dθ)/(rb + s))。升程与推程角不变则 ds/dθ 不变，rb 变小就让分母变小、α 变大。这正是「机器做得越紧凑越容易卡滞」的原因，也是设计时必须先按许用压力角反求最小基圆半径的道理。
```

:::warning[常见误区]

**误区一**：「等速规律最平缓，低速场合用它最稳。」
你以为位移曲线是一条直线就万事大吉——其实**速度的突变才是敌人**。推程起点速度从 0 跳到 $h\omega/\beta$，加速度理论无穷大，这就是**刚性冲击**。它不挑转速，只是转速越高响声越大。等速规律只在极低速的送料机构里勉强可用。

**误区二**：「加速度连续了，机构就不会振。」
你以为柔性冲击可以忽略——其实加速度**跳变**同样会激起系统的固有振动，只是幅度小一些。$a^\* = \pm4$ 的方波在高速下照样让从动件"起飞"（脱离廓线，术语叫**跃离**）。真正安静的规律（摆线、3-4-5 多项式）要求加速度曲线本身也连续。

**误区三**：「压力角大一点顶多效率低，不至于出事。」
你以为它只是个效率指标——其实 $\alpha$ 越接近摩擦角，侧向挤压力越大，导路里的摩擦力增长得比推力还快，最终**推不动**（自锁）。工程上的硬规矩是直动从动件 $\alpha_{\max} \le 30^\circ$（有偏置时可到 $40^\circ$），而它是靠**加大基圆**来换的，不是靠把凸轮做硬。

:::

## 6. 练习

**练习 1**：下面这段代码把压力角的分母写错了，算出 $17.4^\circ$。修正后应输出 `αmax = 13.8°`：

```exercise
# @title: 练习：压力角的分母写错了
# @check: αmax = 13.8°
# @hint: 压力角是 arctan((ds/dθ)/(rb + s))，分母是「接触点到凸轮中心的距离」= 基圆半径加上当前已抬起的高度。代码里漏掉了 s
import math                        # 数学库：pi / sin / cos / radians / atan2 / degrees

rb, h, beta_deg = 40.0, 25.0, 180.0
beta = math.radians(beta_deg)

def law(t):                        # 简谐规律的位移与无量纲速度
    return (0.5 * (1 - math.cos(math.pi * t)),
            (math.pi / 2) * math.sin(math.pi * t))

alpha = 0.0
for i in range(1, 1000):
    t = i / 1000
    S, V = law(t)
    s = h * S
    ds = (h / beta) * V
    alpha = max(alpha, math.degrees(math.atan2(ds, rb)))   # ← 问题在这：分母少了 s
print("αmax = %.1f°" % alpha)
```

**练习 2**：上例的简谐凸轮要求 $\alpha_{\max} \le 25^\circ$，其余参数（$h=25$ mm、$\beta = 180^\circ$）不变。基圆半径至少取多大？

<details>
<summary>点开查看逐步解答</summary>

1. 由 $\alpha = \arctan\frac{ds/d\theta}{r_b+s}$，要求 $\tan 25^\circ = 0.4663 \ge \frac{ds/d\theta}{r_b + s}$；
2. 简谐规律下 $ds/d\theta = \frac{h}{\beta}\cdot\frac{\pi}{2}\sin\pi t$ 在 $t=0.5$ 处最大，值 $\frac{25}{\pi}\times\frac{\pi}{2} = 12.5$ mm/rad；
3. 但**$\alpha$ 的极值不在速度峰值处**：$s$ 同时在增大，分母也在变，所以要整体扫一遍。实算结果：$r_b = 25$ mm → $19.5^\circ$；$r_b = 20$ mm → $22.6^\circ$；$r_b = 18$ mm → $24.2^\circ$；$r_b = 16$ mm → $26.0^\circ$（超限）；
4. 极值点随 $r_b$ 变小而前移（$r_b=40$ 时在 $t\approx0.42$，$r_b=18$ 时提前到 $t\approx0.37$）——**这就是不能只代峰值手算的原因**；
5. **结论**：取 **$r_b \ge 18$ mm**，标准值取 20 mm（$22.6^\circ$，留约 10% 余量）。

**这道题想说的是**：最小基圆半径不是"看着顺眼"定的，而是被许用压力角**反求**出来的。想让机器更紧凑，正确做法是减小升程、加大推程角，或者改用偏置从动件——硬缩基圆只会得到一台会卡死的机器。

</details>

## 7. 选读：压力角公式是怎么来的

<details>
<summary>选读 · 从廓线法线推 α = arctan((ds/dθ)/(rb + s))</summary>

对心直动从动件的廓线在极坐标下是 $r(\varphi) = r_b + s(\varphi)$。取极坐标下曲线的一小段，其切线与径向的夹角 $\psi$ 满足

$$\tan\psi = \frac{r}{dr/d\varphi} = \frac{r_b + s}{ds/d\varphi}$$

而**接触点的公法线**垂直于切线，压力角 $\alpha$ 定义为「从动件运动方向」与「廓线法线」的夹角。从动件沿竖直方向运动，恰好与径向成 $\psi$ 的余角关系，于是

$$\alpha = 90^\circ - \psi,\qquad \tan\alpha = \frac{1}{\tan\psi} = \frac{ds/d\varphi}{r_b + s}$$

即 $\alpha = \arctan\dfrac{ds/d\theta}{r_b+s}$（这里 $\varphi$ 与凸轮转角 $\theta$ 只差一个符号约定，取绝对值）。

三个推论：

1. **$\alpha$ 与载荷无关**，只是几何量——所以它是可以在图纸阶段就查死的指标；
2. **加大 $r_b$ 一定降低 $\alpha$**，代价是凸轮变大、廓线变长、接触应力下降；
3. **偏置** $e$ 把公式变成 $\alpha = \arctan\frac{ds/d\theta - e}{r_b + s}$，正确选向的偏置能显著减小推程压力角（回程会变差，需要权衡）。

</details>
