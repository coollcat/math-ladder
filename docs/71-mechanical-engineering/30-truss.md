# 桁架与杆件内力

## 1. 从一个场景开始

厂房的屋顶、输电的铁塔、工地的塔吊臂，看上去都是一堆细杆拼成的三角形网格。

为什么非得是三角形？拿四根杆钉成一个矩形，轻轻一推就歪成平行四边形——**四根杆的长度没变，形状却变了**。

三角形不会：三条边定下来，形状就锁死了。这一课要把这个几何事实翻译成一条方程，再用它算出每根杆里到底流着多少力。

## 2. 直觉解释

想象一根绳子，两端被人拉着。

绳子很短，只做一件事：**沿着自己的方向被拉**。你没法用绳子去推东西，也没法让绳子"扛弯"——它一旦受横向的力就软下来改变形状。

桁架的每根杆，在理想模型里就是这样一根"刚性绳子"：两端用光滑销钉连接，杆自重忽略，载荷只作用在节点上。于是每根杆都是**二力杆**——它两端只受两个力，这两个力必定等大、反向、共线，也就是说**内力只能沿杆轴线，不是拉就是压**。

这就是桁架的全部魔法：把本来会弯曲的梁，换成一群只承受拉压的杆。钢材抗拉抗压都极好，抗弯却很费料——桁架等于用最省料的方式把跨度撑起来。

而节点，就是把所有杆力汇在一起当场结算的地方：每个节点都是一小张资产负债表，收入支出必须相等。

## 3. 正式定义

**理想桁架的三条假设**：节点为光滑铰接；杆件自重忽略（或折算到两端节点）；外载荷只作用在节点上。

**节点法**：以每个节点为隔离体，列两个平衡方程 $\sum F_x = 0$、$\sum F_y = 0$。未知量是各杆轴力 $N_k$（**拉为正、压为负**）与支座反力分量。

一根杆对节点的贡献，等于轴力乘上从该节点指向另一端的**单位方向向量**：

$$\vec e_{ij} = \frac{\vec r_j - \vec r_i}{|\vec r_j - \vec r_i|} = \bigl(\cos\theta,\ \sin\theta\bigr), \qquad |\vec r_j - \vec r_i| = \sqrt{\Delta x^2 + \Delta y^2}$$

方向余弦就来自勾股定理——这是上一章几何课在机械里最频繁的一次出场。

**静定判据**（平面桁架）：设杆数为 $m$、支座反力数为 $r$、节点数为 $n$，则

$$m + r = 2n \quad \Rightarrow \quad \text{静定}$$

因为 $n$ 个节点提供 $2n$ 个方程，而未知量恰好是 $m$ 根杆力加 $r$ 个反力。未知量多于方程是超静定，少于是机构。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $N_k$ | 第 $k$ 根杆的轴力 | N | **拉为正、压为负** |
| $\vec e_{ij}$ | 单位方向向量 | — | 从节点 $i$ 指向 $j$，长度归一化 |
| $m, r, n$ | 杆数、反力数、节点数 | 个 | 静定判据 $m + r = 2n$ |
| $\theta$ | 杆与水平轴夹角 | rad | 方向余弦 $(\cos\theta, \sin\theta)$ |

## 4. 分步例题

**例**：五节点桁架，下弦 $A(0,0)$、$B(2,0)$、$C(4,0)$，上弦 $D(1,1.8)$、$E(3,1.8)$；杆件为 $AB$、$BC$、$AD$、$DB$、$BE$、$EC$、$DE$；$A$ 为铰支座、$C$ 为辊支座；$D$、$E$ 各受 600 N 竖直向下的力。求各杆轴力。

1. **几何**：斜杆 $AD$ 的水平投影 1 m、竖向 1.8 m，
   $$L = \sqrt{1^2 + 1.8^2} = \sqrt{4.24} = 2.059\ \text{m},\quad \cos\theta = 0.4856,\ \sin\theta = 0.8742$$
   （$\theta = 60.95^\circ$）；
2. **零杆**：节点 $B$ 上只有 $AB$、$BC$（水平）与 $DB$、$BE$（斜）四根杆，没有外载荷。竖向方程只含两根斜杆：$0.8742(N_{DB} + N_{BE}) = 0$。载荷与结构都关于跨中对称，故 $N_{DB} = N_{BE}$，于是
   $$N_{DB} = N_{BE} = 0 \quad \text{——两根零杆}$$
3. **节点 $D$ 竖向**：$AD$ 的竖向分量顶住 600 N，
   $$-0.8742\,N_{AD} - 600 = 0 \ \Rightarrow\ N_{AD} = -686.4\ \text{N（压）}$$
   由对称性 $N_{EC} = -686.4$ N（压）；
4. **节点 $A$ 水平**：$N_{AB} + 0.4856\,N_{AD} = 0 \Rightarrow N_{AB} = +333.3$ N（**拉**）；
5. **节点 $D$ 水平**：$-0.4856\,N_{AD} + 0.4856\,N_{DB} + N_{DE} = 0$
   $$\Rightarrow N_{DE} = 0.4856\times(-686.4) = -333.3\ \text{N（压）}$$
6. **校验**：整体竖向 $A_y + C_y = 1200$ N，由对称性各 600 N ✓；判据 $m+r = 7+3 = 10 = 2n = 2\times 5$ ✓ 静定。

注意结果的"性格"：**上弦压、下弦拉、斜杆要么压要么零**。这不是这道题的巧合——简支桁架受向下载荷时，上弦被压缩、下弦被拉长，就像一根工字梁的上下翼缘，中间的斜杆承担剪力。

## 5. 动手实验

### 实验 1（lab）：拖载荷，看颜色翻脸

```lab
{
  "type": "truss-lab",
  "title": "桁架：绿=受拉，红=受压，粗细=|轴力|",
  "wD": -600,
  "wE": -600
}
```

图上的编码只有三条，但信息量很大：

- **绿色杆受拉、红色杆受压、灰色是零杆**，杆的**粗细**正比于轴力大小，一眼能看出哪根最吃力；
- **紫色箭头**是两个可拖的外载荷（拖箭头改大小），杆力随之实时重算；
- 底部两个按钮：**"卸掉全部载荷"**看零载状态，**"两侧对称加载"**回到例题的 600/600。

三件事建议亲手做：

- 从对称的 600/600 出发，把右边那支箭头往下拖到 800 N：原本灰色的 $DB$ 会变**红**（压）、$BE$ 会变**绿**（拉），两者大小相等方向相反。这一对就是"**把左右不对称的那部分剪力搬运过去**"的通道——不对称载荷越大，它们越粗；
- 把右边载荷拖到 0：$EC$ 的轴力会大幅下降，而 $DE$ 几乎不变（$-277.8$ N）。因为水平杆 $DE$ 承担的是**上弦压力的水平分量**，只跟左边那 600 N 有关；
- 观察上弦永远压、下弦永远拉。**压杆要防屈曲**，这就是后面"压杆稳定"一课的伏笔：同样粗细的杆，受压的允许载荷可能只有受拉时的几分之一。

### 实验 2（python）：把桁架写成线性方程组

```python title="节点法：桁架就是一次高斯消元"
import math                      # 数学库（卷一已引入），这里用 hypot 求杆长

nodes = {"A": (0.0, 0.0), "B": (2.0, 0.0), "C": (4.0, 0.0), "D": (1.0, 1.8), "E": (3.0, 1.8)}
members = [("A", "B"), ("B", "C"), ("A", "D"), ("D", "B"), ("B", "E"), ("E", "C"), ("D", "E")]
supports = [("A", "x"), ("A", "y"), ("C", "y")]        # 左铰 2 个 + 右辊 1 个未知反力
loads = {"D": (0.0, -600.0), "E": (0.0, -600.0)}       # 节点外力（fx, fy）

keys = list(nodes)                                     # 节点名 → 行号
idx = {k: i for i, k in enumerate(keys)}
m = len(members)
cols = m + len(supports)                               # 未知量：7 杆力 + 3 反力 = 10
A = [[0.0] * cols for _ in range(2 * len(keys))]       # 10 个方程（每节点两行）
b = [0.0] * (2 * len(keys))

for k, (p, q) in enumerate(members):                   # 每根杆对两端各贡献一个方向余弦
    dx = nodes[q][0] - nodes[p][0]
    dy = nodes[q][1] - nodes[p][1]
    L = math.hypot(dx, dy)
    cx, cy = dx / L, dy / L
    A[2 * idx[p]][k] += cx                             # 拉为正：在 p 端沿 p→q 拉
    A[2 * idx[p] + 1][k] += cy
    A[2 * idx[q]][k] -= cx                             # 在 q 端沿 q→p 拉
    A[2 * idx[q] + 1][k] -= cy

for k, (nd, d) in enumerate(supports):                 # 反力只出现在它自己的那个方程里
    A[2 * idx[nd] + (1 if d == "y" else 0)][m + k] = 1.0

for nd, (fx, fy) in loads.items():                     # 外力移到等号右边
    b[2 * idx[nd]] -= fx
    b[2 * idx[nd] + 1] -= fy

for col in range(cols):                                # 高斯消元：每列选绝对值最大的主元
    piv = max(range(col, len(A)), key=lambda r: abs(A[r][col]))
    A[col], A[piv] = A[piv], A[col]
    b[col], b[piv] = b[piv], b[col]
    for r in range(col + 1, len(A)):
        f = A[r][col] / A[col][col]
        for c in range(col, cols):
            A[r][c] -= f * A[col][c]
        b[r] -= f * b[col]

x = [0.0] * cols
for r in range(len(A) - 1, -1, -1):                    # 回代
    s = b[r]
    for c in range(r + 1, cols):
        s -= A[r][c] * x[c]
    x[r] = s / A[r][r]

for k, (p, q) in enumerate(members):
    N = x[k]
    kind = "拉" if N > 0.5 else ("压" if N < -0.5 else "零杆")
    print(f"{p}{q}: {N:8.1f} N  {kind}")
print(f"反力 Ax = {x[m]:.1f} N, Ay = {x[m + 1]:.1f} N, Cy = {x[m + 2]:.1f} N")
```

输出与手算一步步对上：`AD = -686.4 N 压`、`AB = +333.3 N 拉`、`DB` 与 `BE` 是零杆、`Ay = Cy = 600 N`。

**这段消元正是组件在浏览器里做的事。** 7 根杆只是教学规模；真实输电铁塔有几千根杆，方程组的系数矩阵**极其稀疏**（每列只有四个非零元素），工程师靠的就是这个稀疏性——把 $O(n^3)$ 的稠密消元变成接近 $O(n)$ 的稀疏求解。

### 快问快答

```quiz
桁架里某根杆在当前载荷下被算成零杆，设计时应该怎么处理？
- 直接删掉它，反正不受力
- 保留它：换一组载荷它立刻受力，而且它能约束受压杆的计算长度 [*]
- 保留它，但把截面积减到原来的一半
? 零杆只是「在这组载荷下」内力为零。半跨雪载、风载、施工荷载一来它马上受力；此外它还把受压杆分段支承，缩短压杆的计算长度、提高抗屈曲能力。真实桁架从不会因为一根杆是零杆就把它去掉。
```

:::warning[常见误区]

**误区一**："桁架节点真的是铰接，杆里只可能有轴力。"
你以为三条假设是物理事实——其实它们是** deliberately 简化的计算模型**。真实桁架的节点是焊接或螺栓连接的，节点板有刚度，杆会弯曲，于是产生"次应力"，通常占主应力的 5%~20%。理想模型给出的是**主体内力**，设计长细比大的轻桁架时够用，节点刚性大或杆很短时就必须修正。

**误区二**："轴力为正就是受拉，我在图上看到箭头朝外就放心了。"
你在记符号——但**拉压的后果完全不对等**。拉杆只会因截面不足而拉断，压杆却可能在应力远低于强度时就**屈曲**（突然侧向弯掉）。同样截面积的一根杆，受压许用载荷可能只有受拉时的三分之一。看桁架图时，红色的杆永远比绿色的杆更值得警惕。

**误区三**："杆数越多越结实。"
你在数数量——其实**杆数与反力数必须满足 $m + r = 2n$ 才静定**。多一根杆，结构变成超静定，内力分配开始依赖各杆的刚度（$EA/L$）而不是纯几何；少一根杆，结构变成机构，一推就塌。加杆之前先数一数这个等式，比事后加粗有用得多。

:::

## 6. 练习

**练习 1**：数一数这副桁架（7 根杆、5 个节点、左铰右辊）静不静定。这段代码把右支座的反力数记错了，修到输出 `静定`：

```exercise
# @title: 练习：这副桁架静定吗
# @check: 静定
# @hint: 平面桁架静定判据是 m + r = 2n。左端铰支座给 Fx、Fy 两个反力，右端辊支座还给一个 Fy，所以 r 是 3 而不是 2
m = 7       # 杆件数
r = 2       # ← 问题在这：右边辊支座还贡献一个竖向反力
n = 5       # 节点数
print("静定" if m + r == 2 * n else ("超静定" if m + r > 2 * n else "机构"))
```

**练习 2**：把支座改成两端都是铰支座（$r = 4$），桁架变成什么？这时候能不能只用节点法求出全部杆力？

<details>
<summary>点开查看逐步解答</summary>

1. 判据：$m + r = 7 + 4 = 11 > 2n = 10$，**超静定 1 次**；
2. 节点法只能列出 10 个独立方程，却有 11 个未知量，**第 11 个方程无处可找**——平衡方程已经用尽；
3. 缺的那条方程来自**变形协调**：各杆受力后会伸长或缩短（$\Delta L = NL/EA$），而这些变形必须能拼回一个自洽的几何形状。把变形协调写成方程，才补得上第 11 条；
4. 补上之后会发现：两个支座的水平反力 $F_x$ 之和为零，但各是多少，取决于各杆的 $EA/L$——**刚度大的路径多分**；
5. 工程含义：这种结构（如两端固定的桥梁）一旦温度变化时想伸长却伸不开，就会产生巨大的温度应力，这正是上一课"约束不是越多越安全"的定量版本。

</details>

## 7. 选读：m + r = 2n 是怎么数出来的

<details>
<summary>选读 · 一个计数论证，不是经验公式</summary>

把桁架的 $n$ 个节点全部隔离，每个节点是一个只受共点力系的质点。共点力系平衡的充要条件是合力为零，在平面里就是 2 个标量方程。于是

$$\text{独立方程数} = 2n$$

（严格说，整体平衡的 3 个方程并不独立——它们可以由这 $2n$ 个方程线性组合出来，所以总数仍是 $2n$。）

未知量方面：每根杆贡献 1 个未知轴力，共 $m$ 个；支座贡献 $r$ 个未知反力分量。于是

$$\text{未知量数} = m + r$$

线性方程组有唯一解，当且仅当未知量数等于独立方程数，即 $m + r = 2n$。

这个计数是**必要条件而非充分条件**：即使数字对得上，某些特殊的几何布置（比如某个节点上所有杆共线）仍会让系数矩阵奇异，结构在某一个特定变形模式下"松掉"，称为**瞬变体系**。判断它要靠矩阵的秩，也就是线性代数里"奇异"的标准——$m + r = 2n$ 只能先帮你过第一关。

</details>
