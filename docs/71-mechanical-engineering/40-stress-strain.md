# 应力与应变

## 1. 从一个场景开始

两根吊索，粗细差一倍，吊起同样重的钢卷。粗的那根纹丝不动，细的"啪"一声断了。

吊起来的重量明明一模一样——**力相同，结果却天差地别**。

原因很简单：材料并不知道"外力是多少"，它只知道**自己身上每平方米分摊到了多少力**。这个量叫应力，它是材料力学里真正的主角。

## 2. 直觉解释

同样是一个人，穿雪地靴踩在雪上稳稳当当，换一双细高跟鞋就陷进去了。

体重没变，变的是**接触面积**。雪面承受的不是"你的体重"，而是"每平方厘米的体重"——这就是压强。

应力完全是同一个想法，只不过它发生在物体**内部**：想象把一根受拉的杆拦腰切开，左边那一半之所以没被拉走，是因为右边的材料正通过切开的整个断面把它拉住。断面上每平方米分摊到多少拉力，就是**正应力**。

第二个直觉：一根橡皮筋，拉长一倍还是那根橡皮筋；一根钢筋，你拉它一万年也看不出变化。

为了把"材料"和"尺寸"这两件事分开，我们再定义一个量——**应变**：伸长量占原长的比例。它是无量纲的，所以

$$\text{应力} = \text{弹性模量} \times \text{应变}$$

这条式子（胡克定律）说的就是：**应变是原因的标准化描述，应力是材料的响应，弹性模量是这种材料的性格常数。**

## 3. 正式定义

**正应力**（轴向拉伸或压缩）：

$$\sigma = \frac{F}{A}$$

**正应变**（轴向）：

$$\varepsilon = \frac{\Delta L}{L}$$

**胡克定律**（线弹性范围内）：

$$\sigma = E\,\varepsilon \qquad \Longleftrightarrow \qquad \Delta L = \frac{FL}{EA}$$

最后这个形式特别实用：伸长量与载荷、长度成正比，与 $EA$ 成反比——$EA$ 叫**轴向刚度**，它把"材料"（$E$）和"尺寸"（$A$）打包成一个数。

**屈服强度** $\sigma_y$：材料开始产生永久变形时的应力。设计准则就是

$$\sigma \le \frac{\sigma_y}{n} \quad (n \text{ 为安全系数，通常 } 1.5\sim 3)$$

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $\sigma$ | 正应力 | Pa | $F/A$；$1\ \text{MPa} = 10^6\ \text{Pa} = 1\ \text{N/mm}^2$ |
| $A$ | 截面积 | m² | 常用 mm²，$1\ \text{mm}^2 = 10^{-6}\ \text{m}^2$ |
| $\varepsilon$ | 正应变 | 无量纲 | $\Delta L/L$；工程上常用微应变 $\mu\varepsilon = 10^{-6}$ |
| $E$ | 弹性模量 | Pa | 结构钢约 200 GPa，铝合金约 69 GPa |
| $\Delta L$ | 伸长量 | m | $\Delta L = FL/(EA)$ |
| $\sigma_y$ | 屈服强度 | Pa | 超过它卸载后回不到原长 |

**单位换算的偷懒技巧**：如果力用 N、尺寸用 mm，那么 $\sigma = F/A$ 给出的单位 N/mm² **恰好等于 MPa**，不用任何换算。这是机械设计里最省事的一条惯例。

## 4. 分步例题

**例**：一根结构钢拉杆，截面 $b \times h = 30 \times 20$ mm，长 $L = 1.5$ m，受 $F = 40$ kN 拉力。已知 $E = 200$ GPa、$\sigma_y = 250$ MPa。求应力、应变、伸长量与屈服载荷。

1. **截面积**：$A = 30 \times 20 = 600\ \text{mm}^2 = 6.0\times 10^{-4}\ \text{m}^2$；
2. **应力**：$\sigma = \dfrac{F}{A} = \dfrac{40\times 10^3}{6.0\times 10^{-4}} = 6.67\times 10^7\ \text{Pa} = 66.7\ \text{MPa}$
   （用 N/mm² 心算：$40000 / 600 = 66.7$ MPa，一步到位）；
3. **应变**：$\varepsilon = \dfrac{\sigma}{E} = \dfrac{66.7\times 10^6}{200\times 10^9} = 3.33\times 10^{-4} = 333\ \mu\varepsilon$（即 0.0333%）；
4. **伸长量**：$\Delta L = \varepsilon L = 3.33\times 10^{-4}\times 1.5 = 5.0\times 10^{-4}\ \text{m} = 0.50\ \text{mm}$；
5. **屈服载荷**：$F_y = \sigma_y A = 250\times 10^6 \times 6.0\times 10^{-4} = 1.5\times 10^5\ \text{N} = 150\ \text{kN}$，是工作载荷的 **3.75 倍**；
6. **校验**：$\sigma = 66.7\ \text{MPa} < \sigma_y = 250\ \text{MPa}$，安全系数约 3.75 ✓。

把第 4 步再读一遍：**1.5 m 长的钢杆，被 4 吨的力拉着，只伸长了半毫米。** 钢材在我们日常尺度下"硬"得几乎没有形变——这也是为什么工程上要测应变，靠的是电阻应变片（测到 $\mu\varepsilon$ 量级）而不是尺子。

```lab
    { "name": "h", "label": "截面厚 h", "min": 2, "max": 60, "step": 1, "value": 20 },
    { "name": "L", "label": "杆长 L", "min": 0.2, "max": 5, "step": 0.1, "value": 1.5 }
  ]
}
```

上半部画拉杆与截面，下半部画 $\sigma$-$\varepsilon$ 图上的工作点。四件事值得做：

- **把 $h$ 从 20 拖到 10**（截面减半）：$\sigma$ 从 66.7 跳到 133.3 MPa，图上的工作点沿直线往上爬，**但斜率不变**——斜率是 $E$，是材料的属性，跟你切多粗无关；
- **继续拖到 5 mm**：$\sigma = 267$ MPa 越过红色屈服线，状态栏变成"已屈服，卸载后留残余变形"。**同样的 40 kN，粗杆安全、细杆报废**；
- **切换材料**（结构钢 / 铝合金 / 紫铜 / 木材）：直线斜率 $E$ 从 200 GPa 一路掉到 11 GPa。同样应力下，木材的应变是钢的 18 倍——木结构要先算变形，再算强度；
- **只拖长 $L$**：$\sigma$ 与 $\varepsilon$ 纹丝不动，但 $\Delta L$ 按比例变长。**应力与杆长无关，伸长量才与杆长成正比**——这条区分很容易记混。

### 实验 2（python）：扫一遍截面，找到屈服点

```python title="应力不是力：面积减半，应力翻倍"
# sliders: F=40.0 [0:300:1]
F = 40e3            # 拉力（N）
area = 600e-6       # 截面积（m²），即 30 × 20 mm
E = 200e9           # 结构钢弹性模量（Pa）
sy = 250e6          # 屈服强度（Pa）
L = 1.5             # 杆长（m）

sigma = F / area                       # 正应力（Pa）
eps = sigma / E                        # 正应变（无量纲）
print(f"σ = {sigma / 1e6:.2f} MPa, ε = {eps * 1e6:.1f} µε, ΔL = {eps * L * 1000:.3f} mm")

Fy = sy * area                         # 屈服载荷：应力达到 σy 时的外力
print(f"屈服载荷 Fy = σy × A = {Fy / 1000:.1f} kN（当前载荷的 {Fy / F:.1f} 倍）")

for a in (600e-6, 300e-6, 150e-6):     # 面积逐次减半，看应力怎么翻
    s = F / a
    print(f"A = {a * 1e6:5.0f} mm² → σ = {s / 1e6:6.2f} MPa {'屈服' if s >= sy else '安全'}")
```

输出：`σ = 66.67 MPa, ε = 333.3 µε, ΔL = 0.500 mm`，`屈服载荷 150.0 kN（3.8 倍）`，以及三行面积扫描——600 mm² 安全、300 mm² 安全、150 mm² 屈服。

**这就是选型的日常**：载荷常常是给定的（要吊多重、要压多大），可调的只有截面积和材料。把 `F` 拖到 150 kN 附近再看一眼，你会看到屈服载荷与实际载荷的差距如何被一点点吃光。

### 快问快答

```quiz
两根杆材料相同、长度相同，受同样的 40 kN 拉力，A 杆截面积 600 平方毫米，B 杆截面积 300 平方毫米。关于应力与伸长，正确的是？
- 应力相同，伸长也相同
- A 杆的应力是 B 杆的一半，伸长也是 B 杆的一半 [*]
- B 杆的应力是 A 杆的一半，但伸长是 A 杆的两倍
? 应力等于力除以面积，面积减半则应力翻倍，所以 A 杆的应力是 B 杆的一半；应变与应力成正比，伸长又与应变成正比，所以 A 杆的伸长也是 B 杆的一半。
```

:::warning[常见误区]

**误区一**："应力就是力，只是换了个单位。"
你以为换个词而已——其实**力和应力差一个面积，量纲都不一样**。10 kN 作用在 1000 mm² 上是 10 MPa，安然无恙；作用在 10 mm² 上是 1000 MPa，任何钢材都当场断裂。真正决定"材料坏不坏"的永远是应力，这也是为什么吊索、螺栓、销轴这些零件都要**按截面积选型**而不是按力选型。

**误区二**："应变是长度，所以它的单位是毫米。"
你在给伸长量找单位——其实应变是**两个长度之比**，无量纲：$\varepsilon = \Delta L/L$。$\Delta L = 0.5$ mm 在 1.5 m 杆上是 333 µε，在 0.15 m 短杆上是 3333 µε，**同一个伸长量对应的应变差十倍**。工程上说"这根梁应变 500 微应变"，无论梁多长都是同一个意思，这正是无量纲量的价值。

**误区三**："弹性模量越大，材料越强。"
你在把刚度和强度混为一谈。**$E$ 是刚度**（抵抗变形的能力），**$\sigma_y$ 是强度**（抵抗永久变形的能力），两者几乎没有相关性。铝合金 $E = 69$ GPa 只有钢的 1/3，可高强度铝合金的 $\sigma_y$ 能到 500 MPa，比普通结构钢还高。飞机蒙皮要的是"强而不重"，机床床身要的是"刚度大、变形小"——两种完全不同的诉求，选错指标就会选错材料。

:::

## 6. 练习

**练习 1**：40 kN 拉力下那根 30 × 20 mm、长 1.5 m 的钢杆伸长多少毫米？这段代码漏了截面积，修到输出 `0.5`：

```exercise
# @title: 练习：40 kN 拉力下这根杆伸长多少
# @check: 0.5
# @hint: 伸长 ΔL = F×L/(E×A)，A 是截面积。用米和平方米算完再乘 1000 换成毫米
F = 40e3                  # 拉力（N）
b, h = 30e-3, 20e-3       # 截面宽与厚（m）
E = 200e9                 # 结构钢弹性模量（Pa）
L = 1.5                   # 杆长（m）
dL = F * L / E            # ← 问题在这：少了截面积 b×h
print(round(dL * 1000, 2))
```

**练习 2**：一颗 M10 螺栓（公称直径 10 mm，危险截面按有效面积 58 mm² 计）承受 20 kN 拉力。它的应力是多少 MPa？若螺栓材料屈服强度为 640 MPa，安全系数是多少？

<details>
<summary>点开查看逐步解答</summary>

1. $\sigma = \dfrac{F}{A} = \dfrac{20000}{58} = 344.8$ MPa；
2. 安全系数 $n = \dfrac{\sigma_y}{\sigma} = \dfrac{640}{344.8} = 1.86$；
3. 1.86 听起来还行，但螺栓连接通常要求 $n \ge 2\sim 3$，因为螺纹根部有**应力集中**（局部应力可达平均值的 2~3 倍），而且螺栓常常还要承受预紧力与工作载荷的叠加；
4. 更稳妥的做法是换 M12（有效面积 84.3 mm²）：$\sigma = 237$ MPa，$n = 2.7$ ✓；
5. 顺带一提：这里"用 N 除以 mm² 直接得 MPa"就是正文里那条偷懒技巧——**单位不用换算**。养成这个习惯能省掉设计计算里一大半的 $10^6$ 错误。

</details>

## 7. 选读：圣维南原理——局部的混乱管不了全局

<details>
<summary>选读 · 为什么可以用平均应力</summary>

$\sigma = F/A$ 假设应力在截面上**均匀分布**。可实际上，力总是通过夹具、螺栓孔或焊缝局部传入，传入口附近的应力分布非常混乱，可能达到平均值的数倍。

圣维南原理给出了兜底的说法：**载荷作用点附近的应力分布细节，只影响局部；离载荷作用区足够远（大约一个特征尺寸之外）后，应力分布就只取决于载荷的合力与合力矩，与具体怎么加的无关。**

所以：

- 用 $\sigma = F/A$ 算**远离端部的截面**是可靠的；
- 算**螺栓孔边、焊缝端部、截面突变处**时必须用**应力集中系数** $K_t$ 放大：$\sigma_{\max} = K_t\,\sigma_{\text{avg}}$，圆孔的 $K_t \approx 3$；
- 这也就是为什么零件要在截面变化处**倒圆角**——减小 $K_t$，比单纯加厚有效得多。

这条原理本质上是说：弹性力学的解在远离载荷区会"忘记"细节，只记得总量。它也是有限元里"用分布载荷代替集中力"这种做法的理论靠山。

</details>
