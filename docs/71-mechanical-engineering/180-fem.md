# 有限元思想：把连续切成小块

## 1. 从一个场景开始

一个带孔、带圆角、厚度还在变的支架，承受 3 kN 的载荷。问：孔边的应力有多大？

这个问题**没有解析解**。不是"很难解"，而是没有人知道它的解长什么样——微分方程写成微分方程，但函数形式无从下手。偏偏这种零件满世界都是。

工程师的解法朴素得惊人：**把它切成一百万个小块，每个小块都用会解的方程，然后用"节点上位移必须连续"这条唯一的要求把它们粘起来。** 这个办法叫有限元，它是当代工程分析的绝对主力。

而它最迷人的地方是：**你切得越细，答案越准，而且"准多少"是可以事先算出来的。**

## 2. 直觉解释

回忆第 14 章求不规则图形面积时的做法：把它切成一堆窄矩形，每个矩形面积会算，加起来就是近似值；切得越窄越准。

有限元是同一个招数，但**每个小块不只是"一小块面积"，而是一个完整的、会解的小问题**：

- 把一根杆切成 $N$ 段，每一段都变成一根**等截面的小拉杆**，它的刚度就是一个数 $k_e = EA/L_e$——你在第 40 课（应力与应变）和第 50 课（材料本构）已经会算了；
- 然后把这些小弹簧**按节点编号串起来**，得到一个大方程组 $Ku = F$；
- 解出每个节点的位移，再回到每个小块内部算出应变和应力。

就这么三步。**有限元不神秘，它只是"承认自己不会解连续问题，于是把它拆成一堆会解的小问题，再要求拼缝处不许裂开"。**

关键的那个"要求"，就是**节点位移连续**（相邻单元共用同一个节点位移）。它是把一堆离散小块重新粘成连续体的唯一胶水。

## 3. 正式定义

以一根受拉的变截面直杆为例（长度 $L$、弹性模量 $E$、截面积 $A(x)$、端部载荷 $P$），走完标准五步：

**① 离散化**：把杆切成 $N$ 个单元、$N+1$ 个节点，单元长度 $L_e = L/N$。

**② 单元刚度**（这是唯一用到材料与几何的地方）：

$$k_e = \frac{E\,A(x_e)}{L_e},\qquad x_e = \text{单元中点}$$

**③ 组装**：按节点编号"对号入座"叠加成整体刚度矩阵 $K$。一维杆的 $K$ 是**三对角**的：

$$K_{ii} = k_i + k_{i+1},\quad K_{i,i+1} = K_{i+1,i} = -k_{i+1}$$

**④ 求解**：加上位移边界条件（固定端 $u_0 = 0$，即划掉第一行第一列），解

$$Ku = F,\qquad F = (0,\ 0,\ \dots,\ P)^{T}$$

**⑤ 后处理**：单元内位移用**形函数**线性插值（$N_1 = 1-\xi,\ N_2 = \xi$），再求

$$\varepsilon = \frac{du}{dx},\qquad \sigma = E\varepsilon$$

**收敛性**（线性单元）：位移误差 $\propto h^2$（$h$ 为单元尺寸），即**加密一倍，误差降到四分之一**。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $N$ | 单元数 | 网格粗细的度量，$h = L/N$ |
| $k_e$ | 单元刚度 | 把"材料 + 几何"压成一个数 |
| $K$ | 整体刚度矩阵 | 稀疏、带状、对称正定（加边界条件后） |
| $u$ | 节点位移向量 | 真正的未知量 |
| $\xi$ | 单元局部坐标 | 形函数的自变量，$\xi \in [0,1]$ |

## 4. 分步例题

**例**：$L = 2$ m，$E = 200$ GPa，$A_0 = 5$ cm²，截面积线性收缩 $A(x) = A_0\left(1 - \dfrac{x}{2L}\right)$，端部载荷 $P = 50$ kN。比较有限元解与解析解。

1. **解析解**（沿轴积分 $u = \int_0^L \frac{P}{EA}\,dx$）：

$$u(L) = \frac{P}{EA_0}(-2L)\ln\!\left(1 - \frac{L}{2L}\right) = \frac{P}{EA_0}\cdot 2L\ln 2 = 1.386\ \text{mm}$$

2. **$N=1$**（整根杆当一个单元，取中点截面积）：$A_{mid} = A_0(1 - 0.25) = 3.75$ cm²，$u = \dfrac{PL}{EA_{mid}} = 1.333$ mm，**误差 3.82%**；
3. **$N=4$**：四个单元的刚度依次是 $k_e = EA_{mid,e}/L_e$，总位移为各段之和 $\sum P/k_e = 1.382$ mm，**误差 0.278%**；
4. **$N=8$**：$1.385$ mm，误差 $0.070\%$；$N=32$：$1.38623$ mm，误差 $0.0044\%$；
5. **收敛阶**：每次加密一倍，误差约降到 $1/4$（实测阶数 1.83 → 1.95 → 1.99 → 2.00），**这就是 $\propto h^2$ 的数值证据**；
6. **注意方向**：有限元解总是**偏小**（偏刚）。因为线性形函数强制位移在单元内走直线，相当于给结构额外加了约束——**有限元天生"过硬"**，这个规律在二维、三维里同样成立。

顶部五段按钮就是标准流程，逐个点过去：

- **① 离散化**：橙色的节点与单元分隔线出现，$N+1$ 个节点、$N$ 个单元——**这是唯一的近似来源**；
- **② 单元刚度**：底部出现一排彩色竖条，每个单元一个 $k_e$。因为截面积往端部收缩，**右边的条更矮**（端部单元更软）；
- **③ 组装**：竖条换成 $N\times N$ 的方阵字形，只有主对角线和两条副对角线是亮的——**三对角、半带宽 1**。真实三维模型的 $K$ 有百万阶，但非零元素占比不到万分之一，稀疏性就是有限元能算得动的全部理由；
- **④ 求解**：$Ku = F$，中间那张图画出节点位移（橙色折线）与解析解（灰色虚线）；
- **⑤ 后处理**：折线被标黄——把节点位移插回单元内部，才算真正完成了分析。

拖动 `N` 从 1 到 40，同时盯住右下角的**双对数收敛曲线**：它是一条斜率约 $-2$ 的直线。**这条直线的斜率，就是这套单元的"精度等级"。**

### 实验 2（python）：手写一次完整的有限元

```python title="从组装到求解：手写一个 N 单元拉杆"
import math                        # 数学库：log，用于算收敛阶

L, E, A0, P = 2.0, 200e9, 5e-4, 50e3

def area(x):
    return A0 * (1 - x / (2 * L))              # 截面积沿轴线性收缩

def u_exact(x):
    return (P / (E * A0)) * (-2 * L) * math.log(1 - x / (2 * L))

def fem(N):
    """组装三对角刚度矩阵，用追赶法求解，返回全部节点位移"""
    Le = L / N
    ke = [E * area((e + 0.5) * Le) / Le for e in range(N)]   # ② 单元刚度
    a = [0.0] * N; b = [0.0] * N; c = [0.0] * N; d = [0.0] * N
    for i in range(N):                                       # ③ 组装
        b[i] = ke[i] + (ke[i + 1] if i < N - 1 else 0.0)
        if i >= 1: a[i] = -ke[i]
        if i <= N - 2: c[i] = -ke[i + 1]
        d[i] = P if i == N - 1 else 0.0
    cp = [0.0] * N; dp = [0.0] * N                           # ④ 追赶法（Thomas）
    cp[0] = c[0] / b[0]; dp[0] = d[0] / b[0]
    for i in range(1, N):
        m = b[i] - a[i] * cp[i - 1]
        if i < N - 1: cp[i] = c[i] / m
        dp[i] = (d[i] - a[i] * dp[i - 1]) / m
    u = [0.0] * (N + 1)
    u[N] = dp[N - 1]
    for i in range(N - 2, -1, -1):
        u[i] = dp[i] - cp[i] * u[i + 1]
    return u

ue = u_exact(L)
print("解析解 u(L) = %.4f mm" % (ue * 1000))
print(" N     u(L)/mm    相对误差")
prev = None
for N in (1, 2, 4, 8, 16, 32):
    u = fem(N)[N]
    err = abs(u - ue) / ue
    tail = "" if prev is None else "   阶 %.2f" % (math.log(prev / err) / math.log(2))
    print("%2d   %8.5f    %7.4f%%%s" % (N, u * 1000, err * 100, tail))
    prev = err
```

三件事值得看：

- **误差列**：3.82% → 1.07% → 0.28% → 0.07% → 0.018% → 0.0044%，每加密一倍掉到约四分之一；
- **阶数那一列**：从 1.83 一路爬到 2.00 并停在那里——**线性单元的位移收敛阶就是 2**，这是理论值，不是巧合；
- **所有有限元解都小于解析解**（1.333 < 1.371 < 1.382 < … < 1.386）：有限元**偏刚**，它给结构多加了一份约束。

这段循环体正是商用有限元软件在做的事，只不过真实软件的单元是三维的、形函数是二次的、方程组用共轭梯度法迭代求解。**骨架一模一样。**

### 快问快答

```quiz
用线性单元做有限元分析，把网格整体加密一倍（单元尺寸 h 减半），位移误差大致会变成多少？
- 约一半
- 约四分之一 [*]
- 约八分之一
? 线性单元的位移误差 ∝ h²，h 减半则误差降到 1/4。工程上做「网格收敛性研究」就是靠这条规律：算三档网格，看误差是否按预期的阶下降，不下降就说明模型里还有别的问题（边界条件、奇异性、单元质量）。
```

:::warning[常见误区]

**误区一**：「网格越密，结果越可信。」
你以为密网格等于精确——其实误差按 $h^2$ 下降，而**计算量和舍入误差同时在涨**。更危险的是：在**几何奇异点**（尖角、集中载荷作用点、裂纹尖端）应力本身是无穷大，网格越密应力越高，**永远不会收敛**。正确做法是先问"这里是不是奇点"，再看收敛曲线。

**误区二**：「位移算准了，应力也就准了。」
你以为两者精度相同——其实**应力是位移的导数**，求导会放大误差：位移在节点上最准，而应力在**单元内部的高斯点**上最准。所以后处理要做的第一件事是应力磨平/外推，而不是直接读节点值。**有限元里位移是一阶量，应力是二阶量。**

**误区三**：「有限元算出来的就是答案。」
你以为软件输出等于现实——其实**输入错了，软件只会高效地给出错误的彩色云图**：材料参数、边界条件（尤其"固定"到底约束了几个自由度）、载荷方向、单位制，任何一个出错，结果都毫无意义。工程上有句行话：**"All models are wrong, some are useful"**——有限元的第一课是怀疑自己的模型，不是相信云图的颜色。

:::

## 6. 练习

**练习 1**：这段代码把整根杆当成等截面（所有单元都用根部截面积 $A_0$），输出 `u(L) = 1.0000 mm`。修正后应输出 `u(L) = 1.3824 mm`：

```exercise
# @title: 练习：单元刚度取错了截面积
# @check: u(L) = 1.3824 mm
# @hint: 变截面杆的单元刚度要用「单元中点」处的截面积 A((e + 0.5)·Le)。代码里所有单元都用了根部 A0，等于把杆当成了等截面（A0 处处不变）
L, E, A0, P, N = 2.0, 200e9, 5e-4, 50e3, 4

def area(x):
    return A0 * (1 - x / (2 * L))

Le = L / N
u = 0.0
for e in range(N):
    k_e = E * A0 / Le              # ← 问题在这：应改用 area((e + 0.5) * Le)
    u = u + P / k_e                # 串联：每个单元承受同一个轴力 P，位移相加
print("u(L) = %.4f mm" % (u * 1000))
```

**练习 2**：为什么端部单元更软、对端部位移的贡献更大？如果只在端部局部加密网格，误差会怎么变？

<details>
<summary>点开查看逐步解答</summary>

1. **端部单元更软**：$A(x) = A_0(1 - x/2L)$，在 $x=L$ 处截面积只剩 $A_0/2$。由 $k_e = EA/L_e$，同样长度的单元，截面积减半则刚度减半，即**柔度翻倍**；
2. **贡献占比**：$N=4$ 时四个单元的柔度 $\propto 1/A_{mid}$，分别是 $1/0.9375$、$1/0.8125$、$1/0.6875$、$1/0.5625$（相对值），最端部的单元贡献了总位移的约 $32\%$——**变形集中在最软的那一段**；
3. **局部加密是对的**：因为误差也集中在那里。把端部单元再细分，误差下降的速度比均匀加密更快；
4. **但要小心**：局部加密会在"粗网格 / 细网格"的交界处产生**不协调的节点**（悬挂节点），位移连续性被破坏，需要引入约束方程或过渡单元；
5. **工程做法**：现代软件用**自适应网格细分**（adaptive refinement）——先算一遍，估计每个单元的误差，只细分误差大的单元，再算，如此循环。**用误差本身来指导网格，比拍脑袋均匀加密高效得多。**

**这题的核心是**：有限元的精度不是"网格密度"一个数字说了算，而是**误差分布**说了算。会看误差分布，才会做分析。

</details>

## 7. 选读：形函数与弱形式——为什么是 $Ku = F$

<details>
<summary>选读 · 从微分方程到矩阵方程</summary>

杆的平衡方程是

$$-\frac{d}{dx}\left(EA\frac{du}{dx}\right) = f(x)$$

有限元不求它，而是求它的**弱形式**（乘一个任意试函数 $w$ 再积分）：

$$\int_0^L EA\,u'\,w'\,dx = \int_0^L f\,w\,dx + \bigl[\text{边界项}\bigr]$$

两次变化带来两个好处：

1. **导数阶数从二阶降到一阶**，于是只需要"位移本身连续"（$C^0$ 连续），分段线性函数就够用了——这就是形函数可以是折线的原因；
2. 把 $u \approx \sum N_j u_j$（形函数展开）代入，并对每个形函数 $N_i$ 都取一次 $w = N_i$，立刻得到 $N$ 个方程：

$$\sum_j \left(\int_0^L EA\,N_i'N_j'\,dx\right) u_j = \int_0^L f N_i\,dx \;\Longrightarrow\; K_{ij} = \int EA\,N_i'N_j'\,dx$$

**$K_{ij}$ 就是形函数导数的乘积的积分**——对线性单元、常数 $EA$，这个积分恰好就是 $\frac{EA}{L_e}\begin{bmatrix}1 & -1\\ -1 & 1\end{bmatrix}$，与本课用的"小弹簧"图像完全一致。

这个方法叫 **Galerkin 加权余量法**。它的意义在于：

- 它告诉你**形函数是唯一的近似假设**——网格、单元类型、精度全由它决定；
- 它也解释了为什么第 55 章的 PINN 是另一条路：PINN 用神经网络当试函数、用损失函数代替弱形式，**两者在"把微分方程变成可优化/可求解的代数问题"这一点上是同一思想的两种实现**。

</details>
