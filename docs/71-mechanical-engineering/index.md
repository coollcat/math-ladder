# 机械工程与力学

机械工程研究如何**让确定的材料，在确定的载荷下，做出确定的运动而不坏**。它是卷六里最古老的一章——从阿基米德的杠杆到今天的有限元，用的还是那两条方程：合力为零，合力矩为零。

这一章的主线只有一条：**先把物体隔离出来（自由体图），再让它受力平衡（静力学），然后看材料内部发生了什么（应力应变），最后把这些关系沿着构件积分一遍（梁的内力图）。**

## 路线图

1. [力、力矩与静力平衡](./10-force-moment.md)——塔吊的配重只有几吨，凭什么压得住几十吨的吊重？答案藏在"力臂"里。
2. [自由体图与约束反力](./20-free-body.md)——桥梁为什么一端要放在滚轴上故意"站不稳"？约束不是越多越安全。
3. [桁架与杆件内力](./30-truss.md)——屋顶桁架全是三角形，不是因为好看，而是因为四边形会塌。
4. [应力与应变](./40-stress-strain.md)——同样 10 kN 的力，粗杆安然无恙，细杆当场屈服：材料感受到的从来不是力。
5. [材料本构与弹性模量](./50-material.md)——回形针弯一次就掰不直，弹簧钢片却能弹回来，差别写在应力-应变曲线上；
6. [流体基础：连续介质的写法](./55-fluid-basics.md)——固体讲应力应变，流体讲压强与流速：连续性方程与伯努利方程是同一套守恒律换了介质；
7. [热传递：传导、对流与辐射](./58-heat-transfer.md)——三种传热方式各有自己的定量规律，热阻网络让复合墙体的传热可以像算电路一样算；
8. [梁的剪力图与弯矩图](./60-beam-diagram.md)——一根梁哪里最危险？不用猜，让剪力图过零的地方告诉你。
9. [梁的挠度与刚度](./70-beam-deflection.md)——输送梁满载下沉 5.4 毫米，皮带开始跑偏，换更贵的钢材却一点用没有——挠度不认材料牌号，只认截面惯性矩；
10. [压杆稳定与屈曲](./80-buckling.md)——2 米长的细钢杆压到 20.6 kN 就突然侧向弯折——不是被压坏，而是被压“失稳”，欧拉临界力先于强度到账；
11. [扭转与轴设计](./90-torsion.md)——传动轴剪应力富余五倍看着很安全，可扭转变形早已把额外载荷写进齿轮——实心换空心还能省下一半重量；
12. [疲劳与 S-N 曲线](./100-fatigue.md)——静强度安全系数接近 3 的轴，转上几年照样断——裂纹不起于一次过载，而是一次次往复应力的累积；
13. [公差配合与尺寸链](./110-tolerance.md)——五个零件个个检验合格，装到一起却装不进去——公差会沿尺寸链叠加，最坏情况与均方根给出两种答案；
14. [平面机构与自由度](./120-mechanism-dof.md)——同样的四杆四销，有人装出能连续转的曲柄摇杆，有人装出推不动的死架子——自由度公式装配前就把结局算好了；
15. [四连杆机构运动学](./130-four-bar.md)——雨刮电机一直朝一个方向转，刮片却只在一百多度里来回摆——四连杆把整周转翻译成往复摆，还顺手放大了力矩；
16. [凸轮与从动件](./140-cam.md)——气门要在 0.02 秒里抬起 8 毫米再精确落回，每分钟重复三千次——凸轮轮廓就是这条运动规律的全部答案，还得绕开刚性冲击；
17. [齿轮传动与传动比](./150-gear-train.md)——电机 3000 转、车轮只要 100 转外加扭矩放大三十倍，一级齿轮齿数不够会根切——多级与行星齿轮组把传动比拆着完成；
18. [带传动与链传动](./160-belt-chain.md)——电机和滚筒隔着半米，一根皮带就把运动和力送过去——欧拉公式划出不打滑的边界，多边形效应则让链传动悄悄抖起来；
19. [机械振动与隔振](./170-vibration.md)——垫了四块橡胶垫，读数反而跳得更厉害——隔振器有个 $\sqrt{2}$ 门槛，转速低于它是放大器，高过它才开始隔振；
20. [有限元思想：把连续切成小块](./180-fem.md)——带孔带圆角的支架没有解析解，那就切成一百万个小块——切得越细答案越准，而且“准多少”可以事先算出来；
21. [机械工程方法地图](./190-method-map.md)——电机发烫、轴断成贝壳纹路：全章工具的导诊地图，不添新定理，只教你故障面前先翻哪一课。

## 方法主线

**隔离 → 平衡 → 本构 → 积分。**

第一步把研究对象从世界里"剪"出来，剪断的地方用反力代替；第二步列平衡方程，把力的世界翻译成线性方程组；第三步引入材料的性格（应力-应变关系），让"受力"变成"变形"；最后一步沿构件积分，把局部的微分关系变成全局的图形。

前五卷的数学在这里第一次成建制地兑现：**向量**给出力的分解，**勾股定理**给出杆长与方向余弦，**高斯消元**解出桁架的几十个未知杆力，**微积分基本定理**把载荷积分成剪力、再积分成弯矩。

## 实战挑战 · 塔吊的配重

> 场景说明：小型塔吊的吊臂长 4 m，支点（塔身）位于距吊臂左端 1 m 处，配重挂在左端 0.4 m 处，吊重挂在右端 4 m 处。取重力加速度 9.8 m/s²。本题的操作情境为教学构造。

吊 200 kg 的构件时，配重至少要多重才不会向前倾覆？下面这段代码忘了把配重自己的力臂除回去，修到输出 `9800.0`：

```exercise
# @title: 实战挑战：这台塔吊要配多重的配重
# @check: 9800.0
# @hint: 对支点取矩：配重 × 配重力臂 = 吊重 × 吊重力臂。吊重力臂是 4.0 − 1.0 = 3.0 m，配重力臂是 1.0 − 0.4 = 0.6 m
g = 9.8              # 重力加速度（m/s²）
m_load = 200.0       # 吊重质量（kg）
W = m_load * g       # 吊重的重力（N）
arm_load = 4.0 - 1.0 # 吊重对支点的力臂（m）
arm_cw = 1.0 - 0.4   # 配重对支点的力臂（m）
W_cw = W * arm_load  # ← 问题在这：等式右边还要除以配重自己的力臂
print(round(W_cw, 1))
```

<details>
<summary>点开查看逐步解答</summary>

1. 吊重的重力 $W = mg = 200 \times 9.8 = 1960$ N；
2. 对支点取矩，吊重的力臂是 $4.0 - 1.0 = 3.0$ m，产生力矩 $1960 \times 3.0 = 5880$ N·m；
3. 配重挂在支点左侧，力臂是 $1.0 - 0.4 = 0.6$ m，必须产生同样大的反向力矩；
4. 于是 $W_{cw} = \dfrac{5880}{0.6} = 9800$ N，约合 **1000 kg 配重**；
5. 校验：吊臂自重还没算进来。真实塔吊会把自重折算成一个向下的等效载荷，工程师还要再乘 1.5 左右的**抗倾覆安全系数**——所以实机配重比这个数大得多。

初始代码算出 5880 N——它把"要让两边力矩相等"做对了一半，却忘了配重的力臂只有 0.6 m，**力臂越短，需要的重量越大**。这就是为什么配重块总是被推到吊臂的最末端：不是为了省地方，是为了省力臂的亏。

</details>
