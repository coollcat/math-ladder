# 梁的挠度与刚度

## 1. 从一个场景开始

一条 6 米跨度的输送线支撑梁，满载后中点稳稳下沉了 5.4 毫米——皮带开始跑偏，托辊异响，每两天就得调一次张紧。

工程师第一反应是"换更好的钢"。但 Q235、Q345、40Cr 的弹性模量全都是 210 GPa 上下，**换钢材一点用都没有**。

真正让挠度降下来的，是把腹板从 300 毫米加高到 400 毫米。同样重量增加不多，挠度直接砍掉一半还多——这背后是一个关于"三次方"的秘密。

## 2. 直觉解释

拿一把塑料尺，两端架在书上，中间用手指压。

你会发现：**尺子每一小段都在"转一点点角度"，而中点的下沉是所有这些小转角一层层累积出来的。**

这就解释了两件事：

- 为什么跨度翻倍那么致命？**段数翻了一倍，每段的转角也翻了一倍**（力臂更长），累积下来是 $2 \times 2 \times 2 = 8$ 倍。挠度与跨度的**三次方**成正比；
- 为什么尺子立着放（薄边朝上）几乎压不动？把材料挪到离中性轴更远的地方，同样的截面面积能换来大得多的"抗弯惯性矩"，而且这个量按高度的**三次方**增长。

所以梁的刚度只有一个旋钮可以拧：**截面形状**。（换个铝合金？E 只有 69 GPa，挠度反而变三倍。）

## 3. 正式定义

梁的挠度曲线 $v(x)$ 满足**挠曲线微分方程**（小变形、平截面假定下）：

$$EI\,\frac{d^2 v}{dx^2} = M(x)$$

只要会写弯矩方程 $M(x)$（上一课的本事），积分两次、用两个边界条件定常数，就得到挠度。

常用解析结果（等截面、单一载荷）：

| 支承与载荷 | 最大挠度 | 位置 |
| --- | --- | --- |
| 简支 · 跨中集中力 $P$ | $\delta = \dfrac{PL^3}{48EI}$ | 跨中 |
| 简支 · 全长均布 $w$ | $\delta = \dfrac{5wL^4}{384EI}$ | 跨中 |
| 悬臂 · 自由端集中力 $P$ | $\delta = \dfrac{PL^3}{3EI}$ | 自由端 |
| 悬臂 · 全长均布 $w$ | $\delta = \dfrac{wL^4}{8EI}$ | 自由端 |

**抗弯刚度** $EI$ 与**挠跨比**：

$$\text{挠跨比} = \frac{L}{\delta_{\max}} \quad(\text{记作 } L/500,\ L/250 \dots)$$

矩形截面 $b \times h$（$h$ 为高度方向）：$I = \dfrac{bh^3}{12}$；圆截面直径 $d$：$I = \dfrac{\pi d^4}{64}$。

| 符号 | 名字 | 单位 | 含义 |
| --- | --- | --- | --- |
| $v(x)$ | 挠度 | 米 m | 轴线偏离原位（下挠为负） |
| $M(x)$ | 弯矩 | 牛·米 N·m | 上一课的剪力图/弯矩图给出 |
| $E$ | 弹性模量 | 帕 Pa | 材料属性，钢材基本都是 210 GPa |
| $I$ | 截面惯性矩 | m⁴ | **几何属性**，抗弯能力，$\propto h^3$ |
| $EI$ | 抗弯刚度 | N·m² | 刚度只看这一个乘积 |
| $\delta_{\max}$ | 最大挠度 | 米 m | 设计校核量 |

## 4. 分步例题

**例**：简支梁跨度 $L = 6$ m，跨中集中力 $P = 20$ kN，工字钢 $I = 8000$ cm⁴，钢 $E = 210$ GPa。求跨中挠度、挠跨比；若设备厂家要求 $\delta \le L/3000$，该怎么改？

1. **单位换算**（这一步错得最多）：$I = 8000\ \text{cm}^4 = 8000 \times 10^{-8}\ \text{m}^4 = 8.0\times10^{-5}\ \text{m}^4$；
2. **抗弯刚度**：$EI = 210\times10^{9} \times 8.0\times10^{-5} = 1.68\times10^{7}$ N·m²；
3. **跨中挠度**：$\delta = \dfrac{PL^3}{48EI} = \dfrac{20000 \times 6^3}{48 \times 1.68\times10^{7}} = \dfrac{4.32\times10^{6}}{8.064\times10^{8}} = 5.36\times10^{-3}$ m $= 5.36$ mm；
4. **挠跨比**：$L/\delta = 6000 / 5.36 = 1119$，记作 **L/1119**；
5. **对照要求**：$L/3000 = 6000/3000 = 2.0$ mm，当前 5.36 mm，**不达标**，需要把 $EI$ 提高 $5.36/2.0 = 2.68$ 倍；
6. **改法**：换钢材无效（$E$ 不变），只能加 $I$。主承弯的是腹板高度 $h$，$I \propto h^3$。把 $h$ 从 300 mm 加到 400 mm，$I$ 变成 $(400/300)^3 = 2.37$ 倍，$\delta = 5.36 / 2.37 = 2.26$ mm；
7. **收尾**：2.26 mm 仍略大于 2.0 mm，再顺手把翼缘加宽 10 mm 补上剩余 12%——**加高优先、加宽次之**，这就是 $h^3$ 教给我们的省钱顺序。

### 实验 2（python）：把弯矩积分两次

```python title="弯矩积分两次得到挠度曲线"
# sliders: L=6 [2:14:0.1]
L = 6.0                      # 跨度（米）
P = 20000.0                  # 跨中集中力（牛）
E = 210e9                    # 钢弹性模量（帕）
I = 8000e-8                  # 8000 cm⁴ 换算成立方米四次方
EI = E * I
n = 600                      # 离散段数
dx = L / n

xs = [i * dx for i in range(n + 1)]                  # 沿梁的采样点
# 简支梁跨中集中力的弯矩：M(x) = P/2 × min(x, L−x)
M = [P / 2 * min(x, L - x) for x in xs]

# 第一次积分：转角 θ(x) = ∫ M/EI dx，取 θ(0) = 0
theta = [0.0]
for i in range(1, n + 1):
    theta.append(theta[-1] + (M[i - 1] + M[i]) / 2 / EI * dx)

# 第二次积分：g(x) = ∫ θ dx，满足 g'' = M/EI，但 g(L) 一般不为零
g = [0.0]
for i in range(1, n + 1):
    g.append(g[-1] + (theta[i - 1] + theta[i]) / 2 * dx)

# 补上支座条件 v(0) = v(L) = 0：减去一条直线即可
v = [g[i] - xs[i] / L * g[-1] for i in range(n + 1)]

dmin = min(v)                                        # 最负的那点就是最大下挠
print(f"跨中挠度 = {abs(v[n // 2]) * 1000:.3f} mm")
print(f"数值极值 = {abs(dmin) * 1000:.3f} mm  位置 x = {xs[v.index(dmin)]:.2f} m")
print(f"解析公式 = {P * L ** 3 / (48 * EI) * 1000:.3f} mm")
print(f"挠跨比 = L/{L / abs(dmin):.0f}")
```

输出是 `5.357 mm / 5.357 mm（x = 3.00 m）/ 5.357 mm / L/1120`——数值解、跨中值、解析解三者完全一致，因为它们本来就是同一个方程的三种写法。

关键点在倒数第三步：**积分会出现两个常数，而它们正好由"两端支座处挠度为零"这两个条件定死。** 这就是为什么挠度问题总是一个边值问题，而不是简单地从 $x=0$ 一路积分过去。

一根简支钢梁，跨度从 4 m 加到 8 m，其他条件完全不变，跨中挠度变成原来的几倍？
- 2 倍
- 4 倍
- 8 倍 [*]
? 挠度正比于 L 的三次方：2³ = 8。这就是长跨度结构（大梁、桥架、行车）必须做成桁架或箱型的根本原因——靠加大截面去硬扛三次方，重量会失控。
```

:::warning[常见误区]

**误区一**："想让梁更硬，就换强度更高的钢。"
你以为 Q345 比 Q235 硬——其实**所有钢材的弹性模量都在 205~210 GPa**，屈服强度差一倍，刚度几乎一模一样。强度决定"会不会断"，刚度决定"弯多少"，两者是独立的两件事。真正能改刚度的只有截面惯性矩 $I$ 和结构形式（加支撑、变桁架、改简支）。

**误区二**："$\delta = PL^3/48EI$ 里 $I$ 是截面面积，加宽翼缘最有效。"
你以为材料越多越硬——其实 $I = \int y^2 dA$ 给**离中性轴远的材料加了平方权重**。同样多的钢材，铺在上下翼缘（远离中心）比堆在中性轴附近有效得多。这就是工字钢、箱型梁、蜂窝板全是"空心"的原因：**中间那块材料对抗弯几乎没贡献**，不如省下来做两个厚翼缘。

**误区三**："挠度算出来 5 mm，挠跨比 L/1200，肯定没问题。"
你在只看数值——**挠度限值取决于用途，没有通用标准**。屋面檩条 $L/200$ 就够（肉眼不嫌），机床横梁要 $L/5000$ 以上（直接影响加工尺寸），精密测量设备的基座甚至要按微米控制。反过来，挠度也不是越小越好：故意做成柔性梁，正是弹簧、秤、柔性铰链的工作原理。

:::

```

**练习 2**：一根悬臂梁，长 $L = 1.5$ m，自由端挂 $P = 3$ kN，$E = 210$ GPa，矩形截面 $b = 40$ mm、$h = 80$ mm（$h$ 是竖直方向）。求自由端挠度；若把截面转 90°（$h = 40$ mm），挠度变成几倍？

<details>
<summary>点开查看逐步解答</summary>

1. 截面惯性矩（$h$ 是弯曲方向的高度）：$I = \dfrac{bh^3}{12} = \dfrac{0.04 \times 0.08^3}{12} = \dfrac{0.04 \times 5.12\times10^{-4}}{12} = 1.707\times10^{-6}$ m⁴；
2. 抗弯刚度：$EI = 210\times10^{9} \times 1.707\times10^{-6} = 3.585\times10^{5}$ N·m²；
3. 悬臂自由端挠度：$\delta = \dfrac{PL^3}{3EI} = \dfrac{3000 \times 1.5^3}{3 \times 3.585\times10^{5}} = \dfrac{1.0125\times10^{4}}{1.0755\times10^{6}} = 9.41\times10^{-3}$ m $= 9.41$ mm；
4. 转 90° 后 $I' = \dfrac{0.08 \times 0.04^3}{12} = 4.267\times10^{-7}$ m⁴，只有原来的 $1/4$；
5. 所以挠度变成 **4 倍**：$\delta' = 37.6$ mm。

同一根矩形条，平放和立放差 4 倍——这就是 $h^3$ 的直接后果。注意第 4 步里 $I$ 缩小 4 倍而不是 2 倍：宽度 $b$ 只是一次方，高度 $h$ 才是三次方，转 90° 时两者互换。

</details>

## 7. 选读：为什么是「积分两次」

<details>
<summary>选读 · 从曲率到挠度，以及常数怎么定</summary>

一根梁弯了之后，轴线变成一条曲线 $v(x)$。曲率的定义是 $\kappa = v''/(1+v'^2)^{3/2}$，小变形下 $v' \ll 1$，于是 $\kappa \approx v''$。

材料力学给出**曲率与弯矩成正比**（纯弯时平截面假定 + 胡克定律）：

$$\kappa = \frac{M}{EI} \quad\Longrightarrow\quad EI\,v'' = M(x)$$

注意量纲：$M$ 是 N·m，$EI$ 是 N·m²，所以 $v''$ 的量纲是 1/m——正好是曲率。

积分一次得转角 $\theta = v'$，再积分一次得挠度 $v$，两次各冒出一个常数 $C_1, C_2$：

$$EI\,v(x) = \int_0^x\!\!\int_0^s M(t)\,dt\,ds + C_1 x + C_2$$

两个常数由**边界条件**定：

- 简支梁：$v(0) = 0$、$v(L) = 0$（两端支座不允许位移，但允许转动）；
- 悬臂梁：$v(0) = 0$、$\theta(0) = 0$（固定端既不移位也不转角）。

以简支梁跨中集中力为例，弯矩是分段的：$M(x) = \frac{P}{2}x\ (x \le L/2)$，$M(x) = \frac{P}{2}(L-x)\ (x > L/2)$。分段积分、用左右两段在 $x=L/2$ 处**转角连续**再补一个条件，最后代入 $v(L)=0$，就能解出

$$v(L/2) = -\frac{PL^3}{48EI}$$

负号表示向下。而上面那段 Python 代码用的"减去一条直线"技巧，本质上就是在数值上完成"定 $C_1$"这一步——**两个支座条件，一个用来保证 $v(0)=0$（取积分下限为 0），另一个用来把 $v(L)$ 拉回零。**

悬臂梁只需换个写法：固定端两个条件都在 $x=0$，可以直接一路积分过去，不需要"拉回来"。这也是为什么悬臂梁的解析解比简支梁好推。

</details>
