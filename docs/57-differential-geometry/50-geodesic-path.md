# 测地线：曲面上的最直路径

## 1. 从一个场景开始

第 35 课我们抄过近道：在篮球上绷一根橡皮筋，它收紧成大圆弧——球面交出的"最短路线"。可世界上不止球面：跳伞员落在山谷坡面上要横穿逃生、自动扫地机器人贴着曲面罩壳规划路线、引力透镜后的星光走的是弯曲时空自己的路。橡皮筋不可能随身携带，谁替所有曲面回答"怎么走才不绕路"？

这一课把"绷紧"翻译成微积分的语言。答案漂亮得出人意料：一条路直不直，不用看完整条路，只要盯住**每一瞬间的加速度指向哪里**。

## 2. 直觉解释

先把主角请回第 10 课：一条参数曲线 $\vec P(t)$ 有速度和加速度。加速度是"拐弯的原动力"，但它分两股——

$$\vec a = \underbrace{\left(\vec a \cdot \vec n\right)\vec n}_{\text{法向分量}} + \underbrace{\text{剩下的切向部分}}_{\text{真正的偏航}}$$

其中 $\vec n$ 是曲面的法向量（垂直于切平面的那根手指）。想象你在山路上开车：

- **法向分量**：地形把你按住的那股力——过拱桥时座椅传来的下压感。它是地面干的，不算你拐弯；
- **切向分量**：你自己方向盘打出来的那部分，方向躺在路面里。只要有它残余，路径就真的偏离了"顺其自然"的走法。

于是测地线登场：**沿弧长匀速前进时，加速度完全砸进法向（切向剩余为零）的曲线就叫测地线**——它是曲面允许范围内最"懒"、最直的走法。

这套"初速加受力决定整条命运轨迹"的眼力，你在[相图与线性化](../22-ode-dynamics/40-phase-portraits.md)一课已经练过一遍；测地方程同样是二阶动力系统，出发点与出发方向一旦给定，命运全程锁定。

## 3. 正式定义

设 $\vec P(s)$ 以弧长 $s$ 为参数（速度恒为单位），$\vec T = d\vec P/ds$ 是单位切向量，$\vec n$ 为曲面在该点的单位法向量。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\vec T$ | 单位切向量 | 前进的方向 |
| $\dfrac{d\vec T}{ds}$ | 方向变化率 | 只剩拐弯信息（速度大小已被匀速锁死）|
| $k_g = \left\|\dfrac{d\vec T}{ds} - \left(\dfrac{d\vec T}{ds}\cdot\vec n\right)\vec n\right\|$ | **测地曲率** | 拐弯中真正属于"自己乱拐"的部分 |
| 测地线 | — | $k_g \equiv 0$ 的曲线 |

三句话读法：

1. $k_g=0$ 等价于 $d\vec T/ds$ 全部指向法向——你只被地形托着，没有自作主张；
2. 在平面里法向根本不在曲面内？不对——平面的法向恰好在曲面外，而匀速圆周运动的向心加速度躺在平面里，全部算切向残留，所以圆不是平面测地线，直线才是；
3. 写成坐标方程时它由 Christoffel 符号（第一基本形式的导数拼装）驱动——选读栏一见，第 60 课正式接棒。

## 4. 分步例题

**例一（平面里的冤案）**：质点以恒定速率绕圆周跑。

1. 加速度 $v^2/r$ 指向圆心，躺在全国面所在平面内；
2. 平面的 $\vec n$ 垂直于纸面，加速度在其上的投影为 0 → 法向分量为零；
3. 切向剩余全额保留，$k_g = v^2/r \neq 0$ → 圆周**不是**测地线。"看起来规规矩矩转圈"救不了它：平面没托它弯，弯全是自己干的。

**例二（圆柱纬线的翻身）**：圆柱半径 2 上绕圈的参数化 $\vec P(t)=(2\cos t,\,2\sin t,\,v_0)$。

1. 匀速时加速度指向轴心，恰好水平径向；
2. 圆柱的法向量正是水平径向（从侧面垂直顶出）→ 加速度与 $\vec n$ 平行；
3. 切向剩余为零，$k_g = 0$ → **绕柱一圈的纬线竟是测地线**！第 30 课早已备好铁证：圆柱剪开摊平后，这条圆变成水平直线。
4. 对照母线（竖直直线）同样 $k_g=0$：解卷后两者都是直线——摊平操作把测地线映成测地线，圆筒的内蕴平坦在此兑现。

**例三（球面纬线的原形毕露）**：单位球上北纬 $\varphi$ 的纬线圈匀速行走。用下一节的数值实验直接量出 $k_g \approx \tan\varphi$：赤道上为 0（纬线即大圆，光荣测地），往两极一路虚胖。除大圆外，没有任何纬线有资格称测地——第 35 课橡皮筋早就演示过了。

## 5. 动手实验

### 实验 1（python 滑块）：亲手量球面纬线的"假直"

思路预告：沿纬线撒一圈等弧长样本点，用中心差分近似 $d^2\vec P/ds^2$（自动就是弧长参数下的加速度），再减去法向分量——剩下的长度就是实测测地曲率。完整可运行版本如下：

```python title="测地曲率实测 vs tan φ（可运行的完整版）"
# sliders: lat_deg=60 [0:84:4]
import math                                  # 标准库 math：三角函数与 pi 常数

phi = math.radians(lat_deg)                  # 滑杆纬度换成弧度
N = 400                                      # 样本数：差分的分辨率
ring = math.cos(phi)                         # 纬线圆半径（单位球）
h = math.sin(phi)                            # 纬线高度

pts = []                                     # 样本坐标列表
for k in range(N):                           # 均匀撒 N 个经度采样
    lam = 2 * math.pi * k / N
    pts.append((ring * math.cos(lam), ring * math.sin(lam), h))

step = ring * 2 * math.pi / N                # 相邻采样的真实弧长
kg_sum = 0.0                                 # 测地曲率的累加器
for k in range(1, N - 1):                    # 遍历内部样本做中心差分
    acc = []
    for i in range(3):                       # 对 x、y、z 三个坐标分别求二阶差商
        a_i = (pts[k + 1][i] - 2 * pts[k][i] + pts[k - 1][i]) / (step * step)
        acc.append(a_i)
    dot = sum(acc[j] * pts[k][j] for j in range(3))     # acc 与法向(=位置向量)的点积
    rest = [acc[j] - dot * pts[k][j] for j in range(3)] # 减去法向分量得到切向剩余
    kg_sum += math.sqrt(sum(rest[j] * rest[j] for j in range(3)))

kg = kg_sum / (N - 2)                        # 取平均得实测 kg
theory = math.sin(phi) / math.cos(phi)       # 理论值 tan φ
print("实测 kg =", round(kg, 4))
print("理论 tan =", round(theory, 4))
```

拖动滑杆：`lat_deg=0` 时两个数字都归零（赤道无愧测地之名）；滑到 60° 后双双逼近 0.577。每一步的速度都一样快，却依然被量出"真在拐弯"——这正是切向剩余抓的那种骗术。

### 快问快答

```quiz
在圆柱面上沿着环绕的纬线圆匀速走，这条路是不是测地线？
- 不是，圆形怎么会是最短路
- 是——把它所在的圆柱剪开摊平，它就是一条水平直线 [*]
- 只有竖直的母线才有资格当测地线
? 圆柱的内蕴几何和平面一模一样：摊平后圆周变直线，直线当然映射回测地线。真正该警惕的是球面——同样的纬线那里就露馅了。
```

:::warning[常见误区]

**误区一**："弯的路一定不是最短路。" 要分开两种弯：被曲面托出来的弯（法向）免费赠送，大家都享受；自己在切平面里拐出去的弯（切向）才是浪费里程。圆柱纬线走的是前者，所以照样测地。

**误区二**："忘了先换到弧长参数。" 变速前进时 $d\vec T/dt$ 里混着加减速度的伪装成分，会冤枉或洗白一条直线。先匀速化再谈方向——这正是定义强制弧长参数的原因。

**误区三**："测地线处处都是全局最短。" 只对足够短的段成立。从北极走到南极沿任何一条经线都是测地线，谁也不比谁短；跨过赤道的两条机场航段里，较长的那条至少还是"局部无可挑剔"。测地的承诺是不偷小步的懒，不是保证夺冠。

:::

**练习 2**（判题）：仓库里有一根半径 2 米的圆柱形烟囱，壁虎从标记线（$u=0,\ v=0$）出发去捕猎：同一时刻目标停在角度转过四分之一圈、高度爬升 8 米的位置 $(u=\pi/2,\ v=8)$。壁虎有两种候选方案——斜着直奔，或者先贴墙水平绕完再竖直攀爬。程序开工了，但作者把"参数角"直接当成了"米"来花。

```exercise
# @title: 练习：给烟囱上的壁虎解卷选路
# @check: 9
# @check: 11
# @hint: 一格参数 du 对应的真实弧长是 r·du，先乘半径再进勾股；两种方案共用同一个 horizontal。
import math                                   # 标准库 math：pi 与 hypot 都在这里

r = 2.0                                       # 柱面半径（米）
du = math.pi / 2                              # 角度方向走了四分之一圈（弧度制）
dv = 8.0                                      # 同时向上爬升的高度（米）

horizontal = du                               # ← 问题在这：弧长不是角度本身，先乘半径换成米
straight = math.hypot(horizontal, dv)         # 斜奔方案：解卷后就是一条直角三角形的斜边
ladder = horizontal + dv                      # 折线方案：先横绕完毕、再一口气竖爬的总里程

print(round(straight))
print(round(ladder))
```

修复口径：改成 `horizontal = r * du`，水平真实路程 $\pi \approx 3.14$ 米随之归位。修好后两行输出 9 与 11——斜奔约 8.59 米完胜折线的 11.14 米。顺手检验：把 dv 缩成 0，斜奔就退化成例二的绕柱纬线，答案回到底 $\pi\times r=3.14$ 米的老答案。

## 7. 边界与适用条件

- 定义里"$k_g=0$"说的每一点都是局部判断；一根测地线整体可以拐出很远（大圆绕球一周）而不违背任何局部承诺。
- 两点之间测地线可能不止一条，长度也可能不同（对跖点的经线家族）；谈"最短"必须限定范围。
- 本课全部实验建立在常曲率经典曲面（球、柱、平面）上；一般曲面上数值差分照样能跑，但解析对照公式如 $\tan\varphi$ 不再可用。
- 差分精度依赖样本密度 N 与浮点舍入，打印结果在小数末位可能抖动 —— 数量级与趋势才是读数重点。
- Christoffel 符号版本（选读栏）只在光滑度规下成立；折痕、尖角处测地方程失效，现实中的"最直"改由变分不等式接管，超出本章范围。

## 8. 选读：测地方程与内蕴出身

<details>
<summary>选读 · Christoffel 符号把球面的脾气写进方程</summary>

在坐标 $(u,v)$ 下，测地线满足二阶方程组

$$\ddot u^k + \Gamma^k_{ij}\, \dot u^i \dot u^j = 0$$

其中 Christoffel 符号 $\Gamma$ 完全由第一基本形式 $E,F,G$ 及其一阶导数拼装而成——零件清单里没有任何第三维的信息。这说明测地线与高斯曲率同宗同源，都是**内蕴量**：住在曲面里的二维生物拿着自己的尺子就能预言哪条路会"自然滚落"、哪条会拐弯。第 22 章[相图与线性化](../22-ode-dynamics/40-phase-portraits.md)的阅读经验再次上线：这是双分量二阶自治系统，初条件 $(u,v,\dot u,\dot v)$ 四个数一钉，轨道唯一确定。推导细节留待泛函分析的变分法视角，此处记住结论即可。

</details>
