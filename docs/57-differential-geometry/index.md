## 实战挑战 · 拼幅布料的分段丈量

**背景**。第 30 课那位在平面地图上量布料的老裁缝又接到一单活：一幅装饰布由左右两块拼成，共用同一张图纸 $(u,v)$，接缝恰好压在 $u=2$ 处。两幅布纬向脾气不同：左幅织得密，图纸上一格参数对应布面真实走出 $2$ 厘米；右幅织得疏，同样一格对应 $4$ 厘米。经向（$v$ 方向）则处处均匀，一格就是 $1$ 厘米。翻译成第一基本形式：整幅布上 $F=0$、$G=1$，而 $E$ 必须随位置查表——左幅 $E=2^2=4$，右幅 $E=4^2=16$。

**题目**。缝纫机要在布面上试走三条互相独立的装饰线：

- **甲线**：左幅内横移 $2$ 格参数，从 $(0,\ 0.5)$ 到 $(2,\ 0.5)$；
- **乙线**：右幅内横移 $2$ 格参数，从 $(2,\ 0.5)$ 到 $(4,\ 0.5)$；
- **丙线**：右幅内斜跨，从 $(2,\ 1)$ 到 $(4,\ 2)$——$u$ 进 $2$ 格、$v$ 进 $1$ 格。

请用 $ds^2 = E\,du^2 + G\,dv^2$ 分别算出三条线的真实长度（单位 cm），并求出三条全走一遍的总针脚长度。程序已经开工，但带着本课点过名的两个老毛病：**一把尺子用到底**、**斜着走忘了纵向的路费**。把它修到四行检查全部通过——顺手也验证了：只要量尺选对，曲线弧长这笔账怎么算都闭合。

```exercise
# @title: 实战挑战：给拼幅布料换对量尺
# @check: 4.0
# @check: 8.0
# @check: 8.1
# @check: 20.1
# @hint: 量尺跟着位置换档——过接缝前后 sqrt(E) 一个是 2、一个是 4；丙线要用完整的 ds² = E·du² + G·dv² 再开方。
import math                                        # 标准库 math：开平方交给 math.sqrt

def zone_E(u):                                     # def 自定义函数：报到坐标 u 处该用哪把量尺系数 E
    if u < 2.0:                                    # if 条件分支：接缝之前归左幅管
        return 4.0                                 # 左幅织得密：一格参数＝2 厘米，故 E = 2² = 4
    return 16.0                                    # 右幅织得疏：一格参数＝4 厘米，故 E = 4² = 16

E_used = zone_E(0.0)                               # ← 坑 1 在这：开工时抓了一把 E 就想全程通用——可 E 是逐点变化的

seg1 = math.sqrt(E_used) * 2.0                     # 甲线：横向匀步，ds = sqrt(E)·du
print(f"{seg1:.1f}")                               # f-string 里 {x:.1f} 表示保留 1 位小数

seg2 = math.sqrt(E_used) * 2.0                     # 乙线同样栽在坑 1 上：人已站进右幅，手里还攥着左幅的旧尺

du = 2.0                                           # 丙线的 u 方向参数增量
dv = 1.0                                           # 丙线的 v 方向参数增量
seg3 = math.sqrt(E_used) * du                      # ← 坑 2 在这：把丙线当成纯横移；斜着走时 v 方向也在消耗布料（ds² = E·du² + G·dv²）

total = seg1 + seg2 + seg3                         # 总针脚长度＝三条线连加
print(f"{seg2:.1f}")
print(f"{seg3:.1f}")
print(f"{total:.1f}")
```

<details>
<summary>点开查看逐步解答</summary>

**第一步 · 坑 1 的病理：$E,F,G$ 是逐点变化的。** 本课误区卡片第一条点名过的老毛病——三件套不是常数，而是"每点一套"的当地法规。程序一开工就把出发点的 $E=4$ 锁死成全局常量：前半段纯属侥幸正确（左幅本来就一路 $E=4$），一过接缝全线失真。处方很朴素：每条线各自在所在幅区现场查表，$\sqrt{E}$ 该是 $2$ 就是 $2$、该是 $4$ 就是 $4$。

**第二步 · 横向两条线分别求解。**

- 甲线全程在左幅：$ds=\sqrt{E}\,du=2\,du$，横移 $2$ 格参数，实长 $2\times2=4$ cm；
- 乙线全程在右幅：$ds=\sqrt{16}\,du=4\,du$，同样 $2$ 格参数，实长 $2\times4=8$ cm。

同一格参数、两种真实长度——旧尺会把乙线也报成 $4$ cm，整片右幅被低估一半。这就是"第一基本形式随身带尺"最直观的兑现。

**第三步 · 坑 2 的病理：斜着走时两个旋钮都在付路费。** 丙线上每个微小位移同时含 $du$ 与 $dv$，其长度平方由本课核心公式给出：

$$ds^2 = E\,du^2 + G\,dv^2$$

好在这段路始终留在右幅内部，沿途 $E=16$ 恒定，把增量整体代进去再开方即可：$\sqrt{16\times2^2+1\times1^2}=\sqrt{65}\approx8.06$ cm。初始代码的 $\sqrt{E}\cdot du$ 把它当成了纯横移，纵向那 $1$ 格的里程凭空蒸发——公式里少一个平方项，答数就差出一大截。

**第四步 · 验证与汇总。** 总长 $=4+8+\sqrt{65}=20.06\ldots\to20.1$ cm。想亲手复核第三步这个闭式解？把丙线切成一百个等分小步、逐段累加 $\sqrt{16\,\Delta u^2+\Delta v^2}$，数值和会收敛到同一个数——"$ds^2$ 只是微小位移的长度平方，曲线弧长靠积分攒出来"这句话由此得到一次实测。

参考答案（运行输出恰为 @check 四行）：

```python
import math

def zone_E(u):
    if u < 2.0:                          # 接缝之前是左幅
        return 4.0                       # 织得密：sqrt(E) = 2 厘米/格
    return 16.0                          # 织得疏：sqrt(E) = 4 厘米/格

seg1 = math.sqrt(zone_E(0.0)) * 2.0       # 甲线全在左幅：直接乘步数
seg2 = math.sqrt(zone_E(2.0)) * 2.0       # 乙线过缝换尺：√16 = 4 登场
du, dv = 2.0, 1.0                         # 丙线的两个参数增量（一行赋两个变量）
seg3 = math.sqrt(zone_E(3.0) * du * du + 1.0 * dv * dv)   # 完整 ds² = E·du² + G·dv²，G 处处为 1
total = seg1 + seg2 + seg3                # 三条线逐一累加

print(f"{seg1:.1f}")
print(f"{seg2:.1f}")
print(f"{seg3:.1f}")
print(f"{total:.1f}")
```

</details>

## 实战挑战 · 圆的曲率 = 1/r

圆的曲率是半径的倒数：$\kappa = \frac1r$。半径越大，圆越"平"。半径 $r=2$ 的圆，曲率是 $0.5$。下面这题把曲率算成了 $\frac1{r^2}$，修到输出 `0.5`：

```exercise
# @title: 实战挑战：圆的曲率 = 1/r
# @check: 0.5
# @hint: 曲率是 1/r，不是 1/r²。
r = 2.0
kappa = 1 / (r * r)    # ← 问题在这：曲率是 1/r
print(kappa)
```

<details>
<summary>点开查看逐步解答</summary>

圆的曲率等于半径的倒数：

```python
kappa = 1 / r    # 1 / 2
print(kappa)     # 0.5
```

改完：$\kappa = \frac{1}{2} = 0.5$。初始代码 $\frac1{r^2} = 0.25$ 是高斯曲率的量纲（曲率×曲率）。半径 $2$ 的圆每走单位弧长方向转过 $0.5$ 弧度；半径 $4$ 则只有 $0.25$——圆越大越"直"。这条 $\kappa=\frac1r$ 是微分几何"曲率"概念的第一块基石。

</details>
