# Riemann 度量与流形直觉

## 1. 从一个场景开始

出国旅行要换插头、换币种、换比例尺——同一件行李，每过一国就得重新校准一遍说明书。地球更是个天生捣蛋鬼：任何一个想把整颗星球画到一张纸上的制图师都注定失败，墨卡托吹胀了极地，等积投影扭歪了形状。

Riemann 在 1854 年的演讲里给出的解决方案豪迈极了：既然做不到"一张纸走天下"，那就干脆承认**几何本身就是许多页局部说明书的合订本**——每页有自己的坐标（自己的尺子），页与页之间备好换算表。"距离"不再由外部空间恩赐，而是这台合订本的本地法规。

## 2. 直觉解释

第一基本形式早已剧透过主线：曲面每点自带三件套 $E,F,G$。现在把镜头拉远一步——

**尺子长在每个点上都可以不一样。** 走同样一格参数位移 $(du,dv)$：

- 在赤道附近的球面上是一条长路；
- 在南极点附近拧经度旋钮等于原地打转；
- 在歪纹布面上横竖两步还会互相搭桥（$F\neq0$）。

把这些观察升格成一条法令：给每个点发一台测量机器 $g(p)$，它吃进两个方向，吐出它们的内积。有了它，长度、角度、面积全部就地结算——**不需要问这张曲面被摆放在哪个更高维的房间里**。

三系数的展开式你其实背过了（第 30 课的 $ds^2=E\,du^2+2F\,du\,dv+G\,dv^2$），如今换个更威风的名字：

$$ds^2 = g_{11}\,du^2 + 2\,g_{12}\,du\,dv + g_{22}\,dv^2$$

对称性 $g_{12}=g_{21}$ 保证机器老实：先横后竖与先竖后横耗路相同。这套语言妙在无上限：三维、四维时空照抄公式加索引就行——收官课的广义相对论段落全靠它开场。

## 3. 正式定义

| 符号/术语 | 名字 | 含义 |
| --- | --- | --- |
| $g(p)$ | **Riemann 度量** | 点 p 处光滑变化的正定二次型：吃两个切向量，吐内积 |
| $\left(M,\ g\right)$ | Riemann 流形 | 一个可以用图册覆盖的点集 M，配上一副度量 g |
| chart（图）| 一页地图 | 一块足够小的区域 + 一套局部坐标 $(u,v)$ |
| atlas（图册）| 地图集合 | 若干页图拼起来盖住整个 M |
| transition map（过渡函数）| 页边换算表 | 相邻两页重叠区的坐标互译规则，要求处处平滑 |

读法分两层：

1. **流形 = 合订本**："每一点都至少落在一页图里"是唯一的地形要求；至于这个点集有没有被放进某个背景大房间，法律条文不管；
2. **度量 = 印在每页上的比例尺备注**：它在不同点、甚至同一页的不同角落都可以取不同的数值——只要变化连续。物理学家说的度规（英文 metric）就是它。

第 11 章[基与坐标：换一套语言说同一个点](../11-linear-algebra/40-basis.md)的经验在此复用：换基不换向量本身；换图不换地形本身。坐标系是页面排版，不是事实。

## 4. 分步例题

**例一（两套账本数同一段路）**：平面换成极坐标后勾股写作 $ds^2 = dr^2 + r^2\,d\theta^2$——原点附近还挺温和，半径越大横向步子越贵（转一度角要走更多米）。

1. 沿正东射线从半径 1 走到 2：逐格累加得 $dr$ 总和 $=1$ 米；
2. 切回直角坐标看同一条线段：就是 x 轴上从 1 到 2 的水平段，长度照样 1 米 ✓；
3. 结论展示的是"记账格式随意、总额唯一"。谁要是嫌切换麻烦直接拿两组端点做平面勾股，下一行马上给他上课。

**例二（天真的端点算法翻车实录）**：沿半径为 2 的圆弧从角度 $0°$ 走到 $30°$：真长 $r\Delta\theta = \pi/3 \approx 1.047$ 米。可这条弧在直角坐标里压根不是坐标直线，两端点是 $(2,\,0)$ 与 $(\sqrt3,\,1)$——端点连线只有约 1.035 米，凭空少付了将近 1.2 个百分点。位移端点买不到路程，只有沿途每点的本地尺子才能结清这笔账：这正是度量存在感的最低消费证明。

**例三（球面本来就装配齐全）**：把单位球的东、西两半球各设一页图（经纬度坐标），在 180° 经线接缝处互译经度符号即完成过渡；配上度量 $ds^2 = d\phi^2 + \sin^2\phi\,d\lambda^2$（第 30 课实测）之后，这本册子就是一个完完整整的 Riemann 流形——尽管谁都清楚它还优雅地嵌在我们的三维展厅里。**嵌入只是福利，不是必需**。

## 5. 动手实验

### 实验 1（viz）：把度量当二次型看一眼

$g(p)$ 是台吃方向吐内积的机器，它的"功率分布"画成正定二次型就是一个倾斜拉伸的椭圆——长短轴对应最省/最费的两个行走方向，倾角来自交叉项：

```viz
{
  "type": "quadratic-form",
  "matrix": [
    4,
    1,
    1,
    1
  ]
}
```

这副样品对应 $E=4,\ F=1,\ G=1$ 的歪尺：横向省力四倍，且横竖两向互相歪着（椭圆轴不与坐标轴重合）。第 21 章讲正定性时画过的正是同一种椭圆——只不过那里描述能量与距离，这里描述"行走的开销"。

### 实验 2（plot）：双曲平面的尺子缩水曲线

Riemann 自己的开山样本之一：上半平面模型 $ds^2 = \dfrac{du^2 + dv^2}{v^2}$——离边界越近，同样的参数格子代表越短的真实路。横向尺子的缩水因子恰是 $1/v$：

```viz
{
  "type": "plot",
  "title": "上半平面的本地尺子：缩水因子 1/v",
  "expr": "1/x",
  "xmin": 0.5,
  "xmax": 5,
  "sliders": []
}
```

曲线无限逼近零却永不触底——"贴着边界走的每一格都便宜到近乎免费"，这是负曲率宇宙发给旅行者的补贴。

### 实验 3（python 滑块）：在同一张地图上量两次

```python title="高度不同，尺价不同"
# sliders: y0=1 [0.2:4:0.2]
import math                                  # 标准库 math：开平方交给 sqrt

du, dv = 1.0, 1.0                            # 待测位移：横一格、竖一格（参数纸面上看完全一样）

scale = 1 / y0                               # 上半平面的尺价：横纵两个方向都按 1/y 结算
walk_real = scale * math.sqrt(du * du + dv * dv)   # 先按勾股合成参数步长，再乘当地尺价
print("所在高度 =", round(y0, 2))
print("真实长度 =", round(walk_real, 2))

lazy_price = 1.0                             # 老毛病示范：死守出发点的尺价一用到底
print("死用旧尺 =", round(lazy_price * math.sqrt(du * du + dv * dv), 2))
```

拖动滑杆：`y0=4` 时同一格对角线只值约 0.35；滑到 `0.5` 附近暴涨到约 2.83。最后一行把"远处尺价"的死数字硬套过来——离边界越近，它偏离真话越远。地图上的格子永远等大，真实大地却步步议价：这就是度量的存在感。

### 快问快答

```quiz
关于把地球装订成一本"地图册"，下面哪句是对的？
- 只要接受足够的扭曲，一张足够大的世界地图就能完美覆盖整个球面
- 至少需要几张互相衔接的图；任何单张平面图都必然留下一个失效点 [*]
- 图册的页数只影响印刷成本，和几何没有任何关系
? 单张连续的参数化总有一处退化：墨卡托图上极点被拉到无穷远，切平面投影则把另一半球挤成一个点。流形的图册制度正是靠多页互译绕开这个死结。
```

:::warning[常见误区]

**误区一**："换了坐标系，$E,F,G$ 数值大变，所以长度也变了。" 变的是账目格式，不变的是总额——例一的 1 米在两套坐标系里如出一辙。判断是否变了实体，永远用过渡函数换算后再比。

**误区二**："流形一定要住在某个高维空间里才谈得上弯曲。" 内蕴账目（度量、曲率、测地线）自给自足；嵌入只是方便外部观众看戏的舞台灯光。上一课的绝好定理已经替内部居民领过工资。

**误区三**："度量就是一张随位置变化的表格，记住了就行。" 它必须连续（理想情形光滑）并且每点处都严格正定——退化或翻转意味着该点的"长度机器"坏了，那里根本不在 Riemann 几何管辖范围。

:::

## 6. 练习

**练习 1**（概念口答）：某地的度量写成 $ds^2 = du^2 + v^2\,dv^2$，当 $v$ 从 0 增大到 3 时，纵向尺子变贵还是变便宜？

<details>
<summary>点开查看逐步解答</summary>

纵向系数是 $v^2$，从 0 涨到 9——同样一格 $dv$ 的真实花费变大，纵向越走越贵。反向读法也成立：越靠近 $v=0$ 这条"免费高速"，纵向里程越便宜，恰与实验 2 的双曲补贴互相呼应。
</details>

**练习 2**（判题）：某织机故障让一块布的左半幅出现了斜纹扭曲，传回的本地度量在采样点是一个歪尺三件套 $E=4,\ F=1,\ G=1$。质检程序开工了，可作者又把交叉项的路费弄丢了。

```exercise
# @title: 练习：歪尺上的位移平方与开口角
# @check: 13
# @check: 60
# @hint: 完整公式是 ds² = E·du² + 2F·du·dv + G·dv²；夹角继承第一基本形式的老配方 cos θ = F / √(EG)。
import math                                   # 标准库 math：acos 反查角、sqrt 开根号

E, F, G = 4, 1, 1                             # 该点的歪尺三件套（整数样例）
du, dv = 2, -1                                # 待测的小位移：横移 2 格、纵向倒退 1 格

ds2 = E * du * du + G * dv * dv               # ← 问题在这：交叉路费 2F·du·dv 凭空蒸发
print(round(ds2))                             # 长度的平方应为整数 13

cos_theta = F / math.sqrt(E * G)              # 两坐标方向夹角的余弦（第 30 课原公式）
theta = math.acos(cos_theta)                  # 反三角登场：从余弦反查角度（第七章的朋友）
print(round(theta * 180 / math.pi))           # 以“度”报出这副本地量角器的开口
```

修复口径：改回完整二次型 `ds2 = E*du*du + 2*F*du*dv + G*dv*dv`。修好后输出 13 与 60——注意交叉项带着负位移来的那一笔 $-4$ 正是把 17 拉回 13 的关键角色：歪尺连倒车都要精确定价，这就是 $F$ 存在的全部意义。

## 7. 边界与适用条件

- 本课只铺二维度量的直观；一般 n 维度量由对称正定矩阵场概括，公式结构完全平行，符号细节留给后续课程。
- 时间允许负号时进入伪黎曼领域（收敛展望课的相对论语言），那已是另一套因果宪法，不要用这里的"正定"直觉硬套。
- 过渡函数的平滑等级（光滑、解析、仅连续）决定能微分的次数；拓扑学档口（第 58 章）会撕开只谈连续的世界。
- 实验 3 的最后一行是有意保留的"错误示范"，它按固定尺价结账，输出本身就是教学道具；正确的对照只有前两行。

## 8. 选读：换页时三件套怎么搬家

<details>
<summary>选读 · 换页时三件套怎么搬家</summary>

设新图坐标 $(u',v')$ 通过平滑映射与旧图相连，Jacobi 记作 $J$（第 20 章的老朋友）。链式法则给出搬家合同：`G' = Jᵀ·G·J`——坐标微分换一次底，度量矩阵就跟着左乘转置、右乘新底各一圈。写成分量虽然吵闹，精神只有一句：**格式万变，事实恒常**。矩阵的对称性与特征值方向在这一路乘法中原封不动（线性代数基变换那一课的连续版）；将来无论把 $E,F,G$ 换成哪套新页面的系数，曲线长度、角度与高斯曲率都会给出同一个数。

</details>
