# Gauss 曲率与绝好定理直觉

## 1. 从一个场景开始

圣诞节前夜你负责包装礼物：卷一筒卫生纸般的圆筒礼盒，一张纸贴上去严丝合缝，纸纹一点没拉伸；换成一个橘子，同样的纸无论怎么摆弄都会起皱、撕裂，或者边缘多出一圈剪不掉的余料。

同样是"弯的"表面，为什么纸能驯服圆筒却驯服不了橘子？答案藏在每一点的一对数字里——**两个主方向各弯多少**。Gauss 把它们的乘积命名为曲面在这一点的高斯曲率，随后证明了一个他自己都忍不住叫"绝好定理"（Theorema Egregium）的事实：这个数只用曲面内部的量尺就能算出，压根不需要抬头看第三维。

## 2. 直觉解释

把曲面想象成一片山地，在每个点上问一句：往哪走、往下陷得多快？

- **山顶附近**：不管朝哪个方向迈步都在下坡——两个主方向同号弯曲。乒乓球壳、鸡蛋壳都是这类，$k_1$ 与 $k_2$ 同正或同负；
- **马鞍面**：顺着马身方向下凹、横跨马背方向上凸——一个主方向朝上弯、另一个朝下弯，$k_1$ 与 $k_2$ 异号；
- **纸面与圆筒侧面**：至少存在一个方向完全笔直（圆筒沿母线方向），$k_1 \cdot k_2 = 0$。

三个方向处境的分水岭就是这个乘积的符号：

$$K = k_1 \cdot k_2$$

- $K > 0$：两方向同弯，山丘或碗；
- $K < 0$：两头翘中间塌，鞍形；三角形内角和会小于 $180°$（第 35 课角盈的另一副手套）;
- $K = 0$：局部摊得平，圆筒与平面在此毫无区别。

住在曲面里的二维生物没有第三只眼，但它拿测角仪绕个小三角形一圈，就能凭内角和的多寡猜出自己站在哪类地形上——这正是上一课角盈留下的伏笔。

## 3. 正式定义

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $k_1, k_2$ | 主曲率 | 过该点两条互相垂直的特殊截线的弯曲程度（单位是长度的倒数）|
| $K = k_1 k_2$ | **高斯曲率** | 两主曲率的乘积，逐点变化 |
| $H = (k_1 + k_2)/2$ | 平均曲率 | 肥皂膜最爱的量，本课点到为止 |
| $\operatorname{II}$ | 第二基本形式 | 携带 $k_1,k_2$ 的那台机器（下一课正课专讲）|

$K > 0$ 时称该点为椭圆点，$K < 0$ 双曲点，$K = 0$ 抛物点或平坦点。

**Theorema Egregium（绝好定理，1827）**：高斯曲率 $K$ 可以写成第一基本形式三件套 $E,F,G$ 及其导数的表达式。换句话说：**只靠曲面内部测量就能算出的量**——哪怕曲面从未被放进三维空间，它的"弯"也写得清清楚楚。

## 4. 分步例题

**例一（圆筒不弯）**：第 30 课量过半径 2 的圆柱面，三件套 $E=4,\ F=0,\ G=1$。

1. 横截线是一个半径 2 的圆，法曲率 $k_1 = 1/2$；
2. 沿母线的竖直截线是一直线，$k_2 = 0$；
3. 于是 $K = 0.5 \times 0 = 0$——纸才能无限顺滑地卷它；
4. 解卷验证：把 $ds^2 = 4\,du^2 + dv^2$ 写成坐标 $x = 2u$ 的平面勾股 $dx^2 + dv^2$，参数换了、长度分毫不差。"看着弯"的印象全被外部第三维承包了。

**例二（球面的常数曲率）**：半径 $R$ 的球面两个主方向都取大圆截线，$k_1 = k_2 = 1/R$，故

$$K = \frac{1}{R^2}$$

用第 35 课的成绩单核对：三直角三角形的角盈 $\varepsilon = \pi/2$、面积 $S = (\pi/2)R^2$，两者之比 $\varepsilon / S = 1/R^2 = K$ ✓。这不是巧合：**小三角形上，角盈密度近似就是高斯曲率**（$\varepsilon \approx K S$），Gauss 本人的验证路线正是如此——下一节的练习请你亲手跑完这笔账。

**例三（包裹失败报告）**：想把纸（$K=0$ 的材质）包上半径 3 的橘子（处处 $K=1/9$），需要纸张各点凭空长出曲率——而绝好定理说曲率是内蕴账目，纯弯不改度规就动不了它。唯一的出路只有褶皱起鼓或剪切拼接，现实中的橘子包装也确实只剩这两招。

### 实验 2（python 滑块）：调系数看分类与乘积

```python title="二次山地：从两个方向的弯曲读出 K"
# sliders: a=1 [-3:3:0.25], b=-1 [-3:3:0.25]
import math                                  # 标准库 math：本块主要做算术

def classify(a, b):                          # def 自定义函数：按 k1*k2 的符号给地形命名
    product = a * b                          # k1*k2 与 a*b 同号（差一个平方因子）
    if product > 0:                          # if 分支：同号为峰或碗
        return "同向弯曲 K 大于零"
    if product < 0:                          # 异号即鞍面
        return "反向翘曲 K 小于零"
    return "存在直行方向 K 等于零"

k1 = 2 * a                                   # z= ax^2+by^2 沿 x 方向的二阶导恰为 2a
k2 = 2 * b                                   # y 方向同理为 2b
print("主方向弯曲 =", round(k1, 2), round(k2, 2))
print("K 近似 =", round(k1 * k2, 2))         # 乘起来就是这一点的 Gauss 曲率代理值
print(classify(a, b))
```

拖动滑杆穿过 0：符号翻转的瞬间正是"从山顶越过垭口变成马鞍"的地貌切换。把 `a` 或 `b` 停在 0，就得到可以解卷的圆筒侧影。

### 快问快答

```quiz
一张纸没有任何拉伸地卷成了圆筒。只能测量内部量的二维生物，能察觉这次卷动吗？
- 能，圆周方向显然变短了
- 不能，卷动从头到尾只是外部第三维的表演 [*]
- 能，因为圆筒出现了一条接缝
? 卷动前后纸上任意两点间的距离、角度全部原封不动——度规纹丝未动。绝好定理保证所有内蕴量（包括高斯曲率 K=0）都不变，所以内部居民与平面宇宙的居民无从分辨。
```

:::warning[常见误区]

**误区一**："圆筒明明是弯的，怎么说它平坦？" 弯与不弯要先约定视角。圆筒的弯是**嵌在空间里的姿势**；内部账目（$E,F,G$ 全套，以及 $K$）与摊平后的纸完全一致。内蕴几何里它就是一块平地。

**误区二**："把坐标改一改，$E,F,G$ 全变了，说明几何变了。" 变的只是记账格式。第 30 课圆柱 $ds^2=4du^2+dv^2$ 里那个 4 是参数穿衣，换坐标后消失；$K$ 与长度、角度这些实体谁也不理睬换装。

**误区三**："正曲率的地方内角和大，所以内角和小一定意味着凹下去。" 鞍面的 $K<0$ 不必靠"凹陷"，只要两主方向异号就够了——它完全可以立在空中没有任何下沉感（比如薯片的中段）。判据永远数的是方向的号，不是上下。

:::

## 6. 练习

**练习 1**（概念口答）：某喇叭花叶片状曲面在一点测得 $k_1 = 3$、$k_2 = -1$（同一单位），这属于哪种地貌？$K$ 和平均曲率各是多少？

<details>
<summary>点开查看逐步解答</summary>

$k_1 k_2 = -3$ 为负 → 双曲点（鞍形地貌）；平均曲率 $H=(3-1)/2=1$。注意 $H$ 在此非零不代表有引力般的整体倾斜——它与 $K$ 各管各的事。
</details>

**练习 2**（判题）：三位勘探员各自报来一份角盈-面积实测记录（单位制统一已处理）， Gauss 的验证路线就是把它们换成曲率。程序开工了，但作者犯了第 35 课点名批评过的老毛病——忘了先换汇。

```exercise
# @title: 练习：先换弧度，再除出 K
# @check: 0.25
# @check: 1.0
# @check: -0.5
# @hint: 度与弧度是两种货币；math.radians 把 90 度换成 π/2 之后再进入公式。
import math                                        # 标准库 math：货币兑换交给 math.radians

def show(excess_deg, area):                        # def：输入角盈（度）与实测面积，回报 K
    excess_rad = excess_deg                        # ← 问题在这：作者把“度”直接当弧度计入了
    return round(excess_rad / area, 2)             # 角盈密度 ＝ 高斯曲率（先修上一行再看这里）

print(show(90, 2 * math.pi))                       # 半径 2 球面上的三直角三角形
print(show(45, math.pi / 4))                       # 单位球面上的迷你款
print(show(-90, math.pi))                          # 某个鞍面宇宙交来的负角盈样本
```

修复口径：把注释标出的一行改成 `excess_rad = math.radians(excess_deg)`。修好后三行输出依次为 0.25、1.0 与 −0.5——第一条正是例二的 $\frac{1}{R^2}$ 实测复核，第三条则演示了双曲点让角盈入不敷出。

## 7. 边界与适用条件

- $K=k_1k_2$ 的严格来历要动用第二基本形式（见选读），本课沿"Gauss 自己的路线"以角盈密度给出可操作直觉；两者在高斯曲率处合流。
- 二次山地代理实验比较的是二阶偏导矩阵的特征方向（你在第 20 章 Hessian 一课见过它），只在图像局部近似主方向截线，不要拿去外推整个曲面。
- 平均曲率 $H$ 不是内蕴量：把它压扁或充气都会改变 $H$ 而 $K$ 不动——肥皂膜的形状选择发生在"外观世界"一侧。
- 绝好定理说 $K$ 可由 $E,F,G$ 算出，没有说任何曲面组合都能在三维里造出来（嵌入问题比它难一级，收官展望课会有接口提示）。

## 8. 选读：第二基本形式一句话

<details>
<summary>选读 · k1、k2 从哪里正式出生</summary>

在切平面上再加一本"高度账"：对曲面上两点的高度差做泰勒展开，二阶项凑成的二次型叫**第二基本形式**，通常记作 $\mathrm{II} = L\,du^2 + 2M\,du\,dv + N\,dv^2$。把它归一化后在切方向上取特征值，得到的两个数就是主曲率 $k_1, k_2$。代入著名的 $K = (LN - M^2)/(EG - F^2)$ 即可产出高斯曲率——不过这条"外部观察者视角"的公式恰恰成为绝好定理的舞台背景：Gauss 接着证明了分子分母里的外部信息会互相抵消，最终表达式只需要第一基本形式。本课程在第 30 课提供的正是一位内部居民的完整装备，此处不再展开。这句"一句话"如今已扩成正课：主曲率的正式出生、法曲率随方向的变化与 $K=(LN-M^2)/(EG-F^2)$ 的完整账本，见[第二基本形式：法向的高度账](./42-second-fundamental-form.md)。

</details>
