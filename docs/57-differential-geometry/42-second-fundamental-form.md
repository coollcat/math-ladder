# 第二基本形式：法向的高度账

## 1. 从一个场景开始

[第一基本形式](./30-first-fundamental-form.md)那位在平面地图上量布料的老裁缝，量的是"贴着表面走了多远"；光学车间的质检员关心的却是另一件事：非球面镜磨完之后，表面相对理想形状**沿法向鼓起或下陷了几纳米**——干涉条纹数一圈，高度账直接读出来。同一张参数网格，两本账：贴着面的长度账（第一基本形式），沿法向的高度账（本课主角）。

上一课（Gauss 曲率与绝好定理）还留了一笔债：$K = k_1 k_2$ 说得头头是道，可 $k_1, k_2$ 这两个主曲率究竟是从哪台机器里"正式出生"的？答案就是这本高度账——第二基本形式。

## 2. 直觉解释

曲面上邻近两点 $P(u,v)$ 与 $P(u+du, v+dv)$ 的位移，一阶主部躺在切平面里（第 30 课的 $d\vec P = \vec r_u\, du + \vec r_v\, dv$）；但完整的展开还有二阶项——位移不只是平着走，还会"翘起来"。把这段二阶主部投影到单位法向量 $\vec n$ 上（记账惯例丢掉系数 1/2），得到三个数：

$$L = \vec r_{uu}\cdot\vec n, \qquad M = \vec r_{uv}\cdot\vec n, \qquad N = \vec r_{vv}\cdot\vec n$$

- $L$：顺着 $u$ 方向走，表面朝法向"弯上去"的加速度；
- $N$：$v$ 方向的同类账目；
- $M$：两股方向的"拧劲"——互相扭曲的交叉账。

三件套拼成的二次型就是**第二基本形式**：

$$\mathrm{II} = L\,du^2 + 2M\,du\,dv + N\,dv^2$$

几何读法：给一个切方向 $(du, dv)$，II 读出"沿这个方向，表面朝法向弯多少"——它是法向截线弯曲程度（**法曲率**）的分子。第一基本形式 I 管分母（长度），II 管分子（高度），两本账一相除就得到该方向的法曲率。方向一变，比值就变——法曲率是个"看方向下菜"的量。

主曲率与主方向就在这里出生：把 II 相对 I 归一化（广义特征值问题），两个特征值就是 $k_1, k_2$，特征方向就是主方向。第 20 章 Hessian 一课里"二阶偏导矩阵的特征方向定地貌"的那套戏，在这里原班重演——只是矩阵换成了两本账的组合。

## 3. 正式定义

设曲面 $\vec r(u,v)$，单位法向量 $\vec n = \dfrac{\vec r_u \times \vec r_v}{\lVert \vec r_u \times \vec r_v \rVert}$（取定一个朝向后不再翻转）：

$$\mathrm{II} = L\,du^2 + 2M\,du\,dv + N\,dv^2, \qquad L = \vec r_{uu}\cdot\vec n,\ \ M = \vec r_{uv}\cdot\vec n,\ \ N = \vec r_{vv}\cdot\vec n$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\mathrm{I} = E\,du^2 + 2F\,du\,dv + G\,dv^2$ | 第一基本形式 | 长度账（内蕴，第 30 课的老朋友） |
| $\mathrm{II}$ | 第二基本形式 | 高度账（外蕴：要借第三只眼看法向） |
| $k_n = \dfrac{\mathrm{II}(X, X)}{\mathrm{I}(X, X)}$ | 法曲率 | 切方向 $X$ 上"高度账 ÷ 长度账" |
| $S$ | 形状算子 | $k_n = \dfrac{\mathrm{II}(X,X)}{\mathrm{I}(X,X)}$ 背后的线性机器（选读栏开箱） |
| $\theta$ | 方向角 | 相对第一主方向转过的角度 |

**Euler 公式**：在主方向坐标系里 II 已对角化成 $k_1 w_1^2 + k_2 w_2^2$，代入单位方向 $(\cos\theta, \sin\theta)$ 即得

$$k_n(\theta) = k_1 \cos^2\theta + k_2 \sin^2\theta$$

**两条生日公式**（$k_1, k_2$ 的正式出生地）：

$$K = k_1 k_2 = \frac{LN - M^2}{EG - F^2}, \qquad H = \frac{k_1 + k_2}{2} = \frac{EN - 2FM + GL}{2(EG - F^2)}$$

## 4. 分步例题

**例一（球面：一页完整账本）**：半径 $R$ 的球面 $\vec r(\phi, \theta) = R(\sin\phi\cos\theta,\ \sin\phi\sin\theta,\ \cos\phi)$，法向取指向球心的 $-\vec p/R$（想让球面读出正曲率）。

1. 长度账（第 30 课量过）：$E = R^2$，$F = 0$，$G = R^2 \sin^2\phi$；
2. 高度账：$\vec r_{\phi\phi} = -\vec p$，与 $\vec n = -\vec p/R$ 点积得 $L = R$；同理 $N = R\sin^2\phi$，交叉项 $M = 0$；
3. 于是 $\mathrm{II} = R\,d\phi^2 + R\sin^2\phi\, d\theta^2 = \frac{1}{R}\,\mathrm{I}$——球面的高度账恰好是长度账的 $1/R$ 倍，任何方向的法曲率都是 $1/R$ ✓；
4. 生日公式：$K = \dfrac{LN - M^2}{EG - F^2} = \dfrac{R^2\sin^2\phi}{R^4\sin^2\phi} = \dfrac{1}{R^2}$——与上一课用角盈密度算出的完全一致，欠下的那页出生证明就此补齐 ✓。顺带 $H = \dfrac{EN + GL}{2(EG-F^2)} = \dfrac{1}{R}$。

**例二（圆柱面：一条直方向）**：第 30 课量过的 $\vec r(u,v) = (2\cos u,\ 2\sin u,\ v)$，法向取指向轴心：$L = 2$（圆周方向弯向轴心），$M = 0$，$N = 0$（母线方向是直线，高度账零）。于是 $k_n(\text{圆周}) = L/E = 2/4 = 1/2$、$k_n(\text{母线}) = 0$——上一课的 $k_1 = 1/2,\ k_2 = 0$ 正式出炉；$K = (2\times 0 - 0)/(4\times 1) = 0$，"纸能卷圆筒"的原因写进了账本。

**例三（Euler 公式的数字体检）**：椭圆抛物面 $z = x^2 + y^2/4$ 的顶点处 $k_1 = 2$、$k_2 = 0.5$（两个主方向恰是 $x$ 轴与 $y$ 轴）。按 Euler 公式：

$$k_n(0°) = 2, \qquad k_n(45°) = 2\times\tfrac{1}{2} + 0.5\times\tfrac{1}{2} = 1.25, \qquad k_n(90°) = 0.5$$

两个彩蛋：$k_n(45°) = 1.25$ 恰好等于平均曲率 $H = (2+0.5)/2$——45° 时 $\cos^2\theta = \sin^2\theta = 1/2$，两个主曲率各摊一半；再算 $k_n(30°) = 1.625$、$k_n(120°) = 0.875$，两者之和仍是 $2.5$——任何一对互相垂直的方向都把 $k_1 + k_2$ 平分，Euler 公式的隐藏对称性。

### 实验 2（python）：马鞍面原点的两本账对质

曲面 $z = x^2 - y^2$ 在原点处两本账都是最简形态，直接代生日公式，再把每个方向的法曲率读一遍：

```python title="马鞍面原点：两本账算出 K 与 H"
import math

# 曲面 r(x, y) = (x, y, x^2 - y^2)，原点处 r_x=(1,0,0)、r_y=(0,1,0)，法向 n=(0,0,1)
E = 1.0                          # 长度账：r_x 与自己点积
F = 0.0                          # 长度账：两方向正交
G = 1.0
L = 2.0                          # 高度账：r_xx·n = 2（x 方向朝上弯）
M = 0.0                          # 高度账：r_xy·n = 0
N = -2.0                         # 高度账：r_yy·n = -2（y 方向朝下弯）

K = (L * N - M * M) / (E * G - F * F)     # 生日公式：高斯曲率
H = (E * N - 2 * F * M + G * L) / (2 * (E * G - F * F))
print("K =", K, "；H =", H)

for deg in [0, 30, 45, 60, 90]:           # 逐个方向读法曲率价目表
    th = math.radians(deg)                # 角度转弧度
    kn = L * math.cos(th) ** 2 + N * math.sin(th) ** 2
    print(deg, "度方向 k_n =", round(kn, 4))
```

$K = (2\times(-2) - 0)/1 = -4$：一凸一凹乘出负号，马鞍面坐实双曲点；法曲率从 2 一路摆到 −2，45° 方向恰好为 0（渐近方向——顺着它走，表面不朝法向弯）。上一课用二次山地代理教具读出的同一批结论，这里全由正规军复算了一遍。

### 实验 3（python）：球面账本复核上一课的 0.25

上一课练习里你算过：半径 2 的球面上，三直角三角形的角盈密度是 0.25。现在用生日公式从两本账正式推一遍：

```python title="球面：K = (LN - M^2)/(EG - F^2) 实算"
import math

R = 2.0                       # 球面半径
phi = math.pi / 4             # 极角取 45 度

E = R * R                     # 长度账：经向（第 30 课量过）
G = R * R * math.sin(phi) ** 2  # 长度账：纬向缩水因子
F = 0.0
L = R                         # 高度账：r_φφ·n（n 指向球心）
M = 0.0
N = R * math.sin(phi) ** 2    # 高度账：纬向弯得越靠极点越松

K = (L * N - M * M) / (E * G - F * F)
print("K =", round(K, 4), "；对照 1/R^2 =", round(1 / (R * R), 4))
```

两行都是 $0.25$——角盈密度的经验值，从此有了"出生证明"级别的来源。

### 快问快答

```quiz
把曲面的法向量 n 换成相反方向后，下列哪个量一定会跟着变号？
- 高斯曲率 K
- 第一基本形式 I 的三个系数
- 平均曲率 H [*]
? 法向翻转把 II 的三个系数全体变号，于是 k_n 与 H 跟着变号；但 K = k1k2 翻两次不动，I 根本不依赖法向。讨论高度账的符号前，先声明法向朝哪。
```

::::warning[常见误区]

**误区一**："你以为 II 只是 I 的补充说明。" 两本账分工明确：I 管"多长、多大面积"（内蕴，二维居民可测），II 管"朝法向弯多少"（外蕴，要借第三只眼）。没有 II，$k_1, k_2$ 的出生证明就缺了原件——上一课只能借角盈密度迂回。

**误区二**："你以为 II 的符号是曲面的固有属性。" 法向一翻，$L, M, N$、$k_n$、$H$ 全体变号。固有的是"差一个整体符号"这件事本身：$K$ 与 $\mathrm{I}$ 才是翻不动的硬通货。

**误区三**："你以为法曲率 $k_n$ 是这一点的户口。" 它依赖方向（和法向选择）；真正属于"这一点"的是两个主曲率及其特征方向。Euler 公式就是"方向 → 法曲率"的价目表：价目随方向变，底价（$k_1, k_2$）不变。

::::

## 6. 练习

**练习 1**（概念口答）：薯片状曲面上一点测得 $k_n(0°) = 3$、$k_n(90°) = -1$。该点的 $K$ 与 $H$ 各是多少？属于哪类地貌？

<details>
<summary>点开查看逐步解答</summary>

主方向上法曲率取到极值，故 $k_1 = 3$、$k_2 = -1$。于是 $K = 3\times(-1) = -3 < 0$：双曲点，鞍形地貌；$H = (3-1)/2 = 1$。注意 $H > 0$ 与"凹陷感"无关——判地貌只看两个主曲率的号（即 $K$ 的符号），这是上一课立过的规矩。
</details>

**练习 2**（判题）：生日公式 $K = \frac{LN - M^2}{EG - F^2}$ 是主曲率的正式出生地。现在它能跑，但两个平方项都抄丢了——交叉账和歪斜账没扣：

```exercise
# @title: 练习：把高斯曲率的出生公式修对
# @check: -1.0
# @check: 3.0
# @hint: 完整公式是 (L*N - M*M) / (E*G - F*F)：分子的 M² 与分母的 F² 是两笔必扣的账。
def gauss_K(L, M, N, E, F, G):
    return L * N / (E * G)        # ← 问题在这：分子的 M² 和分母的 F² 都不见了

print(round(gauss_K(0.0, 1.0, 0.0, 1.0, 0.0, 1.0), 2))    # 曲面 z = xy 在原点：只有交叉账 M = 1
print(round(gauss_K(2.0, 1.0, 2.0, 1.0, 0.0, 1.0), 2))    # 曲面 z = x^2 + y^2 + xy 在原点
```

第一行是纯扭曲面 $z = xy$：$L = N = 0$ 但 $M = 1$，正确答案 $(0 - 1)/1 = -1$——不扣 $M^2$ 会把鞍点错报成平点；第二行是斜放的椭圆抛物面，$M^2$ 一扣才从 4 掉到 3。两行都是"少扣一笔就错"的活证据。

## 7. 边界与适用条件

- 法向的朝向是高度账的"记账币种"：本课各例取定让球面读正的朝向；翻转法向，$\mathrm{II}$、$k_n$、$H$ 全体变号而 $K$ 不动——跨课对答案前先核对币种。
- $K = (LN - M^2)/(EG - F^2)$ 是"外部观察者"公式；上一课的绝好定理说分子分母里的外蕴信息能互相抵消，最终可写成只含 $E, F, G$ 及其导数的表达式——两条路线在高斯曲率处合流，本课补的正是当初被绕开的那条直路。
- Euler 公式在主方向坐标系下最简；任意方向要用完整的 $k_n = \mathrm{II}/\mathrm{I}$（分子里 $M$、分母里 $F$ 的贡献才不会漏）。本课三个例面的坐标方向恰好都是主方向，公式才显得这么干净。
- 上一课实验 2 的二次山地读出的 $2a, 2b$，正是 $z = ax^2 + by^2$ 在原点的两个主曲率——现在可以说明它为什么对了：图像曲面的高度账在驻点处就是二阶偏导 $f_{xx}, f_{yy}$，与 [Hessian 与局部形状](../20-multivariable-calc/40-hessian-shape.md) 的特征方向戏码同源。

## 8. 选读：形状算子与"积与和"的户口

<details>
<summary>选读 · k1、k2 作为广义特征值的两枚果实</summary>

形状算子 $S$ 把"方向 → 法向的转动速率"装进一台线性机器（Weingarten 映射）：$S(X) = -\nabla_X \vec n$——沿 $X$ 方向挪动时法向怎么倒。它与两本账的关系是 $\mathrm{II}(X, Y) = \mathrm{I}(S(X), Y)$：高度账其实是"长度账复合形状算子"。于是主曲率是广义特征值问题 $\det(\mathrm{II} - k\,\mathrm{I}) = 0$ 的两根：把行列式展开成 $k$ 的二次式，两根之积 = 常数项 ÷ 首项系数 $= (LN - M^2)/(EG - F^2) = K$，两根之和 $= (EN + GL - 2FM)/(EG - F^2) = 2H$——高斯曲率与平均曲率作为"积与和"自动掉出来，一分力气不用多花。Gauss 绝好定理的最后一块舞台背景也在这里：这台机器是外蕴的，但它吐出的 $K$ 意外地只需要内蕴零件。
</details>
