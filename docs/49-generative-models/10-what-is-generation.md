# 什么是生成模型

## 1. 从一个场景开始

同一个 AI 实验室里住着两个模型。甲是"鉴定师"：给它一张图片，它回答"猫的概率 0.97"。乙是"画师"：给它一个随机种子，它吐出一张从没人拍过的猫。

鉴定师学的是**边界**——在数据空间里画一条线，把猫和狗分开；画师学到的是**分布**——猫的照片们挤在空间的哪个区域、那个区域有多"稠密"。深度学习文献里有个著名的比喻：鉴定师像验钞的银行柜员，见多了自然知道假钞哪里不对劲；而真正厉害的造假者，必须亲手掌握钞票本身的构造。**生成模型要当的就是后者：不只认得数据，还要能造出以假乱真的新样本。**

## 2. 直觉解释

把"学会世界"拆成两个层次：

- **判别**（第 45 章监督学习的路线）：给定输入猜标签，$p(y \mid x)$。它只需要在类别之间画界线，不必知道数据本身长什么样；
- **生成**：建模数据自己的概率分布 $p(x)$——哪些像素组合常见、哪些罕见，然后从中**抽样**，产出新的 $x$。

按"你手里有什么"给生成模型发证，可以分三档：

| 能力 | 名字 | 形象说法 |
| --- | --- | --- |
| 能写出密度公式/概率表 | 显式密度 | 手里有一张完整的"人口普查表" |
| 能算出指定点的密度值 | 归一化显式 | 表查得到具体数值 |
| 只会抽样本，说不出密度值 | 隐式密度 | 只会表演抽奖，讲不清中奖率 |

自回归语言模型逐字写概率表；VAE 与扩散模型带一点变通地写；GAN 则干脆放弃写表、纯靠采样表演。家族不同，考题相同：**你抽出的新样本，看起来像不像真数据？**

## 3. 正式定义

**目标**：真实数据服从未知分布 $p_{\text{data}}(x)$。生成模型寻找参数化分布 $p_\theta(x)$（$\theta$ 是可学习参数），使得 $p_\theta \approx p_{\text{data}}$。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $p_{\text{data}}(x)$ | 真实分布 | 数据生成世界的"真相"，永远只能间接观察 |
| $p_\theta(x)$ | 模型分布 | 我们能调节的近似品 |
| $\theta$ | 参数 | 模型里的全部可调旋钮 |

衡量"接近"用第 40 章的语言：最小化 KL 散度或其亲戚交叉熵——这一句话统摄了后面几课几乎所有训练目标的灵魂。

**合法性检查**：一个离散分布要成立，所有概率必须非负且总和恰为 1；连续密度的全空间积分必须为 1（归一化条件）。这不是形式主义——归一化失败意味着"人口普查表"加起来不是全世界的人，后续一切计算都会歪。

## 4. 分步例题

**例**：某小城天气的显式密度表如下：晴 $0.5$、阴 $0.3$、雨 $0.15$、雪 $0.05$。

1. 合法性体检：四项非负 ✓，总和 $0.5+0.3+0.15+0.05=1$ ✓——这是一张合法的普查表；
2. 查询任意事件：$P(\text{不下雨}) = 1 - 0.15 = 0.85$；
3. 计算它的熵（第 40 章工具）：约 $1.65$ 比特——这张表的"不确定度总账"；
4. 若换成只会采样的隐式模型：它能按比例抽出"晴晴阴雪晴……"，但你问它"$P(\text{雪})$ 是多少"，它耸肩。**两档能力的分水岭就在这里。**

连续情形同构：身高直方图平滑化后就是一条密度曲线（下一实验亲手画），曲线下总面积为 1，"某区间面积"就是落在该区间的概率。

### 实验 2（python）：从 20 个样本看"数据的形状"

```python title="直方图：数据的粗略普查表"
import matplotlib.pyplot as plt

heights = [152, 155, 157, 158, 160, 160, 161, 162, 163, 165,
           165, 166, 168, 168, 170, 171, 173, 175, 178, 181]

total = 0
for h in heights:          # 先算均值，给直方图立个参照
    total = total + h
mean = total / len(heights)
print(f"平均身高 {round(mean, 1)} cm")

plt.hist(heights, bins=[150, 156, 162, 168, 174, 180], edgecolor="black")
# bins 直接给出分组边界：每一根柱子是一个"概率桶"
plt.axvline(mean, color="tomato", linestyle="--")   # 均值参考线
plt.xlabel("height (cm)")
plt.ylabel("count")
```

柱子的轮廓就是对真实分布的一次粗糙侦察。生成模型做的事，本质上是把这条轮廓学得足够好，好到能从里面"重新抽一个人"而不穿帮。

### 快问快答

```quiz
一个隐式生成模型（如 GAN）通常做不到下列哪件事？
- 生成看起来逼真的新样本
- 给出某个具体点的概率密度数值 [*]
- 从中抽样无数个样本
? 隐式模型只有"采样器"没有"密度表"。想要密度值需要额外的估计技巧，这正是显式与隐式家族的分界线。
```

:::warning[常见误区]

**误区一**："你以为判别模型好就能生成好。" 鉴定钞票的眼力再毒，也不等于掌握了印钞工艺——两者需要的知识有重叠但远不等价。反之亦然。

**误区二**："你以为密度高的地方一定出现样本。" 密度只谈可能性大小；单次抽样完全可以落在低密度区。别拿一次生成的成败评判整个模型。

**误区三**："你以为生成模型的目标是'记住'训练数据。" 背下训练集只是复读机（过拟合，第 41 章）；目标是学会分布，从而产出**从未见过却同样合理**的新样本。"像训练集"和"来自同一分布"是两回事。

:::

```exercise
# @check: 1.0
# @check: 0.05
# @hint: 四项之和必须是 1。现在多出了 0.05——从最大的那项上削掉最合理。

total = 0
for key in probs:              # 遍历字典：依次取出每个键
    total = total + probs[key]

print(round(total, 2))
print(probs["雪"])             # 修好后这一行应输出 0.05
```

**练习 2**：判断三句话各属于哪一档能力：（a）"这个模型告诉我这句话下一个字是'猫'的概率是 0.02"；（b）"这个模型给我看了十张它画的猫"；（c）"我能对任意一张图查询它在模型下的负对数概率"。

<details>
<summary>点开查看逐步解答</summary>

（a）（c）都是显式档：能输出具体点的（对数）概率值；（b）是隐式档：只见样本不见密度。注意（a）说的是"某个具体续写的条件概率"，属于显式能力；很多现代语言模型恰好属于这一档——它们逐词给出完整条件分布，因此既能采样也能算似然。能力档位决定下游用途：要算困惑度、做蒸馏、控风险，就得选显式家族。
</details>

## 7. 选读：为什么"写出密度"这么难

<details>
<summary>选读 · 归一化常数与高维积分之墙</summary>

给图像建密度，朴素写法是 $p_\theta(x) = \frac{\tilde p_\theta(x)}{Z_\theta}$，其中 $\tilde p_\theta(x)$ 是一个随手可算的"打分函数"，$Z_\theta = \int \tilde p_\theta(x)\,dx$ 是让总和恰为 1 的**配分函数**。麻烦在于：图像空间维度是几十万，这个积分没有解析解，数值积分也算不动——这就是著名的"归一化常数之墙"。

各大家族本质上是对这堵墙的不同绕法：自回归模型用链式法则把联合密度拆成一串条件概率，每一步都自动归一化；VAE 用一个易处理的隐变量分布近似后验，代价是多出一项需要近似的下界（ELBO）；扩散模型把"一步建模"拆成上千个微小的高斯去噪步骤，每步都简单；GAN 则宣布不玩了——直接学采样器，彻底绕开密度。本章后续课程将逐一展开其中两条主线：极大似然的直觉，以及扩散去噪的几何。

</details>
