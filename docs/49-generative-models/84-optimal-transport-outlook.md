# 最优传输与分布匹配展望

## 1. 从一个场景开始

高铁修到一半，前方路基填方缺 $4$ 万方土，恰好后方挖方路段多出同样体积。工程指挥部面对的不是"要不要运"，而是**怎么运**：哪一段的土配给哪一个缺口，才让吨公里总数最小？

把"挖方的土"换成"一个分布的概率质量"、"缺口"换成"另一个分布想要的质量落点"，你就得到了最优传输（Optimal Transport，OT）：**在所有能把你从 A 分布搬到 B 分布的方案里，挑出总运费最低的那一种，并把这份最低运费当作两个分布之间的距离**。这也是这一章的最后一课——距离的尺子摆齐了，我们就能给整个家族拍一张全家福。

## 2. 直觉解释

先把老尺子的坏脾气摊开说。KL 散度（第 40 章登场）逐点相除再取对数，一旦真实分布在某处有质量、对比分布在那里却是零，$\ln(\text{正数}/0)$ 当场爆炸成无穷大。这在生成任务里不是罕见事故而是常态：真实数据的直方图上总有一些格口实实在在空着。

Wasserstein 距离换了一副更务实的头脑：既然质无重合处没法逐点比较，那就**搬**。每单位质量每公里计一元运费，两组分布之间的一切搬运方案都会给出一份账单，取其中最省的那张——账单金额就是 $W_1$。土堆和坑完全不重叠也没关系：反正都是整车整车地拉，按里程结账而已。

它的温柔还不止"永远有定义"：运费由**几何路径**决定，所以 $W$ 小意味着真正"近在咫尺"，而不是"碰巧在某些点位对得上数"。GAN 语境里那个著名的升级——WGAN 把判别器换成了返回任意分数的评论家（critic），底层依据正是 $W_1$ 的对偶形式；一句带过，点到为止。

## 3. 正式定义

$$W_p(p, q) = \left(\min_{\gamma} \int d(x, y)^p \,\mathrm{d}\gamma(x, y)\right)^{1/p}, \qquad \text{重点观察 } p=1\text{ 时的 } W_1$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $\gamma(x, y)$ | 搬运方案 | 联合分布：从 $x$ 处搬多少质量到 $y$ 处 |
| $d(x,y)$ | 单价表 | 通常取直线距离 $\lvert x-y \rvert$ |
| $\min_\gamma$ | 挑方案 | 所有可能调运计划里选运费最低者 |

三条值得圈点的性质：

1. **永不缺席**：任何两个合法分布之间，$W_1$ 都有限且有定义——哪怕支撑完全不相交；
2. **它附赠施工图**：取得最小值的那套方案本身就是"怎样改造世界"的操作说明，KL 只报票价、不给路线；
3. **一维情形有闭式解**：两边各自排好序，第 $k$ 单质量的落点互相配对即是最优——与第 36 章逆变换采样那条 CDF 主线遥相呼应。

## 4. 分步例题

数轴上只有四个工地。土堆（源分布）：位置 $0$ 处 $3$ 吨、位置 $6$ 处 $1$ 吨；缺口（目标分布）：位置 $2$ 与位置 $5$ 各缺 $2$ 吨。求 $W_1$。

1. **查总账**：两侧总量 $4 = 4$，平衡，可运；
2. **沿数轴扫一遍累计差额**（源减目标）：过 $0$ 后 $+3$；过 $2$ 后 $+1$；过 $5$ 后 $-1$；过 $6$ 归零——序列 $(+3,\ +1,\ -1,\ 0)$ 的绝对值意味着：边界 $0\!\to\!2$ 间将有 $3$ 吨穿行，$2\!\to\!5$ 与 $5\!\to\!6$ 各有 $1$ 吨穿行；
3. **各段按长度付费**：$3 \times 2 + 1 \times 3 + 1 \times 1 = 10$；
4. 所以 $W_1 = 10$（总土量 $4$ 吨，人均不到 $3$ 公里）。练习里你还要亲手把这个算法交给机器跑一遍。

试试两件事：把 $d$ 缩到 $1$ 以下，山体大面积交叠——这时新旧尺子都还有话可说；再把 $w$ 拖胖拖瘦。注意一件反直觉的事：**山峰不管多宽多瘦，彼此间的 $W_1$ 恒等于 $2d$**——整包概率质量只需整体平移 $2d$ 公里，与山的肥瘦无关。至于 KL：连续高斯的尾巴再矮也从不断绝，于是它只会递上一张随 $d^2/w^2$ 增长的天文数字账单；可一旦换成实验二那种"格子真的可以完全真空"的离散世界，同一把尺子立刻掀桌。

### 实验 2（python）：两把尺子同台考试

```python title="KL 的暴脾气与 W1 的冷静"
import math

def kl_discrete(p, q):
    acc = 0.0
    for pv, qv in zip(p, q):            # zip：把两列并排逐项递出
        if pv > 0 and qv == 0:
            return math.inf             # 有质量的点位对方是空的：当场爆炸
        if pv > 0:
            acc += pv * math.log(pv / qv)
    return acc

def w1_two_piles(pos_a, pos_b):
    return abs(pos_a - pos_b)           # 各一整车土的特例：运费即里程

p_full = [0.5, 0.25, 0.25]              # 满支撑的真实分布
q_gap = [0.75, 0.25, 0.0]               # 第三格真空的候选分布

print("KL(q_gap || p_full) =", round(kl_discrete(q_gap, p_full), 3))
print("KL(p_full || q_gap) =", kl_discrete(p_full, q_gap))
print("两个孤立土堆相距 8 公里时 W1 =", w1_two_piles(-4, 4),
      "，而此时双向的 KL 都只有 inf")
```

第一行还算正经（$0.304$，这个方向恰好有限）；第二行直接打出 `inf`——第三格那点质量在对方土地上找不到落脚点，对数当场沸腾。第三行 $W_1$ 平静地报出 $8$：对于两个孤立的整车土堆，距离就是搬运里程，**重合与否根本不在它的工作范围里**。

### 实验 3（python）：把整支家族请上台领奖

```python title="收官验收：五把尺子的同台快测"
import math

# 同一组小实验里交叉印证前面五课的核心常数
def chain_prob(p_list):
    out = 1.0
    for p in p_list:                    # 自回归：条件链连乘
        out *= p
    return out

def kl_gaussian(mu, sigma):
    return (mu ** 2 + sigma ** 2 - 1 - math.log(sigma ** 2)) / 2  # VAE 的税单

def flow_logpdf_normed(y):
    z = y / 2.0                         # Flow：m=0, s=2 的仿射流
    return -0.5 * z * z - math.log(math.sqrt(2 * math.pi)) - math.log(2)

def w1_two_piles(pos_a, pos_b):
    return abs(pos_a - pos_b)           # OT 特例回顾

checks = [
    ["AR  条件链", chain_prob([0.5, 0.4])],
    ["VAE 散度税", kl_gaussian(2, 1)],
    ["Flow 对数密度", flow_logpdf_normed(2)],
    ["GAN 博弈下限", -math.log(4)],
    ["OT  孤立土堆", w1_two_piles(-3, 3)],
]
for name, val in checks:
    print(name, "=", round(val, 3))
```

五行输出是五门旧课的名片（分母里特意复用了第 60 课那套仿射流公式）。同一道"分布差多少"的考题，尺子各有刻度——正是接下来这张地图要说的事。

```quiz
两团概率分布的支撑完全不重叠时，下列说法正确的是？
- KL 散度与 Wasserstein 距离都变成无穷大
- KL 散度为无穷大，而 Wasserstein 距离依然有限 [*]

? KL 需要 q 在每个 p 有质量的位置兜底；全空则必爆。W1 只认搬运路程——重合与否根本不在它的关心范围内。
```

:::warning[常见误区]

**误区一**："你以为 $W$ 温柔就该处处用它。" 高维空间里的精确 OT 计算代价高昂，实践常用熵正则化（Sinkhorn 型迭代）换取速度；温柔是有票据的。

**误区二**："你以为 $W$ 更小就必然画出更好的样本。" 它只是比较学指标；生成质量还握在解码器容量与训练动态手里——尺子准不等于手艺好。

**误区三**："你以为距离数值能跨任务直接互比。" 运费的单位随数据的量纲缩放走，像素坐标上的 $5$ 和摄氏度上的 $5$ 不是同一种贵；跨域比较前先统一刻度。

:::

## 6. 练习

**练习**：数轴工地接下两单生意。第一单就是第 4 节例题里那批土——正好用机器复核你刚才的手算；第二单是一笔更远的长途线。下面的账房先生能开工，可惜它把每段路都当成一公里：

```exercise
# @title: 练习：把路段长度记进运费
# @check: 10
# @check: 35
# @hint: 过境吨数取累计差额的绝对值；但每一段路的单价不是 1，而是当前站点与上一站点的坐标差 sp - prev。
def w1_route(s_sites, s_tons, d_sites, d_tons):
    # 挖方、填方各自的"站点 -> 吨数"小账本
    s_map = dict(zip(s_sites, s_tons))   # zip + dict：两列配对拼成字典
    d_map = dict(zip(d_sites, d_tons))
    spots = sorted(set(s_sites + d_sites))   # 所有站点排成一列（去重）
    cum, cost, prev = 0, 0, None
    for sp in spots:
        if prev is not None:
            cost += abs(cum) * 1         # ← 问题在这：段长被写死成 1 公里
        cum += s_map.get(sp, 0) - d_map.get(sp, 0)   # 本站供需净额入账
        prev = sp
    return cost if cum == 0 else -1      # 两边总量对不上，宣告无解

print(w1_route([0, 6], [3, 1], [2, 5], [2, 2]))
print(w1_route([0, 10], [5, 0], [7], [5]))
```

<details>
<summary>点开查看逐步解答</summary>

修法一处：`cost += abs(cum) * (sp - prev)`。第一单：过境吨数 $3, 1, 1$ 对应段长 $2, 3, 1$，合计 $6 + 3 + 1 = 10$——和手算分毫不差；第二单 $5$ 吨土要横穿 $7$ 公里荒地，运费正是 $5 \times 7 = 35$。漏掉乘法的后果在第二单现了原形：长途线报价缩水到零头 $5$，差了整整七倍。扫差额法给的从来不是"搬了几次"，而是"每一吨走了多远"——这两个概念只在玩具般的等距格子上恰好重合。
</details>

## 7. 选读：熵正则与对偶的一次露脸

<details>
<summary>选读 · 让运输计划别太死板</summary>

精确最优方案常退化为若干条硬邦邦的专线；Sinkhorn 技巧在目标里加一项"计划的熵 bonus"，鼓励质量多头细流地走，于是整套方案可由几轮行归一化、列归一化的交替缩放高效逼近——这也是深度学习里 OT 能实用化的关键一招。至于对偶形式，$W_1$ 可以改写成"在所有斜率不超过 1 的函数中，最大化它在两个分布上取值的平均差"。GAN 那位改行当评论家的网络，学的正是这个斜率受限的函数族；严格证明留在博弈论那一卷慢慢消化。

到此，本章"怎么造分布"的全旅程画上句号：显式分解、隐式对抗、变分下界、可逆变换、分数导航、土方结算——六种回答合成一张地图，愿你下次遇到任何新的生成模型论文时，都能一眼认出它站在地图的哪个坐标上。
</details>
