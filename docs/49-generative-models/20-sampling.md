# 从分布采样

## 1. 从一个场景开始

抽卡游戏里，金色装备概率 $0.05$、紫色 $0.15$、蓝色 $0.3$、白色 $0.5$。语言模型写小说时也在"抽卡"：每写一个字前，它给词表里几万个候选各配一个概率，然后抽签决定下一个字。

抽卡机的核心零件其实只有一样：一台**绝对公平的均匀骰子**（连续版：能产出区间 $[0,1)$ 里任意数且机会均等）。本课的问题是——怎么把公平骰子的输出，捏弯成任意你想要的分布？答案优雅得像戏法：**逆变换采样**。

## 2. 直觉解释

想象一个幸运转盘：圆盘按概率切扇形——金色占百分之五的弧长、紫色占十五、蓝色三十、白色一半。指针匀速旋转，停下位置在整圈上均匀分布，但**读出的奖品服从目标分布**。

关键动作只有两步：

1. 把概率**累加**起来，铺成一条从 0 长到 1 的台阶（累积分布）；
2. 抽一个均匀随机数 $r$，看它落进哪一级台阶，就输出对应选项。

均匀性没有消失，只是被台阶"重新分区"了：金色区只占数轴的 $5\%$，所以均匀的指针只有 $5\%$ 的机会踩进去——比例原样保留。这就是为什么一维均匀分布被称为**万能原料**。

## 3. 正式定义

设目标离散分布为 $p_1, p_2, \ldots, p_n$（非负、总和为 1）。定义累积和 $c_k = p_1 + p_2 + \cdots + p_k$，则采样算法为：

$$r \sim U(0, 1), \qquad \text{输出最小的 } k \text{ 使得 } r < c_k$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $U(0,1)$ | 标准均匀分布 | 万能原料，`random.random()` 的产出 |
| $c_k$ | 累积概率 | 台阶的第 $k$ 级高度 |
| 最小的接住 $r$ 的 $k$ | 落点 | 第一个满足 $r < c_k$ 的台阶编号 |

正确性一句话说清：$r$ 均匀铺满 $[0,1)$，而"$c_{k-1} \le r < c_k$"这段区间的长度恰是 $p_k$——所以第 $k$ 项被抽中的概率精确等于 $p_k$。大数定律（第 9 章）进一步保证：抽得越多，频率越贴近概率。

## 4. 分步例题

目标分布：晴 $0.5$、阴 $0.3$、雨 $0.2$。台阶高度依次为 $0.5$、$0.8$、$1.0$。

1. 抽到 $r = 0.62$：从左往右找第一级超过它的台阶——$0.5$ 接不住，$0.8$ 接住了 → 输出"阴"；
2. 再抽 $r = 0.08$：第一级 $0.5$ 就接住 → "晴"；
3. 再抽 $r = 0.91$：前两级都失守，落到最后 → "雨"；
4. 自查：三个区间的长度分别为 $0.5, 0.3, 0.2$，与目标严丝合缝，无缝无叠 ✓。

注意边界习惯：比较用严格小于（半开区间），保证每个样本恰好落入唯一一格，不会两头都算账。

## 5. 动手实验

### 实验 1（python）：造一台真的抽卡机

```python title="转盘抽样：频率逼近概率"
import random
import matplotlib.pyplot as plt

labels = ["gold", "purple", "blue", "white"]
probs = [0.05, 0.15, 0.3, 0.5]

counts = [0, 0, 0, 0]            # 与 probs 对齐的计分板
for trial in range(5000):
    r = random.random()          # 公平骰子：[0,1) 内等可能
    acc = 0                      # 累积概率走到哪了
    for k in range(4):
        acc = acc + probs[k]
        if r < acc:
            counts[k] += 1       # += ：计数加一并写回
            break                # break：立刻跳出循环，防止重复计账

freq = []
for k in range(4):
    freq.append(counts[k] / 5000)
    print(f"{labels[k]}: 目标 {probs[k]}, 实测频率 {round(freq[k], 3)}")

plt.bar(range(4), freq)          # 柱状图画实测频率
for k in range(4):               # 在每根柱上方画一段红线标出目标概率
    plt.plot([k - 0.4, k + 0.4], [probs[k], probs[k]], color="tomato", linewidth=3)
```

红段与柱顶几乎齐平——五千次抽样已让频率贴上概率；把 5000 改成 500000 再跑一次会更贴。

### 实验 2（python）：给台阶画个像

```python title="累积台阶：采样的地图"
import matplotlib.pyplot as plt

probs = [0.05, 0.15, 0.3, 0.5]
acc = 0
lefts = []      # 每级台阶的左端
rights = []     # 右端
heights = []    # 台面高度（即累积概率）
for k in range(len(probs)):
    lefts.append(acc)
    acc = acc + probs[k]
    rights.append(acc)
    heights.append(acc)

for k in range(len(probs)):
    plt.hlines(heights[k], lefts[k], rights[k], linewidth=6)   # hlines：画一段水平粗线当台阶面
plt.ylim(0, 1.1)
plt.xlabel("落点 r")
plt.ylabel("累积概率")
```

四段平台的高度就是各级累积概率。任何均匀随机数垂直向上投影，撞到的第一块平台就是它的归宿——算法与几何在此完全重合。

### 快问快答

```quiz
为什么从均匀分布出发就能采样出任意离散分布？
- 因为计算机只能产生均匀随机数
- 因为把 0 到 1 切成与目标概率等长的区间后，均匀落点自然按比例分配 [*]
- 因为所有分布本质上都是均匀的
? 均匀意味着落点密度处处相等，于是各区间中签率等于区间长度。切分方式携带了全部分布信息。
```

:::warning[常见误区]

**误区一**："你以为实测频率就该等于概率。" 五千次抽样里金色出现 218 次（期望 250）完全正常——有限样本必然波动，波动幅度随样本量按 $\frac{1}{\sqrt{n}}$ 收缩。别用小样本质疑骰子。

**误区二**："你以为区间划分可以随意重叠或留缝。" 缝隙会让部分 $r$ 无家可归，重叠会重复计账。合法划分必须无缝、无叠、恰好覆盖 $[0,1)$。

**误区三**："你以为采样器不需要维护。" 概率表一旦更新（比如调节温度后的语言模型），台阶就要重算；拿旧台阶配新概率表，是真实系统里出现过的经典 bug。

:::

## 6. 练习

**练习 1**：假设公平骰子吐出了下面 8 个数。按"晴：小于 0.5；阴：0.5 到 0.8；雨：其余"的正确台阶给它们归类并统计。代码能跑，但第二级判断抄错了——修到通过：

```exercise
# @title: 练习：修好台阶的分界线
# @check: 3
# @check: 3
# @check: 2
# @hint: 三级分界是 0.5 和 0.8。现在第二个分支的条件写成了和第一级一样，导致"阴"永远接不到样本。
r_values = [0.21, 0.93, 0.62, 0.44, 0.77, 0.85, 0.09, 0.58]

counts = {"晴": 0, "阴": 0, "雨": 0}
for r in r_values:
    if r < 0.5:
        counts["晴"] += 1
    elif r < 0.5:                 # ← 问题在这：第二级的分界抄成了 0.5
        counts["阴"] += 1
    else:
        counts["雨"] += 1

print(counts["晴"])
print(counts["阴"])
print(counts["雨"])
```

**练习 2**：把练习 1 的三格改成"金 0.05 / 紫 0.15 / 蓝 0.3 / 白 其余"，手算这 8 个数各自落在哪一级。

<details>
<summary>点开查看逐步解答</summary>

台阶高度依次是 $0.05$、$0.20$、$0.50$。逐个归类：

- $0.21, 0.44$ 落在蓝区（$0.20 \le r < 0.50$）→ 蓝 ×2；
- $0.93, 0.77, 0.85, 0.58$ 都不小于 $0.50$ → 白 ×4；
- $0.09$ 落在紫区（$0.05 \le r < 0.20$）→ 紫 ×1；
- 没有数小于 $0.05$ → 金 ×0。

8 个样本里最稀有的金色一次都没出现——这正是稀有掉率的日常体感，也是为什么游戏公司要按"期望次数"而不是"单抽运气"来谈概率。
</details>

## 7. 选读：连续分布也能这样采

<details>
<summary>选读 · 逆变换法的连续版</summary>

离散台阶升级成连续曲线：设目标密度为 $f(x)$，累积分布函数 $F(x) = \int_{-\infty}^{x} f(t)\,dt$ 单调上升且从 0 长到 1。算法只有两行：

1. 抽 $r \sim U(0,1)$；
2. 输出 $x = F^{-1}(r)$（反函数：从高度反查位置）。

经典例子是指数分布（寿命模型）：取 $F(x) = 1 - e^{-\lambda x}$，解出 $x = -\frac{\ln(1-r)}{\lambda}$。由于 $1-r$ 与 $r$ 同分布，工程上直接写 $x = -\ln(r)/\lambda$。两行代码就能模拟灯泡寿命、放射性衰变。

局限也明显：很多高维分布的 $F^{-1}$ 写不出来（第 10 课讲过的归一化之墙）。那时就要请出马尔可夫链蒙特卡洛等更重的机器——那是第 39 章贝叶斯计算的后话。

</details>
