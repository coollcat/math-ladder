## 实战挑战 · 给真实信号揉进噪声

AI 绘画、语音合成和科学数据同化都会用到扩散模型（代表工作：Ho 等 2020 年的 DDPM）：前向把真实数据一步步掺入噪声——每一步旧信号乘一个略小于 1 的系数（记作 $a$），再加一份随机扰动；反向则学习逐步去噪。同一套规则作用在不同数组上，就得到不同模态：图像的亮度通道、音频的波形样本、气候站的温度距平。下面把三种真实场景各压缩成一个数（系数与噪声取值为**情境原创**的教学简化；把 DDPM 的 $\sqrt{\beta}$ 固定成 1，只保留“缩放旧信号、叠加噪声”的结构）。想看带 β 调度、反向过程与训练目标的完整 DDPM 账本，见[扩散模型的完整推导](./42-diffusion-math.md)。

情境设定：图像起点是一个亮度值 $8$，语音起点是一个波形样本 $-3$，科学数据起点是一个温度距平 $0.2$。三者的加噪规则相同：

$$x_{\text{新}} = a \times x_{\text{旧}} + \varepsilon$$

其中衰减系数 $a = 0.8$（信号每步缩两成），三步的噪声依次为 $\varepsilon_1 = 1$、$\varepsilon_2 = -1$、$\varepsilon_3 = 2$。

请完成：

**(a)** 对三个起点分别走完三步，打印各自的最终值（保留两位小数）；
**(b)** 若图像三步都没有掺任何噪声（纯衰减），亮度还剩多少？（保留一位小数）
**(c)** 对比 (a)(b) 回答：噪声是“毁掉”了信号，还是只是把它“盖住”了？

```exercise
# @title: 实战挑战：图像、语音与气候信号的三步加噪
# @check: 图像 5.94
# @check: 语音 0.3
# @check: 气候 1.94
# @check: 4.1
# @hint: noisy_step 少做了一半工作：先把旧值乘 a 缩小，再加当步噪声。外层循环已经分好三种真实信号。
a = 0.8                                     # 衰减系数：旧信号的存留比例
starts = {"图像": 8.0, "语音": -3.0, "气候": 0.2}
noises = [1, -1, 2]                         # 三步各自收到的固定扰动

def noisy_step(value, eps, decay):          # 单步加噪机器：value 是旧值
    return value + eps                      # ← 问题在这：既没先乘 decay，顺序也不对

for name in starts:                         # 遍历字典：依次取出每个真实场景名
    x = starts[name]
    for eps in noises:                      # 同一条三步噪声链作用于每个信号
        x = noisy_step(x, eps, a)
    print(name, round(x, 2))

signal_left = round(8.0 * 3, 1)             # (b)：三步纯衰减后还剩多少亮度
print(signal_left)
```

<details>
<summary>点开查看逐步解答</summary>

**(a)** 对每个起点反复代入 $x_{\text{新}} = 0.8 \times x_{\text{旧}} + \varepsilon$：

```python
a = 0.8
starts = {"图像": 8.0, "语音": -3.0, "气候": 0.2}

def noisy_step(value, eps, decay):
    return value * decay + eps

for name in starts:
    x = starts[name]
    for eps in [1, -1, 2]:
        x = noisy_step(x, eps, a)
    print(name, round(x, 2))

signal_left = round(a ** 3 * 8.0, 1)
print(signal_left)
```

图像的轨迹是 $8 \to 7.4 \to 4.92 \to 5.936$；语音是 $-3 \to -1.4 \to -2.12 \to 0.304$；气候距平是 $0.2 \to 1.16 \to -0.072 \to 1.9424$。

**(b)** 纯衰减时噪声项消失，只剩几何级数：$8 \times 0.8^3 = 8 \times 0.512 = 4.096 \approx 4.1$。

**(c)** 关键对比：图像第 3 步里信号成分仍是 4.096，实测值 5.94 与它的差 1.84 恰好是三步噪声到此刻的累计残余（$1\times0.8^2 + (-1)\times0.8 + 2 = 1.84$）。语音样本从负压变成正值、气候距平被推离零点，也都是同一件事：**信号从未被销毁，只是被逐层掩埋**。只要知道每层的掩埋规则（$a$ 与噪声分布），就能反向挖出来。这正是扩散模型“训练学预测噪声、采样步步扣除”的全部秘密——也解释了为什么去噪网络能在图像雪花、语音嘶啦声或仪器抖动后面唤回原来的结构。
</details>

## 实战挑战 · 极大似然：数对样本

极大似然估计伯努利硬币的正面概率，就是"数正面、除以总数"。投 6 次得 4 次正面，$\hat p = \frac46$。下面这题数成了反面，修到输出 `0.6667`：

```exercise
# @title: 实战挑战：极大似然数对样本
# @check: 0.6667
# @hint: 1 代表正面，数"1"的个数才对；现在数成了 0。
flips = [1, 0, 1, 1, 0, 1]    # 1=正面，0=反面
heads = 0
for f in flips:
    if f == 0:                # ← 问题在这：数成了反面
        heads = heads + 1
p_hat = heads / len(flips)
print(round(p_hat, 4))
```

<details>
<summary>点开查看逐步解答</summary>

极大似然数的是**正面**（值 1）：

```python
if f == 1:               # 正面才计数
    heads = heads + 1
p_hat = heads / len(flips)   # 4 / 6
print(round(p_hat, 4))       # 0.6667
```

改完：$\hat p = \frac{4}{6} \approx 0.6667$。初始代码数反面得 $\frac{2}{6} \approx 0.3333$。极大似然的精髓就是"让观测到的数据最可能"——对伯努利分布，解恰好就是频率。生成模型的参数学习，几乎都从这一步"数样本、算频率"起步。

</details>
