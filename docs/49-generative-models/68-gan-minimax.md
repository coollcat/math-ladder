# GAN 的极小极大博弈

## 1. 从一个场景开始

一间印钞厂里有两名员工：造假者日夜改进假钞，验钞员每天根据最新一批赝品升级眼光。谁都不甘落后——假钞越像真钞，验钞员越要炼出火眼金睛；验钞员越精，造假者被迫出更逼近的活。这场军备竞赛跑到底会出现什么局面？**当连验钞员自己都分不出真假时，假钞工艺就登峰造极。**

生成对抗网络（GAN）把这间工厂搬进了数学：两个神经网络互为对手、同时训练——这就是本章第一个没有"密度公式"的生成模型。

## 2. 直觉解释

前三课生成模型的发言方式各不相同，但都在回答同一道题："这个样本的概率是多少？"自回归查小表、VAE 请替身近似、Flow 记体积账。GAN 换了一条判别式路线：**不写概率表，直接训练一个比较器**——鉴别手 $D$ 看样本打分（1 表示真品），造假者 $G$ 根据对手的打分调整作品。

两个人的目标恰好相反：

- 鉴别手想赢：把真品判得越接近 1、赝品压得越接近 0，自己的战果越大；
- 造假者想赢：让对手给自己出的分数越高越好——最好让 $D$ 把赝品也看成真品。

双方僵持的那一点就是**纳什均衡**（第 51 章会正式研究这个概念）：谁都无力单方面变得更好。在这个游戏里，均衡长得特别好看——假分布与真实分布完全重合，鉴别手面对任何样本都只好五五开乱猜。至于著名的模式坍塌，根子在于：对造假者个人而言，"在鉴别手眼下最难以分辨的一个点上反复输出"就已经能把个人损失做得很低，**覆盖全部真实形态从来不是他的直接动机**——这是后文实验里看得见的现象。

## 3. 正式定义

$$V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\ln D(x)] + \mathbb{E}_{z}[\ln(1 - D(G(z)))]$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $D(x)$ | 鉴别手置信度 | 输出一个 0 到 1 的数：多大把握认为 $x$ 是真品 |
| $G(z)$ | 生成器 | 把一份随机噪声捏成一件"作品" |
| $V(D, G)$ | 博弈值 | 双方联合记分；鉴别手最大化它，生成器最小化它 |

两个可以闭着眼睛背下来的事实：

1. **最优鉴别手**：给定当前造假水平，$D^*(x) = p_{\text{data}}(x) / \big(p_{\text{data}}(x) + p_g(x)\big)$——谁的地盘人多就偏向谁；
2. **均衡处的景色**：$p_g = p_{\text{data}}$ 时 $D^*$ 处处等于 $1/2$，博弈值恰为 $\ln(1/4) \approx -1.386$：双方都拿不到便宜，游戏封盘。

## 4. 分步例题

把世界缩成三个格子。真实分布 $p_r = (0.5,\,0.3,\,0.2)$；造假者的候选出货分布 $p_g = (0.1,\,0.4,\,0.5)$。

1. 各格点求最优鉴别手：$D^*_i = p_r / (p_r + p_g)$，依次得 $0.8333,\ 0.4286,\ 0.2857$——假货扎堆的 3 号格上，验钞员反倒最有底气；
2. 各格贡献：$p_r \ln D^* + p_g \ln(1 - D^*)$，依次为 $-0.2703,\ -0.4780,\ -0.4188$；
3. 加总得博弈值 $V \approx -1.17$，比均衡值 $-1.386$ 高出一截：说明当前假货质量还嫩，鉴别手赚了；
4. 改进对照：把 $p_g$ 换成 $(0.34, 0.33, 0.33)$，博弈值降到 $-1.35$；换成一模一样的 $p_r$，恰达 $-1.39$。**离均衡越近，博弈值越是俯身贴向 $\ln(1/4)$**——这条刻度尺就是生成器整个职业生涯的进度条。

### 实验 2（python）：三点世界的博弈值计算器

例题的四步账全部代码化，再顺手验证三种出货方案的高下：

```python title="离散最优鉴别手与博弈值"
import math

def game_value(pr, pg):
    V = 0.0                     # 博弈值累加器
    for i in range(len(pr)):
        d = pr[i] / (pr[i] + pg[i])          # 该位置的最优鉴别手
        contrib = pr[i] * math.log(d) + pg[i] * math.log(1 - d)
        print(f"  格 {i}: D*={round(d, 4)}, 贡献 {round(contrib, 4)}")
        V += contrib              # 累加每格的得分
    return V

pr = [0.5, 0.3, 0.2]
for pg in [[0.1, 0.4, 0.5], [0.34, 0.33, 0.33], [0.5, 0.3, 0.2]]:
    v = game_value(pr, pg)
    print("出货方案", pg, "→ 博弈值", round(v, 2))
```

三档输出正是例题口径（$-1.17 \to -1.35 \to -1.39$）。最后那行几乎就是 $\ln(1/4) = -1.3863$ 的四舍五入：以假乱真的终点不是某个神秘数字，而是两人握手言和的那一点。

### 实验 3（python）：单旋钮造假的坍塌现场

给造假者只有一个可调参数：他的"作品"只能从数轴上一个点发出（delta 族，用瘦高斯代替）。真实数据有两个山头（$\pm 2$ 各占一半）。他每次试探左右两点、哪边鉴别手手松就朝哪边挪：

```python title="一步步爬向唯一幸存的山头"
import math

def dens(x, mean, sd):
    z = (x - mean) / sd            # 标准化后套高斯公式
    return math.exp(-0.5 * z * z) / (sd * math.sqrt(2 * math.pi))

def mixture(x):                    # 真实数据：对称双峰
    return 0.5 * dens(x, -2, 0.6) + 0.5 * dens(x, 2, 0.6)

alpha = 0.02                       # 平滑项：防止 0 概率把除法炸掉

def payoff(c):                     # 站在 c 点、对面摆着最优鉴别手的收益
    fake = dens(c, c, 0.25)
    d = (mixture(c) + alpha) / (fake + mixture(c) + 2 * alpha)
    return d                       # d 越接近 1，赝品越被认作真货

g = 3.6                            # 起步远在天边
path = []
for step in range(40):
    path.append(round(g, 1))
    here, pl, prr = payoff(g), payoff(g - 0.2), payoff(g + 0.2)
    if here >= pl and here >= prr:
        continue                   # 两边都占不到便宜，就地收摊
    g = g - 0.2 if pl >= prr else g + 0.2
print("轨迹:", path[::5])
print("最终落脚:", round(g, 1))
```

轨迹干净利落：$3.6 \to 3.0 \to 2.4 \to 2.0$，此后纹丝不动地钉死在右山头。左边的山头从头到尾无人光顾——不是因为不像，而是因为**对单一策略的个人而言，驻守一处已能拿到满分折扣**。真实模型容量大得多，但这种"选边定居"的引力从未消失：多样性要靠目标函数自己去讨，没人白送。

### 快问快答

```quiz
GAN 达到纳什均衡时，最优鉴别手对任何样本的输出是什么？
- 恒为 1，因为所有样本此时都和真品无法区分
- 随机摆动，看心情决定
- 恒为 0.5，真假两侧概率相等，只能弃权 [*]
? 均衡要求生成分布与真实分布完全重合，任何位置的两侧密度一样大，代入 D* 公式都得 0.5。这也正是博弈值恰好停在 ln(1/4) 的原因。
```

:::warning[常见误区]

**误区一**："你以为鉴别手越强越好。" 无坚不摧的鉴别手配合饱和损失只会给出处处平坦的梯度，生成器反而学不动；实战讲究双方实力动态平衡、交替小步升级。

**误区二**："你认为坍塌是生成的图不好看。" 坍塌损的是**多样性**：样样精美却千篇一律。它是"个人最优 ≠ 全局覆盖"的结构性问题，提高画质指标照不出来。

**误区三**："你以为博弈值最小就是好。" 对不同玩家要分开读账：鉴别手希望 $V$ 大、生成器希望 $V$ 小；喊停的标准不是谁的数字更漂亮，而是双方都失去了单方面改进的空间。

:::

## 6. 练习

**练习**：把博弈值计算器的核心公式修回来。现在的代码能跑，可惜把真假颠倒了个个儿：

```exercise
# @title: 练习：接通真实的博弈值
# @check: -1.17
# @check: -1.35
# @check: -1.39
# @hint: 最优鉴别手站在真实分布一边：分子该是 pr。改完三档方案的数值应该逐级下沉。
import math

def game_value(pr, pg):
    V = 0.0
    for i in range(len(pr)):
        d = pg[i] / (pr[i] + pg[i])   # ← 问题在这：分子拿反，D 变成了假货立场
        V += pr[i] * math.log(d) + pg[i] * math.log(1 - d)
    return V

print(round(game_value([0.5, 0.3, 0.2], [0.1, 0.4, 0.5]), 2))
print(round(game_value([0.5, 0.3, 0.2], [0.34, 0.33, 0.33]), 2))
print(round(game_value([0.5, 0.3, 0.2], [0.5, 0.3, 0.2]), 2))
```

<details>
<summary>点开查看逐步解答</summary>

把 `d` 的分子换回 `pr[i]` 即可，输出依次为 $-1.17$、$-1.35$、$-1.39$。分子拿反时三个值全部扭曲（例如第一档变成 $-1.78$），而且再怎么优化出货方案都到不了均衡刻度 $-\ln 4$。辨析一句：颠倒分子的 $d$ 其实是"假货浓度"，用它算出的账更像是在替鉴别手挑对家的软肋——同一堆零件，立场上错一格，整局棋面目全非。
</details>

## 7. 选读：饱和与非饱和的两副面孔

<details>
<summary>选读 · 为什么实战代码里的损失长得不太一样</summary>

原论文里生成器最小化 $\mathbb{E}[\ln(1-D(G(z)))]$；早期训练阶段鉴别手轻松碾压、$D$ 接近零，这一项的梯度也随之枯竭（"反正画什么都不及格"）。实战普遍改用等价的**非饱和替代**：改为最大化 $\mathbb{E}[\ln D(G(z))]$——方向相同，但在起步期梯度充沛。两者的均衡解一致，中途路径不同。

还有一条通往第 84 课的暗线：Goodfellow 在原文里证明，最优鉴别手下极大极小的全局目标恰与某种分布距离度量挂钩——按测度论的正式说法是 Jensen–Shannon 散度。后来的 Wasserstein GAN 把这个度量换成搬运距离，梯度立刻耐摔许多。"距离度量的选择决定对抗训练的性格"，这句话下一课展开。
</details>
