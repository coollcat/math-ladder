# Flow Matching：不掺噪声，直接搬

## 1. 从一个场景开始

搬家公司接了一单活：把仓库 A 里的一堆货（形状是一团乱麻），搬到仓库 B（形状是规规矩矩码好的垛）。货车每开一段，货的位置都要更新一次。

扩散模型的做法像是"边开边抖"——每一站都故意往车上洒点沙土，再让司机一路扫干净；扫得是好，但路线绕、步子碎，从 A 到 B 得走一千站。

Flow Matching 问了一句：**为什么不直接把路线规划好，一站一站直线开过去？**

这课要算清楚的就是这件事：如果给每个货物都规定好一条从 A 到 B 的**直线路径**，那么"怎么把这些路径合成一股统一的车流"这件事，就变成了一个可以逐点学习的回归问题——**而且不需要任何噪声注入**。

## 2. 直觉解释

**第一层直觉：路径是可以硬凑出来的。** 假设 A 仓库里那件货在位置 $x_0$，B 仓库里它该去的位置是 $x_1$。最偷懒的规划是什么？**在两点之间拉一条直线**：

$$x_t = (1-t)\,x_0 + t\,x_1, \qquad t \in [0,1]$$

$t=0$ 时在 $x_0$，$t=1$ 时在 $x_1$（下一节的正式定义里我们会调换这两个端点的角色，让起点是噪声、终点是数据）。对这条直线求导，得到一个**恒定的速度**：

$$\frac{dx_t}{dt} = x_1 - x_0$$

妙处在于：这条直线的"速度"不随 $t$ 变——司机从头到尾一个油门，不用换挡。

**第二层直觉：一个货一个速度不行，得叫出"车流场"。** 麻烦来了。规划是逐件做的：每件货的 $x_1$ 不同，速度 $x_1 - x_0$ 也就不同。可实际采样的时候，我们**手上只有当前位置 $x_t$**，并不知道这件货的起点 $x_0$ 和终点 $x_1$ 是谁。

所以需要把所有"单件路线"揉成一个**只依赖当前位置与时刻的场**：$v(x, t)$。在某个位置 $x$、某个时刻 $t$ 上，问"这里该往哪个方向、多快走"，答案应该是对所有经过这里的路线取**平均**：

$$v(x,t) = \mathbb{E}\big[x_1 - x_0 \ \big|\ x_t = x\big]$$

这就是**条件流的边缘化**。场是一个平均值，不是某条具体路线——这跟[Score matching](./76-score-matching.md) 里那个指北针场的脾气一模一样：**学的是平均趋势，采样时可以随机。**

**第三层直觉：训练目标因此变得极其朴素。** 既然场就是平均速度，那训练目标自然是"让我预测的速度，尽量接近每件货的真实速度"：

$$L = \mathbb{E}_{t,\,x_0,\,x_1}\big[\lVert v_\theta(x_t, t) - (x_1 - x_0)\rVert^2\big]$$

**注意这里没有任何噪声在反向传播之外**——$x_t$ 是 $x_0$ 与 $x_1$ 的凸组合，不是"加了一层噪声的脏图"。这就是 Flow Matching 与扩散最本质的分岔：**扩散是"先毁再修"，Flow Matching 是"直接规划"。**

**第四层直觉：直线一定最好吗？** 不一定。直线路径意味着"每个时刻都在匀速搬运"，但真实分布之间的搬运往往需要"先散开、再收拢"。Flow Matching 的真正自由度在于**你可以自己选路径的形状**。2022 年后续工作把这件事说得更直白：**先用 Flow Matching 训一版，再用模型自己生成的样本重新配对（$x_0$ 与它实际走到的终点 $x_1'$ 组成新对）重训一轮，路径会自动被拉直**——采样步数少时质量立刻改善。这招叫 **reflow**，是 rectified flow 的核心。

## 3. 正式定义

约定方向：$t=0$ 是**噪声端**（先验分布 $p_0$，通常取标准高斯），$t=1$ 是**数据端**（目标分布 $p_1$，就是真实数据的分布）。一条路径写成

$$x_t = \alpha_t\, x_0 + \sigma_t\, x_1$$

| 路径 | $\alpha_t$ | $\sigma_t$ | 形状 |
| --- | --- | --- | --- |
| 线性（条件最优传输） | $1-t$ | $t$ | 直线，速度恒定 |
| 方差保持（VP，即扩散路线） | $\cos\frac{\pi t}{2}$ | $\sin\frac{\pi t}{2}$ | 弧线，两端速度慢 |

$$\text{目标速度：}\quad \frac{dx_t}{dt} = \dot\alpha_t\, x_0 + \dot\sigma_t\, x_1 \qquad \text{条件流匹配损失：}\quad L_{\text{CFM}} = \mathbb{E}\big[\lVert v_\theta(x_t,t) - (\dot\alpha_t x_0 + \dot\sigma_t x_1)\rVert^2\big]$$

**两条正经结论**（这里只写结论，不展开证明）：

1. **条件目标 ⇒ 边缘目标**：把逐对配对的损失对 $x_0, x_1$ 取期望，其最优解恰好是边缘场 $v(x,t) = \mathbb{E}[\dot\alpha_t x_0 + \dot\sigma_t x_1 \mid x_t = x]$。逐点回归的最优解总是条件期望——这一条在[最小二乘与正规方程](../21-linear-algebra-advanced/80-least-squares.md)里已经认识过了，这里是它在连续时间上的重演。
2. **场 ⇒ 分布**：一旦有了这个场，解常微分方程（ODE）

$$\frac{dx}{dt} = v_\theta(x, t), \qquad x(0) \sim p_0$$

就能把噪声分布一路推成数据分布。全程**不需要随机项**，所以同一个初始噪声每次采样结果**完全相同**——这是 Flow Matching 与扩散在采样体验上的直接差异。

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $x_0 \sim p_0$ | 噪声样本 | 起点，标准高斯 |
| $x_1 \sim p_1$ | 数据样本 | 终点，真实数据 |
| $\alpha_t, \sigma_t$ | 路径系数 | 决定插值曲线形状；两者必须满足 $\alpha_0=1,\sigma_0=0$、$\alpha_1=0,\sigma_1=1$ |
| $v_\theta(x,t)$ | 速度场 | 唯一被学习的对象：在 $(x,t)$ 处"往哪走、多快" |
| $L_{\text{CFM}}$ | 条件流匹配损失 | 与每对样本的直线速度比均方误差 |

## 4. 分步例题

取一维小例子：噪声样本 $x_0 = -1$，数据样本 $x_1 = 3$，走线性路径 $\alpha_t = 1-t$、$\sigma_t = t$。

1. **路径**：$x_t = (1-t)(-1) + t\cdot 3 = 4t - 1$。$t=0$ 得 $-1$，$t=1$ 得 $3$，两端对齐无误；
2. **目标速度**：$\dot\alpha_t = -1$、$\dot\sigma_t = 1$，所以 $\dot\alpha_t x_0 + \dot\sigma_t x_1 = -(-1) + 3 = 4$。从头到尾就是 $4$——线性路径的"匀速"在数值上看得见；
3. **抽三个时刻验证**：$t=0.25$ 时 $x_t = 0$；$t=0.5$ 时 $x_t = 1$；$t=0.75$ 时 $x_t = 2$。相邻差都是 $1$，一个时刻差 $0.25$，速度 $1/0.25 = 4$ ✔；
4. **换方差保持路径对比**：$\alpha_t = \cos\frac{\pi t}{2}$、$\sigma_t = \sin\frac{\pi t}{2}$，取 $x_0 = -1$、$x_1 = 3$，$t=0.5$ 时 $x_{0.5} = \cos\frac{\pi}{4}(-1) + \sin\frac{\pi}{4}\cdot 3 = \frac{2}{\sqrt2} = 1.4142$（线性路径在 $t=0.5$ 是 $1$）。**端点相同、中途不同**——这就是"选路径"的自由度在具体数字上的体现；
5. **用欧拉法采样**：拿到场之后怎么从 $x_0 = -1$ 走到 $x_1 = 3$？把 $[0,1]$ 切成 $N$ 步，每步 $x \leftarrow x + v\cdot \Delta t$。取 $N=4$、$v=4$、$\Delta t = 0.25$：$-1 \to 0 \to 1 \to 2 \to 3$，四步精确到达。**步数是采样速度与精度的直接交易**——这也是为什么"把路径拉直"值得投入：路径越直，同样的步数误差越小。

### 实验 2（python）：速度场的边缘化是"平均"

这一节的核心断言是：**场 = 条件速度的平均**。下面直接验证它。构造两对样本（$x_0=-1 \to x_1=3$ 和 $x_0=1 \to x_1=1$），在 $t=0.5$ 处看两条路各自到哪、速度各是多少，再看"碰巧落在同一个位置"的那些起点，它们的平均速度是否等于该处的场值：

```python title="条件速度如何平均成边缘场"
import random

pairs = [(-1.0, 3.0), (1.0, 1.0)]   # 两对训练样本：(噪声, 数据)

def path(x0, x1, t):                # 线性插值：t=0 在噪声端，t=1 在数据端
    return (1 - t) * x0 + t * x1

def vel(x0, x1):                    # 线性路径的速度恒为 x1 - x0，与 t 无关
    return x1 - x0

t = 0.5
for x0, x1 in pairs:
    print("位置 =", round(path(x0, x1, t), 3), "；速度 =", round(vel(x0, x1), 3))

avg = sum(vel(x0, x1) for x0, x1 in pairs) / len(pairs)
print("平均速度（= 该处的场值，两对权重各半）=", round(avg, 3))
print("位置的标准差（看这里是不是真交汇）=", round(
    (sum((path(x0, x1, t) - sum(path(a, b, t) for a, b in pairs) / 2) ** 2
         for x0, x1 in pairs) / 2) ** 0.5, 3))

random.seed(3)
hits = []
for k in range(20000):              # 随机抽配对，看有多少对在 t=0.5 附近撞到一起
    x0 = random.gauss(0, 1)
    x1 = random.gauss(2, 1)
    if abs(path(x0, x1, t) - 0.5) < 0.05:
        hits.append(vel(x0, x1))
if hits:
    print("撞到 x=0.5 附近的样本数 =", len(hits), "；它们的平均速度 =", round(sum(hits) / len(hits), 3))
```

第一段的两条速度是 $4$ 与 $0$，平均 $2$；而它们的位置在 $t=0.5$ 时分别是 $1$ 与 $1$——**位置撞在一起了，速度却要取平均**。这正是"边缘化"的物理含义：同一个 $x$ 上可能叠着多条来路，网络只能学它们的平均走向。

### 实验 3（python）：欧拉采样步数与误差

训练好的场能一步到位，但采样必须离散成有限步。这个实验让"路径直不直"和"步数够不够"变成两个可以调的数字：

```python title="欧拉采样：步数与终点误差"
# 目标：把 x0 = -1 搬到 x1 = 3。
def exact_speed(x0, x1):            # 真速度（教学里直接给，跳过训练）
    return x1 - x0

x0, x1 = -1.0, 3.0
v = exact_speed(x0, x1)

for steps in [1, 2, 4, 8, 16]:
    dt = 1.0 / steps
    x = x0
    for k in range(steps):
        x = x + v * dt
    print("步数 =", steps, "；到站位置 =", round(x, 6), "；误差 =", round(abs(x - x1), 8))
```

**注意这个实验里误差全是 $0$**——因为直线路径的速度恒定，欧拉法一步都不偏。真实的采样误差来自两件事：场学得不够准（每步都得现场预测，预测有误差），以及路径本身是弯的（弯路上恒定速度的假设不成立，步子粗了就切到外圈去）。**"把路径拉直"之所以值钱，就是因为直线让粗步子也安全。**

```quiz
Flow Matching 与扩散模型最本质的分岔在哪一步？
- Flow Matching 的采样过程不需要任何随机噪声注入，同一起点每次结果相同
- Flow Matching 完全不需要 ODE 求解器 [*]
- Flow Matching 只适用于一维数据
? 扩散的反向过程每步都要从高斯里采样（所以有随机性、有方差要处理），Flow Matching 学的是一个确定的常微分方程，采样就是解 ODE；但它仍然需要数值求解器来离散积分。
```

::::warning[常见误区]

**误区一**："你以为 Flow Matching 就是"不要噪声的扩散"。" 更准确的说法是：**扩散是它的一条特殊路径**。把 $\alpha_t,\sigma_t$ 取成余弦与正弦（方差保持），Flow Matching 的框架原封不动地把扩散装进去了。两者的差别在于**路径形状的选择权**，不在于"有没有噪声"这个概念本身——扩散的路径天然带随机项，Flow Matching 选了确定的那条分支。

**误区二**："你以为训练时只需要 $x_t$ 和 $t$，就像扩散那样。" 关键区别在这：扩散训练要**采样一枚噪声** $\varepsilon$，而 Flow Matching 训练要**同时拿到 $x_0$ 和 $x_1$ 两个样本**（然后按路径插值）。所以它在数学上更简单（不需要重参数化、不需要变分下界），但数据配对是它的前提。

**误区三**："你以为学到的场就是某一条确定路线的引导。" 场是**条件期望**，是平均趋势。真实采样时你只沿着场走，走出来的轨迹**不一定等于任何一条训练样本的直线**。这跟 Score matching 学平均指北针场是一回事——记的是趋势，不是复读。

::::

## 6. 练习

**练习 1**（概念口答）：线性路径下速度 $v = x_1 - x_0$ 与 $t$ 无关。既然如此，为什么采样时还非要把 $[0,1]$ 切成很多步？不能一步从 $x_0$ 跳到 $x_1$ 吗？

<details>
<summary>点开查看逐步解答</summary>

因为**你学到的不是真速度，是场的预测值**。训练完之后手里只有 $v_\theta(x,t)$，而它在不同 $t$ 上给出的答案依赖于当时的输入 $x_t$：一步跳意味着你只在 $t=0$ 那一点问了一句路，后面就没再查过。真实数据分布上，不同位置的场互相拉扯（实验 2 里那个"位置撞在一起、速度取平均"就是证据），单点外推会累积偏差。

另外，"一步到位"还要求单条路径真的是直线。训练时路径是逐对设计成直线的，但**采样时走的是场的积分**，而场是许多直线的平均——平均出来的流线通常是弯的。弯路上步子越粗，切弯越多，终点越偏。所以**步数是精度与算力的交易，而不是数学必须**：把路径拉直到接近直线（reflow 那一招），两步甚至一步也能出图。

</details>

**练习 2**（判题）：目标速度这一半写错了——它把 $\dot\alpha_t$ 与 $\dot\sigma_t$ 弄反了，等于把"信号在退场"和"数据在登场"的速率配错了：

```exercise
# @title: 练习：修对目标速度
# @check: 4.0
# @check: 1.4142
# @hint: 线性路径 α=(1-t)、σ=t，于是 α'=-1、σ'=1：噪声项的系数是负的，数据项的系数是正的。
import math

x0 = -1.0     # 噪声样本
x1 = 3.0      # 数据样本

def target_vel(x0, x1, da, ds):
    return da * x1 + ds * x0     # ← 问题在这：两个系数配错了对象

print(round(target_vel(x0, x1, -1.0, 1.0), 4))
print(round(math.cos(math.pi / 4) * (-1.0) + math.sin(math.pi / 4) * 1.0, 4))
```

第一行查线性路径的目标速度：应为 $(-1)\times(-1) + 1\times 3 = 4$。第二行换方差保持路径的中点做交叉检查：$-\cos\frac{\pi}{4} + \sin\frac{\pi}{4} = 0$——但输出要求的是 $1.4142$，提示你先算 $-\cos\frac{\pi}{4}\times(-1) + \sin\frac{\pi}{4}\times 1$，也就是 $\cos\frac{\pi}{4} + \sin\frac{\pi}{4} = 1.4142$。**两行分别卡住"系数要配对的正确对象"和"系数本身要算对"。**

## 7. 选读：从条件流到边缘流，再到 SDE

<details>
<summary>选读 · 为什么"逐对直线"能拼出"整体的流"</summary>

严格的证明走的是**连续性方程**：一个分布族 $p_t$ 随时间演化，它的速度场 $v$ 必须满足 $\partial_t p_t + \nabla\cdot(p_t v) = 0$——这句话的意思是"质量守恒"，分布在某处减少，必然是从那里流走了。条件路径各自满足自己那本小账；把所有配对（连同它们各自的 $x_0, x_1$）边缘化之后，总分布的连续性方程被自动满足，而那个满足方程的速度场**恰好就是条件期望** $\mathbb{E}[\dot\alpha_t x_0 + \dot\sigma_t x_1 \mid x_t = x]$。这就是条件流匹配损失能训出正确边缘场的原因。

更进一步，Flow Matching 还有一个 SDE 版本：在学到的场之上叠加一份扩散系数，就得到一族**共享同一批边缘分布**的随机过程。这意味着"确定性的 ODE 采样"与"带噪声的 SDE 采样"可以在同一个场下切换——ODE 快而稳（适合低步数、适合科学计算的确定性复现），SDE 慢但能修正累积误差（适合质量优先的生成）。扩散模型的所有采样器技巧，在这里都有对应物。

与本章其他家族的接口也很清楚：[Normalizing Flow](./60-normalizing-flows.md) 要求变换可逆、Jacobian 可算，是硬约束；Flow Matching 放弃"可逆 + 显式密度"，换来任意形状的路径与更简单的损失——它没有显式似然，但也不需要。与[扩散的完整账本](./42-diffusion-math.md)相比，它把"调度表 + 反向均值方差 + 变分下界"三件套全部换成了一个回归目标。代价是：**没有了 $\bar\alpha_t$ 这本现成的账，路径形状要你自己想。** [SDE 网络](../55-scientific-ml/60-sde-networks.md)则把这条线继续往下推——那里不再只学"一步的速度"，而是直接学整段连续演化的漂移项。
