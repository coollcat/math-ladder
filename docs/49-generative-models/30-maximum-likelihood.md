# 极大似然直觉

## 1. 从一个场景开始

一枚硬币抛十次，七正三反。你开始怀疑它被动过手脚——可是"公平硬币"也会出现七正三反（概率约 $0.117$），凭什么怪硬币？

换个问法就清楚了：**在所有可能的硬币里（正面率从 0 到 1），哪一种让"七正三反"这组数据显得最不奇怪？** 直觉秒答：正面率 $0.7$ 的硬币。这个朴素直觉被数学化之后，就是统计学与机器学习共同的地基——**极大似然**。语言模型的训练目标（下一词预测 + 交叉熵损失）正是它的现代版。

## 2. 直觉解释

把参数想成嫌疑人，数据想成现场证据：

- **似然** = "如果参数是这个值，看到眼前这些数据的概率有多大"。它是给每个候选参数打分的函数；
- **极大似然估计**（MLE）= 选打分最高的那个参数——不是"最常见"的参数，而是**最能解释证据**的参数。

注意视角的翻转：概率问"给定硬币，数据如何"；似然问"给定数据，硬币如何"。同一个公式 $P(\text{数据} \mid p)$，读法一换，用途全变。

## 3. 正式定义

设数据为 $k$ 次正面、$n-k$ 次反面。若硬币正面率为 $p$ 且每次抛掷独立，则**似然函数**为

$$L(p) = p^{k} \, (1-p)^{\,n-k}$$

| 符号 | 名字 | 含义 |
| --- | --- | --- |
| $L(p)$ | 似然 | 参数为 $p$ 时，这组数据出现的概率 |
| $p^k(1-p)^{n-k}$ | 连乘结构 | 每次正面贡献因子 $p$，每次反面贡献 $1-p$ |
| $\hat{p}$ | MLE | 让 $L$ 达到最大的那个 $p$ |

对 $L(p)$ 求导并令导数为零（或用第 13 章的极值技巧），可得闭式解：

$$\hat{p} = \frac{k}{n}$$

即"正面频率就是最优参数"。更妙的是取对数：$\ln L(p) = k\ln p + (n-k)\ln(1-p)$。把它添个负号、除以样本数，正是第 40 章的**交叉熵**——所以"最小化交叉熵损失"和"极大似然"是同一件事的两种说法。

## 4. 分步例题

数据仍是七正三反（$k=7$, $n=10$）。比较三位嫌疑人：

1. 公平派 $p=0.5$：$L = 0.5^7 \times 0.5^3 = 0.5^{10} \approx 0.000977$；
2. 嫌疑人 $p=0.7$：$L = 0.7^7 \times 0.3^3 \approx 0.00222$；
3. 极端派 $p=0.95$：$L = 0.95^7 \times 0.05^3 \approx 8.7\times10^{-5}$；
4. 排序：$L(0.7)$ 是公平派的约 2.3 倍，是极端派的约 25 倍——证据最偏袒 $p=0.7$，它就是 MLE。

顺带观察：似然值本身都小得可怜（连乘十个小于 1 的数），所以实践中没人直接比 $L$，而是比对数似然——单调变换不改变峰值位置，却避免了连乘下溢。

### 实验 2（python）：数值扫描找峰

```python title="网格扫描：谁最会解释这组数据"
best_p = 0.0
best_L = 0.0

for k in range(1, 100):
    p = k / 100                  # 候选参数从 0.01 试到 0.99
    L = p ** 7 * (1 - p) ** 3    # 七正三反下的似然
    if L > best_L:
        best_L = L
        best_p = p

print(f"最有嫌疑的硬币: 正面率 = {best_p}")
print(f"它的似然 = {round(best_L, 4)}")

for p in [0.5, 0.7, 0.95]:       # 三位嫌疑人的得分对照
    print(f"p = {p}: L = {round(p ** 7 * (1 - p) ** 3, 5)}")
```

扫描结果与例题一致：峰在 $0.7$。数值实验与求导公式在此会师。

### 快问快答

```quiz
抛 10 次全是正面，MLE 给出的正面率是多少？该直接信吗？
- 0.5，因为硬币总归是公平的
- 1.0，但小样本下它是过拟合的极端答案 [*]
- 0.9，留一点余地最稳妥
? MLE 只负责"最能解释已见数据"，十投十正时它会孤注一掷押 1.0。工程上要靠更多数据或先验（第 39 章）来拉住它。
```

:::warning[常见误区]

**误区一**："你以为似然是参数的概率分布。" $L(p)$ 没有对 $p$ 归一化，$\int L(p)\,dp$ 一般不为 1；它只是参数的打分器。"似然最大的参数"与"概率最大的参数"是两个概念。

**误区二**："你以为 MLE 就是真理。" 十次抛掷的 MLE 波动巨大（样本翻倍，估计立刻变脸）；它是"当前证据下的最佳解释"，不是终极真相。贝叶斯学派还会给它加上先验再修正。

**误区三**："你以为训练大模型用的是别的黑魔法。" 语言模型的逐词交叉熵损失、扩散模型的噪声预测损失，骨子里都是（变体）极大似然。工具在进化，灵魂没换过。

:::

**练习 2**：换成"三正一反"的数据，MLE 是多少？用扫描验证，再用公式 $\hat{p} = k/n$ 对照。

<details>
<summary>点开查看逐步解答</summary>

$k=3, n=4$，公式给出 $\hat{p} = 3/4 = 0.75$。数值验证：

```python
best_p = 0.0
best_L = 0.0
for k in range(1, 100):
    p = k / 100
    L = p ** 3 * (1 - p) ** 1     # 三正一反
    if L > best_L:
        best_L = L
        best_p = p
print(best_p)                     # 0.75
print(round(best_L, 4))           # 0.1055
```

峰顶随数据移动——似然曲线永远围着证据转。这也解释了为什么小样本的 MLE 不稳定：四枚硬币的偶然性足以把峰顶拨到任何地方。
</details>

## 7. 选读：从似然到损失函数的一步

<details>
<summary>选读 · 为什么训练代码里找不到"最大化"</summary>

优化器习惯做**最小化**，于是把最大化似然改写成最小化负对数似然：

$$\text{Loss}(\theta) = -\sum_{i=1}^{n} \ln p_\theta(x_i)$$

对语言模型：每个 $x_i$ 是真实下一个词，$p_\theta(x_i)$ 是模型给它的概率——这正是交叉熵。三条好处：(1) 连乘变累加，数值稳定；(2) 取对数后处处可微，方便梯度下降；(3) 与 KL 散度只差一个常数项（数据的熵），所以"压损失"等价于"拉近模型分布与数据分布"。

第 41 章还会补一刀：纯粹追 MLE 会把训练集背得滚瓜烂熟而丧失泛化——所以正则化、早停、验证集这些防过拟合装置，本质都是在给"极大似然"这匹烈马套缰绳。

</details>
