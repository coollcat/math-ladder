# 怎么用本站

## 你需要会什么

- **Python**：变量赋值、`if` 判断、`for` 循环、`def` 定义函数、列表的基本用法。这是唯一的前置要求。
- **数学**：不需要。我们从 $1+1$ 开始。

## 页面上的三种积木

### 1. 代码块 + 浮窗运行器

全站 Python 代码块右上角有一个 **▶ 浮窗运行** 按钮（带滑块交互的实验块则显示 **▶ 浮窗实验**）：

- 点击后代码被装进右下角的**浮窗控制台**，在那里自由修改、运行；
- 浮窗是常驻的：换页、关掉再开，你的草稿都还在；
- 首次运行需下载约 10 MB 的 Python 运行时（Pyodide），之后秒开；画图自动显示。

### 2. 折叠的答案与证明

练习题的解答放在「点开查看逐步解答」折叠块里：**先自己动笔，再展开对照**。标了「选读」的折叠块是更严格的论证，跳过不影响主线。

### 3. 测验、练习与进度

- 课程里穿插**选择题测验**：点选项、按提交，立刻知道对错和原因；
- 动手练习点「▶ 在浮窗作答」，浮窗进入**判题模式**：改代码 → 运行并检查 → 输出与期望一致就亮绿灯；卡住点「提示」；
- 通过状态、代码草稿、每课「已学完」标记都存在你自己的浏览器里，下次打开还在。

### 4. 随手算草稿

浮窗的默认页面是**随手算**：变量在多次运行之间保留（第 1 行定义 `x`，下次运行还能用），草稿自动保存。从课程代码块进入后，点「← 随手算」随时切回自己的草稿。标题栏可拖动，`Esc` 关闭。

### 5. 误区卡片

红色「常见误区」卡片收集了大多数人在这一步会踩的坑。看到它的时候，恭喜——你正在绕过一个坑。

## 方法准入制度（本站的独特规则）

很多教程的代码会突然冒出 `math.sqrt(x)`、`abs(x)` 这种"魔法调用"，读者不知道它凭什么存在。本站立了一条铁律：

> **任何工具（函数），必须在它出现之前的某节课里，讲清楚它是怎么被发明出来的；否则构建脚本直接报错，网站无法发布。**

所以：

- 看到 `sum(...)` 时，你一定在之前的课程里见过"不用 sum 怎么手写循环求和"；
- 看到 `math.sqrt(...)` 时，你一定见过"不开方、只用乘法逼近平方根"的过程；
- 这条规则由 `npm run validate` 强制检查，漏讲一处，构建失败。

你因此可以完全信任代码：**里面没有任何没讲过的东西**。

## 其他实用信息

- 右上角有**全文搜索**，支持中文；
- 导航栏可切换**暗色模式**；
- 手机上可用，代码块横向滑动；
- 公式由 KaTeX 渲染，行内公式形如 $a^2+b^2=c^2$，重要公式单独成行：

$$e^{i\pi} + 1 = 0$$

现在这个公式对你来说是天书，走到第 12 章它会变得像 $1+1$ 一样自然——这正是本站存在的意义。
