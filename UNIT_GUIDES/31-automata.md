## 4. 理论难点处理

1. **NFA 不是随机机**：统一讲成“存在一条接受路径”，并用可达状态集合过渡到子集构造。
2. **封闭性的方向**：只说已知正则可构造出新正则，不用封闭性反向证明某个语言正则。
3. **泵引理量词**：明确必要条件；反证时选坏长串，再排除全部合法拆法。
4. **最小 DFA**：以“所有未来后缀不可区分”为主线，避免把状态重命名当成最小化。
5. **PDA 接受约定**：提醒栈空、输入耗尽、接受态三种约定必须区分。
6. **歧义**：以不同解析树定义，不以推导顺序定义；同时指出固有歧义语言存在。
7. **CYK**：强制 CNF 前提，先判成员再谈树恢复，避免学生把表格当成完整树。

## 6. 待实现专属组件规格

### 公共需求

1. 所有组件使用现有 `viz` JSON 围栏接入，渲染失败显示可读错误。
2. 状态节点支持鼠标、触屏和键盘拖动，保存节点 `x/y` 到组件内部状态，路由切换后重扫不重复绑定。
3. 运行头、栈指针、高亮路径必须有步进控制和可选动画；动画期间禁用重入按钮。
4. 暗色模式对比度达标，移动端优先支持纵向布局。
5. 每个组件提供重置、随机样例和逐步执行；不接受 `while True` 式连续循环。

### dfa-runner

- 目标：可视化五元组 $(Q,\Sigma,\delta,q_0,F)$。
- 配置：`states`、`alphabet`、`transitions`、`start`、`accepting`、`input`。
- 必做：拖动状态节点；点击边编辑转移；运行头随输入前进；终态绿色、拒绝态红色提示。
- 课程落点：30、50、65。

### nfa-guesser

- 目标：展示零条、一条或多条平行路径。
- 必做：同一输入同时维护可达状态集合；可展开具体路径；接受路径金色高亮，失败路径灰化。
- 课程落点：40、45、55。

### subset-construction

- 目标：左侧 NFA，右侧逐步生成子集 DFA。
- 配置：NFA 五元组和最大展开状态数。
- 必做：每一步显示旧集合、符号、合并结果和新状态名；可达子集队列可见；支持撤销一步。
- 课程落点：45、55。

### regex-nfa-map

- 目标：把正则表达式 AST 与 Thompson 构造片段联动。
- 配置：受控正则表达式，仅支持连接、选择、星号和字面量。
- 必做：选中子表达式时高亮对应片段；星号回路动画展示重复；不允许未转义危险输入直接求值。
- 课程落点：55、60。

### pda-stack

- 目标：有限控制加栈的同步动画。
- 配置：输入串、状态集、栈规则、初始栈底。
- 必做：push/pop 有高度变化和缓动动画；栈顶指针始终可见；每步列出 `(state,input,top)` 到 `(state',replace)`。
- 课程落点：70、75、90。

### parse-tree-builder

- 目标：手动和半自动构建 CFG 解析树。
- 配置：CFG、目标串、最大树深。
- 必做：拖动节点调整布局但不改变父子关系；选择产生式生成孩子；多棵树并排比较以演示歧义。
- 课程落点：75、80、85。
