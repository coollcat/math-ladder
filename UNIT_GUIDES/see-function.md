## 一、总览

`/function` 是一个「拼式子 → 立刻看见形状」的站级工具页，顶栏入口「看见函数」。
**同一个输入框认八种形态**：平面四种（y = f(x)、极坐标 r(θ)、参数曲线、隐函数 F(x, y) = 0），
立体四种（曲面 z = f(x, y)、参数曲面、空间曲线、球坐标 r(θ, φ)）。形态由 `forms.js` 按写法猜，
猜歪了点卡片下方的形态按钮重开一张带例子的卡片；平面最多叠 6 条曲线，立体最多叠 3 个对象。
内核是纯 JS（不依赖 React、不依赖 lab 底座），所以既能挂在页面，也能被课文用
` ```lab ` 围栏嵌进去（type 为 `see-function`，注册在 `lab/registries/ch00.js`；
课文给 `mode` / `domain` / `view` / `funcs` / `params` 覆盖默认值）。
它还和 Py 浮窗双向互通：出去译成 numpy / sympy 代码，回来走 `see()` / `seen()`（见 §五）。

除 `x` 外的未知标识符一律当**可调参数**（含 `theta`/`alpha` 这类希腊字母名），
自动出滑块；未知的多字母名 + `(`，单字母按乘法、多字母报「不认识的函数」。

## 二、踩过的坑，别再踩

1. `segments()` 的尺度必须用**分位数**而不是 max−min。tan(x) 在渐近线旁那几个
   采样值能到几万，拿 max−min 当尺子，真正的跳变反而「不够大」，整条 tan 会连成一根。
2. 断点要在**均匀采样上先找出来，再逐段自适应细分**。反过来（先细分再判断）
   细分会在渐近线旁插出一堆巨值，把判据彻底带偏。
3. 采样要 `healIsolated()` 补掉孤立的可去奇点。sin(x)/x 在 x=0 是 0/0，
   采样点又刚好落在 0 上，不补的话这条最该被看见的曲线中间会留个缺口。
   只补「两侧都算得出且彼此挨得近」的——1/x 在 0 两边是 ±64 那种悬崖不能补。
4. 曲线换算屏幕坐标前，y 要夹到视窗外 20 屏（`sySafe`）。1/x 在极点能算出 1e12，
   直接换算出的像素坐标大到 Canvas 会整条不画。
5. 拖画布/缩放时**只重画不重采样**，重采交给防抖回调；拖滑块走 rAF 合并。
   每帧几千次函数求值会拖成幻灯片。
6. 积分遇到算不出的点：内部点两侧差得远 → 报 NaN（真极点）；
   两侧挨得近 → 插值补上（可去奇点）；端点 → 用内侧两点线性外推。
   `∫₀¹⁰ sin(x)/x` 就是靠外推算出来的（1.65835 = Si(10)）。
7. JSX 里写 LaTeX 示例必须走字符串（`<code>{'\\frac{\\sin x}{x}'}</code>`）：
   花括号会被当表达式，`\f` 会被当换页符转义。

## 三、立体模式另有几条

8. 自变量表跟着模式走（2D 是 `['x']`，3D 是 `['x','y']`），由 `build(src, { vars })`
   指定。**切模式必须把所有式子重新编译一遍**，否则 y 的身份（自变量/参数）是旧的。
   2D 下 y 仍然是可调参数，这点别改——已经有人用 y 当旋钮了。
9. 三个方向必须先归一到可比的尺度再投影，z 还要乘 zScale（0.6）夸张一下；
   曲面起伏通常比 xy 范围小一个量级，不夸张看上去就是一张平板。
10. 旋转**不需要重新采样**：采样发生在 xy 平面上，与视角无关。拖动画布只重投影重画；
    真要重采的只有改式子、拖参数、改域这三种情况。拖动时 surface 内部会把
    精度降到 1/4（lod=2），否则 1600 个面片逐帧重画会掉帧。
11. 立体是**多对象**场景（`surface.js` 收 `objects[]`，`MAX_FUNCS_3D` = 3）：面片按深度排序后画，
    不是逐像素深度测试——两张面真正穿插的交线附近前后遮挡可能错一两格，这是已知上限，
    别再退回「只画一条」。要精确对比就让人把两式相减看高度差。
12. `healGrid2` 分辨可去奇点与真极点，靠的是**往外再走一步看落差**，不是四邻是否相等：
    `1/(x²+y²)` 在原点四邻对称、四个值完全相等，但往外一步从 400 掉到 100（75%），
    那是尖峰不是平板，补上就是在悬崖上铺一块假地板。`sin(r)/r` 往外一步只掉 0.1%，可以补。
13. 中心差分的分母是 `xs[i+1] - xs[i-1]`（全跨度），不是它的两倍。
    `(f(x+h)-f(x-h))/2h` 里的 `2h` 恰好就是这个全跨度，再乘一次 2 会得到一半的导数。
    曲面法线由它给出，错了整张图的光影都是歪的。
14. 悬停探针（反投影求光标落在 z=0 平面的 (x,y)）：水平面投影是正交矩阵，
    逆变换就是转置；T 从 ry 里扣掉 z=0 平面的高度贡献。仰角压到接近 0 时
    ry 与 u、v 无关，反解除零爆炸——`|sin(el)| < 0.05` 直接放弃探针。
15. `extrema2` 的同类合并是**双规则**：候选相距 ≤4 格直接并（谷线/山脊这类
    候选密集的线状结构），或从候选出发走「高度与种子相差 <1%」的格子泛滥
    （涟漪环带这种近平通道整圈连得通）。两条缺一不可：涟漪环在对角扇区有
    十几格的候选空洞，光靠距离连不上；尖谷谷线每步落差 20%，光靠等高连不动。
    另外极小**不能按 |z| 降序**排：谷底尖端 z=0 会被排到最后被 limit 截掉，
    显示出来的反而全是谷线远端的「极小」——极小按 z 升序（最深的先）。
16. `healGrid2` 往外走一步的邻居要看守住边界：`z[k-2]` 在 j==1 时索引合法
    但**位置在上一行末尾**（比越界更隐蔽），负索引则靠 undefined→NaN 侥幸。
    显式给 NaN 才是「这一侧没有第二步」的正确表达。
17. 画布高度：CSS（`.ml-fn__plot` 的 440/360/300 响应式）是唯一事实来源，
    JS 侧别再抢着给默认 420——窄屏时画布比容器高 120px，底部被
    `overflow:hidden` 切掉。`workspace` 只把课文显式给的 `height` 传下去。

## 四、嵌进课文时（2026-09-04 卷一回填 28 门课的实证）

18. **围栏写 ```lab，不是 ```viz**。see-function 注册在 `lab/registries/ch00.js`，
    写成 viz 会被 validate 以「未知 viz 类型」拦下；但 validate 对 lab 块**只查
    JSON 合法 + type 白名单 + 滑块规格，不查 funcs/params 字段**——字段错了照样放行，
    出错只发生在页面上，必须人工逐块核对。
19. **params 初值必须落在 [-10, 10]**：`workspace.js:582` 把滑块范围**写死**为
    `min=-10 / max=10 / step=0.05`，没有自定义入口。初值超范围（如 `{"C": 24}`）
    会被浏览器夹到 10，滑块把手与实际取值对不上，用户一拖曲线跳变。
    修法是用派生写法绕开（`C=24` 改成 `4*a` 且 `{"a": 6}`），不是硬塞超范围初值。
20. **3D 块的曲面要在 domain 内看得见**：`mode:"3d"` 时域是 `[-domain, domain]²`，
    `sqrt(R^2 - x^2 - y^2)` 这类式子必须让 R 的初值 ≈ domain，否则 R 远小于 domain
    时只有极小一块有值、R=0 或负则整块空白。另外**3D 下 y 是自变量不是参数**，
    `a*x + b*y + c` 里只有 `a/b/c` 进 params。
21. 除零式（`q/(p-1)` 这类）滑块能拖到分母为 0：JS 不崩（得 ±Infinity，曲线画不出来）。
    要么改式子，要么像 08 章 35 课那样**把它写成教学点**（"p=1 时该改用等差数列"）。

## 五、多形态、视野与 Python 联动（2026-10）

### 形态表（`forms.js` 的 `KINDS`）

| kind | 模式 | 写法示例 | 自变量 | 自带范围 |
|---|---|---|---|---|
| `fx` | 2d | `sin(x)/x`、`y = x^2` | x | 视野 |
| `polar` | 2d | `r = 1 + cos(θ)` | θ | [0, 2π] |
| `param2` | 2d | `(cos(t), sin(t))` | t | [0, 2π] |
| `implicit` | 2d | `x^2 + y^2 = 4` | x, y | 视野 |
| `fxy` | 3d | `x*y`、`z = sin(x)cos(y)` | x, y | 域 [−d, d]² |
| `psurf` | 3d | `(cos(u)sin(v), sin(u)sin(v), cos(v))` | u, v | [0, 2π]² |
| `curve3` | 3d | `(cos(t), sin(t), t/6)` | t | [0, 4π] |
| `sph` | 3d | `r = 1 + 0.2 sin(5θ)` | θ, φ | θ[0,2π] φ[0,π] |

- 范围写在 `KINDS[kind].ranges`，卡片里渲染成「θ 0 … 2π」起止框；改了就重采样。
- 除自变量外的未知标识符仍是可调参数（自动出滑块）。**2D 下 y 是参数，3D 下 y 是自变量**，别混。
- `guessMode(raw)` 只在「Python 送来的字符串没说模式」时用：2D 能解析且出现 y / z / polar 里的 φ → `3d`，否则 `2d`。

### 视野：`fitView()`

- 只有 y = f(x)：x 不动，按曲线定 y 的上下界（`plot.fitY(0.12)`）。
- 一旦有极坐标 / 参数曲线 / 隐函数：**横纵必须等比例**，否则圆画成椭圆、心形线被压扁。
  参数与极坐标按自己的采样框住（两端各去掉 0.5% 的冲天值）四周留 8%；
  只有隐函数时 x 范围保持不动、y 以描出来的部分为中心。
- 等比例靠 `plot.width / plot.height` 算尺度，这两个值是画布最近一次量到的尺寸。

### 与 Python 互通

**出去**（工作区 → 浮窗）：`snapshot()` 打一份快照（mode / view / domain / angles / params / funcs），
`topy.js` 从同一棵 AST 现翻 numpy 与 sympy 两份代码，`openInConsole(key, { autorun: true })` 送进浮窗并运行。

- key 是 `fn-numpy` / `fn-sympy`（不是随手算的旧通道）。
- 3D 带上 `view_init(elev, azim)` 对齐此刻视角，2D 对齐 x 范围与 y 上下界。
- 参数变成脚本里的数值字典；函数名过 `pyName` 洗过（`f1` 这种名字不直呼，统一 `seen(i)` 回调）。

**回来**（浮窗 → 工作区）：`pybridge.js` 的 `PY_FN_HELPERS` 在 Pyodide 里把 `see()` / `seen()` 挂到 builtins。

- `see("sin(x)")` 字符串、`see(sp.diff(f, x))` sympy 表达式（`sp.Eq` → 隐函数）、
  `see(lambda x, a=1: a*np.sin(x))` Python 函数、`see(("cos(t)", "sin(t)"), t=(0, 6.3))` 元组 = 参数式；
  `add=True` 叠加、`mode` / `x` / `domain` / `theta` 等关键字覆盖默认。
- 落地链路：`hub.push(JSON)` → `applySpec(spec)`；`applySpec` 认 `funcs` / `params` / `view` / `domain` / `ranges` / `mode` / `add`。
  spec 有错时 `api.specError` 会被设上，`bridge.js` 据此销毁内嵌实例并抛出——别把错的式子悄悄画成空图。
- **Python 函数不翻译成式子**：`_ml_fn_register` 把它存进 `_ml_fn_reg`（48 条 FIFO），工作区里是一条 `kind:'py'` 的曲线，
  采样走 `_ml_fn_sample` —— 一次给一整排 x（或一张 x-y 网格），numpy 向量化算完按逗号串回来（`nan` 正好被 `parseFloat` 读成 NaN）。
  图上显示成 `f1(x, y) ← 浮窗里的 Python 函数`，这是身份不是表达式；带数值默认值的参数变滑块。
- `seen(i)` 反向取快照，得到 `SeenFunction`：直接按 numpy 求值，`.sym` 给 sympy 形式，`.py` 的复用注册表。

**分享链接**：`shareSpec()` 生成 `?f=<式子>&m=3d`（多函数 / 参数 / 范围 / 视野各有键），
`bridge.readUrlSpec()` 解析，`FunctionLab` 的 `fromUrl` 把它交给 `applySpec()`。改了参数不会静默改写 URL，复制链接才是显式动作。

### 切模式：式子不换，只换画法

- `enterMode()` **把当前的式子原样带到另一种模式**（平面 ⇄ 立体），不再各存一份：同一个
  `sin(x)/x` 在平面是曲线、在立体是「沿 y 拉伸出来的幕布」；`r = 1 + cos(θ)` 在平面是极坐标
  心形线、在立体自动认成球坐标 r(θ, φ)。参数值与视野仍然**各模式各记一份**（`paramsBy`）。
- 带不过去的式子不静默：`parseOne()` 编译失败时会先拿对面的模式再试一次（`modeHint()`），
  能认出来就把错误换成「这是隐函数，只能在「平面」里画——点上面的「平面」……」；认不出来才报原始语法错。
- 立体上限 3 个对象、平面 6 条：超出的卡片留在原地（`.ml-fn__card.is-capped` 虚线 + 降透明度），
  卡片区顶部明写「后面 k 条先收着，切回「平面」就都画」，**不删式子**。渲染侧（`recompute3`）本来就
  只取前 `MAX_FUNCS_3D` 条，这里只是把「没画」这件事说出来。
- `setMode()` 里顺序是 `refreshAll()` → `renderCards()`：先按新模式重新编译，再建卡片，
  否则标题会停在旧形态上（`f₁(x) =` 该是 `f₁(x, y) =`）。

### 右上角「此刻这张图」

- 页面右格不再写固定说明：`workspace.js` 通过 `createWorkspace(host, { onIntro })` 把
  `{ mode, kind, args, params, error, count, domain }` 推给 `FunctionLab` → `src/pages/function.js` 的
  `<NowBox>`，形态名与一句话解释、自变量、可调参数、报错都跟着当前活动卡片走。
- 只在内容真的变了才回调（`notifyIntro()` 用 JSON 串去重）：`refreshAll` / `scheduleParse`（打字防抖后）
  / `syncActive`（切换活动卡片）三处触发。
- 文案表在 `function.js` 的 `FORM_INTRO`（八种形态 + `py`），加形态时记得补一条。

### 踩坑
